# 707 散らばりが x とともに広がるデータで、ふつうの標準誤差の95%区間は何%当たるのか（手法の解説・正解の分かるデータで試す）

回帰のふつうの標準誤差は「誤差の散らばりがどこでも同じ」という前提で出します。散らばりが x とともに広がる（不均一分散）と、区間が狭すぎて本当の値を含まないことが増えます。そのときに使うのが、散らばりの違いを認める「頑健な標準誤差」（HC0・HC3 など）です。**ここでは、y=1+0.5x+誤差（誤差の標準偏差＝x^h、x は右に裾の長い分布）で、h と件数を変えて各4,000回、傾きの95%区間が本当の値0.5を含む割合を数えました。** 数字は置いた前提で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A707 | 不均一分散のとき、ふつう・HC0・HC3 の95%区間は何%当たるか | 単回帰。h=0・0.5・1・1.5、n=20・50・200・1000、各4,000回。式で出した標準誤差が statsmodels の OLS（nonrobust・HC0・HC3）と一致することを確認。seed 707 | `src/a707_robust_se.py` |

## 主な結果
- **ふつうの標準誤差**：200件で、h=0（散らばり一定）なら95.3%当たるが、h=0.5で80.6%、**h=1 で63.8%**、h=1.5で51.8%。標準誤差は本当のばらつきの0.67倍・0.46倍・0.34倍
- **件数を増やしても直らない**：h=1 で20件72.0%、1000件62.1%
- **HC0（ホワイト）**：件数が多ければ直る（h=1・1000件で94.1%）が、少ないと甘い（h=1・20件で77.3%、h=0・20件でも88.9%）
- **HC3**：20件でも89〜94%、200件以上で93〜95%。散らばりが一定のときも94〜95%で、使って損は小さい

- h=0 ではふつうの標準誤差が約95%当たり、作りが正しいことを確かめた

- データファイルは置いていない。データはコードの中で乱数から作る（seed 707）
- 仮定：x は自由度3のχ²分布を3で割ったもの（平均1、右に裾が長い）。誤差は正規分布で、標準偏差が x^h
