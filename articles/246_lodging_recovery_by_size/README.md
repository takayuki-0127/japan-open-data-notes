# 246 施設の大きさで、宿泊客の戻り方は違ったのか

観光庁「宿泊旅行統計調査」の年の確定値（2015〜2025年）で、宿泊施設を従業者数で4つ（0〜9人・10〜29人・30〜99人・100人以上）に分け、延べ宿泊者数と客室稼働率がコロナの前（2019年）に戻ったかを比べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A246 | 施設の大きさ（従業者数）で、客の戻り方は違ったのか | 従業者数の区分ごとの延べ宿泊者数・実宿泊者数を2019年＝100で比べる／客室稼働率の比較／2025年の各月を2019年の同じ月と比べる／延べ宿泊者数の変化を施設数と1施設あたりに分ける | `src/a246_recovery_by_size.py` |

## 主な結果
- 延べ宿泊者数（2019年＝100）が100を超えた年は、0〜9人と10〜29人が2023年（123.8・106.7）、30〜99人が2024年（105.5）、100人以上が2025年（103.3）。全体は2023年（103.6）
- 2025年は、0〜9人112.9、10〜29人118.8、30〜99人108.1、100人以上103.3、全体110.9
- 落ち込みも大きい施設ほど深かった。2021年は0〜9人62.0、100人以上40.5
- 実宿泊者数（泊数を数えない人数）では、2025年の100人以上は97.1で、まだ2019年を下回る
- 客室稼働率は、100人以上が75.6%（2019年）→70.8%（2025年）と4.8ポイント低い。0〜9人は37.0%→35.6%、10〜29人は69.8%→70.4%、30〜99人は72.3%→71.5%、全体は62.7%→61.6%
- 2019→2025年の延べ宿泊者数の変化を分けると、0〜9人は施設数が30.2%増え、1施設あたりは13.2%減った。10〜29人は施設数+4.6%・1施設あたり+13.6%、100人以上は施設数+0.8%・1施設あたり+2.4%（`results/a246_decomposition_2019_2025.csv`。全体の1施設あたりの話は記事249）

## 頑健性
- 2025年の各月を2019年の同じ月と比べても、100人以上が4つの区分でいちばん低い月は12か月中11か月（4月だけ0〜9人が低い）（`results/a246_monthly_2025_vs_2019.csv`）
- 延べ宿泊者数でなく実宿泊者数で比べても、大きい施設ほど戻りが小さい順番は同じ（2025年：0〜9人107.6、10〜29人110.3、30〜99人103.1、100人以上97.1）
- 月の値の12か月の合計は、年計の値とすべての年・区分で一致した
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致することを確かめた

## 動かし方
```
pip install -r requirements.txt
cd src && python a246_recovery_by_size.py   # data/ の CSV から results/・figures/ を作る
python fetch.py             # data/ の CSV を観光庁の Excel から作り直す（任意。ネットにつながる環境で）
```

## データ
- `data/table<n>_national.csv`：観光庁「宿泊旅行統計調査」各年（2015〜2025年）の「1月〜12月分（年の確定値）集計結果」Excel から、全国の行だけを取り出したもの（`src/extract.py`）。month=0 は年計、1〜12 は各月。列名は `src/extract.py` の COLS（total＝総数、tour＝観光目的の宿泊者が50%以上の施設、biz＝同50%未満の施設、s0_9 など＝従業者数の区分、foreign＝うち外国人）
- 施設数（第1表）は各月の値で、年の値は12か月の平均にした

## 注意
- 従業者数の区分は施設ごとの区分で、年によって施設が別の区分に移ることがある。区分ごとの変化には、施設の出入り（新しく開いた施設・閉じた施設）も入る
- 宿泊旅行統計調査は標本調査で、従業者数の小さい施設ほど誤差が大きい（調査の「主要項目別標準誤差率」を参照）
- 客室稼働率は調査票の利用客室数と客室数から出した値。大きい施設の稼働率が下がった理由（客室の増加、価格、働き手の不足など）は、この表からは分からない
- 2026年1月分から、調査の層の分け方が「従業者数」から「客室数」に変わった。この記事は2025年までの従業者数の区分で、2026年以降と同じ形ではつなげない
