# 866 途中でやめた人の回答を入れるか除くかで、結果は変わるのか？（アンケート）

長いアンケートでは、途中で答えるのをやめる人が出ます。集計では「答えた分はすべて使う（入れる）」か「最後まで答えた人だけを使う（除く）」かを決めることになりますが、やめる人の満足が答え続ける人と違うと、どちらでも結果はずれます。ずれ方も違い、「入れる」では問ごとに土台の人が変わるので、前の問と後の問を比べると読み違えます。**ここでは、作成者が乱数で作った架空の家具店の購入者アンケート（12問・1〜5の5段階。客ごとの本当の満足の高さと、満足の低い客ほどやめやすいくせを作成者が置いたもの）で、入れる・除く・除く＋問1の答えで重み付けの3つの数え方が、全員が最後まで答えたときの平均（正解）からどれだけずれるかを数えました。**

回答者の顔ぶれ（そもそも答えるかどうか）は関連する記事 870、同じ選択肢ばかり選ぶ回答の扱いは 867 で扱っています。この記事は「答え始めた人が途中でやめる」場面に絞ります。

| A866 | 途中でやめた客の回答を入れるか除くかで、問ごとの平均と、問どうしの差はどれだけずれるか。最後まで答えた客を問1の答えで重み付けすると、ずれはどれだけ減るか | 架空の家具店の購入者アンケートを始めた客800人。客ごとの本当の満足の高さ z は標準正規。問 q（12問）の答えは round(μ_q＋0.8z＋0.6e) を1〜5で切ったもの（e は標準正規、μ_q は問ごとに3.1〜3.9）。正解は「始めた客全員が最後まで答えたときの平均」。問1は全員が答え、問 q に答えたあと確率 1/(1+exp(−(a−b·z))) でやめる。b=0.8（満足の低い客ほどやめやすい強さ）、a は最後まで答える客が65%になるように決めた（a=−3.36）。数え方は3つ：①入れる（問ごとに、その問まで答えた客の平均）②除く（最後まで答えた客だけの平均）③除く＋問1で重み（最後まで答えた客を、問1の答え1〜5の割合が始めた客全員と同じになるように重み付け）。調査を作り直して2,000回。確かめとして、結びつき b（0・0.4・0.8・1.2）×最後まで答える割合（85・65・45%）の12通り（各500回）を数えた。seed 866 | `src/a866_dropout.py` |

「満足の低い客ほどやめやすい」は作成者が置いた前提です。実際の回答者がそうだと測ったものではありません。

## 主な結果

### 問ごとのずれ（2,000回の平均、`results/by_question.csv`）
| 問 | 答えた客 | 正解 | 入れる | 除く | 除く＋問1で重み |
|---|---|---|---|---|---|
| 問1 店全体の満足 | 100% | 3.57 | 3.57（+0.00） | 3.79（+0.22） | 3.57（+0.00） |
| 問6 配送の日時 | 81% | 3.29 | 3.41（+0.12） | 3.52（+0.23） | 3.40（+0.11） |
| 問12 また来たいか | 65% | 3.48 | 3.70（+0.22） | 3.70（+0.22） | 3.59（+0.11） |
| 12問の平均のずれ | | | +0.12 | +0.22 | +0.10 |

- 「除く」は、どの問も正解より約0.22点高く出た（最後まで答えた客は満足の高い客に偏るため）
- 「入れる」は、問1ではずれず、後の問ほど高くなり、問12では「除く」と同じ+0.22点になった。問ごとに、答えている客の顔ぶれが違う
- 「除く＋問1で重み」は、問1のずれを0にし、問2〜12のずれを約半分（+0.11前後）にした。問1の答えは本当の満足の一部しか表さないので、全部は消えなかった

### 前の問と後の問の比べ方（`a866_main.json` の diff_q12_minus_q1）
| | 正解 | 入れる | 除く | 除く＋問1で重み |
|---|---|---|---|---|
| 問12−問1 | −0.09 | **+0.13** | −0.09 | +0.01 |

- **本当は「また来たいか」が「店全体の満足」より0.09点低いのに、「入れる」では0.13点高く見え、向きが逆になった**。問1は全員、問12は残った65%の平均なので、差には「客の入れかわり」が混ざる
- 「除く」は水準は高くずれるが、同じ客どうしの比べなので差（−0.09）は正解とほぼ同じだった

### やめた客は、どんな客か（`a866_main.json` の z_by_last_answered）
- 本当の満足の高さ（全体の平均0）は、問1でやめた客が−0.74、問11でやめた客が−0.36、最後まで答えた客が+0.29。早くやめた客ほど満足が低い（作成者がそう置いた結果）

### 確かめ：結びつきの強さと、やめる客の多さ（12通り、各500回、`results/robustness.csv`）
| 結びつき b | 最後まで85% | 65% | 45% |
|---|---|---|---|
| 0（結びつきなし） | 0.000 / 0.000 | −0.001 / 0.000 | 0.000 / −0.001 |
| 0.4 | 0.048 / 0.019 | 0.124 / 0.050 | 0.219 / 0.091 |
| 0.8（基本） | 0.091 / 0.037 | 0.223 / 0.099 | 0.374 / 0.185 |
| 1.2 | 0.127 / 0.054 | 0.292 / 0.145 | 0.473 / 0.265 |

（「除く」/「除く＋問1で重み」の12問の平均のずれ、点）
- **満足とやめやすさが結びつかなければ（b=0）、入れても除いてもずれなかった**（12問の平均のずれは最大0.001点）。ずれるかどうかは「やめる客の多さ」ではなく「やめる客が答え続ける客と違うか」で決まり、違うときに、やめる客が多いほど大きくなった
- 結びつきがある9通りで、「除く」のずれは+0.05〜+0.47点、「除く＋問1で重み」は+0.02〜+0.27点。重みは「除く」のずれの44〜60%を消した（`a866_main.json` の weight_share_of_bias_removed）
- 「入れる」の問12−問1は、9通りで−0.05〜+0.38点（正解は−0.09前後）。9通りのうち7通りで、本当は下がる差が上がって見えた

### 1回分の調査（data/respondents.csv）
- 最後まで答えた客は64.2%。問1：正解3.55、除く3.78。問12：正解3.42、入れる・除く3.68、除く＋問1で重み3.55（`a866_main.json` の one_survey）

## 動かし方
```
pip install -r requirements.txt
cd src && python a866_dropout.py
```
10秒ほどで終わります。`data/` の2つのファイルもこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約8秒）
- 満足とやめやすさの結びつきを0にすると、3つの数え方すべてでずれが0.001点以内になることを確かめた（結びつきがないのにずれる作りの誤りがないこと）
- ずれの大きさは、結びつきの強さとやめる客の多さで0.05〜0.47点と動いた（確かめ）。「0.22点」は基本の置き方での値

## データ
- `data/respondents.csv`：1回分の架空の客800人。id・last_answered（最後に答えた問）・q1〜q12（実際に集まった答え。やめた後は空）・full_q1〜full_q12（最後まで答えたらこう答えた、という作成者だけが知る答え）・z（本当の満足の高さ、作成者だけが知る値）
- `data/questions.csv`：問の番号・内容・μ（問ごとの答えの中心）

## 注意（言えないこと）
- 架空のデータです。問ごとの答えの中心、満足とやめやすさの結びつき、やめる客の多さは作成者が置いたもので、結果はこれで決まります。とくにずれの向き（高く出る）は「満足の低い客ほどやめやすい」と置いたためで、逆に置けば逆向きにずれます
- やめるかどうかは本当の満足だけで決まると置きました。問の長さや答えにくさ、画面の見づらさで特定の問でやめる、という置き方はしていません
- 重み付けは問1の答えだけを使う簡単なものです。ほかの情報（購入した品・回答にかかった時間など）を使う方法や、やめた後の答えを推し量って埋める方法は扱っていません
- 「どの数え方がよいか」は、やめる客が答え続ける客とどれだけ違うかで変わり、実際のアンケートではそれが分かりません。この記事は、ずれの向きと大きさの見当をつけるためのものです
- 実在の店や調査を表すものではありません
