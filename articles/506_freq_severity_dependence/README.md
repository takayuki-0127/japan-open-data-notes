# 506 事故の件数と1件あたりの額が一緒に動くとき、別々に見積もった年間損害の「200年に1度」はどれだけ小さく出るのか（保険数理・リスク）

年間の損害は「件数 × 1件あたりの額」の積み上げです。件数と額を別々に見積もり、独立として組み合わせることがよくあります。**ここでは、年ごとの共通の要因（景気・天候など）が件数と額の両方を動かす架空の年間損害を作り、件数と額を別々に見積もって組み合わせた分布と、本当の分布の99.5%点（200年に1度の額）・99%点・平均を比べました。** 数字は、置いた分布と共通の要因の大きさで決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A506 | 件数と額が一緒に動くとき、独立とみなした積み上げは99.5%点をどれだけ小さく出すか | 件数 N ~ ポアソン(50・Z)、1件の額 X ~ 対数正規(13 + b・log Z, 1)、Z は平均1の対数正規（大きさ σ_Z = 0.1・0.2・0.3）。b（つながりの強さ）を −0.5〜2 に変える。各20万年分。「別々の見積もり」は、件数は年ごとの件数の分布、額はすべての請求を集めた分布をそのまま使い、独立に組み合わせる | `src/a506_freq_sev.py` |

## 主な結果
- **基本の場合（σ_Z=0.2、b=1、件数と1件あたりの平均額の順位の相関0.59）**：本当の99.5%点は1.08億円、別々に見積もると0.76億円（29.0%小さい）。平均はほぼ同じ（−0.1%）
- 同じ条件で種を変えて10回くり返すと、99.5%点のずれは −28.6%〜−29.7%
- **つながりの強さ**：σ_Z=0.2 で b=0.5 なら −15.7%、b=1.5 なら −41.2%、b=2 なら −50.3%。99%点（100年に1度）のずれは99.5%点より少し小さい（b=1 で −25.8%）
- **共通の要因の大きさ**：b=1 で σ_Z=0.1 なら −11.2%、0.3 なら −43.1%
- **逆向きに動くとき（b=−0.5）**：別々の見積もりは逆に大きく出る（σ_Z=0.2 で +11.5%）
- **独立のとき（b=0）**：ずれは ±0.3% 以内

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- b=0 のとき、本当と別々の見積もりの99.5%点がほぼ一致する（差 −0.3%）こと
- 平均が一致すること（額を「集めた請求」の分布から取るので、件数の多い年の請求が多く入り、平均は合う）

## 注意（言えないこと）
- 架空のシミュレーション。ずれの大きさは、置いた分布（ポアソン・対数正規）、共通の要因の形と大きさ、つながりの強さで決まる。実際のリスクで何%になるかは言えない
- 「別々の見積もり」は、当てはめの誤差がない理想の場合。実際には当てはめの誤差も加わる
- 資本・準備金・規制の計算方法を勧めるものではない。件数と額のつながりを無視すると裾がどう動くかを数えたもの
- 相関の物差しは「年ごとの件数と1件あたりの平均額の順位の相関」。ほかの物差しでは数値が変わる
