# 1261 失注した商談の一部が記録に残らないと、受注率はどれだけ高く出るのか？（受注の見込み）

受注率は、商談の記録に残った商談から数えます。取れた商談はほぼ必ず記録に残りますが、取れなかった商談は、初回の打ち合わせのあとで立ち消えになったものなど、記録に付けないまま終わることがあります。分母から取れなかった商談が抜けるので、受注率は高く出ます。抜け方が商談の種類で違うと、種類ごとの受注率の大小が入れかわり、記録の付け方を変えた期には、受注の確率が変わっていないのに受注率が下がって見えます。**ここでは、作成者が乱数で作った架空の会社の法人向けの商談（商談ごとに、取れるか取れないか、取れない商談がどの段階で終わったか、金額の大きさを作成者が置いたもの）で、取れなかった商談が記録に残らないと受注率がどれだけ高く出るか、金額の大きさで比べたときにどうなるか、記録の付け方を途中で変えたときにどう見えるかを数えました。本当の受注の確率・初回の打ち合わせのあとで終わる商談の多さ・そこでの残りやすさを変えた27通りも確かめました。**

例の会社・商談は架空のもので、実在の会社や商談の記録の数字ではありません。数えたのは商談の記録の数え方だけで、担当の評価の決め方や、どの商談に力を入れるべきかの助言はしません。

関連する記事：970「「答えなかった人」は、答えた人と同じなのか？」は、記録に残らなかった人が残った人と違うときのずれを、アンケートで扱っています。1225「結果が0件の検索を数から外すと、検索の良さはどう見えるのか？」は、数から外すものを変えると良し悪しが逆に見える例です。895「問い合わせから契約までの割合は、どこで落ちているのか？」は、段階ごとに進む割合を扱っています。1260「受注率を、その期に始まった商談で数えるか、その期に決まった商談で数えるかで、どれだけ違うのか？」は、どの商談も記録に残ると置いたうえで、受注率の分母の決め方を比べています。1262「長引いた商談ほど受注率が低いのは、長引いたせいか、もともと決まりにくい商談だからか？」は、決まるまでの日数ごとの受注率の差の読み方を扱っています。この記事は、取れなかった商談の一部が記録に残らないときに絞ります。

## 主な結果

### 取れなかった商談がでたらめに残らないとき（本当の受注の確率20%、200回の平均、`results/random_missing.csv`）
| 取れなかった商談のうち、記録に残らない割合 | 記録から数えた受注率 | 式の値 |
|---|---|---|
| 0% | 20.1% | 20.0% |
| 10% | 21.74% | 21.74% |
| 20% | 23.73% | 23.81% |
| 30% | **26.38%** | 26.32% |
| 40% | 29.44% | 29.41% |
| 50% | 33.29% | 33.33% |
| 60% | **38.31%** | 38.46% |

- 取れなかった商談の3割が残らないだけで、受注率は20%から26.38%に上がった。これは式どおりの値で、本当の受注の確率10・30%を合わせた21通りで、式の値との差は0.18ポイント以内だった
- 取れなかった商談が多い（本当の受注の確率が低い）ほど、残らない割合が同じでも受注率は何倍にも上がった（図1）

### 段階と金額の大きさで残りやすさが違うとき（基本の置き方、200回の平均、`results/base_by_size.csv`）
| | 本当の受注の確率 | 記録から数えた受注率 | 式の値 | 取れなかった商談のうち記録に残った割合 | 本当（提案まで進んだ商談） | 記録から数えた（提案まで進んだ商談） |
|---|---|---|---|---|---|---|
| 金額の小さい商談 | 17.88% | **27.61%** | 27.8% | 57.06% | 30.32% | 31.64% |
| 金額の大きい商談 | 22.08% | **25.69%** | 25.59% | 81.95% | 36.24% | 37.71% |
| 全体 | 19.98% | 26.52% | 26.54% | 69.17% | 33.32% | 34.72% |

- 全体の受注率は、本当の19.98%に対して26.52%と出た（12期分をまとめた値の、200回の10〜90%の範囲は24.92〜27.99%）
- 本当は大きい商談のほうが受注の確率が高い（22.08%対17.88%）のに、記録から数えると小さい商談のほうが高く見えた（27.61%対25.69%）。200回のうち、記録から数えた受注率で小さい商談のほうが高かったのは77.5%の回で、本当の受注の確率で小さい商談のほうが高かったのは0.5%の回だった
- 提案まで進んだ商談だけで数えると、記録から数えた値と本当の値の差は1.32〜1.47ポイントに縮み、大小は本当と同じ向き（大きい商談のほうが高い）になった。ただし、これは「提案まで進んだ商談の受注率」で、全体の受注率とは別の値です（全体の本当は19.98%、提案まで進んだ商談の本当は33.32%）

### 7期目から失注も記録に残すようにしたとき（本当の受注の確率は変えない、200回、`results/rule_change_by_quarter.csv`）
| | 記録に残った商談（1期あたり） | 本当の受注の確率 | 記録から数えた受注率 | 本当（提案まで進んだ商談） | 記録から数えた（提案まで進んだ商談） |
|---|---|---|---|---|---|
| 1〜6期 | 135.58件 | 20.04% | **26.61%** | 33.39% | 34.79% |
| 7〜12期 | 175.62件 | 19.98% | **20.48%** | 33.35% | 33.61% |

- 受注の確率は変えていないのに、記録から数えた受注率は26.61%から20.48%に下がって見えた。記録に残る商談は1期あたり135.58件から175.62件に増えた
- 6期目から7期目にかけて受注率が5ポイント以上下がった回は59.5%で、記録の付け方を変えていない5期目から6期目（12.0%）より多かった
- 提案まで進んだ商談で数えた受注率は34.79%から33.61%で、動きは1.18ポイントだった（提案のあとで終わった商談の残りやすさも90%→98%に変えた分）。提案まで進んだ商談は1期あたりの件数が少ないので、1期ごとの振れが大きく（各期の10〜90%の範囲を合わせて27.1〜41.3%。全体の受注率では16.37〜31.87%）、5ポイント以上下がった回は6→7期で34.5%、5→6期で20.0%だった

### 確かめ：27通り（各20万件、`results/grid.csv`）
- 記録から数えた受注率は、本当の受注の確率の1.1〜2.087倍（差+1.36〜+20.36ポイント）だった。27通りとも、取れなかった商談のうち記録に残らない割合からの式の値と0.32ポイント以内で合った
- いちばん高く出たのは、本当の受注の確率が低く、取れなかった商談の多くが初回の打ち合わせのあとで終わり、そこでほとんど残らないとき（本当の確率10%・初回のあと70%・残る確率20%で2.087倍）だった
- 提案まで進んだ商談で数えると、記録から数えた値と本当の値の差は+0.75〜+1.58ポイントだった（提案のあとで終わった商談の1割が残らない分）

## 注意（言えないこと）
- 架空のデータです。受注の確率、取れなかった商談が終わる段階、記録に残る確率は作成者が置いたもので、結果はこれで決まります。記録から数えた受注率の上がり方は、取れなかった商談の残らない割合からの式どおりです。新しく数えたのは、残りやすさが金額の大きさで違うと大小が入れかわる回の多さ（77.5%）と、記録の付け方を変えた期の下がり方です
- 金額の小さい商談ほど初回の打ち合わせのあとの失注が残りにくい、と置いたのは作成者です。逆の置き方なら、入れかわりの向きも逆になります
- 取れた商談はすべて記録に残ると置きました。取れた商談が記録から抜ける場合や、同じ商談が二重に記録される場合は入れていません
- 提案まで進んだ商談の受注率は、初回の打ち合わせのあとで終わった商談を除いた別の値で、全体の受注率の代わりにはなりません
- 実在の会社の受注率や記録の付け方を示すものではありません
