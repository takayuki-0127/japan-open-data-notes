# F61 小さい町の「ランキング1位」は、なぜ毎回入れ替わるのか？（ファンネルプロットと経験ベイズ）

**看板記事 F61**。市区町村の率でランキングを作ると、1位や最下位には人口の少ない町がよく並びます。分母が小さいと、数人の違いで率が大きく動くからです。ファンネルプロットで「偶然だけで出る範囲」を引き、経験ベイズ（全国の分布を使って小さい地域の率を全国寄りに縮める方法）で並べ直すと、ランキングの端がどれだけ変わるかを、死亡と検診の2つの指標で確かめました。

## 問い

- 検診受診率の市区町村ランキングで、1位・上位・下位にはどの規模の町が入るか。翌年も同じ町が残るか
- 本当の率が全団体で同じでも、1位はどの規模の町になるか（シミュレーション）
- ファンネルプロットで見ると、「偶然では説明できない差」はどれくらいあるか
- 経験ベイズで縮めると、ランキングの端の顔ぶれはどれだけ変わるか。それは指標によって違うか

## データ（新しい取得はなし）

| 指標 | 単位・期間 | 元の記事 | 出典 |
|---|---|---|---|
| 大腸がん・肺がん検診の対象者数と受診者数（国保・40〜69歳） | 4年度とも値のそろう1,656市区町村、2021〜2024年度 | F19 | 厚生労働省「地域保健・健康増進事業報告」 |
| 死亡数・期待死亡数（全死因・心疾患・脳血管疾患、男女計） | 1,887地域（政令市は区）、2018〜2022年 | F27 | 厚生労働省「人口動態保健所・市区町村別統計」 |

規模の区分は、検診は4年度の対象者数の平均（500人未満／500〜2,000人／2,000〜1万人／1万人以上）、死亡は期待死亡数（100人未満／100〜300人／300〜1,000人／1,000人以上）です。

## 手法

1. **ファンネルプロット**：横軸に分母（対象者数・期待死亡数）、縦軸に率をとり、「本当の値がみな全国と同じでも、偶然（二項分布・ポアソン分布）だけで出る範囲」（95%・99.8%）の線を引く。線の外に出る割合と、過分散の大きさ（φ）を求める
2. **経験ベイズ**：検診はベータ二項モデル、死亡はポアソン・ガンマ（負の二項）モデルで、全国の分布（平均とばらつき）を最尤法で推定し、各地域の率を「(実際の数＋事前の分)÷(分母＋事前の分)」で縮める。分母が小さいほど全国の値に寄る
3. **ランキングの比較**：年度ごとに、そのままの率と縮めた率で、1位・上位10・上位50・下位10・下位50の規模の内訳、翌年度も同じ範囲に残る割合、年度の間の順位相関、4年度の順位の幅を比べる
4. **翌年度の当てはまり**：t年度のそのままの率と縮めた率のどちらが、t+1年度の率に近いかを二乗誤差で比べる
5. **シミュレーション**：実際の分母のまま、全団体の本当の率を全国と同じにして2,000回つくり、1位・上位50がどの規模になるかを数える

## 主な結果

**検診受診率（大腸がん・国保40〜69歳）**

- **1位の顔ぶれ**：そのままの率の1位は、4年度とも別の町で、4つとも対象者500人未満でした（対象者は218人・25人・276人・46人。受診率は69.7%・96.0%・62.7%・76.1%）。全国の受診率は16.8%（2023年度）です
- **上位50の内訳**：対象者500人未満の町は全体の12%ですが、上位50のうち平均23団体（46%）を占めました。下位50では4団体です（小さい町はもともと受診率が高めで、上に偏ります）
- **翌年度も残る割合**：上位10は40%、下位10は40%、上位50は68%。1位が翌年度も1位だったことは一度もありません
- **順位の動き**：4年度の順位の幅（中央値）は、500人未満で258位、1万人以上で104位です。年度の間の順位相関は、500人未満で0.83、1万人以上で0.95でした
- **シミュレーション**：本当の受診率が全団体で同じでも、1位は99.8%の確率で対象者500人未満の町になり、上位50の67%を500人未満の町が占めます
- **ファンネルプロット（2023年度）**：99.8%の線の外に出たのは77%で、偶然の範囲をはるかに超えるばらつきがあります（過分散 φ=251）。線の外の割合は1万人以上で91%、500人未満で59%と、大きい町ほど「本当の差」がはっきり見えます
- **経験ベイズ**：町の間の本当の差（標準偏差で約9ポイント）が偶然のぶれより大きいため、縮める幅は小さく、生の率にかかる重みの中央値は500人未満でも0.94でした（動いた幅の中央値0.59ポイント）。上位50の500人未満の町は23→19団体、上位10が翌年度も残る割合は40%→50%、順位相関は0.925→0.926と、ランキングはほとんど変わりません。翌年度の率への当てはまりは、全体で5.1%、500人未満で9.8%良くなりました

**死亡（全死因の標準化死亡比、2018〜2022年）**

- **ファンネルプロット**：99.8%の線の外は42%。期待死亡数1,000人以上では52%ですが、100人未満では10%で、小さい地域の多くは「偶然の範囲」に収まります
- **地域の間の本当の差**：標準偏差で約9%。生の値にかかる重みの中央値は、期待死亡数100人未満で0.32、100〜300人で0.63、1,000人以上で0.97
- **端の顔ぶれ**：死亡比が低い50地域のうち、期待死亡数300人未満の地域は17→2に、高い50地域では23→11に減りました。生の値は45〜173、縮めた値は60〜172です
- **シミュレーション**：本当の死亡比が全地域で同じでも、いちばん高い地域は95%の確率で期待死亡数100人未満の地域になります
- **F27 の空間ベイズ（BYM2）との一致**：縮めた値と BYM2 の推定の相関は0.98（そのままの値は0.96）。隣の地域の情報を使わない簡単な経験ベイズでも、ランキングの端の直し方はかなり近くなります
- 心疾患・脳血管疾患（地域の間の差は標準偏差で18%・22%）でも、縮めると端の50地域のうち期待死亡数300人未満の地域は大きく減りました

**まとめ**：経験ベイズで縮めるとランキングがどれだけ変わるかは、「地域の間の本当の差」と「分母の小ささによる偶然のぶれ」の比で決まります。死亡のように本当の差が小さい指標では、端に並ぶ小さい地域の多くは偶然で、縮めると大きく入れ替わります。検診のように本当の差が大きい指標では、縮めてもほとんど変わらず、小さい町が上位に残ります。それでも、1位が毎年入れ替わることは変わりません。

## 言えないこと

1. 経験ベイズで縮めた値も推定値で、「この町の本当の率」を言い当てるものではありません。とくに小さい町は、縮めた後も不確かさが大きいままです
2. 検診の受診率は、受診の勧め方・集計の仕方の違いや、国保の加入者の構成の違いも映しています。高い・低いを「取り組みの良し悪し」とは言えません
3. 死亡比の差は、年齢構成をそろえた後の差ですが、その理由（生活習慣・医療・所得など）はこのデータでは分かりません
4. 特定の市区町村の良し悪しを言う記事ではありません。記事でも結果のファイルでも、団体名は出していません
