# 1206 いくつかの配信リストを合わせて送ると、同じ人に2通届く割合はどれだけあるのか？（メール配信）

お知らせのメールを、会員登録の名簿・店頭で書いてもらった名簿・催しの申し込みの名簿のように、いくつかのリストを合わせて送ることがあります。同じ人が2つ以上のリストに入っていると、その人には同じメールが2通届きます。アドレスが同じなら1通にまとめられますが、同じ人が別のアドレスを書いていたり、同じアドレスでも大文字がまざったり空白が入ったりしていると、文字で比べるだけではまとめきれません。**ここでは、作成者が置いた架空の店の読者20,000人（3つのリストへの入り方、アドレスを2つ持つ人の割合、表記のゆれの割合を作成者が置いたもの）で、リストをそのまま足す・文字が同じアドレスだけまとめる・小文字と空白をそろえてからまとめるの3つの合わせ方で、届いた人のうち2通以上届いた人の割合を数えました。アドレスを2つ持つ人の割合・表記のゆれ・熱心な人ほど多くのリストに入るか・リストの数を変えた108通りでも確かめました。**

例の店・名簿・アドレスは架空のもので、実在の店・メール配信の仕組みを表すものではありません。アドレスは作成者が作った記号（`m00001a@example.com` のような形）です。

関連する記事：1024「同じ人の重複した予約は、埋まり具合をどれだけ押し上げるのか？」は、同じ人が別の夜も仮に押さえる重複が、宿の埋まり具合を押し上げる場面を扱っています。1045「区分に分けて足し合わせると、重なりと抜けで合計はどれだけずれるのか？」は、概算で区分の重なりを足し込むずれを扱っています。966「表記ゆれ（全角・半角・言い換え）をそろえると、数はどれだけ動くのか？」は文章の言葉の表記のゆれ、584「同じ人が別のIDで登録された顧客表を、電話・メール・氏名＋生年月日で寄せると、顧客数とリピート率はどれだけ変わるのか？」は顧客表を寄せるときの鍵の選び方を扱っています。同じ企画の 1199「送る回数を増やすと、1通あたりの反応は下がっても、全体の反応はどう動くのか？」は、同じ人に届く通数が増えたときの、1通あたりの開封と配信を止める人の積み重なりを扱っています。この記事は、配信リストを合わせて送るときに、同じ人に何通届くかに絞ります。

## 主な結果

### 合わせ方ごとの2通以上届いた人（基本、200回の平均、`results/by_method.csv`）
| 合わせ方 | 送った通数 | 届いた人 | 2通以上届いた人の割合（10〜90%） | 余分な通数の割合 |
|---|---|---|---|---|
| ① そのまま足す | 20,396.86通 | 13,377.09人 | **42.93%**（42.33〜43.48%） | 34.42% |
| ② 文字が同じアドレスだけまとめる | 14,726.09通 | 13,377.09人 | 9.88%（9.59〜10.21%） | 9.16% |
| ③ 小文字・空白をそろえてまとめる | 14,176.83通 | 13,377.09人 | **5.98%**（5.76〜6.22%） | 5.64% |

- **3つのリストをそのまま足すと、届いた人の42.93%に2通以上届いた**。送った通数の34.42%が、同じ人への2通目以降だった
- 文字が同じアドレスだけまとめると9.88%に減った。②で残った2通以上の人のうち39.51%は、表記のゆれだけ（同じアドレスの別の書き方）によるものだった
- **小文字と空白をそろえてからまとめても5.98%が残った**。残ったのはすべて、別のアドレスを書いた、アドレスを2つ持つ人だった（表記のゆれを大文字と空白だけに置いたので、作りどおり）
- 熱心さの効きを0にしてリストどうしを関係なく置くと、①の2通以上の割合は32.04%で、リストに入る確率から出した式の値32.03%と合った（作りどおり）
- 1回分の例（`data/registrations_example.csv`、20,434件）：アドレスの文字列で数えた②の宛先14,697件・③の宛先14,168件は、コードの中の数え方と一致した

### いつものアドレスを書く確率（各50回、`results/main_address.csv`）
| いつものアドレスを書く確率 | ① | ② | ③ |
|---|---|---|---|
| 50% | 42.94% | 10.95% | 7.15% |
| 70%（基本） | 42.97% | 9.94% | 6.05% |
| 90% | 42.88% | 6.85% | 2.54% |

- ①は書くアドレスでは変わらない（作りどおり）。③に残る分は、いつものアドレスを書く人が多いほど小さくなった

### 確かめ：108通り（各20回、`results/grid.csv`）
- ①そのまま足したときの2通以上の割合は22.91〜66.83%だった。リストの数で、2つ22.91〜47.3%・3つ31.94〜57.09%・5つ46.29〜66.83%。熱心さの効きで、s＝0 は中央値32%、s＝1 は42.94%、s＝2 は56.94%と、熱心な人ほど多くのリストに入ると置くほど大きかった
- **③にそろえてまとめた後の2通以上の割合は、アドレスを2つ持つ人がいない置き方（27通り）ではすべて0%（作りどおり）、いる置き方（81通り）では1.44〜20.49%だった**。アドレスを2つ持つ人の割合ごとの中央値は、15%で2.99%、30%で5.99%、50%で10.03%
- ③で残った割合は、①の割合の0.0624〜0.3081倍（アドレスを2つ持つ人がいる81通り）
- ②と③の差（表記のゆれの分）は最大25.96ポイント（アドレスを2つ持つ人なし・表記のゆれ15%・リスト5つ・熱心さの効き2のとき）
- リストどうしが関係ないとき（s＝0）の①は、式の値（リスト2つ23.08%・3つ32.03%・5つ46.4%）と、アドレスを2つ持つ人なし・表記のゆれなしの数えた値（23.08%・32.01%・46.45%）が合った

## 注意（言えないこと）
- 架空のデータと、作成者が置いたリストへの入り方・アドレスの数・表記のゆれです。2通以上の割合は、とくにリストの数、熱心な人ほど多くのリストに入るか、アドレスを2つ持つ人の割合で大きく変わります。実在の店や配信の数字を表すものではありません
- 表記のゆれは、小文字と空白をそろえれば直るもの（大文字・前後の空白）だけを置きました。打ちまちがいのように届かないアドレスや、届く先は同じでも文字の違いがもっと大きいものは入れていません
- アドレスを2つ持つ人の2通は、文字だけでは同じ人と分かりません。名前や会員番号などでまとめた場合は扱っていません
- 2通届いたときに読者がどう受け取るか（配信の停止が増えるかなど）は数えていません。合わせ方の良し悪しや、配信の決め方の助言をする記事ではありません
