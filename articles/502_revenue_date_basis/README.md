# 502 売上を受注日・出荷日・検収日のどれで数えるかで、月の売上と前年同月比はどれだけ動くのか（実務の型）

架空の受注データ（小売型と法人向け型）を作り、同じ注文の金額を受注日・出荷日・検収日の3つの日付で月に集計して、月の売上の差と前年同月比の向きを比べたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A502 | 数える日付で、月の売上と前年同月比はどれだけ変わるか | 架空の受注（小売型：毎日、出荷まで1〜3日／法人向け型：平日のみ、月末と四半期末に受注が増え、出荷まで中央値15日、検収の半分は月末にまとめる）を2022年10月〜2025年12月で作り、2023年1月〜2025年12月を3つの日付で月に集計 | `src/a502_date_basis.py`、`src/02_monthly_by_basis_duckdb.sql`、`src/01_monthly_by_basis_tsql.sql`（T-SQL 版、未検証） |

## 主な結果
- **小売型**：受注日で数えた月の売上との差は、出荷日で平均1.29%（最大3.49%）、検収日で平均1.48%（最大4.68%）。前年同月比の向き（プラスかマイナスか）が3つの日付で食い違った月は24か月中4か月
- **法人向け型**：受注日との差は、出荷日で平均11.04%（最大28.26%、2025年11月）、検収日で平均14.0%（最大35.33%、2023年4月）。前年同月比の向きが食い違った月は24か月中15か月（受注日と検収日だけで14か月）
- **1年で足すと**：差は小さい（法人向け型で−1.55%〜+0.8%、小売型で0.1%以内）。ずれるのは「どの月に入るか」
- **法人向け型の日数**：受注から出荷まで中央値15日、検収まで中央値37日。月の最後の3日に入る金額の割合は、受注日15.1%、出荷日8.6%、検収日55.5%

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した
- DuckDB（UNPIVOT）で出した月の集計が、pandas の集計と一致すること（コード内の assert）

## データ
- `data/fictional_orders.csv`：架空の受注（seed 502）。列は order_date, ship_date, accept_date, amount, kind。需要は年3%伸び、2025年7月から8%落ちる

## 注意（言えないこと）
- 架空のデータ。差の大きさは、置いた日数の分布と月末の偏りで決まる
- 会計基準や税務で、どの日付で売上を計上すべきかを言うものではない。集計の日付を変えると数字がどう動くかを数えたもの
- 返品・値引き・分納・前受けは入れていない
- T-SQL 版は SQL Server 本体では動かしていない（未検証）
