# 150 黄砂の観測日数は、2000年代から減ったのか？

気象庁「黄砂のデータ集」（全国11地点の目視観測、1967年1月〜2024年3月）の黄砂観測日数・のべ日数と、年ごとの観測地点の表から、黄砂を観測した日数の変化を見たフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A150 | 黄砂の観測日数は2000年代の多い時期から減ったのか。どの地点で減ったのか | 年ごとの観測日数と5年移動平均、期間ごとの年平均（観測日数・のべ日数）、地点別の年平均 | `src/a150_kosa.py` |

## 主な結果
- 観測日数が多かったのは 2001年 38日、2002年 36日、2010年 33日、2000年 32日。20日以上の年は 2000〜2010年に11年中8年あったが、2011〜2023年は0年
- 年平均の観測日数は 1967〜79年 9.5日、1980年代 10.4日、1990年代 16.1日、2000〜2010年 23.6日、2011〜2023年 9.2日。のべ日数は 80.4日 → 28.5日
- 2011〜2023年で平年値（15.8日、1991〜2020年）を上回ったのは2021年（16日）だけ
- 地点別の年平均は、広島 14.6日 → 3.8日、福岡 13.8日 → 5.5日、鹿児島 11.3日 → 3.9日（2000〜2010年 → 2011〜2023年）。多くの地点で1999年以前と同じくらいに戻った
- 観測日の8割前後は3〜5月

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a150_kosa.py
```

## データ
| ファイル | 中身 | 元のページ |
|---|---|---|
| data/kosa_days_monthly.csv | 1967〜2024年の月別・年合計の黄砂観測日数（11地点のどこかで観測した日数） | 黄砂観測日数表 https://www.data.jma.go.jp/env/kosahp/kosa_table_1.html |
| data/kosa_station_days_monthly.csv | 同じく、のべ日数（観測した地点数の合計） | 黄砂観測のべ日数表 https://www.data.jma.go.jp/env/kosahp/kosa_table_0.html |
| data/station_days_by_year.csv | 年ごとの観測日数、1日の最大観測地点数、地点ごとの観測日数 | 年ごとの「黄砂観測日および観測地点の表」（データ集トップの年選択から）を集計 |

地点ごとの日数は、年ごとの表に載っている観測日（768日）の地点名を数えました。1977/02/24 と 2010/03/21 は地点数11に対して地点名が10しか載っていなかったため、載っていない那覇を加えています。この補正で、地点ごとの合計はのべ日数表と全年で一致します。

## 注意
- 気象庁は2024年3月26日で黄砂の目視観測の統計を終えました。2024年は途中までなので分析から外しています
- 観測は気象台の職員による目視で、視程（見通し）や空の様子で判断します。人による判断の差や、ほかの大気汚染（もや・煙霧など）との区別の難しさがあります
- データ集は全期間を同じ11地点で集計しています（札幌・仙台・東京・新潟・名古屋・大阪・広島・高松・福岡・鹿児島・那覇）
- 観測日数は「黄砂が観測された日」の数で、黄砂の濃さ（量）ではありません
- 減った理由（発生源の砂漠や草原の状態、風、雨、雪など）は、このデータでは分けられません。年ごとの振れも大きく、2021年16日、2023年14日のように多い年もあります
