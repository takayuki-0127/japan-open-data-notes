# 690 30件で相関0.3と出たとき、本当の相関はどの範囲にあると言えるのか（手法の解説・正解の分かるデータで試す）

相関係数は、件数が少ないと大きく振れます。「相関0.3」と出ても、件数によっては本当の相関が0かもしれませんし、0.6かもしれません。**ここでは、観測した相関0.3に対する95%区間を件数10〜1,000で計算し、さらに本当の相関（0・0.3・0.6）が分かっている架空のデータで、件数10〜300のときのフィッシャーの z 変換の区間とブートストラップの区間がどれだけ当たるかを数えました。** 各500回です。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A690 | 少ない件数の相関の区間はどれだけ広いか | フィッシャーの z 変換：z = artanh(r)、z ± 1.96/√(n−3) を tanh で戻す。2次元正規（ρ = 0・0.3・0.6）で n = 10・20・30・50・100・300、各500回。ブートストラップはパーセンタイル法500回。seed 690 | `src/a690_corr_ci.py` |

## 主な結果
| 観測した相関0.3の件数 | 95%区間 |
|---|---|
| 10件 | −0.41 〜 0.78 |
| 20件 | −0.16 〜 0.66 |
| **30件** | **−0.07 〜 0.60** |
| 50件 | 0.02 〜 0.53 |
| 100件 | 0.11 〜 0.47 |
| 300件 | 0.19 〜 0.40 |
| 1,000件 | 0.24 〜 0.36 |

- 30件では、相関0.3でも区間は0をまたいだ。区間の幅が0.2を切るには320件が要る
- 30件のとき、本当の相関が0でも7%の回で0.3以上が出て、本当の相関が0.3でも5.8%の回で0以下が出た。本当0.3のときの観測値の90%は −0.01〜0.55 に散らばった
- 区間の当たり方：フィッシャーの区間はどの件数・相関でも92〜96%で、ブートストラップは件数が少ないと89〜93%と少し低かった（例：10件・本当0.6 で92.8% 対 89.0%）
