# F250 売上が落ちた月に、理由を説明する（業務の再現：架空の会社で）

シリーズ③「業務の再現：架空の会社で」の5本目。架空の食品スーパー **サンプルマート（架空）** で、既存店の売上が前年を下回った月（2026年3月）の理由を要因に分け、経営会議に出す「1枚の報告」を書く。

> **会社も数字もすべて架空（乱数で合成したデータ）。** 実在の会社・店・顧客のデータは使っていない。公開データから借りたのは、売上の季節の形と食品の値段の上がり方（F246 の設定）と、業界の参考として出す商業動態統計の前年比だけ。

## 問い
既存店の売上が前年を下回った月に、「なぜ下がったか」を、偶然の揺れまで理由にしてしまわずに、1枚でどう説明するか。

## 結論
- **2026年3月の既存店売上は前年比 −1.1%（21店）**。FY2025 で前年割れはこの月だけ。
- 売上の前年比への寄与は、一品単価 **+4.1pt**（値上がり）、1回の買上点数 **−1.3pt**、暦の差 **−0.9pt**（前年より土曜日が1日少ない）、暦をそろえた客数 **−3.1pt**。暦をそろえると売上は **−0.2%**。
- 暦をそろえた客数（−3.0%）は今年度でいちばん弱い月。業界（商業動態統計・スーパー、全店・名目）も3月は +1.3% と今年度でいちばん低い伸びだった。
- 乱数だけを変えた20通りで測った **偶然の幅（90%）は、全社・1か月の売上の前年比で ±1.1pt**。地域の差は ±1.3〜1.7pt、部門の差は ±0.3〜0.6pt、店1つは ±3.4〜6.6pt。
- 3月だけを見ると「郊外が悪い（全体との差 −1.7pt）」「地方は目立たない（−0.6pt）」に見えるが、合成の設定上の本当の差は郊外 −0.1pt・地方 −2.2pt。**1か月の地域の差は偶然に負ける**。年度の12か月で見ると地方 −2.3pt・都市 +2.1pt（幅 ±0.4〜0.5pt）と、設定どおりの差が見える。
- 地域・部門・店の31項目を見ると、偶然だけでも平均3.1項目（最大6）が幅の外に出る。3月に幅の外に出た店は2つ（地方19店・都市08店）で、答え合わせでは08店は設定上も +4.2pt（開店後の立ち上がり）、19店は設定上 −1.8pt で残りは偶然だった。
- この結果から、1枚の報告は「結論 → 数字（寄与と偶然の幅）→ 理由にしないもの → 次にやること」の順に書いた（`reports/report_202603_onepage.md`）。比べるために、数字を上から順に並べて偶然の揺れまで理由にした「最初の下書き」も残した（`reports/report_202603_first_draft.md`）。

## 手法
1. **既存店の前年比**：既存店＝月初で開店から13か月以上、かつ月末まで営業している店（F246 の決めごと）。前年比は合計どうしの比。
2. **3つの要素に分ける**：売上 ＝ 客数（レシート枚数）× 1回の買上点数 × 一品単価。寄与は対数平均の重み（LMDI）で配り、合計が売上の前年比にちょうど一致するようにした。
3. **暦の差**：前の年度まで（FY2022〜FY2024）の店×日のレシート枚数の対数を、曜日・平日の祝日・年末で回帰した（店×月の平均を引いて、店×月の固定効果を除く）。その係数で、今年と前年の同じ月の「日の重み」の合計を比べた比を暦の差とした（日数の違いも入る）。
4. **地域・部門・店**：全体の動きとの差（pt）で見る。理由の候補にするのは、この差が偶然の幅を超えたときだけ。
5. **偶然の幅**：F246 の `gen(seed)` で種 0〜19 の20通りのデータを作り、同じ計算をした。種の平均（設定どおりの値）からのずれの標準偏差 ×1.645 を「90%の幅（半分の幅）」とした。
6. **答え合わせ**：合成の設定（曜日の係数・物価・売上の季節の形・地域の流れ）から、本当の要因を計算して比べた。
7. **SQL**：既存店の前年比と3つの要素を SQL（`sql/10_existing_store_yoy.sql`）でも計算し、pandas と照合した。DuckDB で実行（SQL Server では動かしていない）。

## 1枚の報告の書き方（この回で決めたこと）
1. 結論を最初の3行に書く：何が、どれだけ、なぜ（寄与の大きい順）。暦の差は必ず別に出す。
2. 数字は寄与と偶然の幅を並べた表1つにする。
3. 「理由にしないもの」を書く：偶然の幅の中の地域・部門・店。幅を超えたものも、1か月だけなら「候補」として来月見る。
4. 次にやることは、来月の数字で何を確かめるかと、それまで何をしないか。

## 言えないこと
- **数字は架空の会社の合成データ**。実在のスーパーの客数・単価・偶然の幅を示すものではない。偶然の幅は合成の設定（店×月のずれ σ=2% など）で決まっている。
- 合成の設定上、客数の月ごとの形は商業動態統計から作っているので、**業界と同じ向きに動くのは作り方による当然の面がある**。報告の「市場全体の動き」は、実務ではほかの材料（競合の出店、天候、近くの店の販促など）と合わせて判断するところ。
- 暦の差は客数だけで測った。チラシの日（水・土）は一品単価が少し下がる設定なので、土曜日が少ない3月は一品単価が少し高めに出ている（+4.18% と設定の +4.0% の差の一部。推測）。
- 偶然の幅は「設定どおりの値からのずれ」で測った。実務では設定（本当の値）が分からないので、過去の月のばらつきや、店を入れ替えた計算で代わりに測ることになる。
- 1枚の報告の書き方は筆者の決めたもの。会社や読み手によって合う形は変わる。
