# wage-increase-japan：厚生労働省「賃金引上げ等の実態に関する調査」で、賃上げ率の企業規模による差を50年分調べる

厚生労働省「賃金引上げ等の実態に関する調査」（令和7年）の時系列表（第1・4・6表）を使ったリポジトリです。対象は常用労働者100人以上の民間企業です。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| 141 | 賃上げ率は企業規模でどれだけ差があったのか。2023年以降の賃上げで差は広がったか | 企業規模別の1人平均賃金の改定率・改定額（1975〜2025年）、5,000人以上と100〜299人の差の年次推移と期間平均、賃金を引き上げた企業の割合、改定で最も重視した要素 | `src/a141_size_gap.py` |

## 主な結果
- 1人平均賃金の改定率は、5,000人以上が2.0%（2022年）→4.0%（2023年）→4.8%（2024年）→5.1%（2025年）、100〜299人が1.9%→2.9%→3.7%→3.6%
- 5,000人以上と100〜299人の差は、2025年に1.5ポイントで、1975年以降で最も大きい。2023・2024年も1.1ポイント。1975〜1989年の平均は0.07ポイント、1990年代は−0.01ポイントで、ほぼ差がなかった。2000〜2012年は平均0.32、2013〜2022年は0.21ポイント
- 改定額（月額）の差は、2022年の1,740円から2025年は6,520円（16,784円と10,264円）
- 1人平均賃金を引き上げた（引き上げる）企業の割合は、2025年に5,000人以上98.9%、100〜299人89.7%。100〜299人は2002年に57.4%、2009年に57.8%まで下がったことがある
- 改定で最も重視した要素（企業規模計）は「企業の業績」が50.0%（2019年）→41.7%（2025年）、「労働力の確保・定着」が9.9%→17.0%、「消費者物価の動向」は0.2%→7.9%（2023年）→3.3%（2025年）

## 動かし方
`data/raw.zip`（e-Stat から取得した第1〜8表の Excel）が入っていて、初回の実行で `data/raw/` に展開されます。

```bash
pip install -r requirements.txt
python src/a141_size_gap.py
```

## 注意
- 改定率は1か月当たりの1人平均所定内賃金の改定率で、定期昇給とベースアップを分けていません（時系列表にはありません）
- 1979年までは単純平均、1980年以降は加重平均です。1974年以前は企業規模の区分が違うので、1975年からを使いました
- 1998年以前は1人平均賃金が増えた企業だけを集計していて、1999年からは減った企業・変わらない企業も含みます。1998年と1999年の間の段差には、この変更が入っています
- 対象は常用労働者100人以上の企業で、99人以下の企業は入っていません
- 差は「5,000人以上」と「100〜299人」の単純な引き算で、業種の構成の違いは調整していません
