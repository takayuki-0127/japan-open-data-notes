# 1145 録音全体の音量を上げると、声と雑音の差は広がるのか？（音の大きさ）

声を録った音が小さいと、録音全体の音量を上げれば、声が雑音から浮き上がって聞き取りやすくなりそうです。けれども、録音の中に入っている雑音は、声と同じだけ上がります。声と雑音の差（強さの比を dB にした値）が広がるかどうかは、雑音が「上げる前に入っているか、上げた後に加わるか」で決まります。**ここでは、作成者が式と乱数で作った架空の録音（20秒。声に見立てた音と雑音を別々に作ったもの）の音量を0〜30 dB 上げ、雑音が入る場所の3通り（A 録音の中の雑音、B 保存の段の粗さ、C 聞く場所の雑音）で、声と雑音の差がどう動くかを数えました。上限（振れ幅1.0）で切れたときの差の縮み方と、録音だけから見積もった差がそれを表すかも確かめ、置き方を変えた27通りでも数えました。**

この記事は数値の計算だけで、人が聞き比べる形の評価はしていません。聞き取りやすさや、音量を上げ下げするときの安全の話もしていません。

同じ大きさの音を重ねると dB がどう増えるかは同じ企画の 1137、上限を超えて切れた点の割合が大きさの数字にどう表れるかは同じ企画の 1144 で扱っています。この記事は、上げたときの声と雑音の差に絞ります。

## 主な結果

### 上げた量ごとの声と雑音の差（基本、`results/gain_sweep.csv`）
| 上げた量 | A 録音の中の雑音 | B 8ビットで保存してから上げる | B 上げてから8ビットで保存 | C 聞く場所の雑音 | A 録音だけからの見積もり | 切れた点 |
|---|---|---|---|---|---|---|
| 0 dB | 20.0 dB | 14.61 dB | 14.61 dB | 4.08 dB | 23.31 dB | 0.0% |
| 10 dB | 20.0 dB | 14.61 dB | 18.35 dB | 13.18 dB | 23.31 dB | 0.0% |
| 20 dB | 20.0 dB | 14.61 dB | 19.74 dB | 18.6 dB | 23.31 dB | 0.0% |
| 25 dB | 18.64 dB | 14.18 dB | 18.57 dB | 18.27 dB | 23.2 dB | 0.14% |
| 30 dB | 13.15 dB | 11.42 dB | 13.15 dB | 13.12 dB | 22.56 dB | 1.55% |

- **A：録音の中の雑音との差は、切れ始めるまでまったく動かなかった**（切れなかった0〜19.5 dB の範囲で変化0.0 dB）。声も雑音も同じ倍率で上がるので、式どおりの結果です
- 切れ始めたのは20.0 dB 上げたところ（声＋雑音のいちばん大きい点からの式で19.82 dB、0.5 dB 刻みの次の値）。そこから差は縮み、24.5 dB 上げると1 dB 縮み、30 dB 上げると13.15 dB と **6.85 dB 縮んだ**。切れて変わった分が雑音に加わるため
- **C：上げた後に加わる雑音との差は、4.08 dB から最大18.97 dB まで14.89 dB 広がった**（22.5 dB 上げたとき）。切れ始めるまでは、録音の中の雑音と聞く場所の雑音を足した式どおり（差0.005 dB 以内）で、録音の中の差（20.0 dB）より広がることはない。切れ始めた後は A と同じく縮んだ
- B：8ビットで保存した段の粗さ（−55.34 dB）は、保存してから上げても差は14.61 dB のままだった。上げてから保存すると、21.0 dB 上げたところで19.77 dB まで戻った。保存の段の粗さは、上げる前に入れば A、上げた後に入れば C と同じ形になる

### 切れて差が縮んでも、録音からの見積もりはほとんど動かない
- A で30 dB 上げて本当の差が6.85 dB 縮んだとき、録音だけからの見積もりは23.31 dB から22.56 dB へ、**0.74 dB しか縮まなかった**。切れて変わった分は声の大きい区間にだけ出るので、「大きい区間＝声」「小さい区間＝雑音」と見る見積もりでは、声の側に数えられる
- 見積もりは切れる前から本当の差（20.0 dB）より3.31 dB 大きかった。小さい1割の区間を雑音とみなしても、大きい半分の区間には息つぎの間が少なく、声の強さが平均より大きく出るため（見積もりの作りどおり）

### 保存の段の細かさ（`results/by_bits.csv`）
| 保存の段 | 保存してから上げる | 上げてから保存（いちばん良い値） |
|---|---|---|
| 8ビット | 14.61 dB | 19.77 dB |
| 12ビット | 19.9 dB | 20.0 dB |
| 16ビット | 20.0 dB | 20.0 dB |

- 12ビット・16ビットでは、段の粗さは録音の中の雑音よりずっと小さく、上げる順で差はほぼ変わらなかった

### 置き方を変えた27通り（`results/grid.csv`）
- A：切れ始めるまでの差の変化は、27通りすべてで0.0 dB だった（式どおり）。30 dB 上げたときの変化は −26.82〜0.0 dB（切れなかった9通りは0）
- A：切れ始めてから差が1 dB 縮むまでに上げた量は **1.0〜9.5 dB**（切れた18通り）。本当の差が大きい録音ほど、少し切れただけで差が縮んだ
- **切れた18通りのうち16通りで、録音だけからの見積もりの縮み（−9.9〜−0.84 dB）は本当の縮み（−26.82〜−1.39 dB）より小さかった**。見積もりの縮みは本当の縮みの0.07〜1.284倍だった
- C：差が広がった量は **0.59〜29.72 dB** だった。声のいちばん大きい点が −30 dB の9通りは、30 dB 上げても切れず、上げた範囲の端（30 dB）がいちばん良かったので、広がった量は上げた範囲で頭打ちになっている。いちばん良い上げ幅は11.5〜30.0 dB だった
- B：上げてから保存すると、保存してから上げるより0.1〜22.01 dB 良かった

## 注意（言えないこと）
- 架空のデータです。声の形、雑音の大きさ、聞く場所の雑音（−45 dB）、保存の段は作成者が置いたもので、結果はこれで決まります。A で差が変わらないこと、C の広がり方は式どおりで、新しく数えたのは、切れたときの縮み方の幅と、録音からの見積もりがその縮みをほとんど表さないことです
- 雑音は声と関係のないでたらめな値だけにしました。声と一緒に大きくなる響きや、上げると目立つ低い唸りのような雑音は入れていません
- 「差」は強さの比で、人が聞き取れるかどうかとは別のものです。人が聞き比べる形の評価はしていません
- 録音だけからの見積もりは、作成者が置いた1つのやり方（大きい半分と小さい1割）です。ほかの見積もり方でも、切れて変わった分を声の側に数えるなら同じ向きになると考えています（推測）
- 音量をどこまで上げるべきかの助言ではありません
