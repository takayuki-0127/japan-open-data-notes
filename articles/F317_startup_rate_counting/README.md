# F317 「日本は開業が少ない」は、数え方でどれだけ変わるのか？ 雇用保険の開業率は2018〜2025年度平均4.2%。分母・産業の重み・除く産業を変えても3.9〜4.3%に収まった

## 結論（先に）
- 厚生労働省「雇用保険事業年報」の開業率（新規適用事業所数 ÷ 前年度末の適用事業所数）は、2018〜2025年度の平均で4.2%でした（最小3.8%、最大5.1%）。
- 分母を年度の初めと終わりの平均にする、任意適用を除く、建設業を除く、産業の構成を固定する、どの産業も同じ重みにする、といった数え方の違いでは、開業率は3.9〜4.3%の幅に収まりました。この統計の中では、数え方で「少ない」の印象は大きくは変わりません。
- 産業別では、宿泊業・飲食サービス業が9.3%でいちばん高く、建設業は4.5%で中ほどでした。事前の予想（建設業がいちばん高い）は外れました。
- 問い直し：2020年度だけ開業率が5.1%に跳ねました。新規適用の増加2.0万所のうち53%が宿泊業・飲食サービス業で、これを除くと2020年度は4.4%でした。また2023年度以降は、開業率と廃業率がほぼ同じ（3.8〜3.9%）になっています。

## 問い
「日本は開業が少ない」とよく言われ、その根拠として雇用保険の開業率がよく使われます。地域の産業や創業の支援の担当の人、統計を読む人にとっては、この数字が数え方にどれだけ左右されるのかが知りたいところです。分母・分子の取り方と、産業の構成の違いで、開業率がどれだけ動くかを確かめました。開業を増やす策の良し悪しは扱いません。

## データ（出典）
- 厚生労働省「雇用保険事業年報」平成29年度〜令和7年度（2017〜2025年度）の第1表「雇用保険産業別適用状況〔適用事業所〕」：産業（大分類）別の新規適用事業所数（うち任意適用）、廃止事業所数、年度末の適用事業所数。
- 元の PDF は9年度分で約50MBあるため、01_fetch.py で第1表のページだけを切り出して保存しました（中身は変えていません）。
- URL と取得日は data/raw/SOURCES.md にあります。

## やったこと
1. 9年度分の第1表から、大分類（Ａ〜Ｔ）の行と合計の行を取り出しました。産業の合計が合計の行と一致すること（新規適用・廃止）を確かめました（年度末の事業所数は数所〜289所のずれがあり、合計の行を使いました）。
2. 開業率・廃業率を年度ごとに計算し、数え方を変えた開業率を並べました。
3. 頑健性を5つ、問い直しを1つ足しました。

## 分かったこと
### 開業率は4%前後（図1）
2018年度4.4%、2019年度4.3%、2020年度5.1%、2021年度4.4%のあと、2022〜2025年度は3.8〜3.9%でした。廃業率は3.1〜3.9%で、2023年度からは開業率とほぼ同じです。

### 産業による差は大きい（図2）
宿泊業・飲食サービス業 9.3%、農業・林業 7.2%、生活関連サービス業・娯楽業 6.1%、情報通信業 5.7% が高く、製造業は1.6%でした。ただし、全体の開業率は産業の構成をどうそろえても大きくは変わりませんでした（H4、R3）。産業ごとの差はあっても、事業所の数の多い産業が中ほどの値だったためと考えられます（推測）。

### 数え方を変えても3.9〜4.3%（図4）
| 数え方 | 開業率（8年度平均） |
|---|---|
| ふつう（新規適用 ÷ 前年度末） | 4.21% |
| 分母を年度の初めと終わりの平均に | 4.19% |
| 任意適用を除く | 4.19% |
| 建設業を除く | 4.15% |
| 産業の構成を2017年度末に固定 | 4.14% |
| どの産業も同じ重み | 4.31% |
| 2020・2021年度を除く | 4.02% |
| 宿泊業・飲食サービス業を除く | 3.88% |
| 純増（開業率 − 廃業率） | 0.70% |

## 問い直し（結果を見てから足した）
図1で2020年度だけ開業率が跳ねているのを見て、「どの産業で新規適用が増えたのか」を確かめました（src/03b_requestion.py、図3）。

- 2019→2020年度の新規適用の増加 +20,459所のうち、宿泊業・飲食サービス業が +10,930所（53%）、卸売業・小売業 +2,739所、生活関連サービス業・娯楽業 +1,478所、建設業 +1,157所でした。
- 宿泊業・飲食サービス業の新規適用は、2019年度 10,782所 → 2020年度 21,712所 → 2021年度 15,964所 → 2022年度 10,494所と、2020年度だけ倍になっています。
- 宿泊業・飲食サービス業を除くと、2020年度の開業率は4.4%で、前後の年度と大きくは違いません。
- この時期に新しく雇用保険に入った事業所が、新しく始めた事業所なのか、すでにあった事業所が制度の利用のために加入したのかは、この表では分けられません（推測では後者も含まれうる）。
- なお、比べる元にした2017年度は、建設業の新規適用が38,967所と、2018・2019年度（約2万所）の倍ほどありました。

## 言えないこと
- 雇用保険の適用事業所は、人を雇っている事業所だけです。ひとりで始めた事業や、会社の設立そのものとは違います。
- 事業所の移転や組織の変更でも、新規適用・廃止として数えられることがあります。
- 海外との比較はしていません。各国の開業率は数え方が違い、そのまま比べられません。
- 経済センサスなど、ほかの統計の開業率とは比べていません。数え方の違いは、この統計の中だけの確かめです。
- 年度末の適用事業所数は、産業の合計と合計の行に小さなずれがあります。

## 仕事で使うなら
- 雇用保険の開業率を使うときは、2020年度の跳ね上がりのように、特定の産業の動きで全体が動くことがあると書き添えると、誤解が減ります。
- 「開業が少ない」を示すときは、廃業率と並べると、事業所の数の増減まで分かります。
