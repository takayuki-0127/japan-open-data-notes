# 156 ネット販売の売上比率が高い業種はどこか：経済センサス‐活動調査（2011・2015年の売上）

総務省・経済産業省「経済センサス‐活動調査」（平成24年・平成28年）の「企業産業（小分類）、電子商取引の有無（4区分）別」の表から、業種（中分類）ごとに「一般消費者との電子商取引（BtoC-EC、ネット販売）の額」が売上に占める割合を比べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A156 | ネット販売の売上比率が高い業種はどこか。2011年から2015年でどう変わったか | 業種の売上全体に占める BtoC-EC の額、電子商取引をした企業の割合、ネット販売をした企業の売上に占める割合のランキングと2時点比較 | `src/a156_ec.py` |

## 主な結果
- 一般消費者とのネット販売の額は、2011年の11.7兆円（売上全体の0.87%）から2015年は19.9兆円（1.22%）に増えた。電子商取引をした企業は全体の4.2%→4.3%で、ほとんど増えていない
- 業種（中分類）の売上に占めるネット販売の割合は、航空運輸業32.2%（2011年10.8%）、インターネット附随サービス業31.8%、無店舗小売業18.0%、宿泊業12.0%（9.0%）が上位
- 機械器具小売業（家電・自動車など）は2.9%→6.8%と2倍以上に。大分類では生活関連サービス業・娯楽業7.5%、宿泊業・飲食サービス業5.2%が高く、製造業は0.21%
- ネット販売をした企業に限ると、その売上の19.0%（2011年14.2%）がネット販売。インターネット附随サービス業76%、娯楽業58%、機械器具小売業42%、無店舗小売業41%

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a156_ec.py
```

- 平成24年 第10表：statInfId=000023604774（2011年の売上）

## 注意
- 「一般消費者と行った電子商取引の額」は、額が分かる企業だけの合計です。分からない企業の分は入らないので、業種の売上全体に対する割合は少なめに出ます
- 電子商取引にはインターネットのほか、EDI などのネットワークを通じた受注も含みます（調査票の定義による）。BtoC の額を「ネット販売」と呼んでいます
- 企業の主な業種で分類しているため、ほかの業種の商品をネットで売った分も、その企業の業種に入ります
- 「X」は秘匿、「-」は該当なしで、欠損として扱いました
- 2021年（令和3年調査）以降の同じ表は、このフォルダでは使っていません。最近の EC 化率は、経済産業省「電子商取引に関する市場調査」が別にあります
