# 950 店の商圏を半径で決めると、重なりはどれだけ数え落とすのか？（地図と場所）

店の商圏（客が来る範囲）を「店から半径1kmの円」と決め、円の中の世帯数を店ごとに数えて足すと、近くの店どうしの円が重なった部分は2回以上数えられます。また、円の中の世帯がその店に来るとは限らず、円の外から来る客もいます。**ここでは、作成者が乱数で作った架空の町（10km四方、世帯約4万）と架空のチェーンの店12軒で、半径の円で数えた世帯数を、重ならずに数えた世帯数と、作成者が置いた店の選び方での本当の客の世帯数と比べました。** 13軒目の店を足したとき、新しい店の円の世帯と、本当に新しく増えた客も比べました。

町・店・世帯はすべて架空のもので、実在の地図や地名は使っていません。距離はまっすぐの距離です。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A950 | 半径の円で数えた商圏の世帯数は、重なりをどれだけ含み、本当の客とどれだけ違うか。新しい店の円の世帯のうち、本当に新しく増える客はどれだけか | 架空の町（10km四方）。世帯は4万を作り、6割は4つのかたまり（中心は2〜8kmの範囲にでたらめ、広がりは標準偏差1.2km）、4割は町全体にでたらめに置いた（町の外に出た世帯は除いた）。店12軒は、世帯の位置からでたらめに選んだ（人の多い所に置かれやすい）。商圏＝店から半径1kmの円の中の世帯。本当の客（作成者の置いた物差し）：世帯はいちばん近い店に行き、2kmより遠ければどこにも行かない。ほかの選び方として、2km以内の店に exp(−距離÷0.5km) の重みで分かれて行く形も数えた。重ならずに数えた世帯＝どれか1つ以上の円に入る世帯。二重に数えた割合＝（円の合計−重ならずに数えた世帯）÷円の合計。新しい店：13軒目を世帯の位置からでたらめに選んで足し、新しい店の円の世帯・本当の客・行く店のなかった世帯がどれだけ減ったか（本当に新しく増えた客）を数えた。町を作り直して100回。確かめとして、店の数（6・12・24軒）×半径（0.5・1・1.5km）×選び方（いちばん近い店・重みで分かれる）の18通りを各20回。seed 950 | `src/a950_trade_area_overlap.py` |

## 主な結果

### 円を足した世帯数と、重ならずに数えた世帯数（店12軒・半径1km、100回の平均）
| | 世帯数 |
|---|---|
| 12軒の円の中の世帯の合計 | 21,943 |
| 重ならずに数えた世帯（どれかの円に入る世帯） | 16,365 |
| 二重に数えた割合 | **23.7%** |
| 円の合計÷重ならずに数えた世帯 | 1.34倍 |
| 本当の客の世帯（どれかの店に行く世帯） | 32,237 |
| 円の合計÷本当の客 | 0.68倍 |

- 円の中の世帯を店ごとに足すと、23.7%は2回以上数えた分だった。1つの店の円の中の世帯のうち、ほかの店の円にも入っている割合は、店の中央値で30.8%だった
- 一方で、本当の客の49.2%は、使う店の半径1kmの円の外（1〜2km）に住んでいた。円の合計は二重に数えた分を含んでも、本当の客の0.68倍にとどまった。半径1kmが、作成者の置いた「2kmまで行く」より狭いため
- 重みで分かれる選び方では、使う店の円の外に住む客の割合は58.9%だった（重なりの数え方は選び方によらない）

### 店ごとの、円の中の世帯÷本当の客（100回の平均）
| 選び方 | 店の中央値 | いちばん小さい店 | いちばん大きい店 |
|---|---|---|---|
| いちばん近い店 | 0.63倍 | 0.31倍 | 1.74倍 |
| 重みで分かれる | 0.65倍 | 0.31倍 | 1.17倍 |

（いちばん小さい店・大きい店は、町ごとの最小・最大の100回の平均）

- 店ごとの円の世帯と本当の客の比は、同じ町の中でも数倍違った。近くにほかの店がある店は円の世帯のわりに客が少なく、まわりに店のない店は円の外からも客が来る
- 1回分の町（図2）では、店ごとに0.29〜1.91倍だった

### 13軒目の新しい店（店12軒・半径1km、100回）
| | 平均 | 中央値 |
|---|---|---|
| 新しい店の半径1kmの円の世帯 | 1,997 | 1,905 |
| そのうち、前からある店の円にも入っていた割合 | 45.7% | 48.3% |
| 新しい店の本当の客 | 2,602 | 2,213 |
| 本当に新しく増えた客（行く店のなかった世帯が減った数） | 621 | 267 |
| 本当に新しく増えた客÷新しい店の円の世帯 | 0.51倍 | 0.16倍 |
| 新しい店の客のうち、ほかの店から移った世帯 | **78.2%** | 87.9% |

- 新しい店の客の多くは、前からある店から移った世帯だった（平均78.2%）。新しい店の円の世帯数だけを見ると、増える客を大きく見積もる
- 平均と中央値が大きく違うのは、店のない所に置かれた回（増えた客が多い）と、店の多い所に置かれた回（ほとんど増えない）が混ざるため
- 重みで分かれる選び方でも、ほかの店から移った世帯は平均77.9%だった

### 確かめ：店の数 × 半径 × 選び方（18通り、各20回）
| | 18通りの幅 |
|---|---|
| 二重に数えた割合 | 4.2〜65.3% |
| 円の合計÷重ならずに数えた世帯 | 1.05〜2.95倍 |
| 円の合計÷本当の客 | 0.12〜2.64倍 |
| 店ごとの円の世帯÷本当の客（店の中央値） | 0.11〜2.63倍 |
| 本当の客のうち、使う店の円の外に住む割合 | 10.5〜90.1% |
| 新しい店：新しく増えた客÷円の世帯（平均） | 0.05〜2.75倍 |
| 新しい店：ほかの店から移った世帯（平均） | 38.4〜99.1% |

- 二重に数えた割合は、店が多く半径が大きいほど大きくなった（6軒・半径0.5kmで4.2%、24軒・半径1.5kmで65.3%、図3）。これは円の重なりの幾何で決まり、店の選び方にはよらない
- 円の合計が本当の客より多いか少ないかは、半径と「どこまで行くか」（作成者が置いた2km）の関係でひっくり返った（0.12〜2.64倍）
- 新しい店の客がほかの店から移る割合は、店が多いほど大きかった（24軒では82.2〜99.1%）

## 動かし方
```
pip install -r requirements.txt
cd src && python a950_trade_area_overlap.py
```
25秒ほどで終わります。`data/stores_example.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約25秒）
- 二重に数えた割合は円の重なりの幾何で決まる値で、店の選び方の2通りで同じ値になることを確かめた
- 「本当の客」は、作成者が置いた店の選び方（いちばん近い店・2kmまで、または重みで分かれる）の写しである。円の合計が本当の客より少ないか多いかは、この置き方で決まる（0.12〜2.64倍）。数えたのは、店ごとの比のばらつきと、新しい店の客がどこから来るか
- 新しい店がほかの店から客を取る割合は、置いた選び方（近い店へ行く）からほぼ決まる向きで、数えたのはその大きさ

## データ
- `data/stores_example.csv`：1回分の町の店12軒。store（店の番号）・x_km・y_km（位置）・households_in_1km（半径1kmの円の中の世帯）・customers_nearest_rule（いちばん近い店へ行くときの本当の客）。この町の世帯は39,580。円の合計は21,896世帯、重ならずに数えると16,147世帯（二重に数えた割合26.3%）、本当の客は31,236世帯

## 注意（言えないこと）
- 架空のデータです。世帯の散らばり方、店の置き方、店の選び方（2kmまで・いちばん近い店へ）は作成者が置いたもので、結果はこれで決まります。実在の町やチェーンを表すものではありません
- 距離はまっすぐの距離で数えました。道のり・川・線路などで行きやすさが変わることは入れていません（道のりとの違いは 947 で扱っています）
- 店の大きさ・品ぞろえ・値段で客が店を選ぶことは入れていません。どの店も同じと置きました
- 出店の場所の決め方の助言ではありません。数えたのは、半径の円で数えた数と、置いた選び方での客の数の違いだけです
- 関連する記事：947（まっすぐの距離と道のりの距離で、近い店は入れ替わるか）、945（区域の線の引き方で「いちばん売れる地区」は入れ替わるか）。951 は、客の場所を丁目の真ん中にまとめると、半径の中の客の数が店ごとにどれだけずれるかを扱っています（この記事は、客の場所は正しいまま、円を足すことと円の中を客と読むことのずれ）。953 は、出店した店の売上だけで場所の良し悪しを読むときの選ばれ方のずれ、956 は、2つの地区の間のどこに拠点を1つ置くと合計の距離が短いかを扱っています
