# 154 最低賃金の地域差は20年で縮まったのか（地域別最低賃金）

厚生労働省「地域別最低賃金改定状況」（平成14〜令和8年度）で、47都道府県の最低賃金（時間額）のばらつきを年度ごとに計算したフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A154 | 最低賃金の地域差は20年で縮まったのか | 変動係数・ジニ係数・最高額÷最低額・最高額−最低額（都道府県は同じ重み）。2016年度の水準と2016→2026年度の引上げ率の相関 | `src/a154_minwage.py` |

## 主な結果
- 最高額÷最低額：1.172倍（2002年度）→ 1.312倍（2014年度、最大）→ 1.180倍（2026年度）
- 変動係数：4.72%（2002）→ 7.27%（2014）→ 4.20%（2026）。ジニ係数：2.61% → 3.77% → 2.04%
- 差額（最高−最低）：104円（2002）→ 224円（2018年度、最大）→ 195円（2026）
- 2026年度：最高 東京都 1,280円、最低 宮崎県 1,085円。29都道府県が1,100円以上
- 2016→2026年度の引上げ率は2016年度の水準と強い負の相関（r = −0.95）。徳島県 54.0% 〜 東京都 37.3%。2002→2016年度は正の相関（r = +0.71）

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a154_minwage.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/minimum_wage_2002_2026.csv | 都道府県別の地域別最低賃金（時間額、円）2002〜2026年度、2025・2026年度の発効日、全国加重平均額 |

元の Excel（https://www.mhlw.go.jp/content/11200000/001756130.xlsx）から書き写しています。

## 注意
- 名目の金額です。物価の違いは考えていません
- 都道府県は同じ重みで扱っています（全国加重平均額は参考として載せています）
- 2025年度は6県で発効日が2026年1月以降でした。年度ごとの金額で比べており、発効日の違いは計算に入れていません
