# F198 調査は、何人に聞けば足りるのか？

## 問い

「何人に聞けば足りるか」は、教科書の式で計算できます。では、その式で出る人数と、実際の公的統計の標本の大きさは、どれくらい違うのでしょうか。違うとしたら、何が人数を押し上げているのでしょうか。

この記事は、方法どうしを比べるものです。実在の調査の良し悪しを評価するものではありません。

## データ

公表資料の数字を、手で転記しました（`data/`）。

| ファイル | 中身 | 出どころ |
|---|---|---|
| `survey_designs.csv` | 5つの調査の標本の大きさ（「約」の値のまま） | 各調査の「調査の概要」ページ |
| `lfs_se_by_size.csv` | 労働力調査の推定値の大きさ別の標準誤差（全国。月次は2025年1〜12月の平均、年平均） | 総務省統計局「標本抽出方法、結果の推定方法及び推定値の標本誤差」 |
| `lfs_main_items_2025.csv` | 主要項目の年平均結果の標準誤差（2025年） | 同上 |
| `lfs_regional_se_annual.csv` | 地域別の年平均結果の標準誤差率 | 同上 |

対象にした5つの調査は次のとおりです。

| 調査 | 標本の大きさ |
|---|---|
| 労働力調査 | 毎月 約2,900調査区・約4万世帯、15歳以上 約10万人 |
| 家計調査（二人以上の世帯） | 168市町村・8,076世帯 |
| 社会生活基本調査（2021年） | 約7,600調査区・約9万1千世帯、10歳以上 約19万人 |
| 就業構造基本調査（2022年） | 約3万4千調査区・約54万世帯、15歳以上 約108万人 |
| 個人企業経済調査 | 約4万企業（全国の個人企業 約170万のうち） |

## 方法

1. **教科書の式**
   - 割合 p を ±e で推定する：n = 1.96² p(1−p) / e²
   - 割合 p の標準誤差率（相対）を cv にする：n = (1−p) / (p cv²)
   - 2時点の差 d を検出力80%・両側5%で見分ける：n = (1.96+0.84)² × 2(1−ρ) p(1−p) / d²（ρ は2時点の推定値の相関）
2. **設計効果の逆算**：労働力調査の公表の標準誤差と、同じ人数（月10万人）を単純無作為で選んだときの標準誤差を比べました。比の2乗が設計効果（DEFF）です。逆に、公表の標準誤差から「単純無作為なら何人分に当たるか」（有効標本数）も求めました。15歳以上人口は、2025年平均の労働力人口と非労働力人口の和（1億966万人）を使っています。
3. **区分の数**：全国だけ／11地域ごと／47都道府県ごとに、同じ精度を出すのに要る総数を求め、実際の標本の大きさと並べました。
4. **シミュレーション**：式どおりの人数と、その1/4の人数で、2万回くり返しました（二項分布、seed 20261105）。

## 結果

### 1. 精度の決め方で、必要な人数は100倍違う

| 推定したい割合 | ±1ポイント | ±3ポイント | 標準誤差率5% |
|---|---|---|---|
| 50% | 9,604人 | 1,067人 | 400人 |
| 10% | 3,457人 | 384人 | 3,600人 |
| 2.5% | 937人 | 104人 | 15,600人 |
| 1% | 380人 | 42人 | 39,600人 |

- 「±何ポイント」で決めると、まれな割合ほど少ない人数で済みます。
- 「割合に対して何%」で決めると、まれな割合ほど人数が増えます。
- 失業率（約2.5%）を標準誤差率5%で出すには、単純無作為でも1万5,600人の労働力人口が要ります。

### 2. 労働力調査の設計効果は1.3〜2.0

- **月次の設計効果**：推定値の大きさ別の表で比べると、公表の月次標準誤差は、同じ10万人を単純無作為で選んだときより大きく、設計効果は1.31〜1.98（中央値1.40）でした。推定値が大きい（5,000万人）ほど設計効果も大きくなります。
- **有効標本数**：月次の有効標本数は、中央値で約7.1万人です。
- **年平均**：年平均の有効標本数は約45万人で、月次の約6.5倍でした（分散の比）。12か月分の12倍にならないのは、同じ世帯を2か月続けて調べ、翌年の同じ月にもう一度調べる仕組みで、月どうしの標本が重なるためと考えられます（推測）。
- **項目による違い**：主要項目の年平均で有効標本数を逆算すると、項目による差が大きく出ました。
  - いちばん大きい「卸売業，小売業」：約64万人
  - いちばん小さい「製造業」：約13万人
  - 差は5.0倍です。標準誤差が1万人単位で丸められていることを考えても、3.6倍以上あります。
  - 製造業・情報通信業・教育など、地域に偏って集まりやすい項目ほど小さい傾向です。同じ調査区に同じ産業の人がまとまって住む・働くためと考えられます（推測。F197 の級内相関の話です）。

### 3. 失業率の前月差：見分けられるのは0.2〜0.3ポイント

- **月次の標準誤差**：完全失業者（約176万人）の月次標準誤差を大きさ別の表から内挿すると約5.1万人で、失業率に直すと約0.07ポイントです。単純無作為なら0.06ポイントで、設計効果は1.37です。
- **見分けられる変化**：前月との差を検出力80%で見分けられる大きさは、2か月の推定値が独立なら0.29ポイント、相関0.5なら0.20ポイントでした。前月差の95%の幅は ±0.14〜0.20ポイントです。
- **0.1ポイントを見分けるのに要る人数**：毎月の労働力人口の標本が26万〜53万人要ります。いまの約6.4万人の4〜8倍です。

### 4. 区分を細かくすると、要る人数は区分の数だけ増える

割合50%を±1ポイントで出すのに要る人数は、設計効果1.5を仮定すると次のとおりです。

| 区分 | 要る人数 |
|---|---|
| 全国だけ | 約1.4万人 |
| 11の地域ごと | 約15.8万人 |
| 47都道府県ごと | 約67.7万人 |

実際の標本を仮に47に等分すると、1区分あたりの±の幅（p=50%、設計効果1.5）は次のとおりです。

| 調査 | ±の幅 |
|---|---|
| 就業構造基本調査 | 0.8ポイント |
| 社会生活基本調査 | 1.9ポイント |
| 労働力調査（月次） | 2.6ポイント |
| 個人企業経済調査 | 4.1ポイント |
| 家計調査（世帯） | 9.2ポイント |

5年ごとの大規模な調査ほど、細かい区分で結果を出すことを前提にした大きさになっています（推測）。

労働力調査の地域別の表では、同じ100万人の推定値でも、標準誤差率は沖縄0.7%から南関東1.5%まで違いました。地域の人口が小さいほど、その地域の中での割合が大きくなるためです。

### 5. 式どおりの人数なら狙いどおり。ただし p=1% では区間がずれる

- **式どおりの人数**：2万回のくり返しで、狙った誤差の幅に入った割合は94.6〜96.0%で、ほぼ95%でした。
- **人数を1/4にした場合**：同じ割合は63〜75%に下がりました。
- **p=1%・±1ポイントの場合**：式の人数（381人）は足りていますが、正規近似の95%区間が本当の値を含んだのは89%だけでした。人数を1/4にすると62%で、38%の回で「0人」になりました。まれな割合では、人数の式だけでなく区間の作り方も変える必要があります。

## 頑健性

- **効果の大きさ**：前月差0.1・0.2・0.3ポイント。要る人数は差の2乗に反比例します（0.1ポイントで53万人、0.3ポイントで5.9万人。独立の場合）。
- **誤差の幅**：±1・2・3・5ポイントと、標準誤差率5・10・20%。
- **区分の数と設計効果**：区分の数（1・11・47）×設計効果（1.0・1.5・2.0）で、要る総数を表にしました（`results/D_domains_total_n.csv`）。
- **前提の数字を動かした場合**：15歳以上人口を±5%、毎月の標本を9万〜11万人に動かすと、設計効果は1.17〜2.18の間で動きます。どの場合も1を上回りました。
- **推定値の相関（標本の重なり）**：0・0.25・0.5 の3通りで計算しました。実際の相関は確かめていません。

## 言えないこと

- **実在の調査の評価ではありません。** 標本の大きさは、費用・回答の負担・公表する区分・必要な精度などを合わせて決められています。この記事の計算は、そのうち「誤差」の面だけを単純にしたものです。
- **家計調査・個人企業経済調査の主な推定値は金額の平均です。** 割合の式で出した±の幅は、比べるための目安にすぎません。金額の平均の精度は、ばらつき（変動係数）で決まります。
- **設計効果は労働力調査の公表値からの逆算です。** 15歳以上人口と標本の人数は「約」の値で、比推定や回答のない分の補正の効果も含んだ値です。ほかの調査の設計効果は分かりません。
- **前月差の計算は、失業率の分母（労働力人口）の誤差と、2か月の推定値の実際の相関を考えていません。** 相関は仮定の値です。
- **月次の標準誤差は2025年の平均です。** 月によって違います。
