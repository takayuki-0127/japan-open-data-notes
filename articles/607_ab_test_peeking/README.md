# 607 A/B テストを毎日のぞいて「差あり」が出た日に止めると、効果が0でも何%で差ありになるのか（手法の解説・正解の分かるデータで試す）

A/B テストの途中経過を毎日見て、p<0.05 が出た日に「差あり」で止めると、1回だけ検定するつもりで作った5%の基準を、何度もくり返し使うことになります。**ここでは、架空の A/B テスト（1日に各群500人、購入率5%、28日間）をシミュレーションで2万回くり返し、のぞく回数と止め方で、効果0のときの偽の「差あり」と、効果ありのときの見つけ方・止めた日に読む効果の大きさを比べました。** 人数と購入率は作成者が置いたもので、数字はその前提で決まります。

|---|---|---|---|
| A607 | のぞく回数と止め方で、偽陽性率・検出力・読んだ効果がどう変わるか | 2つの割合の差の z 検定（累計）。F 28日目に1回、P7/P3/P1 7日・3日・毎日のぞいて p<0.05 で止める、B 毎日のぞき O'Brien–Fleming 型の境界（k 日目は \|z\|>c√(28/k)、c は効果0で全体5%になるようシミュレーションで決定）。本当の効果（購入率の相対差）0・+5%・+10%・+15%。各2万回、seed 607 | `src/a607_ab_peeking.py` |

## 主な結果
- **効果0で「差あり」になった割合**：28日目に1回 4.8%、7日ごと 12.4%、3日ごと 18.2%、**毎日 27.0%**。毎日のぞくと、7日目までに16.4%、14日目までに21.8%が偽の「差あり」で止まる
- **境界を使えば毎日見てもよい**：O'Brien–Fleming 型の境界（c=2.16、1日目は \|z\|>11.4、28日目は \|z\|>2.16）なら 4.6%
- **本当の効果 +10% を見つけた割合**：1回 46.3%、毎日 63.7%（そのかわり偽陽性27%）、境界つき 43.6%
- **止めた日に読んだ効果（本当は +10%）**：毎日のぞいて止めると平均 **+29.7%**（止めた日の中央値9日目）。1回の検定でも「差あり」の回だけ見ると +14.9%、境界つきは +18.1%（中央値21日目）。早く止めるほど、たまたま大きく出た日に止まる
- 本当の効果 +15% のときの検出力：1回 79.4%、毎日 87.3%、境界つき 76.6%

## 確かめたこと
- 空のフォルダで流し直し、results・figures がバイト単位で一致した
- 1回だけ検定した場合の偽陽性率が 5% 前後（4.8%）になること
- 境界の定数 c は、結果を数えるのとは別の乱数で決めた（同じ乱数で決めると5%ちょうどに見えてしまうため）

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 607）
- 仮定：毎日、各群500人が来て、購入するかどうかは独立（二項分布）。曜日の波や、日ごとに来る人の違いは入れていない

## 注意（言えないこと）
- シミュレーションの結果。人数・購入率・日数は作成者が置いたもので、結果はこれで決まる
- O'Brien–Fleming 型の境界は、ここではシミュレーションで定数を合わせた簡単な形。実際には α 消費関数などで決める方法がある
- 止めた日に読む効果が大きく出るのは、「差あり」の回だけを選んで見ることによる。効果を報告するなら、決めた日数まで続けた値を使うほうがよい
