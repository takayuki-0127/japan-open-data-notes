# F260 計画（事前登録）：「100年に1度の損害」は、どの分布を仮定するかでいくら変わるのか

作成：2026-11-11（分析の前に GitHub に置く。結果を見たあとで変えた点は README と記事に書く）

## 問い

保険会社の決算説明やリスク管理の資料には「100年に1度（または200年に1度）の自然災害で想定する損害」がよく出てくる。この数字は、過去の災害の損害額に**どの分布（損害の大きさの形）を当てはめるか**でいくら変わるのか。データが30年あまりしかないとき、その違いはデータで見分けられるのか。

誰が知りたいか：損害保険・再保険のリスク管理の担当、保険会社の資料を読む投資家・記者、極値の考え方を実務で使うデータ分析者。

## データ（F256 で集めたものを再利用。新しい取得はしない）

- 日本損害保険協会「近年の風水害等による支払保険金調査結果」の35事故（2012〜2025年度、事故ごとの支払保険金）
- 同「過去の主な風水災等による保険金の支払い」上位10事故（1991年以降）
- 国土交通省 建設工事費デフレーター（住宅総合、年度）、住宅・土地統計調査の住宅数（F256 の補間値）
- **注意：** 作成者は F256 の作業で、これらの事故の名目額・住宅1戸あたり実質額をすでに見ている。分布を当てはめた結果（100年に1度の額など）はまだ計算していない。

## 損害額のものさし

各事故の損害を「今（2025年度）の建設費と住宅数に直した額」にそろえる：
損害（2025年度換算, 億円） = 住宅1戸あたり実質保険金（2020年度価格, F256）× 2025年度の住宅数 × 2025年度デフレーター / 100

## 比べる分布（事故1件の損害の大きさ）

しきい値 u を超えた事故だけを使い、u より上の部分に当てはめる（最尤法）。
1. 指数分布（裾が軽い基準）
2. ワイブル分布（u で切断）
3. 対数正規分布（u で切断）
4. パレート分布（べき乗）
5. 一般化パレート分布（GPD、POT）

頻度：u を超える事故の年あたり件数 λ をポアソンとみなす（データの年数で割る）。

## 求める数字

- **100年に1度の損害（1事故）**：λ × P(損害 > x) = 0.01 となる x（年に1%の確率で、これ以上の事故が1件以上起きる額にほぼ等しい）
- **200年に1度**（ソルベンシー規制で使われる水準の目安）：同じく 0.005
- **年間の合計損害の 99%・99.5% 点**（PML の目安）：複合ポアソンのシミュレーション（10万年、乱数の種を固定）

## 仮説と「外れ」の基準

- **H1（分布で大きく変わる）**：5つの分布の100年に1度の額の最大÷最小が 2 倍以上。**外れ**：1.5 倍未満。
- **H2（データで見分けられない）**：AIC の最良から差が 2 未満の分布が2つ以上あり、その中で100年に1度の額が 1.5 倍以上違う。**外れ**：最良の分布が他のすべてに AIC で 4 以上の差をつける。
- **H3（同じ分布でも幅が広い）**：AIC 最良の分布で、ブートストラップ（事故を復元抽出・件数もポアソンで振る、2,000回）の100年に1度の額の90%区間の上端÷下端が 3 倍以上。**外れ**：2 倍未満。
- **H4（長いデータで変わる）**：取りこぼしのない35年の大きな事故だけ（F256 の足切り：住宅1戸あたり実質 4,456円以上、1991〜2025年度）で当てはめた GPD／パレートの100年に1度の額が、14年の35事故で当てはめた値と 30% 以上違う。**外れ**：違いが 15% 未満。

## 頑健性チェック（最低3つ）

1. しきい値 u を3通り（例：小さい・中くらい・大きい。事故数が 25・15・10 件前後になるように決める）
2. 物価のものさしを CPI（総合）に替える
3. 最大の事故（2018年台風21号）を1件抜く
4. 台風だけに絞る

## 書き方

- 予測ではなく「仮定の違いで数字がいくら動くか」を示す。保険会社の実際の数字や個社には触れない。
- 気候の変化による増え方（トレンド）は扱わない（F256 で傾向が見えなかったため、定常と仮定。そのことを「言えないこと」に書く）。
