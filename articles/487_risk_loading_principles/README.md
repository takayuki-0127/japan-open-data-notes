# 487 保険料の上乗せを「標準偏差」「分散」「期待効用」で決めると、契約の大きさでどう違うのか？（手法の解説）

保険料には、損害の平均（期待値）に、ばらつきへの備えとして上乗せを足すことがあります。上乗せの決め方の教科書的な例に、**損害のばらつき（標準偏差）に比例させる**、**分散に比例させる**、**指数型の効用で期待効用が変わらない額にする**の3つがあります。**ある1つの契約で3つの決め方の上乗せ率をそろえておいても、契約の大きさが変わると上乗せ率がどれだけ食い違うかを、式で計算しました。** 数字は、置いた損害の分布と、そろえた基準の契約で決まります。

## 置いたこと（架空）
- 損害の合計＝事故の件数（ポアソン）×1件ごとの損害（ガンマ）の和。件数と1件の損害は独立
- 基準の契約：件数の平均10件、1件の平均10万円（指数分布）。損害の平均100万円、標準偏差44.7万円
- 3つの決め方を、基準の契約でどれも上乗せ10%（110万円）になるように合わせた
  - 標準偏差に比例：上乗せ＝0.224×標準偏差
  - 分散に比例：上乗せ＝0.005×分散（万円で計算）
  - 期待効用（指数）：保険料＝ln E[exp(a×損害)] ÷ a、a＝0.00909（1/万円）
- 契約の大きさは2通りで変えた。①1件の損害の金額を c 倍にする（件数は同じ）。②同じ契約を n 件、独立に束ねる

## 主な結果
### ① 金額だけを c 倍にしたとき（上乗せ率、%）
| 金額 | 標準偏差に比例 | 分散に比例 | 期待効用（指数） |
|---|---|---|---|
| 0.1倍 | 10.0 | 1.0 | 0.9 |
| 0.5倍 | 10.0 | 5.0 | 4.8 |
| 1倍（基準） | 10.0 | 10.0 | 10.0 |
| 2倍 | 10.0 | 20.0 | 22.2 |
| 5倍 | 10.0 | 50.0 | 83.3 |
| 10倍 | 10.0 | 100.0 | 1,000.0 |
| 20倍 | 10.0 | 200.0 | 無限大 |

- 標準偏差に比例させると、金額が変わっても上乗せ率は同じ
- 分散に比例させると、上乗せ率は金額に比例して上がる
- 期待効用（指数）は、それより速く上がり、基準の11倍以上では保険料が無限大になる（式が成り立たない）

### ② 同じ契約を n 件束ねたとき（上乗せ率、%）
| 束ねた数 | 標準偏差に比例 | 分散に比例 | 期待効用（指数） |
|---|---|---|---|
| 1 | 10.0 | 10.0 | 10.0 |
| 10 | 3.2 | 10.0 | 10.0 |
| 100 | 1.0 | 10.0 | 10.0 |
| 1,000 | 0.3 | 10.0 | 10.0 |

- 標準偏差に比例させた決め方だけが、束ねるほど上乗せ率が下がる（1/√n）
- 分散に比例・期待効用（指数）は、独立な契約を足しても上乗せが足し算になり、上乗せ率は変わらない

### ③ 24の契約での順位
損害の平均（20・100・500万円）×事故の件数の平均（0.5・2・10・50件）×1件の損害のばらつき（ガンマの形0.5・2）の24契約で、上乗せ率の順位を比べた。

| 比べた2つ | 順位が逆になった組 | 順位の相関（スピアマン） |
|---|---|---|
| 標準偏差 と 分散 | 276組中49組 | 0.78 |
| 標準偏差 と 期待効用 | 266組中48組 | 0.76 |
| 分散 と 期待効用 | 266組中0組 | 0.995 |

- 期待効用（指数）では、24契約のうち5契約が無限大になった（どれも1件の損害が大きい契約）
- 例：損害の平均20万円・件数0.5件の契約は、標準偏差に比例で54.8%（24契約中2位）、分散に比例で60.0%（9位）。損害の平均500万円・件数50件の契約は、5.5%（20位）と15.0%（13位）

全部の数字は `results/` の5つの CSV と `main.json`、24の契約は `data/contracts_24.csv` にあります。

## 注意（言えないこと）
- 架空の損害です。上乗せ率の数字は、件数と損害の分布、基準の契約の置き方で決まります
- 3つの決め方は教科書的な例です。実際の保険料は、経費・資本のコスト・競争・規制などで決まり、この記事の決め方とは違います
- どの決め方を使うべきか、保険料をいくらにすべきかを言うものではありません。数字は置いた前提しだいです
- 1件の損害が裾の重い分布（対数正規やパレート型）だと、期待効用（指数）の保険料はどの契約でも無限大になります。そのためここではガンマを使いました
- 資本と上乗せの関係は416で扱いました
