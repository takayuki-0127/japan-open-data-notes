# 220 養豚と採卵鶏の大規模化は、どれだけ進んだか：規模分布とジニ係数

農林水産省「畜産統計調査」の累年統計表で、豚と採卵鶏の飼養戸数・頭羽数（1960〜2024年）と、規模別の戸数・頭羽数（2002〜2023年）を使い、大規模化の進み方を、1戸あたりの規模・上位階層への集中・ジニ係数で見たフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A220 | 養豚と採卵鶏の大規模化はどれだけ進んだか。経営の間の差は広がったか | 1戸あたり頭羽数の長期推移、規模別の頭羽数の構成比、規模階層の中は同じ規模とみなしたローレンツ曲線とジニ係数（下限の近似） | `src/a220_livestock_scale.py` |

## 主な結果
- 養豚の飼養戸数は1962年の102.5万戸から2024年は3,130戸に。1戸あたりの飼養頭数は1960年の2.4頭から2,811頭になった。飼養頭数は1989年の1,187万頭が最も多く、2024年は880万頭
- 採卵鶏の飼養戸数は1960年の384万戸から1990年は8.7万戸。成鶏めす1,000羽以上の飼養者に絞った1998年以降は、5,390戸から2024年は1,640戸。1戸あたりの成鶏めすは1998年の2.7万羽から2024年は7.9万羽
- 2002→2023年に、肥育豚2,000頭以上の階層が持つ頭数の割合は51.6%→79.1%（戸数では10.2%→31.9%）。成鶏めす10万羽以上の階層が持つ羽数の割合は51.0%→80.1%（戸数では8.5%→20.2%）
- いちばん上の階層の中でも規模は大きくなった。豚の2,000頭以上の1戸あたりは2008年6,017頭→2023年6,948頭、採卵鶏の10万羽以上は2002年20.0万羽→2023年33.6万羽
- ジニ係数は、採卵鶏が0.636（2002年）→0.678（2023年）と上がった（最高は2016年の0.695）。豚は0.604→0.525と下がった（3,000頭以上を分けた7階層でも2008年0.624→2023年0.576）。豚では小さい経営がやめて残った経営の規模がそろってきたため、「大規模化」と「経営の間の差」は同じ動きにならなかった

## 動かし方
```
pip install -r requirements.txt
cd src && python a220_livestock_scale.py
```

## データ
- `data/pig_farms_head_1960_2024.csv`：豚の飼養戸数・飼養頭数（全国、豚飼養戸数・頭数累年統計）
- `data/layer_farms_hens_1960_2024.csv`：採卵鶏の飼養戸数（計、種鶏のみの飼養者を除く）と成鶏めす羽数（千羽）。`basis` は調査対象（all：すべて、ge300：成鶏めす300羽以上、ge1000：1,000羽以上。1997年は両方）
- `data/pig_size_class_2002_2023.csv`：肥育豚飼養頭数規模別の飼養戸数・飼養頭数（累年統計表、平成14年〜令和5年）。1〜99頭は細かい階層を合計した
- `data/layer_size_class_2002_2023.csv`：成鶏めす飼養羽数規模別の飼養戸数・成鶏めす羽数（同）。令和4年から階層区分が変わったため、分析では1,000〜9,999羽、1万〜4.9万、5万〜9.9万、10万羽以上の4階層にそろえた
- `results/`：集中度とジニ係数、1戸あたり規模の計算結果

## 注意
- ジニ係数は、規模階層の中の経営はみな同じ規模とみなして計算した近似で、本当の値より小さくなります。特に一番上の階層（豚2,000頭以上、採卵鶏10万羽以上）は上限がないため、その中の差は入っていません
- 採卵鶏は1991年（300羽未満を除く）と1998年（1,000羽未満を除く）に調査対象が変わり、前後の戸数や1戸あたり羽数はつながりません
- 2005・2010・2015・2020年は農林業センサスの年で調査を休止していて、値がありません（2025年の累年の値もまだ入っていません）
- 規模別の表は学校・試験場などの非営利の飼養者を含まず、累年の戸数・頭数の表と値が少し違います
