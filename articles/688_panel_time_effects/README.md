# 688 店の固定効果だけ入れて、年ごとの流れを入れないと、施策の効果はどれだけずれるのか（手法の解説・正解の分かるデータで試す）

店ごとの売上を何年分か並べたパネルデータで施策の効果を見るとき、店の固定効果（店ごとの水準の違い）を入れるのはよく行われます。ただ、全店に共通する年ごとの流れ（景気・物価・季節以外の伸び）を入れないと、施策を始める店が多い年ほど全体が伸びている場合に、その伸びが施策の効果に入り込みます。**ここでは、架空の100店×8年のパネル（本当の効果1.0）で、全体の伸びを年0〜0.5に変え、店の固定効果だけの推定と、店と年の固定効果を両方入れた推定を比べました。** 各500回です。数字は置いた伸びと施策の始め方で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A688 | 年の効果を入れないと、効果はどれだけずれるか | y = 店の水準（標準偏差2）＋ g×年＋年ごとの振れ（標準偏差0.5）＋1.0×施策＋誤差（標準偏差1）。施策は3〜8年目のどこかで始めて続ける（2割の店は始めない）。推定：店の平均を引いた回帰（店の固定効果）、店と年の平均を引いた回帰（二元配置）。標準誤差は店でまとめる。g = 0・0.1・0.25・0.5、各500回、seed 688 | `src/a688_panel_time.py` |

## 主な結果（500回の平均。本当の効果は1.0）
| 全体の伸び（1年あたり） | 店の固定効果のみ | 区間が当たった割合 | 店と年の固定効果 | 区間が当たった割合 |
|---|---|---|---|---|
| 0 | 1.02 | 43% | 1.01 | 95% |
| 0.1 | **1.42** | 19% | 1.00 | 95% |
| 0.25 | **1.99** | 1% | 1.00 | 95% |
| 0.5 | **2.99** | 0% | 1.00 | 96% |

- 店の固定効果だけだと、全体が1年に0.25伸びるだけで、効果は本当の2倍（1.99）と出た。施策を始めた年より後の年ほど、全体の伸びが上乗せされるため
- 伸びがなくても（0）、店の固定効果だけの95%区間は43%しか当たらなかった。全店共通の年ごとの振れを誤差として扱えず、標準誤差が小さく出るため
- 店と年の固定効果を両方入れると、どの伸びでも推定は1.00前後、区間は95%前後当たった
- ばらつき（標準偏差）も、年の効果を入れたほうが小さかった（0.32 → 0.12）
