# F49 平均寿命の県の差は、何歳の死亡で生まれているか？（生命表の自作と Arriaga 法）

看板記事 F49。厚生労働省「都道府県別生命表」（2000〜2020年、5回分）を使い、①公表の死亡率から生命表を自分で作り直して公表値と一致するかを確かめ、②47都道府県の平均寿命と全国との差を、年齢ごとの死亡率の違いに分解（Arriaga 法）した。③20年でその差の中身がどう変わったかも見た。

## 問い

- 平均寿命（0歳の平均余命）は、年齢別の死亡率からどう計算されるか。自分で計算すると公表値と同じになるか
- 都道府県の平均寿命の差は、何歳の死亡率の違いで生まれているか
- 県の差は縮まっているか。差の中身（年齢）はどう変わったか

## データ

| データ | 中身 | 年 |
|---|---|---|
| 厚生労働省「都道府県別生命表」（e-Stat、政府統計コード 00450012） | 全国と47都道府県の男女別の生命表（各歳。死亡率 nqx・生存数 lx・死亡数 ndx・定常人口 nLx・Tx・平均余命 ex）。CSV | 平成12年（2000）・17年・22年・27年・令和2年（2020） |
| 同 付録80000「都道府県別平均寿命の年次推移」 | 47都道府県の男女別の平均寿命 | 1965〜2020年（記事では1965年以降を使用） |

- 2000・2005年は最高年齢が「95歳以上」、2010年以降は「100歳以上」。年をまたいで比べるときは、95歳以上にまとめた表で計算した
- e-Stat の表番号（statInfId）は `data/raw/f49_lifetables.json` の `ids` に入っている。CSV の中身も同じファイルの `lt` にそのまま入れてある

## 手法

| ステップ | 中身 |
|---|---|
| 生命表の自作 | 公表の死亡率 nqx（各歳）だけから、生存数 lx（10万人から）、定常人口 Lx = lx −(1−a)dx（a は0歳0.1、1歳以上0.5）、Tx、平均余命 ex を計算し直す。最後の年齢階級は公表の平均余命を使う |
| 年齢別の分解 | Arriaga 法。基準（全国）の生命表から県の生命表への平均寿命の差を、各歳の死亡率の違いによる寄与（その年齢を生きる時間の差＋その先まで生き残る人の差）に分け、7つの年齢区分（0歳、1〜14、15〜39、40〜64、65〜74、75〜84、85歳以上）に足し上げる。寄与の合計は差と一致する（公表の平均余命は小数2桁に丸めてあるので、ずれは最大0.008年） |
| 県の差の中身 | 47都道府県の「全国との差」のばらつき（分散）を、年齢区分ごとの寄与の共分散で分ける：cov(寄与_b, 差) ÷ var(差)。合計は1 |
| 20年の変化 | 2000年と2020年で同じ分解をし、ばらつきの中身を比べる。全国の平均寿命の延び（2000→2020年）も同じ方法で年齢別に分ける |

## 主な結果

**自作の生命表**：480表（5年×48地域×男女）で、作り直した平均寿命と公表値の差は最大0.009年、平均0.003年。公表の死亡率が小数5桁に丸めてあるための差で、計算の仕組みは再現できた。

**2020年の平均寿命**

| | 全国 | 最も長い県 | 最長−最短 | 標準偏差 |
|---|---|---|---|---|
| 男 | 81.49年 | 82.73年（滋賀） | 3.46年 | 0.62年 |
| 女 | 87.60年 | 88.29年（岡山） | 1.96年 | 0.44年 |

**県の差のばらつきは、何歳の死亡率で生まれているか**（2020年、分散に占める割合）

| 年齢 | 男 | 女 |
|---|---|---|
| 0歳 | 0.02 | 0.03 |
| 1〜14歳 | 0.00 | 0.01 |
| 15〜39歳 | 0.07 | 0.08 |
| 40〜64歳 | **0.38** | 0.22 |
| 65〜74歳 | 0.25 | 0.15 |
| 75〜84歳 | 0.20 | 0.23 |
| 85歳以上 | 0.06 | **0.28** |

- 男性は40〜64歳の死亡率の違いがいちばん大きく、65〜84歳と合わせると8割を超える。女性は75歳以上が半分を占める
- 上位5県と下位5県の平均の差（男2.07年）の内訳は、40〜64歳0.84年、65〜74歳0.50年、75〜84歳0.42年。0〜14歳は0.04年だけ
- 同じ県でも年齢で向きが違うことがある（例：女性で、85歳以上では全国より長生き、40〜64歳では全国より死亡率が高い県）

**20年の変化**

- 47都道府県の平均寿命の標準偏差（付録80000）は、男が1965年0.97年→2000年0.57年、女が0.73年→0.44年と縮んだが、2000年以降は男0.57〜0.66年、女0.40〜0.45年でほぼ横ばい。**この20年では、県の差は縮まっていない**
- 差の中身は変わった。男は40〜64歳の割合が0.47→0.38に下がり、65〜84歳が0.34→0.46に上がった。女は75〜84歳が0.37→0.23に下がり、40〜64歳が0.15→0.22、15〜39歳が0.00→0.08に上がった
- 全国の平均寿命の延び（2000→2020年、95歳以上でそろえた計算）：男3.78年のうち40〜64歳が1.24年、女2.98年のうち75〜84歳が1.01年

## 頑健性

県の差のばらつきに占める年齢区分の割合（2020年）は、計算の設定を変えてもほとんど変わらなかった（各区分±0.002以内）。年を2015年に変えると、男の15〜39歳が0.04動いた。

| 設定 | 結果 |
|---|---|
| 基準を全国ではなく「47都道府県の死亡率の平均」で作った表にする | 同じ |
| 分解の向きをならす（全国→県と県→全国の平均） | 同じ（女の85歳以上0.27） |
| 公表の表ではなく、自作の生命表で分解する | 同じ |
| 最高年齢を90歳以上にまとめる | 同じ（90歳以上はもともと「85歳以上」の区分に入るため、変わらないのは当然） |
| 2015年で同じ分解をする | 男の40〜64歳0.39・15〜39歳0.11（2020年は0.07）、女の85歳以上0.28 |

- 5歳刻みにすると、男は60〜79歳の4区分がそれぞれ0.12〜0.13、女は75〜89歳の3区分がそれぞれ0.11〜0.13で、特定の1つの年齢に集まってはいない
- 65歳の平均余命の県の差（男の標準偏差0.39年、女0.32年）は、0歳の平均寿命と相関0.92（男）・0.94（女）

## ファイル

- `data/raw/f49_lifetables.json`：e-Stat の CSV（Shift_JIS を文字列にしたもの）と表番号
- `data/lifetables.csv`：年×地域×男女×年齢の生命表（全国と47都道府県）
- `data/e0_trend.csv`：付録80000 の平均寿命の年次推移
- `results/summary.json`：主な数字。`arriaga_2020_男.csv` などは県ごと・年齢区分ごとの寄与
- `figures/`：記事の図（f49_robust.png は GitHub のみ）

## 言えないこと

- 差の理由（生活習慣、医療、所得、職業など）は、このデータでは分からない
- 死因別の分解はしていない。都道府県別生命表には死因別の「死亡確率」はあるが、年齢×死因の死亡率がないため
- 生命表は、その年の死亡率が続いたと仮定した計算で、ある年に生まれた人が実際に何歳まで生きるかではない
- 特定の県を評価する意図はない。記事の本文では、平均寿命が短いほうの県の名前は挙げていない
