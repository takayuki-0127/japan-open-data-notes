# 922 偏差値60は、上から何%なのか？（分布の形で変わるのか）（試験と点数）

偏差値は、得点から平均を引いて標準偏差で割り、10倍して50を足した値です。偏差値60は「平均より標準偏差1つ分上」を表します。「偏差値60は上から約16%」とよく言われますが、これは得点の分布が正規分布（左右対称の釣り鐘の形）のときの値です。**ここでは、作成者が乱数で作った架空の資格試験で、同じ受験者に、やさしい・ふつう・むずかしい試験を受けてもらったときの得点の分布を式で正確に出し、偏差値60以上・70以上の人が何%いるかを数えました。問題数、問題の見分ける力、受験者の実力の分布を変えた156通りで確かめ、少人数の回でどれだけ振れるかも数えました。**

この記事は、点の数え方と読み方だけを扱います。勉強の仕方や講座の良し悪しは扱いません。

| A922 | 偏差値60以上・70以上の人は、受験者の何%か。試験の難しさ（得点の分布の形）でどう変わるか | 架空の資格試験。受験者の実力 θ は標準正規分布（平均0・標準偏差1）。問題の難しさ b は、試験ごとに「標準正規分布の乱数＋ずらし」（100問のときの乱数は全試験で同じものを使い、ずらしだけを変える）。1問ずつ、正解の確率を 1÷(1＋exp(−1.7×a×(θ−b))) と置く（a は問題の見分ける力、基本は1）。ずらしは、やさしい試験 −2、ふつうの試験 0、むずかしい試験 +2。実力を−6〜+6の601点に分け、実力ごとの正解数の分布（問題ごとに確率が違う）を1問ずつ足して出し、実力の分布で重みを付けて足し合わせ、得点の分布を式で正確に出した（乱数による誤差はない）。偏差値は、受験者全体の平均と標準偏差（割る数は人数）で出した。確かめとして、ずらし（−3〜+3を0.5きざみ、13通り）×問題数（20・100問）×見分ける力（0.6・1.0・1.6）×実力の分布（正規、または「2つの群」：初めての人7割が平均−0.5・標準偏差0.8、経験者3割が平均+1.2・標準偏差0.6）の156通り。少人数の回は、ふつうの試験の得点の分布から30人・300人を取り、その回の平均と標準偏差で偏差値を出すことを2万回。seed 922 | `src/a922_deviation60.py` |

## 主な結果

### 同じ受験者が、難しさの違う3つの試験を受けると（100問）
| | やさしい試験 | ふつうの試験 | むずかしい試験 | （正規分布） |
|---|---|---|---|---|
| 平均点 | 85.28点 | 48.0点 | 11.87点 | — |
| 標準偏差 | 13.58点 | 22.93点 | 12.72点 | — |
| ゆがみ（歪度、0で左右対称） | −1.604 | 0.029 | 1.795 | 0 |
| とがり（超過尖度、0で正規分布と同じ） | 2.951 | −0.912 | 3.723 | 0 |
| 偏差値60以上 | **7.91%** | **19.55%** | **14.19%** | 15.87% |
| 偏差値70以上 | 0% | 0.88% | **5.44%** | 2.28% |
| 偏差値40未満 | 14.16% | 19.57% | 0% | 15.87% |
| 上から15.87%目の人の偏差値 | 58.63 | 61.34 | 58.74 | 60 |
| 上から2.28%目の人の偏差値 | 60.84 | 68.31 | 78.39 | 70 |
| 満点の人の偏差値 | **60.84** | 72.67 | 119.26 | — |

- 同じ受験者でも、偏差値60以上の人の割合は、試験の難しさで7.91〜19.55%と動いた。正規分布の15.87%どおりになった試験はなかった
- やさしい試験では、満点でも偏差値は60.84にしかならず、偏差値70以上は0人だった。高い点の人が満点に詰まり、低い点の人が長く尾を引くため、標準偏差が下の尾で大きくなる
- むずかしい試験では、偏差値70以上が5.44%と、正規分布（2.28%）の2倍あまりいた。逆に偏差値40未満は0人だった（0点の人でも偏差値40.67）
- ふつうの試験は左右ほぼ対称（ゆがみ0.029）でも、偏差値60以上は19.55%だった。分布が正規分布より平たい（とがり−0.912）ため、平均から標準偏差1つ分上より外にいる人が多くなる。左右対称なら15.87%になる、とは限らない

### 確かめ：156通りの置き方で
| | 偏差値60以上 | 偏差値70以上 | 上から15.87%目の人の偏差値 |
|---|---|---|---|
| 全156通り | **0〜23.78%** | **0〜6.76%** | 52.44〜62.86 |
| 実力：正規（78通り） | 0〜23.78% | 0〜6.66% | |
| 実力：2つの群（78通り） | 0〜23.11% | 0〜6.76% | |
| ずらし0（ふつうの難しさ、12通り） | 15.68〜23.78% | | |

- 156通りのうち32通りでは、満点の人の偏差値が60に届かなかった（やさしい試験、問題の見分ける力が大きいとき、20問のとき）
- ふつうの難しさ（ずらし0）の12通りは、分布が正規分布より平たく（とがり−1.361〜−0.667）、偏差値60以上は15.68〜23.78%だった
- 20問の試験は得点が21通りしかないため、偏差値60ちょうどの近くに何人いるかで割合が飛ぶ（たとえば20問・見分ける力0.6・正規の実力で、ずらし−2で17.0%、−1.5で9.36%）
- 全156通りの値は `results/robustness.csv`

### 少人数の回では（ふつうの試験、その回の平均と標準偏差で偏差値を出す、2万回）
| 1回の受験者 | 偏差値60以上の割合：10%目の回 | 中央値の回 | 90%目の回 | 全体の値（19.55%）から5ポイントより離れた回 |
|---|---|---|---|---|
| 30人 | 13.33% | 20.0% | 23.33% | 19.83% |
| 300人 | 17.33% | 19.0% | 20.67% | 0.01% |

- 30人の社内試験では、1人が3.33%にあたるので、偏差値60以上の割合は回ごとに13.33〜23.33%（10〜90%の回）と動き、5回に1回ほどは全体の値から5ポイントより離れた

## 動かし方
```
pip install -r requirements.txt
cd src && python a922_deviation60.py
```
10秒ほどで終わります。`data/` の2つのファイルもこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約8秒）
- 図3枚を開き、日本語・重なり・軸を確かめた
- 得点の分布は乱数を使わずに式で出したので、3つの試験と156通りの値に乱数の誤差はない。乱数を使ったのは、問題の難しさを決めるところと、少人数の回の確かめだけ
- 偏差値60以上が15.87%になるのは得点が正規分布のときの式の値で、この記事の結果の多くは「置いた実力と問題の難しさから決まる得点の分布の形」の写しである。新しく数えたのは、同じ受験者でも試験の難しさでどれだけ動くかの幅

## データ
- `data/score_dist_3exams.csv`：3つの試験の得点の分布（exam・score・prob（その得点の人の割合）・deviation（その得点の偏差値））
- `data/small_session_30.csv`：30人の回の1回目（person・score・deviation、得点の高い順）。この回の偏差値60以上は16.67%
- `results/a922_main.json`：主な結果すべて
- `results/robustness.csv`：156通りの確かめ

## 注意（言えないこと）
- 架空のデータです。実力の分布、問題の難しさの散らばり、正解の確率の形（ロジスティックの形）は作成者が置いたもので、結果はこれで決まります。偏差値60以上の割合は、置き方で0〜23.78%と動きました
- 実在の試験や模擬試験の偏差値が、上から何%にあたるかを表すものではありません
- 当てずっぽうで正解する分、部分点、問題どうしの関係（同じ分野の問題がまとめて解ける）は入れていません
- 偏差値の高い・低いから、受かるかどうかや実力の差を言うことはできません。勉強の仕方や講座の良し悪しは言えません
