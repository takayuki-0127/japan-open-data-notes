# 554 セット商品の売上を構成品に分けるとき、金額の割り振り方で商品別の売上はどれだけ変わるのか（実務の型・セットの按分）

セット商品の売上を「どの商品がどれだけ売れたか」に分けるには、セットの金額を構成品に割り振る必要があります。**ここでは、架空の店（単品30品目、セット10種。セットは2〜4品の組み合わせで、単品価格の合計より10.9〜24.8%安い）の2025年の売上 108.4百万円（うちセット 59.8百万円、55.2%）を作り、セットの金額を構成品に割り振る3通りで、商品別の売上・粗利率・順位を比べました。** 価格・原価・セットの組み合わせは作成者が置いたもので、数字はその仮定で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A554 | 割り振り方で、セットに入る17品目の売上・粗利率と、30品目の売上順位がどれだけ変わるか | A 単品価格の比、B 原価の比、C 構成品で均等（数量を考えない）。A の商品別売上を Python と SQL（DuckDB、1スレッド）で突き合わせ。seed 554 | `src/a554_bundle.py`、`src/02_allocation_duckdb.sql`、`src/01_allocation_tsql.sql`（未検証） |

## 主な結果
- **売上**：単品価格の比（A）と比べて、原価の比（B）では −21.7%〜+15.0%（差の絶対値の中央値 4.0%）、均等（C）では −41.7%〜+216.3%（中央値 25.8%）
- **粗利率**：17品目で、3通りの粗利率の幅の中央値は 21.8ポイント、最大は I29（雑貨）の 43.1ポイント（A 40.0%・B 40.1%・C −3.0%）。単価の安い品目（I02・I13 など飲料）は、均等に割り振ると粗利率が 84〜89% まで上がる
- **順位**：30品目の売上順位は、A と B で 11品目、A と C で 20品目が入れ替わった（上位10品目の顔ぶれは B で同じ、C で1品目入れ替わり）。I19 は 13位から4位に上がる
- 店全体の売上と粗利（50.8百万円）は、どの割り振り方でも同じ

## 動かし方
```
pip install -r requirements.txt
cd src && python a554_bundle.py
```
数秒で終わります。`data/` に品目・セット・構成・売上を書き出します。

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures がバイト単位で一致した（DuckDB は `SET threads=1`）
- 単品価格の比で割り振った商品別売上が、Python と DuckDB の SQL で一致した
- T-SQL 版（`01_allocation_tsql.sql`）は書いたが、SQL Server では動かしていない（**未検証**）

## データ
- `data/items.csv`（品目・分類・単品価格・原価）、`data/sets.csv`（セット価格・単品価格の合計・値引き率）、`data/set_components.csv`（セットの構成品と個数）、`data/single_sales.csv`・`data/set_sales.csv`（年間の販売数と金額）
- 仮定：原価率 食品 45〜70%・飲料 25〜45%・雑貨 30〜60%。セットは2〜4品、構成品の個数は1〜3

## 注意（言えないこと）
- 架空のデータ。実際の店や商品の数字ではない
- 差の大きさは、置いた価格差・原価率・セットの組み合わせで決まる。構成品の価格差が大きいセットほど、割り振り方の違いが効く
- どの割り振り方を使うべきかや、会計基準での扱いは扱っていない
- 価格の決め方や会計処理についての助言ではない
