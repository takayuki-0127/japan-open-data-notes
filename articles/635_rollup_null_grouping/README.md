# 635 ROLLUP の小計の行と、もともと区分が空の行を取り違えると、合計はどれだけずれるのか（実務の型）

`GROUP BY ROLLUP` は、区分ごとの行に加えて小計・合計の行を出します。小計の行では区分の列が NULL になりますが、明細にもともと区分が空（NULL）の行があると、結果の表に「区分が NULL の行」が2種類並びます。**ここでは、架空の売上明細2万行（6店×5区分、区分が空の行が7.9%）で店×区分の ROLLUP を DuckDB で出し、結果の表から店の小計を取り出す4通りの読み方で、店の小計と全体の合計がどれだけずれるかを数えました。** 未分類の割合を0〜20%で動かした場合も出しています。数字は置いた割合で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A635 | 小計の行と区分が空の行を取り違えると、合計はどれだけずれるか | 店×区分の `GROUP BY ROLLUP`（DuckDB、1スレッド）。読み方：R0 `GROUPING(category)=1` の行を小計とみなす／R1 区分が NULL の行を小計とみなす／R2 区分が NULL の行を捨てて区分の行を足す／R3 `COALESCE(category,'小計')` で埋め、店ごとに最初の「小計」の行を使う。未分類の割合 0〜20% で各200回。seed 635 | `src/a635_rollup_null.py`、`src/02_rollup_duckdb.sql`、`src/01_rollup_tsql.sql` |

## 主な結果
- ROLLUP の結果は43行で、区分が NULL の行は13行。そのうち本当の小計（GROUPING=1）は7行（店の小計6行＋全体の合計1行）、残り6行は店ごとの「未分類」の行だった
- **区分が NULL の行を小計とみなす（R1）**：店の小計に未分類の売上が足し合わされ、全体の合計は **+7.67%**（未分類の売上の割合と同じ）。店ごとでは最大 +8.43%
- **NULL の行を捨てて区分の行を足す（R2）**：未分類の売上が落ちて **−7.67%**
- **NULL を「小計」で埋めて最初の行を使う（R3）**：結果の並びでは未分類の行が先に来るので、小計として未分類の売上だけを拾い、全体の合計は **−92.33%**
- 未分類の割合を変えると、R1・R2 のずれは割合とほぼ同じ大きさになった（1%で ±1.0%、10%で ±10.0%、20%で ±20.0%）
- GROUPING で見分ける読み方（R0）は、Python で明細から出した店の小計・全体の合計と一致した
