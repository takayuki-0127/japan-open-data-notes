# 803 口コミを書かなかった人の満足度は、口コミの平均とどれだけ違うのか？（口コミと星の数）

口コミを書くのは来た人のごく一部で、とても満足した人と不満な人ほど書きやすいと言われます。そうだとすると、口コミの平均は「来た人全員の満足度」からずれ、書かなかった大多数の人の満足度は口コミからは見えません。**ここでは、作成者が乱数で作った架空の店400軒・1軒あたり来た人3,000人（全員の「付けるとしたら何点か」を作成者が置いたもの）で、口コミの平均・来た人全員の平均・書かなかった人の平均を比べ、だれが書くかの偏りでずれ方がどう変わるかを数えました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A803 | 書く人が満足した人と不満な人に偏ると、口コミの平均は来た人全員の平均からどれだけずれるか。書かなかった人の満足度はどれくらいか | 架空の店400軒、1軒あたり来た人3,000人。店の本当の平均 μ は平均3.6・標準偏差0.4の正規分布（2.3〜4.7で切る）。来た人の星は、平均が μ になる幅0.9の1〜5の山形の分布から引く。口コミを書く確率は、その人の星で変わる。基本は「両端ほど書く」：星1から順に10%・5%・2%・4%・10%。確かめとして「満足した人ほど書く」（2%・2%・3%・5%・10%）、「不満な人ほど書く」（12%・8%・4%・3%・3%）、「だれでも同じ」（どの星も5%）を、店を作り直して20回ずつ数えた。さらに「3割の店は来た人全員に声をかけ、どの星の人も5%が書く。残りの店は両端ほど書く」と混ぜた場合の順位の動きを20回数えた。店どうしの差を言うときの「何倍に広げるか」は、来た人全員の平均に口コミの平均を直線で当てはめた傾き。seed 803 | `src/a803_who_writes.py` |

## 主な結果

### 星の分布：来た人全員と口コミ（店400軒の合計、基本の置き方）
| | 星1 | 星2 | 星3 | 星4 | 星5 |
|---|---|---|---|---|---|
| 来た人全員（正しい答え） | 1.2% | 10.6% | **33.0%** | 38.1% | 17.0% |
| 口コミを書いた人 | 2.8% | 11.4% | **14.3%** | 34.0% | **37.4%** |

- 来た人の3人に1人は星3だったが、口コミでは14.3%に減った。星5は17.0%から37.4%に増えた
- 口コミを書いたのは来た人の4.6%（1軒あたり口コミの件数の中央値は128件）

### 平均：来た人全員・口コミ・書かなかった人（店400軒の平均）
| | 来た人全員（正しい答え） | 口コミ | 書かなかった人 |
|---|---|---|---|
| 全店 | 3.59 | **3.84** | **3.58** |
| 本当の平均が上位2割の店 | 4.16 | 4.52 | 4.14 |
| 本当の平均が下位2割の店 | 3.03 | 2.99 | 3.03 |

- 口コミの平均は、来た人全員の平均より平均で0.25高かった。0.2以上ずれた店は75%
- 書かなかった人（来た人の大多数）の平均は、来た人全員の平均とほぼ同じで（どの店でも差は0.04以内）、口コミの平均より平均で0.26低かった。ただし、書いたのは来た人の4.6%だけなので、「書かなかった人≒来た人全員」になるのは、この置き方からほぼ決まることです。分かったことの中身は「口コミの平均が来た人全員からどれだけずれるか」です
- ずれは上位の店ほど大きく上向きで（4.16が4.52に）、下位の店ではわずかに下向きだった（3.03が2.99に）。口コミの平均は、店どうしの差をおおよそ**1.35倍**に広げて見せた。1.35は直線で当てはめた傾きで、実際の関係はまっすぐではなく、下位の店ではほぼずれず、上位の店ほど大きく上にずれるS字に近い形（図 `a803_scatter.png`）
- 店の並び順はほとんど変わらなかった（来た人全員の平均と口コミの平均の順位相関は0.989）

### 確かめ：だれが書くかの偏りを変える（店を作り直して20回の平均）
| 書く人の偏り | 口コミの平均−来た人全員の平均（平均） | ずれの大きさ（絶対値の平均） | 0.2以上ずれた店 | 店どうしの差の広がり（傾き） | 順位相関 | ずれ：上位2割の店 | ずれ：下位2割の店 |
|---|---|---|---|---|---|---|---|
| 両端ほど書く（基本） | +0.25 | 0.28 | 72% | 1.34倍 | 0.986 | +0.36 | −0.03 |
| 満足した人ほど書く | +0.38 | 0.38 | 98% | 0.94倍 | 0.982 | +0.31 | +0.38 |
| 不満な人ほど書く | −0.26 | 0.26 | 70% | 1.22倍 | 0.983 | −0.13 | −0.37 |
| だれでも同じ（偏りなし） | 0.00 | 0.06 | 0% | 1.00倍 | 0.983 | 0.00 | 0.00 |

- どの店も同じ偏り方なら、平均はずれても、並び順はほとんど変わらなかった
- 「不満な人ほど書く」でも傾きが1を超えたのは、下位の店のずれ（−0.37）が上位の店のずれ（−0.13）より大きく、下位の店がより下に見えたため。「満足した人ほど書く」で1を下回ったのは、下位の店のずれ（+0.38）が上位の店（+0.31）より大きかったため。書く確率の高い星の人が、その店の来た人の中で少数派のときほど、口コミの平均は大きく動く、と読んでいます（推測）

### 店ごとに書かれ方が違う場合（3割の店は全員に声をかける、20回の平均）
| | 値 |
|---|---|
| 来た人全員の平均と口コミの平均の順位相関 | 0.94 |
| 本当の平均が上位4分の1の店のうち、全員に声をかける店の順位の動き | **72.15位下がる** |
| 同じく、声をかけない店の順位の動き | 12.23位上がる |

- 全員に声をかける店は、口コミの平均が来た人全員の平均に近くなる。そのぶん、両端ほど書かれる店より低く見え、本当は上位の店でも400軒中で平均72位ほど下に並んだ

## 動かし方
```
pip install -r requirements.txt
cd src && python a803_who_writes.py
```
数秒で終わります。`data/shops.csv`・`data/write_rates.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダに `src/` と `requirements.txt` だけを写して流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp）。所要は5秒以内

## データ
- `data/shops.csv`：架空の店400軒（shop_id・visit1〜visit5（来た人の星ごとの人数）・post1〜post5（口コミを書いた人の星ごとの人数））
- `data/write_rates.csv`：星ごとの口コミを書く確率（4つの置き方）

## 注意（言えないこと）
- 架空のデータです。来た人の星の分布、星ごとに書く確率は作成者が置いたもので、結果はこれで決まります。確かめのとおり、書く確率の置き方で、ずれは上向きにも下向きにもなります
- 実際に、星ごとに書く確率がどれくらいかは、ここでは分かりません。口コミだけから書かなかった人の満足度を当てることはできず、書く確率を別の方法（来た人全員への聞き取りなど）で知る必要があります
- 「書かなかった人」は、来た人のうち書かなかった人です。来なかった人、ほかの店を選んだ人は含みません
- 口コミの件数の少なさによる振れ（801）、星の分布の形（802）、サクラの投稿（804）は、ここでは扱っていません
- 実際の口コミサイトの数字を表すものではありません
