# F130 介護の認定率の地域差は、高齢化だけで説明できるか？

要介護（要支援）認定率は保険者（市区町村や広域連合）によって違います。高齢者の中でも年齢が高い人が多い地域ほど認定率が高くなるのは当然なので、その分を差し引いたあと、どれだけの差が残るかを確かめました。

## 問い
- 保険者ごとの認定率のばらつきのうち、年齢構成（高齢化の進み方）で説明できるのはどのくらいか
- 小さい保険者の「ぶれ」を除くと、本当の差はどのくらいの幅か
- 残る差は、都道府県の間の差か、同じ県の中の差か

## データ
- 厚生労働省「介護保険事業状況報告（年報）」令和2〜6年度（2020〜2024年度）、e-Stat
  - 第2表 保険者別 第1号被保険者数（65〜74歳・75〜84歳・85歳以上、年度末）
  - 第4-1-1表 保険者別 要介護（要支援）認定者数（第1号被保険者、5歳刻みの年齢 × 要介護度、年度末）
- 2024年度は1,573保険者。取得方法と statInfId は `src/01_取得.md`。
- 分母は同じ報告の第1号被保険者数です（住民基本台帳人口は使っていません）。第2号被保険者（40〜64歳）の認定者は含めていません。

## 手法
1. **年齢調整（間接法）**：全国の年齢別認定率（3つの帯）を各保険者の被保険者数に掛けて「見込みの認定者数 E」を出し、実際の認定者数 O との比 O/E を求めました。直接法の年齢調整率とも比べました（相関 0.997）。
2. **階層ベイズの縮小**：O ~ Poisson(E·θ)、log θ = μ + 都道府県の効果 + 保険者の効果（どちらも正規分布）。PyMC（NUTS、4チェーン×1,500）。同じモデルを、年齢を調整しない見込み（全国の認定率 × 被保険者数）でも当てはめ、log θ の分散（＝偶然のぶれを除いた本当のばらつき）がどれだけ小さくなったかを「年齢で説明できた割合」としました。
3. **ファンネルプロット**：O/E と、ポアソン分布の偶然のぶれの範囲（95%・99.8%）を比べました。
- 乱数の種は 130 に固定しています。収束の指標 R̂ は全てのモデルで 1.01 以下でした。

## 結果（2024年度）
- 全国の認定率は 19.7%。年齢別では 65〜74歳 4.3%、75〜84歳 17.5%、85歳以上 59.5% で、85歳以上の割合は保険者によって 15%〜27%（5%点〜95%点）と違います。
- 粗い認定率は、保険者の5%点〜95%点で 14.5%〜23.4%。年齢構成から見込んだ認定率で説明できたのは、粗い認定率のばらつきの 22%（決定係数、被保険者数で重みづけ）でした。
- 99.8%の範囲を外れる保険者が 58% あり、差の多くは偶然のぶれでは説明できません。
- 階層ベイズで見ると、log θ の標準偏差は年齢を調整しない場合の 0.141 から、年齢調整後は 0.118 に下がりました。分散で見ると **30%（95%区間 10〜47%）** が年齢構成で説明でき、**約7割は残りました**。
- 年齢調整後の差のうち、都道府県の間の差は 43%、同じ県の中の保険者の差が 57% でした。
- 縮めた比（θ）の5%点〜95%点は 0.76〜1.10。±20%を超える保険者は、生の比で 14%、縮めた比で 11% でした。被保険者数が少ない20%の保険者では 26% → 17% と大きく縮み、多い20%では 4% のまま変わりません。
- 被保険者数が多い保険者ほど、年齢調整後の比が高めでした（規模の5分位で 0.90 → 1.03、相関 0.29）。理由はこのデータでは分かりません。

## 頑健性
| 確かめたこと | 年齢で説明できた割合（95%区間） |
|---|---|
| 本推定（2024年度、3つの帯、全ての要介護度） | 30%（10〜47%） |
| 年齢の帯を2つ（65〜74歳／75歳以上） | 22%（1〜40%） |
| 要介護2以上だけ | 29%（14〜42%） |
| 要支援1・2だけ | 4%（−24〜27%） |
| 被保険者3,000人未満の保険者を除く | 30%（8〜47%） |
| ばらつきの事前分布を狭く（HalfNormal 0.1）／広く（2） | 31%／31% |
| 2020〜2023年度 | 33〜35% |
| 経験ベイズ（ガンマ・ポアソン、モーメント法） | 20%（階層ベイズとの θ の相関 0.99） |
| 都道府県単位（47県、単純な分散比） | 20% |

- 2020年度と2024年度の縮めた比の相関は 0.93（生の比では 0.90）で、差は年によってあまり変わりません。
- 帯を細かくすると説明できる割合が増えるので（2つ→3つで 22%→30%）、さらに細かい年齢（5歳刻み）の分母があれば、もう少し大きくなる可能性があります（推測）。

## 言えないこと
- 残る差が「認定の仕方の違い」なのか「実際の健康状態の違い」なのかは、このデータでは区別できません。
- 性別、世帯の状況（一人暮らし）、所得、介護サービスの整い方などは調整していません。
- 被保険者数の年齢の帯が3つしかないので、85歳以上の中の年齢の違いは調整できていません。
- 特定の保険者・都道府県が多い・少ない、良い・悪いを評価するものではありません。保険者名と都道府県名は図や本文に出していません（結果の CSV には含みます）。
