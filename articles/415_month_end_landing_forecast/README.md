# 415 月の途中の実績から、月末の着地をどう見込むか。4つの方法の外れ方（実務の型）

架空の日次売上80本（小売型40本・法人向け型40本、2022〜2025年）で、月の5日・10日・20日時点の実績から月の合計を見込む方法を4つ比べたフォルダです。341（締めたあとの確定）・390（予算の月割り）とは別で、月の途中の見込みに絞ります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A415 | 月の途中の実績から着地を見込むとき、方法でどれだけ外れ方が違うか | ①日割り、②前年同月の進み方、③曜日の型（直前の8週間）、④直近12か月の進み方の平均。2023〜2025年の36か月×80本で、見込みと実績の差を数える | `src/a415_landing.py`、`src/01_landing_tsql.sql`（①②の T-SQL 版、未検証） |

## 主な結果
誤差は（見込み÷実績−1）の絶対値の中央値（%）

| 型 | 時点 | ①日割り | ②前年同月 | ③曜日の型 | ④12か月平均 |
|---|---|---|---|---|---|
| 小売型 | 5日 | 5.0 | 6.0 | 3.1 | 5.8 |
| 小売型 | 10日 | 3.1 | 3.3 | 2.2 | 3.4 |
| 小売型 | 20日 | 1.7 | 1.6 | 1.7 | 1.7 |
| 法人向け型 | 5日 | 32.2 | 15.3 | 27.9 | 14.9 |
| 法人向け型 | 10日 | 20.1 | 8.8 | 18.5 | 10.0 |
| 法人向け型 | 20日 | 14.4 | 3.4 | 14.1 | 4.5 |

- **偏り（誤差の平均）**：法人向け型の①は5日−30.1%、10日−19.4%、20日−14.5%。③は−27.9%、−18.5%、−14.1%。②は+4.3%、+2.0%、+0.2%。小売型の①は−1.5〜−1.6%
- **祝日の多い月**（平日の祝日が2日以上、36か月のうち12か月。10日時点）：法人向け型は①18.3%→25.1%、②8.1%→10.1%、③18.5%→18.6%、④8.5%→13.8%。小売型は①3.4%→2.5%、②3.5%→3.1%、③2.2%→2.2%、④3.7%→3.0%

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した
- DuckDB の SQL で出した①と②（10日時点）の見込みが、Python の計算と80本×36か月すべてで一致する（コード内の assert）

## データ
- `data/daily_sales.csv`：架空の日次売上80本×4年（系列・型・日付・売上）。作成者が乱数で作成（seed 415）
- `data/holidays_2022_2025.csv`：内閣府「国民の祝日について」の一覧から、2022〜2025年を抜き出したもの

## 注意（言えないこと）
- 架空のデータ。誤差の大きさは、月末に集まる強さ（1.6倍）や日ごとの揺れ（10%）の置き方で決まる
- 月の中の波は毎月同じ形にした。形が変わる月（締め日の変更、大口の取引）では②や④も外れる
- どの方法がよいかは売上の型で変わる。1つの方法を勧めるものではない
- ③は直前の8週間だけで曜日の型を作った。月の中の波を足した形や、機械学習の予測とは比べていない
- 見込みの幅は出していない
- T-SQL 版は SQL Server 本体では動かしていない（未検証）
