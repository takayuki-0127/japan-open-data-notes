# 195 病院の数は、どの病床規模から減っているか：医療施設調査

厚生労働省「医療施設調査」の病床の規模別病院数（1987〜2025年、各年10月1日）を並べ、病院の数がどの規模で減ってきたのかを、規模別の構成と増減で見たフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A195 | 病院の数は、どの病床規模から減っているか | 病床の規模別（14区分・5グループ）の病院数の推移、期間別の増減と総数の減少に占める割合、一般病院・精神科病院別の指数（2002年＝100） | `src/a195_bed_size.py` |

## 主な結果
- 病院の数は1990年の10,096が最多で、2025年は8,001（−2,095、−20.8%）
- 1990→2025年の減少のうち、20〜99床の病院が−1,670で約8割。20〜29床は507→146（−71.2%）、50〜99床は2,524→1,953（−571）
- 増えたのは150〜199床だけで、1,026→1,377（+351）。100〜199床のグループは2,634→2,769
- 200〜299床も1,361→1,006（−355）と大きく減った
- 2014→2025年の減少（−492）では、50〜99床が−194（39%）、200〜299床が−110（22%）、300〜599床が計−147。減少が中規模・大規模の病院にも広がっている。20〜29床は117→146と増えた
- 一般病院では2002年を100とすると、2025年は20〜99床77、200〜399床84、400〜599床91、600床以上77。100〜199床は100で横ばい。精神科病院は100〜199床が389→459と増え、300床以上が減った

```bash
pip install -r requirements.txt

```

## データ
| ファイル | 中身 |
|---|---|
| data/hospitals_by_bed_size.csv | 年、種類（総数・精神科病院・一般病院）、病床の規模（14区分）、病院数。1987〜1999年は総数のみ |

- 令和7年医療施設（動態）調査 全国編 第6表「病院数・構成割合，年次・病床の規模・精神科病院－一般病院（再掲）別」（e-Stat statInfId 000040501193、2002〜2025年）
- 平成19年医療施設（動態）調査 上巻 第6表（statInfId 000002027757、1987〜2007年）。2002・2005年の値は両方の表で一致
- 「-」（該当なし）は0とした

## 注意
- 病床規模は許可病床数による区分で、病院が増床・減床して区分を移った分と、開設・廃止の分は、この表では分けられない
- 2002〜2023年は3年ごと、その後は毎年の値（1987〜2002年も3年ごと）
- 病床の種類（一般・療養など）は区別していない
- 減った理由（再編・統合、診療所への転換など）や、150〜199床だけが増えた理由は、このデータでは分からない
