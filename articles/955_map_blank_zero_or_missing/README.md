# 955 地図の上の「空白」は、ゼロなのかデータがないのか？（地図と場所）

区域ごとの件数を色で塗った地図では、色のない「空白」の区域が出ます。空白は「0件」と読みたくなりますが、本当に0件だった区域のほかに、件数が少ないので出さない決まりで空白にした区域や、そもそもデータを取っていない区域もまざります。**ここでは、作成者が乱数で作った架空の町（20×20の区域）の架空の店の配達の注文を、「3件未満は出さない」「東の3列は配達の対象外」と置いて地図にし、空白の中身が何か、空白を0件と読むか除くかで区域あたりの平均がどれだけずれるか、本当に0件だった区域が次の月にも0件かを、200の町で数えました。**

区域・町・店はすべて架空のもので、実在の地図や地名は使っていません。区域を良い順・悪い順に並べることはしていません。

不良が0件の月を「不良率0%」と言えるかは関連する記事 916、人数の少ない区域の率が地図の端で極端な色になることは 948、色分けの区切り方で地図の印象が変わることは 949 で扱っています。この記事は、地図の空白が何を表しているかと、その読み方で数字がどれだけずれるかに絞ります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A955 | 地図の空白のうち、本当に0件だった区域はどれだけか。空白を0件と読むか、空白を除くかで、区域あたりの平均はどれだけずれるか。本当に0件だった区域は、次の月にも0件か | 架空の町を20×20の区域（400区域）に分けた。区域ごとの本当の注文の起きやすさ（1か月の平均件数）は、平均4件・対数の標準偏差0.9の対数正規分布。区域の1か月の注文の件数は、その平均のポアソン分布で引いた（2か月分）。地図は次の決まりで塗る：①東の3列（60区域、15%）は配達の対象外で、データがない、②配達する区域で3件未満（1〜2件）は出さない、③0件の区域も色が付かない。①〜③はどれも地図では空白になる。区域あたりの平均は「空白を0件として400区域で割る」「空白を0件として配達する340区域で割る」「空白を除いて地図に出た区域で割る」の3つの読み方と、本当の値（配達する区域の本当の件数の平均）を比べた。町を200回作り直した。本当に0件になる区域の割合の式の値は、置いた起きやすさ λ から e^(−λ) を足して出した。確かめとして、平均件数（2・4・8件）×出さない線（なし・3件未満・5件未満）×対象外の列（0・3・6列）の27通りと、起きやすさの散らばり（対数の標準偏差0.5・1.3）を、各50の町で数えた。seed 955 | `src/a955_blank_zero_or_missing.py` |

## 主な結果

### 空白の中身（基本の置き方、200の町の平均）
| | 結果 |
|---|---|
| 空白の区域の数 | 224.6区域（400区域の56.2%） |
| うち本当に0件 | **22.5%**（町ごとの10〜90%：19.4〜25.8%、式の値22.4%） |
| うち1〜2件で出さない決まり | 50.8% |
| うち配達の対象外（データなし） | 26.8% |
| 配達する区域のうち、本当に0件だった割合 | 14.9%（式の値14.85%） |

- 地図の空白を「注文がなかった区域」と読むと、400区域の56.2%になる。配達する区域で本当に0件だったのは14.9%だった
- 空白のうち本当に0件だったのは22.5%で、半分（50.8%）は1〜2件の注文がある区域、26.8%はデータを取っていない区域だった
- 本当に0件の割合は、置いた起きやすさとポアソン分布の式の値（22.4%・14.85%）とほぼ同じ。**ここは置いた前提の写し**で、新しく数えたのは、空白を読むときの平均のずれと次の月の動き
- 例の町1つでは、空白230区域のうち、本当に0件が45区域、1〜2件で出さないが125区域、対象外が60区域だった

### 区域あたりの平均件数の読み方（200の町の平均）
| 読み方 | 区域あたりの件数 | 本当の値とのずれ |
|---|---|---|
| 空白を0件として、400区域で割る | 2.99件 | **−25.5%** |
| 空白を0件として、配達する340区域で割る | 3.52件 | −12.3% |
| 空白を除いて、地図に出た区域で割る | 6.82件 | **+70.4%** |
| 本当の値（配達する区域の本当の件数の平均） | 4.01件 | — |
| （参考）本当の起きやすさ（対象外も入れた400区域） | 3.99件 | — |

- 空白を0件と読むと平均は25.5%低く、空白を除くと70.4%高く出た。どちらの読み方も本当の値から外れ、向きは逆だった
- 空白を0件と読むときの低さの半分ほど（−12.3%）は、出さない決まりで消えた1〜2件の分、残りは対象外の区域を0件と数えた分だった
- 対象外の区域にも、町全体の起きやすさの14.8%があると置いた。地図の空白から「対象外の区域には注文が来ない」とは言えない

### 本当に0件だった区域の、次の月（200の町の平均）
| | 結果 |
|---|---|
| 次の月に1件以上の注文があった | **63.0%**（町ごとの10〜90%：54.4〜71.5%） |
| 次の月に3件以上（地図に出る件数）あった | 14.8% |
| 本当に0件だった区域のうち、起きやすさが月0.5件未満だった | 14.5% |
| 配達する区域で空白だった区域のうち、次の月に地図に出た | 26.7% |

- 本当に0件だった区域でも、63.0%は次の月に注文があった。1か月の0件は、多くが「たまたま0件」で、起きやすさが月0.5件未満の区域は14.5%だった

### 確かめ：置き方を変えて（29通り、各50の町）
| 平均件数 | 出さない線 | 対象外 | 空白のうち本当に0件 | 空白を0件（400区域）のずれ | 空白を除いたずれ |
|---|---|---|---|---|---|
| 2件 | 3件未満 | 3列 | 33.4% | −39.8% | +156.4% |
| 4件 | なし | 3列 | 45.2% | −15.0% | +17.2% |
| **4件** | **3件未満** | **3列** | **22.5%** | **−25.5%** | **+71.0%** |
| 4件 | 5件未満 | 3列 | 17.0% | −41.1% | +133.3% |
| 4件 | 3件未満 | 0列 | 30.6% | −12.1% | +69.7% |
| 4件 | 3件未満 | 6列 | 16.0% | −38.6% | +68.9% |
| 8件 | 3件未満 | 3列 | 12.6% | −18.2% | +28.3% |
| 8件 | 5件未満 | 6列 | 6.5% | −38.3% | +56.7% |

（表は27通りのうちの一部。全部は `results/robustness.csv`。太字は基本の置き方を各50の町で数え直した行で、ずれは200の町の値から少し動く）

- 出さない決まりがあり対象外の列もある12通りで、空白のうち本当に0件の割合は6.5〜33.4%だった。起きやすさの散らばり（対数の標準偏差0.5・1.3、ほかは基本）を変えた2通りでは10.3%と34.9%だった。件数が多いほど、出さない線が高いほど、対象外が多いほど小さくなった
- 29通りすべてで、空白を0件と読むと平均は本当の値以下（0〜−70.8%）、空白を除くと本当の値より高かった（+5.6〜+281.7%）。出さない決まりも対象外もないときだけ、空白を0件と読むずれは0になった
- 本当に0件だった区域が次の月に1件以上になった割合は、29通りで44.0〜86.6%だった

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の6ファイルがバイト単位で一致した（cmp、2回流して2回とも一致、約2〜4秒）
- 図3枚を開き、日本語・重なり・軸を確かめた
- 空白のうち本当に0件の割合（22.5%）と、配達する区域で0件の割合（14.9%）が、置いた起きやすさからの式の値（22.4%・14.85%）とほぼ同じことを確かめた。作りが置いたとおりに動いていることの確かめで、空白の中身の割合そのものは置いた前提の写しである
- 出さない決まりも対象外もない置き方で、空白がすべて本当に0件になり、空白を0件と読むずれが0になることを確かめた

## 注意（言えないこと）
- 架空のデータです。区域ごとの起きやすさの分布、出さない線、対象外の区域は作成者が置いたもので、結果はこれで決まります。空白のうち本当に0件の割合は、置き方で6.5〜34.9%と動きました。実在の町や店の数字を表すものではありません
- 出さない決まりと対象外は、空白になる理由の例として作成者が置いたものです。実際の地図では、記録の漏れ、住所が読めなかった注文、集計の期間の違いなど、ほかの理由でも空白になります
- 空白を0件と読むか除くかのどちらが良いかは、地図を何に使うかで決まり、この記事では言えません。どちらの読み方も本当の値からずれた、ということだけを数えました
- 対象外の区域に配達を広げるべきかどうかは言えません
