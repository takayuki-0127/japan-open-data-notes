# 367 1つの世帯の人数は、100年でどう減ったのか（国勢調査）

国勢調査の時系列データ（世帯人員の人数別の世帯数、1920〜2020年）で、1世帯当たりの人数と、1人・2人・5人以上の世帯の割合を数えたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A367 | 1世帯の人数はいつ4人・3人を下回ったか。何人の世帯がいちばん多かったか。世帯の数が増えた理由は人口か、世帯が小さくなったことか | 人数別の世帯数から割合を計算。一般世帯（1960・1970〜2020年）と普通世帯（1920年〜）を並べる。人で数えた割合、世帯数の増加の分解 | `src/a367_household_size.py` |

## 主な結果
- 1世帯当たりの人数（普通世帯）：1920年4.89人、1930年4.98人、1950年4.97人、1955年4.97人、1960年4.54人
- 1世帯当たりの人数（一般世帯）：1960年4.14人、1970年3.41人、1980年3.22人、1990年2.99人、2000年2.67人、2010年2.42人、2020年2.21人。4人を下回ったのは1970年の調査、3人は1990年、2.5人は2010年
- 5人以上の世帯：普通世帯で1920年51.2%、1955年54.6%。一般世帯で1960年41.9%、1980年20.0%、2005年9.5%、2020年5.5%
- ひとり暮らし（一般世帯）：1960年16.5%（372万世帯）、1990年23.1%、2010年32.4%、2020年38.0%（2,115万世帯）。1人と2人を合わせると2000年に52.7%で半分を超えた
- いちばん多い人数（一般世帯）：1960年は1人（16.5%、4人は16.4%）、1970〜85年は4人（1980年25.3%・907万世帯）、1990年からは1人。普通世帯では1955年は5人、1960〜90年は4人、1995・2000年は2人、2005年から1人
- 1960年のひとり暮らしは、普通世帯では5.3%、一般世帯では16.5%。差は、間借り・下宿・会社の寮などの単身者
- 人で数えると（一般世帯）：ひとり暮らしの人は1960年4.0%→2020年17.2%、5人以上の世帯の人は64.6%→13.4%。3〜4人世帯の人は2020年も44.0%でいちばん多い
- 世帯の数は1960→2020年に2.47倍（2,254万→5,570万）。世帯で暮らす人は1.32倍、1世帯の人数は0.53倍。対数で分けると、増えた分の30.5%が人の増加、69.5%が世帯が小さくなった分。1世帯の人数が1960年のままなら2020年の世帯は2,971万
- 2000→2020年は、世帯で暮らす人が0.987倍に減ったのに、世帯は1.19倍に増えた

## 確かめたこと
- 人数別の世帯数を足すと、総数とすべての年で一致した
- 世帯人員÷世帯数は、表にある「1世帯当たり人員」と小数第5位まで一致した
- 普通世帯と一般世帯の両方がある年（1960・1970〜2020年）で並べると、2020年は2.23人と2.21人で、差は小さくなっている
- 空のフォルダで流し直し、data・results・figures が一致した

## データ
- `data/raw/kokusei_000001086172.xlsx`：e-Stat 国勢調査 時系列データ 世帯「第2表 世帯人員の人数別一般世帯数－全国（昭和35年，45年〜令和2年）」（statInfId=000001086172、参考として普通世帯の1920年〜を含む。2026-11-12 取得）
- `data/household_size_1920_2020.csv`：世帯の種類・年ごとの人数別世帯数と割合

## 注意（言えないこと）
- 1955年までは普通世帯、1960年からは一般世帯で見ています。普通世帯は、間借り・下宿・寮のひとり暮らしを含みません。2つの数字はそのままつながりません
- 1940年は人数別の集計が表になく、1945年は調査がありません
- 世帯の人数が減った理由（子どもの数、親との同居、未婚、高齢のひとり暮らし）は、この表からは分けられません
- 施設などで暮らす人（施設等の世帯）は入っていません
- 10人以上の世帯の人数は、世帯人員の合計から逆算した値です
