# F372 PLAN（事前の計画）：「緑茶からコーヒーへ」は、年齢の違いと世代の違いのどちらで説明できるか？

作成：2026-11-16 14:20（データを取得し、表の形を確かめたあと、同じ世代を追う計算や時系列の集計をする前に書いた）

## 問い
家庭で買う緑茶（茶葉）は減り、コーヒーは広く飲まれるようになったと言われます。年齢の高い世帯ほど緑茶を多く買うので、「年を取ると緑茶を飲むようになる（年齢の違い）」のか、「緑茶を多く飲む世代が上にいて、若い世代は年を取っても緑茶を飲まない（世代の違い）」のかで、これからの見通しが変わります。

知りたいこと：同じ生まれの世代を10年追うと、緑茶とコーヒーの購入量はどう変わるのか。同じ年齢の世帯の10年前と今の差、同じ年の10歳上との差と比べて、どちらに近いのか。茶葉からペットボトルなどの茶飲料への置き換わりは、年齢でどう違うのか。

知りたい人：飲料・食品の商品企画や販売の担当、家計の統計を読む人。

既存の看板記事との違い：jodn の 136 は茶の栽培面積と荒茶の生産で、家計の購入や年齢・世代は扱っていない。F286 は品目の価格の対応にコーヒーが出てくるだけ。existing_F_titles.txt と jodn の README を「緑茶」「コーヒー」「茶」で検索して、同じ問いの記事はなかった。

## データ
- 総務省「家計調査」家計収支編 二人以上の世帯 年報の品目別表（食料「調理食品」～「飲料」）2013・2014・2015・2023・2024年。各年の世帯主の年齢階級別（〜29歳、30〜39歳、…、70歳以上）の1世帯当たり年間の支出金額と購入数量、2000〜2024年の時系列。
- 同 2025年 第4-6表 世帯主の年齢階級別1世帯当たり年間の支出金額，購入数量及び平均価格（二人以上の世帯）。
- 品目：緑茶（茶葉、金額と数量100g）、コーヒー（豆・粉・インスタント、金額と数量100g）、茶飲料（金額のみ）、コーヒー飲料（金額のみ）。

## 取得前に見たもの（開示）
- 表の形を確かめるときに、2013年と2024年の年齢階級別の飲料の行（緑茶・コーヒーの金額・数量、茶飲料・コーヒー飲料の金額など）と、2025年の平均・29歳以下・70歳以上の茶・コーヒーの行の値を目にした（例：2024年の緑茶の金額は29歳以下540円、70歳以上5,409円）。同じ年の年齢による差の大きさはおおよそ知っている。同じ世代を10年追った値、同じ年齢の10年の変化、時系列の伸びは計算していない。

## 仮説と「外れ」の基準
- H1：緑茶（数量）で、同じ世代を10年追ったときの変化（4つの年齢区間の平均、対数の差）は、同じ年の10歳上との差（横断の差）の半分に満たない。半分以上なら外れ。
- H2：コーヒー（数量）の、同じ年齢で見た2015→2025年の変化は、60〜69歳と70歳以上の両方でプラス。どちらかがマイナスなら外れ。
- H3：2025年の「緑茶＋茶飲料」の金額に占める茶飲料の割合は、29歳以下で80%以上、70歳以上で50%未満。どちらかが満たされなければ外れ。
- H4：全国平均で、緑茶の購入数量は2000年→2025年に30%以上減り、コーヒーの購入数量の変化は±15%以内。どちらかが満たされなければ外れ。

## 手法
- 10年の間隔の組（2015→2025、2014→2024、2013→2023）で、年齢階級を10歳ずらして同じ生まれの世代を追う（〜29歳→30〜39歳、30〜39歳→40〜49歳、40〜49歳→50〜59歳、50〜59歳→60〜69歳。60〜69歳→70歳以上は上が開いているので参考）。
- 3つの差を対数で計算する：(A) 同じ世代の10年の変化、(B) 同じ年の10歳上との差（横断の差）、(C) 同じ年齢の10年の変化。A＝B（はじめの年）＋C（10歳上の年齢）がなりたつ。
- 年齢・時代・世代は、1つを決めると残りが決まる（識別の制約）ので、「時代の動きがない」と置いたときの読み方と、「同じ年齢の変化はすべて時代の動き」と置いたときの読み方の両方を書く。
- 茶飲料の割合は金額で計算する（茶飲料に数量がないため）。

## 頑健性（3つ以上）
1. 10年の組を 2014→2024、2013→2023 に替えて H1・H2 を見る。
2. 数量の代わりに金額で H1 を見る（価格の動きが入る）。
3. H4 の起点を2002年・2005年に替える。
4. 2018年の家計簿の改正をまたがない比較として、2013→2017 などの短い期間ではなく、年齢別の傾きの形（30代を1とした比）が変わったかを見る。

## 問い直し（予定）
結果を見てから1つ足す。候補：コーヒーと茶を合わせた「家で飲む飲み物」全体の支出は、世代でどう違うのか（置き換わりか、全体の減りか）。

## 言えないこと（予定）
- 世帯主の年齢で分けた世帯の購入で、1人ひとりの飲む量ではない。世帯の人数の違いも入る。
- 同じ生まれの世代を追うといっても、同じ世帯を追ったものではない。
- 年齢・時代・世代の3つは、仮定なしには分けられない。
- 外で飲む分（喫茶代、自動販売機、職場）は品目によって入り方が違う。
- 2018年1月の家計簿の改正で、品目によっては前後の比較に注意が要る。
