# 774 達成率を四捨五入してから「100%以上」を数えると、何店が「達成」に入ってしまうのか（実務の型）

達成率を「99.6%→100%」のように四捨五入して表示し、その表示の値で「100%以上の店」を数えると、目標に届いていない店も「達成」に入ります。**ここでは、作成者が乱数で作った架空の200店×12か月の目標と実績で、達成店を「実績≧目標」で数える場合と、達成率を整数の%・小数1桁の%に丸めてから数える場合を比べました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A774 | 丸めてから判定すると、達成店は何店増えるか | 架空の200店×12か月。実績＝目標×(1＋N(0, 0.06))。達成の判定を「実績≧目標」「ROUND(達成率, 0)≧100」「ROUND(達成率, 1)≧100」の3通りで、DuckDB（1スレッド）と Python で数えて一致を確認。seed 774 | `src/a774_achieve.py`、`src/02_achieve_duckdb.sql`、`src/01_achieve_tsql.sql` |

## 主な結果

| 判定のしかた | 達成店（月平均、200店のうち） | 丸める前より多い店（月平均） |
|---|---|---|
| 実績≧目標（丸める前） | 102.6店 | — |
| 小数1桁に丸めてから | 103.3店 | 0.7店（最大2店） |
| 整数の%に丸めてから | **109.3店** | **6.7店（3〜9店）** |

- 整数の%に丸めてから数えると、毎月3〜9店（平均6.7店）が「達成」に増えた。12か月で延べ80件
- この80件は、本当の達成率が99.50〜99.99%で、目標に平均2.8万円、最大7.2万円届いていなかった
- 小数1桁に丸めると、増えたのは月平均0.7店だった。丸めの桁が細かいほど、境目に入る店は減る


- 空のフォルダで流し直し、results・figures・data が一致した
- 3通りの判定で、月ごとの達成店の数が DuckDB と Python で一致すること（assert）

## データ
- `data/results.csv`：架空の店の目標と実績（month・store_id・target・actual）

## 注意（言えないこと）
- 架空のデータです。達成率のばらつき（標準偏差6ポイント）は作成者が置いたもので、境目に入る店の数はこれで決まります
- 四捨五入は「0.5を切り上げ」で計算しました。四捨五入のしかた（偶数への丸めなど）が違うと、境目の数が少し変わります
- T-SQL 版は未検証です
- 達成の判定の決め方（どの数字を「達成」とするか）は、社内の決まりによります。ここでは、表示の値で判定すると数がずれることだけを示しています
