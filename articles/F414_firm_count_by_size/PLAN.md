# F414 事前の計画（PLAN）

作成：2026-11-18 11:05（JST）。結果を集計する前に書いた。

## 問い
「中小企業の数が減っている」とよく言われます。中小企業庁は、経済センサスをもとに、中小企業の数が2016年の357.8万者から2021年の336.5万者に減ったと公表しています（2023年12月）。では、減ったのはどの規模の、どんな形の企業なのか。個人で営む企業（個人経営）と会社で違うのか。どの産業の分が大きいのか。

## 知りたい人
「中小企業が減った」という見出しを読んで、取引先や地域の企業の数の変化を数字で確かめたい人。減ったことの良し悪しや、政策の評価は扱わない。

## データ
- 総務省・経済産業省「経済センサス」の企業等に関する集計、全国の表「企業産業（中分類）、企業常用雇用者規模（11区分）、経営組織（5区分）別 企業等数」
  - 2012年（平成24年 活動調査、第2表）、2014年（平成26年 基礎調査、第1表）、2016年（平成28年 活動調査、第1表）、2021年（令和3年 活動調査、第1表）
  - 2024年（令和6年 基礎調査、第1表）は「雇用者のいない個人経営の企業を除く」表なので、会社企業だけを比べる参考に使う
- 企業等＝会社企業、会社以外の法人、個人経営の企業。規模は常用雇用者（期間を定めず雇われている人など）の数で分ける（0〜4人、5〜9人、…、5,000人以上の11区分）
- 規模は従業者ではなく常用雇用者の数なので、中小企業庁の「中小企業」の定義（資本金と従業員数）とは同じではない

### 取得前に見たもの（下見）
- 各年のファイルの見出しと最初の20行ほど。全産業・経営組織の総数の行の企業等数（2012年 4,128,215、2014年 4,098,284、2016年 3,856,457、2021年 3,684,049、2024年 2,549,827）と、2012・2016・2021・2024年の全産業・総数の規模別の行（0〜4人 2012年 3,136,695 → 2016年 2,853,123 など）が目に入った
- 経営組織別・産業別の値はまだ見ていない

## 手法
- 本線は活動調査どうしの 2012年→2021年。企業等数の増減を、経営組織（個人経営・会社企業・会社以外の法人）×規模（11区分を5つにまとめる：0〜4人、5〜19人、20〜99人、100〜299人、300人以上）に分けて、どこが何割を占めたかを出す
- 産業（大分類）別の増減と、個人経営の減少への寄与
- 2014年（基礎調査）は途中の点として並べる（調査の違いがあるため、増減の主な計算には使わない）
- 会社企業は 2021年→2024年も参考で比べる
- 地域は使わない

## 仮説（外れの基準つき）
- H1：2012→2021年の企業等数の減少のうち、80%以上は個人経営の減少。外れ：80%未満
- H2：規模別では、0〜4人の区分の減少が、全体の減少の90%以上。外れ：90%未満
- H3：会社企業の数の変化は ±5% 以内で、個人経営は25%以上減った。外れ：どちらかが満たされない
- H4：個人経営の減少のうち、卸売業・小売業、宿泊業・飲食サービス業、建設業の3つの産業で50%以上。外れ：50%未満

## 頑健性（3つ以上）
1. 期間を分ける：2012→2016年と 2016→2021年で、同じ形か
2. 会社以外の法人を除く（中小企業庁の数え方に近づける）
3. 始まりを 2014年（基礎調査）にする
4. 会社企業だけ 2021→2024年も見る
5. 規模のまとめ方を変える（0〜4人と5〜9人を合わせる など）

## 言えないこと（予想）
- 規模の区分ごとの数の増減は「純増減」。廃業・開業・規模の移り（成長して上の区分へ移る）を分けられない
- 調査の方法（活動調査・基礎調査）や、行政の記録を使った名簿の整え方の違いで、年の間に段差がありうる
- 常用雇用者の規模で、中小企業の法律上の定義とは違う
- 減ったことの良し悪しや理由（後継ぎ・人手など）は、このデータでは確かめられない
