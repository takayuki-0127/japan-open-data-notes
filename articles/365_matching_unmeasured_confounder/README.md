# 365 似た相手を選んで比べる方法は、測っていない違いがあるとどこまで外れるのか

施策を受けた人と受けていない人を比べるとき、似た相手を選んで比べる方法（傾向スコアのマッチング）がよく使われます。測っていない違いが残っていると、この方法がどれだけ外れるかを、本当の効果（+500円）が分かっている架空の顧客で測ったフォルダです。F14・F100（傾向スコアを使った記事）とは違い、正解の分かるデータで外れ方を測ります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A365 | 測っていない要因の強さごとに、単純な比べ・回帰・マッチング・重み付けはどれだけ偏るか。測った要因のバランスを見れば気づけるか | 架空の顧客4,000人（クーポンを受け取りやすい人ほど元からよく買う）を200回作り、4つの方法で効果を見積もる | `src/a365_matching_bias.py` |

## データの作り方（架空）
- 測っている要因：過去の購入額、年齢、会員ランク。測っていない要因：買う気の強さ
- クーポンを受け取るかどうかは、4つの要因で決まる。購入額も4つの要因で決まり、クーポンの本当の効果は全員+500円
- 測っていない要因の「強さ」0〜1.5：受け取りやすさと購入額の両方に効く大きさ（1.0で、過去の購入額と同じくらいの効き方）
- 乱数の種は365。実在の顧客・会社の数字ではありません

## 比べた4つの方法
単純な比べ（受け取った人の平均−受け取っていない人の平均）／回帰で調整／傾向スコアのマッチング（測った3つで作ったスコアがいちばん近い相手と1対1、幅の制限あり）／傾向スコアの重み付け

## 主な結果
### 見積もった効果（本当は+500円。200回の平均）
| 測っていない要因の強さ | 単純な比べ | 回帰で調整 | マッチング | 重み付け |
|---|---|---|---|---|
| 0（なし） | +1,170円 | +499円 | +501円 | +498円 |
| 0.25 | +1,209円 | +549円 | +547円 | +551円 |
| 0.5 | +1,305円 | +688円 | +685円 | +689円 |
| 1.0 | +1,683円 | +1,172円 | +1,173円 | +1,172円 |
| 1.5 | +2,189円 | +1,785円 | +1,778円 | +1,784円 |

- **測った要因だけで決まるなら、回帰もマッチングも重み付けも、ほぼ正解を出した**（単純な比べは+1,170円で2.3倍）
- **測っていない要因が効くと、3つの方法は同じだけ外れた**。強さ1.0で+1,172円前後（本当の2.3倍）。方法を変えても、測っていない違いは消えない

### 測った要因のバランスを見れば気づけるか（マッチング）
| 測っていない要因の強さ | 測った3つのバランスが取れた回 | 95%の幅が本当の効果を含んだ回 | マッチング後の「買う気の強さ」の差（標準化） |
|---|---|---|---|
| 0 | 99.5% | 93.5% | 0.00 |
| 0.25 | 98.5% | 86.0% | 0.25 |
| 0.5 | 100% | 5.0% | 0.48 |
| 1.0 | 100% | 0% | 0.90 |
| 1.5 | 100% | 0% | 1.24 |

- **測った3つの要因は、ほぼ毎回きれいにそろった**（標準化した差が3つとも0.1未満）。それでも強さ0.5以上では、95%の幅はほとんど本当の効果を含まなかった
- バランスの表は「測った要因がそろったか」しか教えない

### 測っていない要因が、測っている要因と相関している場合（強さ1.0）
| 過去の購入額との相関 | マッチングの偏り |
|---|---|
| 0 | +672円 |
| 0.3 | +623円 |
| 0.6 | +463円 |
| 0.9 | +153円 |

- **測っている要因と強く相関していれば、その分だけ偏りは減った**。相関0.9で、偏りは相関0のときの約4分の1

### 測っているのに使わなかった場合
- 測っていない要因はなし。過去の購入額をスコアに入れないと、マッチングの偏りは+561円（3つとも入れると−0.3円）

## 動かし方
```
pip install -r requirements.txt
cd src && python a365_matching_bias.py
```
`data/example_customers.csv`、`results/main.json`、`results/bias_by_strength.csv`、`results/bias_by_correlation.csv`、`figures/` の3枚ができます（約15秒）。

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した
- 測っていない要因がないとき、マッチングの95%の幅が本当の効果を含んだのは93.5%（幅の出し方がおおむね合っていることの確認）

## 注意（言えないこと）
- すべて架空のデータです。偏りの大きさは、置いた効き方（係数）で決まります
- 効果は全員同じ+500円にしました。人によって効果が違う場合は試していません
- マッチングは「いちばん近い相手と1対1、同じ相手を何度使ってもよい」の1通りです。幅の出し方は、同じ相手を使った回数を入れた近似です
- 測っていない要因がどれだけ強いかは、データからは分かりません。この記事は「もし強さがこれだけなら、これだけ外れる」という関係を示すだけです
- 施策の効果の測り方について助言するものではありません
