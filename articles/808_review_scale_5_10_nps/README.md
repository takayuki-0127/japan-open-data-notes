# 808 5段階と10段階と「おすすめ度0〜10」で、同じ満足度はどう見えるのか？（口コミと星の数）

満足度の聞き方には、星1〜5の5段階、1〜10の10段階、「この店を人にすすめたいか」を0〜10で聞くおすすめ度などがあります。おすすめ度では、9〜10を付けた人の割合から0〜6を付けた人の割合を引いた数（NPS と呼ばれる数え方）がよく使われます。**ここでは、作成者が乱数で作った架空の店2,000軒（1店200人。本当の満足度を作成者が置いたもの）で、同じ200人が同じ満足度のまま3つの聞き方に答えたとき、平均や順位がどれだけ違って見えるかを数えました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A808 | 同じ満足度でも、5段階・10段階・おすすめ度で見え方はどれだけ違うか。星の平均を2倍すれば10段階の平均になるか。星の平均が同じ店で NPS はそろうか | 架空の店2,000軒。1人ひとりの満足度（100点満点）は、店の平均（平均70点・標準偏差8点の正規分布）を中心に、店ごとの散らばり（標準偏差8〜22点の一様分布）で散らばる（0〜100で切る）。1店200人が3つの聞き方に答える。答えへの当てはめ（区切り）は作成者が置いた「答え方のくせ」あり：星は30・45・60・75点以上で1段ずつ上がる（75点以上で星5）、10段階は20・30・40・50・60・70・80・88・95点以上で1段ずつ上がる（10は95点以上）、おすすめ度は17・26・35・44・53・62・71・80・89・98点以上で1段ずつ上がる（9は89点以上）。「本当の満足度」は、その店の200人の満足度の平均。回答の人数ごとの振れは、平均70点・散らばり15点の店を2万回作り直して数えた。区切りを等間隔（くせなし）にした確かめ、散らばりを全店15点にそろえた確かめも行った。seed 808 | `src/a808_scales.py` |

## 主な結果

### 同じ200人（満足度の平均 約70点・散らばり15点）が3つの聞き方に答えると
| 聞き方 | 平均 | 上のほうを付けた人 |
|---|---|---|
| 星1〜5 | **4.12** | 星4〜5が78% |
| 10段階1〜10 | **6.62** | 9〜10が11.5% |
| おすすめ度0〜10 | 6.43 | 推奨者（9〜10）10%、批判者（0〜6）51.5%、**NPS −41.5** |

- 同じ人たちが同じ満足度で答えても、星では「良い店」、10段階では「まあまあ」、NPS では「大きくマイナス」に見えた

### 星の平均を10段階に直すと（店2,000軒）
| | 値 |
|---|---|
| 星の平均（店の平均） | 4.02 |
| 星の平均×2 | 8.05 |
| 10段階の平均（実際） | 6.55 |
| 「×2」と実際のずれ | **+1.50** |
| 「1〜5を1〜10に引き伸ばす（(星−1)×9÷4＋1）」と実際のずれ | +1.26 |

- 星4.0以上の店は55.3%あったが、10段階8.0以上の店は4.5%、NPS がプラスの店は11.6%だった
- 店の順位の並びは近い（順位の相関：星と10段階 0.98、星と NPS 0.92）

### 星の平均が4.0前後（3.95〜4.05）の店201軒の NPS
| | NPS |
|---|---|
| 10〜90%の範囲 | **−62.5〜−29.0** |
| 最小〜最大 | −70.5〜−18.5 |
| 人による散らばりが小さい店（12.0点以下）の平均 | −61.0 |
| 人による散らばりが大きい店（18.8点以上）の平均 | −30.0 |

- 星の平均が同じでも、NPS は30点以上違った。好き嫌いの分かれる店ほど推奨者（9〜10）が出やすく、NPS が高く出た

### 本当の上位20軒に入っていた割合
| 並べ方 | 基本（答え方のくせあり） | 区切りを等間隔 | 散らばりを全店15点にそろえる |
|---|---|---|---|
| 星の平均 | **65%** | 65% | 90% |
| 10段階の平均 | 100% | 85% | — |
| NPS | 100% | 80% | 95% |

- 星は75点以上がすべて星5になるため、上のほうの店の差が見えにくく、上位の当たりが下がった（天井に詰まる）
- 10段階と NPS の100%は、1店200人と多めに置き、「本当の満足度」もその200人の平均と定めたことによる。答える人が少ない店では下がるはず（推測。数えていない）

### 回答の人数ごとの振れ（平均70点・散らばり15点の店）
| 人数 | 星の平均の標準偏差 | NPS の標準偏差 | 店どうしの差に比べた大きさ（星／NPS） |
|---|---|---|---|
| 30人 | 0.160 | 12.06 | 0.37／0.39 |
| 100人 | 0.088 | 6.64 | 0.20／0.21 |
| 300人 | 0.051 | 3.87 | 0.12／0.13 |

- NPS は30人で±12点ほど振れるが、店どうしの差に比べた大きさは星の平均とほぼ同じだった。NPS の振れが大きく見えるのは、目盛りが−100〜100と広いため

## 動かし方
```
pip install -r requirements.txt
cd src && python a808_scales.py
```
3秒ほどで終わります。`data/shops.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の6ファイルがバイト単位で一致した（cmp、約2秒）
- 区切りを等間隔（くせなし）にすると、「×2」のずれは+1.50から+0.47に、「引き伸ばし」のずれは+1.26から+0.21に縮んだ。NPS がプラスの店は11.6%から36.9%に増えた。聞き方の違いで出るずれの大半は、置いた「答え方のくせ」から来ている
- 人による散らばりを全店15点にそろえると、星と NPS の順位の相関は0.92から0.99に上がった。星の平均が同じ店で NPS が違うのは、店ごとの散らばりの違いから来ている

## 注意（言えないこと）
- 架空のデータです。満足度の分布と、満足度を各目盛りに当てはめる区切りは作成者が置いたもので、結果はこれで決まります。とくに「×2で1.5点ずれる」の大きさは区切りの置き方で大きく変わります（等間隔なら0.47）
- 実際の人が5段階と10段階をどう使い分けるかは、ここでは調べていません。区切りは「星は上を付けやすく、10段階の10やおすすめ度の9〜10は付けにくい」というくせを仮に置いたもの（推測にもとづく置き方）です
- 上位20軒の当たり（10段階・NPS で100%）は、1店200人と置いたことによります。答える人が少ないときの当たりは数えていません
- 1人が3つの聞き方すべてに同じ満足度で答えると置きました。聞く順番や、前の答えに引っぱられることは入れていません
- 実際の口コミサイトやアンケートの数え方を表すものではありません
- 件数が少ない店の星の振れは、関連する記事 801 で扱っています
