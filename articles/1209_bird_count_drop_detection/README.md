# 1209 見つけた鳥の数が去年より減ったのは、鳥が減ったからか、見つけにくくなったからか？（生き物の数え方）

鳥の調査では、決まった地点を見回って、見つけた鳥の数を数えます。見つけた数が去年より2割減ると「鳥が減った」と読みたくなります。けれども、見つけた数は「本当にいる数 × 1羽を見つける確率」で決まります。木の葉が茂った、見回る人が替わった、天気が悪かったなどで見つける確率が下がっても、見つけた数は同じように減ります。**ここでは、作成者が乱数で作った架空の森の観察地点40か所（地点ごとの本当の鳥の数と、1回の見回りで1羽を見つける確率を作成者が置いたもの）で、「本当の数が2割減る」と「見つける確率が0.5から0.4に下がる」を置き分け、見つけた数の合計・地点ごとの最大の合計・見回りどうしの数のばらつきから見つける確率を数え直した数、の3つで2年目の増減がどう見えるかを数えました。置き方を変えた36通りでも確かめました。**

例の森・地点・鳥は作成者が置いた架空のもので、実在の場所・調査・団体の数字ではありません。鳥が増えた・減った理由や、保護の進め方は扱っていません。

関連する記事：1004「「過去最高の来場」は、数え方を変えた年と比べられるのか？」は、途中で数え方を変えた年と前の年を比べるずれを扱っています。1003「数取りの人による数え間違いは、どれだけ出るのか？」は、人の手で数えるときの数え漏れを扱っています。同じ企画の 1219「珍しい種の報告が増えたのは、種が増えたからか、探す人が増えたからか？」は、見つける側の変化のうち観察する人の数と腕前が年で変わる場面、1215「鳴き声で数えると、よく鳴く時期と鳴かない時期で、数はどう見えるのか？」は見つかる見込みが季節の中で動く場面、1214「見つけやすい大きな生き物と見つけにくい小さな生き物では、数の割合はどれだけゆがむのか？」は1回の調査の中で種ごとに見つけやすさが違う場面、1220「群れで動く生き物を数えるとき、群れを見落とすと全体の数のぶれはどれだけ大きくなるのか？」は群れごとに見落とすと数のぶれが大きくなる場面を扱っています（この記事の数え直しは1羽ずつ別々に見つかると置いた式なので、群れごと見落とすと見回りどうしのばらつきが大きく出て、見つける確率を小さく見込むと考えています。推測）。この記事は、数え方を変えていなくても、1羽を見つける確率が年で変わると見つけた数が同じ割合で動く点と、同じ地点を何回か見回った数のばらつきから、その分をどこまで見分けられるかに絞ります。

## 主な結果

### 4つの場面（2,000回の平均、`results/a1209_main.json` の scenarios）
| 場面 | 本当の数の増減 | ①見つけた数の合計 | ②地点ごとの最大の合計 | ③数え直した数（平均／中央値） | ③の5〜95% |
|---|---|---|---|---|---|
| 本当の数は同じ・見つける確率0.5→0.4 | 0.34% | **−19.56%** | −15.47% | 9.31%／**−1.05%** | −38.49〜83.46% |
| 本当の数が2割減・見つける確率は同じ | −19.83% | **−19.85%** | −17.99% | −17.56%／−20.18% | −48.26〜21.31% |
| 本当の数が2割減・見つける確率0.5→0.4 | −19.6% | −35.75% | −30.43% | −11.13%／−20.29% | −49.6〜47.36% |
| どちらも変わらない | 0.4% | 0.45% | 0.36% | 3.6%／0.47% | −34.81〜52.79% |

- **見つけた数の合計は、「本当の数は同じで見つけにくくなった」（−19.56%）と「本当の数が2割減った」（−19.85%）で、ほぼ同じに見えた**。見つけた数の平均は本当の数×見つける確率なので、確率が0.5→0.4（2割下がる）なら見つけた数も2割減る（式どおり）
- 見つけた数の合計が10%以上減ったのは、本当の数は同じで見つけにくくなった場面で2,000回の88.8%、本当の数が2割減った場面で89.45%だった
- 地点ごとに3回の最大を取ると、減り方は−15.47%と少し小さくなった。3回のうちどこかで多く見つかる見込みが残るためで、見つけにくくなった分を消すことはできなかった
- 見回りどうしの数のばらつきで見つける確率を数え直すと（年3回・40地点）、見つける確率の見込みは1年目0.5001・2年目0.4018（平均）で、置いた0.5・0.4にほぼ合った。数え直した数の増減は中央値−1.05%と本当の0%近くに戻った。ただし5〜95%は−38.49〜83.46%と広く、平均は9.31%と上に寄った（見つける確率の見込みが小さく出た回に、数が大きく出るため）

### 一回分の例（本当の数は同じ・見つける確率0.5→0.4の1回目、`data/example_sites.csv`）
- 本当の数は1年目307羽・2年目319羽（3.91%増）。見つけた数の合計は455羽→393羽で−13.63%だった
- 数え直した数は66.97%増と、逆向きに大きく外れた。見つける確率の見込みが1年目0.6198・2年目0.3206と、どちらも置いた値から離れたため

### 確かめ：置き方を変えた36通り（各300回、`results/grid.csv`）
- 見つけた数の合計の、本当の増減からのずれは−48.64〜0.68ポイントだった。見つける確率が2割下がった12通りでは−23.79〜−15.56ポイント、4割下がった12通りでは−48.64〜−31.38ポイントで、ずれはほぼ見つける確率の下がり方で決まった（本当の増減が＋20%のときにずれが大きいのは、ずれが本当の数×確率の掛け算で効くため。式どおり）
- 数え直した数のずれは、鳥ごとの見つけやすさが同じ18通りで−0.4〜30.19ポイント（大きいのは年3回で見つける確率が4割下がったとき。上に寄る分）、違う18通りで−29.55〜1.66ポイントだった
- 鳥ごとの見つけやすさが違うと、見つけやすい鳥ほど毎回見つかるので、見回りどうしのばらつきが小さく出て、見つける確率の見込みは1年目に平均0.6658（置いた平均は0.5）と大きく出た。このとき数え直した数は、見つけにくくなった分の半分ほどしか戻らなかった（見つける確率が2割下がった6通りでずれ−13.07〜−8.08ポイント）

## 注意（言えないこと）
- 架空のデータです。地点ごとの本当の数、見つける確率、見回りの回数は作成者が置いたもので、結果はこれで決まります
- 見つけた数の合計が見つける確率と同じ割合で減るのは、置いた作りどおりです。この記事で新しく数えたのは、見回りどうしのばらつきで数え直したときの戻り方と、その幅です
- 数え直しは、見回りのあいだに鳥が地点を出入りしない・同じ鳥を2回数えない・どの鳥も同じ確率で見つかる、と置いた式です。鳥が出入りするとばらつきが大きく出て、見つける確率を小さく見込みます（確かめていません）。鳥ごとの見つけやすさが違うと、見つけにくくなった分の半分ほどしか戻りませんでした
- 見つける確率が下がった理由（葉の茂り・見回る人・天気など）は分けていません。理由ごとに記録を残せば見分けの手がかりになるかは、確かめていません
- 実際の鳥の調査の方法や、ある場所で鳥が増えた・減ったかは言えません
