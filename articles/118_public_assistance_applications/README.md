## もとのリポジトリの説明

以下は、もとのリポジトリ `public-assistance-japan` の README です（同じリポジトリにあったほかの記事の分も含みます）。

### public-assistance-japan：厚生労働省「被保護者調査」で、生活保護の世帯類型・申請・都道府県差の13年を調べる

厚生労働省「被保護者調査」（月次調査）の年度別の表（2012〜2024年度、2012年4月〜2025年3月の156か月）を使ったリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| W1 | 生活保護を受けている世帯は増えているのか。世帯類型（高齢者・母子・障害者・傷病者・その他）でどう変わったか。単身の高齢者世帯の割合は | 世帯類型別の月次の世帯数、年度の1か月平均、構成比、2012→2017→2024年度の増減の分解、月ごとの前月差（3月の段差の確認） | `src/w1_types.py` |
| W2 | 保護の申請件数・開始世帯数は月ごとにどう動くか。2020年度（コロナ期）にどう動いたか。都道府県の保護率の差は縮まったか | 対数をとった月次の値のSTL分解（周期12、ロバスト）、前年同月比、都道府県（指定都市・中核市を含む）の保護率の標準偏差・変動係数、β収束（2012→2024年度の変化を2012年度の水準で回帰、HC1標準誤差） | `src/w2_flow.py` |

#### 主な結果
- **W1**：被保護世帯数（年度の1か月平均）は155.2万（2012年度）→164.2万（2024年度）で5.8%増えた。ただし増えたのは主に2017年度まで（＋8.1万）で、その後の7年は＋0.9万とほぼ横ばい。月次の最多は2024年7月の164.5万世帯。被保護実人員は213.6万人→200.8万人（−6.0%）で、1世帯当たりの人数は1.38人→1.22人に減った。類型別では高齢者世帯が67.8万→90.6万（＋34%、割合43.7%→55.2%）、障害者世帯が＋28%（11.4%→13.8%）、母子世帯が−46%（7.4%→3.8%）、傷病者世帯が−37%（19.2%→11.3%）、その他の世帯が−8%（2019年度の24.3万を底に2024年度は26.1万）。単身の高齢者世帯は60.8万→84.3万で、全体に占める割合は39.2%→51.3%（2021年度以降は51.3%で横ばい）、高齢者世帯のうち単身は89.8%→93.0%
- **W2**：申請件数は27.5万件（2012年度）→22.3万件（2019年度）に減り、その後増えて2024年度は26.0万件。STLの傾向は2020年2月の月1.82万件が底で、2025年3月は2.24万件（＋23%）。開始世帯数も25.9万→19.9万（2019年度）→22.9万（2024年度）。季節成分は申請件数で7月＋10.3%、3月＋9.2%、5月＋6.9%、12月−13.1%、2月−10.2%。2020年4月の申請は21,507件で前年同月比＋25.0%（STLの残差＋22.5%）、5〜8月は前年を4〜11%下回り、2020年12月〜2021年3月は＋6〜9%だった。2020年度の合計は22.8万件で、2019年度より2.3%多い。都道府県（指定都市・中核市を含む）の保護率は2024年度に4.3‰（富山県）〜30.2‰（大阪府）。標準偏差は7.14→6.29‰、変動係数は0.504→0.450、最大÷最小は10.5倍→7.0倍に縮まった。2012年度に保護率が高かった所ほど下がっていて（β＝−0.137、標準誤差0.028）、47都道府県のうち22で上がった（沖縄県＋4.0‰、宮城県＋2.3‰など）。指定都市の標準偏差も10.5→8.2‰

#### 動かし方
`data/` に整えた CSV（`types_monthly.csv`・`flow_monthly.csv`・`units_fy.csv`）が入っているので、そのまま動きます。元の Excel から作り直すときは、この3つの CSV を消してから実行してください（`data/hogo_raw.zip` が `data/raw/` に自動で展開されます）。

```bash
pip install -r requirements.txt
cd src
python w1_types.py
python w2_flow.py
```

#### データ
| ファイル | 中身 |
|---|---|
| data/hogo_raw.zip | e-Stat の年度別 Excel 39本（`fy<年度>_ruikei`＝第5表、`fy<年度>_hogoritsu`＝第9表、`fy<年度>_shinsei`＝第19表）。ファイル名は作成者が付け直した |
| data/types_monthly.csv | 月×世帯類型：現に保護を受けた世帯数（総数、高齢者・母子・障害者・傷病者・その他の世帯、単身者世帯の計、単身の高齢者世帯） |
| data/flow_monthly.csv | 月：保護の申請件数、保護開始世帯数、保護廃止世帯数（全国） |
| data/units_fy.csv | 年度×都道府県（指定都市・中核市を除く）・指定都市・中核市：被保護実人員（月別、12か月累計、1か月平均）と年度の保護率（人口千対） |

#### 注意
- 年度は4月〜翌年3月です。世帯数は「現に保護を受けた世帯」（保護停止中を含む）、保護率は被保護実人員の1か月平均を10月1日現在の人口で割った値（人口千対、‰）です
- 世帯類型は、毎年3月の値に段差があります。前月と比べて高齢者世帯が平均1.4万世帯増え、傷病者・母子・障害者・その他の世帯が減ります。表からは理由が分からないので、年度の比較には12か月の平均を使いました
- 高齢者世帯は「65歳以上の者のみ（18歳未満の者が加わってもよい）」の世帯です。高齢者世帯が増えた分には、もともと保護を受けていた世帯の世帯員が65歳になって類型が変わった分も含まれますが、この表では分けられません
- 第9表の都道府県の値には、指定都市・中核市の分が入っていません。都道府県全体の保護率は、県と県内の指定都市・中核市の月ごとの実人員を足し、人口は各単位の「1か月平均の実人員÷保護率」の合計で近似しました。保護率の多くは小数1位に丸められているので、人口の近似には±0.4%程度の誤差があります（全国の人口との比較で0.997〜1.002倍）
- 八戸市は2017年1月に中核市になったため、2016年度は1〜3月だけの値です。月ごとに足すことで、県全体の実人員は重複も抜けもなくなります
- 中核市の数は41（2012年度）→62（2024年度）に増えています。都道府県全体で集計しているので、この変化は結果に影響しません
- 申請件数・開始世帯数は月ごとの開庁日数（土日・祝日・年末年始）の違いを調整していません。12月と2月が少ないのは日数の影響を含みます
- 保護率の分母の人口は、国勢調査の年（2015・2020年度）とそれ以外の年で、出どころが少し違います
- 申請や保護が増減した理由（景気、雇用、高齢化、制度や運用の変化など）は、このデータでは分けられません。都道府県の差も、年齢構成・世帯構成・所得などの違いを調整していません
