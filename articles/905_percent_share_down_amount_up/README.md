# 905 構成比が下がっても、量は増えていることはあるのか？（割合とパーセント）

構成比（ある分類の売上÷会社全体の売上）は、その分類が伸びても、ほかの分類がもっと伸びれば下がります。円グラフや「構成比が40%から36%に下がった」という書き方だけを見ると、その分類が縮んだように読めますが、会社全体が伸びていれば、売上そのものは増えていることがあります。**ここでは、作成者が乱数で作った架空の会社2,000社（各社5つの商品分類A〜E、会社全体の伸びを年3%ほどと作成者が置いたもの）で、構成比が下がった分類のうち売上そのものは増えていた割合を、1年と10年で数えました。**

構成比が下がって売上が増えるのは、その分類の伸びが「0より大きく、会社全体の伸びより小さい」ときに限られます（式で決まる）。この記事の数字は、その範囲に入る分類がどれだけあるかを、作成者が置いた伸び方で数えたものです。

| A905 | 構成比が下がった分類のうち、売上そのものは増えていた割合はどれだけか。何で動くか | 架空の会社2,000社×5分類。1年目の構成比はディリクレ分布（パラメータ2）で引き、1年目の会社全体の売上を100とする。毎年の売上の動き（対数）＝会社の傾き（会社ごとに平均0.03・標準偏差0.04）＋会社の年ごとの振れ（標準偏差0.03）＋分類の傾き（分類ごとに平均0・標準偏差0.05）＋分類の年ごとの振れ（標準偏差0.08）。10年分を作り、1年目→2年目（1年）と1年目→11年目（10年）で、構成比が下がった分類のうち売上が増えた割合を数えた。会社全体の伸び（その年の実際の伸び）ごと、構成比の下がり方（ポイント）ごとにも分けた。確かめとして、会社の傾きの平均（−0.05・0・0.03・0.10）×分類の動きの大きさ（分類の傾きと振れの標準偏差を0.5倍・1倍・2倍）の12通りを各2,000社。seed 905 | `src/a905_share_vs_amount.py` |

## 主な結果

### 構成比が下がった分類のうち、売上は増えていた割合（2,000社×5分類＝10,000）
| | 構成比が下がった分類 | そのうち売上は増えていた | 構成比が上がった分類のうち売上は減っていた | 会社全体の売上が増えた会社 | 会社全体の伸び（中央値） |
|---|---|---|---|---|---|
| 1年（1年目→2年目） | 5,062 | **35.6%** | 12.3% | 68.4% | +3.45% |
| 10年（1年目→11年目） | 5,569 | **48.2%** | 9.7% | 78.2% | +47.76% |

- 構成比が下がった分類の35.6%は、売上そのものは増えていた。10年で見ると48.2%だった。会社全体の伸びが積み重なるため、長い期間ほど「構成比は下がったが売上は増えた」が増えた
- 逆に、構成比が上がったのに売上は減っていた分類も、1年で12.3%あった（会社全体が縮んだ会社で起きる）

### その年の会社全体の伸びごと（1年）
| 会社全体の伸び | 会社の数 | 構成比が下がった分類 | そのうち売上は増えていた | 構成比が上がった分類のうち売上は減っていた |
|---|---|---|---|---|
| −5%未満 | 241 | 548 | 0% | 61.3% |
| −5〜0% | 391 | 956 | 0% | 20.5% |
| 0〜+5% | 541 | 1,375 | 24.9% | 0% |
| +5〜+10% | 465 | 1,186 | 55.9% | 0% |
| +10%以上 | 362 | 997 | **80.1%** | 0% |

- 会社全体が縮んだ会社では、構成比が下がった分類の売上は必ず減っていた。会社全体が伸びた会社では、構成比が上がった分類の売上は必ず増えていた。どちらも式で決まる（構成比×全体＝売上）
- 会社全体が+10%以上伸びた会社では、構成比が下がった分類の80.1%で、売上は増えていた

### 構成比の下がり方（ポイント）ごと（1年）
| 構成比の下がり方 | 分類の数 | そのうち売上は増えていた |
|---|---|---|
| 0.5ポイント以内 | 1,637 | 55.35% |
| 0.5〜1ポイント | 1,149 | 38.2% |
| 1〜2ポイント | 1,269 | 26.1% |
| 2〜5ポイント | 951 | 13.5% |
| 5ポイントより大きい | 56 | 0% |

- 下がり方が小さいほど、売上は増えていることが多かった。ただし、下がり方のポイントだけでは決まらず、元の構成比と会社全体の伸びで決まる（下の式）

### 式：会社全体が伸びたとき、売上が減らない構成比の下限
| 会社全体の伸び | 構成比が何倍まで下がっても売上は減らないか | 元の構成比40%なら |
|---|---|---|
| −10% | 1.1111倍（上がらないと減る） | 44.44% |
| 0% | 1倍 | 40% |
| +3% | 0.9709倍 | 38.83% |
| +10% | 0.9091倍 | 36.36% |
| +20% | 0.8333倍 | 33.33% |
| +34%（年3%で約10年） | 0.7463倍 | 29.85% |
| +50% | 0.6667倍 | 26.67% |

- 売上の伸び＝（今の構成比÷前の構成比）×（1＋会社全体の伸び）−1。会社全体が+10%伸びていれば、構成比が40%から36.36%に下がっても売上は同じ。これは割り算の式で、データから見つけたものではない

### 例：構成比は10年続けて下がり、売上は増えた分類（架空の1社）
- 会社全体の10年の伸びが+30〜+70%の会社のうち、「構成比は下がり、売上は増えた」分類で、構成比の下がり方がいちばん大きかったもの（会社1643の分類B）
- 構成比は60.87%→41.94%に下がり、10年のうち10年とも前の年より下がった。売上は60.87→62.95に増えた（10年のうち前の年より増えたのは6年）。会社全体は100→150.09
- 構成比の折れ線だけを見ると縮み続けているように見えるが、売上はほぼ横ばいから少し増えていた

### 確かめ：会社全体の伸びの中心 × 分類の動きの大きさ（12通り、各2,000社）
| 会社の傾きの平均 | 分類の動き 0.5倍 | 1倍（基本） | 2倍 |
|---|---|---|---|
| −0.05（年およそ−5%） | 8.2%／6.8% | 8.0%／6.5% | 10.1%／11.7% |
| 0 | 30.1%／34.9% | 23.5%／28.6% | 19.25%／27.5% |
| 0.03（基本） | 49.4%／60.5% | 35.3%／48.2% | 26.45%／39.0% |
| 0.10（年およそ+10%） | 86.9%／96.0% | 68.2%／87.1% | 45.2%／66.8% |

（表の中は「構成比が下がった分類のうち、売上は増えていた割合」、1年／10年。確かめは置き方ごとに別の乱数で2,000社を作り直したので、基本の行の1年の値は上の35.6%と少し違う）

- 割合は、置き方で1年は8.0〜86.9%、10年は6.5〜96.0%まで動いた。会社全体がよく伸びるほど、分類の動きが小さいほど、構成比の下がった分類の売上は増えていた。分類の動きが小さいと、分類の伸びが「0から会社全体の伸びまで」の範囲に入りやすいため（式からの説明）
- 基本の置き方の35.6%・48.2%は、一般の値としては読めない

## 動かし方
```
pip install -r requirements.txt
cd src && python a905_share_vs_amount.py
```
2秒ほどで終わります。`data/` の2つのファイルもこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の10ファイルがバイト単位で一致した（cmp、約1秒）
- 図はすべて開いて、日本語・文字の重なり・軸を目で確かめた。本文の数字は results と照らした
- 「会社全体が縮んだ会社で、構成比の下がった分類の売上は必ず減る」「会社全体が伸びた会社で、構成比の上がった分類の売上は必ず増える」は、構成比×全体＝売上の式から決まり、数えた値も0%どおりだった
- 構成比が下がって売上が増える割合は、置いた会社全体の伸びと分類の動きの大きさの写しで、12通りで6.5〜96.0%まで動いた

## 注意（言えないこと）
- 架空のデータです。会社全体の伸び、分類ごとの傾きと振れの大きさは作成者が置いたもので、結果はこれで決まります
- 売上の金額だけを扱いました。値上げ・値下げで売上が動いたのか、売れた数が動いたのかは分けていません
- どの分類に力を入れるべきかの判断や、会社の経営の良し悪しを言うものではありません
- 関連する記事：%と%ポイントの違い（構成比の差はポイントで書く）は 897、分母を「全体」にするか「対象者」にするかは 902 で扱っています。円グラフと棒グラフの読み取りの誤差は 815、積み上げ棒グラフの真ん中の項目の増減は 822、流入元の構成が変わると合計の完了率が動く話は 847 で、構成の変化を別の題材で数えています
- 同じ企画の 907 は、構成比の表を四捨五入すると合計が100%にならないことを扱っています
