# 01 取得（住宅・土地統計調査 2018・2023年）

`data/raw/f128_hlts_rent.json` は、e-Stat に置かれている総務省「住宅・土地統計調査」の Excel（DB 用）5つを、2026年11月3日にブラウザの中で読み込み、シートを CSV の文字列にして1つの JSON にまとめたものです（キーの登録は要りません）。

| キー | 表 | statInfId |
|---|---|---|
| `m23` | 令和5年 第122-4表 住宅の所有の関係(4区分)別延べ面積1m²当たり家賃(10区分)別借家(専用住宅)数及び延べ面積1m²当たり家賃－全国、都道府県、市区町村 | 000040210062 |
| `m18` | 平成30年 第123-4表（同じ内容） | 000031865896 |
| `d23` | 令和5年 第107-2表 住宅の種類、所有の関係、建築の時期別借家の1畳当たり家賃－大都市圏、都市圏、距離帯 | 000040209827 |
| `d18` | 平成30年 第108-2表（同じ内容） | 000031866130 |
| `s23` | 令和5年 第206-2表 世帯の型(14区分)、最寄りの交通機関までの距離(12区分)別主世帯数－全国、都道府県、市区町村 | 000040242539 |

取り方：`https://www.e-stat.go.jp/stat-search/file-download?statInfId=<id>&fileKind=0` を e-Stat のページの中で fetch し、SheetJS（xlsx 0.18.5）で読み、`XLSX.utils.sheet_to_csv` で最初のシートを文字列にしました。手で取る場合は、上の URL から Excel をダウンロードすれば同じ内容になります。

市区町村の位置・所得・人口密度・高齢化率は、同じリポジトリの F107（`articles/F107_gcn_municipal/data/nodes.csv`）をそのまま `data/raw/municipal_nodes_F107.csv` として置いています。位置は国土数値情報 行政区域 2021（smartnews-smri/japan-topography の簡略版 TopoJSON、CC BY 4.0）の頂点の平均です。
