# F128 家賃は、都心や駅からの距離でどれだけ下がるのか？（距離帯の集計と市区町村の GAM）

都心から離れるほど家賃は安くなる、とよく言われます。では、どのくらいの距離で、どれだけ下がるのでしょうか。下がり方は一定なのか、どこかで緩やかになるのか。東京・名古屋・大阪で違うのか。駅の近さとは別の話なのか。総務省「住宅・土地統計調査」（2018年・2023年）の集計表で確かめます。

## 問い

- 民営借家の家賃（広さあたり）は、都心から10km 離れるごとに何%下がるか
- 下がり方はまっすぐ（指数的）か、それとも途中で緩やかになるか（GAM・折れ線）
- 東京・名古屋・大阪で下がり方は違うか
- 駅の近さを入れると、都心からの距離の効果はどれだけ小さくなるか
- 建物の古さの違いをそろえても、下がり方は変わらないか

## データ

| データ | 中身 | e-Stat statInfId |
|---|---|---|
| 令和5年 住宅・土地統計調査 第122-4表 | 住宅の所有の関係別 延べ面積1m²当たり家賃（全国・都道府県・市区町村） | 000040210062 |
| 平成30年 同 第123-4表 | 同上（2018年） | 000031865896 |
| 令和5年 同 第107-2表 | 住宅の種類・所有の関係・建築の時期別 借家の1畳当たり家賃（大都市圏・都市圏・距離帯） | 000040209827 |
| 平成30年 同 第108-2表 | 同上（2018年） | 000031866130 |
| 令和5年 同 第206-2表 | 世帯の型・最寄りの交通機関までの距離別 主世帯数（市区町村） | 000040242539 |
| 市区町村の位置・所得・人口密度・高齢化率 | F107 と同じ表（国土数値情報 行政区域 2021 の重心、社会・人口統計体系）。`data/raw/municipal_nodes_F107.csv` | — |

- 家賃は **民営借家** の「延べ面積1m²当たり家賃（家賃0円を除く）」を基本にしました。広さの違いを割り算でそろえるためです。
- 「距離帯」は、調査の集計で使われている東京70キロ圏（都庁が中心）・名古屋50キロ圏・大阪50キロ圏（市役所が中心）の10km 刻みの区分です。
- 市区町村の分析は、同じ中心からの直線距離で、東京70km・名古屋50km・大阪50km 以内の **399市区町村**（政令市は区）です。調査の市区町村別の集計は、おおむね人口1.5万人以上の市区町村にしかありません。

## 手法

1. **距離帯の表**：民営借家の1畳当たり家賃を、0〜10km 圏を1とした比にしました。建築の時期（10区分）ごとに比をとって平均し、建物の古さの違いをそろえた比も出しました。
2. **市区町村の GAM**：対数家賃を都心からの距離のなめらかな関数（pygam、スプライン10本、罰則は格子探索）で表し、都市圏ごとに当てはめました。直線（対数で直線＝一定の割合で下がる）と5分割の交差検証で比べました。折れ点を1つ持つ折れ線（5〜40km で探索）も当てはめました。
3. **駅の近さ**：市区町村ごとの「駅まで1km 未満に住む主世帯の割合」を加えた回帰（都市圏の固定効果、頑健な標準誤差）と、2つのなめらかな項を持つ GAM で、都心からの距離と駅の近さを分けました。
4. **2018→2023年の伸び**：同じ市区町村で、5年間の家賃の伸びが都心に近いほど大きかったかを確かめました。

## 結果

**1. 東京では、60〜70km 圏の家賃は都心の3分の1強だった（距離帯の表、2023年）**

| 都心からの距離帯 | 東京 | 名古屋 | 大阪 |
|---|---|---|---|
| 0〜10km（1畳当たり家賃） | 7,995円 | 3,815円 | 4,351円 |
| 10〜20km | 0.70 | 0.79 | 0.83 |
| 20〜30km | 0.57 | 0.81 | 0.84 |
| 30〜40km | 0.48 | 0.74 | 0.77 |
| 40〜50km | 0.47 | 0.71 | **0.93** |
| 60〜70km | 0.35 | — | — |

大阪圏は 40〜50km 圏で家賃がまた上がります。この距離帯には京都市の中心部などが入るためです（推測）。大阪圏は中心が1つではない都市圏でした。

**2. 市区町村で見ても、下がり方は「最初に急で、その先は緩やか」だった（GAM、2023年）**

都心から5km の家賃を1とした比です。

| 距離 | 東京（5km で 3,098円/m²） | 名古屋（1,491円/m²） | 大阪（1,726円/m²） |
|---|---|---|---|
| 10km | 0.83 | 0.88 | 0.86 |
| 20km | **0.60** | 0.76 | 0.70 |
| 30km | 0.49 | 0.71 | 0.68 |
| 50km | 0.38 | 0.62 | 0.61 |
| 70km | 0.33 | — | — |

- なめらかな曲線（GAM）は、まっすぐな下がり方より交差検証の誤差が小さくなりました（対数の RMSE：東京 0.171 対 0.191、名古屋 0.150 対 0.157、大阪 0.226 対 0.240）。
- 折れ線で見ると、東京は 18km までは10km あたり 37% 下がり、その先は 12% でした。大阪は 14km まで 33%、その先は 3% でした。名古屋は 8km の内側だけが急でした。

**3. 駅の近さは、都心からの距離とは別に家賃と関係していた**（3大都市圏の348市区町村）

| モデル | 都心から10km あたり | 駅1km 未満の世帯割合 10ポイントあたり | R² |
|---|---|---|---|
| 距離だけ | −12.9% | — | 0.61 |
| 距離＋駅の近さ | −9.3% | +5.1% | 0.69 |
| ＋所得・人口密度・高齢化率 | −0.8%（有意でない） | +2.0% | 0.88 |

- 駅の近さを入れると、都心からの距離の傾きは 29% 小さくなりました。都心に近い市区町村ほど駅に近い世帯が多い（相関 −0.56）ためです。
- 所得・人口密度・高齢化率まで入れると、距離の傾きはほぼ消えました。ただし、人口密度や所得は「都心に近いこと」の結果でもあります。距離の効果がなくなったのではなく、距離の効果がこれらの違いとして表れている、と読むのが自然です（推測）。

**4. 建物の古さをそろえても、下がり方はほぼ同じだった**

東京の 30〜40km 圏は、そのままで 0.48、建築の時期をそろえると 0.51 でした。郊外に古い建物が多いから安い、という説明はほとんど当たりませんでした。

**5. 2018→2023年の家賃の伸びは、都心とそれ以外でほとんど変わらなかった**

市区町村の家賃（中央値）は5年で 7.0% 上がりました。東京の 0〜10km は 11.6%、その外は 7〜8% でしたが、距離との関係（10km あたり −0.5 ポイント、標準誤差 0.3）ははっきりしませんでした。

## 頑健性

対数家賃の 10km あたりの傾き（都市圏の固定効果つき）。`results/robustness.csv`

| 条件 | 市区町村数 | 10km あたり |
|---|---|---|
| 基本（2023年・民営借家・家賃0円を除く） | 399 | −13.1% |
| 2018年 | 401 | −12.8% |
| 家賃0円を含む | 399 | −13.7% |
| 借家の総数（公営・給与住宅を含む） | 399 | −13.0% |
| 東京23区を除く | 376 | −11.0% |
| 圏の半径を一律40km | 290 | −15.1% |
| 都市圏別：東京／名古屋／大阪 | 208／83／108 | −15.3%／−9.4%／−7.1% |
| 中心を16都市に広げる（半径50km） | 634 | −11.2% |
| 地方の13都市圏だけ（半径50km） | 281 | −8.2% |
| 距離帯の表（2023年／2018年、1畳当たり） | 17 | −10.7%／−10.3% |

どの条件でも、10km 離れるごとに家賃は 7〜15% 下がりました。大きさは都市圏で違い、東京が最も急でした。

## 言えないこと

- **個々の物件の家賃ではありません。** 市区町村や距離帯の平均です。同じ市区町村の中の駅前と駅から遠い物件の差は、この記事では見えません。設計では物件ごとのヘドニック回帰を考えていましたが、公的な統計では物件ごとの家賃が手に入らないため、集計表に切り替えました。
- 広さは「延べ面積1m²当たり」でそろえましたが、間取り・設備・階数・築年数の違い（距離帯の表では築年数をそろえました）は残っています。
- 「距離が家賃を決める」という因果の話ではありません。都心からの距離・駅の近さ・人口密度・所得は互いに強く結びついていて、どれがどれだけ家賃を決めているかは分けきれません。
- 中心は都庁・市役所の1点としました。新宿・渋谷・梅田など、ほかの中心からの距離は見ていません。大阪圏の 40〜50km 圏の上がり方は、そのためと考えられます（推測）。
- 駅までの距離は、借家だけでなく市区町村のすべての主世帯の分布です。
- 家賃は住んでいる人が答えた値で、新しく借りるときの募集家賃（市場の家賃）とは違います。長く住んでいる人の家賃は低めになりやすいです。
- 市区町村の位置は、行政区域の形の頂点の平均（重心の近似）です。
