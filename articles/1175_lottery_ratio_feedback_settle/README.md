# 1175 前回の倍率を見て申し込む人が増えたり減ったりすると、倍率はどこに落ち着くのか？（抽選と倍率）

同じ抽選がくり返されるとき、前回の倍率を見て申し込むかどうかを決める人がいます。前回の倍率が高ければ「どうせ当たらない」と申し込む人が減り、低ければ増えます。すると今回の倍率は前回と逆の向きに動き、その倍率を見て次の回がまた動きます。倍率が1つの値に落ち着くのか、上下に振れ続けるのかは、前回の倍率で申し込む人がどれだけ大きく入れかわるかで決まります。**ここでは、作成者が置いた架空の料理講座の抽選（毎回の枠100、同じ顔ぶれの申し込みうる人2,000人、1人1口）で、倍率を見る人60%が「前回の倍率から読む当たる見込み」が自分の下限以上なら申し込むと置き、下限の散らばりの幅3通り×見る手がかり2通り（前回の倍率／前3回の倍率の平均）で、80回くり返した倍率を200通りの乱数で数えました。落ち着く先の式（その倍率から読む見込みで申し込む人の見込みが、同じ倍率を生む点）とも照らし、見る人の割合3通りを足した18通りでも確かめました。**

例の講座・申し込みの決まりは作成者が置いたもので、実在の催しや人の動きを表すものではありません。申し込むかどうかの助言でも、倍率をどう知らせるとよいかの助言でもありません。

振れが小さく落ち着く設定では、落ち着く先は式の値になります（式どおり）。前回だけを見る場合に落ち着くかどうかは、落ち着く先の近くで「前回の倍率が少し動いたとき、今回の倍率がどれだけ動くか」（傾き）の大きさが1より小さいかで決まります（式どおり）。この記事で数えて新しく分かったのは、振れ続けるときの倍率の幅と平均、空いた枠、申し込んだ人の当たった割合が、落ち着く先の値からどれだけ離れるかと、見る手がかりを前3回の平均に変えたときの違いです。

関連する記事：25冊目 第10章の 878「混雑の予測を出すと、空いている時間に人が集まって外れるのか？」は、前日の実際の待ちを出すと、空く時間帯が日ごとに入れかわることを扱っています。この記事は同じ「見た数字で人が動き、数字そのものが変わる」仕組みを、抽選の倍率に当てています。同じ企画の 1180「倍率の高い回は、申し込みたい人の多い回だと読んでよいのか？」は、倍率を人気として読めるかを扱っています。同じ企画の 1184「申し込む人数の見込みから枠の数を決めると、見込みの外れで倍率はどれだけ振れるのか？」は、申し込む人ではなく主催者が前の回の人数を見て枠を変える場面で、倍率の振れを扱っています。

- **下限の幅が広いと、前回だけを見ても倍率は式の落ち着く先5.315倍の近くに落ち着いた（41〜80回目の平均5.329倍、10〜90%の範囲5.0〜5.65倍）**。傾きの大きさが0.849で1より小さい
- **下限の幅が中だと、前回だけを見る場合は落ち着かず、10〜90%の範囲は0.73〜12.87倍だった**。前回が1倍に近いと、見る人のほぼ全員が申し込んで12倍台になり、前回が12倍台だと、見る人のだれも申し込まずに1倍を切る。これを交互にくり返した（`data/ratio_series_example.csv`）
- 振れ続けるとき、倍率の平均（6.801倍）は落ち着く先（5.571倍）とも合わなかった。49.36%の回で倍率が1倍を切り、1回あたり平均9.92枠が空いた。申し込んだ人の当たった割合は13.24%で、落ち着く先で当たる割合17.95%より低かった
- 同じ中の幅でも、前3回の倍率の平均を見る場合は、5.569倍（式5.571倍）に落ち着いた。幅が狭いと、前3回の平均を見ても振れが残った（散らばり5.281）

### 確かめ：見る人の割合×下限の幅×手がかりの18通り（各50通り、`results/grid.csv`）
- 式の落ち着く先は、18通りで4.234〜6.101倍だった
- 41〜80回目の散らばりは、前回を見る9通りで0.153〜9.001、前3回の平均を見る9通りで0.047〜7.795だった。散らばりが0.5以上残ったのは、前回を見る9通りのうち7通り、前3回の平均を見る9通りのうち4通りだった
- 前回を見る9通りでは、傾きの大きさが0.849以下の2通りは落ち着き、0.967以上の7通りは振れが残った。0.967（見る人90%・幅が広い）は1より小さいが、80回では振れが残った（散らばり2.628）
- 散らばりが0.5未満の7通りでは、倍率の平均は式の落ち着く先と0.02倍以内で合った。振れが残ったものも含めると、平均と式の差は−0.531〜+3.969倍だった
- 1倍未満の回の割合は、いちばん大きい設定で75.0%だった（見る人90%・幅が狭い・前3回の平均）

## 注意（言えないこと）
- 架空のデータと、作成者が置いた架空の申し込みの決まりです。見る人の割合、下限の散らばり方、見ない人の申し込む確率を変えれば、落ち着く先も振れ方も変わります。実在の催しや人の動きを表すものではありません
- 下限は人ごとに決まっていて変わらず、申し込みうる人の顔ぶれも毎回同じと置きました。人が入れかわる場合、学ぶ場合、前回当たった人の動きは入れていません
- 見る人は全員が同じ手がかりを同じように読むと置きました。手がかりの読み方が人ごとに違うと、振れは小さくなると考えられます（推測、数えていません）
- 1人1口、枠は毎回同じと置きました。枠を倍率に合わせて変える決まりは入れていません
- 申し込むかどうか、倍率をどう知らせるとよいかの助言ではありません
