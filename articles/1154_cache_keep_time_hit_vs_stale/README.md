# 1154 置いておく時間を長くすると、当たり率が上がる分と、古いデータを返す割合が増える分はどう釣り合うのか？（キャッシュの当たり率）

よく使うデータを手元の置き場所（キャッシュ）に置くとき、「置いてから何秒までは置いたものを返す」と時間を決めることがあります。この時間を長くすると、元のデータを取りに行く回数が減り、当たり率は上がります。その代わり、置いている間に元のデータが書きかわっていても気づかないので、古いデータを返す割合が増えます。当たり率はやがて100%に近づいて伸びが鈍りますが、古いデータの割合は時間に比べてほぼまっすぐ増え続けます。**ここでは、作成者が置いた架空のアプリのデータ2,000件（人気の偏りと、元のデータが書きかわる頻度を置いたもの）への24時間ぶんの問い合わせ（約43万件）で、置いておく時間を10秒〜6時間の9通りに変え、当たり率と古いデータを返した割合を乱数で数えて式と照らしました。1段長くするごとに「古い割合の増え÷当たり率の上がり」がどう変わるかを出し、人気のデータほど速く書きかわる場合と、書きかわりの間隔・偏り・問い合わせの多さを変えた27通り（式で出したもの）でも確かめました。問い合わせと書きかわりはすべて作成者が置いた頻度からの乱数で、実機の計測はしていません。**

この記事の主な値（当たり率と古い割合）は、問い合わせも書きかわりもでたらめな時刻に起きると置いたことから、式で決まります（式どおり）。乱数で数えた値は、式との差が当たり率で0.17ポイント以内、古い割合で0.94ポイント以内でした。

関連する記事：同じ企画の 1149「当たり率90%と99%の差は、平均の応答時間で何倍の差になるのか？」は、当たり率の差が応答時間でどれだけになるかを扱っています。置いておく時間を長くして当たり率を上げたときの速さの側の得は、1149 の形で読めます。1153「古く使われたものから捨てる決まりと、使われた回数の少ないものから捨てる決まりは、人気が移り変わるときにどちらが当たるのか？」は、置き場所がいっぱいになったときに何を捨てるかを扱っています。1155「同じものを大勢が同時に取りに来ると、置き場所から消えた瞬間に、元のデータへ何件の問い合わせが流れるのか？」は、置いておく時間がすぎて消えた瞬間に、元のデータへ問い合わせがまとまって流れる場面を扱っています。この記事は、置き場所の大きさに上限を置かず、置いておく時間だけで当たりと古さがどう釣り合うかに絞ります。

## 主な結果

### 置いておく時間ごとの当たり率と古い割合（基本の置き方、`results/by_keep.csv`）
| 置いておく時間 | 当たり率 | 古いデータを返した割合（全部のうち） | 同（当たりのうち） | 当たり率（式） | 古い割合（式） | 古かったとき、書きかわってからの時間（中央値） |
|---|---|---|---|---|---|---|
| 10秒 | 22.04% | 0.03% | 0.15% | 22.05% | 0.03% | 3秒 |
| 30秒 | 34.21% | 0.15% | 0.43% | 34.22% | 0.14% | 9.1秒 |
| 1分 | 42.85% | 0.41% | 0.95% | 42.82% | 0.35% | 18.9秒 |
| 5分 | 64.36% | 2.71% | 4.21% | 64.37% | 2.61% | 87.9秒 |
| 15分 | 78.43% | 9.06% | 11.55% | 78.49% | 9.04% | 271.6秒 |
| 30分 | 85.8% | 18.2% | 21.21% | 85.89% | 18.3% | 555.3秒 |
| 1時間 | 91.34% | 32.71% | 35.81% | 91.47% | 33.65% | 1,155.4秒 |
| 3時間 | 96.48% | 66.82% | 69.25% | 96.65% | 66.04% | 3,996.2秒 |
| 6時間 | 98.15% | 82.83% | 84.39% | 98.24% | 81.91% | 9,072.2秒 |

- **置いておく時間を1分から1時間（60倍）にすると、当たり率は42.85%から91.34%に上がり、元のデータへ行く問い合わせ（外れ）は0.152倍に減った。その間に、古いデータを返した割合は0.41%から32.71%と79.78倍に増えた**
- 当たり率は、人気のデータでは早く100%近くに届くので、時間を延ばすほど伸びが鈍る。古い割合は、置いている時間のうち書きかわったあとの部分に比例して増えるので、伸びが鈍りにくい（どちらも式どおり）
- 古かったとき、元が書きかわってからたっていた時間の中央値は、10秒〜1時間の7段では置いておく時間の0.293〜0.321倍だった（5分で87.9秒、1時間で1,155.4秒。3時間・6時間では0.37倍・0.42倍。`results/by_keep.csv` の stale_age_median_over_keep）
- いちばん人気のデータ（毎秒0.418件問い合わせが来る）では、古い割合は式で、5分で4.02%、30分で21.28%、1時間で36.76%（`results/a1154_main.json` の top1_stale_formula）

### 1段長くするごとの釣り合い（基本の置き方、`results/steps.csv`）
| 置いておく時間 | 当たり率の上がり | 古い割合の増え | 古い割合の増え÷当たり率の上がり | 同（式） |

| 10秒→30秒 | +12.17ポイント | +0.12ポイント | 0.01 | 0.009 |
| 30秒→1分 | +8.64ポイント | +0.26ポイント | 0.03 | 0.024 |
| 1分→5分 | +21.51ポイント | +2.3ポイント | 0.107 | 0.105 |
| 5分→15分 | +14.07ポイント | +6.35ポイント | 0.451 | 0.455 |
| 15分→30分 | **+7.37ポイント** | **+9.14ポイント** | **1.24** | 1.251 |
| 30分→1時間 | +5.54ポイント | +14.51ポイント | 2.619 | 2.751 |

- **15分から30分に延ばすところで、古い割合の増え（9.14ポイント）が当たり率の上がり（7.37ポイント）を初めて上回った**。そこから先は、当たりを1ポイント増やすごとに、古いデータが2.619〜9.587ポイント増えた
- 「どこで釣り合うか」は、当たり1ポイントと古いデータ1ポイントのどちらを重く見るかで変わる。この記事はその重みを決めず、比だけを出した

### 人気のデータほど速く書きかわると（上位20件だけ平均10分に1回、`results/by_keep.csv` の hot）
| 置いておく時間 | 古い割合：どれも平均1時間 | 古い割合：上位20件だけ平均10分 |
|---|---|---|
| 1分 | 0.41% | 1.53% |
| 5分 | 2.71% | 8.27% |
| 15分 | 9.06% | 21.32% |
| 30分 | 18.2% | 34.32% |

- 当たり率はどちらもほぼ同じ（5分で64.36%と64.3%）で、古い割合だけが大きく増えた。上位20件は問い合わせの多くを受けるので、そのデータの書きかわりの速さが全体の古い割合を決める
- この置き方でも、古い割合の増えが当たり率の上がりを初めて上回ったのは15分→30分だった（1.771。基本の置き方は1.24）。その手前の5分→15分は0.924で、基本の置き方（0.451）の約2倍だった

### 確かめ：置き方を変えると（27通り、式で出したもの、`results/grid_formula.csv`）
| | 値 |
|---|---|
| 15分→30分の「古い割合の増え÷当たり率の上がり」 | 0.088〜14.636 |
| そのうち1を超えた（古い割合の増えのほうが大きい）置き方 | 27通り中17通り |
| 古い割合が初めて1%を超えた置いておく時間 | 30秒：4通り、1分：3通り、5分：10通り、15分：8通り、30分：2通り |
| 30分のときの古い割合 | 1.67〜67.05% |
| 30分のときの当たり率 | 41.11〜98.14% |

- 比は、元のデータの書きかわりが速いほど、問い合わせが多いほど、偏りが大きいほど大きくなった。書きかわりが平均6時間の9通りでは、1を超えたのは問い合わせが毎秒50件で偏り0.9・1.2の2通り（1.074・1.427）だけだった
- 元のデータが平均10分で書きかわる置き方では、1分や30秒で古い割合が1%を超えるものもあった

## 注意（言えないこと）
- 架空のデータです。人気の偏り、問い合わせの多さ、元のデータの書きかわりの頻度は作成者が置いたもので、結果はこれで決まります。15分→30分の比は、置き方の27通りで0.088〜14.636まで動きました
- 問い合わせも書きかわりも、でたらめな時刻に起きる（決まった時刻に集まらない）と置きました。書きかわりが決まった時刻にまとまる場合は数えていません
- 置き場所の大きさに上限は置きませんでした。いっぱいになって捨てる分は入っていません
- 「古いデータ」は、1回でも書きかわったかどうかだけで数え、どれだけ違っていたかは数えていません。古いデータを返して困るかどうかは、データの種類で違います
- 実在のソフトや置き場所の製品の設定を表すものではありません。置いておく時間をいくつにすべきかの助言や、費用の見込みではありません
