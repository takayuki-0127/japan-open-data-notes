# F283 計画（事前登録）：値上げの前後で、売れ方はどう変わったか？

作成：2026-11-11。家計調査の品目別の月の支出金額（2015年1月〜2026年9月）と消費者物価の品目指数を取得したが、値は見ていない段階で書いた。例外は2つ：表の見出し（品目名・符号）を確かめたことと、2025年改定で「発泡酒・ビール風アルコール飲料」が「発泡酒」（同じ符号 3X7）に名前を変えていたため、その1行（2025年1月〜2026年9月）を取り直したときに値が目に入ったこと。

## 問い
値上げの日がはっきり分かる品目で、値上げの前・その月・後に、買われる量はどう動いたか。「前に買いだめ（駆け込み）」「直後に落ちる（反動）」「落ち着いた後に残る減り（定着）」に分け、定着した減りから値上げに対する反応の大きさ（弾力性）を出す。直後の前年比だけを見ると、値上げの影響を読み違えるかも確かめる。

誰が知りたいか：値上げを決める小売・メーカーの担当（値上げ月の前年比をどう読むか）、販売計画を立てる担当。

## F234・F209・F266・F11 との違い
- F234 は年のデータで弾力性を出した。ここは月のデータで、値上げの前後の動き（駆け込み・反動・定着）を分ける。
- F11・F263 は消費税（全品目）の駆け込み・反動。ここは品目だけに効く値上げ（税の改正で日付がはっきりしたもの）で、同じ月に値下げされた品目との入れ替わりも見る。
- 会社名は扱わない（税の改正という全社共通の値上げだけを使う）。

## 出来事（日付は税の改正で決まる）
値上げ：
- T1 たばこ 2018年10月、T2 たばこ 2020年10月、T3 たばこ 2021年10月（たばこ税の段階的な引上げ）
- A1 発泡酒・ビール風アルコール飲料 2020年10月、A2 同 2023年10月（酒税の改正。新ジャンルの税の引上げ）
- W1 ワイン 2020年10月、W2 ワイン 2023年10月（果実酒の税の引上げ。上げ幅は小さい）
値下げ（比べるため）：
- B1 ビール 2020年10月、B2 ビール 2023年10月
- S1 清酒 2020年10月、S2 清酒 2023年10月
全品目に効くもの（調整用）：2019年10月の消費税の引上げ（酒・たばこは軽減税率の対象外）。

## データ
- 家計調査（家計収支編）二人以上の世帯、長期時系列表 品目分類 支出金額（月）、2015年1月〜2026年9月（e-Stat statInfId 000040270649・000040270650・000040270651）。品目：ビール、発泡酒・ビール風アルコール飲料（2025年から「発泡酒」）、清酒、ワイン、たばこ、ほかの酒（焼酎・ウイスキー・チューハイ・カクテル）、酒類、消費支出。
- 消費者物価指数（2020年基準）品目指数（月）。F209 で取得したもの。ビール、発泡酒、ビール風アルコール飲料、清酒、ワイン（国産品・輸入品）、たばこ。
- 量の代わり：支出金額 ÷ 品目の物価指数（実質の支出）。発泡酒・ビール風は物価指数を2つのウエイトで幾何平均、ワインは国産・輸入をウエイトで幾何平均。

## 手法
品目ごとに、log(実質の支出) を次で回帰（2015年1月〜2026年9月）：
- 12か月の月ダミー（季節）、直線のトレンド
- 2018年1月の家計簿改正の段差、2025年1月の収支項目分類改定の段差
- 2020年3月〜6月の各月ダミー（コロナの初期）
- その品目の出来事ごとに：k = −2, −1, 0, +1, +2 か月の1回限りのダミー（パルス）と、k ≥ 0 の段差（ステップ）
- 2019年10月の消費税にも同じパルスと段差
指標：
- 駆け込み F = パルス(−2) + パルス(−1)
- 反動 R = パルス(0) + パルス(+1) + パルス(+2)
- 定着 S = 段差（k ≥ 3 以降に残る水準の変化）
- 物価も同じ式（log 物価指数、段差だけ）で、出来事の段差 P を出す。弾力性 ε = S ÷ P
- 不確かさ：同じ品目で、出来事のない年の10月（例：たばこなら2016・2017・2022〜2025年）に偽の出来事を置いて同じ指標を出し、その分布（偽の出来事の数×品目）を偶然の幅とする。あわせて HAC 標準誤差。

## 仮説と「外れ」の基準
- H1 駆け込み：値上げ7件（T1〜T3、A1〜A2、W1〜W2）のうち5件以上で F > 0。4件以下なら外れ。
- H2 反動：F > 0 の値上げのうち半分以上で R ≤ −0.5×F（前の買いだめの半分以上が直後に戻る）。半分未満なら外れ。
- H3 定着：たばこ3件すべてで S < 0 かつ |ε| < 1（量は減るが値上げほどは減らない）。1件でも満たさなければ外れ。
- H4 入れ替わり：2020年と2023年の両方で、ビールの S > 0 かつ発泡酒・ビール風の S < 0。どちらかで満たさなければ外れ。
- H5 直後の前年比の読み違い：値上げ7件のうち4件以上で、値上げ月（k=0）の量の前年比の大きさが、k=+3〜+8 の前年比の平均の大きさの2倍以上。3件以下なら外れ。

## 頑健性（少なくとも3つ）
1. トレンドを2次にする
2. 推定からコロナの期間（2020年3月〜2021年9月）のうち出来事の窓に入らない月を外す
3. 実質化せず、名目の支出金額で同じことをする
4. パルスの窓を k = −3〜+3 にする
5. 推定の期間を2018年1月以降にする（家計簿改正の段差を使わない）

## 言えないこと（先に書いておく）
- 家計調査は二人以上の世帯の平均で、1つの店・ブランドの値上げとは違う（市場全体の動き）。
- 支出 ÷ 物価指数は量の近似。銘柄の入れ替え（高い銘柄から安い銘柄へ）も「量」に混ざる。
- 標本の世帯の入れ替わりによる月ごとの揺れがある。
