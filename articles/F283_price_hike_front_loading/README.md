# F283 値上げの前後で、売れ方はどう変わったか？ ― 税で日付の決まった値上げを家計調査の月の支出で追う

看板記事 F283（精選モード D. 求人票の業務 Q37）。たばこ税・酒税の改正で値上げ（と値下げ）の日がはっきりしている品目について、家計調査の月の支出を物価指数で割った「買われる量」の動きを、値上げの前（駆け込み）・その月から2か月（反動）・3か月目以降に残る変化（定着）に分けて測った。計画（PLAN.md、コミット 18e99ad）はデータの値を見る前に置いた。

## 誰が知りたいか
値上げを決める小売・メーカーの担当、販売計画や月次の数字の説明を受け持つ分析担当。「値上げした月の前年比が大きく落ちた」「前の月は大きく伸びた」をどう読めばよいか、値上げの影響は後にどれだけ残るのかを知りたい人。

## 問い
1. 値上げの前の月に、どれだけ前倒しで買われたか（駆け込み）
2. 前倒しの分は、値上げの月以降にどれだけ戻ったか（反動）
3. 落ち着いた後に、量の減りはどれだけ残ったか（定着）。値上げ幅に対する大きさ（弾力性）は
4. 同じ月に値下げされた品目（ビール）へ、買い物が移ったか
5. 値上げの月の前年比だけで判断すると、どれだけ読み違えるか

## 手法
- 品目ごとに log(実質の支出) を、月ダミー（季節）、直線のトレンド、2018年1月（家計簿改正）・2025年1月（収支項目分類改定）の段差、2020年3〜6月の各月ダミー、出来事ごとのパルス（k = −2〜+2 か月）と段差（k ≥ 0）で回帰した（HAC 標準誤差、ラグ3）。
- **駆け込み F** ＝ パルス(−2)＋パルス(−1)、**反動 R** ＝ パルス(0)＋(+1)＋(+2)、**定着 S** ＝ 段差（3か月目以降に残る水準の変化）。F と R は対数の差の合計なので、「ふだんの月の何か月分を前倒し・後ろ倒しにしたか」とおおよそ読める。
- 物価も同じ式（段差だけ）で出来事の段差 P を出し、弾力性 ε ＝ S ÷ P。
- **偶然の幅**：出来事のない年の10月に偽の出来事を置いて同じ指標を出した（5品目で計24個）。2017年10月と2024年10月は、2018年1月・2025年1月の段差と式の上で区別できないので使わなかった（計画からのずれ）。
- **値上げの月の前年比**：値上げの月（k=0）の量の前年同月比と、k = +3〜+8 の前年同月比の平均を比べた。

| 出来事 | 値上げの月 | 1か月後 | 2か月後 | R＋3×S |
|---|---|---|---|---|
| たばこ2018年 | −24.1% | −0.6% | −4.4% | −0.33 |
| たばこ2020年 | −30.7% | −13.2% | −3.7% | −0.55 |
| たばこ2021年 | −31.5% | −7.2% | −7.7% | −0.53 |
| 発泡酒・ビール風2020年 | −21.3% | −3.2% | +3.6% | −0.24 |

| ワイン2020年 | +6.9% | +12.6% | +14.6% | +0.32 |
| ワイン2023年 | −16.3% | −20.7% | −6.4% | −0.48 |

- 値上げの月以降はパルス＋段差（exp(p_k＋S)−1）。R＋3×S は値上げの月から3か月の、値上げ前の水準と比べた差の合計。
- H2 をこの物差し（R＋3S ≤ −0.5×F）で数えると、6件中4件（たばこ3件と発泡酒・ビール風2023年）。計画の判定（3/6）はそのまま残す。発泡酒・ビール風で「反動がほとんどない」のは、値上げで下がった水準を R に数えない定義によるところもある。

- 偶然の幅（偽の出来事24個の5〜95%）：F −0.35〜+0.32、R −0.61〜+0.31、S −0.150〜+0.107。偽の出来事のうち2022年10月のビールと発泡酒・ビール風は、税の改正はないのに物価指数が前月比 +6.0%・+8.5% 上がった月で、大きな駆け込みと反動が出ていた（下の「問い直し」）。この2つを除く19個では F −0.38〜+0.11、R −0.36〜+0.22、S −0.087〜+0.114。
- たばこ2018・2020年と発泡酒・ビール風2020年の駆け込み（0.47〜0.65）は、偶然の幅の上端（0.32）を大きく超える。たばこ2021年（0.29）と発泡酒・ビール風2023年（0.32）は上端の近くだが、2022年10月を除いた19個の上端（0.11）は超える。ワイン2020年（0.48）は、ワインだけの偽の出来事の F（−0.49〜+0.39）をやや上回る程度。
- 定着 S で偶然の幅（−0.150〜+0.107）の外にあるのは、発泡酒・ビール風2023年（−0.170）とビール2023年（+0.123）だけ。2020年のビール（+0.104）と発泡酒・ビール風（−0.059）は幅の中で、向きだけが2023年と同じ。

## 問い直し（結果を見た後に追加）
**税ではない値上げでも、同じ形になるか？** 偶然の幅を測るために置いた偽の出来事のうち、2022年10月のビールと発泡酒・ビール風だけ、大きな駆け込みと反動が出た。物価指数を見ると、この月はビールが前月比 +6.0%、発泡酒・ビール風が +8.5%、清酒も +6.4% 上がっていた（税の改正はない月）。そこで2022年10月を出来事として加えて測り直した。
| | 前の月 | 値上げの月 | 1か月後 | 駆け込み F | 反動 R | 定着 S | 物価の段差 P |
|---|---|---|---|---|---|---|---|
| ビール2022年10月 | +48% | −19% | −5% | 0.32 | −0.38 | +7.4%（+2〜+13） | +4.5% |
| 発泡酒・ビール風2022年10月 | +24% | −32% | −16% | 0.18 | −0.65 | −4.2%（−10〜+1） | +6.6% |

- 税ではない値上げでも、前の月に増えてその月に減る形が出た。ビールは前の月の上乗せ（+48%）が、たばこの税の値上げ（+35〜+49%）と同じくらい大きかった。
- 2022年10月を式に入れても、2020・2023年の発泡酒・ビール風の S（−0.055・−0.181）とビールの S（+0.103・+0.097）はほとんど変わらない。

## 言えないこと
- 家計調査は二人以上の世帯の平均で、1つの店・1つの商品の値上げとは違う。1つの店が値上げすると、客はほかの店へ移れるので、反応はここよりずっと大きくなりうる（推測）。
- 支出 ÷ 物価指数は量の近似。同じ品目の中で安い銘柄に移ると「量が減った」ように見える。たばこでは紙巻きと加熱式の入れ替わり、発泡酒・ビール風では新ジャンルから発泡酒への入れ替わりが混ざっている可能性がある（推測）。
- たばこの量が値上げの後に減らなかった（H3 外れ）のは、直線のトレンド（たばこは年 −5.2%）を除いた後の話。トレンドを入れないと、たばこの S は +0.033・+0.024・−0.096（2021年は減る）、発泡酒・ビール風 −0.117・−0.237、ビール +0.095・+0.113。条件を変えた5通りでは、たばこの S は −6.2%〜+12.1%（名目の支出で測った R3 では最大 +16.8%）。
- 2019年10月の消費税の段差がたばこ +0.133・発泡酒・ビール風 +0.128・清酒 +0.120（約 +13〜+14%）、2025年1月の分類改定の段差がたばこ +0.160 と、税が上がった後に量が増えたことになる不自然な値が出ている。これらの段差が、紙巻きと加熱式の入れ替わりやコロナ後の動きなどを吸い取っている可能性がある（推測）。たばこの「減りが見えない」は、この式の上での結果として読む。
- 弾力性 ε は、物価の段差 P が小さいワイン2020年・清酒では意味のある値にならない。また P は月ダミーとトレンドを入れた式の段差で、値上げの月の物価の前月比とは少し違う（発泡酒・ビール風2020年は前月比 +8.7% に対して P は +4.6%）。前月比で割ると発泡酒・ビール風の ε は −0.7（2020年）・−2.0（2023年）。
- 家計調査の世帯の入れ替わりで、月の値は揺れる。偶然の幅（偽の出来事24個）はこの揺れの目安だが、品目によって揺れの大きさが違う（ワインは大きい）。
- 2020年10月は、コロナで家で飲む量が増えていた時期と重なる。月ダミーとトレンドだけでは取りきれていない可能性がある（推測）。
- 2026年10月にも酒税の改正（ビール系の税の一本化）があったが、2026年10月の家計調査はまだ公表されていない（2026年11月時点）。

## 計画からのずれ
- 偽の出来事から2017年10月と2024年10月を外した（家計簿改正・収支項目分類改定の段差と式の上で同じになるため）。PLAN には書いていなかった。
- コロナの期間を除く確かめ（R2）で、最初は2021年10月の前後の月も外していたので、出来事の前後2か月は残すように直した。
- レビューで、それでも R2 のたばこは計画行列の階数が足りない（2020年10月と2021年10月の窓の間に月がなく、2つの段差が区別できない）と分かったので、2021年6〜7月も残すように直した（R2 のたばこの S は +0.084・+0.096・+0.001 に変わり、判定は同じ）。
- レビューを受けて、値上げ前の水準と比べた値（図2を差し替え）、トレンドなしの S、各段差の値、前年比の比べる月を results/review_checks.json に足した。
- 2025年以降の「発泡酒」（符号 3X7）の1行は、名前が変わっていて最初の取得で抜けていたため、取り直した。このときこの1行の値が目に入った（PLAN に記載）。
- 問い直し（2022年10月）は、結果を見た後に足した。
- 弾力性は、物価の段差が小さい出来事でも機械的に計算した（表の「—」や括弧で注記）。

## 外に出すなら
Zenn か Qiita に「値上げの影響を月次で読む：駆け込み・反動・定着をパルスと段差の回帰で分ける（statsmodels）」として手法だけを書く。月次の販売データを持つ人がそのまま使える形にする（投稿はしていない）。

## レビューで直したこと
独立レビュー（別の担当が記事・README・コードを確かめた）で、数字の再計算は一致し、判定は計画どおりだった。指摘と直したことは次のとおり。

| 重さ | 指摘 | 直したこと |
|---|---|---|
| 高 | 「たばこは減りが残らない」は直線のトレンドに頼っている | 「直線のトレンドを除いた後では減りが見えなかった」に限定し、トレンドなしの S と、消費税・分類改定の段差の不自然な値を「言えないこと」に書いた。題も直した |
| 高 | k ≥ 0 のパルスは値上げ後の水準と比べた値 | 値上げ前の水準と比べた値の表を足し、図2を差し替えた。R＋3S で数えると H2 は 4/6 になることを並べ、計画の判定（3/6）は残した |
| 中 | 前年比の比べる前年の月が、ほかの出来事の月だった | 比べる月を明記し、H5 の4件のうち2件（ワイン）がこの影響を受けることを書いた |
| 中 | 2022年10月を除いた偶然の幅を本文でも使う | 19個の幅（F の上端 0.11）を並べ、たばこ2021年・発泡酒・ビール風2023年がそれを超えることを書いた |
| 中 | ワイン2020年が「幅を大きく超える」は言いすぎ | ワインだけの幅（−0.49〜+0.39）をやや上回る程度、に弱めた |
| 中 | R2 のたばこは計画行列の階数が足りなかった | 2021年6〜7月を残す窓に直し、全条件・全品目で階数を確かめた |
| 低 | 「−6%〜+15%」は対数の値で、上端は名目 | −6.2%〜+12.1%（名目の R3 では最大 +16.8%）に直した |
| 低 | 弾力性「約 −2」の測り方 | −2.3（式の段差で割る）と −2.0（前月比で割る）を書き分けた |
| 低 | H2 がたばこだけで成り立つこと | 判定の欄に書いた |
