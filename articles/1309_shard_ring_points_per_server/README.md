# 1309 その輪の上に1台を何か所に分けて置くかで、いちばん多い1台の受け持ちはどれだけ平均に近づくのか？（データの振り分け）

「輪の上に並べる振り分け」では、データは輪を時計回りに進んで最初に出会う台に置かれます。1台を輪の上に1か所だけ置くと、台どうしの間隔がそろわず、受け持ちが台ごとに大きく違います（1308）。そこで、1台を輪の上の何か所にも分けて置き、短い区間をたくさん受け持たせると、区間の長さのでこぼこが打ち消し合って、受け持ちの合計は平均に近づきます。では、何か所に分ければどこまで近づくのか。**ここでは、作成者が置いた架空のアプリのデータ10万件を10台に置き、1台を輪の上に置く場所の数を1〜1,000か所の10通りに変えて、いちばん多い1台÷平均を、台の位置を作り直して1,000回ずつ数えました。比べとして、輪を使わず1件ずつ乱数で台を決めたときの値（データの件数で決まる下限の目安）も出しました。1台足したときに、どの台から何台分のデータが動くかも数えました。台数（10・50・100台）とデータの件数（1万・10万・100万件）を変えた9通りでも確かめました。実機では測っていません。**

例のアプリ・数は架空のもので、実在のデータベース・機械を表すものではありません。台数や費用の見込みの助言はしていません。

関連する記事：1308「動くデータを少なくする振り分け（番号を輪の上に並べて、時計回りに次の台へ置く形）で1台足すと、動く量は少なくなっても、台ごとの受け持ちの量はどれだけばらつくのか？」は、この記事の1台1か所の場合を扱い、1台足しても、いちばん多い1台が軽くならない回が多いことを数えています。1305「1万件のデータを乱数で10台に振り分けると、いちばん多い1台の件数は平均の何倍になるのか？」は、この記事で下限の目安として使った「1件ずつ乱数で置く」形の偏りを扱っています。1306「データの件数を変えずに、振り分ける台数を10台から100台に増やすと、いちばん多い1台と平均の比はどう広がるのか？」は、1台あたりの件数が減ると比が広がることを扱っています。1314「1台が止まって、輪の上で次の台がその分をまるごと受け持つと、受け持つ台の量は平均の何倍になるのか？」は、1台が止まったとき、1台を輪の上の何か所に分けて置くかで、止まった台の分がどれだけ多くの台に散るかを扱っています。この記事は、輪の上に置く場所の数を増やしたときの近づき方と、どこで頭打ちになるかに絞ります。

| 100か所 | **1.1639倍** | 1.0984〜1.2428倍 | 1.163倍 | 0.8486倍 | 0.0939 |
| 200か所 | 1.1132倍 | 1.071〜1.1612倍 | 1.1117倍 | 0.8922倍 | 0.0662 |

- いちばん多い1台÷平均は、1か所の2.9801倍から、100か所で1.1639倍、1,000か所で1.0503倍へと平均に近づいた
- **置く場所を10倍にするごとに、平均を超える分（いちばん多い1台÷平均−1）は3.67分の1（1→10か所）、3.29分の1（10→100か所）、3.26分の1（100→1,000か所）にしか縮まなかった**。平均の1.5倍以内には20か所、1.2倍以内には100か所、1.1倍以内には500か所が要り、1.05倍以内には1,000か所でも届かなかった（1.0503倍）
- 10万件・10台では、件数で数えた値と輪の長さで数えた値の差は1,000か所でも0.0018だった。ばらつきのほとんどは輪の上の区間の長さのでこぼこから来ていて、1件ずつ乱数で置いたときの1.0155倍には、1,000か所でもまだ届かなかった
- 1回分の例（図2、`data/example_counts.csv`）では、いちばん多い1台といちばん少ない1台は、1か所で30,202件と79件、10か所で18,798件と4,180件、100か所で10,941件と8,864件だった

### 1台足したとき（10台→11台、各1,000回、`results/by_points.csv`）
| 1台の置き場所 | 動いた割合（平均） | 10〜90%の範囲 | データを渡した台の数（平均） | 渡した量のうち、いちばん多い台の割合 | 足したあとのいちばん多い1台÷平均 |
|---|---|---|---|---|---|
| 1か所 | 8.963% | 0.929〜20.531% | 1.0台 | 100.0% | 3.0533倍 |
| 10か所 | 9.158% | 6.066〜12.735% | 6.35台 | 39.13% | 1.547倍 |
| 100か所 | 9.123% | 8.075〜10.292% | 10.0台 | 18.03% | 1.168倍 |
| 1,000か所 | 9.084% | 8.741〜9.447% | 10.0台 | 12.37% | 1.0527倍 |

- 動いた割合の平均は、どの置き場所の数でも1÷11（9.091%）の近くだった。置く場所を増やすと、1回ごとの散らばりが狭まり（1,000か所で8.741〜9.447%）、データを渡す台が1台から10台すべてに広がった

### 確かめ：9通り（各300回、`results/grid.csv`・`results/grid_summary.csv`）
- いちばん多い1台÷平均は、1か所で2.9504〜5.2658倍、100か所で1.1574〜1.3827倍、1,000か所で1.0507〜1.2709倍だった。台数が多いほど、同じ置き場所の数でも平均から離れた
- 1件ずつ乱数で置いたときの値（下限の目安）は、9通りで1.0049〜1.2592倍だった。1,000か所の値は、9通りすべてでこの下限の目安より0.0117〜0.0605上だった
- **9通りのうち3通り（50台・1万件、100台・1万件、100台・10万件）では、1,000か所でも1.1倍以内に入らなかった**。50台・1万件では、1件ずつ乱数で置いても1.1644倍で、1,000か所の1.1782倍との差は0.0138だった。1台あたりのデータが少ないと、置く場所をいくら増やしても、件数の振れで決まる下限より下がらない（図3）
