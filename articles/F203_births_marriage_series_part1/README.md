# F203 出生率が下がったのは、結婚が減ったからか、夫婦の子どもが減ったからか？（シリーズB「出生と結婚」前編）

## 問い
出生率の低下は、「結婚している人の割合（有配偶の割合）」が下がったからか、「結婚している人が産む数（有配偶の女性の出生率）」が下がったからか。
結婚の時期が遅れた分は、あとで取り戻されたのか。地域の差は、結婚と夫婦のどちらから来ているのか。

後編（F204）では、出生の順番ごとの支援策の効果、2040年までのシナリオ、データで言えること・言えないことを扱う。

## 結論（要点）
- **全国（1970→2020年）**：合計特殊出生率（TFR）は 2.13 → 1.33（−0.81）。このうち「有配偶の割合が下がった分」が **−1.29**、「有配偶の女性の出生率が上がった分」が **+0.48**。結婚の要因だけなら下げ幅の約1.6倍下がっていたところを、夫婦の出生率の上昇が一部押し戻した形。
  - 1990→2020年：−0.21 ＝ 結婚 −0.68 ＋ 夫婦 +0.46。2010→2020年：−0.06 ＝ 結婚 −0.16 ＋ 夫婦 +0.10。
  - 2015→2020年だけは、結婚（−0.07）と夫婦（−0.05）の両方がマイナスだった。
  - 有配偶の割合だけを2025年の値にすると（夫婦の出生率は2020年のまま）、TFR は 1.33 → 1.21。
- **生まれ年（1932〜1974年生まれ）**：30歳までに産んだ数は 1.65 → 0.80、49歳までの数は 2.04 → 1.45。30歳までに減った分のうち、31歳以降に取り戻されたのは **約30%**（条件を変えると 7〜30%）。
  - 1951〜55年生まれ → 1971〜74年生まれで最終の子どもの数は −0.57。うち 45〜49歳で未婚の人が増えた分が −0.25、結婚した人1人あたりの数が減った分が −0.32。
- **地域（2018〜22年の出生率、2020年の国勢調査）**：出生率の地域差（対数のばらつき）のうち、有配偶の割合の違いで説明できる分は、**都道府県で 46%、市区町村で 58〜85%（数え方による。中心は約7割）**。

## 手法
- **時系列の分解**：TFR ＝ 5 × Σ年齢（有配偶の割合 m × 有配偶の女性の出生率 g）。g ＝ 年齢別出生率 ÷ m（婚外の出生は小さいので全部を有配偶とみなす。頑健性で確かめる）。2時点の差を、m の変化分と g の変化分に対称に分ける（Kitagawa の分解）。
- **生まれ年**：30歳までの累積出生と49歳までの累積出生を、生まれ年の間で回帰する。傾きが1なら「30歳までに減った分はそのまま最終の数も減る」、0なら「全部取り戻す」。取り戻した割合＝1−傾き。
- **地域**：全国の g（2018〜22年）を各地域の有配偶の割合に当てはめた「結婚だけで決まる TFR」（E）をつくり、TFR／全国 ＝（E／全国）×（TFR／E）と分ける。前を「結婚の要因」、後を「夫婦の要因」とし、対数の分散を2つに分ける（共分散は半分ずつ）。

## 頑健性
1. **時系列**：婚外の出生の割合（0・2.5・5%）× 定義（有配偶か、結婚経験か）× 年齢の範囲（15〜49・20〜39歳）× 始点（1970・1990・2010年）の36通りで、結婚の要因はいつも下げ幅より大きかった（下げ幅に対して 1970年から 133〜160%、1990年から 226〜318%、2010年から 199〜292%）。分解の重みを始点だけ・終点だけにしても −1.22〜−1.35（1970→2020年）。
2. **生まれ年**：基準の年齢（28・30・32歳）× 終わりの年齢（45・49歳）× 生まれ年の範囲（1932・1945・1955年以降）の18通りで、取り戻した割合は 7〜30%。1955年以降の生まれだけだと 7〜21% で、最近の生まれ年ほど取り戻しが小さい。
3. **地域**：都道府県は 46〜54%（定義・年齢の範囲）。市区町村はベイズ推定値で 72%、素の出生率で 58%、素の出生率を自前で縮小すると 73%、女性15〜49歳が5千人以上の764市区町村で 63〜69%、女性の数で重みをつけると 81〜90%。
4. **小さい分母**：ベイズ推定値は保健所・都道府県の値へ寄せてあるため、結婚の要因と夫婦の要因に見かけの負の相関（−0.53）が出た。素の出生率では −0.07、素の出生率を出生数のポアソン分散で自前に縮小すると 0.01。自前の縮小では、女性1千人未満の町の縮小の強さ（残す割合）の中央値は 0.29、3万人以上は 0.98。

## 言えないこと
- **因果ではない**：分解は「どちらの数字が動いたか」の会計で、なぜ結婚が減ったか、なぜ夫婦の出生率が上がったかは示さない。
- **夫婦の出生率の上昇は「夫婦が多く産むようになった」とは限らない**：結婚する人が減ると、子どもを持ちたい人ほど結婚している割合が高くなる（選ばれ方）。結婚の時期が遅れ、30代で産む人が増えたことも 30〜34歳の率を押し上げている。
- **期間と生まれ年の違い**：期間の TFR は、結婚や出産の時期の遅れ（テンポ）の影響を受ける（F58）。
- **地域の分解は全国の夫婦の出生率を当てはめた近似**：地域の夫婦の要因には、年齢構成の細かな違い・婚外の出生・移動（出産の前後で引っ越す）も入る。
- **生まれ年の結婚経験の割合は粗い**：国勢調査の45〜49歳の未婚割合を5年分の生まれ年にまとめて当てたもの。
- 2025年の見込みは「夫婦の出生率が2020年のまま」の仮定の計算で、予測ではない。
