# F257 労働経済白書の「賃上げが広がった」は、どのデータでどこまで言えるのか？

看板記事 F257（精選モード、B. 白書・審議会）。「賃上げが波及した・広がった」という言い方を **広さ・追いつき・パートへの届き方** の3つに分けて、毎月勤労統計・賃金引上げ等の実態に関する調査・最低賃金で確かめた。計画（[PLAN.md](PLAN.md)）はデータを見る前に書いて先にコミットした。

- note：（公開後に記入）
- シリーズの関連：141（賃上げ率の推移）、087（実質賃金）、F66（統計の段差）、F156（最低賃金の効き方の差）。この記事は「率がいくつか」ではなく「どこまで届いたか」を見る。

## 問い
厚生労働省「令和8年版 労働経済の分析」第Ⅰ部第3章は、2025年の賃上げについて、幅広い事業所規模・産業に広がり、最低賃金の引上げがパートの時給上昇の一因になったと述べている。
「広がった」には少なくとも次の3つの意味がある。それぞれ、公表データでどこまで言えるのか。

1. **広さ**：多くの産業で上がったか
2. **追いつき**：小さい企業・事業所の伸びが大きいところに追いついたか
3. **パートへの届き方**：パートの時給の伸びは、最低賃金の伸びでどこまで説明できるか

## データ
- 厚生労働省「毎月勤労統計調査」全国調査 実数・指数の累積データ（e-Stat、年平均、2000〜2025年）。16大産業、事業所規模4区分（500人以上・100〜499人・30〜99人・5〜29人）、就業形態（一般・パート）
- 厚生労働省「賃金引上げ等の実態に関する調査」時系列表：企業規模別の1人あたり賃金の改定率、引き上げた企業の割合（141 のデータを再利用）
- 地域別最低賃金の全国加重平均（2007〜2025年度、F156 と同じ値）。10月に改定されるので、暦年の値は「前年度の額×3/4＋その年度の額×1/4」とした

## 手法
- H1 広さ：一般労働者の所定内給与（公表の前年比）が+1%・+2%・+3%以上の産業の割合を年ごとに数え、2024〜25年と2015〜19年平均を比べる
- H2 追いつき：規模別の伸び（実数から計算）の差「500人以上−5〜29人」と、水準の比「5〜29人÷500人以上」。企業規模の改定率の差「5,000人以上−100〜299人」でも確かめる
- H3 パート：パートの1時間あたり所定内給与の前年比を、最低賃金の前年比に回帰（2010〜2025年、16年、HC1 の標準誤差）
- 再問い：パートの時給が最低賃金に近い（倍率が低い）産業・規模ほど、2022→2025年の伸びが大きかったか（順位相関）

## 結果
| 仮説 | 結果 | 判定（PLAN の基準） |
|---|---|---|
| H1 広さ | +2%以上の産業の割合：2015〜19年平均15.0% → 2024〜25年71.9%（2025年は16産業のうち12） | 支持（外れの基準に当たらない） |
| H2 追いつき（一般） | 5〜29人の伸びは2024年1.9%・2025年1.9%で、500人以上（2.6%・2.4%）より小さい。水準の比は2019年78.0%→2025年76.9% | 支持（追いついていない） |
| H2 追いつき（パート時給） | 5〜29人が2年続けて上回り（2024年5.0%対2.6%など）、水準の比は2022年81.5%→2025年84.8% | 外れ（パートでは追いついた） |
| H2 企業規模 | 改定率の差（5,000人以上−100〜299人）：2015〜19年平均0.28pt → 2023〜25年平均1.23pt（2025年は5.1%対3.6%） | 支持（差は広がった） |
| H3 パート | 傾き0.88（95%区間0.63〜1.13）、R² 0.62。2016→2025年でパート時給+28%、最低賃金+33% | 支持（ただし下の頑健性を参照） |

- 広さ（H1）：2025年に+2%に届かなかったのは建設業（+0.1%）、運輸・郵便（+0.5%）、学術研究（+0.5%）、教育（+1.9%）。前年比がプラスの産業は2025年に16産業すべて。
- 追いつき（H2）：「全規模で増加」は正しいが、一般労働者では小さい事業所の伸びのほうが小さく、差は縮んでいない。パートの時給だけは小さい事業所が速く上がった。
- パート（H3）：パートの時給は最低賃金とほぼ1対1に近く動く。ただし水準は最低賃金の1.42倍（2010年）→1.30倍（2025年）と、最低賃金に近づいている。
- 再問い：2022年に最低賃金に近かった産業ほど、2022→2025年の伸びがやや大きい（16産業の順位相関 −0.43、p=0.09。パートの少ない3産業を除くと −0.56、p=0.05）。規模では4区分きれいに並ぶ（5〜29人 +12.6% … 500人以上 +8.2%）。最低賃金（+14.3%）を超えたのは卸売・小売だけ。

## 頑健性
| チェック | 結果 |
|---|---|
| 閾値1%・2%・3%（H1） | 2015〜19年平均 → 2024〜25年：37.5%→78.1%、15.0%→71.9%、6.3%→40.6%。どれも大きく上 |
| 基準期間を2010〜19年（H1・H2） | H1：+2%以上は10.4%→71.9%。H2：一般の伸びの差は2010〜19年平均−0.06pt→2023〜25年+0.37pt |
| 雇用で重みづけ（H1、参考） | +2%以上の割合 9.6%→75.5% |
| 月額と1時間あたり（H1・H2） | H1：時給でも+2%以上は23.8%→75.0%。H2：一般の時給でも差は2023〜25年+0.53pt（大きいほうが上）、水準の比は2019年72.3%→2025年72.0% |
| 規模の2つの資料（H2） | 事業所規模（毎月勤労統計）でも企業規模（賃金引上げ等の実態調査）でも、一般・正社員側は「追いついていない」 |
| コロナの年を除く（H3） | 傾き0.98、R² 0.82（14年） |
| 最低賃金の時点の合わせ方（H3） | 前年度の額との比較（1年遅れ）：傾き0.88、R² 0.68。**同じ年度の額と合わせると傾き0.41、R² 0.22 で外れの基準に当たる**。10月改定なので、暦年平均の大半は前年度の額で決まる。時点を合わせないと関係が見えにくくなる |
| 2015年以降だけ（H3） | 傾き0.69、R² 0.53 |

## 言えないこと
- **因果は分からない**。大企業の賃上げが中小に「波及した」のか、同じ人手不足と物価高で同時に上がったのかは、この集計では分けられない。
- 規模別の伸びは実数から計算したので、毎月勤労統計の調査対象の入れ替え（毎年1月）による段差が入る（F66）。公表の前年比は規模別には出ていない。
- 産業の割合は16産業を1つずつ数えたもので、1産業で6.25ポイント動く。鉱業（2025年+19.0%）のように対象が小さい産業は振れが大きい。
- パートの時給の伸びには、短い時間で働く人の割合の変化（構成）が入る。1人ひとりの時給の伸びではない。
- 再問いは16産業と4規模の比較で、数が少ない。p 値は0.05〜0.1の境目で、強い結論ではない。
- 白書は四半期・月次や別の統計（賃金構造基本統計調査など）も使っている。この記事は年平均の公表データだけで確かめたもので、白書の分析そのものの再現ではない。

## 計画からのずれ
- H3 の最低賃金の時点の合わせ方は PLAN に書いていなかった。暦年に直した値を本命とし、同じ年度・1年遅れを頑健性に加えた（同じ年度では外れの基準に当たることも書いた）。
- H1 の雇用での重みづけ、H2 の時給版、H3 の2015年以降は、PLAN に加えて出した。
- H2 は PLAN では1つの判定だったが、結果が一般とパートで逆だったので分けて書いた。
- 再問い（最低賃金への近さと伸び）は、結果を見てから加えた。

## レビューで直したこと
精選モードでは、作業を見ていない別のエージェントに読み直してもらう決まりだが、この記事は分岐した作業の中で書いたため、新しいエージェントを立ち上げられなかった。代わりに次の点を自分で確かめ直した。
- 別の空のフォルダで全スクリプトを流し直し、main.json・reask.json・主な CSV がバイト単位で一致した。
- 手計算の確認：2025年の+2%以上の産業 12/16=75%、パート時給 1,394円÷1,085円−1=+28.5%、最低賃金（暦年）2022→2025年 +14.3%。
- 言い過ぎの修正：H3 を「最低賃金で説明できる」とだけ書くと、時点の合わせ方しだいで外れることを隠すので、頑健性の表と本文に明記した。図4の見出し「2022年から下がり」を「2023年から下がり」に直した（2022年77.7%、2023年77.9%）。再問いの図の見出しは「少し速く」にとどめた。
- 図6でラベルが重なっていた4か所（不動産と5〜29人、鉱業と運輸・郵便など）をずらした。図4の年の目盛りを整数にした。
