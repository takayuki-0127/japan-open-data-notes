# 169 外国人労働者が多い産業は、10年で入れ替わったのか

厚生労働省「『外国人雇用状況』の届出状況まとめ」の参考表（外国人労働者数（産業別）の推移）から、2016〜2025年（各年10月末）の産業別の外国人労働者数を取り出し、構成比と伸びを比べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A169 | 外国人労働者が多い産業は、10年で入れ替わったのか | 産業別（公表の9区分）の構成比の推移、2016年と2025年の順位・構成比・倍率の比較 | `src/a169_share.py` |

## 主な結果
- 外国人労働者数は 2016年 108.4万人 → 2025年 257.1万人（2.37倍）
- 製造業は10年とも1位だが、構成比は31.2% → 24.7%（−6.5ポイント）。人数は1.9倍
- 構成比が上がったのは建設業（3.8% → 8.0%、5.0倍）と医療・福祉（1.6% → 5.7%、8.4倍）。順位は建設業が8位→6位、医療・福祉が9位→7位
- サービス業（他に分類されないもの）、卸売・小売、宿泊・飲食は12〜15%台でほぼ横ばい
- 教育・学習支援は5.5% → 3.2%（6位→9位）
- 上位5区分（製造業・サービス業・その他・卸売小売・宿泊飲食）の顔ぶれは変わらず、大きな入れ替わりは見られない

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a169_share.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/workers_by_industry_2016_2025.csv | 産業別外国人労働者数（人、各年10月末）。2016〜2020年は令和2年10月末の、2021〜2025年は令和7年10月末の届出状況表一覧（Excel）の「参考-6」から |

- 令和7年10月末：https://www.mhlw.go.jp/stf/newpage_68794.html（別添3 Excel）
- 令和2年10月末：https://www.mhlw.go.jp/stf/newpage_16279.html（国立国会図書館 WARP に保存されたページの別添3 Excel）

## 注意
- 事業主からの届出の集計で、特別永住者や「外交」「公用」の在留資格は含まない
- 産業分類は2020年までが日本標準産業分類（平成25年改定）、2021年以降は表注で令和5年改定に対応。9区分の大きな範囲は同じ
- 「その他」は農業・林業、運輸業・郵便業などをまとめた区分で、中身は分けられない
- 元の Excel は Web ブラウザ上で読み取り、必要な値を CSV に書き写した
