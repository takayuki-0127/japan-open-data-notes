# 510 同じ検証データで2つのモデルの成績を比べると、本当は同じ力でも、何%の回で「片方が良い」と出るのか

2つのモデルを同じ検証データで比べ、正解率の高いほうを選ぶことがよくあります。**本当は同じ力（どちらも正解率80%）のモデルと、少しだけ差のある（81%と80%）モデルの架空の予測を作り、検証データの件数を100〜20,000件に変えて各2,000回作り直し、「片方が上に出る」割合と、差の95%区間（ブートストラップ）で「差がある」と出る割合を、対応のある比べと対応のない比べで数えました。** 数字は置いた設定で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A510 | 同じ力の2つのモデルで、上下が付く割合・「差がある」と出る割合はどれだけか。小さな差を見分けるには何件要るか | 1件ごとの難しさ u ~ N(0,1)、モデルが当たるのは u + e > c（e ~ N(0, 0.6²)、A と B で独立）。2つのモデルの当たり外れの一致は約84%、相関0.49。差の区間は、対応あり（1件ごとの組を引き直す）と対応なし（A と B を別々に引き直す）のブートストラップ1,000回。McNemar 検定も併記 | `src/a510_same_validation.py` |

## 主な結果
- **同じ力、検証1,000件**：同点は3.3%だけで、96.7%の回でどちらかが上に出る。1ポイント以上の差が出る回が46.2%、2ポイント以上が12.1%
- **同じ力で「差がある」と出る割合**：対応のある区間で4.4〜5.7%（件数によらずほぼ5%）、McNemar 検定で2.8〜4.7%、対応のない区間では0.4〜0.7%
- **1ポイント以上の差が出る割合**は、100件で90.6%、500件で62.6%、2,000件で26.8%、10,000件で1.5%
- **少し差（81%と80%）**：弱いほうが上に出る割合は、100件で35.9%、1,000件で20.6%、5,000件で3.7%
- **少し差を「差がある」と見分ける割合**：対応のある区間で、1,000件13.0%、5,000件41.8%、10,000件69.6%、20,000件93.8%。8割の回で見分けるには約14,300件（線形補間）。対応のない区間では20,000件でも77.2%

## 動かし方
```
pip install -r requirements.txt
cd src && python a510_same_validation.py
```

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- 対応のある区間の「差がある」割合と McNemar 検定の割合が近いこと

## データ
- `results/reps.csv`：各回の正解率・差・判定（32,000行）。データファイルは置いていない（seed 510）

## 注意（言えないこと）
- 架空の設定。2つのモデルの当たり外れがどれだけそろうか（ここでは一致84%）で、必要な件数は大きく変わる。そろうほど、対応のある比べは少ない件数で差を見分けられる
- 正解率だけを比べた。ほかの物差し（AUC など）では数字が変わる
- 検証データを何度も使ってモデルを選ぶと、選んだモデルの成績は甘く出る。ここではその影響は扱っていない
- どちらのモデルを使うべきかを勧めるものではない
