# 1241 分類の決まりを途中で書き直すと、前に付けた件とあとで付けた件で何がずれるのか？（ラベル付け）

問い合わせ文に分類のラベルを付けていると、途中で「この種類の文は、これからはこちらの分類にする」と決まりを書き直すことがあります。書き直す前に付けた件は古い決まり、あとの件は新しい決まりで付いているので、同じ中身の文に違う分類が付いたまま1つのデータにまざります。付け手が新しい決まりに慣れるまでの週は、両方がまざります。慣れるころには、書き直していない似た文にまで新しい分類を付けすぎることもあります。**ここでは、作成者が置いた架空の問い合わせ文（中身の種類とその割合を作成者が置き、16週のあいだ中身は変えない。9週目から「返品して別の品に替えたい」という境目の文を「返品」から「交換」に書き直し、付け手の慣れ方と付けすぎを置いて、乱数で判定を作ったもの）で、週ごとの「交換」の割合がどう動くか、付いた分類から作った分類する仕組みが新しい決まりでどれだけ当たるか、16週からでたらめに取ったテストの件で当たりを数えるとどう見えるかを数えました。境目の文の割合・付け手の慣れ方・書き直す週を変えた27通りでも確かめました。**

例の問い合わせ文・分類・決まりは架空のもので、実在の作業やサービスを表すものではありません。付け手を人の属性で比べていません。決まりをいつ・どう書き直すべきかの助言はしていません。

関連する記事：848「計測の仕様が月の途中で変わったとき、前月比はどうなるのか？」と 1004「「過去最高の来場」は、数え方を変えた年と比べられるのか？」は、数え方が途中で変わると、前後の数字が同じ物差しで比べられなくなることを扱っています。この記事は、ラベルの決まりの書き直しで、同じ中身の件に違う分類が付いたまま1つのデータにまざり、そのデータから作った仕組みとその成績の数え方にまでずれが残る点に絞ります。542（問い合わせの分類を2人が別々に付けたときの食い違い）は、同じ時期に2人が付けた分類の食い違いを扱っています。759「正解のラベルが1割まちがっていると、モデルの正解率はどれだけ低く見えるのか？」は、テストの件のラベルのまちがいで成績が低く見えることを扱っていて、ラベルのまちがいが学習の件に入る話は扱っていません。この記事では、まちがいではなく決まりの違いが学習の件とテストの件の両方に入ります。同じ企画の 1236「付け手が疲れて後半ほど判定がゆるむと、付けた順番で何がまざるのか？」は、書き直しではなく、付け手の基準が1日の後半ほどゆるむとき、付けた順番の分が製品の差にまざることを扱っています。

## 主な結果

### 週ごとの「交換」の割合（200回、`results/weekly_exchange_share.csv`）
| | 200回の平均 | 式 |
|---|---|---|
| 1〜8週目の平均 | 12.71% | 12.69% |
| 8週目 | 12.72% | |
| 9週目（書き直した週） | 16.38% | 16.34% |
| 12〜16週目の平均 | 18.67% | 18.61% |
| 8週目→9週目の上がり | 3.66ポイント | 3.64ポイント |
| 1〜8週目→12〜16週目の上がり | **5.96ポイント** | 5.91ポイント |

- **中身は16週同じなのに、「交換」の割合は12.71%から18.67%へ段になって上がった。** 上がった分は、置いた境目の件の割合（6%）と、似た件への付けすぎでほぼ決まる（作りどおり）
- 書き直した週とその前の週だけを比べると、上がりは慣れたあとの0.6141倍（3.66ポイント）にとどまった。付け手が慣れるまでの週は、古い決まりと新しい決まりがまざる
- 返品に似た件に交換が付いた割合は、書き直し前1.94%、書き直し後の8週で8.48%だった。書き直していない件にもずれが広がった

### 学習の件の作り方と、新しい決まりでの当たり（200回、`results/train_variants.csv`）
| 学習に使った件 | 返品・交換の件全体の当たり | 境目の件を「交換」と当てた割合 | 返品に似た件を「返品」と当てた割合 |
|---|---|---|---|
| 書き直し前の8週だけ | 83.53% | 17.48% | 98.33% |
| **16週すべて** | **87.22%** | **33.36%**（10〜90%：26.74〜40.41%） | 94.7% |
| 書き直し後の8週だけ | 90.84% | 69.92% | 74.54% |
| 書き直し後の最初の3週を除く | 90.77% | 74.04% | 70.18% |
| 前の「返品」を見直して16週 | 90.87% | 70.11% | 74.47% |
| （比べる相手）16週とも新しい決まりなら | 90.9% | 72.53% | 72.22% |

- **16週すべての件で作った仕組みは、境目の件を33.36%しか交換と当てなかった。** 16週のうち8週は古い決まりで、書き直し後にも慣れるまでの週があるため、学習の件の境目の件には返品の付いたものが多く、引いた境目が古い決まりの側に寄った
- 書き直し後の件だけ、または前の件を見直して付け直した件で作ると、16週とも新しい決まりで付いていた場合（72.53%）に近い69.92%・70.11%まで戻った
- 16週とも新しい決まりでも境目の件の当たりが72.53%にとどまるのは、置いた見た目の値で境目の件と返品に似た件が重なっていて、1本の境目では両方を当てきれないため（置き方による）。書き直し後の最初の3週を除くと境目の件は74.04%に上がったが、付けすぎの分で境目が返品の側に寄り、返品に似た件の当たりは70.18%に下がった

### 16週からでたらめに取ったテストの件で数えると（200回、`results/a1241_main.json` の `mixed_test`）
| 16週すべてで作った仕組みの当たり | 付いた分類と比べる | 新しい決まりの正解と比べる |
|---|---|---|
| 返品・交換の件全体 | 88.95% | 87.26% |
| 境目の件 | **51.7%** | **33.41%** |

- テストの件にも古い決まりの分類がまざっているので、付いた分類と比べると、境目の件の当たりは新しい決まりより18.29ポイント高い51.7%に見えた。全体でも1.69ポイント高く見えた

### 確かめ：27通り（各100回、`results/grid.csv`）
- 16週すべてで作った仕組みの境目の件の当たりは、13.24〜72.66%と大きく動いた。書き直す週で決まり、5週目からなら40.77〜72.66%、9週目からなら21.79〜36.45%、13週目からなら13.24〜28%。どの置き方でも、前の件を見直して付け直すと上がった（50.63〜85.24%）
- 16週とも新しい決まりだった場合との全体の当たりの差は、0.17〜17.11ポイント。境目の件が多く、書き直しが遅いほど大きかった
- テストの件で付いた分類と比べた当たりが、新しい決まりの当たりより高く見えたのは27通り中17通り（9週目・13週目に書き直した置き方）。5週目から書き直した9通りでは、逆に低く見えた。差は−4.34〜+17.46ポイント
- 書き直した週とその前の週の上がりは、慣れたあとの上がりの0.2609〜1.1987倍。付け手がすぐ慣れる置き方では1.0384〜1.1987倍（書き直した週の付けすぎが多い分だけ1倍を超える）、基本では0.5595〜0.8143倍、ゆっくりでは0.2609〜0.6761倍だった。ゆっくり慣れて13週目に書き直す置き方では、16週目までに慣れきらない

## 注意（言えないこと）
- 架空のデータと、作成者が置いた慣れ方・付けすぎ・見た目の値です。とくに16週すべてで作った仕組みの当たりは、新しい決まりで付いた件が学習の件の何割かでほぼ決まります
- 分類する仕組みは、1つの見た目の値に1本の境目を引くだけの簡単なものと置きました。実際の仕組みでは、境目の件を見分ける手がかりが別にあれば、ずれ方は変わります
- 前の件の見直しは、境目の件を90%で見つけると置きました。見直しにかかる手間は数えていません
- 中身の割合は16週同じと置きました。本当に中身が変わった分と、決まりの書き直しの分が重なる場合は扱っていません
