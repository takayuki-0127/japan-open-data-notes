# F515（予備 R14 に替えた）事前の計画（PLAN）

作成：2026-11-16 13:17（JST）。結果を集計する前に書いた。

## 問い
年間休日の多い産業と少ない産業の差は、縮まったのか？

## 知りたい人
仕事を選ぶ人、人手不足の産業で働き方を考える人、「休みの少ない業界」と言われる産業の今を数字で知りたい人。

## データ
- 厚生労働省「就労条件総合調査」各年の「産業・企業規模、年間休日総数階級別適用労働者割合及び労働者１人平均年間休日総数」（2002〜2025年の調査、各年1月1日現在。e-Stat の Excel）。
- 労働者1人平均の年間休日総数（企業で最も多くの労働者に適用される年間休日を、労働者数で加重平均した値）を、産業大分類別・企業規模別に使う。
- 産業分類は2009年調査から今の大分類（宿泊業・飲食サービス業、情報通信業など）になったので、産業の比較は2009〜2025年を中心にする。
- 既存の F363 は同じ調査の「週休制」を企業規模別に見た記事。ここでは「年間休日の日数」を産業別に見る。

### 取得前に見たもの（下見）
- 2002・2009・2015・2025年の表を、形を確かめるために全部の行を見た。例：調査産業計の労働者1人平均は2009年112.6日、2015年113.2日、2025年116.6日。2025年の宿泊業・飲食サービス業108.0日、情報通信業123.2日、2009年はそれぞれ99.2日、122.0日。
- 他の年の値と、差の推移、規模別の推移はまだ計算していない。

## 仮説（外れの基準つき）
※ 2009年と2025年の値は下見で見たので、H1 は確認のための仮説。
- H1（確認）：最も多い産業と最も少ない産業の差（範囲）は、2009年より2025年の方が小さい。外れ：同じか大きい。
- H2：産業間のばらつき（標準偏差）は、2009〜2025年の間、ほぼ毎年縮んだ（2009→2017年と2017→2025年の両方で縮んだ）。外れ：どちらかの期間で広がった。
- H3：差が縮んだのは、休日の少ない産業（宿泊業・飲食サービス業、生活関連サービス業・娯楽業、運輸業・郵便業）が増えたためで、多い産業はほとんど増えていない（多い3産業の平均の増え方は少ない3産業の半分以下）。外れ：半分より大きい。
- H4：企業規模の差（1,000人以上と30〜99人）も、2009年より2025年の方が小さい。外れ：同じか大きい。

## 手法
- 産業大分類ごとの労働者1人平均の年間休日の推移、範囲・標準偏差。
- 2009年の値で「多い3産業」「少ない3産業」を決め、その後の変化を比べる（順位は図に出さない。産業は分類の順に並べる）。
- 企業規模別（1,000人以上、300〜999人、100〜299人、30〜99人）の推移。

## 頑健性（3つ以上）
1. 産業を「2009年から毎年ある産業」にそろえる（複合サービス事業などを除く）。
2. 1年の振れを抑えるため、3年平均で比べる。
3. 2025年を除く（2025年は全体が大きく上がっていて、調査の作り方の変化の影響の可能性がある）。
4. 「120日以上の労働者の割合」でも同じ比較をする。

## 言えないこと（予想）
- 年間休日は企業の決まり（所定）で、実際に休んだ日数（有給の取得など）ではない。
- 常用労働者30人以上の企業だけで、小さい企業は入らない。
- 産業の中の職種や雇用形態の違い（パート・アルバイトなど）は分からない。
- 休日が増えた理由（人手不足への対応、法律の変化など）は、この表からは分けられない。
