# F259 需要予測の外れは、在庫と欠品のどちらに効かせるべきか？

公開データ（商業動態統計の業態別販売額）を、架空の小売チェーン「あおばストア（架空）」の需要に見立て、F231 で作った需要予測を使って2か月ごとに発注する在庫を回した。予測の外れを「安全在庫（余分に持つ在庫）」としてどう積むと、在庫の費用と売り逃しの損の合計が小さくなるか、どの精度の指標がお金と合うかを調べた。

- 計画は結果を計算する前に書いて先に置いた：[PLAN.md](PLAN.md)（コミット f197dd4、メッセージ "plan"）
- 費用の比（在庫1単位1か月=1、売り逃し1単位=p）は**例として置いた比で、実在の費用ではない**。実在の会社のデータは使っていない

## 問い（どこから来たか・誰が知りたいか）
- データアナリストの求人の業務内容によく出てくる「需要予測」。予測の精度（MAPE など）は報告できても、それが在庫や欠品のお金にどうつながるかは説明しにくい。
- 知りたい人：発注や在庫の担当者（安全在庫をどう決めるか）、予測モデルを作る人（どの指標でモデルを選ぶか）、月次報告で予測の精度を KPI にしている人。
- F205（電力の外れの値段）と F235（1か月先・繰り越しなしのニュースベンダー）とは違い、ここでは**繰り越しのある在庫・リードタイム（発注から届くまでの期間）・2か月ごとの発注**を扱う。

## データ
- 経済産業省「商業動態統計調査」業態別の月次販売額（百貨店・スーパー・コンビニ・ドラッグストア・ホームセンター・家電大型専門店、2014年1月〜2026年8月）。業態ごとに 2017〜2019年の月平均＝100 に換算して、架空の会社の6つの売り場の需要とみなした。
- 予測：F231（[articles/F231_sales_forecast_horizon](../F231_sales_forecast_horizon)、コミット 613a8c7）の予測結果をそのまま使った（5モデル：季節ナイーブ・季節ナイーブ＋伸び・ETS・SARIMA・LightGBM、起点は2016年12月〜2024年8月の2か月ごと47回、1〜24か月先）。新しい予測は作っていない。手元のファイルが 613a8c7 の GitHub 上のものと同じ（SHA-256 の先頭が一致）ことを確かめた。

## 手法
- 発注：2か月ごと（R=2）。リードタイム L＝0・1・2・3か月。発注のたびに「次の発注が届くまでの L+R か月の予測の合計＋安全在庫」まで補充する（発注点補充方式）。売れ残りは翌月に繰り越す。足りない分は売り逃し（主）。
- 費用：在庫1単位を1か月持つと h=1、売り逃し1単位で p（主は p=9、ほかに 4・19）。月末の在庫に h をかけ、売り逃しに p をかけて足す。数字は「需要の月平均＝100 の売り場の、月あたりの費用」。
- 期間：コロナ期（2020年3月〜2021年12月）を挟むので、コロナ前（2018年9月〜2020年2月）とコロナ後（2022年1月〜2024年10月）の2区間で回した。始めの状態は「ふだんの回り方」（直前の発注がまだ届いていない分を途中に置く）にそろえた。
- 安全在庫の決め方：
  1. なし（予測の合計そのまま）
  2. ルートの式：1か月先の外れの RMSE × √(L+R) × z（z は目標 α=p/(p+h) の正規分布の点、p=9 で 1.28）
  3. 合計の外れの分位点：過去の起点の「L+R か月の合計の外れ（実績の合計−予測の合計）」の α 分位点をそのまま積む
  4. 後から見た最良の倍率：ルートの式の倍率を −2〜8 から後で選んだ目安（実際には使えない）
  - 2・3 は、その起点より前に結果が出そろった外れだけを使う（先読みしない）。外れはコロナ期にかかる窓を除いてため、8個たまってから使う。
- 指標と費用の合い方：業態×L の24組それぞれで5モデルを並べ、指標（1か月先の MAPE・1か月先の RMSE・L+R か月の合計の外れの RMSE・合計の外れの偏り・ピンボール損失）と費用の順位相関（スピアマン）を出した。
- SQL：`sql/f259_check.sql`（SQL Server で動く書き方）で、在庫の推移の記録から費用を集計し、予測と実績から合計の外れの RMSE 倍率を出した。DuckDB で流して Python と照合（600組の費用の差は最大 8.5e-07、180組の倍率の差は最大 4.8e-07）。在庫の動きそのもの（前の月の在庫に次の月が依存する計算）は Python で回し、SQL では集計の部分を確かめた。
- 判断用の表：`dashboard/index.html`（L と p を選ぶと、決め方ごとの費用・売り逃し率・カバー率、モデル別の費用が出る。架空の会社の社内向けの例）

## 結果（主：p=9・売り逃し・業態ごと）
| 決め方 | L=0 | L=1 | L=2 | L=3 |
|---|---|---|---|---|
| なし | 69.8 | 70.6 | 72.7 | 75.8 |
| ルートの式 | 64.1 | 68.4 | 69.4 | 74.2 |
| 合計の外れの分位点 | 63.2 | 67.8 | 67.9 | 73.7 |
| 後から見た最良の倍率（目安） | 62.0 | 65.7 | 66.5 | 70.9 |

（月あたりの費用。6業態×5モデルの平均。L=2 の内訳は、在庫費 54.7〜63.2、売り逃しの損 5.9〜17.9。費用の大半は「2か月分を一度に入れるので持つ在庫」で、安全在庫の決め方で動くのは数%）

1. **要る安全在庫は、守る期間が長いほど √ の式より速く増えた**（図1）。実際に要った量（合計の外れの90%点）を「1か月先の外れ×z」で割った倍率の中央値は、L+R=2・3・4・5 で 1.30・2.09・2.70・3.59。ルートの式の √(L+R) は 1.41・1.73・2.00・2.24。
   - 理由は「月ごとの外れが同じ向きに続く」ことではなかった。同じ起点の隣の月どうしの外れの相関は中央値 0.01（−0.39〜0.38）。効いていたのは**偏り**（予測が実績より毎月少しずつ低い。1か月あたり平均で約 +1、需要の約1%）で、偏りは期間に比例して積み上がるのに、ばらつきは √ でしか増えない。偏りのほとんどない SARIMA では、L+R=3 の倍率が 1.72 と √3（1.73）とほぼ同じだった。
2. **目標の90%には、どの決め方も届かなかった**（図2）。ルートの式の「覆えた割合」は L=0〜3 で 83%・79%・74%・71%、合計の外れの分位点は 80%・81%・76%・75%。過去の外れの90%点を積んでも、これからの外れの90%は覆えない（外れの大きさが時期で変わる、たまった外れが8〜30個ほどと少ない）。6業態の外れをまとめて分位点を作ると、86% 前後で L によらずほぼ一定になった。
3. **お金と合う指標は「L+R か月の合計の外れ」**（図4）。費用との順位相関の平均は、安全在庫なしのとき 合計の外れの RMSE 0.71・偏り 0.55・1か月先の RMSE 0.45・1か月先の MAPE 0.38。分位点で安全在庫を置いたとき 合計の外れの RMSE 0.48・ピンボール損失 0.48・1か月先の MAPE 0.29。安全在庫で偏りを直すと、偏りの指標は費用と合わなくなる（−0.17）。
4. **モデルの違いの方が、安全在庫の決め方の違いより費用に効いた**（図5）。同じモデルで決め方（なし・ルートの式・分位点）を変えた幅は平均 6.5、同じ決め方でモデルを変えた幅は 10.4。決め方の幅の方が大きかったのは24組中1組。
   - ただし、モデルの順位は1か月先の当たり具合とは違った。分位点で安全在庫を置いたときの費用（L=0〜3 の平均）は、季節ナイーブ＋伸び 66.4、季節ナイーブ 66.7、ETS 67.9、SARIMA 68.2、LightGBM 71.6。F231 で1か月先の MAPE がいちばん小さかった SARIMA（2.5%、季節ナイーブは3.9%）は、お金では真ん中だった。季節ナイーブの外れは偏っているが、偏り方が安定しているので安全在庫で直しやすい。
   - 季節ナイーブを安全在庫なしで使うと 80.4 と飛び抜けて悪い（偏りがそのまま売り逃しになる）。
5. ルートの式と分位点の差は平均 1.5（L=2、約2%）と小さく、業態×モデル×L の120組のうち分位点が良かったのは44%。平均の差は、偏りの大きい組での大きな差（最大15）から来ている。

## 計画とのずれ
- H1（√ より速く増える・ルートの式は目標に届かない）：**当たり**。L=2・3 のルートの式の覆えた割合は 74%・71% で、目標90%から3ポイント以内ではなかった。ただし、理由は計画に書いた「外れが同じ向きに続く（相関）」ではなく「偏りが積み上がる」だった。また、計画で良いと見込んだ分位点の決め方も目標に届かなかった。
- H2（1か月先の MAPE より合計の外れの方が費用と合う）：**当たり**（0.48 対 0.29、安全在庫なしでは 0.71 対 0.38）。
- H3（決め方の差の方がモデルの差より大きい）：**外れ**。モデルの幅 10.4 に対して決め方の幅 6.5（24組中1組だけ逆）。ルートの式と分位点の2つだけで比べても、決め方の幅 2.4 に対してモデルの幅 6.7（LightGBM を除くと 3.9）。
- 計画になかったこと：後から見た最良の倍率の中央値は L によらず 0.85〜1.0 で、z=1.28 より小さかった。安全在庫は次の発注まで2か月持つので、在庫の費用は1回の欠品の判断に対して2か月分かかる。目標を α=p/(p+2h)=0.82（z=0.91）にすると理屈が合う（下の「問いの立て直し」の2）。
- 計画では始めの状態を決めていなかった。最初は全部を手元在庫で始めていたが、L が大きいほど始めの在庫が多すぎて費用がふくらむ（L=3 で月 +31）ことに気づき、「ふだんの回り方」で始めるように直した。

## 頑健性（L=2 の費用：ルートの式 → 合計の外れの分位点、覆えた割合）
| 条件 | ルートの式 | 分位点 | 覆えた割合（ルート/分位点） | モデルの幅 > 決め方の幅 |
|---|---|---|---|---|
| 主（p=9） | 69.4 | 67.9 | 74% / 76% | 23/24 |
| p=4 | 64.0 | 63.3 | 66% / 68% | 21/24 |
| p=19 | 75.8 | 74.2 | 82% / 82% | 17/24 |
| バックオーダー（翌月に回す） | 71.8 | 69.7 | 74% / 76% | 23/24 |
| 6業態まとめて分位点 | 70.3 | 70.1 | 83% / 87% | 23/24 |
| コロナ期も含めて1本 | 78.6 | 80.3 | 80% / 80% | 23/24 |
| 外れが12個たまってから | 71.0 | 69.3 | 74% / 75% | 21/24 |

- 偏りが積み上がって √ の式が足りなくなること、目標に届かないこと、モデルの差の方が大きいことは、どの条件でも同じ向き。
- p=4（売り逃しの損が小さい）では、L=1〜3 で「安全在庫なし」（62.2・62.7・65.7）の方がルートの式（63.4・64.0・67.4）より安い。安全在庫が割に合うのは、売り逃しの損が在庫の費用に比べて十分大きいとき。
- コロナ期も含めると、分位点はルートの式より悪くなる（コロナ期の大きな外れが、そのあとの安全在庫を積みすぎにする）。

## 問いの立て直し（最初の結果を見た後に足した問い）
1. **偏りを直すだけで、どれだけ減るか**：安全在庫を「過去の合計の外れの平均」（偏りの分だけ）にすると、L=2 で 72.7 → 69.5。安全在庫なしから分位点までの減り（4.8）の約3分の2が偏りを直すだけで取れる（L=0 では約半分）。ただし覆えた割合は 48% 前後で、欠品は残る。
2. **目標を「2か月持つ前提」にすると**：分位点の目標を α=p/(p+2h)（p=9 で 0.82）にすると、L=2 で 67.9 → 67.7、L=3 で 73.7 → 73.1。小さいが、L=1〜3 で費用が下がった（L=0 は 63.2 で同じ）。覆えた割合は 68〜73%。

## 言えないこと
- 業界全体の合計の需要で、1店・1品目の需要は外れがずっと大きく、偏りより、ばらつきの方が大きくなりうる。結果の大きさ（特に「モデルの差の方が大きい」）は単位によって変わりうる。
- 費用の比（h=1、p=4・9・19）は例として置いたもの。実在の費用ではない。品切れで客が他の店に流れる損、廃棄、発注の手間、置き場所の上限は入れていない。
- 名目の販売額で、物価・店舗数・休日の並びは調整していない。偏り（実績が予測より高い）の一部は物価の上昇による。
- 評価できる期間は52か月（コロナ前18か月、コロナ後34か月）と短く、たまった外れも少ない。
- 予測は F231 のもの（2か月ごとの起点）で、予測の作り方を変えれば順位は変わりうる。LightGBM は単純な設定。
