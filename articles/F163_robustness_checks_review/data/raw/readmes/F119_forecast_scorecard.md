# F119 予測した記事は、その後どれだけ当たったか？（予測の答え合わせ）

看板記事 F119。これまでに予測を出した看板記事（F13・F18・F22・F55・F86・F92）について、**モデルが学習に使っていない、その後の実績**で予測を答え合わせする。実績がまだ出ていない予測は、何がいつ確かめられるかを一覧にして残す。

## 問い

- 記事を書いたあとに出た実績で見ても、予測は記事に書いたくらい当たっているか
- 予測の幅（予測区間）は、その後の実績を正しい割合で含んでいるか
- 単純な予測（前年のまま・1週間前のまま）と比べて、記事のモデルは勝っているか

## 答え合わせの対象

| 記事 | 予測 | 実績 | 実績はいつ出たか |
|---|---|---|---|
| F22 | 東京エリアの翌日24時間の需要（2026年9月30日までで学習） | 2026年10月1〜28日の1時間値 | 記事のあと（毎日） |
| F92 | 翌日のピーク需要の95%・99%の上限（同上） | 2026年10月1〜28日のピーク | 記事のあと（毎日） |
| F55 | 2026年の月ごとの出生数（2016〜25年の確定数で学習、BSTS と SARIMA） | 2026年1〜5月の月報（概数） | 7月10日〜10月6日。記事の前に公表済みだが、モデルは使っていない |
| F86 | 2025年の平均寿命（日本版死亡データベース 2024年までで学習、Lee–Carter） | 令和7年簡易生命表 | 2026年7月。同上 |
| F13・F18・F55（年間）・F86（2026年） | 失業率・GDP・出生数の年間・平均寿命 | まだ出ていない | 一覧（`results/pending_forecasts.csv`） |

F55 と F86 の実績は記事を作る前に公表されていたが、どちらのモデルも学習に使っていない（学習は2025年12月・2024年まで）。「モデルにとって初めて見る実績」という意味での答え合わせである。

## データ

- 新しく取得：東京電力パワーグリッド「エリア需給実績データ」2026年10月、気象庁「過去の気象データ」東京 2026年10月、厚生労働省「人口動態統計月報（概数）」2026年1〜5月、「令和7年簡易生命表」（`data/raw/SOURCES.md`）
- そのまま使う：F22・F92 の電力と気象（2016年4月〜2026年9月）、F55 の月別出生数（確定数、2000〜2025年）、F86 の予測、F13・F18 の予測

## 手法

1. **電力（F22・F92）**：記事と同じ特徴量・パラメータで、2026年9月30日までのデータで学習し、10月1〜28日を予測する（気温は記事と同じく実測値）。誤差（MAPE）を、記事のバックテストの「過去6年の10月」と比べる。F92 は95%・99%の上限に実績が収まった割合（カバー率）を見る
2. **出生数（F55）**：F55 の 2026〜30年の予測（2016〜25年で学習した BSTS と SARIMA）を、同じ設定で月ごとに出し直す（年間の中央値は 66.27万人で、記事の 66.30万人を再現）。月報の概数は確定数より少なく出るので、2025年1〜5月の確定数÷概数の比（1.0117）で確定数ベースに直して比べる
3. **平均寿命（F86）**：2025年の予測区間と簡易生命表の値を比べ、「前年のまま」「過去10年の伸びを延ばす」と比べる
4. **まだ出ていない予測**：値と、答えが出る時期を一覧にする

## 結果

### 電力（記事のあと：10月1〜28日、672時間）

| モデル | 2026年10月の MAPE | 過去6年の10月（F22 のバックテスト） |
|---|---|---|
| LightGBM | **1.53%** | 1.43〜2.09%（6年の平均 1.74%） |
| 線形回帰（Ridge） | 2.70% | 2.96〜3.16% |
| 1週間前の同じ時刻 | 3.83% | 2.59〜6.73% |
| 前日の同じ時刻 | 6.37% | 5.16〜6.86% |

- LightGBM の誤差は、記事のバックテストの10月とほぼ同じ範囲に収まった。日ごとの MAPE の平均の95%区間はおよそ 1.30〜1.76%。ずれの向き（平均 −0.07%）にも偏りはない
- いちばん外れたのは 10月22日（3.2%）。前日の最高 30.3℃から 25.0℃へ下がった日で、予測が上に外れた
- F92 の95%の上限（点予測＋残差の分位点）には、28日すべてが収まった（カバー率 100%、平均の上乗せ +6.0%）。ただし過去6年の10月も 186日すべてが収まっており、**10月は1年を通して決めた幅が広すぎる月**。28日で「95%が正しい」とは言えない。LightGBM の分位点の95%は 92.9%（2日はみ出し）、一律3%の上乗せは 85.7%

### 出生数（2026年1〜5月、確定数ベースに直した値）

| モデル | 1〜5月の予測（中央値） | 95%区間 | 実績 | 外れ | 実績は予測分布の何%の位置か |
|---|---|---|---|---|---|
| BSTS | 26.73万人 | 25.49〜28.20万人 | 26.67万人 | +0.2% | 47% |
| SARIMA | 26.12万人 | 25.06〜27.25万人 | 26.67万人 | −2.1% | 84% |

- 実績の1〜5月は前年とほぼ同じ（概数どうしで +0.1%）。BSTS は前年比 +0.3%、SARIMA は −2.0% を予測していた。**区間は両方とも実績を含んだが、中心は BSTS がほぼ真ん中、SARIMA は低め**
- 月ごとには、1月は両モデルとも高め、4・5月は低めに外れた。月報の概数と確定数は月の配分が少し違う（2025年は1月だけ比が 1.05）ので、月ごとの比較は合計より不確か
- 2026年の年間（BSTS 66.3万人、前年比 −1.2%）が当たるかは、6月以降の減り方しだい。1〜5月が横ばいでも、年間の予測がそのまま当たるとは言えない

### 平均寿命（2025年）

| | 実績（簡易生命表） | Lee–Carter（F86）中央 | 95%区間 | 前年のまま | 過去10年の伸びを延ばす |
|---|---|---|---|---|---|
| 男 | 81.35年 | 81.27（−0.08） | 80.90〜81.64 | 81.09（−0.26） | 81.15（−0.20） |
| 女 | 87.33年 | 87.35（+0.02） | 86.90〜87.77 | 87.15（−0.18） | 87.19（−0.14） |

- Lee–Carter は男女とも区間の中に入り、単純な2つの方法より外れが小さい。65歳の平均余命も 男 19.61（実績 19.68）・女 24.57（同 24.52）
- 1年分・2つの値なので、「よく当たるモデル」の証拠としては弱い。2024年の日本版死亡データベースと簡易生命表の差は 0〜0.02年で、基準の違いは小さい

## 頑健性

| 確かめたこと | 結果 |
|---|---|
| 電力：気温に予報の誤差を足す（σ=1・2℃、各5回） | LightGBM の MAPE 1.81%・2.25%。実測の気温を使う分だけ良く出ている |
| 電力：1か月古いモデル（8月31日までで学習） | 1.61%（Ridge 2.71%）。ほぼ変わらない |
| 電力：学習を直近3年に限る | 1.49% |
| 出生数：概数を直す方法（月ごとの比／合計の比／直さない） | BSTS の外れ +0.2%・+0.2%・+1.4%、SARIMA −2.1%・−2.1%・−0.9%。どの直し方でも実績は両方の95%区間の中 |
| 平均寿命：比べる相手を変える（前年のまま／10年の伸び） | どちらも Lee–Carter より外れが大きい（男 −0.26・−0.20、女 −0.18・−0.14） |

## 言えないこと

- 答え合わせできたのは、**電力の28日・出生数の5か月・平均寿命の1年**だけ。どれも「外れなかった」ことは言えるが、モデルがこれからも当たる証拠としては短い
- 電力は気温に実測値を使っている。実際の運用では予報の気温を使うので、外れはもっと大きくなる（σ=2℃で 2.25%）
- 出生数の実績は概数を確定数ベースに直した値で、確定数が出ると変わる。直し方で外れは 1ポイントほど動く
- F55 と F86 の実績は、記事を作る前に公表されていた。モデルは使っていないが、「記事を書いたあとに初めて出た実績」ではない
- 失業率と GDP の予測は、まだ答え合わせできていない。予測の値と時期を残しておき、出たあとに確かめる
