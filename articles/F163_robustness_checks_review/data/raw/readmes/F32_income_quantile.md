# F32 所得の高い町と低い町で、効いている要因は同じか？（分位点回帰）

note の看板記事「所得の高い町と低い町で、効いている要因は同じか？ 1,740市区町村を分位点回帰で分けると、大卒の割合は上の町ほど強く効き、人口密度は下の町でだけプラスだった」の分析コード・データ・図です。

## 問い

市区町村の納税者1人あたり所得を、年齢構成・学歴・産業・人口密度などで説明するとき、所得の低い町（10%点）と高い町（90%点）で、効いている要因は同じか。平均だけを見る重回帰（最小二乗法）では見えない違いを、分位点回帰で確かめる。

## データ

| 使ったもの | 中身 | 出典 |
|---|---|---|
| 納税者1人あたり所得 | 課税対象所得 ÷ 納税義務者数（所得割）、2020年度・2015年度 | 総務省「市町村税課税状況等の調」（e-Stat「社会・人口統計体系 市区町村データ」） |
| 年齢構成・世帯・産業・雇用・昼夜間人口比率 | 2020年・2015年国勢調査 | 総務省「国勢調査」（同上） |
| 大卒の割合 | 最終学歴人口のうち大学・大学院（2020年、2015年度の分析では2010年） | 同上 |
| 人口密度 | 総人口 ÷ 可住地面積 | 同上 |

- 対象：1,740市区町村（政令市は市全体、東京23区は区ごと）
- `data/raw/ssds_municipal.json`：e-Stat から取得した元データ（取得の方法は `src/01_取得.md`）
- `data/panel_long.csv`：市区町村×年に整えたもの

## 手法

| 段階 | やったこと |
|---|---|
| 被説明変数 | 納税者1人あたり所得の対数 |
| 説明変数 | 65歳以上の割合、15歳未満の割合、大卒の割合、第1次・第2次産業の割合、log人口密度、単独世帯の割合、昼夜間人口比率、雇用者のうち正規の割合（すべて標準化。係数は「1標準偏差あたり所得が何%違うか」） |
| 比べる相手 | 最小二乗法（HC3 の標準誤差） |
| 分位点回帰 | 10・25・50・75・90%点（係数の推移の図は5%刻み）。statsmodels の QuantReg |
| 信頼区間 | 市区町村を復元抽出するブートストラップ（500回、頑健性は200回）のパーセンタイル区間 |
| 分位点の間の差 | 90%点の係数 − 10%点の係数をブートストラップで検定 |
| 予測した分布 | 5%刻みの分位点の予測を地域ごとにつなぎ、一様乱数で引いて分布を作り、実際の分布と比べる |

## 主な結果

- 所得の分布：10%点 244万円、中央値 282万円、90%点 345万円。右に長く、最大は 1,163万円（東京都港区）
- 最小二乗法の R² は 0.73

| 説明変数（1標準偏差あたり、%） | 最小二乗法 | 10%点 | 50%点 | 90%点 | 90%点−10%点（95%区間） |
|---|---|---|---|---|---|
| 大卒の割合 | +9.3 | +7.4 | +8.9 | +10.8 | +3.4（+2.0〜+4.7） |
| 65歳以上の割合 | −7.1 | −5.5 | −7.6 | −8.6 | −3.2（−4.8〜−1.0） |
| 第1次産業の割合 | +2.9 | +0.9 | +1.8 | +3.8 | +2.9（+1.2〜+4.9） |
| log人口密度 | +1.0（0をまたぐ） | +3.9 | +0.4 | −1.7 | −5.6（−7.3〜−3.2） |
| 単独世帯の割合 | +1.1 | −0.3 | +1.3 | +2.9 | +3.2（+1.2〜+4.4） |
| 15歳未満の割合 | −3.1 | −2.9 | −3.3 | −3.0 | ほぼ同じ |
| 雇用者のうち正規の割合 | −0.1 | −0.2 | −0.6 | −1.3 | −1.1（−1.8〜−0.0） |

- 大卒の割合は、どの分位点でもいちばん強く効き、上の町ほど強い
- 人口密度は、平均（最小二乗法）では0をまたぐが、所得の低い側（10%点）ではプラス、高い側（90%点）ではわずかにマイナス。平均で「効かない」のは、下と上で逆向きの効き方が打ち消し合っているため
- 予測した分布は、実際の分布をほぼ再現する。下の端（1%点）は分位点回帰のほうが近い（実際 224万円、分位点回帰 225万円、最小二乗法＋正規誤差 215万円）

## 頑健性

| 設定 | 大卒の上下差 | 人口密度の10%点と90%点 |
|---|---|---|
| 本体（2020年度） | 7.4 → 10.8 | +3.9 / −1.7 |
| 23区・政令市を除く（1,697） | 6.9 → 10.1 | +3.2 / −2.0 |
| 2015年度（1,736） | 10.2 → 12.2 | +2.1 / −1.9 |
| 県ダミーあり | 6.7 → 9.2 | +3.6 / +1.5（どちらもプラス） |
| 所得を対数にしない（万円） | +20.2万 → +38.4万 | +10.5万 / −2.7万 |

- 大卒の割合が上の町ほど強く効くこと、第1次産業の割合の上下差は、すべての設定で残った
- 人口密度の「下ではプラス、上ではマイナス」は、県ダミーを入れると「下ほど強いプラス」に変わる。上の町でのマイナスは、県の違い（都市圏の県かどうか）で説明できる部分が大きい
- 65歳以上の割合の上下差も、県ダミーを入れると消える
- 昼夜間人口比率は東京都心の区などの極端な値に引っ張られ、区間が広く不安定（記事では扱いを小さくした）

## 言えないこと

- 分位点回帰の「90%点」は「所得の高い町そのもの」の分析ではなく、条件をそろえたうえでの所得の分布の上側の話
- 横断の観察データなので、因果は言えない（大卒の割合が上がれば所得が上がる、という意味ではない）
- 納税者1人あたり所得は、納税していない人を含まず、高所得の少数の人に平均が引っ張られる町もある
- 第1次産業の割合のプラスは、条件をそろえたあとの関係で、農林漁業の所得が高いという意味ではない

## 動かし方

```bash
pip install -r requirements.txt
cd src
python 02_整形.py   # data/raw/ssds_municipal.json → data/panel_long.csv
python 03_分析.py   # results/（ブートストラップがあるので十数分かかる）
python 04_図.py     # figures/
```

乱数の種は `common.py` の `SEED` で固定しています。

## ファイル

- `results/coef_base.csv`：最小二乗法と分位点回帰（10〜90%点）の係数と95%区間
- `results/coef_grid.csv`：5%刻みの分位点の係数（点推定）
- `results/diff_q90_q10.csv`：90%点と10%点の係数の差の検定
- `results/dist_compare.csv`：実際の分布と、モデルから作った分布の分位点
- `results/robustness.csv`：頑健性の4設定
- `figures/`：記事の図5枚

政府統計の総合窓口(e-Stat)（https://www.e-stat.go.jp/）「社会・人口統計体系 市区町村データ」（総務省「市町村税課税状況等の調」「国勢調査」）を加工して作成。
