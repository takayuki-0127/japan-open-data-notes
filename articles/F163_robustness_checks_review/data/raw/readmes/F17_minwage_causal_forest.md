# F17 最低賃金の影響が大きかったのはどんな県か？（因果フォレスト）

看板記事 F17。F01（差の差）で「平均では就業率が下がった形跡は見えない」とした最低賃金の引き上げについて、次の問い「どんな県で影響が大きかったか」を、因果フォレスト（econml の `CausalForestDML`）で調べました。

## 問い

最低賃金の上がり幅が大きかった県・年ほど就業率が下がったか。その効き方は、最低賃金が平均時給に近い県、高齢化が進んだ県、製造業や飲食業が多い県などで違ったか。

## データ

| データ | 中身 | 期間 |
|---|---|---|
| F01 のパネル（`data/raw/f01_panel.csv`） | 47都道府県×年の最低賃金（暦年換算）、就業率・完全失業率（労働力調査 都道府県別モデル推計値）、有効求人倍率、2015年の短時間労働者の平均時給（賃金構造基本統計調査） | 2008〜2025年 |
| 統計センター「SSDSE-B-2026」 | 県×年度の総人口・65歳以上人口（2015年度の値を使用） | 2015年度 |
| 統計センター「SSDSE-A-2021」 | 市区町村×産業の民営従業者数（経済センサス‐活動調査 2016年）を県で合計 | 2016年 |

作ったデータ：`data/f17_panel.csv`（県×年、611行）、`data/f17_pref_features.csv`（県の特徴）、`data/f17_panel_with_tau.csv`（推定した効果つき）。

## 手法

| 項目 | 内容 |
|---|---|
| 単位 | 都道府県×年（2010〜2025年、コロナの2020〜22年を除く。611行） |
| 処置 T | 前年からの最低賃金（暦年換算）の上がり幅を、2015年の短時間労働者の平均時給に対する%ptで表したもの。1単位＝平均時給の1%分（約10円）の引き上げ |
| 結果 Y | 就業率の前年差（%pt） |
| 調整する変数 W | 年ダミー（全国共通の景気と引き上げ）、前年の就業率の変化、前年の有効求人倍率の変化 |
| 効果の違いを説明する特徴 X（12個、すべて2015〜16年の値） | 最低賃金÷平均時給（bite）、平均時給、就業率、失業率、有効求人倍率、15歳以上人口（log）、65歳以上の割合、製造業・卸売小売業・宿泊飲食業・医療福祉・建設業の従業者の割合 |
| 推定 | `CausalForestDML`（Y と T の予測は LightGBM、県ごとにまとめた5分割の交差適合、木2,000本、honest、葉の最小10）。比較に `LinearDML`（効果は一定）と、年効果つきの前年差の回帰（県クラスター） |
| 検証 | 予測した効果の「当たり方」を、県のまとまりごとに外した森で予測し直して確かめる：BLP（予測した効果の差が、実際の残差の差に表れるか）と GATES（予測の4分位ごとの実際の効果） |

年ダミーを入れているので、効果の推定に使われるのは「同じ年の中で、県によって上がり幅が違った分」だけです（年の中での標準偏差は平均0.27%pt）。

## 主な結果（results/main.json）

- **平均の効果**：平均時給の1%分の引き上げで、就業率は **−0.09%pt（95%区間 −0.40〜+0.22）**。LinearDML は −0.09（−0.27〜+0.09）、前年差の単純な回帰は −0.14（−0.27〜−0.01）。条件をそろえると区間は0をまたぎ、F01 と同じく「下がった」とは言えません。
- **県ごとの効果**：森の推定では −0.30（山形）〜+0.06（滋賀・三重）。95%区間が0をまたがないのは47県中2県（愛媛・広島）で、偶然でも5%＝約2県は出る数です。
- **効果の違いは検証で裏付けられなかった**：県を外して予測した効果で確かめると、BLP の異質性の係数は −1.20（p=0.38）。予測の4分位ごとの実際の効果も、予測の順に並びませんでした（results/gates.csv）。森全体の予測と、県を外した予測の相関は0.16しかありません。
- **森が「分ける」のに使った特徴**：15歳以上人口（重要度0.24）、65歳以上の割合（0.12）、失業率（0.10）。県の平均効果と65歳以上の割合の相関は −0.51（高齢化が進んだ県ほど下がる向き）。最低賃金÷平均時給（bite）との相関は −0.04 でした。ただし、プラセボでも同じ「15歳以上人口」が1位になるので、重要度は「本当の違い」の証拠になりません。

## 頑健性（results/robustness.csv）

| 設定 | 平均効果（95%区間） | 異質性の BLP p（同じデータで予測） | 同（県を外して予測） |
|---|---|---|---|
| 基本 | −0.09（−0.40〜+0.22） | <0.001 | 0.38 |
| 葉の最小サイズ 5／20、木の深さ4 | −0.09（区間はいずれも0をまたぐ） | <0.001 | 0.48（葉20） |
| 乱数の種を3通り | −0.10〜−0.09 | <0.001 | |
| 2010〜19年だけ | −0.07（−0.56〜+0.43） | | |
| 2016〜25年（コロナ除く） | −0.14（−0.41〜+0.14） | | |
| 2020〜22年も含める | +0.02（−0.28〜+0.33） | | |
| 結果を失業率の前年差に | +0.05（−0.08〜+0.19） | | |
| プラセボ：年の中で上がり幅をシャッフル（3回） | +0.15〜+0.21（1回は区間が0をわずかに上回る） | <0.001 | 0.34〜0.82 |

- ハイパーパラメータや乱数を変えても、平均効果と県の並び（順位相関0.90〜0.98）はほぼ同じです。期間を変えると県の並びは変わります（順位相関0.38〜0.62）。
- **同じデータで予測した効果で検定すると、上がり幅をでたらめに入れ替えたプラセボでも「異質性あり」（p<0.001）になります**。県を外して予測した効果で検定すると、基本もプラセボも「差なし」です。異質性の検証は、必ず学習に使っていないデータで行う必要があります。
- プラセボの平均効果が +0.15〜+0.21 と0から離れたことは、47県の小さなデータでは森の区間が狭めに出ている可能性を示します。

## 言えないこと

1. 47県のデータで、年ダミーを入れた後に残る上がり幅の違いは小さく（平均時給の0.27%分）、県ごとの効果はほとんど見分けられません。
2. 県ごとの数字（山形 −0.30 など）は推定のぶれが大きく、その県で「最低賃金が雇用を減らした」とは言えません。
3. 効果の大小の理由（高齢化か、人口規模か）は推測にとどまります。人口や高齢化は、地域の景気の流れとも重なっています。
4. 処置の上がり幅は、県が自分で決める部分（地方の最低賃金審議会）と、全国の目安の両方で決まり、地域の景気と無関係とは言い切れません。
5. 結果は県全体の就業率で、最低賃金に近い賃金で働く人だけを見たものではありません。

## 設計書からの変更点

- 処置は「引き上げ幅が大きい年・県（2値）」ではなく、連続の上がり幅（平均時給に対する%pt）にしました。2値にすると、ほぼ全県が毎年引き上げを受けるため差が作れなかったためです。
- 結果は短時間労働者の雇用ではなく、就業率の前年差です（県別の短時間労働者の雇用の年次データが F01 にないため）。
- SHAP の代わりに、森の分割の重要度と、上位・下位25%の特徴の比較を使いました。
- 「F01 の推定と平均が合うか」は、LinearDML と前年差の回帰と並べる形にしました。F01 は「bite の高低×2016年以降」の比較なので、単位がそろわず直接は比べられません（向きはどれも「下がったとは言えない」で一致）。
- 異質性の検証に、プラセボ（年の中での上がり幅のシャッフル）を足しました。
