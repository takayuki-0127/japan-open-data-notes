# F59 学力調査の県の順位は、毎年どれくらい入れ替わるのか？（順位の安定性）

看板記事 F59。全国学力・学習状況調査の都道府県別の結果を7回分集め、平均正答率を正答数の分布から小数まで計算し直して、**都道府県の順位がどれくらい当てにならないか**を調べました。県の順位表を作ることが目的ではありません。記事・図では、どの県が何位かは出していません（データには県名が入っています）。

note の記事：（公開後に記入）

## 問い

- 都道府県の順位は、年ごとにどれくらい入れ替わるのか
- 公表値（整数の平均正答率）で並べると、どれくらい同点になるのか
- 順位の動きのうち、受けた子どもの偶然（標本誤差）で説明できるのはどれくらいか
- 都道府県の差のうち、毎年続く部分と、年ごとに入れ替わる部分はどれくらいか

## データ

| データ | 内容 |
|---|---|
| 国立教育政策研究所「全国学力・学習状況調査 調査結果資料【都道府県別】」 | 各都道府県の「調査結果概況」（公立）。2025・2026年度は NIER のサイト、2019・2021〜2024年度は国立国会図書館 WARP に保存されたページから取得 |

- 対象：2019（平成31／令和元）・2021・2022・2023・2024・2025・2026年度の7回（2020年度は中止）。小学校6年・中学校3年、国語と算数・数学（理科・英語は実施年が限られるので除外）。2018年度以前は国語・算数がA・Bに分かれていたので使っていません
- 1回×学校種×教科ごとに47都道府県、計1,316行
- 各県の「正答数ごとの児童生徒数」から平均正答率を計算し直しました。四捨五入すると公表値（整数）と全1,316行で一致します
- 全国の正答率は、47都道府県の人数で重みを付けた平均で計算し直しました

## 手法

1. 2つの年度の順位の相関（スピアマン、ケンドール）、上位5・上位10・下位10が次の回も残る割合
2. 7回の順位の幅（最低位 − 最高位）と、平均順位との関係
3. 標本誤差（標準偏差 ÷ √人数）だけで正答率を揺らしたときの順位の90%幅（パラメトリック・ブートストラップ 2,000回）
4. 公表値（整数）での同点の数、全国との差が ±1pt・±2pt に入る県の割合
5. 全国との差の分散を「ずっと続く差（7回の平均の違い）」「年ごとの揺れ」「標本誤差」に分解
6. 同じ学年の追跡（小6 → 3年後の中3）と、同じ年の教科間・学校種間の相関

## 主な結果

| 項目 | 結果 |
|---|---|
| 隣り合う順位の正答率の差（中央値） | 0.10ポイント |
| 正答率の標準誤差（中央値） | 0.21ポイント |
| 標本誤差だけで生じる順位の90%幅（中央値） | 5位（中位の県では7位、上位5県は1位） |
| 公表値（整数）の異なる値の数 | 8〜13通り（平均10.1） |
| ほかの県と同じ公表値になる県の割合 | 94% |
| 全国との差が ±1pt 未満／±2pt 未満の県 | 41%／70% |
| 連続する2回の順位の相関（スピアマン） | 平均0.84（0.72〜0.94） |
| 2019年度と2026年度の順位の相関 | 0.38〜0.69 |
| 次の回も残る割合 | 上位5：73%、上位10：76%、下位10：72% |
| 7回の順位の幅（中央値） | 15位。平均順位が上位10付近 6.5位、中位 20位、下位10付近 9位 |
| 7回の間に20位以上動いた県の割合 | 36% |
| 全国との差のうち、ずっと続く差の割合 | 68%（小・国語）〜85%（中・数学） |
| 年ごとの揺れの標準偏差 | 0.72〜1.19ポイント（標本誤差は0.21〜0.25） |
| 小6 → 3年後の中3の順位の相関（同じ学年） | 0.45（同じ年の中3 → 3年後の中3は0.79） |
| 同じ年の国語と算数・数学の相関 | 0.68（小）、0.70（中） |

- 上位と下位の数県は7回ともほぼ同じ位置にいます。一方、中位の県は順位が大きく動きます
- 前回からの順位の変化（中央値4位）は、標本誤差だけで生じる幅（90%幅の中央値5位）と同じくらいです
- 年ごとの揺れは標本誤差の4〜5倍あり、受けた子どもの偶然だけでは説明できません。問題の違い・学年の違いなどが効いていると考えられます（推測です）

## このデータで言えないこと

1. 調査の問題は毎年違うので、正答率の水準を年どうしで比べることはできません。ここでは同じ年の中での順位と、全国との差だけを比べています
2. 年ごとの揺れの原因（問題の違い、学年ごとの違い、学校の取り組みなど）は分けられません
3. 対象は公立の学校だけです。私立・国立に通う子どもが多い地域では、地域全体の学力とは違います
4. 平均正答率は、調査で測っている範囲の学力の一部です。順位の高い県の教育がよい、低い県が悪い、とは言えません
5. 標本誤差は「その年に受けた子どもを、同じような子どもの集まりから選ばれた一組とみなした」場合の目安です。全数調査なので、厳密な意味での標本誤差ではありません
