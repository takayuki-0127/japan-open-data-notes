# F114 東京の1万円と地方の1万円は、同じ価値か？ 所得を物価の地域差で割る

都道府県の所得の差のうち、どれだけが物価の差で打ち消されるのかを、消費者物価地域差指数（全国平均＝100）で名目の所得を割った「実質の所得」で確かめた。

## 問い

- 所得の高い県ほど物価も高いなら、物価で割ると所得の差はどれだけ縮むか
- 東京都の所得は、物価を除くとほかの県と比べてどうなるか
- 家賃の割合が大きい世帯（民営借家・単身）では、答えは変わるか。年や所得の物差しを変えるとどうか

## データ

| データ | 期間 | 出典 |
|---|---|---|
| 10大費目別消費者物価地域差指数（総合・家賃を除く総合・10大費目、全国、地方、都道府県、都道府県庁所在市・政令市） | 2013〜2025年 | 総務省統計局「小売物価統計調査（構造編）」 |
| 同 10大費目別ウエイト（参考表） | 2013〜2025年 | 同上 |
| 住居の所有関係別1世帯当たり1か月間の支出（総世帯・勤労者世帯・単身世帯） | 2024年 | 総務省統計局「家計調査」 |
| 課税対象所得÷納税義務者数（都道府県・市区町村） | 2013・2015・2017・2020・2024年 | 総務省統計局「社会・人口統計体系」（もとは総務省「市町村税課税状況等の調」） |
| 1人当たり県民所得 | 2013〜2023年度 | 内閣府「県民経済計算」 |

- 所得の本体は「課税対象所得÷納税義務者数」。2015・2017・2020年は市区町村の値を都道府県ごとに足した（2005・2010年で都道府県の値と照らすと、差は最大0.004%）。2013・2024年は都道府県の値そのもの。
- 地域差指数の「総合」は持家の帰属家賃（持ち家に住む人が自分に払っているとみなす家賃）を含まない。「住居」は家賃と設備修繕・維持。

## 手法

- 実質の所得 ＝ 名目の所得 ÷（地域差指数／100）
- 47都道府県の対数の所得の標準偏差を、名目と実質で比べる。**縮む割合 ＝ 1 − 実質の標準偏差／名目の標準偏差**
- **傾き β**：対数の地域差指数を対数の所得に回帰した傾き。「所得が10%高い県は、物価が β×10% 高い」。区間は47県を復元抽出するブートストラップ（2,000回、seed 114）
- 世帯の型：10大費目の地域差指数を、家計調査の世帯の型ごとの支出の割合で平均し直した物価で割る（総世帯・持家・民営借家・単身・単身の民営借家・勤労者の民営借家）。あわせて、住居の重みを0〜40%に動かした
- 確認：公式の「総合」を10大費目と全国のウエイトから作り直すと、平均の差は0.06〜0.08ポイント（その地域のウエイトだと0.14〜0.21）。世帯の型の物価は全国のウエイトと同じ作り方にそろえた

## 結果

### 1. 物価で割っても、所得の差は6%しか縮まない（2024年）

| | 名目 | 実質（総合で割る） | 実質（家賃を除く総合で割る） |
|---|---|---|---|
| 47都道府県の対数の標準偏差 | 0.108 | 0.101 | 0.105 |
| 縮む割合 | — | **5.8%**（95%区間 −2.2〜9.6%） | 2.3% |
| 最大÷最小 | 1.78倍 | 1.70倍 | 1.74倍 |
| 名目と実質の順位の相関 | — | 0.986 | 0.988 |

- 傾き β は0.067（95%区間 −0.007〜0.104）。所得が10%高い県でも、物価は平均して0.7%ほどしか高くない。
- 物価で割って順位が5位以上動いたのは1県、最大で8位。中央値は1位。

### 2. 東京都は、物価で割っても中央値の1.5倍

- 東京都の所得はほかの46道府県の中央値の1.58倍。総合で割ると1.50倍、家賃を除く総合で割ると1.54倍。どちらでも1位のまま。
- 東京都の地域差指数は総合104.0、家賃を除く総合102.2、住居127.2（2024年）。
- 圏域ごと（納税義務者数で重み付け、全体の平均＝1）：東京圏 名目1.185 → 実質1.155、名古屋圏・大阪圏 1.007 → 1.021、地方圏 0.870 → 0.883。

### 3. 家賃の重い世帯ほど物価の差は効くが、それでも14%ほど

| 物価の重み | 住居の割合 | 縮む割合 | 傾き β | 東京都の物価 | 東京都の実質（中央値との比） |
|---|---|---|---|---|---|
| 公式（全国） | 7.2% | 6.0% | 0.069 | 104.0 | 1.50倍 |
| 総世帯（平均） | 8.8% | 6.8% | 0.078 | 104.4 | 1.50倍 |
| 持家（総世帯） | 4.7% | 5.0% | 0.059 | 103.4 | 1.52倍 |
| 単身（平均） | 15.2% | 8.7% | 0.101 | 106.2 | 1.46倍 |
| 民営借家（総世帯） | 26.9% | 13.6% | 0.161 | 109.0 | 1.41倍 |
| 勤労者世帯の民営借家 | 26.6% | 13.7% | 0.163 | 109.0 | 1.41倍 |
| 単身の民営借家 | 30.0% | 14.3% | 0.174 | 109.9 | 1.39倍 |

- 住居の重みを0%から40%まで動かすと、縮む割合は2.8%から17.6%まで上がる。40%でも東京都の実質は中央値の1.35倍。
- 単身の民営借家の重みで作った物価は、最も高い東京都で109.9、最も低い県で93.3（差は約18%）。公式の重みでは104.0と96.3（約8%）。

### 4. 物価の差は、住居と食料からそれぞれ4分の1

- 47都道府県の総合のばらつきへの寄与（全国のウエイトでの分解、2024年）：食料28%、住居27%、教養娯楽14%、交通・通信8%、教育7%。
- 物価の差そのもの（総合の標準偏差）は2013年1.66、2025年1.62でほぼ横ばい。家賃を除く総合は1.24 → 1.39。

## 頑健性

| 確かめたこと | 縮む割合 |
|---|---|
| 年を変える（課税対象所得 × 同じ年の総合：2013・2015・2017・2020・2024年） | 9.2%・7.2%・7.7%・8.4%・5.8% |
| 同（家賃を除く総合） | 5.1%・3.3%・3.9%・4.9%・2.3% |
| 所得を1人当たり県民所得にする（2013〜2023年度、総合） | 3.3〜6.4% |
| 同（家賃を除く総合） | 0.9〜3.6% |
| 納税義務者数で重み付けする（2020年） | 13.4%（重みなし 8.4%） |
| 都市（都道府県庁所在市・政令市52市、2020年、総合） | 10.2% |
| 世帯の型・住居の重み（上の3） | 2.8〜17.6% |

- どの組み合わせでも、物価で縮むのは所得の差の2割未満で、東京都は1位のまま。
- 人数で重み付けすると縮む割合が大きくなるのは、人口の多い東京圏・大阪圏で所得と物価がそろって高いため。
- 1人当たり県民所得では東京都の名目は中央値の1.85〜2.06倍、実質で1.75〜1.95倍。企業の所得も入る物差しなので、差はさらに大きい。

## 言えないこと

- 地域差指数の総合は持家の帰属家賃を含まない。持ち家の世帯が住まいに払っている費用（住宅ローンや土地の値段）の地域差は入っていない。持ち家の住まいの費用が家賃と同じように地域で違うなら、答えは「民営借家」の行に近づくと考えられる（推測）。
- 地域差指数は同じ品目の価格の差で、地方で車が必要になる、通勤時間が長い、店まで遠い、といった暮らし方の違いは入らない。住まいの広さの違いも入らない。
- 所得は課税対象所得÷納税義務者数（税を納める人1人当たり）と1人当たり県民所得の2つ。税を納めない人や世帯の人数の違いは入らない。世帯単位の可処分所得ではない。
- 課税対象所得は前年の所得で、年の表記は統計表に合わせた。地域差指数と1年ずれていることがある。
- 世帯の型の重みは全国の平均の支出の割合で、地域ごとの暮らし方の違い（同じ世帯の型でも地域で支出の割合が違う）は入れていない。
- 都道府県の平均の比較で、同じ県の中の差や、個人の暮らしの豊かさを順位づけするものではない。
