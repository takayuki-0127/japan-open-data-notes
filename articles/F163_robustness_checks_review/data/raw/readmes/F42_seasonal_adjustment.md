# F42 季節調整を自分でやってみる：公表値と同じになるか？

note：季節調整を自分でやると、公表値と同じになるか？ X-13ARIMA-SEATSで鉱工業指数と労働力調査を再現すると、就業者は0.02ポイントの差でほぼ一致。鉱工業は曜日と祝日の調整を入れないと前月比の向きが4か月に1回ずれた（看板記事 F42）

## 問い

毎月のニュースで使われる「季節調整値」は、どうやって作られているのか。公表元が説明している設定どおりに、原数値から自分で季節調整すると、公表値とどれだけ一致するか。曜日や祝日の並びの効果はどれくらいか。新しい月が加わると、前月比はどれだけ変わるのか。

## データ

| データ | 出典 | 使った系列 |
|---|---|---|
| 鉱工業指数（2020年基準） | 経済産業省 | 鉱工業総合の生産（付加価値額生産）・出荷。原指数と季節調整済指数。2018年1月〜2026年8月は2020年基準、それ以前は接続指数（1978年〜） |
| 労働力調査 長期時系列表1 a-1 | 総務省統計局（e-Stat） | 労働力人口・就業者・雇用者・完全失業者・非労働力人口・完全失業率（男女計）。原数値・季節調整値・公表の季節指数（2016〜2026年） |
| 一般職業紹介状況 第3表-1 | 厚生労働省（e-Stat） | 有効求人倍率（パートを含む一般）。実数・季節調整値 |

`data/raw/` に取得済みのファイルを置いています（労働力調査と有効求人倍率は 2026-10-26、鉱工業指数は 2026-10-27 に取得。鉱工業指数は鉱工業総合の行だけを抜き出した CSV）。`data/series.csv` は 02 で作る「原数値と公表の季節調整値」の表です。

## 手法

季節調整は米国センサス局の **X-13ARIMA-SEATS**（X-11 方式）で行いました。本体は `pip install x13as` で入るものを使い、設定ファイル（spec）を Python から書いて呼び出しています（`src/common.py` の `run_x13`）。

**公表元の説明どおりの設定**

| | 鉱工業指数（経済産業省の説明） | 労働力調査（総務省の説明） |
|---|---|---|
| 手法 | X-12-ARIMA（事前調整 regARIMA ＋ X-11） | X-12-ARIMA（主要系列は 2013年から regARIMA） |
| 計算期間 | 12年。毎年の年間補正で最新1年分の季節指数だけを入れ替える | 毎年1月に前年12月までのデータで計算し、過去10年分を再計算、当年分は予測 |
| 暦の調整 | 2曜日調整（平日と土日）＋日本の祝日（平日に当たる祝日数 − 同じ月の平均）＋うるう年 | なし |
| 管理限界 | 1.5σ〜2.5σ | 9.8σ〜9.9σ |

- **鉱工業**：年間補正をまねて、2018〜2022年は2011〜2022年のデータ（2020年基準の改定時）、2023年は2012〜2023年、2024年は2013〜2024年、2025年は2014〜2025年のデータで計算した季節指数をつなぎました。2026年は2025年の計算の予測値です。曜日は X-13 の `td1coef`、祝日は `holidays` パッケージで作った変数（`usertype=holiday`）。ARIMA の次数は自動選択（automdl）、外れ値（AO・LS）は自動で探しました。公表元は外れ値を「経済活動から見て妥当なもの」を選んで設定しているので、ここは同じにはなりません。
- **労働力調査**：1990年1月〜2025年12月のデータで計算し、2016〜2025年の季節指数（公表の再計算値）と2026年の予測値を、公表の季節指数シートと比べました。
- **有効求人倍率**：公表元の細かい設定は確認していないので、標準的な設定（対数、ARIMA 自動、外れ値自動）で比べた参考値です。
- **STL**：statsmodels の STL（対数、周期12、季節の窓13、ロバスト）。
- **改定**：2023年1月〜2025年8月の各月について、その月までのデータで計算したときの前月比（初回）と、2026年8月までのデータで計算した前月比を比べました。「毎月計算し直す」方式と、「前年12月までで計算し、当年は予測した季節指数を使う」方式（年に1度、公表のやり方に近い）の2通り。

**比べる指標**：季節指数の差（指数ポイント、100が平均）、季節調整値の水準の差（%、率は%ポイント）、前月比の差・相関・向きの一致率。完全失業率と有効求人倍率は、自作を公表と同じ桁（0.1%・0.01倍）に丸めて比べました。

## 主な結果

**1. 労働力調査はほぼ一致した**（2016〜2025年、120か月）

| 系列 | 季節指数の差の平均 | 季節調整値の差の平均 | 前月比の相関 | 前月比の向きの一致率 |
|---|---|---|---|---|
| 就業者 | 0.024 | 0.005% | 0.999 | 95.8% |
| 雇用者 | 0.028 | 0.008% | 0.999 | 99.2% |
| 労働力人口 | 0.027 | 0.008% | 0.999 | 94.1% |
| 非労働力人口 | 0.025 | 0.007% | 1.000 | 95.8% |
| 完全失業者 | 0.302 | 0.316% | 0.996 | 93.3% |
| 完全失業率 | 0.480 | 0.028%pt | 0.763 | 67.2% |

- 就業者の季節調整値の差は平均0.005%（約0.3万人）。2026年1〜8月（予測した季節指数）でも差は0.025でした。
- 完全失業率は、自分で率を直接調整すると公表値（0.1%刻み）と一致したのは72.5%の月でした。一方、公表の「季節調整済みの完全失業者 ÷ 季節調整済みの労働力人口」は、2000年以降の92.8%の月で公表の失業率と一致しました。公表の失業率は人数から計算している可能性が高いと考えています（推測です。公表資料で確かめてはいません）。

**2. 鉱工業は曜日・祝日の調整が決め手だった**

| 鉱工業生産 | 季節指数の差の平均（最大） | 前月比の相関 | 前月比の向きの一致率 |
|---|---|---|---|
| 公表元の説明どおり：2025年 | 0.13（0.50） | 0.978 | 100% |
| 公表元の説明どおり：2026年1〜8月（予測） | 0.19（0.45） | 0.986 | 100% |
| 公表元の説明どおり：2018〜2024年 | 0.43（2.36） | 0.922 | 91.6% |
| 曜日・祝日の調整なし：2025年 | 1.34（3.07） | 0.778 | 72.7% |

- 鉱工業出荷は2025年で0.42（前月比の向き 90.9%）。
- 2018〜2024年の差が大きいのは、コロナ期の外れ値の扱い（公表元は判断で設定）や、2020年基準の改定時の設定の違いが残るためと考えています（推測）。

**3. 曜日・祝日の効果**（鉱工業は2014〜2025年、労働力調査・有効求人倍率は1990〜2025年で推定）

| 系列 | 平日1日（土日1日と入れ替え） | 平日の祝日1日 |
|---|---|---|
| 鉱工業生産 | +1.89%（t=10.7） | −1.27%（t=−3.7） |
| 鉱工業出荷 | +1.76%（t=9.9） | −1.17%（t=−3.2） |
| 就業者 | −0.02%（t=−2.1） | +0.01%（t=0.6） |
| 完全失業者 | −0.05%（t=−0.4） | +0.33%（t=1.1） |
| 有効求人倍率 | +0.06%（t=1.1） | −0.25%（t=−2.2） |

- 鉱工業生産の暦要素（曜日・祝日・うるう年）は、2014〜2026年で −2.97%〜+3.77%。稼働日数が同じ月の平均より1日多いと、ほぼ2%高く出ます。
- 労働力調査は月末1週間の状態を聞く調査で、曜日の効果はほとんどありません。曜日・祝日の調整を入れると、かえって公表と離れました（就業者で季節指数の差 0.024 → 0.151）。

**4. STL と X-13**（前月比の向きの一致率）

| 系列 | X-13（公表元の説明どおり） | X-13（曜日・祝日なし） | STL |
|---|---|---|---|
| 鉱工業生産（2018〜2025年） | 88.4% | 74.7% | 72.6% |
| 就業者（2016〜2025年） | 95.8% | ― | 87.4% |
| 完全失業者（2016〜2025年） | 93.3% | ― | 89.9% |

STL は曜日・祝日の調整ができないので、鉱工業では「曜日・祝日なしの X-13」とほぼ同じ程度しか合いません。

**5. 新しい月が加わったときの改定**（2023年1月〜2025年8月の32か月、前月比の改定幅の平均絶対値）

| 系列 | 毎月計算し直す | 年に1度だけ計算 | 前月比の向きが変わった割合（毎月／年1回） |
|---|---|---|---|
| 鉱工業生産 | 0.69ポイント | 1.12ポイント | 18.8%／18.8% |
| 完全失業者 | 0.71ポイント | 1.27ポイント | 3.1%／6.3% |
| 就業者 | 0.07ポイント | 0.09ポイント | 9.4%／12.5% |

公表のやり方（年に1度）は、毎月の数字が翌年まで動かない代わりに、あとで直される幅は大きくなります。

## 頑健性

`results/robustness.csv`。公表との季節指数の差の平均（鉱工業は2025年1月〜2026年8月、労働力調査は2016年1月〜2026年8月）。

| 設定 | 鉱工業生産 | 就業者 | 完全失業者 |
|---|---|---|---|
| 基本（公表元の説明どおり） | 0.153 | 0.024 | 0.295 |
| ARIMA を (0 1 1)(0 1 1) に固定 | 0.153 | 0.025 | 0.339 |
| 外れ値を探さない | 0.175 | 0.039 | 0.295 |
| 2020年4〜6月を外れ値（AO）に固定 | 0.156 | 0.032 | 0.335 |
| 曜日だけ（祝日なし） | 0.268 | ― | ― |
| 祝日だけ（曜日なし） | 1.313 | ― | ― |
| 曜日・祝日の調整なし | 1.250 | ― | ― |
| X-11 の既定（事前調整なし） | 1.418 | ― | ― |
| 管理限界を X-13 の既定（1.5σ〜2.5σ）に | ― | 0.039 | 0.414 |
| 曜日・祝日の調整を入れる | ― | 0.151 | 0.418 |
| 計算を2000年から／2010年から | ― | 0.026／0.036 | 0.486／0.505 |

- 系列を変えても（鉱工業2系列、労働力調査6系列、有効求人倍率）、「公表元の説明どおり」に近づけるほど差は小さくなりました。
- 労働力調査では、総務省が説明している管理限界（9.8σ〜9.9σ、つまり極端な値をほとんど置き換えない）にすると、差が 0.039 → 0.024（就業者）、0.414 → 0.295（完全失業者）と小さくなりました。
- 鉱工業では、ARIMA の次数や外れ値の扱いより、曜日の調整のほうがずっと効いていました。

## このデータで言えないこと

- 公表元の細かい設定（外れ値の指定、ARIMA の次数、労働力調査の計算期間の始まり、有効求人倍率の設定）は分からないので、完全には一致しません。差が残る理由の説明は推測を含みます。
- 公表値の「その月に最初に出た値（速報）」は使っていません。改定の分析は、自分で作った季節調整値でのシミュレーションです。
- 季節調整値は推計値です。ここで一致したのは「同じ方法で計算すれば同じになる」ことで、季節調整値が景気の動きを正しく表していることの証明ではありません。
