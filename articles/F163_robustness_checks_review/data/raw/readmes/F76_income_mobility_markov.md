# F76 所得が高い県は、ずっと高いままか？（順位のマルコフ遷移行列・移動性の指標・定常分布）

看板記事 F76。note の記事：「所得が高い県は、ずっと高いままか？ 68年分の県民所得の順位をマルコフ遷移行列で追うと、5年後も7割が同じ5分位にとどまり、1年ごとの入れ替わりを重ねた予測は動きを1.6倍に見積もった」

## 問い

1人当たり所得の高い県（市区町村）は、ずっと高いままなのか。順位はどれくらいの速さで入れ替わるのか。今の入れ替わり方が続くと、県の所得の分布は最後にどうなるのか。

## データ（新しいダウンロードはなし）

- 都道府県：F71 で作った「県民経済計算」の1人当たり県民所得（基準年の違う7つの表を、つなぎ目の段差を消してつないだもの、1955〜2022年度）。沖縄を除く46都道府県で、46県の対数平均との差（相対所得）にした。頑健性で段差を消さない系列と、沖縄を含む47都道府県（1975年度〜）も使う
- 市区町村：F40 で作った「市町村税課税状況等の調」の納税者1人当たり課税対象所得（社会・人口統計体系、2005・2010・2015・2017・2020年度、1,741市区町村）
- `src/01_取得.py` は GitHub に置いた F71・F40 の表を `data/raw/` に取ってくる

## 手法

| 段階 | やったこと |
|---|---|
| 区分 | 各年の順位で5分位（都道府県は46県なので1区分9〜10県）。頑健性で3・4・6区分、市区町村は10分位も |
| 遷移行列 | t年度の区分 → t+5年度の区分の件数を、すべての出発年度で足し上げ、行で割る（都道府県 1955〜2017年度出発、2,898組） |
| 移動性の指標 | Shorrocks の M =（k − 対角の和）/（k − 1）、同じ区分にとどまる割合、第2固有値と「混ざり合う」半減期。区間は都道府県を復元抽出するブートストラップ（500回） |
| 期間の違い | 1955〜79・1975〜99・1995〜2022年度で行列を作り、Anderson–Goodman の尤度比検定で同じかを確かめる（出発年度が重なる組と、5年ごとの重ならない組の両方） |
| マルコフ性 | 1年の行列を5回・20回かけたものと、実際の5年・20年の行列を比べる |
| 定常分布 | 相対所得の水準で5区分（0.85・0.95・1.05・1.15 が境目）にした遷移行列の固有値1の左固有ベクトル |
| 順位の相関 | t年度と t+h年度のスピアマンの順位相関（h＝1〜60年） |

## 主な結果

- 都道府県の5年後の遷移（5分位）：同じ区分にとどまるのは平均69%。下位20%は85%、上位20%は80%、中位は58%。2区分以上動くのは1.9%。Shorrocks の M は0.39、混ざり合う半減期は35年
- 東京は68年間ずっと1位。県ごとの「いちばん高い順位といちばん低い順位の差」は中央値20.5位、最大38位
- 1955年度の下位20%の県の56%、上位20%の33%が、2022年度も同じ区分にいた（入れ替わりがでたらめなら20%）
- 順位相関：1年後0.98、5年後0.94、10年後0.90、20年後0.82、40年後0.66、60年後0.45
- 期間別の M：1955〜79年度 0.37（95%区間 0.25〜0.54）、1975〜99年度 0.41（0.29〜0.53）、1995〜2022年度 0.39（0.31〜0.53）。重なる組を全部使った検定は p=0.003 だが、重ならない組だけでは p=0.32 で、期間の違いは見分けられない（重なる組は独立でないので、前者は p を小さく見せる）
- マルコフ性：1年の行列を5回かけると「同じ区分にとどまる」は50%、実際の5年は69%。20年では28%と50%。1年の行列を重ねた予測は、入れ替わり（M）を0.62と、実際（0.39）の1.6倍に見積もる。1年ごとの入れ替わりの多くは翌年以降に元に戻る動きだと考えられる（推測）
- 定常分布（水準の5区分）：1955〜2022年度の遷移から求めた行き着く先は［0.08, 0.25, 0.39, 0.23, 0.06］で、2022年度の実際の分布［0.07, 0.30, 0.35, 0.24, 0.04］とほぼ同じ。1955年度の分布［0.20, 0.22, 0.26, 0.11, 0.22］より真ん中に寄っている
- 市区町村（5年、5分位）：とどまるのは77〜78%、M は0.27〜0.28 で、3期間ともほぼ同じ。順位相関は5年で0.95〜0.97、15年（2005→2020年度）で0.885（同じ期間の都道府県は0.878）
- 市区町村の規模（2015年度の納税者数で3つに分ける）：とどまる割合は小68%・中77%・大86%、2区分以上動くのは小5.3%・中0.5%・大0.2%

## 頑健性（`results/robustness.csv`）

| 設定 | M | とどまる割合 |
|---|---|---|
| 都道府県 3／4／5／6区分・5年 | 0.29／0.37／0.39／0.47 | 0.81／0.72／0.69／0.61 |
| 都道府県 5区分・1／10／20年 | 0.22／0.49／0.62 | 0.82／0.61／0.50 |
| 段差を消さない系列 | 0.38 | 0.70 |
| 47都道府県（1975年度〜） | 0.39 | 0.69 |
| 東京を除く45道府県 | 0.42 | 0.66 |
| 市区町村 2005→10／2010→15／2015→20 | 0.27／0.28／0.28 | 0.78／0.78／0.77 |
| 市区町村 2015→20（人口1万人以上） | 0.21 | 0.83 |

区分の数と年数で M の大きさは変わるが、「5年で大きく入れ替わることはなく、とどまる県が多い」点はどの設定でも同じ。

## このデータで言えないこと

- 都道府県の平均の動きで、そこに住む人の所得が上がったり下がったりしたことではない（人の移動や年齢構成の変化も混ざる）
- 「とどまる」理由（産業構成、人の流れ、政策など）は分からない
- マルコフ連鎖は「次の区分は今の区分だけで決まる」と仮定する。1年の行列で確かめた通り、この仮定は厳密には成り立たない
- 46県を5つに分けると1区分9〜10県で、行列の1つ1つの値は数件の違いで動く
- 市区町村は2005〜2020年度の15年しかなく、長い期間の入れ替わりは分からない。小さな町の動きには、納税者の少なさによる揺れも含まれる
