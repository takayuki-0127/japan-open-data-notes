# F19 小さな町の検診受診率はどこまで信用できるか？（小地域推定：Fay–Herriot モデル）

看板記事 F19。note の記事：「小さな町の検診受診率は、どこまで信用できるのか？ Fay–Herriot モデルで周りの町から情報を借りると、ぶれが大きいのは対象者500人未満の町で、翌年の値も少しよく当たった」

## 問い

市区町村の検診の受診率は、対象者が少ない町ほど年ごとにぶれる。似た町の情報を借りる「縮小推定」（Fay–Herriot モデル・経験ベイズ）で、より安定した値を出せるか。出せるなら、どの町でどれだけ値が動くか。

## データ

| データ | 内容 |
|---|---|
| 地域保健・健康増進事業報告 健康増進編 市区町村表 第20-1表（令和3〜6年度） | 大腸がん検診の対象者数・受診者数のうち「（再掲）国民健康保険の被保険者」、40〜69歳。e-Stat の CSV（statInfId 000040038221・000040165455・000040262026・000040423652） |
| SSDSE-A-2026（統計センター） | 共変量：65歳以上の割合、可住地人口密度（対数）、人口1万人あたりの一般診療所数・一般病院数、第1次産業就業者の割合、単独世帯の割合 |
| 行政区域の簡略版 TopoJSON（smartnews-smri/japan-topography、国土数値情報 行政区域 2021 をもとにしたもの、CC BY 4.0） | 地図だけに使用 |

- 設計では市町村国保の「特定健診」の受診率を使う予定だった。厚生労働省の公表は都道府県別・保険者の種類別までで、市町村国保ごとの表が見つからなかった。そこで設計の代替案どおり、市区町村ごとに対象者数と受診者数がそろう「大腸がん検診（国保の被保険者）」に切り替えた
- 政令市は市全体の1行。「…」（計数不詳）の町と対象者0の町は除いた。2023年度は1,679市区町村
- 「-」は0として扱った。受診者0の町（2023年度は4町）は報告の仕方の違いかもしれないので、除いた版も頑健性で見た

## 手法

1. 受診率 p を角変換 z = arcsin(√p) する。この尺度では偶然のぶれの分散が 1/(4n)（n＝対象者数）で、p によらない
2. Fay–Herriot モデル：z_i = x_i'β + u_i + e_i、u_i ~ N(0, A)（町の本当の違い）、e_i ~ N(0, D_i = 1/(4n_i))（偶然のぶれ）
3. A を REML で推定し、縮小推定値 z̃_i = γ_i z_i + (1−γ_i) x_i'β、γ_i = A/(A + D_i) を計算（`src/fh.py` に実装）。x は共変量6つ（標準化）と都道府県ダミー
4. 年をまたぐぶれの実測から、二項分布以上のぶれ（過分散）を見積もり（φ ≒ 2.4）、D_i を φ 倍にした版も作った
5. 確かめ方：2023年度の直接の値と縮小推定値のどちらが、2024年度の直接の値に近いか（二乗誤差）。2022→2023 でも同じことをした

## 主な結果（2023年度）

- **ばらつきの大部分は本物の差**：全国の受診率は16.7%。偶然だけなら収まる範囲（99.8%）の外にある町が77%あった。町の本当の違いの標準偏差は、率に直して約7ポイント
- **縮小されるのは小さな町だけ**：直接の値に置く重み γ の中央値は、対象者500人未満で0.90（過分散ありで0.78）、1万人以上で0.998。値が動いた幅の中央値は500人未満で0.70ポイント、2,000〜1万人で0.03ポイント
- **年ごとのぶれ**：2023→2024年度の相関は、500人未満の町で0.79、1万人以上で0.97
- **翌年の当たり方**：縮小推定のほうが2024年度の値に近かった。二乗誤差の改善は全体で3.9%、500人未満の町で6.9%、1万人以上で0.2%。2022→2023年度で同じことをすると、全体13.3%、500人未満31.2%
- **ランキング**：直接の値の上位50には500人未満の町が23（全体での割合は13%）。縮小推定では20、過分散ありでは16。上位50の顔ぶれは46が同じまま。下位50は大きな市が中心（対象者の中央値5,272人）で、縮小しても50がそのまま
- **共変量**（1標準偏差あたり、全国の水準で率に直した目安）：人口密度 −2.7ポイント、第1次産業の割合 +1.6、診療所の多さ +0.8、単独世帯の割合 −0.8、高齢化 −0.7

## 頑健性

`results/robustness.csv`、図 `f19_validation.png`。

| 設定 | 翌年との誤差の改善（全体） | 同（500人未満） |
|---|---|---|
| 基本（共変量＋都道府県） | 3.9% | 6.9% |
| 共変量なし（全国平均へ寄せる） | 0.7% | 0.7% |
| 都道府県ダミーだけ | 1.2% | 1.0% |
| 共変量だけ | 2.3% | 4.1% |
| 過分散あり（D×φ） | 2.7% | 2.1% |
| 基本、2022→2023で検証 | 13.3% | 31.2% |
| 受診者0の町を除く | 4.6% | 8.4% |
| 都道府県ごとに別々に推定（38県） | 2.9% | 5.2% |

- どの設定でも改善はプラス。共変量を入れないと改善はほとんどない（「何に寄せるか」が大事）
- 都道府県ごとに別々に推定した値と全国一括の値の相関は0.999

## 言えないこと

- 受診率の違いの原因は分からない。人口密度などとの関係は「条件をそろえた関連」で、因果ではない
- 町の取り組みの評価にはならない。検診は職場や人間ドックでも受けられ、ここにあるのは市区町村が行った検診の国保の被保険者分だけ
- 縮小推定は「似た町の水準」へ寄せる。本当に飛び抜けた町があっても、対象者が少ないと控えめに出る
- 受診者0の町などは、報告の仕方の違いの可能性がある
