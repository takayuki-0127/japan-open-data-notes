# F56 住宅価格指数を「繰り返し売買法」で作ると、ヘドニックと同じになるか？

note の看板記事「住宅価格指数を『繰り返し売買法』で作ると、ヘドニックと同じになるか？ 東京の中古マンション6.6万組で比べると、そのままでは+45%とヘドニックの+77%より小さく、差のほとんどは『売り直すまでに古くなった分』だった」の分析コード・データ・図です。

## 問い

同じ住戸が2回売られたときの価格の変化だけで指数を作る「繰り返し売買法」（米国の Case–Shiller 指数の方法）を、東京の中古マンションの取引データで作ると、物件の特徴をそろえる「ヘドニック法」（記事037）と同じ上がり方になるか。違うなら、なぜか。

## データ

- 国土交通省 不動産情報ライブラリ「不動産取引価格情報」：東京都・中古マンション等、2015年1〜3月期〜2026年1〜3月期（記事037と同じファイル、182,555件）
- 037 と同じ条件（取引の事情等あり・住宅以外・築60年超・15㎡未満／200㎡超・駅1時間以上・㎡単価の上下0.5%を除く）で 172,706件
- **住戸の ID はない**ので、「同じ市区町村・地区・最寄駅と距離・建築年・構造・都市計画・建ぺい率・容積率・間取り・面積」を同じ住戸の代わりにした（同じ建物の同じタイプの住戸。階や向きは違いうる）。同じキーの取引を時期順に並べ、となり合う2件をペアにした（同じ四半期どうしは除く）
- ペア：65,532組（28,121キー）。間隔の中央値は5四半期（1.25年）

## 手法

| 段階 | 内容 |
|---|---|
| 繰り返し売買法 | ペアの log ㎡単価の差を、四半期ダミー（2回目＝+1、1回目＝−1）で回帰（Bailey–Muth–Nourse）。Case–Shiller の3段階（残差の2乗を間隔で説明し、その逆数で重み付け）を基本にした |
| 区間 | キーごとに取り直すブートストラップ200回 |
| 築年の補正 | 同じ住戸は売り直すまでに古くなる。ヘドニック回帰の築年数の係数（2次）でその分を差し引いた版も作った |
| ヘドニック法 | 037 と同じ式（四半期ダミー＋市区町村＋築年数・面積・駅距離の2次＋構造＋改装）。全取引と、ペアに入った取引だけの2通り |
| 改定 | 2020年末までのデータだけで作った指数と、全期間で作った指数の2015〜2020年の差 |

## 主な結果（2015年平均→2025年平均）

| 指数 | 上昇率 |
|---|---|
| 単純な中央値 | +60.6% |
| 繰り返し売買法（そのまま、CS） | **+45.0%**（95%区間 +43.7〜+46.4） |
| 繰り返し売買法（重みなし） | +45.0% |
| 繰り返し売買法（築年の効果を差し引く） | **+80.5%** |
| ヘドニック法（全取引） | **+77.3%** |
| ヘドニック法（ペアに入った取引だけ） | +76.4% |

- ヘドニックの築年数の係数から計算すると、同じ住戸は1年で約2.2%分、古くなって安くなる。繰り返し売買法はこの分を「価格が上がらなかった」と数えてしまう
- 四半期ごとの変化の相関：繰り返し売買法（そのまま）とヘドニック 0.37 → 築年を差し引くと 0.84
- 四半期ごとの変化の標準偏差：ヘドニック 1.44%、繰り返し売買法 0.86%、中央値 1.78%（繰り返し売買法がいちばんなめらか）
- 2020年→2025年：ヘドニック +40.1%、繰り返し売買法 +26.9%、築年を差し引くと +41.3%
- ペアに入る取引は、全体より面積が小さく（40.2㎡ 対 46.1㎡）、やや新しく（築18.2年 対 19.9年）、23区が多い（90% 対 87%）
- ペアの28%は、1回目と2回目で「改装済み」かどうかが変わっていた
- 改定：2020年末までのデータで作った指数と全期間の指数の差（2015〜2020年の四半期の平均）は、繰り返し売買法（重みなし）0.32%、ヘドニック 0.21%

## 頑健性（繰り返し売買法、2015→2025年）

| 設定 | 上昇率 |
|---|---|
| 基本 | +45.0% |
| 重みなし（BMN） | +45.0% |
| 築年の効果を差し引く | +80.5% |
| 改装の有無が変わったペアを除く | +40.1% |
| 1年未満の転売を除く | +43.2% |
| 築3年未満の売り出しを除く | +47.2% |
| 同じ建物（間取り・面積は問わず、面積の違いをヘドニックで補正） | +41.6% |
| 23区だけ／23区以外だけ | +47.1%／+31.6%（ヘドニックでは +79.3%／+66.4%） |

## 言えないこと

- 同じ住戸かどうかは分からない。「同じ建物・同じ間取り・同じ面積」の別の住戸（階や向きが違う）が多く入っているはずで、間隔の短いペアが多いのもそのためだと考えられる（推測）
- 築年の補正は、ヘドニック回帰（ほかの物件との比較）から借りた係数に頼っている。同じ住戸の中では、時間がたつことと古くなることを分けられない（繰り返し売買法のよく知られた問題）
- ペアになる物件は狭め・23区が多めで、市場全体を代表していない
- 改装・管理状態・階数の違いはそろえられていない。取引価格情報はアンケートにもとづくもので、すべての取引ではない
- 2026年1〜3月期は件数が少なく、今後変わりうる
