# F46 産業構成で決まる「雇用ショック」は、人を動かしたか？ シフトシェア（バーティク）操作変数

note：「雇用が増えた町に、人は集まったのか？ 産業構成から作る『バーティク操作変数』で1,736市区町村を分析すると、効果はプラスに出たが、同じ操作変数が5年前の転入超過まで説明してしまった」（看板記事 F46）

## 問い

雇用が増えた市区町村ほど、人が転入してくるのか。「雇用が伸びたから人が来た」のか「人が来たから雇用が伸びた」のかは、普通の回帰では分けられません。そこで、**その町の産業構成 × 全国の産業ごとの伸び**で雇用の伸びを予測した値（バーティク操作変数）を使い、2段階最小二乗法（2SLS）で因果に近い形で推定できるかを試しました。あわせて、この操作変数の前提が成り立っているかを、Rotemberg 重みと事前トレンド（プラセボ）で確かめました。

## データ

| 中身 | 出どころ | 年 |
|---|---|---|
| 産業大分類（18）別の従業者数（民営） | 経済センサス（基礎調査2014、活動調査2016・2021）。e-Stat「社会・人口統計体系 市区町村データ」から取得 | 2014・2016・2021 |
| 転入者数・転出者数 | 住民基本台帳人口移動報告（同上） | 2009〜2024 の各年 |
| 総人口・年齢3区分人口 | 国勢調査（同上） | 2005・2010・2015・2020 |
| 都道府県間の移動（参考分析） | 住民基本台帳人口移動報告 長期時系列 第11表（F33 で取得したものを再利用） | 2016〜2020 |

- 単位は1,740市区町村（政令市は市全体、東京23区は区ごと）。人口・雇用の欠けた4町村を除いた **1,736** を分析しました
- 結果：2016〜20年の転入超過数の合計 ÷ 2015年の人口（%、上下1%で丸め）
- 雇用の伸び：2016→21年の従業者数の伸び（%、上下1%で丸め）
- バーティク：Σ（2016年の産業シェア）×（全国の産業別の伸び 2016→21、自分の町を除いて計算）
- 統制：2015年の人口（対数）、65歳以上の割合、15〜64歳の割合、都道府県の固定効果。標準誤差は都道府県でクラスター

## 手法

1. バーティク操作変数を作る（自分を除いた全国の伸びを使う leave-one-out）
2. 最小二乗法（雇用の伸び → 転入超過）
3. 2SLS（第1段階：バーティク → 雇用の伸び）
4. 第1段階の強さ（クラスター頑健な F 値）と、弱い操作変数でも使える Anderson–Rubin の区間
5. Rotemberg 重み（Goldsmith-Pinkham, Sorkin and Swift 2020）で、どの産業が推定値を決めているかを調べる
6. 事前トレンド：同じバーティクで、それより前（2010〜14、2011〜15）の転入超過を説明できてしまうか

## 主な結果

- 2016→21年の全国の民営の従業者は **+1.9%**。産業ごとの伸びは、宿泊・飲食 **−12.7%**、生活関連・娯楽 −10.1%、情報通信 **+21.1%**、学術研究・専門サービス +15.2%、医療・福祉 +10.7%（コロナの影響を含む）
- 第1段階：バーティク1%ポイントあたり実際の雇用の伸びは +0.72%ポイント（0.38〜1.05）、**F = 17.5**（目安の10を上回る）
- 雇用の伸び1%ポイントあたりの5年間の転入超過率（%ポイント）

| 推定 | 係数 | 95%区間 |
|---|---|---|
| 最小二乗法（県FEあり） | 0.076 | 0.058〜0.094 |
| **2SLS（県FEあり）** | **0.144** | **0.048〜0.240**（Anderson–Rubin 0.04〜0.24） |
| 最小二乗法（県FEなし） | 0.082 | 0.066〜0.098 |
| 2SLS（県FEなし） | 0.105 | −0.074〜0.285 |

  雇用が10%ポイント多く伸びた町では、5年間の転入超過が人口の約1.4%ポイント多い、という大きさです（最小二乗法では約0.8%ポイント）
- **Rotemberg 重み**：宿泊・飲食が **0.49** と、推定値のほぼ半分を決めていました。続いて医療・福祉 0.12、その他サービス 0.12、情報通信 0.07。負の重みの合計は −0.03 と小さい。つまりこの操作変数は、ほぼ「コロナで宿泊・飲食が落ち込んだ町かどうか」を見ています
- **事前トレンド（プラセボ）**：2016→21 のバーティクは、本期の転入超過（2016〜20）を 0.103（0.014〜0.192）で説明しますが、**それより前の2010〜14年の転入超過も 0.119（0.018〜0.219）、2011〜15年も 0.125（0.021〜0.229）** と同じ大きさで説明してしまいました。産業構成が、雇用のショックとは別の理由で、もともとの人の流れと関係している可能性が高い（操作変数の前提が崩れている）と考えられます
- 前期（2011〜15）の転入超過を統制すると、2SLS は **0.073（−0.022〜0.168）** に下がり、区間が0をまたぎました
- 都道府県（47）で同じ分析をすると、F = 2.1 と第1段階が弱く、2SLS は 0.52（−0.00〜1.04）で決め手になりません

## 頑健性（2SLS、カッコ内は95%区間と第1段階の F）

| 設定 | 2SLS |
|---|---|
| 基本 | 0.144（0.048〜0.240、F=17.5） |
| 県FEなし | 0.105（−0.074〜0.285、F=17.0） |
| 人口で重みづけ | 0.260（0.129〜0.391、F=19.3） |
| 東京圏（1都3県）を除く | 0.096（−0.003〜0.195、F=15.1） |
| 転入超過を2017〜21に | 0.149（0.047〜0.252、F=17.5） |
| 基準年を2014に（シェア2014、伸び2014→21） | 0.149（0.037〜0.261、F=20.7） |
| 産業を8分類にまとめる | 0.059（−0.081〜0.198、F=15.2） |
| 自分を除かない全国の伸び | 0.143（0.048〜0.238、F=17.7） |
| 人口1万人以上 | 0.189（0.017〜0.360、F=17.6） |
| 前期（2011〜15）の転入超過を統制 | 0.073（−0.022〜0.168、F=17.6） |
| 期間 2014→16 | 0.517（−0.254〜1.288、F=1.5：弱い操作変数） |

符号はどの設定でもプラスですが、事前トレンドを統制する、産業を粗くする、県FEを外す、東京圏を除く、のいずれでも区間が0をまたぎます。

## 言えないこと

1. 事前トレンドのテストに引っかかったので、2SLS の値を「雇用が増えたから人が来た」効果とは言えません。産業構成（とくに宿泊・飲食の割合）が、観光地・地方の小さな町といった、もともと人が出ていきやすい町の特徴と重なっている可能性があります（推測です）
2. 2016→21年の雇用の変化にはコロナの影響が強く入っていて、ふだんの景気の波とは性格が違います
3. 経済センサスは2014年が基礎調査、2016・2021年が活動調査で、調査の方法が違います（2014→16 の比較はとくに注意）
4. 民営の事業所だけで、公務は入っていません。従業者は「その町で働いている人」で、住んでいる人ではありません
5. 転入超過は住民票の届け出にもとづく数で、届け出のない移動は入っていません
