# F16 保育所に通う子どもが増えた市区町村で、女性は働きに出たのか？（ダブル機械学習）

看板記事 F16。保育所等に通う子どもが増えた市区町村で、女性の労働力率がどれだけ上がったかを、80の地域の条件を機械学習で取り除く **ダブル機械学習（DML、部分線形モデル）** で推定しました。

## 問い

2010→2015年に、保育所等に通う子ども（0〜5歳100人あたり）が増えた市区町村ほど、女性の労働力率は上がったか。保育所は「働きたい人が多い町」で増えるので、単純な比較には逆向きの関係や地域の性格が混ざる。それを、たくさんの条件で取り除いてから比べる。

## データ

- e-Stat「社会・人口統計体系 市区町村データ」（総務省統計局）。2005・2008・2010・2013・2015・2017・2020年度の市区町村の値を、2026年10月26日に取得（`data/raw/f16_ssds_municipal.json`、取得の方法は `src/01_取得.md`）
  - 結果：女性の労働力率＝労働力人口（女）F110102 ÷（労働力人口（女）＋非労働力人口（女）F110802）。国勢調査の値
  - 処置：保育所等在所児数（詳細票）J2506 ÷ 0〜5歳人口 A1405 × 100
  - 地域の条件：人口・密度・年齢構成・世帯の形・産業・通勤・昼夜間人口比率・所得・財政力・児童福祉費・学歴・雇用の形、2005→10年の変化（前の傾向）、同じ期間の年齢構成の変化、都道府県（46のダミー）。合わせて80列
- 対象：0〜5歳が100人以上の市区町村（政令市は市全体、東京23区は区ごと）で、値がそろう **1,611**

## 手法

| 段階 | 内容 |
|---|---|
| 差をとる | 2010→2015年の変化どうしを比べ、変わらない地域の性格を消す |
| 1つめの予測 | 労働力率の変化 Y を、地域の条件 X から予測（ランダムフォレスト／LightGBM／Lasso） |
| 2つめの予測 | 在所児の変化 D を、同じ X から予測 |
| 残差どうしの回帰 | Y の外れ（Y−予測）を D の外れ（D−予測）で回帰し、係数を効果とする。5分割の交差適合（予測に使ったデータでは推定しない）を5回くり返し、中央値をとる（DoubleML） |
| 比べる相手 | 単純な回帰、同じ X を直線で入れた重回帰 |

効果の単位は「在所児が0〜5歳100人あたり **10人** 増えたとき、女性の労働力率が何ポイント変わるか」。

## 主な結果

| 推定 | 係数 | 95%信頼区間 |
|---|---|---|
| 単純な回帰 | +0.048 | −0.021〜+0.117 |
| 重回帰（80列を直線で） | +0.048 | −0.012〜+0.108 |
| DML（Lasso） | +0.047 | −0.010〜+0.103 |
| **DML（ランダムフォレスト）** | **+0.061** | **−0.002〜+0.125** |
| DML（LightGBM） | +0.066 | +0.006〜+0.125 |

- 2010→15年に、在所児は平均 +6.7（100人あたり）、女性の労働力率は平均 +0.88ポイント。単純な相関は 0.04
- 効果は **プラスだが小さい**。+10人で +0.06ポイント前後。1人あたりに直すと、在所児が1人増えるごとに、労働力の女性が **約0.06人** 増えた計算（区間の上限でも約0.12人）。新しく保育所に入った子どもの多くは、もともと働いていた母親の子どもだった可能性と合う
- データの分け方を20通り変えても、推定値は +0.054〜+0.081 で、すべてプラス
- 予測の当てはまり（交差適合での R²）：Y は 0.35〜0.46、D は 0.13〜0.18。Y の予測には「女性の65歳以上の割合の変化」（高齢化）がいちばん効いた
- 人口密度で3つに分けると、地方 +0.087、中間 +0.006、都市 +0.075。どれも区間が0をまたぎ、はっきりした差は言えない

## 頑健性

| 設定 | 係数 | 95%信頼区間 |
|---|---|---|
| 分割数 2 ／ 10 | +0.059 ／ +0.060 | どちらも下限が −0.005前後 |
| 乱数を変える | +0.068 | +0.004〜+0.133 |
| 極端な1%を除く | +0.051 | −0.027〜+0.129 |
| 人口1万人未満を除く | +0.028 | −0.045〜+0.102 |
| 県のダミーなし | +0.064 | +0.000〜+0.127 |
| 前の傾向（2005→10年）を入れない | +0.045 | −0.019〜+0.109 |
| 結果を就業率に | +0.087 | +0.017〜+0.155 |
| 長い差（在所児 2010→17年・認定こども園を含む／労働力率 2010→20年） | +0.030 | −0.011〜+0.070 |
| **プラセボ**：前の5年（2005→10年）の労働力率の変化を、後の在所児の変化で説明 | −0.037 | −0.119〜+0.047 |

向きはどの設定でもプラスで、プラセボは0と区別できない（「もともと労働力率が伸びていた町で保育所が増えた」形跡は見えない）。ただし、区間が0をまたぐ設定も多く、効果の大きさは「あっても小さい」にとどまる。

## 言えないこと

- 80の条件で取り除けない要因（共働きを望む若い世帯の転入、企業の求人など）があれば、推定は偏る。DML でも観察されない交絡は消えない
- 結果は15歳以上の女性全体の労働力率で、子育て中の母親だけの値ではない（市区町村別・年齢別の値が手に入らなかった）。母親への効果は、この数字より大きく出るはず
- 処置は「定員」ではなく「在所児数」（市区町村別の定員は公表されていない）。在所児は需要にも左右される
- 2015年は認定こども園への移行が始まった年で、J2506 に含まれない施設に移った分は「減った」ように見えることがある（長い差でこども園を足して確かめた）
- 世帯ごとの選択（誰が預けて働き始めたか）は分からない

政府統計の総合窓口(e-Stat)（https://www.e-stat.go.jp/）「社会・人口統計体系 市区町村データ」（総務省統計局）を加工して作成。もとの統計は国勢調査・社会福祉施設等調査・市町村税課税状況等の調・地方財政状況調査など。
