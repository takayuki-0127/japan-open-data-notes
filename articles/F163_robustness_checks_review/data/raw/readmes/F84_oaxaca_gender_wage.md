# F84 男女の賃金差のうち、「説明できる部分」はどれだけか？（集計データ版の Oaxaca–Blinder 分解）

note：男女の賃金差のうち、「説明できる部分」はどれだけか？ 2025年の賃金構造統計でOaxaca–Blinder分解すると、説明できるのは約3割（設定により1〜4割）。いちばん大きいのは勤続年数で、差そのものは50代後半で最も大きかった

## 問い
2025年の一般労働者の所定内給与は、男性 37.3万円、女性 28.6万円（女性は男性の 77%）。この差のうち、年齢・学歴・勤続年数・産業・企業規模という「働き方の構成の違い」で説明できる部分はどれだけで、どの要素がいちばん効いているか。残りの「説明できない部分」が何を意味し、何を意味しないかもあわせて整理する。

## データ（令和7年＝2025年 賃金構造基本統計調査、一般労働者、全国）
| 表 | 中身 | 使い方 |
|---|---|---|
| 産業大分類 第1表（statInfId 000040420843） | 産業（19）×企業規模（3）×性×学歴（6）×年齢階級（12）ごとの平均年齢・平均勤続年数・所定内実労働時間・超過実労働時間・きまって支給する現金給与額・所定内給与額・年間賞与・労働者数 | 本体の分解（セル＝産業×規模×学歴×年齢） |
| 第2表（statInfId 000040420844） | 企業規模×性×学歴×年齢階級×勤続年数階級（9）ごとの所定内給与額・年間賞与・労働者数 | 組み替え（DFL）による頑健性 |

- セルは「学歴不明」を除き、労働者数・給与・時間が正のものだけ（男 2,978、女 2,745 セル）。セルから組み立てた平均（男 37.7万円、女 29.0万円）は、学歴不明を除くため公表値（37.3万円・28.6万円）と少しずれる
- F54 のデータ（都道府県×年齢）は勤続・産業・規模がないため、今回は全国の表を新たに取得した。取得手順は `src/01_取得.md`

## 手法
| 段 | 中身 |
|---|---|
| 回帰 | 男女別に、セルの対数所定内給与を 年齢（12区分）＋学歴（6）＋勤続年数（セルの平均と2乗）＋産業（19）＋企業規模（3）に加重回帰（重み＝労働者数） |
| 分解 | 男女差 = 説明できる部分（平均の構成の差 × 基準の係数）＋ 説明できない部分（係数の差）。基準は本体が男性の係数、頑健性で女性の係数、プール（女性ダミー入り、Neumark 型） |
| 要素別 | 説明できる部分を 年齢・学歴・勤続・産業・企業規模 のグループごとに足し上げる |
| 年齢の中 | 年齢階級ごとに同じ分解（学歴・勤続・産業・規模） |
| 組み替え | 第2表で、女性の構成（規模×学歴×年齢×勤続の 1,467 セル）を男性の構成に組み替えた場合の平均（DiNardo–Fortin–Lemieux 型、回帰の形に頼らない） |

注意：対数の差（×100）はおおよそ「％の差」と読めます（24.5 ≒ 女性が男性より約22%低い）。

## 主な結果
| 項目 | 値 |
|---|---|
| 男女差（対数×100） | 24.5 |
| 説明できる部分 | 6.9（28%） |
| 　うち勤続 | +6.4 |
| 　うち学歴 | +1.5 |
| 　うち年齢 | +0.4 |
| 　うち企業規模 | +0.3 |
| 　うち産業 | −1.8（女性の多い医療・福祉などの産業構成は、この調査の所定内給与では差を少し縮める向き） |
| 説明できない部分 | 17.6（72%） |

- 平均勤続年数は男性 14.4年、女性 10.5年。説明できる部分のほとんどはこの差から来ている
- 年齢の中で分けると、差は 20〜24歳で 2.4 → 30〜34歳 15.2 → 55〜59歳 35.2 と広がり、60歳以降は縮む。説明できる部分は 50〜54歳（9.2）・55〜59歳（7.6）で大きいが、30代はほぼ 0。若い世代の差は、ここで使える変数ではほとんど説明できない
- 時間あたり（所定内給与÷所定内時間）でも差は 21.9 残り、説明できる部分は 29%

## 頑健性
| 設定 | 差 | 説明できる割合 |
|---|---|---|
| 基本（男性の係数） | 24.5 | 28% |
| 女性の係数 | 24.5 | 24% |
| プールの係数 | 24.5 | 30% |
| 時間あたり | 21.9 | 29% |
| きまって支給（残業代込み） | 28.0 | 26% |
| 年間（12×きまって＋賞与） | 30.8 | 34% |
| 産業・規模を入れない | 24.5 | 41% |
| 勤続を入れない | 24.5 | 16% |
| セルを重みづけしない | 19.8 | 13% |
| 組み替え（女性の賃金表で評価） | 24.7 | 25% |
| 組み替え（男性の賃金表で評価） | 24.7 | 30% |

- 基準の取り方・賃金の定義・回帰に頼らない組み替えのどれでも、説明できる部分は 2〜3割台にとどまる
- 変数の組み合わせで最も動くのは勤続。勤続を外すと 16% に下がり、組み替え（男性の賃金表で評価）でも勤続の区分を外すと説明できる部分が 0.075 → 0.049 に下がる（学歴を外すと 0.052、規模 0.072・年齢 0.069 はあまり変わらない）
- 産業・規模を入れないと 41% に上がるのは、産業の寄与がマイナスだから（産業を入れると説明できる部分が減る）
- 重みなしでは 13% と低い。小さなセルを大きなセルと同じ重さで扱うためで、本体は労働者数で重みづけした結果を使う

## 設計から変えたこと
- 年による頑健性（設計の「年」）は行わず、2025年だけで分析した。代わりに賃金の定義（時間あたり・残業代込み・年間）と、回帰に頼らない組み替えを足した
- 設計の代替案（年齢と勤続だけ）ではなく、学歴・産業・企業規模まで入れた本体で行えた

## 言えないこと
- **説明できない部分を「差別」とは言えない。** ここでの「説明できない」は「この表にある5つの変数では説明できない」という意味でしかない。職種、役職、雇用形態（正社員かどうか）、転勤の有無、労働時間の選び方、出産・育児による中断の履歴など、表にない違いはすべてこの部分に入る。逆に、勤続や産業の違いそのものが、採用・昇進・働き続けやすさの違いの結果である可能性もあり、「説明できる部分」が問題ないという意味でもない
- **集計データの限界。** 個人のデータではなく、セル（産業×規模×学歴×年齢）の平均を使っている。セルの中のばらつき（同じセルの中での男女の勤続や職種の違い）は見えず、セルの平均の対数は個人の対数の平均とは一致しない。勤続はセルの平均値で入れているので、勤続の効果は粗く測られている
- 学歴不明のセルを除いているので、全体の平均は公表値と少しずれる
- 1年（2025年）の横断面であり、差が縮んでいるかどうかや、制度の効果は分からない
- 一般労働者だけで、短時間労働者は入っていない。短時間で働く女性が多いことによる差（就業形態の差）は、この分析の外にある
