# F122 手法ごとに、どこでつまずいたか？ 118本の看板記事の作業ログを読む（「設計から変えたこと」と「言えないこと」の集計）

看板記事 F122。これまでに作った看板記事 F01〜F120（F24・F30 を除く118本）の README と作業ログから、「設計から変えたこと」401項目と「言えないこと」568項目を1行ずつ取り出し、キーワードの辞書でカテゴリに分けて数えた。手法の系統（因果推論・時系列・空間など）ごとに、どこでつまずきやすかったかを並べる。自分の作業の振り返りで、新しいデータは取っていない。

## 問い

- 設計どおりに進まなかったとき、何をいちばん多く変えたか
- 「言えないこと」として何をいちばん多く書いたか
- それは手法の系統によって違うか

## データ

- 看板記事 F01〜F120 の README（japan-open-data-notes の `articles/F*/README.md`）。見出し「言えないこと」の箇条書きを1行1項目に、タイトルの（ ）と「手法」の本文を手法の手がかりにした
- 作業ログの「設計から変えたこと」（記事ごとに1行、`data/design_changes_raw.tsv`）を「、」「。」で区切って1項目にした
- 118本・「設計から変えたこと」401項目・「言えないこと」568項目（`data/items_labeled.csv`）

## 手法

1. 取り出し（`zz_f122_01_取得.py`）：README と作業ログから項目の表を作る
2. 分類（`zz_f122_02_整形.py`・`zz_f122_rules.py`）：カテゴリごとのキーワード辞書（正規表現）で、1項目に複数のカテゴリを付ける。記事は、タイトルの（ ）と手法の本文から10の系統のどれかに入れる
3. 集計（`zz_f122_03_分析.py`）：主の数え方は「そのカテゴリが1回でも出た記事の割合」。1本の記事が同じことを何度も書いても1と数える
4. 系統ごとに、全体の割合より多く出たカテゴリを「その系統の典型的なつまずき」とした（記事5本以上の系統）

## 結果

### 1. 設計から変えたこと：いちばん多いのは「頑健性の確認を足した」、次が「データが取れず代用した」

| カテゴリ | 記事の割合 |
|---|---|
| 分析・頑健性を追加 | 60% |
| データが取れない・代用 | 47% |
| 期間・時点を絞った／つないだ | 45% |
| 既存データの再利用 | 41% |
| 粒度・単位を変えた | 31% |
| 手法の差し替え・自作 | 20% |

半分近くの記事で、設計書に書いたデータがそのままでは取れず、代わりのデータや代わりの粒度に切り替えていた。

### 2. 言えないこと：上位5つは50〜61%で並び、はっきりした1位はない

| カテゴリ | 記事の割合 |
|---|---|
| 期間・ほかの場面への一般化 | 61% |
| 因果・交絡 | 58% |
| 定義・測定のずれ | 53% |
| 集計単位・個人には当てはまらない | 52% |
| 前提・設定への依存 | 50% |
| 不確実性・検出力 | 43% |
| 順位づけ・評価の注意 | 24% |

### 3. 系統ごとの典型的なつまずき（全体より多かったもの）

- 統計の作法・集計（12本）：言えないことで「定義・測定のずれ」が 83%（全体 53%）。設計の変更では「既存データの再利用」が 75%
- 生存・人口（11本）：「定義・測定のずれ」82%（登記・調査の定義が結果に効く）
- 空間（11本）：「不確実性・検出力」64%（全体 43%。小さな地域のぶれ）
- 時系列・予測（21本）：「前提・設定への依存」67%（全体 50%。ラグ・モデルの形の選び方）
- 因果推論（25本）：「集計単位・個人には当てはまらない」64%（全体 52%）、設計の変更では「粒度・単位を変えた」48%（全体 31%）

### 4. 1記事あたりの項目数は、F80〜F100 あたりで最も多かった

「設計から変えたこと」は F01〜F80 で平均 2.8〜3.0項目、F81〜F100 で 5.5項目、F101〜F120 で 3.4項目。「言えないこと」は 4.3〜4.5項目から、F81 以降は 5.4〜5.9項目に増えた。

## 頑健性

| 確かめたこと | 設計から変えたこと | 言えないこと |
|---|---|---|
| 項目の数で数える（記事の割合のかわりに） | 順位の相関 0.94、1位は同じ | 相関 0.82、1位が「定義・測定のずれ」に変わる |
| 辞書を厳しくする（各カテゴリの先頭3語だけ） | 相関 0.37、1位は同じ | 相関 −0.25、順位はほぼ入れ替わる |
| 1項目1カテゴリにする | 相関 0.94、1位が「データが取れない・代用」に変わる | 相関 0.68 |
| 前半 F01〜F60 だけ | 相関 0.60 | 相関 0.96 |
| 後半 F61〜F120 だけ | 相関 0.94、1位は同じ | 相関 0.68、1位は同じ |

「設計から変えたこと」の1位（頑健性の追加）は5通りのうち3通りで変わらなかった。「言えないこと」の上位は僅差で、数え方や辞書を変えると順位が入れ替わる。言えるのは「上位5つがどれも半分前後の記事に出る」まで。

## 言えないこと

- 分類はキーワード辞書によるもので、人が1項目ずつ読んで付けたものではない。「設計から変えたこと」の34%、「言えないこと」の29%はどのカテゴリにも当たらず、集計に入っていない
- 書いた数を数えているので、「多く書いた」ことが「多くつまずいた」とは限らない。後半の記事で項目が増えたのは、書き方が丁寧になった分も含む
- F02〜F04 は README の見出しの形が違い、「言えないこと」が取り出せていない（0項目）
- 自分1人の118本の記録で、ほかの分析者や実務の分析に同じ傾向があるかは分からない
