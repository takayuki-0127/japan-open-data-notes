# F26 政策の効果を見つけるには、何年・何県のデータが要るのか？（検出力シミュレーション）

看板記事シリーズの26本目です。これまでの看板記事では「効果は見えなかった」という結論がいくつもありました。それは「効果がない」のか、それとも「あっても見えない設計だった」のか。A/B テストのサンプルサイズ設計と同じ考え方で、都道府県パネルの差の差（DID）が**どれくらいの効果なら見つけられるか**をシミュレーションで調べました。

## 問い

47都道府県・年次のパネルで差の差をするとき、本当の効果がどれくらいの大きさなら、何県・何年分のデータで見つけられるか。標準誤差の選び方を間違えると、何が起きるか。

## データ

新しい公的データは取っていません。F01・F14 で整えたデータを土台にしています。

| データ | 元 | 中身 |
|---|---|---|
| `data/raw/f01_panel.csv` | [F01](../F01_minimum_wage_did)（総務省「労働力調査 都道府県別モデル推計値」ほか） | 47都道府県 × 2008〜2025年の就業率・完全失業率 |
| `data/raw/f14_analysis.csv` | [F14](../F14_compact_city_psm_did)（国土数値情報 人口集中地区ほか） | 市町村の人口集中地区の密度の変化（2010→15年、2015→20年） |

## 手法

| 項目 | 内容 |
|---|---|
| 土台の考え方 | 実データに**でたらめな処置**（処置する県と時期を乱数で決める）を置く。本当の効果は0なので、ここに既知の効果 δ を足して、推定がそれを見つけられるかを数える（Bertrand・Duflo・Mullainathan 2004 型）。実データの誤差の構造（時系列の相関・地域のまとまり）がそのまま入る |
| 推定 | 二方向固定効果（県効果＋年効果）の差の差。標準誤差は県クラスター（CR1、自由度46の t 分布） |
| 動かした条件 | 処置県の数 k＝3・5・10・15・23・30・40、期間 T＝4・6・8・12（2008〜2019年、前後半分ずつ）と 18（2008〜2025年）、効果 δ＝0〜1.2%pt |
| 回数 | 各条件1,000回（標準誤差の比較は500回、wild cluster bootstrap は各199回） |
| 検出力 | 有意（5%）になった割合。最小検出効果（MDE）は検出力80%に届く最小の δ |
| 誤検出 | δ＝0 で有意になった割合（本来は5%） |
| 処置の時期がずれる場合 | 3つの時期（2012・2014・2016年）に8県ずつ処置、効果は4年かけて δ に育つ。二方向固定効果（TWFE）と Callaway–Sant'Anna 型（最後まで処置されない県と比べ、処置の前年を基準にした ATT(g,t) の平均。標準誤差は県単位のブートストラップ99回）を比べる。300回 |
| F14 の設定 | 市町村の2時点の差（処置297・比較338）。でたらめに処置を割り当てて、市町村の数ごとの MDE |

## 主な結果

### 実データの誤差の構造（`results/error_structure.json`）

就業率（2008〜2019年）：県効果・年効果を除いた残差の標準偏差は **0.67%pt**、1年前との相関（AR(1)）は **0.60**。県どうしの残差の相関は平均 −0.02 でほぼ0。

### 何県・何年あれば見つかるか（`results/mde_grid.csv`・`power_grid.csv`）

- 就業率、処置23県・12年：**最小検出効果は 0.70%pt**（乱数の種5通りで 0.685〜0.71）。効果0.3%pt なら見つかるのは21%、0.5%pt でも52%
- 完全失業率、処置23県・12年：最小検出効果は **0.31%pt**（期間4年なら 0.23%pt）
- **処置県の数**：3県だと 1.22%pt、10県で 0.84%pt、23〜30県で 0.70%pt と最小。40県（比較7県）だと 0.98%pt にまた悪くなる。処置と比較が半々に近いほど見つけやすい
- **期間の長さ**：就業率では4年でも12年でも 0.70〜0.73%pt でほとんど変わらない。誤差が年をまたいでつながっている（AR(1) 0.6）ため、年を増やしても情報があまり増えない。失業率では、期間が長いほうがかえって悪くなった（0.23→0.31%pt）

### 標準誤差を間違えると（`results/fpr_by_se.csv`、効果0・12年）

| 処置県の数 | OLS（普通） | HC1 | 県クラスター | wild cluster bootstrap |
|---|---|---|---|---|
| 2 | 32.8% | 42.8% | 31.0% | 0.0% |
| 3 | 33.4% | 41.4% | 19.2% | 1.0% |
| 5 | 32.8% | 35.6% | 11.2% | 7.2% |
| 10 | 32.6% | 33.6% | 5.2% | 4.6% |
| 23 | 29.8% | 30.0% | 4.0% | 5.0% |

（就業率。失業率もほぼ同じ形）

- 普通の標準誤差や HC1 では、効果0なのに**3割前後が「有意」**になる。誤差の時系列の相関を無視しているため
- 県クラスターでも、処置県が5県以下だと誤検出が11〜31%に増える
- wild cluster bootstrap は処置県5県以上ならほぼ5%。ただし処置県が2〜3県だと逆に**ほとんど有意にならない**（Rademacher の重みで作れるパターンが少なすぎる）。処置県がごく少ないときは、どの方法も当てにしにくい

### これまでの看板記事（`results/past_flagships.csv`）

推定値の大きさ ÷ 検出力80%の最小検出効果（MDE＝2.8×標準誤差）：

| 記事 | 推定値 | MDE | 比 |
|---|---|---|---|
| F01 就業率 | +0.41%pt | 0.64%pt | 0.65 |
| F01 失業率 | −0.19%pt | 0.29%pt | 0.66 |
| F14 人口集中地区の密度 | +0.22%pt | 2.55%pt | 0.09 |
| F15 飲食＋小売の雇用（弾力性） | 1.41 | 4.82 | 0.29 |
| F16 保育所と女性の労働力率 | +0.066%pt | 0.085%pt | 0.77 |
| F17 最低賃金の平均効果 | −0.09%pt | 0.44%pt | 0.20 |

どれも1に届いていない。とくに F14・F15 は、推定値が仮に本当の効果でも、この設計で見つけられる大きさの1〜3割しかない。「見えなかった」は「ない」ではなく「この設計では見分けられない」と読むのが正しい。

F14 の設定（市町村の2時点）では、処置をでたらめに割り当てた理想的な場合でも、635市町村で MDE は 1.64%pt、100市町村なら 4.1%pt（`results/f14_mde.csv`）。前の期間の変化をそろえても（ANCOVA）ほとんど変わらない（2期間の変化の相関が0.08と弱いため）。

## 頑健性

- **誤差の構造を変える**（人工データ、47県×12年、23県処置、各2,000回、`results/error_structure_sim.csv`）：AR(1) を 0→0.3→0.6→0.9 にすると、OLS の誤検出は 5.6%→13.6%→25.1%→38.5% に増える。県クラスターは 4.3〜5.0% のまま。効果0.5 の検出力は 0.99・0.92・0.80・0.91。実データ（12年）の推定値のばらつき（0.23）は、AR(1)=0.6 の人工データ（0.17）より大きい。実データには地域のまとまった動きなど、AR(1) だけでは表せない構造がある
- **乱数の種**（5通り、`results/seeds.csv`）：23県・12年の MDE は 0.685〜0.71%pt、誤検出 3.8〜4.5%
- **推定法（TWFE／CS）**（`results/staggered_twfe_cs.csv`）：時期がずれて効果が育つとき、TWFE は本当の平均効果を**12%ほど小さく**推定した（4年目の効果1.0のとき、本当 0.75 に対し 0.66）。CS 型はほぼ本当の値（0.74）。検出力は TWFE 88%・CS 92%、効果0での誤検出は TWFE 2.7%・CS 5.7%
- **期間に2020年以降を入れる**（2008〜2025年）：23県の検出力はほぼ同じ（効果0.5で 54〜62%）

## 言えないこと

- シミュレーションの結果は、仮定した誤差の構造に依存する。実データの「でたらめ処置」は、その県・期間の誤差がこれからも同じように続くと仮定している
- 処置は「ある時点から一斉に、同じ大きさで効く」としている（時期がずれる場合は1通りの形だけ試した）。効果の現れ方が違えば、検出力も変わる
- 処置する県はでたらめに選んだ。実際の政策では「処置される県」に特徴があり、その偏りの問題は検出力とは別に残る
- 過去の看板記事の MDE は、それぞれの記事の標準誤差から 2.8×SE で計算した近似
