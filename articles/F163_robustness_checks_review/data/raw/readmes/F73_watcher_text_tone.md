# F73 街の人の「景気の声」は、数字より先に動くか？ 景気ウォッチャー55万件のコメントを数値にすると、DIとは相関0.83でほぼ同じ動き。先に動く力はDIより弱く、記号に表れない語り口も翌月を当てなかった

看板記事 F73。内閣府「景気ウォッチャー調査」の景気判断理由集（コメント）を、辞書法と文の埋め込みで「強気・弱気」の数値にし、同じ調査の DI や景気動向指数と比べました。

## 問い

景気ウォッチャー調査では、タクシー運転手や店長などの回答者が、景気の判断（◎○□▲×）とあわせて理由をコメントで書いています。このコメントの語り口を数値にすると、

1. 判断の記号（DI のもと）とどれだけ合うのか
2. 景気動向指数（CI）より先に動くのか、DI より早いのか
3. 記号には表れない「語り口の上乗せ」に、翌月の景気の情報が入っているのか

を確かめました。

## データ

| データ | 範囲 | 出どころ |
|---|---|---|
| 景気判断理由集（現状 watcher4.csv・先行き watcher5.csv） | 2010年1月〜2026年9月の201か月、コメント546,795件（現状257,962・先行き288,833） | 内閣府 景気ウォッチャー調査 各月のページ |
| 現状判断DI・先行き判断DI（原数値、全国合計） | 2001年1月〜2026年9月 | 同 watcher2-1.xls・watcher2-4.xls |
| 現状判断DI・先行き判断DI（季節調整値） | 2002年1月〜2026年9月 | 同 watcher5.xls |
| 景気動向指数（CI 一致）・景気基準日付 | 〜2026年8月 | F13・F18 で取ったもの |

- コメントは、回答のうち「主だったもの・特徴的なもの」を内閣府が選んで載せたものです（回答者全員の分ではありません）。
- CSV の公開は2010年1月調査分からで、それより前は PDF だけなので使っていません。
- 2025年10月・2026年4月の先行きの CSV だけは UTF-8 で書かれていたため、文字コードを自動で見分けて読んでいます（ほかの月は Shift_JIS）。
- コメントの全文（f73_watcher.json.gz、約35MB）は GitHub に置いていません。`src/01_取得_browser.js` で集め直せます。

## 手法

| 段階 | 内容 |
|---|---|
| 辞書スコア | コメントごとに（強気語の数 − 弱気語の数）÷（強気語＋弱気語）。語がなければ0。辞書は F53（日銀の声明文）をもとに、街角の言葉（好調・にぎわい・買い控え・節約など）を足した強気21語・弱気23語 |
| 埋め込みスコア | 月×（現状・先行き）ごとに150件を無作為に選び（計6万件）、ruri-v3-30m で「強気の基準文5つとの近さ − 弱気の基準文5つとの近さ」 |
| コメント単位の照合 | 記号（◎=1、○=0.75、□=0.5、▲=0.25、×=0）との相関、良い側（◎○）と悪い側（▲×）を見分ける AUC |
| 月の指数 | 月ごとのスコアの平均（現状・先行き）。公表の DI（原数値）と比べる |
| 先行性 | CI 一致指数の3か月前比との相互相関（−6〜+6か月）、グランジャー因果（ラグ1〜3） |
| 記号に表れない語り口 | 月のテキスト指数を、同じコメントの記号の平均で回帰した残差。今月の DI をそろえて、翌月の DI の変化・CI の動きを説明するか（HAC 標準誤差） |
| 話題 | 物価・値上げ、インバウンド、人手不足、コロナ、天候、消費税の語がコメントに出てくる割合 |

## 主な結果

**1. コメントの語り口は、付けた記号とおおむね合う**

- 辞書の語が1つ以上あるコメントは61%（現状）。記号との相関は0.37、良い側と悪い側を見分ける AUC は0.79（語のあるコメントだけなら0.85）。
- 埋め込みのほうが記号をよく見分けました。同じ6万件で AUC は 0.93（現状）・0.94（先行き）、辞書は0.79・0.77。
- 記号ごとの平均（現状）：◎ +0.31、○ +0.52、□ +0.06、▲ −0.29、× −0.25。◎のほうが○より低いのは、◎のコメントが短く（平均37字、ほかは56〜60字）、辞書の語が入る割合が38%と少ないためです。語のあるコメントだけなら◎が+0.81でいちばん高くなります。

**2. 月のテキスト指数は DI とほぼ同じ動き**

- テキスト指数（現状）と現状判断DI（原数値）の相関は0.83、前月からの変化どうしでも0.79。先行きは0.77。
- 載ったコメントの記号の平均と公表の DI の相関は0.997で、選ばれたコメントの記号の構成は回答全体とほぼ同じでした。テキスト指数の変動の71%は、この記号の平均で説明できます。
- 大きな出来事の月はどちらもはっきり下がりました（震災 2011年3月、消費税8% 2014年4月、消費税10% 2019年10月）。
- ただしコロナの落ち込みは、DI（2020年4月 9.5）ほどテキスト指数は下がりませんでした（平均からのずれは DI が標準偏差の約5.5倍、テキストは約2.4倍）。語り口のスコアは −1〜+1 に収まり、極端な月で頭打ちになるためと考えています（推測です）。
- 年平均で見ると、2020〜23年はテキストが DI より明るく、2019年と2025〜26年は暗めでした。

**3. 景気動向指数より1か月先に動くが、DI より弱い。DI より先には動かない**

| 系列 | CI 3か月前比との相関（同じ月） | 最大の相関（ずれ） | グランジャー p（ラグ1） |
|---|---|---|---|
| 現状判断DI | 0.52 | 0.55（1か月先行） | 0.00002 |
| テキスト指数（現状） | 0.35 | 0.37（1か月先行） | 0.012 |
| テキスト指数（先行き） | 0.20 | 0.30（2か月先行） | — |

- 逆向き（CI → テキスト）は p=0.43 で、見えませんでした。
- テキスト指数の変化と DI の変化は同じ月に0.79で動き、1か月ずらすと −0.09・+0.14。テキストが DI より先に動く形跡はありませんでした。

**4. 記号に表れない「語り口の上乗せ」は、翌月を当てない**

- 残差（記号の平均では説明できない語り口）が翌月の DI の変化を説明する係数は −1.3（95%区間 −12.5〜+10.0、p=0.83）。CI の3か月前比に対しても −5.4（−12.0〜+1.2、p=0.11）でした。
- 先行きのテキスト指数も、今月の DI をそろえると翌月の現状 DI を説明しませんでした（−6.2、p=0.26）。

**5. 話題の移り変わり**

- 消費税の語は2014年4月に58%、2019年に41%。コロナは2020年3月に71%。
- 物価・値上げは2010〜19年平均の1.8%から、2023年1月に24%、2024〜26年平均は17%。インバウンドは2024〜26年平均5.9%（2010〜19年は1.8%）。

## 頑健性

| 設定 | テキストとDIの相関 | 変化どうし | CI3との最大相関（ずれ） |
|---|---|---|---|
| 基本（辞書・全コメント） | 0.83 | 0.79 | 0.37（1か月） |
| 辞書を絞る（期待・不安・懸念・様子見を外す） | 0.82 | 0.78 | 0.37（1か月） |
| 語のあるコメントだけ | 0.85 | 0.80 | 0.39（1か月） |
| 家計動向だけ | 0.78 | 0.76 | 0.34（1か月） |
| 企業動向だけ | 0.79 | 0.61 | 0.42（同じ月） |
| 雇用だけ | 0.61 | 0.39 | 0.30（1か月遅れ） |
| コロナ期（2020年3月〜2021年12月）を除く | 0.89 | 0.82 | — |
| 季節調整値の DI と比べる | 0.78 | 0.69 | — |
| 埋め込み（各月150件） | 0.80 | 0.75 | 0.32（1か月） |
| 同じ150件で辞書 | 0.75 | 0.57 | 0.34（1か月） |

- 語り口の残差が翌月の DI を説明しないことは、どの設定でも同じでした（p=0.36〜0.92）。
- CI を前月比にすると、最大の相関は同じ月（0.35）になり、グランジャーの p は0.29でした。

## 言えないこと

- コメントは内閣府が選んだ「主だったもの」で、回答者全員の文章ではありません。
- 辞書と基準文は私が決めたもので、別の辞書なら値は変わります（頑健性では大きくは変わりませんでした）。
- 回答者は記号とコメントを同時に書いているので、語り口が記号と合うのは当然とも言えます。「記号に表れない分」も、残差の取り方しだいです。
- CI の3か月前比は前後の月と期間が重なるので、「1か月先行」の一部は公表時期の差です。
- 季節調整はしていません（DI も原数値と比べています）。

## 再現手順

```
pip install -r requirements.txt
# 1) https://www5.cao.go.jp/keizai3/watcher_index.html を開き、src/01_取得_browser.js をコンソールで実行
#    → f73_watcher.json.gz を data/raw/ に置く
cd src
python 02_整形.py
RURI_PATH=<ruri-v3-30m のフォルダ> python 03a_埋め込み.py   # CPU で約10〜20分
python 03_分析.py
python 03b_頑健性.py
python 04_図.py
```

乱数の種は42（埋め込みの対象の抽出）。
