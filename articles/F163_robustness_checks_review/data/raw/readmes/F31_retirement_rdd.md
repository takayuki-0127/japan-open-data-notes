# F31 60歳・65歳で、働く人はどれだけ減るのか？（回帰不連続）

看板記事 F31。国勢調査の「年齢（各歳）別の労働力状態」を5回分（2000〜2020年）並べ、60歳と65歳の境目で就業率がどれだけ「段差」のように落ちるかを、年齢を走る変数にした回帰不連続で推定した。

## 問い

- 60歳（多くの会社の定年）と65歳（年金の支給開始・継続雇用の上限）で、就業率は不連続に下がるか
- その段差は、高年齢者雇用安定法の改正（2006年に65歳までの雇用確保措置、2013年に希望者全員の継続雇用）の前後で、20年の間にどう変わったか

## データ

| 年 | 表（総務省「国勢調査」） | statInfId |
|---|---|---|
| 2000 | 第2次基本集計 第1表 労働力状態（8区分），年齢（各歳），男女別15歳以上人口－全国 | 000000031852 |
| 2005 | 第2次基本集計 第1表（同） | 000000038461 |
| 2010 | 産業等基本集計 第1-1表（同）－全国，都道府県 | 000012989686 |
| 2015 | 就業状態等基本集計 第1-1表（同，総数及び日本人） | 000031569350 |
| 2020 | 就業状態等基本集計 第1-1表 男女，年齢（各歳），国籍総数か日本人，労働力状態別人口 | 000032201174 |

- 就業率 ＝ 就業者 ÷（総数 − 労働力状態「不詳」）。不詳は2020年に60歳前後で約7%まで増えたので、分母から除いた。2000・2005年の表には不詳の列がないため、総数 −（労働力人口＋非労働力人口）を不詳とした
- 2000・2005年は84歳まで、2010年以降は99歳まで各歳がある。分析に使うのは45〜80歳
- 2020年は47都道府県の表も使った（頑健性）

## 手法

- 年齢 a を走る変数、境界を c（60 または 65）とし、a ≥ c を「右」として左右で傾きの違う1次式を当てはめる（局所線形回帰）
- 基本の設定：左右5歳ずつ（60歳なら55〜59歳と60〜64歳）、三角カーネル（境界を c−0.5 歳に置く）、HC1 標準誤差
- 年齢は1歳刻みで、左右に5点ずつしかない。HC1 の区間は目安にとどめ、段差がないはずの年齢（45〜57歳・68〜80歳）で同じ推定をした「偽の境界」の分布と比べて判断した
- 推定は年（5回）× 男女（男女計・男・女）× 境界（60・65歳）ごと

## 主な結果

就業率の段差（ポイント、男女計、基本の設定）

| 年 | 60歳 | 65歳 |
|---|---|---|
| 2000 | −10.3 | −1.7 |
| 2005 | −7.4 | −1.2 |
| 2010 | −5.0 | −2.8 |
| 2015 | −4.1 | −4.7 |
| 2020 | −2.5 | −5.5 |

- 60歳の段差は20年で約4分の1になり、2015年に65歳の段差のほうが大きくなった
- 男性：60歳 −14.4 → −2.9、65歳 −2.2 → −7.7。女性：60歳 −6.3 → −2.1、65歳 −1.1 → −3.4
- 59歳と60歳の就業率（男女計）：2000年 68.6% → 56.8%、2020年 79.6% → 75.9%。64歳と65歳：2000年 45.2% → 40.8%、2020年 64.9% → 56.7%
- 男性の完全失業率の段差：60歳 +6.5ポイント（2000年）→ +1.7（2020年）、65歳 +0.3 → +2.9。定年で仕事を探す人が増える境目が、60歳から65歳へ移った
- 2020年の都道府県別：47都道府県すべてで60歳・65歳とも段差はマイナス（60歳 −1.3〜−3.7、中央値 −2.6／65歳 −2.9〜−6.7、中央値 −5.1）

## 頑健性

- 偽の境界（左右3歳、26の年齢×5年）での「段差」は −1.2〜+1.4 ポイント。本物の境界（同じ左右3歳）は、2010年の男性の65歳（−1.45、偽の境界の最小 −1.98）を除いて、すべて偽の境界の範囲の外
- バンド幅3〜8歳・1次と2次・一様カーネル・人口の重み：60歳はどの設定でも2000年 −8.1〜−10.9、2020年 −1.7〜−2.6。65歳は2020年 −3.8〜−6.1 で安定。2000年の65歳は −4.2〜+0.8 と設定で揺れ、はっきりしない
- 結果を労働力率に変えても同じ向き（60歳 −7.6 → −1.6、65歳 −1.6 → −4.5）
- 2015年の日本人のみ：60歳 −4.1、65歳 −4.7（国籍総数と同じ）
- 労働力状態「不詳」の割合は境界の前後でほぼ同じ（2020年：59歳 7.4%・60歳 6.8%、64歳 5.6%・65歳 5.4%）

## 言えないこと

- 国勢調査は5年ごとの別々の人の集まりで、同じ人が60歳で辞めたかどうかは分からない
- 段差の理由（定年・継続雇用の終わり・年金の支給開始・本人の希望）は分けられない。60歳から65歳への移り方は制度改正の時期と合っているが、因果の大きさを制度ごとに切り分けたものではない
- 就業の中身（正社員か、嘱託・パートか、賃金がいくらか）は見ていない
- 年齢が1歳刻みで点が少ないため、標準誤差は小さめに出ている可能性がある

## 動かし方

```
pip install -r requirements.txt
bash src/run_all.sh
```

- `src/01_取得.py`：表の URL（e-Stat）。取得済みの JSON を `data/raw/` に置いている
- `src/02_整形.py`：5回の表を「年×男女×年齢」の縦長の表に → `data/lfs_single_age.csv` など
- `src/03_分析.py`：回帰不連続・偽の境界・頑健性・失業率・都道府県 → `results/`
- `src/04_図.py`：`figures/` に6枚

## ファイル

- `data/raw/f31_census_lfs.json`：2000〜2015年の表（e-Stat の Excel・CSV をシートごとに2次元配列にしたもの）
- `data/raw/f31_census2020_pref.json`：2020年の表のうち全国と47都道府県・国籍総数の行
- `data/lfs_single_age.csv`：年×男女×年齢の就業者・労働力・不詳など
- `results/rd_main.csv`・`rd_placebo.csv`・`rd_vs_placebo.csv`・`rd_robustness.csv`・`rd_unemployment.csv`・`rd_pref2020.csv`
