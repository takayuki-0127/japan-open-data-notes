# F94 市町村合併をどう扱うかで、20年の推移の分析は変わるか？ 新旧の対応表で長期パネルを作る

## 問い

2000年に 3,252（東京23区を含む）あった市町村は、2020年には 1,741 になった。20年の人口の推移を市町村ごとに分析するとき、この間の合併をどう扱うか（今の境域に足し上げる／合併しなかった町だけ見る／コードをそのままつなぐ／旧市町村に割り戻す）で、「どのくらいの町が減ったか」「小さい町ほど減ったか」という結論の数字がどれだけ動くかを確かめる。人口の増減そのものの評価ではなく、**データの扱い方による違い**を見る記事。

## データ

- **2000年国勢調査 第1次基本集計 都道府県結果 第1表**「人口，人口増減（平成7年～12年），面積及び人口密度」（47都道府県の Excel、e-Stat）。2000年10月1日時点の市町村ごとの人口・1995年の人口（2000年の境域に組替済み）・面積。政令市（12市）は市全体の行を使い、東京23区は区ごとに使う。合計 126,925,843 人（全国の公表値と一致）
- **廃置分合等情報**（e-Stat「市区町村名・コード」→「廃置分合等情報を探す」、2000-10-02〜2020-10-01 施行分の CSV、2,677行）。新設合併・編入合併・市制施行・政令指定都市への移行・郡の区域変更などの記録（改正事由の文章に旧・新のコードが入っている）
- **2020年の人口（今の境域）**：社会・人口統計体系（市区町村データ）の A1101（総人口）。F40 と同じデータ（1,741単位、合計 126,146,099 人）
- `data/raw/f94_raw.json` に上の2つの e-Stat データ（CSV の文字列と、Excel を読み込んだ行）をまとめて保存

## 手法

1. **対応表（レコードリンケージ）**：廃置分合の改正事由の文章から旧コード→新コードを取り出す（`src/02_整形.py`）
   - 「A(c1)、B(c2)が合併し、X市(c0)を新設」→ c1,c2→c0（名前を引き継ぐ新設は、同じ名前の旧コードを引き継ぐ）
   - 「A(c1)がX市(c0)に編入」→ c1→c0。政令市の区への編入（例：○○区(26108)）は市のコードに寄せる
   - 市制施行・政令市への移行・郡の区域変更などのコードの付け替えは、境域を変えずにコードだけをつなぐ
   - 1つの村が2つに分かれて編入された例（上九一色村、2006年）が1件ある。大字の数で多い側（富士河口湖町）に寄せ、甲府市側に寄せた場合を頑健性で確かめる
   - 連鎖（2回以上の合併、合併後の政令市移行など）を順にたどって 2000→2020 のコードを決める
2. **検算**：3,252 の旧市町村が 2020年の 1,741 単位にちょうど過不足なく対応すること、都道府県の合計が公表値と一致することを確かめた（`results/validation.json`）。廃置分合の記録から再現した市町村数の推移も 2020年10月で 1,741 になる（図1）
3. **比べる扱い方**（指標はすべて 2000→2020年の人口増減率。三宅村は2000年の人口が0のため除く）
   - **A 再集計**：旧市町村の2000年人口を2020年の境域に足し上げる（1,740単位）
   - **B 変化なしだけ**：20年間に合併に関わらなかった市町村だけ（1,151単位）
   - **C コード突合**：2000年と2020年で同じコードどうしをそのままつなぐ（素朴な結合。2020年にないコードは落ちる。1,428単位）
   - **D 按分**：2020年の人口を2000年の旧市町村に割り戻す（3,251単位）。割り戻しの重みを D1 2000年人口の比／D2 面積の比／D3 1995→2000年の伸びを20年延長した比、の3通り
4. **指標**：増減率の中央値、人口加重の平均、20%以上減った単位の割合、増えた単位の割合、「小さい町ほど減る」傾き（増減率を log10(2000年人口) で回帰した傾き、人口10倍あたりの増減率の差。ブートストラップ1,000回の95%区間、乱数の種 94）
5. **都道府県別**：各県の「合併に関わった旧市町村の割合」と、C と A の中央値のずれの関係

## 結果

| 扱い方 | 単位数 | 中央値 | 人口加重の平均 | 20%以上減 | 増えた単位 | 小さい町ほど減る傾き（95%区間） |
|---|---|---|---|---|---|---|
| A 再集計 | 1,740 | −15.5% | −0.6% | 38.7% | 22.0% | 15.3（14.1〜16.4） |
| B 変化なしだけ | 1,151 | −14.8% | +3.6% | 38.8% | 26.5% | 18.1（16.8〜19.6） |
| C コード突合 | 1,428 | −8.9% | +7.2% | 31.5% | 35.6% | 18.8（16.3〜21.0） |
| D1 按分（人口比） | 3,251 | −15.9% | −0.6% | 37.6% | 17.1% | 13.1（12.3〜13.9） |
| D3 按分（伸び延長） | 3,251 | −18.6% | −0.6% | 46.4% | 17.4% | 17.5（16.6〜18.4） |
| D2 按分（面積比） | 3,251 | −11.2% | −0.6% | 39.8% | 40.2% | −152.8（意味をなさない） |

1. **コードをそのままつなぐ（C）と、「増えた町」が 22.0% → 35.6% に膨らむ**。合併でほかの町を吸収し、コードを引き継いだ 294 単位は、増減率の中央値が +14.6%（合併に関わらなかった単位は −14.9%）。吸収した分の人口が「増えた」ように見えるためで、11 単位は +100% を超えた。同時に、2000年の旧市町村のうち 1,823（56%）は2020年にコードがなく、黙って落ちる。人口加重の平均は +7.2%（実際の全国は −0.6%）
2. **合併しなかった町だけ（B）は、偏った集まりになる**。B に残るのは2000年人口の中央値 16,910 人と、全体（A、27,363 人）より小さい町が多く、大都市の一部も含む。中央値は A と近い（−14.8%）が、人口加重の平均は +3.6% で、傾きは 18.1 と A より大きく出た
3. **割り戻し（D）は、割り戻し方の仮定がそのまま結果になる**。2000年人口の比で割り戻す（D1）と、合併した町の中では全員が同じ増減率になり（同じグループ内のばらつき 0）、「小さい町ほど減る」傾きは 13.1 と小さく出る。1995→2000年の伸びを延長すると（D3）傾きは 17.5、20%以上減の割合は 46.4% になる。面積の比（D2）は人口と関係のない重みなので、増減率が −53%〜+172%（10〜90パーセンタイル）に広がり使えない
4. **「小さい町ほど減る」という向きはどの扱い方でも同じ**（D2 を除く）が、**大きさは 13.1〜18.8 と約1.4倍の幅**で動いた。A と C の区間は一部しか重ならず、A と D1、A と B の区間は重ならない
5. **合併が多い県ほど、素朴なつなぎ方のずれが大きい**。都道府県ごとに「合併に関わった旧市町村の割合」と「C と A の中央値のずれ」の相関は 0.63。合併に関わった割合が9割を超える3県では、ずれが +17〜+32%pt に達した一方、その割合が35%未満の7都道府県では −1.2〜+0.6%pt とほぼ0だった（図5）

## 頑健性

傾き（人口10倍あたりの増減率の差、%pt）。`results/robustness.csv`

| 条件 | A | B | C | D1 |
|---|---|---|---|---|
| 基本（2000→2020） | 15.3 | 18.1 | 18.8 | 13.1 |
| 基準年を1995年に（1995→2020） | 17.4 | 20.9 | 21.5 | 16.3 |
| 政令市・東京23区を除く | 14.9 | 17.9 | 19.4 | 12.6 |
| 福島県を除く | 15.1 | 17.8 | 18.3 | 13.0 |
| 2000年人口1,000人未満の単位を除く | 16.1 | 19.3 | 19.6 | 13.3 |
| 分割編入（上九一色村）の割り当てを変える | 15.3 | 18.1 | 18.8 | 13.1 |

- **按分の方法**：上の結果3のとおり、人口比・伸び延長・面積比で大きく変わる（D1 と D3 の単位ごとの増減率の相関は 0.74）
- **基準年**：1995年を基準にしても、扱い方の並び（D1 < A < B ≈ C）は同じ。期間が長いぶん傾きはどれも約2pt大きい
- **除外の仕方**：政令市・23区、福島県（原発事故の避難指示で2020年の人口が大きく動いた地域を含む）、人口1,000人未満を除いても、並びと差の大きさはほぼ同じ
- 「増えた単位の割合」は C がどの条件でも A より 12〜14pt 高い

## 言えないこと

- **どの扱い方が「正しい」かは問いによる**。今の自治体の単位で比べたいなら A、旧町村の地域ごとの変化を知りたいなら旧市町村の単位のデータ（小地域集計など）が必要で、D の割り戻しはその代わりにならない（割り戻しの仮定が結果を決めてしまう）
- **人口が減った・増えた理由は分からない**。ここで見たのは数え方による違いで、合併そのものが人口に影響したかどうかは分析していない（合併した町と、しなかった町はもともと違う）
- **境界変更は入っていない**。廃置分合の記録のうち、合併・編入・コードの付け替えだけを使い、市町村の一部の区域が隣に移る「境界変更」は扱っていない。そのため 2000年の足し上げが2020年の境域と細かく一致しない単位がありうる（2005年の値〔今の境域〕との比で0.8〜1.2倍を外れたのは9単位。三宅村〔2000年は人口0〕のほかは、いずれも20年間に合併のなかった単位で、2000→2005年の実際の増減と考えられる）
- **分割編入の1件は大字ごとの人口が手元にない**ため、大字の数で寄せた。結果への影響は頑健性で確かめた範囲でほぼない
- **2020年の人口は社会・人口統計体系（今の境域）の値で、2020年国勢調査の公表値と同じ定義だが、その後の境域の変更は反映していない**
- 傾きは「人口の小さい町ほど減りやすい」という記述的な関係で、因果ではない
- 特定の市町村を評価するものではない（図には名前を出していない）
