# F71 都道府県の所得の差は、縮まっているのか？（β収束・σ収束・動学パネル GMM）

看板記事 F71。note の記事：「都道府県の所得の差は、縮まっているのか？ 68年分の県民所得をつないで測ると、差が大きく縮んだのは1960〜70年代前半。その後は東京以外の県の差がゆっくり縮み、収束の速さは手法で半減期10年〜46年と揺れた」

## 問い

都道府県の1人当たり県民所得の差は、時間とともに縮まっているのか（収束しているのか）。縮まっているなら、どれくらいの速さか。

## データ

- 内閣府 経済社会総合研究所「県民経済計算」の1人当たり県民所得と総人口。基準年の違う7つの表をつないで、1955〜2022年度の68年分にした
  - 昭和30〜49年度（1968SNA、昭和55年基準、参考表）／昭和50〜平成11年度（1968SNA、平成2年基準）／平成2〜15年度（1993SNA、平成7年基準）／平成8〜21年度（平成12年基準）／平成13〜26年度（平成17年基準）／平成18〜30年度（2008SNA、平成23年基準）／平成23〜令和5年度（2008SNA、平成27年基準）
  - 令和5年度版は石川・奈良・徳島・香川・宮崎の5県が未公表（2026年10月時点）のため、この5県の2011〜2022年度は令和4年度版の値を使い、2023年度は全県で使っていない
  - 沖縄は1972年度から（それ以前の表にない）。名目値
- `data/raw/kenmin_raw.json`：各表の1枚目のシートをそのまま JSON にしたもの、`data/raw/v2022_missing5.csv`：補った5県の値

## 手法

| 段階 | やったこと |
|---|---|
| 相対所得 | r = ln(県の1人当たり所得) − その年度の47（46）県の対数平均。名目の物価や全国の伸びは年ごとに消える |
| 表のつなぎ方 | 基準年の違う表は、つなぎ目の年度で「新しい表の値 − 古い表の値」を県ごとに古い表に足し、最新の基準年の水準にそろえた（年ごとの変化は各表のまま）。段差を消さずに新しい表の値を優先するだけのつなぎ方は頑健性で比べる |
| σ収束 | r の県の間の標準偏差の推移（単純、人口で重み、東京を除く） |
| β収束（横断面） | 期間の初めの r で、期間中の r の年あたりの変化を回帰（HC1）。λ = −ln(1+βT)/T、半減期 = ln2/λ |
| 動学パネル | 5年ごとのパネルで r_it = ρ r_i,t−5 + 年度効果 + 県の固定効果。OLS（上に偏る）、固定効果（Nickell の偏りで下に偏る）、Arellano–Bond の差分GMM、Blundell–Bond の system GMM（どちらも r のラグ2〜4を collapse した操作変数、2段階推定、標準誤差は1段階の頑健な値）。`src/gmm_ab.py` に自作 |

## 主な結果

- σ（46都道府県、沖縄を除く）：1955年度 0.210 → 1961年度 0.248（最大）→ 1975年度 0.155 → 1990年度 0.174 → 2000年度 0.146 → 2007年度 0.164 → 2020年度 0.126（最小）→ 2022年度 0.142
- 東京・沖縄を除く45道府県の σ：1961年度 0.218 → 1975年度 0.127 → 2019年度 0.088 → 2022年度 0.100。人口で重みを付けた47都道府県の σ は 0.20〜0.25 で、1975年度以降ほぼ横ばい
- 東京の相対所得：0.717（1955）→ 0.616（1975）→ 0.714（1990）→ 0.727（2007）→ 0.690（2022）。段差を消さずにつなぐと 0.442（1975）→ 0.690（2022）と「東京だけが離れていった」ように見えるが、その上昇の多くは基準改定のつなぎ目（2001・2006年度）で起きている
- 順位の相関（スピアマン）：1975→2022年度 0.54

## 頑健性

## 言えないこと

1. 収束の「理由」（産業構造の変化、公共投資、人口移動、交付税など）は、このデータでは分けられない
2. 県民所得には企業所得や財産所得も入り、住んでいる人の手取りや暮らしの豊かさそのものではない。名目値で、県の物価の違い（東京の家賃など）は入っていない
3. 基準年の違う表をつなぐと、つなぎ方で東京の位置づけが大きく変わる。どちらのつなぎ方が「正しい」かは決められない
4. 動学パネルの GMM は検定で問題が残り、収束の速さ（半減期）は手法によって10年〜46年と揺れた。1つの数字として使うことはできない
