# F82 「年収の壁」の手前に、どれくらいの人が集まっているか？（集積分析）

note の記事：「年収の壁」の手前に、人はどれくらい集まっているのか？ 就業構造基本調査で非正規の年収の分布を調べると、有配偶の女性だけ50〜149万円が「なめらかな分布」の約3倍。ただ測れる大きさは当てはめ方と階級の幅しだいだった

## 問い

「103万円」「106万円」「130万円」などの年収の壁の手前に、非正規で働く人はどれくらい集まっているのか。集まり方は、有配偶の女性とほかのグループで違うのか。2017年と2022年で変わったのか。

この記事は、制度そのものの良し悪しを評価するものではありません。所得の分布の形から何が言えるか（そして何が言えないか）を示すことが目的です。

## データ

| データ | 内容 |
|---|---|
| 総務省「令和4年就業構造基本調査」第66表（statInfId 000040077332） | 男女、配偶関係、年齢、所得（主な仕事からの年間収入・収益）、就業調整の有無、雇用形態別の非正規の職員・従業員（2022年10月） |
| 総務省「平成29年就業構造基本調査」主要統計表 第7表（statInfId 000031735818） | 年齢、所得、男女、配偶関係、就業調整の有無別の非正規の職員・従業員（2017年10月） |

- 所得の階級は、50万円未満・50〜99万円・100〜149万円……250〜299万円（50万円刻み）、300〜399万円・400〜499万円（100万円刻み）、500万円以上です。500万円以上は幅が決まらないので分析から外しました。
- 「配偶者のいない」は「総数 − うち配偶者あり」で計算しました（未婚・死別・離別を含みます）。
- 所得の階級の合計は「総数」と最大2.2%ずれます（所得不詳の分）。

## 手法

集積（bunching）分析を、集計表向けに簡単にした形で行いました。

1. 所得の階級ごとの人数を階級の幅で割って「密度」にする
2. 壁の手前の **50〜149万円の2つの階級を「窓」**として外し、窓の外の6つの階級の密度の対数に2次式を当てはめる（反実仮想の「なめらかな分布」）
3. 窓の中の実際の人数 − 反実仮想の人数 = 超過人数。超過人数 ÷ 反実仮想の人数 = 集積の大きさ b

比べるために、反実仮想を「ほかのグループの分布の形」（就業調整をしていない有配偶女性、配偶者のいない女性、有配偶の男性）で作る方法も試しました。形を窓の外の人数に合わせて拡大縮小し、差を数えます。

## 主な結果

**1. 有配偶の女性だけ、50〜149万円に大きく集まっていた**

| グループ（非正規） | 2017年 b | 2022年 b | 窓の中の割合（2022年） |
|---|---|---|---|
| 有配偶の女性 | 2.37 | 1.79 | 63.8% |
| 配偶者のいない女性 | 0.28 | 0.25 | 42.7% |
| 有配偶の男性 | 0.56 | 0.40 | 31.3% |
| 配偶者のいない男性 | 0.22 | 0.21 | 37.9% |

- 有配偶の女性（2022年、非正規938万人）は、窓の中に599万人いて、なめらかな分布なら215万人。超過は384万人（2017年は456万人）。
- ほかのグループの b は0.2〜0.6で、有配偶の女性の1/3〜1/10。

**2. 「就業調整をしている」人は、窓の中に集中していた**

- 有配偶の女性で就業調整をしている人の割合は、50〜99万円・100〜149万円で55%。150万円を超えると7%以下に下がる。
- 2022年に就業調整をしている有配偶の女性366万人のうち、331万人（90%）が50〜149万円にいる。
- 配偶者のいない女性・男性でも50〜99万円で33〜38%と高い。有配偶の男性は16%。

**3. 反実仮想の作り方で b は大きく変わる**

| 反実仮想の作り方（有配偶の女性） | 2017年 | 2022年 |
|---|---|---|
| 窓の外への多項式（基本） | 2.37 | 1.79 |
| 就業調整をしていない有配偶女性の形 | 0.99 | 1.15 |
| 配偶者のいない女性の形 | 1.72 | 1.37 |
| 有配偶の男性の形 | 3.46 | 2.87 |

**4. 雇用形態・年齢（2022年、有配偶の女性）**

- パートの b は2.87（684万人、窓の中73%）、アルバイト1.66、契約社員0.25、派遣−0.02。集積はほぼパートに限られる。
- 就業調整をしている割合は40〜44歳で45%と最も高く、60代で28〜32%、75歳以上で13%。窓の中にいる割合は年齢でそれほど変わらない（55〜67%）。

## 頑健性

| 設定（有配偶の女性） | 2017年 b | 2022年 b |
|---|---|---|
| 対数の密度・1次 | 2.18 | 1.63 |
| 対数の密度・2次（基本） | 2.37 | 1.79 |
| 対数の密度・3次 | 1.41 | 1.20 |
| そのままの密度・1〜3次 | 2.08〜2.87 | 1.60〜2.29 |
| 窓を50〜99万円だけにする | 1.76 | 1.34 |
| 25〜59歳に限る | 2.58 | 1.97 |
| 100万円刻みにまとめる（窓0〜199万円） | −0.55 | −0.74 |

- 50万円刻みのままなら、どの当てはめ方でも b は1.2〜2.9で、有配偶の女性の集積ははっきり大きい。
- **100万円刻みにまとめると窓の外の点が3つしか残らず、反実仮想が大きく外れて b がマイナスになる**。集積分析は階級の幅に強く左右され、粗い集計表では測れないことがある。
- 2017年→2022年に b はどの設定でも下がった（0.21〜0.61）。ただし、両年の調査の設計の違いや、景気・コロナの影響も混ざっている。

## 言えないこと

- **壁のどこに集まっているかは分からない**：所得の階級が50万円刻みなので、103万円・106万円・130万円のどれの手前に集まっているかは区別できない。
- **集積の原因は分けられない**：窓の中の超過には、税・社会保険の壁による就業調整のほか、短い時間で働きたいという希望、家事・育児・介護との両立、職場の都合など、さまざまな理由が混ざっている。「就業調整をしている」という回答も、その理由までは分からない。
- **制度の効果は言えない**：2017年→2022年の変化を、配偶者特別控除の見直し（2018年）などの制度の変更の効果とは言えない。
- **反実仮想の仮定**：壁がなければ分布はなめらかだったという仮定に立っている。本当に分布がなめらかになるかは分からない。
- **集計値**：個票ではなく集計表なので、標本誤差の区間は計算していない。
