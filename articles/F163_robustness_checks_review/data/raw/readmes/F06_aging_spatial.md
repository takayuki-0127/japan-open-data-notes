# F06 高齢化は地図の上で固まっているか？（空間自己相関・LISA）

看板記事 F06。札幌市・横浜市・福岡市の町丁・字ごとの高齢化率（65歳以上の割合）について、「隣どうしで似ているか」を Moran's I で検定し、高齢化の「塊」（ホットスポット）を LISA で取り出しました。2000年と2020年を同じ区域で比べ、塊がどこへ動いたかも見ています。

## 問い

- 町丁・字の高齢化率は、隣の区域どうしで似ているか（地図の上で偏っているか）
- 高齢化の塊はどこにあり、20年でどう動いたか
- 都心からの距離と高齢化率の関係は変わったか

## データ

| データ | 中身 | 出どころ |
|---|---|---|
| 国勢調査 2020年 小地域集計 | 年齢（5歳階級、4区分）別・男女別人口（統計表 T001082） | e-Stat 統計GIS |
| 国勢調査 2000年 小地域集計 | 年齢別（5歳階級、4区分）・男女別人口（統計表 T000002） | e-Stat 統計GIS |
| 小地域の境界（2000年・2020年） | 町丁・字の境界（シェープファイル、世界測地系 緯度経度） | e-Stat 統計GIS |

- 対象：札幌市（10区）・横浜市（18区）・福岡市（7区）
- 高齢化率＝65歳以上 ÷（15歳未満＋15〜64歳＋65歳以上）。年齢「不詳」は分母に入れていません
- 人口50人未満の区域は除きました（頑健性で 30人・100人も確認）
- 2020年の秘匿区域（値が X）は、合算先の区域と境界ごとまとめました。2000年の秘匿・合算の区域（HTKSYU≠0）は除きました
- 2000年の値は、2000年の境界から2020年の境界へ面積で按分して、同じ区域どうしで比べています

## 手法

| 段階 | 内容 |
|---|---|
| 隣接 | Queen 型（辺か頂点を共有すれば隣）。隣のない区域は最も近い1区域を隣とする。行で標準化 |
| 全体の偏り | Moran's I、並べ替え検定 999回 |
| 塊の場所 | LISA（局所 Moran's I）、並べ替え 999回、p<0.05 で 高高・低低・高低・低高 に分類。FDR（偽発見率）で補正した場合の件数も出す |
| 変化 | 2000年と2020年の LISA の分類のクロス表、高高の区域の市役所からの距離（中央値） |
| 都心からの距離 | 市役所からの距離帯ごとに、人口で重み付けた高齢化率 |

## 主な結果

| | 札幌市 | 横浜市 | 福岡市 |
|---|---|---|---|
| 区域の数（2020年） | 5,115 | 1,604 | 1,054 |
| 高齢化率（2000年→2020年） | 14.6% → 27.9% | 14.0% → 25.0% | 13.4% → 22.1% |
| Moran's I（2000年） | 0.15 | 0.34 | 0.28 |
| Moran's I（2020年） | 0.28 | 0.37 | 0.41 |
| 高高の区域（2020年、p<0.05） | 511 | 159 | 106 |
| うち FDR 補正後も残る区域 | 73 | 33 | 33 |
| 高高の区域に住む人の割合（2020年） | 10.1% | 10.0% | 6.4% |
| 2000年の高高のうち2020年も高高 | 98 / 204 | 10 / 174 | 32 / 62 |
| 高高の区域の市役所からの距離（中央値、2000年→2020年） | 6.3km → 9.2km | 2.5km → 11.5km | 8.4km → 9.3km |

- 3都市とも Moran's I はすべての設定で正で、並べ替え検定の p は 0.001（999回で最小）でした。高齢化率は地図の上で固まっていて、その固まり方は20年で強くなっています
- 横浜市は塊が大きく動きました。2000年の高高は市役所から2.5km（中央値）の都心部にありましたが、2020年は11.5km の郊外（市の西部・南部）に移り、2000年の高高174区域のうち2020年も高高なのは10区域だけでした
- 都心からの距離との関係は逆になりました。横浜市の2000年は都心（0〜2km）が18.5%、15km以上が10.2%と都心ほど高かったのに、2020年は0〜2km が20.9%、12〜15km が26.9% と郊外の方が高くなっています。札幌市・福岡市も2020年は都心から離れるほど高く、福岡市は 0〜2km の15.3% に対して 10〜12km で27.4% でした

## 頑健性

`results/moran_robust.csv` にすべての数値があります。

| 確かめたこと | Moran's I の範囲（2020年、3都市） |
|---|---|
| 隣接の定義：Rook 型 | 0.31〜0.41 |
| 隣接の定義：近い8区域（KNN） | 0.26〜0.35 |
| 隣接の定義：重心から1.5km 以内 | 0.16〜0.31 |
| 人口30人以上／100人以上の区域 | 0.28〜0.42 |
| 年齢「不詳」が2割以上の区域を除く | 0.28〜0.41 |
| 並べ替え 9,999回 | 値は同じ、p<0.001 |
| 2000年を按分せず2000年の境界のまま計算 | 0.14・0.33・0.25（按分した値とほぼ同じ） |

隣接の定義を変えると値の大きさは変わります（距離帯は隣が多くなるので小さめに出る）が、すべて正で有意でした。2000年→2020年に Moran's I が上がった点は、どの設定でも同じでした。

## このデータで言えないこと

- なぜ固まるのか（団地や住宅地が同じ時期にできて、同じ世代が入居したことなど）は、このデータだけでは分かりません
- 町丁・字は大きさがばらばらで、札幌市南区などの山の区域は面積が大きく、地図では目立ちます（高高の区域に住む人は全体の1割ほど）
- 2000年の値は面積で按分しているので、区域の中で人が偏って住んでいる場合はずれます（按分しない計算でも結論は同じでした）
- 年齢「不詳」は分母から除いているので、不詳の多い区域では高齢化率が少しずれます
- 特定の地域を評価するものではありません
