# F44 出生率のトレンドはいつ折れたのか？（構造変化の検定・Bai–Perron）

看板記事 F44。合計特殊出生率の長い系列で、トレンドが「いつ」「何回」折れたのかを、折れ目の年を自分で決め打ちせずデータから推定した。全国（1950〜2023年）と47都道府県（1972〜2023年）で同じ分析をして、折れ目の年がそろうかを比べた。

## 問い

- 全国の合計特殊出生率のトレンドは、何回、いつ折れたか
- 推定した折れ目の年は、どれくらい確かか（区間）
- 都道府県ごとに推定しても、同じ年に折れているか
- 「決め打ちの検定（Chow）」「位置を探す検定（sup-F）」「安定性の検査（CUSUM）」で、言えることはどう違うか

## データ

| データ | 中身 | 期間 |
|---|---|---|
| 国立社会保障・人口問題研究所『人口統計資料集（2025年版）』表12-33「都道府県別合計特殊出生率：1925～2023年」 | Excel の2枚目（年ごとの表）を CSV にしたもの（`data/raw/ipss_T12-33_tfr_pref.csv`）。元は厚生労働省『人口動態統計』、総務省『国勢調査』『人口推計』 | 全国：1950年、1951〜2023年は毎年／都道府県：1950〜70年は5年ごと、1971年（沖縄は1972年）から毎年 |

- 全国は日本人人口・年齢各歳による値。1950〜72年の全国は沖縄県を含まない
- 都道府県の率は、年によって分母の女性人口が「総人口」か「日本人人口」かが違う（表の注記）。この切り替えで小さな段差が入っている可能性がある
- 全国の分析は1950〜2023年（74年）、都道府県は47都道府県がそろう1972〜2023年（52年）

## 手法

| ステップ | 中身 |
|---|---|
| モデル | 区間ごとに「切片＋年の傾き」の直線を当てはめる。折れ目で切片と傾きの両方が変わる。全国は1966年（丙午）の落ち込みにダミーを入れる |
| Bai–Perron | 動的計画法で、折れ目の数 m（0〜5）ごとに残差平方和が最小になる位置を求める。最小の区間の長さは8年。m は BIC で選び、LWZ（罰則が重い）とも比べる |
| 折れ目の年の区間 | 選んだ当てはめの残差を AR(1) で作り直し、299回推定し直したときの5〜95%点 |
| Chow 検定 | 1975・1990・2006・2016年を決め打ちして、前後で直線が同じかを F 検定 |
| sup-F | 1か所の折れ目を位置不明として探した F の最大値。p 値は、折れ目なしの直線に「独立な誤差」または「AR(1) の誤差」を足して作り直した499回のブートストラップ |
| CUSUM | 1975〜2023年を1本の直線とみなしたときの再帰的残差の累積和と、5%の境界（Brown–Durbin–Evans） |
| 都道府県 | 1972〜2023年について、都道府県ごとに同じ Bai–Perron（m は0〜5、BIC）を当てはめ、折れ目の年の分布を全国と比べる |

## 主な結果

**全国（1950〜2023年）**：BIC で選ばれた折れ目は4つ。

| 区間 | 傾き（10年あたり） |
|---|---|
| 1950〜57年 | −2.20（戦後のベビーブームのあとの急な低下） |
| 1958〜74年 | +0.08（ほぼ横ばい、2前後） |
| 1975〜2005年 | −0.22 |
| 2006〜15年 | +0.13（持ち直し） |
| 2016〜23年 | −0.35（1975〜2005年より速い低下） |

- BIC は折れ目4つ（−375.2）と5つ（−375.0、1989年が加わる）がほぼ同点。LWZ では3つ（1958・1975・2007年）
- 折れ目の年の90%区間：1958年（1958〜1958）、1975年（1975〜1975）、2006年（1988〜2007）、2016年（2008〜2016）。新しい2つの折れ目は、年の幅がかなり広い
- Chow 検定は、決め打ちした4つの年すべてで p&lt;0.01（1975年 F=12.7、1990年 14.8、2006年 15.2、2016年 5.5）。年を決め打ちすると「どこで切っても有意」になりやすい
- sup-F は1958年で F=100.7。誤差が独立なら95%点は7.9で p&lt;0.002 だが、誤差の1年前との相関（0.95）を入れると95%点は385で p=0.54。出生率のように動きがなめらかな系列では、折れ目の「有無」の検定は誤差の扱いで答えが変わる
- CUSUM：1975〜2023年を1本の直線とみなすと、2016年に5%の境界を超え、2023年まで8年続けて超えた

**都道府県（1972〜2023年）**

- 折れ目の数（BIC）は3つが19、4つが28都道府県
- 折れ目の年（169個）は4つの時期に集まった：1980〜84年（46）、1988〜94年（29）、1999〜2007年（47）、2015〜16年（47）。同じ期間の全国の折れ目は1980・1989・2006・2016年
- 47都道府県すべてで、2015年か2016年から新しい区間が始まり、その区間の傾きはすべてマイナス（中央値 −0.031/年、−0.057〜−0.019）
- 2003〜08年に折れ目があるのは43都道府県。残りの4（栃木・埼玉・千葉・東京）は1999〜2002年に折れ目があった

## 頑健性

全国（`results/robust_national.csv`）

| 設定 | 折れ目の年 |
|---|---|
| 基本（1950〜、h=8、BIC、1966年ダミー） | 1958, 1975, 2006, 2016 |
| 最小区間 h=5 | 1956, 1965, 1975, 2006, 2017 |
| 最小区間 h=10 | 1960, 1974, 2006 |
| 対数をとる | 1958, 1975, 1989, 2006, 2016 |
| LWZ で選ぶ | 1958, 1975, 2007 |
| 1966年ダミーなし | 1958, 1967, 1975, 2006, 2016 |
| 1960年から | 1971, 1979, 1989, 2006, 2016 |
| 1975年から | 1983, 1994, 2006, 2016 |
| 1972年から | 1980, 1989, 2006, 2016 |

- 2006〜07年の折れ目は9設定すべて、2016〜17年は7設定で出た。出なかった h=10 は、2016年以降が8年しかなく「10年以上」の区間を作れないため。LWZ は罰則が重く、折れ目を3つに絞った
- 1975年より前の折れ目は、期間の始まりを変えると動く

都道府県（`results/robust_pref.csv`）

| 設定 | 平均の折れ目の数 | 2003〜08年に折れ目がある都道府県 | 2013〜18年に折れ目がある都道府県 |
|---|---|---|---|
| 基本 h=8 | 3.60 | 43 | 47 |
| h=5 | 4.40 | 40 | 37 |
| h=10 | 3.15 | 33 | 40 |
| 対数 | 3.57 | 45 | 47 |

## 言えないこと

- 折れ目の理由は分からない。折れ目が制度や出来事の年と重なっても、それが原因だとは言えない
- 折れ目の「年」は、新しい2つ（2006年・2016年）では区間が広く、年単位では決めきれない
- 誤差の時間のつながりが強い系列では、折れ目が「ある」こと自体の検定の答えが、誤差の仮定で大きく変わる（sup-F の結果）
- 区間ごとの直線は、出生率の動きを簡単に要約したもの。将来の予測ではない
- 都道府県の率は年によって分母の定義が違い、その切り替えで小さな段差が入っている可能性がある
