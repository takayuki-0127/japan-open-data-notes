# F47 都市ごとの「食の好み」を、行列分解で取り出す（NMF）

看板記事 F47。家計調査の「品目×都市」の支出金額の表（52都市×178品目）を、非負値行列因子分解（NMF）で「好みのパターン」と「都市ごとのパターンの組み合わせ」に分けた。推薦システムで使う行列分解を、身近な食の統計に当てはめ、解釈と安定性（初期値・パターンの数・10年前のデータ）まで確かめた。

## 問い

- 品目×都市の表を分解すると、どんな「好みのパターン」が出てくるか
- 各都市は、どのパターンの組み合わせとして表せるか
- その結果は、初期値・パターンの数・データの選び方を変えても同じか
- 10年前（2013〜15年平均）と比べて、都市の好みは変わったか

## データ

| データ | 中身 | 期間 |
|---|---|---|
| 総務省統計局「家計調査（二人以上の世帯）品目別都道府県庁所在市及び政令指定都市ランキング」 | 食料13分類の Excel（rank01〜13.xlsx）。品目ごとに52都市と全国の1世帯当たり年間支出金額（円） | 2023〜2025年平均 |
| 同（過去のランキング） | rank13-15.xls | 2013〜2015年平均 |
| 行政区域の境界 | smartnews-smri/japan-topography（国土数値情報 行政区域 2021 をもとにした簡略版 TopoJSON、CC BY 4.0）。地図の点の位置にだけ使う | 2021 |

- 2023〜25年平均は253品目。小計・合計の行（「穀類」「生鮮魚介」など）と「学校給食」を外した211品目のうち、中身があいまいな「他の〜」33品目を外した **178品目** を本体に使う
- 2013〜15年平均で名前が違う品目（スパゲッティ→パスタなど3つ）は同じ品目として扱った。両方にある171品目を比べる
- 金額は世帯の支出で、外食や観光客の消費は「外食」の品目以外には入っていない

## 手法

| ステップ | 中身 |
|---|---|
| 表を作る | 品目ごとに「都市の金額 ÷ 全国の金額」（全国=1）。さらに都市ごとに178品目の平均で割り、都市全体の支出の多さの差をそろえる |
| NMF | X（都市×品目）≈ W H。W：都市ごとのパターンの重み、H：パターンごとの品目の重み。どちらも0以上。scikit-learn の NMF（初期値 nndsvda、フロベニウスノルム） |
| パターンの数 | k=2〜10 で相対誤差（平均だけで当てた場合と比べた残差）と、初期値20通りでの安定性（本体とのコサイン類似度、ハンガリー法で対応づけ）を見て、k=6 にした |
| パターンの名前 | 「その品目の重みのうち、このパターンが占める割合」が大きく、かつ重みが平均以上の品目で名前を付けた |
| 都市の構成 | W を都市ごとに合計1にそろえた割合 |
| 頑健性 | k=5・7・8、「他の〜」も含める、支出水準をそろえない、10年前のデータで分解し直す、PCA との比較 |
| 10年前との比較 | 本体の H を固定し、10年前の表から都市ごとの W を非負最小二乗で求めて、構成の変化を見る |

## 主な結果

**6つのパターン**（パターンを特徴づける品目と、そのパターンがいちばん大きい都市の数）

| パターン | 特徴づける品目 | いちばん大きい都市 | 割合が大きい都市 |
|---|---|---|---|
| P1 九州・沖縄型 | 干ししいたけ、カステラ、たい、焼酎、かつお節・削り節 | 12 | 鹿児島 0.65、那覇 0.63、長崎 0.62 |
| P2 関西・北陸型 | かに、牛肉、たい、ぶり、れんこん、中華食 | 13 | 神戸 0.49、京都・福井 0.45 |
| P3 果物・麺の内陸型 | 桃、塩さけ、清酒、中華そば、納豆 | 2 | 福島 0.69、岡山 0.42、長野 0.33 |
| P4 日本海の魚介型 | しじみ、かれい、メロン、梨、いわし、いか | 2 | 松江 0.53、鳥取 0.40、青森 0.37 |
| P5 かつお・しらすの太平洋型 | かつお、干しあじ、しらす干し、はくさい漬 | 1 | 高知 0.56、水戸 0.29、静岡 0.28 |
| P6 東日本・大都市型 | まぐろ、ワイン、さやまめ、しゅうまい、ウイスキー | 22 | 東京区部 0.56、横浜 0.55、札幌 0.53 |

- 元の表でも差は大きく、たとえば桃は福島市が全国の6.0倍、しじみは松江市が6.8倍、カステラは長崎市が6.6倍、かつおは高知市が4.5倍
- 相対誤差は0.71（6つのパターンで、都市の違いの約3割を再現）。パターンを増やすと誤差は少しずつ下がり、はっきりした「ひじ」はない
- いちばん大きいパターンで色分けすると、九州・沖縄（P1）、近畿と北陸（P2）、関東・東北・東海の多く（P6）にきれいに分かれる。都市の多くは2〜3のパターンの組み合わせで、1つのパターンが半分を超える都市は10
- PCA の第1主成分（16%）は「九州の品目 ↔ 首都圏の品目」の軸で、NMF の P1（相関0.81）・P6（−0.90）とほぼ同じ情報。NMF は「0以上の足し算」なので、P2〜P5 のような地域ごとのパターンを別々に取り出せる

## 頑健性

| 確かめたこと | 結果 |
|---|---|
| 初期値を20通り（ランダム） | 13回は本体と同じ解（全パターンの類似度0.99超）。残り7回は誤差が0.002〜0.004だけ大きい別の解で、P5（太平洋型）がほかと混ざることがある（類似度0.73〜0.83） |
| パターンの数 k=5 | P5 が消え、ほかの5つは本体とほぼ同じ（類似度0.96〜1.00） |
| k=7 | 本体の6つはすべて残り（類似度0.97〜1.00）、長崎市を中心とする7つ目（カステラ・あじ・緑茶）が分かれる |
| 「他の〜」33品目も含める | パターンの類似度0.99、都市の構成の相関0.94〜0.97、いちばん大きいパターンが同じ都市90% |
| 都市の支出水準をそろえない | 類似度0.97以上、構成の相関0.91〜0.99、同じ都市96% |
| 10年前（2013〜15年平均）で分解し直す | パターンの類似度は中央値0.87（最小0.78）、都市の構成の相関は中央値0.55と、パターンの切り方そのものはかなり変わる |
| 10年前の表を、本体のパターンで表し直す | 都市の構成の相関はパターンごとに0.95〜0.99、いちばん大きいパターンが同じ都市は52都市中50 |

## このデータで言えないこと

1. 世帯の支出金額なので、「よく食べる」とは限らない。値段が高い地域では同じ量でも金額が大きくなる
2. 外食や観光客の消費、贈答用の購入などが混ざる品目がある。都市の「好み」は世帯の買い物の傾向にとどまる
3. 県庁所在市と政令市だけで、県全体や郊外・農村の好みは分からない
4. パターンの名前は、重みの大きい品目を見て付けたもので、解釈には幅がある。パターンの数も「6つが正しい」わけではない
5. 1都市あたりの標本は数十〜百世帯程度で、3年平均でも品目によってはぶれが大きい
