# F43 金利が上がると、何か月後に何が動くのか？ VAR と局所射影で比べた

看板記事 F43 の分析コード・データ・図です。note の記事「金利が上がると、何か月後に何が動くのか？」の中身をここで再現できます。

## 問い

日本の金利が「予想外に」0.25%ポイント上がったとき、生産・物価・失業率・為替は何か月後にどれだけ動くのか。
同じ識別の仮定のもとで、VAR（ベクトル自己回帰）と局所射影（Local Projections）で答えはそろうのか。

## データ

| 変数 | 系列 | 出典 |
|---|---|---|
| 短期金利 | 無担保コールレート O/N 物（月平均） | 日本銀行「時系列統計データ検索サイト」API（FM02, STRACLUCON） |
| 長期金利 | 10年国債利回り | F18 で取った系列 |
| 為替 | ドル円スポット 17時時点 月中平均 | 日本銀行 API（FM08, FXERM07、記事035・F39 と同じ） |
| 輸入物価 | 輸入物価指数・契約通貨ベース 総平均 | 日本銀行 API（PR01） |
| 消費者物価 | 生鮮食品を除く総合 | 総務省「消費者物価指数」（F12 の集計表） |
| 失業率 | 完全失業率（季節調整値） | 総務省「労働力調査」（F12 の集計表） |
| 生産 | 鉱工業生産指数（季節調整値） | 経済産業省（内閣府「景気動向指数」の個別系列、F13 で取得） |

- 期間：1985年7月〜2026年8月（月次）。基本の推定は短期金利が動いていた **1985年7月〜2008年12月**
- 生産・物価・為替・輸入物価は対数×100（応答は%で読める）
- 消費者物価は消費税の引き上げ月の段差を取り除き（前年・翌年の同じ月の前月比を基準に段差を推定：1989年4月 +1.22、1997年4月 +1.53、2014年4月 +1.80、2019年10月 +0.20）、月ダミーで季節性を除いた
  - 2019年10月は幼児教育の無償化で同じ月に物価が下がったため、段差は小さく出ている

## 手法

| 手順 | 内容 |
|---|---|
| 識別 | 再帰的（コレスキー）。順番は 生産 → 物価 → 失業率 → 金利 → ドル円。生産・物価・失業率は当月は金利に反応せず、金利は当月の3つを見て決まる、と仮定 |
| VAR | 水準の VAR（定数あり、ラグ12）。応答の90%区間は残差ブートストラップ400回（各回で金利の当月の応答を0.25にそろえ直す） |
| 局所射影 | h か月先ごとに「y(t+h) − y(t−1)」を、当月の金利（ショック）・当月の生産／物価／失業率・全変数の過去12か月に回帰。90%区間は Newey–West（ラグ h+1） |
| ショックの大きさ | 金利が当月に0.25%ポイント（25bp）上がる大きさ |
| 比べ方 | 応答の形・区間の幅（局所射影÷VAR）・頑健性9通り |

同じ情報・同じ識別なら、VAR と局所射影は母集団では同じものを推定します（Plagborg-Møller & Wolf, 2021）。違いが出るのは、有限の標本で VAR がラグ12か月の構造で先の月まで外挿するのに対し、局所射影は月数ごとにデータに直接当てはめるからです。

## 主な結果（基本：1985〜2008年、短期金利、ラグ12）

金利は一度上がると下がりにくく、1年後も約0.29%ポイント高いままでした（VAR）。

| 変数 | VAR 12か月後 | VAR 24か月後 | 局所射影 12か月後 | 局所射影 24か月後 | 局所射影 36か月後 |
|---|---|---|---|---|---|
| 鉱工業生産（%） | +0.54（−0.34〜+1.49） | +0.27（−0.54〜+1.18） | +0.15（−0.50〜+0.80） | −0.33（−1.01〜+0.36） | −0.75（−1.41〜−0.09） |
| 消費者物価（%） | +0.12（+0.02〜+0.20） | +0.21（+0.04〜+0.36） | +0.08（+0.01〜+0.15） | +0.03（−0.07〜+0.14） | +0.03 |
| 失業率（%ポイント） | −0.02 | −0.03 | +0.04（+0.00〜+0.07） | +0.02 | −0.02 |
| ドル円（%、上＝円安） | −0.06 | −0.28 | +0.12 | −0.31 | −0.12 |

- **生産**：VAR では3年間ずっと下がらない。局所射影では1年半後からマイナスになり、はっきり下がるのは36か月後だけ
- **物価**：どちらも「金利が上がると物価が上がる」（いわゆる物価パズル）。VAR では3年後まで+0.2%前後が続き、局所射影では1年後の+0.08%をピークに消える
- **失業率**：局所射影では5〜12か月後に+0.03〜0.04%ポイントとはっきり上がる。VAR では動かない
- **2つの手法の形の似かた**（36か月の経路の相関）：生産0.30、物価0.18、失業率0.32、ドル円0.03
- **区間の幅**（局所射影÷VAR、中央値）：生産0.78、物価0.77、失業率1.07、ドル円1.13。局所射影の区間が「いつも広い」わけではなかった（Newey–West の区間は小さい標本で狭く出やすい点に注意）
- **ラグの数**：情報量規準では AIC 7、BIC 1（基本は月次の慣例どおり12）

### 長期金利のショック（1995〜2026年）

短期金利がほぼ動かない期間（前月差の標準偏差：1986〜2008年 0.19 → 2009〜2026年 0.03%ポイント）は、長期金利のショックで同じことをした。

- 生産は **むしろ増えた**：12か月後 VAR +0.97%（+0.08〜+1.46）、局所射影 +1.79%（+1.06〜+2.53）
- 景気がよいときに長期金利が上がるため、再帰的な識別では「予想外の引き締め」をうまく取り出せていないと考えられる（推測）
- 2009〜2026年だけにすると区間が広く、生産・物価ともはっきりしない

## 頑健性（`results/robustness.csv`、図6）

| 設定 | 生産24か月後 VAR／局所射影 | 物価24か月後 VAR／局所射影 |
|---|---|---|
| 基本 | +0.27／−0.33 | +0.21／+0.03 |
| ラグ6 | +0.37／0.00 | +0.18／+0.25 |
| ラグ18 | +1.43／−1.00 | +0.39／−0.03 |
| 輸入物価（資源価格）を先頭に足す | +0.02／−0.37 | +0.12／+0.02 |
| 1985〜1995年だけ（ラグ6） | +0.12／+0.16 | +0.07／+0.11 |
| 1985〜2026年（ゼロ金利期も含める） | +0.55／+0.09 | +0.26／+0.15 |
| 長期金利（1995〜2026年） | −0.05／+0.40 | +0.04／+0.24 |
| 長期金利（2009〜2026年、ラグ6） | +0.02／−0.98 | −0.12／−0.12 |
| 局所射影で当月の遅い変数を制御しない | — ／−0.30 | — ／+0.02 |

- 生産の向きは、手法とラグの数で入れ替わる（ラグ18では VAR +1.43、局所射影 −1.00）
- 輸入物価を入れると、VAR の物価パズルは小さくなり（24か月後 +0.21 → +0.12）、区間が0をまたぐ
- 結論：この識別では、金利の効果を「何か月後にどれだけ」と言い切れない。手法と設定で答えが変わること自体が結果

## 言えないこと

- 再帰的な識別は「金利は当月の生産・物価・失業率を見て決まり、3つは当月は金利に反応しない」という仮定に依存する。取り出したショックが日銀の政策の「予想外の部分」だとは言い切れない（市場の予想を使った識別や、政策決定会合の日の金利の動きを使う方法は使っていない）
- 物価が上がる・生産が増えるという結果は、金利が景気や物価の先行きに反応して動いた分が混ざっている可能性が高い（推測）
- ゼロ金利の期間は短期金利がほとんど動かず、この方法では効果を測れない
- 株価は使っていない（公的な月次の株価指数を手元で用意できなかった）
