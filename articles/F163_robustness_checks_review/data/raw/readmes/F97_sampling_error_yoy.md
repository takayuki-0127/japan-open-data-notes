# F97 「前年比+1%」は、本当に増えたと言えるのか？ 標本誤差で前年比を読み直す

## 問い

家計調査や労働力調査は標本調査なので、公表される数字には「調べた世帯がたまたまこうだった」ことによるぶれ（標本誤差）があります。統計局は標準誤差率を公表しています。それを使うと、ニュースでよく見る「前年同月比 −2.5%」「失業率が0.1ポイント上昇」は、標本誤差の範囲を超えていると言えるでしょうか。

## データ

| データ | 内容 | 期間 |
|---|---|---|
| 総務省統計局「家計調査年報（家計収支編）」の「家計調査の概要」 | 標準誤差率：表2（二人以上の世帯・単身世帯の10大費目、年平均）、表3（二人以上の世帯の消費支出、月別）、表4（地方別） | 2022〜2025年 |
| 総務省統計局「家計調査」参考資料『変動係数を用いて推計した標準誤差率』 | 二人以上の世帯の30項目の標準誤差率と変動係数 | 2018年 |
| 家計調査（家計収支編）二人以上の世帯 長期時系列表（e-Stat） | 品目分類の支出金額（月）、名目・実質の前年同月比（公表値） | 2000年1月〜2026年8月 |
| 総務省統計局「労働力調査」標本抽出方法、結果の推定方法及び推定値の標本誤差 | 推定値の大きさ別の標準誤差率（年平均・月次）、標本の交替のしかた | 2025年 |
| 労働力調査 完全失業率（季節調整値、月） | F18 で取得したもの | 1994年1月〜2026年8月 |

- 標準誤差率の表は PDF から目で書き写し、PDF の文字列に同じ数値の並びがあるかを機械で照合しました（175項目すべて一致、`results/se_transcription_check.csv`）。
- 家計調査の月の系列は F11（statInfId=000040270646・000040270647・000040270648）、完全失業率は F18 で取得したものを使っています。

## 手法

1. **前年比の標準誤差**：2つの時点の標準誤差率を s1, s2、標本の相関を ρ とすると、前年比（%）の標準誤差はおおよそ √(s1² + s2² − 2ρ s1 s2)。前年比の絶対値が 1.96 × これ を超えたら「95%で増えた（減った）と言える」と判定。
   - 家計調査の世帯は6か月で入れ替わるので、**前年同月比の2つの月は別の世帯**（ρ = 0）。年平均どうしは、年をまたぐ世帯が一部重なるので ρ = 0〜0.2 で幅を見た。
   - 労働力調査は、同じ調査区を翌年の同じ月にもう一度調べ、毎月半数の世帯が入れ替わる設計なので、前月差・前年差とも標本が半分重なる。相関は公表されていないため ρ = 0・0.25・0.5 で幅を見た。
2. **標準誤差率**：家計調査の10大費目は2022〜2025年の4年の平均、30項目は2018年の参考表。月の消費支出は表3の48か月の平均（1.42%）。品目の月の標準誤差率は「年の値 × √12」で近似（消費支出では実際の比が 3.54 倍、√12 = 3.46）。
3. **完全失業率の標準誤差**：完全失業者数の大きさから、表の「推定値の大きさ別標準誤差率（月次）」を対数で補間し、労働力人口（約6,900万人と仮定）で割ってポイントに直した。
4. **見つけられる最小の変化**：1.96 × √2 × s（95%）。検出力80%で見つけるには 2.80 × √2 × s。
5. **確かめ**：月の前年比の「13か月移動平均からのばらつき」と、標本誤差だけから予想されるばらつきを比べた。

## 結果

- **月の消費支出**：前年同月比の標準誤差は約2.0ポイントで、**±3.9ポイントの中は標本誤差の範囲**。2001年1月〜2026年8月の308か月のうち、範囲の外だったのは17%（53か月）。月ごとの標準誤差率が分かる2023〜2025年の36か月でも、外だったのは6か月だけ。
- **月の前年比のぎざぎざは、ほぼ標本誤差の大きさ**：13か月移動平均からのばらつき（標準偏差）は1.87ポイントで、標本誤差だけから予想される1.92ポイントとほぼ同じ（消費税・コロナの時期を除く247か月）。
- **年の消費支出**：前年比の標準誤差は約0.57ポイントで、±1.1ポイントの中は範囲内。名目の前年比で見ると、23年のうち10年は範囲内だった。2012年の+1.13%は外、2023年の+1.08%は中。「+1%」は、ちょうど境目。
- **費目で大きく違う**：年の前年比で範囲の外だった年は、食料・光熱水道で83%、住居で0%、教育で22%。住居（標準誤差率2.6%）は±7.3ポイント、教育（3.1%）は±8.5ポイントの変化がないと「増えた」と言えない。30項目で見ると、範囲の外は全体の48%（設備修繕・維持は0%、魚介類は87%）。
- **単身世帯・地方別**：年の消費支出でも、単身世帯は±3.8ポイント、地方別は±2.0（関東）〜±6.1（沖縄）ポイント。月の全国の値と同じくらいの幅がある。
- **確からしさの目安**：公表値が+1%のとき、本当の変化が0より大きい確からしさは、年の消費支出で96%、月の消費支出で69%、年の単身世帯で70%、年の教育で59%（平らな事前分布を置いたおおまかな目安）。
- **完全失業率**：月の標準誤差は約0.07〜0.10ポイント（中央値0.087）。前月差の判定の幅は±0.17（ρ=0.5）〜±0.24（ρ=0）ポイントで、**「0.1ポイント上昇（低下）」は、どの仮定でも範囲の中**。1994年2月〜2026年8月の391か月のうち、前月差が±0.1以内だったのは324か月（83%）。範囲の外は3〜14%。前年差（12か月の差）では53〜68%が外。

## 頑健性

| 確かめたこと | 設定 | 範囲の外の割合 |
|---|---|---|
| 年の標本の相関 | ρ = 0 / 0.1 / 0.2 | 11費目：44% / 46% / 47%、消費支出：57% / 61% / 65% |
| 信頼水準 | 95% / 90% | 年の11費目：44% / 49%、月の消費支出：17% / 23% |
| 標準誤差率の出どころ（年） | 2022年 / 2025年 / 2018年の表 | 44% / 42% / 47% |
| 月の標準誤差率 | 平均1.42% / 最小1.1% / 最大1.7% | 17% / 24% / 11% |
| 特別な月を除く | 2014年1月〜2015年6月と2019年6月〜2021年12月（消費税の引き上げ・コロナの時期）を除く | 11% |
| 名目と実質 | 名目の前年同月比 | 19%（実質は17%） |
| 品目の月の標準誤差率 | √12倍 / 実際の比3.54倍 | 23% / 22% |
| 労働力調査の標本の相関 | ρ = 0 / 0.25 / 0.5 | 前月差：3% / 6% / 14% |

結論（月の消費支出の前年同月比は8割以上が標本誤差の範囲、年の消費支出の「+1%」は境目、完全失業率の0.1ポイントの動きは範囲の中）は、どの設定でも変わりませんでした。

## 言えないこと

1. ここで扱ったのは**標本誤差だけ**です。回答の誤り、記入漏れ、家計簿の改正（2018年）、調査世帯の偏りなどの「標本誤差以外の誤差」は入っていません。範囲の外でも、それが本当の変化とは限りません。
2. 標準誤差率は2018年と2022〜2025年の公表値です。2021年以前の月や年も同じ大きさと仮定しました（集計世帯数は大きくは変わっていません）。
3. 年平均どうし、労働力調査の月どうしの標本の相関は公表されておらず、幅を持たせて計算しました。
4. 品目の月の標準誤差率は「年の値 × √12」の近似です。完全失業率の標準誤差は、大きさ別の表からの補間と、労働力人口を一定と置いた近似です。季節調整や四捨五入（0.1ポイント単位）の影響も入れていません。
5. 「範囲の中」は「変化がなかった」という意味ではありません。この標本の大きさでは見分けられない、という意味です。3か月続けて同じ向き、のように複数の月を合わせて見ると、1か月では見えない変化が見えることがあります。
6. 統計の作り方を批判するものではありません。標準誤差率を公表しているからこそ、こうした読み方ができます。
