# F85 日本経済の「要」の産業はどれか？ 産業連関表108部門をネットワークで読むと、答えは物差ししだい。よく買われるのは対事業所サービス、波及の強いキーセクターは素材と部品の28部門、GDPへの効き方は商業が最大だった

看板記事 F85。2020年産業連関表（統合中分類108部門）の中間取引を「産業どうしのネットワーク」として読み、どの産業が経済の要になっているかを、5つの物差しで比べました。

## 問い

- 日本経済の「要」（ほかの産業とのつながりが強く、止まると影響が広がる産業）はどれか
- その答えは、要の測り方（物差し）を変えるとどれだけ変わるか
- ある産業の需要や供給が減ったとき、影響はどこへどれだけ広がるか

## データ

| データ | 内容 |
|---|---|
| 総務省ほか「令和2年（2020年）産業連関表」取引基本表（生産者価格評価、統合中分類108部門） | e-Stat statInfId=000040187026 |
| 同 雇用表・部門分類コード表 | 000040187066・000040186856 |
| 「平成27年（2015年）産業連関表」取引基本表（統合中分類107部門） | 000031839447（頑健性） |

- 新しく取得せず、F38 で取得した JSON（`data/raw/io_tables.json`）を使いました。
- 表は競争輸入型なので、中間取引には輸入品も入っています。ネットワークの分析では、行ごとの輸入係数（輸入÷国内需要）で輸入分を除いた「国内の中間取引」を使いました（`data/domestic_flows_2020.csv`）。輸入分を除かないと、輸入が多い原油・天然ガスなどの前方連関が実態より何十倍にも大きく出ます。

## 手法

| 物差し | 計算 | 何を測るか |
|---|---|---|
| 後方連関（Rasmussen） | 競争輸入型レオンチェフ逆行列 (I−(I−M)A)⁻¹ の列和を平均で割る | 買い手として、ほかの産業の生産をどれだけ引き出すか |
| 前方連関（Ghosh） | 国内の中間取引の配分係数から作った Ghosh 逆行列の行和を平均で割る | 売り手として、ほかの産業にどれだけ使われるか |
| キーセクター | 後方連関と前方連関がどちらも1を超える部門 | 両方向に波及が強い部門 |
| PageRank・固有ベクトル・媒介中心性・強度 | 国内の中間取引を重みにした有向グラフ（自部門内取引は除く） | ネットワークの中での位置 |
| Domar ウエイト | 国内生産額 ÷ GDP（粗付加価値の合計） | その産業の生産性が1%変わると GDP が何%動くか（Hulten の定理） |
| 仮想的抽出法 | その部門との国内の中間取引をすべて消したとき、ほかの部門の生産が何%減るか | 取引が止まったときの影響 |

ショックの伝わり方は、(1) 最終需要が1兆円減ったときの国内生産の減少（レオンチェフ、競争輸入型）と、(2) 付加価値（供給）が10%減ったときの下流の生産の減少（Ghosh、価格が変わらないという強い仮定）で計算しました。集中度は Gabaix の √Σ(Domar²) で測りました。

## 主な結果

- **取引の集まり方**：国内の中間取引は6,058本あり、その上位632本（10%）で金額の8割を占めます。自部門内の取引は14.8%です。
- **キーセクターは28部門**（国内生産額の14%）。うち20部門が製造業で、鉄鋼（銑鉄・粗鋼、鋼材など）、化学（石油化学系基礎製品、合成樹脂など）、紙・パルプ、自動車部品、その他の電子部品など素材と部品が中心です。サービスでは広告・自家輸送・自動車整備・ネット附随サービス・放送が入ります。
  - 後方連関が最も大きいのは乗用車（1.52）、前方連関が最も大きいのは銑鉄・粗鋼（2.12）。
- **PageRank（よく買われる部門）の上位**：対事業所サービス他（0.102）、商業（0.058）、金融・保険（0.048）、電気（0.043）、不動産仲介及び賃貸（0.041）。サービスが上位を占めます。
- **Domar ウエイトの上位**：商業 0.17、対事業所サービス他 0.10、住宅賃貸料（帰属）0.09、医療 0.08、公務 0.08。合計は1.83で、GDP より国内生産額のほうが大きいぶん、産業の生産性ショックは足し合わせると GDP に約1.8倍で効きます。
  - Domar ÷ 付加価値シェアが大きい（中間投入が多く、付加価値の割に生産が大きい）のは乗用車 6.7、広告 5.9、鋼材 4.2、銑鉄・粗鋼 4.1、自動車部品 3.8。
- **集中度**：√Σ(Domar²) は0.304。付加価値シェアで測ると0.201、108部門がすべて同じ大きさなら0.096。産業ごとのばらばらのショックが打ち消し合わずに GDP に残る度合いは、同じ大きさの部門ばかりの場合の約3.2倍です。
- **仮想的抽出法**：取引を止めたときにほかの部門の生産が最も減るのは商業（4.5%）、医療（3.2%）、建築（2.6%）、乗用車（2.5%）、食料品（2.2%）。最終需要が大きい部門ほど大きく出ます（最終需要との順位相関0.74）。
- **物差しどうしの順位相関**：PageRank と Domar 0.30、後方連関と前方連関 0.29、PageRank と仮想的抽出 0.24。「要の産業」は物差しによって大きく入れ替わります。
- **需要ショック（最終需要1兆円減）**：国内生産の減少は乗用車2.33兆円（うち64%がほかの部門、最大は自動車部品0.71兆円）、自動車部品2.29兆円、飲食サービス1.95兆円、建築1.83兆円、電気1.56兆円（ほかの部門28%）、電子デバイス0.68兆円（輸入が多いため）。
- **供給ショック（付加価値10%減、Ghosh）**：生産の減少は付加価値の減少の、鋼材2.66倍、石油製品2.50倍、自動車部品2.45倍、電気2.40倍、情報サービス1.53倍、商業1.51倍、電子デバイス1.45倍。

## 頑健性

| 確認 | 結果 |
|---|---|
| 2015年表（107部門） | 2020年との順位相関：後方連関0.948、前方連関0.973、Domar 0.981、PageRank 0.989。キーセクターは両年とも25、2020年のみ3、2015年のみ4 |
| 閉鎖型（輸入を考えない逆行列） | 後方連関の順位相関0.836、キーセクター30部門 |
| 帰属家賃・分類不明を除く | 後方連関0.999、前方連関0.999、PageRank 0.991、キーセクター27部門 |
| 2桁コードで39部門に統合 | PageRank 上位は対事業所サービスなど・情報サービスなど・道路輸送など・商業・金融・保険。キーセクターは9部門。108部門の PageRank 上位10は39部門でも上位8以内 |
| PageRank の減衰率（0.5・0.95） | 基本（0.85）との順位相関0.974・0.996 |
| 中心性の指標を変える | 8つの物差しの順位相関の表（`results/rank_corr_measures.csv`） |

同じ物差しなら年・統合・設定を変えても順位はほぼ同じで、違うのは物差しどうし、という結果です。

## 言えないこと

- 産業連関表の係数は固定で、価格の変化や代わりの仕入れ先への切り替えを入れていません。実際のショックの影響は、ここでの計算より小さくなることも大きくなることもあります。
- Ghosh モデル（供給ショック）は、買い手が投入を減らさざるをえないという強い仮定に立っていて、因果の推定ではありません。
- 輸入分は部門ごとに同じ割合で除いた近似です（どの産業が輸入品を多く使うかの違いは入っていません）。
- 108部門の中の細かい品目（たとえば電子デバイスの中の半導体の種類）や、企業どうしの取引の網は見えません。
- 2020年はコロナの年で、宿泊・飲食・輸送などの取引がふだんと違います。
- 「要」の順位は物差しによる違いが大きく、どれか1つを正解とは言えません。
