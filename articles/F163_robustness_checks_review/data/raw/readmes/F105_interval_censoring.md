# F105 閉鎖を数年おきの調査でしか確かめられないと、生存曲線はどこまでずれるか？ 区間打ち切りの生存分析

看板記事 F105。note：「閉鎖を数年おきの調査でしか確かめられないと…」（下書き）

## 問い
公的な調査の多くは、ある出来事（閉鎖・転居・発症など）が「いつ起きたか」ではなく、「前の調査と今回の調査の間に起きたか」しか分からない（区間打ち切り）。5年おきの調査や、1回だけの調査で「まだあるか」を聞くだけでも、何年でどれだけ起きるかの曲線や、グループ間の差（ハザード比）は正しく取り出せるのか。よく使われる「見つけた調査の日を、起きた日とみなす」やり方では、どれだけずれるのか。

閉鎖の日が正確に分かっている F28 の法人データを、わざと「k 年おきの調査でしか見えない」形に粗くし、正確な日付で出した値（本当の値）と比べる。

## データ
- F28 と同じ。国税庁「法人番号公表サイト」全件データ（2026年9月30日更新）から、2015年11月1日以降に法人番号が指定された株式会社・合同会社・その他の設立登記法人 152.9万法人。法人名・法人番号・住所は使わず、公開もしていない。
- 開始＝法人番号の指定日、イベント＝登記の閉鎖（清算の結了等・登記官による閉鎖）8.4万件、打ち切り＝合併・本店移転・2026-09-30 時点で残っている法人（F28 と同じ定義）。

### 調査の作り方（粗くし方）
| 調査 | 内容 | 閉鎖した法人の区間の幅（中央値） |
|---|---|---|
| 1年おき・2年おき・3年おき・5年おき | 毎年9月30日を基準に k 年おき（最後は必ず 2026-09-30） | 13・25・37・61か月 |
| 1回だけ | 2026-09-30 に「まだあるか」だけ（current status データ） | 90か月 |
| 5年おき・3月末 | 調査日を3月31日にずらす（頑健性） | 60か月 |
| 設立から1年ごと・5年ごと | 法人ごとに設立日から数える（頑健性） | 12・60か月 |

閉鎖した法人は「最後に残っていた調査（なければ設立日）〜閉鎖を確かめた調査」の区間、合併などで消えた法人は「最後に残っていた調査」で右打ち切り。時間は月単位にした。

## 手法
| 種類 | 手法 |
|---|---|
| 本当の値 | 正確な閉鎖日の Kaplan–Meier（日単位） |
| 簡単な方法 | 区間の右端（見つけた調査の日）または中点を閉鎖日とみなして Kaplan–Meier |
| 仮定を置かない方法 | Turnbull 推定（区間打ち切りの非パラメトリック最尤推定、EM 法） |
| パラメトリック | ワイブル・対数ロジスティック・対数正規（区間打ち切りの尤度で最尤推定） |
| 比例ハザード | 基準ハザードを1年ごとの区分一定にした比例ハザードモデル（区間打ち切りの尤度）。種別（合同会社・その他の法人）と本店の場所（東京23区・政令市）。中点・右端で代入して「正確な日付」として推定したものと比べる |

評価は、0〜10年の各月の閉鎖割合の本当の値からのずれ（最大・平均、ポイント）と、1・3・5・10年後の閉鎖割合。

## 主な結果
本当の値：閉鎖した割合は 1年後 0.64%、3年後 2.96%、5年後 5.33%、10年後 10.57%。

| 調査 | 方法 | 5年後 | 10年後 | 最大のずれ |
|---|---|---|---|---|
| 5年おき | 右端で代入（見つけた日＝閉鎖日） | 3.54% | 14.56% | 4.0ポイント |
| 5年おき | 中点で代入 | 5.49% | 9.97% | 0.9 |
| 5年おき | Turnbull | 5.20% | 9.97% | 1.5 |
| 5年おき | 対数正規 | 5.43% | 10.68% | 0.14 |
| 1回だけ | 右端で代入 | 1.97% | 17.12% | 6.6 |
| 1回だけ | 中点で代入 | 7.23% | 8.89% | 2.9 |
| 1回だけ | Turnbull | 5.36% | 9.95% | 0.8 |
| 1回だけ | 対数正規 | 5.50% | 10.51% | 0.26 |

- 「見つけた調査の日を閉鎖日とみなす」と、閉鎖が遅く見え、曲線は前半で低く、後半で高くなる。間隔が開くほど悪くなり（最大のずれ 1年おき 1.0 → 5年おき 4.0 → 1回だけ 6.6ポイント）、5年後の閉鎖は5年おきで 3.5%（本当は 5.3%）。
- 中点で代入は3年おきまではずれ1ポイント未満だが、1回だけの調査では 2.9ポイントずれる。
- Turnbull 推定は、間隔を広げても0〜10年の曲線をおおむね取り戻す（最大のずれ 0.6〜1.5ポイント）。ずれの多くは区間の中で質量をどこに置くかが決まらないことによる階段で、1割の抽出を10回くり返しても最大のずれは 1.2〜1.7 と変わらなかった（抽出のばらつきではない）。
- 1回だけの調査（設立日がばらばらなので、経過年数ごとに「まだあるか」が分かる）でも、Turnbull の5年後は 5.36%。ただし1年後は 1.48%（本当は 0.64%）と高い。1年前後の経過年数を持つのは2025年以降に設立された法人だけで、その法人の1年目の閉鎖は他の年の設立より高い（2025年設立 0.97%、他の年 0.57〜0.68%）。2024年までの設立に絞ると、1回だけの調査では2年弱より短い経過年数の値は出せない。
- パラメトリック：対数正規はどの間隔でも最大のずれ 0.3ポイント以内。ワイブルと対数ロジスティックは10年後を 11.0〜11.3%（0.4〜0.7ポイント高い）と見積もる。分布の仮定で答えが変わる。
- ハザード比（比例ハザード）は間隔にほとんど左右されない。本当の値（正確な日付）は 合同会社 1.475、その他の法人 1.628、東京23区 1.571、政令市 1.111。区間打ち切りのままだと、5年おき 1.468・1.624・1.575・1.112、1回だけ 1.464・1.622・1.575・1.112。中点で代入もほぼ同じ。右端で代入だけがずれ、合同会社は 5年おき 1.578、1回だけ 1.648、その他の法人は 1.550・1.491。

## 言えないこと
1. 本物の「数年おきの調査」のデータではなく、正確な日付があるデータを粗くしたもの。本物の調査では、回答しない・調査の間に消えたかどうかを取り違える、といった誤差も加わる。
2. 区間打ち切りの方法は、「調査のタイミングが閉鎖の起きやすさと関係しない」ことを前提にしている。閉鎖しそうな法人ほど調査に答えない、といったことがあると成り立たない。
3. 1回だけの調査で曲線が取り戻せたのは、設立日がばらばらで、いろいろな経過年数の法人が同時に見えるから。さらに「設立の年によって閉鎖のしやすさが変わらない」ことを前提にしている。今回、1年目の値が高く出たのは、2025年以降に設立された法人の1年目の閉鎖が高いためで、その理由（直近の景気、手続きの変化など）はこのデータでは分からない（推測しない）。
4. ハザード比が間隔に左右されなかったのは、閉鎖が年1%前後とまれで、ハザード比が時間でそれほど変わらないこのデータの場合。イベントが多い、または比例ハザードが大きく崩れるデータでは同じとは限らない（F28 では合同会社のハザード比は期間で 1.2〜1.8 と変わる）。
5. 対数正規がよく合ったのはこのデータでの結果で、ほかのデータでも対数正規がよいとは言えない。
6. 「登記の閉鎖」は「事業をやめた」ではない（F28 と同じ）。
