# F35 景気の「山」と「谷」をデータだけで当てられるか？（マルコフ切り替えモデル）

看板記事 F35。景気動向指数（CI一致指数）の動きから、観測できない「景気の局面（拡張・後退）」をマルコフ切り替えモデルで推定し、内閣府の景気基準日付とどれだけ合うか、その時点までのデータだけで何か月後に後退のサインが出るかを調べた。

## 問い

- CI一致指数の動きだけから、景気の「拡張期」と「後退期」をどこまで当てられるか
- 推定した後退期の始まり・終わりは、公式の山・谷と何か月ずれるか
- その時点までに分かっていたデータだけで推定すると、山から何か月後に後退のサインが出るか

## データ

| データ | 中身 | 期間 |
|---|---|---|
| 内閣府「景気動向指数」CI一致指数（2020年=100） | 長期系列 *ci.xlsx（2026年10月公表）。F13 で取得したものを再利用 | 1985年1月〜2026年8月（月次） |
| 同 個別系列 鉱工業生産指数 | 一致系列 *ci2.xlsx。頑健性で使う | 1975年1月〜2026年8月 |
| 内閣府「景気基準日付」 | 第8循環の谷（1975年3月）〜第16循環の谷（2020年5月） | — |

- 後退期は「山の翌月〜谷」とした（1985年以降で7回、168か月）
- 2020年5月の谷のあとの山は、景気基準日付では設定されていない（2026年10月時点のページ）
- 使っているのは今の時点の改定後のデータで、当時実際に公表されていた値（速報値）ではない

## 手法

| ステップ | 中身 |
|---|---|
| 変換 | CI一致指数の3か月前比（対数差×100 ÷ 3、%/月）。前月比はぶれが大きいので頑健性に回した |
| 本体のモデル | マルコフ切り替えモデル（statsmodels の MarkovRegression）。3つの状態で平均が切り替わり、分散は共通。初期値を変えて5回×20通り推定し、対数尤度がいちばん高いものを使う |
| 後退期の確率 | 平均がマイナスの状態（後退・急落）にいる確率の合計。全期間のデータで推定した「平滑化」確率と、その月までの情報だけを使う「フィルタ」確率がある |
| 判定 | 確率が 0.5 を超え、3か月以上続いた区間を後退期とする |
| 公式との比較 | 月ごとの一致率、公式の後退期・拡張期をそれぞれ正しく判定した割合、山・谷とのずれ（月） |
| リアルタイムに近い形 | 1995年1月〜2026年8月の各月 t について、1985年〜t のデータだけで推定し直し、t の月のフィルタ確率を記録（380回）。確率が2か月続けて0.5を超えた月を「後退のサイン」、2か月続けて0.5を下回った月を「回復のサイン」とする |

## 主な結果

### 3つの状態

| 状態 | 平均（3か月前比、%/月） | とどまる確率 | 平均で続く月数 | その状態だった月数 |
|---|---|---|---|---|
| 急落 | −5.69 | 0.75 | 3.9 | 8（2008年11月〜2009年3月、2020年4〜6月） |
| 後退 | −0.73 | 0.90 | 9.9 | 116 |
| 拡張 | +0.43 | 0.97 | 33.8 | 373 |

- 2状態のモデルでは、リーマン・ショックとコロナの「急落」が1つの状態を占めてしまい、ふつうの後退を拾えなかった（下の頑健性）。3つめの状態として「急落」を分けると、ふつうの後退を後退として取り出せた

### 公式の景気基準日付との一致（1985年4月〜2026年8月、497か月）

- 一致率 90.5%。公式の後退期のうち 80.5% を後退、公式の拡張期のうち 93.9% を拡張と判定
- 7回の後退期のうち6回を見つけた。見つけられなかったのは1985年6月〜1986年11月（円高不況）で、確率は最高 0.38 だった

| 公式の山 | 公式の谷 | 推定の始まり | 推定の終わり | 始まりのずれ | 終わりのずれ |
|---|---|---|---|---|---|
| 1985年6月 | 1986年11月 | 見つからず | | | |
| 1991年2月 | 1993年10月 | 1991年2月 | 1993年12月 | −1 | +2 |
| 1997年5月 | 1999年1月 | 1997年9月 | 1998年11月 | +3 | −2 |
| 2000年11月 | 2002年1月 | 2001年1月 | 2002年1月 | +1 | 0 |
| 2008年2月 | 2009年3月 | 2007年12月 | 2009年4月 | −3 | +1 |
| 2012年3月 | 2012年11月 | 2012年5月 | 2012年11月 | +1 | 0 |
| 2018年10月 | 2020年5月 | 2018年7月 | 2020年6月 | −4 | +1 |

（ずれ＝推定 − 公式。始まりは「山の翌月」と比べた。マイナスは公式より早い）

- 公式にない後退期が3つ出た：2011年3〜5月（東日本大震災）、2014年4〜7月（消費増税のあと）、2021年7〜10月（部品不足などで生産が落ちた時期）。2024年1〜2月にも確率が 0.5 を超えたが、2か月なので後退期とは判定していない
- 2026年8月の後退期の確率は 0.01

### その時点までのデータだけで推定すると（1995年〜）

| 公式の山 | 後退のサインが出たデータの月 | 山からの月数 | 公式の谷 | 回復のサイン | 谷からの月数 |
|---|---|---|---|---|---|
| 1997年5月 | 1997年9月 | 4 | 1999年1月 | 1999年4月 | 3 |
| 2000年11月 | 2001年2月 | 3 | 2002年1月 | 2002年4月 | 3 |
| 2008年2月 | 2008年6月 | 4 | 2009年3月 | 2009年6月 | 3 |
| 2012年3月 | 2012年7月 | 4 | 2012年11月 | 2013年2月 | 3 |
| 2018年10月 | 2018年12月 | 2 | 2020年5月 | 2020年9月 | 4 |

- 後退のサインは山の2〜4か月後、回復のサインは谷の3〜4か月後のデータで出た。CI はデータの月からおおよそ2か月後に公表されるので、実際に分かるのはさらに約2か月あと
- 参考：2018年10月の山は、2020年7月30日の景気動向指数研究会で暫定設定された（山から約21か月後）
- その一方で、公式にない時期にサインが出たことが9回あった（1995年に2回、2003〜2005年に3回、2011年、2014年、2021年、2024年）。データが短い1990年代半ばと、景気の足踏みが続いた2000年代半ばに多い
- 1995〜2026年の一致率は 88.2%（後退期 87.8%、拡張期 88.2%）で、全期間のデータを使った推定（あと知恵）より拡張期の誤判定が増える

## 頑健性

| モデル | 一致率 | 公式の後退期を後退と判定 | 公式の拡張期を拡張と判定 | 見つからなかった後退期 | 公式にない後退期 |
|---|---|---|---|---|---|
| 本体（CI一致・3か月前比・3状態、平均だけ切り替わる） | 90.5% | 80.5% | 93.9% | 1 | 3 |
| 2状態（平均と分散が切り替わる） | 82.3% | 61.0% | 89.3% | 1 | 1 |
| 2状態（平均だけ切り替わる） | 76.5% | 5.7% | 99.7% | 5 | 0 |
| 3状態（平均と分散が切り替わる） | 84.3% | 89.4% | 82.6% | 0 | 4 |
| 前月比で3状態 | 76.2% | 3.3% | 100% | 6 | 0 |
| コロナ期を除く（〜2019年12月）2状態 | 87.3% | 76.3% | 91.6% | 1 | 2 |
| コロナ期を除く（〜2019年12月）3状態 | 90.9% | 85.6% | 93.0% | 0 | 2 |
| 鉱工業生産・3状態（1985年〜） | 75.8% | 4.9% | 98.9% | 5 | 1 |
| 鉱工業生産・2状態（1985年〜、平均と分散） | 75.4% | 24.4% | 92.0% | 3 | 3 |
| 鉱工業生産・3状態（1975年〜） | 73.1% | 3.6% | 99.1% | 7 | 1 |

- 2状態で平均だけ切り替わるモデルは、「急落」だけを1つの状態にしてしまい、ふつうの後退はほとんど拾えない
- 前月比と鉱工業生産では、対数尤度がいちばん高い解が「急落・ふつう・急な戻り」の3つになり、後退と拡張を分けられなかった。CI一致指数は複数の系列を合成していてぶれが小さいので、局面を分けやすい
- コロナ期を除いても、3状態モデルの一致は変わらない（90.9%）。2状態でも、コロナを除けば一致率が82%から87%に上がる
- 分散も切り替わる3状態は、7回すべてを見つけたが、2008年と2018年の後退の終わりが1年以上遅れ、拡張期の誤判定も増えた
- 各モデルの山・谷とのずれは `results/turning_points_variants.csv`

## 再現手順

```bash
pip install -r requirements.txt
cd src
python 01_取得.py          # 同梱データを使う（取り直すときは --download）
python 02_整形.py          # 3か月前比などを作る → data/monthly.csv
python 03_分析.py          # 本体と比べるモデル（数分）
python 03b_リアルタイム.py # その時点までのデータで380回推定し直す（20分前後）
python 04_図.py
```

乱数の種は 42 から始めて固定し、BLAS のスレッド数を1にしている（同じ結果を出すため）。リアルタイムの推定は前の月の推定値を初期値に使う（毎年1月だけ乱数の初期値も試す）ので、途中から再開すると結果がわずかに変わることがある。

## 言えないこと

- 公式の景気基準日付は、ヒストリカルDI（複数の系列の山谷）と専門家の検討で決まる。ここでの推定とは方法が違い、「当たった・外れた」は同じ物差しでの比較ではない
- 確率が高い＝必ず後退、ではない。震災や消費増税のような一時的な落ち込みでも確率は上がる
- リアルタイムに近い推定でも、使っているのは改定後のデータ。当時の速報値では、サインの出方は変わりうる
- 状態の数や後退期の判定のルール（0.5、3か月）は自分で決めたもの。変えれば、ずれの月数も変わる
- 景気の局面を当てても、その理由（何が景気を動かしたか）は分からない
