# F95 新幹線の効果は、隣の県にもこぼれたのか？（空間的な波及を入れた差の差・F29 との比較）

看板記事 F95。F29 では、2015年3月の北陸新幹線（長野―金沢）開業で石川県の日本人の延べ宿泊者数が「開業がなかった場合」より約12%多かったと推定した。今回は、その効果が新幹線の駅のない隣の県（福井・岐阜）にこぼれたのか、それとも隣から客を奪ったのかを、F29 と同じ合成コントロール系の手法（SCM・Synthetic DID・Augmented SCM）と、隣・隣の隣を分けて入れた二元固定効果の差の差で確かめた。あわせて、F29 の対照に入っていた岐阜を外すと、F29 の直接効果が変わるかも見た。

## 問い

- 北陸新幹線の開業のあと、隣の県（福井・岐阜）の宿泊客は「開業がなかった場合」と比べて増えたか、減ったか
- 効果は距離とともに小さくなっているか（隣 → 隣の隣 → 遠い県）
- F29 の対照に隣の県（岐阜）が入っていたことで、F29 の石川の推定値はずれていたか

## データ

| データ | 内容 |
|---|---|
| 観光庁「宿泊旅行統計調査」推移表 | 都道府県×月の延べ宿泊者数（総数・日本人・外国人）、2011年1月〜2025年12月の確定値。F29（＝F04）と同じ表（`data/raw/lodging_pref_monthly_2011_2025.csv`） |
| 県の隣接と県庁所在地の座標 | F33 で国土数値情報（行政区域）から作った、県境を共有するかの表（`pairs.csv`）と県庁所在地の経度・緯度（`pref_points.csv`） |

県のグループ（`figures/f01_groups.png`）：

| グループ | 県 | 扱い |
|---|---|---|
| 処置 | 石川・富山 | 2015年3月に北陸新幹線の駅ができた（F29 と同じ） |
| 隣・駅なし（主な「隣」） | 福井・岐阜 | 石川・富山と県境を接し、2015年には北陸新幹線の駅がない |
| 隣・駅あり | 新潟・長野 | 県境を接するが、自県にも北陸新幹線の駅がある（上越妙高・糸魚川・飯山）。直接の効果と波及が混ざるので分けて見る |
| 隣の隣 | 三重・京都・埼玉・山形・山梨・愛知・滋賀・群馬・静岡 | 上の4県と県境を接する県 |
| 対照（32県） | 残りの県 | F29 の33県から岐阜を外したもの |
| 除外 | 北海道・青森／福岡・佐賀・熊本・鹿児島／岩手・宮城・福島 | 別の新幹線の開業、東日本大震災（F29 と同じ理由） |

- 期間：事前 2012年1月〜2015年2月、事後 2015年3月〜2019年12月（コロナ前まで）。F29 と同じ
- 季節：県ごとに対数をとり、事前期間の同じ月の平均を引いた（F29 と同じ）
- 距離：石川・富山の県庁所在地のうち近い方からの大圏距離

## 手法

| 手法 | 内容 | コード |
|---|---|---|
| 隣の県ごとの合成コントロール | 福井・岐阜・新潟・長野を1県ずつ「処置」とみなし、対照32県から SCM・SDID・ASCM・単純な差の差で推定（関数は F29 の `common.py` をそのまま使う） | `03_分析.py` |
| プラセボ（場所） | 対照32県を1つずつ「処置」とみなし、残り31県で推定した値の分布。その標準偏差で95%区間、絶対値の順位で p 値 | `placebo()` |
| まとめた推定 | 福井＋岐阜をまとめた SDID。区間は対照から2県をランダムに選んで「処置」とみなす60回のプラセボ | `pooled_ci()` |
| 二元固定効果の差の差 | 県と月の固定効果、処置×事後・隣×事後・隣の隣×事後を同時に入れた回帰（県でクラスタした標準誤差）。距離帯（0–150km・150–250km・250–400km、基準は400km超）版も | `twfe()` |
| F29 との比較 | 石川・富山の直接効果を、F29 の対照（岐阜を含む33県）・隣を外した32県・隣の隣も外した23県で推定し直す | `03_分析.py` |

乱数は `SEED = 20150314` で固定。

## 主な結果

### 1. 隣の県へのこぼれは見えなかった（点推定はむしろ少しマイナス）

| 県 | SDID | SCM | 95%区間（SDID、プラセボ） | プラセボの順位 |
|---|---|---|---|---|
| 石川（直接、隣を外した対照） | **+11.6%** | +11.9% | −3.7〜+29.3% | 6/33 |
| 富山（直接） | +0.2% | −0.9% | −13.6〜+16.1% | 32/33 |
| 福井（隣・駅なし） | −1.4% | +1.0% | −14.9〜+14.3% | 29/33 |
| 岐阜（隣・駅なし） | −4.7% | −6.5% | −17.8〜+10.4% | 17/33 |
| 福井＋岐阜 | **−3.2%** | — | −13.4〜+8.3% | — |
| 新潟（隣・駅あり） | −0.9% | +1.3% | −14.5〜+14.9% | 30/33 |
| 長野（隣・駅あり） | −2.9% | −5.0% | −16.2〜+12.6% | 25/33 |

- 福井・岐阜とも、開業後の宿泊客は合成した対照とほぼ同じで、対照の県を「処置」とみなしたときのぶれ（±15%前後）の中に収まった（`f02`・`f03`）
- 年ごとに見ると、福井＋岐阜は2015年 +3.3%、2016年 −3.2%、2017年 −7.4%、2018年 −2.8%、2019年 −4.4%（`results/effect_by_year.csv`）。開業の年だけ少しプラス、その後は少しマイナスだが、どの年もプラセボのぶれより小さい
- 「客を奪った」とも「こぼれた」とも言える大きさではない

### 2. 距離による減衰は見えない

- 二元固定効果の回帰（対照は隣の隣も外した23県）：隣・駅なし −1.2%（−9.0〜+7.3%）、隣の隣 −1.9%（−6.7〜+3.1%）
- 距離帯：0–150km −1.2%、150–250km −0.6%、250–400km −1.0%（いずれも区間は0をまたぐ）
- 隣・駅あり（新潟・長野）だけは回帰で −5.8%（−10.7〜−0.6%、p=0.03）と出たが、SDID・SCM では −1〜−5% でプラセボの順位は25〜30/33。手法で答えが変わるので、ここから「新潟・長野は客を奪われた」とは言えない
- なお、この回帰では処置（石川＋富山の平均）が +2.0% と、SDID の石川単独（+11.6%）より小さい。石川と富山をまとめていること、対照を単純な平均で扱うことによる（F29 の単純な差の差と同じ傾向）

### 3. F29 の直接効果は、岐阜を対照から外してもほぼ同じ

| 石川の推定 | SCM | SDID |
|---|---|---|
| F29 の対照（岐阜を含む33県） | +11.9% | +13.2% |
| 隣を外した対照（32県） | +11.9% | +11.6% |
| 隣の隣も外した対照（23県） | +10.4% | +9.1% |

岐阜の波及が小さいので、F29 の対照に岐阜が入っていても結論はほとんど変わらない。隣の隣まで外すと対照が23県に減り、推定値は約2〜4ポイント下がる。

## 頑健性

福井＋岐阜（または別の定義の「隣」）をまとめた SDID（`results/robustness.csv`、`f05`）：

| 種類 | 設定 | 推定値 | 95%区間 |
|---|---|---|---|
| 基本 | 福井＋岐阜 | −3.2% | −13.4〜+8.3% |
| 隣の定義 | 福井だけ／岐阜だけ | −1.4%／−4.7% | いずれも0をまたぐ |
| 隣の定義 | 県境を接する4県（新潟・長野を含む） | −2.6% | −10.1〜+5.6% |
| 隣の定義 | 距離160km以内（山梨・岐阜・愛知・福井） | −1.8% | −9.4〜+6.5% |
| 隣の定義 | 中部地方（福井・山梨・岐阜・静岡・愛知） | −1.8% | −9.1〜+6.1% |
| 隣の定義 | 隣の隣（9県） | −2.3% | −6.8〜+2.6% |
| 期間 | 事後を開業1年目まで／2017年末まで | +0.9%／−3.3% | 0をまたぐ |
| 期間 | 事前を2013年1月から | −2.9% | −12.2〜+7.3% |
| 対照 | 隣の隣も外す（23県） | −4.2% | −14.2〜+7.0% |
| 対照 | 大都市圏8都府県を外す | −1.5% | −12.6〜+11.0% |
| 系列 | 総数（日本人＋外国人）／外国人 | −3.3%／−9.7% | 0をまたぐ（外国人は幅が広い） |
| 時点のプラセボ | 開業を2013年9月とみなす | −0.5% | −8.9〜+8.6% |

どの設定でも −5〜+1% の範囲で、区間は0をまたぐ。回帰でも隣の定義（福井＋岐阜／160km以内／中部）を変えて −1.2%／+0.3%／−0.6%。

## 言えないこと

- 「波及がなかった」とは言えない。言えるのは「プラセボのぶれ（±15%前後）より大きな波及は見えなかった」まで。福井＋岐阜で ±10% 程度の効果があっても、このデータでは見分けられない
- 県単位の集計なので、県の中の動き（例：金沢に近い県内の温泉地は増え、遠い地域は減った）は打ち消し合って見えない。市町村や宿泊施設の単位なら答えが変わる可能性がある
- 延べ宿泊者数は「泊まった人」の数で、日帰りの観光客や消費額は入っていない。新幹線で日帰りが増えて宿泊が減る、という動きも県の宿泊の数字には混ざる
- 新潟・長野は自県にも駅ができたので、波及と直接の効果を分けられない。回帰だけで出たマイナスは手法に依存する
- 2015年以降には訪日客の急増、北陸の観光キャンペーン、2016年の熊本地震などが重なる。対照の重みでならしているが、隣の県だけに効いた別の出来事は取り除けない
- 福井には2024年3月に北陸新幹線が延伸したが、今回はコロナ前（〜2019年）までなので扱っていない
