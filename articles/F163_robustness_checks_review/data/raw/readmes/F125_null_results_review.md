# F125 100本を超えた看板記事で、「見えなかった」はどれくらいあったか？（結論の振り返り）

看板記事シリーズは、結果が弱いときも「差は見えなかった」「言い切れない」とそのまま書く方針で続けてきました。F01〜F120（いまある118本）の結論を1本ずつ読み直し、「見えなかった」「言い切れない」がどれくらいあったのか、どんな記事に多かったのかを数えます。

## 問い

- 118本のうち、結論が「差・関係は見えなかった」または「手法・前提しだいで言い切れない」だった記事は何本か
- それは記事の種類（効果の推定・予測・記述）や手法、データの単位（47都道府県か、1,700市区町村か など）と関係していたか
- 「見えなかった」記事は、どれだけの大きさなら見つけられたか（検出力）を書いていたか

## データ

| データ | 中身 |
|---|---|
| 各記事の README（`articles/F01〜F120/README.md`） | 問い・手法・主な結果・頑健性・言えないこと。`src/01_取得.py` で `data/raw/readmes/` に集める（元の README は各記事フォルダにあるので、ここには入れていない） |
| 各記事の note のタイトル | 結論を1文で書いたもの（`data/coding_manual.csv` の判定の根拠） |
| F122 の手法の系統 | `data/raw/article_family_F122.csv`（因果推論・時系列・空間など10系統） |

新しい公的データは使っていません。F24・F30 はまだないので118本です。

## 手法

| 項目 | 内容 |
|---|---|
| 記事の種類（手作業） | 効果・関係の推定（39本）／予測（24本）／記述・測定・作法（55本） |
| 結論の判定（手作業） | **見えなかった**（区間が0をまたぐ、差は消えた、偶然と区別できない）／**言い切れない**（手法・前提・扱い方で答えが大きく動く、識別できない）／**はっきりした答え**。判定と一言の理由は `data/coding_manual.csv` |
| データの単位 | 効果の39本は手で確認（都道府県・市区町村・法人や地点・全国の時系列・その他）。ほかは README のキーワード |
| 検出力への言及 | README に「検出力」「最小検出」「見つけられる大きさ」があるか |
| 検定 | 単位が大きい（市区町村・法人など）か否かと結論の 2×2 表に Fisher の正確検定 |

## 主な結果

- **118本のうち42本（36%）**が「見えなかった」（15本・13%）か「言い切れない」（27本・23%）でした。
- **効果・関係の推定（39本）では23本（59%）**。見えなかった13本、言い切れない10本で、はっきりした答えは16本でした。予測は25%（6/24本）、記述・測定・作法は24%（13/55本、すべて「言い切れない」）。
- 手法の系統では **因果推論が64%（16/25本）** で最も多く、生存・人口（18%）やベイズ・階層（25%）は少なめでした。
- **データの単位が大きいほど「見えた」わけではありません。** 効果の39本で、都道府県 67%（6/9）、市区町村 70%（7/10）、全国の時系列 58%（7/12）、法人など1万以上 0%（0/3）。市区町村・法人の13本と、それ以外の26本の差は Fisher の検定で p=0.74（オッズ比0.73）でした。単位の数が増えても、比べる「差」（処置の違い）が小さければ見分けられない、という F26・F121 の結果と同じ向きです。
- **「見えなかった」13本のうち、検出力（どれだけの大きさなら見つけられたか）を書いていたのは3本（23%）だけ**でした（F01・F89・F101）。残りの10本は「差は見えなかった」と書きながら、「この設計で見つけられるのはどの大きさからか」を示していません。
- 番号の後半ほど割合が上がりました（F01〜F60 は31%、F61〜F120 は40%）。後半は前提を変えた比較や「同じ問いを手法を変えて」の記事が増えたためと考えられます（推測）。

## 頑健性チェック（results/robustness.csv）

| チェック | 全体の割合 | 効果・関係の推定の割合 |
|---|---|---|
| 基本（手作業の判定） | 36% | 59% |
| README の結果欄のキーワードだけで判定 | 27% | 38% |
| 厳しい定義（「見えなかった」だけ） | 13% | 33% |
| F01〜F60 だけ | 31% | 55% |
| F61〜F120 だけ | 40% | 65% |
| まとめ直し（F118〜F120）と「統計の作法」を除く | 37% | 59% |
| 効果の記事から1本ずつ外す（39通り） | — | 58〜61% |

- どのチェックでも「効果の推定では3〜6割が見えなかった／言い切れなかった」「予測・記述より効果の推定で多い」は変わりません。
- キーワードだけの判定は手作業と63%しか一致せず（κ=0.14）、README の書き方では自動で数えられないことが分かりました。割合の水準は判定の基準しだいで動くので、本文は「おおよそ3分の1」「効果の推定ではおよそ半分以上」と書きます。
- 厳しい定義にしても、データの単位との関係は見えません（オッズ比1.41、p=0.72）。

## 言えないこと

- 判定は筆者が1人で手作業で行ったものです。別の人が判定すれば、特に「言い切れない」の境目は動きます（キーワード判定との一致は63%）。
- 「見えなかった」が多いことは、手法やデータが悪いことを意味しません。公表された集計値だけで、47都道府県や数年の差を比べる設計では、小さな効果は原理的に見分けられません。
- 記事の選び方（どの問いを取り上げたか）自体が結果に影響しています。たとえば因果推論の記事は「効いたのか？」を問うので、見えなかった場合も記事になります。
- データの単位は大まかな分類で、実際に比べた「差の大きさ」（処置の変動）までは数えていません。
