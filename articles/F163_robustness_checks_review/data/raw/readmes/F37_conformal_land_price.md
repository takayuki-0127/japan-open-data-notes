# F37 地価の予測に「この範囲に9割入る」を付ける（コンフォーマル予測）

看板記事 F37。F03（地価を機械学習で読む）の LightGBM に、コンフォーマル予測で予測区間を付け、**本当に目標どおりの割合が区間に入るか**を、データの分け方を変えて確かめました。

## 問い

- 地価公示2.6万地点の価格予測に「90%区間」を付けると、まだ見ていない地点の9割が本当に区間に入るか
- 「ランダムに分けた検証」と「場所で分けた検証」で、当たり方は変わるか。崩れるなら、どう直せばよいか
- 用途（住宅・商業）や地域で、当たり方に偏りはあるか

## データ

F03 と同じ `data/features.csv`（地価公示 2026年 25,565地点、30の特徴量）。元データと加工の方法は `data/raw/SOURCES_F03.md` と F03 の README を参照。

## 手法

| 段階 | やり方 |
|---|---|
| 予測モデル | LightGBM（F03 と同じ特徴量。計算を軽くするため木の数を400本・学習率0.08に変更。対数価格を予測） |
| まだ見ていない地点を作る（外側の検証） | ①ランダム5分割　②20km 四方のブロック5分割（同じブロックの地点は同じ側） |
| 区間の作り方 | 学習側をさらに「学習用75%」と「較正用25%」に分け、較正用の外れ方から区間の幅を決める |
| ①分割コンフォーマル | 較正用の \|実際−予測\| の分位点 q で「予測 ± q」。幅は全地点で同じ |
| ②正規化コンフォーマル | 較正用の半分で「外れの大きさ」を別の LightGBM で学習し、残り半分で較正。幅が地点ごとに変わる |
| ③CQR | 分位点回帰の LightGBM（5%点・95%点）で区間を作り、較正用で広げ方を補正（目標90%のみ） |
| 較正用の取り方 | ランダム／20km ブロック単位 |

分位点は有限標本の補正つき（⌈(n+1)(1−α)⌉/n）。区間の幅は「上限÷下限（倍）」で表します。

## 主な結果

**90%区間に入った割合（25,565地点）**

| 外側の検証 | 較正用の取り方 | 分割 | 正規化 | CQR | 幅の中央値（分割） |
|---|---|---|---|---|---|
| ランダム | ランダム | 89.8% | 90.0% | 90.1% | 2.36倍 |
| 場所（20km ブロック） | ランダム | **82.0%** | 82.3% | 84.6% | 2.28倍 |
| 場所（20km ブロック） | 場所（ブロック） | **91.0%** | 86.6% | 90.7% | 3.05倍 |

- ランダムに分けた検証では、3つの手法とも目標どおり（80・90・95%すべて）
- 場所で分けると、較正をランダムにしたままでは90%区間に82%しか入らない（80%区間は68.5%）。予測の外れ方が「近くの地点を知っているとき」より大きくなるのに、幅が「近くを知っているとき」の外れ方で決まっているため
- 較正用もブロック単位で取ると、分割は91.0%、CQR は90.7%に戻る。代わりに区間は広がる（分割：2.28倍→3.05倍）
- 正規化コンフォーマルは、場所で分けると86.6%と足りなかった（較正に使える点が半分になるうえ、「外れの大きさ」のモデル自体が見ていない場所で外れるため）
- 予測の当たり方そのもの（中央値の外れ）は、ランダム 14.8%、場所で分ける 19〜20%（F03 は 13.7%／18.7%。木を減らした分だけ少し悪い）

**用途・地域別（場所で分ける／較正も場所で、90%区間）**

| | 分割 | 正規化 | CQR |
|---|---|---|---|
| 住宅地 | 92.1% | 86.4% | 91.4% |
| 商業地 | 88.2% | 87.5% | 88.7% |
| 三大都市圏（中心から50km以内） | 92.9% | 88.0% | 90.5% |
| それ以外 | 89.2% | 85.3% | 90.9% |
| 北海道・東北 | 84.2% | 82.4% | 88.3% |
| 九州・沖縄 | 86.4% | 85.2% | 89.3% |
| 関東 | 93.3% | 88.6% | 91.7% |
| 中部 | 94.4% | 87.3% | 92.7% |

- 全体で9割入っても、地域ごとには84〜94%とばらつく（コンフォーマル予測が保証するのは「全体での」割合）
- 予測価格の5分位で見ると、分割は安い地点87.1%・中間93.8%・高い地点88.7%、CQR は 91.0%・92.7%・87.3%。CQR のほうが価格帯による偏りが小さい
- 分割で外れた地点は、上に外れた 5.3%・下に外れた 3.7%（予測より高い地点を取りこぼしやすい）

## 頑健性

目標90%、場所で分ける／較正も場所で（分割／正規化）

| 設定 | 分割 | 正規化 |
|---|---|---|
| 基本（較正用25%） | 91.0% | 86.6% |
| 較正用10% | 88.4% | 84.4% |
| 較正用40% | 90.5% | 87.3% |
| データを無作為に半分（場所で分ける） | 90.5% | 86.6% |
| データを無作為に半分（ランダム） | 89.7% | 88.8% |

- 目標を80・95%にしても、ランダムと「較正も場所で」の分割はほぼ目標どおり（80.8%・95.4%）。「較正はランダム」は 68.5%・90.0% と足りない
- **年をまたぐと崩れる**：2016年の価格で学習・較正した90%区間に、同じ地点の2026年の価格は70.9%しか入らなかった（2016年の価格なら89.7%）。全国の中央値の変化（+6.9%）だけずらしても73.0%。10年の間に地域ごとの値動きが違ったため

## 言えないこと

1. 「9割入る」は、検証に使ったデータと同じ仕組みで新しいデータが生まれるという前提つき。年が変わると大きく崩れた（上の2016→2026年）
2. 保証されるのは全体での割合で、地域や価格帯ごとの割合ではない
3. 区間は「この地点の価格がこの範囲にある」確率であって、将来の値上がり・値下がりの予測ではない
4. 地価公示の地点は、全国の土地を無作為に選んだものではない（地点の選び方の偏りは残る）
