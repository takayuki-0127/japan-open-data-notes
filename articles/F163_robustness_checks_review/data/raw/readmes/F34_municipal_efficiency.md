# F34 同じお金で、どの市町村が多くのサービスを出しているか？（DEA と SFA）

看板記事 F34。1,740市区町村の歳出（入力）と、人口・高齢者・子ども・保育所・面積などの「行政サービスが必要な量」（出力）を比べ、効率性を2つの手法（包絡分析法 DEA と確率的フロンティア SFA）で測った。どの町が効率的かという順位を出すことではなく、「効率の測り方で答えがどれだけ変わるか」を見ることが目的。町ごとの順位表は公開しない。

## 問い

- 同じ人口規模の中で、同じ量のサービス需要に、どれだけ少ない歳出で対応しているか
- DEA と SFA で、効率の高い町・低い町は同じになるか
- 効率は人口密度・高齢化・財政の条件とどう関係するか

## データ

| 使ったもの | 項目（年） | 出所 |
|---|---|---|
| 入力 | 歳出決算総額 − 災害復旧費（2022年度）、一般行政部門職員数（2024年） | 統計センター「SSDSE-A-2026」 |
| 出力 | 総人口・65歳以上人口・15歳未満人口（2020年）、可住地面積（2024年）、小中・義務教育学校の児童生徒数（2024年）、保育所等数（2023年）、図書館数・公民館数（2021年） | 同上 |
| 2段階目 | 可住地人口密度、高齢化率、経常収支比率（2022年度）、財政力指数（2020年度） | 同上、財政力指数は e-Stat 社会・人口統計体系 |
| 年を変えた頑健性 | 歳出決算総額（2015年度）、総人口・65歳以上・15歳未満（2015年）、可住地面積 | e-Stat 社会・人口統計体系（市区町村データ） |

- 単位は市町村と東京23区（政令市は市全体）。2020年の人口が0の町（1町）を除く1,740団体
- 項目の年は少しずつずれている（SSDSE-A の収録年のまま）

## 手法

- **人口規模で5グループ**に分けた（1万人未満 530／1万〜3万人 446／3万〜10万人 481／10万〜30万人 197／30万人以上 86）。DEA はグループごとにフロンティアを作る
- **DEA**（入力指向）：入力1つ（歳出）・出力5つ（総人口・65歳以上・児童生徒数・保育所等数・可住地面積）。規模に関して収穫一定の CCR と可変の BCC。外れ値の確認にスーパー効率 DEA（自分を参照集合から外す）。scipy の linprog（HiGHS）で自作
- **SFA**（費用フロンティア）：ln 歳出 ＝ 定数 ＋ Σ ln 出力 ＋ (ln 人口)²/2 ＋ v ＋ u、v は正規、u は半正規（u ≥ 0 が非効率）。最尤法で自作し、効率は E[exp(−u)|ε]（Battese–Coelli）。全体で1本
- **比べ方**：DEA はグループごとにフロンティアが違うので、効率値をグループの間で比べない。手法の比較は「グループ内のパーセント順位」で行った
- **2段階目**：効率×100 を、人口密度（対数）・高齢化率・財政力指数・経常収支比率（どれも1標準偏差あたり）と規模グループのダミーで回帰（HC1）。財政力指数のない東京23区は除く

## 主な結果

- 1人あたり歳出（中央値）：1万人未満 127万円、1万〜3万人 66万円、3万〜10万人 50万円、10万〜30万人 44万円、30万人以上 46万円。人口10万〜30万人がいちばん小さい U 字
- SFA の OLS 残差の歪度は +1.67（費用の上振れ＝非効率がある形）。λ＝σu/σv＝3.03、σu＝0.33
- DEA（BCC）の効率の中央値：1万人未満 0.66 → 30万人以上 0.94。ただし大きなグループほど団体数が少なく、フロンティア上に乗る割合が高くなる（30万人以上 31%、1万人未満 8%）。グループ間の差は「効率の差」とは読めない
- SFA の効率の中央値は 0.80〜0.86 で、規模による差は小さい
- **2つの手法の一致**：グループ内の順位の相関は 0.62〜0.77（全体 0.71）。DEA で上位25%の町のうち、SFA でも上位25%は 59%。下位25%どうしは 69%
- **地理条件（2段階目）**：DEA（BCC）は人口密度 +1標準偏差で +2.6ポイント（95%区間 +1.0〜+4.1）。SFA では −0.9（−2.2〜+0.5）とはっきりしない。SFA は図で見ると、いちばん密な市区で効率が下がる山形。高齢化率・財政力指数・経常収支比率はどちらの手法でも区間が0をまたぐ（DEA の CCR だけ財政力指数が +2.6）
- 東京23区は DEA（23区を含む規模グループ）では中央値 0.88、SFA では 0.60 と、手法で評価が大きく分かれる

## 頑健性（基本の DEA とのグループ内順位の相関）

| 変えたこと | 相関 | 基本の上位25%が残る割合 |
|---|---|---|
| 出力を需要だけ（人口・65歳以上・15歳未満・面積） | 0.90 | 84% |
| 図書館・公民館を足す | 0.89 | 79% |
| 入力を職員数に | 0.54 | 54% |
| 入力を歳出と職員数の2つに | 0.89 | 82% |
| 災害復旧費を含む歳出 | 0.99 | 98% |
| スーパー効率の上位5%を除いてフロンティアを作り直す | 0.96 | 92% |
| 東京23区を除く | 1.00 | 100% |
| SFA：出力を需要だけ（基本の SFA との相関） | 0.97 | — |
| SFA：規模グループのダミーを入れる（同） | 0.99 | — |
| 2015年度と2022年度（同じ形の DEA どうし、規模グループが変わらない1,684団体） | 0.76 | 71% |

出力の選び方や外れ値ではあまり動かないが、入力を「お金」から「人」に変えると順位は大きく入れ替わる。年が変わると4分の1ほど入れ替わる。

## 言えないこと

- サービスの「質」（待機児童の少なさ、道路の状態、窓口の待ち時間など）は入っていない。効率が低い＝無駄、ではない
- 面積が広い・人が散らばって住む・島がある・豪雪など、出力に入れていない条件で費用がかかる町は、効率が低く出やすい
- 歳出には、国や県の事業を受けて行う分や、年によってぶれる大きな建設事業も含まれる
- 特定の市町村を評価する意図はない。このため町ごとの効率値・順位は GitHub に置かず、`src/03_分析.py` を動かした人の手元にだけ作られる（`results/_eff_by_municipality.csv`）
