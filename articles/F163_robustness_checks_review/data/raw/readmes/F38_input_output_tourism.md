# F38　観光客が1兆円使うと、日本全体の生産はいくら増えるか？（産業連関分析）

看板記事 F38。自治体やイベントでよく見る「経済効果」の数字を、産業連関表から自分で計算し直した。訪日外国人の消費1兆円（2025年の費目の構成）が、宿泊・飲食だけでなく、食料品・商業・事業所向けサービスなどの生産をどれだけ増やすか、雇用は何人分か、そして前提の置き方で数字がどれだけ変わるかを示す。

## 問い

- 訪日客が日本で1兆円使うと、日本全体の生産・付加価値・雇用はどれだけ増えるか
- 同じ1兆円でも、宿泊・飲食・買物のどれに使うかで波及は違うか
- 「経済効果」の数字は、前提（輸入の扱い・2次波及・マージン）でどれだけ変わるか

## データ

| データ | 内容 |
|---|---|
| 総務省ほか「令和2年（2020年）産業連関表」 | 取引基本表（生産者価格評価・購入者価格評価、統合中分類108部門）、雇用表（統合中分類） |
| 同「平成27年（2015年）産業連関表」 | 取引基本表（生産者価格評価、統合中分類107部門）。頑健性の確認に使用 |
| 観光庁「インバウンド消費動向調査」2025年暦年【確報】 | 参考2：費目別1人1回当たり旅行消費単価（全国籍・地域、パッケージツアー参加費の内訳を含む） |

## 手法

| ステップ | 内容 |
|---|---|
| 1. 費目を部門に対応させる | 39の小費目を108部門に対応（`data/mapping_item_to_sector.csv`）。例：宿泊費→宿泊業、新幹線・鉄道→鉄道輸送、菓子類→食料品、化粧品→化学最終製品 |
| 2. 買物代を生産者価格に直す | 家計消費の「生産者価格÷購入者価格」で、品物の部分と商業マージン・貨物運賃に分ける（2020年表の購入者価格評価表から） |
| 3. 輸入に漏れる分を除く | 競争輸入型：国内需要に占める輸入の割合（輸入係数）の分は国内の生産にならない |
| 4. 1次波及 | 逆行列 [I − (I − M)A]⁻¹ で、原材料・サービスの取引の連鎖を計算 |
| 5. 2次波及 | 1次までで増えた雇用者所得 × 消費転換係数0.6 を、家計消費の構成（帰属家賃を除く）で配分して、もう一度逆行列にかける |
| 6. 粗付加価値・雇用 | 部門別の粗付加価値率、従業者数÷国内生産額（2020年の雇用表）をかける |

## 主な結果（2020年表、1兆円あたり）

| 項目 | 値 |
|---|---|
| 国内の直接の需要（直接効果） | 0.93兆円（輸入に0.07兆円。うち商業マージン0.14兆円） |
| 1次波及 | +0.76兆円 |
| 2次波及 | +0.45兆円 |
| 生産の増加（合計） | **2.13兆円（波及倍率2.13倍、1次までなら1.69倍）** |
| 粗付加価値（GDPにあたる部分） | 1.08兆円 |
| 雇用 | 約21.5万人分（1次までなら17.9万人分）。6割が飲食・宿泊・商業 |

費目ごとに1兆円使った場合の倍率（2次まで）は、飲食2.44・宿泊2.35・交通1.94・娯楽等1.88・買物1.71。買物は輸入品とマージンの分、国内に残る直接の需要が0.81兆円にとどまる。

## 頑健性（波及倍率）

| 設定 | 倍率 |
|---|---|
| 基本 | 2.13 |
| 2次波及を含めない | 1.69 |
| 消費転換係数0.5／0.7 | 2.06／2.21 |
| 費目の対応を別案に | 2.13 |
| 買物代のマージンを分けない | 2.05 |
| 2015年表 | 1.94 |
| 輸入を考えない（閉鎖型） | 2.68 |
| 輸入を考えない＋マージンを分けない | 2.77 |

前提の置き方で、同じ1兆円の「経済効果」は1.7〜2.8倍まで変わる。とくに輸入を考えないと大きく出る。

## 言えないこと

1. 波及効果は「供給に制約がない」前提の計算。人手不足の宿泊・飲食では、需要が増えても同じだけ生産が増えるとは限らない
2. 訪日客の消費が、ほかの消費（国内客など）を押しのけた分は差し引いていない。「純増」ではない
3. 2020年表はコロナの年で、宿泊業の国内生産額が2015年表の5.1兆円から3.2兆円に落ちている。投入の構造や雇用係数（従業者÷生産額）がふだんと違う可能性がある（2015年表では倍率1.94）
4. 雇用は「人分」で、新しく雇われる人数ではない。今いる人の労働時間が増えるだけのこともある
5. 費目と部門の対応、消費転換係数（0.6）は筆者が置いた前提
