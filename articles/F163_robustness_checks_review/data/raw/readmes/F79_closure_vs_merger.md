# F79 会社の終わり方は「閉鎖」か「合併」か？ 競合リスクの生存分析

看板記事 F79。note：「会社の終わり方は「閉鎖」か「合併」か？…」（下書き）

## 問い
新しく設立された法人の登記がなくなるとき、それは「清算などによる閉鎖」なのか「合併による解散」なのか。2つの結末を同時に扱う（競合リスク）と、閉鎖しやすさ・合併しやすさは法人の種類や本店の場所でどう違うか。合併を「打ち切り」として扱う普通の生存分析と比べて、数字はどれだけ変わるか。

## データ
- F28 と同じ。国税庁「法人番号公表サイト」全件データ（2026年9月30日更新）から、2015年11月1日以降に法人番号が指定された株式会社・合同会社・その他の設立登記法人（一般社団法人・NPO法人など）152.9万法人。
- 法人名・法人番号・住所は使わず、公開もしていない（`data/raw/` は種別・都道府県・市区町村コード・日付・閉鎖事由だけ）。

| 結末 | 定義 | 件数 |
|---|---|---|
| 閉鎖 | 登記記録の閉鎖のうち「清算の結了等」(01) と「登記官による閉鎖」(21) | 84,165 |
| 合併 | 「合併による解散」(11) | 11,441 |
| 打ち切り | 2026-09-30 時点で登記が残っている | 1,433,092 |

打ち切りは全員 2026-09-30 の管理上のもので、打ち切りの時刻は全員わかっている。

## 手法
| 段階 | 手法 |
|---|---|
| 累積発生 | Aalen–Johansen 法の累積発生関数（CIF）。閉鎖・合併を種別・本店の場所・地方ごとに |
| 無視したときの差 | 競合する結末を打ち切りとみなした 1−Kaplan–Meier と CIF の差 |
| 比較 | 原因別ハザード（cause-specific Cox）と Fine–Gray の部分分布ハザード（30万法人の無作為抽出）。打ち切りの時刻が全員わかっているので、Fine–Gray は「競合イベントが起きた法人を自分の打ち切り時刻までリスク集合に残す」Cox で厳密に推定できる |
| 確認 | 5年以上追える法人（78万）で「5年以内に閉鎖／合併したか」のロジスティック回帰 |
| 背景 | 全法人（古い法人も含む）の年別の清算・合併の件数 |

## 主な結果
- 10年後：株式会社は閉鎖 9.2%・合併 1.8%、合同会社は閉鎖 12.6%・合併 1.0%、一般社団・NPOなどは閉鎖 14.7%・合併 0.3%。登記がなくなった法人のうち合併は、株式会社で17%、合同会社で8%、一般社団・NPOなどで2%。
- 合併を打ち切りとみなした 1−KM は、閉鎖を 10.57%（CIF は 10.49%）と見積もる。差は 0.08ポイント。合併がいちばん多い東京23区の株式会社でも 0.17ポイント。合併がまれなので、競合リスクを無視しても閉鎖の数字はほとんど変わらない。
- 閉鎖しやすさ（Fine–Gray）：合同会社 1.50倍、一般社団・NPOなど 1.63倍、東京23区 1.59倍、政令市 1.11倍。原因別ハザードとほぼ同じ。
- 合併しやすさ（Fine–Gray）：合同会社 0.48倍、一般社団・NPOなど 0.19倍、東京23区 3.40倍（2.96–3.90）、政令市 1.45倍。閉鎖と合併で、合同会社の向きが逆になる。
- 5年以内の合併：東京23区 1.20%、政令市 0.63%、その他の市町村 0.43%。閉鎖を100としたときの合併は 16・13・10。
- 全法人では、清算の結了等と合併の合計のうち合併は約11%（2016〜2024年）。合併は 2016年 4,493件 → 2025年 6,123件と少しずつ増えている。
- 5年以内の2値で確かめても同じ（閉鎖：合同会社 オッズ比1.60、東京23区 1.64／合併：合同会社 0.46、東京23区 3.53）。

## 言えないこと
1. 「合併による解散」は、合併で消える側の法人の登記。グループ内の再編（親会社に吸収）も、買収されたあとの合併も同じ扱いで、成功・失敗は分からない。
2. 「閉鎖」は事業をやめたことと同じではない（F28 と同じ）。事業をやめても清算の登記をしない法人は多い。
3. 対象は2015年11月以降に設立された法人で、最長でも約11年しか追えていない。古い会社では合併の割合はもっと高い可能性がある。
4. 東京23区で合併が多い理由（グループ会社・持株会社の再編、資産管理会社の整理など）は、業種も規模もないこのデータでは分からない。
5. 今回は合併がまれなので、競合リスクを無視しても閉鎖の数字はほとんど変わらなかった。結末の片方が多いデータでは差は大きくなる。
