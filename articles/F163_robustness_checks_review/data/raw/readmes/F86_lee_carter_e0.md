# F86 平均寿命はこの先どこまで延びるのか？ Lee–Carter モデルと「過去の予測の当たり方」

## 問い
日本の平均寿命は2024年で男81.09年・女87.15年（日本版死亡データベース）。死亡率の長期の動きをそのまま先へ延ばすと、2045年・2070年にどこまで延びるのか。予測の幅はどれくらいで、同じ方法で過去に予測していたら当たっていたのか。社人研の将来推計人口（令和5年推計）の仮定と比べてどうか。

## データ
| ファイル | 内容 | 出典 |
|---|---|---|
| data/raw/f86_jmd_bundle.json | JMD の Mx_1x1・Deaths_1x1・Exposures_1x1・E0per（1947〜2024年、各歳、110歳以上）と、人口統計資料集の表5-12等の元データ | 国立社会保障・人口問題研究所「日本版死亡データベース」、同「人口統計資料集（2025）」 |
| data/mx_long.csv | 男女×年×年齢（0〜99歳＋100歳以上）の死亡数・曝露人口・死亡率 | 上を整形 |
| data/e0_jmd.csv | JMD の平均寿命（総数・男・女） | 同上 |
| data/ipss_e0.csv | 公式の平均寿命と社人研 令和5年推計（中位）の仮定値（2045年 男84.03・女90.08、2070年 男85.89・女91.94） | 人口統計資料集 表5-12 |

## 手法
- Lee–Carter：log m(x,t) = a(x) + b(x)k(t)。特異値分解で推定（Σb=1, Σk=0）。
- 2段目（Lee–Miller）：k(t) を、その年の平均寿命が実績と一致するよう推定し直す。
- 予測：k(t) をドリフトつきランダムウォークとし、ドリフトの推定誤差も入れて 5,000 回シミュレーション（seed=42）。出発点は 2024 年の実際の死亡率。
- 平均寿命は各歳の生命表（a=0.5、0歳は0.1、100歳以上は開いた階級）で計算。
- 当て方の確認（バックテスト）：当てはめを1989・1994・1999・2004・2009・2014年で止め、2024年までの実績と比べた。
- b(x) の形の変化：1970〜94年と1995〜2019年で別に当てはめて比べた。

## 主な結果
- 第1主成分の説明力：男 96.3%、女 95.2%。k(t) は1970〜2024年で男女とも年約2.0〜2.2下がった。2020年以降は横ばい。
- 2045年の平均寿命の予測（中心と95%区間）：男 84.7年（82.7〜86.3）、女 90.9年（88.9〜92.8）。社人研の中位（男84.03・女90.08）は、予測分布の下から25%・20%あたり。
- 2070年：男 88.3年（85.5〜90.7）、女 94.6年（91.6〜97.0）。社人研の中位（男85.89・女91.94）は分布の下から4.5%・4.0%で、95%区間のほぼ下端。
- 予測の伸びは10年あたり約1.6年で、1970〜2019年の実績（男2.5・女2.6年）より遅い。
- バックテスト：予測は過去に**平均して長めに外れていた**。10年先の誤差（実際−予測）は男 −0.77年、女 −1.09年。95%区間に実績が入った割合は男72%・女62%で、区間は狭すぎた（2020年以降を除くと73%・75%）。
- b(x) の形：女性は65歳以上の比重が 31%→34% に上がり、改善の中心が高い年齢へ移った。男性は 27%→25%。

## 頑健性
2070年の中心値（男／女）：
| 設定 | 男 | 女 |
|---|---|---|
| 基本（1970〜2024年） | 88.3 | 94.6 |
| 当てはめを1950年から | 88.6 | 94.8 |
| 当てはめを1990年から | 86.6 | 92.7 |
| 2019年まで（コロナ前） | 90.0 | 96.2 |
| 2段目なし | 88.2 | 94.5 |
| 0〜89歳＋90歳以上 | 88.8 | 96.5 |
| 出発点を当てはめ値に | 88.3 | 94.7 |

範囲は男 86.6〜90.0年、女 92.7〜96.5年。学習期間の選び方がいちばん効く。最近の30年だけで当てはめると、社人研の中位にかなり近づく。

## 言えないこと
- これは「過去の傾向が続いたら」の機械的な予測で、医療の進歩・感染症・生活習慣の変化は入っていない。
- 予測の区間は k(t) の揺れとドリフトの不確かさだけを含み、モデルの形（b(x) が一定）の誤りは含まない。バックテストで区間が狭すぎたのはこのため（推測）。
- 社人研の推計は別の方法（年齢別の改善の仮定など）で作られており、どちらが正しいかはこの分析では決められない。
- 2020年以降の横ばいが一時的かどうかは、まだ分からない。
- 都道府県や死因の内訳は扱っていない。

## 設計からの変更
- データは人口動態統計・生命表を直接使わず、それらから作られた JMD（各歳・毎年・1947〜2024年）を使った。
- 5歳階級の代替は不要だった。年齢の上限は0〜99歳＋100歳以上を基本とし、0〜89歳＋90歳以上を頑健性に入れた。
- 社人研の推計との比較と、b(x) の形の変化を追加した。
