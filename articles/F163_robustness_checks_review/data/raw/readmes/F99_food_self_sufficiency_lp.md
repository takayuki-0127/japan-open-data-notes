# F99　作るものを変えると、カロリーの自給率はどこまで上がるか？（線形計画法）

看板記事 F99。2024年度の食料需給表と作物統計を使い、「同じ農地で何をどれだけ作れば、国産の供給熱量が最も多くなるか」を線形計画法で計算しました。食べ方・使える農地・作付けの変え方の前提を変えて、結果を並べています。

**この記事は「前提を置くと、計算の上ではこうなる」というモデルの演習です。** どの作物を増やすべきかという政策の提案ではありません。

## 問い

- 今の農地のまま作るものを組み替えると、カロリーベースの自給率（2024年度 38%）はどこまで上がるか
- 何が上限を決めているのか（農地、食べ方、田の広さ、作付けの変えやすさ）
- 前提を変えると、答えはどれだけ動くか

この環境のスクリプトからは政府のサイトに直接つながらないため、ブラウザ（e-Stat のページ内）でファイルを読み、`data/raw/f99_raw1.json`・`f99_raw2.json` にまとめました。水稲・牧草・ソルゴーの2024年の行は、表が大きいため `f99_raw3.json` に写しています。

## 手法

### 1. 作物ごとの「1ha あたりの熱量」

6作物（米〈主食用〉・小麦・大豆・ばれいしょ・かんしょ・野菜〈ばれいしょを除く主要野菜〉）について、次のように計算しました。

- 食用1t あたりの熱量 ＝ 粗食料／（粗食料＋減耗量）× 歩留り × 純食料100g当たり熱量（食料需給表）
- 10a あたりの熱量 ＝ 2024年産の10a当たり収量 × 上の値
- 1万ha あたり、1人1日あたりの熱量 ＝ 10a あたりの熱量 × 1,000 ÷（人口 × 365）

| 作物 | 2024年の面積 | 10a あたり（万kcal／年） | 1万ha で 1人1日（kcal） | 補正係数 κ |
|---|---|---|---|---|
| かんしょ | 3.2万ha | 256 | 5.7 | 0.70 |
| 米（主食用） | 125.9万ha | 161 | 3.6 | 1.08 |
| ばれいしょ | 7.1万ha | 161 | 3.6 | 0.72 |
| 小麦 | 23.2万ha | 116 | 2.6 | 0.82 |
| 大豆 | 15.4万ha | 61 | 1.3 | 0.86 |
| 野菜 | 35.2万ha | 59 | 1.3 | 1.06 |

### 2. 今の国産熱量を再現する

- 作物ごとの今の国産熱量 ＝ 1人1日当たり供給熱量 × 公表の品目別自給率（大豆は「うち食用」23%）
- 面積から計算した熱量と合うよう、作物ごとに補正係数 κ を置きました。ばれいしょ・かんしょの κ が 0.7 前後なのは、でん粉・焼酎などの加工に回る分があるためと考えられます（推測）。
- 畜産物（肉・卵・乳）の国産熱量は、飼料自給率を反映した公表の自給率で計算しました（67kcal）。
- モデルに入れない品目（魚介・砂糖・果実・油脂など）の国産分は、公表の国産供給熱量 860kcal との差（161kcal）として固定しました。
- 検算：今の面積を入れると、国産熱量は 860.0kcal（38.3%）に戻ります。

### 3. 線形計画（scipy の HiGHS）

- 変数：6作物の面積、各作物の国産熱量、飼料用の農地のうち食用作物に回す面積（飼料用米・WCS 用稲・畑の飼料作物）
- 目的：国産の供給熱量（1人1日）を最大にする
- 制約：
  - 各作物の国産熱量 ≤ κ ×（1ha あたりの熱量）× 面積
  - 各作物の国産熱量 ≤ 食べる量（食べ方の前提）
  - 6作物の面積の合計 ≤ 今の6作物の面積（209.9万ha、延べ）＋ 飼料から回した面積
  - 米 ≤ 今の主食用米の面積 ＋ 田で作っている麦・大豆（31.0万ha）＋ 飼料用米・WCS から回した面積
  - 国産熱量の合計 ≤ 総供給熱量 2,248kcal
- 飼料の農地を食用に回すと、畜産物の国産熱量が減ります。国産の粗飼料（TDN）は飼料作物と WCS の面積に、飼料用米の TDN は飼料用米の面積に比例するとみなしました。飼料用米の TDN は「主食用と同じ収量 × 玄米重量の80%」と置いています（推測にもとづく前提）。

### 4. 前提の組み合わせ（3 × 3 × 2 = 18通り）

| 軸 | 選んだ前提 |
|---|---|
| 食べ方 | D1：今の食べ方のまま（各作物の国産熱量は、今の供給熱量まで）／D2：米は2000年度並み（650kcal、今の1.3倍）まで、ばれいしょ・かんしょは今の2倍まで食べてよい／D3（参考）：食べ方の上限なし（カロリーだけを最大に） |
| 使える農地 | L0：今の6作物の田と畑だけ／L1：＋飼料用米・WCS 用稲の田（15.5万ha）／L2：＋畑の飼料作物も（牧草・青刈りとうもろこし・ソルゴー、80.3万ha） |
| 作付けの変え方 | C1：米以外は今の面積の0.5〜2倍、野菜と大豆は今より減らさない／C0：上限も下限もなし |

## 結果

### 自給率の最大値（%、今は 38.3%）

| 食べ方 | 農地 | 作付けの増減に上限あり（C1） | 上限なし（C0） |
|---|---|---|---|
| 今のまま（D1） | 今の6作物の田畑 | 38.6 | 40.4 |
|  | ＋飼料用米・WCS | 39.8 | 41.5 |
|  | ＋畑の飼料作物 | 41.7 | 46.8 |
| 米を多く食べる（D2） | 今の6作物の田畑 | 39.4 | 43.0 |
|  | ＋飼料用米・WCS | 41.7 | 45.0 |
|  | ＋畑の飼料作物 | 48.2 | 50.8 |
| （参考）上限なし（D3） | 今の6作物の田畑 | — | 46.9 |
|  | ＋飼料用米・WCS | — | 49.3 |
|  | ＋畑の飼料作物 | — | 61.6 |

わかったこと：

- **今の食べ方と今の農地のままでは、組み替えても 38.3% → 38.6%（上限なしでも 40.4%）にとどまりました。**
  - 米・かんしょはすでにほぼ国産で、これ以上作っても食べる量が上限になります。
  - 輸入が多い小麦を全部国産にするには、計算上あと約122万ha が要ります。今の6作物の面積（約210万ha）の6割にあたります。
- **農地を足すと上がります。** 飼料用米・WCS の田を回すと約 +1 ポイント、畑の飼料作物も回すと約 +3 ポイント（上限なしなら +8 ポイント）です。
  - そのかわり、畜産物の国産熱量（飼料自給率の分）は 67kcal から 40kcal（上限なしでは 21kcal）に減ります。
  - 1万ha の飼料作物を小麦に回すと、小麦は約 2.1kcal 増え、畜産物は約 0.5kcal 減る計算です。
- **米を多く食べてよいとすると、さらに上がります（最大 48.2%、上限なしで 50.8%）。** ただし、効いているのは「食べてよい量」ではなく「米を作れる田の広さ」でした。米の上限を今の1.2倍・1.5倍に変えても、答えは変わりません。
- **農地を1万ha 増やしたときの効果（双対価格）は、1人1日 0.5〜3.9kcal（自給率で 0.02〜0.17 ポイント）でした。**
- 作付けの上限を外すと、線形計画は野菜と大豆をゼロにして、小麦や米に回します。カロリーだけを目的にすると、栄養のバランスは見ないためです。
- **（参考）全部の農地（延べ 386万ha）を6作物に回したときの熱量は、作物だけで次のとおりでした。**
  - 米・小麦・大豆・野菜だけ：1,207kcal（実際の最適解では米と小麦だけになる）
  - いもも使う：2,187kcal（すべてかんしょ）
  - 農林水産省の食料自給力指標（米・小麦中心 1,752kcal、いも類中心 2,362kcal）と比べると、いも中心が必要量 2,167kcal を上回る点は同じです。数字が違うのは、自給力指標には畜産・果実などが入り、作付けの前提も違うためです。

### 頑健性（前提を1つずつ変える）

基準にしたのは「今の食べ方＋飼料の農地」（D1-L2-C1、41.7%）と「米を多く食べる＋飼料用米・WCS」（D2-L1-C1、41.7%）です。

| 変えた前提 | D1-L2-C1 | D2-L1-C1 |
|---|---|---|
| 収量 −10%／+10% | −1.0／+1.0 | −3.2／+3.2 |
| 農地 −10% | −0.9 | −2.9 |
| 補正係数 κ を使わない | +1.0 | −1.2 |
| 作付けの上限を今の1.5倍／3倍 | −1.1／+2.1 | 0.0／0.0 |
| 作付けの上限なし | +5.1 | +3.3 |
| 減らす下限（今の半分）をなくす | 0.0 | +1.1 |
| 野菜・大豆も減らしてよい | 0.0 | +2.3 |
| 飼料の農地を減らしたときの畜産の減り ×2／×0.5 | −1.2／+0.6 | −0.3／+0.2 |
| 米を食べる量 1.2倍／1.5倍まで | — | 0.0／0.0 |
| いもを食べる量 1.5倍／4倍まで | — | 0.0／0.0 |

- 収量と農地は ±1〜3 ポイントです。
- いちばん大きく効くのは「作付けをどこまで変えてよいか」で、最大 +5 ポイントでした。

## 言えないこと

- **政策の提案ではありません。** 線形計画は、置いた前提の中での最大値を出すだけです。「小麦を何万ha 増やすべき」とは言えません。
- 次のものはモデルに入っていません。
  - 労働力・機械・費用・価格・農家の収入
  - 輪作や連作障害
  - 地域ごとの気候と土地の向き不向き（田を畑にしたときの収量の違いを含む）
- 収量は全国平均で、面積を増やしても同じ収量が出ると置いています。実際には、条件の悪い土地に広げるほど収量は下がると考えられます（推測）。
- カロリーだけを目的にしています。たんぱく質・ビタミン・食べ慣れは「野菜と大豆を減らさない」という制約で一部を見ただけです。
- 畜産物は、飼料の農地を減らした分だけ国産の熱量が減るとしました。国産飼料の代わりに輸入飼料が増え、畜産物の生産量そのものは変わらないとみなしています。
- 補正係数 κ は、加工・在庫・種子などの違いをまとめて吸収したものです。中身を分けてはいません。
- 魚介・砂糖・果実・油脂などの国産分は固定しています。てんさい・さとうきび・なたねなどを増やす選択肢は入れていません。

## 再現手順

```bash
pip install -r requirements.txt
bash src/run_all.sh   # 01_取得 → 02_整形 → 03_分析 → 04_図
```

- `src/01_取得.py`：`data/raw/*.json` から `data/fbs_2024.csv`・`crops_2024.csv`・`misc_2024.json` を作る
- `src/02_整形.py`：作物ごとのパラメータ（`results/crop_params.csv`）と、畜産・飼料・固定分（`results/params.json`）
- `src/03_分析.py`：18通りのシナリオ（`results/scenarios.csv`）、頑健性（`results/robustness.csv`）、全農地の参考計算（`results/potential_all_land.csv`）
- `src/04_図.py`：図5枚（`figures/`）

乱数は使っていません。
