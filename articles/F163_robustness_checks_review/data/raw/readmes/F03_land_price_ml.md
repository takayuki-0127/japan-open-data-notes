# F03 地価を決めているのは何か？ 全国2.6万地点を機械学習で読む

看板記事シリーズの3本目です。地価公示（2026年、25,565地点）の価格を、地点の属性・周りの駅の乗降客数・市区町村の人口で予測する LightGBM を作り、ランダムCVと空間ブロックCVで精度を比べ、SHAP と部分依存で「何がどう効いているか」を読みます。前年の価格は使いません。

## 問い

地価公示の価格は、駅からの距離・人の集まり・用途地域などで、どこまで説明できるか。どの要因がどれだけ効いているか。

## データ

| データ | 内容 |
|---|---|
| 地価公示（国土数値情報 L01、2026年） | 25,565地点の価格（円/㎡）と属性。2016年の価格も同じファイルから |
| 駅別乗降客数（国土数値情報 S12、2024年） | 10,534駅・路線 → 駅グループに合計し、地点からの距離で集計 |
| 令和2年国勢調査 第1-1表 | 市区町村の人口・人口密度・5年間の増減率 |

元データの取得先は `data/raw/SOURCES.md`。加工済みの特徴量は `data/features.csv`。

## 手法

| 項目 | 内容 |
|---|---|
| 目的変数 | log(地価公示価格) |
| 特徴量 | 30個：数値25（駅までの距離、地積、容積率、建ぺい率、前面道路の幅、ガス・水道・下水、間口・奥行、階数、最寄駅の乗降客数と直線距離、半径1・3・10km内の乗降客数、三大都市の中心までの距離、市区町村の人口・人口密度・増減率、緯度・経度）＋カテゴリ5（用途地域、都市計画区域、防火地域、前面道路の種類、用途） |
| ベースライン | リッジ回帰（数値は標準化、欠損は中央値＋欠損フラグ、カテゴリはダミー、駅距離は log(距離+50)） |
| モデル | LightGBM（学習率0.03、葉63、1,500本、行・列のサブサンプリング0.8） |
| CV | ランダム5分割／20km四方のブロック単位の5分割／都道府県単位の5分割（GroupKFold） |
| 評価 | R²（log）、予測÷実際 の誤差の中央値、±20%以内の割合 |
| 説明 | SHAP（TreeExplainer、全地点）、部分依存（4,000地点の平均）、ブロックCVの残差の地図 |
| 頑健性 | 緯度経度なし、用途地域なし、立地の特徴量なし、住宅地・商業地で別モデル、2016年の価格 |

- 20kmブロックCVで実際が予測の2倍超：608地点、半分未満：466地点。上に外れるのは倶知安（ニセコ）・軽井沢・富良野・高山などの観光・別荘地。沖縄県は平均で予測の1.26倍

結果の表は `results/`、図は `figures/`（f01〜f05）。`results/lgbm_full.txt`（学習済みモデル）と `shap_values.npy` は大きいので置いていません（`04_shap.py` で作り直せます）。

## 動かし方

```
pip install -r requirements.txt
# data/raw/SOURCES.md の URL から L01-26_GML と S12-25_GML を data/raw/ に展開
sh src/run_all.sh
```

CV と SHAP で合わせて15分ほどかかります。乱数は固定しています。

## 注意

- SHAP・部分依存はモデルの予測への寄与で、因果効果ではありません
- 地価公示は鑑定評価で、実際の取引価格とは違います
- 2016年の頑健性チェックは、価格だけが2016年で、属性・乗降客数・人口は2026年時点（2024年・2020年）の値です
- 設計時に予定していた 500mメッシュ人口・学校・医療機関は使わず、市区町村の人口密度で代用しました（設計書の代替案）
- 浜松市は2024年に区を再編したため、新しい区の地点には市全体の人口を使っています
