# F112 救急隊が全部出払う確率は、隊を1つ増やすとどれだけ下がるか？ 待ち行列モデルとシミュレーション

看板記事シリーズの112本目です。窓口や救急のように「来た順にさばく」仕組みでは、担当を1人（1隊）増やしたときの効き目が、平均の忙しさだけでは分かりません。ここでは、総務省消防庁『令和7年版 救急救助の現況』の公表値（出動件数、救急隊数、時刻・月・曜日ごとの件数、病院収容所要時間の分布）を使い、待ち行列理論（M/M/c、Erlang の式）と、時間による変動を入れたシミュレーション（M/G/c）で、「119番の時点で地域の救急隊が全部出払っている割合」が隊の数でどう変わるかを見ます。

公表されていない値（引継ぎ後に次の出動ができるまでの時間など）は仮定で置き、結果は必ず仮定を変えて並べています。特定の地域や消防本部を評価するものではなく、都道府県の値も名前を出さずに分布として示します。

## 問い

- 人口10万人の地域で救急隊を1隊増やすと、全隊出払いはどれだけ減るか
- 平均の忙しさ（稼働率）が同じでも、地域の大きさや時間帯で出払いやすさはどれだけ違うか
- 病院収容までの時間が延びることは、隊の数でいうと何隊分にあたるか

## 手法

| 項目 | 内容 |
|---|---|
| 隊がふさがる時間（1件あたり） | 搬送：病院収容所要時間＋R（引継ぎ後に次の出動ができるまで。**仮定、基準20分**）。不搬送：N（**仮定、基準30分**）。基準の平均は約60.2分 |
| 病院収容所要時間の分布 | 第37表の6区分に、対数正規分布とガンマ分布を区間データとして最尤推定で当てはめ（対数正規：中央値42.1分、σ=0.374）。平均は公表値44.6分に合わせた |
| 到着 | ポアソン到着。強さは「2時間帯×月×曜日」の係数で変える（時間帯で0.40〜1.57倍、すべて重ねると最大1.94倍） |
| 式による近似 | 各時間帯を定常とみなした M/M/c（Erlang C）の「全隊ふさがり確率」を、件数で重み付けして平均 |
| シミュレーション | M/G/c（来た順に、最初に空く隊が担当）。10年分（人口10万人で約6.1万件）。全隊ふさがりのときは待つ（基準）／隣の本部の応援に回す（比較） |
| 地域の想定 | 人口5万・10万・30万人。全国平均の割合（10万人あたり4.35隊）を目安に、隊の数を変える |
| 全国の推移 | 出動件数×1件あたりのふさがる時間÷（隊数×8,760時間）を「稼働率の目安」とする（R=10・20・30分） |

## 主な結果

### 1. 全国の1隊あたりの負担は10年で約2割増えた

- 1隊あたりの出動件数は、2015年の1日3.27件から2024年の3.91件に増えました。
- 稼働率の目安（R=20分）は12.9%から16.4%に上がりました（R=10〜30分では14.0〜18.7%）。2022年は病院収容所要時間が47.2分と長く、件数も増えた年です。
- 都道府県の間では、1隊あたりの出動件数が1日1.4〜8.7件（中央値2.8件）、稼働率の目安は6〜36%と幅があります。人口10万人あたりの隊数が少ないほど稼働率が高い関係（相関 −0.85）でした。

### 2. 人口10万人の地域：隊の数と全隊出払い（時間変動を入れた近似）

| 隊の数 | 稼働率 | 全隊出払いの割合 | 年あたりの件数（出動 約6,100件のうち） |
|---|---|---|---|
| 3 | 23.3% | 6.49% | 約397件 |
| 4 | 17.5% | 1.42% | 約87件 |
| 5 | 14.0% | 0.27% | 約16件 |
| 6 | 11.7% | 0.04% | 約3件 |

- 4隊から5隊にすると、全隊出払いは約5分の1になります。稼働率は17.5%から14.0%にしか変わりません。
- 同じ稼働率17.5%でも、人口5万人・2隊では7.47%、10万人・4隊では1.42%、30万人・12隊では0.007%と、規模が大きいほど出払いにくくなります（隊をまとめて使える効果）。
- 出払いは日中に集中します。10万人・4隊では、10〜12時の入電で2.9%、2〜4時で0.02%です。

### 3. ふさがる時間の延びと、隊の数の釣り合い（10万人・4隊）

| 条件 | 全隊出払いの割合 |
|---|---|
| 1隊減らす（3隊） | 6.49% |
| ふさがる時間 +10分 | 2.36% |
| 病院収容が令和4年並み（47.2分） | 1.61% |
| 基準（令和6年 44.6分） | 1.42% |
| 病院収容が令和元年並み（39.5分） | 1.10% |
| 1隊増やす（5隊） | 0.27% |

- 1隊減らすのと同じだけ悪くなるのは、ふさがる時間が約37分延びたとき（3隊なら約47分、5隊なら約30分）です。
- 令和元年から令和4年への病院収容所要時間の延び（7.7分）は、全隊出払いを1.10%から1.61%に押し上げる大きさでした。

### 4. 式の近似とシミュレーション

- 時間変動を入れた近似（1.42%）とシミュレーション（1.40%、乱数10通りで1.26〜1.45%）はほぼ一致しました。
- 時間変動を無視して1日平均の到着率で計算すると0.60%となり、約2.3分の1に過小評価します。

## 頑健性（10万人・4隊、シミュレーション）

| 変えたもの | 全隊出払いの割合 |
|---|---|
| 基準（対数正規・R=20分・N=30分・待つ） | 1.40% |
| ふさがる時間の分布：指数／ガンマ／病院収容を一定 | 1.20%／1.22%／1.30% |
| R（引継ぎ後の時間）：10／30／40分 | 0.77%／1.96%／2.95% |
| N（不搬送）：20／40分 | 1.18%／1.35% |
| 日ごとの多さのぶれ（ガンマ、変動係数）：10%／20% | 1.39%／1.75% |
| 出払い時は応援に回す（待たない） | 1.00% |
| 5隊のうち1隊／2隊が日中（8〜20時）だけ | 0.31%／0.62%（5隊すべて24時間：0.29%） |
| 時間変動を無視した式（参考） | 0.60% |

- 答えを最も大きく動かすのは、公表されていない R（引継ぎ後に次の出動ができるまでの時間）でした。R が10分から40分に延びると、全隊出払いは約4倍になります。
- ふさがる時間の分布の形（指数・ガンマ・対数正規）による差は、乱数による差（1.26〜1.45%）と同じくらいです。
- どの仮定でも、「1隊増やすと全隊出払いが4〜6分の1になる」「日中に集中する」は変わりませんでした（5隊の結果は `results/simulation.csv`）。

## 言えないこと

- 実際の消防本部の運用（隊の配置場所、出動する隊の選び方、日勤の隊、隣の本部との応援協定、救急車の数と隊の数の違い）は入っていません。「全隊出払い」は、地域を1つのまとまりとみなしたモデルの値です。
- 人口30万人の地域を1つのまとまりとして扱うと出払いにくく見えますが、実際には範囲が広く、近くの隊が出払うと到着が遅れます。規模の効果は、モデルの上での上限に近い見方です（推測）。
- 引継ぎ後に次の出動ができるまでの時間（R）と、不搬送の出動の時間（N）は公表されておらず、仮定です。結果は R に大きく左右されます。
- 時間帯の変動は搬送人員（2時間ごと）から作りました。出動件数の時間帯の内訳とは少し違います。月・曜日・時間帯の係数は全国の値で、地域ごとの違いは入れていません。
- 全隊出払いは「応援を頼む・到着が遅れる」可能性を示すもので、そのまま救命への影響を表すものではありません。
- 都道府県の値は、隊の数（4月1日）と出動件数（年間）を組み合わせた目安で、地域の良し悪しを示すものではありません。
