# F09 国会で「賃上げ」「物価」が語られた40年（テキストマイニング）

国会の発言に「賃上げ」「物価」などの語がどれだけ出てきたかを、国立国会図書館の国会会議録検索システムの API で1985〜2026年について数え、一緒に出た言葉とトピックモデル（LDA）で「どんな文脈で語られたか」の移り変わりを調べました。

- note：https://note.com/takayukimatsuura/n/n91ff52caa4a5
- 看板記事（手法をくわしく見せる長めの記事）です

## 問い

国会の発言で「賃上げ」「物価」「少子化」などの語はいつ増え、どんな文脈で語られてきたか。統計（物価上昇率・賃上げ率）の動きとどれくらい一緒に動くか。

## データ

| データ | 中身 | ファイル |
|---|---|---|
| 国会会議録検索システム 検索用API（国立国会図書館） | 語×年×会議の範囲ごとの発言数（1985〜2026年、2026年は10月24日まで）。15語＋表記ゆれ、全会議・本会議・予算委員会 | data/counts_by_year.csv |
| 同 API の発言の抜粋 | 「賃上げ」「物価」それぞれ、年ごとに無作為な位置から連続100発言を取り、語の前後150字を抜き出したもの（6,632発言） | data/tokens.jsonl.gz（形態素解析後の名詞。発言IDつき） |
| 総務省「消費者物価指数」長期時系列 | 総合・前年比（1971〜2025年、年平均） | data/cpi_annual_yoy.csv |
| 厚生労働省「賃金引上げ等の実態に関する調査」 | 1人平均賃金の改定率（企業規模計、1975〜2025年。記事141と同じデータ） | data/wage_increase_rate.csv |

- 発言数は、その語を含む発言の件数です（1つの発言に何回出ても1件）。発言1万件あたりに直して比べました
- 「本会議」「予算委員会」は API の会議名の指定（部分一致）なので、分科会・公聴会も含みます
- 発言の抜粋そのもの（data/raw/）は GitHub には置いていません。`src/01_fetch_api.py` で取り直せます（発言IDは tokens.jsonl.gz にあります）
- 取得は 2026-10-25。記事では 01 と同じ手順をブラウザのページ内で実行しました（抜粋を取る位置の乱数だけ 01 と違うので、01 で取り直すと抜粋の中身は少し変わります）

## 手法

| 段階 | やったこと |
|---|---|
| 取得 | API で語×年×会議の範囲の発言数（約1,100回）と、発言の抜粋（84回×100件）を取得。アクセスは1.2秒以上あけた |
| 前処理 | Unicode 正規化、発言者名・数字の除去。fugashi（MeCab）＋unidic-lite で名詞だけを残し、定型語・人名を除いた |
| 頻度 | 発言1万件あたりの出現率の推移、年代別の平均とピーク |
| 統計との関係 | 物価上昇率・賃上げ率との相関（3年ブロックのブートストラップで95%区間）、差分の相関、前後1〜2年ずらした相関 |
| 一緒に出た言葉 | 年代ごとの特徴語（事前分布つきの重み付き対数オッズ比、Monroe ほか 2008）、共起ネットワーク（Jaccard 係数） |
| トピック | LDA（scikit-learn、8トピック）。トピックごとの構成比の年次推移 |

## 主な結果

**1. 「賃上げ」は2022年から急に増えた**
- 発言1万件あたり、1995〜2004年の平均1.5件、2005〜14年6.6件から、2022年99.5件、2024年182.8件（ピーク、発言の1.8%）
- 2013年にも18.1件に増えたが、2020年は8.0件まで下がっていた

**2. 「物価」は2025年が40年で最多**
- 1985〜94年の平均94.5件 → 2020年21.2件（最少）→ 2025年307.4件（発言の3.1%）
- 「物価高」は2021年に0.2件だったのが、2022年93.5件、2025年167.0件（それまでの最多は2008年の5.8件）
- 「デフレ」は2013年（138.6件）、「働き方改革」は2018年（152.1件）、「少子化」は2023年（144.5件）がピーク

**3. 統計との関係**
- 「物価」の出現率と消費者物価の上昇率：相関0.68（95%区間0.27〜0.84、1985〜2025年）
- 「賃上げ」の出現率と賃上げ率：全期間では0.23（−0.20〜0.66）と弱い。1990年前後は賃上げ率が5%を超えていたのに、国会ではほとんど語られていなかった。2013〜2025年に限ると0.92

**4. 「賃上げ」が語られる文脈が変わった**
- 「賃上げ」の抜粋のうち、労使系の語（春闘・労使・組合・交渉）を含む割合：1985〜94年50% → 2015〜26年17%
- 政策系の語（税制・支援・補助・助成）を含む割合：5% → 37%
- トピックモデルでも、「賃上げ」の発言に占める「春闘と労使交渉」は50% → 19%、「企業の賃上げと税制・好循環」は7% → 34%、「予算・支援策（介護・地方・高騰対策）」は4% → 26%

**5. 「物価」の文脈**
- 「物価」の発言に占める「金融政策（日銀・物価目標）」は1985〜94年7% → 2005〜14年29%・2015〜26年28%
- 「物価対策（輸入・農産物・料金）」は25% → 7%、「公務員給与・恩給の改定」は21% → 8%

## 頑健性

- **会議の範囲**：全会議と本会議・予算委員会の出現率の相関は、賃上げ0.98・0.99、物価0.97・0.96、少子化0.93・0.89、デフレ0.97・0.94。ピーク年もほぼ同じ（賃上げ2024/2024/2025、物価2025/2025/2026）
- **表記ゆれ**：「賃上げ」と「賃金の引上げ」の相関0.85、「賃金引上げ」0.75。「ベースアップ」は0.35で、1985年がピーク（昔の言い方）
- **トピック数・乱数の種**：K=6・10、種を2つ変えて、K=8 の各トピックにいちばん近いトピックの年次構成比との相関（中央値）は0.90〜0.97。ただし「春闘と労使交渉」は種によって別のトピックと混ざることがある（相関0.50の組あり）ので、トピックモデルを使わない語の割合（結果4）でも確かめた

## 注意（このデータで言えないこと）

1. 発言の量は「国会でどれだけ話題になったか」の目安で、政策の効果や良し悪しを表すものではありません
2. 特定の政党・議員の評価はしていません（会派・発言者では分けていません。人名は分析から除いています）
3. 1つの発言が長くても短くても1件です。長い答弁が増えれば、同じ件数でも語られた量は違います
4. 抜粋は年ごとに連続100発言なので、同じ会議の発言が固まって入ることがあります。1995〜2004年の「賃上げ」は発言自体が少なく、173件しかありません
5. トピックのラベルは、上位の語を見て作成者が付けたものです
