# F91 機械学習の「何が効いているか」は、手法で答えが変わるか？ SHAP・並べ替え重要度・PDP・ALE の比較

## 問い
機械学習のモデルに「何が効いているか」を聞く方法はいくつもある。よく使われる4つ（SHAP、並べ替え重要度、部分依存（PDP）、ALE）で同じモデルを読むと、答えはそろうのか。とくに、互いに強く相関する変数（気温の平均と最高、近くの駅の乗降客数と人口密度など）があるとき、何が起きるのか。

材料は、このシリーズですでに作った2つの予測モデル：地価（F03、全国の地価公示地点）と電力需要（F22、東京エリアの1時間ごと）。

## データ
| データ | 元の記事 | 件数 | 使い方 |
|---|---|---|---|
| 地価公示の地点と特徴量（30変数：数値25・カテゴリ5） | F03 の data/features.csv | 25,565 地点 | 被説明変数は log(価格)。ランダムに80%学習・20%評価（乱数 2026） |
| 東京エリアの1時間ごとの需要と気温 | F22 の data/hourly_tokyo.csv | 91,872 時間（2016年4月〜2026年9月） | 特徴量は F22 と同じ23変数。2023年3月までで学習、2023年4月〜2026年9月から2万時間を評価 |

- data/raw/ の2ファイルは `01_取得.py` が GitHub（F03・F22 のフォルダ）から取る。同じものなので、このフォルダには置いていない。
- 強く相関する変数の組（スピアマン |r|≥0.7）は results/corr_pairs.csv。地価13組（10km 内の乗降客数と市区町村の人口密度 0.92、緯度と経度 0.89、駅までの距離2種 0.88、容積率と建ぺい率 0.88 など）、電力19組（日平均気温と日最低 0.98・日最高 0.98、冷房度日2種 0.91、24時間前と1週間前の需要 0.82 など）。

## 手法
- モデル：LightGBM（地価 学習率0.05・葉63・700本、電力 学習率0.04・葉63・900本、乱数固定）。精度は地価 RMSE 0.253（log、誤差の中央値13.8%）、電力 MAPE 2.26%。
- 4つの重要度（評価データで計算）
  - **SHAP**：TreeExplainer、3,000点の |SHAP| の平均
  - **並べ替え重要度**：1変数ずつ並べ替えたときの RMSE の増え方（5回の平均）
  - **部分依存（PDP）**：その変数だけを全点で同じ値にそろえたときの予測の平均。曲線の幅（最大−最小）を重要度とする
  - **ALE**（Apley & Zhu）：変数の分位点で区切り、各区間に実際にある点だけを動かして差を積み上げる。カテゴリ・0/1 は水準を y の平均で並べて隣どうしの差を積む。曲線の幅を重要度とする（PDP・ALE とも 5〜95% の範囲、2,000点）
  - 参考に LightGBM の gain も保存
- 比べ方：重要度の順位相関（スピアマン・ケンドール）、上位5の重なり、手法ごとに合計を100にした割合
- 相関する変数の落とし穴
  1. **仲間を外す**：日平均気温と相関する5変数（日最高・日最低・冷房度日・暖房度日・最高気温の冷房度日）、3km 内の乗降客数と相関する4変数（1km・10km・最寄り駅の乗降客数、人口密度）を外して学習し直し、取り分の変化を見る
  2. **まとめて並べ替える**：相関する変数のまとまり（気温6つ、乗降客数4つ など）を一緒に並べ替えた重要度と、1つずつの合計を比べる
  3. **ありえない点**：日平均気温だけを並べ替えると、日最高を上回ったり日最低を下回ったりする「ありえない日」がどれだけできるか
  4. **答えが分かっている人工データ**：y = x1 + 0.5·x3 + ノイズ。x2 は x1 と相関 ρ を持つだけで効果0、x4 はまったく関係ない。ρ を 0〜0.99、学習データを 500〜20,000件に変えて各8回

## 主な結果
| | 地価 | 電力需要 |
|---|---|---|
| 手法どうしの順位相関 | 0.70〜0.95 | 0.79〜0.99 |
| いちばん近い組 | PDP×ALE 0.95、SHAP×並べ替え 0.94 | PDP×ALE 0.99 |
| いちばん遠い組 | SHAP×ALE 0.70 | SHAP×ALE 0.79 |
| 上位5の重なり（6組の平均） | 3.7/5 | 4.3/5 |
| 4手法とも1位 | 3km 内の乗降客数 | 24時間前の需要 |

- **上位はそろう**：1位は4手法とも同じ。上位の顔ぶれもおおむね共通（地価：乗降客数・緯度、電力：24時間前の需要・時刻・曜日の区分・1週間前の需要）。
- **大きさと中位の順位は違う**：3km 内の乗降客数の取り分は SHAP 31%・並べ替え 35%・PDP 21%・ALE 14%。電力の「1週間前の需要」は SHAP で2位（12%）だが並べ替えでは5位（6%）。手法は「SHAP・並べ替え」と「PDP・ALE」の2つの組に分かれた。
- **仲間を外すと取り分が集まる**：日平均気温の取り分は、相関する5変数を外すと SHAP 5.0→13.5%（2.7倍）、並べ替え 6.0→20.7%（3.7倍）、PDP 2.5倍、ALE 1.9倍。予測の誤差はほとんど変わらない（RMSE 1,026→1,059 MW、+3%）。地価の3km 内の乗降客数は 1.1〜1.4倍（RMSE 0.253→0.275）。「気温の効き方」は、気温の変数を何個入れたかで見かけが変わる。
- **1つずつの並べ替えは、まとまりの効き目を小さく見せる**：気温6変数を一緒に並べ替えると RMSE は +2,338 MW、1つずつの合計は +1,548、最大の1つ（日最高）は +668。乗降客数4変数でも 1.05 対 合計 0.82 対 最大 0.50。
- **並べ替えと PDP は「ありえない日」を作る**：日平均気温だけを並べ替えると、69%の行で日平均が日最高を上回るか日最低を下回った（PDP の格子でも71%）。地価の容積率と建ぺい率では、並べ替えで容積率＜建ぺい率になるのは0.7%と少なかった。
- **SHAP だけが「年」に重要度を付けた**：電力の「年」は SHAP で 4.1%、ほかの3手法は 0。評価期間（2023年4月以降）の年はすべて学習期間より後で、木の中では同じ枝に入るため、評価データの中で動かしても予測は変わらない。SHAP は学習データの平均との差を測るので、水準のずれを「年」の効果として載せる。手法が測っているものの違いが、そのまま出た例。
- **人工データでは、落とし穴は思ったより小さかった**：効果0の x2 に付く重要度は、相関0.95までは関係ない x4 とほぼ同じ（SHAP・PDP・ALE 約3%、並べ替え 0〜0.6%）。相関0.99で初めて x2 が x4 を上回り（SHAP 7.4% 対 3.8%）、学習データが500件だとその差は 7〜8 ポイント、2万件だと 1〜3 ポイント。LightGBM は本当に効く x1 があれば x2 をあまり使わない。
- SHAP・PDP・ALE は関係ない変数にも数%の重要度を付ける（ノイズの床）。並べ替え重要度は評価データで測るので、関係ない変数はほぼ0になる。

## 頑健性
1. **モデルの設定**（葉15・学習率0.1・別の乱数）：各手法の順位は基本の設定と 0.94〜0.99 の順位相関で、ほぼ変わらない。
2. **モデルの種類**（LightGBM のランダムフォレスト型）：0.66〜0.85 と大きく動く。とくに地価の PDP（0.66）・ALE（0.67）。一方で手法どうしの一致は上がった（平均 地価 0.83→0.97、電力 0.87→0.96）。手法の違いより、モデルの違いのほうが答えを動かす。
3. **計算の設定**：SHAP の点数1,000（0.997〜0.999）、並べ替え20回（0.998〜0.999）、PDP・ALE の点数1,000・区切り10（0.97〜0.99）はほぼ同じ。並べ替えを学習データで測ると、地価 0.98、電力 0.94（過学習ぶんの差）。
4. **相関の強さ・サンプルの大きさ**（人工データ）：上の結果のとおり、相関0.99かつ少ないデータで落とし穴が大きくなる。
5. **データ**：地価と電力の2つで、上位がそろう・中位と大きさが手法で違う・仲間を外すと取り分が集まる、という同じ形が出た。

## 言えないこと
- どの手法が「正しい」かは決められない。4つは測っているもの（予測の分け方、誤差の増え方、平均の曲線、局所の差の積み上げ）が違い、同じ数字になる理由はない。
- PDP・ALE の「曲線の幅」を重要度とするのはこの記事の決め方で、ほかの決め方（曲線の標準偏差など）では順位が変わりうる。
- 重要度は「モデルが何を使ったか」で、「現実で何が原因か」ではない。地価で乗降客数が1位でも、駅を増やせば地価が上がるとは言えない。
- 仲間を外す実験は、外し方（どの変数を残すか）で結果が変わる。ここで見たのは2つの例だけ。
- 人工データは線形で単純な設定。相関がもっと複雑な場合や、別のモデル（線形回帰・ニューラルネット）では落とし穴の大きさは違いうる。
- ALE は自前の実装で、カテゴリ変数の並べ方（y の平均の順）は1つの選び方にすぎない。
