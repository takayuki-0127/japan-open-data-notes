# F69 公的データの「見えにくい欠点」：0 と欠測と秘匿の見分け方（データ品質の点検）

note の看板記事 F69 のコード・データ・図です。

## 問い

公的統計の表には、数字の代わりに「-」「…」などの記号が入っているセルがある。その記号は「0」なのか、「欠測（値がない）」なのか、「秘匿・表章しない」なのか。表ごとに意味は違うのか。データの中の手がかりだけで、どこまで見分けられるか。扱いを間違えると、結果はどれだけずれるか。

## データ（新しくは取っていません）

これまでの記事で取った5つの統計表を、同じ点検ルールにかけました。

| 表 | 中身 | 元の記事 |
|---|---|---|

| T3 感染症発生動向調査（IDWR、インフルエンザ定点） | 2012年37週〜2026年42週、736週×48行 | F52 |

## 手法：点検ルール R1〜R6

| ルール | 中身 |
|---|---|
| R1 記号の検出 | 数値でないセルを数え、どの行・列・年に集まるかを見る |
| R2 0 と記号の併存 | 同じ列に数字の 0 と記号の両方があるか（両方あれば、記号は 0 ではない可能性が高い。0 が1つもなければ、0 が記号で書かれている可能性がある） |
| R3 合計の一致 | 内訳の合計＝総数 が成り立つか。記号を「0 とみなす」「欠測とみなす」の2通りで計算し、どちらで合うかを見る |
| R4 桁ずれ | 前の時点からの比が極端（既定は3倍以上・3分の1以下）なセルを探し、中身を確かめる |
| R5 単位の妥当範囲 | 表の単位（【千円】など）どおりに計算した値（1人あたり所得など）が、ありうる範囲に入るか |
| R6 再計算との一致 | 公表されている率を、公表されている実数から計算し直して一致するか |

## 主な結果

- **記号の割合**：T1 3.8%、T2（増減率の表）24.4%、T3 20.6%、T4（死亡数）8.6%、T5 4.4%。数字の 0 があるのは T1（1.0%）と T2 だけで、T3・T4・T5 の人数の列には 0 が1つもありませんでした。
- **T3 感染症の「-」は 0**：47都道府県の報告数の合計＝総数 は、「-」を 0 とみなすと全736週で一致し、欠測とみなすと一致を確かめられるのは「-」のない365週だけでした。報告数の列に数字の 0 は1つもありません。「…」は2021年の3セルだけです。
- **T5 国勢調査の「-」も 0**：4つの恒等式（総数＝労働力＋非労働力＋不詳 など）と男＋女＝総数は、「-」を 0 とみなすと13,248行すべてで成り立ちました。人数の列に数字の 0 はなく、0 は計算した労働力率の列（51セル）にだけありました。「-」は高い年齢ほど多く、90歳以上では95%の行にあります。
- **T1 社会・人口統計体系の「-」は 0 ではない**：同じ項目×年の列に 0 と「-」の両方がある組が177組中77組ありました。「-」の中身は少なくとも3通りです。
  - その時点で区域がなかった（後からできた政令市の区など、同じ年の総人口も「-」）：1,455セル・29区域
  - 住宅・土地統計調査の対象外の小さな町村（2008・2013年の住宅の項目）：6,410セル・671区域、2020年人口の中央値0.6万人
  - 政令市の区など（2010年以降の所得・財政の項目）：3,463セル・200区域（85%が政令市の区）
  - 一方、数字の 0 は本当の 0 でした（避難指示区域の総人口、出生がなかった村、保育所のない町など）。
- **T4 人口動態の「…」**：記号は「…」だけで、「-」も数字の 0 も1つもありません。死亡数の「…」は、5年間の死亡数500人未満の市区町村ではすべての行に（1行あたり17.2個）、1万人以上ではどの行にもありませんでした。0 も「…」に含まれている可能性が高いと考えていますが、表の中だけでは確かめられません（推測です）。
- **T2 家計調査の「-」は「計算できない」**：増減率の「-」は、比べる前の年がない最初の12か月（5,608セル）と、分類の基準を改めた年（2005・2010・2015年など）に集まり、11〜62の行は全部「-」でした。支出金額から前年同月比を計算し直すと、公表の名目増減率と0.1pt以内で全セル一致しました。和服の2014年1月の名目増減率が「1,660.50」と桁区切りのカンマつきで入っており、数値として読み込むときに落とされやすい形でした。
- **R4 桁ずれ**：総人口の前回比が3倍・3分の1を超えたのは13セル（7町村）で、すべて原発事故の避難指示区域でした。1.5倍に広げると女川町（震災）と球磨村（豪雨）が加わり、どれも実際の出来事でした。入力の誤りとみられる桁ずれは見つかりませんでした。
- **R5 単位**：課税対象所得【千円】÷納税義務者で、1人あたり所得の中央値は 2020年 約282万円。100万〜2,000万円の外に出る区域はありませんでした。【千円】を円と読み違えると中央値は2,816円になります。
- **扱いを間違えたときのずれ**
  - T3：「-」を欠測として除くと、定点当たりの平均はシーズンによって1〜47%大きく出ました。
  - T1：財政力指数の「-」を 0 として含めると、2020年の平均は 0.513 → 0.461 に下がりました。
  - T5：労働力率を、分母に「不詳」を含めて計算すると、公表値との差は中央値で2.85pt でした（公表の定義は不詳を除く）。
  - T1：年齢3区分の合計と総人口の差（年齢不詳）は、2005年の中央値0.003%から2020年は0.6%に増え、最大25%の区域がありました。

## 頑健性

`results/robustness.csv`

- R4 の閾値を 1.25〜10倍に変えた：3倍以上では見つかるのは避難指示区域だけ。1.5倍で女川町・球磨村が加わり、1.25倍では14区域が加わる（人口の変化が大きい市町村）。
- R6 の許容差を 0.05〜0.5pt に変えた：0.05pt では 37セルが外れ、0.1pt 以上ではすべて一致（実額が円単位で丸められているため）。
- T3 の合計チェックを、定点の定義が変わった2025年14週の前と後に分けた：どちらも全週で一致。
- T4 の SMR の表（第6表）でも、「…」がある行は死亡数500人未満の地域に集中（326行中79行、2,000人以上では0行）。
- T5 の許容差を 0.5人から1.5人に広げても、合わない行は0。

## 言えないこと

- 記号の意味を「データの中の手がかり」から推定しています。正式な意味は各統計の凡例・利用上の注意で確かめる必要があります。
- T4 の「…」に 0 が含まれるかどうかは、表の中だけでは確かめられません。
- 5つの表で見つからなかった誤りが、ほかの表にないとは言えません。
- 点検したのは記号・合計・桁・単位で、調査の誤差や定義の違いそのものは対象外です。
