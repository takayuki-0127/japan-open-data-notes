# F02 コロナがなかったら、出生数は何人多かったのか？（時系列の反実仮想）

看板記事シリーズの2本目です。2010〜2019年の月別出生数から「コロナがなかった場合」の出生数を3つのモデルで予測し、2020〜2025年の実際の値と比べます。前年比ではなく、もともとの減少の流れを延ばした値と比べ、予測のぶれを区間で示すのがポイントです。

## 問い

2020年以降の出生数の減少のうち、コロナによって上乗せされた分はどれくらいか。実際の値は「なかった場合」の予測区間から外れたか。

## データ

厚生労働省「人口動態統計」確定数（e-Stat）。詳しくは `data/raw/SOURCES.md`。

| データ | 期間 |
|---|---|
| 全国の月別出生数 | 2000〜2025年 |
| 全国の届出月別婚姻件数 | 2000〜2025年 |
| 都道府県別の年間出生数 | 2010年、2014〜2025年 |

整形後：`data/monthly.csv`（312か月）、`data/pref_annual.csv`。

## 手法

| 項目 | 内容 |
|---|---|
| 予測する値 | log(1日あたり出生数)。月の日数（うるう年を含む）で割ってから予測し、出生数に戻す |
| 学習期間 | 2010年1月〜2019年12月（頑健性：2005〜2019年、2012〜2019年） |
| 予測期間 | 2020年1月〜2025年12月（72か月） |
| モデル | SARIMA(1,1,1)(0,1,1)12、ETS（加法誤差・減衰トレンド・加法季節）、Prophet（年周期）、3モデルの経路をまとめた「3モデル統合」 |
| 区間 | 各モデルで将来の経路を2,000本シミュレーションし、2.5〜97.5%点。累積の差は経路ごとに足してから区間をとる |
| 婚姻を通じた分 | 月次 ARIMAX（12か月婚姻件数の log を9〜15か月ずらして投入）は係数がはっきりせず参考扱い。年単位で log 出生数 ＝ a ＋ b·log 前年婚姻件数 ＋ c·年（2002〜2019年、HAC標準誤差）を推定し、婚姻が2010〜2019年の傾向どおりだった場合との差を計算 |
| 都道府県 | 年単位の簡易版。2014〜2019年の log 出生数に直線を当てはめ、2020〜2022年を予測（頑健性：2010年も加える） |
| バックテスト | 2010〜2014年で学習して2015〜2019年を予測。1年先だけを当てる版（学習期間を1年ずつのばす）も |
| 頑健性 | 学習期間2通り、日数調整なし、の3通り × 4モデル |

## 主な結果（基本＝SARIMA、2010〜2019年学習）

| 指標 | 実際 | なかった場合 | 差（95%区間） |
|---|---|---|---|
| 2021年1月 | 61,040 | 67,424 | −6,384（区間 63,569〜71,540 の外、−9.5%） |
| 2020年12月〜2021年2月 | 185,282 | 196,578 | −11,296（−21,882〜−1,881） |
| 2021年3〜6月 | 271,336 | 263,509 | +7,827（−8,557〜+22,824） |
| 2020〜2022年 | 2,423,216 | 2,397,540 | +25,676（−127,499〜+155,935） |
| 2020〜2025年 | 4,507,947 | 4,512,506 | −4,559（−557,132〜+421,672） |

- 72か月のうち95%区間の下に外れたのは2021年1月だけ（上に外れたのは2020年4月）
- 3モデル統合：2020年12月〜2021年2月 −12,409（−26,586〜−1,637）、2020〜2022年 +3,820（−200,064〜+184,096）
- 頑健性：16通り（4設定×4モデル）中15通りで2021年1月が区間の下。2020年12月〜21年2月の差は −5,883〜−23,463 で、11通りで区間がゼロより下。2020〜2022年の累積がゼロをまたがないのは「2005〜2019年学習の ETS」の1通りだけ
- 婚姻：2020年は 525,507件で、2010〜2019年の傾向（578,016件、95%予測区間 554,911〜602,083）の下。2020〜2022年で傾向より計 172,050件少ない。出生数÷前年の婚姻件数は2010〜2018年に1.50〜1.57、2021年1.54・2022年1.54
- 婚姻の弾力性 0.91（95%CI 0.46〜1.35）。2020〜21年の婚姻が傾向どおりなら、2021〜22年の出生は計 167,369人多い計算（係数の不確実性のみの区間 88,611〜235,799）。出生数だけのモデル（2019年の急減を延長）とは基準が違うため一致しない
- 都道府県（2014〜2019年学習）：2020〜2022年は45都道府県で予測より少なく、中央値 −2.6%。区間の外は栃木（−4.8%）と北海道（−3.3%）。2010年を加えると中央値 −5.6%・29県が区間の外。順位相関 0.80、東京はどちらでも最大の減少（−5.3% / −9.9%）
- バックテスト（2015〜2019年）：MAPE は SARIMA 3.4%、ETS 5.9%、Prophet 7.9%。5年合計の誤差 SARIMA +1.7%、95%区間の的中 85%。2019年は3モデルとも約3%多めに予測

結果の表は `results/`、図は `figures/`（f01〜f05）。

## 動かし方

```
pip install -r requirements.txt
sh src/run_all.sh
```

`data/raw/` の CSV から全部作り直します（1分ほど）。シミュレーションの乱数は固定しています。

## 注意

- 予測との差がすべてコロナのせいとは限りません。同じ時期の物価・働き方などの変化も入ります
- 言えるのは「実際が予測区間から外れたか」までです
- 婚姻の届出月は縁起のよい日（2019年5月の改元、2020年2月22日など）で大きく振れるため、月次では12か月合計を使いました
- 都道府県は年単位・少ない年数での簡易版で、学習期間の選び方に水準が強く左右されます
- 設計時に予定していた「確定数と概数の比較」はしていません（全期間を確定数でそろえました）
