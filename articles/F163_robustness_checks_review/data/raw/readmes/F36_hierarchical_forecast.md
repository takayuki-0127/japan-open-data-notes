# F36 全国と47都道府県の予測を、足し算が合うようにそろえると？（階層時系列予測の整合）

看板記事 F36。観光庁「宿泊旅行統計調査」の延べ宿泊者数を、全国・10地方・47都道府県の58系列について別々に予測すると、47都道府県の合計が全国の予測と合わない。これを「足し算が合う」ようにそろえる6つの方法（整合なし・ボトムアップ・トップダウン・OLS・WLS・MinT）で、段ごとの予測精度がどう変わるかをローリング予測で比べた。

## 問い

- 全国・地方・都道府県を別々に予測すると、合計はどれくらい合わないか
- 足し算が合うようにそろえると、精度は上がるのか、下がるのか。全国・地方・都道府県のどの段で変わるのか
- コロナ後（2025年）でも同じか

## データ

| データ | 内容 |
|---|---|
| 観光庁「宿泊旅行統計調査」推移表 | 都道府県×月の延べ宿泊者数（総数・日本人・外国人）、2011年1月〜2025年12月の確定値。F04 で作った縦長の表をそのまま使う（`data/raw/lodging_pref_monthly_2011_2025.csv`） |

- 階層：全国（1）→ 地方（10、観光庁の地方運輸局の区分にそろえた。`data/regions.csv`）→ 都道府県（47）＝58系列
- 公表の「全国」と47都道府県の合計の差は最大70人泊（四捨五入の差）で、足し算は合っている（`data/check_national.csv`）。分析では47都道府県から上の段を足し上げて作った

## 手法

| 段階 | 内容 | コード |
|---|---|---|
| 基本の予測 | 58系列それぞれに、対数をとった値で ETS（減衰トレンド＋加法の季節、statsmodels）を当てはめ、12か月先まで予測して戻す | `common.fit_forecast` |
| 整合（そろえ方） | 予測 ŷ を、足し算の行列 S と G で S G ŷ に置き換える。G の作り方で6通り | `common.G_matrix` |
| 　整合なし | 別々の予測そのまま（合計は合わない） | |
| 　ボトムアップ | 47都道府県の予測だけを使い、上の段は足し上げる | |
| 　トップダウン | 全国の予測を、直近36か月の「全国に占める割合」の平均で47都道府県に配る | |
| 　OLS | 全系列の重みを同じにした最小二乗の整合 | |
| 　WLS（分散） | 当てはめの残差の分散で重みをつけた整合 | |
| 　MinT | 残差の共分散（対角へ縮小推定）を使う最小トレース整合（Wickramasuriya ほか 2019） | |
| 評価 | ローリング予測（拡張窓）：起点 2017年12月〜2018年12月の13回、1〜12か月先。MASE（学習期間の季節ナイーブの平均絶対誤差で割る）を段ごとに平均 | `03_分析.py`・`04_図.py` |

## 主な結果

### 1. 別々に予測すると、合計は合わない

- 47都道府県の予測の合計は、全国の予測より平均 +1.2%（起点13回×12か月の中央値の絶対値 1.0%、最大 5.5%、人数にすると中央値で約46万人泊）ずれた（`results/gap_by_horizon.csv`）

### 2. 段ごとの精度（2018〜19年、1〜12か月先の平均の MASE）

| 段 | 整合なし | ボトムアップ | トップダウン | OLS | WLS（分散） | MinT |
|---|---|---|---|---|---|---|
| 全国 | 1.861 | 1.584 | 1.861 | 1.833 | 1.618 | **1.573** |
| 地方 | 1.461 | 1.434 | 2.035 | 1.645 | 1.442 | **1.410** |
| 都道府県 | 1.164 | 1.164 | 1.592 | 1.297 | 1.168 | **1.157** |
| 58系列全体 | 1.227 | 1.217 | 1.673 | 1.366 | 1.223 | **1.208** |

- MinT は、整合なしと比べて全国で −15.5%、地方で −3.4%、都道府県で −0.6%、全体で −1.5%
- 全国の予測が良くなったのは、都道府県の情報を足し上げた分が効いたため（ボトムアップでも −14.9%）。都道府県の段はほとんど変わらない
- トップダウンは全体で +36%、OLS は +11% と悪くなった。全国の予測を固定の割合で配ると、県ごとの季節の形の違いが消えるため
- 起点13回のうち MinT が整合なしより良かった回数：全国13回、地方12回、都道府県8回（`results/mint_win_rate_by_origin.csv`）
- 予測の長さ別（全国、整合なし → MinT）：1か月先 1.026 → 0.738、3か月先 1.540 → 1.216、12か月先 2.538 → 2.247
- 参考：季節ナイーブ（12か月前と同じ）の MASE は全国 2.24、都道府県 1.29 で、ETS の基本の予測より悪い

### 3. 都道府県ごとの変化

- MinT で良くなった県 28、悪くなった県 19。中央値 −0.6%、範囲 −7.3%〜+7.2%（`results/pref_change_mint_vs_base.csv`）

### 4. コロナ後とコロナ直前

- コロナ後（2023年1月から学習、起点 2024年12月〜2025年11月、評価は2025年12月まで）：MinT は全国 −4.4%、地方 −0.9%、都道府県 −0.4%、全体 −0.5%。トップダウンは +43%
- コロナ直前の起点（2019年12月）から2020年を予測すると、MASE は全体で 6.4（2018〜19年の約5倍）。どのそろえ方でも 6.40〜7.12 で、整合で救えるものではない（`results/mase_covid2020.csv`）

## 頑健性（58系列全体の MASE、整合なし＝1）

| 設定 | ボトムアップ | トップダウン | OLS | WLS（分散） | MinT | 全国の MinT |
|---|---|---|---|---|---|---|
| 基本（総数・ETS・2011年から学習） | 0.992 | 1.364 | 1.114 | 0.997 | 0.985 | 0.845 |
| 学習を2014年から | 1.000 | 1.357 | 1.054 | 1.000 | 0.992 | 0.909 |
| 日本人のみ | 0.974 | 1.368 | 1.175 | 0.989 | 1.013 | 0.820 |
| 外国人のみ | 0.992 | 1.352 | 1.080 | 0.997 | 0.991 | 1.051 |
| 基本の予測を ARIMA に（起点5回） | 0.998 | 1.466 | 1.020 | 0.999 | 1.003 | 0.969 |
| コロナ後（2023年から学習） | 1.004 | 1.426 | 1.092 | 0.996 | 0.995 | 0.956 |

- トップダウンはどの設定でも +35〜47%、OLS は +2〜18% 悪くなる
- MinT・WLS・ボトムアップは全体で ±3% 以内。全国の段は、外国人のみ（+5.1%）を除いて MinT で 3〜18% 良くなる
- 日本人のみでは、MinT は都道府県の段で +3.2% 悪くなり、全体ではボトムアップ（−2.6%）がいちばん良い。どのそろえ方が最良かは、データで入れ替わる
- 予測の長さ別（1・3・12か月先）は `results/robustness_relative_mase.csv`

## 動かし方

```bash
pip install -r requirements.txt
cd src
bash run_all.sh      # 01 取得 → 02 整形 → 03 分析（2コアで約40分）→ 04 集計と図
```

- `03_分析.py` に設定名を渡すと、その設定だけ動く（例：`python3 03_分析.py main`）
- 結果の誤差は `results/errors_<設定>.csv.gz`（起点・何か月先・系列・段・そろえ方ごとの絶対誤差と MASE の分母）

## 言えないこと

- コロナのような大きな変化は、どのそろえ方でも当たらない（2020年の MASE は通常の約5倍）
- 全国の予測が良くなった理由は「都道府県の情報が入るから」と考えているが、2018〜19年の全国の ETS がたまたま外れやすかった可能性もある（推測）。外国人のみでは逆に悪くなった
- 地方の区分を変えると（例：8地方区分）、地方の段の結果は変わりうる
- 予測モデルは ETS（と ARIMA）だけで、機械学習のモデルや説明変数（為替・祝日など）は入れていない
