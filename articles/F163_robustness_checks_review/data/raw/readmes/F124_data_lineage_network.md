# F124 同じデータを何本の記事で使い回したか？ 118本の看板記事のデータの系譜（二部グラフ・ネットワーク）

看板記事 F124。これまでに作った看板記事 F01〜F120（F24・F30 を除く118本）の README とコードから、「どの記事がどのデータを使ったか」「どの記事が前の記事のデータを読み込んだか」を取り出し、記事とデータのつながりをネットワークとして描いた。よく使ったデータ、使い回しの広がり方、使い回した記事で出やすかった注意点をまとめる。新しいデータは取っていない（材料はこのリポジトリの README・コード・F122 の分類だけ）。

F30（全記事の再現チェック）とは重ならないよう、ここでは「コードが動くか」ではなく「データがどこから来てどこへ流れたか」だけを扱う。

## 問い

- 118本で、どのデータを何本の記事で使ったか。少数のデータに集中しているか
- 前の記事のデータを使い回した記事はどれくらいあり、それは後半ほど増えたか
- 使い回しのつながりは、どこが源流で、どこまで長くつながったか
- 使い回した記事は、そうでない記事と比べて、どんな注意点（「言えないこと」）を書きやすかったか

## データ

- 看板記事 F01〜F120 の README（`articles/F*/README.md`）のうち、見出し「データ」「出典」「言えないこと」「設計から変えたこと」の本文（`data/readme_sections.json`、118本）
- 同じ記事の `src/` のコード（別の記事のフォルダ名 `F\d+_英字` を読み込んでいるかを見るため）
- F122 が README と作業ログから作った、項目ごとのカテゴリ分類（`data/f122_items_labeled.csv`。F122 の `data/items_labeled.csv` の写し）
- F24・F30 は看板記事の形式が違うため、F122 と同じく対象外

## 手法

1. 取り出し（`src/01_取得.py`）：各記事の README の見出しで本文を区切り、「データ」「出典」の本文とコードを集める
2. データの名寄せ（`src/02_整形.py`）：53のデータ（10のグループ）について、表記ゆれを含む正規表現の辞書を作り、「データ」「出典」の本文に出てくるものを記事×データのつながりとした（323本）。記事ごとの平均は 2.74 データ
3. 使い回しの判定：2通りで数えた
   - **ゆるめ（主）**：「データ」「出典」の本文に、ほかの記事の番号（F12 など）が出てくる。ただし「関連記事」のような参照だけの行は除く
   - **厳しめ**：コードが別の記事のフォルダを読み込んでいる
4. 集計（`src/03_分析.py`）：データの使用本数（次数）、データどうしの同時使用、記事→記事の有向グラフ（networkx）の源流・最長の連鎖・連結成分、番号帯ごとの使い回しの割合（Fisher の正確検定）、F122 のカテゴリとの比較（Fisher の正確検定、前半／後半で層別した Mantel–Haenszel）
5. 図（`src/04_図.py`）

## 結果

### 1. よく使ったデータは国勢調査（37本）。上位10のデータで、つながりの半分を占めた

| データ | 使った記事 |
|---|---|
| 国勢調査 | 37本 |
| 社会・人口統計体系 | 22本 |
| 人口動態統計 | 18本 |
| 労働力調査 | 17本 |
| 国土数値情報（行政区域） | 16本 |
| 消費者物価指数 | 16本 |
| 気象庁 過去の気象データ | 12本 |
| 国土数値情報（駅・DID・消防署） | 12本 |
| SSDSE | 11本 |
| 景気動向指数・景気基準日付 | 11本 |

- 53のデータのうち上位10で、つながり323本の半分を占めた。上位5つのどれかを使った記事は 61%
- 1本の記事でしか使っていないデータは 13
- グループで見ると、人口（51本）、地理・気象（35本）、地域統計（30本）、労働（24本）の順
- 一緒に使われやすい組み合わせは「国勢調査×社会・人口統計体系」（14本）、「国勢調査×国土数値情報（駅・DID・消防署）」（11本）、「気象×電力の需給実績」（9本）

### 2. 前の記事のデータを使い回した記事は 59%。後半ほど増えた

- ゆるめの定義で、69本（58.5%）が前の記事のデータを使い回していた（つながり141本）
- 番号帯ごとの割合：F01〜20 で 20%、F21〜40 で 44%、F41〜60 で 55%、F61〜80 で 80%、F81〜100 で 70%、F101〜120 で 80%
- 前半（F01〜F60）23/58本 と 後半（F61〜F120）46/60本 の差は、Fisher の正確検定で p=0.0001
- 厳しめの定義（コードが別の記事のフォルダを読む）では 37本（31.4%）。番号帯ごとに 0%・33%・10%・50%・45%・50% で、後半ほど多いのは同じ

### 3. 源流は F18（景気動向指数）と F12（物価）。最長の連鎖は5本

- ほかの記事に最も多く使われた記事（ゆるめ）：F18 が12本、F12 が11本、F03・F22 が7本、F01・F13・F20・F33 が6本
- 使い回しのグラフは循環のない有向グラフ（後の記事が前の記事を使うだけ）で、最大の連結成分に 91本が入る
- 最長の連鎖（ゆるめ）は F13→F18→F39→F43→F53、厳しめでは F22→F67→F92→F108

### 4. 使い回した記事は、「一般化の限界」と「不確実性」を書きやすかった

F122 のカテゴリ分類（記事にそのカテゴリが1回でも出たか）を、使い回した記事 69本とそれ以外 49本で比べた。

| 言えないこと／設計から変えたこと | 使い回した | それ以外 | p |
|---|---|---|---|
| 既存データの再利用（設計の変更） | 61% | 12% | <0.001 |
| 期間・ほかの場面への一般化 | 71% | 47% | 0.012 |
| 不確実性・検出力 | 52% | 31% | 0.024 |
| 前提・設定への依存 | 58% | 39% | 0.061 |
| 定義・測定のずれ | 48% | 61% | 0.19 |
| 集計単位・個人には当てはまらない | 45% | 61% | 0.095 |

- 「既存データの再利用」が設計の変更として多いのは、定義からほぼ当然（使い回しの確認として載せた）
- 前半／後半で層別しても、一般化（オッズ比 2.39、p=0.031）と不確実性（2.41、p=0.032）の差は残った。後半ほど使い回しも「言えないこと」の項目も増えているので、その分を取り除いても残る、という意味
- データの大きさ（data フォルダの容量の中央値）は、使い回した記事 1.85MB、それ以外 2.5MB で、差ははっきりしない（Mann–Whitney p=0.94）

### 5. 使い回しでつまずいた点（README の本文から）

- **つないだ表の引き継ぎ**：F76 は F71 で作った県民経済計算（基準年の違う7つの表を、つなぎ目の段差を消してつないだもの）をそのまま使った。つなぎ方の前提も一緒に引き継ぐことになる
- **公表時点（ヴィンテージ）**：F90 は F18 で取った景気動向指数を使ったが、「公表の遅れは再現しているが、改定は再現していない」と書いている（改定の影響は F50 で扱った）
- **共有の基準**：景気基準日付（山と谷）は F18・F35・F50・F53・F63 で共通に使っている。内閣府が日付を見直すと、5本の結果に一度に響く
- **定義の引き継ぎ**：F105 は F28 と同じ「打ち切り」の定義をそのまま使った。定義を揃えられる反面、元の定義の弱点も揃う
- 本文から拾った使い回しの記述は `data/reuse_issue_sentences.csv`（12行）

## 頑健性

| 確かめたこと | 結果 |
|---|---|
| R1 名寄せを「出典」の本文だけにする | データの使用本数の順位相関 0.94（Spearman）、上位5つは同じ |
| R2 データでなくグループで数える | 人口・地理・地域統計が上位3つで変わらない |
| R3 使い回しを厳しめ（コードがフォルダを読む）にする | 31.4%（ゆるめ 58.5%）。後半ほど多い傾向は同じ |
| R4 まとめ記事（F89・F100・F118〜F120）を除く | 使い回しの割合 56.6%、番号帯ごとの増え方も同じ |
| R6 前半／後半で層別（Mantel–Haenszel） | 一般化 OR 2.39（p=0.031）、不確実性 OR 2.41（p=0.032）、定義のずれ OR 0.48（p=0.076） |

「国勢調査が最も多い」「後半ほど使い回しが増えた」は、どの数え方でも変わらなかった。使い回しの割合そのもの（31〜59%）は定義で大きく変わる。

## 設計から変えたこと

- 「全記事」ではなく、形式が揃っている看板記事 F01〜F120（F24・F30 を除く118本）にした
- データの特定は人手ではなく、正規表現の辞書による名寄せにした。F56・F99 は辞書のどのデータにも当たらなかった
- 使い回しを1通りに決められなかったため、ゆるめ（README の記述）と厳しめ（コードの読み込み）の2通りで数えた
- 「つまずいた点」は、F122 の分類と結びつけて数え、具体例は README の本文から拾った

## 言えないこと

- データの名寄せは辞書によるもので、辞書にないデータ（1回しか使っていない細かい統計など）は数に入っていない。辞書の作り方で本数は変わる
- 使い回しの割合は定義で 31〜59% と大きく変わる。どちらが「正しい」使い回しかは決めていない
- 使い回した記事で「一般化」「不確実性」を書きやすかったのは関連で、使い回したから注意点が増えた、とは言えない。後の記事ほど扱う問いが複雑になった分も含む（推測）
- README に書いた数を数えているので、書いていない使い回しや、書いていないつまずきは拾えていない
- 自分1人の118本の記録で、ほかの分析者のプロジェクトに同じ傾向があるかは分からない
