# F89 最低賃金の効果、これまでの推定をまとめると？ 3本の記事のメタ分析

## 問い
このシリーズでは、最低賃金と雇用を3本の記事で別々の方法で調べた（F01 県パネルの固定効果、F15 県境をはさむ隣接市町村の比較、F17 機械学習で調整する DML）。どれも単独では「差は見えなかった」。3本をまとめると、何が言えて、何がまだ言えないのか。F26（検出力の記事）の考え方で、まとめたあとに見つけられる大きさも確かめる。

## データ
- これまでの記事の results/ にある推定値（data/raw/ にコピー）：F01（twfe・did・robustness・first_stage・panel）、F15（estimates・robustness）、F17（main・robustness）、F26（過去の記事の MDE）
- 単位をそろえる（data/estimates_common_unit.csv、雇用17個・失業率6個）
  - 雇用：**弾力性**（最低賃金が1%上がると、就業が何%変わるか）
    - F01：log(最低賃金) の係数 β（就業率の%pt）÷ 就業率の平均（2008〜19年 57.31%）
    - F15：もともと弾力性
    - F17：「1単位」が最低賃金の何%にあたるか（1÷2015年の bite 0.730 = 1.370%）で割り、就業率の平均で割る
  - 失業率：最低賃金10%上昇あたりの%ポイント
- 各記事の「主な推定」を1つずつ選ぶ（F01 基本の固定効果 2008〜19年、F15 全産業、F17 ATE）。残りは仕様の組み合わせ（頑健性）に使う。
- F01 の主な比較（bite の高低 × 2016年以降の差の差）は、2つのグループで最低賃金の上がり方がほぼ同じ（2015→19年 11.76% と 11.87%）ため弾力性に換算できず、統合には入れない。

## 手法
- 逆分散の重みによる固定効果、DerSimonian–Laird と REML のランダム効果、研究が少ないときの Hartung–Knapp–Sidik–Jonkman（HKSJ）の区間
- 異質性：Cochran の Q、I²、τ²
- 記事の入れ方：1本ずつ外す。F01 と F17 は同じ県×年のデータを使うので、2本を相関 ρ（0.5・0.8・1.0）を仮定して1本にまとめた場合
- 推定値の選び方：F01 6通り × F15 6通り × F17 5通り = 180通りをすべて統合する（spec curve）
- 出版バイアスの見方：推定値と標準誤差の図（漏斗図）。研究が3本では非対称は判定できないので、仕様違いを含む17個で Egger 回帰を「参考」として出す
- 統合後に見つけられる大きさ：MDE80 = 2.8 × 統合の標準誤差、弾力性 −0.1・−0.2・−0.3 での検出力、あと何本の研究が要るか

## 主な結果
| | 推定値 | 95%区間 | 備考 |
|---|---|---|---|
| F01（固定効果） | −0.00 | −0.23〜+0.23 | 重み74% |
| F15（隣接市町村） | +0.26 | −1.55〜+2.06 | 重み1% |
| F17（DML） | −0.12 | −0.51〜+0.27 | 重み25% |
| **統合（固定効果）** | **−0.03** | **−0.22〜+0.17** | Q=0.34（p=0.84）、I²=0% |
| 統合（ランダム効果・HKSJ） | −0.03 | −0.46〜+0.40 | τ²≈0 |
| 失業率（10%上昇あたり、F01・F17） | +0.28%pt | −0.13〜+0.69 | I²=0% |

- 3本の答えは食い違っていない（I²=0%）。ただしそれは「どれも区間が広い」からでもある。
- 統合しても区間は 0 をまたぎ、海外でよく報告される範囲（0〜−0.3）とも重なる。「影響はない」とも「この程度の影響がある」とも言えない。
- 統合後の MDE80 は 0.28。本当の弾力性が −0.3 なら見つけられる確率は85%、−0.2 なら52%、−0.1 なら17%。
- −0.1 を80%の確率で見つけるには、F01 と同じ精度の独立な研究が全部で約11本（あと約10本）要る。F15 の精度なら約670本。
- 重みの74%は F01 にかかっていて、統合値はほぼ F01 で決まる。

## 頑健性
1. **モデルの選び方**：固定効果・DL・REML は τ²≈0 のためほぼ同じ値（−0.027）。HKSJ の区間は −0.46〜+0.40 と広くなる。
2. **記事の入れ方**：1本ずつ外すと −0.10〜+0.00。F01 を外すと区間が −0.48〜+0.28 に広がる。
3. **F01 と F17 の重なり**：ρ=0.5〜1.0 で1本にまとめると統合値は −0.02〜−0.03、区間は最大 −0.29〜+0.24 に広がる（MDE80 0.33〜0.38）。
4. **推定値の選び方（180通り）**：統合値は −0.21〜+0.07（中央値 −0.06）。固定効果の区間が 0 をまたがないのは20%の組み合わせで、すべてマイナス側で、F01 の県別トレンド入りの推定を選んだとき（主に2008〜25年版）。HKSJ の区間ではどの組み合わせも 0 をまたぐ。I² が50%以上になるのは28%（F15 の精度の高いプラスの推定、20km 以内のペア版や卸売・小売を選んだとき）。
5. **出版バイアスの見方**：精度の低い F15 の推定ほどプラス側に散らばり、Egger の切片は +1.14（p=0.008）。ただし17個は同じ記事の仕様違いで独立でなく、選んで出した結果でもない（このシリーズは結果にかかわらず全部出している）ので、出版バイアスの証拠とは読まない。

## 言えないこと
- 3本は独立な研究ではない。F01 と F17 は同じ県×年のデータを使い、F15 も同じ期間の最低賃金の上がり方に頼っている。統合の区間は実際より狭く見えている可能性がある（頑健性3）。
- 単位の換算は平均の就業率と平均の bite を使った近似で、県や年によって換算の係数は違う。
- 「区間が 0 をまたぐ」ことは「影響がない」ことではない。弾力性 −0.1 程度の影響は、今のデータでは見分けられない。
- 研究が3本では、出版バイアスや異質性を検定する力はほとんどない。
- 最低賃金の引き上げの是非を判断するものではない。就業以外（労働時間・賃金の分布・事業所の数）は扱っていない。

## 設計からの変更
- F26 は推定値を持たない（検出力の記事）ので統合には入れず、MDE の考え方と比較の基準として使った。
- F01 の主な比較（差の差）は換算できないので、同じ記事の log(最低賃金) の固定効果を F01 の代表にした。
- 「記事の入れ方」として、F01 と F17 のデータの重なりを相関 ρ で扱う比較と、180通りの組み合わせ（spec curve）を足した。
- 研究が少ないので HKSJ の区間を足した。
