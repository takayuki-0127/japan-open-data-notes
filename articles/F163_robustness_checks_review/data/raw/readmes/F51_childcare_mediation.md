# F51 保育所の整備は、出生率に「女性の就業」を通じて効いたのか？（媒介分析）

note の看板記事 F51 のコード・データ・図です。

## 問い

保育所に通う子どもが増えた市区町村で、①女性の労働力率が上がり、②それが出生率を押し上げる、という「経路」はデータで見えるか。保育所の効果のうち、女性の就業を通る部分（間接効果）と通らない部分（直接効果）に分けると、それぞれどれくらいか。

## データ

| 役割 | 変数 | 出典 |
|---|---|---|
| 処置 T | 保育所等に通う子ども（0〜5歳100人あたり）の増加、2010→15年。10人単位 | 社会・人口統計体系 市区町村データ（F16 で取得） |
| 媒介 M | 女性（15歳以上）の労働力率の変化、2010→15年（pt） | 国勢調査（同上） |
| 結果 Y | 合計特殊出生率（ベイズ推定値）の変化、2013〜17年 → 2018〜22年 | 人口動態保健所・市区町村別統計（F20 で取得） |
| 条件 X | F16 と同じ80列（人口・年齢構成・世帯・産業・所得・学歴・財政・前の5年の傾向・県ダミー）＋2013〜17年の出生率 | 同上 |

- 対象は両方のデータがそろう 1,586 市区町村です（政令市は区ごと、0〜5歳が100人未満の町村は F16 と同じく除外）。
- 新しいデータは取っていません。`data/raw/` に F16・F20 のデータのコピーがあります。
- 時間の順番は「処置と媒介（2010→15年）→ 結果（2013〜17年 → 2018〜22年）」です。

## 手法

1. **積の方法**：M = a·T + X、Y = c′·T + b·M + X、Y = c·T + X を最小二乗法で推定。間接効果 = a×b、直接効果 = c′、総合効果 = c。区間は市区町村を単位にしたブートストラップ1,000回（県を単位にした版も）
2. **statsmodels の Mediation**（Imai らのシミュレーション法、500回）で同じ値になるかを照合
3. **感度分析**：「労働力率と出生率の両方を動かす見えない要因」があったとき（媒介モデルと結果モデルの誤差の相関 ρ）、間接効果がどう変わるか（Imai, Keele & Yamamoto 2010 の線形モデルの式）
4. **頑健性**：媒介を就業率にする、県ダミーを外す、前の出生率で調整しない、人口1万人以上だけ、外れ値を除く、条件を最小限にする、県でまとめたブートストラップ。人口規模3区分でも推定

## 主な結果

単位：出生率は ‰ポイント（＝合計特殊出生率 0.001）、処置は「在所児+10人（0〜5歳100人あたり）」。

| 効果 | 推定値 | 95%区間 |
|---|---|---|
| a：処置 → 労働力率 | +0.046 pt | −0.014〜+0.106 |
| b：労働力率1pt → 出生率 | +5.86‰ | +1.83〜+9.97 |
| 間接効果 a×b | **+0.27‰** | −0.08〜+0.72 |
| 直接効果 c′ | −4.4‰ | −8.0〜−0.8 |
| 総合効果 c | −4.2‰ | −7.8〜−0.6 |

- この期間、出生率は平均 1.520 → 1.420（−0.099）と下がりました。
- **女性の就業を通る経路はプラスだが、とても小さい**：在所児+10人で出生率 +0.00027。区間は0をまたぎます（県でまとめたブートストラップだと +0.01〜+0.75 でわずかに0の上）。statsmodels の Mediation も +0.27‰（−0.19〜+0.87）で一致。
- 労働力率が上がった町ほど出生率の下がり方が小さい（b はプラスではっきり）一方、処置 → 労働力率（a）が小さいため、積は小さくなります。
- **総合効果はマイナス**：在所児が増えた町ほど、出生率はむしろ下がっていました。条件の入れ方で区間が0をまたぐ設定も多く（基本以外の7設定中6）、安定しません。保育所を増やしたこと自体が出生率を下げたのではなく、保育の需要が急に増えた町（若い世帯が移ってきた都市部など）を拾っている可能性がありますが、推測です。
- **感度分析**：誤差の相関が ρ = 0.085 あるだけで、間接効果は0になります。小さな交絡で消える大きさです。
- **人口規模別**：a は人口の大きい町で +0.175（+0.048〜+0.32）と大きく、小さい町では +0.038（0をまたぐ）。間接効果の区間はどの規模でも0をまたぎます。

### 頑健性（間接効果、‰）

| 設定 | n | 間接効果 | 95%区間 | 総合効果 |
|---|---|---|---|---|
| 基本 | 1,586 | +0.27 | −0.08〜+0.72 | −4.2 |
| 媒介を就業率に | 1,586 | +0.27 | −0.06〜+0.69 | −4.2 |
| 県ダミーなし | 1,586 | +0.41 | +0.01〜+0.93 | −2.2 |
| 前の出生率で調整しない | 1,586 | +0.35 | −0.08〜+0.89 | −3.1 |
| 人口1万人以上 | 1,227 | +0.35 | −0.13〜+1.02 | +0.1 |
| 外れ値を除く | 1,523 | +0.35 | −0.08〜+0.94 | −2.5 |
| 条件は県ダミーと前の出生率だけ | 1,586 | +0.25 | −0.02〜+0.65 | −2.1 |
| 県でまとめたブートストラップ | 1,586 | +0.27 | +0.01〜+0.75 | −4.2 |

間接効果は8設定すべてで +0.25〜+0.41‰ のプラスに収まりますが、区間が0を外れるのは2設定だけです。

## 言えないこと

- **因果の経路は証明できない**：媒介分析は「処置と媒介、媒介と結果のあいだに見えない交絡がない」という強い前提に立っています。感度分析のとおり、この前提が少し崩れるだけで間接効果は消えます
- 市区町村の集計値なので、「保育所を使えた女性が働き、その女性が子どもを産んだ」という個人の経路は分かりません
- 処置は「定員」ではなく「実際に通っている子ども」です。需要が増えた結果として在所児が増えた（逆向き）分を切り分けられません
- 出生率は小さい町ほどベイズ推定で県の値に寄せられているので、小さい町の変化は小さめに出ます
- 女性の労働力率は15歳以上全体で、子育て世代だけの値ではありません
