# F121 「最低賃金と雇用」に、記事はどう答えたか？（手法ごとのまとめ直し）

看板記事 F121。最低賃金と雇用を扱った看板記事（F01 差の差・F15 県境のペア比較・F17 因果フォレスト・F89 メタ分析、F26 の検出力の考え方）を、**同じ単位（雇用の弾力性：最低賃金が1%上がると就業が何%変わるか）にそろえて横並びにし、手法ごとに「何を比べたか」「どこまで見えるか」を整理する**。F89（3本の統合）と重ならないよう、手法の違いと検出力を中心にする。新しいデータは取らない。

## 問い
- 手法を変えると、「最低賃金の引き上げで雇用は減ったか」の答えは変わったのか
- それぞれの手法は、海外でよく報告される大きさ（弾力性 0〜−0.3）の効果を見つけられる設計だったのか
- 区間の広さを決めていたのは何か（比べるのに使えた最低賃金の差の大きさ）

## データ
これまでの記事の data/・results/ をそのまま使う（`data/raw/`）。
| ファイル | 元の記事 | 中身 |
|---|---|---|
| F01_panel.csv | F01_minimum_wage_did | 47都道府県×年の就業率・失業率・log 最低賃金 |
| F15_pairs.csv・F15_muni.csv | F15_border_minwage | 県境で接する市区町村のペアと、2015→20年度の最低賃金の上昇率 |
| F17_panel.csv | F17_minwage_causal_forest | 47都道府県×年の前年差・bite（最低賃金÷平均賃金） |
| F26_past_flagships.csv | F26_power_simulation | 過去記事の MDE |
| estimates_common_unit.csv・constants.json・F89_summary.json | F89_minwage_meta | 弾力性にそろえた推定値（17通り）と換算に使う定数、メタ分析の結果 |

## 手法
1. **単位をそろえる**：F89 と同じ換算で、各記事の係数を雇用の弾力性にする（F01：係数÷就業率の平均、F15：ペアの差の弾力性、F17：効果÷(1/bite)÷就業率の平均×100）
2. **検出力**：各記事の主な推定の標準誤差から、弾力性 −0.1・−0.2・−0.3 を「差がある」と見つけられる確率（両側5%）と、80%で見つけられる最小の効果（MDE80）を計算
3. **識別に使えた変動**：各記事が比べるのに使えた最低賃金の差を、同じ物差し（log 最低賃金の標準偏差、%）で測る（F01：県と年の効果を除いた残差、F15：接するペアの中の上昇率の差、F17：上昇率の年平均からのずれ）
4. **記事の中のばらつき**：同じ記事の仕様違い（期間・産業・調整の仕方）で答えがどれだけ動いたか

## 結果
### 主な推定（弾力性、95%区間、MDE80）
| 記事 | 手法 | 推定 | 95%区間 | MDE80 | −0.1の検出力 | −0.3の検出力 |
|---|---|---|---|---|---|---|
| F01 | 県×年の固定効果（差の差） | −0.001 | −0.23〜+0.23 | 0.32 | 14% | 74% |
| F15 | 県境のペア比較（724組） | +0.26 | −1.55〜+2.06 | 2.58 | 5% | 6% |
| F17 | 因果フォレスト（前年差） | −0.12 | −0.51〜+0.27 | 0.56 | 8% | 33% |
| F89 | 3本の統合（固定効果） | −0.03 | −0.22〜+0.17 | 0.28 | 17% | 85% |

- 手法を変えても、主な推定はどれも「0をまたぐ」で、答えは変わらなかった。ただし、どの記事も弾力性 −0.1 の効果を見つけられる確率は2割未満で、−0.3 でも80%に届いたのは3本を統合した F89 だけ（85%）
- F89 の統合の重みは F01 が74%、F17 が25%、F15 は1%。統合の結論は、ほぼ F01 と F17 で決まっている

### 区間を広くしていたもの：比べるのに使えた最低賃金の差
| 記事 | 比べるのに使えた差（標準偏差） |
|---|---|
| F01 全体のばらつき（2008–19年） | 9.39% |
| F01 県と年の効果を除いたあと | 0.72% |
| F01 さらに県ごとのトレンドも除く | 0.44% |
| F15 接するペアの中の上昇率の差 | 0.56%（最大 1.79%） |
| F17 上昇率の年平均からのずれ | 0.36% |

- 都道府県の最低賃金は全国で一緒に上がるため、年の効果を除くと、比べるのに使える差は1%未満しか残らない。F15 は差が0.56%しかないうえに、市区町村の雇用の伸びのぶれが大きく、区間が最も広くなった

### 記事の中のばらつき
- 同じ記事の仕様違いで、答えは F01 で幅0.22（−0.22〜+0.01）、F17 で0.10、F15 で3.83（+0.26〜+4.09）動いた。記事の間の主な推定のばらつき（標準偏差 0.19）より、F15 の中の仕様違いのほうがはるかに大きい
- F01 の「県別トレンド（2008–25年）」（−0.22、区間 −0.39〜−0.04）と F17 の「前年差の単純な回帰」（−0.18、−0.35〜−0.01）は、区間が0をまたがない。ただし仕様を選んだ結果で、主な推定ではない

## 頑健性
| 確かめたこと | 結果 |
|---|---|
| 単位のそろえ方①：F01 を2008–25年の就業率の平均で割る | −0.001（標準誤差 0.114）で変わらない |
| 単位のそろえ方②：F17 の1単位を bite の中央値（0.733）で換算 | −0.116（0.200）で変わらない |
| 検出力の基準を厳しく（α=0.05、検出力90%） | MDE は F01 0.38、F15 2.99、F17 0.65、F89 0.32 |
| 検出力の基準をゆるく（α=0.10、検出力80%） | MDE は F01 0.29、F15 2.29、F17 0.49、F89 0.25。それでも −0.1 は見つけられない |
| コロナ期（2020–22年）を外した仕様だけで並べる | F01 −0.04（区間 −0.20〜+0.12、MDE80 0.23）、F17 −0.18（−0.53〜+0.17、0.50）。どちらも0をまたぐ |

## 言えないこと
- 「最低賃金を上げても雇用は減らない」とは言えない。どの記事も、海外で言われる大きさの効果を見つけられる設計ではなかった（見えなかった、まで）
- 弾力性への換算は、平均の就業率や bite で割る近似で、記事ごとに測っている雇用（就業率・就業者数・事業所の従業者数）も違う
- F15 の仕様違いの大きなばらつきは、産業を細かく分けると標本のぶれが大きくなることによるもので、産業ごとの本当の違いかは分からない
- 都道府県や市区町村の集計で、働く人一人ひとりへの影響（労働時間・賃金・職を移ったか）は分からない
