# F28 法人は何年続くのか？ 法人番号の全件データで設立と閉鎖を生存分析する

看板記事 F28。note：「法人は何年続くのか？…」（下書き）

## 問い
設立された法人の登記は、何年でどれだけ閉鎖されるのか。株式会社と合同会社、本店の場所、設立年で違うのか。打ち切り（まだ閉鎖していない法人）をきちんと扱うと、「閉鎖した割合」の見え方はどう変わるか。

## データ
- 国税庁「法人番号公表サイト」全件データ（CSV・Unicode、全国、2026年9月30日更新）。583万件のうち、2015年11月1日以降に法人番号が指定された法人（＝ほぼ新しく設立された法人）。
- 対象：株式会社 103.3万・合同会社 37.2万・その他の設立登記法人（一般社団法人・NPO法人など）12.4万、計152.9万法人。
- 法人名・法人番号・住所は使わず、公開もしていない（`data/raw/` は種別・都道府県・市区町村コード・日付・閉鎖事由だけ）。

| 定義 | 内容 |
|---|---|
| 開始 | 法人番号の指定日（新しく設立された法人では設立登記の日とほぼ同じ） |
| 閉鎖（イベント） | 登記記録の閉鎖のうち「清算の結了等」(01) と「登記官による閉鎖」(21) |
| 打ち切り | 2026-09-30 時点で閉鎖されていない法人。合併による解散 (11)・他の管轄への本店移転 (31) はその日で打ち切り |

## 手法
| 段階 | 手法 |
|---|---|
| 生存曲線 | Kaplan–Meier（種別・設立年・本店の場所別、95%区間） |
| 比較 | Cox 比例ハザードモデル（種別・6地域・東京23区／政令市・設立年。30万法人の無作為抽出） |
| 仮定の確認 | Schoenfeld 残差による比例ハザードの検定、期間別（0–1・1–3・3–6・6–11年）のハザード比 |
| 打ち切りの影響 | 打ち切りを無視した閉鎖割合と Kaplan–Meier の比較 |

## 主な結果
- 10年後に登記が残っている割合は 89.4%（5年後 94.7%）。打ち切りを無視して「閉鎖した割合」を数えると 5.5% だが、Kaplan–Meier で10年後まで見ると 10.6% で、約2倍。
- 5年後に残っている割合：株式会社 95.5%、合同会社 92.9%、その他の法人 92.7%。
- Cox：合同会社のハザード比 1.50（1.44–1.55）、その他 1.62（1.54–1.70）、東京23区 1.60（1.53–1.67）、政令市 1.11。
- 年数ごとの閉鎖率は株式会社で1%前後、合同会社は2〜4年目に1.6%で山になり、その後下がる。合同会社の比例ハザードの仮定は成り立たない（p<0.001）：ハザード比は 0–1年 1.37 → 1–3年 1.77 → 3–6年 1.46 → 6–11年 1.20。
- 設立年（2016〜2025年）による違いはほとんどない（3年後に残っている割合 97.0〜97.3%）。コロナ期の設立でも差は見えない。
- 全法人の閉鎖は 2025年に 9.8万件と、前年の 4.3万件から急増。増えたのは「登記官による閉鎖」で、休眠会社の整理（みなし解散）による。

## 頑健性（合同会社のハザード比）
| 設定 | ハザード比（95%区間） |
|---|---|
| 基本 | 1.50（1.44–1.55） |
| 合併による解散も「消えた」に含める | 1.33（1.28–1.37） |
| 清算結了だけを閉鎖とする | 1.52（1.47–1.58） |
| 2019年までの設立だけ | 1.41（1.35–1.48） |
| 1年目に消えた法人を除く | 1.51（1.45–1.57） |
| 地域を入れない | 1.50（1.45–1.56） |
| 別の30万法人の抽出 | 1.50 |

## 言えないこと
1. 「登記の閉鎖」は「事業をやめた」ではない。事業をやめても解散・清算の登記をしない法人は多い。休眠会社・休眠一般法人の整理（株式会社は12年、一般社団・財団法人は5年、登記がないとみなし解散）で閉鎖されるまで残り、合同会社はこの整理の対象外。今回の対象では閉鎖の97%が「清算の結了等」で、登記官による閉鎖はほとんどない。ここでの数字は「事業が続いている割合」よりかなり高く出ている。
2. 飲食店など個人の店（個人事業）は入っていない。業種も分からない。
3. 法人番号の指定日を設立日とみなしている。2015年10月以前に設立された法人は指定日が一律なので除いた。
4. 東京23区のハザード比が高い理由（ペーパーカンパニー、資産管理会社、起業の多さなど）は、このデータでは分からない。
5. 地域のハザード比は特定の地域の良し悪しを示すものではない。
