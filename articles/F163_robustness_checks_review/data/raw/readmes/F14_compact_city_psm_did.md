# F14 コンパクトシティ計画は人口密度を保てたか？（傾向スコアマッチング＋差の差）

note：コンパクトシティの計画を作った市町村で、中心部の人口密度は保てたのか？ 似た市町村と組にして比べると、2015→20年の5年では差は見えなかった（看板記事 F14）

## 問い

立地適正化計画（いわゆるコンパクトシティの計画）を2020年7月までに作って公表した市町村は、作っていない似た市町村と比べて、中心部（人口集中地区＝DID）の人口密度の下がり方が小さかったか。

## データ

| データ | 出典 | 使ったもの |
|---|---|---|
| 立地適正化計画の作成状況（2017年7月・2018年5月・2018年12月・2020年4月・2020年7月時点の5回） | 国土交通省（PDF） | 市町村名と「作成・公表済み（赤字・青字）」「取組中（黒字）」 |
| 人口集中地区（DID）データ A16（2010・2015・2020年） | 国土交通省 国土数値情報（国勢調査をもとに作成） | DID ごとの人口・面積（2005年は2010年データの「前回」の値） |
| SSDSE-A 2026 | 統計センター | 市町村コードと名前、市町村の総人口（2020年国勢調査） |

- `data/raw/plans_pdf_chars.json`：PDF の文字ごとの色・位置（pdf.js で取得）
- `data/raw/did_ksj_A16.json`：A16 の属性表（DBF）
- 取得は 2026-10-26。コンテナから国交省のサイトに届かないため、Chrome のページ内で実行した（`src/01_取得.js`）

### 計画の一覧の作り方（02）

PDF は県ごとに市町村名を並べた1枚の表で、作成・公表済みの市町村は赤字（両方の区域を設定）か青字（都市機能誘導区域のみ）、取組中は黒字で書かれています。文字の色と位置を取り出し、

1. 同じ行・同じ色で隣り合う文字をつないで市町村名にする
2. 同じ列で、すぐ上にある県名の見出しをその市町村の県とする（同じ名前の町村を区別するため）
3. 県名＋市町村名で SSDSE-A の市町村コードに照合する

5回とも、PDF に書かれた合計（取組 357・407・440・522・542、公表 112・161・186・326・339）と完全に一致しました。前の時点で公表済みなのに後の時点で外れた市町村は0。最初に「公表済み」になった時点を、作成の時期とします。

### DID の整え方（03）

- A16 の属性表は、1つの DID が複数の図形に分かれると同じ行がくり返されるので、(市区町村コード, DID番号) で重複を除いた（全国の DID 人口：2010年 8,613万人、2020年 8,829万人。公表値は 8,612万人・8,829万人）
- 政令市の区は市にまとめ、町村から市になってコードが変わった市町村と、2011年の合併（鳩ヶ谷市→川口市、一色町→西尾市）は 2026年のコードにそろえた
- 4時点すべてで DID がある市町村（東京都区部を除く）772 を分析に使った

## 手法

| 段階 | 中身 |
|---|---|
| グループ | 作成（2020年7月までに公表、297）／未作成（どの時点の一覧にも出てこない、338）／作成中（2020年7月に取組中＝まだ作っていない、137） |
| 結果の指標 | DID の人口密度の5年間の変化（対数の差×100 ≒ %）。2005→10・2010→15 は計画前、2015→20 が計画後。境界の引き直しで極端な値が出るので、上下1%で丸めた |
| 傾向スコア | ロジット。共変量は計画前（2010年以前）の DID 人口・DID 人口密度・2005→10年の DID 密度と DID 人口の変化・DID の数、市町村の総人口（2020年、規模の代わり） |
| マッチング | 傾向スコア（ロジット）の最近傍1対1、復元抽出、キャリパー＝標準偏差×0.2 |
| 差の差 | マッチング後の「作成 − 未作成」を、計画後と計画前で比べる |
| 作成時期ごと | Callaway–Sant'Anna 型：公表の時期（5グループ）ごとに、その時期の作成市町村と未作成を二重頑健法（IPW＋回帰調整）で比べ、市町村数で重みづけて平均 |
| 区間 | ブートストラップ（市町村を復元抽出、300〜500回）の 2.5%・97.5%点 |

## 主な結果

| 期間 | 作成の平均 | 未作成の平均 | 単純な差 | マッチング後の差（95%区間） |
|---|---|---|---|---|
| 2005→10（計画前） | −1.95% | −1.14% | −0.81 | +0.46（−0.65〜+1.05） |
| 2010→15（計画前） | −1.69% | −1.04% | −0.65 | −1.51（−2.09〜+0.51） |
| 2015→20（計画後） | −4.68% | −5.42% | +0.74 | **+0.22（−1.51〜+2.06）** |

1. **2015→20年の DID の人口密度は、作成した市町村でも未作成でも約5%下がり、差は0.2ポイントで区間は0をまたいだ。** 内訳は、DID 人口の変化の差 −0.06、DID 面積の変化の差 −0.17（どちらも区間は0をまたぐ）。
2. **マッチングで規模の差はそろった**（標準化差：DID 人口 0.49→0.09、総人口 0.68→0.04）。ただし 2005→10年の DID 密度の変化は 0.13 と、目安の 0.1 をわずかに超えた。
3. **計画前の動きがずれていた。** マッチングに使っていない 2010→15年の変化で、作成した市町村は似た未作成より 1.5ポイント速く密度が下がっていた（区間 −2.09〜+0.51）。計画を作ったのは「中心部の密度が下がり始めていた市町村」だった可能性がある。計画後と計画前の差（差の差）は +1.72（−1.06〜+3.20）。
4. **作成時期ごと**：2017年7月までに公表した103市町村（国勢調査まで3.2年）は −1.56（−3.70〜+0.21）、2020年4月までの125市町村（0.5年）は −0.28。早く作った市町村ほど効果が大きい、という形は見えなかった。5グループの加重平均は −0.47（−2.05〜+0.67）。
5. **人口規模別**：10万人未満 +0.81（−0.60〜+2.36）、10万〜30万人 −1.49（−4.19〜+1.87）。30万人以上は未作成が9市町村しかなく、区間が −14.6〜+18.4 と広すぎて判断できない。

## 頑健性チェック（2015→20年の効果、%ポイント）

| 設定 | 作成 | 対照 | 効果（95%区間） |
|---|---|---|---|
| 本推定：最近傍1対1（キャリパー0.2） | 297 | 338 | +0.22（−1.58〜+2.12） |
| キャリパー0.05 | 297 | 338 | +0.38（−1.69〜+2.20） |
| 最近傍1対3 | 297 | 338 | +0.20（−1.35〜+1.92） |
| IPW（傾向スコアの重み） | 297 | 338 | −1.00（−2.43〜+0.78） |
| 二重頑健（IPW＋回帰調整） | 297 | 338 | −0.70（−2.24〜+0.55） |
| 対照＝2020年7月に作成中の市町村（まだ作っていない） | 297 | 137 | −0.83（−2.01〜+0.55） |
| 政令市を除く | 286 | 334 | +0.01（−1.24〜+1.45） |
| 2018年までに公表した市町村だけ | 162 | 338 | −0.92（−3.13〜+0.67） |
| 差の差（計画後 − 計画前の変化、二重頑健） | 297 | 338 | +0.10（−1.62〜+1.63） |
| 計画前（2010→15）にあてはめた偽の効果 | 297 | 338 | −0.80（−1.62〜+0.01） |

どの設定でも区間は0をまたぎ、点推定は −1.0〜+0.4 の範囲でした。手法によって符号が変わるので、「効果があった」とも「逆効果だった」とも言えません。

## 言えないこと

- **5年で効果が出るとは限らない。** 計画の公表は2017〜2020年で、2020年の国勢調査（10月）まで最も早い市町村でも3年あまり。居住の誘導は長い時間をかけて効く施策なので、「5年では見えない」が結論です。2025年国勢調査の DID データが出たら更新します。
- **計画の中身の違いは区別していない。** 誘導区域の広さ、届出制度の運用、公共交通の計画とのセットなどは市町村で大きく違います。
- **DID は国勢調査ごとに引き直される。** DID の面積が広がると、同じ人口でも密度は下がります。ここでの「密度」は計画の居住誘導区域の密度ではありません。
- **共変量の一部は計画後の値。** 市町村の総人口は2020年の値を規模の代わりに使っています。財政力指数・高齢化率は入れていません。
- **計画前の動きがそろっていない**（結果の3）。マッチングで計画前の水準と2005→10年の変化はそろえましたが、2010→15年の変化はずれたままです。

## 動かし方

```
pip install -r requirements.txt
cd src
python 02_計画一覧.py   # data/plans.csv
python 03_DID整形.py    # data/did_muni.csv
python 04_推定.py       # data/analysis.csv, results/*.csv（ブートストラップで数分）
```

`01_取得.js` は、データを取り直すときにブラウザのコンソールで使うコードです（国交省の PDF は https://www.mlit.go.jp のページで、A16 は https://nlftp.mlit.go.jp のページで実行）。

## ファイル

- `data/plans.csv`：市町村ごとの各時点の状態と、最初に公表済みになった時点
- `data/did_muni.csv`：市町村ごとの DID 人口・面積・人口密度（2005〜2020年）
- `data/analysis.csv`：分析に使った772市町村（変化の値は丸めた後）
- `results/`：`event_psm.csv`（期間ごとの差）、`components.csv`（密度・人口・面積）、`balance.csv`、`pscore.csv`、`pairs.csv`、`pscore_model.txt`、`cohort_att.csv`、`size_att.csv`、`robustness.csv`、`summary.csv`
- `figures/`：a14_pscore（傾向スコアの分布）、a14_balance（共変量のバランス）、a14_trend（DID 密度の変化と差）、a14_cohort（作成時期ごとの効果）、a14_robustness（規模別・頑健性）
