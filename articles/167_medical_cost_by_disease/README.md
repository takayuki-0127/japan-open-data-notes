# 167 医療費のシェアが伸びている病気はどれか

厚生労働省「国民医療費」の第13表（医科診療医療費，傷病分類別）から、2011〜2023年度の傷病大分類ごとの医療費を取り出し、医科診療医療費に占める割合（シェア）の変化を調べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A167 | 医科診療医療費の中で、どの病気（傷病大分類）の割合が伸び、どれが下がったか | 大分類ごとのシェアを年度別に計算し、2011→2023年度のシェアの変化（ポイント）、伸び率、増えた額のうちの寄与を比較 | `src/a167_share.py` |

## 主な結果
- 医科診療医療費の総数は 2011年度 27.81兆円 → 2023年度 34.55兆円（+24.2%）
- シェアが最も伸びたのは新生物＜腫瘍＞（13.1% → 15.0%、+2.0ポイント、額は+42.9%）。増えた6.7兆円のうち23%を占める
- 次いで損傷・中毒（+1.0ポイント）、神経系（+0.7）、筋骨格系（+0.5）
- 最も下がったのは循環器系（20.8% → 18.2%、−2.6ポイント、額は+8.5%）、精神及び行動の障害（6.8% → 5.6%、額は+2.4%）、内分泌・代謝（−0.7）
- 呼吸器系は2020年度に2.28兆円 → 1.72兆円と大きく減り、2023年度は2.60兆円で過去最高
- 2020年度から新型コロナなどを含む「特殊目的用コード」が加わり、2022年度は0.89兆円（2.6%）

## 注意
- 医科診療医療費（入院＋入院外）のみ。歯科・薬局調剤・入院時食事などは含まない
- 傷病分類は2015年度まで ICD-10（2003年版）、2016年度から ICD-10（2013年版）に準拠。大分類の範囲はほぼ同じだが、完全には一致しない
- 2008〜2010年度は表の形式が異なり同じ列を取り出せなかったため、2011年度以降を使った
- 金額は名目値で、人口の高齢化や診療報酬の改定は調整していない
- 元の Excel は Web ブラウザ上で読み取り、必要な値を CSV に書き写した
