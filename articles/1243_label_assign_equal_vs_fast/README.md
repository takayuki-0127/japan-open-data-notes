# 1243 付ける件数を付け手に均等に配るか、早い人に多く配るかで、全体のまちがいはどう変わるのか？（ラベル付け）

問い合わせ文に分類のラベルを付ける仕事を何人かで分けるとき、全員に同じ件数を配るやり方と、速く付ける人に多く配る（空いた人から次の件を取っていく）やり方があります。速い人に多く配れば早く終わりますが、全体のまちがいの数は、速さとまちがいやすさの関係で変わります。そして、付け手ごとのまちがい率を出して平均すると、配り方を変えても同じ値のままで、その変化は見えません。**ここでは、作成者が乱数で作った架空の問い合わせ文10,000件と架空の付け手10人（付け手ごとの速さとまちがいやすさ、その2つの関係を作成者が置いたもの）で、①全員に同じ件数、②速さに比例して配る（全員が同じ時刻に終わる）の2つの配り方で、全体のまちがいの数、終わるまでの時間、付け手ごとのまちがい率の平均、いちばん速い1人の分がまちがいに占める割合を数えました。速さとまちがいやすさの関係×速さの散らばり×人数の27通りでも確かめました。**

例の問い合わせ文・付け手はすべて作成者が置いた架空のものです。付け手は架空の「速さ」と「まちがいやすさ」だけで区別し、人の属性では比べていません。付け手の報酬や処遇の決め方を扱う記事ではありません。

関連する記事：900「割合の平均と、合計で出した割合はどれだけ違うのか？」と 345「店ごとの平均を平均すると、全体の平均からどれだけずれるのか？」は、店ごとの率を平均した値と、合計で割った率が違うことを扱っています。この記事の「付け手ごとのまちがい率の平均」と「全体のまちがい率」の違いも同じしくみです。この記事は、ラベルを付ける件の配り方に絞り、配り方で全体のまちがいの数と、まちがいの中身（だれの分か）がどう変わるかを数えます。

## 主な結果

### 配り方ごとの全体のまちがい（10人、2,000チームの平均、`results/base_rho.csv`）
| 速さとまちがいやすさの関係 | ①同じ件数のまちがい | ②速さに比例のまちがい | ②÷① | ②のほうが多かったチーム |
|---|---|---|---|---|
| 速い人ほどまちがえやすい（＋0.5、基本） | 579.21件（5.792%） | **637.35件（6.374%）** | **1.1004倍** | 83.35% |
| 関係なし（0） | 581.35件（5.814%） | 581.43件（5.814%） | 1.0001倍 | 48.85% |
| 速い人ほどまちがえにくい（−0.5） | 578.27件（5.783%） | **525.04件（5.25%）** | **0.908倍** | 14.75% |

- **速い人に多く配ると、全体のまちがいは、速い人ほどまちがえやすいとき1.1004倍に増え、速い人ほどまちがえにくいとき0.908倍に減った。関係がなければ変わらなかった（1.0001倍）**
- この倍率は、まちがえる確率を配った件数で重みを付けて平均した値の比で、作りどおりだった（基本の見込みの比は1.1025倍）
- 基本の関係でも、②のほうがまちがいが多かったのは83.35%のチームで、残りのチームでは②のほうが少ないか同じだった。チームの顔ぶれが10人だと、速さとまちがいやすさの関係はチームごとに振れる（基本の置き方で、チームの中の関係の強さは平均0.461）
- 例のチーム（基本の最初の1チーム）では、①458件、②457件と、②のほうが1件少なかった

### 時間・付け手ごとの率の平均・まちがいの中身（基本、`results/a1243_main.json` の base）
| | ①同じ件数 | ②速さに比例 |
|---|---|---|
| 全部付け終わるまでの時間（平均） | 15.834時間 | **7.809時間（0.4932倍）** |
| 全体のまちがい率 | 5.792% | 6.374% |
| 付け手ごとのまちがい率の平均（件数の重みなし） | **5.78%** | **5.78%** |
| いちばん速い1人が付けた件数の割合 | 10.0% | 17.6% |
| いちばん速い1人の分がまちがいに占める割合 | 14.72% | **23.53%** |

- ②は全員が同じ時刻に終わるので、いちばん遅い人を待たずにすみ、時間は①の0.4932倍だった
- **付け手ごとのまちがい率を出して平均すると、配り方によらず5.78%で同じだった**（配り方を変えても、付け手のまちがえる確率は変わらないと置いたので、作りどおり）。②の本当の全体のまちがい率6.374%との差は0.594ポイントで、速い人ほどまちがえにくいときは逆に−0.534ポイントだった
- ②では、いちばん速い1人が件数の17.6%を付け、まちがいの23.53%がその1人の分だった。基本の関係では、速い人のまちがいやすさが全体のまちがいに大きくまざった

### 確かめ：関係の強さ × 速さの散らばり × 人数（27通り、`results/grid.csv`）
| 関係 | まちがいの比（②÷①） | ②のほうが多かったチーム | 時間の比（②÷①） |
|---|---|---|---|
| 速い人ほどまちがえやすい（＋0.5） | **1.04〜1.2186倍** | 69.5〜94.1% | 0.1566〜0.7797倍 |
| 関係なし（0） | 0.9923〜1.0051倍 | 43.5〜52.6% | 0.1573〜0.7796倍 |
| 速い人ほどまちがえにくい（−0.5） | **0.8185〜0.9581倍** | 4.0〜27.8% | 0.1571〜0.776倍 |

- **まちがいが増えるか減るかは、27通りすべてで、速さとまちがいやすさの関係の向きで決まった**。速さの散らばりが大きいほど、比は1から離れた（＋0.5で、散らばり0.2では1.04〜1.0501倍、0.8では1.1721〜1.2186倍）
- 時間の比は関係の向きにはよらず、速さの散らばりと人数で決まった（散らばり0.8・20人で0.1566〜0.1573倍）
- 乱数で数えたまちがいの比と、置いた確率からの見込みの比の差は、27通りで最大0.34%だった

## 注意（言えないこと）
- 架空のデータです。速さ・まちがいやすさの分布と、その2つの関係は作成者が置いたもので、結果はこれで決まります。とくに全体のまちがいの比は、置いた確率を件数で重みを付けて平均した値の比で、作りどおりです
- 実際の付け手で、速い人ほどまちがえやすいかどうかは、この記事では言えません。それが分からないと、配り方でまちがいが増えるか減るかは決まりません
- 多く配られた人が疲れてまちがえやすくなる、慣れてまちがえにくくなる、といった件数による変化は入れていません。まちがえる確率は付け手ごとに一定と置きました
- 付け手の報酬・処遇や、だれにどれだけ配るべきかは言えません。この記事は、配り方で全体のまちがいの数と中身がどう変わるかを数えただけです
