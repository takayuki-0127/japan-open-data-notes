# 353 結論の言い切り方は、どう変わったか（④ 振り返り R108）

note に下書きした記事の原稿（手元の md）で、結論の文の文末を「見えなかった・言えない」「変わらなかった」「かもしれない・（推測）」「言い切り」に分けて数えた

## 問い

- 結論を言い切らない文末（見えなかった、言えない、かもしれない）は、増えたのか
- 「見えなかった」「分からなかった」で終わる結論を持つ記事は、どれくらいあるか

## 手法

| 手順 | 中身 |
|---|---|
| 結論の文（`src/a353_extract.py`） | ①題名の答えの部分（最初の「？」「。」より後ろ）、②書き出し（最初の見出しより前の文）、③見出しに「分かること」「まとめ」「結論」がある節の文。原稿614本で6,873文、うち「か」「？」で終わる問いの文802を除いた6,071文 |
| 文末の分け方 | 文のいちばん最後の言い方だけを見る（終わりのかっこ書きと句点は外す）。「見えなかった・分からない・言えない・区別できない・はっきりしない・とは限らない」／「変わらなかった・動かなかった・ほぼ同じ・横ばい・差はなかった」／「かもしれない・と考えられる・可能性がある・〜そうです・（推測）」／「〜た」の言い切り／そのほかの言い切り |
| 文の数の影響 | 結論の文の数が多い記事ほど、言い切らない文が1つは入りやすい。全体の割合のまま、記事ごとの文の数だけから「1つでもある」確率を出し、実際と比べた |
| まとめ方（`src/a353.py`） | 文の割合、記事の割合、題名、看板記事の番号順 |

242（言えないことの書き方）は「言えないこと」の節を数えた。ここでは結論の文の文末だけを数える

- 結論の文のうち、「見えなかった・言えない」で終わるのは1.4%、「変わらなかった・ほぼ同じ」は1.0%。2つを合わせた割合は、どのグループでも1.5〜3.1%で、はっきりした増減はない
- そうした文が結論に1つでもある記事は、通常の記事の11〜12%から精選の50%に増えた。ただ、結論の文の数が5〜6から23〜25に増えていて、文の数だけから見込んだ割合（12〜13% → 43%）とほぼ同じ
- 「かもしれない・（推測）」で終わる文は、通常の記事（000〜226）で0%、F100–F199 で1.4%、精選で1.2%。こちらは文の数から見込むより多く、実際に増えた
- 「〜た」の言い切りは、通常の記事の48〜50%から、F200 以降は27〜29%。結論を箇条書きにして、体言止めや「〜です」で書くことが増えた
- 題名の答えの部分に「見えなかった」か「変わらなかった」の言い方がある記事は614本中84本（14%）。題名の最後が「見えなかった・言えない」で終わるのは18本（3%）

## 確かめたこと

- 分けた文を64文読み（見えなかった15、変わらなかった15、かもしれない10、「〜た」10、そのほか14）、64文とも分け方どおりだった（`data/manual_check.csv`）。最初の版は文の途中の言葉でも拾っていて、「変わらなかった」の14文のうち7文が誤りだったので、文のいちばん最後だけを見るように直した
- 本文のすべての文で数えても、3つの言い方は合わせて3〜8%で、グループの並びは大きく変わらない（`results/body_sentence_share.csv`）
- `src/a353.py` を空のフォルダで流し直し、results と figures が一致することを確かめた

## 言えないこと

- 文のいちばん最後の言い方だけで分けた。文の途中で「〜とは言えないが、…だった」と書いた文は、言い切りに数えている
- 「変わらなかった」には、結果が0に近かったという文と、「設定を変えても結論は変わらない」という確かめの文の両方が入る
- 「結論の文」は、題名・書き出し・「分かること」「まとめ」「結論」の節とした。書き出しには、背景や方法の説明の文も入っている
- 言い切らない文が少ないことが、言い過ぎを意味するわけではない。結果がはっきりしていれば言い切るのがふつう。結論が合っていたかどうかは 251 で数えた
- 「かもしれない・（推測）」が増えた理由は、数字からは決められない。公開前の見直しで「推測」と書き足すようにしたため、というのは推測
- 原稿は note の下書きのもとになった md で、note の画面で直した分は入っていない
