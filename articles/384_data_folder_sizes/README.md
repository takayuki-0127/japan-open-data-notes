# 384 置いたデータは、どれくらいの大きさだったか（④ 振り返り R114）

GitHub に置いた記事639本のファイルの一覧（13,656個）から、data フォルダの数・大きさ・形式・行数を数えた

## 問い

- 記事1本の data フォルダは、どれくらいの大きさか
- 1つのファイル10MB 未満という決まりは守れていたか。上限に近いファイルはいくつあるか
- どの形式が多いか。同じ中身のファイルを、複数の記事に置いていないか

## 手法

| 手順 | 中身 |
|---|---|
| 一覧（`src/a384_extract.py`） | GitHub の API（git/trees/00b426f?recursive=1）で取ったファイルの一覧から、path・size・sha（中身のハッシュ、先頭12桁）を取り出した。`articles/<記事>/<場所>/…` に分け、拡張子を付ける |
| 行数 | data フォルダの CSV 1,985個のうち、手元に同じ大きさの写しがある1,588個の行数と列数を数えた（中身は出していない） |
| まとめ方（`src/a384.py`） | 記事ごとの data の数と大きさ、まとまりごとの中央値、形式ごとの数と大きさ、ファイル1個の大きさの分布、同じハッシュのファイル |

F124（データの系譜）は同じ統計を使った記事をつないだ。325（コードの重なり）はコードを数えた。ここではファイルの大きさを数える。MB は100万バイト

## 主な結果（`results/summary.json`、`results/data_by_group.csv`、`results/data_formats.csv`）

- 記事フォルダ全体：13,656個・1,601MB。data 67%（1,076MB）、figures 21%、results 9%、src 1%
- data フォルダ：2,999個・1,076MB。data がある記事は601本。1本あたりの中央値は3個・0.40MB、平均1.68MB、90%点4.95MB、最大51.5MB
- 上位1割（63本）の記事で data 全体の57%
- ファイル1個：10MB 超は0個、8MB 以上15個、5MB 以上41個、1MB 以上269個、100KB 未満1,935個。最大は F06 の data/units.gpkg（9.76MB）
- 形式：CSV が数で66%・大きさで48%。Excel（xlsx・xls）458個・18%。JSON は数で6%・大きさで12%
- 同じ中身（同じハッシュ）のファイルが2本以上の記事にある組は440組。2個目以降の大きさの合計は347MB で、data 全体の32%。そうしたファイルがある記事は337本
- CSV の行数（1,588個）：中央値260行、90%点5,826行、最大244,684行。100行以下628個、1万行超102個

## 確かめたこと

- 一覧のファイル数（13,656個）が、リポジトリの記事フォルダのファイル数と合うことを確かめた（639フォルダ）
- 8MB 以上の15個を目で見て、同じ大きさが6個あること、ハッシュも同じであることを確かめた
- `src/a384.py` を空のフォルダで流し直し、results と figures が一致することを確かめた（行数の `data/csv_rows.csv` は、手元の写しが要るのでそのまま使った）

## 動かし方

```
python src/a384_extract.py <tree.csv> [<記事フォルダの手元の写しのルート>]   # data/files.csv.gz（と data/csv_rows.csv）
python src/a384.py                                                          # 集計と図
```

## データ

| ファイル | 中身 |
|---|---|
| data/files.csv.gz | 記事フォルダのファイル1個が1行（記事、まとまり、場所、拡張子、大きさ、ハッシュの先頭12桁、パス） |
| data/csv_rows.csv | data フォルダの CSV の行数と1行目の列数（手元に同じ大きさの写しがあるもの） |

## 注意（言えないこと）

- 数えたのは、2026年11月12日時点で GitHub にあるファイル。途中で消したり置き換えたりしたファイルは入っていない
- 「同じ中身」はハッシュが完全に同じファイルだけ。ほぼ同じファイルは別のものとして数えている
- 行数は手元に同じ大きさの写しがあった CSV だけで、000–099 の CSV は入っていない。行数は見出しの行を除いた数
- 圧縮して置いたファイル（csv.gz など）は、圧縮後の大きさで数えている
