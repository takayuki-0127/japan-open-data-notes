# 191 野菜の産地はどれだけ集中しているか：作物統計調査（野菜生産出荷統計）

農林水産省「作物統計調査（野菜生産出荷統計）」の都道府県別・品目別の収穫量から、野菜41品目について、全国の収穫量に占める上位県の割合とハーフィンダール・ハーシュマン指数（HHI）を出し、2014年産と2024年産で比べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A191 | 野菜の産地はどれだけ集中しているか。品目でどう違い、10年でどう変わったか | 都道府県別シェア、上位1・3・5県の割合、HHI（シェアの2乗和×10,000）、2014年産と2024年産の比較 | `src/a191_hhi.py` |

## 主な結果
- 2024年産でHHIが最も高いのはばれいしょ（6,670）。北海道が全国の81.5%を占める。たまねぎ（4,585、北海道66.8%）、にんにく（4,474、青森66.5%）が続く
- 41品目のうち、上位3県で全国の5割以上を占めるのは20品目、1県で3割以上は15品目
- 集中度が低いのはきゅうり（HHI 518、上位3県29.8%）、ほうれんそう（576）、ねぎ（581）、だいこん（609）など。全国で広く作られている
- 2014年産→2024年産でHHIが上がったのは41品目中28品目。上がり幅が大きいのはたまねぎ（+835）、みずな（+690）、ばれいしょ（+542）、はくさい（+350）。下がったのはスイートコーン（−602）など
- 1位の県が入れ替わったのは9品目（キャベツ 愛知→群馬、だいこん 北海道→千葉、ねぎ 千葉→茨城 など）

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a191_hhi.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/pref_harvest.csv | 年産、品目（41品目）、都道府県、収穫量（t）。調査していない県は空欄 |
| data/national_harvest.csv | 年産、品目、全国の収穫量（t）・作付面積（ha） |

- 野菜生産出荷統計 確報「野菜調査4 都道府県別・品目別の作付面積、収穫量及び出荷量」：令和6年産 statInfId 000040389511、平成26年産 000031350174
- 全国の値は「野菜調査1 全国の作付面積、10a当たり収量、収穫量及び出荷量」：令和6年産 000040389426、平成26年産 000031350007
- ダウンロード：`https://www.e-stat.go.jp/stat-search/file-download?statInfId=<ID>&fileKind=4`（平成26年産は fileKind=0）。値はブラウザ上で表を読み取って CSV にした

## 注意
- 都道府県別の値は「主産県」など調査した県だけ。調査していない県の分はシェアに入らないため、HHIと上位県の割合は全国の収穫量を分母にした下限に近い値になる（調査県の合計が全国に占める割合は品目により2024年産で81〜99%、2014年産で69〜100%）
- 調査する県は年によって変わる。2014年と2024年の差には、調査対象の変更も含まれる
- 品目の中の作型（春・夏秋・冬など）は合計した品目単位で見ている。季節ごとの産地のリレーは見ていない
- 収穫量（t）の比較で、金額や出荷量ではない
