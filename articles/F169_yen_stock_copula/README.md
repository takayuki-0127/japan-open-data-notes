# F169 円安と株高は、大きく動く日にだけ一緒に動くのか？（コピュラと裾の依存）

## 問い
「円安の日は株高」とよく言われます。ふつうの相関で見るとどれくらい一緒に動いているのか。そして、相場が大きく動く日には、ふつうの相関から予想される以上に一緒に動いているのか（裾の依存）。円安×株高の側と、円高×株安の側で違いはあるのか。

## データ
| データ | 出どころ | 期間 | 備考 |
|---|---|---|---|
| ドル円（東京市場 スポット 17時時点、日次） | 日本銀行 時系列統計データ検索サイト FM08（系列コード FXERD04）、API で取得 | 1998/1/5〜2026/10/30 | `data/raw/boj_fm08_fxerd04.csv` |
| 日経平均株価（終値、日次） | FRED「NIKKEI225」（出所：日本経済新聞社） | 同上 | **日本経済新聞社の著作物のため、このリポジトリには入れていません。** `src/01_取得.py` で各自取得してください |

- 両方の値がある 7,063 営業日 → 日次の対数変化率 7,062 個（ドル円の＋＝円安、日経平均の＋＝株高）。
- 週次（金曜どうし）1,502 個。
- ドル円は17時、日経平均は15時（2024年11月から15時30分）の終値で、1時間半〜2時間ずれています。

## 手法
1. ふつうの相関：ピアソン・スピアマン・ケンドールのτ（全期間・年ごと）。
2. 経験的な裾の依存：両方の変化を順位（0〜1）に直し、「片方が上位（下位）1−q に入る日に、もう片方も入る割合」を q＝0.90・0.95・0.975・0.99 で計算。区間は20日ブロックのブートストラップ（400回）。
3. 「ふつうの相関だけなら」の基準：ケンドールのτから決めた相関のガウスコピュラで、同じ日数のデータを400回作り、同じ割合を計算。
4. コピュラの当てはめ（順位から作った擬似観測値に最尤法）：ガウス、t、クレイトン、ガンベル（とその回転）、フランク、対称化ジョー・クレイトン（上下の裾を別々に推定）。AIC で比較。
5. 代替案：大きく動いた日だけの相関。ガウスでも同じ選び方をしたらどう出るかと比べる。

## 結果
- 全期間の日次：ピアソン 0.33、スピアマン 0.28、ケンドール 0.20。
- 関係は時期で大きく変わる：ケンドールのτは 1998〜2006 年 −0.01、2007〜2012 年 0.35、2013〜2019 年 0.44、2020〜2026 年 0.14。
- 経験的な裾の依存（全期間・日次、q＝0.975）：円安×株高 0.16（0.11〜0.25）、円高×株安 0.25（0.18〜0.35）、ふつうの相関だけなら 0.10（95%点 0.14）。両方の裾ともガウスより大きく、円高×株安の方が 0.09（0.02〜0.16）大きい。
- 両方が下位2.5%に入った日は44日、上位2.5%は28日（無関係なら約4日）。44日のうち25日が2007〜2012年。
- コピュラ：AIC 最良は t（自由度3.8、裾の依存 0.17、上下同じ）。ガウスとの AIC の差は385。上下を分けた対称化ジョー・クレイトンは上 0.10・下 0.21 だが、AIC は t より147悪い。
- 大きく動いた日だけの相関：日経平均が上下10%に入る日は0.49、ふつうの日は0.21。ただしガウスでも同じ選び方で0.58になる（選び方だけで相関は高く出る）。

## 頑健性
| チェック | 結果 |
|---|---|
| 期間（4つ） | 裾の依存がガウスをはっきり超えるのは 2007〜2012 年（下 0.50 vs ガウス95%点 0.35）。2013〜2019 年は相関は強いが、裾はほぼガウス並み。2020〜2026 年は円高×株安だけがガウスの95%点の境目 |
| 週次 | 全期間で t が最良、裾の依存 0.16。2013〜2019 年はガウスが最良 |
| GARCH(1,1) で値動きの荒さを調整 | t が最良（裾の依存 0.13）、円高×株安 > 円安×株高 は残る |
| 閾値 q | 0.90〜0.99 のすべてで、円高×株安 > 円安×株高 > ガウス |
| 前日が営業日の日だけ | ほぼ同じ（相関 0.30） |
| ドル円を1日ずらす | 相関 0.02：一緒に動くのは同じ日 |

## 言えないこと
- どちらが原因かは分からない（円安が株高を生むのか、同じニュースに両方が反応しているのか）。
- 1時間半〜2時間の時刻のずれがあり、その間の動きはドル円にだけ入っている。
- 「大きく動く日」は少なく（上位1%で各71日）、区間は広い。上下の差の区間も、q＝0.95・0.99 では下端が0付近。
- 関係そのものが時期で変わるため、全期間の数字は「平均的な姿」で、今の姿ではない。
- これは過去の値動きの記述で、投資の判断に使うためのものではない。
