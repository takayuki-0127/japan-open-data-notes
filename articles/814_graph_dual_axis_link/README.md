# 814 2本の縦軸のグラフで、目盛りの取り方だけで「連動」は作れるのか？（グラフ）

左右に別々の縦軸を持つグラフ（2軸のグラフ）では、右の縦軸の目盛りを自由に選べます。目盛りを選べば2本の線を重ねられるので、無関係の数字どうしでも「連動している」ように見せられる、とよく言われます。**ここでは、作成者が乱数で作った架空の「店の来店数」と「別の商品の売上」の組を24か月分、無関係に作った組と本当に関係するように作った組で各2,000組用意し、右の縦軸の目盛りを選ぶと2本の線がどれだけ重なるかを数えました。**

縦軸を0から始めるかは関連する記事 813、前年比の棒と実数の線を1枚に並べる図は 824 で扱います。この記事は「右の縦軸の目盛りの取り方」だけを見ます。

重なりの目安には「2本の線の縦の離れ」（グラフの高さを1としたときの、月ごとの縦の差の平均）を使いました。本当に関係のある組を、左右とも自動の目盛りで描いたときの離れの真ん中（0.088）を「関係あり並み」の線にしました。

## 主な結果

### 3種類の組（各2,000組）
| | 無関係・上り下りあり | 無関係・横ばいの振れ | 本当に関係あり |
|---|---|---|---|
| 月ごとの増減の相関（平均） | 0.00 | 0.01 | 0.79 |
| 水準そのものの相関の大きさが0.5を超えた組 | 62% | 1% | 92% |
| 線の離れ（中央値）：右も自動 | 0.285 | 0.270 | 0.088 |
| 線の離れ（中央値）：右の目盛りを選ぶ | 0.199 | 0.190 | 0.071 |
| 「関係あり並み」に重なった組：右も自動 | 3% | 0% | 50% |
| 「関係あり並み」に重なった組：右の目盛りを選ぶ | **7%** | **0%** | 62% |
| 「関係あり並み」に重なった組：上下を逆にしてもよい | 12% | 0% | 62% |

- 右の目盛りを選ぶと、無関係の組の線の離れは中央値で0.285→0.199と3割ほど縮んだ。しかし「関係あり並み」まで重なったのは、上り下りのある無関係の組の7%（上下を逆にしてよければ12%）で、横ばいの振れだけの組では0%だった
- 重ねられた無関係の組（2,000組のうち143組）は、水準そのものの相関が中央値0.94で、たまたま同じ向きに伸びた組だった。月ごとの増減の相関は平均0.06で、無関係のままだった
- 目盛りで動かせるのは線の上下の位置と幅だけで、線の形（月ごとの上り下り）は変えられない。形がたまたま似ている組だけが重なった

### 逆に、離して見せる
| | 無関係・上り下りあり | 無関係・横ばいの振れ | 本当に関係あり |
|---|---|---|---|
| 離れが最も大きくなるように右の目盛りを選んだときの離れ（中央値） | 0.433 | 0.412 | 0.396 |
| 無関係の組の自動の離れ（0.285）以上に離せた組 | 100% | 100% | **100%** |

- 本当に関係のある組は、右の目盛りを選べば100%、無関係の組をふつうに描いたときより離して描けた。ただし離しても線の形は平行のままで、形を見れば似ていることは読み取れる（推測）

### 確かめ：置き方を変えても（各1,000組）
| 置き方 | 「関係あり並み」の目安 | 上り下りあり：右も自動 | 上り下りあり：右の目盛りを選ぶ | 横ばい：右も自動 | 横ばい：右の目盛りを選ぶ |
|---|---|---|---|---|---|
| 基本（24か月・関係の強さ0.8・線の幅30%以上） | 0.089 | 2.9% | 5.8% | 0% | 0% |
| 12か月 | 0.108 | 3.7% | 7.2% | 0% | 0.1% |
| 60か月 | 0.067 | 5.0% | 9.0% | 0% | 0% |
| 関係の強さ0.5で目安を作る | 0.144 | 14.3% | **26.7%** | 0% | 3.8% |
| 右の線の幅を50%以上に限る | 0.087 | 2.7% | 6.7% | 0% | 0% |

- 「関係あり並み」の目安をどの強さの関係で作るかで、重なった割合は6〜27%と動いた。目安を緩めるほど、無関係の組でも重なって見える割合は増える
- どの置き方でも、上り下りのある無関係の組では、目盛りを選ぶと重なる割合は右も自動のときの1.8〜2.5倍になった。横ばいの振れだけの組は、どの置き方でも4%以下だった

## 注意（言えないこと）
- 架空のデータです。増減の大きさ・伸び・関係の強さは作成者が置いたもので、重なる割合はこれで決まります。とくに「関係あり並み」の目安を何で作るかで、6〜27%と大きく動きます
- 「線の離れ」は、人が「連動している」と感じるかどうかを測ったものではありません。形が平行なら離れていても連動に見える、形が違っても交わりが多ければ連動に見える、といった見え方は入っていません
- 目盛りの取り方だけを数えました。期間の切り出し方や、どの数字を並べるかを選ぶこと（たくさんの数字の中から形の似た組を探すこと）は入っていません。たくさんの組から選べば、目盛りだけのときより重なる組はずっと見つけやすくなります（推測）
- 実在の店・商品の数字を表すものではありません
