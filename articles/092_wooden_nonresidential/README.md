### housing-starts-japan：国土交通省「建築着工統計調査」で、新築住宅の広さと木造の非住宅を調べる

国土交通省「建築着工統計調査」の時系列表（e-Stat）を使ったリポジトリです。新設住宅の利用関係別（持家・貸家・分譲）の戸数と床面積（1948〜2025年）、都道府県別の戸数と床面積（1951〜2025年）、構造別の着工床面積（1951〜2025年）、構造別×用途別の床面積（1988〜2025年度）、民間非居住建築物の用途別床面積（2004年11月〜2026年8月）を使いました。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| W1 | 新設住宅の1戸当たり床面積は小さくなったか。持家・貸家・分譲で違うか。都道府県でどう違うか | 利用関係別の1戸当たり床面積（床面積÷戸数）の推移、平均の変化を「区分の中の変化」と「戸数の構成の変化」に分けるシフトシェア分解（1996→2025年ほか）、都道府県別の2000年と2025年の比較 | `src/w1_floor.py` |
| W2 | 木造の非住宅は増えたか。どの用途で増えたか | 構造別の床面積の割合（暦年）、用途7区分×構造の木造率（年度、都道府県の値を足して全国）、2010〜2025年度の木造率のトレンド（OLS、HAC標準誤差）、民間非居住の用途別床面積（月次を暦年に合計） | `src/w2_wood.py` |

#### 主な結果
- **W1**：新設住宅1戸当たりの床面積は2000年の97.5㎡が最も広く、2025年は76.8㎡。持家は1996年の140.8㎡が最も広く、2025年は112.2㎡。分譲マンションは2001年の94.9㎡から72.3㎡、貸家は47.6㎡、分譲一戸建は102.1㎡でほぼ横ばい。1996→2025年の平均の変化（−19.2㎡）を分けると、区分の中で小さくなった分が−13.4㎡（うち持家−9.5㎡）、広い持家が減り貸家・分譲が増えた構成の変化が−5.8㎡。都道府県では大阪66.3㎡・東京66.4㎡が狭く、徳島99.2㎡・福井98.8㎡が広い。2000→2025年に47都道府県すべてで小さくなった
- **W2**：着工床面積に占める木造の割合は1990年の30.1%が最も低く、2025年は43.4%。ただし多くは住宅で、非住宅（事務所・店舗・工場・倉庫・学校・病院・その他）の木造率は5.8%（1988年度）→7.8%（2010年度）→8.2%（2025年度）とわずかな上昇にとどまり（2010〜2025年度の傾き年0.04ポイント、標準誤差0.02）、木造の非住宅の床面積は627万㎡→348万㎡→295万㎡と減った。用途別では2010→2025年度に病院・診療所4.7%→17.8%、事務所5.7%→11.1%、店舗4.9%→9.6%、学校2.1%→5.9%と上がり、倉庫5.6%→2.3%、工場・作業場3.5%→1.5%は下がった。民間の非居住建築物では倉庫の床面積が2022年に1,319万㎡と最も多く、2019年からは毎年、工場を上回っている

#### 動かし方
`data/` に整えた CSV が入っているので、そのまま動きます。元の Excel から作り直すときは、e-Stat の「建築着工統計調査」（https://www.e-stat.go.jp/stat-search/files?page=1&toukei=00600120 ）の「時系列表」から次の5つを取得し、`src/common.py` の `RAW_FILES` の名前で `data/raw/` に置いて、`data/` の CSV を消してから実行してください。
- 住宅着工統計 › 時系列表 › 年次「【住宅】利用関係別 時系列」→ `住宅_利用関係別_時系列.xls`
- 住宅着工統計 › 時系列表 › 年次「【住宅】都道府県別戸数 時系列」→ `住宅_都道府県別戸数_時系列.xls`
- 建築物着工統計 › 時系列表 › 年次「【建築物】構造別床面積 時系列」→ `建築物_構造別床面積_時系列.xls`
- 建築物着工統計 › 時系列表 › 年度次「【建築物】構造別 用途別 都道府県別」→ `建築物_構造別用途別都道府県別.xls`
- 建築物着工統計 › 時系列表 › 月次「【建築物】民間非居住 用途別 床面積」→ `建築物_民間非居住_用途別床面積.xls`

#### データ
| ファイル | 中身 |
|---|---|
| data/tenure_year.csv | 年×利用関係（総計・持家・貸家・給与住宅・分譲住宅・うち分譲マンション・うち分譲一戸建）：新設住宅の戸数、床面積（㎡） |
| data/pref_year.csv | 年×都道府県：新設住宅の戸数、床面積（㎡） |
| data/structure_year.csv | 年×構造：着工建築物の床面積（千㎡）、工事費予定額 |
| data/structure_use_fy.csv | 年度×用途（居住専用・居住産業併用・事務所・店舗・工場・作業場・倉庫・学校・病院・診療所・その他の非住宅）×構造：棟数、床面積（㎡）、工事費予定額（万円）。都道府県の行を足して全国にしたもの |
| data/private_nonres_month.csv | 年月×用途：民間非居住建築物の棟数、床面積（千㎡） |

#### 注意
- 床面積と工事費は着工時の届出の「予定」の値で、完成した建物の値ではありません。床面積は延べ床面積です
- 新設住宅の床面積は住宅部分の床面積です。分譲住宅の内訳は、分譲マンションが1985年から、分譲一戸建が1988年からあります
- 1戸当たりの床面積は、利用関係ごとに床面積の合計÷戸数で計算した平均です。中央値や分布は分かりません
- 非住宅の7用途は「構造別，用途別」表の再掲区分（事務所・店舗・工場及び作業場・倉庫・学校の校舎・病院・診療所・その他）で、1988年度から同じ区分です。居住専用・居住産業併用の建築物は非住宅に含めていません。2024年度は表が「4月〜12月」と「1月〜3月」に分かれているので足しました
- 非住宅の木造率は、2009年度に非木造の床面積が大きく減ったため（リーマン・ショック後）上がって見えます。割合だけでなく木造の床面積も見てください
- 階数（中高層かどうか）は今回使った時系列表にないので、分析していません
- 民間非居住の用途別の表は、事務所・店舗・工場・倉庫（建物の使い方）と、製造業用・医療，福祉用など（建築主の産業）の2種類の区分が並んでいます。両方を足すと二重に数えることになります
