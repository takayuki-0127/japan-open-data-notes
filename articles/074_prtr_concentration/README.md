## もとのリポジトリの説明

以下は、もとのリポジトリ `prtr-releases-japan` の README です（同じリポジトリにあったほかの記事の分も含みます）。

### prtr-releases-japan：PRTR（化学物質の排出・移動量の届出）の個別事業所データ24年分で、排出の減り方と集中のしかたを調べる

環境省・経済産業省が公表している PRTR の個別事業所データ（ファイル記録事項）、2001年度〜2024年度の24年分（延べ約87万事業所・年、約548万物質・行）を使ったリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| P1 | 届け出られた排出量はどれだけ減ったか。どの物質・業種で減り、「届出をやめた事業所」「新しく届け出た事業所」「続けて届け出た事業所の削減」のどれが効いたか | 24年続けて対象だった180物質に限った集計、物質別・業種別の変化、事業所を年度間でつないだ増減の分解（2時点、1年ずつ） | `src/p1_decline.py` |
| P2 | 排出は一部の事業所に集中しているか。排出から移動（廃棄物・下水道）へ移ったか。都道府県で減り方は違うか | 上位1%・10%のシェア、ジニ係数、ローレンツ曲線、排出量と移動量の推移、都道府県別の増減 | `src/p2_concentration.py` |

#### 主な結果
- **P1**：24年続けて対象だった180物質の排出量は、294千トン（2001年度）→98千トン（2024年度）で−67%（2003年度の273千トン比で−64%）。届け出られたすべての物質では313千トン→137千トン（−56%）。2024年度の排出の92%は大気へ。物質別ではトルエン−70%、キシレン−66%、塩化メチレン−73%と大きく減った一方、エチルベンゼンは+59%。業種別では船舶製造・修理業がほぼ横ばい（−4%）。2003→2024年度の減少175千トンを分けると、届出をやめた事業所の分−97千トン、新しく届け出た事業所の分+34千トン、続けて届け出た事業所の削減−111千トン（2時点で比較）
- **P2**：排出量の上位1%の事業所が全体の約半分（2024年度51%）、上位10%が93%を占め、ジニ係数は0.94〜0.95で24年ほとんど変わらない。排出量に対して、事業所の外への移動量（主に廃棄物）は149〜217千トンで大きくは減らずで、2010年度から排出量を上回る（排出＋移動に占める排出の割合 61%→33%）。都道府県別では47都道府県のうち45で減少し、減少率の中央値は−63%。香川県（−22%）、佐賀県（−18%）、島根県（−24%）などは減り方が小さく、高知県・沖縄県は増えた

#### 動かし方
元データ（各年度約3〜4MBのzip、24ファイル）はリポジトリに入れていません。https://www.env.go.jp/chemi/prtr/kaiji/index.html の「手順２」から、`https://www.env.go.jp/chemi/prtr/kaiji/data/H13PRTRdata.zip` 〜 `.../R06PRTRdata.zip` をダウンロードし、zipのまま `data/raw/` に置いてください。

```bash
pip install -r requirements.txt
cd src
python p1_decline.py
python p2_concentration.py
```

#### データ
| ファイル | 中身 |
|---|---|
| data/raw/H13PRTRdata.zip 〜 R06PRTRdata.zip（各自ダウンロード） | 本紙（事業所の名称・所在地・従業員数・業種）、別紙（物質ごとの排出量・移動量）、他業種 |
| results/p1_constant_substances.csv | 24年続けて届出があった180物質の一覧 |

#### 注意
- 届出は、従業員21人以上で、対象物質を一定量以上取り扱う、決められた業種の事業所だけです。届出外（家庭・自動車・小さな事業所など）の排出は入っていません。数字は事業者による推計です
- 対象物質は2010年度と2023年度に見直されています。年度をまたぐ比較は、24年すべてで届出があった180物質（名前で一致）に限りました。2001〜2002年度は取扱量の基準（5トン以上）が2003年度以降（1トン以上）より高いため、届出の範囲が狭くなっています
- ダイオキシン類は単位（mg-TEQ）が違うので除きました
- 整理番号は年度ごとに振り直されているため、隣り合う年度で「所在地」または「事業所名＋市区町村」が同じ事業所を同じ事業所とみなしてつなぎました。移転と改名が同時にあると別の事業所になり、「届出をやめた」「新しく届け出た」が実際より大きく出ます（特に2004〜2005年度は届出の様式が変わり、つながる割合が83〜85%と低め）。1年ずつつないで足し合わせた分解は、この影響を受けて「新しく届け出た」が大きく出ています
- 本紙には届出者の代表者の氏名が含まれますが、分析では使っていません。結果は都道府県・業種・物質単位の集計だけです
