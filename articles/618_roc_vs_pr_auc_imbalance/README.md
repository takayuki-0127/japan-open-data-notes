# 618 起きる割合が1%のとき、ROC の AUC と PR の AUC では、予測の良し悪しの見え方はどれだけ違うのか（手法の解説・正解の分かるデータで試す）

予測モデルの良し悪しを1つの数字で表すとき、ROC の AUC と PR の AUC（平均適合率）がよく使われます。**ここでは、正解の分かる架空のスコア（起きない人は N(0,1)、モデルAの起きる人は N(1.6,1)、モデルBの起きる人は N(1.0,2²)）で、起きる割合を 50%・10%・1%・0.1% と変え、2つの指標と上位1割の的中率がどう動くか、2つのモデルの順位がどう入れ替わるかを数えました。** 各場面 40万件。さらに 1%・5,000件の小さな検証データを500回作り、指標の振れを見ました。数字は置いた分布で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A618 | 起きる割合で ROC の AUC と PR の AUC はどう変わり、どちらでモデルの順位が入れ替わるか | 2正規分布のスコア（モデルA・B）、ROC AUC・PR AUC（平均適合率）・上位10%の適合率と捕捉率（scikit-learn）。各場面40万件、小標本は5,000件×500回、seed 618 | `src/a618_roc_pr_auc.py` |

## 主な結果
- **ROC の AUC は起きる割合でほぼ動かない**：モデルAは 50% で 0.871、1% で 0.866、0.1% で 0.864
- **PR の AUC は起きる割合とともに下がる**：モデルAは 50% で 0.869、10% で 0.516、**1% で 0.143**、0.1% で 0.017。でたらめに並べたときの値は起きる割合そのもの（1% なら 0.01）なので、0.143 は「でたらめの14倍」
- **順位の入れ替わり（1%）**：ROC の AUC は A 0.866・B 0.671 で A が上、PR の AUC は A 0.143・**B 0.191** で B が上。B は上位のごく一部に起きる人が集まる形で、PR はその部分を重く見る
- **上位1割に印をつけた場合（1%）**：起きる人の捕捉率は A 59.8%・B 43.6%、適合率は A 6.0%・B 4.4% で A が上。どの指標がよいかは「上位何%に手を打つか」で決まる
- **小さな検証データ（1%・5,000件、起きる人は約50人）での振れ**：ROC の AUC の変動係数は A 2.8%・B 7.9%、PR の AUC は A 33.5%・B 29.1%。A の PR AUC の 90% の範囲は 0.075〜0.250。500回のうち、ROC では毎回（100%）A が上、PR では 73.4% の回で B が上
