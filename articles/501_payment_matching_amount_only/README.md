# 501 入金の消込を「金額だけ」で合わせると、何件が別の請求に消し込まれるのか（実務の型）

架空の得意先600社の請求5,712件と入金5,746件（全額・手数料を引いた入金・分割・未入金、半角カナの振込名義、ほかの名義での入金を含む）を作り、消込（入金をどの請求に当てるか）を4通りで行って、正しい請求に当たった件数・別の請求に当たった件数・残った件数を数えたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A501 | 消込の合わせ方で、別の請求に当たる入金は何件か | 架空の請求と入金を作り、①金額だけ（期日の早い未消込から）②金額＋日付の近さ ③金額＋振込名義の正規化（全角半角・法人略号・小さい文字をそろえ、手数料を引いた額も許す）④請求番号があれば番号、なければ③ で消し込み、正解と照合。毎月同じ金額を請求する会社の割合を0〜80%に変えてくり返す | `src/a501_matching.py`、`src/02_rownumber_match_duckdb.sql`、`src/01_matching_tsql.sql`（T-SQL 版、未検証） |

## 主な結果
- **同じ金額の請求**：請求の57.5%は、ほかの請求と金額が同じ
- **①金額だけ**：入金5,746件のうち、別の請求に消し込まれたのが2,146件（37.3%）、残ったのが986件。正しく当たったのは2,614件（45.5%）
- **②金額＋日付の近さ**：別の請求1,982件、残り1,001件。日付だけではあまり減らない
- **③金額＋名義の正規化**：別の請求631件（11.0%）、残り847件
- **④請求番号→なければ③**：別の請求389件（6.8%）、残り730件
- **①のまちがいの中身**：別の会社の同じ金額の請求が2,113件、同じ会社の別の月が33件。分割入金の片方を別の請求に当てたものが65件
- **SQL の ROW_NUMBER で金額ごとに順番を振って結ぶ方法**（DuckDB）は、①と1件も違わない結果になった
- **同じ金額を請求する会社の割合を変えると**：①のまちがいは0%で11.1%、40%で37.1%、80%で65.0%。③は0.04%→11.4%→21.8%、④は0.03%→7.1%→13.2%

## 動かし方
```
pip install -r requirements.txt
cd src && python a501_matching.py
```

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した
- DuckDB の ROW_NUMBER による結び方と①が同じ結果になること（コード内で比較）
- 同じ会社・同じ金額・同じ期日の請求どうしは入れ替えても同じなので、正しい消込として数えた（入れ替えも誤りとする数え方 strict_wrong も results に残した）

## データ
- `data/fictional_customers.csv`、`data/fictional_invoices.csv`、`data/fictional_payments.csv`：架空の得意先・請求・入金（seed 501）。振込手数料は440・660・770円、分割は2回、名義が別（親会社など）の入金が6%

## 注意（言えないこと）
- 架空のデータ。まちがいの件数は、置いた同じ金額の割合・手数料・名義の割合で決まる
- 会計や税務の処理（どの請求に当てるべきか、差額をどう扱うか）を勧めるものではない。照合のしかたで件数がどう動くかを数えたもの
- 実際の銀行の入金明細の形式や、市販の消込の仕組みは試していない
- T-SQL 版は SQL Server 本体では動かしていない（未検証）
