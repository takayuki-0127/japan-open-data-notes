# 01_取得（ブラウザで実行）

家計調査（総務省統計局）年報 2024年「＜品目分類＞1世帯当たり年間の品目別支出金額，購入数量及び平均価格 5 時系列（2002年～2024年）－二人以上の世帯」の Excel 9ファイルを、e-Stat のページ上で取得した。

- statInfId：000040297518〜000040297526（穀類、魚介類、肉類・乳卵類、野菜・海藻（2ファイル）、果物、油脂・調味料・菓子類、調理食品・飲料、酒類・外食、住居・光熱・水道）
- e-Stat（https://www.e-stat.go.jp/）のページを開き、開発者ツールのコンソールで次を実行すると、各シートを CSV 文字列にした JSON（`data/raw/f113_kakei_items.json`）ができる。

```js
// SheetJS を読み込む
await new Promise(r => { const s = document.createElement('script'); s.src = 'https://cdn.jsdelivr.net/npm/xlsx@0.18.5/dist/xlsx.full.min.js'; s.onload = r; document.head.appendChild(s); });
const out = {};
for (let id = 40297518; id <= 40297526; id++) {
  const sid = '0000' + id;
  const b = await (await fetch('/stat-search/file-download?statInfId=' + sid + '&fileKind=0')).arrayBuffer();
  const wb = XLSX.read(b, { type: 'array' });
  out[sid] = {}; for (const n of wb.SheetNames) out[sid][n] = XLSX.utils.sheet_to_csv(wb.Sheets[n]);
  await new Promise(r => setTimeout(r, 1500));   // サーバーに負担をかけないよう間をあける
}
const a = document.createElement('a'); a.href = URL.createObjectURL(new Blob([JSON.stringify(out)])); a.download = 'f113_kakei_items.json'; a.click();
```

公表の消費者物価指数（類別、月次）は F103 で取得した `cpi_chubunrui_f12.csv.gz`（2020年基準 長期時系列 中分類指数、e-Stat 統計表 000032103842）をそのまま使った。
