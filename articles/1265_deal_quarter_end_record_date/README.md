# 1265 期の終わりに受注が集まって見えるのは、決まる日が寄るからか、記録を付ける日が寄るからか？（受注の見込み）

商談の記録で受注を日付ごとに数えると、期の終わりに受注が集まって見えることがあります。本当に期の終わりに決まる商談が多いのかもしれません。けれども、受注が決まってから記録を付けるまでに日数があき、期の締めの前に付けていなかった分をまとめて付けると、決まった日が均等でも、記録の日付は期の終わりに寄ります。記録の「決まった日」の欄に、記録を付けた日をそのまま書く人がいると、その欄も寄ります。**ここでは、作成者が置いた架空の会社の受注（期の最後の14日に決まる割合・決まってから記録を付けるまでの日数・期をまたぐ分を期の最後に付け直す割合・「決まった日」の欄に本当の日を書く割合を作成者が置き、乱数で日付を作ったもの）で、期の受注のうち最後の14日に入る割合を、⓪本当の決まった日、①記録を付けた日、②記録の「決まった日」の欄で数え、①の上ずれを「決まる日が寄る分」と「記録の付け方の分」に分けました。決まる日は寄らないが記録がおくれる場面と、決まる日が寄るが記録はその日に付ける場面を比べ、置き方を変えた27通りでも確かめました。**

例の会社・商談は架空のもので、実在の会社の数字や、商談の記録の仕組みを表すものではありません。ここでの「記録を付ける日」は商談の記録の日付の付け方のことで、会計の売上をいつ計上するかの決まりの話ではありません。売上の目標の立て方、締めの決め方、担当の評価の決め方の助言はしていません。

関連する記事：1000「再来場率は、何日以内で数えるかでどう変わるのか？」は、データを締めた日の直前の人をどう数えるかで値が変わることを扱っています。1268「週ごとに見直した見込みが期の終わりほど当たって見えるのは、見込みが良くなったからか、決まった分が増えたからか？」は、週ごとの見込みが期の終わりほど当たって見えるのが、決まった分が増えたためかどうかを扱っています。この記事は、締めの前後で記録の日付がどこに寄るかに絞ります。

## 主な結果

### 基本の置き方（500回、`results/a1265_main.json` の `headline`）
| 数えた日付 | 期の最後の14日に入る受注の割合 | 期の最後の3日 | 期の最初の14日 |
|---|---|---|---|
| ⓪本当の決まった日 | 28.04% | 6.02% | 13.04% |
| ①記録を付けた日 | **31.95%**（10〜90%で30.55〜33.2%） | **15.72%** | 9.73% |
| ②記録の「決まった日」の欄 | 29.99% | 10.86% | 11.38% |
| 均等なら | 15.38% | 3.3%（3÷91） | 15.38%（14÷91） |

- ①の上ずれ16.57ポイントのうち、**決まる日が寄る分は12.66ポイント、記録の付け方の分は3.91ポイント（上ずれの23.6%）**だった。決まる日が寄る分は、置いた c からの式（15%×(1−15.38%)）どおり
- 記録の日で数えると、最後の3日の割合は本当の決まった日の6.02%から15.72%に増え、最初の14日の割合は13.04%から9.73%に減った
- 期の受注のうち、期の最後に付け直したものは10.3%、次の期に付いたものは2.6%だった

### 2つの場面（各200回、`results/scenarios.csv`・`results/weekly.csv`）
| | A：決まる日は寄らない・記録が平均14日おくれる | B：決まる日が寄る・記録はその日に付ける |
|---|---|---|
| ⓪本当の決まった日で最後の14日 | 15.41% | 28.13% |
| ①記録を付けた日で最後の14日 | **27.76%** | **28.13%** |
| ②「決まった日」の欄で最後の14日 | 21.61% | 28.13% |
| ①で最後の3日 | 15.63% | 6.0% |
| ①で最初の14日 | 7.65% | 13.1% |

- **記録を付けた日で数えた最後の14日の割合は、AとBでほぼ同じ（27.76%と28.13%）だった**。Aは決まる日が寄っていないのに、記録の付け方だけで寄って見えた
- AとBは、最後の3日の割合（15.63%と6.0%）と、最初の14日の割合（7.65%と13.1%）で分かれた。Aでは最後の週に記録が集まり、期のはじめの週は記録が少なかった
- Bでは記録はその日に付けるので、3つの日付は同じ値になった（作りどおり）

### 確かめ：27通り（各40回、`results/grid.csv`）
- ①で最後の14日に入る割合は15.39〜51.56%、⓪は15.27〜41.11%だった
- 記録の付け方の分（①−⓪）は−3.73〜+15.38ポイントだった。記録のおくれが0日なら0ポイント（作りどおり）。27通りのうち7通りで、記録の付け方の分が決まる日が寄る分より大きかった
- **期をまたぐ分を期の最後に付け直す割合が50%で、決まる日が強く寄る（c＝30%）とき、記録の付け方の分はマイナス（−3.69・−3.73ポイント）になった**。期の終わりに決まった受注の一部が次の期に付き、記録の日では期の終わりが少なく見えた
- ①で最後の3日の割合は、おくれ0日で3.3〜8.79%、7日で7.04〜25.87%、14日で10.91〜35.63%だった。⓪の最後の3日の割合は3.22〜8.8%だった。最後の3日の割合は、付け直しが少ないとき（7日・50%で7.04%）は決まる日が寄る場合（おくれ0日で最大8.79%）と重なり、分け目にならなかった

## 注意（言えないこと）
- 架空のデータと、作成者が置いた決まり方・記録の付け方です。おくれの形、付け直しを期の最後の3日に置いたこと、「決まった日」の欄の書き方の割合で、記録の付け方の分の大きさは変わります
- 最後の3日・最初の14日の割合でAとBが分かれたのは、この2つの場面の比べです。27通りの中には、記録の日付だけでは見分けられない組み合わせがありました
- 決まる日が期の終わりに寄る理由（相手の会社の予算の締めなど）は置いておらず、扱っていません
- 会計の売上の計上の日付や決まりは扱っていません。この記事の「記録」は商談の記録の日付です
