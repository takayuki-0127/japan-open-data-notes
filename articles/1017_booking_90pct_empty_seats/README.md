# 1017 予約の埋まり具合が9割でも、当日の席はどれだけ空くのか？（予約とキャンセル）

「前日の夜の時点で、予約は9割埋まっている」と聞くと、当日もほぼ9割の席が埋まると思いがちです。けれども、そのあとに取り消し・無断で来ない人・人数の減りがあり、さらに「9割」を人数で数えたのか卓で数えたのかでも、当日の席の空き方は変わります。**ここでは、作成者が乱数で作った架空の飲食店（2人卓8卓・4人卓8卓＝48席、夜1回の営業。取り消し・無断・人数の減りの起きやすさを作成者が置いたもの）の20,000日で、前日の夜に9割前後埋まっていた日に、当日48席のうち何%に人が座ったかを数え、空いた席の内訳を分けました。置き方を変えた27通りと、当日の飛び込みの客がいる場合も確かめました。**

予約に遅れて来る人が後の人の待ちをどれだけ増やすかは関連する記事 877、キャンセル率の分母の話は 1018、予約を多めに取ったときに断る人の数え方は 1019、前日までの取り消しと当日の無断を1つの率にまとめると何が見えなくなるかは 1021、同じ人の重複した予約で前もっての埋まり具合が押し上げられる話は 1024、予約を締め切る時刻で埋まり具合の見え方が変わる話は 1025 で扱っています。この記事は「前日の夜の埋まり具合と、当日の着席の差」に絞ります。

## 主な結果

### 前日の夜に9割前後埋まっていた日の、当日の48席（基本の置き方、`results/a1017_main.json`）
| | 人数で85〜95%の日 | 卓で85〜95%の日 |
|---|---|---|
| 日数（20,000日のうち） | 5,331日 | 2,631日 |
| 前日の夜の埋まり（人数） | 88.88% | 78.33% |
| 前日の夜の埋まり（卓） | 99.11% | 90.7% |
| **当日座った人数÷48席（平均）** | **74.99%** | **66.11%** |
| 当日座った人数÷48席（10〜90%の日） | 64.58〜85.42% | 54.17〜79.17% |
| 当日75%未満の日 | 42.34% | 77.92% |
| 当日90%以上の日 | 1.29% | 0.08% |
| 当日空いた席（平均） | 12.01席 | 16.27席 |

- **人数で9割前後（平均88.88%）埋まっていた日でも、当日座ったのは48席の平均74.99%だった**。当日も90%以上が座った日は1.29%だった
- 人数で9割前後の日は、卓ではほぼ満席（99.11%）だった。人数で数えた残りの1割は、ほとんどが予約の入った卓の余り（2人の組が4人卓に座るなど）で、もう予約を受けられない席だった
- 卓で9割前後の日は、人数ではまだ78.33%で、当日座ったのは平均66.11%だった。**同じ「9割」でも、卓で数えたか人数で数えたかで、当日の着席は8.88ポイント違った**

### 当日の48席の内訳（平均、48席に対する%）
| | 人数で85〜95%の日 | 卓で85〜95%の日 |
|---|---|---|
| 座った | 74.99% | 66.11% |
| 予約のない卓の席 | 0.71% | 10.5% |
| 予約の入った卓の余り | 10.41% | 11.17% |
| 前日の夜からの取り消し | 7.05% | 6.15% |
| 無断で来ない | 4.13% | 3.64% |
| 人数の減り | 2.7% | 2.43% |

- 前日の夜の予約の人数のうち、当日座ったのは84.37%（人数で9割前後の日）。これは置いた取り消し8%・無断5%・人数の減り10%から出る式の値（84.35%）どおりで、新しく数えた値ではない。新しく数えたのは、卓の余りの大きさ、日ごとの散らばり、人数と卓の数え方の違い
- 卓の余りは、組の人数と卓の大きさの組み合わせで決まる。置いた組の人数の割合では、48席の約1割だった

### 確かめ：取り消し×無断×組の人数（27通り、各3,000日、`results/sensitivity_grid.csv`）
- **人数で9割前後の日に当日座った割合（平均）は、置き方で64.76〜81.62%と動いた**。取り消し4%・無断2%でいちばん高く、取り消し15%・無断10%でいちばん低かった
- 当日75%未満の日の割合は12.87〜84.9%、卓の余りは48席の7.88〜12.14%だった
- 27通りのどれでも、当日座った割合の平均は前日の夜の埋まり（人数）を下回った。人数で9割前後の日の卓の埋まりは96.28〜99.81%と、どの置き方でもほぼ満席だった

### 確かめ：当日の飛び込みの客（基本の置き方、各5,000日、`results/sensitivity_walkin.csv`）
| 飛び込みの客（1日平均） | 当日座った人数÷48席（平均） | 10〜90%の日 | 当日90%以上の日 |
|---|---|---|---|
| 0組 | 74.91% | 64.58〜85.42% | 0.75% |
| 2組 | 80.94% | 70.83〜89.58% | 5.84% |
| 4組 | 83.87% | 77.08〜89.58% | 9.11% |

- 飛び込みの客が空いた卓に入ると当日の着席は上がったが、1日平均4組でも83.87%で、前日の夜の埋まり（人数）には届かなかった。卓の余りは飛び込みでは埋まらないため（仕組みからの説明）
- 0組の行（74.91%）は本表（74.99%）と乱数が違うための差

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約12秒）
- 前日の夜の予約の人数のうち当日座った割合（84.37%）が、置いた取り消し・無断・人数の減りからの式の値（84.35%）と合った。卓で9割前後の日も84.4%対84.3%
- 内訳の6つ（座った・予約のない卓・卓の余り・取り消し・無断・人数の減り）を足すと100%になる
- 「当日座った割合が前日の夜の埋まり（人数）を下回る」は、27通りと飛び込みの3通りのすべてで同じだった。下回る大きさは置いた取り消しと無断の率で大きく動く

## 注意（言えないこと）
- 架空のデータです。取り消し・無断・人数の減りの率、組の人数の割合、卓の数は作成者が置いたもので、「74.99%」は置き方で64.76〜81.62%と動きます。実在の店の予約を測ったものではありません
- 予約の人数のうち当日座る割合（84.37%）は、置いた率からの式どおりです。実際の店では、この率そのものを自分の店の記録で数える必要があります（推測）
- 取り消しと無断は、組ごとにでたらめに決まると置きました。雨の日にまとめて取り消す、大きな組ほど取り消しやすい、といった偏りは入れていません
- 卓をつなげて5人以上の組を受ける、席を入れ替えて2回転する、といった運び方は入れていません
- 空いた席を減らすために予約をどれだけ多めに取るべきか、キャンセル料をどう決めるべきかは、この記事では扱いません。数え方だけを比べています
