# 844 少ない週の次は、必ず伸びて見えるのか？（SNSと動画）

動画やSNSの運用では、再生が少なかった週のあとに、サムネイルや投稿の時間を変える「テコ入れ」をすることがよくあります。次の週に再生が戻ると、テコ入れが効いたように見えます。しかし、週ごとの再生数はたまたま上下するので、少なかった週の次は、何もしなくても戻りやすい形をしています。**ここでは、作成者が乱数で作った架空の動画アカウント（本当の再生の水準を作成者が置き、基本では60週ずっと変わらないとしたもの）で、少ない週の次がどれだけ伸びて見えるか、テコ入れの効き目が比べ方でどう見えるかを数えました。**

1年目の1位が2年目に下がる形は関連する記事 830、低評価に返信した店の前後比較は関連する記事 810 で扱っています。同じ企画の中では、1本のバズで月の平均が動く話を関連する記事 840、同じ内容を2回投稿したときの偶然の差を 845 で扱っています。この記事は、週ごとの数字を「先週と比べる」ときの見え方と、正しい比べ方に絞ります。

## 主な結果

### 少ない週の次の週（基本の置き方）
| | 値 |
|---|---|
| 少ない週の数（全体の週に対する割合） | 35,738週（32.5%） |
| 次の週が少ない週より伸びた割合 | **79.5%** |
| 少ない週と比べた次の週の伸び（中央値） | **+40.2%** |
| 前の4週の平均と比べた次の週の伸び（中央値） | −12.5% |
| 次の週が前の4週の平均を上回った割合 | 36.4% |

- 本当の水準は変えていないのに、少ない週の次は79.5%が伸び、伸びは中央値で40.2%だった。「必ず」ではないが、8割の週で伸びて見えた
- 逆に、前の4週の平均と比べると、次の週は中央値で12.5%少なかった。少ない週は「前の4週がたまたま多かった週」でも選ばれるため、前の4週の平均も高めに出ている
- 逆向きも同じで、多い週（前の4週の平均の1.25倍超）の次の週が多い週より伸びたのは16.6%だけで、中央値で32.4%下がった

### テコ入れの見かけの効き目
| 比べ方 | 本当の効き目 0% | 本当の効き目 +10% |
|---|---|---|
| ①前の週（少ない週）と比べる | **+40.6%** | +54.6% |
| ②前の4週の平均と比べる | −12.5% | −3.6% |
| ③テコ入れしなかった少ない週と比べる | **+0.5%** | **+10.5%** |

- 効き目0%のテコ入れでも、先週と比べると40.6%伸びて見えた
- 前の4週の平均と比べると、今度は逆に効き目10%のテコ入れがマイナスに見えた
- 同じように少なかった週で、テコ入れしなかった週と比べると、本当の効き目（0%・10%）に近い値（+0.5%・+10.5%）になった

### 確かめ：揺れの大きさ・続く揺れ・少ない週の線を変えると（27通り、`results/sensitivity.csv`）
| 揺れの大きさ | 続く分 | 9割未満の線 | 8割未満の線 | 7割未満の線 |
|---|---|---|---|---|
| 0.2 | 0% | +21.0% | +30.2% | +41.1% |
| 0.35 | 0% | +31.6% | +40.6% | +51.7% |
| 0.35 | 50% | +20.1% | +26.2% | +34.2% |
| 0.35 | 80% | +11.3% | +15.0% | +19.3% |
| 0.5 | 0% | +42.4% | +51.5% | +64.0% |

（表は、少ない週と比べた次の週の伸びの中央値。27通りのうち5行を抜き出した）

- 少ない週と比べた次の週の伸びは、27通りで+7.9〜+64.0%、伸びた割合は63.6〜93.9%だった。揺れが大きいほど、少ない週の線が深いほど、揺れが次の週以降に続く分が少ないほど、大きく伸びて見えた
- 前の4週の平均と比べた伸びは、27通りすべてでマイナス（−32.8〜−6.1%）だった。揺れが続く分が多いと、少ない週は本当に水準が下がった週でもあるため、さらにマイナスになった
- テコ入れしなかった少ない週と比べた見かけの効き目（本当は0%）は、27通りで−1.4〜+1.0%に収まった

## データ
- `data/weekly.csv`：はじめの20アカウントの60週。account_id・week・true_level（本当の水準）・views（再生数）・prior4_mean（前の4週の平均）・low_week（少ない週なら1）

## 注意（言えないこと）
- 架空のデータです。揺れの大きさ、揺れの続き方、少ない週の線は作成者が置いたもので、伸びて見える大きさはこれで決まります（+7.9〜+64.0%）
- 基本では、本当の水準は60週ずっと変わらないと置きました。実際のアカウントは伸びたり落ちたりするので、少ない週の一部は本当に水準が下がった週です。その分は確かめ（続く揺れ）で一部だけ入れています
- テコ入れは、少ない週の半分にでたらめに行うと置きました。実際には「とくに悪かった週にだけテコ入れする」ことが多く、その場合はテコ入れしなかった週と比べても、少なさの深さをそろえないとずれます（推測）
- 実在の動画サイトや SNS の再生数の動き方を表すものではありません
