# 152 スマートフォンの保有率が9割を超えるのは何歳までか（通信利用動向調査）

総務省「通信利用動向調査」世帯構成員編の「保有するモバイル端末」の表で、年齢別のスマートフォン保有率を2016〜2025年で並べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A152 | スマホの保有率が9割を超えるのは何歳までか。年齢による差はどう縮まったか | 年齢別の保有率の推移、年齢カーブの比較、おおよそ同じ世代の10年後との比較、高齢層のスマホ以外の携帯電話との内訳 | `src/a152_smartphone.py` |

## 主な結果
- 保有率が9割以上の年齢層は、2016〜2019年は20代・30代だけ。2021年に40代、2022年に50代が加わり、2025年は20〜50代が93〜94%
- 60代は 33.4%（2016年）→ 88.6%（2025年）、70代は 13.1% → 68.1%、80歳以上は 3.3% → 33.0%
- 2016年の50代（66.0%）は、9年後の2025年に60代として88.6%。60代（33.4%）→ 70代 68.1%、70代（13.1%）→ 80歳以上 33.0%
- 2025年、80歳以上の54.7%が携帯電話かスマホを持ち、そのうち約4割はスマホ以外の携帯電話だけ

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a152_smartphone.py
```

## 注意
- 2020年の表は見出しの形が違い、同じ形で取り出せなかったため除いています
- 2016年はモバイル端末・携帯電話の合計の列がなく、スマートフォンの保有率だけです。2017〜2019年は携帯電話の列がありません
- 2025年の6〜12歳の値（31.6%）は前年（49.9%）から大きく下がっており、集計の仕方の変更の影響がありえます。記事では6〜12歳の変化は扱っていません
- 「おおよそ同じ世代」は10歳刻みの年齢層を9年後と比べたもので、厳密な同じ人の追跡ではありません
- 標本調査で、年や年齢層によって回答者数が違います
