# 579 店ごとの比率を平均するか、合計どうしで比を取るかで、全体の比率はどれだけ違うのか（手法の解説・正解の分かるデータで試す）

店ごとの購入率（購入した客÷来店客）から「全体の購入率」を出すとき、店の購入率をそのまま平均する（単純平均）か、全店の合計どうしで割る（合計の比）かで、答えが変わります。**ここでは、来店客数が大きく違い、小さい店ほど購入率が高い架空の50店（2年分）で、単純平均・中央値・来店客数で重み付けた平均・合計の比を比べました。さらに、店の大きさと購入率の結びつきを変えた1,000回ずつの試しと、前年比の向きが食い違う割合を数える2,000回ずつの試しをしました。** 数字は置いた前提で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A579 | 店ごとの比率の平均と合計の比は、どれだけ違うか。前年比の向きは変わるか | 来店客数を対数正規分布で置き、購入率を「店の大きさ（来店客数の対数を標準化）1標準偏差あたり−4ポイント」＋ばらつきで置いた50店。2年目は大きい店ほど購入率が上がる（1標準偏差あたり+0.6ポイント、全体で−0.3ポイント）。4つの出し方で1年目・2年目・変化を計算。SQL は DuckDB（1スレッド）で同じ値を出した。seed 579 | `src/a579_ratio_avg.py`、`src/a579_ratios.sql`、`src/a579_ratios_tsql.sql` |

## 主な結果
- **例の50店・1年目**：単純平均 29.5%、中央値 28.6%、来店客数で重み付けた平均 26.7%、合計の比 26.7%。来店客数の多い上位10店で、来店客の 42% を占める
- **前年比**：単純平均 −0.14ポイント（29.5%→29.4%）、中央値 +0.05ポイント、合計の比 +0.15ポイント（26.7%→26.9%）。単純平均では下がり、全体の購入率では上がった。購入率が上がった店は50店中20店
- 来店客数で重み付けた平均は、合計の比と必ず同じ値になる（重みを来店客数にすると、式が同じになるため）
- **差の大きさ（1,000回）**：店の大きさと購入率の結びつきがなければ、単純平均−合計の比は中央値 0.0ポイント（5〜95%で ±0.5）。1標準偏差あたり1・2・4・6ポイント違うと、差は +0.9・+1.9・+3.7・+5.6ポイント
- **前年比の向きが食い違った割合（2,000回）**：変化と店の大きさの結びつきが 0・0.25・0.5・1ポイントで、10.0%・16.7%・30.4%・44.5%

## 確かめたこと
- 空のフォルダで流し直し、results と data が一致した
- 1年目・2年目の単純平均・重み付けた平均・合計の比が、Python と DuckDB の SQL で一致すること（T-SQL 版は SQL Server では動かしていない：**未検証**）

## データ
- `data/stores.csv`：50店の1年目・2年目の来店客数と購入した客の数（乱数から作った架空の値）

## 注意（言えないこと）
- 架空のデータ。店の大きさと購入率の結びつき・変化の置き方は作成者が置いたもので、結果はこれで決まる
- どちらが「正しい」かではなく、問いで決まる。「客1人あたりの購入率」なら合計の比、「店の運営の典型的な成績」なら店ごとの値の分布（中央値など）が答えになる
- 結びつきがなくても、前年比の向きは10%ほど食い違った。変化が小さいときは、どちらの出し方でも向きはぶれやすい
- 店の数・大きさのばらつき（対数で標準偏差1）を変えた場合は扱っていない
