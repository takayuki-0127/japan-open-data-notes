# 789 学習とテストを1回だけ分けたとき、テストの成績はどれだけ振れるのか（手法の解説・正解の分かるデータで試す）

モデルの成績を測るとき、データを学習用とテスト用に1回だけ分けることがよくあります。テストの件数が少ないと、「どの行がテストに入ったか」だけで成績が大きく変わります。**ここでは、同じデータを100通りに分け直し、テストの正解率がどれだけ振れるか、2つのモデルのどちらが良いかを取り違える割合はどれだけか、を件数を変えて調べました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A789 | 1回の分割で、テストの正解率はどれだけ振れるか | 架空のデータ（x は5つの正規乱数、y は0/1をロジスティックの式で作る）。件数200・500・2,000のデータを1つずつ作り、学習7割・テスト3割の分け方を100通り。ロジスティック回帰と決定木（深さ3）。本当の正解率は10万件の別データで測る。5-fold の交差検証も分け方を変えて20回。scikit-learn。seed 789 | `src/a789_split.py` |

## 主な結果

| 件数（テストの件数） | ロジスティックのテスト正解率（100通り） | 本当の正解率 | 2つのモデルの順位が逆・同点になる割合 |
|---|---|---|---|
| 200（60件） | **60%〜82%**（標準偏差4.6ポイント） | 70% | **31%** |
| 500（150件） | 63%〜79%（3.0ポイント） | 72% | 14% |
| 2,000（600件） | 67%〜75%（1.7ポイント） | 72% | 3% |

- 200件のデータでは、分け方だけでテストの正解率が60%から82%まで動いた
- 本当はロジスティック回帰のほうが7ポイント良い（70%と64%）のに、200件では31%の分け方で決定木が同じか上に見えた（同点8%を含む）
- 5-fold の交差検証を分け方を変えて20回くり返すと、振れ（標準偏差）は200件で1.4ポイントと、1回の分割（4.6ポイント）の3分の1以下だった

## 動かし方

```
pip install -r requirements.txt
cd src && python a789_split.py
```
10秒ほどで終わります。

## 確かめたこと

- 件数が増えるほど、テストの正解率の振れが小さくなること

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 789）

## 注意（言えないこと）
- 架空のデータです。振れの大きさは、テストの件数と正解率の水準で決まります
- 交差検証で小さくなるのは「同じデータの中での分け方による振れ」です。データそのものを取り直したときの振れは、交差検証でも消えません
- 本当の正解率は、各分け方で学習したモデルを10万件の別データで測った値の平均です
