# 204 特定健診の検査値（HbA1c）の都道府県差：NDBオープンデータ

厚生労働省「第10回NDBオープンデータ」の特定健診の検査値（2022年度）から、HbA1c（過去1〜2か月の血糖の平均を表す値）が6.5%以上の人の割合を都道府県で比べたフォルダです。受診者の年齢構成の違いをならすため、全国の受診者の性・年齢構成で年齢調整しています。BMI（肥満度）との関係も見ています。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A204 | 特定健診の検査値（HbA1cなど）の都道府県差は？ | HbA1c 6.5%以上の割合の都道府県ランキング（性・年齢調整、直接法）、全国の性・年齢別の割合、BMI 25以上の割合（同じく年齢調整）との散布図・相関 | `src/a204_hba1c.py` |

## 主な結果
- 2022年度にHbA1cを測った特定健診の受診者2,292万人のうち、6.5%以上は7.26%。6.0%以上まで広げると17.67%
- 性・年齢調整後に多いのは佐賀県8.72%、茨城県8.66%、宮城県8.66%、沖縄県8.62%、熊本県8.48%。少ないのは長野県6.34%、神奈川県6.37%、東京都6.44%、京都府6.53%、鳥取県6.70%。最多と最少の差は1.38倍
- 年齢調整の前と後で順位はおおむね同じ（順位相関0.92）。東京都は調整前5.97%（最少）だが、若い受診者が多いぶんを調整すると6.44%
- 全国では男性が40〜44歳3.2%→70〜74歳16.4%、女性が1.2%→9.1%と、年齢とともに上がる。男性は女性の1.8〜2.9倍（50代前半までは2.7倍以上、70〜74歳は1.8倍）
- BMI 25以上の割合（年齢調整）は沖縄県40.3%が最多、京都府26.2%が最少。HbA1c 6.5%以上の割合との相関係数は0.53。佐賀県・石川県はBMIのわりにHbA1c高値が多く、岩手県・秋田県はBMIのわりに少ない

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a204_hba1c.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/ndb_checkup_hba1c_bmi_2022.csv | 都道府県×性×5歳階級（40〜74歳）の受診者数。HbA1c 4区分（6.5%以上、6.0〜6.5、5.6〜6.0、5.6未満、NGSP値）とBMI 4区分（30以上、25〜30、18.5〜25、18.5未満） |

- 第10回NDBオープンデータ「特定健診 検査」の「HbA1c 都道府県別性年齢階級別分布」「BMI 都道府県別性年齢階級別分布」（いずれも2022年度）。ブラウザで Excel を読み、元の6区分（HbA1c）・7区分（BMI）を上の4区分にまとめて書き写した
- 「都道府県判別不可」の行は除いた
- 元の表は10未満の値などを「‐」で伏せている。伏せた値は0として足したため、該当する区分（主に人数の少ない県・年齢の高値区分）はわずかに少なめになる

## 注意
- 特定健診の受診者（40〜74歳）の集計で、県民全体ではない。受診率や、どんな人が受けるか（被用者保険か国保か）は県によって違う
- HbA1c 6.5%以上は糖尿病が強く疑われる目安の一つだが、この集計だけで糖尿病の人の割合とは言えない（治療中の人も含まれ、他の検査や診断は見ていない）
- HbA1cの代わりに空腹時血糖だけを測った人は入らない（BMIは2,912万人、HbA1cは2,292万人）
- 年齢調整は全国の受診者の性・5歳階級の構成を重みにした直接法
- 県の差の理由（食事、運動、所得、医療へのかかり方など）は、このデータでは分からない
