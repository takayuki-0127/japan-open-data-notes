# F54 働く女性の賃金は、働いている人だけを見ると高く見えるのか？（集計データ版の Heckman 補正）

note：働く女性の賃金は、働いている人だけを見ると高く見えるのか？ 都道府県×年齢の集計でHeckmanの補正をすると、平均はほぼ動かなかった（+3%）。ただ除外制約の選び方で0.8倍〜1.2倍まで揺れた

## 問い
賃金の統計は「働いている人」の賃金です。女性は30代から「主に仕事」をしている人が6割前後に減るので、働いている人が「もともと賃金が高くなりやすい人」に偏っていれば、統計の平均は女性全体の賃金の目安より高く出ます（選択バイアス）。これを Heckman の2段階推定で補正すると、女性の平均賃金と男女の賃金差はどれだけ変わるか。

## データ（2020年、47都道府県×年齢9区分（20〜64歳の5歳階級）×男女）
- 賃金：賃金構造基本統計調査 一般労働者 都道府県別第1表（産業計・企業規模計）の所定内給与額（千円／月）と労働者数
- 働いている割合：国勢調査 就業状態等基本集計（都道府県・男女・各歳）。本体は「主に仕事」の割合（一般労働者に近い）、頑健性で「就業者」の割合。どちらも労働力状態「不詳」を分母から除く
- 都道府県の条件（X）：最低賃金（対数）、有効求人倍率、高校卒業者の進学率、総人口（対数）
- 除外制約の変数（Z）：保育所等の定員（15歳未満人口あたり）×子育て年齢（25〜44歳）、合計特殊出生率×子育て年齢

## 手法
| 段 | 中身 |
|---|---|
| 1段目 | セルの「働いている割合」を probit 変換（Φ⁻¹(p)）し、年齢＋X＋Z で加重回帰（重み＝人口）。集計データ版の probit（Berkson の最小カイ二乗） |
| 2段目 | 働いている人の平均賃金（対数）を 年齢＋X＋逆ミルズ比 λ=φ(指数)/Φ(指数) で加重回帰（重み＝労働者数）。λ の係数 θ（=ρσ）が選択の強さ |
| 補正後の賃金 | 観察された対数賃金 − θλ（全員が働いた場合の平均の推定） |
| 区間 | 都道府県を単位に引き直すブートストラップ（本体500回、頑健性200回） |

除外制約の考え方：保育の受け皿や子どもの数は「子育て年齢の女性が働くかどうか」を動かすが、「働いた場合の賃金」は直接は動かさない、という仮定です。この仮定はデータでは確かめられません。

## 主な結果（女性、本体）
- 1段目：保育所等の定員×子育て年齢 +1.31（標準誤差0.21）、出生率×子育て年齢 −0.54（0.06）。除外制約の F 値は44で、働くかどうかはよく説明できている。25〜44歳女性の「主に仕事」の割合と保育所等の定員の県の相関は0.78
- 2段目：θ = −0.04（95%区間 −0.20〜+0.49）。選択の向きははっきりしない
- 20〜64歳の平均賃金：観察 24.9万円 → 補正 25.6万円（×1.029、区間 0.70〜1.15）
- 男女の賃金差（20〜64歳、それぞれの人口で年齢を重みづけ）：観察 23.3% → 女性を補正した場合 21.0%。年齢とともに広がる形は同じ（20〜24歳 2% → 55〜59歳 34%）
- 2段目の都道府県の条件の係数は、補正の有無でほとんど変わらない（最低賃金の弾力性 0.995 → 0.980）

## 頑健性（女性、補正後÷観察）
| 設定 | θ | 補正後÷観察 |
|---|---|---|
| 本体 | −0.04 | 1.03 |
| 除外＝保育所の定員×子育て年齢のみ（F=8） | +0.23 | 0.85 |
| 除外＝出生率×子育て年齢のみ | −0.04 | 1.03 |
| 除外＝保育所の在所児×子育て年齢 | −0.07 | 1.05 |
| 除外＝県の水準そのもの | −0.23 | 1.18 |
| 除外なし（関数形だけで識別） | +0.55 | 0.67 |
| 働く＝就業者（パート含む） | −0.13 | 1.06 |
| 東京を除く | +0.32 | 0.79 |
| 25〜59歳のみ | +0.11 | 0.93 |

男性は働いている割合が9割前後で県による差が小さく、除外制約の F 値が2〜3しかないため、補正は推定できない（区間が非常に広い）。男女差の比較では男性は観察値のまま使った。全結果は `results/robustness.csv`。

## このデータで言えないこと
- 個人のデータではなく、都道府県×年齢の平均どうしの関係です。個人の Heckman 推定とは同じではありません
- 除外制約（保育・出生は賃金を直接動かさない）は仮定で、確かめられません。設定で答えが大きく変わるのはこのためです
- 賃金は一般労働者（短時間労働者を除く）の雇用者、働いている割合は自営を含む就業者で、対象がそろいきっていません
- 補正後でも残る男女差を、差別などの理由と結び付けることはできません（職種・勤続・労働時間などの違いはこの集計では分けられない）
