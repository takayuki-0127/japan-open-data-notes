# 780 DBSCAN の eps を少し変えると、まとまりの数と外れ値の数はどれだけ変わるのか（手法の解説・正解の分かるデータで試す）

DBSCAN は、近くに点が多く集まっている所を「まとまり」とし、どのまとまりにも入らない点を「外れ値」とする分け方です。「近く」の半径を eps で決めます。まとまりの数を先に決めなくてよいかわりに、eps の決め方で答えが変わります。**ここでは、本当の分け方が分かる架空のデータ（密度の違うまとまり3つと、散らばった外れの点）で、eps を0.1〜1.5に変えたとき、まとまりの数・外れ値の割合・正解との一致がどう変わるかを見ました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A780 | eps を変えると、まとまりの数と外れ値はどう変わるか | 2次元のまとまり3つ（標準偏差0.25・0.5・1.0、各300点）と外れの点60点（6.25%）。DBSCAN（min_samples=10）で eps を0.1〜1.5（0.05刻み）。k 距離の図（10番目に近い点までの距離）の曲がり目でも eps を選ぶ。データは10組。正解との一致は ARI（外れ値も1つの組として扱う）。seed 780 | `src/a780_dbscan.py` |

## 主な結果

| eps | まとまりの数 | 外れ値の割合 | 正解との一致（ARI） |
|---|---|---|---|
| 0.1 | 3.2 | **73%** | 0.27 |
| 0.2 | **4.7** | 41% | 0.66 |
| 0.3 | 4.8 | 21% | 0.77 |
| 0.5 | 3.0 | 8.6% | 0.92 |
| 0.8 | 3.0 | 4.6% | **0.95** |
| 1.2 | 2.9 | 2.5% | 0.90 |
| 1.5 | **1.6** | 1.6% | 0.31 |
| k 距離の図で選ぶ（0.47〜0.68） | 3.0 | 6.9% | 0.94 |

（10組の平均。正解はまとまり3つ、外れ値6.25%）

- eps 0.1〜0.3 では、薄いまとまり（標準偏差1.0）が外れ値になったり、細かく割れたりした。外れ値は21〜73%で、まとまりは4〜5個に増えた
- eps 0.5〜1.2 では、まとまりはほぼ3つで、一致は0.90〜0.95だった。この範囲の中なら、少し変えても答えはあまり動かなかった
- eps 1.5 では、まとまりどうしがつながり、平均1.6個になった
- k 距離の図の曲がり目から選んだ eps（0.47〜0.68）は、一致0.94だった

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 780）

## 注意（言えないこと）
- 架空のデータです。まとまりの密度・間隔と外れの点の数は作成者が置いたもので、よい eps の範囲はこれで決まります
- min_samples は10に固定しました。min_samples を変えると、よい eps の範囲も変わります
- 外れの点のうち、たまたままとまりの近くに落ちたものは、どの eps でもまとまりに入ります。外れ値の割合が正解の6.25%と一致しても、同じ点を当てているとは限りません
