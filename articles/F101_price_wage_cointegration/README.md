# F101 物価と賃金は、長い目で見ると一緒に動いているのか？（共和分と誤差修正モデル）

## 問い
物価が上がれば、いずれ賃金も追いつくのか。2つの系列が短期にはばらばらでも「長い目で見ると一定の関係に戻る」なら、統計では **共和分** の関係があると言う。日本の物価と賃金にその関係があるのか、あるなら、ずれはどちらがどれくらいの速さで埋めるのかを調べた。

## データ
| 系列 | 内容 | 出典 |
|---|---|---|
| 物価 | 消費者物価指数 2020年基準「持家の帰属家賃を除く総合」（月次、実質賃金の計算に使われる系列）。頑健性で「総合」「生鮮食品を除く総合」 | 総務省統計局（e-Stat、statInfId 000032103842。F12 で取り込み済み） |
| 賃金 | 毎月勤労統計調査「きまって支給する給与」指数（5人以上・調査産業計・就業形態計、月次）。頑健性で「現金給与総額」と時間あたり（きまって支給する給与 ÷ 総実労働時間） | 厚生労働省（e-Stat、statInfId 000032189777。F12 で取り込み済み） |
| 生産性（参考） | 実質GDP（季節調整済み）÷（常用雇用指数×総実労働時間指数） | 内閣府 四半期別GDP速報（F18 で取り込み済み） |

- 月次を四半期平均にし、対数をとって STL（周期4）で季節成分を除いた。1970年1〜3月期から2026年4〜6月期（226期）。
- 毎月勤労統計の長期時系列の指数は、標本の入れ替えなどの段差を公表元が接続したもの。接続の方法による影響は残る（F66 参照）。

## 手法
1. **単位根検定**（ADF・KPSS）：各期間で、物価と賃金が「1回差分をとると定常」（I(1)）かを確かめる。
2. **Engle–Granger**：賃金を物価に回帰し、残差（長期の関係からのずれ）が定常かを検定する。定数だけ／定数＋トレンドの2通り。
3. **Johansen**：2変数の VAR から共和分の数（ランク）を検定する。ラグ 1・2・4・6、確定項は定数／トレンド。
4. **誤差修正モデル（ECM）**：前の期のずれ ec が、次の期の賃金の伸びと物価の伸びをどれだけ動かすか（調整の係数 α）。ずれの半減期は ln(0.5)/ln(1+速さ) で近似。
5. 15年（60四半期）の窓を2四半期ずつずらした Engle–Granger の p 値。
6. 期間は 1981–1995／1996–2019（コロナ前）／1996–2026／2013–2026 に分けた。1970年代は物価上昇率そのものが大きく下がっており、物価が I(2) に近いふるまいをするため、1970–2026 の通しは参考にとどめた。

## 結果
**1996年以降の30年では、物価と賃金を結ぶ長期の関係は見えなかった。**
- 1996–2019：Johansen は 8通りすべてで「関係なし」、Engle–Granger は 18通り中 3通りだけ。賃金を物価に回帰した係数は 0.17〜0.30（物価1%に対して賃金0.2〜0.3%）。
- 1996–2026：Johansen 1/8、Engle–Granger 3/18。
- 1996年1〜3月期を100とすると、2026年4〜6月期は 物価 121.8、賃金 112.6。実質賃金は 2007年ごろの約103 から 92.5 まで下がった（図1）。
- 15年の窓では、1983〜1999年あたりの窓は「関係あり」が多いが、2000年代以降に終わる窓はほぼすべて「関係なし」（図2）。

**2013–2026年に限ると関係が出るが、もろい。**
- Engle–Granger 10/18、Johansen 6/8 で「関係あり」。長期の係数は 0.64（きまって支給する給与×持家の帰属家賃を除く総合）。賃金と物価の系列を変えると 0.45〜1.16。
- 誤差修正モデルでは、ずれに反応していたのは **物価の側**（α物価 ＝ +0.39〜+0.73、p＜0.01）で、賃金の反応（α賃金 ＝ −0.13〜−0.23）は有意でなかった。ずれの半減期は約1〜1.4四半期。Johansen の VECM（ラグ2）でも α賃金 −0.20（t ＝ −1.85）、α物価 +0.26（t ＝ 2.61）で同じ向き。
- ただし、
  - 始まりの年を 2012年以前にすると関係は消える（2009〜2012年始まりの p ＝ 0.14〜0.86）。2017年始まりでは p ＝ 0.052（図4）。
  - 2013–2019年だけでは関係なし（p ＝ 0.50、消費税ダミーを入れても 0.28）。
  - 時間あたりの賃金では、6通りすべてで関係なし。
  - 消費税の段差ダミーを入れると p は 0.007 → 0.067 に上がる。2014年の引き上げを外した 2015–2026 では、ダミーありでも p ＝ 0.047。
- 「物価がずれを埋める」は、短い期間（54四半期）に消費税の引き上げとエネルギー価格の大きな動きが重なった結果の可能性がある（推測）。

**1981–1995**：Engle–Granger 0/18、Johansen 3/8 で、はっきりしない。賃金の伸びが物価を上回り（係数 1.8、トレンドを入れると 0.4）、生産性の伸びを入れないと関係が書けない時期と考えられる（推測）。

**生産性を入れた3変数（1994–2026、参考）**：Johansen はランク1以上を示すが、生産性の係数が −0.03〜0.24 とラグで大きく変わり、解釈できなかった。生産性は毎月勤労統計の雇用と時間で割った近似。

## 頑健性
| 変えたもの | 内容 | 結論への影響 |
|---|---|---|
| 期間 | 4期間＋15年の窓、2013年前後の始まりの年 2009〜2017 | 1996年以降は関係なし。2013年以降の関係は始まりの年に敏感 |
| ラグ | Johansen 1・2・4・6、ECM 1・2・4 | 1996–2019 はどのラグでも関係なし。2013–2026 は 6/8 |
| トレンドの入れ方 | 定数／定数＋トレンド（EG・Johansen・ECM） | 傾向は同じ |
| 賃金・物価の系列 | 賃金3系列×物価3系列 | 2013–2026 の関係は時間あたり賃金では出ない |
| 消費税 | 段差ダミー（EG）、2014Q2・2019Q4 のダミー（ECM） | EG は p が 0.067 に上がる。ECM の α物価 は +0.30（p ＝ 0.003）で残る |

## 言えないこと
- 共和分がないことは「物価と賃金は無関係」という意味ではない。長期に一定の比率へ戻る関係が、このデータと期間では確かめられなかったということ。検定の検出力は、30年の四半期データでも高くない。
- 2013年以降の「物価がずれを埋める」は、因果（賃金が上がると物価が上がる）を示していない。消費税・エネルギー価格・補助金など、賃金と関係のない物価の動きが重なっている。
- 賃金は5人以上の事業所の平均で、パートの比率の上昇（構成の変化）を含む。1人ひとりの賃金が物価に追いついたかは、この指数ではわからない。
- 生産性や労働分配率を十分に入れたモデルではない。生産性は近似。
