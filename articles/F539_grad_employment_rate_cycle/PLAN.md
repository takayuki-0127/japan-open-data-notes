# F539 PLAN（事前登録）：大学を卒業する人の就職率は、景気でどれだけ動くのか？

作成：2026-11-19 08:52（結果の数字を集計する前に書いた）

## 問い
「就職氷河期」「売り手市場」という言い方があるように、大学を出た年の求人の多さで、就職できる人の割合は大きく変わると言われます。では、大学（学部）を卒業した人のうち就職した人の割合は、求人倍率が 0.1 上がると何ポイント動くのか。動き方は、上がるときと下がるときで同じか。1990年代のあとで、景気と関係のない分（長い目で見た水準）は変わったのか。

知りたい人：大学で就職を支える仕事の人、採用の担当で毎年の新卒の動きを読む人、統計の読み方を学ぶ人。

## データ
- 文部科学省「学校基本調査」年次統計「卒業者に占める就職者の割合」（1950〜2025年、各年3月の卒業者、5月1日調査）。大学（学部）・短期大学の計・男・女。
- 厚生労働省「一般職業紹介状況（職業安定業務統計）」の長期時系列「有効求人倍率（パートタイムを含む一般）」の年度平均（1963年度〜）。新規学卒者は含まない。
- 頑健性：同じ表の「新規求人倍率」の年度平均。

## 年の合わせ方（事前に決める）
- 卒業年 t（t 年3月卒）の就職率に、t−1 年度（t−1 年4月〜t 年3月）の有効求人倍率の年度平均を合わせる（就職活動と内定の時期がおおむねこの年度に入るため）。
- 主に使う期間：1964〜2025年の卒業（求人倍率の年度平均があるのは1963年度から）。

## 取得前に見たもの（開示）
- 表の見出しの確かめのときに、大学（学部）の就職率の列を確かめる途中で、2005〜2025年の行（2010年 60.8%、2019年 78.0%、2025年 77.0% など）と、有効求人倍率の2018〜2025年の行の一部を目にした。相関や回帰は計算していない。

## 仮説と「外れ」の基準
- H1：前年度の有効求人倍率と大学の就職率は正の関係がある。1964〜2025年の水準の回帰で、倍率 0.1 あたり +1ポイント以上。+1 未満なら外れ。
- H2：年ごとの変化（差分）でも正の関係がある（共通のトレンドだけの見かけでない）。差分の回帰の係数が正で、95%信頼区間が 0 を含まない。含めば外れ。
- H3：景気が同じでも、1990年代のあと（2000年以降の卒業）は就職率の水準が低い。倍率をそろえた回帰で、2000〜2025年のダミーが −3ポイント以下。−3 より大きければ外れ。
- H4：女性の方が景気で大きく動く（係数が男性の1.2倍以上）。1.2倍未満なら外れ。

## 手法
- 水準の回帰：就職率 = a + b × 倍率(t−1) + 期間ダミー + 誤差。標準誤差は Newey-West（ラグ3）。
- 差分の回帰：Δ就職率 = c + d × Δ倍率(t−1)。上がる年と下がる年で係数を分ける（非対称の確かめ）。
- 期間別の係数：1964〜1990、1991〜2010、2011〜2025。
- ブートストラップ（年のブロック、ブロック長4、1,000回、種 20261116）で係数の区間も出す。

## 頑健性（3つ以上）
1. 倍率を新規求人倍率にする。
2. 年の合わせ方を t 年度（卒業した年の年度）や t−1 年（暦年）にする。
3. 2020〜2021年を除く。（レビューで、扱わない話題の語を括弧書きから除いた）
4. 1990年以降だけで推定する。
5. 短期大学で同じ計算をする。

## 言えないこと（予定）
- この就職率の分母は卒業者全体で、大学院に進んだ人も含む。進学する人の割合が変われば、景気と関係なく就職率が動く（この表だけでは分けられない）。
- 文部科学省・厚生労働省の「大学等卒業者の就職状況調査」の4月1日の就職率（就職を希望する人に占める割合、2025年度は98.0%）とは定義が違う。
- 就職の中身（正社員かどうか、どんな会社か）は、この表の長い系列では分からない。
- 求人倍率はハローワークの求人で、大学の新卒の求人そのものではない。関係は相関で、因果の大きさではない。
- どの年に卒業すべきか、採用をどうすべきかといった助言はしない。
