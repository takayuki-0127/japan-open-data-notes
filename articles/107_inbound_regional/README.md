## もとのリポジトリの説明

以下は、もとのリポジトリ `accommodation-stats-japan` の README です（同じリポジトリにあったほかの記事の分も含みます）。

### accommodation-stats-japan：観光庁「宿泊旅行統計調査」で、外国人の宿泊の地方分散とコロナ後の回復を都道府県別に調べる

観光庁「宿泊旅行統計調査」の年次集計（e-Stat、2011〜2025年）から、都道府県×月の延べ宿泊者数（総数・外国人）と、国籍（出身地）別の外国人延べ宿泊者数を取り出して使うリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| W1 | 外国人の宿泊は東京・大阪から地方に広がったのか | 都道府県別の割合、上位N県の割合、ジニ係数・HHI（と「実質的な県の数」1/HHI）、三大都市圏8都府県以外の割合、国籍別の三大都市圏以外の割合（2019年と2025年） | `src/w1_concentration.py` |
| W2 | コロナ後、宿泊者数が戻るのが早かった県・遅かった県 | 2019年の同じ月＝100とした回復率（全国の月次、都道府県の年次）、日本人・外国人別。12か月移動合計が2019年の同じ12か月を初めて上回った月、日本人と外国人の回復の相関 | `src/w2_recovery.py` |

#### 主な結果
- **W1**：外国人延べ宿泊者数は1,842万人泊（2011年）→1億1,566万（2019年）→1億7,992万（2025年）。三大都市圏8都府県（埼玉・千葉・東京・神奈川・愛知・京都・大阪・兵庫）以外の割合は33.5%（2011年）から2017年の41.0%まで上がり、地方への広がりがあった。ところがコロナ後は2022年に26.0%まで下がり、2025年は33.7%と2011年とほぼ同じ水準。東京都の割合は30.7%→24.6%（2018年）→41.1%（2022年）→33.4%（2025年）。都道府県間のジニ係数は0.719（2017年）→0.797（2023年）→0.774（2025年）、1/HHI（実質的な県の数）は9.2→4.9（2022年）→6.5。日本人のジニ係数（0.39〜0.46）よりずっと高い。2019→2025年の伸びは東京都2.05倍、愛媛県2.69倍、石川県2.18倍、福岡県1.98倍に対し、千葉県0.91倍、静岡県0.89倍、佐賀県0.70倍。国籍別（従業者数10人以上の施設）では、三大都市圏以外での宿泊の割合は台湾55%、韓国52%、香港50%に対し、アメリカ17%、カナダ18%、オーストラリア21%（2025年）。中国は30%→26%、タイは39%→36%に下がった
- **W2**：全国の日本人延べ宿泊者数（2019年＝100）は2022年90.4、2023年104.1、2025年100.2。外国人は2022年14.3、2023年101.8、2024年142.2、2025年155.6。月次では日本人は2022年10月から、外国人は2023年7月から2019年の同じ月を上回ることが多くなった。2025年の日本人は47都道府県のうち18で2019年以上、外国人は39で2019年以上。日本人の回復が遅いのは福島県74、京都府79、秋田県81、山形県83、岩手県86で、12か月合計で2019年を一度も上回っていない県が14ある。早いのは奈良県121、北海道118、大阪府116。外国人の回復が遅いのは佐賀県70、滋賀県73、宮崎県81、鹿児島県84、静岡県89、千葉県91。2025年の日本人と外国人の回復率の相関は−0.11で、ほぼ無関係

#### 動かし方
`data/pref_month.csv` と `data/pref_nationality.csv` が入っているので、そのまま動きます。元の Excel から作り直すときは、e-Stat の各年の「集計結果」Excel を `data/raw/` に `shuku_2011.xls`〜`shuku_2014.xls`、`shuku_2015.xlsx`〜`shuku_2025.xlsx` の名前で置き、この2つの CSV を消してから実行してください（元のファイルは合計約57MBあるので、リポジトリには入れていません）。

```bash
pip install -r requirements.txt
cd src
python w1_concentration.py
python w2_recovery.py
```

#### 注意
- 2010年4月から、従業者数9人以下の施設も調査の対象になりました。2007〜2010年3月は従業者数10人以上の施設だけで、2010年は表の形も違うため、系列に段差ができます。このリポジトリは、通年ですべての施設がそろう2011年以降を使いました
- 国籍別（参考第1表）は従業者数10人以上の施設だけの推計で、外国人の総数は全施設の値より小さくなります（2025年は1億5,425万人泊、全施設は1億7,992万人泊）
- 日本人は「総数−外国人」で計算しました。調査の外国人は「日本国内に住所を有しない者」で、日本に住む外国籍の人は日本人の側に入ります
- 標本調査の推計値で、都道府県によっては年の間に段差があります（例：京都府の延べ宿泊者数は2018年2,045万→2019年3,075万人泊）。2019年を基準にする回復率は、2019年の値の高さにも左右されます
- 2020年以降の値は、e-Stat に載っている各年の集計結果のファイルの値です。後から改定されることがあります
- 全国旅行支援（2022年10月〜）や、県ごとの大きなイベント・災害（2024年の能登半島地震など）の影響は分けていません
