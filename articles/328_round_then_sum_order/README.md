# 328 行ごとに丸めてから足すのと、足してから丸めるのでは、どれだけ違うのか（実務の型）

架空の伝票2万枚（明細10万行、税率8%と10%）で、消費税の端数を丸める場所を4通り（明細ごと／伝票の中で税率ごとに1回／伝票全体で1回／得意先の月合計で税率ごとに1回）に変え、税額の差を数えたフォルダです。SQL は DuckDB で動かし、pandas の別計算と一致させました。T-SQL 版は `sql/01_round_order_tsql.sql`（**SQL Server 本体では未検証**）。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A328 | 税の端数を丸める場所で、伝票の税額と1か月の合計はどれだけ変わるか | 得意先400、伝票20,000枚、明細100,450行（1伝票あたり平均5.0行、単価58〜2,980円×数量1〜12）。税額は「税抜×税率÷100」を整数で計算し、切り捨て・四捨五入・切り上げの3通りで丸める | `src/a328_round_order.py`、`sql/01_round_order_tsql.sql` |

## 主な結果（切り捨て）
- ①明細ごとに切り捨てた税額は、②伝票の中で税率ごとに1回切り捨てた税額と、**伝票の72%で1円以上違った**。差は平均−1.2円、最大−8円
- 明細の行数が多いほど差が出る：2行で19%、4〜5行で77%、6〜8行で95%、9行以上でほぼ100%
- 1か月の税額の合計（丸めない合計は33,343,994.68円）：①33,303,464円（−40,531円）、②33,328,434円（−15,561円）、③伝票全体で1回 33,334,566円（−9,429円）、④得意先の月合計 33,343,623円（−372円）
- ①と②の差は1か月で24,970円（税額の0.07%）、①と④の差は40,159円
- ②と③（伝票の中で税率ごとか、伝票全体か）でも、伝票の31%で税額が違った

## 丸め方を変えると
- 四捨五入：①と②が違う伝票は37%。ただし上にも下にもずれるので、平均の差は+0.02円、1か月の合計の差は丸めない値から+683円（①）〜+19円（④）
- 切り上げ：切り捨てと向きが逆で、ほぼ同じ大きさ（①は+40,326円）

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した
- ①と②の伝票ごとの税額は、DuckDB の SQL と pandas の別計算が全伝票で一致した

## 注意（言えないこと）
- すべて架空の伝票です。差の大きさは、1伝票あたりの行数（平均5行）と、単価・数量の置き方で決まります
- 税抜の金額に税率を掛ける形だけを扱いました。税込の金額から割り戻す形、値引きの行、単価に小数がある場合は入っていません
- どの場所で丸めるべきかは、制度や取引先との決まりによります。この記事は差の大きさを数えただけで、税務の助言ではありません
- 233（集計が合わないとき）で出た「丸め」のずれを、1本に広げたものです
