note の記事「引っ越しが距離に左右される度合いは1970年までに弱まり、その後50年ほぼ同じ。東京圏へ向かう割合は西日本や中部で上がり、東北で下がった」の分析コード・データ・図です。

## もとのリポジトリの説明

以下は、もとのリポジトリ `internal-migration-japan` の README です（同じリポジトリにあったほかの記事の分も含みます）。

### internal-migration-japan：住民基本台帳人口移動報告の長期時系列（1954〜2025年）で、都道府県をまたぐ引っ越しの70年を調べる

総務省「住民基本台帳人口移動報告」の長期時系列表（e-Stat）を使ったリポジトリです。全国の月別移動者数、都道府県別の転入超過数、そして都道府県×都道府県の移動者数の表（移動前の住所地×移動後の住所地、1954〜2025年）を使っています。数字はすべて日本人移動者です。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| G1 | 都道府県をまたぐ引っ越しはどれだけ減ったか。東京圏への転入超過はいつ大きく、いつ小さかったか。3〜4月への集中は変わったか | 全国の年計・月別・移動率の推移、3大都市圏の転入超過、10年ごとの転入超過の都道府県、月の構成比 | `src/g1_flows.py` |
| G2 | 移動はどれだけ距離に左右されるか。地方から出ていく人のうち、東京圏へ向かう割合は変わったか | 年ごとの重力モデル（ポアソン回帰、出発地・到着地の固定効果、距離は都道府県庁所在地の間の直線距離）、平均移動距離、出発地ごとの東京圏の割合とハーフィンダール指数 | `src/g2_gravity.py` |

#### 主な結果
- **G1**：都道府県間の移動者は1971年の4,256,605人が最多で、2025年は2,148,329人（ピークの50%）。日本人人口に対する移動率は1970年の4.11%から2018年は1.85%。東京圏（埼玉・千葉・東京・神奈川）は1954〜2025年のうち1994・1995年の2年を除いて毎年転入超過で、最大は1962年の+387,874人。コロナ下の2021年は+80,441人まで縮み、2025年は+112,738人。大阪圏は1974年から転出超過が続き、2023〜2025年に小さな転入超過に戻った。名古屋圏は2013年から転出超過。10年ごとに転入超過だった都道府県は1970年代の18から、2020〜2025年は6（東京・神奈川・埼玉・千葉・大阪・福岡）に減った。3〜4月の移動の割合は1954年の24.8%から1993年の39.2%まで上がり、2025年は36.9%。1960年代は4月が多く（16.6%、3月12.5%）、2020〜2025年は3月が多い（21.7%、4月15.5%）
- **G2**：距離の弾力性（距離が1%長いと移動が何%減るか）は1954年の−1.06から1971年の−0.80まで小さくなり、その後は−0.79〜−0.87の範囲でほぼ横ばい。300km未満の移動の割合は1954年の73.8%から1970年の65.1%に下がり、その後は67〜70%前後。沖縄県を除く42道府県で、転出者のうち東京圏へ向かった割合の中央値は1954年14.5%→1990年23.3%→2025年24.5%。1990→2025年で割合が上がったのは27道府県で、大阪府（17.7%→29.2%）・愛知県（25.7%→34.6%）など西日本・中部で大きく、秋田県（48.6%→37.8%）・青森県・岩手県など東北では下がった

#### 動かし方
元データ（Excel 66ファイル、合計約9MB）は `data/raw/` に入れてあります。e-Stat の「住民基本台帳人口移動報告 長期時系列表（昭和29年～）」（https://www.e-stat.go.jp/stat-search/files?toukei=00200523&tstat=000000070001 ）から取得しました。


#### 注意
- 数字は日本人移動者だけです（外国人の移動は入っていません）
- 1954〜1972年は沖縄県を含みません。重力モデルと東京圏の割合は、比べやすさのため沖縄県を除いて計算しています
- 1989年（平成元年）の都道府県×都道府県のファイルは壊れていて読めなかったため、G2 では1989年がありません（G1 の全国・都道府県の系列には1989年も入っています）
- 移動率は報告書の掲載値で、2018年までです
- 距離は都道府県庁所在地の間の直線距離で、実際の移動距離ではありません。都道府県内の移動は入っていません
- 2019年の値には平成31年1〜4月を含みます（令和元年の表記）
