# 859 見積もりの幅（最短〜最長）を書くと、外れ方はどう変わるのか？（見積もりと締め切り）

見積もりを1つの日数（点）だけで書くと、実際がそこからどれだけずれうるかは伝わりません。「最短〜最長」の幅で書けば、外れたかどうか・どちらに外れたかを数えられます。ただし、幅を狭く書く癖があると「9割はこの中」のつもりの幅に実際は7割ほどしか入らず、幅を左右同じ日数で書くと外れはほとんど遅れの側に寄ります。**ここでは、作成者が乱数で作った架空の作業（作業ごとの本当の日数の分布を作成者が置いたもの）で、点だけ・右に長い幅・左右同じ日数の幅の3つの書き方と、ばらつきの感じ方（本当の0.4〜1.2倍）を変え、幅に入る割合と外れの向きを数えました。過去の作業の実績で幅を広げ直すと、次の作業で入る割合がどこまで9割に近づくかも数えました。**

関連する記事：850「『最もありそうな日数』で計画すると、間に合う確率は何%か？」は最短・最長を使って1つの計画の数を出す（三点見積もり）ことを、854「過去の実績で見積もりを直すと、外れはどれだけ減るのか？」は見積もりの数そのもののずれを直すことを扱います。この記事は、幅そのものの書き方と、幅の広さを実績で直すことだけを扱います。

## 主な結果

### 点だけで書くと（作業20万件）
| | 値 |
|---|---|
| 実際が見積もりの±10%以内 | 16.85% |
| 実際が見積もりの±20%以内 | 33.06% |
| 見積もりより遅れた割合 | 49.95% |
| ずれの大きさ（中央値） | 31.3% |
| 遅れたときの遅れの9割点 | +131.4% |

- 見積もる人が中央値を正しく当てていても、±10%以内に収まったのは17%だった。点だけでは、どれくらい外れうるかが分からない

### 幅の書き方と、感じているばらつき（作業20万件）
| 感じているばらつき | 右に長い幅：入った割合 | 外れのうち遅れの側 | 左右同じ日数の幅：入った割合 | 外れのうち遅れの側 |
|---|---|---|---|---|
| 0.4倍 | 49.00% | 49.9% | 51.32% | 57.6% |
| 0.6倍（基本） | **67.71%** | 49.9% | 72.53% | **73.5%** |
| 0.8倍 | 81.13% | 50.0% | 84.65% | 92.0% |
| 1.0倍（正しい） | 90.00% | 50.2% | 90.33% | **98.9%** |
| 1.2倍 | 95.16% | 50.8% | 93.85% | 100.0% |

- 「9割はこの中」のつもりでも、ばらつきを0.6倍に狭く感じていると、幅に入ったのは67.71%だった。式で出る値（67.63%）と一致した
- 右に長い幅は、外れが遅れの側と早まりの側に半々に分かれた
- 左右同じ日数の幅は、同じ長さでも、外れのほとんどが遅れの側だった。ばらつきを正しく感じていても、外れの98.9%が遅れで、早く終わって幅の外に出ることはほぼなかった
- 遅れて幅を超えたときの超え方（中央値）は、基本（0.6倍）の右に長い幅で+22.0%、左右同じ日数の幅で+24.0%だった

### 過去の実績で幅を広げ直すと（次の100件が入った割合、2,000回）
| 過去の件数 | 狭く見る人（0.6倍） | 10〜90%の範囲 | 入った割合が8割を下回った回 | 正しく見る人（1倍） |
|---|---|---|---|---|
| 直さない | 67.57% | 62〜73% | 99.6% | 89.86% |
| 5件 | 78.68% | 57〜95% | 44.9% | 78.86% |
| 10件 | 83.43% | 69〜96% | 31.2% | 83.31% |
| 20件 | 86.35% | 75.9〜95.1% | 18.8% | 86.54% |
| 50件 | 88.28% | 81〜95% | 7.4% | 88.58% |
| 100件 | **89.24%** | 84〜95% | 2.4% | 89.40% |

- 狭く見る人でも、過去100件の実績で幅を広げ直すと、次の100件が入る割合は89.24%まで戻った
- 過去5件だけで直すと、平均では78.68%に上がるが、回によって57〜95%と大きく振れた。正しく見ていた人が5件で直すと、89.86%から78.86%に下がった。少ない件数の9割点は低めに出やすいため
- 中央値を短めに見る癖（0.8倍）があっても、幅を広げ直すと入る割合は89.10%（100件）まで戻った。ただし外れのうち遅れの側は88.1%で、外れの向きの偏りは残った

### 確かめ：本当のばらつき・短めに見る癖（作業20万件）
| 本当のばらつき（作業ごとの範囲） | 感じ方 | 短めに見る癖 | 右に長い幅：入った割合 | 遅れの側 | 左右同じ日数の幅：入った割合 | 遅れの側 |
|---|---|---|---|---|---|---|
| 0.1〜0.5 | 0.6倍 | なし | 67.82% | 49.7% | 69.65% | 62.1% |
| 0.1〜0.5 | 0.6倍 | 0.8倍 | 49.98% | 92.2% | 47.68% | 95.9% |
| 0.1〜0.5 | 1.0倍 | 0.8倍 | 74.93% | 96.6% | 68.33% | 99.9% |
| 0.3〜0.7（基本） | 0.6倍 | なし | 67.62% | 49.9% | 72.40% | 73.3% |
| 0.3〜0.7 | 0.6倍 | 0.8倍 | 62.17% | 80.4% | 61.49% | 93.4% |
| 0.3〜0.7 | 1.0倍 | 0.8倍 | 86.05% | 87.5% | 79.82% | 99.9% |
| 0.6〜1.0 | 0.6倍 | なし | 67.47% | 49.7% | 77.12% | 94.3% |
| 0.6〜1.0 | 0.6倍 | 0.8倍 | 65.63% | 70.1% | 68.70% | 98.1% |
| 0.6〜1.0 | 1.0倍 | 0.8倍 | 88.60% | 76.4% | 83.48% | 100.0% |

- 右に長い幅に入る割合は、感じ方が同じなら本当のばらつきによらずほぼ同じ（0.6倍で67.47〜67.82%）だった
- 中央値を短めに見る癖があると、入る割合は下がり（0.6倍・0.1〜0.5で49.98%）、外れは遅れの側に寄った（70.1〜96.6%）
- 左右同じ日数の幅の外れが遅れの側に寄る度合いは、ばらつきが大きいほど強かった（62.1%→94.3%）
- 置き方全体で、幅に入る割合は47.68〜90.72%まで動いた（`results/robustness.csv`）

## 注意（言えないこと）
- 架空の作業です。日数の分布の形（対数正規）、ばらつき、見積もる人の癖（ばらつきを何倍に感じるか、中央値を短めに見るか）は作成者が置いたもので、結果はこれで決まります。置き方で、幅に入る割合は約48〜91%まで動きました
- 「0.6倍に狭く感じる」は作成者の置いた例です。実際の人がどれくらい狭く書くかは、この分析では分かりません
- 作業の日数は作業ごとに独立と置きました。全部の作業が一緒に延びる場合、過去の実績で直した幅が次の作業でどれだけ当たるかは、ここより振れる（推測）
- 幅で書くとき、見積もる人が実績を見て幅を書きかえる、締め切りに合わせて作業を急ぐ、といった人の動きは入れていません
- 実在のプロジェクトや会社の実績を表すものではありません
