# 228 外食は、どの年齢の世帯で減り、どこで戻ったのか

総務省統計局「家計調査」年報の第4-6表（世帯主の年齢階級別、二人以上の世帯）を使い、2019〜2025年の「一般外食」（外食から学校給食を除いたもの）と、その内訳の食事代・喫茶代・飲酒代を世帯主の年齢別に比べたフォルダです。物価で割った実質の戻りと、世帯の年齢構成の変化が全体の平均をどれだけ押し下げたかも出しました。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A228 | コロナで減った外食は、どの年齢の世帯で戻り、どこで戻っていないのか | 年齢別の一般外食（2019年＝100）の名目と、CPI「一般外食」で割った実質／世帯の年齢構成を2019年に固定した平均との比較／内訳（食事代・喫茶代・飲酒代）の実質の戻り／全国の長期（2015〜2025年）と2026年1〜9月 | `src/a228_eating_out.py` |

## 主な結果
- 一般外食の平均は、2021年に2019年の69%まで減り、名目では2024年に2019年を超えた。2025年は2019年の114.9%。ただし同じ期間に外食の物価が21.3%上がったので、実質では2019年の94.7%で、まだ戻っていない
- 実質の戻り（2025年／2019年）は、世帯主が29歳以下で105、30代100、40代104、60代102と、多くの年齢で2019年並みかそれ以上だった。戻っていないのは70歳以上（86）と50代（93）
- 名目で2019年を超えた年は、29歳以下が2022年、30〜60代が2023年、70歳以上が2025年
- 全体の平均の戻りが多くの年齢より小さいのは、外食の少ない70歳以上の世帯の割合が30.6%から34.5%に増えたから。世帯の年齢構成を2019年に固定すると、2025年の名目の指数は117.6で、公表の平均（114.9）より2.7ポイント高い
- 内訳の実質の戻り（平均）：食事代95、喫茶代124、飲酒代81。喫茶代はすべての年齢で2019年を上回った（70歳以上でも104）。飲酒代は29歳以下（122）を除いて戻っておらず、70歳以上は63
- 全国の一般外食の実質は、2025年に2015年の95.7%。2026年1〜9月の名目は前年同期比で一般外食+6.9%、喫茶代+9.1%、飲酒代+4.9%

## 頑健性
- 年齢別の値を世帯数分布（抽出率調整）で平均すると、公表の平均と0.1%以内で一致した（年齢構成の計算の確かめ）
- 飲酒代を CPI「ビール（外食）」で割っても、平均84・70歳以上66で、戻っていないという結論は変わらない。喫茶代を CPI「コーヒー（外食）」で割っても、ほぼ同じ値だった（`results/sub_items_real_alt_deflator.csv`）
- 1人あたり（世帯人員で割る）の実質の戻りでも、70歳以上（88）と50代（94）が低いという順番は同じ
- コードはきれいなフォルダで3回動かし直し、results の全ファイルが一致することを確かめた

## データ
- `data/kakei_detail.csv`：年報 第4-6表（世帯主の年齢階級別）の支出金額（2019〜2025年）と世帯数分布・集計世帯数・世帯人員
- `data/kakei_annual.csv`・`kakei_monthly.csv`：長期時系列の品目分類（全国、年・月）
- `data/cpi_annual.csv`：消費者物価指数（2020年基準）の「一般外食」「コーヒー（外食）」「ビール（外食）」など（このリポジトリの F209 から抜き出した）
- `src/kakei_parse.py`：年報の Excel（2019年の xls と2020年以降の xlsx）を長い形に直す

## 注意
- 二人以上の世帯の結果で、単身世帯の外食は含まない。若い単身者の外食の戻りはこの分析では分からない
- 29歳以下の世帯は集計世帯数が約100と少なく、年ごとの振れが大きい（2024年の名目133→2025年128など）
- 実質は、年齢によらず同じ物価（CPI「一般外食」の全国の値）で割った。年齢によって行く店の値上がりが違えば、実質の戻りもずれる
- 「世帯主の年齢」の区分なので、同じ世帯の中の誰が外食したかは分からない
- 年齢構成の効果は、各年齢の中の外食の変わり方を2019年の世帯の割合で重みづけし直した単純な計算で、年齢以外の構成の変化（世帯人員・共働き）は分けていない
