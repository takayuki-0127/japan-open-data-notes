# 787 標準化した係数の大きさで変数の大事さを並べると、データのばらつき方でどれだけ順位が変わるのか（手法の解説・正解の分かるデータで試す）

回帰の係数を「標準化」すると（x と y を標準偏差で割ってから当てはめた係数）、単位の違う変数どうしを並べられるようになります。ただ、標準化係数は「1単位あたりの効き方」に「x のばらつきの大きさ」を掛けたものなので、同じ効き方でも、データの中で x がよく動くほど大きく出ます。**ここでは、同じ式から x のばらつき方だけを変えた2つのデータを作り、ふつうの係数・標準化係数・並べ替えの重要度で変数の順位を比べました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A787 | x のばらつき方を変えると、変数の順位はどれだけ変わるか | y＝1.0·x1＋1.5·x2＋2.0·x3＋ばらつき（sd 2）。データA は x の標準偏差 (2, 1, 0.5)、データB は (0.5, 1, 2)。件数300、各300回。最小二乗の係数・標準化係数・並べ替えの重要度（1列を混ぜたときの誤差の増え方）。x1 の標準偏差だけを0.25〜4に変えた試しも。seed 787 | `src/a787_std_coef.py` |

## 主な結果（300回）

| | データA で1位 | データB で1位 |
|---|---|---|
| ふつうの係数（1単位あたり） | x3（97%） | x3（100%） |
| 標準化係数 | **x1（99.7%）** | **x3（100%）** |
| 並べ替えの重要度 | **x1（99.7%）** | **x3（100%）** |

| 標準化係数の平均 | x1 | x2 | x3 |
|---|---|---|---|
| データA | 0.60 | 0.45 | 0.30 |
| データB | 0.10 | 0.32 | 0.84 |

- 式は同じで、1単位あたりの効き方はどちらのデータでも x3 が最大（係数 1.0・1.5・2.0 をどちらでも当てた）
- 標準化係数と並べ替えの重要度は、データA では x1 を1位、x3 を3位にし、データB では逆にした
- x1 の効き方を変えずに、標準偏差だけを1から3にすると、標準化係数での x1 の順位は3位から1位になった

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 787）

## 注意（言えないこと）
- 架空のデータです。変数どうしの相関はなく、関係は直線です
- 標準化係数がまちがいというわけではありません。「このデータの中でよく動いた分、y がどれだけ動いたか」を表します。別の時期・別の店のデータでは x の動き方が違うので、順位がそのまま使えるとは限りません
- 1単位の大きさが違う変数（円と人など）では、ふつうの係数どうしも単純には比べられません。何を比べたいかを先に決める必要があります
