## もとのリポジトリの説明

以下は、もとのリポジトリ `retail-prices-japan` の README です（同じリポジトリにあったほかの記事の分も含みます）。

### retail-prices-japan：総務省「小売物価統計調査」で、同じ品目の都市間の値段の差と、値上げの起き方を調べる

総務省「小売物価統計調査（動向編）」の表1「調査品目の月別価格及び年平均価格（都道府県庁所在市及び人口15万以上の市）」2010〜2025年（16年、食料・外食などの約230〜260品目×81市×12か月、延べ約32万行）を使ったリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| W1 | 同じ品目の値段は都市によってどれだけ違うか。差は縮まっているか | 25品目の年平均価格を16年すべてにある75市にそろえ、都市間の変動係数（標準偏差÷平均）、最高÷最安の比、90%点÷10%点の比を年ごとに計算。2010〜12年平均と2023〜25年平均の比較、銘柄・単位の改正の有無で分けた比較、品目をまたいだ都市の物価指数、同じ品目で高い都市が高いままかの順位相関 | `src/w1_dispersion.py` |
| W2 | 値上げは一斉か、ばらばらか。2022年以降の物価上昇期に何が変わったか | 都市×品目ごとに前月と価格が変わったか（上げた・下げた）を数え、毎月の割合（価格改定の頻度）と変わったときの幅を、生鮮以外の食品・外食・生鮮に分けて集計。品目×月で「上げた都市の割合」を出し、半数以上の都市が同じ月に上げた品目×月に入る値上げの割合を期間で比較。銘柄・単位の改正月は除く | `src/w2_changes.py` |

#### 主な結果
- **W1**：2023〜25年平均の都市間の変動係数は、ビール2.4%、カップ麺3.2%、米（コシヒカリ）5.9%、鶏卵7.3%、牛乳9.8%、食パン12.0%、中華そば（外食）11.8%、すし（外食）17.1%、豆腐23.2%。2025年の年平均価格で75市のうち最も高い市と安い市は、鶏卵が立川350円・長岡230円（10個1パック）、牛乳が那覇364円・長岡214円（1L）、米が北九州5,196円・盛岡4,126円（5kg）、食パンが那覇743円・郡山295円（1kg）、中華そばが八王子856円・さいたま465円。25品目のうち16品目で変動係数が下がった（中央値10.1%→9.2%）が、銘柄・単位の改正がなかった10品目だけでは縮小5・拡大3・ほぼ同じ2で、中央値は9.6%→9.8%と、はっきり縮まったとは言えない。25品目をならした都市の物価指数（全市平均＝100）は那覇112.5、福井107.6が高く、熊谷90.5、郡山91.0が低い。ある品目で高い都市が別の品目でも高いとは限らず、品目間の相関の中央値は0.12
- **W2**：生鮮以外の食品（約150品目）で、1か月に価格を上げた都市×品目の割合は2015〜19年の25.4%から2022〜25年は31.3%に増え、下げた割合は23.7%→23.3%とほぼ同じ。変えたときの幅（平均）は4.5%→4.9%。外食（約25品目）は上げた割合が5.2%→14.1%と2.7倍になり、幅は4.8%→4.4%と大きくなっていない。半数以上の都市が同じ月に上げた品目×月に入る値上げの割合（消費税率の引き上げ月を除く）は10.2%→27.0%。牛乳は2022年11月に98.8%、2023年8月に97.5%の都市が同じ月に上げたが、中華そば（外食）は消費税の2014年4月（87.7%）を除くと最も多い月でも28.4%で、ばらばらに上がっている。消費税率が5%→8%になった2014年4月は、生鮮以外の食品の82.5%、外食の80.2%が上がった

#### 動かし方
`data/` に整形済みの CSV が入っているので、そのまま動きます。元の Excel から作り直すときは、e-Stat の「小売物価統計調査（動向編）」の各年の「表1 調査品目の月別価格及び年平均価格【都道府県庁所在市及び人口15万以上の市】」のファイル（年ごとに品目の範囲で14ファイル）を `data/raw/kouri_YYYY_NN.xls(x)`（NN＝01〜14、ファイルの並び順）の名前で置き、`python build.py` を実行してください。
- e-Stat：https://www.e-stat.go.jp/stat-search/files?page=1&toukei=00200571

```bash
pip install -r requirements.txt
cd src
python build.py          # data/raw がある場合だけ
python w1_dispersion.py
python w2_changes.py
```

#### データ
| ファイル | 中身 |
|---|---|
| data/prices_1.csv〜prices_4.csv | 分析に使う25品目の都市別の価格（品目×都市×年の1行に、年平均 avg と1〜12月 m01〜m12）。subst は代替銘柄の印（a)～z)）がある行（2019年以前の表のみ） |
| data/items.csv | 25品目の各年の品目名、基本銘柄、単位 |
| data/brand_changes.csv | 全品目の銘柄・単位の改正月（銘柄の説明の「○年○月から基本銘柄改正／単位変更」と、年をまたいで銘柄・単位の文言が変わった1月） |
| data/freq_all_1.csv, freq_all_2.csv | 食料・外食の全品目（銘柄符号1001〜2199）×月：前月と今月の両方に価格がある都市の数 n、上げた都市 up、下げた都市 dn、変化率（対数）の絶対値の合計 sum_abs。改正月は除く |
| data/item_names.csv | 銘柄符号と品目名 |

#### 注意
- 価格は、市ごとに決めた店で、決められた銘柄（基本銘柄）を毎月調べた店頭価格（税込み）です。7日以内の特売価格は含みませんが、それより長い値引きや、店ごとの仕入れの事情で動きます。「前月と変わった」には、メーカーの値上げだけでなく、こうした店頭の動きも入ります
- 生鮮（魚介・野菜・果物）は毎月ほぼすべての都市で値段が変わるので、W2 では分けて集計しました（月に価格が変わる割合は約97%）
- 銘柄や単位が改正された月の変化は除きました。改正の前後では値段の水準が変わり、都市間の差も変わることがあります（例：しょうゆは2024年1月に1L入りから特定の450mL商品に変わり、変動係数が11.4%→2.0%に下がった）。W1 の「縮まったか」は、改正のない品目で別に確かめています
- 2019年10月の外食の銘柄改正（「持ち帰りは除く」）は消費税率の引き上げ（10%、外食は軽減税率の対象外）と同じ月なので、外食の2019年10月の値上げは数えていません
- 調査する市は年によって入れ替わります（2010年の81市と2025年の81市で5市が違う）。W1 は16年すべてにある75市にそろえました。W2 は前月と今月の両方に価格がある都市だけを数えています
- 品目によっては調べる市が約半分（47市）で、W2 の「半数以上の都市」は都市が20以上ある品目×月だけで数えています
- 2020年以降の表には代替銘柄の印がないため、代替銘柄の扱いは年によってそろっていません
- 都市の物価指数は25品目の単純平均（対数）で、家計の支出のウエイトはかけていません
