# 1103 同じ日の分をまとめて比べると、ばらつきはどれだけ減るのか？（試作と実験）

新しい材料と今の材料をくらべるとき、湿り気や気温のように日によって仕上がり全体が上下するものがあると、「新しい材料は月曜から木曜、今の材料は金曜から月曜」のように別々の日に試すと、日の違いが材料の差にまざって見積もりがぶれます。毎日2つの材料を1枚ずつ試し、同じ日の中でくらべると、日の違いは差から消えます。**ここでは、作成者が乱数で作った架空の印刷の工房（新しいインクといつものインクのにじみの幅をくらべる。日による振れと1枚ごとの振れを作成者が置いたもの）で、同じ16枚（1日2枚×8日）を、①インクごとに別々の日、②毎日2つのインクを1枚ずつ、の2つの組み方で試したとき、インクの差の見積もりの散らばりがどれだけ減るかと、差があるかの判定の当たり・空振りを、20,000回ずつ数えました。日の振れの大きさ・インクの差が日によって違う分・日数を変えた45通りも確かめました。**

例の工房とにじみの幅は架空のもので、実在の工房・インク・製品の数字ではありません。にじみの幅は拡大して機械で測った値と置いています（人に聞いて決める値ではありません）。

関連する記事：同じ店の前と後のように、すでに組になっているデータを組を無視してくらべると差を見つける力がどれだけ落ちるかは、656「同じ店の前と後を比べるとき、対応のない検定にすると、差を見つける力はどれだけ落ちるのか」で扱っています。この記事は、試す前に「同じ日にまとめるか、別々の日にするか」を決める組み方の側に絞り、日による振れの大きさで減り方がどう変わるかと、別々の日に試したデータを1枚ずつ数えたときの空振りを数えます。日によって効き方が違う分を短い期間で測るずれは 694「A/B テストを3日だけで止めると、曜日で効き方が違うとき、効果の推定はどれだけずれるのか」、同じ日の中で時間とともに変わる分は同じ企画の 1102 で、日ではなく試す場所によって効き目そのものが違うときに1か所の結果がどこまで当てはまるかは 1109「効き目が試す場所によって違うとき、1か所の結果はどこまで当てはまるのか？」で扱っています。

## 主な結果

### 見積もりの散らばり（基本、20,000回、`results/a1103_main.json` の `base`）
| 組み方 | 差の見積もりの平均（本当は−1.0） | 散らばり（標準偏差） | 式の値 | 本当の差から±0.5以内 |
|---|---|---|---|---|
| ①インクごとに別々の日（4日ずつ） | −1.0061 | 1.1853 | 1.1726 | 32.23% |
| ②毎日2つのインクを1枚ずつ（8日） | −0.9949 | **0.5028** | 0.5 | **67.74%** |

- **同じ16枚でも、同じ日にまとめると、差の見積もりの散らばりは0.4241倍になった（式では0.4264倍）**。57.59%減った（式では57.36%）
- 減った分は、日による振れが差から消えた分で、式どおりだった。どちらの組み方も、見積もりの平均は本当の差−1.0に近かった

### 差があるかの判定（基本、20,000回ずつ、`results/judge_base.csv`）
| 組み方・数え方 | 本当の差−1.0を「差がある」とした割合 | 本当は差がないのに「差がある」とした割合 |
|---|---|---|
| ①別々の日・1枚ずつを別々に数えて判定 | 28.11% | **14.79%** |
| ①別々の日・日の平均で判定 | 11.56% | 4.89% |
| ②同じ日・日ごとの差で判定 | **40.89%** | 4.98% |
| ②同じ日・日を無視して判定 | 8.76% | 0.27% |

- **別々の日に試したデータを1枚ずつ別々に数えると、本当は差がないのに14.79%で「差がある」とした**。決めた基準の5%を上回ったのは、同じ日の2枚が日の振れを共有していることを数えに入れていないため
- 同じ日にまとめ、日ごとの差で判定すると、本当の差−1.0を40.89%で見つけ、空振りは4.98%だった。別々の日を日の平均で正しく数えると、見つけたのは11.56%だった
- 同じ日にまとめても、日を無視して数えると、見つけたのは8.76%に下がった（656 と同じしくみ）

### 置き方を変えると（45通り、各4,000回、`results/grid.csv`）
| 日の振れ（8日、インクの差の日ごとの振れ0） | ②の散らばり÷①の散らばり |
|---|---|
| 0 | 1.0003 |
| 0.5 | 0.8033 |
| 1.0 | 0.5882 |
| 1.5 | 0.4321 |
| 3.0 | 0.2268 |

（この表は45通りの確かめ（各4,000回）の値なので、日の振れ1.5の行の0.4321倍は、上の基本（20,000回）の0.4241倍と少し違います）

- 散らばりの比は、45通りで0.2268〜1.0083倍だった。式の値との差は0.0292以内だった（式どおり）
- **日の振れが0のときは、まとめても散らばりはほとんど減らなかった**（0.8749〜1.0083倍。1未満になったのは、インクの差が日によって違う分を置いた置き方）
- 本当の差を見つけた割合は、日の振れがあるときは②（日ごとの差）が①（日の平均）より4.03〜66.73ポイント多かった。日の振れが0のときは−0.33〜+10.55ポイントで、たとえば8日・日の振れ0では、②を日を無視して数えたほうが47.2%と、日ごとの差で数えた42.45%より多く見つけた
- 別々の日に試したデータを1枚ずつ別々に数えた空振りは、45通りで5.03〜24.82%だった。日の振れが0の置き方でも5.03〜9.78%だった。日の平均で数えると4.58〜6.02%、同じ日の日ごとの差は4.0〜5.85%だった

## 注意（言えないこと）
- 架空のデータです。日による振れ、1枚ごとの振れ、インクの差、インクの差の日ごとの振れは作成者が置いたもので、結果はこれで決まります。散らばりの比は置き方で0.2268〜1.0083倍と動きました
- 散らばりの減り方（0.4241倍）は、置いた日の振れと1枚の振れからの式どおりの値です。新しく数えたのは、別々の日のデータを1枚ずつ数えたときの空振りと、日の振れが小さいときにまとめた利点が消えることです
- 同じ日の2枚は、日の振れを同じだけ受けると置きました。同じ日の中でも時間とともに仕上がりが動くと、どちらのインクを先に刷るかで差がまざります（1102 で扱っています）
- 実在の工房・インク・紙のにじみ方を表すものではありません
