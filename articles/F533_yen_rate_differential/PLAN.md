# F533 事前の計画（PLAN）

作成：2026-11-19 05:47（JST）。結果を集計する前に書いた。

## 問い
円安（ドル高・円安）は、日米の金利差でどこまで説明できるのか。1990年から2026年10月までの月ごとのデータで、金利差とドル円の関係の強さを測り、期間によってどう違うか、関係が崩れた時期はいつかを確かめる。為替や金利の先行きの見通し、投資の助言は書かない。過去の数字の関係の読み方までにとどめる。

## 知りたい人
「円安は日米の金利差のせい」というニュースの説明を、数字で確かめたい人。日本銀行のワーキングペーパー（宮本 2025、No.25-J-2）は、2021年以降の円安の多くが米国の金利で説明できるという趣旨の分析をしている（要約）。同じことが、もっと単純な金利差とドル円の関係で、どの期間にも言えるのかを見たい人。

## データ
- 日本銀行「外国為替市況」東京市場 ドル・円 スポット 17時時点/月中平均（FXERM07）。月末（中心相場、FXERM08）を頑健性に使う。
- 財務省「国債金利情報」2年・10年の国債金利（日次）を月平均にする。
- 米国財務省 Daily Treasury Par Yield Curve Rates 2年・10年（日次）を月平均にする。
- 期間：1990年1月〜2026年10月（米国財務省の日次 CSV が1990年から）。
- 金利差 = 米国の金利 − 日本の金利（%ポイント）。

### 取得前に見たもの（下見）
- 日銀 API の応答の形を見たときに、ドル円の月中平均の最後の3か月（2026年8〜10月：158.81・156.23・157.89）を目にした。
- 財務省の CSV の最初と最後の行（1974年9月24日、2026年10月29・30日の金利。10年は2.8%台）を目にした。
- 米国財務省の2024年の CSV の最初の2行（2024年12月30・31日。2年4.24〜4.25%、10年4.55〜4.58%）を目にした。
- 金利差とドル円の関係は集計していない。

## 仮説（外れの基準つき）
- H1：1990〜2026年の月ごとの変化（ドル円の対数の変化と、2年の金利差の変化）で、金利差が説明する割合（R²）は0.05以上0.3未満。つまり、関係はあるが、月々の動きの大半は金利差の外にある。外れ：R² が0.05未満、または0.3以上、または傾きが負。
- H2：2013〜2026年の R² は、1990〜2007年の R² より大きい。外れ：同じか小さい。
- H3：期間全体で、2年の金利差の方が10年の金利差より R² が大きい。外れ：10年の方が大きいか同じ。
- H4：2021年1月から、2021年以降でドル円の月中平均が最も高かった月までの円安（対数の変化）のうち、1990〜2020年で推定した傾き × その間の2年の金利差の変化で説明できる分は50%以上。外れ：50%未満。

## 手法
- 月ごとの変化の回帰：Δln(ドル円)×100 = a + b × Δ金利差 + e。最小二乗法、標準誤差は Newey–West（ラグ6）。
- 期間別：1990〜1999、2000〜2007、2008〜2012、2013〜2020、2021〜2026年10月、と1990〜2007／2013〜2026。
- 36か月の移動相関（変化どうし）で、関係が弱まった・逆になった時期を見る。
- 水準どうし（ln ドル円と金利差）の相関は、見かけの相関（どちらも長い波を持つ）が出やすいので、参考として示すだけにする。
- H4 の期間の分解：推定した傾き × 金利差の変化の累積を「金利差で説明できる分」、残りを「それ以外」とする。

## 頑健性（3つ以上）
1. 月末のドル円（FXERM08）を使う。
2. 10年の金利差を使う（H3 と同じ計算で、期間別も見る）。
3. 2008年9月〜2009年3月（金融危機の月）を除く。
4. 傾きを2000〜2020年で推定し直して、H4 の分解をやり直す。
5. 3か月ごとの変化で同じ回帰をする。

## 言えないこと（予想）
- 金利差がドル円を動かしたのか、同じ出来事が両方を動かしたのか（因果）は、この回帰では分からない。
- 期待インフレ・リスクへの姿勢・貿易収支・介入など、金利差の外の要因を一つずつ分けることはしない。
- 先行きのドル円・金利の見通しや、投資・政策の判断には使えない。
- 2年・10年の国債金利は、政策金利や期待の一部しか表さない。
