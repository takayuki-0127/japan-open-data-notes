# 450 k-means は、丸くないまとまりや大きさの違うまとまりを、どれだけ取り違えるのか（手法の解説）

**正解のまとまりが分かっている架空の点で、k-means がどんな形のまとまりで外れるか**を測ったフォルダです。混合正規分布・階層的な方法と比べ、まとまりの数を選ぶ指標が当たる割合と、標準化で変わる度合いも測りました。019・F171 は実データの分類で、こちらは正解を置いて試しています。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A450 | 4つの場面（丸い・細長い・広がりが違う・点の数が違う）で、正しいまとまりに入った点の割合はどれだけか。まとまりの数は当たるか。標準化でどう変わるか | 2次元・3つのまとまり・計600点。k-means／混合正規分布（出発点2通り）／ウォード法／平均連結。100回の平均 | `src/a450_kmeans_shapes.py` |

## 置いたこと（架空）
- ①丸くて同じ大きさ：標準偏差1、200点ずつ、中心は一辺6の三角形
- ②細長い：横の標準偏差5.0・縦0.6（長さが幅の約8倍）の3本を、縦に3ずつ離して平行に並べ、30度回す
- ③広がりが違う：標準偏差0.5・1.0・2.5、200点ずつ
- ④点の数が違う：500点・80点・20点、標準偏差1
- 「当たり」：まとまりの番号を、いちばん合う対応（ハンガリアン法）に付け替えてから、正しいまとまりに入った点の割合を数える
- 混合正規分布（ふつうの出発点）：k-means の結果から始める、3回。（出発点を20通り）：データの点からランダムに選んで20回始め、尤度のいちばん高い結果を採る

## 主な結果
### 正しいまとまりに入った点の割合（100回の平均）
| 場面 | k-means | 混合正規分布（ふつうの出発点） | 混合正規分布（出発点を20通り） | ウォード法 | 平均連結 |
|---|---|---|---|---|---|
| 丸くて同じ大きさ | 99.8% | 99.7% | 99.7% | 99.5% | 99.5% |
| 細長い | 37.5% | 39.8% | 97.2% | 41.9% | 37.1% |
| 広がりが違う | 93.1% | 98.1% | 98.1% | 96.4% | 58.2% |
| 点の数が違う | 78.7% | 95.1% | 99.1% | 91.0% | 98.7% |

- k-means で、正解のまとまりごとに正しく入った割合：広がりが違う場面で 100%・99%・80%（いちばん広いまとまりが80%）、点の数が違う場面で 75%（500点）・98%（80点）・90%（20点）
- k-means の当たりが90%を下回った回：細長い100回中100回、点の数が違う100回中81回

### まとまりの数を3と当てた割合（2〜6から選ぶ、50回）
| 場面 | シルエット（k-means） | BIC（混合正規分布・出発点を10通り） |
|---|---|---|
| 丸くて同じ大きさ | 100% | 100% |
| 細長い | 0%（すべて2） | 68%（残りは4） |
| 広がりが違う | 98% | 100% |
| 点の数が違う | 2%（98%が2） | 98% |

### 細長さを変える（40回）
| 長さ ÷ 幅 | k-means | 混合正規分布（ふつうの出発点） | 混合正規分布（出発点を20通り） |
|---|---|---|---|
| 1.0 | 99.0% | 99.0% | 99.0% |
| 2.0 | 99.1% | 99.1% | 99.1% |
| 3.3 | 68.0% | 80.6% | 99.2% |
| 5.0 | 62.4% | 74.4% | 99.2% |
| 8.3 | 37.1% | 38.9% | 98.4% |
| 13.3 | 36.2% | 37.8% | 95.5% |

### 標準化で変わる度合い（k-means、丸い3つのまとまり）
| 場面 | そのまま | 標準化 |
|---|---|---|
| 片方の指標だけを100倍の単位で書いた | 90.9% | 99.7% |
| 差のある指標は片方だけで、もう片方は小さな振れ | 96.8% | 64.8% |

全部の数字は `results/accuracy_by_scene.csv`、`results/kmeans_recall_by_cluster.csv`、`results/number_of_clusters.csv`、`results/elongation_sweep.csv`、`results/standardization.csv`、`results/main.json` にあります。

## 動かし方
```
pip install -r requirements.txt
cd src && python a450_kmeans_shapes.py      # 約3分半（混合正規分布を何度も当てはめるため）
```
`data/` の4ファイル（場面ごとの1回分の点と、k-means・混合正規分布の分け方）、`results/` の6ファイル、`figures/` の3枚ができます。

## 確かめたこと
- 空のフォルダで計算し直し、data・results・figures が一致した
- 丸くて同じ大きさの場面では、どの方法も99%以上
- 細長さが1倍（丸い）なら、k-means と混合正規分布の当たりは同じ

## 注意（言えないこと）
- 架空の点です。まとまりの離れ方、広がり、点の数の置き方で、当たりの割合は変わります
- 指標は2つだけです。指標が多い場合は試していません
- 密度をもとに分ける方法（DBSCAN など）は試していません
- 混合正規分布がうまくいったのは、まとまりが楕円の形だからです。曲がった形や輪の形は試していません
- 実際のデータには正解がありません。「当たり」は正解を置いたから測れた数字です。どの方法を使うべきかを決めるものではありません
- scikit-learn 1.9.1 での結果です。版が違うと、出発点の決まり方が変わり、数字が少し動くことがあります（未検証）
