# 1150 置き場所の大きさを2倍にすると、当たり率はどれだけ上がるのか？（キャッシュの当たり率）

よく使うデータを手元に置いておく置き場所（キャッシュ）は、大きくするほど多くのデータを置けるので、当たり率は上がります。けれども、置き場所を2倍にしても当たり率は2倍にはなりません。あとから置けるようになるのは、もともと置いていたものより使われる回数の少ないデータだからです。2倍にして何ポイント上がるかは、よく使われるものへの偏りの大きさと、今の大きさで変わります。**ここでは、作成者が置いた架空のアプリのデータ10万件への問い合わせ（i番目に人気のデータが選ばれる確率を 1÷i^a に比例させ、a で偏りの大きさを置いたもの）で、置き場所を全体の0.25%から16%まで2倍ずつ大きくし、いちばん長く使われていないものから捨てる決まりで当たり率を数えました。偏り a を0.6・0.8・1.0・1.2の4通りにし、2倍にするごとの上がり幅（ポイント）と、外れ率の縮み方を数えました。人気の上位をずっと置いたときの当たり率（式）とも比べ、データの件数を2万件にした確かめも行いました。問い合わせはすべて作成者が置いた確率からの乱数で、実機の計測はしていません。**

関連する記事：1125「画素の数を縦横2倍にすると、細かさは何倍になったと言えるのか？」は、2倍にしたものと、知りたい物差しの伸びが同じでない場面を画像で扱っています。1118「上限のある能力を上げ続けると、表に出る強さはどこで伸びなくなるのか？」は、上げ続けると伸びが縮む形をゲームの数値で扱っています。同じ企画の 1149「当たり率90%と99%の差は、平均の応答時間で何倍の差になるのか？」は当たり率の差が応答時間でどれだけになるか、1151「当たり率を件数で数えるかデータの量で数えるかで、良し悪しはどう入れかわるのか？」はデータの大きさが違うときの当たり率の数え方を扱っています。1152「よく使われるものへの偏りが大きいときと小さいときで、同じ大きさの置き場所の効き目はどれだけ違うのか？」は、下の表の横の並び（同じ大きさで偏りだけが違うときの差）と、偏りの違う流れを混ぜたときを扱っています。1157「一度しか使われないものが多いと、置き場所を大きくしても当たり率はどこで止まるのか？」は、大きくしても越えられない当たり率の上限を、1153「古く使われたものから捨てる決まりと、使われた回数の少ないものから捨てる決まりは、人気が移り変わるときにどちらが当たるのか？」は人気が移り変わるときの捨て方を扱っています。この記事は、置き場所を件数で数え、大きさを2倍にしたときの当たり率の上がり方（表の縦の並び）に絞ります。

## 主な結果

### 置き場所の大きさと当たり率（データ10万件、`results/hit_by_size.csv`）
| 置き場所（全体の%） | 偏り a=0.6 | a=0.8（基本） | a=1.0 | a=1.2 |
|---|---|---|---|---|
| 0.25% | 1.81% | 11.13% | 37.33% | 69.36% |
| 0.5% | 3.19% | 15.34% | 43.92% | 74.83% |
| 1% | 5.37% | **20.36%** | 50.59% | 79.68% |
| 2% | 8.8% | **26.48%** | 57.35% | 83.85% |
| 4% | 14.02% | 34.08% | 64.28% | 87.5% |
| 8% | 21.98% | 43.39% | 71.35% | 90.77% |
| 16% | 33.96% | 54.8% | 78.75% | 93.56% |

- **基本の偏り（a=0.8）で置き場所を全体の1%から2%にすると、当たり率は20.36%から26.48%へ、+6.12ポイント上がった**。当たり率は1.301倍で、2倍には遠い。外れ率は0.923倍にしか縮まなかった（`results/double_steps.csv`）
- 4通りの偏り×6段の2倍、合わせて24段のうち、当たり率が2倍以上になった段は0段だった。当たり率は1.031〜1.762倍、外れ率は0.698〜0.986倍にとどまった

### 2倍にするごとの上がり幅（ポイント、`results/double_steps.csv`）
| 2倍にする段 | a=0.6 | a=0.8 | a=1.0 | a=1.2 |
|---|---|---|---|---|
| 0.25→0.5% | 1.38 | 4.21 | 6.59 | 5.47 |
| 0.5→1% | 2.18 | 5.02 | 6.67 | 4.85 |
| 1→2% | 3.43 | 6.12 | 6.76 | 4.17 |
| 2→4% | 5.22 | 7.6 | 6.93 | 3.65 |
| 4→8% | 7.96 | 9.31 | 7.07 | 3.27 |
| 8→16% | 11.98 | 11.41 | 7.4 | 2.79 |

- **24段の上がり幅は+1.38〜+11.98ポイントで、同じ「2倍」でも上がり幅は大きく違った**
- 上がり幅の動き方は、偏りの大きさで逆になった。偏りの小さい a=0.6・0.8 では、大きくするほど上がり幅が増えた（a=0.6 で1.38→11.98）。a=1.0 では6.59〜7.4でほぼ同じ、偏りの大きい a=1.2 では大きくするほど減った（5.47→2.79）
- 人気の上位をずっと置いたときの式でも同じ形になった（a=1.0 は2倍ごとに5.72〜5.74ポイントでほぼ一定、a=0.6 は2.93→11.73と増え、a=1.2 は4.21→2.1と減る）。この形は置いた確率の式で決まる（作りどおり）
- 偏りが大きいときに上がり幅が減るのは、すでに当たり率が高く、残りの外れがまれにしか使われないデータに散っているから。偏りが小さいときは、置けるデータが増えるほど、まだ置いていない中程度の人気のデータを拾える

### 捨て方による違い（`results/hit_by_size.csv`）
- いちばん長く使われていないものから捨てる決まりの当たり率は、人気の上位をずっと置いた式より、a=0.8 で11.53〜13.97ポイント低かった（a=0.6 で6.58〜13.93、a=1.0 で6.09〜13.13、a=1.2 で2.09〜7.92ポイント低い）。たまに来た人気の低いデータが、しばらく置き場所を占めるため

### 確かめ：データの件数を2万件にすると（`results/check_items_compare.csv`）
- 同じ割合の大きさでも、2万件では当たり率が10万件より0.43〜13.59ポイント低かった（偏りの大きいほど差が大きい）。全体の何%という言い方だけでは、当たり率は決まらない
- 2倍ごとの上がり幅は+1.22〜+12.04ポイントで、偏りごとの増える・ほぼ同じ・減るの向きは4通りとも10万件と同じだった

## 注意（言えないこと）
- 架空のデータです。人気の偏りの形（1÷i^a）、データの件数、問い合わせの数は作成者が置いたもので、上がり幅はこれで決まります。とくに上がり幅が増えるか減るかは、置いた偏り a でそのまま決まります（作りどおり）。実在のアプリの使われ方を表すものではありません
- 人気は時間で変わらないと置きました。人気が移り変わる場合（1153）や、一度しか使われないデータが多い場合（1157）は入れていません
- データの大きさはすべて同じと置き、置き場所を件数で数えました。大きさが違う場合の数え方は 1151 で扱っています
- 置き場所をどれだけ大きくすべきかや、そのための費用は扱っていません
