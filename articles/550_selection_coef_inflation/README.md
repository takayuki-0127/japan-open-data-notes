# 550 回帰に入れる変数を「有意なものだけ残す」で選ぶと、残った係数はどれだけ大きく出るのか（手法の解説・正解の分かるデータで試す）

回帰分析で、候補の変数を全部入れて当て、p値が0.05未満の変数だけを残すことがあります。残った変数は「たまたま大きく出た回」に選ばれやすいので、その係数は本当より大きく出ます。**ここでは、本当の係数が分かっている架空のデータ（候補20個、効くのは弱い3つ＝0.15と強い2つ＝0.4、どの2つも相関0.3、件数 100・300・1,000）で、4通りの選び方について、残った係数の大きさ、残る割合、95%区間の当たり方を数えました。** 各件数1,000回くり返しています。数字は置いた前提で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A550 | 有意なものだけ残すと、残った係数はどれだけ大きく出るか | M1 全部入れる、M2 全部入れて p<0.05 だけ残して当て直す、M3 後ろ向きステップワイズ（p が最大の変数を1つずつ外す）、M4 半分で M2 の選び方、残り半分で当て直す。最小二乗法、95%区間は t 分布。1,000回、seed 550。確かめとして相関0の場合も | `src/a550_post_selection.py` |

## 主な結果
- **弱い変数（本当は0.15）の、残ったときの係数の平均**：p<0.05だけ残す（M2）で 100件 0.34（**2.29倍**）、300件 0.20（1.36倍）、1,000件 0.15（1.01倍）。ステップワイズ（M3）は 2.03・1.29・1.01倍。全部入れる（M1）は 0.98〜1.01倍
- **強い変数（本当は0.4）**：M2 で 100件 1.22倍、300件 1.05倍
- **残る割合（300件）**：弱い変数は M2 57%・M3 65%・M4 31%。効かない変数は1つあたり5〜6%だが、15個のうち1つでも残る回は 53〜63%
- **残った変数の95%区間が本当の値を含む割合（100件）**：弱い変数で M1 94%・M2 63%・M3 82%・M4 83%。効かない変数が残ったときは M2 35%・M3 0%（残ったのは p<0.05 のときだけなので、区間は必ず0を含まない）
- **分けて選ぶ・当てる（M4）でも、相関があると大きく出る**：100件で 2.07倍。外れた効く変数の分を、相関のある残った変数が肩代わりするため。**変数どうしの相関を0にすると、M4 は 0.96倍（100件）・1.00倍（300件）**、M2 は 1.79倍・1.19倍


## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した（reps.csv.gz は中身で比較）
- 全部入れる（M1）では、係数の平均が本当の値の 0.98〜1.01倍、95%区間が 94〜95% 当たること
- 相関0の場合に、分けて選ぶ・当てる（M4）の係数が本当の値に戻ること

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 550）

## 注意（言えないこと）
- 架空のデータ。変数の数・係数・相関は作成者が置いたもので、結果はこれで決まる
- 「変数を選ぶな」という話ではない。選んだあとの係数と区間をそのまま読むと、どれだけずれるかを数えたもの
- 正則化（Lasso など）や、選んだことを入れた推測の方法は扱っていない
- 説明変数は正規分布、誤差も正規分布で等分散と置いた
