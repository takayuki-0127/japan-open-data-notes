# 800 U字の関係では、相関係数と相互情報量はどれだけ違う答えを出すのか（手法の解説・正解の分かるデータで試す）

相関係数（ピアソン・スピアマン）は「x が増えると y が増える（減る）」という向きのそろった関係を測ります。U字のように、x の真ん中で y が小さく両端で大きい関係は、はっきりしていても相関係数は0に近くなります。相互情報量は「x を知ると y についてどれだけ分かるか」を測るので、形を問わず関係を拾えます。**ここでは、直線・U字・波・関係なしの4つの関係で、3つの物差しが関係を見つける割合を比べました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A800 | 関係の形によって、相関係数と相互情報量はどれだけ違うか | x は−1〜1の一様分布。y＝x（直線）・x²（U字）・sin(3πx)（波）・x と無関係（関係なし）に、ばらつきを足す。件数50・200・1,000、各300回。ピアソンとスピアマンの相関（絶対値）、相互情報量（scikit-learn の mutual_info_regression、近傍3）。「関係なし」の300回の95%点を超えた割合を「見つけた割合」とする。seed 800 | `src/a800_mi.py` |

## 主な結果（200件、300回）

| 関係 | ピアソンの平均 | 相互情報量の平均 | ピアソンで見つけた割合 | スピアマンで見つけた割合 | 相互情報量で見つけた割合 |
|---|---|---|---|---|---|
| 直線 | 0.86 | 0.67 | 100% | 100% | 100% |
| U字 | **0.07** | **1.04** | **8%** | 12% | **100%** |
| 波 | 0.24 | 0.60 | 96% | 96% | 100% |
| 関係なし | 0.05 | 0.02 | 5% | 5% | 5% |

- U字の関係は、点がほぼ曲線の上に乗っているのに、ピアソンの相関は平均0.07で、「関係なし」とほぼ同じだった。相互情報量は300回すべてで関係を見つけた
- 件数を1,000にしても、U字でピアソンが見つけた割合は5%（関係なしと同じ）。件数を増やしても見つからない
- 波は x の範囲で上がり下がりがそろわず、相関が0.24残ったので、相関係数でも200件で96%見つかった。50件では相関係数36%、相互情報量76%
- 直線なら、相関係数で十分に見つかる（50件でも100%）

## 動かし方
```
pip install -r requirements.txt
cd src && python a800_mi.py
```
30秒ほどかかります。

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- 「関係なし」で見つけた割合が、どの物差しでも5%（物差しの決め方どおり）になること

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 800）。各回の値は `results/reps.csv.gz`

## 注意（言えないこと）
- 架空のデータです。関係の形とばらつきの大きさは作成者が置いたもので、見つけた割合はこれで決まります
- 相互情報量は0以上の値で、関係の向き（増えるか減るか）は表しません。値の大きさも相関係数とは単位が違い、直接は比べられません
- 相互情報量の推定値は、推定の方法（近傍の数など）と件数で変わります。ここでは近傍3だけを試しました
