# 265 雨の降る日は減り、1回の雨は強くなったのか（年降水量＝降水日数×1日あたりの雨量に分ける）

気象庁「過去の気象データ検索」の日ごとの値（14地点、1931〜2025年）を使ったフォルダです。262〜266の5本は同じデータ（`data/jma_daily_14st_1931_2025.tsv.gz`）を使っています。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A265 | 雨の降る日は減り、1回の雨は強くなったのか（年降水量＝降水日数×1日あたりの雨量に分ける） | 年降水量・降水日数（1mm以上）・1日あたりの雨量（SDII）・50mm以上の日数を年ごとに出し、1961〜1990年平均＝100の指数を13地点で平均。対数での分解（期間平均）、直線の傾き（HC1標準誤差） | `src/a265_wet_days_intensity.py` |

## 主な結果
- 13地点の平均で、1961〜1990年を100とした指数にすると、降水日数は1931〜2025年の直線で100年あたり5.9ポイント（標準誤差1.7）減り、1日あたりの雨量は7.5ポイント（標準誤差2.2）増えました。年降水量の傾きは0.3ポイントで、ほとんど変わっていません。
- 期間の平均で見ると、降水日数は1931〜1960年の年131日から、1996〜2025年は125日に。1日あたりの雨量は11.8mmから12.4mmになりました。
- 地点ごとに1931〜1960年と1996〜2025年を比べると、13地点すべてで降水日数が減り（網走はほぼ横ばい）、1日あたりの雨量が増えていました。降水日数の減りが大きかったのは境（161日→148日）と浜田（137日→126日）です。年降水量が増えたのは4地点だけでした。
- 強い雨の日も数えました。1日に50mm以上降った日は、13地点の平均で1931〜1960年の年3.8日から、1996〜2025年は4.5日に増えています（19%増）。指数の傾きでは100年あたり37ポイント（標準誤差10）です。1時間の雨の強さについては記事056（1時間100mm以上の雨は40年で2倍）で扱っていて、1日の雨で見ても同じ向きでした。

## 頑健性
- 降水日数の線を0.5mmにしても、13地点の中央値で100年あたり5.6日減る
- 10mm以上の日に限ると、日数はほぼ横ばい（中央値で100年あたり−0.5日）。減ったのは主に弱い雨の日
- 1961年以降に限っても、降水日数は100年あたり−4.3ポイント（標準誤差2.9）、1日あたりの雨量は+11.6ポイント（標準誤差4.2）で同じ向き
- 東京を含めず13地点で計算（東京も同じ向き：105日→102日、14.7mm→15.7mm）
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致した

## 動かし方
```
pip install -r requirements.txt
cd src && python a265_wet_days_intensity.py
```
`src/fetch.py` は気象庁のページから同じ形のデータを取り直すスクリプトです（全地点・全月で約1.6万ページ。ふつうのネット環境向けで、このデータを取ったときはブラウザの中で同じページを読みました。このスクリプト自体は動かして確かめていません）。

## データ
- `data/jma_daily_14st_1931_2025.tsv.gz`：気象庁「過去の気象データ検索」日ごとの値（daily_s1、view=p1）を2026-11-12に取得し、地点・年・月・日・降水量合計・平均気温・最高気温・最低気温・降雪の深さ合計・最深積雪・天気概況（昼・夜）を取り出したもの（485,786行）。値の印（`)` 準正常値、`]` 資料不足値、`×` 欠測、`--` 現象なし）はそのまま残し、`src/common.py` で `)` は使う、`]`・`×` は欠測、`--` は0として読みます
- 地点：網走・根室・寿都・山形・石巻・伏木・飯田・銚子・境・浜田・彦根・多度津・宮崎（気象庁が長い気温の変化に使う、都市化の影響が比較的少ない15地点から、亜熱帯の名瀬・石垣島を除いた13地点）と、比べるための東京

## 注意
- 雨量計の種類や置き方、無人の観測所への切り替え（2000年代に多い）による測り方の変化は補正していません。弱い雨の数え方に影響している可能性があります（推測）
- 1mmの線を0.5mmにすると降水日数の減りは同じ向きですが、1日あたりの雨量の増え方は小さくなります（100年あたり0.46mm）
- 雨の降り方が変わった理由（気温の上昇、梅雨や台風の変化など）は、このデータでは分けていません
- 14地点の結果で、日本全体の平均ではありません
