# 524 深夜まで営業する店で、売上を暦日で切るか「朝5時締めの営業日」で切るかで、曜日別の売上はどれだけ変わるのか？（実務の型）

架空の店（17時〜翌3時に営業）の2025年1年分の1時間ごとの売上を作り、同じ売上を「暦日（0時で切る）」と「営業日（朝5時で切る。0〜4時台は前の日の営業日に入れる）」で日ごとに集計して、曜日別・月別の売上を比べたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A524 | 暦日で切ると、曜日別の売上は営業日で切った場合と何%違うか。売上の多い曜日の順位は入れ替わるか。月の売上はどれだけ違うか。深夜の売上の割合でどう変わるか | 営業日の曜日ごとに売上の大きさと0時以降の割合を置いて1時間ごとの売上を作り、2通りで日ごとに集計する。0時以降の割合を0〜2倍に変えてくり返す。営業日の集計は SQL（DuckDB）でも行い、Python と一致するか確かめる | `src/a524_cutoff.py`、`src/02_business_day_duckdb.sql`、`src/01_business_day_tsql.sql`（T-SQL 版、未検証） |

## 主な結果（0時以降の売上は年間の24.7%）
- **曜日別の1日あたりの売上（暦日 ÷ 営業日 − 1）**：月 −3.6%、火 −0.8%、水 −3.6%、木 −6.5%、金 −18.2%、土 −3.9%、日 +56.8%
- **1位の曜日が入れ替わる**：営業日では金曜（40.5万円）が1位・土曜（39.3万円）が2位、暦日では土曜（37.8万円）が1位・日曜（35.8万円）が2位・金曜（33.1万円）は3位。日曜は営業日では7位
- **月の売上の差**：−1.23%〜+1.67%。前の月の最終日の夜の売上が入り、その月の最終日の夜の売上が出ていくので、月末と前月末の曜日で決まる（3月は前月末が金曜・月末が月曜で+1.67%）
- **年間の合計**はほぼ同じ（2024/12/31 の夜の分が入り、2025/12/31 の夜の分が出るだけ）
- **0時以降の割合を変えると**：12.3%で日曜 +28.4%・金曜 −9.1%、37.0%で日曜 +85.2%・金曜 −27.2%、49.3%で日曜 +113.5%・金曜 −36.3%。0%なら差はない
- SQL（DuckDB）で集計した営業日の売上は、Python と全日一致

## 動かし方

```
pip install -r requirements.txt
cd src && python a524_cutoff.py
```

## データ
- `data/fictional_hourly_sales.csv`：架空の1時間ごとの売上（seed 524）。列は hour_start（その1時間の始まり）・sales（円）

## 注意（言えないこと）
- 架空のデータ。曜日ごとの売上の大きさと0時以降の割合は作成者が置いたもので、実際の店の値ではない
- 祝日や連休は入れていない。祝日の前の夜が混む店では、暦日の祝日明けの日がさらに多く出る
- どちらで切るべきかは決めていない。レジや会計の締め時刻、勤務の区切りとそろっているかで選ぶもの
- 営業時間（17時〜翌3時）と締め時刻（朝5時）は1通りだけ。締め時刻を3時より前にすると、営業日の集計にも夜中の切れ目ができる
- T-SQL 版は SQL Server 本体では動かしていない（未検証）
