# 924 平均点が年ごとに違う試験の点は、そのまま比べてよいのか？（試験と点数）

毎年行う試験では、年ごとに問題を作り直すので、問題の難しさが年で変わります。受ける人の顔ぶれも年で変わります。その年の平均点が下がったとき、問題が難しかったのか、受けた人の実力が低かったのかは、平均点だけでは分かりません。**ここでは、作成者が乱数で作った架空の社内の資格試験5年分（年ごとの問題の難しさと受ける人の実力を作成者が置いたもの）で、年ごとの点を1年目の物差しに直す3つの方法（そのまま／年ごとに平均と散らばりをそろえる／毎年同じ共通の問題でつなぐ）を比べ、年の平均と合否が本当の値からどれだけずれるかを数えました。**

偏差値（その回の受けた人の中での位置）が分布の形でどう変わるかは関連する記事 922、1回の試験の点が実力からどれだけ振れるかは 926 で扱っています。計測の仕組みが途中で変わったときに前月比がふくらむ話は 848（SNSと動画）です。この記事は、年ごとに問題が変わる試験の点を、年をまたいで比べるときのずれに絞ります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A924 | 年ごとに平均点が違う試験で、点をそのまま比べると、年の平均と合否は本当の値からどれだけずれるか。年ごとに平均と散らばりをそろえる方法、毎年同じ共通の問題でつなぐ方法では、どれだけ直るか | 架空の社内の資格試験を5年分、毎年1,000人が受ける。問題は毎年50問（1問2点の100点満点）。そのうち10問は毎年同じ共通の問題（難しさは平均0・標準偏差1の正規分布から1回だけ引く）、40問は年ごとに作り直し、難しさは平均が年ごとに 0・+0.4・−0.3・+0.3・−0.5（+は難しい）、標準偏差1の正規分布。受ける人の実力は、平均が年ごとに 0・+0.2・−0.2・−0.1・+0.3、標準偏差1の正規分布（実力と難しさは同じ物差し。人どうしの実力の標準偏差が1）。1問の正答の確率は 1÷(1+exp(−1.7×(実力−難しさ)))。本当の点は「1年目の50問を解いたときの正答率の見込み×100」。合格は1年目の物差しで60点以上。点の直し方は、A そのまま、B 年ごとに平均と標準偏差を1年目にそろえる（受ける人の実力は毎年同じとみなす）、C 共通の10問でつなぐ（その年の全体の点を共通の10問の点に直線で直し、それを1年目の共通の10問と全体の点の関係で1年目の点に直す。2段の直線でつなぐ方法）。例の5年分のほか、人と問題を作り直して200回数えた。確かめとして、年ごとの難しさの差（0・0.5・2倍）、受ける人の差（0・2倍）、共通の問題の数（5・20問）、受ける人の数（各200人）、共通の問題が出回って2年目以降だけ易しくなる幅（0.3・0.6）を1つずつ変え、各50回で数えた。seed 924 | `src/a924_yearly_compare.py` |

## 主な結果

### 例の5年分（各1,000人）
| 年 | 置いた難しさ | 置いた受ける人の平均 | その年の平均点（そのまま） | 本当の平均（1年目の物差し） | A そのまま − 本当 | B 平均と散らばりをそろえる − 本当 | C 共通の10問でつなぐ − 本当 |
|---|---|---|---|---|---|---|---|
| 1年目 | 0 | 0 | 48.1 | 47.8 | +0.3 | +0.3 | +0.3 |
| 2年目 | +0.4 | +0.2 | 46.0 | 53.8 | **−7.8** | −5.8 | +0.1 |
| 3年目 | −0.3 | −0.2 | 49.2 | 43.9 | +5.3 | +4.2 | −0.1 |
| 4年目 | +0.3 | −0.1 | 35.4 | 47.5 | **−12.2** | +0.5 | +0.1 |
| 5年目 | −0.5 | +0.3 | 61.3 | 56.4 | +4.8 | **−8.4** | −0.4 |

- 2年目は、平均点が1年目より2.1点下がった（48.1→46.0）。けれども本当の平均は6.0点上がっていた（47.8→53.8）。問題が難しくなった分が、受ける人の実力の伸びを上回って見えなくした
- 4年目は、その年の平均点が35.4点と1年目より12.7点低かった。本当の平均は47.5点で、1年目とほぼ同じだった。置いた難しさの平均は+0.3だが、実際に引いた40問の難しさの平均は+0.605で、たまたま難しい側に寄ったので、ずれは−12.2点と大きくなった
- そのままの点が58〜62点だった人の本当の点の平均は、年により**54.4〜74.4点**だった（1年目59.1点、2年目67.7点、3年目54.4点、4年目74.4点、5年目54.8点）。同じ「60点前後」でも、年によって本当の点は19.9点ちがった

| 年 | 本当の合格率 | A そのまま | B 平均と散らばりをそろえる | C 共通の10問でつなぐ |
|---|---|---|---|---|
| 1年目 | 33.3% | 34.7% | 34.7% | 34.7% |
| 2年目 | 42.3% | 32.7% | 32.7% | 42.2% |
| 3年目 | 26.3% | 35.0% | 32.3% | 27.2% |
| 4年目 | 32.8% | **17.6%** | 29.6% | 29.6% |
| 5年目 | 46.9% | 56.8% | 38.5% | 49.4% |

- そのままの点で60点の線を引くと、4年目の合格率は17.6%で、本当の32.8%の半分ほどになった

### 人と問題を作り直して200回
| 直し方 | 年の平均のずれがいちばん大きい年のずれ（平均） | 同じ（10〜90%の範囲） | 合否が本当と同じだった人の割合 |
|---|---|---|---|
| A そのまま | **11.5点** | 8.4〜15.0点 | 88.7% |
| B 年ごとに平均と散らばりをそろえる | 6.9点 | 5.7〜8.2点 | 91.9% |
| C 共通の10問でつなぐ | **0.9点** | 0.5〜1.4点 | 93.6% |

| 年 | A そのまま | B 平均と散らばりをそろえる | C 共通の10問でつなぐ |
|---|---|---|---|
| 2年目（難しい・受ける人が上） | −7.3点 | −4.5点 | −0.4点 |
| 3年目（易しい・受ける人が下） | +5.6点 | +4.5点 | +0.4点 |
| 4年目（難しい・受ける人が少し下） | −5.5点 | +2.2点 | +0.2点 |
| 5年目（易しい・受ける人が上） | +8.5点 | −6.8点 | −0.6点 |

- 正直に書くと、A のずれは置いた問題の難しさの写しで、B のずれは置いた受ける人の差の写し（B は受ける人の差を消してしまうので、受ける人が上の年ほど低く出る）。結果の向きは、置き方から決まる
- C でも、合否が本当と同じだった人は93.6%にとどまった。残りの6.4%は、1回の試験の点そのものの振れによるもの（どの直し方でも消えない。926 で扱う）

### 確かめ：置き方を1つずつ変えると（各50回の平均、年の平均のずれがいちばん大きい年のずれ）
| 変えたもの | A そのまま | B 平均と散らばりをそろえる | C 共通の10問でつなぐ |
|---|---|---|---|
| 基本 | 11.0点 | 7.3点 | 0.9点 |
| 問題の難しさの差 0倍（問題を選ぶ偶然の差だけ） | 5.2点 | 6.9点 | 0.9点 |
| 問題の難しさの差 0.5倍 | 8.1点 | 6.9点 | 0.9点 |
| 問題の難しさの差 2倍 | **17.9点** | 6.9点 | 0.8点 |
| 受ける人の差 0倍（毎年同じ） | 11.1点 | **1.4点** | 0.7点 |
| 受ける人の差 2倍 | 11.5点 | **13.3点** | 1.3点 |
| 共通の問題 5問 | 12.9点 | 7.1点 | 1.5点 |
| 共通の問題 20問 | 9.3点 | 6.9点 | 0.5点 |
| 受ける人 各200人 | 11.7点 | 7.8点 | 1.6点 |
| 共通の問題が出回り0.3易しくなる | 11.7点 | 6.9点 | **6.8点** |
| 共通の問題が出回り0.6易しくなる | 12.5点 | 6.9点 | **13.0点** |

- 共通の問題が出回らない置き方では、ずれは A で5.2〜17.9点、B で1.4〜13.3点、C で0.5〜1.6点だった。C はどの置き方でも2点を下回った
- 問題の難しさの差を0倍にしても、A のずれは5.2点残った。40問を毎年引き直すだけで、年の難しさは偶然に変わるため
- B が当たるのは、受ける人の実力が毎年同じときだけだった（1.4点）。受ける人の差を2倍にすると、B のずれは A を上回った
- C は、共通の問題が2年目以降だけ易しくなると崩れた（0.3で6.8点、0.6で13.0点）。共通の問題が易しくなった分を「受ける人の実力が上がった」と読んでしまうため。共通の問題が年で変わらないことが、C の前提

```
pip install -r requirements.txt

```

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の9ファイルがバイト単位で一致した（cmp、約37秒）
- 図3枚を開き、日本語・重なり・軸を確かめた
- 1年目は3つの直し方がすべて同じ点になる（1年目に1年目をそろえるため）ことを、表の1年目の値で確かめた
- 受ける人の差を0倍にすると B のずれが1.4点に縮み、C は共通の問題が出回らない限り2点を下回った。作りが置いたとおりに動いていることの確かめ

## 注意（言えないこと）
- 架空のデータです。年ごとの問題の難しさ、受ける人の実力の差、共通の問題の数、正答の確率の式は作成者が置いたもので、結果はこれで決まります。そのままのずれは置き方で5.2〜17.9点と動きました。実在の試験の点の出し方や合否の決め方を表すものではありません
- 1問ごとの正答は、実力と難しさだけで決まると置きました。問題の形式の違い、時間の足りなさ、共通の問題を置く位置（前半か後半か）による違いは入れていません
- 共通の問題でつなぐ方法は、2段の直線でつなぐ簡単な方法だけを試しました。ほかのつなぎ方（問題ごとの難しさを推し量ってそろえる方法など）は試していません
- どの方法で合否を決めるべきか、合格点をどう置くべきかは言えません。この記事は、点を年をまたいで比べたときのずれを数えただけです
