# 758 件数が少ないとき、モデルの「上位10%のリフト」はどれだけ揺れるのか（手法の解説・正解の分かるデータで試す）

反応しそうな人を当てるモデルは、「点数の上位10%の反応率が、全体の何倍か」（上位10%のリフト）で比べることがよくあります。反応率が低いと、上位10%に入る反応者はわずかで、リフトは件数しだいで大きく揺れます。**ここでは、架空の DM の反応（全体の反応率2%と5%）で、本当のリフトが3.60のモデル A と3.19のモデル B を作り、検証データの件数を1,000〜30,000件と変えて各1,000回リフトを測りました。** モデルの強さと反応率は作成者が置いたもので、数字はその置き方で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A758 | 件数が少ないと、上位10%のリフトはどれだけ揺れ、2つのモデルの順位は入れ替わるか | 本当の反応のしやすさ z から反応をロジスティックで作り、モデル A の点数 = z＋雑音（標準偏差0.5）、B = z＋雑音（0.8）。件数4通り×反応率2通り×1,000回。本当のリフトは100万件で計算。1回分のデータにブートストラップ（500回）。seed 758 | `src/a758_lift.py` |

## 主な結果
- **反応率2%、1,000件（反応は約20件）**：モデル A のリフトは90%の回で1.9〜5.5（本当は3.60）。30,000件（反応約600件）でも3.29〜3.93
- **順位の入れ替わり**：劣るモデル B が A を上回った割合は、反応率2%で1,000件26.7%、3,000件20.5%、10,000件9.5%、30,000件1.2%。反応率5%では22.7%・12.1%・2.1%・0.1%
- **効くのは反応者の数**：リフトの振れは、件数よりも上位10%に入る反応者の数でほぼ決まる。反応率2%の10,000件（反応約200件）と5%の3,000件（約150件）は、振れが近い
- **1回分のデータの区間**：反応率2%で1,000件のブートストラップ95%区間は1.67〜5.00、10,000件では3.48〜4.78

## 動かし方
```
pip install -r requirements.txt
cd src && python a758_lift.py
```
十秒ほどで終わります。`results/summary.csv` に件数・反応率ごとのリフトの振れと、B が上回った割合を書き出します。

## 確かめたこと
- 空のフォルダで流し直し、results・figures がバイト単位で一致した
- 全体の反応率が2%・5%になるよう切片を数値で合わせ、100万件で2.01%・5.02%になることを確かめた

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 758）
- 仮定：z は標準正規分布、反応の確率 = 1/(1+exp(−(a+1.1z)))。モデルの点数は z に正規分布の雑音を足したもの

## 注意（言えないこと）
- シミュレーションの結果。振れの大きさは、反応率・モデルの強さ・上位何%を見るかで変わる
- 2つのモデルは同じ検証データで比べた。別々のデータで比べると、入れ替わりはもっと多くなる（推測）
- 実在の施策の数字ではない
