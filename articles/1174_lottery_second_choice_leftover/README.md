# 1174 第1希望と第2希望を書ける抽選では、第2希望が当たる見込みは何で決まるのか？（抽選と倍率）

いくつかの回から選んで申し込む抽選では、第1希望と第2希望を書けることがあります。第2希望の当たりやすさを、「その回を第2希望に書いた人の数÷枠」のような倍率で読みたくなります。けれども、第1希望の人を先に抽選する決まりなら、第2希望に回るのは第1希望で埋まらずに残った枠だけです。決まりが変われば、第2希望の当たりやすさも、第1希望の当たりやすさも変わります。**ここでは、作成者が置いた架空の体験講座（A〜Eの5回、枠の合計600、申し込む人1,000人。第1希望の割合はA35%・B25%・C20%・D12%・E8%）で、2つの抽選の決まり（第1希望を先に抽選する／でたらめな順に第1希望・第2希望の順で割り当てる）ごとに、第1希望に外れた人が第2希望で当たる見込みを2,000回の抽選で数え、「残った枠÷外れてその回を第2希望に書いた人」の式と照らしました。申し込む人の数3通り×第1希望の偏り3通りの9通り（決まりごとに各500回）でも確かめました。**

例の講座・申し込み・決まりは作成者が置いたもので、実在の催しや申し込みの仕組みを表すものではありません。どの回を第1希望・第2希望に書くとよいか、申し込むかどうかの助言ではありません。

第1希望を先に抽選する決まり（①）では、第1希望の人の当たる見込みは「枠÷第1希望の人の数（100%まで）」になり（式どおり）、第1希望で埋まった回を第2希望に書いても当たりません（作りどおり）。この記事で数えて新しく分かったのは、残った枠のある回での第2希望の見込みが式とどれだけ合うか、「第2希望に書いた人÷枠」の読みとどれだけ違うか、順に割り当てる決まり（②）ではそれがどう入れかわるかです。

関連する記事：同じ企画の 1179「日にちごとに分けて抽選すると、混む日と空いた日の当たりやすさは何倍開くのか？」は、第2希望のない日ごとの抽選で、日の当たりやすさの開きを扱っています。同じ企画の 1173「「倍率10倍」の抽選で、1人が当たる見込みは本当に10分の1なのか？」は、1人が何口も申し込めるときの掲げる倍率と1人の見込みの差を扱っています。この記事は、第2希望の当たりやすさを決めるものに絞ります。

- **①第1希望を先に抽選すると、第1希望で埋まったA・B・Cを第2希望に書いた人は、どの回も0%だった（作りどおり）**。「枠÷第2希望に書いた人」で読むと37.04〜55.05%に見える
- **残った枠のあるDとEでは、第2希望の見込みは35.9%と75.27%で、式（残った枠30・50÷外れてその回を第2希望に書いた人の見込み83.5人・66.3人）の35.92%・75.46%と0.19ポイント以内で合った**。素朴な読みはどちらも100%だった
- ①の第1希望の見込みは、枠÷第1希望の人（100%まで）と一致した（式どおり）
- **②順に割り当てると、第1希望で埋まるBとCでも、第2希望で7.16%・20.9%当たった**。順の早い人が、第1希望の人より先に枠を使うため。そのぶん、第1希望の見込みはDで100%から77.06%、Cで60.0%から46.97%に下がった
- 申し込んだ人全体で当たった割合は、①も②も60.0%だった（枠600がすべて埋まる、600÷1,000＝60%）。第1希望で当たった割合は①52.0%、②44.69%だった

### 第1希望×第2希望の組ごと（基本、`results/by_pair.csv`）
- 第1希望がAの人がどこかで当たる見込みは、①で、第2希望がBなら28.57%、Eなら82.35%だった（28.57〜82.35%）。②では35.96〜88.23%だった
- ①では、第1希望がDかEの人は、第2希望がどこでも100%だった（第1希望の枠に全員入る、作りどおり）

### 確かめ：9通り（人数×偏り、決まりごとに各500回、`results/grid.csv`）
- 45の回（9通り×5回）のうち、第1希望の倍率が1倍以上の31の回では、①の第2希望の見込みはすべて0%だった（作りどおり）。②では同じ31の回で0〜60.82%だった
- 第1希望の倍率が1倍未満の14の回では、①の第2希望の見込みは15.18〜100%で、式との差は45の回すべてで3.83ポイント以内だった
- 素朴な読み（枠÷第2希望に書いた人）と①の数えた値の相関は0.758、式と数えた値の相関は1.0だった
- ②にすると、第1希望の見込みは①より0〜42.86ポイント下がった（上がった回はなかった）

## 注意（言えないこと）
- 架空のデータと、作成者が置いた架空の抽選の決まりです。回の数、枠、希望の偏り、決まりを変えれば、見込みは変わります。実在の催しの抽選のしかたを表すものではありません
- 第2希望の選び方は、第1希望の割合に比例すると置きました。人が倍率を見て第2希望を選ぶ動きは入れていません
- 第2希望を書かない人、第3希望まで書ける決まり、当たった人の辞退や繰り上げは入れていません
- ②の式は作っていません。②の値は抽選をくり返して数えたものだけです
- どの回を第1希望・第2希望に書くとよいか、申し込むかどうかの助言ではありません
