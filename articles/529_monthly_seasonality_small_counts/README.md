# 529 月別の事故件数を1年分だけで見ると、季節の山は偶然と見分けられるのか（保険数理・リスク）

月別の事故件数を並べると、たいてい山と谷が見えます。それが本当の季節の動きなのか、件数の偶然の振れなのかは、件数の多さと使う年数で見分けやすさが変わります。**ここでは、月平均5・20・100件の架空の件数に、山の大きさ A（平均の ±0〜40%、1月が山）の季節を入れ、1年・3年・10年分の合計について「12か月とも同じ」をカイ二乗検定（5%）で調べた割合を、各場面5,000回のくじで出しました。** 件数のばらつきがポアソンより大きい場合（分散が平均の2倍）も置いています。数字は、置いた件数・山の大きさ・ばらつきで決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A529 | 1〜10年分の月別件数で、季節の山を見分けられるか | 月の平均 = λ ×（1 + A × cos(2π(月−1)/12)）、λ = 5・20・100、A = 0・0.1・0.2・0.4。件数はポアソン（季節なしでは負の二項・分散2倍も）。年数分を月ごとに合計し、一様のカイ二乗検定（自由度11、5%）。季節指数 = 月の合計 ÷ 月平均、本当の指数との差の二乗平均の平方根。山の月（合計が最大の月）が12〜2月に入る割合。各場面5,000回、seed 529 | `src/a529_seasonality.py` |

## 主な結果
- **山の大きさ A=0.2（1月が平均の1.2倍、7月が0.8倍）を見つける割合**：月平均5件では 1年 **9%**・3年 19%・10年 61%、20件では 1年 **26%**・3年 72%・10年 100%、100件では 1年 94%・3年以降 100%
- **山が小さい A=0.1 だと**：月平均20件・1年で 9%、10年でも 62%
- **季節がない（A=0）とき、ポアソンなら見つかってしまう割合は 4.7〜5.3%**（検定の5%どおり）
- **件数のばらつきが平均の2倍あると、季節がないのに 51〜54% で「季節あり」になる**。年数を増やしても下がらない
- **季節指数の誤差（A=0.2）**：月平均5件で 1年 0.42・10年 0.13、20件で 0.21・0.07、100件で 0.09・0.03。季節の山そのものの大きさ（指数の標準偏差 0.14）と比べると、月平均5件では10年分でも誤差が同じくらい
- **山の月が12〜2月に入る割合（A=0.2）**：月平均20件・1年で 62%（季節がなくても 25% は入る）

## 動かし方
```
pip install -r requirements.txt
cd src && python a529_seasonality.py
```

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- 季節がなくポアソンのとき、見つかる割合が5%前後になること
- 季節がないとき、山の月が12〜2月に入る割合が 3/12 = 25% 前後になること
- ばらつき2倍の誤検出率が、カイ二乗の値が2倍になると置いた計算（P(χ²₁₁ > 19.68/2) ≒ 54%）とおおむね合うこと

## データ
- データファイルは置いていない。件数はコードの中で乱数から作る（seed 529）

## 注意（言えないこと）
- 架空の月別件数。実際の事故・実際の会社の数字ではない
- 月の日数の違い（2月が短いなど）、年ごとの件数の増減、祝日などは入れていない
- カイ二乗検定は「12か月とも同じか」を見るもので、山の形や時期を当てるものではない。季節の見方としては、前後の月とのつながりを使う方法などもある
- ばらつきが大きい場合の補正（過分散を見込んだ検定など）はしていない。ここではその影響の大きさだけを示した
