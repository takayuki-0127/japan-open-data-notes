# 1230 同じ内容の文書が何件もあると、上位10件の正しい割合は高く出ても、役に立つ文書はいくつなのか？（検索の良さ）

社内の文書の集まりには、同じ手順書を別のフォルダに置いた写しや、日付だけ違う版が何件も入っています。検索の良さを「上位10件のうち正しい文書の割合」で数えると、同じ中身の写しも1件ずつ正しいと数えます。写しは元の文書とほぼ同じ点になるので、正しい文書が上に来ると、その写しも一緒に上に並びます。割合は高く出ても、読む人にとって役に立つ別々の中身は、正しい文書の件数より少なくなります。**ここでは、作成者が置いた架空の社内の文書と検索語（中身ごとの正しさと写しの件数を作成者が決め、検索の点を乱数で作ったもの）で、文書をそのまま点の順に並べるやり方と、同じ中身の写しは1件だけ残すやり方を比べ、上位10件の正しい割合と、上位10件に入った別々の正しい中身の数がどう違って見えるかを数えました。置き方を変えた27通りで確かめました。**

例の文書と検索語は架空のもので、実在の会社の文書・検索の仕組みを表すものではありません。どちらの並べ方を使うとよいかを勧める記事ではありません。

関連する記事：965「同じ文の重複（コピペ）を除かないと、何が起きるのか？」は、問い合わせの文に混ざった写しを除かないと、話題の割合や件数がどうずれるかを扱っています。1228「長い文書ほど多くの言葉を含むとき、長い文書はどれだけ上に出やすくなるのか？」は、長い文書ほど多くの言葉を含むと、上位10件が長い文書に偏ることを扱っています。どちらも、上位10件の枠を何が埋めるかで良さの数字が動く場面です。この記事は、検索の結果の上位10件という枠の中で、写しが枠を埋めると良さの数え方がどう見えるかに絞ります。

## 主な結果

### 基本の置き方（200語×20回の平均、`results/a1230_main.json`）
| 並べ方 | 上位10件の正しい割合 | 上位10件の正しい文書（件） | うち別々の正しい中身（件） | うちすでに出た正しい中身の写し（件） |
|---|---|---|---|---|
| A 文書をそのまま並べる | **52.72%** | 5.272 | **2.72** | 2.552 |
| B 同じ中身は1件だけ残す | 34.34% | 3.434 | **3.434** | 0 |

- **A は上位10件の正しい割合が52.72%と高く出たが、別々の正しい中身は2.72件だった**。正しい文書5.272件のうち、役に立つ別々の中身は51.58%（0.5158）で、残りはすでに上に出た中身の写しだった
- 上位10件の枠のうち、前に出た中身の写し（正しい中身・正しくない中身の両方）は平均3.792枠だった
- B は正しい割合が34.34%に下がり、別々の正しい中身は3.434件に増えた。**2つの並べ方の良し悪しは、正しい割合では A、別々の正しい中身の数では B と入れかわった**
- B の別々の正しい中身の数が A を下回る検索語はなかった（0%）。B は A の上位10件にある中身をすべて残し、写しの空いた枠に次の中身を入れるので、作りどおり。B のほうが多かった語は52.4%、正しい割合は A のほうが高く別々の中身は B のほうが多かった語は34.58%
- 写しを1件もない置き方にすると、正しい割合は34.09%、別々の正しい中身は3.409件で、B とほぼ同じになった。写しの点はほぼ同じと置いたので、写しを1件にまとめれば写しのない並びに戻る（ほぼ作りどおり）
- 1回分の例（`data/query_top20_example.csv`、200語）：A の上位10件の正しい割合は52.85%、別々の正しい中身は1語あたり2.77件

### 確かめ：27通り（各200語×10回、`results/grid.csv`）
- **27通りすべてで、上位10件の正しい割合は A のほうが高く、別々の正しい中身の数は B のほうが多かった**。正しい割合の差 A−B は2.4〜30.04ポイント、別々の正しい中身の差 B−A は0.11〜2.28件
- **正しい中身もほかの中身と同じ確率で写しを持つ（写しやすさ1倍）9通りでも、正しい割合の差 A−B は2.4〜12.97ポイントあった**。写しは元の中身とほぼ同じ点になるので、上に来る正しい中身の写しは上位10件に入り、下にある正しくない中身の写しは入らない
- A の正しい文書のうち別々の中身の割合は、35.13%〜83.81%（0.3513〜0.8381）だった。写しがある確率が高く、正しい中身ほど写しやすいほど低い
- 差は写しの多さで決まり、写しがある確率0.1・写しやすさ1倍・正しい中身3件で最小（2.4ポイント）、0.4・3倍・6件で最大（30.04ポイント）だった

## 注意（言えないこと）
- 架空のデータです。写しの多さ、正しい中身ほど写しやすいこと、正しい中身の数、点の差の大きさは作成者が置いたもので、差の大きさはこれで決まります。表のとおり、正しい割合の差は置き方で2.4〜30.04ポイントまで動きます
- 写しは「ほぼ同じ点になる同じ中身の文書」とだけ置きました。少し書き足した版、古い版で中身が違うもの、一部だけ重なる文書は入れていません。実際には、どこからを同じ中身とみなすかで B の数え方も変わります
- 正しさは「正しい・正しくない」の2つだけと置きました。写しのどれがいちばん新しい版か、どれを読むべきかの違いは数えていません
- 読む人にとって写しが本当に役に立たないかは、場面によります（ほかの写しの置き場所が分かることに意味がある場合もある）。ここでは、別々の正しい中身の数を「役に立つ文書の数」と置きました
- 実在の検索の仕組みの並べ方を表すものではありません。どちらの並べ方を使うとよいかは扱っていません
