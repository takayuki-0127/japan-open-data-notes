# 846 ハッシュタグの「効果」は、付けた投稿の選ばれ方で決まるのか？（SNSと動画）

SNS や動画サイトの運用で「タグを付けた投稿は、付けない投稿より再生数が多い。だからタグには効果がある」と読むことがあります。しかし、タグを付けるかどうかは投稿する人が選んでいます。自信のある投稿にだけ付けていれば、タグに効果がなくても、タグ付きの投稿は再生数が多く見えます。**ここでは、作成者が乱数で作った架空のアカウントの投稿2,000本（タグの本当の効果を作成者が0と置いたもの）で、「タグ付きの再生数は付けない投稿の何倍か」を、素朴に比べる・ジャンルをそろえて比べる・無作為に付けて比べるの3つで数え、本当の効果（1.00倍）からどれだけずれるかを数えました。**

投稿の時刻と内容が重なって見える話は関連する記事 839、伸びた投稿だけを見て型を決める話は 838 で扱っています。839 は、選び方に効く出来が記録に残らないと記録に残る印で分けてもずれが残ること、くじで決めても本数が少ないと向きを読み違えることを扱います。この記事は「付けるかどうかを人が選ぶこと」と、付ける人の見積もりの正確さと付け方で、見かけの効果の大きさと向きまで変わることに絞ります。

## 主な結果

### 1回分（2,000本）
| | タグ付き | タグなし |
|---|---|---|
| 本数 | 800 | 1,200 |
| 再生数の中央値 | 1,652 | 736 |
| 中身の強さの平均（作成者が置いた値） | 0.68 | −0.47 |

- タグに効果がないと置いても、タグ付きの再生数の中央値はタグなしの**2.24倍**だった。違いはタグではなく、タグ付きの投稿の中身が強かったことから来ている
- 再生数の上位100本のうち87%がタグ付きだった

### 比べ方ごと（300回）
| 比べ方 | タグ付き÷タグなし（中央値） | 5〜95%の範囲 |
|---|---|---|
| 素朴に比べる | **2.45倍** | 2.24〜2.66倍 |
| ジャンルをそろえる | 2.21倍 | 2.03〜2.38倍 |
| 無作為に付けて比べる | **1.00倍** | 0.91〜1.09倍 |

- 素朴に比べると、300回すべてで1.2倍を超えた（100%）。無作為に付けた場合に1.2倍を超えたのは0%だった
- ジャンルをそろえると少しずれが減ったが、2.21倍のままだった。ジャンルは中身の強さの一部しか表していないため、そろえてもジャンルの中での「自信のある投稿」の差は残る

### 見積もりの正確さと付け方（各300回、本当の効果0）
| 見積もりの誤差（標準偏差） | 自信のある投稿4割に付ける | 自信のない投稿4割に付ける（底上げ狙い） |
|---|---|---|
| 0.25（よく分かる） | 3.30倍 | 0.30倍 |
| 0.5 | 3.06倍 | 0.33倍 |
| 1（基本） | 2.46倍 | 0.41倍 |
| 2 | 1.77倍 | 0.56倍 |
| 4（ほぼ分からない） | 1.37倍 | 0.73倍 |
| 無作為に付ける | 1.00倍 | |

- 投稿する人が中身の強さをよく分かっているほど、タグの「効果」は大きく見えた
- 弱そうな投稿をタグで底上げしようとして付けると、同じ効果0のタグが「付けると再生数が0.3〜0.7倍に下がる」ように見えた。見かけの効果の向きは、タグそのものではなく、どの投稿に付けたかで決まった

### 確かめ：置き方を変えても（各300回）
| 置き方 | 本当の効果 | 素朴に比べる | ジャンルをそろえる | 無作為に付ける |
|---|---|---|---|---|
| 基本（効果0・上位4割・見積もり誤差1・中身の効き0.8） | 1.00倍 | 2.45倍 | 2.21倍 | 1.00倍 |
| 本当の効果 +10% | 1.10倍 | 2.69倍 | 2.42倍 | 1.10倍 |
| 本当の効果 −10% | 0.90倍 | 2.23倍 | 1.99倍 | 0.90倍 |
| タグを付ける割合 2割 | 1.00倍 | 2.64倍 | 2.37倍 | 1.00倍 |
| タグを付ける割合 6割 | 1.00倍 | 2.46倍 | 2.22倍 | 1.00倍 |
| 中身が再生数に効く強さ 0.4 | 1.00倍 | 1.57倍 | 1.49倍 | 1.00倍 |
| 中身が再生数に効く強さ 1.2 | 1.00倍 | 3.81倍 | 3.25倍 | 0.99倍 |
| 再生数のたまたまの振れ 0.3 | 1.00倍 | 2.46倍 | 2.19倍 | 0.99倍 |
| 再生数のたまたまの振れ 1.0 | 1.00倍 | 2.49倍 | 2.22倍 | 0.99倍 |

- 本当の効果が−10%（付けると再生数が減る）のときでも、素朴に比べると2.23倍に見えた
- 素朴に比べた値は、見積もりの正確さと中身の効きの置き方で1.37〜3.81倍と大きく動いた。どの置き方でも、無作為に付けて比べた値と本当の効果の差は0.02倍以内だった
- 主な結果の表・見積もりの表・確かめの表の「基本」は、それぞれ別の乱数で300回ずつ作ったので、2.45倍・2.46倍・2.45倍と小数第2位で少し違う

```
pip install -r requirements.txt

```

## 確かめたこと
- 空のフォルダ（/tmp。`src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約14秒）
- 図3枚を開き、日本語・重なり・軸を確かめた
- 無作為に付けた場合、本当の効果を0・+10%・−10%と置くと、比べた値はそれぞれ1.00倍・1.10倍・0.90倍になり、作り方どおりに本当の効果を取り出せることを確かめた

## データ
- `data/posts.csv`：1回分の架空の投稿2,000本（post_id・genre（ジャンル）・strength（中身の強さ、作成者が置いた値）・tag（1＝タグ付き）・views（再生数））
- `results/a846_main.json`：主な結果すべて
- `results/methods.csv`：比べ方ごとの300回の平均・5%・中央値・95%
- `results/judge_accuracy.csv`：見積もりの正確さと付け方ごとの結果
- `results/robustness.csv`：置き方を変えた確かめ

## 注意（言えないこと）
- 架空のデータです。中身の強さの散らばり、中身が再生数に効く強さ、投稿する人の見積もりの正確さ、付ける割合は作成者が置いたもので、見かけの倍率（1.37〜3.81倍）はこれで決まります。「タグ付きは2.45倍に見える」は、この置き方での数字です
- タグの本当の効果は、この分析では作成者が置いたものです。実際のタグに効果があるかないかは、この分析からは言えません
- 「無作為に付けて比べる」がずれないのは、中身と関係なく付けたからです。実際に試すときも、付ける投稿をくじなどで決めないと、同じずれが入ります（推測）
- ジャンル以外に、投稿の長さや題材など見える情報でそろえれば、ずれはもう少し減るかもしれません。ただし、投稿する人が感じた「自信」そのものは記録に残らないので、そろえきれません（推測）
- 実在の SNS・動画サイトのタグの仕組みや、おすすめ表示の決め方を表すものではありません
