# 953 出店した場所の売上が高いのは、場所のおかげか？（地図と場所）

店の売上を場所ごとに比べると、「駅前の店はよく売れる」「この場所は当たりだった」と読みたくなります。けれども、出店した場所は、会社が見込みの高い順に選んだ場所です。見えているのは選ばれた場所の売上だけで、選ばなかった場所の売上は見えません。**ここでは、作成者が乱数で作った架空の町（30×30 の区画）の出店候補地400か所（場所ごとの本当の売上の力を作成者が置いたもの）で、出店前の見込みが基準を超えた場所だけに出店したとき、出店した店の売上から「駅前の有利さ」「場所の力」「見込みの当たり」がどう見えるかを、500の町で数えました。駅前は出店にかかる費用が高いので、出店の基準を駅前だけ高くした、と置いています。**

ハッシュタグを付けた投稿が伸びて見えるのは付けた投稿の選ばれ方による、という形は関連する記事 846、上位だけを見て「成功の秘訣」を決める読み違いは 835、自分で選んで受けた人と講座の人の合格率の比べ方は 928 と同じ「選ばれ方」の話です。区域の線の引き方で「いちばん売れる地区」が入れ替わるかは 945、新しい店の客のうちどれだけがほかの店から移るかは 950 で扱っています。この記事は、出店した場所だけの売上で、場所の良し悪しを読むと何がずれるかに絞ります。

## 主な結果

### 500の町をまとめて（出店した店15,911店、うち駅前2,065店）
| 数えたもの | 結果 |
|---|---|
| 候補地全体の、駅前と駅前以外の本当の力の差 | **+22.4万円** |
| 出店した店の、駅前と駅前以外の売上の差 | **+33.1万円**（駅前429.3万円・駅前以外396.2万円） |
| 同じく、町ごとに数えたときの10〜90%の範囲 | +3.9〜+55.9万円（駅前に出店した461の町） |
| 候補地全体の本当の力の平均 | 331.2万円 |
| 出店した店の1年目の売上の平均 | 400.5万円（候補地全体より**69.3万円**高い） |
| 出店した店の出店前の見込みの平均 | 430.6万円（売上は見込みより**30.1万円**低い） |
| 次に出す5か所の本当の力（駅前） | 400.8万円（いまの駅前の店より28.5万円低い） |
| 次に出す5か所の本当の力（駅前以外） | 375.7万円（いまの駅前以外の店より20.5万円低い） |

- 出店した店だけを見ると、駅前の有利さは33.1万円に見えた。置いた本当の差は20万円で、候補地全体で数えた差は22.4万円。駅前は基準を40万円高くしたので、駅前で出店できたのは、もともと力の強い場所だけだった
- 出店した店の売上は、候補地全体の平均より69.3万円高い。けれども、これは「出店すれば売れる」ではなく、会社が見込みの高い場所を選んだ結果。でたらめな候補地に出していれば、平均は331.2万円だった
- 出店した店の売上は、出店前の見込みより平均30.1万円低かった。見込みが上に外れた場所ほど基準を超えやすく、出店した店に集まるため。店の運営が悪かったからではない（運営の振れは平均0と置いた）
- 次に出す場所は、いまの店より駅前で28.5万円、駅前以外で20.5万円低かった。見込みの高い場所から先に埋まるため
- 例の町1つ（出店39店、うち駅前8店）では、見える駅前の差は+21.2万円で、候補地全体の差（+29.8万円）より小さかった。駅前の店が少ない1つの町では、見える差は大きく振れる

- **本当の駅前の差を20万円と置くと、出店した店で見える差は、基準の差0〜60万円で+9.0〜+42.7万円と動いた**。基準の差が0なら本当の差より小さく、基準の差が大きいほど本当の差より大きく見えた
- **本当の差を0と置いても、駅前の基準を40万円高くすると、出店した店では駅前が23.3万円多く見えた**（基準の差0〜60万円で−1.1〜+35.2万円）
- 基準の差が0のとき、見える差は本当の差より小さかった（本当の差20で+9.0、40で+19.0）。基準を超えた店どうしでは、どちらの店も「基準より上」にそろうため、差が縮む
- 売上が見込みより低く出る分は、見込みの誤差でほぼ決まった（誤差0で0.0、15で−9.2、30（基本）で−29.8、60で−73.8万円）。誤差がなければ、見込みどおりに売れる。ここは選び方の仕組みどおりの結果
- 次に出す駅前の5か所は、どの置き方でも、いまの駅前の店より19.4〜37.6万円低かった
- 基本の置き方（本当の差20・基準の差40）は、確かめで別の300の町を数え直したので、見える差は+34.4万円と、500の町の+33.1万円から少し動く

## 注意（言えないこと）
- 架空のデータです。町の形、駅、人の多さ、本当の売上の力の決まり、見込みの誤差、出店の基準は作成者が置いたもので、結果はこれで決まります。出店した店で見える駅前の差は、本当の差20万円のとき、基準の差の置き方で+9.0〜+42.7万円と動きました。実在の町や会社の出店を表すものではありません
- 出店の基準を駅前だけ高くしたのは、この記事で置いた前提です。実際の会社の出店の決め方を表すものではありません
- 店どうしが客を取り合うこと、出店した店が町の人の動きを変えることは入れていません
- どこに出店すべきか、出店の基準や費用をどう決めるべきかは言えません。この記事は、出店した場所だけの売上を読むと何がずれるかを数えただけです
