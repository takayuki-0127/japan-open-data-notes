# F445 事前の計画（PLAN）

作成：2026-11-18 12:50（JST）。結果を集計する前に書いた。

## 問い
航空貨物は、旅客便が減った時期（2020〜2022年のコロナ期）にどれだけ落ちたのか？ 落ち方は、旅客便の減り方と同じだったのか。国内線と国際線で違うのか。

## 知りたい人
- 物流・荷主の担当で、「航空貨物の多くは旅客機の床下（ベリー）で運ばれている」という説明を聞いたことがある人。旅客便が止まると、貨物の運ぶ場所もそのまま減るのかを数字で知りたい
- 航空の統計を読む人。国土交通省の航空輸送統計の年報で、国内線の貨物の重量がコロナのあとどこまで戻ったかを確かめたい
- 世の中の説明：2020年には「旅客便の減便で貨物スペースが不足し、航空運賃が上がった」と報じられた（国内外の業界紙）。この記事では運賃は扱わず、運んだ重さと便の数だけを見る

## データ
- 国土交通省「航空輸送統計調査」年報（e-Stat）、2014〜2025年の各年
  - 統計表2「国内定期航空月別運航及び輸送実績」：月別の運航回数・旅客数・座席キロ・貨物の重量・貨物トンキロ。総合計・幹線・ローカル線
  - 統計表5「国際航空月別運航及び輸送実績」：月別の運航回数・旅客数・座席キロ・貨物の重量・利用可能トンキロ・重量利用率
- 対象は日本の航空会社。国際線は日本の会社の便だけで、外国の会社の便（成田・関西などの国際貨物の大きな部分）は入らない
- 旅客便と貨物便（貨物専用機）は表で分かれていない

### 取得前に見たもの（下見）
- 2025年の統計表2・5と、2025年の付表1（航空輸送量推移表）をファイルの形の確認のために開いた
- 付表1の国内定期の貨物重量（年）：2015年 919,356トン、2019年 791,800トン、2020年 500,721トン、2025年 616,898トン。旅客数は2019年 106,777千人、2025年 111,856千人
- 2020年の統計表5の1〜4月：運航回数 13,074 → 2,901回、貨物 104,610 → 80,341トン（3月は 129,825トン）
- 月別の2019年比、弾力性、幹線とローカル線の分け方はまだ計算していない

## 仮説（外れの基準つき）
- H1（国内は旅客便と一緒に落ちた）：2020年4〜5月の国内線の貨物重量の2019年同月比の減少率は、座席キロの減少率の0.7〜1.3倍。外れ：0.7倍未満か1.3倍より大きい
- H2（国際は落ち方が小さい）：2020年4〜6月の国際線（日本の会社）の貨物重量の2019年同月比の減少率は、座席キロの減少率の半分未満。外れ：半分以上
- H3（国内の戻りは旅客より弱い。下見の数字から立てたので確かめの意味は弱い）：2025年の国内線の貨物重量は2019年より10%以上少ない一方、座席キロは2019年の95%以上に戻っている。外れ：どちらかを満たさない
- H4（戻りの弱さは幹線もローカル線も同じ）：2019→2025年の貨物重量の変化率が、幹線とローカル線で10ポイント以内。外れ：差が10ポイントより大きい

## 手法
- 月ごとに 2019年の同じ月を100とした指数（貨物重量・座席キロ・運航回数・旅客数）。国内・国際・幹線・ローカル線
- 「落ちの比」＝貨物の減少率 ÷ 座席キロの減少率（2020年4〜5月、4〜6月）
- 月別の対数の回帰：log(貨物) = a + b·log(座席キロ) + 月の固定効果。期間を 2014〜2019年（ふだん）と 2020〜2022年（コロナ期）に分けて b を比べる（b が1に近いほど「床下の量と比例」）
- 国際線は 重量利用率（実際に運んだトンキロ÷運べたトンキロ）と、利用可能トンキロの2019年比も見る
- 年の合計で 2019年と2025年を比べる

## 頑健性（3つ以上）
1. 基準の年を2019年ではなく2018年にする
2. 重量ではなくトンキロ（重さ×距離）で見る
3. 座席キロではなく運航回数で「落ちの比」を出す
4. 郵便物を足した重さで見る
5. 国内は幹線だけ・ローカル線だけで見る

## 言えないこと（予定）
- 旅客便と貨物専用機を分けられない。国際線の落ち方が小さい理由が貨物専用機か、旅客機を貨物だけで飛ばした便か、1便あたりの積み方かは分からない
- 外国の航空会社の便が入らないので、日本の空港の国際貨物全体の動きではない
- 運賃や荷主の選び方（船・トラックへの移り）は見ていない
- 国内の貨物が戻らない理由は、この統計だけでは決められない
