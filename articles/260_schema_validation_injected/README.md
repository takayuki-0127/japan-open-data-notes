# 260 取り込む前に、壊れたファイルを止めるチェックはどこまで効くか（実務の型）

統計センター「SSDSE-県別推移（SSDSE-B）」2026年版（47都道府県×12年度×109項目）に、正解の分かる「壊れ」を10種類×200回ずつ入れて、4段のチェック（下の段を含めて足していく）がそれぞれ何割を止めるかを数えたフォルダです。壊していないファイルでチェックが鳴る件数（空振り）も数えました。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A260 | 型・キー・範囲・列どうしのチェックは、どの壊れを止め、どれを通すか | L1 型と空欄、L2 ＋キー（年度×地域コードの重複・欠け、決まった47コード）、L3 ＋範囲（負になりえない項目が負でないか、前年度からの変化が上限以内か）、L4 ＋列どうし（総数＝男＋女を±1,000まで、うち数≦総数） | `src/a260_schema_checks.py` |

L3 の上限は、2025年版（2011〜2022年度）で見た項目ごとの前年度比の最大×1.5（気温は差）。2026年版の値は上限づくりに使っていません。

## 主な結果（各200回、seed 260）
| 壊れ | L1 | ＋L2 | ＋L3 | ＋L4 |
|---|---|---|---|---|
| K1 空欄 | 100% | 100% | 100% | 100% |
| K2 数字の代わりに記号 | 100% | 100% | 100% | 100% |
| K3 行が二重に入る | 0% | 100% | 100% | 100% |
| K4 行が抜ける | 0% | 100% | 100% | 100% |
| K5 地域コードの打ち間違い | 0% | 100% | 100% | 100% |
| K6 1つの値が10倍（桁ずれ） | 0% | 0% | 94% | 94% |
| K7 1つの値が5%ずれる | 0% | 0% | 7.5% | 21% |
| K8 1年度分の1列が千分の1（単位） | 0% | 0% | 98.5% | 98.5% |
| K9 1年度分の男女の列が入れ替わる | 0% | 0% | 79% | 79% |
| K10 1つの値の符号が逆 | 0% | 0% | 100% | 100% |

- 壊していないファイルで鳴ったのは L3 の2件だけ：保育所等在所児数が、2つの県で2023年度に前年度の4割前後に下がっていた（元の統計の数え方の違いかもしれない：推測）。L1・L2・L4 は0件
- 男女の入れ替え（K9）は合計が変わらないので L4 の「総数＝男＋女」では見つからない。止まった79%は前年度からの変化（L3）による
- L3 の上限の係数を変えると（別の乱数で各200回）：係数1.0で空振り91件・5%のずれ16.5%・10倍97.5%、1.5で空振り2件・3.0%・97.0%、2.0以上で空振り0件・2〜2.5%・92〜95%。上限をゆるめると空振りは減るが、5%のずれはどの係数でも2割未満しか止まらない
- 5%のずれの L3 の割合は、主な結果（7.5%）と係数を変えた試し（係数1.5で3.0%）で違う。どのセルを壊すかの引き方で変わる幅（200回では数%）

## 動かし方
```
pip install -r requirements.txt
cd src && python a260_schema_checks.py    # 2コアで7分ほど
```

## データ
- `data/SSDSE-B-2026.csv`：検査するファイル。`data/SSDSE-B-2025.csv`：L3 の上限をつくるためだけに使う（統計センターの配布ファイルをそのまま、cp932）
- `results/detection_rate.csv`：壊れ×段の止まった割合
- `results/trials.csv`：2,000回の1回ごとの結果
- `results/l3_threshold_tradeoff.csv`：L3 の係数と空振り・止まった割合
- `results/summary.json`：上のまとめと、壊していないファイルで L3 が鳴った2件の中身

## 注意
- 壊れの種類と入れ方は作成者が決めた（各200回、1回に1か所）。実際のファイルでどの壊れがどれくらい起きるかは表していない
- pandera などのライブラリは使わず、同じ考え方のチェックを pandas で書いた
- L4 の規則は作成者が SSDSE-B の項目から選んだ17本。総人口と年齢別の合計は年齢不詳があるので使っていない
- 5%のずれのような小さな誤りは、どの段でもほとんど止まらない。取り込み前のチェックとは別に、前に出した数字との照合（記事259）や、合計の照合が要る
