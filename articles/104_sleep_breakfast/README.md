## もとのリポジトリの説明

以下は、もとのリポジトリ `health-nutrition-survey-japan` の README です（同じリポジトリにあったほかの記事の分も含みます）。

### health-nutrition-survey-japan：厚生労働省「国民健康・栄養調査」で、歩数・睡眠時間・朝食欠食の20年を調べる

厚生労働省「国民健康・栄養調査」の公表表（e-Stat）から、1日の歩数（2003〜2024年）、1日の平均睡眠時間（2009〜2024年の11回分）、朝食欠食率（2003〜2017年）を性・年齢階級別につないだリポジトリです。都道府県別の歩数（2012・2016・2024年）も使っています。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| W1 | 1日の歩数は減ったか。どの年代で減ったか。都道府県の差は誤差より大きいか | 公表の年齢調整値の推移と線形トレンド（2003〜2019年・2003〜2023年、HAC標準誤差）、年齢階級別の期間平均の比較（2003〜05年・2017〜19年・2022〜23年）、都道府県値の全国値からのずれを標準誤差で割った2乗和（Q、自由度46）と年の間の相関 | `src/w1_steps.py` |
| W2 | 睡眠が6時間未満の人は増えたか。どの年代か。朝食を抜く人は年をとっても抜き続けるか | 睡眠時間の区分の割合を年齢構成をそろえて（直接法）比べる、線形トレンド、年齢階級別の期間比較（2009〜11年・2022〜24年）、朝食欠食率の世代の追跡（ある年の年代と10年後の1つ上の年代を比べる） | `src/w2_sleep_breakfast.py` |

#### 主な結果
- **W1**：20歳以上の歩数（年齢調整値）は、男性7,465歩（2003年）→7,162歩（2019年）→6,914歩（2023年）、女性6,757歩→6,105歩→5,922歩。2003〜2019年の傾きは10年あたり男性−221歩（標準誤差44）、女性−265歩（同45）。2019→2022年は男性が7,162→6,790歩と大きく下がった。年代別では、2003〜05年平均→2022〜23年平均で男性20代8,654→7,580歩、男性60代7,351→6,260歩、女性30代7,096→6,272歩と減り、70歳以上は男性5,151→4,987歩、女性4,049→4,211歩でほとんど変わらない。2024年は集計の仕方が変わり（歩数計を1日着けなかった人を除外）、平均7,071歩と高く出たため、前の年とは比べていない。都道府県（20〜64歳、年齢調整）は2012年の男性で兵庫県8,859歩〜宮城県6,439歩と差があり、標本誤差だけでは説明できない大きさ（Q＝285、自由度46）。ただし2012年と2016年の順位の相関は男性0.52、女性0.40にとどまり、2024年の男性はQ＝75と誤差に近い
- **W2**：1日の平均睡眠時間が6時間未満の人の割合（年齢構成をそろえた値）は、男性29.9%（2009年）→38.1%（2019年）→36.7%（2024年）、女性34.6%→40.6%→39.1%。傾きは10年あたり男性＋5.4ポイント（標準誤差0.8）、女性＋4.4ポイント（同1.1）。増えたのは50〜60代で、2009〜11年平均→2022〜24年平均は50代38.7%→50.6%、60代29.6%→40.7%。20代は38.2%→36.1%と増えていない。2022〜24年は女性50代の52%、男性50代の49%が6時間未満。朝食欠食率（2003〜2017年）は男性20代が30%前後で横ばい、男性40代17.0%→25.1%、50代10.8%→17.9%（2003〜05年→2015〜17年）。2003〜07年に40代だった男性は10年後の50代でも17.0%（当時の40代は18.0%）で、欠食の多い世代がそのまま年をとって上の年代の率を押し上げていた

#### 注意
- 2020・2021年は新型コロナの影響で調査をしていません。2019年と2022年の間には2年の空白があります
- 2024年の歩数は「歩数計を1日装着していなかった者」を新たに除外していて、平均が上がり標準偏差が下がっています。年齢調整値の基準人口も令和2年国勢調査に変わりました。前の年とは比べていません
- 2012・2016・2024年は対象地区を増やした大規模調査の年で、表は全国補正値（抽出率などを考慮した値）です。2024年の睡眠時間の割合も全国補正値で、ほかの年は回答者の単純な割合です
- 歩数は対象者が歩数計を着けて記録したもので、100歩未満と5万歩以上を除いています（2012年以降）
- 年齢階級ごとの人数は1年あたり数百人で、特に20代は少なく、年ごとの振れが大きくなります
- 睡眠時間は「ここ1か月間の1日の平均睡眠時間」の自己申告です。2012・2013・2016年は睡眠時間の表がないため使っていません
- 「年齢構成をそろえた値」は、11回分の回答者数を合わせた年齢構成を重みにした直接法の値です
- 都道府県の歩数は1県あたり数十〜百数十人で、95%信頼区間の幅は±1,000歩前後あります。2016年は熊本県が含まれていません
- 朝食欠食率の年次推移表は2017年分までしか取得していないため、2018年以降は分析していません。欠食の定義は「食事をしなかった」「菓子・果物などのみ」「錠剤などのみ」の合計です
- 世代の追跡は、同じ人を追ったものではなく、毎年違う人を調べた結果を生まれた時期でそろえたものです
