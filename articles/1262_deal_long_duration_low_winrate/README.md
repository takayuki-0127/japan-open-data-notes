# 1262 長引いた商談ほど受注率が低いのは、長引いたせいか、もともと決まりにくい商談だからか？（受注の見込み）

商談の記録を決まるまでの日数で分けると、長くかかった商談ほど受注率が低く出ることがあります。これを「長引くと取れなくなる」と読むこともできますが、もともと決まりにくい商談（先方の事情が込み入っている、比べている相手が多いなど）が、決まるのも遅く、取れにくいだけかもしれません。この2つは、日数ごとの受注率の形だけでは見分けられません。**ここでは、作成者が乱数で作った架空の会社の法人向けの商談で、「もともとの違いだけ」「長引いたせいだけ」「両方」の3つの仕組みを置き、日数ごとの受注率、最初の見込みの点で分けたときの差、商談と関係なくでたらめに入る「先方の決裁待ち」（60日）があった商談となかった商談の差が、どれだけ本当の効き目（作成者が置いた、長引いたことで下がる分）に合うかを数えました。違いの強さと長引いたせいの強さを変えた9通り、最初の見込みの点の誤差を変えた4通り、決裁待ちが決まりにくい商談に入りやすいときも確かめました。**

例の会社・商談は架空のもので、実在の会社や商談の記録の数字ではありません。数えたのは商談の記録の読み方だけで、商談の進め方・担当の評価・値引きの助言はしません。

関連する記事：928「「独学の人の合格率」と「講座の人の合格率」は比べられるのか？」は、選んだ人のもとの違いが見かけの差にまざる形を、資格試験で扱っています。1260「受注率を、その期に始まった商談で数えるか、その期に決まった商談で数えるかで、どれだけ違うのか？」と1261「失注した商談の一部が記録に残らないと、受注率はどれだけ高く出るのか？」は、受注率の数え方そのもののずれを扱っています。1259「「確度50%」と付けた商談のうち実際に取れた割合は、まだ決まっていない商談を除いて数えるとどう見えるのか？」は、取れない商談ほど決まるのが遅いと、まだ決まっていない商談を除いた受注の割合が高く出ることを扱っています。この記事は、決まるまでの日数と受注率の関係の読み方に絞ります。

## 主な結果

### 決まるまでの日数ごとの受注率（200回の平均、`results/win_by_days.csv`）
| 決まるまでの日数 | S0 違いだけ | S1 長引いたせいだけ | S2 両方 |
|---|---|---|---|
| 30日以内 | 35.6% | 34.9% | 33.32% |
| 31〜60日 | 25.78% | 28.18% | 27.72% |
| 61〜90日 | 27.52% | 22.59% | 24.95% |
| 91〜180日 | 17.73% | 14.79% | 18.04% |
| 181日以上 | **7.42%** | **4.86%** | 8.06% |
| 全体 | 25.62% | 23.58% | 24.92% |

- 3つの仕組みのどれでも、長くかかった商談ほど受注率が低く出た。30日以内と181日以上の差は、S0で28.18ポイント、S1で30.04ポイント、S2で25.26ポイントだった。S0では長引いても取れる確率は何も変わらないと置いたのに、差の大きさはS1とほぼ同じだった
- S0の61〜90日が31〜60日より高いのは、61〜90日の商談の49.12%が、でたらめに入れた60日の決裁待ちのあった商談だったため（31〜60日では2.89%）。S0では決裁待ちは受注率を変えないので、決まりにくくない商談も長い段に入った

### 3つの見方と本当の効き目（200回の平均、`results/scenario_summary.csv`）
| | ① そのまま（30日以内−181日以上） | ② 最初の見込みの点の5段の中で | ③ 決裁待ちあり−なし（10〜90%の範囲） | 決裁待ちの本当の効き目 |
|---|---|---|---|---|
| S0 違いだけ | 28.18 | 14.31 | **−0.05**（−3.19〜+2.95） | −0.05 |
| S1 長引いたせいだけ | 30.04 | 30.03 | **−10.4**（−13.27〜−7.84） | −10.35 |
| S2 両方 | 25.26 | 20.75 | **−5.12**（−8.27〜−1.91） | −5.21 |

（単位はポイント）

- ①はどの仕組みでも25.26〜30.04ポイントで、①だけでは仕組みを見分けられなかった
- ②は、S0で14.31ポイントに縮んだが0にはならなかった。最初の見込みの点に誤差があるので、同じ段の中にも決まりやすさの違う商談がまざるため。S1では30.03ポイントで①と変わらなかった
- ③は、本当の効き目にほぼ合った（S0で−0.05対−0.05、S1で−10.4対−10.35）。決裁待ちを決まりやすさと関係なくでたらめに入れたので、合うのは作りどおりです。ただし1回（2,000件のうち決裁待ちは約400件）の値は振れ、S0では200回のうち47.0%の回で負に出た。S1では100%、S2では98.0%の回で負だった

## 注意（言えないこと）
- 架空のデータです。決まりやすさの違い、長引いたことで取れる確率が下がる強さ、決裁待ちの長さと入り方は作成者が置いたもので、結果はこれで決まります。③が本当の効き目に合うのは、決裁待ちを決まりやすさと関係なくでたらめに入れたからで、作りどおりです。新しく数えたのは、①と②が仕組みを見分けられない大きさと、決裁待ちが決まりにくい商談に入りやすいと③も外れる大きさです
- 実際の商談で、決まりやすさと関係なくでたらめに入る遅れがあるかは分かりません。この記事では、そのような遅れがあると置いたときの数え方だけを扱いました
- 決まりやすさは1つの値で置き、担当や商談の中身の違いは入れていません。担当どうしを比べるものではありません
- 実在の会社の商談の受注率や、商談の進め方の良し悪しを示すものではありません
