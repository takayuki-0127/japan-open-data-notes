# F249 レイアウト仕様（3ページ＋モバイル）

サンプルマート（架空）・合成データ。キャンバスは 16:9（1280×720）。位置は左上を (0,0) とした px。
同じ設計の HTML 版が `../dashboard/dashboard.html`（?p=1〜3）。Power BI ではこの仕様どおりに置く（自動では作っていない）。

## 共通の決めごと
- **3秒の決めごと**：左上に KGI、その右に KPI ツリーの順でカード。いちばん見せたい数字ほど左上・大きく。
- **色は「偶然の幅の外」だけ**：条件付き書式 → フォントの色 → 書式スタイル「フィールド値」→ `色_*` メジャー。幅の内は灰（#A3A29D）、外は良い青（#2A78D6）・悪い橙（#EB6834）・物価の紫（#5B4FC4）。
- 大きい数字は FY2025（12か月）、カードの下の段に当月（3月）。月の数字は幅が大きい（全社・月の売上 ±1.3%、営業利益 ±11.5%）。
- 各ページの下に「架空・合成データ」「既存店の定義」「偶然の幅の意味」を1行で。
- フォントの最小は 10pt 相当（HTML 版の確認で、1024×640 の画面では 7px 台まで縮む → ノートでは「ページ幅に合わせる」にする）。

## スライサー（全ページ共通、同期）
| 置き場所 | フィールド | 既定 |
|---|---|---|
| 右上 (1000,10,260,30) | dim_date[fy_label] | FY2025 |
| その下 (1000,44,260,30) | dim_date[ym]（当月のカード用、ページの視覚エフェクトの「下の段」だけに効かせる） | 2026-03 |

当月の段は、カードを2つ重ねる（上：FY、下：当月）か、メジャーを `CALCULATE([x], 'dim_date'[ym] = "2026-03")` で固定した版を作る。後者が簡単（このときは「幅の粒度」が月になる）。
