# 1201 長く開いていない人に送るのをやめて開封率が上がったのは、メールが良くなったからなのか？（メール配信）

お知らせのメールで、「最後に開封が記録されてから180日たった人」に送るのをやめると、開封率（開いた通数 ÷ 送った通数）はすぐに上がります。開かない人を分母から外したのだから、上がるのは作りどおりです。けれども、上がった開封率を前の月と並べると、「件名や中身が良くなった」と読みたくなります。**ここでは、作成者が乱数で作った架空の店の会員2万人（週1通、52週）で、メールの良さ（1通を開く確率）を変えない・悪くする・良くするの3通りを置き、送る相手を絞ったあとの12週の開封率が、どれだけ「良くなった」ように見えるかを数えました。止めた人のうち、まだ読んでいた人・開封が記録されないだけの人がどれだけいたか、クリックの合計がどれだけ減ったかもあわせて数え、置き方を変えた27通りで確かめました。**

例の店・会員・メールは作成者が置いた架空のもので、実在のメール配信サービス・メールソフト・会社の数字ではありません。値引きや価格の訴求など、メールの中身の良し悪しは扱っていません。

関連する記事：573「会員の「休眠」を最終購入から90日で切るか180日で切るかで、休眠の人数と「復活」の割合はどれだけ変わるのか」は、区切りの日数で休眠の人数と戻った割合が変わることを数えています。525「メールの開封率は、画像の自動読み込みによる「見かけの開封」を除くと何ポイント下がるのか？」は開封の数えすぎを扱っていて、この記事では逆に、開いても記録されない人を置きました。同じ企画の 1200「配信停止の少ない月は、読者が満足していた月なのか、もう読んでいない人が多い月なのか？」は、読んでいない人が増えると配信停止の率が下がることを数えています。同じ企画の 1198「届かなかったアドレスを分母に残すか除くかで、開封率はどう変わるのか？」は、戻ったアドレスや、届いても読まれないアドレスを分母に残すか除くかで、開封率が変わることを扱っています。同じ企画の 1203「登録して間もない人ほどよく開くとき、全体の開封率の下がり方は、読者の入れかわりでどれだけ説明できるのか？」は、読者の入れかわり（登録してからの週数の内訳）で全体の開封率が動くことを扱っています。この記事は、区切りで送り先を絞ったあとの開封率の読み方に絞ります。

## 主な結果

### メールの良さを変えずに、180日の区切りで送る相手を絞ると（2万人、`results/a1201_main.json` の base_180days）
| | 記録された開封率 |
|---|---|
| 絞る前の12週（41〜52週目、全員） | 15.2% |
| 絞ったあとの12週（送り続けた人） | **23.16%** |
| 同じ12週に全員に送り続けた場合 | 14.91% |

- **メールの良さを変えていないのに、開封率は15.2%から23.16%へ+7.9619ポイント上がった**。そのうち+8.2544ポイントは送る相手を絞った分（作りどおり）で、全員に送り続けた場合の変化は−0.2925ポイント（読まなくなる人が少しずつ増える分）だった
- 止めたのは会員の38.88%で、送る通数は61.11%になった
- 送り続けた人だけで前後を比べると、絞る前の24.87%から23.16%へ−1.7106ポイントと、変えていないのに下がって見えた。送り続けた人は「最近開いた人」として選ばれているので、絞る前の12週の開封率が高めに出るため
- 止める人の10%に送り続けて全員に送った場合を見積もると15.02%で、前の15.2%からの変化は−0.1843ポイントと、全員に送り続けた場合の変化（−0.2925ポイント）に近かった

### メールを悪くしても（1通を開く確率を0.9倍、`results/a1201_main.json` の worse_mail_0_9）
- 全員に送り続けた場合の開封率は−1.5879ポイント下がったのに、**絞ったあとの開封率は前より+5.7285ポイント上がって見えた**
- 送り続けた人だけで前後を比べると−3.7221ポイント、止める人の10%に送り続けて見積もると−1.3504ポイントだった

### 止めた人の中身と、失った分（180日の区切り、基本）
| | 値 |
|---|---|
| 止めた人のうち、区切りの時点で読んでいる人 | 19.27% |
| 止めた人のうち、開いても記録されない人（会員全体では14.98%） | 26.3% |
| 止めた人のうち、その後12週に本当は開いていた人（送り続けた場合） | 23.15% |
| 止めた人のうち、その後12週にクリックしていた人（送り続けた場合） | 5.16% |
| 本当に開いた通数の合計（送り続けた場合を100%） | 91.07% |
| クリックの合計（同上） | **90.45%** |

- 開封率は上がったが、**クリックの合計は送り続けた場合の90.45%に減った**。記録された開封の合計は94.95%で、本当に開いた通数の合計（91.07%）より減り方が小さく見えた。止めた人には、開いても記録されない人が多く入っていたため

### 区切りの日数（`results/by_cutoff.csv`）
| 区切り | 止めた人 | 開封率の上がり | 送り続けた人だけの前後 | クリックの合計 |
|---|---|---|---|---|
| 90日 | 49.44% | **+11.9282ポイント** | −2.9371ポイント | 85.53% |
| 180日 | 38.88% | +7.9619ポイント | −1.7106ポイント | 90.45% |
| 365日 | 26.33% | +4.4369ポイント | −0.9978ポイント | 94.59% |

- 区切りを短くするほど開封率は上がり、クリックの合計は減った。メールの良さはどれも変えていない

### 確かめ：置き方を変えた27通り（各1万人、`results/grid.csv`）
- 絞ったあとの開封率の上がりは+2.3852〜+10.8611ポイントで、27通りすべてで上がった。**メールを0.9倍に悪くした9通りでも、すべてで+2.3852〜+6.685ポイント上がって見えた**
- 全員に送り続けた場合の変化は、0.9倍で−2.07〜−1.35ポイント、1倍で−1.0533〜+0.6492ポイント、1.1倍で+0.45〜+2.5583ポイント。止める人の10%に送り続けて見積もった変化は、それぞれ−2.1879〜−1.1151、−0.8496〜+0.8386、+0.2525〜+2.0738ポイントで、ずれは最大0.568ポイントだった
- 送り続けた人だけの前後は、メールの良さを変えない9通りすべてで下がって見えた（−2.5544〜−0.474ポイント）
- クリックの合計は送り続けた場合の85.45〜97.07%。止めた人のうち区切りの時点で読んでいる人は6.75〜46.9%で、戻る確率を大きく置くほど多かった

## 動かし方

```
pip install -r requirements.txt

```
数秒で終わります。`data/members.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp）
- 図3枚を開き、日本語・重なり・軸（棒グラフの軸は0から）を確かめた

## データ
- `data/members.csv`：架空の会員2万人（読んでいるときの開く確率・区切りの時点で読んでいるか・開封が記録されない人か・最後に記録されてからの週・止めたか）
- `results/a1201_main.json`：主な結果すべて
- `results/weekly_base.csv`：週ごとの開封率・クリック（基本）
- `results/by_cutoff.csv`：区切りの日数ごと
- `results/grid.csv`：27通りの確かめ

## 注意（言えないこと）
- 架空のデータです。読まなくなる速さ・戻る確率・開く確率・記録されない人の割合は作成者が置いたもので、結果はこれで決まります。開封率の上がりは27通りで+2.3852〜+10.8611ポイントに分かれました
- 新しい会員は入れていません。送る相手を絞ったことで届く先の評価が変わる、といったメールの外の動きも入れていません
- 止めた人の分は、送り続けた場合と比べて数えました。止めた人に送らないことの良し悪し（送る費用、読者の受け止め）は扱っていません。どの区切りがよいかも言えません
