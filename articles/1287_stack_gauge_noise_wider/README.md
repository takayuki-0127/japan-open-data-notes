# 1287 部品の寸法の記録に測りのばらつきがまざっていると、記録から見込んだ組み立て品の幅は、本当の幅よりどれだけ広く出るのか？（寸法の積み上げ）

部品をいくつか重ねる組み立て品では、部品ごとの寸法の記録から標準偏差を出し、二乗で足して組み立て品の幅（ばらつき）を見込むことがあります。けれども、記録の値は「本当の寸法＋測りのばらつき」です。記録の標準偏差には測りのばらつきが入り、それが部品の数だけ足されるので、見込んだ幅は本当の幅より広く出ます。**ここでは、作成者が置いた架空の引き出しの部品4つ（部品ごとの本当のばらつきと測りのばらつきを作成者が置き、乱数で記録を作ったもの）で、記録から見込んだ組み立て品の幅が本当の幅の何倍になるか、外れの割合の見込みがどれだけ多く出るか、同じ部品を2回測って測りのばらつきを見込んで引くとどこまで戻るかを数えました。測りのばらつき・そのうち日ごとのずれの割合・部品の数を変えた36通りで確かめました。**

例の引き出し・部品・測りはすべて架空のもので、実在の会社・製品・測定器の数字ではありません。品質の判断や購入の助言はしていません。

関連する記事：911「検査で『不良』と出た品物は、本当に不良なのか？」は、測りの誤差で規格の端の近くの判定が入れかわり、「不良」の一部が良品になることを扱っています。393「説明する側の数字に測り間違いがあると、回帰の係数はどれだけ小さく出るのか？」と 610「説明変数に測りまちがいがあると、回帰の係数はどれだけ小さく出るのか？」は、測りまちがいが係数を小さく見せることを扱っています。917「寸法の平均が規格の中でも、外れる品物は何%あるのか？」は、部品1つの寸法で外れる品物の割合を扱っています。1292「部品ごとに20個だけ測った標準偏差から組み立て品の幅を見込むと、本当の幅より狭く見込んでしまう回はどれだけあるのか？」は、少ない個数で出した標準偏差の振れで幅を狭く見込む回を数えていて、この記事とは向きが逆です。1284「同じ日に作った部品どうしで寸法のずれがそろうとき、関係なしと見て二乗で足した幅は、実際の幅よりどれだけ狭く出るのか？」は、作った日のずれ（部品そのもののずれ）がそろう場合を扱っています。この記事の「日ごとのずれ」は測りの側のずれです。1286「検査で規格外を除いた部品だけを組むと、組み立て品のばらつきは、除く前の部品の標準偏差から見込んだ幅より狭くなるのか、それとも思ったほど狭くならないのか？」は、検査で規格外を除いた部品で組むときの幅を扱い、検査の測りのばらつきで規格の外の部品が通る場合も数えています。1288「部品を測って大きいものどうし・小さいものどうしを組み合わせて組むと、外れる組み立て品は減っても、相手がなくて余る部品はどれだけ出るのか？」は、部品を測って大きさの区分どうしで組むときの余る部品を扱っていて、測りは誤りなくできると置いています。この記事は、1つ1つの判定ではなく、測りのばらつきが記録の標準偏差を広げ、積み上げた見込みが広く出る点に絞ります。

## 主な結果

### 基本の置き方（部品4つ・測りのばらつき0.03mm、2,000回の中央値。`results/examples.csv`・`results/a1287_main.json`）
| 見込み方 | 日ごとのずれ0% | 日ごとのずれ60% |
|---|---|---|
| 本当の幅（置いた値） | 0.09274mm | 0.09274mm |
| 組み立て品を1回測った記録の幅（式） | 0.09747mm（1.051倍） | 0.09747mm（1.051倍） |
| 部品の記録から二乗で足して見込んだ幅 | 0.11023mm（**1.1887倍**） | 0.10998mm（1.1859倍） |
| 同じ日の2回測りで引いた | 0.09272mm（0.9999倍） | 0.10335mm（**1.1144倍**） |
| 別の日の2回測りで引いた | 0.09286mm（1.0013倍） | 0.09251mm（0.9976倍） |

- **部品の記録から見込んだ幅は、本当の幅の1.1887倍だった**（10〜90%の範囲1.1483〜1.2317倍、2,000回すべてで本当の幅より広い）。式 √(1＋部品の数×測りの分散÷本当の分散の合計) の1.1911倍とほぼ同じ（**式どおり**）
- 部品ごとに見ると、記録の標準偏差は本当の値の1.118倍（C 0.06mm）〜1.4142倍（D 0.03mm）で、本当のばらつきが小さい部品ほど広がりが大きい（式どおり、`results/per_part_base.csv`）
- **組み立て品の外れの割合（±0.25mm）は、本当は0.702%（100万個で0.697%）なのに、記録から見込むと2.334%と多く出た**
- 組み立て品をそのまま測った記録には測りのばらつきが1回分しか入らないので1.051倍。部品の記録から見込んだ幅（1.1887倍）のほうが広く、2つを比べると「組んだもののほうがばらつきが小さい」ように見える
- 2回測りで測りのばらつきを見込んで引くと、日ごとのずれがないときは0.9999倍（10〜90%で0.9216〜1.0704倍）に戻った。外れの割合の見込みも0.701%
- **測りのばらつきの6割が日ごとのずれのとき、同じ日の2回測りで引いても1.1144倍が残った**（2,000回のうち99.75%で本当の幅より広い）。同じ日の2回の差には日ごとのずれが出てこないため（作りどおり）。外れの割合の見込みは1.556%。部品ごとに別の日に2回測って引くと0.9976倍に戻った

### 確かめ：36通り（`results/grid.csv`、各1,000回）
- **記録から見込んだ幅は、36通りで本当の幅の1.0202〜1.4862倍**（測りのばらつき0.01mmでは1.0202〜1.0234倍、0.05mmでは1.4585〜1.4862倍）。式との差は0.0166以内
- 倍率は部品の数ではほとんど変わらなかった。部品の数を増やすと、測りのばらつきも本当のばらつきも同じ割合で足されるため（式どおり。部品4つと8つは同じ部品の組み合わせなので式が同じ）
- 同じ日の2回測りで引いたとき、日ごとのずれ0%では0.9976〜1.0189倍、60%では1.0107〜1.3008倍が残った
- 別の日の2回測りで引くと、中央値は0.9837〜1.0271倍に戻った。ただし測りのばらつきが本当のばらつきに比べて大きいと、引いた見込みの散らばりが広く、部品2つ・測りのばらつき0.05mm・日ごとのずれ60%では10〜90%の範囲が0.5939〜1.2405倍だった
- 組み立て品をそのまま測った記録の幅は、36通りで1.0029〜1.2688倍

## データ
- `data/records_base_one_trial.csv`：基本の置き方の1回分の記録（部品A〜D各200個。part・no・day（測った日）・true_mm（本当の寸法）・record_mm（記録の値））
- `results/a1287_main.json`：主な結果（`true_check`・`base`（share0・share60）・`grid_range`）。raw は記録そのまま、corr_same_day は同じ日の2回測りで引いたもの、corr_diff_day は別の日の2回測りで引いたもの
- `results/examples.csv`：基本の置き方の5つの見込み方（asm_sd_mm は組み立て品の標準偏差、ratio_to_true は本当の幅との比、pred_out_pct は外れの割合の見込み）
- `results/per_part_base.csv`：部品ごとの本当の標準偏差と記録の標準偏差（1回分と式）
- `results/grid.csv`：確かめの36通り（*_median_ratio・*_p10・*_p90 は本当の幅との比の中央値と10・90%点、measured_asm_ratio は組み立て品をそのまま測った記録の幅）

## 注意（言えないこと）
- 架空のデータです。部品ごとの本当のばらつき、測りのばらつき、日ごとのずれの割合、記録の数、2回測りの個数は作成者が置いたもので、結果はこれで決まります。とくに倍率は「測りのばらつき÷部品の本当のばらつき」でほぼ決まります（式どおり）
- 測りのばらつきは、本当の寸法の大きさに関係なく同じ大きさで足されると置きました。大きい寸法ほど測りのばらつきが大きくなる場合や、測る人で向きがそろう場合は扱っていません
- 部品どうしの寸法は互いに関係なく決まると置きました。同じ型・同じ日の部品どうしのずれがそろう場合は扱っていません（1284 で扱っています）
- 2回測りで引く見込み方は、作成者が置いた1つのやり方です。測りのばらつきを調べるほかの組み方や、何個・何回測ればよいかは扱っていません
- 実在の測定器・測り方の決まりを表すものではありません。品質の判断や測定器の選び方の助言をする記事ではありません
