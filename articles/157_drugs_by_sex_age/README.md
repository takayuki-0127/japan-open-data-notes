# 157 よく出される飲み薬は、性別と年齢でどう違うか：第10回NDBオープンデータ（2023年度）

厚生労働省「第10回NDBオープンデータ」（診療年月 2023年4月〜2024年3月）の「内服 外来（院外）性年齢別薬効分類別数量」から、錠・カプセルの数量を薬効分類ごと・性別と年齢ごとに集計したフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A157 | よく出される飲み薬の種類（薬効分類）と品目は何か。性別と年齢でどう違うか | 薬効分類別の数量（錠・カプセル）を性×年齢5区分に集計し、区分ごとの構成比、女性の割合、数量上位100品目を比較 | `src/a157_drugs.py` |

## 主な結果
- 外来の院外処方の錠・カプセルは1年で101.2億錠。女性が54.0%、65歳以上が60.6%（75歳以上だけで39.9%）
- 薬効分類で多いのは、消化性潰瘍用剤71.7億錠、糖尿病用剤69.0億錠、血圧降下剤66.2億錠、高脂血症用剤61.4億錠、血管拡張剤57.0億錠
- 0〜14歳は男女とも「その他のアレルギー用薬」が4割前後（男40.3%、女36.3%）。40〜74歳の男性は糖尿病用剤（10.6%・11.9%）がいちばん多く、75歳以上の女性は消化性潰瘍用剤（8.7%）
- 女性の割合は、ビタミンＡ及びＤ剤88%、カルシウム剤88%、混合ビタミン剤78%、甲状腺ホルモン剤74%が高く、痛風治療剤15%、泌尿生殖器官用薬（前立腺の薬などを含む）20%、糖尿病用剤39%が低い
- 品目の1位は酸化マグネシウムの錠剤（マグミット錠330mg 12.6億錠）。上位100品目で全体の31.3%

```bash
pip install -r requirements.txt

```

## データ
| ファイル | 中身 |
|---|---|
| data/class_by_sex_age.csv | 薬効分類（3桁）ごとの数量（千錠）。合計と、男女×年齢5区分（0〜14・15〜39・40〜64・65〜74・75歳以上） |
| data/top100_tablets.csv | 数量上位100品目（錠・カプセル）：順位、薬効分類、医薬品名、単位、薬価、後発品区分（元表の値のまま、分析には使っていない）、数量（千錠） |

元の Excel（https://www.mhlw.go.jp/content/12400000/001495390.xlsx）をブラウザで読み、単位が「錠」「カプセル」の品目だけを足し上げました。元表の5歳刻みを5区分にまとめています。

## 注意
- 外来の院外処方（薬局で受け取る薬）だけです。院内処方や入院中の薬は入りません
- 錠・カプセルの数で比べているため、散剤（g）や液剤（mL）は入っていません。1日に何錠飲むかは薬によって違うので、数量の多さは「処方の多さ」と同じではありません
- 元表で1,000未満は「-」と表示されるため、0として足しています
- 人口あたりではなく数量そのものです。高齢者の数量が多いのは、人数と1人あたりの量の両方によります
- 「女性の割合」は数量の割合で、使っている人の割合ではありません
