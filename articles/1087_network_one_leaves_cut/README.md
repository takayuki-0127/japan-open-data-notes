# 1087 1人が抜けると、全体のつながりはどれだけ切れるのか？（つながり）

社内のやり取りから1人が抜けると（異動などで）、そのぶんつながりが切れます。「どれだけ切れたか」は、①その人のつながりの数、②つながりをたどっても行き来できなくなった2人の組、③遠回りになった分、のどれで数えるかで大きさが違います。また「つながりの多い人が抜けると、いちばん切れる」と考えがちですが、行き来できなくなる組を作るのは、部署と部署をつなぐ位置にいる人です。**ここでは、作成者が乱数で作った架空の会社（社員300人、10部署×30人。部署の中のやり取りのしやすさと、部署をまたぐやり取りの数・集まり方を作成者が置いたもの）で、社員を1人ずつ抜いて3つの物差しで数え、いちばん切る人がつながりのいちばん多い人かを60社で数えました。部署をまたぐつながりの数と集まり方を変えた6通りの確かめも行いました。**

例の会社は架空のもので、実在の会社の名前は使っていません。社員は番号だけで、個人を表すものではありません。抜ける理由は扱わず、「その人がやり取りから外れた」とだけ置いています。

関連する記事：同じ企画の 1079「「中心の人」は、中心の測り方で入れかわるのか？」は中心の人の測り方の違いを、1084「少ないつながりでも、たどれば何人目で全員に届くのか？」はたどって届くまでの人数を扱います。1088「新しい道具の使い始めは、まわりの何人が使えば広がるのか？」は、部署をまたぐつながりの少なさが広がりを止めることを扱っています。この記事は、1人が抜けたときの切れ方の数え方に絞ります。

## 主な結果

### 1社（社員300人、つながり667本、うち部署をまたぐ30本、`data/removal_one_company.csv`）
| 物差し | 300人の平均 | いちばん大きい人 |
|---|---|---|
| ① 切れたつながりの数（全体の%） | 0.6667% | 1.949% |
| ② 行き来できなくなった組（全体の%） | 0.0819% | **17.315%** |
| ③ 全体の近さの下がり方 | 0.228% | **11.88%** |

- ①の平均0.6667%は、2÷300人の式どおりです（つながり1本は2人に数えられるため）
- ②で組を切ったのは300人のうち12人だけで、**96%の人は抜けても行き来できない組を作らなかった**。部署の中のつながりが多く、ほかの道が残るため
- ②がいちばん大きかった人（P052、17.315%）は、つながりの数9人で多いほうから4番目だった。この人は、自分の部署から外へのつながり2本を2本とも持っていて、抜けると部署の残り29人がほかの266人と行き来できなくなった。つながりのいちばん多い人（P248、13人）が抜けても、②は0%、③は4.8301%だった
- ③は、媒介中心性と順位がよくそろった（順位相関0.9387。つながりの数とは0.6311）。②とつながりの数の順位相関は0.0852で、ほとんど関係がなかった
- ③が0.5%未満の人は88.6667%だった

### 60社で数えると（`results/companies_60.csv`）
| | 値 |
|---|---|
| 抜けても②が0%の人の割合 | 95.5222% |
| ②の300人の平均 | 0.0785% |
| いちばん切る人の②（1社の平均） | **7.9885%**（1割の会社は0.6664%以下、1割の会社は17.9794%以上） |
| 1人で全体の組の5%超を切る人がいる会社 | 41.6667% |
| いちばん切る人が、つながりのいちばん多い人だった会社 | **3.3333%** |
| いちばん切る人が、媒介中心性のいちばん大きい人だった会社 | 21.6667% |
| つながりのいちばん多い人が抜けたときの②（平均） | 0.3848% |
| 媒介中心性のいちばん大きい人が抜けたときの②（平均） | 4.1323% |
| いちばん切る人の、つながりの数の順位（中央値） | 43.5番目 |

- **いちばん切る人は、つながりの数では平均6.3333人で、つながりのいちばん多い人（平均11.5人）ではなかった**。つながりの数で上から43.5番目（中央値）だった
- 媒介中心性のいちばん大きい人は、つながりの数よりは当たったが、いちばん切る人だったのは21.6667%にとどまった。媒介中心性は遠回りも含めた道の上にいる割合で、ほかに道がない（その人がいないと届かない）かどうかとは違うため

| 15本 | 0.5 | 18.57% | 94.36% | 86.67% | 3.33% | 44.5番目 |
| 15本 | 2.0 | 22.17% | 94.23% | 96.67% | 6.67% | 48.5番目 |
| 30本 | 0.5 | 3.21% | 96.01% | 13.33% | 0% | 75番目 |
| 30本 | 2.0 | 10.37% | 95.22% | 50% | 6.67% | 50.5番目 |

- いちばん切る人の②は、部署をまたぐつながりの数と集まり方で0.99〜22.17%と大きく動いた。またぐつながりが少ないほど、また一部の人に集まるほど、1人で大きく切れる
- ②が0%の人の割合は、6通りとも94.23〜96.98%だった

## 動かし方
```

```

## 注意（言えないこと）
- 架空のデータです。部署の大きさ、部署の中のやり取りのしやすさ、部署をまたぐつながりの数と集まり方は作成者が置いたもので、結果はこれで決まります。いちばん切る人の②は、置き方で0.99〜22.17%と動きました
- つながりは「やり取りがあるかないか」だけで数え、やり取りの多さ・向きは入れていません。抜けた人の仕事をほかの人が引き継いで新しいつながりができることも入れていません
- ③の「近さ」は、間にはさむ人数だけで数えた1つの物差しです。仕事の進みやすさそのものではありません
- 実在の会社の組織を表すものではなく、誰を異動させるべきかも言えません。この記事は、1人が抜けたときの切れ方が物差しでどう違うかを数えただけです
