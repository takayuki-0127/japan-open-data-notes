# F106 同じ県の会社は、同じように閉鎖しやすいのか？ フレイル（共有ランダム効果）つきの生存分析

看板記事 F106。note：「同じ県の会社は、同じように閉鎖しやすいのか？…」（下書き）

## 問い
F28・F79 では、法人は1社ずつ独立に閉鎖すると仮定してきた。でも、同じ県（同じ市区町村）の法人には、地域の景気・登記の慣行・法務局の運用など、共通の事情がありそう。
- 種別・地域区分・設立年をそろえたうえで、閉鎖しやすさは県ごとにどれだけ違うか
- そのばらつきは、県・市区町村・地方のどの単位で大きいか
- ばらつきを無視すると、これまでの記事の倍率（ハザード比）や区間はどう変わるか

## データ
- F28・F79 と同じ。国税庁「法人番号公表サイト」全件データ（2026年9月30日更新）から、2015年11月1日以降に法人番号が指定された株式会社・合同会社・その他の設立登記法人（一般社団法人・NPO法人など）152.9万法人。
- 閉鎖＝登記記録の閉鎖のうち「清算の結了等」(01) と「登記官による閉鎖」(21)。84,165件。合併による解散(11) は打ち切り（原因別ハザード）。
- 観察は 2026-09-30 まで。リスク年は合計 772万年。
- グループ：47都道府県、1,771市区町村（政令市の区は市にまとめ、東京23区は区ごと）、6地方。
- 法人名・法人番号・住所は使わず、公開もしていない。県・市区町村の名前は記事と図に出さない（`results/pref_eb.csv` の県コードは再現用）。

## 手法
| 段階 | 手法 |
|---|---|
| モデル | 区分化指数モデル（経過年ごとの階段状の基準ハザード＝Cox と同じく形を決めない）を、グループ×種別×地域区分×設立年×経過年のセル（29.5万）の事象数とリスク年で最尤推定 |
| フレイル | 閉鎖のハザード λ = z_g · λ0(t) · exp(xβ)。z_g はグループ共通の倍率。ガンマ（平均1・分散θ、周辺尤度は閉じた形）と対数正規（適応型ガウス–エルミート求積）の2通り。自作の実装（`src/frailty.py`） |
| 比べるもの | 独立を仮定したモデル（通常のSE・県で束ねた頑健SE）、県の固定効果（設計の「取れないときの代替」） |
| 大きさの読み方 | θ（z の分散）、z の90%範囲、Kendall のτ＝θ/(θ+2)（同じグループの2社の閉鎖時刻の連動）、尤度比検定（境界なので χ²(1) の半分） |
| 分け方 | 県・地方・市区町村のフレイル、県の固定効果を入れた上での市区町村のフレイル（県の中の違い） |
| 個別の倍率 | 経験ベイズ（z の事後平均）で、県・市区町村の「実績÷期待」を縮める |
| 安定性 | 設立年の前半（2015〜19）と後半（2020〜26）、株式会社とそれ以外で、県の倍率の相関 |
| シミュレーション | 本当のθを決めてデータを作り直し、θの取り戻し・θ=0 での誤検出・東京23区の区間のカバー率を確かめる（各100回） |

## 主な結果
- **県のばらつきははっきりある**：種別・地域区分・設立年をそろえても、県のフレイルの分散は θ=0.027（95%区間 0.017〜0.041）。標準偏差 0.16 で、県の90%は平均の 0.75〜1.28 倍に入る。尤度比検定は 1,321（p&lt;10⁻²⁰⁰）。対数正規でも標準偏差 0.16 で同じ。
- **ただし2社の連動はごく弱い**：Kendall のτは 0.013。同じ県の2社を取り出しても、閉鎖する時期はほとんど連動していない。データが大きいので「ある」とは言えるが、1社ごとの運命を決めるほどの共通部分ではない。
- **属性ではほとんど説明できない**：設立年だけをそろえたときの θ=0.029 が、種別・地域区分を足しても 0.027。県の差は、株式会社が多い・政令市が多いといった構成の違いではない。
- **単位による違い**：地方（6）0.13、県 0.16、市区町村 0.20（標準偏差）。県の固定効果を入れた上での市区町村の差は 0.12。分散で見ると、市区町村のばらつき（0.041）のうち県の中の違いは 0.015 で、残りの6割ほどは県の単位でそろっている。
- **倍率への影響**：
  - 種別の倍率は変わらない：合同会社 1.46→1.48、一般社団・NPOなど 1.63→1.64。
  - 東京23区は 1.57→1.43、政令市は 1.11→1.14。東京23区の差の一部は「東京都全体」の高さだった。
  - 東京23区の SE は、ガンマ・フレイルで独立モデルの 2.7倍。県の固定効果とほぼ同じ（1.42、95%区間 1.36〜1.49）。
- **県で束ねた頑健SE の落とし穴**：合同会社の SE は 5.7倍、一般社団・NPOなどは 11倍に広がった。共有フレイルでは広がらないので、原因は「県ごとに種別の差が違う」こと。県×種別の交互作用は尤度比 791（自由度94）で、県の中の合同会社の倍率は県によって 1.26〜1.75（80%範囲）、一般社団・NPOなどは 1.17〜2.41。
- **県の倍率**（経験ベイズ）：0.74〜1.41。95%区間が1を含まない県は32。地方の平均は 中部 1.16、北海道・東北 1.05、関東 1.01、中国・四国 0.98、近畿 0.95、九州・沖縄 0.85。
- **安定性**：設立年の前半と後半（どちらも設立後5年まで）で、県の倍率の相関は 0.79。株式会社とそれ以外でも 0.78。市区町村は全体で 0.36、期待30件以上の122市区町村に絞ると 0.63。
- **小さい市区町村は縮める**：期待10件未満の1,058市区町村では、実績÷期待の対数の標準偏差 1.51 が経験ベイズで 0.08 になる。0件の市区町村が172ある。期待100件以上では 0.19→0.17 とほぼそのまま。

## 言えないこと
1. 「閉鎖」は登記の閉鎖で、事業をやめたことと同じではない（F28 と同じ）。県の倍率が高いのは、事業をやめたときに清算の登記まで済ませる法人が多い、ということかもしれない。倍率の高い・低いを、地域の経済の良し悪しとして読んではいけない。
2. 県の差の理由（景気、業種の構成、税理士・司法書士の慣行、法務局の運用など）は、業種も規模もないこのデータでは分からない。地方ごとに傾向がそろうことの理由も同じ（推測の域を出ない）。
3. τ が小さいのは「同じ県の2社の閉鎖時期がほとんど連動しない」という意味で、県の差が小さいという意味ではない。両者を混ぜて読まない。
4. 共有フレイルは「県全体を一律に何倍か」だけを表す。種別の差が県によって違うこと（県×種別）は、このモデルには入っていない。
5. 対象は2015年11月以降に設立された法人で、最長でも約11年しか追えていない。
6. フレイルの分布（ガンマ・対数正規）は仮定。今回は2つの答えがほぼ同じだったが、ほかの分布で同じになる保証はない。
