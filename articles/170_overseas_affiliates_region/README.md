# 170 日本企業の海外現地法人は、中国からどこへ移ったのか

経済産業省「海外事業活動基本調査」の現地法人の時系列データ（第55回調査、2015〜2024年度）から、地域別の現地法人数・常時従業者数・売上高を取り出し、中国（香港を含む）とほかの地域の構成の変化を調べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A170 | 日本企業の海外現地法人は、中国からどこへ移ったのか | 地域別の法人数・常時従業者数・売上高の推移と、全地域に占める割合の2015→2024年度の変化 | `src/a170_region.py` |

## 主な結果
- 現地法人数（全地域）は 2015年度 25,233社 → 2024年度 25,745社とほぼ横ばい
- 中国（香港を含む）は 7,900社 → 7,123社（割合 31.3% → 27.7%）、ASEAN10は 6,563社 → 7,960社（26.0% → 30.9%）。2021年度にASEAN10が中国を上回り、2024年度まで続く
- 常時従業者数は中国が161.7万人 → 96.9万人（−40.1%）。ASEAN10は193.9万人 → 192.7万人（−0.6%）とほぼ横ばいで、中国で減った分がASEAN10で増えたわけではない
- 従業者数の割合は中国 29.0% → 18.8%、ASEAN10 34.8% → 37.4%、北米 12.3% → 14.3%、中南米 4.3% → 7.1%
- 売上高の割合は中国 18.8% → 14.3%、ASEAN10 19.4% → 20.3%、北米 34.3% → 35.7%

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a170_region.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/affiliates_by_region_fy2015_2024.csv | 地域別の現地法人数（社）・常時従業者数（人）・売上高（百万円）、2015〜2024年度。metric=firms/employees/sales_mjpy |

e-Stat「海外事業活動基本調査」第55回調査結果（2024年度実績）の「4. 現地法人の時系列データ」（statInfId 000040458710）の ④-01-2、④-02-2、④-03-2 シート。

## 注意
- 「中国」は中国本土と香港の合計。中国本土だけでは 6,670社 → 6,016社
- 調査に回答した現地法人の集計で、回収率の変化が数に影響する
- EUは2020年度から英国を含まない（2019年度 2,540社 → 2020年度 2,047社）。この分析では「欧州」を使った
- 個々の企業が中国から別の地域へ移ったかどうか（企業単位の移転）は、この集計からは分からない
- 元の Excel は Web ブラウザ上で読み取り、必要な値を CSV に書き写した
