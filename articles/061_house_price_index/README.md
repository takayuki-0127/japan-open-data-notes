## もとのリポジトリの説明

以下は、もとのリポジトリ `real-estate-prices-japan` の README です（同じリポジトリにあったほかの記事の分も含みます）。

### real-estate-prices-japan：国交省「不動産情報ライブラリ」の全国214万件で、中古マンション・戸建ての値上がりと「成約価格と取引価格の差」を調べる

国土交通省「不動産情報ライブラリ」の不動産価格（取引価格・成約価格）情報、全都道府県・2021年第1四半期〜2025年第4四半期（2,138,873件）を使ったリポジトリです。分析には中古マンション等と宅地（土地と建物）の約128万件を使いました。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| R1 | 品質をそろえると、中古マンション・戸建ての価格は圏域ごとにどれだけ上がったか | 時間ダミー法のヘドニック価格指数（市区町村固定効果、築年・面積・駅距離・構造・間取りを調整、市区町村クラスター頑健標準誤差）、取引価格と成約価格の2本で推定 | `src/r1_index.py` |
| R2 | 同じ市区町村・同じ四半期・同じ条件なら、成約価格（レインズ）と取引価格（登記＋アンケート）はどれだけ違うか | 市区町村×四半期の固定効果つき回帰（圏域別・年別・市区町村の価格水準5分位別）、前期比の相互相関 | `src/r2_gap.py` |

#### 主な結果
- **R1**：2021年平均→2025年平均の品質調整済みの上昇率（取引価格）は、中古マンションが東京圏+30%、大阪圏+29%、地方4市（札幌・仙台・広島・福岡）+31%、その他+23%、名古屋圏+16%。中古戸建ては東京圏+16%、大阪圏+15%、その他+10%、地方4市+9%、名古屋圏+7%。成約価格で作った指数もほぼ同じ動き（差は大きくても5ポイント程度）。「その他」の中古マンションは、㎡単価の中央値だけで見ると+15%で、品質をそろえた指数（+28%、いずれも2025年10〜12月期、2021年1〜3月期比）より大きく低く出る
- **R2**：同じ条件で比べると、中古マンションの成約価格は取引価格より約10%低い（東京圏−11.7%、大阪圏−9.0%、その他−4.9%）。この差は2021〜2025年でほぼ一定。中古戸建ては東京圏・大阪圏でほぼ差がない一方、価格水準の低い市区町村ほど成約価格が高く出る（最も安い20%の市区町村で+95%）。分析に使った件数のうち成約価格情報の割合は、戸建てで2024年34%→2025年48%と急に増えた。四半期ごとの動きは同時期の相関が最も高く、どちらかが先行する形は見られない

#### 動かし方
元データ（全国、約440MB）はリポジトリに入れていません。https://www.reinfolib.mlit.go.jp/realEstatePrices/ で「全都道府県」「すべて」「2021年第1四半期〜2025年第4四半期」を選んでダウンロードし、zipの中のCSV（`01_Hokkaido_20211_20254.csv` など47ファイル）を `data/raw/` に置いてください。

```bash
pip install -r requirements.txt
cd src
python r1_index.py
python r2_gap.py
```

#### データ
| ファイル | 中身 |
|---|---|
| data/raw/NN_*_20211_20254.csv（各自ダウンロード） | 1件ごとの種類、価格情報区分（取引価格／成約価格）、市区町村、最寄駅までの距離、価格、面積、間取り、建築年、構造、取引時期など |

#### 注意
- 取引価格情報は、登記をもとに国交省が行うアンケートの回答から作られています。成約価格情報は、不動産流通機構の「レインズ」に登録された成約事例で、個別の物件が分からないよう加工されています。集め方も対象も違う別のデータです
- 価格指数は、データにある条件（築年・面積・駅距離・構造・間取り・取引の事情）と市区町村の違いだけをそろえたものです。眺望・階数・管理状態・リフォームの中身などはそろえていません
- R2の差は、同じ物件を比べたものではありません。「取引価格」には業者が買い取って再販売する取引、親族間や地元の取引など、レインズに出てこない取引が含まれると考えられ、差の理由はこのデータだけでは分けられません
- 2025年に成約価格情報の件数が増えた理由は確かめていません。登録や提供の範囲が変わった可能性があります
- 最寄駅までの距離の区間表記（30分〜60分など）は区間の中央の値に置き換えています
