# F102 円安が物価に効くのは、円安が大きいときだけか？ 閾値 VAR で「状態で切り替わる伝わり方」を確かめる

看板記事 F102 のコード・データ・図です。note の記事「円安が物価に効くのは、円安が大きいときだけか？」の中身をここで再現できます。

## 問い

「円安が小さいうちは物価にあまり響かないが、大きな円安になると一気に値上げが広がる」という見方があります。ドル円の動きが消費者物価に伝わる割合（パススルー）は、円安が大きい局面で本当に強くなるのでしょうか。

- 大きな円安の局面とそれ以外で、1%の円安が消費者物価・国内企業物価をどれだけ押し上げるかを分けて推定する
- しきい値（どれだけ円安なら「大きい」か）はデータから決め、線形のモデルと比べて当てはまりが良くなるかを検定する
- ショックの大きさ・向き（円高）を変えたときに、1%あたりの反応が変わるかも見る

## データ

新しく取ったデータはありません。035・F12・F39 で取得したものを `data/raw/` にコピーして使っています（`src/01_取得.py`）。

| 変数 | 系列 | 出典 |
|---|---|---|
| 輸入物価（契約通貨） | 輸入物価指数・契約通貨ベース・総平均（為替の影響を除いた、海外の価格の動き） | 日本銀行 時系列統計データ（企業物価指数） |
| ドル円 | 東京市場 ドル・円 スポット 17時時点／月中平均（上がると円安） | 日本銀行 時系列統計データ |
| 国内企業物価 | 国内企業物価指数・総平均 | 日本銀行 時系列統計データ（企業物価指数） |
| 消費者物価 | 消費者物価指数・生鮮食品を除く総合（全国） | 総務省 消費者物価指数（F12 のデータマート経由） |

- 期間：1981年1月〜2026年8月（548か月。しきい値に過去12か月の値を使うので、前月比は1980年1月から作っています）
- 各系列は前月比（対数差×100）にし、月ダミー（季節性）と、特殊な月のダミーを OLS で取り除きました（平均は残す）
- 取り除いた特殊な月：消費税の導入・引き上げ（1989年4月、1997年4月、2014年4月、2019年10月）、携帯電話の通信料の値下げ（2021年4月）、電気・ガスの負担軽減策の開始（2023年2月）
- 輸入物価（円ベース）は図と局所射影の参考だけに使いました（契約通貨ベースとドル円からほぼ決まるので、VAR には入れていません）

## 手法

| 手法 | 何をするか |
|---|---|
| 線形 VAR | 4変数（輸入物価〔契約通貨〕→ドル円→国内企業物価→消費者物価）の VAR。ラグは BIC で1。ショックは Cholesky 分解（この順番）で識別 |
| 閾値 VAR（TVAR） | しきい値変数 z = 前月までの12か月のドル円の変化率（＋が円安）。z がしきい値 γ を超える月は「大きな円安の局面」として、定数・係数・誤差の分散をすべて別にする。γ は z の15〜85%点の71点から、残差の共分散行列の対数行列式が最小になるものを選ぶ |
| sup-LR 検定 | 線形 VAR と TVAR の当てはまりの差（LR = T ×〔線形の対数行列式 − TVAR の対数行列式〕）の最大値。線形 VAR からシミュレーションしたデータ（しきい値変数もシミュレーションしたドル円から作る）で同じ探索を300回くり返して p 値を出す |
| 局面ごとのインパルス応答 | 局面ごとの係数と Cholesky で、ドル円が当月1%円安になるショックへの累積の反応（水準）。帯は、局面の並びを観測どおりに固定した再帰的ブートストラップ500回 |
| パススルー率 | h か月後の消費者物価の累積の反応 ÷ 同じ月のドル円の累積の反応 |
| 一般化インパルス応答（GIRF） | Koop–Pesaran–Potter の方法。各月の実際の履歴から24か月先までを100回ずつシミュレーションし、ショックあり・なしの差を平均する。ショックの途中で局面が切り替わることも含まれる。ショックの大きさは −2, −1, +1, +2, +3 標準偏差 |
| 状態で分けた局所射影（設計の代替案） | h か月後までの累積の変化を、当月のドル円の変化 ×（大きな円安の局面か、それ以外か）に回帰（当月の輸入物価〔契約通貨〕、4変数の1か月前の値、局面ダミーを入れる。Newey–West）。同じ形で「その月の動きの大きさ（上位20%か）」「円安の月か円高の月か」でも分けた |

## 主な結果

**しきい値と、線形との比較**

- いちばん当てはまるしきい値は、過去12か月で **+8.7% の円安**。548か月のうち121か月（22%）がこの局面に入りました（1996〜97年、2001〜02年、2013〜15年、2022〜23年など18の時期）
- 2つの局面に分けると、当てはまりは線形より良くなりました（sup-LR = 47.8、p = 0.007）。ただし、−3.5% 前後（小さな円高）で分けても、ほぼ同じくらい当てはまりが良くなります（図2）

**局面ごとの反応（ドル円が当月1%円安になったとき、24か月後までの累積）**

| | 大きな円安の局面 | それ以外 | 分けない（線形） |
|---|---|---|---|
| ドル円そのもの | +1.47% | +1.42% | +1.44% |
| 国内企業物価 | +0.070%（90%区間 0.003〜0.126） | +0.102%（0.050〜0.155） | +0.076% |
| 消費者物価（生鮮除く） | +0.013%（−0.018〜0.038） | +0.026%（0.010〜0.042） | +0.020% |
| パススルー率（消費者物価 ÷ ドル円） | 0.009（95%区間 −0.015〜0.034） | 0.018（0.005〜0.032） | 0.014 |

- 大きな円安の局面のほうが、消費者物価への伝わり方は **むしろ小さい** という点推定でした。ただ差（−0.009）の95%区間は −0.036〜+0.017 で、どちらとも言えません
- どちらの局面でも、1%の円安が2年で消費者物価を押し上げるのは0.01〜0.03%ほど（10%の円安なら0.1〜0.3%）。国内企業物価へはその4〜5倍です
- 反応はほぼ半年でおさまり、12か月後と24か月後の値はほとんど同じでした

**ショックの大きさ・向きを変える（GIRF、24か月後、当月1%あたり）**

| ショック | −2σ（円高） | −1σ | +1σ（円安） | +2σ | +3σ |
|---|---|---|---|---|---|
| 消費者物価の反応 | 0.034 | 0.035 | 0.039 | 0.041 | 0.042 |

- ショックを3倍にしても、1%あたりの反応は1割ほどしか大きくなりませんでした。円安のほうが円高より少しだけ大きい
- GIRF の値が局面ごとのインパルス応答より大きいのは、円安ショックで局面が「大きな円安」に切り替わると、その局面の定数（平均の物価上昇）に移る分が含まれるためだと考えられます（推測）

**局所射影（24か月後、当月1%あたり、90%区間）**

- 大きな円安の局面 +0.030%（−0.077〜+0.137）、それ以外 +0.079%（+0.013〜+0.145）
- その月の動きが大きい（上位20%） +0.040%、小さい +0.132%
- 円安の月 +0.038%、円高の月 +0.090%
- どの分け方でも「大きい・円安のほうが強い」という形は出ず、区間は大きく重なりました

- 「大きな円安の局面で強まる」形（差がプラスで、区間が0をまたがない）は、どの設定でも出ませんでした

- しきい値の位置は設定でぶれます。ラグを3以上にしたり、期間を2021年や2012年までにしたりすると、データが選ぶしきい値は円高の側（−4〜−13%）に移りました
- 物価が上がっている時期（過去12か月で+1.3%超）のほうが伝わり方は大きい（0.021 対 0.006）ものの、区間は0をまたぎました
- ラグを増やすとパススルー率は大きくなります（ラグ1で0.014〜0.018、ラグ6で0.04前後）。大きさはラグの選び方に左右されます

## 言えないこと

- **局面の違いが「円安の大きさ」のせいかは分かりません。** 大きな円安の局面は18の時期しかなく、その時期の景気・エネルギー価格・企業の価格設定の変化も一緒に入っています。逆に、大きな円高の局面で伝わり方が大きく出たのは1980年代後半（プラザ合意のあと）の影響が大きく、原油価格の急落など、輸入物価（契約通貨）だけでは取り切れない動きが混ざっている可能性があります（推測）
- **2022年以降の値上げの広がりを否定するものではありません。** この分析は1981年以降をまとめて2つの局面に分けたもので、ある時期だけ伝わり方が変わった可能性は、局面の分け方では拾えません。2022年以降を除くと、しきい値の位置そのものが変わりました
- **ドル円の「ショック」は、Cholesky の順番（輸入物価のあと）で決めた仮定にもとづくものです。** ドル円を最初に置いても結果はほとんど変わりませんでしたが、金融政策や景気の変化に反応したドル円の動きを、完全には切り分けられていません
- 消費者物価は生鮮食品を除く総合で、品目ごとの違い（エネルギーと食料・サービスなど）は見ていません。ドル円だけを見ていて、ユーロなどほかの通貨や実効為替レートは使っていません
- パススルー率の大きさはラグの選び方に左右され、ラグ1（BIC）では小さめに出ます
