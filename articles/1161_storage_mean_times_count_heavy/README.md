# 1161 1件あたりの大きさの平均に件数を掛けた見込みは、とても大きい件が少しまざるとどれだけ外れるのか？（データ量の見込み）

保存するデータの量を見込むとき、「今あるファイルからいくつか選んで1件あたりの平均の大きさを出し、来年の件数を掛ける」やり方がよく使われます。平均×件数は、平均すれば正しい答えに合います（作りどおり）。けれども、ごく一部のとても大きいファイルが量の大半を占めると、選んだファイルにその大きいファイルが何件入ったかで、見込みは大きく上下します。多くの回では1件も入らずに低く出て、たまに入った回に大きく高く出ます。**ここでは、作成者が置いた架空のアプリの保存ファイル（ふつうのファイルと、件数で0.1%だけの「とても大きいファイル」の大きさの分布を置き、乱数で作ったもの）で、来年の100万件の合計を、今あるファイルから選んだ1,000件の平均×100万で見込み、10,000回くり返して、見込みが正しい答えから何倍ずれるかを数えました。中央値×件数・上の1%を外れとして除いた平均×件数とも比べ、とても大きいファイルの割合・大きさ・選ぶ件数を変えた18通りで確かめました。**

関連する記事：1043「大きく外れた要素が1つあると、ほかを正しくしても全体はどれだけずれるのか？」は、掛け算の概算で要素の1つが大きく外れる場面を扱っています。この記事の外れは要素の取り違えではなく、選んだ件にまれな大きい件が入るかどうかで起きます。1042「要素ごとに平均を使うか中央値を使うかで、掛けた答えはどれだけ違うのか？」は、右に長い要素で中央値を掛けると低く出る形を扱っています。1041「掛け算でつなぐ要素が増えるほど、概算はどれだけ外れやすくなるのか？」は、要素の誤差が重なる形です。この記事は、件数は正しく分かっていて、1件あたりの平均だけを一部のファイルから見込む場面に絞ります。同じ企画の 1168「小さなファイルがたくさんあると、大きさの合計と実際に使う量はどれだけ違うのか？」は、逆に件数の多い小さなファイルが、区画への切り上げで実際に使う量をふくらませる場面を扱っています。この記事は大きさの合計を見込む場面で、量の大半を件数の少ない大きいファイルが占めます。

## 主な結果

### 置いた分布で、量の大半はとても大きいファイル（`results/a1161_main.json` の `setting`・`actual_years`）
- 件数で0.1%のとても大きいファイルが、量の**58.22%**を占める（置いた分布からの式どおりの値。200年分の実際の1年でも平均58.21%）
- 実際の1年（100万件）の合計は、正しい答え（期待値）の0.9576〜1.0395倍（200年の5〜95%）に収まった。1年に入るとても大きいファイルは200年の平均で1,000.9件あり、年ごとの振れは小さい

### 1,000件の平均×100万の見込み（10,000回、`results/a1161_main.json` の `base`）
| | とても大きいファイル0.1%あり | なし（対照） |
|---|---|---|
| 見込み÷正しい答えの平均 | 0.9895倍 | 1.0008倍 |
| 見込み÷正しい答えの中央値 | **0.7261倍** | 0.9999倍 |
| 10〜90%の範囲 | 0.4077〜1.9606倍 | 0.9481〜1.0541倍 |
| 正しい答えの±20%に入った回 | **17.87%** | 100% |
| 0.8倍より低かった回 | 54.86% | 0% |
| 1.25倍より高かった回 | 25.52% | 0% |
| 正しい答えより低かった回 | 64.88% | 50.06% |

- **平均×件数の見込みは、10,000回の平均では0.9895倍で正しい答えにほぼ合った（平均すれば合うのは作りどおり）。けれども真ん中の回は0.7261倍で、±20%に入ったのは17.87%の回だけだった**
- とても大きいファイルがないと、同じ1,000件の平均×100万でも、すべての回が±20%に入った

### 選んだ1,000件にとても大きいファイルが何件入ったか（`results/base_by_huge_count.csv`）
| 入った件数 | 回の割合 | 見込み÷正しい答え（中央値） |
|---|---|---|
| 0件 | 37.2% | 0.418倍 |
| 1件 | 37.07% | 0.844倍 |
| 2件 | 18.07% | 1.3927倍 |
| 3件 | 5.99% | 1.9521倍 |
| 4件以上 | 1.67% | 2.5712倍 |

- 選んだ1,000件に入るとても大きいファイルの数の見込みは1件（1,000×0.1%）。1件も入らなかった回は37.2%で、置いた割合からの式（1,000件すべてがふつうのファイルになる確率）の36.77%とほぼ同じだった。この回の見込みは0.418倍で、ふつうのファイルの分しか数えていない
- 1件入るか2件入るかで、見込みは0.844倍から1.3927倍に跳ねた

### ほかの見込み方（基本の置き方、`results/a1161_main.json` の `base`）
- 中央値×100万は0.254倍（とても大きいファイルなしの対照でも0.6068倍）。中央値はふつうのファイルの真ん中の大きさで、右に長い分布では平均より小さい（作りどおり）
- 大きい方から1%を除いた平均×100万は0.386倍（対照でも0.9179倍）。とても大きいファイルを外れとして除くと、量の58.22%を占める分が見込みから抜ける

### 確かめ：18通り（各2,000回、`results/grid.csv`）
| とても大きいファイル（件数の割合・中央値） | 量に占める割合（式） | 100件を選ぶ | 1,000件 | 10,000件 |
|---|---|---|---|---|
| 0.01%・50MB | 1.37% | 88.4% | 98.7% | 100% |
| 0.01%・500MB | 12.22% | 72.5% | 90.3% | 90.4% |
| 0.1%・50MB | 12.23% | 68.35% | 87.45% | 99.7% |
| 0.1%・500MB（基本） | 58.22% | 0.1% | 17.65% | 58.35% |
| 1%・50MB | 58.44% | 18.75% | 57.8% | 98.6% |
| 1%・500MB | 93.36% | 11.05% | 40.25% | 88% |

（表の数字は、見込みが正しい答えの±20%に入った回の割合）

- **±20%に入った回は、18通りで0.1〜100%と大きく動いた**。とても大きいファイルが量に占める割合が大きく、選ぶ件数の中に入るとても大きいファイルの数の見込み（件数×割合）が少ないほど、外れやすい傾向があった
- 見込みの平均は18通りすべてで0.9245〜1.0453倍と、正しい答えに近かった（作りどおり）。見込みの中央値は0.4242〜0.998倍で、18通りすべてで1倍より低かった
- 正しい答えより低く出た回は51.3〜91.35%で、18通りすべてで半分を超えた（9通りで60%を超えた）
- 基本の置き方（0.1%・500MB）では、選ぶ件数を10倍の10,000件にしても、±20%に入った回は58.35%だった

## 注意（言えないこと）
- 架空のデータです。ふつうのファイルととても大きいファイルの大きさの分布、割合、件数は作成者が置いたもので、外れ方はこれで決まります。とくに、とても大きいファイルが量に占める割合と、選ぶ件数に入る数の見込みで、結果は大きく動きます（18通りで±20%に入る回が0.1〜100%）。実在のアプリの保存データを表すものではありません
- 来年の件数は正しく分かっているとし、来年のファイルも今あるファイルと同じ分布から来ると置きました。件数の見込みの外れや、増え方の変化は入れていません
- 選ぶファイルは今あるものからでたらめに選ぶと置きました。新しい順・フォルダごとなど、偏った選び方は入れていません
- 圧縮・同じ中身のまとめ・控え（バックアップ）など、実際に使う量を変えるものは入れていません
- 容量をどれだけ用意すべきかや、その費用は扱っていません
