# researchers-industry-japan：企業の研究者は、どの産業で増えたのか（科学技術研究調査 2012〜2025年）

総務省「科学技術研究調査」の企業 第5表「産業、専門別研究者数」を2012〜2025年調査の14年分つなぎ、企業で働く研究者がどの産業・どの専門分野で増えたのかを、シフトシェア分解で調べたリポジトリです。

| 問い | 手法 | スクリプト |
|---|---|---|
| 研究者が増えたのはどの産業か。全体の伸びで説明できる分と、その産業ならではの分はどれくらいか | 2012〜14年平均と2023〜25年平均の比較（年ごとの振れをならすため3年平均）。いちばん細かい40産業で、増減を「全体と同じ率で増えた分」と「産業固有の分」に分ける（シフトシェア分解） | `src/a139_shiftshare.py` |
| 情報科学などの専門分野が増えたのは、その分野の多い産業が伸びたからか、どの産業でもその分野の割合が上がったからか | 専門分野の増減＝Σ（産業の人数の変化×最初の分野の割合）＋Σ（後の人数×分野の割合の変化）の2つに分解 | `src/a139_shiftshare.py` |

## 主な結果
- 企業の研究者（実数）は53.2万人（2012〜14年平均）→61.0万人（2023〜25年平均）で14.7%増えた（7.8万人増）
- 増えた7.8万人のうち、製造業は1.1万人（14%）だけ。情報通信業が2.4万人（30%）、学術研究・専門・技術サービス業が2.5万人（32%）、そのほか（卸売など）が1.8万人（24%）。製造業の割合は87.4%→78.0%
- 産業別では自動車＋3.0万人（＋46%）、情報サービス＋2.3万人（＋95%）が大きい。情報通信機械器具製造業は9.7万人→4.1万人（−58%）と大きく減った
- 情報科学が専門の研究者は3.2万人→6.8万人（2.1倍）。増えた3.5万人のうち、情報系の産業が伸びた分が1.8万人、同じ産業の中で情報科学の割合が上がった分が1.7万人と、ほぼ半々
- 機械・船舶・航空は＋1.8万人だが、産業の伸び（主に自動車）で＋2.9万人、産業内の割合の低下で−1.1万人。電気・通信は−1.0万人で、ほぼすべてが産業（情報通信機械など）の縮小による

## 動かし方
`data/researchers_industry_field.csv`（年×産業×専門分野に整えたもの）が入っているので、そのまま動きます。元の Excel から作り直すときは、e-Stat の各年の企業 第5表を `data/raw/139_<調査年>.k0` の名前で置き、CSV を消してから実行してください。

```bash
pip install -r requirements.txt
cd src
python a139_shiftshare.py
```

| ファイル | 中身 |

| data/researchers_industry_field.csv | 調査年×産業番号（1〜49、48・49は男女の再掲）：研究者数（実数）、自然科学計、理学・工学・農学・保健の計と細分野、人文・社会科学 |
| results/a139_industry_shiftshare.csv | 40産業の3年平均、増減、増減率、全体並みの分・産業固有の分、構成比 |

| results/a139_field_decomposition.csv | 専門分野8区分の増減と、その分解 |

- 元データ：総務省統計局「科学技術研究調査」企業 第5表 産業、専門別研究者数（e-Stat https://www.e-stat.go.jp/stat-search/files?toukei=00200543 ）。2012〜2020年調査は xls、2021年調査以降は xlsx（データベース形式）

## 注意
- 調査年は「その年の3月31日現在の研究者数」です（例：2025年調査＝2025年3月31日現在）
- 研究者数は実数（人）で、研究に使った時間の割合で換算した値ではありません。標本調査の推計値なので、年ごとの振れがあります（例：情報サービス業は2023年に5.7万人、2024年に3.7万人）。そのため3年平均で比べています
- 2022年調査で、卸売業（7.7千人→17.3千人）、専門サービス業（2.3千人→9.8千人）、技術サービス業（4.2千人→17.4千人）が段のように増えています。会社の主な産業の分け方や調査対象の変化が含まれている可能性があり、研究者が実際にその分だけ増えたとは限りません
- 2022年調査から「数学・物理」が「数学」「物理」に分かれたので、足し合わせて使いました。理学・工学・農学・保健には、表にない「その他」の分野が含まれるため、分析では「理学（情報以外）」「工学（その他）」のように差で求めています
- 秘匿（X）になっている値（2022年のパルプ・紙、印刷、2025年の農林水産業、電気・ガス）は平均から除いています
- 大学・公的研究機関などの研究者は含みません（企業の表だけ）
