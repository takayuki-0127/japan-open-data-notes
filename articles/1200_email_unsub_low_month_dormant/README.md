# 1200 配信停止の少ない月は、読者が満足していた月なのか、もう読んでいない人が多い月なのか？（メール配信）

お知らせのメールでは、「配信停止 ÷ 送った通数」（配信停止率）が下がると、「読者が満足している」と読みたくなります。けれども、配信停止のリンクはメールの中にあるので、もう開かなくなった人は停止もあまり押しません。読んでいない人が増えると、不満が同じでも、送った通数あたりの停止は下がります。**ここでは、作成者が乱数で作った架空の店の会員向けメール（月4通、36か月）で、月ごとの不満の強さと、読んでいない人の割合を作成者が置き、配信停止を「送った通数」で割るか「開いた通数」で割るかで、停止の少ない月がどちらを表すかを数えました。置き方を変えた27通りでも確かめました。**

例の店・会員・メールは作成者が置いた架空のもので、実在のメール配信サービス・メールソフト・会社の数字ではありません。値引きや価格の訴求など、メールの中身の良し悪しは扱っていません。

関連する記事：475「解約率の分母を変えると、月次と年率はどれだけ変わるのか」は、同じ解約の数を期首の人数・在籍日数など何で割るかを比べています。同じ企画の 1199「送る回数を増やすと、1通あたりの反応は下がっても、全体の反応はどう動くのか？」は、送る回数を増やしたときに、配信を止めた人が積み重なって開封の合計がどう動くかを扱っています。同じ企画の 1201「長く開いていない人に送るのをやめて開封率が上がったのは、メールが良くなったからなのか？」は、読んでいない人を送り先から外したときの開封率を扱います。この記事は、割る数を「送った通数」と「開いた通数」で比べ、メールでは開かない人が停止も押さない点に絞ります。

## 主な結果

### 年をまたいで比べると（300リストの平均、`results/a1200_main.json` の lists300.base）
| | 3年目 ÷ 1年目 |
|---|---|
| 配信停止 ÷ 送った通数 | **0.6846倍** |
| 開いた通数 ÷ 送った通数（開いた割合） | 0.6227倍 |
| 配信停止 ÷ 開いた通数 | 1.103倍 |

- 不満の強さは、3年目と1年目で平均の差が0.0189と、ほぼ同じに置いた。それでも、**送った通数あたりの停止は3年目に1年目の0.6846倍に下がった**。読んでいない人の割合が、1か月目の23.77%から36か月目の65.93%に増えたため
- 送った通数あたりの停止 ＝ 開いた割合 × 開いた通数あたりの停止（＋開かずに停止した分）で、0.6846倍はほぼ0.6227倍×1.103倍になる（式どおり）
- 送った通数あたりの停止が3年目に2割以上下がったリストは84%あった。そのうち、3年目のほうが本当に不満が弱かったのは55.16%で、半々に近かった。読んでいない人の数を動かさない対照では、2割以上下がったリストは11%だった
- 開いた通数あたりの停止は、3年目に1.103倍と少し上がった。開かずに停止する人（確率0.0002）は読んでいない人の中にもいて、その分を開いた通数で割るため。開かずに停止する確率を0と置いた9通りでは0.9956〜1.0441倍だった（`results/grid.csv`）

### 月ごとの上下で比べると（300リストの平均）
| | その月の不満の強さとの相関 | 停止の少ない6か月のうち、不満の弱い月 | 停止の少ない6か月のうち、読んでいない人の割合が高い3分の1の月 |
|---|---|---|---|
| 停止 ÷ 送った通数 | **0.7705**（5〜95%：0.6573〜0.8675） | 86.44% | **59.67%** |
| 停止 ÷ 開いた通数 | 0.9005（5〜95%：0.8298〜0.943） | 93.39% | 23.78% |
| 対照（読んでいない人の数を動かさない）、停止 ÷ 送った通数 | 0.901 | 93.56% | — |

- 月ごとの上下では、停止の少ない月の多くは不満の弱い月だった（送った通数で割って86.44%）。ただし、**送った通数で割ると、停止の少ない6か月の59.67%が、読んでいない人の割合の高い3分の1の月に寄っていた**（でたらめなら3分の1）。開いた通数で割ると23.78%だった
- 送った通数あたりの停止の月ごとの上下（対数）のうち、28.97%は開いた割合の上下から来ていた。対照では−0.02%（ほぼ0）だった
- 例のリスト（`data/example_list_months.csv`）では、停止がいちばん少なかったのは27か月目（送った通数あたり0.0478%）で、36か月の中でいちばん不満の弱い月だった。このときの読んでいない人の割合は58.4619%。停止の少ない6か月のうち5か月が不満の弱い月だった

### 確かめ：置き方を変えた27通り（各100リスト、`results/grid.csv`）
- 3年目÷1年目は、送った通数あたりで0.5519〜0.8293倍、開いた通数あたりで0.9956〜1.393倍だった。27通りすべてで、送った通数あたりの停止は3年目に下がった
- 不満の強さとの月ごとの相関は、送った通数で割って0.404〜0.8634、開いた通数で割って0.4034〜0.9326。開いた通数で割るほうが高かったのは27通り中22通りで、低かった5通りは、開かずに停止する確率を大きく（0.001）置いたときだった
- 停止の少ない6か月のうち不満の弱い月の割合は、送った通数で割って58.33〜96.67%。不満の効きを小さく（0.15）置くと低くなり、読んでいない人の割合の上下が効いた
- 停止率の月ごとの上下のうち、開いた割合の上下から来る分は10.63〜87.57%だった


## 注意（言えないこと）
- 架空のデータです。読んでいる人が読まなくなる速さ、開く確率、停止の確率、不満の強さの月ごとの振れは作成者が置いたもので、結果はこれで決まります。3年目÷1年目の下がり方は、27通りで0.5519〜0.8293倍に分かれました
- 読んでいない人は戻らないと置きました。戻ってくる人がいれば、読んでいない人の割合の増え方は緩やかになります（確かめていません）
- 開いた通数は、本当に開いた数として数えました。開封の記録には、画像の読み込みなどで数え漏れや数えすぎがあり、開いた通数で割った値もその分ずれます
- 不満の強さは作成者が置いた架空の値で、実際の読者の満足を測る方法は扱っていません。メールの中身・送る頻度の良し悪しも言えません
