# 432 死亡率の将来の下がり方を過去から延ばす方法は、正解の分かるデータでどれだけ当たるのか（手法の解説）

将来の正解まで分かっている架空の年齢別死亡率60年分を作り、**リー・カーターの方法で前半40年から後半20年を予測したとき、どれだけ当たるか**を確かめたフォルダです。F86 は実際のデータでの予測で、こちらは正解を置いて、方法が外れる場面を測ります。

|---|---|---|---|
| A432 | 下がり方が一定／途中で鈍る／年齢で違ってくる、の3つの場面で、20年先の死亡率と平均生存年数はどれだけ外れるか。予測の幅は正解を含むか | 架空の死亡率（40〜99歳・60年）。観測の死亡数はポアソン。特異値分解で当てはめ、全体の水準をドリフトつきランダムウォークで延ばす。各条件300回 | `src/a432_lee_carter.py` |

## 置いたこと（架空）
- 年齢40〜99歳、60年分。はじめの年の死亡率は、40歳0.12%から年齢1歳につき約10%ずつ高くなる形
- 下がり方：40歳で年2.0%、99歳で年0.7%（あいだは直線）。全年齢に共通の年ごとの当たり外れ（ランダムウォーク、下がり方の0.8年分）を足す
- 場面：「一定」／「途中で鈍る」31年目から下がり方が半分／「年齢で違ってくる」若い側が鈍り高齢の側が速まって、60年かけて入れ替わる
- 観測：各年齢の人口20万人または2万人。死亡数はポアソン分布（0件でも対数が取れるよう0.5を足す）
- 当てはめ：1〜40年目（または直近の21〜40年目）。予測：41〜60年目。予測の幅は500本の道から
- 65歳からの平均生存年数：65歳から100歳まで（100歳で打ち切り）

### 年齢ごとの死亡率の偏り（20万人・40年）
| 場面 | 45歳 | 70歳 | 90歳 |
|---|---|---|---|
| 一定 | +0.5% | +0.5% | +0.3% |
| 途中で鈍る | −12.9% | −9.3% | −6.4% |
| 年齢で違ってくる | −11.7% | +0.9% | +12.2% |

- 置き方が合っている「一定」では、幅はほぼ看板どおり。合っていない2つでは、看板より低い
- 人口が2万人だと、幅が約2倍に広がり、偏りがあっても正解を含む

## 動かし方
```
pip install -r requirements.txt
cd src && python a432_lee_carter.py      # 約10秒
```
`data/` の2ファイル、`results/` の2ファイル、`figures/` の3枚ができます。

## 確かめたこと
- 空のフォルダで計算し直し、data・results・figures が一致した
- 「一定」の場面では、平均生存年数の偏りがほぼ0（−0.02年）で、幅が正解を含む割合が95%に近い（98%）
- 正解の平均生存年数（当たり外れをならした値）：40年目に、一定22.4年・途中で鈍る22.0年・年齢で違ってくる22.8年。60年目に24.0年・22.8年・25.0年

## 注意（言えないこと）
- すべて架空の数字です。下がり方の速さ、鈍る時期、年齢での入れ替わり方、当たり外れの大きさで結果が決まります。実際の死亡率がどの場面に近いかは言えません
- リー・カーターのいちばん基本の形だけを試しました。生まれ年の効果を入れる方法や、下がりやすさが変わる方法は試していません
- 正解の死亡率は年齢に対してなめらかで、特定の年齢の山や、生まれ年ごとの違いは入っていません
- 「途中で鈍る」は、当てはめの期間の中で鈍る場合だけです
- 人口が少ないと幅が広がる理由（死亡数のばらつきが当たり外れに混ざる）は推測で、切り分けては確かめていません
- 保険料や年金の設計について、何かを勧めるものではありません
