# 793 空の文字と NULL を区別せずに数えると、未入力の件数はどれだけずれるのか（実務の型）

同じ「未入力」でも、表の中では NULL（値なし）、空の文字 `''`、空白だけの文字（半角・全角）と、形がいろいろです。ウェブの入力は NULL、ファイルからの取り込みは `''`、窓口の手入力は空白、のように、入ってきた経路で形が変わることもあります。`IS NULL` だけで数えると `''` と空白を見落とし、`COUNT(列)` で入力率を出すと `''` や空白も「入力あり」と数えます。**ここでは、作成者が乱数で作った架空の顧客5,000人の「建物名」で、数え方ごとの未入力の件数を比べました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A793 | 未入力の形が混ざると、数え方で件数はどれだけ違うか | 架空の顧客5,000人。建物名は55%が入力あり。未入力は、ウェブ（5割）は NULL、取り込み（3割）は ''、窓口（2割）は半角か全角の空白。IS NULL・NULL か ''・空白を除いてから、の3通りと COUNT(列) を DuckDB（1スレッド）で数え、Python の値と一致を確認。CSV に書き出して pandas の既定で読み直した場合も。seed 793 | `src/a793_blank.py`、`src/02_blank_duckdb.sql`、`src/01_blank_tsql.sql` |

## 主な結果

| 数え方 | 未入力の件数 |
|---|---|
| IS NULL だけ | **1,125件（23%）** |
| NULL か '' | 1,826件（37%） |
| 空白を除いてから（本当の未入力） | 2,260件（45%） |

| 入力率の出し方 | 値 |
|---|---|
| COUNT(列)÷件数（DB のまま） | **78%** |
| CSV に書き出して pandas の既定で読み直し、欠けていない割合 | 63% |
| 本当の入力率 | 55% |

- IS NULL だけで数えると、本当の未入力2,260件の半分（1,135件）を見落とした。取り込みの701件（''）と窓口の434件（空白）は1件も数えられなかった
- COUNT(列) は '' と空白も数えるので、入力率は78%と、本当の55%より23ポイント高く出た
- 同じ表を CSV に書き出して pandas の既定で読むと、'' は欠けた値（NaN）になるが空白だけの値は残る。入力率は63%で、DB の上で数えた78%とも本当の55%とも違った

## 確かめたこと
- 空のフォルダで流し直し、results・figures・data がバイト単位で一致した
- DuckDB の4つの数え方が、Python で数えた値と経路ごとに一致し、「空白を除いてから」が置いた未入力の数と一致すること（assert）

## データ
- `data/customers.csv`：架空の顧客表（customer_id・source・building）。CSV では NULL と '' が同じ空欄になるので、DB の上での区別はコードの中だけにある

## 注意（言えないこと）
- 架空のデータです。ずれの大きさは、経路ごとの割合と未入力の形の置き方で決まります
- T-SQL 版は未検証です。全角の空白を TRIM で除けるかは SQL Server の版によって違うので、REPLACE で半角にしてから除く書き方にしました（推測を含む）
- 「空白だけ」以外にも、「なし」「-」のような入力が未入力の意味で使われることがあります（扱っていない）
