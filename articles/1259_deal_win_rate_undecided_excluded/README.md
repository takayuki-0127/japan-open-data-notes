# 1259 「確度50%」と付けた商談のうち実際に取れた割合は、まだ決まっていない商談を除いて数えるとどう見えるのか？（受注の見込み）

確度の付け方が当たっているかを確かめるには、「確度50%」と付けた商談のうち、実際に取れた割合を数えます。けれども、数える日には、まだ決まっていない商談が残っています。決まった商談だけで数えると、早く決まる商談が多めに入ります。取れる商談と取れない商談で決まるまでの日数が違えば、取れた割合はずれて見えます。**ここでは、作成者が置いた架空の会社の商談（「確度50%」と付けた商談が過去360日に毎日同じ割合で始まり、最後に取れる確率と、取れる・取れない商談それぞれの決まるまでの日数を作成者が決め、乱数で作ったもの）で、決まった商談だけの受注の割合・決まっていない商談を取れなかったと数えた割合・始めて120日以上たった商談だけの割合を、最後まで待った本当の割合と比べました。決まる速さ・商談が始まる期間・本当の割合を変えた27通りで確かめました。**

例の会社と商談は架空のもので、実在の会社や商談の記録は使っていません。確度の付け方や担当の評価の助言をする記事ではありません。

関連する記事：1064「時間切れで打ち切った処理を除くと、平均の応答時間はどう見えるのか？」は、打ち切った処理を除くと、いちばん遅い処理が抜け落ちて平均が短く出ることを扱っています。決まっていない商談を除くのも、同じく「まだ終わっていないもの」を除く数え方です。1258「確度70%以上の商談の金額だけを足した見込みは、確度を掛けて足した見込みと比べて、実績より多く出るのか少なく出るのか？」は、記録の確度が高すぎる・低すぎるときに見込みがどちらへずれるかを扱っています。1260「受注率を、その期に始まった商談で数えるか、その期に決まった商談で数えるかで、どれだけ違うのか？」は、期の受注率を、その期に始まった商談で数えるか決まった商談で数えるかを比べています。そこでの「期末までに決まった数で割る」数え方は、この記事の①と同じ仕組みです。1267「見込みの良し悪しを、期の合計の外れで見るか、1件ずつの確度の当たりで見るかで、良い付け方は入れかわるのか？」は、確度の当たりを1件ずつで見るか、期の合計の外れで見るかで、良い付け方の順が入れかわることを扱っています。1262「長引いた商談ほど受注率が低いのは、長引いたせいか、もともと決まりにくい商談だからか？」は、取れない商談ほど決まるのが遅く見えるとき、それが長引いたせいか、もともと決まりにくい商談だからかの読み方を扱っています。この記事は、確度が当たっているかを確かめるときの、取れた割合の数え方に絞ります。

## 主な結果

### 基本：取れない商談ほど決まるのが遅いとき（600件×2,000回、`results/a1259_main.json`）
| 数え方 | 受注の割合（平均） | 10〜90%の範囲 |
|---|---|---|
| ① 決まった商談だけ | **56.40%** | 53.38〜59.39% |
| ② 決まっていない商談を取れなかったと数える | 43.42% | 40.83〜46.0% |
| ③ 始めて120日以上たった、決まった商談だけ | 52.87% | 49.61〜56.28% |
| ④ 最後まで待った本当の割合 | 50.04% | 47.5〜52.67% |

- **確度どおりに半分が取れると置いたのに、決まった商談だけで数えると56.40%と高く出た**。式の値は56.34%で、ずれは置いた決まるまでの日数からの式どおり。数える日に、600件のうち23.01%がまだ決まっていなかった
- 2,000回のうち6.3%の回では、①が60%以上になった
- ②は逆に低く出た（43.42%）。まだ決まっていない商談のうち、あとで取れる分まで取れなかったと数えるため
- ③は52.87%で、①より本当の割合に近かった（式の値は52.8%）。始めて120日以上たった商談でも、5.76%はまだ決まっていなかった

### 始まってからの日数ごと（`results/by_start_age.csv`）
| 始まったのは何日前か | 決まった商談だけの受注の割合 | まだ決まっていない割合 |
|---|---|---|
| 0〜30日 | 95.86% | 95.22% |
| 30〜60日 | 85.3% | 66.71% |
| 90〜120日 | 64.03% | 26.51% |
| 180〜210日 | 53.19% | 6.93% |
| 330〜360日 | 50.57% | 1.03% |

- 始まって30日以内の商談では、決まったもののうち95.86%が受注だった。早く決まるのは主に取れる商談なので、新しい商談ほど、決まったものは受注に偏る
- 最後まで待った割合は、どの30日でも49.72〜50.53%で、本当の割合（50%）と変わらない

### 決まる速さで向きが入れかわる（`results/scenarios.csv`）
| 場面 | ① 決まった商談だけ | ② | ③ | まだ決まっていない割合 |
|---|---|---|---|---|
| 取れない商談が遅く決まる（100日、基本） | 56.35% | 43.36% | 52.86% | 23.06% |
| 同じ速さ（40日） | 50.0% | 43.36% | 50.0% | 13.29% |
| 取れない商談が早く決まる（16日） | **47.86%** | 43.38% | 49.95% | 9.35% |

- 基本の行の56.35%は、上の表の56.40%とは別に作り直した値
- 取れる・取れない商談が同じ速さで決まるなら、①は本当の割合どおり（作りどおり）
- 取れない商談が早く決まる（断りがすぐ来る）と、①は逆に低く出た（47.86%）
- ②は、決まる速さにかかわらず低く出た

### 確かめ：27通り（`results/grid.csv`）
- **①と本当の割合の差は、27通りで−4.87〜+14.25ポイントだった**。取れない商談が遅く決まる9通りでは+2.28〜+14.25ポイント（いつも高く出る）、早く決まる9通りでは−4.87〜−0.82ポイント（いつも低く出る）、同じ速さの9通りでは−0.15〜+0.09ポイントだった
- ずれは、商談が始まる期間が短いほど大きかった。取れない商談が遅く決まるとき、過去180日に始まった商談では+10.86〜+14.25ポイント、過去720日では+2.28〜+2.71ポイント。期間が短いほど、決まって間もない商談の割合が大きいため
- ③（始めて120日以上だけ）は、決まる速さの違う18通りすべてで①より本当の割合に近かった。それでも、取れない商談が遅く決まる9通りでは+0.93〜+6.97ポイントのずれが残った
- ②と本当の割合の差は−18.75〜−1.87ポイントで、27通りすべてで低く出た
- ①は、27通りで式の値との差が0.23ポイント以内だった（作りどおり）

## 注意（言えないこと）
- 架空のデータです。決まるまでの日数の分布、取れる・取れない商談の速さの違い、商談の始まり方は作成者が置いたもので、ずれの向きと大きさはこれで決まります。①の値は式でも出せます（作りどおり）。新しく数えたのは、置き方ごとの向きの入れかわりと、③でどれだけ残るかです
- 決まるまでの日数は、確度と関係なく、取れる・取れないだけで違うと置きました。長い間動かずに残り、記録の上で決まらないままになる商談は入れていません
- 確度は本当の確率どおりと置きました。①が50%から離れても、それは確度の付け方の外れではなく、数え方のずれです
- 確度の付け方、担当の評価、見込みの立て方には使えません
