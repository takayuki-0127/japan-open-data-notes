# 1111 条件の刻み（5度ごと・10度ごと）で、良い条件の見つかり方はどう変わるのか？（試作と実験）

温度のように連続して変えられる条件を試すときは、「5度ごと」「10度ごと」と刻みを決めます。刻みを細かくすれば、良い温度を細かく言い当てられそうに見えます。けれども、試せる板の枚数が決まっていると、刻みを細かくするほど1つの温度あたりの枚数が減り、温度ごとの平均がぶれます。粗くすると、本当に良い温度が刻みの間に落ちます。**ここでは、作成者が乱数で作った架空の塗装工房（焼き付けの温度150〜210度ごとの本当のつやを山の形で置き、山の頂上の温度を回ごとに160〜200度から乱数で決めたもの）で、試し焼きの板60枚を5・10・15・20・30度の刻みで分けて、いちばんつやの良かった温度を選んだとき、①選んだ温度の本当のつやの不足、②頂上からの温度のずれ、③選んだ温度の見かけのつやの上ずれ、を4,000回ずつ数えました。板を半分ずつ使う二段の刻み（15度ごと→良かった温度の前後を5度ごと）も比べ、山のとがり・板のぶれ・板の枚数を変えた27通りも確かめました。**

例の工房と温度は架空のもので、実在の窯・塗料・会社を表すものではありません。つやは機械で測る値と置いています（人の好みを聞いて決める評価ではありません）。塗装の強さや安全にかかわる試験ではありません。

関連する記事：同じ企画の 1106「両端の2つの条件だけを試すと、真ん中の山を見落とすのか？」は、試し焼き12個を両端の2温度から12温度までに割り、真ん中の山を見落とすか、2次の曲線を当てはめるとどうかを扱っています。1104「条件の数を増やして繰り返しを減らすと、何を見落とすのか？」は、別々の条件の数と1条件あたりの枚数の割り方で、ばらつきの大きい条件を選んでしまうことを扱っています。1108「良い方へ少しずつ条件を動かしていくと、いちばん良い所に着くのか？」は、少しずつ動かす試し方と、着いた所の見かけの点数が本当より高く出ることを扱っています。この記事は、1つの温度の刻みの細かさだけを変え、頂上からのずれと見かけの上ずれがどう変わるかに絞ります。

## 主な結果

### 板60枚を刻みで分けたとき（基本、各4,000回、`results/by_step.csv`）
| 刻み | 温度の数×1温度の枚数 | ①つやの不足（平均） | ①で1を超えた割合 | ②頂上からのずれ（平均） | ②で2度以内だった割合 | ③見かけ−本当 | 板のぶれがないときの①・② |
|---|---|---|---|---|---|---|---|
| 5度 | 13×4〜5 | 0.47 | 14.67% | **3.5度** | 34.92% | **+1.3** | 0.058・1.31度 |
| 10度 | 7×8〜9 | **0.42** | 11.77% | **3.33度** | 35.8% | +0.39 | 0.2257・2.57度 |
| 15度 | 5×12 | 0.49 | 15.6% | 3.64度 | 30.18% | +0.09 | 0.4542・3.57度 |
| 20度 | 4×15 | 0.91 | 39.12% | 5.25度 | 20% | +0.04 | 0.8886・5.17度 |
| 30度 | 3×20 | 2.33 | 68.33% | 9.03度 | 9.9% | +0.03 | 2.377・9.16度 |
| 二段（15度→5度） | 5×6→5×6 | **0.38** | 11% | 3.14度 | 38.73% | +1.01 | − |

- **5度ごとに刻んでも、選んだ温度は頂上から平均3.5度ずれ、10度ごと（3.33度）より縮まなかった**。板のぶれがなければ5度ごとのずれは1.31度だが、1温度4〜5枚では平均のぶれのほうが大きく、隣の温度とつやの差がぶれに埋もれた
- つやの不足がいちばん小さかった一様な刻みは10度ごと（0.42）だった。5度ごとの不足0.47のうち、板のぶれがないときの分は0.058で、残りはぶれで隣の温度を選んだ分だった。30度ごとの不足2.33は、板のぶれがないとき（2.377）とほぼ同じで、刻みの粗さでほぼ決まった
- **選んだ温度の見かけのつやは、5度ごとでは本当より1.3高く出た**（20度ごとでは+0.04）。13温度の平均の中からいちばん高いものを選ぶので、たまたま高く出た温度を選びやすい
- 二段（15度ごと→前後を5度ごと）は、不足0.38・ずれ3.14度と、一様な刻みのどれより小さかった。ただし見かけの上ずれは+1.01と、5度ごとに近かった

### 刻みの粗さの分（板のぶれがないとき、`results/by_step.csv`）
- 山を左右同じ放物線にしたとき、板のぶれがないときの不足は、5度で0.0412、10度で0.1693、20度で0.6613で、0.02×刻み²÷12の式（0.0417・0.1667・0.6667）どおりだった。頂上の温度が刻みの間に一様に落ちるため。15度・30度は、頂上の範囲（160〜200度）が刻みの整数倍にならないので式と合わない（0.3224と0.375、1.8827と1.5）
- 山の形を変えても、不足の順は大きくは変わらなかった。焼きすぎ側が4倍急な山では5度0.5・10度0.46・15度0.63、左右同じ放物線では5度0.45・10度0.39・15度0.39

### 確かめ：置き方を変えると（27通り、各1,500回、`results/grid.csv`）
| | 27通りの結果 |
|---|---|
| つやの不足がいちばん小さかった一様な刻み | 5度：10通り、10度：6通り、15度：9通り、20度：2通り |
| 5度ごとの不足÷いちばん小さい刻みの不足 | 1〜1.31倍 |
| 30度ごとの不足÷いちばん小さい刻みの不足 | 1.25〜27.67倍 |
| 二段の不足÷いちばん小さい一様な刻みの不足 | 0.77〜1.09倍（25通りで1倍未満） |
| ③見かけ−本当（5度ごと） | +0.08〜+6.02 |
| ③見かけ−本当（20度ごと） | −0.01〜+1.37 |

- **不足のいちばん小さい刻みは、山のとがりと板のぶれで5〜20度に分かれた**。山がとがっている（低い側に10度で6.59下がる）と5度ごとが多く、なだらか（0.49下がる）だと15〜20度が多かった
- 細かすぎる刻みの損は小さく（5度ごとはいちばん良い刻みの1.31倍まで）、粗すぎる刻みの損は大きかった（30度ごとは最大27.67倍）
- 5度ごとのずれが10度ごと以上だったのは27通り中15通りだった。山がとがっている置き方では、5度ごとのほうがずれは小さかった
- 見かけの上ずれは、27通りすべてで5度ごとのほうが20度ごとより大きかった
- 二段は25通りで一様な刻みのいちばん良いものより不足が小さく、27通りすべてで5度ごとより小さかった。小さくならなかった2通りは、山がなだらか（0.005）で板のぶれが小さい（1.5）置き方だった

## 動かし方
```
pip install -r requirements.txt
cd src && python a1111_step_size.py
```
5秒ほどで終わります。`data/example_boards.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約5秒）
- 山を左右同じ放物線にし、板のぶれをなくしたとき、刻み5・10・20度の不足が 0.02×刻み²÷12 の式と合うことを確かめた
- 図3枚を開き、日本語・重なり・軸（棒は0から）を確かめた

## データ
- `data/example_boards.csv`：例の工房（頂上183度）を5度ごとと20度ごとで試したときの板1枚ずつ（step・temp・board・gloss）
- `results/a1111_main.json`：主な結果すべて（例の工房、刻みごと、二段、置き方を変えた範囲）
- `results/by_step.csv`：刻みごとの結果（板のぶれなし・山の形を変えたもの・式の値も入れた）
- `results/grid.csv`：27通りの確かめ

例の工房（`example`）では、5度ごとに試すと180度を選び（見かけのつや91.51、本当89.82）、20度ごとに試すと190度を選びました（見かけ87.31、本当88.13）。

## 注意（言えないこと）
- 架空のデータです。つやの山の形、山の頂上の範囲、板1枚のぶれ、板の枚数は作成者が置いたもので、結果はこれで決まります。不足のいちばん小さい刻みは、置き方27通りで5〜20度に分かれました
- 刻みの位置（150度から始める）は固定しました。同じ刻みでも、155度から始めると選ばれる温度は変わります
- 選び方は「いちばん平均の高かった温度」だけにしました。曲線を当てはめて頂上を見積もる選び方は 1106 で扱っています
- 二段の分け方（半分ずつ、15度→5度）は1通りだけ数えました
- 実在の窯・塗料での良い温度を表すものではなく、どの刻みを使うべきかも言えません。この記事は、刻みの細かさで見つかり方がどう変わるかを数えただけです
