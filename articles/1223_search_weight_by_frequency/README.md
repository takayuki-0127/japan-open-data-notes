# 1223 よく検索される語に重みを付けて平均するか、語ごとに同じ重みで平均するかで、改善の大きさはどう見えるのか？（検索の良さ）

検索のやり方を変えたときの改善は、検索語ごとに良さ（ここでは上位10件の正しい割合）を数え、その平均の差で見ることが多くあります。平均には、どの語も同じ重みで足す方法と、1か月に検索された回数で重みを付ける方法があります。検索の回数はごく一部の語に集まるので、回数で重みを付けると、よく使われる少数の語の変化で平均がほぼ決まります。改善がめったに使われない語に偏っていると、2つの平均で改善の大きさ、ときには向きまで変わります。**ここでは、作成者が置いた架空の社内の検索語400語（語ごとの検索の回数・正しい文書の数・今のやり方の強さ・新しいやり方での強さの変化を作成者が置き、検索の結果を乱数で作ったもの）で、2つの平均で改善がどう見えるか、評価に使う50語の選び方でどちらの平均に近くなるかを数えました。検索の回数の偏り・改善の付き方・語の数を変えた27通りでも確かめました。**

例の検索語・文書・検索のやり方は架空のもので、実在の検索の仕組みや検索の記録を表すものではありません。どちらの平均で改善を見るべきかは扱っていません。

## 主な結果

### 基本の置き方（200回の平均、`results/a1223_main.json` の `headline`）
| 平均の取り方 | 今のやり方 | 新しいやり方 | 改善 |
|---|---|---|---|
| 語ごとに同じ重み | 29.74% | 38.18% | **＋8.44ポイント** |
| 検索の回数で重み | 34.26% | 33.33% | **−0.94ポイント** |

- **同じ新旧の差でも、語ごとに同じ重みで平均すると＋8.44ポイントの改善、検索の回数で重みを付けると−0.94ポイントで、向きが逆になった**
- 400語のうち95.25%の語で改善したが、それらの語の検索の回数は全体の47.78%だった
- 検索の回数の上位10語で重みの44.58%（1位の語だけで15.22%、上位50語で68.48%）を占めた。上位10語の改善は−17.15〜＋0.1ポイントで、回数の重みを付けた平均への寄与は上位10語で−3.7ポイント、残りの390語で＋2.76ポイントだった
- 上位10語のうち、どの語で何ポイント下がるかは、語ごとの正しい文書の数でも動いた（置いた上乗せの変化は1位の語の−0.4がいちばん大きく、順位が下がるほど小さくなるが、改善は1位で−6.3、2位で−17.15ポイント）

### 1回だけ数えたときの振れと、50語の選び方（200回、`results/reps_base.csv`）
| 数え方 | 200回の平均 | 5〜95%の範囲 | 改善が＋だった回 |
|---|---|---|---|
| 全400語・同じ重み | 8.44ポイント | 7.17〜9.88 | 100% |
| ①でたらめに選んだ50語 | 8.2ポイント | 4.19〜12.41 | 100% |
| ③よく使われる上位50語 | −0.14ポイント | −4.42〜4.01 | 47% |
| 全400語・検索の回数で重み | −0.94ポイント | −5.67〜4.14 | 34% |
| ②記録から抜いた50回の検索 | −0.69ポイント | −6.42〜5.21 | 38.5% |

- ①は同じ重みの平均に、②は検索の回数の重みの平均に近かった（②は、回数の多い語ほど何度も入るので、回数の重みを付けたのと同じ形になる。作りどおり）
- 全400語を数えても、検索の回数で重みを付けた平均は1回ごとの振れが大きく（5〜95%で−5.67〜4.14ポイント）、同じ重みの平均（7.17〜9.88ポイント）より広かった。重みのほとんどが少数の語に乗るので、その語の1回ごとの結果の振れがそのまま残る
- ③の上位50語は、回数の重みの平均とも同じ重みの平均とも違う値だった（上位50語の中では同じ重みで、51位より下の語を数えない）

### 確かめ：27通り（各50回、`results/grid.csv`）
- **2つの平均の向き（＋か−か）が逆になったのは27通り中10通り**で、「めったに使われない語ほど良くなる」9通りのうち5通り、「よく使われる語ほど良くなる」9通りのうち5通り。「どの語も同じだけ良くなる」9通りでは0通りだった
- 「めったに使われない語ほど良くなる」では、同じ重みの改善は7.15〜9.27ポイント、回数の重みの改善は−5.34〜2.03ポイント。「よく使われる語ほど良くなる」では、同じ重みは−8.12〜−6.82ポイント、回数の重みは−1.91〜6.4ポイント。「どの語も同じだけ良くなる」では、同じ重み4.58〜4.88ポイント、回数の重み3.42〜4.86ポイントで近かった
- 上位10語の重みは、回数の偏りが0.8乗で23.05〜35.66%、1乗で39.13〜49.83%、1.2乗で56.92〜63.94%（語の数で変わる）
- 回数の重みを付けた平均の1回ごとの振れ（標準偏差）は、同じ重みの平均の1.77〜9.91倍だった
- 「よく使われる語ほど良くなる」でも、回数の偏りが0.8乗だと回数の重みの改善は−1.91〜−1.13ポイントで、同じ重みの平均と同じ向き（−）だった。改善の向きが逆になるかどうかは、置いた改善の付き方と回数の偏りの組み合わせで決まる

## データ
- `data/terms.csv`：400語（term_id（検索の回数の順位）・monthly_searches（1か月の検索の回数、丸め）・weight（重み）・n_correct（正しい文書の数）・old_strength（今のやり方の上乗せ）・change（新しいやり方での上乗せの変化）・old_top10_share / new_top10_share（200回の平均の上位10件の正しい割合）・improvement（本当の改善））
- `results/a1223_main.json`：主な結果すべて（`headline` に基本の置き方、`one_run` に1回ごとの振れ、`eval_sets_50` に50語の選び方、`robust` に確かめのまとめ）
- `results/reps_base.csv`：基本の置き方の200回（`all_equal`・`all_weighted` は全400語の2つの平均、`random50`・`log50`・`top50` は50語の選び方①②③、どれも改善を割合（0.01＝1ポイント）で）
- `results/grid.csv`：確かめの27通り（`s` は回数の偏り、`pattern` は改善の付き方（tail＝めったに使われない語ほど良くなる、flat＝どの語も同じ、head＝よく使われる語ほど良くなる）、`terms` は語の数、`equal_pt`・`weighted_pt` は2つの平均の改善（ポイント））

## 注意（言えないこと）
- 架空のデータと、作成者が置いた検索の回数・点数の付き方です。とくに「よく使われる語ほど悪く、めったに使われない語ほど良くなる」という置き方で、2つの平均の向きが逆になることはほぼ決まります
- 検索の回数の重みの平均は、少数の語で決まるので、その語の正しい文書の数などの置き方で大きく動きます
- 正しい文書はすべて分かっていると置きました。判定が一部しかないときのずれは入れていません（1222 で扱っています）
- 検索の回数は1か月で変わらないと置きました。新しいやり方で、言いかえて検索し直す人の数が変わることは入れていません
- どちらの平均で改善を見るべきかは、検索を使う人の数で見たいか、語の幅で見たいかで決まり、この記事では扱っていません
