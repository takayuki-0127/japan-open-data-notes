# 151 農業経営体は5年で何割減ったか（2025年農林業センサス）

農林水産省「2025年農林業センサス」確報（総括編）の都道府県別の表で、2020年と2025年の農業経営体数を比べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A151 | 農業経営体は5年で何割減ったか。どの県で大きく減り、何と一緒に動いていたか | 都道府県別の増減率、個人・団体・法人の内訳、経営主の年齢階層別の比較、後継者の確保状況・高齢者割合との相関 | `src/a151_farms.py` |

## 主な結果
- 農業経営体は 2020年 107.6万 → 2025年 83.6万（−22.3%）。個人経営体は −23.3%、団体経営体は +4.9%、法人経営は +10.1%（3.07万 → 3.38万）
- 都道府県の減少率は −13.4%（佐賀）〜 −36.3%（石川）、中央値 −22.6%。北陸・東海・中国で大きく、佐賀・和歌山・沖縄・北海道で小さい
- 経営主（個人経営体）でいちばん多い年齢は 65〜69歳（2020年）→ 70〜74歳（2025年）。55〜69歳の層が4割前後減り、75歳以上の割合は 26.2% → 32.0%
- 2025年に後継者を確保していない個人経営体は 64.7%。ただし県ごとの「後継者のいない割合」と減少率の相関はほぼ0（−0.01）

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a151_farms.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/pref_2020_2025.csv | 全国・都道府県：農業経営体数（計・個人・団体・法人、2025年・2020年）、経営主75歳以上・65歳以上の個人経営体数（両年）、後継者の確保状況（2025年） |
| data/national_age.csv | 全国：経営主の年齢階層別の個人経営体数（2025年・2020年） |

元の Excel（e-Stat、2025年農林業センサス 確報 第２ 総括編）：農業経営体数（statInfId=000040483737）、経営主の年齢階層別経営体数（000040483789）、後継者の確保状況別経営体数（000040483791）。必要な行の値を CSV に書き写しています。

## 注意
- 市区町村別の2025年の表はまだ公表されていないため、都道府県別で見ています
- 経営体の減少には、離農のほか、法人化や他の経営体への集約（規模拡大）も含まれます。農地や生産量が同じだけ減ったわけではありません
- 石川県の減り方が大きい理由（2024年の能登半島地震の影響など）は、この表だけでは分けられません
- 後継者の確保状況は2025年だけの値で、2020年の値とは比べていません
