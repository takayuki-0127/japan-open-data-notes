# 906 割合の差と割合の比、どちらで比べると順位が変わるのか？（割合とパーセント）

施策の前後で購入率（来店者のうち買った人の割合）が上がった店を並べるとき、「何ポイント上がったか」（差）で並べるか、「何倍になったか」（比）で並べるかで、上位の店が変わることがあります。比は「後÷前＝1＋差÷前の率」なので、前の率が低い店ほど、同じ差でも比が大きく出ます。**ここでは、作成者が乱数で作った架空の会社の店40店（前の月の購入率・来店者数・施策の効き方を作成者が置いたもの）で、差と比の上位5店がどれだけ重なるか、前の率の散らばりと来店者の多さでそれがどう変わるか、「本当の効き目」を差で決めるか比で決めるかでどちらの並べ方が当たるかを数えました。**

比の上位に前の率の低い店が集まること自体は、上の式から決まります。この記事で数えたのは、その入れかわりがどれくらいの大きさになるかと、来店者の数が限られて見かけの率が振れるときに何が起きるかです。

## 主な結果

### 基本の置き方（前の率2〜30%、来店者500〜5,000人、1,000回の平均）
| 型 | 差と比の上位5店の重なり | 1位が同じ | 順位の相関 | 上位5店の前の率（中央値）差で並べる／比で並べる |
|---|---|---|---|---|
| 足し算型 | **1.47店** | 8.3% | 0.68 | 10.5%／2.8% |
| 掛け算型 | **1.22店** | 4.5% | 0.71 | 21.2%／4.9% |

- どちらの型でも、差と比の上位5店で重なったのは平均1〜2店だった。差の上位には前の率の高い店が、比の上位には前の率の低い店が集まった
- 来店者が限りなく多い（見かけ＝本当）と置いても、重なりは足し算型で1.62店、掛け算型で1.75店で、入れかわりは振れのせいではなかった

### 1回分の40店（足し算型、`data/stores_one_draw.csv`）
- 差の上位5店と比の上位5店で、重なった店は0店だった。順位の動きは中央値で7位、最大で25位
- 差の1位の店は、前14.6%→後19.6%（+5.0ポイント、1.34倍）で、比では16位
- 比の1位の店は、前2.3%→後5.4%（+3.1ポイント、2.33倍）で、差では9位

### 確かめ：前の率の幅ごとの、差と比の上位5店の重なり（来店者の多さ4通り×型2つの幅）
| 前の率の幅 | 上位5店の重なり | 1位が同じ |
|---|---|---|
| 10%でそろう | 4.16〜5.00店 | 62.4〜100% |
| 8〜12% | 3.62〜4.03店 | 53.4〜61.6% |
| 5〜20% | 2.22〜2.88店 | 21.0〜32.0% |
| 2〜30%（基本） | 1.20〜1.79店 | 4.4〜20.2% |
| 1〜50% | 0.62〜1.57店 | 1.4〜17.4% |

- 40通り全体では、重なりは0.62〜5.00店、1位が同じ割合は1.4〜100%まで動いた。どれだけ入れかわるかは、ほぼ前の率の散らばりで決まった
- 前の率が10%でそろい、来店者が限りなく多いときは、差と比の順位は必ず同じになる（比＝1＋差÷10%のため）。来店者が限られると、見かけの前の率が振れるので4.16〜4.66店になった

### どちらの並べ方が「本当の効き目」の上位5店を当てるか（基本の置き方、1,000回の平均）
| 型 | 本当の差の上位5店：差で並べる／比で並べる | 本当の比の上位5店：差で並べる／比で並べる |
|---|---|---|
| 足し算型 | **2.26店**／1.49店 | 1.03店／**3.40店** |
| 掛け算型 | **3.68店**／0.81店 | 1.63店／**1.96店** |

- 本当の効き目を「差」で決めれば差で並べるほうが、「比」で決めれば比で並べるほうが当たった。どちらが正しい並べ方かは、何を効き目と決めるかの写しである
- ただし、比で並べる当たりは、来店者の数に強く左右された。掛け算型・前の率2〜30%で、本当の比の上位5店を比で並べて当てたのは、来店者0.2倍で1.09店、1倍で1.96店、5倍で3.08店。来店者0.2倍では、差で並べたほう（1.36店）が比で並べるより多く当てた。前の率の低い店は買った人が少なく、見かけの比が大きく振れるため
- 確かめの40通りのうち振れのある30通りで、本当の比の上位を比で並べたほうが多く当てたのは19通り。残りの11通りは、前の率が10%でそろう6通り、8〜12%の掛け算型2通り、来店者0.2倍の掛け算型3通り（5〜20%・2〜30%・1〜50%）で、差で並べたほうが同じか多く当てた（`which_wins` に一覧）

- 比の上位に前の率の低い店が集まることは「比＝1＋差÷前の率」の式から決まる結果で、データから見つけたものではない。数えたのは、その入れかわりの大きさと、来店者が限られるときの当たり方

## 注意（言えないこと）
- 架空のデータです。前の率の散らばり、来店者の数、施策の効き方（足し算型・掛け算型、その大きさ）は作成者が置いたもので、結果はこれで決まります。実在の会社・店の数字を表すものではありません
- 差と比のどちらで比べるのが正しいかは、この記事では決めていません。「来た人のうち何人多く買ったか」を知りたいなら差、「元の水準から何倍になったか」を知りたいなら比、と目的で変わります（目的の決め方は扱いません）
- 施策の効き方が店の前の率と関係する置き方（前の率の低い店ほど上がりやすい、など）は入れていません。そうした関係があれば、入れかわりの大きさは変わります
- 店の大きさ（来店者数）をかけた「増えた購入の人数」で並べる比べ方は扱っていません
- 関連する記事として、反応率の分母（フォロワー・表示・再生）を変えると良い投稿が入れかわる 837、勝ち点と勝率で順位が入れかわる 832 があります。同じ企画では、「10%から12%」を2ポイントと書くか20%増と書くかの違いを 897、小さい数からの「300%増」がどこまで意味を持つかを 903 で扱っています。この記事は、同じ2つの割合から出す「差」と「比」の違いに絞りました
- 同じ企画の 900 は、店ごとの購入率の平均と合計どうしで割った率の違い（全体の率の出し方）を扱っています。この記事は、店ごとの前後の変化を差と比のどちらで並べるか（店どうしの比べ方）で、問いは重ならない
