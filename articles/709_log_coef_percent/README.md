# 709 y を対数にした回帰の係数を「そのまま%」と読むと、効果が大きいときどれだけずれるのか（手法の解説・正解の分かるデータで試す）

`log(y) = a + b×施策 + 誤差` の回帰で、係数 b を「施策で y が b×100% 変わる」と読むことがよくあります。これは b が0に近いときの近似で、本当の変化は exp(b)−1 です。**ここでは、係数と本当の変化の差を式で出したうえで、架空の店（施策あり・なし各50店、対数の誤差の標準偏差0.5）で本当の効果を−60%〜+200%に置き、各3,000回、3つの読み方の平均を本当の値と比べました。** 数字は置いた前提で決まります。

|---|---|---|---|
| A709 | 係数×100 と exp(係数)−1 はどれだけ違い、推定ではどう出るか | 式によるずれの曲線、各50店×3,000回のシミュレーション。読み方は係数×100、exp(係数)−1、ケネディの補正 exp(係数−分散/2)−1。statsmodels の OLS と一致を確認。seed 709 | `src/a709_logcoef.py` |

## 主な結果
- **ずれが1ポイントを超えるのは**、係数が+0.14（本当は+15.0%）か−0.15（本当は−13.9%）を超えたとき
- **大きい効果では大きくずれる**：係数0.30は「30%」と読めるが本当は+35.0%。係数0.69は「69%」→本当は **+99.4%（ほぼ2倍）**。係数−0.69は「−69%」→本当は−49.8%。係数1.10は「110%」→本当は+200%
- **プラスは小さく、マイナスは大きく読む**：本当の−60%は係数−0.92で、「−92%」と読める
- **推定の平均**：本当の+50%のとき、係数×100 の平均は40.6、exp(係数)−1 は50.8（わずかに大きい）、ケネディの補正は50.0。−60%では−91.6・−59.8・−60.0

## 注意（言えないこと）
- シミュレーションの結果。誤差の散らばりが群で違うと、exp(係数)−1 は中央値の比になり、平均の比とは一致しない
- 連続の x（1単位あたり）でも、読み方の式は同じ。ただし「1単位」が大きいと同じように大きくずれる
- y に0を含む場合（log(y+1) など）は別の問題で、ここでは扱っていない
