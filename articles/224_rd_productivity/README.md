# 224 研究開発をする企業ほど、生産性は高いのか：企業活動基本調査の業種別データで見る

経済産業省「経済産業省企業活動基本調査」（2025年確報、2020〜2024年度実績）の業種別集計で、研究開発費の比率（研究開発費÷売上高）と労働生産性（付加価値額÷従業者数）の関係を、製造業とそれ以外の交差項を入れた回帰で見たフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A224 | 研究開発に力を入れる業種ほど、生産性は高いか。製造業とそれ以外で違うか。同じ業種の中でも言えるか | 126業種×5年度のパネル。log(生産性) を log(1+研究開発費比率)・製造業ダミー・その交差項・1社あたり従業者数・年度で回帰（業種でクラスタした標準誤差）。研究開発をした企業の割合でも推定。業種の固定効果モデル。製造業の4分位比較 | `src/a224_rd_productivity.py` |

## 主な結果
- 2024年度の業種別の相関（対数）は、製造業59業種で0.50、製造業以外67業種で0.23。研究開発費比率の中央値は製造業2.1%、製造業以外0.03%（製造業以外の21業種は研究開発費0）
- 交差項モデルでは、研究開発費比率が1%→5%の業種は、製造業で生産性が16%高い（95%信頼区間 +6〜+27%）。製造業以外は+35%（+2〜+80%）と幅が広く、交差項（傾きの差）ははっきりしない（p=0.26）。学術・開発研究機関（比率40%）を除くと、製造業以外の傾きは+81%（+25〜+162%）に変わり、数業種に左右される
- 「研究開発をした企業の割合」で見ても同じ向き（10ポイント高いと、製造業以外で+22%、製造業で+6%）
- 製造業59業種を研究開発をした企業の割合で4つに分けると、生産性の中央値は 941万円（割合の中央値29%）→1,105万円→1,143万円→1,501万円（71%）
- 業種の固定効果を入れて「同じ業種の中で、研究開発費比率が高い年ほど生産性が高いか」を見ると、1%→5%で+2%（−2〜+6%）と関係は見えない。5年分の業種の中の変化は小さく、研究開発の成果が出るまでの時間も入っていない

## 動かし方
```
pip install -r requirements.txt
cd src && python a224_rd_productivity.py
```

## データ
- `data/t1_raw.csv`：第1巻 第1表（産業別、企業数・従業者数・売上高・経常利益・付加価値額など、2020〜2024年度）
- `data/t10_raw.csv`：第1巻 第10表（産業別、研究開発を行った企業数・売上高・研究開発費・売上高研究開発費比率など）
- `data/t9_raw.csv`：第1巻 第9表（研究開発への取組状況、参考）
- `results/panel_industry_year.csv`：分析に使った126業種（3桁の細分類。下に細分類がある業種の合計行は除く）×5年度
- `results/regressions.csv`：5つのモデルの係数・標準誤差・p値
- `results/slope_by_group.csv`：交差項モデルの製造業・製造業以外の傾きと「1%→5%」の差
- `results/mfg_quartiles_2024.csv`・`corr_2024.csv`：製造業の4分位と2024年度の相関

## 注意
- 個々の企業のデータ（個票）ではなく、業種ごとの合計から作った値です。「研究開発をする企業ほど生産性が高い」かは直接は分からず、「研究開発に力を入れる業種ほど生産性が高いか」を見ています
- 調査の対象は従業者50人以上かつ資本金3,000万円以上の企業です。小さな企業は入っていません
- 付加価値額÷従業者数は、電気・ガスや物品賃貸のように設備が大きい業種で高くなります。資本の量は入れていません
- 相関や回帰の係数は因果ではありません。生産性が高く利益の出る業種が研究開発にお金を回している、という逆向きの関係もありえます
- 秘匿（X）の値は欠けとして扱いました
