# F290 計画（事前登録）：アンケートの回答の偏りは、重み付けでどこまで補正できるか

作成：2026-11-11。シミュレーションの結果を見る前に書いた。

## 問い

Web パネルや社内外のアンケートは、答える人が偏る。年齢・性別に合わせて重みを付ければ直る、とよく扱われるが、
(1) どの項目に合わせれば、どこまで直るのか、
(2) 「答えるかどうか」が知りたい項目そのものに関わるとき、重み付けで直らないことを、手元のデータで気づけるのか、
を、答えが分かっている母集団で確かめる。F117（国民生活基礎調査の回収率と所得）は公表表での補正の効き方を見た。今回は実務の手順（補正に使う項目の選び方と、補正できたかの確かめ方）に絞る。

## 母集団（答えが分かっているもの）

- 総務省「令和4年就業構造基本調査」第52表（全国、有業者）の6変数の多重クロス表（F139・F147 と同じ表、statInfId 000040077317）。男女(2)×年齢(7)×本業の雇用形態(4)×本業の所得(16)×本業の就業時間(4)×副業の有無(2)。就業時間の「総数」は除く。
- 値は推計人口（約6,335万人）。この表を「全数」とみなす。
- 事前に見たもの：この表の1変数の周辺（副業ありの割合 約5%など）は F139・F147 で見ている。シミュレーションの結果は見ていない。

## 知りたい項目（アウトカム）

- 副業ありの割合（本当の値は表から計算）。

## 回答の仕組み（シミュレーション）

母集団から招待者 N=25,000人を抜き出し、各人が確率 p で答える。logit p = a + 年齢 + 男女 + 雇用形態 + 就業時間 + 所得 + δ×副業あり。

係数（Web アンケートでよく言われる傾向を置いた仮定。推測）：
- 年齢：15〜24歳 0、25〜34 +0.3、35〜44 +0.3、45〜54 +0.1、55〜64 −0.2、65〜74 −0.6、75歳以上 −1.2
- 男女：女 +0.2
- 雇用形態：正規 0、非正規 +0.2、役員 −0.5、自営業主など −0.4
- 就業時間：週35〜59時間 0、週35時間未満 +0.3、週60時間以上 −0.6、200日未満 +0.3
- 所得：200万円未満 +0.2、200〜699万円 0、700万円以上 −0.3
- a は全体の回答率が約20%（回答者 約5,000人）になるよう決める。

場面：
- S1 年齢・男女だけで答えが決まる（上の年齢・男女の項だけ）
- S2 観測できる5項目で決まる（MAR）
- S3 S2 ＋ 副業ありほど答えやすい（δ = log 2、オッズ2倍）（MNAR）

各場面500回くり返す。乱数の種は 290。

## 補正の方法

- M0 重みなし
- M1 男女×年齢の事後層化（14セル）
- M2 男女・年齢・雇用形態の周辺に合わせるレーキング
- M3 男女・年齢・雇用形態・就業時間・所得（6区分）の周辺に合わせるレーキング
- M4 男女×年齢×雇用形態の事後層化（56セル。回答者0のセルは M2 で代える）

## 評価

- 副業ありの割合の偏り（500回の平均−本当の値）、RMSE、95%区間（Kish の設計効果で広げた正規近似）が本当の値を含む割合
- Kish の設計効果 1＋（重みの変動係数）²
- 補正に使っていない「答えの分かっている項目」（所得・就業時間の分布）の全変動距離 TVD。比べる目安は、回答の偏りがない無作為の回答者で同じ人数のときの TVD の95%点

## 仮説と「外れ」の基準

- H1：S2 で、M1（男女×年齢）は M0 の偏りの半分未満しか減らさない。外れ：半分以上減る。
- H2：S2 で、M3 は M0 の偏りの90%以上を消す（|偏り M3| ≤ 0.1×|偏り M0|）。外れ：消せるのが90%未満。
- H3：S3 で、M3 の偏りは2ポイント以上残り、95%区間が本当の値を含むのは50%未満。外れ：どちらかが満たされない。
- H4：S3 で、所得を使わないレーキング（男女・年齢・雇用形態・就業時間）の後、所得の分布の TVD は無作為の回答者の95%点より小さい（＝補正に使っていない項目では合っているように見える）のに、副業ありの割合の偏りは2ポイント以上残る。外れ：TVD が95%点以上（確かめで気づける）、または偏りが2ポイント未満。
- H5：S2 で、M3 の設計効果は1.3以上。外れ：1.3未満。

## 頑健性（少なくとも3つ）

- R1 回答率を10%・40%にする
- R2 係数をすべて0.5倍・2倍にする
- R3 回答者を約2,000人・約20,000人にする
- R4 2017年の表を母集団にする
- R5 所得を4区分にしてレーキング
