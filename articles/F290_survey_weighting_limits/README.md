# F290 アンケートの回答の偏りは、重み付けでどこまで直せるか？（答えの分かる母集団で試す）

Web アンケートや社内外の調査では、答える人が偏る。「年齢・性別に合わせて重みを付ければ直る」とよく扱われるが、どの項目に合わせればどこまで直るのか、直らないことに手元のデータで気づけるのかは、本当の値が分からないと確かめられない。そこで、総務省「令和4年就業構造基本調査」の多重クロス表（有業者 約6,335万人）を「答えが分かっている母集団」とみなし、そこから招待・回答をシミュレーションして、重み付けの効き方を確かめた。知りたい項目は「副業ありの割合」（本当の値 4.92%）。

計画（仮説と外れの基準）は結果を見る前に書いて GitHub に置いた（[PLAN.md](PLAN.md)、コミット 53e4452。コード・結果・図のコミットはすべてこの後）。

F117（国民生活基礎調査の回収率と所得）は、公表表で補正の効き方を見た。今回は実務の手順、つまり「補正に使う項目の選び方」と「補正できたかの確かめ方」に絞った。

## 問い

- 回答の偏りが観測できる項目（年齢・男女・雇用形態・就業時間・所得）で決まるとき、どの項目に合わせれば、知りたい項目の偏りはどこまで消えるか
- 「答えるかどうか」が知りたい項目そのもの（副業の有無）にも関わるとき、重み付けでどこまで直るか
- そのとき、補正に使っていない「答えの分かっている項目」で確かめれば、直っていないことに気づけるか

## データ

- 総務省「令和4年就業構造基本調査」第52表（全国、有業者）。男女(2)×年齢(7)×本業の雇用形態(4)×本業の所得(16)×本業の就業時間(4)×副業の有無(2)。就業時間の「総数」は除いた（合計 63,349,400人、副業ありの割合 4.924%）。母集団の範囲：表の有業者総数は 67,060,400人、男女・年齢・所得・副業の内訳をすべて持つ人（就業時間は総数）は 64,297,400人で、就業時間4区分に分かれる人に絞ると 63,349,400人になる。この記事の「母集団」はこの約6,335万人。F139・F147 と同じ表で、整形も同じ（`src/zz_f290_02_整形.py`）。
- 頑健性に「平成29年就業構造基本調査」の同じ表（副業ありの割合 4.116%）。
- 役員は「雇用者−正規−非正規」、自営業主などは「総数−雇用者」の引き算で作った。2022年の表の母集団に使う行のうち255行で役員が負になり（合計 −25,500人、母集団の0.04%）、0にした（元の表全体では総数・小計の行を含めて948行が負）。自営業主などが負になる行はなかった。
- 6変数の組み合わせ 7,168セルのうち 2,297セルは0人で、母集団から外した（0人のセルは招待されないので結果は変わらない）。
- 新しい取得はしていない（`src/zz_f290_01_取得.md`）。

## 手法

**シミュレーション**：母集団から招待者を抜き出し（多項分布）、各人が確率 p で答える（二項分布）。回答率は約20%、回答者は約5,000人（招待者25,000人）。各場面500回、乱数の種 290。

logit p = a ＋ 年齢 ＋ 男女 ＋ 雇用形態 ＋ 就業時間 ＋ 所得 ＋ δ×副業あり

係数は「Web アンケートで言われる傾向」を置いた仮定（推測）。年齢（15〜24歳 0、25〜34・35〜44歳 +0.3、45〜54歳 +0.1、55〜64歳 −0.2、65〜74歳 −0.6、75歳以上 −1.2）、女 +0.2、雇用形態（非正規 +0.2、役員 −0.5、自営業主など −0.4）、就業時間（週35時間未満・200日未満 +0.3、週60時間以上 −0.6）、所得（200万円未満 +0.2、700万円以上 −0.3）。a で回答率を合わせた。

| 場面 | 答えるかどうかを決めるもの |
|---|---|
| S1 | 年齢・男女だけ |
| S2 | 観測できる5項目（年齢・男女・雇用形態・就業時間・所得） |
| S3 | S2 ＋ 副業ありの人はオッズ2倍（δ = log 2。頑健性 R2 で係数を c 倍するときは δ も c 倍になる） |

**補正の方法**（母集団の構成は正しく分かっているとする）

| 記号 | 方法 |
|---|---|
| M0 | 重みなし |
| M1 | 男女×年齢の事後層化（14セル） |
| M2 | 男女・年齢・雇用形態の周辺に合わせるレーキング |
| M3 | 男女・年齢・雇用形態・就業時間・所得（6区分）の周辺に合わせるレーキング |
| M4 | 男女×年齢×雇用形態の事後層化（56セル。回答者0のセルがあれば M2 で代える） |
| M2h | 男女・年齢・雇用形態・就業時間でレーキング（所得を「確かめ用」に残す。H4 用） |

**評価**：副業ありの割合の偏り（500回の平均−本当の値、ポイント）、標準偏差、RMSE、95%区間（Kish の設計効果で広げた正規近似）が本当の値を含む割合、Kish の設計効果。補正に使っていない項目（所得6区分・就業時間4区分）の分布のずれは全変動距離（TVD）で測り、偏りのない無作為の回答者5,000人のときの TVD の95%点（所得 0.0202、就業時間 0.0159。2,000回）と比べた。

## 結果

### 1. 回答者の構成（回答率20%、期待値。図1）

- S2 の回答者は、母集団より 25〜44歳・非正規が多く、55歳以上・役員・自営業主などが少ない。
- 副業ありの割合は、S2 の回答者で 5.1%（本当の値 4.9%）とほぼ変わらない。S3 では 8.0% になる。

### 2. 方法ごとの偏り（ポイント、500回の平均。図2・図3）

| 場面 | M0 重みなし | M1 男女×年齢 | M2 ＋雇用形態 | M3 ＋就業時間・所得 | M4 56セル |
|---|---|---|---|---|---|
| S1 | −0.26（区間の当たり 83%） | −0.00（94%） | −0.00（95%） | −0.00（94%） | −0.00（95%） |
| S2 | +0.23（89%） | +0.34（82%） | +0.19（90%） | +0.02（93%） | +0.19（90%） |
| S3 | +3.12（0%） | +3.39（0%） | +3.19（0%） | +2.96（0%） | +3.19（0%） |

- 1回ごとのぶれ（標準偏差）は 0.30〜0.43 ポイント。偏りの500回の平均の誤差は約 0.016 ポイント。
- S2 では、重みなしの偏りはもともと小さい（+0.23。ぶれの標準偏差 0.32 より小さい）。男女×年齢だけで合わせると偏りは +0.34 に大きくなった。5項目すべてで合わせると +0.02 になった。
- M1 で偏りが広がった理由（推測を含む）：S1（年齢・男女だけで答えやすさが決まる場面）では重みなしの偏りが −0.26 で、年齢・男女の偏りだけなら副業ありの割合は下に引っぱられる。母集団の副業ありの割合は、答えやすい層（非正規 7.3%、200日未満 8.9%、所得100万円未満 8.7%）でも、答えにくい層（65歳以上 7.9%、役員 9.4%、自営業主など 8.9%）でも高い。S2 の重みなしが +0.23 にとどまったのは、雇用形態・就業時間・所得による上向きの偏りが、年齢・男女による下向きの偏りとおおむね打ち消し合っていたためと考えられる。男女×年齢に合わせると答えにくい側だけが直り、答えやすい側の偏りが残る（正規 2.6%、週35〜59時間 3.2%）。
- S3 では、どの方法でも偏りは約3ポイント残り、95%区間は500回とも本当の値を含まなかった。5項目の重み付けで消えたのは偏りの5%。
- M4（56セルの事後層化）は、S1〜S3 の 86〜95% の回で回答者0のセルがあり、M2 で代えた（女15〜24歳の役員などは母集団の0.01%で、回答者約5,000人では期待値0.3人）。

### 3. 仮説の判定

| 仮説 | 基準 | 結果 | 判定 |
|---|---|---|---|
| H1 S2 で男女×年齢は偏りの半分未満しか減らさない | 減る割合 < 50% | 減るどころか 46% 増えた（+0.23→+0.34） | 支持 |
| H2 S2 で5項目のレーキングは偏りの90%以上を消す | |M3| ≤ 0.1×|M0| | 89.7%（+0.23→+0.024） | 外れ（境目。500回の誤差を考えると90%と区別できない） |
| H3 S3 で M3 の偏りは2ポイント以上・区間の当たりは50%未満 | 両方 | +2.96 ポイント、0% | 支持（基本の条件。頑健性では係数0.5倍で +1.40 と2ポイントに届かず、回答率40%では +2.02 で境目） |
| H4 S3 で所得を確かめに残すと、所得のずれはぶれの範囲なのに偏りは2ポイント以上 | TVD < 95%点 かつ 偏り ≥ 2 | 所得の TVD 0.028 > 0.020（確かめは「合っていない」と出る）、偏り +2.96 | 外れ |
| H5 S2 で M3 の設計効果は1.3以上 | ≥ 1.3 | 1.23 | 外れ |

- H4 の補足：所得の TVD は S2（副業が答えやすさに関係しない）でも 0.028、S3 でも 0.028 で同じだった（図4）。確かめで「所得が合っていない」と気づけても、それは S2 と S3 で同じように出るので、知りたい項目が直っているかどうかは見分けられない。なお、比べる目安（0.020）は重みなしの無作為の回答者5,000人から作った。M2h は設計効果が約1.21あり、重み付き推定のずれはその分大きく出やすいので、目安はやや厳しめになっている。ただ S2 と S3 で同じ値になる点は目安によらない。
- H2 の補足：重みなしの偏りがぶれより小さい場面では「何割消えたか」が安定しない（頑健性では 24〜99% と動く）。基準を割合にしたのは計画の甘さだった。基本の条件を200回で流した頑健性の行（base200）では 91.5%（+0.228→+0.019）で「支持」になり、500回の 89.7% と合わせて、9割と区別できないことを裏づける。

### 4. 頑健性（各200回。B_robust.csv）

| 条件 | S2 の偏り（M0 → M1 → M3） | S3 の偏り（M0 → M3） | M3 の設計効果（S2） |
|---|---|---|---|
| 基本 | +0.23 → +0.34 → +0.02 | +3.13 → +2.98 | 1.23 |
| R1 回答率10% | +0.29 → +0.40 → +0.03 | +4.03 → +3.63 | 1.29 |
| R1 回答率40% | +0.11 → +0.22 → +0.02 | +1.98 → +2.02 | 1.13 |
| R2 係数0.5倍（S3 のオッズ約1.41倍） | +0.07 → +0.14 → −0.00 | +1.49 → +1.40 | 1.05 |
| R2 係数2倍（S3 のオッズ4倍） | +0.52 → +0.61 → −0.00 | +6.05 → +6.85 | 2.26 |
| R3 回答者約2,000人 | +0.24 → +0.34 → +0.04 | +3.17 → +2.95 | 1.24 |
| R3 回答者約20,000人 | +0.20 → +0.30 → −0.01 | +3.13 → +2.96 | 1.22 |
| R4 2017年の母集団 | +0.07 → +0.18 → −0.05 | +2.53 → +2.52 | 1.26 |
| R5 所得4区分 | +0.23 → +0.34 → +0.02 | +3.13 → +2.98 | 1.23 |

- 男女×年齢だけの補正が S2 の偏りを大きくする（H1）のは、8つの条件（R1〜R5）すべてで同じ。R5（所得の区切り）は M1 に使わないので、M1 の結果には影響しない。
- R2 は係数を c 倍し、副業の δ も c 倍した。係数0.5倍の S3 は副業ありのオッズが約1.41倍、2倍の S3 はオッズ4倍の場面になる。
- S3 で5項目の補正後に区間が本当の値を含む割合は、どの条件でも0〜2%。係数2倍では、重み付けで S3 の偏りがむしろ大きくなった（+6.05→+6.85）。
- H3 の「2ポイント以上」は、すべての条件では成り立たない。係数0.5倍（オッズ約1.41倍）では M3 の偏りは +1.40 で2ポイントに届かない（区間の当たりは2%で、外れる点は同じ）。回答率40%では +2.02 で境目にあり、重み付けで偏りがわずかに広がった（+1.98→+2.02）。
- 回答率は、R1 では回答者が約5,000人になるよう招待者を変えた（計画には書いていない。ずれ）。
- data/raw と src だけの別のフォルダで 02→03→04 を流し直し、整形データ・results・図の11ファイルがバイト単位で一致した。
- 回答者を増やすと、ぶれが小さくなって偏りの比重が上がる。S2 で回答者約20,000人のとき、重みなしの区間の当たりは 74%、5項目の補正後は 93%（図5）。

## もう一度問う（結果を見てから足した問い）

「副業ありの人が答えやすい」程度がどれくらいなら、補正後の偏りが標本のぶれを超えるか。オッズ比を 1.0〜3.0 で動かし、各300回で M3 を見た（C_tipping.csv、図6）。

| オッズ比 | 1.0 | 1.1 | 1.2 | 1.3 | 1.5 | 2.0 | 3.0 |
|---|---|---|---|---|---|---|---|
| M3 の偏り（ポイント） | +0.02 | +0.34 | +0.72 | +1.03 | +1.62 | +2.98 | +5.05 |
| 95%区間の半幅 | 0.67 | 0.68 | 0.71 | 0.73 | 0.76 | 0.83 | 0.92 |
| 区間が本当の値を含む割合 | 94% | 83% | 46% | 16% | 0% | 0% | 0% |

- 副業ありの人が「1.2倍答えやすい」だけで、区間が本当の値を含むのは 46% に下がった。このとき補正後の偏り +0.72 は区間の半幅 0.71 とほぼ同じ（差 0.014 は300回の平均の誤差 約0.021 より小さい）。
- 偏りがないとき（オッズ比1.0）でも、M3 の区間の当たりは 93〜94% で95%に少し届かない。Kish の設計効果で広げた標準誤差（S2 で 0.339）が、500回の実際のぶれ（0.358）より小さいため。
- このあいだ、所得を確かめに残したときの所得の TVD は 0.028〜0.029 でほぼ動かなかった（図4）。

## 計画からのずれ

- R1（回答率10%・40%）は、回答者の数をそろえるため招待者を 50,000人・12,500人に変えた（計画では回答率だけを変えると書いた）。
- H4 の「TVD が95%点より小さい」は、500回の TVD の平均で判定した（計画では平均か1回ごとかを決めていなかった）。
- M4 は回答者0のセルが出る回が86〜95%あり、計画どおり M2 で代えたので、ほとんど M2 と同じ値になった。
- もう一度問う（オッズ比の変化）は計画の候補どおり。結果を見たあとで、図4のために M2h も残すようにした。
- PLAN を書く前に、母集団の表の1変数の周辺（副業ありの割合など）は F139・F147 で見ていた（PLAN に記載）。

## 言えないこと

- 回答の仕組みと係数は置いた仮定で、実際の Web アンケートの値ではない（推測）。結論は「この仕組みのもとで」の話。
- 母集団の構成（男女・年齢・雇用形態・就業時間・所得）は正しく分かっているとした。実務では、合わせる先の数字にもずれや古さがある。
- 母集団は推計人口の表で、個人の記録ではない。表のセルを母集団の人の集まりとみなした。
- 重み付けの方法は事後層化とレーキングだけ。回帰で補う方法、傾向スコアで重みを作る方法（答えなかった人の情報が要る）は試していない。
- 区間は Kish の設計効果で広げた正規近似で、レーキングの分散を正確には出していない。

## レビューで直したこと

独立レビュー（別のエージェントが記事を見ずにコードと結果を確かめた）で、数字の一致、レーキングの収束、クリーンな再実行のバイト一致を確認。指摘を受けて次を直した（新しい数字は自分で計算し直した）。

- H3 の「2ポイント以上」が頑健性のすべての条件で成り立つように読めた。係数0.5倍で +1.40（届かない）、回答率40%で +2.02（境目、重み付けで +1.98→+2.02 と広がる）を明記。
- 係数を c 倍すると副業の δ も c 倍になることを明記（係数2倍の S3 はオッズ4倍、0.5倍は約1.41倍）。
- 問い直しの「1.2倍で偏りが区間の半幅を超える」は言い過ぎだった（0.721 対 0.707、差は平均の誤差 約0.021 より小さい）。「ほぼ同じ」に改め、区間の当たり 46% を中心に書き直し。偏り0でも当たりが 93〜94% になること（Kish の標準誤差 0.339 ＜ 実際のぶれ 0.358）を追記。図6の題も直した。
- 母集団の範囲（表の総数 6,706万人、内訳を持つ 6,430万人、就業時間4区分の 6,335万人）、役員・自営業主などを引き算で作り負の255行を0にしたこと、0人の 2,297セル（7,168中）を外したことを明記。
- M1 で偏りが広がる理由に、S1 の重みなしの偏り（−0.26）を根拠として足し、推測であることを明記。
- 「8つの条件」の中身（R1〜R5、所得の区切りを含む）と、R5 が M1 に影響しないことを明記。
- H2 の境目に、200回の基本条件では 91.5% で支持になることを追記。
- 所得の確かめの目安（0.020）が重みなしの無作為抽出から作ったもので、設計効果約1.21の M2h にはやや厳しめであることを追記。
- requirements.txt の版を、再実行に使った版に固定。
