# 629 相関の強い2つの列があると、並べ替えの重要度はどれだけ小さく出るのか（手法の解説・正解の分かるデータで試す）

並べ替えの重要度は、確かめのデータで1列の値をばらばらにしたとき、予測がどれだけ悪くなるかで列の効き目を測ります。よく似た列がもう1つあると、モデルが2つの列に頼りを分けたり、外した列の代わりをもう1つが果たしたりして、効き目が小さく出ることがあります。**ここでは、売上に効く x1 と、x1 と相関 ρ を持つが売上には効かない x2 がある架空の店のデータで、ρ を0〜0.99と変え、ランダムフォレストの「x1 だけ並べ替え」「x1 と x2 をまとめて並べ替え」「x1 を外して学習し直す」の3通りで x1 の効き目を測りました。** 各 ρ で12回。数字は置いたデータで決まります。

## 主な結果
- **x1 だけ並べ替えた重要度**：ρ=0 で 1.14、0.5 で 1.13、0.8 で 1.13、**0.95 で 1.00（−13%）、0.99 で 0.71（−38%）**。効かない x2 の重要度は 0.95 で 0.010、0.99 で 0.066
- **x1 と x2 をまとめて並べ替えた重要度**：どの ρ でも 1.12〜1.14 で、ほぼ変わらない
- **x1 を外して学習し直したときの差**：ρ=0 で 0.62、0.5 で 0.47、0.8 で 0.23、0.95 で 0.06、**0.99 で 0.016（−97%）**。x2 が x1 の代わりを果たすので、「なくても困らない」と出る
- 予測の当たり方（R²）は、どの ρ でも 0.68 前後で変わらない
- R² の下がり方が1を超えるのは、並べ替えると予測が「平均をそのまま言う」より悪くなるため
