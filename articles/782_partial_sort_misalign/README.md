# 782 表の1列だけを並べ替えると、何行の値が別の行とつながってしまうのか（実務の型）

Excel で表の1列だけを選んで並べ替えると、その列だけが動き、ほかの列はそのまま残ります。並べ替えの前に確認が出ることもありますが（推測。Excel では未検証）、そのまま進めると、各行の値が別の顧客のものになります。合計は変わらないので、合計で確かめても気づけません。**ここでは、作成者が乱数で作った架空の顧客表2,000人で、「今年の購入額」の列だけを降順に並べ替えた場合を Python で再現し（Excel では未検証）、どれだけの行がずれ、集計がどう変わるかを見ました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A782 | 1列だけ並べ替えると、何行がずれ、集計はどう変わるか | 架空の顧客2,000人（顧客番号・会員ランク・前年の購入額・今年の購入額）。ランクは前年の購入額の上位10%がゴールド、次の30%がシルバー。今年と前年の相関0.87。「今年の購入額」の列だけを降順に並べ替える操作を再現。元の表の並びが顧客番号の順・前年の購入額の順の2通り。顧客番号での照合を DuckDB（1スレッド）で行い、Python と一致を確認。seed 782 | `src/a782_partial_sort.py`、`src/02_check_duckdb.sql`、`src/01_check_tsql.sql` |

## 主な結果

| | 正しい | 1列だけ並べ替え（元は顧客番号の順） | 1列だけ並べ替え（元は前年の順） |
|---|---|---|---|
| 別の顧客の値が入った行 | 0 | **1,993行（99.7%）** | 1,980行（99.0%） |
| 1行あたりのずれ | — | 2.5万円 | 0.8万円 |
| ゴールドの平均購入額 | 8.4万円 | **3.0万円** | 9.3万円 |
| 一般の平均購入額 | 1.6万円 | 3.0万円 | 1.5万円 |
| 前年との相関 | 0.87 | **0.00** | **0.99** |
| 購入額の合計 | — | 差0円 | 差0円 |

- どちらの場合も、ほぼすべての行（99〜99.7%）に別の顧客の購入額が入った。合計は変わらなかった
- 元が顧客番号の順だと、ランクの差がほぼ消え（ゴールド3.0万円・一般3.0万円）、前年との相関も0になった
- 元が前年の購入額の順だと、ずれた表のほうが前年との相関が強く（0.99）、ランクの差も大きく見えた。数字がそれらしいので、かえって気づきにくい

## 動かし方
```
pip install -r requirements.txt
cd src && python a782_partial_sort.py
```
数秒で終わります。`data/customers.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダで流し直し、results・figures・data が一致した
- 顧客番号で照合したずれた行の数と、ずれの合計が DuckDB と Python で一致し、購入額の合計の差が0になること（assert）

## データ
- `data/customers.csv`：架空の顧客表（customer_id・rank・prev_amount・amount。並べ替える前の正しい表）

## 注意（言えないこと）
- 架空のデータです。購入額の分布と前年との相関は作成者が置いたもので、ずれの大きさはこれで決まります
- Excel の動き（1列だけ並べ替える操作、確認の表示）は Python で再現したもので、Excel では未検証です
- T-SQL 版は未検証です
