# 251 結論が逆になったとき、何を見落としていたか（④ 振り返り R005）

このシリーズで、結論が外れたり、公開前の見直しで題名や結論を直したりした記録を数えたフォルダです。初期の3本を作り直した [F161](https://github.com/takayuki-0127/japan-open-data-notes/tree/main/articles/F161_rewrite_old_articles)、頑健性チェックで結論が動いた割合を数えた [F163](https://github.com/takayuki-0127/japan-open-data-notes/tree/main/articles/F163_robustness_checks_review)、言い方の直しを数えた [242](https://github.com/takayuki-0127/japan-open-data-notes/tree/main/articles/242_limits_section_writing) とは別に、「結論が動いたとき、何を見落としていたか」に絞りました。

## 問い

- 計画（PLAN）を先に書いた記事で、仮説はどのくらい外れたか
- 公開前の見直しで題名・結論・判定を動かした直しは、何を見落としていたものだったか

## 手法

| 手順 | 中身 |
|---|---|
| 仮説の判定 | 計画を先に書いた記事（F256〜F295 と T）の README の表から「H1」「H2」…の行を拾い、最後の列（判定）を「支持」「外れ」「一部・保留」「その他（数値だけ等）」に分けた |
| 結論を動かした直し | 「レビューで直したこと」の項目（箇条書きと表の行）のうち、題名・結論・判定・向きを動かした言葉（題名・結論・判定・逆・符号・取り下げ・削除・弱め・消え・誤り）がある項目を拾った。「結論は変わらない」などは除いた |
| 見落としの種類 | 拾った項目を8つの種類の言葉で分けた（1項目に複数つく）。乱数（seed 7）で12項目を選んで目で確かめ、12項目とも題名・結論・判定を動かした直しだった（`data/precision_check.csv`） |

## 主な結果

- 計画を先に書いた35本の仮説159個のうち、支持107、外れ39（25%）、一部・保留1、その他12。外れが1つ以上あった記事は25本（35本中）
- 見直しの記録がある40本・382項目のうち、題名・結論・判定を動かした項目は105（38本）
- その105項目の見落としの種類（`results/cause_counts.csv`、図2）：

| 種類 | 項目 | 記事 |
|---|---|---|
| 結果を限る条件を書いていなかった | 31 | 23 |
| 1つの月・年・単位に頼っていた | 26 | 16 |
| 言葉の強さ・因果 | 21 | 18 |
| 幅・不確かさを出していなかった | 18 | 14 |
| 期間・起点の選び方 | 16 | 12 |
| 計算・コードの誤り | 15 | 14 |
| 定義・測り方・分け方の違い | 14 | 12 |
| 比べる基準・偶然の幅 | 13 | 11 |

- どの種類の言葉にも当たらなかった項目は23。向きが逆になったことを示す言葉（逆・符号）がある項目は14、弱めた・外したことを示す言葉がある項目は28。結論が「逆になる」より「限られる・弱まる」ほうがずっと多い
- 実際の例（`data/cases.csv`、図3）：F289（1部門が一部の比較にだけ入っていた）、F264（相関が2020年の1年に頼っていた）、F261（比べた手法の数が年で違った）、F273（有利な比べる相手）、F291（説明の数字が合わなかった）、F161（標本の入れ替えを見ていなかった）

## データ

| ファイル | 中身 |
|---|---|
| data/hypotheses.csv | 仮説の行（記事・仮説・判定・判定の列の先頭80字） |
| data/review_items.csv | 見直しの項目（記事・結論を動かしたか・種類・先頭300字） |
| data/precision_check.csv | 目で確かめた本数と当たり |
| data/cases.csv | 図3の例（README から作成者が選んだ） |

## 注意（言えないこと）

- README に書き残したことだけを数えている。見直しの記録があるのは主に精選の記事なので、ほかの記事でどうだったかは分からない
- 判定と種類は言葉で分けた。種類の分け方には外れと取りこぼしがあり、目で確かめたのは「結論を動かした」かどうかの12項目だけ
- 仮説が外れたことは、分析の誤りではない。外れの基準を先に決めていたから、外れたと書けた
- 見落としの種類の多い少ないは、記事の題材（時系列が多い・県の比較が多い）にも左右される
