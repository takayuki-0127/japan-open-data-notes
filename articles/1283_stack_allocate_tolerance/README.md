# 1283 組み立て品の許容差を先に決めて部品に割り振るとき、二乗の足し算で割り振ると最悪の足し算より部品を何倍ゆるくでき、そのとき外れる組み立て品は何%出るのか？（寸法の積み上げ）

組み立て品の高さの許容差（図面の寸法から外れてよい幅）を先に決め、それを部品ごとの許容差に割り振ることがあります。部品の許容差をそのまま足して組み立て品の許容差に収める（最悪の足し算）と、どんな部品が来ても外れませんが、部品の許容差はきつくなります。部品の許容差を二乗して足し、平方根が組み立て品の許容差になるように割り振る（二乗の足し算）と、部品の許容差はゆるくできますが、外れる組み立て品が出ます。どれだけ外れるかは、部品が許容差の中でどう散らばって作られるかで決まります。**ここでは、作成者が置いた架空の引き出し付きの小物入れ（底板・引き出しの段3つ・天板の5つを重ね、高さの許容差を±1.0mmと先に決める。部品1個ずつの寸法の散らばり方を作成者が置き、乱数で100万台を組んだもの）で、2つの割り振り方の部品の許容差と、組んだときに±1.0mmを外れる割合を、部品の作られ方4つで数えました。部品の数を2〜20個に変えた40通りでも確かめました。**

例の小物入れ・部品・寸法は架空のもので、実在の製品や規格を表すものではありません。品質の判断や購入の助言はしていません。

関連する記事：1281「5つの部品を重ねた棚の高さで、許容差をそのまま足した『最悪の幅』は、実際の高さのばらつきよりどれだけ広いのか？」は、部品の許容差が先に決まっているときに、組み立て品の幅を見込む2つの足し方を実際の幅と比べています。1282「部品の平均が許容差の中で少しずつ同じ向きにずれていると、二乗で足して見込んだ外れの割合は、実際の何分の1に出るのか？」は、部品の平均がそろってずれたときの見込みの外れを扱っています。1041「掛け算でつなぐ要素が増えるほど、概算はどれだけ外れやすくなるのか？」は、要素の誤差が√（要素の数）で広がる概算の外れを数えています。917「寸法の平均が規格の中でも、外れる品物は何%あるのか？」は、部品1つの寸法の散らばりと分布の形から、規格を外れる割合を数えています。この記事は、組み立て品の許容差を部品に割り振る向きで、ゆるくできる倍率と、そのとき外れる割合に絞ります。

## 主な結果

### 部品の許容差（式どおり）
| 割り振り方 | 部品1つの許容差 | 最悪の足し算の何倍か |
|---|---|---|
| 最悪の足し算 | ±0.2mm | 1倍 |
| 二乗の足し算 | ±0.4472mm | **2.236倍（√5）** |

- 二乗の足し算で割り振ると、部品の許容差は最悪の足し算の2.236倍ゆるくできた。これは割り振りの式どおりの値で、部品が2・3・5・10・20個なら1.414・1.732・2.236・3.162・4.472倍（√部品の数）になる

### 部品5つ・各100万台で、高さが±1.0mmを外れた割合（`results/base_k5.csv`）
| 部品の作られ方 | 最悪の足し算で割り振る | 二乗の足し算で割り振る | 二乗の足し算のときの式の値 | 二乗の足し算のとき、部品1つが許容差を外れた割合 |
|---|---|---|---|---|
| 正規・標準偏差t/4 | 0.0% | 0.006% | 0.0063% | 0.0068% |
| **正規・標準偏差t/3** | 0.0% | **0.2745%** | 0.27% | 0.2682% |
| 正規・標準偏差t/2.5 | 0.0% | 1.2463% | 1.2419% | 1.2454% |
| **許容差の中で一様** | 0.0% | **8.3574%** | 8.3265%（正規と見た目安） | 0.0% |

- **二乗の足し算で割り振ると、部品が前提どおり（標準偏差t/3）に作られていれば、外れる組み立て品は0.2745%だった（式で0.27%）**。正規の作られ方では、組み立て品の外れの割合は、部品1つが許容差を外れる割合とほぼ同じになった（式どおり）
- **部品が許容差いっぱいに一様に散らばると、部品は1つも許容差を外れていないのに、組み立て品は8.3574%外れた**。一様に散らばる部品の標準偏差は t/√3 で、前提の t/3 の1.732倍あるため
- 最悪の足し算で割り振ると、4つの作られ方すべてで外れは0.0%だった。部品の許容差を外れた部品も除かずに組んだが（標準偏差t/2.5で1.2465%）、それでも外れは出なかった
- 許容差いっぱいに一様に散らばる部品で、組み立て品の標準偏差の3倍を1.0mmに合わせると、部品の許容差は±0.2582mmで、最悪の足し算の1.291倍にとどまった。このとき外れは0.0954%だった。この倍率は部品の数で決まり（式どおり）、2・3・5・10・20個で0.816・1.0・1.291・1.826・2.582倍（2個では最悪の足し算よりきつい）

### 確かめ：40通り（各40万台、`results/grid.csv`）
| 部品の作られ方 | 二乗の足し算で割り振ったときの外れ（部品2〜20個） | 最悪の足し算で割り振ったときの外れ（いちばん大きい通り） |
|---|---|---|
| 正規・標準偏差t/4 | 0.0055〜0.0075% | 0.0% |
| 正規・標準偏差t/3 | 0.2565〜0.273% | 0.0028% |
| 正規・標準偏差t/2.5 | 1.217〜1.2548% | 0.0432% |
| 許容差の中で一様 | **8.3247〜8.5903%** | 0.0% |

- 二乗の足し算で割り振ったときの外れは、部品の数をほとんど問わず、部品の作られ方で決まった。部品の数でゆるくできる倍率は1.414〜4.472倍と大きく変わるが、外れの割合はほぼ動かなかった
- 最悪の足し算でも外れが出たのは、部品2個の標準偏差t/3（0.0028%）と、部品2・3個の標準偏差t/2.5のとき（部品が許容差を外れたまま組まれるため）で、いちばん大きくて0.0432%（標準偏差t/2.5・2個）だった

## 注意（言えないこと）
- 架空の小物入れと、作成者が置いた部品の作られ方です。ゆるくできる倍率は式どおりで、外れの割合は置いた作られ方でほぼ決まります
- 部品の平均は図面の寸法どおり（ずれなし）、部品どうしの寸法は関係なしと置きました。平均が同じ向きにずれる場合は 1282 で扱っています。ずれがあると、二乗の足し算で割り振ったときの外れは増えます
- 部品の許容差は5つとも同じ大きさに割り振りました。部品ごとに作りやすさが違うときに大きさを変えて割り振る場合は数えていません
- 部品の作られ方は4つだけ置きました。山が2つの形や、許容差を外れた部品を検査で除く場合は入れていません
- どちらの割り振り方を使うべきか、外れの割合をどこまで認めるかの判断や助言をするものではありません
