# 837 反応率の分母（フォロワー・表示・再生）で、良い投稿は入れ替わるのか？（SNSと動画）

SNS や動画サイトの「反応率」は、反応の数（いいね・コメントなど）を何かで割った数です。割る数（分母）には、フォロワー数・表示回数・再生回数などがあり、どれを使うかで「良い投稿」の顔ぶれが変わります。**ここでは、作成者が乱数で作った架空のアカウントの1年分の投稿300本（投稿ごとに「見た人が反応する本当の確率」を作成者が置いたもの）で、反応の数を4つの分母で割り、上位20本がどれだけ入れ替わるか、本当に反応されやすい上位20本にどれだけ当たるかを数えました。**

|---|---|---|---|
| A837 | 反応率の分母を「今のフォロワー数」「投稿時のフォロワー数」「表示回数」「再生回数」に変えると、上位20本はどれだけ入れ替わるか。本当に反応されやすい投稿にどれだけ当たるか | 架空のアカウントの投稿300本（1年の中の投稿日は一様）。フォロワー数は1年で8,000人から20,000人へ（2.5倍）なめらかに伸びる。「今のフォロワー数」は1年後の20,000人。投稿ごとの本当の反応のしやすさ（再生した人が反応する確率）は中央値4%・対数の標準偏差0.35（0.2〜30%で切る）。表示回数は「投稿時のフォロワー数 × 0.3 × おすすめの振れ」のポアソン分布（おすすめの振れは対数で標準偏差0.8、本当の反応のしやすさとの相関0.3）。再生回数は表示回数のうち再生された割合（中央値25%・対数の標準偏差0.4、反応のしやすさとは無関係）の二項分布。反応の数は再生回数 × 本当の反応のしやすさの二項分布。上位20本の当たり・重なりは、投稿を作り直して200回の平均。確かめとして、おすすめの振れ（0.4・1.2）、おすすめが中身に沿う度合い（0・0.6）、再生された割合の散らばり（0.2・0.6）、フォロワーの伸び（1倍・4倍）を変えた（各200回）。seed 837 | `src/a837_engagement_denominator.py` |

関連する記事：842「表示が増えると、クリック率は下がって見えるのか？」は表示回数の分母が大きくなるときの見え方を、この記事は分母の選び方で上位の顔ぶれが変わることを扱います。

## 主な結果

### 分母ごとの上位20本（200回の平均）
| 分母 | 本当に反応されやすい上位20本に入っていた割合 | 上位20本のうち前半半年の投稿の割合 |
|---|---|---|
| 今のフォロワー数 | 28.7% | **30.7%** |
| 投稿時のフォロワー数 | 29.6% | 50.9% |
| 表示回数 | 36.8% | 52.1% |
| 再生回数 | **73.1%** | 52.1% |
| （反応の数そのまま） | 28.7% | − |

- この記事では「見た（再生した）人が反応する確率」を本当の良さと置いたので、再生回数で割る率が本当の上位にいちばん当たるのは、置き方からほぼ決まる結果です。それでも当たりは73.1%で、残りは件数の少なさによる振れでした
- フォロワー数で割る率は、おすすめに載ったかどうかの振れをそのまま含み、当たりは3割ほどでした
- 今のフォロワー数で割るのは、全部の投稿を同じ数で割るので、反応の数そのままと同じ順位になりました。フォロワーが少なかった前半半年の投稿は上位20本の30.7%に減りました（投稿時のフォロワー数で割ると50.9%）

### 2つの分母どうしで、上位20本が重なった本数（200回の平均）
| | 投稿時のフォロワー数 | 表示回数 | 再生回数 |
|---|---|---|---|
| 今のフォロワー数 | 15.8本 | 6.8本 | 5.1本 |
| 投稿時のフォロワー数 | | 7.3本 | 5.3本 |
| 表示回数 | | | 7.4本 |

- 4つの分母のどれでも上位20本に入った投稿は、平均**2.8本**（0〜8本）だった
- 1回分のデータ（`data/posts.csv`）では4つに共通する投稿は0本、投稿時のフォロワー数と再生回数の両方で上位20本に入ったのは7本だった。2つの率の順位の相関（スピアマンの順位相関）は0.558

### 確かめ：置き方を変えると（各200回）
| 置き方 | 4つに共通（本） | 投稿時フォロワー×再生の重なり（本） | 当たり：投稿時フォロワー | 当たり：表示 | 当たり：再生 |
|---|---|---|---|---|---|
| 基本 | 2.8 | 5.3 | 29.6% | 36.8% | 73.1% |
| おすすめの振れ 小（0.4） | 4.4 | 7.4 | 37.7% | 37.9% | 73.8% |
| おすすめの振れ 大（1.2） | 2.3 | 4.5 | 27.7% | 36.7% | 71.3% |
| おすすめが中身に沿う度合い 0 | 1.9 | 3.6 | 20.1% | 36.9% | 70.8% |
| おすすめが中身に沿う度合い 0.6 | 4.5 | 8.4 | 45.2% | 36.7% | 77.9% |
| 再生された割合の散らばり 小（0.2） | 3.9 | 6.2 | 33.9% | 55.9% | 74.4% |
| 再生された割合の散らばり 大（0.6） | 2.6 | 5.1 | 28.8% | 28.0% | 72.6% |
| フォロワーの伸び なし（1倍） | 3.3 | 5.4 | 31.4% | 36.6% | 67.8% |
| フォロワーの伸び 4倍 | 2.9 | 5.8 | 31.6% | 37.0% | 76.4% |

- 置き方を変えても、4つの分母に共通する上位20本は1.9〜4.5本だった。分母で上位がほとんど入れ替わる向きはどの置き方でも同じ
- 投稿時のフォロワー数で割る率の当たりは、おすすめが中身に沿う度合いで20.1〜45.2%まで動いた。表示回数で割る率の当たりは、再生された割合の散らばりで28.0〜55.9%まで動いた
- 今のフォロワー数で割ったときの前半半年の投稿の割合は、フォロワーが伸びないと51.0%、4倍に伸びると20.9%（`results/robustness.csv`）

## 注意（言えないこと）
- 架空のデータです。フォロワーの伸び、おすすめの振れ、再生された割合、反応のしやすさの分布は作成者が置いたもので、結果はこれで決まります。4つの分母に共通する上位20本は、置き方で1.9〜4.5本まで動きました
- 「本当の良さ」を「再生した人が反応する確率」と置いたので、再生回数で割る率が当たるのは置き方による結果です。「多くの人に届くこと」を良さとするなら、フォロワー数で割る率や反応の数そのままのほうが目的に合います。どの分母が正しいかではなく、何を知りたいかで分母を選ぶ、というのがこの記事の言えることです
- 実際の SNS・動画サイトの表示回数や再生回数の数え方（何秒見たら再生とするか、同じ人が何度見たときの数え方など）は入れていません
- 実在のアカウントやサービスの数字を表すものではありません
