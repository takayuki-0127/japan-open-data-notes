# 1275 「何倍速くなったか」は、1つで動かしたときの何と比べるかで、どれだけ違って見えるのか？（並列処理）

処理を同時にいくつも動かすように作り直したとき、「8つで動かしたら何倍速くなったか」を、8つで動かした時間で「1つで動かした時間」を割って出すことがあります。けれども、「1つで動かした時間」には何通りかあります。同時に動かせるように作り直した版をそのまま1つで動かした時間には、仕事を渡す手間や動かし始めの手間が入ります。同時に動かさない今の版には、その手間がありません。作り直しの途中で1つの仕事の中身も手直ししたなら、手直し前の古い版と比べると、手直しの分まで「同時に動かした効果」に入ります。**ここでは、作成者が置いた架空のアプリの処理（仕事4,000個、1つの仕事の時間の分布、分けられない読み込み、渡す手間、動かし始めの手間、古い版の遅さを作成者が決め、乱数でシミュレーションしたもの）で、同じ「8つで動かした時間」を3つの物差しで割り、「何倍」がどれだけ違って見えるかを数えました。渡す手間・始めの手間・古い版の遅さ・読み込みを変えた72通りでも確かめました。**

実機での計測はしていません。すべて作成者が置いた決まりでのシミュレーションです。実在のアプリ・道具の動きを表すものではありません。台数や費用の見込みの助言をする記事でもありません。

関連する記事：1055「平均・中央値・最小値のどれで比べるかで、速い方は入れかわるのか？」は、同じ測った時間を、どのまとめ方で比べるかで速い方が入れかわることを扱っています。1057「小さいデータで速かった方法は、大きいデータでも速いのか？」は、試す件数と本番の件数の違いで速い方が入れかわることを扱っています。1276「量を変えずに数を増やす試し方と、数に合わせて量も増やす試し方では、速さの伸び方はどう違って見えるのか？」は、同じ版で、量を変えずに数を増やすか、数に合わせて量も増やすかで「何倍」の見え方が違うことを扱っています。1269「処理を8つに分けて同時に動かしても8倍速くならないのは、分けられない部分がどれだけあるときか？」は、分けられない部分の割合で、8つで何倍になるかが頭打ちになることを扱っています。この記事は、量を同じにして、同時に動かした時間を割る相手（1つで動かしたときのどの版の時間か）で、「何倍」がどれだけ違うかに絞ります。

## 主な結果

### 8つで動かした時間（1.7199秒、20回の中央値）を3つの物差しで割ると（`results/a1275_main.json`）
| 物差し（1つで動かしたとき） | 時間（20回の中央値） | 8つで動かすと何倍 |
|---|---|---|
| ① 同時に動かす版を1つで動かした | 9.493秒 | **5.5196倍** |
| ② 同時に動かさない今の版 | 8.5369秒 | **4.9637倍** |
| ③ 手直し前の古い版 | 12.5114秒 | **7.2746倍** |

- **同じ8つで動かした結果が、物差しで4.9637倍から7.2746倍まで違って見えた**
- 3つの「何倍」どうしの比は、物差しの時間どうしの比そのままになる（式どおり）。③÷②は1.4656、①÷②は1.112。③が②より大きいのは、古い版の1つの仕事が1.5倍遅いと置いたため（作りどおり）。①が②より大きいのは、①に渡す手間と始めの手間が入るため（作りどおり）
- 1回ずつ測った時間どうしで割る（20回×20回の組）と、8つで動かした「何倍」の10〜90%の範囲は、① 5.3611〜5.6834倍、② 4.7817〜5.1131倍、③ 7.0645〜7.5352倍で、3つの物差しの範囲は重ならなかった

### 同時に動かす数を変えると（`results/speedup_base.csv`）
| 同時に動かす数 | 時間（秒） | ①と比べて | ②と比べて | ③と比べて |
|---|---|---|---|---|
| 1 | 9.493 | 1倍 | 0.8993倍 | 1.318倍 |
| 2 | 5.0203 | 1.8909倍 | 1.7005倍 | 2.4922倍 |
| 4 | 2.826 | 3.3592倍 | 3.0208倍 | 4.4273倍 |
| 8 | 1.7199 | 5.5196倍 | 4.9637倍 | 7.2746倍 |
| 16 | 1.1518 | 8.2416倍 | 7.4115倍 | 10.8621倍 |

- 同時に動かす版を1つで動かすと、今の版より遅かった（②と比べて0.8993倍）。③の古い版と比べると、1つで動かしただけで1.318倍速く見えた
- 2つ・4つで動かしたとき、③と比べた「何倍」は、動かす数（2倍・4倍）を上回って見えた（2.4922倍・4.4273倍）

### 確かめ：72通り（8つで動かしたとき、回ごとの振れなし、`results/grid.csv`）
- 「何倍」の範囲は、① 4.5215〜7.9846倍、② 3.8427〜7.9832倍、③ 3.8427〜15.9664倍だった
- 1つの置き方の中で、いちばん大きい「何倍」といちばん小さい「何倍」の比は1〜2倍だった。2倍は、古い版が2倍遅いと置いた通り（作りどおり）
- **8倍を上回ったのは72通りのうち33通りで、すべて③の古い版と比べたときだった**。①・②と比べて8倍を上回った置き方は0通り
- 渡す手間と始めの手間を0にした置き方（6通り）では、①と②は同じ値になり（作りどおり）、②と比べた「何倍」は6.0123〜7.9832倍だった。8倍に届かない分は、分けられない読み込みと、最後に残った仕事の待ちの分

## 注意（言えないこと）
- 架空のデータです。渡す手間・始めの手間・古い版の遅さ・読み込みの長さは作成者が置いたもので、3つの「何倍」の差はこれで決まります。物差しどうしの差は、物差しの時間どうしの比そのものです（式どおり）。新しく数えたのは、置き方を変えたときにその差がどれだけの幅になるかです
- 同時に動かす所どうしは、置き場所の取り合いなどで互いに遅くし合わないと置きました。取り合いがある場合、仕事の数が変わる場合は入れていません
- どの物差しを使うべきかは、何を言いたいかで変わります。この記事は、物差しで「何倍」がどれだけ変わるかだけを数えました
- 実機の計測ではありません。実在のアプリや道具での「何倍」を表すものではありません
