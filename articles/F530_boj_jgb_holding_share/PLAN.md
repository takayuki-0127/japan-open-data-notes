# F530 事前の計画（PLAN）

作成：2026-11-19 05:45（JST）。データを取った直後、割合の推移を集計する前に書いた。

## 問い
国債のうち日銀が持つ割合は、どこまで上がり、どこから下がり始めたのか？

## 知りたい人
2022年9月末の資金循環統計で「日銀の国債保有が初めて5割を超えた」と報道されました（時事通信など）。その後、日銀は2024年7月に国債の買い入れを段階的に減らす計画を決めています。ニュースで「日銀の保有割合」を見る人、金融機関や公的部門の資料で保有者別の内訳を扱う人が、割合がいつ・どの水準で頂点をつけ、その後どれだけ下がり、空いた分を誰が持つようになったのかを、公式の統計で確かめたい。政策の良し悪し、金利や国債の売買の見通しは扱いません。

## データ
- 日本銀行「資金循環統計」（時系列統計データ検索サイトの API、db=FF）。四半期末の残高（時価）、1997年10〜12月期〜2026年4〜6月期（速報）。
  - 国債・財投債（長期）と国庫短期証券（短期）の、保有部門別の残高：中央銀行、銀行等（うち国内銀行、農林水産金融機関、中小企業金融機関等）、保険・年金基金（生命保険、非生命保険、年金基金）、証券投資信託、ディーラー・ブローカー、非金融法人企業、一般政府（うち社会保障基金・公的年金）、家計、対家計民間非営利団体、海外など
  - 発行残高（負債側）：一般政府と財政融資資金の国債・財投債、国庫短期証券。額面ベースの残高（一般政府分）
  - 中央銀行・銀行等・保険年金・海外・社会保障基金・家計の取引（フロー）と調整（主に時価の変化）
- 日本銀行「日本銀行勘定」（db=BS01）。月末の長期国債・短期国債の残高（簿価）。

### 取得前に見たもの（下見）
- API の動作確認で、2026年4〜6月期の中央銀行の国債・財投債の残高（4,700,401億円）と、一般政府＋財政融資資金の発行残高（9,299,434＋765,801億円）の値を見た。割合にすると約47%。それ以外の期の値や頂点の時期はまだ見ていない。
- 参考図表 sjlong.xlsx の「国内発行債券の発行体別かつ保有者別残高」は2024年以降の10期分しかないため、長い系列は API で取る。

## 定義
- 主な指標：日銀の保有割合＝中央銀行の国債・財投債の残高 ÷（一般政府＋財政融資資金の国債・財投債の発行残高）。時価。四半期末。
- 「その他」は合計から主な部門を引いた残り。

## 仮説（外れの基準つき）
- H1：日銀の保有割合（国債・財投債、時価）の頂点は50%を超え、頂点の期は2023年以降。外れ：頂点が50%以下か、2022年以前。
- H2：2026年4〜6月期の割合は、頂点より5%ポイント以上低い。外れ：下がり幅が5%ポイント未満。
- H3：頂点から2026年4〜6月期までの日銀の残高の減少のうち、半分以上は取引（償還を下回る買い入れによる純減）による。外れ：調整（時価の変化など）が半分を超える。
- H4：頂点から2026年4〜6月期までに割合が最も上がった部門は海外。外れ：海外以外の部門。

## 手法
- 四半期の部門別の割合の推移。頂点の期、頂点からの変化。
- 日銀の残高の変化を「取引」と「調整」に分ける（残高の差＝取引＋調整。資金循環統計の恒等式）。
- 部門別の割合の変化（頂点の期→最新の期）。

## 頑健性（3つ以上）
1. 国庫短期証券（短期）を含めた「国債等」で見る（日銀の参考図表 6-2 の定義）。
2. 簿価・額面に近い基準で見る：日銀勘定の長期国債（簿価、四半期末の月）÷ 額面の発行残高（一般政府分は額面、財政融資資金分は時価に一般政府分の額面／時価の比をかけた近似）。
3. 年度末（3月末）だけで見る。
4. 頂点の期を、割合でなく日銀の残高（時価・簿価）で見たときの頂点の時期と比べる。

## 言えないこと（予想）
- 割合が下がった理由が、日銀の方針の変更なのか、償還の時期の偏りなのかは、この統計だけでは分けられない。
- 時価のため、金利が上がると残高が小さく出る。割合への影響は分子・分母の両方にかかる。
- 2026年4〜6月期は速報値で、改定される。
- 今後の割合、金利、国債の需給の見通しは書かない。政策の評価もしない。
