# 667 反応しそうな人に配るのと、配ったら反応が増える人に配るのでは、増える件数はどれだけ違うのか（手法の解説・正解の分かるデータで試す）

クーポンや案内を配る相手を選ぶとき、「買いそうな人（反応率の高い人）」から配ることがよくあります。けれども、買いそうな人の中には、配らなくても買う人がいます。配ったことで増えるのは、「配ったら買う確率が上がる人」の分だけです。配ると逆に買わなくなる人もいます。**ここでは、配らなくても買う人・配ると買う人・配ると買わなくなる人が混ざった架空の顧客を作り、反応率のモデルと、2つのモデルの差（アップリフト）で上位から配ったとき、増えた購入を比べました。** 本当の購入確率が分かるので、増えた件数を正確に数えられます。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A667 | 反応率の順とアップリフトの順で配ると、増える購入はどれだけ違うか | 無作為に半分に配った学習用2万人で、R 配った人だけの反応率のモデル（ロジスティック回帰）、U 配った人・配らない人で別に当てた2つのモデルの差。新しい10万人に上位から配り、本当の確率の差の合計を数える。参考に、無作為と本当の差の順（後から分かる最善）。50回。seed 667 | `src/a667_uplift.py` |

## 主な結果
- **上位20%（2万人）に配ると、反応率の順では1,663件、アップリフトの順では3,755件増えた**（2.26倍）。50回すべてでアップリフトの方が多かった。後から分かる最善は3,765件、無作為は191件
- **反応率のモデルが選んだ上位20%は、配らなくても買う確率が平均34.0%**（全体は16.3%）。配ると増える確率は平均8.3ポイントで、31%は配ると逆に買わなくなる人だった
- **アップリフトの順で選んだ上位20%は、配ると増える確率が平均18.8ポイント**で、配ると買わなくなる人は含まれなかった
- **配る割合を増やすと**：アップリフトの順では60%まで配ると増えた購入は5,236件で最大、全員に配ると965件まで減る。反応率の順では40%で1,889件が最大
- この設定では、全体の41%が「配ると買わなくなる人」。全員に配ると、増える分と減る分が打ち消し合う

## 動かし方
```
pip install -r requirements.txt
cd src && python a667_uplift.py
```
十数秒で終わります。`results/incremental.csv.gz` に、方法・配った割合ごとの増えた購入を書き出します。

## 確かめたこと
- 空のフォルダで流し直し、results・figures がバイト単位で一致した
- 無作為に配ったときの増えた購入は、配った割合にほぼ比例した（全員で965件、20%で191件）
- 本当の差の順で全員に配ったときと、ほかの方法で全員に配ったときの増えた購入が一致した

## データ
- 仮定：特徴量4つは標準正規。配らないときの購入確率は logit p0 = -2.2 + 1.3 x1 + 0.6 x2、配ったときは logit p1 = logit p0 + 0.25 + 0.8 x3 − 0.7 x1
- x1 が大きい人は、もともと買いやすいが、配ると効きにくい（逆効果のこともある）。x3 が大きい人は、配ると買いやすくなる
- 学習用は2万人を無作為に半分に配った（A/B テストの形）

## 注意（言えないこと）
- シミュレーション。モデルの形は本当の形（ロジスティック）と合っているので、アップリフトはほぼ最善に届いた。実際には形が分からず、差を当てるのはずっと難しい
- アップリフトを当てるには、無作為に配った（配らない人もいる）データが要る。配った人だけのデータからは当てられない
- 配る費用や、配ると買わなくなる人の割合は作成者が置いたもの。実際の顧客にどれだけいるかは分からない
