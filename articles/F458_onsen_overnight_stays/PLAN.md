# F458 事前の計画（PLAN）

作成：2026-11-16 19:20（JST）。年ごとの集計の前に書いた。

## 問い
温泉地に泊まる人は、30年でどれだけ減ったのか？ 宿の数や大きさはどう変わったのか？

## 知りたい人
温泉地の観光や宿の仕事をしている人、地方の観光の記事を読む人。「温泉地の宿泊客は減っている」と言われる一方で、訪日客は増えている。環境省が毎年まとめている温泉利用状況の長い表で、温泉地の宿泊施設の数・収容定員・年度の延べ宿泊利用人員が、30年でどう変わったかを確かめる。

## データ
- 環境省「温泉利用状況経年変化表」（昭和32年度〜令和6年度、PDF）。温泉地数、宿泊施設数、収容定員、年度延宿泊利用人員、温泉利用の公衆浴場数、国民保養温泉地の年度延宿泊利用人員
- 表は PDF だけで公開されているので、一度だけ文字を取り出して CSV にした（src/01b_extract.py。源泉総数と内訳の和の一致で、列がずれていないことを確かめた）
- 表の注にあるとおり、宿泊利用人員は参考数値

### 取得前に見たもの（下見）
- PDF の形を確かめるときに、表の最初と最後の数行（例：平成4年度の延宿泊1億4,325万人、令和6年度 1億2,541万人、宿泊施設 15,154軒と13,425軒）を見た
- 30年の比較、1軒あたり、稼働の目安はまだ計算していない

## 仮説（外れの基準つき）
- H1：年度の延べ宿泊利用人員は、1994年度より2024年度の方が10%以上少ない。外れ：減りが10%未満。
- H2：宿泊施設の数は、いちばん多かった年度から10%以上減った。外れ：10%未満。
- H3：宿泊施設1軒あたりの収容定員は、1994年度より2024年度の方が10%以上多い（宿が大きくなった）。外れ：10%未満。
- H4：収容定員1人分あたりの年間の延べ宿泊（稼働の目安）は、2019年度の方が1994年度より低い。外れ：同じか高い。

## 手法
- 1957〜2024年度の推移と、30年（1994→2024年度）の変化
- 1軒あたりの収容定員、収容定員あたりの延べ宿泊（延べ宿泊 ÷ 収容定員 ÷ 365 を「稼働の目安」とする）
- コロナの年（2020・2021年度）は別に扱い、比べる終わりを2019年度にした場合も見る

## 頑健性（3つ以上）
1. 比べる年を1992〜96年度平均→2022〜24年度平均にする
2. 終わりをコロナ前の2019年度にする
3. いちばん多かった年度からの減りで見る
4. 国民保養温泉地だけの延べ宿泊で見る

## 言えないこと（予想）
- 宿泊利用人員は参考数値で、集め方は都道府県によって違う可能性がある
- 日本人と訪日客の内訳は分からない
- 温泉地の宿の売上や、日帰りの利用は分からない
- 宿の数が減った理由（廃業、統合、建て替え）は分からない
