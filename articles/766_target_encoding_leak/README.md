# 766 カテゴリを「目的変数の平均」で置きかえて学習すると、学習データの成績はどれだけよく見えるのか（手法の解説・正解の分かるデータで試す）

種類の多いカテゴリ（地区コード・店コードなど）をモデルに入れるとき、「そのカテゴリの購入率」のような目的変数の平均で置きかえる方法（ターゲットエンコーディング）がよく使われます。学習データ全体で平均を出すと、各行の平均には自分の答えが入っているので、学習データでは答えを少し知っている列になります。**ここでは、架空の会員の購入予測（購入は約20%）に、購入とは無関係な地区コード（50〜1,000種類）を足し、置きかえ方を4通り変えて、学習とテストの AUC と、置きかえた列の係数の z 値を各60回測りました。** 効く変数の強さとカテゴリの数は作成者が置いたもので、数字はその置き方で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A766 | 目的変数の平均で置きかえると、学習とテストの成績はどれだけ違うか | ロジスティック回帰（x＋置きかえた列）。A 学習データ全体の平均（自分の行も含む）、B 5-fold で自分の fold 以外の平均、C 平滑化（全体の購入率に寄せる、m=20）を全体で計算、D カテゴリを使わない。学習5,000件・テスト5,000件、各60回。seed 766 | `src/a766_target_encoding.py` |

## 主な結果
- **学習だけよく見える**：1,000種類のとき、A の学習の AUC は0.848、テストは0.609。カテゴリを使わない D は0.705・0.707
- **テストは悪くなる**：無関係な列に重みがつくので、A のテストの AUC は D より0.10低い。種類が少ない（50種類）と差は小さい（学習0.717・テスト0.698）
- **平滑化だけでは直らない**：C（m=20）も1,000種類で学習0.839・テスト0.626
- **fold の外の平均なら直る**：B は学習0.705・テスト0.706 で、D とほぼ同じ
- **偽の効き目**：置きかえた列の係数は、A と C ではすべての回で有意（|z|>1.96）。B では13〜22%で、無関係なら本来の5%より多い

## 動かし方
```
pip install -r requirements.txt
cd src && python a766_target_encoding.py
```
十秒ほどで終わります。`results/summary.csv` に種類の数・置きかえ方ごとの学習とテストの AUC と、有意になった割合を書き出します。

## 確かめたこと
- 空のフォルダで流し直し、results・figures がバイト単位で一致した
- カテゴリを使わない D で、学習とテストの AUC がほぼ同じ（差0.002以内）になることを確かめた

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 766）
- 仮定：購入の確率 = 1/(1+exp(−(−1.6+0.8x)))、x は標準正規分布。地区コードは購入と無関係に一様に割り当てた

## 注意（言えないこと）
- シミュレーションの結果。差の大きさは、カテゴリの種類の数と1種類あたりの件数で決まる
- テストデータは、学習データ全体の平均で置きかえた。B の係数が5%より多く有意になる理由は確かめていない（fold ごとに平均がずれるため、と考えている。推測）
- 決定木などほかのモデルでは、差がもっと大きくなることがある（推測）
