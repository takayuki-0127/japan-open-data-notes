## もとのリポジトリの説明

以下は、もとのリポジトリ `jma-typhoon-besttrack` の README です（同じリポジトリにあったほかの記事の分も含みます）。

### jma-typhoon-besttrack：気象庁のベストトラック（1951〜2025年に台風になった1,951個）で、台風の数・接近・強さ・発達する場所の変化を調べる

気象庁 RSMC Tokyo 台風センターの「Best Track Data」（北西太平洋の熱帯低気圧の6時間ごとの中心位置・中心気圧など）を使ったリポジトリです。台風（最大風速34ノット以上＝熱帯低気圧の階級TS以上）になった1951〜2025年の1,951個を分析しました。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| Y1 | 台風の発生数と日本への接近数は増えたか。発生・接近する月は変わったか | 中心位置を1時間ごとに直線補間し、全国50か所の気象台から300km以内に入ったら「接近」。年ごとの数のポアソン回帰・負の二項回帰（HAC標準誤差、1951年〜と1977年〜）、30年ずつの月の分布とカイ二乗検定 | `src/y1_counts.py` |
| Y2 | 台風が最も発達する場所は北へ移ったか。強い台風・急発達は増えたか。日本に近づいたときの強さは変わったか | 生涯の最低気圧に達したときの緯度の年トレンド（OLS＋HAC、年単位のブートストラップ信頼区間、Kossin型）、930hPa以下・急発達（24時間で30hPa以上の低下）の数のポアソン回帰、最接近時の中心気圧のトレンド | `src/y2_intensity.py` |

#### 主な結果
- **Y1**：台風の発生数は年平均26.0個（最多1967年39個、最少2010年14個）。30年平均で比べると26.9個（1951〜1980年）→24.1個（1996〜2025年）と少ないが、年トレンドは10年あたり−1.7%（95%信頼区間−3.8〜+0.5%、p=0.13）で、はっきりした減少とは言えない（1977年以降でも−2.5%、p=0.11）。日本への接近数（この定義で）は年平均9.2個、9.1個→9.3個でほぼ変わらず（10年あたり+0.1%、p=0.96）。発生した台風のうち接近した割合は33.8%→38.8%。発生・接近する月の分布にも、はっきりした違いはなかった（カイ二乗検定 p=0.64、p=0.26）。気象台ごとでは、宮崎（年3.2個→2.6個）・大分・鹿児島など九州・四国で少なく、盛岡・新潟・前橋（各+0.3個）など東北・北関東で多くなったが、差は小さく検定はしていない
- **Y2**：最低気圧975hPa以下まで発達した台風が最も発達した緯度は、10年あたり+0.05度（95%信頼区間−0.15〜+0.26度）で、北上ははっきりしない。全台風・1980年以降に限ると10年あたり+0.42度（HAC 0.02〜0.82度、ブートストラップ0.09〜0.71度、p=0.041）で北へ移っていた（平均北緯19.99度：1980〜1999年→20.80度：1996〜2025年）。930hPa以下まで発達した台風は年4.7個→4.5個、急発達した台風は年6.8個→6.6個で、どちらも年トレンドははっきりしない。日本に最も近づいたときの中心気圧の平均は976.5hPa→974.8hPa（トレンドは10年あたり−0.2hPa、p=0.59）。最接近時に960hPa以下だった台風は年1.9個→2.4個だが、年トレンドは有意でない（p=0.33）

#### 動かし方
元データ（bst_all.zip、約0.7MB）は `data/raw/` に入っています。最新版は https://www.jma.go.jp/jma/jma-eng/jma-center/rsmc-hp-pub-eg/besttrack.html から取得できます（書式は同じページの「Format」）。

```bash
pip install -r requirements.txt
cd src
python y1_counts.py
python y2_intensity.py
```

#### データ
| ファイル | 中身 |
|---|---|
| data/raw/bst_all.zip | 1951年以降の北西太平洋の熱帯低気圧のベストトラック（6時間ごと、近年は一部3時間ごと。時刻・階級・緯度経度・中心気圧、1977年以降は最大風速など） |
| results/y1_storms.csv・y2_storms.csv | 台風ごとの発生時刻、接近したか、最接近時の距離・気圧、最低気圧とその緯度、24時間の最大気圧低下 |

#### 注意
- 「接近」は、中心が全国50か所の気象台（都道府県庁所在地の気象台と、銚子・彦根・下関・名瀬・石垣島・南大東島など）のどれかから300km以内に入ったこととしました。気象庁の公式の「接近」は全国の気象官署（約150か所）で判定するため、ここでの接近数は公式の数より少なくなります
- 年は、その台風が初めてTS以上になった時刻の年です（年をまたぐ台風もそのように数えています）
- 1977年より前は最大風速の記録がないため、強さはすべて中心気圧で測っています。気象衛星の観測が整う前（1970年代まで）と後では、推定の方法と精度が違います。結果の頑健性として1977年以降・1980年以降の推定も載せています
- 急発達の判定は元の観測時刻（6時間ごと）の気圧の差で、24時間後の時刻が記録にある場合だけです
- 1時間ごとの位置は6時間ごとの位置の直線補間です
