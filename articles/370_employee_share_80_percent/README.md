# 370 雇われて働く人が8割を超えたのは、いつだったのか（労働力調査）

労働力調査の長期時系列（従業上の地位別就業者数、1953〜2025年）で、雇用者・自営業主・家族従業者の割合を数えたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A370 | 雇用者の割合が5割・8割・9割を超えたのは何年か。家族従業者と自営業主はどう減ったか。男女で違うか | 就業者の総数に対する割合。水準を初めて超えた年を数える | `src/a370_status.py` |

## 主な結果
- 雇用者の割合：1953年42.4% → 1959年51.9%（5割超）→ 1965年60.8% → 1976年70.4% → 1993年80.7%（8割超）→ 2006年85.7% → 2023年90.1%（9割超）→ 2025年90.6%
- 10年ごとの上がり方：1953〜63年+15.7ポイント、1963〜73年+10.6、1973〜83年+4.7、1983〜93年+7.3、1993〜2003年+3.8、2003〜13年+3.5
- 家族従業者：1953年1,262万人（32.3%）、1955年1,284万人（最多）→ 1975年628万人（1953年の半分）→ 2002年に4分の1、2023年に10分の1を下回り、2025年115万人（1.7%）
- 自営業主：1953年991万人（25.3%）、1957年1,038万人（最多）、1980年951万人、1989年に900万人を下回り、2025年499万人（7.3%）
- 雇用者は1,660万人→6,185万人で3.7倍、就業者は1.7倍。割合が1953年のままなら2025年の雇用者は2,897万人
- 男性の雇用者の割合：1953年51.2%、1989年に8割超、2025年89.3%。女性：1953年29.5%、1966年に5割超、1999年に8割超、2016年に9割超、2025年92.1%。2006年から女性のほうが高い
- 女性の家族従業者：1953年55.7%（883万人）→ 1970年30.9% → 1990年16.7% → 2025年2.9%
- 参考（14歳以上、別の表）：1948年の雇用者の割合は36.8%

## 確かめたこと
- 1973年は沖縄県を含まない数字と含む数字の両方がある。雇用者の割合は68.8%と68.7%で、差は0.1ポイント
- 2005〜21年は、あとから基準の人口に合わせて直した数字（時系列接続用数値）。直す前の公表値（同じファイルの別シート）でも、8割・9割を超えた年は変わらない範囲（2021年の公表値で89.6%）
- 空のフォルダで流し直し、data・results・figures が一致した

## データ
- `data/raw/roudou_lt04_000001082690.xlsx`：e-Stat 労働力調査 長期時系列データ「長期時系列表4（1）従業上の地位別就業者数－全国」（statInfId=000001082690、1953〜2025年、2026-11-12 取得）
- `data/raw/chouki_19-07.xls`：総務省統計局「日本の長期統計系列」19-7（1948〜52年の参考値に使用。Internet Archive の保存版から取得）
- `data/status_1953_latest.csv`：男女・年ごとの人数と割合

## 注意（言えないこと）
- 割合の分母は、従業上の地位が分からない人を含む就業者の総数です
- 1972年までは沖縄県を含みません。1977年以前は、あとから時系列でつながるように直した数字です
- 雇用者には、会社などの役員、パート・アルバイト、派遣社員も入ります。正規・非正規の内訳はこの表にはありません
- 主な仕事で数えているので、副業としての自営は分かりません。業務委託で働く人は、自営業主に数えられます
- 割合が動いた理由（農業からの移動、会社の大きさ、制度）は、この表からは分けられません。産業の入れ替わりは 339 で見ました
