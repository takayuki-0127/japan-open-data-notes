# 441 基準の年が変わった指数をつなぐとき、つなぎ方で長期の伸びはどれだけ変わるのか（実務の型）

消費者物価指数の2010年・2015年・2020年・2025年基準（全国、月次、総合と10大費目など12本）を、3つの方法でつないで2010年1月〜2026年9月の系列を作り、長期の伸びと前年同月比がどれだけ変わるかを数えたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A441 | 旧基準と新基準をつなぐ係数を、いつの数字で取るかで、15年の伸びはどれだけ変わるか | ①新しい基準年の12か月の平均（公表と同じ考え方）②基準年のどれか1か月（12通り）③旧基準が公表された最後の月、の3つでつなぐ。重なる時期の前年同月比を新旧で比べる。古い年の数字が丸めで動く幅を5つの基準のファイルで比べる | `src/a441_link.py`、`src/01_link_tsql.sql`（T-SQL 版、未検証） |

## 主な結果（2010年平均→2025年平均の伸び）
| 系列 | ①年平均でつなぐ | 公表の2025年基準の系列 | ②1か月でつなぐ（12通りの幅） | ③最後の月でつなぐ − ① |
|---|---|---|---|---|
| 総合 | 18.05% | 18.06% | 17.7〜18.5%（0.8ポイント） | +1.0ポイント（19.1%） |
| 生鮮食品を除く総合 | 16.57% | 16.55% | 0.6ポイント | +1.2ポイント |
| 食料 | 41.73% | 41.75% | 2.0ポイント | −0.1ポイント |
| 住居 | 3.51% | 3.54% | 0.3ポイント | −0.1ポイント |
| 光熱・水道 | 34.16% | 34.17% | 1.4ポイント | −0.1ポイント |
| 交通・通信 | 2.37% | 2.34% | 1.4ポイント | +5.4ポイント（7.7%） |
| 教育 | −7.39% | −7.45% | 2.0ポイント | +0.2ポイント |
| 教養娯楽 | 17.91% | 17.91% | 4.3ポイント | +0.9ポイント |

（全12本は `results/growth_2010_2025_by_method.csv`）

- **①と公表の系列の差**：12本とも0.06ポイント以内
- **つなぎ目ごとの係数**（`results/link_factors_by_junction.csv`）：2021年12月の時点で、2015年基準の総合は、年平均の係数で見た2020年基準の水準より0.87%高い。交通・通信は5.16%
- **重なる時期の前年同月比**（新基準−旧基準、小数第1位）：12本×3回で828か月のうち、0.1ポイント以上違う月が638か月（77%）。総合は 2010→2015年 13/24か月、2015→2020年 21/24か月（2021年の平均 −0.57ポイント）、2020→2025年 13/21か月。最大は交通・通信の2015→2020年で5.1ポイント
- **古い年の前年同月比**（総合、2010年基準のファイルと2025年基準のファイル）：0.1ポイント以上違う月は、1971〜79年 69%、1980年代 60%、1990年代 43%、2000年代 39%。最大0.5ポイント
- **長い期間の伸び**：1970年平均→2005年平均の総合の伸びは、5つの基準のファイルで207.32〜207.56%

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した
- ①の係数を SQL（DuckDB）で出し、Python の計算と一致する（コード内の assert）

## データ
- `data/raw/cpi_base2010_mid.csv` ほか3つ：総務省統計局「消費者物価指数」長期時系列データ 品目別価格指数 全国 月次「中分類指数（1970年1月〜最新月）」。e-Stat の statInfId は 2010年基準 000011288575、2015年基準 000031431696、2020年基準 000032103842、2025年基準 000040482943（2026年11月12日取得、文字コードは Shift_JIS のまま）
- `data/cpi_base2005_sogo.csv`：2005年基準（000002032502）から総合だけを取り出したもの
- `data/cpi_four_bases_2009on.csv`：4つのファイルから12本の系列を縦長に直したもの（2009年1月以降）

## 注意（言えないこと）
- 消費者物価指数の12本での結果。ほかの指数では差の大きさは違う
- どのつなぎ方が正しいかは決めていない。公表の系列は年平均でつないでいる
- 基準の変更で前年同月比が動いた理由（重み・品目・作り方）は分けていない
- T-SQL 版は SQL Server 本体では動かしていない（未検証）
