# 767 カテゴリを1・2・3の数にして線形回帰に入れると、ダミー変数と比べて予測はどれだけ悪くなるのか（手法の解説・正解の分かるデータで試す）

売り場の種類のような順番のない区分を、データベースの番号（1・2・3…）のまま数として線形回帰に入れると、「番号が1増えるごとに一定だけ増える」という、ありえない形を当てはめることになります。**ここでは、架空の店の客単価（8つの売り場の種類ごとに効き目が違い、ほかに数の変数 x がある）で、種類を番号のまま入れた線形回帰、ダミー変数で入れた線形回帰、番号のまま入れた決定木を比べました。番号の振り方を200通り変えて、係数と予測の誤差の変わり方も測りました。** 種類ごとの効き目は作成者が置いたもので、数字はその置き方で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A767 | 区分を番号のまま線形回帰に入れると、予測と係数はどうなるか | y = 効き目[種類] + 0.5x + 誤差（標準偏差1）。番号のまま線形回帰、ダミー変数（7列）で線形回帰、番号のまま決定木（深さ3・6）、種類を使わない線形回帰。学習2,000件・テスト2,000件。番号の振り方を200通り。seed 767 | `src/a767_label_encoding.py` |

## 主な結果
- **番号のままの線形回帰は、種類を使わないのとほぼ同じ**：テストの RMSE は中央値1.274（種類を使わない1.301）。ダミー変数なら0.982で、番号のままは29.8%大きい
- **係数は番号の振り方しだい**：番号の係数は200通りの振り方で−0.29〜+0.33、54%の振り方でプラス、46%でマイナス。「番号が1増えると客単価が増える」のような読み方には意味がない
- **振り方によっては少し当たる**：たまたま効き目の順に近い振り方では RMSE 1.033 まで下がった（最大は1.302）
- **決定木は番号でも分けられる**：番号のままでも、深さ3で1.153、深さ6で1.043。種類ごとに分けるのに何段も分岐が要るので、浅い木では足りない
- **x の係数**：ダミー変数で0.519、番号のままで0.538（本当は0.5）。種類と x は無関係なので、x の係数はあまりずれない

## 動かし方
```
pip install -r requirements.txt
cd src && python a767_label_encoding.py
```
数秒で終わります。`results/perms.csv` に番号の振り方ごとの係数と予測の誤差を書き出します。

- ダミー変数の係数が、置いた種類ごとの効き目の差と0.12以内で一致した

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 767）。`results/train_sample.csv` に学習データ（1回分）を置いた
- 仮定：8種類の効き目は 0・−0.8・0.6・1.5・−1.2・0.3・1.0・−0.4（順番に意味はない）、x は標準正規分布、誤差は標準偏差1

## 注意（言えないこと）

- 区分に本当に順番がある場合（S・M・L など）は、番号で入れるのが合うこともある
- 実在の店の数字ではない
