# 928 「独学の人の合格率」と「講座の人の合格率」は比べられるのか？（試験と点数）

「講座の受講生の合格率は42.12%、独学の人は17.45%」のような比べ方を見ると、その差の24.67ポイントが講座の効き目のように読めます。けれども、講座を選ぶ人と独学を選ぶ人は、もとの力が違うかもしれません。また、講座の合格率が「修了して受験した人」だけで数えられていると、途中でやめた人は分母から外れます。**ここでは、作成者が乱数で作った架空の資格試験の受験者（講座の本当の効き目を作成者が置いたもの）で、「全員が講座を受けたとき」と「全員が独学のとき」の合格率の差（本当の差）と、見かけの合格率の差を比べました。**

講座や勉強法の良し悪し、講座を選ぶべきかの助言はしません。数えたのは、合格率の比べ方のずれだけです。

## 動かし方
```
pip install -r requirements.txt
cd src && python a928_self_vs_course.py
```
30秒ほどで終わります。`data/candidates.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、2回流して約11〜33秒。ほかの処理と同時に流したので幅がある）
- 選び方0・やめる偏りなしで、見かけの差が本当の差とほぼ同じになった（効き目0・3・6点で −0.09対0、7.32対7.29、15.54対15.45）。作りの確かめ
- 見かけの差が選び方で動くのは、置いた「力の高い人ほど（低い人ほど）講座を選ぶ」の写しで、選び方を0にすれば消える。数えたのは、その動きが効き目の大きさと比べてどれだけ大きいかと、段に分ける比べ方でどこまで戻るか

## データ
- `data/candidates.csv`：基本の置き方の1回分の受験者2万人から3,000人を抜き出したもの。person_id・ability_z（もとの力）・course（1＝講座）・quit（1＝途中でやめた）・pretest（練習テスト）・score（点）・passed（1＝合格）

## 注意（言えないこと）
- 架空のデータです。もとの力の分布、講座の効き目、選び方、やめやすさ、合格点は作成者が置いたもので、結果はこれで決まります。実在の試験や講座の合格率を数えたものではありません
- 講座の効き目は全員に同じ点を足すと置きました。人によって効き目が違えば、「全員が講座なら」の差と「講座を選んだ人にとっての差」も違ってきます（推測）
- 実際の講座の発表の数え方（分母が受講申込者か、修了者か、合格の報告をした人か）は、講座ごとに違うはずです（推測）。この記事では「修了して受験した人」の1通りだけを置きました
- 講座や勉強法の良し悪し、講座を選ぶべきかの助言はしません
- 関連する記事 927 は、勉強時間と点数の傾きの読み方を扱っています。誰がそうしたかで比べ方がずれる話は、846（ハッシュタグを付けた投稿の選ばれ方）、870（謝礼で回答者の構成が変わる）とも同じ仕組みです。この記事は、2つの集まりの合格率の比べ方に絞りました。同じ企画の 932（2回目の受験の合格率が高いのは、なぜなのか？）も、比べる2つの集まりがそもそも違う（受け直す人が選ばれている）という同じ形の問題です
