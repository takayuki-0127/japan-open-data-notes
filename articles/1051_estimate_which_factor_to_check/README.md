# 1051 要素の1つを実際に数えて確かめるなら、どの要素から確かめると外れがいちばん縮むのか？（概算）

「世帯数×自転車のある割合×台数×修理の回数×出張を頼む割合」のように要素を掛けて件数を見込んだあと、要素の1つだけを実際に数えて確かめられるとします。調べやすい要素（世帯数など）から確かめたくなりますが、全体の外れがいちばん縮むのは、いちばん外れやすい要素を確かめたときのはずです。ただし、数えた値にも誤差が残ります。まれなことの割合は、少ない件数を数えても当たりにくいからです。**ここでは、作成者が乱数で作った架空の概算（5つの要素の本当の値と、見込む人の当て推量の外れやすさを作成者が置いたもの）で、どの要素を確かめると全体の外れがどれだけ縮むかを20万人分数えました。数える件数・要素どうしの外れの相関・いちばん外れやすい要素の外れやすさを変えた36通りの確かめも行いました。**

例の B市とサービスは架空のもので、実在の地名・会社の数字は使っていません。

関連する記事：同じ企画の 1041「掛け算でつなぐ要素が増えるほど、概算はどれだけ外れやすくなるのか？」は要素の数を、1043「大きく外れた要素が1つあると、ほかを正しくしても全体はどれだけずれるのか？」は1つの要素の大きな外れの効き方を扱います。この記事は、確かめる要素を1つ選ぶときの選び方と、数えた値に残る誤差に絞ります。まれなことを数える件数の話は 909「不良率0.1%を確かめるには、何個検査すればよいのか？」と同じしくみで、数えて0件だったときの扱いは 992「「ありえない」と感じる確率は、何%くらいなのか？」と近い話です。

## 主な結果

### どれを確かめるかで、全体の外れはどれだけ縮むか（n＝100、20万人、`results/strategies_base.csv`）
| 確かめる要素 | 外れの大きさの中央値 | 式の値 | 10人に1人はこれ以上外れる（90%点） | 2倍以内に入った割合 |
|---|---|---|---|---|
| 確かめない | 2.0338倍 | 2.037倍 | 5.6927倍 | 48.99% |
| ①世帯数 | 2.0259倍 | 2.0304倍 | 5.6243倍 | 49.24% |
| ②自転車のある世帯の割合 | 2.0006倍 | 2.0014倍 | 5.471倍 | 49.99% |
| ③自転車のある世帯の台数 | 2.0109倍 | 2.0123倍 | 5.5194倍 | 49.66% |
| ④1台が1年に修理の要る回数 | 1.8215倍 | 1.8184倍 | 4.3138倍 | 56.47% |
| ⑤修理のうち出張を頼む割合 | **1.6923倍** | 1.677倍 | **3.6507倍** | 62.52% |

- 「外れの大きさ」は、見込みと本当の件数の大きいほう÷小さいほう
- **いちばん外れやすい⑤を100件数えて確かめると、外れの大きさの中央値は2.0338倍から1.6923倍に縮んだ。調べやすい①世帯数を確かめても2.0259倍で、ほとんど縮まなかった**
- この順番は式どおり。掛け算の外れ（対数）の分散は要素の σ² の和で、確かめると σ² が「数えた値の誤差」に入れかわる。外れの対数の標準偏差は、確かめないとき1.0556（式1.0548）、⑤を確かめたとき0.7862（式0.7665）
- ⑤を確かめても、10人に1人は3.6507倍以上外れた。残りの要素の外れが残るため
- 1人ずつ見ると、その人の外れがいちばん縮んだ要素が⑤だったのは38.44%、④が28.03%、②が12.98%、③が11.16%、①が9.39%だった。平均でいちばん効く要素でも、1人ひとりの概算でいちばん効くとは限らない

### 数える件数 n で、④と⑤のどちらが効くかが入れかわる（各10万人、`results/by_count_n.csv`）
| n | ④を確かめた外れの中央値 | ⑤を確かめた外れの中央値 | ⑤を数えて0件だった割合（式） |
|---|---|---|---|
| 10 | 2.0917倍 | 1.8281倍 | 43.44% |
| 15 | 1.9918倍 | 1.9173倍 | 28.63% |
| 20 | **1.9421倍** | 1.9638倍 | 18.87% |
| 30 | **1.8921倍** | 1.9277倍 | 8.2% |
| 50 | 1.8473倍 | 1.7991倍 | 1.55% |
| 100 | 1.8197倍 | 1.6916倍 | 0.02% |
| 300 | 1.8074倍 | 1.6215倍 | 0.0% |

- **n＝20と30では、④を確かめたほうが⑤より外れが小さかった**。8%しか起きない⑤の割合は、20〜30件を数えても当たるのは数件で、数えた値の誤差が大きく残るため
- n＝10と15で⑤が④より小さく出たのは、0件を0.5件として扱った決め方のため。n＝10では43.44%の回で0件になり、数えた値が「0.5件÷10件」より下にならないので、低いほうの外れが押さえられた。この決め方を変えると、少ない n の結果は変わる
- n＝50以上では、⑤を確かめたほうが外れが小さかった
- この表の n＝100の行（1.6916倍）は、上の表（1.6923倍）と乱数が違うため少し違う

### 確かめ：置き方を変えると（36通り、各6万人、`results/sensitivity.csv`）
- 外れの対数の標準偏差でいちばん縮んだ要素は、36通りのうち⑤が23通り、④が12通り、③が1通り。外れの大きさの中央値では⑤が21通り、④が14通り、①が1通り。2つの物差しで答えが違ったのは3通り
- n が100以上の12通りでは、⑤がいちばん（標準偏差で）だったのは8通り。残りの4通りは⑤のσを0.5（④の0.6より小さい）にした通りで、いちばん外れやすい要素がいちばん効くという順は変わらなかった
- ①世帯数を確かめても、外れの中央値の「1を超えた分」が縮んだのは36通りで0.17〜5.88%だった
- いちばん効く要素を確かめたあとの外れの中央値は36通りで1.5108〜2.1191倍（確かめないときは1.7686〜2.8651倍）
- n＝10の σ5＝0.5・相関0の通りでは、④を確かめると外れが確かめないときより大きくなった（1.8057倍対1.7686倍）。数えた値の誤差が当て推量の外れと同じくらい大きいと、確かめても縮まない

- `results/strategies_base.csv`：確かめる要素ごとの外れ（sd_log は外れの対数の標準偏差、median_miss_times は外れの大きさの中央値、p90_miss_times は90%点、formula_ は式の値）

- `results/sensitivity.csv`：36通りの確かめ（f1〜f5 は①〜⑤を確かめたとき）

## 注意（言えないこと）
- 架空のデータです。要素の本当の値、当て推量の外れやすさ σ、数える件数、0件の扱いは作成者が置いたもので、結果はこれで決まります。どの要素がいちばん効くかは、σ² と数えた値の誤差の差でほぼ式どおりに決まります
- 見込む人が「どの要素がいちばん外れやすいか」を知っていると置いています。実際には、どれが外れやすいかの見当そのものが外れることがあります
- 数える手間（費用・時間）は入れていません。手間を入れると、確かめるべき要素は変わりえます
- 実在のサービスの需要を表すものではありません
