### school-basic-survey-japan：学校基本調査の年次統計で、大学進学率のS字カーブと学校数の減り方を調べる

文部科学省「学校基本調査」の（参考資料）年次統計（1948〜2025年）を使ったリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| S1 | 大学（学部）進学率は男女それぞれどこまで上がりそうか。女性の短大進学の減少は大学進学に置き換わったか | ロジスティック曲線（4パラメータ）の非線形最小二乗、5年ブロックの残差ブートストラップで上限の区間、年変化の回帰（HAC標準誤差） | `src/s1_logistic.py` |
| S2 | 子どもが減ると、学校はどれくらい遅れて減るのか | 対数差分の分布ラグ回帰（0〜10年、HAC標準誤差）と累積の弾力性、期間別の弾力性 | `src/s2_schools.py` |

#### 主な結果
- **S1**：大学（学部）進学率は女性2.4%（1954年）→56.5%（2025年）、男性60.7%。S字カーブの上限は女性63.5%（95%区間58〜78%）、男性66.7%（54〜100%）で、特に男性は区間が広く決め打ちできない。女性の短大進学率は1994年の24.8%がピークで2025年は4.7%。1994年以降、短大進学率が1ポイント下がった年は、大学進学率がふだんより0.44ポイント多く上がった（95%区間0.22〜0.66）。男女差は1978年の28.2ポイントから2025年は4.2ポイント
- **S2**：小学校の子どもは1985〜2025年に48%減、学校は26%減。期間別の弾力性（学校数の変化率÷子どもの変化率）は、1985〜2000年0.09、2000〜2010年1.76、2010〜2025年0.91。分布ラグ回帰の10年累積の反応は小学校0.17・中学校0.19と小さく、学校数の減少は子どもの数の変化よりも「時期」（2000年代以降）で説明される部分が大きい

#### 動かし方
```bash
pip install -r requirements.txt
cd src
python s1_logistic.py
python s2_schools.py
```

#### 注意
- 大学（学部）・短大（本科）への進学率は「過年度高卒者等を含む入学者数 ÷ 3年前の中学校等卒業者数」です
- S字カーブは「この形で伸びる」と仮定した当てはめで、将来の予測ではありません。男性は1976〜1990年に横ばい（大学の定員が抑えられた時期）があり、S字にきれいに乗りません
- 学校数の減少には、市町村合併や統廃合の方針など、子どもの数以外の要因が大きく関わります。このデータからは理由までは分かりません
- 1972年以前は沖縄県を含みません。S2の回帰は1975年以降を使っています
