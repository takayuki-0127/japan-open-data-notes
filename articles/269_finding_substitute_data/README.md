# 269 「データが取れない」とき、どう代わりを探したか（④ 振り返り R011）

このシリーズで、ほしいデータが取れない・公表されていないときに何を代わりにしたかと、その代わりで何が言えなくなったかを、記事ごとの README から数えたフォルダです。公的データで困ったことの種類を数えた [241](https://github.com/takayuki-0127/japan-open-data-notes/tree/main/articles/241_public_data_troubles) とは別に、「どう代わりを作ったか」に絞りました。

## 問い

- 代わりの記録がある記事はどれだけあるか
- 代わりをどう作ったか
- 代わりを使って、何が言えなくなったか

## 手法

| 手順 | 中身 |
|---|---|
| README の重複を除く | 267 と同じ（528 → 463本） |
| 文を拾う | 「代わりに」「代用」「代替」「取れない」「公表されていない」「載っていない」「ないため」などの言葉と、データ・統計・表などの言葉が同じ文にあるもの（「代替バイアス」「交差弾力」などは除く）。218文・146本 |
| 目で確かめる | 乱数（random_state 11）で20文を選んで目で判定（`data/precision_sample_judged.csv`）。データが取れずに代わりを使った記録は11文（55%） |
| 代わりの作り方 | 6種類の言葉で分けた（1文に複数つく） |
| 実例 | 9本の「ほしかったもの・代わり・確かめたこと・言えなくなったこと」を README から手で写した（`data/cases.csv`） |

## 主な結果

- 代わりの言葉がある記事は463本中146本（31.5%）。目で確かめた精度（55%）からみると、本当に代わりを使った記事はその半分強と見ている（推測）
- グループ別（図3）：精選68%（27/40）、F100〜F199 39%、F200〜F255 31%、F01〜F99 29%、1000本計画 22%、100〜226 22%、000〜099 20%
- 代わりの作り方（記事数、図2）：別の統計・別の表に切り替えた39、単位を粗くした33、期間・範囲を変えた19、近い指標で見立てた9、手で写した・PDF から起こした3、延ばした・推計した1。どれにも当たらない68
- 9本の実例（図1）のうち8本で、代わりを使った分だけ言えないことが1つ増えていた。増えなかったのは、つなぎ目の2025年が両方の表で一致することを確かめた T001 だけ

## 言えないこと

- 言葉で拾ったので精度は55%。146本は多めの数
- 作り方の6種類も言葉で分けたので、取りこぼしと数え過ぎがある
- 代わりを使わずに題材ごとやめた案は README に残っていないので数えていない
