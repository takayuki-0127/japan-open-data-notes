# population-pyramid-japan：100年分の人口ピラミッドは、いつ「つぼ型」になったのか（人口推計 1920〜2024年）

総務省「人口推計」の長期時系列（年齢各歳・男女別、1920〜2020年）と各年10月1日現在人口（2021〜2024年）をつなぎ、日本の人口ピラミッドの形がいつ変わったのかを、形の指標とベビーブーム世代の追跡で調べたリポジトリです。

| 問い | 手法 | スクリプト |
|---|---|---|
| ピラミッドの裾（0〜4歳）はいつから細くなったか。子どもと高齢者の割合、中位年齢はどう動いたか | 年ごとに、0〜14歳・65歳以上の割合、老年化指数、中位年齢（各歳の中で線形補間）、いちばん多い5歳階級、0〜4歳÷いちばん多い5歳階級、0〜4歳÷40〜44歳を計算 | `src/a140_pyramid.py` |
| 2つのベビーブーム世代は、ピラミッドの中をどう動いたか | 生まれ年（年−年齢）でそろえた団塊の世代（1947〜49年生まれ）と団塊ジュニア（1971〜74年生まれ）の人数、各年のいちばん人口の多い年齢 | `src/a140_pyramid.py` |

## 主な結果
- 0〜4歳がいちばん多い5歳階級（＝裾がいちばん広い富士山型）だったのは1953年まで。1954年からは団塊の世代（当時5〜9歳）のほうが多くなった
- 第2次ベビーブームで、1974年には0〜4歳がいちばん多い階級（25〜29歳）の99.8%まで戻ったが、その後は細くなる一方で、0〜4歳÷いちばん多い階級は0.93（1975年）→0.61（1990年）→0.40（2024年）
- 1981年に0〜4歳が40〜44歳より少なくなり、その後一度も上回っていない（中年より裾が細い＝つぼ型の目安）
- 65歳以上が0〜14歳を上回ったのは1997年、2倍を超えたのは2014年。2024年は0〜14歳11.2%、65歳以上29.3%
- 中位年齢は1920年22.2歳、1950年22.3歳とほぼ変わらず、その後上がり続けて2024年は50.1歳
- いちばん人口の多い年齢は、1950年から2022年まで団塊の世代（1948年前後生まれ）だったが、2023年から団塊ジュニア（1973年前後生まれ、2023年に50歳）に替わった
- 団塊の世代は生まれ年1年あたり245万人（1950年）→189万人（2024年）、団塊ジュニアは203万人（1975年）→198万人（2024年）

## 動かし方
`data/pop_age_sex.csv`（年×年齢×男女、千人）が入っているので、そのまま動きます。元の Excel から作り直すときは、e-Stat の下のファイルを `data/raw/` に置き、CSV を消してから実行してください。

```bash
pip install -r requirements.txt
cd src
python a140_pyramid.py
```

## 注意
- 1941〜43年は年齢別の推計がなく、1944〜46年は数え年なので、分析から除きました
- 1945〜71年は沖縄県を含みません
- 最上位の年齢区分は年によって「79歳以上」〜「100歳以上」と違うので、85歳以上はまとめて扱い、形の指標とピラミッドの図は0〜84歳で見ています
- 国勢調査の年は国勢調査人口、それ以外の年は推計人口です（年齢不詳はあん分済み）。1920〜1940年などには補間補正人口が含まれます
- 年齢は10月1日現在なので、「年−年齢」で求めた生まれ年は前後1年ずれます。世代の人数は外国人の出入りも含む総人口の値で、死亡だけで減ったわけではありません
- 「つぼ型」には決まった定義がありません。ここでは「0〜4歳が40〜44歳より少ない」を目安にしました
