# F529 事前の計画（結果を集計する前に書く）

作成：2026-11-19 06:55（UTC）。元データの取得、系列の数（全国計・8地方計・47都道府県×7項目＝392系列）と期間（1998年4月〜2026年9月、月末残高）の確認、日本銀行サイトの公表資料（2026年3月末の Excel）の見出しの確認までです。預貸率の計算はまだしていません。

## 問い
預金は増えても貸出が追いつかない（預貸率の低下）と言われる。これは地域でどう違うのか。預貸率の動きを「預金の伸び」と「貸出の伸び」に分けると、地域の差はどちらから来ているのか。最近（2023年ごろから）は上がっているのか。

## 知りたい人
- 地域の金融の話題で「預貸率が低い」「お金が地域で使われていない」と聞いて、数字で確かめたい人
- 地域の金融機関・自治体の企画の担当で、自分の地方の預金と貸出の伸びを全国と比べたい人
- 日本銀行「金融システムレポート」（2026年4月号）は、預貸率は地域銀行を中心にやや上昇傾向にあるが、全体では預金残高が貸出残高を大きく上回っていると書いている。これを地域別の統計で見る

## データ
- 日本銀行「時系列統計データ検索サイト」MD12 都道府県別預金・現金・貸出金（国内銀行、銀行勘定、月末残高、億円）。店舗の所在地で集計（信用金庫などは含まない）
- 項目：預金合計、一般預金、個人預金、公金預金、金融機関預金、譲渡性預金、貸出金
- 照らし合わせ：日本銀行サイトの公表資料（2026年3月末の Excel）。都道府県名（見出しの文字）で API の値と突き合わせる

## 定義
- 預貸率 ＝ 貸出金 ÷ 預金合計（年度＝4月〜翌3月の月末残高の平均）。年度は1998〜2025年度。直近は2025年10月〜2026年9月の12か月平均も出す
- 地域：日本銀行の地方区分（北海道、東北、関東、北陸、中部、近畿、中国、四国、九州・沖縄）。東京は本店の多い大きな銀行の影響が大きいので、「関東（東京を除く）」と「東京」に分けても出す
- 並べ方は北から南（地方の順）。悪い方からの順位は出さない

## 仮説（それぞれ「こうなったら外れ」）
- H1：全国の預貸率は、1998年度から2025年度に10ポイント以上下がった。外れ：下がり幅が10ポイント未満
- H2：預貸率の下がり幅は、東京より東京以外の地方の方が大きい。外れ：東京以外の地方の下がり幅の中央値が東京以下
- H3：2022年度→2025年度に、9地方（東京を分けると10）の半分以上で預貸率が上がった。外れ：上がった地方が半分未満
- H4：1998年度→2025年度の預貸率の変化の地方差（都道府県の間のばらつき）は、預金の伸びの差より貸出の伸びの差から来ている部分が大きい。外れ：都道府県の間で、log(預貸率)の変化の分散のうち、貸出の伸びの分散の方が預金の伸びの分散より小さい

## 手法
1. 年度平均の残高から預貸率を出す（全国、地方、都道府県）
2. 分解：Δlog(預貸率) ＝ Δlog(貸出) − Δlog(預金)。期間は 1998→2025年度、1998→2012年度、2012→2022年度、2022→2025年度
3. 都道府県の間で、Δlog(預貸率) の分散を、貸出・預金の分散と共分散に分ける
4. 図：全国と地方の預貸率の推移、地方ごとの分解（北から南）、2022→2025年度の変化

## 頑健性（3つ以上）
- R1：分母に譲渡性預金を足す（貸出 ÷（預金＋譲渡性預金））
- R2：分母を一般預金（公金・金融機関預金を除く）にする
- R3：年度平均ではなく3月末の残高にする
- R4：東京・大阪（大きな銀行の本店の影響が大きい）を除いて H4 を確かめる

## 問い直し（候補）
- 預金の伸びのうち、個人預金と、それ以外（法人など）のどちらが効いているか

## 言えないこと（予想）
- 店舗の所在地での集計で、借り手・預け手がどこに住んでいるかとは一致しない（東京の本店が地方の企業に貸す、など）
- 国内銀行だけで、信用金庫・信用組合・農協・ゆうちょ銀行は入らない
- 預貸率が高い・低いことの良し悪しは言えない。銀行の経営の良し悪しも扱わない
- 預金・貸出の伸びの原因（人口、企業の立地、政策）は、この分析では確かめない
