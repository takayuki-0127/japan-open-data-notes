## もとのリポジトリの説明

以下は、もとのリポジトリ `municipal-waste-japan` の README です（同じリポジトリにあったほかの記事の分も含みます）。

### municipal-waste-japan：環境省「一般廃棄物処理実態調査」で、市区町村のごみの量・リサイクル率・処理経費の18年を調べる

環境省「一般廃棄物処理実態調査結果」の市区町村別「ごみ処理概要」（2007〜2024年度、延べ約3.1万行）と、都道府県別の廃棄物処理事業経費を使ったリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| W1 | 1人1日当たりのごみの量とリサイクル率は、全国と市区町村でどう変わったか。多かった所ほど減ったか | 市区町村の値の合計による全国値、分位点、σ収束（期間中ずっとある1,698市区町村の対数標準偏差）、β収束（2012→2024年度の年率変化を2012年度の水準で回帰、HC1標準誤差）、人口10万人以上の市区のランキング | `src/w1_trend.py` |
| W2 | ごみはどう処理されているか。人口規模でごみの量やリサイクル率は違うか。処理の経費はどう変わったか | 処理方法の構成比、人口規模別の中央値と対数弾力性（2024年度）、都道府県別の経費（1人当たり・1トン当たり）と小さな市町村に住む人の割合との関係 | `src/w2_scale.py` |

#### 主な結果
- **W1**：全国の1人1日当たりのごみの量は1,092g（2007年度）→839g（2024年度）で23%減った。生活系（家庭から）は766g→580g、事業系は323g→259g（2020年度に280g→255gと下がり、その後ほぼ横ばい）。リサイクル率は2010年度の20.8%が最も高く、2024年度は19.3%に下がった。2012年度に量が多かった市区町村ほど速く減っていて（β＝−3.04、標準誤差0.49）、市区町村の差（対数の標準偏差）は0.31→0.24に縮まった。一方、リサイクル率が30%以上の市区町村の割合は17.7%→12.4%に下がり、リサイクル率の高かった所ほど下がっていた（β＝−0.32）。人口10万人以上の256市区では、1人1日当たりが最も少ないのは日野市（578g）、多いのは北九州市（1,128g）
- **W2**：ごみ処理量のうち直接焼却は77.6%→80.8%、直接埋立は2.5%→0.8%、最終処分量は635万トン→306万トン（−52%）。2024年度の家庭系ごみ（中央値）は人口5千人未満の町村で547g、30万人以上の市で451g、事業系は108g→257gと逆向きで、合計はどの規模でも約810〜850gとほぼ同じ（人口に対する弾力性−0.004）。リサイクル率は人口規模とはっきりした関係がない。ごみ処理の経費は1人当たり13.9千円（2012年度）→19.7千円（2024年度、名目）で、1トン当たりでは39.5千円→64.3千円。都道府県の処理及び維持管理費は1人当たり11.3千円（長野県）〜21.9千円（徳島県）で、人口3万人未満の市町村に住む人の割合との相関は0.25と弱い

#### 動かし方
`data/muni_panel.csv`（市区町村×年度に整えたもの）と `data/pref_cost.csv` が入っているので、そのまま動きます。元の Excel から作り直すときは、各年度のファイルを `data/raw/` に「年度フォルダ名_total_番号.xlsx」の名前で置き、この2つの CSV を消してから実行してください。
- 市区町村別ごみ処理概要：2007〜2011年度は https://www.env.go.jp/recycle/waste_tech/ippan/<h19〜h23>/data/shori/total/02.xls 、2012年度以降は …/<h24〜r6>/data/shori/total/01.xls(x)
- 経費（都道府県別）：…/<年度>/data/shori/total/05.xls(x)（シート「廃棄物事業経費（歳出）」）
- 年度フォルダ名：h19（2007年度）〜h30、r1（2019年度）〜r6（2024年度）

```bash
pip install -r requirements.txt
cd src
python w1_trend.py
python w2_scale.py
```

#### データ
| ファイル | 中身 |
|---|---|
| data/muni_panel.csv | 市区町村×年度：総人口、ごみ総排出量、集団回収量、1人1日当たり（合計・生活系・家庭系・事業系）、ごみ処理量、直接焼却量、直接最終処分量、焼却以外の中間処理量、直接資源化量、中間処理後再生利用量、リサイクル率、最終処分量 |
| data/pref_cost.csv | 都道府県×年度：ごみの建設・改良費、処理及び維持管理費、合計（千円、市区町村と一部事務組合、組合分担金を除く） |

#### 注意
- 各年度のフォルダの表題は「○○年度実績」で、その年度の実績です（例：r6＝2024年度）
- 2005〜2006年度のファイル（h17・h18）には市区町村別のごみ処理概要がないので、使っていません
- 東京23区は、ごみの量が「23区」の行にまとめて入り、人口は区ごとの行に入っている年があるため、23区を1つの単位として扱い、人口は区の合計を使いました（23区の生活系・事業系の内訳は一部の年で計算できません）
- 2007〜2011年度は市町村合併が続いていて、市区町村の数が年によって違います。σ収束は全期間にある1,698市区町村、β収束は2012年度と2024年度の両方にある1,710市区町村で計算しました
- 家庭系ごみ（資源ごみ等を除く）は2022年度以降の表にしかありません
- リサイクル率は焼却灰のセメント原料化なども含む定義（R）です。焼却灰をセメント工場に送る市町村では90%を超えることがあります
- 家庭ごみの有料化の有無は「ごみ処理体制」の表にあり、今回は取得していないので分析していません
- 経費は名目の金額で、物価や人件費の上昇は差し引いていません。市町村ごとの経費ではなく、都道府県単位の合計です
