# 1130 2枚の画像の「似ている度合い」は、画素ごとの差で測るか形で測るかで、似た組の順位がどう変わるのか？（画像と色）

同じ商品を写した画像を探したり、重なった画像を見つけたりするとき、2枚の「似ている度合い」を数えます。いちばん素直なのは、同じ位置の画素の値の差を数えるやり方です。ほかに、小さな窓ごとに明るさ・濃淡の幅・濃淡の並び（形）を比べるやり方もあります。**ここでは、作成者が式と乱数で作った架空の商品の写真に見立てた白黒の画像（商品30点×6枚＝180枚。元の画像と、明るさ違い・濃淡の幅違い・2画素ずれ・ぼかし・粒の5種類の別の写り）で、全部の組16,110組を、①画素の差、②形の似ている度合い、の2つで似ている順に並べ、上位450組（同じ商品の組の数）の顔ぶれがどれだけ重なるか、同じ商品の組がどれだけ入るか、どの写りの組がどこに並ぶかを数えました。窓の大きさ・明るさの違い・粒の強さを変えた27通りも確かめました。**

例の画像は式と乱数で作った架空のもので、実在の写真・商品・カメラを表すものではありません。「似ている」の正しい答えは「同じ商品から作った画像かどうか」で、作成者が置いたものです。人に見てもらって似ているかを確かめたものではありません。

関連する記事：32冊目 第4章の 960「「似ている度合い」の数え方で、似ている文章の組は入れ替わるのか？」は、文章どうしの似ている度合いを4つの数え方で数え、上位の組の顔ぶれがどれだけ重なるかを扱っています。この記事は同じ形の問いを画像で数え、画像に固有の「画素の差」と「形の差」に絞ります。同じ企画の 1129「明るさの差を数値のまま測ると、人が見て感じる差とどこでずれるのか？」は、明るさの差を画素の値で数えたときのずれを扱っています。

## 主な結果

### 2つの物差しの上位450組（`results/a1130_main.json`）
| | ①画素の差 | ②形の似ている度合い |
|---|---|---|
| 上位450組のうち同じ商品の組 | **57.6%** | **52.2%** |
| 上位450組に入った別の商品の組 | 191組 | 215組 |
| 2つの上位450組で共通した組 | **187組** | |
| 全部の組16,110組での順位の相関 | 0.443 | |

- **2つの物差しの上位450組で共通したのは187組だった**。同じ商品の組が上位に入った割合は57.6%と52.2%で大きくは違わないが、入った組の顔ぶれは半分以上入れかわった

### 元の画像と別の写りの組が、上位450組に入ったか（各30組、`results/by_kind.csv`）
| 別の写り | ①画素の差：上位450組に入った割合 | 順位（中央値） | ②形：上位450組に入った割合 | 順位（中央値） |
|---|---|---|---|---|
| 明るさ違い（+25） | **33.3%** | 469位 | **100%** | 17位 |
| 濃淡の幅違い（0.7倍） | 100% | 55位 | 100% | 59位 |
| 2画素ずれ | 40% | 707位 | 46.7% | 627位 |
| ぼかし | 100% | 39位 | 100% | 136位 |
| 粒（標準偏差12） | **100%** | 74位 | **0%** | 8,299位 |

- **明るさだけ違う組は、画素の差では上位に入りにくく（33.3%）、形では全部が上位に入った**。全体に25を足すと、画素の差はほぼ25になる（例の商品で25.0、作りどおり）。形の物差しは明るさの近さを比で数えるので、明るい背景の上では25の違いが小さく効く
- **粒を足した組は、画素の差では全部が上位に入り、形では1組も入らなかった**（順位の中央値8,299位）。形の物差しは、平らな背景の窓で「濃淡の並び」を比べるため、片方にだけ粒があると窓ごとの近さが大きく下がる（例の商品で0.512）
- 2画素ずれは、どちらの物差しでも半分以上が上位450組に入らなかった。どちらも同じ位置どうしを比べるため

### 上位に入った別の商品の組
- 元の画像のうち背景が占める割合は、30点の平均で87.2%だった。上位450組に入った別の商品の組では、画素の差で93.4%、形で95.4%と、**背景の広い商品どうしが、どちらの物差しでも似ていると並んだ**
- 別の商品の組のうち画素の差でいちばん似ていた組は、画素の差で96位、形では341位だった
- 例の商品A（図1）では、元の画像との画素の差は、明るさ違い25、2画素ずれ25.28、粒11.91、ぼかし9.17。形の似ている度合いは、明るさ違い0.992、粒0.512、2画素ずれ0.746だった。画素の差でいちばん近い別の商品は、画素の差31.53・形0.673だった

### 確かめ：置き方27通り（各回で画像を作り直す、`results/grid.csv`）
| | 27通りの結果 |
|---|---|
| 上位450組のうち同じ商品の組：①画素の差 | 41.3〜76.7% |
| 同：②形 | 44.4〜82.7%（①より高かったのは12通り） |
| 2つの上位450組で共通した組 | 180〜350組 |
| 全部の組での順位の相関 | 0.37〜0.644 |
| 明るさ違いの組が上位に入った割合：①／② | 6.7〜100%／100%（27通りすべて） |
| 粒の組が上位に入った割合：①／② | 40〜100%／0〜100% |
| 2画素ずれの組が上位に入った割合：①／② | 16.7〜40%／23.3〜63.3% |

- **どちらの物差しのほうが同じ商品の組を多く上位に集めるかは、置き方で入れかわった**。形のほうが高かったのは、窓5画素で9通り中1通り、7画素で4通り、11画素で7通り。明るさの違いが+10では2通り、+40では6通りだった
- 明るさ違いの組は、27通りすべてで形の上位450組に全部入った。粒の組が形の上位に入る割合は、窓が大きく粒が弱いほど高かった（窓11画素・粒6で100%）

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約20秒）
- 同じ画像どうしなら、画素の差が0、形の似ている度合いが1になることを確かめた（`self_check`）
- 図3枚を開き、日本語・重なり・軸（棒は0から）を確かめた

## データ
- `data/pairs.csv`：全部の組16,110組（img_a・img_b＝画像の番号、prod_a・prod_b＝商品の番号、kind_a・kind_b＝写りの種類、same_product＝同じ商品なら1、pixel_diff・shape_sim＝2つの物差しの値、rank_pixel・rank_shape＝似ている順の順位）
- `results/a1130_main.json`：主な結果すべて（例の商品Aの値 `example_product_A` を含む）

- `results/grid.csv`：27通りの確かめ

## 注意（言えないこと）
- 架空のデータです。商品の画像の作り方、別の写りの種類と強さ、2つの物差しの式（窓の大きさ・c1・c2）は作成者が置いたもので、結果はこれで決まります。どちらの物差しが良いかは、置き方27通りで入れかわりました
- 「似ている」の正しい答えは「同じ商品から作ったか」と置きました。人が見て似ていると感じるかは数えていません
- 2画素ずれの組がどちらでも上位に入りにくいのは、2つとも同じ位置どうしを比べる物差しだからです。位置のずれを探してから比べるやり方は数えていません
- 実在の画像検索・重なり探しの仕組みの良し悪しを表すものではありません
