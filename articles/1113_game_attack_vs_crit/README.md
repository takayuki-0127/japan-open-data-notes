# 1113 攻撃力を10%上げるのと会心率を10ポイント上げるのでは、与えるダメージはどちらが伸びるのか？（ゲームの数値設計）

ゲームの強化で「攻撃力+10%」と「会心率+10ポイント」のどちらかを選ぶ場面があります。どちらも「10」なので同じくらいに見えますが、会心率の10ポイントがどれだけ効くかは、会心のときの倍率と、もとの会心率で決まります。会心の倍率が小さいと、会心率の10ポイントは10%よりずっと小さくしか効きません。さらに、会心はたまにしか出ないため、よく目にする1回のダメージの数字はほとんど変わらず、試し打ちの合計で比べても見分けにくくなります。**ここでは、作成者が置いた架空のゲームの数値（攻撃力1,000・会心率20%・会心の倍率1.5倍、1回のダメージに±10%の振れ）で、2つの強化の1回あたりの平均の伸び（式どおり）、よく見る数字（1回のダメージの真ん中）の伸び、試し打ちの回数ごとに合計で比べて伸びる方を選べた割合を数えました。もとの会心率と会心の倍率を変えた40通りの確かめも行いました。**

例のゲームと数値は作成者が置いた架空のもので、実在のゲームの数値や計算の決まりを表すものではありません。課金・くじの話は扱いません。

関連する記事：989「平均で考えると、どのくじが得に見えるのか？」は、たまに大きく当たるものは平均と多くの人が実際に受け取る量が離れることを扱っています。この記事の「会心率を上げても、よく見る数字はほとんど変わらない」は同じしくみを、ゲームの強化の比べ方に当てたものです。801「星4.8（5件）と星4.3（500件）は、どちらが良い店か？」は、少ない数で比べると振れで答えが入れかわることを扱っています。対戦の勝ち負けの記録の読み方は 1065〜1076（例：1069「キャラクターごとの勝率は、使う人のうまさでどれだけ動くのか？」）で扱っています。同じ企画の 1114「強化の倍率を足し合わせる決まりと掛け合わせる決まりでは、重ねたときの強さはどれだけ違うのか？」は同じ種類の強化を重ねる決まりを、1115「平均のダメージで敵の体力を割って「何回で倒せるか」を出すと、実際の回数とどれだけずれるのか？」はこの記事と同じ置き方で倒すまでの回数を扱っています。1119「命中と会心が関係しているのに別々の確率と見て掛けると、ダメージの見込みはどれだけずれるのか？」は、外れのある攻撃で命中と会心の決め方が関係しているときの見込みのずれと、「命中+10ポイント」と「会心+10ポイント」の選び方を扱っています。1118「上限のある能力を上げ続けると、表に出る強さはどこで伸びなくなるのか？」は、会心率に上限があるときの伸びの縮み方を扱っています。この記事は、勝ち負けの記録ではなく、強化の数値の作り方そのものに絞ります。

## 主な結果

### 1回あたりの平均と、よく見る数字（基本の置き方、乱数100万回、`results/builds.csv`）
| | もと | 攻撃力+10% | 会心率+10ポイント |
|---|---|---|---|
| 1回あたりの平均（式） | 1,100 | 1,210 | 1,150 |
| 平均の伸び（式） | − | **+10%** | **+4.55%** |
| 平均の伸び（乱数100万回） | − | +10% | +4.56% |
| 1回のダメージの真ん中（乱数） | 1,025.07 | 1,127.67 | 1,042.85 |
| 真ん中の伸び（乱数） | − | +10.01% | **+1.73%** |
| 1回のダメージの10%の位置〜90%の位置 | 925.02〜1,500.11 | 1,017.4〜1,649.91 | 928.49〜1,550.03 |
| いちばん大きい1回 | 1,650 | 1,815 | 1,650 |

- **会心の倍率1.5倍では、会心率+10ポイントの平均の伸びは+4.55%で、攻撃力+10%の半分に届かなかった（式どおり）**。会心率の10ポイントで増えるのは「10回に1回、ダメージが0.5倍分増える」ことなので、伸びは 0.1×0.5÷（1＋0.2×0.5）になる
- 1回のダメージの真ん中は、会心率+10ポイントでは+1.73%しか動かなかった（式では 1,025 → 1,042.86）。会心は10回に3回なので、真ん中は会心でない回の中にとどまる。攻撃力+10%は真ん中も+10.01%動いた
- 会心率+10ポイントでは、いちばん大きい1回（1,650）も変わらない。変わるのは大きい数字の出る回数だけだった

### 試し打ちの合計で比べたとき（各10,000組、`results/trial_pick.csv`）
| 試し打ちの回数 | 会心1.5倍（伸びる方：攻撃力、差 10%対4.55%） | 会心2.0倍（伸びる方：攻撃力、差 10%対8.33%） | 会心2.5倍（伸びる方：会心率、差 10%対11.54%） |
|---|---|---|---|
| 10回 | 71.86% | 54.38% | 54.21% |
| 30回 | 84.05% | 55.88% | 55.63% |
| 100回 | 96.62% | 62.67% | 58.25% |
| 300回 | 99.91% | 70.38% | 64.51% |
| 1,000回 | 100% | 83.4% | **75.1%** |

- 会心の倍率を2.5倍にすると、会心率+10ポイントの平均の伸びは+11.54%で、攻撃力+10%を上回った（式どおり）
- ただし、その差は、それぞれ1,000回打った合計で比べても75.1%しか正しく見分けられなかった。10回では54.21%で、でたらめ（50%）とほとんど変わらない
- 差の大きい会心1.5倍では、30回で84.05%、100回で96.62%が見分けられた

### 確かめ：もとの会心率と会心の倍率を変えると（40通り、式、`results/grid.csv`）
| 会心の倍率 | 会心率+10ポイントが上回った | 同じ | 攻撃力+10%が上回った |
|---|---|---|---|
| 1.5倍 | 0通り | 0通り | 10通り |
| 2.0倍 | 0通り | 1通り（もと0%） | 9通り |
| 2.5倍 | 4通り（もと0〜30%） | 0通り | 6通り |
| 3.0倍 | 5通り（もと0〜40%） | 1通り（もと50%） | 4通り |

- **40通りのうち、会心率+10ポイントが上回ったのは9通り、攻撃力+10%が上回ったのは29通り、同じが2通り**。会心率+10ポイントの伸びは3.45%（会心1.5倍・もと90%）〜20%（会心3.0倍・もと0%）と動いた
- 会心率+10ポイントの伸びは、もとの会心率が高いほど小さくなった。攻撃力+10%と同じになる会心の倍率は、もとの会心率20%で2.25倍、50%で3倍、80%で6倍（式どおり、`results/a1113_main.json` の tie_mult_by_base_crit）

## 注意（言えないこと）
- 架空の数値です。攻撃力・会心率・会心の倍率・振れの幅は作成者が置いたもので、どちらが伸びるかはこれで決まります。主な値（平均の伸び・40通り）は置いた式どおりです
- 敵の防御、会心率の上限（100%）、命中しない回、会心どうしの重なりは入れていません。会心率の上限は 1118、命中しない回と会心の関係は 1119 で扱っています。防御をダメージから引くと、攻撃力の伸びは10%と違ってきます
- 比べたのは1回あたりの平均と合計だけです。敵を何回で倒せるかは別の問いで、平均のダメージで割った見込みは実際の回数より少なめに出ます（1115）
- 実在のゲームでどちらを選ぶべきかを言うものではありません
