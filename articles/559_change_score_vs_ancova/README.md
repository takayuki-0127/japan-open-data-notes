# 559 前後の差で比べるか、前の値を入れた回帰で比べるかで、効果の答えが変わるのはなぜか（手法の解説・正解の分かるデータで試す）

施策の前と後で売上を測ったとき、効果の出し方は主に2つあります。「施策あり・なしで、前後の差（後−前）の平均を比べる」方法と、「後の売上を、施策ありなしと前の売上で回帰する（共分散分析）」方法です。同じデータでも、2つの答えは食い違うことがあります（Lord のパラドックスとして知られる）。**ここでは、本当の効果が2万円の架空の400店で、施策をする店の決め方（割り付けの仕組み）を3通りに変え、2,000回くり返して比べました。** 数字は置いた前提で決まります。

## 主な結果（本当の効果は 2万円、2,000回の平均）
- **A くじで決める**：前後の差 2.01、前の値を入れた回帰 2.01。ぶれ（標準偏差）は 0.87 と 0.78 で、回帰のほうが小さい
- **B 前の売上が低い30%の店にする**：前後の差 7.99（4倍）、回帰 2.02。施策をした店は前の売上が平均16.5万円低く、施策がなくても後で上がる（平均への回帰）。95%信頼区間が2を含んだ割合は 0% と 95%
- **C もともと水準の低い系列の店にする**：前後の差 1.98、回帰 0.18。95%信頼区間が2を含んだ割合は 95% と 37%。回帰は前の値の傾き（0.64）で前の差（−5.0万円）の64%だけを差し引くため、残りの差が効果から引かれる
- **前後の相関を変えると**：B では前後の差のずれが、相関0.2で 15.2、0.95で 2.8。C では回帰のずれが、相関0.2で −2.0、0.95で 1.75。相関が1に近いほど、2つの方法は近づく
- **例の1回（B）**：前後の差 7.28、回帰 −1.56、群内の傾き 0.47（2,000回の中では回帰の値が低く出た1回）

## 確かめたこと

## データ

## 注意（言えないこと）
- 架空のデータ。ふだんの水準・日ごとの振れ・施策の決め方は作成者が置いたもので、結果はこれで決まる
- どちらの方法が当たるかは、施策をする店をどう決めたかで決まる。B のように前の値そのもので決めたなら回帰、C のように前の値と関係する別の安定した違いで決めたなら前後の差が当たる。実際にはどちらか分からないことも多い
- C で前後の差が当たったのは、施策がなければ2つの系列が同じだけ動く（平行に動く）と置いたため。系列で伸び方が違えば、前後の差も外れる
- 季節や景気のように全店に同じく効く動きは入れていない
