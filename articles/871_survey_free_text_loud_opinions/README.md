# 871 自由記述の多い意見は、全体の多い意見なのか？（アンケート）

アンケートの自由記述は、件数の多い順にまとめられがちです。しかし、自由記述に書くかどうかは、その意見を持っている人の多さだけでなく、その話題の書きやすさ（腹が立った出来事は書きやすい、など）にも左右されます。**ここでは、作成者が乱数で作った架空の店の来店客アンケート（8つの困りごとを持つ人の本当の割合と、困りごとごとの書きやすさを作成者が置いたもの）で、自由記述の件数の順が本当の多さの順とどれだけ合うかを数え、選択肢で少人数に聞いた場合と比べました。**

「当てはまるものをすべて」と「1つだけ」で割合がどう変わるかは関連する記事 864 で扱っています。この記事は「自由記述の件数を、全体の多さとして読めるか」に絞ります。

## 主な結果

### 困りごとごとの本当の割合と、自由記述（3,000人、500回の平均）
| 困りごと | 本当の割合 | 本当の順位 | 自由記述に書いた人（回答者の中の割合） | 自由記述の件数の中の割合 | 自由記述の順位（平均） | 選択肢200人の順位（平均） |
|---|---|---|---|---|---|---|
| レジの待ち時間 | 30% | 1 | 3.89% | 23.8% | 1.04 | 1.24 |
| 品ぞろえ | 26% | 2 | 3.04% | 18.6% | 2.05 | 2.02 |
| 駐車場の狭さ | 22% | 3 | 1.99% | 12.2% | 4.07 | 2.91 |
| 営業時間 | 17% | 4 | 1.32% | 8.1% | 6.42 | 4.02 |
| ポイントの仕組み | 13% | 5 | 1.34% | 8.2% | 6.25 | 5.18 |
| 店内の案内表示 | 11% | 6 | 0.73% | 4.5% | 7.97 | 5.74 |
| 店内の清潔さ | 7% | 7 | 1.62% | 9.9% | 5.18 | 7.11 |
| 店員の対応 | **5%** | **8** | 2.42% | **14.8%** | **3.03** | 7.79 |

- 本当はいちばん少ない「店員の対応」（5%）が、自由記述では件数の中の14.8%を占め、平均3.03番目に多かった。500回のうち89%で3番目以内に入った
- 自由記述の件数は1回あたり平均491件（回答者3,000人）。「自由記述の中の割合」は書いた人の中の割合で、回答者全体の割合ではない。「レジの待ち時間」は自由記述の中では23.8%だが、回答者の中で書いた人は3.89%、本当に困っている人は30%だった
- 回答者の15%の「よく書く人」が、自由記述の件数の33.7%を書いた

### 本当の順位との合い方（500回）
| | 3,000人の自由記述の件数 | 200人に選択肢で聞いた割合 |
|---|---|---|
| 本当の順位との順位相関（平均） | **0.49** | **0.96** |
| 順位相関の5〜95%の範囲 | 0.36〜0.62 | 0.90〜1.00 |
| 1位が当たった割合 | 96.4% | 79.2% |
| 上位3つのうち当たった数（平均） | 2.10 | 2.86 |

- 順位相関（スピアマンの順位相関）は、2つの順位がどれだけ同じ並びかを−1〜1で表す。1なら完全に同じ順
- 200人に選択肢で聞くほうが、3,000人の自由記述より順位全体はよく当たった
- ただし1位だけは、自由記述のほうがよく当たった（96.4%と79.2%）。1位と2位の本当の差（30%と26%）が小さく、200人では入れ替わることがあるため

### 確かめ：書きやすさの差の強さ×回答者の数（順位相関、各300回）
| 書きやすさの差の強さ | 300人 | 1,000人 | 3,000人 | 「店員の対応」の自由記述の順位（3,000人） |
|---|---|---|---|---|
| 0（差なし） | 0.835 | 0.944 | 0.979 | 7.86 |
| 0.5 | 0.699 | 0.811 | 0.877 | 6.14 |
| 1（基本） | 0.431 | 0.500 | 0.490 | 3.09 |
| 1.5 | 0.140 | 0.137 | 0.133 | 1.35 |

- **書きやすさに差がなければ（0）、自由記述の件数の順位もほぼ当たった**（3,000人で0.979）。自由記述の読み違いは、置いた書きやすさの差の写しに近い
- 書きやすさに差があると、回答者を増やしても順位相関は上がらなかった（基本の置き方で300人0.431・1,000人0.500・3,000人0.490）。人数を増やして減るのは偶然の揺れの分だけで、書きやすさの差の分は残る
- よく書く人の割合と倍率を変えると（3,000人、書きやすさの差は基本）、順位相関は、よく書く人なしで0.476、15%×3倍で0.504、30%×5倍で0.616だった。よく書く人は件数の0%・33.9%・66.2%を書いた。よく書く人が多いと書く確率が上限（95%）に近づき、書きやすさの差が縮むため、少し上がった（`results/sensitivity_heavy_writers.csv`）

### 1回分のデータ（data/respondents.csv）
- 回答者3,000人のうち462人が自由記述を書き、件数は493件だった。件数の順は、レジの待ち時間141件・店員の対応82件・品ぞろえ76件・駐車場の狭さ59件の順で、「店員の対応」（本当は5.4%の人が持つ）が2番目だった

## 動かし方
```
pip install -r requirements.txt
cd src && python a871_free_text.py
```
5秒ほどで終わります。`data/respondents.csv` と `data/topics.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の9ファイルがバイト単位で一致した（cmp、約5秒）
- 書きやすさの差の強さを0〜1.5に変えると、自由記述の順位相関は0.979〜0.133と大きく動いた（3,000人）。「0.49」はこの置き方での値
- 書きやすさの差がないとき（0）は、自由記述でも人数が多いほど順位が当たった（300人0.835 → 3,000人0.979）。差があるときは人数で直らなかった

## データ
- `data/respondents.csv`：架空の回答者3,000人（1回分）。resp_id・heavy_writer（よく書く人か、1/0）・has_1〜has_8（その困りごとを持っているか）・wrote_1〜wrote_8（自由記述に書いたか）
- `data/topics.csv`：8つの困りごと。topic_no・topic・true_share（本当の割合）・ease（書きやすさ）

## 注意（言えないこと）
- 架空のデータです。困りごとの本当の割合、書きやすさ、よく書く人の割合は作成者が置いたもので、結果はこれで決まります。とくに「店員の対応が3番目に多く見える」は、置いた書きやすさ（4.0）の写しです。どの話題が実際に書きやすいかは、ここでは測っていません
- 自由記述は「1つの困りごとにつき1件」と数えました。1人が同じことを長く書く、言い回しで分類が割れる、などは入れていません
- 選択肢の質問は、困りごとを持っている人は必ず選ぶと置きました。選択肢の並び順や「すべて選ぶ」の取りこぼしは入れていません（関連する記事 863・864）
- 自由記述は、件数の多さとは別に、選択肢にない困りごとや具体的な出来事を知る手がかりになります。この記事は、件数を「全体の多さ」として読めるかだけを扱いました
- 実在の店やアンケートを表すものではありません
