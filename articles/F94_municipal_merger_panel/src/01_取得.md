# 01_取得（ブラウザで e-Stat から取得）

e-Stat はコンテナから直接届かないため、Chrome のページ内で fetch して取得した。

## 1. 廃置分合等情報（CSV）

1. https://www.e-stat.go.jp/municipalities/cities/absorption-separation-of-municipalities を開く
2. 検索条件：廃置分合等施行年月日 2000年10月2日〜2020年10月1日、都道府県すべて、境界変更は既定（含まない）
3. ページ内のフォームの値に `file_format=csv&charset=UTF-8&bom=0&op=download` を足した URL を fetch（画面の「ダウンロード」→「CSV形式（UTF-8 BOM無し）」と同じ）
4. 2,677行（改正事由に改行を含むため、ファイルの行数は 3,581）

## 2. 2000年国勢調査 第1次基本集計 都道府県結果 第1表（Excel × 47）

- 一覧：`https://www.e-stat.go.jp/stat-search/files?layout=dataset&toukei=00200521&tstat=000000030001&tclass1=000000030001&tclass2=000000030005&tclass3=<県>&tclass4=<県の報告書掲載表>`
  - 北海道 tclass3=000000030006・tclass4=000000030007 から、県ごとに 3 ずつ増える（沖縄 000000030144・000000030145）
- 各一覧で「総人口・総世帯数 1 人口，人口増減（平成7年～12年），面積及び人口密度」の表の ID（`a.js-data` の `data-value`。英字を含むものがある）を取り、
  `https://www.e-stat.go.jp/stat-search/file-download?statInfId=<ID>&fileKind=0` を fetch して SheetJS（xlsx 0.18.5）で読み込む
- 福井県の表だけ列の並びが違う（7桁コードの列がない）。`02_整形.py` で名前の列の位置から合わせる

## 3. 保存

上の2つを `{"merger_csv": <CSVの文字列>, "census2000_t1": {"1": {"id":…, "rows":[…]}, …}}` の JSON にまとめ、1回だけダウンロードして `data/raw/f94_raw.json`（2.2 MB）に置いた。
