# 177 受療率の都道府県差は、年齢をそろえても残るか：患者調査

厚生労働省「患者調査」（令和5年＝2023年）の都道府県・年齢階級別の受療率と、総務省「人口推計」（2023年10月1日）の都道府県別人口を使い、直接法で年齢調整した受療率を比べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A177 | 入院・外来の受療率の都道府県差は、高齢者の多さをそろえても残るか | 直接法による年齢調整（基準人口＝2023年の全国の年齢構成、10階級）。粗率と調整率の比較、順位の変化、最大÷最小・変動係数 | `src/a177_age_adjust.py` |

## 主な結果
- 入院受療率（人口10万対）は、そのままだと高知1,785〜神奈川665で2.68倍。年齢調整後は鹿児島1,573〜神奈川715で2.20倍。差は縮むが大きく残る
- 調整後の入院の上位は 鹿児島1,573・長崎1,467・高知1,458・熊本1,408・佐賀1,394・福岡1,365・山口1,316・大分1,304・徳島1,227・北海道1,203。上位12県のうち10県が九州・四国・山口
- 九州・四国・山口の12県の調整後入院受療率は平均1,325で、ほかの35都道府県の平均917の1.4倍
- 年齢調整で順位が大きく下がったのは秋田（14位→22位）、新潟、山形など高齢化の進んだ県。上がったのは沖縄（26位→12位）、大阪、東京
- 外来は差が小さく、そのままで1.51倍、調整後1.40倍。調整後の1位は愛知6,769、最も低いのは京都4,820
- 粗率と65歳以上の割合の相関は入院0.63、調整後は0.40

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a177_age_adjust.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/jyuryo_2023_pref_age.csv | 都道府県（全国含む）、年齢階級（総数＋10階級）、入院受療率・外来受療率（人口10万対、男女計）、人口（千人） |

- 受療率：e-Stat「患者調査」令和5年 都道府県編 第36表（受療率（人口10万対），入院－外来・性・年齢階級×都道府県別）の総数（男女計）
- 人口：e-Stat「人口推計」2023年10月1日現在 第10表（都道府県，年齢（5歳階級），男女別人口－総人口）を、患者調査の年齢階級（0〜4、5〜14、…、85以上）にまとめた

## 注意
- 受療率は調査日（10月の1日）に医療施設で受療した推計患者数をもとにした値で、標本調査の誤差がある（例：神奈川の85歳以上の外来18,073は前後の階級より大きく外れる）
- 受療率は患者の住所地ではなく施設の所在地で集計されている
- 年齢調整は10階級でしか行っていないので、階級の中の年齢の違いは残る。男女の構成の違いは調整していない
- 調整後の値は基準人口（今回は2023年の全国）によって変わる。順位の比較に使う
