# 283 食料品の輸出は、どの品目で伸びたのか

財務省「貿易統計」の統計品別表（輸出、9桁）のうち、HS 第1〜23類（食料品・飲料・飼料、たばこの第24類は除く）を「食料品」とし、2015・2020・2025年の輸出額の伸びを品目（HS 4桁）ごとに分けたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A283 | 食料品の輸出は、どの品目で伸びたのか | HS 4桁の品目ごとの増加額と、増加に占める割合。数量の単位がそろう品目は、増加を「量」「ドルに直した単価」「為替（ドル円）」に分ける（対数平均の重み、A281 と同じ方法） | `src/a283_food_exports.py` |

## 主な結果
- 食料品の輸出は2015年6,294億円 → 2020年8,376億円 → 2025年1兆3,886億円（10年で2.2倍、2020→2025年は1.66倍）。輸出全体に占める割合は0.8% → 1.3%
- 増加7,593億円の58%を上位10品目、81%を上位20品目（182品目中）が占める。増えた額の大きい順に、その他の調製食料品（2106、+680億円）、茶（0902、+620億円、104→724億円）、ウイスキーなどの蒸留酒（2208、+575億円）、ソース・調味料（2103、+533億円）、清涼飲料水など（2202、+407億円）、清酒などの発酵酒（2206、+348億円）、ほたて貝などの軟体動物（0307、+330億円）、魚のフィレ・すり身など（0304、+308億円）、冷凍牛肉（0202、+304億円）、生鮮・冷蔵牛肉（0201、+303億円）
- 酒類（ビール・ワイン・清酒など・蒸留酒）は390億円 → 1,495億円（3.8倍）
- 182品目中42品目は減った。いちばん減ったのは甲殻類・軟体動物の調製品（1605、484→297億円）
- 2020→2025年で、数量の単位がそろう品目（2025年の金額の91%）の増加4,686億円を分けると、量 +2,756億円、為替 +3,310億円、ドルに直した単価 −1,380億円。量は伸び、ドルで見た単価は下がっていた。茶だけはドル単価もわずかに上がった

## 頑健性
- 2015→2025年で同じように分けると、そろう品目は2025年の金額の71%しかない（2017・2022年の HS 改正で品目番号が変わったため）。その範囲では量 +2,512億円、為替 +1,443億円、ドル単価 +855億円で、量がいちばん大きいのは同じ
- 2106（その他の調製食料品）は2020年1,287億円から2025年1,186億円に減っており、10年の増加は2015→2020年の分
- コードは新しいフォルダで2回動かし直し、results と figures のすべてのファイルが一致することを確かめた

## 動かし方
```
pip install -r requirements.txt
cd src && python a283_food_exports.py   # data/ から results/ と figures/ を作る
python fetch.py                          # data/ を e-Stat・日本銀行 API から作り直す（任意）
```

## データ
- `data/food_exports_hs9.csv`：統計品別表（輸出、1-12月）の HS 第1〜23類の品目番号・単位・数量・金額（千円）。e-Stat の statInfId は `src/fetch.py`
- `data/all_exports_total.csv`：輸出全体の金額
- `data/hs9_to_gaikyo_export.csv`：品目番号を概況品に割り当てた表（作成者が作成）
- `data/usdjpy_annual.csv`：ドル円の年平均（日本銀行、[F282](../F282_yen_exports_quantity_price) で取得したもの）

## 注意
- 農林水産省の「農林水産物・食品の輸出額」とは範囲が違う（真珠・木材・たばこなどを含まない一方、農林水産省が除くものを含む場合がある）。金額は一致しない
- 品目の名前（HS 4桁）は、作成者が HS の項の内容から短くつけたもの
- 単価は「金額÷数量」で、品質や中身の変化も含む。「為替」の分は、すべての輸出がドルで値決めされていると考えた場合の分け方（推測）
- 増えた理由（海外の需要、販売の取り組み、規制の変更など）は、貿易統計からは分からない
