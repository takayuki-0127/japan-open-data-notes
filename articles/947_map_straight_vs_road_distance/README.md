# 947 まっすぐの距離と道のりの距離で、近い店は入れ替わるのか？（地図と場所）

地図の上で「いちばん近い店」を選ぶとき、まっすぐの距離（直線の距離）で測るのは手軽です。けれども、人は道を歩くので、道が碁盤の目なら斜めには進めず、川があれば橋まで回り道をします。**ここでは、作成者が乱数で作った架空の町（碁盤の目の道と、橋が2本だけの川を作成者が置いたもの）で、家ごとに「まっすぐの距離でいちばん近い店」と「道のりでいちばん近い店」を比べ、入れ替わる家の割合と、まっすぐの距離で選んだときに余分に歩く道のりを数えました。** 橋の数と店の数を変えて確かめ、川がないときの碁盤の目だけの効きとも比べました。

地図は架空の格子で、実在の地名や地図のデータは使っていません。

関連する記事：区域の線の引き方で1位の地区が変わる話は 945、店の数を面積で割るか人口で割るかで地図が変わる話は 946 で扱っています。距離から配送の時間を見積もるときの外れは 952、2つの地区の間のどこに拠点を置くと合計の距離が短いかは 956（道のりで測った場合も数えた）で扱っています。この記事は、距離の測り方で「いちばん近い店」が変わるかに絞ります。

| # | 問い | 手法 | ファイル |

| A947 | まっすぐの距離でいちばん近い店と、道のりでいちばん近い店は、どれだけの家で違うか。違うとき、余分に何m歩くか。「半径500m以内に店がある家」は、道のりで数えるとどれだけ減るか | 架空の町は40×40の交差点（となりの交差点まで100m）の碁盤の目の道。町の真ん中（19番目と20番目の行の間）を東西に川が流れ、渡れるのは橋の列だけ（基本は2本、x＝10と30）。家は交差点ごとに1軒（1,600軒）、店はランダムな交差点に6軒。道のりは道に沿った最短の距離（交差点を1つ進むごとに100m）。家ごとに、まっすぐの距離でいちばん近い店（同じ距離が複数あれば道のりの短いほう）まで歩く道のりが、道のりでいちばん近い店までの道のりより長いとき「入れ替わる」と数えた。店の置き場所を変えて500回数えた。確かめとして、橋の数（川なし・8・4・2・1本）と店の数（3・6・12軒）を変え、各300回で数えた。川のない碁盤の目で、向きがでたらめなときの「道のり÷まっすぐの距離」の平均は4/π（約1.27）になる式とも比べた。seed 947 | `src/a947_straight_vs_road.py` |

## 主な結果

### 例の町（店6軒・橋2本）
| | 値 |
|---|---|
| 近い店が入れ替わる家 | **127軒（7.9%）** |
| そのうち、まっすぐで近い店が川の向こう側にある家 | 67軒 |
| 入れ替わる家の余分な道のり | 中央値200m・最大1,500m |
| 余分な道のりが200m以下の家 | 71軒 |
| 500m以上余分に歩く家（全体のうち） | 1.6% |
| まっすぐ500m以内に店がある家 | 25.4% |
| 道のり500m以内に店がある家 | 19.2% |

入れ替わる家127軒の余分な道のり：100m 49軒、200m 22軒、300m 19軒、400m 11軒、600m 9軒、800m 7軒、1,000m 5軒、1,300m 3軒、1,500m 2軒。

### 店の置き場所を変えて500回（店6軒・橋2本）
| | 平均 | 10〜90%の範囲 |
|---|---|---|
| 近い店が入れ替わる家 | **10.8%** | 5.3〜17.5% |
| 余分な道のり（入れ替わる家の中央値） | 300m | |
| 500m以上余分に歩く家（全体のうち） | 3.9% | |
| まっすぐ500m以内に店がある家 | 24.2% | |
| 道のり500m以内に店がある家 | **18.3%** | |
| 道のり÷まっすぐの距離 | 中央値1.33・平均1.37 | |

- まっすぐの距離で選ぶと、平均で家の10.8%が、道のりでいちばん近い店とは別の店を選ぶことになった
- 「半径500m以内に店がある家」はまっすぐで数えると24.2%、道のりで数えると18.3%。まっすぐの距離の円で数えると、店の近い家を多めに数えた。道のりはまっすぐの距離より短くならないので、減る向きは式どおりで、数えたのはその大きさ

### 確かめ：橋の数と店の数を変えると（各300回の平均）
| 変えたもの | 値 | 入れ替わる家 | 10〜90% | 余分な道のり（中央値） | 500m以上余分に歩く家 | まっすぐ500m以内 | 道のり500m以内 | 道のり÷まっすぐ（平均） |
|---|---|---|---|---|---|---|---|---|
| 橋の数 | 川なし | **7.1%** | 3.4〜12.1% | 200m | 0.5% | 24.3% | 19.2% | 1.26 |
| | 8本 | 6.9% | 3.4〜11.4% | 200m | 0.5% | 24.3% | 18.8% | 1.27 |
| | 4本 | 7.6% | 3.9〜11.7% | 200m | 0.7% | 24.1% | 18.4% | 1.30 |
| | **2本（基本）** | 10.9% | 6.1〜17.3% | 300m | 3.9% | 24.1% | 18.2% | 1.37 |
| | 1本 | **16.2%** | 7.8〜25.9% | 800m | 10.1% | 24.0% | 18.1% | 1.53 |
| 店の数（橋2本） | 3軒 | 9.8% | 3.7〜18.6% | 300m | 3.6% | 12.8% | 9.6% | 1.36 |
| | **6軒（基本）** | 10.7% | 5.6〜16.2% | 300m | 3.7% | 24.2% | 18.4% | 1.37 |
| | 12軒 | 10.7% | 6.9〜15.2% | 300m | 3.6% | 42.4% | 33.3% | 1.37 |

- **近い店が入れ替わる家の割合は、置き方で6.9〜16.2%動いた。川がなくても7.1%残った。** 碁盤の目では斜めに進めないので、まっすぐの距離が同じくらいの2つの店は、向きによって道のりの順が入れ替わる
- 橋が1本になると、入れ替わる家は16.2%に増え、余分な道のりの中央値は800mになった。川の効きは、橋が4本以上あるとほぼ消えた（7.6%以下）
- 川のない町の「道のり÷まっすぐの距離」の平均は1.26で、碁盤の目で向きがでたらめなときの式の値4/π（1.27）に近かった。作りが置いたとおりに動いていることの確かめ
- 店の数を3軒から12軒に変えても、入れ替わる家の割合は9.8〜10.7%でほぼ同じだった
- 基本の置き方は、変えたものごとに乱数を変えて数え直したので、入れ替わる家は10.7〜10.9%と、500回の10.8%から少し動く

## 注意（言えないこと）
- 架空のデータです。碁盤の目の道、川と橋の場所、家と店の置き方は作成者が置いたもので、結果はこれで決まります。入れ替わる家の割合は、置き方で6.9〜16.2%と動きました。実際の町の道や店を表すものではありません
- 道はすべて碁盤の目で、斜めの道、行き止まり、一方通行、坂、信号、線路は入れていません。斜めの道が多い町では、まっすぐの距離と道のりの差は小さくなると考えられます（推測）
- 人は道のりでいちばん近い店に行くとは限りません。店の大きさ、品ぞろえ、通勤の道の途中かどうかは入れていません
- どの店を選ぶべきか、どこに出店すべきかは言えません。この記事は、距離の測り方で「いちばん近い店」がどれだけ変わるかを数えただけです
