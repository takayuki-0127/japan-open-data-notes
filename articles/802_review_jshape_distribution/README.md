# 802 星の平均で、「普通」の多さは見えるのか？（口コミと星の数）

口コミの星を全部合わせると、星5がいちばん多く、次に星4、星3と下がり、星2で底を打って星1で少し上がる「Jの字」の形になりやすいとされます。こうした分布では、平均の星が同じ店でも、星2〜4の「普通」の口コミが多い店もあれば、星5と星1に割れている店もあります。**ここでは、作成者が乱数で作った架空の店1,000軒（本当の星の分布を作成者が置いたもの）で、見かけの平均がほぼ同じ店の中で「普通」（星2〜4）の割合がどれだけ違うか、平均からどれだけ言い当てられるかを数えました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A802 | 星の平均が同じ店どうしで、「普通」（星2〜4）の割合はどれだけ違うか。平均からどれだけ言い当てられるか | 架空の店1,000軒。店ごとの本当の星の分布は「ふつうの山」と「両極端（星1か星5）」を混ぜたもの。ふつうの山は、中心が本当の平均 μ（平均3.9・標準偏差0.45の正規分布、2.5〜4.8で切る）、幅0.8 の1〜5の山形。両極端の割合（偏り）w は 0〜0.6 の一様分布で、μ とは無関係に置いた。両極端の中の星5の割合は (μ−1)/4 として、混ぜても店の平均が μ のままになるようにした。口コミの件数は30〜1,000件（対数で一様）、星は本当の分布から引く。見かけの平均3.9〜4.1の店を取り出し、本当の「普通」の割合の幅を数えた。「平均で言い当てられる割合」は、直線の当てはめの決定係数。確かめとして、w の上限を0.3・0.9に変えたもの、「評価の低い店ほど両極端」にしたもの（w を μ に結びつける）を、店2,000軒×20回で数えた。seed 802 | `src/a802_jshape.py` |

## 主な結果

### 口コミ全部を合わせた星の分布（店1,000軒・287,700件）
| 星1 | 星2 | 星3 | 星4 | 星5 |
|---|---|---|---|---|
| 8.2% | 3.2% | 17.6% | 30.3% | 40.7% |

- 星5がいちばん多く、星2がいちばん少ない。星1は星2より多い（Jの字）

### 見かけの平均が3.9〜4.1の店（167軒）の、本当の分布
| | 10%の店 | 90%の店 | いちばん少ない店 | いちばん多い店 |
|---|---|---|---|---|
| 「普通」（星2〜4）の割合 | **33.9%** | **70.5%** | 26.6% | 77.0% |
| 星1の割合 | 1.6% | 14.0% | | |
| 星3の割合 | 9.8% | 22.4% | | |

- 平均がほぼ同じでも、「普通」の割合は3割台から7割まで散らばった。星1の割合も1.6%から14.0%まで違った

### 同じ平均4.0前後の2軒（見かけの平均3.95〜4.05・口コミ300件以上の中で、両極端の割合がいちばん小さい店と大きい店）
| | 店A | 店B |
|---|---|---|
| 件数 | 521件 | 538件 |
| 見かけの平均 | 4.05 | 4.04 |
| 星1・2・3・4・5の割合 | 0.0%・1.9%・19.8%・49.7%・28.6% | 13.0%・0.7%・9.9%・21.6%・54.8% |
| 「普通」（星2〜4）の割合 | **71.4%** | **32.2%** |

### 平均から言い当てられる割合（店1,000軒、決定係数）
| 言い当てたいもの | 平均だけ | 平均と星のばらつき（標準偏差） | 星1〜2の口コミの割合を直接見る |
|---|---|---|---|
| 本当の「普通」の割合 | 0.43 | 0.75 | |
| 本当の星1〜2の割合 | 0.68 | | 0.90 |

- 平均だけでは「普通」の割合の4割ほどしか言い当てられなかった。星のばらつき（標準偏差）を合わせると7割台に上がった

### 確かめ：両極端の度合いの置き方を変える（店2,000軒×20回の平均）
| 置き方 | 平均3.9〜4.1の店の「普通」の割合（10〜90%の範囲） | 平均だけで言い当てられる割合 |
|---|---|---|
| 両極端は0〜30% | 53.5〜73.3% | 0.72 |
| 両極端は0〜60%（基本） | 34.1〜70.1% | 0.42 |
| 両極端は0〜90% | 14.4〜67.9% | 0.18 |
| 評価の低い店ほど両極端 | 50.8〜67.1% | 0.27 |

- 店ごとの両極端の度合いの差が大きいほど、平均の同じ店どうしで「普通」の割合の差は広がった
- 「評価の低い店ほど両極端」と置くと、平均の同じ店どうしの幅は狭くなった（平均に両極端の度合いが一部含まれるため）

## 動かし方
```
pip install -r requirements.txt
cd src && python a802_jshape.py
```
数秒で終わります。`data/shops.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダに `src/` と `requirements.txt` だけを写して流し直し、results・figures・data の6ファイルがバイト単位で一致した（cmp）。所要は5秒以内

## データ
- `data/shops.csv`：架空の店1,000軒（shop_id・n（口コミの件数）・polar（両極端の割合 w）・true_mean（本当の平均）・mean（見かけの平均）・cnt1〜cnt5（星ごとの口コミの件数））

## 注意（言えないこと）
- 架空のデータです。Jの字の形、両極端の度合いの幅、両極端の度合いが平均と無関係なことは作成者が置いたもので、結果はこれで決まります。確かめのとおり、置き方を変えると幅は14〜73%の間で動きます
- 「普通」を星2〜4としたのは作成者の決め方です。星3だけを「普通」とする見方もあります（星3の割合も表に載せました）
- 口コミを書く人の偏り（とても満足した人や不満な人ほど書く）は入れていません。本当の分布をそのまま口コミの分布として置きました（書く人の偏りは 803 で扱います）
- 件数の少ない店の平均の振れ（801 で扱いました）は、件数を30件以上にして小さくしています
- 実際の口コミサイトの星の分布を表すものではありません
