# 1203 登録して間もない人ほどよく開くとき、全体の開封率の下がり方は、読者の入れかわりでどれだけ説明できるのか？（メール配信）

お知らせのメールは、登録したばかりの人ほどよく開き、登録してから時間がたつと開かなくなっていきます。入会の勢いが落ちると、読者の中で登録して間もない人の割合が減るので、メールの中身が同じでも、全体の開封率（開いた通数÷送った通数）は下がります。ここで「開封率が下がったのはメールがつまらなくなったから」と読むと、読者の入れかわりの分までメールのせいにしてしまいます。**ここでは、作成者が置いた架空の店の会員向けのお知らせのメール（1人ひとりのもとの開く確率、登録してからの週数で開く確率が下がる形、毎週の入会とやめる割合を作成者が置き、乱数で作ったもの）で、送り始めの13週と最後の13週の開封率の差のうち、登録してからの週数の内訳を前の13週にそろえると消える分（入れかわりで説明できる分）を、週数の分け方を変えて数えました。メールそのものが弱くなる場合、後から入る人ほどもともと開きにくい場合とも比べ、置き方を変えた72通りでも確かめました。**

例の店・会員・メールは架空のもので、実在の店・メール配信の仕組みを表すものではありません。どんな中身を送るとよいか、値引きなどの書き方の良し悪しは扱っていません。

関連する記事：1072「調整の前後でキャラクターの勝率を比べると、使う人の入れかわりが何をまぜるのか？」は、同じ「入れかわり」が前後の比べにまざる形を、対戦ゲームの勝率で扱っています。1171「中身の種類で圧縮のかかり方が違うとき、種類の割合が変わると全体の圧縮率はどう動くのか？」は、全体の率が内訳の割合の重みで動く形を、保存データの圧縮率で扱っています。995「「前年比120%」の来場は、新しい人か、来る回数が増えたのか？」は、新しい人と前からの人に分けて読むときのずれを来場者で扱っています。同じ企画の 1201「長く開いていない人に送るのをやめて開封率が上がったのは、メールが良くなったからなのか？」は、送る相手を外して読者の顔ぶれを変えたときの開封率の上がり方を扱っています。同じ企画の 1204「迷惑メールに振り分けられた分は、開封率の数字のどこに表れるのか？」は、開封率が下がる別の理由（迷惑メールのフォルダへの振り分け）を、送る側に見える数字で扱っています。この記事は、メールの読者に固有の「登録してからの週数」で内訳をそろえるとき、分け方の細かさと、メールのせいか読者のせいかの見分けに絞ります。

## 主な結果

### S1 メールは変わらない（50回の平均、`results/scenarios_summary.csv`）
| 週数の分け方 | 前の13週 | 後の13週 | 内訳をそろえた後の13週 | 入れかわりで説明できる割合（10〜90%） |
|---|---|---|---|---|
| 1週ごと | 20.12% | 16.79% | 20.06% | **98.55%**（87.67〜109.26%） |
| 4週ごと | 20.12% | 16.79% | 20.06% | 98.36% |
| 3つ（12週未満・12〜51週・52週以上） | 20.12% | 16.79% | 19.83% | 91.34% |
| 2つ（1年未満・1年以上） | 20.12% | 16.79% | 19.16% | **71.27%** |

- **メールの強さを変えていないのに、開封率は20.12%から16.79%へ3.33ポイント下がった**。1回分のデータでは、登録して12週未満の人に送った通数の割合が、前の13週の22.16%から後の13週の4.84%に減った。入った週の開封率は34.7%、52週以上の人は15.76%だった
- **登録してからの週数を1週ごとにそろえると、下がり幅の98.55%が消えた（ほぼ全部が入れかわりの分。作りどおり）**。4週ごとでも98.36%だった
- **1年で2つに分けると71.27%しか消えず、残りの約3割はメールが弱くなったように見えた**。1年未満の中でも、登録して間もない人の割合が減るため（1年未満の区分の中で入れかわりが残る）
- 後の13週の内訳にそろえて比べると、1週ごとで93.63%、2つで85.44%だった（`mix_share_l`）。どちらの期間の内訳にそろえるかでも値が動いた
- S4 入会の数が週120人のままでも、開封率は2.32ポイント下がり、1週ごとにそろえると101.29%が消えた。この例では、会員の募集を始めてまだ1年で長く登録している人が少なく、入会の数が同じでも、登録からの週数が長い人の割合が増えていくだけで下がった

### S2 メールそのものが弱くなる・S3 後から入る人ほど開きにくい（各50回の平均）
| 週数の分け方 | S2 説明できる割合 | S2 内訳をそろえた比（後÷前） | S3 説明できる割合 | S3 内訳をそろえた比 |
|---|---|---|---|---|
| 1週ごと | 51.07% | **0.8642** | 35.61% | 0.8631 |
| 4週ごと | 50.98% | 0.864 | 35.51% | 0.8629 |
| 3つ | 47.32% | 0.8538 | 31.84% | 0.8551 |
| 2つ（1年で分ける） | 36.97% | 0.8252 | 20.31% | 0.8306 |
| 本当のメールの強さの比 | | **0.8663** | | 1 |

- S2：開封率は5.53ポイント下がった。1週ごとにそろえた比0.8642は、置いたメールの強さの比0.8663に近かった。2つに分けると0.8252で、メールの弱まりを大きく見た
- **S3：メールの強さは変えていないのに、1週ごとにそろえた比は0.8631で、S2（メールが0.8663倍に弱くなる）とほとんど同じに見えた**。後から入った人がもともと開きにくい分は、登録してからの週数の内訳をそろえても消えず、「メールが弱くなった」分と区別できなかった（開封率は4.27ポイント下がった）
- S3 で後の13週の内訳にそろえると、説明できる割合は1週ごとで72.24%（前の13週にそろえると35.61%）と、そろえる期間で大きく違った

### 確かめ：72通り（各3回、`results/grid.csv`）
- **メールが変わらない36通り**：開封率はそのまま比べると0.6304〜0.9807倍（下がり幅0.49〜7.72ポイント）に下がった。1週ごとにそろえた比は0.9742〜1.0097で、1から2%より外れたのは1通りだった。2つに分けた比は0.8611〜1.0058で、10通りで0.95を下回った（メールが5%以上弱くなったように見えた）
- 下がり幅が0.5ポイントを超えた34通りでは、説明できる割合は1週ごとで86.04〜134.32%、2つで36.5〜119.41%（中央値79.9%）だった。下がり幅が小さいと、割合は乱数のぶれで100%を大きく超えた
- **メールが最後に0.85倍に弱くなる36通り**（本当の比0.8663）：1週ごとにそろえた比は0.845〜0.8811、2つでは0.7686〜0.8755、そのまま比べると0.545〜0.8502だった
- 1週ごとでもずれが残ったのは、週数の形がゆっくり下がる（26週）置き方で、52週以上を1つにまとめた区分の中にまだ下がる分が残るため

## 注意（言えないこと）
- 架空のデータと、作成者が置いた開く確率の形です。登録してからの週数で開く確率が下がる形、入会の数の減り方を変えれば、下がり幅も説明できる割合も変わります
- 1週ごとにそろえると入れかわりの分がほぼ全部消えるのは、開く確率が週数だけで決まると置いたからです（作りどおり）。実際には、季節や曜日、送る中身の回ごとの違いもまざります
- やめる確率は、開くかどうかと関係なく置きました。開かない人ほどやめる場合、残った人の開封率は上がって見え、内訳をそろえても別のずれが入ります
- 後から入る人ほど開きにくい場合（S3）と、メールが弱くなる場合（S2）は、登録してからの週数でそろえるだけでは見分けられませんでした。入った時期ごとの開封率を並べるなど別の情報が要ります（推測）
- 開封の数え方（画像の読みこみで数えるなど）のずれ、届かなかったアドレス、迷惑メールへの振り分けは入れていません
