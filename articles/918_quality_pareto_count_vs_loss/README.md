# 918 不良の原因の上位を、件数で並べるか損失で並べるかで変わるのか？（品質と検査）

不良の原因を多い順に並べた図（パレート図）は、ふつう件数で作ります。けれども、1件あたりの損失（手直しや廃棄にかかる分）は原因ごとに違うので、件数の上位と損失の上位は同じとは限りません。**ここでは、作成者が乱数で作った架空の工場の不良の記録（原因12種類の本当の件数と1件の平均の損失を作成者が置いたもの）で、件数の上位3と損失の上位3がどれだけ重なるか、数えた件数・数えた損失で並べた順位が本当の損失の上位3をどれだけ当てるかを数えました。** 損失は円ではなく指数（全体の1件の平均を1）で表しています。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A918 | 件数の上位3と損失の上位3はどれだけ重なるか。件数の順・損失の順は、本当の損失の上位3をどれだけ当てるか。何か月数えればよいか | 架空の工場の1つの部品。不良の原因は12種類。1か月の不良は合わせて300件（期待値）。原因ごとの件数の差は対数正規（標準偏差1.0）。原因ごとの1件の平均の損失も対数正規で、差の大きさ（対数の標準偏差）は基本1.0、件数との相関は基本0。1件ごとの損失は、その原因の平均のまわりで対数正規に散らばる（基本1.0）。件数はポアソン分布で引く。本当の上位3は、件数の期待値の順と、件数×1件の平均の損失の順。工場を作り直して300回。確かめとして、損失の差（0・0.5・1.0・1.5）×件数との相関（−0.5・0・+0.5）の12通り、1件の散らばり（0.5・1.0・1.5）×1か月の件数（300件・30件）×数えた期間（1・3・6・12か月）の24通りを数えた。seed 918 | `src/a918_count_vs_loss.py` |

## 主な結果

### 1つの工場の12か月（`data/defects_one_factory_12months.csv`）
| | 件数の順 | 損失の順 |
|---|---|---|
| 上位3 | C・J・K | C・G・J |
| 1位 | K（損失では4位） | G（件数では11位） |
| 上位3が損失に占める割合 | 49.4% | 58.3% |

- 12か月で不良は3,591件。件数の上位3は件数の62.9%を占めたが、損失では49.4%だった
- 損失の1位の G は、件数では12原因のうち11位だった（1件の平均の損失を、ほかより大きく置いた原因）

### 本当の値どうしで（300工場の平均、基本の置き方）
| | 値 |
|---|---|
| 件数の上位3と損失の上位3の重なり | **59.2%** |
| 1位が同じだった割合 | 48.0% |
| 件数の上位3が、本当の損失に占める割合 | 56.5% |
| 損失の上位3が、本当の損失に占める割合 | 70.2% |

### 確かめ：1件の損失の差と、件数との相関を変えると（`results/grid_true_overlap.csv`）
| 1件の平均の損失の差 | 相関−0.5 | 相関0 | 相関+0.5 |
|---|---|---|---|
| 0（どの原因も同じ） | 100% | 100% | 100% |
| 0.5 | 71.4% | 75.4% | 81.6% |
| 1.0（基本） | 48.3% | 59.2% | 73.0% |
| 1.5 | 33.0% | 52.4% | 67.3% |

（件数の上位3と損失の上位3の重なり）

- 1件の損失がどの原因も同じなら、2つの順位は必ず同じになる（式どおり）。違いがあるときの重なりは33.0〜81.6%、1位が同じ割合は14.0〜72.3%まで、**置き方で大きく動いた**
- よく起きる原因ほど1件が安い（相関−0.5）と置くと、件数で並べた上位3が損失に占める割合は32.5%まで下がった

### 数えた期間で：本当の損失の上位3を当てた割合（300工場の平均）
| 1か月の件数・1件の散らばり | 件数の順（1か月→12か月） | 損失の順（1か月→12か月） |
|---|---|---|
| 300件・1.0（基本） | 59.4% → 61.6% | 85.7% → 94.3% |
| 300件・1.5 | 60.8% → 61.0% | 81.2% → 92.1% |
| 30件・1.0 | 54.3% → 59.1% | 67.8% → 87.7% |
| 30件・1.5 | 54.8% → 59.2% | 64.7% → 81.2% |

- **件数の順は、何か月数えても損失の上位3を54.3〜62.9%しか当てなかった**。長く数えると件数の上位3そのものはよく当たる（1か月300件の工場の12か月で96.3〜97.0%）が、それは件数の上位であって損失の上位ではないため
- 損失の順は、1件の損失の散らばりで1か月の値が振れる。それでも24通りすべてで件数の順より当たり、差は9.9〜35.7ポイントだった。1か月30件の工場で1件の散らばりが大きいと、1か月では64.7%にとどまった

## データ
- `data/defects_one_factory_12months.csv`：架空の工場の12か月の不良1件ずつ（month・cause（原因 A〜L）・loss（損失、指数））
- `results/causes_one_factory.csv`：同じ工場の原因ごとのまとめ（count・loss・true_count_per_month（置いた月の件数）・true_mean_loss_per_case（置いた1件の平均の損失）・true_loss_per_month・rank_count・rank_loss）

## 注意（言えないこと）
- 架空のデータです。原因ごとの件数の差、1件の損失の差、件数と1件の損失の相関、1件ごとの散らばりは作成者が置いたもので、2つの順位がどれだけずれるかはこれで決まります。差0なら順位は同じという結果は式どおりで、新しく数えたのは、ずれの大きさが置き方でどれだけ動くかと、数えた期間で当たりがどう変わるかです
- 損失は手直し・廃棄の分を1つの指数にまとめました。お客さまからの苦情、止まった時間、安全にかかわる重さなど、件数でも損失の指数でも表せないものは入れていません
- 「損失の上位3を当てる」ことを目当てにした比べ方です。何を先に直すべきかは、直しやすさや直す費用でも変わり、ここからは言えません
- 原因の分け方（何を1つの原因とするか）は決まっていると置きました。分け方を変えれば順位も変わります
- 関連する記事 892 は、1件の大きな案件で副業の収入の平均がどれだけ動くかを数えています。この記事の損失の順が1か月で振れるのも、1件の大きな損失が入るかどうかによります。919 は、改善の前後で不良率を比べるときに何か月見ればよいかを数えています
