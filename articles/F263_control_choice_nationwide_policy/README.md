# F263 比べる相手がないとき、何を対照にするか？（全国一斉の消費税率引き上げで、6つの対照を比べる）

精選モード（計画を先に公開・問い直し1回・別のエージェントのレビュー）。計画：[PLAN.md](PLAN.md)（コミット 3e1c482、データ・結果のコミットはすべてこの後）。

## 問い

全国一斉に始まる施策は、どの地域も同時に影響を受けるので「受けなかった比較相手」がない。効果検証の仕事でよくあるこの状況で、何を対照（施策がなかった場合の見込み）に置くかで答えはどれだけ変わり、どれを信じればよいのか。

例として、2019年10月の消費税率引き上げ（8%→10%。食料〔酒類・外食を除く〕と新聞は8%のまま）で、標準税率の品目の値段がどれだけ上がったか（転嫁）を測る。全部転嫁したときの目安は 110/108−1＝+1.85%（100×対数で 1.83）。これは計算上の目安で、正解ではない。

既存の記事との違い：F11 は同じ増税の駆け込み・反動（販売額）、F240 は他の都道府県から作る合成対照、F251 は架空の会社で答えを入れた比較。この回は、比べる地域が1つもない施策を、実データの値段で、対照の候補（自分の過去／影響を受けない別の品目／その組み合わせ）と「何もない月」での偶然の幅で比べる。

## データ

| データ | 期間 | 出典 |
|---|---|---|
| 消費者物価指数 2020年基準 品目別価格指数（全国・月次）とウエイト | 2015年1月〜2026年9月 | 総務省統計局「消費者物価指数」。F209 の `data/cpi_items_monthly.csv.gz`・`cpi_items_meta.csv` の写し（新しい取得なし） |

- 品目は表の並び順で直前の類に属させ、税の区分に分けた（`data/item_class.csv`）。期間中に欠けのない品目だけ使う：標準税率 335品目（ウエイト 51%）、軽減税率 178品目（20%）、非課税 23品目（28%、持家の帰属家賃を含む）、除外 1品目（保育所保育料：同じ月の幼児教育・保育の無償化）。
- 単位：数字は100×対数の差（小さな変化ならほぼ%と同じ）。全部転嫁の目安は%で +1.85%、100×対数で 1.83。
- 軽減税率：食料のうち酒類と一般外食を除く品目（学校給食を含む）、新聞代。非課税：家賃・持家の帰属家賃・授業料等・診療代・教科書・火災地震保険料・自動車保険料（自賠責・任意）・傷害保険料・介護料・行政証明書手数料・パスポート取得料・自動車免許手数料・PTA会費（小学校・中学校。授業料等の類にあるため）。学童保育料も非課税に入れる決まりにしたが、期間中に欠けがあり使っていない。
- ピザ（配達）は本来は軽減税率（8%）だが、一般外食の類にあるため標準税率の群に入っている（標準税率の群のウエイトの0.15%）。軽減税率に移しても6つの推定の変化は0.01〜0.03（`results/E_review_checks.json` の pizza_reduced）。
- 群の指数は2020年のウエイトでの加重平均（ラスパイレス）、100×対数で扱う。

## 手法

施策月 2019年10月、主は施策後3か月（10〜12月、翌年のコロナを避ける）の平均。

| 方法 | 対照（施策がなかった場合の見込み） |
|---|---|
| M1 前後比較 | 直前3か月の平均 |
| M2 前年同月比の差 | 直前3か月の前年同月比がそのまま続く |
| M3 中断時系列 | 直前24か月の傾き＋月の効果（季節）を延ばす |
| M4 軽減税率の品目と差の差 | 軽減税率の群の動き（M1 と同じ前後比較の差） |
| M5 非課税の品目と差の差 | 非課税の群の動き |
| M6 合成対照 | 軽減税率・非課税の品目（201品目）の非負・合計1の重み。直前24か月の平均を引いて合わせる |

- 時点のプラセボ：同じ計算を「何もない月」に当てはめ、効果がゼロのときに出る数字の 5〜95%点（90%の幅）を偶然の幅とした。落ち着いた期間＝施策月を2017年1月〜2019年7月に置く（h=3 で31か月）、荒れた期間＝2022年1月〜2026年7月（55か月、前の24か月にコロナ・物価高・補助金が入る）。

## 結果

### 1. 対照の置き方で +0.7〜+1.6 に分かれた（H2 支持）

2019年10〜12月の標準税率の品目の値上がり（100×対数、全部転嫁の目安 1.83）：

| 方法 | 推定 | 落ち着いた期間の偶然の幅（5〜95%点） | ゼロと合うか | 全部転嫁（1.83）と合うか |
|---|---|---|---|---|
| M1 前後比較 | +1.65 | −0.38〜+0.65 | 合わない | 合う |
| M2 前年同月比の差 | +1.03 | −0.49〜+0.63 | 合わない | 合わない |
| M3 中断時系列 | +0.71 | −0.66〜+1.14 | **合う**（効果なしと区別できない） | 合わない（−1.12） |
| M4 軽減税率の品目と差の差 | +1.19 | −2.02〜+2.37 | **合う** | 合う |
| M5 非課税の品目と差の差 | +1.31 | −0.45〜+0.66 | 合わない | 合わない |
| M6 合成対照 | +1.38 | −1.26〜+0.96 | 合わない | 合う |

「合う」＝推定（全部転嫁なら推定−1.83）が偶然の幅の中。

- 最大−最小は 0.93ポイントで、H2（0.5以上）は支持。
- 2%の税率の引き上げでも、M3 と M4 では「何もない月」の幅に収まり、効果なしと区別できなかった。
- 偶然の幅（プラセボの5〜95%点）は0を中心にしておらず、M3 は平均 +0.26 の偏り（`results/B_bands.csv` の mean）。

### 2. 別の品目を対照にしても、偶然の幅は狭くならなかった（H1 外れ）

- 生鮮食品を含む基本の条件・落ち着いた期間・3か月で、自分の過去を使う M1〜M3 の偶然の幅（幅の半分）の平均 0.66 に対し、別の品目を使う M4〜M6 は 1.29。比は 0.51倍で、H1（1.5倍以上）は外れ。
- 主な理由は軽減税率の群（食料）が生鮮食品で大きく揺れること。対照から生鮮食品を除くと M4 の幅は 2.20→0.60、M6 は 1.11→0.60 に縮み、M4〜M6 のほうがわずかに狭くなる（M1〜M3 が 1.12倍）。それでも計画の基準1.5倍には届かず、H1 は外れのまま。
- 合成対照（M6）は201品目のうち23品目に重みがつき、直前24か月の当てはまりの RMSE は 0.010（標準税率の群の同じ期間の標準偏差 0.42）。品目の数が月の数より多いので、ほぼぴったり合うのは当然で、信頼できる証拠にはならない。施策後の差は10月 +1.09、11月 +1.28、12月 +1.78 と広がる。
- 「影響を受けない」はずの対照も動いていた：2019年10〜12月に非課税の群は +0.34（火災・地震保険料 +8.00、傷害保険料 +2.84、介護料 +2.02、診療代 +0.20。料金の改定に税の負担分が一部入った可能性、推測）、軽減税率の群は +0.46。非課税の群からこの4品目を除くと M5 は +1.31→+1.65（偶然の幅 −0.45〜+0.73）。
- 合成対照（M6）の重みは、せんべい・乾燥スープ・チョコレート・カレーパン・コーヒー豆など食料の加工品に集まった（`results/C_synth_weights_201910.csv`）。

### 3. 幅が最も狭い方法は全部転嫁の目安に近かったが、決め方はもろい（H3 は6条件中4つで支持）

- 基本の条件で偶然の幅が最も狭いのは M1（±0.52）で、推定 +1.65 は目安 1.83 から −0.19（PLAN どおり%の 1.85 と比べても −0.20）。H3（±0.3以内）は支持。
- ただし M1・M2・M5 の幅は 0.52・0.56・0.56 とほぼ同じで、条件を変えると「最も狭い方法」が入れ替わる。前36か月では M2（+1.03、−0.80）、エネルギーを除くと M2（+1.46、−0.37）が最も狭くなり、どちらも H3 は外れ。前12か月・軽減税率の対照から生鮮を除く・単純平均（M3 +1.54、−0.299 で境目）では支持で、6条件中4つで支持。

### 4. 荒れた期間では偶然の幅が約2倍（H4 支持）

- 荒れた期間の偶然の幅は、M1 1.09（2.1倍）、M2 1.41（2.5倍）、M3 2.00（2.2倍）、M4 2.13（0.97倍）、M5 1.22（2.2倍）、M6 1.97（1.8倍）。2倍以上は6つ中4つで H4 は支持。
- 荒れた期間の幅は、多くの方法で全部転嫁の目安（1.83）と同じくらいかそれ以上。物価が大きく動く時期には、2%の値上げの施策でも見分けにくい。
- 見る期間を延ばすと（h=12）、M2・M3・M6 の荒れた期間の幅は 2.6〜3.1 まで広がる。

## 問い直し：品目ごとに見ると、全部転嫁した品目はどれだけあったか

全体の +1.0〜+1.6 は「どの品目も少しずつ足りない」のか、「多くは全部転嫁で、一部の品目が下がった」のかを、品目ごとの推定と、その品目自身の「何もない月」の幅で調べた（`src/zz_f263_05_品目.py`、M6 は品目ごとには計算していない）。

- 品目ごとの推定の中央値は M1 +1.98、M2 +1.82、M3 +1.89 で、全部転嫁の目安 1.83 に近い。ウエイトでの平均は M1 +1.67、M2 +1.03、M3 +0.74 と低い。
- 不足をどの品目に分けるかは方法で変わる：前年同月比の差（M2）で分けると、目安からの不足 −0.80 のうちエネルギー（電気代・都市ガス代・プロパンガス・灯油・ガソリン）が −0.47、ほかに携帯電話機・通信料（携帯電話）・たばこ・外国パック旅行費など。前後比較（M1）で分けると不足は −0.16 で、エネルギーが −0.20（ほかの品目は合わせてわずかに目安を上回る）。
- ほかの説明もありうる（どれも推測）：電気・ガス・水道・電話などは10月1日をまたぐ検針・請求の分に経過措置で旧税率が使われる。外国パック旅行費は海外の部分に消費税がかからず目安が当てはまらない。携帯電話は同じ10月に端末代の割引の制限が始まった。たばこは前年（2018年10月）の値上げが M2 の前年同月比に残る。
- 品目ごとの判定（M2、標準税率のウエイトに占める割合）：全部転嫁と合う 24%（115品目）、区別できない 30%（95品目）、ゼロと合う 16%（31品目）、どちらとも合わない間 13%（27品目）、全部転嫁を上回る 14%（55品目）、ゼロを下回る 2%（12品目）。M1 でも 28%・24%・15%・19%・14%・1% とほぼ同じ形。
- 品目の単位では「何もない月」の幅の中央値が ±1.1〜1.6 と大きく、全部転嫁と転嫁ゼロを区別できない品目がウエイトで約3割あった。

## 計画からのずれ

- 最初の実行で、落ち着いた期間のプラセボの始まりを誤って2018年4月にしていた（PLAN は2017年1月）。結果を一度見たあとで PLAN どおり2017年1月に直し、判定は直した後の数字で行った。誤った期間（2018年4月〜、16か月）のままだと、M3 の偶然の幅は −0.70〜+0.23（±0.46）で推定 +0.71 は幅の外、H1 の比は 0.40倍だった（`results/E_review_checks.json` の old_window）。直したことで M3 は「幅の外」から「幅の中」に変わった。
- 前12か月では M3（係数13個）が計算できないため「計算せず」とした。
- PLAN の非課税の例にない学童保育料を非課税に入れる決まりにしたが、欠けがあり実際には使っていない。PTA会費（2品目）は授業料等の類にあるため非課税に入れた（PLAN に書いていなかった）。
- PLAN の H3 は「+1.85% から ±0.3」だったが、計算は100×対数の 1.83 と比べた。1.85 と比べても M1 は −0.20 で判定は同じ。
- 見る期間 h=12 は PLAN（1・3・6）になく、あとから足した。
- 頑健性の「エネルギー・生鮮を除く」は、標準税率に生鮮食品がないため実際にはエネルギーだけを除いている（名前を「エネルギーを除く」に直した）。
- 独立レビューを受けて、`src/zz_f263_07_レビュー検算.py` で、非課税の4品目を除いた M5、ピザの移しかえ、誤った期間での再計算、合成対照の当てはまり、ゼロ・全部転嫁と合うかの判定、不足の分け方を結果のあとに計算した。
- 問い直しの「その間」「上回る」「下回る」の区分は結果を見てから足した。
- 2019年10月には通信料（携帯電話）の制度変更（端末代の割引の制限）もあったが、PLAN では除外していない。問い直しで携帯電話機・通信料が不足の一部を作っていることを示した。

## 言えないこと

- 全部転嫁の +1.85% は計算上の目安で、正解ではない。企業が前もって値上げした分、同じ時期のほかの値動き（原油・端末の制度変更など）が混ざる。
- 落ち着いた期間にも2018年10月のたばこ税の引き上げが入っている。
- 「影響を受けない」はずの対照も同じ時期に動いていた（非課税の群 +0.34、軽減税率の群 +0.46）。料金の改定に税の負担分が入った可能性があり（推測）、差の差の推定はその分だけ低めに出ている可能性がある。
- 偶然の幅は2017〜2019年（落ち着いた期間）と2022〜2026年（荒れた期間）から測ったもので、施策の時期にも同じとは限らない。落ち着いた期間のプラセボは31か月と少なく、5・95%点は粗い。
- 「何を対照にすべきか」の一般的な答えは出していない。この施策・このデータでの比較で、別の施策では順番が変わりうる（推測）。
- 政策の評価（増税の良し悪し）はしていない。

## レビューで直したこと

別のエージェント（作業を見ていない）が記事・README・src を読み、数字の照合とクリーンな再実行を行った。数字はすべて一致し、再実行もバイト単位で一致した。本文の書き方が結果と合っていない点など12件の指摘を受け、次のように直した（新しい数字は `src/zz_f263_07_レビュー検算.py` で計算し直した）。

1. 【高】生鮮食品を除いた比較の読み違い：1.12倍は「M1〜M3 の幅が M4〜M6 の1.12倍」で、M4〜M6 のほうがわずかに狭い。本文と結論を「生鮮を除くとわずかに狭くなるが、基準1.5倍に届かず H1 は外れのまま」と直し、結論に「生鮮を含む基本の条件では」と加えた。
