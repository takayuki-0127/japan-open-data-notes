# 714 空白のセルと0のセルが混ざった列を Excel の AVERAGE で平均すると、値はどれだけ変わるのか（実務の型・表計算の集計）

Excel の AVERAGE は、空白のセルと文字のセルを数えず、0のセルは数えます。AVERAGEA は文字を0として数えます。合計を日数で割ると、空白を0とみなしたのと同じになります。未入力（空白）・本当の0・文字で入った数（"7" のような文字列）が混ざった記録表では、どれを使うかで平均が変わります。**ここでは、架空の30店×60日の問い合わせ件数の記録表（空白7.6%、文字4.3%、本当の0が11.5%）で、4つの平均の出し方を本当の60日の平均と比べました。** Excel の関数の動きは Python で再現したもので、Excel では確かめていません（**Excel では未検証**）。入力のされ方は作成者が置いたもので、数字はその置き方で決まります。

| A714 | 空白・0・文字が混ざった列で、平均の出し方によって値はどれだけずれるか | AVERAGE（数だけ）、AVERAGEA（文字を0）、SUM÷60（空白を0）、文字を数に直してから AVERAGE。Python で再現。seed 714 | `src/a714_average.py` |

## 主な結果
- **30店の平均のずれ**：AVERAGE +0.0%、AVERAGEA **−4.7%**、SUM÷60 **−11.9%**、文字を数に直して AVERAGE −0.0%
- **店ごとのずれの大きさ（絶対値の平均）**：AVERAGE 2.4%、AVERAGEA 5.0%、SUM÷60 11.9%、文字を直して AVERAGE 1.7%
- **5%以上ずれた店**：SUM÷60 は30店中29店、AVERAGEA は13店、AVERAGE は4店、文字を直して AVERAGE は2店
- **数えたセルの数**：AVERAGE は1店あたり平均52.9日分、AVERAGEA は55.5日分、SUM÷60 は60日分。AVERAGE でも最大15.1%ずれた店があった（文字のセルが抜けたぶん、残った日が偏るため）

## 動かし方
```
pip install -r requirements.txt
cd src && python a714_average.py
```
数秒で終わります。`data/daily_sheet.csv` に記録表を書き出します（文字のセルは先頭に ' を付けて区別）。

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures がバイト単位で一致した
- 店ごとに「数・文字・空白」のセルの数を足すと60日になることを確かめた
- Excel の AVERAGE・AVERAGEA・SUM の動きは、関数の説明に沿って Python で再現した。Excel のファイルを開いて確かめてはいない（**Excel では未検証**）

## データ
- `data/daily_sheet.csv`：行が日（1〜60）、列が店（店01〜店30）
- 仮定：本当の件数は店ごとのポアソン分布（平均0.8〜15件）。空白（未入力）は8%、文字での入力は5%の確率で、本当の値と関係なく起きる

## 注意（言えないこと）
- 架空のデータ。ここでは空白を「未入力（本当の値は分からない）」とした。空白が「0件だったので書かなかった」の意味なら、SUM÷60 が正しくなる。空白の意味を決めておくことがいちばん大切
- 未入力が忙しい日に偏るなど、本当の値と関係して起きると、どの平均もずれる。ここでは扱っていない
- 実在の店の数字ではない
