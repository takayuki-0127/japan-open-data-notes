# 995 「前年比120%」の来場は、新しい人か、来る回数が増えたのか？（来場者と集客）

延べの来場が前年の120%になったとき、新しい人が増えたのか、同じ人が来る回数が増えたのかは、延べだけでは分かりません。来た人を見分けられる（会員証など）ときは、「前年に来ていない人」と「前年に来た人」に分けて読むことがあります。でも、ふだんから毎年は来ない人が多い施設では、何も変わらなくても前年に来ていない人は多く、前年に来た人の回数は翌年に減って見えます。**ここでは、作成者が乱数で作った架空の植物園（来る可能性のある人20万人、人ごとの来やすさを作成者が置いたもの）で、延べが1.2倍になる道を4つ（変化なし・新しい人だけ・回数だけ・半々）置き、実人数・1人あたりの回数・前年に来ていない人・前年に来た人の延べがどう見えるかを数えました。**

植物園・来場者はすべて架空のもので、実在の施設の数字は使っていません。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A995 | 延べが前年の1.2倍のとき、新しい人の分と回数の分を、実人数・1人あたりの回数・前年に来ていない人・前年に来た人の延べから読み分けられるか | 架空の植物園。来る可能性のある人を20万人置き、人ごとの来やすさのもと（1年に来る回数の平均）をガンマ分布で置いた（平均0.5回、形 k=0.5）。年ごとの来やすさは、もとの値に、年ごとに引き直す揺れ（対数で標準偏差 σ=0.5、平均は変えない）をかけた。実際の回数はその平均のポアソン分布で引いた。2年目の道は4つ：**変化なし**、**新しい人だけ**（来る可能性のある人を4万人足して1.2倍、来やすさは同じ分布）、**回数だけ**（全員の来やすさを1.2倍、人は足さない）、**半々**（人も来やすさも √1.2 倍）。来た人は全員見分けられると置いた。延べ・実人数・1人あたりの回数の2年目÷1年目、今年来た人のうち前年に来ていない人の割合、前年に来た人の延べの2年目÷1年目を出した。延べの伸びのうち実人数の分は、対数で分けた（log(実人数の比)÷log(延べの比)）。各道30回の平均。揺れなし（σ=0）のときの実人数の比と、前年に来た人の延べの比は、ガンマ分布とポアソン分布の式とも比べた。確かめとして、k（0.2・0.5・1・2）×平均（0.25・0.5・1回）×揺れ σ（0・0.5・1）の36通りで、変化なし・新しい人だけ・回数だけを各5回。seed 995 | `src/a995_growth_split.py` |

## 主な結果

### 4つの道（各30回の平均、`results/scenarios_30reps.csv`）
| | 変化なし | 新しい人だけ | 回数だけ | 半々 |
|---|---|---|---|---|
| 延べ（2年目÷1年目） | 1.001 | 1.2001 | 1.2005 | 1.2 |
| 実人数 | 1.0001 | 1.1993 | **1.1117** | 1.1552 |
| 1人あたりの回数 | 1.0009 | 1.0007 | 1.0799 | 1.0387 |
| 延べの伸びのうち実人数の分（対数） | — | 99.6638% | **57.9306%** | 79.1822% |
| 今年来た人のうち、前年に来ていない人 | **48.0782%** | 56.7441% | 49.0706% | 53.0413% |
| 　そのうち本当に新しい人（今年来た人に対して） | 0% | 16.6717% | 0% | 8.7356% |
| 前年に来た人の延べ（2年目÷1年目） | **0.6082** | 0.607 | **0.7294** | 0.6649 |
| 前年に来た人のうち、今年も来た人 | 51.9287% | 51.876% | 56.6157% | 54.2478% |

- 回数だけ1.2倍にして、新しい人は1人も足していないのに、実人数は1.1117倍に増え、延べの伸びの57.9306%が実人数の分に見えた。来やすさが上がると、前年は0回だった人が1回以上来るようになるため
- 何も変えなくても、今年来た人の48.0782%は前年に来ていない人だった。ふだんから毎年は来ない人が多いため。新しい人だけの道でも56.7441%で、差は8.666ポイントしかない
- 前年に来た人の延べは、何も変えなくても0.6082倍に減って見え、回数だけ1.2倍にしても0.7294倍だった。前年に来た人は、その年にたまたま多く来た人を多く含むので、翌年は平均へ戻る（平均への回帰）。揺れなし（σ=0）・k=0.5・平均0.5回では、変化なしで0.646、回数だけで0.776（`results/sensitivity_grid.csv`）で、式の値（0.646・0.776）と同じだった（式どおり）
- 4つの道を見分けやすかったのは、実人数と1人あたりの回数の組（新しい人だけは1.1993と1.0007、回数だけは1.1117と1.0799）。前年に来ていない人の割合と、前年に来た人の延べは、どの道でも似た値になった

### 確かめ：36通り（各5回、`results/sensitivity_grid.csv`）
| | 回数だけ1.2倍の36通りの幅 | 変化なしの36通りの幅 | 新しい人だけの36通りの幅 |
|---|---|---|---|
| 延べ | 1.192〜1.206 | — | — |
| 実人数 | 1.071〜1.168 | 0.993〜1.005 | 1.197〜1.208 |
| 延べの伸びのうち実人数の分 | 37.404〜82.966% | — | — |
| 今年来た人のうち、前年に来ていない人 | 28.084〜76.971% | 26.559〜76.698% | 38.773〜80.677% |
| 前年に来た人の延べ | **0.295〜1.061** | 0.25〜0.885 | 0.246〜0.883 |

- 回数だけ1.2倍の36通りで、前年に来た人の延べは36通りすべてで1.2を下回り、34通りで1を下回った（減って見えた）
- 前年に来ていない人の割合は、置き方で28.084〜76.971%と大きく動き、新しい人だけの道との差は同じ置き方で3.705〜10.689ポイントだった。この割合の大きさは、新しい人の多さより、来やすさの分布の置き方で決まった
- 回数だけの道でも、実人数は36通りすべてで増えた（1.071〜1.168倍）。新しい人だけの道との実人数の比の差は、同じ置き方で0.033〜0.13だった
- 揺れなし（σ=0）の12通りで、回数だけの実人数の比は式の値と0.006以内で合った

## 動かし方
```
pip install -r requirements.txt
cd src && python a995_growth_split.py
```
40秒ほどで終わります。`data/people_example_frequency_only.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約40秒）
- 回数だけの道で実人数が増えること、前年に来た人の延べが翌年に減って見えること（平均への回帰）は、置いた来やすさの分布からの式どおりの向きで、揺れなしでは式の値と合った。データから見つけたものではない
- 新しく数えたのは、その大きさが置き方でどれだけ動くかと、4つの道を読み分けるのにどの数が役に立ち、どの数が役に立たないか

## データ
- `data/people_example_frequency_only.csv`：回数だけの道の1回分で、2年のどちらかに来た人（85,587人）。person_id・rate_y1／rate_y2（作成者が置いた、その年の来やすさ）・visits_y1／visits_y2（その年に来た回数）

## 注意（言えないこと）
- 架空のデータです。来る可能性のある人の数、来やすさの分布、年ごとの揺れ、4つの道は作成者が置いたもので、結果はこれで決まります。実在の施設の来場者を表すものではありません
- 実際には、実人数と1人あたりの回数を出すには来た人を見分ける仕組みが要ります。ここでは作成者が全員を見分けられる形で数えました。会員だけが見分けられる場合は扱っていません（999 で扱っています）
- 来やすさの上がり方は、全員を同じ倍率にしました。一部の人だけ回数が増える場合や、前年の人がやめて別の人が来る場合は入れていません
- 「新しい人」は、来る可能性のある人として新しく足した人と定めました。前年に来ていない人のうち、ふだんから来うる人と本当に新しい人は、実際のデータでは見分けられません
- 関連する記事：830（2年目のジンクス）と 940（去年高かった人の点が下がる）は、同じ平均への回帰を、成績と評価で扱っています。887 は継続率を月で数えるか案件で数えるかを扱っています。同じ企画の 993 は延べと実人数の違いを、994 は入口のゲートとチケットで人数がどう変わるかを、999 は会員の来場だけで全体の傾向を読むことを、1000 は再来場率を何日以内で数えるかを扱っています
