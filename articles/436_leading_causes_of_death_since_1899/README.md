# 436 いちばん多い死因（病気）は、何から何へ入れ替わったのか（人口動態統計、1899〜2024年）

人口動態統計の「死因年次推移分類」のうち、病気の5つ（結核・悪性新生物・心疾患・脳血管疾患・肺炎）の死亡率を126年分並べたフォルダです。病気だけを比べ、事故などの外因は扱っていません。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A436 | 5つの病気のうち、率がいちばん高いものはいつ入れ替わったか。結核の率は何年で10分の1になったか。年齢構成をそろえるとどう見えるか | 人口10万人あたりの死亡率を並べ、年ごとの1位と入れ替わりの年を出す。1950年以降は、年齢5歳階級別の死亡数から「年齢構成が1950年のままだったら」の率（直接法）を計算 | `src/a436_causes.py` |

## 主な結果
- 5つのうちの1位：1900〜1917年は結核、1918〜1931年は結核と肺炎が入れ替わり（1918〜20年は肺炎）、1932〜1950年は結核、1951〜1980年は脳血管疾患、1981年からは悪性新生物
- 結核の死亡率（人口10万対）：1918年の257.1が最高。1947年 187.2 → 1950年 146.4 → 1955年 52.3 → 1960年 34.2。山の半分になったのは1951年、10分の1は1963年（45年後）、100分の1は1994年。1947年の値の10分の1になったのは1967年で、20年。2024年は1.2
- 悪性新生物が脳血管疾患を上回ったのは1981年（142.0 対 134.3）。心疾患は1985〜93年に脳血管疾患を上回り、1994〜96年に下回ったあと（表の注：死亡診断書の書き方の変更の影響）、1997年からは上
- 肺炎は2011〜16年に脳血管疾患を上回った。2017年からは下
- 2024年の率：悪性新生物 319.3、心疾患 188.2、脳血管疾患 85.5、肺炎 66.6、結核 1.2。死亡総数に占める割合は、悪性新生物 23.9%、心疾患 14.1%
- 年齢構成を1950年にそろえた率（1950年 → 2024年）：悪性新生物 77.4 → 51.0（山は1965年の89.3）、心疾患 64.1 → 18.6、脳血管疾患 127.1 → 10.0（山は1960年の135.6）、肺炎 65.1 → 4.5。そのままの率は、悪性新生物 77.4 → 319.4、心疾患 64.1 → 188.2
- 65歳以上の人口の割合は、1950年 4.9% → 2024年 30.0%。悪性新生物で亡くなった人のうち65歳以上は、36% → 89%

## 確かめたこと
- 年齢別の死亡数と人口（死亡総数÷死亡率から逆算）から計算した「そのままの率」は、公表の率と最大0.18の差（人口を逆算した丸めの分）
- 空のフォルダで流し直し、data・results・figures が一致した

## データ
- `data/jinkou_r7_jokan_5-12_diseases_total.csv`：上巻 5-12 死因（死因年次推移分類）別にみた性・年次別死亡数及び死亡率（statInfId=000040502543）の総数から、死亡総数と、結核・悪性新生物・心疾患・脳血管疾患・肺炎・老衰の列だけを抜き出したもの（老衰は分析に使っていません）
- `data/jinkou_r7_jokan_5-15_diseases_by_age_total.csv`：上巻 5-15 同 年齢（5歳階級）・年次別（statInfId=000040502545）の総数から、死亡総数と上の5つの病気を抜き出したもの
- どちらも e-Stat「人口動態調査 人口動態統計 確定数 死亡」（2025年）を2026-11-12に取得

## 注意（言えないこと）
- 比べたのは、死因年次推移分類にある病気のうちの5つだけです。「日本でいちばん多い死因」の順位そのものではありません（たとえば戦前は胃腸炎が多く、いまは老衰が多いですが、ここでは比べていません）
- 死因の分類は何度も改正されていて、年をまたいだ数字は完全には同じ中身ではありません（表の注）。1994〜95年の心疾患と脳血管疾患の動きは、死亡診断書の書き方と分類の変更の影響を受けています
- 1944〜46年は資料がなく、1947〜72年は沖縄県を含みません
- 2025年の率は、人口が確定していないため公表されていません。率は2024年までです
- 年齢構成をそろえた率は、1950年の人口を基準にした場合の数字です。基準を変えると水準は変わります（下がっている向きは変わりません）。90歳以上は1つの階級にまとめています
- 率が動いた理由（治療・薬・生活・診断の変化など）は分けていません。健康についての助言ではありません
- 全国の集計だけで、地域ごとの違いは見ていません
