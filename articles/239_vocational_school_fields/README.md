# 239 専門学校に進む人は、どの分野で増えたのか

文部科学省「学校基本調査」の年次統計「専修学校の学校数、在籍者数、教職員数（昭和51年〜）」（1976〜2025年度）と、各年度の「設置者別学科別生徒数」（2000〜2025年度）を並べたフォルダです。専修学校の生徒（高等課程・専門課程・一般課程の計）を、8つの分野と学科ごとに見ました。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A239 | 専門学校に進む人は、どの分野で増えて、どこで減ったのか | 生徒数の長期推移（1976〜2025年度）／8分野の生徒数の推移（2000〜2025年度）／学科ごとの増減（2005→2025年度） | `src/a239_vocational.py` |

## 主な結果
- 専修学校の生徒は1992年度の861,903人が最多で、2025年度は621,626人（最多の年の72%）。2000年度の750,824人からは17%減った
- 分野で動きが違う。2000→2025年度に、医療は199,551人→157,266人（2005年度の223,745人が最多）、工業は139,311人→102,892人、教育・社会福祉は62,684人→29,119人、服飾・家政は45,447人→16,288人に減った
- 文化・教養（141,160→154,638人）と商業実務（79,108→79,298人）、農業（3,490→4,452人）は減っていない。2025年度は医療（25.3%）と文化・教養（24.9%）がほぼ同じ大きさ
- 学科で見ると（2005→2025年度、「その他」を除く）、増えたのは商業（5,074→19,662人、3.88倍）、動物（9,562→20,386人、2.13倍）、情報（6,715→13,120人、1.95倍）、歯科衛生（1.37倍）、製菓・製パン（1.79倍）
- 減ったのは看護（94,882→72,094人）、受験・補習（36,836→18,807人）、介護福祉（22,702→10,849人）、和洋裁、准看護（15,345→4,053人）、美容など
- 商業実務の生徒は2020年度の83,484人から2023年度の59,252人に減り、2025年度に79,298人へ戻った

## 頑健性
- 8分野の合計は表の計と、表の計は年次統計の在籍者と、2000〜2025年度のすべての年で一致した
- 学科の区分は2005年度から今と同じなので、学科ごとの比較は2005年度からにした（2000〜2004年度の表には「情報」「旅行」「介護福祉」「理学・作業療法」などの区分がない）
- コードはきれいなフォルダで3回動かし直し、results と data の全ファイルが一致することを確かめた

## 動かし方
```
pip install -r requirements.txt
cd src && python a239_vocational.py   # data/raw の Excel から data/・results/・figures/ を作る
python fetch.py                       # 学科別の表を e-Stat から取り直す（任意。年次統計は statInfId 000031852321）
```

## データ
- `data/raw/nenji_K008_000031852321.xlsx`：年次統計 専修学校の学校数、在籍者数、教職員数（1976〜2025年度）
- `data/raw/<年度>_S_<statInfId>`：設置者別学科別生徒数（1枚目のシート＝計）
- `data/senshu_nenji.csv`・`data/senshu_students_by_field.csv`・`data/senshu_students_by_subfield.csv`

## 注意
- 「専門学校」は専修学校の専門課程のこと。ここでは高等課程・一般課程も含めた専修学校全体の生徒で見た（2025年度は専門課程が569,107人で、計の92%）
- 商業や情報、ビジネスの学科と、2020〜2023年度の商業実務の増減には、外国人の留学生の増減が関わっているとみられるが、この表には国籍の内訳がないので確かめていない（推測）
- 看護・准看護の減少には、看護師を育てる場が大学に移ったことが関わっているとみられる（推測）。大学の看護学の学生は別の記事（236）のデータで2000年度の17,429人から2025年度の95,562人に増えている
- 生徒の数で、入学者の数ではない。修業年限の違う学科（1年制と4年制など）は、在学年数の分だけ生徒数に差が出る
