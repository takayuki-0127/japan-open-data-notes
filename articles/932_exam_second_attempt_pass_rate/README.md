# 932 2回目の受験の合格率が高いのは、なぜなのか？（試験と点数）

資格試験では「2回目の受験の人の合格率は、1回目の人より高い」という数字を見ることがあります。これを「1回落ちてから勉強した分、実力が伸びたから」と読みたくなります。けれども、2回目を受けるのは落ちた人の全員ではありません。合格点に近かった人ほど受け直し、遠かった人は受け直さないことが多いと考えられます。**ここでは、作成者が乱数で作った架空の社内資格試験の受験者200万人（本当の実力、受け直す人の決まり方、受け直す人の実力の伸びを作成者が置いたもの）で、2回目の人の合格率を、受け直す人の選ばれ方と実力の伸びに分けました。同じ人のまま、選ばれ方と伸びだけを変えた比べ方と、置き方を変えた45通りの確かめを行いました。**

| A932 | 2回目の人の合格率が1回目の人より高いのは、受け直す人の選ばれ方によるのか、実力の伸びによるのか。伸びがなくても高くなるのか | 架空の社内資格試験。100問・1問1点、合格点は60点で固定。本当の実力（何度も受けたときの平均の正答率）は平均55点・標準偏差13点のベータ分布。試験の日は当日の調子で実力が標準偏差3点だけ上下し、1問ずつその確率で正解する（930・931と同じ形）。1回目に落ちた人は、1回目の点 x で受け直すかを決める。受け直す確率は、59点で70%、そこから1点下がるごとにロジット（対数オッズ）で b だけ下がる（基本 b=0.25。55点で46%、50点で20%、45点で6.6%、40点で2.0%）。受け直す人は、実力が平均5点（人ごとに標準偏差2点、0点より下は0点）伸びて2回目を受ける。1回目・受け直しの決め方・2回目の乱数は、置き方によらず同じものを使い、「落ちた人全員が受け直す」「伸びなし」に変えた4通りを同じ200万人で比べた。確かめとして、実力の標準偏差（8・13・18点）×選ばれ方の強さ b（0・0.06・0.12・0.25・0.5）×伸び（0・2・5点）の45通りを各40万人。b=0 は、落ちた人が点によらず70%ずつ受け直す場合。seed 932 | `src/a932_second_attempt.py` |

## 主な結果

### 同じ200万人で、選ばれ方と伸びを分ける（`results/decomposition.csv`）
| 置き方 | 2回目の合格率 | 受け直した人の本当の実力（1回目の時点、平均） |
|---|---|---|
| （比べる相手）1回目の全員 | **38.74%** | 55.01点（全員） |
| 落ちた人全員が受け直す・伸びなし | 14.04% | 47.48点 |
| 合格点に近い人ほど受け直す・伸びなし | **28.75%** | 54.53点 |
| 落ちた人全員が受け直す・伸び5点 | 28.22% | 47.48点 |
| 合格点に近い人ほど受け直す・伸び5点（基本） | **51.11%** | 54.53点 |

- 基本の置き方では、2回目の人の合格率は51.11%で、1回目の38.74%より12.37ポイント高かった
- 伸びをなくすと、2回目の合格率は28.75%で、1回目より9.99ポイント低かった。**伸びがなければ、合格点に近い人だけが受け直しても、2回目の合格率は1回目を上回らなかった**。受け直す人の本当の実力（54.53点）は、1回目の受験者全体の平均（55.01点）とほぼ同じで、合格点（60点）より下の人が多いため
- 落ちた人全員が受け直すときの14.04%から基本の51.11%までの37.07ポイントのうち、選ばれ方（全員→合格点に近い人ほど、伸びなし）で14.71ポイント、そのうえでの伸びで22.36ポイント上がった。伸びの分は差の60.3%だった
- 受け直した人のうち、本当の実力が60点以上だった（1回目はたまたま落ちた）人は19.8%だった。一方、受け直した人の本当の実力の平均と1回目の点の平均の差は+0.14点しかなかった。合格点（60点）が受験者の平均（55点）より上にあるので、合格点の少し下の点の人は、本当の実力も同じくらいの人が多い。「たまたま低く出た分が戻る」効き目は、平均ではほとんどなかった

### 1回目の点ごと（基本の置き方、`results/by_first_score.csv`）
| 1回目の点 | 受け直した割合 | 本当の実力の平均 | 受け直した人の2回目の合格率 |
|---|---|---|---|
| 0〜39点 | 0.6% | 35.93点 | 3.8% |
| 40〜44点 | 3.6% | 44.12点 | 11.3% |
| 45〜49点 | 11.0% | 48.31点 | 24.2% |
| 50〜54点 | 29.5% | 52.52点 | 42.2% |
| 55〜57点 | 52.5% | 55.88点 | 57.6% |
| 58〜59点 | 67.4% | 57.99点 | 67.4% |

- 受け直した割合は置いた決まりそのもの（59点で70%から下がる）。2回目の合格率は、伸び5点を置いたうえでの値

### 確かめ：置き方を変えると（45通り、各40万人、`results/robustness.csv`）
| 伸び | 2回目が1回目より高かった通り（15通りのうち） |
|---|---|
| 0点 | **1通り**（実力の標準偏差8点・b=0.5で+0.19ポイント） |
| 2点 | 4通り |
| 5点 | 10通り |

- 2回目の合格率 − 1回目の合格率は、45通りで−31.71〜+24.97ポイントだった。選ばれ方が強いほど（b が大きいほど）、伸びが大きいほど高く、人どうしの実力の差が大きいほど低かった
- 伸び0点の15通りでは、差は−31.71〜+0.19ポイントで、1回目を上回ったのは1通りだけだった。伸び5点でも、15通りのうち5通りでは2回目のほうが低かった（b が0〜0.12で、落ちた人が点によらず受け直しやすい置き方）
- 受け直した人の本当の実力の平均と1回目の点の平均の差は、45通りで−0.62〜+1.83点だった。点によらず受け直す置き方（b=0）では少し上（1回目の点が低く出た分が戻る）、合格点のすぐ下の人だけが受け直す置き方（b=0.5）では少し下になった
- このことから、2回目の合格率が1回目より高いか低いかだけでは、受け直した人の実力がどれだけ伸びたかは読めない。同じ伸び5点でも、差は選ばれ方と人どうしの実力の差で−21.09〜+24.97ポイントに動いた（`results/robustness.csv` の gain=5 の行）

## 注意（言えないこと）
- 架空のデータです。実力の分布、受け直す人の決まり方、実力の伸びは作成者が置いたもので、数字はこれで決まります。2回目の合格率が1回目より高くなるかは、伸びと選ばれ方の置き方の写しで、45通りで−31.71〜+24.97ポイントと向きも入れかわります。新しく数えたのは、伸びがないと選ばれ方だけでは1回目をほとんど上回らないこと（この置き方で、合格点が受験者の平均より上にある場合）と、合格率の差から伸びを読めないことです
- 1回目の受験者は全員が初めての人と置きました。実際の試験では、1回目の人の中に準備の度合いの違う人がまざり、2回目の人と比べる相手そのものが変わります。合格点が受験者の平均より下にある試験では、落ちた人の点は実力より低く出やすく、伸びがなくても2回目の合格率が上がりやすくなると考えます（推測）
- 伸びは、受け直す人に一律に置いた数で、どんな勉強や講座で伸びるかは扱っていません。勉強のしかたや講座の良し悪しは、ここからは言えません
- 実在の試験の受験回数別の合格率を表すものではありません
- 関連する記事：同じ企画の 930 は、合格点のすぐ下で落ちた人がもう一度受けると何%受かるか（伸びなし・全員が受け直す）を数えています。928（独学の人と講座の人の合格率は比べられるか）は、比べる2つの人の集まりがそもそも違うという同じ形の問題です。925（過去問の点が上がったのは実力か問題を覚えたからか）は、同じ人の点の上がり方を扱っています。運と実力の企画の 830（2年目のジンクス）は、成績で選ばれた人の次の成績が上振れの分だけ戻ることを数えています
