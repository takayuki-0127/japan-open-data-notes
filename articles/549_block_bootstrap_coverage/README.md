# 549 自己相関のある日次データで、ふつうのブートストラップの95%区間は、正解を何%含むのか（手法の解説・正解の分かるデータで試す）

ブートストラップは、データから何度も引き直して区間を作る方法です。ふつうのやり方は1件ずつばらばらに引き直すので、「今日の値が昨日の値に似る」（自己相関）という性質が消えます。**ここでは、本当の平均が100と分かっている架空の日次の系列（AR(1)、自己相関 φ = 0・0.3・0.6・0.9、長さ 90・365・1,000日）で、平均の95%区間を5通りで作り、本当の平均を含む割合と区間の幅を数えました。** 各場面500回くり返しています。数字は置いた系列の作り方で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A549 | 自己相関があるとき、平均の95%区間は本当の平均を何%含むか | t区間、ふつうのブートストラップ（1日ずつ引き直す）、ブロックブートストラップ（循環の移動ブロック、5・20・50日、長さの3分の1未満のときだけ）。どれもパーセンタイル。ブートストラップ499回、各場面500回、seed 549。本当に必要な幅は AR(1) の分散の式から計算 | `src/a549_block_bootstrap.py` |

## 主な結果（365日の場合、φ = 0 / 0.3 / 0.6 / 0.9）
- **ふつうのブートストラップ**：本当の平均を含んだ割合は 96% / 82% / 68% / **33%**。t区間もほぼ同じ（96% / 84% / 69% / 33%）
- **区間の幅**：ふつうのブートストラップの幅は、本当に必要な幅の 0.99 / 0.73 / 0.49 / **0.22倍**
- **ブロックブートストラップ**：5日 95% / 92% / 87% / 60%、20日 94% / 93% / 90% / 82%、50日 92% / 90% / 88% / 86%。自己相関が強いほど、長いブロックが必要
- **日数を増やしても、ふつうのブートストラップは当たるようにならない**：φ=0.9 で 90日 36%、365日 33%、1,000日 34%。20日のブロックは 71% → 82% → 87%
- **ブロックでも 95% には届かない場面がある**：φ=0.9 では 1,000日・50日のブロックで 91%。90日だと 20日のブロックで 71%


## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- 自己相関なし（φ=0）で、t区間とふつうのブートストラップが 95% 前後（93〜96%）になること
- ブロックの引き直しを累積和で速くした関数が、日付の番号で並べる素直なやり方と同じ値になること

## データ
- データファイルは置いていない。系列はコードの中で乱数から作る（seed 549）

## 注意（言えないこと）
- 架空の系列。実際の売上やアクセスの数字ではない
- 系列は AR(1)・正規分布と置いた。曜日の波・季節・トレンドがある系列では、数字は変わる
- ブロックの長さは 5・20・50日だけ試した。長さを自動で決める方法は扱っていない
- 区間はパーセンタイルだけ。ほかの区間の作り方（BCa など）は扱っていない
