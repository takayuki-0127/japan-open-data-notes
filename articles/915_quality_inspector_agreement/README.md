# 915 検査員によって合否が違うとき、何を数えればよいのか？（品質と検査）

外観検査のように人の目で合否を決める検査では、同じ部品でも検査員によって合否が分かれます。そこで「2人の判定がどれだけそろったか（一致率）」を数えたくなりますが、一致率が高いことは、判定が正しいことを意味しません。同じ癖を持つ2人は、よくそろったまま、同じ不良をそろって見逃します。**ここでは、作成者が乱数で作った架空の工場の樹脂部品（本当の傷の大きさと、本当に不良かどうかを作成者が置いたもの）を4人の検査員が判定したときに、一致率・κ（カッパ、偶然でもそろう分を引いた一致の度合い）・不良と判定した割合・見逃しと誤検出を数え、どれが検査員の違いを表すかを比べました。**

検査で「不良」と出た品物が本当に不良かは関連する記事 911、全数検査で見逃しが残ることは 914 で扱っています。この記事は「検査員どうしの合否の違いを、何で数えるか」に絞ります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A915 | 検査員によって合否が違うとき、一致率・κ・不良と判定した割合・見逃しと誤検出のどれが検査員の違いを表すか | 架空の工場の樹脂部品（ふた）の外観検査。部品ごとに本当の傷の大きさ（mm）を置き、対数正規分布（対数の標準偏差0.6）で、1.0mmを超える部品を本当の不良とした（作成者が置いた物差し）。本当の不良の割合は基本5%（傷の分布の中心をずらして合わせる）。検査員は傷の大きさを見誤り（見えた大きさ＝本当の大きさ×exp(誤差)、誤差は標準偏差0.2の正規分布、1個ごと・1人ごとに別々）、自分の線を超えたら不良と判定する。線はA 0.85mm（厳しめ）、B 1.00mm（物差しどおり）、C 1.20mm（甘め）、D 1.20mm（甘め、Cと同じ線）。1回に部品2,000個を4人が全部判定し、300回くり返して平均した。一致率は2人の判定が同じだった部品の割合、κは（一致率−偶然の一致率）÷（1−偶然の一致率）。見逃しは本当の不良のうち良品と判定した割合、誤検出は本当の良品のうち不良と判定した割合。A・B・Cの多数決も数えた。限度見本（本当に不良と分かっている部品）で検査員Cの見逃しを測るとき、見本が10・30・100個でどれだけ振れるかを5,000回数えた。確かめとして、本当の不良の割合（1%・5%・20%）×見誤りの大きさ（0.1・0.2・0.4）の9通りを各100回。seed 915 | `src/a915_inspector_agreement.py` |

## 主な結果

### 検査員ごと（本当の不良4.99%、300回の平均）
| 検査員 | 不良と判定した割合 | 見逃し（不良を良品と判定） | 誤検出（良品を不良と判定） |
|---|---|---|---|
| A（厳しめ、線0.85mm） | 9.59% | **6.16%** | 5.17% |
| B（物差しどおり、線1.00mm） | 5.91% | 20.0% | 2.02% |
| C（甘め、線1.20mm） | 3.22% | **44.13%** | 0.46% |
| D（甘め、線1.20mm） | 3.23% | 43.94% | 0.46% |
| A・B・Cの多数決 | 5.39% | 16.45% | 1.29% |

- 同じ部品を判定しても、不良と判定した割合はAとCで2.98倍違った。この割合は本当の答えがなくても数えられ、検査員の線のずれがすぐに見える
- 物差しどおりの線のBでも、見誤りがあるため不良の20.0%を見逃し、良品の2.02%を不良とした。線の上下の部品は、見誤りで両方向に入れかわる
- 多数決は、Bより見逃しが少なく誤検出も少なかった（16.45%と1.29%）。ただし多数決にしても、本当の不良の割合（4.99%）とは別の5.39%になった

### 検査員の組ごと（300回の平均）
| 組 | 一致率 | κ | 2人とも見逃した不良の割合 |
|---|---|---|---|
| A-B | 94.11% | 0.590 | 2.33% |
| A-C | 93.11% | 0.435 | 4.36% |
| A-D | 93.11% | 0.434 | 4.28% |
| B-C | 96.04% | 0.546 | 13.32% |
| B-D | 96.02% | 0.545 | 13.06% |
| C-D | **97.49%** | **0.597** | **26.82%** |

- 一致率がいちばん高かったのは甘めの2人（C-D、97.49%）で、2人そろって見逃した不良もいちばん多かった（26.82%）。同じ線を持つ2人は、同じ不良を見逃すのでよくそろう
- κでも C-D（0.597）は A-B（0.590）と並んでいちばん高い側だった。κは偶然の一致を引くが、2人の癖が同じかどうかを見るもので、正しさは表さない
- 一致率は、どの組でも93%以上だった。本当の不良が5%と少ないので、ほとんどの部品は誰が見ても良品で、そこで一致する

### 限度見本で検査員Cの見逃しを測ると（本当の見逃し44.7%、5,000回）
| 見本の不良の数 | 見逃しの推定の平均 | 10〜90%の範囲 |
|---|---|---|
| 10個 | 44.6% | 30.0〜60.0% |
| 30個 | 44.5% | 33.3〜56.7% |
| 100個 | 44.8% | 38.0〜51.0% |

- 見逃しは、本当に不良と分かっている部品（限度見本）を判定させれば数えられる。振れの大きさは二項分布の式どおりで、10個では30〜60%の幅があった
- 見本は不良の部品からでたらめに選んだ。実際の限度見本は線の近くの部品を選ぶことが多く、そのときは見逃しの数字の意味が変わる（推測）

### 確かめ：本当の不良の割合×見誤りの大きさ（9通り、各100回）
| 本当の不良の割合 | A-C の一致率 | A-C のκ | C の見逃し |
|---|---|---|---|
| 1% | 95.71〜98.34% | 0.242〜0.361 | 49.97〜52.60% |
| 5% | 88.67〜93.98% | 0.321〜0.454 | 43.57〜45.92% |
| 20% | 77.26〜84.30% | 0.399〜0.539 | 35.73〜38.87% |

（各行は見誤りの大きさ0.1・0.2・0.4の3通りの幅）

- 9通りすべてで、C-D の一致率は A-B より高く、2人とも見逃した不良も C-D のほうが A-C より多かった
- κは9通りのうち6通りで C-D が A-B より高かった（C-D 0.278〜0.829、A-B 0.312〜0.752）
- 同じ2人（A-C）でも、本当の不良が少ないほど一致率は高く（20%で77.26%、1%で98.34%）、κは低く出た（1%で0.242）。一致率もκも、検査員だけでなく部品の中の不良の割合で動く
- Cの見逃しも、不良の割合で35.73〜52.60%動いた。この置き方では不良の割合を傷の分布の中心で合わせたので、不良が少ないほど、線のすぐ上の小さな傷の不良が多くなり、甘めの線で見逃されやすい。見逃しは検査員だけでは決まらず、どんな不良が流れてくるかでも変わる

## 動かし方
```
pip install -r requirements.txt
cd src && python a915_inspector_agreement.py
```
2秒ほどで終わります。`data/one_round_parts.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約2秒）
- 「C-D がいちばんよく一致する」は、CとDに同じ線を置いたことの写しで、新しく数えたものではない。数えたのは、そのとき一致率・κ・不良と判定した割合・見逃しがそれぞれどう見えるか
- 検査員ごとの見逃し・誤検出の値（Cの44.13%など）は、作成者が置いた線と見誤りの大きさで決まる値で、9通りでは35.73〜52.60%動いた
- 限度見本での見逃しの振れは、二項分布の式どおりの幅になった

## データ
- `data/one_round_parts.csv`：1回分の部品2,000個（本当の不良は88個）。part_id・flaw_mm（本当の傷の大きさ）・true_defect（本当の不良なら1）・judge_A〜judge_D（各検査員が不良と判定したら1）

## 注意（言えないこと）
- 架空のデータです。傷の大きさの分布、物差し（1.0mm）、検査員の線と見誤りの大きさは作成者が置いたもので、結果はこれで決まります。実在の工場・検査を数えたものではありません
- 検査員の見誤りは、部品ごと・人ごとに別々と置きました。見えにくい傷は誰にとっても見えにくい、のように見誤りが人どうしでそろうと、一致率はさらに上がり、2人とも見逃す不良も増えるはずです（推測）
- 検査員の線は一定と置きました。疲れや慣れ、時間帯で線が動くことは入れていません
- どの検査員の線が良いか、見逃しと誤検出のどちらを減らすべきかは、不良の重さと手間で決まることで、ここでは扱いません
- 関連する記事 911 は検査で「不良」と出た品物が本当に不良か、914 は全数検査でも見逃しが残ることを扱っています。この記事は検査員どうしの違いの数え方に絞りました
