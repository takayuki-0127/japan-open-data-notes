# 397 住まいは、いつから「共同住宅」が増えたのか（住宅・土地統計調査、1968〜2023年）

住宅の建て方（一戸建・長屋建・共同住宅）と建物の階数を、1968〜2023年の12回の調査で並べたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A397 | 共同住宅はいつ3割・4割を超えたか。6階建て・11階建て・15階建て以上の建物にある住宅はどれだけ増えたか | 時系列統計表 第12-1表の実数から割合を計算。増えた分を建て方・階数に分ける | `src/a397_apartments.py` |

## 主な結果
- 共同住宅の割合：1968年18.4% → 1988年30.5% → 2003年40.0% → 2023年44.9%。一戸建は66.5%→52.7%、長屋建は14.7%→2.3%
- 住宅の総数は2,420万戸→5,567万戸（2.3倍）。増えた分の65%が共同住宅、42%が一戸建（長屋建は−7%）
- 共同住宅は445万戸→2,497万戸（5.6倍）。1〜2階建の割合は75%→25%、6階建以上は1%→38%。増えた分の45%が6階建以上
- 6階建以上の共同住宅にある住宅は住宅全体の0.2%（5万戸）→16.8%（937万戸）。11階建以上は1978年1.0%（33万戸）→7.3%（405万戸）、15階建以上は0.05%（1.6万戸）→2.1%（115万戸）
- 一戸建のうち平屋は63%（1,018万戸）→11%（335万戸）

## 確かめたこと
- 建て方の合計＝総数、共同住宅の階数の合計＝共同住宅（100戸単位の丸めの範囲）
- 自分で割った割合が、表の割合（小数第1位）と一致
- 空のフォルダで流し直し、data・results・figures が一致した

## データ
- `data/raw/hlts_ts_t12_1.csv`：e-Stat「令和5年住宅・土地統計調査 時系列統計表」第12-1表（statInfId=000040354042）の閲覧用 Excel を CSV にしたもの（2026-11-12 取得）
- `data/dwellings_by_type_stories.csv`：調査年ごとの実数と割合

## 注意（言えないこと）
- 建て方と階数をあわせた表は1968年からです。11階建て以上・15階建て以上は1978年からです
- 階数は建物の階数で、住んでいる階ではありません。人が住んでいる住宅の数で、空き家は入っていません
- 全国の数字です。1968年は沖縄県を含みません。標本調査の推定値です
- 共同住宅が増えた理由は、この表からは分けられません
