# 1244 付け手の意見が割れた件を「難しい件」として別に数えると、分類の正解率の上限はどう見えるのか？（ラベル付け）

1件を3人で付けて多い方の判定を「正解ラベル」にすると、3人がそろわなかった件が出ます。これを「難しい件」として別に数え、分類する仕組みの正解率を「そろった件」と「割れた件」に分けて出すことがあります。けれども、割れた件では正解ラベルそのものがまちがっていることが多く、本当の分類をいつも当てる仕組みでも、正解ラベルとは一部しか合いません。また、「割れた件」は「本当に見分けにくい文」とぴったりは重なりません。**ここでは、作成者が乱数で作った架空の問い合わせ文10,000件（「急ぎ」か「急ぎでない」かの本当の分類と、文ごとの見分けやすさを作成者が置いたもの）で、本当の分類をいつも当てる仕組み（いちばん良い仕組み）が、正解ラベルと比べて全体・そろった件・割れた件で何%に見えるか（上限）、付け手どうしの一致率、ふつうの仕組みの測った正解率と本当の正解率を数えました。5人で付けた場合と、見分けにくい文の割合×見分けにくさ×人数の18通りでも確かめました。**

例の問い合わせ文・分類・付け手・仕組みはすべて作成者が置いた架空のもので、実在の会社・サービス・分類する仕組みを表すものではありません。

関連する記事：915「検査員によって合否が違うとき、何を数えればよいのか？」は、検査員どうしの一致率が高くても判定が正しいとは限らないことを扱っています。この記事では、付け手どうしの一致率を正解率の上限とみなすと、上限を低く見積もることを数えます。1222「まだ判定していない文書を「正しくない」と見なすと、新しい検索のやり方はどれだけ不利になるのか？」は、比べる相手の判定が足りないと、良いやり方が低く測られることを扱っています。759「正解のラベルが1割まちがっていると、モデルの正解率はどれだけ低く見えるのか？」は、テストの件の正解ラベルの一部がまちがっていると、正解率が全体として低く見えることを扱っています。この記事は、そのまちがいが3人の割れた件に集まり、そろった件と割れた件に分けると見え方が大きく違う点を数えます。同じ企画の 1233「1件を3人で見て多い方の判定に決めると、1人で見るより正しくなるのは、どんなときか？」は、この記事と同じ「3人の多い方」を、1人より正しくなる条件の側から数えています。1235「迷った件を「分からない」として除くと、残ったデータで作った分類はどれだけ易しい問題になるのか？」は、迷った件を「分からない」として除くと、残った件で確かめた正しさが来る件全体より高く出ることを扱っています。この記事の「割れた件を別に数える」とは逆向きの見え方のずれです。1240「一部の件だけを2人で付けて確かめると、残りの件のまちがいの数はどこまで見込めるのか？」は、一部の件を2人で付けた食い違いから残りのまちがいの数を見込むと、2人がそろって同じ分類にまちがえる分が見えず、少なく見込むことを扱っています。この記事は、比べる相手の正解ラベルにまちがいがまざるときに、割れた件で正解率がどう見えるかに絞ります。

## 主な結果

### 全体・そろった件・割れた件で分けた正解率（基本、3人、200回の平均、`results/base_groups.csv`）
| | 全体 | 3人がそろった件 | 割れた件（難しい件） |
|---|---|---|---|
| 件数の割合 | 100% | 74.92% | 25.08% |
| (a)本当の分類を当てる仕組みの測った正解率（上限） | 93.77% | 98.86% | **78.58%** |
| 付け手どうしの一致率 | **83.28%** | 100% | 33.33% |
| (b)ふつうの仕組みの測った正解率 | 89.24% | 94.58% | **73.28%** |
| (b)ふつうの仕組みの本当の正解率 | 92.6% | 95.15% | **84.97%** |
| (c)もう1人の付け手の測った正解率 | 86.76% | 92.09% | 70.83% |

- **本当の分類をいつも当てても、割れた件で正解ラベルと合ったのは78.58%だった**。正解ラベルが本当の分類と合っていた割合そのもので、上限はラベルのまちがいで決まった。3人で2対1に割れた件では、多い方が正しい確率は1人が正しく付ける確率と同じになるので、割れた件の上限は文ごとのその確率の平均になる（式では78.65%）
- **付け手どうしの一致率（全体83.28%）を上限とみなすと、本当の上限93.77%より低く見積もる**。ふつうの仕組みの測った正解率89.24%は、その一致率を上回った。割れた件の一致率33.33%は、2対1に割れると3組のうち1組しか合わないことからの作りどおりの値
- **ふつうの仕組みは、割れた件で測ると73.28%だが、本当は84.97%当てていた**。割れた件では、正解ラベルのまちがいの分だけ低く測られた

### 「割れた件」と「本当に見分けにくい文」のずれ（基本、`results/a1244_main.json` の base）
| | 割合 |
|---|---|
| 割れた件のうち、本当に見分けにくい文 | **54.49%** |
| 本当に見分けにくい文のうち、割れた件に入った文 | **68.33%** |
| 見分けやすい文のうち、割れた件に入った文 | 14.27% |
| 3人がそろった見分けにくい文のうち、3人そろってまちがえた文 | 13.37% |
| 3人がそろった件のうち、正解ラベルがまちがっていた件 | 1.14% |

- **割れた件のうち本当に見分けにくい文は54.49%で、残りは見分けやすい文だった**。見分けやすい文は数が多いので、1人がまちがえるだけで割れた件に入る（見分けやすい文の14.27%）
- 本当に見分けにくい文のうち割れた件に入らなかった文は3人がそろった件に入り、その中の13.37%は3人そろってまちがえていた。この分は「そろった件」の中で、いちばん良い仕組みの正解率を下げる（そろった件の上限98.86%）
- 割れた件に入る割合（見分けにくい文68.33%）は、式（1−3人がそろう確率）の68.25%どおりだった

### 5人で付けると（`results/a1244_main.json` の five_raters）
| | 3人 | 5人 |
|---|---|---|
| 割れた件の割合 | 25.08% | 35.66% |
| 上限（全体） | 93.77% | 95.19% |
| 上限（割れた件） | 78.58% | 86.83% |
| 上限（そろった件） | 98.86% | 99.83% |
| 本当に見分けにくい文のうち、割れた件に入った文 | 68.33% | 87.86% |
| 割れた件のうち、本当に見分けにくい文 | 54.49% | 49.14% |
| ふつうの仕組みの割れた件での正解率（測った／本当） | 73.28%／84.97% | 79.45%／86.15% |

- 5人にすると、正解ラベルのまちがいが減って上限は上がったが、割れた件も増え、その中の見分けにくい文の割合は49.14%に下がった

### 確かめ：見分けにくい文の割合 × 見分けにくさ × 人数（18通り、`results/grid.csv`）
| | 18通りの範囲 |
|---|---|
| 上限（全体） | 85.45〜99.34% |
| 上限（割れた件） | **67.96〜97.56%** |
| 上限（そろった件） | 95.87〜100% |
| 割れた件のうち、本当に見分けにくい文 | 24.68〜77.24% |
| 本当に見分けにくい文のうち、割れた件に入った文 | 47.85〜91.33% |
| 付け手どうしの一致率−上限（全体） | −16.17〜−9.2ポイント |
| ふつうの仕組みの割れた件での、本当−測った | 1.35〜16.39ポイント |

- **18通りすべてで、割れた件の上限は全体の上限より低く、付け手どうしの一致率は全体の上限より低かった**。ふつうの仕組みの全体の測った正解率は、18通りすべてで付け手どうしの一致率を上回った（4.23〜7.42ポイント）
- 18通りすべてで、ふつうの仕組みの割れた件での測った正解率は本当の正解率より低かった
- 上限の値は式どおりだった（式との差は全体で最大0.05ポイント、割れた件で最大0.18ポイント）

## 注意（言えないこと）
- 架空のデータです。見分けにくい文の割合、付け手が正しく付ける確率、仕組みが当てる確率は作成者が置いたもので、結果はこれで決まります。とくに上限の値は、置いた確率からの式どおりです
- 見分けやすさは「やすい」「にくい」の2段にし、付け手はみな同じ確率で、ほかの付け手とは別々にまちがえると置きました。付け手ごとのくせや、付け手どうしが同じようにまちがえる分は入れていません（入れれば、そろってまちがえる件が増え、そろった件の上限も下がると推測します）
- 分類は2つだけにしました。3つ以上の分類では、割れ方と多い方の決め方が変わります
- 実在の分類する仕組みの正解率や、正解率の上限がどれだけかは言えません
