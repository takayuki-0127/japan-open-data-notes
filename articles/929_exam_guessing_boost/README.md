# 929 選択問題の「当てずっぽう」は、点をどれだけ押し上げるのか？（試験と点数）

選択問題の試験では、知らない問でもどれかを選べば、何割かは当たります。そのため、点数は「知っている問の数」より高く出ます。平均でどれだけ上がるかは式で決まりますが、合格点の近くでは、当たりの運で合否が入れかわります。**ここでは、作成者が乱数で作った架空の社内資格試験（4択・50問・30問以上で合格）の受験者2万人（知っている問の割合を作成者が置いたもの）で、当てずっぽうで点がどれだけ上がるか、合格した人のうち知っている問だけでは合格点に届かなかった人が何%いるかを数えました。**

合格点の決め方の良し悪しや、試験での答え方の助言はしません。

| A929 | 当てずっぽうで、点と合否はどれだけ動くか。選択肢の数・問の数・誤りの選択肢を外せるかで、どう変わるか | 架空の社内資格試験。基本は4択・50問・30問（60%）以上で合格。受験者2万人の「知っている問の割合」は平均0.5・標準偏差0.15のベータ分布。1問ずつ、その割合の確率で「知っている」とし、知っている問は必ず正解。知らない問は、残った選択肢から1つをでたらめに選ぶ。誤りの選択肢を外せる数（0・1・2個）の割合は、基本は「なし」（必ず0個）、確かめで「少し」（0個50%・1個30%・2個20%）と「多い」（20%・40%・40%）。選択肢は必ず2つ以上残す。知っている問だけの点と、当てずっぽうを含めた点を比べた。知っている割合が0.3〜0.75の人（各1万人）の合格する確率も数えた。確かめとして、選択肢の数（3・4・5択）×問の数（20・50・100問）×外せる数（なし・少し・多い）の27通りと、知っている割合の平均（0.4・0.5・0.6）の3通りを各2万人で数えた。当てずっぽうの分を差し引く式（正解数−誤答数÷（選択肢の数−1））も比べた。seed 929 | `src/a929_guessing_boost.py` |

## 主な結果

### 基本の置き方（4択・50問・30問で合格・外せる選択肢なし、2万人）
| | 当てずっぽうを含めた点 | 知っている問だけの点 |
|---|---|---|
| 合格した人の割合 | **60.52%** | 30.53% |
| 点の標準偏差（100点に直した点） | 13.11 | 16.48 |

- 当てずっぽうで、点は平均12.53点（100点に直した点）上がった。これは「知らない問の割合÷選択肢の数」の式どおりの値で、新しく数えたものではない
- 合格した人の**49.56%**は、知っている問が30問に届いていなかった。22.11%は25問以下で、いちばん少ない人は14問だった
- 式で見ると、4択で60%の点に平均で届くには、知っている問の割合が46.67%あればよい（（0.6−1/4）÷（1−1/4））
- 当てずっぽうは、点の散らばりを小さくした（標準偏差16.48→13.11）。知らない問が多い人ほど多く上乗せされるため

### 知っている問の割合ごとの、合格する確率（各1万人）

|---|---|---|---|---|---|---|---|---|
| 当てずっぽうを含めた点で | 5.46% | 28.72% | 49.78% | **70.05%** | 86.11% | 95.47% | 99.11% | 99.88% |
| 知っている問だけの点で | 0.0% | 0.34% | 2.47% | 10.33% | 28.3% | 56.35% | 80.84% | 95.19% |

- 知っている問がちょうど半分の人は、70.05%の確率で合格した。知っている割合40%の人でも28.72%が合格した
- 知っている割合が合格点と同じ60%の人は、当てずっぽうを含めると95.47%が合格した

pip install -r requirements.txt

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、2回流して約3〜8秒。ほかの処理と同時に流したので幅がある）
- 点の上がり方の平均は、式「知らない問の割合÷選択肢の数」どおりの値（基本で平均12.53点）で、新しく数えたものではない。差し引く式が、でたらめに選ぶときにずれないことも式どおり
- 数えたのは、合格点の近くで合否が入れかわる人の割合と、それが選択肢の数・問の数・外せる選択肢・受験者の分布でどれだけ動くか

## 注意（言えないこと）
- 架空のデータです。知っている問の割合の分布、誤りの選択肢の外せ方、合格点は作成者が置いたもので、結果はこれで決まります。実在の試験を数えたものではありません
- 「知っている」か「知らない」かの2つに分けました。実際には、知っているつもりで間違える問や、迷って正解を外す問もあるはずです（推測）。そうした問は入れていません
- 合格点は、作る側が当てずっぽうの分を見込んで決めているかもしれません（推測）。この記事は、合格点の決め方の良し悪しを扱いません
- 試験での答え方（空欄にするか、どれかを選ぶか）の助言はしません。誤答で減点する試験は置いていません
- 関連する記事 827（連勝の長さは偶然でどこまで伸びるか）・836（実力差と偶然の逆転）は、運の振れが結果を動かす話をスポーツの例で扱っています。この記事は、選択問題の当たりの運と合格点の関係に絞りました。同じ企画の 921（実力が合格ラインちょうどの人は何%受かるか）は、当てずっぽうのない形で、実力ごとに受かる確率を数えています
