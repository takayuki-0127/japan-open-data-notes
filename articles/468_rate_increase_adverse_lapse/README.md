# 468 一律に保険料を上げたとき、事故の少ない契約から先に抜けると、残った契約の損害率はどう動くのか（手法の解説）

保険料を全部の契約で同じ率だけ上げたとき、抜ける契約が事故の少ない側に偏ると、残った契約の損害率は見込みほど下がりません。**契約ごとの本当の事故率が分かっている架空の契約で、抜け方の偏りの強さを4通りに置いて計算しました。** 抜け方は置いた前提で、実際の契約者の動きを表すものではありません。数字は前提で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A468 | 一律の値上げのあと、残った契約の損害率は、偏りなく抜ける場合と比べて何ポイント高くなるか。目標の損害率まで値上げをくり返すと、保険料と契約の数はどうなるか | 架空の契約20万件（事故率は平均0.08のガンマ分布、変動係数0.6。損害の平均50万円。保険料は一律で、はじめの損害率75%）。値上げ r のとき更新しない確率を logit=logit(0.10)+8r−s·(r/0.10)·z（z は事故率の対数を標準化した値、s=0・0.25・0.5・1.0）と置き、見込みの損害率を計算 | `src/a468_lapse.py` |

## 置いたこと（架空）
- 値上げがなければ、どの契約も10%が更新しない。10%の値上げで、平均して約20%が抜ける
- 偏りの強さ s は、値上げの幅に比例して効く（大きな値上げほど偏りが強い）
- 損害率は見込みの値（偶然の振れなし）。偶然の振れは契約2,000件・2万件で別に測った
- 新しく入ってくる契約は入れていない
- くり返しの値上げ：損害率が65%を上回るあいだ、毎年、偏りなしなら65%に届く率だけ上げる（上限は年20%）

## 主な結果
### 10%の値上げのあと（はじめの損害率75%、偏りなしの見込み68.2%）
| 偏りの強さ | 損害率 | 下がるはずの幅のうち消えた割合 | 残った契約 | 残った契約の事故率 | 抜けた契約の事故率 | 保険料の合計 |
|---|---|---|---|---|---|---|
| なし（0） | 68.2% | 0% | 80.2% | 8.00% | 8.00% | −11.8% |
| 弱い（0.25） | 70.0% | 27% | 79.9% | 8.22% | 7.14% | −12.1% |
| 中くらい（0.5） | 71.9% | 55% | 79.1% | 8.44% | 6.35% | −13.0% |
| 強い（1.0） | **75.5%** | 107% | 76.6% | 8.86% | 5.20% | −15.8% |

### 値上げの幅を変えたとき（損害率、%）
| 値上げ | 偏りなしの見込み | 弱い | 中くらい | 強い |
|---|---|---|---|---|
| +5% | 71.4 | 72.1 | 72.8 | 74.3 |
| +10% | 68.2 | 70.0 | 71.9 | 75.5 |
| +20% | 62.5 | 68.3 | 73.1 | 78.8 |
| +30% | 57.7 | 69.2 | 75.6 | 80.0 |

### 10%の値上げで更新しない割合（事故率の順の10等分。置いた前提）
| 偏りの強さ | 事故がいちばん少ない1割 | いちばん多い1割 |
|---|---|---|
| なし | 20% | 20% |
| 弱い | 28.9% | 14.5% |
| 中くらい | 40.0% | 10.4% |
| 強い | 62.7% | 5.3% |

### 目標65%まで値上げをくり返したとき（6年分）
| 偏りの強さ | 65%に届いた年 | 保険料の水準（はじめ=100） | 6年目の契約の数（はじめ=100） |
|---|---|---|---|
| なし | 1年目 | 115.4 | 42.8 |
| 弱い | 4年目 | 123.5 | 39.7 |
| 中くらい | 5年目 | 136.5 | 35.1 |
| 強い | 6年目 | 164.7 | 30.2 |

- 事故率の散らばり（変動係数0.3／0.6／1.0）を変えると、10%値上げ後の損害率は、中くらいの偏りで70.2／71.9／73.5%、強い偏りで72.2／75.5／78.4%
- 1年分の実績の振れ（標準偏差）：契約2,000件で約9ポイント、2万件で約3ポイント

全部の数字は `results/` の5つの CSV と `main.json` にあります。

## 動かし方
```
pip install -r requirements.txt
cd src && python a468_lapse.py      # 約1分
```
`data/example_policies.csv`（例の契約の一部）、`results/` の6ファイル、`figures/` の3枚ができます。

## 確かめたこと
- 空のフォルダで計算し直し、data・results・figures が一致した
- 偏りなし（s=0）では、値上げ後の損害率が 75%÷(1+値上げ率) と一致し、残った契約と抜けた契約の事故率が同じ
- 偏りなしでは、くり返しの値上げは1年目（+15.4%）で終わる

## 注意（言えないこと）
- 架空の契約です。数字は、事故率の散らばり、値上げで抜ける割合、抜け方の偏りの置き方で決まります。実際の契約者の動きは、この計算からは分かりません
- 保険料は一律と置きました。事故率に合わせて差をつけている場合は、偏りの出方が変わります（区分の細かさは335、逆選択の基本は320）
- 新しい契約、ほかの会社の保険料、契約者が自分の事故率をどこまで知っているかは入れていません
- 偏りの強さが値上げの幅に比例する置き方は、説明のための単純な形です。大きな値上げの数字ほど置き方に左右されます
- 保険料をどう決めるべきか、値上げをすべきかどうかを言うものではありません。本物の保険データでは確かめていません
