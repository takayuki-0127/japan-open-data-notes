# 983 振り分けで「迷惑メール」と出たとき、本当に迷惑メールの確率は？（確率の直感）

メールの振り分けの仕組みが「迷惑メールの95%を見つけ、ふつうのメールを間違えるのは1%だけ」と聞くと、「迷惑」と出たメールはほぼ迷惑メールだと思いがちです。けれども、「迷惑」と出たメールのうち本当に迷惑メールの割合は、届くメールのうち迷惑メールがもともとどれだけあるか（もとの割合）で大きく変わります。同じ会社の中でも、受信箱ごとにもとの割合は違います。**ここでは、作成者が乱数で作った架空の会社の300人の受信箱（受信箱ごとの迷惑メールの割合と、振り分けの見逃し・誤検出の割合を作成者が置いたもの）で、「迷惑」と出たメールのうち本当に迷惑メールの割合を、会社全体と受信箱ごとに数え、受信箱ごとの散らばりと誤検出の割合を変えるとどう動くか、「迷惑」と出た割合からもとの割合を読むとどれだけずれるかを確かめました。**

## 注意（言えないこと）
- 架空のデータです。受信箱ごとの迷惑メールの割合とその散らばり、見逃しと誤検出の割合、届く数は作成者が置いたもので、結果はこれで決まります。「迷惑」の半分より多くがふつうのメールの受信箱の割合は、置き方で0〜67.93%と動きました
- 会社全体の当たり（81.83%）と、もとの割合×誤検出の表は、条件つきの確率の式どおりの値です。この記事で新しく数えたのは、会社全体の値がほとんど動かない置き方でも、受信箱ごとに見ると「迷惑」の多くがふつうのメールになる受信箱の割合が大きく動くこと、「迷惑」と出た割合を直す読み方が誤検出の見積もりと受信箱の小ささで崩れることです
- 見逃しと誤検出の割合は、どの受信箱でも、どのメールでも同じと置きました。実際の振り分けは、受信箱やメールの種類で間違えやすさが変わることがあり、そのときはこのとおりにはいきません（推測）
- 実際のメールの振り分けの仕組みや、その当たりを表すものではありません。どの振り分けの設定を使うべきかの助言はしません
