# 900 割合の平均と、合計で出した割合はどれだけ違うのか？（割合とパーセント）

店ごとの購入率を出してその平均を取るか、全店の購入数の合計を来店数の合計で割るか。どちらも「購入率」と呼ばれますが、答えている問いが違います。合計で割った率は「来た人のうち何%が買ったか」、率の平均は「ふつうの店の購入率はいくらか」です。**ここでは、作成者が乱数で作った架空の雑貨チェーン200店の1か月（店ごとの本当の購入率を作成者が置いたもの）で、2つの数え方の差がどれだけ出るか、それぞれがどちらの「本当の値」に当たるかを数え、差が店の大きさと購入率の結びつきの置き方でどう動くかを確かめました。**

2つの差は、式でちょうど「−（来店数と率の共分散）÷来店数の平均」になります。この記事の数字の多くはこの式どおりの値で、数えて新しく分かったのは、置き方ごとの差の大きさと、結びつきがないときの1か月ごとの振れです。

## 主な結果

### 1か月分（data/stores.csv）
| 数え方 | 値 |
|---|---|
| 合計÷合計 | **17.96%** |
| 店ごとの率の平均 | **20.69%** |
| 店ごとの率の中央値 | 19.91% |
| 差（平均−合計） | 2.725ポイント |
| 式（−共分散÷来店数の平均）で出した差 | 2.725ポイント |

- 来店数の多い上位2割の店が、来店数の46.78%を占めた。この店たちの合計の率は15.80%、残りの店は19.87%だった。合計で割ると、来店の多い店の低い率が強く効く
- 差は式の値と一致した（1,000回で、ずれは最大6.59e-17）

### 2つの数え方と、2つの本当の値（1,000回）
| 数え方 → 本当の値 | 平均のずれ | 10〜90%の範囲 |
|---|---|---|
| 合計で割る → 会社全体の本当の購入率 | +0.001ポイント | −0.054〜+0.058 |
| 合計で割る → 店の本当の購入率の平均 | −2.443ポイント | −3.119〜−1.763 |
| 店ごとの率の平均 → 会社全体の本当の購入率 | +2.445ポイント | +1.779〜+3.12 |
| 店ごとの率の平均 → 店の本当の購入率の平均 | +0.001ポイント | −0.077〜+0.085 |

- どちらの数え方も、自分の問いの本当の値にはほぼ当たり、相手の問いには約2.4ポイント外れた
- 率の平均は1,000回すべてで合計の率より高かった。差の平均は2.445ポイントで、合計の率に対して13.15%の大きさだった

### 確かめ：来店数と購入率の相関 × 来店数の店どうしの差（15通り、各300回）
| 相関 | 差 0.3 | 差 0.8 | 差 1.2 |
|---|---|---|---|
| −0.6 | +1.397 | +3.58 | +5.183 |
| −0.3 | +0.707 | +1.856 | +2.707 |
| 0 | −0.002 | −0.029 | +0.024 |
| +0.3 | −0.719 | −1.95 | −2.955 |
| +0.6 | −1.452 | −4.023 | −6.13 |

（率の平均−合計の率、ポイント、300回の平均）

- 差の向きは、置いた相関の向きで決まった。来店の多い店ほど率が高いと置くと、率の平均のほうが低く出た。差の大きさは、店の大きさの差が大きいほど大きかった。15通りで−6.13〜+5.183ポイント
- 相関を0と置くと、差は平均で0.03ポイント以内に消えた。ただし1か月ごとには振れ、来店数の差1.2では10〜90%の範囲が−1.121〜+1.106ポイントだった

## 動かし方
```
pip install -r requirements.txt
cd src && python a900_mean_vs_pooled.py
```
5秒ほどで終わります。`data/stores.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約5秒）
- 2つの数え方の差は、式（−共分散÷来店数の平均）とすべての回で一致した。差の向きと大きさは、置いた相関と店の大きさの差の写しである。データから見つけたものではない
- 相関0では差が平均で消えることを確かめた（作りが正しいことの確かめ）

## データ
- `data/stores.csv`：架空の200店の1か月。store_id・visits（来店数）・true_rate（作成者が置いた本当の購入率）・buys（購入数）・rate（見かけの購入率）

## 注意（言えないこと）
- 架空のデータです。来店数の分布、購入率の店どうしの差、来店数と購入率の相関は作成者が置いたもので、結果はこれで決まります。とくに差の向きは、置いた相関の向きの写しです
- どちらの数え方が正しいかは、問いで決まります。「来た人のうち何%が買ったか」には合計で割った率、「ふつうの店はどうか」には率の平均（または中央値）が当たります。この記事はどちらかをすすめるものではありません
- 店の数（200店）と1か月という長さは作成者が置いたものです。店が少ないと、相関がなくても1か月ごとの差はもっと振れます
- 関連する記事 890 は見積もりの外れで、896 は手数料の割合で、「1件ごとの割合の平均」と「合計どうしの比」が違う値になることを扱っています。この記事は、その差がどちらの向きにどれだけ出るかを、店の大きさと率の結びつきで数えたものです
- 既存の記事 579 は、小さい店ほど購入率が高い架空の50店（2年分）で、単純平均・中央値・重み付き平均・合計の比を比べています。この記事は、2つの数え方がそれぞれどちらの「本当の値」に当たるかと、差の向きが店の大きさと率の結びつきの向きで逆になることに絞りました
- 同じ企画では、割合だけの表からは人数で重みを付けた合計の割合が出せないことを 908、店ごとの前後の変化を差と比のどちらで並べるかを 906 で扱っています（906 は店どうしの変化の比べ方で、この記事は全体の率の出し方です）
