### boj-timeseries：日本銀行の API で時系列を取り、物価と景況感を分析する

日本銀行「時系列統計データ検索サイト」の API でデータを取得し（`src/fetch_boj.py`）、整形して分析までを Python で行うリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| B1 | 円安は、何か月かけて輸入物価と国内企業物価に伝わるか | 輸入物価の前年比の分解（為替要因・契約通貨要因）、VAR（ベクトル自己回帰）のインパルス応答、変数の順番・ラグを変えた頑健性 | `src/b1_passthrough.py` |
| B2 | 短観の「先行き」は、3か月後の実績を当てているか | 予測誤差（MAE・RMSE）、素朴な予測との比較、バイアス、Mincer–Zarnowitz 回帰 | `src/b2_tankan_forecast.py` |

#### 主な結果
- **B1**：1%の円安で、輸入物価（円ベース）は当月に約0.7%上がる。国内企業物価への累積効果は1年で約0.03%（95%区間は0をまたぐ。変数の順番やラグを変えても0.03〜0.11%）。一方、契約通貨ベースの輸入物価（資源価格など）が1%上がると、国内企業物価は1年で約0.5%上がる。2022年7月の輸入物価（円ベース）の前年比+40%のうち、為替要因は約17ポイント、契約通貨要因は約24ポイント
- **B2**：1990〜2026年の147四半期で、大企業・製造業の予測の平均絶対誤差は4.7ポイント（「前の四半期と同じ」とする素朴な予測は5.8）。非製造業では素朴な予測のほうが外れが小さい。2010年代以降はどの区分も実績が予測を上回りがちで、中小企業・非製造業では平均+3.9ポイント

#### データ
| ファイル | 中身 |
|---|---|
| data/raw/boj_prices_fx.csv | 国内企業物価指数・輸入物価指数（円ベース・契約通貨ベース）・輸出物価指数（2020年基準、総平均、月次）、ドル円（東京市場 17時時点 月中平均） |
| data/raw/boj_tankan_di.csv | 短観 業況判断DI（大企業・中小企業 × 製造業・非製造業、実績と予測、四半期） |

- 短観の予測DIは、「対象の四半期」の行に入っています（例：2026Q4 の予測は、2026年9月調査で答えたもの）
- 取得日：2026年10月22日

#### 注意
- VAR の結果は、変数の並べ方（どれが先に動くとみなすか）で変わります。`results/b1_robustness.csv` に並べ方とラグを変えた結果を置きました
- 輸入物価の分解は「円ベース ≒ 契約通貨ベース × 為替」の近似です
- どれも過去のデータの関係で、将来も同じとは限りません
