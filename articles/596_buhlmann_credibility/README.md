# 596 小さい契約群の実績を全体の平均とどう混ぜるか？ Bühlmann のクレジビリティで、群の大きさごとに予測の誤差はどれだけ減るのか（手法の解説・保険数理）

契約件数の少ない群は、たまたまの数件で事故率が大きく振れます。かといって全体の平均だけを使うと、本当に事故率の違う群の差を消してしまいます。**ここでは、架空の300の契約群（1年あたり20〜5,000件、本当の事故率は平均5%）で、過去3年の実績から翌年の事故率を予測するとき、①自分の実績だけ、②全体の平均だけ、③Bühlmann–Straub のクレジビリティ（自分の実績と全体の平均を重み Z で混ぜる）を比べました。** 群どうしの本当の差の大きさ（変動係数 CV 0〜0.6）も変えています。数字は置いた前提で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|

## 主な結果（本当の事故率のばらつき CV 0.3）
- **全300群の誤差（RMSE）**：自分の実績だけ **1.22ポイント**、全体の平均だけ **1.50ポイント**、クレジビリティ **0.79ポイント**（自分の実績だけより35%、全体の平均だけより47%小さい）
- **1年100件未満の群**：自分の実績だけ2.03、全体の平均だけ1.49、クレジビリティ1.18ポイント。重み Z は平均0.38
- **1年2,000件以上の群**：自分の実績だけ0.23、クレジビリティ0.23ポイント（Z は平均0.98で、ほぼ自分の実績）
- **推定した k**：中央値223件（本当の値は222件）。本当の k を使った場合との誤差の差は0.01ポイント未満
- **群どうしの差を変えると**：差がない（CV 0）と全体の平均だけが最も良く、クレジビリティもほぼ同じ（0.02と0.03ポイント）。差が大きい（CV 0.6）と自分の実績だけ1.22、全体の平均だけ3.00、クレジビリティ1.03ポイント
- **翌年の実際の事故率との誤差**は、翌年の偶然の揺れが加わるので差が縮む（自分の実績だけ2.44、クレジビリティ2.26ポイント）
- 例の1回：k = 314件（3年分の件数で数える）。1年100件の群の Z は0.49、1,000件の群は0.91

## 前提
- 群は300。1年あたりの契約件数は20〜5,000件（対数で一様）で、年ごとに±10%動く
- 本当の事故率は、平均5%・変動係数 CV のガンマ分布。年が変わっても同じ（傾向や季節はない）
- 事故件数はポアソン分布。大きな事故や1件の金額は扱わず、件数の率だけを扱う

## 注意（言えないこと）
- 架空のデータ。実際の保険会社の契約群ではない
- 結果は、本当の事故率が年で変わらない、群が同じ分布から来ている、という前提で決まる。群の事故率に傾向があるときや、特定の群だけ別の性質を持つときは、そのまま当てはまらない
- 縮める推定の記事（F19・F61）と同じ考え方を、保険の契約群と件数の重み（Bühlmann–Straub）で試したもの
- 料率や保険料の決め方、引受の判断の助言ではない
