# 事前の計画（結果を見る前に決めたこと）

F01 の差の差（bite の高い県 vs 低い県、2016年以降）を、前提の確かめまでやり直す。新しく、改定の上げ幅が「その年の全国の中央値より大きかった県」を処置とするずらし型（staggered）の設計も足す。

## 設計A：bite の差の差（同じ時期に始まる）
- 処置群：2015年の bite（最低賃金÷短時間労働者の平均時給）が中央値より高い23県。比較群：残り24県
- 期間：2008〜2019年（コロナ前）。処置後：2016年以降
- 主の指標：就業率（%pt）。副：完全失業率
- 主の推定：就業率 = 県効果 + 年効果 + δ×（処置群×2016年以降）。標準誤差は県でクラスター
- 確かめること（この順番で、全部出す）
  1. 効いているか（first stage）：短時間労働者の平均時給（log）でも同じ差の差。処置群の時給が速く上がっていなければ、設計の前提が弱い
  2. 事前トレンド：イベントスタディ（基準2015年）の2008〜14年の係数の同時検定
  3. 事前トレンド検定の力：処置前から直線で開いていくずれがあったとき、検定が見つける確率（Roth 2022 の考え方）。50%・80%で見つかる傾きと、その傾きが処置後に生む偏り
  4. 平行トレンドが崩れたときの感度（Rambachan–Roth の考え方を簡略化して自作）
     - 相対的な大きさ：処置後の1年あたりのずれが、処置前の1年あたりの最大のずれの M̄ 倍まで許すとき、結論（0を含むか）が変わる M̄
     - 直線の延長：処置前のずれの傾きをそのまま延ばしたときの推定値と区間
  5. プラセボ：開始を2012年とみなす（2008〜15年）、効かないはずの指標（15歳以上人口の log）
  6. 少ないクラスターでの推論：wild cluster bootstrap（帰無仮説で制約、Rademacher と Webb の6点、9,999回）
  7. 最小検出効果：2.8×標準誤差（両側5%・検出力80%）
- 判定：「雇用が減った」と言うのは、主の推定の95%区間の上限が0未満で、かつ 2・5 で問題がないときだけ

## 設計B：上げ幅の大きい県（ずれて始まる）
- 処置：2016年度以降で初めて、改定の上げ幅（円）がその年度の47県の中央値より5円以上大きかった年度。改定は10月なので、暦年では翌年から処置後とする
- 期間：2015〜2025年（年効果で全国共通のコロナの動きを除く）
- 推定を並べる：TWFE（処置ダミー）、Callaway–Sant'Anna 型（比較＝期間内に一度も処置されない県、および まだ処置されていない県）、Sun–Abraham 型（比較＝一度も処置されない県）
- TWFE の中身：Goodman-Bacon の分解（2×2 の比較とその重み）、de Chaisemartin–D'Haultfœuille の重み（負の重みの数）
- 推論：県の再標本化（999回）と wild cluster bootstrap
- 判定：処置群の県が少ない場合は、推定値より「見分けられる最小の差」を先に書く

## やらないこと
- 最低賃金をどう決めるべきかの意見は書かない
- 県を悪い順に並べない
- 結果を見てから処置群・期間・指標を変えない（変えた場合は「計画からの変更」に書く）
