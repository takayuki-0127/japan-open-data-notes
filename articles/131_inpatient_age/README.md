### inpatient-age-japan

厚生労働省「患者調査」の年次推移表（1955〜2023年）を使い、**入院患者の平均年齢がどこまで上がったか**を、人口の高齢化と年齢別の受療率に分けて見るリポジトリです。

#### 問い / 手法 / スクリプト

| 問い | 手法 | スクリプト |
|---|---|---|
| 入院患者の平均年齢・65歳以上/75歳以上の割合はどう変わったか。人口の高齢化と比べると？ | 性・年齢階級別の推計患者数から年齢の加重平均（階級の中央値）。人口は「推計患者数÷受療率」で逆算。1999年と2023年の年齢別受療率を入れ替えた比較 | `src/a131_inpatient_age.py` |

#### 主な結果

- 入院患者の平均年齢は **36.4歳（1960年）→72.9歳（2023年）**。外来患者は30.3歳→58.5歳、人口（逆算）は29.2歳→48.3歳。
- 入院患者に占める65歳以上は6.0%→**75.5%**、75歳以上は1.2%→**57.3%**（人口では65歳以上29.1%、75歳以上16.1%）。
- 入院患者数（推計）は1990年の150万人が最多で、2023年は117.5万人。
- 年齢別の入院受療率（人口10万対）は、1999→2023年にどの年齢でもほぼ半分（75〜79歳 4,093→2,033、90歳以上 12,399→6,275）。
- 1999年の年齢別受療率のままなら、2023年の入院患者は234万人（実際は117.5万人）。逆に2023年の受療率で1999年の人口なら75万人。

#### データ

- `data/raw.zip`：患者調査（令和5年）全国編 第2表「推計患者数の年次推移，入院－外来×性・年齢階級別」（4ファイル）、第4表「受療率（人口10万対）の年次推移，入院－外来×性・年齢階級別」（4ファイル）。CSV（Shift_JIS）。e-Stat 政府統計コード 00450022（https://www.e-stat.go.jp/stat-search/files?toukei=00450022）
- `data/patients_by_age.csv`：上を縦長に整えたもの（年・入院/外来・年齢階級・推計患者数（千人）・受療率）
- `results/`：年ごとの平均年齢と割合、1999年と2023年の年齢別受療率、受療率を入れ替えた比較

#### 注意

- 平均年齢は年齢階級の中央値で計算した近似です。最上位の階級（1960〜65年は75歳以上、1970〜83年は80歳以上、1984〜96年は85歳以上、1999年以降は90歳以上）は82〜92.5歳と仮定しており、階級の切り方が変わった年に小さな段差があります。
- 1983年以前は7月、1984年以降は10月の調査です。2011年は宮城県の一部と福島県を除きます。2002年から、分娩後の母親に伴って入院している正常な新生児を含みません。
- 人口は推計患者数÷受療率で逆算したもので、受療率が四捨五入されているため少しずれます。
- 入院が減った理由（在院日数の短縮、病床の削減、介護施設への移行、外来・在宅医療の広がりなど）は、このデータでは分けられません。
