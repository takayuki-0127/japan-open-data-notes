# 893 作業時間の記録を15分単位で切ると、何%消えるのか？（副業の数字）

作業時間を記録するとき、「15分単位で切り捨て」のように丸めることがあります。まとまった作業なら、1回で失うのは15分未満です。けれども、連絡や確認のような短いやり取りは、1回が15分に届かず、切り捨てると丸ごと0分になります。**ここでは、作成者が乱数で作った架空の副業の人1人の作業の記録（短いやり取りとまとまった作業の回数・長さを作成者が置いたもの）で、1回ごとの切り捨て・四捨五入・切り上げ、1日の合計の切り捨ての4つの丸め方で、記録の合計が本当の時間から何%ずれるかを数えました。**

やり取りや修正の時間を入れると案件の時給がどれだけ下がるかは関連する記事 885、実働と拘束のどちらで割るかで時給がどう変わるかは 886、見積もりと実際の作業時間の外れの数え方は 890 で扱っています。この記事は、時間の記録の丸め方だけで、記録の合計がどれだけずれるかに絞ります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A893 | 作業時間を15分単位で丸めて記録すると、本当の時間の何%が消える（または増える）か。丸め方（1回ごと／1日の合計、切り捨て／四捨五入／切り上げ）でどれだけ違うか。短いやり取りの多さや記録の単位で変わるか | 架空の副業の人1人の1か月（作業する日20日）。1日の短いやり取り（連絡・確認）の回数はポアソン分布（平均6回）、1回の長さは対数正規分布（中央値5分・対数の標準偏差0.6）。1日のまとまった作業の回数はポアソン分布（平均3回）、1回の長さは対数正規分布（中央値45分・対数の標準偏差0.6）。記録の単位は15分。丸め方は、①1回ごとに切り捨て、②1回ごとに四捨五入（7.5分以上は15分）、③1回ごとに切り上げ、④1日の合計を切り捨ての4つ。例の1か月で種類ごとに数え、1か月を1,000回作り直して幅を数えた。確かめとして、やり取りの回数（0・3・12回）、記録の単位（5・10・30分）、やり取りの長さ（中央値3・10分）、作業の長さ（中央値20・90分）、作業の回数（1.5・6回）を1つずつ変え、各300か月で数えた。あわせて「1回ごとの切り捨てで1回あたり単位の半分（7.5分）を失う」とした目安の式（回数×7.5分÷本当の時間）と比べた。seed 893 | `src/a893_timelog_rounding.py` |

## 主な結果

### 例の1か月（175回・本当の時間57.54時間）
| 丸め方 | 記録の合計 | 本当の時間からのずれ |
|---|---|---|
| 本当の時間 | 57.54時間 | |
| 1回ごとに切り捨て | 40.25時間 | **−30.1%** |
| 1回ごとに四捨五入 | 53.75時間 | −6.6% |
| 1回ごとに切り上げ | 84.00時間 | **+46.0%** |
| 1日の合計を切り捨て | 54.50時間 | −5.3% |

| 種類 | 回数 | 15分未満の回 | 本当の時間 | 1回ごとに切り捨て | 四捨五入 | 切り上げ |
|---|---|---|---|---|---|---|
| 短いやり取り | 128回 | 96.1% | 12.79時間 | **−90.2%**（1.25時間） | −37.4% | +160.1% |
| まとまった作業 | 47回 | 2.1% | 44.75時間 | −12.9%（39.00時間） | +2.2% | +13.4% |

- 1回ごとに切り捨てると、17.29時間が記録から消えた。その66.7%は短いやり取りの分だった。やり取りは96.1%が15分未満で、記録には1.25時間しか残らなかった
- 同じ仕事の量を記録の時間で割ると、時間あたりの数字は43.0%大きく出る（57.54÷40.25）。記録の時間が短いほど、時間あたりの数字はよく見える
- 1日の合計を切り捨てると、失うのは1日あたり15分未満なので、ずれは−5.3%にとどまった

### 1,000か月で
| 丸め方 | ずれの平均 | 10〜90%の範囲 |
|---|---|---|
| 1回ごとに切り捨て | **−28.2%** | −32.1〜−24.5% |
| 1回ごとに四捨五入 | −6.7% | −9.1〜−4.4% |
| 1回ごとに切り上げ | +40.9% | +35.0〜+47.5% |
| 1日の合計を切り捨て | −3.9% | −4.8〜−3.0% |

- 四捨五入でも、ずれは0にならず−6.7%だった。7.5分未満のやり取りが多いと、0分に落ちる分が15分に上がる分より多くなるため
- 1回ごとの切り捨てと切り上げでは、同じ1か月の記録の合計が、本当の時間の約0.7倍から約1.4倍まで変わった

### 確かめ：置き方を1つずつ変えると（各300か月の平均）
| 変えたもの | 値 | 1回ごとに切り捨て | 1回ごとに四捨五入 | 1回ごとに切り上げ | 1日の合計を切り捨て | 目安の式（回数×単位の半分） |
|---|---|---|---|---|---|---|
| やり取りの回数（1日） | 0回 | −13.9% | −0.0% | +14.0% | −4.4% | −13.9% |
| | 3回 | −21.9% | −3.7% | +28.9% | −4.2% | −25.4% |
| | **6回（基本）** | **−28.4%** | −6.6% | +41.0% | −3.9% | −34.7% |
| | 12回 | −38.4% | −11.3% | +60.0% | −3.3% | −49.2% |
| 記録の単位 | 5分 | −11.9% | +0.3% | +11.1% | −1.3% | −11.5% |
| | 10分 | −21.7% | −1.9% | +23.8% | −2.6% | −22.8% |
| | 30分 | −41.9% | −14.8% | +96.7% | −7.8% | −69.3% |
| やり取りの長さ（中央値） | 3分 | −24.3% | −9.0% | +50.8% | −4.2% | −37.5% |
| | 10分 | −29.3% | −0.5% | +28.8% | −3.2% | −29.1% |
| 作業の長さ（中央値） | 20分 | −52.2% | −11.2% | +73.9% | −6.9% | −63.1% |
| | 90分 | −15.8% | −3.8% | +22.9% | −2.2% | −19.4% |
| 作業の回数（1日） | 1.5回 | −38.4% | −11.4% | +60.4% | −6.7% | −49.4% |
| | 6回 | −21.7% | −3.6% | +28.5% | −2.1% | −25.1% |

- **1回ごとの切り捨てで消える割合は、置き方で−11.9〜−52.2%と大きく動いた。けれども、どの置き方でも、1日の合計を切り捨てたずれ（−1.3〜−7.8%）よりずっと大きかった**
- 短いやり取りがないとき（0回）、切り捨てのずれ（−13.9%）は目安の式（回数×7.5分÷本当の時間）とそろった。まとまった作業だけなら、結果は式どおりの値
- 短いやり取りが多いほど、目安の式は消える分を大きく見積もりすぎた（12回で式−49.2%、実際−38.4%）。15分に届かない回は、失うのが7.5分ではなく、その回の長さ（中央値5分）だけだからと考えられる
- 基本の置き方は、変えたものごとに乱数を変えて数え直したので、1回ごとの切り捨ては−28.0〜−28.4%と、1,000か月の−28.2%から少し動く（表には「やり取りの回数」で数えた値を載せた）

## 注意（言えないこと）
- 架空のデータです。やり取りと作業の回数・長さ、記録の単位は作成者が置いたもので、結果はこれで決まります。1回ごとの切り捨てで消える割合は、置き方で−11.9〜−52.2%と動きました。実際の人の作業の記録を表すものではありません
- 記録は1回ごとに、始めと終わりを正しく測れていると置きました。記録し忘れ、複数の作業を同時に進める場合、やり取りを1回にまとめて記録する場合は入れていません
- 「どの丸め方にすべきか」「時間あたりの単価をどう決めるか」は言えません。この記事は、丸め方で記録の合計がどれだけ変わるかを数えただけです
- 取引先との時間の数え方の決まり、手数料・料金・税・会計については何も言えません
