# 354 地域を比べた記事で、順位の表はどれだけ載せていたか（④ 振り返り R109）

note に下書きした記事の原稿（手元の md）と GitHub の README で、地域を比べた記事を数え、順位の表・順位の言葉・地域の名前つきの「高い／低い」の文がどれだけあるかを数えた。個別の地域の名前は出さず、件数だけを出す

## 問い

- 都道府県や市区町村を比べた記事は何本あり、順位の表をどれだけ載せていたか
- 「低い側」の地域を名前で書いた文は、どれくらいあるか
- 「地域の悪い順位づけをしない」という決まりに合わない書き方は、何件あるか

## 手法

| 手順 | 中身 |
|---|---|
| 地域の単位（`src/a354_extract.py`） | 原稿614本。本文に都道府県の名前が5つ以上あるか「都道府県」などの言葉が2回以上なら都道府県、「市区町村」「市町村」が2回以上なら市区町村（両方なら市区町村） |
| 順位の書き方 | 順位の言葉（順位・ランキング・○位・上位・下位・トップ・ワースト・最下位）、題名の順位の言葉、地域の名前と「最も高い・いちばん多い・1位・上位」などが同じ文にある文、地域の名前と「最も低い・いちばん少ない・最下位・下位・低いのは」などが同じ文にある文、図の説明の「順位・高い順・並べた」、順位の列がある表 |
| 目で読む | 「低い・少ない」の言葉と地域の名前が同じ文にある90文をすべて読み、4つに分けた（`data/manual_check.csv`。記事の番号と分類だけ）。「高い・多い」の側は155文から50文を引いて読んだ |
| 4つの分類 | 評価を含む指標で名指し（所得・進学率・貸出冊数・求人倍率・健診の結果など、低い側や悪い側と読める位置に地域の名前を書いた文）／どちらとも言える（指標の良し悪しが読む人で分かれる、文だけでは指標が分からない）／中立の指標（物価・気温・面積・受療率・費用など）／名指しなし・順位づけでない（「いちばん低い県」と名前を出さずに書いた文、分位の説明など） |
| README の表 | README 542本の表で、1列目が順位（1, 2, 3…）で地域の名前がある行を数えた |

- 原稿にも README にも、順位の列がある表（地域を5行以上並べたもの）は0本。README の表で順位つきの行があるのは5本で、どれも1〜4行
- 順位の言葉は、地域を比べた記事の48%にある。ただし多くは「上位10%の市区町村」「上位3県で88%」のような、まとまりや集中の書き方
- 「評価を含む指標で名指し」は14文・9本。9本はすべて通常の記事（000–099 が6本、100–226 が3本）で、看板記事と1000本計画では0本
- 看板記事では、低い側は「いちばん低い県」のように名前を出さずに書いた文が多い（名指しなし25文のうち24文が看板記事）
- 「高い・多い」の側は50文を読み、評価を含む指標で悪い側を名指しした文は0文、どちらとも言えるが1文

## 確かめたこと

- 最初の版は「最低賃金」「最小二乗」の「最低」「最小」を拾っていた。これを外し、「低いのは」「少ないのは」の形を足して、90文にした
- 90文は全部読んだ。分類は1人で1回読んだもの
- `src/a354.py` を空のフォルダで流し直し、results と figures が一致することを確かめた

## 動かし方

```
python src/a354_extract.py <md のフォルダ> <japan-open-data-notes のルート>   # 手元の原稿があるときだけ。data/ を作る
python src/a354.py                                                            # 集計と図
```

原稿（md）はリポジトリに入れていない。`data/` には、記事ごとの数と、読んだ文の分類（記事の番号と分類だけ）を置いた。地域の名前と文は置いていない

## 言えないこと

- 図の中身は見ていない。47都道府県を高い順に並べた棒グラフは、図の説明に「順」「並べた」と書いていなければ数えていない
- GitHub に置いた結果のファイル（csv）には、地域ごとの値がそのまま入っている。これは順位の表としては数えていない
- 「評価を含む指標」かどうかは、読んだ人の判断。指標の良し悪しは立場で変わるので、「どちらとも言える」を別にした
- 機械が拾うのは「最も低い」「下位」「低いのは」などの決まった言い方だけ。「〜にとどまる」「〜に届かない」のような言い方で低い側の地域を書いた文は拾えていない
- 地域の単位は言葉の数で決めた。国や地方（関東・九州など）、都市圏、港、駅を比べた記事は「全国・その他」に入る
- 名指しがあった9本は、直す候補として番号を控えた。この記事では、どの記事か・どの地域かは書かない
