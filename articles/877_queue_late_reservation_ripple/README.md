# 877 予約の時刻どおりに来ない人が1割いると、後の人はどれだけ待つのか？（待ち時間と混雑）

予約制の店では、遅れて来る人が少しいるだけで、その日の後ろの人まで待たされることがあります。どれだけ待たされるかは、遅れた人をどう扱うか（来るまで待つか、来た順に回すか）でも変わります。**ここでは、作成者が乱数で作った架空の店の予約制カウンター（担当1人・15分ごとに1人の予約、1人の手続き時間と遅れ方を作成者が置いたもの）で、同じ日の同じ手続き時間・同じ着く時刻のまま「1割が遅れて来る」と「だれも遅れない」を比べ、時刻どおりに来た人の待ちがどれだけ増えるかを、5つの回し方で数えました。**

利用の割合が8割を超えると待ちが急に伸びる話は関連する記事 874、手続き時間のばらつきの話は 880、開店直後の行列の話は 883 で扱っています。この記事は「予約に遅れて来る人が、ほかの人の待ちをどれだけ増やすか」に絞ります。

## 主な結果

### 時刻どおりに来た人の待ち（遅れる人1割・平均12分遅れ、2,000日）
| 回し方 | だれも遅れない | 1割が遅れる | 増えた分 | 10分より長く待った人 | 遅れた人1人あたり、ほかの人の待ちの合計の増え |
|---|---|---|---|---|---|
| 来た順（遅れた人は着いた時点で並ぶ） | 2.09分 | **3.28分** | +1.19分 | 6.4%→11.5% | 10.7分 |
| 5分まで待つ | 2.09分 | 3.28分 | +1.19分 | 6.4%→11.5% | 10.7分 |
| 10分まで待つ | 2.09分 | 3.29分 | +1.20分 | 6.4%→11.5% | 10.8分 |
| 予約順を必ず守る（来るまで待つ） | 2.09分 | **4.87分** | **+2.79分** | 6.4%→17.9% | **25.1分** |
| 来た順＋早く着いた人は前倒しで始める | 1.45分 | 2.73分 | +1.28分 | 4.4%→9.6% | 11.5分 |

- 1割が遅れると、来た順に回しても、時刻どおりの人の平均の待ちは2.09分から3.28分に増えた。遅れた人1人につき、ほかの人の待ちが合わせて10.7分増えた計算になる
- 遅れた人を来るまで待つ回し方では、4.87分（+2.79分）に増え、遅れた人1人あたり25.1分だった
- 5分・10分まで待つ回し方は、来た順とほぼ同じだった。置いた遅れ方では、5分以内の遅れは遅れた人の19.9%、10分以内は54.1%（分布からの計算の値）。10分まで待っても増えなかったのは、遅れた人の枠の時刻に、担当がまだ前の人の手続き中であることが多いためと考えている（推測）
- 来た順でも待ちが増えたのは、遅れた人の枠で担当の手の空く時間ができ、遅れた人の手続きがその後ろの枠に押し出されるためと考えている（仕組みからの説明。手が空いた時間そのものは数えていない）。これと合うように、終わりの時刻（18:00）を過ぎた分の平均は、来た順で2.16分→4.22分、必ず守る回し方で5.39分だった
- 遅れた人自身の待ち（着いてから）は、来た順で平均2.73分、必ず守る回し方で1.81分だった

### 確かめ：遅れの長さ×手続き時間の平均×ばらつき（遅れる人1割、27通り×各300日）
- 時刻どおりの人の待ちの増え方は、来た順で+0.12〜+3.10分、予約順を必ず守る回し方で+0.12〜+11.57分と、置き方で大きく動いた
- 遅れの平均が5分なら、どの回し方もほぼ同じ（来た順+0.12〜+0.72分、必ず守る+0.12〜+0.74分）。遅れの平均が20分だと、必ず守る回し方は+4.39〜+11.57分で、来た順（+0.58〜+3.10分）との差が開いた
- 27通りすべてで、必ず守る回し方の増え方は来た順と同じか大きかった（1.0〜9.49倍）
- 手続き時間の平均が枠（15分）に近いほど、増え方は大きかった（来た順で、平均10分なら+0.12〜+0.77分、13.5分なら+0.48〜+3.10分）
- 遅れた人1人あたりの、ほかの人の待ちの合計の増えは、来た順で1.0〜28.6分、必ず守る回し方で1.1〜106.7分だった

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の9ファイルがバイト単位で一致した（cmp、約3秒）
- 「遅れる人がいると、時刻どおりの人の待ちが増える」「来るまで待つ回し方は、来た順より増え方が同じか大きい」は、確かめた27通りと遅れる人の割合4通りのすべてで同じだった
- 増え方の大きさは、置いた遅れの長さと、手続き時間の平均（枠の15分にどれだけ近いか）で大きく動いた。「+1.19分」「+2.79分」は基本の置き方での値
- 基本の置き方（遅れる人1割）の来た順の待ちは、本表（2,000日）で3.28分、遅れる人の割合の確かめ（別の乱数で500日）で3.63分、27通りの確かめ（300日）で3.20分だった。だれも遅れない場合の値も2.06〜2.22分と日の引き方で動くので、増えた分（+1.14〜+1.41分）で読む

## データ
- `data/one_day.csv`：架空の1日32枠。slot・appt_min（予約の時刻、10:00からの分）・service_min（手続き時間）・arrival_min（着いた時刻）・is_late（遅れた人なら1）・arrival_if_none_late（だれも遅れなかった場合の着いた時刻）・start_g0／start_g5／start_g10／start_ginf／start_early（5つの回し方での手続きの始まり。g0＝来た順、g5・g10＝5分・10分まで待つ、ginf＝予約順を必ず守る、early＝前倒しあり）

## 注意（言えないこと）
- 架空のデータです。遅れる人の割合、遅れの長さ、手続き時間の分布、時刻どおりの人の着き方は作成者が置いたもので、結果はこれで決まります。実在の店の予約を測ったものではありません
- 来ない人（予約を取り消さずに来ない人）は入れていません。来ない人がいると、その枠は担当の手が空くので、遅れる人とは違う動き方をするはずです（推測）
- 遅れる人は毎回でたらめに決まると置きました。同じ人が繰り返し遅れる、雨の日に遅れが増える、といった偏りは入れていません
- 担当は1人で、手続きの途中で別の人を受けることはないと置きました
- 回し方の公平さ（遅れた人を後ろに回すことへの不満）は、ここでは測っていません。「来た順」がよいかどうかは、待ち時間だけでは決まりません
