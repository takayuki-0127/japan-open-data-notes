# 1249 新しい本を出したあと、シリーズの前の本の売れ方がどれだけ押し上げられたかは分かるのか？（電子書籍）

シリーズの2巻を出すと、1巻も売れ始めることがあります。その押し上げを「2巻の発売の前の30日と後の30日で、1巻の冊数を比べる」読み方で数えると、1巻がもともとゆっくり売れ方を減らしている分は押し上げを小さく見せ、2巻の発売が分野全体の売れる時期（季節の山）と重なった分は大きく見せます。**ここでは、作成者が置いた架空の電子書籍のシリーズ（1巻のふだんの売れ方の減り方、2巻による押し上げの大きさ、季節の山、毎日の揺れを作成者が決め、乱数で毎日の冊数を作ったもの）で、①前の30日と比べる、②前の91日の減り方を延ばして比べる、③別のシリーズの本の前後の変化で割り引く、の3つの読み方が、本当の押し上げ（作成者だけが分かる冊数）をどれだけ当てるかを数えました。押し上げを0と置いたときに押し上げがあるように見える割合も数え、1巻の減り方・季節の山・売れ方の大きさを変えた27通りで確かめました。**

例の本と数字はすべて架空のもので、実在の本や販売の数字を表すものではありません。値段の付け方や広告の出し方、売上の見込みを勧める記事ではありません。

関連する記事：919「改善の前後で不良率を比べるとき、何か月見ればよいのか？」は、前後で比べるときに月ごとの振れで見分けにくくなることを、何か月見るかの側から扱っています。1072「調整の前後でキャラクターの勝率を比べると、使う人の入れかわりが何をまぜるのか？」は、前後の比べに使う人の入れかわりがまざることを扱っています。1027「前年の同じ日の予約と比べると、何を読み違えるのか？」は、比べる相手の日のずれを扱っています。377「季節のあるデータで「施策の前後」を比べると、効果0でもどれだけ差が出るのか」は、季節の上下だけで前後に差が出ることを月ごとの販売額で扱っています。1246「1冊目から2冊目へ進んだ割合は、出してからの日数をそろえないとどう見えるのか？」は、同じシリーズの2冊の売れた冊数から、1冊目から2冊目へ進んだ割合を読むときのずれを扱っています（2冊目を出したことで1冊目が売れる分は入れていません）。1255「表紙を変えた前後の売れ方を比べると、発売からの日数で自然に減る分はどうまざるのか？」は、同じ本の表紙を変えた前後で、自然に減る分と変える日の選び方がまざることを扱っています。この記事は、新しい本を出したときの前の本への押し上げを、前の本がもともと減っていく分・季節の山の分と、別のシリーズの本で割り引く読み方の当たり外れに絞ります。

## 主な結果

### 押し上げありの場面（4,000回、`results/scenarios.csv`）
| 場面 | 読み方 | 見積もりの平均 | 見積もりの10〜90% | 本当の押し上げの平均 | 本当の±25%に入った割合 |
|---|---|---|---|---|---|
| 自然な減りだけ | ①前の30日と比べる | **18.2冊** | −1.0〜38.0冊 | 29.1冊 | 30.75% |
| | ②前の91日の減り方を延ばす | 28.1冊 | 6.1〜49.6冊 | 29.1冊 | 35.73% |
| | ③別のシリーズの本の前後の変化で割り引く | 28.6冊 | 4.8〜51.1冊 | 29.1冊 | 33.0% |
| 季節の山（0〜20日目に+30%） | ①前の30日と比べる | **44.3冊** | 23.0〜66.0冊 | 37.1冊 | 42.65% |
| | ②前の91日の減り方を延ばす | **54.6冊** | 30.8〜77.9冊 | 37.1冊 | 24.32% |
| | ③別のシリーズの本の前後の変化で割り引く | 36.1冊 | 7.5〜63.5冊 | 37.1冊 | 34.05% |

- **自然な減りだけの場面で、①は本当の押し上げより平均で37.33%小さく出た**。押し上げがなくても後の30日は前の30日より10.835冊少ない（式どおり）ので、その分が押し上げから引かれる
- 季節の山が重なると、①は平均44.3冊と、本当（37.1冊。押し上げにも季節の山がかかる）より大きく出た。季節の山がふだんの分に足す冊数は18.164冊（式どおり）で、①ではそこから自然な減りの分が引かれた。②は自然な減りは延ばせても季節の山は延ばせないので、54.6冊とさらに大きく出た
- ③は2つの場面とも平均では本当に近かった（−1.63%・−2.66%）。ただし、1回ごとの見積もりが本当の±25%に入ったのは33.0%・34.05%で、3つの読み方のどれでも1回の見積もりの幅は広かった
- 例の1回（`data/daily_example.csv`）では、本当の押し上げ27冊に対し、①1冊・②6.635冊・③13.121冊だった

### 確かめ：27通り（各2,000回、`results/grid.csv`）
- 見積もりの平均÷本当の押し上げの平均は、**①で0.1709〜1.5964倍**、②で0.8804〜1.7152倍、③で0.4608〜1.167倍だった
- ①は季節の山なしの9通りすべてで小さく出た（0.1709〜0.8285倍）。1巻の減り方が速い（120日で 1/e）ほど小さく、季節の山が+20%で減り方250日の3通りでは1.0353〜1.039倍と、減りと季節の山が打ち消し合ってたまたま近くなった
- ②は季節の山なしでは0.8804〜1.0099倍、+50%では1.6297〜1.7152倍
- ③は、1巻と別のシリーズの本の減り方が同じ（250日）9通りで0.8798〜1.0058倍、1巻のほうが速く減る（120日）と0.4608〜0.632倍、遅く減る（500日）と1.0554〜1.167倍だった。割り引く相手の本の減り方が違うと、その差がそのまま残った。ふだん1日1冊の本では、減り方が同じでも0.8798〜0.9397倍と少し小さく出た（理由は確かめていない）
- 本当の±25%に入った割合は、ふだん1日1冊の本で①0.164〜0.3005・②0.16〜0.2195・③0.174〜0.227、1日10冊の本で③0.3175〜0.6065だった
- 押し上げ0で、本当の押し上げの半分以上に見えた割合は、①0〜0.648・②0.056〜0.796・③0.0015〜0.3715だった

## 注意（言えないこと）
- 架空のデータです。1巻の減り方、押し上げの大きさと続き方、季節の山、別のシリーズの本の減り方は作成者が置いたもので、①・②のずれの大きさはこれでほぼ決まります（①の自然な減りの分、季節の山の分は式どおり）
- ③が平均で当たるのは、別のシリーズの本が1巻と同じ減り方・同じ揺れ・同じ季節の山を受けると置いたためです。そう置かないと（27通りの減り方の違い）ずれました
- 2巻の発売が別のシリーズの本の売れ方を変える（読者が両方を見る）ことは置いていません
- 「分かるのか」には、平均のずれと1回ごとの幅の2つがあります。この置き方では、1回の30日の見積もりが本当の±25%に入る割合は、27通りのどの読み方でも最大0.66でした
- 実在の販売サイトの集計を表すものではありません。値段・広告・売上の見込みの助言はしません
