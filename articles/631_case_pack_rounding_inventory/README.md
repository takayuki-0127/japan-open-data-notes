# 631 発注をケース単位に切り上げると、在庫は平均で何日分多く持つことになるのか（実務の型）

仕入れ先がケース単位（6個入り・24個入りなど）でしか受けない場合、必要な数をケースに切り上げて発注します。切り上げた分は在庫として残ります。**ここでは、架空の店の1品目（1日平均5・20・50個売れる）を、7日ごとに発注し2日後に届く決まりで2年分流し、発注の単位（ばら、6・12・24・48個入り、最低2ケース）ごとに平均在庫が何日分になるかを数えました。** 各20回。発注数の切り上げは SQL（DuckDB）でも出し、Python と一致することを確かめています。数字は置いた売れ方と発注の決まりで決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A631 | 発注の単位で平均在庫は何日分増えるか | 売れ数はポアソン、7日ごとの定期発注（次の品が届くまでの需要の95%点まで戻す）、リードタイム2日、730日×20回、seed 631 | `src/a631_case_pack.py` |
| SQL | 必要数をケースに切り上げ、最低ケース数を守る | DuckDB 版（1スレッドで実行）、T-SQL 版（未検証） | `src/02_case_round_duckdb.sql`・`src/01_case_round_tsql.sql` |

## 主な結果
- **ばらで発注したときの平均在庫**：1日平均5個で6.2日分、20個で5.1日分、50個で4.7日分
- **1日平均5個の品目**：6個入りで +0.5日分、12個入りで +1.1日分、24個入りで +2.3日分、**48個入りで +4.7日分**（10.9日分）
- **1日平均50個の品目**：48個入りでも +0.5日分
- **目安「切り上げで平均（入数−1）÷2 個多く持つ」**：シミュレーションの増え方とよく合った（5個/日・24入りで 2.30日分に対し 2.30日分、50個/日・48入りで 0.48日分に対し 0.47日分）
- **最低2ケースの決まり**：1日平均5個の品目で、24個入りなら +4.7日分（切り上げだけの2倍）、48個入りで +9.6日分（15.8日分）。売れ数の多い品目ではほとんど効かない
- 欠品率はどの場合も0.04%以下で、切り上げで減る分はわずか

## 注意（言えないこと）

- 賞味期限・置き場所・仕入れ値の割引は入れていない。どの単位で発注するのがよいかの助言ではない
- 売れ数の季節の波は入れていない
