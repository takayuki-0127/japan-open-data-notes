# 1157 一度しか使われないものが多いと、置き場所を大きくしても当たり率はどこで止まるのか？（キャッシュの当たり率）

よく使うデータを手元に置いておく置き場所（キャッシュ）は、同じデータが2回目以降に来たときにしか当たりません。その場かぎりで二度と来ないデータへの問い合わせは、置き場所をどれだけ大きくしても必ず外れます。くり返し使われるデータも、初めて来たときは外れます。そのため当たり率には、置き場所の大きさでは越えられない上限があります。**ここでは、作成者が置いた架空のアプリへの問い合わせ20万件（その場かぎりの新しいデータへの問い合わせの割合を0・20・40・60%に変え、残りは2万種類のくり返し使われるデータから引いたもの）で、置ける数を100種類から3万種類まで変えて当たり率を数え、無制限のときの上限と比べました。記録の中で「1回しか使われなかったもの」の割合を種類と件数の2つで数え、「2回目に来たものから置く」決まりとも比べました。その場かぎりの割合×偏り×数える長さの27通りでも確かめました。問い合わせはすべて作成者が置いた確率からの乱数で、実機の計測はしていません。**

関連する記事：同じ企画の 1150「置き場所の大きさを2倍にすると、当たり率はどれだけ上がるのか？」は、一度しか使われないデータを入れずに、置き場所を2倍にするごとの上がり方を扱っています。1152「よく使われるものへの偏りが大きいときと小さいときで、同じ大きさの置き場所の効き目はどれだけ違うのか？」は、偏りの小さい問い合わせが置き場所を占め、一度も当たらずに捨てられることを扱っています。1153「古く使われたものから捨てる決まりと、使われた回数の少ないものから捨てる決まりは、人気が移り変わるときにどちらが当たるのか？」は、人気が移り変わるときの捨て方を、1159「問い合わせの一部を抜き出して当たり率を見積もると、置き場所を小さくして試した値はどれだけずれるのか？」は、短い記録では初めて来たデータの外れが多く入り見積もりが低く出ることを扱っています。この記事は、その場かぎりの問い合わせがあるときに、置き場所を大きくしても越えられない上限に絞ります。

## 主な結果

### 置ける数と当たり率（いちばん長く使われていないものから捨てる、20万件、`results/by_size.csv`）
| 置ける数 | その場かぎり0% | 20% | 40%（基本） | 60% |
|---|---|---|---|---|
| 100種類 | 12.022% | 8.579% | 5.303% | 2.643% |
| 1,000種類 | 34.486% | 24.957% | 16.284% | 9.122% |
| 1万種類 | 77.496% | 53.922% | 35.553% | 20.277% |
| 3万種類 | 90.305% | 68.141% | **46.064%** | 26.962% |
| 無制限（上限） | 90.305% | 70.666% | **51.069%** | 32.09% |

- **その場かぎりの問い合わせが40%だと、置き場所を無制限にしても当たり率は51.069%で止まった**。20万件のうち、来た種類は97,861種類で、1 − 97,861÷200,000 の恒等式どおり（`results/used_once.csv`）
- 上限は、その場かぎりの分（実際の乱数では39.953%）と、くり返し使われるデータが初めて来た分（17,955種類、8.977%）を引いた値。くり返し使われるデータの種類（2万）より大きい3万種類を置けても、上限の90.2%（46.064%）までだった
- その場かぎり0%なら、3万種類で上限（90.305%）に届いた

### その場かぎりのデータが置き場所を占める（`results/crowding.csv`）
- 同じ置き場所で比べると、当たり率はその場かぎりの分（1−u倍）より大きく下がった。基本の40%・1万種類では、0%のときの当たり率77.496%の0.6倍は46.498%だが、実際は35.553%で、さらに10.945ポイント低かった
- その場かぎりのデータも、来るたびに置き場所に入り、一度も当たらないまま、くり返し使われるデータを追い出すため。この上乗せの下がり方は、20〜60%・100〜3万種類の18通りで1.039〜10.945ポイントだった

### 「1回しか使われなかったもの」は、数え方で大きく違う（`results/used_once.csv`）
| その場かぎりの割合 | 種類の数で数えた割合 | 問い合わせの数で数えた割合 |
|---|---|---|
| 0% | 9.38% | 0.91% |
| 20% | 72.32% | 21.21% |
| 40% | **85.55%** | **41.86%** |
| 60% | 91.94% | 62.44% |

- 基本の40%では、記録に出てきた種類の85.55%が1回しか使われていなかった。問い合わせの数で見ると41.86%で、その場かぎりの割合（40%）に、くり返し使われるデータのうち20万件の間に1回しか来なかったもの（3,812種類）が足された値
- 「種類の8割以上が1回きり」と「問い合わせの4割が1回きり」は、同じ記録の別の数え方で、当たり率の上限に効くのは問い合わせの数で数えたほう

### 「2回目に来たものから置く」決まりと比べると（基本の40%、`results/by_size.csv`）
| 置ける数 | すぐ置く | 2回目から置く |
|---|---|---|
| 100種類 | 5.303% | 8.066% |
| 3,000種類 | 24.39% | 31.598% |
| 1万種類 | 35.553% | 42.675% |
| 3万種類 | 46.064% | 43.998% |
| 無制限（上限） | 51.069% | 43.998% |

- 小さい置き場所では、2回目から置くほうが高かった。その場かぎりのデータが置き場所に入らないため
- そのかわり、くり返し使われるデータの2回目も外れになるので、上限は43.998%に下がった。3万種類では、すぐ置くほうが高くなった
- 27通りの確かめ（置ける数2,000種類）では、27通りすべてで2回目から置くほうが3.187〜6.802ポイント高かった

### 置き方を変えた27通り（`results/grid.csv`）
- 上限は、その場かぎり20%で50.692〜77.544%、40%で33.976〜57.595%、60%で19.348〜37.592%。偏りと数える長さで大きく動いた
- 数える長さを延ばすと、くり返し使われるデータの「初めて」の分が薄まり、上限は「1 − その場かぎりの割合」に近づいた。差は5万件で10.524〜29.308ポイント、20万件で6.019〜9.937ポイント、80万件で2.405〜2.58ポイント
- 置ける数2,000種類の当たり率は、数える長さではほとんど変わらなかった（たとえば40%・偏り0.8で21.032〜21.194%）。短い期間で測った上限は、長い期間の上限より低く出る

## 注意（言えないこと）
- 架空のデータです。その場かぎりの割合、偏り、データの種類の数は作成者が置いたもので、結果はこれで決まります。上限は数え方からの恒等式どおりで、新しく分かるのは、その値が数える長さで動くことと、置き場所の効き方がその場かぎりの分より大きく下がること
- 人気は時間で変わらないと置きました。人気が移り変わる場合や、その場かぎりのデータが時間でまとまって来る場合は入れていません
- データの大きさはすべて同じと置きました。「2回目から置く」決まりでは、一度見た種類の記録を無制限に持てると置いたので、記録に場所がかかる場合は入れていません
- 実在のソフトやサーバーの動きを表すものではありません。どの置き方を選ぶべきかの助言でも、費用の見込みでもありません
