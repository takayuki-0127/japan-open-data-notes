# 1269 処理を8つに分けて同時に動かしても8倍速くならないのは、分けられない部分がどれだけあるときか？（並列処理）

1つの処理を8つに分けて同時に動かしても、はじめの準備や最後のまとめのように分けられない部分は、8つで動かしても同じ時間がかかります。そのため、何倍速くなるかは分けられない部分の割合で頭打ちになります。この頭打ちは式で決まりますが、実際には「分けられない部分の割合」そのものが分からず、1つ・2つ・4つで動かして測った時間から見込むことになります。**ここでは、作成者が置いた架空のアプリの1回の処理（1つで動かすと600秒。分けられない部分の割合と、分けられる部分の中の小さな単位の時間のばらつきを作成者が置き、乱数で時間を作ったもの）で、①分けられない部分の割合ごとに8つで何倍になるか（式どおり）、②同じ処理の時間の内訳を1つで見るか8つで見るかで割合がどれだけ違って見えるか（式どおり）、③1つ・2つ・4つで3回ずつ測った時間から分けられない部分を見込み、8つで何倍になるかを見込んだとき、どれだけ外れるかを数えました。本当の割合・測るときの振れ・単位の時間のばらつきを変えた27通りでも確かめました。実機での計測はしていません。**

- 分けられない部分が5%でも、8つで5.926倍、64個に分けても15.422倍で、上限は20.0倍（1÷5%）だった

### ② 同じ処理の内訳を、1つで見るか8つで見るか（式どおり、`results/share_in_time.csv`）
| 1つで動かしたときの分けられない部分 | 8つで動かしたときの時間のうちの分けられない部分 | 16個で何倍か（本当） | 8つの内訳の割合を1つのときの割合と取りちがえて見込むと |
|---|---|---|---|
| 2% | 14.04% | 12.308倍 | 5.153倍 |
| 5% | **29.63%** | 9.143倍 | **2.939倍** |
| 10% | 47.06% | 6.4倍 | 1.985倍 |
| 14.29% | 57.14% | 5.091倍 | 1.672倍 |

- 1つで動かしたときに5%の分けられない部分は、8つで動かしたときの時間の内訳では29.63%を占めた。分けられる部分だけが8分の1に縮むため
- 8つの内訳の29.63%を、1つのときの割合として式に入れると、16個で2.939倍と見込んでしまう（本当は9.143倍）。8つの内訳から8つ→16個への伸びを数えるなら、8つの時間を1とした割合のまま使えば本当の1.543倍と一致した

### ③ 1つ・2つ・4つで3回ずつ測って見込む（基本：本当の分けられない部分5%・振れ3%・単位のばらつき0.5、2,000回、`results/a1269_main.json` の `base`）
| | 値 |
|---|---|
| 本当の5%を式に入れた8つの速さ | 5.926倍 |
| 本当の8つの速さ（単位のばらつきあり） | **4.971倍**（式より16.12%遅い） |
| 測った時間から見込んだ分けられない部分（中央値） | **9.11%**（10〜90%で4.61〜13.86%） |
| 見込んだ8つの速さ（中央値） | 4.884倍（10〜90%で4.06〜6.048倍） |
| 見込みの外れ（中央値） | −1.75%（10〜90%で−18.31〜+21.67%） |
| 外れが±10%以内だった回 | **47.05%** |

- 単位の時間にばらつきがあると、分けた組のうちいちばん遅い1つを待つ分だけ8つの速さは式より下がった（5.926倍→4.971倍）。測った時間から見込むと、この待ちの分も分けられない部分にまざり、見込んだ割合は本当の5%より大きい9.11%（中央値）になった
- 見込んだ割合で8つの速さを見込むと、中央値では本当の値に近かった（−1.75%）。けれども1回ごとには外れが大きく、±10%以内に入ったのは47.05%だった
- 分けられない部分がまったくない（0%）ときも、単位のばらつきが0.25・0.5・1.0なら、見込んだ割合は2.24%・4.75%・9.49%と出た（`results/variation_looks_serial.csv`）。本当の8つの速さはそれぞれ7.074倍・6.288倍・5.073倍だった
- 測る回数を増やすと、±10%以内は1回で32.2%、3回で47.05%、10回で76.3%だった（`results/by_reps.csv`）
- 測った割合9.11%を本当の分けられない部分と読んで、本当の部分を半分（5%→2.5%）に減らした場合、見込んだ伸びは1.1196倍、本当の伸びは1.1173倍で近かった。本当の2.5%を式に入れた6.809倍には、本当の速さ（5.554倍）は届かなかった

### 確かめ：27通り（各2,000回、`results/grid.csv`）
- 本当の8つの速さは3.605〜7.018倍で、式の値より0〜33.09%遅かった。単位のばらつきが0なら式どおり、0.5で4.112〜5.686倍、1.0で3.605〜4.697倍だった
- 見込んだ分けられない部分（中央値）は、単位のばらつき0で2.0〜10.0%（本当の値のとおり）、0.5で6.36〜14.21%、1.0で10.62〜17.97%と、ばらつきが大きいほど本当の値より大きく出た
- 見込みの外れの中央値は27通りすべてで−3.21〜+0.19%と小さかった。**±10%以内に入った回は26.4〜100%で、単位のばらつきと振れが大きいほど減った**（振れ1%で29.45〜100%、5%で26.8〜62.75%）
