# F368 PLAN（事前の計画）：失業率は低いが、「もっと働きたい人」を含めるとどう見えるか？

作成：2026-11-16 13:50（データを取得し、表の形を確かめたあと、年齢・男女別の比べや分解を集計する前に書いた）

## 問い
日本の失業率は2%台と低い水準です。ただ、働いていても「もっと長く働きたい」人（追加就労希望就業者）や、働きたいが今は仕事を探していない人（潜在労働力人口）は、失業率には入りません。総務省「労働力調査」は2018年から、これらを含めた「未活用労働指標」（LU1〜LU4）を公表しています。

- LU1 ＝ 失業者 ÷ 労働力人口（失業率に近い）
- LU2 ＝（失業者 ＋ 追加就労希望就業者）÷ 労働力人口
- LU3 ＝（失業者 ＋ 潜在労働力人口）÷（労働力人口 ＋ 潜在労働力人口）
- LU4 ＝（失業者 ＋ 追加就労希望就業者 ＋ 潜在労働力人口）÷（労働力人口 ＋ 潜在労働力人口）

知りたいこと：LU4 は LU1 の何倍か。その差は、男女・年齢でどう違い、何（追加就労希望か、潜在労働力か）でできているのか。2020年の景気の落ち込みのとき、どの指標が大きく動いたのか。

知りたい人：労働市場の統計を読む記者・研究者、人手不足の対策を考える企業や自治体、働き方の相談を受ける人。

既存の看板記事との違い：F354（失業率と求人倍率）は失業率だけを扱った。未活用労働指標を使った記事は既存にない（existing_F_titles.txt と jodn の README を「未活用」で検索）。

## データ
- 総務省「労働力調査」年報 詳細集計 全国・時系列表「年齢階級別未活用労働指標」（LU1〜LU4、補助指標1・2、男女別）。各年版に直近5年分（男女計・男・女）と、その年の年齢階級別（15〜24歳、25〜34歳、35〜44歳、45〜54歳、55〜64歳、65歳以上）がある。2019〜2025年版を使い、年ごとに最も新しい版の値を使う（2018〜2025年）。
- 長期時系列表 1-e-3「未活用労働指標１」（月次、2002年1月〜、季節調整値）。LU1 の長い動きの参考。

## 取得前に見たもの（開示）
- 表の形を確かめるときに、2025年版の2021〜2025年の男女計・男・女の LU1〜LU4 と補助指標、2025年の年齢階級別の値（例：男女計 LU1 2.8%、LU4 6.1%、女の LU4 7.4%、男 5.0%）、長期時系列の2002年1〜4月の値を目にした。2018〜2020年の値、年齢別の推移、差の分解は計算していない。

## 指標の分け方（事前に決める）
- 追加就労希望の分 ≒ LU2 − LU1（労働力人口に対する割合）。
- 潜在労働力の分 ≒ LU3 − LU1（分母に潜在労働力を足すので近似）。
- 交わり：LU4 − LU1 ≒ 追加就労希望の分 ＋ 潜在労働力の分（近似の誤差も表に出す）。

## 仮説と「外れ」の基準
- H1：2018〜2025年のどの年も、LU4 は LU1 の2倍以上。2倍未満の年があれば外れ。
- H2：女の LU4 − LU1 は、どの年も男より大きい。どれかの年で男以上なら外れ。
- H3：2019→2020年（景気の落ち込み）の上がり幅は、LU1 より LU2 − LU1（追加就労希望の分）のほうが大きい。小さければ外れ。
- H4：2025年の年齢別で、LU4 − LU1 が最も大きいのは15〜24歳か65歳以上（若い層・高齢層）。35〜54歳のどれかが最も大きければ外れ。

## 手法
- 年ごと・男女・年齢の LU1〜LU4 を並べ、LU4 ÷ LU1、LU4 − LU1 と、その内訳（追加就労希望の分、潜在労働力の分）を出す。

## 頑健性（3つ以上）
1. 倍率ではなく差（ポイント）で H1 を見る。
2. 年齢別の比べ（H4）を2019年と2022年でも行う。
3. 年の値ではなく、2つの版で重なる年（例：2021年）の値が版で違うかを確かめる（人口の基準の切り替え）。
4. LU1 を長期時系列の月次（季節調整値）の年平均と比べ、年報の値と合うか確かめる。

## 問い直し（予定）
結果を見てから1つ足す。候補：女の35〜54歳で追加就労希望の分が大きいなら、その大きさを男の同じ年齢と比べる。

## 言えないこと（予定）
- 追加就労希望は「もっと働きたいか」を本人が答えたもので、すぐに働ける時間や賃金の条件は分からない。
- 潜在労働力人口には「仕事があればすぐ働ける」「探しているがすぐには働けない」が入り、どれだけが実際に働くかは分からない。
- 内訳は指標の差からの近似。
- 2018年より前は LU2〜LU4 がない。
