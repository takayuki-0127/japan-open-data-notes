# 1171 中身の種類で圧縮のかかり方が違うとき、種類の割合が変わると全体の圧縮率はどう動くのか？（データ量の見込み）

保存するデータを圧縮したあとの量を見込むとき、今年の全体の圧縮率（圧縮後の合計÷圧縮前の合計）を来年の元の量に掛けることがあります。けれども、中身の種類によって縮み方は大きく違います。文章や記録はよく縮み、すでに縮めてある画像はほとんど縮みません。全体の率は、種類ごとの率を「量（バイト）の割合」で重みを付けた平均にちょうどなるので（式どおり）、種類ごとの縮み方が変わらなくても、量の割合が変われば全体の率は動きます。**ここでは、作成者が置いた架空のアプリの保存ファイル（文章・記録・表・画像の4種類。種類ごとに大きさの分布と縮み方を置き、乱数で作ったもの）で、今年の全体の率を来年に当てはめた見込みが、種類の割合の変わり方でどれだけ外れるかを数えました。来年は「画像の量が増える」「それに加えて、どの種類も縮み方がよくなる」「件数の割合は同じで、画像1件が大きくなる」の3通りを置き、種類ごとの率×来年の種類ごとの量の見込みとも比べました。来年の画像の量の割合と画像の縮み方を変えた18通りで確かめました。**

全体の率が量の割合で重みを付けた種類ごとの率の平均になること、そのため今年の全体の率での見込み÷実際が「今年の全体の率÷来年の全体の率」になることは、式どおりです。この記事で数えて新しく分かったのは、置いた割合の変わり方ごとのずれの大きさと向きです。

関連する記事：1162「ファイルごとの圧縮率を平均すると、全体の縮み方とどれだけ違うのか？」は、同じ時点のファイルで、率の平均と合計÷合計の違いを扱っています。この記事は、合計÷合計の全体の率を正しく出したうえで、それを種類の割合が違う来年に当てはめるずれに絞ります。

## 主な結果

### 今年（`results/a1171_main.json` の `this_year`、`results/by_type.csv`）
| 種類 | 件数の割合 | 量の割合 | 種類ごとの圧縮率 |
|---|---|---|---|
| 文章 | 65.61% | 9.97% | 25.28% |
| 記録 | 8.18% | 39.91% | 12.15% |
| 表 | 19.68% | 30.17% | 40.45% |
| 画像 | 6.53% | 19.95% | 93.09% |
| 全体 | | 499.792GB | **38.15%** |

- 量の割合で重みを付けた種類ごとの率の平均は38.15%で、全体の率と同じ値になった（式どおり）

### 来年の3通り（`results/a1171_main.json` の `next_year`）
| 来年 | 画像の量の割合 | 全体の圧縮率 | ①今年の全体の率での見込み÷実際 | ②種類ごとの率での見込み÷実際 |
|---|---|---|---|---|
| A 画像の量が40%に | 39.89% | **51.82%** | **0.7361倍** | 1.0004倍 |
| B Aに加え、どの種類もよく縮む | 39.97% | 47.82% | 0.7977倍 | 1.0847倍 |
| C 件数の割合は同じ、画像1件が1.5倍 | 27.31% | 43.15% | 0.884倍 | 0.9993倍 |

- **A：種類ごとの縮み方は変わらないのに、画像の量が19.95%から39.89%に増えるだけで、全体の率は38.15%から51.82%になった。今年の率で見込むと、圧縮後の量を0.7361倍に少なく見込んだ**。①÷実際は今年の率÷来年の率になる（式どおり）
- B：どの種類も率が下がった（よく縮むようになった。文章−2.53・記録−1.23・表−4.06・画像−6.45ポイント）のに、全体の率は38.15%から47.82%に上がった。種類ごとの改善より、縮みにくい画像の量が増えた分のほうが大きかった。このときは②も、種類ごとの率が今年から変わったぶん1.0847倍に多く見込んだ
- C：種類ごとの件数は今年と同じ（件数の割合も同じ）でも、画像1件が大きくなると量の割合は19.95%から27.31%に増え、全体の率は43.15%になった。①は0.884倍だった。件数の割合だけを見ていると、この変化は見えない
- ②は、種類ごとの縮み方が今年と同じA・Cでは0.9993〜1.0004倍で当たった（作りどおり）

### 1か月ごとに画像の量の割合が20%から40%へ動くとき（`results/monthly.csv`）
- 全体の率は、0か月目の37.56%から12か月目の52.43%まで上がった。どの月も、今年の種類ごとの率をその月の量の割合で平均した値との差は0.58ポイント以内だった

| 画像の圧縮率（今年） | 来年の画像の量10% | 20%（今年と同じ） | 30% | 40% | 50% | 60% |
|---|---|---|---|---|---|---|

（表の数字は、①今年の全体の率での見込み÷実際。画像の圧縮率は、画像の縮み方の中央値0.5・0.75・0.97のときの今年の値）

- **①の見込み÷実際は、18通りで0.5819〜1.2229倍だった**。画像の量の割合が今年と同じ20%なら0.9976〜1.0016倍で当たり、離れるほど外れた。画像が増えれば少なく見込み、減れば多く見込む
- 画像がほかの種類より縮みにくいほど、同じ割合の変化での外れが大きかった（60%のとき、画像の率50.6%で0.7385倍、93.06%で0.5819倍）
- 来年の全体の率は18通りで27.02〜65.78%だった。②は18通りすべてで0.9996〜1.0017倍だった（種類ごとの縮み方を変えていないので作りどおり）

## 注意（言えないこと）
- 架空のデータです。種類、種類ごとの大きさの分布と縮み方、今年と来年の割合は作成者が置いたもので、ずれの大きさはこれで決まります（18通りで0.5819〜1.2229倍）。実在のアプリの保存データや、実在の圧縮のやり方を表すものではありません
- 1件の縮み方は大きさによらないと置きました。大きさで縮み方が違う場合は 1162 で扱っています。決まった上乗せ（見出しの情報など）も入れていません
- ②が当たるのは、来年の種類ごとの量が正しく分かり、種類ごとの縮み方が今年と同じときです。Bのように縮み方が変わると②も外れました。来年の種類ごとの量の見込みの外れは入れていません
- 種類は4つに分けました。同じ種類の中でも中身で縮み方が違う場合、種類の中の割合の変化でも同じことが起きると考えられます（推測）
- 容量をどれだけ用意するかや、その費用、どの圧縮のやり方がよいかは扱っていません
