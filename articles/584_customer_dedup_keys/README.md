# 584 同じ人が別のIDで登録された顧客表を、電話・メール・氏名＋生年月日で寄せると、顧客数とリピート率はどれだけ変わるのか（実務の型・名寄せ）

会員登録をし直したり、店舗とネットで別に登録したりすると、同じ人が別の顧客IDで顧客表に入ります。**ここでは、架空の顧客表（本当の人数20,000人、登録24,411件）と1年分の注文を作り、電話・メール・氏名＋生年月日のどれで寄せるか（同じ人とみなすか）によって、顧客数・リピート率・寄せ漏れ・寄せすぎがどれだけ変わるかを、正解と比べました。** 表記ゆれ（ハイフン・全角・空白・異体字）、番号やアドレスの変更、家族での共有は作成者が置いたもので、数字はその仮定で決まります。**氏名・電話・メールはすべて架空で、実在の個人情報は使っていません。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A584 | 寄せるキーによって、顧客数・リピート率・誤りがどれだけ変わるか | 電話（数字だけに正規化）・メール（小文字に）・氏名（空白を消し異体字をそろえる）＋生年月日の完全一致で寄せる。キーを組み合わせるときは、どれか1つで一致すれば同じ人とみなし、つながりをたどってまとめる。寄せない・正解とも比べ、正規化しない場合も出す。電話だけで寄せた顧客数を DuckDB（1スレッド）の SQL と突き合わせ。seed 584 | `src/a584_dedup_keys.py`、`src/02_dedup_duckdb.sql`、`src/01_dedup_tsql.sql`（未検証） |

## 主な結果
| 寄せ方 | 顧客数 | 本当の人数との差 | リピート率 | 寄せ漏れ（別々のままの人） | 寄せすぎ（別の人が混ざった顧客） |
|---|---|---|---|---|---|
| 寄せない（IDのまま） | 24,411 | +22.1% | 52.2% | 3,562 | 0 |
| 電話 | 21,185 | +5.9% | 55.6% | 1,316 | 173 |
| メール | 22,451 | +12.3% | 54.3% | 2,224 | 27 |
| 氏名＋生年月日 | 20,920 | +4.6% | 55.9% | 897 | 11 |
| 電話またはメール | 20,555 | +2.8% | 56.4% | 756 | 193 |
| 3つのどれか | 19,945 | −0.3% | 57.1% | 174 | 202 |
| 正解（本当の人） | 20,000 | — | 57.0% | 0 | 0 |

- 2つ以上のIDを持つ人は 3,562人。寄せないと、リピート率は正解より 4.8ポイント低く出る
- 「3つのどれか」は顧客数がほぼ正解に近いが、寄せ漏れ174人と寄せすぎ202件が打ち消し合った結果で、誤りがないわけではない
- 寄せすぎの多くは、家族で共有する固定電話や家族のメールアドレスによるもの
- **正規化しないと**：電話は 22,587人（寄せ漏れ 2,455人）、氏名＋生年月日は 23,209人（寄せ漏れ 2,863人）で、ほとんど寄らない

## 動かし方
```
pip install -r requirements.txt
cd src && python a584_dedup_keys.py
```
数秒で終わります。`data/customers.csv`（customer_id・name・birth_date・phone・email）、`data/orders.csv`（order_id・customer_id）、確かめ用の正解 `data/answer_person.csv`（customer_id・person）を書き出します。

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures がバイト単位で一致した（DuckDB は `SET threads=1`）
- 電話だけで寄せた顧客数 21,185 が、Python と DuckDB の SQL（`02_dedup_duckdb.sql`）で一致した
- T-SQL 版（`01_dedup_tsql.sql`）は書いたが、SQL Server では動かしていない（**未検証**）。キーを組み合わせた寄せ方（つながりをたどる処理）は Python だけで行った

## データ
- 架空の人20,000人。氏名はありふれた姓30・名30を組み合わせた架空のもの（同姓同名がある）。30%の人は2〜4人の世帯で、固定電話と家族のメールを共有することがある
- 登録：1人あたり1件82%・2件14%・3件4%
- 電話：いつもの携帯70%・世帯の固定電話15%・変えた後の携帯10%・空5%。30%はハイフンつき、その一部は全角
- メール：いつもの60%・別のアドレス20%・家族のアドレス5%・空15%。10%は大文字
- 氏名：空白なし・半角空白・全角空白。4つの姓は25%の確率で異体字（髙・﨑・齋・邊）。生年月日：空10%・1日ずれ2%
- 注文：人ごとの1年の購入回数をガンマ・ポアソン分布で作り、その人のIDのどれかに付けた

## 注意（言えないこと）
- 架空のデータ。実在の人・会社の顧客表ではない
- 誤りの数は、置いた表記ゆれ・番号の変更・家族での共有の多さで決まる
- ここでは完全一致だけで寄せた。似ている名前（読み・ふりがな）や住所で寄せる方法、点数をつけて判定する方法は扱っていない
- 個人情報の扱い（利用目的・同意など）の判断は扱っていない
