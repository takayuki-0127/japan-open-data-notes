# 1152 よく使われるものへの偏りが大きいときと小さいときで、同じ大きさの置き場所の効き目はどれだけ違うのか？（キャッシュの当たり率）

よく使うデータを手元に置いておく置き場所（キャッシュ）の効き目は、置き場所の大きさだけでは決まりません。問い合わせが一部の人気のデータに集中しているなら、小さな置き場所でも多くの問い合わせに当たります。問い合わせがいろいろなデータに散らばっているなら、同じ大きさでもほとんど当たりません。「全体の1%を置けば何割当たる」という数字は、偏りの大きさを決めないと言えません。**ここでは、作成者が置いた架空のアプリのデータ1万件への問い合わせ（r番目に人気のデータが選ばれる確率を 1÷r^a に比例させ、a で偏りの大きさを置いたもの）で、置き場所を100件（全体の1%）に決めたまま、偏り a を0.5〜1.3の9通りに変えて当たり率を数えました。同じ当たり率に届くのに要る大きさ、偏りの大きい流れと小さい流れを1つの置き場所に混ぜたときの当たり率、データの件数と置き場所の割合を変えた9通りの確かめも行いました。問い合わせはすべて作成者が置いた式からの乱数で、実機の計測はしていません。**

置き場所は件数で数え、いっぱいになったら「最後に使われてからいちばん長くたったもの」を捨てる決まりにしました。比べとして、人気の上位100件をずっと置いておけたときの当たり率（上位100件の確率の合計。式で決まる）も出しました。

関連する記事：同じ企画の 1150「置き場所の大きさを2倍にすると、当たり率はどれだけ上がるのか？」は、同じ形の問い合わせ（データ10万件）で、置き場所を2倍にするごとの当たり率の上がり方を扱っています。1150 の表の横の並び（全体の1%で偏り0.6が5.37%、1.2が79.68%）にも、同じ大きさで偏りだけが違うときの差は出ています。この記事は、その差を「同じ当たり率に要る大きさ」に直したものと、偏りの違う流れが1つの置き場所を分け合うときに絞ります。1149「当たり率90%と99%の差は、平均の応答時間で何倍の差になるのか？」は当たり率の差が応答時間でどれだけになるか、1151「当たり率を件数で数えるかデータの量で数えるかで、良し悪しはどう入れかわるのか？」はデータの大きさが違うときの当たり率の数え方を扱っています。1160「試験の環境で測った当たり率は、本番の使われ方の偏りが違うとどれだけ外れるのか？」は、同じ仕組み（当たり率が偏りで大きく変わること）を、試験と本番で偏りが違うときの外れの幅として扱っています。1157「一度しか使われないものが多いと、置き場所を大きくしても当たり率はどこで止まるのか？」は、一度しか使われないデータが置き場所を占める場面を扱っています。

## 主な結果

### 置き場所100件（全体の1%）で、偏りごとの当たり率（`results/by_alpha.csv`）
| 偏り a | 当たり率 | 人気の上位100件をずっと置いたとき（式） | 当たり率÷上位100件のとき | 元のデータへの問い合わせ（1万件あたり） | 人気の上位10%（1,000件）への問い合わせの割合（式） |
|---|---|---|---|---|---|
| 0.5 | 2.33% | 9.36% | 0.2487 | 9,767.1件 | 31.13% |
| 0.6 | **4.42%** | 14.2% | 0.311 | 9,558.5件 | 38.61% |
| 0.7 | 8.49% | 21% | 0.4044 | 9,150.8件 | 47.36% |
| 0.8 | 15.6% | 30% | 0.5199 | 8,440件 | 57.06% |
| 0.9 | 26.3% | 40.96% | 0.6421 | 7,369.9件 | 67.08% |
| 1.0 | 39.13% | 53% | 0.7383 | 6,087.2件 | 76.48% |
| 1.1 | 52.78% | 64.79% | 0.8147 | 4,722.2件 | 84.39% |
| 1.2 | **65.82%** | 75.08% | 0.8767 | 3,418.1件 | 90.34% |
| 1.3 | 76.17% | 83.19% | 0.9157 | 2,383件 | 94.38% |

- **同じ100件の置き場所で、当たり率は偏り0.6で4.42%、1.2で65.82%と、14.891倍違った**
- 元のデータへ流れる問い合わせ（外れ）で比べると、偏り0.6は1万件あたり9,558.5件、1.2は3,418.1件で、2.796倍だった。偏りが小さいと、置き場所があってもほとんどの問い合わせが元のデータへ行く
- 偏りが小さいほど、「人気の上位100件をずっと置けたとき」に届かない割合も大きかった。当たり率は、上位100件のときの0.311倍（偏り0.6）〜0.8767倍（偏り1.2）。偏りが小さいと、一度しか使われないデータが次々に入ってきて、人気のデータを押し出すため
- 上位100件のときの当たり率は、置いた確率の式どおりの値（乱数ではない）

### 同じ当たり率に届くのに要る大きさ（`results/size_needed.csv`・`results/by_size.csv`）
| 偏り a | 偏り1.0・100件の当たり率（39.13%）に届く大きさ | 全体のうち | 100件の何倍か |
|---|---|---|---|
| 0.6 | 約2,020件 | 20.2% | 20.2倍 |
| 0.8 | 約744件 | 7.44% | 7.44倍 |
| 1.0 | 約101件 | 1.01% | 1.01倍 |
| 1.2 | 約14件 | 0.14% | 0.14倍 |

- **偏り1.0なら100件で届く当たり率に、偏り0.6では約2,020件（20.2倍）が要った**。偏り1.2なら約14件で届いた
- 1.0が100件でなく約101件になったのは、(1) と (2) で問い合わせの乱数が違うため
- 大きさは、6〜6,400件の11段で数えた当たり率を、大きさの対数で直線に補って出したもので、段のあいだは補った値

### 偏りの大きい流れと小さい流れを混ぜると（別々のデータ5,000件ずつ、半分ずつ、`results/a1152_main.json` の mix）
| | 偏り1.2の流れ | 偏り0.6の流れ | 全体 |
|---|---|---|---|
| その流れだけで100件を使う | 67.93% | 7.12% | （2つの平均 37.53%） |
| その流れだけで50件を使う（100件を半分に分ける） | 59.58% | 3.84% | 31.71% |
| 2つを混ぜて100件を分け合う | **55.87%** | 4.85% | **30.45%** |

- **偏りの大きい流れは、それだけなら67.93%当たるのに、偏りの小さい流れと混ぜると55.87%に下がった**。偏りの小さい流れも7.12%から4.85%に下がった
- 問い合わせは半分ずつなのに、置き場所100件のうち平均63.26件を偏り0.6の流れのデータが占めていた。そのデータの96.11%は、置き場所にいる間に一度も当たらずに捨てられた
- 2つを別々に測った当たり率の平均（37.53%）は、混ぜたときの全体（30.45%）より高く出た。置き場所を50件ずつに分けたとき（31.71%）より、混ぜたほうが少し低かった

混ぜる割合を変えると（`results/mix_share.csv`）：

| 偏り1.2の流れの割合 | 偏り1.2の流れの当たり率 | 偏り0.6の流れの当たり率 | 全体 |
|---|---|---|---|
| 2割 | 42.73% | 6.17% | 13.47% |
| 5割 | 55.87% | 4.85% | 30.45% |
| 8割 | 63.07% | 2.63% | 51.1% |

## 注意（言えないこと）
- 架空のデータです。人気の偏りの形（1÷r^a）、データの件数、置き場所の大きさ、捨てる決まりは作成者が置いたもので、結果はこれで決まります。当たり率の差の大きさは、置き方の9通りで7.274〜35.608倍まで動きました
- 人気は時間がたっても変わらないと置きました。人気が移り変わる場合は 1153 で扱っています
- データの大きさはすべて同じと置き、件数で数えた当たり率だけを出しました
- 2つの流れを混ぜた結果は、データが重ならない2つの流れを、でたらめな順に混ぜた場合です。時間帯で流れが入れかわる場合は数えていません
- 実在のソフトや置き場所の製品の当たり率を表すものではありません。置き場所の大きさを決める助言や、費用の見込みではありません
