# 1016 スコアを狙って動くと、スコアと本当の良さはずれていくのか？（指数とスコア）

店や製品のスコアは、本当の良さの一部を測ったものです。スコアを評価に使い始めると、スコアの上がる動きが得になります。その中には、測っている面を本当に良くする動きのほかに、見かけだけを整える動きや、測っていない面を後回しにする動きもまざります。そうすると、スコアと本当の良さの結びつきは弱まっていきます（「測るものが目標になると、よい物差しでなくなる」という言い方で知られる考え方です）。**ここでは、作成者が乱数で作った架空の飲食チェーン200店（本当の良さと、店ごとの「スコアに寄せる度合い」を作成者が置いたもの）で、スコアを評価に使い始めてから6期の間に、スコアと本当の良さの相関、スコア上位20店の中身、スコアがいちばん伸びた店の本当の伸びがどう動くかを数え、見かけだけの上げやすさと測らない面の後回しの大きさでどう変わるかを確かめました。ずれていく向きは、作成者が置いた動き方から決まります。数えたのは、その大きさと、上位の店の入れかわり方です。**

## 主な結果

### スコアと本当の良さの相関（500回の平均、`results/by_period.csv`）
| 期 | 店ごとに寄せる（基本） | 置いた式の値 | どの店も寄せない |
|---|---|---|---|
| 0期（評価に使う前） | 0.635 | 0.632 | 0.628 |
| 2期 | 0.603 | 0.602 | 0.639 |
| 4期 | 0.523 | 0.52 | 0.642 |
| 6期 | **0.42** | 0.42 | 0.65 |

- 評価に使い始めると、相関は0.635から6期で0.42まで下がった。どの店も寄せないときは、0.628から0.65へ少し上がった
- 相関は、**置いた式どおり**だった（差は最大0.004）。下がる向きと大きさは、置いた寄せ方（g・δ・k の散らばり）から決まる

### スコア上位20店の中身（500回の平均、`results/by_period.csv`）
| 期 | 本当の上位20店に入っていた割合 | 強く寄せる店の割合 | 本当の良さの、全店の平均との差 |
|---|---|---|---|
| 0期 | 40.69% | 17.9% | ＋6.22点 |
| 2期 | 38.9% | 31.95% | ＋6.29点 |
| 4期 | 33.29% | 44.92% | ＋5.75点 |
| 6期 | **26.33%** | **56.4%** | ＋4.72点 |

- **スコア上位20店のうち本当の上位20店に入っていた割合は、40.69%から26.33%に下がった**。どの店も寄せないときは、6期で42.6%
- **スコア上位20店のうち強く寄せる店は、17.9%から56.4%に増えた**。全店のうち強く寄せる店は17.86%なので、スコア上位に偏って集まった
- それでも、6期のスコア上位20店の本当の良さは、全店の平均より4.72点高かった（0期は6.22点）。スコアは本当の良さとまだ結びついているが、結びつきが弱まった

### スコアがいちばん伸びた20店（0期→6期、500回の平均、`results/a1016_main.json`）
- 全店の平均では、スコアは10.18点、本当の良さは3.59点伸びた。どの店も寄せないときは、スコア3点、本当の良さ6.02点。これらの平均の伸びは、置いた伸び方から**式どおり**に決まる値
- **スコアがいちばん伸びた20店は、スコアが19.33点伸びたのに、本当の良さは3.96点しか伸びず、全店の平均（3.59点）とほとんど変わらなかった**。この20店の46.1%は、本当の良さの伸びが全店の平均より小さかった。20店のうち67.04%が強く寄せる店だった
- どの店も寄せないときは、スコアがいちばん伸びた20店の本当の良さは8.8点伸びた

## 注意（言えないこと）
- 架空のデータです。スコアで測る面と測らない面の大きさ、寄せる度合いの分布、見かけだけの上げの効き、測らない面の後回しの大きさは作成者が置いたもので、ずれていく向きと大きさはこれで決まります（相関は置いた式どおり）。新しく数えたのは、スコア上位20店の当たりと中身の入れかわり、いちばん伸びた店の本当の伸びです
- 寄せる度合いは店ごとに決まっていて、期によって変わらず、本当の良さとも関係なく置きました。良くない店ほど寄せる、評価が厳しくなるほど寄せる、といった動きは入れていません
- 「見かけだけの上げ」と「測らない面の後回し」は、仕組みを分けて見るための置き方で、実際の店で何がこれに当たるかは扱っていません
- スコアを評価に使うべきか、どう使うべきかを勧めるものではありません
- 実在の店の評価や、実在の指数・ランキングを表すものではありません
- 関連する記事：925（過去問の点が上がったのは、実力か問題を覚えたからか）は、点の伸びのうち本当の力でない分を試験で扱っています。936（目標達成率は、目標の置き方でどれだけ変わるのか）・942（評価の点と売上の相関は、評価の正しさを示すのか）は、人事評価の数字の読み方を扱っています。同じ企画の1008（項目が互いに似ていると、合計点は何を測っているのか）は、合計点が何を測っているかを、1009（項目の数を増やすと、合計点は安定するのか）は、2か月の点がそろうことと本当の良さに近いことが別に動くことを扱っています。この記事は、スコアを目標にしたあとに、スコアと本当の良さがずれていく大きさに絞りました
