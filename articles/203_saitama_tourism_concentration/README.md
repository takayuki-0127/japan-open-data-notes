# 203 観光客は、少数の市町村に集中しているか：埼玉県の市町村別観光入込客数

埼玉県「観光入込客統計調査結果」の県内市町村観光入込客数（63市町村、2011〜2025年）で、観光客がどれだけ少数の市町村に集まっているかを見たフォルダです。上位の市町村が県全体に占める割合とジニ係数の推移、新型コロナの前後での観光地点とイベントの違いも見ています。

当初の問いは「観光地点の入込客数は、少数の名所に集中しているか」（観光庁「共通基準による観光入込客統計」）でしたが、観光庁の公表表には観光地点ごとの値がなく、地点別の表を出している他県サイトにも今回は届かなかったため、埼玉県が公表している市町村別の表に置き換え、「名所」ではなく「市町村」の単位で集中の度合いを測っています。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A203 | 観光客は、少数の市町村に集中しているか | 2025年の市町村ランキング、上位1・5・10市町村の割合とジニ係数の推移（2011〜2025年）、観光地点とイベントの入込客数の推移 | `src/a203_concentration.py` |

## 主な結果
- 2025年の県全体の観光入込客数は1億7,162万人回。越谷市が5,691万人回で33.2%、さいたま市が2,528万人回で14.7%を占め、上位3市（越谷市・さいたま市・所沢市）で過半数（52.6%）
- 上位5市町村の割合は60.0%、上位10市町村は72.8%。63市町村のジニ係数は0.74。市町村の真ん中（中央値）は約90万人回
- 上位5市町村の割合は2011〜2019年に58.4〜61.4%で、15年を通して大きくは変わっていない。コロナ禍の2020年だけ64.5%に上がった（1位の越谷市は39.4%）
- イベントの入込客数は2019年3,352万人回→2021年527万人回（−84.3%）、観光地点は1億3,430万→1億742万人回（−20.0%）。2025年は観光地点が2019年を3.2%上回り、イベントは20.3%下回る
- 2025年の県全体は2019年より2.3%少なく、63市町村のうち38で2019年を下回った。所沢市（+36.3%）、深谷市（+27.7%）、長瀞町（+21.8%）などは増えた
- 越谷市の入込客数の97%前後は観光地点で、さいたま市はイベントの割合が2015年まで5割前後、2016〜2020年は4割弱、2025年は28.0%

```bash
pip install -r requirements.txt

```

## データ
| ファイル | 中身 |
|---|---|
| data/saitama_muni_visitors_2011_2025.csv | 年、市町村番号、市町村名、観光地点・イベント・合計の入込客数（人回、1〜12月） |

- 埼玉県「観光入込客統計調査結果について（平成23年以降）」の各年「県内市町村観光入込客数」の Excel（2011〜2025年の15本）。ブラウザで Excel を読み、各年の表の当年分の列を書き写した
- 令和2年・令和元年・平成30年・平成29年のファイルは複数のシートがあるため、表題の年がファイルの年と一致するシートを使った
- 表の「-」は空欄にした。川越市は観光地点とイベントの内訳がなく、合計だけ
- 白岡市の2011・2012年は合計欄がふじみ野市と同じ値になっていたため、観光地点＋イベントの値に置き換えた
- 一部の市町村・年に小数の値があり（按分の結果と思われる）、そのまま使った

## 注意
- 観光入込客数は「人回」で、1人が複数の地点を訪れると重ねて数えられる。県外客と県内客の区別はこの表にはない
- どの施設を観光地点として数えるかは市町村ごとに違う。越谷市の大きさは観光地点の数え方による部分が大きいと考えられ、「観光地として人気」とはそのまま言えない
- 年によって調査対象の地点が入れ替わることがあり、市町村ごとの増減には対象の変更が含まれうる（例：入間市は2012→2013年に約66万→約701万人回）
- 市町村の単位で測っているため、市町村の中で特定の名所に集中しているかどうかは分からない
- 2020〜2022年は新型コロナでイベントの中止や施設の休業があった
