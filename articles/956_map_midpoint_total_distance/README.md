# 956 2つの拠点の中間に置くと、全体の距離は本当に短くなるのか？（地図と場所）

客が集まる場所が2つあるとき、配送の拠点を「2つのちょうど真ん中」に置けば、全体の距離は短くなりそうに見えます。けれども、真ん中に置くと短くなるのは、いちばん遠い客までの距離です。全員までの距離の合計がいちばん短くなる場所は、客の数が多いほうに寄ります。**ここでは、作成者が乱数で作った架空の町の2つの住宅地（A地区2,000世帯・B地区1,000世帯、中心の間5km）に配送の拠点を1つだけ置くとき、2つの地区の真ん中・A地区の中心・世帯の平均の場所（重心）・合計の距離がいちばん短い点の4つで、世帯までの平均の距離と、95%の世帯が入る距離を200の町で比べました。** 世帯の数の比、地区の散らばり、地区の間の距離、距離の測り方（まっすぐ・碁盤の目の道のり）を変えて確かめました。

町・地区・世帯はすべて架空のもので、実在の地図や地名は使っていません。「2つの拠点」は、ここでは客の集まる2つの住宅地として置きました。

まっすぐの距離と道のりの距離で近い店が入れ替わるかは関連する記事 947、店の商圏を半径で決めたときの重なりは 950、配送の時間が距離に比例するかは 952 で扱っています。合計の距離をいちばん短くする点は、平均ではなく中央値の仲間で、平均と中央値の違いは 891 と同じ話です。この記事は、拠点を1つ置く場所で、合計の距離と遠い世帯までの距離がどう変わるかに絞ります。

## 主な結果

### 拠点の置き方ごとの距離（基本の置き方、まっすぐの距離、200の町の平均）
| 置き方 | 拠点の東西の位置 | 平均の距離 | いちばん短い点より | 95%の世帯が入る距離 | A地区の世帯 | B地区の世帯 |
|---|---|---|---|---|---|---|
| A地区の中心 | 2.50km | 2.356km | +4.8% | 5.88km | 1.00km | 5.06km |
| 2つの地区の真ん中 | 5.00km | 2.632km | **+17.1%** | **3.91km** | 2.63km | 2.63km |
| 世帯の平均の場所（重心） | 4.17km | 2.392km | +6.4% | 4.25km | 1.87km | 3.43km |
| 合計の距離がいちばん短い点 | 3.18km | **2.248km** | — | 5.20km | 1.18km | 4.39km |

（A地区の世帯・B地区の世帯の列は、それぞれの地区の世帯までの平均の距離）

- 真ん中に置くと、世帯までの平均の距離は、合計がいちばん短い点より17.1%長かった（町ごとの10〜90%：16.6〜17.5%）。A地区の中心に置くより、200の町すべてで長く、平均0.276km 長かった
- 合計がいちばん短い点は、東西3.18km（A地区の中心は2.50km、真ん中は5.00km）で、世帯の多いA地区のほうに寄っていた。世帯の平均の場所（重心）でもなく、重心は+6.4%長かった
- 一方、95%の世帯が入る距離は、真ん中が3.91kmでいちばん短く、合計がいちばん短い点では5.20kmだった。真ん中は「遠い世帯まで」を短くし、「全体の合計」を長くする置き方だった
- 道のり（碁盤の目）で測っても同じ向きで、真ん中は+18.8%、A地区の中心は+3.3%、重心は+8.5%長かった
- 例の町1つでは、平均の距離は真ん中2.62km・合計がいちばん短い点2.24kmで、95%の世帯が入る距離がいちばん短い点（東西4.75km）は平均2.54km・95%点3.83kmだった

### A地区とB地区を結ぶ線の上で拠点を動かすと（まっすぐの距離、比ごとに町を1つ）
| A地区:B地区の世帯 | いちばん短い場所（A=0・真ん中=0.5・B=1） | その平均の距離 | 真ん中の平均の距離 | A地区の中心の平均の距離 |
|---|---|---|---|---|
| 1:1 | 0.5 | 2.633km | 2.633km | 3.024km |
| 2:1 | 0.15 | 2.239km | 2.625km | 2.350km |
| 4:1 | 0.075 | 1.774km | 2.635km | 1.806km |

- 世帯の数が同じ（1:1）なら、真ん中がいちばん短く、A地区の中心より短かった。比が2:1になると、いちばん短い場所はA地区のほうへ大きく寄った

### 確かめ：置き方を変えて（72通り、各30の町）
| | 結果 |
|---|---|
| 世帯の数が同じ（1:1）18通りで、真ん中の余分 | 0.00〜0.02%（真ん中がほぼいちばん短い） |
| 世帯の数が違う54通りで、真ん中の余分 | **0.45〜93.37%** |
| 重心の余分（72通り） | 0.00〜28.44% |
| 比2:1以上の36通りのうち、真ん中がA地区の中心より短い町が半分を超えた組 | 4通り |
| 真ん中の95%点 − 合計がいちばん短い点の95%点 | −3.29〜+0.12km |

- 真ん中の余分は、世帯の数の比が偏るほど、地区がまとまっている（散らばりが小さい）ほど、地区の間が遠いほど大きくなった。比4:1・散らばり0.5km・間8km では、まっすぐの距離で+93.37%だった
- 比2:1では、地区の間が2kmと近く散らばりが0.8〜1.5kmと大きい4通り（まっすぐ・道のり）で、真ん中のほうがA地区の中心より短い町が多かった
- 遠い世帯までの距離（95%点）は、真ん中に置くと、合計がいちばん短い点より−3.29〜+0.12km だった。長くなった組でも0.12km 以内だった

## 動かし方
```
pip install -r requirements.txt
cd src && python a956_midpoint_distance.py
```
10〜25秒ほどで終わります（計算機の混み方で変わります）。`data/households_example_town.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の9ファイルがバイト単位で一致した（cmp、2回流して2回とも一致、約12〜23秒）
- 図3枚を開き、日本語・重なり・軸を確かめた
- 世帯の数が同じ（1:1）とき、真ん中と合計がいちばん短い点の差が18通りすべてで0.02%以内になることを確かめた。左右が同じ形なら真ん中がいちばん短くなる、という作りどおりの動き
- 合計の距離をいちばん短くする点が多いほうに寄ること（2点なら多いほうの点そのもの、道のりなら縦横の中央値）は、よく知られた性質で、新しく見つけたことではない。数えたのは、真ん中に置いたときに余分になる大きさと、それが置き方でどれだけ動くか

## 注意（言えないこと）
- 架空のデータです。2つの地区の世帯の数・広がり・間の距離、距離の測り方は作成者が置いたもので、結果はこれで決まります。真ん中に置いたときの余分は、世帯の数が違う54通りで0.45〜93.37%と動きました。実在の町や配送の会社を表すものではありません
- 世帯ごとに同じ回数届けると置きました。届ける回数や荷物の量が地区で違えば、合計がいちばん短い点も動きます
- 拠点から1件ずつ往復すると置いた距離です。何件も回る配送の道順、道の混み方、拠点を置ける土地の場所や費用は入れていません
- 合計の距離と遠い世帯までの距離のどちらを優先して拠点を置くべきかは、この記事では言えません
