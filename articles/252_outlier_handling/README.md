# 252 外れ値を消すか残すか、どう決めてきたか（④ 振り返り R008）

このシリーズの記事512本の README で、外れ値や特別な点（東京、コロナの年、1つの業種など）をどう扱ったかを数えたフォルダです。都道府県の回帰で1県の影響を調べた [F178](https://github.com/takayuki-0127/japan-open-data-notes/tree/main/articles/F178_regression_influence) の結果もあわせて見ます。

## 問い

- 外れ値・特別な点を、消したのか、残したのか、両方並べたのか
- 何を外すことが多かったか
- 外したとき、結論は動いたか

## 手法

| 手順 | 中身 |
|---|---|
| 拾う（`src/a252.py`） | README を1行ずつ読み、外れ値・除くと・外すと・1つずつ除く・上下○%・影響度などの言葉がある行を拾った（リンクの行と見出しは除く） |
| 扱い方・外したもの | 拾った行を、扱い方4つと外したもの6つの言葉で分け、記事の数を数えた（1記事に複数つく） |
| 結論が動いたか | 「除くと・外すと」を書いた行から乱数（seed 11）で30行を選び、結果が書かれた行を目で「動いた」「変わらなかった」に分けた（`data/manual_outcome_sample.csv`） |
| F178 の数字 | F178 の README の表（3,403組の単回帰で、いちばん効く1県を除くと p<0.05 の判定が入れ替わる割合）を写した |

## 主な結果

- 外れ値・特別な点の扱いを書いた記事は162本（512本中、32%）。扱い方は「除いた結果も並べた」130本、「頑健な指標・変換を使った」44本、「1つずつ外して確かめた」24本、「端を丸めた」16本
- 外したものは、東京・大都市31本、業種・部門・品目19本、コロナの時期16本、1つの年・月12本、災害・特別な出来事10本、小さい市町村・少ない件数5本
- 書いた記事の割合は、精選（F256〜F295）58%、F100〜F199 47%、F01〜F99 41%、000〜099 36%、F200〜F255 33%、100〜226 5%、227以降・T 5%（100〜226 と 227以降は README の形が短く、注意の節にまとめて書いていることが多い）
- 目で確かめた30行のうち、外したときの結果が書かれていたのは13行で、動いた7・変わらなかった6。残りの17行は手順の説明などで、結果は書かれていなかった
- F178：3,403組のうち p<0.05 は1,742組（51%）。いちばん効く1県を除くと、そのうち12.6%が p≥0.05 になった。p が0.01〜0.05 の組では38.9%、0.001〜0.01 の組では16.7%（乱数のデータでは1.7%）が入れ替わった（図2）

## 注意（言えないこと）

- README に書き残したことだけを数えている。外して確かめたのに書かなかったことは入らない
- 言葉で拾ったので、外れ（「除く」が外れ値と関係ない定義の説明など）と取りこぼしがある。結論が動いたかは30行だけを目で見た小さな数で、割合は目安にとどまる
- 「動いた」記事の結論が間違っていた、という意味ではない。どの点を外すのが正しいかは、題材ごとに決まる
- 都道府県の名前は、記事の題材として外した点を示すためだけに書いた。良し悪しの評価ではない
