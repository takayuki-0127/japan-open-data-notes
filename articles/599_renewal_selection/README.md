# 599 事故のあった人ほど契約を更新しないと、翌年の保有の事故率はどれだけ下がって見えるのか（手法の解説・保険数理）

事故を起こした人は、保険料が上がったり、乗り換えたりして、契約を更新しないことが多くなります。もともと事故を起こしやすい人ほど事故を起こすので、毎年「事故のあった人が少し多めにやめる」だけで、残った保有の顔ぶれは少しずつ事故を起こしにくい人に寄っていきます。**ここでは、架空の契約者30万人（新しく入る人の平均の事故率7%、人ごとの差は変動係数 CV で置く）で、事故のなかった人は90%、事故のあった人は70%の確率で更新し、やめた分を新しい人で埋める15年をつくりました。** 誰の事故率も変えていないのに、保有の事故率がどれだけ下がって見えるかを、人ごとの差と更新率の差を変えて比べています。数字は置いた前提で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A599 | 事故の有無で更新率が違うと、保有の事故率は新規よりどれだけ低くなるか | 人ごとの本当の事故率をガンマ分布で置き、毎年の件数をポアソン分布で作る。事故の有無で更新の確率を変え、やめた分は新しい人で埋める（保有の件数は一定）。保有全体・新規・更新した人の事故率と、保有の年数ごとの事故率を比べる。比較として、やめるかどうかを事故と無関係にした場合（更新率は同じ水準）と、人ごとの差がない場合。DuckDB（1スレッド）の SQL と Python で保有の年数ごとの事故率を突き合わせ。seed 599 | `src/a599_renewal.py`、`src/02_tenure_duckdb.sql`、`src/01_tenure_tsql.sql`（未検証） |

## 主な結果（人ごとの差 CV 0.8、事故のなかった人90%・あった人70%で更新）
- **保有全体の事故率**：1年目6.98%から15年目6.59%（本当の平均は6.99%→6.61%）。13〜15年目で新規より **5.4%低い**。誰の事故率も変えていない
- **やめるかどうかが事故と無関係なら**（更新率は同じ水準）：15年目も7.05%で、下がらない
- **人ごとの差がないなら**（全員7%）：事故のあった人が多くやめても、翌年の事故率は変わらない（15年目6.96%）
- **保有の年数ごと**（11〜15年目の平均）：1年目6.99%、5年目6.74%、10年以上6.33%（本当の平均）。長く続いている契約ほど低いのは、選ばれて残った人だから
- **人ごとの差と更新率の差を変えると**（13〜15年目、新規との差）：CV 0.4・事故のあった人の更新率80%で−0.6%、CV 1.2・50%で−18.1%
- 保有の事故率が下がったのを見て「契約者が安全になった」と読むと誤る。新しく入る人の事故率は7%のまま

## 動かし方
```
pip install -r requirements.txt
cd src && python a599_renewal.py
```
数秒で終わります。`data/policy_years.csv`（policy_id・year・tenure・claims・renewed、2万件の13〜15年目）を書き出します。

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures がバイト単位で一致した（DuckDB は `SET threads=1`）
- 保有の年数ごとの事故率が、Python と DuckDB の SQL（`02_tenure_duckdb.sql`）で一致した（差の最大0）。データの更新率は、事故なし90.0%・事故あり69.0%
- T-SQL 版（`01_tenure_tsql.sql`）は書いたが、SQL Server では動かしていない（**未検証**）

## 前提
- 人ごとの本当の事故率は、平均7%（1年あたりの件数）・変動係数 CV のガンマ分布。人の事故率は年で変わらない
- 事故件数はポアソン分布。更新の確率は、その年の事故の有無だけで決まる（保険料や等級は扱わない）
- やめた分と同じ数の新しい人が入り、保有の件数は一定

## 注意（言えないこと）
- 架空のデータ。実際の保険会社の契約者ではない
- 結果は、人ごとの差の大きさと、事故の有無による更新率の差で決まる。実際には年齢や車の変化などで、人の事故率そのものも変わる
- 料率・引受・更新の判断の助言ではない
