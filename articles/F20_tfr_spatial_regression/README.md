# F20 出生率は隣の町と似るのか？ 空間回帰で考える

## 問い
市区町村（政令市は区）の合計特殊出生率は、地域の特徴（若い女性の割合、所得、通勤、保育所、産業、人口密度）でどこまで説明できるか。普通の回帰（OLS）の誤差に残る「地域の固まり」をどう扱うと、答えはどう変わるか。地域ごとに関係は違うか。

## データ
- 出生率：厚生労働省「人口動態保健所・市区町村別統計」の合計特殊出生率（ベイズ推定値、2018〜22年。頑健性で2013〜17年）
- 説明する変数（社会・人口統計体系、2020年。住宅は2018年の住宅・土地統計調査）
  - 15〜39歳女性の割合（15歳以上女性 − 40歳以上女性）÷ 総人口
  - 納税者1人あたり課税対象所得（対数）。政令市の区は区の値がないので市の値（129区域）
  - 市区町村外への通勤・通学の割合（流出人口 ÷ 従業・通学者）
  - 0〜5歳人口千人あたり保育所等数
  - 第3次産業就業者の割合
  - 可住地1km²あたり人口（対数）
- 境界と隣接：国土数値情報 行政区域 2021 の簡略版 TopoJSON。境界線（弧）を共有する区域を「隣」とする（Queen 隣接）。島などで隣がない50区域は、いちばん近い1区域を隣とした
- 分析対象：1,841区域（出生率が「…」の福島・熊本の9町村、人口0の区域、データが欠けた区域を除く）

## 手法
| 段階 | 内容 | コード |
|---|---|---|
| 1 | OLS（説明する変数は標準化。係数は「1標準偏差あたりの出生率の差」） | `03_分析.py` |
| 2 | 出生率と OLS 残差の Moran's I（並べ替え999回） | 同上 |
| 3 | LM 検定（ラグ・誤差、頑健版）で空間ラグか空間誤差かを見る | 同上（spreg） |
| 4 | 空間ラグモデル（SAR）・空間誤差モデル（SEM）を最尤法で推定 | 同上 |
| 5 | SAR の直接効果・間接効果（波及）。区間は係数と ρ を共分散から500回引いて計算 | 同上 |
| 6 | 地理的加重回帰（GWR、適応型 bisquare、近い区域の数は AICc で選択）。局所 t 値は多重比較を補正 | 同上（mgwr） |
| 7 | 頑健性：隣接の定義（近い6区域・30km以内の距離の逆数）、期間（2013〜17年）、政令市の区・東京23区を除く、未婚者割合を加える、持ち家・住宅の広さを加える、都道府県ダミーを加える | `03_分析.py`・`03b_県の固定効果.py` |

## 主な結果
- 出生率の Moran's I は **0.68**。隣どうしが強く似ている（九州・中国で高く、北海道・東北・首都圏・京阪神の中心で低い）
- OLS の決定係数は **0.15** で、残差の Moran's I も **0.56**。説明しきれない部分が地域で固まっている
- LM 検定はどちらも有意。頑健版はラグが大きい（227 対 22）が、AIC は空間誤差モデル（−2,264）が空間ラグ（−2,248）よりわずかに良い。空間の偏りのパラメータは ρ=0.75、λ=0.79 と大きい
- 空間の偏りを入れると係数が変わった（1標準偏差あたり、OLS → 空間誤差モデル）

| 変数 | OLS | 空間誤差モデル |
|---|---|---|
| 15〜39歳女性の割合（1SD=2.3ポイント） | +0.057 | +0.015 |
| 所得（1SD=対数で0.16） | **−0.071** | **+0.023** |
| 市区町村外への通勤・通学（1SD=18ポイント） | −0.060 | +0.004（0をまたぐ） |
| 保育所数（1SD=7.7か所） | −0.003 | −0.010 |
| 第3次産業の割合（1SD=10ポイント） | −0.029 | −0.032 |
| 人口密度 | +0.024 | +0.001（0をまたぐ） |

  OLS で見えた「所得が高い町ほど出生率が低い」「通勤で外に出る町ほど低い」は、地域の固まり（九州は所得が低く出生率が高い、など）を取り込んだ見かけだった可能性が高い
- 空間ラグモデルでは、効果の約7割が間接効果（まわりの区域を通じて広がる分）になる。ただしこれは「隣の出生率が自分の出生率を動かす」という仮定の上の数字
- 都道府県ダミーを入れると、決定係数は0.15→**0.62**、残差の Moran's I は0.56→**0.23**、λは0.79→0.43 に下がった。「隣と似ている」の多くは県の単位の違いで説明できる
- GWR（近い97区域で推定）の決定係数は **0.76**、残差の Moran's I は0.06。係数は地域で違い、局所の係数の四分位範囲は標準誤差の中央値の1.8〜2.6倍。ただし多重比較を補正して有意な区域は少ない（第3次産業が負：15%、保育所数が負：12%、所得が正：8%、若い女性が正：3%）
- 第3次産業の割合の係数は、8通りの頑健性チェックすべてで負（−0.023〜−0.036）。所得は2013〜17年だけ0をまたぐ。若い女性の割合は都道府県ダミーを入れると0をまたぐ

## 注意（このデータで言えないこと）
- すべて相関で、どの施策が出生を増やすかは言えない。保育所数の負の係数は、子どもが少ない町ほど「子ども千人あたり」の数が大きくなる逆向きの関係を含む
- 出生率はベイズ推定値で、小さな町の値は県や二次医療圏の値に寄せられている。隣どうしが似る理由の一部は、この推定方法そのものにある
- 空間ラグの「間接効果」は、隣の出生率が自分の出生率を動かすというモデルの仮定に依存する。空間誤差モデルとの違いはデータだけでは決めきれない
- 説明する変数は2020年前後の値、出生率は2018〜22年の平均。個人の結婚・出産の判断は分からない
- 政令市の区の所得は市の値で代用している
