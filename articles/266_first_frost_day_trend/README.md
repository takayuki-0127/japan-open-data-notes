# 266 初霜の日は、どれだけ遅くなったのか（日ごとの表で毎年そろえて作れる「最低気温が0℃を下回る最初の日（初冬日）」で見る）

気象庁「過去の気象データ検索」の日ごとの値（14地点、1931〜2025年）を使ったフォルダです。262〜266の5本は同じデータ（`data/jma_daily_14st_1931_2025.tsv.gz`）を使っています。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A266 | 初霜の日は、どれだけ遅くなったのか（日ごとの表で毎年そろえて作れる「最低気温が0℃を下回る最初の日（初冬日）」で見る） | 寒候年（8月〜翌7月）ごとに日最低気温0℃未満の最初・最後の日と日数を求め、1961〜1990年平均からの差を13地点で平均。直線の傾き（HC1標準誤差）、Theil–Sen、線（0℃未満・2℃以下・4℃以下）を変えた比較 | `src/a266_first_frost_day.py` |

## 主な結果
- 13地点の平均で、最初の冬日は1931〜2024年の直線で10年に1.5日（標準誤差0.2日）遅くなり、1961年以降に限ると10年に2.6日でした。最後の冬日（春）は10年に2.3日のペースで早くなり、1961年以降は10年に3.0日です。
- 1931〜1960年と1995〜2024年の平均で比べると、最初の冬日は地点の中央値で9日遅く、最後の冬日は13日早くなりました。冬日のない期間は、13地点の平均で23日ほど延びた計算です。
- 地点ごとに見ると、13地点すべてで最初の冬日が遅くなり、最後の冬日が早くなっていました。最初の冬日の遅れが大きかったのは銚子（12月27日→1月13日）、彦根（12月9日→12月25日）、山形（11月7日→11月21日）、宮崎（12月7日→12月20日）です。地点ごとの傾きの95%区間が0を含まないのは、13地点のうち10地点でした。
- 比べるために見た東京では、最初の冬日が12月7日から1月8日へ、1か月あまり遅くなっていました。冬日の数も年49日から6日に減っていて、13地点より大きな変化です。都市化の影響が重なっていると考えられます（推測）。
- 霜は、地面の近くが地上1.5mで測る最低気温より冷えて降りるので、最低気温が0℃より少し高くても降りることがあります。そこで線を2℃以下・4℃以下に変えて、最初の日を数え直しました。13地点の中央値で、どちらも10年に1.6日遅くなっていて、0℃未満の1.5日とほぼ同じでした。

## 頑健性
- 線を2℃以下・4℃以下に変えても、13地点の中央値で10年に1.6日遅くなった
- 傾きを Theil–Sen 法で測っても、13地点の中央値で10年に1.4日遅くなった
- 13地点のうち10地点で、地点ごとの傾きの95%区間が0を含まない
- 冬日の日数も13地点すべてで減った（7〜25日）
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致した

## 動かし方
```
pip install -r requirements.txt
cd src && python a266_first_frost_day.py
```
`src/fetch.py` は気象庁のページから同じ形のデータを取り直すスクリプトです（全地点・全月で約1.6万ページ。ふつうのネット環境向けで、このデータを取ったときはブラウザの中で同じページを読みました。このスクリプト自体は動かして確かめていません）。

## データ
- `data/jma_daily_14st_1931_2025.tsv.gz`：気象庁「過去の気象データ検索」日ごとの値（daily_s1、view=p1）を2026-11-12に取得し、地点・年・月・日・降水量合計・平均気温・最高気温・最低気温・降雪の深さ合計・最深積雪・天気概況（昼・夜）を取り出したもの（485,786行）。値の印（`)` 準正常値、`]` 資料不足値、`×` 欠測、`--` 現象なし）はそのまま残し、`src/common.py` で `)` は使う、`]`・`×` は欠測、`--` は0として読みます
- 地点：網走・根室・寿都・山形・石巻・伏木・飯田・銚子・境・浜田・彦根・多度津・宮崎（気象庁が長い気温の変化に使う、都市化の影響が比較的少ない15地点から、亜熱帯の名瀬・石垣島を除いた13地点）と、比べるための東京

## 注意
- 気象庁が発表する「初霜」（霜が降りたのを見て記録する日）とは違う指標です。実際の初霜は、地面の冷え方しだいでこの記事の日付より早いことが多いと考えられます（推測）
- 最低気温の測り方や観測の場所の変化は補正していません
- 1つの冬の値は揺れが大きく、1つの年で傾向は言えません
- なぜ遅くなったか（温暖化、都市化、地点のまわりの変化）は、このデータでは分けていません
