# F172 生まれる日・亡くなる日は、曜日と季節でどう偏るか？（円周統計と曜日効果）

## 問い

- 生まれる日は、曜日・祝日・年末年始でどれくらい偏っているか。偏りは、出生の場所（病院・診療所・助産所・自宅）や時刻で違うか。
- 生まれる月・亡くなる月は、季節にどれくらい集中しているか。その集中の強さと「季節の重心」は、1947年から今までにどう変わったか。

## データ

すべて e-Stat の人口動態統計（確定数、厚生労働省）の CSV です。

| ファイル（data/raw/） | 統計表 | 期間 |
|---|---|---|
| hokan_shussei_t07_YYYY.csv | 保管統計表 出生 第7表「出生数，出生の場所・出生月・出生日・出生時別」 | 2018〜2025年（各年） |
| joukan_shussei_t4_2_2025.csv | 上巻 出生 第4.2表「出生月別にみた年次別出生数及び出生率」 | 1947〜2025年（1947〜2000年は5年おき） |
| joukan_shibou_t5_4_2025.csv | 上巻 死亡 第5.4表「死亡月別にみた年次別死亡数及び死亡率」 | 1947〜2025年（1947〜2005年は5年おき） |

- 統計表ID は `src/common.py` にあります。e-Stat の CSV は Shift_JIS なので、UTF-8 に直して保存しています。
- 整形後のデータは次の2つです。
  - `data/births_daily_place_hour.csv`：日×出生の場所×時刻。2,922日×6区分です。
  - `data/births_deaths_monthly.csv`：年×月の出生数・死亡数。
- 日別の出生数を年で合計すると、8年とも上巻の年間出生数と一致しました。
- 死亡は、日別・曜日別の統計表が公表されていません。保管統計表の死亡は1表だけです。そのため、死亡は月別だけで分析しています。

## 手法

**曜日の指数**
- その年の1日平均を100として、曜日・祝日・年末年始（12/29〜1/3）ごとの平均を出しました。祝日は jpholiday で判定し、祝日と年末年始は曜日から外しています。
- 回帰でも確かめました。log(出生数) を日の種類と年×月の固定効果で説明し、HC3 の標準誤差を使っています。基準は火曜です。

**出生の場所と時刻**
- 場所別に、平日（月〜金）の平均を100とした指数を出しました。
- 時刻は、9時台〜16時台の割合を、平日と日曜・祝日で比べました。

**季節の円周統計**
- 月を円の上の角度に置き、1日あたりの件数（月の日数で割った値）を重みにして、次の2つを出しました。
  - 平均の方向：季節の重心。日付に直しています。
  - 集中度 R：0なら偏りなし、1なら1点に集中。
- 曜日も7日の円に置いて、同じ R を出し、季節の偏りと大きさを比べました。

## 結果

**曜日・祝日・年末年始（出生、2018〜2025年、計629万人）**
- その年の1日平均を100とした指数：

  | 日の種類 | 指数 |
  |---|---|
  | 火曜 | 120（いちばん多い） |
  | 月・木・金 | 111 |
  | 土曜 | 78 |
  | 日曜 | 67 |
  | 祝日 | 72 |
  | 年末年始 | 67 |

- 平日（月〜金）の平均と比べると、日曜は −40.6%、土曜は −30.8%、祝日は −36.2%、年末年始は −41.4% でした。
- 回帰で年×月をそろえても、火曜と比べて日曜は −44.0%（95%区間 −44.4〜−43.5%）、土曜は −34.7% でした。
- 日曜の指数は、2018年の70.9から2025年は62.1へ、毎年下がっています。
- 土日祝・年末年始が平日並みだった場合と比べた「足りない分」は、年間出生数の12.0%（2018年）から16.7%（2025年）に増えました。

**出生の場所**

| 場所 | 出生数に占める割合 | 日曜の指数（平日＝100） |
|---|---|---|
| 病院 | 54.3% | 54.5 |
| 診療所 | 45.0% | 65.1 |
| 助産所 | 0.49% | 98.0 |
| 自宅 | 0.12% | 93.6 |

- 自宅の日曜の指数は、年ごとに80〜105と幅があります。年で層別した並べ替え検定では p=0.075 で、はっきりした差とは言えません。

**時刻**
- 9時台〜16時台に生まれる割合は、平日が55.6%、日曜・祝日が39.6%でした。
- 平日と日曜・祝日の差（1日あたり約970人）の80%は、9時台〜16時台に集まっています。
- 0時台〜6時台の出生数は、日曜・祝日も平日とほぼ同じでした（0.93倍）。

**季節（月別、1日あたり）**
- 出生
  - 1950〜1960年は、1〜2月に集中していました（R 0.057〜0.073、いちばん多い月といちばん少ない月の比 1.4〜1.6倍）。
  - 1980年以降は R が0.003〜0.03まで小さくなり、重心は7〜10月に移りました（2000〜2019年は20年中17年で9月がいちばん多い）。
  - 2015〜2025年の R の平均は0.016です。各年の月の値を並べ替えたときの95%点（0.022）を下回り、「1つの季節にまとまった」偏りとは言えません。
- 死亡
  - どの年も冬が多く、R は1965年の0.128から、2000〜2019年は平均0.067になりました。
  - 2000〜2019年は16年中13年で1月がいちばん多く、重心は1月中旬〜2月上旬です。
  - 2015〜2025年の R の平均は0.064で、並べ替えの95%点（0.048）を上回ります。
- 大きさ比べ：2018〜2025年の出生では、曜日の円の R が0.110、季節の R（月別）が平均0.018で、曜日の偏りが約6倍大きいという結果でした。

## 頑健性

1. **年**
   - 日曜の指数は8年すべてで62〜71、土曜は74〜82でした。順位（火曜がいちばん多い、日曜がいちばん少ない）は8年とも同じです。
2. **出生の場所**
   - 土日の落ち込みは病院・診療所に限られ、助産所・自宅ではほぼ見られません（上の表）。
3. **回帰でそろえた場合**
   - 年×月の固定効果を入れても、曜日の差はほぼ同じでした（R² 0.947）。
4. **月の日数で割るかどうか**
   - 割らないと、出生の R は大きく出ます（例：2005年 0.0032 → 0.0086）。2月が短いことが見かけの偏りになるためです。
5. **日別か月別か**
   - 2018〜2025年の出生を日単位で計算すると、R は0.013〜0.036で、月別（0.008〜0.030）より少し大きくなりました。
   - 曜日・祝日の指数で割ると、日単位でも0.008〜0.032となり、月別とほぼ同じです。月ごとの祝日・週末の数の違いは、季節の R を大きくは動かしていません。
6. **期間**
   - 出生は、1947〜1965年（R 平均0.051）と1970年以降（0.010〜0.021）で大きく違います。2020〜2025年は0.021とやや大きく、2021年1月の落ち込みが効いています（推測：感染症の流行の影響）。
   - 死亡は、2020〜2025年に重心が12月下旬〜1月上旬に寄りました。

## 言えないこと

- **原因**：出生の土日の落ち込みは、計画分娩や帝王切開の日時の決め方と整合的です（推測）。ただし、このデータには分娩の方法がないため、確かめられません。
- **死亡の曜日**：日別・曜日別の死亡の統計表が公表されていないため、亡くなる日の曜日の偏りは分析していません。
- **月別の分析の粗さ**：季節は月の単位で見ているので、月の中の動き（年末年始など）はならされます。2000年以前は5年おきの年しかありません。
- **R は小さい値**：出生の季節の R は0.01前後で、件数が多いので検定すればほぼ必ず「有意」になります。そのため、効果の大きさと並べ替えの比較で判断しています。
- **地域・個人**：全国の集計値だけを使っています。地域や医療機関ごとの比較はしていません。
- **死亡の季節の原因**：冬の死亡の多さが、気温・感染症・医療体制のどれによるものかは分けていません。
