# 1284 同じ日に作った部品どうしで寸法のずれがそろうとき、関係なしと見て二乗で足した幅は、実際の幅よりどれだけ狭く出るのか？（寸法の積み上げ）

部品をいくつも重ねて組む品物の高さのばらつきは、部品ごとの標準偏差を二乗して足し、平方根をとって見込むことがあります。この足し方は「部品どうしのずれは互いに関係ない」ことを前提にしています。同じ日に作った部品が、種類が違ってもそろって少し厚め（または薄め）になるなら、ずれは打ち消し合わず、組んだ品物の幅は見込みより広くなります。広がり方は、標準偏差＝見込み×√(1＋(部品の数−1)×関係の強さ) という式で決まります。**ここでは、作成者が置いた架空の棚（5種類の部品を重ねて高さが決まる。寸法のずれのうち「作った日」で決まる割合を作成者が置き、乱数で60日・1,200台を組んだもの）で、部品ごとの記録から二乗で足した見込みが実際の棚の標準偏差の何分の1に出るか、見込みの±3倍の外に出る棚が何%あるかを数えました。記録を60日分使うか1日分だけ使うか、何日分の部品をまぜて組むか、そろう部品の種類の数を変え、日で決まる割合・部品の数・まぜる日数の27通りでも確かめました。**

例の棚・部品・工場はすべて架空のもので、実在の会社・製品・規格の数字ではありません。品質の判断や購入の助言はしていません。

- **60日分の記録から二乗で足した見込みは、実際の棚の標準偏差の0.6765倍（中央値）と狭く出た。実際は見込みの1.4781倍で、式の値1.4832倍とほぼ同じ（式どおり）**。外に出た棚は0.27%の見込みに対して平均4.356%（式では4.311%）
- 500工場すべてで、実際は見込みの1.1倍を超えた。工場ごとにも、60日のあいだに出た日ごとのずれの大小で、比は1.3877〜1.5752倍（500工場の5〜95%）と動いた
- **1日分の記録だけから見込むと、比は1.7745倍（中央値）とさらに広がり、外に出た棚は平均9.81%だった**。1日の中では日ごとのずれが動かないので、記録の標準偏差に日ごとのずれの分が入らない。見込みは実際の0.5635倍（中央値）になった
- 記録を日ごとに並べると、部品の種類どうしの相関は0.2977（500工場の中央値）と、置いた0.3がそのまま見えた。記録の中に関係は出ているが、種類ごとに標準偏差だけを出して二乗で足すと、それが落ちる

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の9ファイルがバイト単位で一致した（cmp）
- 実際÷見込みを、式 √(1＋そろう種類の数×(そろう種類の数−1)×関係の強さ÷部品の数) の値（何日分かをまぜて組むときは、関係の強さ÷まぜる日数）と照らした（27通りで差は最大0.032）
- 図3枚を開き、日本語・重なり・軸（棒グラフの軸は0から）を確かめた

## 注意（言えないこと）
- 架空のデータです。部品の数、標準偏差、日で決まる割合、記録の個数、組み方は作成者が置いたもので、結果はこれで決まります。比の大きさは式で決まる値で、シミュレーションはそれを確かめたものです
- ずれは正規分布で、日ごとのずれはどの種類にも同じ大きさで同じ向きに出ると置きました。種類によって逆向きにずれる（関係が負の）場合は、見込みより狭くなりますが、この記事では数えていません
- 日ごとのずれは日どうしで関係なく置きました。何日も続けて同じ向きにずれる場合は、60日分の記録でも日ごとのずれの分を少なく見ることがあります（推測）
- 実在の家具・部品の寸法のばらつきの大きさや、日ごとのずれの割合を表すものではありません。品質の判断・部品の買い方の助言をする記事ではありません
