# 603 日次の前年比を「前年の同じ日」と比べるか「前年の同じ曜日」と比べるかで、どれだけ違って見えるのか（実務の型・比べる相手の日）

曜日で売上が大きく変わる店では、日ごとの前年比を「前年の同じ日付」と比べると、曜日がずれた分だけ数字が上下します。2025年の日付は、2024年の同じ日付と曜日が1つ（1〜2月）か2つ（3月以降、2024年はうるう年）ずれています。**ここでは、本当の伸びが毎日 +3% の架空の店の日次売上（2024〜2025年、土日は平日の1.5倍前後、祝日は日曜と同じ）で、2025年の前年比を3通りで出しました。** 曜日の波と日々の振れ（標準偏差 約3%）は作成者が置いたもので、数字はその仮定で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A603 | 比べる相手の日の選び方で、日ごとの前年比の散らばりとマイナスに見える日がどれだけ変わるか | D1 前年の同じ日付、D2 364日前（同じ曜日）、D3 364日前でどちらかだけが祝日の日を除く。7日と月の合計での比較。祝日は2024・2025年の国民の祝日と振替休日。seed 603 | `src/a603_yoy_compare_day.py` |

## 主な結果
- **前年の同じ日付（D1）**：日ごとの前年比の標準偏差 **20.9ポイント**、10%点 −29.3% から90%点 +33.5%。本当の +3% から10ポイント以上外れた日が196日。マイナスに見えた日は131日（35.9%）
- **曜日で偏る**：D1 の曜日ごとの平均は、月曜 −24.3%、土曜 +37.3%（前年の同じ日付が木曜にあたることが多い）。364日前（D2）なら、どの曜日も +2.5〜+7.3%
- **364日前（D2）**：標準偏差 10.7ポイント、10ポイント以上外れた日は30日。残る大きな外れは、祝日の有無が違う26日（春分の日・GW・振替休日など）
- **祝日の有無が違う日を除く（D3、339日）**：標準偏差 4.6ポイント、10ポイント以上外れた日は11日
- **それでも1日の前年比は振れる**：D3 でもマイナスに見えた日は84日（24.8%）。日々の振れ（約3%）が2日分重なるため。7日の合計で比べると、どちらの比べ方でもマイナスは52週のうち2週、月の合計では0か月
- D1 と D2 で前年比の符号が逆になった日は153日

## 動かし方
```
pip install -r requirements.txt
cd src && python a603_yoy_compare_day.py
```
数秒で終わります。

## 確かめたこと
- 空のフォルダで流し直し、results・figures がバイト単位で一致した
- 7日の合計では、7日に各曜日が1回ずつ入るので、D1 と D2 の差がほぼ消えること

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 603）。作った日次売上は `results/daily_sales.csv`
- 仮定：曜日の倍率（月〜日）1.00・0.95・0.97・1.02・1.18・1.55・1.45、祝日は日曜と同じ、季節の波 ±8%、2025年は一律 +3%、日々の振れは対数正規（標準偏差0.03）

## 注意（言えないこと）
- 架空のデータ。実際の店の数字ではない
- 曜日の波が小さい業態では、同じ日付で比べてもずれは小さい。逆に、給料日や月末で動く業態では、同じ日付で比べるほうがよい場合もある
- 年末年始・お盆のように、日付で決まる行事は364日前と比べるとずれる。この記事の架空の店には入れていない
