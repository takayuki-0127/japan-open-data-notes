# F510 事前の計画（PLAN）

作成：2026-11-16 12:45（JST）。結果を集計する前に書いた。

## 問い
固定電話は、どれだけ減ったのか？ 減った分は、同じ市外局番の番号を使う IP 電話（0ABJ-IP 電話、いわゆる光回線の電話）に置き換わったのか。

## 知りたい人
家や会社の電話をどうするか考える人、通信の統計を読む人、「固定電話はもう使われていない」という話の大きさを確かめたい人。

## データ
- 総務省「情報通信統計データベース」
  - 加入電話及びISDNの加入数（1989年度末〜2026年6月末。全体とNTT東西。万加入）
  - IP電話利用数（050-IP と 0ABJ-IP。2003年12月末〜2026年6月末。万件。番号の数で、厳密な契約数ではない）
  - 携帯電話・PHSの加入契約数（単純合算。1988年度末〜2026年6月末）
- 令和8年版情報通信白書の図表のCSV（固定通信＝NTT東西の加入電話・ISDN、直収電話、CATV電話。2016〜2025年）。定義を変えた確かめに使う。
- 比べるのは毎年の年度末（3月末）。

### 取得前に見たもの（下見）
- 加入電話及びISDNの表は全部の行を目で見た（形を確かめるため）。全体の最高は1997年度末の6,284.9万、2025年度末は1,146.3万。前年同月比の減少率も表に載っていて、2007年度以降はおおむね −7〜−9% だった。
- 白書のCSV（固定通信・移動通信・0ABJ型IP電話・050型IP電話の2016〜2025年の値）も見た。0ABJ型IP電話は2022年の3,612万が最も大きく、その後わずかに減っていた。
- 0ABJ-IP 電話と加入電話を合わせた数、置き換わりの割合、NTT東西とそれ以外の比較、携帯電話との比較は計算していない。

## 仮説（外れの基準つき）
- H1（確認）：加入電話＋ISDN は、最高時から8割以上減った。外れ：減少が8割未満。※下見で値を見ているので、確認のための仮説。
- H2：0ABJ-IP 電話の増加は、0ABJ-IP の数が表に出る最初の年度末（2004年度末）から2025年度末までの、加入電話＋ISDN の減少の半分以上を埋めた。外れ：半分未満。
- H3：加入電話＋ISDN＋0ABJ-IP の合計（市外局番から始まる固定の番号）は、2025年度末で、その合計の最高時から2割以上減った。外れ：減少が2割未満。
- H4：加入電話＋ISDN の年度末の前年比は、2008〜2025年度のすべての年で −5% から −10% の範囲に入る（一定の率で減っている）。外れ：1年でもこの範囲の外。※一部の率は下見で見た。

## 手法
- 年度末の値をつなぎ、最高時からの減少率、半分になるまでの年数、前年比を出す。
- 置き換わりの割合＝0ABJ-IP の増加 ÷ 加入電話＋ISDN の減少（期間ごと）。
- 一定の率で減るとみなした当てはめ（対数の直線、2008〜2025年度）で年率を出す。将来の予測には使わない。
- 人口あたりの比較は携帯電話の表の普及率を使う。

## 頑健性（3つ以上）
1. 加入電話だけ（ISDN を除く）。
2. NTT東西だけ。
3. 白書の「固定通信」（直収電話・CATV電話を含む）で2016〜2025年を比べる。
4. 期間を変える（2008〜2016年度と2016〜2025年度）。
5. 年度末でなく12月末で比べる。

## 言えないこと（予想）
- 契約数（回線数）であって、通話の回数や時間ではない。
- 世帯が固定電話を持つ割合は、この表からは分からない（世帯と事業所が混ざっている）。
- 0ABJ-IP は「番号の数」で、契約数と同じではない。
- 減った理由（携帯への置き換え、料金、世帯の構成）はこのデータでは分けられない。
