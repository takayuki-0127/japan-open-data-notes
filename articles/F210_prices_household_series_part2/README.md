# F210 円安は品目の値段にどれだけ時間をかけて届き、物価の見通しは家計と企業でどれだけ違うのか？（後編）

看板記事 F210（深いシリーズE「物価と家計」の後編）のコード・データ・図です。前編は F209（`articles/F209_prices_household_series_part1`、note の下書き key：n3c4125d93928）。

## 前編の要点（3行）
- 2020→2025年の物価上昇（CPI 総合 +11.9%）の57%は食料で、財は+20.6%、サービスは+3.1%。上がったのはほぼ「モノ」
- 買う物の割合で計算し直すと、収入の低い20%の世帯は+15.5%、高い20%は+12.9%（差2.6ポイント）
- 値段が大きく上がった品目ほど買う量を減らした（価格弾力性 1年で −0.28、4年で −0.87）

## 問い
1. 円安は、どの品目の値段に、どれだけの時間をかけて届くのか（F102 の続編。F102 は「大きな円安のときだけ効くか」を総合で見た。ここでは品目と「届く速さ」を見る）
2. 物価の見通しは、家計と企業でどれだけ違い、どちらが実際に近いのか（F72 の続編。F72 は家計の見通しだけを推定した）
3. 物価のデータで言えること・言えないこと（シリーズEと、深いシリーズA〜Eのまとめ）

## 手法
**A 円安の届き方（局所射影）**
- h か月後までの値段の変化（対数×100、`y(t+h) − y(t−1)`）を、当月のドル円の変化に回帰（h = 0〜24）
- コントロール：ドル円と値段の前月比のラグ3、契約通貨の輸入物価（海外の価格の動き）の当月とラグ3、月ダミー、特殊な月のダミー（2019年10月 消費税、2020年4月 高等教育の無償化、2021年4月 携帯電話の通信料、2023年2月 電気・ガスの補助）
- ドル円そのものも同じ式で回帰し（1か月の1%円安は、12か月後も0.84%残る）、値段の反応 ÷ ドル円の反応を「パススルー率」（為替1%あたりの値段の変化 %）とした。標準誤差は HAC（ラグ h+1）
- 「届くまでの月数」：22〜24か月後の平均を行き着く先とし、その半分に初めて届いた月
- 品目：F209 の582品目のうち、欠けが少なく値が正の537品目。24か月後のパススルーの t 値が1.96を超えたものを「はっきり上がった品目」とした
- 数え方の確かめ：ドル円の変化を12か月のブロックごとに並べ替えた「偽の為替」で同じ計算を100回行い、偶然でも「はっきり上がった」と出る割合と比べた（140品目の標本）

**B 物価の見通し（四半期）**
- 短観の調査月（3・6・9・12月）にそろえて、家計（F72 の推定値）と企業（短観）の1年後の見通しを、その時点の CPI 総合の前年比、1年後に実際になった前年比と比べた
- 平均の外れ（見通し − 実際）、平均絶対誤差、「いまの物価がそのまま続く」とした場合との比較
- 見通しを「その時点の物価」と「1年後の実際の物価」に回帰（HAC、ラグ4）

## 主な結果

### A 円安の届き方

| 分類 | 12か月後のパススルー率（95%区間） | 24か月後 | 半分に届いた月 |
|---|---|---|---|
| 総合 | 0.12（0.02〜0.23） | 0.08（−0.08〜0.24） | 6か月 |
| 耐久消費財 | 0.24（0.08〜0.40） | 0.21（−0.01〜0.43） | 5か月 |
| 他の工業製品 | 0.16（0.01〜0.30） | 0.15（−0.08〜0.37） | 6か月 |
| 食料工業製品 | 0.19（−0.05〜0.42） | 0.22（−0.10〜0.55） | 9か月 |
| サービス | 0.02（−0.05〜0.08） | 0.03（−0.10〜0.16） | — |
| 石油製品 | −0.29（−1.00〜0.41） | −0.75（−1.40〜−0.10） | — |
| 電気・都市ガス・水道 | 0.35（−0.58〜1.28） | −0.27（−1.04〜0.51） | — |

- 1%の円安は、1年で総合の物価を約0.12%押し上げる（10%の円安なら約1.2%）。ただし24か月後の区間は0をまたぐ
- 届くのが速いのは耐久消費財（5か月）と他の工業製品（6か月）、加工食品（食料工業製品）は9か月。サービスにはほとんど届かない
- 石油製品と電気代はマイナスや不安定。2022年以降、円安の局面と燃料油・電気・ガスの補助金が重なったためと考えられる（推測）。この方法ではエネルギーへの届き方は測れない
- **品目**：537品目のうち、24か月後に「はっきり上がった」のは102品目（19%、重みでは13.5%）、「はっきり下がった」は9品目
  - 偽の為替では平均6%しか出ない（140品目の標本：実際23%、偽の為替の95%点17%、p=0.04）
  - 費目別：食料 39/208、被服及び履物 22/62、教養娯楽 16/71、家具・家事用品 10/43。光熱・水道は 0/6
  - はっきり上がった102品目が半分まで届いた月数：中央値9か月（25〜75%点 7〜11か月）
  - 上位：ロードサービス料、外国パック旅行費、冷凍調理コロッケ、煮干し、焼豚、電球、電気洗濯機、カレールウ、ソースなど
- 円安が届きやすい品目ほど、2020→2025年に値段が上がっていた（順位相関0.40）

### B 物価の見通し

| 期間 | 家計（1年後） | 企業（1年後） | 企業（5年後） | その時点の物価 | 1年後の実際 |
|---|---|---|---|---|---|
| 2014〜2021年 | 2.69% | 0.87% | 1.21% | 0.64% | 0.63% |
| 2022年〜 | 5.31% | 2.47% | 2.19% | 2.72% | 2.74% |
| 全期間（51四半期） | 3.67% | 1.47% | 1.57% | 1.42% | 1.30% |

- 1年後の実際と比べられる47四半期で、平均の外れは家計 +2.24ポイント（平均絶対誤差2.27）、企業 +0.07（0.80）。「いまの物価がそのまま続く」は0.07（1.11）
- 実際との相関は家計0.65、企業0.66でほぼ同じ。違うのは水準で、家計はいつも2ポイントほど高い
- 回帰：家計 = 2.19 + 0.65×（いまの物価）+ 0.35×（1年後の実際）。企業 = 0.55 + 0.43×（いま）+ 0.18×（1年後）。どちらも「いま」の係数が大きいが、1年後の実際の係数もプラスで0と区別できる
- 家計と企業の差は、物価が高い時期ほど広がる（差と、その時点の物価の相関0.62）
- 2026年9月：家計4.9%、企業 1年後2.6%・3年後2.6%・5年後2.5%、その時点の物価2.2%

## 頑健性
- **A 円安の届き方**（`results/A6_robustness.csv`）：起点を円ベースの輸入物価にする、契約通貨の輸入物価で調整しない、ラグ6、2015〜2021年だけ、2018年以降だけ。工業製品（耐久消費財・他の工業製品・食料工業製品）の24か月後のパススルーは、2015〜2021年だけの食料工業製品（−0.22、区間は非常に広い）を除いて0.10〜0.32の範囲。総合は0.07〜0.24。石油製品・電気は作り方で符号が入れ替わり、定まらない
- **品目の数え方**：偽の為替（ブロック並べ替え100回）と比べた（上記）
- **B 家計の見通しの推定法**：δ を0.25・1.0に固定、ロジスティック分布、「分からない」を0%として扱う。平均の外れは2.14〜2.26ポイントで変わらない
- **B 実際の物価の測り方**：生鮮食品を除く総合で比べても、家計 +2.33、企業 +0.16
- **B 企業の規模**：大企業 −0.24、中小企業 +0.23。2022年以降は大企業が実際より0.73低い

## 言えないこと
- **円安「だけ」の効果ではない**：海外の価格（契約通貨の輸入物価）と季節性、特殊な月は取り除いたが、同じ時期の人手不足・賃金・需要の変化、補助金や政策は取り除けていない。とくにエネルギーは補助金と重なっていて測れない
- **2015〜2026年の約11年分**：大きな円安の局面は2022年以降に集中していて、期間を切ると区間が大きく広がる。半分に届いた月数は点推定で、幅がある
- **品目の「はっきり上がった」には偶然も混ざる**：537品目を同時に見ているので、偽の為替でも6%程度は出る。個々の品目の順位はあまり信用できない
- **家計の見通しは推定値**：消費動向調査は「5%以上」「2〜5%」のような区分で答える。数値にするには分布の仮定が要る（F72）。水準は仮定で少し動くが、企業より大きく高いことは変わらない
- **「専門家」との比較はしていない**：設計では民間の予測（ESP フォーキャスト調査など）と比べる予定だったが、過去の分をまとめて取れる公開データがなかったため、短観の企業の見通しで代えた。企業の見通しは「物価全般」を答えたもので、CPI そのものの予測ではない
- **短観は四半期、標本は47四半期**：1年後の実際と比べられるのは2025年9月調査まで
- **どの見通しが「正しい」かの評価ではない**：家計の見通しが高いことは、家計が実際に感じる物価（よく買う物の値上がり、前編のとおり食料の割合が高い世帯ほど物価の上がり方が大きい）を映している可能性がある（推測）

## シリーズEのまとめ（前編＋後編）
- この5年の値上がりは、ほぼ「モノ」の値上がりで、食料が6割近く（前編）
- 円安は工業製品に半年ほどで届き、加工食品には9か月ほどかかる。サービスにはほとんど届かない（後編）
- 収入の低い世帯・高齢の世帯ほど物価が大きく上がり（前編）、家計の見通しは企業より2ポイントほど高い（後編）
- 家計は値上がりした品目の量を、時間をかけて減らしている（前編）

## 深いシリーズA〜Eのまとめ（F201〜F210）
| シリーズ | 1つの問いを最後まで詰めて分かったこと |
|---|---|
| A 最低賃金と働き方（F201・F202） | 効果は方法を変えても「はっきりしない」。原因は方法ではなく、県ごとの上げ幅の差が小さく、見分けられないこと |
| B 出生と結婚（F203・F204） | 出生率の低下の多くは結婚の減少から。支援策の効果は、前からの傾きを除くとはっきりしない |
| C 電力需要の予測（F205・F206） | 「いちばん良いモデル」は指標しだい。外れの値段と見張り方、合計と内訳のそろえ方が実務の差になる |
| D 地価・住宅（F207・F208） | 駅の効き方は比べ方しだいで10倍変わり、毎年の予測は同じ地点で外れ続ける |
| E 物価と家計（F209・F210） | 値上がりはモノ中心で、円安は工業製品に半年で届く。家計の見通しは企業より高い |

5つに共通するのは、「方法を1つ変えると答えがどれだけ動くか」を必ず見たことと、「見分けられない」を「効果がない」と書き分けたことです。
