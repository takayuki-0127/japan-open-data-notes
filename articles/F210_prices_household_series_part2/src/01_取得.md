# 01 取得

新しく取ったのは日本銀行の時系列統計データ（輸入物価・為替・短観の物価見通し）だけです。そのほかは前編 F209 と F72 のデータを `data/raw/` にコピーしています。

## 日本銀行 時系列統計データ（2026-11-06 取得）
この作業環境から日本銀行のサイトに直接つながらないため、ブラウザ（www.stat-search.boj.or.jp）のページの中で日本銀行の API を呼び、CSV にまとめました（`data/raw/boj_import_prices_fx_tankan.csv`）。

```
https://www.stat-search.boj.or.jp/api/v1/getDataCode?format=json&lang=jp&db=PR01&startDate=201001&endDate=202612&code=PRCG20_2600000000,PRCG20_2500000000,PRCG20_2600120001,...,PRCG20_2601020001
https://www.stat-search.boj.or.jp/api/v1/getDataCode?format=json&lang=jp&db=FM08&startDate=201001&endDate=202612&code=FXERM07
https://www.stat-search.boj.or.jp/api/v1/getDataCode?format=json&lang=jp&db=CO&startDate=201401&endDate=202604&code=TK99F0000204HCQ00000,TK99F0000204HCQ01000,TK99F0000204HCQ03000,TK99F0000205HCQ00000,TK99F0000206HCQ00000
```

| 系列 | コード |
|---|---|
| 輸入物価指数・円ベース 総平均／類別10 | PRCG20_2600000000、PRCG20_26xx20001 |
| 輸入物価指数・契約通貨ベース 総平均 | PRCG20_2500000000 |
| ドル円 スポット 17時時点・月中平均 | FXERM07 |
| 短観 物価全般の見通し（企業の物価見通しの平均）1年後・3年後・5年後（全規模全産業）、1年後（大企業・中小企業） | TK99F0000204HCQ00000 ほか |

短観の日付は「年＋四半期（01=3月調査 … 04=12月調査）」です。

## 前編・ほかの記事から使ったもの
- `cpi_items_monthly.csv.gz`・`cpi_items_meta.csv`・`cpi_gs_monthly.csv`・`cpi_gs_meta.csv`：F209（消費者物価指数 2020年基準、品目別と財・サービス分類、2015/1〜2026/9）
- `f209_item_contrib_2020_2025.csv`：F209 の品目別の寄与（10大費目・中分類の対応と、2020→2025年の値上がり）
- `f72_household_expectations.csv`：F72 の家計の予想インフレ率（消費動向調査の「1年後の物価の見通し」を Carlson–Parkin 法で数値にしたもの、二人以上の世帯、2004/4〜2026/9）と、その時点・1年後の CPI 前年比
