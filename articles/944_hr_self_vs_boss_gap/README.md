# 944 自己評価と上司評価のずれは、何を表しているのか？（人事評価）

自己評価と上司評価を並べると、「上司評価の低い人ほど自分を高く付けている」という形がよく見えます。これは「できない人ほど自分を高く見る」と読まれがちです。けれども、上司評価にもその年のぶれと上司の甘さが入っているので、上司評価で人を分けると、ぶれの分だけこの形が出ます。**ここでは、作成者が乱数で作った架空の会社の評価（本当の働き・本人の自己評価の癖・上司の甘さを作成者が置いたもの）で、ずれ（自己評価−上司評価）が何でできているか、どう分けるとどう見えるかを数えました。**

## 主な結果

### ずれの中身（基本の置き方、`results/a944_main.json` の base_200k）
| ずれをつくるもの | 1年のずれのばらつきのうちの割合（式） |
|---|---|
| 本人の自己評価の癖 | 14.0% |
| 上司の甘さ | 14.0% |
| 自己評価のその年のぶれ | 36.0% |
| 上司評価のその年のぶれ | 36.0% |

- **1年のずれのばらつきのうち、本人の癖で決まるのは14.0%だった**（置いた標準偏差からの式）。1年のずれと本人の癖の相関は0.376、上司の甘さとの相関は−0.376、本当の働きとの相関は0.0だった
- 本人の癖が0より上（自分を高めに付ける）の人は78.7%だが、1年のずれが0より上だったのは61.5%。1年のずれの向き（+か−か）が本人の癖の向きと違った人は34.5%いた
- 3年のずれの平均にすると、本人の癖との相関は0.521に上がった。年ごとのぶれは平均で薄まるが、同じ上司の甘さは3年とも残る
- 上司ごとに部下10人のずれを平均すると、上司の甘さとの相関は−0.788だった。部署ごとのずれの平均は、部下の癖より上司の甘さを映す

| 働きと無関係 | 別の上司の評価 | 0.193 | 0.194 | −0.001 |

- **本人の癖が働きと無関係でも、その年の上司評価で分けると、下位25%のずれは0.609点、上位25%は−0.216点で、差は0.825点あった**。本当の働きで分けると差は−0.003点で、形は出なかった
- 同じずれを自己評価で分けると、向きが逆になった（下位−上位が−0.822点）。分けた物差しのぶれが、ずれに入り込んでいるためで、物差しを変えると形が変わる
- 甘さもぶれも別の、別の上司の評価で分けると、癖が働きと無関係なら差は−0.001点で消えた。本当に「働きが低い人ほど高く見る」と置いた場合は0.283点で、本当の働きで分けた0.39点に近い形が残った。その年の上司評価で分けると1.099点で、本当の形より大きく見えた

## 注意（言えないこと）
- 架空のデータです。本人の癖・上司の甘さ・その年のぶれの大きさは作成者が置いたもので、ずれの中身の割合はこれで式どおりに決まります。上司評価で分けると形が出るのは平均への回帰と同じ仕組みで、新しく数えたのはその大きさと、別の評価で分けると消えることの確かめです
- 点は連続の値で置き、1〜5の段階に丸めていません。丸めると、上の端・下の端で点が頭打ちになり、ずれの形はさらに変わると推測します
- 本人の癖は年をまたいで変わらないと置きました。上司から返ってきた評価を見て、次の年の自己評価を変える人のことは入れていません
- 「本当の働き」は作成者が置いた物差しで、実際には誰にも分かりません。「別の上司の評価」は、甘さもぶれも独立な2つ目の評価を置いたもので、実際にそういう評価が手に入るとは限りません
- 誰の自己評価が正しいか、評価面談の進め方、給与・処遇の決め方については何も言えません
- 関連する記事：830 は、1年目に良かった選手が2年目に下がって見えること（同じ平均への回帰の仕組み）を扱っています。同じ企画の 940 は去年高かった人の点が下がって見えることを、933 は甘い評価者と辛い評価者の点の比べ方を扱っています。942 は評価と売上が「合う」ことを正しさと読めるかを、941 は部署の平均点の差が人の差か評価者の差かを扱っています。この記事は、2つの評価の「ずれ」を何で分けて読むかに絞りました
