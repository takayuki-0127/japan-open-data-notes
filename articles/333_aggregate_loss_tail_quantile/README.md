# 333 1年の損害の合計の「200年に1度」（99.5%点）は、近似でどこまで出せるのか

1年間の損害の合計は「事故の件数 × 1事故の損害額」の足し合わせです。その99.5%点（200年に1度の水準）を、正規近似・歪みを足した近似・シミュレーション・パンジャーの再帰式で出して、基準の値と比べたフォルダです。F260（100年に1度の損害は分布の仮定でいくら変わるか）が「1事故の大きさ」を扱ったのに対し、こちらは「件数と金額を掛け合わせた合計」の計算の仕方を比べます。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A333 | 合計の99.5%点は、近似でどこまで出せるか。契約が少ない（件数が少ない）・裾が重いとき、どれだけ外れるか | 事故件数はポアソン（平均10・100・1,000件）、損害額は平均1のガンマ／対数正規σ=1.0／対数正規σ=1.5 の9場面。基準は細かい目盛り（約210万点）での高速フーリエ変換による数値計算 | `src/a333_aggregate.py` |

## 主な結果（99.5%点の、基準からのずれ）
| 損害額の分布 | 件数 | 99.5%点÷平均 | 正規近似 | 歪みを足した近似 | ずらしたガンマ | シミュレーション1万年分の揺れ（RMSE） | 再帰式（目盛り＝平均の1/2／1/10／1/50） |
|---|---|---|---|---|---|---|---|
| ガンマ（変動係数1） | 10 | 2.42倍 | −11.1% | +0.5% | +0.4% | 1.3% | −0.87%／−0.04%／+0.04% |
| | 100 | 1.39倍 | −2.0% | +0.03% | +0.03% | 0.5% | −0.50%／0.00%／0.00% |
| | 1,000 | 1.12倍 | −0.25% | 0.00% | 0.00% | 0.2% | −0.89%／−0.04%／0.00%（分割） |
| 対数正規 σ=1.0 | 10 | 2.97倍 | −21.2% | +2.2% | +1.0% | 2.2% | −0.75%／−0.08%／−0.01% |
| | 100 | 1.50倍 | −4.9% | −0.26% | −0.29% | 0.8% | −0.19%／+0.01%／+0.01% |
| | 1,000 | 1.14倍 | −0.64% | −0.03% | −0.03% | 0.3% | −0.53%／+0.01%／0.00%（分割） |
| 対数正規 σ=1.5 | 10 | 5.68倍 | −38.3% | +110.5% | +32.4% | 4.3% | −0.60%／−0.07%／0.00% |
| | 100 | 2.24倍 | −19.9% | +17.8% | +12.3% | 2.4% | −1.11%／−0.04%／0.00% |
| | 1,000 | 1.32倍 | −5.3% | +1.1% | +1.0% | 0.7% | −2.02%／−0.07%／0.00%（分割） |

- **正規近似は、いつも小さく出る**。件数が10件で裾が重い場面では−38%、1,000件あっても裾が重ければ−5%
- **歪みを足した近似（NP近似）とずらしたガンマは、裾が軽ければよく合う**（ガンマ・対数正規σ=1.0 では±2.2%以内）。裾が重い対数正規σ=1.5 では逆に大きく出すぎる（10件で+110%・+32%）
- **シミュレーションは偏りが小さいが、回すたびに揺れる**。1万年分での揺れ（RMSE）は0.2〜4.3%、10万年分で0.07〜1.2%（10万年分は12回のくり返しなので粗い）
- **パンジャーの再帰式は、目盛りを平均の1/10にすれば±0.1%以内**、1/50でほぼ一致。平均の1/2では−0.2〜−2.0%
- **再帰式は、件数の平均が1,000だとそのままでは始められない**。出発点の確率 e^(−1000) が計算機の上で0になるため。件数を8等分（平均125件）して再帰式を回し、畳み込みで戻した
- 基準の確かめ：対数正規σ=1.0・100件の場面で、100万年分のシミュレーションとの差は−0.11%

## 動かし方
```
pip install -r requirements.txt
cd src && python a333_aggregate.py
```
`data/scenarios.csv`、`results/main.json`、`results/quantile_errors.csv`、`figures/` の3枚ができます（約4分、メモリ2GBほど）。

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures がバイト単位で一致した
- 基準（フーリエ変換）と、目盛りを細かくした再帰式・100万年分のシミュレーションが近い値になった

## 注意（言えないこと）
- すべて架空の分布です。誤差の大きさは、置いた分布と件数で決まります。対数正規σ=1.5 より裾が重い分布や、1事故の上限がある場合は試していません
- 事故件数はポアソンと置きました。年によって件数の出やすさが変わる場合（負の二項分布など）や、1つの出来事で多くの契約が同時に損害を受ける場合（自然災害）は扱っていません。その場合、合計の裾はもっと重くなります
- ここで比べたのは「分布が分かっているときの計算の仕方」だけです。実際には分布そのものが不確かで、その影響のほうが大きいことがあります（F260・F288・331）
- 「基準」も数値計算です。目盛りの幅（約0.002〜0.006）と計算の範囲の分だけの誤差があります
- 保険会社の資本やリスク管理の水準について助言するものではありません
