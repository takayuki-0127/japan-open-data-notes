# 768 強く相関する変数があるとき、部分依存の図はどれだけ本当の効き方とずれるのか（手法の解説・正解の分かるデータで試す）

部分依存（PD）は、ある変数だけを決めた値に置きかえ、ほかの変数はデータのままにして予測の平均を出す図です。変数どうしが強く相関していると、データにほとんどない組み合わせ（x1 が大きいのに x2 が小さい、など）でも予測を出すことになります。ALE（累積局所効果）は、データのある近くだけで少しずつ動かした差を積み上げる方法です。**ここでは、本当の効き方が分かる架空のデータで、x1 と x2 の相関を0〜0.95に変え、PD と ALE がどれだけ本当の曲線からずれるかを比べました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A768 | 相関が強いと、PD と ALE はどれだけずれるか | x1・x2 は標準正規で相関 ρ＝0〜0.95、y＝x1＋2·sin(2·x2)＋N(0, 0.5²)、2,000件。HistGradientBoosting（200回、学習率0.1）で学習し、−2〜2の21点で PD と ALE（40区間）を出す。平均を0にそろえた曲線の RMSE で比べる。各ρ5回。seed 768 | `src/a768_pdp.py` |

## 主な結果

| x1 と x2 の相関 | PD のずれ（x2） | ALE のずれ（x2） | PD のずれ（x1） | ALE のずれ（x1） | データから遠い組 |
|---|---|---|---|---|---|
| 0 | 0.13 | 0.14 | 0.10 | 0.10 | 1% |
| 0.5 | 0.15 | 0.13 | 0.13 | 0.12 | 5% |
| 0.8 | 0.41 | 0.13 | 0.32 | 0.12 | 18% |
| 0.9 | 0.57 | 0.14 | 0.47 | 0.10 | 34% |
| 0.95 | **0.75** | **0.19** | **0.67** | 0.11 | **46%** |

- 相関が0〜0.5なら、PD も ALE も本当の曲線とほぼ同じだった（ずれ0.10〜0.15。x2 の効きの振れ幅は±2）
- 相関0.95では、PD のずれは x2 で0.75、x1 で0.67になった。ALE は0.19と0.11で、相関が0のときとあまり変わらなかった
- 相関0.95では、PD が予測に使う組の46%が、近くに学習データのない組だった（最も近い学習点まで0.3より遠い）

## 動かし方
```
pip install -r requirements.txt
cd src && python a768_pdp.py
```
40秒ほどで終わります。

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- 相関0では PD と ALE がどちらも本当の曲線に近いこと（ずれ0.10〜0.14）

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 768）

## 注意（言えないこと）
- 架空のデータです。関係の形（直線と sin）と相関の強さは作成者が置いたもので、ずれの大きさはこれで決まります
- PD のずれは、モデルがデータのない所をどう埋めるかで変わります。勾配ブースティング以外のモデルでは別の大きさになります
- ALE は「その近くで動かしたときの効き」を表します。相関の強い2つの変数の効きを、どちらのものかはっきり分ける方法ではありません
- 「データから遠い組」の基準（距離0.3）は作成者が決めたものです
