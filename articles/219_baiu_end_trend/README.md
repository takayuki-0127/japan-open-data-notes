# 219 梅雨明けは早まっているのか？ 地方別の長期トレンド

気象庁「過去の梅雨入りと梅雨明け」（確定値）の12地方・1951〜2026年の梅雨入り・梅雨明けの日付に、Mann-Kendall検定とTheil-Sen推定を当てて、長期の傾向があるかを見たフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A219 | 梅雨明けは早まっているのか。梅雨入りや梅雨の長さはどうか | 日付を1月1日からの日数にして、地方ごとにMann-Kendall検定（年とのKendallの順位相関）とTheil-Sen推定の傾き（10年あたり日数、95%信頼区間）。前半（1951〜88年）と後半（1989〜2026年）の平均と標準偏差 | `src/a219_baiu_trend.py` |

## 主な結果
- 梅雨明けの日付は、12地方のどこでも5%水準で有意な傾向がない。Theil-Sen推定の傾きは10年あたり0.0〜+0.8日で、早まる向きの地方はない（いちばん大きいのは東北南部の+0.8日、p=0.06）
- 2025年の梅雨明けは、沖縄・奄美・九州北部・四国・中国・近畿・北陸・関東甲信の8地方で1951年以降いちばん早かった（関東甲信は6月28日ごろ）。それでも76年の傾向としては、梅雨明けが早まったとは言えない
- 梅雨入りは東海で10年あたり−1.0日（p=0.047）と早まる傾向。関東甲信も−0.5日（p=0.055）。東海の梅雨入りの平均は、前半の6月10日ごろから後半の6月6日ごろに
- 梅雨明けを「特定しない」年は26地方・年あり、すべて1993年以降（1993年は10地方、東北北部は計8回）。特定しない年は計算から外している
- 年ごとのばらつき（標準偏差）は、北陸で前半6.7日→後半10.0日、関東甲信で7.5日→9.0日と大きくなった

## 動かし方
```
pip install -r requirements.txt
cd src && python a219_baiu_trend.py
```

## データ
- `data/baiu_onset_end_1951_2026.csv`：地方・年ごとの梅雨入り・梅雨明け（確定値、「〜日ごろ」の日付）。`*_doy` は1月1日を1とする日数（うるう年も平年の暦で数えた）。特定しない年は空欄
- `results/trend_by_region.csv`：地方別のMann-Kendall検定・Theil-Sen推定の結果（梅雨入り・梅雨明け・梅雨の長さ）
- `results/halves_by_region.csv`：前半・後半の平均と標準偏差

## 注意
- 梅雨入り・梅雨明けは、天気の推移から気象庁が判断する「〜日ごろ」の日付で、5日程度の移り変わりの期間があります。毎年9月ごろに春から夏の天候を振り返って確定値を決めていて、速報の日付とは違う年があります
- 「特定しない」年を外しているため、梅雨明けがはっきりしない年（多くは冷夏の年）が抜けています。東北では、この欠けが結果に影響している可能性があります
- 地方の境界や名前は気象庁の区分です（九州北部は山口県を含む）
