# F373 PLAN（事前の計画）：「魚より肉」は、いつ逆転し、世帯主の年齢でどう違うのか？

作成：2026-11-16 14:50（データを取得し、表の形を確かめたあと、逆転の年や年齢別の比を計算する前に書いた）

## 問い
家庭の食卓で「魚より肉」が進んだと言われます。家計調査では、生鮮魚介と生鮮肉への支出がいつ逆転したのか、量（g）で見るとどうか、世帯主の年齢によって逆転の時期がどう違うのかを確かめます。

知りたいこと：全国（二人以上の世帯）で、金額と数量のそれぞれで、生鮮肉が生鮮魚介を上回ったのはいつか。世帯主の年齢別に、2013〜2025年のどこで逆転したか（またはまだか）。年齢による差は縮まっているのか。

知りたい人：食品の小売り・水産・食肉の担当、家計の統計を読む人。

既存の看板記事との違い：jodn の F47 は品目の地域の組み合わせの分解で、魚と肉の逆転や年齢は扱っていない。existing_F_titles.txt と jodn の README を「魚」「肉」「生鮮魚介」「生鮮肉」で検索して、同じ問いの記事はなかった。

## データ
- 総務省「家計調査」家計収支編 二人以上の世帯 年報の品目別表 2013〜2024年の各年（食料「魚介類」、食料「肉類～乳卵類」）。各年の世帯主の年齢階級別（29歳以下〜70歳以上の6つ）の生鮮魚介・生鮮肉の支出金額と購入数量（g）、時系列（1991〜2024年。1999年以前は農林漁家世帯を除く値）。
- 同 2025年 第4-6表 世帯主の年齢階級別（二人以上の世帯）。

## 取得前に見たもの（開示）
- 表の形を確かめるときに、2025年の平均の生鮮魚介（41,089円、17,792g）と生鮮肉（83,265円、50,618g）の値を目にした。2025年の時点で肉が魚の2倍前後であることは知っている。年齢別の値、各年の値、逆転の年は見ていない。

## 仮説と「外れ」の基準
- H1：全国で、金額の逆転（生鮮肉＞生鮮魚介になった最初の年で、その後に戻らない）は2008〜2013年の間。外れなら外れ。
- H2：数量の逆転は、金額の逆転より5年以上早い。5年未満の差、または遅ければ外れ。
- H3：2013年には、70歳以上の世帯では金額でまだ魚が肉を上回っていて、70歳以上の逆転は2014〜2025年のどこかで起きた。2013年にすでに肉が上、または2025年もまだ魚が上なら外れ。
- H4：2013→2025年の「肉÷魚」（金額）の上がり幅は、70歳以上のほうが29歳以下より大きい（年齢の差が縮まっている）。小さければ外れ。

## 手法
- 年報の時系列から、全国の生鮮魚介・生鮮肉の金額と数量を1991〜2025年で並べ、「肉÷魚」の比が1を超えた年を探す。
- 各年の年齢別の表から、年齢別の「肉÷魚」（金額・数量）を2013〜2025年で並べる。
- 年齢別の逆転の年は、比が1を超え、その後に戻らない最初の年とする。

## 頑健性（3つ以上）
1. 生鮮魚介の代わりに鮮魚（貝類などを除く）で H1・H3 を見る。
2. 年齢別の比を3年移動平均にして H3 の逆転の年を見る（標本の振れ）。
3. 1999年以前の農林漁家を除く時系列と、2000年以降の含む時系列の段差を確かめる（2000年の2つの値の比較）。
4. H4 を数量で見る。

## 問い直し（予定）
結果を見てから1つ足す。候補：同じ生まれの世代を10年追うと、「肉÷魚」は上がるのか（年を取ると魚に寄るのか、世代の好みのままか）。

## 言えないこと（予定）
- 家で食べる分の購入で、外食や弁当・総菜の中の魚・肉は入っていない。
- 世帯主の年齢で分けた世帯の購入で、1人ひとりの食べる量ではない。
- 金額の逆転には値段の動きが入る（数量で補う）。
- 2002年から食料の数量の調べ方が変わり、2018年に家計簿が改正されている。
- 年齢別の表は2013年からしかそろえていないので、若い世代の逆転の年は分からない。
