# 291 父親の年齢は、母親より速く上がっているのか

厚生労働省「人口動態統計」確定数（2025年）上巻 4-19（出生順位別 母の平均年齢）、4-20（出生順位別 父の平均年齢）、4-22（第1子出生までの父母の結婚期間）を使ったフォルダです（全国の集計のみ）。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A291 | 子が生まれたときの父の平均年齢は、母より速く上がっているのか | 父と母の平均年齢を出生順位ごとに並べ、差（父−母）と10年あたりの上がり方を比べた。第1子については、母の平均年齢の上がり分を、結婚から第1子までの平均期間の延びと、それ以外に近似で分けた | `src/a291_parent_age_gap.py` |

## 主な結果
- 第1子が生まれたときの平均年齢は、1975年に父28.3歳・母25.7歳、2025年に父32.8歳・母31.0歳でした。50年で父は4.5歳、母は5.3歳上がり、上がり方は母のほうが大きい。
- 父と母の差（第1子）は、1985年の2.9歳が最大で、1995年2.5歳、2005年2.0歳、2025年1.8歳と縮みました。第2子・第3子・全体でも、2025年はどれも1.8歳です。
- 10年あたりの上がり方（第1子）は、1975〜1995年が母0.90歳・父0.85歳、1995〜2015年が母1.60歳・父1.35歳、2015〜2025年が母0.30歳・父0.10歳。どの期間も母のほうが速く上がりました。1996〜2025年の毎年の変化で見ても、父が母より大きく上がった年は6年、母のほうが大きかった年は14年（残りは同じ）です。
- 第1子の父の平均年齢は、2016年からは32.8〜33.0歳でほぼ止まっています。
- 結婚してから第1子が生まれるまでの平均期間（嫡出の第1子）は、1975年1.55年、2000年1.89年、2025年2.88年。1年未満は39%から19%に、3年以上は10%から39%に変わりました。
- 1975〜2025年の母の第1子の平均年齢の上がり（5.3歳）のうち、結婚から第1子までの期間の延び（1.33年）にあたるのは約4分の1でした（近似）。2015〜2025年は期間が0.47年延びたのに対し、平均年齢は0.3歳しか上がっていません（推測：結婚の年齢はこの10年でほとんど上がっていない）。

## 頑健性
- 父母の差は、第1子・第2子・第3子・全体のどれで見ても、1990年代後半から縮む形
- 1991年までは満年齢に0.5歳を足した平均、1992年からは日齢からの平均で、計算のしかたが変わっています。差（父−母）は同じ方法どうしの差なので、この変更の影響は小さいと考えています（推測）
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致した

## データ

- いずれも e-Stat「人口動態調査 人口動態統計 確定数 出生」（2025年、2026-09-30公表）を2026-11-12に取得したもの（cp932）

## 注意
- 父の平均年齢は、父の年齢が分かる出生で計算されていると考えられます（推測）。嫡出でない子の多くは含まれていない可能性があります
- 結婚期間の表は嫡出の第1子だけで、母の平均年齢の表（すべての第1子）とは対象が少し違います。分け方は近似です
- 平均の比較なので、年齢差の大きい夫婦・小さい夫婦の分布の変化は分かりません
- 第1子を産む母の年齢の分布は記事 290 で扱っています
