# 255 野菜の作付けは、どの品目で減ったのか

農林水産省「作物統計調査（野菜生産出荷統計）」の品目別作付面積・収穫量の累年統計（全国、1973〜2024年）を使ったフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A255 | 野菜の作付けは、どの品目で減ったのか。増えた品目はあるか | 1973年から毎年全国の値がある27品目の1973→2024年の倍率と、減った面積への寄与。2005年から値がある39品目の2005→2024年の倍率（作付面積と収穫量）。季節区分（春・夏・秋冬など）は使わず、品目の計だけを使う | `src/a255_vegetable_area.py` |

## 主な結果
- 27品目の作付面積の合計は、70.4万ha（1973年）→37.3万ha（2024年）で0.53倍。収穫量の合計は0.63倍で、面積ほどは減っていない
- 27品目中25品目で減った。増えたのはレタス（11,900→19,300ha、1.62倍）とえだまめ（10,600→11,900ha、1.12倍）だけ
- 減り方が大きいのは、さやえんどう0.21倍、すいか0.22倍、さといも0.28倍、なす0.30倍、きゅうり0.32倍
- 減った面積33.0万haのうち、ばれいしょ（−7.6万ha、23%）、だいこん（−4.9万ha、15%）、すいか（−3.0万ha、9%）、はくさい（−3.0万ha、9%）の4品目で56%
- 分類別（1973→2024年）：果実的野菜（いちご・すいか）0.25倍、根菜類0.45倍、果菜類0.54倍、葉茎菜類0.74倍
- 2005→2024年（39品目）：合計51.2万ha→42.0万ha（0.82倍）。面積が増えたのはブロッコリー1.62倍、こまつな1.32倍、にんにく1.30倍、たまねぎ1.09倍の4品目。ブロッコリーは1989年の8,150haから2024年は17,300ha

## 頑健性
- 端の1年ではなく3年平均（1973〜75年 → 2022〜24年）で比べても、27品目の合計は0.55倍、増えたのはレタスとえだまめだけで、減り方の大きい順もさやえんどう・すいか・さといも・なすが上位
- 2005→2024年は面積と収穫量の両方を並べた。にんにくは面積1.30倍に対して収穫量0.96倍、しょうがは面積0.84倍に対して収穫量1.04倍など、品目によっては面積と量で向きが違う
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致した

## 注意
- 野菜生産出荷統計の全国値は、品目によって調べ始めた年が違う（こまつな・ちんげんさいなどは2002年から、ブロッコリーは1989年から、メロンは1982年から）。そのため、1973年からの比較は27品目に限った
- ばれいしょ（じゃがいも）は加工用・でん粉用も含む全体の面積。野菜の作付けの減りの中では、ばれいしょの寄与がいちばん大きい
- 作付面積の減りは「野菜を食べなくなった」ことと同じではない。輸入、10a当たり収量の伸び、加工・業務用への切り替えなどが入っている
- 面積が減った理由（担い手の高齢化、転作、ハウスへの切り替えなど）は、このデータでは分からない
