# 619 外れ値が混ざったデータで、ふつうの回帰と Huber の回帰では、係数はどれだけ違うのか（手法の解説・正解の分かるデータで試す）

外れ値に強い回帰として、Huber の回帰（大きな残差の点の重みを下げる方法）がよく紹介されます。**ここでは、本当の関係が y = 1 + 2x の架空のデータ（200件）に、外れ値を 0〜20% 混ぜ、ふつうの回帰（OLS）・Huber の回帰・「残差が3を超える点を除いた OLS」の3つで、傾きがどれだけずれ、どれだけ振れるかを数えました。** 外れ値は2種類で、x はふつうで y だけ大きい「縦の外れ値」と、x が離れた位置にある「てこの外れ値」です。各条件500回くり返しています。数字は置いた外れ値の作り方で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A619 | 外れ値の種類と割合で、OLS・Huber・除外 OLS の傾きはどう変わるか | statsmodels の OLS と RLM（HuberT、c=1.345）、内部スチューデント化残差の絶対値が3を超える点を除いた OLS。200件、外れ値 0・1・5・10・20%、各500回、seed 619 | `src/a619_huber_ols.py` |

## 主な結果
- **外れ値なし**：3つとも傾きの平均は 2.00。標準偏差は OLS 0.070、Huber 0.072（Huber の効率は OLS の 92%）
- **縦の外れ値（y に +15）**：傾きの平均はどの方法もほぼ 2.00（x と関係なく混ざるので、ずれは切片に出る）。ただ傾きの標準偏差は、20% で OLS 0.433 に対し **Huber 0.133**。除外 OLS は 5% まで 0.071 と良いが、10% で 0.393、20% で 0.433 と OLS と同じになった（外れ値が多いと残差の標準偏差がふくらみ、どの点も「3」を超えなくなる）
- **てこの外れ値（x が 4〜6、y が −8 前後）**：1% で OLS の傾きは 1.23、**Huber は 1.92**、除外 OLS は 2.01。5% で OLS −0.12、Huber 1.49、除外 OLS 0.24。**10% では Huber も −0.61** と、3つとも符号が逆になった
- てこの外れ値は、線を自分のほうへ引き寄せて残差が小さくなるので、残差で重みを決める Huber や残差で除く方法では見つけにくい
