# 1251 読み放題のページ数は、文字の大きさや図の多さでどれだけ変わるのか？（電子書籍）

電子書籍の読み放題では、「読まれたページ数」で本の読まれ方を見ることがあります。ところが電子書籍には紙のような決まったページがありません。めくった画面の数で数えれば、読者が文字を大きくするほど1画面に入る字が減り、同じ中身でもページが増えます。文字の大きさによらない「標準のページ」（決まった字数で1ページ）で数えても、図1枚を何ページと数えるかの決まりで、図の多い本のページ数が変わります。**ここでは、作成者が置いた架空の電子書籍8冊（字数と図の数を作成者が決めたもの）と、架空の読者（端末の文字の大きさと、どこまで読んだかを乱数で決めたもの）で、①最後まで読んだときのページ数が文字の大きさと図の数でどれだけ変わるか、②1人あたりの読まれたページ数で8冊を並べると、本当に読まれた分量の順とどれだけ逆になるかを数えました。文字の大きさの割合の本ごとの差・図1枚の本当の重さ・読んだ割合の本ごとの差を変えた27通りでも確かめました。**

例の本・読者・ページの数え方は架空のもので、実在の読み放題のサービスのページの数え方や、支払いの決まりを表すものではありません。本の作り方（文字の量や図の数）や値段・広告の決め方の助言はしていません。

関連する記事：968「文字数の数え方（文字・バイト・単語）で、何が変わるのか？」は、同じ文の長さが数え方で違う順に並ぶことを、文章の文字の数え方で扱っています。1247「読み放題で読まれたページ数から、最後まで読んだ人の数はどこまで分かるのか？」は、1ページは本のどこでも同じ量と置いたうえで、読まれたページ数の合計から最後まで読んだ人の数がどこまで分かるかを扱っています。この記事は、電子書籍の「ページ」に固有の、読者の文字の大きさと図の数え方で変わる点に絞ります。

## 主な結果

### 最後まで読んだときのページ数（式どおり、`results/full_read_pages.csv`）
| 本 | 字数 | 図 | 画面のページ（文字の大きさ1・小） | 画面のページ（大きさ5・大） | 5÷1 | 標準（図1枚＝0.25ページ） | 標準（図1枚＝1ページ） | 標準（図1枚＝2ページ） |
|---|---|---|---|---|---|---|---|---|
| A | 90,000 | 0 | 100 | 360 | 3.6倍 | 180 | 180 | 180 |
| D | 60,000 | 20 | 86.67 | 260 | 2.9999倍 | 125 | 140 | 160 |
| E | 50,000 | 40 | 95.56 | 240 | 2.5115倍 | 110 | 140 | 180 |
| H | 35,000 | 120 | 158.89 | 260 | 1.6364倍 | 100 | 190 | 310 |

- **同じ1冊を最後まで読んでも、画面のページは文字の大きさで1.6364〜3.6倍違った（式どおり）**。図は文字の大きさによらず1画面と置いたので、図の多い本ほど倍率は小さい
- 標準のページでは、図のない本Aは図の数え方によらず180ページだが、図120枚の本Hは図1枚を0.25ページと数えると100ページ、2ページと数えると310ページになった（式どおり）

### 1人あたりのページ数で8冊を並べると（基本の置き方、200回、`results/a1251_main.json` の `headline`）
| 数え方 | 本当の読まれた分量と順が逆の組（28組中、平均） | 範囲 | 1位が当たった割合 |
|---|---|---|---|
| 画面のページ | **2.68組** | 0〜10組 | 69% |
| 標準のページ（図1枚＝0.25ページ） | **7.96組** | 2〜17組 | 38.5% |
| 標準のページ（図1枚＝1ページ） | 0組 | 0〜0組 | 100% |
| 標準のページ（図1枚＝2ページ） | 5.5組 | 1〜14組 | 53.5% |

- 標準のページ（図1枚＝1ページ）が0組なのは、本当の分量を「図1枚＝500字分」と置き、500字で1ページとしたためで、作りどおり
- 画面のページでは、200回の91.5%で少なくとも1組が逆になった。読まれた分量1万字分あたりの画面のページは、図のない本Aで10〜90%が19.91〜25.69ページ（最小18.14・最大28.74）と、読者の文字の大きさの割合しだいで動いた（`results/pages_per_10k_amount.csv`）。本ごとの「大きい文字（4・5）の読者の割合」と「1万字分あたりの画面のページ」の相関は、200回の平均で0.7584だった
- 図1枚を0.25ページと軽く数えると、1万字分あたりのページは図のない本Aの20に対し、図120枚の本Hで10.53と、図の多い本ほど少なく数えられた。2ページと重く数えると本Hは32.63になった

### 確かめ：27通り（各50回、`results/grid.csv`）
- 逆になった組の平均は、画面のページで1.04〜10.42組、標準のページ（図1枚＝0.25ページ）で1.9〜20.64組、（1ページ）で0〜9.34組、（2ページ）で0〜17.1組だった
- **どの数え方の逆がいちばん少ないかは、図1枚の本当の重さの置き方で決まった**。250字分なら図1枚＝0.25ページ、500字分なら1ページ、1,000字分なら2ページ（重さが数え方とちょうど合うときは0組、作りどおり）
- 画面のページの逆は、本ごとの読んだ割合の差が小さいほど多かった（平均の幅0.5〜0.6で3.1〜10.42組、0.2〜0.9で1.04〜4.78組）。本どうしの本当の差が小さいと、文字の大きさの割合の違いで順が入れかわりやすい

## 動かし方
```
pip install -r requirements.txt
cd src && python a1251_pages_font_figures.py
```
5秒ほどで終わります。`data/books.csv` と `data/readers_one_set.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の10ファイルがバイト単位で一致した（cmp、約4.4秒）
- 最後まで読んだときのページ数が、字数÷1画面の字数＋図の数（画面のページ）、字数÷500＋図の数×重さ（標準のページ）の式どおりであること、標準のページ（図1枚＝1ページ）が基本の置き方で200回すべて逆0組であること（作りどおり）を確かめた
- 図3枚を開き、日本語・重なり・軸（棒グラフの縦軸は0から）を確かめた

- `results/full_read_pages.csv`：最後まで読んだときのページ数（`screen_font1`〜`5` は画面のページ、`std_w0.25` などは標準のページ、`amount_10k` は本当の分量（万字分））
- `results/pages_per_10k_amount.csv`：読まれた分量1万字分あたりのページ（200回の平均・10%・90%）

## 注意（言えないこと）
- 架空のデータと、作成者が置いたページの数え方です。実在の読み放題のサービスが、ページをどう数えているかを表すものではありません
- 「本当の読まれた分量」は、作成者が図1枚を500字分と置いて作った物差しです。図1枚の重さをどう見るのが正しいかは、この記事では決められません。確かめでは、置いた重さとちょうど合う数え方がいちばん逆が少なくなりました（作りどおり）
- 図は本の中に均等にあり、読者は前から順に読むと置きました。図の多い章だけ飛ばす読み方や、読み返しは入れていません
- 1画面の字数は文字の大きさだけで決まると置きました。端末の画面の大きさ・行の間隔・図の大きさの違いは入れていません
- 本ごとの読者の文字の大きさの割合の違いは乱数で置いたもので、どんな本で大きい文字の読者が多いかは扱っていません
