# F200 200本の看板記事で使ったデータと手法は、どうつながっているか？ 197本の README を記事×手法×データのネットワークにする

看板記事 F200。これまでに作った看板記事 F01〜F199 のうち、このリポジトリにフォルダがある197本（F24・F30 は形式が違うため対象外）の README から、「どの手法を使ったか」と「どのデータを使ったか」を辞書で取り出し、記事×手法×データのつながりとして整理した。

F124（データの系譜図）の続編で、F124 が「データの側」を見たのに対し、ここでは **手法の側** を中心にする。F122（作業ログのつまずき）、F125（結論の強さ）、F162（データの取り方）、F163（頑健性チェックの効き目）、F165（再現チェック）とは重ならないよう、「どの手法を、どのデータと、どの時期に組み合わせたか」だけを扱う。

## 問い

- 197本で、どの手法を何本の記事で使ったか。少数の手法に集中しているか
- 手法とデータの組み合わせで、よく使ったもの・見込みがあるのに一度も使っていないものはどこか
- 同じ記事で一緒に使われる手法は、手法の区分の中でまとまっているか、区分をまたいでいるか
- 新しい手法は、記事の番号が進むにつれてどう出てきたか。主な手法の区分は時期で変わったか

## データ

- 看板記事 F01〜F199 の README（`articles/F*/README.md`、197本）。コミット `de38ce51a03d811f05262a534e9c6662545f1d90`（2026-11-05 時点の main、F199 まで）に固定して取得した
- 見出し「## 手法」（ない記事は「## 方法」）、「## データ」「## 出典」の本文と題名を `data/readme_sections.json` に保存した（F118 は手法の節がないため、題名と冒頭1,500字を使った）
- 新しく外部のデータは取っていない

## 手法

1. **取り出し**（`src/01_取得.py`）：README を見出しで区切る
2. **手法とデータの辞書**（`src/02_整形.py`、`data/dictionaries.json`）
   - 手法：95の細かい区分を、13の粗い区分（因果推論、回帰・GLM、時系列、機械学習・予測、ベイズ・階層、空間統計、分類・次元削減、分解・指標、生存・人口、シミュレーション・最適化、統計の作法・検定、テキスト・データ工学、分布・極値）にまとめ、表記ゆれを含む正規表現で当てた
   - 主の取り出しは **題名＋手法の節**。比較用に「README 全体（出典・関連記事の行を除く）」と「題名だけ」でも同じ辞書を当てた
   - データ：F124 の53区分に、F121 以降で増えたデータ（建築着工、自動車保有、航空輸送、宅配便、労働災害、社会生活基本調査、夜間光など）を足した59区分・11グループ。「データ」「出典」の節と題名に当てた
   - どの手法にも添えて使う5つ（標本誤差・不確かさ、ブートストラップ、置換検定、モンテカルロ・擬似データ、交差検証・予測の評価）は「道具」として分けて数えた
3. **主な区分**：1記事に1つの「主な区分」を、2通りで決めた
   - 辞書：題名に出た手法を3点、手法の節に出た手法を1点として、道具を除いていちばん点の高い区分
   - 手作業：197本の題名と手法の節を読んで1つ決めた（`data/manual_primary_family.csv`）
4. **集計**（`src/03_分析.py`）
   - 手法ごとの記事の数、上位への集中
   - 手法の区分×データのグループの表。独立なときの見込み（区分を使った記事の数×グループを使った記事の数÷197）と比べ、「見込みが3本以上なのに0本」を「使われていない組み合わせ」とした
   - 同じ記事で2本以上一緒に使った手法どうしをつなぐネットワーク（networkx）。媒介中心性、コミュニティ（貪欲法のモジュラリティ最大化）、同じ区分どうしの線の割合（区分のラベルを2,000回並べ替えた基準と比較）
   - 番号帯（F01〜40、41〜80、81〜120、121〜160、161〜199）ごとの新しい手法の数と、手作業の主な区分の割合（Fisher の正確検定）
5. **図**（`src/04_図.py`）

### 1. いちばん多く使ったのは「道具」。主な手法では固定効果パネル（30本）と勾配ブースティング（21本）

|---|---|

| ブートストラップ（道具） | 46本 |
| 固定効果パネル | 30本 |
| モンテカルロ・擬似データ（道具） | 25本 |
| 勾配ブースティング | 21本 |
| 合成指標・重みづけ | 16本 |
| 交差検証・予測の評価（道具） | 16本 |
| 置換検定（道具） | 16本 |
| ポアソン・負の二項・PPML | 13本 |

- 辞書の95区分のうち94区分が、少なくとも1本で使われていた。1本でしか使っていない手法は17、2本以下は34
- 1本の記事で使った手法は平均3.0（中央値3）、道具を除くと2.2
- 道具のどれかを使った記事は114本（58%）
- 上位10の手法で、つながり（記事×手法）の42%を占めた（道具を除いた上位10では34%）

### 2. 手法の区分×データのグループでは、偏った組み合わせと、見込みがあるのに0本の組み合わせがあった

- 見込みより多かった組み合わせ（5本以上）：時系列×景気・金融（18本、見込み6.5本）、機械学習・予測×住宅・交通（15本、4.9本）、空間統計×地理・気象（10本、3.4本）、生存・人口×産業・企業（8本、2.0本）
- 見込みが3本以上なのに0本：分解・指標×文章・メタ（見込み5.6本）、機械学習・予測×物価・家計（5.1本）、時系列×文章・メタ（5.0本）、テキスト・データ工学×人口（4.4本）
- 143のマスのうち0本は20
- 細かい手法×細かいデータでは、ありうる5,546の組み合わせのうち使ったのは867（16%）

### 3. 一緒に使う手法は、区分をまたいでつながっていた

- 2本以上の記事で一緒に使った手法どうしの線は162本（94手法のうち63手法がどこかとつながり、31は孤立）
- 同じ区分どうしの線は20%で、区分のラベルを並べ替えた基準（8%）より多い（p&lt;0.001）。ただ、8割の線は区分をまたいでいた
- 媒介中心性が高いのは、ブートストラップ（0.117）、標本誤差・不確かさ（0.109）、固定効果パネル（0.098）。道具と固定効果パネルが、ほかの区分どうしをつなぐ役になっていた
- 道具を除いてよく一緒に使ったのは、勾配ブースティング×特徴量の寄与（7本）、固定効果パネル×差の差（5本）、固定効果パネル×空間回帰（4本）、コンフォーマル×勾配ブースティング（4本）
- 2手法以上のコミュニティは6つで、大きい3つ（20・20・14手法）はそれぞれ7〜9区分にまたがった（モジュラリティ0.35）

### 4. 新しい手法は最初の40本で6割が出そろい、後半は主な区分が入れ替わった

- 初めて出てきた手法の数：F01〜40 で57、F41〜80 で19、F81〜120 で9、F121〜160 で4、F161〜199 で5
- F161 以降で初めて出てきたのは、極値理論・コピュラ・組成データ・円周統計・頑健回帰（影響度）の5つ
- 手作業の主な区分で見ると：
  - 因果推論：F01〜40 で10/38本、F41 以降は11/159本（Fisher p=0.002）
  - ベイズ・階層：F01〜40 で3/38本、F41 以降は0本（p=0.007）
  - 分布・極値：F160 までで3/158本、F161 以降は7/39本（p&lt;0.001）
  - 統計の作法・検定：F80 までで7/78本、F81 以降は22/119本（p=0.10、はっきりしない）
  - 時系列はどの時期も同じくらい（F100 まで13/98本、以降17/99本、p=0.55）
- 道具を使った記事の割合は、番号帯で50〜65%と大きく変わらなかった（χ² p=0.63）

## 頑健性

|---|---|
| 取り出す範囲を README 全体に広げる | 手法ごとの本数の順位相関0.92、道具を除いた上位10の重なり6/10。「使われていない組み合わせ」は3つで、主と重なるのは1つ |
| 題名だけで取り出す | 順位相関0.51、上位10の重なり3/10。区分の割合は最大44ポイント動いた |
| 振り返りの記事14本（F100・F118〜F125・F161〜F165）を除く | 順位相関0.98、上位10は同じ。「使われていない」3つはすべて主と重なる |

## 言えないこと

- 数えたのは README に書いた手法とデータで、コードの中だけで使ったもの・書き漏らしたものは入らない。逆に「使わなかった理由」として名前だけ出したものも、主の取り出し（題名＋手法の節）では一部入る
- 辞書と手作業の区分は、どちらも自分で作ったもので、外の人の判断と照らし合わせていない。手作業の区分は、辞書のタグの一覧を見たあとにつけたので、一致は高めに出ている可能性がある（推測）
- 「使われていない組み合わせ」は、条件を変えると入れ替わった。安定していた7つにも、テキスト×人口のように題材として組み合わせにくいものが含まれ、「作るべき記事」を示すものではない
- 番号帯の変化は、題材を選んだ順番（設計書の並び）の結果で、手法の好みが変わったことを示すわけではない
- 手法の「重要さ」や「難しさ」は測っていない。本数が多いことは、その手法が優れていることを意味しない
- F24・F30 は形式が違うため含めていない
