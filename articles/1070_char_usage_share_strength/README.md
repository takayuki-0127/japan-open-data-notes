# 1070 使われる割合の高いキャラクターは、強いキャラクターなのか？（対戦とレーティング）

対戦ゲームでは、「使われる割合の高いキャラクター＝強いキャラクター」と読まれがちです。強いキャラクターが選ばれやすいのは確かですが、使われる割合には、見た目・使い心地・話題といった強さと関係のない人気も混ざります。とくに、まだうまくない人ほど強さより好みで選ぶなら、使われる割合の上位には「人気の出やすいキャラクター」が入ってきます。**ここでは、作成者が乱数で作った架空の対戦ゲーム（キャラクター20体の本当の強さと人気の出やすさ、プレイヤー4,000人の本当のうまさを作成者が置いたもの）で、使われる割合のいちばん高いキャラクターがどれだけ本当に強いかを、キャラクターの置き方を作り直して200回数えました。** 点数の上位2割の人が使う割合、そのままの勝率とも比べました。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A1070 | 使われる割合の高いキャラクターは、本当に強いか。上位2割の人が使う割合や、そのままの勝率と比べて、本当の強さの上位3体をどれだけ当てられるか | 架空の対戦ゲーム（1対1）。キャラクター20体の本当の強さ（ロジット）は平均0・標準偏差0.10、人気の出やすさは平均0・標準偏差0.5の正規分布（互いに関係なし）。プレイヤー4,000人の本当のうまさは平均0・標準偏差1。各プレイヤーは「人気の出やすさ＋λ×w×本当の強さ＋好みの揺れ（ガンベル分布）」がいちばん大きい1体を選ぶ。λ＝10（強さで選ぶ重さ）、w＝1÷(1＋e^(−2×うまさ))（うまい人ほど強さを重く見る）。勝つ確率＝1÷(1＋e^(−(1.0×うまさの差＋キャラクターの強さの差)))。見えている点数＝本当のうまさ＋誤差（標準偏差0.5）、毎回小さなゆらし（標準偏差0.3）を足して並べ、隣どうしで対戦（1人20試合）。同じキャラクターどうしの試合は勝率から除く。本当の勝率は同じうまさの相手（相手のキャラクターは使われる割合どおり）と当たったときの勝率（式）。①使われる割合 ②点数の上位2割の人が使う割合 ③そのままの勝率、の上位3体が本当の強さの上位3体とどれだけ重なるか。キャラクターとプレイヤーを作り直して200回。λ（5・10・20）×人気の出やすさの散らばり（0.25・0.5・1.0）×うまさによる重みの違い（変わらない w＝1・基本・強く変わる w＝1÷(1＋e^(−4×うまさ))）の27通りの確かめ（各40回）。seed 1070 | `src/a1070_usage_share.py` |

## 主な結果

### 本当の強さの上位3体をどれだけ当てられるか（基本の置き方、200回の平均、`results/base_by_signal.csv`）
| 数字 | 上位3体のうち本当の上位3体だった割合 | いちばん上の1体が本当の上位3体に入っていた割合 | いちばん上の1体の本当の順位（平均） | 本当の強さとの順位相関 |
|---|---|---|---|---|
| ①使われる割合 | **52%** | **71.5%** | 3.19位 | 0.625 |
| ②点数の上位2割の人が使う割合 | 64.5% | 89% | 1.97位 | 0.815 |
| ③そのままの勝率 | 80.67% | 97.5% | 1.35位 | 0.917 |
| でたらめに3体選んだとき | 15% | － | － | － |

- **いちばん使われる1体が本当にいちばん強かったのは200回中84回（42%）、本当の上位3体に入っていたのは71.5%**。本当の順位が11位以下だったことも6%あった（`results/most_used_true_rank.csv`）
- 使われる割合との順位相関は、人気の出やすさとで0.695、本当の強さとで0.625。強さと関係ない人気のほうが、使われる割合とよくそろった
- ②上位2割の人が使う割合は、①より当たった。うまい人ほど強さで選ぶと置いたため
- ③そのままの勝率が当たったのは、この置き方では「強いキャラクターをうまい人が選ぶ」ので、使う人のうまさのずれ（1069）が本当の強さと同じ向きに出たことも効いている（推測）。使われる割合と「そのままの勝率−本当の勝率」の順位相関は0.418で、使われるキャラクターほど勝率が高めに出ていた

### 例の1回分（20体、`data/characters_example.csv`）
- いちばん使われたのは10番（21.9%）で、本当の強さは6位（本当の勝率50.62%）。人気の出やすさは20体の中で1位だった
- 本当にいちばん強い14番（本当の勝率55.86%）は16.35%で、使われる割合は2位
- 使われる割合は0.4〜21.9%、本当の勝率は43.77〜55.86%。使われる割合と本当の強さの順位相関は0.471

### 確かめ：λ×人気の出やすさの散らばり×うまさによる重みの違い（27通り、各40回、`results/sensitivity_grid.csv`）
- **①いちばん使われる1体が本当の上位3体に入っていた割合は30〜100%**、上位3体の当たりは21.67〜91.67%と大きく動いた
- 人気の出やすさの散らばりで分けると、①上位3体の当たりは 0.25 で49.17〜91.67%、0.5 で24.17〜81.67%、1.0 で21.67〜71.67%。強さと関係ない人気の散らばりが大きいほど当たらなかった
- ②上位2割の人が使う割合は26.67〜90.83%で、①より当たったのは27通り中18通りで、うまさで重みが変わる18通りすべてだった（うまさで重みが変わらない9通りでは、①と同じか少し下）
- ③そのままの勝率は39.17〜91.67%。λ＝20 でうまさで重みが変わらないとき（39.17〜43.33%）は、ほとんど使われないキャラクターが試合数の少なさで勝率の1位になり（勝率1位のキャラクターの使われる割合が1%未満だった回が62.5〜72.5%）、当たりが下がった
- 使われる割合と「そのままの勝率−本当の勝率」の順位相関は、うまさで重みが変わらないとき−0.164〜−0.037、基本で0.081〜0.698、強く変わるとき0.107〜0.625

## 動かし方
```
pip install -r requirements.txt
cd src && python a1070_usage_share.py
```
1分ほどで終わります。`data/characters_example.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp）
- うまさで強さの重みが変わらない置き方では、使われる割合と勝率のずれの順位相関がほぼ0（−0.164〜−0.037）になった（使う人のうまさがキャラクターで違わないので、ずれないはず、という作りの確かめ）

## データ
- `data/characters_example.csv`：基本の置き方の例の1回分（20体）。char_id・power_logit（本当の強さ）・appeal（人気の出やすさ）・usage_pct（使われる割合）・usage_top20_pct（点数の上位2割の人が使う割合）・raw_winrate（そのままの勝率）・true_winrate（本当の勝率、式）・users_mean_skill（使う人の本当のうまさの平均）・games（同じキャラクターどうしを除いた試合数）

## 注意（言えないこと）
- 架空のデータです。強さと人気の出やすさの散らばり、選び方（λ、うまさによる重み）、点数の誤差は作成者が置いたもので、結果はこれで決まります。とくに「使われる割合が強さをどれだけ表すか」は、人気の出やすさの散らばりと λ でほぼ決まります。実在のゲームのキャラクターや使われる割合を表すものではありません
- プレイヤーは本当の強さを（重みの分だけ）知っていて選ぶと置きました。実際には、強さは勝率や評判から推し量るしかなく、使われる割合を見てさらに使われる、といった動きもあります。それは入れていません
- 1人1体、1回きりの選び方で、時間とともに選び直すことは入れていません
- どのキャラクターを使うべきか、強さを変更すべきかの判断はしません。賭け・課金の話もしません
