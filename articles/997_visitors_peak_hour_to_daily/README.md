# 997 ピークの1時間の人数から、1日の人数を見込むと？（来場者と集客）

1日じゅう人を数えるのは手間がかかるので、いちばん混む1時間だけを数え、「1日はピークの何倍」という係数を掛けて1日の人数を見込むことがあります。この係数は、1日の中で人がどう分かれて来るか（時間ごとの形）で決まります。形が違う日に同じ係数を使うと、見込みはずれます。**ここでは、作成者が乱数で作った架空の屋内の催事館「B館」の入館者（平日・土日・ショーのある催しの日の、時間ごとの形を作成者が置いたもの）で、ピークの1時間×係数の見込みを、本当の1日の人数と比べました。係数を平日の数えた日だけで決めた場合、日の種類ごとに決めた場合、決まった時間（13時台）だけを数えた場合の3つです。ショーに集まる割合・時間ごとの振れ・館の大きさ・係数を決める日の数を変えた確かめも行いました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A997 | ピークの1時間の人数×係数で、1日の人数はどれだけ当たるか。日の種類で何がずれるか | 架空の催事館（10時〜20時の10時間）。日の種類は平日・土日・催しの日の3つ。1日の人数の平均は平日3,000人・土日6,000人・催しの日8,000人で、日ごとの振れは対数の標準偏差0.2。時間ごとの割合の形（`results/profiles_pct.csv`）：平日は12時台と17時台の2つの山（ピーク12.27%）、土日は13〜14時台の1つの山（ピーク14.74%）、催しの日は土日の形の85%に、14時台のショーに集まる15%を足したもの（ピーク27.53%）。時間ごとの入館者は、1日の人数×割合に時間ごとの振れ（対数の標準偏差0.1）を掛けた平均のポアソン分布から引き、1日の人数はその合計。見込み方は3つ：A ピークの1時間（その日にいちばん多かった1時間）×平日の係数、B ピークの1時間×日の種類ごとの係数、C 13時台の1時間×平日の係数。係数は、全部の時間を数えた日（較正の日、日の種類ごとに10日）の「1日の人数÷その1時間の人数」の平均。見込みは、日の種類ごとに別の300日で確かめた。較正の日と確かめる日を作り直して200回。確かめとして、ショーに集まる割合（5・15・30%）×時間ごとの振れ（0.05・0.1・0.2）×館の大きさ（1日の人数1倍・0.1倍）の18通りを各50回、係数を決める日の数（3・10・30日）を各100回。seed 997 | `src/a997_peak_hour.py` |

## 主な結果

### 見込みのずれ（見込み÷本当の1日の人数−1、200回の平均、`results/a997_main.json`）
| 日の種類 | A ピーク×平日の係数 | B ピーク×日の種類ごとの係数 | C 13時台×平日の係数 |
|---|---|---|---|
| 平日 | +0.31%（±10%に入った日 83.4%） | +0.31%（83.4%） | +1.32%（62.25%） |
| 土日 | **+20.36%**（11.28%） | +0.38%（83.18%） | +40.03%（1.08%） |
| 催しの日 | **+111.61%**（0%） | +0.91%（76.91%） | +18.99%（23.19%） |

（平日の A と B は、同じ平日の係数を使うので同じ値。日ごとの10〜90%は `results/base_by_type_method.csv`。A の催しの日は +90.76〜+132.98%）

- **平日に決めた係数（7.691）をそのまま使うと、土日は1日の人数を20.36%、催しの日は111.61%多く見込んだ**。催しの日はショーの1時間に人が集まるので、ピークの1時間が1日に占める割合が大きく、ピークの何倍かという係数は小さい（日の種類ごとに決めた係数は3.667）
- 向きと大きさは、置いた時間ごとの形でほぼ決まる。振れがないとすると、A のずれは「その日の種類のピークの割合÷平日のピークの割合−1」の式で、土日+20.1%・催しの日+124.3%になる
- **催しの日の A が式の値（+124.3%）より小さい+111.61%になったのは、平日のピークの1時間が振れで大きく数えられるため**。平日の形の上のピークは12.27%だが、日ごとにいちばん多かった1時間を取ると平均13.043%になり、係数は形から出る8.149より小さい7.691になった。平日は2つの山がほぼ同じ高さなので、いちばん多かった時間が形の上のピーク（12時台）と違う日が53.392%あった。催しの日はショーの山がはっきりしていて、ピークの割合は形どおり（27.515%）だった
- 日の種類ごとに係数を決める（B）と、平均のずれは+0.31〜+0.91%に収まった。それでも、±10%に入ったのは76.91〜83.4%の日で、残りの日は時間ごとの振れで外れた
- 決まった時間（13時台）だけ数える C は、土日+40.03%・催しの日+18.99%ずれた。13時台が1日に占める割合は、平日10.66%・土日14.74%・催しの日12.53%と違うため（式では土日+38.2%・催しの日+17.5%）

### 確かめ：置き方を変えると（`results/grid_spike_hoursd_scale.csv` 18通り各50回、`results/by_n_calibration.csv`）
| 置き方を変えたもの | A 土日のずれ | A 催しの日のずれ | B ±10%に入った日（平日） |
|---|---|---|---|
| 18通り全部 | +14.28〜+21.12% | **+30.04〜+219.02%** | 57.63〜94.25% |
| 館の大きさ1倍（9通り） | +18.16〜+21.12% | +36.18〜+219.02% | 62.89〜94.25% |
| 館の大きさ0.1倍（1日 平均300人、9通り） | +14.28〜+15.61% | +30.04〜+194.6% | 57.63〜71.07% |

- **催しの日の A のずれは、ショーに集まる割合でほぼ決まった**（5%で+30.04〜+51.01%、30%で+166.5〜+219.02%）。時間ごとの振れが大きいほど、平日の係数が小さくなって少し縮んだ
- 日の種類ごとの係数（B）でも、±10%に入る日の割合は時間ごとの振れと館の大きさで動いた。1日 平均300人の小さな館では、人数の少なさによる振れが加わり、平日で57.63〜71.07%だった
- 係数を決める日の数を3・10・30日に変えても、B の平均のずれは+0.03〜+1.58%で、±10%に入った日は72.83〜84.81%だった。A の催しの日のずれ（+111.31〜+111.52%）は日を増やしても変わらなかった。係数の決め方ではなく、形の違いによるずれだから

## 動かし方
```
pip install -r requirements.txt
cd src && python a997_peak_hour.py
```
10秒ほどで終わります。`data/hourly_example.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の10ファイルがバイト単位で一致した（cmp）
- 時間ごとの振れを0.05にし、館の大きさを1倍にすると、A の土日のずれ（+20.53〜+21.12%）が形からの式の値（+20.1%）に近づいた
- 平日では A と B が同じ係数になり、同じ値になる（作りの確かめ）

## データ
- `data/hourly_example.csv`：日の種類ごとに10日分の、時間ごとの入館者（type・day・hour（その時台）・visitors）

## 注意（言えないこと）
- 架空のデータです。日の種類ごとの時間の形、ショーに集まる割合、時間ごとの振れは作成者が置いたもので、どの日にどれだけずれるかはこれで決まります。A の催しの日のずれは、置き方で+30.04〜+219.02%まで動きます
- ずれの向きと大きさの大部分は、置いた形の違いの写しです（土日+20.1%・催しの日+124.3%は式の値）。この記事で新しく数えたのは、ピークの1時間を「いちばん多かった1時間」として数えると振れで大きく出て係数が小さくなること、同じ種類の日の係数を使っても±10%に入らない日がどれだけあるか、です
- 「1時間」は時計の時台（13時台など）で区切りました。13時30分から14時30分のような区切り方は数えていません
- 入館した人を数えると置き、館の中にいる人の数（滞在している人）は数えていません。出入りや再入場も入れていません（同じ時間に館の中の場所を移る人の数え方は 1002、再入場で入口の数が増えることは 994 で扱っています）
- 実在の施設・催しの人数ではありません
- 関連する記事：883（開店直後の行列は何分で解消するか）は、時間ごとに来る人の偏りを行列で扱っています。990（偶然の集まり）は、平らな売れやすさでも、いちばん混んだ時間が偶然大きく出ることを扱っています。この記事は、ピークの1時間から1日の人数に戻すときの係数に絞りました
