# F269 中小企業白書の「価格転嫁できた企業」は、どんな企業か？

> 精選モード（B. 白書・審議会 Q16）。計画は結果を見る前に [PLAN.md](PLAN.md) に書いてコミットした（コミット 8a1de2b、メッセージ "plan"）。

## 問い
価格転嫁は「転嫁率は○%」と1つの数字で報じられる。中小企業の経営者・営業担当や、発注側の購買担当、取引先を見る金融機関にとって知りたいのは、**転嫁できた企業とできなかった企業が、どの属性で分かれているのか**と、**その差は縮んでいるのか**。中小企業庁「価格交渉促進月間フォローアップ調査」の公表された集計表（2023年3月〜2026年3月の7回分）と、日本銀行「短観」で確かめた。個社名・発注者リストは使っていない。業種名を順位で並べることはしない（図にも業種名は出さない）。

## 手法
1. テキストから表を正規表現で起こす（src/zz_f269_02_整形.py）。業種名の表記の揺れはそろえる（例：不動産・物品賃貸 → 不動産業・物品賃貸業）。
2. H1：1次請けと4次請け以上の転嫁率の差。H3：原材料費と労務費の差。H4：業種の間の差（最大−最小）と取引段階の差の比。
3. H2：交渉の有無別の転嫁率は公表されていないので判定できない。代わりに業種の単位で、価格交渉の平均点と転嫁率の相関（同じ回）と、同じ業種の変化どうしの相関（2024年9月→2026年3月）を見た（計画からのずれ）。価格交渉の平均点は、中小企業庁が回答を −10〜10点に点数化して発注企業の業種ごとに平均したもの（発注側の申し入れで交渉が行われた 10点、受注側から申し出て行われた 8点、コストが上がらず交渉不要として申し入れを辞退も 10点、コストは上がったが交渉不要として辞退 10点、発注減少などを恐れて辞退 5点、恐れて申し出なかった −5点、申し出たが応じてもらえなかった −10点、市場価格に連動する場合などは対象外）。「交渉が行われたか」だけを測る数字ではない。
4. H5：短観の「販売価格DI − 仕入価格DI」（仕入の値上がりに比べて売値をどれだけ上げられたか）を規模ごとに比べ、中小企業と大企業の差を 2021〜2022年と 2025〜2026年で比べた。

### 頑健性
1. **指標を変える（H1）**：全額転嫁（10割）の割合の差は 15.2 → 7.8、「0割・マイナス」の割合の差（4次以上−1次）は 17.8 → 9.5、区間の中央値で計算し直した転嫁率の差は 16.0 → 9.6。どれも縮小。中央値での計算は公表値より平均 0.75 ポイント高い（最大 1.18）。
2. **業種のそろえ方（H4）**：7回すべてにある27業種だけでも 3.2倍、最も低い1業種を除くと 2.6倍。真ん中半分の幅で比べると 0.79倍で、「業種の差のほうが大きい」は両端の少数の業種で決まっている（最も低い1業種を除く・上下10%を除く・真ん中半分は結果を見てから足した）。最大−最小は比べる組の数が多いほど大きくなりやすい（業種は32、段階は4）。
3. **製造業・非製造業（H5）**：製造業は −12.5 → −13.4（縮まず）、非製造業は −13.5 → −12.3（わずかに縮小）。全産業の判定は外れのまま。
4. **H2 の代わりの見方**（結果を見てから足した）：新しく加わった業種（警備・ビルメンテナンス）と最も低い業種を除くと、2026年3月の相関は 0.50。

### 問い直し（結果を見てから足した）：転嫁率の低い業種は、追いついているのか
- 7回すべてにある27業種で、2023年3月の転嫁率が低い業種ほど、2026年3月までに大きく上がった（傾き −0.55、相関 −0.71）。最初に低かった3分の1の業種は平均 +16.1 ポイント、高かった3分の1は +2.4 ポイント。
- 業種の間の標準偏差は 10.4（2023年3月）→ 6.6（2024年3月）と縮んだが、その後は 7.1〜7.6 で横ばい。この間に回答企業数は 3.6万社（2023年9月）→ 7.0万社（2026年3月）とほぼ倍になっており、散らばりが縮んだのが回答する企業の入れ替わりによる分は分けられない。2024年9月→2026年3月（30業種）だけで見ると、追いつきははっきりしない（傾き −0.16、p=0.20）。
- 同じ業種でも1回ごとに平均 3.7 ポイント動くので、最初の値の振れが戻る分（平均への回帰）も含まれる。期間が短くなる（2023年9月→2026年3月）ので −0.55 とはそのまま比べられないが、その期間で測ると、2023年3月の値で説明した傾きは −0.18（p=0.056）、2023年3月の値を操作変数にした傾きは −0.28、2023年9月の値での単純な回帰は −0.29（p=0.013）。重ならない期間の傾きは測定の誤差で0に寄りやすいので、追いつきの大きさは −0.28〜−0.18 程度と見る。追いつきの一部は平均への回帰だと考える（推測）。
- 業種の並び順の相関（2023年3月と2026年3月）は 0.46、2024年9月と2026年3月は 0.70。

## 計画からのずれ
- **H2**：交渉の有無別の転嫁率は公表されていなかったので「判定できない」とし、代わりに業種の単位での相関を見た（結果を見てから決めた代わりの見方）。
- **期間**：計画は2021年9月〜だったが、2021年9月の結果は業種別の転嫁率の表の形が違い、2022年の回は中小企業庁のページから国立国会図書館のアーカイブへのリンクになっていて今回は取っていないので、比べられる2023年3月〜2026年3月（7回）にした。取引段階の表は2024年9月の回からしかない。交渉の平均点は、2024年9月の回で回答項目が一部変わったので2024年9月以降だけを使った。
- **頑健性3（「コスト上昇なし」を分母に含めるか）**：取引段階・業種の表に「価格転嫁不要」の割合がないので行っていない。
- **中小企業白書**：白書の図表そのものは使っていない。白書の価格転嫁の図表も同じフォローアップ調査を使っていると考える（推測）。
- 問い直しと、平均への回帰を避ける確かめ（重ならない期間・操作変数）は結果を見てから足した。
- H4 の上下10%を除く幅・真ん中半分の幅・最も低い1業種を除く比、H2 の業種の除外は、結果を見てから足した。
- 計画にあった「回答数で重みをつけた標準偏差」は、業種ごとの回答数が公表されていないので計算していない。「区間の下限・上限で計算した転嫁率」も計算していない（真ん中の値での計算だけ）。

## 言えないこと
- すべて回答した企業の集計で、個々の企業を追ったものではない。属性どうしの関係（業種×段階など）は公表されていないので分けられない。
- 業種は「発注企業の業種」で集計した転嫁率で、受注企業の業種ではない。
- 交渉の点と転嫁率の相関は業種の単位のもので、交渉したから転嫁できたという因果ではない。
- 回答は延べ数で、回ごとに回答した企業が違う。回答する企業の偏りは分からない。
- 短観の DI は「上昇と答えた割合 − 下落と答えた割合」で、転嫁率とは定義が違う。値上げの大きさではなく、値上げしたと答えた企業の割合。短観の中小企業は資本金2千万〜1億円の企業。
- 回答数は回ごとに大きく増えた（回答企業数 3.6万社〔2023年9月〕→ 5.1万 → 6.6万 → 7.0万 → 7.0万社〔2026年3月〕、取引段階の表の n は 33,377〔2024年9月〕→ 76,339〔2026年3月〕）。差が縮んだ一部は、回答する企業の入れ替わりによる可能性がある（推測）。
- 価格交渉の平均点には「コストが上がらず交渉不要」の回答も 10点で入る。一方、転嫁率は「転嫁不要」の回答を除いているので、定義の違いが業種の相関に影響している可能性がある（推測）。
- 業種ごとの回答数は公表されていない。最大−最小は比べる組の数が多いほど大きくなりやすい（業種32、段階4）。
- 政策の評価や、特定の業種・企業の良し悪しは扱っていない。

## レビューで直したこと
別のエージェントによる独立レビュー（PDF からの抜き出しは正確、数字はすべて一致、クリーンな再実行で一致）を受けて、次を直した。
1. 価格交渉の平均点の定義（−10〜10点、「コストが上がらず交渉不要」も10点）を本文・図4の軸に正しく書いた。定義の違いが相関に影響しうることを「言えないこと」に足した。
2. 変化どうしの相関 0.14 に95%区間（−0.24〜0.47）と点の変化の標準偏差 0.43 を足し、「上がったとは言えない」を「確かめられなかった」に直した。同じ回の4つの相関に p を足し、独立な4つの確かめではないことを書いた。
3. 追いつきの傾き −0.18 は期間が短く、測定の誤差で0に寄りやすいので、同じ期間の操作変数（−0.28）・単純な回帰（−0.29）と並べて −0.28〜−0.18 程度とした。
4. 回ごとの回答数の増加（回答企業数 3.6万→7.0万社、段階の表の n 33,377→76,339）を書き、「追いついた」を「散らばりが縮んだ（回答数の増加の影響は分けられない）」に弱めた。
5. 結果を見てから足した指標（四分位範囲・上下10%除く・最も低い1業種を除く・H2 の除外）と、計画にあってやっていないこと（回答数での重み、区間の下限・上限）を「計画からのずれ」に書いた。
6. 最大−最小が組の数で大きくなりやすいこと、業種ごとの回答数が分からないことを書いた。
7. 短観の中小企業の範囲（資本金2千万〜1億円）、差の変化が四半期の振れの範囲であること（p=0.19）を書き、推測の言い方を「値上げしたと答える企業の割合の差」に直した。
8. 公開のコードと結果の中で特定の業種が分かるキー名を、「最も低い1業種」を表す名前に変えた。
9. PDF をリポジトリから外す .gitignore を足した。30業種と27業種の違い、原材料費と労務費の差のいちばん小さい回（2025年9月の5.0）を書いた。
