# F269 中小企業白書の「価格転嫁できた企業」は、どんな企業か？

> 精選モード（B. 白書・審議会 Q16）。計画は結果を見る前に [PLAN.md](PLAN.md) に書いてコミットした（コミット 8a1de2b、メッセージ "plan"）。

## 問い
価格転嫁は「転嫁率は○%」と1つの数字で報じられる。中小企業の経営者・営業担当や、発注側の購買担当、取引先を見る金融機関にとって知りたいのは、**転嫁できた企業とできなかった企業が、どの属性で分かれているのか**と、**その差は縮んでいるのか**。中小企業庁「価格交渉促進月間フォローアップ調査」の公表された集計表（2023年3月〜2026年3月の7回分）と、日本銀行「短観」で確かめた。個社名・発注者リストは使っていない。業種名を順位で並べることはしない（図にも業種名は出さない）。

## データ
| データ | 中身 | 期間 |
|---|---|---|
| 中小企業庁「価格交渉促進月間フォローアップ調査の結果」（結果1、PDF 6本） | 全体・コストの種類別・発注企業の業種別の転嫁率、業種別の価格交渉の平均点、取引段階（何次請けか）別の回答分布と転嫁率 | 2023年3月〜2026年3月（7回。取引段階は2024年9月〜の4回、交渉の平均点は2024年9月〜の4回） |
| 日本銀行「短観」販売価格判断DI・仕入価格判断DI（実績） | 規模別（大企業・中堅・中小）× 全産業・製造業・非製造業、四半期 | 2010年〜2026年9月調査 |

- PDF はブラウザで保存し（2026-11-11）、`pdftotext -layout` でテキストにしたもの（data/raw/txt/）をリポジトリに置いた。PDF そのものは置いていない（md5 は data/raw/MANIFEST.json）。
- 転嫁率は調査の定義（コスト上昇分のうち価格に転嫁できた割合の平均、「価格転嫁不要」を除く）。回答は回ごとの延べ数（2026年3月は約7万2千件）。

## 手法
1. テキストから表を正規表現で起こす（src/zz_f269_02_整形.py）。業種名の表記の揺れはそろえる（例：不動産・物品賃貸 → 不動産業・物品賃貸業）。
2. H1：1次請けと4次請け以上の転嫁率の差。H3：原材料費と労務費の差。H4：業種の間の差（最大−最小）と取引段階の差の比。
3. H2：交渉の有無別の転嫁率は公表されていないので判定できない。代わりに業種の単位で、交渉の平均点と転嫁率の相関（同じ回）と、同じ業種の変化どうしの相関（2024年9月→2026年3月）を見た（計画からのずれ）。
4. H5：短観の「販売価格DI − 仕入価格DI」（仕入の値上がりに比べて売値をどれだけ上げられたか）を規模ごとに比べ、中小企業と大企業の差を 2021〜2022年と 2025〜2026年で比べた。

## 結果
### 全体の推移
| 回 | コスト全般 | 原材料費 | エネルギー費 | 労務費 |
|---|---|---|---|---|
| 2023年3月 | 47.6 | 48.2 | 35.0 | 37.4 |
| 2023年9月 | 45.7 | 45.4 | 33.6 | 36.7 |
| 2024年3月 | 46.1 | 47.4 | 40.4 | 40.0 |
| 2024年9月 | 49.7 | 51.4 | 44.4 | 44.7 |
| 2025年3月 | 52.4 | 54.5 | 47.8 | 48.6 |
| 2025年9月 | 53.5 | 55.0 | 48.9 | 50.0 |
| 2026年3月 | 54.2 | 55.7 | 48.9 | 50.0 |

### 仮説の判定
| 仮説 | 基準 | 結果 | 判定 |
|---|---|---|---|
| H1 取引段階 | 各回で1次−4次以上が5pt以上、かつ縮小 | 16.1 → 13.4 → 12.6 → 9.7 ポイント（4回すべて5以上、縮小） | 支持 |
| H2 価格交渉 | 交渉ありの企業の転嫁率が20pt以上高い | 交渉の有無別の転嫁率は公表されていない。業種の単位では、交渉の平均点が高い業種ほど転嫁率が高い（相関 0.35・0.71・0.66・0.63、2026年3月は1点で約9.4ポイント）。ただし同じ業種の変化どうしの相関は 0.14（p=0.48） | 判定できない |
| H3 コストの種類 | 原材料−労務が平均5pt以上、労務が上回る回が半分未満 | 10.8 → 5.7 ポイント（平均7.2、労務が上回った回はなし） | 支持 |
| H4 どの属性の差が大きいか | 業種の差（最大−最小）が取引段階の差の2倍以上 | 31.4 ÷ 9.7 = 3.2倍。ただし上下10%を除く幅（19.9）では2.05倍、真ん中半分の幅（7.6）では0.79倍 | 支持（両端の業種しだい） |
| H5 短観での確かめ | 中小企業の「販売−仕入」が大企業より低く、2021〜22年より2025〜26年のほうが差が小さい | 差は 2021年以降の平均 −12.4ポイント。2021〜22年 −11.8 → 2025〜26年 −12.9 と縮んでいない（2010〜19年の平均は −14.1） | 外れ |

### 頑健性
1. **指標を変える（H1）**：全額転嫁（10割）の割合の差は 15.2 → 7.8、「0割・マイナス」の割合の差（4次以上−1次）は 17.8 → 9.5、区間の中央値で計算し直した転嫁率の差は 16.0 → 9.6。どれも縮小。中央値での計算は公表値より平均 0.75 ポイント高い（最大 1.18）。
2. **業種のそろえ方（H4）**：7回すべてにある27業種だけでも 3.2倍、最も低い1業種を除くと 2.6倍。真ん中半分の幅で比べると 0.79倍で、「業種の差のほうが大きい」は両端の少数の業種で決まっている。
3. **製造業・非製造業（H5）**：製造業は −12.5 → −13.4（縮まず）、非製造業は −13.5 → −12.3（わずかに縮小）。全産業の判定は外れのまま。
4. **H2 の代わりの見方**：新しく加わった業種（警備・ビルメンテナンス）と最も低い業種を除くと、2026年3月の相関は 0.50。

### 問い直し（結果を見てから足した）：転嫁率の低い業種は、追いついているのか
- 7回すべてにある27業種で、2023年3月の転嫁率が低い業種ほど、2026年3月までに大きく上がった（傾き −0.55、相関 −0.71）。最初に低かった3分の1の業種は平均 +16.1 ポイント、高かった3分の1は +2.4 ポイント。
- 業種の間の標準偏差は 10.4（2023年3月）→ 6.6（2024年3月）と縮んだが、その後は 7.1〜7.6 で横ばい。2024年9月→2026年3月だけで見ると、追いつきははっきりしない（傾き −0.16、p=0.20）。
- 同じ業種でも1回ごとに平均 3.7 ポイント動くので、最初の値の振れが戻る分（平均への回帰）も含まれる。2023年3月の値で、重ならない期間（2023年9月→2026年3月）の上昇を説明すると傾きは −0.18（p=0.056）まで小さくなる。追いつきの一部は平均への回帰だと考える（推測）。
- 業種の並び順の相関（2023年3月と2026年3月）は 0.46、2024年9月と2026年3月は 0.70。

## 計画からのずれ
- **H2**：交渉の有無別の転嫁率は公表されていなかったので「判定できない」とし、代わりに業種の単位での相関を見た（結果を見てから決めた代わりの見方）。
- **期間**：計画は2021年9月〜だったが、2021年9月の結果は業種別の転嫁率の表の形が違い、2022年の回は中小企業庁のページから国立国会図書館のアーカイブへのリンクになっていて今回は取っていないので、比べられる2023年3月〜2026年3月（7回）にした。取引段階の表は2024年9月の回からしかない。交渉の平均点は、2024年9月の回で回答項目が一部変わったので2024年9月以降だけを使った。
- **頑健性3（「コスト上昇なし」を分母に含めるか）**：取引段階・業種の表に「価格転嫁不要」の割合がないので行っていない。
- **中小企業白書**：白書の図表そのものは使っていない。白書の価格転嫁の図表も同じフォローアップ調査を使っていると考える（推測）。
- 問い直しと、平均への回帰を避ける確かめ（重ならない期間）は結果を見てから足した。

## 言えないこと
- すべて回答した企業の集計で、個々の企業を追ったものではない。属性どうしの関係（業種×段階など）は公表されていないので分けられない。
- 業種は「発注企業の業種」で集計した転嫁率で、受注企業の業種ではない。
- 交渉の点と転嫁率の相関は業種の単位のもので、交渉したから転嫁できたという因果ではない。
- 回答は延べ数で、回ごとに回答した企業が違う。回答する企業の偏りは分からない。
- 短観の DI は「上昇と答えた割合 − 下落と答えた割合」で、転嫁率とは定義が違う。
- 政策の評価や、特定の業種・企業の良し悪しは扱っていない。
