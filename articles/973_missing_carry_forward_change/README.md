# 973 前の値で埋めると、変化はどう見えるのか？（欠けたデータ）

月ごとの数字に報告の抜けがあると、「前の月の値をそのまま入れておく」埋め方がよく使われます。表は埋まり、線グラフも途切れません。ただ、埋めた月は「前の月から変化なし」になり、上がった月や下がった月は、次に報告があった月まで遅れて出ます。途中で報告をやめた店は、最後の値のまま止まり続けます。**ここでは、作成者が乱数で作った架空の会社の200店の月の売上（24か月）に、ところどころの報告の抜けと、途中で報告をやめた店を置き、「前の値で埋める」「報告のあった店だけで比べる」「前後の値を線でつなぐ」の3つで、店ごとの前の月との変化・改装した店の上がり・全店の前年同月比がどう見えるかを、500回作り直して数えました。**

店・会社・売上はすべて架空のもので、実在の会社の数字は使っていません。

空欄を平均で埋めたときのばらつきと相関は関連する記事 972、途中から測り始めた項目を前の期間と比べることは 977、前年比の前年比が何を表すかは 901、途中でやめた人の回答を入れるか除くかは 866 で扱っています。抜けた日を前の値で埋めたときの1年の平均と傾きのずれは 500 で扱っています（こちらは店ごとの変化の見え方、改装の上がりの遅れ、途中でやめた店の前年同月比を数えます）。この記事は、時間の順に並んだ数字を前の値で埋めたときの「変化」の見え方に絞ります。

## 主な結果

### 店ごとの前の月との変化（基本の置き方、500回の平均）
| | 本当の売上 | 前の値で埋める |
|---|---|---|
| 前の月から変化0の月の割合 | 0% | **24.92%** |
| 2〜24か月目で報告が抜けた店×月の割合 | — | 24.92% |
| 前の月から10%以上動いた月の割合 | 9.44% | 7.65% |
| 前の月との変化の標準偏差 | 5.93% | 5.29% |

（でたらめな店がやめるとき。伸びの低い店ほどやめるときもほぼ同じ：変化0が24.93%、10%以上動いたのが本当9.38%・前の値で埋める7.67%）

- 前の値で埋めると、抜けた月はすべて「変化0」になる。変化0の割合は抜けた店×月の割合と同じだった。**ここは埋め方の作りどおり**で、72通りのどれでも差は0だった
- 月ごとの振れを毎月でたらめに置いたので、抜けのあとの月にまとめて大きく動く形はほとんど出ず、10%以上動いた月の割合はむしろ減った（9.44%→7.65%）。前の値で埋めた表は、本当より落ち着いて見えた

### 改装した店の上がり（改装しない店との差、500回の平均）
| | 13か月目 | 14か月目 | 18か月目 |
|---|---|---|---|
| 本当の売上 | 15.26% | 15.27% | 15.95% |
| 前の値で埋める | **11.58%** | 13.87% | 14.96% |

- 13か月目に上がった15.3%のうち、前の値で埋めた表で13か月目に見えたのは11.6%だった。13か月目の報告が抜けた店では、上がりは次に報告した月まで遅れて出る
- 伸びの低い店ほどやめるときも、13か月目は本当15.22%に対し11.40%だった
- 確かめの66通り（抜けかやめた店がある置き方）で、13か月目に見えた上がりは本当の0.5102〜0.9443倍だった。抜けの割合とやめた店の割合が大きいほど小さく見えた

### 全店の前年同月比（24か月目÷12か月目、500回）
| やめ方 | 扱い方 | 前年同月比の平均 | 本当との差 | 10〜90%の範囲 |
|---|---|---|---|---|
| でたらめな店がやめる | 本当の売上 | 16.78% | — | 15.71〜17.93% |
| でたらめな店がやめる | **前の値で埋める** | **15.17%** | **−1.6ポイント** | 14.11〜16.27% |
| でたらめな店がやめる | 報告のあった店だけ | 16.81% | +0.03ポイント | 12.82〜20.86% |
| でたらめな店がやめる | 前後を線でつなぐ | 16.48% | −0.3ポイント | 13.04〜19.54% |
| 伸びの低い店ほどやめる | 本当の売上 | 16.73% | — | 15.72〜17.74% |
| 伸びの低い店ほどやめる | 前の値で埋める | 16.08% | −0.65ポイント | 15.09〜17.13% |
| 伸びの低い店ほどやめる | **報告のあった店だけ** | **19.27%** | **+2.54ポイント** | 15.36〜23.18% |
| 伸びの低い店ほどやめる | 前後を線でつなぐ | 18.89% | +2.16ポイント | 15.61〜22.08% |

- 前の値で埋めると、報告をやめた店は最後の値のまま止まるので、会社全体が伸びている間は全店の伸びが小さく見えた（−1.6ポイント）
- 報告のあった店だけで比べると、でたらめな店がやめるときは平均では本当に近い（+0.03ポイント）が、12か月目と24か月目で比べる店の顔ぶれが違うので、10〜90%の範囲は12.82〜20.86%と、本当（15.71〜17.93%）より広かった
- 伸びの低い店ほどやめるときは、報告のあった店だけで比べると+2.54ポイント高く出た。前後を線でつないでも、最後の報告より後は除くので+2.16ポイント高く出た

### 確かめ：置き方を変えて（72通り、各100回）
- ところどころの抜けだけ（やめた店0%）の置き方では、前の値で埋めた前年同月比のずれは0.14ポイント以内だった。ずれは主に途中でやめた店から出た
- でたらめな店がやめるとき、前の値で埋めた前年同月比のずれは−6.42〜+0.04ポイントだった。会社全体の伸びが大きく、やめた店が多いほど低く出た（伸び月2%・やめた店30%の4通りで−6.14〜−6.42ポイント、全部は `results/robustness.csv`）。会社全体の伸びが0のときは、ずれは0.55ポイント以内だった
- 伸びの低い店ほどやめるとき、前の値で埋めたずれは、会社全体の伸びが0なら+0.44〜+0.75ポイント（下がり続ける店を高い値で止めるので高く出る）、伸びがあれば−4.51〜−0.63ポイントで、**向きが置き方で入れかわった**
- 報告のあった店だけで比べるずれは、でたらめな店がやめるときは0.96ポイント以内、伸びの低い店ほどやめるときは+1.81〜+5.52ポイントだった

## 動かし方
```
pip install -r requirements.txt
cd src && python a973_carry_forward.py
```
15秒ほどで終わります。`data/stores_example.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約13秒）
- 図3枚を開き、日本語・重なり・軸を確かめた
- 前の値で埋めたときの「変化0」の月の割合が、抜けた店×月の割合と72通りすべてで一致することを確かめた（差0）。埋め方の作りどおりに動いていることの確かめで、結果として新しく見つけたものではない
- 抜けもやめた店もない置き方で、3つの扱い方の前年同月比が本当の値と一致する（ずれ0）ことを確かめた

## データ
- `data/stores_example.csv`：例の1回分（でたらめな店がやめる）の200店×24か月（store_id・month・renovated（改装した店なら1）・stopped（途中でやめた店なら1）・sales_true（作成者が置いた本当の売上、万円）・sales_reported（報告された売上、抜けは空）・filled_previous（前の値で埋めた値）・filled_line（線でつないだ値、最後の報告より後は空））
- `results/a973_main.json`：主な結果すべて
- `results/yoy_by_way.csv`：前年同月比の扱い方ごとの結果（500回）
- `results/robustness.csv`：置き方を変えた確かめ（72通り）

## 注意（言えないこと）
- 架空のデータです。売上の伸び、店ごとの差、月ごとの振れ、抜けとやめた店の割合、やめる店の選び方は作成者が置いたもので、結果はこれで決まります。前の値で埋めた前年同月比のずれは、置き方で−6.42〜+0.75ポイントと向きも変わりました。実在の会社の数字を表すものではありません
- 月ごとの振れは毎月でたらめ（前の月と関係しない）と置きました。振れが何か月か続く場合は、抜けのあとにまとめて大きく動く形が出ると考えます（推測）
- 報告が抜けた月の売上は、本当はあったものとして数えました。休業した月（本当に0）とは別の話です
- どの扱い方を使うべきかは、何を比べたいかと、なぜ報告が抜けたかで変わり、この記事では言えません
