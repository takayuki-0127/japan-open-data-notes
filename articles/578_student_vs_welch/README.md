# 578 平均の差を見るとき、群で散らばりが違うと、ふつうのt検定は何%の回で「差あり」と言うのか（手法の解説・正解の分かるデータで試す）

2つの群の平均を比べるふつうのt検定（スチューデントのt検定）は、2群の散らばり（分散）が同じだと置いて、2群の分散を合わせた1つの値を使います。散らばりが違うと、この前提がくずれます。**ここでは、本当の差が0の2群を、人数の組み合わせ（20人・20人／10人・40人／40人・10人）と散らばりの比（1〜4倍）を変えて各20,000回作り、ふつうのt検定・ウェルチの検定・「先に等分散を検定して選ぶ」方法が、5%の基準で「差あり」と言った割合を数えました。等分散で差があるときの検出力も比べました。** 数字は置いた前提で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A578 | 群で散らばりが違うと、ふつうのt検定は何%の回で「差あり」と言うか | 正規分布の乱数で2群を作り、scipy の ttest_ind（equal_var=True／False）で p 値を計算。先に Levene 検定（中央値版）で等分散を検定し、p<0.05 ならウェルチ、そうでなければふつうのt検定を使う方法も試した。各条件20,000回。例の1回の t 値と自由度を DuckDB（1スレッド）の SQL で計算し、scipy と比べた。seed 578 | `src/a578_welch.py`、`src/a578_t_values.sql`、`src/a578_t_values_tsql.sql` |

## 主な結果（本当の差は0、狙いは5%）
- **人数が同じ（20人・20人）**：ふつうのt検定 4.9〜5.5%、ウェルチ 4.7〜5.1%。散らばりが4倍違っても、ほぼ5%
- **人数の少ない群の散らばりが大きい（40人・10人）**：ふつうのt検定は 1.5倍で 12.3%、2倍で 18.2%、3倍で 25.7%、4倍で 29.9%。ウェルチは 5.1〜5.3%
- **人数の多い群の散らばりが大きい（10人・40人）**：ふつうのt検定は 1.4%・0.5%・0.1%・0.1% と少なすぎる（差があっても見逃しやすい）。ウェルチは 4.7〜5.0%
- **先に等分散を検定して選ぶ方法**（40人・10人）：9.6%・9.1%・6.2%・5.5%。散らばりの差が中くらいのとき、等分散の検定が違いを見つけられず、ずれが残る
- **等分散で差があるとき**：20人・20人では検出力は同じ（差0.5で 34%／34%）。10人・40人ではウェルチがやや低い（差0.5で 28%／26%、差1.0で 79%／75%）
- **例の1回**（A群10人・B群40人、B群の散らばり3倍）：ふつうのt検定 t=−0.32（p=0.75）、ウェルチ t=−0.53（p=0.60、自由度40.1）

## 注意（言えないこと）
- 架空のデータ。2群とも正規分布と置いた。分布が大きくゆがんでいる場合や、外れ値がある場合は扱っていない
- 割合は20,000回の結果で、±0.3ポイントほどぶれうる
- 「差あり」の割合は p<0.05 という基準での話。差の大きさや区間で判断することの代わりにはならない
- 人数が同じなら、ふつうのt検定でもずれは小さかった。人数が違うときに、どちらの群の散らばりが大きいかで、ずれの向きが変わる
