# 519 100万件のデータでは、相関0.01のような小さな関係でも何%の回で「有意」と出るのか（統計の考え方）

データの件数が多くなると、ごく小さな関係でも検定で「有意」と出やすくなります。**ここでは、本当の相関が 0・0.005・0.01・0.02・0.05 の架空のデータを件数100〜100万で作り、相関の検定（両側5%）で「有意」と出る割合、相関の95%信頼区間の幅、相関で説明できる分散の割合（R²）を数えました。** 数字は、置いた分布（正規分布）と有意水準で決まります。

|---|---|---|---|
| A519 | 件数が多いと、小さな相関は何%の回で有意になるか | x・y は標準正規分布、本当の相関 ρ。件数 n = 100〜100万。標本の相関をウィシャート分布から直接作るシミュレーション（各20,000回）と、フィッシャーの z 変換の近似式で「有意」の割合を出す。n=10万・ρ=0.01 では生データを作るシミュレーション（500回）でも確かめる。100万件・ρ=0.01 の1回分で、x の十分位ごとの y の平均も出す | `src/a519_large_n.py` |

## 主な結果
- **本当の相関0.01で「有意」と出た割合**：1,000件で 5.7%、1万件で 16.9%、10万件で **88.7%**、100万件で **100%**（20,000回すべて）
- **本当の相関0.005（さらに半分）**：10万件で 35.5%、100万件で 99.9%
- **本当の相関0（関係なし）**：どの件数でも約5%（4.7〜5.2%）。件数が多くても、関係がなければ「有意」は増えない
- **80%の回で有意になる件数**（近似式）：相関0.05で約3,100件、0.02で約2万件、0.01で約7.8万件、0.005で約31万件
- **95%信頼区間の幅**：1万件で ±0.020（幅0.039）、100万件で ±0.002（幅0.0039）。100万件なら相関0.01は0とはっきり区別できる
- **それでも関係は小さい**：相関0.01で説明できる y の分散は **0.01%**（R² = 0.0001）。100万件の1回分（標本の相関0.009、p = 3×10⁻²¹）では、x がいちばん小さい10%と大きい10%で y の平均は −0.013 と +0.018。y の標準偏差（1.0）に比べるとごくわずか

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- シミュレーションと近似式が合う（相関0.01・10万件で 88.7% 対 88.5%、相関0.005・10万件で 35.5% 対 35.3%）
- 生データを作るシミュレーション（10万件・相関0.01・500回）でも有意の割合は 90.0%（近似式 88.5%）

## 注意（言えないこと）
- 架空のシミュレーション。x と y は正規分布で、ほかの偏りはないと置いた
- 実際の大きなデータでは、測り方の偏りや混ざった集団などで、本当は関係がなくても0.01くらいの相関が出ることがある。ここで「有意」と出ても、因果や意味のある関係を示すとは言えない
- 「有意かどうか」と「関係が大きいかどうか」は別の問い。どれくらいの大きさなら意味があるかは、使い道によって決まり、この分析からは言えない
