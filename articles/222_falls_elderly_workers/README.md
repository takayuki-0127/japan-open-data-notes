# 222 労災の主役は「高齢者の転倒」になっていた：事故の型別の構成比

厚生労働省の労働災害統計（労働者死傷病報告、休業4日以上の死傷者、全産業）で、事故の型別・年齢別の死傷者数（2009〜2025年）と、2025年の年齢別・事故の型別の死傷度数率を使い、労災の中身がどう変わったかを見たフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A222 | 労災の中で「転倒」はどれだけ増えたか。高齢の働き手とどう関係するか | 事故の型別の構成比と2009年=100の指数、死傷者に占める60歳以上の割合、年齢別・男女別の転倒の度数率、度数率×延べ実労働時間による年齢別の転倒の死傷者数の推計（2025年） | `src/a222_falls.py` |

## 主な結果
- 転倒による死傷者は2009年の23,002人から2025年は37,195人（1.62倍）で、事故の型で最も多い。「その他」を除いた死傷者に占める割合は20.4%→28.1%
- 同じ期間に「動作の反動・無理な動作」は13,127人→22,166人（1.69倍）。墜落・転落は20,006人→20,864人でほぼ横ばい、はさまれ・巻き込まれは15,514人→13,047人（−16%）。全体（その他を除く）は+17%
- 死傷者に占める60歳以上の割合は19.1%（2009年）→31.3%（2025年）
- 2025年の転倒の度数率（100万労働時間あたりの死傷者数）は、女性の70〜74歳で2.62と、20〜24歳（0.10）の約26倍。男性は75歳以上で1.17
- 度数率と延べ実労働時間から推計すると、2025年の転倒の死傷者の48%（約1.8万人）が60歳以上。60歳以上の死傷者の42%が転倒で、75歳以上では49%

## 動かし方
```
pip install -r requirements.txt
cd src && python a222_falls.py
```

## データ
- `data/injuries_by_accident_type_2009_2025.csv`：事故の型別の死傷者数（全産業、各年の「死傷災害統計確定値」の業種・事故型の表の合計行）。2011年は表の形が違い読み取れなかったため欠けています
- `data/injuries_by_age_2009_2025.csv`：年齢別の死傷者数（同、業種・年齢の表）。2021年以前は6区分、2022年以降は13区分の表で、6区分にまとめた列も入れています
- `data/frequency_rate_by_age_type_2025.csv`：2025年の年齢別・事故の型別の死傷度数率（男女計、主な6つの型と合計）、男女別の転倒・合計の度数率、年齢別の延べ実労働時間（千万時間）
- `results/`：構成比、指数、60歳以上の割合、2025年の年齢別の転倒の推計

## 注意
- 2020・2021年の表には新型コロナウイルス感染症へのり患による労災が「その他」に含まれます（2021年は「その他」が21,028人）。構成比は「その他」を除いた合計で計算しました。60歳以上の割合の2020・2021年はコロナを含む値です
- 年齢別の転倒の人数は、度数率（有効数字3けた）×延べ実労働時間で出した推計値で、公表された人数ではありません（合計は37,231人で、公表の37,195人とほぼ一致）
- 死傷者数の増加には、働く高齢者の増加と、高齢者ほど転倒しやすいことの両方が入っています。ここでは2つを分けていません
- 休業4日以上の死傷者で、休業3日以下のけがは入っていません
