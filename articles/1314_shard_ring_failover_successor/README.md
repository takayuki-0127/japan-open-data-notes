# 1314 1台が止まって、輪の上で次の台がその分をまるごと受け持つと、受け持つ台の量は平均の何倍になるのか？（データの振り分け）

データを何台かに分けて置くとき、データと台を同じ輪の上に並べ、データは時計回りに進んで最初に出会う台に置く、という振り分け方があります（輪の上に並べる振り分け）。この形では、1台が止まると、その台が受け持っていたデータは時計回りに次の台へ移ります。1台が輪の上に1か所しかなければ、止まった台の分は、となりの1台がまるごと受け持ちます。**ここでは、作成者が置いた架空のアプリのデータ（10万件と10台を、輪の上に乱数で置いたもの）で、1台が止まったとき、その分を受け持った台の量が、止まったあとの平均（10万件÷9台）の何倍になるかを数えました。輪の置き方を作り直して500回×止まる台10通りを数え、1台を輪の上の何か所に分けて置くか（1〜256か所）を変えた9通りと、台の数・置き場所の数・データの件数を変えた24通りで確かめました。実機では測らず、すべてシミュレーションです。**

例のアプリ・データ・台は架空のもので、実在のデータベースや機械の振り分け方を表すものではありません。台数・費用の見込みの助言はしていません。

関連する記事：1305「1万件のデータを乱数で10台に振り分けると、いちばん多い1台の件数は平均の何倍になるのか？」は、1件ずつ置く台を乱数で決めたときのいちばん多い1台の倍率を扱っています。1308「動くデータを少なくする振り分け（番号を輪の上に並べて、時計回りに次の台へ置く形）で1台足すと、動く量は少なくなっても、台ごとの受け持ちの量はどれだけばらつくのか？」は、輪の上に1台を1か所ずつ置く振り分けで1台足したとき、動く量と台ごとの受け持ちのばらつきを数えています。1309「その輪の上に1台を何か所に分けて置くかで、いちばん多い1台の受け持ちはどれだけ平均に近づくのか？」は、1台を輪の上の何か所に分けて置くかで、いちばん多い1台の受け持ちがどれだけ平均に近づくかを数えています。1315「写しを3台ずつに置いても、3台が同時に止まったときに読めなくなるデータの割合は、写しの置き方でどれだけ違うのか？」は、台が止まったときに読めなくなるデータの割合が、写しの置き方でどう違うかを数えています。この記事は、1台足すときやどの台も動いているときの偏りではなく、1台が止まったときにその分がどこへ行き、受け取った台がどれだけ重くなるかに絞ります。

## 主な結果

### 基本（10台・置き場所1か所・データ10万件、500回×止まる台10通り、`results/a1314_main.json` の base_points1）
| | 値 |
|---|---|
| 受け持った次の台の量（止まったあとの平均の何倍か）の平均 | **1.8倍** |
| 同じく90%点 | **3.3103倍** |
| 同じく最大 | 7.1541倍 |
| 次の台が平均の2倍以上になった割合 | 37.14% |
| いちばん多い台が止まったときの、次の台の量の平均 | 3.3431倍 |
| 止まったあと、いちばん多い台（平均の何倍か）の平均 | 2.855倍 |
| 止まる前、いちばん多い台（平均の何倍か）の平均 | 2.9661倍 |

- **受け持った次の台の量は、平均で止まったあとの平均の1.8倍で、台を等間隔に置いたときと同じだった**。どの輪でも、止まる台を10台すべてについて平均すると、次の台の量の合計は「すべての台の量の2倍」になるので、平均は式どおり 2×（台数−1）÷台数 になる（作りどおり）
- **ただし散らばりは大きく、90%点は3.3103倍、最大は7.1541倍だった**。5,000回のうち37.14%で平均の2倍以上になった（図2）。止まった台がいちばん多い台だったときは、次の台は平均で3.3431倍を受け持った
- 1回目の輪では、台0（7,750件）が止まり、次の台7（35,851件）がまるごと受け持って43,601件になった。止まったあとの平均の3.9241倍で、止まったあとのいちばん多い台だった（`data/ring_example.csv`、図1）
- 置き場所1か所では、止まる前からいちばん多い台は平均の2.9661倍あった。止まったあとのいちばん多い台（2.855倍、止まったあとの平均で割った値）は止まる前とほぼ同じ倍率で、次の台が受け持つ分は、もとからある偏りの上に乗る形だった

### 1台を輪の上の何か所に分けて置くか（10台、各500回×10通り、`results/by_points.csv`）
| 置き場所の数 | いちばん多く受け取った台の量（平均） | 同じく90%点 | その台が受け取った分÷止まった台の分 | 受け取った台の数（平均） | 止まったあとのいちばん多い台（平均） |
|---|---|---|---|---|---|
| 1か所 | 1.8倍 | 3.3103倍 | 1.0 | 1.0台 | 2.855倍 |
| 4か所 | 1.438倍 | 2.0851倍 | 0.5938 | 3.261台 | 1.8406倍 |
| 16か所 | 1.2014倍 | 1.5045倍 | 0.333 | 7.471台 | 1.4011倍 |
| 64か所 | 1.0918倍 | 1.2366倍 | 0.2127 | 8.993台 | 1.1953倍 |
| 128か所 | **1.0623倍** | 1.166倍 | 0.1806 | 9.0台 | 1.1363倍 |
| 256か所 | 1.0427倍 | 1.1156倍 | 0.1596 | 9.0台 | 1.0966倍 |

- **1台を何か所にも分けて置くと、止まった台の分はいくつもの台に散り、いちばん多く受け取った台の量は平均に近づいた**。16か所では7.471台が受け取り、いちばん多く受け取った台でも止まった台の分の0.333（3分の1）だった
- 平均の2倍以上になった割合は、1か所37.14%、4か所12.72%、16か所0.1%、32か所以上で0.0%だった（`results/by_points.csv` の share_top_recv_ge_2x）
- 置き場所を増やすと、止まる前のいちばん多い台も平均に近づいた（1か所2.9661倍→128か所1.1413倍）。止まったあとのいちばん多い台は、どの置き場所の数でも止まる前とほぼ同じ倍率だった

### 確かめ：24通り（`results/grid.csv`）
- 置き場所1か所の8通りでは、受け持った次の台の量の平均は1.6〜1.96倍で、8通りすべてで等間隔の式 2×（台数−1）÷台数 と同じ値だった（差は0.0）。90%点は2.6486〜3.822倍、最大は3.6732〜11.7992倍で、台が多いほど大きかった
- いちばん多く受け取った台の量の平均は、16か所の8通りで1.1609〜1.2164倍、128か所の8通りで1.0563〜1.0663倍だった
- 止まったあとのいちばん多い台の平均は、1か所で2.0839〜4.4555倍、128か所で1.0912〜1.2622倍だった。データの件数（1万・10万件）による違いは小さかった

## 注意（言えないこと）
- 架空のデータです。データと台の置き場所を輪の上に一様な乱数で置き、データの読み書きの多さはどれも同じと置きました。読み書きがいくつかのデータに集まる場合は、受け持つ台の負荷はもっと偏ります（数えていません）
- 受け持った台の「量」は件数だけで数えました。止まった台のデータを次の台へ写す時間や、その間の読み書きは数えていません
- 止まるのは1台だけ、どの台も同じ確率で止まると置きました。続けて2台止まる場合は数えていません
- 何か所に分けて置くのがよいか、何台用意するかを言うものではありません。台数・費用の見込みの助言はしていません
