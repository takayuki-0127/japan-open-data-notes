# 205 人口あたりの図書館の貸出冊数は、どこが多いか：社会教育調査

文部科学省「社会教育調査」の図書館の貸出冊数（都道府県別）を、総務省「人口推計」の人口で割って、1人あたりの貸出冊数を都道府県で比べたフォルダです。全国の貸出冊数の推移（2014・2017・2020・2023年度）と、図書館の数との関係も見ています。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A205 | 人口あたりの図書館の貸出冊数は、どこが多いか | 都道府県別の1人あたり貸出冊数のランキング（2023年度）、全国の貸出冊数と児童書の割合の推移、人口10万人あたり図書館数との散布図・相関 | `src/a205_library.py` |

## 主な結果
- 全国の1人あたり貸出冊数は2023年度4.78冊（2020年度4.21冊）
- 多いのは滋賀県7.30冊、東京都6.93冊、高知県6.93冊、福井県6.26冊、鳥取県6.22冊。少ないのは青森県・秋田県2.74冊、鹿児島県2.89冊、沖縄県3.10冊、宮崎県3.18冊。最多と最少の差は2.7倍
- 全国の貸出冊数は2014年度6.62億冊→2017年度6.54億冊→2020年度5.31億冊→2023年度5.94億冊。2023年度も2014年度より10.3%少ない
- 貸出のうち児童書の割合は28.4%（2014年度）→33.0%（2023年度）
- 人口10万人あたりの図書館数と1人あたり貸出冊数の相関係数は0.25と弱い。神奈川県は0.91館で3.32冊、秋田県は5.36館で2.74冊、高知県は6.01館で6.93冊
- 2020→2023年度で1人あたり貸出冊数は47都道府県中44で増えた

## データ
| ファイル | 中身 |
|---|---|
| data/library_loans_raw.csv | 調査年度、都道府県、図書館数、登録者数、帯出者数、貸出冊数、うち児童書の貸出冊数 |
| data/population_pref.csv | 都道府県別の総人口（千人、2015・2020年は国勢調査、2021〜2023年は10月1日現在の推計） |

- 社会教育調査「図書の貸出業務等の実施状況」の表：令和5年度間（statInfId 000040439495）、令和2年度間（000040038489）、平成29年度間（000031924416）、平成26年度間（000031559141）
- 人口推計「都道府県，男女別人口（各年10月1日現在）」（statInfId 000040166077）
- ブラウザで Excel を読み、都道府県別の行を書き写した。1人あたりの値は2023年度は2023年10月1日、2020年度は2020年10月1日の人口で割った

## 注意
- 社会教育調査の「図書館」は図書館法の図書館（公立と私立）で、学校図書館や大学図書館、公民館図書室は入っていない
- 貸出冊数は図書館がある都道府県で数えるため、県境を越えて借りる人や、都道府県立図書館の貸出も含まれる
- 2020年度は新型コロナで休館や利用制限があった年で、他の年と同じようには比べられない
- 2014・2017年度は都道府県別の人口をそろえていないので、1人あたりの比較は2020・2023年度だけにした
- 登録者数は自治体ごとに数え方（有効期限の扱いなど）が違い、県によっては人口に近い値や前回から大きく動いた値があるため、分析には使っていない
- 貸出が多い理由（図書館の広さ、開館時間、電子書籍、書店の数など）は、このデータでは分からない
