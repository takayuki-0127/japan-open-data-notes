# 1186 平均の対応時間が短い担当は、手早い担当なのか、易しい問い合わせを受けた担当なのか？（問い合わせ対応）

問い合わせ窓口で、担当ごとの「1件あたりの平均の対応時間」を並べることがあります。ところが、担当によって受ける問い合わせの種類の混ざり方が違うと、平均の時間の短さは、手早さよりも「易しい種類を多く受けたこと」を表します。**ここでは、作成者が置いた架空の会社の窓口（担当20人が1か月に300件ずつ、易しい順に4つの種類。担当ごとの本当の手早さと、受ける種類の混ざり方を作成者が置いたもの）で、平均の対応時間の順と、種類をそろえた比の順が、本当の手早さの順とどれだけ合うかを200回数えました。手早さと混ざり方の関係・混ざり方の差の大きさ・同じ種類の中の見えない難しさの偏りを変えた36通りでも確かめました。**

例の会社・窓口・担当は作成者が置いたもので、実在の会社や人を表すものではありません。担当は番号（担当01〜20）で呼び、人の属性では比べていません。人事評価や処遇の決め方の助言でもありません。

担当ごとの本当の手早さ（同じ問い合わせにかかる時間の倍率）は、作成者が置いた値です。種類ごとに混ざり方が違っても、本当の倍率が同じなら種類をそろえた比は同じになるように作っています（作りどおり）。この記事で数えて新しく分かったのは、混ざり方の配り方しだいで平均の時間の順がどこまで外れるか、種類をそろえた比がどこまで戻すか、種類で見えない難しさが偏るとそれがどこまで崩れるかです。

関連する記事：695「1人あたりの処理件数を、出勤した日数で割るか働いた時間で割るかで、担当者の順位はどれだけ入れ替わるのか？」は、件数を割る分母で担当者の順位がどう変わるかを扱っています。941「部署ごとの平均点の差は、人の差か評価者の差か？」は、部署の平均点の差に評価者の甘さ辛さがどれだけ混ざるかを扱っています。この記事は、担当ごとの平均の時間に、受けた問い合わせの種類の混ざり方がどれだけ混ざるかに絞ります。同じ企画の 1192「担当から担当へ回された問い合わせの解決を、どの担当の数字に入れるかで、担当ごとの解決率はどう変わるのか？」は、回された件の数え方の決まりで担当の解決率の順が変わる場面、1196「返事が遅いほど満足度が低く見えるのは、遅さのせいか、難しい問い合わせほど遅く満足も低いからか？」は、同じ難しさの混ざり方が満足度との関係に入る場面を扱っています。

## 主な結果

### 例の1か月（`results/example_month.csv`）
- 担当20人の平均の対応時間は11.19〜33.39分、難しい種類（C・D）の割合は11.33〜66.33%だった。平均の時間の順と、難しい種類の割合の順の順位の相関は0.853だった
- 平均の時間の順と本当の手早さの順の順位の相関は**−0.024**で、ほとんど関係がなかった。種類をそろえた比の順では**0.955**だった
- 平均の時間が3番目に短い担当14（難しい種類は11.33%）は、本当の手早さでは16番目だった。本当の手早さが3番目の担当18は、難しい種類が65.0%で、平均の時間では16番目だった

### 基本の置き方で200回（手早さと混ざり方の相関0.5、混ざり方の差は広い、見えない偏りなし。`results/a1186_main.json` の base）
| | 平均の対応時間の順 | 種類をそろえた比の順 |
|---|---|---|
| 本当の順との順位の相関（200回の平均） | **−0.071** | **0.918** |
| 上位5人のうち本当の上位5人に入った人数（平均） | 0.92人 | 4.13人 |

- 平均の時間がいちばん短い担当が、本当の上位5人に入っていたのは200回の20.5%だった。その担当が受けた難しい種類の割合は平均14.6%だった
- 平均の時間の順と本当の順の相関がマイナスになったのは、200回の60.0%だった

### 確かめ：36通り（`results/grid.csv`）
| 手早さと混ざり方の相関（混ざり方の差は広い、見えない偏りなし） | 平均の対応時間の順 | 種類をそろえた比の順 |
|---|---|---|
| −0.5（手早いほど易しい種類） | 0.682 | 0.922 |
| 0（関係なし） | 0.333 | 0.927 |
| 0.5（手早いほど難しい種類、基本） | −0.071 | 0.918 |
| 0.8 | −0.444 | 0.916 |

- **平均の対応時間の順と本当の順の相関は、36通りで−0.613〜0.864と動いた**。全員が同じ混ざり方なら0.846〜0.864だった
- 手早い担当ほど易しい種類を受ける置き方（−0.5）では、平均の時間の順は本当の順に寄り（0.682）、手早い担当ほど難しい種類を受ける置き方（0.8）では逆の順に寄った（−0.444）
- **見えない偏りがないとき（12通り）、種類をそろえた比の順の相関は0.916〜0.932で、混ざり方の配り方によらなかった**
- **同じ種類の中の見えない難しさが偏ると、種類をそろえても戻しきれなかった**。混ざり方の差が広く相関0.5のとき、種類をそろえた比の相関は、偏りなし0.918、0.15で0.622、0.3で0.193だった。36通りでいちばん低いのは−0.129（相関0.8、偏り0.3）
- 36通りすべてで、種類をそろえた比の相関は平均の時間の相関より高かった

## 注意（言えないこと）
- 架空のデータと、作成者が置いた架空の窓口です。種類ごとの時間、混ざり方、手早さの差、混ざり方の配り方を変えれば、結果は変わります。実在の窓口の担当を表すものではありません
- 種類をそろえた比が本当の順に近づいたのは、種類の違いで時間の差のほとんどが決まり、種類の中の見えない難しさが担当に偏らないと置いたときです。種類の付け方が粗い、または同じ種類の中の難しい件が特定の担当に回る場合は、そろえても戻りません（36通りで−0.129まで下がった）
- 対応時間だけを数えました。答えの正しさ、もう一度来る問い合わせ、受けた件数の違いは入れていません
- 担当どうしを比べてよいか、比べた結果を人事評価や処遇にどう使うかの助言ではありません。人の属性による比較もしていません
