# 1136 明るい所と暗い所を1枚に収める処理で、明るさの順番は入れかわるのか？（画像と色）

窓のある部屋のように、明るい所と暗い所の差が何千倍もある場面は、そのままでは画面の256段階に収まりません。収め方には、①場面全体に同じ曲線をかけて縮める方法と、②部分ごとに周りの明るさを見て、明るい所は暗めに、暗い所は明るめに合わせる方法があります。①は明るさの順を変えませんが、暗い所が少ない段階に押しこまれます。②は暗い所の違いも見えるようにしますが、場所によって合わせ方が違うので、本当は明るい物が画面では暗く出ることがあります。**ここでは、作成者が置いた架空の場面（左半分が部屋、右半分が照明1000倍の窓の外、両側に白さの違う板12枚ずつ）で、2つの処理で256段階に収めたときに、板24枚の276組と画素の組20万組で、本当の明るさの順と画面の順が入れかわった割合・同じ段階につぶれた割合を数えました。周りの明るさを縮める強さ・周りの明るさを取る広さ・照明の差を変えた27通りでも確かめました。**

例の場面・板は、すべて作成者が式と乱数で置いたもので、実在の写真・カメラ・画像ソフトを表すものではありません。明るさの順は、作成者が置いた光の強さ（照明×白さ）と画面の値（0〜255）で比べたもので、人に見せて感じる明るさを確かめたものではありません。

関連する記事：同じ企画の 1129「明るさの差を数値のまま測ると、人が見て感じる差とどこでずれるのか？」は、画素の値の差と感じる明るさの差のずれを、作成者が置いた見え方の式で数えています。この記事は、差の大きさではなく、明るさの順が保たれるかに絞ります。1126「色の値をそのまま平均して混ぜた色は、なぜ暗く濁って見えるのか？」は、色の値が光の量を約2.2乗の形で縮めて記録した数であることを扱っています（この記事の②も、最後に同じ決まりで256段階にしています）。1133「色の段階を減らして保存すると、なめらかな空の明るさにどれだけ段ができるのか？」は、明るさを決まった段階に丸めたときにできる帯を扱っています（この記事の「同じ段階につぶれた組」も、256段階への丸めで起きます）。31冊目の 949「色分けの区切り（等間隔・同じ件数）で、地図の印象はどう変わるのか？」は、数字を少ない段階に分けると、違う値が同じ色になることを地図で扱っています。

### 板24枚の276組（基本、`results/a1136_main.json`）

| 全部の組の入れかわり | 0% | 6.16% |
| 同じ段階につぶれた組 | 2.9% | 0% |
| 部屋の板12枚の画面の値の幅（最大−最小） | 5.06 | 43.8 |
| 窓の外の板12枚の画面の値の幅 | 153 | 62.33 |

- **①は、どの組も明るさの順が入れかわらなかった（明るさの順に並べた値を縮める曲線なので、作りどおり）**。そのかわり、部屋の板12枚は0〜255のうち幅5.06に押しこまれ、同じ側どうしの組の6.06%が同じ段階につぶれた
- **②は、部屋の板12枚を幅43.8に広げてすべて見分けられるようにしたが、板の組の6.16%で明るさの順が入れかわった**。例では、部屋の白さ0.9の板（画面の値55.8）が、本当は201倍明るい窓の外の白さ0.18の板（54.1）より明るく出た
- 同じ側どうしの入れかわりは、部屋と窓の外の境目の近くで起きた。窓の外の、境目から32画素の板は周りに暗い部屋が入るので明るめに出て、白さ0.04の板（47.3）が、境目から120画素の白さ0.13の板（45.8）を上回った

## 注意（言えないこと）
- 架空のデータです。場面の作り（部屋と窓の外の境目がまっすぐ）、板の白さと置き場所、2つの処理の式、縮める強さとぼかしの広さは作成者が置いたもので、入れかわりの割合はこれで決まります（27通りで0〜26.39%）
- ①で入れかわりがないのは、明るさの順に並べた値を縮める曲線を使ったための作りどおりの結果です
- 明るさの順は、光の強さと画面の値で比べました。人の目は周りとの差で明るさを感じるので、②で入れかわった組が、見た人に「逆」に見えるとは限りません（推測）
- ここで数えた2つ以外の収め方（境目をよけてぼかすものなど）は数えていません
- 実在のカメラ・画像ソフトの処理を表すものではなく、どちらの処理を使うべきかも言えません
