# 970 「答えなかった人」は、答えた人と同じなのか？（欠けたデータ）

アンケートの結果は、答えた人だけで出します。答えなかった人の答えは分からないので、「答えなかった人も答えた人と同じだろう」と読んでいることになります。よく使われる確かめ方に、「催促してから答えた人は、答えなかった人に近いはず」と考えて、1回目に答えた人と催促後に答えた人を比べるものがあります。**ここでは、作成者が乱数で作った架空のサービスの利用者8,000人（全員の「満足しているかどうか」を、答えなかった人の分まで作成者が置いたもの）で、答えるかどうかの決まり方を2つ置き、答えなかった人の満足が回答者とどれだけ違うか、回答者そのまま・利用年数で重み・答えなかった人を催促後の回答者と同じと置く、の3つの見積もりがどれだけ外れるかを数えました。**

利用者・サービス・アンケートはすべて架空のもので、実在の会社の数字は使っていません。

関連する記事：口コミを書かなかった人の満足は 803、謝礼で回答者の顔ぶれが変わることと、利用の多さで重みを付ける直し方は 870、途中でやめた人の回答の扱いは 866 で扱っています。同じ企画の 969 は1つの欄の空欄を除いた平均を、979 は名簿の区分で重みを付けてどこまで戻せるか（この記事の②を、区分を増やして詳しく見たもの）を、978 は答えなかった人だけを電話など別の方法で埋めたときに混ざるものを、980 は答えなかった理由が分からないときに何も仮定しない幅で何まで言えるかを扱います。この記事は、アンケートにまるごと答えなかった人と、催促後の回答者を手がかりにする読み方に絞ります。

## 主な結果

### 1回目・催促後・答えなかった人の満足の割合（300回の平均）
| | A：答えにくさが続いている | B：答えない人に忙しい人 |
|---|---|---|
| 1回目に答えた人 | 69.69% | 61.41% |
| 催促後に答えた人 | 66.20% | 57.42% |
| 回答者（合わせて） | 68.38% | 59.91% |
| **答えなかった人（ふつうは見えない）** | **54.32%** | **60.05%** |
| 全員の本当の割合 | 59.94% | 59.99% |
| 答えなかった人−回答者 | **−14.06ポイント** | +0.14ポイント |
| 答えなかった人−催促後に答えた人 | −11.88ポイント | +2.63ポイント |
| 回答率（1回目／催促後まで） | 24.97%／39.96% | 25.04%／40.08% |

- Aでは、答えなかった人の満足の割合は回答者より14.06ポイント低かった。満足している人ほど答えると置いたことから出る向きで、新しく数えたのはその大きさ
- Bでも、1回目から催促後へ満足の割合は下がった（61.41%→57.42%）。この下がり方から「答えなかった人はもっと低い」と読みたくなるが、答えなかった人は60.05%で、回答者（59.91%）とほぼ同じだった。満足している割合の高い忙しい人が、答えなかった人に多くまざっていたため

### 見積もりの外れ（見積もり−全員の本当の割合、300回の平均）
| 見積もり | A | B |
|---|---|---|
| 1回目の回答者だけ | +9.75ポイント | +1.41ポイント |
| ①回答者そのまま | **+8.44ポイント** | **−0.08ポイント** |
| ②利用年数で重み | +7.48ポイント | −0.98ポイント |
| ③答えなかった人を催促後の回答者と同じと置く | **+7.14ポイント** | **−1.58ポイント** |

- Aでは、③で外れは8.44→7.14ポイントに縮んだが、多くは残った。催促後の回答者も、答えなかった人より満足の割合が11.88ポイント高かったため
- Bでは、①の外れはほぼ0（−0.08ポイント）だったのに、②で−0.98、③で−1.58ポイントに広がった。ただし③で外れが広がったのは、Bの置き方15通りのうち4通り（答えなかった人のほうが満足の割合が高い置き方）で、残りの11通りでは③のほうが外れが小さかった。Bの①がほぼ0になったのは、置いた値で満足している人ほど答える向きと、満足している忙しい人が答えない向きがたまたま打ち消し合った結果で、Bの置き方を変えると外れは−8.30〜+11.15ポイントと動いた
- 300回のうち10〜90%の範囲は、Aの①が+7.64〜+9.30ポイント、Aの③が+6.09〜+8.18ポイント、Bの③が−2.75〜−0.42ポイント
- 回答者と全員の利用年数の構成の差は、区分ごとの差のいちばん大きいところでAが6.04ポイント、Bが5.12ポイント。台帳で見える構成のずれは、満足の割合のずれの大きさを教えてくれない

|---|---|---|---|

- Aで満足の答えやすさを置いた9通り（オッズ1.4〜3.0倍）では、答えなかった人は回答者より8.75〜26.15ポイント低く、9通りすべてで③は①より外れが小さかったが、③の外れも+2.92〜+17.32ポイント残った
- Aでオッズ1.0倍（満足と答えやすさが無関係）の3通りでは、①の外れは+0.70〜+1.24ポイントで、利用年数の違いの分だけだった
- 27通りすべてで、1回目の回答者のほうが催促後の回答者より満足の割合が高かった。それでも、Bの15通りのうち4通りでは答えなかった人のほうが回答者より満足の割合が高く、③が①より外れたのも15通りのうち4通りだった。Bの15通りで、答えなかった人−催促後に答えた人は−15.41〜+14.86ポイント

## 動かし方
```
pip install -r requirements.txt
cd src && python a970_nonrespondents.py
```
10秒ほどで終わります。`data/survey_example_B.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、2回流して2回とも一致、約8秒）
- 図3枚を開き、日本語・重なり・軸を確かめた
- 回答率が置いたねらい（1回目25%・催促後まで40%）どおりになり、全員の満足の割合が式どおりの60%前後になることを確かめた
- 満足と答えやすさを無関係（オッズ1.0倍）にすると、答えなかった人と回答者の差が利用年数の違いの分（−1.48ポイント前後）だけになり、利用年数で重みを付けると外れが0.1ポイント以内になることを確かめた

## 注意（言えないこと）
- 架空のデータです。答えやすさの決まり方、忙しい人の割合と満足は作成者が置いたもので、結果はこれで決まります。答えなかった人と回答者の差は、Bの15通りで−18.57〜+13.84ポイント、Aで満足の答えやすさを置いた9通りで−26.15〜−8.75ポイントと動きました。実在のサービスの数字を表すものではありません
- 実際のアンケートで、答えなかった人の満足は分かりません。この記事では、催促後の回答者を手がかりにする読み方が、当たる置き方と外れる置き方があることを示しただけです
- 答えなかった人の一部に改めて聞く、別の記録と突き合わせるといった方法は数えていません
- どの直し方を使うべきかは、答えない理由が分からない限り、この記事では言えません
