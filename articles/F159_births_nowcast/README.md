# F159 出生数の予測を、毎月の速報で更新すると当たり方は変わるか？（ナウキャスト）

看板記事 F159。note の記事：「出生数の予測を、毎月の速報で更新すると当たり方は変わるか？ 公表日どおりに2012〜25年をやり直すと、速報が1〜3か月分のうちは年初の予測より外れが大きく、11月には1.5%から0.5%まで縮んだ。2026年は66.3万人前後と出た」（note のURLは公開後に記入）

## 問い

F55 では、前年までの確定数だけで、その年の出生数を予測した（構造時系列モデル）。けれど実際には、年の途中から毎月「速報」と「概数」が出てくる。これを公表された日付どおりに足していくと、年間の出生数（確定数）の推計はいつから、どれだけ当たるようになるか。速報（外国人を含む）と確定数（日本人）の違いは、どう直せばよいか。

## データ

| データ | 中身 | 公表の遅れ | 期間 |
|---|---|---|---|
| 人口動態統計速報（厚生労働省） | 出生数。日本における外国人・外国における日本人を含む | 2か月後の月（236回すべて。月末から48〜61日、中央値53日） | 2005年1月〜2026年8月（2007年1月分〜2026年8月分の236回の表から） |
| 人口動態統計月報（概数） | 出生数（日本における日本人）の「当月を含む過去1年間」の合計 | 約5か月後（12月分は翌年6月の年計） | 2011年2月〜2026年5月（184回） |
| 人口動態統計（確定数） | 出生数（日本における日本人）、月別 | 翌年9月末 | 2000〜2025年（F02 と同じ） |

- 速報も概数の12か月合計も、回をまたいで値が書き換えられたことはなかった。そのため「その日に見えていた値」は、最後の表の値と同じになる。
- 概数の年計は、確定数と0.03%以内で一致した（2011〜2025年）。
- 取得方法は `src/01_取得.md`、出典は `data/raw/SOURCES.md` に書いた。

## 手法

対象は2012〜2025年の各年 Y の年間出生数（確定数）。Y年1月1日からY+1年10月1日まで、毎月1日の22時点で推計した。各時点では、その日までに公表されていたものだけを使っている。

| 方法 | 中身 |
|---|---|
| A 年初の予測（F55型） | Y−1年までの確定数（月次、直近10年）に構造時系列モデルを当てて、Y年を予測する。log（1日あたり）に局所線形トレンドと固定の季節を置き、statsmodels の UnobservedComponents で推定。時点によらず一定。確定数が出るのは翌年9月なので、実際には年初に使えない有利な条件で作っている |
| B 速報だけ | 前年の速報の年計に、速報の年初からの前年同期比と換算比（確定÷速報、最新の確定年の値）を掛ける |
| C 概数だけ | 前年の年間（確定 → 年計概数 → 速報×換算比の順に、その時点で一番よいもの）に、概数の前年同期比を掛ける。前年同期比は「概数の12か月合計の増減 ÷ 前年同期の出生数」で出す |
| D 速報＋概数 | C と同じ前年の年間に「速報の前年同期比 ＋ 概数と速報の前年同期比の差」を掛ける。差は、両方が出ている月で計算する。外国人の出生の増え方の分を、同じ年の概数で直すため |
| E 速報＋概数＋モデル | D の補正を入れた月次の系列に A と同じモデルを当て直し、まだ出ていない月を予測して足す |

- 評価は、確定数との外れ（%）の平均絶対値（MAE）。2012〜2025年の14年で平均した。
- 区間は、その年より前の年の、同じ時点での外れの二乗平均（RMSE）から、正規分布で80%・95%の幅を作った。2016〜25年のY年4月〜Y+1年2月の各時点で、実際に入った割合を確かめた。

## 主な結果

- **年初の予測（A）の外れは平均1.46%** だった。平均すると高めに外れていて（+0.79%）、減り方が予測より速かった年が多い。
- **速報を1〜3か月分だけ足すと、かえって悪くなる。**
  - 4月1日・5月1日・6月1日時点の D の外れは、2.37%・2.71%・1.80%。月ごとの前年比の揺れが大きいためで、2021年は1〜3月の急な減少で −6.0% まで外れた。
  - モデルで残りの月を延ばす E では、1.64%・1.37%・1.41% だった。5月以降は A を下回る。
- **夏以降は、時点が進むほど外れが縮む。**

  | 時点 | A | D | E |
  |---|---|---|---|
  | 8月1日 | 1.46% | 1.14% | 1.02% |
  | 10月1日 | 1.46% | 0.88% | 0.71% |
  | 11月1日 | 1.46% | 0.73% | **0.48%** |
  | 翌年1月1日 | 1.46% | 0.36% | 0.25% |

  12か月分の速報がそろう翌年3月1日には、D・E とも 0.03% になった。確定数の半年前にあたる。
- **概数だけ（C）は遅い。** 11月1日に1.11%、翌年3月1日でも0.46%で、確定数の基準に近いのに、5か月の遅れが効いている。
- **速報を確定数に直す比（確定÷速報）が、2023・24年に大きく下がった。**
  - 比は 0.975（2005年）→ 0.964（2022年）→ 0.959（2023年）→ 0.952（2024年）→ 0.951（2025年）。外国人の出生が速報に含まれるため（推測：外国人の出生の割合が増えた）。
  - 前年の比をそのまま使う B は、12か月分の速報がそろっても 2023年 +0.53%、2024年 +0.73% 外れた。
  - 概数との差で直す D・E は、それぞれ +0.04% だった。
- **区間は狭すぎた。** 80%区間に入ったのは D で74%・E で66%、95%区間は 87%・85% だった。過去の年数が少ないため。
- **2026年（2026年11月3日時点、速報は1〜8月・概数は1〜5月）：**
  - 速報の1〜8月は前年同期比 −0.09% とほぼ横ばいだった。ただ、概数（日本人）の前年同期比は速報より 0.36ポイント低い。
  - 各方法の推計：

    | 方法 | 2026年の推計 |
    |---|---|
    | D | 66.83万人 |
    | E | 66.30万人（95%区間 65.54〜67.06万人） |
    | C | 67.18万人 |
    | B | 67.07万人 |
    | A | 66.14万人 |

  - F55 の予測は 66.30万人（62.3〜71.4万人）で、E の推計は F55 の中央値とほぼ同じになった。D と E はどちらも、2025年の確定数 67.13万人を下回る。
  - E の推計は、2026年4月以降の公表のたびに 65.1〜67.2万人のあいだで動いた。

## 頑健性

D の平均絶対誤差（%）。

| 確かめたこと | 6月1日 | 9月1日 | 12月1日 | 翌年3月1日 |
|---|---|---|---|---|
| 基本（換算比＝前年の値） | 1.80 | 1.05 | 0.46 | 0.03 |
| 換算比＝直近3年の平均 | 1.76 | 1.05 | 0.46 | 0.03 |
| 換算比＝直近5年の傾きで1年先へ延ばす | 1.78 | 1.05 | 0.46 | 0.03 |
| 概数との差で直さない | 1.80 | 0.96 | 0.49 | 0.21 |
| 残りの月を直近3か月の前年比で延ばす | 1.80 | 0.95 | 0.40 | 0.03 |
| 公表を1か月遅れで使う | 2.71 | 1.14 | 0.73 | 0.24 |

- 換算比の決め方や、残りの月の延ばし方では、結果はほとんど変わらなかった。
- 効いたのは公表のタイミングと、概数での補正だった。ただし概数での補正は、概数が2〜3か月分しかない9月1日時点では、補正しないほうが少し良かった（1.05% と 0.96%）。
- 期間で分けると、E の外れは12月1日時点で 2012〜19年 0.27%、2020〜25年 0.67%。2020〜25年は、6月1日時点で E（1.87%）が A（1.77%）より悪かった。コロナ期の急な変化を、年の前半の数か月からは読み切れていない。2020・21年を除くと、9月・12月時点の D と E の差はほぼなくなった（0.90% と 1.10%、0.38% と 0.40%）。どの期間でも、11月以降は A より外れが小さかった。

## このデータで言えないこと

- 2026年の推計は「1〜8月の動きと、これまでの減り方が続いた場合」の計算で、確定数（2027年9月公表予定）とずれる可能性がある。区間は過去の外れから作ったもので、実際には狭すぎた（95%区間の的中は85%）。
- 比べたのは2012〜25年の14年だけで、方法の差（たとえば E と D の0.25ポイント）は年の入れ替えで動く大きさ。
- 速報と確定数の比が下がった理由を、このデータでは確かめていない（外国人の出生の割合の増加は推測）。
- A は確定数が出る前に使えない有利な条件で作っている。また F55 そのもの（PyMC のベイズ構造時系列）ではなく、同じ形のモデルを最尤法で当てたもの。
- 出生数の増減の理由（結婚・景気・政策など）は扱っていない。
