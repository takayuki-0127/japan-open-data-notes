# 01 取得（Chrome のページ内で実行）

厚生労働省のサイトはコンテナから直接取れないため、Chrome で https://www.mhlw.go.jp/toukei/list/81-1a.html を開き、ページ内の JavaScript で次を行った（2026-11-03）。

1. ページ内の「人口動態統計速報」の各月リンク（/toukei/saikin/hw/jinkou/geppo/sYYYY/MM.html、2007年1月〜2026年8月の236件）と「月報（概数）」の各月リンク（.../mYYYY/MM.html、257件）を集める
2. 各ページを fetch（Shift_JIS を TextDecoder でデコード）し、公表日（「令和8年10月23日」など）と Excel のリンクを取る
   - 速報：「当月分及び当月を含む過去１年間（12ヶ月）の動向」（xls/YYYYMM.xls(x)）
   - 概数：「当月分を含む過去１年間の動向」（xlsx/M-18.xlsx など。2011年1月分以前は Excel なし）
3. SheetJS（xlsx@0.18.5）で読み、出生の行（速報は「当月」の3年分、概数は「総数」の3年分の12か月合計）を取り出す
4. 速報：各年の12か月を、その年が入っている回の表からまとめる（回による書き換えはなかった）。概数：各回の「その月」の12か月合計と公表日を記録する

確定数（kakutei_monthly_2000_2025.csv）は F02 の data/raw/births_monthly_2000_2025.csv をコピーした。
