# 459 選ばれた人や店だけで相関を見ると、相関はどれだけ小さく見えるのか（手法の解説）

入社試験の点数と入社後の成績、出店前の評価と開店後の売上のように、**選ばれた側のデータしか残らない**場面で、相関がどれだけ小さく（ときには逆向きに）見えるかを、正解の分かる架空のデータで測ったフォルダです。範囲の制限の補正式がどこまで戻すかも試しました。434（残った店だけの平均）・393（測り間違い）・364（平均への回帰）とは別で、相関の縮み方に絞っています。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A459 | 本当の相関0.3・0.5・0.8のとき、上位だけを残すと相関はいくつに見えるか。選び方（x の上位／x と似た別の点数の上位／x と y の合計の上位／中を除く）でどう違うか。符号が逆に出る割合、補正式で戻る幅 | 2つの数字 x・y を2変量正規で1,000人分作り、選んだ側だけの相関を出す（各4,000回）。補正は、選ぶ前後の x の標準偏差の比を使う式 | `src/a459_range_restriction.py` |

## 置いたこと（架空）
- x は選ぶ前に分かる点数、y はあとの成績。どちらも平均0・標準偏差1の正規分布で、相関は0.3・0.5・0.8
- 選ぶ前の人数は1,000人。残す割合は90%〜5%
- 選び方：① x の上位だけ（「x の下位を除く」も同じ決まり）、② x と相関0.7の別の点数 z の上位だけ（z は y と直接は関係しない）、③ x と y の合計の上位だけ（あとの成績も選ぶ材料に入っている）、④ x の上位と下位だけ（中を除く）
- 補正式：補正後 = r×u ÷ √(1 + r²(u²−1))。u は、選ぶ前の x の標準偏差 ÷ 選んだあとの x の標準偏差。選ぶ前の標準偏差は分かっているとする

## 主な結果
### 選ばれた側だけの相関（4,000回の平均）
| 選び方 | 本当の相関 | 残す90% | 70% | 50% | 30% | 20% | 10% | 5% |
|---|---|---|---|---|---|---|---|---|
| x の上位だけ | 0.3 | 0.26 | 0.22 | 0.19 | 0.16 | 0.14 | 0.13 | 0.11 |
| | 0.5 | 0.44 | 0.38 | 0.33 | 0.28 | 0.26 | 0.23 | 0.21 |
| | 0.8 | 0.75 | 0.68 | 0.63 | 0.57 | 0.53 | 0.48 | 0.44 |
| 似た別の点数の上位だけ | 0.5 | 0.47 | 0.45 | 0.43 | 0.42 | 0.41 | 0.41 | 0.40 |
| x と y の合計の上位だけ | 0.3 | 0.14 | −0.04 | −0.19 | −0.34 | −0.42 | −0.52 | −0.59 |
| | 0.5 | 0.36 | 0.19 | 0.04 | −0.12 | −0.21 | −0.33 | −0.42 |
| | 0.8 | 0.73 | 0.63 | 0.53 | 0.41 | 0.32 | 0.20 | 0.10 |
| x の上位と下位だけ | 0.5 | 0.52 | 0.56 | 0.62 | 0.68 | 0.72 | 0.77 | 0.81 |

- x の上位だけの結果は、正規分布の式で出した値と0.007以内で一致
- 符号が逆（マイナス）に出た割合：x の上位2割（200人）で、本当の相関0.3なら2.2%、上位1割（100人）なら11.6%。合計の上位では、本当の相関0.3なら残す割合50%以下で100%、0.5でも30%以下で96%以上

### 補正式で戻した相関（残す割合20%）
| 選び方 | 本当の相関0.3 | 0.5 | 0.8 |
|---|---|---|---|
| x の上位だけ | 0.29 | 0.49 | 0.80 |
| 似た別の点数の上位だけ | 0.30 | 0.50 | 0.80 |
| x の上位と下位だけ | 0.30 | 0.50 | 0.80 |
| x と y の合計の上位だけ | −0.55 | −0.31 | 0.53 |

- 補正後の値の散らばり（標準偏差）：x の上位2割で、本当の相関0.3なら0.13、0.5なら0.10。上位1割では0.21と0.17
- 式の前提と違う場合（本当の相関は全体で測った値、上位2割）：x が高いほど y の散らばりが大きいと、全体0.45に対して補正後0.27。x が高いと頭打ちになる関係だと、全体0.61に対して補正後0.11

## 確かめたこと
- 空のフォルダで計算し直し、data・results・figures が一致した
- x の上位だけを残したときの相関は、切り取った正規分布の式と0.007以内で一致
- 残す割合が大きいほど、選ばれた側の相関は本当の相関に近づく

## 注意（言えないこと）
- 架空のデータです。x と y は正規分布で、関係は直線、y の散らばりは x によらない、と置きました。補正式がうまく戻したのは、この置き方に合う選び方だけです
- 実際には、どんな決まりで選ばれたかが分からないことが多く、選ぶ前の x の標準偏差も分からないことがあります。その場合、補正式は使えません
- 「x と y の合計で選ぶ」のように、あとの成績（かそれに近いもの）が選ぶ材料に入っていると、補正式ではかえって大きく外れます。そうなっているかどうかは、選ばれた側のデータだけでは見分けられません
- 相関だけを見ています。回帰の傾きは、x だけで選んだ場合は変わりません（確かめていません）
- 選ばれなかった側の y は、ふつうは手に入りません。この記事の「本当の相関」は、架空のデータだから分かる数字です
