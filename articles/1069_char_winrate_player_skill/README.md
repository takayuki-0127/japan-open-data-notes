# 1069 キャラクターごとの勝率は、使う人のうまさでどれだけ動くのか？（対戦とレーティング）

対戦ゲームでは、キャラクターごとの勝率を並べて「どのキャラクターが強いか」を読むことがよくあります。けれども、勝率にはキャラクターの強さのほかに、そのキャラクターを使う人のうまさが混ざります。うまい人が好んで使うキャラクターは、強くなくても勝率が高く出ます。点数の近い人どうしで当てていても、点数には誤差があるので、この混ざりは消えきりません。**ここでは、作成者が乱数で作った架空の対戦ゲーム（プレイヤー6,000人の本当のうまさと、10体のキャラクターの本当の強さ・むずかしさを作成者が置いたもの）で、キャラクターごとの勝率を4つの数え方で出し、本当の勝率（同じうまさの相手と当たったときの勝率）とどれだけずれるかを数えました。**

| 数え方 | 10体のずれの大きさの平均 | いちばん大きいずれ | むずかしい3体のずれ（平均） | やさしい2体のずれ（平均） | 本当の勝率との順位相関 |

- **②上位2割だけで見ると、ずれはかえって大きくなった**。上位2割に入るやさしいキャラクターの使い手は少なく、点数が誤差で高く出ている人が多く混じるため。上位2割どうしの試合は、A では1,127.2試合、B では8,064試合（5回の平均）だった
- **③点数の差で調整しても、ずれはほとんど減らなかった**（3.139→3.144）。点数の近い人どうしで当てているので、調整に使える点数の差がもともと小さく、点数の誤差の分も調整できないため
- ④本当のうまさで調整すると、ずれはほぼ消えた。ずれのもとは使う人のうまさだけ、という作りの確かめ。実際には本当のうまさは分からない
- プレイヤーを作り直した5回の間の振れ（標準偏差）は、①・③とも、どのキャラクターでも0.7ポイント未満（最大0.667・0.678）

### 確かめ：γ×点数の誤差×当て方（27通り、`results/sensitivity_grid.csv`）
- γ＝0（うまさで選ぶキャラクターが分かれない）の9通りでは、①のずれの大きさの平均は0.264〜1.031ポイントで小さかった（式どおり、使う人のうまさが同じならずれない）
- γ＞0 の18通りでは、①のずれは1.757〜12.07ポイント。当て方で、近い点数どうし1.757〜7.613、ゆるく近い点数どうし5.828〜8.675、くじ9.484〜12.07ポイント
- **③点数の差で調整したずれは、点数の誤差でほぼ決まった**：誤差0.25で1.049〜2.099、0.5で3.183〜5.142、1.0で6.216〜9.297ポイント（γ＞0 の各6通り）。①より小さくなったのは18通り中14通り
- ②上位2割どうしが①より小さくなったのは18通り中10通り
- I（本当は9位）の①での順位は、γ＞0 の18通りで3〜5位だった

## データ
- `data/players.csv`：基本の置き方の1回目のプレイヤー6,000人。player_id・skill（本当のうまさ）・points_visible（見えている点数）・char（使うキャラクター）
- `data/games_first_10rounds.csv`：同じ回の最初の10回分の対戦（3万試合）。game_id・player_a・player_b・char_a・char_b・win_a（a が勝てば1）

## 注意（言えないこと）
- 架空のデータです。キャラクターの強さとむずかしさ、選び方の偏り γ、点数の誤差、当て方は作成者が置いたもので、結果はこれで決まります。実在のゲームのキャラクターや勝率を表すものではありません
- 1人1体だけを使い、キャラクターの強さは使う人のうまさで変わらない（うまい人ほど強くなるキャラクターはない）と置きました。うまい人ほど力を出せるキャラクターがあると、「本当の勝率」そのものがうまさで変わり、1つの数では表せません
- 見えている点数は、本当のうまさに誤差を足しただけと置きました。点数がキャラクターの強さで上下することは入れていません
- どのキャラクターを使うべきか、調整（強さの変更）をすべきかの判断はしません。賭け・課金の話もしません
