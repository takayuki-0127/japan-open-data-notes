# 1205 1通に入れるリンクの数を増やすと、クリックした人の割合とクリックの回数はどう動くのか？（メール配信）

お知らせのメールの反応は、「クリックした人の割合」（1本でもクリックした人÷開いた人）でも、「クリックの回数」（全部のクリック÷開いた人）でも数えられます。リンクが1本なら、2つの違いは同じリンクを2回押す人の分だけですが、リンクを増やすと、1人が何本も押すので、回数は人の割合より大きく伸びます。回数が3倍になったのを「3倍の人が反応した」と読むと、反応した人の広がりを多く見ます。**ここでは、作成者が置いた架空の店の会員向けのお知らせのメール（開いた6,000人の1人ひとりのクリックしやすさ、リンクごとの引き、下のリンクほど押されにくい度合い、リンクが多いと1本ごとに押されにくくなる度合い（目移り）を作成者が置き、乱数で作ったもの）で、リンクの数を1〜10本に変えて、クリックした人の割合とクリックの回数がどう動くかを数えました。目移りの強さ・人ごとのクリックしやすさの差・下のリンクの押されにくさを変えた30通りでも確かめました。**

例の店・会員・メールは架空のもので、実在の店・メール配信の仕組みを表すものではありません。リンクを何本入れるとよいか、リンクの中身（値引きの訴求など）の良し悪しは扱っていません。

関連する記事：842「表示が増えると、クリック率は下がって見えるのか？」は、クリック率の分母（表示）に、クリックしにくい相手がまざる形を SNS の投稿で扱っています。同じ企画の 1197「開封率で選ぶかクリック率で選ぶかで、良い件名は入れかわるのか？」は、開封率とクリック率（送った数あたり・開いた人あたり）のどれで件名を選ぶかで、選ぶ件名が入れかわることを扱っています。この記事は、分母（開いた人）は同じまま、分子を「人」で数えるか「回数」で数えるかの違いに絞ります。同じ企画の 1204「迷惑メールに振り分けられた分は、開封率の数字のどこに表れるのか？」は、開いた通数あたりのクリックが、開いた人の顔ぶれで動く場面を扱っています。

## 主な結果

### リンクの数ごと（200回の平均、`results/by_k_base.csv`）
| リンクの数 | クリックした人の割合 | 開いた100人あたりのクリックの回数 | クリックした人1人あたりの回数 | 2本以上押した人からのクリック | 全員が同じなら（式） |
|---|---|---|---|---|---|
| 1本 | 17.09% | 21.34回 | 1.248回 | 0% | 17.1% |
| 2本 | 26.35% | 36.93回 | 1.396回 | 20.82% | 27.39% |
| 3本 | 31.55% | 47.49回 | 1.499回 | 31.83% | 33.36% |
| 5本 | 36.23% | 59.2回 | 1.629回 | 42.41% | 39.17% |
| 8本 | **37.68%** | **63.6回** | 1.684回 | 46.31% | 40.97% |
| 10本 | 37.1% | 62.79回 | 1.689回 | 46.63% | 40.42% |

- **1本から10本にすると、クリックした人の割合は2.1713倍、クリックの回数は2.9425倍になった**（5本では2.1199倍と2.7742倍）
- 回数÷人の割合は、クリックした人1人あたりの回数で、1本の1.248回（同じリンクを平均0.25回多く押すと置いた分、作りどおり）から10本の1.689回に増えた。10本では、クリックした人の27.96%が2本以上押し、クリックの46.63%はその人たちからだった
- 1本→10本で回数の比が人の割合の比を上回るのは、2本以上押す人がいれば必ずそうなる（作りどおり）。数えたのは、その差の大きさ
- 目移り（0.1）を置いたので、人の割合も回数も8本でいちばん高く、9本・10本では少し下がった。いちばん高くなる本数は、人の割合と回数で同じだった
- **人ごとのクリックしやすさに差があると、クリックした人の割合は、全員が同じだと置いた式より低かった**（10本で37.1%と40.42%）。押しやすい人が何本も押し、押しにくい人はどれも押さないため、リンクを増やしても新しく押す人が増えにくい
- 1本のときのクリックした人の割合は、どのリンクが1本目に来たかで大きく動いた（5〜95%の範囲で9.75〜26.22%）。10本では33.26〜41.75%だった
- 200回のうち12%の回では、10本は4本より回数が多いのに、クリックした人の割合は低かった

### 確かめ：30通り（各20回、`results/grid.csv`）
- **10本÷1本の比は、クリックした人の割合で0.9393〜4.9462倍、回数で1.103〜10.6915倍だった。30通りすべてで回数の比が上回った**（作りどおり）
- 目移りがない6通りでは、人の割合2.5193〜4.9462倍に対し、回数5.2569〜10.6915倍だった
- 目移りが強く（0.4）、下のリンクが押されにくいと、10本の人の割合は1本の0.9393倍に下がっても、回数は1.13873倍に増えた（人ごとの差が大きいとき）
- いちばん高くなる本数が、人の割合と回数で違ったのは30通り中2通りだった。いちばん高くなる本数は、目移りが0・0.05では10本、0.1では8〜10本、0.2では5〜10本、0.4では3〜10本と、目移りの強さで決まった（置き方しだい）
- 全員が同じだと置いた式÷数えた人の割合（10本）は、人ごとの差が大きいと1.1154〜1.5627倍、基本で1.0469〜1.18倍、小さいと1.0053〜1.0395倍で、差が大きいほど式は人の割合を多く見た

## 注意（言えないこと）
- 架空のデータと、作成者が置いたクリックの確率の式です。とくに目移り（リンクが多いと1本ごとに押されにくくなる度合い）は置いた値で、いちばん高くなる本数はこれでほぼ決まります。実際の読者の押し方を表すものではありません
- リンクの数で、メールを開く人の数や、次の回から開く人の数は変わらないと置きました
- リンクどうしは、引きと位置だけで違うと置きました。同じ先へのリンクを2か所に置く場合、リンクの中身どうしが食い合う場合は入れていません
- クリックは正しく数えられると置きました。受信側の仕組みが自動でリンクを確かめてクリックと数える場合などのずれは入れていません
- リンクを何本入れるとよいか、どんな中身のリンクを入れるとよいかは扱っていません
