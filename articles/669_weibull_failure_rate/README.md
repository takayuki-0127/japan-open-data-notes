# 669 部品の故障の起き方を「毎年同じ割合」と置くと、使った年数ごとの故障の見込みはどれだけずれるのか（手法の解説・正解の分かるデータで試す）

故障や解約の起き方を「毎年同じ割合」（指数分布）と置くのは手軽ですが、実際には使い始めに壊れやすいものも、使うほど壊れやすくなるものもあります。ワイブル分布は、形の値 k でこの違いを表せます（k<1 は初めに壊れやすい、k=1 は毎年同じ、k>1 は使うほど壊れやすい）。**ここでは、架空の部品5,000個を5年間だけ見たデータ（5年で20%が壊れる）から、指数分布とワイブル分布を当てはめ、使って何年目に壊れる割合と、データの外の6〜10年目に壊れる数の見込みを、本当の値と比べました（各200回）。** 数字は置いた k と「5年で20%」で決まります。

## 主な結果
- **毎年同じ割合で当てると、どの k でも年4.1〜4.4%の故障率になる**。5年分の平均しか見ないため
- **使うほど壊れやすい部品（k=2.5）**：本当の故障率は1年目0.40%、8年目18.5%。毎年同じ割合だと1年目4.17%・8年目4.17%で、8年目を4分の1以下に見る
- **6〜10年目に壊れる数**：本当は k=2.5 で2,585個、k=3.5 で3,600個。毎年同じ割合だと767個・757個で、**70%・79%少なく見る**。ワイブル分布なら差は0.5%以内
- **初めに壊れやすい部品（k=0.7）**は逆で、6〜10年目の故障を56%多く見る（本当520個に対し812個）
- ワイブル分布の当てはめでは、k の推定は本当の値のまわりに標準偏差0.02〜0.10で集まった

## 注意（言えないこと）
