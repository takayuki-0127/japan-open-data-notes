# 561 同じ人が続けて送った問い合わせを、何分以内なら1件とみなすかで、件数はどれだけ変わるのか（実務の型・重複の判定）

問い合わせフォームの記録には、ボタンの押し直しによる二重送信や、自動返信が来ないための送り直しが混ざります。「同じ人の直前の問い合わせから何分以内なら同じ件とみなすか」の幅で、件数が変わります。**ここでは、架空の問い合わせ窓口（2025年10〜12月、6,000人・13,639行、正しい件数 11,778件）で、幅を0秒〜3日の10通りに動かし、件数と、取りこぼし（重複なのに別の件とした数）・まとめすぎ（別の用件なのに同じ件とした数）を数えました。「同じ分類のときだけまとめる」条件も比べました。** 重複や別の用件の混ざり方は作成者が置いたもので、数字はその仮定で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A561 | 幅をどう置くと、件数・取りこぼし・まとめすぎがどう変わるか | 同じ人の直前の問い合わせ（LAG）からの間隔が幅以内なら同じ件。幅：0秒・30秒・1分・5分・10分・30分・1時間・3時間・24時間・3日。分類を問わない／同じ分類だけ。正しい件数は作成者が付けた用件の番号で出す。全20通りの件数を Python と SQL（DuckDB、1スレッド）で突き合わせ。seed 561 | `src/a561_dedup_window.py`、`src/02_dedup_duckdb.sql`、`src/01_dedup_tsql.sql`（未検証） |

## 主な結果
- **混ぜた行**：本来の問い合わせ 11,356行、二重送信 940行（0.5〜20秒後）、送り直し 593行（2〜60分後）、催促 328行（1〜3日後）、同じ人の別の用件 422行（5分〜6時間後）
- **幅0秒（まとめない）**：13,608件で、正しい件数より **+15.5%**。取りこぼし 1,800件
- **幅30秒〜5分**：+7.8〜+7.5%。二重送信はほぼまとまるが、送り直しと催促が残る（取りこぼし 891〜856件）
- **幅10分**：+6.5%（取りこぼし 803件、まとめすぎ 66件）
- **幅1時間**：+0.5% と件数は正しい値に近いが、取りこぼし 300件とまとめすぎ 269件が打ち消し合った結果
- **幅24時間**：−2.3%（取りこぼし 300件、まとめすぎ 606件）。**幅3日**：−7.6%（取りこぼし 0件、まとめすぎ 923件）
- **同じ分類のときだけまとめる**：まとめすぎが減る（幅1時間で 269件→85件、3日で 923件→244件）。取りこぼしは同じ（重複は同じ分類で送られると置いたため）
- 別の用件で、直前から10分以内に来たものは 66組、1時間以内は 269組。重複で1時間を超えて来たもの（催促）は 300組

## 動かし方
```
pip install -r requirements.txt
cd src && python a561_dedup_window.py
```
数秒で終わります。`data/` に問い合わせ（inquiries.csv）と、正しい件数を出すための用件の番号（inquiries_true_case.csv）を書き出します。

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures がバイト単位で一致した（DuckDB は `SET threads=1`）
- 幅10通り × 分類の条件2通りの件数が、Python と DuckDB の SQL で一致した
- T-SQL 版（`01_dedup_tsql.sql`）は書いたが、SQL Server では動かしていない（**未検証**）

## データ
- `data/inquiries.csv`（inquiry_id・customer_id・received_at・category）、`data/inquiries_true_case.csv`（true_case・kind）
- 仮定：1人あたりの用件は 1＋ポアソン（平均0.9）件。用件ごとに、二重送信 7%（うち2割は2回）、送り直し 5%、催促 3%、別の用件を続けて送る 4%（35%は同じ分類）。受付は日中が多い
- 判定は「直前の問い合わせからの間隔」で区切る（最初の問い合わせからの間隔ではない）。続けて来れば、幅を超えて1件につながることがある

## 注意（言えないこと）
- 架空のデータ。実際の窓口の数字ではない
- どの幅がよいかは、二重送信や送り直しの起こり方と、件数を何に使うか（対応の負荷か、用件の数か）で変わる
- 実際の運用では「同じ用件か」の正解は分からない。ここでは正解を置いて、幅ごとのずれを数えた
- 催促を「同じ件」とするか「別の件」とするかは決め方しだい。ここでは同じ件とした
