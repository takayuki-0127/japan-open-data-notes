# 713 率が5%から6%になったのを「1ポイント増」と「20%増」のどちらで書くかで、店の並びはどれだけ変わるのか（実務の型・率の比べ方）

率の変化は、差（ポイント）で書くか、元の率に対する割合（%）で書くかで、数字の印象が大きく変わります。5%→6%は「1ポイント増」でも「20%増」でもあります。店を「伸びた順」に並べると、%の変化は前の率が低い店ほど大きく出ます。**ここでは、架空の30店の申込み率（前の期1〜18%）2期分で、ポイントの差・%の変化・申込み件数の差の3つで並べ、順位と上位5店を比べました。** 率と来店数は作成者が置いたもので、数字はその置き方で決まります。

## 主な結果
- **順位の相関**：ポイントと%で0.89、ポイントと件数で0.90、%と件数で0.85。最大で9位入れ替わった店があった
- **上位5店**：ポイントの差と%の変化で、重なるのは **5店のうち2店**。%の変化の上位5店は、5店とも前の率が中央値より低い店（ポイントの差では2店）
- **例**：S08 は1.07%→2.79%で「+162%」の1位だが、ポイントでは+1.72で2位。S07 は12.5%→14.3%で「+1.84ポイント」の1位だが、%では+14.7%で10位。申込みの件数は S07 が+247件、S08 が+90件

## 注意（言えないこと）
- 架空のデータ。ここでは変化を「ポイント」で置いたので、%の変化は率の低い店に寄る。変化が「%」で起きる世界なら逆になる。どちらが正しい書き方かは、目的（率の改善か、件数か）で決まる
- 率の低い店は件数も少ないので、偶然のゆれで%の変化が大きく出やすい。ここでは区間は出していない
- 実在の店の数字ではない
