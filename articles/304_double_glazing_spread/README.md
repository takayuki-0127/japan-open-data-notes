# 304 省エネの窓は、どれだけ広まったのか（住宅・土地統計調査）

二重以上のサッシ・複層ガラスの窓（以下「二重窓」）がある住宅の割合を、2003〜2023年の5回の調査で比べたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A304 | 二重窓のある住宅はどれだけ増えたか。持ち家と借家、地方で違うか | 時系列統計表 第19表（所有の関係・省エネルギー設備等別の住宅数、全国・都道府県）。割合＝二重窓のある住宅÷住宅の総数（設備「不詳」を含む。公表の割合と同じ分母）。増えた戸数を持ち家・借家に分ける／全体の割合の変化を「持ち家・借家の中の変化」と「持ち家と借家の割合の変化」に分ける／47都道府県の分布と6つの地方のまとまりを見る | `src/a304_double_glazing.py` |

## 主な結果
- 全国の割合（すべての窓＋一部の窓）：2003年18.0%→2008年21.1%→2013年25.2%→2018年29.0%→2023年31.9%。すべての窓にある住宅は8.2%→16.8%、一部の窓は9.8%→15.1%
- 戸数では843万戸→1,776万戸（+933万戸）。増えた分の84%は持ち家（+784万戸）、借家は+149万戸
- 持ち家は23.1%→42.7%、借家は10.6%→17.0%。差は12.5ポイントから25.7ポイントに開いた
- 全体の+14.9ポイントのうち、持ち家・借家それぞれの中での上がり方が+14.7、持ち家の割合が増えた分は+0.2
- 5年ごとの上がり方（すべて＋一部）は+3.0、+4.2、+3.7、+2.9ポイント。すべての窓だけなら+2.4、+2.2、+1.9、+2.1ポイント
- 地方ごと（すべて＋一部）：北海道・東北は57.7%→64.1%、中部19.6%→37.4%、関東12.2%→28.1%、中国・四国10.9%→27.8%、近畿11.6%→24.5%、九州・沖縄8.3%→21.4%
- 47都道府県の中央値は12.0%→29.7%。20%未満の県は36→3、50%以上の県は4→8
- 同じ表の太陽光発電は0.6%→4.9%、太陽熱温水器は6.6%→3.0%

## 確かめたこと
- 自分で割った「すべての窓」の割合は、公表の割合（8.2・10.6・12.8・14.7・16.8%）と5回とも一致
- 分母を「窓について答えのあった住宅」に変えると18.4%→33.3%（設備「不詳」は2.2%→4.2%に増えている）
- 「すべての窓」だけで見ても8.2%→16.8%と2倍
- 空のフォルダで流し直し、data・results・figures が一致した

## データ
- `data/raw/hlts_ts_t19.csv`：e-Stat「令和5年住宅・土地統計調査 時系列統計表」第19表（statInfId=000040354051）の閲覧用 Excel を、ブラウザの中で SheetJS（xlsx 0.18.5）で CSV の文字列にしたもの（3つのシート：総数・持ち家・借家。2026-11-12 取得）。手で取る場合は `https://www.e-stat.go.jp/stat-search/file-download?statInfId=000040354051&fileKind=4`
- `data/energy_equipment_long.csv`：全国と47都道府県を縦長にしたもの

## 注意（言えないこと）
- 「二重以上のサッシ又は複層ガラスの窓」があるかどうかの調査で、窓の断熱の性能（樹脂サッシか、ガラスの種類など）は分かりません。「一部の窓」が何枚かも分かりません
- 増えた理由（新築が増えた分か、今ある家の改修か）は、この表では分けられません。建築の時期別の集計は使っていません
- 地方ごとの違いの理由（気候、住宅の建て方、新しい住宅の多さ）は分けていません
- 標本調査の推定値です。総数には、所有の関係「不詳」の住宅を含みます
