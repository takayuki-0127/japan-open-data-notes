# 1121 敵の体力を1割増やすと、倒すのに要る回数はなぜ1割より大きく跳ねることがあるのか？（ゲームの数値設計）

ゲームの調整で敵の体力を1割増やすと、倒すのに要る手間も1割ほど増えると考えがちです。けれども、倒すのに要る回数は整数で、「体力÷1回のダメージ」の切り上げで決まります。体力の増えた分が、ちょうど1回分の境目をまたぐかどうかで、回数は変わらないか、まるごと1回増えます。4回で倒せていた敵が5回になれば+25%、2回が3回になれば+50%です。ダメージに振れがあると、この段はならされますが、境目の近くの攻撃力ではやはり大きく跳ねます。**ここでは、作成者が置いた架空のゲームの数値（敵の体力1,000→1,100、プレイヤーの攻撃力50〜600）で、ダメージが決まっているときの回数の増え方（作りどおり）、ダメージが±10%振れるときの回数の平均と「決まった回数のうちに倒せる割合」の動き（各2万回）、攻撃力のばらばらな架空のプレイヤー5,000人での増え方を数えました。体力の増やし方（5%・10%・20%）×ダメージの振れ（0〜±20%）×会心の有無の24通りの確かめも行いました。**

例のゲームと数値は架空のもので、実在のゲームやその計算式を表すものではありません。課金やくじの話は扱いません。

関連する記事：同じ企画の 1115「平均のダメージで敵の体力を割って「何回で倒せるか」を出すと、実際の回数とどれだけずれるのか？」は、体力を変えずに、最後の1回のあふれで回数の平均が見込みより多くなることを扱っています。同じ企画の 1116「平均のダメージがいちばん大きい武器は、決まった回数のうちに倒せる割合もいちばん高いのか？」は、敵の体力によって決まった回数で倒せる武器が入れかわることを扱っています。この記事は、同じプレイヤーにとって敵の体力を少し増やしたときの回数の跳ね方に絞ります。893「作業時間の記録を15分単位で切ると、何%消えるのか？」は、区切りの単位で数字が段になることを、作業時間の記録で扱っています。同じ企画の 1124「ダメージの小数を毎回切り捨てて計算すると、小さな強化はどれだけ消えるのか？」は、ダメージの小数の切り捨てで小さな強化が消える段を扱っています。

## 主な結果

### ダメージが決まっているとき（攻撃力50〜600の551通り、`results/fixed_damage.csv`・`results/fixed_by_hits.csv`）
| 体力1,000で倒すのに要る回数 | 攻撃力 | 体力1,100で回数が増えた割合 | 増えたときの増え方（いちばん大きいもの） |
|---|---|---|---|
| 2回 | 500〜600 | 49.5% | **+50%**（3回） |
| 3回 | 334〜499 | 19.88% | +33.33%（4回） |
| 4回 | 250〜333 | 29.76% | +25%（5回） |
| 5回 | 200〜249 | 40.0% | +20%（6回） |
| 6回 | 167〜199 | 51.52% | +16.67% |
| 8回 | 125〜142 | 72.22% | +12.5% |
| 10回 | 100〜111 | 83.33% | +10% |
| 11〜20回 | 50〜99 | 100% | +10〜+18.18%（いちばん小さいものは+5.26%） |

- **体力を1割増やしても、攻撃力551通りのうち55.72%では回数が変わらなかった。残りの44.28%は1回以上増え、いちばん大きいところで+50%だった**（作りどおり：回数は体力÷攻撃力の切り上げ）
- 増え方が+10%を超えたのは36.48%、+20%以上は23.23%。551通りを平らにならした平均は+10.88%で、ほぼ体力の増え方と同じだった
- 少ない回数で倒せる強いプレイヤーほど、増えるときの跳ねが大きく、増えることは少なかった。攻撃力200〜600では、回数が増えたのは31.92%で、増えたときの平均は+36.13%だった
- 倒すのに10回以上かかる弱いプレイヤーでは、ほとんどいつも回数が増えたが、増え方は+10%前後に近づいた。ただし、増え方がいちばん小さいところは+5.26%（19回→20回）で、1割より小さいこともあった

### ダメージが±10%振れるとき（各2万回、`results/random_damage.csv`）
| 攻撃力 | 回数の平均（体力1,000） | 回数の平均（体力1,100） | 平均の増え方 | 振れなしの回数のうちに倒せた割合（1,000 → 1,100） |
|---|---|---|---|---|
| 200 | 5.503 | 6.0 | +9.04% | 5回以内：49.71% → 0% |
| 250 | 4.502 | 5.0 | +11.07% | 4回以内：49.85% → 0% |
| 300 | 4.0 | 4.0 | +0.01% | 4回以内：100% → 99.95% |
| 340 | 3.284 | 3.994 | **+21.63%** | 3回以内：**71.6% → 0.56%** |
| 400 | 3.0 | 3.003 | +0.09% | 3回以内：100% → 99.72% |

- 振れがあると段はなめらかになったが、回数の平均の増え方は攻撃力によって**0〜34.12%**と大きく違った（111通りの平均は+10.21%）
- 平均の増え方が小さく見えるところでも、「決まった回数のうちに倒せる割合」は大きく動いた。攻撃力340では、3回で倒せた割合が71.6%から0.56%に下がった
- 攻撃力300・400のように、体力1,100でも同じ回数で余裕をもって届くところでは、ほとんど変わらなかった

### プレイヤーの集まり（5,000人、攻撃力の中央値200、`data/players.csv`）
| | 値 |
|---|---|
| 振れなし：回数が変わらなかった人 | **46.84%** |
| 振れなし：回数が増えた人 | 53.16%（増えた人の平均+17.9%、いちばん大きい人+50%） |
| 振れなし：1人ずつの増え方の平均 | +9.52% |
| 振れなし：全員の回数の合計の増え方 | +9.19% |
| 振れ±10%：1人ずつの回数の平均の増え方（5〜95%） | 0.12〜21.13% |
| 振れ±10%：+15%を超えて増えた人 | 18.8% |

- **集まり全体では回数は約1割（合計で+9.19%）増えたが、1人ずつでは、半分近くは変わらず、増えた人は平均+17.9%だった**。全体の平均の1割は、0%の人と大きく跳ねた人をならした値だった

### 確かめ：置き方を変えると（24通り、攻撃力100〜500、`results/grid.csv`）
| 体力の増やし方 | 振れなし（会心なし） | ±5% | ±10% | ±20% | 平均の増え方（8通り） |
|---|---|---|---|---|---|
| +5% | 最大+50% | +26.31% | +15.82% | +9.13% | 3.97〜4.29% |
| +10% | 最大+50% | +33.33% | +27.1% | +15.88% | 7.67〜8.4% |
| +20% | 最大+50% | +33.33% | +33.26% | +26.38% | 15.15〜16.47% |

（最大は、攻撃力81通りの中でいちばん大きい回数の平均の増え方。会心ありでは、同じ振れで少し小さかった：体力+10%・振れなしで+47.92%、±20%で+14.3%）

- 振れが大きいほど、いちばん大きい跳ねは小さくなった。それでも、体力+10%・振れ±20%でも、増え方の最大は+15.88%で、1割を上回った
- 体力+5%でも、振れが小さければ回数が+50%跳ねる攻撃力があった
- 攻撃力100〜500の81通りをならした平均の増え方は、体力の増やし方の8割前後（+10%で7.67〜8.4%）だった。この範囲では倒すのに要る回数が2〜10回と少なく、変わらないところが多いためと考えられる（推測）

## データ
- `data/players.csv`：架空のプレイヤー5,000人（player・attack・振れなしの回数（体力1,000・1,100）・振れ±10%の回数の平均（同））

- `results/a1121_main.json`：主な結果すべて（置いた値、振れなしの割合、振れありの例、プレイヤーの集まり、置き方を変えた結果）
- `results/fixed_damage.csv`：振れなしの攻撃力551通り

- `results/random_damage.csv`：振れ±10%の攻撃力111通り

## 注意（言えないこと）
- 架空のデータです。体力・攻撃力・ダメージの振れ・会心は作成者が置いたもので、どの攻撃力で跳ねるかはこれで決まります。振れなしの段は作りどおりです
- 敵の防御、回復、命中の外れ、複数の敵は入れていません。倒すのに要る回数だけを数え、時間や手間（ターン数・秒数）には直していません
- プレイヤーの攻撃力の散らばりは作成者が置いたもので、集まり全体の値（変わらなかった人の割合など）はこの置き方で変わります
- 敵の体力をどう決めるのがよいかは言えません。この記事は、体力の小さな変化で回数がどう跳ねるかを数えただけです
