# F177 「差がある」は、並べ替えで確かめるとどうなるか？（置換検定・ランダム化推論と t 検定の比較）

看板記事 F177。これまでの記事で「差がある」と書いた小さな比較を3つ選び、t 検定の p 値と、グループの付け方を並べ替えて作った p 値（置換検定・ランダム化推論）を比べました。あわせて、正解の分かる人工データで、小さな標本・外れ値・ばらつきの違いがあるときに、それぞれの検定がどれくらい「差なしなのに差あり」と言うかを調べました。外部のデータは新しく取っていません。

## 問い

- 小さな比較で、t 検定の p と並べ替えの p はどれくらい違うか
- 違いを生むのは「検定の種類」か、それとも「何を並べ替えるか（単位）」か
- 並べ替えの回数や、比べる統計量（平均の差・t・中央値・順位）を変えると、答えは変わるか
- 並べ替え検定は、外れ値やばらつきの違いに強いのか

## 手法

- **並べ替え検定（2グループ）**：グループの付け方を、人数を変えずにでたらめに付け直し、そのたびに統計量を計算して「差がない世界」の分布を作る。p ＝（実際以上に極端な数 + 1）／（並べ替えの回数 + 1）。両側。
- **統計量**：平均の差、Welch の t、中央値の差、20%刈り込み平均の差、順位の和（Mann–Whitney と同じ）。
- **比べる検定**：Welch の t 検定、Student の t 検定、Mann–Whitney 検定。
- **並べ替えの単位**：
  - 例2：47県をばらばらに並べ替える（1万回）と、隣どうしつながる17県を選び直す（5千回、F80 と同じ作り方）。
  - 例3：事後6か月と事前24か月の「月」をばらばらの標本とみなす t 検定、事前の期間ににせの開始月を置く（時期をずらす、19通り）、対照の県から被災県と同じ数を選んで被災したとみなす（県をずらす。1県なら全対照県、2県以上なら2,000通り）。
- **人工データ**：1グループ5・10・15人、各2,000回、並べ替えは999回。分布は ①正規、②対数正規（右に裾が長い）、③正規で片方の1点だけ +6、④片方のばらつきが3倍で人数が半分（もう片方は2倍の人数）。差なし（上段）と差あり（正規・外れ値・対数正規は1標準偏差ぶん、④は1.5）の2通り。

乱数の種は177に固定しています。

## 結果

### 例1：都市と都市以外の差（F168）は、並べ替えでも p≈0.05 で、境目に乗ったまま

| 統計量 | 並べ替えの p | 回数 |
|---|---|---|
| 平均の差（+0.49℃／100年） | 0.0498 | 10万回 |
| Welch の t | 0.0498 | 10万回 |
| 中央値の差 | 0.061 | 2万回 |
| 20%刈り込み平均の差 | 0.052 | 2万回 |
| 順位の和 | 0.030 | 10万回 |

- Welch の t 検定は 0.049、Student は 0.049、Mann–Whitney（正確）は 0.029。t 検定と並べ替えの答えはほぼ同じで、統計量の選び方のほうが p を動かした（0.030〜0.061）。
- 1地点ずつ抜くと、並べ替えの p は 0.018〜0.092 に動き、0.05 を下回ったのは30通り中10通り（Welch でも11通り）。結論は「境目」で、どの1地点が入るかで有意・有意でないが入れ替わる。
- 並べ替えの回数を変えて種を20通り試すと、100回では p が 0.030〜0.109、1,000回では 0.043〜0.060 と揺れ、0.05 未満になったのは20回中11回。1万回でも 0.044〜0.052（16回）、10万回で 0.048〜0.050（20回）。F168 では1万回で 0.047 と書いたが、これは回数による揺れの範囲内だった。

### 例2：東西の100指標（F80）は、検定を換えても同じだが、単位を換えると19→4

| p &lt; 0.05 の指標の数 | 数 |
|---|---|
| Welch の t 検定 | 19 |
| Student の t 検定 | 20 |
| Mann–Whitney | 21 |
| 並べ替え（県をばらばら・平均の差） | 21 |
| 並べ替え（県をばらばら・Welch の t） | 19 |
| 並べ替え（隣どうしつながる17県） | 4 |

- 県をばらばらに並べ替えた p は、Welch の p と順位相関 0.993 でほぼ一致した。0.05 の判定が食い違ったのは2指標だけ（Welch 0.061・0.063 → 並べ替え 0.033・0.034）。外れ値の大きい指標（どこかの県が平均から4標準偏差以上離れる15指標）でも、並べ替えの p は Welch の 0.94倍（中央値）で、ほとんど変わらなかった。
- ところが「隣どうしはつながっている」ことを残したまま選び直すと、Welch で 0.05 未満の19指標のうち15指標は 0.05 以上になった。残ったのは年平均気温・最低気温・消費者物価地域差指数（教養娯楽）など4指標で、年平均気温でも p は 0.00004 → 0.031。
- 47県を「互いに無関係な47人」とみなしてよいか（交換可能か）で答えが決まり、t 検定か並べ替えかではほとんど決まらなかった。

### 例3：災害のあとの宿泊者数（F98）は、何を並べ替えるかで p が 0.03 から 0.18 へ

| 事例 | 被災県 | 6か月の差 | 月を標本とみなす t | 時期をずらす | 県をずらす |
|---|---|---|---|---|---|
| 熊本地震 | 2 | +1.1% | 0.86 | 0.90 | 0.79 |
| 平成30年7月豪雨 | 3 | −5.8% | **0.034** | 0.05 | 0.18 |
| 北海道胆振東部地震 | 1 | −7.1% | 0.19 | 0.05 | 0.29 |

- 平成30年7月豪雨は、月をばらばらの標本とみなすと p=0.034 だが、「同じくらいの差は、被災していない県を被災県とみなしても18%の組み合わせで出る」。月どうしは隣の月と似ていて（事前の1か月ずれの自己相関 0.64〜0.78）、月を独立とみなす t 検定は確かさを大きく見積もる。
- 時期をずらす並べ替えは、事前24か月に置ける6か月の窓が19通りしかなく、p は最小でも 0.05（1/20）。豪雨と北海道はどちらもこの最小値で、「事前のどの時期よりも低い」とは言えるが、それ以上の細かさはない。
- 北海道は被災県が1つで、対照は41県。県をずらす p は最小でも 1/42≈0.024 で、実際は 0.29（41県中11県で同じくらい以上の差）。1県の事例では、どんなに大きな差でも p は 0.024 より小さくならない。

### 人工データ：並べ替えは「外れ値に強い」が、「ばらつきの違い」には弱い

差がないのに「差あり」と言う割合（1グループ5〜15人、目標5%）：

| 状況 | Welch | Student | 並べ替え（平均の差） | 並べ替え（Welch の t） | Mann–Whitney |
|---|---|---|---|---|---|
| 正規分布 | 4.0〜4.8% | 4.6〜5.0% | 4.0〜4.9% | 4.0〜4.9% | 2.6〜4.1% |
| 右に裾の長い分布 | 2.2〜3.5% | 3.1〜3.8% | 4.6〜5.1% | 4.6〜5.1% | 3.2〜5.1% |
| 片方に外れ値1点（ほかは差なし） | 0.2〜3.0% | 0.8〜3.3% | 4.6〜4.8% | 4.6〜4.8% | 3.0〜4.6% |
| ばらつき3倍・人数半分 | 4.2〜5.6% | 13.6〜16.2% | **13.8〜17.2%** | 5.2〜8.2% | 8.2〜9.6% |

- 人数が同じとき、「平均の差」と「Welch の t」で並べ替えた結果は完全に同じになる（図では重なっている）。
- 外れ値が1点あると、t 検定は分散が膨らんで「差あり」と言いにくくなり（5人で0.2%）、差があっても見つけにくい（5人の検出力 Welch 7% → 並べ替え 36%）。並べ替えは5%近くを保った。
- 右に裾の長い分布では、並べ替えは5%を保ち、検出力も t 検定よりやや高い（15人で 42% と 38%）。いちばん検出力が高いのは順位（71%）。
- ばらつきが違い、人数の少ないほうのばらつきが大きいときは、「平均の差」で並べ替えると Student の t と同じく14〜17% も「差あり」と言う。並べ替えは「グループを入れ替えても分布が同じ」ことを前提にしているので、ばらつきが違えば前提が崩れる。Welch の t を統計量にして並べ替えると 5〜8% に収まった。

## 頑健性

- **並べ替えの単位**：例2（県をばらばら／つながった塊）、例3（月／時期／県）。単位を換えたときの p の変化（19→4指標、0.034→0.18）は、検定の種類を換えたときの変化（19〜21指標）よりずっと大きかった。
- **並べ替えの回数**：例1で100〜10万回、種20通り。p が 0.05 に近いと、1万回でも判定が入れ替わる（20回中4回は 0.05 以上）。
- **統計量**：例1で5種類（p=0.030〜0.061）、例2で平均の差と Welch の t（21 と 19 指標）。
- **1地点ずつ抜く**：例1で30通り（p=0.018〜0.092）。
- **人工データ**：人数3通り、分布4通り。

## 言えないこと

- **並べ替えは「差がない」を正しく作れたときだけ正しい。** 例2・例3で示したとおり、並べ替えの単位が現実の似かたを壊していれば、t 検定と同じく確かさを見積もりすぎる。つながった17県の並べ替えも1つの作り方にすぎず、「本当の」帰無分布だとは言えない。
- **元の記事の結論を覆したわけではない。** 例1は F168 と同じく「境目」、例2は F80 と同じく「隣どうしが似ていると有意が増える」、例3は F98 がもともとプラセボの帯で判断していた。この記事は、その判断を p 値の形で並べ直したもの。
- **例3の t 検定は、わざと単純にしたもの。** 月の自己相関を考える方法（HAC 標準誤差など）なら t 検定でも p は大きくなるはずだが、ここでは試していない。
- **人工データの条件は4つだけ。** 人数の比、外れ値の大きさ、裾の重さを変えると数字は変わる。「並べ替えのほうが常に良い」とは言えない。
- **p＝0.05 の線に意味を持たせすぎない。** 例1の p は 0.018〜0.092 の幅で動く。差の大きさ（+0.49℃／100年）とその不確かさで読むほうが大切。
- **指標の中身は評価していない。** 例2の指標の東西差は、記事 F80 の比較をそのまま使ったもので、どちらが良い・悪いの評価はしていない。
