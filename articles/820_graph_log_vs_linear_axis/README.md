# 820 対数の軸と普通の軸で、「伸びが鈍った」の見え方は変わるのか？（グラフ）

会員数や売上のように増え続ける数字は、普通の目盛りの軸（普通の軸）で描くか、1,000→2,000→4,000が同じ間隔になる対数の目盛りの軸（対数の軸）で描くかで、線の曲がり方が変わります。普通の軸の傾きは「1か月に何人増えたか」、対数の軸の傾きは「1か月に何%増えたか（伸び率）」を表します。**ここでは、作成者が乱数で作った架空の会社の60か月の会員数（36か月目から伸び率を変えたもの）で、変わる前の12か月と最後の12か月の線の傾きを比べたときに、普通の軸と対数の軸のそれぞれで「伸びが鈍った」と読む割合を数えました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A820 | 伸び率が下がったとき、普通の軸と対数の軸で「伸びが鈍った」と読めるか。読み違いはどの組み合わせで起きるか | 架空の会社の毎月の会員数、60か月。0か月目は1,000人。35か月目までは毎月 r1 の率で増え、36か月目から r2 の率で増える。毎月の数には、掛け算で標準偏差2%の上下（月ごとに独立）を足す。「鈍った」の読み方は、変わる前の12か月（24〜35か月目）と最後の12か月（48〜59か月目）で、線の傾き（最小二乗の直線の傾き）を比べ、後÷前が1より小さければ「鈍った」とする。普通の軸は会員数そのもの、対数の軸は会員数の対数の傾き。r1 は2〜6%、r2 は0%から r1＋1ポイントまで0.5ポイント刻み。各組み合わせで200回。本当の答えは「伸び率が下がったか（r2＜r1）」と置いた。確かめとして、後の12か月を変わった直後（36〜47か月目）にした場合、上下の大きさを1%・4%にした場合、毎月同じ40人ずつ増える会社も数えた。seed 820 | `src/a820_log_axis.py` |

## 主な結果

### 例：伸び率が4%から3%に下がった会社（1回分）
| | 普通の軸 | 対数の軸 |
|---|---|---|
| 後の傾き÷前の傾き（上下あり） | **1.54** | **0.72** |
| 同（上下なし、置いた流れ） | 1.61 | 0.75 |
| 読み | 速まった | 鈍った |

- 会員数は0か月目1,008人、35か月目3,986人、59か月目8,167人
- 置いた流れでは、1か月に増える人数は前の12か月で125.4人、最後の12か月で202.2人。伸び率は下がったが、増える人数は増えた。普通の軸は増える人数を、対数の軸は伸び率を見せる

### 伸び率を1ポイント下げたとき、「鈍った」と読む割合（200回）
| 前の伸び率 r1 → 後の r2 | 普通の軸 | 対数の軸 | 普通の軸（後を36〜47か月目にした場合） |
|---|---|---|---|
| 2% → 1% | 98.5% | 100% | 100% |
| 3% → 2% | 13% | 100% | 79.5% |
| 4% → 3% | **0%** | **100%** | 5.5% |
| 5% → 4% | 0% | 100% | 0% |
| 6% → 5% | 0% | 100% | 0% |

- 対数の軸は、伸び率の下がりを1ポイントでほぼ毎回「鈍った」と読めた。普通の軸は、前の伸び率が3%以上だと、1ポイント下げてもほとんど「鈍った」と読めなかった
- 普通の軸で「鈍った」と読めるのは、上下なしの置いた流れで、r2 が次の値以下のときだけだった：r1＝2%なら1.0%、3%なら1.5%、4%なら2.0%、5%なら2.0%、6%なら2.5%。伸び率がおよそ半分以下に下がらないと、普通の軸の線は寝なかった
- 後の12か月を変わった直後にすると、普通の軸でも少し読みやすくなった（3%→2%で13%→79.5%）。時間がたつほど、元の数が大きくなって増える人数が増えるため、普通の軸では「鈍った」が見えにくくなる

### 伸び率が変わらないとき
- r2＝r1（伸び率は同じ）のとき、普通の軸は一度も「鈍った」と読まなかった（0%）。対数の軸は50.9%で「鈍った」と読んだ。傾きの比がほぼ1になるので、毎月の上下でどちらにも転ぶ。対数の軸で「少し鈍った」に見えても、上下の範囲かもしれない

### 確かめ：毎月の上下の大きさ（r1＝4%、200回）
| 上下の大きさ | r2＝2%：普通の軸 | r2＝3%：対数の軸 | r2＝3.5%：対数の軸 | r2＝4%（変わらない）：対数の軸 |
|---|---|---|---|---|
| 1% | 97.5% | 100% | 100% | 51% |
| 2%（基本） | 81% | 100% | 98.5% | 52.5% |
| 4% | 68.5% | 98.5% | 81% | 50.5% |

- 上下を大きくすると、対数の軸でも小さな下がり（4%→3.5%）は読み落としが増えた（4%の上下で81%）。普通の軸で4%→3%を「鈍った」と読む割合は、どの上下の大きさでも0%だった

### 毎月同じ40人ずつ増える会社
| | 普通の軸 | 対数の軸 |
|---|---|---|
| 後の傾き÷前の傾き（上下なし） | 1.00 | **0.69** |
| 同（上下あり、1回分） | 0.62 | 0.43 |

- 増える人数は毎月同じでも、伸び率は1か月目の4.0%から59か月目の1.2%まで下がり続ける。普通の軸ではまっすぐ、対数の軸では寝ていく線になった。どちらの読みが正しいかは、「伸び」を人数で見るか率で見るかで決まる
- この会社は毎月の増え方が小さい（40人）ので、上下ありの1回分では、普通の軸でも傾きの比が0.62と振れた

## 動かし方
```
pip install -r requirements.txt
cd src && python a820_log_axis.py
```
数秒で終わります。`data/members_4to3.csv`・`data/members_straight.csv` もこのとき作ります。

- 後の12か月の取り方（48〜59か月目・36〜47か月目）と、毎月の上下の大きさ（1・2・4%）を変えて数えた（上の表）
- 図3枚を開き、日本語の表示・文字の重なり・軸を目で確かめた

## データ
- `data/members_4to3.csv`：伸び率4%→3%の会社の60か月（month・true（置いた流れ）・members（上下ありの会員数））
- `data/members_straight.csv`：毎月40人ずつ増える会社の60か月（同じ列）

## 注意（言えないこと）
- 架空のデータです。伸び率、変わる月、上下の大きさは作成者が置いたもので、割合の数字はこれで決まります
- 「鈍った」の読み方は、12か月ずつの直線の傾きを比べるという作成者の置き方です。実際に人がグラフを見てどう感じるかは、人に見せて確かめていません（線の傾きの比が、見た目の曲がり方に近いと置いた）
- 本当の答えを「伸び率が下がったか」と置きました。増える人数で見るなら、普通の軸の読みのほうが正しくなります。どちらの軸が正しいかではなく、二つの軸が別の問いに答えている、というのがここで言えることです
- 実際の会社の会員数や、どの事業が伸びているかを表すものではありません
- 累積のグラフが止まっても右肩上がりに見える話は、関連する記事 816、縦軸を0から始めるかは 813 で扱います
