# 1220 群れで動く生き物を数えるとき、群れを見落とすと全体の数のぶれはどれだけ大きくなるのか？（生き物の数え方）

水鳥のように群れで動く生き物を数えるとき、見落としは1羽ずつではなく、群れごとに起きやすくなります。見つけた群れは全部数え、見落とした群れは丸ごと抜けます。見つかる割合が同じ80%でも、1羽ずつ見落とすときと群れごとに見落とすときでは、数えた数の平均は同じでも、1回ごとのぶれの大きさが違います。**ここでは、作成者が乱数で作った架空の湖「C湖」（本当は1,000羽の水鳥がいて、群れの大きさを作成者が置いたもの）で、①1羽ずつ80%で見つかる、②群れごとに80%で見つかる、の2つで、数えた数を0.8で割り戻した見込みが1回ごとにどれだけ散るか、本当の±10%に入る回の割合、本当は10%減ったときに減ったと出る割合を数えました。群れの大きさの平均×大きさの散らばり×見つける割合の27通りでも確かめ、大きい群れほど見つけやすいときに、見つけた群れの割合で割り戻すと何が起きるかも数えました。**

例の湖・水鳥・群れはすべて作成者が置いた架空のもので、実在の場所・種・調査を表すものではありません。

関連する記事：1193「1つの不具合で問い合わせが一度に来ると、件数の上位の種類は何を表すのか？」は、1つの原因から問い合わせが固まって来ると、月の件数がかたまりの大きさで振れることを扱っています。この記事の「群れごとに抜ける」のも、数がかたまりで入ったり抜けたりする同じ形のぶれです。1003「数取りの人による数え間違いは、どれだけ出るのか？」は、人がまとめて通ると数取りの押し漏れが増えることを扱っています。同じ企画の 1209「見つけた鳥の数が去年より減ったのは、鳥が減ったからか、見つけにくくなったからか？」は、見回りどうしの数のばらつきから見つける確率を数え直す場面で、その式は1羽ずつ別々に見つかると置いています。この記事は、生き物の群れを丸ごと見落とすときの、全体の数のぶれに絞ります。

## 主な結果

### 1羽ずつ見落とすときと、群れごとに見落とすとき（基本、20,000回、`results/a1220_main.json` の base）
| | ①1羽ずつ80% | ②群れごとに80% |
|---|---|---|
| 見込みの平均 | 1,000.08羽 | 998.94羽 |
| 見込みの標準偏差 | 15.79羽 | **98.26羽** |
| 見込みの10〜90%の範囲 | 980.0〜1,020.0羽 | 868.75〜1,120.0羽 |
| 本当の±10%に入った回 | 100% | **68.88%** |
| 本当の±5%に入った回 | 99.81% | 38.0% |
| 9割の回で±10%に入るのに要る回数（平均を取る） | 1回 | 3回 |

- 群れは1回あたり平均50.96個、群れの大きさの平均は19.624羽だった
- **見込みの平均はどちらもほぼ1,000羽で、群れごとに見落としても数え方は平均では外れなかった。けれども、1回ごとのぶれ（標準偏差）は1羽ずつのときの6.2242倍だった**
- **この倍率は、√（群れの大きさの2乗の合計÷全体の数）の式（6.1838倍）どおりだった**。中の √ の値は、「1羽の鳥から見た、自分のいる群れの大きさ」の平均（38.24羽）にあたり、群れの大きさの平均（19.624羽）の1.949倍だった。大きい群れには鳥が多くいるので、1羽から見ると群れは平均より大きい
- ②の見込みは、20,000回の中で最小506.25羽・最大1,250.0羽だった

### 本当は10%減った（1,000羽→900羽）とき、2回の数の比べ（`decline_10pct`、20,000組）
| | 減ったと出た | 増えたと出た |
|---|---|---|
| ①1羽ずつ80% | 100% | 0% |
| ②群れごとに80%（1回ずつ） | **77.3%** | **22.43%** |
| ②群れごとに80%（3回ずつ数えた平均） | 89.72% | 10.1% |

- **群れごとに見落とすと、本当は10%減っていても、22.43%の組で増えたと出た**。3回ずつ数えて平均すると10.1%に下がった

### 確かめ：群れの平均の大きさ×大きさの散らばり×見つける割合（27通り、`results/grid.csv`）
| | 27通りの範囲 |
|---|---|
| 標準偏差の倍率（②÷①） | **2.5177〜14.0847倍** |
| 倍率の、式との差 | 最大2.78% |
| ②で本当の±10%に入った回 | 19.7〜100% |
| ①で本当の±10%に入った回 | 99.97〜100% |
| ②で9割の回を±10%に入れるのに要る回数 | 1〜30回 |

- **標準偏差の倍率は、27通りすべてで式どおりだった（差は最大2.78%）**。倍率は見つける割合ではほぼ変わらず、群れの大きさの平均と散らばりで決まった（平均5羽・そろう 2.5177〜2.5972倍、平均50羽・大きく散る 13.8744〜14.0847倍）
- 見つける割合0.8では、②で±10%に入った回は、平均5羽・そろうで98.58%、平均50羽・大きく散るで30.13%だった（図2）
- **27通り中26通りで、②の±10%に入った回は①より少なかった**（残る1通りは見つける割合0.95・平均5羽・そろうで、どちらも100%）
- 要る回数は、見つける割合0.6・平均50羽・大きく散るで30回だった

### 大きい群れほど見つけやすいとき（`results/size_dependent_detection.csv`、各5,000回）
| c（見つけやすさが大きさで上がる速さ） | 群れの平均 | 見つけた群れの割合 | 見つけた鳥の割合 | 群れの割合で割り戻した見込みの平均 |
|---|---|---|---|---|
| 10 | 5羽 | 0.6379 | 0.7368 | 1,155.9羽（+15.59%） |
| 10 | 20羽 | 0.8239 | 0.9353 | 1,138.27羽（+13.83%） |
| 10 | 50羽 | 0.9121 | 0.983 | 1,081.83羽（+8.18%） |

- **大きい群れほど見つけやすいと、見つけた鳥の割合（0.9353）は見つけた群れの割合（0.8239）より大きくなる。数えた数を群れの割合で割り戻すと、見込みは多すぎた（+13.83%）**
- 9通りすべてで多すぎた（+4.99〜+17.1%）。見つけた鳥の割合は、本当の数が分からないと出せない

## 注意（言えないこと）
- 架空のデータです。群れの大きさの分布、群れの分かれ方、見つける割合は作成者が置いたもので、結果はこれで決まります。とくに標準偏差の倍率は、置いた群れの大きさからの式どおりです
- 数えるたびに群れの分かれ方は入れかわると置き、群れどうしはばらばらに見つかる（見落とす）と置きました。群れが近くに集まっていて、まとめて見落とすような場合は入れていません（入れれば、ぶれはさらに大きくなると推測します）
- 見つけた群れの中の数は、数え間違いなく全部数えると置きました。大きい群れほど数え間違いが増える分は入れていません
- 実在の水鳥の数や、どう数えるべきかは言えません。この記事は、置いた条件で群れごとの見落としがぶれをどれだけ大きくするかを数えただけです
