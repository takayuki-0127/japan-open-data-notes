# 223 ネットで買う品目の順位は10年でどう入れ替わったか：家計消費状況調査の22品目

総務省統計局「家計消費状況調査」の、インターネットを利用した支出（ネットショッピング、二人以上の世帯の1世帯当たり月平均）22品目を2015〜2025年で並べ、支出額の順位がどれだけ入れ替わったかを見たフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A223 | 22品目の順位は10年でどう入れ替わったか。どの品目が伸び、どの年に大きく動いたか | 年ごとの順位とバンプチャート、順位相関（スピアマン・ケンドール、前年比と2015年比）、2015→2025年の倍率、増加額への寄与、9グループの構成比 | `src/a223_online_shopping_rank.py` |

## 主な結果
- 22品目計は月8,643円（2015年）→26,928円（2025年）で3.1倍。利用した世帯の割合は27.6%→56.9%
- 順位はあまり入れ替わっていない。2015年と2025年の順位相関（スピアマン）は0.89。2015年の上位4品目（旅行〈ネット上で決済〉・上記以外の商品・サービス・食料品・家電）は、2025年も上位4つのまま（食料品が3位→2位）
- 大きく上がったのは出前（21位→13位、52円→728円で14.0倍）、飲料（14位→9位）、チケット（10位→7位）。下がったのは音楽・映像・ゲームソフト（13位→19位、1.6倍）、書籍（15位→18位）、旅行〈ネット以外で決済〉（5位→8位）、贈答品（8位→11位）
- 前年との順位相関がいちばん低いのは2020年（0.85）。旅行〈ネット上で決済〉が1位→4位、チケットが7位→19位に下がり、食料品・出前が上がった。旅行とチケットは2023〜25年に元の順位近くまで戻った一方、食料（食料品・飲料・出前）の割合は2019年の13.9%から2021年に22.5%へ上がり、2025年も21.6%と高いまま
- 2015→2025年の増加額（18,285円）への寄与は、旅行〈ネット上で決済〉17.2%、食料品17.1%、上記以外の商品・サービス13.3%

## 動かし方
```
pip install -r requirements.txt
cd src && python a223_online_shopping_rank.py
```

## データ
- `data/net_shopping_2015_2025.csv`：22品目の年平均（月額、円）。統計局「家計消費状況調査 年報」時系列表（2017年版・2019年版・2022年版・2025年版のExcel）から
- `data/totals_2015_2025.csv`：22品目計、注文した世帯の割合（1万分比）、注文した世帯当たりの支出、世帯人員、世帯主の年齢
- `results/rank_2015_2025.csv`：品目別の順位（2015・2019・2020・2025年）、倍率、構成比
- `results/rank_correlation.csv`：順位相関（前年比・2015年比）と上位5品目の重なり
- `results/contribution_2015_2025.csv`：増加額への寄与
- `results/group_yen.csv`・`group_share.csv`：9グループの金額と構成比（教養はチケットを含む）

## 注意
- 金額は「ネットで注文した世帯」だけでなく、二人以上の世帯全体の平均です。利用世帯の割合が上がると、1品目当たりの金額も上がります
- 利用世帯の割合は2016→2017年に27.8%→34.3%と大きく上がっていて、この年の前後の金額の水準はそのまま比べにくい可能性があります。順位はその影響を受けにくい比べ方です
- 22品目は統計局の区分のままです。「上記以外の商品・サービス」には日用品など多くのものが入っています
- 名目の金額で、物価の変化は除いていません。品目の中身（どの店・どのサービスか）は分かりません
