# 206 食品ロスは、家庭と事業者のどちらが減ったか：食品ロス量の推計値

環境省・農林水産省の「我が国の食品ロスの発生量の推計値」（2012〜2024年度）で、食品ロスの減少分を事業系（業種別）と家庭系（発生要因別）に分けたフォルダです。2030年度の削減目標までの距離も見ています。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A206 | 食品ロスは、家庭と事業者のどちらが減ったか | 2012→2024年度・2019→2024年度・2015→2024年度の増減を業種・発生要因に分解（寄与度）、事業系・家庭系の推移と2030年度目標（2000年度比）との比較 | `src/a206_food_loss.py` |

## 主な結果
- 食品ロスは2012年度643万トン→2024年度461万トン（−182万トン、−28.3%）。事業系が−94万トン（−28.4%）、家庭系が−88万トン（−28.2%）で、減少分はほぼ半々（51.6%：48.4%）
- 事業系で最も減ったのは外食産業（119→70万トン、−49万トン）、次いで食品製造業（141→110万トン、−31万トン）。家庭系では過剰除去（野菜の皮のむき過ぎなど）が92→35万トン（−57万トン）と大きく、食べ残しは−19万トン、直接廃棄は−12万トン
- コロナ前の2019年度からでは、事業系−72万トン、家庭系−37万トンと事業系の減り方が大きい（減少分の66%）。ただし外食産業は2022年度60万トンを底に、2024年度は70万トンに増えた
- 2000年度比の削減率は事業系56.7%（目標60%、あと18万トン）、家庭系48.3%（目標50%、あと8万トン）

```bash
pip install -r requirements.txt
cd src
python a206_food_loss.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/food_loss_2012_2024.csv | 年度別の食品ロス量（万トン）：計・事業系・家庭系、事業系の業種別（食品製造業・食品卸売業・食品小売業・外食産業）、家庭系の発生要因別（直接廃棄・過剰除去・食べ残し） |
| data/targets.csv | 2030年度目標（事業系は2000年度547万トン比60%減の219万トン、家庭系は433万トン比半減の216万トン） |

- 計・事業系・家庭系は報道発表資料の表、内訳は別添資料（我が国の食品ロスの発生量の推移等）の図に書かれた値。ブラウザでPDFの文字を読み、図の位置から年度ごとの値を書き写した（内訳の合計は、端数処理で表の値と1万トン違う年がある）

## 注意
- 推計値で、事業系は食品リサイクル法に基づく事業者の報告など、家庭系は市町村への実態調査などをもとにしている。推計方法の見直しで年度間の比較に段差が出ることがある
- 家庭系の過剰除去は2016→2017年度、2018→2019年度に大きく減っており、行動の変化だけでなく調査・推計の方法の影響を含む可能性がある
- 2020〜2021年度は新型コロナで外食が減った時期で、外食産業の減少にはその影響が含まれる
- 減った理由（事業者の取組、需要の変化、推計方法など）は、このデータでは分けられない
