# 01 取得

この作業環境からは e-Stat・職場のあんぜんサイトに直接つながらないため、ブラウザでそれぞれのサイトを開き、開発者ツールのコンソールで SheetJS（xlsx 0.18.5）を読み込んで Excel を読み、必要な列を CSV にした（2026年11月5日取得）。

| 出力 | 取得元 | 処理 |
|---|---|---|
| `data/dosu_kyodo_rate.csv` | e-Stat「労働災害動向調査 時系列表：産業別労働災害率（度数率及び強度率）の推移」 `https://www.e-stat.go.jp/stat-search/file-download?statInfId=000040303459&fileKind=4` | シート「事業所規模100人以上」「事業所規模30～99人」の、調査産業計・林業（2011年から農業，林業）・漁業・鉱業・建設業（総合工事業／職別・設備工事業）・製造業（合計）・電気ガス熱供給水道業・運輸業（運輸・通信業／運輸業／運輸業，郵便業）・卸売・小売業・サービス業の度数率と強度率。表の途中で産業分類が変わるたびに見出し行が入るので、見出しごとに列の位置を探し直した。和暦は西暦に直した。1992〜2003年の「（ ）」内の値（調査対象追加前の範囲）は `old_scope=1` の行に入れた。「x」（秘匿）「-」（該当なし）「・」（項目なし）はそのまま残し、02 で欠測にした |
| `data/sennin_rate.csv` | 職場のあんぜんサイト「労働災害統計」 `https://anzeninfo.mhlw.go.jp/user/anzen/tok/r7_senninritsu.xlsx` シート「主要業種」 | 平成24年〜令和7年の15業種をそのまま。年は西暦に直した |
| `data/employees_lfs.csv` | e-Stat「労働力調査 長期時系列表5（4）産業（第12・13回改定分類）別雇用者数」 `https://www.e-stat.go.jp/stat-search/file-download?statInfId=000001082696&fileKind=0` シート「長期05」 | 男女計の2012〜2025年。「非農林業」の列は除いた |
| `data/shibou_dosu_rate.csv` | 職場のあんぜんサイト `r7_sibou_dosuritsu.xlsx` | そのまま |

コンソールで使った読み込みの例：

```js
await new Promise((ok, ng) => { const s = document.createElement('script');
  s.src = 'https://cdn.jsdelivr.net/npm/xlsx@0.18.5/dist/xlsx.full.min.js'; s.onload = ok; s.onerror = ng; document.head.appendChild(s); });
const wb = XLSX.read(await (await fetch('/stat-search/file-download?statInfId=000040303459&fileKind=4')).arrayBuffer());
const rows = XLSX.utils.sheet_to_json(wb.Sheets['事業所規模100人以上'], { header: 1, defval: '' });
// 見出し行（「調査産業計」を含む行）ごとに、産業名の列を探して度数率・強度率の2列を取り出す
```
