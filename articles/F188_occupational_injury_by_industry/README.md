# F188 労働災害は、どの産業で減り、どこで減らなかったのか

## 問い

日本の労働災害は長い目で見て大きく減ってきました。では、どの産業で減り、どの産業で減らなかったのか。全体の数字が横ばいに見える近年は、「どこでも横ばい」なのか、それとも「下がる産業と上がる産業が打ち消し合っている」のか。

## データ

| ファイル | 内容 | 出典 |
|---|---|---|
| `data/dosu_kyodo_rate.csv` | 産業別の度数率・強度率（事業所規模100人以上：1965〜2024年、30〜99人：1993〜2024年）。主な産業だけを抜き出した | 厚生労働省「労働災害動向調査」時系列表「産業別労働災害率（度数率及び強度率）の推移」（e-Stat、statInfId=000040303459） |
| `data/sennin_rate.csv` | 業種別の死傷年千人率（休業4日以上、2012〜2025年、15業種） | 厚生労働省「労働災害発生状況」（職場のあんぜんサイト、`r7_senninritsu.xlsx`）。元は労働者死傷病報告と労働力調査 |
| `data/employees_lfs.csv` | 産業別雇用者数（万人、2012〜2025年） | 総務省「労働力調査」長期時系列表5（4）（e-Stat、statInfId=000001082696） |
| `data/shibou_dosu_rate.csv` | 全産業の死亡度数率（2016〜2025年、参考） | 職場のあんぜんサイト `r7_sibou_dosuritsu.xlsx` |
| `data/tidy_*.csv` | 上の表を縦長にしたもの（`src/02_整形.py` で作成） | |

- **度数率**＝死傷者数÷延べ実労働時間数×100万（労働時間あたり）。**強度率**＝延べ労働損失日数÷延べ実労働時間数×1,000（重さ）。労働災害動向調査の死傷者は休業1日以上と死亡。
- **年千人率**＝休業4日以上の死傷者数÷平均労働者数×1,000（労働者あたり）。
- 個別の事故・事業所・企業は扱っていません。すべて公表された集計値です。

## 手法

1. **長期の変化（度数率）**：産業ごとに、1965〜1990年・1990〜2010年・2010〜2024年（と2015〜2024年）の「年あたりの変化率」を、対数リンクの擬似ポアソン回帰（尺度は Pearson χ²/自由度）で推定。
2. **労働者あたりの変化（年千人率、2012〜2025年）**：労働力調査の雇用者数を当てて死傷者数を近似し、雇用者数を offset にしたポアソン回帰（過分散を補正）で業種ごとの年変化率を推定。コロナ前（2012〜2019年）、2016〜2025年でも推定。
3. **シフト・シェア分解**：全産業の年千人率 R＝Σ（雇用者の割合×業種の率）と書き、2012→2025年の変化を「業種の中の率の変化」と「雇用者の構成の変化」に分ける（平均重み。対応する業種のない部分は「その他」として残差で計算）。

## 結果

- **1990年ごろまでに大きく下がった**：規模100人以上の度数率（全産業）は1965年の12.38から2024年の2.10へ、83%下がりました。下がったのはほとんどが1965〜1990年（年−7.5%、95%区間 −8.3〜−6.8%）で、1990〜2010年は年−0.8%、2010〜2024年は年+2.5%（+2.0〜+3.1%）と上向きでした。最も低かったのは2013年の1.58です。
- **減り方の大きさは産業で違う**：1965→2024年で、鉱業は104.1→0.7、建設業（職別・設備工事業）は16.2→0.8（−95%）、製造業は7.3→1.3、運輸業は12.1→3.6。林業は15.9→8.0 と半分にとどまり、いまも最も高い水準です。卸売・小売業は1992年の1.65から2024年の2.60に上がっています。
- **2010年以降は、ほとんどの産業で上向き**：規模100人以上で、2010〜2024年の度数率がはっきり上がったのは、全産業・製造業・運輸業・サービス業・卸売小売業・総合工事業・林業。はっきり上がっていないのは職別工事業・鉱業・電気ガス水道業でした。規模30〜99人でも全産業は年+2.4%。
- **重さ（強度率）は上がっていない**：全産業の強度率は 1965〜1990年 年−7.8%、1990〜2010年 −3.3%、2010〜2024年 −0.7%（はっきりしない）。死亡度数率も2016年の0.0085から2025年の0.0064へ下がっています。
- **労働者あたり（年千人率）では、全体は横ばいで、下がる産業と上がる産業が分かれた**（2012〜2025年）：
  - 下がった：建設業 5.0→4.0（年−1.3%）、製造業 3.0→2.7（−0.6%）、金融業 0.8→0.6（−1.5%）、林業 31.6→17.7（−3.0%）
  - 上がった：保健衛生業 1.5→2.2（年+4.0%）、教育研究業 0.3→0.5（+4.6%）、商業 1.9→2.3（+2.0%）、接客娯楽業 2.4→2.8（+1.1%）、運輸業 6.3→6.8（+0.8%）
  - 全産業は 2.3→2.3（年+0.2%、はっきりしない）。近似した死傷者数では、保健衛生業が約1.0万人から約2.0万人に倍増し、建設業は約2.1万人から約1.6万人に減りました。
- **全体が横ばいなのは、打ち消し合いの結果**：2012→2025年の変化（±0）は、業種の中の率の上昇 +0.10 と、雇用者の構成の変化 −0.10 に分かれました。製造業・建設業・運輸業の割合が下がったことが全体の率を下げ、保健衛生業・商業などの率の上昇が押し上げました。2012年の構成のままなら、2025年の年千人率は約2.39 だった計算です。

## 頑健性

- **分母（労働者数か労働時間か）と統計**：2012〜2024年の年変化率は、年千人率（労働者あたり・休業4日以上・全規模）で全産業 +0.2%、製造業 −0.7%、建設業 −1.2%。一方、労働災害動向調査の度数率（労働時間あたり・休業1日以上・規模別）では全産業 +3.0%（100人以上）・+2.2%（30〜99人）、製造業 +2.6% と、向きが逆になりました。2つの統計は分母だけでなく、数える災害の範囲（休業1日以上か4日以上か）と対象の事業所も違うため、どれが効いているかは分けられません。
- **期間**：コロナ前（2012〜2019年）では、保健衛生業は年+2.5%で上がっていましたが、商業（+0.7%）・接客娯楽業（+0.3%）ははっきりせず、上昇の多くは2020年以降です（年千人率の死傷者数には新型コロナへのり患を含みません）。分解でも、2012→2019年は率の効果 −0.05・構成 −0.05 と両方マイナス、2015→2025年は率 +0.18・構成 −0.08 でした。
- **産業区分**：分解で、労働力調査の「農業，林業」のうち林業を 0%・8%・15% とみなす3通り、平均重みとラスパイレス型（交差項つき）の2通りで、構成の効果は −0.100〜−0.115、率の効果は +0.087〜+0.101 でした。建設業は、度数率（100人以上）の職別工事業 +0.2%、総合工事業の工事現場 +6.8%、30〜99人 +2.1% と、区分で大きく変わります。
- **調査範囲の変更**：1992〜2003年の度数率は、調査対象の追加前の範囲（旧範囲）の値も公表されています。旧範囲では新範囲より0.05〜0.10低いだけで、1990〜2010年の「ほぼ横ばい」という形は変わりません。

## 言えないこと

- **原因**：なぜ保健衛生業や商業で率が上がったのか（高齢の労働者の増加、介護の仕事の増加、転倒・腰痛の増加など）は、このデータでは確かめていません。業種の中の年齢構成の変化も分けていません。
- **2つの統計の違い**：労働災害動向調査（度数率）は休業1日以上・一定規模以上の事業所の標本調査、年千人率は休業4日以上の報告件数と労働力調査の雇用者数による値で、業種の分類も細部が違います。どちらが「正しい」とは言えません。
- **報告の変化**：労働者死傷病報告は届け出の件数です。報告の徹底や意識の変化で件数が変わった可能性があり、これを実際の発生の変化と区別できません。
- **近似の誤差**：年千人率は小数1桁で公表されているため、全産業の 2.3→2.3 には ±0.05 ほどの丸めの幅があり、分解の数字（±0.10）は同じくらいの大きさです。雇用者数は役員を含む値で代用しているため、死傷者数の近似は少し大きめです。
- **分類の変更**：1992・2004・2008・2011年に産業分類や調査範囲が変わっています（2011年からの林業は「農業，林業」）。長期の比較は、同じ名前の産業でも中身が少しずつ違います。
