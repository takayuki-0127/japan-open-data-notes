# 290 第1子を産む母の年齢は、何歳ずつ上がり、どれだけ広がったのか

厚生労働省「人口動態統計」確定数（2025年）上巻 4-17「出生順位別にみた母の年齢（5歳階級）・年次別出生数」と 4-19「出生順位別にみた年次別母の平均年齢」を使ったフォルダです（全国の集計のみ）。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A290 | 第1子を産む母の年齢は、平均だけでなく、ばらつきも変わったのか | 第1子の出生数を母の年齢5歳階級で並べ、階級の中は一様に分かれていると置いて10・25・50・75・90%点を計算（19歳以下は15〜20歳、45歳以上は45〜50歳と置く）。階級の真ん中で計算した平均を公表の平均年齢と突き合わせた | `src/a290_first_birth_age.py` |

## 主な結果
- 第1子を産む母の平均年齢（公表値）は、1975年の25.7歳から2015年の30.7歳へ40年で5.0歳上がりました。そこから2025年の31.0歳までは10年で0.3歳です。
- 真ん中（中央値）は1975年25.7歳、2014年30.5歳、2025年30.9歳。下の端（10%点）は21.0歳→23.1歳→24.9歳、上の端（90%点）は29.8歳→38.3歳→38.3歳でした。
- 10%点から90%点の幅は、1975年の8.8歳から2014年の15.2歳まで広がりました。2015年からは上の端が38歳台で止まり、下の端だけが上がったので、幅は2025年に13.4歳まで縮んでいます。25%点から75%点の幅も、2014年の7.8歳が最も大きく、2025年は7.2歳です。
- 第1子に占める35歳以上の割合は1975年1.7%、2000年6.4%、2015年21.4%で、その後は20〜22%で横ばい（2025年20.4%）。25歳未満は43.1%から10.2%に下がりました。
- 出生全体（第1子に限らない）でも、10%点から90%点の幅は1975年11.3歳、2000年12.8歳、2025年13.6歳でした。

## 頑健性
- 階級の真ん中で計算した平均は、公表の平均年齢と0.1歳以内で一致した（25年分、最大0.09歳の差）
- 標準偏差（階級内の一様分布の分を足したもの）も、1975年3.9歳→2014年5.7歳→2025年5.4歳と、同じ形
- 25%点〜75%点の幅でも、最大は2014年
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致した

## 動かし方
```
pip install -r requirements.txt
cd src && python a290_first_birth_age.py
```

## データ
- `data/jinkou_r7_jokan_4-17_births_order_mother_age.csv`：上巻 4-17（statInfId=000040503654）
- `data/jinkou_r7_jokan_4-19_mother_mean_age.csv`：上巻 4-19（statInfId=000040503655）
- どちらも e-Stat「人口動態調査 人口動態統計 確定数 出生」（2025年、2026-09-30公表）を2026-11-12に取得したもの（cp932）

## 注意
- 5歳階級のデータなので、%点は階級の中を一様と置いた近似です
- 「出生順位」は、その母がこれまでに産んだ子の数で数えた順です
- 1970〜2005年は5年ごとの値で、その間の年は分かりません
- 年齢の分布の変化が、結婚の時期の変化によるのか、結婚から出産までの期間の変化によるのかは、この表では分けていません（期間の変化は記事 291 で扱っています）
- 年齢別の出生率の変化は記事 F58、出生数の減少の分解は記事 F262 で扱っています。ここでは第1子の母の年齢の分布の形に絞りました
