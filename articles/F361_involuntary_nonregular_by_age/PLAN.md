# F361 PLAN（事前の計画）：「非正規で働く人の多くは望んでそうしている」は、年齢別に見ても本当か？

作成：2026-11-16 12:57（データを取得し、表の形を確かめたあと、割合を集計する前に書いた）

## 問い
厚生労働省の資料（労働政策審議会 雇用環境・均等分科会 第90回 参考資料2-4「短時間・有期雇用労働者対策基本方針（案）データ集」、2026年3月26日）は、「不本意非正規雇用労働者」（非正規の仕事についた主な理由が「正規の職員・従業員の仕事がないから」の人）の割合が2025年に8.4%で、12年連続で下がったと書いています。ここから「非正規で働く人の多くは望んでそうしている」と言われることがあります。

知りたいこと：その割合は、年齢・男女で分けても低いのか。下がったのは、働く人の年齢構成が変わった（理由の違う高齢の非正規が増えた）からか、各年齢の中で下がったからか。人手不足（求人倍率）と一緒に動いているのか。

知りたい人：人事・採用の担当、非正規雇用の政策や統計を読む人、記者。

既存の看板記事との違い：existing_F_titles.txt と jodn の README を「非正規」「不本意」で検索して、同じ問いの記事はなかった。

## データ
- 総務省「労働力調査」詳細集計（年平均）の「年齢階級，現職の雇用形態についた主な理由別非正規の職員・従業員数」（男女別、15〜24歳／25〜34歳／35〜44歳／45〜54歳／55〜64歳／65歳以上、万人）。2013〜2025年。年報の時系列表（2017年版・2022年版・2025年版）をつなぐ。2021・2022年は2つの版で重なるので、値が同じか確かめ、新しい版の値を使う。
- 厚生労働省「一般職業紹介状況」有効求人倍率（パートを含む、実数の年平均）。

## 取得前に見たもの（開示）
- 厚労省の資料の文言（2025年8.4%、12年連続の低下、「特に44歳以下において明確な低下傾向」）と、年齢別の図の数字の一部（30.3、19.6 など。どの年齢・年かは読み取っていない）。
- 表の形を確かめるときに、2013〜2017年と2019〜2025年の男女計の総数・15〜24歳などの数行の実数を目にした。割合は計算していない。

## 割合の定義（事前に決める）
- 主：不本意の割合 = 「正規の職員・従業員の仕事がないから」÷ 7つの理由の合計（表の注にある統計局の割合と同じ定義）。
- 比べるため：分母を「総数」（理由を答えなかった人を含む）にした割合も出す。

## 仮説と「外れ」の基準
- H1：2025年の男女計・年齢計の不本意の割合は10%未満。10%以上なら外れ。
- H2：2025年でも、男の25〜34歳・35〜44歳・45〜54歳の不本意の割合は、それぞれ男女計・年齢計の2倍以上。どれか1つでも2倍未満なら外れ。
- H3：2013→2025年の男女計・年齢計の低下のうち、年齢構成の変化による部分は3割未満（主に各年齢の中の低下）。3割以上なら外れ。
- H4：2013→2025年の低下幅（ポイント）は、25〜34歳のほうが55〜64歳より大きい。小さければ外れ。

## 手法
- 割合を性・年齢ごとに計算する。
- 年齢構成の分解（シフト・シェア）：Δ割合 = Σ（各年齢の重みの平均 × 各年齢の割合の変化） + Σ（各年齢の割合の平均 × 重みの変化）。重みは理由の合計の年齢構成。男女×年齢（12区分）でも同じことをする。
- 有効求人倍率との相関（年の値、13点）。差分（前年からの変化どうし）の相関も出す（どちらも傾向で下がり・上がっているだけの見かけの相関を避けるため）。

## 頑健性（3つ以上）
1. 分母を「総数」にする。
2. 分解の区分を、年齢6区分から男女×年齢12区分にする。
3. 期間の終わりを2019年にする（コロナの前）。
4. 2021・2022年の値を古い版にしたときに変わるかを見る。

## 問い直し（予定）
結果を見てから1つ足す。候補：不本意の割合が下がったとき、ほかのどの理由（都合のよい時間、家計の補助、家事・育児など）が増えたのか。

## 言えないこと（予定）
- 「主な理由」1つだけを答える形で、複数の理由がある人の本心は分からない。「家計の補助」などが本当に望んだ働き方かは分からない。
- 調査の時点の答えで、同じ人を追っていない。
- 求人倍率との相関は因果ではない。
- 2013年より前は、この形の表がない（質問が2013年から）。
