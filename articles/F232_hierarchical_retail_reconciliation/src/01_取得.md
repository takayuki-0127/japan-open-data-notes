# 01 取得

- 使うのは、経済産業省「商業動態統計」の時系列データ（月次・全国・販売額）。百貨店・スーパーは商品別、コンビニ・ドラッグストア・ホームセンター・家電大型専門店は商品（品目）別。
- 取得は F135（雨の日と小売の売上）で行い、整形済みの縦持ちファイルを同じリポジトリに置いている：`articles/F135_rain_retail/data/raw/` の業態別の月次販売額（取得手順は F135 の README と src/01 を参照）。
- このフォルダには、そこから「全国・販売額・2014年1月〜2026年8月」だけを抜き出した `data/raw/retail_national_2014_2026.csv`（9,580行）を置いた。新しいデータは取っていない。
- 2014年1月からにしたのは、ドラッグストア・ホームセンター・家電大型専門店の商品別がそろうのが2014年からのため。家電大型専門店の細かい品目（調理家電など）は2021年からしかないので使わず、2014年からある6区分（AV・情報・通信・カメラ・生活・その他）を葉にした。
