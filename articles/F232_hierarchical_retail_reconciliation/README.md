# F232 店の種類ごとの予測と全体の予測を、どうそろえるか？

看板記事 ② 実務に近い分析（F231〜F245）の2本目。部門別の予算と全社の予算が合わない、という実務の問題を、公開データの小売の販売額で再現した。

## 問い
- 業態（百貨店・スーパー・コンビニ・ドラッグストア・ホームセンター・家電大型専門店）と、その中の商品ごとに別々に売上を予測すると、全体の予測と「下の予測の合計」はどれだけ食い違うのか。
- 食い違いをなくす「そろえ方」（足し上げ・割り振り・MinT など）のうち、どれが外れをいちばん小さくするのか。全体・業態・商品のどの単位で見るかで答えは変わるのか。
- 実務で「全社の予算」「業態の予算」「商品の発注」に使うなら、どれを選べばよいか。

## データ
| データ | 内容 | 期間 |
|---|---|---|
| 経済産業省「商業動態統計」時系列データ（F135 で取得したものを再利用） | 全国・月次の販売額（百万円）。百貨店・スーパーは商品別10、コンビニは4、ドラッグストア・ホームセンターは9、家電大型専門店は6 | 2014年1月〜2026年8月（152か月） |

- 葉（いちばん細かい単位）48商品を足すと、公表の業態合計・中分類と一致することを確かめた（ずれは最大0.004%、`results/00_hierarchy_check.csv`）。百貨店・スーパーの「衣料品」は身の回り品を含む。
- 階層：全体（1）→ 業態（6）→ 中分類（百貨店・スーパーの「衣料品」「その他」、コンビニの「商品販売額」の5）→ 商品（48）。合わせて60系列。

## 手法
1. **ベース予測**：60系列それぞれに、対数の ETS（減衰つきトレンド＋季節）を当てて12か月先まで予測。
2. **そろえ方（7つ）**：ボトムアップ（商品の予測を足し上げる）、トップダウン2種（過去36か月の割合で割り振る／予測の割合で上から順に割り振る）、OLS、WLS（構造：下にある商品の数で重み）、WLS（ばらつき：1か月先の外れの分散で重み）、MinT（外れの分散と相関を縮小推定）。
3. **評価**：2022年6月〜2025年8月の39か月を起点に、毎月予測し直す（ローリング）。60系列×12か月先×39回の絶対パーセント誤差（APE）を、階層ごと・予測の先ごとに平均（MAPE）。
4. **差の確かさ**：起点ごとの平均の差を、6か月ブロックのブートストラップ（2,000回）で区間にした。
5. **SQL**：予測を縦持ちの表に入れ、「親の予測＝子の予測の合計」になっているかを SQL で検算（`sql/02_coherence_check.sql`）。精度の集計も SQL で書き、Python と一致を確認（`sql/03_accuracy_by_level.sql`、差は丸めの0.0005以内）。SQL は SQL Server 互換の書き方で、検算は DuckDB で動かした（型名と N'' だけ読み替え）。
6. **BI**：最新の起点（2025年8月）からの予測を見る静的な HTML ダッシュボード（`dashboard/index.html`、外部ライブラリなし）。系列を選ぶと、実績・3つの予測・「下の合計とのずれ」の表が出る。

## 結果
### 別々に作ると合わない
- 全体の予測と「6業態の予測の合計」のずれは、1か月先で中央値1.2%、12か月先で2.5%（39回の90%点は3.8%）。
- 2025年8月起点の予測では、業態の予測と「その下の商品の予測の合計」のずれは平均0.9%、最大4.3%（SQL の検算）。そろえた予測では、どの親子でもずれは0。

### どのそろえ方がよいか（MAPE、1〜12か月先の平均）
| 方法 | 全体 | 業態 | 中分類 | 商品 |
|---|---|---|---|---|
| ボトムアップ（足し上げ） | **1.55** | **2.91** | **5.20** | 5.53 |
| WLS（ばらつき） | 1.69 | 2.93 | 5.27 | 5.53 |
| WLS（構造） | 1.75 | 3.01 | 5.57 | 7.03 |
| MinT（縮小） | 1.87 | 3.11 | 5.84 | 5.77 |
| ベース（そろえない） | 2.15 | 3.12 | 5.29 | 5.53 |
| トップダウン（予測の割合） | 2.15 | 3.32 | 5.74 | 5.89 |
| OLS | 2.00 | 3.48 | 6.05 | 9.32 |
| トップダウン（過去の割合） | 2.15 | 6.30 | 10.05 | 12.35 |

- 全体の外れは、商品の予測を足し上げるだけで2.15%→1.55%（−28%）。1〜3か月先でも7〜12か月先でも、足し上げがいちばん小さい（1.13%・1.41%・1.83%）。
- MinT は足し上げより、全体で+0.32ポイント（95%区間 +0.04〜+0.67）、業態で+0.20（+0.04〜+0.43）、商品で+0.23（+0.02〜+0.55）悪かった。足し上げのほうが良かった起点は、全体で39回中30回（77%）。
- 過去の割合で上から割り振ると、業態・商品の外れが2倍以上になった（ドラッグストアの調剤の伸びなど、割合が動いたため）。
- 業態ごとに見ると、足し上げが一番だったのはコンビニ・スーパー・ドラッグストア・百貨店。ホームセンターはそろえない予測（2.17%）、家電大型専門店は OLS とトップダウン（3.53%）がわずかに良かった（`results/F_mape_by_store_type.csv`）。

### 実務での選び方（この記事のデータでの目安）
| 使いみち | おすすめ | 理由 |
|---|---|---|
| 全社の予算 | 商品の予測の足し上げ | 全体の外れがいちばん小さい（1.55%） |
| 業態の予算 | 足し上げ（または WLS（ばらつき）） | 2.91%と2.93%でほぼ同じ |
| 商品の発注 | 商品ごとの予測のまま（足し上げと同じ） | そろえても商品の精度は上がらない |
| 避けたい | 過去の割合で割り振るトップダウン、OLS | 業態・商品の外れが大きく悪化 |
| 前年同月をそのまま使う予測 | そろえる必要なし | もともと足し算が合っている |

## 頑健性
| 条件 | 全体：足し上げ | 全体：MinT | 全体：ベース | 商品：足し上げ | 商品：MinT |
|---|---|---|---|---|---|
| 主（2022-06〜2025-08起点、ETS） | 1.55 | 1.87 | 2.15 | 5.53 | 5.77 |
| コロナ前（2017〜2018起点） | 1.56 | 1.56 | 1.67 | 4.77 | 4.75 |
| MinT の外れの期間を24か月 | 1.55 | 1.75 | 2.15 | 5.53 | 5.65 |
| ベースを前年同月（季節ナイーブ） | 3.50 | 3.50 | 3.50 | 6.26 | 6.26 |
| 2階層だけ（全体と6業態） | 1.96 | 1.91 | 2.15 | ― | ― |
| 主・売上で重みづけした MAPE | 1.44 | 1.73 | 2.05 | 3.49 | 3.61 |

- コロナ前の期間では、足し上げ・MinT・WLS（ばらつき）がほぼ同じ（1.56%）。MinT が負けたのは、主に2022年以降の期間。
- 2階層だけ（業態の予測を足して全体を作る）だと、足し上げの全体の外れは1.96%で、48商品から足し上げた1.55%より大きい。細かい単位から足すほうが、この期間では全体も当たった。
- 前年同月をそのまま使う予測は、もともと足し算が合っているので、どのそろえ方でも同じ数字になる。
- MinT の縮小の強さ（λ）は平均0.34。

## 言えないこと
- **一般にボトムアップが一番、とは言えない**：MinT は多くの研究で強い方法とされる。ここで負けたのは、2022年以降の物価上昇やコロナ後の回復で、1か月先の当てはまりの外れ（MinT の重みの元）と、12か月先までの実際の外れの形がずれたためと考えている（推測）。コロナ前の期間では差がなかった。
- **ベース予測は ETS の1種類だけ**：ベース予測を変えると、どのそろえ方が良いかも変わりうる。
- **評価期間は約3年（39回）**：区間がぎりぎり0を超えた比較もあり、期間を変えると順位が入れ替わる可能性がある。
- **公表の集計値で、店の単位ではない**：実際の会社の部門予算は、店・地域・品目の組み合わせがもっと複雑で、この結果をそのまま当てはめられない。
- **ダッシュボードの「架空の社内向け画面」は例**：数字は公開データの加工で、実在の会社の数字ではない。
