# 937 評価者の数を増やすと、点の振れはどれだけ減るのか？（人事評価）

1人を何人で評価するかを増やすと、点の振れは「1÷√人数」で減ると言われます。けれども、それが成り立つのは評価者ごとのずれがばらばらなときだけです。目立つ仕事が多い人を誰もが高く見るように、どの評価者にも同じに見えるずれは、何人で平均しても消えません。**ここでは、作成者が乱数で作った架空の会社の300人と評価者40人（本当の点・評価者の甘さ辛さ・どの評価者にも同じに見えるずれ・評価者だけのぶれを作成者が置いたもの）で、1人を評価する人数を1〜20人に変え、評価の点が本当の点からどれだけ外れるか、上位10%がどれだけ当たるかを数えました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A937 | 評価者の数を増やすと、評価の点の本当の点からの外れはどれだけ減るか。どこまで減るか。上位10%の当たり、本当に5点違う2人の順の当たりはどう変わるか | 架空の会社の300人。本当の点は平均60・標準偏差10の正規分布。評価者40人の甘さ辛さは標準偏差 s_l=5点。人ごとの「どの評価者にも同じに見えるずれ」（共通の見え方）は標準偏差 s_c=5点。1回の評価ごとの「その評価者だけのぶれ」は標準偏差 s_e=10点。1人の評価者の点＝本当の点＋甘さ辛さ＋共通の見え方＋ぶれ。1人につき40人からでたらめに k 人を選び（k=1・2・3・5・8・10・20）、その平均を評価の点とした。外れの大きさは「評価の点−本当の点」の二乗平均の平方根（ほぼ標準偏差）で、式 √(s_c²＋(s_l²＋s_e²)÷k) と比べた。300人を作り直して200回の平均。比べとして、共通の見え方なし（s_c=0）と、全員が同じ k 人に評価される場合も数えた。確かめとして、s_c（0・5・10点）× s_e（5・10・15点）の9通りを、k=1・3・5・10 の各100回で数えた。あわせて評価者2人の点の相関（評価者どうしのそろい方）を数えた。seed 937 | `src/a937_number_of_raters.py` |

## 主な結果

### 評価者の数と外れ（200回の平均、`results/by_k_base.csv`・`results/by_k_no_shared.csv`）
| 1人を評価する人数 | 外れ（共通の見え方5点） | 式 | 外れ（共通の見え方なし） | 上位10%の当たり（共通5点） | 上位10%の当たり（共通なし） |
|---|---|---|---|---|---|
| 1人 | 12.24点 | 12.25点 | 11.15点 | 41.6% | 44.1% |
| 3人 | 8.14点 | 8.16点 | 6.47点 | 53.0% | 61.1% |
| 5人 | **7.10点** | 7.07点 | 4.98点 | 57.6% | 68.5% |
| 10人 | 6.09点 | 6.12点 | 3.53点 | 62.3% | 76.0% |
| 20人 | **5.58点** | 5.59点 | 2.49点 | **65.0%** | 83.2% |

- 外れは式どおりに減った（式との差は0.05点以内）。1人から5人にすると、外れは1人の0.58倍になった。1÷√5＝0.447倍よりも減り方は小さい
- **20人で平均しても外れは5.58点で、共通の見え方の5点より下がらなかった**。共通の見え方がなければ、20人で2.49点まで下がった
- 本当の点の上位10%に入っていた割合は、20人でも65.0%で頭打ちに近かった。共通の見え方がなければ83.2%だった
- 本当に5点違う2人の順が合う割合は、1人で61.2%、5人で69.0%、20人で73.8%（共通の見え方なしでは62.5%・76.5%・93.0%）

### 全員が同じ k 人に評価される場合（`results/by_k_same_panel.csv`）
- 同じ評価者に評価されると、評価者の甘さ辛さは全員に同じだけ乗り、順位には効かない。全員に共通のずれを除いた外れは、5人で6.70点（でたらめに選ぶと7.05点）、上位10%の当たりは59.5%（同57.6%）で、少し良くなるだけだった。残る外れの多くは共通の見え方と評価者だけのぶれだった

### 確かめ：共通の見え方 × 評価者だけのぶれ（9通り、各100回、`results/grid_ratio.csv`・`results/grid_shared_noise.csv`）
| 共通の見え方 | ぶれ | 5人の外れ÷1人の外れ | 10人の外れ÷1人の外れ | 評価者2人の点の相関 | 10人の平均と本当の点の相関 |
|---|---|---|---|---|---|
| 0点 | 5点 | 0.442 | 0.313 | 0.664 | 0.979 |
| 0点 | 10点 | 0.444 | 0.316 | 0.455 | 0.945 |
| 0点 | 15点 | 0.451 | 0.318 | 0.278 | 0.896 |
| 5点 | 5点 | 0.674 | 0.629 | 0.716 | 0.876 |
| 5点 | 10点 | 0.581 | 0.502 | 0.497 | 0.855 |
| 5点 | 15点 | 0.522 | 0.426 | 0.332 | 0.817 |
| 10点 | 5点 | 0.866 | 0.842 | 0.798 | 0.698 |
| 10点 | 10点 | 0.745 | 0.711 | 0.612 | 0.684 |
| 10点 | 15点 | 0.652 | 0.599 | 0.439 | 0.664 |

- 5人にしたときの外れの減り方は、9通りで1人の0.442〜0.866倍と動いた。共通の見え方がなければ1÷√5＝0.447倍の近く、共通の見え方が大きく、ぶれが小さいほど減らなかった
- 10人の平均で上位10%に入っていた割合は、9通りで42.7〜85.4%だった
- **評価者どうしがいちばんよくそろったのは、共通の見え方10点・ぶれ5点（2人の点の相関0.798）だったが、そのとき10人の平均と本当の点の相関は0.698と、9通りの中で低いほうだった**。評価者どうしがそろうことは、本当の点に近いことを示さない。共通の見え方は、評価者どうしをそろえる向きに働くため

## 動かし方
```
pip install -r requirements.txt
cd src && python a937_number_of_raters.py
```
10秒ほどで終わります。`data/` の3つのファイルもこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の13ファイルがバイト単位で一致した（cmp、約7秒）
- 外れの大きさが、7つの人数すべてで式 √(s_c²＋(s_l²＋s_e²)÷k) と0.05点以内で合うことを確かめた（評価者40人から選ぶので、甘さ辛さの分は式より少し小さく出る）
- 評価者2人の点の相関が、基本の置き方の式の値 (10²＋5²)÷(10²＋5²＋5²＋10²)＝0.5 の近く（0.49〜0.51）になることを確かめた

## データ
- `data/people.csv`：架空の1回分の300人（person・true（本当の点）・shared_view（共通の見え方））
- `data/raters.csv`：評価者40人（rater・leniency（甘さ辛さ））
- `data/ratings.csv`：1人につき10人の評価者が付けた点（person・order・rater・score）。先頭から k 人の平均を取ると、この1回では外れが1人で12.95点、5人で7.39点、10人で6.21点（`results/a937_main.json` の one_draw）

## 注意（言えないこと）
- 架空のデータです。甘さ辛さ・共通の見え方・ぶれの大きさは作成者が置いたもので、結果はこれで決まります。外れが式 √(s_c²＋(s_l²＋s_e²)÷k) で減ること、共通の見え方の分が残ることは、置いた形からの式どおりの結果です。新しく数えたのは、上位10%の当たりや2人の順の当たりがどこで頭打ちになるか、評価者どうしのそろい方が本当の点への近さと逆を向くことがあることです
- 評価者どうしは互いの点を見ずに付けると置きました。先に付けた人の点に引っぱられる、話し合いで点をそろえる、といったことは入れていません。入れると、ぶれの一部が共通のずれになり、人数を増やしても減りにくくなります（推測）
- 「本当の点」は作成者が置いたもので、実際の評価では分かりません。評価者どうしの一致だけからは、共通の見え方の大きさは分かりません
- 何人で評価すべきか、評価を給与や処遇にどう使うべきかは、ここからは言えません
- 関連する記事 915 は、検査員どうしの一致率が正しさを表さないことを数えています（915 は、合否の線を同じように甘めに置いた2人がそろう話で、この記事は、人ごとの「共通の見え方」が評価者全員を同じ向きにずらしてそろえる話です）。801 は口コミの件数が少ない店ほど星の平均が振れることを数えています。同じ企画の 933（甘い評価者と辛い評価者の点を、そのまま比べてよいのか）は評価者の甘さ辛さそのものの記事で、この記事はそれを含めた振れが人数でどれだけ減るかに絞っています
