# F483 事前の計画（PLAN）

作成：2026-11-16 13:06（JST）。仮説の判定に使う計算（分解・回帰）をする前に書いた。予備 R12 に替えた記事（REPLACED.md 参照）。

## 問い
家計の携帯電話の通信料は、料金の値下げのあとどれだけ減ったのか？

## 知りたい人
家計の支出を分析する人、通信サービスにかかわる人。2021年春に携帯電話の新しい低料金プランが広がり、消費者物価指数の「通信料（携帯電話）」は大きく下がりました（既存の F88 で物価の側は扱い済み）。では、家計が実際に払う額はどれだけ減ったのか、年齢によって違うのかを確かめたい人。

## データ
- 総務省「家計調査」年報 第4-6表（二人以上の世帯、世帯主の年齢階級別、品目分類）2015〜2025年：携帯電話通信料（2019年までは「移動電話通信料」）、固定電話通信料、消費支出、世帯数分布。
- 総務省「家計調査」長期時系列 表1-2（二人以上の世帯）・表6（単身世帯）：中分類「通信」と消費支出（2000〜2025年）。
- 総務省「消費者物価指数」2025年基準 品目別（年平均）：通信料（携帯電話）、通信、総合。

### 取得前に見たもの（下見）— 正直に書く
- 表を読み込むスクリプトを確かめるとき、年齢階級別の携帯電話通信料・固定電話通信料・消費支出の2015〜2025年の値と、消費者物価指数の2014〜2025年の値を、表のまま一度表示してしまった。
- このため、「平均の支出額がいくら減ったか」「どの年齢で増えたか（70歳以上は増えていた）」は、計画の前に見ている。これらは仮説にせず、記述（結果）として示す。
- 長期時系列の「通信」（二人以上・単身）の2015年前後の値も、行を探すときに目に入った。
- まだ計算していないもの：年齢構成の変化による分解、物価との回帰、物価で割った実質の値、消費支出に占める割合。

## 仮説（外れの基準つき）— まだ計算していないものだけ
- H1：2019→2025年の平均の携帯電話通信料の変化を「各年齢の中での変化」と「世帯主の年齢構成の変化（高齢の世帯が増えた）」に分けると、年齢の中での変化が全体の80%以上を説明する。外れ：80%未満。
- H2：2015〜2025年の平均の支出額（対数）を、通信料（携帯電話）の物価（対数）と直線の時間の傾きで説明すると、物価の係数は0より大きく1より小さい（物価ほどには支出が減らない＝使う量や契約数が増えた）。外れ：係数が1以上、または0以下。

## 手法
- シフト・シェア分解：ΣΔ(年齢別の支出)×平均の構成比 と ΣΔ構成比×平均の支出（2時点の平均を使う対称形）。
- 回帰：log(支出) = a + b·log(物価) + c·年 （11年、HC1 の標準誤差）。
- 実質の値：支出 ÷ 通信料（携帯電話）の物価（2025年＝100）。

## 頑健性（3つ以上）
1. 比べる年を2019→2025年でなく、3年平均（2017〜19年 → 2023〜25年）にする。
2. 2020年を起点にする（値下げの直前の年）。
3. 回帰の時間の傾きを外す／物価を総合で割った相対価格にする。
4. 単身世帯は品目がないので、中分類「通信」で二人以上の世帯と比べる。

## 問い直しの候補（結果を見てから一つ選ぶ）
- 値下げがなく2015〜2019年の伸びが続いていたら、2025年の支出はいくらだったか（直線の延長との差）。

## 言えないこと（予想）
- 家計調査の「携帯電話通信料」には、端末の分割払いが含まれる場合があり、通信の料金だけではない（調査の定義を確かめる）。
- 1世帯あたりの支出で、1人あたりや契約1件あたりではない。
- 値下げが家計のほかの支出にどう回ったかは言えない。
- 物価との回帰は11年分しかなく、因果ではない。
