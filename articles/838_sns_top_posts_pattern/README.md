# 838 伸びた投稿だけ見て「伸びる型」を決めると、何が起きるのか？（SNSと動画）

SNS や動画サイトの運用では、よく伸びた投稿を集めて「伸びる型」を探すことがあります。けれども、伸びた投稿だけを見ると、平均で強い型ではなく、当たり外れの大きい型が多く見えます。また、ほとんどの投稿に付いている特徴は、伸びた投稿にも多く付いて見えます。**ここでは、作成者が乱数で作った架空のアカウントの投稿600本（型ごとの再生回数の分布を作成者が置いたもの）で、上位の投稿だけを見たときの型の割合と、全部の投稿で見た平均を比べ、「伸びる型」に全部を替えたときに次の100本の再生回数がどうなるかを数えました。**

## 主な結果

### 上位のどこまでを見るかで、型の割合が変わる（1,000回の平均）
| 見た範囲 | 流行に乗る型の割合 | 字幕ありの割合 |
|---|---|---|
| 上位1%（6本） | **74.1%** | 79.7% |
| 上位5%（30本） | **40.3%** | 79.9% |
| 上位10%（60本） | 29.4% | 79.8% |
| 上位25%（150本） | 20.0% | 80.0% |
| 上位50%（300本） | 16.6% | 79.9% |
| 全部（600本） | 30.0% | 80.0% |

- 流行に乗る型は、全部の投稿では3割だが、上位5%では40.3%、上位1%では74.1%を占めた。平均は定番より約2割低いと置いたのに、上の端だけを見ると多く見えた
- 上位25%・50%まで広げると、逆に定番の型が多くなった。どこで切るかで「伸びる型」の答えが変わった
- 「上位5%の中の割合が全体より大きい型を伸びる型とする」決まりでは、87.9%の回で流行に乗る型が選ばれた
- 字幕は、どの範囲でも約8割だった。「伸びた投稿の8割に字幕が付いている」は、全部の投稿の8割に付いているだけで、効き目を表していなかった
- 全部の投稿の中央値で比べると、流行に乗る型が定番より高く見えた回は0%、平均で比べると4.0%だった（右の裾に長い分布では、平均も1本の大当たりで動くため）

### 1回分のデータ（`data/posts.csv`）
| 型 | 本数 | 再生回数の平均 | 中央値 | 2万回以上の割合 |
|---|---|---|---|---|
| 定番の型 | 454 | 3,548 | 3,092 | 0.0% |
| 流行に乗る型 | 146 | 4,818 | 1,254 | 1.4% |

- この回は、流行に乗る型が全体の24.3%、上位5%（30本）の40.0%だった
- この回は、全部の投稿の平均でも流行に乗る型が高く見えた（1,000回のうち4.0%に当たる回）。中央値では定番の型のほうが高かった

### 次の100本を全部「流行に乗る型」にしたら（1万回）
| | 今の混ぜ方のまま（流行3割） | 全部を流行に乗る型にする |
|---|---|---|
| 合計再生回数の平均 | 335,047 | 278,693 |
| 100本の中央値（1万回の中央値） | 2,594 | 1,200 |
| 2万回以上の投稿の本数（平均） | 0.51本 | 1.5本 |

- 全部を流行に乗る型に替えると、合計再生回数が今のままより増えたのは**18.0%**の回だけだった
- 2万回を超える「大当たり」は増えた（0.51本→1.5本）が、ふだんの投稿の再生回数は半分以下になった

### 確かめ：流行に乗る型の置き方を変えると（各1,000回）
| 置き方 | 全体の割合 | 上位5%の割合 | 伸びる型に選ばれた回 | 本当の平均（定番を1として） |
|---|---|---|---|---|
| 基本（振れ1.3・中央値1,200） | 30% | 40.3% | 87.9% | 0.78 |
| 振れ 1.0 | 30% | 18.4% | 6.6% | 0.55 |
| 振れ 1.6 | 30% | 59.5% | 99.8% | 1.20 |
| 中央値 800 | 30% | 23.4% | 18.3% | 0.52 |
| 中央値 2,000 | 30% | 66.1% | 100.0% | 1.30 |
| 平均を定番と同じにする（中央値1,543） | 30% | **52.1%** | 99.0% | 1.00 |
| 本数 1割 | 10% | 13.7% | 70.4% | 0.78 |
| 本数 5割 | 50% | 63.0% | 91.5% | 0.78 |
| 振れを定番と同じ0.6（中央値1,200） | 30% | 0.9% | 0.0% | 0.40 |

- 平均を定番と同じにしても、流行に乗る型は上位5%の52.1%を占め、99.0%の回で「伸びる型」に選ばれた。上位で多く見えるかどうかは、平均より振れの大きさで決まった
- 振れを定番と同じにすると、上位5%の割合は0.9%に下がった。平均が低い型が上位で多く見えるのは、振れが大きいときだけだった
- 平均が定番より低い置き方で「伸びる型」に選ばれた回は、0.0〜91.5%と置き方で大きく動いた。基本の置き方の87.9%は、振れと中央値の置き方による

## 注意（言えないこと）
- 架空のデータです。型ごとの中央値・振れ・本数の割合は作成者が置いたもので、結果はこれで決まります。とくに「平均が低い型が伸びる型に選ばれる」かどうかは、振れと中央値の置き方で0.0〜91.5%まで動きました
- 型の違いだけで再生回数が決まると置きました。実際の投稿では、同じ型の中でも中身・時期・フォロワー数で再生回数は変わります
- 「流行に乗る型が悪い」とは言えません。大当たりの本数を増やしたいなら、平均が低くても振れの大きい型を混ぜる意味はあります（推測）。この記事で言えるのは、上位だけを見ると、平均ではなく振れの大きい型が多く見える、ということです
- 次の100本で合計が増えた18.0%は、基本の置き方（振れ1.3・中央値1,200）だけで数え、置き方を変えた確かめはしていません。振れや中央値を変えると動くと考えられます（推測）
- 実在のアカウントやサービスの数字を表すものではありません
