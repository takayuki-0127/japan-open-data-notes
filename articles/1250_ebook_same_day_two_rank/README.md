# 1250 同じ日に2冊出すと、1冊ずつ出したときと比べて、1冊あたりの順位はどう見えるのか？（電子書籍）

電子書籍の販売の順位は、ここ数日の売れ方で決まります。同じ作者が2冊を同じ日に出すと、ファンの買い物が2冊に分かれたり、片方を後回しにしたりして、1冊ごとの発売の山が低くなることがあります。順位は売れた冊数に比例しないので、冊数が少し減っただけでも、順位の数字は大きく動いて見えます。**ここでは、作成者が置いた架空の電子書籍の分野（ほかの本2万冊の売れ方と、順位の決まりを作成者が決め、乱数で毎日の冊数を作ったもの）で、作成者の架空の本 X・Y を、14日あけて1冊ずつ出したときと同じ日に出したときで、1冊あたりの最高順位、100位以内の日数、14日の冊数を比べました。両方を買うはずのファンが片方だけ買う割合と、2冊目を後回しにする割合を0にした対照と、ファンの数を変えた27通りで確かめました。**

例の本・分野・順位の決まりはすべて架空のもので、実在の販売サイトの順位の決まりを表すものではありません。いつ出すとよいか、値段や広告の出し方を勧める記事ではありません。

関連する記事：1248「発売した週の山を含めて平均すると、ふだんの1日の売れ方はどう見えるのか？」は、発売の山がふだんの売れ方の読みに入ることを扱っています。1014「合計点の差が小さいとき、順位の差は意味があるのか？」は、順位の差が点の差の大きさを表さないことを、店の合計点で扱っています。1245「販売の順位から、1日に何冊売れたかはどこまで読めるのか？」は、順位から冊数を読むときのずれを、1254「「売れ筋の何位以内」に入った日数で本を比べると、分野ごとの競争の違いで何がずれるのか？」は、分野の何位以内に入った日数で本を比べるときのずれを扱っています。この記事は、同じ日に2冊出したときの1冊あたりの順位の見え方に絞ります。

## 主な結果

### 1冊あたりの比べ（300回、`results/a1250_main.json`）
| 置き方 | 1冊ずつ：最高順位（中央値） | 同じ日：最高順位（中央値） | 最高順位の比（同じ日÷1冊ずつ、1回ごとの比の中央値） | 14日の冊数の比 | 同じ日のほうが最高順位が下だった回 |
|---|---|---|---|---|---|
| どちらもいない（c＝0・q＝0） | 12.0位 | 12.5位 | 1.0435倍 | 0.9999倍 | 56% |
| 片方だけ買う人だけ（c＝0.2） | 12.0位 | 14.5位 | 1.2094倍 | 0.9244倍 | 87.33% |
| おくらせる人だけ（q＝0.3） | 12.0位 | 15.0位 | 1.2698倍 | 0.9817倍 | 91% |
| 基本（c＝0.2・q＝0.3） | 12.0位 | **17.5位** | **1.4677倍** | **0.9095倍** | 98% |

- **基本の置き方では、同じ日に出すと1冊あたりの14日の冊数は0.9095倍（166.627冊→151.547冊）だったが、最高順位の数字は1.4677倍（12.0位→17.5位）になった**
- 片方だけ買う人もおくらせる人もいない対照では、最高順位は1.0435倍とほぼ同じだった。同じ日に出したもう1冊が上にいると1つ下がる分だけ（作りどおり）
- おくらせる人だけ（q＝0.3）では、14日の冊数は0.9817倍とほとんど減らないのに、最高順位は1.2698倍になった。冊数が減るより、発売の日のまわりに買い物が集まらなくなることのほうが、最高順位に効いた
- 100位以内の日数は、1冊ずつ4.185日・同じ日4.058日（0.9697倍）と、最高順位ほどは変わらなかった

### 順位と点の関係（ある1つの分野の14日目、`results/rank_score_curve.csv`）
| 順位 | その順位に要る点 |
|---|---|
| 10位 | 91.186 |
| 20位 | 66.247 |
| 50位 | 41.645 |
| 100位 | 29.771 |

- 上位では、点の差が小さくても順位の数字は大きく動く。最高順位の比が冊数の比より大きく出るのは、この形と、買い物が散って山が低くなることの2つによる（推測。2つを分けては数えていない）

### 例の1回（`data/example_run.csv`）
- 1冊ずつ：X の最高13位・Y の最高14位（14日の冊数173冊・161冊）。同じ日：X の最高20位・Y の最高30位（141冊・135冊）

### 確かめ：27通り（`results/grid.csv`）
- **最高順位の比は1.0308〜2.0351倍**。c＝0・q＝0の3通りは1.0308〜1.0455倍で、ほかの24通りは1.1807〜2.0351倍だった
- 14日の冊数の比は0.8225〜1.0099倍。27通りすべてで、最高順位の比は冊数の比の逆数より大きかった
- おくらせる人だけ（c＝0、q＝0.3・0.6）の6通りでは、冊数の比が0.9589〜0.9905倍でも、最高順位の比は1.2414〜1.6429倍だった
- 100位以内の日数は、ファン200人・400人ではあまり変わらなかった（同じ日3.81〜4.19日・5.255〜6.13日、1冊ずつ4.145日・5.77日）。ファン100人（最高順位が50位前後）では、c＝0・q＝0を除く8通りで同じ日のほうが少なくなった（0.885〜2.3日、1冊ずつ2.63日）

## 注意（言えないこと）
- 架空のデータです。ほかの本の売れ方、順位の決まり、ファンの数と買い方（c・q）は作成者が置いたもので、最高順位がどれだけ下がるかはこれで決まります（27通りで1.0308〜2.0351倍）
- 同じ日に出すとファンがどれだけ片方だけ買うか・後回しにするかは、作成者が置いた値で、実際にどうなるかは分かりません。c・q が0なら順位はほぼ変わりません
- 同じ日に2冊出すと、本を見つける人が増えるなどの効き目は置いていません
- 実在の販売サイトの順位の決まりを表すものではありません。いつ出すか・値段・広告の助言はしません
