# 1240 一部の件だけを2人で付けて確かめると、残りの件のまちがいの数はどこまで見込めるのか？（ラベル付け）

データにラベルを付ける作業では、全件を2人で付けるのは手間がかかるので、一部の件だけを2人目にも付けてもらい、2人の食い違いから「残りの件にどれだけまちがいがあるか」を見込むことがあります。けれども、2人の食い違いはまちがいそのものではありません。片方だけがまちがえれば食い違いになりますが、紛らわしい件で2人がそろって同じ分類にまちがえると、食い違いには出てきません。**ここでは、作成者が置いた架空の製品の写真に見立てた10,000件（5つの分類の本当の分類と、件ごとの紛らわしさ、付け手がまちがえる確率とまちがえるときの付け先を作成者が置き、乱数で判定を作ったもの）で、1人目が全件に付け、でたらめに選んだ500件だけ2人目も付けたとき、4つの見込み方で残り9,500件の1人目のまちがいの数がどれだけ当たるかを数えました。確かめる件の数を100〜2,000件に変えた場合、2人目が1人目の答えを見てから付けた場合、紛らわしい件の割合・紛らわしい件でまちがえる確率・同じ相手に寄る確率を変えた27通りでも確かめました。**

例の写真・分類・付け手は架空のもので、実在のラベル付けの作業やサービスを表すものではありません。付け手を人の属性で比べていません（付け手はみな同じまちがい方と置いています）。何件を2人で確かめるべきかの助言はしていません。

関連する記事：542（問い合わせの分類を2人が別々に付けたときの食い違い）は、2人の食い違いの割合と、偶然の一致を除いた一致の度合いを数えていて、2人が同じまちがいをすると一致に数えられることにも触れています。915「検査員によって合否が違うとき、何を数えればよいのか？」は、検査員どうしの一致率が高くても判定が正しいとは限らないことを扱っています。同じ企画の 1244「付け手の意見が割れた件を「難しい件」として別に数えると、分類の正解率の上限はどう見えるのか？」は、付け手の意見が割れた件と本当に見分けにくい件のずれを扱っています。1233「1件を3人で見て多い方の判定に決めると、1人で見るより正しくなるのは、どんなときか？」は、3人の多い方で決めても、3人が同じ件で外しやすいと1人より正しくなる幅が縮むことを数えています。この記事の「2人がそろって同じ分類にまちがえる分」が食い違いに出ないのと同じ根です。この記事は、一部の件の食い違いから、残りの件のまちがいの「数」を見込むときのずれに絞ります。

## 主な結果

### 基本の置き方（500回、`results/a1240_main.json` の `headline`）
| 残り9,500件のまちがいの数の見込み方 | 見込んだ数（平均） | 見込み÷本当（平均） | 10〜90%の範囲 | 本当より少なく見込んだ回 | 式 |
|---|---|---|---|---|---|
| 本当の数 | 722.07件 | | | | 722件 |
| ①食い違いの割合をそのまま | 1,149.46件 | **1.5938倍** | 1.3353〜1.8511倍 | 0% | 1.6032倍 |
| ②食い違いの割合の半分 | 574.73件 | 0.7969倍 | 0.6676〜0.9255倍 | 97.4% | 0.8016倍 |
| ③食い違った件だけ見直す | 605.87件 | **0.8401倍** | 0.6671〜1.025倍 | 86.8% | 0.8442倍 |
| ④確かめた件をすべて正解と照らす | 720.97件 | 0.9997倍 | 0.82〜1.2098倍 | 52.6% | 1倍 |

- 1人目のまちがいの割合は7.6%、2人の食い違いの割合は12.18%、2人がそろって同じ分類にまちがえる割合は1.18%（式。500回の平均ではそれぞれ7.59%・12.1%・1.21%）
- **①食い違いをそのまままちがいとみなすと、1.5938倍に多く見込んだ。** 食い違いには2人目のまちがいも入るため
- **③食い違った件を正しく見直しても、0.8401倍と少なく見込んだ。** 2人がそろって同じ分類にまちがえた件は食い違いに出てこないため、1人目のまちがいの15.58%（式、1.18÷7.6）は見えなかった
- ②の「半分」は、2人がそろってまちがえる分を差し引きすぎて0.7969倍になった
- ④だけが平均で本当に一致した（作りどおり）。ただし500件では1回ごとに0.82〜1.2098倍と振れた
- 1回分の10,000件では、1人目のまちがい757件の79.52%が紛らわしい件（2,059件）の中にあった

### 確かめ：27通り（各200回、`results/grid.csv`）
- **27通りすべてで、③は本当より少なく（0.6713〜0.994倍）、①は本当より多く（1.2973〜1.8625倍）見込んだ。** ②は27通りすべてで少なく（0.6486〜0.9313倍）、④は0.9884〜1.0324倍だった
- ③の少なさは、紛らわしい件でまちがえるとき同じ相手に寄る確率で決まった。50%で0.8845〜0.994倍、80%で0.7671〜0.927倍、95%で0.6713〜0.9033倍。紛らわしい件が多いほど、まちがえる確率が高いほど、少なく見込んだ
- ①・③の見込み÷本当の平均は、式の値と0.0315以内で合った

- `results/reps_base.csv`：基本の置き方の500回（`true_rest` は残り9,500件の本当のまちがいの数）
- `results/by_check_size.csv`：確かめる件の数ごとの③・④の見込み÷本当
- `results/grid.csv`：確かめの27通り（`hard` は紛らわしい件の割合、`e_hard` は紛らわしい件でまちがえる確率、`same` は同じ相手に寄る確率、`*_ratio` は見込み÷本当の平均、`*_formula` は式の値）

## 注意（言えないこと）
- 架空のデータと、作成者が置いたまちがい方です。③がどれだけ少なく見込むかは、紛らわしい件の多さと、2人がそろって同じ分類にまちがえる確率でほぼ決まります（式どおり）
- 付け手はみな同じまちがい方と置きました。付け手ごとにまちがいやすさが違う場合、2人目を誰にするかで見込みは変わります
- ③では、食い違った件の見直しはまちがいなくできると置きました。見直す人もまちがえる場合は入れていません
- 確かめる件は全件からでたらめに選ぶと置きました。易しそうな件や特定の日の件だけを選ぶと、ずれ方は変わります
- 何件を2人で確かめるべきか、どの見込み方を使うべきかの助言はしていません
