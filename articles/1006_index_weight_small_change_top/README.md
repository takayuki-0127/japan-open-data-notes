# 1006 重みを少し変えると、上位は何位入れ替わるのか？（指数とスコア）

チームや店の「総合指数」は、項目ごとの値に重みを掛けて足して作ります。重みは「得点力3割、守り2.5割」のように決めますが、0.30 と 0.25 の間に強い根拠があることはあまりありません。重みを0.05だけ別の項目へ移しても、指数の作り方としてはどちらも「ありそう」に見えます。**ここでは、作成者が乱数で作った架空のリーグの60チーム（5項目の値と項目どうしの結びつきを作成者が置いたもの）で、基本の重みから1つの項目の重みを0.02・0.05・0.10だけ別の項目へ移した20通りで指数を出し直し、上位10チームと1位がどれだけ入れ替わるか、それが1位と2位の差の大きさでどう決まるかを数えました。「どの重みが正しいか」は扱いません。**

関連する記事 939（人事評価）は、「均等」「成果重視」のように考え方の違う重みや、0.05刻みのすべての重み（455通り）で、30人のチームの1位・上位3人が入れ替わるかを数えています。同じ企画の 1005 は、重みを均等のまま足す前のそろえ方を変えたときです。この記事は、1つの基本の重みのすぐ近く（0.02〜0.10だけ移す）に絞り、上位10チームの順番の動きと、1位と2位の差との関係を数えます。

## 主な結果

### 例のリーグ（`results/example_moves_d005.csv`）
- 基本の重みでの上位10チームは 38・40・56・30・22・26・19・29・35・27 番。指数は1位65.71点、2位64.52点（差1.194点）、10位58.31点。リーグ全体の指数の標準偏差は7.114点
- 重みを0.05移す20通りのうち、1位が変わった（40番が1位になった）のは2通りだった
- 上位10チームの顔ぶれは、20通りのどれでも変わらなかった。ただし順番は動き、基本の上位15チームのうち9チームは20通りの中で順位が3つ以上動いた。いちばん大きく動いたチーム（16番）は7つ動いた（図1）

### 1,000リーグで（`results/by_delta.csv`）
| 移した重み δ | 1通りで1位が変わる割合（20通りの平均） | 20通りのどれかで1位が変わったリーグ | 上位10から外れたチーム（平均） | 上位10の順番が変わった位置（10のうち、平均） | 上位10のチームの順位の動き（いちばん大きいチーム、平均） |
|---|---|---|---|---|---|
| 0.02 | 4.3% | 16.7% | 0.27チーム | 2.665か所 | 1.213 |
| **0.05** | **10.72%** | **37.3%** | 0.61チーム | **4.852か所** | 2.425 |
| 0.10 | 21.37% | 64.1% | 1.14チーム | 6.68か所 | 4.457 |

- **重みを0.05だけ移すと、上位10の10の位置のうち平均4.852か所で違うチームが入り、20通りのどれかで1位が変わったリーグは37.3%だった**
- 上位10の顔ぶれ（どのチームが10位以内か）は、0.05移しても平均0.61チームしか変わらなかった。変わるのは主に10位以内の順番
- 1位と2位の差は中央値1.998点、10位と11位の差は中央値0.326点だった（δ＝0.05のリーグ）。指数の点で見ると、上位どうしはわずかな差で並んでいる

### 1位と2位の差と、1位の入れ替わり（δ＝0.05、`results/by_gap.csv`）
| 1位と2位の差 | リーグの数 | 20通りのどれかで1位が変わった |
|---|---|---|
| 0.5点未満 | 163 | **99.39%** |
| 0.5〜1点 | 137 | 93.43% |
| 1〜2点 | 201 | 38.31% |
| 2〜3点 | 162 | 3.7% |
| 3〜5点 | 188 | **0%** |
| 5点以上 | 149 | 0% |

- **1位が入れ替わるかは、1位と2位の差でほぼ決まった**。差が1点未満のリーグ（全体の30.0%）では9割以上で入れ替わり、3点以上ではまったく入れ替わらなかった
- これは**式どおり**の結果です。重みを δ 移すと、2チームの指数の差は「10×δ×（移した先の項目の差−移した元の項目の差）」だけ動くので、差がこの大きさを超えると入れ替わりようがありません。どれかの動かし方で1位が変わったリーグの1位と2位の差は、いちばん大きくても δ＝0.02で0.92点、0.05で2.825点、0.10で4.875点で、δ にほぼ比例した

### 確かめ：置き方を1つずつ変えると（δ＝0.05、各500リーグ、`results/robustness.csv`）
| 変えたもの | 値 | どれかで1位が変わった | 1通りで1位が変わる割合 | 上位10から外れたチーム | 上位10の順番が変わった位置 |
|---|---|---|---|---|---|
| チームの数 | 20 | 33.2% | 8.92% | 0.34チーム | 3.784か所 |
| | **60（基本）** | 36.2% | 10.89% | 0.609チーム | 4.9か所 |
| | 200 | 43.6% | 13.69% | 0.835チーム | 5.535か所 |
| 項目どうしの相関 | 0 | **61.8%** | 20.24% | 1.01チーム | 6.297か所 |
| | **0.3（基本）** | 37.0% | 9.69% | 0.627チーム | 4.792か所 |
| | 0.6 | **28.0%** | 7.8% | 0.381チーム | 3.635か所 |
| 基本の重みの形 | **基本（0.30〜0.10）** | 38.2% | 10.47% | 0.637チーム | 4.873か所 |
| | 均等（0.20ずつ） | 43.0% | 12.7% | 0.647チーム | 5.011か所 |
| | 偏り（0.40・0.30・0.10・0.10・0.10） | 40.2% | 11.38% | 0.587チーム | 4.704か所 |

- **20通りのどれかで1位が変わったリーグは、置き方で28.0〜61.8%と動いた**。いちばん効いたのは項目どうしの相関で、項目どうしの結びつきが弱いほど、重みを少し動かしただけで1位が入れ替わった
- チームが多いほど、上位どうしの差が詰まるので入れ替わりやすかった
- 基本の重みの形を変えたときの動きは小さかった（38.2〜43.0%）
- 基本の置き方は、変えたものごとに乱数を変えて数え直したので、1,000リーグの値（37.3%）から少し動く（36.2〜38.2%）

## 注意（言えないこと）
- 架空のデータです。項目の数、項目どうしの相関、チームの数、基本の重みは作成者が置いたもので、結果はこれで決まります。20通りのどれかで1位が変わったリーグの割合は、置き方で28.0〜61.8%と動きました。実際のリーグや大会の指数を表すものではありません
- 「どの重みが正しいか」「どのチームが本当に強いか」は言えません。本当の強さは置いておらず、重みの小さな違いだけで順番がどれだけ動くかを数えました
- 1位が入れ替わるかが1位と2位の差でほぼ決まるのは、指数の作り（重みを掛けて足す）からの式どおりの結果です。新しく数えたのは、その差がこの置き方でどれくらいの大きさになりやすいか（差が1点未満のリーグが30.0%）と、上位10の順番がどれだけ動くかです
- 項目の値は測り間違いのないものと置きました。測り方の誤差が加わると、順番はさらに動くと考えられます（推測）
- 関連する記事：939（項目の重みで順位が入れ替わるか）は、考え方の違う重みや0.05刻みのすべての重みで30人の順位を比べた話で、5段階の点の同点も入っています。この記事は、1つの基本の重みのすぐ近くだけを動かし、1位と2位の差との関係を数えた点が違います。同じ企画の 1005 は、足す前のそろえ方を変える話です。1014 は、重みは変えずに、客の顔ぶれによる合計点の振れで隣の順位がどれだけ入れかわるかを扱っています。1位が入れかわるかが1位と2位の差で決まる点は共通で、こちらは重みの小さな違い、1014 は測るときの振れが原因です
