# 887 継続率は、月で数えるか案件で数えるかで変わるのか？（副業の数字）

副業の取引先がどれだけ続けて頼んでくれるか（継続率）は、数え方がいくつもあります。「先月取引のあった取引先のうち今月もある割合」（月で数える）、「終わった案件のうち同じ取引先から次の案件が来た割合」（案件で数える）、「取引先のうち2件目が来た割合」（取引先で数える）は、同じ記録から出しても同じ値になりません。**ここでは、作成者が乱数で作った架空の取引先（取引先ごとの「次を頼む確率」・案件の長さ・次の案件までの空きを作成者が置いたもの）の36か月の記録で、3つの数え方の継続率を比べ、それぞれが置いた答えのどれに近いか、置き方を変えるとどう動くかを数えました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A887 | 同じ記録から、月で数えた継続率・案件で数えた継続率・取引先で数えた継続率はどれだけ違うか。それぞれ何を当てているか | 架空の取引先2,000社、記録は36か月。1件目の開始月は1〜36か月で一様。取引先ごとに、案件が終わったあと次の案件を頼む確率 p をベータ分布（平均0.5、集中度 κ＝2）で置く。案件の長さは1＋ポアソン（平均2か月）、次の案件までの空きはポアソン（平均1か月、0なら翌月から続けて始まる）。記録の窓（36か月）の中で見えるものだけで数える。案件で数えるときは、窓の中で終わった案件すべて（次がまだ来ていない案件も「続かなかった」に入る）と、終わって6か月以上たった案件だけの2通り。基本の置き方は30回の平均。κ（1・2・10・差なし）×案件の長さ（平均1・2・4か月）×空き（平均0・1・3か月）の36通りで確かめた（各5回）。seed 887 | `src/a887_retention.py` |

## 主な結果

### 基本の置き方（取引先2,000社×30回の平均）
| 数え方 | 継続率 |
|---|---|
| 月で数える | 62.2% |
| 案件で数える（次がまだ来ていない案件も入れる） | 60.0% |
| 案件で数える（終わって6か月以上たった案件だけ） | **64.0%** |
| 取引先で数える（2件目が来た割合） | **45.8%** |
| 取引先で数える（1件目が記録の24か月目までの取引先だけ） | 49.8% |
| 置いた答え：取引先の平均の「次を頼む確率」 | 50.0% |
| 置いた答え：案件1件あたりの「次を頼む確率」 | 65.2% |

- 同じ記録から、数え方で継続率は45.8〜64.0%に分かれた
- **案件で数えた継続率（64.0%）は、取引先の平均（50.0%）ではなく、案件1件あたりの「次を頼む確率」（65.2%）に近かった**。よく頼む取引先ほど案件の数が多く、案件で数えるとその取引先が多く入るため。この65.2%は、取引先どうしの差の置き方から決まる値です
- 取引先で数えた45.8%が50.0%を下回ったのは、記録の終わりのほうで取引の始まった取引先に、まだ2件目が来ていないため。1件目が記録の24か月目までの取引先に絞ると49.8%だった
- 案件で数えるとき、次がまだ来ていない案件も「続かなかった」に入れると60.0%に下がった。終わってから待つ月数を0・1・3・6・12か月にすると、60.5%・62.9%・64.9%・64.6%・62.8%だった（各10回の平均）

### 月で数えた継続率は、案件の長さと空きで動く（κ＝2）
| 案件の長さ（平均） | 空き 平均0か月 | 空き 平均1か月 |
|---|---|---|
| 1か月 | 72.8% | 25.1% |
| 2か月 | 84.2% | 62.4% |
| 4か月 | 91.1% | 81.5% |

- **月で数えた継続率は、取引先が次を頼む確率が同じでも、案件の長さと次の案件までの空きの置き方で25.1〜91.1%まで動いた**。案件が長いほど、同じ案件の途中の月が「続いた」に数えられ、空きが1か月でもあると「続かなかった」に数えられるため

### 取引先どうしの差を変えると（案件の長さ2か月・空き1か月）
| 取引先どうしの差（κ） | 案件で数える（6か月以上たった案件） | 取引先で数える（2件目が来た割合） |
|---|---|---|
| とても大きい（1） | 70.2% | 45.6% |
| 大きい（2、基本） | 64.2% | 46.0% |
| 小さい（10） | 54.1% | 46.0% |
| 差なし | 50.3% | 46.6% |

- 取引先どうしの差が大きいほど、案件で数えた継続率は高く出た。差がなければ、取引先の平均（50%）とほぼ同じだった

### 確かめ：36通りで
| | 最小 | 最大 |
|---|---|---|
| 月で数える | 2.4% | 92.5% |
| 案件で数える（すべて） | 42.3% | 77.9% |
| 案件で数える（6か月以上たった案件） | 49.2% | 80.2% |
| 取引先で数える（2件目が来た割合） | 39.6% | 48.6% |

- 案件で数えた継続率（6か月以上たった案件）と、案件1件あたりの「次を頼む確率」の差は、36通りで−2.5〜+0.8ポイントだった。取引先どうしの差がない9通りでは、案件で数えた継続率は49.2〜50.8%だった
- 1件目が記録の24か月目までの取引先に絞った「取引先で数える」は、36通りで48.9〜51.5%で、取引先の平均（50%）に近かった
- 36通りのうち、月で数えた継続率がほかの3つの数え方より高かったのは58.3%だった。月で数えると高く出るか低く出るかは、案件の長さと空きで逆になった

## 動かし方
```
pip install -r requirements.txt
cd src && python a887_retention.py
```
7秒ほどで終わります。`data/projects_300clients.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約6秒）
- 取引先どうしの差をなくすと、案件で数えた継続率（6か月以上たった案件）が置いた答え50%に戻ることを確かめた（49.2〜50.8%）
- 案件で数えた継続率が、記録から別に数えた「案件1件あたりの次を頼む確率」とほぼ一致することを確かめた（差−2.5〜+0.8ポイント）

## データ
- `data/projects_300clients.csv`：架空の取引先300社の案件の記録（client_id・project_no（何件目か）・start・end（開始月・終了月、1〜36か月目。終了月は36を超えることがある）・next_ordered（次を頼むと決まったか。次の案件が記録の外（37か月目以降）で始まる場合も True になる、作成者だけが知る値）・p_true（置いた「次を頼む確率」））。この1回では755件の案件があり、月で数える62.5%、案件で数える（6か月以上たった案件）67.3%、取引先で数える44.7%だった

## 注意（言えないこと）
- 架空のデータです。取引先ごとの「次を頼む確率」の分布、案件の長さ、次の案件までの空きは作成者が置いたもので、どの数え方がどれだけ高く出るかはこれで決まります。とくに月で数えた継続率は、置き方で2.4〜92.5%まで動きました
- 案件で数えた継続率が取引先の平均より高く出るのは、取引先どうしの差を置いたことの写しです。差がなければ同じになります
- どの数え方が正しいかは、何を知りたいかで決まります。「取引先1社がまた頼んでくれるか」なら取引先の平均、「いま受けている案件のあとに次が来るか」なら案件1件あたりの確率に近いものを見ることになります（推測：どちらを知りたいかは使う人によります）
- 取引先が次を頼むかどうかは、それまでの案件の数や時期と関係しないと置きました。取引の途中で頼む確率が変わることは入れていません
- 報酬・料金の決め方や、取引先の選び方については何も言えません。この記事は継続率の数え方だけを扱っています
- 関連する記事 888 は、取引先の発注が毎月決まった確率で止まると置いたとき、1社に頼る割合で月の収入の落ち方がどう変わるかを数えています。この記事は、取引先が続く割合そのものを、同じ記録からどう数えるかを扱います
