# 577 2つの測り方の一致を、相関で見るか、差の平均と幅で見るかで、結論はどう変わるのか（手法の解説・正解の分かるデータで試す）

新しい計量器が今の計量器と同じ値を出すかを確かめるとき、2台の値の相関係数を見ることがあります。しかし相関は「一緒に動くか」を測るもので、「同じ値になるか」は測りません。**ここでは、架空の荷物200個を2台で1回ずつ測った4つの場面（ずれなし／一定のずれ+0.5kg／比例のずれ3%／ずれなし・重さの範囲が狭い）で、相関と、差の平均・一致の幅（Bland–Altman 法、平均±1.96×差の標準偏差）を比べました。さらに、ずれのない同じ2台で、測る荷物の重さの範囲だけを0.5kg〜29kgに変えて500回ずつ試しました。** 数字は置いた前提で決まります。

## 主な結果
- **ずれなし（1〜30kg）**：相関 0.9997、差の平均 +0.01kg、一致の幅 −0.34〜+0.35kg、差が±0.3kg以内 91%
- **一定のずれ+0.5kg**：相関 0.9997（ずれなしと同じ）、差の平均 +0.50kg、一致の幅 +0.14〜+0.86kg、±0.3kg以内 12.5%
- **比例のずれ3%**：相関 0.9998（4つの中でいちばん高い）、差の平均 +0.45kg、一致の幅 −0.10〜+1.00kg。差は重い荷物ほど大きい（1kg あたり+0.029kg）。±0.3kg以内 31%
- **ずれなし・範囲が狭い（5〜6kg）**：相関 0.816 に下がるが、一致の幅は −0.39〜+0.37kg で、ずれなし（広い範囲）とほぼ同じ
- **範囲の広さを変えた500回**：相関の中央値は 0.5kg 幅で 0.57、1kg で 0.84、2kg で 0.95、5kg 以上で 0.99〜1.00。一致の幅の半分はどの範囲でも ±0.35kg（2台の誤差から計算した値 ±0.353kg と同じ）。相関が0.95を超えた割合は 0%・0%・75%・100%・100%・100%

## データ
- `data/paired_measurements.csv`：4つの場面の測定値（場面・荷物の番号・今の計量器・新しい計量器、kg）。乱数から作った架空の値

## 注意（言えないこと）
- 架空のデータ。計量器の誤差・ずれの大きさは作成者が置いたもので、結果はこれで決まる。実際の計量器の性能ではない
- 一致の幅が「十分に狭いか」は、使い道で決まる。統計からは決められない（ここでは例として±0.3kgを使った）
- 1回ずつ測った値だけを使った。同じ荷物を何度も測って、それぞれの計量器のばらつきを分けることはしていない
- 一致の幅は、差が正規分布に近く、大きさで変わらないことを前提にしている。比例のずれのように差が大きさで変わるときは、そのままでは幅を読み違える
