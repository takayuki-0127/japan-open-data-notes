# F323 PLAN（事前の計画）：通勤時間は長くなったのか、短くなったのか？

作成：2026-11-16 07:00 JST（都道府県別の集計をする前に書いた）

## 問い
「テレワークで通勤時間が減った」と言われる一方、長い目で見ると通勤時間は伸びてきたとも言われる。
働く人（有業者）の1日あたりの通勤・通学時間は、1976年から2021年にどう動いたのか。2016→2021年の減り方は、もともと通勤が長い東京圏で大きかったのか。
働き方の構成（パートの増加など）の変化で見かけが変わっていないかも確かめる。

知りたい人：住まい選びや職場の立地を考える実務の人（不動産・人事・交通）、自治体の交通や住宅の計画の担当、生活時間の記事を読む人。
「1日の通勤時間」が、通勤する日の長さの話なのか、通勤する日の数の話なのかで、読み方が変わるため。

## データ
- 総務省「社会生活基本調査」令和3年 第6表 男女、ふだんの就業状態、曜日、行動の種類別総平均時間の推移（1976〜2021年、全国）
- 同 平成28年 生活時間－地域 第68-1表、令和3年 第74-1表（曜日、男女、従業上の地位、雇用形態、行動の種類別総平均時間（有業者）、全国・都道府県）
- 指標は「総平均時間」＝その属性の人全員で割った1日あたりの平均（通勤しなかった日・人も0分として入る）。

## 取得前・下見で見たもの（開示）
- 第6表で、全国の有業者の週全体の通勤・通学時間（1976〜2021年の10回分）を見た（2016年48分、2021年43分など）。
- 令和3年第74-1表の全国の行（有業者総数43分、正規の職員・従業員51分など）と、平成28年第68-1表の全国の数行を見た。
- 埼玉県の統計ページ（令和3年社会生活基本調査の解説）で、平日に通勤・通学した人だけの平均（行動者平均）が全国で2016年・2021年とも1時間19分だったこと、神奈川・千葉・東京が上位であることを読んだ。
- そのため H1・H4 の一部は数字を見たあとに置いた仮説で、参考扱いにする。都道府県別の値は集計していない。

## 仮説と「外れ」の基準
- H1（参考）：全国の有業者の週全体の通勤・通学時間は、1986→2016年に3分以上伸びた。3分未満なら外れ。
- H2：2016→2021年の減り方（正規の職員・従業員、平日）は、東京圏（埼玉・千葉・東京・神奈川の単純平均）で地方圏（三大都市圏を除く36道県の単純平均）の2倍以上。2倍未満なら外れ。
- H3：47都道府県で、2016年の通勤時間が長い県ほど2016→2021年に大きく減った（正規、平日、相関係数 r ≤ −0.5）。r > −0.5 なら外れ。
- H4（参考）：全国の2016→2021年の減少は、正規の職員・従業員だけで見ても3分以上ある（パートの増加などの構成の変化では説明しきれない）。3分未満なら外れ。

## 手法
- 全国の推移は表の値をそのまま並べる（週全体・平日、男女）。
- 都道府県は2016年と2021年の差。県の並びは北から南、または地方別。順位は作らない。
- 相関はピアソンとスピアマン。ブートストラップ（県を単位に2,000回、乱数の種 20261116）で相関の区間を出す。

## 頑健性（3つ以上）
1. 平日ではなく週全体で
2. 正規の職員・従業員ではなく有業者総数で
3. 男女別に
4. 東京都を除く
5. スピアマンの順位相関

## 言えないこと（予想）
- 総平均時間は「通勤する日の長さ」と「通勤する人・日の割合」が混ざる。どちらが動いたかは、この表だけでは分けられない
- 社会生活基本調査は標本調査で、県の値には標本のぶれがある（表は分単位に丸められている）
- 2021年は新型コロナの時期の調査で、その後に戻ったかは分からない
- 通勤の手段や距離は分からない
