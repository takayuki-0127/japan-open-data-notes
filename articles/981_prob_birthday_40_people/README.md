# 981 40人の中に同じ誕生日の人がいるのは、珍しいのか？（確率の直感）

40人の集まりで同じ誕生日の2人が見つかると、「すごい偶然」と感じがちです。けれども、40人の中の2人の組は780組あり、どれか1組が同じ日になればよいので、同じ誕生日の2人がいるほうがふつうです。「自分と同じ誕生日の人がいるか」と「だれか2人が同じ誕生日か」は、別の問いです。**ここでは、作成者が乱数で作った架空の会社の40人のグループ（誕生日の起きやすさを作成者が置いたもの）で、同じ誕生日の2人がいる確率、自分と同じ誕生日の人がいる確率、同じ誕生日の組の数を数え、人数・季節の偏り・2月29日を変えるとどう動くかを確かめました。**

## 主な結果

### 40人のグループ（365日が同じ起きやすさ、20万グループ）
| | 乱数 | 式 |
|---|---|---|
| だれか2人が同じ誕生日 | **89.16%** | 89.12% |
| 自分と同じ誕生日の人がいる | **10.17%** | 10.15% |
| （参考）40÷365 | | 10.96% |
| 同じ誕生日の2人の組の数（平均） | 2.13組 | 2.137組 |
| 3人以上が同じ誕生日 | 6.64% | |
| 誕生日が1日違い以内の2人がいる | **99.92%** | |
| 誕生日が3日違い以内の2人がいる | 100.0% | |

- **40人なら、だれか2人が同じ誕生日の確率は89.12%（式どおり）で、同じ誕生日の2人がいないほうが珍しかった（10.88%）**。2人の組は780組あり、1組ごとに同じ日になる確率は1/365なので、平均で2.137組（780÷365）が同じ誕生日になる
- 「自分と同じ誕生日の人」は、ほかの39人と自分の39組だけを見るので、10.15%だった。「だれか2人」の89.12%との差は、見ている組の数の差（780組と39組）
- 同じ誕生日の組の数は、0組が10.84%、1組が26.19%、2組が28.0%、3組以上が34.97%だった（図2）
- 「同じ日」を「1日違い以内」にゆるめると、99.92%になった。何を「同じ」と数えるかで、起きやすさは大きく変わる

### 会社全体（40人のグループ50個、4,000社）
- 同じ誕生日の2人がいないグループは、平均5.42個（式では50×10.88%＝5.44個）だった。10〜90%の範囲は3〜8個で、0個の会社は0.2%だった
- 50個のグループのほとんどで同じ誕生日の2人が見つかる。「うちのグループにもいた」は、ほぼどのグループでも言える

### 人数ごと（`results/by_group_size.csv`、式と各5万グループの乱数）
| 人数 | だれか2人が同じ誕生日（式） | 自分と同じ（式） | 1日違い以内（乱数） | 3人以上が同じ（乱数） |
|---|---|---|---|---|
| 10人 | 11.69% | 2.44% | 31.4% | 0.1% |
| 20人 | 41.14% | 5.08% | 80.42% | 0.89% |
| 23人 | **50.73%** | 5.86% | 89.01% | 1.28% |
| 30人 | 70.63% | 7.65% | 97.86% | 2.82% |
| 40人 | 89.12% | 10.15% | 99.89% | 6.61% |
| 50人 | 97.04% | 12.58% | 100.0% | 12.58% |
| 80人 | 99.99% | 19.49% | 100.0% | 41.73% |

- だれか2人が同じ誕生日の確率は、23人で50.73%と半分を超えた。自分と同じ誕生日の人がいる確率は、80人でも19.49%だった
- 乱数で数えた値と式の値の差は、13通りで最大0.28ポイントだった（30人を超えるとどの数え方も式とほぼ同じ）

### 確かめ：季節の偏りと2月29日（`results/by_seasonality.csv`、40人）
| いちばん多い日÷いちばん少ない日 | 同じ誕生日の2人がいる（式、2月29日なし） | 2月29日あり | 乱数（2月29日なし、10万グループ） |
|---|---|---|---|
| 1倍（偏りなし） | 89.12% | 89.09% | 89.21% |
| 1.22倍 | 89.24% | 89.21% | 89.17% |
| 1.5倍 | 89.58% | 89.56% | 89.47% |
| 2.33倍 | 90.85% | 90.83% | 90.71% |
| 9倍 | **94.65%** | 94.65% | 94.67% |

- **誕生日に季節の偏りを置くと、同じ誕生日の2人がいる確率は上がった。置き方で89.09〜94.65%**。多い日に人が集まるので、同じ日になりやすい
- ただし、いちばん多い日がいちばん少ない日の1.5倍という偏りでも、89.58%と0.46ポイント上がるだけだった。9倍という大きな偏りを置いて、ようやく94.65%
- 2月29日を入れても、0〜0.03ポイント下がるだけだった
- 偏りの大きさは作成者が置いたもので、実際の誕生日の偏りを表すものではありません

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約10秒）
- 図3枚を開き、日本語・重なり・軸を確かめた
- 365日が同じ起きやすさのとき、乱数で数えた「だれか2人が同じ誕生日」は、式の値と13通りで最大0.28ポイントの差でそろった。季節の偏りがあるときも、厳密な式の値と乱数の差は10通りで最大0.14ポイントだった
- 同じ誕生日の組の数の平均（2.13組）が、式の780÷365＝2.137組とそろうことを確かめた

## 注意（言えないこと）
- 架空のデータです。誕生日の起きやすさ（365日同じ、または作成者が置いた季節の偏り）は作成者が置いたもので、結果はこれで決まります。同じ誕生日の2人がいる確率は、置き方で89.09〜94.65%と動きました
- 主な結果（89.12%・10.15%・2.137組・23人で半分を超えること）は、よく知られた式どおりの値です（誕生日のパラドックスと呼ばれます）。この記事で新しく数えたのは、季節の偏りを置いたときの動きの小ささ、「1日違い以内」にゆるめたときの増え方、会社の中のグループの数で見たときの見え方です
- 人どうしの誕生日は互いに影響しないと置きました。双子や、同じ日に入社した人の誕生日がそろいやすいといったつながりは入れていません
- 実際の誕生日の季節の偏りは扱っていません。実際の人の集まりでの確率は言えません
