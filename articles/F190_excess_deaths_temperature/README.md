# F190 暑い夏と寒い冬に、亡くなる人はどれだけ増えるのか？

全国の月ごとの死亡数を、「いつもの年ならこのくらい」という期待値と比べ、その差が気温とどう関係しているかを調べました。地域や施設ごとの比較はせず、全国の集計値だけを使っています。

## 問い

- 平年より暑い夏の月、寒い冬の月には、死亡数は期待値よりどれだけ多くなるか。
- 2020年以降の大きな超過死亡のうち、気温で説明できるのはどのくらいか。
- 答えは、期待値の作り方・期間・気温の測り方・コロナ期の扱いでどれだけ動くか。

## データ

| ファイル | 内容 |
|---|---|
| data/raw/deaths_monthly_F172.csv | 厚生労働省「人口動態統計」確定数 上巻 死亡 第5.4表（死亡月別にみた年次別死亡数）。F172 で整形したもの。2000〜2025年は毎年 |
| data/raw/jma_temp_monthly_pref_1995_2026.csv | 気象庁「過去の気象データ検索」月ごとの値。47都道府県の気象台（県庁所在地など、jma_stations.csv）の月平均気温・日最高気温の月平均・日最低気温の月平均。値の後ろの `|q` は準正常値、`|i` は資料不足値 |
| data/raw/jma_temp_monthly_national.csv | 上の47地点を、2020年国勢調査の都道府県人口で重みづけした全国平均（popw）、単純平均（unw）、東京（tokyo）。資料不足値は除いて平均 |
| data/raw/jma_mon_jpn_anomaly.csv | 気象庁「日本の月平均気温偏差」（15地点平均、1991〜2020年平均との差） |
| data/monthly_panel.csv | 02_整形.py の出力（2000〜2025年、312か月） |

- 気温の「平年差」は、その月の1995〜2020年の平均との差です（47地点の月ごとの値が1995年から取れるため）。
- 気象庁のサイトはこの作業環境から直接つながらないので、ブラウザで取得・集計して data/raw/ に置きました。01_取得.py に、同じ取得を行う関数があります。

## 手法

1. **期待死亡数**：2010〜2019年の月別死亡数に、ポアソン回帰（過分散を補正）を当てはめました。説明変数は「月」と「時間の直線トレンド」、月の日数をオフセットにしています。2011年3月（震災の月）は学習から除きました。これを2010〜2025年にのばした値を期待値とし、実際との差を超過死亡とします。
2. **気温との関係**：2010〜2019年の各月について「実際÷期待」の対数を、その月の気温の平年差（人口重みの全国平均気温）に回帰しました。夏（6〜9月）と冬（12〜3月）で別々に推定し、HC3 の標準誤差を使っています。
3. **同時モデル**（確認）：2000〜2019年で、月・2次トレンド・夏の気温差・冬の気温差・冬の前の月の気温差を1つのポアソン回帰に入れました。
4. **気温で説明できる分**：2の係数と各月の気温差から「平年どおりの気温だった場合との差」を計算し、季節ごとに足しました（冬は12月を翌年の冬に含めます）。

## 結果

### 季節の形
- 2010〜2019年の1日あたり死亡数は、1月が4,133人、8月が3,259人で、1月は8月の1.27倍でした。季節そのものの差はこれだけ大きいので、以下は「同じ月どうしで、平年より暑いか寒いか」の比較です。

### 気温の平年差と死亡（2010〜2019年）
| 季節 | 1℃高いときの死亡数の変化 | 95%区間 | p | 月数 |
|---|---|---|---|---|
| 夏（6〜9月） | +0.63% | +0.13〜+1.13% | 0.013 | 40 |
| 冬（12〜3月） | −1.39% | −2.07〜−0.71% | <0.001 | 39 |

- 夏は暑いほど少し多く、冬は寒いほどはっきり多くなりました。冬の1℃は夏の1℃の約2倍の大きさです。
- 夏を気温差で4つに分けると、実際÷期待の平均は −0.5℃以下で0.997、−0.5〜+0.5℃で0.993、+0.5〜+1℃で1.008、+1℃超で1.006 でした。月の平均では、はっきりした「暑さの山」は見えません。
- 同時モデル（2000〜2019年）では、夏 +0.86%（+0.19〜+1.54%）、冬 −1.90%（−2.43〜−1.37%）、冬の前の月 −0.76%（−1.29〜−0.24%）でした。寒さの影響は翌月にも残ります。

### 人数にすると
- 平年より1.1℃暑かった2010年の夏（6〜9月）：気温で説明できる分は約2,500人（超過は約5,500人）。
- 平年より1.0℃寒かった2012年の冬：約6,600人（超過は約5,700人）。
- 2023・2024・2025年の夏は平年より1.8〜2.3℃暑く、気温で説明できる分は1夏あたり約5,200・5,700・6,800人でした。超過は約43,000・49,000・15,600人です。
- 2020〜2025年の超過は合計約43.8万人でした。気温で説明できる分は合計で約−1.4万人です。暑い夏の分（+2.1万人）より、暖かかった冬で少なくなった分（−3.6万人）が大きかったためです。

## 頑健性

| 確かめたこと | 結果 |
|---|---|
| 学習期間（2010–19・2005–19・2000–19・2014–19）×トレンド（直線・2次）×気温の指標6通り（人口重み平均・最高・最低・47地点単純平均・東京・気象庁15地点の平年差）の48通り | 夏 +0.36〜+1.09%（p<0.05 は48通り中34）、冬 −1.05〜−2.24%（48通りすべて p<0.05） |
| コロナ期の扱い：年ごとの水準を別に推定（年ダミー）して2010〜2025年を全部使う | 夏 +0.25%（p=0.53）、冬 −1.59%（p<0.001） |
| 2020〜2025年だけ（年ダミー） | 夏 −0.59%（p=0.46）、冬 −2.28%（p=0.003） |
| 2010〜2019年を年ダミーで | 夏 +0.63%（p=0.13）、冬 −1.42%（p<0.001） |

- 冬の関係は、どの条件でもはっきりしていました。
- 夏の関係は、2019年までを使う48通りではすべてプラスでしたが、大きさは0.4〜1.1%と幅があり、年ごとの水準を別に推定するとはっきりしなくなります。2020〜2025年だけではマイナス（はっきりしない）でした。月の平均気温では、暑さの影響は弱くしか見えません。

## 言えないこと

- **月の単位の粗さ**：熱中症のような暑さの影響は数日単位で起きます。月の平均気温と月の死亡数では、短い猛暑の影響は薄まります。ここでの「夏+0.6%」は、日単位で見た影響より小さく出ていると考えられます（推測）。
- **冬の原因**：寒い冬の死亡の多さが、気温そのものか、同じ時期に流行する感染症（インフルエンザなど）によるものかは分けていません。
- **2020年以降の超過**：期待値は2010〜2019年の傾きをのばしたものです。超過の原因（感染症、医療、高齢化の進み方の変化など）は、このデータでは分けられません。
- **期待値の作り方**：人口や年齢構成は直接入れず、時間のトレンドで代わりにしています。
- **気温の代表値**：47の気象台の値を人口で重みづけした近似で、人の住む場所の気温そのものではありません。
- **地域の差**：全国の集計値だけを使い、地域ごとの比較はしていません。
