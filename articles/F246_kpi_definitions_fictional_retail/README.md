## 問い
「売上は伸びているのに利益が減っている」会社で、分析担当は最初にどの KPI を、どう定義して見ればよいか。定義（全店か既存店か、客数とは何か）と粒度（日・週・月、1店か全社か）で、数字の見え方はどれだけ変わるか。

## データ
- 架空の会社「サンプルマート（架空）」：24店（都市・郊外・地方 各8、期間中に開店2・閉店2）、7部門、FY2022〜FY2025（2022年4月〜2026年3月）。店×日 32,325行、店×日×部門 226,275行、会員の月次 1,062行、ネットスーパーの日次 913行。
- 公開データ（新しい取得はなし。リポジトリ内の写し）：
  - 経済産業省「商業動態統計」スーパー販売額（F231 の data/）→ 売上の月ごとの形
  - 総務省「家計調査」品目別価格（F243 の data/）→ 一品単価の上がり方。**2025・2026年は統計がないので年+4%と置いた（仮定）**
  - 曜日・祝日の表（F233 の data/、内閣府「国民の祝日」をもとに作成）

## 手法
- **KPI ツリー**：営業利益 ← 粗利（廃棄後）・人件費・その他の経費。売上 ＝ 客数 × 買上点数 × 一品単価、粗利率（廃棄後）＝ 廃棄前 − 廃棄率、人件費 ＝ 人時 × 時給。
- **営業利益の橋渡し（ウォーターフォール）**：既存店の FY2024→FY2025 の営業利益の差を、売上・粗利率・時給・人時・その他の経費に分けた。
- **全店と既存店**：既存店の決め方（開店から12・13・24か月）を変えて、月の前年比の向きと差を比べた。
- **偶然の幅**：同じ設定で乱数の種だけ変えたデータを20回作り、本当の変化がないときの前年比の標準偏差 ×1.96 を、日・週・月 × 1店・全社（期間中ずっと営業の20店）で測った。
- **定義の比べ方**：客単価（合計の比・店の単純平均）、客数（レシート・会員のレシート・会員の延べ人数・来店頻度）、粗利率（廃棄前・後）、曜日・祝日の並びの補正。
- **KPI の採点**：店・月の営業利益の前年差との順位相関（同じ月・1〜3か月先）、偶然の幅、店で動かせるか（筆者の判断）。
- **SQL**：既存店の月次 KPI を SQL Server 互換の書き方で書き（`sql/kpi_monthly.sql`）、DuckDB で流して pandas と照合。

## 結果（seed 0、既存店 FY2024→FY2025）
- **売上 +2.9%（258.2億円）、営業利益 −3.2%（全店は売上 +4.4%、営業利益 −4.3%）。**
- 売上の伸びは**物価**：客数 ±0.0%、買上点数 −1.0%、一品単価 +4.0%。
- 粗利率（廃棄後）23.60%→23.43%（−0.16pt）。廃棄前は 25.78% で横ばいで、**廃棄率 +0.16pt（2.18%→2.35%）**がそのまま利益を削った。
- 営業利益の橋渡し（百万円）：売上 +172.5、粗利率 −41.8、**時給の上昇 −98.0**、人時 −0.3、その他の経費 −56.1、合計 −23.8。
- 人時粗利 +2.2%（3,296円）でも、時給 +4% で人件費率 +0.11pt。
- **客数の定義**：レシート −0.0% に対して、会員の延べ人数は **+4.2%**（会員比率 +2.5pt）。来店頻度は −0.2%（都市 +0.9%、郊外 −0.3%、地方 −1.4%）。「客数」をどちらで書くかで、報告の向きが逆になる。
- **全店と既存店**：36か月のうち客数の前年比の向きが逆の月が3か月、差は最大 3.4pt。
- **偶然の幅**（本当の変化がないときの前年比のぶれ、±1.96σ）：1店・日の売上 ±20.1%、1店・週 ±8.9%、1店・月 ±6.4%、全社・月 ±1.3%。**1店・月の営業利益は ±205%**、全社・月でも ±11.5%。
- **曜日・祝日の並び**：効果が1pt以上の月が36か月中5か月、補正で前年比の向きが変わる月が5か月、最大 3.4pt。
- **採点**：営業利益との相関が高いのは人時粗利（0.97）・売上（0.94）・人件費率（−0.94）・客数（0.91）。1〜3か月先との相関はどれも 0.26 以下で、**先に動く KPI は見つからなかった**。

### 決めた KPI（v1）
- KGI：営業利益（全社・月）
- 主要：既存店売上の前年比（曜日補正つき）を、客数・買上点数・一品単価に分けて見る／来店頻度（会員）／粗利率（廃棄後）と廃棄率を並べて／人時粗利
- 補助：人件費率
- 店の評価に営業利益は使わない（1店・月では偶然の幅が大きすぎる）。

## 頑健性
1. **既存店の決め方**：12・13・24か月で、客数の向きが逆の月はどれも3か月、差の平均 0.55〜0.61pt。結論は変わらない。
2. **乱数の種**：20回作り直して偶然の幅を測った（結果の数字は seed 0。偶然の幅はそのばらつき）。
3. **客単価の計算の仕方**：合計の比 +2.96%、店の単純平均 +3.00%、店の前年比の平均 +3.00%。この会社では差は小さい。
4. **曜日・祝日の補正**：補正の前後で比べた（D_calendar_adjust.csv）。
5. **SQL 照合**：DuckDB で SQL を流し、36か月の既存店の売上・客数の前年比が pandas と一致（差は最大 5.6×10⁻⁸、既存店の数は一致）。

## 言えないこと
- 数字は架空の会社の合成データで、**結果の多くは合成の設定（物価 +4%、時給 +4%、地方の廃棄の悪化など）から来ている**。実在のスーパーの利益率・廃棄率・人時の水準や、地域の傾向を示すものではない。
- 2025・2026年の物価は仮定（年+4%）。
- 「店で動かせるか」と KPI の選び方は筆者の判断。相関は因果ではない。
- 偶然の幅は、この合成の乱数の置き方（ポアソンなど）での大きさ。実際の店のぶれは、天気・競合・欠品などでもっと大きいかもしれない（推測）。
- 目標値の決め方、ネットスーパーの KPI、部門別の細かい KPI はこの回では決めていない。
