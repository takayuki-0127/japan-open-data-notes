# サンプルマート（架空）KPI 定義書 v1

分析担当として最初に作る「数字の辞書」。**会社・数字は架空（合成データ）。** 会社の設定は `company_spec.md`、一覧表は `../sheet/kpi_sheet.html`（図6）。

## 0. 共通の決めごと
| 項目 | 決めごと | 理由 |
|---|---|---|
| 既存店 | その月の月初で開店から13か月以上、かつその月の末日まで営業している店 | 新店・閉店で全店の前年比が動くのを外す。12・24か月にしても結果はほぼ同じ（差の平均 0.55〜0.61pt） |
| 前年比の比べ方 | 当月の既存店と、前年同月の**同じ店**の合計どうしの比 | 店ごとの比の平均は、小さな店の揺れに引っぱられる |
| 比の計算 | 合計の比（例：客単価 ＝ 売上の合計 ÷ レシートの合計） | 店の客単価の単純平均とは別の数字になる（この会社では +2.96% と +3.00%） |
| 日・週の前年比 | 日は364日前、週は52週前（同じ曜日どうし） | 曜日がずれると、土曜1日で数%動く |
| 曜日・祝日の補正 | 月の前年比は「曜日・祝日の並びの効果」を引いた値も並べる | 並びの効果が1pt以上の月が36か月中5か月、最大3.4pt |
| 偶然の幅 | 本当の変化がなくても出る前年比のぶれ（±1.96σ） | 幅より小さい動きで評価・原因探しをしない |
| 金額 | 円、税抜きのつもり。営業利益 ＝ 粗利（廃棄後）− 人件費 − その他の経費 | |
| ネットスーパー | 店の KPI に入れない。別の KPI（後の回） | 店の評価が配送の都合で動かないように |

## 1. KPI ツリー
```
営業利益（KGI）
├─ 粗利（廃棄後）
│   ├─ 売上
│   │   ├─ 客数（レシート枚数）── 会員：来店した会員の人数 × 来店頻度
│   │   └─ 客単価 ＝ 買上点数 × 一品単価
│   └─ 粗利率（廃棄後）＝ 粗利率（廃棄前）− 廃棄率
├─ 人件費 ＝ 人時 × 時給   →  店の評価は 人時粗利 ＝ 粗利（廃棄後）÷ 人時
└─ その他の経費
```

## 2. KPI ごとの定義
各 KPI：ID／名前／計算式／見る粒度／頻度／担当（役割）／元のテーブル／目標の考え方／注意。担当は役割の名前で、人の名前ではない。

### K00 営業利益（KGI）
- 計算式：Σ gross_profit − Σ labor_cost − Σ other_cost
- 粒度・頻度：全社・月（四半期でも確認）／月次／経営企画
- 元：fact_store_day
- 目標の考え方：年度予算。月の目標は前年の月の形で配る
- 注意：**1店・月の前年比は偶然の幅が ±205%**（営業利益が売上の3%前後と薄いため）。店の評価には使わず、K08 人時粗利と K06・K07 を使う。全社・月でも ±11.5%。

### K01 既存店売上（前年比）
- 計算式：Σ sales（当月・既存店）÷ Σ sales（前年同月・同じ店）− 1
- 粒度・頻度：全社・月（週も見る）／週次・月次／営業部
- 目標の考え方：物価の見込み（この会社では +4%、仮定）を足した値と、引いた「量」の両方
- 注意：曜日・祝日の並びを補正した値を並べる。物価で上がる分を含むので、K02〜K04 に分けて読む。1店・月の偶然の幅 ±6.4%、全社・月 ±1.3%。

### K02 客数（レシート枚数）
- 計算式：Σ receipts
- 粒度・頻度：店・月（週も見る）／週次／店長
- 注意：**会員の延べ人数とは別物**。会員比率が上がると、レシート枚数が同じでも会員の人数は増える（この会社：レシート −0.0%、会員の延べ人数 +4.2%）。報告で「客数」と書くときはどちらかを明記する。

### K03 買上点数
- 計算式：Σ items ÷ Σ receipts
- 粒度・頻度：店・月／週次／店長・部門担当
- 注意：客単価 ＝ 買上点数 × 一品単価。客単価だけ見ると、物価で上がった分と、点数が減った分が打ち消し合って見えない（この会社：客単価 +3.0% ＝ 点数 −1.0% × 単価 +4.0%）。

### K04 一品単価
- 計算式：Σ sales ÷ Σ items
- 粒度・頻度：全社・月／月次／商品部
- 注意：物価の影響が大きく、店では動かしにくい（店の評価には使わない）。

### K05 来店頻度（会員）
- 計算式：Σ member_receipts ÷ Σ active_members（月）
- 粒度・頻度：店・月／月次／販促担当
- 元：fact_member_month
- 注意：会員だけの数字。会員比率が変わると、全体の客の動きの代わりにならない。地域で向きが違う（都市 +0.9%、郊外 −0.3%、地方 −1.4%）。

### K06 粗利率（廃棄後）
- 計算式：Σ gross_profit ÷ Σ sales（gross_profit ＝ 廃棄前の粗利 − 廃棄）
- 粒度・頻度：店・部門・月／月次／部門担当
- 元：fact_store_day_category
- 注意：**廃棄前の粗利率だけだと、廃棄の悪化が見えない**（この会社：廃棄前 25.78% で横ばい、廃棄後 23.60%→23.43%）。

### K07 廃棄率
- 計算式：Σ waste ÷ Σ sales
- 粒度・頻度：店・部門・週／週次／部門担当
- 注意：上がると悪い。値引きで廃棄を減らすと粗利率が下がるので、K06 と並べて見る。店によって 1.2%〜4.2% と差が大きい。1店・月の偶然の幅 ±0.13pt。

### K08 人時粗利
- 計算式：Σ gross_profit ÷ Σ labor_hours
- 粒度・頻度：店・月／月次／店長
- 注意：時給が上がる年は、人時粗利が +2% でも利益は減る（この会社：時給 +4%）。営業利益との相関が高く（0.97）、店で動かせるので、店の利益の代わりに使う。

### K09 人件費率（補助）
- 計算式：Σ labor_cost ÷ Σ sales
- 粒度・頻度：全社・月／月次／経営企画
- 注意：時給の改定は店では動かせない。店の評価には K08 を使う。
