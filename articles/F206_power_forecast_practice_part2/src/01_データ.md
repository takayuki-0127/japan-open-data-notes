# 01 データ

新しい取得はしていない。F22・F157・F205 のデータを使う。

| ファイル | 中身 | もと |
|---|---|---|
| data/area_pred_tokyo_2025_26.csv.gz | 東京エリアの1時間ごとの実績と予測（2025年10月〜2026年9月。毎週・毎月・固定・1週間前） | F157 の予測（F205 の data） |
| data/area_pred_kansai_2025_26.csv.gz | 関西エリアの同じもの | 同上 |
| data/hourly_tokyo_2024_26.csv.gz | 東京エリアの1時間ごとの需要と日ごとの気温など（2024年4月〜2026年9月） | F22 の data（東京電力パワーグリッド「エリア需給実績データ」、気象庁「過去の気象データ検索」東京） |
| data/hourly_kansai_2024_26.csv.gz | 関西エリアの同じもの | F22 の data（関西電力送配電「エリアの需給実績」、気象庁 大阪） |

需要の単位は MW（1時間の平均）。ダッシュボードでは10で割って万kW で表示している。

全国10エリアの需要は、この作業環境から各送配電会社のサイトに直接つながらず、取得していない（「言えないこと」参照）。
