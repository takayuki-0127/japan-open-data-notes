# F206 電力需要の予測を実務で回す（後編）：エリアと合計のそろえ方・見せ方・1年の見張り

## 前編のまとめ（3行）

- 同じ9つの予測でも、何で測るかで「いちばん」が入れ替わる。近いモデルどうしの差は偶然の幅の中だった
- 足りない値段が余る値段の9倍なら、点予測に約3%上乗せするだけで外れの値段は約4割減った（値段の比は例示）
- ずれに気づくには、外れの大きさ（MAPE）より、ずれの向きを見るほうが数倍早かった

## 問い

1. エリアごとの予測と、合計の予測を別々に作ると、数字が合わない。どうそろえるのがよいか（ボトムアップ・トップダウン・OLS・WLS・MinT）
2. 1日の電力量は、直接当てるのと、24時間の予測を足すのと、どちらがよいか（時間の階層）
3. 予測をどう見せるか。区間（80%・95%）は表示どおりに当たっているか。ダッシュボードには何を載せるか
4. 1年回すと、見張りのアラートはいつ鳴るか。実務のチェックリストにすると何か

## データ

- 東京・関西エリアの1時間ごとの需要の実績と、F157 の予測（2025年10月〜2026年9月）。予測は F157 の「毎週学習し直す LightGBM」を主に使い、「毎月」「固定」で確かめた
- 合計（東京＋関西）を直接当てる予測は、このフォルダで新しく作った（LightGBM、毎月学習し直し、2024年4月から学習。説明に使ったのは時刻・曜日・月・休日・東京と大阪の気温・24時間前と1週間前の合計の需要・前日の平均）
- 新しい取得はなし。詳しくは src/01_データ.md

## 手法

- **整合（3系列：合計＝東京＋関西）**：1日ごとに、その日より前の90日の外れ（実績−予測）だけを使って重みを決め、24時間分をそろえる（外れを知ってからそろえることはしない）
  - そろえない／下から足す（BU）／上から割る（TD：直近28日の時刻ごとの東京の割合で割る）／等しい重み（OLS）／外れの分散で重み（WLS）／外れの相関も使う（MinT、相関を0に縮める Schäfer–Strimmer 型）
- **時間の階層**：1日の電力量を直接当てる LightGBM（毎月学習し直し）と、24時間の予測の合計、その2つをそろえたもの（数で重み／外れの分散で重み）を比べた
- **区間**：その日より前の90日の「実績÷予測−1」の時刻ごとの分位点（10・90%、2.5・97.5%）を予測にかけて作る
- **見張り**：F205 のおすすめの例（ずれの7日平均が±1.5%を超えたら）を、東京の「毎週」の予測に1年間当てた
- **評価期間**：2026年1月1日〜9月30日（2025年10〜12月は外れの履歴をためる期間）。見張りは2025年10月から
- **差の確かさ**：週ごとのブロック・ブートストラップ（2,000回）。乱数の種は 206

## 結果

### 1. そろえる前は、合計と内訳が合わない

合計を直接当てた予測と「東京の予測＋関西の予測」の差は、1時間ごとに平均で合計の1.8%、上位5%の時間では4.7%以上あった。日平均で見ると −6.0%〜+6.1%。

### 2. そろえ方ごとの外れ（1時間ごとの MAPE、%）

| 方法 | 合計 | 東京 | 関西 |
|---|---|---|---|
| そろえない | 2.77 | 2.31 | 2.71 |
| 下から足す（BU） | **2.08** | 2.31 | 2.71 |
| 上から割る（TD） | 2.77 | 3.13 | 3.76 |
| 等しい重み（OLS） | 2.42 | 2.50 | 3.28 |
| 外れの分散で重み（WLS） | 2.15 | 2.38 | 2.75 |
| 外れの相関も使う（MinT） | **2.09** | 2.31 | 2.74 |

- 合計は、直接当てる（2.77%）より、東京と関西を足す（2.08%）ほうが外れが小さかった。東京と関西の外れの相関は0.39で、足すと一部が打ち消し合う
- MinT と BU の差は、合計 +0.007ポイント（95%区間 −0.002〜+0.016）、東京 +0.002（−0.005〜+0.009）、関西 +0.020（−0.021〜+0.055）。ほぼ同じ
- 上から割る（TD）と等しい重み（OLS）は、外れの大きい合計の予測を内訳に流し込むので、東京・関西を悪くした
- MinT の縮小の強さ（相関を0に寄せる度合い）は平均0.004で、相関はほぼそのまま使われていた

### 3. 1日の電力量（MAPE、%）

| 方法 | 東京 | 関西 |
|---|---|---|
| 1日の量を直接当てる | 2.22 | 2.32 |
| 24時間の予測を足す | **1.37** | 1.89 |
| そろえる（数で重み） | 1.62 | 1.91 |
| そろえる（外れの分散で重み） | 1.38 | **1.87** |

### 4. 区間は表示どおりに当たったか（2026年1〜9月）

| エリア | 外れの履歴 | 80%区間に入った割合 | 95%区間に入った割合 | 80%区間の幅 |
|---|---|---|---|---|
| 東京 | 30日 | 75.3% | 90.3% | 7.0% |
| 東京 | 90日 | 76.6% | 91.4% | 7.0% |
| 東京 | 180日 | 77.2% | 92.3% | 6.9% |
| 関西 | 90日 | 76.8% | 91.7% | 8.3% |

- 月ごと（東京・90日）：3〜6月は80%区間に82〜87%入ったが、1月67%、7月72%、8月63%。95%区間も8月は81%
- 1日のピークの時間に、実績が95%区間の上の端を超えなかった割合は90.8%

### 5. 見張り（東京、2025年10月〜2026年9月）

ずれの7日平均が±1.5%を超えたのは9回・28日。年末（12/28〜31）、1月の連休前後、2月の連休（2/11〜14）、3月上旬、7月中旬（7/12〜16）、お盆（8/12〜17、最大3.2%）など。

`dashboard/dashboard_sample.html`（外部ファイルを使わない静的な HTML）。2026年7月22日（2026年度上期で需要がいちばん大きかった日）の前日24時に出したとして、次の4つを1画面に置いた。

- 24時間の予測と80%・95%区間、準備の目安（ピーク予測＋3.3%：F205 の「足りないが余るの9倍」の例）
- 直近7日の MAPE と、ずれの7日平均（見張り）
- 読み方のメモ（どうなったら何をするか）

## 1年回して分かったこと（実務のチェックリスト）

1. 合計は別に当てず、エリアの予測を足して出す。そろえたいなら MinT か WLS。上から割る・等しい重みは内訳を悪くする
2. 1日の量も、24時間の予測を足して出す。直接当てるより外れが小さかった
3. 区間は「表示どおりに入っているか」を月ごとに確かめる。季節の変わり目と真夏・真冬は狭すぎた
4. 見張りは、外れの向き（ずれの7日平均）で見る。鳴った日の多くは連休・年末年始・お盆の前後
5. 1画面に「予測・区間・準備の目安・見張り・読み方」を置く。値段の比は関係者で決めて書いておく
6. 比べる前に、締め切り・評価期間・指標をそろえる（前編）

## 確かめたこと（頑健性）

- 外れの履歴の長さ（30・90・180日）：MinT の合計 2.08〜2.10%、BU との差 +0.007〜+0.018
- エリアの予測を「毎月」「固定」に：MinT と BU の差は合計 +0.008・+0.012（「固定」は区間が0をまたがず、わずかに MinT が悪い）
- 合計の予測を弱くする（気温なし、MAPE 4.06%）：BU 2.08%、MinT 2.06%（差 −0.015、−0.033〜+0.003）。MinT は合計の予測の重みを自動で下げた。OLS は 3.19%、TD は 4.06% に悪化
- 季節（1〜6月／7〜9月）：MinT と BU の順はどちらも同じ。7〜9月はどの方法も外れが大きい
- 区間：外れの履歴（30・90・180日）と関西で、80%区間の当たりは74〜78%、95%区間は90〜93%

## 言えないこと

- **エリアは2つだけ**：全国10エリアの需要は、この作業環境から各送配電会社のサイトにつながらず取得していない。10エリアになると、MinT の相関の推定は難しくなり、結果が変わる可能性がある
- **合計の予測は1つの作り方だけ**：合計を直接当てる予測は、東京・関西より学習期間が短い（2024年4月から）。もっと良い合計の予測なら、MinT が BU より良くなる可能性がある
- **区間の作り方は1つだけ**：「直近90日の外れの分位点」は季節の変わり目に追いつかない。去年の同じ季節の外れを足すなどの方法は試していない
- **値段は例示**：準備の目安（＋3.3%）は、前編で置いた「足りないが余るの9倍」の例。実在の会社の費用ではない
- **ダッシュボードは見本**：実際の画面ではなく、公開データで作った静的な見本。誰が見て、何を決めるかによって、載せるものは変わる
- **見張りのアラートの原因は確かめていない**：連休・年末年始・お盆と重なったが、それが原因かは調べていない（推測）
- **1年だけの結果**：2025年10月〜2026年9月の1年。別の年では違う可能性がある
