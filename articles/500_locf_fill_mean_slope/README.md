# 500 抜けた値を「前の値」で埋めると、平均と傾きはどれだけずれるのか（手法の解説）

架空の日次データ（365日、1日+0.05の伸び、曜日の波、前の日に似た揺れ）で、抜け方5通り×扱い方4通りの、1年の平均・傾き・日ごとの変化の大きさのずれを比べたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A500 | 前の値で埋める（LOCF）と、平均と傾きはどれだけずれるか | 抜け方：ばらばら・7日まとめて・後ろほど・大きい値ほど（10%と30%）、最後の60日。扱い方：抜いたまま・前の値（pandas ffill）・直線（interpolate）・曜日の平均。各2,000回。傾きは直線の当てはめ | `src/a500_fill_missing.py` |

## 置いたこと（架空）
- 値＝100＋0.05×日＋8×sin(2π×日/7)＋揺れ（前の日の0.6倍＋標準偏差4の新しい揺れ）。1年の平均は約109
- 最初の日は抜けない

## 主な結果（30%抜けたとき、最後の60日は16%）
| 抜け方 | 平均のずれ（抜いたまま／前の値／直線） | 傾きの誤差 RMSE（抜いたまま／前の値／直線） |
|---|---|---|
| ばらばら | −0.01／−0.02／0.00 | 5.0%／5.4%／4.1% |
| 7日まとめて | −0.01／−0.08／0.00 | 5.7%／13.2%／10.2% |
| 後ろほど | −1.30／−0.02／0.00 | 5.6%／7.1%／6.2% |
| 大きい値ほど | −4.31／−2.55／−2.52 | 27.5%／27.7%／27.1% |
| 最後の60日 | −1.44／+0.33／+0.33 | 8.3%／23.8%／23.8% |

- 最後の60日は、直線で埋めてもつなぐ相手がないので、前の値と同じになる
- 曜日の平均で埋めると、どの抜け方でも傾きが30〜52%小さく出る（1年の平均で埋めるため）
- 日ごとの変化の標準偏差（ばらばら30%）：前の値+3.8%、直線−13.9%、曜日の平均+13.5%。7日まとめて30%では前の値−14.8%、直線−18.6%

## 動かし方
```
pip install -r requirements.txt
cd src && python a500_fill_missing.py     # 1分ほど
```

## データ
- `data/example_later_missing_30pct.csv`：後ろほど抜ける（30%）例の本当の値・抜け・3つの埋め方

## 注意（言えないこと）
- 架空の日次データ。ずれは波や揺れの大きさ・傾き・抜け方で決まる（数字は置いた前提しだい）
- 抜け方は5通りだけ
- どの埋め方を使うべきかを言うものではない
- 欠けた値を埋める方法を公的データで比べた例は F41・F179、月が抜けたときの前年同月比は232で扱った
