# 268 差の差・回帰不連続・合成コントロールを、どう選んできたか（④ 振り返り R009）

このシリーズで効果を測る手法を、どんな状況で選んだかを、記事ごとの README から数えたフォルダです。最低賃金の記事を手法ごとにまとめ直した [F121](https://github.com/takayuki-0127/japan-open-data-notes/tree/main/articles/F121_minwage_methods_review)、推定の方法で答えがどこまで変わるかを比べた [F201](https://github.com/takayuki-0127/japan-open-data-notes/tree/main/articles/F201_minimum_wage_series_part1) は1つの題材を詳しく扱っています。ここでは題材をまたいで、状況と手法と確かめ方を並べました。

## 問い

- どんな状況のとき、どの手法を選んだか
- 手法ごとに、プラセボや事前の確かめを書いていたか
- 確かめた後に、推定はどうなったか

## 手法

| 手順 | 中身 |
|---|---|
| README の重複を除く | 267 と同じ（528 → 463本） |
| 手法を拾う | 差の差・イベントスタディ・合成コントロール（Synthetic DID を含む）・回帰不連続・操作変数・中断時系列とベイズ構造時系列の名前を、README に2回以上書いた記事を拾った。題名にあるか5回以上書いた記事を「主な手法として使った」とした |
| 確かめ方 | 「プラセボ」「並べ替え」と、「事前の差・傾き・当てはまり」「計画前」「処置前」「第1段階」「帯域」などの言葉 |
| 実例 | 10本の状況・手法・主な推定・確かめ方・確かめた後を README から手で写した（`data/cases.csv`） |

## 主な結果

- 手法の名前を2回以上書いた記事は37本、主な手法として使った記事は23本（1本に複数の手法がある記事は8本）
- 主な手法として使った23本のうち21本が、プラセボか事前の確かめを書いていた
- 手法ごと（主な手法の記事のうち確かめを書いた本数／主な手法の記事／2回以上書いた記事）：差の差 13/13/22、合成コントロール 7/7/9、操作変数 3/4/6、イベントスタディ 3/3/4、中断時系列・ベイズ構造時系列 2/3/4、回帰不連続 2/2/2（図3、`results/method_counts.csv`）
- 37本のうち43%は「0と区別できない」「0をまたぐ」などと書いていた
- 状況から手法を選ぶ流れ（図1、記録からの整理）：比べる相手がいない → 対照を複数並べる・中断時系列（F263・F240）、1つの地域だけ → 合成コントロール（029・F29）、始まった年がずれる → 段階的な差の差（F145）、境目がある → 回帰不連続（F31・F88）、外から決まる変動 → 操作変数（F46。弱ければ使わない：F234）
- 確かめた後（図2）：F01 は県ごとの傾きを入れると +0.41 → +0.00 ポイント、F14 は規模をそろえると +0.74 → +0.22 ポイント（0をまたぐ）。F145 は事前の差 ±0.6% 以内で −3.5% が残った

## 言えないこと

- 手法と確かめ方は言葉で拾った。名前を書いただけの記事や、別の言い方で確かめた記事で、取りこぼしや数え過ぎがある
- 図1の流れは、記録を見て後から整理したもの。記事を作ったときにこの順で考えていたとは限らない（推測）
- 確かめを書いたことは、推定が正しいことを示さない
