# 1104 条件の数を増やして繰り返しを減らすと、何を見落とすのか？（試作と実験）

試し塗りの板の枚数が決まっているとき、たくさんの条件を1枚ずつ試すか、少ない条件を何枚もくり返して試すかを選ぶことになります。条件を増やせば良い条件を候補に入れやすくなりますが、1条件あたりの枚数が減ると、その条件の板ごとのばらつき（安定さ）が見えなくなります。平均が良くても板ごとにむらが大きく振れる条件は、たまたま1枚だけ良く塗れると、いちばん良く見えてしまいます。**ここでは、作成者が乱数で作った架空の塗装工房の試し塗り（候補の条件24通りそれぞれに、本当の平均のむらと板ごとのばらつきを作成者が置いたもの）で、板24枚を「条件の数×1条件あたりの枚数」に分ける7通りの割り方と、2段に分けて試す割り方を比べ、見かけの平均のむらがいちばん小さい条件を選んだときに、その条件の本当の手直しの割合がどれだけになるかを数えました。ばらつきが条件で同じと置いた対照と、置き方を変えた54通りの確かめも行いました。**

例の工房と条件は架空のもので、実在の会社・塗料の名前は使っていません。むらの点は作成者が置いた架空の物差しで、塗装の品質の基準を表すものではありません。

関連する記事：801「星4.8（5件）と星4.3（500件）は、どちらが良い店か？」は、件数の少ない店ほど星の平均が振れて上位に集まることを扱っています。この記事は、同じ「少ない数で振れたものが選ばれる」しくみを、試作で条件の数と繰り返しの数をどう割り振るかに絞り、選ばれやすいのが「ばらつきの大きい条件」である点を数えます。657「交互作用を見つけるには、主効果を見つけるときの何倍の件数が要るのか」は、組み合わせの効き方の違いを見つけるのに要る件数を扱っています。同じ企画の 1111「条件の刻み（5度ごと・10度ごと）で、良い条件の見つかり方はどう変わるのか？」は、温度のように続いた1つの条件で、決まった枚数を刻みの細かさと1温度あたりの枚数にどう分けるか（どの温度も板のぶれは同じ）を、1106「両端の2つの条件だけを試すと、真ん中の山を見落とすのか？」は両端だけを試すか真ん中も入れるかを、1108「良い方へ少しずつ条件を動かしていくと、いちばん良い所に着くのか？」は着いた所の見かけの点数が本当より高く出ることを扱っています。この記事は、候補どうしの関係を使わない24通りの候補で、条件ごとにばらつきが違うときに絞ります。

## 主な結果

### 割り方ごとの、選んだ条件（基本の置き方、4,000回の平均、`results/by_design.csv`）
| 割り方 | 選んだ条件の本当の手直しの割合 | 試し塗りの板で見えた手直しの割合 | 見かけの平均が本当より良く見えた分（むらの点） | ばらつきの大きい条件を選んだ割合 | 候補24通りの中で本当にいちばん手直しの少ない条件だった割合 |
|---|---|---|---|---|---|
| 2通り×12枚 | 9.01% | 8.17% | 0.196 | 23.77% | 7.62% |
| 3通り×8枚 | 5.72% | 4.44% | 0.406 | 25.15% | 9.78% |
| 4通り×6枚 | 4.29% | 2.73% | 0.56 | 24.57% | 11.88% |
| 6通り×4枚 | **3.59%** | 1.24% | 1.146 | 27.35% | 14.65% |
| 8通り×3枚 | 3.67% | 0.89% | 1.66 | 31.3% | 16.05% |
| 12通り×2枚 | 4.19% | 0.3% | 2.961 | 35.65% | 16.7% |
| 24通り×1枚 | **6.4%** | 0% | 6.803 | **47.2%** | 13.98% |
| 12通り×1枚→良い3通り×4枚 | 2.26% | 0.81% | 1.044 | 26.52% | 20.65% |

- **24通りを1枚ずつ試すと、ばらつきの大きい条件を47.2%の回で選び（でたらめなら25%）、選んだ条件の本当の手直しは6.4%だった**。6通り×4枚の3.59%の1.783倍
- 24通り×1枚で選んだ条件の本当の平均のむらは43.245で、6通り×4枚（44.217）より良かった。平均では良い条件を選べていて、見落としたのは板ごとのばらつきだった
- 1枚ずつでは、選んだ条件の板は1枚だけで、それがいちばんむらの小さい板なので、板で見えた手直しは0%になる（作りどおりに近い）。本当は6.4%だった。見かけの平均は本当より6.803点良く見えた
- 2通り×12枚では、ばらつきはよく見えるが（見かけの手直し8.17%と本当の9.01%が近い）、候補が2つしかないため良い条件を候補に入れられず、手直しは9.01%といちばん多かった
- 2枚以上塗った条件でも、選んだ条件の板から出したばらつきは本当より小さく出やすかった。本当の半分より小さく出た割合は、6通り×4枚で14.17%、12通り×2枚で37.65%（`results/a1104_main.json` の pick_sd_under_half）
- 候補24通りの中のいちばん良い条件の本当の手直しは平均0.004%、候補全体の平均は21.74%だった。本当の平均のむらがいちばん小さい条件を選んでも手直しは0.8%で、それが手直しのいちばん少ない条件だったのは29.48%だった（平均だけでは手直しの少なさは決まらない）

### 対照：ばらつきを条件で同じと置くと（4,000回、`results/control_same_sd.csv`）
| 割り方 | 選んだ条件の本当の手直しの割合 | 見かけの平均が本当より良く見えた分 |
|---|---|---|
| 2通り×12枚 | 8.6% | 0.147 |
| 6通り×4枚 | 1.92% | 0.897 |
| 12通り×2枚 | 0.98% | 2.214 |
| 24通り×1枚 | **0.93%** | 4.891 |

- **ばらつきが条件で同じなら、24通りを1枚ずつ試すのが手直しのいちばん少ない割り方だった**。見かけが良く見える分（4.891点）は残るが、選ぶ順は変わらないため
- 基本の置き方との違いは、条件ごとにばらつきが違うかどうかだけ。条件の数を増やして繰り返しを減らすと見落とすのは、条件ごとのばらつきの違いだった

### 確かめ：置き方を変えると（54通り、各1,000回、`results/grid.csv`）
| | 値 |
|---|---|
| 手直しがいちばん少なかった割り方（条件の数）：ばらつきが条件で同じ18通り | 8通り：2、12通り：7、24通り：9 |
| 同：ばらつきが条件で違う36通り | 3通り：5、4通り：7、6通り：12、8通り：6、12通り：4、24通り：2 |
| 24通り×1枚が6通り×4枚より手直しが多かった置き方 | ばらつきが違う36通り中31通り、同じ18通り中4通り |
| 24通り×1枚の手直し÷いちばん少なかった割り方の手直し（ばらつきが違う36通り） | 1〜4.051倍 |
| ばらつきの大きい条件を選んだ割合（ばらつきが違う36通り） | 24通り×1枚：24.6〜81.9%、2通り×12枚：23.1〜27.2% |
| 24通り×1枚の見かけが本当より良く見えた分 | 0.335〜30.475点 |

- **いちばん良い割り方は、置き方で3通り〜24通りまで動いた**。ばらつきが条件で同じなら12通りか24通り（18通り中16通り）、違うなら3〜8通りに寄った（36通り中30通り）
- ばらつきの大きい条件を選びやすくなるのは、ばらつきが違う36通り中35通りで、24通り×1枚のほうが2通り×12枚より多かった

## 動かし方
```
pip install -r requirements.txt
cd src && python a1104_more_conditions.py
```
数秒で終わります。`data/` の2つのファイルもこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の9ファイルがバイト単位で一致した（cmp、約2.5秒）
- ばらつきを条件で同じと置くと、ばらつきの大きい条件を選ぶ割合は数えられない（すべて同じ）ので、その場合は数えないようにした
- 図3枚を開き、日本語・重なり・軸（棒は0から）を確かめた

## データ
- `data/conditions_one_draw.csv`：1回分の候補24通り（condition・true_mean（本当の平均のむら）・true_sd（板ごとのばらつき）・true_fail_share（本当の手直しの割合））
- `data/pieces_one_draw.csv`：その候補で、24通り×1枚と6通り×4枚を塗ったときの板（design・condition・piece・unevenness（むらの点））
- `results/a1104_main.json`：主な結果すべて（置き方を変えた範囲も入れた）
- `results/by_design.csv`：割り方ごとの結果（基本の置き方）
- `results/control_same_sd.csv`：ばらつきを条件で同じと置いた対照
- `results/grid.csv`：54通りの確かめ

## 注意（言えないこと）
- 架空のデータです。候補の条件の数、平均とばらつきの分布、手直しの線（55）は作成者が置いたもので、結果はこれで決まります。いちばん良い割り方は、置き方で3通り〜24通りまで動きました
- 条件は24通りの「候補」として扱い、薄め方・距離・時間のそれぞれの効き方（組み合わせの形）は使っていません。条件の形を使って当てはめる試し方は入れていません
- 選び方は「見かけの平均がいちばん小さい条件」だけです。ばらつきも見て選ぶ選び方は比べていません
- 実際の塗装の品質や、どの割り方で試すべきかを言うものではありません。この記事は、置いた条件のもとで、割り方によって何が見えなくなるかを数えただけです
