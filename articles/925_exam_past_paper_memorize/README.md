# 925 過去問の点が上がったのは、実力か問題を覚えたからか？（試験と点数）

資格試験の勉強で過去問をくり返し解くと、点は上がっていきます。けれども、上がった理由は2つまざります。初めて見る問題でも解ける力が伸びた分と、一度見た問題の答えを覚えた分です。本番は初めて見る問題なので、効くのは前の分だけです。**ここでは、作成者が乱数で作った架空の資格試験の過去問と、それを解く架空の200人（実力の伸びと答えを覚える確率を作成者が置いたもの）で、過去問の点の伸びのうち、実力の伸びと覚えた分がそれぞれどれだけかを数え、「初めて見た問題だけの点」で本当の伸びを読めるかを確かめました。**

1回の試験の点が実力からどれだけ振れるかは関連する記事 926、2回目の受験の合格率が高い理由は 932 で扱っています。この記事は、同じ過去問をくり返し解いたときの点の伸びの中身に絞ります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A925 | 過去問の点の伸びのうち、本当の実力の伸びはどれだけで、問題を覚えた分はどれだけか。過去問の数と覚えやすさでどう変わるか。初めて見た問題だけの点で、本当の伸びを読めるか | 架空の資格試験の過去問300問（難しさは平均0・標準偏差1の正規分布）。架空の200人が、週に1回、過去問から40問を選んで（同じ週の中では重ならない）解き、答え合わせをする。これを12週。最初の実力は平均−0.5・標準偏差0.7の正規分布（難しさと同じ物差し）。実力は週ごとに一定の幅で伸び、その幅は人ごとに0〜0.1の一様分布（平均0.05）。答え合わせをした問題は、人ごとの確率（0.1〜0.5の一様分布、平均0.3）で答えを覚え、忘れない。覚えた問題は必ず正解、それ以外は 1÷(1+exp(−1.7×(実力−難しさ))) の確率で正解。本当の実力は、別に作った初めて見る問題2,000問の正答率の見込み×100。本番は、その2,000問から選んだ40問。例の200人のほか、200人を作り直して100回数えた。確かめとして、過去問の数（100・300・1,000・3,000問）×覚える確率の平均（0・0.15・0.3・0.5。それぞれ±0.2の一様分布、0未満は0）×実力の伸びの平均（週0・0.05・0.1）の48通りを、各200人×10回で数えた。seed 925 | `src/a925_past_paper.py` |

## 主な結果

### 例の200人（過去問300問・覚える確率 平均0.3・伸び 週0.05）
| | 1週目 | 12週目 | 伸び |
|---|---|---|---|
| 過去問の点（40問） | 36.65点 | 68.0点 | **+31.3点** |
| 本当の実力（初めて見る問題の正答率） | 38.5点 | 51.8点 | **+13.3点** |
| 過去問のうち、初めて見た問題だけの点 | 36.65点 | 51.5点 | +14.9点 |

- 過去問の点の伸び31.3点のうち、本当の実力の伸びは13.3点で、残りの18.0点（**57.5%**）は答えを覚えた分だった
- 12週目の40問のうち、平均13.8問（34.4%）はすでに答えを覚えた問題だった。初めて見た問題は平均8.5問しか残っていなかった
- 12週目の過去問の点（68.0点）は、本当の実力（51.8点）より16.1点高かった。初めて見る40問の本番の平均は46.4点で、過去問の点より21.6点低かった（本番の40問がたまたま少し難しかった分もふくむ）
- 初めて見た問題だけの点は、12週目で本当の実力との差が平均−0.3点だった。くり返し出た問題を除けば、本当の実力に近い点が読めた
- 1週目でも過去問の点（36.65点）は本当の実力（38.5点）より1.9点低い。過去問300問の難しさが、たまたま初めて見る問題より少し難しかったため

| 1人ずつ（200人）で | 値 |
|---|---|
| 過去問の点の伸びと、本当の実力の伸びの相関 | 0.35 |
| 初めて見た問題だけの点の伸びと、本当の実力の伸びの相関 | 0.38 |
| 過去問の点の伸びと、答えを覚える確率の相関 | 0.44 |
| 過去問の伸びの上位20%のうち、本当の伸びでも上位20%だった人 | 40.0% |

- 過去問の伸びが大きい人は、実力が伸びた人というより、答えを覚えやすい人だった。1人ずつでは、初めて見た問題だけの点も、問題の数が少ない（12週目で平均8.5問）ので振れが大きく、相関は0.38にとどまった

### 確かめ：過去問の数と覚える確率を変えると（実力の伸び 週0.05、各200人×10回の平均）
伸びのうち覚えた分の割合：

| 過去問の数 | 覚える確率 0 | 0.15 | 0.3 | 0.5 |
|---|---|---|---|---|
| 100問 | −1.0% | 62.4% | 71.7% | **76.4%** |
| 300問（基本） | −0.0% | 40.9% | 54.3% | 64.8% |
| 1,000問 | −0.1% | 19.1% | 29.7% | 40.8% |
| 3,000問 | −0.6% | **7.9%** | 14.3% | 20.2% |

12週目の過去問の点 − 本当の実力：

| 過去問の数 | 覚える確率 0 | 0.15 | 0.3 | 0.5 |
|---|---|---|---|---|
| 100問 | +0.1点 | +21.8点 | +35.4点 | +43.7点 |
| 300問（基本） | −0.6点 | +10.0点 | +17.6点 | +25.4点 |
| 1,000問 | −0.2点 | +3.0点 | +5.9点 | +8.8点 |
| 3,000問 | −0.1点 | +1.0点 | +2.5点 | +3.6点 |

- 覚える確率が0より大きく、実力も伸びる24通りで、伸びのうち覚えた分の割合は**4.7〜76.4%**、12週目の過去問の点と本当の実力の差は1.0〜43.7点だった。過去問が少なく、答えを覚えやすいほど、伸びの多くは覚えた分になった
- 実力の伸びを0にすると、本当の実力は動かないのに、過去問の点は1.6〜56.6点上がった（過去問100問・覚える確率0.5で56.6点）
- 覚える確率を0にすると、覚えた分は12通りすべてで±0.3点以内になった。作りが置いたとおりに動いていることの確かめ
- 初めて見た問題だけの点の伸びは、過去問300問以上の36通りで、本当の実力の伸びとの差が1.1点以内だった。過去問が100問しかないと、12週目には初めて見る問題が1人平均0.14〜0.16問しか残らず、この読み方は使えなかった
- 1人ずつの相関（過去問の伸びと本当の伸び）は、伸び週0.05では覚える確率が0でも0.62〜0.65にとどまった（40問の点そのものが振れるため）。覚える確率が大きく過去問が少ないほど下がり、100問・0.5では0.01だった

## 動かし方
```
pip install -r requirements.txt
cd src && python a925_past_paper.py
```
45秒ほどで終わります。`data/weekly_scores.csv` と `data/learners.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約44秒）
- 図3枚を開き、日本語・重なり・軸を確かめた
- 覚える確率を0にすると覚えた分が±0.3点以内に消え、初めて見た問題だけの点の伸びが本当の伸びと1.1点以内でそろった（過去問300問以上）。作りが置いたとおりに動いていることの確かめ

## データ
- `data/weekly_scores.csv`：例の200人×12週（learner_id・week・past_score（過去問の点）・true_new_score（本当の実力）・n_first_seen（初めて見た問題の数）・first_seen_score（初めて見た問題だけの点）・n_known_before（すでに答えを覚えていた問題の数））
- `data/learners.csv`：例の200人（learner_id・theta_start（最初の実力）・growth_per_week（週ごとの伸び）・memory_rate（答えを覚える確率）・exam_score（本番の点））
- `results/a925_main.json`：主な結果すべて
- `results/weekly_mean.csv`：週ごとの200人の平均
- `results/robustness.csv`：48通りの確かめ

## 注意（言えないこと）
- 架空のデータです。過去問の数、答えを覚える確率、実力の伸び、正答の確率の式は作成者が置いたもので、結果はこれで決まります。伸びのうち覚えた分の割合は、置き方で4.7〜76.4%と動きました。実在の試験や過去問集を表すものではありません
- 覚えた答えは忘れない、覚えた問題は必ず正解、と置きました。忘れること、似た問題に覚えた答えが効くこと、答えを覚える過程で実力も伸びることは入れていません。とくに最後のものがあると、「覚えた分」と「実力の伸び」はこの記事のようにきれいには分かれません
- 本当の実力を初めて見る問題の正答率としたのは作成者の置き方です。本番の問題が過去問と同じ形で出る試験では、覚えた分も本番の点に効くことがあります
- どう勉強すべきか、過去問を何回解くべきか、どの教材や講座がよいかは言えません。この記事は、過去問の点の伸びの中身を数えただけです
