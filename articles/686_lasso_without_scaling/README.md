# 686 単位をそろえずに Lasso をかけると、どの変数が選ばれやすくなるのか（手法の解説・正解の分かるデータで試す）

Lasso は、係数の大きさの合計に罰を付けて、効かない変数の係数を0にする方法です。罰は係数の数字の大きさにかかるので、変数の単位で選ばれやすさが変わります。同じ量を「百万円」で入れると係数は大きく、「百円」で入れると小さくなるためです。**ここでは、架空のデータ（200件、変数10個のうち5個が同じ強さで効く）で、5つの単位（×0.01〜×100）の変数を作り、標準化してから Lasso をかける場合と、そのままかける場合で、各変数が選ばれる割合を数えました。** 300回のくり返しです。数字は置いた単位の違いで決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A686 | 単位をそろえない Lasso で、どの変数が選ばれやすいか | 標準正規の10変数（効かない5個は効く5個と相関0.5）、y = 効く5個 × 0.25 + 誤差（標準偏差1）。各変数に ×0.01・×0.1・×1・×10・×100 の単位をかける。scikit-learn の LassoCV（5-fold、強さ60通り）を、StandardScaler あり・なしでかける。選ばれた割合と、新しいデータ5,000件での予測の二乗誤差。300回、seed 686 | `src/a686_lasso_scaling.py` |

## 主な結果（300回）
| 単位 | 効く変数が選ばれた割合（標準化あり） | （そのまま） | 効かない変数が選ばれた割合（標準化あり） | （そのまま） |
|---|---|---|---|---|
| ×0.01 | 99.3% | **0.0%** | 59.7% | 0.0% |
| ×0.1 | 99.3% | 39.7% | 58.0% | 4.0% |
| ×1 | 99.0% | 91.7% | 59.3% | 55.3% |
| ×10 | 100.0% | 98.0% | 62.3% | 90.0% |
| ×100 | 99.0% | 100.0% | 60.0% | **99.3%** |

- 標準化してからかけると、効く5個はどの単位でも99%以上選ばれ、効かない5個はどれも6割前後だった（単位に関係しない）
- そのままかけると、数字の小さい単位（×0.01）の効く変数は一度も選ばれず、数字の大きい単位（×100）の効かない変数は99%残った
- 新しいデータでの予測の二乗誤差は、標準化ありで1.038、そのままで1.144（誤差だけの下限は1.0）

## 注意（言えないこと）
- 架空のデータです。単位の差（1万倍）と効き目の大きさは作成者が置いたもので、選ばれる割合はこれで決まります
- 効かない変数が6割残るのは、交差検証で強さを選ぶと予測に有利な側に寄るためで、標準化の有無とは別の話です（選択の安定は630で扱いました）
- リッジ回帰や Elastic Net でも単位の影響はありますが、ここでは扱っていません
- 0/1 のダミー変数を標準化するかどうかの議論は扱っていません
