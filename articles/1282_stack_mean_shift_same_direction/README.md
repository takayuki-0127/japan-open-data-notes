# 1282 部品の平均が許容差の中で少しずつ同じ向きにずれていると、二乗で足して見込んだ外れの割合は、実際の何分の1に出るのか？（寸法の積み上げ）

部品を重ねた組み立て品の高さを見込むとき、部品ごとの散らばりを二乗で足して組み立て品の標準偏差を出し、そこから許容差を外れる割合を見込むことがあります。この見込みは、部品の平均が図面の寸法どおり（真ん中）にあることを前提にしています。部品の平均が許容差の中で少しずつずれていても、部品1つずつで見れば外れはわずかで気づきにくいのですが、5つの部品のずれが同じ向きにそろうと、ずれは足し算でそのまま重なります。**ここでは、作成者が置いた架空の書類ケース（同じ形のケース5段を重ねる。1段80mm±0.4mm、重ねた高さの許容差±0.9mm。部品の平均のずれと散らばりを作成者が置き、乱数で100万台を組んだもの）で、二乗で足した見込みの外れの割合と、平均が同じ向き・でたらめな向き・交互にずれたときの実際の外れの割合を比べました。ずれの大きさ・段の数・1個ずつの散らばりを変えた24通りでも確かめました。**

例の書類ケース・寸法は架空のもので、実在の製品や規格を表すものではありません。品質の判断や購入の助言はしていません。

## 主な結果

### ずれの向きと外れの割合（5段・1段のずれ+0.08mm、各100万台、`results/base_by_direction.csv`）
| ずれの向き | 5段のずれの合計 | ±0.9mmを外れた割合 | 見込みの何倍か |
|---|---|---|---|
| 二乗で足した見込み（ずれなしの前提、式） | 0mm | 0.254% | 1倍 |
| ずれなし（組んだ数） | 0mm | 0.253% | 1.0倍 |
| ①5段とも同じ向き | 0.4mm | **4.697%** | **18.5倍** |
| ②向きがでたらめ（32通りの平均） | 平均0.15mm（大きさ） | 0.936% | 3.69倍 |
| ③交互 | 0.08mm | 0.349% | 1.37倍 |

- **5段とも同じ向きに+0.08mmずれると、二乗で足した見込み（0.254%）は、実際の外れ（4.697%）の18.5分の1だった**
- 1段ずつで見ると、平均のずれ+0.08mmは許容差±0.4mmの中にあり、1段で許容差を外れる割合は0.27%（ずれなし）から0.837%に増えただけだった。1段ずつの外れは小さくても、重ねた高さでは平均が0.4mm（平均400.4001mm）動き、外れはほぼ上の側（4.696%）に集まった
- 重ねた高さの散らばり（標準偏差0.2983mm）は、ずれなしの式の値（0.2981mm）とほぼ同じだった。散らばりは変わらず、分布が丸ごとずれた
- 平均のずれを足し算に入れて式で見込むと4.677%で、実際（4.697%）とほぼ同じだった。実際の外れは、ずれを入れた式どおり
- 向きがでたらめだと、ずれの一部が打ち消し合い、外れは見込みの3.69倍だった。32通りのうち、5段とも同じ向きになるのは2通り（＋の向き・−の向き、各3.125%）で、外れは4.637〜4.998%だった（`results/random_direction_by_sum.csv`）

### 確かめ：24通り（各40万台、`results/grid.csv`）
| 1個ずつの標準偏差 | 見込み（ずれなし、式） | 同じ向きにずれたときの、見込みに対する実際の外れ（ずれのある9通りずつ、式） |
|---|---|---|
| t/3 | 0.27% | **2.51〜162.54倍** |
| t/4 | 0.0063% | **7.46〜6609.81倍** |

- 平均のずれのある18通りすべてで、実際の外れは見込みの2倍を超えた。同じ向きにずれたときの実際の外れは0.0473〜43.8825%だった
- t/3 で5段のとき、1段のずれが許容差の1割・2割・3割で、実際の外れは見込みの3.72倍・18.01倍・59.89倍だった。10段で3割ずれると162.54倍（外れ43.8825%）だった
- 段が多いほど、1個ずつがよくそろう（t/4）ほど、倍率は大きくなった。よくそろうと見込みの外れがもともと小さい（0.0063%）ので、同じずれでも何倍かは大きく出る。t/4・10段・3割ずれの6609.81倍も、外れの割合そのものは41.8682%で、t/3 の同じ置き方（43.8825%）と近い。何倍かは見込みの小ささで大きく振れるので、題名には基本と同じ t/3 の9通りの幅（2.51〜162.54倍）を使った
- このとき1段ずつで許容差を外れる割合は、いちばん大きい置き方（t/3・3割ずれ）でも1.7913%だった
- 平均のずれ0の6通りは、見込みどおり（1.0倍、作りどおり）。組んだ数と式の差は、24通りで最大0.1262ポイントだった

## 注意（言えないこと）
- 架空の書類ケースと、作成者が置いた平均のずれ・散らばりです。1個ずつの寸法を正規の乱数で作ったので、外れの割合はずれを入れた式でほぼ決まり、組んだ数はその確かめです。何倍になるかは、ずれの大きさ・段の数・1個ずつの散らばりで大きく動きます
- 「同じ向きにずれる」は、同じ型・同じ材料で作った部品の平均がそろってずれる場合を置いたものです。実際の部品でずれがどの向きにどれだけそろうかは、この記事では分かりません
- 平均はずれても、1個ずつの散らばりは変わらないと置きました。同じ日に作った部品どうしで1個ずつのずれまでそろう場合は、散らばりそのものも広がり（1284 で扱っています）、外れはさらに増えると考えられます（推測）
- 部品の検査で許容差を外れたものを除く決まりは入れていません（基本の置き方で、1段ずつの外れは0.837%）
- 品質の判断の決まりや、許容差の決め方の助言をするものではありません
