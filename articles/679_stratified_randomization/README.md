# 679 層別に割り付けると、単純な無作為の割り付けよりも効果の推定のばらつきはどれだけ小さくなるのか（手法の解説・正解の分かるデータで試す）

店の数が少ないテストで、施策の店と対照の店を単純に無作為に選ぶと、大きい店がどちらかに偏ることがあります。売上の差で効果を測ると、その偏りがそのまま推定のずれになります。店を大きさの層に分け、層ごとに半分ずつ割り付ける（層別の割り付け）か、割り付けたあとで層の違いを調整すると、このずれを除けます。**ここでは、本当の効果が分かる架空の40店で、3つの方法の推定のばらつきを比べました（各5,000回）。** 数字は置いた売上で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A679 | 層別の割り付けで、推定のばらつきはどれだけ小さくなるか | 40店を大8・中16・小16の3層に。場面A：売上の平均 大3,000万・中1,000万・小300万円。場面B：1,200万・1,000万・800万円。各店は層の平均に±15%（標準偏差）の振れ。施策は売上を本当に5%上げる。20店ずつ割り付け、単純（40店から20店）・層別（各層の半分）・単純＋層で調整（層のダミーで回帰）を比べる。各5,000回、seed 679 | `src/a679_strata.py` |

## 主な結果
- **場面A（大きさの差が大きい）：推定のずれの標準偏差は、単純336万円、層別72万円、単純＋層で調整72万円**（本当の効果は1店あたり56万円）
- 場面B（大きさの差が小さい）：単純68万円、層別47万円、単純＋層で調整49万円（本当の効果48万円）
- 場面Aの単純な割り付けでは、施策側に入った「大」の店が8店のうち2店以下か6店以上になった回が24.1%。6店入ると推定は平均+486万円、2店だと−485万円ずれた
- 場面Aで、推定が本当の効果より大きくずれた（ずれが56万円を超えた）回は、単純86%、層別43%。効果をマイナスと推定した回は43%と22%
- どの方法も平均では本当の効果に近い（ずれの平均は±5万円以内）。違うのは1回ごとの振れ
- 層別でも、40店・効果5%・各店の振れ15%では、5回に1回ほどは効果をマイナスと推定した
