## もとのリポジトリの説明

以下は、もとのリポジトリ `medical-facilities-japan` の README です（同じリポジトリにあったほかの記事の分も含みます）。

### medical-facilities-japan：医療情報ネット（ナビイ）のオープンデータで、診療所が開いている時間と、医療機関・薬局の近さを調べる

厚生労働省「医療情報ネット（ナビイ）」オープンデータ（2026年6月1日時点）の病院7,715施設・診療所80,155施設・薬局61,398施設を使ったリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| M1 | 診療所は土曜・日曜・祝日・夜（平日19時以降）・朝（平日8時半まで）に開いているか。診療科・地域・都道府県でどう違うか | 診療科×時間帯の行を施設ごとにまとめた割合、ロジスティック回帰（日曜診療・夜診療、診療科・所在地の種類・有床・診療科の数、頑健標準誤差） | `src/m1_hours.py` |
| M2 | 薬局から医療機関はどれだけ近いか。市区町村から最寄りの産婦人科・小児科まではどれだけ遠いか | 最寄りの施設までの直線距離（BallTree、haversine）、市区町村ごとの掲載施設の有無 | `src/m2_access.py` |

#### 主な結果
- **M1**：診療時間が登録されている77,966診療所のうち、土曜に診療89.6%、日曜8.2%、祝日6.0%、平日19時以降24.6%、平日8時半まで15.6%。日曜は美容皮膚科49%、眼科14%、小児科8%、内科6%。所在地別の日曜診療は特別区・政令市11.9%、市6.3%、町村3.7%。都道府県別の日曜診療は東京都14.8%が最も高く、長崎県2.5%が最も低い。平日19時以降の診療は京都府71.7%、大阪府64.6%、奈良県64.5%、滋賀県61.0%と近畿で高く、東京都は27.3%、岩手県4.1%。ロジスティック回帰の日曜診療のオッズ比は、美容皮膚科11.7、眼科2.2、小児科1.7、特別区・政令市1.7（市と比べて）、町村0.62
- **M2**：座標のある薬局54,095のうち、いちばん近い病院・診療所まで50m未満が50.9%、100m未満が69.7%（中央値49m）。特別区・政令市では50m未満が60.7%、町村では39.8%で、1km以上も6.9%。病院・診療所・薬局のどれかが掲載されている1,840市区町村のうち、産婦人科・産科を掲げる病院・診療所が1つも掲載されていないのは864（町村726、市129、特別区・政令市9）、小児科は236（町村228）、病院は449（町村431）。市区町村の中心から最寄りの産婦人科・産科までの直線距離の中央値は、特別区・政令市0.7km、市1.2km、町村8.3kmで、20km以上は165市区町村（うち町村156）

#### データ
| ファイル | 中身 |
|---|---|
| data/raw/01-1・02-1（各自ダウンロード） | 施設票：所在地の市区町村コード・緯度経度、休診日、病床数 |
| data/raw/01-2・02-2（各自ダウンロード） | 診療科・診療時間票：診療科ごとに3つの時間帯の、曜日別の診療開始・終了時間 |
| data/raw/05（各自ダウンロード） | 薬局：所在地・緯度経度・開店時間 |
| data/raw/muni_names.csv | 市区町村コードと名前の対応（厚生労働省「介護サービス情報公表システム」オープンデータから作成）。ない市区町村は所在地の文字列から取った |
| results/m2_muni_access.csv | 市区町村ごとの中心の位置、最寄りの小児科・産婦人科・病院までの距離、掲載の有無 |

#### 注意
- 医療機関が自分で報告した内容をもとにしたデータです。掲載されている診療所は80,155で、全国の診療所の数（約10万）より少なく、掲載の割合は都道府県によって違う可能性があります。病院の数や病床数も、他の統計と一致しない県があります。都道府県の比較は、掲載されている施設の中での割合です
- 「診療している」は、その曜日の診療時間が登録されていることです。毎週か、隔週かは区別していません。夜は平日のどれかの日の診療終了が19時以降、朝はどれかの日の診療開始が8時半までとしました
- 小児科・産婦人科は、その診療科を掲げているかどうかです。分娩を扱っているかどうかは、このデータでは分かりません
- 距離は直線距離です。市区町村の中心は、その市区町村にある病院・診療所・薬局の位置の平均で、役場や人口の中心ではありません
- 個々の施設の名前は分析に使っていません
