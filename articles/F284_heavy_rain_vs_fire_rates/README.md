# F284 豪雨の増え方を、火災保険の料率はどこまで追いかけているのか

note 記事「豪雨の増え方を、火災保険の料率はどこまで追いかけているのか？」のコード・データ・図です（精選モード A. 保険数理・リスク Q08）。

## 問い

気象庁によると、1時間に50mmを超えるような大雨は増えています。一方、火災保険の参考純率（損害保険料率算出機構）は2014〜2023年に5回引き上げられました。料率の上がり方は、大雨の増え方に比べて大きいのか小さいのか。料率は、大雨の増え方をどのくらい遅れて取り込む仕組みなのか。保険会社の料率・商品の担当者、保険数理の担当者、損害保険を研究する人が知りたい問いです。

計画（仮説・比べ方・頑健性・「外れ」の基準）は、支払保険金と料率をつき合わせる計算の前に [PLAN.md](PLAN.md) としてコミットしました（コミット 2919e25）。大雨の回数と改定率の値は、PLAN を書く前に目にしています（PLAN に記載）。

## 結論

1. **大雨の回数は年約1%ずつ増えている**：1時間50mm以上の年間回数（アメダス1,300地点あたり）は、1976〜1985年の平均226回から2016〜2025年の平均340回へ1.50倍。準ポアソン回帰の傾きは年 +1.0%（95%区間 +0.5〜+1.5%）。しきい値を変えた7系列すべてで傾きは正（年 +1.0〜+1.8%）。H1 支持（ただし値を見てから置いた仮説で、確かめとしては弱い）
2. **料率は大雨の回数より約6倍大きく上がった**：5回の改定の累計は +43.5%（1.035×1.055×1.049×1.109×1.130）。同じ期間（改定が基にした保険統計の末年 2012年度と 2022年度）の1時間50mm以上の直前10年平均は 305.9→328.0回で +7.2%。H2 支持。系列×平均の期間（5・10・15年）の21通りのうち17通りで「料率の上げ幅が大雨の増え方の2倍以上」。外れの4通りは、日・3時間の系列を5年平均で見た場合（2018〜2022年に大雨の多い年が集まる）
3. **支払保険金は大雨の回数より台風で決まる**：主な風水災の火災保険の支払保険金（2012〜2025年度、修理費で実質化）と、その年の1時間50mm以上の回数の順位相関は 0.27（14年、p=0.34）。H3 支持。支払の77%は台風、大雨は10%で、2018・2019年度の2年で全体の62%
4. **大雨の増え方だけなら、取り込みの遅れによるずれは数%**：基データの末年から料率が使われる期間の真ん中まで約4.2年（届出まで平均0.65年＋適用まで約1年（推測）＋保険期間5年の半分）。年 +1.0% の傾きでは、ずれは +4.2%（傾きの95%区間の上側で +6.3%）で、1回の改定の平均 +7.6% より小さい。H4 支持。ただし、基データを10年平均で使っていると見て遅れを約9年とすると +9.6% で、1回の改定より大きくなる。1時間100mm・日300mmの傾きを使うと +7.3〜7.5% と、ほぼ同じ大きさ
5. **問い直し：料率の上げ幅の大半は、修理費の上がり方と同じ大きさ**（結果を見てから足した）：同じ期間に建設工事費デフレーター（住宅総合）は 87.8→115.3 で +31.3%。料率の累計 +43.5% を対数で分けると、修理費 約75%、大雨の回数 11〜32%（使う系列による）、残り −7〜+14%。損害が「回数 × 1件あたりの修理費」で動くとみなした機械的な分け方で、原因を示すものではない（推測を含む）

- 改定が基にした保険統計の末年度は、2014・2018・2019年の改定は後の案内文に書かれた値。2021年（2020年度まで）と2023年（2022年度まで）は案内文に書かれておらず、挙げられている災害の年から置いた値（推測）。

## 手法

- 大雨の傾き：年を説明変数にしたポアソン回帰。過分散（分散/平均は約17）があるので、標準誤差を準ポアソンで補正。比べるために対数の直線（OLS）も推定
- 料率の累計：5回の平均改定率の掛け算。平均改定率は「全ての契約条件の改定率の平均」（案内文の注）で、補償の種類（火災・風災・水災など）の合計
- 大雨の増え方（H2）：改定の基データの末年 2012年と 2022年、それぞれの直前10年平均の比
- 支払保険金（H3）：協会が個別に調べた主な風水災の火災保険分の年度合計。発生年度の建設工事費デフレーター（住宅総合）で2025年度の値に換算。ケンドールではなくスピアマンの順位相関（計画どおり）
- 遅れによるずれ（H4）：exp(g×L)−1。g は大雨の傾き（対数）、L は基データの末年（年度末）から料率が使われる期間の真ん中までの年数
- 問い直し：log(料率の累計) = log(大雨の10年平均の比) + log(修理費の比) + 残り

## 計画と結果

| 仮説 | 基準 | 結果 | 判定 |
|---|---|---|---|
| H1 大雨は増えている | 傾きの95%区間が正、直近10年÷最初の10年 ≥ 1.3 | 年 +1.0%（+0.5〜+1.5%）、1.50倍 | 支持（PLAN 前に値を見て置いた仮説なので、確かめとしては弱い） |
| H2 料率は大雨より大きく上がった | 料率の上げ幅 ≥ 大雨の増え方 × 2 | +43.5% 対 +7.2%（6.0倍） | 支持（21通り中17通り） |
| H3 支払保険金と大雨の回数は弱い連動 | 順位相関 < 0.5 | 0.27（p=0.34、14年） | 支持 |
| H4 遅れによるずれ < 1回の改定 | exp(gL)−1 < 平均改定率 7.56% | +4.2%（上側 +6.3%） | 支持（遅れを約9年とみると +9.6% で外れ） |

## 頑健性

| 替えたもの | 結果 |
|---|---|
| しきい値（7系列） | 傾きはすべて正（年 +1.0〜+1.8%）、95%区間はすべて0を含まない。直近10年÷最初の10年は1.50〜2.00倍 |
| 推定法（対数の直線） | 年 +1.1〜+2.1%（準ポアソンと同じ向き） |
| 外れ年（2004・2011年）を除く | 年 +0.9〜+1.7%（ほぼ同じ） |
| 平均の期間（5・10・15年） | 1時間50mmの増え方は +12.0%・+7.2%・+3.7%。21通り中17通りで H2 支持 |
| 支払保険金から2018年度を除く | 順位相関 0.18（p=0.57） |
| 系列を替えた順位相関 | 合計×日200mm 0.34、合計×3時間100mm 0.48。大雨の支払×日200mm 0.45（どれも p>0.05） |
| H4 の遅れ | 約2.2年で +2.2%、約6.7年（保険期間10年の半分）で +6.9%、約9.2年（10年平均の真ん中）で +9.6% |

## 計画からのずれ

- H3 の支払保険金は「主な風水災」の合計で、協会が個別に調べた事故だけ（小さな事故は入っていない）。計画どおりだが、年ごとの合計は大きな台風に引っぱられる
- 問い直しは、計画の候補（料率の上げ幅を大雨・修理費・その他に分ける）をそのまま使った
- 計画にない追加：H4 の遅れを4通りに変えた計算、住宅物件の全国の保険料・保険金（F272、2017〜2024年度）を参考に載せたこと
- 改定の基データの末年度のうち2回分は推測（「データ」参照）

## 言えないこと

- 料率の改定率は補償全体の平均で、水災・風災などの内訳は公表資料にない。大雨（水災）の部分だけがどれだけ上がったかは分からない
- 2023年の改定では水災料率が地域で5区分に分かれた。全国平均は +13.0% でも、契約者ごとの上がり方は大きく違う
- 料率は修理費だけでなく、台風の評価方法の見直し、築年数の古い住宅の増加（案内文が挙げる理由）も反映している。問い直しの分け方は機械的なもので、それぞれの理由がどれだけ効いたかは分からない
- 大雨の回数は気象のものさしで、浸水する建物の数や被害額とは直接つながらない（川の整備や土地の使い方でも変わる）
- 住宅物件の全国の保険料÷保険金額（参考）は保険期間の構成で動く（2022年10月の最長5年化の前後など）ので、料率の動きそのものではない
- 料率の良し悪し、個人の保険の選び方、制度への提言は扱わない。都道府県の順位づけはしない

## 外に出すなら

保険数理の勉強会（日本アクチュアリー会の研究会や、損保数理の自主勉強会）で「料率改定と気候トレンドの取り込みの遅れ」として5分程度の LT にできる。数式（exp(gL)−1）と図5が中心。投稿はしていない。
