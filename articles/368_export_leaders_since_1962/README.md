# 368 日本の輸出の主役は、何から何へ入れ替わったのか（1962〜2025年）

輸出総額に占める割合を、繊維・鉄鋼・化学製品・一般機械・電気機器・輸送用機器の6分野と、自動車・船舶・半導体等電子部品で並べたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A368 | 輸出の割合がいちばん大きい品目は、いつ入れ替わったか。それぞれの山は何年か | 分野・品目ごとに、その年の輸出総額に対する割合を計算。1987年までは「日本の長期統計系列」（外国貿易概況）、1988年からは貿易統計の概況品別 | `src/a368_exports.py` |

## 主な結果
- 繊維：1962年25.6% → 1970年12.5% → 1973年に10%を、1978年に5%を下回り、2025年0.8%
- 鉄鋼：1962年10.8% → 1974年19.4%（山）→ 1983年に10%を下回り、2025年3.6%
- 品目で比べると（1969年〜）、1位は1969年が繊維（14.2%、鉄鋼13.5%）、1970〜76年が鉄鋼、1977年からは自動車。自動車が繊維を上回ったのは1972年
- 自動車：1969年6.2% → 1980年17.9% → 1986年20.4%（山）→ 1995年12.0% → 2025年16.0%。船舶の山は1973年の10.0%、半導体等電子部品の山は1995年の9.2%
- 6分野で比べると（1969〜2025年の57年）、1位は輸送用機器が48年、電気機器が6年（1994・95・99〜2001・2004年）、一般機械が3年（1996・97・2021年）
- 機械の3分野（一般機械・電気機器・輸送用機器）の合計：1969年38.6%、1980年54.7%、1990年70.1%、1994年71.5%（最大）、2010年61.2%、2025年56.5%
- 化学製品：1962年5.3% → 2009年に10%を超え、2021年12.7%（山）、2025年10.7%
- 2025年の割合：輸送用機器21.9%、一般機械17.9%、電気機器16.8%、化学製品10.7%。半導体等製造装置は4.1%（2024年4.2%が最大）

## 確かめたこと
- 2つの出どころが重なる1988〜2004年で、総額は一致。鉄鋼・化学製品・一般機械・電気機器・輸送用機器・自動車・船舶・半導体等電子部品の割合の差は0.0ポイント。繊維だけ平均0.4ポイント（最大0.5）の差があった（分け方の違い）
- 長期統計系列の金額は1978年まで1,000ドル、1979年から100万円。割合は同じ年の総額で割るので、単位の違いは影響しない
- 空のフォルダで流し直し、data・results・figures が一致した

## データ
- `data/raw/chouki_18-01-b.xls`・`chouki_18-03.xls`（`chouki_18-01-c.xls` は参照用）：総務省統計局「日本の長期統計系列」18-1-b 輸出額－商品分野別（1962〜2004年）、18-3 品別輸出数量及び金額（1969〜2004年）。もとの資料は日本関税協会「外国貿易概況」。統計局のサイトでは掲載が終わっているため、Internet Archive の保存版から取得（2026-11-12）
- `data/raw/d51ca.csv`：財務省「貿易統計」輸出入額の推移（主要商品別）世界 年別（輸出）（1988〜2025年、2026-11-12 取得）
- `data/export_shares_1962_2025.csv`：つないだ割合。`data/exports_chouki_1962_2004.csv`・`data/exports_customs_1988_2025.csv`：もとの金額

## 注意（言えないこと）
- 記事案では1950年からの予定でしたが、公開の表で品目別にたどれるのは1962年からでした。1950年代の入れ替わりは見ていません
- 一般機械・電気機器・輸送用機器と、自動車などの品目は1969年からです。1962〜68年の「1位」は決められません
- 1988年に品目の分け方が全面的に変わりました。1987年→1988年に電気機器は17.8%→23.4%、輸送用機器は27.9%→24.8%と段差があります。この年をまたぐ比べはできません
- 見ているのは金額の割合です。数量や、海外での生産に移った分は分かりません
- 割合が下がっても、金額が減ったとは限りません
