# 624 週の途中の数字を先週の合計と比べると、どれだけ低く見えるのか（実務の型）

ダッシュボードで「今週の売上」を先週の合計と並べると、週の途中では当然低く見えます。曜日の波があると、どの曜日に見るかで低さも変わります。**ここでは、本当の水準を変えていない架空の日次売上2年分（土日に多い店頭型、平日に多い事務所型）で、各曜日の夜に「今週ここまで」を先週の合計・先週の同じ曜日まで・直近7日とその前の7日の3通りで比べ、見かけの増減と、「10%以上下がった」と出る割合を数えました。** 週は月曜始まりです。SQL（DuckDB）でも1日分を出し、Python と一致することを確かめています。数字は置いた曜日の波と振れで決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A624 | 比べる相手の取り方で、週の途中の増減はどう見えるか | 曜日の波（店頭型：土1.7・日1.6、事務所型：土0.25・日0.1）、週ごとの振れ（標準偏差5%）と日ごとの振れ（8%）、2024〜2025年、seed 624 | `src/a624_partial_week.py` |
| SQL | 今週ここまで・先週の合計・先週の同じ曜日まで | DuckDB 版（1スレッドで実行）、T-SQL 版（未検証） | `src/02_week_to_date_duckdb.sql`・`src/01_week_to_date_tsql.sql` |

## 主な結果
- **今週ここまで ÷ 先週の合計（平均）**：店頭型は月曜の夜 −88%、水曜 −64%、金曜 −40%、土曜 −19%、日曜 0%。事務所型は月曜 −81%、水曜 −44%、金曜 −6%、土曜 −2%。同じ「金曜の夜」でも、店頭型は4割低く、事務所型はほぼ同じに見える
- **先週の同じ曜日まで・直近7日で比べる**：平均はどの曜日も 0〜1% で、見かけの下落は消える
- **散らばり（店頭型、先週との比の標準偏差）**：先週の同じ曜日までは月曜 13.1ポイント、水曜 9.6、日曜 8.6。直近7日どうしは 6.0〜8.6ポイント
- **「10%以上下がった」と出た日の割合（本当は変わっていない）**：先週の合計と比べると、店頭型は月〜金曜の100%、全体で87.0%。先週の同じ曜日までだと全体で15.6%（月曜21.4%）、直近7日どうしは7.0%

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- 2025年6月18日（水）の店頭型の3つの合計が、SQL（DuckDB）と Python で一致すること
- 日曜の夜は3つの比べ方がすべて同じ値になること

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 624）

## 注意（言えないこと）
- 架空のデータ。曜日の波と振れは作成者が置いたもので、結果はこれで決まる
- 祝日・連休・月末の波は入れていない
- 「直近7日どうし」が常によい、という話ではない。週の区切り（週次の目標など）に合わせたいときは同じ曜日までで比べる
