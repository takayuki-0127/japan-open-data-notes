# 443 分類を付け替えたあと、過去の集計は「当時の区分」と「今の区分」でどれだけ違うのか（実務の型）

架空の商品400点・12区分・3年分の売上に、分類の付け替えを3回入れて、3つの集計のしかたで区分ごとの前年比がどれだけ変わるかを数えたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A443 | 過去の売上をどの区分に入れるかで、区分ごとの前年比はどれだけ変わるか | ①いまの分類マスタだけを結合 ②期間つきマスタで当時の区分 ③いちばん新しい区分を過去にも当てる、の3つを Python と SQL（DuckDB）で計算して一致を確かめる。乱数を変えた2,000社、付け替える商品の割合、扱いをやめる商品の割合を変えて比べる | `src/a443_reclass.py`、`src/01_asof_join_tsql.sql`（T-SQL 版、未検証） |

## 主な結果（架空の1社、seed 443）
- 付け替えは3回（2024年4月・10月、2025年4月）。1回以上移った商品は400点中87点
- **②当時の区分 と ③今の区分に引き直す の前年比**：5ポイント以上違う区分は、2025年5区分・2024年5区分（12区分のうち）。10ポイント以上は3区分ずつ。向きが逆の区分は2025年3区分・2024年2区分
- **大きく違った区分（2025年の前年比）**：区分C ②−42.6% ③+4.1%、区分G ②+18.8% ③−3.5%、区分L ②+17.4% ③+4.0%（全区分は `results/category_table_main.csv`）
- **①いまのマスタだけ**：扱いをやめた商品の売上が落ちる。2023年6.6%、2024年4.3%、2025年0.7%。全体の2025年の前年比は、本当は−1.0%、①では+2.7%

## 2,000社（乱数を変える）
| 指標 | 2024年の前年比 | 2025年の前年比 |
|---|---|---|
| 前年比が5ポイント以上違う区分の数（平均） | 5.6 | 7.6 |
| 10ポイント以上違う区分の数（平均） | 2.5 | 4.6 |
| ②で2割以上の増減に見え、③で1割未満の区分の数（平均） | 0.5 | 1.9 |
| それが1つ以上ある会社 | 38% | 93% |

- **付け替える商品の割合**（まとめての付け替えなし、300社の平均）：0%で0区分、2%で3.4区分、6%で6.6区分、10%で7.9区分（2025年の前年比が5ポイント以上違う区分）
- **扱いをやめる商品の割合**（3年で）：2%なら2年前の売上が2.0%落ち、5%なら5.1%、10%なら10.0%

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した
- 3つの集計を SQL（DuckDB）で実行し、区分×年のすべての値が Python の計算と一致する（コード内の assert）

## データ
- `data/sales.csv`：架空の売上（商品×月、14,117行）
- `data/class_hist.csv`：期間つきの分類マスタ（487行）、`data/class_now.csv`：いまの分類マスタ（扱いをやめた商品は載っていない）
- すべて架空（作成者が乱数で作成、seed 443）

## 注意（言えないこと）
- 架空のデータでの結果。区分の数、付け替えの回数と大きさで数は変わる
- 「当時の区分」と「今の区分」のどちらで見るべきかは決めていない
- 区分が分かれる・まとまる・新しくできる変更は入れていない
- T-SQL 版は SQL Server 本体では動かしていない（未検証）
