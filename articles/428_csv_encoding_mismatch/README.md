# 428 文字コードを取り違えて CSV を読むと、何行が壊れ、何行が黙って通るのか（実務の型）

架空の顧客表2万行を cp932・UTF-8・BOM つき UTF-8 で保存し、文字コードとエラーの扱いを変えて読んだとき、読み込みが止まるか、黙って通るか、どの検査で気づけるかを数えたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A428 | 文字コードを取り違えると、止まるのか、黙って通るのか。黙って通ったとき、どの検査で気づけるか | 3つのファイル × 読む文字コード（cp932・utf-8・shift_jis・latin-1）× エラーの扱い（strict・ignore・replace）の16通りを Python の標準の機能で読み、元の表と1行ずつ比べる。9つの検査（行数・見出し・キー・列の数・置き換え文字・文字化けの字・想定外の字・氏名の字・バイト列の往復）を当てる | `src/a428_encoding.py` |

## 主な結果
| ファイル → 読み方 | エラーの扱い | 結果 | 中身が変わった行 |
|---|---|---|---|
| cp932 → utf-8 | strict | 1行目で止まる | − |
| cp932 → utf-8 | ignore／replace | 通る | 20,000行（100%） |
| utf-8 → cp932 | strict | 1行目で止まる | − |
| utf-8 → cp932 | ignore／replace | 通る | 20,000行（100%） |
| cp932 → shift_jis | strict | 2行目で止まる | − |
| cp932 → shift_jis | ignore | 通る | 5,955行（29.8%）。うち字が消えた行 4,381（21.9%） |
| BOM つき utf-8 → utf-8 | strict | 通る | 0行（見出しの1列目に見えない字が付く） |
| utf-8 → latin-1 | strict | 通る（エラーは出ない） | 20,000行（100%） |

- **どの読み方でも**：行数は2万行のまま、列の数が変わった行は0、顧客番号（英数字）は2万行すべて元と同じ
- **shift_jis で読めない字のある行**：旧字の姓854、㈱ 1,992、ローマ数字861、丸数字992（重なりを除いて4,381行）。読めない字は ⅠⅡⅢ①②③④⑤㈱德栁桒濵髙﨑 の15字
- **全角の「～」**：cp932 で読むと U+FF5E、shift_jis で読むと U+301C（波ダッシュ）になる。2,009行
- **書き出し（cp932 にない字を600行に入れた場合）**：strict は148行目で止まる。replace は600行に「?」。ignore は氏名の種類が512→496
- **BOM**：csv モジュールで読むと見出しの1列目が `\ufeffcustomer_id` になる。pandas（encoding="utf-8"）は BOM を取り除く
- **検査（黙って通った7つの読み方のうち気づけた数）**：行数0、キーの突き合わせ0、列の数0、見出しの名前1、置き換え文字2、文字化けの字2、氏名に漢字・かながあるか3、想定外の字5、バイト列の往復5。cp932→shift_jis（ignore）に気づけたのはバイト列の往復だけ

## 動かし方
```
pip install -r requirements.txt
cd src && python a428_encoding.py     # 数秒。data/ に3つの CSV を作る
```

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した
- 正しい文字コードで読んだ3通り（cp932→cp932、utf-8→utf-8、BOM つき→utf-8-sig）は、2万行すべてが元の表と一致する

## データ
- `data/customers_cp932.csv`・`customers_utf8.csv`・`customers_utf8_bom.csv`：架空の顧客表2万行を3通りの文字コードで保存したもの（合わせて約5.5MB）。大きいのでこのリポジトリには入れていません。`src/a428_encoding.py` を実行すると作られます（seed 428）
