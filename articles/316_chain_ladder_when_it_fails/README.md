# 316 支払いの進み方から将来の支払いを見積もる方法（チェインラダー法）は、どんなときに外れるのか

保険の支払備金（起きた事故のうち、まだ払っていない保険金のために積んでおくお金）を見積もる基本の方法、チェインラダー法を、最終の支払額が分かる架空のデータで試したフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A316 | チェインラダー法の見積もりは、支払いの進み方が一定のとき・遅くなるとき・速くなるとき・インフレがあるときに、どれだけ外れるか。新しい事故年度ほど外れるか | 事故年度10年×経過10年の支払額の三角形を5つの場面で1,000組ずつ作り、見積もった備金と正解（三角形の外も含む、その後に実際に払う額）を比べる。比は「全年度の加重平均」と「直近3年分」の2通り | `src/a316_chain_ladder.py` |

## データの作り方（架空）
- 事故年度ごとの最終の支払額＝保険料（1,000百万円から年3%で増える）×損害率（平均65%、変動係数8%の対数正規）
- 支払いの進み方：ワイブル型の曲線で、経過1年目までに25%、2年目までに46%、5年目までに83%、10年目で払い終わる
- 1マス（事故年度×経過年）の支払額に、変動係数12%のガンマ分布のばらつきをかける
- 場面は、直近3本の対角線（暦年8〜10年目）から先で変わる。B：支払いの進む速さが0.8倍、B'：1.25倍、C1：インフレが最初から年3%、C2：インフレが年1%から6%に上がり、その先も6%が続く
- 乱数の種は316。実在の会社の数字ではありません

## 主な結果（支払備金の見積もりの誤差、全年度の比）
| 場面 | 誤差の平均 | 10〜90%の範囲 | 低く見積もった割合 | 直近3年の比にした場合の平均 |
|---|---|---|---|---|
| A 進み方が一定 | +0.4% | −7.0〜+7.8% | 48% | +0.4% |
| B 支払いが遅くなる（0.8倍） | −31.5% | −36.3〜−26.1% | 100% | −33.8% |
| B' 支払いが速くなる（1.25倍） | +44.9% | +33.0〜+56.9% | 0% | +48.2% |
| C1 インフレが一定（年3%） | +0.2% | −7.5〜+8.3% | 51% | +0.3% |
| C2 インフレが強まる（年1%→6%） | −10.5% | −17.9〜−3.4% | 96% | −6.9% |

- **進み方が一定なら、平均ではほぼ当たる**。インフレがあっても、ずっと同じ率なら同じ（C1）
- **支払いが遅くなると、備金は平均32%少なく出た**。1,000組すべてで少なすぎた。直近3年の比に替えても直らない（−34%）。いまの累計そのものが「遅れた分だけ小さい」ため
- **インフレが強まると平均10%少なく出た**。直近3年の比に替えると−7%に縮む
- **進み方が一定でも、新しい事故年度ほど外れる**。最終の支払額の誤差の大きさ（RMSE）は、事故年度2の0.3%に対し、いちばん新しい事故年度10では10.0%。備金の誤差（二乗和）の95%は直近3事故年度から来ていた
- **気づく手がかり**：経過1→2年目の比を事故年度ごとに並べると、場面Bでは変わり目の年度だけ1.86→1.71に下がり、場面C2では1.87→1.91に上がる（1,000組の平均。1組だけだとばらつきに隠れることがある）

## 注意（言えないこと）
- すべて架空のデータです。誤差の大きさ（32%、10%など）は、速さの変わり方（0.8倍）・インフレ（1%→6%）・進み方の曲線・ばらつきの置き方で決まります。言えるのは向きと、どの場面で直近の比が効くか・効かないかまでです
- 変化は「直近3年から先もずっと続く」と置きました。先で元に戻る場合は、誤差の向きも大きさも変わります
- 使ったのは支払額の三角形だけです。発生保険金（支払額＋個別に見積もった未払額）の三角形、件数や平均単価に分ける方法、インフレを取り除いてから当てる方法、尻尾の係数は扱っていません
- 場面Bでは、経過10年を超えて払う分（備金の平均8%）が三角形の外に残ります。これはチェインラダー法では原理的に見えません
- 実務の備金の見積もり方や水準について助言するものではありません
