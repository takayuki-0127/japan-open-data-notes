# 545 割引を2つ重ねるとき、「足し算」「掛け算」「適用の順番」の違いで、請求額は何件・何円違うのか（実務の型・計算ルール）

「20%引き」と「1,000円引き」のように割引を2つ重ねるとき、どの順番で、どう組み合わせて計算するかで請求額が変わります。**ここでは、架空の注文20,000件（%引きと円引きのクーポンを0〜2枚使う）で、重ね方を4通りにして請求額を出し、何件が・何円違うかを数えました。** 注文の金額やクーポンの使われ方は作成者が置いたもので、件数や合計の差はその仮定で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A545 | 割引の重ね方4通りで、請求額が違う注文の件数・差の合計・最大の差はどうなるか | M1 足し算（%→円：どの割引も元の金額から計算して合計）、M2 掛け算（%→円：%引きを順に掛け、そのあと円引き）、M3 掛け算（円→%：円引きのあと%引きを順に掛ける）、M4 足し算（円→%：円引きのあと%引きの合計を掛ける）。%引きのたびに1円未満を切り捨て（比較として最後に1回だけ切り捨てる場合も）。0円未満にはしない。seed 545 | `src/a545_stacked_discount.py` |

## 主な結果
- **注文 20,000件**：クーポンなし 12,035件、1枚 4,005件、2枚 3,960件（%引き2枚 1,017件、%引きと円引き 2,332件、円引き2枚 611件）
- **4通りのどれかで請求額が違う注文は 3,339件（全体の16.7%、2枚使った注文の84.3%）**。4通りの最大と最小の差は合計 254,038円、1件で最大 550円
- **組み合わせごと**：M1 と M3（足し算・%が先 と 掛け算・円が先）、M2 と M4 がいちばん多く違い、それぞれ 3,339件。M1 と M2、M3 と M4（足し算か掛け算か）は %引き2枚の 1,017件すべてで違い、最大 550円。M2 と M3（順番だけの違い）は %引きと円引きの 2,322件で違い、最大 200円
- **請求額の合計**：M1 87,949,736円 〜 M3 88,203,646円で、253,910円（約0.29%）の差
- **クーポン1枚の注文と円引き2枚の注文は、どの重ね方でも同じ**。%引きと円引きでも、円引きで0円になる10件は同じ
- **端数の切り捨て**：%引きのたびに切り捨てるか最後に1回だけかで、1,426〜2,079件が1〜2円違った
- 例：10,000円に「20%引き」と「1,000円引き」は、%が先なら 7,000円、円が先なら 7,200円。「20%引き」と「10%引き」は、足し算なら 7,000円、掛け算なら 7,200円

## 動かし方
```
pip install -r requirements.txt
cd src && python a545_stacked_discount.py
```
数秒で終わります。`data/orders.csv` に注文とクーポンを書き出します。

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures がバイト単位で一致した
- 例の3つ（10,000円・3,000円）を手で計算した値と一致すること
- クーポンが1枚以下の注文では、4通りの請求額がすべて同じになること

## データ
- `data/orders.csv`：注文（order_id・金額・使ったクーポン）。`results/bills.csv`：4通りの請求額（_end は最後に1回だけ切り捨てた場合）
- 仮定：金額は中央値 4,000円の対数正規（10円単位）。クーポンは 60% が使わない・20% が1枚・20% が2枚。2枚の内訳は %引き2枚 25%・%引きと円引き 60%・円引き2枚 15%。%引きは 5・10・15・20%、円引きは 300・500・1,000円

## 注意（言えないこと）
- 架空のデータ。実際の店やサービスの数字ではない
- どの重ね方が正しいかを決めるものではない。クーポンの条件や利用規約で決まる
- 税の計算（税込み・税抜きのどちらに割引を当てるか）や、会計での値引きの扱いは入れていない。税・会計の助言ではない
- 値引きの明細への割り振り（記事473）や、丸めの順番そのもの（記事328）は扱っていない
