# F155 分析の手順を変えると、答えはどこまで変わるか？ マルチバース分析

看板記事 F155。note：「分析の手順を変えると、答えはどこまで変わるか？…」（下書き）

ひとつの問いを分析するとき、処置の定義、期間、追加する条件、対象、重み、外れ値の扱いなど、分析する人が決める「選択肢」はたくさんあります。どれも一応もっともらしい選び方があり、記事ではふつう、そのうち1通り（と、いくつかの頑健性チェック）だけを示します。

この記事では、過去の2本の記事の問いについて、もっともらしい選択肢を **すべて組み合わせて** 推定しました（マルチバース分析／specification curve）。そのうえで、次の3つを確かめています。

- 答えの分布がどうなるか
- 答えのばらつきがどの選択肢から来ているか
- 「本当は効果0」の世界でも同じくらいの答えが出るか

## 問い

| | 問い | 元の記事 | 単位 |
|---|---|---|---|
| **問いA** | 最低賃金が平均の時給に近い県（bite が高い県）で、2016年以降に就業率が下がったか | [F01](../F01_minimum_wage_did/) | 都道府県×年（差の差） |
| **問いB** | 保育所等に通う子どもが多い（増えた）市区町村ほど、合計特殊出生率は高い（上がった）か | [F100](../F100_five_methods_one_question/) | 市区町村（横断） |

確認のため、別の結果でも同じことをしました。問いAは完全失業率、問いBは女性の労働力率です。

## データ

新しい取得はしていません。F01・F100 の整形済みデータを使い回しました（`data/`、詳しくは `src/01_取得.md`）。

- **問いA**：47都道府県×2008〜2025年
  - 総務省「労働力調査 都道府県別結果（モデル推計値）」
  - 厚生労働省「地域別最低賃金の全国一覧」「賃金構造基本統計調査（2015年、短時間労働者）」
- **問いB**：1,606〜1,610 市区町村
  - 総務省統計局「社会・人口統計体系 市区町村データ」
  - 厚生労働省「人口動態保健所・市区町村別統計」（合計特殊出生率のベイズ推定値）

## 手法

### 選択肢（すべての組み合わせを推定）

**問いA（6次元・288通り）**

効果は「bite 1標準偏差（2.7%ポイント）あたりの就業率の差（%ポイント）」にそろえました。2分・3分の1のときは、2つのグループの bite の差で割って直しています。

| 次元 | 選択肢 |
|---|---|
| 処置の定義 | 中央値で2分（F01 の基本）／上下3分の1（真ん中を除く）／連続（bite） |
| 期間の始まり | 2008年／2012年 |
| 期間の終わり | 2019年／2022年／2025年／2025年（2020〜22年を除く） |
| 追加の条件 | なし（県・年の固定効果だけ）／地方×年の固定効果／県別の線形の傾き |
| 対象 | 47県／被災3県（岩手・宮城・福島）を除く |
| 重み | なし／15歳以上人口 |

- 標準誤差は県でクラスター（CR1）、区間は t 分布（自由度＝県の数−1）。
- 引き上げの開始は2016年で固定しました。

**問いB（7次元・528通り）**

効果は「在所児（0〜5歳100人あたり）が10人多い（増えた）ときの出生率の差」にそろえました。3分の1のときは、上下のグループの在所児の差で割って直しています。

| 次元 | 選択肢 |
|---|---|
| 比べ方 | 水準の比較（2015年の在所児 → 2018〜22年の出生率）／変化の比較（2010→15年の変化 → 出生率の変化） |
| 地域の条件 | なし／人口・密度／＋年齢・世帯／＋産業・通勤・所得／＋財政・学歴・雇用（2010年の23列すべて）／＋前の値（変化の比較だけ：もとの出生率・在所児・期間中の年齢構成の変化など） |
| 県の違い | 除く（県ダミー）／除かない |
| 対象 | 全体／人口1万人以上／政令市・23区を除く |
| 重み | なし／人口 |
| 外れ値 | そのまま／在所児と出生率の上下1%を除く |
| 処置の定義 | 連続（在所児）／上下3分の1（真ん中を除く） |

- 標準誤差は HC1 です。
- 地域の条件は、F100 の「条件を1段ずつ足す」と同じ順に入れ子で足しました。

### 分析

1. **specification curve**：全指定の推定値を小さい順に並べ、それぞれの指定でどの選択肢を使ったかを下に並べます（図1・図2）。
2. **ばらつきの分解**：推定値を各次元のダミーで回帰し、R² をシャープレイ値で次元に分けました（図3）。「足し合わせ」は交互作用を入れない R² で、残りは選択肢どうしの組み合わせの効果です。
3. **「効果0の世界」との比較（joint inference）**：Simonsohn・Simmons・Nelson（2020）にならい、全指定の推定値の中央値と、有意になった指定の割合を、効果が0になるように作り直したデータで同じ数だけ推定した分布と比べました（図4）。
   - 問いA：bite を県の間でランダムに並べ替え、500回。
   - 問いB：各指定で y−b̂·d として効果を0にしてから、市区町村を復元抽出し、500回。どの指定にも同じ抽出を使いました。
4. **頑健性**
   - 指定の重み付けを変える（図5左）
   - 選択肢を1つだけ基本に固定して、答えの幅がどれだけ縮むかを見る（図5右）
   - 別の結果で同じことをする（図6）

乱数のシードは 20261103 です。

## 主な結果

### 問いA：最低賃金と就業率（288通り）

| | 値 |
|---|---|
| 推定値の中央値 | **+0.12%ポイント**（bite 1標準偏差あたり） |
| 5〜95%の幅 | −0.04〜+0.32 |
| 最小〜最大 | −0.19〜+0.38 |
| 0より大きい | 87.5% |
| 95%区間が0より上 | 13.5% |
| 95%区間が0より下（就業率が下がった） | **0%** |
| F01 の基本の指定 | +0.27（288通りの中で下から89%の位置） |

- **就業率がはっきり下がった指定は、288通りに1つもありませんでした。** 一方で、はっきり上がった指定も13.5%だけで、大半は0をまたぎます。
- F01 の基本の指定は、たまたま大きめの答えが出る側にありました。
- **ばらつきの分解：** 足し合わせで説明できるのは28%で、残りは組み合わせの効果です。どれか1つの選択肢が答えを決めているわけではありません。
  - 重み 13%
  - 処置の定義 6%
  - 追加の条件 6%
  - 期間の始まり 2%
  - 期間の終わり 1%
  - 対象 0%
- 重みを人口にすると、中央値は +0.18 から +0.09 に下がり、有意な指定の割合も22%から5%に下がりました。
- **効果0の世界との比較：**
  - 並べ替えたときの中央値は −0.21〜+0.18（95%）に散らばり、実際の +0.12 は p=0.23 でした。
  - 有意（正）の指定の割合 13.5% は、並べ替えたときの平均（どちら向きでも有意 6.8%）より多いものの、p=0.064 です。
  - 「288通りをまとめると、効果0と区別できるほどの就業率の上昇もない」と読めます。
- **完全失業率（確認）：** 中央値 −0.03%ポイント。有意に上がった指定 0.7%、下がった指定 3.5%。ばらつきの55%は「追加の条件」で、地方×年を入れると中央値は +0.01 になります。

### 問いB：保育所と出生率（528通り）

| | 値 |
|---|---|
| 推定値の中央値 | **+0.0027**（在所児 +10人あたり。出生率の平均1.42の約0.2%） |
| 5〜95%の幅 | −0.014〜+0.015 |
| 最小〜最大 | −0.025〜+0.042 |
| 95%区間が0より上 | 23% |
| 95%区間が0より下 | 18% |
| F100 の基本の指定 | 水準 −0.009（全体の下から14%）、変化 −0.004（変化の比較288通りの中でいちばん小さい） |

- **有意にプラスの指定と有意にマイナスの指定が、両方とも2割前後ありました。** 選び方によって「保育所の多い町ほど出生率が高い」とも「低い」とも言えてしまう状態です。
- **水準の比較では、「県の違いを除くか」の1つで向きが逆になりました。**
  - 県ダミーなし（120通り）：中央値 +0.011、75%が有意にプラス、マイナスは0%。
  - 県ダミーあり（120通り）：中央値 −0.010、78%が有意にマイナス、プラスは0%。
  - ばらつきの分解でも、水準の比較の中では「県の違い」が71%、「地域の条件」が12%でした。
- **変化の比較（288通り）は0の近く**です。中央値 +0.003、有意にプラス12%、マイナス0.7%。「前の値」（もとの出生率や在所児）を入れた48通りでは、中央値 −0.0005、有意にプラスは0でした。
- 全体のばらつきの分解：県の違い 32%、地域の条件 8%、比べ方 2%、そのほか各1%以下。足し合わせは43%です。
- **効果0の世界との比較：**
  - 実際の中央値 +0.0027 は p=0.092 でした。
  - 有意にプラスの割合 23% は p=0.014 で、効果0のときの平均（どちら向きでも有意 6.3%）を大きく上回ります。
  - ただし、有意にマイナスの指定も18%あります。全体として「データに何の関係もない」とは言えませんが、関係の向きは選び方で決まっていて、「保育所が出生率を上げる（下げる）」とは読めません。
- **女性の労働力率（確認）：** 中央値 +0.055%ポイント（在所児 +10人あたり）。
  - 水準の比較：66%が有意にプラス。
  - 変化の比較：有意にプラスは2.8%だけで、中央値 +0.037。
  - F100 と同じく「水準ではプラス、変化では小さい」でした。

## 頑健性チェック

| チェック | 問いA（就業率） | 問いB（出生率） |
|---|---|---|
| 等しい重み（基本） | 中央値 +0.123、5〜95% −0.04〜+0.32 | +0.0027、−0.014〜+0.015 |
| 比べ方ごとに等しい重み | — | +0.0026、−0.014〜+0.015 |
| 精度の重み（1/SE²） | +0.146、−0.01〜+0.32、有意（正）21% | +0.0017、−0.013〜+0.014 |
| 妥当と考えた指定だけ※ | +0.124（144通り）、有意（負）0% | +0.0017（336通り）、有意（正）17%・（負）18% |
| 選択肢を1つ固定 | どれを固定しても幅は最大9%しか縮まない（「2008年から」に固定すると13%広がる） | 水準：県の違いを固定で−50%、地域の条件を固定で−43%。変化：前の値を固定で−23% |
| 別の結果 | 失業率：中央値 −0.03、有意（正）0.7%・（負）3.5% | 女性の労働力率：中央値 +0.055、有意（正）31% |

※「妥当と考えた指定」は分析前の私の判断です。
- 問いA：2020〜22年を含む期間（「2022年まで」「2025年まで」）を除く。コロナの影響が県によって違うため。
- 問いB：地域の条件が「なし」「人口・密度」だけの指定を除く。

重み付けを変えても中央値の向きと大きさはほとんど変わらず、「問いAは就業率が下がった証拠なし」「問いBは向きが選び方しだい」という結論は同じでした。

## 言えないこと

- **選択肢の範囲は私が決めたものです。** 「もっともらしい選択肢」の範囲を変えれば、答えの分布も変わります。たとえば、問いAで処置の開始年や bite の作り方を変える、問いBで機械学習の手法（F100 の DML など）を入れる、といった選択肢は入れていません。
- **指定は独立ではありません。** 同じデータから作った似た推定なので、「何%の指定で有意」は、独立な証拠がその数だけあるという意味ではありません。そのため、効果0の世界との比較で判断しています。
- **すべての指定が同じくらい正しいわけではありません。** 中央値は「平均的な分析者の答え」で、正しい答えではありません。問いBの水準の比較で県ダミーを入れるかどうかは、「県の違いは交絡か、効果の通り道か」という考え方の違いで、データだけでは決められません。
- 問いA・B とも、因果効果を示すものではありません。前提（並行トレンド、条件付きの独立性）は、元の記事 F01・F100 と同じです。
- 問いAの「就業率が下がった指定が0」は、下がっていないことを示すものではありません。区間の下端は −0.8%ポイント程度まで広がる指定もあり、小さな影響があったかどうかは見分けられません。
