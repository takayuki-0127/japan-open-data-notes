# 01 取得

F155 では新しくデータを取っていません。2本の過去の記事で取得・整形したデータを、そのまま使い回しています。

| ファイル | 元の記事 | 中身 |
|---|---|---|
| `data/f01_panel.csv` | [F01 最低賃金と雇用](../../F01_minimum_wage_did/) の `data/panel.csv` | 47都道府県×2008〜2025年。最低賃金、bite（2014年度の最低賃金÷2015年の短時間労働者の平均時給）、15歳以上人口、就業率、完全失業率など |
| `data/f100_q1_level.csv`・`data/f100_q1_change.csv` | [F100 同じ問いを5つの手法で](../../F100_five_methods_one_question/) の `data/q1_*.csv` | 市区町村。保育所等に通う子ども（0〜5歳100人あたり）と合計特殊出生率（ベイズ推定値）、地域の条件 |
| `data/f100_q2_level.csv`・`data/f100_q2_change.csv` | 同 `data/q2_*.csv` | 同じく、女性の労働力率（確認用の別の結果） |

元データの出典と取得方法は、それぞれの記事の README と `src/01_*` にあります。

- 総務省「労働力調査 都道府県別結果（モデル推計値）」、厚生労働省「地域別最低賃金の全国一覧」「賃金構造基本統計調査」「職業安定業務統計」
- 総務省統計局「社会・人口統計体系 市区町村データ」、厚生労働省「人口動態保健所・市区町村別統計」
