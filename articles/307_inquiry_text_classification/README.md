# 307 問い合わせの記録を、カテゴリに自動で分ける（実務の型）

問い合わせの文を6つのカテゴリ（請求・支払い／ログイン・アカウント／配送／返品・交換／使い方／解約）に分ける仕組みを、TF-IDF（文字の並びの出やすさを数にする方法）とロジスティック回帰で作り、どこまで当たるかを架空の文で確かめたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A307 | 問い合わせ文の自動分類は、どんな文で間違え、ラベルつきの文は何件あれば足りるか | 架空の問い合わせ 3,000件（学習 2,400・テスト 600）。文字 1〜3 文字の TF-IDF＋ロジスティック回帰。キーワードの決まりと比較、学習件数を 30〜2,400 に変える、自信の高さで分ける | `src/a307_run.py`・`a307_figs.py` |

## データの作り方（架空）
`src/a307_run.py` の中で、seed 307 の乱数で作っています。実在の問い合わせではありません。
- ふつうの文（68%）：カテゴリごとの「もの」6〜7語 ×「どうした」6〜7通りの組み合わせ
- ほかのカテゴリの言葉が混ざる文（8%）：「解約したのに請求が来ています」など。ラベルは主な用件
- 用件が2つの文（10%）：2つ目に別のカテゴリの用件が続く。ラベルは先に書いたほう
- 短い文（9%）：「まだ届かない」「退会」など
- 文だけでは分からない文（5%）：「先日の件、どうなっていますか」など。どのカテゴリにも同じ文が出る
- 前後にあいさつや「急ぎです」を付け、15% の文に1文字の誤字を入れ、**学習用のラベルの 3.7% は付け間違い**にした（正解率はすべて、付け間違いのない正しいカテゴリに対して測る）

## 主な結果（テスト600件）
- 正解率は **92.7%**（間違い44件）。人が最初に書きそうなキーワードの決まり（1カテゴリ2〜3語）は 60.5% で、28% の文はどの語にも当たらなかった。データを作った言葉を全部入れた決まり（実際には手に入らない）は 90.7%
- **間違いは2種類の文に集まった**：用件が2つ（73件中 20件の間違い、正解率 73%）と、文だけでは分からない文（32件中 24件、25%）。ふつうの文・言葉が混ざる文・短い文は全件正解
- カテゴリ別の正解率は 配送 98%〜使い方 87%。取り違えの行き先でいちばん多いのは請求・支払い（解約→請求 6件、使い方→請求 4件）
- 学習の件数：30件で 43%、120件で 76%、240件で 85%、480件で 90%、960件で 92%、2,400件で 93%
- 自信（いちばん高いカテゴリの確率）が 0.7 以上の文だけを自動で分けると、**全体の 88% を 99.2% の正解率で分けられ**、残りの 12% を人が見る形になる
- ラベルの付け間違いをなくして学習すると 94.5%（+1.8 ポイント）

## 動かし方

```
pip install -r requirements.txt
cd src && python a307_run.py && python a307_figs.py
```

## 確かめたこと

## 注意
- **文は型の組み合わせで作った架空のものです。** 実際の問い合わせは言い回しがずっと多く、ふつうの文が全件正解になることはまずありません（推測）。92.7% という水準は上のほうに出ていると考えられます。言えるのは「間違いは、用件が2つある文と、文だけでは決まらない文に集まる」「自信で分ければ自動にする分の正解率を上げられる」という向きまでです
- 日本語を単語に区切らず、文字の並び（1〜3文字）で数えています。単語に区切る方法との比較はしていません
- 用件が2つの文のラベルを「先に書いたほう」とした決まりは、作成者の置き方です
