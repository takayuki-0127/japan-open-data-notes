# 435 対数に直して回帰した予測を元に戻すと、合計はどれだけ小さく出るのか（手法の解説）

金額を対数に直して回帰し、予測を元の単位に戻して足し上げると、**合計がどれだけ小さく出るか、補正はどこまで効くか**を、正解の分かる架空のデータと、市区町村の歳出の例で測ったフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A435 | 対数の回帰の予測をそのまま戻すと、合計は何%小さく出るか。分散の半分を足す補正／残差の平均で戻す補正／一般化線形モデルで、どこまで直るか | 架空：y＝exp(2.0＋0.6x＋誤差)。500件で当てはめ、別の500件の合計を本当の平均の合計と比べる。500回。公的データ：市区町村の歳出を人口から当て、5分割で確かめる | `src/a435_retransformation.py` |

## 置いたこと
- 架空のデータ：x は0〜3の一様。対数の誤差の標準偏差 σ は0.2・0.5・0.8・1.0・1.5
- 誤差の形：正規／右に偏る（ガンマ分布・形2を平均0・分散1にそろえる）／たまに大きく外れる（1割が3倍の散らばり、分散1にそろえる）
- 散らばりが x で違う場合：標準偏差＝σ×(1＋0.6×(x−1.5)/1.5)
- 戻し方：①そのまま exp(予測) ②exp(予測＋分散/2) ③exp(予測)×残差を戻した値の平均（スミアリング） ④一般化線形モデル（ガンマ・対数リンク）
- 公的データの例：`data/municipal_2022_from_F34.csv`（記事 F34 のフォルダからの写し。歳出決算総額−災害復旧費 2022年度、総人口 2020年、1,740団体）

## 主な結果
### 合計の予測のずれ（誤差が正規分布、500件）
| σ | そのまま戻す | 式 exp(−σ²/2)−1 | 分散の半分を足す | 残差の平均で戻す | 一般化線形モデル |
|---|---|---|---|---|---|
| 0.2 | −2.0% | −2.0% | −0.0% | −0.1% | −0.1% |
| 0.5 | −11.7% | −11.8% | +0.1% | +0.1% | +0.1% |
| 0.8 | −27.1% | −27.4% | +0.6% | +0.4% | +0.4% |
| 1.0 | −39.1% | −39.3% | +0.5% | +0.3% | +0.4% |
| 1.5 | −67.5% | −67.5% | +0.1% | −1.2% | −1.0% |

- σ=1.0 のとき、1回ごとのずれの散らばり：そのまま2.8%、補正した3つは5.4〜6.1%。30件では26〜27%

### 誤差が正規分布でない・散らばりが一定でない（合計のずれ）
| 場面 | そのまま戻す | 分散の半分を足す | 残差の平均で戻す | 一般化線形モデル |
|---|---|---|---|---|
| 右に偏る σ=0.5 | −15.2% | −3.9% | −0.1% | +0.1% |
| 右に偏る σ=1.0 | −64.6% | −41.4% | −0.4% | −2.2% |
| たまに大きく外れる σ=0.5 | −13.1% | −1.4% | +0.2% | +0.2% |
| たまに大きく外れる σ=1.0 | −58.4% | −31.1% | −0.1% | +2.2% |
| 散らばりが x で違う σ=0.5 | −16.9% | −4.4% | −4.1% | +0.1% |
| 散らばりが x で違う σ=1.0 | −54.6% | −20.6% | −15.4% | −1.3% |

- 散らばりが x で違う・σ=1.0：残差の平均で戻す補正は、x の小さい所で+52%、大きい所で−33%。一般化線形モデルは−1%と−4%
- 右に偏る・σ=1.0 では、残差の平均で戻す補正と一般化線形モデルの1回ごとの振れが77〜102%

### 公的データの例：市区町村の歳出を人口から当てる（当てはめに使っていない団体での合計のずれ）
| 式の形 | そのまま戻す | 分散の半分を足す | 残差の平均で戻す | 一般化線形モデル |
|---|---|---|---|---|
| 直線（人口の対数） | −23.1% | −18.4% | −17.5% | −19.2% |
| 曲線（人口の対数とその2乗） | −2.3% | +1.6% | +2.2% | +0.3% |

- 対数の残差の標準偏差：直線0.34、曲線0.28。残差の歪度は約1.0（右に偏る）
- 直線の式は、人口のいちばん小さい組で−11〜−19%、真ん中の3組で+7〜+19%、いちばん大きい組で−30〜−35%
- 1件ごとの誤差の絶対値の平均は、直線26〜29%、曲線21〜23%で、戻し方ではほとんど変わらない

全部の数字は `results/retransformation_bias.csv`、`results/theory.csv`、`results/public_example_municipal_spending.csv` にあります。

## 動かし方
```
pip install -r requirements.txt
cd src && python a435_retransformation.py      # 約20秒
```
`data/example_sigma1.csv`、`results/` の4ファイル、`figures/` の3枚ができます。

## 確かめたこと
- 空のフォルダで計算し直し、data・results・figures が一致した
- そのまま戻した場合のずれが、式 exp(−σ²/2)−1 と0.4ポイント以内で合う
- 誤差が右に偏る場合の本当の平均は、ガンマ分布の式から計算した

## 注意（言えないこと）
- 架空のデータの数字は、式の形・500件・誤差の形の置き方で決まります。説明する変数が多い場合は試していません
- 一般化線形モデルは、ガンマ分布・対数リンクの1通りです
- 市区町村の例は1時点の関係で、人口のほかに何が歳出を決めているかは扱っていません。個々の団体の歳出が多い・少ないを言うものでもありません
- 曲線の式が正しい形だと言うものではありません。いちばん小さい組では、曲線でも2〜10%小さく出ています
- この記事で扱ったのは、合計や平均のずれです。1件ごとの当たり外れは、戻し方ではほとんど変わりません
