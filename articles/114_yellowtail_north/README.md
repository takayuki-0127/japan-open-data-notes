## もとのリポジトリの説明

以下は、もとのリポジトリ `marine-fisheries-japan` の README です（同じリポジトリにあったほかの記事の分も含みます）。

### marine-fisheries-japan：農林水産省「海面漁業生産統計調査」で、魚種別の漁獲量の69年と、ブリの北上を調べる

農林水産省「海面漁業生産統計調査」（漁業・養殖業生産統計）の魚種別漁獲量の累年統計（全国・39都道府県、1956〜2015年）と、年別の「大海区都道府県振興局別 魚種別漁獲量」（2003〜2024年）を使ったリポジトリです。養殖業と内水面は含みません。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| W1 | 魚種別の漁獲量は、いつから減ったか・増えたか | 全国の魚種別漁獲量（1956〜2024年）のピークの年と2024年のピーク比、log10(漁獲量)の平均水準の変化点（ruptures の動的計画法、区間数はBICで選び最大4つ、各区間5年以上） | `src/w1_species.py` |
| W2 | ブリ類は北で獲れるようになったか | 都道府県別ぶり類漁獲量の地域別割合、漁獲量で重みをつけた県庁所在地の緯度の平均（重心緯度）、気象庁の日本近海の海面水温（年平均の平年差）との相関（水準・前年差・直線トレンド除去後） | `src/w2_buri.py` |

#### 主な結果
- **W1**：海面漁業の漁獲量はピークの1984年の1,150万トンから2024年は279万トン（ピークの24%）。水準の変化点は1968・1992・1998・2011年。2024年のピーク比は、するめいか3%（ピーク1968年の66.8万トン→2.0万トン）、すけとうだら4%（1972年の304万トン→12.4万トン）、さんま7%（1958年の57.5万トン→3.9万トン、2022年は1.8万トン）、さけ類16%（1996年の28.7万トン→4.7万トン）。直近の変化点は、さんま2019年、するめいか2016年、さけ類2017年。まいわしは1988年の449万トンから2000年代に10万トン前後まで減ったあと、2015年以降に増えて2024年は66.6万トン。ぶり類は2010年以降の平均が10.5万トンで、ピークは2014年の12.5万トン（2024年は8.1万トン、ピークの65%）
- **W2**：ぶり類漁獲量に占める北海道の割合は1956〜65年平均2.2%、1976〜85年0.6%、2016〜24年11.9%、2024年は19.9%。重心緯度（県庁所在地の緯度で代用）は1956〜65年平均35.50度→2016〜24年36.32度、2024年36.88度。1990〜2024年の傾きは10年あたり0.41度。日本近海の海面水温（13海域平均）との相関は、水準で0.74（北海道の割合）だが両方とも上がっているためで、前年差どうしでは0.18、三陸沖の水温とは0.36

#### データ
| ファイル | 中身 |
|---|---|
| data/national_species.csv | 全国×年×魚種の漁獲量（t、1956〜2024年、111項目、小計・計を含む） |
| data/pref_species.csv | 39都道府県×年：漁獲量計、ぶり類、さんま、さけ類、するめいか、まいわし（t）。src＝累年（1956〜2015年）／年別（2003〜2024年） |
| data/sst_japan.csv | 気象庁：日本近海の海面水温の年平均の平年差（℃、13海域平均と3海域） |

#### 注意
- 都道府県別の漁獲量は、獲った海域ではなく、漁業経営体（漁船）の所属する都道府県で集計されています。北海道の割合が増えたことは「北海道の漁業者がより多く獲った」ことで、北海道の沖で獲れたとは限りません
- 重心緯度は、各都道府県の漁獲量を県庁所在地の緯度に置いた近似です。北海道は札幌の43.06度で代表させています
- 累年統計（〜2015年）と年別の表（2003年〜）は、重なる2003〜2015年のぶり類が全都道府県・全年で一致しました。2003年以降は年別の表を使っています
- 2012〜2013年は福島県と岡山県のぶり類が秘匿（x）のため欠けていて、都道府県の合計が全国より最大2,382トン少なくなっています。沖縄県は1962年からです
- ぶり類には、ぶり・わらさ・いなだ・はまち・ひらまさ・かんぱちなどが含まれます。養殖のぶり類は含みません
- 変化点は、漁獲量の対数の平均が段差のように変わる年を探したものです。年ごとの値には自己相関があるため、BIC はどの魚種でも上限の4つを選んでいて、変化点の数に強い意味はありません。区間の切れ目の位置の目安として使ってください
- 海面水温との相関は、因果関係を示すものではありません。両方とも上がっている系列どうしは、関係がなくても水準の相関が高くなります
