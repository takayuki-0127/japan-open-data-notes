# 731 「上位10%の顧客で売上の何割」を、買わなかった会員を含めて数えるか除くかで、どれだけ違うのか（実務の型）

「上位10%の顧客が売上の何割を占めるか」は、売上の集中を見るよく使う数字です。ところが「10%」の分母を、その期間に買った人にするか、会員全員（買わなかった人を0円として含める）にするかで、上位10%の人数が変わり、シェアも大きく変わります。**ここでは、架空の会員10,000人の12か月の購入で、2通りの分母で上位10%の売上シェアを出し、集計の期間を1〜12か月に変えて比べました。** DuckDB の SQL と Python で同じ値になることを確かめています。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A731 | 上位10%の売上シェアは、分母の人の取り方でどれだけ違うか | 架空の会員10,000人。買う頻度はガンマ分布（形0.35、月平均0.4回）、1回の金額は対数正規（中央値3,000円）。「買った人だけ」と「会員全員（0円を含む）」の上位10%のシェアを、期間1・3・6・12か月で。seed 731 | `src/a731_top_share.py`、`src/02_top_share_duckdb.sql`、`src/01_top_share_tsql.sql`（T-SQL：未検証） |

## 主な結果
| 集計の期間 | 買った人 | 会員全員の上位10%（1,000人）のシェア | 買った人だけの上位10%のシェア | 差 |
|---|---|---|---|---|
| 1か月 | 2,316人（23.2%） | **75.1%** | **32.2%**（232人） | 42.8ポイント |
| 3か月 | 4,054人（40.5%） | 60.6% | 35.7%（406人） | 24.8ポイント |
| 6か月 | 5,161人（51.6%） | 55.8% | 37.8%（517人） | 18.0ポイント |
| 12か月 | 6,064人（60.6%） | 53.2% | 39.4%（607人） | 13.8ポイント |

- 同じ12か月の売上でも、「上位10%で売上の53%」とも「39%」とも言える。上位10%の人数が1,000人と607人で違うため
- 期間が短いほど買わない会員が増え、2つの数え方の差は1か月で42.8ポイントまで開いた
- 会員全員で数えたシェアは期間が短いほど高く、買った人だけで数えたシェアは期間が短いほど低くなり、向きも逆だった

## 確かめたこと
- 空のフォルダで流し直し、results・figures・data が一致した
- 4つの期間の2通りのシェアと買った人の数が、DuckDB の SQL と Python で一致すること（assert）

## データ
- `data/members.csv`：架空の会員番号（10,000人）
- `data/purchases.csv`：架空の会員番号・月（1〜12）・その月の購入金額（円）。買わなかった月の行はない。作成者が乱数で作ったもの（seed 731）

## 注意（言えないこと）
- 架空のデータです。買う頻度と金額の分布は作成者が置いたもので、シェアの大きさはこれで決まります
- どちらの分母が正しいということはありません。数字を出すときに、分母（買った人か、会員全員か）と期間を書き添える必要があります
- T-SQL の書き方は SQL Server では試していません（未検証）
