# 197 騒音の苦情の発生源は、工場から何に変わったか：公害苦情調査

総務省公害等調整委員会「公害苦情調査」から、全国の地方公共団体が受け付けた騒音の苦情を、発生源の産業別（2004〜2024年度）と主な発生原因別（2022・2024年度）に並べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A197 | 騒音の苦情の発生源は、20年でどう変わったか | 発生源（産業）別の件数と割合の推移、2004年度と2024年度の比較、主な発生原因別の件数 | `src/a197_noise.py` |

## 主な結果
- 騒音の苦情は2004年度15,689件→2019年度15,434件とほぼ横ばいだったが、2020年度に19,769件へ増え、2024年度は18,811件（2004年度比+19.9%）
- 製造業が発生源の苦情は2,553件→1,467件（−42.5%）、割合は16.3%→7.8%
- 建設業は4,557件→7,237件（+58.8%）、割合は29.0%→38.5%。建設業は製造業の1.8倍→4.9倍
- 2019→2020年度の増加4,335件のうち、建設業が1,501件、個人が622件、飲食店・宿泊業が508件
- 2024年度の主な発生原因は工事・建設作業7,440件（39.6%）、産業用機械の作動2,883件（15.3%）、飲食店の営業1,144件（6.1%）、カラオケ740件（3.9%）。家庭生活（機器・ペット・その他）は合わせて1,302件（6.9%）

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a197_noise.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/noise_by_source.csv | 年度、騒音の苦情の合計、発生源の産業別の件数（会社・事業所）と、会社・事業所以外（個人・その他・不明） |
| data/noise_by_cause.csv | 2022・2024年度の騒音の苦情の主な発生原因別の件数 |

- 公害の種類、発生源別苦情件数の推移：平成18年度（statInfId 000008552270、2004〜2006年度）、平成23年度（000016447458、2007〜2011年度）、平成28年度（000031646305、2012〜2016年度）、令和3年度（000032265157、2017〜2021年度）
- 公害苦情受付件数（公害の種類、発生源別）第6表：令和4年度（000040124545）、令和5年度（000040228211）、令和6年度（000040368518）
- 公害苦情受付件数（公害の種類、主な発生原因別）第5表：令和4年度（000040124544）、令和6年度（000040368517）
- ブラウザで Excel を読み、騒音の件数の行を書き写した。各年度で内訳の合計が騒音の合計と一致することを確かめた

## 注意
- 件数は地方公共団体が受け付けた苦情の数で、騒音の量や被害の大きさではない
- 産業の分類は2019年度から変わり（学術研究、生活関連サービス業などが分かれた）、2016年度以前の「飲食店、宿泊業」と2017年度以降の「宿泊業、飲食サービス業」は範囲が少し違う。そのため細かい産業は「その他の会社・事業所」にまとめた
- 2001〜2003年度は産業の分類が違うため使わなかった
- 主な発生原因の表は、古い年度と分類が違うため2022・2024年度だけを使った
- 苦情が増えた理由（工事の量、在宅時間、住まいの近さなど）は、このデータでは分けられない
