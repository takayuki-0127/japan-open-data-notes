# F131 大学に進む人が増えると、地元に残る若者は減るのか？（固定効果パネルと分解）

看板記事 F131。文部科学省「学校基本調査」の出身高校の所在地県別 大学入学者数（47×47 の行列、2005〜2025年度）と、総務省「住民基本台帳人口移動報告」の年齢別 転入超過数（日本人、2010〜2025年）を組み合わせ、大学に進む人の増加が、県外への進学や15〜19歳の転出とどう結びついているかを見ました。

## 問い
- 大学に進む人が増えるほど、県外の大学に出ていく若者は増えたのか
- 県外の大学へ出る人の数の変化は、「高校卒業者の数」「大学に進む多さ」「県外の大学を選ぶ割合」のどれで動いたのか
- 進学が伸びた県ほど、15〜19歳の転出（住民票の移動）は増えたのか

## データ
| データ | 期間 | 出所 | 使い方 |
|---|---|---|---|
| 出身高校の所在地県別 入学者数（大学、短期大学） | 2005〜2025年度 | 文部科学省「学校基本調査」高等教育機関 学校調査（e-Stat） | 大学の所在地×出身高校の所在地の入学者数。計・国立・私立・男（2021年度以降は女も計算可） |
| 年齢（5歳階級）、男女別転入超過数－都道府県 | 2010〜2025年 | 総務省「住民基本台帳人口移動報告」年報 第3-3表（e-Stat） | 日本人移動者の15〜19歳・20〜24歳の転入超過数 |
| 高等学校卒業者数・中学校卒業者数 | 2012〜2023年度 | 統計センター「SSDSE-B-2026」（元は学校基本調査） | 分母。SSDSE-B の「年度」t の卒業者は t+1 年3月の卒業者なので、1年ずらして入学年度にそろえた |

statInfId は `src/01_取得.md` にまとめています。

## 手法
都道府県 p・入学年度 t について、次の量を作りました。

- E：p の高校出身の大学入学者（どこの大学でも）、S：そのうち p の大学に入った人、O = E − S（県外の大学へ）
- I：他県の高校出身で p の大学に入った人
- G：p の高校卒業者数
- **大学に進む多さ r = E / G**（過年度卒を含むので「率」ではなく目安）
- **県外の大学を選ぶ割合 o = O / E**
- **15〜19歳の転入超過 m15 = 15〜19歳の転入超過数（日本人）/ G**

1. **全国の推移**（2005〜2025年度）：o の推移（全国、大都市圏8都府県以外、47都道府県の中央値）、r の推移（2013〜2024年度）
2. **分解**：ln O = ln G + ln r + ln o なので、2013→2024年度の O の変化を3つの寄与に分けた（全国、大都市圏8都府県以外、大都市圏8都府県）。大都市圏8都府県＝埼玉・千葉・東京・神奈川・愛知・京都・大阪・兵庫
3. **県ごとの変化**：r の伸びと、o の変化・m15 の変化の相関
4. **固定効果パネル**：m15 を r と o に回帰。都道府県と年の固定効果、県でクラスターした標準誤差（2013〜2024年度、47県×12年＝564）
5. **住民票への表れ方**：県の平均で、m15 を「大学入学の出入り（I − O）/ G」に回帰した傾き。データの仕組みどおりなら期待される r の係数（−o の平均 × 傾き）も計算

## 結果
- **大学に進む人は増え、県外の大学を選ぶ割合はゆるやかに下がった。**
  - r は全国で 0.551（2013年度）→ 0.661（2024年度）。47都道府県すべてで上がった。
  - o は全国で 58.7%（2005年度）→ 54.6%（2025年度）。大都市圏8都府県以外では 67.2% → 63.9%、47都道府県の中央値は 75.5% → 70.5%。2013→2024年度で o が下がったのは 33県（7割）。
- **県外の大学へ出る人の数はほぼ横ばい。** 2013→2024年度の O の変化は全国で −1.2%（339,176人 → 335,023人）。内訳（対数差×100）は次のとおり。
  - 高校卒業者数：−16.9
  - 大学に進む多さ：+18.3
  - 県外の大学を選ぶ割合：−2.6
  - 大都市圏8都府県以外では O は −2.9%（卒業者 −21.5、進学 +20.1、県外の割合 −1.5）
- **進学が伸びた県ほど 15〜19歳の転出が増えたわけではない。**
  - 県ごとの r の伸びと m15 の変化の相関は +0.09。
  - 固定効果パネルで r の係数は +0.019（95%区間 −0.107〜+0.146、p=0.76）。o の係数は −0.074（−0.179〜+0.031）。
  - r の伸びと o の変化の相関は +0.55（伸びが最も大きい1県を除くと +0.23）。
- **住民票の移動に表れるのは、大学入学の出入りの一部。**
  - 県の平均で、m15 を大学入学の出入りに回帰した傾きは 0.23（相関 0.63）。固定効果パネルでは 0.11（0.04〜0.17）。
  - この表れ方を前提にすると、データの仕組みどおりなら r の係数は −0.07〜−0.15 程度になるはず。推定の区間（−0.107〜+0.146）は0を含み、−0.07 も含む。「効果がない」とまでは言えず、「このデータでは見えない」にとどまる。
- **20〜24歳：** 4年前に県外の大学へ出た人が多い県ほど、20〜24歳の転入超過も小さい（相関 −0.25）。ただし固定効果パネルでは係数 −0.03（−0.40〜+0.34）で、はっきりしない。
- **男女：** 2021〜2025年度の o は男性 56.5〜57.6%、女性 52.5〜52.9% で、男性のほうが県外の大学を選ぶ割合が高い。

## 頑健性
固定効果パネル（m15 を r と o に回帰）の r の係数を、条件を変えて推定し直しました（`results/results.json` の robust）。

| 条件 | r の係数 | 95%区間 |
|---|---|---|
| 基本（2013〜2024年度） | +0.019 | −0.107〜+0.146 |
| 期間 2013〜2018年度 | +0.023 | −0.116〜+0.163 |
| 期間 2019〜2024年度 | −0.009 | −0.166〜+0.149 |
| 2020・2021年を除く | +0.011 | −0.119〜+0.142 |
| 男性の転入超過 | +0.066 | −0.109〜+0.240 |
| 女性の転入超過 | −0.027 | −0.145〜+0.092 |
| 大都市圏8都府県を除く | −0.027 | −0.155〜+0.101 |
| 分母を3年前の中学卒業者 | +0.007 | −0.134〜+0.149 |
| 高卒者数で重みづけ | +0.107 | −0.065〜+0.279 |
| 大学＋短期大学 | +0.011 | −0.114〜+0.135 |
| 県外の割合を私立だけで | −0.001 | −0.129〜+0.127 |
| 県外の割合を国立だけで | +0.002 | −0.116〜+0.120 |

どの条件でも区間は0を含みました。分解の向き（卒業者の減少と進学の増加が打ち消し合い、県外の割合は少し下がる）は、全国・大都市圏以外・大都市圏のどれでも同じでした。

## 言えないこと
- 住民票を移さない学生が多いとみられ（推測）、15〜19歳の転入超過は大学進学による移動の一部しか映していません。「地元に残る若者」を住民票の移動で測ると、実際の移動を小さく見積もります。
- r は「大学入学者 ÷ その年の高校卒業者」で、過年度卒を含みます。文部科学省の公表する大学進学率とは定義が違います。
- 出身高校の所在地で見ているので、県外の高校に通った人や、高卒認定などで入学した人（表の「その他」）は扱っていません。
- 県と年の固定効果を入れた後に残る r のばらつきは小さく（標準偏差 0.014）、効果があっても見つけにくい設計です。「関係がない」ではなく「このデータでは見えなかった」です。
- 就職・専門学校への進学・卒業後のUターンは、この分析の対象外です。20〜24歳は参考に見ただけです。
- 都道府県の集計値だけを使っています。個人の進路の選び方はわかりません。特定の県の良し悪しを示すものではありません。
