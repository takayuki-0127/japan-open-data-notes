# 1074 力の近い人どうしを当てると、勝率はなぜ皆5割に近づくのか？（対戦とレーティング）

対戦ゲームでは、点数の近い人どうしを当てる組み方がよく使われます。すると、強い人も弱い人も勝率が5割前後にそろい、「勝率を見ても誰が強いか分からない」ことが起きます。理由は単純で、自分とほぼ同じ強さの相手には、勝つ確率がほぼ5割になるからです（式どおり）。**ここでは、作成者が乱数で作った架空の対戦ゲームのリーグ（2,000人の本当の強さを作成者が置いたもの）で、相手を ①でたらめに決める ②点数の近い人どうしにする ③本当の強さの近い人どうしにする（参考。実際にはできない）の3つの組み方で400試合させ、後半200試合の勝率と最後の点数が、本当の強さをどれだけ表すかを数えました。置き方を変えた27通りでも確かめました。**

ここでいう「点数の付け方」は、勝つと点数が上がり、負けると下がり、その幅を「点数の差から見込んだ勝つ確率」で変える一般的なやり方です（実在のゲームや方式を表すものではありません）。

初めの点数をいくつにするかで新しく入った人の順位がずれることは同じ企画の関連する記事 1065、1試合で動かす点の幅の大きさは 1066、対戦の相手を自分で選べるときの点数の上がり方は 1068、キャラクターごとの勝率が使う人のうまさで動くことは 1069、シーズンの初めに点数を戻したときの上位の入れかわり（点数の近い人どうしを当てると点数の差が広がる向きも数えた）は 1075、総当たりでない記録で当たった相手の偏りが勝率に入る話は 1076 で扱っています。実力差と偶然の逆転の起きにくさは 836、勝率6割のチームが短い試合数で負け越す確率は 825 で扱っています。この記事は、相手の組み方で「勝率」という物差しが何を表すようになるかに絞ります。

## 主な結果

### 組み方ごとの後半200試合の勝率と最後の点数（基本、`results/by_mode.csv`）
| | ①でたらめ | ②点数の近い人どうし | ③本当の強さの近い人どうし（参考） |
|---|---|---|---|
| 勝率が45〜55%に入る人 | 18.25% | **94.6%** | 83.5% |
| 勝率の標準偏差 | 20.05ポイント | **2.75ポイント** | 3.78ポイント |
| 1試合ごとの本当の勝つ確率と5割との差（平均） | 16.47ポイント | 3.08ポイント | 1.39ポイント |
| 勝率と本当の強さの順位相関 | 0.986 | **0.825** | 0.405 |
| 最後の点数と本当の強さの順位相関 | 0.966 | **0.974** | 0.92 |
| 強さの上位10%の人の勝率（平均） | 83.88% | 53.98% | 52.77% |
| 強さの上位10%（200人）を勝率の上位200人で当てた割合 | 90.5% | 55.0% | 23.0% |
| 同じく、点数の上位200人で当てた割合 | 84.0% | 84.0% | 69.5% |

- **点数の近い人どうしを当てると、勝率が45〜55%に入る人は18.25%から94.6%に増えた**。相手の本当の強さと自分の本当の強さの相関は0.993で、1試合ごとの本当の勝つ確率は平均で5割から3.08ポイントしか離れていなかった。勝率が5割に集まるのは、ほぼ同じ強さの相手と当たるからで、式どおりの向き
- 同じ強さの相手とだけ200試合すれば、勝率が45〜55%に入るのは二項分布の式で86.26%（勝率の標準偏差は3.54ポイント）。③（参考）の83.5%はこれに近い
- ②では、勝率の散らばり（2.75ポイント）が、1試合ごとの勝つ確率から見込んだ偶然の散らばり（3.53ポイント）の0.781倍と、偶然の分より小さかった。勝ちが続くと点数が上がって強い相手と当たり、負けが続くと弱い相手と当たるので、勝率が5割に引き戻される
- **強さは勝率ではなく点数に出た**。②では、勝率と本当の強さの順位相関は0.825に下がったが、点数は0.974だった。強さの上位10%を勝率で当てられたのは55.0%、点数では84.0%
- 強さの上位10%の人の勝率は、最初の20試合では75.5%、最後の20試合では53.35%だった（`results/blocks_rating_mode.csv`）。点数が本当の強さまで上がると、強い相手と当たるようになり、勝率が5割に下りてくる。下位10%は25.07%から47.27%に上がった

### 置き方を変えると（②点数の近い人どうし、27通り、`results/grid.csv`）
- 勝率が45〜55%に入る人は32.25〜97.9%。勝率と本当の強さの順位相関は0.461〜0.979と大きく動いた
- 組むときのゆらぎが0（いつも点数がいちばん近い人と当てる）の9通りでは順位相関0.461〜0.557、ゆらぎ200（相手の点数がかなりばらつく）の9通りでは0.955〜0.979。相手が「近い」ほど、勝率は強さを表さなくなる
- 点数の順位相関（0.81〜0.991）が勝率の順位相関を上回ったのは27通り中22通り。上回らなかった5通りは、すべてゆらぎ200の通りだった
- 勝率の散らばりが偶然の分より小さかったのは27通り中15通り（ゆらぎ0の9通りすべてと、ゆらぎ50の6通り）
- ①でたらめでは、勝率が45〜55%に入る人は散らばり100・200・300でそれぞれ30.2%・17.7%・14.9%（`results/a1074_main.json` の `random_by_sd`）

### 点数の「差」の物差しもずれる
- ②では、最後の点数を本当の強さに直線で当てはめた傾きが1.45だった（①は1.04）。点数の順番は合っていても、点数の差が本当の強さの差の約1.45倍に広がっていた。ほぼ5割の相手としか当たらないので、「差が何点なら勝つ確率は何%か」を確かめる試合が少ないため（推測）
- 27通りでは傾きが0.5〜5.83と大きく動いた。ゆらぎ200の9通りでは0.89〜1.31

## 注意（言えないこと）
- 架空のデータです。本当の強さの散らばり、勝つ確率の式、点の幅、組むときのゆらぎは作成者が置いたもので、結果はこれで決まります。勝率が45〜55%に入る人の割合は、置き方で32.25〜97.9%と動きました
- 本当の強さは400試合の間変わらないと置きました。うまくなる人・下手になる人がいると、勝率が5割から離れる人が増えます（推測）
- 全員が同じ回数だけ対戦すると置きました。たまにしか対戦しない人との比べ方は、同じ企画の1067の問いです
- 実在の対戦ゲームの組み方や点数の付け方を表すものではありません。どの組み方がよいかの助言ではなく、組み方で勝率という物差しが何を表すかが変わることを数えただけです
