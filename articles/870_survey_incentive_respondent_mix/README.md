# 870 謝礼を付けると、回答者の構成はどう変わるのか？（アンケート）

アンケートに謝礼を付けると、答える人が増えます。ただし、増えるのは「もともと答えてくれる人」と同じ顔ぶれとは限りません。謝礼が誰に効くかで、回答者の構成は全体に近づくことも、全体から離れることもあります。**ここでは、作成者が乱数で作った架空のサービスの利用者2万人（利用の多さと、本当に満足しているかを作成者が置いたもの）で、謝礼なし・利用の少ない人に効く謝礼（謝礼A）・利用の多い人に効く謝礼（謝礼B）の3つの条件で回答者の構成と「満足の割合」の見積もりを比べました。**

回答が少ない層の割合をどこまで読めるかは関連する記事 865、途中でやめた人の扱いは 866 で扱っています。この記事は「謝礼で答える人の顔ぶれがどう変わるか」に絞ります。

## 主な結果

### 3つの条件の回答者（400回の平均）
| 条件 | 回答率 | 回答者数 | 利用が少ない | 中くらい | 利用が多い |
|---|---|---|---|---|---|
| （利用者全体） | | | 40% | 35% | 25% |
| 謝礼なし | 11.0% | 441人 | **18.2%** | 33.1% | 48.7% |
| 謝礼A（利用の少ない人に効く） | 18.9% | 757人 | **34.7%** | 32.6% | 32.7% |
| 謝礼B（利用の多い人に効く） | 18.4% | 736人 | **15.1%** | 30.3% | 54.7% |

- 謝礼なしでは、回答者の半分近く（48.7%）が利用の多い人で、全体の25%の約2倍だった
- 謝礼Aでは利用の少ない人が18.2%から34.7%に増え、全体の構成（40%）に近づいた。謝礼Bでは15.1%に減り、全体から離れた
- 回答率は謝礼Aと謝礼Bでほぼ同じ（18.9%と18.4%）だった。回答率だけでは、構成が近づいたか離れたかは分からない

### 満足の割合の見積もりのずれ（見積もり − 本当の割合、ポイント、400回）
| 条件 | 回答者そのまま（平均） | 5〜95%の範囲 | 利用の多さで重み付け（平均） | 5〜95%の範囲 |
|---|---|---|---|---|
| 謝礼なし | **+15.0** | +11.8〜+18.1 | +9.4 | +5.0〜+13.6 |
| 謝礼A（利用の少ない人に効く） | **+6.6** | +3.9〜+9.4 | +4.5 | +1.6〜+7.2 |
| 謝礼B（利用の多い人に効く） | **+12.5** | +9.7〜+15.1 | +5.8 | +2.1〜+9.6 |

- どの条件でも、満足の割合は本当より高く出た（満足している人ほど答えやすいと置いたため）
- 利用の多さで重み付けすると、構成のずれの分は消えるが、同じ区分の中で満足している人ほど答えやすい分は残った。謝礼なしで、利用の少ない回答者の満足の割合は平均56.2%（本当は45%）だった
- 謝礼につられて答える道は満足と関係がないと置いたので、謝礼を付けると、同じ区分の中のずれも薄まった（重み付けのずれ：謝礼なし+9.4 → 謝礼A+4.5・謝礼B+5.8）

### 確かめ：満足している人の答えやすさ×謝礼の効き方の強さ（回答者そのままのずれ、ポイント、各200回）
| 満足している人の答えやすさ | 謝礼なし | 謝礼A 0.5倍 | 謝礼A 1倍 | 謝礼A 2倍 | 謝礼B 0.5倍 | 謝礼B 1倍 | 謝礼B 2倍 |
|---|---|---|---|---|---|---|---|
| 1.0倍（満足と関係なし） | +6.55 | +3.09 | +0.96 | −0.85 | +7.84 | +8.43 | +9.23 |
| 1.6倍（基本） | +15.22 | +9.65 | +6.58 | +2.84 | +13.59 | +12.61 | +11.47 |
| 2.5倍 | +21.43 | +15.62 | +11.50 | +6.80 | +18.74 | +16.54 | +14.23 |

- 謝礼Aは、どの置き方でも謝礼なしよりずれを縮めた（+6.55〜+21.43 → −0.85〜+15.62）
- **謝礼Bの向きは置き方で逆転した**。満足と答えやすさが関係ない（1.0倍）と、謝礼Bは構成を全体から離すだけなので、ずれは+6.55から+8.43〜+9.23に広がった。満足している人が答えやすい（1.6倍・2.5倍）と、同じ区分の中のずれが薄まる分が勝ち、ずれは縮んだ
- 満足と答えやすさが関係ない（1.0倍）ときは、利用の多さで重み付けすると、どの条件でもずれは±0.3ポイント以内になった（`results/sensitivity.csv`）
- 基本の置き方の謝礼なしのずれは、本表（400回）で+15.0、確かめ（別の乱数で200回）で+15.2だった

### 1回分のデータ（data/users.csv）
- この回の本当の満足の割合は58.5%。謝礼なしの回答者は433人（利用の少ない人19.2%、満足の割合70.9%）、謝礼Aは752人（35.8%、63.2%）、謝礼Bは733人（16.1%、69.2%）だった

## 動かし方
```
pip install -r requirements.txt
cd src && python a870_incentive.py
```
5秒ほどで終わります。`data/users.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約4秒）
- 満足している人の答えやすさと謝礼の効き方の強さを変えると、回答者そのままのずれは−0.85〜+21.43ポイントと大きく動いた（上の表）。「+15.0 → +6.6」はこの置き方での値
- 謝礼Aがずれを縮める向きは9通りすべてで同じだった。謝礼Bは、満足と答えやすさの関係の置き方で、ずれを広げる向きにも縮める向きにもなった

## データ
- `data/users.csv`：架空の利用者2万人（1回分）。user_id・segment（利用の多さの区分）・satisfied（本当に満足しているか、1/0）・invited（回答をお願いした4,000人、1/0）・answered_0／answered_1／answered_2（謝礼なし／謝礼A／謝礼Bで答えたか。3つの条件は同じ乱数で比べた）

## 注意（言えないこと）
- 架空のデータです。区分ごとの満足の割合、もともとの答えやすさ、謝礼が誰にどれだけ効くかは作成者が置いたもので、結果はこれで決まります。とくに「謝礼Bでずれが広がるか縮むか」は、満足している人の答えやすさの置き方で逆転します
- 謝礼につられて答える道は、満足しているかと関係ないと置きました。謝礼目当ての人が不満を書きやすい・満足と書きやすい、といった偏りや、謝礼目当ての雑な回答は入れていません（同じ選択肢ばかり選ぶ回答は関連する記事 867）
- 重み付けは、利用の多さの区分が利用記録で全員分かると置きました。区分が分からないときは使えません
- 謝礼の金額や種類をどう決めるべきかは、ここでは言えません。謝礼が誰に効くかは、実際のアンケートで回答者の構成を利用記録と比べて確かめる必要があります（推測）
- 実在のサービスやアンケートを表すものではありません
