# 878 混雑の予測を出すと、空いている時間に人が集まって外れるのか？（待ち時間と混雑）

時間帯ごとの混雑の予測（予想待ち時間）を出すと、それを見た人が「空いている」とされた時間帯に移ります。移る人が多いと、その時間帯が混み、予測は外れます。**ここでは、作成者が乱数で作った架空のテーマパークの人気の乗り物（1時間に乗れる人数、乗りたい人の数と行きたい時刻、予測を見た人の動き方を作成者が置いたもの）で、4つの予測の出し方（出さない／人が動く前の混み方をそのまま出す／前日の実際を出す／人の動きを織り込んで出す）を比べ、予測の外れと実際の待ちを数えました。**

利用の割合が8割を超えると待ちが急に伸びる話は関連する記事 874、行列の長さと待ち時間の違いは 879、開店直後の行列は 883 で扱っています。この記事は「予測を出したことで、人の動きが変わり、予測そのものが外れる」に絞ります。

## 主な結果

### 予測の出し方ごとの外れと待ち（見る人4割・前後2時間・揺らぎ0、30回×50日）
| 予測の出し方 | 全員の平均の待ち | いちばん混む時間帯の待ち | 予測の外れ（時間帯ごとの差の平均） | 人が移ってきた時間帯の「実際−予測」 |
|---|---|---|---|---|
| 予測を出さない | 54.5分 | 106.7分 | （3.45分） | − |
| 人が動く前の混み方をそのまま出す | **73.9分** | 135.9分 | **30.9分** | **+14.8分** |
| 前日の実際の待ちを出す | 46.9分 | 99.4分 | 28.5分 | +13.1分 |
| 人の動きを織り込んだ予測 | 14.4分 | 41.9分 | 16.9分 | −9.4分 |

- 「予測を出さない」の外れ（3.45分）は、人が動く前の混み方の予測を、だれも見ずに動かなかった場合の外れで、日ごとの来る人数の揺れだけから出る大きさ
- 人が動く前の混み方をそのまま出すと、予想3.0分の11時台は実際37.2分、予想16.3分の12時台は86.4分になった。人が移ってきた時間帯では、実際の待ちが予測より平均14.8分長かった
- いちばん混む時間帯は、予想の16時台（106.3分）から15時台（137.7分）に移った。予測で空くとされた昼前に人が集まり、その列が午後まで残ったため
- この出し方では、全員の平均の待ちも、予測を出さないとき（54.5分）より長くなった（73.9分）。予想が低い昼前に人が寄り、夕方の空いた時間が使われなくなった（`data/one_day.csv` の1日では、11時台が650人→1,341人、18時台が368人→226人）
- 前日の実際の待ちを出すと、空く時間帯が日ごとに入れ替わった（図2）。予測の外れは28.5分で、人が動く前の予測と同じくらい外れた
- 人の動きを織り込んだ予測は、平均の待ちを14.4分まで下げた。ただし全員が同じ計算で選ぶ置き方では、予測と実際がそろう値が見つからず、外れは16.9分残った

（ずらせる幅は前後2時間。全16通りは `results/sensitivity.csv`）

- **人が動く前の混み方をそのまま出す予測は、16通りすべてで外れた（外れ5.9〜46.1分）**。見る人が多いほど、選び方がそろうほど（揺らぎが小さいほど）、ずらせる幅が広いほど外れは大きかった。人が移ってきた時間帯の「実際−予測」は+0.5〜+30.8分
- この予測を出すと、16通りすべてで全員の平均の待ちが出さないときより長くなった（+0.2〜+29.2分）。揺らぎ15分・見る人10%では、ほぼ同じ（54.37分と54.65分）
- 人の動きを織り込んだ予測は、揺らぎがある置き方（10通り）では外れが3.31〜3.53分で、だれも動かないときの日ごとの揺れの分（3.33〜3.62分）とほぼ同じ大きさだった。揺らぎ0（全員が同じ計算で選ぶ）では3.9〜23.7分で、見る人が多いほど外れた
- 前日の実際を出す予測で、平均の待ちが出さないときより長くなったのは16通りのうち12.5%（2通り）、織り込んだ予測では6.2%（1通り）だった

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の9ファイルがバイト単位で一致した（cmp、約5秒）
- 「人が動く前の混み方をそのまま出すと、人が移った時間帯で予測が外れる」向きは、16通りすべてで同じだった。外れの大きさ（5.9〜46.1分）は、置いた見る人の割合・選び方の揺らぎ・ずらせる幅で大きく動く。「30.9分」は基本の置き方での値
- 予測を出さないときの平均の待ちは、16通りで53.9〜54.6分とほぼ一定だった（予測を見ないので、置き方の違いは効かない）
- 人の動きを織り込んだ予測が、揺らぎ0で外れるのは、全員が同じ計算で選ぶと、少しの予想の違いで全員が同じ時刻に動くためと考えている（推測）。この置き方は、作成者が置いた極端な選び方である

## データ
- `data/one_day.csv`：架空の1日（見る人4割・人が動く前の予測を出した日と、出さなかった日）。hour（時間帯）・preferred（行きたい時刻の人数）・arrivals_no_forecast（予測を出さないときの来た人数）・arrivals_naive_forecast（人が動く前の予測を出したときの来た人数）・capacity（1時間に乗れる人数）・wait_no_forecast／wait_naive_forecast（その時間帯に来た人の平均の待ち、分）・forecast_naive（出した予測、分）
- `results/by_hour_base.csv`：基本の置き方の時間帯ごとの予測と実際（1回目の50日の平均）。`results/yesterday_days11_30.csv`：前日の実際を出したときの11〜30日目の待ち

## 注意（言えないこと）
- 架空のデータです。乗れる人数、乗りたい人の数と行きたい時刻、予測を見る人の割合、ずらす手間（1時間10分）、選び方は作成者が置いたもので、結果はこれで決まります。実在のテーマパークや店の予測を表すものではありません
- 待ち時間は、1時間ごとの人数から流れとして計算しました。1時間の中での来かたのばらつき、乗り物の休止は入れていません。とくに予測を出さないときの昼前の待ちは、実際より短く出ているはずです（推測）
- 予測を見た人は、行きたい時刻をずらすだけで、乗るのをやめる人や別の乗り物に行く人は入れていません
- 「人の動きを織り込んだ予測」は、作成者が置いた人の動き方を知っている前提で作りました。実際には人の動き方は分からないので、この予測はここまで当たらないはずです（推測）
- どの予測の出し方がよいかは、外れの小ささと待ちの短さのどちらを重く見るかで変わります
