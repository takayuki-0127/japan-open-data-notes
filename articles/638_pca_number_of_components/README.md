# 638 主成分の数を「固有値1以上」「累積80%」「並行分析」で選ぶと、本当の数を何%で当てるのか（手法の解説・正解の分かるデータで試す）

主成分分析で「いくつの主成分を残すか」は、固有値1以上（カイザー基準）や、累積寄与率80%で決めることがよくあります。**ここでは、本当の因子の数（1〜6個）が分かっている架空のデータ（変数20個、300件）で、3つの決め方が本当の数を当てる割合を数えました。** 因子の効き（負荷量）は0.4・0.6・0.8の3通り、各条件200回です。数字は置いた因子の数・負荷量・件数で決まります。

## 主な結果（本当の数を当てた割合。k=1〜6 の平均）
| 負荷量 | 固有値1以上 | 累積80% | 並行分析 |
|---|---|---|---|
| 0.4 | 0.1% | 0.0% | 85.8% |
| 0.6 | 94.8% | 0.0% | 100.0% |
| 0.8 | 100.0% | 0.0% | 100.0% |

- **累積80%は一度も当たらなかった**。選んだ数の中央値は、負荷量0.4で14個、0.6で12〜13個、0.8で8個。因子で説明できない独自のばらつきが大きいほど、80%に届くまでの数が増える
- **固有値1以上は、効きが弱いと多すぎる**。負荷量0.4では選んだ数の中央値が6〜8個で、本当の数より多く選んだ回が99%以上。0.6・0.8ではほぼ当たった
- **並行分析**は負荷量0.6・0.8ですべて当たり、0.4でも k=1〜4 で97〜100%。k=5 は78%、k=6 は41%で、因子が多く効きが弱いと少なめに選んだ
- 乱数データの固有値の95%点は、1番目1.58・2番目1.46・3番目1.38（300件・20変数）。件数が少ないほど、固有値1の線との差は大きくなる

## 注意（言えないこと）
- 架空のデータ。各変数が1つの因子だけに載る、きれいな形で作った。因子どうしに相関がある場合や、複数の因子に載る変数がある場合は扱っていない
- 累積80%は「何個残せば情報を80%残せるか」の目安で、因子の数を当てるための決め方ではない。ここでは数を当てる目的での比較
- スクリープロットの肘の目視、MAP 法、交差検証による決め方は比べていない
