# 292 生まれたときの体重は、どれだけ軽くなったのか

厚生労働省「人口動態統計」確定数（2025年）上巻 4-25（性・年次別の出生時体重）、4-27（単産－複産別の出生時体重）、4-28（母の年齢・単産－複産別の2,500g未満の出生）、4-6（母の年齢別出生数）を使ったフォルダです。全国の集計だけを使っています。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A292 | 生まれたときの体重は、どれだけ軽くなったのか。2,500g未満の割合の上がりは、母の年齢構成の変化でどこまで説明できるか | 男女の平均体重と2,500g未満の割合の推移。2025年の母の年齢別の2,500g未満の割合を固定し、各年の母の年齢構成に当てた「年齢構成だけが変わった場合」の割合（直接標準化）と、実際の割合を比べた | `src/a292_birth_weight.py` |

## 主な結果
- 出生時の平均体重は、男は1975年の3.24kgがいちばん重く、2005年に3.05kg、2025年は3.04kg。女は3.15kgから2.96kg、2.95kgでした。2005年ごろからはほぼ横ばいです。
- 2,500g未満で生まれた割合（男女計）は、1975年の5.1%が最も低く、2005年に9.5%まで上がりました。2005〜2025年は9.2〜9.8%の間で、2025年は9.8%（6万5,600人）です。3.5kg以上の割合は23.3%から10.2%に下がりました。
- 2025年の母の年齢別の2,500g未満の割合は、25〜29歳の8.9%が最も低く、40〜44歳12.5%、45歳以上17.6%でした（単産だけでは7.6%、10.4%、15.8%）。
- 2025年の割合で固定して、母の年齢構成だけを1975年から2025年に動かすと、2,500g未満の割合は9.1%から9.8%へ0.6ポイント上がる計算です。実際は5.1%から9.8%へ4.7ポイント上がったので、年齢構成で説明できるのは約14%でした。
- 2025年は、双子などの複産で生まれた子が出生の2.5%で、その69%が2,500g未満でした。2,500g未満で生まれた子の18%が複産の子です。単産だけの2,500g未満の割合は8.2%でした。

## 頑健性
- 比べる始まりの年を1985年にしても、年齢構成で説明できる割合は約12%
- 単産の年齢別の割合で同じ計算をしても、年齢構成だけの上がりは1975→2025年で0.3ポイント（7.9%→8.2%）
- 男女別に見ても、2,500g未満の割合は1975年が最も低く（男4.7%・女5.5%）、2005年からほぼ横ばい
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致した

## 注意
- 母の年齢別・単産－複産別の値は2025年の分しか使っていません。過去の年の年齢別の割合が今と違えば、標準化の結果も変わります
- 年齢構成以外に、どんな変化が割合を上げたのかは、このデータでは分けていません
- 1991年までは100g単位で把握して平均に0.05kgを足した値、1992年からはグラム単位の平均です（表の注）。1951〜1960年は特殊報告からの値です
- 体重の変化が健康にどう関わるかは、このデータからは言えません。この記事は、統計の数字の変化だけを扱っています
