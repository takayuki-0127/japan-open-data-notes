# 984 3つの扉のどれかを選び直すと、当たりやすくなるのか？（確率の直感）

3つの扉の1つに景品があり、参加者が1つ選んだあと、司会者が残りの扉を1つ開けて外れを見せ、「選び直しますか」と聞くゲームがあります。残りは2つなので「どちらも半々」と感じますが、よく知られた答えは「選び直すと当たりが3分の2になる」です。ただし、この答えは司会者が「必ず外れの扉を開け、必ず選び直しを聞く」という決まりのときの値です。**ここでは、作成者が乱数で作った架空のゲーム（司会者の決まりを作成者が置いたもの）で、司会者の開け方と聞き方の決まりを変えると、選び直したときの当たりがどれだけ動くかを数えました。あわせて、少ない回数の記録から選び直しの得が見えるかを数えました。**

ゲームの確率の数え方だけを扱います。何かに参加することをすすめたり止めたりする話はしません。司会者や番組は架空のもので、実在のゲームを表すものではありません。

## 主な結果

### 司会者の決まりごとの当たり（`results/rules.csv`）
| 司会者の決まり | 数えた回 | そのままのときの当たり | 選び直したときの当たり | 式の値（選び直し） |
|---|---|---|---|---|
| A 必ず外れを開け、必ず聞く | 全部の回 | 33.26% | **66.74%** | 3分の2 |
| B でたらめに開ける | 外れが出た回 | 50.03% | **49.97%** | 2分の1 |
| C 外れが2つなら番号の小さい扉を必ず開ける（q＝1） | 小さい番号が開いた回 | 49.96% | 50.04% | 2分の1 |
| C 同じ決まり | 大きい番号が開いた回 | 0% | 100% | 1 |
| D 当てた人にだけ聞く | 聞かれた回 | 100% | **0%** | 0 |
| D 外した人にだけ聞く | 聞かれた回 | 0% | 100% | 1 |

- 決まりAでは、選び直すと66.74%で当たった。最初の選択が当たっているのは3分の1で、外れていれば残った扉は必ず景品なので、**式どおり3分の2です。この値そのものは新しく数えたものではありません**
- 決まりBでは、司会者が景品の扉を開けて終わった回が33.41%あり、外れが出た回だけを見ると、選び直しもそのままも半々（49.97%と50.03%）だった。同じ「外れが1つ開いた」場面でも、司会者が外れと知って開けたのか、たまたま外れが出たのかで答えが変わる
- 決まりCでは、全部の回で見ると選び直しの当たりはどの q でも66.62〜66.72%（式どおり3分の2）だった。開いた扉で分けると、q＝0.75 では57.07%と79.99%、q＝0.9 では52.65%と90.90%に分かれた（`results/host_pref_q.csv`）。**司会者が必ず外れを開けて必ず聞く限り、開け方に好みがあっても、選び直しの当たりが半分を下回ることはなかった**
- 決まりDの24通りでは、選び直したときの当たりは0〜100%に動いた（`results/offer_grid.csv`）。選び直しが得だったのは16通り、半々が2通り、損が6通りで、損になったのは「当てているときに聞く確率」が「外しているときに聞く確率」の2倍を超えるときだった（式どおり）

### 混ざった司会者（`results/mix_w.csv`）
| 「当てた人にだけ聞く」回の割合 w | 聞かれた回で選び直したときの当たり | そのままのときの当たり |
|---|---|---|
| 0（いつも決まりA） | 66.68% | 33.32% |
| 0.2 | 61.70% | 38.30% |
| 0.4 | 54.51% | 45.49% |
| 0.5 | **49.93%** | 50.07% |
| 0.6 | 44.45% | 55.55% |
| 0.8 | 28.60% | 71.40% |
| 1（いつも当てた人にだけ聞く） | 0% | 100% |

- 「当てた人にだけ聞く」回が半分あると、選び直しの得はなくなった（49.93%、式では 2(1−w)÷(3−2w) で、w＝0.5 のときちょうど2分の1）。参加者に司会者の決まりが分からないときは、「選び直せば3分の2」とは言えない

### 確かめ：扉の数（`results/n_doors.csv`、各50万回）
| 扉の数 | そのまま | 司会者が外れを n−2 枚開けて選び直す | 司会者が外れを1枚だけ開けて選び直す |
|---|---|---|---|
| 3 | 33.28% | 66.72% | 66.72% |
| 4 | 24.96% | 75.04% | 37.44% |
| 5 | 19.98% | 80.02% | 26.69% |
| 10 | 10.00% | 90.00% | 11.22% |

- 外れを1枚だけ開けても、選び直しはそのままより当たりやすかった（扉10枚で11.22%対10.00%）が、差は小さかった。どれも式（(n−1)÷n、(n−1)÷(n(n−2))）どおり

### 確かめ：少ない回数の記録（決まりA、`results/small_record.csv`、各4,000通り）
| 記録の回数 | 選び直した回の当たりが、そのままの回の当たり以下だった記録 | 選び直した回の当たり（10〜90%の範囲） |
|---|---|---|
| 10回 | **17.97%** | 40.00〜100% |
| 30回 | 3.77% | 50.00〜81.82% |
| 100回 | 0.03% | 57.78〜75.00% |
| 300回 | 0% | 61.74〜71.54% |
| 1,000回 | 0% | 63.95〜69.37% |

- 10回の記録では17.97%で選び直しの得が見えなかったが、30回で3.77%、100回で0.03%に減った。決まりAなら得は大きいので、記録を数十回とれば見える

## 注意（言えないこと）
- 架空のデータです。司会者の決まりは作成者が置いたもので、当たりの値はこれで決まります。表の値はどれも式どおりで、乱数で新しく見つけた値ではありません。新しく数えたのは、決まりを並べたときの動き方（0〜100%）と、少ない記録で見え方がどう振れるかです
- 景品の扉と参加者の選び方は等しい確率と置きました。参加者が景品のある扉を選びやすい、といった偏りは入れていません
- 実在のゲームや番組の決まりを表すものではありません。参加をすすめたり止めたりするものでもありません
- 関連する記事：834「くじは、先に引くのと後に引くのでどちらが有利か？」は、前の人の結果が見えるときに残りのくじの当たりがどう変わるかを扱っています。この記事は、見せる側（司会者）の決まりで、同じ「外れが1つ見えた」が何を意味するかが変わることに絞りました。911「検査で『不良』と出た品物は、本当に不良なのか？」は、もとの割合と判定の当たり外れから条件付き確率を数える点で同じ形です。同じ企画の983「振り分けで『迷惑メール』と出たとき、本当に迷惑メールの確率は？」は、同じ条件付き確率を、もとの割合（届くメールのうち迷惑メールの割合）で扱っています
