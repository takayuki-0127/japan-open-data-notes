# 201 サービス業の売上は、事業所の規模とどう比例するか：経済構造実態調査

総務省・経済産業省「経済構造実態調査」（2020年乙調査）の、選定サービス業27業種の事業従事者規模別の事業所数・事業従事者数・年間売上高から、1事業所あたりの人数と売上の関係を両対数回帰で調べたフォルダです。傾きが1なら売上は人数にちょうど比例し、1より大きければ大きな事業所ほど1人あたりの売上が多いことになります。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A201 | サービス業の売上は、規模とどう比例するか | 規模の区分ごとに1事業所あたり事業従事者数と年間売上高を計算し、log10(売上) を log10(人数) に回帰（業種ごと、業種の固定効果つきでまとめて）。1人あたり売上の最小区分と最大区分の比 | `src/a201_scale.py` |

## 主な結果
- 27業種・159区分をまとめた業種内の傾きは1.055（標準誤差0.017）。人数が10倍の事業所は、売上が平均で約11.4倍（10^1.055）
- 業種ごとの傾きは中央値1.044。1より大きい業種が18、小さい業種が9
- 傾きが大きいのは自動車賃貸業1.31、ゴルフ練習場1.26、広告業1.17、情報処理・提供サービス業1.16、ソフトウェア業1.15
- 1より小さいのは冠婚葬祭互助会0.62、葬儀業0.73、教養・技能教授業0.78、結婚式場業0.82
- 事業従事者1人あたり年間売上高は、ソフトウェア業で4人以下1,361万円、500人以上3,949万円（2.9倍）。広告業は4,280万円→1億1,299万円（100人以上、2.6倍）、学習塾は280万円→450万円（1.6倍）。葬儀業は2,459万円→850万円（0.35倍）
- 業種ごとのあてはまり（R²）は多くが0.98以上

## 注意
- 単位は事業所で、企業ではない。同じ会社の支社・営業所は別々に数えている
- 各区分の値は合計なので、区分の中のばらつきは分からない。回帰の点は「区分の平均」で、1つ1つの事業所の関係ではない
- 映像・新聞・出版・クレジットカード業（企業単位の表）と、スポーツ・娯楽用品賃貸業（売上高なし）、映画館（列の構成が違う）は除いた。秘匿（X）や該当なし（***）の区分も除いた
- 事業従事者数には他社からの派遣などを含み、従業者数とは一致しない
- 業種によって最大の区分が「50人以上」「100人以上」「500人以上」と違う
- 売上が大きいことは利益や賃金が大きいこととは違う。物品賃貸業などは仕入れ・設備の大きさが売上に効く
