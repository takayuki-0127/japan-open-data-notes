# 891 月の収入は、平均で見るか中央値で見るかで、どれだけ違って見えるのか？（副業の数字）

副業の人たちの月の収入は、少ない人が多く、ごく一部の人の収入が大きい形になりやすいと考えられます（推測）。このとき「平均の月収」は、ごく一部の人に引っぱられて、真ん中の人（中央値）より上に出ます。**ここでは、作成者が乱数で作った架空の副業の人たち（人ごとの収入の水準、月ごとの上下、案件のない月の割合を作成者が置いたもの）で、平均と中央値がどれだけ離れるか、平均を下回る人が何%いるか、少ない人数に聞いたときに平均・中央値がどれだけ振れるか、1人の12か月ではどうかを数えました。**

1本の投稿のバズで月の平均再生数が動く話は関連する記事 840、1人の収入で単発の大きな案件1本が平均の月収をどれだけ動かすかは 892 で扱っています。840・892 は「1つの大きな値が平均を動かす」話です。この記事は「人どうしの差が大きいときに、平均がどの人を表しているか」に絞ります。

## 主な結果

### 1か月の1,000人（1か月目）
| | 0円の人も入れる（1,000人） | 0円の人を除く（848人） |
|---|---|---|
| 平均 | **4.72万円** | 5.56万円 |
| 中央値 | **2.33万円** | 3.07万円 |
| 平均 ÷ 中央値 | **2.02倍** | 1.81倍 |
| 平均を下回った人 | **70.9%** | 72.4% |
| 上位10%の人が合計に占める割合 | 47.0% | 43.1% |

- 平均は中央値の2.02倍に出て、70.9%の人が平均を下回った。上位10%の人が、1,000人の合計の47.0%を占めた
- その月に0円だった人は15.2%。0円の人を除くと、平均も中央値も上がった（4.72→5.56万円、2.33→3.07万円）。「平均の月収」を読むときは、0円の人を入れた数字かどうかで値が変わる
- 人ごとに12か月をならした値で数えても、平均4.81万円・中央値2.86万円（1.68倍）で、69.4%の人が平均を下回った。月をならしても、人どうしの差は残った
- 20万人の1か月でも、平均4.78万円・中央値2.34万円（2.05倍）、平均を下回った人は71.2%で、1,000人の結果とほぼ同じだった

### 少ない人数に聞いたとき（全体20万人から、1万回）
| 聞いた人数 | 平均 ÷ 全体の平均（10〜90%の範囲） | 中央値 ÷ 全体の中央値（10〜90%の範囲） | 平均が全体から±30%以上ずれた回 | 中央値が全体から±30%以上ずれた回 | 平均が全体の平均を下回った回 |
|---|---|---|---|---|---|
| 10人 | 0.47〜1.64 | 0.50〜1.89 | 51.8% | 54.3% | 60.6% |
| 20人 | 0.59〜1.48 | 0.61〜1.58 | 38.8% | 40.1% | **59.1%** |
| 50人 | 0.72〜1.32 | 0.73〜1.34 | 18.9% | 19.9% | 55.7% |
| 200人 | 0.85〜1.16 | 0.86〜1.16 | 2.2% | 1.6% | 53.8% |

- 20人に聞いた平均は、59.1%の回で全体の平均を下回った。ふだんは低めに出て、ごくまれに収入の大きい人が入った回だけ大きく上に出るためと考えられる（推測）
- ずれの大きさ（±30%以上ずれた回）は、平均と中央値でほぼ同じだった。この置き方では「中央値なら少ない人数でも安定する」とは言えなかった。中央値は、平均よりも全体の真ん中の人に近い値を表すが、少ない人数で振れにくいわけではない

### 1人の12か月
- 自分の12か月の平均を下回った月は、平均で53.8%だった。1人の12か月の平均は、12か月の中央値の1.05倍（1,000人の中央の値）で、1.2倍以上離れた人は18.1%だった
- この置き方では、平均と中央値の差（2倍）の大部分は、1人の月どうしではなく、人どうしの差から来ていた。1人の収入で単発の大きな案件が入る場合は 892 で扱っています

## 注意（言えないこと）
- 架空のデータです。人どうしの差、月ごとの上下、0円の月の割合は作成者が置いたもので、結果はこれで決まります。とくに平均が中央値の何倍になるかは、散らばりの置き方で1.36〜4.83倍と動きました。実際の副業の人の収入の分布を表すものではありません
- 人ごとの水準は12か月で変わらないと置きました。始めたばかりで伸びていく人、やめていく人は入れていません
- 少ない人数の振れは、でたらめに選んだときの話です。収入を答えてくれる人に偏り（多い人ほど答えやすい、など）があると、ずれ方は変わります（推測）
- 「中央値のほうが良い」とは言えません。全員の収入の合計や総額を知りたいときは、平均（合計÷人数）が正しい数字です。この記事は「平均の値がどの人を表しているか」を読むときの話です
- 収入の目安や、どうすれば収入が増えるかについては何も言えません
