# 176 コンテナ取扱量の港ランキングは、15年でどう変わったか：港湾統計

国土交通省「港湾調査」の港湾統計年報（第２部 甲種港湾 第５表 コンテナ個数表、2009〜2024年）から、港ごとの外貿コンテナ（輸出＋輸入、TEU）を取り出して比べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A176 | 外貿コンテナの港の順位は、2009年から2024年でどう入れ替わったか。上位の港への集中は変わったか | 港別TEUの順位の推移、京浜・阪神・名古屋の割合、2009→2024年・2019→2024年の増減率 | `src/a176_ports.py` |

## 主な結果
- 全国の外貿コンテナは 2009年 1,474万TEU → 2019年 1,884万TEU → 2024年 1,748万TEU（2009年比+18.6%、2019年比−7.2%）
- 2024年の上位は 東京417万・横浜276万・名古屋259万・神戸213万・大阪202万・博多81万・北九州42万・清水40万・苫小牧18万・四日市17万TEU
- 上位10港の顔ぶれは2012年以降ずっと同じ（10位は2010年が広島、2011年が新潟）。順位が入れ替わったのは4位・5位の神戸と大阪、7位・8位の北九州と清水だけ
- 京浜（東京・横浜・川崎）・阪神（大阪・神戸）・名古屋の合計の割合は 78.9%（2009年）→ 78.7%（2024年）でほとんど変わらない
- 2019→2024年は、主要17港のうち横浜（+2%）以外はすべて減った。仙台塩釜−32%、苫小牧−26%、川崎−39%

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a176_ports.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/major_ports.csv | 年、港、輸出コンテナ（TEU）、輸入コンテナ（TEU）。2009〜2024年のどこかで外貿コンテナの上位15位に入った17港 |
| data/national_total.csv | 年、全国（甲種港湾の計）の輸出・輸入コンテナ（TEU）、外貿コンテナを扱った港の数 |

元の表：e-Stat「港湾調査」港湾統計（年報）第２部 甲種港湾 2-5-1 第５表（１）輸出コンテナ仕向国別表、2-5-2（２）輸入コンテナ仕出国別表（https://www.e-stat.go.jp/stat-search/files?toukei=00600280）。各港の「計」の行を足し上げた。2024年の輸出の合計は第１部 1-5-1 の総計（8,701,075TEU）と一致することを確かめた。

## 注意
- 外貿（輸出・輸入）のコンテナで、国内の移出・移入は入れていない
- 2005〜2008年の表は PDF だけなので、2009年からの15年分を使った（バックログの「30年」より短い）
- 順位は data の17港の中での順位。上位15位以内は全港での順位と同じになる
- TEU は20フィートコンテナ換算。空コンテナとトランシップ（積み替え）を含む
