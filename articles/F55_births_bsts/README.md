# F55 ベイズで出生数を予測すると、予測の幅はどう変わるか？（ベイズ構造時系列）

看板記事 F55。note の記事：「ベイズで出生数を予測すると、予測の幅はどう変わるのか？ 構造時系列モデルで月次の出生数を読むと、幅はSARIMAの1.4倍に広がり、そのほうが過去の予測の当たり方に合っていた」

## 問い

月ごとの出生数を、水準・傾き・季節に分けて少しずつ動く形で表す「ベイズ構造時系列（BSTS）」で予測すると、F02 で使った SARIMA と比べて予測の中身と幅はどう変わるか。その幅は、過去の予測の当たり方と合っているか。

## データ

- 厚生労働省「人口動態統計」2025年確定数：上巻 出生 第4.2表「出生月別にみた年次別出生数」（e-Stat statInfId=000040503641）。F02 で書き出した月次の出生数（2000年1月〜2025年12月）をそのまま使っています（`data/raw/births_monthly_2000_2025.csv`、`data/monthly.csv`）
- 分析する値は log（1日あたり出生数）です（月の日数の違いを除くため）

## 手法

| 項目 | 内容 |
|---|---|
| モデル | y_t = μ_t + γ_月 + ε_t。水準 μ はランダムウォーク＋傾き δ、傾き δ もランダムウォーク。季節 γ は12か月の効果（合計0）。PyMC（nutpie）で推定、2チェーン×2,500サンプル |
| 事前分布（基本） | 水準のゆれの標準偏差 HalfNormal(0.01)、傾きのゆれ HalfNormal(0.001)、観測のゆれ HalfNormal(0.05)（いずれも log・1か月あたり） |
| 予測 | 事後分布のサンプルから将来を前向きに4,000本シミュレーションし、予測分布をつくる（パラメータの不確実さも予測の幅に入る） |
| 比べる相手 | SARIMA(1,1,1)(0,1,1)12（F02 の基本モデル） |
| 評価 | ① 2010〜19年で学習して2020〜25年を予測（F02 と同じ「コロナがなかった場合」）、② バックテスト（2014〜18年末を起点に、それぞれ直前10年で学習し、2019年12月までを最大36か月先まで予測。区間に入った割合と CRPS）、③ 2016〜25年で学習して2026〜30年を予測、④ 2005〜25年で学習した傾きの事後分布の推移 |

## 主な結果

- **予測の幅**：95%区間の幅（予測の中央値に対する割合）は、12か月先で BSTS 13.6%・SARIMA 10.5%、36か月先で 32.6%・22.9%、72か月先で 68.7%・48.1%。BSTS の幅は SARIMA のおよそ1.3〜1.4倍
- **バックテストでの当たり方**（2014〜18年末起点、計144か月）：80%区間に入った割合は BSTS が 90%・83%・94%（1〜12・13〜24・25〜36か月先）、SARIMA が 77%・75%・75%。SARIMA は幅が狭すぎ、BSTS はやや広め。95%区間は BSTS 97〜100%、SARIMA 92〜100%。予測の外れ（CRPS）は 1〜24か月先で BSTS がやや小さく、25〜36か月先は SARIMA が小さい（平均ではほぼ同じ）
- **コロナがなかった場合**（2010〜19年で学習）：2020〜22年の累計の「実績−予測」は、BSTS −1.3万人（95%区間 −21.5万〜+19.0万）、SARIMA +2.4万人（−12.0万〜+16.1万）。どちらも区間は0をまたぐ。72か月のうち95%区間の外に出たのは BSTS では2021年1月の1か月だけ（実績61,040、区間63,725〜73,548）
- **2023〜25年**：実績は BSTS の予測の中央値を下回り続け、2025年は実績67.1万人に対して中央値71.3万人（95%区間 50.4万〜95.0万）
- **2026〜30年**（2016〜25年で学習）：BSTS の中央値は 2026年 66.3万人（95%区間 62.3万〜71.4万）、2030年 57.8万人（42.2万〜87.1万）。2030年に60万人を下回る確率は60%。SARIMA の中央値は2030年 56.6万人（46.9万〜68.7万）で、区間は BSTS より狭い
- **傾きの推移**：トレンドの傾き（中央値）は 2005〜13年の −1.8〜−2.1%/年から、2023年1月の −3.0%/年まで大きくなり、2025年は −2.8%/年。ただし90%区間は広く（例：2023年 −5.9%〜−0.7%）、加速の大きさははっきりとは言えない

## 頑健性

| 設定 | 2020〜22年累計の差（中央値、95%区間） | 95%区間の外の月（72か月中） | 36か月先の95%幅 |
|---|---|---|---|
| 基本（2010〜19年・base） | −1.3万（−21.5万〜+19.0万） | 1 | 32.6% |
| 事前分布 tight | −1.2万（−16.5万〜+14.1万） | 2 | 23.7% |
| 事前分布 loose | −1.6万（−22.3万〜+19.9万） | 1 | 33.8% |
| 学習 2005〜19年 | −4.6万（−24.9万〜+20.5万） | 1 | 34.7% |
| 学習 2014〜19年 | +0.1万（−32.5万〜+27.2万） | 1 | 52.8% |
| 傾きなし（ローカルレベル） | −15.7万（−33.2万〜+0.7万） | 47 | 22.0% |
| 季節も動かす | −1.1万（−21.8万〜+20.1万） | 1 | 33.0% |

- 傾きを入れないと、減り続けるトレンドを追えず、72か月中47か月で実績が区間の下に出た（モデルの成分の選び方が結果を大きく左右する例）
- 事前分布を狭くすると区間はかなり狭まる。予測の幅は事前分布の置き方にも依存する
- 2030年の予測：基本 57.8万（42.2万〜87.1万）、tight 56.0万（48.1万〜68.8万）、loose 57.9万（39.3万〜93.3万）、学習2010〜25年 58.8万（44.5万〜81.5万）、傾きなし 68.1万（54.1万〜85.9万）
- 収束：すべての当てはめで R̂ ≤ 1.017、ESS（bulk、分散パラメータ）≥ 111（`results/fit_diagnostics.csv`）

## このデータで言えないこと

- 予測は「これまでの動きが続いた場合」の計算で、出生数の将来を言い当てるものではない（政策・結婚の動き・景気は入っていない）
- 予測の幅は、モデルの形と事前分布の置き方で変わる。「BSTS の区間のほうが正しい」とは言えず、今回のバックテスト（2014〜19年の144か月）では当たり方に合っていた、というところまで
- バックテストは起点が5つで、同じ期間を重ねて使っているので、区間に入った割合の差は大まかな目安
- 傾きの加速は区間が広く、はっきりとは言えない
