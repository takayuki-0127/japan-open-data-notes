# 186 営業用と自家用、トラック輸送の割合はどう変わったか：自動車輸送統計調査

国土交通省「自動車輸送統計調査」の年報 総括表（輸送トン数・輸送トンキロの推移）から、トラックの輸送を営業用（運送会社が運賃をもらって運ぶ）と自家用（自社の荷物を自社の車で運ぶ）に分け、1960〜2025年度の割合の変化を見たフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A186 | トラック輸送のうち営業用の割合は、重さと距離でどう変わったか | 営業用の割合（輸送トン数・輸送トンキロ）の推移、営業用・自家用の輸送トン数、1トンあたり平均輸送距離（トンキロ÷トン） | `src/a186_share.py` |

## 主な結果
- 輸送トン数（重さ）で見た営業用の割合は、1970年度の24.1%から2009年度の60.3%に上がり、2015年度以降は66〜69%で横ばい（2025年度66.9%）
- 輸送トンキロ（重さ×距離）では、1960年度の46.3%から2009年度87.6%、2025年度87.9%
- 自家用の輸送トン数は1991年度の36.9億トンが最大で、2025年度は12.0億トン。営業用は2000年度の29.3億トン前後で頭打ちになり、2025年度は24.3億トン（2019年度比−14.7%）
- 1トンの荷物を運ぶ平均距離は、営業用が1960年度25km→2009年度109km（2015年度以降の新しい集計では約78km）、自家用はこの65年ずっと14〜23km

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a186_share.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/truck_transport_fy.csv | 年度、系列（A・B・C）、輸送トン数（千トン：合計・営業用・自家用）、輸送トンキロ（百万トンキロ：同） |
| data/truck_ton_by_type_fy2015_2025.csv | 2015〜2025年度の輸送トン数の車種別内訳（営業用普通車の最大積載量別は2020年度から） |

- 系列A：2009年度年報 総括表（１）（２）（statInfId 000031848855・000031848856）の1960〜2009年度。自家用に軽自動車を含む。1986・1994年度は年報に値がない
- 系列B：2014年度年報 総括表（１）（000031355138）。2010年度の調査方法の変更に合わせて2005〜2009年度を組み替えた値と2012〜2014年度。自家用の軽自動車を含まない
- 系列C：2025年度年報 総括表 2-1・2-2（000040511069・000040511070）の2015〜2025年度。2020年3月以前の営業用は接続係数で遡って改訂された値
- ダウンロード：`https://www.e-stat.go.jp/stat-search/file-download?statInfId=<ID>&fileKind=4`（2009年度分は fileKind=0）

## 注意
- 2010年度に調査方法が変わり、2010・2011年度は年報に連続した値がないため、系列の間はつないでいない。系列Bの2012〜2014年度はトンキロがない
- 平均輸送距離は系列Cで営業用の値が系列Aより小さく、調査方法の違いを含む。系列の中での変化だけを読む
- 営業用の割合の上昇には、自家用トラックの減少（運送の外部委託）と、営業用の長距離化の両方が含まれる。どちらがどれだけかは分けていない
