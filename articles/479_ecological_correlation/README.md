# 479 地域の平均どうしの相関は、1人ずつの相関とどれだけ違うのか？（手法の解説）

地域ごとの平均を並べて相関を出すと、強い関係が見えることがあります。けれども、それは「1人ずつで見ても同じ関係がある」ことを意味しません。**地域の平均どうしの相関と、1人ずつの相関がどれだけ離れるかを、式と架空の地域・人のデータで計算しました。** 実在の地域は使っていません。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A479 | 地域の平均どうしの相関は、1人ずつの相関の何倍になるか。向きが逆になるのはどんなときか。地域の数が少ないとどれだけ振れるか | 架空の地域と人。ばらつきを「地域ごとの差」と「地域の中の人ごとの差」に分け、それぞれの相関を別々に置く。100通りの設定を式で計算し、5つの場面を50地域×300人・1,000回の乱数で確かめる。地域の数は10〜200 | `src/a479_ecological.py` |

## 置いたこと（架空）
- x と y のばらつきのうち、地域ごとの差が占める割合（2〜20%）
- 地域の差どうしの相関（−0.8〜+0.8）と、地域の中での相関（−0.3〜+0.3）
- 式：1人ずつの相関＝地域の差の割合×地域の差どうしの相関＋（1−地域の差の割合）×地域の中の相関。平均どうしの相関は、人ごとの差が人数で割られて小さくなるので、地域の差どうしの相関に近づく

## 主な結果
### 100通りの設定（1地域300人、式）
| 見たこと | 結果 |
|---|---|
| 平均どうしと1人ずつで、相関の向きが逆 | 100通りのうち28通り |
| 平均どうしの相関が、1人ずつの2倍以上 | 66% |
| 倍率の中央値 | 3.0倍 |
| 平均どうしは0.5以上なのに、1人ずつは0.2未満 | 26通り |

### 5つの場面（50地域×300人、1,000回の平均）
| 場面 | 地域の差の割合 | 1人ずつ | 平均どうし | 地域の中だけ |
|---|---|---|---|---|
| A 地域の差どうしは強く、地域の中はほぼ関係なし | 5% | +0.06 | **+0.75** | +0.02 |
| B 地域の差どうしはプラス、地域の中はマイナス | 10% | −0.10 | **+0.77** | −0.20 |
| C 地域の差どうしは関係なし、地域の中はプラス | 5% | +0.29 | +0.02 | +0.30 |
| D どちらも同じ向きで同じ強さ | 10% | +0.30 | +0.30 | +0.30 |
| E 地域ごとの差がごく小さい | 0.5% | +0.10 | +0.51 | +0.10 |

- B では、1,000回すべてで向きが逆になった
- C では、平均どうしの相関は0のまわりで振れ（標準偏差0.14）、44%の回でマイナスになった

### 地域の数と、平均どうしの相関の振れ（場面A、1地域300人、90%の回が入る幅）
| 地域の数 | 幅 |
|---|---|
| 20 | 0.54〜0.89 |
| 50 | 0.63〜0.84 |
| 100 | 0.68〜0.82 |
| 200 | 0.70〜0.80 |

1地域30人だと、平均どうしの相関は0.50まで下がる（人ごとの差が平均に残るため）。

### 本当は関係がないとき（地域の差も地域の中も相関0、2,000回）
| 地域の数 | 相関の絶対値が0.3以上 | 0.5以上 |
|---|---|---|
| 10 | 40% | 14% |
| 20 | 19% | 2.6% |
| 50 | 3.6% | 0% |
| 200 | 0% | 0% |

全部の数字は `results/` の5つの CSV と `main.json` にあります。

## 確かめたこと
- 空のフォルダで計算し直し、data・results・figures が一致した
- 式の値と乱数の平均は、5つの場面とも0.02以内で合った（`results/scenarios.csv`）
- 場面D（どちらも同じ強さ）では、3つの相関がそろう

## 注意（言えないこと）
- 架空の地域と人です。実際のデータで、地域の差と地域の中の関係がどう組み合わさっているかは、1人ずつのデータがないと分かりません
- 平均どうしの相関が「まちがい」なのではありません。地域について言うなら地域の相関、人について言うなら1人ずつの相関、と問いに合わせて使い分ける話です
- 正規分布で、どの地域も同じ人数と置きました。人数がばらばらの場合や、地域ごとに傾きが違う場合は扱っていません
- 相関は、原因と結果の関係を示すものではありません
- 都道府県どうしの相関の出方は376、市区町村を合併でまとめたときの変化は469で扱いました
