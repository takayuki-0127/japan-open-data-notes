# F454 事前の計画（PLAN）

## 問い
「荷物の小口化」は、物流センサスでどこまで進んだのか？

## 知りたい人
物流の効率や人手不足の記事で「荷物が小口化・多頻度化している」と読む人、運送や倉庫の仕事で出荷の形の変化を数字で知りたい人。国の物流の検討の場でも、1回に運ぶ荷物が小さくなり、回数が増えたことが、トラックの積載率の低さの背景として挙げられてきた。国土交通省の物流センサス（全国貨物純流動調査）で、1件あたりの重さ（流動ロット）がどれだけ小さくなったか、どの運び方で小さくなったかを確かめる。

## データ
- 国土交通省「全国貨物純流動調査（物流センサス）」（5年ごと、3日間調査の拡大推計）
  - 表1-5-15 代表輸送機関別の流動量（重量・件数）と流動ロット：2015年調査の表（2000〜2015年）と2021年調査の表（2005〜2021年）
  - 表1-5-12 発産業業種別の流動量・流動ロット（2005〜2021年）
  - 表2-7-1・2-7-2 流動ロット階層別の流動量（重量・件数）：2015年調査と2021年調査
- 流動ロット = 重量 ÷ 件数（トン／件）

### 取得前に見たもの（下見）
- 表1-5-15の形と、合計の流動ロット（2000年 1.73、2005年 1.27、2010年 0.95、2015年 0.98、2021年 0.83トン／件）、トラック（小計）・自家用トラック・宅配便等混載・一車貸切の行の値をざっと見た
- ロット階層別の分布、業種別、分解はまだ計算していない

## 仮説（外れの基準つき）
- H1：合計の流動ロットは、2000年から2021年で40%以上小さくなった。外れ：40%未満。
- H2：2000年から2021年で、件数は増え、重量は減った（3日間調査）。外れ：件数が増えていないか、重量が減っていない。
- H3：合計のロットの縮みは、輸送機関の構成の変化（宅配便などに件数が移ったこと）より、同じ輸送機関の中でのロットの縮みで多く説明できる（2005→2021年）。外れ：構成の変化の分の方が大きい。
- H4：2021年に、0.1トン未満の荷物は件数の80%以上を占めるが、重量では2%未満。外れ：どちらかが満たされない。

## 手法
- 合計と輸送機関別のロットの推移
- 合計のロットの変化を、件数の構成の変化と、輸送機関ごとのロットの変化に分ける（シフトシェア、2005→2021年）
- ロット階層別の件数と重量の割合（2015年と2021年）

## 頑健性（3つ以上）
1. 期間を2005→2021年、2015→2021年に変える
2. 宅配便等混載を除いて合計のロットを計算し直す
3. 2つの公表年の表の重なる年（2005・2010・2015年）の値が一致するか
4. ロット階層の区切りを0.05トン・0.5トンに変える

## 言えないこと（予想）
- 3日間の調査の拡大推計で、季節の違いや年ごとの振れがある
- 2021年はコロナの影響を受けた時期の調査
- 小口化の理由（通販、在庫の持ち方、取引の慣行）は分からない
- 消費者向けの宅配のすべてが入るわけではない（調査対象は鉱業・製造業・卸売業・倉庫業の事業所の出荷）
