# F268 計画（事前登録）：生命表が5年で変わると、年金の負担はどれだけ動くのか？

書いた日：2026-11-11（年金現価の計算はまだしていない）

## 問い
年金の負担を見積もるときは、「65歳から一生、毎年1円を払うには、いまいくら要るか」（65歳の年金現価、a65）を生命表から計算する。
生命表は5年ごとに更新され、死亡率が下がると a65 は上がる。
- 生命表が5年新しくなると、a65 は何％動くのか。
- その動きは、何歳の死亡率の改善から来ているのか。
- 割引率（運用利回り）を変えた場合と比べて、どれくらい大きいのか。
- 2020年以降の「寿命の伸びの止まり」は、a65 にどう出ているのか。
- 財政検証（令和6年）が前提にしている死亡率の見通し（将来推計人口の中位・高位・低位）は、過去の5年ごとの動きと比べて速いのか、遅いのか。

## 事前に見たもの（開示）
- F86 の README（日本版死亡データベースの平均寿命の動き、Lee–Carter の結果）を、作業の前に読んでいる。
- 令和6年財政検証の前提値（スプレッド1.3〜1.7%、実質の運用利回り1.4〜3.4%、2070年の平均寿命 中位 男85.89・女91.94 など）を読んでいる。
- 65歳の年金現価そのものは、まだ1つも計算していない。

## データ
- 主：日本版死亡データベース（JMD）の年齢別死亡率 mx（1947〜2024年、0〜99歳と100歳以上）。F86 で取得済みのものを写す。
- 確かめ：厚生労働省「簡易生命表」の死亡率 qx（2019年・2024年など、取れる年）。JMD との差を見る。
- 財政検証の前提：令和6年財政検証の経済前提（スプレッド・実質の運用利回り）と人口前提（死亡中位・高位・低位の平均寿命）。
- 将来推計人口（令和5年推計）の平均寿命の仮定値（2045年・2070年、中位・高位・低位）。

## 変数と手法
- 生命表：mx から各歳の生命表を作る（a=0.5、100歳以上は開いた階級、L=l/m）。F86 と同じ作り方。
- 年金現価：a65 = Σ_{t≥0} v^t · t p65（毎年はじめに1円払う終身年金）。開いた階級（100歳以上）は、その死亡率が一定と置いて先まで足し切る。
- 割引率：基本は1.7%（財政検証のスプレッド＝賃金に対する運用利回り、成長型経済移行・継続ケースと過去30年投影ケース）。ほかに 0%・1.3%・2.2%・3.2%。
- 5年ごとの変化：Δ = a65(t+5)/a65(t) − 1 を、1970年から2024年の各5年（重なりを許す1年ずらし）で計算。
- 年齢の分解：65〜69歳、70〜74歳、…、95歳以上の年齢層ごとに、死亡率だけを入れ替えて a65 の変化に分ける。前から入れ替える順番と後ろから入れ替える順番の平均を取り、交互作用の残りも出す。
- 割引率との比較：割引率を0.5ポイント下げたときの a65 の変化と比べる。
- 財政検証の見通しとの比較：F86 と同じ Lee–Carter（1970〜2024年で当てはめ）の k(t) を、2045年・2070年の平均寿命が将来推計人口の中位（高位・低位）に一致するよう合わせる。その死亡率から a65 を出し、5年あたりの伸びを過去と比べる。

## 仮説と「外れ」の基準
- H1：2014→2019年（コロナ前の最後の5年）に、a65（1.7%）は男女とも +2% 以上上がった。どちらかが +2% 未満なら外れ。
- H2：2019→2024年の a65 の変化は、2014→2019年の半分に届かない（伸びの止まり）。男女どちらかで半分以上なら外れ。
- H3：2014→2019年の a65 の変化のうち、60%以上は75歳以上の死亡率の改善から来ている。男女どちらかで60%未満なら外れ。
- H4：割引率を0.5ポイント下げたときの a65 の変化は、生命表の5年の更新（2014→2019年）より大きい。男女どちらかで小さければ外れ。
- H5：将来推計人口の中位の見通しでは、2020→2070年の a65 の5年あたりの伸びは、1990〜2019年の実績の5年あたりの伸びの平均より小さい。男女どちらかで大きければ外れ。

## 頑健性（3つ以上）
1. 割引率：0%・1.3%・1.7%・2.2%・3.2%。
2. 生命表の出どころ：JMD の代わりに、厚生労働省の簡易生命表の qx で a65 を計算する（取れる年だけ）。
3. 単年のぶれ：単年の死亡率の代わりに、3年平均の死亡率で生命表を作る。
4. 開いた階級：100歳以上を一定の死亡率で足し切る代わりに、100歳で打ち切る／死亡率を年10%ずつ上げて延ばす。
5. 年金を始める年齢：60歳・70歳でも同じ計算をする。

## 問い直し（1回）
結果を見てから1つ足す。足したものは、結果を見た後に決めたと書く。

## 言えないこと（先に書いておく）
- 実際の年金財政の負担は、加入者・受給者の人数、給付の調整（マクロ経済スライド）、賃金・物価で決まる。a65 は「1人分の一生の給付にいくら要るか」の目安で、年金財政そのものの見通しではない。
- 公的年金の制度や政策の良し悪しは扱わない。個人の年金の選び方の助言もしない。
