# F268 生命表が5年で変わると、年金の負担はどれだけ動くのか？（精選）

計画（事前登録）：[PLAN.md](PLAN.md)（コミット be442dc、年金現価を1つも計算する前に書いた）

## 問い
年金の負担を見積もるときは、「65歳から一生、毎年1円を払うのに、いまいくら要るか」（65歳の年金現価、a65）を生命表から計算する。生命表は毎年・5年ごとに新しくなり、死亡率が下がると a65 は上がる。
- 生命表が5年新しくなると、a65 は何％動くのか。
- それは何歳の死亡率から来ているのか。
- 割引率（運用利回り）の小さな変更と比べて、どれくらいの大きさか。
- 2020年以降の寿命の伸びの止まりは、a65 にどう出たのか。
- 令和6年財政検証が前提にしている死亡率の見通し（将来推計人口の中位・高位・低位）は、過去と比べて速いのか、遅いのか。

保険会社や年金基金で負債を計算する人、財政検証を読む人が知りたい点。

## 手法
- 生命表：mx から各歳の qx（a=0.5）。100歳以上は開いた階級の死亡率が一定と置いて先まで足す（F86 と同じ作り方）。
- 年金現価：a65 = Σ v^t · t p65（毎年はじめに1円を払う終身年金）。基本の割引率は年1.7%（令和6年財政検証の「成長型経済移行・継続」「過去30年投影」ケースのスプレッド＝賃金に対する運用利回り）。
- 5年ごとの変化：a65(t+5)/a65(t) − 1 を1960年から各年。
- 年齢の分解：65〜69歳 … 95歳以上の7つの年齢層ごとに死亡率を入れ替え、若い順と高い順の2通りの平均を寄与とした（寄与の合計は全体の変化に一致）。1つずつ入れ替えた場合の合計との差（交互作用の残り）は、7つの期間のどれでも全体の0.3%以下。
- 割引率との比較：同じ生命表で割引率を0.25・0.5ポイント下げたときの a65 の変化。生命表の5年の更新と同じ大きさになる割引率の下げ幅も逆算した。
- 将来推計人口の見通し：Lee–Carter（1970〜2024年、Lee–Miller の2段目つき）で、2024年の実際の死亡率から出発し、k(t) を2070年の平均寿命（死亡中位・高位・低位）に合うよう動かした。中位は2045年の平均寿命にも合わせて2024→2045→2070年を折れ線でつないだ。2045年の値を持たない高位・低位は、2045年までの動きが2070年までの動きに占める割合（男女とも約0.59）を中位と同じと置いた。

## 結果（割引率1.7%）
| | 2014年 | 2019年 | 2024年 | 2014→2019年 | 2019→2024年 |
|---|---|---|---|---|---|
| 男 a65（円） | 16.48 | 16.87 | 16.65 | +2.3% | −1.3% |
| 女 a65（円） | 19.91 | 20.24 | 20.11 | +1.7% | −0.7% |
| 男 65歳の平均余命（年） | 19.23 | 19.78 | 19.48 | +0.55年 | −0.30年 |
| 女 65歳の平均余命（年） | 24.12 | 24.62 | 24.41 | +0.50年 | −0.21年 |

- 1990→2019年の a65 の伸びは、5年あたり男2.9%・女3.0%（1年ずつずらした25の5年の範囲：男1.3〜5.3%、女0.9〜5.7%）。
- 2014→2019年の変化のうち、75歳以上の死亡率から来た分は男71%・女79%。男は65〜69歳も21%と大きい。
- 割引率を0.5ポイント下げると a65 は男+5.2%・女+6.2%、0.25ポイントで男+2.6%・女+3.0%。生命表の5年の更新（2014→2019年）は、割引率を男0.23ポイント・女0.14ポイント下げたのと同じ大きさ。
- 2019→2024年の下げは、男は75〜79歳（寄与の40%）、女は75〜79歳（29%）と90〜94歳（18%）から。
- 将来推計人口の見通しでは、2020→2070年の5年あたりの伸びは、中位で男1.2%・女1.1%、高位で男0.8%・女0.7%、低位で男1.6%・女1.4%。どれも1990〜2019年の実績（2.9〜3.0%）の半分程度かそれ以下。2024年から測っても中位で男1.5%・女1.3%。
- 当てはめの確かめ：見通しの65歳の平均余命は、中位で2045年 男21.65・女26.82年、2070年 男23.08・女28.37年。将来推計人口の中位の値（2045年 男21.71・女26.77、2070年 男23.14・女28.36）とほぼ同じ。

### 計画からのずれ
- H5 の見通しの作り方：計画は「2045年・2070年の平均寿命に合わせる」だったが、高位・低位は2045年の仮定値を持っていないため、2045年までの動きの割合を中位と同じと置いた（中位は計画どおり両方に合わせた）。H5 の判定は2020年と2070年の値だけで決まるので、この置き方は判定に影響しない。
- 頑健性 R3 の「3年平均」は、2024年を真ん中にできないため、その年と前2年の平均にした。
- 年齢の分解の頑健性（割引率5通り・3年平均）と、2024→2070年で測った伸びは、計画になく足したもの。
- 問い直し（下）は結果を見た後に決めた。

## 問い直し：その年の生命表は、実際に生きた人より何％低く見積もっていたか
結果を見て、「5年ごとに更新しても、その時点の表は将来の改善を含まない。それでどれだけ低く見積もってきたのか」を足した。
- 1975〜1990年に65歳になった人の a65 を、その後に実際に経験した死亡率（2024年まで、1990年に65歳の人は99歳まで実績）で計算し、その年の生命表での値と比べた。
- その年の生命表の値は、実際より男5.8〜9.8%・女9.7〜13.4%低かった（1985〜1990年の平均で男6.5%・女10.4%）。5年後の生命表に替えても、男4.5%・女7.0%低いまま（1985〜1990年の平均）。
- 2024年に65歳の人は、将来推計人口の中位に合わせた見通しで、その年の生命表の値が男5.3%・女5.8%低い（高位〜低位で男3.8〜6.8%・女4.1〜7.6%）。
- 割引率を0〜3.2%に変えても、過去（1985〜1990年の平均）は男5.4〜7.8%・女8.7〜12.7%、2024年（中位）は男4.4〜6.4%・女4.7〜7.3%低い。
- 実務の年金数理は、将来の改善を見込んだ生命表（将来生命表）を使うことが多い。ここでの「その年の生命表」は、その改善を入れない場合の目安。

## 言えないこと
- 実際の年金財政の負担は、加入者・受給者の人数、マクロ経済スライドによる給付の調整、賃金・物価で決まる。a65 は「1人分の一生の給付にいくら要るか」の目安で、年金財政の見通しではない。
- 公的年金の給付は賃金・物価で改定される。割引率を「賃金に対する運用利回り」にしたのは単純化で、財政検証の計算そのものではない。
- 見通しは Lee–Carter の形（年齢ごとの改善の比 b(x) が一定）を置いたもので、将来推計人口の死亡率の年齢ごとの形とは違いうる（65歳の平均余命はほぼ一致した）。
- 単年の生命表には、その年の感染症・暑さなどのぶれが入る（2020〜2024年の動きの一部はそのぶれと考えられる。推測）。
- 制度や政策の良し悪し、個人の年金の選び方は扱わない。
