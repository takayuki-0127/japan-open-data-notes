# F239 広告費は、売上にどれだけ効いているのか？（マーケティング・ミックス・モデル）

看板記事・シリーズ「実務に近い分析」（F231〜F245）の9本目。広告費と売上の関係を、(A) 公開データ（業界全体の月次）と (B) 架空の会社「みどりホーム（架空）」のシミュレーションで調べ、(C) 推定した反応曲線で予算配分を決めるとどうなるかを確かめた。MMM（マーケティング・ミックス・モデル：広告費と売上の時系列から、媒体ごとの効き目を推定するモデル）が当たる条件と当たらない条件を、本当の値が分かるシミュレーションで比べている。

## 問い
- 業界全体の公開データで、広告費が多い月に売上は多いのか。それは広告の効き目と言えるのか
- アドストック（効き目の持ち越し）と飽和（出しすぎると頭打ち）を入れた MMM は、媒体ごとの ROI（売上の上乗せ÷広告費）をどこまで当てられるのか
- 広告費を需要の見込みに合わせて動かしていると、何が起きるのか。地域を分けた実験と比べるとどうか
- 推定した反応曲線で予算配分を決めると、本当の売上の上乗せはどうなるか

## 結果（要点）
### A. 業界全体（2014年1月〜2024年12月、132か月）
| 推定の仕方 | 広告業の売上高合計の弾力性（95%区間） |
|---|---|
| 1 そのまま（水準どうし） | +0.153（+0.103〜+0.203） |
| 2 ＋月の違い | −0.057（−0.324〜+0.210） |
| 3 ＋月＋トレンド | +0.148（−0.000〜+0.295） |
| 4 ＋月＋トレンド＋コロナ期・消費税 | +0.020（−0.063〜+0.104） |
| 5 前年同月比どうし | +0.056（−0.036〜+0.148） |
- 弾力性＝広告費が1%多い月に、小売3業態の販売額が何%多いか（HAC 標準誤差、ラグ12）
- テレビは −0.288〜+0.101、インターネット広告は −0.118〜+0.103 と、推定の仕方で符号まで入れ替わった
- 前年同月比どうしの相関（コロナ期を除く）：売上が6か月先に動くずれで +0.26、同じ月は −0.11、広告が3か月先に動くずれで −0.22。売上が先に動き、広告があとから動く形（相関は弱い）

### B. みどりホーム（架空）のシミュレーション（3年＝156週、60回）
本当の設定：テレビ（減り方0.6・ROI 5.51）、Web（0.2・5.88）、チラシ（0・1.91）。ROI は「いまの平均の出し方を続けたときの、媒体が生む売上の上乗せ÷その媒体の広告費」。

| 場面 | 方法 | テレビ | Web | チラシ |
|---|---|---|---|---|
| 広告費が需要と関係なく動く | MMM（中央値のずれ） | −10% | +13% | +16% |
| 〃 | MMM（ずれの大きさの中央値） | 38% | 33% | 37% |
| 広告費を需要の見込みに合わせて動かす | MMM（中央値のずれ） | +3% | +53% | +68% |
| 〃 | MMM（ずれの大きさの中央値） | 23% | 53% | 68% |
| 両方 | 地域実験（Web、47地域の半分で12週止める） | — | +2% / +0%（ずれの大きさ 17% / 19%） | — |
| 需要に合わせる | 実験で Web を補正した MMM | +27% | +0% | +97% |

- 需要に合わせる場面では、Web の ROI の推定は60回中の25〜75%点が +25〜+84%、チラシは +52〜+116% で、ほとんどの回で大きめに出た
- 地域実験は偏りはほぼないが、1回ごとのばらつき（標準偏差）は24〜31%
- 実験で Web だけを補正しても、需要に合わせる場面ではチラシの過大評価が +68% → +97% に増えた（Web が説明していた分が他の媒体に移る）

### C. 予算配分（週130万円、架空）
| 配分の決め方 | 本当の売上の上乗せ（最適＝100） | いまの配分より悪くなった回 |
|---|---|---|
| いまの配分（テレビ35・Web19・チラシ46%） | 95.0 | — |
| 本当の反応曲線で最適化（45・30・25%） | 100.0 | — |
| MMM（需要と関係なく動くデータ） | 98.3（25〜75%点 96.4〜99.2） | 60回中17% |
| MMM（需要に合わせるデータ） | 98.5（95.2〜99.1） | 25% |
| 実験で補正した MMM（需要と関係なく） | 98.8（97.6〜99.5） | 10% |
| 実験で補正した MMM（需要に合わせる） | 99.1（98.1〜99.5） | 13% |
- 配分の見直しで上がる余地は約5%。MMM で決めると多くはその近くまで行くが、4〜10回に1回はいまより悪くなった
- ROI が大きく外れても配分の損が小さいのは、反応曲線が頭打ちで、配分の多少の違いでは売上があまり変わらないため（推測）

- アドストック（再帰 CTE）と4週計・52週平均（ウィンドウ関数）を T-SQL で書き、DuckDB で流して Python と比べた。差は最大 7×10⁻¹²（`results/D_sql_check.json`）

## 頑健性（B、広告費が需要と関係なく動く場面、30回）
| 条件 | テレビ | Web | チラシ |
|---|---|---|---|
| 主（3年・季節あり） | 平均−3%・中央値34% | +25%・29% | +49%・48% |
| データ1年（52週） | +28%・43% | +35%・47% | −1%・55% |
| 雑音2倍 | −6%・41% | +22%・36% | +102%・71% |
| 季節を入れない | +8%・80% | +25%・42% | −49%・90% |
| アドストックなしと決めつける | −76%・76% | −35%・40% | +26%・33% |
（平均のずれ・ずれの大きさの中央値）
- テレビのように効き目が持ち越す媒体で、アドストックを入れないと ROI を約4分の1に見積もる
- 地域実験の長さ：Web を 8 週止めると、ずれの標準偏差は 37%、12 週なら 29%（実験だけを150回くり返して確認。平均のずれは −7% と −4%）

## データ
- 経済産業省「特定サービス産業動態統計調査」長期データ「広告業」月・実数（1988年1月〜2024年12月、2024年分は年間補正済）。広告会社の売上高で、広告主が払った広告費そのものではない（目安として使う）
- 経済産業省「商業動態統計」業態別販売額（スーパー・コンビニ・百貨店、2014年1月〜2024年12月。F135・F231 で取得したもの）
- みどりホーム（架空）のデータは `src/03_分析.py` のシミュレーション（実在の会社の数字ではない）

## 手法
- A：小売3業態の販売額（対数）を広告業の売上高（対数）に回帰。月のダミー、トレンド、コロナ期（2020年4月〜2021年12月）、消費税の駆け込み・反動のダミーを順に入れる。HAC 標準誤差
- B：アドストック a_t＝s_t＋減り方×a_{t−1}、飽和 x/(x+K)。MMM は減り方（0〜0.8）と K（4通り）を格子で選び、残りは最小二乗（季節は年2周期までのフーリエ項とトレンド）
- 需要に合わせる場面：担当者には見えるがデータに残らない需要の動き（AR(1)）と季節に合わせて広告費を増やす
- 地域実験：47地域を半分に分け、片方で Web を12週止める。止める前の16週との差の差で ROI を出す
- 実験で補正した MMM：Web の ROI を実験の値に固定し、他の媒体を推定し直す
- C：反応曲線から、週の予算130万円の配分を5%刻みで最適化し、本当の曲線で評価

## 言えないこと
- 業界全体の回帰は、広告の効き目を測っていない。売上が先に動いて広告があとから動く形があり、季節・景気・コロナ期が両方を動かしている
- 広告業の売上高は広告主の広告費とは違う（広告会社の取扱い、調査対象の企業の入れ替わりもある）。電通「日本の広告費」は年次しかないので使っていない
- シミュレーションの結果は、置いた設定（3媒体・減り方・飽和の形・雑音の大きさ）での話。実際の MMM の当たり方は、データの量と広告費の動き方しだい
- 地域実験は、地域どうしで需要の動きがそろっていること、止めた媒体が他の地域にこぼれないことを仮定している
- 予算配分の「約5%」は、この架空の設定での値
