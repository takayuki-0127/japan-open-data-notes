# durable-goods-diffusion-japan：内閣府「消費動向調査」で、家電や車の普及率が描いたS字を調べる

内閣府「消費動向調査」の長期時系列表1-3「主要耐久消費財の普及率の推移（二人以上の世帯）」（1960〜2026年）を使ったリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| 142 | 温水洗浄便座やエアコンの普及率は、どんなS字を描いたか | 品目ごとに3パラメータのロジスティック曲線 p(t)=K/(1+exp(−r(t−t0))) を最小二乗で当てはめ、上限K、上限の半分に達した年t0、上限の10%→90%にかかる年数（4.394/r）を比べる。ピークの後に下がった品目はピークの年までで当てはめた | `src/a142_scurve.py` |

## 主な結果
- 上限（K）は、薄型テレビ100%（上限に張り付き）、ルームエアコン91%、乗用車84%、温水洗浄便座83%、パソコン81%、食器洗い機39%
- 上限の10%から90%まで広がる年数は、薄型テレビ7年、パソコン16年、温水洗浄便座24年、乗用車25年、ルームエアコン27年（普及の初期から記録がある5品目）
- 普及率が初めて50%を超えた年：乗用車1978年、ルームエアコン1985年、パソコン2001年、温水洗浄便座2003年、薄型テレビ2009年
- 温水洗浄便座は14.2%（1992年）から82.5%（2026年）まで上がり、2016年以降は80〜82%で頭打ち
- ピークの後に下がった品目：デジタルカメラ77.0%（2013年）→47.6%（2026年）、乗用車86.4%（2003年）→76.2%、パソコン79.1%（2016年）→74.7%、薄型テレビ98.1%（2016年）→94.1%

## 動かし方
`data/raw.zip`（e-Stat から取得した Excel）が入っていて、初回の実行で `data/raw/` に展開されます。

```bash
pip install -r requirements.txt
python src/a142_scurve.py
```

## 注意
- 普及率は「1台以上持っている世帯の割合」で、何台持っているかは入っていません
- 2013年4月（調査方法の変更）、2018年10月（郵送・オンライン調査）、2025年3月（新規世帯のオンライン化と品目の変更）に調査が変わっていて、前後で段差がありえます
- 表1-3にはこの表の品目だけが入っていて、洗濯機・冷蔵庫・カラーテレビなどの古い品目は入っていません。洗髪洗面化粧台・システムキッチン・食器洗い機・スマートフォン・タブレット型端末は、記録が始まった時点ですでに上限の4分の1を超えていたので、広がる速さの比較からは外しました
- 薄型テレビの上限は100%に張り付きました。2011年の地上デジタル放送への移行でブラウン管テレビから一斉に買い替えた影響が大きく、ふつうのS字とは成り立ちが違います
- ロジスティック曲線は形を要約するための当てはめで、将来の予測ではありません
