# F292 南海トラフの被害想定は、人口の変化でどう変わるのか

内閣府の南海トラフ巨大地震の被害想定（2025年3月）にある都府県別・原因別の死者数を使います。揺れ・津波・建物・避難の条件はそのままにして、人口の規模と年齢構成だけを社人研の将来推計（2023年推計）に置き換え、2050年まで動かしました。

- 計画：[PLAN.md](PLAN.md)（データを開く前に書いてコミット）
- 図：[figures/](figures/)　数値：[results/main.json](results/main.json)

## 問い

2025年想定の死者数（最大で約29.8万人）について、ほかの条件を一切変えずに人口と年齢だけを2050年の推計に置き換えると、何%動くか。そのとき動くのはどの原因か。

## 手法

1. **96表の読み取り**（`zz_f292_00`, `zz_f292_02`）：テキスト化しただけだと列の順が崩れる行があったので、数値の右端の x 座標から列を決めました。各表について、都府県の足し上げと印刷されている合計を比べると、印刷値が1,000人以上の576列のうち70列で3%を超え、最大7.6%でした（都府県の値も合計も「約」で丸めてあるため）。独立レビューで別の方法で抜き出した96表（3,840行）とも、すべての行が一致しました。
2. **主表**：96表のうち合計が最大の表（陸側ケース・津波ケース①・冬・深夜・風速8m/s・早期避難率低。原因の足し上げ 296,840人、印刷合計は約29.8万人）。
3. **規模**：原因ごとに 死者 × P(t)/P(2020)（都府県別。2020年は国勢調査の実績）。手法資料（sanko_gaiyo pp.28–29 ほか）で人口の大きさに比例するのは、建物倒壊（建物1棟当たり滞留人口）・津波・火災のうち b（倒壊・焼失家屋内の救出困難者）と c（延焼時の逃げまどい：焼失人口）です。急傾斜地（0.098×全壊棟数×0.7×滞留人口比率）と火災 a（0.055×出火件数×屋内滞留人口比率）は時刻の「比率」なので、人口の大きさは効きません。表では火災が a/b/c に分かれていないため、**全原因を人口に比例させる近似**にしました。急傾斜地と火災（全部）を固定すると、主表の2050年は規模だけ −23.7%、差し引き −10.4% で、本文の値（−24.5%、−11.1%）より約0.7ポイント小さい減りになります（`main.json` の S1）。
4. **年齢**：手法資料の補正係数 C ＝ 0.34×(15歳未満比率) ＋ 0.62×(15–64) ＋ 1.79×(65–74) ＋ 2.81×(75+) は**津波の死者だけ**に掛かります。そこで津波の死者に C(t)/C(2015) を掛けました（想定は2015年国勢調査の比率で係数を作っています）。想定では市区町村別の比率を使っていますが、ここでは**都道府県の比率で近似**しています。
5. **分解**：対数平均（LMDI）で、変化を「規模」と「年齢」に分けました。
6. 都府県ごとの値は出さず、全体の集計だけを示します。

## 結果（主表・2050年）

| | 死者数 | 想定からの変化 |
|---|---|---|
| 想定のまま（原因の足し上げ） | 296,840 | — |
| 人口の規模だけ変える | 224,197 | **−24.5%** |
| 規模＋年齢構成 | 263,885 | **−11.1%** |

- **動くのは津波です。** 津波の死者は規模で −58,892人、年齢で +45,661人動き、年齢が規模の減りの **77.5%** を打ち消します（図2）。建物倒壊（−17,556人）と火災など（−2,168人）は規模だけで下がります。全体では、年齢が規模の減りの 58.1% を打ち消します。
- 被害の出る40都府県の人口は2020→2050年に −14.6%（単純合計）です。死者の多い地域ほど減りが大きいので、死者で重み付けした規模の減りは −24.5% と大きくなります。
- 65歳以上の割合（40都府県）は 2015年 26.1% → 2020年 27.8% → 2050年 36.1% です。年齢係数は2015年基準なので、**2020年の時点ですでに +3.4%** 上にずれています（図1の2020年の点）。

| 仮説（PLAN） | 結果 | 判定 |
|---|---|---|
| H1 規模だけで2050年の合計が15%以上減る | −24.5% | 支持 |
| H2 津波では、年齢が規模の減りの1/3以上を打ち消す | 77.5% | 支持 |
| H3 差し引きの減りは15%未満 | −11.1% | 主表では支持。ただし96表中56表で15%以上減る（R1）、重みを半分にすると −17.6%（R2b） |
| H4 2012年想定（約32.3万）→2025年想定（約29.8万）の差 −2.5万のうち、基準人口（規模と年齢）の変化で説明できるのは半分未満 | 規模＋年齢：−0.14万（5.5%）／参考：規模だけ −1.50万（60%） | 支持（計画どおりの規模＋年齢で判定。2012年想定も同じ年齢補正係数を平成22年国勢調査で使っていたことを手法資料で確認。2025年想定の都府県・原因の内訳で近似した計算） |

## 頑健性

| ケース | 規模だけ | 規模＋年齢 |
|---|---|---|
| 主 | −24.5% | −11.1% |
| R1 96表すべて | −23.7%〜−29.2% | −8.1%〜−21.7%（津波の割合との相関 0.85、図3） |
| R2a 65歳以上の重みを一つに（2.30） | −24.5% | −14.0% |
| R2b 重みの強さを半分に | −24.5% | −17.6% |
| R3 2045年で比べる：2023推計／2018推計 | −20.2%／−20.2% | −8.0%／−8.3% |
| R4 年齢の基準を2020年に | −24.5% | −14.1% |
| R5 主表で死者1,000人以上の17都府県だけ | −24.5% | −11.0% |

規模の効果はどの組み合わせでもほぼ同じでした。差し引きの減りは、年齢の重みの置き方と、津波が占める割合で大きく動きます（図3・図4）。

## 問い直し（事後に決めた比較）

同じ条件（地震動・津波ケース・季節時刻・風速）で、早期避難率を「低」から「高＋呼びかけ」に変えた場合の差を、想定の表どうしで比べました。主表では **−40.4%**、48組の範囲は −40%〜−80% です。人口を2050年にしたときの変化（−8%〜−17%）より、48組すべてで大きくなりました（図6）。避難の条件を「高＋呼びかけ」にした表でも、2050年の人口での変化は −13.8% でした。これは想定の中の条件の差を並べただけで、何かの施策の効果を見積もったものではありません。

## 言えないこと

- 揺れ・津波の浸水・建物の数と耐震性・避難の行動は**2025年想定のまま**固定しています。2050年の死者数の予測ではありません。建物の建て替えや耐震化が進めば数は変わります。
- 年齢の補正係数は市区町村別の比率で作られているのに対し、ここでは**都道府県の比率で近似**しています。沿岸の市町村は高齢化が速い傾向があるので、年齢の効果を小さめに見ている可能性があります（推測）。
- 想定の基準人口は2020年国勢調査ベースと見ています（要配慮者の推計に令和2年国勢調査を使うと書かれているため。**推測**）。
- 建物倒壊・火災の死者に年齢の影響は入れていません（想定の手法で入っていないため）。
- 都府県の値は「ある程度幅をもって見る必要がある」と注記されています。
- 手法資料（p.26）では、避難の速さが避難行動要支援者（とその同行者）の割合で変わります。この年齢の経路はここでは入れていないので、年齢の効果を小さめに見ている可能性があります（推測）。
- 急傾斜地と火災 a は本来人口の大きさに比例しませんが、近似として比例させています（影響は約0.7ポイント、手法3）。

## 計画からのずれ

- 列の読み取りを、テキストから PDF の座標に変えました（テキストだと列順が崩れる表があったため）。
- H4 は2012年想定の原因別の内訳を確かめられなかったため、2025年想定の都府県・原因の重みで近似しました（PLAN に書いた代替のとおり）。
- 問い直しは、結果を見てから決めました。
- H4：初稿では計画にない「規模だけ・規模＋年齢の両方が半分未満」という基準で「どちらとも言えない」としていました。レビューを受けて計画どおり規模＋年齢で判定し直しました（支持）。手法資料の★印から年齢補正が2025年に新しく入った可能性も考えましたが、2012年の手法資料（資料2-2）に同じ係数（平成22年国勢調査）があることを確認したので、規模だけ（60%、外れ）は参考として併記しています。
- R3：2018年推計では2020年も推計値（国勢調査の実績ではない）なので、その基準は推計どうしの比です。

## レビューで直したこと

別のエージェントが記事とコードだけを見て確かめました。数字の照合はすべて一致し、96表は独立に抜き出した3,840行と一致、年齢の重みの扱いは手法資料どおり、再実行はバイト単位で一致しました。指摘を受けて次の点を直しました：人口に比例する原因の説明を手法資料どおりに直し、急傾斜地・火災を固定した場合（−23.7%・−10.4%、約0.7ポイント）を追加／H4 を計画どおりの基準で判定し直し（支持）、ずれに経緯を記載、2012年の手法資料で年齢補正の有無を確認／合計とのずれを数字で記載（70列で3%超、最大7.6%）／296,840人と約29.8万人の書き分け／避難の速さを通じた年齢の経路を「言えないこと」に追加／`data/` は書き写しのみで集計結果に都府県の値がないことを明記／R3 の2020年が推計値であることを記載。
