# F261 計画（事前登録）

2026-11-11 作成。この計画は、手法ごとの推計値を計算する前にコミットしています。データの取得のとき、内閣府・日本銀行の公表値の最新の数字（2026年4-6月期の潜在成長率 0.6%、GDP ギャップ +0.7% など）は目に入っています。手法を並べた結果はまだ見ていません。

## 問い

経済財政白書（内閣府）は毎年「潜在成長率は 0%台半ば」と書いています。この「潜在成長率」は、計算の仕方を変えるとどれだけ変わるのか。

- 内閣府と日本銀行は、どちらも生産関数アプローチで推計していますが、値は同じではありません。
- 統計の手法（HP フィルター、バンドパスフィルター、Hamilton フィルター、状態空間モデル）だけで実質 GDP からトレンドを取り出すと、どれだけ違う値になるか。
- 「直近の潜在成長率」は、あとでデータが増えるとどれだけ書き換わるか（端点の問題）。

## データ

- 内閣府「GDP ギャップ、潜在成長率」（月例経済報告の関係資料、2026年4-6月期2次速報ベース、2622gap.xlsx）：1994年1-3月期〜2026年4-6月期の GDP ギャップ、潜在成長率と、その寄与度（TFP・資本・労働時間・就業者数）
- 日本銀行「需給ギャップと潜在成長率」（2026年10月5日公表、gap.xlsx）：1983年1-3月期〜2026年4-6月期の需給ギャップ（資本・労働の内訳つき）、半期ごとの潜在成長率と寄与度
- 内閣府「四半期別GDP速報」2026年4-6月期2次速報の実質季節調整系列（2020暦年連鎖価格）：1994年1-3月期〜2026年4-6月期
- F50 で集めた GDP 速報の公表回ごとの実質季節調整系列の前期比（2001〜2026年の195回）：リアルタイムの推計に使う

## 手法

統計の手法は、実質 GDP の対数にかけて「潜在 GDP（トレンド）」を出します。潜在成長率は、トレンドの前年同期比（％）で比べます。内閣府の公表値は前期比年率なので、比べるときは4四半期の平均にそろえます。

| 名前 | 中身 |
|---|---|
| CAO | 内閣府の公表値（生産関数） |
| BOJ | 日本銀行の公表値（生産関数）。半期の値を、その半期の四半期に割り当てる |
| HP1600 | HP フィルター、λ=1600（四半期の標準） |
| BK | Baxter–King バンドパス（6〜32四半期、K=12）。両端12四半期は出ないので、端は計算しない |
| CF | Christiano–Fitzgerald バンドパス（6〜32四半期、非対称） |
| HAM | Hamilton フィルター（h=8、p=4）：8四半期先を、いまの4四半期分の値で回帰した当てはめ値をトレンドとする |
| UC | 状態空間モデル（ローカル線形トレンド＋AR(2) のサイクル、statsmodels UnobservedComponents、平滑化した値） |
| LIN | 景気の山を区切りにした折れ線トレンド（区切りは 2008年1-3月期と 2020年1-3月期、事前に固定） |

指標：
1. 潜在成長率の手法間の幅（最大−最小）：年度平均で、FY2000〜FY2025 の各年度。とくに直近の FY2025
2. GDP ギャップの符号：手法の間で符号（＋／−）が割れた四半期の割合（2000〜2026年）
3. CAO と BOJ の潜在成長率の差（暦年 2010〜2025 の平均）を、寄与度（TFP・資本・労働時間・就業者数）に分ける
4. 端点：データを各四半期で切って HP1600・UC・HAM を流し、その時点の「直近の潜在成長率」が、全期間で推計した値とどれだけ違うか（疑似リアルタイム）。F50 の公表回ごとのデータを使った本当のリアルタイムの値とも比べる

## 仮説と「外れ」の基準

- H1：直近（FY2025）の潜在成長率は、手法の間の幅が 0.5ポイント以上ある。**外れ**：幅が 0.3ポイント未満
- H2：2000〜2026年の四半期のうち 20%以上で、手法の間で GDP ギャップの符号が割れる。**外れ**：10%未満
- H3：CAO と BOJ の潜在成長率の差の半分以上（絶対値の平均で）は TFP の寄与の違いから来る。**外れ**：TFP の割合が半分未満
- H4：疑似リアルタイムの直近の潜在成長率は、全期間の値と平均で 0.3ポイント以上違う（平均絶対差、HP1600）。リアルタイム（データの改定込み）の方が疑似リアルタイムより違いが大きい。**外れ**：平均絶対差が 0.15ポイント未満、またはリアルタイムの方が小さい

## 頑健性のチェック（3つ以上）

1. HP の λ を 400・1600・6400 で変える
2. コロナ期（2020年4-6月期〜12月期）を前後の線でならしてから推計する
3. 潜在成長率の定義を「前年同期比」から「前期比年率の4期平均」に変える
4. 推計の開始を 1994年から 2000年に変える
5. Hamilton の h を 8 から 12 に変える
