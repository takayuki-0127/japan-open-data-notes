### regional-price-index-japan：消費者物価地域差指数で、物価がいちばん高い県と費目ごとの差を調べる

総務省「小売物価統計調査（構造編）」の「10大費目別消費者物価地域差指数」（全国平均＝100、47都道府県、2013〜2025年）を使ったリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A127 | 物価がいちばん高い県はどこか。費目ごとに見ると地域差はどこで大きいか。順位は年によって変わるか | 2025年の順位、費目ごとの散らばり（標準偏差・最大と最小）、「家賃を除く総合」の2013年と各年の順位相関（スピアマン）と上位3県に入った年数 | `src/a127_regional_prices.py` |

#### 主な結果
- 2025年の総合は東京都104.2が最も高く、神奈川県103.3、北海道102.4、京都府101.1が続く。最も低いのは群馬県96.2、鹿児島県96.4、長野県96.9。総合の1位は2013〜2025年の13年ずっと東京都
- 家賃（持家の帰属家賃を含む）を除く総合では、2025年は北海道103.2が1位で、神奈川県102.7、東京都102.2の順。北海道は100.1（2013年）→103.2（2025年）と13年で3.1上がり、2023年から1位
- 費目ごとの都道府県の標準偏差（2025年）は、教育9.3、住居8.6、光熱・水道5.2が大きく、交通・通信1.2、保健医療1.1が小さい。住居は東京都129.8〜岡山県79.1、光熱・水道は北海道117.8〜大阪府90.6、教育は大阪府124.7〜富山県78.1、食料は沖縄県106.6〜長野県95.0
- 家賃を除く総合の順位の、2013年との相関は2014年0.94、2019年0.85、2025年0.60と下がってきた。13年すべてで上位3県に入ったのは東京都と神奈川県だけ。2013→2025年で上がったのは北海道（＋3.1）、宮城県（＋1.9）、熊本県（＋1.8）、下がったのは和歌山県（−2.0）、滋賀県（−1.7）、鹿児島県（−1.5）

#### 動かし方
`data/regional_price_index.csv`（都道府県×年×費目に整えたもの）が入っているので、そのまま動きます。元の Excel から作り直すときは、各年の「表1 10大費目別消費者物価地域差指数」を `data/raw/127_<年>.xls` の名前で置き、この CSV を消してから実行してください（e-Stat：https://www.e-stat.go.jp/stat-search/files?toukei=00200571 の「構造編」）。

```bash
pip install -r requirements.txt
cd src
python a127_regional_prices.py
```

#### データ
| ファイル | 中身 |
|---|---|
| data/regional_price_index.csv | year, pref（47都道府県）, item（総合・家賃を除く総合・10大費目）, index（全国平均＝100）, imputed_rent_included（総合と住居が持家の帰属家賃を含むか） |

#### 注意
- 2013〜2017年の「総合」「住居」は持家の帰属家賃を除いたもの、2018年以降は含むもので、定義が違います。年をまたいで比べるときは、全期間で同じ定義の「家賃を除く総合」を使いました
- 地域差指数は、各都道府県の県庁所在市などで調べた価格と、その地域の買い物の中身（ウエイト）から作った指数です。県内のほかの市町村の物価を表すものではありません
- 指数は年ごとに全国平均＝100で作られていて、物価の上がり方（時系列の変化）ではなく、その年の全国との差を表します
- 教育は私立学校の授業料などの影響が大きく、県によって在学者の構成が違うことにも注意が要ります
