# 862 質問の順番で、後の質問の答えはどれだけ変わるのか？（アンケート）

アンケートでは、前に聞いた質問が、後の質問の答えに影響することがあります。たとえば「店員の対応」を先に聞くと、そのあとの「店全体」の満足が、対応の印象に引っぱられます。**ここでは、作成者が乱数で作った架空の飲食店の客アンケート（客600人の料理・対応・値段の本当の満足を作成者が置いたもの）で、半分は「店全体 → 対応」、半分は「対応 → 店全体」の順で聞き、店全体の満足の割合がどれだけ動くか、どんなときに動かないかを数えました。**

真ん中の選択肢の有無は関連する記事 861、選択肢の並び順は 863 で扱っています。この記事は「質問どうしの順番」に絞ります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A862 | 前の質問（店員の対応）を先に聞くと、後の質問（店全体の満足）の答えはどれだけ動くか。どんなときに動き、どんなときに動かないか。1回の調査で見分けられるか | 架空の飲食店の客600人。客ごとに料理・店員の対応・値段の本当の満足（1〜5の連続の値）を置く。平均は料理4.2・対応3.0・値段3.8、標準偏差はどれも0.7、3つの相関は0.3。本当の全体の満足 g は3つの平均（平均3.67）。答えは5段階で、答えるときのぶれ（標準偏差0.5）を足して四捨五入し1〜5に収める。順番A（300人）は店全体を先に聞き、g+ぶれで答える。順番B（別の300人）は対応のあとに店全体を聞き、(1−λ)×g＋λ×対応＋ぶれで答える。λ は前の質問に引っぱられる強さで、基本は0.3（作成者が置いた値）。満足の割合は「満足」「やや満足」（4・5）の割合。調査を作り直して2,000回。「1回の調査で見分けられるか」は、2つの割合の差の検定（目安として差が標準誤差の1.96倍を超えるか）で数えた。確かめとして、λ を−0.2〜0.5の6通り、対応の平均を2.6〜4.4の5通りに変えた30通りを各500回数えた。seed 862 | `src/a862_question_order.py` |

## 主な結果

### 順番ごとの「店全体に満足（4・5）」の割合（2,000回の平均）
| | 満足の割合 | 10〜90%の範囲 | 平均の点 |
|---|---|---|---|
| 順番A：店全体を先に聞く | 59.2% | 55.7〜63.0% | 3.66 |
| 順番B：店員の対応のあとに聞く | 48.1% | 44.3〜51.7% | 3.46 |
| （参考）店員の対応に満足 | 28.0% | 25.7〜30.3% | — |

- 対応を先に聞くと、店全体の満足は**11.0ポイント**下がった（10〜90%の範囲で6.0〜16.0ポイント）。2,000回の99.4%で、順番Bのほうが低かった
- 順番Aでは「過半数が満足」、順番Bでは「満足は半分以下」と読める
- 1回の調査（各300人）で、差が偶然では説明しにくい大きさ（目安の検定）になったのは78.8%だった。残りの約2割では、順番の影響があっても見分けられなかった
- 「店員の対応」と「店全体」の答えの相関は、順番Aで0.37、順番Bで0.46だった

### 確かめ：引っぱられる強さ λ と、対応の平均を変えると（30通り、各500回、`results/robustness.csv`）
| 対応の平均（λ=0.3） | 対応 − 全体（本当の満足の平均の差） | 順番B − 順番A | 1回の調査で見分けられた割合 | 相関（A → B） |
|---|---|---|---|---|
| 2.6 | −0.93 | −15.2ポイント | 97.8% | 0.37 → 0.46 |
| 3.0（基本） | −0.66 | −11.1ポイント | 78.4% | 0.37 → 0.46 |
| 3.4 | −0.40 | −6.5ポイント | 38.8% | 0.37 → 0.46 |
| 4.0 | 0.00 | −0.3ポイント | 5.6% | 0.36 → 0.45 |
| 4.4 | +0.27 | +2.4ポイント | 10.6% | 0.34 → 0.43 |

| λ（対応の平均3.0） | −0.2 | 0（影響なし） | 0.1 | 0.2 | 0.3（基本） | 0.5 |
|---|---|---|---|---|---|---|
| 順番B − 順番A | +6.9 | −0.2 | −3.6 | −7.3 | −11.1 | −17.8ポイント |
| 1回の調査で見分けられた割合 | 40.6% | 5.0% | 14.0% | 43.6% | 78.4% | 99.2% |

- 動く向きと大きさは、λ（作成者が置いた引っぱりの強さ）と、前の質問と全体の差で決まった。30通りで−23.7〜+10.3ポイント
- 対応の平均が全体とほぼ同じ（4.0）なら、λ をどう置いても差は1.2ポイント以内で、平均の割合からは順番の影響が見えなかった
- それでも、λ が正の20通りすべてで、順番Bの相関が順番Aより0.03〜0.14高かった。平均が動かないときでも、2つの答えは似てくる
- λ を負（前の質問から逆に離れる）に置くと、向きが逆になり、順番Bの満足が上がった。どちらの向きになるかは、ここでは置いた値で決めている

### 1回分の調査（data/respondents.csv）
- 店全体の満足は順番A 59.7%、順番B 52.3%（差−7.3ポイント）。相関は順番A 0.39、順番B 0.52

## 動かし方
```
pip install -r requirements.txt
cd src && python a862_question_order.py
```
数秒で終わります。`data/respondents.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約3秒）
- λ=0（影響なし）の5通りでは、差がどれも±0.4ポイント以内で、目安の検定で見分けられた割合は4.4〜6.8%（偶然に引っかかる約5%どおり）だった
- 「11ポイント」は λ=0.3・対応の平均3.0と置いたときの値で、置き方で−23.7〜+10.3ポイント動いた（上の表）

## データ
- `data/respondents.csv`：1回分の架空の客600人。id・order（A_全体が先／B_対応が先）・food・service・price（本当の満足）・q_service・q_overall（5段階の答え）

## 注意（言えないこと）
- 架空のデータです。料理・対応・値段の満足の分布、引っぱられる強さ λ、答えるときのぶれは作成者が置いたもので、結果はこれで決まります。とくに「11ポイント」は λ と対応の平均の置き方で−24〜+10ポイント動きます
- 前の質問に寄るか（λ が正）、逆に離れるか（λ が負）は、作成者が置いて決めています。実際にどちらの向きになるかは、質問の内容や聞き方で変わり、ここでは言えません
- 引っぱられる強さは全員同じと置きました。人によって強さが違う場合、店の種類や質問の数による違いは入れていません
- どちらの順番が「正しい」かは、ここでは言えません。ここでは、全体を先に聞いた答えを作成者が置いた本当の満足に近いものとして扱っています
- 実際の人の答え方を測った実験ではありません
