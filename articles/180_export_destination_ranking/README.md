# 180 日本の輸出相手国のランキングは30年でどう変わったか：普通貿易統計

財務省「貿易統計」（普通貿易統計）の「輸出入額の推移（地域（国）別・年別）」から、1995〜2025年の国別の輸出額を取り出し、輸出相手国の順位と割合の変化を調べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A180 | 日本の輸出相手国のランキングは、1995年から2025年の30年でどう変わったか | 国別輸出額の順位の推移（バンプチャート）、輸出総額に占める割合、1995年と2025年の順位の比較 | `src/a180_rank.py` |

## 主な結果
- 輸出総額は 1995年 41.5兆円 → 2025年 110.4兆円（2.66倍）
- 1位は1995〜2008年は米国。その後は米国と中国が入れ替わり、中国が1位だったのは2009〜2012年、2018年、2020〜2022年の8年。2023年からは米国が1位
- 米国の割合は 27.3%（1995年）→ 18.5%（2025年）、中国は 5.0% → 17.0%。中国向けの輸出額は30年で9.1倍
- 上位10か国のうち8か国は1995年と2025年で同じ。マレーシア（9位→13位）と英国（10位→14位）が抜け、インド（21位以下→8位）とベトナム（21位以下→9位）が入った
- 欧州6か国（ドイツ・英国・オランダ・フランス・ベルギー・イタリア）の割合は 13.4% → 8.3%。アジア11か国・地域は 42.9% → 53.2%
- 2025年の上位は 米国20.4兆円、中国18.8兆円、台湾7.9兆円、韓国7.0兆円、香港6.4兆円、タイ4.2兆円、シンガポール3.2兆円、インド2.9兆円、ベトナム2.8兆円、ドイツ2.7兆円

## 動かし方

```bash
pip install -r requirements.txt

```

## データ
| ファイル | 中身 |
|---|---|
| data/exports_by_country_1995_2025.csv | 年、国・地域、税関の国コード、輸出額（百万円）。1995〜2025年のどこかの年で上位20位以内に入った26か国・地域 |
| data/exports_total_1995_2025.csv | 年、輸出総額（百万円、地域別ファイルの合計） |

元の表：財務省 貿易統計「輸出入額の推移（地域（国）別・主要商品別）」（https://www.customs.go.jp/toukei/suii/html/time.htm）の地域別・年別CSV（d42ca001〜009.csv、千円）。普通貿易統計（e-Stat toukei=00350300）と同じ集計。

## 注意
- 順位は data の26か国・地域の中での順位。上位20位まではすべての国の中での順位と同じで、21位以下はまとめて「21位以下」とした
- 金額は名目の円建てで、為替や物価の影響を含む
- 香港を経由して中国本土に届く分などは、統計上は香港向けになる（仕向国は貨物の最終の届け先として申告された国）
- 2025年は確報前の値を含む可能性がある
