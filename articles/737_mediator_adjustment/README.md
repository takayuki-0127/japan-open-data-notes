# 737 施策の効き道になる変数を回帰に入れると、施策の効果はどれだけ小さく出るのか（手法の解説・正解の分かるデータで試す）

施策が「来店回数を増やし、その結果として売上が増える」とき、来店回数は施策の効き道（媒介する変数）です。売上の回帰に来店回数を入れると、施策の係数からは来店回数を通る分が抜け、全体の効果より小さく出ます。**ここでは、全体の効果を10千円に固定した架空の会員1,000人で、来店回数を通る割合を0〜100%に変え、来店回数を入れる・入れないで施策の係数を比べました。** 来店回数と売上の両方に効く見えない要因があるときも試しました。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A737 | 効き道の変数を入れると、施策の係数はどれだけ小さくなるか | 会員1,000人、施策は無作為に半分。来店回数＝通る分×施策＋誤差（sd 3）、売上＝直接の効果×施策＋1.0×来店回数＋誤差（sd 10）。全体の効果10千円、通る割合0〜100%。見えない要因 U の強さ0〜4（通る割合50%）。各1,000回、最小二乗。seed 737 | `src/a737_mediator.py` |

## 主な結果

| 来店回数を通る割合 | 入れない（全体の効果） | 入れる |
|---|---|---|
| 0% | 10.0 | 10.0 |
| 50% | **10.0** | **5.1** |
| 100% | 10.0 | 0.0 |

（単位：千円、1,000回の平均）

- 来店回数を入れると、施策の係数は来店回数を通る分だけ小さくなった。全部が来店回数を通るときは0になった
- 入れない回帰は、どの割合でも全体の効果10千円をほぼ当てた（施策を無作為に配ったため）
- 来店回数と売上の両方に効く見えない要因があると、来店回数を入れた係数は本当の直接の効果5千円からも外れ、要因の強さ4では−1.4千円とマイナスになった

```
pip install -r requirements.txt

```

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- 来店回数を入れない推定が、どの条件でも全体の効果10千円に近いこと（9.98〜10.04）

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 737）

## 注意（言えないこと）
- 架空のデータです。効き道・係数・ばらつきは作成者が置いたもので、数字はこれで決まります
- 「来店回数を入れた係数＝直接の効果」と読めるのは、来店回数と売上の両方に効く要因がほかにない場合だけです。実際のデータでそれを確かめる方法は、このデータからは分かりません
- 施策を無作為に配っていない場合は、全体の効果の推定にも別の偏りが入ります（扱っていない）
