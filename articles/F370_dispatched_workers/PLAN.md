# F370 PLAN（事前の計画）：派遣で働く人は、2008年のピークからどこまで減ったのか？

作成：2026-11-16 14:00（データを取得し、表の形と注を確かめたあと、男女・年齢別の推移を集計する前に書いた）

## 問い
労働者派遣は、2004年に製造業への派遣が解禁されて大きく増え、2008年の景気の落ち込みで「派遣切り」が話題になりました。2012年・2015年には派遣の法律が改正され、日雇い派遣の原則禁止や派遣期間の上限の見直しがありました。

知りたいこと：労働者派遣事業所の派遣社員は、2008年のピークからどこまで減り、その後どうなったのか。男女・年齢でどう違うのか。非正規の中で、派遣の割合はどう変わったのか。

知りたい人：人材派遣・人事の担当、労働市場の統計を読む人、働き方を考える人。

既存の看板記事との違い：jodn の 370 は雇用者の割合（従業上の地位）を扱い、雇用形態の内訳は扱っていない。existing_F_titles.txt と jodn の README を「派遣」で検索して、同じ問いの記事はなかった。

## データ
- 総務省「労働力調査」長期時系列データ（詳細集計）年平均 10-1「年齢階級（10歳階級）別就業者数及び年齢階級（10歳階級）、雇用形態別雇用者数」（2002〜2025年、男女別、万人）。2005〜2021年はベンチマーク人口の切り替えに合わせた時系列接続用の値。
- 同 四半期平均 9-1（2002年1〜3月期〜、男女計）。ピークの時期の確かめに使う。
- 「労働者派遣事業所の派遣社員」は勤め先での呼び方による区分（本人の答え）。

## 取得前に見たもの（開示）
- 表の形を確かめるときに、年平均の派遣社員の男女計・男・女の2002〜2025年の値（男女計：2008年140万人、2012年91万人、2025年156万人など）と、2016〜2025年の雇用形態の内訳の一部、注（2013年の調査票の変更、2009年以降の非正規の集計方法など）を目にした。年齢別の値と割合は計算していない。

## 仮説と「外れ」の基準
- H1：2025年の派遣社員は2008年の数を上回っている。下回っていれば外れ。
- H2：2008→2012年の減り方（%）は、男のほうが女より大きい。小さければ外れ。
- H3：派遣社員のうち45歳以上の割合は、2008年から2025年に15ポイント以上上がった。上がりが15ポイント未満なら外れ。
- H4：非正規の職員・従業員に占める派遣社員の割合は、2025年のほうが2008年より低い。高いか同じなら外れ。

## 手法
- 年ごとの派遣社員の数を男女・年齢（15〜24歳、25〜34歳、35〜44歳、45〜54歳、55〜64歳、65歳以上）で並べる。
- 非正規に占める割合、役員を除く雇用者に占める割合。
- 2012年と2013年の間に調査票の変更があるので、その段差の大きさを、ほかの雇用形態の動きと並べて確かめる。

## 頑健性（3つ以上）
1. 四半期の値でピークの時期と底の時期を確かめる。
2. 2013年の調査票の変更をまたがない期間（2013→2025年）で H3・H4 を見る。
3. 割合を「役員を除く雇用者」に占める割合にする。
4. 既公表値（時系列接続をしていない値）で H1 を確かめる。

## 問い直し（予定）
結果を見てから1つ足す。候補：同じ生まれの世代（例：2008年に25〜34歳の世代）を追うと、派遣で働く人は年を取ってからも派遣のままなのか（年齢階級の10年ずらし）。

## 言えないこと（予定）
- 本人の答える「勤め先での呼び方」で、派遣元に雇われている人の数と完全には一致しない。
- 2013年の調査票の変更の影響の大きさは、この表だけでは決められない。
- 派遣で働く理由や、正社員への転換は分からない。
- 産業・職業の内訳はこの表にない。
- 法改正の影響は、景気の動きと同じ時期で分けられない。
