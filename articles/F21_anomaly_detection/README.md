# F21 公的統計の「いつもと違う動き」を自動で見つける（異常検知）

看板記事 F21。物価・景気・家計の月次98系列から、STL・Isolation Forest・変化点検出で「いつもと違う月」に自動で印を付け、出来事の年表と答え合わせした。

## 問い

毎月の統計から、過去と比べて異常な動きを自動で見つけられるか。見つかったのはどんな出来事で、見落としや「理由の分からない印」はどれくらいあるか。

## データ

| 統計 | 系列 | 変換 |
|---|---|---|
| 消費者物価指数（2020年基準、全国、中分類、原数値） | 48分類（穀類〜他の諸雑費。合計や再掲の系列は除く） | 対数の前月差 |
| 景気動向指数の個別系列ほか（内閣府） | 20系列（鉱工業生産・出荷・在庫率・求人・輸出・消費者態度指数・株価・長期金利・完全失業率など） | 対数の前月差（率や前年比の系列は前月差） |
| 家計調査（二人以上の世帯、1世帯あたり支出額・名目） | 30品目（米・生鮮野菜・一般外食・電気代・自動車等購入・宿泊料など） | 対数の前月差 |

- 期間は 2005年1月〜2026年8月の260か月。
- 生データはこのリポジトリの F12（物価）・F18（景気動向指数）・F11（家計調査）で取得したものを再利用した（`src/01_取得.py` が GitHub から取り直す）。

## 手法

| 段階 | 方法 | 何を見るか |
|---|---|---|
| 1系列ずつ | STL（周期12・seasonal=13・robust）で前月差を季節・傾向・残差に分け、残差を頑健な z スコアにする | |z|>4 の月に「印」 |
| まとめて | Isolation Forest（500本、98系列の |z| を10で頭打ち） | 月ごとの「動き方の珍しさ」 |
| 水準の変わり目 | PELT（ruptures、l2、最小区間6か月） | 新しい水準が始まった月 |
| 答え合わせ | 出来事の年表14件（前後1か月を含む） | 見つかった割合・印のうち出来事の月に入る割合 |

- 頑健な z は「(残差 − 中央値) ÷ 尺度」。尺度は MAD×1.4826 と平均絶対偏差×1.2533 の大きいほう。公共料金のようにほとんど動かない物価の系列では MAD が0に近くなり、z が数千になってしまうため、平均絶対偏差を下限にした。
- `src/detect.py` は、ほかの月次系列にもそのまま使える関数にしてある。

## 主な結果

- 閾値4で、98系列×260か月の中に印は555個（1系列あたり4年に1回ほど）。
- **年表の14件のうち13件**で、動くはずの系列のどれかに印が付いた。見つからなかったのは 2018年1月の家計調査の家計簿の改正だけ（家計調査の30品目の |z| は最大1.4）。
- 印のうち**53%が出来事の月**（前後1か月）に入った。出来事の月は全体の22%なので、でたらめに付けた場合の約2.5倍。ただし「動くはずの系列」で「出来事の月」に入る印は11%だけで、残りは年表にない動き。
- 年表にない印（259個）の75%は物価で、多くは制度の変更だった（年表に入れていなかった 2006年・2018年・2021年のたばこ税の引き上げ、2025年4月・2026年4月の授業料等の低下など）。
- **Isolation Forest の上位15か月のうち14か月**が出来事の月。1位は 2014年4月（44系列に印）、2位は 2019年10月、3位は 2020年4月。15位までで年表にないのは 2025年4月（授業料等・酒類・住宅着工床面積）だけ。乱数の種を5通り変えても順位の相関は0.96以上。
- 変化点（PELT）は、たばこで 2006/07・2010/10・2014/04・2018/10・2020/10・2021/10 と、増税の月をすべて当てた。電気代は 2023/02（負担軽減策の開始）と 2024/05（終了）、通信は 2021/04（値下げ）。授業料等は 2010/04・2019/10・2025/04 など。
- 閾値を下げると見落としは減るが印が増え、出来事に当たる割合が下がる（閾値2.5：印1,456個・14件すべて・40%／閾値8：印134個・9件・60%）。

## 頑健性

| 設定 | 印の数 | 年表の出来事を見つけた割合 | 印のうち出来事の月 | IF 上位15か月のうち出来事の月 |
|---|---|---|---|---|
| 基本（seasonal=13・robust・閾値4） | 555 | 93% | 53% | 93% |
| STL seasonal=7 | 688 | 100% | 50% | 80% |
| STL seasonal=25 | 533 | 86% | 53% | 93% |
| STL robust=False | 262 | 86% | 64% | 87% |
| STL を使わない（前月差をそのまま頑健z） | 1,201 | 86% | 34% | 60% |
| 物価だけ | 346 | 64% | 44% | 53% |
| 景気動向指数の系列だけ | 110 | 36% | 73% | 93% |
| 家計調査だけ | 99 | 36% | 65% | 80% |
| 系列を無作為に半分（3回） | 260〜295 | 57〜79% | 52〜58% | 73〜87% |

- STL の設定を変えても、結論（出来事の多くは見つかり、印の半分ほどは出来事の月）は変わらない。
- 季節を除かないと印が倍になり、出来事に当たる割合はでたらめに近づく（季節の動きを「異常」と数えてしまう）。
- 見つけられる出来事は、どの系列を監視するかで大きく変わる。

## 言えないこと

- 印が付いた理由は、データからは分からない。答え合わせは自分で作った年表との照合で、年表にない出来事は「理由の分からない印」に数えている。
- 年表の14件は自分で選んだもので、ほかの選び方をすると割合は変わる。
- 前月からの変化を見ているので、ゆっくり進む変化（物価の上昇が続くなど）は印になりにくい。
- 変化点は、区間の最小の長さ（6か月）の制約で、系列の最後の変わり目が1か月ずれることがある（授業料等の 2026/03 は、実際には 2026年4月の低下）。

## 再現手順

```
pip install -r requirements.txt
python src/01_取得.py     # data/raw/ を GitHub から取り直す（同梱済みなので省略可）
python src/02_整形.py     # data/changes.csv（260か月×98系列の前月差）
python src/03_分析.py     # results/
python src/04_図.py       # figures/（5枚）
```

## ファイル

- `src/detect.py`：STL 残差の頑健 z・印・Isolation Forest・PELT の関数
- `results/flags_stl_thr4.csv`：印の一覧（大きい順）／`events_check.csv`：年表との答え合わせ／`monthly_scores.csv`：月ごとの印の数と IF スコア／`top_months_isolation.csv`／`change_points.json`／`threshold_tradeoff.csv`／`robustness.csv`／`summary.json`／`z_scores.csv`
- `figures/`：f21_1 1系列の例／f21_2 ヒートマップ／f21_3 IF の上位の月／f21_4 変化点／f21_5 閾値のトレードオフ
