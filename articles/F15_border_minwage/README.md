# F15 県境をまたぐと最低賃金が違う。県境の町で雇用は違うか？（境界不連続デザイン）

看板記事 F15。県境をはさんで接する市区町村のペアの中で、最低賃金の上がり方の違いと、飲食・小売の従業者の伸びの違いを比べる。

## 問い

最低賃金が高い県と低い県が接する県境で、すぐ隣どうしの市区町村を比べると、最低賃金がより大きく上がった側で、飲食・小売の雇用の伸びは小さかったか。

## データ

| データ | 中身 | 置き場所 |
|---|---|---|
| 統計センター「SSDSE-A-2021」 | 経済センサス‐活動調査（2016年6月1日）の市区町村×産業大分類の従業者数・事業所数（民営） | data/raw/SSDSE-A-2021.csv |
| 統計センター「SSDSE-A-2026」 | 経済センサス‐活動調査（2021年6月1日）の同じ項目、2020年国勢調査の人口 | data/raw/SSDSE-A-2026.csv |
| 厚生労働省「地域別最低賃金の全国一覧」 | 都道府県別の最低賃金（年度ごと） | data/raw/minimum_wage_2002_2026.csv（F01・154 と同じ） |
| 市区町村の境界 | 国土数値情報 行政区域（2021）をもとにした簡略版 TopoJSON（smartnews-smri/japan-topography、CC BY 4.0） | `01_pairs.py` が取得 |

- 経済センサスの調査日（6月1日）に効いていた最低賃金は前年度10月の改定額なので、2016年 → 2015年度の額、2021年 → 2020年度の額を使った。
- 政令市は区を市にまとめた（SSDSE が市単位のため）。

## 手法

1. **ペアを作る**（`01_pairs.py`）：TopoJSON では隣どうしの市区町村が同じ境界線（arc）を共有するので、県の違う2つの市区町村が同じ arc を使っていれば「接している」とした。724ペア（656市区町村、県の組＝境界は87）。頑健性用に、接していなくても中心どうしが20km以内のペア（+1,271）も作った。
2. **ペアの中の差**（`03_reg.py`）：
   (Δlog 従業者_A − Δlog 従業者_B) = β ×（Δlog 最低賃金_A − Δlog 最低賃金_B）+ 誤差
   Δ は 2016→2021年。ペア固定効果を入れた回帰と同じ。β は弾力性（最低賃金が1%多く上がると従業者は何%変わるか）。標準誤差は県の組でクラスタ。外れ値は上下1%で丸めた。
3. **対照**：最低賃金の影響を受けにくい製造業でも同じ推定をし、飲食＋小売から製造業を引いた「三重差」も出した。
4. **並べ替え検定**：境界ごとに最低賃金の差の向きをランダムに入れ替えて、偶然でどれくらいの傾きが出るかを見た（2,000回）。

## 主な結果

| 産業（従業者） | 弾力性 | 95%区間 |
|---|---|---|
| 宿泊・飲食 | 0.31 | −3.30〜+3.93 |
| 卸売・小売 | 4.09 | −0.10〜+8.29 |
| 飲食＋小売 | 1.41 | −1.96〜+4.78 |
| 製造業（対照） | 2.72 | −0.12〜+5.55 |
| 全産業 | 0.26 | −1.55〜+2.07 |
| 飲食＋小売 − 製造業 | −1.12 | −4.97〜+2.73 |

- どの産業でも区間は0をまたぎ、最低賃金の上がり方の差と雇用の伸びの差に、はっきりした関係は見えなかった。並べ替え検定の p は0.44。
- ただし区間はとても広い。ペアの中の最低賃金の「上がり方」の差は最大でも1.8ポイント（2015→20年度の上昇率は全県で11.1〜13.6%）しかなく、水準の差（中央値33円、最大175円）に比べて、上がり方はほぼそろっている。この設計で80%の確率で見つけられる弾力性は約±4.8で、海外の研究でよく報告される0〜−0.3の大きさは見分けられない。
- 2016→21年の伸び（市区町村の中央値）は、宿泊・飲食が−13.8%、卸売・小売が−3.9%、製造業が−2.1%。2021年6月はコロナの最中で、飲食の落ち込みが大きい。

## 頑健性

`results/robustness.csv`（飲食＋小売の弾力性）

| 設定 | 弾力性 | 95%区間 |
|---|---|---|
| 基本（接するペア） | 1.41 | −1.96〜+4.78 |
| 中心が20km以内のペアも入れる | 1.46 | +0.34〜+2.57 |
| 大都市の境（1都3県・京阪神・中京の中）を除く | −1.15 | −5.00〜+2.70 |
| 人口で重みづけ | 0.83 | −0.31〜+1.97 |
| 最低賃金の差が20円以上のペアだけ | 1.46 | −2.00〜+4.92 |
| 外れ値を丸めない | 1.54 | −1.97〜+5.04 |
| 事業所数（飲食）で見る | 3.93 | −0.01〜+7.87 |
| 製造業を引く（三重差） | −1.12 | −4.97〜+2.73 |

- 20km以内のペアを足すと区間が0を外れるが、向きは「最低賃金が多く上がった側で雇用が伸びた」で、製造業も同じ向きに動いている。最低賃金の上がり方が大きいのは水準の低い県（地方）なので、地域全体の景気やコロナの影響の違いを拾っている可能性が高い。製造業を引くと向きは逆になり、区間は0をまたぐ。
- 2021年の水準（人口あたり従業者）で比べても、飲食＋小売 0.51（−0.36〜+1.39）、製造業 −1.30（−3.76〜+1.16）で、差は見えなかった（`results/level_2021.csv`）。

## 言えないこと

- 経済センサスは2016年と2021年の2時点だけで、計画前の動き（事前トレンド）を確かめられない。2021年はコロナの最中で、県ごとの営業制限の違いが飲食の雇用に混ざっている。
- ペアの中の最低賃金の上がり方の差が小さすぎて、小さな効果（弾力性 0〜−0.3 程度）は見分けられない。「影響がない」ではなく「この設計では見えない」。
- 市区町村をまたいで通勤する人の影響、個人の賃金・労働時間・パートの比率は分からない。
- 従業者数は事業所の所在地で数えた民営の数で、公務は含まない。
