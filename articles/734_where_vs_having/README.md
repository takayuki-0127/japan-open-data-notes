# 734 「1回1万円以上の注文がある顧客」と「合計1万円以上の顧客」を取り違えると、何人がずれるのか（実務の型）

SQL の WHERE は集計の前に行を絞り、HAVING は集計した後に絞ります。「1万円以上の顧客」を出すとき、WHERE で1万円以上の注文に絞ってから顧客を数えると「1回1万円以上の注文がある顧客」に、顧客ごとに合計してから HAVING で絞ると「合計1万円以上の顧客」になります。**ここでは、架空の顧客3,000人の1年間の注文（19,189件）で、2つの顧客の数と重なり、WHERE を先にかけて売上を出したときのずれを数えました。** 金額の基準を5,000〜30,000円に変えた場合も出しています。DuckDB の SQL と Python で同じ値になることを確かめています。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A734 | WHERE と HAVING を取り違えると、顧客の数と売上はどれだけずれるか | 架空の顧客3,000人（買った人2,645人）、注文19,189件。1人の注文回数はポアソン（平均は人によって違う）、1回の金額は対数正規（中央値3,510円）。基準5,000・10,000・15,000・20,000・30,000円。seed 734 | `src/a734_where_having.py`、`src/02_where_having_duckdb.sql`、`src/01_where_having_tsql.sql`（T-SQL：未検証） |

## 主な結果（基準1万円）
| 項目 | 結果 |
|---|---|
| 合計1万円以上の顧客（HAVING） | 2,031人 |
| 1回1万円以上の注文がある顧客（WHERE） | 1,021人 |
| 合計1万円以上だが、1回1万円以上の注文はない顧客 | **1,010人（49.7%）** |
| 合計1万円以上の顧客の売上（すべての注文） | 85,818,690円 |
| WHERE で1万円以上の注文に絞ってから合計し HAVING をかけた売上 | 22,771,590円（**73.5%少ない**） |

| 金額の基準 | 合計が基準以上（HAVING） | 1回で基準以上（WHERE） |
|---|---|---|
| 5,000円 | 2,338人 | 2,066人 |
| 10,000円 | 2,031人 | 1,021人 |
| 15,000円 | 1,750人 | 435人 |
| 20,000円 | 1,495人 | 173人 |
| 30,000円 | 1,100人 | 38人 |

- 1回で基準以上の注文がある顧客は、必ず合計も基準以上なので、WHERE の顧客は HAVING の顧客に含まれる。取り違えると、こつこつ買う顧客がまるごと抜ける
- WHERE を先にかけると、合計に使う注文も基準以上のものだけになるので、売上は顧客数以上に小さく出た
- 基準が高いほど差は開き、3万円では HAVING 1,100人に対し WHERE 38人だった
