# 583 在庫を帳簿上の数で見るか、引当を除いた使える数で見るかで、欠品の判定は何品目変わるのか（実務の型・在庫の見方）

在庫が「ある」かどうかは、帳簿上の在庫（有り高）で見ることもあれば、受注を受けてまだ出荷していない分（引当）を引いた、新しい注文に使える数（引当可能数）で見ることもあります。**ここでは、架空の200品目・半年分の在庫と受注（63,283件、最初の4週を除く）で、日ごとの欠品の判定を「有り高が0以下」「引当可能数が0以下」「引当可能数＋入荷予定（発注残）が0以下」の3通りで比べ、実際に出荷予定日に遅れた注文の数と並べました。** 受注の出方・出荷までの日数・先の日付の大口受注・週1回の発注のしかたは作成者が置いたもので、数字はその仮定で決まります。

## 主な結果
（2025年1月29日〜7月1日の154日 × 200品目 = 30,800品目・日）
- **有り高が0以下**：283品目・日（0.92%）。1日平均 1.8品目。1回でも当てはまった品目は 95
- **引当可能数が0以下**：4,837品目・日（15.7%、有り高の 17.1倍）。1日平均 31.4品目。1回でも当てはまった品目は 197
- **引当可能数＋入荷予定が0以下**：939品目・日（3.05%）。1日平均 6.1品目。1回でも当てはまった品目は 82
- **帳簿では在庫ありに見える**のに引当可能数は0以下：4,554品目・日。引当可能数が足りず、すぐ引き当てられなかった注文 8,494件のうち 91.4%（7,761件）は、その時点の有り高では足りていた
- **実際に出荷予定日に遅れた注文**：355件（出荷済みの注文の 0.57%）、107品目
- **品目の種類別**（品目・日のうち欠品と判定される割合。有り高／引当可能数／＋入荷予定）：A 小口中心 0.5%／5.3%／0.0%、B 先の日付の大口受注あり 0.4%／37.8%／9.6%、C 動きが少ない 2.7%／8.5%／0.9%

## データ
- 品目200：A 小口中心100（1日1.5〜4件、1件1〜3個、1〜3日後に出荷）、B 60（A と同じ小口に加え、6%の日に15〜59個の大口受注が入り、10〜30日後に出荷）、C 動きが少ない40（1日0.1〜0.5件）
- 出荷は予定日以降、有り高が足りる注文から出す。足りなければ翌日以降に回す
- 発注は週1回、引当可能数＋発注残を一定の水準まで戻す。入荷は発注の5日後
- 最初の4週（2025年1月1日〜28日）は立ち上がりとして集計から除いた

## 注意（言えないこと）
- 架空のデータ。実際の会社の在庫ではない
- どの判定が「正しい欠品」かは、何に使うか（今日の出荷、新しい受注の受付、発注の判断）で決まる。ここでは3通りの数え方と、実際の遅れの件数を並べただけ
- 判定の差は、先の日付の受注の多さと、発注のしかたで大きく変わる
- 在庫の評価額や会計上の扱いは扱っていない
