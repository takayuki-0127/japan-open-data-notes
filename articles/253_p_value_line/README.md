# 253 p値0.05の線を、どう扱ってきたか（④ 振り返り R015）

このシリーズの記事512本の README に書いた p の値を拾い、0.05 の前後でどう書いてきたかを数えたフォルダです。並べ替え検定と p＝0.05 の境目を扱った [F177](https://github.com/takayuki-0127/japan-open-data-notes/tree/main/articles/F177_permutation_tests) とは別に、自分の書き方の記録を見ます。

## 問い

- README に書いた p は、0.05 のすぐ下に集まっていないか
- p と一緒に、区間（95%区間など）や効果の大きさを書いてきたか
- 0.05〜0.10 の p を、どんな言葉で書いてきたか

## 手法

| 手順 | 中身 |
|---|---|
| 拾う（`src/a253.py`） | README を1行ずつ読み、「p=0.03」「p＝0.047」「p≈0.05」の形の値を拾った。「p<0.05 の判定」のような基準の書き方（21か所）と「p<0.001」のような不等号の値は、分布には入れていない |
| 書き方 | 同じ行に区間（区間・95%・〜…））があるか、慎重な言葉（区別できない・言い切れない・境目など）か強い言葉（差がない・有意でない・効果がないなど）があるかを言葉で判定した |
| 「有意」 | README に「有意」という言葉が1回でもある記事を数えた |
| 0.03〜0.05 の行 | 重複を除いた29行を目で読み、同じ行に「別の設定では弱まる」確かめがあるかを分けた（`data/manual_003_005_lines.csv`） |

## 主な結果

- 書いた p の値は239個（72本）。0.05未満は34%
- 0.03〜0.05 は33個、0.05〜0.07 は21個、0.07〜0.10 は18個。0.05 のすぐ下だけが目立って多い形ではなかった（図1）
- 0.05〜0.10 の39個のうち、同じ行に区間を書いたのは20、慎重な言葉は12、「差がない」などの強い言葉は0
- p と同じ行に区間も書いた割合は全体で46%。まとまりごとでは F100〜F199 の32%が低く、精選は57%（図2）
- 「有意」という言葉を使った記事は26本（512本中5%）。精選では40本中1本
- 0.03〜0.05 の p を書いた行（検定の診断2行を除く27行）のうち9行は、同じ行に「別の設定では弱まる」確かめを書いていた（F101・F152・F168・F177・F185・F195・F276・F50・F95）
- 0.05〜0.10 の書き方の例は図3（F172・F29・F195・F289・F236・F277）

## 注意（言えないこと）

- README に書いた p だけを数えている。記事の本文や表のファイルにだけある p は入らない
- 同じ行に複数の p があると、その行の言葉はすべての値に数えている。言葉の判定には外れと取りこぼしがある
- 0.05 のすぐ下に集まっていないことは、結果を選んで書いていないことの証明にはならない。値の数（239個）も、分布の形を細かく言うには少ない
- 「有意」を使う記事が少ないのは、言葉の決まり（「はっきり」「区別できない」で書く）に合わせたためでもある（推測）
