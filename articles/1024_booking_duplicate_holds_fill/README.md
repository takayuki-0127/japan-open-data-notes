# 1024 同じ人の重複した予約は、埋まり具合をどれだけ押し上げるのか？（予約とキャンセル）

泊まる夜を決めかねた人が、前後の別の夜も「仮に」押さえておき、あとで片方を取り消すことがあります。仮の予約が残っている間、台帳の埋まり具合はその分だけ高く見え、満室に見えた夜には、本当に泊まりたい人を断ることもあります。**ここでは、作成者が乱数で作った架空の宿（20室。申し込みの1割が別の夜も仮に押さえ、早いほうの夜の3〜14日前に仮の予約を取り消すが、その1割は取り消し忘れると作成者が置いたもの）の3,000夜で、30・14・7・1日前の埋まり具合がどれだけ押し上げられるか、泊まった部屋と断った人がどう変わるかを、同じ申し込みで重複がない場合と比べて数えました。置き方を変えた27通りも確かめました。**

前日の夜の埋まり具合と当日の着席の差は同じ企画の関連する記事 1017、キャンセル率の分母（日付の変更を取り消しに数えるか）は 1018、予約を多めに取ったときの「断る人の%」は 1019、受付を始める時期の違いは 1023、予約を締め切る時刻の違いは 1025 で扱っています。この記事は「同じ人の仮の予約が、埋まり具合と断った人をどれだけ動かすか」に絞ります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A1024 | 同じ人が別の夜も仮に押さえると、何日か前の埋まり具合はどれだけ高く見えるか。泊まった部屋と、満室で断った人はどれだけ変わるか | 架空の宿（20室、1人1部屋の申し込み）。夜ごとの申し込みは平均18件×曜日（金・土の夜1.375倍、ほかの夜0.85倍）のポアソン分布。申し込みは泊まる夜の何日か前に入る（平均20日の幾何分布、最大90日）。申し込みの10%は、泊まる夜の前後1〜7日の別の夜も同時に仮に押さえる（空いていれば）。仮の予約は、早いほうの夜の3〜14日前（一様）に取り消すが、10%は取り消し忘れて当日来ない。泊まる夜が満室なら申し込みを断る（仮の予約も取らない）。本当に泊まる人の取り消しはない。30・14・7・1日前の朝の埋まり具合を、仮の予約も含めた部屋と、本当に泊まる人の部屋で数える。比べる相手は、同じ申し込みで誰も仮の予約をしない場合。最初と最後の120夜を除いた3,000夜。確かめとして、仮に押さえる人の割合（5・10・20%）×申し込みの多さ（平均12・18・24件）×仮の予約を取り消す時期（早いほうの夜の1〜3日前・3〜14日前・7〜21日前）の27通り（各600夜）。seed 1024 | `src/a1024_duplicate_holds.py` |

## 主な結果

### 何日前に見た埋まり具合か（基本の置き方、20室に対する%の平均、`results/a1024_main.json`）
| 何日前 | 押さえた部屋（仮も含む） | そのうち本当に泊まる人 | 押し上げ | 重複がない場合 |
|---|---|---|---|---|
| 30日前 | 21.2% | 19.27% | 1.93ポイント（0.39室） | 19.27% |
| 14日前 | 47.9% | 44.25% | **3.65ポイント（0.73室）** | 44.28% |
| 7日前 | 64.14% | 62.28% | 1.86ポイント（0.37室） | 62.47% |
| 1日前 | 79.91% | 79.19% | 0.72ポイント（0.14室） | 79.37% |

- **仮の予約による押し上げは、14日前に見たときがいちばん大きく、平均3.65ポイント（20室のうち0.73室）だった**。仮の予約を早いほうの夜の3〜14日前に取り消すと置いたので、14日前はまだ多くが残り、7日前には多くが取り消された（仕組みからの説明）
- 1日前に残る押し上げ（0.72ポイント）は、取り消し忘れた仮の予約の分。1日前の予約のうち0.92%が、当日来ない仮の予約だった
- 7日前に押さえた部屋が18室（90%）以上に見えた夜は17.97%（重複がない場合16.03%）。そのうち11.5%の夜は、本当に泊まる人だけでは90%に届いていなかった

### 泊まった部屋と断った人（3,000夜）
| | 重複した予約10% | 重複がない場合 |
|---|---|---|
| 泊まった部屋（20室に対する%） | 81.83% | 82.06% |
| 満室で断った人（100夜あたり） | 175.1人 | 170.5人 |
| 断った人÷申し込み | 9.66% | 9.41% |

- **泊まった部屋は0.23ポイント減っただけだった**。仮の予約の多くは泊まる夜より前に取り消され、空いた部屋に後から来た申し込みが入ったため
- 重複で増えた断った人は100夜あたり4.6人。取り消し忘れた仮の予約は100夜あたり14.7室あったが、満室にならない夜が多いので、その多くは断った人につながらなかった（仕組みからの説明）
- 取り消しを入れていないので、泊まった部屋＝申し込み−断った人になる（3,000夜すべてで確かめた）

### 申し込みの多さ別（7日前、`results/by_demand.csv`）
| その夜の申し込み | 夜の数 | 押し上げ（7日前） | 断った人（100夜あたり、重複あり） | 同（重複なし） |
|---|---|---|---|---|
| 11件以下 | 339 | 1.77ポイント | 0.0人 | 0.0人 |
| 12〜15件 | 814 | 1.98ポイント | 0.0人 | 0.0人 |
| 16〜19件 | 776 | 1.85ポイント | 0.4人 | 0.0人 |
| 20〜23件 | 493 | 1.82ポイント | 143.2人 | 130.6人 |
| 24〜27件 | 328 | 1.83ポイント | 552.1人 | 540.9人 |
| 28件以上 | 250 | 1.76ポイント | 1,092.8人 | 1,078.4人 |

- 7日前の押し上げは、申し込みの多さによらず1.76〜1.98ポイントだった。断った人が増えたのは、申し込みが20件を超える夜だけだった

### 確かめ：仮に押さえる人の割合×申し込みの多さ×取り消す時期（27通り、各600夜、`results/sensitivity_grid.csv`）
- **14日前の押し上げは、置き方で0.73〜11.44ポイントと動いた**。7日前は0.34〜11.92ポイント、30日前は0.53〜5.36ポイント、1日前は0.22〜3.4ポイントだった
- 押し上げがいちばん大きかったのは、20%が仮に押さえ、申し込みが多く、仮の予約を夜の1〜3日前まで持つ置き方だった。どの日に見た埋まり具合がいちばん押し上げられるかは、仮の予約を取り消す時期で決まった
- 泊まった部屋は27通りすべてで重複がない場合より少なく、差は−2.11〜−0.03ポイントだった。重複で増えた断った人は100夜あたり0.5〜42.0人だった

## 動かし方
```
pip install -r requirements.txt
cd src && python a1024_duplicate_holds.py
```
数秒で終わります。`data/nights.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約4秒）
- 重複がない場合は、どの日に見ても「押さえた部屋」と「本当に泊まる人の部屋」が一致した（押し上げ0）
- 3,000夜すべてで、泊まった部屋＝申し込み−断った人（重複あり・なしの両方）
- 押し上げの大きさは置いた仮の予約の割合と取り消す時期でほぼ決まる（仕組みからの説明）。新しく数えたのは、何日前に見たかでの違いの大きさと、泊まった部屋・断った人への効きが押し上げより小さいこと

## データ
- `data/nights.csv`：基本の置き方の最初の1,000夜。night・requests（申し込み）・lost（満室で断った人）・stayed（泊まった部屋）・forgot_holds（取り消し忘れた仮の予約）・fill_all_30d〜1d（押さえた部屋÷20室、仮も含む）・fill_true_30d〜1d（本当に泊まる人の部屋÷20室）・stayed_nodup・lost_nodup（重複がない場合）

## 注意（言えないこと）
- 架空のデータです。仮に押さえる人の割合、取り消す時期、取り消し忘れの割合、申し込みの多さは作成者が置いたもので、「3.65ポイント」は置き方で0.73〜11.44ポイントと動きます。実在の宿の予約を測ったものではありません
- 仮の予約は「別の夜」を押さえる形だけにしました。同じ夜を2部屋押さえる、同じ人が別の名前で2回申し込む、といった重複は入れていません
- 本当に泊まる人の取り消しは入れていません。取り消しのある宿では、押し上げと泊まった部屋の差は変わります（推測）
- 台帳から仮の予約を見分ける方法は扱っていません。この記事は、作成者が仮の予約かどうかを知っている架空のデータで数えています
- 仮の予約をどう扱うべきか、キャンセル料をどう決めるべきかは扱っていません。数え方だけを比べています
