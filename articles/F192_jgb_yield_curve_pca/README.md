# F192 国債の金利は、何で動いているのか？（イールドカーブの主成分分析）

## 問い
国債の金利は年限（1年〜40年）ごとに毎日動きます。その動きは「全部がそろって上下する」のか、「短い金利と長い金利で別々に動く」のか。どの形の動きがどれだけを占め、日本銀行の政策決定の日にはどの形がどれだけ動いたのかを確かめます。投資の判断をするための分析ではありません。

## データ
- 財務省「国債金利情報」（日次、1974年9月〜2026年11月2日）。過去分 `jgbcm_all.csv` と当月分 `jgbcm.csv` を 2026-11-05 に取得（`data/raw/`、Shift_JIS を UTF-8 に変換）
- 主の分析は、年限 1・2・3・5・7・10・15・20年がそろう 1992年1月〜2026年11月の 8,547日（変化では 8,546日）
- 日本銀行の政策決定の日付（12日）は、日本銀行の公表資料の日付を手で入力（`src/03_分析.py` の EVENTS）

## 手法
- 日次の変化（bp）の共分散行列を主成分に分ける。第1主成分＝全年限が同じ向き（水準）、第2＝短い年限と長い年限が逆向き（傾き）、第3＝中間の年限だけが逆向き（曲率）
- 期間を4つに分けて比べる：1992〜2013年3月／量的・質的緩和（2013年4月〜2016年9月）／長短金利操作（2016年9月〜2024年3月）／操作の終了後（2024年3月〜）
- 出来事の前後：政策決定の日の前日→当日の主成分の得点を、前後250営業日の標準偏差で割る（z）。12日の |z| の平均を、無作為に選んだ12日（5,000回）と比べる（乱数の種 192）

## 結果
| 項目 | 値 |
|---|---|
| 説明できる割合（日次の変化、主） | 水準 81.0%・傾き 11.3%・曲率 3.9%（計 96.3%） |
| 金利そのもの（変化でなく水準）の主成分 | 第1主成分だけで 97.1% |
| 10年−2年の差の変化と「傾き」の相関 | 0.77 |
| 10年金利の変化と「水準」の相関 | 0.95 |
| 水準の動きの上位1%の日（85日）が占める分散 | 24.1% |

**期間別**（`results/by_regime.csv`）

| 期間 | 水準 | 傾き | 曲率 | 2年の1日の動き（bp） | 10年の1日の動き（bp） | 10年と20年の相関 |
|---|---|---|---|---|---|---|
| 1992〜2013/3 | 81.6% | 11.1% | 3.7% | 2.54 | 3.35 | 0.87 |
| 量的・質的緩和 | 81.1% | 11.0% | 5.0% | 0.91 | 2.03 | 0.77 |
| 長短金利操作 | 80.5% | 9.8% | 4.3% | 0.93 | 1.57 | 0.75 |
| 操作の終了後 | 83.6% | 12.9% | 1.7% | 2.00 | 3.11 | 0.84 |

- 10年の1日の動きを、7年と15年の平均で割ると 0.93・0.94・0.89・0.98。長短金利操作の期間に10年だけがいちばんへこみ、操作の終了後はへこみがほぼ消えた

**日本銀行の政策決定の日**（`results/events.csv`）
- 12日のうち8日で、水準の |z| が2を超えた。|z| の平均は 水準2.80・傾き3.14・曲率2.66 で、無作為の12日より大きい（並べ替え p<0.001、3つとも）
- 量的・質的金融緩和の導入（2013-04-04）：水準 −6.9、傾き −13.2（20年 −23.7bp、10年 −11.3bp、2年 +0.2bp）。翌日を足した2日では水準 −1.6 で、水準の動きはほぼ戻った（傾きは −9.8 のまま）
- マイナス金利の導入決定（2016-01-29）：水準 −5.3（10年 −12.5bp）
- 変動幅の拡大（2022-12-20）：水準 +3.9（10年 +15.0bp）、柔軟化（2023-07-28）：+3.4（10年 +10.8bp）
- マイナス金利と長短金利操作の終了（2024-03-19）：水準 −0.9、政策金利の引き上げ（2025-01-24）：+0.8 と、前後1年の普段の動きの範囲だった
- 水準の動きが前後1年と比べて大きかった上位10日のうち、政策決定の当日・翌営業日は 2013-04-04・2016-07-29・2018-08-01 の3日。いちばん大きかったのは 2024-08-05（z=7.1）

## 頑健性
1. **年限・変化の幅・標準化**（24通り、`results/robustness.csv`）：水準 67〜90%、3つ合計 95〜99%。40年まで入れると傾きが 15〜22% に増える
2. **主成分の数**（`results/n_components_oos.csv`）：1つ前の期間の負荷量で次の期間を再現すると、3つで 95.0%・94.3%・97.9%（同じ期間で決めた場合 97.1%・94.6%・98.2%）。1つだけだと 74〜83%
3. **期間**：4期間とも水準 80〜84%
4. **代わりの指標**：10年−2年の差の変化と傾きの得点の相関 0.77
5. **出来事の窓**：当日だけと、当日＋翌日の2通り

## 言えないこと
- 主成分は「どの形で動いたか」を分けるだけで、なぜ動いたか（海外の金利、物価の見通し、需給など）は分けていない
- 政策決定の日の動きには、同じ日のほかの出来事（海外の金利の動きなど）も入っている。12日は日本銀行の公表日をもとに手で選んだもので、すべての会合を網羅していない
- 財務省の金利は1日1回の値で、発表の前後の動きは分けられない
- 2024-08-05 などの大きな動きの理由は確かめていない
- 投資の判断に使うための分析ではない
