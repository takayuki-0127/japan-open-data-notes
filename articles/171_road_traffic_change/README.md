# 171 道路の交通量は、コロナの前後でどれだけ減った？ 道路交通センサスで2015年度と2021年度を比べる

国土交通省「全国道路・街路交通情勢調査（道路交通センサス）」一般交通量調査の集計表（平成27年度・令和3年度）を使ったフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A171 | 2015年度→2021年度で、道路の種類ごと・都道府県ごとの交通量はどう変わったか。高速道路が延びた県では交通が増えたか | 全国・都道府県×道路種別（高速道路・一般国道・地方道）の延長、24時間平均交通量、走行台キロ、大型車混入率の比較。高速道路の延長の伸びと走行台キロの変化の相関 | `src/a171_traffic.py` |

## 主な結果
- 全国の合計で、24時間平均交通量は7,786→7,348台/日（−5.6%）、走行台キロ（交通量×延長）は−5.3%
- 高速道路は延長が+7.9%伸びたが、平均交通量は26,298→23,412台/日（−11.0%）、走行台キロは−3.9%
- 走行台キロの合計は47都道府県すべてで減った（中央値−4.7%、最小の減り 茨城県−1.0%、最大 岩手県−10.7%）
- 都道府県×道路種別141のうち増えたのは21で、ほとんどが高速道路（山形県+36.0%、鳥取県+24.5%、埼玉県+11.6%）
- 高速道路の延長の伸びと走行台キロの変化の相関は0.62。ただし平均交通量の変化との相関は−0.14で、延びた区間の分だけ1区間当たりは薄まっている
- 高速道路の大型車混入率は全国で25.4→28.9%、43/47都道府県で上がった（中央値+4.0ポイント）

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a171_traffic.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/traffic_census_pref_road.csv | 都道府県（47＋全国）×道路種別（高速道路計・一般国道計・地方道計・合計）の延長（km）、24時間平均交通量（台/日）、24時間走行台キロ（千台キロ）、12時間大型車混入率（%）。15＝平成27年度、21＝令和3年度 |

元の表：国土交通省 道路交通センサス 一般交通量調査 集計表（syuukei04.csv、平成27年度・令和3年度）の「交通量推定不能区間を含む」「沿道状況＝合計」の行から書き写した。都道府県の合計が全国の値と合うことを確かめている。

## 注意
- 令和3年度の調査は、新型コロナの影響が残る時期に行われた。2つの年度の差には、コロナの影響と、それ以外の長い変化（人口減少など）がまざっている
- 調査は秋の平日の1日の観測（と推定）にもとづく値で、休日や季節の違いは入っていない
- 高速道路は、新しく開通した区間が加わると平均交通量が下がりやすい。延長と走行台キロをあわせて見ている
- 地方道は主要地方道と一般都道府県道など、調査対象の道路に限られ、市町村道の多くは入っていない
