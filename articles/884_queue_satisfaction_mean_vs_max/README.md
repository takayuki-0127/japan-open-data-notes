# 884 満足度は、待ち時間の平均と最長のどちらで決まるのか？（待ち時間と混雑）

店の待ち時間を報告するとき、「平均の待ち」を出すことも「いちばん長く待った人の待ち（最長）」を出すこともあります。どちらが客の満足に近いかは、客1人ずつの満足が待ちでどう決まるかによります。**ここでは、作成者が乱数で作った架空のテイクアウトの店の2,000日（客1人ずつの満足は「自分の待ち」だけで決まると作成者が5通りに置いたもの）で、日ごとの待ちの指標（平均・最長・上位10%の線・10分以上待った人の割合）のうち、その日の満足にいちばん合うのはどれかを数えました。どの指標が合うかは、作成者の置いた決まり方の写しです。この記事で数えたのは、その写しが日ごとのデータからどこまで見分けられるか、です。**

平均の待ちが5分でも長く待つ人がどれだけいるかは関連する記事 873、「混んでいる」と感じる人の割合は 875、行列の最後尾の人の待ちと平均の待ちの違いは 881 で扱っています。この記事は「日ごとの満足に近い待ちの指標はどれか」に絞ります。

## 主な結果

### 2,000日：指標とその日の満足（全員の平均）の相関
| 1人の満足の決まり方 | 平均の待ち | 最長の待ち | 上位10%の線 | 10分以上待った人の割合 | いちばん合った指標 |
|---|---|---|---|---|---|
| 基本：1分0.1点＋10分以上で2点 | **−0.989** | −0.947 | −0.968 | −0.980 | 平均 |
| 毎分だけ：1分0.25点 | **−1.000** | −0.945 | −0.970 | −0.939 | 平均 |
| 線だけ：10分以上で3点 | −0.939 | −0.917 | −0.932 | **−1.000** | 10分以上の割合 |
| 線を5分に：1分0.1点＋5分以上で2点 | **−0.974** | −0.946 | −0.962 | −0.968 | 平均 |
| 線を15分に：1分0.1点＋15分以上で2点 | **−0.993** | −0.939 | −0.965 | −0.957 | 平均 |

- 5通りのうち4通りで平均の待ちが、「線だけ」で10分以上待った人の割合が、いちばん合った。**これは置いた決まり方の写し**で、「毎分だけ」では満足が平均の待ちの式そのもの（相関−1.000）、「線だけ」では10分以上の割合の式そのもの（相関−1.000）になる
- 最長の待ちは、5通りのどれでもいちばん合う指標にならず、4通りで最下位だった（「毎分だけ」では10分以上の割合が最下位）。ただし、いちばん合った指標との差は相関で0.028〜0.083と小さかった
- 指標どうしの相関は0.917〜0.981で、日ごとの指標はどれも一緒に動いた。混んだ日はどの指標も悪くなるので、2,000日を全部並べると、どれも満足と0.9以上の相関になった（`results/metric_correlations.csv`）

### 200日ずつの組100組で、相関がいちばん大きかった指標（回数）
| 1人の満足の決まり方 | 満足の測り方 | 平均 | 最長 | 上位10% | 10分以上の割合 |
|---|---|---|---|---|---|
| 基本 | 全員 | 100 | 0 | 0 | 0 |
| 基本 | アンケート40人 | 81 | 0 | 0 | 19 |
| 基本 | アンケート10人 | 66 | 0 | 2 | 32 |
| 毎分だけ | アンケート40人 | 86 | 0 | 2 | 12 |
| 線だけ | アンケート40人 | 0 | 0 | 0 | 100 |
| 線を5分に | アンケート40人 | 74 | 0 | 5 | 21 |
| 線を15分に | アンケート40人 | 100 | 0 | 0 | 0 |

- 1日40人のアンケートで200日分あっても、基本の決まり方で「10分以上の割合がいちばん合う」と出た組が19組あった。10人のアンケートでは32組だった。アンケートの人数が少ないと、1位の指標は入れ替わりやすい
- 最長の待ちは、15の組み合わせ（決まり方5通り×測り方3通り）で1,500回のうち1回しか1位にならなかった（全部は `results/best_metric_wins_200days.csv`）

### 平均の待ちが同じくらいの日（1.5〜2.5分、384日）での相関
| 1人の満足の決まり方 | 平均の待ち | 最長の待ち | 上位10%の線 | 10分以上待った人の割合 |
|---|---|---|---|---|
| 基本 | −0.760 | −0.803 | −0.757 | **−0.900** |
| 毎分だけ | **−1.000** | −0.424 | −0.657 | −0.401 |
| 線だけ | −0.401 | −0.848 | −0.627 | **−1.000** |
| 線を5分に | **−0.889** | −0.368 | −0.795 | −0.347 |
| 線を15分に | **−0.954** | −0.563 | −0.682 | −0.522 |

- 平均の待ちが同じくらいの日どうしで比べると、決まり方の違いがはっきり出た。満足が「10分を超えたかどうか」で下がる決まり方（基本・線だけ）では、最長の待ち（−0.803・−0.848）が平均の待ち（−0.760・−0.401）より満足に合った。最長が10分を超えたかどうかが、10分以上待った人がいたかどうかの目印になるため
- 満足が待ちの長さに比例して下がる決まり方（毎分だけ・線を15分に）では、最長の待ちは−0.424・−0.563で、平均の待ちに遠く及ばなかった
- 「線を5分に」で10分以上の割合が弱い（−0.347）のは、満足の線（5分）と指標の線（10分）がずれているため
- 基本の決まり方で、この384日のうち最長の待ちが短い1割の日（9.36分以下）は満足7.817、長い1割の日（15.46分以上）は7.673だった。10分以上待った人の割合は0%と5.45%だった

## 動かし方
```
pip install -r requirements.txt
cd src && python a884_satisfaction.py
```
2秒ほどで終わります。`data/days.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の9ファイルがバイト単位で一致した（cmp、約2秒）
- 1人の満足の決まり方を5通り、満足の測り方を3通り（全員・アンケート40人・10人）に変えた。いちばん合う指標は決まり方で入れ替わったが、最長の待ちが2,000日の相関で1位になることはなかった
- 「毎分だけ」で平均の待ちの相関が−1.000、「線だけ」で10分以上の割合の相関が−1.000になるのは、置いた式どおりの結果で、乱数で見つけたものではない

## データ
- `data/days.csv`：架空の店の2,000日（基本の決まり方）。day・per_hour（その日の客の多さの置き方）・peak（昼の山の高さ）・n（客数）・mean／max／p90（平均・最長・上位10%の線の待ち、分）・share10（10分以上待った人の割合）・sat_all（全員の満足の平均）・sat_survey40／sat_survey10（40人・10人のアンケートの平均）

## 注意（言えないこと）
- 架空のデータです。客1人の満足の決まり方（5通り）、アンケートのゆれ、客の多さと昼の山の置き方は作成者が置いたもので、どの指標が合うかはこれで決まります。実際の客の満足が待ちでどう決まるかは、ここでは測っていません
- 客1人の満足は「自分の待ち」だけで決まると置きました。前に何人並んでいたか、待つ間の案内、いちばん長く待った人の話が口コミで広がる、といったことは入れていません。最長の待ちそのものが店の評判を動かす場合は、結果が変わると考えられます（推測）
- 待ちが長いと帰ってしまう客は入れていません
- 「どちらで決まるか」をデータから見分けるには、平均が同じくらいで最長や長い待ちの割合が違う日が要る、というのはこの置き方での結果です
- 実在の店を表すものではありません
