# corporate-retained-earnings-japan：法人企業統計で、内部留保（利益剰余金）が現預金として積み上がったのかを見る

財務省「法人企業統計調査」年次別調査の統計表2（業種別・規模別 資産・負債・純資産及び損益表）を、2006〜2022年度の17年分つないだリポジトリです。対象は「全産業」（金融業・保険業を除く）です。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| 143 | 企業の内部留保（利益剰余金）は、現金・預金として積み上がっていたのか。規模で違うか | 利益剰余金と主な資産（現金・預金、投資有価証券、有形固定資産）の推移、2006→2022年度の資産の増加の内訳、資本金規模別（1億円未満・1億〜10億円未満・10億円以上）の総資産に占める割合 | `src/a143_retained.py` |

## 主な結果
- 利益剰余金は252兆円（2006年度）→555兆円（2022年度）で2.2倍（+302兆円）。同じ期間に現金・預金は147兆円→295兆円（+148兆円）で、利益剰余金の増加の約半分（49%）にあたる
- 総資産の増加は+708兆円。内訳は現金・預金+148兆円、投資有価証券+212兆円、有形固定資産+51兆円、その他+297兆円。有形固定資産（設備・土地など）はほとんど増えていない
- 現金・預金の総資産に占める割合は10.6%→14.1%。資本金1億円未満の企業は16.4%→24.3%と高く、2022年度の現金・預金295兆円のうち173兆円（59%）を持っている。資本金10億円以上の企業では現金・預金は5.7%→7.4%にとどまり、投資有価証券が19.3%→28.6%に増えた

## 動かし方
`data/bs_pl_by_size.csv`（年度×資本金規模×項目に整えたもの）が入っているので、そのまま動きます。

```bash
pip install -r requirements.txt
python src/a143_retained.py
```

元の Excel から作り直すときは、e-Stat「法人企業統計調査 年次別調査」の各年度の「統計表2 業種別，規模別資産・負債・純資産及び損益表」を `data/raw/143_<年度>.k0` の名前で置き、`data/bs_pl_by_size.csv` を消してから実行してください（https://www.e-stat.go.jp/stat-search/files?toukei=00350600 ）。

## データ
| ファイル | 中身 |
|---|---|
| data/bs_pl_by_size.csv | 年度（2006〜2022）×資本金規模（total・small＝1億円未満・medium＝1億〜10億円未満・large＝10億円以上）×項目（現金・預金、有価証券、棚卸資産、有形固定資産、土地、投資有価証券、資産合計、利益剰余金、資本金、純資産、売上高、経常利益、当期純利益、配当金、従業員給与）。単位は百万円 |

## 注意
- 利益剰余金は貸借対照表の右側（調達の側）の項目で、特定の資産と1対1には対応しません。「内部留保が現金で積み上がった」かどうかは、同じ期間の資産の増え方と並べて比べているだけです
- 投資有価証券には子会社・関連会社の株式が含まれます。大企業の投資有価証券の増加は、海外子会社への投資やM&Aによるものが含まれると考えられますが、このデータでは分けられません
- 年次別調査は標本調査の推計値です。年度によって標本の入れ替えがあり、前年度との段差があります
- 資本金の階級の区切りは年度で違うため、1億円・10億円で3つにまとめ直しました。規模別の合計と総額の差は最大53百万円（四捨五入）です
- 2023年度以降の統計表は今回取得していません
- 2006年度の表は「資本」、2007年度以降は「純資産」です
