# 1211 1回の調査で見つからなかった種は、その場所にいないと言えるのか？（生き物の数え方）

生き物の調査で、ある池を探して種Aが見つからなかったとき、「この池に種Aはいない」と書きたくなります。けれども、いても見つけられないことがあります。数の少ない池ほど見つけにくく、天気の悪い日は見つけにくくなります。**ここでは、作成者が乱数で作った架空の池300か所（種Aがいる池の割合、いる池での数、1回探したときに1匹を見つける確率、日ごとの見つけやすさの上下を作成者が置いたもの）で、探した回数ごとに、見つからなかった池のうち本当は種Aがいた割合を数えました。別々の日に探すか同じ日にまとめて探すか、見つける確率を平均の1つに置いた式とどれだけ違うかも比べ、置き方を変えた18通りで確かめました。**

例の池・種は作成者が置いた架空のもので、実在の場所・生き物・調査の数字ではありません。生き物を守る・減らすなどの進め方は扱っていません。

関連する記事：909「不良率0.1%を確かめるには、何個検査すればよいのか？」は、不良が0個でも不良率が小さいとは言い切れないことを、検査した個数から数えています。992「『ありえない』と感じる確率は、何%くらいなのか？」は、見てきた日数のあいだに一度も起きなかったことの本当の確率を数えています。この記事は、いる・いないの2つに分かれる場所について、見つける確率と、もともといる場所の割合から、「見つからなかった」がどれだけ「いない」を意味するかに絞ります。同じ企画の 1213「調べた区画の数が違う2つの森で、見つかった種の数をそのまま比べると、何がずれるのか？」は、見つからなかった種がいないとは限らないことを、森で見つかった種の数の比べ方で扱っています。

| A1211 | 1回探して見つからなかった池に、本当は種Aがいる割合はどれだけか。何回探せば5%以下になるか。数の少ない池・日ごとの見つけやすさの上下で、どれだけ増えるか | 架空の池300か所。種Aがいる池の割合は0.4。いる池での数は1匹以上で、1匹に「池ごとに平均5で大きく散らばる目安」から引いた数を足した（平均5.99匹・中央値4匹、少ない池が多い）。1回探すと、1匹ごとに確率0.08×その日の倍率で見つかり、1匹でも見つかれば「見つかった」とする。日の倍率は平均1で、対数で標準偏差0.6の上下（天気などをまとめた）。別々の日に探すときは回ごとに倍率を引き直し、同じ日にまとめて探すときは1回目の倍率を全部の回で使う。1〜20回探す。いる池の、1回の見つける確率の平均（日の上下を除く）は0.3429。比べる式は「いる池の割合×(1−平均の見つける確率)^回数」を、それに「いない池の割合」を足した数で割った値（どの池も同じ確率で見つかると置いたとき）。池300か所を200回作った。確かめに、いる池の割合（0.1・0.4・0.7）×1匹を見つける確率（0.04・0.08・0.16）×日ごとの上下（0・0.6）の18通りを各100回。seed 1211 | `src/a1211_not_found_absent.py` |

## 主な結果

### 1回だけ探すと（200回の平均、`results/a1211_main.json` の base）
- 種Aが本当にいた池は39.83%、1回で見つかった池は12.43%だった。いる池のうち68.79%は、1回では見つからなかった
- **1回で見つからなかった池のうち、31.29%には本当は種Aがいた**。見つける確率を平均の1つに置いた式では30.46%で、1回目はほぼ式どおりだった
- **見逃した池の多くは、数の少ない池だった**。いる池の数の中央値は、見つかった池で8匹、いたのに見つからなかった池で3匹。3匹以下の池の割合は、見つかった池の17.81%に対し、見逃した池では52.67%だった

### 探した回数ごと（`results/base_by_visits.csv`）
| 探した回数 | 見つからなかった池にいた割合（別々の日） | 同じ日にまとめて | 平均の1つの確率の式 | 見つかった池の割合（別々の日） |
|---|---|---|---|---|
| 1回 | 31.29% | 31.29% | 30.46% | 12.43% |
| 2回 | 25.22% | 25.9% | 22.35% | 19.53% |
| 3回 | 20.64% | 21.96% | 15.91% | 24.18% |
| 5回 | 14.53% | 16.78% | 7.55% | 29.6% |
| 10回 | 7.16% | 9.76% | 0.99% | 35.19% |
| 20回 | 2.43% | 4.53% | 0.02% | 38.33% |

- **見つからなかった池にいた割合が5%以下になるのは、別々の日に探して14回目、同じ日にまとめて探すと19回目だった。平均の1つの確率の式では7回目で、半分の回数で足りるように見えた**
- 回数を重ねるほど、見つからずに残るのは数の少ない池（1回の見つける確率の低い池）に偏るため、1回ごとに減る割合が小さくなった。式はどの池も同じ確率と置くので、この偏りを入れていない
- 同じ日にまとめて探すと、天気の悪い日に当たった池は何回探しても見つけにくいままで、別々の日より多く残った

### 一回分の例（`data/example_ponds.csv`）
- 300か所のうち種Aがいたのは117か所。1回で見つかったのは43か所、見つからなかった257か所のうち74か所に種Aがいた
- 3回探すと、別々の日で75か所、同じ日で74か所が見つかった

### 確かめ：置き方を変えた18通り（各100回、`results/grid.csv`）
- 1回で見つからなかった池にいた割合は、4.88〜65.26%に分かれた。いる池の割合が高いほど、見つける確率が低いほど大きくなった
- 3回探したあとでは2.12〜57.06%で、18通りすべてで平均の1つの確率の式より大きかった
- 5%以下になる回数（別々の日）は、20回までに届いた12通りで1〜14回だった。残る6通り（いる池の割合0.4で見つける確率0.04、いる池の割合0.7で見つける確率0.04か0.08）は20回でも届かなかった（式ではこの6通りは10〜18回）
- 20回までに届いた12通りで、要る回数は式より0〜7回多かった
- 日ごとの上下がある9通りでは、3回探したあとに見つからなかった池にいた割合は、9通りすべてで同じ日にまとめたほうが別々の日より大きかった

## 注意（言えないこと）
- 架空のデータです。いる池の割合、いる池での数、見つける確率、日ごとの上下は作成者が置いたもので、結果はこれで決まります。とくに「見つからなかった池にいた割合」は、もともといる池の割合で大きく変わります（18通りで1回後4.88〜65.26%）
- 1回目の割合が式とほぼ合うのは、置いた作りどおりです。この記事で新しく数えたのは、回数を重ねたときに数の少ない池が残っていく分と、同じ日にまとめる分のずれです
- 調査のあいだに種Aが池に来たり去ったりすることは置いていません。種Aを別の種と見間違えることも置いていません
- 実際の生き物の見つけやすさや、ある場所に生き物がいるかどうかは言えません
