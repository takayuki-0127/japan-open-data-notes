# 236 理系の学部に進む女子は、どれだけ増えたのか

文部科学省「学校基本調査」の各年度の「関係学科別 学生数」（大学の学部、2000〜2025年度、男女別）から、分野と学科ごとに女子学生の割合を出したフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A236 | 理系の学部に進む女子は、どれだけ増えたのか。どの学科で増えて、どこで増えていないのか | 関係学科（大分類・小分類）ごとの女子学生の割合の推移／理学＋工学の女子学生の数／工学の女子学生の増加を「学生全体の増減」と「女子の割合の上昇」に分ける／1年次だけで同じ割合を出す | `src/a236_women_stem.py` |

## 主な結果
- 理学と工学を合わせた女子学生は、2000年度の68,771人から2025年度の94,810人へ1.38倍。学生全体は555,063人から476,892人に減ったので、女子の割合は12.4%から19.9%に上がった
- 割合の上がり方は2010年度ごろから。2000〜2010年度は12.4%→13.4%とほとんど動かず、その後の15年で6.5ポイント上がった
- 分野別の女子の割合（2000→2025年度）は、工学10.0%→17.9%、理学25.3%→29.4%、農学40.3%→47.5%、保健54.1%→64.5%。学部全体は36.9%→46.1%
- 工学の女子学生は46,489人から70,590人へ24,101人増えた。工学の学生全体は減ったので、女子の割合が上がった分（+31,325人）が全体の減り（−7,224人）を上回った
- 学科で差が大きい。土木建築工学13.8%→26.4%、応用化学19.5%→29.9%、経営工学9.2%→19.1%と伸びた一方、機械工学は2.9%→7.1%、電気通信工学は5.7%→10.9%で、まだ1割前後
- 理学の数学（20.9%→20.0%）と物理学（12.3%→14.3%）はほぼ横ばい。保健では医学32.4%→39.0%、歯学35.4%→44.9%と上がった

## 頑健性
- 1年次の学生だけで見ても、工学の女子の割合は10.4%（2000年度）→20.3%（2025年度）、理学＋工学は12.9%→22.3%で、全学年より高い。入ってくる学生のほうが女子の割合の上昇が速い（`results/a236_female_share_first_year.csv`）
- 2025年度の「その他」の分野は、計から他の分野を引いた値と、表に載っている「その他」の行の値が一致した
- コードはきれいなフォルダで3回動かし直し、results と data の全ファイルが一致することを確かめた

## 動かし方
```
pip install -r requirements.txt
cd src && python a236_women_stem.py   # data/raw の Excel から data/・results/・figures/ を作る
python fetch.py                       # data/raw を e-Stat から取り直す（任意）
```

## データ
- `data/raw/<年度>_GU_<statInfId>`：関係学科別 学生数（大学の学部、国公私立の計）
- `data/univ_students_by_field.csv`（大分類）・`data/univ_students_by_subfield.csv`（小分類）・`data/univ_first_year_by_field.csv`（1年次、大分類）

## 注意
- 学生数（在学しているすべての学年）で、入学者の数ではない。医学・歯学・薬学（6年制）は在学年数が長いぶん学生数が多く出る
- 関係学科は学校基本調査の学科系統分類による。情報系の学科は「工学」や「その他」に分かれて入るため、情報分野だけの割合は出していない
- 学科の名前は2000年度と2025年度で同じものだけを比べた（例：金属工学は2025年度に学生がいない）
- 大学院・短期大学・高等専門学校は含まない

文部科学省「学校基本調査」（e-Stat、https://www.e-stat.go.jp/stat-search/files?toukei=00400001）各年度の高等教育機関の表をもとに作成者が加工して作成
