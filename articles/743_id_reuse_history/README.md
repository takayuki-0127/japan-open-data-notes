# 743 退会した会員の番号を新しい会員に使い回すと、何人の新しい会員に前の人の購入がつくのか（実務の型）

会員の番号を使い回す仕組みでは、退会した人の番号が、あとから入会した別の人に付きます。購入の表に番号しか入っていないと、番号だけでつないだとき、新しい人に前の人の購入が、前の人に新しい人の購入がつきます。**ここでは、作成者が乱数で作った架空の会員（番号4,000個、のべ6,590人）と購入79,707件で、番号だけでつなぐ場合と、番号と在籍期間（入会日以上・退会日より前）でつなぐ場合を比べました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A743 | 番号の使い回しで、購入はどれだけ別の人につくか | 架空の会員。2021〜2025年、番号1〜4,000。在籍日数は平均1,800日の指数分布、退会した番号は30〜400日後に新しい人へ。購入は在籍中だけ（1人の頻度はガンマ分布）。DuckDB（1スレッド）で2つのつなぎ方を実行し、期間つきが購入の本当の持ち主と全件一致することを確認。seed 743 | `src/a743_id_reuse.py`、`src/02_join_duckdb.sql`、`src/01_join_tsql.sql` |

## 主な結果

| | 番号だけでつなぐ | 番号と在籍期間でつなぐ |
|---|---|---|
| つないだ行 | 126,109 | 79,707（購入の件数と同じ） |
| 2人目以降の会員（2,590人）のうち、入会前の購入がついた人 | **2,291人（88%）** | 0人 |
| 2人目以降の会員の購入額の合計 | 3億6,063万円 | 1億5,728万円（2.29倍の差） |
| 退会後の購入がついた前の会員 | 2,262人 | 0人 |

- 使い回された番号の新しい会員2,590人のうち2,291人（88%）で、初回の購入が入会より前になった。初回購入月は中央値で27か月早く見えた
- 2人目以降の会員の購入額は、番号だけでつなぐと2.29倍になった
- 1つの購入が、前の人と今の人の両方につく。年ごとの「買った人」の数は、2025年で3,579人が5,694人になった

## 動かし方
```
pip install -r requirements.txt
cd src && python a743_id_reuse.py
```
10秒ほどで終わります。`data/members.csv`・`data/purchases.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダで流し直し、results・figures・data がバイト単位で一致した
- 番号と在籍期間でつないだ結果が、購入の件数と同じで、全件が本当の持ち主と一致すること（assert）

## データ
- `data/members.csv`：架空の会員（person_id・member_no・joined_on・left_on）。person_id は分析のためにつけた「人」の番号で、購入の表にはない
- `data/purchases.csv`：架空の購入（purchase_id・member_no・purchased_on・amount）

## 注意（言えないこと）
- 架空のデータです。使い回しの多さ（在籍日数・空ける日数）は作成者が置いたもので、ずれの大きさはこれで決まります
- T-SQL 版は未検証です
- 退会日と同じ日の購入や、退会の取り消しなど、境目の扱いは仕組みごとに違います（ここでは退会日より前を在籍中とした）
