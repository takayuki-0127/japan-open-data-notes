# 394 似た変数を2つ入れた回帰は、係数の符号がどれくらい逆になるのか

よく似た動きをする2つの変数を、同じ回帰に入れたときに起きること（多重共線性）を、真の係数が分かっている架空のデータで数えたフォルダです。本当はどちらもプラスの係数が、**マイナスに出る割合**を、2つの変数の相関とデータの件数ごとに出しました。あわせて、予測の誤差が変わるかどうかを確かめました。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A394 | 2つの説明変数の相関（0〜0.99）と件数（30〜1,000件）で、係数の符号が逆になる割合はどう変わるか。片方を外すとどうなるか。予測の誤差は変わるか | y = x1 + x2 + 揺れ のデータを4,000回ずつ作って回帰する。新しいデータ（同じ相関／相関が切れた）で予測の誤差を測る | `src/a394_collinearity.py` |

## 設定
- 本当の関係：y = 1.0×x1 + 1.0×x2 + 揺れ（標準偏差2）。x1・x2 は標準偏差1
- 係数の大きさが違う場合（1.0 と 0.3）も試した

## 主な結果
### どちらかの係数がマイナスに出た割合（%、4,000回）
| 相関 | VIF | 30件 | 100件 | 300件 | 1,000件 |
|---|---|---|---|---|---|
| 0 | 1.0 | 1.6 | 0.0 | 0.0 | 0.0 |
| 0.5 | 1.3 | 2.7 | 0.0 | 0.0 | 0.0 |
| 0.8 | 2.8 | 12.1 | 0.4 | 0.0 | 0.0 |
| 0.9 | 5.3 | 27.1 | 3.2 | 0.0 | 0.0 |
| 0.95 | 10.3 | 41.9 | 12.8 | 0.8 | 0.0 |
| 0.99 | 50.3 | 69.0 | 48.0 | 22.0 | 2.8 |

（VIF は 1÷(1−相関²)。係数のばらつきが、相関がないときの何倍になるかを分散で表した値）

- **相関0.9では、30件で27%、100件で3%**。相関0.95では100件でも13%、相関0.99では300件でも22%
- 理屈の式（係数のばらつき＝揺れ÷√(件数×(1−相関²))）から出した割合と、100件以上では1ポイント以内で合った
- マイナスに出ても、**「はっきりマイナス」（p<0.05）と出たのは多くて1.8%**。符号が逆のときは、たいてい幅が0をまたいでいる
- **2つとも「効いているとは言えない」のに、2つ合わせると「効いている」と出た割合**：相関0.9・30件で58%、相関0.95・100件で33%、相関0.99・300件で55%

### 1つずつは揺れるが、合計は揺れない（相関0.95・100件）
- x1 の係数のばらつき（標準偏差）は0.66。値は−1.2から3.0まで出た
- 2つの係数の合計のばらつきは0.21。x1 の係数と x2 の係数の相関は−0.95で、片方が大きく出ると、もう片方が小さく出る

### 本当の係数が1.0と0.3のとき、どちらかがマイナスに出た割合（%）
| 相関 | 30件 | 100件 | 300件 | 1,000件 |
|---|---|---|---|---|
| 0 | 21.5 | 7.1 | 0.5 | 0.0 |
| 0.8 | 36.5 | 19.6 | 5.8 | 0.3 |
| 0.9 | 50.1 | 27.5 | 12.9 | 1.9 |
| 0.95 | 60.6 | 38.4 | 21.6 | 6.7 |

- 小さい係数は、相関がなくても件数が少ないと符号が逆になる。相関が高いと、1,000件でも残る

### 予測の誤差（RMSE。これ以上は下がらない値は2.0。100件で作った式）
| 作ったときの相関 | 新しいデータも同じ相関：2つとも／x2 を外す | 新しいデータは相関なし：2つとも／x2 を外す |
|---|---|---|
| 0 | 2.03 ／ 2.26 | 2.03 ／ 2.26 |
| 0.8 | 2.03 ／ 2.11 | 2.06 ／ 2.39 |
| 0.9 | 2.03 ／ 2.07 | 2.12 ／ 2.43 |
| 0.95 | 2.03 ／ 2.04 | 2.22 ／ 2.45 |
| 0.99 | 2.03 ／ 2.03 | 2.88 ／ 2.46 |

- **新しいデータでも2つの変数が同じように一緒に動くなら、予測の誤差は相関によらず2.03**。符号が逆でも予測は外れない
- x2 を外すと、x1 の係数は 1＋相関（相関0.95で1.96）になり、x2 の分を肩代わりする。相関が高いほど、外しても予測の誤差は変わらない
- **新しいデータで2つの変数の動きが分かれると、どちらの式も外れる**。相関0.99で作った「2つとも入れた式」は2.88で、片方を外した式（2.46）より悪い

## 動かし方
```
pip install -r requirements.txt
cd src && python a394_collinearity.py      # 約30秒
```
`data/example_r095_n100.csv`、`results/` の4ファイル、`figures/` の3枚ができます。

## 確かめたこと
- 空のフォルダで計算し直し、data・results・figures が一致した
- 符号が逆になる割合は、理屈の式の値と、100件以上では1ポイント以内で一致した（30件では最大4ポイント多い）
- 係数の平均は、どの相関・件数でも0.96〜1.04（偏りはなく、ばらつきだけが大きくなる）

## 注意（言えないこと）
- すべて架空のデータです。割合は、揺れの大きさ（標準偏差2。相関0.9のとき、y の散らばりの約半分を説明できる強さ）で決まります。揺れが小さければ、符号は逆になりにくくなります
- 変数は2つだけです。3つ以上が絡む場合や、合計が決まっている割合どうし（構成比）は扱っていません
- リッジ回帰などの「係数を縮める」方法は試していません
- 「どちらを外すべきか」は、ここからは言えません。外した式の係数は「x1 だけの効果」ではなく、x2 の分を含みます
