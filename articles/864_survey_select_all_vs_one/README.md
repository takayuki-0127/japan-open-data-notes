# 864 「当てはまるものをすべて」と「1つだけ」で、割合はどう変わるのか？（アンケート）

「どの機能を使っていますか」のような質問は、「当てはまるものをすべて選んでください」と「いちばん大事なものを1つだけ選んでください」のどちらでも聞けます。2つの聞き方の割合は、同じ人に聞いても別の数字になり、並べて比べたり、片方をもう片方の代わりに読んだりすると読み違えます。**ここでは、作成者が乱数で作った架空の料理レシピのサービスの利用者アンケート（8つの機能について、利用者ごとに「使っているか」（正解）と「その機能をどれだけ大事に思っているか」を作成者が置いたもの）で、機能ごとに「はい・いいえ」で聞く・すべて選ぶ・1つだけ選ぶの3つの聞き方と、「すべて」の2つの割り方で、割合と順位がどう変わるかを数えました。**

選択肢の並び順の影響は関連する記事 863、質問文を変えた年の前年比は 872 で扱っています。この記事は「複数選ぶか1つだけか」に絞り、並び順の影響は入れていません。

| A864 | 「すべて」と「1つだけ」で、機能ごとの割合と順位はどう変わるか。「すべて」の割合を回答者数で割るか、選ばれた数で割るかで何が変わるか | 架空の料理レシピのサービスの利用者1,000人。8つの機能（検索・お気に入り保存・人気順の一覧・タイマー・手順の動画・買い物リスト・献立の提案・コメント欄）を使っている人の割合（正解）は80・55・50・45・40・30・25・20%。使い方の重なり：利用者ごとの「使う多さ」a（標準正規）と機能ごとのでたらめな値から z=λa+√(1−λ²)e を作り、z が正規分布の p 分位点より小さければ使っていると置いた（λ=0.5）。使っている機能ごとの「大事さ」s は、機能ごとの平均（−0.6・0・−0.3・−0.8・0.8・0.6・0.9・−0.5）＋標準正規。聞き方は3つ：①機能ごとに「はい・いいえ」：使っている機能を確率 1/(1+exp(−(3.5+s))) で「はい」②すべて選ぶ：使っている機能を確率 1/(1+exp(−(1.9+s))) で選ぶ（大事さの弱い機能ほど選び忘れる）③1つだけ：使っている機能のうち s＋迷い（標準偏差 σ=0.5 の正規）がいちばん大きいもの。使っている機能がない人は「特になし」。調査を作り直して2,000回。確かめとして、重なり λ（0・0.5・0.8）×迷い σ（0.25・0.5・1.5）×選び忘れの強さ（1.0・1.9・3.0）の27通り（各300回）と、大事さの差をなくした3通りを数えた。seed 864 | `src/a864_select_all_vs_one.py` |

ここでの「大事さ」「選び忘れ」「迷い」は、すべて作成者が置いた物差しです。人の答え方を測ったものではありません。

## 主な結果

### 聞き方ごとの割合（2,000回の平均、`results/shares_by_format.csv`）
| 機能 | 正解（使っている人） | はい・いいえ | すべて（回答者数で割る） | すべて（選ばれた数で割る） | 1つだけ |
|---|---|---|---|---|---|
| 検索 | 80.0% | 74.0% | 59.8% | 21.5% | 17.8% |
| お気に入り保存 | 55.0% | 52.6% | 45.9% | 16.4% | 16.0% |
| 人気順の一覧 | 50.0% | 47.1% | 39.7% | 14.2% | 10.9% |
| タイマー | 45.0% | 41.0% | 32.2% | 11.5% | 5.9% |
| 手順の動画 | 39.9% | 39.1% | 36.4% | 13.0% | **19.2%** |
| 買い物リスト | 30.0% | 29.2% | 26.8% | 9.6% | 11.7% |
| 献立の提案 | 25.0% | 24.6% | 23.0% | 8.2% | 11.7% |
| コメント欄 | 20.1% | 18.7% | 15.3% | 5.5% | 2.8% |
| 合計 | 345% | 326% | 279% | 100% | 96%（特になし4.2%） |

- **「1つだけ」の割合は、使っている人の割合とは別ものだった**。8割が使う検索は「1つだけ」では17.8%（5〜95%の範囲で15.8〜19.8%）で、手順の動画（19.2%）に次ぐ2位だった。使っている人のうち、いちばんに選んだのは、検索で22.2%、手順の動画で48.0%、献立の提案で46.6%
- 「1つだけ」の1位は、2,000回のうち手順の動画が1,497回（74.9%）、検索が474回（23.7%）。順位の相関（正解の順位とどれだけそろうか、1なら同じ順）は、1つだけ 0.53、すべて 0.97、はい・いいえ 0.99
- 「すべて」は、使っている機能の80.8%しか選ばれなかった（はい・いいえは94.5%）。1人あたり使っているのは3.45個、選んだのは2.79個。大事さの弱い機能ほど減り、正解に対して検索は0.75倍、タイマー0.72倍、コメント欄0.76倍、手順の動画0.91倍、献立の提案0.92倍。タイマーと手順の動画は順位が入れかわった
- 「すべて」を選ばれた数の合計で割ると合計100%になり、「1つだけ」と同じ大きさの数字に見える（検索21.5%と17.8%）。ただし意味は「選ばれた印のうちの割合」で、使っている人の割合でも、いちばんに選んだ人の割合でもない

### 確かめ：置き方を変えると（`results/robustness.csv`）
- 27通りで、検索の「1つだけ」の割合は14.4〜24.3%（「1つだけ」は選び忘れの強さによらないので、実際は重なり×迷いの9通り）。どの置き方でも使っている人の80%とは大きく離れた
- 「1つだけ」の1位が検索（正解の1位）になった調査の割合は、0〜100%と置き方で大きく動いた。使い方の重なりが強い（よく使う人は何でも使う）か迷いが大きいと検索が1位になり、重なりがなく迷いが小さいと検索は1位にならなかった（図3）
- 「1つだけ」と正解の順位の相関は0.38〜0.79、「すべて」で選ばれた割合（使っている機能のうち）は67〜92%、コメント欄の「すべて」は正解の0.60〜0.90倍、手順の動画は0.82〜0.97倍
- **大事さの差をなくす（どの機能も同じくらい大事と置く）と、「1つだけ」の順位は正解とほぼそろった**（相関0.98、検索は27.1%で1位）。この記事の順位の入れかわりは、作成者が置いた「機能ごとの大事さの差」から出ている

### 1回分の調査（data/respondents.csv）
- 検索：正解79.6%、はい・いいえ73.0%、すべて58.6%、1つだけ18.3%。手順の動画：正解39.9%、すべて36.5%、1つだけ18.4%（`a864_main.json` の one_survey）

## 動かし方
```
pip install -r requirements.txt
cd src && python a864_select_all_vs_one.py
```
20秒ほどで終わります。`data/` の2つのファイルもこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約17秒）
- 2,000回の平均の「使っている人の割合」が、置いた正解（80・55・…・20%）と0.1ポイント以内で合うことを確かめた（`shares_by_format.csv` の truth と truth_sim）
- 大事さの差をなくすと「1つだけ」の順位が正解とそろうことを確かめ、入れかわりが置いた大事さの差から出ていることを確かめた

## データ
- `data/respondents.csv`：1回分の架空の利用者1,000人。id・use_1〜use_8（その機能を使っているか、作成者だけが知る正解）・all_1〜all_8（すべて選ぶで選んだか）・yn_1〜yn_8（はい・いいえで「はい」か）・one（1つだけで選んだ機能の番号、0は特になし）
- `data/items.csv`：機能の番号と名前

同じ人に3つの聞き方を全部したことにしていますが、実際には1人に1つの聞き方しかできません。答えどうしが影響し合わないように置いた、作成者の計算上の比べ方です。

## 注意（言えないこと）
- 架空のデータです。使っている人の割合、機能ごとの大事さ、選び忘れの強さ、迷いの大きさは作成者が置いたもので、結果はこれで決まります。とくに「1つだけ」で順位が入れかわるかどうかは、大事さの差の置き方の写しに近く、差をなくすと入れかわりは消えました
- 「すべて」で選び忘れる割合（使っている機能の67〜92%しか選ばれない）は、作成者が置いた値です。実際にどれだけ選び忘れるかを測ったものではありません
- 選択肢の並び順（上のほうが選ばれやすいなど）は入れていません（関連する記事 863）
- 「1つだけ」の割合から「使っている人の割合」を推し量る方法は扱っていません。2つは別の問いの答えです
- 実在のサービスの機能や利用のされ方を表すものではありません
