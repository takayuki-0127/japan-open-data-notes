# 945 区域の線の引き方で、「いちばん売れる地区」は入れ替わるのか？（地図と場所）

町をいくつかの地区に分けて売上を合計すると、「いちばん売れる地区」が決まります。けれども、同じ売上でも、地区の線をどこに引くかで、どの地区の合計がいちばん大きくなるかは変わります。**ここでは、作成者が乱数で作った架空の町（20×20の街区。売れる場所Aと、それより少し弱い売れる場所Bの2つの山を作成者が置いたもの）の1か月の売上を、線の引き方だけを変えた2,000通りの区割り（5地区）で集計し、いちばん売れる地区がAを含むかBを含むかを数えました。** 区割りを固定して月ごとの売上の振れだけを変えた場合とも比べ、置き方を変えて確かめました。

地図は架空の格子で、実在の地名や地図のデータは使っていません。

関連する記事：期間の切り出し方で「上昇」も「下落」も描ける話は 817（グラフ）で、この記事はその「区切り方」を時間ではなく場所で数えたものです。数の少ないカテゴリで1位が偶然に決まる話は 811（口コミと星の数）、店の数を面積で割るか人口で割るかで地図が変わる話は 946、区域の大きさ（細かさ）を変えると区域の平均どうしの相関がどう変わるかは 954 で扱っています。954 は区域の大きさを変える話で、この記事は地区の数（5）を変えずに線の位置だけを変える話です。

## 主な結果

### 同じ1か月の売上を、2,000通りの区割り（5地区）で集計
町全体の売上は8,275万円。Aのまわり（半径4街区以内）は2,184万円、Bのまわりは1,892万円だった。

| いちばん売れる地区が | 区割りのうちの割合 |
|---|---|
| Aだけを含む | **51.9%** |
| Bだけを含む | **38.5%** |
| AとBの両方を含む | 2.6% |
| AもBも含まない | 7.0% |

- 売上は1か月分で同じなのに、線の引き方だけで、いちばん売れる地区がAを含まずBを含む区割りが38.5%あった。2つの区割りをでたらめに選ぶと、40.1%の組で、一方はAを含む地区、もう一方はBを含む地区が1位になった
- いちばん売れる地区は、5地区のうちいちばん広い地区であることが68.6%あった。広さと関係がなければ20%のはず。合計は街区の数が多いほど大きくなるので、これはほぼ足し算どおりの結果
- 1位の地区が町全体の売上に占める割合は、区割りによって29.2〜47.8%（10〜90%の範囲）と動いた
- 街区ごとに「いちばん売れる地区」に入った割合は、Aの街区で54.1%、Bの街区で41.6%。どの街区も16.4%以上の区割りで1位の地区に入り、5%以下の街区は1つもなかった

### 例の4つの区割り（同じ売上）
| 区割り | 1位の地区 | 1位の地区の街区の数 | 1位の地区の売上（万円） |
|---|---|---|---|
| 区割り1 | Aを含む | 69 | 2,392 |
| 区割り2 | Bを含む | 154 | 3,462 |
| 区割り3 | Bを含む | 115 | 2,941 |
| 区割り4 | AもBも含まない | 104 | 2,413 |

### 区割りを固定し、月ごとの振れだけを変えると
- 区割り1のまま売上を1,000か月作り直すと、1位の地区は**100%**同じだった。この置き方では、1位を入れ替えるのは月ごとの振れではなく線の引き方だった
- ただし、月ごとの振れはポアソン分布と置いたので、1位の地区の合計（例の4つの区割りで2,392〜3,462万円）に比べて小さい。1位が変わらないのは、この置いた振れの小ささからほぼ決まる結果で、月ごとの振れが大きい売上なら1位は月でも入れ替わりうる（推測。数えていない）

### 確かめ：置き方を1つずつ変えると（各500通りの区割り）
| 変えたもの | 値 | Aだけを含む | Bだけを含む | 両方を含む | どちらも含まない | 1位が最も広い地区 | 広さと無関係なら |
|---|---|---|---|---|---|---|---|
| Bの山の強さ（Aに対する比） | 0.3 | 77.8% | **13.6%** | 1.8% | 6.8% | 55.6% | 20% |
| | 0.45 | 71.6% | 16.2% | 2.2% | 10.0% | 59.4% | 20% |
| | 0.6 | 60.2% | 30.2% | 2.2% | 7.4% | 65.0% | 20% |
| | **0.85（基本）** | 49.8% | 39.8% | 2.2% | 8.2% | 68.4% | 20% |
| | 1.0 | 46.0% | **46.8%** | 1.6% | 5.6% | 70.6% | 20% |
| 地区の数 | 3 | 53.2% | 32.4% | 10.6% | 3.8% | 80.8% | 33.3% |
| | **5（基本）** | 53.0% | 38.8% | 2.2% | 6.0% | 66.6% | 20% |
| | 8 | 54.6% | 38.4% | 0.0% | 7.0% | 54.0% | 12.5% |
| | 12 | 56.4% | 34.4% | 0.0% | 9.2% | 48.0% | 8.3% |

- **Bだけを含む地区が1位になる割合は、置き方で13.6〜46.8%動いた。Bの山をAの0.3倍まで弱くしても、13.6%の区割りでBだけを含む地区が1位になった**
- 地区の数を3から12に増やしても、Bだけを含む地区が1位になる割合は32.4〜38.8%で、線の引き方の効きは消えなかった
- どの置き方でも、1位の地区がいちばん広い地区である割合（48.0〜80.8%）は、広さと無関係なときの割合（8.3〜33.3%）を大きく上回った
- 基本の置き方は、変えたものごとに売上と区割りを作り直して数えたので、Bだけを含む割合は35.6〜39.8%と、2,000通りの38.5%から少し動く

## 動かし方
```
pip install -r requirements.txt
cd src && python a945_zoning_top_district.py
```
2秒ほどで終わります。`data/cells_example_month.csv` と `data/zonings_example4.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約1.8秒）
- 図3枚を開き、日本語・重なり・軸を確かめた。区割りの境界線は街区の辺に沿って引いた
- Bの山をAに近づけるほどBだけを含む地区が1位になる割合が上がり（13.6%→46.8%）、作りが置いたとおりに動いていることを確かめた

## データ
- `data/cells_example_month.csv`：架空の町の400街区（x・y・level（本当の売上の水準、万円）・sales（例の1か月の売上、万円））
- `data/zonings_example4.csv`：例の4つの区割り（街区ごとの地区の番号）
- `results/a945_main.json`：主な結果すべて
- `results/zonings_2000.csv`：2,000通りの区割りごとの1位の地区（Aを含むか・Bを含むか・いちばん広い地区か・街区の数・売上の割合）
- `results/robustness.csv`：置き方を1つずつ変えた確かめ

## 注意（言えないこと）
- 架空のデータです。売れる場所の数・強さ・広がり、区割りの作り方は作成者が置いたもので、結果はこれで決まります。Aを含まずBを含む地区が1位になる割合は、置き方で13.6〜46.8%と動きました。実際の町や店の売上を表すものではありません
- 区割りはランダムな中心からのボロノイ分割だけで作りました。道路や川に沿った線、面積や人口をそろえた線、営業の担当で決めた線などは入れていません
- 「いちばん売れる地区」を合計で決めました。1街区あたりの売上で比べると、狭い地区が上に来やすくなるなど、別の偏りが出ます（割る数の話は 946）
- どの区割りが正しいか、どこに出店すべきかは言えません。この記事は、同じ売上でも線の引き方で1位の地区が変わることを数えただけです
