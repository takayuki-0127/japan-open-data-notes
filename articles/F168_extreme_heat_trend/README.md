# F168 猛暑日の数は、どこまで増えたと言えるか？

note の看板記事 F168 の分析コード・データ・図です。

## 問い

猛暑日（日最高気温35℃以上の日）は「増えた」とよく言われます。気象庁の30地点、125年分の年ごとの値を使って、次の2つを確かめます。

- どこまでなら「増えた」と言えるか
- その増え方のうち、どれだけが都市の影響と見分けられるか

## データ

気象庁「過去の気象データ検索」の年ごとの値（気温・日数のページ、view=a2）を使います。

- **期間**：観測開始〜2025年。分析は1901〜2025年です。
- **使った値**：地点ごとの年最高気温（その年でいちばん高かった日最高気温）、日最高気温の年平均、日最高気温が25℃・30℃・35℃以上の日数。
- **地点**：30地点。2つのグループに分けます。
  - **R（都市化の影響が少ない15地点）**：気象庁が日本の平均気温の計算に使う地点です。網走・根室・寿都・山形・石巻・伏木・飯田・銚子・境・浜田・彦根・多度津・宮崎・名瀬・石垣島。
  - **U（大都市など15地点）**：東京・名古屋・大阪・福岡・京都・札幌・仙台・広島・熊谷・甲府・岐阜・鹿児島・横浜・神戸・新潟。
- **除いた値**：資料不足値（「 ]」の付いた値）・欠測（×）、年の途中の2026年。除いたのは74行で、残りは4,074行です。
- **仙台**：1926年からです。

| ファイル | 中身 |
|---|---|
| data/raw/jma_annual_a2.csv | 取得したままの表。30地点の全年。資料不足値の印もそのまま残しています |
| data/annual_clean.csv | 02_整形.py の出力（4,074行） |

## 手法

- **年最高気温：非定常の一般化極値分布（GEV）**
  - 位置母数 μ に時間トレンドを入れます：μ(t) = μ0 + μ1·t（t は100年単位）。
  - 尺度 σ と形 ξ は一定です。
  - 地点ごとに最尤法で推定し、μ1 の95%区間は数値ヘッシアンから求めました。
  - トレンドがない形（定常）とは、尤度比で比べます。
  - 38℃以上になる確率は「何年に1度」に直して、1925年と2025年で比べます。
    - 2025年の区間は、母数の推定誤差を多変量正規分布から2,000回引いて求めました。
- **猛暑日の数：回数のモデル**
  - 年ごとの猛暑日の数を、年に回帰しました。ポアソン回帰と負の二項回帰の両方です。
  - 10年あたりの倍率で示します。
  - 1901〜2025年の合計が20日未満の地点では、モデルを当てていません。
- **モデルを使わない数え方**
  - 年最高気温が37℃・38℃以上だった「地点×年」の数を、1901〜1950年と1976〜2025年で比べます。
- **都市の影響**
  - RとUで、μ1 の平均の差を比べます。
  - 検定は Welch の t 検定と、グループの付け替えによる並べ替え検定（1万回）です。

乱数の種は168に固定しています。

## 結果

### 年最高気温

- **上昇の大きさ**：30地点すべてで、年最高気温の位置母数ははっきり上がっていました（95%区間が0より上）。中央値は100年あたり +1.70℃、範囲は名瀬の +0.63℃ から熊谷の +3.53℃ です。
- **形の母数**：ξ の中央値は −0.27 です。年最高気温には上限がある形になります。

### 38℃以上の年

- **モデルを使わない数え方**：
  - 38℃以上は、1901〜1950年に26（地点×年）、1976〜2025年に167で、6.4倍になりました。
  - 37℃以上は、108から379で、3.5倍です。
- **2025年の当てはめで「何年に1度」か**（括弧は95%区間）：

| 地点 | 何年に1度（2025年） |
|---|---|
| 熊谷 | 1.4（1.2〜1.7） |
| 岐阜 | 1.7 |
| 京都 | 1.9 |
| 甲府 | 2.1 |
| 名古屋 | 2.4 |
| 大阪 | 3.2 |
| 東京 | 3.9（2.6〜6.5） |
| 境 | 7.7（4.4〜15.3） |

- **1925年の当てはめ**：東京は約460年に1度、熊谷は約53年に1度です。ただし直線を100年さかのぼった値なので、幅はとても広くなります（「言えないこと」を参照）。

### 猛暑日の数

- **対象**：合計が20日以上ある23地点です。
- **30年平均の比較**：1901〜1930年の平均（中央値1.4日）より、1996〜2025年の平均（中央値7.5日）の方が、23地点すべてで多くなりました。比の中央値は5.3倍です。
- **10年あたりの倍率**：負の二項回帰で、中央値は1.21倍です。はっきり1を超えたのは21地点でした。
  - 名瀬：区間が1をまたいでいます。
  - 横浜：区間を計算できませんでした。
- **猛暑日がほとんどない地点**：北海道の4地点、石巻、銚子、石垣島の7地点は、125年の合計が20日に届きません。
- **ポアソン回帰では区間が狭くなりすぎる**：ポアソン回帰では過分散（中央値4.9倍）があり、区間の幅は負の二項回帰のおよそ半分になります。
- **真夏日（30℃以上）**：30地点すべてではっきり増えていました。10年あたり1.035倍で、RとUの差はありません（p=0.62）。

### 都市の影響

- **差の大きさ**：Uの平均は +1.98℃、Rの平均は +1.50℃ で、差は +0.49℃／100年でした（Welch p=0.049、並べ替え p=0.047）。
- **地点の入れ替え**：1地点ずつ抜いても、差は +0.37〜+0.57℃ です。東京を抜くと +0.43℃ でした。

## 言えないこと

- **原因**
  - この分析は「増えたかどうか」を見たもので、地球温暖化と都市化のどちらがどれだけ効いたかは分けていません。
  - RとUの差（100年で約0.5℃）は、都市化の影響の目安にはなります。ただし、地点の選び方で動く範囲（0.4〜0.6℃）があり、p=0.05前後です。
  - Rの15地点にも、周りの開発の影響はありえます。
- **観測点の移転・測器の変更**
  - 補正していません。たとえば東京は2014年に大手町から北の丸公園へ移りました。
  - 年ごとの値は気象庁の公表値をそのまま使っています。移転の前後で値がずれていても、そのまま入っています。
- **1925年の「何年に1度」**
  - 直線を100年さかのぼった値です。点の推定でも数十〜数百年に1度と幅があり、1,000年を超える地点もあります。
  - 数字そのものより、モデルを使わない数え方（26 → 167）の方を信頼してください。
- **年最高気温は、1年で1日だけの値**
  - 暑い日が何日続いたかや、夜の暑さは見ていません。夜の暑さは日最低気温で見るべきものです。
- **猛暑日の「35℃」**
  - 気温の分布の端の、ある1点の数です。北海道などでは、ほとんど0のまま数が動きません。
  - 「猛暑日の倍率」は、もともと少ない地点ほど大きく出ます（最大75倍）。
- **これから先**
  - 直線や折れる線を、この先に延ばして予測したものではありません。
- **30地点を並べて調べたこと**
  - 個々の地点の「はっきり」には、偶然の当たりが混ざります。ただし30地点すべて同じ向きなので、全体の結論は変わりません。
- **地域の比較**
  - 地点ごとの差は、地域の良し悪しを示すものではありません。
