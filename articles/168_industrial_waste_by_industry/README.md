# 168 産業廃棄物は、どの業種からどれだけ出ているか

環境省「産業廃棄物の排出及び処理状況等（令和5年度実績）」の別添資料（PDF）から、業種別・種類別の排出量と処理の流れを取り出し、どの業種・どの種類が多いかを調べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A168 | 産業廃棄物はどの業種から、どんな種類がどれだけ出ているか。どれくらい再生利用されているか | 業種別（製造業は中分類に分けて並べる）・種類別の構成比、令和4年度からの増減、種類別の再生利用率 | `src/a168_share.py` |

## 主な結果
- 総排出量は令和5年度 3億6,725万t（令和4年度から −1.8%）
- 業種別では 電気・ガス・熱供給・水道業 26.5%、農業・林業 22.0%、建設業 21.8%、パルプ・紙 7.4%、鉄鋼業 6.0%で、上位5業種で83.6%
- 製造業（大分類）全体では26.1%。製造業の中ではパルプ・紙と鉄鋼業が大きい
- 種類別では汚泥 42.1%、動物のふん尿 21.9%、がれき類 16.5%で、3種類で80.5%
- 全体の再生利用率は54.7%、最終処分は2.4%。がれき類・金属くず・動物のふん尿・鉱さいは再生利用率90%超、汚泥は7.6%
- 前年度からの変化では鉱業 −34.5%、電子部品・デバイス −28.0%、電気機械 +101.8%（いずれも1年分の変化）

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a168_share.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/by_industry_r5_r4.csv | 表1-1 業種別排出量（千t、令和5年度・令和4年度）。level=大分類／製造業内訳／合計 |
| data/by_type_r5_r4.csv | 表1-2 種類別排出量（千t）と、本文で示された種類別の再生利用率（令和5年度） |
| data/flow_r5.csv | 図2-1 処理フロー（令和5年度） |

## 注意
- 都道府県の報告を環境省が集計し、未調査業種などを補正した推計値
- 業種と種類のクロス集計はこの資料にはなく、「どの業種がどの種類を出しているか」は直接は分からない
- 製造業内訳の合計（95,502千t）は製造業の値（95,669千t）と四捨五入などで一致しない
- 再生利用率は本文に数値が書かれている種類だけを使った
- 元の PDF は Web ブラウザ上で読み取り、必要な値を CSV に書き写した
