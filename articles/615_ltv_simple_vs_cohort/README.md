# 615 顧客の生涯の売上を「月の購入額÷退会率」で出すと、登録月ごとの実績からどれだけずれるのか（実務の型・LTV の見積もり）

会員1人の生涯の購入額（LTV）を「1か月の購入額÷1か月の退会率」で出す簡便式は、全員が同じ退会率で辞めていく前提の式です。実際には、すぐ辞める人と長く残る人が混ざっていて、長く残る人ほどよく買うことがあります。**ここでは、退会率と購入額の違う2種類の会員（ライト6割：退会率12%・月2,000円、ヘビー4割：退会率3%・月5,000円）が毎月1,000人入会する架空の店（2023〜2025年の36か月）で、簡便式2通りと登録月ごとの実績からの見積もりを、本当の値（10年間）と比べました。** 会員の種類と数字は作成者が置いたもので、結果はその仮定で決まります。

## 主な結果
- **本当の値**：入会した人1人あたり10年間で74,943円（期限なしなら76,667円）
- **簡便式（在籍者全体、L1）**：在籍者の月の購入額3,948円÷退会率6.18%＝**63,863円（−14.8%）**
- **簡便式（入会12か月以内、L2）**：3,509円÷7.43%＝47,201円（**−37.0%**）
- **登録月ごとの実績＋延長（L3）**：71,352円（−4.8%）。観測が12か月だけなら61,218円、24か月なら68,874円で、観測が短いほど小さく出る
- **在籍者の顔ぶれは入会時と違う**：2025年12月の在籍者のヘビーの割合は64.7%（入会時は40%）。在籍30か月を超えた会員では9割前後
- 簡便式が小さく出るのは、「購入額の平均÷退会率の平均」が、「（購入額÷退会率）の平均」と等しくないため。入会した人1人あたりの生涯の購入額76,667円（期限なし）のうち、66,667円を退会率の低いヘビーが占める

## 確かめたこと
- 空のフォルダで流し直し、results・figures がバイト単位で一致した（DuckDB は `SET threads=1`）
- 簡便式の材料（購入額・退会率）が、DuckDB の SQL と pandas で一致した
- 入会からの月ごとの購入額の実績が、本当の値の曲線と重なること

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 615）。会員の月次の表は約34万行
- 仮定：退会は月ごとに一定の確率（種類ごと）、在籍した月には必ず購入があり、購入額はガンマ分布（平均は種類ごと）。退会した月にも購入する

## 注意（言えないこと）
- 架空の店。実際の会社の数字ではない
- ずれの向きと大きさは、会員の種類の混ざり方で決まる。全員が同じ退会率なら簡便式は正しい。購入額と退会率の関係が逆（よく買う人ほど辞めやすい）なら、ずれの向きも変わる
- 割り引き（将来の売上を今の価値に直すこと）は入れていない。広告費や価格の決め方についての助言ではない
