# 788 変数選びを交差検証の前に全部のデータでやると、関係のないデータでも正解率はどれだけ高く出るのか（手法の解説・正解の分かるデータで試す）

たくさんの候補から「y とよく関係する変数」を選び、そのあと交差検証で成績を測る、という手順はよく使われます。このとき、変数選びを全部のデータでやってから交差検証すると、テスト用の fold の情報まで使って選んだことになり、成績が高く出ます。**ここでは、どの変数も y と無関係な（本当の正解率が50%の）架空のデータで、変数選びを先にやる場合と fold の中でやる場合の正解率を比べました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A788 | 変数選びの順番で、交差検証の正解率はどれだけ変わるか | 100件、y は0/1を半分ずつ、x は y と無関係な正規乱数（候補 p＝50〜2,000）。f 検定の上位 k 個（5・20・50）を選び、ロジスティック回帰を5-fold の交差検証で評価。「先に全部のデータで選ぶ」と「fold の中で選ぶ（Pipeline）」を各50回。scikit-learn。seed 788 | `src/a788_fs_leak.py` |

## 主な結果（50回の平均、本当の正解率は50%）

| 候補の数 p（20個選ぶ） | 先に選ぶ | fold の中で選ぶ |
|---|---|---|
| 50 | 63% | 51% |
| 200 | 74% | 51% |
| 1,000 | 82% | 50% |
| 2,000 | **84%** | **49%** |

| 候補2,000個から選ぶ数 | 先に選ぶ | fold の中で選ぶ |
|---|---|---|
| 5個 | 74% | 49% |
| 20個 | 84% | 49% |
| 50個 | **91%** | 50% |

- 関係のない変数だけなのに、先に選ぶと正解率は63〜91%と出た。候補が多いほど、選ぶ数が多いほど高く出た
- 候補2,000個から20個選ぶ場合、50回すべてで正解率が70%以上になった
- fold の中で選ぶと、どの条件でも49〜52%で、本当の50%に近かった

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- 候補が50個で50個すべてを使う（選ばない）場合は、2つの手順が同じ値（50.4%）になること

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 788）

## 注意（言えないこと）
- 架空のデータです。y と関係のある変数は1つもないので、どんな正解率も「見かけ」です
- 関係のある変数がまざる実際のデータでは、高く出る分は小さくなることがあります。ただ、どれだけ高く出たかは、手順を直して測り直すまで分かりません
- f 検定で選ぶ方法だけを試しました。ほかの選び方（Lasso など）でも、選ぶ手順を fold の外でやれば同じことが起きます（推測）
