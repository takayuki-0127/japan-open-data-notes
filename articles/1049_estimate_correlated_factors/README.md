# 1049 要素どうしが関係しているとき、別々に見込んで掛けると何がずれるのか？（概算）

概算では「世帯数×1世帯あたりの台数×1台あたり頼む割合」のように、要素を別々に見込んで掛けます。けれども、台数の多い世帯ほど掃除を頼みやすい、のように要素どうしが関係していると、平均どうしを掛けた値は「台数×割合」の平均と合いません。ずれの大きさは、平均(台数×割合)＝平均(台数)×平均(割合)＋共分散 という式で決まります。もう1つ、1人が要素を見込むときの誤差どうしが同じ向きにそろうと、「要素の誤差は互いに関係ない」と置いて作った幅は狭すぎます。これも式で決まります。**ここでは、作成者が乱数で作った架空の A町の12,000世帯（世帯ごとの台数と頼みやすさ、その関係を作成者が置いたもの）で、①世帯ごとの平均どうしを掛ける、②台数で重みを付けた割合を使う、③戸建て・集合住宅に分けて①を作って足す、の3つの概算を本当の件数と比べ、関係の置き方を変えた45通りで、ずれの向きと大きさ、区分に分けるとどれだけ縮むかを数えました。後半では、3つの要素の見込みの誤差どうしの相関を変え、独立と置いた90%の幅に本当の値が入る割合を数えました。**

例の町・数字はすべて架空のもので、実在の地名・人口・会社の数字は使っていません。

関連する記事：2つの出来事が同時に起きる確率を掛け算で出してよいのは独立のときだけ、という話は 986 で、割合の平均と合計で出した割合の違いは 900 で扱っています。この記事の①と②の違いは 900 と同じ形（世帯ごとの割合の平均と、台数で重みを付けた割合）で、それが掛け算の概算でどれだけのずれになるかを数えます。同じ企画の 1041 は要素の見込みの誤差が掛ける要素の数でどう広がるかを扱い、同じ人の誤差がそろう場合も「2倍以内に入る割合」で数えています。この記事の後半は、誤差どうしの相関を変えたとき、独立と置いて作った90%の幅がどれだけ当たるかに絞ります。前半の、要素どうしが関係すると平均を掛けても本当の値に届かないことは、1042 の後半（来店回数と個数が関係するとき）と同じしくみです。この記事では、関係の向きでずれの向きが変わること、台数で重みを付けた割合と区分に分けた掛け算でどれだけ直るかを数えます。

## 主な結果

### 基本の町での3つの概算（`results/a1049_main.json`）
| 概算 | 件数 | 本当の件数（2,285件）の何倍か |
|---|---|---|
| ① 別々に（世帯ごとの平均どうし） | 1,950.735件 | **0.8537倍** |
| ② 台数で重みを付けた割合 | 2,285.0件 | 1.0倍 |
| ③ 区分ごとに①を作って足す | 2,096.7553件 | 0.9176倍 |

- 1世帯あたりの台数の平均は2.1342台。世帯ごとの「頼んだ割合」の平均は0.0762、台数で重みを付けた割合は0.0892だった。台数の多い世帯ほど頼みやすいので、台数で重みを付けると割合が上がる
- **①は本当の件数の0.8537倍と少なく出た。このずれは、台数と頼んだ割合の共分散からの式の値（0.8537倍）とそのまま一致した（式どおり）**。②は台数で重みを付けたので本当の件数と一致した（これも式どおり）
- 世帯ごとの台数と頼んだ割合の相関は0.1381と小さかった（頼む確率との相関は0.4658。頼んだかどうかは偶然で決まる分が大きいため）。相関が小さく見えても、①は0.8537倍までずれた
- 区分ごとに見ると、戸建ては台数1世帯あたり2.788台・頼んだ割合0.1068、集合住宅は1.585台・0.0633だった。③は区分どうしの違いの分を直し、ずれは0.9176倍まで縮んだ。残りは区分の中での関係から来る
- 町を作り直した100回で、①は0.8289〜0.8791倍（平均0.8581倍）、③は0.9035〜0.9376倍（平均0.9206倍）、②は100回とも1.0倍だった

### 関係の置き方を変える（45通り、`results/grid_45.csv`）
| 世帯の中の相関 | 区分の違い | ①（割合の散らばり0.3／0.6／0.9） | ③（同じ順） |
|---|---|---|---|
| −0.5 | なし | 1.0568／1.1185／1.174倍 | 1.0567／1.1185／1.174倍 |
| −0.5 | 基本 | 0.9928／1.0377／1.0746倍 | 1.0613／1.1175／1.1659倍 |
| 0 | なし | 1.0205／0.989／0.9994倍 | 1.0204／0.989／0.9994倍 |
| 0 | 基本 | 0.9452／0.9444／0.9338倍 | 1.0005／1.0124／0.9978倍 |
| 0 | 基本の2倍 | 0.795／0.791／0.7861倍 | 1.0012／0.9953／1.0019倍 |
| 0.5 | 基本 | 0.875／0.8566／0.7943倍 | 0.9457／0.9175／0.8524倍 |
| 0.5 | 基本の2倍 | 0.775／0.7132／0.6846倍 | 0.9564／0.9145／0.8752倍 |

- **45通りで、①は本当の件数の0.6846〜1.174倍**だった。台数の多い世帯ほど頼みやすい置き方では少なく、頼みにくい置き方（相関が負）では多く出た。どの通りでも①は共分散の式の値と一致した（差の最大0.0）
- 世帯の中の相関を0にした9通りで、①は0.7861〜1.0205倍だった。区分の違いがなければ0.989〜1.0205倍（偶然で生じた共分散の分だけ）だが、区分の違いが基本の2倍だと0.7861〜0.795倍とずれた。台数の多い戸建てほど頼みやすいという区分の違いが、町全体では台数と割合の関係になるため
- ③は45通りで0.8398〜1.174倍。①よりずれが小さかったのは45通り中28通りだった。①のずれがほぼ0の通りを除き、ずれが増えた通りも含めた縮み方の中央値は28.8%だった。区分の違いがないときは①と同じで、区分の中の関係が区分どうしの違いと逆向きのとき（相関−0.5で区分の違いが基本など）は、③のほうがずれた。③は区分どうしの違いの分しか直さない
- ②（台数で重みを付けた割合）は45通りすべてで1.0倍だった（式どおり）

### 後半：見込みの誤差どうしの相関と、独立と置いた90%の幅（各20万回、`results/width_by_error_corr.csv`）
| 3つの見込みの誤差どうしの相関 | 独立と置いた90%の幅 | 幅に入った割合 | 式の値 | 本当に90%入るのに要る幅 |
|---|---|---|---|---|
| −0.3 | ×÷2.711倍 | 99.08% | 99.07% | ×÷1.878倍 |
| 0 | ×÷2.711倍 | 89.89% | 90.0% | ×÷2.718倍 |
| 0.3 | ×÷2.711倍 | 80.73% | 80.65% | ×÷3.522倍 |
| **0.5** | ×÷2.711倍 | **75.5%** | 75.52% | ×÷4.105倍 |
| 0.8 | ×÷2.711倍 | 69.27% | 69.23% | ×÷4.989倍 |

- **見込みの誤差どうしの相関が0.5なら、独立と置いて作った90%の幅（本当の値の2.711倍から2.711分の1まで）に本当の値が入ったのは75.5%**だった。本当に90%入れるには、4.105倍から4.105分の1までの幅が要った。どれも正規分布の式の値どおり
- 相関が負（−0.3）だと、誤差が打ち消し合い、独立と置いた幅は広すぎた（99.08%）

## データ
- `data/households.csv`：基本の置き方の12,000世帯。household・house（1＝戸建て）・units（台数）・p（1台あたり頼む確率）・requests（頼んだ台数）
- `results/a1049_main.json`：主な結果すべて（100回の範囲、45通りの範囲も入れた）
- `results/grid_45.csv`：45通りの①②③と式の値、相関（rho は世帯の中の相関、gap は区分の違い、sig_p は頼む確率の散らばり）
- `results/width_by_error_corr.csv`：見込みの誤差どうしの相関と90%の幅

## 注意（言えないこと）
- 架空のデータです。台数と頼む確率の分布、その関係、区分どうしの違いは作成者が置いたもので、①のずれはこれで決まります（式どおり）。45通りで0.6846〜1.174倍と、向きまで変わりました
- ①の「頼んだ割合」は世帯ごとに頼んだ台数÷台数で数え、それを世帯で平均しました。調べ方（世帯に聞くか、台数で数えるか）で、どちらの割合が手に入るかは変わります
- 後半の見込みの誤差は、3つとも同じ大きさで同じ相関と置きました。実際の人の見込みの誤差がどれだけ関係しているかを測ったものではありません
- 実在の町の需要や、商売の判断に使える数字を表すものではありません。要素どうしの関係で概算がどうずれるかを数えただけです
