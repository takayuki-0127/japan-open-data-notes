# 783 合計の範囲を固定したまま行を足していくと、月の合計はどれだけ少なく出るのか（実務の型）

月ごとの入力シートの下に「=SUM(B2:B101)」のような合計の式を置いておくと、入力が101件を超えた分は合計に入りません。式はエラーを出さず、数字はそれらしく出続けます。列全体の合計や、表（テーブル）の範囲の合計にしておけば、行が増えても入ります。**ここでは、作成者が乱数で作った架空の入力表（2025年の12か月、月に89〜164件）で、範囲を100行に固定した合計がどれだけ少なく出るかを Python で再現しました（Excel では未検証）。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A783 | 範囲が固定された合計は、月にどれだけ少なく出るか | 架空の入力表1,525件（1件1行、日付順）。合計の式は先頭100行に固定、とする。列全体・表の範囲の合計（全行が入る）と比べる。全件の月の合計を DuckDB（1スレッド）でも出し、一致を確認。seed 783 | `src/a783_sum_range.py`、`src/02_check_duckdb.sql`、`src/01_check_tsql.sql` |

## 主な結果

| | 値 |
|---|---|
| 行が100件を超えた月 | 12か月のうち **10か月** |
| 1年の合計の不足 | 215万円（**24.1%**） |
| 最も少なく出た月 | 12月（164件）、**41.3%** 少ない |
| 合計がずれ始めた日 | 早い月で18日、まん中の月で24日 |

- 100件を超えた10か月では、合計が平均26.7%少なく出た
- 合計がずれ始めるのは月の後半（18〜25日）からで、月の前半に確かめても気づけない
- 12月は18日から合計が止まり、あとは入力しても増えなかった

## 注意（言えないこと）
- 架空のデータです。月の件数と式の範囲（100行）は作成者が置いたもので、不足の大きさはこれで決まります
- Excel の動き（範囲の外の行は合計に入らないこと）は Python で再現したもので、Excel では未検証です。範囲の途中に行を挿入した場合は、範囲が広がることがあります
- T-SQL 版は未検証です
