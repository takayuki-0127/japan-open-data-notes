# 600 過去の年の損害から分布を推定するとき、推定の誤差を入れないと、99.5%点はどれだけ小さく出るのか（手法の解説・保険数理）

200年に1度の大きな損害の目安（99.5%点）を、過去10年ほどのデータから分布を当てはめて出すことがあります。このとき、推定した平均とばらつきを「本当の値」としてそのまま使うと、推定そのものの誤差（10年分しかないことによる揺れ）が入りません。**ここでは、架空の年間の総損害（対数正規、中央値1億円）で、過去5・10・20・50年分のデータから99.5%点を、①推定値をそのまま使う、②パラメトリック・ブートストラップ、③ベイズの予測分布（無情報の事前分布）の3通りで出し、翌年の損害がその点を本当に超える確率を比べました。** 年ごとのばらつき（対数の標準偏差 σ 0.2・0.4・0.6）も変えています。数字は置いた前提で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A600 | 推定の誤差を入れないと、99.5%点を本当に超える確率はどれだけ大きいか | 年間の総損害を対数正規で n 年分つくり、対数の平均と標準偏差を推定する。①そのまま exp(μ̂ + 2.576 σ̂)、②推定した分布から n 年を作り直して推定し直し、次の1年を引く（2,000通り）、③ μ̂ + t(n−1) × s × √(1 + 1/n)。本当の分布で超える確率を各2万回（②は2,000回）の平均で出す。10年分の例を DuckDB（1スレッド）の SQL と Python で突き合わせ。seed 600 | `src/a600_param_uncertainty.py`、`src/02_quantile_duckdb.sql`、`src/01_quantile_tsql.sql`（未検証） |

## 主な結果（σ 0.4）
- **10年分のとき、翌年の損害が99.5%点を本当に超える確率**：推定値をそのまま使うと **2.2%**（目標の0.5%の4倍強）、ブートストラップ1.8%、ベイズの予測分布0.49%
- **年数を変えると**（そのまま使う場合）：5年5.3%、10年2.2%、20年1.2%、50年0.74%。ベイズの予測分布はどの年数でも0.49〜0.55%
- 超える確率は σ によらない（σ 0.2・0.4・0.6 で、10年分はどれも2.2〜2.3%）。対数正規では、推定の誤差の大きさが σ に比例するため
- **10年分から推定した99.5%点のぶれ**：そのまま使うと、本当の99.5%点に対する比の中央値0.92で、63%の回で本当より小さい
- **誤差を入れた分の上乗せ**（ベイズの予測分布 ÷ そのまま − 1、中央値）：10年分で σ 0.2 なら21%、0.4 なら45%、0.6 なら74%。5年分の σ 0.6 では350%、50年分の σ 0.2 では3%
- 10年分の例：そのまま使うと2億6,887万円、ベイズの予測分布では4億2,988万円（本当の99.5%点は2億8,020万円）

## 動かし方
```
pip install -r requirements.txt
cd src && python a600_param_uncertainty.py
```
1分ほどで終わります。`data/annual_losses.csv`（year・total_loss、10年分の例、単位は万円）を書き出します。

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures がバイト単位で一致した（DuckDB は `SET threads=1`）
- 10年分の例の μ̂・σ̂・2つの99.5%点が、Python と DuckDB の SQL（`02_quantile_duckdb.sql`）で一致した。t 分布の99.5%点は SQL では計算できないので、Python で計算して表 `params` で渡した
- T-SQL 版（`01_quantile_tsql.sql`）は書いたが、SQL Server では動かしていない（**未検証**）

## 前提
- 年間の総損害は、毎年同じ対数正規分布から独立に出る（傾向・インフレ・年どうしのつながりはない）
- 分布の形（対数正規）は正しいとした。形を間違える誤差は扱っていない（分布の仮定の話は F260、件数の揺れの話は 597）
- ベイズの予測分布は、平均と対数の分散に無情報の事前分布（p(μ, σ) ∝ 1/σ）を置いたもの

## 注意（言えないこと）
- 架空のデータ。実際の会社の損害ではない
- ブートストラップの結果は、作り直しの回数（2,000通り）と方法で少し変わる
- 必要な資本・ソルベンシー・保険料・責任準備金の判断の助言ではない
