# 566 死亡率が下がり続けると、その年の生命表の平均余命は、実際に生きる年数よりどれだけ短く出るのか（保険数理・架空の死亡率）

ある年の「平均余命」は、ふつうその年の各年齢の死亡率だけで計算します（期間生命表）。けれども、いま0歳の人が80歳になるのは80年後で、そのときの死亡率は今より下がっているかもしれません。実際に生きる年の死亡率で計算する（コーホート生命表）と、平均余命は長くなります。**ここでは、Gompertz–Makeham 型の架空の死亡率（改善なしで0歳の平均余命83.9年）を置き、死亡率が毎年一定の割合で下がる場合に、2つの表の平均余命がどれだけ違うかを計算しました。** 数字は置いた死亡率と改善の速さで決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A566 | 死亡率が毎年下がるとき、期間生命表とコーホート生命表の平均余命はどれだけ違うか | 架空の死亡率 μ(x)=0.0002+0.000012×1.105^x（2025年）。全年齢の死亡率が毎年 r（0〜3%）ずつ下がると置き、2025年に0・40・65・85歳の人の平均余命を、2025年の死亡率だけで計算（期間）と、その人が x+k 歳になる 2025+k 年の死亡率で計算（コーホート）。改善率が20年・50年で直線的に0まで下がる場合も比べた。120歳で全員亡くなるとした。期間生命表の計算は DuckDB（1スレッド）の SQL でも行い Python と一致を確認 | `src/a566_life_table.py`、`src/a566_life_table.sql`、`src/a566_life_table_tsql.sql` |

## 主な結果
- **改善がないとき**は2つは同じ：0歳83.9年、65歳22.0年
- **毎年1%下がると**：コーホートの平均余命は 0歳 92.7年（期間より **+8.8年**）、40歳 +4.0年、65歳 23.6年（**+1.5年**）、85歳 +0.4年
- **毎年1.5%**：0歳 +14.0年、65歳 +2.4年。**毎年2%**：0歳 +19.3年、65歳 +3.4年
- **差は若いほど大きい**：先の年の死亡率まで使う期間が長いため
- **改善が止まっていく場合**（年1.5%から直線で0へ）：50年で止まると 0歳 +4.1年・65歳 +1.8年、20年で止まると 0歳 +1.7年・65歳 +1.1年。差の大きさは、将来の改善をどう置くかでほとんど決まる
- **期間の平均余命は毎年伸びていく**（毎年1.5%の改善で、2025年の65歳 22.0年→2050年 25.4年）。2025年の65歳のコーホートの値（24.5年）は、期間の値でいうと2040〜2045年の間（24.0〜24.7年）にあたる

## 確かめたこと
- 空のフォルダで流し直し、results がすべて一致した
- 改善1.5%の2025年の期間生命表で、0歳と65歳の平均余命が Python と DuckDB の SQL で一致すること（T-SQL 版は SQL Server では動かしていない：**未検証**）

## データ
- データファイルは置いていない。死亡率はコードの中の式で作る（乱数は使っていない）

## 注意（言えないこと）
- 架空の死亡率。実際の生命表や、実際の死亡率の改善の見通しではない
- 改善は全年齢で同じ率と置いた。実際には年齢によって改善の速さは違う
- 120歳で全員亡くなるとした。改善が1.5%以上だと120歳まで生きる人が数%残るので、コーホートの値は少し小さめに出る（推測）
- 期間とコーホートのどちらが「正しい」かではなく、何を知りたいかで使い分ける。保険料や責任準備金の計算への使い方の助言ではない
