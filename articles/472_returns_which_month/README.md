# 472 返品を売れた月に戻すか、返ってきた月で引くかで、月次の売上はどれだけ変わるのか（実務の型）

架空の注文と返品（27か月分）で、返品を①元の売上の月に戻して引く、②返ってきた月の売上から引く、の2通りで月次の純売上を出し、差を測ったフォルダです。①では、締めたあとに過去の月の数字が動きます。その大きさも測りました。集計の置き方の比べであり、会計や税務の処理としてどちらが正しいかは扱っていません。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A472 | 返品を置く月で、月次の純売上・前月比・前年比はどれだけ違うか。①は締めたあと何日でどこまで固まるか。返品率と返るまでの日数でどう変わるか | 架空の注文438,899件・返品38,932件を2通りに集計／締めの日を動かして①を出し直す／返品率と日数を変えて流し直す。SQL は DuckDB で実行し、pandas の値と一致を確かめる | `src/a472_returns.py`、`src/01_returns_tsql.sql`（T-SQL 版、未検証） |

## 主な結果
基本の場面：返品率8.9%（件数・金額とも）。セールの期間（7月と12月の後半）は返品率が1.8倍。売れてから返るまでの日数は中央値10日、9割が24日以内。返品の44%は翌月以降に返ってくる

- **月ごとの差**（②を①と比べる）：差の大きさの平均1.77%、最大+4.5%（2025年7月）、最小−5.6%（2025年8月）。セールの月は②が+3.9〜+4.5%高く、その翌月は−5.1〜−5.6%低い
- **前月比**（セールの翌月）：①−19〜−21%、②−26〜−28%、返品を引かない売上は−23%
- **前年比**：差は平均0.37pt、最大0.70pt。2025年の年間合計の差は−0.006%
- 返品を引かない売上は、純売上より平均9.5%大きい
- **①は締めたあとに動く**：月末の時点の数字は確定値より平均+4.0%（最大7.3%）大きい。5日後で+2.5%（最大4.6%）、10日後で+1.4%、20日後で+0.4%、31日後で+0.08%。確定は92日後
- 月末から5日後に締めると、締めるたびに過去の2か月が動き、動く額は平均285万円（1か月の売上の2.7%。セールのあとは5.3〜5.5%）
- **返品率と日数**（差の大きさの平均、日数5日→40日）：返品率2%で0.33〜0.65%、8%で1.2〜2.4%、20%で3.4〜6.9%。最大の月は21%まで。セールがなければ平均0.29%、最大0.75%

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した
- SQL（DuckDB）で出した①②の月次が、pandas で出した値と27か月すべて一致する（コード内の assert）

## データ
- `data/sales_sample.csv`、`data/returns_sample.csv`：架空の注文と返品の一部（全体はコードで作り直す。seed 472）

## 注意（言えないこと）
- 架空のデータ。差の大きさは、返品率、返るまでの日数、セールの置き方で決まる
- 会計や税務の処理としてどちらが正しいかは扱っていない。ここで比べたのは、分析用の月次の表でどちらの月に置くかだけ
- 返品は全額の返品だけ。一部の返品、交換、返金の時期のずれは扱っていない
- T-SQL 版は SQL Server 本体では動かしていない（未検証）。SQL は DuckDB で実行した
