# F100 同じ問いを5つの手法で分析すると、答えはそろうのか？

看板記事 F100。「保育所に通う子どもが多い（増えた）市区町村ほど、出生率は高い（上がった）か」という1つの問いを、**回帰・固定効果・マッチング・ダブル機械学習（DML）・空間回帰** の5つの手法で推定し、答えがどれだけそろうか、そろわないなら何が答えを分けたかを調べました。データはすべてこれまでの記事（F16・F20）で取得したものを使い回しています。

## 問い

- **問い1（主）**：保育所等に通う子ども（0〜5歳100人あたり）が多い・増えた市区町村ほど、合計特殊出生率は高い・上がったか
- **問い2（確認）**：同じく、女性の労働力率は高い・上がったか（F16 と同じ問い）

それぞれを2つの比べ方（設計）で見ます。

| 比べ方 | 処置 | 結果 | 地域の条件 |
|---|---|---|---|
| **水準の比較** | 2015年の在所児（100人あたり） | 問い1：2018〜22年の出生率／問い2：2015年の労働力率 | 2010年の地域の性格23列 |
| **変化の比較** | 2010→15年の在所児の変化 | 問い1：出生率の変化（2013〜17年→2018〜22年）／問い2：労働力率の変化（2010→15年） | 上の23列＋もとの出生率・在所児・労働力率、前の5年の変化、同じ期間の年齢構成の変化 |

効果の単位はすべて「在所児が0〜5歳100人あたり **10人** 多い（増えた）とき、結果がどれだけ違うか」。

## データ

- e-Stat「社会・人口統計体系 市区町村データ」（総務省統計局、F16 で2026年10月26日に取得）
- 厚生労働省「人口動態保健所・市区町村別統計」の合計特殊出生率（ベイズ推定値、2013〜17年・2018〜22年。F20 で取得）
- 境界：国土数値情報 行政区域 2021 の簡略版 TopoJSON（F20 と同じ）。政令市の区は市にまとめ、境界を共有する区域を「隣」とした。島などで隣がない24区域は、いちばん近い1区域を隣とした
- 単位：市区町村（政令市は市全体、東京23区は区ごと）。0〜5歳が100人以上で値がそろう **1,606〜1,611** 区域（福島の出生率が「…」の町村などを除く）

## 手法

| 手法 | 何をそろえて比べるか | 実装 |
|---|---|---|
| 回帰 | 地域の条件を直線で入れる（重回帰、頑健な標準誤差） | statsmodels |
| 固定効果 | 2期間の市区町村固定効果（＝変化どうしの回帰）。変わらない地域の性格は差で消え、期間中に変わる条件（年齢構成・人口増減）と県ごとの傾向だけを入れる。標準誤差は県でクラスタ。**変化の比較だけ** | statsmodels |
| マッチング | 在所児が上位3分の1の区域と下位3分の1の区域を、傾向スコア（ロジスティック回帰）が近い組で比べる（最近傍1対1・復元あり・キャリパー0.2SD）。差を在所児の差で割って単位をそろえる。区間はブートストラップ200回 | scikit-learn |
| DML | 結果と処置をそれぞれ地域の条件から機械学習で予測し、外れどうしを回帰（部分線形モデル、5分割の交差適合×3回）。学習器はランダムフォレスト・LightGBM・Lasso | DoubleML |
| 空間回帰 | 空間誤差モデル（誤差が隣と似る）と空間ラグモデル（結果が隣と似る、直接効果）を最尤法で推定 | spreg・libpysal |

すべての手法で同じ地域の条件と、同じ県ダミー（46列）を使う。そのうえで「県ダミーを入れるか」「人口1万人以上だけにするか」を変え、問いごとに60通り（固定効果は変化の比較だけなので 2×2×(7+8)）を推定した。

## 主な結果（問い1：保育所と出生率）

県ダミーあり・全体の推定値（出生率の差、在所児+10人あたり、95%区間）

| 手法 | 水準の比較 | 変化の比較 |
|---|---|---|
| （参考）条件なしの単純な回帰 | **+0.015**（+0.011〜+0.020） | −0.001（−0.006〜+0.003） |
| 回帰 | −0.009（−0.013〜−0.005） | −0.004（−0.008〜−0.001） |
| 固定効果 | — | +0.001（−0.003〜+0.005） |
| マッチング | −0.016（−0.038〜+0.006） | −0.000（−0.010〜+0.009） |
| DML（RF） | −0.003（−0.009〜+0.002） | −0.001（−0.005〜+0.003） |
| DML（LightGBM） | −0.004（−0.009〜+0.001） | −0.001（−0.005〜+0.003） |
| DML（Lasso） | −0.007（−0.010〜−0.003） | −0.003（−0.007〜+0.001） |
| 空間誤差モデル | −0.009（−0.012〜−0.005） | −0.004（−0.008〜−0.001） |
| 空間ラグモデル（直接効果） | −0.009（−0.013〜−0.005） | −0.004（−0.008〜−0.001） |

- **単純に並べると「在所児が多い町ほど出生率が高い」**（相関 +0.15）。ところが地域の条件を足していくと、水準の比較の係数は +0.015 → +0.001（財政・学歴・雇用まで）→ **−0.009（県ダミーを足す）** と向きが変わった。変化の比較は、条件を足しても −0.001 → −0.004 とほぼ0のまま
- 同じ比べ方の中では、5つの手法の答えは **おおむねそろった**。水準の比較はすべての手法でマイナス（−0.003〜−0.016）、変化の比較はすべて −0.004〜+0.001 の0の近く
- 60通りのばらつきのうち、「比べ方（水準か変化か）」だけで説明できるのは **31%**、「手法」だけでは **13%**、「県ダミーを入れるか」は 9%、「比べ方×県の扱い」で **46%**。答えを動かしたのは、手法よりも **何と何を比べるか** だった
- 大きさで見ると、どの推定も小さい。いちばん大きい −0.016 でも、在所児が+10人で出生率（平均1.42）が約1%違う程度。変化の比較の区間（およそ ±0.005）は、出生率の変化のばらつき（標準偏差0.087）に比べて小さく、「保育所が増えた町で、5年後の出生率がはっきり上がった」形跡はこのデータでは見えない
- マッチングは区間が広い。特に水準の比較では、在所児が多い町と少ない町の性格が大きく違い、マッチング後も条件の差（標準化平均差の平均）が 0.34 → 0.17 までしか縮まらなかった（変化の比較は 0.10 → 0.07）
- 空間回帰：県ダミーを入れたあとの空間の偏りは小さく（水準 λ=0.17、変化 λ=−0.07）、係数は回帰とほぼ同じ。F20 で見た「隣と似る」の多くは、県の違いで説明できる

## 問い2（保育所と女性の労働力率）

- どの手法・比べ方でもプラス（52通り中52通り、マッチングを含む60通りでも60通り）。手法による違いは小さい
- 大きさは比べ方で約3倍違う：水準の比較 +0.14〜+0.19ポイント（マッチングを除く）、変化の比較 +0.04〜+0.06ポイント。変化の比較の DML（RF）は +0.063 で、F16 の +0.061 とほぼ同じ（同じデータを作り直して再現できた）
- ばらつきのうち「比べ方」で説明できるのは 62%、「手法」は 6%（マッチングを除く52通り）

## 頑健性（問い1）

| 確かめたこと | 水準の比較 | 変化の比較 |
|---|---|---|
| DML（RF）を乱数を変えて10回 | −0.003（−0.009〜+0.002） | −0.002（−0.006〜+0.003） |
| マッチング 1対3 ／ キャリパーなし | −0.010 ／ −0.016（どちらも0をまたぐ） | −0.000 ／ −0.001（0をまたぐ） |
| 空間誤差モデルの隣を「近い6区域」に | −0.009（−0.012〜−0.005） | −0.004（−0.008〜−0.001） |
| 政令市・東京23区を除く（回帰／マッチング／DML／空間／固定効果） | −0.009／−0.018／−0.004／−0.009／— | −0.005／−0.003／−0.001／−0.004／+0.001 |
| 処置を「保育所等の数（0〜5歳千人あたり）」に（1SDあたり） | −0.010〜−0.053（すべてマイナス） | −0.003〜+0.003（すべて0をまたぐ） |
| 人口1万人以上だけ（60通りに含む、県ダミーあり） | −0.002〜−0.013（すべてマイナス） | −0.000〜+0.007 |

県ダミーを入れた推定では、向きと大きさの関係（水準はマイナス、変化はほぼ0）は、どの確かめ方でも同じだった。県ダミーを入れない場合は、水準の比較の向きが手法によってプラスにもマイナスにもなる（−0.011〜+0.013）。

## 言えないこと

- **どの比べ方が「正しい」かは、このデータでは決められない**。水準の比較は、地域の性格のうち条件に入れていない部分（働き方の慣行、住宅事情など）が混ざる。変化の比較は、それを消せる代わりに、5年という短い期間と、2015年までの変化しか見ていない。効果が現れるまでにもっと時間がかかる可能性もある（推測）
- 水準の比較で、県ダミーを入れると「在所児が多い町ほど出生率がわずかに低い」になるのは、同じ県の中では、共働きが多く出生率の低い町（都市部など）で保育所の利用が多いためと考えられる（推測）。保育所が出生率を下げるという意味ではない
- 出生率は市区町村の「ベイズ推定値」で、小さい町では二次医療圏などの値に引き寄せられている。小さい町の差は実際より小さく見えている可能性がある
- 処置は在所児の数（利用）で、保育所の定員や待機児童ではない。利用は需要にも左右される
- 個人や世帯の出産の決め方は分からない。市区町村の集計どうしの関係を見ている
- 5つの手法はどれも「地域の条件で説明できない違いはない」（または変化で消える）という仮定に頼っている。手法の答えがそろっても、その仮定が崩れていれば、そろって偏る

## 動かし方

```
pip install -r requirements.txt
cd src
python 02_整形.py            # data/raw → data/panel_long.csv・q1_*.csv・q2_*.csv・adjacency.csv
python 03_分析.py            # results/（2コアで約25分。途中の結果は results/_cache.json に残る）

```
