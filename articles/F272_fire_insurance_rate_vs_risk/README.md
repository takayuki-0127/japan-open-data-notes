# F272 火災保険料の地域差は、リスクの差にどこまで見合っているか？（保険数理・リスク、精選モード）

住宅の火災保険の保険料は都道府県によって違います。その違いは、実際に払われた保険金の違い（＝リスクの違い）にどこまで見合っているのかを、損害保険料率算出機構の公表統計で確かめました。
個人の保険の選び方や、料率の制度の良し悪しは扱っていません。都道府県を「悪い順」に並べることもしていません（図にも名前は出していません）。

- 計画（事前登録）：[PLAN.md](PLAN.md)（コミット 8dc232b。都道府県別の値を集計する前に書いた）
- note の記事：下書き（公開後にリンクを追加）

## 結論

1. **料率の差は、保険金の差の一部しか映していない**（ここでの「料率」は保険金額あたりの保険料で、構造・保険期間・水災補償・免責など契約の中身を含む）：2017〜2024年度の合計で、保険金額あたりの保険料は都道府県の間で最大2.3倍、保険金額あたりの支払保険金は5.4倍違う。対数で回帰すると傾きは 0.20（95%区間 0.08〜0.32）で、保険金が2倍の地域でも保険料は約15%高いだけ（H2 支持）。順位相関は 0.36（H1 の基準 0.5 に届かず外れ）
2. **長期の損害率は地域で大きく違う**：支払保険金 ÷ 新契約の保険料は、真ん中半分で 55〜91%、両端で 32%〜153%（全国 79%）
3. **その差は「いちばん大きな1年」だけでは説明できない**：各都道府県で支払がいちばん大きかった年度を除いても、損害率の散らばり（対数の標準偏差）は 0.36 → 0.31 と15%しか小さくならない（H3 外れ）。2018・2019年度をすべての都道府県で除いても 0.36 のまま
4. **前に損害率が高かった地域ほど料率が上がった、とは言えない**：2017〜19年度の損害率と、料率の全国比の変化（2017〜19→2022〜24年度）の順位相関は 0.13（H4 外れ）。ただしこの「料率」には保険期間の構成が入り、比べた期間は2022年10月の長期契約の見直し（最長10年→5年）をまたぐので、料率の改定への反応を直接測ったものではない。見直し前で終わる窓（2017〜19→2020〜21、→2020〜22年度）でも −0.02、0.02
5. **問い直し：8年の実績は、リスクのものさしとしては大きく揺れる**：8年を4年ずつに分けて保険金の水準を比べると相関は 0.29（35通りの中央値、0.16〜0.45）。8年分の「信頼性」は 0.46 の目安で、この揺れを補正すると、対数のピアソン相関は 0.46 → 0.68、傾きは 0.20 → 0.44（折半の幅で 0.32〜0.71、都道府県の再標本化300回の95%区間 0.19〜1.14 で1を含む、逆回帰による上限 0.95、2018・19年度を除く6年で補正すると 0.35）。信頼性 0.8 に届くには数十年（折半の幅で約19〜81年）が要る計算。いずれも年ごとの保険金が独立で同じ大きさの揺れを持つという前提の目安で、2年を除くと信頼性が 0.46 → 0.79 に変わるので、この前提は成り立っていない

## データ

損害保険料率算出機構「火災保険・地震保険の概況」2015〜2025年度版（Excel、2026-11-11 取得）の第2表「火災保険 住宅物件都道府県別統計表」。
- 新契約の件数・保険金額（百万円）・保険料（千円）と、支払の件数・保険金（千円）。47都道府県＋分類不能＋合計。都道府県と分類不能の和は合計と一致（02 で確かめた）
- k_YYYY.xlsx は YYYY 年度版で、中身は YYYY−1 年度の統計
- **2015〜2017年度版（2014〜2016年度）は1年契約だけの集計**、2018年度版（2017年度）からは全契約の集計。このため主な分析は 2017〜2024年度（8年）にした（計画からのずれ）
- 「支払保険金が僅少の場合 X」と注記がある年もあるが、住宅物件の都道府県別では X はなかった
- 2024年度版（2023年度の統計）からは「保険金には付帯費用を含みます」と注記されている
- 保険料は「異動・解約にかかる保険料を加減していません」と注記されている（総額）
- 支払はその年度に払った保険金なので、1つの台風の保険金が2つの年度にまたがることがある

## 手法

都道府県 p ごとに、2017〜2024年度の合計で次の3つを出した。
- 料率の水準 R ＝ Σ保険料 ÷ Σ保険金額（保険金額1,000円あたりの保険料）
- 保険金の水準 C ＝ Σ支払保険金 ÷ Σ新契約の保険金額（同じ分母で、保険金額あたりの支払）
- 長期の損害率 L ＝ Σ支払保険金 ÷ Σ保険料 ＝ C ÷ R

新契約の保険料には長期契約（最長10年、2022年10月からは5年）の一括払いが入り、支払は保有契約全体からの支払なので、単年では分子と分母の対象がずれる。8年の合計でならしている。L は会計上の損害率とは違う。

- H1：R と C の順位相関（スピアマン）
- H2：log R を log C に回帰した傾き（47都道府県、重みなし。t分布の95%区間と、都道府県の再標本化4,000回の区間）
- H3：都道府県ごとに支払保険金が最大の年度を1つ除き、log L の標準偏差の減り方
- H4：2017〜19年度の L と、料率の全国比の変化（2017〜19年度平均 → 2022〜24年度平均の対数差）の順位相関
- 問い直し：8年を4年ずつに分ける35通りで、前半と後半の log C の相関（中央値）を求め、スピアマン・ブラウンの式で8年分の信頼性を出した。相関の補正は r ÷ √(信頼性C × 信頼性R)、傾きの補正は b ÷ 信頼性C

## 結果

| 仮説 | 基準 | 結果 | 判定 |
|---|---|---|---|
| H1 | 順位相関 ≥ 0.5 | 0.36（p=0.014） | 外れ |
| H2 | 0 < 傾き、95%区間の上限 < 1 | 0.20（0.08〜0.32、再標本化 0.08〜0.32） | 支持 |
| H3 | 最大の1年を除いて散らばりが1/3以上減る | 0.364 → 0.310（−15%） | 外れ |
| H4 | 順位相関 ≥ 0.3 | 0.13（p=0.37） | 外れ |

- 料率の水準 R：1,000円あたり 1.86〜4.30円（中央値 2.59円）。保険金の水準 C：0.74〜4.00円（中央値 1.90円）
- 全国の支払保険金（住宅）は 2018年度 7,320億円・2019年度 6,611億円が突出し、ほかの年は 2,048〜3,910億円。都道府県の「いちばん大きかった年度」は2018年度が16、2019年度が9
- 単年の損害率の散らばり（log L の標準偏差）は 0.46〜0.83 で、8年の合計（0.36）より大きい
- H4 の機械的な相関を避ける確かめ：前半の保険金の水準を後半の料率で割った損害率で見ると 0.00、前半の保険金の水準だけで見ると 0.18
- 料率の全国比の変化は −15.7%〜+16.4%（全国の水準は対数で +0.061）

## 頑健性

| 条件 | 順位相関 | 傾き（95%区間） | 最大÷最小 R / C |
|---|---|---|---|
| 基本 | 0.36 | 0.20（0.08〜0.32） | 2.31 / 5.38 |
| 1件あたりで測る | 0.35 | 0.15（0.05〜0.26） | 1.79 / 5.59 |
| 前半 2017〜20年度 | 0.07 | 0.05（−0.05〜0.16、0を含む） | 2.37 / 8.69 |
| 後半 2021〜24年度 | 0.58 | 0.23（0.14〜0.32） | 2.22 / 7.71 |
| 2018・2019年度を除く | 0.61 | 0.27（0.19〜0.36） | 2.26 / 6.47 |
| 保険料で重みづけ（傾きのみ） | 0.36 | 0.23（0.11〜0.36、再標本化 −0.00〜0.45 で0を含む） | 2.31 / 5.38 |
| 1年契約だけ 2014〜16年度 | 0.59 | 0.16（0.08〜0.24） | 2.20 / 14.71 |

- 傾きは、どの条件でも 1 よりはっきり小さい（0.05〜0.27）。H2 の結論は変わらない
- 順位相関は、大きな台風の年を含むかどうかで 0.07〜0.61 と大きく動く。H1 の判定は期間しだい

## 計画からのずれ

- 計画では 2014〜2024年度の11年を使うつもりだったが、2014〜2016年度は1年契約だけの集計と分かったので、主な期間を2017〜2024年度の8年にした。2014〜2016年度は頑健性（1年契約だけ）に回した
- H4 の期間も合わせて、「2014〜2018年度の損害率、2014〜16→2022〜24年度の料率の変化」から「2017〜19年度の損害率、2017〜19→2022〜24年度の料率の変化」に変えた
- 計画の頑健性3（全国の上位2年度を除く）は、結果として2018・2019年度になった
- 表の形を確かめる途中で、各版の合計行（全国の値）を目で見ている
- 頑健性2（期間を分ける）は、計画の「前半2014〜18年度・後半2019〜24年度」ではなく、2017〜20年度と2021〜24年度で行った
- H4 の機械的な相関を避ける確かめ（C ÷ 後半の R、C だけ）と、問い直し（信頼性の計算）は結果を見てから足した
- 独立レビューを受けて、補正した傾きの幅（折半の幅・再標本化・逆回帰・6年分）、見直し前で終わる窓での H4、比で表した料率の変化を結果のあとに計算した（03 の末尾、main.json の review）

## 言えないこと

- R は保険料 ÷ 保険金額で、料率表そのもの（参考純率）ではない。都道府県によって、建物の構造（木造・非木造など）、保険期間（1年〜10年）、補償の付け方（とくに水災補償を付けるかどうか）、割引の構成が違い、それも R と C の両方に入っている。今回のデータではこれらを分けられない
- C は実際に払われた保険金で、リスクの「実績」。料率は長い期間の災害の見込み（台風などのシミュレーションを含む）で決まるので、8年の実績と合わなくても、料率が間違っているとは言えない
- L は「支払 ÷ 新契約の保険料」で、会計上の損害率（既経過保険料あたり）とは違う。長期契約の多い地域ほど分母が大きく出る可能性がある（推測）
- 全国の料率の水準は、1年契約だけの2014〜16年度で 1.37〜1.41円、全契約の2017年度で 2.33円、2022年度 2.74円から2023年度 2.36円と、保険期間の構成で大きく動く。H4 の料率の変化にもこれが入る
- 支払は年度ごとの支払いの集計で、1つの台風の保険金が2つの年度にまたがることがある。H3（最大の1年を除く）の確かめはその分弱い（推測）
- 保険料は異動・解約を加減していない総額。2023年度の統計からは保険金に付帯費用を含む
- 信頼性の計算は、年ごとの保険金が互いに独立で、同じ大きさの揺れを持つという前提の目安。2018・2019年度を除くと信頼性が 0.46 → 0.79 に変わることから、この前提は成り立っておらず、補正した値の幅は大きい（再標本化の95%区間は1を含む）
- 都道府県の単位の集計で、市区町村や地点ごとのリスクの違いは見ていない
- 個人の保険の選び方、料率の制度・水準の良し悪しは扱っていない

## レビューで直したこと

別のエージェントによる独立レビュー（抽出133行×5列の照合で不一致0、数字の再計算と再実行で一致）の指摘を受けて、次を直した。
1. 【高】補正した傾き 0.44 に幅を付けた（折半の幅 0.32〜0.71、再標本化 0.19〜1.14、逆回帰の上限 0.95、6年分で 0.35）。「補正しても1より小さいことは変わらない」を削除し、「約38年」を「数十年（約19〜81年）」に、タイトルの「2倍ほど強まる」を「強まるが、幅は大きい」に弱めた
2. 【高】H4 の料率に保険期間の構成が入り、比べた期間が2022年10月の見直しをまたぐことを書き、見直し前で終わる窓（−0.02、0.02）を足した
3. 【中】「料率」の定義を最初に書き、「料率の差は保険金の差の2割しか映していない」（弾力性の読み違い）を「保険金が2倍でも保険料は約15%高い」に直した
4. 【中】「見え方の半分ほどは揺れから」を「観測された傾きは揺れで小さく出ている可能性がある（推測、幅は大きい）」に直した
5. 【中】0.46 → 0.68 が対数のピアソン相関であることを明記した
6. 【中】支払が年度で分かれ、1つの台風が2年度にまたがりうること、それが H3 の確かめを弱めること（推測）を書いた
7. 【低】料率の変化を比で −15.7%〜+16.4% と書いた
8. 【低】重みづけの傾きの再標本化の区間（−0.00〜0.45）と、前半の区間が0を含むことを書いた
9. 【低】付帯費用の注記は2024年度版（2023年度の統計）からと直し、保険料が異動・解約を加減していない総額であることを書いた
10. 【低】頑健性2の期間が計画と違うことをずれに書いた
11. 【低】図2（fig1）の点の大きさをそろえ、保険料の大きさで都道府県が分からないようにした
