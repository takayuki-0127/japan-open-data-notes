# 1144 上限を超えて切れた部分の割合は、大きさの数字にどう表れるのか？（音の大きさ）

音の波は、上限（振れ幅1.0、0 dB）を超えられません。音量を上げすぎると、超えた分は上限で平らに切れます（クリップ）。切れた部分がどれだけあるかは、曲の大きさの数字やいちばん大きい点の値を見れば分かりそうですが、そうとは限りません。**ここでは、作成者が式と乱数で作った架空の曲（30秒。音のもとは雑音に近い音・音程のはっきりした音・打つ音の多い音の3種類）を、いちばん大きい点がちょうど上限になる状態から音量を上げて切り、切れた点の割合が、大きさ・いちばん大きい点・その差・切れて変わった分の強さにどう表れるかを数えました。架空の200曲で大きさの数字から切れた割合が読めるか、あとから音量を少し下げたり保存したりした曲で切れた点を数えられるかも確かめ、置き方を変えた27通りでも数えました。**

この記事の「大きさ」は、波の値の二乗（強さ）の平均を 10×log10 で dB にした値です（上限いっぱいを0 dB、音の高さによる重みはなし）。人が聞いて感じる大きさとは一致しません。

いちばん大きい点と平均の強さの差が曲ごとに違うことは同じ企画の 1139、超えそうな瞬間だけ音量を下げて大きくする処理は同じ企画の 1140 で扱っています。この記事は、下げずに上限で切ったとき、切れた分が数字にどう表れるかに絞ります。上限で切れて記録に残らない分は、時間切れで打ち切った処理を除く 1064 と同じ形のしくみです。同じ企画の 1148「「3dB 上げる」は、音の強さで見るか波の振れ幅で見るかで、何倍の変化になるのか？」は、3dB 上げて上限で切れたとき、いちばん大きい瞬間の比と強さの比が別々に動くことを、3dB の読み方に絞って数えています。この記事は、切れた点の割合そのものが数字にどう表れ、どう数えられるかを扱います。1145「録音全体の音量を上げると、声と雑音の差は広がるのか？」は、切れて声と雑音の差が縮んでも、録音からの見積もりにはほとんど表れないことを数えています。

## 主な結果

### 切れた点の割合ごとの数字（強弱 ±3 dB、`results/by_clipped_share.csv`）
| 音のもと | 切れた点 | 上げた量 | 大きさの増え | 上げた分より小さくなった量 | いちばん大きい点と大きさの差（上げる前） | 切れて変わった分（大きさとの比） |
|---|---|---|---|---|---|---|
| 雑音に近い音 | 0.1% | 2.38 dB | 2.37 dB | 0.009 dB | 10.9 dB（13.27 dB） | −39.4 dB |
| 雑音に近い音 | **1%** | 4.73 dB | 4.63 dB | **0.096 dB** | 8.64 dB（13.27 dB） | −26.2 dB |
| 雑音に近い音 | 10% | 8.95 dB | 8.04 dB | 0.911 dB | 5.23 dB（13.27 dB） | −13.3 dB |
| 音程のはっきりした音 | 1% | 2.78 dB | 2.75 dB | 0.037 dB | 7.7 dB（10.45 dB） | −33.2 dB |
| 打つ音の多い音 | 1% | 10.34 dB | 9.44 dB | 0.899 dB | 13.93 dB（23.37 dB） | −12.3 dB |

- **雑音に近い音で1%の点が切れても、大きさの数字は上げた分より0.096 dB 小さくなっただけだった**。10%切れても0.911 dB だった。大きさの数字はほぼ上げた分だけ増え、切れたことはほとんど表れない
- 強弱のない雑音なら、上げた分より小さくなる量は式どおり（1%で式0.0826 dB に対し0.0818 dB、0.1〜10%の4つで差0.0084 dB 以内、`results/formula_check.csv`）
- **いちばん大きい点は、切れても切れなくても0 dB のまま**だった（上限で切るので作りどおり）。切れた点の割合は、いちばん大きい点の値には出ない
- 減ったのは「いちばん大きい点と大きさの差」で、切れた量の手がかりになった。ただしこの差は上げた量（大きさの増え）だけ縮むので、もとの差が分からないと、切れたのか、もとから差の小さい音なのかは分からない。もとの差は音のもとで10.45〜23.37 dB と違った
- 打つ音の多い音は、もとの差が大きいので1%切れるまでに10.34 dB 上がり、そのぶん上げた分より0.899 dB 小さくなり、切れて変わった分も −12.3 dB と大きかった

### 200曲で、大きさの数字から切れた割合が読めるか（`data/songs.csv`、`results/songs_corr_by_material.csv`）
- 大きさが −12〜−11 dB の11曲で、切れた点の割合は **0.1996〜10.2646%** と大きく違った（いちばん大きい点と大きさの差は5.11〜11.058 dB）
- 切れた割合との相関係数（−1〜1。1に近いほど一緒に動く）は、大きさで0.59、いちばん大きい点と大きさの差で −0.615 だった。音のもとを分けると、差では −0.796〜−0.889、大きさでは0.693〜0.757 で、差のほうがよく表した。音のもとが混ざると、どちらも弱くなった

### あとから処理した曲で、切れた点を数えられるか（1%切れた雑音に近い音、`results/detect_after_processing.csv`）
| 処理 | ①上限ちょうどの点 | ②いちばん大きい値の99.9%以上 | ③②の中で同じ値が3点以上続く点 |
|---|---|---|---|
| そのまま | 1.0% | 1.009% | 0.51% |
| 16ビットで保存 | 1.0% | 1.009% | 0.51% |
| 0.5 dB 下げて16ビットで保存 | **0.0%** | 1.009% | 0.51% |
| 0.5 dB 下げ、ごく小さな雑音を足して16ビットで保存 | **0.0%** | 1.008% | **0.054%** |

- 本当に切れた点は1.0%。**切ったあとに0.5 dB 下げるだけで、①上限ちょうどの点の数え方では0%になった**
- ③同じ値が続く点の数え方は、2点だけ切れた所を数えないので、そのままでも0.51%と半分に出た。ごく小さな雑音を足すと平らな部分がなくなり、0.054%に下がった
- ②いちばん大きい値の近くを数える方法は、4つの処理すべてで1.008〜1.009%と本当に近かった。切れていない曲では、どの数え方も0.0%だった

### 置き方を変えた27通り（`results/grid.csv`）
- 切れた点1%のとき、上げた分より小さくなった量は **0.013〜1.126 dB**、切れて変わった分は −39.7〜−10.6 dB だった。音のもとで大きく違い、打つ音の多い音で大きかった
- 1%切れるまでに上げた量は2.0〜11.77 dB だった
- 切れた点5%でも、上げた分より小さくなった量は0.086〜3.664 dB だった

## 注意（言えないこと）
- 架空のデータです。音のもとの形、強弱、上げる量は作成者が置いたもので、結果はこれで決まります。上げた分より小さくなる量は、強弱のない雑音なら式どおりで、新しく数えたのは、音のもとでの違い（27通りで0.013〜1.126 dB）、大きさの数字から切れた割合が読めないこと、あとから処理したときの数え方の違いです
- 切れた音が人にどう聞こえるかは数えていません。人が聞き比べる形の評価はしていません
- あとから処理したのは、音量を下げる・保存する・ごく小さな雑音を足すの3つだけです。音の高さで分けて強めたり弱めたりする処理や、1秒あたりの点の数を変える処理では、平らに切れた部分の形が崩れ、②の数え方でも数えにくくなると考えています（推測）。また、もとから大きい点の近くに値が集まる曲（超えそうな瞬間だけ下げて大きくした曲など）では、②は切れていない点も数えるかもしれません（推測）
- 実在の曲・機材・ソフトの数字を表すものではなく、音量をどこまで上げるべきかの助言でもありません
