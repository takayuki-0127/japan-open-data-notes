# F143 漁獲量の減り方は、魚の種類でどう違うのか？ — 時系列クラスタリングと変化点

## 問い
日本の海面漁業の漁獲量は、1984年の1,150万tから2024年には279万tまで減りました。この減り方は、魚の種類によってどう違うのか。すべての魚が同じように減ったのか、それともいくつかの「減り方の型」があるのか。減り方が変わった年（変化点）はいつか。

## データ
| データ | 内容 | 使い方 |
|---|---|---|
| 農林水産省「漁業・養殖業生産統計（海面漁業生産統計調査）長期累年」海面漁業魚種別漁獲量累年統計（全国） | 1956〜2024年、魚種別の漁獲量（t） | 主な分析 |
| 同 海面漁業種類別漁獲量累年統計（全国） | 1956〜2024年、漁業種類別の漁獲量（t） | 漁業種類で見た頑健性チェック |

- 対象は、1960〜2024年の65年がすべてそろい、期間中の最大が1万t以上の **42魚種** です（海産ほ乳類は除く）。「計」「小計」「その他の〜」は使っていません。
- 2007年に分類が変わった魚種（例：わかめ類、はまぐり類）は、途中で値がなくなるため対象外です。
- 漁獲量には遠洋漁業の分も含みます。養殖業は含みません。
- 漁業種類は、分類の変更をまたいで続く10種類（大中型まき網、沖合底びき網、小型底びき網、船びき網、定置網、さんま棒受網、まぐろはえ縄、かつお一本釣、いか釣、刺網）にまとめ、1975〜2024年を使いました。

## 手法
1. **形をそろえる**：各魚種の漁獲量を5年の中心移動平均にし、期間中の最大を1とした「形」にしました。量の大きさではなく、増え方・減り方の形だけを比べるためです。
2. **時系列クラスタリング**：形（65年分のベクトル）を k-means（初期値50回、シード0）で分けました。型の数は、解釈しやすい3〜6の中でシルエット係数が最大の4にしました。
3. **型の特徴**：最大の年、直近5年（2020〜2024年）の平均が最大の何%か、最後の区間の年あたりの変化率をまとめました。
4. **変化点**：各魚種の log(漁獲量) に区分線形（区間ごとに切片と傾き）を当てはめ、変化点の数（0〜3）と位置を BIC で選びました。区間は8年以上とし、動的計画法で厳密に探しました。漁獲量計にも同じ方法を使いました。
5. **型ごとの寄与**：漁獲量計が最大だった1984年から2024年までの減少量を、型ごとに足し上げました。

## 結果
### 1. 全体：1988年からの8年で大きく減り、そのあとも年2.4%ずつ減っている
- 漁獲量計は1984年の1,150万tが最大で、2024年は279万t（最大の24%）でした。
- 変化点は1968年、1988年、1996年でした。区間ごとの年あたりの変化は次のとおりです。
  - 1960〜1967年：+2.0%
  - 1968〜1987年：+1.6%
  - 1988〜1995年：−8.7%
  - 1996〜2024年：−2.4%

### 2. 減り方は4つの型に分かれた
| 型 | 魚種数 | 最大の年（中央値） | 直近5年は最大の（中央値） | 主な魚種 |
|---|---|---|---|---|
| A 早く大きく減った | 16 | 1968 | 7% | すけとうだら、さば類、かれい類、まあじ、いかなご類、にしん、ずわいがに など |
| B ゆるやかに減った | 17 | 1968 | 27% | するめいか、かたくちいわし、さんま、ほっけ、こんぶ類、まだら、たこ類 など |
| C 大きな波 | 1 | 1986 | 16% | まいわし |
| D 最大が遅く、まだ多い | 8 | 2000年ごろ | 58% | かつお、ほたてがい、さけ類、ぶり類、うるめいわし、しらす、さわら類、すずき類 |

- 42魚種のうち12魚種は、直近5年が最大の10%を下回りました。21魚種は25%を下回り、中央値は23%でした。
- 最後の区間の変化率は、42魚種中32魚種でマイナスでした（中央値は年−3.9%）。
- まいわしは1988年に449万tまで増えたあと、2000年代には最大の1〜2%まで減りました。最後の区間（2006年以降）は年+18.7%で増えています。
- 型 D の8魚種は、最大の年が1975〜2021年に分かれていて、2010年代に最大になったもの（うるめいわし、ぶり類、ほたてがい）を含みます。

### 3. 1984年からの減少の4割は、まいわし1種だった
1984年から2024年までの871万tの減少の内訳は、次のとおりでした。
- C まいわし：351万t（40%）
- A 早く大きく減った：272万t（31%）
- B ゆるやかに減った：99万t（11%）
- D 最大が遅く、まだ多い：8万t（1%）
- 分析の対象外の魚種など：141万t（16%）

### 4. 最初の変化点は1970年代に集まっていた
- 42魚種の最初の変化点は、1960年代9、1970年代22、1980年代5、1990年代6でした（中央値1973.5年）。
- 13魚種は、最後の変化点が2010年以降でした（さんま2012年、するめいか2016年、はたはた2017年、いかなご類2017年 など）。
  - この4魚種の最後の区間の変化率は、年−19%、−15%、−24%、−43%でした。

## 頑健性
| 条件 | 型の一致度（ARI、1＝同じ） |
|---|---|
| 型の数を3にする | 0.96 |
| 型の数を5にする | 0.82 |
| 型の数を6にする | 0.43 |
| Ward 法（階層クラスタリング） | 0.72 |
| 主要20魚種だけ（設計の代替案） | 0.83 |
| 移動平均をとらない | 0.62 |
| 年の8割をランダムに使って200回分け直す | 平均0.68（下位5%は0.45） |
| 期間を1970〜2024年にする | 0.48 |
| 期間を1960〜2000年にする | 0.25 |
| 期間を1990〜2024年にする | 0.15 |
| 最大を1にする代わりに、log をとって標準化する | 0.22 |

- 型の数・手法・魚種の絞り方を変えても、型の分かれ方はおおむね同じでした。
- **ただし、見る期間とそろえ方を変えると、型の分かれ方は大きく変わりました。** 型は「1960〜2024年の形を最大で割って比べたとき」の分け方で、魚種に固有の性質とは言えません。
- シルエット係数は型の数2〜7で0.20〜0.27と低く、型と型の境目ははっきりしていません。
- 変化点は、区間の最小を5年・10年に変えても、それぞれ96%・90%が±3年以内に残りました。
- **漁業種類で見た場合**（1975〜2024年、3つの型）：
  - 沿岸で保っている：小型底びき網（直近5年は最大の86%）、定置網（64%）、船びき網（53%）
  - 早く減った：大中型まき網、沖合底びき網、かつお一本釣、刺網（18〜23%）
  - 最大が遅く、そのあと急減：さんま棒受網（9%）、いか釣（6%）、まぐろはえ縄（30%）

## 言えないこと
- 漁獲量は「とった量」で、資源の量（海にいる魚の量）ではありません。漁獲量の減少には、資源の変動のほかに、漁業の規制、200海里水域の設定による遠洋漁業の縮小、漁船や漁業者の減少、需要の変化などが含まれ、このデータでは分けられません。
- 1960年が最大の年になっている魚種は、それより前にもっと多かった可能性があります。
- 型は形の似かたで分けたもので、見る期間やそろえ方で変わります。型の名前は、分けたあとに付けた説明です。
- 変化点は統計的に選んだ年で、その年に何が起きたか（原因）は示しません。
- 2007年の分類の変更で途中から値がない魚種は、対象から外れています。
