# PLAN — F265 少子化社会対策大綱の数値目標は、いまのペースで届くのか？

作成：2026-11-11（データを計算する前）。このファイルを GitHub に最初にコミットしてから分析を始める。

## 正直に書いておくこと（計画前に見てしまった数字）
- データを探す途中で、次の見出しの数字は目にしている：男性の育児休業取得率 令和7年度 50.9%、年次有給休暇取得率 令和7年調査 66.9%、女性（25〜44歳）の就業率 2024年 81.9%。
- 予測・逆算・判定の計算はまだ一度もしていない。方法・期間・判定の線はここで固定し、結果を見て変えない。変えたら README と記事に「計画からのずれ」として書く。

## 問い
少子化社会対策大綱（2020年5月）が置いた「2025年」の数値目標のうち、毎年のデータがある3つ（男性の育児休業取得率 30%、年次有給休暇取得率 70%、25〜44歳の女性の就業率 82%）について、
1. 目標を決めた時点のペースを延ばすと、届くと読めたのか。実際はどうだったか。
2. 目標のその後の版（男性育休 2030年 85%、有給 2028年 70%）に、いまのペースで届くのか。どれくらいの確かさで言えるのか。

## データ
- 男性（女性）の育児休業取得率：厚生労働省「雇用均等基本調査」事業所調査（令和7年度 結果概要 図4、平成8〜令和7年度）。年度＝調査年度。令和5年度から産後パパ育休を含む。
- 年次有給休暇取得率：JILPT「早わかり グラフでみる長期労働統計」図4（元は厚生労働省「就労条件総合調査」、1984〜2025年調査）。調査年の前年（または前会計年度）の値。2008年・2015年に対象の変更あり。
- 25〜44歳の女性の就業率：総務省「労働力調査」長期時系列 表3(3)・表3(1)（5歳階級の就業者数と人口、万人）から、就業者の合計÷人口の合計で計算（1968〜2025年）。
- 目標：こども家庭庁が掲載する「少子化社会対策大綱 施策に関する数値目標」（2020年大綱の目標・現状・前回大綱の目標）、厚生労働省「雇用環境・均等行政の主要指標の動向」（2025年9月）。

### 年のそろえ方（固定）
- 目標の「2025年」は、男性育休＝令和7年度調査、有給＝2025年1年間の値（2026年調査、未公表）、女性就業率＝2025年平均とする。大綱が「現状」に挙げた値（男性育休 6.16%＝2018年度、有給 52.4%＝2018年、女性 77.7%＝2019年）とこのそろえ方が一致することを確かめる。

## 方法（固定）
- 「ペース」の延ばし方は3つ：
  - M1：直近5時点の直線（最小二乗）
  - M2：直近5時点のロジット（割合を log(p/(1−p)) にしてから直線）。上限100%に近づくと伸びが鈍る形
  - M3：直近10時点の直線
- 予測の幅：同じ指標・同じ方法・同じ何年先で、過去のすべての起点から予測したときの外れ（実績−予測）の分布の10%点と90%点を、予測に足して80%の幅とする（経験的な幅）。外れが5個未満なら、3指標をまとめた外れを使う（この場合は記事に書く）。
- 「届く確率」：予測＋過去の外れ（同じ何年先）を全部足して、目標以上になる割合。
- 策定時点の情報：2020年5月の時点で公表済みの値まで（男性育休は2018年度まで、有給は2019年調査まで、女性就業率は2019年まで）。
- いまの情報：2026年11月時点の公表値まで（男性育休 2025年度、有給 2025年調査、女性就業率 2025年）。

## 仮説と「外れ」の基準
- H1：策定時のペース（M1）で延ばすと、2025年目標に届くと読めた指標は3つ中1つ以下。
  外れ：2つ以上が目標以上に読めた。
- H2：策定時のペース（M1）の2025年の予測と実績の差は、過去の同じ年数先の外れの80%の幅に、実績が分かる指標の過半で収まる。
  外れ：収まった指標が半分以下。
- H3：いまのペース（M1）で、男性育休 2030年 85% に届く確率は 50% 以上。
  外れ：50% 未満。
- H4：延ばし方（M1・M2・M3）を変えると、少なくとも1つの先の目標（男性育休 2030年 85%、有給 2028年 70%）で「届く／届かない」（予測の中心が目標以上か）が入れ替わる。
  外れ：3つの延ばし方で判定がすべて同じ。

## 頑健性（少なくとも3つ）
1. 窓の長さ：直線の窓を 3・5・7・10 時点に変える。
2. 段差の扱い：有給は 2015年以降だけ、男性育休は令和5年度（産後パパ育休を含む）以降の段差を除いた（2022年度までの）直線でも見る。
3. 女性就業率の作り方：自分で万人から計算した値と、厚生労働省の資料にある公表値（2024年まで）との差を確かめる。
4. 幅の作り方：外れを指標ごとにするか、3指標まとめるか。
5. 有給の目標年：2025年（2020年大綱）と 2028年（過労死防止大綱）の両方。

## 問いの立て直し（1回、結果を見てから決める）
最初の結果を見て、1つだけ追加の問いを立てる。候補：目標を決めたときに「それまでのペースの何倍」を求めていたか（必要な伸び÷過去5時点の伸び）と、届いたかどうかの関係を、2015年大綱（2020年目標）と2020年大綱（2025年目標）でそろえて見る。

## 書かないこと
- 政策の良し悪し・効果の評価はしない（「届くか」の算数だけ）。
- 都道府県や企業の順位はつけない。
