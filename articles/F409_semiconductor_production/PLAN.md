# F409 PLAN（事前の計画）：半導体の国内生産は、増えているのか？

作成：2026-11-18 08:10（元データを取得し、表の形を確かめたあと、年の平均・2019年との比・相関・品目別の分け方を計算する前に書いた）

## 問い
政府は半導体の工場の誘致に大きな補助金を出し、2023年の「半導体・デジタル産業戦略」では「2030年に国内で半導体を生産する企業の合計売上高を15兆円超（2020年は約5兆円）」という目標を掲げた。新しい工場が動き出したと報じられる一方で、「国内の生産はまだ増えていない」という声もある。そこで、経済産業省の鉱工業指数（工場の生産量の指数）で、集積回路（IC）と半導体製造装置の国内生産が、2019年（コロナの前）と比べて増えたのかを確かめる。あわせて、出荷・在庫の動き、輸出入（財務省の貿易統計を日銀の物価で割った実質の量）との関係、世界の値動き（日銀の輸出物価の契約通貨ベース）との連動を見る。

知りたい人：製造業・部品・素材の仕事をする人、地域の産業の記事を書く人、景気の統計を読む人。特定の会社・工場の良し悪し、補助金の是非、投資の判断は扱わない。

既存の看板記事との違い：368（輸出の主役の入れ替わり、輸出額の割合）、F282（円安と輸出の数量・価格）、F289（ICT 資本と生産性）、F85（産業連関表）。半導体の国内生産の指数を、出荷・在庫・輸出入と並べて見た記事はない。

## データ
- 経済産業省「鉱工業指数」2020年基準（2018年1月〜2026年9月）と2015年基準（2013年1月〜2023年4月）、業種別・品目別の月次の季節調整済指数（生産・出荷・在庫）。e-Stat の掲載分（経産省のサイトは 403）。
- 財務省「貿易統計」輸出入額の推移 世界 月別 主要商品別：半導体等電子部品、そのうち IC、半導体等製造装置（輸出）。千円。
- 日本銀行「企業物価指数」：輸出物価（円ベース・契約通貨ベース）と輸入物価（円ベース）の集積回路（商品群、2015年基準と2020年基準）、輸出物価（契約通貨ベース）のモス型メモリ集積回路。
- 世界の半導体の売上（WSTS）は使わない（業界団体の資料で、再配布の扱いがはっきりしないため）。

## 取得前・計画前に見たもの（開示）
- 表の形を確かめるときに、2020年基準の業種別の季節調整済の生産指数の最初の月と最後の月を見た：集積回路 88.6（2018年1月）→ 139.6（2026年9月）、半導体・フラットパネルディスプレイ製造装置 115.7 → 224.6、鉱工業 112.3 → 103.9、電子部品・デバイス工業 101.1 → 109.1。品目別では、モス型 IC（メモリ）73.7 → 182.6、アクティブ型液晶パネル（中・小型）151.3 → 10.4、マイコン・シリコンウエハなどは秘匿（X）の月がある。
- 2015年基準の集積回路は 85.2（2013年1月）→ 120.2（2023年4月）。
- 年の平均、2019年との比、出荷と在庫、輸出入の実質化、相関は、まだ計算していない。

## 計算（事前に決める）
- 2つの基準をつなぐ：2018年1〜12月の平均で、2020年基準 ÷ 2015年基準の比を出し、2015年基準の2013〜2017年の値にかけてつなぐ（業種別の4系列：鉱工業、電子部品・デバイス工業、集積回路、半導体・FPD 製造装置。生産・出荷・在庫）。
- 比べる期間：「直近12か月」＝2025年10月〜2026年9月の平均 と 2019年1〜12月の平均。
- 輸出入の実質：貿易統計の IC の金額 ÷ 日銀の集積回路の物価（輸出は輸出物価・円ベース、輸入は輸入物価・円ベース）。物価は2015年基準を2020年の平均でつないで2020年基準にそろえる（2015年1月〜）。季節の動きは12か月の移動平均か前年同月比で除く。
- 相関：前年同月比（12か月前との比の対数）どうしのピアソンの相関。期間は2016年1月〜2026年9月（物価が2015年からのため）。
- 世界の値動き：モス型メモリ集積回路の輸出物価（契約通貨ベース）の前年同月比と、メモリの生産指数の前年同月比の相関を、ずれ0〜12か月で見る。

## 仮説と「外れ」の基準
- H1：集積回路の生産は、直近12か月の平均が2019年の平均を10%以上上回る。10%未満なら外れ。
- H2：半導体・FPD 製造装置の生産の伸び（同じ比べ方）は、集積回路の伸びより大きい。小さければ外れ。
- H3：IC の実質の輸出の前年同月比と、集積回路の出荷指数の前年同月比の相関が0.5以上。0.3未満なら外れ、0.3〜0.5は「弱く支持」。
- H4：メモリの生産の前年同月比は、世界の値動き（メモリの輸出物価・契約通貨ベースの前年同月比）と、ずれ0〜12か月のどこかで相関0.4以上になる。どのずれでも0.2未満なら外れ。

## 頑健性（3つ以上）
1. 比べる期間を変える：2025年1〜12月の平均と2019年、直近12か月と2018年。
2. つなぎ方を変える：2018年の平均ではなく、2020年基準と2015年基準が重なる2018年1月〜2023年4月の全体の平均でつなぐ。
3. 相関の期間を変える：コロナの時期（2020〜2021年）を除く。
4. 実質の輸出の物価を変える：円ベースではなく、国内企業物価の集積回路で割る。
5. 集積回路のほか、電子部品・デバイス工業全体でも H1 を見る。

## 問い直し（予定）
結果を見てから1つ足す。候補：集積回路の生産の伸びを、品目（メモリ・ロジック・線形・混成・秘匿の品目）の寄与に分ける。

## 言えないこと（予定）
- 指数は付加価値の重みをつけた量の指数で、売上高（15兆円の目標の物差し）とは違う。目標に近づいたかどうかは言えない。
- 個々の工場の稼働の影響は、指数からは分けられない。秘匿の品目もある。
- 相関は因果ではない。世界の値動きが日本の生産を動かした、とは言い切れない。
- 貿易統計の IC と鉱工業指数の集積回路は、範囲がそろっていない（輸入品の再輸出なども含む）。
