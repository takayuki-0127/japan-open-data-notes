# 1256 シリーズの何冊目から読み始める人が多いかで、1冊目から順に読む割合はどう見えるのか？（電子書籍）

シリーズの本で、「1冊目を読んだ人のうち、どれだけ2冊目へ進んだか」を、巻ごとの読者数の比（2冊目の人数÷1冊目の人数）で読むことがあります。けれども、読者がみな1冊目から読み始めるとは限りません。新しい巻や話題になった巻から読み始める人は、2冊目以降の人数に足されますが、1冊目の人数には入りません。途中から読み始めて、あとで1冊目に戻る人もいます。**ここでは、作成者が置いた架空の電子書籍のシリーズ（何冊目から読み始めるかの割合、次の巻へ進む確率、1冊目に戻る割合を作成者が決め、読者2万人の読んだ順を乱数で作ったもの）で、「1冊目から2冊目へ進んだ割合」と「1冊目から最後の巻まで読んだ割合」を3つの数え方で出し、作成者が置いた進む確率と比べました。1冊目から読み始める人の割合を100〜20%に変え、巻の数・進む確率・戻る割合・途中から読み始める形を変えた54通りで確かめました。**

例のシリーズと読者は架空のもので、実在の販売サイトや読み放題の記録は使っていません。シリーズの出し方や並べ方の助言をする記事ではありません。

関連する記事：887「継続率は、月で数えるか案件で数えるかで変わるのか？」は、同じ取引の記録から、数える単位で継続率が変わることを扱っています。1246「1冊目から2冊目へ進んだ割合は、出してからの日数をそろえないとどう見えるのか？」は、2冊の売れた冊数の累計の比で進んだ割合を読むときに、2冊目を出してからの日数でどうずれるかを扱っています。この記事は、シリーズの途中から読み始める人が、巻ごとの人数の比にどうまざるかに絞ります。

## 主な結果

### 基本の置き方（5冊、1冊目から6割、p 0.6、q 0.3、`results/per_book_base.csv`）
| 巻 | 読んだ人 | 前の巻の何倍 | その巻から読み始めた人 |
|---|---|---|---|
| 1冊目 | 14,259人 | — | 11,849人 |
| 2冊目 | 10,107人 | 0.7088倍 | 2,015人 |
| 3冊目 | 7,957人 | 0.7873倍 | 2,088人 |
| 4冊目 | 6,671人 | 0.8384倍 | 2,050人 |
| 5冊目 | 5,885人 | 0.8822倍 | 1,998人 |

| 数え方 | 1冊目→2冊目 | 1冊目→最後の巻 |
|---|---|---|
| A 巻ごとの人数の比 | **0.7088** | **0.4127** |
| B 1冊目を読んだ人のうち（順番は問わない） | 0.608 | 0.1387 |
| C 1冊目から読み始めた人のうち | **0.5933** | **0.1245** |
| （置いた確率） | 0.6 | 0.1296（0.6の4乗） |

- **進む確率を0.6と置いたのに、巻ごとの人数の比では2冊目へ0.7088、最後の巻へ0.4127と見えた**。最後の巻の人数には、その巻から読み始めた人（1,998人）が入るため、1冊目から読み始めた人の0.1245の3.3155倍になった
- C が置いた確率に近いのは作りどおり（1冊目から読み始めた人だけを数えるので）
- 巻ごとの人数の比は、後ろの巻ほど1に近づいた（0.7088→0.8822）。置いた進む確率はどの巻も0.6で同じ。後ろの巻ほど、途中から読み始めた人の分が積み上がるため
- B は、途中から読み始めて1冊目に戻った人（途中から読み始めた人の29.57%）を、1冊目を読んだ人に入れる。1冊目を読んだ人のうち、1冊目から読み始めた人は83.1%だった

### 1冊目から読み始める人の割合を変えると（`results/start_share_sweep.csv`）
| 1冊目から読み始める人 | A 1→2（均等） | A 1→最後（均等） | A 1→2（新しい巻に集まる） | A 1→最後（新しい巻に集まる） | C 1→2（均等） |
|---|---|---|---|---|---|
| 100% | 0.5929 | 0.1288 | 0.5985 | 0.1295 | 0.5929 |
| 80% | 0.6464 | 0.2458 | 0.6207 | 0.3121 | 0.6004 |
| 60% | 0.7135 | 0.4071 | 0.6362 | 0.5657 | 0.6011 |
| 40% | 0.8101 | 0.6545 | 0.6857 | 0.9569 | 0.6018 |
| 20% | **0.9672** | **1.0362** | 0.7454 | **1.5346** | 0.5988 |

- 1冊目から読み始める人が少ないほど、人数の比は大きく見えた。**1冊目から読み始める人が2割だと、最後の巻の人数が1冊目より多く（1.0362倍・1.5346倍）、「1冊目を読んだ人より多くが最後まで読んだ」ように見えた**
- 途中から読み始める人がいちばん新しい巻に集まる形では、2冊目への比のずれは小さく（0.7454）、最後の巻への比のずれは大きかった（1.5346）。どの巻の比がずれるかは、読み始める巻の分かれ方で決まる
- 新しい巻に集まる形で1冊目から2割のとき、隣の巻どうしの人数の比の最大は2.926倍だった
- 60%の行は、基本の置き方（上の表）とは別に作り直したもので、0.7135と0.7088のように少しずれる

### 確かめ：54通り（1冊目から6割、`results/grid.csv`）
- **54通りすべてで、A の人数の比は C を上回った**。2冊目へは C の1.0186〜1.8065倍、最後の巻へは1.371〜332.7333倍だった。最後の巻への332倍は、8冊・p 0.4 で、1冊目から読み始めた人が最後まで順に読む割合がとても小さい（0.4の7乗）置き方
- 54通りのうち29通りで、どこかの隣の巻どうしの人数の比が1を上回った（0.7694〜8.6579倍）
- B は C の0.9996〜1.2108倍。1冊目に戻る人がいない（q＝0）18通りでは、B と C は同じ値だった（作りどおり：途中から読み始めた人は1冊目を読まない）
- C と置いた進む確率の差は、54通りすべてで0.0088以内だった（作りどおり）
- 2冊目への比のずれは、巻の数が多いほど小さかった（C に対する倍率の最大は、3冊で1.8065倍、5冊で1.42倍、8冊で1.2452倍）。途中から読み始める4割が多くの巻に分かれ、2冊目に来る人が減るため

## データ
- `data/readers_base.csv`：基本の置き方の読者2万人（reader_id・start_book（読み始めた巻）・last_book_forward（前へ進んで読んだ最後の巻）・went_back_to_1（1冊目に戻ったら1）・last_book_after_back（戻ってから読んだ最後の巻、戻らなければ0））
- `results/per_book_base.csv`：基本の置き方の巻ごとの人数
- `results/start_share_sweep.csv`：1冊目から読み始める割合を変えた10通り（A_count_ratio_*・B_read1_*・C_started1_* が A・B・C、formula_* は置いた確率、max_step_ratio は隣の巻どうしの人数の比の最大）
- `results/grid.csv`：確かめの54通り（A_over_C_* は A÷C）
- `results/a1256_main.json`：主な結果のまとめ

## 注意（言えないこと）
- 架空のデータです。読み始める巻の割合、進む確率、戻る割合は作成者が置いたもので、人数の比のずれはこれで決まります。A の値は、置いた割合と確率から式でも出せます（作りどおり）。新しく数えたのは、置き方を変えたときにどの巻の比がどれだけずれるかです
- 進む確率はどの巻でも同じ、読む人どうしは互いに関係しないと置きました。巻ごとに進みやすさが違う場合、途中で読むのを休んであとで戻る場合は入れていません
- 読者の記録が1人ずつ、読んだ順に分かることを前提にした C は、巻ごとの人数しか分からない場では出せません
- シリーズの出し方、どの巻から勧めるとよいかは扱っていません
