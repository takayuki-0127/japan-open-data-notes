# 256 1人あたりの魚と肉は、いつ入れ替わったのか

農林水産省「食料需給表」（令和6年度、1960〜2024年度。2024年度は概算値）を使ったフォルダです。データは記事101（`articles/101_food_balance`）と同じ e-Stat の CSV です。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A256 | 1人あたりの肉類と魚介類は、いつ入れ替わったのか。重さと熱量で違うか | 国民1人・1年当たり供給純食料（kg）と1人・1日当たり供給熱量（kcal）で、肉類が魚介類を上回った年度・下回った年度を数える。3年移動平均でも確かめる。肉類は牛肉・豚肉・鶏肉・鯨に分ける | `src/a256_fish_meat.py` |

## 主な結果
- 重さ（1人・1年当たり供給純食料）で肉類が魚介類を上回ったのは2011年度（肉29.6kg・魚28.5kg）。その後、入れ替わりは起きていない
- 熱量（1人・1日当たり供給熱量）では、1979年度にいったん肉が上回り（肉138.6kcal・魚133.0kcal）、1985年度に一度だけ魚が上に戻ったあと、1987年度からはずっと肉が上
- 重さと熱量で30年以上ずれるのは、1kg当たりの熱量が違うから。2024年度は肉類約1,930kcal/kg、魚介類約1,320kcal/kg（1日当たり熱量×365÷1年当たり重さで計算）
- 魚介類は2001年度の40.2kgが最大で、2024年度は21.3kg（−18.9kg、−47%）。同じ期間に肉類は27.8→34.3kg（+6.5kg）で、増えたのは鶏肉（+4.5kg）と豚肉（+2.4kg）。牛肉は−0.4kg
- 1960年度は肉5.2kg・魚27.8kgで、魚が肉の5倍以上だった。2024年度は肉34.3kg・魚21.3kg
- 鶏肉と豚肉を足しただけで魚介類を上回ったのは2016年度

## 頑健性
- 3年移動平均で見ても、重さで上回った年は2011年度。熱量は1979年度（移動平均では1985年度の戻りが消える）
- 1年の数字の上下（2001年度の魚の山など）に左右されないよう、比べ方を「上回った年」と「その後戻ったか」の両方で書いた
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致した

## 動かし方
```
pip install -r requirements.txt
cd src && python a256_fish_meat.py
```

## データ
- `data/jukyu_r6_14.csv`：e-Stat「食料需給表」令和6年度 項目別累年表（国民1人・1年当たり供給純食料、kg）。記事101の `data/jukyu_raw.zip` の中身を UTF-8 にしたもの
- `data/jukyu_r6_16.csv`：同じく国民1人・1日当たり供給熱量（kcal）
- 元のファイル：e-Stat「食料需給表」（政府統計コード 00500300）https://www.e-stat.go.jp/stat-search/files?page=1&toukei=00500300&tstat=000001017950

## 注意
- 供給純食料は「国内に供給された食べられる部分の量」で、実際に食べた量ではない。食べ残しや廃棄も含む
- 魚介類と肉類の重さは、骨や皮などを除いた「純食料」。同じ1kgでも、栄養や満腹感は違う
- 2001年度の魚介類の山（40.2kg）は前後の年より目立って高い。統計の計上の仕方による可能性がある（推測）が、このデータでは確かめられない
- 2024年度は概算値。確定値で変わることがある
- 魚から肉へ移った理由（値段、調理の手間、世帯の形など）は、このデータでは分からない
