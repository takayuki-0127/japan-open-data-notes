# 626 2つの事業の損害を「独立」と置いて合わせると、合計の99.5%点はどれだけ小さく出るのか（手法の解説・正解の分かるデータで試す）

いくつかの事業の損害を合わせた「200年に1度の損害」（99.5%点）を出すとき、事業どうしを独立と置くと計算は簡単ですが、同じ年に一緒に悪くなる関係（相関）があると小さく出ます。**ここでは、架空の2つの事業の年間の損害（対数正規、平均100、変動係数0.3と0.6）を正規コピュラで相関0〜0.75に結び、合計の99.5%点を「本当（相関を入れたシミュレーション）」「独立と置いたシミュレーション」「相関行列の式」「それぞれの99.5%点を足す」の4通りで比べました。** 5つの事業でも同じことをしています。各200万回。数字は置いた分布で決まります。料率・備金・資本の助言ではありません。

|---|---|---|---|

## 主な結果
- **2つの事業（平均の合計200）の合計の99.5%点（本当）**：ρ=0 で 466、0.25 で 489、**0.5 で 512**、0.75 で 537。独立と置くと 468 のまま
- **独立と置いたときの過小**：2つの事業で ρ=0.5 のとき合計で −8.7%、平均を引いた部分（99.5%点−平均）では 268 対 312 で **−14%**。ρ=0.75 では合計 −13.0%
- **5つの事業（変動係数0.3〜0.7）**：ρ=0.5 で本当 1,230 に対し独立 913（**−25.8%**）、平均を引いた部分では 413 対 730 で −43%。事業が多いほど、独立の仮定の効き方が大きい
- **相関行列の式**：2つの事業で本当より 1.0〜2.6% 大きく、5つの事業では 3.1〜8.9% 大きかった（右に偏った分布を、偏りのない分布のように合わせるため）
- **それぞれの99.5%点を足す**：2つの事業で 562（ρ=0.5 の本当より 9.7% 大きい）、5つの事業で 1,531（24.4% 大きい）
