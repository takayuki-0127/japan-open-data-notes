# 622 「新規の顧客」を過去何年さかのぼって判定するかで、新規の割合はどれだけ変わるのか（実務の型）

「新規の顧客」は、ふつう「前回の購入から一定の期間あいている人」で判定します。さかのぼる期間を短くすると、しばらく離れて戻ってきた人も新規に入ります。**ここでは、架空の顧客4万人の購買履歴（2010〜2025年、手元のデータは2018年1月から）で、2025年に買った人を「12・24・36か月あいたら新規」「手元のデータに前回がない」の4通りで判定し、本当の新規（2010年以降で初めての購入）と比べました。** 24か月の判定は SQL（DuckDB、LAG）でも出し、Python と一致することを確かめています。数字は置いた買い方・離れ方・戻り方で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A622 | さかのぼる期間で新規の割合はどれだけ変わるか | 月ごとの購入のシミュレーション（買う確率は人により違う、毎月3%が離れ、その35%が6〜60か月後に戻る）、前回の購入月との差で判定、seed 622 | `src/a622_new_lookback.py` |
| SQL | 24か月の判定 | LAG で前回の購入月を取る。DuckDB 版（1スレッドで実行）、T-SQL 版（未検証） | `src/02_new_customer_duckdb.sql`・`src/01_new_customer_tsql.sql` |

## 主な結果
- **2025年に買った 11,162人のうち「新規」の割合**：本当の新規 23.1%（2,577人）。**12か月あいたら新規 38.9%（4,340人）**、24か月 31.7%、36か月 28.5%、手元のデータに前回がない 23.4%
- **新規に混ざった「戻ってきた人」**：12か月 1,763人（新規と数えた人の41%）、24か月 961人、36か月 607人、手元のデータ全期間 29人（2018年より前に買っていた人）。本当の新規の見落としはどの判定でも0人
- **月ごとの新規の割合（2025年）**：本当の新規 6.1〜7.7%、12か月の判定 11.0〜13.0%
- **データの始まりに近い年ほど、全期間の判定は新規を多く数える**：手元のデータに前回がない人の割合は、2018年は100%（全員）、2019年 37.0%（本当は26.2%）、2021年 28.2%（23.9%）、2024年 23.6%（23.3%）
