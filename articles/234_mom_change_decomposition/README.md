# 234 前月比の増減を、店舗数・日数・客数・客単価に分ける（実務の型）

月次の報告でよく出る「売上は前月より○億円増えた。要因は客数と客単価」の分け方を、日本フランチャイズチェーン協会のコンビニ統計（正会員チェーンの全店、2005年1月〜2025年12月の252か月）で試したフォルダです。売上を「店舗数 × 月の日数 × 1店1日あたり客数 × 客単価」に分け、3つの分け方（順番に置き換える、対数平均（LMDI）、全順番の平均（シャープレイ値））を比べました。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A234 | 前月比の増減を、要因ごとにどう分けると説明しやすいか。分け方で答えは変わるか | 4つの要因の積への分解。順番に置き換える方法（24通り）、LMDI-I、シャープレイ値。前年同月比でも同じ分解 | `src/a234_decompose.py` |

## 主な結果
- 2025年12月の売上は前月より650億円増えた。LMDI で分けると、客単価+352億円、日数（30→31日）+335億円、店舗数+9億円、1店1日あたり客数−46億円
- 置き換える順番を24通り変えると、同じ月の寄与は客単価で345億〜359億円、日数で329億〜342億円と動いた。全251か月で見ると、順番による幅は、増減の大きさに対して中央値で3%、上位1割の月で13%以上
- LMDI とシャープレイ値の差は小さく、2025年12月はどの要因も1億円未満だった（全期間の最大で0.9億円）
- 前月比の増減のうち、絶対値で見て平均42%は「月の日数」の違いだった。251か月のうち149か月で、日数がいちばん大きい要因だった。前年同月比で分けると日数の割合は平均2%に下がり、日数がいちばん大きい月は6か月（うるう年の2月とその翌年など）だけだった
- 売上＝来店客数×客単価の関係は、元の表の数字で相対誤差0.01%以内で成り立った

## 動かし方
```
pip install -r requirements.txt
cd src && python a234_decompose.py
```

## データ
- `data/jfa_cvs_monthly.csv`：コンビニ正会員チェーンの全店の売上高（百万円）・店舗数・来店客数（千人）・平均客単価（円）。月次、2005年1月〜2025年12月（F267 で取得したものの写し）
- `results/mom_decomposition.csv`：前月比の分解（要因ごとの LMDI・シャープレイ値・既定の順番・24通りの最小と最大）
- `results/yoy_decomposition.csv`：前年同月比の分解（LMDI）
- `results/summary.json`：まとめの数字

## 注意
- 店舗数は月末の数で、月の途中の開店・閉店はならしていません。1店1日あたり客数は「来店客数 ÷ 店舗数 ÷ 月の日数」で作った値です
- 曜日の並び（土日の数）や祝日、天気の違いは、「1店1日あたり客数」の中に入っています
- 要因に分けても、それぞれの要因が売上を「動かした」原因だとは言えません（たとえば値上げで客数が減る、のような要因どうしの関係は分けられません）
- 全店の数字なので、既存店だけの動きとは違います
