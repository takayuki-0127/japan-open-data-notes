# 883 開店直後の行列は、何分で解消するのか？（待ち時間と混雑）

開店前に並んだ行列を見て「60人で、1分に1.5人会計できるから40分でなくなる」と読むことがあります。ところが、開店後にも客は来て、行列の後ろにつきます。行列が減る速さは、会計の速さではなく、会計の速さから来る速さを引いた「余力」です。**ここでは、作成者が乱数で作った架空のパン屋の開店直後（開店前の行列・レジの台数・会計の時間・開店後に来る客の速さを作成者が置いたもの）で、行列が解消するまでの時間を2,000日分数え、「行列÷会計の速さ」と「行列÷余力」の2つの見込みと比べました。**

行列の最後尾の人の待ちと平均の待ちの違いは関連する記事 881、1人増やしたときの待ちの減り方は 882 で扱っています。この記事は「開店前からの行列が、いつなくなるか」に絞ります。

## 主な結果

### 基本：開店前に平均60人、レジ3台、会計2分、開店後は1分に1.0人（2,000日）
| | 分 |
|---|---|
| 見込み①：行列÷会計の速さ（2,000日の平均） | 40.2 |
| 見込み②：行列÷（会計の速さ−来る速さ） | 120.0 |
| 解消までの中央値 | **111.7** |
| 解消までの平均 | 115.9 |
| 解消までの10〜90%の範囲 | 72.7〜165.1 |
| 開店後に来た人の待ちが初めて5分未満になった時刻（中央値） | 99.3 |

- 2,000日のどの日も、見込み①（40分）までには解消しなかった（見込み①以内に解消した日は0%）。87.2%の日は、見込み①の2倍より長くかかった。解消までの時間は、その日の見込み①の中央値で2.77倍だった
- 見込み②（120分）は、解消までの平均（115.9分）・中央値（111.7分）に近かった。**この見込みは、行列の減る速さが平均で「会計の速さ−来る速さ」になる、という式（流れを水のように見た計算）から出る値**で、乱数の結果はそれをほぼなぞった。中央値が式より少し早いのは、「初めて0人になった時刻」を数えたので、客の来方が偶然まばらな時間に先に0人になる日があるため
- 日による幅は広く、10〜90%で72.7〜165.1分だった。開店前の行列が55〜65人の日（1,046日）だけで見ても76.6〜158.5分で、幅の多くは行列の人数ではなく、開店後の客の来方と会計時間の揺れから来ていた
- 見込み①の40分は、開店前の行列の最後尾の人が会計に進むまでの時間に近い（1回分のデータで38.4分）。行列の最後尾の人が会計に進んでも、その後ろに開店後の客がついているので、行列は残る

### 確かめ：開店後に来る速さ（レジ3台・開店前60人、各500日）
| 来る速さ（1分あたり） | 見込み②（分） | 解消の中央値（分） | 10〜90%（分） | 8時間で解消しなかった日 | 見込み①の何倍か（中央値） |
|---|---|---|---|---|---|
| 0.5人 | 60 | 55.1 | 40.4〜73.3 | 0% | 1.40 |
| 0.75人 | 80 | 73.0 | 51.0〜101.9 | 0% | 1.84 |
| 1.0人（基本） | 120 | 110.5 | 69.8〜165.6 | 0% | 2.76 |
| 1.25人 | 240 | 204.3 | 111.2〜358.0 | 2.0% | 5.14 |
| 1.4人 | 600 | 460.3 | 181.3〜（8時間より後） | **47.8%** | 10.16 |

- 来る速さが会計の速さ（1.5人）に近づくほど、解消は遅れ、日による幅も広がった。1分に1.4人では、48%の日が8時間たっても解消しなかった
- 見込み①（約40分）は来る速さで変わらないので、外れ方は1.40倍から10倍以上まで広がった

### 確かめ：開店前の行列・レジの台数・会計のばらつき（各500日）
| 置き方 | 見込み①（平均、分） | 見込み②（分） | 解消の中央値（分） | 10〜90%（分） |
|---|---|---|---|---|
| 開店前 平均30人 | 19.9 | 60 | 50.1 | 25.2〜84.7 |
| 開店前 平均60人（基本と同じ置き方） | 40.1 | 120 | 110.5 | 69.8〜165.6 |
| 開店前 平均90人 | 60.2 | 180 | 166.8 | 121.8〜234.0 |
| レジ4台 | 30.0 | 60 | 53.5 | 38.5〜73.2 |
| 会計のばらつき係数0.5 | 40.3 | 120 | 116.6 | 81.9〜156.5 |
| 会計のばらつき係数1.5 | 39.8 | 120 | 105.3 | 60.1〜178.2 |

- 開店前の行列が倍になると、解消までもほぼ倍になった（30人で50.1分、60人で110.5分、90人で166.8分）
- レジを3台から4台にすると、会計の速さは1.33倍だが、余力は1分に0.5人から1.0人の2倍になり、解消の中央値は110.5分から53.5分に縮んだ
- 会計のばらつきを変えても、中央値は105.3〜116.6分で見込み②の近くにあった。ばらつきが大きいほど、日による幅は広がった

## データ
- `data/one_day_customers.csv`：架空の1日の客（開店前の60人と開店後の客）。customer_id・arrival_min（開店からの来店時刻、開店前に並んだ人は0）・start_min（会計を始めた時刻）・service_min（会計の時間）・wait_min（待ち）・in_line_at_open（開店前から並んでいたか）
- `results/base_days.csv`：基本の2,000日。day・q0（開店前の行列の人数）・clear_min（解消した時刻）・wait_lt5_min（来た人の待ちが初めて5分未満になった時刻）・naive_min（見込み①）・margin_min（その日の行列での見込み②）

## 注意（言えないこと）
- 架空のデータです。開店前の行列の人数、開店後に来る速さ、会計の時間、レジの台数、「解消」の定義は作成者が置いたもので、結果はこれで決まります
- 見込み②は、行列の減る平均の速さから出る式の値で、乱数の結果はそれをほぼなぞったものです。この記事で新しく数えたのは、日による幅と、来る速さが会計の速さに近いときの遅れ方です
- 開店後に来る速さは8時間ずっと同じと置きました。実際には開店直後に多く、その後減ることが多いと考えられます（推測）。その場合、来る速さは時間帯ごとに置き直す必要があります
- 行列が長いと並ばずに帰る客、途中でレジを増やすことは入れていません
- 実在の店の開店時の様子を表すものではありません
