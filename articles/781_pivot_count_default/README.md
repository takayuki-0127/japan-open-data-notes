# 781 数の列に文字が1つまざると、Excel のピボットの集計はどう変わり、合計はどれだけ消えるのか（実務の型）

Excel のピボットでは、値の列に文字（「12,000」のように文字として貼り付いた数や「-」）が1つでもまざると、既定の集計が「合計」ではなく「個数」になると言われています。気づいて「合計」に切り替えても、文字のセルは足されません。**ここでは、作成者が乱数で作った架空の売上表（10店×300行、店によって金額の一部が文字になっている）で、この動きを Python で再現し（Excel では未検証）、店ごとにどれだけの売上が消えるかを数えました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A781 | 文字がまざると、ピボットの値と合計はどうなるか | 架空の10店×300行。文字になった金額の割合を店ごとに0〜30%、「-」は約1%。「文字が1つでもあれば既定は個数」「合計は文字を無視」を Python で再現（Excel では未検証）。数に直す SQL（TRY_CAST・REPLACE）を DuckDB（1スレッド）で動かし、正しい合計と一致を確認。seed 781 | `src/a781_pivot.py`、`src/02_clean_duckdb.sql`、`src/01_clean_tsql.sql` |

## 主な結果

| | 値 |
|---|---|
| 文字のセル | 3,000行のうち256（8.5%） |
| ピボットの既定の集計 | **個数**（どの店も「300」と出る） |
| 「合計」に切り替えた全体の売上 | 2,656万円（正しくは2,870万円、**7.5%少ない**） |
| 最も消えた店（文字30%の店 I） | **30.6%** 少ない |

| 店 | 文字のセル | 正しい売上 | 「合計」の値 | 消えた割合 |
|---|---|---|---|---|
| 店A・B・C・J | 2〜4（「-」だけ） | — | 同じ | 0% |
| 店F | 22 | 291.6万円 | 276.0万円 | 5.3% |
| 店G | 38 | 289.4万円 | 252.6万円 | 12.7% |
| 店H | 66 | 288.8万円 | 221.8万円 | 23.2% |
| 店I | 100 | 278.8万円 | 193.4万円 | 30.6% |

- 「-」のような文字が1セルでもあれば、ピボットの既定は「個数」になり、どの店も行の数（300）が出た
- 「合計」に切り替えると、文字として入っていた金額だけが足されず、全体で7.5%、店 I では30.6%少なくなった
- 正しい売上で5位の店 H は、「合計」の値では9位になった。文字の多い店ほど売上が小さく見える

## 注意（言えないこと）
- 架空のデータです。文字になる割合は作成者が置いたもので、消える割合はこれで決まります
- Excel のピボットの動き（既定の集計が個数になる条件、合計で文字を無視すること）は Python で再現したもので、Excel では未検証です。Excel の版や設定で違うことがあります
- T-SQL 版は未検証です
