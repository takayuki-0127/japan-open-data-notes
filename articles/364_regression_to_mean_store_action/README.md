# 364 成績の悪かった店だけに手を打つと、何もしなくてもどれだけ「良くなって」見えるのか

成績の悪い店を選んで施策を打つと、施策に効果がなくても、その後の数字は良くなって見えます（平均への回帰）。その「見かけの改善」がどれだけの大きさになるかを、効果0と分かっている架空の100店で測ったフォルダです。F60（去年悪かった県は今年よくなるか）とは違い、施策の評価の場面で試します。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A364 | 効果0でも、下位の店を選ぶとどれだけ改善して見えるか。選ぶ期間を長くする・比べる店を置くと、どこまで消えるか | 架空の100店の月次売上（その店のふだんを100とする）で、下位20店を選び、その後3か月と比べる。2,000回くり返す | `src/a364_rtm_stores.py` |

## データの作り方（架空）
- 100店・30か月。各店の売上は、その店のふだんの水準（100）のまわりで、月ごとに偶然8%ばらつく
- 施策の効果は入れていない（効果0）
- 不調が何か月か続く場面では、続く不調（大きさ8%、月をまたぐ続きやすさ0〜0.95）を足す
- 乱数の種は364。実在の店の数字ではありません

## 主な結果
### ある月の下位20店を選ぶ（偶然のばらつきだけ）
- 選んだ月の20店の平均は89.6、その後3か月の平均は100.4。**効果0でも+12.1%の改善に見えた**（10回のうち8回は+10.0〜+14.4%）
- 選んだ20店の前後を比べる検定は、**2,000回すべてで「効果あり」**（片側2.5%）
- 選ばなかった80店と変化を比べても、2,000回すべてで「効果あり」（差は+13.5ポイント）。選ばなかった店は逆に下がって見えるため、差はむしろ広がる
- **本当に+3%の効果があったとすると、前後の比べでは+15.4%に見える**

### 選び方を変える
| 選ぶときに使う期間 | 選んだ時点の平均 | 見かけの改善 | 前後比べで「効果あり」 |
|---|---|---|---|
| 直前1か月 | 89.6 | +12.1% | 100% |
| 直前2か月の平均 | 92.6 | +8.4% | 100% |
| 直前3か月の平均 | 94.0 | +6.8% | 100% |
| 直前6か月の平均 | 95.8 | +4.8% | 97% |
| 直前12か月の平均 | 97.1 | +3.3% | 82% |

| 選ぶ店の数（直前1か月） | 見かけの改善 |
|---|---|
| 下位5店 | +17.8% |
| 下位10店 | +15.2% |
| 下位20店 | +12.1% |
| 下位50店 | +6.8% |

- **長い期間の成績で選ぶほど、見かけの改善は小さくなる**が、12か月の平均で選んでも+3.3%残った
- **極端な店だけを選ぶほど、見かけの改善は大きい**

### 比べる店をくじで決める
- 下位40店を選び、くじで20店を「手を打つ店」、20店を「比べる店」にする。どちらもその後+8.2%・+8.3%で、差は−0.1ポイント
- **誤って「効果あり」と出たのは5.6%**で、本来の5%とほぼ同じ

### 不調が続く場合（続く不調の大きさ8%を足す）
| 続きやすさ | 直前1か月で選ぶ | 直前3か月の平均で選ぶ |
|---|---|---|
| 0（続かない） | +17.6% | +9.7% |
| 0.5 | +14.8% | +9.5% |
| 0.8 | +11.6% | +7.0% |
| 0.95 | +9.5% | +4.5% |

- 不調が続きやすいほど、その後3か月での戻りは小さい。それでも続きやすさ0.95で+9.5%に見えた

## 動かし方
```
pip install -r requirements.txt
cd src && python a364_rtm_stores.py
```

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した

## 注意（言えないこと）
- すべて架空のデータです。見かけの改善の大きさは、月ごとの偶然のばらつき（8%と置いた）で決まります。ばらつきが半分なら、改善もおよそ半分になります
- 店のふだんの水準は変わらない前提です。本当に落ち込み続けている店が混ざる場合は、戻りは小さくなります
- 季節や全店に共通の動きは入れていません
- 「その店のふだん」を知っている前提で100にそろえました。実際には、ふだんの水準も過去の実績から見積もることになります
- 施策の打ち方について助言するものではありません
