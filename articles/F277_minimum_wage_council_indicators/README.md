# F277 最低賃金の審議会資料にある指標で、上げ幅はどこまで説明できるか？

精選モード（B. 白書・審議会 Q18）。計画は [PLAN.md](PLAN.md)（コミット 31b398c、分析より先）。

## 問い

最低賃金の上げ幅（地域別最低賃金の全国加重平均額の引上げ率）は、中央最低賃金審議会の資料にある指標でどこまで説明できるか。説明できない残りは、いつから、どれだけあるか。

## データ（2003〜2026年度、24年）

| 変数 | 定義 | 出典 | ファイル |
|---|---|---|---|
| y | 全国加重平均額の引上げ率（%） | 厚生労働省「地域別最低賃金改定状況」（JILPT「早わかり グラフでみる長期労働統計」図3 から転記） | data/raw/jil_mw_weighted_avg.csv |
| t4 | 賃金改定状況調査 第4表 賃金上昇率（産業計・男女計・ランク計） | 各年の目安に関する小委員会の議事録・資料（年ごとの URL は CSV の source 列） | data/raw/t4_rate.csv |
| cpi | 持家の帰属家賃を除く総合の前年同月比、前年10月〜当年6月の平均 | 総務省統計局 消費者物価指数 2020年基準 長期時系列（F209 で e-Stat から取得した品目別ファイルの列） | data/raw/cpi_ex_imputed_rent_monthly.csv |

| di_biz, di_emp | 日銀短観 中小企業・全産業の業況判断DI、雇用人員判断DI（6月調査） | 日本銀行 時系列統計データ検索サイト API | data/raw/boj_tankan_sme.json |
| addon_mean | 目安を上回った額の47都道府県の単純平均（2016〜2025年度、頑健性 R3） | 令和8年 第1回目安に関する小委員会「主要統計資料」p.49（東京労働局の掲載資料から転記） | data/raw/mw_add_on_over_meyasu_2016_2025.csv |

整形後は data/processed/panel.csv（1年1行）。

## 手法

- 第4表方式（上げ幅 = 第4表）の差を年ごと・時期ごとに出す（H1）
- OLS：y ~ t4、y ~ t4 + cpi + spr + di_biz + di_emp。決定係数、1年ずつ抜いた予測（LOO）の誤差（H2、H4）
- 2003〜2015年度で当てはめて2016〜2026年度を予測（H3）
- 比べる基準：「前年と同じ上げ幅」
- 問い直し（結果を見た後に追加）：t4 ~ 前年度の引上げ率 + spr + di_emp（2004〜2026年）

## 結果

| 仮説 | 基準 | 結果 | 判定 |
|---|---|---|---|
| H1 第4表だけでは足りなくなった | 2003〜06年の差の絶対値の平均 ≤0.5、2007〜26年の差の平均 ≥1.0 | +0.20 ／ +1.73（結果を見た後の区切りで 2007〜15年 +1.45、2016〜19年 +1.81、2021〜26年 +2.57） | 支持 |
| H2 指標を全部使えば説明できる | 決定係数 ≥0.7 | 0.81（自由度調整 0.76）。ただし LOO の誤差 1.04ポイントで、第4表だけの式（0.98）より大きい。LOO の決定係数 0.58 | 支持 |
| H3 2016年以降は指標で説明できない上乗せ | 2003〜15年の式で予測した差の平均 ≥+1.0 | −3.96（2023年度 8.5%、2024〜26年度 18.1〜19.2% に飛んだ） | 外れ |
| H4 2020年は指標から大きく下にずれた | 残差が24年で最小 | −1.52 で最小 | 支持 |

- 5つの指標の式で効いていたのは、春季賃上げ（係数 0.96、p=0.006）と雇用人員判断DI（−0.061、p=0.063）。t4 は −0.66（p=0.38）と、ほかの指標と一緒に動くため偶然と区別できない
- 「前年と同じ」の誤差は 1.14ポイント（2004〜2026年）。同じ23年で比べた LOO の誤差は、5指標 1.08、第4表だけ 1.00。「前年と同じ」の誤差は 2020年度（−2.98）と 2021年度（+2.99）でほぼ決まる
- 「前年と同じ」を式に加えると、その係数は 0.20（p=0.49）、LOO の誤差は 1.17ポイント（計画にない追加）
- H3：第4表だけの式（2003〜2015年）では、2016〜2026年度の差の平均 +0.84（2020年度を除くと +1.14）。5指標の式は、2016〜2022年度は 2020年度（−2.90）と 2021年度（+1.70）を除いて ±0.6 の内

## 問い直し：第4表は前年の引上げを映していないか（結果を見た後に追加）

第4表は前年6月→当年6月の賃金の上昇率で、前年度の最低賃金の引上げ（多くは10月発効）がその期間に入る。

| 式（被説明変数 t4、2004〜2026年、23年） | 前年度の引上げ率の係数 | p | 決定係数 |
|---|---|---|---|
| 前年度の引上げ率だけ | 0.47 | <0.001 | 0.73 |
| ＋春季賃上げ | 0.26 | 0.013 | 0.81 |
| ＋春季賃上げ＋雇用人員DI | 0.15 | 0.016 | 0.94 |
| 同上（2021年を除く） | 0.12 | 0.071 | 0.94 |
| 同上（2009・2021年を除く） | 0.14 | 0.056 | 0.94 |

- 係数 0.12（2021年を除く）〜0.15 で計算すると、2016〜2026年の第4表（平均1.65%）のうち平均 0.40〜0.50ポイント、2026年の 3.0% のうち 0.75〜0.93ポイントが前年の引上げで説明できる計算（目安）
- 2021年：前年度の引上げ 0.11% → 第4表 0.4%（3指標の式の当てはめ値 0.62%、2021年を含めて当てはめた値）
- 前年の引上げの分を除いた第4表との差は、2007〜2026年度で平均 +2.12ポイント
- 係数には賃金の流れ（年をまたいだ持続）も混ざる（推測）

## 計画からのずれ

- H3 は計画どおり「外れ」と判定。春季賃上げが当てはめの範囲（1.6〜2.4%）の外に出て予測が飛んだことが主な理由。第4表だけの式での比較は結果を見た後に加えた
- R3 は上乗せの単純平均（働く人の数で重みを付けていない）。人口の多い都府県は上乗せが小さいので、上乗せを大きめに見ている
- R4 で「前年と同じ」の誤差を円でも出した。「前年と同じ」を式に加えた比較も追加した（どちらも計画になし）
- 問い直し（6章）は結果を見た後に加えた
- データを集める途中で、第4表と全国加重平均額の年ごとの値は目にしていた（PLAN に記載）。物価の系列も F209 で取得したもので、値を見ていた可能性がある（PLAN に書き漏れ。PLAN は書き換えていない）
- 2007年以降を3つの時期に分けた差は、結果を見た後に置いた区切り（計画は 2003〜06 と 2007〜26 だけ）
- 頑健性の比べ方を、レビューを受けて同じ年どうしに直し、2021年度も除く確認を加えた
- 事後に試した式（src/zz_f277_05、results/review_checks.json）：y ~ 前年度の引上げ率 + 春季賃上げ + 雇用人員DI は LOO の誤差 0.88（前年の係数 0.03、p=0.89）、y ~ 前年 + 春季賃上げ は 1.00、y ~ 第4表 + 前年 は 1.04

## 言えないこと

- 審議会がどう決めたか（議論の中身、政府の方針の効き方）は分からない。示したのは公表された指標と決定の数字の関係だけ
- 第4表は2004〜2005年に計算の仕方が変わり、ランクの区分も2017年と2023年に変わっている。ランク計の値をそのままつないだ
- 上げ幅は目安そのものではなく、都道府県の上乗せを含む
- 物価は指数（小数1桁）から前年同月比を計算し直した。2025・2026年の期間平均（3.92%、2.12%）は審議会資料の値（3.9%、2.1%）と一致
- 24年に指標5つで、係数は不安定。どの指標が効いたかは決められない
- 問い直しの係数は因果の大きさではない
- 春季賃上げは毎年8月に出る確定値で、審議の時点で見えていた値（連合の集計など）とは違う（推測）
- 最低賃金の水準や上げ幅の良し悪しは扱わない

## レビューで直したこと

独立したレビュー（別のエージェント）で、再現はバイト単位で一致し、第4表（複数年）・最低賃金の全系列・春季賃上げの転記と、時点の先読みがないことが確かめられた。指摘12件を次のとおり直した。

| # | 指摘 | 直し方 |
|---|---|---|
| 1 | 結論4「2023年度以降は15〜19%」は誤り（2023年度は8.5%） | 「2024年度以降は18〜19%（2023年度は8.5%）」に |
| 2 | タイトル・結論6の言い切りが強い（2021年を除くと p=0.07） | 「映している可能性がある」に。寄与を 0.75〜0.9ポイントに。結論6を「結果を見た後に加えた問い」と明記 |
| 3 | 第4表だけの式の LOO の誤差（0.98）が書かれていない | 本文・図3・図5に追加。指標を足すと予測の誤差が大きくなったことを明記 |
| 4 | 考察の式は試していない | 事後に計算（LOO 0.88、前年の係数 0.03）し、事後の結果と明記。考察を第4表だけの式と前年と同じを基準にする形に直した |
| 5 | 頑健性で「前年と同じ」を全年の値と比べていた | 条件ごとに同じ年で計算し直し（R2：0.76・0.82・0.97、2021も除くと 0.78・0.77・0.74）、図5を作り直した。全年の 1.14 は 2020・2021年度でほぼ決まることを明記 |
| 6 | 時期の区切り（2007〜15・2016〜19・2021〜26）は事後 | 本文と計画からのずれに明記 |
| 7 | 第4表だけの式の H3 比較は事後 | 本文に明記、H3 の判定は変わらない |
| 8 | 春季賃上げは確定値 | 言えないことに追加（推測） |
| 9 | 1章の「1.0〜2.4%」 | 「1.4〜2.4%（2011年度だけ0.96%）」に |
| 10 | 法改正と政府方針の出典 | 最低賃金法の一部を改正する法律（平成19年法律第129号）、ニッポン一億総活躍プラン（2016年6月閣議決定）を追加 |
