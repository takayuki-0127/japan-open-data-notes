# PLAN（F277、結果を見る前に書いた計画）

2026-11-11 作成。分析のコードを書く前、指標を合わせた当てはめを一度も計算する前に置く。

## 問い

最低賃金の上げ幅は、中央最低賃金審議会の資料に並ぶ指標（賃金改定状況調査の第4表、消費者物価、春季賃上げ、企業の景況や人手の足りなさ）で、どこまで説明できるか。説明できない残りは、いつから、どれだけあるか。

## 正直に書いておくこと（事前に見たもの）

データを集める途中で、次の値は目にしている。

- 賃金改定状況調査 第4表（産業計・男女計・ランク計）の賃金上昇率：2003〜2026年。議事録と審議会資料の本文で読んだ。
- 地域別最低賃金の全国加重平均額：2002〜2026年度（JILPT の長期統計の表）。
- 2026年の目安が「全国加重平均で 4.9%（55円）を基準」とされたこと（公益委員見解の本文）。

指標を組み合わせた回帰、残差、期間を分けた予測は、まだ一度も計算していない。

## データ（すべて公表値の集計）

| 変数 | 定義 | 出典 |
|---|---|---|
| Y（上げ幅） | 地域別最低賃金の全国加重平均額の引上げ率（年度 t、%） | JILPT「早わかり グラフでみる長期労働統計」図3（厚生労働省「地域別最低賃金改定状況」から転記） |
| T4 | 賃金改定状況調査 第4表 賃金上昇率（産業計・男女計・ランク計、前年6月→当年6月、%） | 厚生労働省 中央最低賃金審議会 目安に関する小委員会の資料・議事録 |
| CPI | 消費者物価指数 持家の帰属家賃を除く総合 の前年同月比の平均（前年10月〜当年6月、%） | 総務省統計局 消費者物価指数（2020年基準 長期時系列） |
| SPR | 主要企業の春季賃上げ率（当年、%） | 厚生労働省「民間主要企業春季賃上げ要求・妥結状況」（JILPT 図2から） |
| DI_biz | 日銀短観 中小企業・全産業 業況判断DI（当年6月調査） | 日本銀行 |
| DI_emp | 日銀短観 中小企業・全産業 雇用人員判断DI（当年6月調査、マイナスほど人手不足） | 日本銀行 |

期間は 2003〜2026年度（24年）。第4表の値を議事録・資料で確かめられた年に合わせる。

## 仮説と「外れ」の基準

- **H1（第4表だけでは足りなくなった）**：2003〜2006年は Y と T4 の差が小さく（平均の差の絶対値 0.5ポイント以下）、2007〜2026年は Y が T4 を平均1.0ポイント以上上回る。
  - 外れ：2007〜2026年の平均の差（Y − T4）が 1.0ポイント未満、または 2003〜2006年の平均の差の絶対値が 0.5ポイントを超える。
- **H2（指標を全部使えば、ある程度は説明できる）**：Y を T4・CPI・SPR・DI_biz・DI_emp で回帰すると、24年全体の決定係数が 0.7 以上。
  - 外れ：0.7 未満。
- **H3（2016年以降は、指標で説明できない上乗せがある）**：2003〜2015年だけで当てはめたモデル（H2 と同じ指標）で 2016〜2026年を予測すると、実際の Y は予測を平均1.0ポイント以上上回る。
  - 外れ：平均の差が 1.0ポイント未満。
- **H4（2020年は指標から大きく下にずれた）**：H2 のモデルで、2020年の残差（実際 − 当てはめ）が24年の中で最も小さい（最も大きなマイナス）。
  - 外れ：2020年より小さい残差の年がある。

## 手法

1. 第4表方式（Y = T4、傾き1・切片0）の誤差を年ごとに出す。
2. OLS：Y ~ T4、Y ~ T4 + CPI + SPR + DI_biz + DI_emp。係数、決定係数、1年ずつ抜いた予測（LOO）の誤差（RMSE）。
3. 期間を分けた予測：2003〜2015年で当てはめ、2016〜2026年を予測。
4. 比べる基準として「前年と同じ上げ幅」の予測の誤差も出す。

## 頑健性（4つ）

- R1：物価の定義を「前年の暦年の前年比」に替える。
- R2：2020年（目安が示されなかった年）と2009年（リーマン・ショック後）を除く。
- R3：Y を、地方の審議会が目安に上乗せした分を引いた値（目安に近い値）に替える。上乗せの表がある 2016〜2025年度だけ。
- R4：Y を金額（円）の引上げ額にし、T4 なども「前年の最低賃金額 × 率」の円に直して同じことをする。

## 書かないこと

- 最低賃金をいくらにすべきか、政策の良し悪しは書かない。
- 審議会の誰の主張が正しいかは書かない。指標と決定の関係を数字で並べるだけにする。
