# 520 0を含むデータを log(x+1) で変換して回帰すると、係数はどれだけずれるのか（統計の考え方）

支出額や売上のように「0の人が多く、使う人の額は大きくばらつく」データでは、0 を対数にできないので log(y+1) にしてから回帰することがよくあります。**ここでは、使うかどうかと使う額の2段階で作った架空の支出額（0の割合54〜60%）で、2つのグループの平均の差（本当の効果）を、log(y+1)（円・千円）、log(y+c)、ポアソン回帰、2段階モデルで推定して比べました。** 予測の合計がどれだけ実際と合うかも数えています。数字は、置いた分布と効果の形で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A520 | log(y+1) の係数は、本当の効果とどれだけずれるか | 2万人（x=0 と x=1 が半分ずつ）。使う確率は x=0 で40%、使うときの額は 5,000円 × exp(β・x + 正規乱数（標準偏差1.2）)。3つの場合：A 使う額だけ増える（β=0.2）、B 使う人だけ増える（使う確率 40%→52%）、C 両方。各200回。係数は「x=1 の平均が何%多いか」に直して比べる。x が 0/1 なので、回帰の係数はグループごとの平均から計算し、1回分を statsmodels の OLS・ポアソン回帰で確かめた | `src/a520_log1p.py` |

## 主な結果
- **本当の効果**：A +22%、B +31%、C +60%
- **log(y+1)（円）**：A **+9%**（小さく出る）、B **+188%**、C **+221%**（本当の3〜6倍）。使う人の割合が変わると、0 と 5,000円前後の差（対数で約8.5）が係数に入り込み、大きくずれる
- **単位を千円にしてから log(y+1)**：A +7%、B +27%、C +38%。同じデータでも単位を変えるだけで C は +221% → +38% になる
- **足す数 c を変えると**（C の場合）：c=0.01円で +470%、1円で +221%、100円で +81%、1,000円で +38%、10万円で +2%。千円にして +1 は c=1,000円と同じ。c しだいでどんな値にもなりうる
- **ポアソン回帰**：A +22%、B +31%、C +61%。**2段階モデル**：A +23%、B +31%、C +60%。どちらも本当の値に近い。200回のばらつき（標準偏差）は C で ポアソン 7.5ポイント、2段階 4.8ポイント、log(y+1) 20.2ポイント
- **合計の予測**：log(y+1) の当てはめ値を exp(·)−1 で戻して合計すると、実際の合計の **約1%**（C で1.2%）にしかならない。ポアソン回帰は定数項があれば合計がちょうど合い（100%）、2段階モデル（対数正規の戻しの補正あり）は100.5%

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- グループの平均から計算した係数が、statsmodels の OLS（log(y+1)）とポアソン回帰の係数と一致すること（1回分）
- 「千円にして log(y+1)」と「円のまま log(y+1000)」の効果が同じになること（log(y/1000+1) = log(y+1000) − log1000）

- データファイルは置いていない。シミュレーションはコードの中で作る（seed 520）

## 注意（言えないこと）
- 架空のシミュレーション。ずれの大きさは、0の割合、使う額のばらつき、効果の形（使う人が増えるか、額が増えるか）で決まる
- log(y+1) の係数は「平均が何%多いか」ではなく、ここではその意味で比べた。別の量（たとえば対数の平均の差そのもの）を知りたい場合は、ずれとは言えない
- ポアソン回帰や2段階モデルがいつも正しいわけではない。2段階モデルの戻しの補正は、使う額が対数正規でばらつきがグループで同じと置いたときのもの
- どの方法を使うべきかを決めるものではない。「この形のデータで、それぞれの方法がどれだけずれるか」を数えたもの
