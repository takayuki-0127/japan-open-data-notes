# 921 合格率30%の試験で、実力は合格ラインちょうどの人は何%受かるのか？（試験と点数）

試験の点は、同じ人が受けても回ごとに上下します。たまたま知っている問題が多い回もあれば、少ない回もあるからです。では、実力がちょうど合格ラインにいる人は、何%の確率で受かるのでしょうか。「ちょうど」なら半分、と考えがちですが、合格点が「上から30%目の人の点」で決まる試験では、その合格点そのものも回ごとに動きます。**ここでは、作成者が乱数で作った架空の社内資格試験（受験者ごとの実力を作成者が置いたもの）で、「実力が合格点ちょうどの人」と「実力の順で上から30%ちょうどの人」が受かる確率を数え、9割の確率で受かるには合格点よりどれだけ上の実力が要るかを、問題数・実力の散らばり・受験者数・合格率を変えて確かめました。**

この記事は、点の数え方と読み方だけを扱います。勉強の仕方や講座の良し悪しは扱いません。

## 主な結果

### 実力が「ちょうど」の人が受かる確率（基本の置き方：100問・受験者2,000人・合格率30%）
| 「ちょうど」の決め方 | 実力（100点満点） | 受かる確率 |
|---|---|---|
| ①実力が合格点と同じ | 63点 | **55.75%** |
| ②実力の順で上から30%ちょうど | 62.33点 | **50.24%** |
| （比べ）合格点を63点に固定し、実力63点 | 63点 | 54.47% |
| （比べ）合格点を63点に固定し、実力62.5点 | 62.5点 | 50.34% |

- 実力が合格点ちょうどの人は、半分より少し多い55.75%で受かった。得点がちょうど合格点でも合格になる（「以上」で数える）ためで、合格点を固定したとき、実力63点の人がちょうど63点を取る確率は8.24%あった。実力を0.5点下げると、受かる確率は50.34%とほぼ半分になった
- これは二項分布の式からほぼ決まる値で、データから新しく見つけたものではない
- 実力の順で上から30%ちょうどの人（実力62.33点）は50.24%だった。得点は実力より散らばるので、得点の上から30%目（合格点）は、実力の上から30%目より少し上に来る。100問ではその差は0.67点ほどだった
- 合格率は、同点の人も合格にするため、平均で31.22%だった

### 実力と受かる確率
| 実力−合格点 | 受験者2,000人の回 | 受験者50人の回 |
|---|---|---|
| −10点 | 3.07% | 4.32% |
| −5点 | 19.12% | 20.35% |
| −3点 | 31.93% | 31.86% |
| −1点 | 47.55% | 45.59% |
| 0点 | 55.75% | 52.83% |
| +1点 | 63.77% | 60.03% |
| +3点 | 78.02% | 73.38% |
| +5点 | 88.53% | 84.16% |
| +10点 | 98.99% | 97.61% |

- 9割の確率で受かるには、合格点より**5.4点**上の実力が要った（受験者50人の回では6.5点）。合格点より7.0点下の実力でも、1割の確率で受かった
- 受かる確率が1割〜9割のあいだにいる人（受かるか落ちるかが、その回しだいの人）は、受験者の31.76%だった（受験者50人の回では35.27%）

### 合格点そのものの振れ（100問）
| 1回の受験者 | 合格点の分布 |
|---|---|
| 2,000人 | 61点 0.08%・62点 21.12%・63点 73.55%・64点 5.25% |
| 50人 | 1割目の回 60点〜9割目の回 66点 |

- 受験者が2,000人いると、合格点は62〜63点でほぼ決まった。受験者が50人の社内試験では、同じ実力の受験者の集まりでも、合格点が回によって60〜66点（10〜90%の回）動いた。そのぶん、実力の高い人も落ちやすく、低い人も受かりやすくなった（上の表）

### 確かめ：問題数・実力の散らばり・合格率・受験者数を変えると（72通り）
| 合格率 | ①実力が合格点と同じ人が受かる確率 | ②実力の順でちょうどの人が受かる確率 | 9割受かるのに要る実力（合格点より上） |
|---|---|---|---|
| 10% | 50.62〜71.11% | 32.63〜49.27% | 3.4〜11.4点 |
| 30% | **50.31〜67.15%** | **46.64〜54.48%** | **3.9〜12.9点** |
| 50% | 51.26〜59.18% | 47.28〜60.91% | 4.05〜13.15点 |

- ①はどの置き方でも50%以上だった。合格点ちょうどの得点でも受かるためで、問題数が少ない（1問の重みが大きい）ほど、ちょうどの得点を取る確率が大きく、受かる確率は半分より大きくずれた
- ②は合格率で向きが変わった。合格率10%の試験では、実力の順で上から10%ちょうどの人が受かるのは32.63〜49.27%と半分を下回った。得点の散らばりが実力より大きいぶん、得点の上から10%目は実力の上から10%目よりはっきり上に来るため
- 9割受かるのに要る実力は、問題数で大きく動いた（合格率30%・受験者2,000人で、20問なら10.1〜12.9点、200問なら3.9〜4.4点）
- 受かる確率が1割〜9割の人の割合は、合格率30%の36通りで16.14〜88.24%だった。問題数が少なく実力の散らばりが小さい試験ほど、受験者の多くが「その回しだい」になった
- 全72通りの値は `results/robustness.csv`

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約15秒）
- 図3枚を開き、日本語・重なり・軸を確かめた
- 合格点を固定したとき、実力が合格点ちょうどの人が受かる確率（54.47%）は二項分布の式の値そのもので、ちょうど合格点を取る確率（8.24%）のおよそ半分だけ50%を上回る、という理屈と合う
- 実力を合格点の0.5点下に置くと、受かる確率は50.34%とほぼ半分になった

## 注意（言えないこと）
- 架空のデータです。実力の分布、問題数、1問ずつ実力の確率で正解すること（問題どうしが互いに関係しないこと）は作成者が置いたもので、結果はこれで決まります。実力が合格点ちょうどの人が受かる確率は、置き方で50.31〜67.15%（合格率30%）と動きました
- 主な結果の多くは二項分布の式の値です。この記事で新しく数えたのは、上から30%目で決まる合格点が回ごとに動くことの効き方と、「ちょうど」の決め方の違い、9割受かるのに要る実力の幅です
- 問題の難しさの違い、得意・不得意の分野、当日の調子の上下は入れていません。これらが入ると、1回の得点はもっと上下し、9割受かるのに要る実力はもっと大きくなると考えられます（推測）
- 実在の試験の合格点の決め方や、合格の見込みを表すものではありません。どう勉強すればよいか、どの講座がよいかは言えません
