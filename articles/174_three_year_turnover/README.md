# 174 「3年で3割辞める」は本当に30年変わらなかったのか：新規学卒就職者の離職状況

厚生労働省「新規学卒就職者の離職状況」の「新規学校卒業就職者の在職期間別離職状況」（1996〜2023年3月卒、学歴別）を使ったフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A174 | 就職後3年以内の離職率は30年でどう動いたか。何年目に辞める人が多いか | 卒業年ごとの推移、1〜3年目の内訳、最初の会社に残る割合の曲線（卒業年コホート別） | `src/a174_turnover.py` |

## 主な結果
- 大卒の3年以内離職率は28年間の平均33.0%で、28年中27年が30%以上（最小は2009年3月卒の28.8%、最大は2004年3月卒の36.6%）。「3年で3割」は大卒ではほぼ変わっていない
- 高卒は2000年3月卒の50.3%から下がり、2016年以降の平均は37.7%。短大等は40〜45%でほぼ横ばい
- 大卒の1年目の離職率は14.1%（1996年3月卒）→11.0%（2023年3月卒）に下がり、3年目は8.5%→9.3%。辞める時期が少し後ろにずれた
- 3年後に最初の会社に残っている割合は、高卒が52%（1996年3月卒）→63%（2023年3月卒）、大卒が66%→69%

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a174_turnover.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/turnover_by_education.csv | 卒業年（3月卒）、学歴（高校・短大等・大学）、3年以内の離職率と1年目・2年目・3年目の離職率（%） |

元の表：厚生労働省「新規学卒就職者の離職状況」のページの「［表］新規学校卒業就職者の在職期間別離職状況」（PDF、https://www.mhlw.go.jp/content/11800000/001318985.pdf）から書き写した。1〜3年目の合計が3年以内の値と一致することを確認している（四捨五入の差を除く）。

## 注意
- 離職率は、雇用保険の加入記録から「新規学卒者と推定される人」を数えたもの。転職先の会社に移った人も、職を離れた人も同じ「離職」になる
- 2024年3月卒と2025年3月卒は3年たっていないので使っていない
- 中卒は人数が少ないので図に入れていない
- 「就職した年の景気」との関係はこのフォルダでは調べていない
