# F288 計画（分析の前に書く）

## 問い
損害額の分布の「裾の重さ」（大きな損害がどれだけ出やすいか）は、手元の損害の件数がいくつあれば見分けられるのか。

誰が知りたいか：損害保険・再保険の料率やリスク管理の担当、保険数理の担当、「この損害の分布は裾が重い」という報告を読む人。F260 では、15事故に5つの分布を当てはめると合い方が同じなのに100年に1度の額が大きく違い、パレートの形の値（α=0.81、平均が無限大）まで出た。F260 は「記録が何年あれば100年に1度の額が絞れるか」を見た。F288 は額ではなく、**裾の形そのもの（裾の指数 ξ、分布の種類、平均が有限か）を件数 n でどこまで見分けられるか**を、本当の答えが分かるシミュレーションで測る。

## データ
シミュレーションだけ（取得なし）。しきい値を超えた分の損害（超過額 Y > 0）を、次の「本当の分布」から n 件作る。尺度は中央値が1になるようにそろえる（裾の形だけを比べるため）。
- 指数分布（ξ=0、裾が軽い基準）
- ワイブル分布 形0.6（ξ=0 だが指数より重い）
- 対数正規分布 σ=1.0・1.5（ξ=0 だが、少ない件数では裾が重く見えやすい）
- 一般化パレート分布（GPD）ξ=0.2・0.4・0.6・0.8（裾が重い。ξ≥1 なら平均が無限大）

件数 n：10・15・20・30・50・100・200・500・1000。各組み合わせ 500回（乱数の種 288）。

## 手法
- 当てはめる分布：指数・ワイブル・対数正規・GPD の4つ（どれも最尤法、超過額 Y に直接）。
- 裾が重いかの検定：GPD 対 指数の尤度比検定（ξ=0 が境界なので、片側5%の臨界値 2.706）。「重い」と判定された割合を数える。
- 裾の指数の推定：GPD の最尤推定 ξ̂。各 n で 5%点・95%点、平均二乗誤差。
- 分布の選択：4つのうち AIC が最小のものを選び、本当の分布を選べた割合。
- 平均が無限大に見える割合：ξ̂ ≥ 1 になった割合。

## 仮説と「外れ」の基準
- H1：ξ=0.4 の GPD で、尤度比検定が「重い」と判定する割合（検出力）は n=50 では80%に届かない。→ n=50 で80%以上なら外れ。
- H2：対数正規 σ=1.5（本当は ξ=0）でも、n=100 で「重い」と判定される割合は50%以上。→ 50%未満なら外れ。
- H3：n=30 では、GPD ξ=0.4 と対数正規 σ=1.5 のどちらが本当でも、AIC で本当の分布を選べる割合は50%未満。→ どちらかが50%以上なら外れ。
- H4：n=15、本当の ξ=0.5 の GPD で、ξ̂ ≥ 1（平均が無限大に見える）になる割合は10%以上。→ 10%未満なら外れ。（ξ=0.5 は格子にないので、この仮説のために ξ=0.5 も作る）
- H5：ξ=0.4 の GPD で、ξ̂ の 5〜95%の幅が真の値の ±0.15 に収まるには n ≥ 200 が要る。→ 200 未満で収まれば外れ。

## 頑健性（少なくとも3つ）
- R1：検定の水準を10%に、選択を BIC に替える。
- R2：推定を確率加重モーメント法（PWM、Hosking–Wallis）に替えて H4・H5 を見直す。
- R3：乱数の種を変える（別の種で全体をもう1回）。
- R4：超過額を「対数正規 σ=1.5 の損害の上位20%・10%・5%」として作る（しきい値を本当の分布の分位点に置く、実務の peaks-over-threshold に近い形）。
- R5：要の組み合わせ（H1・H2・H4）を 2,000回に増やす。
