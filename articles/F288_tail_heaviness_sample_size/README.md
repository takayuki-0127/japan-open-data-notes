# F288 損害額の分布の「裾の重さ」は、データの量でどこまで見分けられるか（シミュレーション）

note 記事「損害額の分布の「裾の重さ」は、データの量でどこまで見分けられるか？」のコード・結果・図です。

## 問い

損害の分布の「裾の重さ」（まれに出る大きな損害がどれだけ出やすいか）は、手元の損害の件数がいくつあれば見分けられるのか。見分けたいのは次の3つ。

- 裾が重いか軽いか（一般化パレート分布 GPD の裾の指数 ξ が0より大きいか）
- 裾の指数 ξ の大きさ
- 分布の種類（指数・ワイブル・対数正規・GPD のどれか）と、平均が有限か（ξ<1 か）

誰が知りたいか：損害保険・再保険の料率やリスク管理の担当、保険数理の担当、「この損害は裾が重い」という報告を読む人。F260 では15事故に5つの分布を当てはめると合い方が同じで、パレート（平均が無限大になる形）まで出た。F260 は「100年に1度の額」が記録の年数でどう絞れるかを見たが、F288 は額ではなく**裾の形そのもの**を、件数 n でどこまで見分けられるかを、本当の答えが分かるシミュレーションで測った。

計画（仮説・手法・頑健性・外れの基準）は分析の前に [PLAN.md](PLAN.md) としてコミットした（コミット d937e18、メッセージ "plan"）。シミュレーションなので、計画の前に見た結果はない。コード・結果はすべてこの後のコミット。

## 結論

1. **裾が重い GPD（ξ=0.4）でも、「重い」と判定できるのは50件で7割、100件で9割（H1 支持）**。15件23%、50件70.8%（±2.0%）、100件91%。8割の境目は補間で約70件。ξ=0.2 なら約200件、ξ=0.8 でも約26件要る。
2. **理論上は ξ=0（平均も分散も有限）だが指数よりは重い対数正規（σ=1.5）やワイブル（形0.6）は、件数が限られると GPD 型と見分けられない（H2 支持）**。30件で8割以上が「重い」と判定される。検定の誤りではなく、「重い」をパレートのような裾と読むと誤解を招く、ということ。対数正規の ξ が0に近づくのはしきい値を限りなく上げたときだけで、その近づき方は非常に遅い。上位5%だけを使っても、推定 ξ は1,000件で0.44のまま（R4）。
3. **15件では、本当が裾の重い GPD でも1割しか GPD と当たらない（H3 は外れ）**。本当が GPD ξ=0.4 なら選べたのは15件で10%、30件で21.4%（±1.8%）で、15件では49%が指数を選んだ。本当が対数正規 σ=1.5 なら30件で68.2%（±2.1%）、15件でも対数正規・ワイブル・指数は54〜57%当たった。計画の「どちらも50%未満」は外れ。
4. **15件で本当の ξ=0.5 のとき、推定 ξ が1以上（平均が無限大に見える）になるのは7.6%（±1.2%、2,000回で7.45±0.6%。H4 は外れ、計画の基準は10%以上）**。ただし本当がワイブル 形0.6 なら15件で32%、対数正規 σ=1.5 で13%、GPD ξ=0.8 で23%が「平均が無限大」に見えた。
5. **推定 ξ の5〜95%の幅を本当の値の±0.15に収めるには、ξ=0.4 で200件でほぼ届き、確実に収まるのは500件（H5 支持）**。200件では 0.248〜0.554 で、上下とも0.005ほど外（500回のぶれは0.01ほど）。
6. **問い直し（結果を見てから足した）：F260 のような15件の結果（4つの AIC の差が2未満、推定 ξ が0.47前後）は、どの本当の分布からも出る**。出る割合は対数正規 σ=1.5 で8.6%（±1.3%）、GPD ξ=0.2〜0.8 で4.0〜7.2%、ワイブル 4.8%、指数 3.2%（±0.8%）、対数正規 σ=1.0 で1.4%（±0.5%）。対数正規 σ=1.0 を除けば差は3倍以内（含めると6倍）で、15件の結果から裾の形を決めることはほとんどできない。

## 手法

- **本当の分布**：しきい値を超えた分の損害（超過額 Y）を、指数（ξ=0）、ワイブル 形0.6、対数正規 σ=1.0・1.5（どれも本当は ξ=0）、GPD ξ=0.2・0.4・0.5・0.6・0.8 から作った。尺度は中央値1にそろえた（裾の形だけを比べるため）。
- **件数**：n=10・15・20・30・50・100・200・500・1000。各組み合わせ500回（乱数の種288）。
- **当てはめ**：指数・ワイブル・対数正規・GPD の4つを、超過額 Y に最尤法で当てはめた。GPD は θ=ξ/σ のプロファイル尤度を格子で探した（`zz_f288_common.py`。scipy の `genpareto.fit` と小数2桁で一致を確認）。ξ<−1 では尤度が上に有界でなく最尤推定が存在しないため、θ の下限を −0.999/最大値 に置いた。下限に張り付いた回（`gpd_bound`）は n=10 で19.2%、15件で4.5%（本当が指数なら12.2%）、20件で1.3%、30件で0.2%、50件以上で0%。
- **裾が重いかの検定**：GPD 対 指数の尤度比検定。ξ=0 は GPD のパラメータの範囲の内側の点なので、統計量は近似的に χ²(1)。「ξ>0 か」だけを見る片側検定（符号つきの尤度比）にし、片側5%の臨界値は2.706（χ²(1) の上側10%点）。推定 ξ>0 かつ統計量>2.706 を「重い」とした。指数が本当のときに「重い」と判定した割合（検定の大きさ）は 1.4〜4.6% で、5%よりやや控えめ。
- **分布の選択**：4つの AIC を比べて最小のものを選び、本当の分布の種類（GPD ξ の値は問わない）と一致した割合。
- **平均が無限大に見える割合**：推定 ξ ≥ 1 の割合。

## 仮説の判定（PLAN の基準どおり）

|---|---|---|---|

| H2 対数正規 σ=1.5、n=100 で「重い」が50%以上 | 50%未満なら外れ | 99.8% | 支持 |
| H3 n=30 で GPD ξ=0.4・対数正規 σ=1.5 のどちらも、本当の分布を選べる割合は50%未満 | どちらかが50%以上なら外れ | GPD 21.4%、対数正規 68.2% | **外れ** |
| H4 n=15、ξ=0.5 で推定 ξ≥1 が10%以上 | 10%未満なら外れ | 7.6% | **外れ** |

## 頑健性

| 確かめ | H1 | H2 | H3（GPD／対数正規） | H4 | H5 |
|---|---|---|---|---|---|
| 本体（種288、500回） | 70.8% | 99.8% | 21.4%／68.2% | 7.6% | 500 |
| R1 検定10%（H1・H2）・BIC で選択（H3） | 76.0% | 100% | 16.8%／65.2% | 7.6% | 500 |
| R2 確率加重モーメント法（PWM） | — | — | — | （作りの上で ξ̂<1 のため確かめにならない） | 500 |
| 下限に張り付いた回を除く（レビュー後に追加） | 70.8% | 99.8% | 21.2%／68.2% | — | — |
| R3 種2881 | 68.8% | 99.8% | 19.6%／70.2% | 7.6% | 500 |

- **判定はどの条件でも同じ**（H1・H2・H5 支持、H3・H4 外れ）。
- **R2**：PWM の推定 ξ は作りの上で1未満（Hosking–Wallis）なので、H4 の確かめには数えない。H5 は PWM でも500件。
- **モンテカルロ誤差**：割合の標準誤差は H1 ±2.0%、H3 ±1.8%／±2.1%、H4 ±1.2%（R5 ±0.6%）、問い直し ±0.5〜1.3%（`main.json` の `mc_se`）。
- 計画にあった推定の平均二乗誤差は `E_table_seed288.csv` の `rmse` 列に載せた（本文には出していない）。
- 15件以下で GPD の推定が下限に張り付いた回では、AIC が GPD を選ぶ割合が77%と高い。この回を除くと、15件で GPD ξ=0.4 を正しく選べた割合は10.4%→8.2%、問い直しの「両方」は1.5〜8.8%（`main.json` の `excl_bound`）。
- **R4**：対数正規 σ=1.5 の損害の上位20%・10%・5%を超過額として使った（実務の「しきい値を超えた分だけを見る」形）。100件で「重い」と判定された割合は98.6%・97.0%・94.4%、1,000件での推定 ξ の中央値は0.52・0.47・0.44。しきい値を上げても見かけの ξ は0に近づくのが遅い。

## 問い直し（結果を見た後に追加）

F260 の15事故の結果（5つの分布の AIC の差が0.5以内、GPD の推定 ξ=0.47）と同じような結果が、どの本当の分布から出やすいかを、本体のシミュレーションの15件の回で数えた。条件は「4つの AIC の最大と最小の差が2未満」かつ「推定 ξ が0.37〜0.57」。

| 本当の分布 | AIC の差<2 | ξ̂ 0.37〜0.57 | 両方 |
|---|---|---|---|
| 対数正規 σ=1.5 | 25.6% | 17.0% | 8.6% |
| GPD ξ=0.8 | 19.4% | 13.4% | 7.2% |
| GPD ξ=0.4 | 27.2% | 13.0% | 7.0% |
| GPD ξ=0.5 | 22.8% | 14.6% | 6.2% |
| GPD ξ=0.6 | 21.6% | 15.6% | 4.8% |
| ワイブル 形0.6 | 10.2% | 13.6% | 4.8% |
| GPD ξ=0.2 | 26.8% | 9.0% | 4.0% |
| 指数 | 23.4% | 4.6% | 3.2% |
| 対数正規 σ=1.0 | 32.6% | 8.4% | 1.4% |

500回ずつなので、各割合の標準誤差は±0.5〜1.3ポイント（`main.json` の `mc_se`）。30件の同じ表は `results/H_reask_n15_n30.csv`。F260 とは条件が違う：F260 はパレートを含む5つの分布を、しきい値で切った形で当てはめ、AIC の差は0.5以内だった。ここでは4つの分布を超えた分に当てはめ、差2未満で数えている。

## 計画からのずれ

- 検定の大きさ（指数が本当のときに「重い」とした割合）は 1.4〜4.6% で、計画の5%より控えめに出た。少ない件数ほど控えめ。
- R2 の PWM は推定 ξ が作りの上で1未満なので、H4 の確かめにはならなかった。
- 問い直しは、結果を見た後に F260 との比較として決めた。

## 言えないこと

- シミュレーションで作った分布だけを比べている。実際の損害は、年ごとの物価・保険の加入の変化・集計の足切りなどで、ここより見分けにくくなりうる（推測）。
- 尺度（中央値）は分かっている前提ではなく、毎回推定している。しきい値の選び方そのもの（どこから上を「裾」とみるか）は R4 で一部を見ただけ。
- ξ<−1 側では最尤推定が存在しないため下限を置いた。15件以下の分布の選択・問い直しの数字はこの影響を受ける（除いた値を上に併記）。10件の推定の幅（図2の左端）も下限の影響を受けている。
- 4つの候補に入れていない分布（対数ロジスティック、ガンマなど）が本当なら、選択の結果は変わる。
- 料率・個人の保険の選び方・制度への提言は扱っていない。
