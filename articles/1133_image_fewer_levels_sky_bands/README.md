# 1133 色の段階を減らして保存すると、なめらかな空の明るさにどれだけ段ができるのか？（画像と色）

画像の明るさは、決まった段階の数（256段階など）のどれかに丸めて保存されます。空のように明るさが少しずつ変わる所では、丸めた値が同じになる画素が帯のように並び、帯の境目で明るさが1段ずつ跳ねます。段階の数を減らすと、帯は太く、1段は高くなります。**ここでは、作成者が式と乱数で作った架空の空の画像100枚（明るさだけ、縦1,000×横200画素、上から下へなめらかに明るくなる）を、256・64・32・16段階に丸めて保存し、段の数・段の幅・1段の高さ・本当の明るさとのずれを数えました。丸める前に細かいざらつきを足す保存のしかたとも比べ、もとの空のざらつき（写真のざらつきに見立てた）×ならして見る幅×段階の数の36通りでも確かめました。**

例の空はすべて作成者が式と乱数で作ったもので、実在の写真・カメラ・画像ソフトを表すものではありません。人に見比べてもらうことはしていません。「離れて見たときのずれ」は、作成者が置いた見え方（縦横15画素の正方形の中をならして見る）で数えた値です。

関連する記事：949「色分けの区切り（等間隔・同じ件数）で、地図の印象はどう変わるのか？」は、数字を何段階かの色に分けるときの区切り方を、1048「途中の数字を1桁に丸めて計算すると、答えは何倍まで外れるのか？」は、丸めのずれを扱っています。この記事は、画像の明るさを決まった段階に丸めたときにできる帯と、丸める前にざらつきを足したときの見え方のずれに絞ります。同じ企画の 1136「明るい所と暗い所を1枚に収める処理で、明るさの順番は入れかわるのか？」は、明るい所と暗い所を256段階に収めたとき、違う明るさが同じ段階につぶれたり明るさの順が入れかわったりすることを扱っています。1131「圧縮して保存し直すことを10回くり返すと、元の画像との差はどれだけ積み重なるのか？」は、圧縮の丸めを保存のたびにくり返したときのずれの積み重なりを扱っています。

## 主な結果

### 段階の数ごとの段とずれ（100枚の平均、`results/levels_base.csv`）
| 段階の数 | 1段の高さ（0〜255） | 段の数 | 段の幅（画素、100枚の範囲） | ずれの二乗平均の平方根（そのまま／ざらつきを足す） | 15画素でならして見たずれの最大（そのまま／ざらつきを足す） | ざらつきを足したときの比 |
|---|---|---|---|---|---|---|
| 256 | 1.0 | 77.5 | 13.4（9.7〜19.2） | 0.291／0.41 | 0.268／0.166 | **0.619倍** |
| 64 | 4.048 | 19.9 | 52.2（38.5〜76.9） | 1.167／1.651 | 1.672／0.582 | **0.348倍** |
| 32 | 8.226 | 10.2 | 101.3（76.9〜142.9） | 2.366／3.353 | 3.703／1.133 | 0.306倍 |
| 16 | 17.0 | 5.5 | 188.6（142.9〜250.0） | 4.896／6.934 | 8.054／2.333 | **0.29倍** |

- **段の数は、空の明るさの幅×（段階の数−1）＋1でほぼ決まった（式どおり）**。256段階でも、明るさの幅0.2〜0.4の空では使える段は77.5段で、縦1,000画素の空に幅13.4画素の帯が並んだ。64段階では19.9段・幅52.2画素、16段階では5.5段・幅188.6画素（式の値は77.6・19.9・10.3・5.5段）
- **画素ごとのずれ（二乗平均の平方根）は、1段の高さ÷√12の式どおりだった**（256段階で0.291、式0.289）
- **ならして見たずれの最大は、そのまま丸めると1段の0.268〜0.474倍だった**。段の幅がならす幅（15画素）より太いほど、帯の境目の跳ねがならしても残り、1段の半分に近づいた（256段階0.268倍、16段階0.474倍）
- **丸める前にざらつきを足すと、画素ごとのずれは√2倍に大きくなる（1段÷√6、式どおり）のに、ならして見たずれは0.29〜0.619倍に小さくなった**。帯の境目がざらつきで細かく入りまじり、ならすと本当の明るさに近づくため。中央の列で値が変わる所は、64段階でそのまま18.9か所に対し、ざらつきを足すと332.0か所だった
- 段階の数が少ないほど、ざらつきを足して減る割合は大きかった（256段階0.619倍、16段階0.29倍）

### 確かめ：もとの空のざらつき×ならす幅×段階の数（36通り、各30枚、`results/grid.csv`）
| 段階の数 | ざらつきを足したときの比（12通りの範囲） |
|---|---|
| 256 | 0.787〜1.13倍 |
| 64 | 0.275〜1.12倍 |
| 32 | 0.138〜1.099倍 |
| 16 | 0.103〜0.971倍 |

- **ざらつきを足して減るのは、もとの空がなめらかなときだった**。もとの空にざらつき（標準偏差0.51）があると、256段階では足しても減らず、1.08〜1.13倍とわずかに増えた。もとの空のざらつきが、すでに帯の境目を入りまじらせているため。ざらつき2.04では、64段階でも1.081〜1.12倍だった
- もとの空にざらつき0.51があると、256段階でそのまま丸めたときのならして見たずれ（15画素で0.171）は、丸めないとき（0.149）に近かった
- ならす幅が5画素と狭いと、ざらつきを足しても0.868〜1.099倍とほとんど減らなかった。45画素と広いと、16段階で0.103倍まで減った
- 36通りのうち、ざらつきを足して増えたのは、もとの空にざらつきがあるか、ならす幅が5画素の通りだけだった（最大1.13倍）
- 確かめの値は空30枚の平均で、上の表（100枚）とは少し違う（たとえば256段階・ざらつき0・15画素で0.325／0.256）

## データ
- `data/skies_measured.csv`：空100枚×段階の数4つ×そのまま・ざらつきの記録（sky・span（明るさの幅）・levels・dither（1＝ざらつきを足す）・step（1段の高さ、0〜1）・band_width_px・n_levels_used（使われた段の数）・changes_mid_column（中央の列で値が変わる所の数）・rmse・blur_max_dev・blur_rmse（0〜1の目盛り））
- `results/a1133_main.json`：主な結果すべて（置いた設定、段階の数ごとの表、36通りの範囲（段階の数ごと・ならす幅ごと・もとの空のざらつきごと））
- `results/levels_base.csv`：段階の数ごとの表（_255 の列は0〜255の目盛り、in_steps の列は1段を1とした値）
- `results/grid.csv`：36通り（noise_sd_255 もとの空のざらつき、blur_px ならす幅、no_rounding_blur_max_dev_255 丸めないときのならして見たずれ）

## 注意（言えないこと）
- 架空のデータです。空の明るさの形、画像の大きさ、ざらつきの足し方、見え方（15画素の正方形でならす）は作成者が置いたもので、結果はこれで決まります。段の数と画素ごとのずれは式どおりです
- 「ならして見たずれ」は作成者が置いた見え方の式で、人が段を見分けられるかどうかを表すものではありません。人に見比べてもらうことはしていません
- 明るさだけを扱いました。色の3つの成分を別々に丸めると、帯の境目で色合いも変わることがありますが、数えていません
- 保存のときの圧縮は入れていません。圧縮すると、ざらつきが消されて帯が戻ることがあります（推測）
- どの段階の数で保存すべきかは言えません
