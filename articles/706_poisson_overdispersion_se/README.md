# 706 件数のデータにばらつきの大きさを考えずポアソン回帰を使うと、効果が0でも何%で「有意」になるのか（手法の解説・正解の分かるデータで試す）

ポアソン回帰は「分散＝平均」を前提に標準誤差を出します。実際の件数データは、店ごとの事情などで分散が平均より大きい（過分散）ことが多く、そのまま使うと標準誤差が小さく出て、差がなくても「有意」になりやすくなります。**ここでは、架空の200店（半分が施策あり、施策の効果は0）の1か月の件数（平均5件）を負の二項分布で作り、過分散の大きさ α を0〜2で変えて各2,000回、4つの標準誤差で施策の係数を検定しました。** 数字は置いた前提で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A706 | 過分散があるとき、ポアソン回帰の検定は何%で偽の有意を出すか | ポアソン回帰、準ポアソン（ピアソンの χ² で膨らます）、負の二項（α をモーメント法で推定）、頑健な標準誤差（HC0）。α=0〜2、各2,000回。式で出した値が statsmodels の GLM と一致することを確認。seed 706 | `src/a706_overdispersion.py` |

## 主な結果
- **ポアソン回帰の偽の有意**：α=0（本当にポアソン）で5.2%。α=0.25（分散が平均の2.25倍）で17.8%、**α=1（6倍）で43.3%**、α=2（11倍）で54.3%
- **標準誤差の小ささ**：ポアソンの標準誤差は本当のばらつきの、α=0.25 で0.68倍、α=1 で0.41倍、α=2 で0.31倍
- **直し方はどれも効く**：準ポアソン・負の二項・頑健な標準誤差は、どの α でも偽の有意が4.3〜5.6%、標準誤差の比は0.99〜1.01
- 推定値（施策の係数）そのものは4つとも同じ。違うのは標準誤差だけ

## 動かし方
```
pip install -r requirements.txt
cd src && python a706_overdispersion.py
```
十秒ほどで終わります。

## 確かめたこと
- 空のフォルダで流し直し、results・figures がバイト単位で一致した
- 説明変数が施策の有無だけなので、推定値と4つの標準誤差は式で出した。1回分を statsmodels の GLM（Poisson、scale="X2"、cov_type="HC0"、NegativeBinomial）と比べて一致した
- α=0 では4つとも偽の有意が約5%で、検定の作りが正しいことを確かめた

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 706）
- 仮定：200店、平均5件、施策ありとなしで同じ平均（効果0）。件数はガンマ分布で平均を揺らしたポアソン（負の二項分布）

## 注意（言えないこと）
- シミュレーションの結果。過分散の大きさと店の数は作成者が置いたもので、結果はこれで決まる
- 説明変数が1つの単純な形だけを試した。変数の多いモデルや件数の少ない場合は、直し方の効き方が変わることがある
