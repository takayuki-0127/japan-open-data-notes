## もとのリポジトリの説明

以下は、もとのリポジトリ `jma-phenology` の README です（同じリポジトリにあったほかの記事の分も含みます）。

### jma-phenology：気象庁の生物季節観測（1953〜2025年）で、さくら・紅葉の時期の変化と、記録されなくなった生き物を調べる

気象庁「生物季節観測」の累年値ファイル（植物41種目・動物24種目、地点×年の観測日）を使ったリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| S1 | うめ・さくらの開花、いちょうの黄葉、かえでの紅葉は、どれだけ早く・遅くなったか。気温が1℃高いと何日ずれるか | 地点ごとのTheil–Sen推定、地点固定効果つきの回帰（年トレンド・気温、年でクラスター頑健標準誤差）、1961〜1990年と1996〜2025年の平均の差、地点の緯度と気温への反応 | `src/s1_plants.py` |
| S2 | 動物の初鳴・初見（うぐいす・つばめ・ほたる・とのさまがえるなど12種目）は、どれだけ記録されなくなったか。日付は変わったか | 記録があった地点数の推移（さくらの開花と比べる）、観測期間中に記録がなかった年の割合、地点固定効果つきの回帰 | `src/s2_animals.py` |

#### 主な結果
- **S1**：地点の違いをそろえた10年あたりの変化は、さくらの開花−1.1日（95%信頼区間−1.5〜−0.7日）、満開−1.0日、うめの開花−0.8日（−1.7〜+0.1日、はっきりしない）、いちょうの黄葉+2.5日、かえでの紅葉+3.1日。1961〜1990年の平均と1996〜2025年の平均の差は、さくらの開花−4.8日、満開−4.2日、うめ−4.5日、いちょう+8.5日、かえで+10.7日。30年以上観測した地点のうち、さくらの開花が早まった地点は88%、かえでの紅葉が早まった地点は3%。気温が1℃高い年は、うめの開花が7.4日、さくらの開花・満開が4.1日早く、いちょうの黄葉が5.9日、かえでの紅葉が7.2日遅い。さくらの開花日（地点平均の平年差）と2〜3月の気温の相関は−0.89。北の地点ほどさくらの開花が気温によく反応する（緯度との相関−0.46）
- **S2**：記録があった地点数は、1971〜1990年平均→2011〜2020年平均で、多くの種目が35〜48%減った。同じ期間に、さくらの開花の記録地点数も41%減っており（測候所の無人化などで観測地点そのものが減ったため）、多くの種目の減少はこれと同じくらい。その中で、とのさまがえるの初見は46地点→5.3地点（−88%）と大きく減り、観測期間中に記録がなかった年の割合も1960年代27%→2010年代45%に上がった。日付は、とのさまがえるの初見（10年あたり+4.3日）としおからとんぼの初見（+3.7日）が遅くなり、あぶらぜみの初鳴（−0.7日）は早まった

#### データ
| ファイル | 中身 |
|---|---|
| data/raw/001.csv〜119.csv | 生物季節観測累年値（種目ごと、地点×年の観測日。値はMMDD、0は観測なし。各年の右の列はrm） |
| data/raw/mon_jpn.csv | 日本の月平均気温偏差（1898年〜、1991〜2020年平均との差、都市化の影響が少ない15地点の平均） |

#### 注意
- 気象庁は2020年末で動物の観測をすべて、植物も多くの種目をやめ、2021年以降はうめ・さくら・あじさい・すすき・いちょう・かえでの6種目だけを続けています。また2000年代後半に、測候所の無人化などで観測地点が約80から約50に減っています
- さくらは、rm（リマーク）が6・7の値を除きました。6・7は主に北海道・沖縄・離島の地点で使われており、ソメイヨシノ以外（エゾヤマザクラ・ヒカンザクラなど）を観測した値と考えられます（rmの意味はファイルの説明書に照らして確かめていません）
- 年をまたぐ日付は、種目のふつうの時期に合わせて前後の年に寄せています（例：かえでの紅葉が1月なら前年の続き）
- 地点の緯度は、気象台・測候所の所在地のおおよその値（小数1桁）を手で入れたものです
- 「記録なし」は、その年に見つからなかった場合と、観測しなかった場合の両方を含みます。動物の初鳴・初見は観測者や周りの環境（都市化）にも左右されるので、生き物そのものの数の変化とは限りません
- 全国の気温は15地点の平均で、各地点の気温ではありません
