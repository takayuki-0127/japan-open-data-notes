# 01 取得の手順

e-Stat の統計表の一覧を取る API（getStatsList）にはアプリケーションIDの登録が要るので、この記事ではサイトの「統計データを探す → ファイル」の一覧ページ（データセット表示、1ページ50件）をブラウザでたどった。

1. ブラウザで https://www.e-stat.go.jp/ を開く
2. 開発者ツールのコンソールに `01_取得_browser.js` を貼り付けて実行する。公開（更新）年月 2026年1月〜10月の一覧を順にたどる（`/stat-search/files?layout=dataset&page=N&open_date=YYYYMM`）。1ページごとに1秒あけ、実測で全896ページ・約40分
3. ダウンロードされた `estat_files_2026.json` を gzip して `data/raw/estat_files_2026.json.gz` に置く

取得日：2026年10月28日。この時点の e-Stat のファイルは全体で 1,494,286 件、うち 2026年1〜10月に公開・更新されたのが 44,533 件（ひと月ごとの件数はサイトの絞り込みの件数と一致）。

## 取り直した表題（title_fix.json）

最初の取得では、データベース（DB）へのリンクもある表で、表題を取りこぼした（DB へのリンクにも `stat_infid` が入っていて、先にそちらを拾ったため。1,232 件、労働力調査・国民経済計算など）。該当する161ページだけを、表題のリンク（`a.js-data`）を読む形で取り直し、`data/raw/title_fix.json`（id → 表題）に保存した。`01_取得_browser.js` は修正後の読み方になっている。

## 埋め込みモデル

`cl-nagoya/ruri-v3-30m` と `cl-nagoya/ruri-v3-70m`（どちらも Apache-2.0）を Hugging Face から取る。ネットにつながらない環境では、手元に置いたフォルダを環境変数 `RURI30_PATH`・`RURI70_PATH` で指定する。
