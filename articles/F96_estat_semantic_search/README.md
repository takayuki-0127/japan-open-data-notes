# F96 e-Stat の数万の統計表から、欲しい表をすぐ探せるか？ 表題の文埋め込みによる意味検索と、検索精度の評価

## 問い

e-Stat には 149万件のファイル（統計表）がある。欲しい表を探すとき、サイトの検索は「表題に入っている言葉」で探すので、統計の言葉（「完全失業率」「被保護実世帯数」「所定外労働時間」）を知らないと見つけにくい。表題を文埋め込み（文の意味を数字のベクトルにしたもの）にして**意味の近さで探す**と、日常の言葉で聞いても欲しい表にたどり着けるのか。単語の一致による検索と比べ、どれくらい当たるのかを、正解を決めた44件の「探しもの」で測った。

## データ

- **e-Stat「統計データを探す → ファイル」の一覧**（データセット表示）。2026年1〜10月に公開・更新されたファイル 44,533 件（e-Stat 全体 1,494,286 件の約3%）。取得日 2026-10-28。1件ごとに、政府統計名・提供統計名と提供分類（パス）・調査年月・公開日・表題・統計表ID を保存（`data/raw/estat_files_2026.json.gz`、取得の手順は `src/01_取得.md`）
- 同じ政府統計の同じ表題（毎月・毎年の更新）を1つにまとめ、**31,383 表・352 統計**を検索の対象にした（`data/tables.csv.gz`）。表題の長さの中央値は38文字
- 最初の取得で表題を取りこぼした 1,232 件は、該当ページだけ取り直して埋めた（`data/raw/title_fix.json`）

## 手法

1. **検索のしくみ（6通り）**（`src/engines.py`）。検索する文は「表題（政府統計名／提供統計名・分類）」
   - **キーワード全部一致**：質問を単語に分け（fugashi＋unidic-lite）、全部を含む表だけを並べる。サイトの表題検索に近い
   - **単語の一致（BM25）**：単語の重なりに、珍しい単語ほど重みをつけた点数
   - **文字の一致**：2〜3文字の並び（文字 n-gram）の TF-IDF。分かち書きに頼らない
   - **文埋め込み（ruri-v3-30m）**：日本語の文埋め込みモデル（256次元、F25 と同じ）。文書に「検索文書: 」、質問に「検索クエリ: 」を付け（モデルの説明どおり）、コサイン類似度で並べる
   - **文埋め込み（ruri-v3-70m）**：同じ系統の約2.5倍の大きさのモデル（384次元）
   - **組み合わせ**：BM25 と ruri-v3-30m の順位を Reciprocal Rank Fusion（k=60）で合わせる
2. **探しもの 44件 × 質問 3通り＝132問**（`src/queries.py`）。人口・労働・物価・経済・農林水産・健康福祉・教育の44件。同じ探しものに、①統計の言葉のキーワード（「完全失業率 年齢階級別」）、②統計の言葉の文（「年齢階級別の完全失業者数と完全失業率」）、③日常の言葉の文（「仕事を探しているのに見つからない人の割合を年代ごとに」）を用意した
3. **正解**：政府統計名が一致し、表題が決めた条件（正規表現）に合う表。正解の数は探しものごとに2〜808表（中央値 42.5、`results/rel_counts.csv`）。質問文と正解の条件は、表の一覧だけを見て、検索結果を見る前に決めた
4. **指標**：上位10件に正解が1つでも入る割合（Hit@10）、最初の正解の順位の逆数の平均（MRR）、nDCG@10。95%区間は探しもの単位のブートストラップ（2,000回、乱数の種 96）。手法の差は対応のあるブートストラップ

## 結果

上位10件に正解が入った割合（%）。`results/summary.csv`

| 手法 | キーワード（統計の言葉） | 文（統計の言葉） | 文（日常の言葉） |
|---|---|---|---|
| キーワード全部一致 | 93 | 84 | **0**（全問 0件） |
| 単語の一致（BM25） | 95 | 95 | 25（14〜39） |
| 文字の一致（2〜3文字） | 93 | 95 | 14 |
| 文埋め込み（ruri 30m） | 93 | 95 | **64（50〜77）** |
| 文埋め込み（ruri 70m） | 98 | 93 | 57 |
| 組み合わせ（BM25＋30m） | 95 | 95 | 48 |

1. **統計の言葉で聞けば、どの方法でもほぼ見つかる**。キーワードでも文でも、上位10件に正解が入るのは9割を超えた。最初の正解の順位（MRR）は BM25 が 0.94 と最も高く、文埋め込み（0.86）より上だった（文での差 −0.08、95%区間 −0.15〜−0.02）。言葉を知っている人には、単語の一致で十分
2. **日常の言葉では、単語の一致はほとんど役に立たない**。キーワード全部一致は 44問すべてで 0件（「赤ちゃん」「歯みがき」はどの表題にもない）。BM25 は 25% で、文字の一致は 14%
3. **文埋め込みは日常の言葉で 64%**。BM25 との差は +39ポイント（95%区間 +25〜+52）。「1日に何回歯みがきをしているか」で歯科疾患実態調査の「歯をみがく頻度」が1〜3位、「県ごとに生まれた赤ちゃんの数」で人口動態調査の出生数が1位に出た（BM25 では45位）
4. **それでも3分の1は上位10件に出ない**。「日本全体で石油や電気をどれだけ作って使っているか」（エネルギーバランス表）、「県ごとの働いている人と仕事がない人の数」（労働力調査の都道府県別）は、30m・BM25・組み合わせのどれでも1000位までに出なかった（後者は 70m だと50位）。「物価を差し引くと、給料は増えているのか」では、正解の毎月勤労統計調査（実質賃金）より、別の統計の賃金の表（賃金引上げ等の実態に関する調査）が上に来た（7位）
5. **組み合わせは、日常の言葉では文埋め込みだけより下がった**（48%、差 −16ポイント、−27〜−7）。BM25 が日常の言葉で外れた表を上位に混ぜるため。統計の言葉の質問では MRR が少し上がる（+0.06）
6. **大きいモデル（70m）は、30m を上回らなかった**（日常の言葉 57%、差 −7ポイント、−20〜+7）。文書の埋め込みにかかる時間は 30m が約9分、70m が約21分（31,383 表、CPU 2コア）

## 頑健性

`results/robust_size.csv`・`robust_doctext.csv`・`stat_level.csv`、図4・図6

| 条件（日常の言葉、上位10件に正解） | 文埋め込み 30m | BM25 |
|---|---|---|
| 基本 | 64% | 25% |
| 埋め込みモデルを 70m に | 57% | — |
| 接頭辞（検索クエリ:／検索文書:）なし | 52% | — |
| 文書を表題だけに（統計名・分類を入れない） | 52% | 20% |
| 正解をゆるく（正しい政府統計の表なら可） | 80% | 32% |
| 対象を 5,556 表に間引く（正解以外を5%に） | 88% | 48% |

- **件数**：正解以外の表を間引くと、日常の言葉での当たりは大きく上がる（30m：5,556表で 88% → 31,383表で 64%、BM25：48% → 25%）。統計の言葉では件数を変えてもほぼ 95〜100% のまま。e-Stat 全体（149万件）ではさらに下がると考えられる（推測。今回は測っていない）
- **埋め込みモデル**：70m でも、接頭辞を外しても、文書を表題だけにしても、BM25 との差は残った。接頭辞を外すと上位10件の当たりは下がる（−11ポイント、0〜−23）が、MRR は少し上がった（0.36 → 0.40、区間は0をまたぐ）
- **質問の作り方**：結果1〜3のとおり、質問に統計の言葉が入るかどうかが、手法の違いよりずっと大きく効く
- **正解の決め方**：表題の条件を外し「正しい政府統計の表なら正解」とすると、30m は 80%、70m は 82%、BM25 は 32%。外れた質問の多くは「近いが別の表」を返している（例：実質賃金 → 賃金改定の表）

## 言えないこと

- **e-Stat 全体の検索精度ではない**。対象は2026年1〜10月に公開・更新された表（全体の約3%）で、件数が増えるほど当たりにくくなる（頑健性）。全体を対象にすれば、今回の数字より下がると考えられる（推測）
- **正解は表題の言葉で決めた**。そのため、言葉が一致する手法（BM25）にやや有利で、別の統計の「使える表」は外れに数えている（ゆるい正解では差が広がる）
- **質問は1人（筆者）が作った44件**で、実際の利用者の質問の分布とは違う。統計の言葉の質問は表題を見て作ったので、当たりやすさは実際より高めに出ている可能性がある
- **e-Stat のサイトの検索そのものは使っていない**。「キーワード全部一致」はサイトの表題検索に近い動きを手元で再現したもので、サイトの並べ方や絞り込みとは同じではない
- **表の中身（数字や列の見出し）は見ていない**。表題・統計名・分類だけで探しているので、表題に出てこない項目は見つからない
- 埋め込みモデルは2つ（同じ系統の 30m と 70m）だけで、ほかのモデルや、質問を書き換えてから探す方法（生成AIで統計の言葉に言い換えるなど）は試していない
