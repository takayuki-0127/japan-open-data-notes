# 164 学習塾の売上は、少子化でも伸びていたのか：特定サービス産業動態統計調査（2004〜2024年）

経済産業省「特定サービス産業動態統計調査」の長期データ（学習塾、年計）から、売上高・受講生数・講師数などを、公表の前年比をつないだ指数にして比べ、売上高のトレンド回帰で2020年以降を確かめたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A164 | 学習塾の売上は、受講生が減っても伸びていたのか | 調査対象の追加による段差を除くため前年比（調整済み）をつないだ指数（2004年＝100）、log(売上指数)の線形トレンド回帰（2012〜2019年）と2020〜2024年の外挿、受講生1人当たり受講料収入 | `src/a164_juku.py` |

## 主な結果
- 売上高の指数は 2004年 100 → 2019年 132 → 2024年 136。年平均の伸びは 2004〜12年 2.9%、2012〜19年 0.8%、2019〜24年 0.6%
- 2012〜2019年のトレンド（年0.9%増、R²=0.93）に対し、2020年は 94% に落ちたが、2021年 101%、2024年 99% とほぼトレンドに戻った
- 受講生数の指数は 2018年 126 をピークに 2024年 114。2019→2024年で −8.9%（年 −1.8%）
- 受講生1人当たり受講料収入の指数は 2019年 107 → 2024年 121。売上の伸びは「1人当たり」で支えられていた
- 非常勤講師の指数は 164、専任講師は 106、事業所数は 131（2024年）

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a164_juku.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/juku_annual_level.csv | 年計の実数：売上高（合計・受講料収入・教材料売上高、百万円）、受講生数、事業所数、従業者数（正社員・パート等）、講師数（専任・非常勤） |
| data/juku_annual_growth.csv | 同じ項目の前年比（%、調査対象の追加による不連続を調整した公表値） |

経済産業省「長期データ」のページ（https://www.meti.go.jp/statistics/tyo/tokusabido/result/result_1.html）の Excel「19．学習塾」の「年・実数」「年・伸び率」シートをブラウザで読み、書き写しました。

## 注意
- 2011年7月、2012年1月、2015年1月、2020年7月に調査対象が追加されたため、実数は不連続です（例：2020→2021年の売上は実数で+17%ですが、調整した前年比は+9.1%）。分析は前年比をつないだ指数で行い、実数は参考として置いています
- 調査は一定規模以上の事業者を対象とした標本調査で、業界全体の売上の合計ではありません
- 子どもの人口は入れていません。「少子化」は受講生数の動きで見ています
- 受講生1人当たり受講料収入＝受講料収入の指数÷受講生数の指数で、値上げ・授業数の増加・個別指導化などを区別できません
