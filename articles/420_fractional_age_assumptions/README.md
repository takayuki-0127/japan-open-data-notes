# 420 1年より短い期間の死亡率は、仮定の置き方でどれだけ違うのか（手法の解説）

1年ごとの死亡率しかない生命表から、月ごとの死亡率を作るときの3つの仮定で、**月払いの年金と保険の現在価値がどれだけ変わるか**を測ったフォルダです。公表の生命表での仮定どうしの差と、正解の分かる死亡率（死亡の強さがなめらかに上がる形）での正解との差の、両方を出しました。F268（生命表と年金の現価）とは別で、1年未満の仮定を扱います。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A420 | 1年の中の亡くなり方の仮定で、月ごとの死亡率と、月払いの年金・保険の現在価値はどれだけ違うか。どの仮定が正解に近いか | 令和6年簡易生命表（男・女）の年の死亡率を、3つの仮定で月ごとに分ける。ゴンペルツの法則で作った死亡率では、月ごとの正しい値と比べる | `src/a420_fractional_age.py` |

## 3つの仮定（q＝年の死亡率、s＝年のはじめからの時間）
| 仮定 | 年のはじめの人が s まで生きている割合 | 月ごとの死亡率の形 |
|---|---|---|
| 一様に亡くなる（UDD） | 1 − s·q | 年の終わりに向かって上がる |
| 死亡の強さが一定 | (1 − q)^s | 平ら |
| バルドゥッチ | (1 − q) ÷ (1 − (1 − s)·q) | 年の終わりに向かって下がる |

## 置いたこと
- 死亡率：厚生労働省「令和6年簡易生命表」（男・女）。`data/life_table_2024_qx.csv`（F268 のフォルダから写したもの）
- 105歳から先：表は「105歳以上の死亡率1」で終わる。そのままだと最後の1年の置き方だけで差が出るので、90〜104歳の死亡の強さの伸び方を120歳まで延ばした
- 金額：月のはじめに1/12ずつ払う終身年金、亡くなった月の終わりに1を払う終身保険・定期保険。金利1%
- 正解の分かる死亡率：死亡の強さ μ(x)＝B·c^x（B＝7.48×10⁻⁶、c＝1.116。令和6年の表（男）の60〜100歳に当てた）。月ごとの生きている割合は式で厳密に出せる

## 主な結果
### 月ごとの死亡率（男。最後の月 ÷ 最初の月）
| 年齢（年の死亡率） | 一様に亡くなる | 死亡の強さが一定 | バルドゥッチ |
|---|---|---|---|
| 60歳（0.6%） | 1.006 | 1 | 0.994 |
| 80歳（4.9%） | 1.05 | 1 | 0.96 |
| 90歳（15.2%） | 1.16 | 1 | 0.86 |
| 100歳（40.4%） | 1.59（3.4%→5.3%） | 1（4.2%） | 0.63（5.3%→3.4%） |

### 月払いの終身年金の現在価値：「一様に亡くなる」との差（男）
| 年齢 | 死亡の強さが一定 | バルドゥッチ | 近似（年払い − 11/24） |
|---|---|---|---|
| 65歳 | −0.05% | −0.09% | +0.01% |
| 75歳 | −0.09% | −0.18% | +0.01% |
| 85歳 | −0.25% | −0.50% | +0.03% |
| 95歳 | −1.1% | −2.2% | +0.06% |
| 100歳 | −2.8% | −5.6% | +0.09% |

- 女では、65歳で−0.04%・−0.08%、85歳で−0.17%・−0.34%、100歳で−1.9%・−3.8%
- 1年の定期保険の差は、100歳でも0.1%未満（保険金が出るかどうかは年の死亡率で決まり、仮定で変わるのは払う月だけ）

### 正解の分かる死亡率で：月払いの終身年金の、正解との差
| 年齢 | 一様に亡くなる | 死亡の強さが一定 | バルドゥッチ |
|---|---|---|---|
| 65歳 | +0.001% | −0.04% | −0.09% |
| 85歳 | +0.11% | −0.14% | −0.39% |
| 90歳 | +0.28% | −0.21% | −0.69% |
| 95歳 | +0.73% | −0.31% | −1.35% |
| 100歳 | +2.0% | −0.5% | −2.9% |
| 105歳 | +5.5% | −0.8% | −6.9% |

- **85歳までは「一様に亡くなる」、90歳からは「死亡の強さが一定」が正解に近い**。バルドゥッチはどの年齢でもいちばん遠い

全部の数字は `results/` の4つの CSV と `results/main.json` にあります。

## 動かし方
```
pip install -r requirements.txt
cd src && python a420_fractional_age.py      # 数秒
```
`data/gompertz_fit_vs_life_table.csv`、`results/` の5ファイル、`figures/` の3枚ができます。

## 確かめたこと
- 空のフォルダで計算し直し、data・results・figures が一致した
- 3つの仮定とも、12か月たった時点の生きている割合は 1 − q になる（年の死亡率は変えていない）
- 「一様に亡くなる」の月払いの年金は、年払いの年金 − 11/24 の近似と0.1%以内で合う
- 表の最後（105歳以上の死亡率1）をそのまま使うと、100歳の年金の差は−3.6%・−6.2%になる（延ばした場合は−2.8%・−5.6%）

## 注意（言えないこと）
- 公表の生命表での比べは、仮定どうしの差です。正解との比べは、ゴンペルツの法則を正解と置いた場合の結果です
- 死亡の季節による多い少ない、誕生日からの1年と暦の1年の違いは入れていません
- 105歳から先は手元で延ばした値で、100歳の差はこの延ばし方に左右されます
- 金利は1%の1通り。保険料の計算や責任準備金への影響は見ていません
- 実務でどの仮定を使うかは、決まりや慣行で定められていることがあります。どれを使うべきかを言うものではありません
