# 194 大きな都市ほど、自動車を使う割合は低いのか：全国都市交通特性調査

国土交通省「全国都市交通特性調査」（令和3年度、70都市）の都市別の代表交通手段構成比と、国勢調査の人口を組み合わせ、人口の大きい都市ほど自動車の分担率が低いのかを単回帰で確かめたフォルダです。1987〜2021年の7回の推移も見ています。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A194 | 大きな都市ほど、自動車を使う割合は低いのか | 自動車分担率（平日、運転＋同乗）を log10人口・log10人口密度で単回帰、三大都市圏と地方都市圏に分けた回帰、重回帰、7時点の都市グループ平均 | `src/a194_city_size.py` |

## 主な結果
- 70都市全体で、人口が10倍になると自動車分担率は約23ポイント低い（相関係数−0.71、決定係数0.50）。人口密度で見るとさらに当てはまりがよい（10倍で約26ポイント、決定係数0.66）
- ただし同じ人口でも三大都市圏と地方都市圏で差が大きい。地方都市圏の回帰線は三大都市圏より上にあり、傾きも小さい（10倍で約15ポイント）
- 人口100万人以上でも、東京23区12.0%・大阪市12.7%に対し、仙台市50.2%・札幌市43.8%・広島市42.8%・名古屋市41.1%
- 自動車分担率が最も高いのは小矢部市84.5%、湯沢市82.6%、伊那市81.6%。70都市の中央値は60.2%で、48都市が50%以上
- 休日の自動車分担率は70都市すべてで平日より高い（平均68.8%、平日55.4%）
- 7回とも調査した都市の平均で、地方都市圏の中心都市は1987年39.7%→2021年58.3%、周辺・その他の都市は41.6%→71.8%に上がった。三大都市圏の中心都市は24.9%→23.6%でほぼ横ばい

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a194_city_size.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/modal_share_r3.csv | 70都市の平日の代表交通手段構成比（鉄道・バス・自動車運転・同乗・自動二輪・自転車・徒歩その他）、平均トリップ長（km）、休日の鉄道・自動車 |
| data/population.csv | 国勢調査の人口（2020年は2025年の境域に組み替えた値、2025年）、面積、人口密度 |
| data/car_rail_timeseries.csv | 7時点（1987・1992・1999・2005・2010・2015・2021年度）の自動車と鉄道の分担率（平日） |

- 全国都市交通特性調査 集計データ（https://www.mlit.go.jp/toshi/tosiko/toshi_tosiko_fr_000024.html）の「都市別指標 R3」と「都市別指標（時系列）」
- 令和7年国勢調査 第1-1表（e-Stat statInfId 000040506423）の2020年人口（組替）と面積

## 注意
- 各都市およそ500世帯の標本調査で、1都市ごとの値には誤差がある
- 2021年度は新型コロナの影響で外出率が下がっており、手段の構成にも影響している可能性がある
- 1992年度までは市街化区域内のみが対象で、1999年度以降と調査範囲が違う。1987年度は運転と同乗を分けていない（合計で比較）
- 調査対象の70都市は全国の都市から選ばれた一部で、全国の縮図ではない
- 人口と自動車分担率の関係は相関で、鉄道網や道路、駐車場、地形などの影響は分けていない
