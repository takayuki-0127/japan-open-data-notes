# F201 最低賃金と働き方（前編）：誰に届き、推定の方法で答えはどこまで変わるか

看板記事 F201。深いシリーズ A「最低賃金と働き方」の前編です（後編は F202）。

これまでの最低賃金の記事を1本にまとめ直しました（F01 差の差、F15 県境の比較、F17 因果フォレスト、F26 検出力、F156 賃金の低さ別）。そのうえで、新しく2つのことをしています。
- 最低賃金がどれだけの人に「届いた」か（影響率）の20年の推移を並べた
- 同じ県×年のデータに4つの推定の方法を当てて並べた

## 結論（先に）

1. **届く人は大きく増えた。** 最低賃金の改定で賃金を上げる必要が出る人の割合（影響率）は、2005年の1.6%から2024年の23.2%まで増えました。一方、もともと最低賃金を下回っている人の割合（未満率）は、20年間ずっと1〜3%です。
2. **雇用への効果は、4つの方法のどれでも「はっきりしない」。** 最低賃金10%上昇あたりの就業率の変化は、−1.07〜−0.13%pt でした。雇用の弾力性に直すと −0.18〜−0.02 です。県別トレンドつきの差の差だけが、95%区間で0をわずかに下回りました。
3. **方法の違いより、「使える差」の小ささが効いている。** どの方法でも、80%の確率で見つけられる最小の差は1.3〜2.6%pt でした。海外でよく報告される大きさ（弾力性 −0.3 ≒ 0.18%pt）の7〜14倍です。
4. **地域や産業による違いも、はっきりしない。** 最低賃金が平均時給に近い県と遠い県の差は +0.21%pt（95%区間 −0.01〜+0.43）でした。産業別（F15）も、すべて区間が0をまたぎます。

## 問い

- 最低賃金はこの20年でどう上がり、どれだけの人の賃金に届いたのか。
- 雇用への効果は、推定の方法（差の差・合成コントロール・隣り合う県の比較）を変えると、どこまで変わるのか。
- 効果は、賃金の低い地域や特定の産業で大きいのか。

影響率・未満率は、中央最低賃金審議会 目安に関する小委員会の配布資料から手で転記しました。
- 平成17〜26年度：平成27年7月15日 第2回 資料 p5
- 平成26〜令和5年度：地域別最低賃金の推移等に関する資料 No.22-1
- 令和6年：令和7年第1回 資料 p17・p18

平成17〜26年度の表は、区分名がテキストから読めませんでした。そこで、H26 の値（未満率2.0%・影響率7.3%）が No.22-1 の全国計と一致する段を、全国計として採用しています。

**用語**
- **影響率**：改定後の最低賃金を下回ることになる労働者の割合。改定で賃金を上げる必要が出る人の割合です。
- **未満率**：改定前の最低賃金を、すでに下回っている労働者の割合。
- **カイツ指標**：最低賃金 ÷ 平均賃金。ここでは短時間労働者の平均時給を使います。1に近いほど、最低賃金が平均に近い（よく効く）ことを意味します。
- **弾力性**：最低賃金が1%上がったとき、雇用が何%変わるか。

## 手法

すべての結果は「最低賃金10%上昇あたり」にそろえました。主な期間は2008〜2025年で、コロナの2020〜22年は外しています。

| 方法 | どこで比べるか | 中身 |
|---|---|---|
| 差の差（二方向固定効果） | 全国の県どうし | 就業率 ＝ log(最低賃金) ＋ 県の効果 ＋ 年の効果。標準誤差は県でクラスター |
| 差の差＋県別トレンド | 同上 | 上に、県ごとの直線の傾きを加える |
| 隣り合う県の比較 | 同じ県境の両側だけ | 89組の県境ごとに2県を積み上げ、ペア×年の効果とペア×県の効果を入れる（Dube らの方法を県単位にしたもの）。標準誤差は県でクラスター |
| 合成コントロール | 似た動きの県を重みづけして作った「合成県」 | 2019→2025年度の上げ幅が大きかった上位10県（上げ幅の平均26.8%）を処置とする。上げ幅の小さい下位20県（21.6%）から、2008〜19年の就業率の動きが合う重みを県ごとに選ぶ。2023〜25年の差を比べ、上げ幅の差（合成県との差の平均5.25%）で割って10%あたりにする |

違いは2つの切り口で見ました。
- **bite の高さ別：** 2009〜11年の「最低賃金 ÷ 平均時給」で県を3つに分け、差の差の傾きを分けて推定しました。
- **産業別：** F15 の結果（2016→21年、県境をはさむ市区町村の従業者数）を並べました。データが違うので、参考として示しています。

## 結果

### 1. 届き方（図1・図2）

- **影響率：** 1.6%（2005年）→ 7.3%（2014年）→ 16.3%（2019年）→ 23.2%（2024年）と増えました。2020年は、引き上げがほぼ0円（加重平均 +1円）だったため、4.7%に落ちています。
- **未満率：** 1.1〜2.7%の間で、上がり続けてはいません。引き上げは、守られていない人を増やすより、「ちょうど最低賃金で働く人」を増やす形で効いてきたと読めます（推測）。
- **特別集計（5人以上の事業所）の影響率：** 6.9〜8.8%（2022〜24年）でした。基礎調査は小さい事業所が対象なので、同じ年でも約3分の1の大きさです。どの事業所を数えるかで、影響率は大きく変わります。
- **カイツ指標（県の中央値）：** 0.709（2009年）→ 0.756（2019年）と上がりました。2020年に調査の作り方が変わって段差があり、2025年は0.728です。最低賃金が平均時給に近い県（上位1/3）と遠い県（下位1/3）の差は、0.04前後のまま縮んでいません（`results/kaitz_by_tercile.csv`）。

### 2. 4つの方法を並べる（図3、`results/method_comparison.csv`）

就業率（%pt、10%あたり、2008〜25年・2020〜22年除く）：

| 方法 | 推定値 | 95%区間 | 弾力性に直すと |
|---|---|---|---|
| 差の差（二方向固定効果） | −0.21 | −1.10〜+0.68 | −0.04 |
| 差の差＋県別トレンド | −1.07 | −2.03〜−0.11 | −0.18 |
| 隣り合う県の比較（89組） | −0.13 | −1.05〜+0.80 | −0.02 |
| 合成コントロール（上位10県 vs 下位20県） | −0.56 | −2.38〜+1.26（並べ替え p=0.51） | −0.10 |

完全失業率（%pt、10%あたり）：

| 方法 | 推定値 | 95%区間 |
|---|---|---|
| 差の差 | −0.27 | −0.76〜+0.22 |
| 差の差＋県別トレンド | +0.31 | −0.02〜+0.64 |
| 隣り合う県の比較 | +0.12 | −0.09〜+0.33 |
| 合成コントロール | −0.45 | −0.80〜−0.10（並べ替え p=0.015） |

- 4つの推定値は、すべてマイナス〜0付近の範囲に入りました。区間はどれも広く、県別トレンドつき以外は0をまたぎます。
- 失業率は、方法によって向きが逆になりました。合成コントロールだけが「大きく上げた県で失業率が下がった」とはっきり出ています。ただし、処置の10県は地方の県が多く、その地域の景気の動きと重なっている可能性があります（推測）。

### 3. 使える差と検出力（図4・図5、`results/mde.csv`）

- **最低賃金の差の大きさ：**
  - 差の差で使える残り（県と年を除いたあと）の標準偏差：0.86%
  - 同じ県境の両側の差：0.48%
  - 合成コントロールの上げ幅の差：5.25%
- **80%の確率で見つけられる最小の差（就業率、10%あたり）：** 差の差 1.27、県別トレンド 1.37、隣り合う県 1.32、合成コントロール 2.59（%pt）。どれも、海外でよく報告される弾力性 −0.3（≒0.18%pt）の7〜14倍です。
- **合成コントロールの差の推移（図5）：** 2008〜19年は、上位10県と合成県の差は ±0.3%pt 以内でそろっていました。2024〜25年は −0.4〜−0.7%pt と下にずれています。ただ、無作為に選んだ10県でも同じくらいのずれは出ます（95%の範囲 −0.96〜+0.87）。

### 4. 違い（図6、`results/heterogeneity_bite.csv`）

- **bite の高さ別（就業率、10%あたり）：** 遠い県 −0.57、中位 −0.59、近い県 −0.35 でした。近い−遠いの差は +0.21（±0.22）で、「近い県ほど悪い」向きではありません。F156 でも、雇用の差は同じ地方の中で比べると消えていました。
- **産業別（F15、10%あたりの従業者数）：** 宿泊・飲食 +3%、卸売・小売 +41%、製造業 +27%、全産業 +3% でした。区間はすべて0をまたぎ、小さな効果は見分けられない設計です。

## 頑健性（`results/method_comparison.csv`）

| 確かめたこと | 就業率（10%あたり） |
|---|---|
| コロナ期を含める（2008〜25年の全年） | 差の差 −0.09、県別トレンド −1.20、隣り合う県 −0.06 |
| 2008〜19年だけ | 差の差 −0.01、県別トレンド −0.71、隣り合う県 +0.91（−0.01〜+1.83） |
| 接する部分が長い県境だけ（市区町村ペア5組以上の72組） | +0.23（−0.74〜+1.19） |
| 合成コントロールの処置・候補を変える | 上位5県 vs 下位20県 −0.67、上位10県 vs 下位30県 −0.16 |
| 合成コントロールの並べ替え（無作為な10県で200回） | p=0.51（就業率）、p=0.015（失業率） |

- 期間や組の選び方で、推定値は −1.2〜+0.9 の間で動きました。符号も入れ替わります。
- 「県別トレンドつきの差の差」だけが、期間を変えても一貫してマイナスでした。ただ、県ごとの直線の傾きは、最低賃金の効果そのもの（ゆっくり効く分）も吸い取ってしまうので、この1つだけで「雇用が減った」とは言えません。

## 後編（F202）に渡すもの

- `results/main.json` の `for_F202`：
  - 就業率の10%あたりの効果の幅（方法による違い）と、95%区間の両端
  - 2025年の県別カイツ指標
- **シナリオ計算（全国一律など）の前提：**
  - 就業率の弾力性は「−0.18〜0（方法の幅）」と「区間の端 −0.35」の2段で振る。
  - 時給への届き方は、F156 の推定（最低賃金の額が1標準偏差低い県で、全国1%の引き上げあたり時給 +0.35%）を使う。
  - `results/wage_passthrough.csv`（年の効果を入れた単純な届き方）は、同じ年の中の上げ幅の差が小さすぎて区間が広いので、使わない。
- 後編の扱い：「年収の壁」と最低賃金の重なり（就業構造基本調査・F82）、全国一律のシナリオ、データが言えること・言えないこと。

## 言えないこと

1. 「最低賃金は雇用を減らさない」とは言えません。どの方法でも、見つけられる最小の差が、海外でよく報告される大きさより大きいからです。言えるのは「大きな悪影響（弾力性で −0.3 を大きく超えるもの）は見えない」までです。
2. 影響率は全国の値だけで、県別の時系列は使っていません。2つの調査（基礎調査と特別集計）では対象の事業所が違うので、水準は比べられません。
3. 平成17〜26年度の影響率は、区分名が読めない表から、H26 の値の一致で全国計を選んで転記しました。
4. 隣り合う県の比較は県単位なので、市区町村単位の F15 より粗い比較です。県境の両側が本当に似た労働市場かは確かめていません。
5. 合成コントロールの処置県は「上げ幅が大きかった県」です。上げ幅は地方の審議会が地域の事情を見て決めるので、景気と無関係とは言えません。
6. 2020年以降の県の時給は、調査の作り方の変更と標本のぶれで、年ごとの動きが大きくなっています。平均時給が前年から急に跳ねる年がある県もあります。
7. 県の名前を挙げての評価はしていません。
