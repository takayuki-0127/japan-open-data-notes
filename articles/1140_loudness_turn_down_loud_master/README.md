# 1140 配信先が決まった大きさまで音量を下げるとき、大きく作った曲は得をするのか？（音の大きさ）

曲を仕上げるとき、いちばん大きい瞬間が上限を超えないように、超えそうな瞬間だけ音量を下げながら全体を大きくする処理（この記事では「つぶす処理」と呼びます）をかけると、曲全体の大きさの数字は上がります。けれども、配信先が曲の大きさを測って決まった大きさまで下げて再生するなら、大きくした分は下げられて消えます。そのうえ、つぶした分だけ静かな部分と盛り上がる部分の差は縮んでいるので、盛り上がる部分はかえって小さく鳴るかもしれません。**ここでは、作成者が式と乱数で作った架空の曲500曲（静かな部分と盛り上がる部分が6秒ずつ交互、強弱の差を作成者が置いたもの）を、いちばん大きい瞬間を上限にそろえた状態から0〜16 dB 大きく作り、配信先の2つの決まり（①決まった大きさより大きい曲だけ下げる、②大きい曲は下げ、小さい曲は上げる。上げて上限を超える瞬間は配信先がつぶす）で再生したとき、大きく作らない同じ曲より、曲全体・盛り上がる部分がどれだけ大きく鳴るか（数値の上で）を数えました。曲の強弱の差の置き方3つ×決まった大きさ3つ×決まり2つの18通りでも確かめました。**

例の曲はすべて作成者が式と乱数で作った波形で、実在の曲・配信サービス・音量の基準・機材やソフトを表すものではありません。「配信先の決まった大きさ」は作成者が置いた値で、実在の配信先の基準の値ではありません。大きさはすべて数値の計算で、人に聞き比べてもらうことはしていません。

関連する記事：同じ企画の 1139「いちばん大きい瞬間の値で音量をそろえると、曲ごとの聞いた大きさはどれだけばらつくのか？」は、いちばん大きい瞬間でそろえるか、曲全体の平均の強さでそろえるかで、そろえたあとの大きさがどれだけ散らばるかを扱っています。この記事は、平均の強さでそろえる配信先の決まりのもとで、大きく作った曲の得失に絞ります。1141「音をつぶして大きくする処理をかけると、平均の大きさと強弱の幅はどう入れかわるのか？」は、つぶし方ごとに何が減るかを扱っています。1147「曲ごとに大きさをそろえる再生と、アルバム全体でそろえる再生では、曲どうしの強弱の差はどう残るのか？」は、曲ごととアルバムごとに大きさをそろえたとき、作り手が置いた曲どうしの差がどう残るかを、1144「上限を超えて切れた部分の割合は、大きさの数字にどう表れるのか？」は、つぶさずに上限で切ったとき、切れた割合が大きさの数字にどう表れるかを数えています。

## 主な結果

### 大きく作った量ごとの、作らない同じ曲との差（基本、500曲の平均、`results/by_push.csv`）
| 大きく作った量 | 再生前の曲全体の大きさ | 再生前の強弱の差（盛り上がる−静か） | 決まった大きさ（−16 dB）を超えた曲 | ①曲全体 | ①盛り上がる部分 | ②曲全体 | ②盛り上がる部分 | （比べるため）下げない：盛り上がる部分 |
|---|---|---|---|---|---|---|---|---|
| 0 dB | −20.37 dB | 7.44 dB | 0% | 0 | 0 | 0 | 0 | 0 |
| 4 dB | −16.71 dB | 7.02 dB | 30.8% | +3.42 | +3.34 | 0 | −0.01 | +3.58 |
| 8 dB | −13.81 dB | 5.82 dB | 95.2% | +4.34 | **+4.04** | +0.01 | −0.19 | +6.26 |
| 12 dB | −11.59 dB | 4.34 dB | 100% | +4.37 | +3.73 | +0.01 | −0.52 | +8.14 |
| 16 dB | −10.43 dB | 2.25 dB | 100% | **+4.37** | +3.08 | +0.01 | **−1.17** | +8.65 |

（①②の列の単位は dB。＋は大きく作った曲のほうが大きく鳴る）

- 基本の置き方では、大きく作らない曲（k＝0）はどれも決まった大きさ −16 dB より小さかった（曲全体の大きさの平均 −20.37 dB、10〜90%の範囲 −22.09〜−18.58 dB）
- **①大きい曲だけ下げる決まりでは、大きく作ると曲全体は大きく鳴ったが、その得は「決まった大きさ−もとの大きさ」で止まった（式どおり）**。16 dB 大きく作ったときの得の平均 4.37 dB は、決まった大きさともとの大きさの差の平均 4.37 dB と、500曲すべてで同じだった（差の最大 0.0 dB）。決まった大きさに届いた量は、曲の中央値で6 dB
- **①で盛り上がる部分がいちばん大きく鳴ったのは、決まった大きさにちょうど届くくらい大きく作ったときだった**。曲ごとのいちばん得な量は中央値6 dB で、決まった大きさに届いた量との相関は0.94（平均の差 −0.12 dB）、95.4%の曲で8 dB 以下だった。**それより大きく作ると、16 dB では盛り上がる部分が、いちばん得な量のときより平均1.12 dB 小さくなった**。つぶした分だけ強弱の差が縮み（8 dB で7.44→5.82 dB、16 dB で2.25 dB）、全体をそろえると盛り上がる部分が下がるため
- **②上げ下げする決まりでは、大きく作っても曲全体の得はほとんどなかった（+0.01 dB）**。大きく作らない曲も、配信先が決まった大きさまで上げるため。盛り上がる部分は、16 dB 大きく作ると −1.17 dB で、94.2%の曲で0.5 dB 以上小さくなった。大きく作らない曲は、配信先が上げるときに超える瞬間だけつぶされるが、その量は自分で16 dB つぶすより少ないため
- いちばん大きい3秒で比べても同じ向きだった（16 dB 大きく作ったとき ①+3.02 dB・②−1.23 dB、`results/a1140_main.json` の compare_k16_vs_k0）
- 配信先が下げなければ、16 dB 大きく作った曲は盛り上がる部分で +8.65 dB 大きかった。①②の結果との違いは、配信先の決まりから来ている

### 例の1曲（`figures/a1140_example.png`、`data/example_song_3s.csv`）
- 大きく作らないときの曲全体の大きさは −21.19 dB、12 dB 大きく作ると −11.33 dB
- ①では、大きく作らない曲は下げられず、盛り上がる部分の3秒ごとの大きさの最大は −18.69 dB。12 dB 大きく作った曲は −16 dB まで下げられ、最大は −14.16 dB
- ②では、大きく作らない曲も −16 dB まで上げられ、盛り上がる部分の最大は −13.79 dB と、12 dB 大きく作った曲（−14.16 dB）より大きかった。静かな部分の3秒ごとの最小は、作らない曲 −20.26 dB、12 dB 大きく作った曲 −19.11 dB

### 確かめ：強弱の差×決まった大きさ×決まり（18通り、`results/grid.csv`）
| | 8 dB 大きく作ったとき（9通りの範囲） | 16 dB 大きく作ったとき（9通りの範囲） |
|---|---|---|
| ①曲全体 | +0.38〜+6.54 dB | +0.38〜+8.86 dB |
| ①盛り上がる部分 | −0.01〜+6.24 dB | **−0.9〜+7.92 dB** |
| ②曲全体 | 0〜+0.06 dB | **0〜+0.18 dB** |
| ②盛り上がる部分 | −0.39〜+0.05 dB | **−1.28〜−0.46 dB** |

- **②では、9通りすべてで曲全体の得は0.18 dB 以下、16 dB 大きく作ると盛り上がる部分は9通りすべてで小さくなった（−1.28〜−0.46 dB）**
- ①の得の大きさは、決まった大きさがもとの曲よりどれだけ大きいかでほぼ決まった。決まった大きさが −12 dB（もとの曲よりずっと大きい）なら16 dB 大きく作った曲の盛り上がる部分は +6.4〜+7.92 dB、−20 dB（もとの曲の多くがすでに超えている、k＝0 で超えていた曲 29.0〜58.3%）なら −0.9〜+0.12 dB だった
- ①で16 dB と8 dB を比べた盛り上がる部分の差は −0.99〜+1.68 dB。決まった大きさ −12 dB では8 dB ではまだ届かない曲が多く、16 dB のほうが大きかった。届いたあとに大きく作るほど盛り上がる部分が下がる、という向きは、決まった大きさ −20・−16 dB の6通りで同じだった（`grid.csv`）

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約44秒）
- ①で決まった大きさに届いた曲の曲全体の得が「決まった大きさ−もとの大きさ」と一致することを確かめた（500曲で差の最大 0.0 dB、作りどおり）
- つぶす処理のあとの、いちばん大きい瞬間が上限（0 dB）を超えないことを確かめた（500曲×9通りの最大 0.0 dB、`max_peak_after_push_dB`。区切りごとに超えない倍率を選ぶので、作りどおり）
- 図3枚を開き、日本語・重なり・軸を確かめた

## 注意（言えないこと）
- 架空のデータです。曲の作り（雑音と拍の打ち、6秒ずつの強弱）、つぶす処理のしくみ、配信先の決まりと決まった大きさは作成者が置いたもので、結果はこれで決まります。とくに①の得の大きさは、決まった大きさともとの曲の大きさの差でほぼ決まります（式どおり）
- 大きさは重みなしの二乗平均で測りました。実在の配信先は、低い音・高い音に重みを付けたり、静かすぎる部分を除いたりして測ることがあり、その分は入っていません（重みの違いは 1142 で扱っています）
- 実在の配信先がどの決まりで再生しているかは扱っていません。どれだけ大きく作るべきかも言えません。この記事は、決まりごとに大きく作った分がどう残るかを数えただけです
- 人の耳での大きさの感じ方は扱っていません。盛り上がる部分の大きさは、数値の二乗平均の差です
