# 720 2つの系列が同じ原因で動き、片方が遅れて反応するとき、グレンジャー因果の検定は何%で「因果あり」と言うのか（手法の解説・正解の分かるデータで試す）

グレンジャー因果の検定は、「X の過去が、Y の過去だけよりも Y をよく予測するか」を見る検定です。名前に「因果」とありますが、見ているのは予測に役立つかどうかです。**ここでは、X と Y に直接の関係はなく、どちらも共通の原因 Z で動き、Y だけが遅れて反応する架空の月次の系列で、X→Y の検定が何%で「因果あり」と言うかを数えました。** Z の過去を入れた検定、逆向き（Y→X）の検定とも比べています。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A720 | 共通の原因と遅れがあるとき、グレンジャー検定は何%で「因果あり」と言うか | 共通の原因 Z は AR(1)（係数0.5）。X＝Z＋ノイズ（標準偏差1）、Y＝b×（L か月前の Z）＋ノイズ（標準偏差1）、基本は b＝0.3・120か月。検定はずらし4か月の F 検定（5%）。遅れ L＝0〜4か月、長さ60・120・240か月、b＝0.1〜0.5、各500回、seed 720 | `src/a720_granger.py` |

## 主な結果（120か月・b＝0.3、500回）
| Y の遅れ | X→Y（ふつうの検定） | X→Y（Z の過去を入れた検定） | Y→X（逆向き） |
|---|---|---|---|
| 0か月 | 12.0% | 4.8% | 7.0% |
| 1か月 | **52.8%** | 5.6% | 5.0% |
| 2か月 | **52.6%** | 3.4% | 5.6% |
| 3か月 | **59.8%** | 5.6% | 3.8% |
| 4か月 | **54.2%** | 5.0% | 5.6% |

- X と Y に直接の関係はないのに、Y が1〜4か月遅れて反応すると、ふつうの検定は53〜60%の回で「X が Y をグレンジャー因果する」と言った。逆向き（Y→X）はほぼ5%だった
- 共通の原因 Z の過去を入れると、「因果あり」は3.4〜5.6%で、5%の水準どおりになった
- 遅れ2か月で、系列が長いほど（60か月 27.2%・120か月 52.6%・240か月 92.2%）、Z の効きが強いほど（b＝0.1 で 9.4%・0.5 で 92.4%）「因果あり」が増えた

## 動かし方
```
pip install -r requirements.txt
cd src && python a720_granger.py
```

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- 共通の原因の過去を入れた検定で、「因果あり」の割合が5%前後になること（直接の関係がないので、これが正しい割合）

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 720）

## 注意（言えないこと）
- 架空のデータです。Z の動き・遅れ・効きの強さ・ノイズは作成者が置いたもので、「因果あり」の割合はこれで決まります
- 実際には共通の原因は見えないことが多く、ここでの「Z を入れた検定」はいつもできるわけではありません
- グレンジャー因果が「あり」でも、X を動かせば Y が動くとは言えません。予測に役立つかどうかの検定です
- 検定のずらしの長さ（4か月）は作成者が決めたもので、長さを変えると割合も変わります
