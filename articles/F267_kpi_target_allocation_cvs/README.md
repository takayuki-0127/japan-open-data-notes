# F267 売上の目標を、客数と客単価の目標にどう分けるか？（コンビニ既存店で割り付けを過去に当てはめる）

精選モード（D. 求人票の業務 Q33「KPI 設計：売上の目標を、現場が動かせる指標に分解するには？」）。計画（事前登録）は [PLAN.md](PLAN.md)（コミット 881920a）。

## 問い

「既存店の売上を前年より +X% にする」という目標を、店で動かせる「客数」と「客単価」に割り付けるとき、どう割り付ければ、それぞれの目標が売上の目標と同じくらい届くものになるか。架空の会社（F243・F246〜F255）ではなく、公表されている業界の実データで確かめる。

## データ

- 日本フランチャイズチェーン協会「コンビニエンスストア統計調査」月次の時系列表（PDF、2005〜2016年・2017〜2025年）→ `data/raw/jfa_cvs_monthly_*.pdf`、整形後 `data/jfa_cvs_monthly.csv`（252か月）・`data/jfa_cvs_annual.csv`（21年）。正会員チェーンの合計。全店・既存店の売上高、店舗数、来店客数、平均客単価と前年同月比。月の売上の合計は年の売上と全年で一致。
- 経済産業省「商業動態統計」コンビニ販売額（2014〜2026年、F231 のデータの写し）→ 協会の全店の売上の照合に使う。
- 総務省「消費者物価指数」2020年基準 財・サービス分類（2015〜2026年、F209 のデータの写し）→ 問い直しで使う。
- 実在の1社・1店のデータは使っていない。

## 手法

1. 既存店の売上の前年比を対数にし、売上の伸び s ＝客数の伸び c ＋客単価の伸び p と分ける（表の前年比の丸めで、足し算のずれは最大 0.13ポイント）。
2. 分散の分け方：客数の寄与 ＝ (Var(c)＋Cov(c,p))/Var(s)、客単価の寄与 ＝ (Var(p)＋Cov(c,p))/Var(s)。
3. 割り付けのバックテスト：その年の売上の目標 X ＝ 前5年の既存店売上の平均の伸び（前の年までのデータだけ）。等分・過去の傾向の比（前5年の c と p の平均の伸びの比）・全部を客単価、の3ルール（補助に「傾向＋差を等分」）。2010〜2025年の16年で、売上・客数・客単価の目標に届いた年の割合を数える。固定の X＝0%・+1%・+2%（2006〜2025年）も。
4. 月の判定（前年同月比 ≥ 目標）と、同じ年の年の判定が食い違う月の割合（2010〜2025年の192か月）。

## 結果

| 仮説（計画） | 基準 | 結果 | 判定 |
|---|---|---|---|
| H1 売上の揺れは客数の寄与が半分超（月次、2006〜2025） | 客数の寄与 > 50% | 客数 79%・客単価 20% | 基本の期間では支持。コロナを除くと 52%、さらに税・たばこの時期を除くと 48〜50% で、外れになる条件がある |
| H2 客数と客単価は負の相関 | 相関 < −0.3 | −0.45 | 支持（コロナを除くと +0.04、前半 +0.21 で外れ） |
| H3 等分は一方が売上と20pt以上ずれ、傾向の比なら両方10pt未満 | 両方 | 等分 25pt・傾向の比 12.5pt（2年分） | 外れ。達成率が近くても、売上と判定が逆の年は傾向の比で客単価 8/16年・客数 2/16年（等分 5年・6年） |
| H4 月の判定が年の判定と3割以上食い違う | 各指標 ≥ 30% | 売上 23%・客数 19%・客単価 31%（傾向の比）／18%（等分） | 客単価（傾向の比）だけ支持、ほかは外れ |

- 割り付け別の達成率（目標＝前5年の平均、16年）：売上 56%（9年）。等分：客数 31%・客単価 75%。傾向の比：44%・56%。全部を客単価：31%・63%。傾向＋差を等分：44%・50%。
- 全店の3つの分解（店舗数・1店あたり客数・客単価）：9%・83%・8%（コロナを除くと 7%・47%・46%）。
- 2つの出所の照合：協会の全店の売上と商業動態統計の前年同月比 相関 0.98、差の絶対値の平均 0.48pt（2015〜2025年、132か月）。

詳しい数字は `results/main.json`、`results/H3_allocation_summary.csv`、`results/H3_allocation_by_year.csv`。

## 問い直し（結果を見てから足した）

客単価は「現場が動かせる」指標か？ 既存店の客単価の前年同月比と消費者物価の前年同月比（2016〜2025年）：
- 相関は食料工業製品（加工食品）−0.18 だが、ほぼ2020〜2021年から来ており、2016〜2021年は物価の前年比が +0.2〜+1.1% しか動いていないので、月ごとの相関からはほとんど何も言えない（コロナを除くと −0.02、2019年の消費税と2018・2020・2021年のたばこ税の時期も除くと +0.06）。
- 2022〜2025年の4年で、食料工業製品（加工食品）の物価 約+24%、既存店の客単価 約+7%、客数 約+4%、売上 約+11%。この差が結論の根拠。客単価にはたばこの値上げ（2021年10月のたばこ税など）の分も入っている（推測）。
- → 客単価は値上げの分がそのまま乗る数字ではない。買上点数や品目の切り替えが入っている（推測。表に買上点数はない）。`results/reask.json`

## 頑健性

コロナの時期（2020〜2022年）を除く／税とたばこの時期も除く（taspo 2008・たばこ税 2010・消費税 2014 の前月から12か月で客数 48%、2018〜2021年のたばこ税と2019年の消費税も除くと 50%）／前半（2006〜2015）・後半（2016〜2025）／全店の3つの分解／そのままの%で分ける（客数 76%・客単価 21%・交差項 3%）／年の値（客数 85%・相関 −0.53）／目標の大きさ（0%・+1%・+2%）／2つの出所の照合。結果は記事と `results/main.json` の `robustness`・`H3`。

## 計画からのずれ

- 計画の前に、2017年の表の先頭の数行を見ていた（計画に記載）。
- H3 は計画の最初に挙げた X＝前5年の平均で判定した（どの X で判定するかは計画に書いていなかった）。
- 「傾向＋差を等分」のルールは計画になく、補助として足した。
- H4 の割り付けルールは計画に書いていなかったため、傾向の比と等分の両方を出した。
- 前5年の平均を使うため、H3・H4 は2010〜2025年。
- 問い直しは結果を見てから足した。
- 独立レビューを受けて、税・たばこの時期を除く分け方、年ごとの判定の食い違い、税・たばこを除いた物価との相関を結果のあとに計算した（`src/zz_f267_06_レビュー検算.py` → `results/review_checks.json`）。

## 言えないこと

- 正会員チェーンの合計で、1社・1店の数字ではない。1店はもっと大きく揺れる（推測）。
- 客数はレシートの枚数。来店の回数・買上点数・1品あたりの値段は分けられない。
- 客単価（たばこ・サービスを含むコンビニの売上）と物価（全国の値段）は、そのままは比べられない。
- たばこ税（2010年、2018〜2021年の各10月）、消費税（2014年4月、2019年10月）、taspo（2008年）、チェーンの統合・看板の掛け替え（2016〜2018年ごろ）は基本の計算で分けていない。税込みか税抜きかも不明（2014年4月の客単価 −1.8% から税抜きの可能性。推測）。
- 過去の傾向の比は、前5年の客数と客単価の伸びの合計が0に近いと不安定（2023年は +0.05%）。2010〜2011年は売上の目標がマイナスで客数の目標がプラスになった。
- 16年分しかないので、達成率は1年で6.25ポイント動く。
- 目標の立て方の話で、施策の因果は扱っていない。

## レビューで直したこと

独立レビュー（作業を見ていない別のエージェント）の結果：数字はすべて一致し、クリーンな再実行もバイト単位で一致。指摘10件を次のように直した（新しい数字はすべて `src/zz_f267_06_レビュー検算.py` で自分で計算）。

| # | 指摘 | 直したこと |
|---|---|---|
| 1 高 | 「客単価が売上とそろう」は達成率だけ。年ごとには逆の年が多い | 判定が逆の年を追加（傾向の比：客単価 8/16・客数 2/16、等分：5・6）。考察を「傾向から出発しても届く年はそろわない」に直し、題名を「達成率で2年分ずれ、届いた年も売上とは食い違った」に変更 |
| 2 中 | 2011年の伸びを震災で説明していた | 2011年は客単価 +4.5%、1〜2月から +4% 超。2010年10月のたばこ税（推測）、9月の駆け込み（客単価 +10.6%）、10月の反動（売上 −5.9%）を記載 |
| 3 中 | たばこ税・消費税・taspo・統合を扱っていない | 言えないことに追加。頑健性に「税とたばこの時期も除く」（客数 48〜50%）を追加し、H1 は「外れになる条件がある」と判定を直した。前半から除くと客数 47%・相関 +0.36 |
| 4 中 | 「コロナ期に上がった客単価が下がった分」は誤り（2022〜2025年は下がっていない） | 「伸びが鈍った分（推測）」に修正 |
| 5 中 | 物価との相関 −0.18 は2020〜21年が主で、物価がほぼ動いていない期間 | 「月ごとの相関からはほとんど何も言えない」とし、税・たばこを除いた値（+0.06）を記載。結論は24%対7%の差に置き、たばこの値上げの分も（推測）で記載 |
| 6 低 | H4 の理由の説明が不正確 | 「2016年以降の客単価の目標（+0.3〜+3.0%）が実際の伸びとほぼ同じ高さに置かれ、月の値が上下を行き来するため（推測）」に修正 |
| 7 低 | まとめ買いの説明に推測の印がない | （推測）を付けた |
| 8 低 | 62.5% の丸め | 63% にそろえた（図4の表示も） |
| 9 低 | 物価の系列の名前 | 「食料工業製品（加工食品）」にそろえた（図6も） |
| 10 低 | 傾向の比が不安定な年 | 2023年（合計 +0.05%）と2010〜2011年の符号の食い違いを、言えないことと記事に記載 |

レビューの数字と私の再計算で違ったもの：税・たばこの時期を除いた H1 はレビュー 45%・私 48%、前半は 41%・47%、物価との相関は +0.13・+0.06。除く月の決め方（前月から12か月）の違いによる。本文は私の計算の値。
