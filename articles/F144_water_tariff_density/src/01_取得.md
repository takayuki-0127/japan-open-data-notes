# 01 取得

総務省のサイトはコンテナから直接取得できないため、ブラウザのページ内で Excel を読み、JSON にして保存した。

1. 総務省「地方公営企業年鑑」水道事業のページを開く
   - 令和6年度: https://www.soumu.go.jp/main_sosiki/c-zaisei/kouei_R06/index_su.html
   - 令和元年度: https://www.soumu.go.jp/main_sosiki/c-zaisei/kouei_R01/index_su.html
2. 個表「（23）施設・業務概況及び経営分析に関する調（法適用，事業別）」の xls を SheetJS で読む
   - 令和6年度: /main_content/001064895.xls（シート №1〜№9、1,703事業）
   - 令和元年度: /main_content/000741619.xls（シート No.1〜No.7、1,374事業）
3. 各シートの1列＝1事業。項目の行0〜109と、列7以降の事業を取り出す（団体名が空の列は除く）

```js
function ext(wb){const out={labels:null,ents:[]};
 for(const n of wb.SheetNames){ if(n==='index')continue;
  const a=XLSX.utils.sheet_to_json(wb.Sheets[n],{header:1,defval:'',raw:true});
  if(!out.labels) out.labels=a.slice(0,110).map(r=>r.slice(1,7).filter(x=>x!=='').join('|'));
  const w=Math.max(...a.map(r=>r.length));
  for(let c=7;c<w;c++){const col=a.slice(0,110).map(r=>r[c]===undefined?'':r[c]);
   if(String(col[5]).trim()==='')continue; out.ents.push(col);} }
 return out;}
```

4. `{R06: ext(wb令和6), R01: ext(wb令和元)}` を `data/raw/f144_water_nenkan.json` として保存
5. 市区町村の面積は SSDSE-A-2026（独立行政法人統計センター）を `data/raw/SSDSE-A-2026.csv` に置いた
