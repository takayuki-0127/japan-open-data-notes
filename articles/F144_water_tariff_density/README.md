# F144 水道料金の差は、人口密度と水源でどこまで説明できるか

## 問い
家庭の水道料金は事業ごとに大きく違う。その差のうち、給水人口（規模）・管路1kmあたりの給水人口（密度）・水源の種類で説明できるのはどれくらいか。

## データ
- 総務省「地方公営企業年鑑」水道事業 個表（23）施設・業務概況及び経営分析に関する調（法適用，事業別）
  - 令和6年度（主）、令和元年度（頑健性）
  - 使った項目：現在給水人口、取水能力（ダム以外の表流水・ダム・受水）、導送配水管延長、年間総有収水量、家庭用10m³当たり料金（口径13mm）、供給単価、給水原価、有収水量1m³当たりの費用の内訳、有収率、法定耐用年数を経過した管路延長
- 独立行政法人統計センター「SSDSE-A-2026」（市区町村の可住地面積。頑健性だけに使用）

対象は上水道の末端給水事業（給水形態=1）で、料金・給水人口・管路延長・取水能力がそろう1,228事業。用水供給事業は家庭に直接売らないので除き、簡易水道は頑健性で加えた。

## 手法
- 料金の対数を、給水人口の対数・管路1kmあたり給水人口の対数・水源の割合（取水能力のうちダム・ダム以外の表流水・受水。基準は地下水等）で回帰（OLS、HC1 標準誤差）
- 説明できた割合（R²）を、規模・密度・水源の3つに Shapley 値で分けた（区間はブートストラップ300回）
- 都道府県の固定効果を入れたときと比べ、県の間の差と同じ県の中の差を見た
- 5分割交差検証で、線形回帰と勾配ブースティングの説明力を比べた（非線形を許すと上がるか）
- 費用関数：給水原価（円/m³）を、年間有収水量と管路1kmあたり有収水量で回帰し、密度の経済と規模の経済を分けた
- 管路1kmあたり給水人口の5分位ごとに、有収水量1m³あたりの費用の内訳を比べた

## 結果（令和6年度、1,228事業）
| 項目 | 値 |
|---|---|
| 10m³あたり料金 | 中央値 1,561円、5%点 924円、95%点 2,530円（2.7倍） |
| 3つで説明できた割合 R² | 0.37（95%区間 0.33〜0.43） |
| うち密度 / 水源 / 規模 | 0.19 / 0.10 / 0.08 |
| 密度の弾力性 | −0.27（−0.30〜−0.23）：密度2倍で料金 −17%、10倍で −46% |
| 規模の弾力性（密度をそろえて） | −0.035（−0.051〜−0.018）：給水人口10倍で −8% |
| 水源（地下水等との差、規模と密度をそろえて） | ダム +23%、ダム以外の表流水 +17%、受水 +27% |
| 都道府県だけで説明 | R² 0.41。3つ＋都道府県で 0.57 |
| 主モデルの残差のうち県で説明できる割合 | 27% |
| 交差検証 R² | 線形 0.37、勾配ブースティング 0.32（有収率・老朽管・回収率を足しても 0.36） |
| 給水原価の弾力性 | 管路1kmあたり有収水量 −0.36、有収水量 −0.02 |
| 密度5分位の料金中央値 | 1,970 → 1,760 → 1,606 → 1,383 → 1,205円 |
| 密度5分位の給水原価（平均） | 280 → 214 → 188 → 171 → 167円/m³ |
| 供給単価÷給水原価が1未満 | 56%の事業（中央値 0.98） |

密度の低い事業ほど、1m³あたりの減価償却費が大きかった（平均 166円 → 59円）。

| 主 | 1,228 | 0.37 | −0.27 | +0.36 | +0.28 |

| 都道府県平均（設計の代替案） | 47 | 0.57 | −0.31 | — | — |

どの条件でも、密度が高いほど安く、ダム・受水・表流水は地下水等より高い向きは同じだった。簡易水道を入れると説明できる割合は下がった。Shapley の順は令和元年度でも「密度＞水源＞規模」だった。供給単価を結果にすると「水源＞密度」に入れ替わった。

## 言えないこと
- 料金は家庭用10m³（口径13mm）の1点だけで、20m³や用途別の料金体系の違いは見ていない（年鑑の個表に20m³の料金がないため）
- 密度は管路延長あたりの給水人口で、給水区域の面積あたりではない。管路の長さそのものが事業の判断の結果でもある
- 回帰は関連を示すだけで、密度を上げれば料金が下がるという因果は言えない
- 一般会計からの繰入や、料金改定の時期の違いは考えていない
- 事業ごとの料金の順位や、特定の自治体の評価はしない
