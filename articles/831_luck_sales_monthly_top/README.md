# 831 営業成績の月間1位は、何か月続くのか？（運と実力）

営業の月間1位が翌月には別の人に替わると、「先月の1位は調子を落とした」と読みがちです。ところが、毎月の売上には実力のほかに、その月の運（大きな案件がたまたま入ったか）が混ざります。**ここでは、作成者が乱数で作った架空の営業チーム（人ごとの本当の実力を作成者が置き、実力は1年のあいだ変わらないもの）で、月間1位が何か月続くか、本当にいちばん実力のある人が何か月1位になるかを数えました。**

前半の1位が後半も1位かどうか（平均への回帰）は関連する記事 826、連勝の長さは 827、実力差と逆転の起きにくさは 836 で扱います。この記事は「毎月の1位の入れ替わり」に絞ります。826 は2つの区切りでトップの順位がどれだけ残るかを見たのに対し、この記事は12回の区切りで1位が何人に分かれるか、実力1位の人を月間1位で見つけられるかを見ます。

| A831 | 月間1位は何か月続くか。12か月で何人が1位になるか。本当にいちばん実力のある人は何か月1位になるか | 架空の営業チーム20人。人ごとの本当の実力（毎月の売上の見込み）は平均300万円・標準偏差30万円の正規分布で、1年のあいだ変わらない。毎月の売上は、実力にその月の運（平均0・標準偏差60万円の正規分布、人どうし・月どうしで関係なし）を足したもの。このとき、毎月の売上の散らばりのうち実力の差が占める割合は 30²÷(30²＋60²)＝0.2。1年（12か月）を5,000回作り直した平均。1位が続いた月数は1年の中で数える（年の初めと終わりで切れる）。目安として、実力の差を0にした「運だけ」のチームも数えた。確かめとして、運の振れを30・60・120万円（実力の占める割合0.5・0.2・0.06）、チームの人数を10・20・50人に変えた9通りを、それぞれ3,000回数えた。seed 831 | `src/a831_monthly_top.py` |

## 主な結果

### 月間1位の続き方（20人、実力の占める割合0.2、5,000回の平均）
| | 基本 | 運だけ（実力の差0） |
|---|---|---|
| 翌月も同じ人が1位の確率 | **9.6%** | 5.1% |
| 1位が続いた月数の平均 | 1.10か月 | 1.05か月 |
| 3か月以上続けて1位の人が1年に1度でも出る確率 | 10.7% | 2.5% |
| 12か月で1位になった人数の平均（10〜90%の範囲） | 7.77人（6〜9人） | 9.19人（8〜11人） |
| 本当に実力1位の人が月間1位になった月数の平均 | **2.26か月** | 0.61か月 |
| 本当に実力1位の人が1年に1度も月間1位にならない確率 | **9.9%** | 52.6% |
| 12か月の合計の1位が、本当に実力1位の人だった確率 | 53.2% | 4.8% |

- 実力の差を置いても、翌月も同じ人が1位なのは9.6%で、運だけのとき（1÷20人＝5%）の約2倍にとどまった。1位が続いた月数の平均は1.10か月で、1位はほぼ毎月替わった
- 12か月の1位は平均7.77人に分かれた。本当に実力1位の人が月間1位になったのは平均2.26か月で、1年に1度も1位にならない年が9.9%あった
- 12か月を合計すると、1位が本当に実力1位の人だった確率は53.2%まで上がった

## 動かし方
```
pip install -r requirements.txt
cd src && python a831_monthly_top.py
```
数秒で終わります。`data/team_one_year.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の6ファイルがバイト単位で一致した（cmp、約2秒）
- 運の振れ（実力の占める割合0.5・0.2・0.06）とチームの人数（10・20・50人）を変えた9通りで、翌月も同じ人が1位の確率は2.6〜29.6%だった（上の表）
- 実力の差を0にした「運だけ」のチームでは、翌月も同じ人が1位の確率は5.1%で、1÷20人＝5%とほぼ一致した（数え方の確かめ）

## データ
- `data/team_one_year.csv`：架空のチーム20人の1年分（person_id・skill（本当の実力、万円）・m01〜m12（月ごとの売上、万円）・skill_rank（実力の順位）・months_top（月間1位になった月数））

## 注意（言えないこと）
- 架空のデータです。実力の差の大きさ、運の振れの大きさ、人数は作成者が置いたもので、1位が続く確率はこれで決まります（置き方で2.6〜29.6%）。実際の営業チームで実力が何割を占めるかは、ここでは分かりません
- 実力は1年のあいだ変わらず、月ごとの運は人どうし・月どうしで関係がないと置きました。担当の地域や季節の波、大きな案件が翌月にずれ込むこと、調子の波（好調が続くこと）は入れていません。これらがあると、1位は今回より続きやすくなるはずです（推測）
- 1位が続いた月数は1年（12か月）の中で数えたので、年をまたいで続いた分は切れています
- 「月間1位が続かない」ことは、1位の人の実力がないことを意味しません。この置き方では、実力1位の人でも1年に1度も1位にならない年が約1割ありました
