# 546 2つの系列のずらし幅を0〜12か月で動かして最も強い相関を選ぶと、関係がなくても相関はどれだけ高く出るのか（手法の解説・正解の分かるデータで試す）

「広告費は3か月遅れで売上に効く」のように、2つの月次系列をずらして相関を見ることがあります。ずらし幅を0〜12か月の13通り試して、いちばん強い相関を選ぶと、選んだぶんだけ相関は高く出ます。**ここでは、本当は関係のない2つの架空の月次系列（どちらも AR(1)、自己相関 φ = 0・0.5・0.9、長さ 5・10・20年）を各1,000回作り、最も強い相関がどれだけ高く出るか、5つの判定のしかたで「有意」と出る割合がどれだけかを数えました。** 数字は、置いた系列の作り方（AR(1)、正規分布の誤差）で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A546 | ずらし幅を選んだときの最大相関と、判定のしかたごとの「有意」の割合 | y_t と x_{t-k}（k = 0〜12）の相関から絶対値の最大を選ぶ。T1 ずらし幅0だけ t 検定、T2 選んだ幅を t 検定、T3 並べ替え（最大の相関を出し直す）、T4 12か月ブロックの並べ替え、T5 x に AR(1) を当てはめて作り直す。T3〜T5 は199回、各場面1,000回、有意水準5%、seed 546 | `src/a546_lag_search.py` |

## 主な結果（10年＝120か月の場合）
- **最も強い相関の中央値**：自己相関なし（φ=0）で 0.19（ずらし幅0だけなら 0.07）、φ=0.5 で 0.22、**φ=0.9 で 0.33**。φ=0.9 では 1,000回の 58% で 0.3 以上になった
- **選んだ幅をそのまま t 検定（T2）**：関係がないのに「有意」と出た割合は φ=0 で **48%**、φ=0.5 で 68%、φ=0.9 で **84%**
- **ずらし幅0だけの t 検定（T1）でも**、φ=0.9 では 51% が「有意」。選ばなくても、自己相関が強いと t 検定は当てにならない
- **並べ替え（T3）**：選び方は入るので φ=0 では 4% になるが、並べ替えで自己相関が壊れるため φ=0.5 で 20%、φ=0.9 で 66%
- **12か月ブロックの並べ替え（T4）**：4% / 6% / 12%。**AR(1) で作り直す（T5）**：4% / 5% / 7%
- **長さを変えても T2 は 5% に戻らない**：5年・10年・20年で φ=0 は 47〜48%、φ=0.9 は 82〜86%。T5 は 20年で φ=0.9 でも 4.6%

5年・20年を含む全部の数字は `results/summary.csv` にあります。

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- 自己相関なし・ずらし幅0だけ（T1）の「有意」の割合が 5% 前後（4.2〜6.6%）になること
- 最初に試した「丸ごとずらす（循環シフト）検定」は、ずらし方の取り方しだいで 0% や 22% になり、この設定では安定しなかったので使っていない

## データ

## 注意（言えないこと）
- 架空の系列。実際の売上・広告・景気の数字ではない
- 系列は AR(1) と置いた。季節性、トレンド、構造変化がある系列では、数字は変わる。トレンドがある場合は、ここより強く出やすい（推測）
- T4・T5 も前提つき。T4 はブロックの長さ、T5 は AR(1) という形を正しいと置いている
- 「ずらして相関を見るな」という話ではない。何通り試したかを判定に入れること、自己相関を入れることの2つを数字で見たもの
