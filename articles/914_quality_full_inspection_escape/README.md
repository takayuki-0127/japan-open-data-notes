# 914 全数検査なら、不良はゼロになるのか？（品質と検査）

全数検査は、抜き取りではなく作った品物を全部検査することです。全部見るので不良は出ていかない、と考えがちですが、人の目や機械の検査にも見逃しがあります。見逃しの率が10%なら、不良の1割は検査を通って出ていきます。そこで検査を2回、3回とくり返すことがあります。「1回で1割残るなら、2回で1割の1割（1%）」と読みたくなりますが、これは2回目の検査が、1回目に見逃した不良も同じ90%で見つけるときだけの値です。**ここでは、作成者が乱数で作った架空の工場の外観検査（不良1個ごとの見つけやすさを作成者が置いたもの）で、全数検査を1〜3回くり返したときに出ていく不良の数と、「2回目で見つかった数」から残りを読む素直な読み方がどれだけずれるかを数えました。**

1回の全数検査で出ていく不良は「不良の数×見逃しの率」の式どおりです。くり返したときの値も、見つけやすさの分布（ベータ分布）を決めれば式で出せます。この記事では、その値をシミュレーションで数え、置き方でどれだけ動くかを並べました。

## 主な結果

### 全数検査をくり返したときに出ていく不良（月100,000個・不良0.5%・見つけやすさ平均90%、1,000か月の平均）
| 不良ごとの見つけやすさ | 1回 | 2回 | 3回 | 2回のとき「1割の1割」の何倍か | 3回のとき「1割の3乗」の何倍か |
|---|---|---|---|---|---|
| 全部同じ（κ＝∞） | 50.39個（503.9ppm） | 4.96個（49.6ppm） | 0.52個（5.2ppm） | 0.99倍 | 1.05倍 |
| 少し違う（κ＝20） | 50.19個（501.9ppm） | 7.23個（72.3ppm） | 1.34個（13.4ppm） | 1.45倍 | 2.69倍 |
| **違う（κ＝4、基本）** | 50.05個（500.6ppm） | **14.07個（140.7ppm）** | 5.62個（56.2ppm） | **2.81倍** | 11.21倍 |
| 大きく違う（κ＝1） | 49.92個（499.2ppm） | 27.54個（275.4ppm） | 19.33個（193.3ppm） | 5.51倍 | 38.68倍 |

（ppm は100万個あたりの個数）

- 1回の全数検査で出ていく不良は、どの置き方でも月約50個（不良の約1割）で、式どおり。出ていく不良が0個の月はなかった
- 見つけやすさが不良ごとに違うと、2回目の検査は1回目に見逃した「見つけにくい不良」ばかりを相手にする。κ＝4では、2回目が残りの不良を見つけた割合は71.9%、3回目は60.1%で、90%より低かった
- 見つけやすさの平均は、全部の不良で90.0%、1回目で見逃された不良で71.9%、2回目でも見逃された不良で60.0%だった（κ＝4、40万個の不良で数えた）

### 2回目で見つかった数から、残りを読むと（1,000か月の平均）
| 不良ごとの見つけやすさ | 1回目のあとに本当に残っていた | 2回目で見つかった | 素直に読んだ1回目のあとの残り | 2回目のあとに本当に残った | 素直に読んだ2回目のあとの残り | 本当÷素直 |
|---|---|---|---|---|---|---|
| 全部同じ（κ＝∞） | 50.4個 | 45.4個 | 50.5個 | 4.96個 | 5.05個 | 0.98倍 |
| 少し違う（κ＝20） | 50.2個 | 43.0個 | 47.7個 | 7.23個 | 4.77個 | 1.51倍 |
| 違う（κ＝4） | 50.1個 | 36.0個 | 40.0個 | 14.07個 | 4.0個 | **3.52倍** |
| 大きく違う（κ＝1） | 49.9個 | 22.4個 | 24.9個 | 27.54個 | 2.49個 | 11.07倍 |

- 素直な読み方では、2回目で見つかる数が少ないほど「残りも少ない」と読む。実際には、2回目で見つかる数が少ないのは残りが見つけにくいためで、2回目のあとに残る数は逆に多かった

## 動かし方
```
pip install -r requirements.txt
cd src && python a914_full_inspection.py
```

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の9ファイルがバイト単位で一致した（cmp）
- 1回の全数検査で出ていく不良は、どの置き方でも「不良の数×10%」の式の値と同じだった（1.0倍前後）。見つけやすさが全部同じなら、2回・3回でも「10%の2乗・3乗」と同じだった（0.99倍・1.05倍）。作りの確かめで、この部分は式の写し
- くり返したときの倍率は、見つけやすさをベータ分布と置いたときの式（(1−見つけやすさ) の2乗・3乗の平均）でも出せる値で、新しく数えたのは、その値が置き方でどれだけ動くかと、素直な読み方とのずれ
- 倍率は、不良ごとの違いを大きくする（κを小さくする）ほど、どの見つけやすさの平均でも大きくなった（16通りで同じ向き）

## データ
- `data/one_month_defects_kappa4.csv`：基本の置き方（κ＝4）の1か月分の不良1個ずつ。defect_id・visibility（1回の検査で見つかる確率）・found_in_pass1〜3（その回で見つかったら1）・escaped_after_3（3回とも見逃されたら1）。この月の不良は486個で、1回目で430個、2回目で37個、3回目で10個見つかり、9個が3回とも見逃された。見つけやすさが50%未満の不良は2.9%

## 注意（言えないこと）
- 架空のデータです。不良の入る割合、見つけやすさの平均と不良ごとの違い（ベータ分布）は作成者が置いたもので、結果はこれで決まります。実在の工場・製品・検査を表すものではありません
- 見つけやすさの違いは、不良そのものの見えにくさだけを置きました。検査する人の疲れや慣れ、検査する人ごとの差、検査の回ごとの違い（別の人・別の機械で見るなど）は入れていません。2回目を別のやり方で見る場合は、見つけにくい不良が別のやり方では見つけやすいこともあり、この記事の倍率より小さくなりうる（推測）
- 良品を不良とする誤りは入れていません。検査で「不良」と出た品物が本当に不良かは扱っていません
- 素直な読み方は、見本で測った見つけやすさの平均が正しいと置いています。見本の不良が実際の不良より見つけやすければ、ずれはさらに大きくなります（推測）
- どの検査の回数がよいか、検査にいくらかけるべきかは扱いません
- 関連する記事 858 は、締め切り直前に作業が集まると点検が追いつかず、見逃される不具合が増える話を扱っています。この記事は点検が追いついていても残る見逃しを扱いました。911 は測りの誤差で良品が「不良」と出ることと測り直し、915 は検査員どうしの違いの数え方、910 は抜き取り検査で合格したロットに残る不良（検査の見逃しはなしと置いたもの）を扱っています
