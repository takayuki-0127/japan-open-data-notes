## もとのリポジトリの説明

以下は、もとのリポジトリ `mhlw-food-poisoning` の README です（同じリポジトリにあったほかの記事の分も含みます）。

### mhlw-food-poisoning：厚生労働省の食中毒事件一覧（2000〜2025年、約3.3万件）で、食中毒の中身の変化と「1件の大きさ」を調べる

厚生労働省「食中毒統計資料」の食中毒事件一覧（1件ごとの記録）を2000〜2025年の26年分つなげたリポジトリです（国外での発生を除いて33,040件）。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| F1 | 2000〜2025年で、食中毒の原因（病因物質）はどう変わったか。何月に多いか | 病因物質別の事件数・患者数の推移、準ポアソン回帰による年あたりの変化率（2020〜22年のダミーつき）、月別の割合 | `src/f1_trend.py` |
| F2 | 1件あたりの患者数はどんな分布か。何が原因で、どこで起きると大きくなるか | 相補累積分布（両対数）、上位の事件が占める患者の割合、裾へのべき分布・切断対数正規分布の最尤推定とVuong検定、負の二項回帰 | `src/f2_size.py` |

#### 主な結果
- **F1**：事件数は2000〜04年平均の1,876件から2021〜25年平均の984件へほぼ半減し、患者数は30,922人から13,741人に減った。減ったのは腸炎ビブリオ（年あたり−24%、2025年は2件）、サルモネラ（−16%）、黄色ブドウ球菌（−7%）、カンピロバクター（−4%）。ノロウイルスは長い目では横ばい（年あたり+0.1%）で、2020〜22年は4分の1に減ったあと2025年は462件・患者18,566人（その年の患者の75%）に戻った。アニサキスは病因物質に加わった2013年の88件から2022年の570件まで増え（2013年以降、年あたり+10%）、2025年は281件。2016〜2025年の事件で見ると、ノロウイルスは12〜3月に72%、サルモネラ・黄色ブドウ球菌・腸管出血性大腸菌は7〜9月に53〜57%が集まる（腸炎ビブリオは8〜9月に87%だが、この10年で47件しかない）
- **F2**：1件あたりの患者数の中央値は4人、平均は17.7人で、患者1人の事件が33%。患者数の多い上位1%の事件で全患者の25%、上位5%で48%、上位10%で62%を占める。裾（患者20人以上）は対数正規分布のほうがべき分布より当てはまりがよく（Vuong検定 p<0.001）、100人以上に限ると両者は区別できない（べき指数は約2.6）。病因物質と原因施設をそろえた負の二項回帰では、カンピロバクター・飲食店と比べて、ウェルシュ菌で5.6倍、ノロウイルスで3.2倍、製造所で6.0倍、仕出屋で3.7倍、家庭で0.32倍、アニサキスで0.27倍。500人以上の事件61件のうち32件が仕出屋、28件がノロウイルス

#### 動かし方
元データ（各年の事件一覧 Excel、合計約5MB）は `data/raw/` に入れてあります（ファイル名の先頭が年。`nenji_` は年次別の発生状況、`2026s_` は2026年の速報）。つなげたデータは `data/outbreaks_2000_2025.csv` です。

```bash
pip install -r requirements.txt
cd src
python f1_trend.py
python f2_size.py
```

#### データ
| ファイル | 中身 |
|---|---|
| data/raw/YYYY_*.xls(x) | 各年の食中毒事件一覧：都道府県名等、発生月日、発生場所、原因食品、病因物質、原因施設、摂食者数、患者数、死者数 |
| data/outbreaks_2000_2025.csv | 上を1つにつなげ、病因物質と原因施設をまとめたもの（group, fac 列） |

#### 注意
- 国外での発生（参考として載っている分）は除きました。それでも年次別の公表値より数件〜数十件多い年があります（2000年は2,276件、公表値2,247件など）
- 2003年以前の「小型球形ウイルス」はノロウイルスとしてまとめました。アニサキスは2013年から病因物質の分類に加わったため、それ以前は「その他」に入っていて比べられません
- 病因物質の「その他の病原大腸菌」「クドア」「セレウス菌」などは「その他・不明」にまとめています
- 届け出られた食中毒だけの数です。患者1人の事件（アニサキスやカンピロバクターに多い）は、医療機関の受診と届け出の傾向に左右されます
- 2020〜2022年は新型コロナの影響（外食や宴会の減少）を受けていると考えられます
