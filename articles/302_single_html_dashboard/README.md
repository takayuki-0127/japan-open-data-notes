# 302 HTML だけで、配れるダッシュボードは作れるか（実務の型）

サーバーを立てずに、HTML ファイルを1つ渡すだけで見られるダッシュボードを、同じ画面・同じデータで4つの作り方にして、ファイルの大きさ・ネットなしで描けるか・描き終わるまでの時間を Chromium で測ったフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A302 | HTML 1枚のダッシュボードは、どの作り方なら、渡した相手の手元で確実に開けるか。データはどこまで中に入れられるか | 宿泊旅行統計の全国・月別の延べ宿泊者数（2015〜2025年、6区分）で、区分の切り替え・3つの数字・折れ線の画面を作る。V1＝グラフの部品（Chart.js 4.4.1）を CDN から読む／V2＝部品も HTML の中に入れる／V3＝部品を使わず SVG を自分で描く／V4＝部品は中に入れ、データだけ別ファイル（data.json）から読む。開き方は「ファイルをそのまま開く（ネットあり・なし）」と「手元のサーバーから開く」。各15回。別に、中に入れる明細を1,000〜100万行に増やして測る（各5回） | `src/a302_build.py`・`a302_measure.py`・`a302_figs.py`、`html/` |

## 主な結果
- **V1（部品を CDN から）**：11KB。ネットがあれば描けた（15/15）が、ネットなしでは0/15。画面には数字のカードだけが出て、グラフは空のまま
- **V2（部品も中に）**：211KB（zip で76KB）。ネットあり・なしとも15/15、描き終わるまで約60〜70ミリ秒
- **V3（部品なし・SVG）**：11KB。ネットあり・なしとも15/15、約10ミリ秒
- **V4（データだけ別ファイル）**：ファイルをそのまま開くと、ネットがあっても0/15（データを読み込めない）。手元のサーバーから開けば15/15
- 区分の切り替え（外国人に切り替えて2019年比が155.6%になる）は、V2・V3 ともネットなしで動いた
- **中に入れる明細の行数**：10万行で約2MB・0.1秒、30万行で約6MB・0.3秒、100万行で約20MB（zip で5.4MB）・約1秒。V2 と V3 の差は、部品の大きさ（約200KB・約50ミリ秒）の分だけ

時間は測るたびに数%〜数十%揺れます（`results/variants.csv` の min・max）。大小の関係は2回測って同じでした。

## 動かし方
```
pip install -r requirements.txt
python -m playwright install chromium   # まだ入っていない場合
cd src && python a302_build.py && python a302_measure.py && python a302_figs.py
```
`html/` に V1〜V4 と data.json、行数を増やした `big_*.html`（最大20MB。GitHub には置いていません）ができます。

## 確かめたこと
- 空のフォルダで作り直し、`html/` の V1〜V4・data.json が一致した。測り直しても「描けた回数」とファイルの大きさは同じ（時間は揺れる）
- 2019年比のカードの値（全体110.9%）は、元の CSV から計算した値と同じ

## 注意（言えないこと）
- 測ったのは Chromium 1種類・1台の環境です。ほかのブラウザや古い PC、スマホでは時間が変わります。V1 の「ネットあり」の時間は、この環境から CDN までの回線の速さを含みます
- 会社のメールやチャットで HTML の添付が止められるか、開いたときに警告が出るかは、試していません
- HTML の中に入れたデータは、ファイルを受け取った人が全部見られます。出してよい範囲に集計してから入れる必要があります
- 行数の試しは架空の明細（3列）です。列が多いデータや、画面での集計が重い場合は、もっと少ない行数で遅くなります
- 「問いに答えやすい画面か」は F271 で扱いました。この記事は配り方に絞っています
