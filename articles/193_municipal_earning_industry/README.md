# 193 市区町村の「稼ぐ力」は、どの産業が支えているか：令和3年経済センサス‐活動調査

令和3年経済センサス‐活動調査の市区町村別・産業大分類別の純付加価値額から、市区町村ごとに付加価値（稼ぎ）が最も大きい産業と特化係数が最も高い産業を出し、事業従事者1人当たりの純付加価値額と製造業の割合の関係を見たフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A193 | 市区町村の「稼ぐ力」は、どの産業が支えているか | 市区町村ごとの産業別純付加価値額の構成比、1位の産業、特化係数（市区町村の構成比÷全国の構成比）、事業従事者1人当たり純付加価値額、製造業の割合別の中央値 | `src/a193_extract.js`（ブラウザ上で集計）、`src/a193_plots.py`（図と要約） |

## 主な結果
- 全国の純付加価値額は医療・福祉（21.6%）、製造業（16.4%）、卸売業・小売業（16.2%）の順に大きい
- それでも市区町村ごとに1位の産業を見ると、製造業が1,741市区町村のうち910（52.3%）と過半数。卸売業・小売業303（17.4%）、医療・福祉270（15.5%）、建設業149（8.6%）が続く
- 事業従事者10万人以上の119市区町村では卸売業・小売業が58で最多、5千人未満の656市区町村では製造業244・建設業139・医療・福祉126
- 構成比5%以上の産業で特化係数が最も高いのも製造業（507）。農林漁業284（中央値26.9倍）、建設業236、運輸業・郵便業190、宿泊・飲食サービス117
- 1つの産業で純付加価値の半分以上を占める市区町村は234あり、うち185が製造業
- 事業従事者1人当たり純付加価値額の中央値は、製造業の割合が10%未満の市区町村で361万円、50%以上で489万円（市区町村全体の中央値396万円、相関係数0.27）

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a193_plots.py
```
- `a193_extract.js` は e-Stat のページで SheetJS を読み込んで実行し、元の表（約21万行）から data/ の集計を作ったもの

## データ
| ファイル | 中身 |
|---|---|
| data/national_industry.csv | 全国の産業大分類別 事業所数・事業従事者数・純付加価値額（百万円）・構成比 |
| data/muni_by_industry.csv | 産業ごとの「1位の産業」の市区町村数（規模別）、1人当たり純付加価値額と1位産業の割合の中央値、「特化係数1位」の市区町村数と特化係数の中央値 |
| data/muni_by_size.csv | 事業従事者数の規模別の市区町村数と中央値 |
| data/muni_by_mfg_share.csv | 製造業の割合別の1人当たり純付加価値額（中央値と25・75%点） |
| data/big_cities.csv, data/top_va_per_worker.csv, data/lq_examples.csv | 事業従事者30万人以上の市区、1人当たり純付加価値額の上位（事業従事者1,000人以上・秘匿の割合10%以下）、特化係数の例 |

- 令和3年経済センサス‐活動調査 事業所に関する集計 産業横断的集計 第2-2表（statInfId 000040067943、全国・都道府県・市区町村、経営組織＝総数）
- 市区町村は1,741（政令市は市の計、東京23区は区ごと。都道府県計・特別区部計・境界未定地域・政令市の区を除く）

## 注意
- 純付加価値額は事業所単位の値で、本社に大きく計上される企業や法人があると、その市区町村の値が大きくなる（港区の1人当たり5,002万円・医療・福祉73%など）
- 秘匿（X）の値は構成比では0として扱い、1人当たりの値は値が出ている産業の従事者だけで割った。秘匿の多い小さな町村ほど誤差が大きい
- 特化係数は全国の構成比が小さい産業（農林漁業0.35%、鉱業0.10%など）ほど大きく出やすい
- 公務は含まない。2021年6月時点（コロナ禍の影響を含む）の1時点の比較
- 「稼ぐ力」は純付加価値額で見ていて、域外から稼ぐ（移出する）産業かどうかは、このデータでは分けられない
