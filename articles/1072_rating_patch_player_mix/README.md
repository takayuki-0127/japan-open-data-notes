# 1072 調整の前後でキャラクターの勝率を比べると、使う人の入れかわりが何をまぜるのか？（対戦とレーティング）

対戦ゲームでキャラクターを強くする調整が入ると、「調整の前後で勝率がどれだけ上がったか」で効き目を読みがちです。けれども、強くなったキャラクターには、新しく使い始める人が集まります。新しく使い始めた人が、使い続けてきた人よりうまくなければ、同じ人なら勝率が上がっていても、全体の勝率は下がって見えることがあります。**ここでは、作成者が乱数で作った架空の対戦ゲーム（キャラクターXを強くする調整の効き目と、使う人のうまさ・入れかわりを作成者が置いたもの）で、前後の勝率をそのまま比べる・同じ人だけで比べる・調整の前の点数の帯ごとに比べるの3つを、本当の上がり幅と比べました。**

季節のあるデータで施策の前後を比べる話は 377、キャラクターの勝率に使う人のうまさが混ざる話は同じ企画の 1069、使われる割合の高いキャラクターが強いのかは 1070 で扱っています。この記事は、時間の流れや季節は入れず、調整の前後で使う人が入れかわることだけに絞ります。勝った人ほど使い続けるときの「同じ人だけ」のずれは、830（2年目のジンクス）と同じ平均への回帰の仕組みです。

## 主な結果

### 基本の置き方（500回の平均、`results/reps_base.csv`）
| 比べ方 | 後−前の勝率 | 5〜95%の範囲 |
|---|---|---|
| ① 前後をそのまま | **−3.38ポイント** | −3.95〜−2.8 |
| ② 同じ人だけ | +5.24ポイント | +4.79〜+5.7 |
| ③ 調整の前の点数の帯ごと | +2.88ポイント | +2.35〜+3.4 |
| 本当の上がり幅（後に使った人） | **+5.33ポイント** | +5.31〜+5.34 |
| 本当の上がり幅（同じ人＝残った人） | +5.24ポイント | +5.21〜+5.26 |

- **同じ人なら勝率が+5.33ポイント上がる調整なのに、前後をそのまま比べると−3.38ポイントと下がって見えた**（500回すべてで下がって見えた）
- ①は、本当の上がり幅（+5.33）と、使う人の入れかわりの分（−8.71）の足し算に分かれる。式の値は、前 56.45%・後 53.06%・差 −3.39 で、本当の上がり幅 5.33 ＋入れかわり −8.71 のとおり（式どおり）。調整の後に使った人のうち、新しく使い始めた人が 67.57% を占めた
- ②の同じ人だけの比べは、残った人の本当の上がり幅（+5.24）に合った。ただし、これは「残った人」にとっての上がり幅で、新しく使い始めた人の上がり幅は含まない
- ③の点数の帯ごとの比べは +2.88 で、①よりは近いが本当の上がり幅の半分ほどにとどまった。点数がうまさを誤差つきでしか表さないので、帯の中にもうまさの差が残るため

### グループごとの勝率（式の値、`results/a1072_main.json` の `groups_formula` と図2）
- 使い続けてきた人は、調整がなかったら 56.45%、調整の後 61.68%。新しく使い始めた人は、調整がなかったら 43.55%、調整の後 48.92%。どちらのグループも上がっているのに、全体では 56.45% → 53.06% と下がって見える

### 確かめ：入れかわりの置き方（42通り、各100回、`results/sensitivity_grid.csv`）
- ①のずれ（本当の上がり幅との差）は −13.68〜+3.44ポイント。調整を効かせた28通りのうち18通りで、①の平均が0未満（向きまで逆）だった
- 新しく使い始めた人がいなくても、勝った人ほど使い続けると、①は +3.33〜+3.44ポイント大きく出た（うまい人が残るため）
- ②のずれは、残り方が勝ち負けに関係ないとき −0.05〜+0.07ポイント、勝った人ほど残るとき −1.23〜−1.11ポイント。前の期間にたまたま勝った人が残り、後の期間に平均へ戻るため（平均への回帰）
- ③のずれは −4.19〜+0.92ポイント。新しく使い始めた人のうまさが低いほど、大きく下にずれた

### 1回分のデータ（`data/players_example.csv`）
- 基本の置き方の1回分。使い続けてきた人1,500人のうち残ったのは1,177人。前の勝率 56.56%、後 52.9%、①の差 −3.67、②の差 +5.12、③の差 +2.69ポイント

- 新しく使い始めた人がいなくて、残り方が勝ち負けに関係ないとき、①②③はどれも本当の上がり幅と合った（ずれ −0.03〜+0.01ポイント）

## 注意（言えないこと）
- 架空のデータです。調整の効き、使う人のうまさ、入れかわりの人数、残り方は作成者が置いたもので、結果はこれで決まります。①のずれの大きさは、置いたうまさの差と入れかわりの割合からの式どおりです。新しく数えたのは、②③で直したときに残るずれと、その向きです
- 相手は全体からでたらめに当たると置きました。点数の近い人どうしを当てる仕組みがあると、勝率はうまさに関係なく5割に近づくので、話が変わります（1074 で扱っています）
- 新しく使い始めた人が使ううちにうまくなること、相手のキャラクターの調整、時間の流れや季節は入れていません
- 実在のゲームの調整を評価するものではありません。調整をどうすべきかの助言もしません
