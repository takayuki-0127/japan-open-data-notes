# 396 自然災害で亡くなる人は、いつから大きく減ったのか（防災白書の付属資料、1945〜2025年）

令和8年版 防災白書の付属資料にある「自然災害による死者・行方不明者数」（年ごと）と「主な自然災害の状況」（災害ごと）から、主な地震・津波・噴火の分を引いた数を作り、時期ごとに比べたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A396 | 自然災害による死者・行方不明者は、戦後のいつから大きく減ったか | 年ごとの数から、一覧にある地震・津波・噴火の死者・行方不明者を引く（「地震などを除いた数」）。時期ごとの平均・中央値、1,000人以上・500人以上・100人未満の年の数 | `src/a396_disaster_deaths.py` |

## 主な結果
- 1945〜2025年の合計は79,384人。多い5年（2011・1995・1945・1959・1948年）で58%。東日本大震災・阪神・淡路大震災・福井地震の3つで41%
- 地震などを除いた数の年平均：1945〜59年 1,860人（中央値1,291人）→ 1960年代 447人 → 1970年代 244人 → 1980年代 188人 → 1990年代 98人 → 2000年代 107人 → 2010年代 172人 → 2020〜25年 109人
- 1960年代は1945〜59年の24%。1959年を外した1945〜58年（1,574人）と比べても28%
- 1,000人以上の年は10回で、すべて1945〜59年（最後は1959年）。500人以上は1982年（524人）が最後。100人未満の年は1945〜59年に1回、1960〜89年に4回、1990〜2025年に18回
- 5年ごとの平均：1960〜64年505人 → 1985〜89年121人 → 1995〜99年90人。2010〜14年は187人、2015〜19年は157人で、1990年代より多い。2018年は409人で1982年より後の最多

## 確かめたこと
- 文字から取り出した年ごとの数は81年分。1945・1959・1995・2011・2024・2025年の値を白書の表と照合
- 一覧の災害は69（地震・津波・噴火30、風水害28、雪害11）。伊勢湾台風・東日本大震災・阪神・能登の年と人数を照合
- 1945年を除く（1946〜59年の平均1,724人）、一覧の地震が100人以上の年を丸ごと除く、の2通りでも、1960年前後の段差は同じ向き（`results/a396_main.json`）
- 空のフォルダで流し直し、data・results・figures が一致した

## 動かし方
```
pip install -r requirements.txt
cd src && python a396_disaster_deaths.py
```

## データ
- `data/raw/bousai_r8_appendix_p1_2.txt`：内閣府「令和8年版 防災白書」附属資料（PDF）の1〜2ページを `pdftotext -layout` で文字にしたもの（2026-11-12 取得）。PDF そのものは置いていません
- `data/annual_deaths.csv`：年ごとの数、一覧にある地震・津波・噴火の分、それを引いた数
- `data/major_disasters.csv`：一覧の災害（年・名前・種類・死者・行方不明者数）。種類は名前から機械的に分けたもの

## 注意（言えないこと）
- 「地震などを除いた数」は風水害だけの数ではありません。雪害などを含み、一覧にない小さな地震の分も残っています
- もとの資料は時期で違います（1945年は主な災害だけ、1946〜52年は日本気象災害年報、1953〜62年は警察庁、1963年以降は消防庁）
- 人口では割っていません。減った理由（堤防・予報・避難・台風の来方など）は分けていません。対策の効果を測ったものではありません
- 年ごとの全国の合計だけを使っています。2025年は速報値です
