# F293 毎月の数字の「おかしい」を、どう自動で見つけるか？ ― 本物の公的統計3つに、正解の分かる汚れを入れて試す

看板記事 F293（精選モード D. 求人票の業務 Q40、F69・F253 の続き）。F253 では、架空のスーパーの合成データで、毎月の品質チェックが汚れの98%を見つけ、汚れのない月の誤報はほぼ0だった。同じ考え方のチェックを**本物の公的統計の月の系列**（商業動態統計・消費者物価・家計調査）にかけ、**正解の分かる汚れ**を1か月に入れて見つかる割合を測り、汚れのない月に鳴った月を**事前に書き出した出来事のカレンダー**で仕分けた。計画（PLAN.md、コミット 25f1b24）はチェックの結果を出す前に置いた。

## 問い

- 合成データでうまくいったチェックは、本物の統計でも汚れを見つけられるか。統計の種類（ふだんの揺れの大きさ）で、見つけられる汚れの大きさはどう変わるか。
- 汚れのない月に、チェックはどれだけ鳴るか。鳴った月のうち、消費税・コロナ・補助金・税の改正などの出来事で説明できるのはどれだけか。

|---|---|---|---|---|

| S3 | 総務省統計局「家計調査」品目別支出金額（二人以上の世帯、円） | 消費支出・食料・酒類・清酒・焼酎・ビール・ウイスキー・ワイン・発泡酒等・チューハイ等・たばこの11 | 2015-01〜2026-09 | F283 |

評価する月は、チェックに必要な過去の月（15か月＋揺れを測る36か月）がそろう月から：S1 は 2018-04〜2026-08、S2・S3 は 2019-04〜2026-09（S1 6系列×101か月、S2 537品目×90か月、S3 11品目×90か月）。

## チェック（毎月、その月より前のデータだけで判定）

| 記号 | 中身 |
|---|---|
| R | 0以下・欠け・**前月とまったく同じ値** |
| R（停止なし） | 0以下・欠けだけ |
| M1 | 前年同月比の対数が ±0.2 を超える（約±20%） |
| M2 | 予測＝前年同月の値 × 直近3か月の前年同月比の平均。外れを、過去36か月の外れの MAD×1.4826 で割った z が ±4 を超える |
| M3 | 前月比の、前年同月の前月比との差を、過去36か月の MAD で割った z が ±4 を超える |

主に使う組み合わせは R（停止なし）∪ M2（R ∪ M2 は H1 の判定に使用）。揺れの大きさには下限 0.2% を置いた（CPI のほとんど動かない品目で MAD が0になるため。計画にはなかった）。

## 入れた汚れ

系列ごとに、評価する月から1か月を乱数で選び、1種類ずつ入れた（S1・S3 は系列×汚れ×200回、S2 は品目×汚れ×5回、乱数の種0）。

E1 10倍／E2 10分の1／E3 1000倍／E4 0／E5 前月の値のまま／E6 同じ統計の別の系列の値／E7 +15%／E8 −15%／E9 +5%

## 出来事のカレンダー（計画で決めたもの）

全系列：消費税（2014-03〜05、2019-09〜11）、コロナ（2020-03〜2021-09）。S2・S3 は品目名で、携帯電話の通信料・保育料・授業料・宿泊料・電気代と都市ガス代（補助金）・ガソリンと灯油・米・たばこ（税）・酒類（税）の期間を足し、S3 には家計簿の改正（2018-01）・品目分類の改定（2025-01）を足した。それぞれ前後1か月までを出来事の月とした。

## 結果

### 入れた汚れが見つかった割合（R（停止なし）∪ M2、%）

| 汚れ | S1 商業動態 | S2 消費者物価 | S3 家計調査 |
|---|---|---|---|
| 10倍・10分の1・1000倍・0 | 100 | 100 | 100 |
| 別の系列の値 | 91.8 | 56.6 | 85.4 |
| −15% | 70.5 | 91.4 | 21.5 |
| +15% | 65.1 | 90.2 | 19.0 |
| +5% | 13.1 | 63.3 | 3.0 |
| 前月の値のまま | 25.4 | 6.6 | 10.5 |

- 前年同月比±20%（M1）だけだと、+15% は 21%・17%・29%。家計調査では M1 のほうが M2 より多く見つける（+15% 29.1% 対 19.0%、−15% 26.3% 対 21.5%、別の系列の値 94.1% 対 85.4%、前月の値のまま 21.4% 対 10.5%）が、汚れのない月の鳴りも年1.13回対0.25回（4.4倍）と多い。
- CPI の「前月の値のまま」（E5）は、入れた月の26.3%がもともと前月と同じ値だった（入れても値が変わらない）。値が前月と違った月だけで数えると 6.3%（S1 25.4%、S3 10.5%）。
- ふだんの揺れ（M2 の外れの MAD×1.4826、系列の中央値）は S1 2.6%、S2 0.9%、S3 8.4%。z=4 で見つかるのは、揺れの4倍より大きいずれになる。

### 汚れのない月の鳴り（本物の動きを含む。1系列・1年あたり）

汚れを入れていない元の系列で鳴った回数。本物の値上げや出来事の月も入っているので、すべてが「誤報」ではない。

| | 前月と同じ値 | M1 | M2 | M3 |
|---|---|---|---|---|
| S1 | 0.00 | 0.44 | 0.81 | 0.69 |
| S2 | 3.06 | 0.26 | 0.81 | 0.70 |
| S3 | 0.04 | 1.13 | 0.25 | 0.33 |

- M2 が鳴った月のうち出来事の月：S1 88%（41回中36）、S2 36%（3,250回中1,175）、S3 67%（21回中14）、合わせて37%。
- ただし汚れのない月のうち、もともと出来事の月は S1 25.7%・S2 29.5%・S3 34.7%（合わせて29.5%）ある。鳴った月の割合はこの基準の S1 3.4倍・S2 1.23倍・S3 1.9倍で、**S2 は偶然に近い**。コロナの期間を除くと、S2 は鳴った月の17.4%が出来事の月で、基準は10.6%。
- コロナの期間（2020-03〜2021-09）とそれ以外の M2 の鳴る回数（1系列・1年）：S1 2.63 対 0.39（6.7倍）、S2 0.87 対 0.79、S3 0.29 対 0.25。合わせると1.13倍。

### 仮説の判定

| 仮説 | 結果 | 判定 |
|---|---|---|
| H1 大きな汚れ（E1〜E4）は R∪M2 で3つとも99%以上 | 3つとも100% | 支持（10倍・0などはふだんの揺れよりはるかに大きいので、ほぼ作りから決まる確認の仮説） |
| H2 +15% の見つかる割合は家計調査が消費者物価より30ポイント以上低い | 90.2% 対 19.0%（差71ポイント） | 支持 |
| H3 CPI では「前月と同じ値」が汚れのない月にも10%以上 | 25.5%（1品目あたり年3.1回鳴る） | 支持 |
| H4 M2 が鳴った月の50%以上が出来事の月 | 37%（S2 が鳴りの98%を占める。S1 88%・S3 67%。基準の割合は 25.7%・29.5%・34.7%で、S2 は1.23倍と偶然に近い） | 外れ |
| H5 コロナの期間の鳴る割合がそれ以外の3倍以上 | 合わせて1.13倍（S1 だけなら6.7倍。事後の内訳で、S1 の鳴りは41回だけ） | 外れ |

## 問い直し（結果を見た後に足した）：出来事で説明できない CPI の鳴りは、何が鳴らしているのか

- **1つの段差が何回も鳴る**：CPI で M2 が鳴った3,250回のうち、同じ品目で直前2か月にも鳴っていた「続き」が56%、10〜14か月前に鳴っていた「1年後の折り返し」が18%で、「はじめの1回」は26%だけだった。新聞代のように値段が段で上がる品目では、上がった月から3か月続けて鳴り、1年後に前年同月が入れ替わるときにもう一度鳴る（M2 の予測が前年同月の値と直近3か月の伸びでできているため）。はじめの1回だけを数えると、鳴る回数は1品目あたり年0.81回から0.21回（出来事以外は0.14回）になる。
- **動かない品目ほど鳴る**：品目を「前月と同じ値」の多さで5つに分けると、出来事以外で鳴る回数は、よく動く品目（同じ値1%）で年0.33回、ほとんど動かない品目（同じ値80%）で年1.26回だった。
- **2022年からの値上げ**：出来事以外の鳴りは、2019〜2021年は年20〜77回、2022〜2025年は年298〜451回だった。4月・10月の割合は21%（12か月に均等なら17%）で、時期の偏りは小さかった。
- **直し方の1つ**：揺れの下限を0.2%から1%に上げると、CPI の汚れのない月の鳴りは年0.81回から0.35回に減り、+15% の見つかる割合はほぼ変わらず（90.2→90.1%）、+5% は63.3%から60.2%になった。ただし減るのは出来事の月の鳴りに偏り、鳴った月のうち出来事の月の割合は36%から21.5%に下がった（本物の動きも一緒に消している）。

## 計画からのずれ

- 評価する月の始まり：計画は 2018-01 からだったが、チェックに要る過去の月がそろうのが S1 2018-04、S2・S3 2019-04 だったので、そこから始めた。
- 揺れの大きさに下限 0.2% を置いた（CPI の動かない品目で MAD が0になり、z が無限大になるため）。
- 「前月と同じ値」のルールが CPI で年3回鳴ったため、主な組み合わせとして R（停止なし）∪ M2 も並べた（H1 の判定は計画どおり R ∪ M2）。
- 計画の R にあった「同じ統計の別の系列と同じ値」のルールは入れなかった（汚れ E6 は M2 で測った）。
- 問い直し（段差の続き・折り返し、動かなさ、年別、下限1%）は結果を見た後に足した。
- 出来事のカレンダーの品目の当て方が、計画の言葉と少し違った：「携帯電話」の語で携帯電話機（物価）も当たった、米類は表にあるうるち米A・Bだけになった、酒の語に焼酎・ウイスキー・酒を足した。計画の言葉どおり（携帯電話機を外し、酒の語を計画の例に限る）に当て直しても、M2 が鳴った月のうち出来事の月は合わせて37.0%（S1 88%・S2 36.1%・S3 67%）で変わらない（`results/D_reask.json`）。
- H4 の基準の割合（汚れのない月のうち出来事の月）、E5 を値の変わった月だけで数えた割合、誤報をそろえる条件のしきい値と中身は、独立レビューの後に足した。

## 言えないこと

- 汚れは筆者が入れたもので、本物の統計で実際に起きる誤りの起き方・大きさとは違う。公表された数字に誤りがあったという話ではない。
- 出来事のカレンダーは筆者が書き出したもので、漏れがありうる。とくに CPI の個別の値上げ（会社ごとの価格改定）は入れていない。
- S3 は11品目、S1 は6業態と少ない。S2 の汚れは品目ごとに5回しか入れていない。
- 家計調査の揺れには、世帯の入れ替わりによる標本の揺れが入っている。会社の中の数字（POS や会計）は、家計調査よりずっと揺れが小さいことが多い（推測）。
- チェックの設計（M2 の予測の作り方、z=4）は1つの例で、季節調整のモデルや機械学習の方法は試していない。

## レビューで直したこと

記事・README・コードを別の担当に渡して、独立に確かめてもらった。M2 にその月より後のデータが入っていないこと、出来事のカレンダーが計画にあること、数字の再計算と再現は一致した。指摘を受けて次を直した。

- H4：汚れのない月のうち出来事の月の基準の割合（25.7%・29.5%・34.7%）を足し、CPI の37%前後は偶然の1.23倍で、偶然に近いと書いた。
- 家計調査では M1 のほうが M2 より多く見つけるが、鳴りも4.4倍多いことを足した。
- 「誤報を年0.5回にそろえる」条件に先読みがあること、実際の回数（0.59・0.53・0.53）を書いた。その中身を results に出した。
- 汚れのない月の鳴りには本物の動きも入るので、「誤報」と言い切らないようにした。下限1%で出来事の月の鳴りが多く消えること（36%→21.5%）を足した。
- 数字の丸め（6.7倍、90.1%、97.3%）、CPI の E5 で入れた月の26.3%がもともと前月と同じ値だったこと、カレンダーの当て方のずれ、S1 の内訳が41回だけの事後の内訳であること、H1 が確認の仮説であることを書いた。
