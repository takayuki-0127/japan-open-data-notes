# F318 フリーランス・ひとりで働く人は、本当に増えたのか？ 労働力調査の「雇人のない業主」は2000〜02年の522万人から2023〜25年の398万人に減った。最近増えたのは女性だけで、男性は−9だった

## 結論（先に）
- 労働力調査で、人を雇わずにひとりで事業をする自営業主（雇人のない業主）は、2000〜02年平均の522万人から2023〜25年平均の398万人に減りました（対数差×100 で −27）。働く人に占める割合も8.2%から5.9%に下がりました。この統計で見る限り、「ひとりで働く人が増えた」とは言えません。
- 2013〜15年平均から見ても、全体では418万人から398万人（−5）で、増えていませんでした。ただし男女で分けると、男性は −9、女性は +5 で、最近増えたのは女性だけでした。
- 問い直し：女性の雇人のない業主は増えましたが、女性の働く人の増え方（+12）より小さく、女性の働く人に占める割合は4.2%から3.9%に下がっていました。
- 雇われて働く人（雇用者）は +14 増え、雇有業主（人を雇う自営業主）は −49、家族従業者は大きく減りました。自営は、どの形でも減っています。ただし自営の中では、ひとりで事業をする人の割合（自営業主と家族従業者の合計に占める割合）が51%から64%に上がりました。

## 問い
「フリーランスが増えた」「会社に属さずひとりで働く人が増えた」とよく言われます。働き方の統計を読む人や、地域の産業の担当の人にとっては、それが統計でどこまで確かめられるのかが知りたいところです。労働力調査の「雇人のない業主」で、長い目の動き、働く人に占める割合、男女の違い、最近の動きを見ました。フリーランスという働き方の良し悪しは扱いません。

## データ（出典）
- 総務省「労働力調査」基本集計 長期時系列表4(1)「従業上の地位別就業者数」（1953〜2025年、年平均、男女別、万人）：就業者総数、自営業主、うち雇有業主、家族従業者、雇用者。
- 雇人のない業主 ＝ 自営業主 − 雇有業主。1973年は沖縄を含む値（2行あるうちの後ろ）を使いました。
- URL と取得日は data/raw/SOURCES.md にあります。

## やったこと
1. 長期時系列表から、年×男女の就業者の内訳を取り出し、雇人のない業主を計算しました。
2. 3年平均どうしを対数差×100 で比べ、割合はポイントで比べました。
3. 頑健性を4つ、問い直しを1つ足しました。

## 分かったこと
### 雇人のない業主は長い目で見て減った（図1）
1990年の685万人から、2000年に549万人、2011年に424万人、2025年に395万人になりました。2016年ごろからは400万人前後で、減り方はゆるやかになっています。

### 働く人に占める割合も下がった（図2）
男女計で、1990年の約11%から2023〜25年平均の5.9%になりました。女性は2016年ごろから3.9%前後で横ばいです。

### 雇われる人は増え、自営はどの形でも減った（図3）
2000〜02年→2023〜25年で、雇用者は +14、雇人のない業主は −27、雇有業主は −49 でした。働く人全体（+6）の伸びは、ほぼ雇われる人の増加によるものです。

## 問い直し（結果を見てから足した）
H4 を男女に分けると、男性は −9、女性は +5 と向きが逆でした。「女性のひとり事業主が増えたのは、女性の働く人が増えたからではないか」と考え、男女それぞれの就業者に占める割合と、始点を変えたときの差を見ました（src/03b_requestion.py、図4）。

| 2013〜15年平均 → 2023〜25年平均 | 男性 | 女性 |
|---|---|---|
| 雇人のない業主（対数差） | −8.7 | +4.8 |
| 就業者（対数差） | +1.8 | +12.0 |
| 就業者に占める割合 | 8.3% → 7.5% | 4.2% → 3.9% |

始点を2010〜12年から2018〜20年までの3年平均に変えても、女性は +3〜+8、男性は −5〜−11 で、向きは同じでした。女性のひとり事業主は数としては増えましたが、女性の働く人の増え方には届かず、割合では下がっていました。

## 言えないこと
- 労働力調査の「雇人のない業主」は、フリーランスと同じではありません。農家や商店の自営も含み、会社をつくって役員になった人は入りません。
- 主な仕事の区分なので、副業でフリーランスをする人は見えません。
- 女性の雇人のない業主の増加は、3年平均で約116万人から約121万人へ、6万人ほどです。労働力調査は標本調査で万人単位の値なので、この大きさの差には標本のぶれも含まれうると考えます（推測。標準誤差は計算していません）。
- 年齢や産業の構成の変化（農業の自営の減少など）は、この表だけでは分けられません。
- 2011年は東日本大震災の影響で、一部の県の値を補った推計です。
- 2022年の就業構造基本調査で集計された「フリーランス」の数とは比べていません。

## 仕事で使うなら
- 「フリーランスが増えた」を示すときは、どの統計のどの区分かを書き添えると、誤解が減ります。労働力調査の雇人のない業主では、全体としては増えていません。
- 男女や時期を分けると向きが変わることがあります。数と割合を並べると、読み違いが減ります。
