# 1300 配送先の方面ごとに分けて詰め、方面をまぜないと、全部をまとめて詰めるより車は何台増えるのか？（箱詰めと積載）

配送では、届け先の方面ごとに車を分け、1台の車にほかの方面の荷物をまぜないことがあります。まとめて積めば1台に収まる荷物も、方面ごとに分けると、方面ごとに最後の1台が半端に残ります。**ここでは、作成者が置いた架空の通販の配送（荷物1個の大きさ、1日の荷物の量、4つの方面の割合を置き、乱数で作ったもの）で、その日の荷物を全部まとめて積んだときと、方面ごとに分けて積んだときの車の台数を200日分数え、何台増えるかを比べました。方面の数・1日の量・荷物の大きさ・方面の割合の偏りを変えた36通りで確かめました。**

すべて作成者が置いた決まりでのシミュレーションです。荷物は大きさ（体積）だけで数え、重さや形は考えていません。実在の運送会社・車を表すものではありません。

関連する記事：876「窓口を1列にするか、窓口ごとに並ぶかで、待ち時間は？」は、窓口ごとに列を分けると、1列にまとめるより平均の待ちが長くなることを扱っています。1168「小さなファイルがたくさんあると、大きさの合計と実際に使う量はどれだけ違うのか？」は、1件ごとに決まった大きさの区画へ切り上げると、使う量が大きさの合計を上回ることを扱っています。1304「届ける順に取り出せるよう、あとで届ける荷物を奥に積む決まりを入れると、積載率はどれだけ下がるのか？」は、あとで届ける荷物を奥に積む決まりを入れると、並べる順が縛られて床の積載率が下がり、台数が増えることを数えています。この記事は、同じ「分けると融通がきかなくなる」形を車の台数で数え、分けた単位ごとに最後の1台へ切り上げる分が、分けた数だけ重なる点に絞ります。

## 主な結果

### 基本の置き方（方面4・同じ割合・1日車10台分・荷物の中央値20L、200日、`results/a1300_main.json` の base）
| 積み方 | 車の台数（平均） | 積載率（平均） | 台数が下限と同じだった日 |
|---|---|---|---|
| まとめて積む | 10.575台 | 95.19% | 100.0% |
| 方面ごとに分けて積む | 12.11台 | 83.14% | 100.0% |

- **方面ごとに分けると、車は平均1.535台（14.78%）増えた**。積載率は平均で12.05ポイント下がった
- 増えた台数の日ごとの分布は、+0台が3.0%、+1台が44.0%、+2台が49.5%、+3台が3.5%の日だった
- どちらの積み方も、200日すべてで台数が下限（切り上げ）と同じだった。荷物が車に比べて小さいので、詰め方の差ではなく、切り上げの回数の差がそのまま増えた台数になった（ほぼ算数どおり）。目安の（4−1）÷2＝1.5台に近かった
- 1日目は、まとめると12台、方面ごとだと14台だった。方面ごとの台数はA3台・B4台・C4台・D3台で、方面ごとの最後の1台が半端に残った（`data/day1_items.csv`、図1）

### 確かめ：36通り（`results/grid.csv`）
- **増えた台数の平均は、36通りで0.4〜4.99台だった**。方面2で0.4〜0.58台、方面4で0.96〜1.78台、方面8で3.41〜4.99台と、ほぼ方面の数で決まった。増えなかった置き方はなかった
- 方面の割合が同じで、1つの方面の量が車2.5台分以上の10通りでは、増えた台数は目安の（方面の数−1）÷2との差が−0.11〜+0.05台だった
- 増えた割合（まとめて積んだ台数に対する）は36通りで1.37〜149.0%だった。1日の量が車3台分では12.68〜149.0%、10台分では4.49〜41.86%、30台分では1.37〜12.56%と、1日の量が少ないほど大きかった。方面8・車3台分では、1つの方面の量が車1台分に満たないので、方面ごとに少なくとも1台ずつ要った
- 積載率の下がり方は1.31〜51.23ポイントだった
- 台数が下限と同じだった日の割合は、まとめてで93.0%以上、方面ごとで90.0%以上だった（荷物の中央値80Lで少し下がった）


## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp）
- 基本の置き方で、どちらの積み方も200日すべて下限と同じ台数になり、増えた台数の平均（1.535台）が下限どうしの差の平均（lb_extra_mean 1.535台）と同じになることを確かめた
- 図3枚を開き、日本語・重なり・軸（棒グラフの軸は0から）を確かめた

## データ
- `data/day1_items.csv`：基本の置き方の1日目の荷物（area は方面、size_L は大きさ、truck_mixed・truck_split はまとめて・方面ごとに積んだ車の番号）
- `results/a1300_main.json`：主な結果（`base`・`robust`）
- `results/base_days.csv`：基本の置き方の200日（mixed・split は台数、lb_mixed・lb_split は下限、extra は増えた台数、fill_* は積載率）
- `results/grid.csv`：確かめの36通り（extra_mean は増えた台数の平均、extra_pct_mean は増えた割合、half_rule は（方面の数−1）÷2、fill_drop_pt は積載率の下がり方）

## 注意（言えないこと）
- 架空のデータです。荷物の大きさの分布、1日の量、方面の数と割合、車の容量は作成者が置いたもので、結果はこれで決まります。とくに増えた割合（1.37〜149.0%）は1日の量と方面の数で大きく動きました
- 荷物は大きさだけで数え、重さ・形・重ねられるかは考えていません。これらを入れると、どちらの積み方も台数は下限より増えます（どれだけ増えるかは数えていません）
- 方面ごとに分けて積むと、届ける道のりが短くなる・積み下ろしが楽になる、といった良さがありますが、この記事ではそれを数えていません。台数の差だけを数えたもので、分けるか分けないかの良し悪しを決めるものではありません
- 車1台ごとの費用や料金、何台用意するかの助言をする記事ではありません
