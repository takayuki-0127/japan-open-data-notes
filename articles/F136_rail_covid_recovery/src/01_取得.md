# 01 取得（鉄道輸送統計調査 月次 表2-2）

`data/raw/f136_rail_t22.json` は、e-Stat に置かれている「鉄道輸送統計調査」（国土交通省、政府統計コード 00600350）の月次の Excel「表2-2 旅客営業キロ及び旅客数量」を、2026年11月3日にブラウザの中で読み込み（SheetJS 0.18.5）、1枚目のシートを CSV の文字列にして1つの JSON にまとめたものです。

- 対象：2014年1月〜2026年6月の150か月（取得日時点で公開されていた最新月まで）
- キーは `22_<年>-<月>`。`statInfId` に各月のファイルの ID を入れてあります
- 取り方：`https://www.e-stat.go.jp/stat-search/file-download?statInfId=<id>&fileKind=4`（2026年の一部は `fileKind=0`）。手で取る場合は、e-Stat の「鉄道輸送統計調査 → 月次 → 年 → 月」の一覧から「表番号 2-2」の Excel をダウンロードすれば同じ内容です
- 表2-2 には、運輸局別（10区分）と業態別（JR旅客会社・うち新幹線・民鉄・うち大手・中小・公営）の、定期・定期外・計の旅客数（千人）と営業キロが載っています
