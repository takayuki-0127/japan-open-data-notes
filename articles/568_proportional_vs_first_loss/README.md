# 568 保険金額が実際の価値より小さい契約で、比例てん補を入れると、支払いと必要な保険料はどう変わるのか（保険数理・架空のデータ）

物の保険で、保険金額（契約で決めた上限）が物件の実際の価値より小さいことを「一部保険」といいます。損害が起きたとき、**比例てん補**では「損害×保険金額÷価値」を払い、**実損てん補**では保険金額までなら損害をそのまま払います。ここでは、架空の物件と損害20万件で、付保割合（保険金額÷価値）を30〜100%に変えたとき、2つの払い方で支払と純保険料（損害の支払にあてる分の期待値）がどれだけ違うかを計算しました。数字は置いた損害の分布で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A568 | 一部保険で、比例てん補と実損てん補の支払と純保険料はどれだけ違うか | 架空の損害20万件。物件の価値は対数正規（平均3,000万円）、損害率（損害÷価値）は 85%が小さい損害（Beta(1,12)）、12%が中くらい（Beta(2,4)）、3%が全損。1年に損害が起きる確率は2%。付保割合 k を 0.3〜1.0 にして、比例てん補（損害×k）と実損てん補（min(損害, k×価値)）の支払、損害のうち支払われる割合、保険金額100万円あたりの純保険料を計算。k=0.6 の支払の合計は DuckDB（1スレッド）の SQL でも計算し Python と一致を確認。seed 568 | `src/a568_indemnity.py`、`src/a568_indemnity.sql`、`src/a568_indemnity_tsql.sql` |

## 主な結果
- 損害率の平均は 13.5%、1件の損害の平均は 405万円（全損は3%）
- **損害のうち支払われる割合**（額で）：比例てん補は付保割合そのもの（60%なら60%）。実損てん補は付保割合60%で 90.5%、30%でも 76.3%
- **全額支払われた損害の件数**：実損てん補は付保割合60%で 96.0%、30%で 89.5%。比例てん補は付保割合100%でないかぎり 0件
- **保険金額100万円あたりの純保険料**：比例てん補はどの付保割合でも 2,700円。実損てん補は 100%で 2,700円、60%で 4,074円（1.5倍）、30%で 6,864円（2.5倍）
- **1件あたりの払われない額**（付保割合60%）：比例てん補 162万円、実損てん補 38万円
- **損害率ごと**（付保割合60%）：損害率60%以下の損害では、実損てん補は全額、比例てん補は6割。差がなくなるのは全損だけ

## 確かめたこと
- 空のフォルダで流し直し、results がすべて一致した
- 付保割合60%の2通りの支払の合計が、Python と DuckDB の SQL で一致すること（T-SQL 版は SQL Server では動かしていない：**未検証**）

## データ
- データはコードの中で乱数から作る（seed 568）。損害の一部（2,000件）を `results/loss_sample_2000.csv` に置いた

## 注意（言えないこと）
- 架空のデータ。損害率の分布と損害の起きる確率は作成者が置いたもので、結果はこれで決まる。小さい損害が多いほど、2つの払い方の差は大きくなる
- 純保険料は支払の期待値だけで、経費や利益などは入れていない。実際の保険料の水準ではない
- 特定の保険商品の説明や、保険の選び方・入り方の助言ではない
