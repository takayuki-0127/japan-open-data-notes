# 620 取引の金額の先頭の数字は、ベンフォードの法則にどれだけ従い、入力の偏りをどこまで見つけられるのか（手法の解説・正解の分かるデータで試す）

桁をまたいで広く散らばる数では、先頭の数字が1になる割合は約30%、9は約5%になる、という経験則をベンフォードの法則といいます。データの点検で「先頭の数字の割合が法則に合うか」を見ることがあります。**ここでは、架空の取引金額（対数正規、中央値1万円）で、散らばりの広さによってどこまで法則に従うか、1,000〜9,999円の一様な「手で作った金額」を0〜20%混ぜたとき、カイ二乗の適合度検定と MAD がどれだけ「合わない」と出すかを数えました。** 各条件500回。数字は置いた金額の分布で決まります。不正の有無を判定するものではありません。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A620 | 法則に従う範囲と、混ぜた金額の見つかり方 | 先頭の数字の割合、カイ二乗の適合度検定（p<0.05）、MAD（0.015 を超えたら「合わない」）。自然な金額は対数正規（σ 0.3〜2.0）、件数 500・2,000・10,000、各500回、seed 620 | `src/a620_benford.py` |

## 主な結果
- **広く散らばる自然な金額（σ=1.5、5〜95%点が 848〜11.8万円）**：先頭の数字の割合は法則とほぼ同じ（1 が 30.1%、9 が 4.6%）。MAD 0.0005
- **範囲が狭いと、手の入らない金額でも合わない**：MAD は σ=1.0 で 0.003、**σ=0.75 で 0.017（目安 0.015 を超える）**、σ=0.3 で 0.094。σ=0.3（6,105〜16,380円が9割）では先頭が1の金額が 48.9%、2〜4 はほとんどない
- **手で作った金額（一様）**：先頭の数字はどれも約11%
- **カイ二乗の適合度検定**：何も混ぜなくても 4〜6% の回で「合わない」（p<0.05 の決まりどおり）。手で作った金額を 5% 混ぜると、500件で 6.4%、2,000件で 14.6%、**10,000件で 66.6%**。10% 混ぜると 2,000件で 51.4%、10,000件で 99.6%
- **MAD（0.015 を超えたら合わない）**：件数の影響を受けにくいかわり、20% 混ぜても 10,000件で 0%、2,000件で 15.2%。一様な金額を混ぜたときの MAD は「混ぜた割合×0.06」程度にしかならず、目安を超えるには約25%が要る（計算上）。500件では何も混ぜなくても 7.2% の回で目安を超えた

## 動かし方
```
pip install -r requirements.txt
cd src && python a620_benford.py
```

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- 何も混ぜないとき、カイ二乗の検定で「合わない」と出る割合が 5% 前後になること

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 620）

## 注意（言えないこと）
- 架空のデータ。金額の分布と「手で作った金額」の形は作成者が置いたもので、結果はこれで決まる
- 法則に合わないことは、不正や誤りの証拠ではない。範囲の狭い金額（価格の決まった商品、上限のある経費など）は、手が入っていなくても合わない
- MAD の目安 0.015 は、先頭の数字について広く使われている目安の1つを使った。目安の決め方そのものは扱っていない
