# 481 「20日締め」と「月末締め」で、月の売上はどれだけ動くのか（実務の型）

同じ日次の売上を、月末締め（暦月）と20日締め（前月21日〜当月20日）の2通りで月に集計し、月の売上と前年同月比がどれだけ違って見えるかを測ったフォルダです。架空の日次売上（2023〜2025年、小売型と法人向け型）を使い、祝日は内閣府の一覧を使っています。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A481 | 締め日の位置だけで、月の売上・前年同月比・営業日数・値上げの出方はどれだけ変わるか | 曜日と祝日で形の違う2つの型の日次売上を作り、DuckDB で2通りに集計（pandas の集計と一致を assert）。揺れを変えて500回くり返し、前年同月比の向きが逆になる月を数える | `src/a481_closing.py`、`src/01_closing_tsql.sql`（T-SQL 版、未検証） |

## 主な結果
- **月の売上の差**（同じ日次売上、2023〜2025年の36か月）：20日締めと月末締めの差は、小売型で平均5.6%（最大12.4%）、法人向け型で平均9.3%（最大21.0%）
- **前年同月比**（2024〜2025年の24か月）：2つの締めの差は、小売型で平均3.1ポイント（最大9.9）、法人向け型で平均6.9ポイント（最大19.1）。向きが逆になった月は、小売型で5か月、法人向け型で13か月
- **500回くり返し**（売上の伸び年3%）：向きが逆になる月は、小売型で平均4.4か月、法人向け型で平均12.7か月（24か月中）。伸び0の場合は10.3か月と14.3か月
- **営業日数**（法人向け型）：どちらの締めでも、1か月の営業日は18〜23日。ただし同じ月で比べると、2025年は2月が月末締め18日・20日締め22日、3月が20日・18日のように入れ替わる
- **値上げの出方**（2024年10月1日から+10%、揺れなし）：月末締めは10月から100%出る。20日締めの10月分（9月21日〜10月20日）には66%しか出ず、11月分で100%
- **年の合計**：暦年と「前年12月21日〜当年12月20日」の差は−0.6〜+0.5%で小さい

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した
- DuckDB で出した2つの締めの月の売上が、pandas で別に集計した値と一致する（コード内の assert）

## データ
- `data/fictional_daily_sales_retail.csv`：架空の日次売上（小売型、seed 481）。法人向け型はコードで作り直す
- `data/syukujitsu_utf8.csv`：内閣府「国民の祝日」（このリポジトリの 356・451 と同じもの）

## 注意（言えないこと）
- 架空の売上。曜日の形・季節・揺れは置いた値で、数字はこの置き方での結果
- どちらの締め日が正しいかを言うものではない。比べる相手と締め日がそろっているかを見る、という話
- 会計上の売上の計上時期の助言ではない
- 締めてから数字が確定するまでの日数は 341、曜日の並びと前年同月比は 356 で扱った
- T-SQL 版は SQL Server 本体では動かしていない（未検証）。SQL は DuckDB で実行した
