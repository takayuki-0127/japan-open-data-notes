# 207 UVインデックスは何月がピークで、どの地点が高いか：気象庁の紫外線観測

気象庁の紫外線観測（札幌・つくば・那覇・南極昭和基地）の「日最大UVインデックスの月平均値」で、季節の形と地点の差を見たフォルダです。札幌・那覇は2018年1月で観測を終えているため、3地点がそろう2005〜2017年で比べ、つくばは2025年までの推移も見ています。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A207 | UVインデックスは何月がピークで、どの地点が高いか | 2005〜2017年の月別平均（季節パターン）、各年で最も高かった月の集計、UVインデックスの区分（強い・非常に強いなど）別の月数、つくばの2005〜2025年の年平均と7〜8月平均の直線の傾き | `src/a207_uv.py` |

## 主な結果
- 月平均が最も高いのは、那覇が7月（10.3）、札幌も7月（6.1）、つくばは8月（7.0）。南半球の昭和基地は12月（6.9）
- 太陽が最も高い6月は、つくば6.0・那覇8.7・札幌5.6と、7〜8月より低い
- 13年のうち年間最大の月は、那覇が7月11回・8月2回、つくばが7月6回・8月7回、札幌が7月8回・8月4回・6月1回で、どの地点も7〜8月に集中
- 12か月の平均は那覇6.6、つくば4.2、札幌3.3で、那覇はつくばの1.55倍。差は冬に大きく、12月は那覇が札幌の4.5倍、7月は1.7倍
- 月平均が「非常に強い」（8以上）になったのは、那覇が156か月中51か月、つくばは2か月、札幌は0か月。那覇は6〜8月に10を超えた月が16回あった
- つくばの7〜8月平均は2005〜2014年の6.90から2016〜2025年は7.40に上がり、直線の傾きは10年あたり+0.65（年平均は+0.25）。2023年8月の8.8が期間中で最も高い月

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a207_uv.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/uvimax_monthave_raw.csv | 地点・年ごとの、日最大UVインデックスの月平均値（1〜12月）。値の後ろの「]」は資料不足値 |

- 気象庁「紫外線のデータ集」の「日最大UVインデックス（観測値）の月平均値」の表（札幌・つくば・那覇・南極昭和基地、2005年〜2026年8月）。ブラウザで表を読み、書き写した
- 資料不足値（観測できた日が月20日未満）も値はそのまま使った（昭和基地に多く、日本の3地点にはない）

## 注意
- 観測地点は4か所だけで、ほかの地域の値は分からない。地図で比べるには気象庁の「解析値」（推定値）を使う必要がある
- 札幌・那覇の観測は2018年1月で終わっているため、地点の比較は2005〜2017年に限った
- 日最大の値の月平均なので、晴れた日の真昼の強さよりは低めになる
- つくばの上昇は21年間の短い期間の傾きで、オゾン量・雲・大気の濁りのどれによるかは、このデータでは分からない
