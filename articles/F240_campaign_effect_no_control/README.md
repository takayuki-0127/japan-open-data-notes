# F240 キャンペーンの効果を、比べる相手がないときにどう測るか（合成対照・中断時系列・ベイズ構造時系列・プラセボ）

シリーズ「実務に近い分析」（F231〜F245）の10本目。A/B テストのように「施策を受けない比較群」を最初から用意できないとき、施策の効果をどう測るかを、**2025年の大阪・関西万博（4月13日〜10月13日）の期間に、大阪府の日本人の延べ宿泊者数はどれだけ増えたか**を例に確かめた。同じデータで、前年比・中断時系列（ITS）・合成対照・ベイズ構造時系列（CausalImpact 型）を並べ、プラセボ（偽の施策）で方法そのものを点検した。

- 広告費の効き方を時系列で分ける方法（マーケティング・ミックス・モデル）は F239 で扱っている
- これまでの因果の記事（差の差 F01・合成対照 F26・イベントスタディ F98 など）は「比べる相手がいる」場合。ここでは比べる相手を自分で作る／作れないときの判断に絞った
- ダッシュボードの例は、架空の宿泊チェーン「なにわステイ」の社内向けという設定（数字は大阪府全体の公的統計で、自社データではない）

## 問い

- 「前年同月比 +12.9%」は、万博の効果と言ってよいのか
- 比べる相手がいないとき、どの方法なら効果を測れるのか。方法によって答えはどれだけ変わるのか
- 測った効果が偶然でないことを、どう確かめるのか（プラセボ）
- 周りの府県から客を奪っただけ、ということはないのか

## データ

| データ | 中身 | 使い方 |
|---|---|---|
| 観光庁「宿泊旅行統計調査」推移表（F98 の `data/panel.csv` を使い回し） | 都道府県×月の延べ宿泊者数（総数・日本人・外国人）、2011年1月〜2025年12月 | 主の指標は大阪府の**日本人**延べ宿泊者数（対数）。総数・外国人は確認用 |
| 大阪・関西万博の会期（公表資料） | 2025年4月13日〜10月13日 | 2025年4〜10月を「期間中」、11〜12月を「閉幕後」とした |

新しいデータの取得はしていない。コロナ期（2020〜2022年）は前の期間から外した。

## 手法

| 方法 | 比べる相手 | 中身 |
|---|---|---|
| 前年同月比 | 去年の同じ月 | 4〜10月の合計を前年と比べる。ほかの県の前年比との差も出す |
| 中断時系列（ITS） | 大阪自身の過去 | 対数の宿泊者数を、トレンド＋月の効果で回帰し（前の期間：2023年1月〜2025年3月、または2015〜19年も入れてコロナ後の水準の段差を足す）、期間中の見込みと比べる |
| 合成対照 | ほかの都道県の組み合わせ | 前の期間（2023年1月〜2025年3月）の大阪の動きに合うよう、非負・合計1の重みでほかの県を混ぜる（平均を引いた対数で合わせる）。主は関西の5府県（滋賀・京都・兵庫・奈良・和歌山）を対照から除く |
| ベイズ構造時系列（BSTS、CausalImpact 型） | 大阪自身の過去＋ほかの県の合計 | 状態空間モデル（水準＋季節）にほかの41都道県の合計を説明変数として入れ、2015年以降（コロナ期は欠測扱い）で推定し、期間中の値を予測 |
| プラセボ（場所） | — | 関西以外の41都道県を1つずつ「大阪」とみなして同じ合成対照をつくり、期間中の外れの大きさの順位を見る |
| プラセボ（時期） | — | 万博のない2024年4〜10月に「施策があった」として、同じ方法で効果が0に近く出るかを見る |

- **SQL**：前年比と「去年の同じ月 × ほかの県の前年比」の素朴なベースラインを SQL Server 互換の書き方で書き（`src/04_前年比とベースライン.sql`）、DuckDB で流して pandas と照合
- **ダッシュボード**：`dashboard/index.html`（1枚の静的 HTML）

## 結果

### 1. 素朴な比較：前年同月比

- 大阪府の日本人延べ宿泊者数は、2025年4〜10月の合計で 2,119万人泊。2024年の同じ期間（1,877万人泊）より **+12.9%**
- 同じ期間のほかの46都道府県の合計は −3.1%（関西を除く41都道県では −2.8%）
- 「去年の同じ月 × ほかの県の前年比」を見込みにすると、増加は +16.3%（約297万人泊）。SQL と pandas の差は最大 2×10⁻¹⁶

### 2. 合成対照（主）

- 合成の大阪の重み：福岡 44.5%・東京 19.8%・三重 12.7%・千葉 10.4%・佐賀 5.3% など
- 前の期間の合わせの外れ（RMSPE）は 0.029（対数、約3%）
- 期間中の増加は **+11.4%（約222万人泊）**。月ごとでは 4月 +0.9%、5月 +11.7%、6月 +14.7%、7月 +3.5%、8月 +10.1%、**9月 +32.7%**、10月 +9.1%
- 閉幕後の 11月は −9.1%、12月は −1.4%（2か月の平均 −5.3%）

| 条件 | 期間中の増加 | 閉幕後 |
|---|---|---|
| 主（日本人・関西を除く・2023〜25年で合わせる） | +11.4% | −5.3% |
| 関西も対照に入れる | +11.3% | −6.3% |
| 東京も除く | +8.8% | −7.9% |
| 前の期間に2015〜19年も入れる | +17.8% | +1.0% |
| 総数（日本人＋外国人） | +2.9% | −8.4% |
| 外国人 | −15.1% | −13.8% |

### 3. プラセボ

- **場所**：42都道府県（大阪＋対照41）の中で、期間中の外れ ÷ 前の期間の外れ の比は大阪が **1位**（偶然でこうなる確率 1/42 ≒ 2.4%）。効果の大きさだけで並べると4位（9.5%）。前の期間の合わせが大阪の2倍以内の30府県に絞ると2位
- **時期**（2024年4〜10月に偽の施策）：合成対照 +1.0%、BSTS +1.3%（95%区間 −11.8〜+16.3%）とほぼ0。ところが ITS（2023〜24年で学習）は **+6.4%（+4.3〜+8.5%）** と、万博のない年にも「効果」が出た

### 4. 方法による違い（期間中の増加）

| 方法 | 増加 | 95%区間 |
|---|---|---|
| 前年同月比（大阪だけ） | +12.9% | — |
| 前年比の差で補正した見込み | +16.3% | — |
| ITS（2023〜25年で学習） | +13.4% | +8.6〜+18.3% |
| ITS（2015〜19年も使い、コロナ後の段差を入れる） | +1.3% | −5.0〜+7.9% |
| BSTS（説明変数なし） | +10.3% | −7.1〜+31.0% |
| BSTS（ほかの県の合計を説明変数） | +11.8% | +0.4〜+24.6%（月を独立とみなすと +7.3〜+16.5%） |
| 合成対照（主） | +11.4% | プラセボの順位で評価 |

### 5. 周りの府県への波及（関西以外の対照で合成対照）

期間中の増減：京都 −13.5%、兵庫 −5.0%、滋賀 +0.9%、和歌山 +2.0%、奈良 +11.5%。ただし京都（前の期間の外れ 0.081）・奈良（0.068）は合わせが悪く、どれも「はっきり増えた・減った」とは言えない。

## 頑健性

- 対照の選び方（関西を含める・東京も除く）：+8.8〜+11.4%
- 前の期間（2023〜25年／2015〜19年も入れる）：+11.4% と +17.8%
- 指標（日本人／総数／外国人）：+11.4%／+2.9%／−15.1%
- プラセボ（場所42・時期1）、BSTS の説明変数あり・なし
- ITS の学習期間2通り（結果が大きく変わることを確かめた）

## 言えないこと

- **万博だけの効果とは言い切れない**：同じ時期の大阪のほかのイベント、ホテルの開業、料金の変化などと分けられていない
- **外国人の宿泊が減った理由は分からない**：日本人で宿泊施設が埋まり外国人が入れなかったのか、ほかの要因かは、このデータでは区別できない。合成対照の合わせも悪い（外れ 0.064）
- **周りの府県からの「奪い合い」は判断できない**：周りの府県の合わせが悪く、区間も広い
- **閉幕後のマイナスが「前倒し」かどうか**は、2か月しかなく分からない（推測）
- **宿泊者数であって、消費額や経済効果ではない**：日帰り客や、大阪府外に泊まった来場者は数えていない
- **合成対照の区間**は出していない。偶然かどうかはプラセボの順位で見ている
- **ITS の結果は前の期間の選び方で大きく変わった**：大阪だけの過去しか使わない方法は、トレンドの置き方に強く依存する
