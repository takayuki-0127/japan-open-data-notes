# T001 定点観測：賃上げ率の大企業と中小企業の差は、2026年も大きいままか（141 の2026年版）

[141_wage_increase](../141_wage_increase)（賃上げ率の企業規模の差、1975〜2025年）の定点観測（更新記事）です。厚生労働省「賃金引上げ等の実態に関する調査」の令和8年（2026年）の結果を足して、元記事と同じコードで計算し直しました。新しい年を見る前に、予想と判定の基準を [PLAN.md](PLAN.md) に書いてコミットしました。

## 結果（2026年）
- **判定：縮んだが残った**（PLAN の基準：1.0ポイント以上なら「続いた」、0.5以上1.0未満なら「縮んだが残った」）
- 1人平均賃金の改定率は、5,000人以上が5.1%（2025年）→4.8%（2026年）、100〜299人が3.6%→3.9%。企業規模計は4.4%で2025年と同じ
- 差（5,000人以上 − 100〜299人）は1.5ポイント→0.9ポイント。2023年より前に0.9ポイント以上だったのは1975年（0.9）だけで、1976〜2022年の最大は2000年・2002年の0.7。2013〜2022年の平均は0.21、2023〜2026年の平均は1.15。ただし1979年までの改定率は単純平均、1980年以降は加重平均なので、1975年とは直接は比べられない
- 縮んだこと自体は丸めを考えても確か（1.5→0.9）。一方、「1.0未満」かどうかは小数第1位の丸めの範囲に入る
- PLAN の予想との比較：率の予想（5,000人以上4.5〜5.5%、100〜299人3.3〜4.0%）はどちらも当たり（4.8%・3.9%）、差の予想（1.0〜1.6）は小さい側に外れた
- 改定額（月額）の差は6,520円→5,401円（16,680円と11,279円）。100〜299人の額は5,000人以上の61.2%→67.6%で、2024年と同じ水準に戻った（2019年は73.6%）
- 1人平均賃金を引き上げた（引き上げる）企業の割合は、100〜299人で89.7%→91.3%。1999年以降で最も高い。5,000人以上は98.9%→97.7%
- 改定で最も重視した要素（企業規模計）は「企業の業績」41.7%→46.0%、「労働力の確保・定着」17.0%→12.1%、「消費者物価の動向」3.3%→3.9%。100〜299人では「労働力の確保・定着」が17.1%→11.0%、5,000人以上では17.3%→19.9%

## 新しい切り口：4区分は規模の順に並んだか
- ここでは「厳密に大きい順」（5,000人以上 ＞ 1,000〜4,999人 ＞ 300〜999人 ＞ 100〜299人、同じ値を含めない）で数える
- 2026年は 4.8% ＞ 4.7% ＞ 4.2% ＞ 3.9% で厳密に大きい順。厳密に大きい順だった年は1975〜2026年で2002・2015・2024・2025・2026年の5年だけで、3年続いたのは1975年以降で初めて
- 同じ値を許して（≥）数えると、1998〜2000年、2002〜04年、2009〜12年、2018〜20年にも続いた時期があり、2024〜26年だけの特徴とは言えない（1975〜2012年は38年中10年、2013〜2022年は10年中4年、2013年以降は14年中7年）
- 計算は `results/t001_main.json`（`order_strict_years_all`・`order_weak_years_all`）

## 頑健性
- 比べる相手を1,000〜4,999人にすると、差は1.4ポイント（2025年）→0.8ポイント（2026年）。2022年は −0.1、2023年0.2、2024年0.4
- **計画からのずれ**：PLAN では「1,000人以上 − 100〜299人」で計算する予定だった。1,000人以上の改定率は、5,000人以上と1,000〜4,999人を労働者数で重み付けしないと作れず、時系列表と令和8年の表には規模別の労働者数（重み）がないため計算できなかった。代わりに1,000〜4,999人で比べた
- 率でなく額の比（100〜299人 ÷ 5,000人以上）で見ても、2026年は差が縮んだ（61.2%→67.6%）が、2019年（73.6%）や2022年（73.1%）よりは開いたまま
- 2025年の値は、時系列表（令和7年調査）と令和8年調査の表の両方にある。改定額・改定率・実施状況・重視した要素の8項目×5区分がすべて一致した（`results/t001_check_2025_overlap.csv`）

## 注意・言えないこと
- 改定率は小数第1位までの公表値です。差は0.1ポイント刻みで、0.9と1.0の違いは丸めの範囲に入りうる大きさです
- 2026年の値は令和8年調査の単年の表から取りました。後で出る時系列表で値が変わる可能性は低いと考えます（2025年の値が一致したため、推測）
- 毎年、調べる企業が入れ替わる標本調査です。1年の動きには標本のぶれも入っています
- 対象は常用労働者100人以上の企業で、99人以下の企業は入っていません。業種の構成の違いは調整していません
- 1979年までの改定率は単純平均、1980年以降は加重平均です。1975年の差（0.9）は2026年と同じ値ですが、平均の取り方が違うため直接は比べられません
- 差が縮んだ理由（大企業の伸びが落ち着いた、中小企業が追いついた、など）は、この表からは分けられません

## レビューで直したこと
公開前に、別のエージェントが記事・README・コードだけを見て確かめました。数字は再計算でき、2025年のつなぎ目と元記事の再現も確かめられました。指摘を受けて次の点を直しました。
- 「3年続けて規模の順」「ここ数年の特徴」が言い過ぎだった：同じ値を許すと過去にも続いた時期がある。定義を「厳密に大きい順」に決め、厳密な並びが3年続いたのは1975年以降で初めて、と書き直した
- `src/a141_size_gap.py` で `# T001` のコメントが `ax.set_ylabel(...)` と `ax2.tick_params(...)` を飲み込んでいた：コードの後ろにコメントを移し、t001_rate.png の縦軸の名前と小さい図の目盛りを直した。空のフォルダでの再実行もバイト単位で一致
- 1979年までは単純平均で1975年とは直接比べられないことを書いた。1976〜2022年の最大を「2000年・2002年の0.7」にした
- PLAN の頑健性（1,000人以上 − 100〜299人）を計算できなかった理由を「計画からのずれ」に書いた。率の予想は2つとも当たったことを書いた。PLAN のコミット（78622dc）がデータのコミットより前であることを確かめた
- 図1の2013〜2024年を淡い灰にし、題を「2025年（濃い灰）と2026年（橙）」に直した。図の番号を記事・README・コードのコメントでそろえた
- 「理由を挙げる」を「最も重視した要素に挙げる」に、1章に「縮んだのは確かだが、1.0未満かどうかは丸めの範囲」と書いた
