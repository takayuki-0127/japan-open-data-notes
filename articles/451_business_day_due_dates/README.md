# 451 「5営業日後」の期日は、祝日の持ち方で何件ずれるのか（実務の型）

架空の取引6万件（受付日 2019〜2025年）について、「受付日の次の営業日を1日目として5営業日目」の期日を、休みの日の持ち方を変えて出し、正しい決まりの期日と違った件数を数えたフォルダです。341（締めてからの営業日）は土日だけを除きました。356（曜日の並び）と 366（祝日の数）は売上や日数を扱いました。ここでは、期日の計算だけを扱います。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A451 | 休みの日の持ち方で、期日は何件・何日ずれるか | 休みの日の表を7通り作り、営業日の通し番号で期日を出す。正しい決まり（土日・祝日と休日・年末年始12/29〜1/3）と比べる。同じ計算を DuckDB の SQL でも実行して一致を確かめる | `src/a451_due_dates.py`、`src/01_due_date_tsql.sql`（T-SQL 版、未検証） |

## 主な結果
| 休みの日の持ち方 | 対象 | 件数 | 期日が違った件数 | 割合 | 早すぎ | 遅すぎ | 最大のずれ |
|---|---|---|---|---|---|---|---|
| 土日だけ除く | 全期間 | 60,000 | 15,147 | 25.2% | 15,147 | 0 | 10日 |
| 土日と祝日（年末年始を入れない） | 全期間 | 60,000 | 1,909 | 3.2% | 1,909 | 0 | 7日 |
| 振替休日・国民の休日を入れ忘れる | 全期間 | 60,000 | 2,936 | 4.9% | 2,936 | 0 | 7日 |
| 法律が変わる前の一覧のまま | 2019〜2021年の受付 | 25,592 | 1,457 | 5.7% | 892 | 565 | 7日 |
| 一覧を1年更新し忘れる（2025年分なし） | 2025年の受付 | 8,757 | 2,146 | 24.5% | 2,146 | 0 | 5日 |
| 前の年の月日を写す（2025年分） | 2025年の受付 | 8,757 | 1,690 | 19.3% | 652 | 1,038 | 3日 |

- **休みの日の数**：2019〜2025年の平日のうち、正しい決まりで休みになるのは131日。土日だけ除くと131日すべてが抜ける。年末年始を入れないと26日、振替休日・国民の休日を入れ忘れると18日が抜ける
- **ずれの日数**：土日だけ除く場合、ずれた15,147件のうち1日が8,187件、2日が759件、3日が3,109件、4日以上が3,092件（休みが土日とつながると、ずれは3日以上になる）
- **受付の月**：年末年始を入れない場合、ずれるのは12月（30.9%）と1月（5.8%）だけ。振替休日・国民の休日の入れ忘れは、4月（12.8%）・2月（10.7%）・8月（10.5%）で多い。6月はどの持ち方でも0%（祝日がない）
- **年ごと（振替休日・国民の休日の入れ忘れ）**：2019年9.4%、2020年4.7%、2021年2.0%、2022・2023年0%、2024年11.2%、2025年6.8%（祝日が日曜に当たる年に多い）
- **2025年分の祝日がないとき**：2月49.1%、9月46.0%、10月39.1%。6月と12月は0%
- **前の年の月日を写したとき**：3〜6月と12月は0%（月日が同じ）、2月53.8%、7月34.9%（月曜に動く祝日と振替休日は、年によって日付が違う）。遅すぎる期日（1,038件）のほうが多い
- **DuckDB**：営業日の通し番号を使う SQL の期日が、Python の計算と6万件すべてで一致

## 動かし方
```
pip install -r requirements.txt
cd src && python a451_due_dates.py     # 数秒
```

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した
- DuckDB の SQL の期日が、Python の計算と6万件すべてで一致する（コード内の assert）

## データ
- `data/syukujitsu_utf8.csv`：内閣府「国民の祝日について」の祝日・休日の一覧（1955〜2027年。356 で使ったものの写し、文字コードを UTF-8 に直したもの）
- `data/transactions.csv`：架空の取引6万件（番号・受付日）。作成者が乱数で作成（seed 451）。土日の受付は平日の4分の1の重み

## 注意（言えないこと）
- 取引は架空のデータ。ずれる割合は、受付日の散らばり方と「5営業日」という長さで変わる
- 「正しい決まり」は、土日・祝日と休日・年末年始（12/29〜1/3）を休みとする、ここで置いた決まり。会社や契約によって休みの日は違う
- 「法律が変わる前の一覧」は、2019年の即位に伴う休日がなく、2020・2021年の海の日・スポーツの日・山の日が元の日付にある一覧を、作成者が決まりから作ったもの。当時配られていた一覧そのものではない
- 「前の年の月日を写す」は、2024年の祝日・休日の月日を2025年にそのまま当てたもの
- T-SQL 版は SQL Server 本体では動かしていない（未検証）
