# F313 町の小さな店が減ったのは、大きな店に置き換わったからか？ 1991→2007年に小売の店は47万減り、99%が個人の店。売場は+31広がったが、売場が広がった業種ほど個人の店が減った、という関係はなかった

## 結論（先に）
- 小売業の事業所数は、1991年（再集計値）の160.6万から2007年の113.8万に、46.8万減りました。そのうち46.3万（98.9%）が個人経営の店の減少です。法人（会社など）の店は57.1万から56.6万で、ほぼ横ばい（−0.9%）でした。
- 同じ期間に、売場面積は1.10億㎡から1.50億㎡に増え（対数差×100 で +31）、1店当たりの売場面積は68㎡から132㎡になりました（+65）。販売額は −5 でした。
- 「店は減り、売場は広がった」は確かです。ただ、業種（細分類）ごとに比べると、売場面積が伸びた業種ほど個人の店が減った、という関係は見られませんでした（重みつきの傾き +0.20、p=0.19。向きはむしろ逆）。
- 問い直し：それでも、46業種のうち44業種で店に占める個人の割合が下がり、全体の下がり方（−12.6ポイント）はほぼすべて業種の中の変化でした。置き換わりは「売場が広がった業種」に限らず、どの業種でも起きていた形です。

## 問い
町の小さな店が減った、とよく言われます。商店街や流通の担当の人、地域の統計を読む人にとっては、それが「大きな店に置き換わった」結果なのか、それとも業種ごと縮んだのかが知りたいところです。商業統計で、小売業の店の数・売場面積を、個人の店と会社の店に分けて見ました。出店の良し悪しは扱いません。

## データ（出典）
- 経済産業省「平成19年商業統計表 第1巻 産業編（総括表）」第1表：産業分類細分類別、年次別の事業所数（法人・個人別）、従業者数、年間商品販売額、売場面積（1982〜2007年の10回分）。
- 1991年には、1994年調査と対応するよう再集計した値（下段）があり、本文ではこれを使いました。
- URL と取得日は data/raw/SOURCES.md にあります。

## 事前の計画
[PLAN.md](PLAN.md) に、小売業の行の値を見る前に仮説を書きました。

| 仮説（1991年→2007年、小売業） | 基準 | 結果 | 判定 |
|---|---|---|---|
| H1 減少の90%以上が個人の店で、法人は横ばいか増加 | 両方を満たす | 個人 98.9%、法人 −5,213（−0.9%） | 外れ（法人がわずかに減ったため。前半は満たす） |
| H2 売場面積が増えた | +15 以上 | +31 | 支持 |
| H3 売場が伸びた業種ほど個人の店が減った | 傾きが負で p<0.10 | +0.20（p=0.19） | 外れ |
| H4 1店当たり売場面積が大きくなった | +40 以上 | +65 | 支持 |

H1 は「法人は横ばいか増加」を数字で決めていなかったので、文字どおり「減っていない」と読んで外れとしました。

## やったこと
1. 第1表から、小売業計と細分類（4桁）の業種の、年ごとの値を取り出しました。
2. 1991年（再集計値）と2007年を、差と対数差×100 で比べました。
3. 両方の年に値がそろう細分類46業種で、売場面積の伸びと個人の店の数の伸びの関係を、1991年の個人の店の数で重みづけて回帰しました（頑健な標準誤差 HC3）。
4. 頑健性を4つ、問い直しを1つ足しました。

## 分かったこと
### 減ったのは、ほぼ全部が個人の店（図1）
個人の店は1982年の128.6万から減り続け、2007年には57.2万になりました。法人の店は1982年の43.6万から1999年の60.7万まで増え、その後は少し減りました。2007年には、個人と法人の店の数がほぼ並びました。

### 店は減り、売場は広がった（図2）
1991→2007年に、売場面積は +31、1店当たりの売場面積は +65 でした。販売額（名目）は −5、従業者数は +8 でした。

### 業種ごとに見ると、関係ははっきりしない（図3）
売場面積が伸びた業種で、個人の店が大きく減ったわけではありませんでした。菓子小売業のように、売場面積も個人の店も大きく減った業種があり（−78 と −159）、業種全体が縮んだ形です。法人の店の伸びと個人の店の伸びは、むしろ同じ向きに動きました（R3、傾き +0.94）。

## 問い直し（結果を見てから足した）
H3 が外れたのを見て、「置き換わりは、業種ごとの伸び縮みではなく、どの業種の中でも起きたのではないか」と考え直しました（src/03b_requestion.py、図4）。

- 46業種のうち44業種で、店の数に占める個人の割合が下がりました。
- 46業種をまとめた個人の割合は 66.6% → 54.0%（−12.6ポイント）で、業種の中の変化が −12.6、業種の構成の変化が +0.03 でした。
- 個人の店の減少（33.1万）のうち、売場面積が増えた業種で43%、減った業種で57%が起きていました。

つまり「大きな店に置き換わった」は、業種ごとの売場の伸びでは説明できませんが、どの業種の中でも個人の店の割合が下がった、という形では見えました。

## 頑健性
| 確かめたこと | 減少に占める個人の割合 | 法人の増減 | 売場面積 | 1店当たり | H3 の傾き（p） |
|---|---|---|---|---|---|
| 本文（1991年再集計→2007年） | 98.9% | −5,213 | +31 | +65 | +0.20（0.19） |
| R1 始点を1994年 | 95.8% | −15,238 | +21 | +48 | +0.39（0.02） |
| R2 1991年の再集計前の値 | 100.3% | +1,327 | +31 | +64 | +0.44（0.03） |
| R3 H3 を法人の店の伸びで | | | | | +0.94（0.00） |
| R4 H3 を重みなしで | | | | | +0.15（0.35） |

R2 では法人がわずかに増え、H1 の判定は「支持」に変わります。H3 はどの確かめでも傾きが正で、「売場が伸びた業種ほど個人の店が減った」は見られませんでした。

## 言えないこと
- 「個人＝小さな店、法人＝大きな店」は目安です。法人の小さな店も多くあります。
- 業種の分類は年によって変わり、両方の年に値がそろう46業種は、2007年の個人の店の59%しか覆っていません。コンビニのように新しくできた業種は H3 から抜けています。
- 業種をまたいだ置き換わり（酒屋からコンビニへ、など）は、業種ごとの比較では見えません。
- 個人の割合が下がったことには、同じ店が個人経営から会社に切り替えた分（いわゆる法人成り）も入ります。「大きな店に置き換わった」とは限りません。
- 2007年までの数字です。2012年以降は経済センサスと調査の作り方が変わり、このフォルダではつないでいません。
- 店が減った理由（後継ぎ、人口、規制、通信販売など）は分けられません。

## 仕事で使うなら
- 「小さな店が減った」を示すときは、法人・個人別の事業所数を並べると、減ったのがどちらかがはっきりします。
- 「大きな店に置き換わった」を業種ごとの売場面積だけで示すのは難しく、業種の中の個人の割合の変化を合わせて見るほうが、実態に近い数字になります。
