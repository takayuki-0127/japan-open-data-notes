# F189 日本人の1日は、20年でどう変わったのか？（生活時間の組成データ分析）

## 問い
1日は誰にとっても1,440分です。ある行動が増えれば、別の行動が必ず減ります。この「足すと24時間になる」データを、F170 で使った組成データの方法（対数比・Aitchison 距離）で見ると、2001年から2021年の日本人の1日はどう変わったのか。年齢・男女・曜日で違うのか、高齢化でどこまで説明できるのかを確かめます。

## データ
- 総務省「社会生活基本調査」時系列統計表（令和3年）
  - 第7表：男女、ふだんの就業状態、年齢、行動の種類別総平均時間の推移（10歳以上、週全体）1976〜2021年
  - 第6表：男女、ふだんの就業状態、曜日、行動の種類別総平均時間の推移（15歳以上）1976〜2021年
- 総務省「人口推計」長期時系列データ 第3表（年齢5歳階級別人口、各年10月1日）。2021年の重みは2020年10月1日の値で代用
- 行動の20区分は1996年から。それより前は1次・2次・3次活動と睡眠だけを使用
- 全国の集計値だけを使い、個人や地域の値は扱っていない

## 手法
- 20区分を、主の分析では8区分にまとめた：睡眠／身の回り・食事（受診・療養を含む）／仕事・通勤／学業・学習／家事関連（家事・介護・育児・買い物）／テレビ等（テレビ・ラジオ・新聞・雑誌）／休養・くつろぎ／趣味・交際など（移動・趣味・スポーツ・ボランティア・交際・その他）
- 変化の大きさは、各部分の「ほかに対する比」（clr）の差と、Aitchison 距離で測った。分の差とも並べた
- 高齢化の分け方：年齢別の生活時間を、人口推計の年齢構成で重みづけて全体を作り直し、「年齢構成が変わった分」と「同じ年齢の中で変わった分」に分けた（2つの順番の平均）
- 男女の差：男女の組成の Aitchison 距離と、家事関連÷仕事・通勤の対数比

## 結果（2001→2021年、10歳以上・週全体）
1. **分で見るか比で見るかで「いちばん変わったもの」が違う**
   - 分の差の上位：休養・くつろぎ +37分（80→117分）、テレビ等 −24分（152→128分）、交際・付き合い −16分（26→10分）
   - 比で見ると、交際・付き合い −62%、ボランティア −50%、休養 +46% の順。20区分の距離の2乗の69%は交際とボランティアの2つで、8区分にまとめると休養が65%を占める
   - 分の差の大きさと比の変化の大きさの順位相関は、20区分で0.46、8区分で0.69
2. **5年ごとの動きは2016→2021年が最大**：8区分の距離は0.10〜0.13（1996〜2016年の各5年）に対し、2016→2021年は0.26。20区分では0.33〜0.49に対し0.89。丸め（±0.5分）だけで出る大きさは0.024（95%点）。一方、1次・2次・3次活動の4区分では2016→2021年（0.042）は1981→1986年（0.091）より小さく、粗くまとめると「大きな変化」は見えない
3. **若い世代ほど大きく変わった**：男女×年齢の20グループで、変化が最も大きいのは男性20〜24歳（距離1.51）、最も小さいのは男性65〜69歳（0.32）。男性15〜19歳のテレビ等は127分→55分（2016年）→32分（2021年）で、減少の大半はコロナ前に起きていた。休養・くつろぎは70歳以上（男女とも）を除くすべての年齢で増えた
4. **高齢化の影響は、全体の変化とほぼ別の向き**：65歳以上の割合（10歳以上人口に対して）は20%→31%。年齢構成の変化だけで、テレビ等は+17分、仕事・通勤は−23分、学業・学習は−10分動く計算。実際のテレビ等は−22分なので、同じ年齢の中では約40分減った。休養の+37分は、ほぼすべて同じ年齢の中での増加（年齢構成による分は+1分）。年齢構成の効果を全体の変化の向きに射影した割合は3%
5. **男女の差は約3分の1縮んだ**：8区分の男女の距離は2.25（1996年）→2.03（2001年）→1.50（2021年）。30〜39歳では2.55→1.55。男性の家事関連は24分（1996年）→51分（2021年）（30〜39歳は28分→62分）、女性は214分→204分。ただし1次・2次・3次活動の4区分でまとめると、男女の距離は0.17→0.15とほぼ動かない（仕事と家事が同じ「2次活動」に入るため）
6. **曜日（15歳以上）**：日曜は休養 +56分・趣味・交際など −52分、土曜は仕事・通勤 −46分（男性は −72分）、平日は休養 +30分

## 頑健性
- 区分の粒度（4・8・20区分）：結論の向きは同じだが、「どこが大きく変わったか」と「2016→2021年がどれだけ特別か」は粒度で変わる（上の1・2・5）
- 0の置き換え（0.1・0.5・1・2分）：全国の値には0がなく、結果は同じ。年齢別の20区分では0が34セルあり、変化の大きさの順位は置き換え値で大きく動いた（0.5分の場合との順位相関0.28〜0.76）。そのため年齢別は8区分で示した
- コロナ前だけ（2001→2016年）：若い世代ほど大きく変わった形は同じ（年齢順の順位相関0.82）。15〜29歳の平均距離は2001→2016年0.93、2016→2021年0.55
- 人口の重み：重みづけ平均と公表の総数のずれは最大1.3〜2.9分。2001→2016年で分けても、年齢構成による分はテレビ等+13分、仕事・通勤−21分で同じ向き
- 曜日・男女・有業者に分けても、休養の増加とテレビ等・交際の減少は同じ向き

## 言えないこと
- 2021年の調査（10月）はコロナ禍の最中で、2016→2021年の大きな動きのうちどこまでが一時的なものかは分からない
- 「休養・くつろぎ」が増えた理由（スマートフォンの利用が回答上どこに入るかなど）は、このデータでは分けられない。区分の定義の運用が年によって変わった可能性も否定できない
- 年齢別の値は同じ人を追ったものではなく、世代の効果と時代の効果は分けていない
- 高齢化の分け方は、10歳以上の年齢10区分での近似で、2021年の重みは2020年の人口で代用している
- 平均時間（その行動をしなかった人も0分として含む総平均）なので、「する人が減った」のか「する人の時間が減った」のかは区別できない
