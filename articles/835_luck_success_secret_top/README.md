# 835 上位だけを見て「成功の秘訣」を決めると、何を読み違えるのか？（運と実力）

成績の上位の人に共通するやり方を集めて「成功の秘訣」とする話はよくあります。ところが、上位だけを見ると、平均を上げるやり方と、振れを大きくするだけのやり方の区別がつきません。また、関係のない習慣でも、たくさん調べれば1つは上位に多く見えます。**ここでは、作成者が乱数で作った架空の営業担当1,000人（実力・運・やり方を作成者が置いたもの）で、上位20人だけを見たときに「大きな案件を狙うやり方」と、成績と関係のない20個の習慣がどう見えるかを数えました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A835 | 上位20人に多いやり方や習慣は、成績を上げるものと言えるか。上位だけを見ると何を読み違えるか | 架空の営業担当1,000人。年間の成績＝100＋実力＋運。実力は標準偏差8、運は標準偏差12の正規分布。3割の人は「大口狙い」（大きな案件を狙うやり方）で、平均は同じ（差0）だが運の振れが1.6倍。成績と関係のない習慣を20個置き、それぞれ半分の人が持つ。1年目と2年目は実力が同じで、運だけ引き直す。人を作り直して200回の平均。確かめとして、大口狙いの運の振れ（1.0・1.3・1.6・2.0倍）と平均の差（−5・0・+5）を変えた場合と、上位の切り方（10・20・50・100人）を変えた場合も数えた。seed 835 | `src/a835_secret.py` |

## 主な結果

### 成績の順に分けたときの大口狙いの割合（200回の平均）
| グループ | 大口狙いの割合 |
|---|---|
| 上位20人 | **71.3%** |
| 上位100人 | 47.4% |
| 全員 | 29.9% |
| 下位100人 | 47.6% |
| 下位20人 | **70.3%** |

- 平均の差は0と置いた（200回の平均で、大口狙い−ふつうのやり方＝+0.01）のに、上位20人の7割は大口狙いだった。下位20人も7割が大口狙いだった
- 2年目の成績で上位20人を選び直しても、大口狙いは72.4%だった。「翌年も上位に多い」ことは、成績を上げるやり方である証拠にならなかった
- 1回分のデータ（`data/sales_people.csv`）では、上位20人の85%、下位20人の60%が大口狙いだった。成績の標準偏差は、大口狙いが20.83、ふつうのやり方が14.32

### 上位の切り方と、大口狙いの割合（基本の置き方、200回の平均）
| 上位の人数 | 10人 | 20人 | 50人 | 100人 |
|---|---|---|---|---|
| 大口狙いの割合 | 79.8% | 71.3% | 57.6% | 47.4% |

- 上位を狭く切るほど、振れの大きいやり方が多く見えた

### 確かめ：運の振れの倍率と平均の差を変える（上位20人・下位20人の大口狙いの割合、200回の平均）
| 運の振れ | 平均の差 −5 | 平均の差 0 | 平均の差 +5 |
|---|---|---|---|
| 1.0倍 | 15.1% ／ 48.8% | 30.2% ／ 29.7% | 49.4% ／ 15.2% |
| 1.3倍 | 34.7% ／ 70.2% | 51.8% ／ 52.0% | 70.0% ／ 34.8% |
| 1.6倍（基本） | 54.7% ／ 84.9% | 71.0% ／ 71.2% | 84.5% ／ 54.6% |
| 2.0倍 | 78.1% ／ 95.1% | 89.1% ／ 88.6% | 95.6% ／ 77.3% |

（各セルは「上位20人 ／ 下位20人」。全員での大口狙いの割合は約30%）

- **上位20人での割合は、平均の差より運の振れの倍率で大きく動いた**。振れが1.6倍なら、平均が5低いやり方（成績を下げるやり方）でも上位20人の54.7%を占め、全員での割合（約30%）より多く見えた
- 平均の差の向きは、上位だけでなく下位も並べると見えた。平均の差−5なら下位のほうが多く（54.7% ／ 84.9%）、+5なら上位のほうが多い（84.5% ／ 54.6%）

### 成績と関係のない20個の習慣（200回の平均）
| | 上位20人での割合 − 全員での割合 |
|---|---|
| 1年目：上位20人でいちばん差の大きい習慣を選ぶ | **+20.4ポイント** |
| 2年目：同じ習慣を、2年目の上位20人で数え直す | −0.3ポイント |

- 関係のない習慣を20個調べると、上位20人では、どれか1つが平均で20ポイント多く見えた。200回のうち50%で、差は20ポイント以上だった
- 選んだあとに別の年で数え直すと、差はほぼ0に戻った

## 動かし方
```
pip install -r requirements.txt
cd src && python a835_secret.py
```
数秒で終わります。`data/sales_people.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約2秒）
- 運の振れを1.0倍（ふつうのやり方と同じ）に置くと、平均の差0では上位20人・下位20人とも約30%（全員での割合と同じ）になり、上位に多く見える現象は消えた（上の表）
- 運の振れの倍率と平均の差を12通りに変えても、「上位20人での割合だけでは、平均を上げるやり方かどうかは分からない」ことは変わらなかった。割合の大きさそのものは置き方で15〜96%と大きく動いた

## データ
- `data/sales_people.csv`：架空の営業担当1,000人（person_id・big_deal_style（大口狙いなら1）・skill（実力）・score_y1・score_y2（1年目・2年目の成績）・habit01〜habit20（成績と関係のない習慣、持っていれば1））

## 注意（言えないこと）
- 架空のデータです。実力と運の大きさ、大口狙いの割合と振れの倍率、習慣の数は作成者が置いたもので、割合の大きさはこれで決まります
- 実際の営業で、大きな案件を狙うやり方が成績を上げるか下げるかは、ここでは何も言えません。言えるのは「上位だけを見ても、それは分からない」というところです
- 運は1年ごとに引き直し、実力は2年で変わらないと置きました。やり方を途中で変える人、成績の悪い人がやめていく（下位が記録に残らない）ことは入れていません。下位が記録に残らない場合は、下位と比べる確かめ方そのものができなくなります
- 習慣は成績とまったく関係がないと置きました。本当に効く習慣が混ざっているときに、それを見分けられるかは数えていません
- 平均への回帰（たまたま上位だった人が翌年に戻る）は関連する記事 826、月間1位が続く長さは関連する記事 831 で扱っています
