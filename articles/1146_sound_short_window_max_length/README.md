# 1146 短い区間ごとに測った大きさの最大値は、区間の長さでどう変わるのか？（音の大きさ）

曲の大きさは、曲全体で1つの値を出すほかに、「0.4秒ごと」「3秒ごと」のように短い区間ごとに測り、その最大値を見ることがあります。けれども、区間を短くするほど、たまたま大きい一瞬や短い強い音が平均でならされずに残るので、最大値は上に出ます。どの区間の長さで測ったかで、「どちらの曲の最大値が大きいか」も入れかわります。**ここでは、作成者が式と乱数で作った架空の曲（120秒の波形。全体の大きさはどれも−20dBにそろえた）200曲で、区間の長さを0.05〜30秒の7通りに変え、区間ごとの大きさの最大値が曲全体より何dB上に出るか、曲どうしの大小がどれだけ入れかわるかを数えました。曲の作り方を変えた27通りでも確かめました。**

例の曲は作成者が式と乱数で作ったもので、実在の曲・配信先の音量の基準・測る機材やソフトの値を表すものではありません。人に聞き比べてもらった実験ではなく、大きさは波の値の二乗平均だけで数えています（低い音と高い音の重み付けはしていません）。

関連する記事：20冊目 第7章の 819「移動平均の幅で、山と谷はどれだけ動くのか？」は、毎日の来店数で平均する幅を変えると山の高さ・日付が動くことを数えています。この記事は同じ「平均する幅」の話を、音の大きさの最大値と、曲どうしの大小の入れかわりに絞ります。同じ企画の 1143「静かな部分を含めて測るか除いて測るかで、1曲の大きさの数字はどれだけ変わるのか？」は、短い区間ごとに数えた大きさのうち小さい区間を除いて平均する話で、この記事は除かずに最大値を見ます。

## 主な結果

### 区間の長さと、最大値が曲全体より上に出る分（200曲、`results/by_window.csv`）
| 区間の長さ | 平均 | 中央値 | 5〜95%の範囲 |
|---|---|---|---|
| 0.05秒 | **+7.49dB** | +7.342dB | +4.318〜+10.699dB |
| 0.1秒 | +6.078dB | +5.957dB | +3.288〜+9.238dB |
| 0.4秒 | +3.393dB | +3.202dB | +1.144〜+6.215dB |
| 1秒 | +2.905dB | +2.734dB | +0.714〜+5.664dB |
| 3秒 | **+2.688dB** | +2.5dB | +0.473〜+5.392dB |
| 10秒 | +2.485dB | +2.29dB | +0.347〜+5.187dB |
| 30秒 | **+1.469dB** | +1.401dB | +0.159〜+3.157dB |

- **全体の大きさが同じ−20dBの曲でも、区間を短くするほど最大値は上に出た**。200曲の平均で、30秒の区間では+1.469dB、3秒では+2.688dB、0.05秒では+7.49dBだった
- 0.4秒と3秒の差は平均0.706dBと小さく、0.05秒と3秒の差は平均4.803dBだった。0.05秒の最大値が3秒より3dB以上大きい曲は89%あった
- 3秒の区間の最大値は、部分ごとの上下の大きさ s とよく連動し（相関0.7927）、短い強い音の強さ b とはほとんど連動しなかった（−0.0736）。0.05秒の区間の最大値は b と連動した（0.65）。0.4秒では b との相関は0.0275だった。0.4秒の区間は強い音の間隔（0.5秒）に近く、どの区間にも強い音がほぼ1つずつ入ってならされたためと考えられる（推測。間隔を変えた確かめはしていない）

### 例の2曲（`results/example_two_songs.csv`）
| 区間の長さ | A（部分ごとの上下が大きい） | B（短い強い音が強い） | 大きいほう |
|---|---|---|---|
| 0.05秒 | +7.623dB | +8.083dB | B |
| 0.1秒 | +7.082dB | +5.911dB | A |
| 0.4秒 | +6.22dB | +1.528dB | A |
| 3秒 | +5.902dB | +0.33dB | A |
| 30秒 | +4.199dB | +0.062dB | A |

- **全体の大きさが同じ2曲で、0.05秒の区間ではBの最大値が大きく、0.1秒より長い区間ではAが大きかった**。Bの最大値は、0.05秒の+8.083dBから3秒の+0.33dBまで下がった

### 曲どうしの大小の入れかわり（200曲、19,900組、`results/a1146_main.json` の songs200）
| 比べた2つの区間の長さ | 大小が入れかわった組 | 順位の相関 |
|---|---|---|
| 0.4秒と3秒 | 4.3% | 0.9891 |
| 0.1秒と10秒 | 23.13% | 0.734 |
| 0.05秒と3秒 | **26.69%** | 0.6518 |

- 0.4秒と3秒では、大小が入れかわった組は4.3%で、最大値の上位10曲のうち7曲が同じだった
- **0.05秒と3秒では、曲の組の26.69%で、どちらの最大値が大きいかが入れかわった**

### 大きさの形のない一様な雑音でも、最大値は上に出る（20回の平均、`results/steady_noise.csv`）
| 区間の長さ | 長さ30秒の音 | 120秒 | 480秒 |
|---|---|---|---|
| 0.05秒 | +1.947dB | +2.09dB | +2.358dB |
| 0.4秒 | +0.606dB | +0.729dB | +0.807dB |
| 3秒 | +0.178dB | +0.23dB | +0.272dB |

- 大きさの形を置かない雑音でも、0.05秒の区間の最大値は全体より+2.09dB（120秒の音）上に出た。区間が短いと中の点が少なく、でたらめさだけで大きさが振れるため
- 同じ区間の長さでも、音が長いほど最大値は上に出た（0.05秒で30秒の音+1.947dB、480秒の音+2.358dB）。区間の数が増え、たまたま大きい区間に当たる回数が増えるため

### 区間をずらす刻み（`results/a1146_main.json` の songs200）
- 区間を重ねずに並べて測ると（0.4秒なら0.4秒ずつ）、0.01秒ずつずらしたときより最大値が平均0.129dB（最大0.565dB）低かった。3秒の区間では平均0.065dB（最大0.198dB）。区間の切れ目の置き方でも最大値は動いた

### 確かめ：曲の作り方を変えた27通り（各40曲、`results/grid.csv`）
- 0.05秒と3秒で大小が入れかわった組は、27通りで10.9〜43.85%だった。0.4秒と3秒では2.05〜20.38%
- 最大値の平均の差は、0.05秒−3秒で+3.091〜+6.5dB、0.4秒−3秒で+0.505〜+1.012dBで、27通りすべてで短い区間のほうが上に出た
- 0.4秒と3秒の入れかわりが大きかったのは、部分ごとの上下が小さく（上限1dB）、強い音が強い（上限12・18dB）ときだった。曲どうしの差が部分ごとの上下で決まりにくくなり、強い音の分が効いたためと考えられる（推測）

## 注意（言えないこと）
- 架空のデータです。曲の作り方（雑音に大きさの形を掛ける、0.5秒ごとの強い音、8〜20秒ごとの部分の上下）は作成者が置いたもので、結果はこれで決まります。大小の入れかわりは、置き方27通りで0.05秒と3秒の組の10.9〜43.85%に分かれました
- 0.4秒の区間で強い音の影響が小さかったのは、強い音の間隔を0.5秒に置いたためです。間隔を変えた確かめはしていません
- 大きさは波の値の二乗平均だけで数え、低い音と高い音の重み付け、静かな部分を除く決まりは入れていません。実在の配信先の音量の基準や測る機材の値とは違います
- 人が聞いてどう感じるかは数えていません。どの区間の長さで測るのがよいかも言えません
