# 723 前年がマイナスの利益の伸び率を、ふつうの式で出すと、何店で向きが逆に見えるのか（実務の型）

伸び率は「（今年−前年）÷前年」で出します。前年がプラスなら問題ありませんが、前年がマイナス（赤字）だと、分母がマイナスなので符号が逆になります。赤字が縮んだ店の伸び率が「−」に、赤字が広がった店が「＋」になります。**ここでは、架空の40店（前年が赤字の店8店を含む）の営業利益で、ふつうの式・分母を絶対値にした式・差額の3通りを出し、向きが逆に見える店と、並びの入れ替わりを数えました。** DuckDB の SQL と Python で同じ値になることを確かめています。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A723 | 前年がマイナスの店の伸び率は、何店で向きが逆に見えるか | 架空の40店の営業利益（万円）の前年と今年（前年は平均300・標準偏差400、今年は前年に平均+60・標準偏差250の変化）。ふつうの伸び率・分母を絶対値・差額の3通りと順位。seed 723 | `src/a723_growth_neg.py`、`src/02_growth_duckdb.sql`、`src/01_growth_tsql.sql`（T-SQL：未検証） |

## 主な結果（40店）
| 項目 | 結果 |
|---|---|
| 前年が赤字の店 | 8店 |
| ふつうの式で向きが逆に見えた店 | **8店（前年が赤字の8店すべて）** |
| うち、よくなったのに「−」 | 6店（例：−110万円→＋274万円で **−349%**） |
| うち、悪くなったのに「＋」 | 2店（例：−147万円→−278万円で ＋89%） |
| 差額の順位との順位相関 | ふつうの式 0.382、分母を絶対値 0.901 |
| ふつうの式の下位5店のうち、よくなった店 | 3店 |

- 前年が赤字の店は、例外なく伸び率の向きが逆になった。黒字に転じた店（−110→＋274万円）は、ふつうの式では40店中最下位、差額では5位だった
- 前年が0に近い店（±50万円未満、3店）は、伸び率が最大1,184%と大きく振れ、並べると上位を占めた
- ふつうの式と分母を絶対値にした式で、順位が最大37位動いた

## データ
- `data/profits.csv`：架空の店・前年と今年の営業利益（万円）。作成者が乱数で作ったもの（seed 723）

## 注意（言えないこと）
- 架空のデータです。利益の分布は作成者が置いたもので、向きが逆になる店の数はこれで決まります
- 分母を絶対値にした式は向きをそろえるだけで、前年が0に近い店の振れは残ります。前年がマイナスや0に近い店は、差額で示すか「黒字化」などと書くのが分かりやすいです
- 会計の扱いや、店の評価の方法についての助言はしません。数字の出し方で見え方が変わることを見たものです
