# F150 季節のパターンそのものは、年々変わっているのか？ 動的調和回帰（時変の季節成分）

看板記事 F150。note の記事は下書きのみです。

## 問い

月ごとの統計は、季節の形（何月に多く、何月に少ないか）を毎年同じとみなして「季節調整」することが多い。しかし、季節の形そのものが年々変わっているなら、その前提は崩れる。出生数・訪日外客数・電力需要の3つで、季節の形が変わったかどうか、どう変わったか、変わったなら予測に効くかを調べた。

## データ

3つとも、このリポジトリの過去の記事が公的な出典から取得した表を使い回した（`src/01_取得.py` が各記事のフォルダから取得する）。

| 系列 | 出典 | 期間・単位 | 元の記事 |
|---|---|---|---|
| 出生数 | 厚生労働省「人口動態統計」2025年確定数 上巻 出生 第4.2表（e-Stat） | 2000年1月〜2025年12月。月の日数で割り、1日あたりにした | F02 |
| 訪日外客数（総数と主な7か国・地域） | 日本政府観光局（JNTO）「国籍/月別 訪日外客数（2003年～2026年）」 | 2003年1月〜2025年12月。1日あたり。2020年2月〜2022年12月は入国制限の期間として分析から外した（欠測として扱う） | F68 |
| 電力需要（東京エリア） | 東京電力パワーグリッド「でんき予報」エリア需給実績、気象庁 東京の日平均気温 | 2016年4月〜2026年9月。月平均（GW）。気温から冷房度日（日平均 22℃を超えた分の合計）と暖房度日（14℃を下回った分の合計）を作った | F22 |

`data/monthly_series.csv` は `src/02_整形.py` で作る月次の表です。電力の1時間ごとの表（`data/raw/hourly_tokyo.csv`、約7MB）は F22 のフォルダにあるので、このフォルダには置いていません（`01_取得.py` で取得できます）。

## 手法

**動的調和回帰（状態空間モデル）**：対数をとった系列を、トレンド（傾きも変わる局所線形トレンド）＋季節成分＋不規則な変動に分ける。季節成分は 12か月周期の6つのフーリエ項（調和項）の和で、その係数がランダムウォークで少しずつ動くことを許す（`statsmodels` の `UnobservedComponents`、`stochastic_freq_seasonal`）。係数が動かない（季節を固定する）モデルと、尤度比・AIC で比べた。季節の分散が0かどうかは境界の検定なので、p 値は 0.5χ²(0)+0.5χ²(1) の混合で出した。

**季節の形**：カルマン平滑化で取り出した季節成分を、期間ごとに月別に平均した（年の平均との差、%）。「振れ幅」は最も高い月と最も低い月の差（%ポイント）。

**予測**：前年12月までのデータで当て、翌年1〜12月を予測する。予測を始める年を出生は2014〜2024年、訪日は2011〜2018年と2023・2024年、電力は2020〜2024年とし、外れ方の平均（対数の差の絶対値、%）を比べた。水準の外れを除いた「形の外れ方」も出した。比較の相手は「前年の形をそのまま」。

## 結果

### 1. 季節の形が年々変わる、という証拠の強さ

| 系列 | 尤度比 | p 値 | AIC の差（変わる − 固定） | 振れ幅（前 → 後） | 前後の期間 |
|---|---|---|---|---|---|
| 出生数 | 42.4 | <0.001 | −40.4 | 8.7 → 13.4 | 2000〜04年 → 2021〜25年 |
| 訪日外客数 | 4.9 | 0.014 | −2.9 | 21.8 → 13.8 | 2005〜09年 → 2024〜25年 |
| 電力需要 | 9.5 | 0.001 | −7.5 | 26.9 → 32.3 | 2017〜19年 → 2023〜25年 |

### 2. どう変わったか

- **出生数**：1〜3月が低く、7〜10月が高い形が強まった。1月は −0.3% → −4.4%、3月は −3.1% → −7.3%、7月は +2.9% → +4.9%。9月がいちばん多い月なのは変わらない。振れ幅は 2006年ごろの約8ポイントから、2025年の約14ポイントまでほぼ一直線に広がった（図1・図2）。
- **電力需要**：7月が +8.3% → +14.7%、8月が +12.8% → +15.9% と夏の山が高くなり、春（4・5月）と秋（10・11月）の谷が深くなった。ただし、7・8月の平均気温は 2017〜19年の 27.1℃ から 2023〜25年の 29.0℃ に上がっている。冷房度日・暖房度日を説明変数に入れると、7・8月の季節成分は前後とも ±2% 以内に収まり、夏の山の高まりはほぼ気温で説明できた。気温を入れたあとも季節は固定より「変わる」モデルのほうがよく合う（尤度比 19.0）が、残る変化は4・5月が2ポイントほど低くなった程度（図3）。
- **訪日外客数**：モデルの上では、季節の振れ幅は 2003年の 23 ポイントから 2025年の 14 ポイントへ、ゆっくり縮んだ。ただし証拠は弱く、調和項を3つにする（p=0.10）、2019年までにする（p=0.07）と、固定モデルとの差ははっきりしなくなる。一方、期間ごとにトレンドを除いた実際の形を比べると、7月は +14.6% → −0.6%、8月は +9.1% → −7.2% と、夏の山は入国制限のあとに消えている。モデルは季節の変わる速さを主に 2003〜2019年の緩やかな変化から学ぶため、この入れ替わりに追いついていない（図4の点線）。

### 3. 訪日の夏の山が消えたのは、国・地域の構成の変化か

国・地域を、韓国・中国・台湾・香港・米国・タイ・豪州・その他の8つに分け、季節の形と年間の構成比を 2005〜09年と 2024〜25年で比べた（`results/inbound_mix_decomposition.csv`）。

| | 7月 | 8月 | 振れ幅 |
|---|---|---|---|
| 2005〜09年（実際） | +14.6 | +9.1 | 23.3 |
| 構成だけ 2024〜25年にした場合 | +14.0 | +9.3 | 24.9 |
| 各国・地域の形だけ 2024〜25年にした場合 | −3.2 | −11.1 | 20.5 |
| 2024〜25年（実際） | −0.6 | −7.2 | 18.1 |

構成を入れ替えても夏の山はほとんど変わらず、各国・地域の形が変わったことで消えていた。たとえば7月は、韓国が +17.7% → −7.7%、台湾が +32.4% → +7.9%、香港が +33.2% → +1.4% と下がった。一方、中国は +9.5% → +28.3% と上がった（`results/inbound_market_shapes.csv`）。理由（夏の暑さ・航空便・休暇の取り方など）はこのデータからは分からない。

### 4. 予測に効くか

| 系列 | 前年の形をそのまま | 季節を固定 | 季節が年々変わる |
|---|---|---|---|
| 出生数（外れ方 / 形の外れ方） | 4.03 / 1.85 | 2.64 / 1.67 | 2.44 / 1.60 |
| 訪日外客数 | 22.94 / 7.96 | 10.47 / 6.41 | 10.25 / 6.31 |
| 電力需要 | 3.48 / 3.17 | 3.52 / 3.37 | 3.48 / 3.07 |

季節を年々変えるモデルは、3系列とも形の外れ方をわずかに小さくした（0.07〜0.30 ポイント）。予測の外れの大部分は水準（トレンド）の外れで、季節の形の扱いで変わる部分は小さい。

## 頑健性チェック（`results/robustness_models.csv`）

1. **調和項の数（2・3・4・6）**：出生（振れ幅 6.4〜8.7 → 11.4〜13.4、すべて p<0.001）と電力（すべて p≤0.001、夏の山が高くなる）は変わらない。訪日は3つにすると p=0.10 になる。
2. **期間**：出生を 2010年からにしても p<0.001（2010〜14年 11.3 → 2021〜25年 13.8）。電力を 2017年からにしても p=0.007。訪日を 2019年までにすると p=0.07。
3. **系列の形**：出生・訪日を1日あたりでなく月の合計にしても、同じ向き（出生 13.4 → 18.9、訪日 22.6 → 17.1）。
4. **気温**：電力は、夏の山の高まりがほぼ気温で説明できる（上の結果2）。
5. **別の手法（窓ごとの固定フーリエ回帰）**：5年（電力は3年）の窓ごとに、3次のトレンド＋固定のフーリエ項を最小二乗で当てると、振れ幅は出生 8.5（2000〜04年）→ 14.6（2021〜25年）、電力 25.8（2017〜19年）→ 36.3（2023〜25年）、訪日 28.3（2003〜07年）→ 22.1（2015〜19年）。状態空間モデルと同じ向き（`results/rolling_ols_profiles.csv`）。
6. **訪日の構成の分解**：上の結果3。

## 言えないこと

- 出生の季節の形が変わった理由（妊娠の時期の選び方、出産の場所や方法の変化など）は、このデータからは分からない。
- 電力では、気温を実測で入れている。また、2016〜2026年の10年しかないので、季節の分散の推定は不確か。
- 訪日は、入国制限の前後で季節の形が大きく入れ替わったが、状態空間モデルはその速さに追いつかない。2024〜25年の2年分しかないので、新しい形が定着したのかは、まだ分からない。
- 季節調整の実務（X-13 など）と比べたわけではない。
- p 値は、季節の分散が0かどうかの近似的な検定です。
