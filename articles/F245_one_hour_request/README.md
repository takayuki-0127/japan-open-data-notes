# F245 1つの依頼に、1時間でどこまで答えられるか？

架空の依頼「あおばドラッグ（架空）の8月の売上は前年同月比 −1.0%。業界も落ちているのか、うちだけか。年間はどう着地しそうか。月曜朝の会議で使いたい」に、**60分の枠**で答えた記録です。問いを分ける → データを集める → 最初の答え → 確かめる → 1枚にまとめる、の順で進め、実際にかかった時間も残しました。

シリーズ「② 実務に近い分析（F231〜F245）」の最後の1本で、これまでの F231（予測の地平）・F233（カレンダーと天気）・F243（KPI ツリーと構成）・F244（間違えにくい SQL）を道具として使っています。

**「あおばドラッグ」は架空の会社です。** チェーンの数字（8月 −1.0%）と品目構成は依頼文の仮の値で、実在の会社のデータではありません。業界の数字はすべて公的統計です。

## この記事で分かること
- 業界（ドラッグストア、全国）の8月は前年同月比 **+3.07%**、関東は +3.25%。6〜8月の3か月でも全国 +2.35%、関東 +2.50%。
- 業界の伸びの内訳は、**食品 +1.20pt と調剤 +0.89pt で7割**。OTC医薬品は −0.37pt。
- カレンダー（+0.24pt）と天気（−0.33pt）はほぼ打ち消し合い、除いても +3.11%。
- 比べ方を5通りに変えても、架空チェーン（−1.0%）と業界の差は **−3.1〜−4.3ポイント**。品目構成を合わせても −3.15pt（構成を±50%揺らすと業界 +1.7〜+2.6%）。
- ただし業界の数字は**全店ベース**（新店の分を含む）で、チェーンの既存店と同じ土俵ではない。「うちだけ悪い」と言い切るには既存店どうしの比較が要る。
- 業界の2026年の着地は **+4.2〜+4.6%**（SARIMA 2014年〜で +4.37%）。1〜8月の実績は +4.53%。
- 実際の作業は、問いを分けるところから1枚の答えまで**約4分**（AI のコーディング支援あり、データとコードは F231・F233 のものを再利用）。60分の枠の大半は、問いの切り分けと「言えないこと」の整理に使うべき、というのが結論。

## 問い
- 依頼の「うちだけ悪いのか」を、どの比較で答えるか（全国／地域／品目構成／カレンダー・天気）。
- 1時間で出せる答えはどこまでで、何は「もっと時間があれば」に回すべきか。

## データ
| データ | 内容 | 期間 |
|---|---|---|
| 経済産業省「商業動態統計」 | ドラッグストアの販売額（全国・9地域・品目9区分） | 2014年1月〜2026年8月 |
| F233 の結果 | ドラッグストアの月別のカレンダー・天気の寄与 | 2026年8月 |
| F231 の結果 | 年間合計の予測の外れ（1年目 SARIMA 1.63%） | — |

新しい取得はしていません（F233 で取得したデータの再利用）。

## 手法
1. **問いを分ける**：①業界も落ちたか ②うちだけか（比べ方） ③何が効いたか（品目） ④年間の着地。
2. **比べ方を5通り**：全国、関東、調剤を除く、架空チェーンの品目構成に合わせる（業界の品目別の伸びを構成で加重）、カレンダー・天気を除く（F233 の係数）。
3. **品目別の寄与**：品目の増減 ÷ 前年の合計（ポイント）。合計は全体の前年比と一致。
4. **年間の着地**：9〜12月を SARIMA(1,1,1)(0,1,1)12（対数）、ETS（加法）、季節ナイーブ（前年同月×直近1年の伸び）で予測し、1〜8月の実績と足した。学習の始まりを2014・2018・2022年の3通り。
5. **SQL**：前年比と品目寄与を SQL Server 互換の SQL（CTE・SUM OVER）で書き、DuckDB で実行して pandas と照合。
6. **1枚の答え**：会議用の HTML（`dashboard/one_page_answer.html`）。

## 頑健性
- 比べ方を5通り（上の表）：差は −3.1〜−4.3pt で、どれでも業界より低い。
- 単月ではなく6〜8月の3か月：業界 全国 +2.35%、関東 +2.50%。差は少し縮むが残る。
- 品目構成を±50%ランダムに揺らす（2,000回）：構成を合わせた業界の伸びは +1.70〜+2.61%（5〜95%点）。
- 年間の着地はモデル3通り×学習期間3通り：+4.16〜+4.60%。
- 地域どうしの8月の前年比のばらつき（標準偏差）は年により 1.6〜6.9pt。1社1か月の3〜4ポイントの差は、それだけで「異常」とは言えない大きさ。
- SQL との照合：地域の前年比・品目の寄与とも、丸め（小数2桁）の範囲で一致（差は0.005未満）。

## 1枚の答え（会議用）
`dashboard/one_page_answer.html`（図6）。答え・比べ方の表・品目の内訳・言えないこと・もう1日あればやること、を1枚に入れています。

## もっと時間があれば
- 既存店どうしの比較（チェーンの既存店 vs 業界の既存店に近い指標）。業界の全店の伸びには新店の分が入る（F243 でスーパーは全店と既存店の差が平均3ポイント）。
- 店舗別・品目別の内訳、客数×客単価の分解（F243 の KPI ツリー）。
- 来月以降のチェーンの予測（F231 の方法）と、販促・値上げの影響（F234・F240）。

## 言えないこと
- **架空チェーンの数字と品目構成は仮の値**で、実在の会社ではない。
- **業界の数字は全店ベース**。新店の分を含むので、チェーンの既存店の数字と直接は比べられない（ドラッグストアの店舗数はこのデータにない）。
- **F233 のカレンダーの係数は、ドラッグストアでは期間外にうまく効かなかった**（F233 の検証）。今回は寄与がほぼ0なので結論は変わらないが、ほかの月では注意。
- 年間の着地は業界の見込みで、チェーンの着地ではない。
- 時間の記録は1回だけの記録で、AI の支援あり。人が1人で同じ順番で進めた場合の時間は分からない。
