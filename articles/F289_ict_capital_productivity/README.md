# F289 情報通信白書のデジタル化の指標は、生産性と結びついているか？

**問い。** 情報通信白書は、ICT投資やソフトウェアへの投資を「デジタル化」の指標として示し、生産性を上げる鍵として扱います。産業ごとに見て、ICT資本の多い産業・増やした産業ほど、生産性は高く、伸びたのか。企業の情報システム部門や経営企画、投資の判断をする人、白書を読み解く記者が知りたい問いです。

**答え（先にまとめ）。**
- ICT資本（情報機器・通信機器・ソフトウェア）の多い産業ほど、労働生産性の水準は高い。2015年の92産業で順位相関 **0.71**（95%区間 0.58〜0.82）
- ただし、ICT資本を増やした産業ほど労働生産性が伸びた、とは言いにくい。1995→2007年 **+0.18**、2007→2019年 **+0.07**（どちらも95%区間が0をまたぐ）
- ICTを積んだ分を除いた生産性（TFP）の伸びとは、結びつきはなく、2007→2019年はむしろ逆向き（**−0.22**、95%区間 −0.42〜0.00）
- 白書がよく使う「ICT投資比率」が1995〜2007年に高かった産業が、2007→2019年に伸びたわけでもない（**+0.16**）
- 問い直し：水準の強い結びつきの多くは「資本全体が多い産業だから」。ICT以外の資本の多さをそろえると、ICTだけの結びつきは1995年に **0.00** だったのが、2015年 **0.49**、2019年 **0.53** と、年を追って強くなった

## データ
- 経済産業研究所・一橋大学「JIPデータベース2023」（1994〜2020年、99部門）
  - `jip2023_2.xlsx`：資本（投資・資産マトリックス：部門×資産×年の名目・実質投資と純資本ストック）
  - `jip2023_4.xlsx`：成長会計（実質付加価値 V、名目付加価値 NV、付加価値ベースTFP成長率 TFPva、労働生産性上昇率 LP_G、集計部門の定義 DS）
  - `jip2023_3-8.xlsx`：部門別マンアワー（従業者数×年間総実労働時間÷1000）
- ICT資産＝3ba 情報機器＋3bb 通信機器＋6c コンピュータソフトウェア
- 使った部門：DS の「市場経済」（202）に入る92部門。除いたのは住宅・公務・教育・医療・保健衛生・社会保険・社会福祉・介護・会員制団体（JIPの定義で市場経済に入らない部門）と分類不明
- Excel は大きいのでリポジトリに入れていません（`.gitignore`）。`src/zz_f289_01_取得.py` が RIETI から取り直し、md5 を `data/MANIFEST.json` と照らします

## 手法
- 労働生産性＝実質付加価値（2015年連鎖価格）÷マンアワー（円／時間）
- ICT資本の深さ＝実質ICT純資本ストック（2015年価格）÷マンアワー（円／時間）
- 伸び＝期間の対数差÷年数（年率）。TFPの伸び＝TFPva の期間の年平均
- ICT投資比率＝期間の名目ICT投資の合計÷名目投資の合計
- 産業の間の順位相関（スピアマン）。95%区間は産業を選び直すブートストラップ（1,000回、種289）
- 期間：前半 1995→2007年、後半 2007→2019年（2020年はコロナで外し、頑健性で入れた）

## 計画と結果（PLAN.md を先にコミット：0717448）
| 仮説 | 基準 | 結果 | 判定 |
|---|---|---|---|
| H1 水準 | 2015年の順位相関 ≥ 0.3 | 0.71（0.58〜0.82） | 支持 |
| H2 伸び | 前半・後半とも > 0 | +0.18（−0.04〜0.37）、+0.07（−0.14〜0.29） | 支持（基準の上では。ただし両方とも区間が0をまたぎ、弱い） |
| H3 TFP | 前半・後半とも絶対値 < 0.2 | −0.10、**−0.22** | 外れ（後半が−0.2を超えて逆向き） |
| H4 白書の指標 | 前半のICT投資比率と後半の労働生産性の伸び < 0.2 | +0.16（−0.06〜0.34） | 支持（＝結びつきは弱い） |

H3 は「結びつきがほぼない」を予想していましたが、後半は逆向きに −0.2 を超えました。成長会計では TFP＝付加価値の伸び−（労働・資本の寄与）なので、付加価値が伸びないままICT資本だけ積むと、その分 TFP は小さく出ます。逆向きの一部はこの作り方から来ている可能性があります（推測）。

## 問い直し（結果を見た後に足した）
H1 の強い結びつきは、ICTだから高いのか、それとも資本全体が多い産業（設備の大きい産業）だから高いのか。ICT以外の資本の多さ（1時間あたり）をそろえた偏順位相関を見ました。

| 年 | ICT資本と労働生産性 | ICT以外の資本と労働生産性 | ICT（ICT以外をそろえた偏相関） | 資本に占めるICTの割合と労働生産性 |
|---|---|---|---|---|
| 1995 | 0.28 | 0.56 | 0.00 | −0.39 |
| 2007 | 0.55 | 0.71 | 0.26 | −0.24 |
| 2015 | 0.71 | 0.81 | 0.49 | −0.22 |
| 2019 | 0.73 | 0.80 | 0.53 | −0.22 |

- 水準の結びつきの多くは資本全体の多さと重なりますが、ICTだけの分も年を追って強くなりました
- 「資本の中のICTの割合」が高い産業ほど、労働生産性はむしろ低い（設備の小さいサービス業でICTの割合が高いため（推測））
- 割合を増やした産業ほど伸びたか：労働生産性 前半 +0.08、後半 −0.11、TFP 前半 −0.03、後半 −0.23

## 計画からのずれ
- PLAN を書く前に、ファイルの構成を確かめる途中で「部門別名目投資フロー」の農業・農業サービスの2行の値を目にしました（生産性の値は見ていません）
- 使った部門は「市場経済」の旗で決めたので、教育・医療・保健衛生・社会保険・社会福祉・介護・会員制団体も除いています（計画では「公務などの非市場」と書いていた）
- 石炭製品は前半の労働生産性の伸びが計算できず、伸びの比較は91部門です
- 問い直しの内容（偏相関・ICTの割合）は結果を見てから決めました

## 言えないこと
- 産業の単位の相関で、企業や働く人の話ではありません（同じ産業の中で、ICTを使う企業ほど生産性が高いかは分かりません）
- 相関は因果ではありません。生産性が高く利益の出る産業ほどICTに投資できる、という逆の向きもありえます
- 労働生産性の伸びには、成長会計の作り方上、ICT資本を積んだ分が含まれます。H2 が弱いながらプラスなのは、ある程度この作り方から来ます
- ICT資本はJIPの推計で、価格（品質の向上）の扱いで実質の量は変わります
- 白書の「デジタル化」には、クラウドの利用、テレワーク、データの活用、人材など、ICT資本では測れないものも含まれます。ここで見たのはその一部（ICT資本・投資）だけです
- 2020年までで、生成AIなど直近の動きは入っていません
