# F289 情報通信白書のデジタル化の指標は、生産性と結びついているか？

**問い。** 情報通信白書は、ICT投資やソフトウェアへの投資を「デジタル化」の指標として示し、生産性を上げる鍵として扱います。産業ごとに見て、ICT資本の多い産業・増やした産業ほど、生産性は高く、伸びたのか。企業の情報システム部門や経営企画、投資の判断をする人、白書を読み解く記者が知りたい問いです。

**答え（先にまとめ）。**
- ICT資本（情報機器・通信機器・ソフトウェア）の多い産業ほど、労働生産性の水準は高い。2015年の91産業で順位相関 **0.72**（95%区間 0.58〜0.82）
- ただし、ICT資本を増やした産業ほど労働生産性が伸びた、とは言いにくい。1995→2007年 **+0.18**、2007→2019年 **+0.07**（どちらも95%区間が0をまたぐ）
- 資本（ICTもそれ以外も）と労働の寄与を除いた生産性（TFP）の伸びとは、結びつきが見えなかった（1995→2007年 **−0.10**、2007→2019年 **−0.19**、95%区間 −0.39〜0.03）。TFPはICTの通常の見返りを差し引いた残りなので、これは「通常の見返りを超える上乗せ」があったかの確かめで、相関が0でもICTに効果がないとは言えない
- 白書がよく使う「ICT投資比率」が1995〜2007年に高かった産業が、2007→2019年に伸びたわけでもない（**+0.16**）
- 問い直し：水準の強い結びつきの多くは「資本全体が多い産業だから」。ICT以外の資本の多さをそろえると、ICTだけの結びつきは1995年 **0.00**（−0.25〜0.23）、2007年 **0.26**（0.00〜0.50）、2015年 **0.49**（0.25〜0.68）、2019年 **0.53**（0.31〜0.69）。91産業

## データ
- 経済産業研究所・一橋大学「JIPデータベース2023」（1994〜2020年、99部門）
  - `jip2023_2.xlsx`：資本（投資・資産マトリックス：部門×資産×年の名目・実質投資と純資本ストック）
  - `jip2023_4.xlsx`：成長会計（実質付加価値 V、名目付加価値 NV、付加価値ベースTFP成長率 TFPva、労働生産性上昇率 LP_G、集計部門の定義 DS）
  - `jip2023_3-8.xlsx`：部門別マンアワー（従業者数×年間総実労働時間÷1000）
- ICT資産＝3ba 情報機器＋3bb 通信機器＋6c コンピュータソフトウェア
- 使った部門：DS の「市場経済」（202）に入る92部門から、石炭製品（code 24）を除いた **91部門**。すべての比較で同じ91部門を使う。選び方は「1994〜2020年の全年で労働生産性が正の値で求まり、1995〜2019年の全年で TFPva がある」こと（`src/zz_f289_03_分析.py`）。石炭製品は付加価値が負の年が27年中18年、TFPva は2009〜2016年だけ。市場経済に入らない部門（住宅・公務・教育・医療・保健衛生・社会保険・社会福祉・介護・会員制団体）と分類不明は、はじめから除いている
- Excel は大きいのでリポジトリに入れていません（`.gitignore`）。`src/zz_f289_01_取得.py` が RIETI から取り直し、md5 を `data/MANIFEST.json` と照らします

## 手法
- 労働生産性＝実質付加価値（2015年連鎖価格）÷マンアワー（円／時間）
- ICT資本の深さ＝実質ICT純資本ストック（2015年価格）÷マンアワー（円／時間）
- 伸び＝期間の対数差÷年数（年率）。TFPの伸び＝TFPva の期間の年平均（期間内の全年に値があるときだけ）
- TFPva は付加価値の伸びから、資本（ICT・ICT以外）と労働（時間・質）の寄与を除いた残り。ICTの通常の見返りは資本の寄与に入っている
- ICT投資比率＝期間の名目ICT投資の合計÷名目投資の合計
- 産業の間の順位相関（スピアマン）。95%区間は産業を選び直すブートストラップ（1,000回、種289）
- 期間：前半 1995→2007年、後半 2007→2019年（2020年はコロナで外し、頑健性で入れた）

## 計画と結果（PLAN.md を先にコミット：0717448）
| 仮説 | 基準 | 結果 | 判定 |
|---|---|---|---|
| H1 水準 | 2015年の順位相関 ≥ 0.3 | 0.72（0.58〜0.82） | 支持 |
| H2 伸び | 前半・後半とも > 0 | +0.18（−0.05〜0.38）、+0.07（−0.14〜0.29） | 支持（基準の上では。ただし両方とも区間が0をまたぎ、弱い） |
| H3 TFP | 前半・後半とも絶対値 < 0.2 | −0.10（−0.29〜0.10）、−0.19（−0.39〜0.03、p=0.065） | 支持（後半は基準の境目に近い） |
| H4 白書の指標 | 前半のICT投資比率と後半の労働生産性の伸び < 0.2 | +0.16（−0.06〜0.34） | 支持（＝結びつきは弱い） |

すべて n=91。H3 の後半は −0.2 のすぐ内側で、向きはわずかにマイナスです。理由の候補は、ICT資本の品質調整による量の測り誤差（その分がTFPの側にずれて表れる）と、効果が出るまでの遅れや入れ替えの手間（Jカーブ）です（どちらも推測）。ICT資本が付加価値に占める取り分は小さいと考えられるので、こうした仕組みでTFPが動く大きさは限られます（推測）。

## 問い直し（結果を見た後に足した）
H1 の強い結びつきは、ICTだから高いのか、それとも資本全体が多い産業（設備の大きい産業）だから高いのか。ICT以外の資本の多さ（1時間あたり）をそろえた偏順位相関を見ました。どの年も91産業、95%区間は産業を選び直すブートストラップ（1,000回）。

| 年 | ICT資本と労働生産性 | ICT以外の資本と労働生産性 | ICT（ICT以外をそろえた偏相関、95%区間） | 資本に占めるICTの割合と労働生産性 |
|---|---|---|---|---|
| 1995 | 0.28 | 0.56 | 0.00（−0.25〜0.23） | −0.39 |
| 2007 | 0.55 | 0.71 | 0.26（0.00〜0.50） | −0.24 |
| 2015 | 0.72 | 0.81 | 0.49（0.25〜0.68） | −0.21 |
| 2019 | 0.73 | 0.80 | 0.53（0.31〜0.69） | −0.22 |

- 水準の結びつきの多くは資本全体の多さと重なります。ICTだけの分は、1995年には見えず、2015年・2019年は区間が0から離れています。強くなった理由は、このデータからは分かりません（ICTを生かす仕事のやり方が広がった、生産性の高い産業ほど投資できるようになった、などが考えられる：推測）
- 「資本の中のICTの割合」が高い産業ほど、労働生産性はむしろ低い（設備の小さいサービス業でICTの割合が高いため（推測））
- 割合を増やした産業ほど伸びたか：労働生産性 前半 +0.08、後半 −0.11、TFP 前半 −0.03、後半 −0.21

## 計画からのずれ
- PLAN を書く前に、ファイルの構成を確かめる途中で「部門別名目投資フロー」の農業・農業サービスの2行の値を目にしました（生産性の値は見ていません）
- 使った部門は「市場経済」の旗で決めたので、教育・医療・保健衛生・社会保険・社会福祉・介護・会員制団体も除いています（計画では「公務などの非市場」と書いていた）
- 石炭製品は、レビューの後、すべての比較から除きました（下の「レビューで直したこと」）。どの比較も同じ91部門です
- 計画では問い直しを1つとしていましたが、3つの分析（ICT以外の資本をそろえた偏相関、資本に占めるICTの割合と労働生産性、その割合の伸びと生産性の伸び）を足しました。どれも結果を見てから決めました

## 言えないこと
- 産業の単位の相関で、企業や働く人の話ではありません（同じ産業の中で、ICTを使う企業ほど生産性が高いかは分かりません）
- 相関は因果ではありません。生産性が高く利益の出る産業ほどICTに投資できる、という逆の向きもありえます
- 労働生産性の伸びには、成長会計の作り方上、ICT資本を積んだ分が含まれます。ただ、ICT資本が付加価値に占める取り分は小さいと考えられるので、その分の大きさは限られます（推測）
- TFP は資本（ICT・ICT以外）と労働の寄与を除いた残りで、ICTの通常の見返りはすでに差し引かれています。TFP との相関が0でも、ICTに効果がないとは言えません。マイナス寄りに出る理由の候補は、品質調整したICT資本の測り誤差と、効果の遅れ・入れ替えの手間（Jカーブ）です（推測）
- ICT資本はJIPの推計で、価格（品質の向上）の扱いで実質の量は変わります
- 白書の「デジタル化」には、クラウドの利用、テレワーク、データの活用、人材など、ICT資本では測れないものも含まれます。ここで見たのはその一部（ICT資本・投資）だけです
- 2020年までで、生成AIなど直近の動きは入っていません

## レビューで直したこと
独立レビュー（メインで実施）：数値はすべて一致、JIP の抜き出しは有効数字6桁で照合、流し直しはバイト単位で一致。指摘を受けて次を直しました。
- [高] 石炭製品（code 24）：付加価値が負の年が27年中18年、TFPva は2009〜2016年だけ。平均で欠けた年を飛ばしていたため、H3 後半と H4 の TFP 版にだけ入り（92部門）、労働生産性の比較（91部門）と組がずれていた。すべての比較を同じ91部門にそろえ、平均は期間の全年に値があるときだけにした。H3 後半は −0.22 → **−0.19**（p=0.065）、ピアソンは −0.37 → −0.22、H3 は **外れ → 支持**。H1 は 0.71 → 0.72、図・表も作り直した
- [高] 題名・まとめの「2007年以降はむしろ逆向き」は言い過ぎ（直す前でも区間の上端が 0.00）。「TFPの伸びとは結びつきが見えなかった」に改めた
- [中] TFP を「ICTの分を除いた生産性」と書いていたのを、「資本と労働の寄与を除いた生産性」に直し、通常の見返りを超える上乗せを見ていること（相関0≠効果なし）を足した
- [中] TFP がマイナス寄りに出る理由を「作り方から来る」としていたのを、測り誤差と Jカーブ（推測）に直し、ICT の取り分が小さく効き方は限られることを足した
- [中] 「H3 の後半はどの条件でもマイナス」は誤り（R3 の TFP はプラス）。順位相関の条件に絞って書き直し、R3 の TFP を載せた
- [中] 問い直しの偏相関に95%区間と n を足し、91部門にそろえた。強くなった理由の説明は（推測）とした
- [低] 白書の出典を令和元年版 第1部第1章第2節と明記し、言い回しを引用符から外した（note 本文）。計画1つ→3つの分析をずれに足した。R5 の H4（+0.05）を note 本文にも載せた
