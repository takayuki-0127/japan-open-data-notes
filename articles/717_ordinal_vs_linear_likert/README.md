# 717 5段階の評価を1〜5の数として回帰するのと、順序ロジットで見るのとでは、効果の向きや有意はどれだけ違うのか（手法の解説・正解の分かるデータで試す）

5段階の評価は、1〜5を数とみなして平均や回帰で比べることが多いですが、段の間隔が等しいとは限りません。順序ロジットは、目に見えない「満足の度合い」が区切りを超えたかで評価が決まると考え、段の間隔を数として扱いません。**ここでは、区切りが不ぞろいな5段階の評価（4と5が多い形）で、2つの案（各100人）を比べる場面を2つ作り、1〜5を数とした t 検定（線形回帰と同じ）・順序ロジット・上位2つの割合の3つで、有意になる割合と向きを各300回で数えました。** 数字は置いた前提で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A717 | 評価の見方で、有意の出方と向きはどれだけ違うか | 潜在変数（ロジスティック分布）と区切り（−2.5・−1.5・−0.5・0.5）で評価を作る。場面1：散らばりが同じで平均の差 d=0・0.25・0.5。場面2：案Bだけ散らばりが2.5倍（潜在の平均は A が0.3高い）。t 検定、順序ロジット（statsmodels OrderedModel）、上位2つの割合の z 検定。各300回。seed 717 | `src/a717_ordinal.py` |

## 主な結果
- **場面1（散らばりが同じ）**：効果0で5.0%・5.3%・5.0%（t 検定・順序ロジット・上位2つ）。d=0.25で15.0%・14.0%・11.7%、**d=0.5で45.3%・48.3%・37.3%**。数として扱っても順序ロジットとほぼ同じで、上位2つの割合は少し弱い
- **場面2（案Bは好き嫌いが分かれる）**：Bは1が26.9%（Aは5.8%）、5はどちらも約45%。有意になった割合は t 検定 **78.3%**、順序ロジット **46.3%**、上位2つ54.3%。向きはどれも「A が高い」で、逆向きの有意は0%
- 順序ロジットは「案で散らばりは変わらない」と置くモデルなので、散らばりが違う場面では当てはまりが悪く、有意になりにくかった
- この設定では、見方によって向きが逆になる例は出なかった

## 注意（言えないこと）
