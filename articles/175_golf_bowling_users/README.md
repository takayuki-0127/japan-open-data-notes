# 175 ゴルフ場やボウリング場の利用者は、長い目でどう減ったか：特定サービス産業動態統計調査

経済産業省「特定サービス産業動態統計調査」の長期データ（ゴルフ場・ゴルフ練習場・ボウリング場、2000〜2024年の年計）を使ったフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A175 | 利用者数は2000年からどれだけ減ったか。コロナ後は、それまでの傾向と比べてどこまで戻ったか | 調整済みの前年比をつないだ指数、減衰トレンドの指数平滑法（Holt、2000〜2019年で推定）による延長、利用者1人当たり売上の指数 | `src/a175_leisure.py` |

## 主な結果
- 利用者数の指数（2000年＝100）は、2024年にゴルフ場95、ゴルフ練習場80、ボウリング場34
- ボウリング場は2000〜2019年に年平均4.3%減り、2019年は43。コロナで2020年に26まで落ち、2024年は34（2019年比−21%）
- ただし2019年までの傾向をそのまま延ばした値（2024年29）と比べると、2024年の実際は1.16倍で、傾向より上にある
- ゴルフ場は2021年に急増し、2024年は2019年とほぼ同じ（+0.7%）。ゴルフ練習場は2021年に92まで上がったあと、80に戻った
- 利用者1人当たりの売上（指数の比）は、ゴルフ場が2000年から25%下がった一方、ボウリング場は2024年に2000年の水準に戻った

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a175_leisure.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/tokusabi_golf_bowling.csv | 年、施設（golf=ゴルフ場、golf_range=ゴルフ練習場、bowling=ボウリング場）、売上高（百万円）、利用者数（人）、売上高・利用者数の前年比（%、調査対象の追加などを調整した値） |

元の表：経済産業省「特定サービス産業動態統計調査」長期データ（https://www.meti.go.jp/statistics/tyo/tokusabido/result/result_1.html）の hv15101j.xls（ゴルフ場）、hv15201j.xls（ゴルフ練習場）、hv15301j.xls（ボウリング場）の「年・実数」「年・伸び率」シートから書き写した。

## 注意
- 調査対象の追加や見直しで、実数（水準）には何度も段差がある（ボウリング場は2011年と2015年に大きい）。そのため年ごとの比較は、公表の「調整済みの前年比」をつないだ指数で行った。実数どうしの比較（1人当たり売上の円）は目安
- 調査の対象は一定規模以上の事業所で、全国のすべての施設ではない
- 指数平滑法の延長は「2019年までの傾向が続いたら」という目安で、予測の精度を検証したものではない
