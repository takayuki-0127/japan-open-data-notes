# 1293 荷物の体積の合計を箱1つの容量で割って見込んだ箱の数は、1つずつ詰めていったときの本当の箱の数よりどれだけ少なく出るのか？（箱詰めと積載）

発送の準備で「今日の品物の体積を合わせると箱20.2個分だから、箱は21個」と見込むことがあります。けれども、品物を1つずつ詰めていくと、箱の中には「次の品物が入らない」すきまが残ります。すきまは箱ごとに積み重なるので、本当に使う箱の数は、体積の合計を容量で割った見込みより多くなります。どれだけ多くなるかは、品物の大きさが箱に比べてどれくらいか、そして入らなかったときに箱を閉じてしまうか、まだすきまのある箱に戻して入れるかで変わります。**ここでは、作成者が置いた架空の通販の箱詰め（その日の品物の体積の合計が平均で箱20個分、品物1つの大きさは平均で箱の10%、大きさの散らばりを作成者が置いて乱数で作ったもの）で、「体積の合計÷容量の切り上げ」の見込みと、①入らなければ箱を閉じる、②入る箱に戻して入れる、の2つの詰め方の本当の箱の数を2,000日分比べました。品物の大きさの平均5通り×散らばり3通りの15通りで確かめました。**

すべて作成者が置いた決まりでのシミュレーションです。形は気にせず、体積だけで入るかどうかを決めています。実在の通販・箱・配送の数字を表すものではありません。

## 主な結果

### 基本の置き方（品物200個・大きさの平均は箱の10%、2,000日、`results/a1293_main.json` の `base`）
| | 見込み（体積の合計の切り上げ） | ① 入らなければ閉じる | ② 入る箱に戻して入れる |
|---|---|---|---|
| 箱の数の平均 | 20.4955個 | **21.9855個** | 20.6895個 |
| 本当−見込み（平均） | − | **+1.49個** | +0.194個 |
| 見込みが本当より少ない割合 | − | **6.715%** | 0.9201% |
| 見込みどおりの箱の数で済んだ日 | − | **0.75%** | 80.6% |
| 積載率（体積の合計÷箱の数、日ごとの平均） | − | 91.0402% | 96.6983% |

| 本当−見込み（`results/base_extra_dist.csv`） | 0個 | 1個 | 2個 | 3個 | 4個 |
|---|---|---|---|---|---|
| ① 入らなければ閉じる | 0.75% | 51.65% | 45.5% | 2.05% | 0.05% |
| ② 入る箱に戻して入れる | 80.6% | 19.4% | 0.0% | 0.0% | 0.0% |

- **①では、見込みは本当の箱の数より平均で6.715%（1.49個）少なかった**。見込みどおりの数で済んだ日は2,000日のうち0.75%で、45.5%の日は2個多かった
- ①で閉じた箱に残ったすきまは、1箱あたり平均0.072（箱の容量を1とした大きさ。真ん中は0.0533）で、1日の合計は平均1.5118箱分だった。この合計が、見込みより多かった1.49個とほぼ同じ大きさだった
- ②では、あとから来た小さな品物がすきまに入るので、見込みは本当より0.9201%（0.194個）少ないだけで、80.6%の日は見込みどおりの数で済んだ

### 確かめ：品物の大きさの平均×散らばりの15通り（各400日、`results/grid.csv`）
| 大きさの平均（箱に対する割合） | 散らばり | ① 見込みが少ない割合 | ② 見込みが少ない割合 | ①で閉じた箱のすきま（1箱あたり） |
|---|---|---|---|---|
| 2% | 0.3 / 0.6 / 1.0 | 1.76% / 1.45% / 2.47% | 0.57% / 0.15% / 0.04% | 0.0109 / 0.0145 / 0.0269 |
| 5% | 0.3 / 0.6 / 1.0 | 2.49% / 3.49% / 5.9% | 0.89% / 0.48% / 0.05% | 0.0271 / 0.0361 / 0.0651 |
| 10% | 0.3 / 0.6 / 1.0 | 5.17% / 6.54% / 9.99% | 1.84% / 0.76% / 0.52% | 0.0547 / 0.071 / 0.1102 |
| 20% | 0.3 / 0.6 / 1.0 | 10.11% / 12.99% / 14.86% | 3.83% / 2.36% / 1.5% | 0.1096 / 0.1395 / 0.1617 |
| 30% | 0.3 / 0.6 / 1.0 | 15.28% / 17.63% / 17.59% | 6.44% / 4.17% / 2.73% | 0.1642 / 0.19 / 0.1921 |

- **15通りすべてで、見込みは本当の箱の数より少なかった**（見込みは切り上げなので、本当の箱の数を超えることは作りの上でない）。①では1.45〜17.63%、②では0.04〜6.44%少なかった
- **品物が箱に比べて大きいほど、見込みの足りなさは大きかった**。①では、大きさの平均が箱の2%なら1.45〜2.47%、30%なら15.28〜17.63%少なかった
- 散らばりの効き方は2つの詰め方で逆だった。①では散らばりが大きいほど足りなさが大きく（大きな品物が来るたびに箱を閉じるため）、②では散らばりが大きいほど足りなさが小さかった（小さな品物がすきまを埋めるため）
- 大きさの平均30%・散らばり1.0では、箱より大きい品物を引き直したため、大きさの平均は0.2384になった（`grid.csv` の item_mean_actual）

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp）
- 2,000日すべてで、①と②の箱の数が見込み以上であることを確かめた（`data/days_base.csv`。見込みは本当の箱の数の下限なので作りどおり）
- ①で閉じた箱のすきまの1日の合計（平均1.5118箱分）が、見込みより多かった箱の数（平均1.49個）とほぼ同じことを確かめた
- 図3枚を開き、日本語・重なり・軸（棒グラフの軸は0から）を確かめた

## データ
- `data/days_base.csv`：基本の置き方の2,000日（items は品物の数、volume_sum は体積の合計（箱の個数分）、estimate_boxes は見込み、boxes_close は①の箱の数、boxes_any は②の箱の数、gap_sum_closed は①で閉じた箱のすきまの合計）
- `results/a1293_main.json`：主な結果（`base`・`base_settings`・`grid_range`）
- `results/base_extra_dist.csv`：基本の置き方の「本当−見込み」の日の割合
- `results/grid.csv`：確かめの15通り（est_short_*_pct は見込みが少ない割合、fill_*_pct は積載率、share_days_*_eq_est は見込みどおりで済んだ日の割合、gap_close_mean は①で閉じた箱のすきまの1箱あたりの平均、gap_sum_closed_mean はその1日の合計）

## 注意（言えないこと）
- 架空のデータです。品物の大きさの分布、その日の品物の数、詰め方は作成者が置いたもので、見込みの足りなさはこれで決まります
- 形は気にせず、体積だけで入るかどうかを決めました。縦・横・高さの形で入らない場合や、品物を重ねられない場合は入れていません。これらがあると、本当の箱の数はさらに多くなる向きです（推測。数えていない）
- ②は、開けた箱をいくつでも開けたままにしておけると置きました。置き場所の都合で開けておける箱の数に限りがあると、①に近づく向きです（推測。数えていない）
- 箱は1種類だけと置きました。大きさの違う箱を使い分ける場合は扱っていません
- 送料・料金の見込みや、どの箱を使うべきかの助言をする記事ではありません
