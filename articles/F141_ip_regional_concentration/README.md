# F141 特許の出願は、どの分野で地方に広がったのか？ — 集中度の指標（HHI・立地係数）と時系列

## 問い
特許・実用新案・意匠・商標の出願は、2007年からの18年で東京や三大都市圏から地方へ広がったのか。広がったなら、どの権利（分野）でか。

## データ
- 特許庁「特許行政年次報告書」2010・2013・2016・2019・2022・2025年版の、次の都道府県別の表（日本人によるもの）。
  - 都道府県別出願件数表：特許・実用新案・意匠・商標
  - 都道府県別登録件数表：特許
  - 都道府県別発明者、考案者、創作者数表：特許（発明者数）
- 各版の3年分をつないで、2007〜2024年の18年 × 47都道府県 × 6系列（`data/pref_ip_long.csv`、5,076行）。
- 出願件数は出願人の住所、発明者数は発明者の住所で都道府県に分けたもの。都道府県が特定できない「その他」は除き、47都道府県の合計を分母にした。
- 2019年版より前の版は、特許庁サイトがアクセス集中の確認画面を出したため、Internet Archive の保存版から取った（`src/01_取得.md`）。

## 手法
- 集中度の指標（系列 × 年）：東京都の割合、三大都市圏（11都府県）の割合、「地方」（それ以外の36道県）の割合、上位5都府県以外の割合、HHI、東京を除く46道府県の HHI、ジニ係数。
- 時系列の傾き：年に対する OLS の傾き（10年あたり）、95%区間は HAC（ラグ2）。期間の比較は 2007–09年平均と 2022–24年平均。
- 特化係数（立地係数）：4つの権利の出願の合計を基準に、都道府県 × 権利で計算。
- 4つの権利を合わせた地方の割合の変化を、「権利ごとの地方割合の変化」と「権利の構成の変化」に分けた（シフトシェア、両期間の平均を重みにした対称な式）。
- 地方ブロック別（9区分、東京都は別立て）の割合の変化。

## 結果
| 系列 | 地方の割合 2007–09 → 2022–24 | 10年あたりの傾き（95%区間） | 東京都の割合 2007–09 → 2022–24 |
|---|---|---|---|
| 特許出願 | 10.2% → 9.9% | +0.26pt（−0.46〜+0.99） | 51.6% → 52.9%（2024年は55.3%） |
| 特許登録 | 10.2% → 11.2% | +0.97pt（+0.56〜+1.39） | 52.3% → 51.0% |
| 特許の発明者数 | 21.8% → 16.7% | −3.46pt（−3.83〜−3.08） | 33.2% → 41.2% |
| 意匠出願 | 17.4% → 19.4% | +1.51pt（+1.07〜+1.96） | 35.2% → 36.6% |
| 商標出願 | 20.9% → 21.8% | −0.29pt（−2.08〜+1.50） | 46.2% → 45.0% |
| 実用新案出願 | 33.6% → 31.7% | −1.18pt（−2.08〜−0.29） | 25.2% → 26.0% |

- 特許出願の「地方」の割合は18年間ほぼ1割のままで、はっきりした傾きはない。2019〜2020年の11.3%が高く、2024年は9.3%。2023〜24年は東京都の割合が上がった。
- 地方の割合がはっきり上がったのは意匠だけ（+1.5pt/10年）。特許登録も小さく上がった（+1.0pt/10年）。
- 発明者の住所で数えると、東京都の割合は 33.2%→41.2% に上がり、地方は 21.8%→16.7% に下がった。東京以外の関東（−5.6pt）から東京都（+7.9pt）への移り方が大きい。
- 4つの権利を合わせた地方の割合は 13.4%→14.5%（+1.07pt）。そのうち +0.87pt は、地方の割合が高い商標の比重が 22%→32% に増えた「構成の変化」で、権利ごとの地方割合の変化は +0.20pt だった。
- 特化係数が1を超える地方の県の数は、特許 2→3、意匠 22→20、商標 34→33、実用新案 36→35 で、ほとんど変わらない。
- 地方ブロック別では、特許出願は近畿 −2.5pt・中部 +2.0pt・東京都 +1.3pt で、三大都市圏の中での入れ替わりが中心だった。
- 出願の総数は、特許 33.3万件（2007年）→23.7万件（2024年）、商標 11.8万件→11.6万件。

## 頑健性
1. 指標を変える：上位5都府県以外の割合、東京を除く HHI、ジニ係数でも、特許出願は「はっきりした変化なし」、意匠は「分散」、発明者数は「集中」で同じ向き（`results/trend_table.csv`、図5）。
2. 期間を変える：2020〜21年を除いても傾きはほぼ同じ。単年の比較（2007年→2024年）では特許出願の地方割合は −1.0pt と、3年平均より下がり方が大きい。
3. 数え方を変える：出願（出願人の住所）・登録・発明者（発明者の住所）で結果が分かれる。特許は出願と登録で地方の割合はほぼ同じ水準だが、発明者で数えると東京への集中が強まる。
4. 版のつなぎ目：版が変わる年の東京都の割合の段差（平均の絶対値）は、ほかの年の変化より大きくない（`results/edition_break_check.csv`）。

## 言えないこと
- 技術分野（IPC など）× 都道府県の表は公表されていないため、「分野」は特許・実用新案・意匠・商標の4つの権利で代わりにした。特許の中のどの技術で地方に広がったかは、このデータでは分からない。
- 出願人の住所は本社の住所であることが多く、研究開発がどこで行われたかとは一致しない（推測）。発明者の住所も勤務先の住所で書かれることがあるとみられ、2020年代の東京都の割合の上昇が、研究の場所の移動なのか、書き方の変化なのかは区別できない（推測）。
- 地方の割合が変わらないことは、地方の出願が増えていないという意味ではない（総数は減っている）。
- 人口や事業所数で割った指標は使っていない。
- 時系列の区間は18年分の年次データによるもので、47都道府県を独立な標本とみなしたものではない。
