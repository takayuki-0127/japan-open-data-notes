# 01_取得（手順）

特許庁のサイトはブラウザ以外からの取得を受け付けないため、ブラウザの開発者ツール（JavaScript）で CSV を取得し、1つの JSON（`data/raw/jpo_nenji_pref_tables.json`）にまとめた。

| 版 | 対象年 | 取得元 |
|---|---|---|
| 2025年版 | 2022〜2024 | https://www.jpo.go.jp/resources/report/nenji/2025/ の「都道府県別出願件数表」（1）〜（4）、「都道府県別登録件数表」（1）、「都道府県別発明者、考案者、創作者数表」（1） |
| 2022年版 | 2019〜2021 | https://www.jpo.go.jp/resources/report/nenji/2022/ の同じ表 |
| 2019年版 | 2016〜2018 | 同じ表（特許庁サイトがアクセス集中の確認画面を出したため、Internet Archive の保存版から取得） |
| 2016年版 | 2013〜2015 | 同上（Internet Archive） |
| 2013年版 | 2010〜2012 | 旧サイト nenpou2013/toukei/2-14-1〜4, 2-15-1, 2-16-1（Internet Archive） |
| 2010年版 | 2007〜2009 | 旧サイト nenpou2010/toukei/2-15-1〜4, 2-16-1, 2-17-1（Internet Archive） |

JSON の形：`{版: {app: [特許, 実用新案, 意匠, 商標], reg: [特許], inv: [特許の発明者数]}}`。各要素は `{fn: ファイル名, s: HTTPステータス, t: CSV本文}`。
