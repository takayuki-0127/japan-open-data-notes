# 908 「n人中x人」を割合だけで書くと、何が消えるのか？（割合とパーセント）

「試食した人のうち60%が買った」と書くと、それが5人中3人なのか、500人中300人なのかが消えます。割合だけを並べた表では、人数の少ない店の「0%」「50%」「100%」と、人数の多い店の「31%」が同じ重さで並びます。**ここでは、作成者が乱数で作った架空の店300店（店ごとに「試食した人のうち買う本当の割合」と試食した人数を作成者が置いたもの）で、表示の%だけからは人数がどこまで戻せるか、同じ表示の%でも本当の割合がどれだけ散らばるか、表示の差で2店を比べたときに向きがどれだけ逆になるか、人数が書いてあれば何ができるかを数えました。**

人数が少ないほど見かけの割合が振れること自体は、二項分布（買うか買わないかを人数分くり返したときの数え方）の式で決まります。この記事で数えたのは、人数を書かずに割合だけを並べたとき、その振れが読み手からどれだけ見えなくなるかです。

## 主な結果

### 表示の%だけから、人数は戻せるか（算数で決まる）
| 表示 | その表示になりうる最小の人数 | 1〜100人のうち、ありうる人数の数 |
|---|---|---|
| 0%・100% | 1人 | 100通り |
| 50% | 2人 | 50通り |
| 33%・67% | 3人 | 61通り・59通り |
| 25%・75% | 4人 | 50通り |
| 20%・40%・60%・80% | 5人 | 52通り |
| 31% | 13人 | 50通り |
| 47% | 15人 | 50通り |
| 1%・99% | 67人 | 34通り |

- 0〜100%の101通りの表示のうち11通りは、5人以下でも出せる表示だった。どの表示も、1〜100人のうち34通り以上の人数でありうる。表示の%からは、人数はほぼ戻せない
- 最小の人数がいちばん多いのは1%と99%の67人で、それ以外の表示はすべて41人以下でも出せた（`results/shown_pct_possible_n.csv`）

### 人数の層ごとの、表示と本当の割合（基本の置き方、6万店）
| 試食した人数 | 店 | 表示と本当のずれ（平均） | 10ポイント以上ずれた店 | 0%か100%と表示 | 表示55〜65%の店の本当の割合（10〜90%） |
|---|---|---|---|---|---|
| 2〜9人 | 15,092 | 18.23ポイント | **67.7%** | 29.0% | **26.0〜48.6%**（中央値37.0%） |
| 10〜29人 | 10,927 | 8.69ポイント | 35.1% | 1.9% | 31.3〜54.3%（42.5%） |
| 30〜99人 | 11,746 | 4.88ポイント | 10.6% | 0.05% | 42.5〜59.0%（49.5%） |
| 100〜299人 | 10,689 | 2.72ポイント | 0.6% | 0% | 48.9〜61.1%（54.7%） |
| 300〜1,000人 | 11,546 | 1.56ポイント | 0% | 0% | **53.0〜61.3%**（56.6%） |

- 同じ「60%前後」の表示でも、2〜9人の店の本当の割合は26.0〜48.6%に散らばり、中央値は37.0%だった。300人以上の店では53.0〜61.3%に収まった
- どの層でも、表示が60%前後の店の本当の割合は60%より低めだった。本当の割合の平均を30%と置いたので、60%前後の表示はたまたま上に振れた店が多いため（置いた分布からの説明）

### 「きりのよい」表示は、人数の少ない店に集まる
| 表示 | 店 | そのうち10人以下の店 |
|---|---|---|
| 0% | 4,212 | 96.1% |
| 33% | 3,614 | 55.5% |
| 50% | 2,566 | 79.9% |
| 67% | 828 | 92.4% |
| 100% | 381 | **100%** |
| 全体 | 60,000 | 26.8% |

- 表示の%で並べた上位10店は、試食した人数の中央値が4人で、本当の上位10店に入っていたのは平均2.03店だった

### 表示の差が20ポイント以上ある2店で、本当は向きが逆だった割合
| 2店の人数 | 組 | 本当は逆 |
|---|---|---|
| どちらも10人未満 | 116,559 | **30.8%** |
| どちらも10〜99人 | 59,753 | 6.2% |
| どちらも100人以上 | 36,635 | 0% |
| 人数を問わない | 72,680 | 16.6% |

（組の数は、行ごとの条件に合う店から2店ずつ20万組を抜き出し、そのうち表示の差が20ポイント以上だった組。行ごとに別に抜き出したので、足しても全体にはならない）

### 人数が書いてあれば：ウィルソンの95%区間
| 試食した人数 | 区間が本当の割合を含んだ割合 | 区間の幅（中央値） |
|---|---|---|
| 2〜9人 | 96.0% | 59.1ポイント |
| 10〜29人 | 95.6% | 38.4ポイント |
| 30〜99人 | 94.8% | 22.7ポイント |
| 100〜299人 | 95.3% | 13.1ポイント |
| 300〜1,000人 | 95.3% | 7.4ポイント |

- 区間が本当の割合を含んだ割合は、どの層でも95%前後だった（式どおり）
- 区間の下限で並べた上位10店は、人数の中央値が222人で、本当の上位10店に入っていたのは平均4.76店だった（表示の%で並べると2.03店）。人数を書いておけば、こうした並べ方ができる

### 確かめ：本当の割合の平均×店どうしの差×人数の幅（27通り）
- 10人未満の店で10ポイント以上ずれた割合は、人数の幅が基本（2〜1,000人）の9通りで19.3〜68.0%
- 表示の差20ポイント以上の10人未満どうしの組で、本当は逆だった割合は2.0〜40.9%（人数の幅に10人未満を含む18通り）。店どうしの差を大きく置くほど、逆は減った
- 表示の%で並べた上位10店の当たりは0.73〜9.11店、区間の下限で並べると2.30〜8.80店。区間の下限のほうが多く当てたのは27通り中21通りで、残りの6通りは、店どうしの差を大きく置いた（標準偏差20ポイント）か人数が20人以上の置き方だった（`pct_ge_wilson_cases` に一覧）
- ウィルソンの区間が本当の割合を含んだ割合は、27通りで94.9〜96.9%

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約3秒）
- 表示になりうる人数の表は、x を0〜n まで動かして四捨五入した%を全部書き出して数えた（乱数を使わない算数）
- ウィルソンの区間が本当の割合を含む割合が、どの層・どの置き方でも95%前後になることを確かめた（作りの確かめ。式どおり）
- 人数が少ない店ほど表示が振れること、「0%」「100%」が人数の少ない店に集まることは、二項分布の式から決まる結果で、データから見つけたものではない。数えたのは、その振れが割合だけの表でどれだけ見えなくなるかの大きさ

## 注意（言えないこと）
- 架空のデータです。本当の割合の分布、店どうしの差、人数の分布は作成者が置いたもので、結果はこれで決まります。実在の店の数字を表すものではありません
- 買う人は、試食した人ごとにでたらめに決まると置きました。同じ日に来たまとまりの客がそろって買うような偏りは入れていません。入れれば、人数の多い店でも振れは大きくなります
- ウィルソンの区間は、人数が書いてあるときの読み方の例として使いました。どの区間の出し方がよいかは扱いません
- 割合を「〜%（n=…）」の形で書くか、「n人中x人」と書くかといった書き方の決まりは扱いません
- 関連する記事として、口コミの件数が少ない店ほど星の平均が振れる 801、回答の少ない層の割合が何件で読めるかを扱った 865、応募の採用率が何件で読めるかを扱った 889 があります。同じ企画では、小さい数からの「300%増」を 903、割合の平均と合計で出した割合の違いを 900 で扱っています（割合だけの表からは、人数で重みを付けた合計の割合も出せません）。この記事は、人数を書かずに割合だけを並べたときに何が読めなくなるかに絞りました
- 既存の記事 458 は、件数が少ないときに割合の95%の幅（ウィルソンなど）が正解を何%含むかを、590 は分母の小さい店が上位と下位に集まることを扱っています。この記事は、人数を書かずに割合だけを並べたときに読めなくなるもの（人数・確かさ・比べた向き）に絞りました
