# F238 前の期間のデータを使うと、テストはどれだけ早く終わるか（CUPED）

シリーズ「実務に近い分析」（F231〜F245）の8本目。A/B テストの結果を「テストの前の期間の値」で調整（CUPED・回帰調整・層別）すると、推定のばらつきがどれだけ減り、テストが何日短くなるかを確かめた。人数の決め方は F236、途中で結果を見る問題は F237 で扱っている。

- 市区町村の模擬テスト：公開データ（SSDSE）の「前の値」と「今の値」を使い、市区町村をランダムに2群に分けて、人工の効果を足した
- ユーザー単位：架空のサービスのシミュレーション（実在のサイトのデータではない）

## 問い

- 前の期間の値で調整すると、同じ精度に必要な人数（数）はどれだけ減るのか
- 減り方は、指標の種類（よく繰り返す行動／まれな購入の金額）や、前の期間の長さでどう変わるのか
- 新規ユーザー（前の期間のデータがない人）が多いと、どうなるのか
- 何を共変量にしてはいけないのか

## データ

| データ | 中身 | 使い方 |
|---|---|---|
| 統計センター「SSDSE-A」2026年版・2021年版（F196 の `data/frame.csv` を使い回し） | 1,729市区町村の出生数・人口・従業者数・高齢化率など。2026年版を「今の値」、2021年版を「前の値」とした | 市区町村を単位にした模擬テスト。前回の人口が0の町と、避難指示区域が設定された福島県の12市町村を除く（F180・F197 と同じ）。除かない場合は頑健性で確かめた |
| シミュレーション（架空のサービス） | 1人ごとの「使いやすさ」をガンマ分布、週ごとの回数をポアソン分布、1回の購入金額を対数正規分布（平均約5,000円）で引く。値はすべて置いた値 | 3つの指標：よく来る人の訪問回数（週平均約3回）、まれな購入の回数と金額（2週間で購入する人は約7%）。テストの期間は2週間 |

新しいデータの取得はしていない。

## 手法

- **素の差**：2群の平均の差
- **差の差**：y −（前の値）の平均の差（前の値の係数を1に決め打ち）
- **CUPED**：y − θ（x − x̄）、θ ＝ cov(y, x) / var(x) を両群まとめて推定（Deng ほか 2013）
- **回帰調整（群ごと）**：群ごとに傾きを推定して、x̄ の位置で比べる（Lin 2013 と同じ点推定）
- **層別**：前の値の5分位で層に分け、層ごとの差を重みづけ（事後層化）
- 市区町村：ランダムな割り当てを4,000回（効果なし）くり返し、推定のばらつき（分散の比）と、有意になった割合（第1種の誤り）を数えた。検出力は、素の差で検出力80%になる大きさの効果と、その半分の効果で各1,000回
- ユーザー単位：40万人の母集団で前の期間（1〜26週）とテスト2週間の相関 ρ を出し、必要な人数の比（≒1−ρ²）を計算。1群3,000人のテストを2,000回くり返して第1種の誤りと検出力を確かめた
- **SQL**：CUPED を SQL Server 互換の書き方で書き（`src/04_CUPED.sql`）、DuckDB で流して Python と照合
- **計算ツール**：`dashboard/index.html`（1日の訪問者数・指標の平均と変動係数・見つけたい差・ρ・前の期間のデータがある人の割合 → 必要日数）

## 結果

### 1. 市区町村の模擬テスト（1,729市区町村、4,000回）

推定の分散（素の差＝1。同じ精度に必要な数の比と同じ）：

| 指標（前の値との相関） | 差の差 | CUPED | 回帰調整 | 5分位で層別 |
|---|---|---|---|---|
| 出生率（ρ=0.83） | 0.41 | 0.32 | 0.32 | 0.36 |
| 従業者数÷人口・対数（ρ=0.97） | 0.057 | 0.055 | 0.055 | 0.34 |
| 高齢化率（ρ=0.98） | 0.040 | 0.035 | 0.035 | 0.12 |
| 出生数（ρ=0.999） | 0.027 | 0.002 | 0.002 | 0.74 |

- CUPED の分散の比は、どの指標でもほぼ 1−ρ²（出生率 0.305 に対して 0.316）
- 差の差（前の値をそのまま引く）は、ρ が1に近く前後の水準がそろうときは CUPED に近いが、出生数のように5年で水準が変わると CUPED の10倍以上のばらつき
- 5分位の層別は、ρ が高いほど CUPED に負ける（出生数 0.74）
- 効果がないときに有意になった割合は 4.6〜5.3%（回帰調整の出生数だけ 6.4%）
- 素の差で検出力80%になる効果の半分の大きさでは、検出力は素の差 28〜31%、CUPED 66%（出生率）〜100%

### 2. ユーザー単位：指標と前の期間の長さ（架空のサービス）

テスト2週間の値と前の期間の値の相関 ρ（必要な人数の比）：

| 指標 | 前1週 | 前4週 | 前13週 | 前26週 |
|---|---|---|---|---|
| よく来る：訪問回数 | 0.73（0.47） | 0.84（0.29） | 0.88（0.23） | 0.89（0.21） |
| まれに買う：購入回数 | 0.14（0.98） | 0.25（0.94） | 0.34（0.88） | 0.38（0.85） |
| まれに買う：購入金額 | 0.08（0.99） | 0.13（0.98） | 0.20（0.96） | 0.24（0.94） |

- 前の期間を長くすると相関は上がるが、訪問回数は4週を超えるとほぼ頭打ち
- まれな購入の金額では、前の期間の金額で調整してもほとんど縮まない。前の回数も足すと 0.96、**上位1%を切る（ウィンザー化）と 0.44**、ウィンザー化＋CUPED で 0.42

### 3. 新規ユーザーの割合（訪問回数、前4週）

前の期間のデータがない人の割合が 0・20・40・60・80% のとき、必要な人数の比は 0.29・0.43・0.58・0.72・0.86。近似式 1 −（データがある人の割合）×ρ² とほぼ一致した。

### 4. 日数の例（1日の訪問者 5,000人、両側5%・検出力80%）

| 指標と見つけたい差 | 素の差 | CUPED（前4週） | CUPED（前13週） | ウィンザー化＋CUPED |
|---|---|---|---|---|
| 訪問回数 +2% | 14日 | 4日 | 3日 | — |
| 訪問回数 +5% | 3日 | 1日 | 1日 | — |
| 購入金額 +5% | 76日 | 75日 | 73日 | 33日 |
| 購入金額 +10% | 19日 | 19日 | 19日 | 9日 |

### 5. 有限の標本での確かめ（訪問回数、1群3,000人、2,000回）

- 効果がないとき有意になった割合：素の差 4.8%、CUPED 4.6%、差の差 5.7%
- 効果 +3% の検出力：素の差 24%、CUPED 65%、差の差 22%
- θ をテストの前の2つの期間だけで決めても（0.444）、テストのデータで決めても（0.454）、分散の比は 0.285 と 0.284 で同じ
- 1回分のデータ（`data/sim_users.csv.gz`、本当の差は約 +0.18回）：素の差 +0.29（z=1.95）、CUPED +0.18（z=2.31）

### 6. 落とし穴：テスト中に測った値で調整する（800回）

新しい画面が訪問回数を増やし、それを通じて購入金額も増える、と置いた。テストの前4週の金額で調整した CUPED は本当の効果の 1.01倍（平均）だったが、**テスト中の訪問回数**で調整すると 0.41倍で、効果の約6割が消えた。共変量は、テストの影響を受けない「割り当ての前」の値に限る。

### 7. SQL の検算

`src/04_CUPED.sql`（SQL Server 互換）を DuckDB で流し、素の差と CUPED の推定・標準誤差が Python と一致（差の最大 6×10⁻¹⁶）。

## 頑健性

- **外れ値のある市区町村を入れる**（避難指示区域の12市町村、前の値の出生率が最大634）：出生率の ρ は 0.21 に落ち、CUPED の分散の比は 0.96。差の差は 114倍に悪化し、群ごとの回帰調整は第1種の誤りが 52% になった。5分位の層別は 0.37 で外れ値に強かった
- **対数をとらない従業者比**（千代田区などの極端な値を含む）：素の差の第1種の誤りが 0.6% と小さすぎ、群ごとの回帰調整は 11%。CUPED は 4.3%
- **θ の決め方**（テストの前のデータだけ／テストのデータ）：同じ
- **指標の種類と前の期間の長さ**（3指標×6通り）、**新規ユーザーの割合**（5通り）、**ウィンザー化との組み合わせ**
- **有限の標本**での第1種の誤り・検出力のシミュレーション

## 言えないこと

- ユーザー単位の数字は、置いた分布（ガンマ・ポアソン・対数正規）での結果。実際のサービスの ρ は、まず過去のデータで測る必要がある
- 市区町村の「前の値」は SSDSE の版の違い（約5年前の調査）で、テストの直前の値ではない。地域を単位にしたテストの練習として使った
- 効果は人工的に足したもので、実際の施策の効果ではない
- 共変量は1つ（と回数）だけ。機械学習で予測した値を共変量にする方法（CUPAC など）は比べていない
- 途中で結果を見る運用との組み合わせ（F237）は扱っていない
