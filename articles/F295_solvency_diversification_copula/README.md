# F295 リスクを分けて計る（ソルベンシー）と、分散効果はどれだけ効くのか？（精選）

**すべて架空の会社・例示の値によるシミュレーションです。実在の会社・規制の数値ではありません。投資や保険の購入の助言はしません。**

## 問い
保険会社の資本（ソルベンシー）の計算では、リスクを「自然災害」「死亡」「市場」「オペレーショナル」などに分けて計り、相関の表で足し合わせます。こうすると、単独の必要資本の合計より小さくなります（分散効果）。
では、リスクどうしが「ふだんは弱くしか連動しないが、大きく崩れるときは一緒に崩れる（裾の依存）」場合、相関の表で計った分散効果はどれだけ残るのか。資本やリスク管理の担当、保険数理の担当、ESR などの数字を読む人が気にする点です。

事前登録：[PLAN.md](PLAN.md)（コミット 8d2d3bf、結果を計算する前）。

## 設定
- 架空の保険会社の1年の損失を4つのリスクで作る（単位：億円）。
  - 自然災害：件数 Poisson(2)、1件 10＋GPD（ξ=0.5、σ=10）の合計（ξ は F260・F288 の議論を参考にした例示の値）
  - 死亡：対数正規（σ=0.35）の上振れ
  - 市場：自由度4の t 分布
  - オペレーショナル：件数 Poisson(0.5)、1件 対数正規（σ=1.5）の合計
  - 4つとも単独の必要資本（VaR99.5 − 平均）が 100 になるよう尺度をそろえた（200万年の経験分布）。裾の形はそろっていない（図1）。
- 依存の形（周辺分布は同じ、つなぎ方だけ変える）：独立／ガウスコピュラ（すべての組で ρ=0.25）／t コピュラ（同じ ρ、自由度4）／グンベル／裏返したクレイトン（どちらもケンドールのτをガウスと同じ 0.161 に合わせた）／完全に一緒（共単調）。
- 分散効果 ＝ 1 − まとめた必要資本 ÷ 単独の必要資本の合計。必要資本 ＝ VaR99.5 − 平均（TVaR99.5 でも計る）。
- 相関の表の式：sqrt(s' R s)。s がすべて 100、ρ=0.25 なら分散効果 33.9%。
- 各設定 100万年（20万年×5ブロック、ブロックの散らばりで誤差を計る）。

## 結果（ρ=0.25、100万年）

| 依存の形 | 分散効果 VaR99.5 | 分散効果 TVaR99.5 | まとめた必要資本（VaR） | 2つのリスクが同時に上位0.5%に入る割合（÷0.5%） |
|---|---|---|---|---|
| 独立 | 54.9%（±0.1） | 53.4% | 180 | 0.5% |
| ガウス | 41.5%（±0.2） | 43.8% | 234 | 2.3% |
| t（自由度4） | 33.6%（±0.2） | 32.0% | 265 | 16.8% |
| グンベル | 26.5%（±0.2） | 24.2% | 292 | 22.6% |
| 裏返しクレイトン | 26.3%（±0.2） | 25.2% | 294 | 20.4% |
| 完全に一緒 | 0.0% | 0.0% | 400 | 100% |
| 相関の表の式 | 33.9% | 33.3% | 265 | — |

| 仮説 | 結果 | 判定 |
|---|---|---|
| H1 ガウスの分散効果は式と ±5pt 以内 | 41.5% 対 33.9%（+7.6pt）。シード5通りで 41.2〜42.0%、ρ=0.10 で +6.7pt、ρ=0.50 で +7.2pt | **外れ**（式のほうが分散効果を小さく見る） |
| H2 t はガウスより相対で 1/3 以上小さい | (41.5−33.6)/41.5 ＝ 19%（自由度3でも22%） | **外れ** |
| H3 グンベル・裏返しクレイトンはガウスより小さい | 26.5%・26.3% 対 41.5% | 支持 |
| H4 TVaR だとガウスと t の差が大きい | VaR 7.9pt → TVaR 11.8pt | 支持 |
| H5 自然災害の ξ を上げると、独立の分散効果は小さい | ξ 0.3→0.7 で VaR 56.2→53.5%、TVaR 56.6→44.2% | 支持（VaR では小さく、TVaR で大きい） |

## 頑健性（results/B_robustness.csv）
- R1 シード5通り・20万年：ガウス 41.2〜42.0%、t 33.5〜34.3%、グンベル 25.9〜27.4%。順番は同じ。
- R2 ρ=0.10：ガウス 49.7%、t 41.1%、グンベル 41.1%、裏返しクレイトン 42.1%、式 43.0%。ρ=0.50：ガウス 28.1%、t 22.0%、グンベル 12.1%、裏返しクレイトン 8.7%、式 20.9%。組ごとに違う表（ρ の平均 0.25）でも、ガウス 41.4%・t 33.3%・式 33.9%。
- R3 自然災害の ξ 0.3／0.5／0.7：ガウス 42.1／41.5／40.5%、グンベル 26.3／26.5／26.3%（VaR）。TVaR では ξ=0.7 で全体に下がる（ガウス 39.0%、グンベル 21.6%）。
- R4 t の自由度 3／4／6／10／30：32.4／33.6／36.3／37.9／40.3%（ガウスは 41.5%）。
- R5 自然災害を2倍：ガウス 39.0%、t 32.1%、グンベル 24.9%、式 32.2%。

## もう一度問う（結果を見た後に足した問い）
「相関の表の式で、それぞれの依存の形の資本を再現するには、表にいくつの相関を入れればよいか（逆算した相関）」と、それが損失データで測る相関とどれだけ違うか（results/C_reask.json）。
- ρ=0.25 のとき、逆算した相関（VaR）は、独立 −0.06、ガウス 0.12、t 0.25、グンベル 0.40、裏返しクレイトン 0.40。
- 同じ損失で測る順位相関（スピアマン、6組の平均）は 0.22〜0.24、ピアソン相関は 0.14〜0.27 で、依存の形による差は小さい。
- ρ=0.50 のとき、逆算した相関は ガウス 0.36、t 0.47、グンベル 0.70、裏返しクレイトン 0.77。
- つまり、式に入れるべき相関は「データで測った相関」ではなく、裾の重なり方で決まる。

## 計画からのずれ
- 問い直し（逆算した相関）は、結果を見た後に決めた。
- 上の裾の依存の目安（2つが同時に上位0.5%に入る割合）、損失で測る相関は、計画になく後から足した記述の集計。
- 組ごとに違う相関の表（R2）では、グンベル・裏返しクレイトンは1つの τ しか持てないので計算していない（独立・ガウス・t のみ）。

## 言えないこと
- 実在の会社・規制（ソルベンシー II の標準式、日本の ESR など）の数値ではない。相関、分布、尺度はすべて例示。
- どのコピュラが「正しい」かは、このシミュレーションからは分からない。年の損失データが数十年分あっても、裾の依存の形を見分けるのは難しい（推測。F288 の議論を参照）。
- 周辺分布の裾の形（特に自然災害の ξ）と、つなぎ方（コピュラ）のどちらも、結果を大きく左右する。
- 4つのリスクがすべて同じ強さでつながる設定は単純化。実際の組み合わせごとの違いは R2 で1つだけ試した。
- 投資・保険の購入の助言、規制の良し悪しの評価はしない。
