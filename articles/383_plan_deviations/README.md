# 383 先に決めた確かめ方のうち、実際にはできなかったものは何だったか（④ 振り返り R113）

精選の記事40本（F256〜F295）の PLAN.md（分析の前に書いた計画）と、README の「計画からのずれ」236項目を読み、計画どおりにできなかったものを数えた

## 問い

- 「計画からのずれ」には、何が書かれているか
- 計画したデータ・比べ方・確かめ方のうち、計画どおりにできなかったのは何項目か。理由は何か
- 計画に書いた頑健性の確かめのうち、やめたもの・代えたものはいくつか

## 手法

| 手順 | 中身 |
|---|---|
| 拾う（`src/a383_extract.py`） | PLAN.md がある記事41本のうち、README に「計画からのずれ」「計画とのずれ」の節がある40本（F256〜F295、コミット 00b426f）。PLAN.md の「頑健性」の節の項目数と、README のずれの節の項目（236個）を取り出す |
| 手で付ける（`data/manual_labels.csv`） | 236項目を全部読み、計画したデータ・比べ方・確かめ方が計画どおりにできなかった項目に、何が（頑健性／データ／期間・単位／比べ方／手法／指標／判定の基準）・どうなったか（やめた／代えた／一部だけ）・理由（データ／意味／計算／理由なし）を付けた |
| 言葉での目安（`src/a383.py`） | 項目の先頭120字に出てくる言葉（加えた・変えた・書いていなかった・誤り など）で機械的に分けた。1項目に複数付く |

251（仮説の当たり外れ）は仮説の判定を数えた。ここでは手順のずれだけを数える。T001 は PLAN.md があるが、README に「計画からのずれ」の節がないので入れていない

## 主な結果（`results/summary.json`、`results/target_by_reason.csv`）

- 「計画からのずれ」は40本で236項目（1本あたり3〜9項目、中央値6）
- 計画どおりにできなかったのは47項目（20%）、26本
- 理由：データがなかった・そろわなかった25、計画どおりでは意味がなかった15、計算できなかった4、理由を書いていない3。時間が理由のものは0
- どうなったか：代えた32、やめた10、一部だけ5

| 何が | データ | 意味 | 計算 | 理由なし | 計 |
|---|---|---|---|---|---|
| 頑健性の確かめ | 7 | 7 | 1 | 1 | 16 |
| データ | 9 | 0 | 0 | 2 | 11 |
| 期間・単位 | 7 | 0 | 0 | 0 | 7 |
| 比べ方 | 1 | 6 | 0 | 0 | 7 |
| 手法 | 0 | 0 | 3 | 0 | 3 |
| 指標 | 1 | 1 | 0 | 0 | 2 |
| 判定の基準 | 0 | 1 | 0 | 0 | 1 |

- 計画に書いた頑健性の確かめは195個（1本あたり4〜6個）。ずれに書かれたのは16個（8.2%、14本）：代えた11、やめた3、一部だけ2
- README の頑健性の節の項目は、1本あたり中央値9個（計画は5個）
- 言葉での目安：「足した」77項目（39本）、「変えた」62項目、「決めていなかった」18項目（14本）、「誤りを直した」17項目（14本）、先に見ていたデータの開示14本

## 確かめたこと

- 言葉で「できなかった」に当たる項目26個と、「変えた」や言葉のない項目約150個を読み、手で付けた47項目を決めた（言葉だけの分類では、できなかった項目の半分近くを取りこぼす）
- `src/a383_extract.py` と `src/a383.py` を空のフォルダで流し直し、data・results・figures が一致することを確かめた

## 注意（言えないこと）

- 数えたのは README の「計画からのずれ」に書いてあることだけ。書き漏らしたずれは数えられない
- 「計画どおりにできなかった」かどうかと理由は、項目を読んで手で付けた。読む人が変われば数は数個ずれる可能性がある
- 「計画どおりに行った」179個は、ずれに書かれなかった数。1つずつ PLAN と結果を突き合わせてはいない
- 言葉での分け方は目安。「どの言葉もない」項目が73個ある
- 40本だけの記録で、計画の細かさは記事によって違う
