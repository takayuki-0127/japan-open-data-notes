# 276 出荷のうち、輸出向けはどれだけ増えたのか

経済産業省「鉱工業出荷内訳表」（2020年=100）で、鉱工業の出荷を輸出向けと国内向けに分けて1998〜2025年を並べたフォルダです。1998〜2022年は接続指数、2023年以降は2020年基準の指数を使っています（重なる2018〜2022年は一致、差0.0）。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A276 | 出荷のうち、輸出向けはどれだけ増えたのか | 輸出向け・国内向けの出荷指数（季節調整済）の年平均を比べる。2020年のウエイト（輸出向け19.35%）で重みづけし、出荷に占める輸出向けの割合（2020年の価格で）と、出荷全体の変化への寄与を計算。業種別にも同じ計算 | `src/a276_export_domestic.py` |

## 主な結果
- 鉱工業の輸出向け出荷は1998年74.9→2007年119.6→2019年113.8→2025年111.1（1998年の1.48倍）。国内向けは120.9→134.3→111.9→96.8（1998年の0.80倍）
- 出荷に占める輸出向けの割合（2020年の価格で）は1998年12.9%→2007年17.6%→2009年16.9%→2025年21.6%
- 1998年→2025年の出荷全体の変化（−11.7ポイント）は、輸出向けが+7.0、国内向けが−19.4ポイント（ウエイトで重みづけした寄与。合計とのずれは最大0.05）
- 2019年→2025年は輸出向け−2.4%、国内向け−13.5%。2007年→2025年は輸出向け−7.1%、国内向け−27.9%。輸出向けが増えたのは2007年まで
- 業種別（14業種）：輸出向けの割合が上がったのは12業種。化学12.4%→23.7%、窯業・土石7.1%→15.6%、プラスチック製品3.5%→12.3%、輸送機械23.4%→29.7%。下がったのは電子部品・デバイス（45.3%→34.1%、国内向けが1998年の3.1倍に増えた）と汎用・業務用機械（31.6%→31.4%）

## 頑健性
- 出荷指数＝（輸出向けのウエイト×輸出向け＋国内向けのウエイト×国内向け）÷出荷のウエイト が、2025年の全業種で0.05ポイント以内で成り立つことを確かめた
- 業種によって系列の始まりが違う（1998・2013・2018年）。割合の変化は、その業種の系列の最初の年との比較
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致した

## 動かし方

```
pip install -r requirements.txt
cd src && python a276_export_domestic.py
```

## データ
- `data/shipments_breakdown_2018_2026.csv`：`b2020_nblnc_gsm1j.xlsx`（業種別 月次 季節調整済：出荷・輸出・国内）
- `data/shipments_breakdown_connected_1998_2022.csv`：`b2020_nblnc_sutw.xlsx`（業種別出荷内訳 接続指数 月次 季節調整済）
- `data/weights_2020.csv`：`b2020_nblnc_weight.xlsx`（2020年のウエイト：出荷・輸出・国内）

## 注意
- 指数は数量の動き（2020年の価格で重みづけ）で、金額ではない。円安で輸出の金額が増えても、数量が増えなければ指数は増えない（記事F282 で輸出額を数量と価格に分けた）
- 輸出向けの割合は2020年のウエイトで重みづけした値で、その年の実際の金額の割合とは違う
- 国内向けの出荷には、国内の工場が部品として使う分も入る。国内向けの減りが、国内の最終需要の減りか、海外生産への移転かは分けていない
