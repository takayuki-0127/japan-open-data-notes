# 421 生まれて1年以内に亡くなる子は、いつ、どれだけ速く減ったのか（人口動態統計、1899〜2025年）

人口動態統計の年次推移から、乳児死亡率（出生1,000あたり、1歳になる前に亡くなった子の数）を1899年から2025年まで並べ、下がり方の速さと、生後4週未満・それ以後の内訳を見たフォルダです。全国の集計だけを使っています。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A421 | 乳児死亡率は、いつ、どれだけ速く下がったか | 出生数と乳児死亡数から率を計算（公表の率と照合）。はじめて下回った年、1920年の半分・4分の1…になった年、期間ごとの年あたりの変化率、新生児（4週未満）とそれ以後の内訳 | `src/a421_infant_mortality.py` |

## 主な結果
- 乳児死亡率（出生1,000あたり）：1899年 153.8 → 1918年 188.6（最高）→ 1950年 60.1 → 1975年 10.0 → 2000年 3.2 → 2025年 1.9。乳児死亡数は1918年の33万8千人から2025年は1,256人
- 1899〜1920年はほぼ横ばい（年+0.3〜+0.4%）。下がりはじめたのは1920年代（年−2.9%）
- 1920年（165.7）の半分になったのは1947年（27年後）。そのあとは1955年・1964年・1975年・1987年と、8〜12年ごとに半分になった。次の半分は2008年で21年かかった
- 年あたりの下がり方は、1950年代 −6.5%、1960年代 −8.1%、1970年代 −5.4%、1980年代 −4.8%、2000年代 −3.4%、2010年代 −2.4%。2020→2025年は+0.8%（1.80→1.87）
- 100を切ったのは1940年、50は1952年、10は1976年、5は1987年、2は2015年
- 生後4週未満（1943年までは1か月未満）の割合は、1899年51% → 1920年42% → 1975年68% → 2025年46%。1950〜60年代は「4週以後」が速く減り（年−8〜−11%）、1980年代は「4週未満」が速く減った（年−6.2%）

## 確かめたこと
- 自分で計算した率（乳児死亡数÷出生数×1,000）は、公表の率と124年すべてで一致（小数第1位）
- 3年の移動平均で見ても、100・25・10・5を切った年は同じ（50だけ1952年→1953年）
- 起点を1900〜1950年に変えて「10分の1になるまでの年数」を出すと、67・57・47・41・37・34年（`results/a421_main.json`）
- 空のフォルダで流し直し、results・figures が一致した

## 注意（言えないこと）
- 1944〜46年は数字がありません。1947〜72年は沖縄県を含みません
- 「新生児」は、1943年までは生後1か月未満、1947年からは28日未満で、少し範囲が違います
- 下がった理由（栄養・衛生・医療・出産の場所など）は分けていません。何が効いたかは、この数字からは言えません
- 明治・大正の時期は、届け出のもれや、死産と出生の届け出の区別があいまいだった可能性があります（推測）。古い年の水準には幅を見てください
- 2020年代は年に1,200〜1,500人で、率の小数第1位は年ごとに揺れます。2020→2025年の上がりは、向きが変わったとは言えない大きさです
- 全国の集計だけで、地域や家庭の事情による違いは見ていません。健康や育児についての助言ではありません
