# 661 新しく開いた店と閉じた店を含めたまま前年比を出すと、既存店だけの前年比とどれだけ違うのか（実務の型・比べる範囲）

売上の前年比は、比べる店の範囲で大きく変わります。新しく開いた店は前年に売上がなく、閉じた店は今年に売上がないので、全店の合計どうしを比べると、店の出入りがそのまま「伸び」に入ります。**ここでは、架空のチェーン（2023年末に100店、2024〜2025年に26店を開き13店を閉じる）で、既存の店の本当の伸びを毎月+1%に置き、2025年の前年比を4通りで出して比べました。** 店の出入りと新店の立ち上がり方は作成者が置いたもので、数字はその仮定で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A661 | 全店・既存店・店×営業日あたりの前年比は、本当の既存店の伸びとどれだけ違うか | Y1 全店の合計どうし、Y2 既存店（前年の同じ月も今年もまる1か月営業）、Y4 既存店のうち2023年以前からの店、Y3 全店の売上を店×営業日で割って比べる。DuckDB（1スレッド）と pandas で一致を確認。seed 661 | `src/a661_same_store.py`、`src/02_same_store_duckdb.sql`、`src/01_same_store_tsql.sql`（未検証） |

## 主な結果
- **全店の合計どうし（Y1）は年間 +10.2%**：本当の既存店の伸び（+1%）の約10倍。月ごとには +7.6%〜+12.1% で、新店が増える年末ほど大きい
- **既存店だけ（Y2）は年間 +1.9%**（月ごとに +0.6%〜+3.2%）。2024年に開いた店が、前年は立ち上がりの途中（売上が低い）だったため、まだ少し上に出る
- **既存店のうち2023年以前からの店（Y4）は +1.0%** で、置いた伸びとほぼ一致した（月ごとに +0.2%〜+1.7%）
- **店×営業日あたり（Y3）は +3.2%**（月ごとに +1.3%〜+6.7%）。店の数の増減は消えるが、新店の売上の水準や立ち上がりが混ざる
- 既存店に入る店は、その月に営業した107〜113店のうち93〜99店

## 動かし方
```
pip install -r requirements.txt
cd src && python a661_same_store.py
```
数秒で終わります。`data/monthly.csv`（store_id・ym・sales・open_days・days_in_month）に月次売上を、`results/monthly_yoy.csv` に月ごとの前年比を書き出します。

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures がバイト単位で一致した（DuckDB は `SET threads=1`）
- 全店と既存店の売上（今年・前年）が DuckDB と pandas で一致した
- T-SQL 版（`01_same_store_tsql.sql`）は書いたが、SQL Server では動かしていない（**未検証**）

## データ
- 仮定：2023年末の100店は売上の水準が対数正規（中央値1,500）。季節の波を共通に置き、既存の店は前年比+1%で伸びる（月ごとに3%の誤差）
- 新店は2024年に8店、2025年に18店（2025年は前半に多い）。開店から6か月かけて、売上が55%から100%まで上がる
- 閉店は売上の小さい店から、2024年に3店、2025年に10店。開店・閉店の月は日割り

## 注意（言えないこと）
- 架空のデータ。実際の会社の数字ではない
- 「既存店」の決め方（開店から13か月以上、改装中の店を除くなど）は会社ごとに違う。どの決め方で出したかを書いておくのが安全
- 閉店する店が売上の小さい店に偏ると、全店の前年比はさらに上に出る。ここでは閉店の数が少ないので、その影響は小さい
