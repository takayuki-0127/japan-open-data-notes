# 1295 荷物を来た順に詰めるか、大きい順に並べ替えてから詰めるかで、使う車の台数と積載率はどれだけ違うのか？（箱詰めと積載）

車に荷物を積むとき、来た順に積んでいくと、最後のほうに大きな荷物が来て、どの車のすきまにも入らず新しい車を使うことがあります。その日の荷物を全部そろえてから、大きい順に並べて積めば、大きな荷物を先に置き、小さな荷物ですきまを埋められます。では、並べ替えると車は何台減り、積載率（積んだ荷物の体積の合計÷荷台の大きさの合計）はどれだけ上がるのでしょうか。**ここでは、作成者が置いた架空の通販の配送（その日の荷物の体積の合計が平均で荷台20台分、荷物1つの大きさは平均で荷台の20%、大きさの散らばりを作成者が置いて乱数で作ったもの）で、A 来た順に詰める、B 大きい順に並べてから詰める、の台数と積載率を1,000日分比べました。どちらも「入る車のうち、いちばん先に使い始めた車に積む」決まりです。荷物の大きさの置き方16通りで確かめました。**

すべて作成者が置いた決まりでのシミュレーションです。形は気にせず、体積の合計だけで荷台に入るかを決めています。実在の通販・運送・車の数字を表すものではありません。

関連する記事：1270「分けた仕事の大きさがばらつくと、全体の時間はいちばん遅い1つでどれだけ延びるのか？」は、分けた仕事の大きさがばらつくと、全体の時間がいちばん遅い1つで決まることを扱っています。1271「仕事を初めに同じ数ずつ割り当てるか、終わった所が次を取りにいくかで、全体が終わる時刻はどれだけ違うのか？」は、割り当て方の比べの中で「大きい順に並べて取りにいく」を扱い、全体が終わる時刻を数えています。1293「荷物の体積の合計を箱1つの容量で割って見込んだ箱の数は、1つずつ詰めていったときの本当の箱の数よりどれだけ少なく出るのか？」は、「体積の合計÷容量」の切り上げで見込んだ箱の数が、箱ごとに残るすきまの分だけ本当の箱の数より少なく出ることを数えています。1294「車の台数を重さの上限だけ、または大きさの上限だけで見込むと、両方の上限を守って積んだときの台数よりどれだけ少なく出るのか？」は、重さと大きさの2つの上限があるとき、片方だけで台数を見込むとどれだけ少なく出るかを数えています。1303「詰め方の良さを、『体積の合計÷容量』の切り上げと比べるか、いちばん良い詰め方と比べるかで、どれだけ見え方が違うのか？」は、詰め方の良さを「体積の合計÷容量」の切り上げ（下限）と比べるか、いちばん良い詰め方と比べるかで、無駄の大きさの見え方がどれだけ違うかを数えています。1304「届ける順に取り出せるよう、あとで届ける荷物を奥に積む決まりを入れると、積載率はどれだけ下がるのか？」は、あとで届ける荷物を奥に積む決まりを入れると、並べる順が縛られて床の積載率が下がり、台数が増えることを数えています。この記事は、1271 のような時刻ではなく容量の決まった車の台数と積載率を数え、同じ「入る車に積む」決まりのまま、詰める順番だけを変えたときの違いに絞ります。

## 主な結果

### 基本の置き方（荷物100個・大きさの平均は荷台の20%、1,000日、`results/a1295_main.json` の `base`）
| | A 来た順に詰める | B 大きい順に並べてから詰める | 参考 C 来た順・入らなければ次の車 |
|---|---|---|---|
| 台数の平均 | 20.865台 | **20.512台** | 23.409台 |
| 積載率（日ごとの平均） | 95.2402% | **96.8722%** | 85.0092% |
| 下限（体積の合計の切り上げ）どおりの台数で済んだ日 | 49.7% | 85.0% | − |

- **大きい順に並べると、台数は平均0.353台減り、積載率は1.632ポイント上がった**（下限の平均は20.362台）
- 1,000日のうち、並べ替えで1台減った日は35.3%、変わらなかった日は64.7%で、2台以上減った日と増えた日はなかった（`results/base_diff_dist.csv`）
- 並べ替えで台数が減った最初の日（2日目、荷物100個）では、Aは20台、Bは19台だった。Aでは最後の2台の埋まりが67.93%と47.69%で、Bでは19台とも93.35%以上埋まった（`results/example_day.csv`、図1）
- 参考に、来た順で入らなければ次の車に移るCと比べると、Aは平均2.544台少なく、積載率は10.2309ポイント高かった。並べ替え（AとB）の差より、すきまのある車に戻って積むかどうか（CとA）の差のほうが大きかった

- **16通りで、並べ替えで減った台数は平均0.0133〜0.96台、積載率の差は0.06〜3.4ポイントだった**。荷物が荷台に比べて大きいほど差は大きく、同じ大きさの平均では、散らばりが1.0と大きいと差は小さかった
- 荷物が小さい（平均5%）と、来た順でも小さな荷物がすきまを埋めるので、差はほとんどなかった（0.06〜0.39ポイント）
- 一様に20〜45%では、並べ替えたほうが1台多くなった日が5.0%あった。大きい順に並べるやり方は、いつも台数が少なくなるとは限らなかった
- 一様に30〜50%では、並べ替えで81.33%の日に台数が減り、積載率の差（3.4ポイント）が、すきまのある車に戻って積むかどうかの差（2.26ポイント）より大きかった。16通りの中で、B−AがA−Cより大きかったのはこの1通りだけだった

## 動かし方
```
pip install -r requirements.txt
cd src && python a1295_order_sorted_vs_arrival.py
```
5秒ほどで終わります。`data/days_base.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp）
- 基本の1,000日すべてで、A・B・Cの台数が下限（体積の合計の切り上げ）以上であることを確かめた（`data/days_base.csv`。作りどおり）
- 図3枚を開き、日本語・重なり・軸（0から）を確かめた

## データ
- `data/days_base.csv`：基本の置き方の1,000日（volume_sum は体積の合計（荷台の台数分）、lower_bound は下限、trucks_arrival はA、trucks_sorted はB、trucks_close はCの台数）
- `results/a1295_main.json`：主な結果（`base`・`example_day`・`grid_range`）
- `results/base_diff_dist.csv`：基本の置き方で、並べ替えで減った台数ごとの日の割合
- `results/example_day.csv`：図1の日の、車ごとの荷台の埋まり（%）
- `results/grid.csv`：確かめの16通り（p1・p2 は対数で正規の分布なら大きさの平均と散らばり、一様な分布なら下と上の端。fewer_by_sorting_mean は並べ替えで減った台数、fill_gain_sorted_vs_arrival_pt は積載率の差（B−A）、fill_gain_arrival_vs_close_pt は積載率の差（A−C）、*_at_bound は下限どおりで済んだ日の割合）

## 注意（言えないこと）
- 架空のデータです。荷物の大きさの分布、その日の荷物の数、詰め方は作成者が置いたもので、差の大きさはこれで決まります
- Bは、その日の荷物を全部そろえてから積み始めると置きました。荷物が届くたびに積んで出す場合は、この並べ替えはできません。そろうまで待つ時間や置き場所は数えていません
- 形は気にせず、体積の合計だけで荷台に入るかを決めました。縦・横・高さの形、重さの上限、重ねられない荷物、届ける順に取り出す決まりは入れていません
- 車は何台でも開けたままにしておけると置きました
- 送料・料金の決め方や、どの車を使うべきか・何台用意すべきかの助言をする記事ではありません
