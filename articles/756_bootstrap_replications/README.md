# 756 ブートストラップの回数を100回・1,000回・10,000回と変えると、95%区間の端はどれだけ揺れるのか（手法の解説・正解の分かるデータで試す）

ブートストラップは、手元のデータから同じ件数を重複ありで何度も選び直し、その結果のばらつきから区間を出す方法です。選び直す回数 B が少ないと、同じデータでもやり直すたびに区間の端が変わります。**ここでは、架空の客単価50件（対数正規分布）に対して、B を100・1,000・10,000回と変えてそれぞれ100回やり直し、平均と中央値の95%区間（パーセンタイル法）の端の振れを測りました。あわせて、データを600回作り直して、区間が本当の値を含む割合を数えました。** 分布の形と件数は作成者が置いたもので、数字はその置き方で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A756 | B を変えると、区間の端はどれだけ揺れ、当たる割合は変わるか | パーセンタイル法の95%区間。同じ50件で B=100・1,000・10,000 を各100回やり直す。端の標準偏差を区間の幅（B=10,000 の平均）で割る。データを600回作り直して当たる割合。seed 756 | `src/a756_boot_reps.py` |

## 主な結果
- **平均の区間の端の振れ**（両端の標準偏差÷区間の幅）：B=100 で6.4%、1,000 で2.2%、10,000 で0.6%。回数を10倍にすると約3分の1になる
- **中央値の区間**：4.9%・2.6%・0.6%。中央値はデータの値の上にしか乗らないので、端が飛び飛びに動く
- **円で見ると**：平均の区間（約3,300〜4,430円）の上の端は、B=100 では100回のやり直しで最大355円、B=10,000 では40円の幅で動いた
- **当たる割合は回数では決まらない**：平均の区間は B=100 で89.7%、1,000 で91.7%、10,000 で92.0%。どれも95%に届かないのは、件数が少なく分布が歪んでいるため（回数を増やしても直らない）

## 動かし方
```
pip install -r requirements.txt
cd src && python a756_boot_reps.py
```
十数秒で終わります。`results/redo_intervals.csv` にやり直しごとの区間を、`results/summary.csv` に振れの大きさを、`results/coverage.csv` に当たる割合を書き出します。

## 確かめたこと
- 空のフォルダで流し直し、results・figures がバイト単位で一致した
- B を10倍にすると端の振れが約1/√10（0.32倍）になることを、結果（平均の区間で6.4%→2.2%→0.6%、どれも約0.3倍）で確かめた
