# 911 検査で「不良」と出た品物は、本当に不良なのか？（品質と検査）

検査には、不良を良品と判定する「見逃し」と、良品を不良と判定する「誤検出」があります。検査が全体として99%以上正しくても、不良がもともと少ない工程では、「不良」と出た品物のかなりの部分が良品になりえます。**ここでは、作成者が乱数で作った架空の工場の部品の長さの検査（本当の長さと測りの誤差を作成者が置いたもの）で、「不良」と判定された品物のうち本当に不良の割合を数えました。不良の多さと測りの誤差を変えるとどう動くか、「不良」と出た品物を測り直すとどれだけ当たりが上がるか、測りの誤差が品物ごとに毎回同じ向きに出るときはどうかも確かめました。**

関連する記事：812「『4.5以上』で絞り込むと、良い店は何%外れるのか？」は、見かけの値の境目で絞り込むと、本当は良い店が外れ、本当は違う店が入ることを数えていて、この記事の「規格の端の近くで判定が入れかわる」と同じ形です。909「不良率0.1%を確かめるには、何個検査すればよいのか？」は、検査は正しく判定できると置いて、検査の個数だけを扱っています。この記事は、検査の判定そのものの当たり外れを扱います。914「全数検査なら、不良はゼロになるのか？」は、同じ不良を何度検査しても見つけにくい不良が残ること、915「検査員によって合否が違うとき、何を数えればよいのか？」は、人の目の検査で検査員どうしの違いを何で数えるかを扱っています。この記事の測り直しは「不良」と出た品物の当たりを上げる話で、914 のくり返しの全数検査は見逃しを減らす話です。

## 主な結果

### 基本の置き方（不良率1%・測りの誤差0.03mm、100万個）
| | 値 |
|---|---|
| 本当の不良率 | 1.031% |
| 「不良」と判定された割合 | 1.288% |
| 正しく判定した割合（良品を良品、不良を不良） | **99.321%** |
| 「不良」と出た品物のうち、本当に不良 | **63.71%** |
| 「不良」と出た品物のうち、本当は良品 | 36.29% |
| 本当の不良のうち、見逃した割合 | 20.48% |
| 誤検出した良品のうち、本当の長さが規格の端から0.05mm以内 | 88.53% |

| 1万個あたり | 個数 |
|---|---|
| 本当の不良 | 103個 |
| 「不良」と判定 | 129個 |
| そのうち本当に不良 | 82個 |
| そのうち本当は良品（誤検出） | 47個 |
| 見逃した不良 | 21個 |

- **正しく判定した割合は99.321%でも、「不良」と出た品物の36.29%は本当は良品だった**。良品は不良の95.95倍あるので、良品のわずかな誤検出でも、不良の判定の中では大きな割合になる
- 誤検出された良品の88.53%は、本当の長さが規格の端から0.05mm以内だった（図1）。規格ぎりぎりの良品が、測りの誤差で外に出たもの
- 式（数値積分）では、本当に不良の割合は63.10%、見逃しは20.39%で、乱数で数えた値とそろった

### 不良の多さと測りの誤差を変える（各100万個）
| 本当の不良率 | 測りの誤差 | 本当に不良の割合 | 式の値 | 見逃し | 正しく判定した割合 |
|---|---|---|---|---|---|
| 0.2% | 0.01mm | 85.03% | 83.84% | 11.24% | 99.945% |
| 0.2% | 0.03mm | 46.43% | 47.65% | 24.62% | 99.784% |
| 0.2% | 0.06mm | **15.23%** | 15.32% | 34.34% | 99.220% |
| 1% | 0.01mm | 88.95% | 88.88% | 8.32% | 99.804% |
| 1% | 0.03mm | 63.83% | 63.10% | 20.55% | 99.335% |
| 1% | 0.06mm | 31.78% | 31.71% | 30.15% | 98.212% |
| 5% | 0.01mm | **93.81%** | 93.46% | 5.55% | 99.409% |
| 5% | 0.03mm | 78.65% | 78.53% | 14.50% | 98.109% |
| 5% | 0.06mm | 56.18% | 56.19% | 23.66% | 95.842% |

- **「不良」と出た品物のうち本当に不良の割合は、置き方で15.23〜93.81%と大きく動いた**。工程の不良が少ないほど、測りの誤差が大きいほど下がった
- 正しく判定した割合は、9通りとも95.842〜99.945%と高かった。この割合は、「不良」の判定がどれだけ当たるかをほとんど表さない。不良率0.2%・誤差0.06mmでは、正しく判定した割合が99.220%でも、本当に不良は15.23%だった
- 乱数で数えた値と式の値の差は、9通りで最大1.22ポイント（不良の少ない置き方ほど、「不良」と出る品物が少なく乱数で振れる）
- 基本の置き方（1%・0.03mm）は、乱数を変えて数え直したので63.83%と、上の表の63.71%から少し動く

### 測り直すと（不良率1%、各100万個）
| 誤差のうち品物ごとに同じ向きの分 | 測りの誤差 | 1回の判定：本当に不良 | 測り直し後：本当に不良 | 1回の判定：見逃し | 測り直し後：見逃し |
|---|---|---|---|---|---|
| 0% | 0.03mm | 62.60% | **84.45%** | 20.12% | 34.08% |
| 50% | 0.03mm | 62.63% | 76.41% | 20.73% | 30.07% |
| 90% | 0.03mm | 62.30% | **67.76%** | 20.19% | 24.49% |
| 0% | 0.06mm | 31.73% | 62.25% | 30.47% | 49.95% |
| 50% | 0.06mm | 31.99% | 48.60% | 29.56% | 42.36% |
| 90% | 0.06mm | 31.97% | 37.37% | 29.98% | 35.71% |

- 測るたびに誤差が変わるなら、「不良」と出た品物を測り直して2回とも外のものだけを不良にすると、本当に不良の割合は62.60%から84.45%に上がった
- **誤差の90%が品物ごとに毎回同じ向きに出るときは、測り直しても67.76%までしか上がらなかった**。同じ品物を同じように測り直しても、同じ向きにずれるため
- 測り直しには代わりの損もあった。1回目で正しく「不良」と出た不良が、2回目に規格の中と出て良品に戻るので、見逃しは20.12%から34.08%に増えた（誤差がすべて測るたびに変わるとき）

## 動かし方
```
pip install -r requirements.txt
cd src && python a911_flagged_defective.py
```
数秒で終わります。`data/parts_example.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約3.2秒）
- 図3枚を開き、日本語・重なり・軸を確かめた
- 品物ごとに同じ向きの誤差がない9通りで、乱数で数えた「本当に不良の割合」が、正規分布の数値積分（式）の値と最大1.22ポイントの差でそろった

## データ
- `data/parts_example.csv`：基本の置き方の最初の5,000個（part_id・true_length（本当の長さ、mm）・measured1（1回目に測った値）・measured2（測り直した値）・true_defect（本当に規格の外か）・flagged1（1回目で「不良」か）・flagged_after_recheck（測り直し後も「不良」か））。measured2 は、1回目で「不良」と出なかった品物にも入れてある（数える式では使わない）
- `results/a911_main.json`：主な結果すべて
- `results/by_rate_and_error.csv`：不良の多さと測りの誤差を変えた9通り
- `results/recheck.csv`：測り直しの確かめ

## 注意（言えないこと）
- 架空のデータです。本当の長さの分布（正規分布）、規格の幅、測りの誤差の大きさと形は作成者が置いたもので、結果はこれで決まります。「不良」と出た品物のうち本当に不良の割合は、置き方で15.23〜93.81%と動きました
- 主な結果は、条件つきの確率（ベイズの定理）からくる式どおりの値です。この記事で新しく数えたのは、誤検出が規格の端に集まる様子と、品物ごとに同じ向きの誤差があると測り直しが効きにくいことです
- 長さの検査だけを扱いました。外観の検査など、合否が人の目で決まる検査は入れていません
- 規格の外の品物をすべて「不良」としました。どの程度の外れが実際に問題になるかは扱っていません
- どの測り方・どの判定の線（規格より内側に線を引くなど）を使うべきか、取引先との約束や規格の決まりについては言えません
