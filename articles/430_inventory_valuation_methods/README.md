# 430 同じ仕入れと販売でも、在庫の評価の方法で、月の粗利はどれだけ違うのか（実務の型）

架空の商品200点、36か月の仕入れと販売で、先入先出・移動平均・総平均（月ごと）の3つの方法の売上原価と粗利を計算し、月ごとの差を数えたフォルダです。F235（在庫の量）・F259（欠品）は在庫をどれだけ持つかを扱いました。ここでは、持っている在庫をいくらとみなすかを扱います。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A430 | 在庫の評価の方法を変えると、月の粗利と粗利率はどれだけ変わるか。差はいつ大きくなるか | 3つの方法を Python で計算（取引を1件ずつ順にたどる）。先入先出は「累計の数量の区間の重なり」で出す SQL を DuckDB で実行して一致を確かめる。在庫を持つ量（0.5〜4か月分）と値動きの大きさ（0〜60%）を変えて比べる | `src/a430_inventory.py`、`src/01_inventory_tsql.sql`（T-SQL 版、未検証） |

## 主な結果
設定：仕入れ値は前半18か月で+30%、後半18か月でそこから−20%。売値はその月の仕入れ値の1.3倍（その月の仕入れ値で計算した粗利率は23.1%）。在庫は約2か月分。

| | 先入先出 | 移動平均 | 総平均（月ごと） |
|---|---|---|---|
| 粗利率：仕入れ値が上がる18か月の平均 | 25.2% | 25.0% | 25.0% |
| 粗利率：仕入れ値が下がる18か月の平均 | 21.4% | 21.5% | 21.6% |
| 3年分の粗利の合計 | 1億8,418万円 | 1億8,454万円 | 1億8,474万円 |
| 36か月の終わりの在庫の金額 | 2,929万円 | 2,965万円 | 2,985万円 |

- **先入先出 − 移動平均の月の粗利の差**：大きさの中央値0.31%。0.5%未満の月が21か月、1%以上の月が9か月（2023年1〜4月の +1.1〜+3.2%、2024年7〜10月の −1.6〜−4.8%、2025年1月の −1.4%）。最大 +3.2%（2023年2月）、最小 −4.8%（2024年8月）
- **総平均 − 移動平均**：大きさの中央値0.25%、最大 +1.5%、最小 −0.9%。1%以上の月は4か月（2024年7〜10月）
- **年の合計（先入先出 − 移動平均）**：2023年 +0.67%、2024年 −1.06%、2025年 −0.13%。3年の合計 −0.20%（−36万円）
- **3年の合計の粗利の差（−361,227円）は、36か月の終わりの在庫の金額の差と同じ**
- **在庫を持つ量（先入先出 − 移動平均、上がる時期／下がる時期の平均）**：0.5か月分 +0.01%／−0.01%、1か月分 +0.11%／−0.17%、2か月分 +0.48%／−0.82%、4か月分 +1.80%／−3.69%。4か月分のとき、先入先出の粗利率は上がる時期27.0%、下がる時期20.0%
- **値動きの大きさ（18か月の上がり幅。先入先出 − 移動平均、上がる時期／下がる時期の平均）**：0% で −0.01%／+0.01%、10% で +0.17%／−0.32%、30% で +0.48%／−0.89%、60% で +0.86%／−1.55%（下がり幅は、36か月の終わりに仕入れ値が元に戻る大きさ）

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した
- DuckDB の SQL で出した先入先出の月ごとの売上原価が、Python の計算と36か月すべてで一致する（コード内の assert）
- 3つの方法で、「粗利の合計の差」と「期末の在庫の金額の差」が一致する（仕入れた金額の合計は方法によらない）

## データ
- `data/purchases.csv`：架空の仕入れ7,400件（商品・日付・数量・仕入れ値）。期首の在庫も、2022年12月31日の仕入れとして入っている
- `data/sales.csv`：架空の販売28,800件（商品・日付・数量・売値）
- どちらも作成者が乱数で作成（seed 430）

## 注意（言えないこと）
- 架空のデータ。差の大きさは、仕入れ値の動き方・在庫を持つ量・仕入れの回数の置き方で決まる。仕入れ値は一直線に上がって一直線に下がる形だけ
- 売値はいつも仕入れ値の1.3倍。売値を上げるのが遅れる場合は見ていない
- どの方法がよいか、会計・税の決まりでどれが認められるかは扱っていない
- 後入先出・売価還元法・最終仕入原価法、在庫の評価損、品切れ・返品は入れていない
- T-SQL 版は SQL Server 本体では動かしていない（未検証）。移動平均と総平均の SQL は書いていない
