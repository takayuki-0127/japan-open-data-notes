# F371 PLAN（事前の計画）：所定外の労働時間は、生産の動きより先に動くのか？

作成：2026-11-16 14:10（データを取得し、表の形を確かめたあと、時差の相関や景気の山・谷の前後の動きを計算する前に書いた）

## 問い
工場では、注文が増えるとまず残業で対応し、人を増やすのは後になると言われます。逆に注文が減ると、まず残業が減ります。そうなら、製造業の所定外労働時間（いわゆる残業の時間）は、生産の動きと同じか、少し先に動くはずです。

知りたいこと：製造業の所定外労働時間指数は、鉱工業の生産指数より先に動くのか、同時なのか、後なのか。景気の山・谷の前後で、どちらが先に向きを変えたのか。生産が1%動くと、所定外は何%動くのか。2019年からの時間外労働の上限規制のあとで、この関係は変わったのか。

知りたい人：製造業の生産管理・人事の担当、景気の統計を読む人、月次の統計を早く読みたい人。

既存の看板記事との違い：jodn の 533 は所定外の時間の丸め（端数）を扱い、生産との関係は扱っていない。jodn の F35・F174 は景気の局面の推定（複数系列）で、所定外と生産の時差は扱っていない。existing_F_titles.txt と jodn の README を「所定外」「残業」「生産指数」「景気」で検索して、同じ問いの記事はなかった。

## データ
- 厚生労働省「毎月勤労統計調査」全国調査 長期時系列表「季節調整済指数」（1998年1月〜2026年8月、2020年=100）。製造業・事業所規模5人以上・就業形態計の所定外労働時間指数（季調済）を主に使う。30人以上、総実労働時間は頑健性に使う。
- 内閣府「景気動向指数」一致系列の個別系列 C1 生産指数（鉱工業、2020年=100、季節調整済）（1975年1月〜2026年8月）。
- 内閣府経済社会総合研究所「景気基準日付」（第16循環の谷 2020年5月まで）。

## 取得前に見たもの（開示）
- 表の形を確かめるときに、毎勤の列見出しと、所定外労働時間指数（製造業5人以上）の最初の2か月と最後の3か月の値（1998年1月111.5、2026年8月114.3 など）、景気動向指数の生産指数の最後の数か月の値（2026年8月101.9 など）、景気基準日付の表を目にした。時差の相関、山・谷の前後の動き、弾力性は計算していない。

## 仮説と「外れ」の基準
- H1：前月からの変化率どうしの相関は、時差0（同じ月）でいちばん高い。ほかの時差でいちばん高ければ外れ。
- H2：景気の山（1998年以降の4回）の前後12か月で、所定外の山（3か月移動平均の最大の月）は、生産の山より平均1か月以上早い。平均の差が1か月未満なら外れ。
- H3：3か月前からの変化率で見て、生産が1%動くと所定外は1.5%より多く動く（回帰の傾きが1.5より大きい）。1.5以下なら外れ。
- H4：2019年4月以降（上限規制のあと）は、3か月変化率どうしの相関が、2009年4月〜2019年3月より0.1以上低い（2020年3〜12月を除く）。低下が0.1未満なら外れ。

## 手法
- 両系列を対数にし、前月比（%）と3か月前比（%）を作る。
- 時差の相関：所定外の変化率と、k か月あとの生産の変化率の相関（k=−6〜+6）。k>0 で高ければ所定外が先。
- 景気の山・谷（山：2000年11月、2008年2月、2012年3月、2018年10月。谷：1999年1月、2002年1月、2009年3月、2012年11月、2020年5月）の前後12か月で、3か月中心移動平均の最大（山）・最小（谷）の月を両系列で探し、月の差を比べる。
- 弾力性：3か月前比の所定外を、同じ期間の生産に回帰した傾き。

## 頑健性（3つ以上）
1. 事業所規模30人以上の所定外労働時間指数で H1〜H3 を見る。
2. 2008年10月〜2009年6月と2020年3〜12月（大きな落ち込みの月）を除いて H1・H3 を見る。
3. 移動平均をかけない原系列（季調済）の最大・最小の月で H2 を見る。
4. 所定外の代わりに総実労働時間指数（製造業）で時差の相関を見る。

## 問い直し（予定）
結果を見てから1つ足す。候補：生産1単位あたりの所定外（所定外指数÷生産指数）は、長い目で見て下がっているのか（同じ生産でも残業が減ったのか）。

## 言えないこと（予定）
- 所定外は1人あたりの時間で、働く人の数は入っていない。製造業全体の残業の総量ではない。
- 鉱工業の生産指数には、製造業でない鉱業も入る（ごく一部）。
- 毎勤は調査の対象の入れ替えや、2018年前後の集計の見直しで、段差がある月がある。
- 先に動くことが分かっても、所定外が生産を動かす（因果）とは言えない。
- 2020年5月より後の景気の山・谷は、まだ決まっていない。
