# 277 製造工業生産予測調査の見込みは、どれくらい当たるのか

経済産業省「製造工業生産予測指数」（2020年基準）の時系列表で、企業が前の月に答えた「当月の生産の見込み」と、翌月に答えた実績の差（実現率）を業種別に並べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A277 | 生産予測調査の見込みは、どれくらい当たるのか。外れ方に偏りはあるか | 公表の実現率（季節調整済の「前月実績」÷前の月の調査の「当月見込」−1）を業種別に要約（平均・中央値・±2%以内の割合）。見込みの前月比と実際の前月比の向き・相関。過去の年の平均の外れで見込みを補正したときの誤差 | `src/a277_forecast_accuracy.py` |

## 主な結果
- 製造工業の実現率は、2018年2月〜2026年10月の調査のうちコロナの時期（2020年1月〜2021年3月）を除く90か月で、平均−2.8%、中央値−2.6%。実績が見込みを下回った月が94%、±2%以内に収まった月は36%
- 13業種すべてで平均がマイナス。いちばん大きいのは生産用機械工業の−5.7%（±2%以内は18%）、次が電気機械工業−5.0%。いちばん小さいのは鉄鋼業の−0.4%（±2%以内72%）
- 前の月の調査で答えた当月の前月比（見込み）は90か月の90%でプラスだったが、実際の前月比がプラスだったのは41%。向きが合ったのは50%。ただし見込みと実際の前月比の相関は0.74で、見込みがマイナスだった8か月はすべて実際もマイナスだった
- 前月比の誤差（絶対値の平均）は、見込みをそのまま使うと3.0%、「前の月と同じ（前月比0）」と置くと2.2%。過去の年の平均の外れ（実現率の平均）だけ見込みを下げると1.7%（66か月、その時点で分かる値だけで補正）

## 頑健性
- コロナの時期を含めた105か月でも、製造工業の平均−2.8%、下回った月95%
- 年ごとの平均は2018年−2.4%、2019年−2.2%、2022年−4.7%、2025年−2.6%、2026年（10月調査まで）−2.0%で、どの年もマイナス
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致した

## 動かし方
```
pip install -r requirements.txt
cd src && python a277_forecast_accuracy.py
```

## データ
- `data/production_forecast_survey.csv`：`b2020_ygzosm1je.xlsx`（製造工業生産予測指数 業種・財別 月次 原指数・季節調整済）を縦長にしたもの。列は前月実績・当月見込・翌月見込、それぞれの前月比、実現率、予測修正率（季節調整済と原指数）

## 注意
- 見込みは調査に答えた企業の生産計画で、景気の予想ではない。計画が実績より高く出やすいのは、計画どおりに作れなかった分や、注文が後ろにずれた分が入るから（推測）
- 経済産業省も、過去の傾向で見込みを補正した値を公表時に参考として示している。ここでの補正は、作成者が過去の平均だけで簡単に試したもの
- 実現率は「前月実績」の速報の値で計算されていて、後の改定は入っていない
- 業種によって見込みの対象品目は鉱工業指数より少なく、指数の動きは鉱工業指数の生産と完全には一致しない
