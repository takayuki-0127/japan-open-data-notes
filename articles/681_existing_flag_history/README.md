# 681 「有効」フラグの立った商品だけで集計すると、廃番になった商品の過去の売上はどれだけ消えるのか（実務の型）

商品マスタには、いま売っている品かどうかを表す「有効」フラグ（is_active）がよくあります。売上を集計するときに `WHERE is_active = 1` で絞ると、いまは廃番の品の、売っていた頃の売上まで消えます。マスタは集計した時点のものなので、昔の月ほど多く消え、前年比は実際より高く見えます。**ここでは、作成者が乱数で作った架空の商品マスタ（275品、うち72品が途中で廃番）と3年分の月ごとの売上で、フラグで絞る・期間つきで絞る・絞らないの3通りを比べました。** 数字は置いた廃番の割合と売上で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A681 | フラグで絞ると、過去の売上はどれだけ消えるか | 2023年1月に200品。毎年その時点の品の約12%が年の途中で廃番、新しい品が毎年25品。廃番が近い品は最後の6か月で売上が落ちる。廃番の品の20%は、廃番の後1〜2か月だけ在庫処分の売上がある。マスタは2025年12月末の時点。フラグ（is_active = 1）・期間（売上の月が valid_from〜valid_to の間）・絞らないの3通り。seed 681。DuckDB の SQL でも出して一致を確認 | `src/a681_flag.py`、`src/02_flag_duckdb.sql`、`src/01_flag_tsql.sql` |

## 主な結果
- **フラグで絞ると、消えた売上は2023年27.3%、2024年16.3%、2025年5.2%**。月ごとでは2023年1月の33.0%から、2025年12月の0.3%まで、集計の時点に近いほど小さくなる
- **前年比は、本当の2024年+14.5%・2025年+1.9%が、フラグで絞ると+31.9%・+15.4%に見えた**
- 期間つきで絞ると、前年比は+14.5%・+1.8%で、ほぼ本当の値。ただし廃番の後の在庫処分の売上206万円（3年の売上の0.06%）は落ちる
- 年ごとの売上の合計を知りたいときは、マスタで絞らずに集計するのが本当の値

## 動かし方
```
pip install -r requirements.txt
cd src && python a681_flag.py
```
数秒で終わります。`data/products.csv`・`data/sales.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダで流し直し、results・figures・data がバイト単位で一致した
- 3通りの年ごとの売上が、Python と DuckDB の SQL で一致すること

## データ
- `data/products.csv`：架空の商品マスタ（product_id・product_name・valid_from・valid_to・is_active）。2025年12月末の時点。valid_to が空の品はいまも売っている
- `data/sales.csv`：架空の月ごとの売上（month・product_id・amount＝万円）

## 注意（言えないこと）
- 架空のデータ。廃番の割合・新しい品の数・売上の形は作成者が置いたもので、結果はこれで決まる
- 消える割合は、廃番の多さと、集計の時点からどれだけ離れているかで変わる
- 「いま売っている品だけの推移」を見たい場合は、フラグで絞るのが目的に合う。ここで比べたのは全体の売上
- マスタの属性（分類や価格）が途中で変わる場合は扱っていない（551）。T-SQL 版は未検証
