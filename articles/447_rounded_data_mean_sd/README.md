# 447 5歳刻みや千円単位に丸めたデータから出した平均とばらつきは、元のデータとどれだけ違うのか（手法の解説）

階級にまとめられたデータから、**階級の真ん中の値で平均と標準偏差を出したとき、元のデータからどれだけずれるか**を、元の値が分かっている架空のデータで測ったフォルダです。分布の形3通りで、刻みの幅を変え、シェパードの補正（分散から 幅²÷12 を引く）が効く場面と効かない場面を分けました。F115（公表値から分布を戻す）と近いですが、丸めの影響に絞っています。

## 置いたこと（架空）
- 形①山が真ん中：正規分布（平均45歳・標準偏差12歳）。階級の区切りの位置は毎回ずらす
- 形②右に裾が長い：対数正規分布（中央値3,000円、対数の標準偏差0.8。平均約4,130円・標準偏差約3,910円）。0円から区切る
- 形③0の近くがいちばん多い：指数分布（平均2,000円）。0円から区切る

- 満年齢（切り捨て）の5歳階級の代表の値：22歳（階級の下限＋2）で計算すると平均44.5歳、22.5歳で45.0歳（本当は45.0歳）
- いちばん上の階級が「〜以上」（上位5%をまとめる、千円刻み）：②で、ほかと同じ幅とみなすと平均−5.1%・標準偏差−23.4%、下限の1.5倍とみなすと+0.5%・−4.0%（本当の平均は下限の1.46倍）。③は−1.0%・−12.5%と+4.4%・+5.0%（同1.31倍）
- 件数が少ないとき（年齢・5歳刻み）：丸めのずれ+0.7%に対し、標準偏差そのものの振れは50件で10%、200件で5%、1,000件で2.3%、1万件で0.7%

## 確かめたこと
- 空のフォルダで計算し直し、data・results・figures が一致した
- 正規分布では、標準偏差のずれが式 √(1＋(幅÷標準偏差)²÷12)−1 と合う（幅が標準偏差の2倍まで）
- 幅を小さくすると（年齢1歳、金額100円）、どの形でもずれは0.03%以下

## 注意（言えないこと）
- 架空の数字です。分布の形と階級の区切り方で、ずれの大きさは変わります
- 金額の階級は0円から区切りました。区切りの位置を動かしたのは、山が真ん中の形だけです
- 「〜以上」の階級は、2通りの置き方を比べただけです。裾の形を当てはめる方法は試していません
- 階級の人数から元の分布を当てはめ直す方法は扱っていません（F115）
- 実際の統計表について、どの階級幅なら十分かを言うものではありません
