# 593 開店と閉店がある期間で、「1店あたりの売上」を月末の店数で割るか営業日数で割るかで、どれだけ違うのか（実務の型・分母の取り方）

チェーンの月次資料でよく見る「1店あたりの売上」は、分母の店数をどう数えるかで値が変わります。月の途中で開いた店・閉じた店は、その月の一部しか営業していないからです。**ここでは、架空のチェーン（120店、3年間で40店が開店・25店が閉店）の日次売上で、①月末の店数、②月初と月末の店数の平均、③営業日数（店×日）の3つの分母で1店あたりの月の売上と前年同月比を出し、比べました。** 開閉店の時期・店の売上の水準・新店の立ち上がりは作成者が置いたもので、数字はその仮定で決まります。残った店だけで比べる「既存店」の考え方とは別で、ここでは全店の数字の分母だけを扱います。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A593 | 分母の取り方で、1店あたりの月の売上と前年同月比はどれだけ違うか | 全店の月の売上を、①月末に営業している店数、②月初と月末の店数の平均、③その月の営業日数の合計（店×日）÷月の日数、の3つで割る。③との差（%）と、前年同月比の差（ポイント）を月ごとに出す。店数・営業日数・3つの値を DuckDB（1スレッド）の SQL と Python で突き合わせ。seed 593 | `src/a593_per_store.py`、`src/02_per_store_duckdb.sql`、`src/01_per_store_tsql.sql`（未検証） |

## 主な結果
- 120店（期間の初めに80店、2023〜2025年に40店が開店・25店が閉店）。2024年10月25日に12店をまとめて開店、2025年3月31日に8店をまとめて閉店
- **営業日数で割った値との差**：月末の店数で割ると −9.0%〜+9.0%（36か月の中央値は絶対値で0.53%）、月初と月末の平均で割ると −3.1%〜+4.3%（同0.14%）
- **まとめて開店した2024年10月**：月末の店数（98店）で割ると −9.0%、平均で割ると −3.1%。月の終わりの7日しか営業していない12店が、まるごと分母に入るため
- **まとめて閉店した2025年3月**：閉店日まで売上はあるのに月末の店数（89店）には入らないので、月末の店数で割ると +9.0%、平均で割ると +4.3%
- **前年同月比**（2024〜2025年の24か月）：営業日数で割った値との差は、月末の店数で最大10.2ポイント（2025年10月：+11.2% 対 +1.0%）、平均で最大3.8ポイント。増減の向きが逆になった月は、月末の店数で4か月、平均で3か月
- 2024年10月の前年同月比：月末の店数 −7.4%、平均 −2.0%、営業日数 +0.8%

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures がバイト単位で一致した（DuckDB は `SET threads=1`）
- 月ごとの月末の店数・月初の店数・営業日数と、3つの1店あたりの値が、Python と DuckDB の SQL（`02_per_store_duckdb.sql`）で36か月すべて一致した
- T-SQL 版（`01_per_store_tsql.sql`）は書いたが、SQL Server では動かしていない（**未検証**）

## データ
- 店ごとの1日の売上の水準は対数正規（中央値30万円）。季節の動き（12月が高く2月が低い）と、年2%の伸びを置いた
- 開店から3か月は売上が控えめ（75%から100%へ上がる）
- 閉店日はその日まで営業。営業していない日は行がない
- 「営業日数で割る」は、その月に営業した店×日の合計で売上を割り、月の日数をかけて「1店が1か月営業した場合」にそろえた値

## 注意（言えないこと）
- 架空のデータ。実際のチェーンの売上ではない
- ずれの大きさは、月の途中の開閉店の数と時期で決まる。開閉店が少ない月はどの分母でもほぼ同じ
- 営業日数で割った値にも、新店の立ち上がりの低さは入っている。店の実力の伸び（ここでは年2%）を見たいなら、既存店で比べるなど別の工夫がいる
- 経営判断や出店・閉店の助言ではない
