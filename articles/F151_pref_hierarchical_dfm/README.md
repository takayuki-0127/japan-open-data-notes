# F151 47都道府県の時系列の「同じ動き」は、いくつに分けられるか？（階層型の動的因子モデル）

看板記事 F151。note：「47都道府県の求人倍率の『同じ動き』は、いくつに分けられるか？…」（公開後に記入）

## 問い

47都道府県の有効求人倍率は、毎月それぞれ上がったり下がったりする。その動きは、

- 全国に共通する動き
- 地方（関東・近畿など）に共通する動き
- その県だけの動き

に分けると、それぞれどれくらいの大きさか。全国の動きを除いた残りは、地方の区分どおりにまとまるのか。データから分けると、いくつのまとまりになるのか。

## データ

| データ | 出典 | 使った系列 | 期間 |
|---|---|---|---|
| 一般職業紹介状況 長期時系列表11（都道府県・受理地別） | 厚生労働省（e-Stat） | 有効求人数・有効求職者数（季節調整値）。主な分析は、この2つから求人倍率を計算し直したもの。ほかに公表の有効求人倍率・新規求人倍率（季節調整値） | 1963年1月〜2026年9月（分析は1990年2月〜） |
| 一般職業紹介状況 長期時系列表18（都道府県・就業地別） | 厚生労働省（e-Stat） | 有効求人数（季節調整値） | 2005年2月〜2026年9月 |
| 鉱工業指数（全国） | 経済産業省 | 鉱工業生産（季節調整済）。F42 で取得したもの | 1978年1月〜2026年8月 |

- `data/raw/f151_jobs_pref.json`：e-Stat の Excel から、使うシートを CSV 文字列にしたもの（2026-11-03 取得）。
- `data/*_sa.csv`：02 で整えた「月×都道府県」の表。

**公表の有効求人倍率を使わなかった理由**：公表値は0.01倍に丸められているため、月々の変化（1%前後）に丸めの誤差が乗る。そこで、有効求人数÷有効求職者数を計算し直した。公表値でも結果はほぼ同じ（頑健性を参照）。

## 方法

1. **変数**：求人倍率の対数の前月差（×100、ほぼ前月比%）。47県×440か月（1990年2月〜2026年9月）。県ごとに標準化した。
2. **動きの数**：相関行列の固有値。Ahn–Horenstein の固有値比（ER）と、Bai–Ng の情報量基準（ICp2）で因子の数を選んだ。
3. **階層型の動的因子モデル**：各県の動きを「全国の因子＋その県が属する地方の因子＋県だけの部分（AR(1)）」に分けた。因子は AR(1)。地方は次の7つ。
   - 北海道・東北（7道県）、関東（7）、中部（新潟〜愛知の9）、近畿（三重〜和歌山の7）、中国（5）、四国（4）、九州・沖縄（8）
   - 北海道は1道だけで地方の因子を作れないので、東北と合わせた。
   - statsmodels の `DynamicFactorMQ`（EM 法）で推定した。県ごとに、全国の成分で説明できる割合（R²）と、地方の成分を足して増える割合を求めた。
4. **データから分ける**：
   - 第1主成分（全国の動き）を除いた残りの相関を、県の組み合わせ1,081組で計算した。
   - 「1−相関」を距離にして階層クラスタリング（群平均法）にかけ、2〜12個に分けた。
   - それぞれの分け方を、シルエット係数と、7地方との一致度（調整ランド指数 ARI）で評価した。
   - 残りの相関と、県庁所在地どうしの距離の関係も見た。
5. **時期による違い**：10年の窓を1年ずつずらし、第1主成分の説明割合を計算した。
6. **全国の因子と生産**：全国の因子を、全国の鉱工業生産の前月比と比べた。

## 結果

### 1. 動きは、ほぼ「1つ」

第1主成分が47県の動きの **51%**（1か月の変化）を説明した。3か月の変化では68%、12か月の変化では84%。2番目以降は、どれも3%前後で横ばいだった。ER はどの変化の取り方でも1因子を選んだ。ICp2 は、1か月の変化では1、3か月では3、12か月では5を選んだ。

### 2. 県ごとの分け方：全国53%、地方6%、県だけ37%（中央値）

| | 全国 | 地方 | 県だけ |
|---|---|---|---|
| 47県の中央値 | 53% | 6% | 37% |
| 47県の平均 | 50% | 9% | 42% |

- 全国の割合は県によって18%〜80%と幅があった。
- 地方ごとの中央値は次のとおり。全国の割合が高いのは近畿・中部・関東で、低いのは四国・九州・沖縄・北海道・東北。地方の動きが比較的大きいのは関東と北海道・東北で、中部と近畿ではほとんどなかった。

| 地方 | 全国 | 地方 | 県だけ |
|---|---|---|---|
| 北海道・東北 | 41% | 12% | 41% |
| 関東 | 58% | 15% | 34% |
| 中部 | 62% | 2% | 34% |
| 近畿 | 65% | 3% | 35% |
| 中国 | 56% | 6% | 31% |
| 四国 | 34% | 9% | 58% |
| 九州・沖縄 | 35% | 4% | 49% |

県ごとの値は `results/decomp_main.csv`。この記事は、県の良し悪しを比べるものではない。

### 3. 全国の動きを除くと、近い県ほど一緒に動く。ただ、まとまりは弱い

- **残りの相関と距離**：同じ地方の県どうしは平均 +0.057、違う地方どうしは −0.034。県庁所在地の距離で見ると、次のとおり近いほど高かった。

| 県庁所在地の距離 | 残りの相関（平均） |
|---|---|
| 100km以内 | +0.081 |
| 100〜200km | +0.021 |
| 200〜300km | −0.021 |
| 500km超 | −0.05 前後 |

- **いちばん相関の高い相手**：47県のうち66%で同じ地方の県だった。その相手との距離は中央値129km。
- **データから分けた場合**：シルエット係数は2〜12個のどれでも0.06〜0.07で、はっきりした区切りはなかった。7地方との一致度（ARI）は、7〜8個に分けたときに最大で0.36。
- **7個に分けたまとまり**：地理の区分とは一部ずれる。南関東は大阪・兵庫と、北関東は長野・東海・三重と同じまとまりに入った。
  1. 埼玉・千葉・東京・神奈川・大阪・兵庫
  2. 茨城・栃木・長野・岐阜・静岡・愛知・三重
  3. 北海道・東北6県・新潟
  4. 群馬・石川・福井・山梨・滋賀
  5. 富山・和歌山・香川・愛媛・高知・佐賀・長崎・宮崎・鹿児島
  6. 福岡・熊本・大分・沖縄
  7. 京都・奈良・中国5県・徳島

  なぜこう分かれたのかは、このデータからは分からない（大都市圏や、製造業の多い地域がまとまっているように見えるのは推測）。

### 4. そろって動く度合いは、時期によって大きく変わる

10年の窓での第1主成分の割合は、次のとおりだった。

| 10年の窓 | 第1主成分の割合 |
|---|---|
| 1980〜89年 | 24% |
| 1990〜99年 | 40% |
| 2000〜09年 | 57% |
| 2008〜17年 | 62% |
| 2010〜19年 | 35% |
| 2016〜25年 | 54% |

大きな共通のショック（2008〜09年の世界金融危機、2020年のコロナ）を含む窓で高く、含まない2010年代の窓で低い。2番目の動きは、どの窓でも4〜6%だった。

### 5. 全国の因子は、生産と一緒に動く

全国の因子と、全国の有効求人倍率の前月比との相関は0.97だった。鉱工業生産の前月比との相関は、同じ月で0.31、生産が1か月先のときに0.37で最大になった。3か月平均どうしでは0.48。2009年と2020年の落ち込みは両方に出ている。

## 頑健性

| 条件 | 全国（中央値） | 地方（中央値） |
|---|---|---|
| 基本（1か月の変化、7地方、AR(1)） | 53% | 6% |
| 因子の AR 次数を2 | 53% | 6% |
| 10地方に分ける | 54% | 8% |
| 3か月の変化 | 72% | 4% |
| 公表の有効求人倍率（0.01倍に丸め） | 52% | 5% |
| 新規求人倍率 | 21% | 9% |
| 有効求人数だけ（受理地、2005年3月〜） | 48% | 7% |
| 有効求人数だけ（就業地、2005年3月〜） | 54% | 6% |
| 1990〜2007年 | 45% | 8% |
| 2008〜2026年 | 62% | 8% |
| コロナ期（2020年3月〜22年3月）を欠測にする | 50% | 6% |

- どの条件でも、地方の割合は4〜9%で、全国の割合よりずっと小さかった。
- 新規求人倍率は、月々のぶれが大きく、全国の割合が下がった。
- 分け方（クラスタリング）を3か月の変化やウォード法で行っても、シルエット係数は0.06〜0.11、7地方との ARI は最大0.23〜0.35だった。はっきりしたまとまりはない、という結論は同じ。

## 言えないこと

- **求人倍率に限った話**：設計では鉱工業指数の都道府県別も使う予定だった。ただ、都道府県別の月次の鉱工業指数は各県が別々に公表していて、47県分をそろえられなかった。そのため、生産の側は全国の指数との比較にとどめた。
- **地方は1段だけ**：地方の区分は7つ（頑健性で10）に決め打ちしている。地方の中のさらに細かい階層や、地方を越えたまとまり（大都市圏など）はモデルに入れていない。
- **受理地別の数字**：有効求人数は、求人を受け付けたハローワークの県で数えている。働く場所の県（就業地別）では2005年以降しか比べていない。
- **変化の大きさは比べていない**：割合は、県ごとに標準化した変化の分散の中での割合。県の動きの大きさそのものや、求人倍率の水準の差は比べていない。
- **時期による違いの理由**：同調の度合いが時期で変わるのは、大きなショックがあったかどうかによると考えられる（推測）。統計の作り方の変更（ハローワークの統合など）の影響は分けられていない。
- 県どうしの動きの因果（どの県が先に動くか）は見ていない。
