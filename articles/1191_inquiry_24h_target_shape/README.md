# 1191 「24時間以内に返事」の目標を置くと、返事までの時間の分布はどう形を変えるのか？（問い合わせ対応）

問い合わせ窓口に「24時間以内に返事」の目標を置くと、担当は締め切りの近いものを先に片付けるようになります。すると、すでに24時間を過ぎてしまったものは、急いでも目標の数字が良くならないので後回しになりがちです。目標の達成率は上がっても、返事までの時間の分布は、目標の線の前後で形を変えると考えられます。**ここでは、作成者が置いた架空の会社の問い合わせ窓口（交代で24時間受ける、担当4人。1日に来る数の波と1件の対応時間のばらつきを作成者が置いたもの）で、同じ問い合わせの列を ①来た順、②24時間を過ぎていないものを来た順に・過ぎたものは後回し、③②に加えて締め切りまで余裕があるうちは軽いものから、の3つの取り方で片付け、返事までの時間の分布を比べました。仕事の量・来る日の波・対応時間のばらつきを変えた27通りも確かめました。**

②③で24時間以内の割合が上がり、過ぎた件がより長く待つという向きは、取り方の決まりから出る作りどおりの結果です。数えたのは、その大きさと、分布のどこが膨らみどこが縮むかです。例の窓口は架空のもので、実在の会社・問い合わせ管理の仕組みを表すものではありません。目標の置き方や担当の働き方の良し悪しを言う記事ではありません。

関連する記事：1016「スコアを狙って動くと、スコアと本当の良さはずれていくのか？」は、スコアを評価に使い始めると、スコアに寄せる動きで本当の良さとの結びつきが弱まることを、架空の店で数えています。この記事は、問い合わせ窓口の「24時間以内」という1本の線を目標にしたとき、返事までの時間の分布の形がどう変わるかに絞ります。同じ企画の 1190「自動の受付返信を「初めの返事」に数えると、初めの返事までの時間はどれだけ縮んで見えるのか？」は、担当の動きは同じまま、数え方だけで24時間以内の割合が上がって見える場面を扱っています。

## 主な結果

### 基本の置き方（2,880日分、`results/a1191_main.json`）
| | ①来た順 | ②過ぎたものは後回し | ③余裕があれば軽いものから |
|---|---|---|---|
| 24時間以内 | 79.61% | **94.01%** | **93.66%** |
| 平均 | 20.51時間 | 20.24時間 | 18.73時間 |
| 中央値 | 3.21時間 | 2.51時間 | 1.02時間 |
| 90%点 | 56.29時間 | 22.08時間 | 22.83時間 |
| 99%点 | 279.64時間 | **511.52時間** | 510.22時間 |
| いちばん長い | 314.5時間 | 1,662.2時間 | 1,661.7時間 |
| 20〜24時間 | 2.24% | 6.4% | **10.27%** |
| 24〜28時間 | 1.57% | 4.05% | 4.39% |
| 48時間超 | 11.69% | 1.9% | 1.89% |
| 24時間を過ぎた件の平均 | 83.28時間 | **251.7時間** | 238.93時間 |

- **24時間以内は、①79.61%から②94.01%・③93.66%に上がった。一方で、24時間を過ぎた件の平均は83.28時間から251.7時間（②）・238.93時間（③）に延び、99%点も279.64時間から511.52時間に延びた**
- ②の平均は20.24時間で、①の20.51時間とほぼ同じだった。②は順番を入れかえるだけで、仕事の量も担当の数も変わらないため（作りどおりに近い。27通りでも②と①の平均の差は−3.64〜+2.71%）
- 分布の形は、目標の線の前後で変わった（図1、`results/hist.csv`）。①は0時間から長い裾までなだらかに減るが、③では20〜24時間の区分が2.24%から10.27%に膨らみ、24時間の手前に2つ目の山ができた。②の山は22〜26時間（4.12%・3.82%）で、24時間をわずかに過ぎる件も増えた（手を付けたのが24時間の手前で、対応を終えたのが過ぎてから）。26時間から先は②③とも①より少なかった
- ①で24時間を過ぎた件のうち70.61%は、②では24時間以内に返事が届いた。その分、②で過ぎた件は、後回しのまま長く待った
- ③では、軽いもの（対応時間の短い3/4）の24時間以内は94.98%、重いもの（長い1/4）は89.71%だった（①の重いものは79.1%）。重いものの16.91%が20〜24時間に入った
- ③の中央値は1.02時間と①（3.21時間）より短かった。軽いものを先に片付けるので、多くの件はすぐ返事が届く

### 確かめ：置き方を変えると（27通り、各1,440日分、`results/grid.csv`）
- **27通りすべてで、②③の24時間以内は①以上だった**（①43.81〜99.7%、②81.86〜99.89%、③81.74〜99.87%。②の上がり幅は+0.16〜41.45ポイント）
- **③の20〜24時間の割合は、27通りすべてで①より大きかった**（①0.13〜4.61%、③0.69〜15.97%）
- ①で24時間を過ぎる件が0.5%以上ある25通りでは、**25通りすべてで、24時間を過ぎた件の平均が②③のほうが長かった**（②は①の1.974〜4.009倍）
- 99%点が②で①より長くなったのは25通りのうち16通りだった（②÷①は0.331〜5.498倍）。過ぎる件が少ない置き方では、99%点は24時間の手前に収まり、①より短くなった
- ②と①の平均の差は−3.64〜+2.71%、③は①より2.82〜36.68%短かった
- ③の「締め切りが近い」とみなす残り時間を2・4・8時間に変えると（`results/buffer.csv`）、20〜24時間の割合は5.79%・10.35%・6.8%、24時間以内は93.25%・95.24%・95.59%だった

## 注意（言えないこと）
- 架空のデータです。来る数の波、対応時間のばらつき、仕事の量、担当の取り方は作成者が置いたもので、結果はこれで決まります。②③で24時間以内が上がり、過ぎた件が長く待つ向きは、取り方の決まりから出る作りどおりの結果です
- ②③は「過ぎたものは、過ぎていないものがなくなるまで手を付けない」と強く置きました。いちばん長い1,662.2時間は、この置き方から出たものです。実際の窓口では、過ぎたものもどこかで拾われると考えられ、裾はここまで長くならないかもしれません（推測）
- 窓口は交代で24時間受けると置き、営業時間・夜や休みの日のまとめ受けは入れていません。返事が遅れた人がもう一度問い合わせる動き、自動の受付返信も入れていません
- ③では担当が対応時間を前もって知っていると置きました。実際には見込みが外れるので、軽いものから選ぶ効き目はこれより小さいと考えられます（推測）
- 目標を置くべきかどうか、担当の働き方の良し悪し、人の評価には使えません
