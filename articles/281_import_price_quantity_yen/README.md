# 281 輸入は、どの品目で円安の影響を受けたのか

財務省「貿易統計」の統計品別表（輸入、9桁の統計品目番号、約8,000品目）で、2020→2025年の輸入額の増加を、品目ごとに「量」「ドルに直した単価」「為替（ドル円）」に分けたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A281 | 輸入は、どの品目で円安の影響を受けたのか | 品目ごとに 金額＝量×円の単価、円の単価＝ドルに直した単価×ドル円 と分け、対数平均（LMDI）の重みで足し合わせる（品目の和が増加額にぴったり合う）。概況品（5桁）と大分類にまとめる。2019年を起点にした場合・燃料を除いた場合も計算 | `src/a281_import_decomp.py` |

## 主な結果
- 輸入額は2020年68.0兆円 → 2025年113.3兆円（+45.3兆円、1.67倍）。ドル円の年平均は106.8円 → 149.6円（+40%）
- 両方の年に数量があり単位が同じ7,118品目（2025年の輸入額の89%）で分けると、増加39.8兆円のうち **量 −0.03兆円（ほぼ0）、為替 +26.5兆円（67%）、ドルに直した単価 +13.3兆円（33%）**。残りの5.6兆円は品目の新設・廃止（HS の改正など）や数量のない品目で、分けられない
- ドルに直した単価の上昇 13.3兆円の50%は鉱物性燃料（原油 +3.1兆円、石油ガス類 +1.8兆円、石炭 +1.0兆円）。燃料を除くと、増加28.9兆円のうち為替21.1兆円・ドル単価6.6兆円・量1.2兆円
- 増加額の大きい品目：原油及び粗油 +5.0兆円、石油ガス類（LNG・LPG）+2.9兆円、半導体等電子部品 +1.7兆円、事務用機器（パソコンなど）+1.7兆円、石炭 +1.6兆円、医薬品 +1.5兆円。上位10品目で増加の49%
- 2025年の輸入額で重みをつけると、ドルに直した単価が下がった品目は23%、そのうち円の単価は上がった（円安で円の値段だけ上がった）品目が20%。単価の変化の中央値は円で+67%、ドルで+19%
- 量が減った品目は2025年の輸入額の55%

## 頑健性
- 2020年はコロナと原油安で輸入が少ない年。2019年を起点にすると、増加29.7兆円（分けられる品目）のうち量 −7.4兆円、為替 +26.6兆円、ドル単価 +10.4兆円で、「量は増えず、為替の分がいちばん大きい」は同じ
- 燃料を除いても為替の分が7割（上の数字）
- コードは新しいフォルダで2回動かし直し、results と figures のすべてのファイルが一致することを確かめた

## 動かし方
```
pip install -r requirements.txt
cd src && python a281_import_decomp.py      # data/ から results/ と figures/ を作る
python fetch.py                              # data/ を e-Stat・日本銀行 API から作り直す（任意）
```

## データ
- `data/imports_hs9_2019_2020_2025.csv`：統計品別表（輸入、1-12月）の品目番号・単位・数量・金額（千円）。e-Stat の statInfId は `src/fetch.py`
- `data/hs9_to_gaikyo_import.csv`：9桁の品目番号を、概況品コード表（2025年）の範囲に入るいちばん細かい概況品に割り当てた表（作成者が作成、99.8%の品目に割り当て）
- `data/usdjpy_annual.csv`：ドル円（東京市場 17時時点 月中平均）の年平均。日本銀行 時系列統計データ（FM08、FXERM07）。このリポジトリの [F282](../F282_yen_exports_quantity_price) で取得したもの
- `src/tradecodes.py`：e-Stat・税関のページからの取得と、コード表の読み込み

## 注意
- 「為替」の分は、ドルに直した単価が変わらなくても円の単価が上がる分（ドル円の変化 × 金額）で、すべての輸入がドルで値決めされていると考えた場合の分け方。実際には円建て・ユーロ建てなどの輸入もあり、その分は為替の分を多めに見ていることになる（推測）
- 単価は「金額÷数量」の平均で、同じ品目番号の中の品質や中身の変化も含む。物価指数（輸入物価指数）とは作り方が違う
- 2022年の HS 改正などで品目番号が変わった品目は、両方の年にそろわず「分けられない分」に入る
- 為替の動きが量に与えた影響（円安で買う量が減ったかなど）は、この分け方では分からない
- 円安と物価の関係は [F210](../F210_prices_household_series_part2)、輸出の側は [F282](../F282_yen_exports_quantity_price) でも扱った
