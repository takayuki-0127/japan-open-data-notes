# 1258 確度70%以上の商談の金額だけを足した見込みは、確度を掛けて足した見込みと比べて、実績より多く出るのか少なく出るのか？（受注の見込み）

受注の見込みの出し方には、商談ごとの確度×金額を足す方法のほかに、「確度70%以上の商談の金額だけを足す」方法があります。後者は、70%以上の商談がすべて取れ、70%未満の商談は1件も取れないとみなす数え方です。実際には、70%以上の商談の一部は取れず、70%未満の商談の一部は取れます。どちらが多いかで、見込みが実績より多く出るか少なく出るかが決まります。**ここでは、作成者が置いた架空の会社の商談（1期40件、金額と記録の確度を作成者が決め、取れる・取れないを乱数で決めたもの）を5,000期作り、2つの見込みを期の実績と比べました。記録の確度の分かれ方（5通り）と、記録の確度が本当の確率どおりか・高すぎるか・低すぎるか（3通り）、しきい値（50・70・90%）を変えた45通りで確かめました。**

例の会社と商談は架空のもので、実在の会社や商談の記録は使っていません。見込みの立て方や目標の決め方の助言をする記事ではありません。

関連する記事：1257「確度を掛けて足した見込みの合計は、1件ずつ取れるか取れないかの振れで、期の実績とどれだけ外れるのか？」は、確度が正しいときに、確度を掛けて足した見込みのまわりで期の実績がどれだけ振れるかを扱っています。1259「「確度50%」と付けた商談のうち実際に取れた割合は、まだ決まっていない商談を除いて数えるとどう見えるのか？」は、記録の確度が当たっているかを確かめるときに、まだ決まっていない商談を除くと取れた割合がどう見えるかを扱っています。1267「見込みの良し悪しを、期の合計の外れで見るか、1件ずつの確度の当たりで見るかで、良い付け方は入れかわるのか？」は、確度の付け方の良し悪しを、期の合計の外れで見るか1件ずつの当たりで見るかで、良い順が入れかわることを扱っています。この記事は、確度で区切って金額だけを足す数え方が、どちらの向きにずれるかに絞ります。

## 主な結果

### 基本：確度が均等で、確度どおりに取れるとき（5,000期、`results/a1258_main.json`）
| 見込み | 偏り（見込みの平均÷実績の平均−1） | 見込みが実績より多かった期 | 1期ごとの外れ |
|---|---|---|---|
| ① 確度を掛けて足す | −0.89% | 48.84% | **16.16%** |
| ② 確度50%以上の金額 | +18.93% | 79.7% | 24.8% |
| ② 確度70%以上の金額 | **−20.82%** | 18.02% | 25.86% |
| ② 確度90%の金額 | −60.13% | 0.42% | 60.28% |

- **確度どおりに取れると置くと、70%以上の金額だけを足した見込みは、実績より平均で20.82%少なく出た**。式では0.8倍（−20%）。1期の平均で、70%未満の商談から取れた分は3,620.1万円、70%以上の商談で取れなかった分は1,541.2万円で、取れた分のほうが大きかった
- しきい値を50%に下げると、向きが逆になり+18.93%多く出た。区切りの位置で、多く出るか少なく出るかが入れかわった
- 1期ごとの外れは、確度を掛けて足した見込み（16.16%）がいちばん小さかった

例の1期（`data/example_quarter.csv`）では、確度を掛けて足した見込みが1億4,774万円、70%以上の金額が1億3,480万円、実績が1億3,120万円だった。70%未満の22件から取れた1,640万円と、70%以上の18件で取れなかった2,000万円が打ち消し合い、この期はたまたま70%以上の金額のほうが実績に近かった。また、確度50%のいちばん大きい商談（680万円）が70%に上がるだけで、70%以上の金額は680万円増えるが、確度を掛けて足した見込みは136万円しか増えない。

### 確かめ：確度の分かれ方と当たり方を変えると（しきい値70%、`results/grid.csv`）
| 記録の確度の分かれ方 | 確度どおり | 確度が高すぎる | 確度が低すぎる |
|---|---|---|---|
| 低い確度が多い | −56.26% | −40.65% | −70.49% |
| やや低い確度が多い | −37.79% | −15.47% | −54.35% |
| 均等 | −20.36% | +7.14% | −36.48% |
| やや高い確度が多い | −8.56% | +21.94% | −21.44% |
| 高い確度が多い | −1.26% | +30.93% | −12.88% |

（70%以上の金額だけを足した見込みの偏り。均等・確度どおりの−20.36%は、基本の−20.82%とは別に作り直した値）

- **確度どおりに取れると置くと、分かれ方5通りすべてで70%以上の金額は少なく出た（−1.26〜−56.26%）**。この5段階の置き方では、70%未満の商談から取れる分が、70%以上の商談で取れない分をいつも上回った
- 記録の確度が高すぎる（本当は0.75倍）と置くと、5通りのうち3通り（均等・やや高い確度が多い・高い確度が多い）で多く出た。確度を掛けて足した見込みも、この置き方では+33.04〜+34.08%多く出た
- 記録の確度が低すぎると置くと、5通りすべてで少なく出た（−12.88〜−70.49%）。確度を掛けて足した見込みも−11.34〜−32.7%少なく出た
- 偏りの値は、45通りすべてで式との差が1.2ポイント以内だった（作りどおり）

### 1期ごとの外れで、どちらが実績に近いか
- 確度どおりに取れる置き方では、しきい値50・70・90%の15通りすべてで、確度を掛けて足した見込みのほうが1期ごとの外れが小さかった（確度を掛けて足した見込みの外れは12.27〜23.84%）
- **70%以上の金額のほうが外れが小さかったのは、確度が高すぎる置き方の3通り（やや低い確度が多い・均等・やや高い確度が多い）だけだった**。確度を掛けて足した見込みが+33%ほど多く出る分を、70%未満を数えない分がたまたま打ち消した形
- 45通りで、しきい値で区切った見込みのほうが外れの小さかったのは7通りで、どれも記録の確度が本当の確率とずれている置き方だった

## 注意（言えないこと）
- 架空のデータです。確度の段階と分かれ方、金額の分布、確度の当たり方は作成者が置いたもので、偏りの向きと大きさはこれで決まります。偏りは式でも出せます（作りどおり）。新しく数えたのは、置き方ごとの向きの入れかわりと、1期ごとの外れの比べです
- 金額と確度は無関係と置きました。大きな商談ほど確度が低いといった関係があれば、偏りの大きさは変わります
- 「確度が高すぎる」「低すぎる」は、すべての段階で同じ割合だけずれる形だけを置きました。段階ごとにずれ方が違う場合は入れていません
- 見込みの立て方、目標の決め方、担当の評価には使えません
