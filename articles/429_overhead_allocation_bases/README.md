# 429 共通の費用を部門に配る基準を変えると、何部門の損益の符号が変わるのか（実務の型）

架空の会社（12部門、共通費3種類）で、共通費を配る基準（人数・売上・面積・使った時間）を変えたときに、部門の利益の符号と順位がどれだけ変わるかを数えたフォルダです。同じ置き方で架空の会社を2,000社作り、どれくらい起きるかも数えました。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A429 | 配る基準を変えると、黒字と赤字が入れ替わる部門はいくつあるか。それは共通費の大きさや、部門ごとの使い方の違いでどう変わるか | 4つの基準と2つの混ぜた基準で配ったあとの利益を Python で計算し、同じ SQL を DuckDB で実行して一致を確かめる。架空の会社を2,000社（設定を変えた比べは各1,000社）作って数える | `src/a429_alloc.py`、`src/01_allocate_tsql.sql`（T-SQL 版、未検証） |

## 主な結果
**1つの会社（seed 429。売上の合計55.7億円、配る前の利益の合計6.01億円、共通費3.61億円＝配る前の利益の6割）**
- 配る前は12部門すべて黒字。配ったあとの赤字の部門：人数1、売上1、面積1、使った時間3、費用ごとに基準を変える1、売上と人数を半々1
- **4つの基準のあいだで黒字と赤字が入れ替わる部門：4部門**（部門A・B・C・K）
- 部門B：人数 −4,881万円、面積 +2,061万円。部門A：面積 −1,839万円、ほかは +2,846万〜+3,586万円
- **順位が動く幅の最大：9**（部門Aは3位〜12位、部門Kは2位〜11位）。3つ以上動く部門は7部門
- 利益がいちばん多い部門は、どの基準でも部門E
- 基準どうしの順位相関：人数×売上0.86、売上×使った時間0.93、面積×使った時間0.01、売上×面積0.18

**架空の2,000社（同じ置き方）**
- 入れ替わる部門：平均4.62、中央値5。0部門の会社は2社、3部門以上の会社は93.2%
- 利益がいちばん少ない部門が基準で変わる会社：94.2%。順位相関の平均0.63

**設定を変えた比べ（各1,000社）**
| 共通費 ÷ 配る前の利益の合計 | 入れ替わる部門（平均） | 1部門以上で入れ替わる会社 |
|---|---|---|
| 10% | 0.25 | 22.4% |
| 20% | 0.62 | 50.2% |
| 40% | 2.35 | 95.9% |
| 60% | 4.67 | 99.8% |
| 80% | 6.47 | 100% |
| 100% | 7.57 | 100% |

- 部門ごとの使い方の違い（0＝全部門が売上に比例、1＝基本の設定）：0で平均0.04、0.5で2.61、1.0で4.55、1.5で5.49

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した
- DuckDB の SQL で出した配ったあとの利益（4つの基準と、費用ごとに基準を変える配り方）が、Python の計算と一致する（コード内の assert）

## データ
- `data/departments.csv`：架空の会社の12部門（売上・配る前の利益・人数・面積・システムを使った時間）
- `data/shared_costs.csv`：共通費3種類（本社費・施設費・システム費）
- どちらも作成者が乱数で作成（seed 429）

## 注意（言えないこと）
- 架空のデータ。入れ替わる部門の数は、共通費の大きさと部門ごとの使い方の違いの置き方で決まる
- どの基準が正しいかは扱っていない。部門の評価や、部門を残すかどうかの判断については何も言えない
- 段階のある配り方、端数の処理は試していない
- T-SQL 版は SQL Server 本体では動かしていない（未検証）
