# 538 0か1かの結果を線形回帰で当てると、確率が0〜1をはみ出す割合と、効果の推定はどれだけずれるのか（統計・回帰）

申し込んだか（1）・申し込まなかったか（0）のような結果を、ふつうの線形回帰でそのまま当てる「線形確率モデル」は、係数を「確率の差（ポイント）」としてそのまま読めるので、よく使われます。一方で、予測が0未満や1超になることがあります。**ここでは、架空の会員5,000人（案内を送ったか D は無作為に半分、利用の多さ x）で、本当の仕組みをロジスティックに置き、線形確率モデルとロジスティック回帰を当てて比べました。** x の効き方（c = 0.5・1・2）と全体の申し込み率（約5・20・50%）を変え、各場面200回くり返しています。数字は、置いた仕組みで決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A538 | 予測のはみ出しと、案内の効果の推定のずれ | 本当の仕組み logit P = a + 0.5·D + c·x。線形確率モデル（最小二乗）とロジスティック回帰（ニュートン法）。平均の効果（申し込み率の差）と、x の上下1割の層の効果を比べる。5,000人×200回、seed 538 | `src/a538_lpm_vs_logit.py` |

## 主な結果
- **はみ出す予測の割合**：x の効き方が強く、申し込み率が低いほど多い。c=2・約5% で **24.9%**（すべて0未満）、c=1・約20% で 7.9%、c=0.5・約50% で 0.0%
- **平均の効果はほぼ同じ**：9つの場面すべてで、線形の係数と本当の平均の効果の差は ±0.2ポイント以内。ロジスティックから出した平均の効果も同じくらい
- **端の層では離れる**：c=1・約20% で、本当の効果は x の下位1割で 1.6ポイント、上位1割で 12.0ポイント。線形の係数は 6.8ポイントで一律なので、下位1割では5.1ポイント大きく、上位1割では5.2ポイント小さい
- 差が最も大きいのは c=2・約5% の上位1割：本当の効果 9.1ポイントに対し、線形は 1.9ポイント（7.2ポイント小さい）
- ロジスティック（本当の仕組みと同じ形）は、どの層でも本当の効果とほぼ一致した

## 動かし方
```
pip install -r requirements.txt
cd src && python a538_lpm_vs_logit.py
```

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- どの場面でも、作ったデータの申し込み率が置いた値（5・20・50%）に合うこと
- 線形の係数（最小二乗）を numpy の lstsq で、ロジスティックをニュートン法で求め、ニュートン法が収束していること（変化 1e-10 未満）

## データ
- データファイルは置いていない。会員のデータはコードの中で乱数から作る（seed 538）

## 注意（言えないこと）
- 架空のデータ。実際のキャンペーンや会員の数字ではない
- 本当の仕組みをロジスティックに置いたので、ロジスティックが合うのは当然。本当の仕組みが別の形なら、結果も変わる
- D は無作為に割り当てた。D と x がつながっている（観察データ）場合は扱っていない
- どちらの手法を使うべきかを勧めるものではない。平均の効果を知りたいか、層ごとの効果や予測の確率を知りたいかで向き不向きが変わる
