# F115 01 取得

厚生労働省「国民生活基礎調査」（令和7年、所得・貯蓄）年次推移の4表を、e-Stat から CSV で取得した。
政府のサイトは作業環境から直接読めないので、ブラウザ（Chrome）で e-Stat を開き、ページの中で次のように取得して1つの JSON にまとめた（`data/raw/f115_kokumin_r7.json`、同梱済み）。

| キー | 表 | statInfId |
|---|---|---|
| t01 | 第1表 平均所得金額－平均世帯人員－平均有業人員，年次別 | 000040473360 |
| t02 | 第2表 世帯数の相対度数分布－累積度数分布，年次・所得金額階級別 | 000040473361 |
| t06 | 第6表 １世帯当たり平均所得金額－世帯人員１人当たり平均所得金額，所得五分位階級・年次別 | 000040473365 |
| t07 | 第7表 所得五分位値－中央値，年次別 | 000040473366 |

```js
// https://www.e-stat.go.jp/ を開いた状態で、開発者ツールのコンソールで実行
const getcsv = async id => { const b = await (await fetch('/stat-search/file-download?statInfId=' + id + '&fileKind=1')).arrayBuffer();
  return new TextDecoder('shift_jis').decode(b); };
const ids = {t01:'000040473360', t02:'000040473361', t06:'000040473365', t07:'000040473366'};
const o = {fetched: new Date().toISOString(), ids};
for (const [k, id] of Object.entries(ids)) { o[k] = await getcsv(id); await new Promise(r => setTimeout(r, 1500)); }
const a = document.createElement('a'); a.href = URL.createObjectURL(new Blob([JSON.stringify(o)], {type: 'application/json'}));
a.download = 'f115_kokumin_r7.json'; a.click();
```

`src/02_整形.py` が JSON の中の CSV を `data/raw/t01.csv` などとして使う（同梱済み）。年は「所得の年」（調査の前年）。令和元年（2019年）の所得は調査がない。
