# 1132 背景の色と照明が違うと、同じ商品の写真の色の数値はどれだけ動くのか？（画像と色）

同じ商品でも、白い布の上で撮るか黒い台の上で撮るか、暖かい色の照明か青白い照明かで、写真の上の色の値（0〜255の赤・緑・青）は変わります。カメラが明るさや色合いを自動で合わせると、合わせる手がかりに背景も入るので、商品は変わっていないのに商品の色の値が動きます。**ここでは、作成者が置いた架空の商品（色の板）40個を、5つの背景（灰色・白・黒・赤・青）×3つの照明（昼の光・暖かい光・青白い光）で写し、カメラの調整のしかた3通り（①自動、②固定（基準の条件で合わせたまま）、③商品の横に置いた灰色の板で毎回合わせる）で、商品の色の値がどれだけ動くかを数えました。写真の中で商品が占める割合と、背景から商品に映りこむ光の強さを変えた9通りでも確かめました。**

例の商品・背景・照明・カメラは、すべて作成者が式と乱数で置いたもので、実在の商品・カメラ・照明器具を表すものではありません。人の色の見え方は扱わず、写真の上の数値だけを数えます。

関連する記事：821「色の順番と強さで、どの数字が目立つかは変わるのか？」は、グラフで背景の色によって目立つマスが変わることを、置いた見え方の決まりで数えています。1061「同じ設定のつもりの2台で、速さはどれだけ違うのか？」は、同じつもりの条件の違いが比べたい差にまざることを処理の速さで扱っています。この記事は、写真の色の値そのものが背景と照明でどれだけ動くかに絞ります。同じ企画の 1134「1台の画面で合わせた色は、色の出方の違う別の画面でどれだけずれるのか？」は、写真の色の値は同じまま、見る側の画面の違いで見え方がどれだけずれるかを扱っています。この記事は写す側、1134 は見る側と書き分けます。

## 主な結果

### 調整のしかたごとの商品の色の動き（40個の平均、`results/summary_base.csv`）
| 調整のしかた | 背景だけ替える（昼の光、4つの背景の平均） | 照明だけ替える（灰色の背景、2つの照明の平均） | 両方替える（8通りの平均） |
|---|---|---|---|
| ①自動 | **67.72** | 2.23 | 67.84 |
| ②固定（基準で合わせたまま） | 3.73 | **24.61** | 24.74 |
| ③灰色の板で毎回合わせる | **0.15** | **3.23** | 3.22 |

- **自動の調整のままでは、背景を替えるだけで商品の色の値が平均67.72動いた**。照明だけを替えたとき（2.23）よりずっと大きかった。自動の調整は画面全体を手がかりに合わせるので、背景の色と明るさがそのまま商品の色に入る
- 背景ごとに見ると（①自動・昼の光）、白では商品が暗く写り（明るさ−24.24、色の差42.17）、黒では明るく写った（+46.51、82.52）。赤では色合いが大きく動き（色合いの動き66.72、色の差79.48）、青も同じ（55.87、66.69）。赤い背景では、画面全体を灰色にそろえようとして赤が弱められ、商品は青緑の側へずれた
- 自動の調整では、基準の条件（昼の光・灰色の背景）でも、灰色の板で合わせた写真と平均20.79違った。商品そのものの色も画面の平均に入るため（`results/a1132_main.json` の auto_vs_card_at_reference_condition）
- **調整を固定すると、背景の影響は3.73に減ったが、照明を替えると24.61動いた**。暖かい光で31.13、青白い光で18.09で、多くは色合いの動き（29.88・16.29）だった
- **灰色の板で毎回合わせると、背景の影響は0.15、照明の影響は3.23まで減った**。背景が白・黒（波長によらず一定）なら0（作りどおり）で、赤・青の背景で0.38・0.24残った。照明の影響が0にならないのは、灰色の板は3色の倍率しか合わせられず、照明の波長ごとの強さの違いが商品の色によって違う形で効くため。暖かい光では、いちばん動いた商品で8.87だった

### 確かめ：商品の占める割合×映りこみの強さ（9通り、`results/grid.csv`）
| 調整のしかた | 背景だけ替える | 照明だけ替える | 両方替える |
|---|---|---|---|
| ①自動 | **22.78〜116.83** | 1.38〜2.85 | 22.82〜117.12 |
| ②固定 | 0〜7.2 | 24.61〜24.61 | 24.61〜25.28 |
| ③灰色の板 | 0〜0.3 | 3.23〜3.23 | 3.22〜3.23 |

- **自動の調整で背景が効く大きさは、商品の占める割合で大きく変わった**。映りこみ0.10で、商品が10%なら114.12、25%なら67.72、50%なら23.47。商品が小さく写るほど、背景が合わせ方を決める
- 固定と灰色の板で背景が効くのは、映りこみの分だけだった。映りこみを0と置くと、どちらも0（作りどおり）。映りこみ0.20では、固定7.2・灰色の板0.3
- 固定と灰色の板の「照明だけ替える」は、9通りで変わらなかった（24.61・3.23）。灰色の背景からの映りこみは照明を一様に強めるだけで、倍率の合わせ方で消えるため（作りどおり）
- 9通りすべてで、自動は照明より背景を替えたときに大きく動き、固定は背景より照明を替えたときに大きく動いた。灰色の板は、どの替え方でも3.23以下だった

## 注意（言えないこと）
- 架空のデータです。商品・背景の返しやすさ、照明の強さ、カメラの感じやすさ、自動の調整のしかた（画面の平均を灰色にそろえる、真ん中を2倍重く見る）は作成者が置いたもので、結果はこれで決まります。とくに①自動の大きさは、自動の調整の置き方と、商品が写真に占める割合で大きく変わります
- 実在のカメラの自動の調整は、もっと込み入った決まりで動きます。この記事の①は、画面全体を手がかりにする簡単な決まりの一例です
- 色の差は、写真の上の値（0〜255）の差で数えました。人が見て感じる色の差とは一致しません。どのくらいの差なら見て分かるかは扱っていません
- 影・光沢・ピントのぼけ、写真の圧縮は入れていません
- どの撮り方を使うべきかは言えません。この記事は、置いた条件で色の値がどれだけ動くかを数えただけです
