# 534 アンケートの「その他」の自由記述を選択肢に振り直すと、各選択肢の割合は何ポイント動くのか？（実務の型）

架空のアンケート（「購入の決め手」を1つ選ぶ、回答2,000件）を作り、「その他」を選んだ人の自由記述に、既存の選択肢と同じ内容（「安かったから」など）と、どれにも当てはまらない内容を混ぜました。振り直す前、キーワードで振り直した後、人手で振り直した後の構成比を比べ、順位の入れ替わりと、キーワードの当たり外れを見たフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A534 | 「その他」を振り直すと、各選択肢の構成比は何ポイント動くか。キーワードと人手でどれだけ違うか | 自由記述をキーワード（上から順に当てる）で振り直す。人手の結果は、作成時に置いた正解の区分とみなす。キーワードでの振り直しを SQL（DuckDB）でも行い、Python と一致するか確かめる | `src/a534_other_recode.py`、`src/02_other_recode_duckdb.sql`、`src/01_other_recode_tsql.sql`（T-SQL 版、未検証） |

## 主な結果（2,000件、「その他」227件＝11.4%）
- **「その他」の割合**：振り直す前 11.4% → キーワード 8.2% → 人手 5.4%。人手で見ると、「その他」の半分強は既存の選択肢と同じ内容だった（そう作ったデータ）
- **人手で振り直したときの変化**：口コミ +2.7ポイント（12.3% → 15.0%）がいちばん大きく、価格 +0.9、店員の対応 +0.9、デザイン +0.8、品質 +0.6
- **キーワードで振り直したときの変化**：デザイン +1.2 がいちばん大きく、口コミは +0.9 にとどまる。人手との差は、口コミ −1.8ポイント、デザイン +0.5ポイント
- **キーワードと人手の一致**：「その他」227件のうち58%。外れの多くは「当たらない」もの（「友だちに勧められて」「家族が使っていて良いと言った」「SNSで見て」→ 口コミなのに「その他」のまま）
- **誤って当たる例**：「色々比べて家から近い店にした」が「色」に当たってデザインに入った（20件）。「値段は高いが丈夫」は、上から順に当てるため品質でなく価格に入った（1件）
- **順位**：このデータでは、振り直しの前後で5つの選択肢の順位は入れ替わらなかった。デザインと口コミの差は、前 2.9ポイント → 人手 1.0ポイントに縮んだ
- SQL（DuckDB）のキーワードでの振り直しは、Python と全件一致

## データ
- `data/fictional_survey.csv`：架空のアンケート（seed 534）。列は resp_id・choice（選んだ選択肢）・other_text（「その他」の自由記述）・manual_label（人手で振り直した先とみなす区分）

## 注意（言えないこと）
- 架空のデータ。選択肢の割合、「その他」に既存の内容が混ざる割合（55%）、自由記述の書き方は作成者が置いたもので、実際の調査の値ではない
- 人手の結果は「正解」として置いたもの。実際の人手の振り直しにも、人による揺れがある
- キーワードの一覧と順番は一例。一覧を足せば一致は上がるが、誤って当たる例も増えうる
- 複数回答の設問や、「その他」を分析から外す扱いは見ていない
- T-SQL 版は SQL Server 本体では動かしていない（未検証）
