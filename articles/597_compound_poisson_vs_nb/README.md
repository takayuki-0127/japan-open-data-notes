# 597 年間の総損害を件数×金額の複合分布で作るとき、件数の年ごとの揺れを無視すると、99.5%点はどれだけ小さく出るのか（手法の解説・保険数理）

1年の総損害は「件数」と「1件の金額」の組み合わせで決まります。件数をポアソン分布とみなすと、件数の散らばりは平均と同じ大きさしかありません。ところが実際の件数は、天候や景気などで年ごとに全体が上下することがあり、ポアソンより大きく散らばります。**ここでは、架空の損害（1件平均100万円・変動係数2の対数正規）で、件数をポアソン分布とみなした「複合ポアソン」と、年ごとの揺れを入れた「複合負の二項」（ポアソンの平均にガンマ分布の揺れをかけたもの）の年間の総損害の分布を FFT で計算し、99.5%点を比べました。** 件数の期待値（年20・100・500件）と揺れの大きさ（変動係数10・20・30%）を変えています。10年分の件数から揺れに気づけるかも調べました。数字は置いた前提で決まります。

## 主な結果
- **年100件・揺れ20%**：平均はどちらも1億円。99.5%点は複合ポアソン1億7,820万円、複合負の二項1億9,855万円。複合ポアソンは **10.2%小さい**。本当は揺れがあるとき、複合ポアソンの99.5%点を超える確率は0.5%ではなく **1.4%**
- **件数が多いほど不足が大きい**（揺れ20%）：年20件で3.2%、年100件で10.2%、年500件で21.7%小さい。年500件・揺れ30%では34.5%小さく、超える確率は16.2%
- 件数が少ないうちは1件の金額の散らばりが大きく効き、件数の揺れの影響は相対的に小さい。件数が増えると金額の散らばりは平均化されるが、年ごとの揺れは平均化されずに残る
- **10年分の件数で揺れに気づける割合**（5%水準）：年100件で揺れ10%なら48%、20%なら95%。年20件では揺れ20%でも40%。揺れがなくても約5%は「揺れあり」と出る
- **確かめ**：年100件・揺れ20%の20万年のシミュレーションで、99.5%点は1億9,836万円（FFT は1億9,855万円）。件数の分散÷平均は4.99（理論値は1 + 100×0.2² = 5）

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures がバイト単位で一致した（DuckDB は `SET threads=1`）
- 20万年のシミュレーションの99.5%点と件数の分散÷平均が、Python と DuckDB の SQL（`02_quantile_duckdb.sql`）で一致した
- FFT の99.5%点とシミュレーションの99.5%点の差は0.4%以内
- T-SQL 版（`01_quantile_tsql.sql`）は書いたが、SQL Server では動かしていない（**未検証**）

## 前提
- 1件の損害額は平均100万円・変動係数2の対数正規。件数と金額は独立
- 件数の揺れ：ポアソンの平均に、平均1・変動係数 c のガンマ分布をかけた（負の二項分布になる）。年ごとに独立
- 再保険、インフレ、支払の時期、1件の金額の年ごとの揺れは扱っていない
