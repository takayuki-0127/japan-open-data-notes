# 190 黄砂は西日本ほど多いのか：11地点の観測日を地点別に比べる

気象庁「黄砂のデータ集」の年ごとの「黄砂観測日および観測地点の表」から、1967〜2023年に黄砂を観測した768日について、どの地点で観測したかを1日ずつ並べ、11地点の観測日数を西から東へ比べたフォルダです。黄砂の年ごとの増減は [150_yellow_sand](../150_yellow_sand) で扱っていて、ここでは地点ごとの違いに絞っています。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A190 | 黄砂は西日本ほど多いのか。東日本で観測される日はどんな日か | 地点別の年平均観測日数と経度の相関、地点の組み合わせごとの同じ日の観測割合（条件付き割合の行列）、観測した日の全国の観測地点数、その地点だけで観測した日の割合 | `src/a190_stations.py` |

## 主な結果
- 年平均の観測日数は福岡7.5日、広島7.0日、鹿児島5.1日、高松4.9日、大阪4.6日が多く、東京0.8日、札幌0.7日が少ない。福岡は東京の9.5倍
- 気象台の経度と年平均の相関係数は那覇を除く10地点で−0.94、那覇を含めると−0.75。那覇（3.2日）は最も西にあるのに福岡の半分以下
- 東京で黄砂を観測した日には、広島でも78%、福岡でも69%の日で観測していた。逆に福岡で観測した日に東京でも観測したのは7%だけ。東日本の観測日は、西日本から広く覆われた日がほとんど
- 東京・仙台・札幌のどこかで観測した138日のうち75%は、鹿児島・福岡・広島のどこかでも観測していた
- 観測日の40%（304日）は1地点だけ。その地点だけで観測した日の割合は那覇35%、福岡23%、札幌24%と高く、名古屋（1%）や東京（4%）は低い

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a190_stations.py
```

## データ
| ファイル | 中身 | 元のページ |
|---|---|---|
| data/kosa_days_by_station.csv | 観測日、その日の観測地点数、11地点それぞれの観測の有無（1/0）。1967年1月〜2024年3月の768日 | 年ごとの「黄砂観測日および観測地点の表」 https://www.data.jma.go.jp/env/kosahp/kosa_table_YYYY.html |

- 1977/02/24 と 2010/03/21 は地点数11に対して地点名が10しか載っていなかったため、載っていない那覇を加えた（150と同じ補正）。地点ごとの年合計は150の `station_days_by_year.csv` と全年で一致
- 経度は各地点の気象台のおよその値

## 注意
- 観測は気象台の職員による目視で、2024年3月で終わっている。分析は1967〜2023年
- 観測日数は「黄砂が見えた日」の数で、黄砂の量（濃さ）ではない。雨や雲で見えない日は数えられない
- 11地点の比較で、地点の間の地域のことは分からない。那覇が少ない理由（風の通り道、季節、海からの距離など）はこのデータでは分けられない
