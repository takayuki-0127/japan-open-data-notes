# F183 車を持つ世帯は、どこで減りはじめたのか？

看板記事シリーズの183本目です。自動車検査登録情報協会（AIRIA）の「自家用乗用車の世帯当たり普及台数」を都道府県別に2005〜2026年の22年分読み取り、「減りはじめた年」を3つの測り方で決め、人口密度・鉄道・高齢化との関係を見ました。分母（世帯・人口・なし）と車種（軽四輪）を変えた確認もしています。

## 問い
- 自家用乗用車の世帯当たり台数は、どの都道府県で、いつ減りはじめたのか
- 減りはじめの早さは、人口密度や鉄道の多さと関係があるのか
- 減っているのは「車」なのか、それとも「分母の世帯」が増えただけなのか

## データ
| データ | 内容 |
|---|---|
| AIRIA 自家用乗用車の世帯当たり普及台数 | 全国1975〜2026年、都道府県2005〜2026年（各年3月末の台数÷住民基本台帳の世帯数）。2011年は岩手・宮城・福島なし |
| 全国軽自動車協会連合会 軽四輪車の世帯当たり普及台数 | 都道府県、12月末 2015〜2025年（3月末 2006〜2013年も一部） |
| SSDSE-E-2026・SSDSE-B-2026（統計センター） | 総人口、可住地面積、65歳以上割合、年度別の総人口（2012〜2023） |
| 国土数値情報 駅別乗降客数（S12） | 2024年（F03 のデータを再利用）。都道府県ごとに合計し人口千人あたりに |

## 手法
1. 全国：世帯当たり台数の変化を、台数の変化と世帯数の変化に分解（Δlog率＝Δlog台数−Δlog世帯）
2. 都道府県ごとに「減りはじめた年」を3通りで決める
   - 世帯当たり台数が最も高かった年
   - 折れ線（ヒンジ）回帰：率＝a＋b·t＋c·max(0, t−τ) の τ を2007〜2023年から最小二乗で選ぶ（直線との BIC の差も記録）
   - 台数そのものが最も多かった年
3. 2016→2026年の変化を、台数と世帯数に分ける
4. 人口密度（可住地あたり）・鉄道の乗降客数（人口千人あたり）・65歳以上割合との順位相関（並べ替え5,000回）と回帰（HC3）
5. 頑健性：τ の決め方（2014年の段差を入れる、2010年から当てはめる）、分母（世帯・人口・なし）、車種（軽四輪）、1県ずつ除く・大都市3都府県を除く

## 結果
- **全国**：世帯当たり台数は2006年の1.112台が最高で、2026年は1.001台（1996年以来の水準）。ただし台数そのものは2026年が過去最多（6,184万台）。2014〜2026年は台数が年0.35%増えたのに対し、世帯数が年0.95%増えた。
- **都道府県の「最も高かった年」**：23都道府県が2005〜2007年（うち10は集計の最初の2005年で、それ以前に最高だった可能性がある）、17県が2017〜2021年。2つの山に分かれた。
- **折れ線で見た減りはじめ**：37県が2017〜2021年、8都府県が2007〜2010年。6県は折れ線が直線よりはっきり良いとは言えない（BIC の差2未満）。最も高かった年との一致（±2年）は47中20。
- **台数そのもの**：2016→2026年に減ったのは9県だけ。17都府県は2026年が最多で、まだ増えている。
- **分解（2016→2026年、中央値）**：世帯当たり −4.0% ＝ 台数 +1.8% − 世帯数 +5.9%。世帯当たりの減少は、台数の減少ではなく世帯の増加でほぼ説明できる。
- **人口当たり**：2013→2024年に人口当たりの台数が増えたのは45県。減ったのは東京・神奈川だけ（それぞれ2013年・2014年が最高）。
- **鉄道・人口密度・高齢化**：最も高かった年と鉄道の乗降客数の順位相関は −0.81（並べ替え p&lt;0.001、大都市3都府県を除いても −0.77）。人口密度は −0.58、65歳以上割合は +0.74。3つを同時に入れた回帰では、どれもはっきりしない（重なりが大きく分けられない）。
- **軽四輪**：軽四輪車の世帯当たり台数は、2015→2025年に34県で増え、31県は2025年が最高。世帯当たりの減少は、主に登録車の側で起きている（推測：軽四輪には貨物も含まれるため）。

## 頑健性
| 確認 | 結果 |
|---|---|
| τ に2014年の段差（外国人世帯の算入）を入れる | 47中43で τ が±2年以内 |
| 当てはめを2010年からにする | 47中32で±2年以内 |
| 分母を人口にする | 45県で増加（世帯当たりの「減少」は分母の効果） |
| 分母なし（台数） | 38県で増加 |
| 軽四輪 | 34県で増加 |
| 相関を1県ずつ除く | 鉄道と最も高かった年の順位相関は −0.84〜−0.80 |

## 言えないこと
- **「車を持つ世帯の割合」は分からない**：この統計は「台数÷世帯数」で、1台も持たない世帯の割合ではない。複数台を持つ世帯が増えれば、持たない世帯が増えても率は下がらない。
- **市区町村の変化点は見ていない**：設計では市区町村も予定していたが、データを取れず都道府県で行った。
- **2005年より前は都道府県別に見ていない**：2005年が最高だった10都府県は、それ以前に減りはじめていた可能性がある。
- **鉄道・人口密度・高齢化の効果は分けられない**：47都道府県では、3つがほぼ同じ並びになる。どれが原因かは言えない。
- **鉄道の乗降客数は近似**：駅の都道府県を最寄りの地価公示地点で割り当て、乗り換え駅の重複も含む。
- **世帯数の定義の変化**：2014年から外国人世帯を含む。段差を入れた確認はしたが、県ごとの影響は完全には除けていない。
- 都道府県の順位づけや評価はしていない。
