# 1235 迷った件を「分からない」として除くと、残ったデータで作った分類はどれだけ易しい問題になるのか？（ラベル付け）

分類のラベルを付けるとき、どちらとも決めにくい件を「分からない」として除き、残った件だけで分類する仕組みを作って確かめることがあります。除かれるのは境目の近くの件なので、残った件は分けやすい件にかたよります。残った件で確かめた正しさは、実際に来る件（迷う件も含む）での正しさより高く出ます。**ここでは、作成者が置いた架空の問い合わせ文（件ごとの「返品の相談らしさ」と本当の分類、分類する仕組みが見る2つの手がかり、付け手の見え方のぶれを作成者が置き、乱数で作ったもの）で、残った件で確かめた正しさと、来る件全体での正しさがどれだけ違うか、除き方が上下で片寄るとどうなるかを数えました。除く幅・手がかりのぶれ・片寄りを変えた30通りでも確かめました。**

例の問い合わせ文・付け手・分類する仕組みは架空のもので、実在のラベル付けのやり方や分類の仕組みを表すものではありません。

関連する記事：866「途中でやめた人の回答を入れるか除くかで、結果は変わるのか？」は、アンケートで最後まで答えた人だけを使うと、満足の高い人にかたよって平均が高く出ることを数えています。1225「結果が0件の検索を数から外すと、検索の良さはどう見えるのか？」は、0件の検索語を外すと、見つけにくい語が分母から消えて検索の良さの見え方が変わることを数えています。この記事は、ラベルを付けるときに迷った件を除くと、分類の問題そのものが易しくなる点に絞ります。同じ企画の 1233「1件を3人で見て多い方の判定に決めると、1人で見るより正しくなるのは、どんなときか？」は3人の多い方で決める話、1234「付け手ごとの甘さ・辛さのくせは、見本の件でどこまで直せるのか？」は付け手のくせを見本の件で直す話です。1244「付け手の意見が割れた件を「難しい件」として別に数えると、分類の正解率の上限はどう見えるのか？」は、迷う件を除くのではなく、3人の意見が割れた件を「難しい件」として別に数えると、割れた件の正解率の上限が正解ラベルのまちがいで低く見えることを扱っています。どちらも、迷う件の扱い方で分類の成績の見え方が変わる場面です。

## 主な結果

### 基本の置き方（手がかりのぶれ1.0、各200回、`results/base.csv`）
| | 対称（境目の上下0.4を除く） | 片寄り（下0.4・上0.8を除く） |
|---|---|---|
| 「分からない」で除いた件 | 28.89% | 39.99% |
| ①残った件で、付けた分類と比べた正しさ | **87.36%** | **91.9%** |
| ②残った件で、本当の分類と比べた正しさ | 87.54% | 91.64% |
| ③来る件全体で、本当の分類と比べた正しさ | **81.13%** | **79.9%** |
| 除いた件だけでの正しさ | 65.46% | 62.2% |
| ④手がかりから出せる最善（残った件） | 87.57% | 90.74% |
| ④手がかりから出せる最善（来る件全体） | 81.15% | 81.12% |
| 除かずに作った仕組み：来る件全体で本当の分類と比べた正しさ | 81.13% | 81.08% |

- 対称に28.89%を除くと、残った件で確かめた正しさは87.36%、来る件全体では81.13%で、6.23ポイントの差があった。手がかりから出せる最善の正しさも、残った件では87.57%、来る件全体では81.15%で、**除いたことで、分類の問題そのものが6.42ポイント易しくなった**。境目の近くを除くので、残りが易しくなる向きは作りどおり
- 対称に除いても、仕組みの来る件全体での正しさ（81.13%）は、除かずに作ったとき（81.13%）と同じだった。除いて変わったのは、確かめた数字の見え方だった
- 片寄りで除くと、残った件での正しさは91.9%、来る件全体では79.9%で、差は12.0ポイントに広がった。来る件全体での正しさも、除かずに作ったとき（81.08%）より1.18ポイント下がった
- 残った件で付けた分類の誤り（本当の分類との違い）は、対称1.38%・片寄り0.83%だった。残った件では付け手の分類がほぼ正しいので、①と②はほぼ同じになる

### 分類の割合と、仕組みの確からしさ（`results/base.csv`）
| | 対称 | 片寄り |
|---|---|---|
| 本当の「返品の相談」の割合 | 40.05% | 39.91% |
| 残った件で付けた「返品の相談」の割合 | 37.52% | 25.97% |
| 仕組みが来る件全体で「返品の相談」と分けた割合 | 37.81% | **28.86%** |
| 同（除かずに作った仕組み） | 37.76% | 37.66% |
| 仕組みが出した確からしさの平均（来る件全体） | 84.97% | 88.24% |
| 同（除かずに作った仕組み） | 79.75% | 79.9% |

- 片寄りで除くと、「返品の相談」の近くの件が多く除かれ、残った件の「返品の相談」は25.97%に減った。その件で作った仕組みは、来る件全体の28.86%しか「返品の相談」と分けなかった（本当は39.91%）
- 残った件で作った仕組みは、来る件全体での確からしさを84.97%（片寄り88.24%）と出したが、実際の正しさは81.13%（79.9%）だった。除かずに作った仕組みは79.75%（79.9%）と出した。残った件では2つの分類が離れているので、仕組みの重みが大きくなり（重みの大きさ1.842、除かずに作ると1.257）、自信が強めに出た

### 確かめ：30通り（各30回、`results/grid.csv`）
- 除いた件の割合は7.37〜66.06%だった。①残った件で付けた分類と比べた正しさと③来る件全体での正しさの差は−0.5〜25.54ポイントで、30通り中29通りで①が上だった。下回った1通りは、除く幅が上下0.1と小さく手がかりのぶれも0.5と小さいとき（−0.5ポイント）だった
- 差は除く割合が多いほど大きく、片寄りでは対称より大きかった。手がかりのぶれごとの差は、0.5で−0.5〜16.59、1.0で0.36〜21.21、2.0で0.6〜25.54ポイントだった
- 手がかりから出せる最善の正しさは、残った件のほうが来る件全体より1.06〜17.46ポイント高かった（30通りすべて）
- 対称に除いた15通りでは、来る件全体での正しさは除かずに作ったときと−0.11〜+0.07ポイントの差で、ほぼ同じだった。片寄りの15通りでは、14通りで除かずに作ったときより下がった（−6.44〜+0.03ポイント）。仕組みが「返品の相談」と分けた割合は、片寄りで13.46〜37.63%、対称で32.86〜39.66%だった（本当は約40%）
- 仕組みが出した確からしさの平均は、30通り中28通りで実際の正しさより高かった（差は−1.15〜21.03ポイント）
- 除かずに作った仕組みを、付け手の分類（迷った件も「どちらかといえば」で付けたもの）と比べると、本当の分類と比べるより0.82〜3.25ポイント低く出た。付け手の分類にも誤りがあるため

## 注意（言えないこと）
- 架空のデータです。返品の相談らしさの分布、手がかりのぶれ、付け手の見え方のぶれ、除く幅は作成者が置いたもので、差の大きさはこれで決まります。境目の近くを除けば残りが易しくなる向きは作りどおりで、新しく数えたのは、その大きさと、片寄って除いたときに分類の割合と正しさがどうずれるかです
- 付け手は、分類する仕組みが見る手がかりよりよく分かる（見え方のぶれ0.3）と置きました。付け手も手がかりと同じ程度にしか分からない場合は入れていません
- 迷った件は、境目からの近さだけで決まると置きました。文が短い・読みにくいなど、境目と関係なく迷う件は入れていません
- 分類する仕組みは2つの手がかりの重み付きの和だけを扱いました。ほかの作り方では、確からしさの出方は変わります
- 迷った件を除くのがよいか悪いかは扱っていません。この記事が言えるのは、除いたときに、確かめた数字が何を表すかです
