# 666 見逃しと空振りのコストが違うとき、確率0.5で切るのと費用で決めた閾値では、損失はどれだけ違うのか（手法の解説・正解の分かるデータで試す）

確率を出すモデルで「陽性か陰性か」を決めるとき、0.5で切るのが既定になっていることがよくあります。けれども、見逃し（陽性を陰性と判定）1件のコストが空振り（陰性を陽性と判定）1件の r 倍なら、損失が最小になる閾値は 1/(1+r) です（確率が正しく出ている場合）。**ここでは、陽性が10%のデータを作り、ロジスティック回帰の確率を3通りの閾値で切って、r を1〜50倍に変えながら損失を比べました。** 正解（後から分かる最善の閾値）が分かるので、どれだけ損をしたかを数えられます。

|---|---|---|---|

## 主な結果
- **0.5で切ると、見逃しが高いほど損をする**：最善の閾値より、r＝2で+4.7%、5で+29.9%、10で+76.1%、50で+436%多い
- **費用から決めた閾値 1/(1+r) は、どの r でも最善より+0.4〜+0.7%多いだけ**だった
- **交差検証で選んだ閾値は+1.2〜+2.2%多い**。中央値は 1/(1+r) とほぼ同じだが、学習用2,000件の中の陽性（約200件）だけで選ぶので、ぶれが大きい（r＝10で0.07〜0.115、10〜90%の範囲）。費用の閾値の方が損失が小さかった回は70〜79%
- r＝1（コストが同じ）では、0.5と 1/(1+r) は同じ閾値になる
- 見逃しが50倍高いとき、0.5で切った損失（1,000件あたり4,199）は、全員を陰性にしたとき（4,828）と大差なかった

## 動かし方
```
pip install -r requirements.txt
cd src && python a666_threshold.py
```
1分ほどかかります。`results/reps.csv.gz` に1回ずつの損失と閾値を書き出します。

## 確かめたこと
- 空のフォルダで流し直し、results・figures がバイト単位で一致した
- r＝1では、0.5と 1/(1+r) の損失が一致した
- 損失の曲線（閾値ごとの損失）を並べ替えで出す計算が、閾値ごとに数えた損失と一致することを確かめた（0.5と 1/(1+r) は直接数えている）

## データ
- 仮定：特徴量5つは標準正規。陽性になる確率はロジスティック（切片-2.95、係数0.9・-0.7・0.6・0.5・-0.4）で、陽性は約9.6%
- 損失＝見逃しの件数×r＋空振りの件数。1,000件あたりで、空振り1件のコストを1として数えた
- 学習用2,000件、評価用5万件。回帰は正則化なし（C＝100万）

## 注意（言えないこと）
- シミュレーション。モデルの形は正しく、確率もほぼ正しく出るように置いた。確率がずれるモデル（学習データの陽性の割合が違う、正則化が強いなど）では、1/(1+r) はそのままでは最善にならない
- コストの比 r が分かっている前提。実際には r を決めること自体が難しい
- どの r が正しいかや、どの判断に使うべきかには触れていない
