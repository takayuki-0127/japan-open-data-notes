# 558 予測確率が「30%」と出た人のうち、本当に起きるのは何%なのか（手法の解説・正解の分かるデータで較正を確かめる）

モデルが出す「解約する確率30%」は、そのまま「30人に約9人が解約する」と読めるとは限りません。予測の確率と実際の割合が合っているかを「較正（キャリブレーション）」と呼びます。**ここでは、本当の確率が分かる式から作った架空の会員（学習15,000人・較正5,000人・テスト10,000人）で、4つのモデルの較正曲線・Brier スコア・ECE を数え、Platt と isotonic で較正し直しました。** 数字は置いた前提で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A558 | 予測確率は、実際の割合と合っているか。合っていなければ、どこまで直せるか | 5つの特徴（うち1つは少し相関）と交互作用・2乗の項から本当の確率を作り、解約を引く。ほぼ同じ情報の特徴を2つ足す（本当の確率には使わない）。ロジスティック回帰（解約あり・なしを半々に間引いて学習）、ランダムフォレスト、ナイーブベイズ、勾配ブースティングを学習。較正曲線、予測が25〜35%だった人の実際の割合、Brier スコア、ECE（10区間）、AUC を比較。別の5,000人で Platt と isotonic を学習し、較正に使う人数（100〜5,000人、各100回）も変えた。SQL は DuckDB（1スレッド）で較正表と Brier を確かめた。seed 558 | `src/a558_calibration.py`、`src/a558_calibration.sql`、`src/a558_calibration_tsql.sql` |

## 主な結果
- **テストの解約率は 33.3%**。本当の確率をそのまま使った場合の Brier は 0.163、ECE は 0.008（くじの振れだけで出る下限の目安）
- **予測が25〜35%だった人の実際の解約率**（そのまま）：半々に間引いて学習したロジスティック回帰 17%（1,392人）、ランダムフォレスト 30%、ナイーブベイズ 30%、勾配ブースティング 30%
- **全体のずれ（ECE）**（そのまま）：ロジスティック回帰（間引き）0.132、ナイーブベイズ 0.143、ランダムフォレスト 0.012、勾配ブースティング 0.011。ナイーブベイズは25〜35%では合っていたが、低い予測は実際より低く、高い予測は実際より高く出ていた（較正曲線が30%付近で対角線と交わる）
- **Platt で較正し直すと**：ロジスティック回帰（間引き）の25〜35%は 31%、ECE 0.132→0.022、Brier 0.201→0.183。ナイーブベイズの ECE 0.143→0.015。AUC は変わらない（0.759・0.758 のまま）
- **もともと合っていたモデルは、較正で良くならない**：ランダムフォレストの ECE 0.012→0.019（Platt）、勾配ブースティング 0.011→0.015（Platt）。較正後の平均予測は 0.348 で、較正に使った5,000人の解約率（34.8%）に寄る
- **較正に使う人数**：100人では ECE が Platt 0.045〜0.052、isotonic 0.068〜0.073。isotonic が Platt に並ぶのは3,000〜5,000人から

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 558）。ナイーブベイズのテストの予測は `results/test_predictions_nb.csv`

## 注意（言えないこと）
- 架空のデータ。本当の確率の式、特徴の作り方、モデルの設定は作成者が置いたもので、結果はこれで決まる。ランダムフォレストやナイーブベイズがいつもこうなる、という話ではない
- ECE は区間の切り方で値が変わる。ここでは10%ごとの10区間
- 較正で直るのは「確率の目盛り」だけで、並べ替えの力（AUC）は変わらない
- 較正に使うデータは、学習にもテストにも使っていない別の人で作った。同じデータで較正すると、ずれは小さく見える（推測）
