# F315 「製造業の国内回帰」は、工場の立地で見えるのか？ 2021〜25年の製造業の立地件数は2015〜19年より−24（対数差）。設備投資の予定額は+16で、1件の案件が大きくなった形だった

## 結論（先に）
- 工場立地動向調査（1,000㎡以上の用地を取得した工場）で、製造業の立地件数の年平均は、2015〜19年の1,029件から2021〜25年の809件に減りました（対数差×100 で −24）。件数で見る限り「国内回帰」は見えません。
- 一方、製造業の設備投資の予定額は、年平均0.93兆円から1.09兆円に増えました（+16、名目）。1件当たりの敷地面積は +23、1件当たりの設備投資額は +41 で、件数は減り、1件の案件が大きくなった形です。
- 増えた分の多くは輸送用機械（35%）、金属製品（21%）、非鉄金属（20%）でした。電子部品・デバイスは2021〜25年の製造業の設備投資額の6.5%で、半導体などを除いても増え方（+16）はほぼ同じでした。
- 為替（前年のドル円）と立地件数の伸びの相関は 0.34（p=0.17）で、はっきりした関係はありませんでした。2009・2010年を除くと 0.01 です。

## 問い
円安やサプライチェーンの見直しで「製造業が国内に戻ってきた」と言われます。地域の産業や工場の誘致の担当の人、製造業の統計を読む人にとっては、それが工場の立地の数字にどこまで表れているのかが知りたいところです。件数・面積・設備投資の予定額はどう動いたか、増えたとすればどの業種か、半導体などの大型案件を除くとどうか、為替と関係があるかを見ました。誘致や補助の良し悪しは扱いません。

## データ（出典）
- 経済産業省「工場立地動向調査」2025年調査 統計表（e-Stat）：第1表 立地件数、第3表 敷地面積、第13表 設備投資額（いずれも業種別、2006〜2025年）、第34-1表 新設・増設別立地件数。
- 日本銀行「外国為替相場」東京市場 ドル・円 スポット 17時時点 月中平均（年平均にした）。
- URL と取得日は data/raw/SOURCES.md にあります。

## 事前の計画
[PLAN.md](PLAN.md) に、業種別の集計の前に仮説を書きました。表の一覧を確かめるときに、全業種合計の2006〜2012年ごろの値を見たことは開示しています。

| 仮説（2015〜19年平均 → 2021〜25年平均） | 基準 | 結果 | 判定 |
|---|---|---|---|
| H1 立地件数が増えた | 対数差 > 0 | 1,059件 → 835件（−24） | 外れ |
| H2 設備投資額が +20 以上、電子部品を除くと半分未満 | 全業種 | −1.5（電子部品を除くと −2.6） | 外れ |
| H3 電子部品・デバイスが設備投資額の20%以上 | 2021〜25年 | 6.0% | 外れ |
| H4 前年のドル円の伸びと件数の伸びが正の相関（p<0.10） | 2008〜2025年、n=18 | 0.34（p=0.17） | 外れ |

H1〜H4 は、電気業・ガス業・熱供給業を含む「全業種」で計画しました。製造業だけの見方は問い直しで足しています。

## やったこと
1. 2025年調査の経年掲載の表から、業種×年の件数・面積・設備投資額を取り出しました。
2. 5年平均どうしを対数差×100 で比べ、設備投資額の増減を業種に分けました。
3. 立地件数の伸びとドル円の伸びの相関を、並べ替え検定（5,000回、種 20261116）で確かめました。
4. 頑健性を5つ、問い直しを1つ足しました。

## 分かったこと
### 立地件数は2021年以降も増えていない（図1）
製造業の立地件数は、2008年の金融危機で大きく減り、2014〜2018年に1,000件前後まで戻りましたが、2020年以降は800件前後で、2025年は719件と20年間でいちばん少ない年でした。新設だけで見ても −21 でした。

### 設備投資の予定額は、製造業で増え、発電所などで減った（図2）
全業種の合計は −1.5 でほぼ横ばいでした。その中で、製造業は +16 増え、電気業・ガス業・熱供給業は年平均0.26兆円から0.08兆円に減りました。2017〜2019年の発電所などの大きな案件が、比べる元の期間を押し上げていた形です。

### 件数は減り、1件の案件は大きくなった（図3）
製造業の1件当たりの敷地面積は +23、1件当たりの設備投資額は +41 でした。設備投資額は名目なので、建設費や機械の値上がりも含みます（推測）。

## 問い直し（結果を見てから足した）
H2 で、設備投資額の合計が、業種ごとの増加を足したものより小さいのを見て、電気業（発電所）などの大きな減少が混ざっていると考えました。「製造業の国内回帰」を見るため、電気業・ガス業・熱供給業を除いて比べ直しました（src/03b_requestion.py、図2〜図4）。

| 製造業（2015〜19年平均 → 2021〜25年平均） | 結果 |
|---|---|
| 立地件数 | 1,029件 → 809件（−24） |
| 敷地面積 | 1,189万㎡ → 1,169万㎡（−2） |
| 設備投資の予定額 | 0.93兆円 → 1.09兆円（+16） |
| 1件当たり敷地面積 | +23 |
| 1件当たり設備投資額 | +41 |
| 電子部品・デバイスを除いた設備投資額 | +16 |

増加分の業種の寄与は、輸送用機械 35%、金属製品 21%、非鉄金属 20%、生産用機械 16%、電気機械 15% でした。食料品は −428億円で、いちばん減りました（図4）。

## 頑健性
| 確かめたこと | 結果 | 結論は変わるか |
|---|---|---|
| R1 H1 を敷地面積で（全業種） | +9.9 | 面積では増えた。ただし製造業だけでは −1.7 |
| R2 H1 を新設だけで | −21.4 | 変わらない |
| R3 H4 を同じ年のドル円で | 0.34（p=0.16） | 変わらない |
| R4 H4 を2009・2010年を除いて | 0.01（p=0.97） | 関係はさらに見えない |
| R5 H1 を2010〜14年平均と比べる | −7.2 | 変わらない |

## 言えないこと
- 用地を取得した件数で、工場の建物の新設や生産の量ではありません。持っている用地での建て替えや増設は入らないことがあります。
- 設備投資額は予定額で、名目です。値上がりの分を除いていません。
- 海外から戻った工場かどうかは、この表では分かりません。
- 為替と立地の関係は相関で、原因とは言えません。年数も20年分と少ないです。
- 2023年調査は、能登半島地震の影響で後日調査を追加した旨の注記があります。

## 仕事で使うなら
- 「国内回帰」を工場立地で示すときは、件数と設備投資額で向きが違うことを書き添えると、誤解が減ります。
- 全業種の合計には発電所などの大きな案件が入るので、製造業だけの数字と並べると読み違いが減ります。
