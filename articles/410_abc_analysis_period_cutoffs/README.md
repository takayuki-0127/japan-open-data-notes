# 410 売れ筋を A・B・C に分ける分析は、期間と区切りでどれだけ入れ替わるのか（実務の型）

商品を売上の大きい順に A・B・C に分ける分析（ABC 分析）を、集計する期間（1か月・3か月・1年）と区切り（70/90・80/95）を変えて行い、ランクが変わる商品の割合を、架空の600商品で数えたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A410 | 期間と区切りを変えると、何%の商品のランクが変わるか。季節の商品は、月の分析で何か月 C に落ちるか | 架空の600商品×24か月（seed 410、15%は夏型・冬型の季節の商品）。2025年の1年分のランクを基準に、1か月（12回）・3か月（4回）・前の年の1年分と比べる。月ごとの揺れの大きさを変える | `src/a410_abc.py`、`src/01_abc_tsql.sql`（未検証） |

## 主な結果
- **1年分のランクの数**：70/90で A 80・B 148・C 372、80/95で A 132・B 184・C 284。区切りを変えるとランクが変わる商品は23.3%（B→A が52、C→B が88）
- **1年分とランクが違う商品（70/90）**：1か月で平均14.1%（12.0〜18.7%）、3か月で9.1%、前の年の1年分で9.2%。80/95では16.2%・11.5%・8.7%
- **種類ごと（70/90）**：通年の商品は1か月10.6%・3か月5.4%、夏型は32.6%・31.8%、冬型は33.3%・28.1%
- **季節の商品**：1年分で A か B の34商品が、月の分析で C になった月は平均5.7か月。6か月以上 C の商品は67.6%。通年の商品（194）は平均1.3か月
- **月から次の月へ**：A だった商品のうち、次の月に A でない商品は平均22.5%（10.0〜32.5%）。A の数は月によって58〜80
- **月ごとの揺れを変える**（1か月で1年分と違う割合、全商品／通年の商品だけ）：揺れ0で8.1%／3.7%、0.1で9.0%／5.0%、0.3で14.4%／11.5%、0.5で19.3%／17.4%

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した
- DuckDB の SQL で付けたランクが、pandas で付けたランクと600商品すべてで一致する（コード内の assert）

## データ
- `data/monthly_sales.csv`：架空の600商品×24か月の売上（商品ID・種類・年・月・売上）。作成者が乱数で作成（seed 410）

## 注意（言えないこと）
- 架空のデータ。割合は、売上の差の大きさ・季節の商品の割合・月ごとの揺れの置き方で決まる
- 売上の金額だけで分けている。粗利・販売数・在庫の回転では試していない
- 新商品・取り扱いをやめた商品は入れていない
- どの期間・区切りがよいかは、使い道で決まる。この記事はそれを決めない
- T-SQL 版は SQL Server 本体では動かしていない（未検証）
