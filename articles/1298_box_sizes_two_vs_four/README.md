# 1298 用意する箱の大きさを2種類から4種類に増やすと、箱の中のすきま（詰め物の量）はどれだけ減るのか？（箱詰めと積載）

通販の発送では、注文の中身に合わせて、用意した箱のうち入るいちばん小さい箱を使います。箱と中身の差（すきま）は詰め物で埋めます。箱の大きさの種類を増やすと、中身に近い箱を選べるので、すきまは減ります。けれども、どれだけ減るかは、増やした箱の大きさをどこに置くかで変わります。**ここでは、作成者が置いた架空の通販の1か月の注文3,000件（中身の大きさの分布を置き、乱数で作ったもの）で、箱の大きさを①倍ずつ（1つ下は半分）、②注文を件数で等分する境目、③すきまの合計がいちばん少なくなる大きさ、の3つの決め方で選び、1〜8種類で、すきまの合計がどれだけ減るかを数えました。分布の形（山の数）・散らばり・いちばん大きい箱の大きさを変えた12通りで確かめ、選んだ大きさを翌月の注文に使ったときも数えました。**

すべて作成者が置いた決まりでのシミュレーションです。中身は大きさ（体積）だけで「入る・入らない」を決め、形は考えていません。実在の箱の規格・運送会社を表すものではありません。

関連する記事：631「発注をケース単位に切り上げると、在庫は平均で何日分多く持つことになるのか？」（索引の題名で確認）は、発注の数をケース単位に切り上げた分が在庫として残ることを扱っています。1168「小さなファイルがたくさんあると、大きさの合計と実際に使う量はどれだけ違うのか？」は、1件ごとに決まった大きさの区画へ切り上げると、使う量が大きさの合計を上回ることを扱っています。1299「荷物の体積の合計は箱の容量に収まっていても、縦・横・高さで並べると入らない組み合わせはどれだけあるのか？」は、体積の合計では箱に収まる注文が、縦・横・高さで並べると入らない割合を数えています。この記事は、切り上げる先（箱の大きさ）の種類の数と置き方を変えたときに、切り上げで生まれるすきまがどれだけ減るかに絞ります。

## 主な結果

### 箱の種類の数とすきまの割合（`results/base_by_types.csv`）
| 箱の種類 | ①倍ずつ | ②件数で等分 | ③すきまが最少 | ③の1件あたりのすきま |
|---|---|---|---|---|
| 1種類 | 81.67% | 81.67% | 81.67% | 31.2784リットル |
| 2種類 | 64.23% | 68.27% | 52.68% | 7.8176リットル |
| 3種類 | 41.1% | 58.29% | 37.89% | 4.2842リットル |
| 4種類 | 31.38% | 50.72% | **29.67%** | 2.9625リットル |
| 6種類 | 30.45% | 40.01% | 20.03% | 1.7592リットル |
| 8種類 | 30.45% | 32.77% | 14.99% | 1.2384リットル |

- **2種類から4種類にすると、すきまの合計は③（すきまが最少の大きさ）で62.10%減った**（すきまの割合は52.68%→29.67%）
- 同じ2種類→4種類でも、①倍ずつでは74.53%、②件数で等分では52.17%減った。減り方は大きさの決め方で違った
- ②が約半分なのは、いちばん大きい箱に入る注文が、2種類では上の半分、4種類では上の4分の1になるため（ほぼ作りどおり）。上の4分の1の注文は、中身にかかわらず38.3リットルの箱を使うので、4種類でもすきまの割合は50.72%残った
- ①は2種類（38.3・19.15リットル）のとき、中央値くらいの注文も19.15リットルの箱に入るので、すきまが大きかった。4種類で4.7875リットルの箱が入ると大きく減った。6種類と8種類が同じなのは、8種類で足した小さい箱（0.5984リットル以下）に入る注文がなかったため（使われた箱は6種類）
- ③で4種類から8種類にしても、すきまはさらに58.2%減った（1種類→2種類は75.01%）

### 翌月の注文に使うと（`base_by_types.csv` の gap_share_next_month）
- ③で選んだ4種類を翌月の3,000件に使うと、すきまの割合は29.67%→30.8%だった。12通りでは、翌月との差は−1.42〜+1.86ポイントだった

### 確かめ：12通り（`results/grid.csv`・`results/check_largest_box_x1_5.csv`）
- **2種類→4種類のすきまの減りは、③で57.74〜75.33%、②で50.27〜52.19%、①で8.45〜82.02%だった**
- ①がいちばん減らなかった（8.45%）のは、山が1つで散らばりが小さく（0.3）、いちばん大きい箱が99.9%点の1倍のとき。2種類のうち半分の大きさの箱にほとんどの注文が入り、2種類のときからすきまの割合が32.26%と小さかった
- ③の4種類でも、すきまの割合は16.44〜50.54%残った。散らばりが大きいほど、山が2つのときほど、いちばん大きい箱が大きいほど残った
- ③の4種類→8種類の減りは54.43〜62.07%だった

## 注意（言えないこと）
- 架空のデータです。注文の大きさの分布、いちばん大きい箱の大きさ、3つの決め方は作成者が置いたもので、結果はこれで決まります。とくに①倍ずつの減り方は、置いた分布といちばん大きい箱の大きさで8.45〜82.02%と大きく動きました
- 中身は大きさだけで「入る」を決めました。形を考えると、入る箱は同じか大きくなるので、すきまはこれより減ることはありません（大きさは数えていません）
- ③はその月の注文に合わせて選んだ大きさです。注文の分布が月ごとに大きく変わるときの減り方は数えていません
- 詰め物の量はすきまの体積とみなしました。実際の詰め方・詰め物の種類は扱っていません
- 送料・料金の決め方や、どの箱を何種類用意するかの助言をする記事ではありません
