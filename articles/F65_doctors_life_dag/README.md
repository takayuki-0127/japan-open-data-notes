# F65 医師が多い県で、平均寿命は長いか？（DAG で調整する変数を選ぶ）

**看板記事 F65**。「医師が多い県ほど平均寿命が長い」という関係を確かめるとき、どの変数で「条件をそろえるか」で答えは変わります。この記事では、因果の仮定を図（DAG：有向非巡回グラフ）に書き、そこから「そろえるべき変数」「入れても入れなくてもよい変数」「入れてはいけない変数」を機械的に選びました。そのうえで、変数の入れ方を全部（256通り）試して、答えがどれだけ揺れるかを見ています。

## 問い

- 人口10万人当たりの医師数が多い県ほど、平均寿命は長いか（男女別）
- 調整する変数の選び方で、答えはどれだけ変わるか
- DAG で選ぶと、答えの幅はどれだけ狭まるか。どの変数を入れると答えが大きく動くか

## データ（新しい取得はなし）

| 変数 | 年 | 元の記事 | 出典 |
|---|---|---|---|
| 医療施設に従事する医師数（人口10万人当たり） | 2010・2022 | 209 | 厚生労働省「医師・歯科医師・薬剤師統計」（e-Stat「社会・人口統計体系 都道府県データ」I0920101） |
| 課税対象所得（納税義務者1人当たり） | 2010・2024 | 209 | 総務省「市町村税課税状況等の調」（同 D02206） |

| 一般病院病床数（人口10万人当たり） | 2010・2023 | 209 | 厚生労働省「医療施設調査」（同 I0910203） |

基本の分析は、説明する側を2010年、平均寿命を2015年（5年のずれ）にしました。単位は47都道府県です。

## 手法

1. **DAG を書く**（仮定）：都市化（人口集中地区の割合）は医師数・所得・大卒の割合・大学数・高齢化率・失業率と平均寿命に効く。所得・大卒の割合・高齢化率は医師数と平均寿命の両方に効く。大学数は医師数にだけ効く。気温と失業率は平均寿命にだけ効く。標準化死亡率は平均寿命と同じ死亡から計算されるので「結果の一部」。病床数は、A：医師数→病床数→平均寿命（中間）と、B：病床数→医師数・平均寿命（共通原因）の2通りを置く
2. **裏口基準**で、医師数→平均寿命の効果を測るのに有効な調整セットを全部列挙する（networkx の d 分離）。最小のセットは、A では {都市化・所得・大卒・高齢化}、B ではそれに病床数を足したもの
3. 「医師が人口10万人当たり50人多い」ときの平均寿命の差を、調整のしかた8通りで推定する（最小二乗法、HC3 標準誤差）
4. 調整に使える8変数（標準化死亡率を除く）の入れ方 2⁸＝256 通りすべてで推定し、DAG で有効な組み合わせとそうでない組み合わせの幅を比べる
5. 頑健性：年を変える、同じ年どうし、65歳の平均余命、東京・沖縄を除く、地方ブロックを入れる、変化どうし（医師の増加と平均寿命の伸び）、1県ずつ除く

## 主な結果

**相関**：医師数と平均寿命の相関は、男性 0.06、女性 0.37。医師数は病床数（0.66）、気温（0.39）、高齢化率（0.26）と相関し、所得・大卒の割合・都市化とはほぼ無相関。

**調整のしかた別**（医師が人口10万人当たり50人多いときの平均寿命の差、年。カッコは95%区間）

| 調整のしかた | 男性 | 女性 |
|---|---|---|
| 調整なし | +0.05（−0.18〜+0.28） | +0.21（+0.06〜+0.36） |
| DAG の最小セット（都市化・所得・大卒・高齢化） | +0.01（−0.18〜+0.20） | +0.15（−0.08〜+0.38） |
| 最小セット＋気温・失業（推奨） | +0.09（−0.07〜+0.25） | +0.17（−0.09〜+0.43） |
| ＋病床数 | +0.09（−0.16〜+0.34） | +0.18（−0.15〜+0.50） |
| ＋大学数 | +0.06（−0.18〜+0.29） | +0.15（−0.12〜+0.41） |
| 高齢化を外す（裏口が残る） | −0.01（−0.16〜+0.13） | +0.11（−0.16〜+0.39） |
| ＋標準化死亡率（結果を調整） | +0.07（−0.03〜+0.17）、R² 0.93 | +0.16（−0.05〜+0.37）、R² 0.80 |
| 全部入れる | +0.01（−0.15〜+0.16） | +0.12（−0.15〜+0.39） |

- 女性は調整なしでははっきりプラスだが、DAG で選んだ変数で調整すると区間が0をまたぐ。男性はどの調整でもほぼ0
- 標準化死亡率を入れると R² が0.93まで上がり区間も狭くなるが、結果そのものを説明変数に入れているだけで、医師数の効果の推定としては意味がない

**256通りの入れ方**

| | 男性 | 女性 |
|---|---|---|
| 256通りの係数の幅 | −0.09〜+0.34 | +0.08〜+0.31 |
| DAG で有効な組み合わせ（A：8通り）の幅 | −0.02〜+0.11 | +0.10〜+0.21 |
| 係数がプラスの割合 | 89% | 100% |
| 区間が0を上回る割合 | 4% | 42% |

- その変数を入れると係数が動く大きさ（入れたときの平均−入れないときの平均）：大卒の割合が最も大きく、男性 −0.11、女性 −0.07。次に病床数（男性 +0.07）、気温（−0.04〜−0.05）。都市化はほぼ0

**頑健性**（推奨セット）

| 確認 | 男性 | 女性 |
|---|---|---|
| 医師2022年→平均寿命2020年 | +0.15（+0.00〜+0.30） | +0.27（+0.16〜+0.38） |
| 同じ年（2010年どうし） | +0.03 | +0.11 |
| 65歳の平均余命 | −0.00 | +0.12 |
| 東京・沖縄を除く | +0.11 | +0.10 |
| 地方ブロックの違いを入れる | +0.03 | +0.13 |
| 変化どうし（医師2010→2022の増加と、平均寿命2010→2020の伸び） | +0.53（+0.22〜+0.84） | +0.44（−0.04〜+0.92） |
| 1県ずつ除く（係数の最小〜最大） | +0.07〜+0.13 | +0.06〜+0.20 |

- 新しい年の女性と、変化どうしの男性では区間が0を上回る。ほかの多くの確認では0をまたぐ

## 言えないこと

- **DAG は仮定**：矢印の向きと有無は、私がおいた仮定です。たとえば「平均寿命が長い県に医師が集まる」逆向きの矢印や、喫煙・食生活・運動など、ここで測っていない共通の原因があれば、どの調整セットでも偏りは残ります
- **都道府県の平均どうしの関係**：47の県の平均を比べているので、医師にかかった人ほど長生きする、という個人の話はできません（生態学的誤謬）
- **47県しかない**：変数を増やすほど区間が広がり、小さな効果は見分けられません
- **変化どうしの結果**：医師が増えた県で平均寿命の伸びが大きいのは、医療の改善以外に、同じ時期の別の変化（高齢者の構成、地域の経済）を拾っている可能性があります。推測です
- **医師数の中身**：医療施設に従事する医師の総数で、診療科や地域内の偏り（都市部への集中）は入っていません
