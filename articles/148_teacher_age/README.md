# 148 小学校の先生の年齢構成は、「ふたコブ」からどう変わったか？

文部科学省「学校教員統計調査」（3年ごと）の小学校の本務教員の年齢別人数を、1998〜2025年度の10回分つなぎ、年齢構成の変化を見たフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A148 | 40代が多い「上の山」と若い世代の構成は、四半世紀でどう変わったか | 年齢別人数の重ね描き、年代別の割合、年齢×年度のヒートマップと最多年齢の推移 | `src/a148_age.py` |

## 主な結果
- 1998年度は40代が全体の40%で、41〜43歳が各年約1.8万人の大きな山。この山は2007年度に50〜51歳、2016年度に57歳へ動き、2019年度以降は退職でほぼ消えた
- 50代の割合は 18%（1998）→ 37%（2010）が最大 → 23%（2025）
- 20代の割合は 8%（2001）→ 20%（2025）。22〜24歳の先生は 4,174人（2001）→ 23,841人（2025）と約5.7倍
- 60歳以上は 2,335人（1998）→ 24,754人（2025）、割合は 0.6% → 6.5%
- 2025年度は25〜31歳が各年約1.1万人で、20代後半〜30代前半が最も多い形になった。年代ごとの割合は20〜28%で、ほぼ平らになっている
- 1966年生まれの学年は前後より少なく（1998年度32歳 9,285人、31歳 11,418人、33歳 11,829人）、その谷が2007年度41歳、2016年度50歳と同じように動いている
- 本務教員の総数は 39.7万人（1998）→ 38.3万人（2025）

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a148_age.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/elementary_teachers_by_age.csv | 年度ごとの小学校本務教員数（国立・公立・私立の計）。le19＝19歳以下、20〜59＝各歳、60plus＝60歳以上 |

e-Stat の Excel（statInfId）：1998 000001196249／2001 000001195567／2004 000001193764／2007 000002847522／2010 000012921847／2013 000028981288／2016 000031687425／2019 000032071148／2022 000040167962／2025 000040477632。各年度の「年齢別 本務教員数」の小学校（計）の行を書き写しました。1995年度以前は5歳刻みの表しかないため使っていません。

## 注意
- 調査は10月1日時点。本務教員（その学校に籍のある常勤の教員）で、校長・副校長・教頭なども含みます。講師（非常勤）は含みません
- 2022年度の表は59歳までの各歳しかないため、60歳以上は「総数 − 59歳以下の合計」で求めました
- 再任用の先生は本務教員として数えられるため、60歳以上の増加には定年後の再任用が含まれます
- ヒートマップの●は「40〜59歳の中で最も多い年齢」。2022年度以降は山がほぼなくなったため、●の位置の上下は小さな差によるものです
- 若い先生が増えた理由（大量退職の補充、採用数、35人学級など）は、このデータでは分けられません
