### immigration-entries-japan：出入国管理統計で、外国人がどの空港・港から、どの季節に入ってくるかを調べる

出入国在留管理庁「出入国管理統計」の月報の表「港別 入国外国人の国籍・地域」（2013年1月〜2026年7月、163か月）を使ったリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| W1 | 外国人はどの空港・港から入るようになったか。コロナの前と後で何が変わったか | 港別の入国者数と全体に占める割合（2013・2019・2023〜2025年）、2019年→2025年の増減の国籍別の内訳、2019年の同じ月を100とした回復の度合い（3か月平均） | `src/w1_ports.py` |
| W2 | 国籍・地域ごとに、入国の多い季節は違うか。似た形の国はどれか | 2025年の入国者数の上位20か国・地域について、月別の入国者数の対数をSTL（周期12、robust）で分け、季節成分を月ごとの「年平均からのずれ（%）」にした。形（長さ1にそろえたベクトル）をk-means（k＝4）でまとめ、2023年1月〜2026年7月の形と比べた | `src/w2_season.py` |

#### 主な結果
- **W1**：外国人入国者は1,126万人（2013年）→3,119万人（2019年）→4,243万人（2025年）。全体に占める割合は、成田37.9%→28.8%→28.1%、関西20.6%→26.9%→25.5%、羽田11.5%→13.7%→16.8%、福岡6.1%→6.9%→8.9%。2019年→2025年の伸びは福岡1.75倍、羽田1.67倍、成田1.33倍、関西1.29倍、中部1.00倍（全体1.36倍）。羽田の増加286万人のうち117万人は米国。韓国は関西（+96万人）・福岡（+94万人）・成田（+73万人）で増え、中国は中部（−36万人）などで減った。2026年1〜7月は前年同期比で中国が0.51倍となり、関西は0.85倍、中部は0.90倍に下がった。海港（フェリーなど）の割合は5.5%→1.6%
- **W2**：シルエット係数は k＝2〜4 で0.22〜0.23と低く、グループの境目ははっきりしない。k＝4では、G1（台湾・米国・欧州・ベトナム・インドなど11か国・地域：1〜2月が少なく、3〜4月と10月が多い）、G2（韓国・中国：秋〜12月が少ない）、G3（香港：7月と12月が多く9月が少ない）、G4（タイ・オーストラリア・東南アジア6か国：12月と4月が多く、8月が最も少ない）。シンガポールの12月は年平均の2.5倍。コロナ前と2023年以降の形の相関は米国・タイ0.93、オーストラリア0.92と高く、台湾0.28、韓国0.25、中国0.55は低い

#### 動かし方
`data/` の CSV（元の表を整えたもの）が入っているので、そのまま動きます。元の Excel から作り直すときは、e-Stat の出入国管理統計（https://www.e-stat.go.jp/stat-search/files?page=1&toukei=00250011 ）の月報から、表「港別 入国外国人の国籍・地域」を月ごとに `data/raw/nyu_YYYY_MM.xls(x)` の名前で置き、`data/*.csv` を消してから実行してください。

```bash
pip install -r requirements.txt
cd src
python w1_ports.py
python w2_season.py
```

#### 注意
- 取得できた月報は2013年1月〜2026年7月です。2012年以前の月別の港別表は使っていません（時系列表は1950〜2005年の年計のみ）
- 「入国外国人」は新しく入国した人と再入国した人を合わせた数で、乗員と、特例上陸（船舶観光上陸許可など）は含みません。2015年からクルーズ船の乗客の多くは船舶観光上陸許可で上陸しているため、那覇・石垣・博多などの海港の数字はクルーズ客の動きを表しません。海港の数字の多くは、韓国と対馬（比田勝・厳原）・博多・下関を結ぶフェリーの客です
- 2024年以降の表は様式が変わり、港の名前が一部違います（富士山静岡→静岡、大阪（阪神）→大阪 など）。合わせてからつなぎました
- 「中国」には台湾・香港・マカオを含みません。国籍で数えているので、住んでいる国とは限りません
- 2020〜2022年は入国がごく少なく、割合の比較には使っていません
- STLの季節成分は、2013〜2019年（84か月）と2023年1月〜2026年7月（43か月）で別々に計算しました。後の期間は短く、2023年の回復の途中や、2025年12月以降の中国の急な減少を傾向で吸収しきれていない可能性があり、中国の2023年以降の形は特に不確かです
- 月の長さや祝日の位置（旧正月、イースター、ゴールデンウィーク）の違いは調整していません
