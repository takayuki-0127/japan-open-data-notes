# 1037 待ち合わせに余裕を何分みれば、9割の確率で間に合うのか？（移動と時間）

待ち合わせの時刻から逆算して家を出るとき、「いつもの所要時間＋何分」の余裕をみます。9割の確率で間に合いたいなら、所要時間の分布の90%点（10回のうち9回はそれより早く着く時間）まで余裕をみればよいはずです。けれども、その90%点を自分の過去の記録から決めると、記録の回数が少ないうちは本当の90%点より短く出やすくなります。また、相手と2人とも間に合う確率は、1人ずつ9割にしても9割になりません。**ここでは、作成者が乱数で作った架空の移動（家から駅まで歩く・電車を待つ・乗る・歩く。ときどき遅れが出て、2人に共通の遅れやすい日もある）で、9割間に合うには平均＋何分が要るか、過去10・20・50回の記録から3つの決め方で余裕を決めると本当に何%間に合うか、2人とも9割間に合うには何分要るかを数えました。置き方を変えた27通りでも確かめました。**

平均の所要時間どおりに出ると何回に1回遅れるかは、同じ企画の関連する記事 1030 で扱っています。乗り換えの遅れは 1032、少ない日の記録で「いちばん速い道」を選ぶと外れることは 1038、乗りかえ先の電車の間隔で時間の減りが「0分か1本分」に分かれることは 1039 で扱っています。余裕を作業ごとに持つか最後にまとめて持つかは 852、最もありそうな日数で計画したときに間に合う確率は 850、平均の待ち時間と長く待つ人の割合の違いは 873 で扱っています。この記事は、9割間に合う余裕の大きさと、それを少ない記録から決めるときのずれ、2人のときの余裕に絞ります。

## 主な結果

### 1人の所要時間（基本、40万日）
| | 値 |
|---|---|
| 平均 | 39.07分 |
| 90%点 | 44.03分 |
| **9割間に合うのに要る余裕（90%点−平均）** | **平均＋4.96分** |
| 平均の時間で出たときに間に合う割合 | 53.89% |
| 平均＋1.28×標準偏差（本当の平均と標準偏差を使う）で出たときに間に合う割合 | 93.95% |

- 9割間に合うには、平均の所要時間に4.96分を足す必要があった。27通りでは平均＋3.22〜8.66分で、電車の間隔が長いほど大きかった（間隔20分の9通りでは8.22〜8.66分）
- 平均の時間で出ると、間に合うのは53.89%（27通りで50.34〜61.34%）。この点は 1030 で詳しく扱っている
- 正規分布の式（平均＋1.28×標準偏差）は、本当の平均と標準偏差を使っても93.95%と9割からずれた（27通りで89.48〜94.8%）。所要時間の分布が右に長い（まれに大きく遅れる）ので、標準偏差が大きく出るため

### 過去の記録から余裕を決めると（基本、2万人の平均、`results/rules_by_records.csv`）
| 記録の回数 | 決め方 | 本当に間に合う割合 | 80%を下回った人 | 余裕の平均（本当の平均＋何分） |
|---|---|---|---|---|
| 10回 | ①過去の90%点 | **83.71%** | 31.31% | 4.48分 |
| 10回 | ②平均＋1.28×標準偏差 | 87.53% | 19.2% | 5.8分 |
| 10回 | ③過去の最長 | 90.89% | 10.66% | 8.58分 |
| 20回 | ①過去の90%点 | 86.46% | 17.72% | 4.68分 |
| 20回 | ②平均＋1.28×標準偏差 | 89.83% | 8.84% | 6.0分 |
| 20回 | ③過去の最長 | 95.23% | 1.05% | 11.92分 |
| 50回 | ①過去の90%点 | 88.45% | 4.23% | 4.83分 |
| 50回 | ②平均＋1.28×標準偏差 | 91.79% | 1.35% | 6.19分 |
| 50回 | ③過去の最長 | 98.04% | 0.01% | 17.76分 |

- **過去10回の記録の90%点で余裕を決めると、本当に間に合うのは平均83.71%で、9割に届かなかった**。31.31%の人は80%も下回った。50回にしても88.45%だった
- 27通りでも、過去10回の90%点は82.93〜84.19%とほとんど動かなかった。記録を並べた順位で決める方法なので、分布の形によらずほぼ同じ値になる
- ③過去の最長で決めると、間に合う割合は10回で90.89%、20回で95.23%、50回で98.04%。これは「n回の記録の最長を超えない確率は n÷(n+1)」という式どおり（10÷11＝90.91%、20÷21＝95.24%、50÷51＝98.04%）。ただし余裕は回数とともに伸び、50回では平均＋17.76分になった

### 2人とも間に合う（基本、40万日）
| | 遅れやすい日が2人に共通（基本） | 遅れやすい日が2人で別々 |
|---|---|---|
| 2人とも自分の90%点で出たとき、2人とも間に合う割合 | **81.75%** | 81.0% |
| 2人とも9割間に合うのに要る余裕 | **平均＋6.82分** | 平均＋6.96分 |
| そのときの1人ずつの間に合う割合 | 94.68% | 94.89% |
| 1人のときより余分に要る余裕 | 1.85分 | 1.99分 |

- **1人ずつ9割にしても、2人とも間に合うのは81.75%だった**。2人が別々なら0.9×0.9＝81%で、別々の通りの81.0%は式どおり
- 2人とも9割にするには、1人ずつの余裕を平均＋6.82分（1人のときより1.85分長く）にする必要があった。そのとき1人ずつは94.68%で、別々なら式の√0.9＝94.87%に近い
- 遅れやすい日が2人に共通でも、別々のときと比べて2人とも間に合う割合は0.75ポイントしか変わらなかった。この置き方では、遅れの多くが1人ずつの偶然（待ち時間・遅れ）から来るため
- 27通りでは、2人とも自分の90%点で出たとき2人とも間に合うのは80.88〜82.32%、2人とも9割に要る余裕は平均＋4.21〜11.39分、1人のときより余分に要るのは0.99〜4.21分だった

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約3秒）
- 図3枚を開き、日本語・重なり・軸を確かめた
- 過去の最長で決めたときの間に合う割合が、式 n÷(n+1) と合う（10回で90.89%対90.91%、20回で95.23%対95.24%、50回で98.04%対98.04%）ことを確かめた
- 遅れやすい日が2人で別々のとき、2人とも自分の90%点で間に合う割合が式の81%と合う（81.0%）ことを確かめた

## 注意（言えないこと）
- 架空のデータです。歩く時間、電車の間隔、乗る時間の振れ、遅れの確率と大きさ、遅れやすい日の割合は作成者が置いたもので、結果はこれで決まります。9割間に合う余裕は、置き方で平均＋3.22〜8.66分と動きました。実在の路線や会社の運行を表すものではありません
- 電車は決まった間隔で来て、家を出る時刻と電車の時刻の関係はでたらめと置きました。時刻表に合わせて出る人は、待つ時間が短くなります（推測）
- 過去の記録は、毎日の条件が同じまま続くと置きました。季節や工事で所要時間が変わると、記録から決めた余裕はさらにずれます（推測）
- 遅れたときにどうするか（連絡・待つ時間の決め方など）は扱っていません。何分の余裕をみるべきかの助言ではなく、余裕の決め方で間に合う割合がどう変わるかを数えただけです
