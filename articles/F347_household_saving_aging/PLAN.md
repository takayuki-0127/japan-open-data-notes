# F347 PLAN（事前の計画）：家計の貯蓄率が下がったのは、高齢化のせいか？

作成：2026-11-16 07:40（JST）。集計のスクリプトを書く前に書いた。

## 問い

国民経済計算（GDP 統計）の家計貯蓄率は、1990年代の10%台から、近年は0〜数%まで下がりました。よく言われる説明は「高齢化で、貯蓄を取り崩して暮らす世帯が増えたから」です。一方で、働いている世帯の貯蓄の割合は、むしろ上がっているとも言われます。

家計調査で、働いている世帯（勤労者世帯）と、仕事をしていない世帯（無職世帯。多くは年金で暮らす高齢の世帯）の貯蓄の割合と、その構成の変化を見て、「世帯の構成が変わった分」で貯蓄率の低下をどこまで説明できるかを、おおまかに確かめます。

知りたい人：家計の統計や景気のニュースを読む人、金融・保険の仕事で家計の動きを追う人。

## データ

- 内閣府「国民経済計算 2024年度年次推計」：家計（個人企業を含む）の所得の使用勘定、家計貯蓄率（暦年、1994〜2024年）
- 総務省「家計調査」長期時系列表2：二人以上の世帯と勤労者世帯の年平均（2000〜2025年）。勤労者世帯の可処分所得・黒字率（黒字率＝可処分所得から消費支出を引いた残りの割合）、集計世帯数、世帯主の年齢
- 総務省「家計調査」2019年・2025年 第3-2表：世帯主の年齢階級別の、勤労者世帯と無職世帯の可処分所得・黒字率

## 取得前に見たもの（開示）

- 国民経済計算の家計貯蓄率の1994・1995・2023・2024年の値（12.3%、10.7%、−0.4%、1.1%）を見た
- 家計調査の2025年の勤労者世帯の黒字率（35.0%）、無職世帯の黒字率（−16.4%）、勤労者世帯の集計世帯数の2022〜2025年の値、2019年・2005年の表の一部の行を、列の位置を確かめるときに見た
- 2000年の勤労者世帯の黒字率や、構成を変えた計算は見ていない

## 方法

1. 国民経済計算の家計貯蓄率の推移
2. 家計調査：勤労者世帯の黒字率の推移（2000〜2025年）
3. 構成：二人以上の世帯のうち勤労者世帯の割合を、集計世帯数の比で近似する（抽出率の調整がない、おおまかな値）
4. 構成だけを変えた試算：勤労者世帯と、それ以外の世帯（無職世帯の値で代表させる）の黒字率と可処分所得を2025年（と2019年）の値に固定し、勤労者世帯の割合だけを2000年と2025年で入れ替えたとき、合わせた黒字率がどれだけ変わるかを出す

## 仮説（それぞれ「こうなったら外れ」の基準つき）

- **H1**：勤労者世帯の黒字率は、2025年の方が2000年より高い。外れ：2025年の方が低いか同じ
- **H2**：二人以上の世帯のうち勤労者世帯の割合（集計世帯数の比）は、2000→2025年に5ポイント以上下がった。外れ：下がり方が5ポイント未満
- **H3**：構成だけを変えた試算で、合わせた黒字率は3ポイント以上下がる。外れ：3ポイント未満
- **H4（確かめ。上の開示のとおり事前ではない）**：国民経済計算の家計貯蓄率は、1994→2024年に8ポイント以上下がった。外れ：8ポイント未満

## 頑健性の確かめ（3つ以上）

1. 固定する黒字率・可処分所得を2019年の値にする
2. それ以外の世帯の黒字率を0%（取り崩さない）にした場合
3. 世帯主の年齢階級別の勤労者世帯・無職世帯の黒字率（2025年）で、年齢の構成の変化の向きを確かめる
4. 国民経済計算の調整貯蓄率（現物給付を含めた貯蓄率）でも同じ向きか

## 言えないこと（予想）

- 家計調査は二人以上の世帯の数字で、単身世帯や個人企業の分は含まない。国民経済計算の貯蓄率とは定義が違う
- 勤労者世帯でも無職世帯でもない世帯（自営業など）を、無職世帯の値で代表させるのはおおまかな近似
- 集計世帯数の比は、世帯の数の割合のおおまかな目安にすぎない
- 貯蓄や資産運用についての助言はしない
