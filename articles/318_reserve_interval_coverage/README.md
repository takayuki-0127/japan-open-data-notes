# 318 見積もった支払備金の「幅」は、正解を何%含むのか

支払備金の見積もりにつける「95%の幅」が、本当に95%の割合で正解を含むのかを、最終の支払額が分かる架空のデータで数えたフォルダです。316・317（チェインラダー法）と同じ作りのデータを使っています。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A318 | マックの方法とブートストラップで作った95%区間は、正解の備金を何%の組で含むか。三角形が小さいと下がるか。データが方法の前提と違うとどうなるか | 支払額の三角形を、データの型3つ×大きさ3つ（事故年度10・7・5年）で1,000組ずつ作る。備金の合計について、マックの式の標準誤差（正規分布・対数正規分布で幅をとる）と、残差を引き直すブートストラップ（500回）の2.5〜97.5%点を出し、正解が入った組を数える | `src/a318_interval_coverage.py` |

## データの型（架空）
- **マックの前提どおりの型**：次の年の累計＝いまの累計×比＋ばらつき。ばらつきの分散は、いまの累計に比例する
- **1マスごとに独立にばらつく型**：316 の場面Aと同じ。1マス（事故年度×経過年）の支払額が、それぞれ独立に変動係数12%でばらつく
- **インフレが強まる型**：上の型に、直近3年から先のインフレ（年1%→6%、その先も続く）を入れたもの。316 の場面C2
- 事故年度が7年・5年の三角形は、支払いの進み方を7年・5年で払い終わる形に縮めて作った
- 乱数の種は318。実在の会社の数字ではありません

## 主な結果（95%区間が正解を含んだ割合、各1,000組）
| データの型 | 事故年度の数 | マック（正規） | マック（対数正規） | ブートストラップ |
|---|---|---|---|---|
| マックの前提どおり | 10 | 94.0% | 94.2% | 96.7% |
| | 7 | 92.3% | 92.5% | 94.6% |
| | 5 | 91.2% | 90.9% | 94.0% |
| 1マスごとに独立 | 10 | 88.7% | 89.5% | 91.2% |
| | 7 | 86.9% | 86.6% | 90.8% |
| | 5 | 88.4% | 88.7% | 92.4% |
| インフレが強まる | 10 | 43.1% | 45.0% | 52.9% |
| | 7 | 82.0% | 83.2% | 88.3% |
| | 5 | 86.4% | 87.3% | 92.0% |

- **前提どおりのデータなら、ほぼ95%**。マックの方法は94%、ブートストラップは97%（1,000組で数えたときの誤差の目安は±1.4ポイント）
- **三角形が小さいと、マックの方法は94%→92%→91%と下がった**。ブートストラップは97%→95%→94%
- **ばらつき方が前提と違う（1マスごとに独立）と、マックは87〜90%、ブートストラップは91〜92%**。95%には届かない。外れ方は上下ほぼ同じ
- **インフレが強まる型では、事故年度10年で43〜53%しか含まなかった**。外れた組のほぼすべてで、正解が区間より上（備金が足りない側）だった。見積もりそのものが平均10%少なく、区間の幅の半分（10〜12%）とほぼ同じ大きさだったため
- 同じ型でも事故年度7年・5年では82〜92%。小さい三角形は、ほとんどがインフレの強まった後の年でできているので、見積もりの偏りが小さい（−4.5%、−0.7%）
- 区間の幅の半分は、見積もりに対して、事故年度10年で8〜12%、5年で14〜21%

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures がバイト単位で一致した
- 見積もりの誤差の平均は、インフレのない2つの型では+0.1〜+0.8%で、偏りはほぼない

## 注意（言えないこと）
- すべて架空のデータです。含んだ割合（94%、89%、43%など）は、ばらつきの大きさ・進み方の形・インフレの置き方で変わります。言えるのは「前提どおりなら名目に近い」「前提と違うと届かない」「偏りがあると大きく外れる」という並びまでです
- 幅は備金の合計についてだけ見ました。事故年度ごとの幅、1年先の動き（1年後に見積もりがどれだけ変わるか）は扱っていません
- ブートストラップは、残差を引き直して先の支払いにガンマ分布のばらつきを足す、よく使われる形の1つです。引き直しの回数は500回で、区間の端には引き直しの誤差が残ります
- マックの式の最後の年の分散は、決まった外挿の式で置いています
- 実際の備金の水準や、幅のとり方について助言するものではありません
