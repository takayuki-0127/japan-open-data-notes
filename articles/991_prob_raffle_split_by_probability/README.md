# 991 くじの当たりを「確率で山分け」すると、何がずれるのか？（確率の直感）

何人かでくじを持ち寄り、「当たった景品は確率で山分けしよう」と決めることがあります。ところが「確率」には、当たる本数の見込み、少なくとも1本当たる確率、1枚あたりの当たる確率と、いくつもの読み方があります。当たりが1本だけなら前の2つは同じ割合になりますが、当たりが何本もあると、少なくとも1本当たる確率は枚数に比例しなくなります。**ここでは、作成者が置いた架空の社内イベントのくじ（100枚・当たり10本、4人の仲間が1・4・15・30枚を持つ）で、3つの読み方で分けたときの1人あたりの取り分の見込みが、自分のくじだけのときの見込みからどれだけずれるかを、式と乱数の両方で数えました。当たりの本数と持つ枚数を変えるとどう動くかも確かめました。**

くじの例は、確率の数え方だけを扱います。くじを買う・引くことを勧めたり止めたりするものではありません。

## 主な結果

### 3つの読み方の取り分の見込み（100枚・当たり10本、`results/split_base.csv`）
| | Aさん（1枚） | Bさん（4枚） | Cさん（15枚） | Dさん（30枚） |
|---|---|---|---|---|
| 自分のくじの本数の見込み | 0.1個 | 0.4個 | 1.5個 | 3個 |
| 少なくとも1本当たる確率 | 10% | 34.84% | 81.92% | 97.71% |
| (a) 本数の見込みの割合で分ける | 0.1個（0%） | 0.4個（0%） | 1.5個（0%） | 3個（0%） |
| (b) 少なくとも1本の確率の割合で分ける | 0.2227個（**+122.75%**） | 0.776個（+94%） | 1.8248個（+21.66%） | 2.1764個（**−27.45%**） |
| (c) 1枚あたりの確率で分ける（均等） | 1.25個（+1150%） | 1.25個（+212.5%） | 1.25個（−16.67%） | 1.25個（**−58.33%**） |

（括弧の中は、自分のくじの本数の見込みからのずれ）

- **(b) で分けると、30枚のDさんの取り分の見込みは2.1764個で、自分のくじだけのとき（3個）より27.45%少なかった**。Dさんの少なくとも1本当たる確率97.71%は、1枚のAさんの10%の9.77倍で、枚数の比の30倍にならない。2本目・3本目の当たりは「少なくとも1本」に数えられないので、多く持つ人ほど割合が小さく出る
- (c) は、1枚あたりの確率が誰でも10%で同じなので、均等に分けることになる。Dさんは58.33%少なく、Aさんは1150%多くなった
- (a) は、どの人も自分のくじだけのときと同じ見込みになった。持ち寄る本数の見込み5本を、本数の見込みの割合で分けるので、式の上でそうなる
- 式の値と乱数20万回の値の差は、本数の見込みで0.0022個以内、少なくとも1本の確率で0.15ポイント以内、取り分の見込みで0.0006個以内だった

### 景品が0個になる割合（`results/a991_main.json`）
- 自分のくじだけなら、景品が0個の割合はAさん90.11%・Bさん65.09%・Cさん18.23%・Dさん2.35%（乱数20万回）
- 持ち寄って分けると、4人とも0個になるのは仲間の50枚がすべて外れたときだけで、0.0593%（式）・0.051%（乱数）だった
- 持ち寄ると、見込み（(a) のとき）は変わらずに、0個になる人がほぼいなくなる。ずれるのは見込みではなく、振れの大きさ

### 確かめ：当たりの本数と持つ枚数（式、`results/by_prizes.csv`）
| 当たりの本数 | 30枚の人のずれ（1・4・15・30枚） | 1枚の人のずれ（1・4・15・30枚） | 20枚の人のずれ（5・10・15・20枚） | 5枚の人のずれ（5・10・15・20枚） |
|---|---|---|---|---|
| 1本 | 0% | 0% | 0% | 0% |
| 3本 | −7.9% | +25.31% | −5.3% | +10.89% |
| 5本 | −14.8% | +52.28% | −10.04% | +21.8% |
| 10本 | −27.45% | +122.75% | −19.49% | +48.14% |
| 20本 | −39.85% | +260.99% | −30.1% | +91.59% |
| 30本 | −45.59% | +389.66% | −34.46% | +120.09% |
| 50本 | −51.57% | +626.48% | −37.05% | +144.72% |

（(b) 少なくとも1本の確率の割合で分けたとき、自分のくじの本数の見込みからのずれ）

- **当たりが1本なら、少なくとも1本当たる確率は枚数÷100で枚数に比例するので、(b) は (a) と同じになり、ずれは0だった**
- 当たりが3本以上になると、いちばん多く持つ人は5.3〜51.57%少なくなった。当たりが多いほど、持つ枚数の差が大きいほど、ずれは大きくなった
- (c) の均等のずれは、当たりの本数によらず同じ（1・4・15・30枚の30枚の人で−58.33%）。枚数の差だけで決まる

## 注意（言えないこと）
- 架空のくじです。100枚・当たり10本・4人の持つ枚数は作成者が置いたもので、ずれの大きさはこれで決まります。表のとおり、いちばん多く持つ人のずれは置き方で0〜51.57%まで動きます。ずれは式どおりの値で、乱数は式の確かめに使いました
- 新しく数えたのは、「確率で分ける」の読み方の違いが、当たりが1本のときは表に出ず、当たりが多いほど大きく出ること、持ち寄ると見込みは同じでも0個になる割合が大きく変わることです
- 景品は分けられるものとして見込みを数えました。実際の景品は1個ずつで、分け方の決まり（じゃんけん・順番など）によって結果は変わります
- どの分け方がよいかの助言はしません。(a) が自分のくじだけのときと同じ見込みになるのは、計算の上でそうなるということです
- くじを買う・引くことを勧めたり止めたりするものではありません
- 関連する記事：834（くじは先に引くのと後に引くのでどちらが有利か）は、戻さずに引くくじの順番を扱っています。828（1%を100回引いても当たらない人）は、毎回同じ確率で引くときの「少なくとも1回」を扱っています。同じ企画の987は、「少なくとも1回」の確率が回数でどう増えるかを、989は、1回の平均（期待値）が大きいくじでも多くの人がもらう量は平均よりずっと少ないことを扱っています。この記事は、確率を割合として分けるときの読み方の違いに絞りました
