# 954 区域を細かくすると、相関はどう変わるのか？（地図と場所）

区域ごとの平均を2つ並べて相関を出すと、「この2つは強く結びついている」と読みたくなります。けれども、同じ世帯のデータでも、区域を細かくするか大きくするかで相関の大きさは変わります。区域の平均どうしの相関は、1世帯ずつの相関とは別のものです。**ここでは、作成者が乱数で作った架空の町（48×48マス、世帯約1万8千）の世帯ごとの「店での1か月の買い物額」と「ネット注文の1か月の額」を、1×1マス（2,304区域）から24×24マス（4区域）までの9通りの大きさの区域でまとめ、区域の平均どうしの相関がどう動くかを200の町で数えました。** 世帯ごとの相関を負に置いた場合と、場所の傾向どうしに関係がない場合も数えました。

地図は架空の格子で、実在の地名や地図のデータは使っていません。区域を良い順・悪い順に並べることはしていません。

区域の線の引き方で「いちばん売れる地区」が入れ替わるかは関連する記事 945（区域の数を変えずに線の位置を変える話。この記事は線の位置ではなく区域の大きさを変える話）、人数の少ない区域の率が大きく振れることは 948 で扱っています。相関から「何時間で何点上がる」と読むときの外れ方は 927 で扱っています。この記事は、同じ世帯を区域の大きさだけ変えてまとめたとき、相関の大きさがどう変わるかに絞ります。

## 主な結果

### 区域の大きさと、区域の平均どうしの相関（基本の置き方、200の町）
| 区域の大きさ | 区域の数 | 1区域の世帯（平均） | 相関の平均 | 町ごとの10〜90% | 式の値 |
|---|---|---|---|---|---|
| 世帯ごと | — | 1 | **0.171** | 0.156〜0.186 | 0.17 |
| 1×1マス | 2,304 | 8 | 0.404 | 0.358〜0.445 | 0.401 |
| 2×2マス | 576 | 32 | 0.642 | 0.581〜0.692 | 0.640 |
| 3×3マス | 256 | 72 | 0.721 | 0.656〜0.772 | 0.718 |
| 4×4マス | 144 | 128 | 0.752 | 0.690〜0.808 | 0.751 |
| 6×6マス | 64 | 288 | 0.777 | 0.712〜0.831 | 0.776 |
| 8×8マス | 36 | 512 | **0.788** | 0.709〜0.851 | 0.785 |
| 12×12マス | 16 | 1,152 | 0.791 | 0.674〜0.884 | 0.790 |
| 16×16マス | 9 | 2,048 | 0.778 | 0.596〜0.918 | 0.776 |
| 24×24マス | 4 | 4,608 | 0.750 | 0.385〜0.979 | 0.748 |

- 世帯ごとの相関は0.171なのに、2,304区域では0.404、36区域では0.788になった。同じ世帯の同じ額でも、区域を大きくするほど相関は高く出た
- 区域の平均どうしの相関は、作成者が置いた「場所の傾向どうしの相関」0.8に近づいた。区域を大きくすると世帯ごとの分は平均で打ち消され、場所で決まる分だけが残るため。**ここは置いた値の写しで、式の値と200の町の平均の差は、どの大きさでも0.003以内だった**
- 区域の数が少ないほど、町ごとの振れは大きくなった。4区域では10〜90%が0.385〜0.979、36区域では0.709〜0.851だった
- 例の町1つ（18,431世帯）では、世帯ごとの相関0.172、576区域で0.676、36区域で0.804、9区域で0.801だった

### 世帯ごとの向きと区域の向きが逆になるとき（ρe=−0.2、200の町）
| | 世帯ごと | 1×1マス（2,304区域） | 2×2マス（576区域） | 8×8マス（36区域） |
|---|---|---|---|---|
| 相関の平均 | **−0.100** | 0.231 | 0.569 | **0.776** |
| 町ごとの10〜90% | −0.118〜−0.079 | 0.173〜0.291 | 0.493〜0.635 | 0.704〜0.843 |

- 世帯ごとの相関は200の町すべてで負（平均−0.100）だったのに、36区域の平均どうしでは0.776と強い正になった。区域の平均で「店で多く買う区域ほどネット注文も多い」と見えても、1世帯ずつでは「店で多く買う世帯ほどネット注文が少ない」ことがある

### 場所の傾向どうしに関係がないとき（ρs=0、200の町）
| 区域の数 | 相関の平均 | 町ごとの10〜90% | 絶対値が0.5を超えた町 |
|---|---|---|---|
| 世帯ごと | 0.091 | 0.061〜0.117 | 0% |
| 2,304 | 0.060 | −0.060〜0.160 | 0% |
| 36 | 0.013 | −0.292〜0.288 | 0.5% |
| 16 | 0.020 | −0.387〜0.395 | 8.0% |
| 9 | 0.041 | −0.481〜0.531 | **21.5%** |
| 4 | −0.023 | −0.794〜0.730 | **44.5%** |

- 場所の傾向どうしに関係を置かなくても、9区域では21.5%の町で相関の絶対値が0.5を超えた。区域の数が少ないと、たまたまの並びで強い相関が出る

### 確かめ：置き方を変えて（40通り、各50の町）
| 置き方 | 世帯ごとの相関 | 36区域の相関 |
|---|---|---|
| 場所の傾向どうしに関係がある24通り（ρs=0.5・0.8） | −0.165〜0.450 | **0.451〜0.808** |
| 場所の傾向どうしに関係がない12通り（ρs=0） | −0.191〜0.285 | −0.075〜0.030 |
| なめらかさ L=2マス・8マス（ほかは基本） | 0.170・0.172 | 0.774・0.795 |
| 1マスの世帯 2・32（ほかは基本） | 0.171・0.168 | 0.749・0.789 |

- ρs>0 の24通りすべてで、36区域の相関は世帯ごとの相関より高かった（差は+0.124〜+0.895）。36区域の相関は、ほぼ置いた ρs（0.5なら0.45〜0.51、0.8なら0.75〜0.81）で決まり、世帯ごとの相関の大きさ（w と ρe）にはあまりよらなかった
- 世帯ごとの相関が負で、36区域の相関が正になった組は40通りのうち5通りあった
- 1マスの世帯が少ないほど、細かい区域の相関は低く出た（1×1マスで、世帯2なら0.217、8なら0.396、32なら0.636）。細かい区域では世帯ごとの分が打ち消しきれないため

## 動かし方
```
pip install -r requirements.txt
cd src && python a954_scale_correlation.py
```
20〜45秒ほどで終わります（計算機の混み方で変わります）。`data/households_example_town.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の9ファイルがバイト単位で一致した（cmp、2回流して2回とも一致、約22〜45秒）
- 図3枚を開き、日本語・重なり・軸を確かめた
- 区域の平均どうしの相関が式の値と0.003以内で合うこと、世帯ごとの相関が式 w×ρs＋(1−w)×ρe（0.17）と合うことを確かめた。作りが置いたとおりに動いていることの確かめで、区域を大きくしたときの相関の行き先は置いた ρs の写しである
- 区域の平均の相関が世帯の相関と違うことは「生態学的誤謬」、区域の大きさや切り方で結果が変わることは「可変単位地区問題」として知られた話で、新しく見つけたことではない。数えたのは、その違いの大きさと、区域の数が少ないときの振れ

## 注意（言えないこと）
- 架空のデータです。場所で決まる分の割合（w=0.1）、場所の傾向どうしの相関（ρs=0.8）、世帯ごとの相関（ρe=0.1）、傾向のなめらかさ、世帯の数は作成者が置いたもので、結果はこれで決まります。36区域の相関は、場所の傾向どうしに関係がある24通りで0.451〜0.808と動きました。実在の町や店の数字を表すものではありません
- 区域は四角に切りました。同じ大きさでも線の引き方を変えると相関は変わりますが（945 と同じ話）、ここでは数えていません
- 区域の平均どうしの相関から、1世帯ずつの関係（ある世帯が店で多く買えばネット注文も多いか）は言えません。逆に、世帯ごとの相関から区域どうしの関係も言えません
- 場所で決まる分が、なぜ2つの額で似ているのか（店の近さ、配達の範囲など）は置いていません。どちらかがもう一方の原因かどうかも言えません
