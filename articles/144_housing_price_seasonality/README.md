# housing-price-seasonality-japan：不動産価格指数（住宅）は何月に高く出るのか

国土交通省「不動産価格指数（住宅）」の月次（2008年4月〜2025年11月、2010年平均＝100）と、指数の作成に使う取引件数（移転登記ベース）を使い、原系列（季節調整前）の季節の動きを調べたリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| 144 | 住宅の価格指数は何月に高く・低く出るのか。種類（住宅地・戸建住宅・マンション）や地域で違うか。取引件数の季節性は | 原系列の対数を STL（周期12、ロバスト）で分解し、月別の季節成分を平均。公表の季節調整値との比（原系列÷季節調整値）と比較。季節の幅と不規則な振れ（残差の標準偏差）の比較。前半（〜2016年）と後半（2017年〜）の形の相関 | `src/a144_season.py` |

## 主な結果
- 全国の住宅総合は、3月が年平均より+1.3%、9月が+0.6%と高く、10〜12月が−0.8〜−1.5%と低い。季節の幅（最大月−最小月）は2.8%で、不規則な振れ（0.7%）の約4倍。公表の季節調整値との比で見ても同じ形（幅2.8%）
- 戸建住宅は3月+1.7%・10月−1.3%、住宅地は1月・9月+1.2%・12月−2.1%、マンションは4月+0.9%・12月−1.4%。どの種類も12月（戸建は10月）がいちばん低い
- 季節の形は2008〜2016年と2017〜2024年でおおむね似ている（住宅総合の相関0.71）が、地域別・東京都では不規則な振れが季節の幅と同じくらい大きく、形も安定していない
- 取引件数は3月にマンション+38%・戸建+25%と大きく増え、1月はそれぞれ−20%・−26%

## 動かし方
`data/price_index_monthly.csv` と `data/transactions_monthly.csv` が入っているので、そのまま動きます。

```bash
pip install -r requirements.txt
python src/a144_season.py
```

元の Excel から作り直すときは、国土交通省の報道発表（令和7年11月分 https://www.mlit.go.jp/report/press/tochi_fudousan_kensetsugyo05_hh_000001_00252.html ）の「不動産価格指数（住宅）」と「取引件数」の Excel を `data/raw/144_housing_index.xlsx`・`data/raw/144_torihiki_kensu.xlsx` の名前で置き、2つの CSV を消してから実行してください。

## データ
| ファイル | 中身 |
|---|---|
| data/price_index_monthly.csv | 地域（全国・南関東圏・名古屋圏・京阪神圏・東京都）×月×種類（住宅総合・住宅地・戸建住宅・マンション（区分所有））：原系列、季節調整値、サンプル数 |
| data/transactions_monthly.csv | 全国×月：戸建住宅・マンション（区分所有）の取引件数 |

## 注意
- 季節性の推定には2024年12月までを使いました。2025年の月は速報で、あとの公表でサンプルが増えて値が変わります
- 不動産価格指数はヘドニック法で物件の質の違いを調整した指数ですが、調整しきれない物件の違い（年度末に売れる物件の種類など）が季節の動きに入っている可能性があります。季節の動きの理由は、このデータでは分けられません
- 季節の幅は1〜3%程度で、1か月ごとの原系列の上下には季節の動きが大きく入っています（例：全国の住宅総合の原系列は、平均して12月→1月に+2.4%、9月→10月に−1.4%動く）。月ごとの比較には季節調整値か前年同月比を使うのが安全です
- 取引件数は登記ベースで、契約の時期とはずれがあります
