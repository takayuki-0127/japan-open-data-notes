# 1014 合計点の差が小さいとき、順位の差は意味があるのか？（指数とスコア）

店や製品を合計点で並べると、1位と2位、10位と11位のように必ず順位が付きます。けれども、合計点は答えた客の顔ぶれで毎月少しずつ振れます。店どうしの合計点が近いと、隣の順位の差は振れの大きさより小さくなり、どちらが上かは客の顔ぶれしだいになります。**ここでは、作成者が乱数で作った架空のカフェ40店（店ごとの本当の合計点を作成者が置いたもの）で、1か月100人の答えから出した100点満点の合計点の差が、本当の差をどれだけ表すかを数え、隣の順位の差の大きさ、次の月も1位が続く割合、客の人数と店どうしの差の大きさでどう動くかを確かめました。**

## 主な結果

### 1か月分の40店（`data/stores.csv`、`results/a1014_main.json` の one_month）
- 40店の合計点は62.25〜73.97点。隣の順位どうしの差は**中央値0.2点**（いちばん大きい差でも3.1点）。39の隣の差のうち34が0.5点未満だった
- 1位の店33（73.97点）と2位（73.66点）の差は0.31点。店33は本当の合計点でも1位で、次の月は2位だった。客を選び直したときの店33の順位の90%の幅は1〜4位
- 客を選び直したときの順位の90%の幅は、**中央値で15位分**。40店のうち35店で10位分以上あった。90%の幅に1位が入る店は3店
- 1か月目と次の月の順位の相関は0.851、1か月目と本当の順位の相関は0.906。次の月までに順位は平均4.9位動いた

- 本当の合計点の店どうしの標準偏差は2.64点、1か月100人の合計点の測る振れは0.921点
- 差の大きさごとの「上の店が本当に上」の割合は、でたらめに選んだ2店では**式どおり**だった（差は最大0.77ポイント）。隣の順位の2店でも、ほぼ同じ値だった
- この式では、上の店が本当に上の確率が90%になる差は1.77点、75%になる差は0.93点（式どおりの値）

## データ

## 注意（言えないこと）
- 架空のデータです。店どうしの差の大きさ、客の甘さと散らばり、1か月の客の人数は作成者が置いたもので、結果はこれで決まります。隣の2店で上の店が本当に上だった割合は、置き方で52.48〜78.84%、1位が次の月も1位の割合は11.67〜91%まで動きました
- 差の大きさごとの「上の店が本当に上」の割合と、90%になる差は、正規分布の式どおりの値です。新しく数えたのは、40店を並べたときの隣の差がどれだけ小さいかと、そのときの順位の入れかわりの大きさです
- 客は来た人からでたらめに選ばれ、店の本当の点は2か月で変わらないと置きました。答える人の偏り（満足した人ほど答えるなど）や、月ごとの本当の変化は入れていません
- 合計点は5項目の平均を同じ重みで足しただけです。そろえ方や重みを変えると順位は別に動きます（1005・1006）
- 実在の店の評価やランキングの出し方を表すものではありません
- 関連する記事：930（合格点ぎりぎりで落ちた人と受かった人は、どれだけ違うのか）は、1点差の2人のどちらが上かを1回の試験の点で扱っています。836（実力差がどれだけあれば、偶然の逆転は起きにくくなるのか）・831（営業成績の月間1位は、何か月続くのか）は、勝ち負けや月間成績の入れかわりを扱っています。同じ企画の1009（項目の数を増やすと、合計点は安定するのか）は、項目の数と月ごとのぶれを扱っています。1006（重みを少し変えると、上位は何位入れ替わるのか）は、重みの小さな違いで1位が入れかわるかが1位と2位の差で決まることを、1010（平均で合わせるか、いちばん低い項目で合わせるか）は、翌月の順位とのそろい方を扱っています。この記事は、たくさんの店を合計点で並べたときの隣の順位の差に絞りました
