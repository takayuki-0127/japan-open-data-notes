# 毎月やること（月次レポートの運用）

架空の会社サンプルマート（架空）の設定での手順。データは合成なので「届いたファイルを置く」ところは、
実際には F247 の `src/02_整形.py` が作っている。実在の会社で同じ形にするなら、ここが現場のファイルの置き場になる（推測）。

| いつ | やること | コマンド・見る場所 | 終わりの合図 |
|---|---|---|---|
| 翌月1日〜5日 | 現場のファイル（POS・勤怠・廃棄・会計）が届く | F247 の `data/raw_synth/` に置かれる | — |
| 5日 | mart を作り、テストを流す | F247 `src/03_整える.py`（run_all.py の F247 の段） | テストの失敗 0（F247 `results/` のテスト結果） |
| 5日 | 速報 v1 を作る | F248 `src/02_整形.py` → `src/03_レポート.py` | `reports/report_YYYYMM_v1.*`。保留の店と「境目」の判定を確かめる |
| 5日 | 速報を送る | v1 の HTML（または PDF） | 送った先と日付を改訂履歴に書く |
| 20日 | 確定 v2 を作り、v1 と置き換える | 同じ手順（締めの日なし） | 予告していない判定の変化が 0 か（改訂履歴の欄） |
| 20日 | 照合する | `python run_all.py --check-only` | 数字のファイルの「違う」が 0 |
| 四半期に1回 | 偶然の幅を測り直す | F248 `src/03_レポート.py` の noise_widths（20通り） | 前回と大きく変わっていないか（F248 `results/` の幅の表） |
| 店の開店・閉店があったとき | 既存店の判定を確かめる | `python tests/test_rules.py` | OK。開店日が月の途中なら decisions.md の D1 を決め直す |

## 毎月見ないもの（見ると説明が増えるだけのもの）

- 1店・1日の数字の上下（偶然の幅が大きい。F246 の結果で、1店・日の売上は ±20%）
- 偶然の幅の内側の前年比の動き
- 売上の上下5店の並び（本当に差がある店は6%しか入らない。F248 の結果）
