# F248 月次レポートの「型」を作る ― 架空のスーパー「サンプルマート（架空）」で、載せる・載せないの決まりと速報・確定の版

看板記事 F248（③ 業務の再現：架空の会社で、F246〜F255 の3本目）。F246 で決めた KPI と、F247 で整えた mart を使い、分析担当が毎月出す**月次レポートの型**を作った。毎月同じ順番・同じ行で、Python が HTML・PDF・Markdown を自動で作る。**何を載せ、何を載せないか**を偶然の幅で決め、**締めのあとで数字が直るときの版（速報 v1 → 確定 v2）**の扱いも決めた。

- **会社・数字は架空（合成データ）。実在の会社とは関係がない。** 顧客のデータは使っていない。
- note：（公開後に記入）
- 成果物：月次レポートの決めごと `docs/report_rules.md`、見本（2025年12月）`reports/report_202512_v1.html`・`.pdf`（図2）と確定版、12か月分の Markdown、SQL `sql/monthly_report_kpi.sql`

## 問い
毎月の数字を「毎月同じ型」で報告するとき、どの動きを説明し、どれを説明しないか。締めの早い速報の数字があとで直るとき、報告をどう出し直すか。

## データ
- F247 の mart（コミット e8ba90f）：店×月 1,062行、会員の月次、dim。締めの日ごとの店×月は F247 の `build_mart_pd(raw, close_day=k)` で作り直した（`data/versions/`）。
- F246 の結果（コミット 3006b82）：偶然の幅の表、曜日・祝日の並びの効果。
- 市場の前年比（参考の行）：経済産業省「商業動態統計」スーパー販売額（F231 で取得し F246 に写したもの）。新しい取得はなし。
- FY2025 の計画（予算）：架空の経営企画が作った、という設定の合成（`data/plan_fy2025.csv`。前年同月 × 売上 +3%、人件費 +3%、その他の経費 +2%）。

## 手法
- **型**：①まとめ3行 ②KPI 表（毎月同じ11行）③要因（売上の分解・営業利益の計画との差の分解）④店の例外（5行まで）⑤次のアクション（担当は役割、期限つき）⑥載せなかったもの・改訂履歴。
- **偶然の幅**：F246 と同じく、乱数の種だけ変えて20回作り直し、KPI ごとに σ を測り直した（全社・月の売上 ±1.42%、F246 は ±1.33%）。
- **全社の KPI**：先月までの3か月の平均から 1.96σ を超えて動いたら「流れが変わった」。既存店売上・客数は市場の前年比との差で判定。上の KPI が KPI ツリーの下の動きで説明できるときは説明を下で1回だけ。
- **店の例外**：既存店の真ん中の店（中央値）と比べ、今月 3σ 超えか、3か月続けて同じ向きに 1σ 超え。同じ地域3店以上は1行に。
- **版**：v1 速報（翌月5日の締め）では、届いた割合 99.5% 未満の店を保留し、届いていない分を会計の売上高で補うと判定が変わるものを「境目」と予告。v2 確定（20日）は v1 と置き換え、予告していない判定が変わったときだけ知らせ直す。
- **SQL**：KPI 表を SQL Server 互換の書き方（CTE・CAST・CONCAT・SUBSTRING）で書き、DuckDB で流して pandas と照合（SQL Server そのものでは動かしていない）。

## 結果（seed 0、FY2025 の12か月）
- 12か月分のレポートを同じ型で自動で作った。まとめは毎月3行、店の例外は1か月 1〜5行（平均 2.8行）。
- **全社の KPI**：前年比のままだと1か月に平均 3.4行が「流れが変わった」になり、市場との差と KPI ツリーでまとめると、説明するのは 0.9（種20通りの平均）。seed 0 では 12か月で31の「動いた」のうち、説明したのは 10。
- 4月に**廃棄率**の流れが変わり（設定：地方の店の廃棄が FY2025 から 1.25倍）、同じ月から「地方の7店 廃棄率+」が例外に出続けた。
- **店の例外の決まり**（種20通り）：今月 1.96σ 超えは1か月 14.8件で、本当に差があるのは 61%。採用した決まり（3σ か 3か月続けて 1σ）は 11.3件・78%、見つけた割合 63%。**売上の前年比の上下5店を並べるやり方では、本当に差があるのは 6%**。
- **版**：5日の締めで、予告がなければ 12か月のうち7か月・計15の判定が速報と確定で「変わった」に見える。保留と境目の予告をつけると、予告なしに変わった判定は 0。締めを1日にすると 4、3日で 2、10日で 0。
- 見本の2025年12月：速報では営業利益 152百万円・計画比 −13.0%（幅を超えて下回った、ただし境目）→ 確定では 158百万円・−9.2%（幅の中）。既存店売上の前年比は −0.0% → +1.5%。
- 計画：FY2025 の営業利益の計画 7.81億円に対し実績 7.13億円（−8.7%）。計画比が幅を超えた月は下回り4・上回り2。

## 頑健性
1. **偶然の幅を測り直す**：F246 の幅とほぼ同じ（全社・月の売上 ±1.42% と ±1.33%、1店・月の売上 ±6.5% と ±6.4%、全社・月の営業利益 ±11.9% と ±11.5%）。`A_noise_widths_vs_F246.csv`
2. **乱数の種（店の例外の決まり）**：20通りで、決まりごとの件数・当たりの割合・見つけた割合を比べた。`B_store_rule_summary.csv`
3. **判定のしかた**：前年比そのまま・曜日補正・市場との差を、種20通りで比べた。`C_company_judgment_summary.csv`
4. **締めの日**：1・3・5・10日で、保留・境目・予告なしの変更を数えた。`D_close_day_summary.csv`
5. **SQL と pandas**：12か月×11行 の KPI 表が一致（差は最大 4.4×10⁻¹⁴）。`E_sql_vs_pandas.csv`
6. **計画の置き方**：計画の売上の伸びを +2%・+4% にすると、営業利益の計画比の判定が12か月のうち4・5か月で変わる（売上は1・6か月）。`F_plan_assumption.csv`

## 言えないこと
- 数字は架空の会社の合成データ。偶然の幅は合成の乱数の置き方での大きさで、実際の店のぶれ（天気・競合・欠品など）はもっと大きいかもしれない（推測）。
- 「本当に差がある」は、合成の設定で置いた差（20通りの平均で 1σ を超えるもの）。実際の店では答えが分からないので、当たりの割合は測れない。
- 市場との差で判定したのは、合成の売上の月の形を商業動態統計から借りているため、この会社では効きやすい。実際の会社では市場とのずれがもっと大きいはず。
- 計画比の判定は、計画の置き方しだいで変わる（頑健性 6）。計画は合成。
- 速報の「境目」は、会計の売上高が締めの時点でそろっている設定で作った。会計が遅い会社では使えない。
- 次のアクションの文面は型の例で、実際の原因を調べたものではない。

## 再現手順
```

# 先に F247 のフォルダで src/01〜03 を流しておく（締めの日ごとの店×月を作るため）

python src/03_レポート.py   # 偶然の幅を測り直し、12か月 × 速報・確定 のレポート（reports/）
python src/04_分析.py       # 頑健性（約1分）
python src/05_図.py         # figures/fig1〜6 と見本の PDF（Playwright の Chromium を使う）
```
