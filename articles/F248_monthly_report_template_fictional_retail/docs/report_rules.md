# サンプルマート（架空）月次レポートの決めごと v1

分析担当が毎月出す月次レポートの「型」と、載せるもの・載せないものの決まり。**会社・数字はすべて架空（合成データ）。**
KPI の定義は F246 の `kpi_definitions.md`、データは F247 の mart（`store_month.csv` など）。作るコードは `src/03_レポート.py`。

## 1. 型（毎月同じ順番）
| 節 | 載せるもの | 載せないもの |
|---|---|---|
| 1. 今月のまとめ | 3行まで。①営業利益（全店）の計画比・前年比 ②流れが変わった KPI ③店の例外の件数といちばん大きいもの | 幅の中の動きの理由、経緯の説明 |
| 2. KPI 表 | 毎月同じ11行（営業利益・売上（全店）、既存店売上、客数、買上点数、一品単価、来店頻度、粗利率（廃棄後）、廃棄率、人時粗利、人件費率）と参考の市場の前年比。今月・前年比・計画比・先月までの3か月・偶然の幅・判定 | 行の入れ替え、その月だけの指標 |
| 3. 要因 | 既存店売上を客数×買上点数×一品単価に分けた図、営業利益の計画との差を売上・粗利率・人件費・その他の経費に分けた図。文章は「流れが変わった」KPI だけ | 市場と同じ動きの説明、上の KPI の重ねての説明 |
| 4. 例外（店） | 決まり（4節）を満たした店。5行まで、利益への影響の目安が大きい順 | 店ごとの営業利益、売上の前年比の上下5店の順位 |
| 5. 次のアクション | 例外・流れが変わった KPI ごとに、内容・担当（役割の名前）・期限。前月のアクションが続いているか | 担当のない「様子を見る」 |
| 6. 載せなかったもの・改訂履歴 | 幅の中だった KPI の名前、毎月載せないもの、版ごとの日付と変わったこと | |

## 2. 全社の KPI の判定
- **偶然の幅**：同じ設定で乱数の種だけ変えて20回作り直し、同じ月の値の種の間の標準偏差（σ）を KPI ごとに出した（F246 と同じ作り方）。`results/A_noise_widths.csv`。
- **流れが変わった**：今月の値と、先月までの3か月の平均の差が、1.96σ ×√(1＋1/3) を超えたとき。
- **既存店売上・客数**は、市場（経済産業省「商業動態統計」スーパー販売額）の前年比との差で判定する。市場と同じ上下（天気・曜日の並び・物価）は説明しない。
- **売上（全店）**は店の出入りで動くので、流れは判定せず計画比だけで判定する。
- **KPI ツリー**：上の KPI（営業利益・人時粗利・人件費率・粗利率（廃棄後）など）の動きが、下の KPI（廃棄率・客数など）や市場と同じ売上の動きで説明できるときは「〜で説明」と書き、文章の説明は下で1回だけ。
- **計画比**：計画との差が 1.96σ を超えたときだけ、まとめに「幅を超えて下回った／上回った」と書く。

## 3. 計画
- FY2025 の計画は、架空の経営企画が 2025年3月に作った、という設定の合成の予算（`data/plan_fy2025.csv`）。
- FY2024 の同じ月の実績 × 売上 +3%（粗利率は同じ）、人件費 +3%、その他の経費 +2%。前年同月のない店×月は、同じ地域・大きさの店の平均 × 0.9。

## 4. 店の例外
- 比べる相手は既存店の**真ん中の店（中央値）**。全社の合計と比べると、ある地域がまとめて動いたとき、ほかの地域の店が逆向きの例外に見える。
- KPI は店で動かせる5つ：売上・客数・粗利率（廃棄前）・廃棄率・人時粗利。店の営業利益は使わない（1店・月の偶然の幅が ±205%、F246）。
- **今月 3σ を超えた**か、**3か月続けて同じ向きに 1σ を超えた**ときだけ載せる。
- 同じ地域で同じ KPI・同じ向きの店が3店以上なら1行にまとめる。同じ店で下の KPI も例外なら、上の KPI は「も」として添える。
- 5行を超えた分は付録（件数だけ本文に書く）。

## 5. 版（速報と確定）
| 版 | いつ | 何で作るか | 書くこと |
|---|---|---|---|
| v1 速報 | 翌月6日 | 翌月5日の24時までに届いた POS。廃棄・勤怠・会計はそろっている（設定） | 売上の届いた割合、確定までに動く幅（F247：平均 0.5pt、最大 1.6pt） |
| v2 確定 | 翌月20日 | すべて届いたあと | v1 からの変わり |

- v1 では、売上の届いた割合（POS ÷ 会計の売上高）が **99.5% 未満の店は例外の判定を保留**する。
- v1 では、届いていない分を店ごとの会計の売上高で補った場合に判定が変わるものを「**境目（確定版で確認）**」と書く。
- v2 は同じ場所で v1 と置き換える。**予告（保留・境目）していない判定が変わったときだけ全員に知らせ直す**。それ以外は改訂履歴に1行足す。
- FY2025 の12か月では、この2つの予告で、予告なしに判定が変わったのは 0（予告がなければ 7か月・15の判定が「変わった」に見えた）。

## 6. 出力
- 毎月 `reports/report_YYYYMM_v1.html`、`_v2.html`、`_v2.md`（チャットやメール用）、`report_YYYYMM.json`（判定の中身）。PDF はブラウザで HTML を印刷したもの。
- リポジトリには見本の月（2025年12月）の HTML・PDF・JSON と、12か月分の Markdown を置いた。ほかは `src/03_レポート.py` で作り直せる。
