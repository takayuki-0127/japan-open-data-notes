# F176 白書の文章は、年々読みやすくなったのか（文の長さ・漢字・語種・jReadability の時系列）

看板記事 F176。3つの白書の HTML 版から本文の文を約39万文取り出し、読みやすさの指標を年ごとに計算して並べた。

- 1文の長さ
- 漢字・カタカナの割合
- 漢語・外来語の割合
- 総合指標 jReadability

比べるのは読みやすさの指標だけで、白書の中身や作った省庁の評価はしない。

## 問い

白書の文章は、年を追って短く・やさしくなったのか。答えは、どの指標で測るか、どの白書を見るか、どの部分の文を選ぶかで変わるのか。

## 手法

| 段階 | 方法 |
|---|---|
| 本文の文 | 同じ白書・同じ年のページの20%以上に出る行（サイトのメニューなど）と、「。」を含まない行（見出し・図表の題・表）を除き、「。」で区切る。5字未満・400字超の文は除く |
| 文の長さ | 1文の字数（空白を除く）の平均・中央値、100字以上の文の割合、1文あたりの読点の数 |
| 文字 | 漢字の割合。分母は句読点・記号・数字・英字を除いた字数。漢数字（〇一二…百千万億兆）を除いた版も作る。カタカナの割合 |
| 語彙 | fugashi＋unidic-lite で形態素解析し、UniDic の語種で漢語（音読みの語）・和語・外来語の割合を出す。白書・年ごとに400文を無作為に選ぶ（種は176） |
| 総合 | jReadability（李 2016）＝ 1文の語数×−0.056 ＋ 漢語率(%)×−0.126 ＋ 和語率(%)×−0.042 ＋ 動詞率(%)×−0.145 ＋ 助詞率(%)×−0.044 ＋ 11.724。大きいほどやさしい。0.5〜1.4が「上級後半」、5.5〜6.4が「初級前半」の区分 |
| 傾き | 年ごとの値を年に回帰し、10年あたりの変化を出す。95%区間は Newey–West（ラグ3）。期間は全体のほか、2004〜2025年（3つの白書の共通期間）、経済白書は1947〜1969・1970〜1999・2000〜2025年に分ける |

## 主な結果

### 1文の長さ（年代ごとの平均、字）

| 白書 | 1940年代 | 1950年代 | 1960年代 | 1970年代 | 1980年代 | 1990年代 | 2000年代 | 2010年代 | 2020年代 |
|---|---|---|---|---|---|---|---|---|---|
| 経済 | 77.2 | 73.0 | 68.5 | 69.4 | 69.0 | 73.7 | 68.7 | 70.3 | **80.1** |
| 情報通信 | | | | 79.8 | 76.7 | 81.2 | 87.0 | 82.5 | **95.1** |
| 国土交通 | | | | | | | 89.3 | 87.9 | 89.7 |

- **経済白書**
  - 1947〜1969年は10年あたり−5.3字（95%区間 −9.6〜−1.0）と短くなりました。1970〜1999年は+2.4字（1.1〜3.7）、2000〜2025年は+6.6字（2.2〜11.0）と長くなっています。
  - いちばん短いのは2009年の54.0字、いちばん長いのは2025年の92.3字です。
  - 100字以上の文の割合は、1960〜80年代に16%前後でしたが、2020年代は28%（2025年は39%）でした。
  - 79年全体の直線の傾きは+0.3字（−1.0〜+1.6）で、一方向の変化ではありません。
- **情報通信白書**：53年全体で10年あたり+2.4字（0.7〜4.1）長くなりました。100字以上の文は1970年代の27%から2020年代の39%に増えています。
- **国土交通白書**：2004〜2025年で+1.2字（−2.4〜+4.8）で、ほぼ横ばいでした。

### 文字と語彙（年代ごとの平均）

| 指標 | 経済 1940年代→2020年代 | 情報通信 1970年代→2020年代 | 国土交通 2000年代→2020年代 |
|---|---|---|---|
| 漢字の割合（漢数字を除く） | 45.7% → 49.6%（傾き +0.15pt/10年、p=0.13） | 50.2% → 45.8%（2010年代は43.6%、−1.5pt/10年） | 54.0% → 53.0% |
| カタカナの割合 | 2.0% → 6.5% | 8.1% → 15.9% | 6.4% → 8.8% |
| 漢語の割合（語） | 35.7% → 36.9%（1970〜90年代は32.9〜34.1%） | 39.4% → 35.6%（−1.3pt/10年） | 42.5% → 41.7% |
| 外来語の割合（語） | 1.1% → 2.7% | 3.0% → 5.6% | 2.4% → 3.2% |
| jReadability | −1.05 → −0.54（1970年代は+0.07） | −0.67 → −0.43（2010年代は0.00） | −1.46 → −1.21 |

- カタカナ・外来語は、3つの白書すべてではっきり増えました（どれも p<0.001）。
- 漢字の割合は、経済白書ではほぼ横ばいです。下がったのは情報通信白書だけでした。
- 漢語の割合も、経済白書では79年でほとんど変わりませんでした（傾き −0.04pt/10年）。
- jReadability は、3つの白書のどの年も、この指標でいちばん難しい区分（上級後半、0.5〜1.4）より下でした。
  - 経済白書は、1947〜1969年に10年あたり+0.60（0.39〜0.81）とやさしくなりました。1970〜1999年は−0.13（−0.20〜−0.06）です。
  - 情報通信白書は、53年全体で+0.11（0.04〜0.17）とやさしくなりました。文は長くなりましたが、漢語の割合が下がったためです。**同じ白書でも、文の長さで測るか、総合指標で測るかで向きが逆になりました。**

## 頑健性

| 確かめたこと | 結果 |
|---|---|
| 指標の定義（12指標） | 「長くなった／短くなった」は文の長さの指標どうしでそろう（平均・中央値・100字以上の割合）。漢字の割合は、漢数字を含めても除いても傾きはほぼ同じ（経済 −0.01〜+0.15pt/10年） |
| 白書の種類（2004〜2025年の共通期間、1文の長さ） | 経済 +8.3字/10年（0.3〜16.3）、情報通信 +5.2（−0.1〜10.4）、国土交通 +1.2（−2.4〜4.8）。はっきり短くなった白書はない |
| 文の選び方（2004〜2025年、1文の長さ） | 中央値・「」を含まない文・ページの前1/3・中1/3でも、経済白書は+7.7〜+12.1字/10年（「」を含まない文は95%区間 −0.1〜15.4 で、わずかに0をまたぐ）。数字を含まない文だけにすると+4.2（−1.3〜9.6）で、はっきりしなくなる。情報通信白書は数字を含まない文で+5.7（1.6〜9.8）。ページの後1/3は年ごとの文が少なく、経済 −10.9（−33.0〜11.2）、情報通信 +18.3（14.6〜22.0）と大きく振れる（`results/robust_summary.csv`、図5） |
| 章の選び方（全期間、ページの前・中・後1/3） | 情報通信白書の jReadability の改善は前・中で+0.16〜+0.17/10年、後では−0.03。経済白書の後1/3だけ、漢字・漢語が増え、jReadability が上がる（`results/robust_chapter.csv`） |
| 形態素解析の文の数（200・400・800） | jReadability の傾き：経済 0.009・0.027・0.021、情報通信 0.088・0.106・0.101、国土交通 0.200・0.104・0.113。向きは変わらない（`results/robust_sample.csv`） |

## 動かし方

```bash
pip install -r requirements.txt
# 1) 各白書のサイトを開き、src/01_取得_browser.js の WP を変えてコンソールで実行
#    window.crawl.pages を data/raw/pages_<wp>.json に保存（keizai / joho / kokudo）
python src/02_整形.py data/raw      # 本文の文 → data/raw/sentences.parquet
python src/03_分析.py data/raw .    # 指標と傾き → data/metrics_by_year.csv、results/
python src/04_図.py .               # 図 → figures/
```

- 記事の数字を出したときは、取得を白書ごとに少しずつ違う版で行いました。違いは本文の場所の指定の順番と、並行して取りに行く数だけで、`01_取得_browser.js` はそれを1本にまとめたものです。
- 白書のサイトの構成は変わることがあります。取り直すと、ページ数・文の数が少し変わる可能性があります。

## 言えないこと

- **読みやすさそのものではありません。** 文の長さ・文字・語種から計算した指標です。実際に人が読んで分かりやすいか（構成、図の使い方、用語の説明、要約版の有無）は測っていません。
- **jReadability は日本語学習者向けの教材で作られた式です。** 白書の値がどの区分より下になるのは、式の想定する文章の範囲を外れているためでもあります。区分の名前（上級など）を、そのまま読み手の水準と読まないでください。
- **HTML 版の作り方の違いが混ざります。** 昔の白書は、後から HTML にしたものです。旧字体・漢数字・句読点（「，」）の違いがあり、本文の区切り方もサイトで違います。数字を含まない文だけでも確かめましたが、作り方の違いを全部は除けていません。
- **文の分け方は「。」だけです。** 箇条書きや「。」のない文は入っていません。
- **2020年代の経済白書で文が長くなった理由は分けていません。** 分析の文章が増えたのか、書き方が変わったのか、HTML の分け方が変わったのかは、このデータからは分かりません（2025年版は14ページに本文がまとまっていました）。
- **3つの白書だけです。** 白書全体の傾向とは言えません。環境白書なども候補にしましたが、今回の取得の方法では安定して取れませんでした。
- **評価ではありません。** 文章が長い・漢語が多いことは、内容の専門性や正確さの必要から来ることもあります。どの白書・どの省庁がよい悪いを示すものではありません。
