# 240 グラフの縦軸を0から始めなかったら、どう見えたか（④ 振り返り R007）

このシリーズの記事のコードを数えて、図の縦軸の下端をどう決めていたかを振り返り、0から始めなかった棒グラフを、もとの数字で描き直したフォルダです。縦軸を切ると差がどれだけ大きく見えるかは、看板記事 [F70](../F70_chart_honesty) でいろいろな見せ方を使って比べています。この記事はその考え方で、自分の図を見直したものです。

## 問い

- 記事のコードは、縦軸の範囲をどう指定していたか
- 縦の棒グラフで下端を0より上にしていた（切っていた）のは、どこで、何か所あったか
- 実際の数字で描き直すと、どれくらい誇張して見えていたか

## 手法

| 手順 | 中身 |
|---|---|
| コードを数える（`src/a240_01_scan.py`） | 記事フォルダ501本の `.py` から、`.bar(`・`.barh(`・`.plot(` と、`set_ylim(`・`plt.ylim(` の最初の引数（下端）を拾う。下端を「0」「0より下」「0より上」「変数」に分ける |
| 候補を読む | 縦の棒（`.bar(`）があるファイルで0より上の下端を指定していた117か所のうち、直前の描画が棒だった28か所のコードを読み、「下端を切った縦の棒」「100や1を基準にした棒」「対数目盛」「二軸のもう一方の軸」「判断できない」に分けた（作成者の判定、`data/bar_flags_checked.csv`） |
| 描き直す（`src/a240_02_analyze.py`） | 記事227の家で淹れるコーヒーの購入量と、F244 の12月の売上を、0からと下端を切った形で描く。lie factor（見える変化 ÷ データの変化）は F70 と同じ定義 |

## 主な結果

- 図を描くコードがあった記事は492本。縦軸の範囲の指定は707回で、0から349回、0より下から137回、0より上から171回、変数で50回
- 縦の棒と0より上の下端が同じ図にあった28か所を読むと、下端を切った縦の棒が17か所（15本の記事）、100や1を基準にした棒が4か所、対数目盛2か所、二軸2か所、判断できないもの3か所
- 下端を切った棒には、予測の区間が目標の90%をどれだけ覆ったかを70〜100%で比べる図（F108・F75・F92・F37 など）が多かった
- 家で淹れるコーヒー（2019年 2,515g → 2025年 2,481g、−1.35%）は、縦軸を2,400gからにすると lie factor 約21.9
- F244 の12月の売上（BETWEEN 63.27百万円、>= と < 64.89百万円、−2.5%）は、元の図の縦軸（55から）で lie factor 約6.6

## 注意（言えないこと）

- コードの文字を数えたもので、出来上がった図を1枚ずつ見たのではない。棒の図とみなした28か所以外の89か所は、直前の描画が折れ線や点だったので外しただけ
- 28か所の分け方は作成者の判定。どの描き方が正しいかの判定ではない（100を基準にした棒や対数目盛は目的に合った描き方）
- 図に値を書き込んでいた場合、読み手が誤解したかは分からない
