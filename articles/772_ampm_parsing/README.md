# 772 「12:30 AM」のような午前午後の表記を読み違えると、時間帯別の件数はどれだけずれるのか（実務の型）

時刻を「12:30 AM」「09:15 PM」のような12時間表記の文字で持つデータがあります。12時間表記では「12:30 AM」は深夜0時30分、「12:30 PM」は昼の12時30分です。これを「PM なら12を足す」だけで24時間表記に直すと、12時台の読みがずれます。AM・PM を見ずに数字だけ取ると、午後はすべて午前に重なります。**ここでは、作成者が乱数で作った架空の受付ログ5万件で、3つの読み方の時間帯別の件数を比べました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A772 | 読み方で、時間帯別の件数はどれだけずれるか | 架空の受付ログ5万件（昼12時台と夜21時台に山、深夜0時台も少し）。正しい読み（strptime の %I %p）・PM なら12を足すだけ・AM/PM を見ない、の3通り。DuckDB（1スレッド）と Python で一致を確認。seed 772 | `src/a772_ampm.py`、`src/02_hour_duckdb.sql`、`src/01_hour_tsql.sql` |

## 主な結果

| | 正しい読み | PM なら12を足すだけ | AM・PM を見ない |
|---|---|---|---|
| 0時台 | 2,099件 | **0件** | 0件 |
| 12時台 | 4,324件 | **2,099件**（深夜0時台の分） | 6,423件 |
| 「24時」 | — | **4,324件** | — |
| 18〜23時 | 23,004件 | 23,004件 | **0件** |
| いちばん多い時 | 21時 | 21時 | **9時** |
| 時を読み違えた件数 | — | 6,423件（12.8%） | 33,904件（67.8%） |

- 「PM なら12を足すだけ」では、12:xx AM（深夜0時台）2,099件が昼の12時台に、12:xx PM（昼12時台）4,324件がありえない「24時」に移った
- AM・PM を見ないと、午後の件数がすべて1〜12時に重なり、夜21時の山が朝9時の山に見えた
- どちらの読み違いも、エラーにはならず、数字がそれらしく出る
