# 172 理容所は減り、美容所は増えた？ 衛生行政報告例で、生活衛生施設の60年を見る

厚生労働省「衛生行政報告例」の付表-1（興行場・旅館業・公衆浴場・理容所・美容所・クリーニング業の数、1965〜2024年度）を使ったフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A172 | 理容所と美容所の数はどう変わったか。ほかの生活衛生施設（銭湯・クリーニング・映画館・簡易宿所）と比べるとどうか | 長期推移、1施設当たりの従業者数、最大の年を100とした指数 | `src/a172_salons.py` |

## 主な結果
- 理容所は1986年度の14.5万が最大で、2024年度は10.8万（−25.5%）。美容所は1965年度の9.0万から27.8万（3.1倍）に増え、2024年度は理容所の2.57倍
- 美容所が理容所を上回ったのは1978年度
- 1施設当たりの従業者は、理容所が1.8人前後で横ばい、美容所は1990年代の1.7人から2.1人に増えた
- 最大の年と比べた2024年度の数は、一般公衆浴場（銭湯）−84%（1977年度比）、映画館−78%、クリーニング−58%、旅館・ホテル−38%。簡易宿所は2024年度が最大

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a172_salons.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/seikatsu_eisei_facilities.csv | 年度、映画館、旅館・ホテル営業の施設数、簡易宿所、公衆浴場、一般公衆浴場、理容所、従業理容師、美容所、従業美容師、クリーニング所の数 |

元の表：e-Stat「衛生行政報告例」令和6年度 付表-1（statInfId=000040359238、CSV）から、使う列を書き写した。

## 注意
- 1996年までは暦年、1997年度以降は年度の値
- 2010年度は東日本大震災の影響で、宮城県・福島県の一部の市町村が含まれない
- 一般公衆浴場は1977年以降の値（それより前は表にない）。2006年以前は「普通浴場」の数
- 旅館・ホテル営業は、2017年度以前は「ホテル営業」と「旅館営業」の合計
- 施設数は届出にもとづく数で、営業していても規模や売上は分からない
