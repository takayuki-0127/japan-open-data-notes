# 548 過去の損害を今の水準に直すトレンド率が1ポイントずれると、見込みの損害はどれだけずれるのか（手法の解説・保険数理）

過去の損害から来年の損害を見込むとき、昔の損害は物価などの伸び（トレンド）の分だけ今より小さいので、トレンド率で今の水準に直してから平均します。トレンド率を1ポイント間違えると、見込みはどれだけずれるか。**ここでは、本当のトレンドが年3%の架空の損害10年分（2016〜2025年、毎年約1,000件、大きな損害の割合 0・1・3%）で、2027年の1件あたりの損害額を見込むとき、(1) トレンド率をずらしたときのずれ、(2) トレンド率をデータから推定したときの振れ、(3) 免責500万円を超えた分でのずれを数えました。** 各場面2,000回くり返しています。数字は置いた損害の分布とトレンドで決まります。

## 主な結果
- **1ポイント高くすると、見込みは直近3年で +2.9%、5年で +4.0%、10年で +6.5%**（1ポイント低いと −2.9%・−3.8%・−6.1%）。古い年ほど直す年数が長いので、ずれが大きくなる。大きな損害の割合ではほとんど変わらない
- **免責500万円を超えた分では、同じ1ポイントが約2.2倍効く**（大きな損害1%で、3年 +6.4%、5年 +8.7%、10年 +14.6%）。大きな損害なしでは 3.3〜3.4倍（10年で +22.3%）、3%では 2.0倍
- **トレンド率を推定すると、振れが大きい**：10年分から推定したトレンド率のばらつき（標準偏差）は、大きな損害 0% で 0.5ポイント、1% で 0.9ポイント、3% で 1.2ポイント。5年分では 1.3・2.5・3.3ポイント
- **本当の3%から1ポイント以上ずれる割合**：10年分で 3%・20%・34%、5年分で 44%・64%・72%
- **推定したトレンド率で見込んだときの見込みの振れ（5〜95%点）**：10年分・大きな損害1%で −8.2%〜+10.1%、3%で −11.4%〜+14.0%

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- 本当のトレンド率（3%）を使うと、見込みのずれの平均がほぼ0（大きな損害0・1%で −0.06%〜+0.02%、3%では +0.1〜+0.7%。パレートの裾が重く、2,000回では平均が安定しきらない）になること
- 2027年の本当の値は、400万件の乱数で出している

## データ
- データファイルは置いていない。損害はコードの中で乱数から作る（seed 548）

## 注意（言えないこと）
- 架空の損害。実際の保険会社の損害や料率の数字ではない
- 保険料・料率・準備金の決め方を勧めるものではない。「トレンド率がこれだけずれると、見込みはこれだけずれる」を計算したもの
- 件数は毎年同じ水準と置き、伸びるのは1件あたりの損害額だけとした。件数のトレンド、制度の変更、損害の確定までの時間（支払いの遅れ）は入れていない
- トレンドは毎年一定の率と置いた。途中で率が変わる場合は扱っていない
