# 1142 低い音と高い音では、同じデシベルでも、測り方の重み付けしだいで大きさの数字がどれだけ違うのか？（音の大きさ）

音の大きさの数字は、波の値の二乗平均を dB（デシベル）にしたものが基本ですが、音の高さ（1秒あたりの振動の回数、この記事では「高さ」と書きます）ごとに重みを掛けてから足す測り方もよく使われます。重みの形は測り方ごとに違い、とくに低い音をどれだけ下げるかが大きく違います。同じ「−16 dB の曲」でも、どの重みで測った値かで、数字も曲どうしの順位も変わります。**ここでは、3つの重み（①重みなし、②低い音を大きく下げる重み、③低い音を少しだけ下げ高い音を少し上げる重み）で、1つの高さの音（式どおり）と、作成者が乱数で作った架空の曲1,000曲（重みなしではどれも −16 dB にそろえたもの）を測り、重みを付けた大きさがどれだけ違うか、上位の曲がどれだけ入れかわるか、低い音を +6 dB 足したとき大きさの数字がどれだけ上がるかを数えました。低い音のふくらみの高さ3つ×③の形9つの27通りでも確かめました。**

例の音と曲はすべて作成者が式と乱数で作ったもので、実在の曲・配信サービス・音量の基準・機材やソフトを表すものではありません。②の重みは、広く使われる重み付けの1つの形を式で写したもので、③は広く使われる別の重み付けの形に似せて作成者が置いた式です（その基準そのものではありません）。大きさはすべて数値の計算で、人に聞き比べてもらうことはしていません。

関連する記事：1006「重みを少し変えると、上位は何位入れ替わるのか？」は、総合指数の項目の重みを少し動かしたときの上位の入れかわりを扱っています。この記事は、音の高さごとの重みの形の違いで、大きさの数字と順位がどれだけ変わるかに絞ります。同じ企画の 1140「配信先が決まった大きさまで音量を下げるとき、大きく作った曲は得をするのか？」は重みなしで測った配信先の決まりを扱っています。1148「「3dB 上げる」は、音の強さで見るか波の振れ幅で見るかで、何倍の変化になるのか？」は、低い音の帯だけを上げたとき、重みなしの全体の大きさがどれだけ上がるかを式で確かめています。この記事の「低い音を足す」は、その上がりが重みしだいで変わることを数えます。

## 主な結果

### 1つの高さの音：重みなしで同じ dB の音を、重みを付けて測ると（式どおり、`results/tones.csv`）
| 高さ | ②低い音を大きく下げる重み | ③低い音を少し下げ高い音を少し上げる重み | ②−③ |
|---|---|---|---|
| 31.5 | −39.53 dB | −4.94 dB | −34.59 dB |
| 63 | **−26.22 dB** | −0.53 dB | **−25.69 dB** |
| 125 | −16.19 dB | −0.01 dB | −16.18 dB |
| 250 | −8.67 dB | 0.11 dB | −8.78 dB |
| 1,000 | 0 dB | 1.23 dB | −1.23 dB |
| 4,000 | 0.96 dB | 3.51 dB | −2.54 dB |
| 8,000 | −1.15 dB | 3.86 dB | −5.01 dB |

- **重みなしで同じ dB の音でも、高さ63の低い音は、②で測ると26.22 dB 小さく、③では0.53 dB しか小さくならない**。重みの形から決まる式どおりの値で、27本の帯の中で②は −39.7〜+1.27 dB、③は −5.03〜+3.94 dB 動く
- 高い音では、③のほうが②より大きく測る（8,000 で5.01 dB の差）

### 重みなしでは同じ −16 dB の曲1,000曲を、重みを付けて測ると（`results/a1142_main.json` の songs）
| | ②−①（重みなしとの差） | ③−①（重みなしとの差） |
|---|---|---|
| 平均 | −11.41 dB | −0.55 dB |
| 10〜90%の範囲 | −15.3〜−7.59 dB（幅7.71 dB） | −0.84〜−0.17 dB（幅0.67 dB） |
| いちばん小さい〜大きい | −18.56〜−4.5 dB | −1.11〜+0.69 dB |
| 置いた低い音のふくらみとの相関 | −0.654 | −0.477 |

- **重みなしではどれも −16 dB の曲が、②で測ると10〜90%の範囲で7.71 dB 散らばった**。③では0.67 dB だった。低い音のふくらみが0〜4 dB の曲（331曲）は②で平均 −9.28 dB、8〜12 dB の曲（333曲）は −13.62 dB と、低い音の多い曲ほど②で小さく測られた
- 配信先が③で同じ大きさにそろえたとしても、その曲どうしを②で測ると、10〜90%の範囲で7.05 dB 散らばった（②−③ が −14.46〜−7.41 dB）
- **②と③で大きい順に並べた順位の相関は0.872で、上位1割（100曲）のうち両方に入ったのは83曲（83%）だった**

### 低い音（高さ130以下の帯）を +6 dB 足すと（`figures/a1142_bass_add.png`）
| | 大きさの数字の上がり（1,000曲の平均） | 1,000曲の範囲 |
|---|---|---|
| ①重みなし | +5.24 dB | +3.59〜+5.88 dB |
| ②低い音を大きく下げる重み | **+0.76 dB** | +0.1〜+2.6 dB |
| ③低い音を少し下げ高い音を少し上げる重み | +4.94 dB | +2.77〜+5.84 dB |

- **同じように低い音を足しても、①や③で測る配信先では大きさの数字が5 dB 前後上がり、②で測ると0.76 dB しか上がらなかった**。配信先が決まった大きさにそろえるなら、①や③で測る配信先は曲全体をそのぶん下げるので、低い音以外の部分は5 dB 前後小さく再生されることになる（②では0.76 dB）

### 確かめ（27通り、各500曲、`results/grid.csv`）
| | 27通りの範囲 |
|---|---|
| ②−① の10〜90%の幅 | 6.35〜7.86 dB |
| ③−① の10〜90%の幅 | 0.18〜3.38 dB |
| ②と③の順位の相関 | **0.14〜0.98** |
| ②と③の上位1割の重なり | **36〜90%** |
| 低い音 +6 dB での上がり（①・②・③） | ①5.09〜5.26・②0.5〜1.2・③4.08〜5.16 dB |

- 27通りすべてで、重みなしで同じ大きさの曲の散らばりは②のほうが③より大きく、低い音を足したときの上がりは ①＞③＞② の順だった
- **順位の相関と上位の重なりは、低い音のふくらみをどの高さに置くかと③の形で大きく動いた**。ふくらみの真ん中が100 の9通りでは、順位の相関0.14〜0.869・上位1割の重なり36〜86%と幅が広く、③の高い側の上げ幅が2 dB のとき（0.14〜0.517）がいちばん低かった。高さ100 の音は②では −19.14 dB 下がるが、③（基本の形）ではほとんど下がらない（−0.07 dB）ため。ふくらみの真ん中が40 の9通りでは0.864〜0.978・72〜90%だった（`grid_ranges` の by_bump_center）

## 注意（言えないこと）
- 架空のデータです。曲の高さごとの強さの配分（傾き・低い音と高い音のふくらみ）は作成者が置いたもので、②と①の差の大きさ（平均 −11.41 dB）は、低い音をどれだけ置いたかでほぼ決まります。実在の曲で②と①がどれだけ違うかは表しません
- 1つの高さの音の値は、重みの式から決まる式どおりの値です。新しく数えたのは、曲どうしの散らばり・順位の入れかわり・低い音を足したときの上がりです
- ③は作成者が置いた式で、実在の基準の重みそのものではありません。実在の基準は、静かすぎる部分を除く、時間をならすなどの決まりも持ちますが、ここでは高さの重みだけを扱いました
- どの重みで測るのがよいか、人の耳でどう聞こえるかは言えません。この記事は、重みの違いで数字がどれだけ変わるかを数えただけです
