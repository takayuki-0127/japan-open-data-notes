# 437 人を運ぶ主役は、鉄道から自動車へ、いつ入れ替わったのか（輸送機関別の旅客輸送、1950〜2004年度）

「日本の長期統計系列」12-2-a（輸送機関別国内輸送－旅客）から、鉄道・自動車・旅客船・航空の割合を、運んだ人数と運んだ距離（人キロ）の両方で並べたフォルダです。369（石炭と石油）と同じ作り方です。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A437 | 自動車が鉄道を上回ったのは何年度か。鉄道の割合の最大と最小、航空は1割に届いたか | 4つの輸送機関の合計に占める割合を、輸送人キロと輸送人員で計算。1987年度の数え方の変更は、自家用貨物車を除いた場合も計算 | `src/a437_transport.py` |

## 主な結果
- 輸送人キロの割合：鉄道は1950年度 90.1% → 1960年度 75.7% → 1970年度 49.2% → 1980年度 40.2% → 2004年度 27.1%。自動車は 7.7% → 22.9% → 48.4% → 55.1% → 66.8%
- 自動車が鉄道を上回ったのは、輸送人キロで1971年度（50.6% 対 47.0%）、輸送人員で1966年度
- 乗用車がバスを上回ったのは1968年度、乗用車だけで鉄道を上回ったのは1979年度。バスの割合は1964年度の21.4%が最大
- 鉄道の割合の最小は2002年度の26.8%。ただし鉄道の輸送人キロは、1950年度の1,060億 → 1970年度 2,890億 → 2004年度 3,850億人キロで、3.6倍（最大は1993年度の4,030億）
- 航空の割合は、1968年度に1%、1997年度に5%を超え、最大は2002年度の5.9%。1割には届いていない
- 旅客船は1950年度の2.2%から2004年度は0.3%
- 1987年度から軽自動車と自家用貨物車が入り、自動車の割合は57.1%（1986年度）から64.8%（1987年度）に上がった。自家用貨物車を除くと1987年度は58.8%、2004年度は64.0%

## 確かめたこと
- 4つの輸送機関の合計は、表の「計」の99.7〜100.4%（丸めの分）
- 空のフォルダで流し直し、data・results・figures が一致した

## データ
- `data/raw/chouki_12-02-a.xls`：総務省統計局「日本の長期統計系列」12-2-a 輸送機関別国内輸送－旅客（昭和25年度〜平成16年度）。統計局のサイトでは掲載が終わっているため、Internet Archive の保存版から取得（2026-11-12）
- `data/passenger_km_by_mode_fy1950_2004.csv`・`data/passengers_by_mode_fy1950_2004.csv`：上の表から読み取った輸送人キロ（10億人キロ）と輸送人員（100万人）

## 注意（言えないこと）
- 2004年度までの数字です。その後は自動車の輸送の数え方が変わっていて、同じ線でつなげないため、長期統計系列のある年度までで書いています
- 1987年度から、自動車に軽自動車と自家用貨物車が入りました。1986年度と1987年度のあいだは同じ数え方ではありません。自動車が鉄道を上回った年度（1971年度）は、この変更より前です
- 旅客船の輸送人キロは、1969年度までは人数×27kmで計算した値です（表の注）。1987年度以降の JR は、会社をまたぐ分が重複して数えられています
- 歩き・自転車・二輪車は入っていません
- 全国の合計だけで、地域ごとの違い（都市と地方など）は見ていません。入れ替わった理由（道路・車の値段・所得など）も分けていません
