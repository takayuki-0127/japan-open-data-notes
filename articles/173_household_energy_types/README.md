# 173 家庭の光熱費の内訳で52都市を分けると、何タイプになる？ 家計調査でクラスタリング

総務省「家計調査」2024年 家計収支編（総世帯）詳細結果表 第11表「都市階級・地方・都道府県庁所在市別 1世帯当たり年間の品目別支出金額」を使ったフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A173 | 家庭の光熱費（電気・都市ガス・プロパンガス・灯油など）の内訳で、都道府県庁所在市と政令市（52都市）は何タイプに分かれるか | 4つの割合を標準化して k-means（k=2〜6 をシルエット係数で比較）。Ward法でも同じ分け方になるか確認 | `src/a173_energy_types.py` |

## 主な結果
- シルエット係数は k=3 が最も高く（0.484）、3タイプに分かれた。Ward法でも同じ分け方（調整ランド指数1.00）
- 灯油型（4都市：札幌・青森・盛岡・秋田）：灯油などが光熱費の26.4%。光熱費は1世帯当たり平均24.2万円
- 電気・プロパン型（30都市）：電気68.3%、プロパンガス14.2%。光熱費18.4万円
- 都市ガス型（18都市、大都市圏の多く）：都市ガス28.0%。光熱費16.1万円
- 光熱費が最も多いのは青森市（25.2万円）、最も少ないのは神戸市（13.1万円）で1.93倍。灯油などの割合と光熱費の相関は0.78

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a173_energy_types.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/kakei2024_utilities_by_city.csv | 全国・都市階級・地方・52都市の、世帯数分布、世帯人員、消費支出、光熱・水道、電気代、ガス代（都市ガス・プロパンガス）、他の光熱（うち灯油）、上下水道料（円/年、1世帯当たり） |

元の表：e-Stat「家計調査」2024年 家計収支編 総世帯 詳細結果表 第11表（statInfId=000040246947、Excel）から書き写した。電気代＋ガス代＋他の光熱＋上下水道料が光熱・水道と（四捨五入の1円の差を除き）合うことを確かめている。

## 注意
- もともとは環境省「自治体排出量カルテ」で市町村の部門別CO2排出の内訳を分類する予定だったが、データを取り出せなかったため、家計調査の光熱費（家庭のエネルギーの使い方）に切り替えた
- 支出金額（円）の内訳で、使ったエネルギーの量やCO2の量ではない。電気やガスの単価の地域差も入っている
- 総世帯（単身世帯を含む）の値。1都市あたりの調査世帯は多くないので、1年の値は振れやすい
- 「灯油など」は家計調査の「他の光熱」（灯油のほか、木炭なども含むが大半は灯油）
- 都市（県庁所在市・政令市）の値で、県全体の値ではない
