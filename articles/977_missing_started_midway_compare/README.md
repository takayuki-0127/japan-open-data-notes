# 977 途中から測り始めた項目は、前の期間とどう比べるのか？（欠けたデータ）

新しい項目を記録し始めると、記録を始める前の期間はまるごと空欄になります。しかも、記録はいっせいには始まらず、一部の店から順に広げたり、始めた直後は記録漏れがあったりします。そのまま合計を並べると、記録する店が増えるだけで大きく伸びて見えます。前の年との比べ（前年比）は、記録のない期間の値を何かで見込まない限り出せず、その見込みの置き方で答えが決まります。**ここでは、作成者が乱数で作った架空のチェーン20店の24か月（会計の件数は1か月目から、持ち帰りの件数は13か月目から店を順に足して記録。本当の持ち帰りの件数を作成者が置いたもの）で、記録を始めてからの伸びを4つの読み方で本当の伸びと比べ、記録のない1年目を割合で戻す2つのやり方で前年比がどれだけずれるかを数えました。**

チェーン・店・件数はすべて架空のもので、実在の会社の数字は使っていません。

計測の仕様が月の途中で変わったときの前月比は関連する記事 848、質問文を変えた年のアンケートの前年比は 872 で扱っています。報告が途中で抜けたり、途中で報告をやめた店を前の値で埋めたときの変化の見え方は、同じ企画の 973 で扱っています（こちらは記録が途中で始まる側です）。この記事は、項目そのものが途中から記録され始めた（前の期間は空欄）場面に絞ります。

## 主な結果

### 記録を始めてからの伸び（基本の置き方、200回の平均）
| 読み方 | 比べた月 | 見かけの伸び | 本当の伸び | ずれ |
|---|---|---|---|---|
| (a) 記録された件数の合計 | 13→24か月目 | **+332.32%** | +6.54%（全店の件数） | +325.78ポイント |
| (b) 記録した店の1店あたり | 13→24か月目 | +8.08% | +6.54%（全店の件数） | +1.54ポイント |
| (c) 記録した店の持ち帰りの割合 | 13→24か月目 | +63.85% | +6.49%（全店の割合） | +57.36ポイント |
| (d) (c)から記録の最初の3か月を除く | 16→24か月目 | **−3.3%** | +4.72%（全店の割合） | −8.02ポイント |
| (e) 13か月目から記録している5店だけ | 16→24か月目 | +4.39% | +4.72%（全店の割合） | −0.33ポイント |
| (c) 全店がそろった18か月目から | 18→24か月目 | +9.13% | +3.44%（全店の割合） | +5.69ポイント |
| (d) 全店がそろい記録漏れもない21か月目から | 21→24か月目 | +1.71% | +1.71%（全店の割合） | 0ポイント |

- 記録された件数の合計は、13か月目から24か月目で+332.32%伸びて見えた。本当の伸びは+6.54%で、残りは記録する店が5店から20店に増えた分と、記録漏れが減った分
- 割合にすると店の数の増え方は消えるが、(c) は記録の最初の月の記録漏れで13か月目が21.82%（本当33.56%）と低く、+63.85%伸びて見えた
- 記録漏れの月を除いた (d) は、16か月目に記録漏れのない店が大きい5店だけで、大きい店ほど持ち帰りの割合が高いと置いたので、36.96%（本当34.13%）と高く始まり、本当は伸びているのに−3.3%と下がって見えた
- 同じ5店だけで比べた (e) は+4.39%で、その5店の本当の割合の伸び（+4.39%）と同じだった。記録漏れのない月どうし・同じ店どうしなら、記録の値は本当の値と同じになる（**式どおり**）
- (b) 1店あたりが本当に近く見えたのは、記録漏れで上がる分と、小さい店が加わって下がる分が打ち消し合ったためと考えられる（推測）
- 例の1回分では、記録を始めた店の数は13か月目5店、14〜18か月目に3店ずつだった

### 前年比（13〜24か月目÷1〜12か月目、200回の平均）
| | 前年比 | 10〜90%の範囲 |
|---|---|---|
| 本当の持ち帰りの件数 | **+7.41%** | +7.03〜+7.81% |
| やり方1：割合は一定と置いて1年目を戻す | **−0.02%** | −0.2〜+0.17% |
| やり方2：割合は直線で動くと置いて1年目を戻す | +7.47% | +6.09〜+8.96% |
| （参考）会計の件数 | −0.02% | — |

- やり方1の前年比は、会計の件数の前年比（−0.02%）とまったく同じになった。1つの割合を両方の年に掛けるので、持ち帰りの割合の伸びは消え、会計の件数の伸びだけが残る（**式どおり**、32通りすべてで差0）。本当は割合が毎月0.2ポイント伸びているので、前年比は本当より7.43ポイント小さく出た
- やり方2は、2年目のデータから求めた傾き（毎月0.201ポイント、10〜90%：0.167〜0.237）を1年目へ伸ばしたので、本当の前年比に近かった。ただし、1年目も同じ直線で動いていたと置いたからで、ここは置いた前提が当たった結果
- 1年目の本当の持ち帰りの割合は平均32.25%だったが、やり方1が1年目に掛けた割合（2年目の記録漏れのない店月の割合）は35.67%だった

### 確かめ：置き方を変えて（32通り、各50回）
| 本当の割合の動き方 | 本当の前年比 | やり方1のずれ | やり方2のずれ |
|---|---|---|---|
| 一定 | −0.06〜+0.05% | −0.06〜+0.04ポイント | −0.39〜+0.35ポイント |
| 直線（0.2ポイント／月） | +7.43〜+7.74% | −7.72〜−7.41ポイント | −0.3〜+0.36ポイント |
| 2年目だけ伸びる（0.4ポイント／月） | +8.33〜+8.69% | −8.69〜−8.32ポイント | **+8.23〜+8.91ポイント** |
| 1年目だけ伸びる（0.4ポイント／月） | +6.52〜+6.86% | −6.85〜−6.53ポイント | −7.03〜−6.13ポイント |

（各行は、記録漏れ×始める順×店の大きさの効きの8通りの幅。全部は `results/robustness.csv`）

- どちらのやり方も、記録のない1年目の割合の動き方を当てたときだけ本当の前年比に近く、外すと−8.69〜+8.91ポイントずれた。2つのやり方のどちらが良いかは、記録のない期間に何が起きていたかで決まり、記録からは分からない
- 2年目だけ伸びたときのやり方2は、2年目の伸びを1年目にも伸ばすので、前年比を本当より8.23〜8.91ポイント多く見積もった。このときのやり方2の見積もりは、8通りの10〜90%の範囲を合わせて+14.79〜+20.48%だった
- 記録された件数の合計の見かけの伸び（13→24か月目）は、32通りで+140.7〜+703.1%だった（でたらめな順に始めると大きい）
- (c) 記録した店の割合のずれは、記録漏れがあると+52.85〜+78.73ポイント。記録漏れがなくでたらめな順で店の大きさの効きもなければ0.1ポイント以内、大きい店から始めて大きさの効きがあると−9.53ポイントまで（下がって見える）

```
pip install -r requirements.txt

```

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、2回流して2回とも一致、1本10秒以内）
- 図3枚を開き、日本語・重なり・軸を確かめた
- やり方1の前年比が、会計の件数の前年比と32通りすべてで一致すること（差0）を確かめた。式からそうなることの確かめで、新しく数えたものではない
- 記録漏れのない月どうし・同じ店どうしの (e) の伸びが、その店の本当の割合の伸びと同じになること（+4.39%）を確かめた
- やり方2が求めた傾き（0.201ポイント／月）が、置いた傾き（0.2ポイント／月）と合うことを確かめた

## 注意（言えないこと）
- 架空のデータです。店の大きさ、記録を始める順と速さ、記録漏れの割合、持ち帰りの割合の動き方は作成者が置いたもので、結果はこれで決まります。前年比のずれは、置き方で−8.69〜+8.91ポイントと動きました
- 記録のない1年目の本当の値は、記録からは分かりません。この記事の前年比は、作成者が1年目の本当の値を知っているので数えられたものです。実際には「割合は一定」「直線で動く」などの置き方を書き添えて読むしかありません
- 記録漏れは最初の3か月だけ、店ごとに同じ割合で起きると置きました。ずっと続く記録漏れや、店ごとに違う記録漏れは入れていません
- 季節による動きは入れていません。季節の動きがあると、記録のある月の選び方でさらにずれます（推測）
- 実在のチェーンの記録の始め方や件数を表すものではありません
