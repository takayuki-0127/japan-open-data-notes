# F184 空の便は、新幹線の開業でどれだけ減ったのか？（路線別の差の差）

## 問い

新幹線が開業すると、同じ区間の飛行機の旅客はどれだけ減るのか。どの路線でも同じように減るのか、鉄道の所要時間で違うのか。

F29（北陸新幹線と石川の宿泊客）・F95（隣の県へのこぼれ）では「行き先の人の数」を見た。この記事では、同じ開業を「空の便」の側から見る。

## データ

- 国土交通省「航空輸送統計調査」統計表3「国内定期航空路線別、区間別、月別運航及び輸送実績」（e-Stat、2006〜2019年・2021〜2025年の年報）
  - 路線ごと・月ごとの旅客数・座席数・運航回数（往復の合計）
  - 2020年の表は e-Stat の検索で見つからなかった。2020〜2022年はコロナ期なので、分析には使わない。
  - 2007年は表に載っている路線が少ない（151路線）。主な分析の期間には入らない。
- 8年以上あり、平均旅客3万人以上の214路線を使った（`data/air_routes_annual.csv`、`data/air_routes_monthly.csv`）。

## 手法

**開業イベントと処置路線**

| 開業 | 時期 | 処置路線 | 鉄道の最速所要時間（開業時、新幹線の駅まで、おおよそ） |
|---|---|---|---|
| 東北新幹線 新青森 | 2010年12月 | 羽田―青森 | 約3時間20分 |
| 〃 | 〃 | 羽田―三沢（比較用：八戸は2002年に開業済み） | ほぼ変わらない |
| 九州新幹線 全線 | 2011年3月 | 鹿児島―福岡 | 約1時間20分 |
| 〃 | 〃 | 大阪―熊本 | 約3時間 |
| 〃 | 〃 | 大阪―鹿児島 | 約3時間45分 |
| 北陸新幹線 金沢 | 2015年3月 | 羽田―富山 | 約2時間10分 |
| 〃 | 〃 | 羽田―小松 | 約2時間30分（金沢まで） |
| 北海道新幹線 新函館北斗 | 2016年3月 | 羽田―函館 | 約4時間 |
| 北陸新幹線 敦賀 | 2024年3月 | 羽田―小松（小松駅に新幹線が止まるようになった） | — |

**対照**
- 開業区間の空港（青森・三沢・富山・小松・能登・函館）に関わる路線と、九州新幹線と競合する路線は対照から外した。
- 残りのうち、前後の期間のすべての年に旅客5万人以上ある路線（109〜145路線）を対照にした。

**推定**
- 主の推定は差の差。処置路線の「開業後3年の平均 − 開業前3年の平均」（対数）から、対照の平均の同じ差を引いた。
- 確からしさは並べ替えで測った。対照の各路線を「処置されたことにした」ときの差の差と比べている（F177 と同じ考え方）。
- 7路線（三沢と敦賀を除く）の平均は、各イベントの対照から無作為に1路線ずつ選ぶ並べ替えを10,000回行って評価した。

**頑健性**
- 期間：前後2・3・4年
- 対照：全路線／羽田発着だけ／旅客20万人以上／開業前の伸びが近い10路線
- 開業の年を除く
- 開業前の傾きを延ばして差し引く
- 月次：開業月を除く前後12か月
- 同じ空港の別の路線との比較
- 座席数・搭乗率への分解

## 結果

**路線ごとの差の差（開業後3年、対照との差）**

| 路線 | 旅客 | 並べ替え p | 13通りの幅 | 座席 | 搭乗率 |
|---|---|---|---|---|---|
| 鹿児島―福岡 | −74% | 0.009 | −81〜−60% | −68% | −10.5pt |
| 羽田―富山 | −52% | 0.024 | −58〜−47% | −47% | −5.5pt |
| 羽田―小松 | −40% | 0.041 | −43〜−34% | −39% | −0.3pt |
| 大阪―熊本 | −27% | 0.14 | −32〜−20% | −29% | +1.2pt |
| 大阪―鹿児島 | −27% | 0.14 | −33〜−20% | −24% | −2.8pt |
| 羽田―青森 | −21% | 0.18 | −28〜−14% | −30% | +7.1pt |
| 羽田―函館 | −14% | 0.19 | −17〜−9% | −9% | −3.3pt |
| 羽田―三沢（比較用） | +11% | 0.40 | 0〜+22% | +4% | +4.4pt |
| 羽田―小松（敦賀延伸、2024〜25年） | −21% | 0.09 | −22〜−14% | −15% | −4.7pt |

- **7路線の平均：** −40%（並べ替え p＜0.001）。偶然の幅（95%）は −12〜+21%。
- **鉄道の所要時間との関係：** 鉄道が速いほど大きく減った。順位相関は 0.89（並べ替え p=0.011、7路線）。1時間速いと、減り方が対数で約0.4大きい。
- **偶然の幅：** 対照どうしの差の差のばらつき（95%）は −20〜+68% と広い。そのため函館（−14%）と青森（−21%）は、1路線だけでは偶然と区別できない。
- **月次（開業月を除く前後12か月）**

  | 路線 | 対照との差 | 並べ替え p |
  |---|---|---|
  | 鹿児島―福岡 | −62% | 0.009 |
  | 富山 | −44% | 0.007 |
  | 小松 | −39% | 0.007 |
  | 大阪―熊本 | −16% | |
  | 大阪―鹿児島 | −17% | |
  | 函館 | −9% | 0.15 |
  | 青森 | −5% | |
  | 敦賀延伸後の小松 | −6% | 0.29 |

  青森は、2011年3月の東日本大震災で新幹線が止まり、飛行機に移った分が入る。
- **開業前の傾きを差し引くと：** 処置路線は開業前から対照より年2〜3%ずつ減っていた。その分を除くと次のとおりで、順番は変わらない。

  | 路線 | 対照との差 |
  |---|---|
  | 青森 | −15% |
  | 鹿児島―福岡 | −63% |
  | 大阪―熊本 | −20% |
  | 大阪―鹿児島 | −32% |
  | 富山 | −46% |
  | 小松 | −35% |
  | 函館 | −8% |

- **同じ空港の別の路線（開業前後3年の変化）：** 新幹線と関係のない路線は減っていない。減ったのは空港全体の需要ではなく、新幹線と並ぶ路線だった。

  | 空港 | 新幹線と並ぶ路線 | 関係のない路線 |
  |---|---|---|
  | 富山 | 羽田―富山 −47% | 富山―新千歳 +7% |
  | 小松 | 羽田―小松 −34% | 小松―新千歳 +8%、福岡―小松 +19% |

- **座席：** 航空会社は座席もほぼ同じだけ減らし、搭乗率の変化は小さかった。

## F29・F95 との関係

- F29 では、北陸新幹線の開業後、石川の日本人の宿泊は約12%増えた。
- 同じ時期に羽田―小松の旅客は対照より約40%減っていた。行き来は増えても、空の便の取り分は大きく減ったことになる。ただし、両者の数え方（宿泊者数と旅客数）は違うので、これは推測。

## 言えないこと

- 処置路線は7本（イベントは4回）しかない。1路線ずつでは偶然の幅が広く、函館・青森・大阪―熊本・大阪―鹿児島は単独でははっきりしない。
- 2010〜2011年は東日本大震災、2024年は能登半島地震、2020〜2022年はコロナ期と重なる。特に青森と敦賀延伸の推定は、これらと分けられていない。
- 航空会社の路線再編（機材の小型化、LCC の参入・撤退、羽田の発着枠）は、新幹線と同時に起きている。座席の減少が「需要が減ったから」なのか「先に供給を減らしたから」なのかは、このデータでは分けられない。
- 鉄道の所要時間は開業時の最速列車のおおよその値で、本数・運賃・駅から空港までの時間は入れていない。
- 対照路線にも、別の開業や地域の出来事の影響が残っている可能性がある。
- 鹿児島―福岡は2004年の部分開業以降すでに減っていた。開業前の傾きを差し引いても大きく減ったが、もともと小さい路線（年約16万人）なので割合は大きく出やすい。

## 再現手順

