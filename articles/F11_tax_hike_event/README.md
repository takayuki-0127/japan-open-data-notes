# F11 消費増税の駆け込みと反動はどれだけだったか？（イベントスタディ）

看板記事 F11。2014年4月（5→8%）と2019年10月（8→10%）の消費増税の前後で、家計の支出がどれだけ前倒しされ（駆け込み）、その後どれだけ減ったか（反動）を、家計調査の月次データで測りました。2019年は食料が軽減税率で8%のままだったので、食料の動きの違いも比べています。

## 問い

- 増税の前に支出はどれだけ増え、後にどれだけ減ったか
- 2014年と2019年で違ったか
- 軽減税率の対象（食料）は、対象外の品目と違う動きをしたか

## データ

- 総務省「家計調査（家計収支編）」二人以上の世帯 長期時系列表（e-Stat）
  - 品目分類（小分類まで）支出金額（月、2000年1月〜）statInfId=000040270646
  - 同 名目増減率・実質増減率（前年同月比）000040270647・000040270648
- 実質化：名目と実質の前年同月比から、前年同月に対する物価の比 (1+名目)/(1+実質) を求め、2015年の各月を1として12か月ずつつないで品目ごとのデフレーターを作った（`src/02_整形.py`）
- グループ（小分類を合計）
  - 耐久財＝家庭用耐久財＋教養娯楽用耐久財＋自動車等購入＋自転車購入
  - 日用品＝家事用消耗品＋理美容用品＋医薬品＋保健医療用品・器具
  - 食料（酒類・外食を除く）＝食料−酒類−外食（軽減税率の対象のおおよその近似）
  - ほかに 消費支出・被服及び履物・外食・酒類

## 手法

| 手順 | 内容 |
|---|---|
| 「増税がなかった場合」 | 系列ごとに、増税の48〜13か月前で `log(実質支出) = 定数 + 傾き×月 + 月のダミー（季節）`（2019年は2018年1月の家計簿改正の段差も）を推定し、増税の12か月前〜12か月後に延ばす |
| 基準をそろえる | 12〜7か月前の平均のずれを0にそろえる（イベントスタディの基準期間） |
| 駆け込み・反動 | 増税の6か月前〜前月の差の合計＝駆け込み、増税の月〜4か月後の差の合計＝反動（2019年は2020年3月以降がコロナなので、比べやすいように両年とも5か月） |
| 不確かさ | 増税のない年（2005〜2012年・2016〜2017年）の4月と10月を「偽の増税月」にして同じ計算をし（18回）、その95%の範囲と比べる |
| 軽減税率 | 食料と日用品の差を、2014年（どちらも増税）と2019年（食料は据え置き）で比べる |
| 品目別 | 小分類ごとに、増税前3か月の上乗せが平常の何か月分かを計算（平常の月の支出が300円以上の品目） |

## 主な結果

| | 2014年 | 2019年 |
|---|---|---|
| 消費支出：増税の前月の差 | +11.4%（2014年3月） | +8.5%（2019年9月） |
| 消費支出：駆け込み（6か月、1世帯） | +3.08万円（平常の0.10か月分） | +3.61万円（0.13か月分） |
| 消費支出：反動（5か月） | −8.59万円（駆け込みの2.8倍） | −3.35万円（駆け込みとほぼ同じ） |
| 消費支出：反動（12か月） | −16.2万円 | （コロナを含むので比べない） |
| 耐久財：駆け込み（6か月） | +2.93万円（平常の2.4か月分） | +1.10万円（0.88か月分） |
| 耐久財：増税の前月の差 | +83% | +32%（2か月前に+52%） |
| 日用品：増税の前月の差 | +46% | +41% |
| 日用品：反動（5か月、平常の何か月分） | −0.61か月分 | −0.07か月分 |
| 食料（酒類・外食を除く）：増税前3か月の月平均 | ±0.0% | +1.2% |
| 食料：増税後5か月の月平均 | −4.5% | +1.6% |

- 偽の増税月での「前月の差」の95%の範囲は、消費支出 −5.2〜+4.2%、日用品 −11.9〜+8.1%、耐久財 −30.8〜+34.1%。2019年の耐久財の前月（+32%）は、この範囲の中に入る
- 駆け込みの量（6か月の合計）は、消費支出では偽の増税月の範囲（−4.8万〜+5.5万円）に入ってしまう。はっきり言えるのは「前月の跳ね上がり」と、耐久財・日用品の動き
- 2014年の消費支出は、増税後12か月にわたって「なかった場合」より約4%低いままだった。これには反動だけでなく、税率が上がって実質の所得が減った分も入っている（分けられない）
- 食料と日用品の差：増税前3か月は2014年 −14.6ポイント、2019年 −12.7ポイントで、差の差は +1.9ポイント（偽の増税月の範囲 −4.9〜+4.1ポイントの中）。駆け込みの差ははっきりしないが、増税後の食料の落ち込みは2019年にはなかった
- 駆け込みが大きかった品目：2014年は教養娯楽用耐久財（平常の2.2か月分）・設備材料（2.1）・家事用耐久財（1.9）・自動車等購入（1.5）、2019年は自動車等購入（1.2）・家事用耐久財（0.9）・他の光熱（0.7）

## 頑健性

`results/robustness.csv`（図5）。推定期間（36か月／72か月）、駆け込みの窓（3か月）、反動の窓（3か月）、2018年の段差の有無、名目のまま、基準期間でそろえない、の7通り。

- 耐久財の駆け込みは、どの設定でも2014年（1.5〜2.9か月分）が2019年（0.7〜1.8か月分）より大きい
- 2019年の食料の反動は、どの設定でも −0.03〜+0.14か月分で、はっきりした落ち込みはない（2014年は名目のままを除き −0.12〜−0.24か月分）
- 消費支出の駆け込みは0.05〜0.25か月分と設定で動き、2014年と2019年の大小は決められない
- 72か月の推定期間は、2019年の場合に2014年の増税期を含んでしまうので参考

## このデータで言えないこと

- 世帯ごとの行動（同じ世帯が前倒しして後で減らしたか）は分からない。集計値の動き
- 2019年10月〜2020年6月のキャッシュレス・ポイント還元、2019年10月の台風、2014年4月の Windows XP のサポート終了（パソコンの買い替え）など、同じ時期のほかの出来事が混ざる
- 2020年3月以降はコロナの影響が大きく、2019年の反動を1年分は測れない
- 「食料（酒類・外食を除く）」は軽減税率の対象の近似で、対象の範囲と完全には一致しない（外食は対象外、テイクアウトは対象など）
- 家計調査は標本調査なので、品目が細かいほど月ごとのぶれが大きい
- 2018年1月の家計簿の改正で、一部の品目の水準が変わっている（段差のダミーで調整したが、完全ではない）
