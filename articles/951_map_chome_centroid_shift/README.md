# 951 住所の「丁目」でまとめると、何がずれるのか？（地図と場所）

客の住所を地図に置くとき、番地まででなく「◯町◯丁目」までにまとめて、その丁目の真ん中（代表点）に全員を置くことがあります。1人ずつの場所は、丁目の大きさの分だけずれます。そのずれが、店からの距離、店の半径◯m の中の客の数、2つの店のどちらが近いかに、どれだけ響くか。**ここでは、作成者が乱数で作った架空の町（2,000m 四方を A町〜D町の4つの町と48の丁目に分けたもの。番地の付け方も作成者が決めた架空のもの）と客3,000人の場所で、客を丁目の真ん中に置き換えたときと本当の場所のときを比べ、店をでたらめな場所に300か所置いて、ずれを数えました。**

区域の線の引き方で「いちばん売れる地区」が入れ替わるかは関連する記事 945、まっすぐの距離と道のりの距離の違いは 947、店の商圏を半径で決めたときの重なりは 950 で扱っています。記録を15分単位にまとめると短い作業が消える、という「単位でまとめるずれ」は 893 と同じ形です。この記事は、客の場所を丁目の代表点にまとめることだけで、距離と半径の中の人数がどれだけずれるかに絞ります。

## 主な結果

### 基本の町（48丁目・客3,000人・店300か所）
| 数えたもの | 結果 |
|---|---|
| 丁目の大きさ（面積の平方根） | 中央値283.1m（200.6〜345.1m） |
| 1丁目の客の数 | 10〜203人 |
| 客の本当の場所から丁目の真ん中までの距離 | 中央値**117.6m**、90%の客で187.1m 以内（平均119.4m） |
| 店からの距離のずれ（店から500m 以内の客） | 平均74.6m、距離の**32.2%** |
| 半径500m の客の数のずれ（店300か所の平均） | **+0.4%** |
| 半径500m の客の数のずれ（10〜90%の範囲） | **−14.9〜+15.2%** |
| ±10%を超えてずれた店の場所 | **36.3%** |
| 本当は500m 以内なのに外に出た客／本当は外なのに入った客 | 13.1%／13.5%（本当の500m 以内の客の数に対して） |
| 2店のどちらが近いかが入れ替わった客 | **5.1%**（10〜90%の範囲 2.8〜8.2%） |

- 半径の中の客の数は、店300か所の平均ではほとんどずれなかった（+0.4%）。外に出た客（13.1%）と入った客（13.5%）が打ち消し合うため
- それでも、1か所ずつ見ると、店の場所の36.3%で±10%を超えてずれた。いちばん増えた場所では418人が589人（+40.9%）、いちばん減った場所では365人が255人（−30.1%）になった
- 1人ずつの場所のずれは、丁目の大きさでほぼ決まる。長方形の中に一様に住むなら、真ん中までの距離の平均は一辺の約0.38倍（正方形のとき）で、この式の値（113.1m）は数えた平均（119.4m）に近かった。ここは式どおりの結果

### 店からの距離ごとの、距離のずれ（店300か所×客3,000人）
| 店からの本当の距離 | ずれの平均 | 距離に対するずれの割合 |
|---|---|---|
| 0〜250m | 74.3m | **62.7%** |
| 250〜500m | 74.8m | 20.2% |
| 500〜1,000m | 75.8m | 10.5% |
| 1,000m 以上 | 73.7m | 5.8% |

- ずれの大きさ（m）は、店からの距離によらず75m 前後だった。そのため、店のすぐ近くの客ほど、距離の割合で見たずれが大きい

### 確かめ：置き方を1つずつ変えると（各10の町×店300か所の平均）
| 変えたもの | 値 | 場所のずれ（中央値） | 人数のずれ 10%点 | 90%点 | ±10%を超えた店の場所 | 入れ替わった客 |
|---|---|---|---|---|---|---|
| 丁目の数 | 12 | 235.3m | −41.3% | +46.3% | **77.2%** | 9.3% |
| | 24 | 166.3m | −27.4% | +28.4% | 62.3% | 6.9% |
| | **48（基本）** | 118.7m | −15.0% | +18.4% | 42.0% | 4.9% |
| | 96 | 84.2m | −9.6% | +10.7% | 20.8% | 3.5% |
| | 192 | 59.2m | −5.7% | +6.3% | **5.3%** | 2.4% |
| 半径 | 300m | 119.8m | −31.5% | +38.1% | 72.0% | 4.9% |
| | 800m | 117.8m | −8.1% | +7.3% | 12.0% | 4.8% |
| 代表点 | 丁目の真ん中（基本） | 118.8m | −16.6% | +17.8% | 44.4% | 4.8% |
| | 客の重心 | 113.8m | −16.3% | +16.8% | 41.2% | 4.8% |
| 集まる客の割合 | 0%（一様） | 119.1m | −12.2% | +15.0% | 34.1% | 4.1% |
| | 90% | 117.6m | −19.8% | +24.3% | 48.7% | 5.2% |
| 集まり方の広さ | 150m | 117.5m | −21.1% | +25.0% | 48.4% | 5.0% |
| | 400m | 118.4m | −13.8% | +15.0% | 37.8% | 4.8% |

- **±10%を超えてずれる店の場所の割合は、丁目の数と半径で5.3〜77.2%と大きく動いた**。決め手は「丁目の大きさ」と「半径」の比で、丁目が半径に比べて大きいほどずれる
- 代表点を丁目の真ん中から客の重心に変えても、±10%を超えた店の場所は44.4%から41.2%にしか減らなかった。丁目の中で客が散らばっている分は、代表点をどこに取っても消えない
- 客が集まっているほど（集まる割合90%・広さ150m）、ずれは少し大きくなった
- 基本の置き方は、変えたものごとに別の10の町で数え直したので、±10%を超えた店の場所は42.0〜44.4%と、基本の町1つの36.3%から動く

## 動かし方
```
pip install -r requirements.txt
cd src && python a951_chome_centroid.py
```
20秒ほどで終わります。`data/chome.csv`・`data/customers.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の9ファイルがバイト単位で一致した（cmp、約13.8秒）
- 図3枚を開き、日本語・重なり・軸を確かめた
- 客の場所のずれの平均（119.4m）が、長方形の中に一様に住むときの式の値（113.1m）に近いことを確かめた。作りが置いたとおりに動いていることの確かめ

## データ
- `data/chome.csv`：架空の48丁目（chome（丁目の名前）・town（町）・x0・x1・y0・y1（長方形の端、m）・cx・cy（真ん中）・n_customers（客の数）・area_m2（面積））
- `data/customers.csv`：架空の客3,000人（customer_id・x・y（本当の場所、m）・chome（住む丁目））
- `results/a951_main.json`：主な結果すべて
- `results/stores_base.csv`：店を置いた300か所ごとの、本当の人数・丁目の真ん中で数えた人数・ずれ・外に出た客と入った客の割合・入れ替わった客の割合
- `results/distance_bands.csv`：店からの距離ごとの距離のずれ
- `results/robustness.csv`：置き方を1つずつ変えた確かめ

## 注意（言えないこと）
- 架空のデータです。町の形、丁目の分け方、客の住み方、半径は作成者が置いたもので、結果はこれで決まります。±10%を超えてずれる店の場所の割合は、丁目の数と半径で5.3〜77.2%と動きました。実在の町や住所の付け方を表すものではありません
- 丁目は長方形と置きました。実際の区域は形がいびつで、川や道路で切れていることがあり、ずれはこれより大きくも小さくもなりえます（推測）
- 距離はまっすぐの距離で数えました。道のりの距離（947）は扱っていません
- どの細かさで住所をまとめるべきか、店をどこに置くべきかは言えません。この記事は、まとめ方で数がどれだけ動くかを数えただけです
