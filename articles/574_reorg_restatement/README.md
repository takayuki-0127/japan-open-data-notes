# 574 部署の統廃合があったとき、過去の部署別の数字を今の組織に組み替えると、推移はどう変わるのか（実務の型・組織変更と新旧対応表）

部署の統合・分割・事業の移管があると、部署別の月次実績は「当時の部署名」で残ります。今の組織で前年と比べるには、過去の数字を今の組織に組み替える必要があります。**ここでは、架空の会社（2022年4月〜2026年3月の月次実績）で、2024年4月の統合（営業1課＋営業2課→営業部）と、2025年4月の分割（企画部→企画部＋デジタル企画部）・移管（製品Xを開発事業部→サービス部）を置き、そのまま比べた場合、新旧対応表（比率つき）で組み替えた場合、正解（見えないチーム単位で組み替えた値）を比べました。** チームごとの伸び方は作成者が置いたもので、数字はその仮定で決まります。

| A574 | 組み替え方で、部署別の2025年度の前年比がどれだけ変わるか | 会社に残るのは当時の部署単位の月次実績だけとする。新旧対応表（old_dept・new_dept・ratio）で2025年3月以前を組み替え。分割・移管の比率は、変わった直後 k か月（1・3・6・12）の構成比で決める。正解は、作成者が置いたチーム単位の実績を今の組織で足したもの。組み替えた2024年度の合計を Python と SQL（DuckDB、1スレッド）で突き合わせ。seed 574 | `src/a574_reorg.py`、`src/02_restate_duckdb.sql`、`src/01_restate_tsql.sql`（未検証） |

## 主な結果
- **そのまま比べると**：2025年度の前年比が、サービス部 +107.6%、開発事業部 −55.4%、企画部 −39.1%になる。デジタル企画部は前年がないので比べられない。正解は、それぞれ +7.4%・−5.7%・+3.1%、デジタル企画部 +36.3%
- **対応表で組み替えると（直後3か月の比率）**：サービス部 +5.6%、開発事業部 −1.8%、企画部 +10.1%、デジタル企画部 +24.9%。段差は消えるが、分割・移管した部署の伸び率は正解と 2〜11ポイントずれる
- **ずれる理由**：デジタル企画部は伸びているので、分割した直後の構成比（44.7%）は、過去の本当の構成比（2024年度 41.0%、2022年度 27.1%）より大きい。その比率で過去を割り振ると、過去が大きく出て、伸び率が小さく出る
- **比率を決める期間**：直後1か月なら +27.4%、3か月なら +24.9%、6か月なら +22.0%、12か月なら +16.7%（正解 +36.3%）。長く取るほど、比率が今の構成に寄って、ずれが大きくなる
- **統合（営業部）は**：足すだけなので、組み替えても正解と同じ（+1.3%）。会社全体の前年比（+3.95%）は、どの方法でも変わらない

## 動かし方
```
pip install -r requirements.txt
cd src && python a574_reorg.py
```
数秒で終わります。`data/monthly_by_dept.csv`（month・dept・sales）と `data/dept_mapping.csv`（old_dept・new_dept・ratio、直後3か月の比率）を書き出します。チーム単位の実績は書き出していません。

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures がバイト単位で一致した（DuckDB は `SET threads=1`）
- 対応表で組み替えた2024年度の部署別合計が、Python と DuckDB の SQL で一致した
- T-SQL 版（`01_restate_tsql.sql`）は書いたが、SQL Server では動かしていない（**未検証**）

## データ
- 見えないチームが10あり、それぞれ年 −3%〜+35% で伸びる（デジタル企画のチームが +35%、製品Xが +12%）。季節の波と、月ごとに ±4%程度の揺れをつけた。単位は百万円
- 組織：〜2024年3月 営業1課・営業2課・企画部・開発事業部・サービス部／2024年4月 営業1課と営業2課を統合して営業部／2025年4月 企画部からデジタル企画部を分割、製品Xを開発事業部からサービス部へ移管
- 製品Xの移管の比率は、移管直後の製品X単独の実績が分かるものとして決めた

## 注意（言えないこと）
- 架空のデータ。実際の会社の数字ではない
- ずれの大きさは、分割・移管した部分の伸び方の違いで決まる。伸び方が同じなら、比率で割り振っても正解とほぼ同じになる
- 過去の細かい単位（チームや事業）の実績が残っていれば、比率を使わずに組み替えられる。残っていないときの近似として比率を使っている
- 人事評価や組織の決め方についての助言ではない
