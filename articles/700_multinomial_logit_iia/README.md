# 700 選択肢を1つ足したとき、多項ロジットは他の選択肢のシェアをどう奪うと見て、本当の動きとどれだけずれるのか（手法の解説・正解の分かるデータで試す）

多項ロジットには「無関係な選択肢からの独立（IIA）」という性質があります。新しい選択肢を足すと、それは今ある選択肢から、いまのシェアに比例して同じ割合で客を奪う、と見ます。よく似た商品を足したときは、本当は似た商品の客を主に奪うはずなので、この見方はずれます。**ここでは、よく似た商品 B・C と別の種類の商品 A がある架空の選択データを、入れ子ロジット（本当の選び方）で作り、多項ロジットと入れ子ロジットを当てはめて、「A・B だけの棚に C を足す」ときのシェアを本当の値と比べました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A700 | C を足したときのシェアの予測は、本当の動きとどれだけずれるか | 本当の選び方は入れ子ロジット（B と C が同じ入れ子、λ＝0.3）。効用＝定数（A 0、B 0.2、C 0.2）−1.0×価格。2万人が {A,B} か {A,B,C} の棚（半々）を見て、価格は2〜3の一様乱数。多項ロジット・入れ子ロジットを最尤法で当てはめ、価格をすべて2.5にした棚で C を足す前後のシェアを比べた。λ を0.1〜1.0に変えたときも比べた。seed 700 | `src/a700_iia.py` |

## 主な結果（λ＝0.3、価格はどれも2.5）
| | A・B だけの棚（A ／ B） | C を足した棚（A ／ B ／ C） | C のシェアのうち A から来た分 |
|---|---|---|---|
| 本当 | 45.0% ／ 55.0% | 39.9% ／ 30.0% ／ 30.0% | 16.9% |
| 多項ロジットの予測 | 50.2% ／ 49.8% | **34.6%** ／ 34.3% ／ 31.1% | **50.2%** |
| 入れ子ロジットの予測 | 45.5% ／ 54.5% | 40.1% ／ 29.0% ／ 30.9% | 17.3% |

- 本当は、C のシェアの83%は似た商品 B から来た。多項ロジットは A と B から半分ずつ（いまのシェアに比例）と見て、C を足したあとの A のシェアを5ポイント小さく見積もった
- 多項ロジットは価格の係数も1.49と、本当の1.0より大きく推定した。入れ子ロジットは1.00、λ は0.301と、本当の値に近かった
- B と C が似ているほど（λ が小さいほど）、A のシェアの予測のずれは大きかった（λ＝0.1で本当43.3%・多項ロジット36.5%、λ＝1.0で29.0%・29.6%）

## 動かし方
```
pip install -r requirements.txt
cd src && python a700_iia.py
```

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- λ＝1.0（B と C が似ていない）では、多項ロジットと入れ子ロジットの予測が一致した
- λ を変えた比較（by_lambda.csv）は、λ ごとに新しく乱数でデータを作って当てはめ直した

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 700）

## 注意（言えないこと）
- 架空のデータです。商品の似ている度合い・価格の効き方は作成者が置いたもので、ずれの大きさはこれで決まります
- 本当の選び方を入れ子ロジットで作ったので、入れ子ロジットが当たるのは当然です。実際のデータでは、どの商品が同じ入れ子かを決める必要があり、決め方を間違えると入れ子ロジットもずれます
- 価格や販売の判断の助言ではありません
