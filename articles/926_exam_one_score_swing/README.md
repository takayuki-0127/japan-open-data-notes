# 926 1回の試験の点は、実力からどれだけ振れるのか？（試験と点数）

試験の点は、1回きりの数字として扱われがちです。けれども同じ人が同じ実力のまま受け直しても、点は同じにはなりません。1問ごとに当たり外れがあり、どの問題が出るかも回によって違い、当日の調子もあります。**ここでは、作成者が乱数で作った架空の社内試験（問題の集まりと受ける人の本当の実力を作成者が置いたもの）で、1回の点が本当の点からどれだけ振れるか、振れの元を1つずつ足すとどう増えるか、同じ人が2回受けると合否がどれだけ入れかわるかを数えました。**

合格率30%の試験で合格ラインちょうどの実力の人が何%受かるかは関連する記事 921、合格点ぎりぎりで落ちた人と受かった人の違いは 930、年ごとに問題が変わる試験の点の比べ方は 924 で扱っています。少ない回数の成績の振れは 833（運と実力）、月ごとの不良率の上下が偶然かどうかは 913（品質と検査）で扱いました。この記事は、1回の試験の点の振れの大きさそのものに絞ります。

## 主な結果

### 本当の点ごとの、1回の点の振れ（各5,000回）
| 本当の点 | 振れの標準偏差 | 本当の点からのずれ（10〜90%） | 10点以上ずれた割合 | 参考：二項分布の式の標準偏差 |
|---|---|---|---|---|
| 30点 | 8.1点 | −10〜+10点 | 26.8% | 6.5点 |
| 40点 | 8.7点 | −12〜+12点 | 30.5% | 6.9点 |
| 50点 | 8.9点 | −12〜+12点 | 31.6% | 7.1点 |
| 60点 | **8.7点** | **−12〜+10点** | **30.5%** | 6.9点 |
| 70点 | 7.8点 | −10〜+10点 | 25.3% | 6.5点 |
| 80点 | 6.9点 | −10〜+8点 | 17.9% | 5.7点 |
| 90点 | 4.9点 | −6〜+6点 | 6.0% | 4.2点 |

- 本当の点60点の人でも、1回の点は10〜90%で48〜70点に散らばり、3回に1回近く（30.5%）は10点以上ずれた
- 振れは真ん中の点の人ほど大きく、90点の人では4.9点まで小さくなった。満点の近くでは、上に振れる余地がないため
- 二項分布の式（50問を同じ正答率でくり返す場合）の標準偏差より、どの点でも振れは大きかった。当日の調子の分が上乗せされたため（下の表）

### 本当の点60点の人で、振れの元を1つずつ足すと（各20,000回）
| 振れの元 | 振れの標準偏差 | 本当の点からのずれ（平均） | 10〜90%の範囲 |
|---|---|---|---|
| ①1問ごとの当たり外れだけ（同じ50問） | 5.4点 | +2.7点 | −4〜+10点 |
| ①＋②どの50問が出るか | 6.8点 | +0.0点 | −8〜+8点 |
| ①＋②＋③当日の調子（基本） | **8.8点** | −0.2点 | −12〜+12点 |

- 同じ50問なら、振れは5.4点だった。ただしこの50問では、この人の見込みは62.6点で、本当の点より2.7点高い。どの50問が出るかで、1回の点の見込みそのものがずれる
- どの50問が出るかを入れると6.8点、当日の調子（実力の標準偏差の0.2倍）を入れると8.8点に増えた
- 同じ基本の置き方でも、乱数を変えて数え直したので、振れの標準偏差は上の表の8.7点・この表の8.8点・確かめの表の8.8点と少し動く

### 1,000人が2回受けたら（合格60点）
| | 値 |
|---|---|
| 1回目と2回目の点の相関 | **0.90** |
| 点の標準偏差（1回目） | 24.4点 |
| 本当の点の標準偏差 | 23.3点 |
| 1回の点の本当の点からのずれ（標準偏差） | 7.8点 |
| 参考：標準偏差×√(1−相関) の式 | 7.7点 |
| 2回の点の差の平均（絶対値） | 8.4点 |
| 2回の点が10点以上ちがった人 | 34.6% |
| 2回の点が20点以上ちがった人 | 9.4% |
| 2回で合否が入れかわった人 | **11.7%** |
| 1回目の合否が、本当の点の合否と違った人 | 9.9% |
| 本当の点が55〜65点の人（133人）で、合否が入れかわった割合 | **42.1%** |
| それ以外の人で、合否が入れかわった割合 | 7.0% |

- 相関0.90は高く見えるが、それでも3人に1人は2回の点が10点以上ちがい、合否は11.7%で入れかわった
- 本当の点が合格点の近く（55〜65点）の人では、42.1%で合否が入れかわった。合格点の近くでは、1回の合否はほとんど運で決まる
- 全体の11.7%は、受ける人のうち合格点の近くにいる人がどれだけいるかで決まる数で、置いた実力の分布（平均の点・散らばり）の写しでもある。この記事では、この割合の置き方による幅は数えていない（合格点の近くの人が多い集まりほど大きくなる、推測）。得点が合格点のすぐ両側だった人の本当の実力ともう一度受けたときの合否は 930 で数えている
- 相関0.90は、受ける人どうしの実力の差が大きい（点の標準偏差24.4点）ことにも支えられている。実力の近い人ばかりの集まりなら、同じ振れでも相関は下がる（推測。この記事では数えていない）
- 1回の点のずれの標準偏差（7.8点）は、2回の点の相関から出す式（7.7点）とほぼ一致した

### 本当の点が違う2人の、点の逆転（60点をはさむ2人、各20,000回）
| 本当の点の差 | 低い人が同点以上を取る確率 | 低い人が上回る確率 |
|---|---|---|
| 2点 | 46.7% | 40.5% |
| 5点 | **37.3%** | 31.3% |
| 10点 | 23.2% | 18.6% |
| 15点 | 12.8% | 9.8% |

- 本当の点が10点ちがっても、1回の試験では5回に1回近く（18.6%）は低い人が上回った

### 確かめ：問題数と当日の調子を変えると（本当の点60点の人、各5,000回）
| 問題数 | 当日の調子 | 振れの標準偏差 | 10〜90%の範囲 | 10点以上ずれた割合 | 参考：二項分布の式 |
|---|---|---|---|---|---|
| 20問 | 0 | 11.1点 | −15〜+15点 | 50.3% | 11.0点 |
| 20問 | 0.2 | 12.1点 | −15〜+15点 | 53.6% | 11.0点 |
| 20問 | 0.4 | **15.2点** | −20〜+20点 | 63.3% | 11.0点 |
| 50問 | 0 | 6.7点 | −8〜+8点 | 18.6% | 6.9点 |
| **50問** | **0.2（基本）** | **8.8点** | −12〜+12点 | 30.5% | 6.9点 |
| 50問 | 0.4 | 12.5点 | −16〜+16点 | 49.0% | 6.9点 |
| 100問 | 0 | **4.9点** | −6〜+6点 | 5.1% | 4.9点 |
| 100問 | 0.2 | 7.2点 | −10〜+9点 | 19.0% | 4.9点 |
| 100問 | 0.4 | 11.7点 | −16〜+14点 | 43.7% | 4.9点 |
| 50問（難しさの散らばり0.5） | 0.2 | 10.1点 | −14〜+12点 | 38.0% | 6.9点 |
| 50問（難しさの散らばり1.5） | 0.2 | 8.1点 | −10〜+10点 | 27.2% | 6.9点 |

- 振れの標準偏差は、置き方で**4.9〜15.2点**と動いた
- 正直に書くと、当日の調子を0にした振れ（20問11.1点・50問6.7点・100問4.9点）は、二項分布の式（11.0点・6.9点・4.9点）とほぼ同じで、式どおりの結果。振れが問題数の平方根に反比例して減るのも式どおり
- この記事で新しく数えたのは、当日の調子を入れると問題を増やしても振れが残ること（当日の調子0.4では100問でも11.7点）と、それが合否の入れかわりにどれだけ効くか
- 問題の難しさの散らばりを0.5に狭めると、振れは10.1点に増えた。難しさが実力の近くに集まると、当日の調子で正答率がまとめて動きやすくなるためと考えられる（推測）

## 動かし方
```
pip install -r requirements.txt
cd src && python a926_one_score_swing.py
```
10秒ほどで終わります。`data/examinees_two_sittings.csv` もこのとき作ります。

## 注意（言えないこと）
- 架空のデータです。問題の難しさと見分ける力、当日の調子の大きさ、正答の確率の式は作成者が置いたもので、結果はこれで決まります。とくに当日の調子の大きさは、実際にどのくらいかを作成者は知りません。振れの標準偏差は置き方で4.9〜15.2点と動きました。実在の試験の点の振れを表すものではありません
- 2回の受験は、実力が変わらず、1回目の問題を覚えていない、と置きました。2回目のほうが慣れる・問題を覚える場合は入れていません（過去問をくり返したときの覚えた分は 925 で扱っています）
- 当日の調子は、人ごと・回ごとに独立に、同じ大きさで振れると置きました。調子が崩れやすい人とそうでない人の違いは入れていません
- 合格点をどこに置くべきか、何問の試験にすべきか、受け直しを認めるべきかは言えません。この記事は、1回の点の振れの大きさを数えただけです
