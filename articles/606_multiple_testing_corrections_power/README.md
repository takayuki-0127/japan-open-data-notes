# 606 指標を10個見るとき、Bonferroni・Holm・BH の補正で、本当の効果を見つける力はどれだけ違うのか（手法の解説・正解の分かるデータで試す）

指標をいくつも同時に検定すると、効果が0でも「差あり」がどこかに出やすくなるので、p値の基準を補正します。ただ、補正は本当の効果も見つけにくくします。**ここでは、10個の指標を同時に検定する場面をシミュレーションで作り、本当に効果のある指標の数（0〜10）を変えて、補正なし・Bonferroni・Holm・Benjamini–Hochberg（BH）の4つで、偽の「差あり」の出方と、本当の効果を見つける割合を数えました。** 効果の大きさは、1つだけ検定すれば5%水準で70.5%見つかる大きさ（z の平均 2.5）です。各条件2万回。数字は置いた前提で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A606 | 補正の方法で、偽の「差あり」と本当の効果を見つける割合がどう変わるか | 無補正（p<0.05）、Bonferroni（p<0.05/m）、Holm、BH（偽発見率5%）。FWER（偽が1つでも出る割合）・FDR（差ありのうち偽の割合）・検出力。指標どうしの相関0.5の場合、指標の数 m=2〜100 の場合も。各2万回、seed 606 | `src/a606_multiple_corrections.py` |

## 主な結果
- **効果が0のとき（k=0）**：偽の「差あり」が1つでも出る割合は、補正なしで **40.0%**、Bonferroni 4.8%、Holm 4.8%、BH 4.9%。指標どうしの相関が0.5なら、補正なしでも29.2%
- **効果のある指標を見つける割合（10個中3個に効果）**：補正なし 70.6%、Bonferroni **38.2%**、Holm 39.3%、BH **46.8%**
- **効果のある指標が多いほど、Holm と BH が追いつく**：10個中8個に効果なら Bonferroni 37.9%、Holm 42.7%、BH 60.8%。10個すべてに効果なら Holm 45.1%、BH 64.5%。Bonferroni は k によらず約38%
- **そのかわり BH は FWER を守らない**：10個中3個に効果のとき、偽の「差あり」が1つでも出る割合は BH 8.8%（Bonferroni 3.6%、Holm 4.2%）。BH が5%に抑えるのは「差ありのうち偽の割合」（このとき3.6%）
- **指標の数を増やすと（5分の1に効果）**：Bonferroni の検出力は m=2 で60.6%、10 で38.2%、100 で16.4%。BH は m=100 でも35.1%

```
pip install -r requirements.txt
cd src && python a606_multiple_corrections.py
```
十数秒で終わります。

## 確かめたこと
- 空のフォルダで流し直し、results・figures がバイト単位で一致した
- 自作の BH の判定が、scipy の `false_discovery_control` の結果と一致した
- 1つだけ検定したときの検出力（理論値 70.5%）と、補正なしの検出力（70.5〜70.7%）が合うこと

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 606）
- 仮定：各指標の検定統計量は正規分布（効果なしは平均0、効果ありは平均2.5、分散1）、両側検定。相関ありの場合は1つの共通の要素で全指標に相関0.5

## 注意（言えないこと）
- シミュレーションの結果。効果の大きさと数は作成者が置いたもので、結果はこれで決まる
- どの補正を使うかは目的で決まる。「1つでも偽が出たら困る」なら Bonferroni か Holm（Holm は Bonferroni より常に同じか良い）、「見つけたもののうち偽の割合を抑えたい」なら BH
- 補正の前に、主に見る指標を1つ決めておく、という方法もある
