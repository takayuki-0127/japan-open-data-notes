# 1120 回復と攻撃を同じ割合で強くすると、勝負がつくまでの長さはどう変わるのか？（ゲームの数値設計）

ゲームの数値を見直すとき、攻撃力と回復量を「どちらも2割増し」のように同じ割合で強くすることがあります。差し引きの力関係は変わらないので、勝負がつくまでの長さは「1.2で割った分だけ短くなる」と考えたくなります。けれども、体力の上限をそのままにすると、1ターンごとの体力の上下の振れも1.2倍に大きくなります。回復が攻撃に追いつくほど、勝負は差し引きではなく振れでつくようになり、長さは1.2で割るよりも大きく縮みます。**ここでは、作成者が置いた架空のゲームの1対1の勝負（体力の上限1,000・攻撃力100・4割のターンで回復、ダメージに±25%の振れと1割の会心）で、回復の見込みを受ける攻撃の見込みの0〜1.2倍に置いた5通りについて、攻撃力と回復量に同じ倍率（1.1〜2倍）を掛けたときの勝負がつくまでのターン数を、各4,000回の勝負で数えました。体力の上限・ダメージの振れ・回復を選ぶ確率を変えた48通りの確かめも行いました。**

例のゲームと数値は架空のもので、実在のゲームやその計算式を表すものではありません。課金やくじの話は扱いません。

関連する記事：同じ企画の 1115「平均のダメージで敵の体力を割って「何回で倒せるか」を出すと、実際の回数とどれだけずれるのか？」は、回復のない敵を倒すまでの回数の見込みのずれを扱っています。1121「敵の体力を1割増やすと、倒すのに要る回数はなぜ1割より大きく跳ねることがあるのか？」は、回数が整数で切り上げの段をまたぐと跳ねることを扱っています。この記事は、双方が攻撃と回復をする勝負で、攻撃と回復を同じ割合で強くしたときの長さの変わり方に絞ります。

## 主な結果

### 倍率 k ごとの勝負の長さ（各4,000回、`results/length_by_k.csv`）
| 回復の見込み÷受ける攻撃の見込み ρ | k＝1 の平均ターン数 | k＝1.1 | k＝1.2 | k＝1.5 | k＝2 |
|---|---|---|---|---|---|
| 0（回復量0） | 14.02 | 0.905倍 | **0.833倍** | 0.663倍 | 0.497倍 |
| 0.5 | 27.08 | 0.901倍 | 0.816倍 | 0.644倍 | 0.467倍 |
| 0.8 | 50.63 | 0.884倍 | 0.783倍 | 0.578倍 | 0.379倍 |
| 1.0 | 85.04 | 0.841倍 | 0.729倍 | 0.472倍 | 0.283倍 |
| 1.2 | 152.21 | 0.754倍 | **0.611倍** | 0.36倍 | **0.187倍** |
| 目安：1/k | − | 0.909 | 0.833 | 0.667 | 0.5 |
| 目安：1/k² | − | 0.826 | 0.694 | 0.444 | 0.25 |

（倍は、同じ ρ の k＝1 の平均ターン数に対する比）

- **回復量0（ρ＝0）では、両方を1.2倍にすると長さは0.833倍で、1/1.2 の目安どおりだった**。差し引きで体力が減る速さが1.2倍になるだけなので
- **回復が強いほど、同じ1.2倍で長さは大きく縮んだ**。ρ＝1.0 で0.729倍、ρ＝1.2 では0.611倍と、1/1.2² の目安（0.694）よりも縮んだ。k＝2 では ρ＝1.2 で0.187倍だった
- ρ＝1.0 や1.2 では、差し引きでは体力がほとんど減らない（上限で捨てる回復の分だけ減る）。勝負は、悪いターンが続いて体力が0まで落ちることでつく。1ターンの振れが k 倍になると、振れだけで決まる長さの目安は 1/k² になる（振れの大きさの2乗に反比例するため）。回復が攻撃を上回るときは、これよりさらに縮んだ
- 真ん中の長さも同じ向きだった。ρ＝1.2 の真ん中は k＝1 で112ターン、k＝1.2 で69ターン、k＝2 で21ターンだった
- **体力の上限も同じ1.2倍にすると、5通りすべてで長さは1.0倍（k＝1 と同じ）だった（作りどおり）**。攻撃・回復・体力をそろって同じ割合で変えると、勝負は同じ形のまま大きさだけが変わる

### 勝負の長さの散らばり（ρ＝1.2）
| k | 平均 | 真ん中 | 90%の位置 |
|---|---|---|---|
| 1 | 152.21 | 112 | 328 |
| 1.2 | 93.0 | 69 | 196 |
| 1.5 | 54.8 | 41 | 114 |
| 2 | 28.49 | 21 | 59 |

- 長い勝負ほど大きく縮み、90%の位置は k＝1.2 で328→196ターンになった

### 確かめ：置き方を変えると（k＝1.2、48通り、各1,500回、`results/grid_k12.csv`）
| ρ | k＝1 の平均ターン数の範囲 | k＝1.2 での長さ（k＝1 に対する比） |
|---|---|---|
| 0 | 6.11〜33.77 | 0.819〜0.895倍 |
| 0.5 | 10.57〜65.93 | 0.804〜0.839倍 |
| 1.0 | 13.89〜525.65 | 0.686〜0.814倍 |
| 1.2 | 15.15〜6,335.57 | **0.383〜0.85倍** |

- 48通りのうち40通りで 1/1.2（0.833）より縮み、11通りで 1/1.2²（0.694）より縮んだ。1/1.2² より縮んだのは、すべて ρ が1.0以上の置き方だった
- いちばん縮んだのは、体力の上限2,000・振れ±10%・回復を選ぶ確率0.5・ρ＝1.2 の0.383倍（k＝1 の平均は6,335.57ターン）
- 体力の上限が500で、1回の攻撃に比べて体力が小さいと、ρ＝1.2 でも0.85倍にとどまる置き方があった（回復を選ぶ確率0.3・振れ±10%）。数回の攻撃で勝負がつき、回復が効くひまがないため（推測）
- ρ＝0 で 1/1.2 から少し離れたのは（0.819〜0.895倍）、倒すのに要る回数が整数で、少ない回数では切り上げの段が効くためと考えられる（推測。段で回数が跳ねることは 1121 で扱っています）

## 注意（言えないこと）
- 架空のデータです。体力・攻撃力・回復量・回復を選ぶ確率・ダメージの振れは作成者が置いたもので、縮み方はこれで決まります。とくに ρ（回復の見込み÷受ける攻撃の見込み）の置き方で、縮み方が 1/k から 1/k² を超えるところまで変わります
- 回復するか攻撃するかは、毎ターン決まった確率で選ぶと置きました。体力が減ったら回復するなど、状況で選び方を変える決まりは入れていません。選び方を変えると結果も変わります
- 同じ強さの2人の勝負だけを数えました。強さの違う2人の勝ち負けの割合や、敵の側だけを強くした場合は数えていません
- 1/k・1/k² は目安の式で、この勝負の長さを正確に表す式ではありません
- 長さのよしあし（どれくらいの長さがよいか）は言えません。この記事は、同じ割合で強くしたときに長さがどう変わるかを数えただけです
