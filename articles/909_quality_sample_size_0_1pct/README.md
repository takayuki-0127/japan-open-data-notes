# 909 不良率0.1%を確かめるには、何個検査すればよいのか？（品質と検査）

「不良率は0.1%以下です」と言うには、何個を検査すればよいのでしょうか。1,000個を調べて不良が0個でも、それだけでは0.1%以下とは言えません。さらに、本当の不良率が0.1%に近い工程ほど、言えるまでに要る個数は急に増えます。**ここでは、作成者が乱数で作った架空の工場の部品（本当の不良率を作成者が置いたもの）で、検査した個数と見つかった不良の数から「0.1%以下」と言える確率を、本当の不良率ごとに数えました。あわせて、日ごとに不良率が上下する工程で、検査する品物を1日の製品だけから取ると、どれだけ言い間違えるかを数えました。**

## 主な結果

### 不良が0個なら何個で言えるか（式）
| 検査した個数（不良0個） | 不良率の95%の片側の上限 |
|---|---|
| 1,000個 | 0.299% |
| 2,000個 | 0.150% |
| 3,000個 | 0.100% |
| 5,000個 | 0.060% |

- 不良0個のとき「0.1%以下」と言えるのは、**2,995個**から（よく使われる目安「3÷0.1% ＝ 3,000個」とほぼ同じ）
- 1,000個を調べて不良0個でも、言える上限は0.299%まで。本当の不良率が0.1%でも、1,000個で不良が0個になる確率は36.77%あり、0.3%でも4.96%ある

### 個数ごとに許される不良の数と、「0.1%以下」と言える確率（式）
| 検査した個数 | 許される不良の数 | 本当0.02% | 本当0.05% | 本当0.08% | 本当0.10% | 本当0.15% | 本当0.20% |
|---|---|---|---|---|---|---|---|
| 1,000個 | （言えない） | 0% | 0% | 0% | 0% | 0% | 0% |
| 3,000個 | 0個 | 54.9% | 22.3% | 9.1% | 5.0% | 1.1% | 0.25% |
| 5,000個 | 1個 | 73.6% | 28.7% | 9.2% | 4.0% | 0.5% | 0.05% |
| 10,000個 | 4個 | 94.7% | 44.0% | 10.0% | 2.9% | 0.09% | 0.0% |
| 20,000個 | 12個 | 99.97% | 79.2% | 19.3% | 3.9% | 0.02% | 0.0% |
| 50,000個 | 38個 | 100% | 99.4% | 41.6% | 4.7% | 0.0% | 0.0% |
| 100,000個 | 83個 | 100% | 100% | 65.8% | 4.6% | 0.0% | 0.0% |

- 本当の不良率が0.05%（目標の半分）の工程でも、3,000個の検査で「0.1%以下」と言えるのは22.3%だけだった。3,000個では不良が1個でも出ると言えないため
- 本当の不良率が0.1%ちょうど、またはそれより悪いと、何個調べても言える確率は5%以下（100〜200万個で最大5.0%）。これは「95%の上限」という決め方からくる式どおりの値

### 9割（5割）の確率で「0.1%以下」と言える個数
| 本当の不良率 | 5割の確率で言える個数 | 9割の確率で言える個数 |
|---|---|---|
| 0.01% | 3,000個 | 6,300個 |
| 0.02% | 4,800個 | 9,200個 |
| 0.03% | 6,300個 | 13,200個 |
| 0.05% | 11,900個 | **27,900個** |
| 0.07% | 32,600個 | 86,500個 |
| 0.08% | 72,200個 | 201,600個 |
| 0.09% | 279,800個 | **832,700個** |

- 本当の不良率が目標の0.1%に近づくほど、要る個数は急に増えた。0.05%なら27,900個、0.09%なら832,700個
- 個数を少し増やすと、許される不良の数が1つ増える前は言える確率が下がる（図1のぎざぎざ）。表の「言える個数」は、それより多いどの個数でも下回らない個数にした

### 確かめ：日ごとに不良率が上下する工程（各20万回）
| 検査した個数 | 本当の不良率（20日の平均） | 日ごとのばらつき（変動係数） | 1日の製品だけから取る | 20日から同じ数ずつ取る | 毎日同じとしたときの式 |
|---|---|---|---|---|---|
| 3,000個 | 0.15% | 0（毎日同じ） | 1.1% | 1.1% | 1.1% |
| | | 0.5 | 4.9% | 1.3% | |

| | | 2 | **47.8%** | 4.0% | |
| 3,000個 | 0.05% | 0 | 22.25% | 22.36% | 22.3% |
| | | 1 | 39.9% | 23.4% | |
| | | 2 | 61.3% | 27.0% | |
| 10,000個 | 0.15% | 0 | 0.09% | 0.09% | 0.09% |
| | | 1 | 27.5% | 0.6% | |

- **本当は0.15%（目標より悪い）工程でも、日ごとに不良率が上下し、3,000個をすべて1日の製品から取ると、「0.1%以下」と言えてしまう確率は1.1%から18.1%（ばらつき1）・47.8%（ばらつき2）に上がった**。たまたま不良の少ない日を調べると、その日の数字が工程全体の数字に見えるため
- 20日から150個ずつ取ると、ばらつき2でも4.0%にとどまった。調べる個数を10,000個に増やしても、1日だけから取るとばらつき2で57.2%と、言い間違いは減らなかった
- 日ごとのばらつきが0のとき、乱数で数えた値（22.25%・22.36%）は式の値（22.3%）とそろった。作りが置いたとおりに動いていることの確かめ
- 表は一部の行。全行は `results/day_variation.csv`（0.5の行も含む）

## 注意（言えないこと）
- 架空のデータです。品物どうしが互いに関係しないこと、日ごとの上下の形（ガンマ分布）と大きさは作成者が置いたもので、とくに日ごとの上下の確かめの結果はこれで決まります。1日の製品だけから取ったときに言えてしまう確率は、置き方で4.9〜57.2%（本当0.15%のとき）と動きました
- 「95%の片側の上限が0.1%以下」という決め方を使いました。90%や99%の上限、別の上限の出し方（ベイズの方法など）を使うと、要る個数は変わります
- 主な結果の多くは二項分布の式の値です。この記事で新しく数えたのは、本当の不良率ごとの要る個数の並びと、日ごとの上下があるときの取り方の差です
- 検査そのものの見逃しや誤検出（不良を良品と判定する・良品を不良と判定する）は入れていません。検査で見つかった不良は、すべて本当の不良と置きました
- どの個数で検査すべきか、取引先とどんな約束をすべきか、規格や規則でどう決まっているかは言えません
