# 484 明細の「単価×数量」と「金額」が合わない行は、どの確かめ方で何件見つかるのか（実務の型）

架空の明細10万行に、種類の分かる誤りを8種類×150件（計1,200件）入れ、明細の金額を確かめる8つの方法が、誤りを何件見つけ、正しい行に何件鳴るか（空振り）を数えたフォルダです。正しい行には、単価に小数がある行（四捨五入）、値引きがある行、切り捨てで金額を出す行、返品（マイナス）の行を混ぜています。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A484 | 金額の確かめ方ごとに、どの誤りを見つけ、どの正しい行で空振りするか | 確かめ方8つ（完全一致、差1円まで、差0.5%まで、値引きを引いて差0.5円まで、値引きを引いて差1円未満、符号だけ、単価をマスタと照合、その組み合わせ）を DuckDB の SQL で判定し、pandas の判定と一致を assert | `src/a484_checks.py`、`src/01_checks_tsql.sql`（T-SQL 版、未検証） |

## 主な結果
- **誤り1,200件のうち見つけた数／正しい行98,800件の空振り**：
  - 完全一致（値引き列を見ない）：858件／19,718件（値引きの行9,292・小数の行10,134・切り捨ての行292）
  - 差1円まで許す：758件／9,231件（すべて値引きの行）
  - 差0.5%まで許す：673件／11,967件。1〜9円の打ち間違いは39%しか見つけない
  - 値引きを引いて差0.5円まで：900件／137件（切り捨てで金額を出す行など）
  - 値引きを引いて差1円未満：895件／0件
  - 符号だけ：150件（返品が＋の誤りだけ）／0件
  - 単価をマスタと照合：150件（単価の誤りだけ）／0件
  - 値引きを引いて1円未満＋符号＋マスタ：1,045件／0件
- **金額の確かめ方では見つからない誤り**：数量の打ち間違いで金額も計算し直された行（150件）。値引きや小数の単価の行でたまたま鳴った分（完全一致で26件など）を除くと、どの確かめ方でも見つからない。行の中では数字がそろっているので、出荷の記録など別の元と突き合わせないと見つからない
- **値引きを引いて差1円未満でも見逃した行**：1〜9円の打ち間違い150件のうち4件（小数の単価で、もともとの端数と打ち間違いが打ち消し合った行）、値引きの引き忘れ1件

## 注意（言えないこと）
- 架空の明細と誤り。誤りの種類と件数は置いた値で、実際の明細の誤りの割合を表すものではない
- 単価マスタと照合する方法は、マスタの単価が正しく、明細の単価は必ずマスタどおり、という前提。値引き後の単価や特価がある仕組みでは空振りが出る
- 金額の端数の扱い（四捨五入・切り捨て）は仕組みごとに違う。差0.5円で切る確かめ方は、切り捨ての仕組みで空振りする
- 丸めの順番は 328、件数と合計の照合は 326 で扱った
- T-SQL 版は SQL Server 本体では動かしていない（未検証）。SQL は DuckDB で実行した
