# 242 分析の「言えないこと」は、どう書くと誠実か（④ 振り返り R013）

このシリーズの看板記事の README にある「言えないこと」の書き方と、精選の記事で公開前の見直しのときに直した言い方を数えたフォルダです。何を言えないこととして書いたか（カテゴリ）は [F122](../F122_pitfalls_from_logs) で数えたので、ここでは書き方（推測の印・数字・確かめ方）と、直した言い方を見ます。

## 問い

- 「言えないこと」の書き方は、時期でどう変わったか
- 公開前の見直しで、どんな言い方を直したか
- 直した例から、どんな書き方の型が見えるか

## 手法

| 手順 | 中身 |
|---|---|
| 取り出す（`src/a242_01_extract.py`） | README の見出しに「言えないこと」を含む節の箇条書き・表の行を1項目として取り出す。見出しが「レビューで直したこと」の節も同じように取り出す |
| 書き方を数える（`src/a242_02_analyze.py`） | 看板記事（F01〜F295）の項目について、「推測」を含むか、数字を含むか、確かめ方・次に要るもの（確かめ・調べ・別の・必要 など）を含むか。まとまり（F01–F99・F100–F199・F200–F255・F256–F295）ごとに割合 |
| 直したことを分ける | 「レビューで直したこと」の項目を、8つの種類の言葉の一覧で分ける（1項目に複数つく） |

## 主な結果

| まとまり | 本数 | 1本あたりの項目 | 項目の文字数（中央値） | 「推測」あり | 数字あり | 確かめ方あり |
|---|---|---|---|---|---|---|
| F01–F99 | 97 | 4.69 | 55 | 3.7% | 43.1% | 9.7% |
| F100–F199 | 100 | 6.15 | 61 | 7.3% | 52.2% | 12.4% |
| F200–F255 | 36 | 5.89 | 60 | 10.8% | 52.4% | 11.8% |
| F256–F295（精選） | 40 | 7.00 | 63 | 20.0% | 61.8% | 12.1% |

- 見直しで直したこと：40本・382項目（1本あたり中央値9）。項目に占める割合は、計画（PLAN）との対応 25%（38本）、定義・前提・範囲を書いた 17%（29本）、（推測）を足した 15%（34本）、図・表示 15%（31本）、言い過ぎ・一般化を弱めた 10%（26本）、数字・計算の誤り 6%（19本）、事後の分析だと明記 5%（12本）、因果の言い方 1%（3本）
- 直した例は `data/rewrite_examples.csv`（図3）

## 注意（言えないこと）

- README の文を数えたもので、読み手にとって分かりやすいかは測っていない
- 「推測」「数字」「確かめ方」や直したことの種類は言葉で判定した。外れと取りこぼしがあり、目では確かめていない
- 通常の記事（000〜226）は「注意」などの節にまとめて書いていて見出しがそろわないので、集計に入れていない
- 時期の違いには、記事の長さや題材の違いも入っている
