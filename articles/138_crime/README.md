# crime-trends-japan：警察庁「犯罪統計資料」で、刑法犯の認知件数が何で減り、何で増えたかを調べる

警察庁「犯罪統計資料」（各年1〜12月の確定値）の第1表（刑法犯 罪種別 認知・検挙件数）と第2表（窃盗 手口別 認知・検挙件数）から、2007〜2025年の認知件数をつないだリポジトリです。件数（集計値）だけを使い、被害者や個人に関する情報は扱っていません。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A138 | 刑法犯の認知件数は20年でどれだけ減り、何が減ったのか。2022年からの増加は何によるのか | 包括罪種別の推移（2007〜2025年）、2007→2021年（最少の年）の減少と2021→2025年の増加を、手口・罪種13区分の増減に分ける（寄与度分解：各区分の増減÷全体の増減） | `src/a138_trends.py` |

## 主な結果
- 刑法犯の認知件数は190.9万件（2007年）から56.8万件（2021年）へ70.2%減り、2025年は77.4万件（2021年比+36.3%）。2025年は2019年（74.9万件）を3.4%上回った
- 2007→2021年の減少134万件の内訳：自転車盗−28.9万（全体の21.5%）、車上ねらい・部品ねらい−21.0万（15.6%）、侵入盗−13.8万（10.3%）、器物損壊等−12.9万（9.6%）、その他の非侵入盗−12.4万（9.3%）、オートバイ盗・自動車盗−10.2万（7.6%）。窃盗全体で減少の78.2%。減り方の率はオートバイ盗・自動車盗−88.9%、置引き・ひったくり・すり−87.8%、車上ねらい・部品ねらい−85.2%に対し、万引き−39.2%、粗暴犯−31.8%
- 2021→2025年の増加20.6万件の内訳：自転車盗+6.6万（32.1%）、詐欺+3.9万（19.0%、3.3万→7.3万で2.2倍）、その他の非侵入盗+2.7万、その他+2.3万、万引き+1.9万（+21.9%）、粗暴犯+1.2万

## 動かし方
元の資料（各年の「犯罪統計資料」PDF、2020年分からは CSV も）は e-Stat の「犯罪統計」（https://www.e-stat.go.jp/stat-search/files?toukei=00130001 ）から取得し、`data/raw/` に `138_H20.k2`（2008年分 PDF）〜`138_H31.k2`（2019年分 PDF）、`138_R02.k1`（2020年分 CSV）〜`138_R07.k1`（2025年分 CSV）の名前で置きます（合計約23MB のためリポジトリには入れていません）。集計済みの `data/crime_counts.csv` が入っているので、分析だけなら元の資料は要りません。

```bash
pip install -r requirements.txt
cd src
python build.py       # 元の資料から data/crime_counts.csv を作る（data/raw/ が必要）
python a138_trends.py # 図と results/ を作る
```

## データ
| ファイル | 中身 |
|---|---|
| data/crime_counts.csv | 年（2007〜2025年）×表（1：罪種別、2：窃盗手口別）×項目の認知件数（count）と、その年の資料に載っている前年の値（prev） |
| results/a138_total.csv | 刑法犯総数と2007年=100の指数 |
| results/a138_categories.csv | 包括罪種別の認知件数 |
| results/a138_items_by_year.csv | 手口・罪種13区分の認知件数（各年） |
| results/a138_decline_2007_min.csv / a138_rise_min_2025.csv | 13区分の増減と、全体の増減に占める割合 |

## 注意
- 各年の値は、その年の資料の当年の数字です。2007年は2008年分の資料の前年の数字です。前年の資料と次の年の資料で同じ年の数字は一致していました
- 認知件数は警察が把握した件数で、実際に起きた件数そのものではありません。届け出のしやすさや取り締まりの方針でも変わります
- 2017年・2023年の刑法改正で罪名と範囲が変わりました（強姦→強制性交等→不同意性交等、強制わいせつ→不同意わいせつ）。2023年7月からは性的姿態撮影等処罰法の罪も刑法犯の表に入り、2025年は9,962件です。2021→2025年の「その他」の増加には、これらの変更による分が含まれます
- 区分は資料の表の項目を組み合わせたものです。「その他の非侵入盗」は非侵入盗の計から車上ねらい・部品ねらい・自動販売機ねらい・万引き・置引き・ひったくり・すりを引いた残り、「その他」は刑法犯総数から12区分を引いた残り（凶悪犯、風俗犯、横領、偽造、住居侵入など）です
- 2008〜2019年分は PDF の表から文字を読み取っています（pdfplumber）
