# 1027 前年の同じ日の予約と比べると、何を読み違えるのか？（予約とキャンセル）

予約の数を「前年の同じ日」と比べるのはよくある読み方です。けれども、1年（365日）たつと同じ日付の曜日は1つずれます。さらに、今年はまだ予約の途中なのに、前年は締まったあとの数と比べてしまうこともあります。**ここでは、作成者が乱数で作った架空の飲食店（予約制・夜1回の営業。今年のお客を前年より5%多く置いたもの）の2年分の毎日の予約で、①同じ日付の前年の最終の予約と比べる、②同じ日付の前年の同じ日数前と比べる、③同じ曜日の日（364日前）の同じ日数前と比べる、の3つの前年比を、置いた伸び（+5%）と比べ、400回作り直して数えました。**

「前年比」の棒と実数の線を並べたグラフの読み違いは関連する記事 824、「前年比の前年比」は 901、途中でやめた店が入ったときの前年同月比のずれは 973、記録のない1年目との前年比は 977、来場の「前年比120%」を新しい人と来る回数に分ける話は 995 で扱っています。予約の多い日が当日も多いかは同じ企画の 1022、予約の数から当日の人数を見込むときの外れは 1028 で扱っています。この記事は「前年の同じ日と比べる」ときの、日のそろえ方と時点のそろえ方に絞ります。

- **同じ日付で比べると、お客は前年より5%多いと置いたのに、今年の日曜は−27.82%、金曜は+46.9%に見えた**。曜日ごとの値は、置いた曜日の重みの比×1.05 の式の値（日曜−27.81%・金曜+47.0%）どおりで、7曜日で最大0.55ポイントの差だった
- 同じ曜日の日（364日前）で比べると、どの曜日も+4.68〜+5.48%と置いた伸びに近かった
- 休日の印が今年と前年で食い違う日（③で21日）は、③でもずれた。今年だけ休日の11日は+56.3%（式の値+57.5%）、前年だけ休日の10日は−30.13%（式の値−30.0%）

## 注意（言えないこと）
- 架空のデータです。曜日と休日の重み、日ごとの振れ、何日前に予約が入るか、今年の伸びは作成者が置いたもので、結果はこれで決まります。曜日のずれ・休日の食い違い・前年の最終と比べたときのずれの大きさは、置いた重みと割合からの式どおりです。新しく数えたのは、たまたまの上下と合わさったときの日ごと・7日・1か月の見え方です
- 前年と今年で、予約の入り方（何日前に入るか）は同じと置きました。予約が早まった・遅くなった年は、②③でもずれます（1028 で扱っています）。取り消し、席の上限、天気、行事は入れていません
- 休日の日付は作成者が置いた架空のもので、実際の暦ではありません
- どの比べ方を使うべきかの助言ではなく、比べ方でずれ方がどう違うかを数えただけです
