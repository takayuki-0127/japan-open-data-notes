# 442 移動平均でならすと、向きが変わったことに気づくのは何日遅れるのか（実務の型）

上がり続けて、ある日から下がりはじめる架空の日次系列500本で、移動平均の窓の長さごとに、向きの変化に気づくまでの日数と、空振りの回数を数えたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A442 | 移動平均の窓を長くすると、気づくのは何日遅れ、空振りは何回減るか | 後ろ7・14・28・56日の平均、中心7日の平均、そのまま、の6つで「ならした値が7日前より低い日が3日続いたら下向き」の印を出す。最初の印までの日数、印が14日続きはじめるまでの日数、向きが変わらない系列での印の回数を数える。窓（3〜84日）、続く日数、動きと揺れの大きさを変える | `src/a442_ma.py`、`src/01_moving_average_tsql.sql`（T-SQL 版、未検証） |

## 主な結果（1日の動き0.1、揺れの標準偏差3、500本）
| ならし方 | 最初の印まで（中央値） | 9割の系列で | 印が14日続きはじめるまで（中央値） | 空振り（1年あたり） |
|---|---|---|---|---|
| そのまま（前の週の同じ曜日と比べる） | 7日 | 18日 | 続かない（続いたのは0.2%） | 17.0回 |
| 後ろ7日 | 7日 | 13日 | 79日（続いたのは81%） | 17.2回 |
| 後ろ14日 | 11日 | 18日 | 20日 | 8.8回 |
| 後ろ28日 | 18日 | 25日 | 24日 | 1.7回 |
| 後ろ56日 | 32日 | 39日 | 38日 | 0.0回 |
| 中心7日（3日あとに確定） | 8日 | 14日 | 79日 | 17.0回 |

- **窓の長さ**（`results/delay_by_window.csv`）：印が続きはじめるまでは、5日106.5日、7日79日、10日32日、14日20日、21日20日、28日24日、42日31日、56日38日、84日52日
- **続く日数の条件**：後ろ7日で、1日なら3日後・空振り年35回、3日なら7日後・年17回、7日なら14日後・年6回、10日なら26日後・年0.9回
- **動きと揺れ**：結果は動きと揺れの比で決まる。動き0.2・揺れ1.5では、7日の平均で空振り年1.4回、続きはじめるまで10日。動き0.05・揺れ3では、28日の平均でも空振り年9.0回、続きはじめるまで32日
- **曜日の型の残り**：日々の揺れなしで、後ろ5日の平均は7.0%、10日は4.0%の幅で波打つ。7日・14日は0%
- **中心7日の最新の値**：手元の4日分だけで出すと、確定値との差は平均3.4%（大きいほうの1割は5.5%以上）。1日先まであれば2.2%、2日先まであれば1.1%

## 動かし方

```
pip install -r requirements.txt

```

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した
- 移動平均と「7日前より低い」の印を SQL（DuckDB）で出し、Python の計算と一致する（20本分、コード内の assert）

## データ
- `data/daily_sample_20_series.csv`：500本のうち20本分の日次の値（SQL の確認に使ったもの）
- `data/turn_days.csv`：500本それぞれの、向きが変わった日
- すべて架空（作成者が乱数で作成、seed 442）。500本全体はコードで作り直せる

## 注意（言えないこと）
- 架空の系列での結果。日数や回数は、動きの速さ・揺れ・曜日の型・「下向き」の決まりで変わる
- 向きの変わり方は、ある日を境に折れる形だけ。ゆっくり変わる場合や一時的な落ち込みは試していない
- 「最初の印」は空振りと区別できない
- T-SQL 版は SQL Server 本体では動かしていない（未検証）
