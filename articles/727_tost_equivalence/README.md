# 727 「有意な差がない」ことを「同じ」と読むと、本当は差のある案を何%で同じとしてしまうのか（手法の解説・正解の分かるデータで試す）

ふつうの検定で「有意な差がない」と出ても、それは「差があるとは言えない」という意味で、「同じ」とは言えません。人数が少なければ、差があっても見つけられないからです。「同じとみなしてよい」と言いたいときは、同じとみなす幅を先に決めて、差がその幅の中に収まることを示す同等性の検定（TOST）を使います。**ここでは、本当の差が分かる架空の2案の購入額で、「有意な差がない」を「同じ」と読む判定と、TOST（±200円）の判定が、何%で「同じ」と言うかを比べました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A727 | 「有意な差がない」を「同じ」と読むと、差のある案を何%で同じとするか | 架空の2案の1人あたりの購入額（標準偏差1,000円）。本当の差0・100・200・300・500円、1案30・100・300・1,000人。t 検定で p≥0.05 なら「同じ」と、TOST（差の90%区間が ±200円の中）を各4,000回。seed 727 | `src/a727_tost.py` |

## 主な結果（「同じ」と判定した割合、4,000回）
| 本当の差 | 1案30人：p≥0.05 | 1案30人：TOST | 1案1,000人：p≥0.05 | 1案1,000人：TOST |
|---|---|---|---|---|
| 0円 | 95.0% | 0.0% | 94.0% | **99.6%** |
| 100円 | 92.9% | 0.0% | 39.9% | 72.9% |
| 200円（幅の端） | 87.8% | 0.0% | 0.7% | 5.7% |
| 300円 | **79.1%** | 0.0% | 0.0% | 0.0% |
| 500円 | **51.2%** | 0.0% | 0.0% | 0.0% |

- 1案30人では、「同じとみなす幅」の外の差（300円・500円）でも、79%・51%の回で「有意な差がない」になった
- TOST は、幅の外の差を「同じ」とする割合が5%以下に抑えられた（幅の端の200円で 0.0〜5.7%）。そのかわり、人数が少ないと本当に同じでも「同じ」と示せない（1案30人・100人では0%、300人で58%、1,000人で99.6%）
- 1案100人で本当の差が300円のとき、95%区間が0をまたいだのは20回中11回だった（図3）

## 注意（言えないこと）
- 架空のデータです。ばらつき・差・人数は作成者が置いたもので、割合はこれで決まります
- 同等とみなす幅（±200円）は作成者が決めたものです。実際には、データを見る前に、業務の上で「この差なら同じ扱いでよい」と言える幅を決める必要があります
- TOST の90%区間は、片側5%の検定を2回することと同じです
