# 775 前回の順位と比べるとき、前回いなかった店を外すかどうかで、「順位が上がった店」の数はどれだけ変わるのか（実務の型）

店の売上の順位を前回と比べて「上がった店」「下がった店」を数えるとき、前回から今回の間に閉まった店や新しく開いた店があると、数え方で答えが変わります。各期の全店の順位をそのまま比べると、新店が上位に入った分だけ既存の店は押し下げられ、閉店した店の分だけ押し上げられます。**ここでは、作成者が乱数で作った架空の店の2期分の売上で、「上がった店」の数を3通りで数え、新店の数を変えたときの動きも見ました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A775 | 数え方で、「上がった店」の数はどれだけ違うか | 架空の前期100店。今期は10店が閉店、新店が加わる（新店は売上が大きめ）。A 全店の順位をそのまま比べる（前回いない店は比べない）、B 新店を「前回は最下位の次（101位）」とする、C 両方の期にいた店だけで順位を付け直す、の3通り。順位は RANK()。新店0〜30店で各30回。DuckDB（1スレッド）と pandas で順位の一致を確認。seed 775 | `src/a775_rank_change.py`、`src/02_rank_duckdb.sql`、`src/01_rank_tsql.sql` |

## 主な結果

| 数え方 | 「上がった」店（新店15店の例、今期105店） | 新店0店 | 新店30店 |
|---|---|---|---|
| A 全店の順位をそのまま | **28店** | 62.2店 | **5.8店** |
| B 新店は前回最下位の次 | 43店（新店15店を含む） | 62.2店 | 35.0店 |
| C 両方にいた店だけで詰める | 41店 | 40.1店 | 40.8店 |

（新店0店・30店は30回の平均）

- 新店15店の例では、「上がった店」は数え方で28店・43店・41店と変わった
- A では、両方にいた90店の順位が平均4.5位下がった。新店が上位に入った分、押し下げられたため。C で詰めると平均の変化は0になる
- 新店が0店（閉店だけ）だと A は62店が「上がった」になり、新店が30店だと5.8店になった。C はいつも約41店だった
- B は、新店がみな「上がった」に入るので、既存の店の動きと新店の数がまざる

## 動かし方
```
pip install -r requirements.txt
cd src && python a775_rank_change.py
```
10秒ほどで終わります。`data/sales.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダで流し直し、results・figures・data が一致した
- DuckDB の RANK() の順位が、pandas の rank(method="min") と一致すること（assert）

## データ
- `data/sales.csv`：架空の店の2期分の売上（period・store_id・sales。新店15店の例）

## 注意（言えないこと）
- 架空のデータです。新店の売上を大きめにしたのは作成者の置き方で、A のずれの向きと大きさはこれで決まります（新店が小さければ逆に「上がった」が増える）
- どの数え方が正しいかは、何を知りたいかによります。「店の力の変化」を見るなら C、「表の上での位置」を見るなら A です
- T-SQL 版は未検証です
