# 321 題名に書いた数字は、結果のファイルと合っているか（④ 振り返り R101）

note の記事の題名に入れた数字を1つずつ拾い、その記事のフォルダの README と results のファイルに同じ数字があるかを突き合わせたフォルダです。題名の長さや形は [288](https://github.com/takayuki-0127/japan-open-data-notes/tree/main/articles/288_writing_lessons_record) で数えたので、ここでは数字が合っているかだけを見ます。

## 問い

- 題名の数字は、README・結果ファイルの数字と合っているか
- 合わないように見える数字は、丸め方の違いか、言い換えか、それとも直すべきものか

## 手法

| 手順 | 中身 |
|---|---|
| 題名の数字を拾う（`src/a321_extract.py`） | 手元の原稿（md）の1行目の題名から、数字を1つずつ拾う。西暦の年、「2023〜25年」の25、「第4表」、「1人あたり」「1日」のような単位の1は除く。数字の後ろの文字で、率（%・ポイント・倍・割）、量（円・人・万…）、期間（年・か月・日）、個数（都道府県・品目…）に分ける |
| 突き合わせる相手 | 同じ記事のフォルダの README.md と、results/ の json・csv・txt。README のうち、題名そのものが書いてある行（1行目や「note の記事『…』」の行）は外す。外さないと、題名の数字が必ず見つかってしまう |
| 機械の判定 | ①README に同じ数字がある ②結果ファイルにだけ同じ数字がある ③四捨五入すると一致する数字がある（同じ単位のついた細かい数字、または結果ファイルの値。割合→%、万・億・兆の換算も試す） ④「10年で」のような年数で、題名か README の2つの年の差と合う ⑤どれでもない |
| 読んで確かめる（`data/manual_check.csv`） | ⑤と、切り捨て・切り上げでしか合わなかった数字（合わせて55個）は、README と結果ファイルを読んで1つずつ判定した |
| 集計（`src/a321.py`） | 記事のグループ別・数字の種類別に数える |

## 主な結果（`results/summary.json`、`results/by_group.csv`）

- 突き合わせた記事は576本。うち題名に数字があるのは552本で、数字は2,231個（1本あたり中央値4個）
- 機械で確かめられたのは2,176個（97.5%）：README に同じ数字 1,810個（81%）、結果ファイルにだけ同じ数字 53個、四捨五入すると一致 275個（12%）、年数 38個
- 残りの55個を読んで確かめると、46個は合っていた（丸め・表記の違い24、README の数字から計算すると出る15、「4割弱」「5倍台」のような幅のある言い回し7）
- 直す候補は9個・9本（題名の数字の0.4%、記事の1.6%）
  - 切り捨てになっている 4個：F132「7経営体」（README は7.5倍）、172「25%減」（−25.5%）、130「98%」（98.5%）、F291「16〜20%」（16.5%）
  - 粗い言い換え 1個：146「2倍に」（README は +105〜+175%）
  - 期間の言い方が粗い 4個：262・263・265・266 の「90年で」。データは1931〜2025年（94〜95年分）で、比べたのは1931〜1960年の平均と1995〜2025年ごろの30年の平均
- README や結果ファイルとはっきり食い違う数字（別の値が書いてある）は見つからなかった

- 看板記事（F）は README に題名と同じ表記の数字がある割合が高い（86〜90%）。通常の記事と1000本計画では、README の細かい数字（87.1）を題名で丸めた（87%）ものが14〜19%ある
- 数字の種類では、率（942個）の21%が丸めての一致。個数（都道府県・品目の数など）は95%が README に同じ数字

## 確かめたこと

- 「四捨五入すると一致」の275個から24個を抜き取ると、17個は README に同じ単位の細かい数字があった。残り7個は結果ファイルの値との一致で、目では確かめていない
- 有効数字が1桁の数字（880個）は、README のどこかに偶然同じ数字があることがある。README に同じ数字があった割合は、1桁89%、2桁74%、3桁以上82%
- `src/a321_extract.py`（リポジトリのルートを渡す）と `src/a321.py` を空のフォルダで流し直し、data・results・figures が一致することを確かめた

## 動かし方

```
python src/a321_extract.py <japan-open-data-notes のルート>   # data/tokens.csv を作る
python src/a321.py                                            # 集計と図
```

`data/titles.csv` は、記事の番号と note の題名（手元の原稿の1行目）。原稿の本文はリポジトリに入れていない。

## 言えないこと

- 「同じ数字がある」は、同じ表記の数字が README か結果ファイルのどこかにある、という意味。その数字が題名と同じものを指しているかまでは、機械では確かめていない。偶然の一致を含む
- 見たのは題名の数字だけ。本文の数字、図の数字は見ていない
- README と結果ファイルが両方まちがっている場合は、この方法では見つからない。計算そのものの正しさは確かめていない
- 読んで確かめた55個の判定は、1人で1回見たもの。「粗い」「直す候補」の線引きには見る人による違いがある
- 突き合わせたのは2026年11月12日時点のリポジトリ（コミット 0c67a63）。それより後に直した README は反映していない
