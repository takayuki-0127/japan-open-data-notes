# 971 空欄を0で埋めると、平均と割合はどうなるのか？（欠けたデータ）

金額や回数を聞く欄では、使わなかった人が「0」と書かずに空欄のまま出すことがよくあります。そのため集計で「空欄は0」と埋めたくなりますが、空欄には本当は使ったのに書かなかった人もまざります。逆に空欄を除くと、本当に0の人までまとめて抜けます。**ここでは、作成者が乱数で作った架空のカフェの会員アンケート（回答3,000人、物販に本当に使った金額を作成者が全員分置いたもの）で、空欄を0円で埋めるか除くかで、1人あたりの平均金額・使った人の割合・使った人の平均金額が全員の本当の値からどれだけずれるか、空欄の多い入口（紙）と少ない入口（Web）の比較がどう見えるかを数えました。**

会員・店・アンケートはすべて架空のもので、実在の店の数字は使っていません。

関連する記事：地図の空白が0件かデータなしかは 955、割合の分母を「全体」にするか「対象者」にするかは 902 で扱っています。955 も空白を0と読むか除くかで平均がずれる話ですが、地図の空白に「出さない決まり」や「対象外」がまざる場面です。表計算で空白と0のセルが混ざった列の平均は 714、欠品の日の売上を0と見るか欠測と見るかは 591、不明の割合が違う2店の比べ方は同じ企画の 976 で扱っています。同じ企画の 969 は空欄を除いて平均したときのずれを、空欄の出方（でたらめか、値に関わるか）で比べています。この記事は、空欄の中に「本当の0」と「書かなかっただけ」がまざる場面で、0で埋めるか除くかに絞ります。

## 主な結果

### 空欄の扱いで、平均と割合がずれる（300回の平均）
| | 本当の値（空欄なし） | (1) 0円で埋める | (2) 空欄を除く |
|---|---|---|---|
| 1人あたりの平均金額 | 930.56円 | 791.72円（**−14.92%**） | 1,030.77円（**+10.77%**） |
| 使った人の割合 | 45.08% | 38.33%（−14.97%） | 49.90%（+10.71%） |
| 使った人の平均金額 | 2,064.46円 | 2,065.56円（+0.05%） | 2,065.56円（+0.05%） |

- 回答の23.19%が空欄で、空欄のうち本当に0円の人は70.91%だった（式の値23.25%・70.97%）
- 0円で埋めると、平均金額も使った人の割合も約15%低く出た。これは「使った人が空欄にする確率」（15%）の分だけ使った人が0円に数えられる、**式どおりの値**（式の値−15.00%、使った人の割合38.25%）
- 空欄を除くと、本当に0円の人が多く抜けるので、平均金額は10.77%・使った人の割合は10.71%高く出た（使った人の割合の式の値49.84%）
- 使った人の平均金額は、どちらでもほぼずれなかった。空欄が金額の大きさと関係なしと置いたためで、作りどおりの結果
- 300回のうち10〜90%の範囲は、0円で埋めた平均のずれが−16.91〜−12.84%、除いた平均のずれが+8.60〜+13.20%

### 紙とWeb：使い方は同じでも、空欄の多い紙がずれる（300回の平均）
| | 紙（空欄35.87%） | Web（空欄14.74%） | 紙÷Web |
|---|---|---|---|
| 本当の平均金額 | 927.65円 | 932.53円 | 0.997 |
| 0円で埋めた平均金額 | 698.60円 | 853.81円 | **0.820** |
| 空欄を除いた平均金額 | 1,089.49円 | 1,001.36円 | **1.090** |

| | 紙−Web（使った人の割合） |
|---|---|
| 本当の値 | −0.12ポイント |
| 0円で埋める | −7.45ポイント |
| 空欄を除く | +4.34ポイント |

- 本当は使い方が同じでも、0円で埋めると紙の平均はWebの0.820倍（18%低く）、除くと1.090倍（9%高く）に見えた。向きは空欄の扱いで逆になった
- 300回のうち、0円で埋めて紙のほうが低く出た回は99.67%、除いて紙のほうが高く出た回は86%。本当の値で紙のほうが低かった回は52.33%で、半々だった

### 確かめ：置き方を変えて（36通り、各100回）
| 使った人 | 空欄の確率（0円の人） | 空欄の確率（使った人） | 空欄のうち本当に0円 | (1) 0円で埋めた平均のずれ | (2) 除いた平均のずれ |
|---|---|---|---|---|---|
| 45% | 30% | 0% | 100% | 0.00% | +19.81% |
| 45% | 30% | 5% | 88.05% | −4.97% | +16.75% |
| **45%** | **30%** | **15%** | **71.00%** | **−14.75%** | **+10.95%** |
| 45% | 30% | 30% | 55.23% | −29.44% | +0.44% |
| 25% | 10% | 30% | 49.80% | −30.10% | −17.68% |
| 25% | 50% | 0% | 100% | 0.00% | +59.75% |
| 70% | 10% | 30% | 12.39% | −29.85% | −7.72% |

（表は36通りのうちの一部。全部は `results/robustness.csv`。太字は基本の置き方を各100回で数え直した行で、300回の値から少し動く）

- 0円で埋めた平均のずれは、使った人が空欄にする確率（0・5・15・30%）にほぼ等しくなった（使った人の空欄が0%でない27通りで−30.10〜−4.85%）。これも式どおりで、置いた確率の写し
- 除いた平均のずれは、36通りで−17.68〜+59.75%と大きく動いた。0円の人のほうが空欄にしやすいと上に、使った人のほうが空欄にしやすいと下にずれた
- どちらが本当の値に近いかは、置き方で入れかわった。0円で埋めるほうが近かったのは36通りのうち18通り。空欄のうち本当に0円の人が72.09%未満の置き方では、どれも除くほうが近く、85.91%を超える置き方では、どれも0円で埋めるほうが近かった。その間は使った人の割合などで入れかわった
- 使った人の割合のずれ（ポイント）は、0円で埋めると27通りで−21.08〜−1.23ポイント、除くと36通りで−6.08〜+17.06ポイントだった

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の6ファイルがバイト単位で一致した（cmp、2回流して2回とも一致、約2秒）
- 図3枚を開き、日本語・重なり・軸を確かめた
- 0円で埋めたときのずれ（−14.92%）と使った人の割合（38.33%）、空欄を除いたときの使った人の割合（49.90%）、空欄の割合（23.19%）と空欄のうち本当に0円の割合（70.91%）が、置いた確率からの式の値（−15.00%・38.25%・49.84%・23.25%・70.97%）とほぼ同じことを確かめた。0円で埋めたずれは作りどおりで、新しく数えたのは除いたときのずれ、入口の比較、どちらが近いかの入れかわり
- 使った人の空欄の確率を0%にすると、0円で埋めたずれが0になることを確かめた（9通り）

## 注意（言えないこと）
- 架空のデータです。使った人の割合、金額の分布、空欄の確率は作成者が置いたもので、結果はこれで決まります。0円で埋めたずれは置いた「使った人が空欄にする確率」そのもので、除いたずれは置き方で−17.68〜+59.75%と動きました。実在の店の数字を表すものではありません
- 空欄が金額の大きさと関係なく起きると置きました。少ない金額ほど書かずに飛ばすなら、使った人の平均金額もずれます（推測、この記事では数えていない）
- 実際のアンケートで、空欄のうち本当に0円の人がどれだけかは、その表だけでは分かりません。0で埋めるか除くかのどちらが良いかは、この記事では言えません
- 紙とWebの使い方が同じと置いたのは、空欄の扱いだけで差が出ることを見せるための例です
