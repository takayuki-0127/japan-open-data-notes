# F52 インフルエンザは、どの県からどの県へ広がるのか？（時空間の自己回帰）

看板記事 F52。note：「インフルエンザは、どの県からどの県へ広がるのか？ 12シーズンの週次データで調べると、始まる順番は毎年かなり入れ替わり、効いていたのは「隣の県」より「人の行き来が多い県」の先週の流行だった」

## 問い

インフルエンザの流行は、毎年同じ県から始まるのか。始まり方は地図の上で固まっているか。ある県の今週の流行は、全国の波とは別に、「隣の県」や「人の行き来が多い県」の先週の流行で説明できるか。

## データ

| データ | 内容 | 出典 |
|---|---|---|
| 感染症発生動向調査（IDWR 速報データ） | 定点把握疾患の都道府県別 報告数・定点当たり報告数（週次、2012年第37週〜2026年第42週、736週）のうち、インフルエンザの列 | 国立健康危機管理研究機構（JIHS）感染症情報提供サイト |
| 都道府県の隣接・距離 | 境界を共有するか、県庁所在地間の距離 | F33（国土数値情報 行政区域の簡略版から作成） |
| 都道府県間の移動者数 | 2025年、日本人（往復の合計を重みに使う） | F10（住民基本台帳人口移動報告） |
| 人口 | 2023年 | F10（人口推計） |

- シーズンは第36週〜翌年第35週。主な分析はコロナ前の8シーズン（2012/13〜2019/20）。2020/21・2021/22 は流行がほぼなかったので除き、2022/23〜2025/26 は頑健性に使った
- 2025年第14週から、インフルエンザの定点が急性呼吸器感染症（ARI）定点に変わった。定点当たりの数字の水準は、それより前と完全には比べられない
- 集計値だけを使い、個人の情報は扱っていない

## 手法

1. **流行開始週**：第40週以降で、定点当たり1.0以上が2週続いた最初の週（全国の流行開始の目安と同じ1.0）
2. **開始の順番の一貫性**：シーズンどうしの順位相関（Spearman）、Kendall の一致係数 W（順位をでたらめに並べ替えた999回と比べる）
3. **地図の上の固まり**：開始週の Moran's I（隣接の重み、並べ替え検定999回）
4. **時空間の自己回帰**：y = log(1+定点当たり報告数) を、自分の1・2週前、重み付きの近隣の1週前で説明する。
   シーズン×週の固定効果（全国の波）とシーズン×県の固定効果（その県の水準）を入れ、標準誤差は県でクラスター。
   近隣の重みは「隣接（境界を共有）」「移動（人の行き来の量）」「距離（距離の2乗の逆数）」の3通り
5. **1週先の予測**：固定効果なしのモデル（自分の1・2週前＋全国の先週の平均）に近隣の項を足して、1シーズン抜きの検証。全国のピーク前8週の RMSE で比べる

## 主な結果

- 開始週は、全国の中央値で見ると第46週〜翌年第2週（シーズンにより違う）。47都道府県の早い方から10%と遅い方から10%の差は、多くのシーズンで2〜5週
- **順番はシーズンごとにかなり入れ替わる**：シーズンどうしの順位相関は平均0.20（−0.19〜0.56）。Kendall の W は0.28で、偶然（95%点0.15）よりは一致している（p=0.001）
- 平均して早く始まるのは、沖縄（−7.3週、ほぼ一年中流行がある）、北海道（−1.9）、佐賀（−1.4）・新潟（−1.3）、埼玉・福岡・東京（−1.1）。遅めに始まりやすいのは中国・四国の一部（+1〜+1.9週）
- 早く始まる県は、人口が多く（順位相関 −0.41、p=0.004）、東京圏（1都3県）との人の行き来の割合が高い（−0.46、p=0.001）。緯度とは関係がはっきりしない（−0.14）
- 開始週の Moran's I：8シーズン中4シーズンで有意。8シーズンの平均の早さでは0.23（p=0.006）
- **時空間の自己回帰**（全国の波を除いたうえで、近隣の先週の値が1上がると、今週の自分の値がどれだけ上がるか。対数）：

| 近隣の重み | 係数（95%区間） |
|---|---|
| 隣接だけ | 0.091（0.061〜0.122） |
| 移動だけ | 0.257（0.158〜0.355） |
| 距離だけ | 0.133（0.082〜0.185） |
| 両方：隣接 | 0.040（0.012〜0.069） |
| 両方：移動 | 0.185（0.058〜0.313） |

- **予測**：1週先の予測（ピーク前8週）は、移動の重みの近隣を足すと RMSE が2.0%小さくなった。隣接だけでは0.3%
- 県の並びをでたらめに入れ替えた「偽の隣接」（20回）では、係数は平均 −0.001（−0.039〜+0.024）

## 頑健性

| 設定 | 結果 |
|---|---|
| 開始の閾値 0.5 ／ 2.0 | 順位相関の平均 0.23 ／ 0.16 |
| 沖縄を除く | 順位相関 0.15、時空間AR：隣接 0.033、移動 0.251 |
| Moran's I の重みを移動・距離に | 平均 0.07 ／ 0.12（隣接で0.15前後） |
| コロナ後の4シーズン（2022/23〜2025/26） | 時空間AR：隣接 0.029（区間が0をまたぐ）、移動 0.188（0.081〜） |
| コロナ前の平均の順番とコロナ後 | 順位相関の平均 0.28 |

## 言えないこと

- 「移動の多い県から広がった」ことの証明ではない。人の行き来が多い県どうしは、学校の休みや気候など、別の理由で同じように動いている可能性がある
- 定点当たり報告数は、定点医療機関の受診者数で、感染者の数そのものではない。県によって定点の置き方が違う
- 2025年第14週からの定点の変更で、それ以降の数字の水準は前と完全には比べられない
- 特定の県を評価するものではない。開始の早さは、人口の多さや人の行き来とともに、その年の流行株や学校の行事でも変わる
