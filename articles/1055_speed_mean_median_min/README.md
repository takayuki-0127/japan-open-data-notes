# 1055 平均・中央値・最小値のどれで比べるかで、速い方は入れかわるのか？（処理の速さ）

2つのやり方の処理時間を何回か測って比べるとき、平均で比べる人も、中央値（真ん中の値）で比べる人も、最小値（いちばん速かった回）で比べる人もいます。処理時間の分布の形が2つで同じなら、どれで比べても速い方は同じです。けれども、一方は「ふだんは速いが、まれに大きく遅れる」、もう一方は「まれな遅れはないが、ばらつきが大きめ」のように形が違うと、物差しによって速い方が入れかわります。**ここでは、作成者が置いた分布から乱数で作った架空のアプリの処理時間（実機では測っていない）で、本当の平均・中央値・最小値の期待値でどちらが速いか、A・B を3〜100回ずつ測って3つの物差しで比べたとき答えがそろわない組が何%あるかを数えました。形が同じ2つ（A をそのまま5%遅くした B）と比べ、まれな遅れの確率・大きさと B のばらつきを変えた36通りでも確かめました。**

1回ずつ測った時間で速い方を選ぶとどれだけまちがえるか（平均で比べたとき）は、同じ企画の関連する記事 1053、温まる前の最初の回を平均に入れるとどれだけ長く出るかは 1054、平均が速くなっても遅い側の数%が遅くなることがあるかは 1060 で扱っています。平均の待ち時間と長く待つ人の割合の違いは 873、遅れの平均と遅れた便の遅れの平均の違いは 1031 で扱っています。この記事は、同じ測った値を平均・中央値・最小値のどれでまとめるかで、速い方の答えが変わることに絞ります。

## 主な結果

### 本当の値（基本、`results/true_values.csv`）
| 物差し | A | B | 速いのは | B は A より |
|---|---|---|---|---|
| 平均 | 116.25ミリ秒 | 111.26ミリ秒 | **B** | −4.29% |
| 中央値 | 100.84ミリ秒 | 110ミリ秒 | **A** | +9.08% |
| 3回の最小値の期待値 | 94.19ミリ秒 | 97.49ミリ秒 | A | +3.5% |
| 5回の最小値の期待値 | 91.65ミリ秒 | 92.91ミリ秒 | A | +1.37% |
| 10回の最小値の期待値 | 88.86ミリ秒 | 87.65ミリ秒 | B | −1.36% |
| 30回の最小値の期待値 | 85.24ミリ秒 | 81.19ミリ秒 | B | −4.75% |
| 100回の最小値の期待値 | 82.07ミリ秒 | 75.67ミリ秒 | B | −7.8% |

- 本当の平均では B が4.29%短く、中央値では B が9.08%長い。A のまれな大きな遅れが平均だけを押し上げるためで、置いた分布の形どおり（平均は式で A 116.32・B 111.24ミリ秒）
- 最小値の期待値は、何回測るかで入れかわった。5回までは A、10回からは B が速い。最小値は分布の左の端で決まり、測る回数が多いほど、ばらつきの大きい B のほうが小さな値を引きやすくなる

### n 回ずつ測って比べたとき（基本、2万組、`results/measured_by_n.csv`）
| A・B 各何回 | 平均で A を選ぶ | 中央値で A を選ぶ | 最小値で A を選ぶ | **3つの答えがそろわない組** | 対照（形が同じ）でそろわない組 |
|---|---|---|---|---|---|
| 3回 | 68.69% | 75.67% | 60.16% | 39.95% | 35.69% |
| 10回 | 59.52% | 90.72% | 45.07% | 65.57% | 48.05% |
| 30回 | 44.36% | 98.66% | 27.94% | **85.23%** | 48.94% |
| 100回 | 28.25% | 100% | 11.89% | 96.19% | 39.72% |

- 30回ずつ測ると、3つの物差しの答えがそろわない組は85.23%だった。回数を増やすと答えは「中央値なら A、平均と最小値なら B」に割れたまま固まり、100回では96.19%がそろわなかった
- 30回ずつの平均で比べても、本当に平均の短い B を選んだのは55.64%（A を選んだ44.36%の残り）で、平均の差4.29%はまれな遅れの振れに埋もれた
- 形が同じ対照でも、30回ずつで48.94%の組がそろわなかった。まれな大きな遅れがあると、平均の答えが振れるため（対照の平均で A を選んだのは62.19%）。そろわないことは、形の違いの手がかりにはなるが、それだけで形が違うとは言えない

### 36通りの確かめ（30回ずつ、`results/grid.csv`）
| | 値 |
|---|---|
| 本当の3つの物差し（平均・中央値・30回の最小値）で速い方が同じだった通り | 36通り中6通り |
| 本当の平均と中央値で速い方が違った通り | 18通り |
| 30回測って3つの答えがそろわない組 | 23.36〜97.25% |
| うち本当の3つが同じ通り | 23.36〜43.96% |
| うち本当の3つが違う通り | 56.05〜97.25% |
| 中央値で A を選んだ割合 | 89.42%以上（36通りすべて） |
| 平均で A を選んだ割合 | 4.93〜95.09% |

- 中央値では、36通りすべてで A が本当に速く、30回ずつ測ると89.42%以上の組で A を選んだ。中央値は、まれな遅れの確率が16%まででは、ふだんの時間の真ん中からあまり動かないためと考えられる（推測）
- 平均でどちらが速いかは、まれな遅れの確率と大きさで入れかわった（18通りで A、18通りで B）
- どの物差しでどちらが速いかは、作成者が置いた分布の形の写しで決まる。この記事で新しいのは、それを有限の回数で測ったときに答えがどれだけ割れるか

## 注意（言えないこと）
- 架空のデータです。A と B の分布の形（ふだんの時間・ばらつき・まれな遅れの確率と大きさ）は作成者が置いたもので、どの物差しでどちらが速いかはこれで決まります。実在のソフトやサーバーで測った値ではありません
- どの物差しが正しいかは、何を知りたいかで決まります。たくさん処理したときの合計の時間なら平均、ふつうの1回の時間なら中央値、邪魔の入らないときの速さなら最小値が近いと考えています（推測）。この記事は、物差しを決めずに比べると答えが割れることを数えただけです
- 遅い側の数%（99パーセンタイルなど）での比べは扱っていません（平均と遅い側が逆に動くことは同じ企画の 1060）
- 1回ごとの時間は互いに関係なく振れると置きました
