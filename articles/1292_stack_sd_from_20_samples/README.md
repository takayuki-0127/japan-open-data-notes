# 1292 部品ごとに20個だけ測った標準偏差から組み立て品の幅を見込むと、本当の幅より狭く見込んでしまう回はどれだけあるのか？（寸法の積み上げ）

部品を重ねて組む品物では、部品ごとに何個か測って標準偏差を出し、それを二乗で足して組み立て品のばらつきの幅を見込むことがあります。けれども、20個ほどで出した標準偏差は、測るたびに上にも下にも振れます。見込んだ幅が本当の幅より狭ければ、見込みの外に出る組み立て品は、思っていたより多くなります。**ここでは、作成者が置いた架空の棚（5枚の部品を重ねた高さ。部品ごとの本当の標準偏差を作成者が置いたもの）で、部品ごとに20個を測って「±3×√(標準偏差の2乗の和)」で幅を見込むことを20,000回くり返し、本当の幅より狭く見込んだ回の割合と、見込んだ幅の外に出る組み立て品の割合を数えました。測る個数を5〜100個に変え、部品の寸法の形（山が1つ・平ら・まれに大きくずれる）、部品の数（2・5・10枚）、標準偏差の置き方（そろう・1つが大きい）を変えて確かめました。**

例の棚・部品はすべて架空のもので、実在の会社・製品・規格の数字ではありません。品質の判断や購入の助言はしていません。

関連する記事：917「寸法の平均が規格の中でも、外れる品物は何%あるのか？」は、部品1つの寸法で、30個・100個の抜き取りの平均と標準偏差から外れる割合を出すと、幅が広く、形が違うと中央値もずれることを扱っています。909「不良率0.1%を確かめるには、何個検査すればよいのか？」は、検査した個数と見つかった不良の数から「0.1%以下」と言える確率を扱っています。1058「99パーセンタイルの応答時間は、何件測れば落ち着くのか？」は、少ない件数で測った遅い側の値が大きく振れることを扱っています。1284「同じ日に作った部品どうしで寸法のずれがそろうとき、関係なしと見て二乗で足した幅は、実際の幅よりどれだけ狭く出るのか？」は、部品どうしのずれがそろうと二乗で足した幅が狭く出ることを扱っています。1285「1つ1つの部品の寸法が正規分布でないとき、何個重ねると、組み立て品の外れの割合は正規と見た見込みに近づくのか？」は、部品の形によって±3倍の幅の外に出る割合が、正規と見た見込みと違うことを扱っています。1287「部品の寸法の記録に測りのばらつきがまざっていると、記録から見込んだ組み立て品の幅は、本当の幅よりどれだけ広く出るのか？」は、測りのばらつきで記録から見込んだ幅が広く出ることを扱っています。この記事は、少ない個数で出した部品ごとの標準偏差を二乗で足して組み立て品の幅を見込むときに、狭く見込む回がどれだけあるかに絞ります。

## 主な結果

### 部品ごとに20個（5枚・山が1つ、20,000回、`results/a1292_main.json` の `main_n20`）
| | 値 |
|---|---|
| 本当の幅より狭く見込んだ回 | **52.43%** |
| 1割以上狭く見込んだ回 | **10.38%** |
| 2割以上狭く見込んだ回 | 0.51% |
| 見込んだ幅÷本当の幅（10%点・中央値・90%点） | 0.8984・0.9955・1.0979 |
| 本当の幅の外に出る組み立て品 | 0.2623% |
| 見込んだ幅の外に出る組み立て品（中央値・90%点） | 0.2754%・**0.6992%** |
| 見込んだ幅の外に出る組み立て品が1%を超えた回 | 3.46% |

- 20個ずつ測ると、半分を少し超える回（52.43%）で本当より狭く見込み、10回に1回ほど（10.38%）は1割以上狭く見込んだ
- 見込んだ幅の外に出る組み立て品は、中央値では0.2754%と本当の幅の外（0.2623%）に近いが、10回に1回は0.6992%を超えた
- 狭い回が50%を少し超えるのは、測った標準偏差の2乗は平均すれば本当の値に合うが、その平方根をとった幅は、真ん中の値が本当より少し小さく出るため（式の上の性質。見込み÷本当の中央値0.9955）

### 測る個数を変えると（5枚・山が1つ、各20,000回、`results/main_by_n.csv`）
| 部品ごとに測る個数 | 本当より狭い | 1割以上狭い | 見込み÷本当（10%点〜90%点） | 見込んだ幅の外（90%点） |
|---|---|---|---|---|
| 5個 | 55.16% | 31.66% | 0.7717〜1.2063 | 2.0548% |
| 10個 | 53.2% | 20.57% | 0.8515〜1.1414 | 1.0627% |
| 20個 | 52.43% | 10.38% | 0.8984〜1.0979 | 0.6992% |
| 50個 | 51.65% | 2.08% | 0.9358〜1.0615 | 0.4974% |
| 100個 | 51.09% | 0.15% | 0.9554〜1.0444 | 0.412% |

- 「本当より狭い」回は、100個測っても51.09%と半分前後のまま。測る個数で減るのは、大きく狭く見込む回（1割以上狭いは5個で31.66%、100個で0.15%）

### 確かめ：形・部品の数・標準偏差の置き方（各4,000回、`results/grid.csv`・`results/grid_n20_summary.csv`）
部品ごとに20個のとき、18通り（形3つ×部品の数3つ×標準偏差の置き方2つ）で、本当の幅より狭く見込んだ回は49.98〜65.03%、1割以上狭く見込んだ回は0.12〜44.5%だった。

| 形（20個ずつ） | 本当より狭い | 1割以上狭い | 見込んだ幅の外（90%点） |
|---|---|---|---|
| 山が1つ | 51.23〜53.92% | 2.67〜27.18% | 0.5249〜1.5633% |
| 平ら | 49.98〜51.52% | 0.12〜16.88% | 0.0〜0.2977% |
| まれに大きくずれる | 54.83〜65.03% | 13.8〜44.5% | 1.1827〜2.9594% |

（部品の数2・5・10枚×標準偏差の置き方2つの6通りの最小〜最大）

- 5枚・山が1つで、標準偏差がそろうと1割以上狭いのは8.82%、1枚だけ大きいと20.62%だった。幅の多くを1枚の部品が決めると、実質その1枚の20個で幅を見込むことになり、振れが大きくなる。部品の数が少ないときも（2枚でそろう20.55%・1つが大きい27.18%）、同じように振れが大きかった
- まれに大きくずれる形では、20個の中に大きくずれる品が入るかどうかで標準偏差が振れ、狭く見込む回が多かった（5枚・そろうで1割以上狭い24.2%）。この形では本当の幅（±3×本当の標準偏差）の外に出る組み立て品も0.7782%あり、山が1つの形（5枚・そろうで0.2656%）より多かった。±3倍の幅そのものが表す外れの割合が、形で違う
- 平らな形では、少ない個数でも標準偏差がばらつきにくく、狭く見込む回は少なかった（5枚・そろうで1割以上狭い2.0%）
- 5個しか測らないと、5枚・1つが大きい・まれに大きくずれる形では、1割以上狭い回が51.95%だった（`grid.csv`）

- `results/main_by_n.csv`：測る個数ごとの結果（narrower_pct は本当より狭い回、narrower10_pct・narrower20_pct は1割・2割以上狭い回、ratio_p10・ratio_p50・ratio_p90 は見込んだ幅÷本当の幅の10%点・中央値・90%点、out_pct_true_width は本当の幅の外に出る組み立て品、out_pct_median・out_pct_p90 は見込んだ幅の外に出る組み立て品の中央値・90%点、out_over1_pct はそれが1%を超えた回）

## 注意（言えないこと）
- 架空のデータです。部品ごとの本当の標準偏差、形、部品の数は作成者が置いたもので、結果はこれで決まります
- 部品の真ん中の値はずれていないと置きました。真ん中の値も20個から見込むと、ずれの分だけ外れはさらに増えると考えられます（推測。数えていない）
- 部品どうしの寸法はたがいに関係なく決まると置き、測りの誤差は入れていません
- 「±3×標準偏差」の幅を見込む決まりは、作成者が置いた見込み方です。実在の規格や会社の決まりを表すものではありません。何個測るべきか、品質の判断や購入の助言をする記事ではありません
