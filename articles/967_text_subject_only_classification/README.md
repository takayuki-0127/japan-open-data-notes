# 967 問い合わせの件名だけで分けると、本文と比べて何がずれるのか？（文章の数字）

問い合わせを用件ごとに数えるとき、件名だけで分けると手軽です。けれども、件名には「お問い合わせ」「至急」のように用件の分からないものや、困りごとの話題（「配送の件」）だけを書いて本文では不満を伝えているものがあります。**ここでは、作成者が乱数で語を組み合わせて作った架空の店への問い合わせ2,000件（本当の用件6分類と、2つめの用件を作成者が置いたもの）で、作成者が作った「言葉→分類」の一覧を使い、件名だけで分けた場合と本文で分けた場合の、分類ごとの割合・当たり・2つめの用件の拾い方を比べました。**

文章を自動で分けたときの正解率を何と比べるかは同じ企画の 964、同じ用件の書き分けをそろえる話は 966、自由記述の多い意見が全体の多い意見かは 871、「当てはまるものをすべて」と「1つだけ」で割合が変わる話は 864 で扱っています。この記事は、件名と本文という、同じ問い合わせのどこを読んで分けるかに絞ります。

## 主な結果

### 分類ごとの割合（300回の平均、`results/shares_by_category_300reps.csv`）
| 分類 | 本当 | 件名だけ（全体に占める割合） | 件名だけ（分けられた件の中） | 本文 |
|---|---|---|---|---|
| 配送 | 22.0% | 17.1% | 23.4% | 22.0% |
| 返品・交換 | 16.0% | 12.9% | 17.7% | 16.7% |
| 支払い | 14.0% | 11.6% | 15.85% | 15.0% |
| 会員・ログイン | 14.0% | 11.5% | 15.8% | 14.9% |
| 商品の質問 | 20.0% | 15.7% | 21.5% | 20.1% |
| 不満・要望 | 14.1% | **4.2%** | **5.7%** | 8.1% |
| 分類できない | — | **27.1%** | — | 3.2% |

- 件名だけで分けると、27.1%が分類できず、不満・要望は4.2%（10〜90%の範囲で3.6〜4.7%）しか数えなかった。本当は14.1%
- 分類できない件を除いて割合を出し直しても、不満・要望は5.7%で、ほかの5分類が本当より高く出た。分類できない件は分類ごとに同じ率で出るわけではないため、除いても元に戻らない
- 本文で分けても、不満・要望は8.1%だった。不満の本文は困りごとの話題（「先日の配送の件です。」）から書き始めると置いたので、不満の文が1文だと同数になり、先に出た話題の分類に入った。本文が正しいのではなく、本文の分け方にも決まりの置き方によるずれがある

### 当たりと2つめの用件（300回の平均）
| 数えたもの | 件名だけ | 本文 |
|---|---|---|
| 本当の用件どおりに分けた割合（全体） | **63.7%** | 84.2% |
| 同じく、不満・要望 | 25.2% | 57.9% |
| 同じく、ほかの5分類 | 69.9〜70.2% | 88.3〜88.7% |
| 2つめの用件（全体の31.4%にある）を拾えた割合 | **25.5%** | 90.4% |
| 本当にはない用件を拾った問い合わせの割合 | 4.7% | **18.5%** |

- 件名だけの当たりは、置いた率の写しです。不満・要望以外は「一般的な件名25%＋別の話題5%」を除いた70%、不満・要望は「40%＋35%」を除いた25%にほぼなる（式どおり）
- 2つめの用件は、件名だけでは25.5%しか拾えなかった。本文なら90.4%拾えたが、「前回の配送は問題ありませんでした。」のような関係のない言葉も拾い、18.5%の問い合わせで本当にはない用件を足した

| 一般的な件名の率 | 不満・要望での倍率 | 件名だけの不満・要望（全体に占める割合） | 分類できない | 件名だけの当たり | 本文の不満・要望 |
|---|---|---|---|---|---|
| 10% | 1.0 | 8.33% | 9.98% | 80.81% | 7.98% |
| 10% | 2.5 | 6.22% | 12.04% | 78.67% | 8.01% |
| 25% | 1.0 | 6.23% | 25.00% | 65.86% | 8.11% |
| 25% | 1.6（基本） | 4.18% | 27.07% | 63.81% | 8.10% |
| 25% | 2.5 | 0.96% | 30.28% | 60.54% | 8.10% |
| 40% | 1.0 | 4.12% | 40.09% | 50.80% | 8.00% |
| 40% | 2.5 | 0.63% | 47.82% | 47.33% | 8.01% |

（9通りのうち7通りを載せた。全部は `results/grid_generic_tilt.csv`。不満・要望の本当の割合は9通りとも13.94〜14.15%）

- **件名だけの不満・要望の割合は、9通りで0.63〜8.33%と大きく動いた**。本当の14%に届いた置き方はなかった。不満・要望で別の話題を書く率を5%にしても8.29%、60%にすると0.64%（`results/by_complaint_subject_other_topic.csv`）
- 件名だけの当たりは47.33〜80.81%と動き、本文の当たりは84.07〜84.31%でほとんど動かなかった
- 本文の不満・要望の割合は、困りごとにふれる率で動いた。30%なら10.46%、70%（基本）なら8.02%、100%なら6.18%（`results/by_complaint_trouble_mention.csv`）
- 分類による差をなくす（倍率1.0、別の話題を書く率も5%にそろえる）と、分けられた件の中の不満・要望は13.71%で本当（13.77%）とほぼ同じになり、6分類の差は最大0.37ポイントだった。このとき分類できない件は25.03%。**件名だけで割合がずれるのは、分類によって件名の書き方が違うと置いたとき**で、ずれの大きさはその置き方で決まる

## 動かし方
```
pip install -r requirements.txt
cd src && python a967_subject_vs_body.py
```
6秒ほどで終わります。`data/inquiries_example.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の10ファイルがバイト単位で一致した（cmp）
- 例の2,000件は、数の上で作った言葉の並びから文を組み立てたあと、文の中から一覧の言葉を探し直し、件名の最初の言葉と本文の言葉の並びが、作った並びと同じになることを全件で確かめた。決まった文の型やつなぎの文に一覧の言葉が入っていないこと、一覧の言葉どうしが互いの一部になっていないことも確かめた（作りの確かめ）
- 分類による差をなくすと、分けられた件の中の割合が本当とほぼ同じになる（差は最大0.37ポイント）ことを確かめた

## 注意（言えないこと）
- 架空のデータです。文は作成者が決まった文の型に語を入れて作ったもので、実在の問い合わせ・口コミ・SNS の文は使っていません。用件の割合、件名の書き方の率、本文の書き方は作成者が置いたもので、ずれの大きさはこれで決まります
- とくに「不満・要望は一般的な件名や困りごとの話題の件名になりやすい」は作成者の置き方です。分類による差がなければ、件名だけでも分けられた件の中の割合はほぼ本当どおりになります
- 「本当の用件」は作成者が決めたものです。不満の問い合わせを「配送」と「不満・要望」のどちらに入れるべきかは、数える目的で変わります
- 分け方は、一覧の言葉が文の中にあるかを見るだけの単純な決まりです。言い回しの意味を読む分け方や、人が読んで分ける場合は比べていません。文章を自動で分ける道具の働き方を表すものでもありません
- 本文の同数の扱い（先に出た方）は作成者が決めた決まりで、本文の不満・要望が少なく出たのはこの決まりにもよります
