# 336 平均寿命が43〜44歳だった時代に、65歳まで生きた人は、あと何年生きたのか（完全生命表）

国の最初の生命表（1891〜98年）から2020年までの19回分で、年齢ごとの平均余命と生存数を並べ、0歳の平均余命の延びを年齢ごとに分けたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A336 | 平均寿命が40代だった時代に、65歳まで生きた人はあと何年生きたか。平均寿命の延びはどの年齢の死亡が減った分か | 完全生命表 第1回〜第19回・第23回の生存数 lx と平均余命 ex（男女・各歳）。0歳・20歳・65歳の平均余命と、65歳まで生きる割合を回ごとに並べる。0歳の平均余命の差を Arriaga の方法で7つの年齢層に分ける（基準の表を入れ替えた場合も計算） | `src/a336_life_tables.py` |

## 主な結果
- 65歳の平均余命：1891〜98年 男10.2年・女11.4年 → 2020年 男19.97年・女24.88年（+9.8年・+13.5年）。0歳は男42.8→81.56年、女44.3→87.71年（+38.8年・+43.4年、1.9倍・2.0倍）
- 65歳の平均余命は、1891〜98年から1947年まで男9.3〜10.6年・女11.1〜12.2年でほぼ動かず、1950〜52年（男11.35・女13.36）から延びが続いた。1965年は男11.88年・女14.56年
- 最初の生命表では、5歳までに男24%・女22%が亡くなり、65歳まで生きたのは男31.5%・女35.4%。20歳まで生きた人のうち65歳に届いたのは男45%・女50%。2020年は65歳まで男89.7%・女94.6%
- 0歳の平均余命の延び（第1回→第23回）の内訳（第1回を基準）：5歳未満 男18.9年（49%）・女18.9年（44%）、15〜64歳 男13.8年（36%）・女16.4年（38%）、65歳以上 男3.1年（8%）・女4.8年（11%）
- 基準を2020年の表にすると、5歳未満は男33%・女28%、65歳以上は男23%・女29%
- 時期で分けると、1935〜36年→1965年（男+20.8年）は5歳未満が52%、1965年→2020年（男+13.8年・女+14.8年）は5歳未満が14%・11%、65歳以上が40%・56%

## 確かめたこと
- 年齢層ごとの寄与を足すと、0歳の平均余命の差と一致する（`results/decomposition.csv` の sum_check）
- 生存数を台形で積み直した0歳の平均余命は、公表値と一致（第1回 男42.8/42.8・女44.3/44.33、第23回 男81.56/81.56・女87.71/87.71）
- 分け方の基準を入れ替えると割合が変わる（5歳未満は28〜49%）ことを結果に書いた
- 空のフォルダで流し直し、data・results・figures が一致した

## データ
- `data/raw/chouki_02-35.xls`：総務省統計局「日本の長期統計系列」2-35 完全生命表（明治24年〜平成12年）。統計局のサイトでは掲載が終わっているため、Internet Archive の保存版（`https://web.archive.org/web/2013id_/http://www.stat.go.jp/data/chouki/zuhyou/02-35.xls`）から取得（2026-11-12）
- `data/raw/lt23_male.xlsx`・`lt23_female.xlsx`：e-Stat 第23回生命表（statInfId=000032173232・000032173233）
- `data/life_tables.csv`：回・男女・年齢ごとの生存数・死亡率・平均余命を縦長にしたもの

## 注意（言えないこと）
- 生命表は、その時期の年齢ごとの死亡率が一生続いたと仮定した計算で、その年に生まれた人が実際に何年生きたかではありません
- 明治・大正の生命表は、もとになる人口や届け出の正確さが今と違います
- 年齢ごとの割合は基準の表で変わります。死亡が減った理由は分けられません
- 第7回は作られていません。第20〜22回（2005〜2015年）は使っていません
