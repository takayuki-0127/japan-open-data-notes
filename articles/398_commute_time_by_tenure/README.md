# 398 家から職場までの時間は、住まいの種類でどれだけ違うのか（住宅・土地統計調査、1988〜2023年）

家計を主に支える人が雇用者である世帯の通勤時間を、住宅の所有の関係（持ち家・民営借家・公営の借家・UR・公社の借家・給与住宅）ごとに比べたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A398 | 片道1時間以上の世帯の割合と通勤時間の中央値は、住まいの種類でどれだけ違うか。35年で変わったか | 時系列統計表 第23-1表。区分のそろう6回（1988・1993・2008・2013・2018・2023年）を8区分にそろえ、不詳を除いて割合を計算。中央値は区分から計算して表の値と照合。全体の変化を内訳の変化とそれぞれの中の変化に分ける | `src/a398_commute.py` |

## 主な結果
- 片道1時間以上（2023年）：持ち家17.2%、民営借家11.9%、公営の借家6.9%、UR・公社の借家25.1%、給与住宅8.4%、全体15.2%
- 全体は1988年15.0%→1993年16.2%→2008年16.4%→2013年14.9%→2018年15.4%→2023年15.2%。1時間半以上は3.6〜3.9%
- 持ち家と民営借家の差：1988年7.2ポイント→2008年7.8→2023年5.4
- 中央値（分）：全体26.8→28.1、持ち家28.2→29.4、民営借家25.0→26.5、公営の借家25.0→22.3、UR・公社の借家44.8→42.3、給与住宅18.9→19.2
- 15分未満（自宅・住み込みを含む、2023年）：全体24%、給与住宅43%、公営の借家32%、UR・公社の借家13%
- 全体の+0.2ポイント（1988→2023年）は、内訳の変化+0.3、それぞれの中の変化−0.1

## 確かめたこと
- 区分の合計＝総数（丸めの範囲）。自分で計算した中央値は、表の中央値と最大0.2分の差
- 給与住宅は2023年に不詳が37%。不詳をすべて1時間未満／1時間以上と置くと5.3〜42.1%。ほかの4つは不詳0.3〜0.7%で、幅は0.7ポイント以内
- 空のフォルダで流し直し、data・results・figures が一致した

## 注意（言えないこと）
- 家計を主に支える人が雇用者である世帯だけです。ほかの家族や自営の人の通勤は入りません
- 持ち家の通勤が長い理由（年齢、郊外の一戸建、大都市圏かどうか）は分けていません。因果は言えません
- 時系列の表には建て方別がなく、所有の関係で比べました。1998・2003年は区分が違うため除きました
- 全国の数字です。給与住宅は不詳が多く、近年の数字は確かではありません
