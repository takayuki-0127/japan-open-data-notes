# F29 北陸新幹線の金沢延伸で、石川県の宿泊客はどれだけ増えたか？（Synthetic DID・Augmented SCM）

看板記事 F29。2015年3月14日の北陸新幹線（長野―金沢）開業で、石川県・富山県の日本人の延べ宿泊者数が「開業がなかった場合」と比べてどれだけ増えたかを、合成コントロール法とその発展形（Synthetic DID・Augmented SCM）で推定し、F04 と同じ流儀の構造時系列モデルとも比べた。

## 問い

- 金沢延伸のあと、石川県・富山県の宿泊客は、開業がなかった場合と比べて何%・何人泊増えたか
- 手法（合成コントロール・SDID・ASCM・単純な差の差・構造時系列）で答えは変わるか
- 新幹線の開業がなかった県を「開業した」とみなしても、同じくらいの差が出てしまわないか（プラセボ）

## データ

| データ | 内容 |
|---|---|
| 観光庁「宿泊旅行統計調査」推移表 | 都道府県×月の延べ宿泊者数（総数・日本人・外国人）、2011年1月〜2025年12月の確定値。F04 で作った縦長の表をそのまま使う（`data/raw/lodging_pref_monthly_2011_2025.csv`） |

- 処置：石川・富山（2015年3月開業。3月は14日からなので、3月から事後とした）
- 対照（33県）：次の県を除いた残り
  - 新潟・長野：同じ北陸新幹線で2015年に駅ができた（上越妙高・糸魚川・飯山）
  - 北海道・青森：2016年3月 北海道新幹線
  - 福岡・佐賀・熊本・鹿児島：2011年3月 九州新幹線全線開業
  - 福井：金沢から特急で接続していて、波及するおそれがある
  - 岩手・宮城・福島：東日本大震災で事前期間が大きく乱れる
- 期間：事前 2012年1月〜2015年2月（38か月）、事後 2015年3月〜2019年12月（58か月、コロナ前まで）
- 季節：県ごとに対数をとり、事前期間の同じ月の平均を引いた（「いつもの同じ月」との差）

## 手法

| 手法 | 内容 | コード |
|---|---|---|
| 単純な差の差 | 石川 − 対照33県の平均、の事前と事後の差 | `common.did` |
| 合成コントロール（SCM） | 事前の差の二乗和が最小になる、非負・合計1の対照県の重み | `common.scm` |
| Augmented SCM（リッジ） | SCM の事前のずれを、対照県の事前→事後のリッジ回帰で補正（Ben-Michael ほか 2021）。罰則は対照県の一つ抜きで選ぶ | `common.ascm` |
| Synthetic DID | 県の重み（切片つき・リッジ）と時点の重みを推定し、重みつきの差の差（Arkhangelsky ほか 2021）。区間はプラセボ法 | `common.sdid` |
| 構造時系列 | 局所水準＋対照県平均を説明変数にした状態空間モデル（statsmodels、最尤）。F04 の CausalImpact 型と同じ流儀 | `03_分析.py` |

推定はすべて自前のコード（scipy の SLSQP、statsmodels）で、外部の synthdid パッケージは使っていない。

## 主な結果

**石川（日本人、2015年3月〜2019年12月の平均）**

| 手法 | 効果 | 増えた人泊（58か月） |
|---|---|---|
| 単純な差の差 | +10.0% | 約357万 |
| 合成コントロール | +11.9% | 約416万 |
| Augmented SCM | +11.9% | 約416万 |
| Synthetic DID | +13.2%（95%区間 −2.1〜+30.8） | 約456万 |
| 構造時系列 | +11.9%（95%区間 +4.3〜+19.8） | — |

- 年あたりにすると約86万〜94万人泊。石川県の日本人の延べ宿泊者数は 2014年 719万 → 2015年 821万 人泊
- プラセボ（対照33県を1つずつ「開業した」とみなす）：石川の SDID は34県中2番目（片側 p = 0.06）、SCM は4番目（p = 0.12）。沖縄・埼玉・愛媛でも＋11〜15%が出る。事前と事後の当てはまりの比（RMSPE 比）では13番目
- ASCM が SCM とほぼ同じなのは、SCM の事前の当てはまりがよく（事前 RMSE 0.030）、補正がほとんど要らないため。罰則を弱くしても +9.1〜+11.9%
- 年ごとの効果：SCM は 11〜14% で横ばい、SDID は 2015年 16.6% → 2019年 8.1% と縮む
- 合成石川県の重み：SCM は静岡 0.37・山口 0.25・愛媛 0.17 など、SDID は33県に広く薄く（最大 0.07）

**富山（日本人）**

- 平均ではほぼ0（SCM +0.1%、SDID +0.7%、差の差 −4.1%）。開業から1年（2015年3月〜2016年2月）だけなら +7.5〜7.6%
- 石川と富山をまとめた SDID：+6.7%

**外国人・総数（石川）**

- 総数：SCM +14.2%、SDID +12.3%
- 外国人だけ：SCM +10.8%、SDID +5.3%（増えた人泊は約6万〜15万）。2015年以降の訪日客の急増が全国で起きていて、外国人では対照づくりが難しい

## 頑健性

| 確認 | 石川の効果（SCM / SDID / 差の差） |
|---|---|
| 基本 | 11.9 / 13.2 / 10.0 |
| 福井も対照に入れる | 11.9 / 13.1 / 9.9 |
| 東北3県も入れる | 14.7 / 13.8 / 10.4 |
| 九州新幹線の4県も入れる | 11.6 / 12.9 / 10.1 |
| 大都市・沖縄を除く | 12.0 / 13.8 / 11.2 |
| 近畿・中部の近い県だけ | 12.6 / 12.9 / 11.0 |
| 事前を2011年1月から | 12.1 / 12.4 / 9.2 |
| 事前を2013年1月から | 19.0 / 12.5 / 11.6 |
| 事後を1年に限る | 11.5 / 16.9 / 13.4 |

- 一つ抜き（SCM の重みが大きい県を1つずつ外す）：SCM 10.6〜12.1%、SDID 11.6〜14.2%
- 時間のプラセボ（開業前の2013年3月・2014年3月に「開業した」とする）：石川 −4.8〜+4.2%、富山 −6.7〜−2.8%。事後の +12% はこの幅より大きいが、プラセボでも ±5% 程度は出る

## 言えないこと

- 2015年は北陸新幹線のほかにも、観光キャンペーンや国内旅行の回復があった。石川だけに起きた別の出来事があれば、効果に混ざる
- 33県の中にも＋10%を超える県が3つあり、「偶然では出ない」とまでは言い切れない（片側 p = 0.06〜0.12）
- 宿泊だけを見ている。日帰り客、消費額、県の経済全体への効果は分からない
- 東京など首都圏から石川へ移った分（他県で減った分）は区別していない
- 都道府県の単位なので、金沢市とそれ以外の差は見ていない

## 動かし方

```bash
pip install -r requirements.txt
bash src/run_all.sh
```

- `src/01_取得.py`：元データ（F04 で作った表）を取る。元の Excel は観光庁の推移表
- `src/02_整形.py`：都道府県×月の表（`data/monthly_pref.csv`）
- `src/03_分析.py`：推定・プラセボ・頑健性（約2分）
- `src/03b_追加の確認.py`：時間のプラセボと ASCM の罰則
- `src/04_図.py`：図6枚
