# 903 小さい数からの「300%増」は、どこまで意味があるのか？（割合とパーセント）

前年比の%は、前年の数で割るので、前年が小さいほど大きく振れます。前年1個が今年4個になれば「+300%」です。売上表で前年比の大きい順に並べると、上位には前年の少ない品目が集まります。**ここでは、作成者が乱数で作った架空の会社の商品2,000品目（品目ごとに「本当の伸び」を作成者が置いたもの）で、「前年比+300%以上」の品目のうち、本当に伸びた品目がどれだけ入っているか、前年の個数でそれがどう変わるかを数えました。**

本当に伸びる品目は全体の5%（本当の倍率は中央値3倍）、ほかの品目は本当は横ばい前後、と作成者が置いています。結果は、この置き方で大きく動きます（下の「確かめ」）。

| A903 | 前年比+300%以上の品目のうち、本当に伸びた品目はどれだけか。前年の個数でどう変わるか | 架空の商品2,000品目。前年の同じ月の「本当の売れる速さ」は中央値20個・対数で標準偏差1.2（0.3〜3,000個で切る）。本当に伸びる品目は5%と置き、その本当の倍率は中央値3倍・対数で標準偏差0.4。ほかの品目の本当の倍率は中央値1倍・対数で標準偏差0.1。前年・今年・翌年の販売個数は、それぞれの本当の速さのポアソン分布から引く（翌年の本当の速さは今年と同じ）。前年比＝（今年−前年）÷前年。前年が0個の品目は前年比を出せないので除いた。「+300%以上」は今年が前年の4倍以上。品目を作り直して50回の平均。並べ方の比べは、前年比の大きい順・増えた個数の多い順・前年と今年に5個ずつ足した比・前年10個以上に絞った前年比の順の上位20品目。確かめとして、伸びる品目の割合（1%・5%・10%）×前年の速さの中央値（5・20・80個）の9通りを各20回。seed 903 | `src/a903_small_base.py` |

## 主な結果

### 「+300%以上」の品目の中身（2,000品目×50回）
| | 値 |
|---|---|
| +300%以上の品目（2,000品目あたり） | 45.64品目 |
| そのうち前年3個以下 | **42.3%** |
| そのうち前年の個数の中央値 | 6個 |
| そのうち本当に伸びる品目 | **65.2%** |
| そのうち本当は横ばい前後の品目（2,000品目あたり） | 15.9品目 |
| 本当に伸びる品目のうち、+300%以上に入った割合 | 30.0% |
| 前年0個で前年比を出せない品目 | 1.2% |

- +300%以上の品目のうち、本当に伸びる品目は65.2%だった。残りは、本当は横ばい前後の品目が、たまたま前年に少なく今年に多く売れたもの
- 一方、本当に伸びる品目のうち+300%以上に入ったのは30.0%だけだった。置いた本当の倍率が中央値3倍（+200%）なので、+300%の線では多くがこぼれる
- 前年10個以上に絞ると、+300%以上の品目（2,000品目あたり19.06品目）はすべて本当に伸びる品目だった。そのかわり、本当に伸びる品目のうち拾えたのは19.2%に減った

### 前年の個数ごと（50回の平均）
| 前年の個数 | 品目数（2,000品目あたり） | +300%以上の品目数 | +300%以上になった割合 | +300%以上のうち本当に伸びる品目 | 横ばい前後の品目が+300%以上になった割合 |
|---|---|---|---|---|---|
| 1個 | 42.1 | 11.92 | 28.3% | **9.9%** | 26.6% |
| 2〜3個 | 115.3 | 7.40 | 6.4% | 39.5% | 4.1% |
| 4〜9個 | 371.0 | 7.26 | 2.0% | 90.6% | 0.19% |
| 10〜29個 | 700.7 | 9.60 | 1.4% | 100% | 0% |
| 30個以上 | 746.3 | 9.46 | 1.3% | 100% | 0% |

- 前年1個の品目の「+300%以上」は、本当に伸びる品目が9.9%だけだった。前年1個は、今年4個売れれば+300%になる
- 前年10個以上では、横ばい前後の品目が+300%以上になることはなかった（50回で0）

### 本当は横ばい（倍率1）の品目で、前年比が振れる大きさ（各20万品目）
| 本当の速さ（月の個数） | 前年0個で出せない割合 | +300%以上になる割合（出せた品目のうち） | 前年比の10〜90%の範囲 |
|---|---|---|---|
| 1個 | 36.8% | 1.1% | −100%〜+100% |
| 2個 | 13.6% | 4.5% | −100%〜+200% |
| 3個 | 5.0% | 5.9% | −75%〜+200% |
| 5個 | 0.7% | 3.8% | −60%〜+150% |
| 10個 | 0% | 0.54% | −45.5%〜+83.3% |
| 30個 | 0% | 0% | −28.6%〜+40.0% |
| 100個 | 0% | 0% | −16.7%〜+20.0% |

- これはポアソン分布の式から決まる値で、データから見つけたものではない。本当の速さが月3個の品目は、何も変わっていなくても、前年比が−75%〜+200%の範囲に8割が入る

### 並べ方ごとの上位20品目（50回の平均）
| 並べ方 | 上位20品目のうち本当に伸びる品目 | 上位20品目の前年の個数（中央値） |
|---|---|---|
| 前年比（%）の大きい順 | **73.0%** | 5.88個 |
| 増えた個数の多い順 | 96.4% | 86.82個 |
| 前年・今年に5個ずつ足した比 | 100% | 30.23個 |
| 前年10個以上に絞って前年比の順 | 99.9% | 30.15個 |

- 前年比の順の上位20品目は、前年の個数の中央値が5.88個で、本当に伸びる品目は73.0%だった。前年の小ささに手を当てる並べ方（個数の差・足してから割る・前年の下限）では、ほぼすべて本当に伸びる品目になった
- この並べ方の差は、置いた「伸びる品目は約3倍、ほかは横ばい」という分かれ方の写しでもある。伸び方がなだらかに散らばる置き方では、差は小さくなると考えている（推測、数えていない）

### 翌年：+300%以上の品目の、翌年の個数
| | 品目数（50回の合計） | 翌年÷今年（中央値） | 翌年が今年より減った割合 |
|---|---|---|---|
| 本当に伸びる品目 | 1,487 | 0.979 | 55.3% |
| 横ばい前後の品目 | 795 | **0.636** | 72.3% |
| 全体 | 2,282 | 0.934 | 61.2% |

- 横ばい前後の品目の+300%は、翌年には今年の0.636倍（中央値）に戻った。本当の速さは今年と同じと置いているので、この戻りはたまたま多く売れた分が消えただけ

### 確かめ：伸びる品目の割合 × 前年の速さの中央値（9通り、各20回）
| 伸びる品目 | 前年の速さの中央値 | +300%以上（2,000品目あたり） | うち本当に伸びる品目 | うち前年3個以下 |
|---|---|---|---|---|
| 1% | 5個 | 48.55 | 9.7% | 94.4% |
| 1% | 20個 | 23.80 | 26.1% | 75.4% |
| 1% | 80個 | 7.90 | 66.5% | 31.6% |
| 5% | 5個 | 68.15 | 44.1% | 77.7% |
| 5% | 20個（基本） | 44.80 | 65.7% | 42.6% |
| 5% | 80個 | 28.05 | 92.0% | 10.0% |
| 10% | 5個 | 97.65 | 59.9% | 68.1% |
| 10% | 20個 | 73.40 | 80.2% | 30.7% |
| 10% | 80個 | 54.75 | 96.3% | 5.1% |

- +300%以上のうち本当に伸びる品目の割合は、置き方で9.7〜96.3%まで動いた。本当に伸びる品目が少なく、前年の個数が少ない品目の多い売上表ほど、「+300%」は当てにならない
- 本当に伸びる品目のうち+300%以上に入る割合は、9通りとも25.3〜29.8%で、置き方でほとんど動かなかった（本当の倍率の置き方で決まる）

- 横ばいの品目の前年比の振れ（上の表）は、ポアソン分布の式で決まる値です。前年10個以上で横ばいの品目が+300%を超えないのも、置いた分布からの計算で決まります

## データ
- `data/items.csv`：架空の商品2,000品目（1回分）。item_id・lam0（前年の本当の売れる速さ）・true_ratio（本当の倍率）・grower（本当に伸びる品目なら1）・y0（前年の個数）・y1（今年の個数）・y2（翌年の個数）・pct（前年比、%。前年0個は空欄）。この1回分では、+300%以上は47品目で、うち本当に伸びる品目は32品目、前年3個以下は18品目。前年比がいちばん大きかったのは+1,100%（前年1個→今年12個）で、本当は横ばい前後の品目だった

## 注意（言えないこと）
- 架空のデータです。本当に伸びる品目の割合、その伸びの大きさ、前年の個数の分布は作成者が置いたもので、結果はこれで決まります
- 販売個数は、本当の速さのまわりでポアソン分布どおりに振れると置きました。まとめ買い・品切れ・値引きのように、実際の売上をもっと大きく振らせることは入れていません。入れれば、横ばいの品目の+300%はもっと増えると考えています（推測）
- 「伸びる品目」と「ほかの品目」をはっきり2つに分けて置きました。実際には伸び方はなだらかに散らばっているはずで、そのときは「本当に伸びた」の線の引き方で割合が変わります
- 前年0個の品目は前年比を出せないので除きました。表によっては「新規」や「−」と書かれ、並べ方から消えることがあります
- 関連する記事：%と%ポイントの違いは 897、「n人中x人」を割合だけで書くと何が消えるかは 908 で扱っています。件数の少ない店ほど星の平均が振れる話は 801、少ない打席の最高打率は 833 で、同じ「分母が小さいと振れる」仕組みを別の題材で数えています
- 既存の記事 590 は、来店客数の違う店の購入率を並べると、分母の小さい店が上位と下位に集まることを数えています。この記事は、前年比（変わった率）の「+300%」に本当の伸びがどれだけ入っているかに絞りました。同じ企画の 906 は、前の率が低い店ほど比（倍）が大きく出ることを扱っています
