# 1128 圧縮の画質の設定を下げると、ファイルの大きさと見た目の差は同じ割合で動くのか？（画像と色）

画像を保存するとき、「画質の設定」を下げるとファイルは小さくなり、元の画像との差は大きくなります。設定を半分にしたら大きさも半分、差は2倍、のように同じ割合で動くと思いがちです。けれども、大きさの減り方と差の増え方は、設定のどこで動くかが違います。**ここでは、作成者が式と乱数で作った架空の白黒の画像4種類（なめらかな傾き・架空の商品の写真に見立てた色の板・細かい縞・ざらざらした粒）各16枚を、作成者が置いた簡単な圧縮で画質95〜5の11段階に保存し、①ファイルの大きさ、②元の画像との画素の差、を数えました。画質95→5の全体の動きのうち、95→50で起きた割合を、大きさと画素の差で比べています。画質の設定から丸めの刻みへの式は作成者が置いたもので、結果はこの式で大きく変わります（刻みをまっすぐ増やす置き方も数えました）。丸めの強さ・画像の粒の強さ・かたまりの大きさを変えた27通りも確かめました。**

例の画像は式と乱数で作った架空のもので、実在の写真・商品を表すものではありません。圧縮も作成者が置いた簡単なもので、実在の画像の形式・ソフトの圧縮を表すものではありません。「見た目の差」は画素の値の差で数えていて、人に見てもらって確かめたものではありません。

関連する記事：同じ企画の 1129「明るさの差を数値のまま測ると、人が見て感じる差とどこでずれるのか？」は、画素の値の差と、作成者が置いた見え方の式の差がどこでずれるかを扱っています。この記事の「画素の差」は、そのずれを入れていない物差しです。1131「圧縮して保存し直すことを10回くり返すと、元の画像との差はどれだけ積み重なるのか？」は、同じ形の簡単な圧縮で、保存し直しをくり返したときの差の積み重なりを数えています。この記事は、1回の保存で画質の設定を変えたときの大きさと差の動き方に絞ります。

## 主な結果

### 画質ごとの大きさと画素の差（各16枚の平均、`results/by_type_quality.csv`）
| 画像の種類 | 画質95の大きさ | 画質50の大きさ（画質95を1として） | 画質10の大きさ（同） | 画素の差：画質95 | 画質50 | 画質10 |
|---|---|---|---|---|---|---|
| なめらか | 4,232バイト | 0.143 | 0.045 | 0.84 | 1.33 | 3.88 |
| 色の板 | 7,912バイト | 0.157 | 0.038 | 0.95 | 3.49 | 8.89 |
| 細かい縞 | 10,081バイト | 0.136 | 0.018 | 0.95 | 5.13 | 23.58 |
| ざらざら | 15,325バイト | 0.34 | 0.03 | 0.95 | 8.43 | 23.31 |

### 画質95→5の動きのうち、95→50で起きた割合
| 画像の種類 | 大きさの減り | 画素の差の増え | 大きさが半分になった画質 | そのときの画素の差 |
|---|---|---|---|---|
| なめらか | **89.3%** | **13.4%** | 83.5 | 1.02 |
| 色の板 | 86.5% | 28.5% | 76.9 | 1.87 |
| 細かい縞 | 87.2% | 16.5% | 76.6 | 2.08 |
| ざらざら | **67.2%** | **32.3%** | 61.6 | 5.17 |

- **大きさの減りの67.2〜89.3%は画質95→50で起き、画素の差の増えは13.4〜32.3%しか起きなかった**。大きさは設定を下げはじめた所で大きく減り、画素の差は設定を下げきった所で大きく増えた。同じ割合では動かなかった
- 画質90→50で、なめらかな画像の大きさは5.07分の1になり、画素の差は1.41倍だった。ざらざらの画像は、大きさ2.73分の1に対して画素の差6.88倍と、種類で動き方が逆だった
- 画質50で大きさの比が小さい順（細かい縞→なめらか→色の板→ざらざら）と、画素の差が小さい順（なめらか→色の板→細かい縞→ざらざら）は一致しなかった。細かい縞は、大きさがいちばん縮んだのに、画素の差は2番目に大きかった
- かたまりの境目の段差は、画質50で0.65〜3.04、画質10で3.57〜16.71増えた（細かい縞がいちばん大きい）

### 確かめ1：刻みを画質に対してまっすぐ増やすと（各16枚、`results/by_type_quality_linear_step.csv`）
| 画像の種類 | 大きさの減りのうち95→50 | 画素の差の増えのうち95→50 |
|---|---|---|
| なめらか | 88.5% | 66.3% |
| 色の板 | 90.7% | 69.5% |
| 細かい縞 | 91.2% | 66.6% |
| ざらざら | 91.4% | 86% |

- **画質と刻みの関係をまっすぐに置くと、画素の差の増えも66.3〜86%が95→50で起き、大きさとのずれは小さくなった**。大きさの減りが先に起きる向きは同じだが、ずれの大きさは、画質の数字と刻みの関係をどう置くかでほぼ決まる。画質の数字は、刻みにつけた目盛りにすぎない

### 確かめ2：置き方27通り（各種類6枚、`results/grid.csv`、刻みは基本の式）
| | 27通り×4種類＝108組の結果 |
|---|---|
| 大きさの減りのうち95→50 | 52.2〜95.3% |
| 画素の差の増えのうち95→50 | 10〜66.4% |
| 大きさの割合−画素の差の割合 | +16.1〜+79.2ポイント（108組すべてで大きさのほうが大きい） |
| 大きさが半分になった画質 | なめらか61.3〜84.6、色の板67.9〜82.2、細かい縞67.5〜80.1、ざらざら48.4〜71.5 |
| そのときの画素の差 | なめらか0.63〜1.86、色の板0.95〜3.76、細かい縞1.15〜3.68、ざらざら2.68〜11.09 |

- 刻みを基本の式にしたままなら、108組すべてで大きさの減りが先に起きた。2つの割合の差がいちばん小さかったのは、ざらざらの画像で細かい成分の刻みの増えを大きく（1.0）し、粒を弱く（0.5倍）した3通りだった（画素の差の増えのうち63.2〜66.4%が95→50）
- 「大きさが半分になる画質」も、画像の種類と置き方で48.4〜84.6と大きく動いた

## 注意（言えないこと）
- 架空のデータです。画像の作り方、圧縮のしかた、画質の設定から刻みへの式は作成者が置いたもので、結果はこれで決まります。とくに「大きさの減りと画素の差の増えのずれの大きさ」は、刻みの式で大きく変わりました（確かめ1）
- 画質95の大きさを1としました。画質95の大きさには、画像の粒（細かいざらつき）を詰める分が多く入っていて、粒の強さで割合は動きます（27通りで確かめた）
- 「見た目の差」は画素の差の大きさだけで数えました。人がどこから差に気づくかは測っていません。人の見え方は明るい所と暗い所で違い（1129）、画素の差が同じでも気づきやすさは違うと考えられます（推測）
- 実在の画像の形式・ソフトの「画質」の数字とは対応しません。どの画質で保存するとよいかも言えません
