# 507 生命表の死亡率を「1年に死亡する確率」と「年の途中の死亡の速さ」で取り違えると、年金の現価はどれだけずれるのか（保険数理・リスク）

生命表の「死亡率」には、x歳ちょうどの人が1年以内に死亡する確率 qx と、1年に死亡した人数をその1年の延べ生存人年で割った中央死亡率 mx があります。名前が似ていて、データによってどちらが入っているかが違います。**令和6年簡易生命表（男・女）の ndx と nLx から mx を計算し、qx と mx を取り違えたときに終身年金の現価がどれだけずれるかを、年齢別・利率別に数えました。** 数字は、使った生命表と年金の置き方で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A507 | qx と mx を取り違えると、終身年金の現価はどれだけずれるか。年齢・利率で違うか | 令和6年簡易生命表の各歳の nqx・ndx・nLx から mx = ndx ÷ nLx を作る。期始払いの終身年金（105歳で打ち切り）の現価を、①正しい p=1−qx ②mx を qx として p=1−mx ③qx を mx として p=1−qx/(1+qx/2) ④mx から正しく直す p=1−mx/(1+mx/2) で計算。20〜95歳、利率0〜3% | `src/a507_qx_mx.py` |

## 主な結果
- **2つの率の差**：mx は qx より、65歳で0.3〜0.5%、80歳で1〜2.5%、90歳で5〜8%、100歳で21〜27%大きい
- **65歳からの年金（利率1%）**：男の正しい現価は17.90。mx を qx として使うと17.70（−1.13%）、qx を mx として扱うと18.11（+1.14%）。女は21.88 → 21.69（−0.84%）・22.06（+0.83%）
- **年齢が高いほど大きくずれる**（利率1%、mx を qx として）：男は20歳から −0.26%、80歳から −3.03%、90歳から −7.48%、95歳から −11.98%。女は90歳から −5.18%
- **利率**：65歳・男で、利率0%なら −1.32%、3%なら −0.84%。利率が高いほど遠い将来の重みが小さく、ずれも少し小さい
- **mx から正しく直せば**（一様に死亡すると置く）、65歳からの現価のずれは0.01%、90歳からでも0.2%以内

## 動かし方
```
pip install -r requirements.txt
cd src && python a507_qx_mx.py
```

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した
- ndx・nLx は整数に丸められているので、若い年齢（死亡数が少ない）では mx ÷ qx が ±2% ほど揺れる。図1は50歳以上にした。年金の現価への影響は小さい（④のずれが20〜65歳で0.01%以内）

## データ
- `data/raw/mhlw_kani_2024.xlsx`：厚生労働省「令和6年簡易生命表」生命表（男・女）。F268 のフォルダから写したもの
- `data/life_table_2024_qx_mx.csv`：各歳の qx・lx・ndx・nLx と、計算した mx

## 注意（言えないこと）
- 1つの生命表（令和6年簡易生命表）で試しただけ。死亡率の水準が違う表では数字が変わる
- 年金の置き方（期始払い、105歳で打ち切り、将来の死亡率の改善なし）で数字が決まる
- 保険料・準備金の決め方を勧めるものではない。率の取り違えで現価がどう動くかを数えたもの
- 簡易生命表そのものには mx の列はなく、ndx と nLx から計算した（ストックの案の「両方がある」から変えた）
