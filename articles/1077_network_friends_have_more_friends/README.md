# 1077 「自分の知り合いは、自分より知り合いが多い」と感じるのはなぜか？（つながり）

会員どうしの知り合いを数えると、多くの人で「自分の知り合いの知り合いの数の平均」が自分の知り合いの数より多くなります。自分だけが知り合いが少ないわけではありません。知り合いの多い人は、多くの人の「知り合い」として何度も数えられるので、知り合いから1人選ぶと、知り合いの多い人に当たりやすくなるためです。**ここでは、作成者が乱数で作った架空の会員コミュニティ（会員2,000人、人ごとの知り合いの作りやすさを作成者が置いたもの）で、会員から1人選んだときと知り合いから1人選んだときの知り合いの数を比べ、知り合いの平均が自分より多い会員の割合を数えました。作りやすさの差の大きさと平均の知り合いの数を変えた12通りでも確かめました。**

会員・知り合いのつながりはすべて架空のもので、実在の会や SNS の数字は使っていません。会員は番号だけで表し、人を属性で比べることはしていません。

## 主な結果

### 会員から選ぶか、知り合いから選ぶか（50回の平均、`results/a1077_main.json`）
| | 値 |
|---|---|
| 会員1人あたりの知り合いの数（平均） | **7.98人** |
| 　同じく中央値 | 5.17人 |
| 　知り合いが1人もいない会員 | 11.26% |
| 知り合いから1人選んだときの、その人の知り合いの数（つながりの端で数えた平均） | **17.02人**（2.133倍） |
| 　式：平均＋分散÷平均 | 17.02人（50回すべてで差0.0） |
| 会員ごとの「知り合いの知り合いの数の平均」を、会員で平均した値 | 17.04人（2.136倍） |

- 知り合いから1人選ぶと、その人の知り合いの数は平均17.02人で、会員全体の平均7.98人の2.133倍だった。これは「平均＋分散÷平均」の式どおりで（50回すべてで一致）、データから見つけたものではない。知り合いの数に人ごとの散らばりがあれば、必ず平均より大きくなる
- 知り合いの数の分布（`results/pick_distribution.csv`）：会員から選ぶと知り合い11人以上の人は27.25%だが、知り合いから選ぶと64.94%になった。知り合い2人以下の人は29.7%から3.39%に減った
- 知り合いの多い上位1割の会員が、つながりの端の34.54%を受け持っていた

### 会員ごとに比べると（知り合いが1人以上いる会員、50回の平均）
| | 割合 |
|---|---|
| 知り合いの知り合いの数の平均が、自分より多い | **83.98%**（50回で82.21〜86.36%） |
| 同じ | 0.32% |
| 自分より少ない | 15.7% |
| 自分の知り合いの数が平均（7.98人）より多い会員のうち、知り合いの平均が自分より多い | 62.11% |
| 知り合いのうち、自分より知り合いの多い人の割合（会員の平均） | 72.03% |
| 知り合いの過半数が自分より知り合いが多い会員 | 73.6% |

- 知り合いのいる会員の83.98%で、知り合いの知り合いの数の平均が自分より多かった。知り合いの数が平均より多い会員でも62.11%がそうだった
- 「知り合いの平均」だけでなく、1人ずつ比べても、知り合いの72.03%は自分より知り合いが多い人だった（会員の平均）

### 確かめ：12通り（各10回、`results/grid.csv`）
| 作りやすさの変動係数 | 平均4人 | 平均8人 | 平均16人 |
|---|---|---|---|
| 0（全員同じ） | 65.18% | 62.82% | 60.23% |
| 0.5 | 71.84% | 73.99% | 73.77% |
| 1.0（基本） | 80.44% | 83.78% | 85.51% |
| 1.5 | 86.52% | 88.93% | 90.33% |

（表の値は、知り合いの平均が自分より多い会員の割合）

- 12通りすべてで半分を超え、60.23〜90.33%だった。知り合いから選んだ人の知り合いの数は、会員の平均の1.063〜3.576倍
- **作りやすさを全員同じに置いても（変動係数0）、60.23〜65.18%の会員で知り合いの平均が自分より多かった**。このときも知り合いから選んだ人の知り合いの数は平均より0.986〜1.01人多く、式（分散÷平均＝1、知り合いの数がポアソン分布になるため）どおりだった
- 割合の大きさは、人ごとの作りやすさの差の置き方でほぼ決まった

## データ

- `data/ties_one_run.csv`：同じ1回分の知り合いのつながり（member_a・member_b）
- `results/a1077_main.json`：主な結果（`headline` に本文で使った値）
- `results/base_reps.csv`：基本の置き方の50回分
- `results/pick_distribution.csv`：会員から選ぶときと知り合いから選ぶときの、知り合いの数の分布
- `results/grid.csv`：12通りの確かめ

## 注意（言えないこと）
- 架空のデータです。会員の数、作りやすさの分布、つながりのでき方は作成者が置いたもので、結果はこれで決まります。知り合いの平均が自分より多い会員の割合は、置き方で60.23〜90.33%と動きました。実在の会や SNS のつながりを表すものではありません
- つながりは「知り合いかどうか」だけで、仲の良さや会う回数は入れていません。知り合いどうしが似た数の知り合いを持ちやすい（または持ちにくい）偏りも入れていません。こうした偏りがあると、割合は変わると考えています（推測）
- 「感じる」こと自体は数えていません。ここで数えたのは、知り合いの知り合いの数を自分と比べたときの割合です
- 知り合いの多い人が良い・悪いということは扱っていません
