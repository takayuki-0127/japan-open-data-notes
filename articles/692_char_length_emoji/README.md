# 692 文字数の上限を len() で確かめると、絵文字や結合文字を含む文は何件が見た目と違う数になるのか（実務の型）

入力欄の「20文字まで」を確かめるとき、Python の len() はコードポイント（Unicode の番号）の数を、JavaScript の length などは UTF-16 の単位の数を返します。見た目の1文字が、絵文字の組み合わせや濁点の分かれた文字では、2〜11に数えられることがあります。**ここでは、架空の入力文2万件（ふつうの文字だけ・絵文字6種類・濁点が分かれた文字）で、見た目の文字数（書記素）と、len・UTF-16・NFC で正規化してからの len を比べ、上限20文字の判定の食い違いと、20コードポイントで切ったときに文字が壊れる件数を数えました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A692 | 文字数の数え方で、上限の判定はどれだけ食い違うか | 架空の入力文2万件（8〜22文字）。7種類：ふつう55%、ふつうの絵文字15%、肌の色つき6%、ZWJ で合成した絵文字6%、国旗4%、異体字セレクタつき7%、濁点が分かれた文字（NFD）7%。見た目の文字数は regex の \X（書記素クラスタ）、len、UTF-16 の単位、unicodedata.normalize("NFC") 後の len。上限20で判定、先頭20コードポイントで切って書記素の途中か調べる。seed 692 | `src/a692_char_length.py` |

## 主な結果（2万件、上限20文字）
| 項目 | 件数 |
|---|---|
| 見た目と len の文字数が違う | 6,010件（30.1%） |
| 見た目と UTF-16 の単位が違う | 8,801件（44.0%） |
| NFC にしても見た目と違う | 4,524件（22.6%） |
| 見た目で20文字を超える | 2,614件 |
| len で「超え」と判定 | 3,885件（うち **1,271件は見た目では20文字以内**） |
| UTF-16 で「超え」と判定 | 4,910件（うち **2,296件は見た目では20文字以内**） |
| 20コードポイントで切ると、最後の文字が途中で切れる | 385件 |

- 家族の絵文字（👨‍👩‍👧‍👦）は見た目1文字だが、len で7、UTF-16 で11と数えた
- 合成の絵文字を含む文では、見た目20文字以内なのに len で45%、UTF-16 で67%が「超え」と判定された
- 濁点が分かれた文字（Mac のファイル名などで起きる）は、len では2文字だが NFC にすれば1文字に戻った。絵文字は NFC にしても戻らない
- ふつうの絵文字（😀）は len では1文字だが、UTF-16 では2になる

## 注意（言えないこと）
- 架空のデータです。絵文字や分かれた濁点の割合は作成者が置いたもので、件数はこれで決まります
- 見た目の文字数は Unicode の書記素クラスタの規則（regex の \X）で数えました。表示する画面やフォントによって、見た目がさらに違うことがあります
- SQL Server の LEN・DATALENGTH や Excel の LEN の数え方は確かめていません（未検証）
- 保存先の列の長さ（バイト数）の上限は扱っていません
