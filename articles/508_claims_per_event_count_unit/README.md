# 508 同じ事故の複数の請求を別々の損害として数えると、1件あたりの額と大きな損害の層の見積もりはどれだけずれるのか（保険数理・リスク）

1つの事故から、被害者ごと・補償ごとに複数の請求が出ることがあります。損害の分析を請求の単位で行うか、事故の単位で行うかで、件数・1件あたりの額・裾の形が変わります。**架空の事故（10年で2,028件）と請求（3,861件）を作り、事故単位と請求単位で、件数・平均額・99%点と、1事故あたりの層「1.5億円 xs 5,000万円」の年あたりの期待損害を比べました。** 数字は、置いた分布と請求の分け方で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A508 | 請求を別々の損害として数えると、件数・平均額・裾・層の期待損害はどれだけずれるか | 事故は年にポアソン(200)、損害は対数正規（中央値300万円、σ=1.4）。請求は1〜5件（55・20・12・8・5%、大きな事故ほど多くなりやすい）、ディリクレ分布で額を分ける。事故単位・請求単位で、観測そのままと対数正規の当てはめで層の期待損害を計算。100回作り直してくり返す | `src/a508_claims_events.py` |

## 主な結果
- **件数**：年203件 → 請求単位で386件（1.90倍）
- **1件あたりの額**：平均754万円 → 396万円（53%）、中央値287万円 → 164万円、99%点7,825万円 → 3,701万円
- **層「1.5億円 xs 5,000万円」の年あたりの期待損害**（本当の値は17,736万円）
  - 事故単位：観測そのまま18,533万円、対数正規の当てはめ16,731万円
  - 請求単位：観測そのまま5,858万円（事故単位の32%）、当てはめ12,798万円（76%）
- **100回くり返した中央値**：請求単位の観測そのままは事故単位の38%、当てはめは87%
- **大きな事故ほど請求が多い、という置き方を外す**と（請求の数を額と無関係にする）、観測そのままは77%、当てはめは196%（2倍近く大きく出る）。請求単位は件数が増えて額のばらつきも広がるので、当てはめの結果は置き方しだいで上にも下にも動く

## 動かし方
```
pip install -r requirements.txt
cd src && python a508_claims_events.py
```

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した
- 事故単位の当てはめは、100回の中央値で本当の値の99.7%（観測そのままは98.7%）

## データ
- `data/fictional_events.csv`：架空の事故（年・事故番号・損害額・請求の数）
- `data/fictional_claims.csv`：架空の請求（事故番号・請求の番号・額、円未満を丸め）（seed 508）

## 注意（言えないこと）
- 架空のデータ。ずれの大きさは、1事故あたりの請求の数の分布、額の分け方、事故の額との関係で決まる
- 実際の契約で「1事故」をどう定めるか（約款の決め方）は扱っていない
- 再保険・料率の決め方を勧めるものではない。数える単位の違いで見積もりがどう動くかを数えたもの
- 当てはめは対数正規だけ。ほかの分布では違う結果になりうる
