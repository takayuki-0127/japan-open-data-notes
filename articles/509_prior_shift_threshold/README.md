# 509 起きる割合が学習のときから変わると、0.5で切る予測は何件を見逃し、確率はどれだけ外れるのか

分類のモデルは、学習データで「起きる割合」も一緒に覚えます。本番で起きる割合が変わると、出てくる確率も「0.5で切る」決め方もずれます。**中身の分布は同じで起きる割合だけが変わる架空の分類データを作り、学習1% → 本番2・3・5%、学習30% → 本番15・45% で、①0.5で切る ②しきい値を直す ③確率を直す の3通りの見逃し・空振りと、予測した確率の平均を数えました。** 本番の割合は、正解を見ずに予測した確率だけから推定しています。数字は置いたデータで決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A509 | 起きる割合が変わったとき、0.5で切る予測の見逃し・空振りと確率はどれだけずれるか。直すとどうなるか | 5つの特徴（起きた例は平均が 1.5・1.2・1.0・0.8・0.6 ずれる、標準偏差1）。学習20万件でロジスティック回帰、本番10万件。②は「出す」件数を推定した割合に合わせる、③は割合の比で確率を直して0.5で切る。割合は EM 法（Saerens ら 2002）で推定 | `src/a509_prior_shift.py` |

## 主な結果
- **学習1% → 本番5%（起きた4,966件）**
  - ①0.5で切る：見逃し3,801件（77%）、空振り76件。予測した確率の平均は2.1%（本当は5.0%）
  - ②しきい値を直す：見逃し1,810件、空振り2,015件
  - ③確率を直す：見逃し2,549件、空振り784件。確率の平均は5.2%（推定した割合5.17%）
  - 見逃しと空振りの合計は ①3,877件、②3,825件、③3,333件
- **学習1%のまま本番の割合が上がると**、①の見逃しの割合は 77%（1%）→ 77%（2%）→ 79%（3%）→ 77%（5%）。件数は784件 → 3,801件に増える
- **学習30% → 本番15%（起きた14,832件）**：①は空振りが5,258件、確率の平均は20.3%（本当は14.8%）。③は空振り2,338件・見逃し4,713件で、確率の平均14.96%
- **学習30% → 本番45%**：①は見逃し8,849件、確率の平均39.8%（本当は44.8%）。③は見逃し5,774件、確率の平均45.3%
- 推定した本番の割合は、本当の割合と 0.5 ポイント以内の差（学習1%→本番5% で 5.17% と 4.97%、学習30%→本番45% で 45.31% と 44.82%）

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- 割合が変わらないとき（1%→1%、30%→30%）は、①と③がほぼ同じ結果になること

## データ
- データファイルは置いていない。シミュレーションはコードの中で作る（seed 509）

## 注意（言えないこと）
- 架空のデータ。「中身の分布は同じで割合だけ変わる」と置いている。特徴の分布そのものが変わる場合には、③の直し方はそのままでは使えない
- どの切り方がよいかは、見逃しと空振りのどちらが重いかで決まる。ここでは件数を数えただけで、どれかを勧めるものではない
- 割合の推定（EM 法）は、モデルの確率が学習データで合っていることを前提にしている
- 健康・医療の例には当てはめていない
