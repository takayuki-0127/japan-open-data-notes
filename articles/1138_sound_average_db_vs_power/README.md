# 1138 何曲かの音の大きさをデシベルのまま平均すると、音の強さで平均した値とどれだけずれるのか？（音の大きさ）

曲ごとの大きさが dB（デシベル）で並んでいると、その値を足して曲数で割りたくなります。けれども dB は、音の強さ（波の値の二乗平均）を10×log10 で表した値なので、何曲かをつなげて流したときの大きさは、強さに戻して平均してから dB に直した値になります。dB のまま平均すると、強さで平均した値より必ず低く出ます（式どおり）。**ここでは、作成者が乱数で作った架空のアルバム2,000枚（1枚12曲、曲ごとの大きさと長さを作成者が置いたもの）で、①dB のまま平均、②強さで平均、③曲の長さで重みを付けて強さで平均（つなげた波形を測った値と同じ）、の3つを比べ、ずれの大きさ、静かな曲が1曲入ったとき、1曲の中の1秒ごとの大きさ、2枚のどちらが大きいかの入れかわりを数えました。曲どうしのばらつき・曲数・ばらつきの形を変えた24通りでも確かめました。**

例の曲・アルバムはすべて作成者が乱数で作った架空のもので、実在の曲・配信先・音量の基準を表すものではありません。この記事は数値の計算だけで、人に聞き比べてもらうことはしていません。

関連する記事：345「店ごとの平均を平均すると、全体の平均からどれだけずれるのか」は、平均どうしを平均するときの重みのずれを扱っています。644「毎年の伸び率を足して割った平均と、年率（幾何平均）では、5年後の値はどれだけ違うのか」と 1029「行きは時速40km、帰りは60kmなら、平均は50kmなのか？」は、何を足し合わせるべきかで平均の取り方が変わる例です。この記事は、dB という掛け算を足し算に直した物差しで、同じことが起きる大きさを数えます。1137「同じ大きさの音を2つ重ねると、デシベルの値は2倍になるのか？」は、同じ「強さに戻してから計算する」ことを、音を重ねるときで数えています。同じ企画の 1147「曲ごとに大きさをそろえる再生と、アルバム全体でそろえる再生では、曲どうしの強弱の差はどう残るのか？」は、この記事の③（長さで重みを付けた強さの平均）でアルバム全体の大きさを出し、再生の大きさをそろえたときに曲どうしの差がどう残るかを数えています。1143「静かな部分を含めて測るか除いて測るかで、1曲の大きさの数字はどれだけ変わるのか？」は、1曲の中の静かな区間を数に入れるかどうかを扱っていて、この記事の「前奏を除くとずれが縮む」と同じしくみです。

## 主な結果

### 基本（12曲・ばらつき3dB、2,000枚、`results/a1138_main.json` の base）
| 比べ方 | ずれの平均 | 5〜95%の範囲 | 最小〜最大 |
|---|---|---|---|
| ②強さで平均 − ①dB のまま平均 | **0.924dB** | 0.378〜1.663 | 0.128〜3.056 |
| ③長さで重みを付けて強さで平均 − ① | 0.919dB | 0.301〜1.738 | |

- **dB のまま平均すると、2,000枚すべてで強さで平均した値より低く出た（式どおり）**。ずれは平均0.924dB で、ばらつき3dB の左右対称の分布の式（ばらつき²×ln10÷20＝1.036dB、12曲の平均で数えると1.036×11÷12＝0.95dB）にほぼ合った
- ずれは、そのアルバムの中の曲どうしのばらつきでほぼ決まった（アルバムごとのばらつきとずれの相関0.938）
- 100枚で、曲ごとの雑音の波形を作ってつなげ、そのまま測った大きさは③と一致した（差0.0dB、つなげた波形の強さは長さで重みを付けた強さの平均そのもの、作りどおり）。つなげて測った大きさは、dB のまま平均より平均0.963dB 大きかった

### 静かな曲が1曲あるアルバム（例、`results/summary.csv`）
| | dB のまま平均 | 強さで平均 | 長さで重みを付けて強さで平均 |
|---|---|---|---|
| 11曲（−12.5〜−14.4dB） | −13.436dB | −13.398dB | −13.388dB |
| 12曲（−30dB・60秒の曲を足す） | −14.817dB | −13.767dB | −13.49dB |
| 下がった分 | **1.38dB** | 0.369dB | 0.103dB |

- −30dB の静かな曲を1曲足すと、dB のまま平均は1.38dB 下がったが、つなげて測った大きさ（③）は0.103dB しか下がらなかった。強さに戻すと、−30dB の曲の強さはほかの曲よりずっと小さく、足してもほとんど効かない。dB のままだと「−30」がほかの曲と同じ重みで効く

### 1曲の中の1秒ごとの大きさ（200曲、`results/within_song.csv`）
- 1秒ごとの大きさを dB のまま平均すると、強さで平均した値（1曲全体の大きさ）より平均2.875dB（5〜95%で2.189〜3.617dB）低く出た
- 静かな前奏を除くと、ずれは1.496dB に縮んだ。ずれの半分ほどは、前奏の静かな数十秒が dB のまま平均を引き下げた分だった

### 2枚のどちらが大きいか（19,991組、`results/a1138_main.json` の pairs）
- アルバムごとのばらつきを1〜6dB のでたらめにすると、dB のまま平均で比べた「どちらが大きいか」と、③で比べた答えは、**26.05%の組で入れかわった**（長さの重みを付けない②と比べても25.72%）
- dB のまま平均の差が1dB 未満の組（10,466組）に限ると、35.74%で入れかわった
- ③と①のずれは、アルバムごとに −0.067〜11.031dB（平均1.421dB）と違った。曲どうしのばらつきが大きいアルバムほど、dB のまま平均では小さく見えた（`figures/a1138_albums.png`）。ずれがわずかにマイナスの枚は、長さの重みで大きい曲より静かな曲のほうが長かった枚と考えられる（推測）

### 確かめ：ばらつき×曲数×形の24通り（各1,000枚、`results/grid.csv`）
| ばらつき | 左右対称・5曲 | 左右対称・12曲 | 左右対称・50曲 | 静かな曲がときどき・12曲 |
|---|---|---|---|---|
| 1dB | 0.095 | 0.104 | 0.113 | 1.181 |
| 3dB | 0.781 | 0.921 | 1.007 | 1.993 |
| 6dB | 2.824 | 3.422 | 3.971 | 4.519 |
| 10dB | 6.447 | 8.432 | 10.102 | 9.28 |

（数字は「強さで平均 − dB のまま平均」の平均、dB）

- **24通りすべてで、dB のまま平均のほうが低く出た**（どの通りでも5%点が0より上）。ずれの平均は0.095〜11.08dB と、曲どうしのばらつきでほぼ決まった
- ばらつき3dB 以下の左右対称では、ずれは式（ばらつき²×0.115×(曲数−1)÷曲数）と0.048dB 以内で合った。ばらつきが大きく曲数が少ないと式より小さくなり、10dB・5曲では式9.21dB に対し6.447dB だった（式は曲が多いときの近似）
- 1割の曲が15dB 静かな形では、ばらつき1dB でも1.023〜1.181dB ずれた。曲の大きさの数字のばらつきだけでなく、静かな曲がまざるかどうかで決まる

## 注意（言えないこと）
- 架空のデータです。曲の大きさの分布・長さ・静かな曲の入り方は作成者が置いたもので、ずれの大きさはこれで決まります。dB のまま平均が低く出る向きは置き方によらず式どおりで、新しく数えたのは、その大きさ・静かな曲1曲の効き方・2枚の比べが入れかわる割合です
- この記事の「大きさ」は、波の値の二乗平均（強さ）だけで数えた値です。人が聞いて感じる大きさや、配信先の音量の基準の測り方（音の高さで重みを付ける・静かな部分を除くなど）とは一致しません
- 「強さで平均」のほうが正しいのは、曲をつなげて流したときの大きさを知りたいときです。曲ごとの大きさの真ん中くらいを知りたいときに dB の平均や中央値を使うことまで誤りとは言えません
- 実在の曲・配信先・機材を表すものではありません
