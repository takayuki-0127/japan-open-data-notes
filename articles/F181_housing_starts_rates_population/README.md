# F181 家が建つ数は、金利と人口のどちらで決まるのか？

新設住宅の着工戸数（国土交通省「建築着工統計調査」）が、金利（日本銀行）と、家を建てる・借りる中心の年齢層である25〜44歳の人口（総務省「人口推計」）の、どちらとどれだけ一緒に動いてきたかを、年次の回帰・四半期の VAR（分散分解）・都道府県パネルの3つで調べました。

## 問い

- 着工戸数の年ごとの増減は、金利の動きと人口の動きの、どちらでより多く説明できるか
- 1973年のピーク（約190万戸）から2024年（約79万戸）への減少は、人口の減少でどこまで説明できるか
- 全国共通の動き（金利など）を除いて都道府県どうしを比べると、人口が減った県ほど着工も減ったか

## 手法

1. **年次（1967〜2024年、58年）**：着工戸数の対数の前年差を、基準割引率の前年差と25〜44歳人口の対数の前年差で回帰（HAC 標準誤差）。2変数の R² をシャープレイ値で分けた。10年差でも同じことをした。
2. **四半期の VAR（1977年第1四半期〜2024年第4四半期、192期）**：25〜44歳人口（対数、年の値を第4四半期に置いて補間）・都市銀行の長期貸出金利（残高）・着工戸数（季節調整値の四半期合計、対数）の3変数、定数とトレンドあり、ラグは AIC（2）。1・5・10年先の予測の外れの分散を、コレスキー分解（人口→金利→着工）と、並べ順によらない一般化分散分解（Pesaran–Shin）で分けた。
3. **都道府県パネル（2012〜2023年、47都道府県×12年）**：着工戸数の対数を総人口の対数で回帰し、県の固定効果と年の固定効果を入れた。年の固定効果が、金利など全国共通の動きを吸収する。県別の標準誤差はクラスター。

## 結果

- **年ごとの増減**：金利と人口の2つで説明できたのは16%。取り分は金利15%、人口2%。基準割引率が1ポイント上がった年は、着工が平均4.6%少なかった（p=0.005）。人口の係数ははっきりしない（p=0.24）。10年差で見ると、2つを合わせても R² 4% で、どちらもはっきりしない。
- **VAR**：5年先の予測の外れのうち、金利で説明できるのは22%（コレスキー）〜26%（一般化）、人口は6%、残りの68〜72%は着工自身の動き（消費税・建築基準法の改正・景気など、ここに入っていない要因）。金利が1標準偏差（0.10ポイント）上がると、着工は6四半期後に2.4%低くなった。
- **ピークからの減少**：1973→2024年に着工は58%減ったが、25〜44歳人口は21%の減少。着工が人口に比例するとしても、減少（対数）の27%しか説明できない。25〜44歳1,000人あたりの着工は 54.6戸→28.9戸（−47%）。1996→2024年も着工−52%に対し人口−19%（28%）。1996→2009年は人口が2%増えたのに、着工は52%減った。金利はこの間、横ばいか低下。
- **都道府県**：年の固定効果を入れると、人口の弾力性は0.05（標準誤差0.58、p=0.93）で、区別がつかない。年の固定効果を入れないと1.51（p&lt;0.001）になるが、これは全国共通の減少を人口が拾ったもの。県の中での動きの41%は、年の固定効果（全国共通の動き）で説明できた。2012→2023年の変化どうしの傾きは0.30（標準誤差0.38、R² 0.01）。

## 頑健性（5年先、一般化分散分解）

| 条件 | 金利 | 人口 |
|---|---|---|
| 基本（ラグ2、1977–2024） | 26% | 6% |
| ラグ4／ラグ8 | 26%／24% | 2%／3% |
| 並べ順を変える（コレスキー、3通り） | 22〜31% | 0〜6% |
| トレンドなし | 16% | 3% |
| 前半 1977–1999／後半 2000–2024 | 26%／46% | 9%／15% |
| 2007・2014・2020年を除く | 25% | 4% |
| 金利を国内銀行の新規・長期に（1994–） | 10% | 26% |
| 金利を基準割引率に | 27% | 14% |
| 持家／貸家／分譲 | 33%／13%／43% | 7%／1%／7% |
| 差分の VAR | 8% | 1% |

金利の取り分は8〜46%、人口は1〜26%と、条件で大きく動く。金利が人口を上回ったのは15条件中14条件で、例外は1994年以降の新規貸出金利を使った場合。

## 言えないこと

- 「金利が着工を決めた」という因果は言えない。金利は景気とともに動き、景気そのものが着工を動かす。VAR の分解は、並べ順や変数の選び方の仮定の上の数字である
- 人口の効きは、データの作りから小さく出やすい。25〜44歳人口はなめらかに動くため、その「予測の外れ」はほとんど生まれず、長い減少はトレンドに吸収される。人口が長い目で着工を押し下げている可能性は否定できない（推測）
- 人口の代わりに世帯数を使っていない。世帯数のほうが住宅の需要に近い（推測）
- 1990年代後半以降の着工の減少の大半は、金利でも25〜44歳人口でも説明できなかった。空き家の増加・建て替えの周期・住宅の長寿命化・建築コストの上昇・税制などが候補だが、このデータでは確かめていない（推測）
- 都道府県パネルは2012〜2023年の12年だけで、県の間の人口の変化の差も小さい（標準偏差 約4.6ポイント。着工の変化は約14ポイント）。そのため、人口の効きが本当にないのか、見分けられないだけなのかは区別できない
- 金利は住宅ローンの金利そのものではなく、銀行の長期貸出の平均金利や基準割引率である
- 2007・2014・2020年を除く確認では、除いた四半期の前後をつないで VAR を推定しており、粗い確認である
