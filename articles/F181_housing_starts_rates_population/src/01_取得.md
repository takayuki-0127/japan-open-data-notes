# 01 取得

data/raw/ に置いた元データの取り方です（2026-11-04 取得）。

1. **建築着工統計（月次）**：e-Stat「建築着工統計調査 住宅着工統計 → 時系列表 → 月次」から
   - 【住宅】利用関係別 戸数（statInfId=000040521928）
   - 【住宅】季節調整値（statInfId=000040521931）
   を Excel で取得し、最初のシートを CSV（UTF-8）に変換して `estat_starts_tenure_monthly_000040521928.csv`・`estat_starts_sa_000040521931.csv` として保存。
   取得 URL：`https://www.e-stat.go.jp/stat-search/file-download?statInfId=<id>&fileKind=0`
   Excel には「13か月以前の行を非表示」にした行がありますが、非表示の行も含めて CSV にしています。
2. **金利**：日本銀行 時系列統計データ検索サイトの API から月次で取得し、1つの CSV（`boj_rates_monthly_raw.csv`、列＝系列コード）にまとめました。
   - `https://www.stat-search.boj.or.jp/api/v1/getDataCode?format=csv&lang=en&db=IR01&code=MADR1M&startDate=196001`
   - 同 `db=IR04`、`code=DLLI2CI@07`・`DLLI2CI@08`・`DLLR2CIDBNL3`・`DLLR2CIDBST3`
3. **年次の着工（利用関係別・都道府県別）**：本リポジトリ `articles/091_housing_floor_area/data/` の `tenure_year.csv`・`pref_year.csv` をコピー。
4. **全国の年齢別人口**：本リポジトリ `articles/140_population_pyramid/data/pop_age_sex.csv` を年×年齢で合計し、総人口・25〜44歳・30〜39歳・20〜64歳にまとめた（`f140_pop_national_year.csv`、千人）。
5. **都道府県の人口**：本リポジトリ `articles/022_nursery_birthrate_fe/data/raw/SSDSE-B-2026.csv`（統計センター SSDSE-B）から、年度・都道府県・総人口（A1101）・15〜64歳人口（A1302）を抜き出した（`ssdse_b_pref_pop.csv`）。

このサービスは、日本銀行時系列統計データ検索サイトの API 機能を使用しています。サービスの内容は日本銀行によって保証されたものではありません。
