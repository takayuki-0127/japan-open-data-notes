# 931 分野ごとの足切りがあると、合格率はどう変わるのか？（試験と点数）

いくつかの分野からなる試験では、合計点のほかに「どの分野も一定の点以上」という足切りが置かれることがあります。足切りは「苦手な分野を残したまま合格する人」を落とすためのものと説明されます。けれども、問題の少ない分野ほど1回の点は大きく振れるので、本当はその分野が足切りより上の人も、たまたま低く出て落ちます。**ここでは、作成者が乱数で作った架空の社内資格試験の受験者200万人（分野ごとの本当の実力を作成者が置いたもの）で、足切りで合格率がどれだけ下がるか、足切りで落ちた人は本当にその分野が足切りより下だったのか、本当に苦手な分野のある人を足切りがどれだけ落とせたかを数えました。分野どうしの実力の結びつき・足切りの高さ・分野の問題数を変えた確かめも行いました。**

|---|---|---|---|
| A931 | 足切りで合格率はどれだけ下がるか。合計は足りたのに足切りで落ちた人のうち、落ちた分野の本当の実力が足切り以上だった（振れで落ちた）人は何%か。本当に足切りより下の分野がある人のうち、足切りで落とせたのは何%か | 架空の社内資格試験。分野 A 40問・B 40問・C 20問（1問1点、合計100点）。合格は合計60点以上（6割）。足切りありでは、さらにどの分野も4割以上（A・B 16点、C 8点）が要る。受験者ごとの分野ごとの「本当の実力」（何度も受けたときの平均の正答率）は、どの分野も平均55点・標準偏差13点のベータ分布で、分野どうしの相関は0.6（正規分布の相関をベータ分布の形に写した）。試験の日は当日の調子で3分野の実力が同じだけ上下し（標準偏差3点）、1問ずつその確率で正解する。「本当に足切りより下の分野」は、本当の実力が4割より下の分野。「もう一度受けたら」は、同じ実力で当日の調子と問題の当たり外れだけを引き直した。基本は200万人を1回。確かめとして、分野どうしの相関（0.3・0.6・0.9）×足切りの高さ（3・4・5割）×C の問題数（10・20・40問、合格は合計の6割）の27通りを各40万人。落ちた人などが200人未満の割合は空欄にした。seed 931 | `src/a931_section_cutoff.py` |

## 主な結果

### 基本の置き方（200万人）
| | 値 |
|---|---|
| 合格率：合計6割だけ | 36.93% |
| 合格率：合計6割＋どの分野も4割 | 36.22% |
| 足切りによる合格率の下がり | **0.71ポイント** |
| 合計で受かった人のうち、足切りで落ちた人 | 1.93%（14,242人） |
| 足切りで落ちた人のうち、C で落ちた人 | 84.8%（A 7.1%・B 8.1%） |
| 足切りで落ちた人のうち、落ちた分野の本当の実力が4割以上（振れで落ちた） | **85.3%** |
| 足切りで落ちた人のうち、本当の合計の実力が6割以上 | 60.5% |
| 合計で受かった人のうち、本当に4割より下の分野がある人 | 1.47%（10,832人） |
| そのうち足切りで落とせた人 | **19.5%** |
| 足切りありで受かった人のうち、本当に4割より下の分野がある人 | 1.20% |
| もう一度受けて受かる割合（足切りあり）：足切りで落ちた人／受かった人 | 54.7%／73.0% |

- 足切りを入れても、合格率は0.71ポイントしか下がらなかった。合計で6割を取れる人は、どの分野もそれなりに取れていることが多いため（分野どうしの相関0.6）
- 足切りで落ちた人の84.8%は、問題の少ない C（20問）で落ちていた。そして足切りで落ちた人の85.3%は、落ちた分野の本当の実力が4割以上で、1回の点が低く振れて落ちた人だった。本当の合計の実力の平均は、足切りで落ちた人61.59点、足切りありで受かった人65.35点だった
- 一方、合計で受かった人のうち本当に4割より下の分野がある人（1.47%）を、足切りで落とせたのは19.5%だけだった。足切りの線の近くでは、苦手な人も得意な人も1回の点が振れるので、どちらにもよく外れる
- 受験者全体では26.1%の人に本当に4割より下の分野があったが、そうした人の多くは合計の6割でもう落ちていた。足切りがはたらく人は、合計で受かった人の中のわずかな人だけだった
- 「足切りで落ちた人の多くは振れで落ちた」は、本当に苦手な人が合計で受かった人の中に少ないことの写しでもある。もともと少ないものを、振れの大きい1回の点で探すと、見つけたもののうち本物は少なくなる（検査で不良と出た品物のうち本当の不良の割合と同じ仕組み）

### C の本当の実力ごとに、C で足切りされる割合（合計で受かった人、`results/cut_by_true_C.csv`）
- C が20問のとき、C の本当の実力が38〜40点の人で19.9%、44〜46点の人で10.9%が C で足切りされた。問題が少ないほど、足切りの線の上の人も落ち、下の人も残った（図 `a931_cut_by_true_C.png`）

### 確かめ：置き方を変えると（27通り、各40万人、`results/robustness.csv`）
| 分野どうしの相関 | 足切り | 合格率の下がり（C 10／20／40問） | 足切りで落ちた人のうち振れで落ちた（同） | 本当に苦手な分野のある人を落とせた（同） |
|---|---|---|---|---|
| 0.3 | 4割 | 2.57／1.58／0.97ポイント | 72.6%／65.5%／61.3% | 32.3%／30.1%／26.2% |
| 0.6 | 4割 | 1.57／0.75／0.33ポイント | 89.8%／84.7%／81.8% | 22.9%／21.3%／15.5% |
| 0.9 | 4割 | 0.80／0.20／0.03ポイント | 99.5%／99.4%／空欄 | 空欄 |
| 0.6 | 3割 | 0.38／0.08／0.01ポイント | 98.5%／96.6%／空欄 | 空欄 |
| 0.6 | 5割 | 5.98／4.95／4.10ポイント | 64.3%／60.7%／58.2% | 36.0%／35.2%／33.7% |

（空欄は、足切りで落ちた人、または合計で受かった人のうち本当に苦手な分野のある人が200人未満）

- 合格率の下がりは27通りで0〜8.60ポイントだった。足切りが高いほど、分野どうしの相関が低いほど、C の問題数が少ないほど大きく下がった
- **足切りで落ちた人のうち振れで落ちた人は、値のある23通りで39.7〜100%だった**。足切り4割の8通りでは61.3〜99.5%で、どの置き方でも半分を超えた。半分を下回ったのは、相関0.3で足切り5割の3通り（39.7〜45.9%）だけで、本当に苦手な人が多い置き方だった
- 本当に苦手な分野のある人を足切りで落とせた割合は、値のある18通りで14.2〜44.5%だった。どの置き方でも半分に届かなかった
- 足切りで落ちた人がもう一度受けて受かる割合は、値のある23通りで37.0〜62.3%だった

- C を40問にして A・B と同じにすると、足切りで落ちた人の内訳は C が33.1〜35.2%（3分野でほぼ3等分）になった（`results/robustness.csv` の removed_by_C、値のある通り）。C で落ちる人が多いのは問題数が少ないためで、C だけ難しく置いたためではない

## 注意（言えないこと）
- 架空のデータです。分野ごとの実力の分布、分野どうしの相関、当日の調子の振れ、足切りと合格点の高さは作成者が置いたもので、数字はこれで決まります。とくに「振れで落ちた人の割合」は、合計で受かった人の中に本当に苦手な人がどれだけいるかで大きく動きます（23通りで39.7〜100%）
- どの分野も同じ難しさ・同じ実力の分布と置きました。ある分野だけ難しい試験、分野の点を問題数で割り戻して比べる試験（点の換算）は入れていません
- 合格点は固定で、合格者の数を決める試験（上から何%）は扱っていません。その場合は、足切りで落ちた人の分だけ合格点が下がり、合格率は変わりません（推測）
- 足切りを置くべきか、どの高さがよいかは、ここからは言えません。「本当に4割より下の分野がある人を落とす」以外の目的（その分野を勉強させるなど）は数えていません
- 関連する記事：同じ企画の 930 は、合格点のすぐ両側の人の実力がほとんど同じであることを1つの合格点について数えていて、足切りの線の近くでも同じことが起きます。品質と検査の企画の 911（検査で不良と出た品物は本当に不良か）は、少ないものを振れのある検査で探すと見つけたもののうち本物が少なくなることを数えていて、この記事の「足切りで落ちた人の多くは振れで落ちた」と同じ仕組みです。920（工程を2つつなぐと良品率はどうなるか）は、すべての工程で良品である割合を数えていて、どの分野も足切りを超える割合と同じ掛け算の形です
