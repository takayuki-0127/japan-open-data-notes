# F294 介護の費用は、2040年度にどこまで増えるのか？ 前提を変えると？

精選モード（A. 保険数理・リスク Q11）。計画は [PLAN.md](PLAN.md)（結果を出す前に書いてコミット済み）。

## 問い
介護保険料、自治体の事業計画、介護の仕事の需要を考える人にとって、「2040年度に介護の費用はいくらか」は基本の数字です。
ただ、答えは前提で変わります。この記事では、全国の公表集計値だけを使い、次の3つの前提がそれぞれどれだけ効くかを分けて示します。

1. 人口の見通し（死亡の仮定）
2. 年齢別の受給率（人口に占める受給者の割合）
3. 受給者1人当たりの費用の伸び

将来の数字は「前提を置いた計算」であって、予測ではありません。

## データ（全国の集計値のみ）
| データ | 中身 | ファイル |
|---|---|---|
| 厚生労働省「介護給付費等実態統計」概況の図表データ（平成26・令和元・令和6・令和7年度） | 65歳以上の性・5歳階級別の受給者数と受給率（各年度11月審査分）、統計表６（2001〜2025年度の年間実受給者数と費用額累計、介護予防／介護）、受給者1人当たり費用額（各年4月審査分） | data/raw/kyufu*_09.xls(x) |
| 国立社会保障・人口問題研究所「日本の将来推計人口（令和5年推計）」表1-9A・4-9A・7-9A | 男女・5歳階級別人口（出生中位で、死亡中位・高位・低位） | data/raw/ipss_*.xlsx |
| 「2040年を見据えた社会保障の将来見通し（議論の素材）」（2018年5月、内閣官房・内閣府・財務省・厚生労働省） | 介護給付費 2018・2025・2040年度（経済ベースラインケース、計画ベースと現状投影） | 数値をコードに転記（src/zz_f294_03_分析.py） |

出典URLとmd5は data/raw/manifest.json。

用語：
- **費用額**：審査で決まった額。保険給付・公費・利用者負担の合計。償還払いと、総合事業（地域支援事業）の費用は含まない。2025年度は12.2兆円。
- **受給率**：性・年齢階級別の人口に占める受給者（介護予防サービスか介護サービスを受けた人）の割合。11月審査分。

## 手法
- 2040年度の費用額 ＝ 2025年度の費用額 × 受給者の伸び × 受給者1人当たり費用の伸び。
- 受給者の伸び ＝ Σ 受給者2025(年齢, 性) × 人口の比2040/2025(年齢, 性) × 受給率の変化(年齢, 性) ÷ Σ 受給者2025。
  65歳以上の7つの年齢階級（95歳以上はまとめる）× 男女。
- シナリオ：死亡の仮定3つ × 受給率4つ（2025年のまま／2014→25年度の年率が続く／2019→25年度の年率が続く／2014→25年度の年率の半分）× 1人当たり費用の伸び3つ（名目 年0%・1%・2%）＝ 36通り。
- 答え合わせ：2014→2025年度などの費用の伸びを、対数で「人口構成（受給率を固定）」「受給率の変化」「受給者1人当たり」に分けた。過去の人口は受給者数÷受給率（受給率は小数1桁に丸めた値なので、誤差がある）。
- 政府見通しとの比較：範囲（給付費と費用額）も2025年度の水準も違うので、金額ではなく2025→2040年度の倍率で比べた。

## 結果
| 項目 | 値 |
|---|---|
| 2025年度の費用額（実績） | 12.2兆円 |
| 人口の変化だけ（受給率・1人当たり費用は2025年度のまま、死亡中位）の65歳以上の受給者 | 1.25倍 → 費用額15.3兆円 |
| 同じで、1人当たり費用が年1%／年2%伸びる | 17.7兆円／20.6兆円 |
| 36通りの幅 | 12.9〜21.4兆円（最大÷最小 1.66倍） |
| 死亡の仮定だけを変える（受給率一定） | 2040年の受給者数が中位より 死亡高位 −4.1%、死亡低位 +4.0% |
| 受給率が2014→25年度の年率で下がり続ける（1人当たり一定） | 受給者1.10倍、13.5兆円 |
| 受給率が2019→25年度の年率で動く（1人当たり一定） | 受給者1.25倍、15.2兆円（2025年のままとほぼ同じ） |
| 政府見通し（2018年）2025→2040年度の倍率 | 計画ベース1.686倍、現状投影1.685倍（年3.5%） |
| 受給率一定でその倍率に届くのに要る1人当たり費用の伸び（本記事の計算） | 年2.0% |
| 実績の1人当たりの伸び | 統計の「受給者1人当たり費用額」（各年4月審査分）：2014→25年 年1.0%、2019→25年 年0.6%、2017→18年の段差（+6.4%）を除くと2014→25年 年0.5%。費用額÷65歳以上の受給者（11月審査分）：2014→25年 年1.0%、2019→25年 年0.5% |
| 過去の実績の伸び（年0.5〜1.1%）を置いたとき（受給率一定、死亡中位） | 16.5〜18.0兆円（0.5%→16.5、0.6%→16.7、1.0%→17.7、1.1%→18.0） |

過去の分解（費用額、対数の寄与）：
| 期間 | 費用の倍率 | 人口構成 | 受給率の変化 | 1人当たり |
|---|---|---|---|---|
| 2014→2025年度 | 1.31（年2.5%） | ×1.33 | ×0.88 | ×1.12 |
| 2014→2019年度 | 1.13（年2.5%） | ×1.18 | ×0.89 | ×1.09 |
| 2019→2025年度 | 1.16（年2.5%） | ×1.14 | ×0.99 | ×1.03 |

受給率を固定して人口構成だけで見込むと、2014→2025年度は実績（×1.31）より高い×1.33になった。受給率の下がりがその分を打ち消し、1人当たりの伸びが足された。受給率の下がりは2014→19年度に集中している。

### 問い直し（結果を見てから足した。計画外）
**2014→19年度の受給率の下がりは、介護予防サービス（要支援）の側に偏っているか？**
2015〜2017年度に、介護予防の訪問介護・通所介護は総合事業へ移りました。総合事業の受給者は、この記事で使った費用額・受給者数の表（統計表６、図２データ）には入りません。受給者数は同じ統計の統計表５（令和7年度版。令和元年度版は統計表４）に別に載っていて、2025年度は月に94〜96万人です（src/zz_f294_05_再質問.py）。

| 期間 | 人口構成だけ | 全体 | 介護サービス | 介護予防サービス |
|---|---|---|---|---|
| 2014→2019年度 | ×1.175 | ×1.039 | ×1.119 | ×0.723 |
| 2019→2025年度 | ×1.136 | ×1.121 | ×1.096 | ×1.245 |

- 2014→19年度の受給率の下がり（対数）は、約6割が「介護サービスだけを見ると消える」部分で、介護予防の側の減りと重なります（近似。全体と介護では数え方が少し違う）。
- 介護サービスだけでも、人口構成の伸びよりやや遅い（2014→19 ×0.95、2019→25 ×0.96）。
- このため「2014→25年度の受給率の傾向が続く」シナリオ（13.5兆円）は、制度の切り替えでできた下がりを将来に延ばしている面があると考えられます（推測）。
- 1人当たり費用額の2017→18年の段差（+6.4%）も、費用の小さい介護予防の受給者がこの表から外れた時期に重なります。
- 注意：年間実受給者には40〜64歳が含まれ、両方を使った人は両方に数えられます。人口構成の伸びは65歳以上の11月審査分から計算した近似です。
- 足し戻しの確認（レビュー後に追加、results/reask_addback_sogo.csv）：11月審査分の月の受給者数で、介護予防＋総合事業は2014年111.5万（総合事業の前）→2019年174.0万（78.4万＋95.6万）→2025年196.9万（100.6万＋96.3万）。足し戻すと要支援の側の数は減らずに増える。ただし総合事業には要介護認定を受けていない事業対象者も入り、両方を使う人は二重に数えるので、受給率の比較には使っていない。

## 計画からのずれ
- R1は「基準年を2019年度にする」としていた。2040年の人口比はIPSSの2025年起点なので、「受給率を2019年度の水準に置く」で代えた。
- R5は「費用額累計で分解をやり直す」としていた。基本の分解がすでに費用額累計なので、「1人当たりを年間実受給者数で測る」に代えた。
- H5は計画ベースの2040年度の水準と比べる予定だった。範囲（給付費と費用額）と基準年度の水準が違うので、2025→2040年度の倍率で比べた。水準で比べても、政府25.8兆円・本記事17.7兆円で、向きは同じ。
- 「傾向の半分」は計画では頑健性（R4）だったが、本体のシナリオにも入れた（27通り→36通り）。
- H5 の比較相手は、計画の「計画ベース」ではなく「現状投影」の倍率（1.685）を使った。計画ベースは1.686で、判定は変わらない。
- 計画にない追加：統計表６の2001〜2025年度の長い系列、1人当たり費用額の2017→18年の段差の除外、問い直し（介護予防と介護の分離）。

## 言えないこと
- 2040年度の費用の予測ではない。報酬改定、賃金・物価、制度の変更は入れていない（1人当たりの伸びとしてまとめて置いただけ）。
- 40〜64歳の受給者（第2号）は年齢別に入れていない。65歳以上と同じ割合で動くと置いた。
- 総合事業（地域支援事業）の費用は入っていない。
- 年齢別の1人当たり費用はこの表にない。R3は仮の重み。
- 受給率の下がりが「元気な高齢者が増えた」のか「使い方・制度が変わった」のかは、この集計値では分けられない。問い直しで分かったのは、下がりの多くが介護予防の切り替えの時期と重なることだけ。
- 名目の金額。物価で割った実質の比較はしていない。
- 受給者数÷受給率で戻した2025年の人口は、IPSS中位の2025年人口より90〜94歳で約2〜3%、95歳以上で約6%少ない（results/implied_vs_ipss_2025.csv）。推計人口のほうが高い年齢の死亡を低めに見ている可能性がある（推測）。人口は比で使っているので、本体の計算への影響は小さいと考える。
- 政府見通しとは範囲が違う（給付費、地域支援事業の扱いは資料で確認できなかった）。倍率で比べたのは推測を含む簡便な比較。

## レビューで直したこと
独立レビュー（作成に関わっていない別のエージェント）で、出典の値・政府見通しの数値・本文の数字がすべて一致し、別のフォルダでの再実行もバイト単位で一致した。指摘を受けて直したこと：
- 「総合事業はこの統計の外」は誤り。同じ統計の統計表５（令和元年度版は統計表４）に総合事業の受給者数が載っている。「この記事で使った費用額・受給者数の表には入らない」に直し、受給者を足し戻す確認を足した（src/zz_f294_05_再質問.py、results/reask_addback_sogo.csv）。
- 政府見通しとの比較の「過去の実績の伸びなら17〜18兆円」を「年0.5〜1.1%なら16.5〜18.0兆円」に直した（計算し直した値）。
- 「受給率の下がりの約6割は介護予防の側の減り」は、数え方の違う量の比べなので「約6割が介護予防の側の減りと重なる（近似）」に弱めた。
- 「制度の切り替えの影響が入っている」を「入っていると考えられる（推測）」にした。最近の物価・賃金の動きについての文にも（推測）を付けた。
- 「いちばん効くのは1人当たりの伸び」に「年0〜2%の幅を置くと」の条件を付けた。政府見通しとの対応は「本記事の計算では年2.0%の伸びに相当」と書き直した。
- 1人当たりの伸びの年0.5%と年0.6%が、別の定義（費用額÷65歳以上の受給者／統計の受給者1人当たり費用額）であることを明記した。
- 死亡の仮定の効果を「伸び」ではなく「2040年の受給者数が中位より」と書き直し、「90歳前後」を「90歳代」にした。
- 計画からのずれに「傾向の半分を本体に入れた（27→36通り）」「H5 は現状投影と比べた」を足した。
- 言えないことに、受給者数÷受給率で戻した2025年の人口が推計人口より高い年齢で少ないこと（results/implied_vs_ipss_2025.csv）を足した。
