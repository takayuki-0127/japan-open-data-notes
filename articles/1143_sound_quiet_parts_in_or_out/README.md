# 1143 静かな部分を含めて測るか除いて測るかで、1曲の大きさの数字はどれだけ変わるのか？（音の大きさ）

1曲の大きさを1つの数字にするとき、曲の頭や終わりの無音、途中の切れ目、静かに弾く部分を数に入れるかどうかで、数字が変わります。配信先の音量の基準の測り方のように、短い区間ごとに大きさを数え、小さすぎる区間を除いてから平均するやり方もあります。**ここでは、作成者が式と乱数で作った架空の曲300曲（1曲60秒。大きい部分・静かに弾く部分・無音の長さと大きさを作成者が置いたもの）を、①全部含める、②とても小さい区間（−70 dB 未満）だけ除く、③②の値より10 dB 以上小さい区間も除く（2段で除く）、の3つで測り、1曲の数字がどれだけ変わるか、曲どうしの大きさの順がどれだけ入れかわるかを数えました。静かに弾く部分の深さを少しずつ変えた曲と、置き方を変えた27通りでも確かめました。**

この記事の「大きさ」は、波の値の二乗（強さ）の平均を 10×log10 で dB にした値です（上限いっぱいの振れ幅1.0を0 dB とした値、音の高さによる重みはなし）。人が聞いて感じる大きさや、実在の配信先の測り方の数字とは一致しません。

何曲かの大きさを dB のまま平均するずれは同じ企画の 1138 で扱っています。1138 は曲どうしのまとめ方、この記事は1曲の中のどの区間を数に入れるかに絞ります。1138 の確かめの中にも「静かな前奏を除くと dB のまま平均のずれが縮む」という結果があり、静かな部分が数字を引き下げるしくみは同じです。同じ企画の 1146「短い区間ごとに測った大きさの最大値は、区間の長さでどう変わるのか？」は、短い区間ごとの大きさの最大値が区間の長さでどう変わるかを数えています。区間ごとに測る点は同じで、この記事は静かな区間を除いて平均し、1146 は除かずに最大値を見ます。

## 主な結果

### 300曲で、①全部含める と ③2段で除く の差（`results/a1143_main.json`）
| | 値 |
|---|---|
| ③−① の中央値 | **1.61 dB** |
| ③−① の5〜95%の範囲 | 0.24〜3.82 dB |
| ③−① の最大 | 5.89 dB |
| ②−① の中央値（無音だけ除いた分） | 0.86 dB |
| 2曲の組のうち、①と③で大きさの順が入れかわった組 | **10.86%** |
| 大きさの順位が30位以上動いた曲 | 31.3% |

- 静かな部分を除いた③は、全部含めた①より、300曲の中央値で1.61 dB 大きく出た。除いて小さく出る曲はなかった（③−① の最小0.0 dB）
- **無音の分のずれは式どおり**。無音が値0なら、①は鳴っている部分の本当の大きさより 10×log10(1−無音の割合) だけ低く出る（無音30%で −1.549 dB、40%で −2.218 dB）。300曲すべてで、式との差は0.036 dB 以内だった
- ①は鳴っている部分の本当の大きさより中央値で0.96 dB、最大で2.21 dB 低く出た
- 2曲の組（44,850組）のうち10.86%で、①と③でどちらが大きいかが入れかわった

### 鳴っている部分が同じで、無音の割合だけ違う2曲（`results/pair_same_music.csv`）
| 無音の割合 | ①全部含める | ②−70 dB 未満を除く | ③2段で除く |
|---|---|---|---|
| 0% | −14.0 dB | −14.0 dB | −14.0 dB |
| 40%（頭と終わりに20%ずつ） | −16.22 dB | −14.01 dB | −14.01 dB |

- 同じ演奏でも、頭と終わりに無音を足すだけで①は −14.0 dB から −16.22 dB に下がった。②と③は無音を除くので、ほぼ同じ値になった

### 静かに弾く部分の深さで、③が何を測るかが変わる（`results/by_soft_depth.csv`、静かに弾く部分が10%を超える曲）
| 静かに弾く部分の深さ | 曲数 | ③−鳴っている部分の本当の大きさ（中央値） | ③−大きい部分だけの本当の大きさ（中央値） | ③−①（中央値） |
|---|---|---|---|---|
| 4〜8 dB | 41 | −0.06 dB | −1.38 dB | 1.08 dB |
| 8〜12 dB | 33 | −0.04 dB | −0.97 dB | 1.27 dB |
| 12〜16 dB | 52 | 1.11 dB | −0.18 dB | 2.14 dB |
| 16〜20 dB | 45 | 1.35 dB | −0.13 dB | 2.04 dB |
| 20〜24 dB | 50 | 1.46 dB | −0.14 dB | 2.36 dB |

- 静かに弾く部分が12 dB より浅いと③は「鳴っている部分全体」の大きさに近く、深いと「大きい部分だけ」の大きさに近くなった。③は、静かに弾く部分をどこまで曲の一部と見るかを、境目の位置で決めている
- 300曲で、③が鳴っている部分の本当の大きさから±0.5 dB 以内だったのは50.0%、大きい部分だけの本当の大きさから±0.5 dB 以内だったのは75.0%だった

### 静かに弾く部分（40%）が境目をまたぐと、数字が跳ぶ（`results/jump_sweep.csv`）
| 静かに弾く部分の深さ | ③2段で除く | ③で数えた静かに弾く区間 |
|---|---|---|
| 10 dB | −15.93 dB | 100.0% |
| 11 dB | −15.99 dB | 100.0% |
| 12 dB | −15.25 dB | 55.0% |
| 13 dB | −13.99 dB | 0.0% |
| 14 dB | −13.99 dB | 0.0% |

- 静かに弾く部分を11 dB 小さくした曲と13 dB 小さくした曲で、③は**2.0 dB** 跳んだ。同じ2曲で①は −0.08 dB しか変わらなかった。静かに弾く部分が、②の値−10 dB の境目をまたいで、まるごと数から外れたため
- 跳ぶ大きさは「静かに弾く部分を含めた強さの平均」と「大きい部分だけ」の差で、式で決まる（11 dB のとき含めた式の値 −15.994 dB、大きい部分だけ −14 dB）。新しく数えたのは、深さが2 dB 変わるだけでその差がまるごと出ることです

### 置き方を変えた27通り（各150曲、`results/grid.csv`）
- ③−① の中央値は **0.97〜1.66 dB**、最大は3.77〜5.96 dB だった。区間を長くするほど、③の境目を深くするほど、差は小さくなった
- ①と③で順が入れかわった組は **7.36〜10.77%** だった
- **無音に −60 dB や −45 dB の小さな雑音が入ると、②（−70 dB 未満を除く）は何も除かなくなった**（②−① は9通りすべてで0.0 dB。無音が値0のときは0.71〜0.88 dB）。③は雑音の入った無音も除いたので、③−① は雑音なしのときとほぼ同じだった
- ③が鳴っている部分の本当の大きさから±0.5 dB 以内だった曲は46.7〜78.7%だった

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の10ファイルがバイト単位で一致した（cmp）
- 図3枚を開き、日本語・重なり・軸を確かめた（図2の縦軸は0から）
- 無音が値0のとき、①と鳴っている部分の本当の大きさの差が式 10×log10(1−無音の割合) と0.036 dB 以内で合うことを確かめた
- 境目の確かめで、静かに弾く部分を全部数えるとき③が含めた式の値（11 dB で −15.994 dB に対し −15.99 dB）、全部除くとき大きい部分だけの値（−14 dB に対し −13.99 dB）と合うことを確かめた

## 注意（言えないこと）
- 架空のデータです。無音・静かに弾く部分の割合と深さ、曲の大きさは作成者が置いたもので、差の大きさはこれで決まります。無音の分のずれは式どおりで、新しく数えたのは、静かに弾く部分の深さによる違い、順の入れかわり、境目をまたぐときの跳び、無音に雑音が入るときの②の効かなさです
- ②・③の境目（−70 dB・−10 dB）と区間の長さは作成者が置いた値です。実在の配信先の音量の基準の測り方（区間の重ね方、音の高さによる重みなど）を写したものではなく、その数字を言い当てるものでもありません
- 曲は「大きい部分」「静かに弾く部分」「無音」の3つの段だけで作りました。だんだん小さくなる終わり方や、強弱が細かく続く曲では、跳び方はなだらかになると考えています（推測）
- どの測り方を使うべきかの助言ではなく、含め方で数字がどれだけ変わるかを数えただけです。人が聞いて比べる形の評価はしていません
