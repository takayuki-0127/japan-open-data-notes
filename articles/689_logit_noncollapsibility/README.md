# 689 結果に効く変数をロジスティック回帰に入れないと、施策と関係のない変数でも、施策の係数はどれだけ小さく出るのか（手法の解説・正解の分かるデータで試す）

ふつうの回帰（線形回帰）では、施策と関係のない変数は、入れても入れなくても施策の係数の期待値を変えません。ロジスティック回帰では違います。結果に強く効く変数を入れないと、施策を無作為に割り付けていても、施策のオッズ比は1に近づきます（オッズ比が「つぶれない」性質＝非崩壊性）。**ここでは、架空の申込みデータ（2,000人、施策は無作為に半分）で、もともとの申込みやすさ X の効き方を4通りに変え、X を入れた回帰と入れない回帰の施策のオッズ比、確率の差、標準誤差を比べました。** 各400回です。数字は置いた効き方で決まります。

## 主な結果（400回）
| X の効き方 c | X を入れたオッズ比 | X を入れないオッズ比 | X で平均した本当のオッズ比 | 申込率の差（本当／単純比較） |
|---|---|---|---|---|
| 0 | 2.01 | 2.01 | 2.01 | 15.7 / 15.6 ポイント |
| 1 | 2.01 | **1.79** | 1.79 | 13.5 / 13.4 |
| 2 | 2.02 | **1.53** | 1.53 | 10.2 / 10.1 |
| 3 | 2.02 | **1.37** | 1.38 | 7.9 / 7.8 |

- X を入れた回帰は、どの c でも本当のオッズ比 2.01（= exp(0.7)）に近かった
- X を入れないと、X が施策と無関係でも、オッズ比は c=2 で1.53、c=3 で1.37と1に近づいた。これは「間違い」ではなく、X で平均した全体のオッズ比（別の量）を当てている
- 確率の差（申込率の差）は、X を入れない単純な比較でも本当の値とほぼ一致した。施策が無作為なので、確率の差はずれない
- 施策の係数の標準誤差は、X を入れたほうが大きかった（c=3 で0.136 対 0.091）。ただし係数そのものも大きいので、検定の力は X を入れたほうが強い

## 注意（言えないこと）
- 架空のデータです。X の効き方は作成者が置いたもので、縮み方の大きさはこれで決まります
- 「X を入れるべきか」は、何を知りたいか（X をそろえた人どうしの比較か、全体の比較か）で決まります。ここでは2つが違う量であることを示しました
