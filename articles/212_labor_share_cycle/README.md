# 212 労働分配率は景気の波でどう動くか：法人企業統計（四半期別調査）

財務省「法人企業統計調査」四半期別調査の時系列（1954年4〜6月期〜2026年4〜6月期、金融業・保険業を除く）で、四半期の労働分配率を計算し、季節調整したうえで、内閣府の景気基準日付（山・谷）の前後でどう動くかを見たフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A212 | 労働分配率は景気の波でどう動くか | 労働分配率＝人件費÷（人件費＋経常利益＋支払利息等＋減価償却費）。STL（周期4）で季節調整、HPフィルター（λ=1600）の循環成分の相関、景気の山・谷を0とした前後8四半期のイベントスタディ、後退期（山→谷）の変化、資本金規模別 | `src/a212_labor_share.py` |

## 主な結果
- 季節調整済みの労働分配率（全規模）は、最低が1960年10〜12月期の45.7%、最高が2009年1〜3月期の71.9%。直近の2026年4〜6月期は51.5%
- 14回の景気後退期（山→谷）のうち13回で分配率が上がり、平均+4.08ポイント。上がり幅が大きいのは1973〜75年（+10.65）、1991〜93年（+9.39）、2008〜09年（+8.15）、2018〜20年（+7.61）で、どれも経常利益が47〜70%減った時期
- 山から4四半期後の分配率は平均+2.84ポイント（14回中13回で上昇）、谷から4四半期後は平均−2.76ポイント（14回すべてで低下）
- HPフィルターの循環成分の相関は、分配率と経常利益が−0.88、分配率と売上高が−0.58。売上高の循環との相関は分配率が1四半期遅れたとき（−0.66）が最も強い
- 循環成分の大きさ（標準偏差）は、経常利益18.1%に対し人件費2.66%。人件費があまり動かず利益が大きく動くことが、分配率が景気と逆に動く理由
- 10年平均は1990年代65.3%、2000年代65.5%、2010年代62.0%、2020年代56.3%。資本金10億円以上は2020〜24年平均41.8%、2025年以降35.7%と下がり、1千万〜1億円（約70%）との差が開いた

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a212_labor_share.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/mof_quarterly_1954_2026.csv | 四半期（開始月）ごとの人件費・経常利益・支払利息等・売上高・減価償却費（億円）。全規模（all）、資本金10億円以上（all_large）、1億〜10億円（all_mid）、1千万〜1億円（all_small）、製造業（mfg）、非製造業（nonmfg） |

- 財務省財務総合政策研究所「法人企業統計調査」の主要項目の時系列データ（英語版ページ https://www.mof.go.jp/english/pri/reference/ssc/historical.htm の Excel：income・personnel・all）。ブラウザで読み、必要な列だけ書き出した。原数値（季節調整なし）
- 景気基準日付は内閣府経済社会総合研究所「景気基準日付」（https://www.esri.cao.go.jp/jp/stat/di/hiduke.html、第16循環の谷2020年5月まで）を src/common.py に書いた

## 注意
- 四半期別調査には「付加価値」の項目がないため、年次別調査の定義（人件費＋支払利息等＋動産・不動産賃借料＋租税公課＋営業純益）とは違う近似で、水準は年次の労働分配率と一致しない
- 経常利益には子会社からの受取配当なども含まれるため、大企業の分配率は低めに出る。近年の大企業の低下には、海外子会社からの配当の増加も影響している可能性がある
- 季節調整は X-13ARIMA-SEATS ではなく STL（statsmodels）を使った。年によって標本の入れ替えによる段差がある
- 2020年5月の谷以降、新しい山は決まっていない
