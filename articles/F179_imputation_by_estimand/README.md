# F179 欠測を埋める方法で、答えはどれだけ変わるか？（推定したい値ごとの比較）

看板記事 F179。市区町村の統計で値が欠けたとき、どう埋めるかで答えはどれだけ変わるかを、「何を知りたいか（平均・分布の端・ばらつき・割合・相関・回帰係数）」ごとに比べました。値がそろっている SSDSE を「答えがわかっている母集団」とみなし、3つの項目をわざと3割欠かして、8通りの方法で埋めています。

[F41](../F41_missing_data_mi/) では、1つの変数（持ち家率）の欠測が1つの回帰係数をどう動かすかを見ました。F179 では、次の点を足しています。

- 3つの変数を同時に欠かす
- 6種類の「知りたい値」を比べる
- 毎回、母集団から標本を引き直して、95%区間の当たりを正しく数える
- 埋める回数 m と、埋めるモデルの形も比べる

## 問い

- 欠測を「捨てる」「平均で埋める」「回帰で埋める」「近い町で埋める」「多重代入」で、答えはどれだけ変わるか
- 平均・90%点・標準偏差・割合・相関・回帰係数のうち、埋め方の影響を受けやすいのはどれか
- 多重代入でも直らないのはどんなときか。埋める回数 m はいくつあれば足りるか

## データ

統計センター SSDSE-A-2026（市区町村、1,741行）。人口が0の1町を除いた 1,740 市区町村を使いました。SSDSE には欠測がありません。そのため、そろったデータを母集団として、あとから欠かしています（設計書の代替案「欠測を人工的に作ってシミュレーションだけで行う」）。

| 列 | 中身 | 年 | 欠かすか |
|---|---|---|---|
| logpop | 総人口の対数 | 2020 | 欠かさない |
| aging | 65歳以上人口の割合（%） | 2020 | 欠かさない |
| logdens | 可住地1km²あたり人口の対数 | 2020／2024 | 欠かさない |
| births | 人口千人あたり出生数 | 2023 | 欠かさない |
| single | 一般世帯に占める単独世帯の割合（%） | 2020 | 欠かさない |
| logtax | 1人あたり地方税（千円）の対数 | 2022 決算 | **欠かす** |
| unemp | 完全失業率（%） | 2020 | **欠かす** |
| tert | 就業者に占める第3次産業の割合（%） | 2020 | **欠かす** |

## 知りたい値（真の値は 1,740 市区町村で計算）

| 値 | 真の値 |
|---|---|
| 1人あたり地方税の平均 | 152.6 千円 |
| 1人あたり地方税の90%点 | 199.8 千円 |
| 失業率の標準偏差 | 1.15 ポイント |
| 失業率5%以上の市区町村の割合 | 8.7% |
| 失業率と第3次産業の割合の相関 | 0.265 |
| 回帰係数：第3次産業の割合1ポイントあたりの地方税の差（log 地方税を、第3次産業・高齢化・人口密度・失業率で回帰、HC1） | +0.30% |

## 方法

**くり返し**：1,740 市区町村から同じ数を復元抽出し（標本のばらつきを入れるため）、3列をそれぞれ平均30%欠かしてから、埋めて推定しました。これを250回くり返しています（木のモデルは40回、頑健性は120回）。

**欠け方（3通り）**

| 名前 | 中身 |
|---|---|
| でたらめ（MCAR） | どの町も同じ確率で欠ける |
| 人口が小さい町ほど欠ける（MAR） | 欠けるかどうかは、欠かさない人口だけで決まる。人口1標準偏差あたりロジット1.5 |
| 値が大きいほど欠ける（MNAR） | その値自体が大きいほど欠ける |

人口が小さい町ほど欠ける場合、いちばん小さい1割の町では75%、いちばん大きい1割では2%が欠けます（図1）。

**埋め方（8通り）**

| 方法 | 中身 |
|---|---|
| 値がある町だけ | 値ごとに、そろっている町だけで計算。回帰と相関は全部そろった町だけ |
| 平均で埋める | 値がある町の平均で埋める |
| 回帰で1回埋める | ほかの7列からの回帰の予測値で埋める（連鎖方程式を10回まわす。ばらつきは足さない） |
| 回帰＋ばらつきで1回 | 多重代入（正規）を1組だけ作り、それをそろったデータとして扱う |
| 近い5町で埋める | 標準化した7列で近い5町の平均（scikit-learn の KNNImputer） |
| 木のモデルで埋める | ExtraTrees を使った連鎖方程式（IterativeImputer、1組） |
| 多重代入（正規） | 連鎖方程式。係数と分散を事後分布から引き、正規分布の誤差を足して埋める。m=10、ルービンのルール |
| 多重代入（PMM） | 同じだが、予測値が近い5町の実際の値から1つ引いて埋める（予測平均マッチング） |

多重代入は自分で書いたもの（`src/common.py` の `mice`）で、m 本の鎖を10回ずつまわします。埋めるときには、欠かさない5列と、欠かす3列（地方税を含む）をすべて使います。

**評価**
- 偏り：推定の平均 − 真の値。「欠かす前の推定の標準偏差の何倍か」でも示しました
- 95%区間の当たり：区間が真の値を含んだ割合。1回だけ埋める方法は、埋めたデータをそろったデータとして SE を計算しました
- 90%点と標準偏差は SE を出していないので、偏りだけを比べました

## 主な結果

### でたらめに欠ける場合（30%）

| 方法 | 地方税の平均 | 90%点 | 失業率のSD | 5%以上の割合 | 相関 | 回帰係数 |
|---|---|---|---|---|---|---|
| 真の値 | 152.6 | 199.8 | 1.15 | 8.7% | 0.265 | +0.30 |
| 欠かす前 | 152.3 | 199.5 | 1.16 | 8.6% | 0.267 | +0.29 |
| 値がある町だけ | 152.4 | 199.4 | 1.15 | 8.6% | 0.267 | +0.27 |
| 平均で埋める | 148.1 | 182.0 | 0.96 | 6.0% | 0.186 | +0.16 |
| 回帰で1回埋める | 148.8 | 187.7 | 1.02 | 6.1% | 0.348 | +0.39 |
| 近い5町で埋める | 148.5 | 190.3 | 1.04 | 6.7% | 0.270 | +0.25 |
| 木のモデルで埋める | 150.2 | 191.5 | 1.05 | 7.0% | 0.311 | +0.33 |
| 多重代入（正規） | 150.9 | 204.7 | 1.16 | 9.5% | 0.267 | +0.27 |
| 多重代入（PMM） | 151.3 | 199.3 | 1.15 | 8.6% | 0.270 | +0.27 |

（250回の平均）

- でたらめに欠けるなら、値がある町だけで計算しても、ほぼ偏りません。
- 1つの値で埋める方法（平均・回帰1回・近い町・木）は、どれも分布を内側に縮めます。
  - 失業率5%以上の割合は、8.7%が6.0〜7.0%に縮みました（−19〜−31%）。
  - 標準偏差は 9〜17% 小さく出ます。
- 相関と回帰係数は、埋め方によって向きまで逆に動きます。
  - 平均で埋めると、0に向かって弱まりました（相関 0.19、係数 +0.16）。
  - 回帰で1回埋めると、強まりました（相関 0.35、係数 +0.39）。
- 多重代入（正規）は、平均・相関・係数には強いものの、分布の端がずれました。
  - 失業率5%以上の割合は 9.5%（+10%）、90%点は +2.5% です。
  - 正規分布から引くので、裾がもとの分布より厚くなります。ありえない値（失業率がマイナス、第3次産業が100%超）は、1組あたり平均1.4個でした（埋めた値は約1,000個）。
- 多重代入（PMM）は、6つすべてで欠かす前とほぼ同じでした。

### 95%区間の当たり（でたらめに欠ける場合）

| 方法 | 地方税の平均 | 5%以上の割合 | 相関 | 回帰係数 |
|---|---|---|---|---|
| 欠かす前 | 85% | 97% | 93% | 90% |
| 値がある町だけ | 82% | 97% | 94% | 86% |
| 平均で埋める | 54% | 0% | 8% | 72% |
| 回帰で1回埋める | 55% | 0% | 19% | 60% |
| 回帰＋ばらつきで1回 | 71% | 76% | 76% | 70% |
| 多重代入（正規） | 72% | 86% | 94% | 82% |
| 多重代入（PMM） | 81% | 98% | 91% | 84% |

- 「回帰＋ばらつきで1回」は、点推定は多重代入とほぼ同じでした。それでも、区間は 70〜76% しか当たりません。1組だけでは、埋めたことによる不確かさが SE に入らないためです。
- 欠かす前でも、地方税の平均は85%、回帰係数は90%しか当たりません。1人あたり地方税は、一部の町（発電所などがある町、推測）が極端に大きく、裾が長いためです。比べるときは、95%ではなく「欠かす前」を基準にしています。

### 人口が小さい町ほど欠ける場合（30%）

| 方法 | 地方税の平均 | 失業率のSD | 5%以上の割合 | 相関 | 回帰係数 | 係数の区間の当たり |
|---|---|---|---|---|---|---|
| 真の値 | 152.6 | 1.15 | 8.7% | 0.265 | +0.30 | — |
| 値がある町だけ | 147.4 | 1.01 | 8.4% | 0.244 | **−0.29** | 6% |
| 平均で埋める | 145.0 | 0.85 | 5.9% | 0.175 | −0.02 | 14% |
| 多重代入（正規） | 145.3 | 1.05 | 8.5% | 0.285 | −0.15 | 30% |
| 多重代入（PMM） | 145.9 | 1.04 | 8.0% | 0.291 | −0.10 | 31% |
| 人口で5つに分けて多重代入（正規） | 155.8 | 1.19 | 9.4% | 0.263 | +0.21 | 90% |
| 人口で5つに分けて多重代入（PMM） | 148.3 | 1.13 | 8.8% | 0.276 | +0.11 | 87% |

- 値がある町だけで回帰すると、第3次産業の係数は真の値（+0.30）と符号が逆の −0.29 になりました。
- 欠けるかどうかは人口だけで決まるので、教科書どおりなら多重代入で直るはずの欠け方（MAR）です。それでも、ふつうの多重代入では −0.10〜−0.15 にしか戻らず、区間の当たりは30%前後でした。
- 原因は、関係が町の大きさで違うことです。そろったデータで人口を5つに分けて同じ回帰をすると、第3次産業の係数は次のようになりました。

  | 人口の五分位 | 係数 |
  |---|---|
  | 小さい1/5 | +0.81 |
  | 2番目 | +0.60 |
  | 3番目 | −0.06 |
  | 4番目 | −0.77 |
  | 大きい1/5 | −0.48 |

  埋めるモデル（すべての町で共通の直線）は、この違いを写せません。そのため、欠けた小さい町を「大きい町のような関係」で埋めてしまいます。
- 人口で5つに分けて、グループごとに別々に多重代入すると、次のように戻りました。
  - 係数：+0.11〜+0.21（区間の当たり 87〜90%）
  - 失業率の標準偏差：1.13〜1.19（真の値 1.15）
  - 地方税の平均の当たり：15〜21% → 61〜67%
- 地方税の平均は、分けずに埋めるどの方法でも 144〜147 千円（−3〜−6%）と低めに出ました。分けて埋めても、PMM では −2.8% 残っています。小さい町の地方税は、中央値は低いのに裾が長く、その裾は値のある町から予測しにくいためです（推測）。

### 値が大きいほど欠ける場合（30%）

- どの方法でも大きく偏り、区間はほとんど当たりませんでした。
  - 失業率5%以上の割合：8.7% → 1.4〜2.4%
  - 地方税の平均：152.6 → 126〜131 千円
- 多重代入でも直りません。欠けるかどうかが値そのものに依存すると、手元のデータからはその分を取り戻せないためです。

### 埋める回数 m

母集団に1回だけ欠かしたデータ（人口が小さい町ほど欠ける、30%）を固定し、埋める乱数だけを30通り変えて、答えの揺れを測りました。

| m | 係数の揺れ ÷ SE | 相関の揺れ ÷ SE | 5%以上の割合の揺れ ÷ SE | 地方税の平均の揺れ ÷ SE |
|---|---|---|---|---|
| 2 | 0.37 | 0.49 | 0.27 | 0.11 |
| 5 | 0.24 | 0.30 | 0.22 | 0.10 |
| 10 | 0.18 | 0.21 | 0.13 | 0.09 |
| 20 | 0.15 | 0.13 | 0.11 | 0.05 |
| 50 | 0.08 | 0.11 | 0.05 | 0.04 |

- 欠測で失われた情報の割合（fmi）は、地方税の平均 0.05、5%以上の割合 0.26、係数 0.29、相関 0.41 でした（m=200 の値）。
- 揺れを SE の1割程度に抑えるには、fmi が0.3〜0.4の値では m=20〜50 が必要でした。fmi が0.05の地方税の平均は、m=5 でも十分でした。
- よく使われる m=5 では、係数と相関の点推定が、SE の4分の1ほど埋め直すたびに動きます。

## 頑健性（人口が小さい町ほど欠ける、30%、多重代入（PMM）、120回）

| 設定 | 回帰係数 | 係数の区間の当たり | 地方税の平均 |
|---|---|---|---|
| 基本（k=5、10回、m=10） | −0.10 | 31% | 145.9 |
| 近い町の数 k=1／k=10 | −0.11／−0.13 | 38%／31% | 146.8／145.7 |
| 連鎖の回数 5回／20回 | −0.11／−0.10 | 28%／31% | 146.2／146.1 |
| m=5／m=30 | −0.12／−0.09 | 37%／32% | 145.9／145.8 |
| 埋めるときに地方税を使わない | +0.06 | 55% | 146.0 |
| **人口で5つに分けて埋める** | **+0.11** | **87%** | **148.3** |
| 欠測の割合 10%／50% | +0.14／−0.26 | 79%／17% | 149.8／143.5 |
| 欠け方の強さ 0.75／3.0 | +0.05／−0.23 | 62%／7% | 148.2／142.9 |

- k・連鎖の回数・m を変えても、答えはほとんど動きませんでした。動かしたのは「埋めるモデルの形」（町の大きさで分けるかどうか）と、「欠け方の強さ・割合」です。
- 埋めるときに地方税を使わないと、係数は +0.06 と真の値に少し近づき、当たりも55%に上がりました。ただしこれは、0に向かう偏りがマイナスへの偏りと打ち消し合っただけです。よい方法だという意味ではありません（F41 と同じ）。
- 地方税を対数にせず、そのまま回帰した場合：欠かす前でも係数の区間は62%しか当たりませんでした。極端な町に引っぱられるためです。対数をとる分析モデルを基本にしました。
- 値が大きいほど欠ける場合は、欠け方を弱めても強めても、多重代入で当たりは戻りませんでした（地方税の平均の当たり 0%）。

## 言えないこと

1. これは、そろったデータから人工的に欠かした実験です。実際の統計で値がない町が、この3通りのどれに近いかはわかりません。実際の欠測の例は F41（持ち家率）を見てください。
2. 「人口で5つに分けて埋める」がうまくいったのは、関係が人口で変わることを、あらかじめ欠かさない人口で拾えたからです。欠け方や関係を決める変数が手元にないときは、同じことはできません。
3. 値そのもので欠ける場合（MNAR）は、どの埋め方でも直りませんでした。この場合は、欠け方を仮定した感度分析が必要です。この記事では扱っていません。
4. 8通りの方法は、それぞれ1つの設定だけです。近い町の数や木の深さを調べ尽くしたわけではありません。
5. 標本は、母集団からの復元抽出です。実際の調査のような層別・集落抽出の効果は入っていません。
6. 欠かす3列は、同じ町で同時に欠ける相関を入れず、列ごとに独立に欠かしました。
7. 回帰係数は1時点の地域の比較です。第3次産業の割合が地方税を決めるという因果は言えません。特定の市区町村の評価もしていません。

## 動かし方

```
pip install -r requirements.txt
cd src
python 01_取得.py     # data/raw/SSDSE-A-2026.csv があることを確かめる（同梱）
python 02_整形.py     # → data/muni.csv
python 03_分析.py     # → results/（2コアで約35分。--quick で短縮版）
python 04_図.py       # → figures/
```

乱数の種は `common.py` の SEED（20261104）です。くり返しごとの種は (種類, 回) から決まるので、並列の順番によらず同じ結果になります。
