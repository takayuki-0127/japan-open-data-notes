# 01 取得

コンテナからは各サイトに直接つながらないため、Chrome のページ内で fetch して JSON を保存しました（取得日 2026-11-03）。

| ファイル | 取得元 | 内容 |
|---|---|---|
| `data/raw/comtrade_jpn_exports.json` | UN Comtrade 公開プレビュー API `https://comtradeapi.un.org/public/v1/preview/C/A/HS?reporterCode=392&period=<年>&flowCode=X&cmdCode=<品目>` | 日本（報告国 392）の相手国別 輸出額（米ドル、年次）。品目は TOTAL と HS 2桁の 27・29・39・72・84・85・87・90 類、2000〜2024年。`D` は「年_品目」→[相手国コード, 金額]、`P` は相手国コードの対応表（`/files/v1/app/reference/partnerAreas.json`） |
| `data/raw/imf_weo_ngdpd.json` | IMF DataMapper API `https://www.imf.org/external/datamapper/api/v1/NGDPD` | 名目 GDP（十億米ドル、WEO） |
| `data/raw/wb_gdp_pop_capital.json` | 世界銀行 API `https://api.worldbank.org/v2/country?format=json` と `/v2/country/all/indicator/{NY.GDP.MKTP.CD, SP.POP.TOTL, NY.GDP.PCAP.CD}` | 国の一覧（地域、首都の緯度経度）、GDP、人口 |

- 日本が UN Comtrade に報告している輸出額は、財務省「貿易統計」をもとにした値です。円建ての公表値とは通貨が違います。
- 公開プレビュー API は呼び出し回数に上限があり、上限に達したときは待ってから取り直しました。
- 相手国コード 490（Other Asia, nes）は台湾として扱いました。台湾の首都の座標（台北）は世界銀行の一覧にないので手で入れています。
