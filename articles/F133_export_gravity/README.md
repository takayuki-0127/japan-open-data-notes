# F133 輸出先は、距離と経済規模でどこまで決まるのか？（重力モデル・PPML）

看板記事 F133。日本の相手国別の輸出額（財務省「貿易統計」を UN Comtrade 経由の米ドル建てで取得、194か国×2000〜2024年）に、IMF の GDP と東京からの距離を組み合わせ、貿易の重力モデルを PPML（ポアソン疑似最尤法）で推定しました。

## 問い
- 日本の輸出先の違いは、相手国の経済規模（GDP）と距離で、どこまで説明できるのか
- 距離が2倍になると、輸出はどれだけ減るのか。その効き方は25年で変わったのか
- 品目によって、距離の効き方は違うのか
- 経済規模と距離から見込むより多く・少なく輸出している国はどこか

## データ
| データ | 期間 | 出所 | 使い方 |
|---|---|---|---|
| 相手国別 輸出額（総額、HS 2桁の8品目） | 2000〜2024年 | 財務省「貿易統計」（UN Comtrade に日本が報告した値、米ドル） | 被説明変数。GDP のある194か国×25年の格子に並べ、輸出がない組はゼロとした |
| 名目 GDP | 2000〜2024年 | IMF「World Economic Outlook」（DataMapper の NGDPD） | 経済規模 |
| 名目 GDP、人口、首都の緯度経度 | 2000〜2024年 | 世界銀行 World Development Indicators・国の一覧 | 頑健性（GDP の別系列、1人あたり GDP）、距離 |
| EPA の発効年 | — | 外務省の EPA/FTA 一覧を作成者が整理 | 補助の説明変数（7月以降の発効は翌年から1） |

距離は、東京と相手国の首都の大円距離（km）です。194か国でカバーした輸出額は、各年の対世界の輸出総額の 99.5〜99.9% でした（`data/world_total.csv`）。取得の手順は `src/01_取得.md` にあります。

## 手法
相手国 j・年 t の輸出額 X_jt について、次の重力モデルを推定しました。

X_jt = exp( a_t + b1·ln GDP_jt + b2·ln 距離_j + b3·内陸国_j + b4·EPA_jt ) × 誤差

1. **基本（M1）**：年の固定効果つきの PPML。標準誤差は国でクラスター。ゼロの輸出も含めて推定できるのが PPML の利点
2. **説明力**：予測値と実績の相関の2乗（水準）と、輸出が正の組での対数の相関の2乗。GDP だけ・距離だけ・両方で比べた
3. **国と年の固定効果（M3）**：設計どおり国の固定効果を入れると、距離（国ごとに一定）は固定効果に吸収されて推定できない。そこで M3 では、同じ国の中での GDP の伸びと EPA の効果だけを見た
4. **年ごとの断面**：年ごとに PPML を当て、距離の弾力性の推移を見た
5. **品目別**：HS 2桁の8品目それぞれに M1 を当てた
6. **実績 ÷ 予測**：M1 の予測と実績を、2015〜2024年の合計で比べた

## 結果
- **経済規模と距離で、輸出額の差の7〜8割は説明できた。**
  - M1 の説明力は、水準で 0.76、対数で 0.77。
  - GDP だけでも水準で 0.76、対数で 0.69。距離を加えると、対数で 0.73 に上がる（水準ではほとんど変わらない）。距離だけでは水準で 0.20、対数で 0.11。
  - 2024年は上位10か国で輸出の 70% を占める。水準の説明力は、大きな相手国でほぼ決まる。
- **距離の弾力性は −0.87（95%区間 −1.23〜−0.51）。** 距離が2倍になると、輸出は約45%少ない。GDP の弾力性は 0.80（0.59〜1.01）、内陸国は −1.04（約65%少ない）。
- **距離の効き方は、25年でほとんど変わっていない。** 年ごとの距離の弾力性は、2000〜2004年の平均 −0.87、2020〜2024年の平均 −0.88。2009〜2010年に −1.03 前後と強まり、2019年に −0.72 まで弱まったあと、コロナの2020・2021年に −1.08・−1.11 と強まり、2022年以降は −0.7〜−0.8 に戻った。
- **品目で、距離の効き方は大きく違う。**
  - 鉄鋼（72類）−1.70、プラスチック（39類）−1.54、鉱物性燃料（27類）−1.39、有機化学品（29類）−1.36 は、距離で大きく減る。
  - 機械（84類）−0.83、光学・精密機器（90類）−1.03 は、総額と同じくらい。
  - 自動車・部品（87類）は +0.14（−0.18〜+0.46）で、距離ではほとんど減らない。2024年の自動車の輸出先の1位は米国（503億ドル）。
- **見込みより多い国・少ない国（2015〜2024年の合計、実績 ÷ 予測）。**
  - 多い：香港 5.23、タイ 3.16、台湾 3.15、シンガポール 2.93、アラブ首長国連邦 2.64、マレーシア 2.15、ベトナム 1.96、米国 1.86。東南アジアの国が多く、日本企業の生産拠点やサプライチェーンの影響と考えられる（推測）。
  - 少ない：インド 0.38、イタリア 0.39、フランス 0.41、ロシア 0.54、中国 0.67、英国 0.70。
  - 上位25か国の外では、パナマが 10.9 と特に大きい。船舶の輸出（便宜置籍）によるものとみられる（推測）。
- **EPA の効果は、国の中の変化では見えない。** M1 では EPA の係数が 0.51（0.02〜1.00）だが、これは EPA を結んだ国がもともと日本との貿易が多い国だったことも含む。国と年の固定効果を入れた M3 では 0.05（−0.03〜+0.14）で、0と区別できない。M3 での GDP の弾力性（同じ国の中での伸び）は 0.56（0.42〜0.70）。

## 頑健性
距離と GDP の弾力性を、条件を変えて推定し直しました（`results/robustness.csv`）。

| 条件 | 距離の弾力性 | 95%区間 | GDP の弾力性 |
|---|---|---|---|
| 基本：PPML（ゼロを含む、2000〜2024年） | −0.87 | −1.23〜−0.51 | 0.80 |
| PPML（ゼロを除く） | −0.87 | −1.23〜−0.51 | 0.80 |
| 対数の OLS（ゼロを除く） | −1.33 | −1.71〜−0.96 | 0.88 |
| 対数の OLS（ln(1+百万ドル)、ゼロを含む） | −1.39 | −1.77〜−1.02 | 0.85 |
| 期間 2000〜2009年 | −0.93 | −1.22〜−0.64 | 0.86 |
| 期間 2010〜2019年 | −0.87 | −1.28〜−0.46 | 0.81 |
| 期間 2020〜2024年 | −0.80 | −1.21〜−0.39 | 0.75 |
| 輸出額の上位50か国に絞る | −0.80 | −1.16〜−0.44 | 0.69 |
| GDP を世界銀行の値にする | −0.81 | −1.13〜−0.49 | 0.83 |
| 米国と中国を除く | −1.18 | −1.53〜−0.83 | 0.63 |
| 1人あたり GDP を加える | −0.92 | −1.22〜−0.61 | 0.79 |
| 地域の固定効果を加える | −0.45 | −0.76〜−0.13 | 0.67 |
| EPA の変数を除く | −0.84 | −1.20〜−0.49 | 0.79 |

- **ゼロの扱い**：輸出がゼロの組は 2.4% と少なく、PPML ではゼロを含めても除いても同じ。一方、対数の OLS では距離の弾力性が −1.3〜−1.4 と大きくなった。対数をとる推定は、ばらつきの大きさが規模で変わると偏ることが知られており（Santos Silva & Tenreyro 2006）、PPML を基本にした。
- **地域の固定効果を加えると −0.45 に弱まる**。「アジアかどうか」と距離が強く重なっているためで、距離の効果の一部は地域の違いとしても読める。
- **米国と中国を除くと −1.18 に強まる**。遠くて大きい米国への輸出が多いことが、距離の効果を弱めて見せている。
- どの条件でも、距離は輸出を減らし、GDP は増やす向きは同じだった。

## 言えないこと
- 輸出国が日本だけなので、相手国の「貿易のしやすさ全般」（多角的抵抗項）を国の固定効果で取り除くと、距離が推定できません。ここでの距離の弾力性は、年の固定効果だけのモデルによるもので、距離と重なる相手国の特徴（地域・言語・制度など）も含みます。地域の固定効果を入れると、効果は半分ほどになりました。
- 距離は首都間の直線距離です。海上輸送の経路や港までの距離、輸送費そのものは使っていません。
- 金額は米ドル建てなので、為替の動きが年ごとの値に入ります（年の固定効果で全体の動きは取り除いていますが、国ごとの違いは残ります）。
- 輸出の最終的な行き先ではなく、統計上の仕向け国です。香港やシンガポールなど中継地への輸出は、その先の国への輸出を含みます。
- EPA の係数は、どの国と EPA を結ぶかが貿易の多さで決まる面があるため、因果の効果とは言えません。国の中の変化で見ると、効果ははっきりしませんでした。
- 「見込みより多い・少ない」は、このモデルの変数で説明できない部分です。国ごとの良し悪しを示すものではありません。
