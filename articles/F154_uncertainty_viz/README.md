# F154 推定の「不確かさ」を図でどう見せるとよいか？ 区間・ファン図・ドットプロット・HOP と読み違いの例

看板記事 F154。note の記事は下書きのみです。

## 問い

予測や推定には幅（不確かさ）がある。これまでの記事では、95%区間やファン図でその幅を示してきた。では同じ不確かさでも、図の形が変わると、読む人が取り出せる情報はどう変わるのか。どんな読み違いが起きやすいのか。これまでの記事の推定を3つ選んで、数で確かめた。

## データ（これまでの記事の推定を使い回す）

| 例 | 中身 | 元の記事 |
|---|---|---|
| ① 出生数 2026〜2030年 | ベイズ構造時系列（BSTS）の予測。4,000本のシミュレーション（年の出生数の道筋）。2010〜19年で学習して2020〜25年を予測した4,000本（月→年に足し上げ）も頑健性に使う | F55（厚生労働省「人口動態統計」2025年確定数 上巻 出生 第4.2表） |
| ② 平均寿命 2025〜2070年（女・男） | Lee–Carter（1970〜2024年で当てはめ、2段目あり、出発点は2024年の実際の死亡率、ドリフトの誤差を入れたランダムウォーク）。F86 と同じ手順・同じ乱数の種でやり直した5,000本。2045・2070年の中央値と2.5%点は F86 の表と小数3桁まで一致 | F86（国立社会保障・人口問題研究所「日本版死亡データベース」） |

## 手法

**A. 確率を図から読む**：「X年に〇〇を下回る確率は？」という問い（出生数は2.5万人きざみ、平均寿命は1年きざみのしきい値。正解の確率が2〜98%の問いだけ。① 44問、② 女186問・男176問）を、図の形ごとの読み方で答え、シミュレーションから数えた正解とのずれ（%ポイントの絶対値の平均）を比べた。

| 図の形 | 読み方（仮定） |
|---|---|
| 点だけ（中央値） | 中央値がしきい値より下なら「下回る（100%）」、上なら「下回らない（0%）」 |
| 95%区間（エラーバー） | 区間を正規分布の±1.96σとみなす（頑健性：区間の中は一様で外に2.5%ずつ／区間の外はないとみなす） |
| ファン図（2.5・10・25・50・75・90・97.5%の境目） | 境目のあいだを直線でつなぐ |
| 分位点ドットプロット（20点） | 1点5%として、しきい値より下の点を数える |
| HOP（Hypothetical Outcome Plots） | 1コマに1本の道筋を順に見せるアニメ。k コマ見て、下回ったコマの割合を答える（1,000回くり返した平均） |

**B. 2つの年の比較**：「2050年は2045年より長いか」の確率を、道筋から数えた正解と、年ごとの95%区間だけから2つの年を独立とみなして読んだ値とで比べた。

**C. 帯と道筋**：各年の95%（80%）の帯に、最初から最後までおさまる道筋の割合。あわせて、5年の合計の区間と、年ごとの区間の端を足したものを比べた。

**D. 「1日ごとの95%」と1か月**：95%上限を実績が超えた日を月ごとに数え、外れが日ごとに独立だったときの分布（二項分布）と比べた。

## 結果

### A. 確率を図から読む

| 図の形 | 出生数 2026〜30年 | 平均寿命・女 | 平均寿命・男 | 出生数 2020〜25年 |
|---|---|---|---|---|
| 点だけ | 20.4 | 18.7 | 18.6 | 18.4 |
| 95%区間（一様とみなす） | 12.3 | 6.6 | 6.4 | 8.7 |
| 95%区間（正規とみなす） | 2.5 | 0.7 | 0.8 | 2.1 |
| HOP 20コマ | 6.5 | 6.2 | 6.1 | 6.2 |
| HOP 100コマ | 2.9 | 2.8 | 2.7 | 2.7 |
| ドット 20点 | 1.3 | 1.3 | 1.4 | 1.3 |
| ファン図 | 0.7 | 0.6 | 0.6 | 0.9 |

（確率の読みのずれ、平均・%ポイント）

- 例：「出生数が2030年に60万人を下回る確率」の正解は 59.6%。点だけ（中央値57.8万人）では「下回る」としか読めない。95%区間（42.2万〜87.1万人）を正規とみなすと 57.7%、ファン図 58.6%、ドット20点 60%。
- 区間を正規とみなす読み方は、平均寿命（左右がほぼ対称）ではよく合ったが、出生数（上に長い分布）では2ポイントほどずれた。区間の中を一様とみなすと6〜12ポイントずれた。
- HOP は20コマでは平均6ポイントずれる。60万人の問いで正解の±5ポイント以内に入るのは、20コマで34%、100コマで65%、200コマで84%。

### B. 2つの年の比較

| 比較 | 道筋から数えた確率 | 年ごとの区間から（独立とみなして）読んだ確率 |
|---|---|---|
| 平均寿命・女：2050年 > 2045年 | 97% | 70% |
| 平均寿命・女：2046年 > 2045年 | 82% | 55% |
| 平均寿命・女：2060年 > 2050年 | 99% | 82% |
| 出生数：2028年 < 2027年 | 76% | 60% |
| 出生数：2030年 < 2029年 | 75% | 56% |

- 平均寿命の5年おきの比較41組は、どれも95%区間が重なっていたのに、41組すべてで「後の年のほうが長い」確率が95%以上だった（平均97%、区間から読むと平均73%）。となり合う年どうしや出生数でも、区間から読んだ確率は正解より16〜26ポイント低かった。
- 理由は、道筋が年をまたいで強く結びついていること（平均寿命の2045年と2050年の相関 0.93）。年ごとの区間には、この結びつきが描かれていない。

### C. 帯と道筋

- 各年の95%の帯に、全期間おさまる道筋：出生数（5年）88%、平均寿命・女（10年）81%、（46年）72%。80%の帯では、平均寿命・女の46年で28%。
- 「95%の帯の下の端を通る未来」は、1年ごとの下側2.5%を並べたもので、1本の道筋ではない。
- 5年の合計の95%区間（263.8万〜389.3万人）と、年ごとの区間の端を足したもの（259.5万〜393.0万人）の差は6%ほどで、小さかった。年どうしの相関が強いため。

### D. 「1日ごとの95%」と1か月

- 95%上限を超えた日は全体で5.0%で、狙いどおりだった。
- しかし月ごとに見ると、超えた日が1日もない月は49%（外れが独立なら21%）。3日以上超えた月は28%（独立なら19%）で、最も多い月は11日（2021年1月）だった。
- 超えた日の翌日も超える確率は17.6%で、全体の5%の3.5倍。外れは寒波や猛暑の時期にまとまって起きる。超えた割合は冬9.6%・夏7.3%・その他1.7%。

## 頑健性

| 確かめたこと | 結果 |
|---|---|
| 区間の読み方（正規・一様・外なし） | どの例・どのしきい値でも「正規とみなす」がいちばん合い（0.4〜2.6ポイント）、一様とみなす2通りは3〜13ポイントずれる |
| 点・コマの数（基本のしきい値） | ドット10点 2.6〜2.9、50点 0.5、100点 0.2〜0.3。HOP 10コマ 8.7〜9.3、50コマ 3.9〜4.1、100コマ 2.7〜2.9（ポイント）。点・コマが増えるほど合うが、HOP は100コマでもドット20点に届かない |
| しきい値の選び方 | 確率10〜90%の問いだけ、しきい値を分位点5〜95%から無作為に選ぶ（各年20個）、のどちらでも、ファン図（0.3〜0.9）とドット20点（0.7〜1.3）は1ポイント前後、区間（正規）は平均寿命で0.4〜0.7・出生数で2.0〜2.6、HOP 20コマは3〜8、点だけは9〜28ポイントで、大きな並びは変わらない |
| 例を変える | 平均寿命・男、出生数（2019年までで2020〜25年を予測）でも同じ |
| 比べる年の組 | 平均寿命のとなり合う年45組：正解平均81〜82%、区間から55〜56%。5年おき41組：正解97〜98%、区間から73〜74% |
| 電力の予測方法・水準 | 線形の分位点回帰、LightGBM の分位点、90%・99%でも、翌日も超える確率は全体の割合より高い（95%で 0.15〜0.22、90%で 0.23〜0.28）。ただし分位点回帰と LightGBM は超える割合そのものが狙いより多い（95%で6.6%・8.1%） |

## 言えないこと

- 実際の読者に図を見せた実験ではない。「この図ならこう読む」という読み方を仮定し、その読み方で取り出せる数とずれを計算した。人が実際にどう読むかは、読み方の仮定によって変わる。
- 「正解」は各モデルのシミュレーションで、モデルの外れ（F55・F86 のバックテストで、区間は過去の当たり方より狭かった）は含まない。図を工夫しても、モデルの不確かさの過小評価は直らない。
- HOP の評価は「k コマを正確に数える」読み方で、アニメの速さや記憶の負担は入っていない。note では GIF（20コマ）でしか見せられない。
- 例は3つの記事（出生数・平均寿命・電力）に限られる。分布の形が違う推定（たとえば0付近に固まる割合）では、区間の読み方のずれは変わりうる。

## 再現手順

```
pip install -r requirements.txt
python src/01_取得.py      # F55・F86・F92 のフォルダから取得
python src/02_整形.py      # 平均寿命のシミュレーションをやり直し、data/samples.npz を作る（1分ほど）
python src/03_分析.py      # A〜D
python src/03b_頑健性.py   # 頑健性（10分ほど）
python src/04_図.py        # 図（fig2_hop.gif はアニメ）
```

乱数の種は42（平均寿命は F86 と同じ。しきい値を無作為に選ぶ頑健性だけ43）。
