# 993 延べの来場者と実際の人数は、どれだけ違うのか？（来場者と集客）

施設の「年間来場者数」は、ふつう入った回数を足した延べの数です。同じ人が3回来れば3と数えます。実際に来た人の数（実人数）は、それより少なくなります。どれだけ少ないかは、同じ人が何回来るかの偏りと、数える期間の長さで決まります。**ここでは、作成者が乱数で作った架空の科学館の1年（来る可能性のある人20万人、人ごとの来やすさを作成者が置いたもの）で、延べと実人数を、数える期間（1日・1か月・3か月・1年）ごとに比べ、月ごとの実人数を12か月足すと年の実人数の何倍になるか、延べが同じでも実人数が置き方でどれだけ変わるかを数えました。**

科学館・来場者はすべて架空のもので、実在の施設の数字は使っていません。

|---|---|---|---|
| A993 | 延べの来場者と実人数はどれだけ違うか。数える期間でどう変わるか。月ごとの実人数を足すと何が起きるか | 架空の科学館の1年。1か月を30日、1年を360日と置いた。来る可能性のある人を20万人置き、人ごとの1年に来る回数の平均（来やすさ）をガンマ分布で置いた（平均0.5回、形 k=0.5。k が小さいほど一部の人に回数が偏る）。延べの見込みは10万回。人ごとの実際の回数は、来やすさを平均にしたポアソン分布で引き、来る日は360日からでたらめに選んだ（同じ人の同じ日は1回に数える）。**延べ**＝人×日の数、**実人数**＝期間の中で1回以上来た人の数。期間（1日・30日・90日・360日）ごとに、1期間あたりの延べ÷実人数と、期間ごとの実人数を1年分足したもの÷年の実人数を出した。20万人を作り直して20回の平均。1年の実人数は式 20万×(1−(k/(k+平均))^k) とも比べた。確かめとして、延べの見込みを10万回にそろえたまま、k（0.2・0.5・1・2・5）×来る可能性のある人と平均（10万人×1回・20万人×0.5回・40万人×0.25回）の15通り（各5回）。seed 993 | `src/a993_total_vs_unique.py` |

## 主な結果

### 基本の置き方（20万人・平均0.5回・k=0.5、20回の平均、`results/a993_main.json`）
| 数える期間 | 1期間あたりの 延べ÷実人数 | 期間ごとの実人数を1年分足したもの÷年の実人数 |
|---|---|---|
| 1日 | 1.0 | 1.704 |
| 1か月 | 1.06 | **1.608** |
| 3か月 | 1.182 | 1.442 |
| 1年 | **1.704** | 1.0 |

- 1年の延べは99,817.4回、実人数は58,569.05人（約5.86万人）。延べは実人数の1.704倍で、これは来た人1人あたりの回数（1.704回）と同じ
- 1年の実人数は、置いた来やすさからの式の値（58,578.644人）と0.016%しか違わなかった（式どおり）。20回の振れは58,125〜59,016人
- 1か月で数えると、延べ（月あたり約8,318回）と実人数（約7,847人）は1.06倍しか違わない。それでも、月ごとの実人数を12か月足すと、年の実人数の**1.608倍**になった。月をまたいで来た人を、月ごとに別の人として数えるため
- 1日で数えると、同じ日の2回目を数えない置き方なので延べと実人数は同じ（1.0）。日ごとの実人数を1年分足したものは延べそのもの（1.704倍）

### 何回来た人が延べを作っているか（1回分、`results/visits_distribution_rep0.csv`）
- 1年に1回だけ来た人は、実人数の60.726%、延べの35.664%（20回の平均では実人数の60.41%、延べの35.447%）
- 回数の多い上位10%の人で、延べの25.749%（20回の平均）

### 確かめ：延べの見込みを10万回にそろえた15通り（各5回、`results/sensitivity_grid.csv`）
| | 15通りの幅 |
|---|---|
| 1年の延べ | 99,234.8〜100,160.8回 |
| 1年の実人数 | **30,079.4〜86,590.6人**（3.01万〜8.66万人） |
| 1年の 延べ÷実人数 | 1.154〜3.301 |
| 月ごとの実人数の12か月の合計÷年の実人数 | 1.14〜2.685 |
| 1か月の 延べ÷実人数 | 1.012〜1.229 |
| 1回だけ来た人の割合 | 38.69〜86.245% |

- 延べはどれも約10万回でも、実人数は3.01万〜8.66万人と3倍近く違った。来る可能性のある人が多く1人あたりの回数が少ないほど、また回数の偏りが小さい（k が大きい）ほど、実人数は延べに近づく
- 20万人・平均0.5回のままでも、k を0.2から5に変えると、1年の実人数は44,281人から75,955人まで動いた
- 月ごとの実人数を12か月足すと年の実人数を上回るのは15通りすべてで同じ（1.14〜2.685倍）。どれだけ上回るかは置き方で大きく動いた
- 15通りの1年の実人数は、式の値と−0.362〜0.211%の差だった

## 注意（言えないこと）
- 架空のデータです。来る可能性のある人の数、来やすさの分布（平均と偏り）は作成者が置いたもので、延べと実人数の比はこれで決まります。実在の施設の来場者の分布を表すものではありません
- 実際の施設で実人数を数えるには、同じ人を見分ける仕組み（会員証・年間パスなど）が要ります。ここでは作成者が全員を見分けられる形で数えました
- 曜日や季節で来やすさが変わること、同じ人が同じ日に2回入ることは入れていません（再入場は 994 で扱っています）
- 関連する記事：965 は同じ文の重複を除かないと件数がどうずれるかを、950 は商圏を半径で決めると重なりをどう数え落とすかを扱っています。同じ企画の 994 は入口のゲートとチケットで人数がどう変わるかを、995 は前年比の伸びを新しい人と来る回数に分けられるかを、998 は館の中のアンケートの「初めて」の割合が延べの来場の割合になることを、1002 はエリアごとの人数を足すと同じ人を何度も数えることを扱っています
