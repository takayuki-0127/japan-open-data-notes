# F464 事前の計画（PLAN）

作成：2026-11-18（JST）。PDF の表の抜き出し（01b_extract.py）と、全国の行と47都道府県の合計の一致の点検のあと、地方別・頑健性・問い直しの集計の前に書いた。

## 問い
荒れた農地は、「再生できない」ほうが増えているのか？

## 知りたい人
農地・地域づくり・農業の支援にかかわる人。荒廃農地（耕作をやめて荒れ、ふつうの農作業では作物が作れない農地）は、全国で26〜28万haほどで大きくは動いていないと言われる。一方で、中身は「再生利用が可能（A分類）」から「再生利用が困難（B分類。森林のようになっているなど）」に移っているとも言われる。農水省は「荒廃農地の現状と対策」などで、A・B の面積の推移を示している。全体の面積が横ばいでも、B が増えているのか、どの地方で増えたのかを、公表された都道府県別の表で確かめる。

## データ
- 農林水産省「荒廃農地の発生・解消状況に関する調査」の各年の公表資料（PDF）の資料2「都道府県別の荒廃農地面積」（2011〜2020年は暦年、2021〜2024年度）
  - 荒廃農地の面積計、A分類、B分類、再生利用された面積（2013年からは農用地区域内の内数も）、2021年度からは新たに発生した面積
  - 都道府県別の表は実績値。全国の見出しの値（2015年までは推計値）とは少し違う
- 2021年度の調査から、調査の一本化と調査内容の見直し、非農地判断（農地でないと判断して台帳から外すこと）の徹底、ドローンなどによる調査精度の向上があり、農水省は「特にB分類が減少したため、前年度までとの単純比較はできない」と注記している。2020年と2021年度の間は「切れ目」として扱う

### 抜き出しの点検で見たもの（下見）
- 抜き出しの確かめのとき、全国の行を年ごとに見た：面積計 2011年 25.1万ha、2015年 28.3万、2020年 28.2万、2021年度 25.9万、2024年度 25.7万。A は 2011年 13.8万 → 2020年 9.0万 → 2024年度 9.8万。B は 2011年 11.4万 → 2020年 19.2万 → 2021年度 16.9万 → 2024年度 15.9万
- 全国の B の割合は、この値から暗算で 2011年 45%ほど、2020年 68%ほど、2024年度 62%ほどと見えている
- 2024年度と2018年の都道府県別の表は、PDF の読み取りを確かめるときに全体を目で見た（地方別の集計はしていない）。2021年度・2024年度の全国の「新たに発生した面積」（3.0万・2.4万ha）と「再生された面積」（1.3万・0.8万ha）も見た
- 地方別、農用地区域内、都道府県の中央値、問い直しの集計はまだしていない。H1・H2 は見えた値の確かめ。H3・H4 は集計していない値についての仮説（H4 は2024年度の県の表を目で見ているので、半分は見えている）

## 仮説（外れの基準つき）
- H1：全国の B の割合（B ÷ 面積計）は、2011年から2020年に15ポイント以上上がった。外れ：上がり方が15ポイント未満。（確かめ）
- H2：2021年度から2024年度に、B の面積は減った。外れ：同じか増えた。（確かめ）
- H3：10の農業地域（北海道・東北・北陸・関東東山・東海・近畿・中国・四国・九州・沖縄）のうち8以上で、B の割合が2013年から2020年に上がった。外れ：7以下。
- H4：2024年度の B の割合は、中国・四国・九州の3地方のすべてで全国より高い。外れ：3地方のうち1つでも全国以下。

## 手法
- 全国の面積計・A・B と B の割合の推移（2011〜2024年度。2020年と2021年度の間に切れ目の線を入れる）
- 地方別の B の割合（2013年・2020年・2021年度・2024年度）。図は北から南の地方の順。悪い順には並べない
- 都道府県別の B の割合の変化は、都道府県コード順（北から南）の図にする
- 2021年度からの「新たに発生した面積」「再生された面積」と、面積計の変化をくらべる

## 頑健性（3つ以上）
1. 農用地区域内（農業振興地域の中で農業に使うと決めた区域）だけで B の割合を見る（2013年から）
2. 始まりの年を2013年にする（2011・2012年は農用地区域の内数がなく、調査の年の区切りも違う）
3. 2015→2016年に A が大きく減って B が増えている（下見で見えた）。この1年を除いた2016→2020年だけでも B の割合が上がったかを見る
4. 全国の合計ではなく、都道府県の B の割合の中央値で見る
5. 2021年度からの B の減少が、一部の県だけで起きたのかを、県別の増減の数で見る

## 言えないこと（予想）
- B の増加が「荒れが進んだ」からか「判定のしかたが変わった」からかは、この表だけでは分けられない
- 2021年度の切れ目の前後はくらべられない（農水省の注記）
- B から非農地判断で外れた面積（台帳から消えた面積）は、この表にはない
- 荒廃農地にあたらない「耕作していないが荒れていない農地」はこの調査の外
