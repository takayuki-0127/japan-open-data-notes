# 289 婚姻届が多い月は、変わったのか

厚生労働省「人口動態統計」確定数（2025年＝令和7年）上巻 9-3「届出月別にみた年次別婚姻件数及び百分率」を使ったフォルダです（1947〜1995年は5年ごと、2000年以降は毎年）。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A289 | 婚姻届の多い月は、変わったのか | 月ごとの件数を月の日数で割った「1日あたりの件数」を、その年の平均＝100の指数にして期間ごとに平均。月の偏りの大きさ（指数の標準偏差）を年ごとに計算。2000年以降は、同じ月の前後3年の割合の中央値からのずれで「ふだんより多い月」を探した | `src/a289_marriage_month.py` |

## 主な結果
- 1965・70・75年の平均では、婚姻届が多い月は4月（指数142）・5月（140）・11月（138）、少ない月は8月（42）でした。春と秋に山、真夏に谷という形です。
- 2021〜2025年では、多い月は3月（138）・11月（131）・2月（109）。4月は75に下がり、8月は103で平均を上回りました。2014〜2018年も上位3つは3月・11月・2月で、この10年ほどは同じ形です。
- 1965〜75年と2021〜25年の月の順位の相関は0.12で、月の並びはほぼ入れ替わっています。2003〜07年と2021〜25年の形の相関は0.64でした。
- 月の偏りの大きさ（指数の標準偏差）は1975・80年の約38が最大で、2000年代は12〜17に下がりました。2021〜2025年は21〜22とやや大きくなっています。2019・2020年は30を超えました。
- 前後の年と比べて特に多かったのは2019年5月（割合15.3%、前後3年の中央値8.1%、約4.3万件多い）と2020年2月（13.9%、約2.8万件多い）です。2025年7月（約1.4万件）、2023年8月、2022年1月、2000年1月、2001年1月、2010年10月、2019年11月、2020年11月が続きます。

## 頑健性
- 1日あたりにならさず月の件数の割合で比べても、1965〜75年と2021〜25年の順位の相関は0.17で、結論は同じ
- 2019・2020年を除いた2014〜2025年の偏りの大きさの平均は18.2で、2000年代より少し大きい
- 「ふだんより多い月」の基準を前後3年の中央値から平均に変えても、上位2つ（2019年5月・2020年2月）は変わらない（`results/a289_month_anomaly.csv` に全月のずれ）
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致した

## 動かし方
```
pip install -r requirements.txt
cd src && python a289_marriage_month.py
```

## データ
- `data/jinkou_r7_jokan_9-3_marriage_by_month.csv`：e-Stat「人口動態調査 人口動態統計 確定数 婚姻」上巻 9-3（2025年、2026-09-30公表、statInfId=000040503695）を2026-11-12に取得したもの（cp932）

## 注意
- この表は「届出月」（婚姻届を出した月）で、結婚式を挙げた月や一緒に暮らし始めた月ではありません
- 特に多い月の理由（改元、日付の並びなど）は月の件数からは分かりません。日ごとの件数がないので、どの日に集まったかは確かめていません（記事では理由の見方に（推測）と付けています）
- 1995年までは5年ごとの値なので、その間の年の動きは分かりません
- 2004・2006・2009〜2017年は報告漏れの再集計のあとの値です（表の注）
