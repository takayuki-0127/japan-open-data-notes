# 208 飲む牛乳の生産は減り、何が増えたのか：牛乳乳製品統計調査

農林水産省「牛乳乳製品統計調査」の累年統計（全国・年計、1985〜2024年）で、牛乳等5品目（牛乳・加工乳・成分調整牛乳・乳飲料・はっ酵乳・乳酸菌飲料）の生産量と構成比、生乳の用途別処理量の推移を見たフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A208 | 飲む牛乳の生産は減り、何が増えたのか | 牛乳等5品目の生産量（kl）と5品目合計に占める割合の推移、10年ごとの増減、生乳の用途別処理量（牛乳等向け・乳製品向け）の割合 | `src/a208_milk.py` |

## 主な結果
- 牛乳の生産量は1994年の433.5万klが最大で、2024年は307.3万kl（−29.1%）。2005→2015年の10年で81.7万kl減った
- はっ酵乳（ヨーグルトなど）は1985年の18.8万klから2020年の117.5万klまで増え、2024年は102.4万kl（1985年の5.5倍）。牛乳に対する比は5.1%から33.3%に
- 乳飲料は2013年の136.7万klが最大で、2024年は101.8万kl
- 5品目合計に占める牛乳の割合は68.1%（1985年）→50.2%（2013年）→55.0%（2024年）。はっ酵乳と乳飲料を合わせた割合は16.9%→36.6%
- 生乳生産量は1996年の865.7万tが最大で、2024年は735.7万t（−15.0%）。牛乳等向けの処理量は1996年の518.6万tから382.3万tに減り、乳製品向け（348.7万t）との差は184万tから34万tに縮んだ
- 2015→2024年は牛乳が+6.8万klと下げ止まり、乳飲料（−28.8万kl）、はっ酵乳（−3.0万kl）が減った

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a208_milk.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/milk_annual_1985_2024.csv | 年ごとの牛乳等5品目の生産量（kl）、生乳の用途別処理量（牛乳等向け・乳製品向け・その他、t）、生乳生産量（t） |

- e-Stat の牛乳乳製品統計調査「長期累年」の表（1 生乳生産量、3 生乳処理量（用途別）、4 牛乳等生産量）の年計の列をブラウザで読み、書き写した
- 用途別処理量の合計は、各年とも生乳生産量に一致することを確かめた

## 注意
- 生産量は国内の工場の生産で、輸入品や消費量そのものではない
- 2009年に牛乳が減り、加工乳・成分調整牛乳が増えている。品目の区分の扱いが変わった可能性があり、この年の前後の比較は品目別より合計で見るほうがよい
- 品目ごとの単位はkl（容量）で、はっ酵乳には固形のヨーグルトも含まれる
- 増減の理由（健康志向、価格、人口構成など）は、このデータでは分けられない
