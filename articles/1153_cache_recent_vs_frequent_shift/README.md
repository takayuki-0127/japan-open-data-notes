# 1153 古く使われたものから捨てる決まりと、使われた回数の少ないものから捨てる決まりは、人気が移り変わるときにどちらが当たるのか？（キャッシュの当たり率）

よく使うデータを手元に置いておく置き場所（キャッシュ）は、いっぱいになると何かを捨てなければなりません。よく使われる決まりは2つあります。1つは「最後に使われてからいちばん長くたったものを捨てる」（古い順）、もう1つは「使われた回数がいちばん少ないものを捨てる」（回数）です。人気が変わらないなら、回数を数えるほうが本当に人気のデータを見分けられます。けれども、人気が移り変わると、昔たくさん使われたデータが回数の多さで居座り、新しく人気になったデータが入れません。**ここでは、作成者が置いた架空のアプリのデータ5,000件への問い合わせ（r番目に人気のデータが選ばれる確率を 1÷r^0.9 に比例させたもの）に、「D 件の問い合わせごとに、新しいデータが1件、人気の上位50位までのどこかに入る」という移り変わりを置き、D を「なし」から200件まで7通りに変えて、4つの捨てる決まりの当たり率を数えました。偏り・新しいデータの入る位置・置き場所の大きさを変えた32通りの確かめも行いました。問い合わせはすべて作成者が置いた式からの乱数で、実機の計測はしていません。**

捨てる決まりは次の4つです。①〜④は同じ問い合わせの列に通して比べました。

- ①古い順：最後に使われてからいちばん長くたったものを捨てる
- ②回数（ずっと数える）：これまでに使われた回数がいちばん少ないものを捨てる。回数は置き場所から出ても覚えておく。同じ回数なら、最後に使われたのが古いほうを捨てる
- ③回数（置き場所にいる間だけ）：置き場所に入ってから使われた回数がいちばん少ないものを捨てる。捨てたら回数は忘れる
- ④回数（2万件ごとに半分）：②の回数を、問い合わせ2万件ごとに全部半分にする

関連する記事：同じ企画の 1152「よく使われるものへの偏りが大きいときと小さいときで、同じ大きさの置き場所の効き目はどれだけ違うのか？」と 1150「置き場所の大きさを2倍にすると、当たり率はどれだけ上がるのか？」は、人気が変わらないと置いたうえで、①の決まりの当たり率を数えています。1066「1試合で動かす点の幅を大きくすると、強さは早く当たるのか、ぶれるのか？」は、新しい結果に重みをかけると変化に早く追いつくがぶれる、という同じ形の釣り合いを、対戦の点数の付け方で扱っています。1157「一度しか使われないものが多いと、置き場所を大きくしても当たり率はどこで止まるのか？」は、一度しか使われないデータが置き場所を占める場面を扱っています（下の①が人気の低いデータに置き場所を使うのと同じ形）。この記事は、捨てる決まりと人気の移り変わりの速さに絞ります。

## 主な結果

### 移り変わりの速さごとの当たり率（偏り0.9・置き場所100件、`results/by_speed.csv`）
| 新しいデータが入る間隔 | ①古い順 | ②回数（ずっと） | ③回数（置き場所にいる間だけ） | ④回数（2万件ごとに半分） | 新しいデータへの問い合わせの割合 |
|---|---|---|---|---|---|
| なし | 30.87% | **45.74%** | 41.86% | 45.7% | 0% |
| 2万件 | 31.18% | 45.18% | 38.09% | 45.76% | 5.41% |
| 5,000件 | 30.9% | 42.63% | 26.57% | 45.03% | 23.14% |
| 2,000件 | 30.86% | 39.36% | 16.69% | 44.11% | 36.13% |
| 1,000件 | 30.89% | 34.65% | 11.67% | 42.51% | 46.08% |
| 500件 | **31.03%** | **28.81%** | 5.42% | 39.97% | 59.02% |
| 200件 | 30.87% | 20.89% | 2.87% | 34.26% | 71.84% |

その時点の人気の上位100件をずっと置けたときの当たり率は45.88%（式どおり。どの速さでも同じ）。

- **人気が移り変わらなければ、②回数（ずっと数える）は45.74%で、上位100件を置けたとき（45.88%）にほぼ並び、①古い順（30.87%）を上回った**
- **②は移り変わりが速くなるほど下がり、500件ごとに新しいデータが入る速さで①を下回った（①31.03%、②28.81%）**。200件ごとでは①30.87%、②20.89%
- ①古い順の当たり率は、移り変わりの速さによらず30.86〜31.18%でほとんど動かなかった。直前に使われたかどうかだけで決めるので、どのデータが人気かが入れかわっても、人気の偏りの形が同じなら当たり方は変わらない
- ④回数を2万件ごとに半分にすると、移り変わる6通りすべてで4つの中でいちばん当たった（2万件ごと45.76%〜200件ごと34.26%）。移り変わりがないときは45.7%で、②とほぼ同じ
- ③回数（置き場所にいる間だけ）は、移り変わりがなくても41.86%と②より低く、移り変わると急に下がった（200件ごとで2.87%）。入ったばかりのデータは回数が1なので、次に外れたときにすぐ捨てられ、前からいるデータが居座るため

### 置き場所の中身（新しいデータが1,000件ごとに入るとき、5,000件ごとに見た平均、`results/by_speed.csv`）
| 決まり | いまの人気の上位100位 | 101〜1,000位 | 1,000位より下 |
|---|---|---|---|
| ①古い順 | 31.86件 | 37.36件 | 30.78件 |
| ②回数（ずっと） | 47.6件 | **52件** | 0.4件 |
| ③回数（置き場所にいる間だけ） | 12.32件 | **86.2件** | 1.48件 |
| ④回数（2万件ごとに半分） | **81.24件** | 18.3件 | 0.46件 |

- ①古い順は、一度しか使われない人気の低いデータ（1,000位より下）にも30.78件を使っていた。移り変わりがなくても当たり率が30.87%にとどまるのはこのため
- ②回数（ずっと）は、人気の低いデータはほとんど置かないが、100件の半分（52件）を101〜1,000位のデータが占めていた。新しいデータに押し下げられる前に回数をためた、昔の上位のデータと見られる（推測。順位の移り方は数えていない）
- 新しく入ったデータへの問い合わせの当たり率は、1,000件ごとのとき①54.74%、②58.16%、③3.28%、④78.36%。500件ごとでは①50.48%、②45.68%で、②が①を下回った

### 確かめ：置き方を変えると（32通り、`results/grid.csv`）
| | 値 |
|---|---|
| 移り変わりなしで②が①を上回った置き方 | 8通り中8通り（9.62〜14.58ポイント上） |
| ①が②を上回った置き方：5,000件ごと | 8通り中0通り |
| 同：1,000件ごと | 8通り中1通り |
| 同：200件ごと | 8通り中4通り（①−②は−10.26〜＋30.34ポイント） |
| 同：移り変わる24通りの合計 | 24通り中5通り |
| 移り変わる24通りで、いちばん当たった決まり | ④22通り、①2通り |
| ④が②を上回った（移り変わる24通り） | 24通り中23通り（残り1通りは小数4けたで同じ） |

- **①が②を上回ったのは、新しいデータが上位10位までに入る（強く入れかわる）置き方に限られた**。上位500位までのどこかに入る置き方では、200件ごとでも②が上だった
- いちばん当たった決まりが①になったのは、偏り1.1・上位10位までに入る・200件ごとの2通りだけで、それ以外の移り変わる22通りでは④だった
- ①の当たり率は、32通りで7.2〜64.71%だった（偏りと置き場所の大きさで決まり、移り変わりの速さではほとんど動かない）

## 注意（言えないこと）
- 架空のデータです。人気の偏りの形、移り変わりの置き方（新しいデータが上位に1件ずつ入る）、置き場所の大きさは作成者が置いたもので、結果はこれで決まります。①が②を上回るかどうかは、移り変わりの速さと、新しいデータがどれだけ上位に入るかで入れかわりました
- 人気がゆっくり下がっていく・いくつかのデータが同時に入れかわる、といった別の移り変わり方は数えていません
- ④の「2万件ごとに半分」の間隔は作成者が1つ置いたもので、ほかの間隔は比べていません
- データの大きさはすべて同じと置き、件数で数えた当たり率だけを出しました
- 実在のソフトや置き場所の製品の決まり・当たり率を表すものではありません。どの決まりを使うべきかの助言や、費用の見込みではありません
