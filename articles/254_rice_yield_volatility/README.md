# 254 米の10a当たり収量は、天候でどれだけ揺れるのか

農林水産省「作物統計調査」の水稲の収穫量累年統計と、気象庁「日本の季節平均気温」を使ったフォルダです。米の作況指数の「揺れの大きさ」が時期でどう変わったか、それが夏の気温の揺れによるものか、気温への効き方によるものかを見ました。データは記事111（`articles/111_rice_yield_summer`）で整えたものをそのまま使っています。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A254 | 米の10a当たり収量は、天候でどれだけ揺れるのか。揺れは小さくなったのか | 全国の作況指数（2020年以降は作況単収指数）の標準偏差・95未満の年の数を4つの時期（1926〜44・1946〜69・1970〜99・2000〜2025年）で比較。平年収量に頼らない見方として、10a当たり収量の対数から LOWESS（frac=0.3）のトレンドを引いた偏差でも比較。9地域の比較（1958〜99年と2000〜25年）。夏（6〜8月）の気温偏差（LOWESS でトレンド除去）の標準偏差と、涼しい側の傾き（作況指数を min(気温偏差,0) に回帰、HC1 標準誤差）を時期ごとに比較 | `src/a254_rice_volatility.py` |

## 主な結果
- 全国の作況指数の標準偏差は、1926〜1944年 9.3、1946〜1969年 7.5、1970〜1999年 7.1、2000〜2025年 2.8。2010〜2025年に限ると1.5で、最低でも98（2010年）
- 作況指数が95未満の年は、1970〜1999年の30年で4回（最低は1993年の74）、2000〜2025年の26年で1回（2003年の90）
- 平年収量を使わず、10a当たり収量そのものの長期トレンドからの偏差で見ても、標準偏差は1970〜1999年 7.0%、2000〜2025年 2.6%で、同じように小さくなった
- 地域別（1958〜1999年 → 2000〜2025年の標準偏差）：北海道 18.1→7.7、東北 10.2→4.6、関東・東山 6.1→2.7、東海 6.4→2.4 など8地域で半分前後（比0.38〜0.53）。九州は8.6→7.1（比0.83）で、2004・2006・2019・2020年に84以下の年があった
- 夏の気温偏差の標準偏差は、1970〜1999年 0.63℃、2000〜2025年 0.55℃で、大きくは変わっていない。−0.5℃以下の涼しい夏も、前者で8回、後者で4回あった
- 変わったのは効き方。夏が1℃涼しいときの作況指数の下がり方（涼しい側の傾き）は、1970〜1999年 15.5（標準誤差3.3）、2000〜2025年 5.8（同2.2）
- 1970〜1999年の気温の並びに2000〜2025年の傾きを当てはめると、気温による作況の揺れ（標準偏差）は5.3→2.0。逆に2000〜2025年の気温に1970〜1999年の傾きを当てはめると4.7。揺れが小さくなったのは、涼しい夏が減ったからより、涼しい夏に落ちにくくなったからが大きい

## 頑健性
- LOWESS の frac を0.2・0.4に変えても、2000〜2025年の偏差の標準偏差は2.6〜2.7%、1970〜1999年は6.9〜7.0%
- 記録的な冷夏の1993年を除くと、1970〜1999年の傾きは10.5（標準誤差3.7）に下がる。2003年を除くと2000〜2025年の傾きは2.3（同1.1）。どちらを除いても「後の時期のほうが小さい」は同じ
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致した

## データ
- `data/rice_panel.csv`：記事111で e-Stat の Excel（作物統計調査 作況調査 確報 収穫量累年統計 水稲：全国 明治16年〜令和7年、地域・都道府県 昭和33年〜令和7年）から整えたもの。`sakkyo_any` は2019年までは作況指数、2020年以降は作況単収指数
- `data/ssn_jpn.csv`：気象庁「日本の季節平均気温」の偏差（1991〜2020年平均との差、℃。全国15地点の平均）を UTF-8 にしたもの

## 注意
- 作況指数は「その年の10a当たり収量 ÷ 平年収量 × 100」。平年収量は農林水産省が毎年見直すので、平年収量の作り方が変わると揺れの見え方も変わる。そのため、平年収量を使わない偏差でも確かめた
- 2020年から作況単収指数（生産者が使うふるい目の基準）に変わった。2000〜2025年の揺れには、この切り替えの前後の両方が入っている
- 気温は全国の平均で、地域ごとの気温ではない。台風・日照不足・病害虫（いもち病、ウンカなど）は分けていない。九州の低い年は台風や害虫の年と重なる（推測）
- 「落ちにくくなった」理由（冷害に強い品種、田植えの時期、水の管理など）は、このデータでは分からない
- 揺れの小ささは「量」の話で、暑さによる品質の低下（白く濁った米など）は入っていない
