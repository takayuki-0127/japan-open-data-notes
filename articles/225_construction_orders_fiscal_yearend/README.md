# 225 建設工事の受注は、年度末に偏っているのか：大手50社の月次受注高をSTL分解

国土交通省「建設工事受注動態統計調査（大手50社調査）」の月次受注高（2011年1月〜2026年8月、188か月）を、STL分解でトレンド・季節・残りに分け、3月（年度末）にどれだけ偏っているかを、発注者別（民間の製造業・非製造業、国の機関、地方の機関）に見たフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A225 | 受注は年度末の3月に偏っているか。偏りは公共工事だけか。偏りは強まっているか | 対数をとった月次受注高のSTL分解（周期12、ロバスト）、月別の季節の倍率、季節成分の強さ、年度ごとの3月の割合とその直線トレンド、3月の上乗せ分の発注者別内訳 | `src/a225_fiscal_yearend.py` |

## 主な結果
- 総計の3月の季節の倍率は2.18倍（ふつうの月の約2倍）。次に多いのは9月（1.32倍）と12月（1.27倍）で、少ないのは5月（0.73倍）。季節成分の強さは0.85
- 年度の受注高に占める3月の割合は、2011〜2025年度の平均で18.1%（12か月で均等なら8.3%）。1〜3月の3か月では32.6%。年度で13.3%（2013年度）から24.5%（2020年度）まで動き、総計ではっきりした増減の傾向はない（年+0.23ポイント、p=0.27）
- 3月の倍率は、国の機関2.85倍、地方の機関2.58倍、民間の非製造業2.30倍、民間の製造業1.62倍。公共工事だけでなく、民間の非製造業も3月に集中している
- 3月に「ふつうの月より多く入った分」の内訳は、民間の非製造業が58%、国の機関20%、地方の機関9%、民間の製造業8%。金額が大きい民間の非製造業が、年度末の山の大部分をつくっている
- 地方の機関の3月の割合は、2011年度の13.7%から2025年度は27.2%に上がった（年+0.72ポイント、p<0.001）

## 動かし方
```
pip install -r requirements.txt
cd src && python a225_fiscal_yearend.py
```

## データ
- `data/big50_orders_monthly_2011_2026.csv`：大手50社の月次受注高（百万円）。総計・国内計・民間等（製造業・非製造業）・公共機関（国の機関・地方の機関）・その他・海外。2011〜2018年は各年12月分、2019年は11月分の「時系列」表（13か月分）、2019年12月以降は2026年8月分の「時系列」表から
- `results/stl_*.csv`：系列ごとのSTL分解（トレンド・季節の倍率・残り）
- `results/seasonal_factor_by_month.csv`・`seasonal_strength.csv`：月別の季節の倍率と季節成分の強さ
- `results/march_share_by_fy.csv`・`march_share_trend.csv`：年度ごとの3月の割合（9月・1〜3月も）と、その直線の傾き
- `results/march_excess_by_client.csv`：3月の上乗せ分の発注者別内訳

## 注意
- 大手50社（受注の多い総合建設会社など）の受注で、建設業全体ではありません。全体の受注動態統計は2021年の見直し後の月次（2022年4月〜）しか時系列表になく、長い期間がとれないため、大手50社を使いました
- 受注は契約した月に計上されます。工事の施工（出来高）の時期とは違います
- 民間の発注者の多くも3月決算で、3月の山は「公共の予算の年度末」だけでなく、企業の決算期の影響も入っていると考えられますが、このデータでは分けられません
- 大きな工事1件で月の値が大きく動きます。STLはロバスト推定にしています
