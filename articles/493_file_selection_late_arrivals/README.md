# 493 ファイル名の日付で取り込み対象を選ぶと、遅れて置かれたファイルを何件落とすのか（実務の型）

毎日置かれる売上ファイル（1年分）を、毎朝の取り込みで「どれを読むか」の選び方5通りで処理し、年末に、落としたファイル、直した版を入れていないファイル、二重に入った行、合計金額のずれを数えたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A493 | 取り込み対象の選び方で、遅れて置かれたファイルと置き直されたファイルをどれだけ取りこぼすか | 架空の置き方（ふつうは翌日2時、8%は1〜5日遅れ、3%は1〜3日後に直した版を同じ名前で置き直し）を作り、毎朝6時の取り込みを5通りで年末＋12日まで回す。遅れの割合を0〜25%に変えて各20回 | `src/a493_file_selection.py`、`src/01_manifest_tsql.sql`（T-SQL 版、未検証） |

## 主な結果
- **置き方**（seed 493）：365ファイル、362,148行。遅れて置かれたのは25件、置き直しは11件
- **①ファイル名が「昨日」のもの**：25件（25,526行）を落とし、置き直し10件は古い版のまま。1年の売上合計は −7.12%
- **②前回の取り込みより後に置かれたもの（追記）**：落としは0件だが、置き直しの11件は古い版も残って10,839行が二重。合計は +2.99%
- **③②＋同じ名前は消して入れ直す**：落とし0、二重0、合計のずれ0
- **④取り込み済みの名前の一覧にないもの**：落としは0件だが、置き直し11件は同じ名前なので入れ直さない。合計は −0.06%
- **⑤名前と版（中身）の一覧にないもの＋入れ直す**：落とし0、二重0、合計のずれ0
- **遅れの割合を変えると**（各20回の平均）：①の落としは遅れに比例して増え、遅れ5%で年18件、25%で年89件（合計 −24.5%）。④は遅れに関係なく、置き直しの約10件だけを取りこぼす。⑤はどの場合も0

## 注意（言えないこと）
- 架空の置き方。落とす件数は、置いた遅れと置き直しの割合で決まる
- ②③はファイルの更新日時を使う。コピーで更新日時が引き継がれる・サーバーの時計がずれる、といったことは入れていない（入れると②③も取りこぼす）
- ファイルの中に前日の売上の行が混ざる（ここでは1%）ことはデータに含めたが、行の日付での集計は扱っていない（締めの話は 341・481、集計表のずれは 402 で扱った）
- T-SQL 版は SQL Server 本体では動かしていない（未検証）
