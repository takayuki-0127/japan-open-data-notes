# F10 人の流れで見ると、日本はいくつの「圏」に分かれるか？（ネットワーク分析）

看板記事（手法をくわしく見せる長めの記事）です。

## 問い

都道府県の間の引っ越し（転入・転出）と、市区町村の間の通勤のつながりをネットワークとして見ると、日本はいくつのまとまり（圏）に分かれるか。中心はどこか。30年でどう変わったか。

## データ

| データ | 内容 | 使い方 |
|---|---|---|
| 総務省「住民基本台帳人口移動報告」長期時系列表 第11表 | 都道府県×都道府県の移動者数（1990・2000・2010年、日本人） | 移動のネットワーク（47×47、向きつき） |
| 同 年報（実数）2025年 表2 | 都道府県×都道府県の移動者数（2025年） | 1990〜2010 とそろえるため日本人移動者を使う。外国人を含む移動者は頑健性で使う |
| 総務省「令和2年国勢調査」従業地・通学地集計 第3表 | 1都3県（埼玉・千葉・東京・神奈川）の市区町村間の15歳以上就業者の通勤（政令市は区、東京は特別区） | 通勤のネットワーク（251市区町村） |
| 統計センター SSDSE-B-2026 | 都道府県の日本人人口（2012・2023年） | 人口で割る正規化（2010年に2012年、2025年に2023年の人口を近似で使う） |
| smartnews-smri/japan-topography | 国土数値情報 行政区域 2021 の簡略版（CC BY 4.0） | 地図と都道府県の代表点 |

## 手法

| 段階 | 内容 |
|---|---|
| ネットワークにする | 都道府県（または市区町村）を点、移動者数（通勤者数）を線の重みにする |
| 中心性 | 向きつき・重みつきの PageRank、流入・流出・転入超過 |
| コミュニティ検出 | 両方向を足した重みで Leiden 法（RBConfiguration＝解像度つきのモジュラリティ）。乱数の種を100通り（通勤は50通り）変えて、いちばん多く出た分け方を採用 |
| 解像度 | 0.5〜3.0 で変え、圏の数と8地方区分との一致（NMI）を見る |
| 比較 | 年どうし（1990・2000・2010・2025年）、正規化どうしの一致を ARI・NMI で比べる |

## 主な結果

- **4つの圏（解像度1、2025年）**：①北海道・東北・関東・新潟・山梨・長野（東京を中心とする「東」）、②北陸・岐阜・静岡・愛知・三重（中部）、③近畿・中国・四国（山口を除く）、④九州・沖縄＋山口。100通りの種のうち97通りで同じ分け方。
- **30年でほとんど変わらない**：1990年と2025年の分け方の一致は ARI 0.89。入れ替わったのは静岡（1990年は「東」、2000年以降は中部）と山口（2025年だけ九州側）の2県。
- **中心は東京で、さらに強まった**：PageRank は東京 0.131（1990年）→0.159（2025年）。東京圏以外の道府県から出た移動のうち東京圏（1都3県）へ向かう割合は 30.4%→32.9%。
- **圏の境目は弱まっている**：解像度1のモジュラリティは 0.274（1990年）→0.240（2025年）。
- **解像度で圏の数が変わる**：2025年は解像度0.75で2つ（東と西）、1.0で4つ、1.5で8つ、2.0で9つ。8地方区分との一致（NMI）は解像度1.5前後で最大（0.87）。
- **通勤（1都3県、2020年）**：6つのまとまり（モジュラリティ 0.38）。都県境をまたぐ通勤は市区町村間の通勤の32%で、まとまりは都県境をまたいでいる（例：新宿・豊島・板橋と多摩・埼玉西部、千代田・中央・江東と千葉の東葛、港・渋谷・品川と川崎）。都県との一致は NMI 0.66。

## 頑健性

| 確かめたこと | 結果 |
|---|---|
| 乱数の種 | 移動（2025年・解像度1）：100通り中97通りで同じ分け方。1990年は76通り。通勤：6つになるが、細かい境界は種で動く（同じ分け方は20%、ペアの77%は95%以上の種で同じ組／別の組で安定） |
| 正規化 | 期待値との比（出し入れの大きさで割る）、人口の積で割る：どちらも4つだが、関西が中部と同じ圏になり、静岡は「東」に入る（件数の分け方との ARI 0.71） |
| 外国人を含める（2025年） | ARI 0.95。山口は中国・四国側に戻る（山口の所属は境目） |
| 年の違い | 1990・2000・2010・2025年で、解像度ごとの圏の数はほぼ同じ |

## 言えないこと

- 移動・通勤の理由（進学・就職・結婚・住宅）は分からない
- 1990〜2010年は日本人だけの移動。2025年も日本人移動者でそろえたので、外国人の移動は主な結果に入っていない
- 通勤は1都3県の中だけ（茨城南部などからの通勤は入っていない）。全国の市区町村の通勤圏や、都市雇用圏との比較はしていない
- コミュニティの数は解像度という設定しだいで、「日本は4つ」が唯一の答えではない
- 人口の正規化は 2012年・2023年の人口で近似した
