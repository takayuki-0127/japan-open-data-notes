# 400 漁業で働く人は、何歳の人が残っているのか（漁業センサス 累年統計、1973〜2023年）

海面漁業の就業者数を年齢5歳きざみで並べ、同じ生まれ年の人数が5年ごとに何倍になったかを追ったフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A400 | 漁業就業者は何人に減り、65歳以上は何割か。同じ生まれ年の人は5年で何割残るか | 累年統計の年齢階層別人数。ある回のa歳階級に対する、5年後の(a+5)歳階級の人数の比（やめた人と入った人の差し引き） | `src/a400_fishery_workers.py` |

## 主な結果
- 就業者：1963年62.6万人、1973年51.1万人 → 1993年32.5万人 → 2003年23.8万人 → 2013年18.1万人 → 2023年12.1万人（1973年の24%）
- 65歳以上の割合：8.4%（1973年）→11.5%（1988年）→33.3%（2003年）→39.2%（2023年）。人数は4.3万人→7.9万人（2003年）→4.8万人
- 40歳未満は20.2万人→2.2万人。2023年にいちばん多い年齢層は75歳以上（1.8万人）。2003→2023年に増えたのは75歳以上だけ
- 5年後の人数の倍率（1998〜2023年の6回の平均）：15〜19歳→3.04、20〜24歳→1.25、25〜29歳→1.11、30〜34歳→1.05、35〜39歳→1.02、40〜44歳→0.96、45〜49歳→0.96、50〜54歳→0.91、55〜59歳→0.91、60〜64歳→0.80、65〜69歳→0.73
- 1978〜93年の平均は50〜54歳→0.85、55〜59歳→0.81で、近年のほうが高い

## 確かめたこと
- 男女の合計＝総数、年齢の合計＝総数
- 2003→2008年は数える範囲が広がったため、2008年の倍率は全体に高い（表の注）
- 空のフォルダで流し直し、data・results・figures が一致した

## 動かし方
```
pip install -r requirements.txt
cd src && python a400_fishery_workers.py
```

## データ
- `data/raw/gyogyo_census_2023_ruinen_age.csv`：e-Stat「2023年漁業センサス 総括編」累年統計「男女別・年齢階層別漁業就業者数」（statInfId=000040252567）の Excel を CSV にしたもの（2026-11-12 取得）
- `data/fishery_workers_by_age.csv`：調査年ごとの人数と割合
- `results/a400_main.json` の `if_same_ratio_2028` は、足し算の確かめのために置いた値で、見通しではありません（記事では使っていません）

## 注意（言えないこと）
- 倍率はやめた人・亡くなった人と、新しく入った人の差し引きです。やめた人の数そのものは分かりません
- 年齢5歳きざみは1973年から、65歳以上の内訳は1993年からです。平均年齢の列は階級の真ん中を使った大まかな値です
- 海面漁業だけの、全国の数字です。年30日以上、海の上で仕事をした人を数えています
