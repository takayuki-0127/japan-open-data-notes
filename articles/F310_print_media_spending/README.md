# F310 新聞・書籍・雑誌への支出は、どれだけ減ったのか？ 物価を除くと20年余りで−69（対数差）。新聞は29歳以下−252、70歳以上−9で、生まれ年で並べるとよくつながった

## 結論（先に）
- 二人以上の世帯が「書籍・他の印刷物」に払う年間の支出は、2002〜04年平均の約5.6万円から2023〜25年平均の約3.6万円になりました（名目、対数差×100 で −45）。この間に書籍・他の印刷物の物価は +24 上がったので、物価を除いた実質では **−69** です。
- 品目別（名目）では、新聞 −44、書籍 −34、雑誌 −82 でした。金額で一番大きく減ったのは新聞です（約3.9万円→約2.5万円）。
- 新聞の減り方は世帯主の年齢で大きく違います。29歳以下 −252、30代 −214 に対して、60代 −35、70歳以上 −9 でした。
- 新聞の支出は「年齢＋時代」より「年齢＋世代（生まれ年）」の組み合わせのほうがずっとよく当てはまりました（AIC 147 対 −109）。
- 問い直し：高齢の世帯の割合が増えたこと（70歳以上 15%→34%）が、平均の新聞の減り方を小さく見せていました。年齢の構成を2002〜04年に固定すると、新聞は −65 になります。

## 問い
紙の新聞・雑誌・本が読まれなくなった、とよく言われます。出版・新聞・書店の担当の人や、家計の統計を読む人にとっては、「どれだけ」「どの品目で」「どの世帯で」が知りたいところです。家計調査で、二人以上の世帯が新聞・雑誌・書籍に払うお金は、この20年余りでどれだけ減ったのか。値段の上がり分を除くとどうか。新聞の減り方は、生まれ年で説明しやすいのか。紙と電子のどちらがよいかは扱いません。

## データ（出典）

- 総務省「消費者物価指数」2025年基準 全国 中分類「書籍・他の印刷物」。月次の指数を年平均にして、実質化に使いました。

## やったこと
1. 4つの品目と世帯数分布を、年×年齢の階級（6つ）×品目の表にしました。
2. 2002〜04年平均と2023〜25年平均を対数差×100 で比べました。実質 ＝ 名目 ÷ 物価指数です。
3. 世代 ＝ 調査年 − 年齢の階級の中央（25・35・…・75歳）を5年ごとにまとめました。新聞の支出（対数）を「年齢＋時代」「年齢＋世代」「世代＋時代」の3つの組み合わせで回帰して、AIC（当てはまりのよさの目安。小さいほどよい）を比べました。3つを同時には分けられないので、2つずつの比較にとどめています。
4. 頑健性を4つ、問い直しを1つ足しました。

## 分かったこと
### 支出はそろって減りました（図1）
| | 2002〜04年平均 | 2023〜25年平均 | 名目の変化 |
|---|---|---|---|
| 書籍・他の印刷物 | 55,817円 | 35,746円 | −45（実質 −69） |
| 新聞 | 38,674円 | 24,822円 | −44 |
| 書籍 | 10,401円 | 7,416円 | −34 |
| 雑誌 | 4,927円 | 2,165円 | −82 |

書籍は2020〜21年に一時増えました。外出が減った時期と重なりますが、理由はこの表からは分かりません。

### 新聞は若い世帯ほど大きく減りました（図2）
29歳以下と30代の平均は −233、60代と70歳以上の平均は −22 で、差は211ポイントです。29歳以下の新聞の支出は約2.2万円から千円台になりました。70歳以上はほとんど変わっていません。

### 生まれ年で並べるとよくつながります（図3）
横軸を生まれ年にすると、隣の年齢の階級の線がほぼつながります。AIC は 年齢＋時代 147、年齢＋世代 −109、世代＋時代 −101 でした。生まれ年が1925年ごろの世代を0とすると、1970年ごろの世代は −90、1990年ごろは −330 です。ただし、これは「年齢の効果は時代によらず同じ」などの仮定の下での当てはまりの比較です。世代そのものが原因だとは言えません。

## 問い直し（結果を見てから足した）
H3 を見て、「若い世帯ほど大きく減ったのに、平均は −44 にとどまるのはなぜか」と考え直しました。世帯数分布を重みにして、年齢の構成を2002〜04年に固定した平均を作りました（図4）。

| 品目 | 公表の平均 | 構成を固定 | 構成の変化の分 |
|---|---|---|---|
| 新聞 | −44 | −65 | +21 |
| 書籍 | −34 | −22 | −11 |
| 雑誌 | −82 | −84 | +2 |
| 書籍・他の印刷物 | −45 | −56 | +11 |

新聞を多く払う高齢の世帯が増えたので、平均の減り方は小さく見えていました。書籍は逆です。高齢の世帯は書籍への支出が少ないため、構成の変化で減り方が大きく見えました。なお、重みから作り直した平均は公表の平均とほぼ一致しました（差 0.1 以下）。

## 頑健性
| 確かめたこと | 結果 | 結論は変わるか |
|---|---|---|
| R1 終点を2017〜19年（コロナの前）、実質 | −40 | H1 の基準（−30）は満たす |
| R2 H3 を実質で | 若い −256、高齢 −46 | 変わらない |
| R3 H4 を書籍で | 年齢＋時代 −218、年齢＋世代 −208 | 書籍は時代のほうが少しよい |
| R3 H4 を雑誌で | 年齢＋時代 27、年齢＋世代 −117 | 新聞と同じ向き |
| R4 始点を2005〜07年、実質 | −63 | 変わらない |

世代でよく説明できるのは新聞と雑誌で、書籍は違いました。

## 言えないこと
- 二人以上の世帯だけで、単身の世帯は入りません。若い単身の世帯の動きは分かりません。
- 29歳以下が世帯主の二人以上の世帯は標本が少なく（2025年は約100世帯）、−252 のような若い階級の値や、新しい生まれ年の世代の差（1990年ごろ −330）は、標本のぶれを大きく含みます。
- 電子版の新聞・電子書籍がこれらの品目にどこまで入っているかは、確かめていません。紙だけの動きとは限りません。
- 支出であって、読む量や時間ではありません。
- 実質化に使った物価は「書籍・他の印刷物」全体で、新聞・雑誌の個別の値段の動きとは違う可能性があります。
- 年齢・時代・世代の効果は仮定なしには分けられません。
- 新聞を「とらなくなった」世帯が増えたのか、とる世帯の支出が減ったのかは分けられません（推測：前者の寄与が大きいと思われますが、購入世帯の割合の表は使っていません）。

## 仕事で使うなら
- 平均の減り方は、年齢の構成を固定するかどうかで変わります（新聞 −44 と −65）。どちらの数字かを書き添えると誤解が減ります。
- 書籍は新聞・雑誌と違い、世代より時代の動きに近い形でした。「紙の印刷物」とまとめた数字だけでは、この違いが見えません。
