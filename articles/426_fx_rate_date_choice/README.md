# 426 外貨の売上を円に直すとき、どの日のレートを使うかで、月の売上はどれだけ変わるのか（実務の型）

日本銀行のドル円の日次レート（1998〜2025年、336か月）に、架空のドル建ての取引を当てて、円に直す方法（取引日のレート・月中平均・月末レートなど）で月の売上がどれだけ違うかを数えたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A426 | 円に直すレートの日を変えると、月の売上と年の売上はどれだけ変わるか | 5つの直し方（①取引日 ②月中平均 ③月末 ④前の月の月末 ⑤前の月の平均）を Python で計算し、①〜④は同じ SQL を DuckDB で実行して一致を確かめる。取引の日の偏り（散らばる・月末に集まる・月初に集まる）と件数を変えて比べる | `src/a426_fx.py`、`src/01_convert_tsql.sql`（T-SQL 版、未検証） |

## 主な結果（取引が営業日に散らばる場合。①取引日のレートで直した額との差）
| 直し方 | 差の中央値 | 9割の月はこの範囲 | 最大 | 1%を超えた月 | 2%を超えた月 | 年の合計の差の最大 |
|---|---|---|---|---|---|---|
| ②月中平均 | 0.10% | 0.34% | 1.7%（1998年10月） | 0.3% | 0% | 0.24%（1998年） |
| ③月末レート | 0.96% | 2.50% | 5.9%（1998年10月） | 47.6% | 20.2% | 0.84%（2008年） |
| ④前の月の月末 | 0.97% | 2.84% | 10.0%（1998年10月） | 49.3% | 20.9% | 1.48%（2013年） |
| ⑤前の月の平均 | 1.46% | 3.71% | 9.0%（1998年10月） | 63.6% | 37.9% | 1.77%（2013年） |

- **月末レートとの差が大きかった月**：1998年10月 −5.9%（月の中のレートの幅18.8%）、2009年2月 +5.3%、2003年9月 −4.4%、2024年7月 −4.4%、2004年3月 −4.0%
- **差の向き**：月初から月末へのレートの変化と、月末レートとの差の相関は0.87
- **月の中のレートの幅と差**：幅2%未満の56か月で、月末レートとの差の中央値0.42%・月中平均0.04%。幅6%以上の35か月で、2.48%・0.26%。幅の中央値は3.3%
- **取引の日の偏り**：月の終わりの5営業日に半分が集まると、②0.22%・③0.72%。月の初めの5営業日に半分が集まると、②0.27%（最大4.2%）・③1.19%（最大8.3%）
- **取引の件数**：②の差の中央値は月5件で0.33%、20件で0.18%、60件で0.09%、300件で0.05%。③は0.93〜0.98%で変わらない
- **28年分の合計**：②−0.004%、③+0.04%

## 動かし方
```
pip install -r requirements.txt
cd src && python a426_fx.py     # 数秒
```

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した
- DuckDB の SQL で出した①〜④の月ごとの円換算額が、Python の計算と336か月すべてで一致する（コード内の assert）

## データ
- `data/boj_usdjpy_daily.csv`：日本銀行 時系列統計データ検索サイト、外国為替市況（FM08、系列コード FXERD04）、東京市場 ドル・円 スポット 17時時点の日次。1998/1/5〜2026/10/30（F169 の写し。使ったのは2025年12月まで）
- `data/fx_transactions_even.csv`：架空のドル建ての取引20,160件（取引が営業日に散らばる場合）。作成者が乱数で作成（seed 426）

## 注意（言えないこと）
- 取引は架空。差の大きさは、取引の日と金額の散らばり方で変わる
- レートは東京市場の17時時点のスポット。銀行の仲値（TTM）や社内レートではない。売りと買いの差は入れていない
- どの直し方が正しいか、会計・税の決まりでどれが認められるかは扱っていない
- ドル以外の通貨、売掛金の評価替え（為替差損益）は試していない
- T-SQL 版は SQL Server 本体では動かしていない（未検証）
