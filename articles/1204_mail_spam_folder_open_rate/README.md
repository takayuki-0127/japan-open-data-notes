# 1204 迷惑メールに振り分けられた分は、開封率の数字のどこに表れるのか？（メール配信）

お知らせのメールを送ると、送る側の集計には「届かなかった（宛先がない）」「届いた」「開いた」「クリックした」が出ます。けれども、「届いた」メールが受信箱に入ったのか、迷惑メールのフォルダに入ったのかは、送る側には見えません。迷惑メールのフォルダに入ったメールはほとんど開かれないので、振り分けが増えると、届いた割合は変わらないまま開封率だけが下がり、「読者が読まなくなった」と区別がつきにくくなります。**ここでは、作成者が置いた架空の店の会員2万人へのお知らせのメール（1人ひとりの開く確率、受信側のメールサービスA・B・C（架空）、迷惑メールのフォルダに入る確率を作成者が置き、乱数で作ったもの）で、開封率が同じだけ下がる3つの場面（サービスBで振り分けが増える・開かない人ほど振り分けられる・振り分けは同じで読む気が落ちる）を比べ、送る側に見える数字のどこに違いが表れるかを数えました。置き方を変えた39通りでも確かめました。**

例の店・会員・メールサービスは架空のもので、実在のメールサービス・メール配信の仕組みを表すものではありません。振り分けの仕組みや、振り分けを避ける方法は扱っていません。

関連する記事：983「振り分けで「迷惑メール」と出たとき、本当に迷惑メールの確率は？」は、振り分けの仕組みの判定の当たり方を、受信する側から、もとの割合で扱っています。この記事は、送る側の開封率の数字の中で、振り分けられた分がどこに表れるかに絞ります。同じ企画の 1203「登録して間もない人ほどよく開くとき、全体の開封率の下がり方は、読者の入れかわりでどれだけ説明できるのか？」は、開封率が下がる別の理由（読者の入れかわり）を扱っています。同じ企画の 1198「届かなかったアドレスを分母に残すか除くかで、開封率はどう変わるのか？」は、届かなかったアドレス（送る側に見える分）を分母に入れるかどうかを扱っています。この記事の振り分けは、送る側には「届いた」と見える分です。

## 主な結果

### 3つの場面の、前の8週と後の8週（各100回の平均、`results/scenarios_summary.csv`・`results/a1204_main.json`）
| 送る側に見える数字 | T サービスBで振り分けが増える | P 開かない人ほど振り分けられる | I 読む気が落ちる |
|---|---|---|---|
| 届いた割合（届いた通数÷送った通数） | 98.01% → 98.01% | 98.01% → 98.01% | 98.01% → 98.01% |
| 開封率（開いた通数÷届いた通数） | 29.44% → 24.31%（**−5.13**） | 29.41% → 24.3%（−5.11） | 29.43% → 24.29%（−5.14） |
| クリック率（クリック÷届いた通数） | 5.76% → 4.74% | 5.75% → 4.91% | 5.75% → 4.75% |
| 開いた通数あたりのクリック | 19.56% → 19.51%（−0.05） | 19.55% → 20.21%（**+0.67**） | 19.54% → 19.58%（+0.04） |
| サービスAの開封率の変化 | 0 | −5.14 | −5.15 |
| サービスBの開封率の変化 | **−17.13** | −5.08 | −5.1 |
| サービスCの開封率の変化 | −0.01 | −5.1 | −5.18 |
| 下がり幅のうちサービスBの分 | 100% | 29.76% | 29.73% |
| 直前の8週に1回も開いていない人（8週目 → 26週目） | 12.77% → 20.6% | 12.79% → 20.7% | 12.78% → 17.37% |
| （送る側には見えない）受信箱に入った割合 | 98% → 80.04% | 98% → 74.64% | 98% → 98% |
| （送る側には見えない）受信箱に入った分の開封率 | 30.01% → 29.99% | 29.98% → 32.15% | 30% → 24.76% |

- **3つとも、届いた割合は98.01%のまま変わらず、開封率だけが約5ポイント下がった**（開封率の下がり幅が同じになるように置いた）。振り分けられたメールは「届いた」に数えられ、分母に残ったまま、分子（開いた通数）から抜けた
- T の下がり幅5.13ポイントは、「サービスBの割合×振り分けの増え×（1−フォルダでの開く倍率）×もとの開く確率の平均」＝0.3×0.6×0.95×0.3の式どおり（式の値5.13ポイント）
- **T では、サービスごとに分けると、サービスBの開封率だけが17.13ポイント下がり、AとCは動かなかった**。受信箱に入った分の開封率は29.99%で、読者は読まなくなっていなかった
- **P では、サービスごとの下がり方は3つともほぼ同じ（−5.08〜−5.14）で、I（読む気が落ちる）と区別できなかった**。違いは、開いた通数あたりのクリックが0.67ポイント上がった（5〜95%の範囲で+0.23〜+1.13）こと。よく開き、よくクリックする人ほど受信箱に残るので、開いた人の顔ぶれがよくクリックする人に寄った。受信箱に入った分の開封率は32.15%に上がっていた
- 直前の8週に1回も開いていない人は、振り分けの2つの場面で20.6%・20.7%と、I の17.37%より多く増えた。振り分けられた人は、まったく開かなくなるため

### 確かめ（各10回、`results/grid.csv`）
- **T の27通り**：開封率の下がり幅は0.47〜12.04ポイントで、式の値との差は0.15ポイント以内だった（式どおり）。届いた割合の変化はすべて0。下がり幅のうちサービスBの分は96.32〜108.5%で、どの置き方でもBに集まった。開いた通数あたりのクリックの変化は−0.19〜+0.18ポイントで、ほとんど動かなかった。直前の8週に1回も開いていない人は0.38〜26.17ポイント増えた
- **P の12通り**：下がり幅のうちサービスBの分は28.8〜30.63%で、どの置き方でも会員の割合（30%）と同じくらいだった。開いた通数あたりのクリックの変化は、開かない人への偏りなし（0乗）で−0.08〜−0.04ポイント、1乗で+0.2〜+0.47、3乗で+0.59〜+0.64、6乗で+0.95〜+1.04ポイント。偏りがないと、送る側に見える数字では、読む気が落ちた場合とほとんど見分けがつかなかった
- P で、T と同じ下がり幅にするのに要った全体の振り分けの増えは、偏りなしで18%、1乗で19.8%、3乗で23.38%、6乗で28.49%だった。開かない人ほど振り分けられるほど、同じ下がり幅でも、振り分けられた通数は多かった

## 注意（言えないこと）
- 架空のデータと、作成者が置いた振り分けの確率・開く確率です。3つの場面の開封率の下がり幅は、同じになるように作成者が決めました。実際の振り分けの起こり方・割合を表すものではありません
- 迷惑メールのフォルダに入ったメールの開く確率（受信箱の0.05倍）は置いた値です。0倍・0.2倍でも確かめましたが、実際の値は分かりません
- 開いたかどうかは正しく数えられると置きました。画像を読みこまないと開いたと数えられない場合や、受信側の仕組みが自動で開いたと数える場合のずれは入れていません
- サービスごとに分けて見えるのは、振り分けがサービスで偏ると置いたからです（作りどおり）。偏りがない（P）と、送る側の数字だけでは読む気が落ちた場合と区別しにくいという結果でした
- 振り分けの仕組みのしくみや、振り分けを避ける方法は扱っていません
