# F291 死亡率の改善は、年齢のどこで止まりつつあるのか？（精選モード A. 保険数理・リスク Q10）

日本の死亡率は長く毎年下がってきた。その「改善」がいまどの年齢で鈍っているのかを、日本版死亡データベース（元は人口動態統計）の1947〜2024年の死亡数と人口から、5歳階級ごとに測った。2020〜2024年（新型コロナなどの時期）の上振れは、それ以前の傾向と分けて見た。F86（Lee–Carter）・F268（生命表と年金現価）の続き。

- 計画（事前登録）：[PLAN.md](PLAN.md)（コミット 752ca70。分析のコミットはすべてこの後）
- 新しい取得はない。F86 で取得した JMD と、F268 で取得した簡易生命表を写して使った。

## 問い
- 2000年代と2010年代で、死亡率の改善率（年あたり、%）はどの年齢で下がったか
- 2020〜2024年の死亡率は、2010年代の傾向からどれだけ上に出たか
- 平均寿命の伸びは、どの年齢の改善から来ていたか（Arriaga 法）
- 問い直し（結果を見た後に追加）：65〜74歳の鈍りは「時期」のせいか、「生まれ年（世代）」のせいか

## 手法
- 改善率：r = −Δln m ÷ 年数 ×100（年あたり%）。m は5歳階級の死亡率。2000年代＝1999→2009年、2010年代＝2009→2019年、コロナ期を含む直近＝2019→2024年（5年）。
- 改善率の地図：10年の窓を1年ずつずらして（終わりの年 1957〜2024）、年齢×窓で並べた。
- コロナ期の上振れ：区分ごとに2010〜2019年の ln m に直線を当てはめ、2020〜2024年に延ばした値と実際の比を出した。
- 平均寿命の年齢分解：各歳の生命表（a=0.5、0歳は0.1、100歳以上は開いた階級）と Arriaga 法。
- 問い直し：各歳50〜89歳の5年の改善率（1995〜2019年）を、「年齢＋時期」と「年齢＋生まれ年」のダミーで当てはめ、自由度調整済み R² を比べた。生まれ年ごとに、年齢ごとの平均からの差も出した。

## 問い直し（結果を見た後に追加）
65〜74歳の鈍りは時期の効果か、生まれ年の効果か。
- r5(x,t) は、同じ年齢 x で生まれ年 c と c−5 の世代を比べた値。生まれ年に付く値は「その世代の改善」ではなく「5年上の世代と比べて、同じ年齢での死亡率がどれだけ下がったか」。
- 各歳50〜89歳の5年の改善率（1995〜2019年）：自由度調整済み R² は、男で「年齢＋生まれ年」0.564 対「年齢＋時期」0.192、女で 0.507 対 0.520。観測の少ない両端の生まれ年を除くと（観測10以上：1915〜1960年生まれ、20以上：1925〜1950年生まれ）、男 0.587・0.649 対 0.219、女 0.491・0.471 対 0.556・0.575（results/review.json）。
- 調整済み R² の比較は参考程度。5年の差は重なり合っていて誤差が独立でなく、年齢・時期・生まれ年を同時に入れた式（APC モデル）も当てていない。
- 1945〜49年生まれは、5年上の世代と比べて同じ65〜74歳での死亡率がほとんど下がっていない（男0.88%・女0.98%。1940〜44年生まれは男1.69・女2.18、1950〜54年生まれは男2.04・女2.00）。
- 2010年代の65〜69歳（2009→2019年）は1940〜44年生まれと1950〜54年生まれを比べており、1945〜49年生まれはどちらの端にも入らない。世代の差だけで決まるなら10年の改善率は2つの5年の差の平均で男1.46%・女1.49%ほどになるが、実際は男0.98%・女0.85%。10年の鈍りとのつながりは推測。
- 世代で見たほうが当てはまるのは男だけで、女では差がない（端を除くと時期のほうがよい）。1945〜49年生まれの低さは、終戦前後に生まれた世代の育った環境（推測）のほか、この前後で出生数が大きく変わるため人口（曝露）の推計の誤差が死亡率に出ている可能性（推測）もあり、ここでは分けられない。生まれ年の式は当てはめる数が多い（103 対 64）ことにも注意。

## 計画からのずれ
- H2 は計画どおり全年齢で判定し「外れ」（いちばん鈍ったのは10〜14歳で、死亡数が少なく率のぶれが大きい区分）。40歳以上に限った見方は結果を見た後に足した。
- 「3つの測り方すべてで鈍った区分」という見方と、2019→2024年の Arriaga 分解（計画は2000→2010・2010→2019）は結果を見た後に足した。
- 若い年齢（40歳未満）は死亡数が少なく、コロナ期の上振れの理由も分けられないので、記事では扱わない（数字は results にある）。
- 問い直しは計画になく、結果を見た後に決めた。
- R2 は計画では「2011年を除き、その年をはさむ区間は前後の年で補間」だった。区間の端の年の比べ方では2011年が端に来ないので結果は基本と同じになるため、記事では2000年代・2010年代それぞれの直線の傾き（2011年を除く）に置き換えた。2011年を含む直線・補間した直線はレビュー後に足した。
- H3 の基準直線（2010〜2019年）には2011年を含めていて、R2 と扱いが違う。2011年を除いた場合はレビュー後に足した。
- 問い直しの両端の生まれ年を除いた比較、65〜69歳の10年の改善率と5年の差の関係、データの性質の確かめ（src/zz_f291_06_レビュー対応.py）はレビュー後に足した。

## 言えないこと
- 改善が鈍った理由（病気の種類・医療・暮らしの変化など）は、このデータでは分けられない。
- 高い年齢の改善率は、選ぶ年や測り方で大きく動く。「どの年齢で止まった」と1つに決めるのは難しい。
- 2020〜2024年の上振れは、2010〜2019年の直線を延ばした値との比で、超過死亡の公式の推計とは違う。新型コロナだけの影響とも言えない。
- 90歳以上の死亡率はデータの性質に注意が要る。JMD は高い年齢の人口（曝露）を、死に絶えた世代の方法や生き残りの比の方法で推計しており、まだ生きている人の多い最近の世代では仮定に頼る部分が大きいと思われる（推測）。各歳の死亡数の98%は小数で（90歳以上の2000年以降は99%）、按分などの推計が入っている。死亡率はならし（Kannisto など）をかけない生の値。H4 と H3 の95歳以上の判定は、このデータに乗っている。
- JMD の100歳以上は人数が少なく、推計の誤差が大きい（推測）。
- 健康や生活についての助言、医療政策の評価はしない。

## レビューで直したこと
独立レビュー（メインで実施）：別の環境で流し直して19ファイルがバイト単位で一致し、数字もほぼ一致。指摘12件を反映した。
- 問い直しの読み方：r5 は「その世代の改善」でなく「5年上の世代と比べた同じ年齢での低下」。2009→2019年の65〜69歳は1945〜49年生まれを端に含まず、世代だけなら男1.46%・女1.49%ほどになるはずで実際（0.98%・0.85%）と合わないため、10年の鈍りとのつながりを（推測）とし、題名から世代の部分を外した。
- 式の比較：調整済み R² は参考程度と明記（5年の差の重なり、APC なし）。両端の生まれ年を除いた結果を足し、結論を男に限った（女は0.520対0.507で同じくらい）。
- 90歳以上のデータの性質（曝露の推計方法〔推測〕、死亡数の98%が小数、ならしなし）を「言えないこと」に足し、H4・H3 の95歳以上がこれに乗ることを明記。
- R2 が計画（補間）と違う直線の傾きだったことを「ずれ」に開示し、2011年を含む直線（男の65〜69歳 1.56、除くと1.35）・補間の直線を足した。
- H3 の基準直線は2011年を含むことを注記し、除いた場合（0.0〜0.9ポイント、判定は変わらず）を足した。
- R3 で80〜94歳も小さくなること（男 3.3〜5.6ポイント）を明記。
- 4章の見出し、H4 の「0.75%以下」、題名・結論の「1〜1.6%」、地図の「女は3%前後・男は2%前後（2000年代は男にとって高い時期だった可能性〔推測〕）」、H1 の判定を1つの文に、5章の「女は70〜90代」。
