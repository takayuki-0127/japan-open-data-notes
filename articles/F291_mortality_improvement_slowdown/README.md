# F291 死亡率の改善は、年齢のどこで止まりつつあるのか？（精選モード A. 保険数理・リスク Q10）

日本の死亡率は長く毎年下がってきた。その「改善」がいまどの年齢で鈍っているのかを、日本版死亡データベース（元は人口動態統計）の1947〜2024年の死亡数と人口から、5歳階級ごとに測った。2020〜2024年（新型コロナなどの時期）の上振れは、それ以前の傾向と分けて見た。F86（Lee–Carter）・F268（生命表と年金現価）の続き。

- 計画（事前登録）：[PLAN.md](PLAN.md)（コミット 752ca70。分析のコミットはすべてこの後）
- 新しい取得はない。F86 で取得した JMD と、F268 で取得した簡易生命表を写して使った。

## 問い
- 2000年代と2010年代で、死亡率の改善率（年あたり、%）はどの年齢で下がったか
- 2020〜2024年の死亡率は、2010年代の傾向からどれだけ上に出たか
- 平均寿命の伸びは、どの年齢の改善から来ていたか（Arriaga 法）
- 問い直し（結果を見た後に追加）：65〜74歳の鈍りは「時期」のせいか、「生まれ年（世代）」のせいか

## データ
| ファイル | 中身 | 出典 |
|---|---|---|
| data/raw/jmd_mx_long_from_F86.csv | 男女×年（1947〜2024）×各歳（0〜99歳、100歳以上）の死亡数・曝露人口・死亡率 | 国立社会保障・人口問題研究所「日本版死亡データベース（JMD）」（元は人口動態統計・人口推計）。F86 で取得 |
| data/raw/mhlw_qx_from_F268.csv | 簡易生命表（2014・2019・2024年）の各歳の死亡率 qx | 厚生労働省「簡易生命表」。F268 で取得 |
| data/group_mx.csv | 5歳階級の死亡率（Σ死亡数÷Σ曝露人口） | 上を整形 |
| data/MANIFEST.json | 元ファイルの md5 | |

## 手法
- 改善率：r = −Δln m ÷ 年数 ×100（年あたり%）。m は5歳階級の死亡率。2000年代＝1999→2009年、2010年代＝2009→2019年、コロナ期を含む直近＝2019→2024年（5年）。
- 改善率の地図：10年の窓を1年ずつずらして（終わりの年 1957〜2024）、年齢×窓で並べた。
- コロナ期の上振れ：区分ごとに2010〜2019年の ln m に直線を当てはめ、2020〜2024年に延ばした値と実際の比を出した。
- 平均寿命の年齢分解：各歳の生命表（a=0.5、0歳は0.1、100歳以上は開いた階級）と Arriaga 法。
- 問い直し：各歳50〜89歳の5年の改善率（1995〜2019年）を、「年齢＋時期」と「年齢＋生まれ年」のダミーで当てはめ、自由度調整済み R² を比べた。生まれ年ごとに、年齢ごとの平均からの差も出した。

## 計画と結果
| 仮説 | 基準 | 結果 | 判定 |
|---|---|---|---|
| H1 鈍りは広い | 40歳以上13区分のうち、2010年代の改善率が2000年代より小さい区分が男女とも7以上 | 男9・女12（区間の端の年で計算） | 支持。ただし頑健性では男2〜4・女6で外れ（下） |
| H2 鈍りの中心は高齢 | いちばん大きく鈍った区分が男女とも65歳以上 | 男女とも10〜14歳（約4.2ポイント）。40歳以上に限ると男女とも65〜69歳 | 外れ |
| H3 コロナ期は傾向と別の上振れ | 2022〜2024年、75歳以上の各区分で傾向より平均5%以上高い（男女とも） | 75〜79歳 男19.7%・女16.5%、80〜84歳 15.3%・10.2%、85〜89歳 9.1%・10.3%、90〜94歳 8.8%・9.7%、95〜99歳 5.0%（4.99）・6.3%、100歳以上 2.6%・2.4% | 外れ（95歳以上で届かない） |
| H4 いちばん高い年齢では改善がほぼ止まった | 2010年代の90〜94・95〜99歳の改善率が男女とも年1%未満 | 90〜94歳 男0.62・女0.62、95〜99歳 男0.09・女−0.11 | 支持。ただし頑健性では90〜94歳の女が1.15・1.14、男が1.05で外れ |

主な数字（年あたりの改善率、2000年代→2010年代）：
- 65〜69歳：男 2.96→0.98、女 3.09→0.85。70〜74歳：男 2.72→1.26、女 3.00→1.63。この2区分は3つの測り方すべてで鈍った（男女とも）。
- 女の80〜84・85〜89歳も3つすべてで鈍った（85〜89歳 2.78→1.05）。
- 男の40〜59歳はむしろ速まった（40〜44歳 1.37→3.61）。
- 2019→2024年：40歳以上の26区分のうち17区分で改善率がマイナス（死亡率が上がった）。
- 平均寿命：男 2000→2010年 +1.82年、2010→2019年 +1.86年、2019→2024年 −0.27年。女 +1.71年、+1.19年、−0.29年。2010年代の伸びのうち65歳以上の改善から来た分は男51%・女69%。

## 頑健性
| 確かめ | 結果 |
|---|---|
| R1 5年の窓（2004→2009 と 2014→2019） | H1 男4・女6（外れ）、H2 外れ（15〜19歳）、H4 女の90〜94歳 1.15（外れ） |
| R2 10年の直線の傾き、2011年（東日本大震災）を除く | H1 男2・女6（外れ）、H2 外れ、H4 男の90〜94歳 1.05・女1.14（外れ） |
| R3 H3 の傾向を2005〜2019年で当てはめる | 75〜79歳 男19.2%・女14.5%、95〜99歳 1.1%・2.0%、100歳以上 −1.1%（外れのまま） |
| R4 簡易生命表（2014→2019年）と JMD の5年改善率の照合 | 1歳以上の40区分で相関0.963、差の絶対値の平均0.28ポイント |

**区間の端の年で測ると、高い年齢の「鈍り」は大きく見えるが、5年の窓や直線の傾きでは男の75歳以上・女の90歳以上の鈍りは消える。** 端の年（1999・2009・2019年）の流行などの年ごとのぶれが、高い年齢の改善率を大きく動かすためとみられる（推測）。3つの測り方すべてで鈍ったのは、男女とも65〜74歳、女の50〜54・80〜89歳だけだった。

## 問い直し（結果を見た後に追加）
65〜74歳の鈍りは時期の効果か、生まれ年の効果か。
- 各歳50〜89歳の5年の改善率（1995〜2019年）：自由度調整済み R² は、男で「年齢＋生まれ年」0.564 対「年齢＋時期」0.192、女で 0.507 対 0.520。
- 65〜74歳の5年の改善率を生まれ年で分けると、1945〜49年生まれが男0.88%・女0.98%で、1940〜44年生まれ（男1.69・女2.18）・1950〜54年生まれ（男2.04・女2.00）より低い。
- 男では世代で見たほうがよく当てはまり、女では差がない。1945〜49年生まれの低さは、終戦前後に生まれた世代の育った環境（推測）のほか、この前後で出生数が大きく変わるため人口（曝露）の推計の誤差が死亡率に出ている可能性（推測）もあり、ここでは分けられない。生まれ年の式は当てはめる数が多い（103 対 64）ことにも注意。

## 計画からのずれ
- H2 は計画どおり全年齢で判定し「外れ」（いちばん鈍ったのは10〜14歳で、死亡数が少なく率のぶれが大きい区分）。40歳以上に限った見方は結果を見た後に足した。
- 「3つの測り方すべてで鈍った区分」という見方と、2019→2024年の Arriaga 分解（計画は2000→2010・2010→2019）は結果を見た後に足した。
- 若い年齢（40歳未満）は死亡数が少なく、コロナ期の上振れの理由も分けられないので、記事では扱わない（数字は results にある）。
- 問い直しは計画になく、結果を見た後に決めた。

## 言えないこと
- 改善が鈍った理由（病気の種類・医療・暮らしの変化など）は、このデータでは分けられない。
- 高い年齢の改善率は、選ぶ年や測り方で大きく動く。「どの年齢で止まった」と1つに決めるのは難しい。
- 2020〜2024年の上振れは、2010〜2019年の直線を延ばした値との比で、超過死亡の公式の推計とは違う。新型コロナだけの影響とも言えない。
- JMD の100歳以上は人数が少なく、推計の誤差が大きい（推測）。
- 健康や生活についての助言、医療政策の評価はしない。
