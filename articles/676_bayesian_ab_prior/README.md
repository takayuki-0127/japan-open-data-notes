# 676 ベイズの A/B テストで、事前分布を強く置くと、効果の推定と「勝つ確率」はどれだけ動くのか（手法の解説・正解の分かるデータで試す）

ベイズの A/B テストでは、申込み率に事前分布を置き、データと合わせた事後分布から「B の伸び」と「B が A に勝つ確率」を出します。事前分布を A・B で同じにして強く置くと、両方の申込み率が事前の平均へ引き寄せられ、差は0の方へ縮みます。**ここでは、本当の伸びが分かる架空の A/B テストで、事前分布の強さ（無情報・弱い・強い）と1案あたりの人数を変え、伸びの推定と勝つ確率がどれだけ動くかを比べました（各設定400回）。** 数字は置いた申込み率と人数で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A676 | 事前分布の強さで、伸びの推定と勝つ確率はどれだけ動くか | A の申込み率 5%、B は本当に 0%・+5%・+10%（相対の伸び）。1案 1,000・5,000・20,000人。事前分布は A・B とも同じベータ分布：無情報 Beta(1,1)、弱い Beta(5,95)（100人ぶん）、強い Beta(500,9500)（1万人ぶん）。事後分布から4,000回引いて、伸び（B/A−1）の事後平均と P(B>A) を出す。各400回、seed 676 | `src/a676_bayes_prior.py` |

## 主な結果
- **本当の伸び +10% のとき、伸びの事後平均（400回の平均）は、強い事前で 1案1,000人 +1.1%、5,000人 +3.2%、20,000人 +6.7%**。無情報と弱い事前では 5,000人 +9.8%・+9.6%、20,000人 +10.2%・+10.1%
- 「勝つ確率が95%を超えた」割合（本当は +10%）は、5,000人で無情報26.3%・弱い25.5%・強い4.0%、20,000人で71.5%・71.3%・57.8%
- 本当は差がないときに「勝つ確率95%超」になった割合は、無情報・弱い事前で5〜7%、強い事前で0〜1.8%
- 弱い事前（100人ぶん）は、1案1,000人以上ではほぼ無情報と同じ結果だった
- 無情報の事前でも、1案1,000人では伸びの事後平均が +13.7%と大きめに出た（B/A の比は、A の申込み率がばらつくと平均で大きく出るため）
- 例（1案5,000人、本当は +10%、観測では +3.8%）：事後平均は無情報 +4.2%、強い +1.4%。勝つ確率は66%と60%
