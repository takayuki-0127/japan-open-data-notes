# F191 お金の量を増やすと、貸出は増えたのか？（マネタリーベース・マネーストック・貸出の時系列と構造変化）

## 問い
日本銀行は2001年の量的緩和、2013年の量的・質的緩和などで、お金の量（マネタリーベース）を大きく増やしてきました。そのあいだに、世の中に出回るお金（マネーストック M2）と、銀行の貸出はどれだけ増えたのか。お金の量の伸びと貸出の伸びには、時期をずらしても関係が見えるのか。関係は時期によって変わったのか。

## データ
日本銀行「時系列統計データ検索サイト」の API で取得（月次、2026年11月5日取得）。`data/raw/boj_raw.csv`（長い形）→ `data/monthly.csv`（月×系列、億円）。

| 名前 | 系列コード | 内容 | 期間 |
|---|---|---|---|
| mb | MD01 / MABS1AN11 | マネタリーベース 平均残高 | 1970/01〜2026/10 |
| mb_current | MD01 / MABS1AN113 | 日銀当座預金 平均残高 | 1981/04〜 |
| mb_notes | MD01 / MABS2AN116 | 日本銀行券発行高 平均残高 | 1970/01〜 |
| m2 | MD02 / MAM1NAM2M2MO ＋ MAMS3ANM2C | M2 平均残高（2003/03 以前は旧 M2+CD の動きで遡ってつないだもの） | 1998/04〜2026/09 |
| m3 | MD02 / MAM1NAM3M3MO | M3 平均残高 | 2003/04〜 |
| loan_banks | MD13 / FAAPOBAL1 | 貸出・預金動向：貸出 平均残高（都銀等＋地銀＋地銀Ⅱ） | 1991/07〜2026/09 |
| loan_shinkin | MD13 / FAAPOBSB | 同 信用金庫 | 2000/01〜 |
| dep_banks | MD13 / FAAPOBRDCD | 同 実質預金＋CD | 1991/07〜 |
| loan_dom_avg / loan_dom_end | MD11 / DLCLBADBLTTO・DLCLBEDBLTTO | 国内銀行 銀行勘定 貸出金 平均残高／月末残高 | 1998/04〜2026/08 |

- M2 のつなぎ目：重なる2004/04〜2008/04 で、新旧の前年比の差は平均 −0.02 ポイント（最大 0.11）。
- 伸びはすべて前年同月比（対数、%）で見ています（季節の動きを除くため）。

## 手法
1. 倍率：1998/04・2001/02・2013/03 などから直近までの伸び。
2. 前年比どうしの相関：お金の量の側を0〜36か月ずらす。無関係でも出る幅は、MB の前年比を24か月のブロックで並べ替えて作る（2,000回）。
3. 回帰：貸出の前年比 ＝ a ＋ b × お金の量の前年比（ずれ k か月）、Newey–West の標準誤差（18か月）。
4. グレンジャー因果：月次の対数差の VAR（月ダミー、ラグは AIC、最大12）。
5. 構造変化：上の回帰の係数と切片が変わる時点を Bai–Perron 型の動的計画法で探す（区間は最低24か月、区切りは最大4、BIC で選択）。
6. 緩和の出来事の前後24か月の増減（2001/03、2006/03、2013/04、2016/01、2020/04、2024/03）。
7. 代替案：暦年の平均残高の伸び率どうしの比較（26年、年の並べ替え検定 10,000回）。

## 結果
- 倍率（1998/04→2026/09）：マネタリーベース 9.7倍（55兆→533兆円）、M2 2.2倍、銀行の貸出 1.17倍（516兆→602兆円）。
  - 2013/03→2026/09：MB 3.96倍、M2 1.55倍、貸出 1.49倍。
  - 2001/02→2006/02（量的緩和の期間）：MB 1.72倍、M2 1.11倍、貸出 0.84倍（減少）。
  - M2÷MB は1998年の10.7から2022年4月に1.75まで下がり、2026年9月は2.43。
- 前年比の相関（1999/04〜）：MB→貸出はずれ0で −0.10、いちばん高いのはずれ36か月で 0.15。無関係でも出る幅（95%）は −0.51〜+0.39 で、その中に収まる（並べ替え p=0.68）。
- 回帰：MB→貸出の係数はずれ0〜24か月で −0.03〜0.00（p≥0.55、R² 0.01以下）。M2→貸出はずれ0で 0.60（p=0.04、R² 0.07）。MB→M2 は 0.054（p<0.001、R² 0.24）。
- グレンジャー：MB→貸出 p=0.55（2013年以降 0.36）。逆向きの貸出→MB は p<0.001。MB→M2 は p=0.008。
- 構造変化：区切りは上限の4つ（2005/10、2009/12、2012/12、2020/04）が選ばれた。区間ごとの係数は −0.17〜+0.17 で、符号も入れ替わる。区間の貸出の伸びの平均は −4.5%（1999〜2005年）→ +1.5% → −0.7% → +2.3% → +3.4%（2020年以降）。
- 出来事の後24か月：MB は量的緩和で +47%、量的・質的緩和で +101% だったが、貸出は −9%・+5%。マイナス金利の解除（2024/03）のあとは MB −14% に対して貸出 +8%。
- 年次（代替案）：MB と貸出の伸びの相関 −0.04（1年ずらして −0.05、並べ替え p=0.86）。MB が大きく伸びた9年の貸出の伸びは平均 +0.42%、ほかの年は +0.63%。M2 と貸出は 0.33。
- 1999/04〜2005/12 は、貸出の前年比が全月でマイナス。最大の伸びは2020年8月の +6.4%。

## 頑健性
| チェック | 結果 |
|---|---|
| 期間（1999〜、2003〜、2013〜、1999〜2012、コロナ期 2020/03〜2021/12 を除く）×貸出の定義4×ずれ4（MB） | 80通りのうち「はっきりプラス」は0、「はっきりマイナス」27（1999〜2012 年と2013年以降の一部） |
| お金の量の定義（日銀当座預金・銀行券） | どちらも「はっきりプラス」0。銀行券は80通り中64で「はっきりマイナス」 |
| M2・M3 を使う | 「はっきりプラス」13・14、「はっきりマイナス」16・9。期間で向きが変わる（1999〜2012 年はマイナス、2003年以降の全体ではプラス） |
| 年次の伸び率（代替案） | 相関 −0.04、並べ替え p=0.86 |
| 構造変化をずれ0や M2 で探す | 区切りの時期はほぼ同じ（2005/10、2009/11〜12、2012/01〜02、2021/06） |

全体の表は `results/robustness_grid.csv`（400行）。

## 言えないこと
- お金の量を増やさなかったら貸出がどうなっていたかは、このデータでは分からない。相関がないことは「効果がない」ことの証明ではない。
- 貸出は、企業の資金需要、景気、不良債権の処理、政府の資金繰り支援（2020年の実質無利子・無担保融資など）にも大きく左右される。これらは分けていない。
- 貸出・預金動向は大手・地方銀行の集計で、信用金庫や政府系金融機関などは一部しか含まない。
- 前年比どうしの相関は、ゆっくり動く系列どうしだと偶然でも大きく出やすい。ブロックの並べ替えで幅を示したが、幅は広い。
- 構造変化の区切りの数は BIC が上限まで選んでおり、平均の伸びの変化を拾っている面が大きい。
- これは過去の動きの記述で、金融政策の良し悪しや、投資の判断を示すものではない。
