# 759 正解のラベルが1割まちがっていると、モデルの正解率はどれだけ低く見えるのか（手法の解説・正解の分かるデータで試す）

モデルの成績は、テストデータの「正解」のラベルと比べて測ります。そのラベル自体に入力の誤りや記録漏れがあると、モデルが正しく当てても「外れ」と数えられ、成績は本当より低く見えます。**ここでは、架空の解約予測（解約は約30%）で、強いモデル A と弱いモデル B を作り、テストデータ5,000件のラベルを0〜30%まちがえて、正解率・AUC・2つのモデルの差を各200回測りました。まちがい方は「どちらの向きにも入れかわる」と「解約した人の一部が記録されない」の2通りです。** モデルの強さとまちがいの割合は作成者が置いたもので、数字はその置き方で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A759 | ラベルのまちがいで、成績とモデルの差はどれだけ見かけで変わるか | 本当の解約しやすさ η からラベルを作る。A の点数 = η＋雑音（0.8）、B = η＋雑音（1.4）、点数0以上を解約と予測。まちがいの割合 r = 0・5・10・20・30%、各200回。見かけの正解率 = 本当×(1−r)＋(1−本当)×r を確認。seed 759 | `src/a759_label_noise.py` |

## 主な結果
- **正解率**：モデル A の本当の正解率は75.1%。ラベルが5%まちがうと72.6%、10%で70.1%、20%で65.1%、30%で59.9%に見えた。式（本当×(1−r)＋(1−本当)×r）との違いは最大0.1ポイント
- **AUC**：0.777 が10%で0.707、30%で0.594
- **モデルの差も縮む**：A と B の正解率の差は本当は3.77ポイント、10%で3.03、30%で1.45。AUC の差も0.050 が0.037、0.016 に。差はおよそ (1−2r) 倍になる
- **片側のまちがい**（解約した人を「解約していない」と記録）：正解率と再現率はほとんど変わらず（75.1%→75.4%、48.6%→48.7%）、適合率だけが60.3%から10%で54.3%、30%で42.3%に下がって見えた

## 動かし方
```
pip install -r requirements.txt
cd src && python a759_label_noise.py
```
十秒ほどで終わります。`results/summary.csv` にまちがいの割合ごとの成績を書き出します。

## 確かめたこと
- 空のフォルダで流し直し、results・figures がバイト単位で一致した
- 対称のまちがいで、見かけの正解率が式どおりになることを確かめた（差は0.1ポイント以内）

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 759）
- 仮定：η は平均−1.2・標準偏差1.5の正規分布、解約の確率は 1/(1+exp(−η))。テスト5,000件

## 注意（言えないこと）
- シミュレーションの結果。まちがいはモデルの点数と無関係に入れた。点数と関係するまちがい（判断の難しい人ほどまちがう）では、結果が変わる
- 学習データのラベルのまちがい（モデルそのものが弱くなる話）は扱っていない
- 実在の顧客の数字ではない
