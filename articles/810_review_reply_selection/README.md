# 810 低評価に返信した店は、その後の平均が上がるのか？（口コミと星の数）

低評価の口コミに店が返信を始めると、その後の星の平均が上がった、という比べ方をよく見ます。ところが、返信を始めるのは「最近たまたま低評価が続いた店」が多く、たまたまの落ち込みは、何もしなくても元に戻ります（平均への回帰）。**ここでは、作成者が乱数で作った架空の店3,000軒（本当の満足度を作成者が置き、返信の効き目を0または+0.10と置いたもの）で、4つの比べ方が返信の効き目をどれだけ正しく見積もるかを数えました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A810 | 低評価に返信を始めた店の、その後の星の平均の上がり方は、返信の効き目と言えるか。どの比べ方なら効き目を正しく見積もれるか | 架空の店3,000軒。本当の満足度は平均3.8・標準偏差0.35の正規分布（2.5〜4.8で切る）で、期間中は変わらない。口コミは、前の期間A（30件）→ 直前の期間B（10件）→ 返信を始めたあとの期間C（20件）の順に付く。1件の星は、平均が本当の満足度になる1〜5の分布から引く（801 と同じ作り方）。期間Bの平均が3.3以下の店（低評価が続いた店）は60%、それ以外の店は10%の確率で返信を始める。返信の効き目は、期間Cの本当の満足度に足す（基本0、確かめで+0.10）。比べ方は4つ：①返信した店の前後（期間B→C）、②①から返信しなかった店の前後を引く、③期間Bの平均が同じ0.1刻みの店どうしで、返信した店としなかった店の前後を比べる、④返信した店の期間Cを、前の期間Aと比べる。店を作り直して200回の平均。確かめとして、「やる気のある店」（3割）が返信しやすく、返信と関係なく期間Cに0.15よくなる場合と、期間Bの件数を5・10・20件に変えた場合も数えた。seed 810 | `src/a810_reply.py` |

## 主な結果

### 期間ごとの星の平均（1回分、店3,000軒、返信の効き目0）
| | 店の数 | 本当の満足度 | 前の期間A | 直前の期間B | 返信のあとC |
|---|---|---|---|---|---|
| 低評価に返信した店 | 508 | 3.605 | 3.594 | **3.487** | **3.582** |
| 返信しなかった店 | 2,492 | 3.836 | 3.836 | 3.855 | 3.837 |

- 返信の効き目は0と置いたのに、返信した店の平均は3.49から3.58に上がった。期間Bの低さは、たまたまの落ち込みだった

### 比べ方ごとの見積もり（200回の平均）
| 比べ方 | 本当の効き目0 | 本当の効き目+0.10 | 効き目0・やる気のある店が返信しやすい |
|---|---|---|---|
| ①返信した店の前後（B→C） | **+0.112** | +0.210 | +0.187 |
| ②返信しなかった店の前後を引く | **+0.135** | +0.234 | +0.173 |
| ③直前の平均が同じ店どうしで比べる | −0.002 | +0.098 | +0.053 |
| ④前の期間Aと比べる | 0.000 | +0.100 | +0.079 |

- ①は、効き目0でも+0.11、効き目+0.10なら+0.21と、たまたまの落ち込みの戻り分だけ大きく見積もった
- ②は、返信しなかった店の平均がわずかに下がる（たまたま高かった店が戻る）ため、①よりさらに大きくなった
- ③と④は、効き目0なら0、+0.10なら+0.10を当てた
- ただし「やる気のある店ほど返信し、返信と関係なく店もよくなる」場合は、③も+0.05、④も+0.08と、返信の効き目と店の努力を分けられなかった

### 直前の期間Bの件数と、①の見かけの効き目（100回の平均、効き目0）
| 期間Bの件数 | ①の見かけの効き目 |
|---|---|
| 5件 | +0.192 |
| 10件 | +0.113 |
| 20件 | +0.059 |

- 返信を決めるときに見た直前の口コミが少ないほど、たまたまの落ち込みが大きく、見かけの効き目も大きくなった

## 動かし方
```
pip install -r requirements.txt
cd src && python a810_reply.py
```
30秒ほどで終わります。`data/shops.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の6ファイルがバイト単位で一致した（cmp、約28秒）
- 返信の効き目を+0.10に置くと、③と④は+0.10前後を当て、①と②は+0.21〜+0.23に大きく見積もった（上の表）
- 期間Bの件数を5・10・20件に変えると、①の見かけの効き目は+0.19・+0.11・+0.06と変わった
- 「やる気のある店」を入れると、どの比べ方も効き目0を当てられなかった

## データ
- `data/shops.csv`：架空の店3,000軒（shop_id・true（本当の満足度）・mean_A・mean_B・mean_C（期間ごとの星の平均）・dip（期間Bが3.3以下か）・reply（返信したか））

## 注意（言えないこと）
- 架空のデータです。返信を始める確率、期間ごとの件数、本当の満足度の分布は作成者が置いたもので、見かけの効き目の大きさはこれで決まります
- 実際に返信に効き目があるかどうかは、ここでは何も言えません。言えるのは「前後を比べるだけでは、効き目0でも上がって見える」というところです
- ③と④が当たったのは、「低評価が続いた店の中で、返信するかどうかはでたらめに決まる」と置いたからです。返信する店が、ほかの面でも店をよくしている場合は、③と④でも分けられません。④は、本当の満足度が期間中に変わらないと置いたことにもよります
- 返信を見た客の書き方が変わることや、返信で口コミの件数が増えることは入れていません
- 実際の口コミサイトの数字を表すものではありません
- 件数が少ない店の星の振れそのものは、関連する記事 801 で扱っています
