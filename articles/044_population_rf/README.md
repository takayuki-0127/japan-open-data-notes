## もとのリポジトリの説明

以下は、もとのリポジトリ `japan-population-2050` の README です（同じリポジトリにあったほかの記事の分も含みます）。

### japan-population-2050：市区町村の将来推計人口（社人研）を、自然増減と人の移動に分け、何が2050年を決めているかを調べる

国立社会保障・人口問題研究所「日本の地域別将来推計人口（令和5（2023）年推計）」の結果表（総人口・封鎖人口・65歳以上の割合）を使ったリポジトリです。1,728市町村（政令市は市全体、東京23区は区ごと、福島県浜通り地域を除く）が対象です。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| P1 | 2050年に人口が半分以下になる市町村はいくつか。変化は出生・死亡と移動のどちらによるか | 推計人口と封鎖人口（人の移動がないと仮定した推計）の差による分解、4つのタイプ分け | `src/p1_decompose.py` |
| P2 | 2050年の推計人口は、市町村のどんな特徴で決まっているか | ランダムフォレストと重回帰（5分割交差検証）、並べ替え重要度、部分依存 | `src/p2_rf.py` |

#### 主な結果
- **P1**：2050年に2020年の半分未満になるのは341市町村、70%未満は1,046、増えるのは77。出生と死亡だけで見ると、99%の市町村が減少（自然減）。人の移動でプラスになるのは492市町村で、東京23区・政令市・その周辺が中心。人口が増えるのは中央区（124.7）・流山市（120.9）・港区（120.0）など
- **P2**：特徴10個のランダムフォレストで、交差検証の決定係数0.90（RMSE 5.7、重回帰は6.0）。並べ替え重要度は65歳以上の割合が群を抜いて大きく、次が転入超過・15歳未満の割合。推計は、ほぼ「今の年齢構成」で決まっている

#### 動かし方
```bash
pip install -r requirements.txt
cd src
python p1_decompose.py
python p2_rf.py
```

#### 注意
- 将来推計は、過去（主に2015〜2020年）の傾向が続くと仮定した計算で、予言ではありません。P2 は「推計が何によって決まっているか」を見たもので、将来の人口そのものを予測したものではありません
- 封鎖人口との差は、国内の移動と国際移動の両方を含みます
- 説明に使った特徴（SSDSE-A）は年がそろっていません（転入・転出は2024年など）
