# 847 流入元の違う再生数を合わせると、何を読み違えるのか？（SNSと動画）

動画サイトの再生は、検索から来たもの、おすすめ表示から来たもの、外部のリンクや SNS の共有から来たものが混ざっています。流入元（再生がどこから来たか）ごとに、最後まで見てもらえる割合はもともと違います。全部を合わせた数字だけを見ると、流入元の内訳が変わっただけで、良くなったものが悪くなったように見えたり、良い動画が悪い動画に見えたりします。**ここでは、作成者が乱数で作った架空の動画チャンネル（流入元ごとの完了率の水準と、動画ごとの中身の良さを作成者が置いたもの）で、(A) 月の比較と (B) 動画120本の比較で、全部を合わせた完了率がどれだけ読み違えるかを数えました。**

再生数の平均が1本のバズで動く話は関連する記事 840、長さの違う動画の維持率の比べ方は 841 で扱っています。表示が広がるとクリック率が下がって見える関連する記事 842 も「分けるとどれも上なのに、合わせると下」という同じ形を扱いますが、842 は引きの強い投稿ほど表示が遠い人に広がる、という投稿の良さそのものが内訳を決める場合です。この記事は「流入元の内訳が違うものを合わせること」に絞ります。

## 主な結果

### (A) どの流入元でも上がったのに、合計では下がった
| 流入元 | 先月の再生 | 先月の完了率 | 今月の再生 | 今月の完了率 |
|---|---|---|---|---|
| 検索 | 40,000 | 55.2% | 40,000 | 56.8% |
| おすすめ表示 | 30,000 | 24.8% | 140,000 | 27.3% |
| 外部リンク | 15,000 | 45.0% | 15,000 | 47.8% |
| SNSの共有 | 15,000 | 39.5% | 15,000 | 42.0% |
| 合計 | 100,000 | **42.2%** | 210,000 | **35.4%** |

- 4つの流入元すべてで完了率が上がったのに、合計の完了率は42.2%から35.4%に下がった。完了率の低いおすすめ表示の割合が30%から67%に増えたため
- 今月の完了率を先月の流入元の内訳に合わせて計算し直すと44.4%で、先月の42.2%より上がっていた

### (B) 動画120本を並べる（1回分）
| | 全部を合わせた完了率 | 流入元ごとの平均との差 |
|---|---|---|
| 中身の良さとの順位の相関 | 0.57 | **0.98** |
| 上位10本の当たり | 60% | 90% |

- 全部を合わせた完了率は、おすすめ表示からの割合との順位の相関が−0.81で、中身の良さより流入元の内訳をよく表していた
- 合わせた完了率の上位10本は、おすすめ表示の割合の中央値が18%だった（120本全体では49%、本当の上位10本では31%）。おすすめ表示に多く出た動画は、中身が良くても下に並んだ

### (B) 300回の平均と、置き方を変えた確かめ
| 置き方 | 順位の相関（合わせた完了率） | 順位の相関（流入元ごとの差） | 上位10本の当たり（合わせた完了率） | 上位10本の当たり（流入元ごとの差） |
|---|---|---|---|---|
| 基本 | 0.60 | 0.99 | **38%** | **89%** |
| 流入元どうしの差を半分 | 0.83 | 0.99 | 59% | 90% |
| 流入元どうしの差なし | 0.99 | 0.99 | 89% | 89% |
| 中身の差を大きく（10ポイント） | 0.84 | 1.00 | 57% | 94% |
| 中身の差を小さく（2ポイント） | 0.28 | 0.94 | 22% | 78% |
| 内訳のばらつきを小さく（Beta(8,8)） | 0.83 | 0.99 | 58% | 90% |
| 良い動画ほどおすすめ表示が多い | 0.36 | 0.98 | 21% | 86% |
| 良い動画ほどおすすめ表示が少ない | 0.78 | 0.98 | 56% | 87% |
| おすすめ表示では中身が半分しか効かない | 0.48 | 0.97 | 32% | 78% |
| おすすめ表示の完了率が中身と別に振れる（5ポイント） | 0.57 | 0.86 | 40% | 63% |

- 流入元どうしの差がなければ、合わせても読み違えなかった（89%と89%）。読み違えの大きさは、流入元どうしの完了率の差と、動画ごとの内訳の違いの大きさで決まった
- 良い動画ほどおすすめ表示に多く出る置き方では、合わせた完了率の当たりは21%まで下がった。良い動画ほど完了率の低い流入元から多く見られるため
- 流入元ごとの差で並べる方法は、どの置き方でも合わせた完了率より当たったが、おすすめ表示の完了率が中身と関係なく振れる置き方では63%まで下がった。この方法は「中身の良さはどの流入元でも同じように効く」という前提に近いほどよく当たる

## 動かし方
```
pip install -r requirements.txt
cd src && python a847_traffic_source_mix.py
```
5秒ほどで終わります。`data/` の2つのファイルもこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp。`src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約3秒）
- 図3枚を開き、日本語・重なり・軸を確かめた
- 流入元どうしの完了率の差をなくすと、2つの並べ方の当たりがほぼ同じ（順位の相関0.99と0.99）になり、読み違えが流入元の差から来ていることを確かめた

## 注意（言えないこと）
- 架空のデータです。流入元ごとの完了率の水準（55%・25%・45%・40%）、動画ごとの内訳のばらつき、中身の良さの大きさは作成者が置いたもので、読み違えの大きさはこれで決まります。たとえば上位10本の当たり38%は、置き方を変えると21〜89%と動きました
- 「流入元ごとの平均との差」がよく当たったのは、中身の良さがどの流入元でも同じだけ完了率を動かすと置いたからです。この前提から外れると当たりは下がりました（確かめの表の下の2行）
- (A) の「先月の内訳に合わせて計算し直す」は、内訳の変化を取り除いた比べ方の一つです。どの月の内訳に合わせるかで数字は少し変わります
- 実在の動画サイトの流入元の分け方、完了率や維持率の定義、おすすめ表示の決め方を表すものではありません
