# 1086 人数が倍になると、つながりの密度はどう変わるのか？（つながり）

会員どうしのつながりの「密度」は、つながりのある2人の組の数を、ありうる2人の組の数で割った値です。人数が倍になると、ありうる組はおよそ4倍に増えます。1人が付き合える相手の数には限りがあるので、人数が増えると密度は下がります。そのため「密度が下がった」を「やり取りが薄くなった」と読むと、人数が増えただけのことを取り違えます。**ここでは、作成者が乱数で作った架空の会員制の趣味のコミュニティ（会員1人の月のやり取りの回数と、相手に選ばれやすさを作成者が置いたもの）で、1人のやり取りの回数を同じに置いたまま会員を50〜800人に変え、密度・1人あたりの相手の数・1人あたりのやり取りの回数がどう動くかを数えました。「つながりあり」を月1回以上・3回以上・5回以上のやり取りで数える3通りと、小グループの中の相手に送る割合を変えた確かめも行いました。さらに人数の違うコミュニティ120か所を並べ、密度で「活発なコミュニティ」を選べるかを数えました。**

例のコミュニティは架空のもので、実在の SNS・会社の名前は使っていません。会員は番号だけで、個人を表すものではありません。

関連する記事：同じ企画の 1078「双方向で数えるか片方向で数えるかで、つながりの数は何倍違うのか？」はつながりの向きの数え方を、1085「何か月分の記録でつながりを数えるかで、顔ぶれはどう変わるのか？」は数える期間の長さを扱います。この記事は1か月の記録で数え、人数を変えたときの密度の読み方に絞ります。1077「「自分の知り合いは、自分より知り合いが多い」と感じるのはなぜか？」は同じ人数の中での相手の数の偏りを扱っています。

## 主な結果

### 人数と密度・相手の数（基本 g=0.5、各10回の平均、`results/by_size.csv`）
| 会員の数 | 1人あたりのやり取りの回数 | 密度（月1回以上） | 相手の数（月1回以上） | 密度（月3回以上） | 相手の数（月3回以上） | 相手の数（月5回以上） |
|---|---|---|---|---|---|---|
| 50 | 20.73回 | 0.42384 | 20.768人 | 0.0978 | 4.792人 | 1.432人 |
| 100 | 20.489回 | 0.25479 | 25.224人 | 0.03653 | 3.616人 | 0.878人 |
| 200 | 20.2825回 | 0.1395 | 27.761人 | 0.01413 | 2.812人 | 0.709人 |
| 400 | 20.13325回 | 0.07369 | 29.402人 | 0.00609 | 2.4305人 | 0.559人 |
| 800 | 19.93225回 | 0.03748 | 29.95人 | 0.00286 | 2.2885人 | 0.52825人 |

### 200人→400人（倍）にしたときの比（`results/doubling.csv`）
| 物差し | 比（基本 g=0.5） |
|---|---|
| 1人あたりのやり取りの回数 | 0.9926倍 |
| 密度（月1回以上） | **0.5282倍** |
| 1人あたりの相手の数（月1回以上） | 1.0591倍 |
| 密度（月3回以上） | 0.4311倍 |
| 1人あたりの相手の数（月3回以上） | 0.8643倍 |
| 密度（月5回以上） | 0.3932倍 |
| 1人あたりの相手の数（月5回以上） | 0.7884倍 |
| 参考：相手の数がまったく同じなら（式 199÷399） | 0.4987倍 |

- 1人のやり取りの回数は人数で変わらないように置いた（0.9926倍）。これは作成者の置いた前提の写しです
- **それでも200人→400人で、密度（月1回以上）は0.5282倍とほぼ半分になった**。密度の比は「相手の数の比×199÷399」で決まる（式どおり：1.0591×0.4987≈0.5282）。人数が倍になると、相手の数が少し増えても、ありうる組がそれ以上に増えるため
- **1人あたりの相手の数は、「つながり」の数え方で向きが分かれた**。月1回以上なら1.0591倍に増え、月3回以上なら0.8643倍、月5回以上なら0.7884倍に減った。同じ回数を、選べる相手の増えた分だけ広く薄く送るように置いたため（月1回の相手は増え、何度もやり取りする相手は減る）
- 人数の倍ごと（50→100、100→200、200→400、400→800）と g の3通りの12通りで、密度（月1回以上）の比は0.5011〜0.6617倍、相手の数（月1回以上）の比は1.0035〜1.3369倍、相手の数（月3回以上）の比は0.2639〜1.0217倍と動いた。小グループの中で送る割合 g が大きいほど、相手の数は人数で変わりにくく、密度の比は式の0.4987倍に近づいた（g=0.9 の200→400で密度0.5034倍）

### 人数50〜800人の120か所を並べたとき（10回の平均、`results/communities_measures.csv`）
| 物差し | 上位10か所が本当の上位10か所に入っていた割合 | 本当の活発さとの順位相関 | 会員の数との順位相関 | 選んだ上位10か所の会員の数（平均） |
|---|---|---|---|---|
| 密度（月1回以上） | **21%** | 0.3615 | **−0.921** | 63人 |
| 1人あたりの相手の数（月1回以上） | 65% | 0.9123 | 0.3 | 395人 |
| 1人あたりの相手の数（月3回以上） | 63% | 0.9313 | −0.2864 | 151.25人 |
| 1人あたりのやり取りの回数 | 85% | 0.9834 | −0.0088 | 283.75人 |

- 密度で並べると、会員の数とほぼ逆の順になり（順位相関−0.921）、上位10か所は会員の数が平均63人の小さなコミュニティばかりになった。本当に活発な上位10か所に入っていたのは21%だった
- 1人あたりのやり取りの回数が85%といちばん当たったのは、「本当の活発さ」を1人の月の平均の送る回数として作成者が置いたためです（作成者の置いた物差しの写し）。外れた分は、会員ごとの回数の散らばりから来る
- 1人あたりの相手の数は65%・63%で、月1回以上なら人数の多いところ、月3回以上なら人数の少ないところに少し寄った（会員の数との順位相関 0.3 と −0.2864）

| g（小グループの中で送る割合） | コミュニティどうしの活発さの差 | 密度 | 相手の数（月1回以上） | 相手の数（月3回以上） | やり取りの回数 |
|---|---|---|---|---|---|
| 0 | 0.2 | 18% | 56% | 34% | 84% |
| 0 | 0.4 | 24% | 56% | 48% | 86% |
| 0 | 0.8 | 38% | 64% | 52% | 88% |
| 0.5 | 0.2 | 20% | 56% | 46% | 76% |
| 0.5 | 0.4 | 26% | 64% | 62% | 86% |
| 0.5 | 0.8 | 34% | 72% | 74% | 96% |
| 0.9 | 0.2 | 10% | 66% | 60% | 66% |
| 0.9 | 0.4 | 22% | 80% | 78% | 78% |
| 0.9 | 0.8 | 26% | 84% | 94% | 96% |

- **9通りすべてで、密度の当たり（10〜38%）は相手の数（月1回以上、56〜84%）よりも、やり取りの回数（66〜96%）よりも低かった**
- コミュニティどうしの活発さの差が大きいほど、密度でも少しは当たるようになった（g=0 で18%→38%）。人数の違いより活発さの違いが大きくなるため
- g=0.9 では、相手の数がやり取りの回数と同じかそれ以上に当たった（差0.2で66%対66%、差0.4で80%対78%）

## 注意（言えないこと）
- 架空のデータです。1人のやり取りの回数の分布、選ばれやすさの分布、小グループの大きさと割合、「つながり」とする回数は作成者が置いたもので、結果はこれで決まります。とくに1人あたりの相手の数が人数で増えるか減るかは、「つながり」を何回以上で数えるかと、小グループの中で送る割合で入れかわりました
- 1人のやり取りの回数は人数で変わらないと置きました。人数が増えると1人の回数が増える（または減る）コミュニティでは、比はこの記事の値と違います
- 「本当の活発さ」を1人の月の平均の送る回数と置いたので、1人あたりのやり取りの回数がよく当たるのは作りどおりです。活発さを別の意味で決めれば、当たる物差しは変わります
- 実在のコミュニティや社内のやり取りの密度を表すものではありません。この記事は、人数の違う集まりを密度で比べたときに何がずれるかを数えただけです
