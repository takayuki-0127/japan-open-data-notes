# 01 取得

## 小売業の事業所数など（新しく取得）

`data/raw/ssds_retail_raw.json` は、e-Stat「社会・人口統計体系 市区町村データ」
（https://www.e-stat.go.jp/regional-statistics/ssdsview/municipality ）から、2026年10月29日にブラウザの中で取得しました（キーの登録は要りません）。

画面で「地域：全て選択 → 分野 C 経済基盤・キーワード「小売業」→ 項目を選択 → 確定」として一度表示し、そのとき送られる `api_get_result`（POST）の `tops`（年度）だけを書き換えて、年度ごとに送り直しました（行数の上限 `inputNumberOfRows` は 3000 に変更）。画面で年度を1つずつ選んで表示・ダウンロードしても同じ値が取れます。

| 項目コード | 項目 | 取れた年度（SSDS の表記 → 調査の時点） |
|---|---|---|
| C350202 | 小売業事業所数 | 2002・2004・2007（商業統計）、2011年度 → 2012年（経済センサス-活動調査）、2014（商業統計）、2016・2021（経済センサス-活動調査） |
| C350302 | 小売業従業者数 | 同上 |
| C350102 | 小売業年間商品販売額 | 2001・2003・2006・2011・2013・2015・2020年度（それぞれ上の調査の前年の販売額） |
| C210843・C220843 | 事業所数・従業者数（民営）（小売業） | 2012・2014・2016・2021（参考） |

## 再利用したもの（新しい取得なし）

- `data/raw/ssds_pop_raw_from_F46.json`：同じ市区町村データの総人口・65歳以上人口（国勢調査 2005・2010・2015・2020）。F46 で取得したもの
- `data/raw/ipss_projection_from_F45.csv`：国立社会保障・人口問題研究所「日本の地域別将来推計人口（令和5年推計）」の2050年の市区町村人口。F45 で整形したもの
- `data/raw/ssdse_a_area.csv`：統計センター「SSDSE-A 2026」の総面積・可住地面積（B1101・B1103）から抜き出したもの
