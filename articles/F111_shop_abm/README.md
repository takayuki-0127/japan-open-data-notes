# F111 人口が減る町で、店はいつ消えるのか？ エージェントベースのモデルと実データの照合

看板記事シリーズの111本目です。住民と店を1つずつ動かすエージェントベースのモデル（ABM）を作りました。2012→2021年に市区町村で実際に起きた「人口の変化と小売の店の数の変化」で照合したうえで、社人研の2050年の推計人口を入れて投影しています。結果はモデルの前提で大きく動くので、前提を14通りに変えた結果も並べました。

## 問い

- 人口が減った町で、小売の店の数はどれだけ減ってきたか。人口より速く減るのか（実データ）
- 「住民は近い店で買い、売上が固定費を下回る店は閉じる」という単純なモデルで、その減り方を再現できるか
- 同じモデルで2050年まで進めると、小さい町の店と「近くに店がない住民」はどうなるか。答えは前提でどれだけ動くか

## データ

| データ | 内容 | 年 |
|---|---|---|
| 小売業事業所数・従業者数・年間商品販売額 | e-Stat「社会・人口統計体系 市区町村データ」（C350202・C350302・C350102。商業統計と経済センサス-活動調査）。今回取得 | 2002・2004・2007・2012・2014・2016・2021 |
| 総人口・65歳以上人口 | 同（国勢調査。F46 で取得） | 2005・2010・2015・2020 |
| 2050年の推計人口 | 国立社会保障・人口問題研究所「日本の地域別将来推計人口（令和5年推計）」（F45 で整形） | 2050 |
| 可住地面積 | 統計センター「SSDSE-A 2026」 | 2024年度 |

- 政令市の区と東京都の特別区部の合計は二重になるので外し、1,742市区町村（店の数が2012・2021年ともに取れる1,734）で分析した
- 2012年と2021年はどちらも経済センサス-活動調査で、調査の仕方がそろっている。2007年（商業統計）→2012年は調査の違いで全国の店の数が3割減って見えるため、主な比較には使っていない
- 2012年・2021年の人口は、国勢調査の間を対数で直線につないで（2021年は2015→2020年の伸びを延ばして）求めた
- 2050年の推計がない72市町村（福島県の一部など）は投影から外した（1,670市区町村）

## 手法

### 実データ

市区町村ごとに、店の数の変化 log(2021年/2012年) を人口の変化 log(2021年/2012年) に回帰し、傾き（人口が1%減ると店が何%減るか）を求めた。傾きが1より大きければ「店は人口より速く減る」。

### エージェントベースのモデル（`src/abm.py`）

| 部分 | 内容 |
|---|---|
| 町 | 可住地面積の正方形を10×10の区画に分ける。人口は中心ほど多い（中心からの距離で指数的に減る。広がりは一辺の0.3倍） |
| 住民 | 区画ごとに、店 i に exp(−距離/λ) の重みで支出を分ける（λ=1.5km）。町の外（郊外の大型店・通販など）にも重みがあり、最初の年は支出の20%が町の外に流れる。近くの店が減ると、そのぶん町の外へ流れる |
| 店 | 最初の年の店の数は実データに合わせ、人口に比例した場所に置く。固定費は最初の年の売上の0.6〜1倍（店ごとに一様分布）。売上が固定費を2年続けて下回ると閉じる。ほかに毎年2%が引退などで閉じる |
| 出店 | 毎年（店の数×2%×倍率）の候補が人口に比例した場所に現れ、見込み売上が固定費（今の店の固定費の中央値をもとに引く）を上回れば出店する |
| 校正 | 出店の倍率だけを、2012→2021年の店の変化の平均が実データに合うように選んだ（1.49）。傾きや規模別の違いは合わせていない（照合に使う） |
| 投影 | 2020年の人口と2021年の店の数から始め、人口は2050年の推計まで対数で直線に減らす。30年進める |

比べたもの：① 2012→2021年の傾き（全体・規模別）② 町ごとの店の変化の当たり方（RMSE）。比べる相手は「店は人口に比例して変わる」（単純な需要の閾値のモデル）と「どの町も全国の平均だけ変わる」。

## 主な結果

### 1. 実データ：店の数は、ほぼ人口と同じ割合で減っていた（2012→2021）

| | 傾き | 95%区間 |
|---|---|---|
| 全体（1,734市区町村） | **0.95** | 0.84〜1.06 |
| 都道府県の違いを除く | 1.01 | 0.86〜1.15 |
| 従業者数 | 1.29 | 1.16〜1.42 |

- 人口の変化で5つに分けても、店の変化の平均は人口の変化とほぼ同じ（人口 −21.6% の組で店 −19.4%、人口 +4.2% の組で店 +4.6%、対数差）。人口が大きく減った町で、店が人口より速く減った形跡はない
- 規模別の傾きは、小さい町（人口の中央値 3,700人）0.82、1.1万人 0.94、2.6万人 1.05、5.3万人 1.21、大きい市 0.83
- 1,000人あたりの店の数は、小さい町ほど多い（小さい町 10.1、大きい市 5.8。2012年）。断面では、店の数は人口の0.87乗に比例する
- ただし期間を変えると傾きは変わる。2016→2021年（同じ経済センサスどうし）は 0.58、2002→2007年（商業統計どうし。人口は2005→2010年で代用）は 0.48。「ちょうど比例する」のは2012→2021年の特徴かもしれない

### 2. 照合：ABM は平均には合うが、規模別の違いは再現できなかった

- 平均だけを合わせた ABM の傾きは 0.86（種を変えた3回で 0.85〜0.87）。実データの 0.95 よりやや小さい
- 規模別では、ABM はどの規模でも 0.61〜0.87 で、実データの「中くらいの市で1を超える」形は出ない
- 町ごとの店の変化の当たり方（RMSE、対数差）は、ABM 0.178、「人口に比例」0.163、「全国の平均だけ」0.186。**町ごとの予測は、単純な比例のほうが ABM より当たる**

### 3. 2050年への投影（基準の前提）

| 規模 | 人口の変化 | 店の数の変化（ABM） | 1km 以内に店がない住民（2020→2050） | 2km 以内に店がない住民 |
|---|---|---|---|---|
| 小さい町（中央値 3,700人） | −48% | −50% | 11.7% → 21.8% | 1.5% → 4.5% |
| 1.1万人 | −43% | −41% | 3.3% → 8.3% | 0.3% → 1.0% |
| 2.6万人 | −38% | −35% | 0.9% → 3.4% | 0.0% → 0.2% |
| 5.3万人 | −29% | −25% | 0.2% → 1.0% | 0.0% → 0.0% |
| 大きい市 | −18% | −14% | 0.0% → 0.1% | — |

- 全体では、店の数は −17%（人口は −18%）。店が人口より速く減る町は23%
- 小さい町だけが、店が人口よりわずかに速く減る（傾きは全体で1.08）。店が減ると近所の住民が町の外で買うようになり、残った店の売上がさらに減る、という連鎖が小さい町でだけ効く
- 「近くに店がない住民」は、店の数よりはっきり増える。小さい町で1km 以内に店がない住民は約2倍になる。店の数が人口に比例して減っても、残る店が中心に寄るため（モデルの中の話）
- 店が3つ以下の町は、3 → 19 になる。店がなくなる町は1つ

### 4. 前提を変えると（規模別に選んだ400市区町村、各2回の平均。図4）

小さい町（人口は2050年に −45%）の店の数の変化：

| 前提 | 店の数の変化 | 1km 以内に店がない住民（2050） | 同じ前提で 2012→2021 を再現した傾き |
|---|---|---|---|
| 基準 | −48% | 22.7% | 0.85 |
| 余裕が大きい（固定費÷売上 0.4〜1） | **−36%** | 18.5% | 0.75 |
| 余裕が小さい（0.8〜1） | **−60%** | 26.8% | 1.15 |
| 町の外の伸び +1%/年 | −54% | 23.5% | 0.89 |
| 町の外の伸び +2%/年 | **−62%** | 27.3% | 0.88 |
| 距離の減り方 λ=0.75km／3km | −50%／−47% | 22.4%／22.3% | 0.88／0.91 |
| 赤字1年／3年で閉店 | −49%／−47% | 22.7%／22.8% | 0.93／0.84 |
| 入れ替わり 年1%／4% | −48%／−49% | 22.1%／23.5% | 0.79／0.89 |
| 人口減は周辺ほど速い | −50% | 19.6% | 0.94 |
| 人口が中心に集まる／散らばる | −48%／−47% | 18.3%／22.7% | 0.85／0.90 |

- 答えをいちばん動かすのは、**店の「余裕」（売上が固定費をどれだけ上回っているか）と、町の外（通販など）への流れの伸び**。どちらも、小さい町の店の減り方を −36%〜−62% の幅で動かす
- 距離の減り方、閉店までの年数、入れ替わりの速さは、ほとんど効かない
- 2012→2021年の実データ（傾き 0.95）は、余裕が「0.4〜1」（0.75）でも「0.8〜1」（1.15）でもない、その間を指す。ただ、この1つの傾きだけでは前提を絞りきれない

### 5. 架空の町で50年（人口が7割減る。図5）

- 基準の前提では、人口1,000人・3,000人・1万人のどの町でも、店はほぼ人口に比例して減り、ある人口で急に消える「転換点」は出なかった
- 町の外への流れが毎年2%伸びる前提を重ねたときだけ、人口1,000人の町で20回中14回、最後の店が消えた（中央値45.5年目）。3,000人の町では8回、1万人では1回

## 頑健性

| 確かめたこと | 結果 |
|---|---|
| 実データの期間（2012→2021、2016→2021、2002→2007） | 傾きは 0.95、0.58、0.48。比例に近いのは2012→2021年だけ |
| 実データの都道府県の違い | 除いても 1.01 |
| ABM の乱数（照合は3回、前提の確認は2回、架空の町は20回） | 照合の傾きは 0.85〜0.87。架空の町の帯は図5 |
| ABM の前提14通り（上の表） | 小さい町の店の変化は −36%〜−62%。どの前提でも「近くに店がない住民」は2020年より増える（18〜27%） |
| 校正の倍率（0.75〜2.0） | 倍率が大きいほど傾きも大きい（0.67〜0.90）。どの倍率でも実データの 0.95 には届かない |

## 言えないこと

- **モデルの答えは前提しだい**です。特に店の余裕と町の外への流れは、実データから決められていません。2050年の数字は「この前提ならこうなる」という計算で、予測ではありません
- 照合で使ったのは、市区町村ごとの店の数の変化（1期間）だけです。ABM は平均に合わせただけで、規模別の違いは再現できず、町ごとの当たり方は単純な比例より悪い結果でした
- 店の場所のデータは使っていません。「近くに店がない住民」はモデルの中で区画の距離から計算したもので、実際の店の場所や道路の距離とは違います
- 「小売業の事業所」には、食料品店だけでなく、衣料・家電・自動車・燃料など、ふだんの買い物とは限らない店も入ります。店の大きさ（売場面積）も考えていません。コンビニ1店と商店1店を同じ1つと数えています
- 商業統計と経済センサスは調査の仕方が違い、つないだ比較には段差が入ります。主な比較は経済センサスどうし（2012・2021）にしましたが、2016→2021年など期間を変えると傾きは変わります
- 移動販売、宅配、買い物の送迎など、店以外で買う手段はモデルに入れていません
- 特定の市区町村を取り上げて評価するものではありません
