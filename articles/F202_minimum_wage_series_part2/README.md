# F202 最低賃金は「年収の壁」とどう重なり、全国一律にしたら何が起きるのか？（後編）

看板記事 F202。深いシリーズ A「最低賃金と働き方」の後編です。前編は [F201](../F201_minimum_wage_series_part1/)（note の下書き key：na914898fa082）。

note の記事：（公開後に記入）

## 前編のまとめ（3行）

- 改定で賃金を上げる必要が出る人の割合（影響率）は、20年で1.6%から23.2%に増えた。
- 同じ県×年のデータに4つの推定の方法を当てると、雇用への効果はどれも「はっきりしない」（弾力性で −0.18〜−0.02）。
- 答えを決めていたのは方法の違いより、県による上げ幅の差が小さいこと。ふつう報告される効果の7〜14倍でないと見分けられない。

## 問い

1. 最低賃金が上がると、「年収の壁」の手前で働ける時間はどれだけ短くなったか。壁の手前に人が集まる形（F82）や、就業調整をしている人の割合と、最低賃金は重なって動いているか。
2. 全国一律の最低賃金にしたら、雇用はどれだけ変わると考えられるか。前編の推定の幅を使い、前提を振った「幅」で示す。
3. 最低賃金の議論で、データが言えること・言えないことは何か。

この記事は、最低賃金の水準や全国一律の是非を評価するものではありません。データからどこまで言えるかを示すことが目的です。

## データ

| データ | 内容 | 出どころ |
|---|---|---|
| 地域別最低賃金（2002〜2026年度、全国加重平均つき） | 県×年度 | 厚生労働省「地域別最低賃金の全国一覧」（F201 から） |
| 就業構造基本調査 主要統計表 第8表（2017年・2022年） | 男女、就業調整の有無、年齢別の非正規の職員・従業員数（全国・都道府県） | 総務省（e-Stat の Excel をブラウザで読み込み） |
| F82 の集積の結果 | 有配偶の女性などの、50〜149万円への集積の大きさ b（2017・2022年） | articles/F82_income_wall_bunching |
| F201 のパネル・推定結果 | 県×年の就業者・就業率、4つの方法の推定値、検出力、2025年のカイツ指標 | articles/F201_minimum_wage_series_part1 |

- 「年収の壁」は、社会保険の **106万円**（一定の条件を満たす職場で、週20時間以上かつ月額8.8万円以上で加入）と **130万円**（扶養から外れる目安）を使いました。所得税の「103万円」は令和7年度の税制改正で見直されたため、使っていません。
- 年収を時間に直すときは、1年＝52週としました。

## 手法

1. **壁を時間に直す**：壁の金額 ÷ 最低賃金 ÷ 52 で、最低賃金で働いたときに壁の手前に収まる「週の時間」を出しました。週20時間で月8.8万円になる時給（88,000 ÷ (20×52÷12) ＝ 1,015.4円）を超える県の数も数えました。
2. **県の就業調整の割合と最低賃金**：非正規の女性のうち「就業調整をしている」人の割合を県ごとに出し、(a) 2022年の断面で最低賃金の額と、(b) 2017→2022年の変化で最低賃金の上がり方（対数差）と比べました。非正規の人数で重みをつけた回帰（頑健な標準誤差）と、並べ替え検定（4,000回）を使い、男性を比べる相手にしました。
3. **全国一律のシナリオ**：2026年度の各県の最低賃金を、(i) 全国加重平均 1,177円、(ii) いちばん高い県 1,280円、(iii) 1,500円 にそろえる（下回る県だけ引き上げる）とします。就業者の変化 ＝ 県の就業者（2025年）× 弾力性 × 引き上げ幅（対数）を県ごとに計算して足しました。弾力性は前編の推定から、
   - 4つの方法の幅：−0.18・−0.04・0
   - 区間の端：−0.35（前編が渡した端、95%区間の下端と同じ）・+0.14（95%区間の上端）
   を使いました。カイツ指標（最低賃金÷短時間労働者の平均時給）が、これまで観測された最大（0.819）を超える県の数も数えました。2026年のカイツ指標は、2025年の値 ×（2026年度÷2025年度の最低賃金）÷（1＋時給の伸び4.25%）で見込みました。
4. **検出力**：前編の「80%の確率で見つけられる最小の差」を弾力性に直し、1,500円のときの人数に換算しました。

## 主な結果

### 1. 年収の壁を時間に直すと

| 年度 | 最低賃金（全国加重平均） | 106万円の手前の週の時間 | 130万円の手前の週の時間 |
|---|---|---|---|
| 2005 | 668円 | 30.4時間 | 37.4時間 |
| 2017 | 848円 | 24.0時間 | 29.5時間 |
| 2022 | 961円 | 21.1時間 | 26.0時間 |
| 2026 | 1,177円 | 17.3時間 | 21.2時間 |

- 最低賃金が週20時間で月8.8万円を超える（1,016円以上）県は、2021年度2県 → 2023年度6県 → 2024年度12県 → **2025年度47県**。2025年度からは、どの県でも「週20時間」と「月8.8万円」がほぼ同じ線になりました。
- 2026年度の最低賃金で月8.8万円に届くのは週15.9〜18.7時間、130万円の手前に収まるのは週19.5〜23.0時間（県による）。

### 2. 2017年と2022年（全国）

- 有配偶の女性の集積の大きさ b（F82）：2.37 → 1.79（当てはめ方を変えても0.21〜0.60下がる）
- 非正規の女性で就業調整をしている割合：31.7% → 30.6%。男性：14.2% → 14.1%
- 130万円の手前の週の時間：29.5 → 26.0時間（−12%）
- 2時点しかないので、最低賃金が原因かどうかは分けられません。

### 3. 県で比べると（results/adjust_vs_mw.csv）

| 女性・断面・カイツ指標+0.05あたり | +0.2 | −2.4〜+2.7 | − |
| 男性・2022年の断面（比べる相手） | +2.6 | +1.9〜+3.2 | 0.002 |

- 断面では、最低賃金の高い県ほど就業調整の割合が高い形（重みなしの相関0.51）。ただし男性でも同じ形（相関0.66）で、最低賃金そのものより、都市部で非正規の働き方が違うことなどと重なっていると考えられます（推測）。
- 2017→22年の最低賃金の上がり方は、県で11.2〜14.7%（標準偏差0.93%）しか違わず、就業調整の割合の変化（47県中36県で低下、平均−0.99pt）とは関係が見えませんでした。

- 前編の推定で見分けられる最小の差（弾力性0.22〜0.24）は、1,500円のときの約 ±368万人にあたります。4つの方法の幅はその内側に収まり、今のデータでは「どれくらい減るか」を見分ける精度がありません。

## 頑健性

| 確かめたこと | 結果 |
|---|---|
| 県の比較で年齢を25〜54歳に限る | 断面 +0.1、変化 +0.37（どちらも区間が0をまたぐ） |
| 東京を除く | 断面は +3.5 とはっきりプラス、変化は −0.25（はっきりしない） |
| 最低賃金の額の代わりにカイツ指標を使う | +0.2（はっきりしない） |
| 男性で同じことをする（比べる相手） | 断面は女性と同じ向き（+2.6）。最低賃金だけの話ではない |
| 並べ替え検定 | 女性の変化 p=0.80、断面 p=0.28 |
| シナリオの基準を2025年度にする | 1,500円・弾力性−0.18で −373万人（2026年度基準は −311万人） |
| これまでの範囲を超える分は効き方を2倍にする | 1,500円で最大 −882万人。範囲の外の前提で答えが大きく動く |
| F82 の当てはめ方を変える | b の低下は 0.21〜0.60（100万円刻みにまとめた設定は除く） |

## 言えないこと

- 県の比較は、47県×2時点の集計値です。就業調整をしている人が、最低賃金のせいで時間を減らしたのかどうか（個人の行動）は分かりません。
- 2017年と2022年の比較には、コロナや調査の設計の違いが混ざっています。
- シナリオは「前編の推定がそのまま当てはまる」という前提の機械的な計算です。1,500円では就業者の77%がいる県で、これまでに観測した範囲（カイツ指標0.82まで）を超えるため、外挿になります。範囲の外で効き方が変わるかどうかは、このデータからは分かりません。
- 弾力性は、県全体の就業率から推定したものです。最低賃金近くで働く人だけへの効果ではありません。
- 時給への届き方（波及）や、価格・利益・労働時間への影響は計算していません。
- 社会保険の106万円の条件（職場の規模など）は、県ごとの違いを考えていません。
- 2026年度の最低賃金は発表された値、2026年のカイツ指標は見込みです。
