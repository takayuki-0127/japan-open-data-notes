# 1222 まだ判定していない文書を「正しくない」と見なすと、新しい検索のやり方はどれだけ不利になるのか？（検索の良さ）

検索の良さを数えるには、検索語ごとに、どの文書が正しい（探している人の役に立つ）かの判定が要ります。文書がたくさんあると全部は見られないので、前からある検索のやり方の上位の文書にだけ判定を付け、判定のない文書は「正しくない」と見なして数えることがよくあります。前からあるやり方の上位10件はすべて判定済みですが、違う文書を拾う新しいやり方の上位10件には、まだ判定していない文書がまざり、その中の正しい文書は数に入りません。**ここでは、作成者が置いた架空の社内の文書3,000件と架空の検索語50語（語ごとの正しい文書と、正しい文書が「検索語と同じ言葉を含む文書」か「言いかえた文書」かを作成者が決め、検索の点数を乱数で作ったもの）で、前からある2つのやり方（旧1・旧2）の上位20件にだけ判定を付けたとき、新しいやり方（新）の上位10件の正しい割合が本当の値からどれだけ下がるか、旧より良いのに悪く見えることがあるかを数えました。判定する深さ・言いかえた文書の割合・新と旧の点数の揺れの重なり・新の強さを変えた108通りでも確かめました。**

例の文書・検索語・検索のやり方は架空のもので、実在の検索の仕組みや、実在の判定の集め方を表すものではありません。どう判定を集めるべきかの助言はしていません。

関連する記事：971「空欄を0で埋めると、平均と割合はどうなるのか？」は、アンケートの空欄を0と見なすと、本当は使った人の分が消えて平均が下がることを扱っています。この記事は、検索の判定のない文書を「正しくない」と見なすときに、判定が前からあるやり方の上位から作られているため、ずれが新しいやり方にだけかかる点に絞ります。1221「上位10件の正しい割合で比べるか、正しい文書を拾えた割合で比べるかで、良い方の検索は入れかわるのか？」は、正しい文書がすべて分かっているときの物差しの選び方を、1223「よく検索される語に重みを付けて平均するか、語ごとに同じ重みで平均するかで、改善の大きさはどう見えるのか？」は、語の重みの付け方を扱っています。1227「クリックされた文書を正しいと見なすと、上に出ていた文書はどれだけ有利になるのか？」は、今の検索の上位から答えを作るゆがみを、判定の代わりにクリックで扱っています。

## 主な結果

### 基本の置き方（200回、`results/a1222_main.json` の `headline`）
| 上位10件の正しい割合 | 旧1 | 旧2 | 新 |
|---|---|---|---|
| ①本当の値 | 40.91% | 41.22% | **52.28%** |
| ②判定のない文書を正しくないと見なす | 40.91% | 41.22% | **26.09%** |
| ③判定済みの文書だけで並べ直す | 40.91% | 41.22% | 54.17% |

- **新は本当は旧1より11.37ポイント上なのに、判定のない文書を正しくないと見なすと14.83ポイント下に見えた。200回すべてで、上下が入れかわった**
- 新の見かけ（②）は本当の値（①）の0.499倍で、ほぼ半分だった
- 旧1・旧2の上位10件は、判定を付けた上位20件に必ず入るので、②は200回すべてで本当の値と同じだった（作りどおり）
- 新の上位10件のうち68.57%は判定のない文書で、正しいのに判定のない文書が26.19%あった。そのうち75.06%は言いかえた文書だった（正しい文書全体では40%）。旧が拾えない文書ほど、判定から漏れる
- 新の上位20件も判定に入れると、新の②は200回すべてで本当の値と同じになった（作りどおり、51.87%）
- ③（判定済みの文書だけで並べ直す）は、新を本当の値より1.89ポイント高く数えた（旧1との差は13.26ポイント上）

### 判定する深さを変えると（言いかえ40%・重なり0.5・新2.4、各10回、`robust.by_depth_base`）
| 旧の上位何件に判定を付けるか | 新の本当の値 | ②正しくないと見なす | ②÷① | 新の上位10件のうち、正しいのに判定のない文書 |
|---|---|---|---|---|
| 上位10件 | 52.74% | 21.1% | 0.4001 | 31.64% |
| 上位20件 | 51.42% | 25.94% | 0.5045 | 25.48% |
| 上位50件 | 50.96% | 32.08% | 0.6295 | 18.88% |
| 上位100件 | 51.3% | 34.54% | 0.6733 | 16.76% |

- 判定を旧の上位100件まで深くしても、新の見かけは本当の値の0.6733倍にとどまった。旧が低い順位に置く言いかえた文書は、深くしても判定に入りにくい

### 確かめ：108通り（各10回、`results/grid.csv`）
- **108通りすべてで、新の見かけ（②）は本当の値より低かった（本当の値の21.04〜86.5%）**
- 判定する深さごとの②÷①は、上位10件で21.04〜62.88%、20件で26.24〜71.55%、50件で35.77〜81.39%、100件で43.64〜86.5%。言いかえた文書の割合ごとでは、20%で33.78〜86.5%、40%で27.83〜74.92%、60%で21.04〜62.51%。重なりが0だと21.04〜73.04%、0.75だと33.27〜86.5%で、新が旧と違う文書を拾うほど低く出た
- 新が本当に旧1より良かった84通りのうち、74通りで見かけ（②）では旧1より下になった。下にならなかった10通りは、判定の深さがすべて上位50件か100件で、10通りのうち9通りは新の上乗せが2.8（新が本当に大きく良い）の置き方だった
- ③（判定済みの文書だけで並べ直す）の本当の値との比は62.59〜176.77%で、108通り中56通りで本当の値より高かった。新が本当は旧1より悪い18通り（すべて新の上乗せ2.0）では、③では新が旧1より良く見えた

## 注意（言えないこと）
- 架空のデータと、作成者が置いた点数の付き方です。とくに「旧は言いかえた文書に弱く、新は強い」という置き方で、新が不利になる大きさはほぼ決まります。新が旧と同じ文書を拾うやり方なら、ずれは小さくなります
- 判定はいつも正しいと置きました。判定する人の見落としや迷いは入れていません
- 正しい・正しくないの2つだけで、正しさの度合いは入れていません
- ③（判定済みの文書だけで並べ直す）は比べる相手として数えただけで、勧めるものではありません。この置き方では新を高く数えることが多くありました
- 判定をどの深さまで、どのやり方の上位から集めるべきかは扱っていません
