# 556 同じ分母で割った2つの比率は、もとの数に関係がなくてもどれだけ相関するのか（手法の解説・正解の分かるデータで試す）

店ごとの「来店客1,000人あたりの問い合わせ」と「来店客1,000人あたりの返品」のように、同じ分母で割った2つの比率を並べて相関を見ることがあります。分子どうしに関係がなくても、分母が店ごとに振れると、比率どうしには相関が出ます（Pearson が1897年に指摘した「見かけの相関」）。**ここでは、問い合わせ件数・返品件数・来店客数を互いに独立に作った架空の200店（正解：相関0）で、分母の振れを変えて、比率どうしの相関と「有意」になる割合を数えました。** あわせて、本当に効き方があるとき（弾力性0.3）に、3つの方法の推定を比べています。各条件2,000回（一部1,000回）くり返しています。数字は置いた前提で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A556 | 同じ分母で割った比率どうしは、どれだけ相関するか | 対数正規分布で X・Y・Z を独立に作り、分母 Z の変動係数（CV）を 0〜1.0、分子の CV を 0.1〜1.0 で動かす。比率どうしの相関・p<0.05 の割合、Pearson の近似式と比較。本当に効くとき（弾力性 0.3）の推定を、比率どうしの回帰・対数で分母を入れた回帰・もとの数どうしの回帰で比較（分子が店の大きさと無関係な場合 A、来店客数に比例する場合 B）。SQL は DuckDB（1スレッド）で例の1回の相関を確かめた。seed 556 | `src/a556_ratio_corr.py`、`src/a556_ratio_corr.sql`、`src/a556_ratio_corr_tsql.sql` |

## 主な結果
- **比率どうしの相関（分子の CV 0.3、200店）**：分母の CV 0.1 で 0.10、0.2 で 0.30、0.3 で 0.48、0.5 で 0.69、1.0 で 0.85。もとの件数どうしはどれも 0.00
- **関係がないのに p<0.05 になる割合**：比率どうしは分母の CV 0.1 で 30%、0.2 で 99%、0.3 以上で 100%。もとの件数どうしと、対数で分母を入れた回帰は 4〜6%（名目どおり）
- **分子の振れが小さいほど相関は高い**（分母の CV 0.5）：分子の CV 0.1 で 0.95、0.3 で 0.69、0.5 で 0.45、1.0 で 0.17
- **Pearson の近似式**は、平均をやや上に出す（CV 0.5 で式 0.74、実際の平均 0.69）が、形はよく合う
- **本当に効いているとき（弾力性 0.3、分母の CV 0.5）**：分子が店の大きさと無関係（A）なら、比率どうしの回帰は 0.80 と大きく出て、もとの数どうしと対数で分母を入れた回帰は 0.30。分子が来店客数に比例する（B）なら逆に、もとの数どうしが 0.81 と大きく出て、比率どうしと対数で分母を入れた回帰が 0.30。**どちらの場合も、対数で分母を説明変数に入れた回帰は 0.30**
- **例の1回（分母の CV 0.5）**：もとの件数どうしの相関 −0.01、1,000人あたりどうし 0.64

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 556）。例の1回の200店は `results/example_stores.csv`

## 注意（言えないこと）
- 架空のデータ。件数・変動係数・効き方は作成者が置いたもので、結果はこれで決まる
- 「比率を使うな」という話ではない。分子が分母に比例する（B）なら、比率どうしの比較が正しく、もとの数どうしのほうが大きく出る。どちらに近いかはデータで変わる
- 対数で分母を入れた回帰が両方で当たったのは、置いたモデル（対数で直線）がそのまま当てはまるため。実際のデータで同じとは限らない
- 3つの数は対数正規分布、互いに独立と置いた。件数が少なく0が多いデータは扱っていない
