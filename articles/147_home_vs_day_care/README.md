# 147 訪問介護と通所介護、利用者の伸びの差は？

厚生労働省「介護給付費等実態統計」（年度報告）の「介護サービス年間実受給者数，都道府県・サービス種類別」を2006〜2025年度の20年度分つなぎ、訪問介護と通所介護（デイサービス）の利用者の伸びを比べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A147 | 訪問介護と通所介護、どちらの利用者がどれだけ伸びたか。時期や都道府県で違うか | 年間実受給者数の推移、期間ごとの年平均増加率、都道府県別の利用割合 | `src/a147_home_day.py` |

## 主な結果
- 2008→2025年度で、介護サービス全体の受給者は 367万人→578万人（+57%）。訪問介護は 116万人→162万人（+40%）、通所介護（地域密着型を含む）は 126万人→231万人（+84%）
- 年平均の伸びは、2008→15年度は通所介護 6.2%・訪問介護 3.0% と通所が2倍。2016→19年度は 1.8%・0.5%。2019→25年度は通所 0.6%・訪問 1.7% と逆転した
- 2019→2020年度（コロナ）は通所介護 −3.6%、訪問介護 +1.1%、訪問看護 +8.6%
- 訪問看護は 38万人→111万人（約3倍）。受給者に占める割合は 10%→19%
- 2025年度に訪問介護を使った人の割合は全国28%。大阪府45%・和歌山県38%・青森県36%が高く、佐賀県14%・鳥取県17%・福井県17%が低い

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a147_home_day.py
```

## 注意
- 年間実受給者数は、各年度の4月〜3月サービス提供分を名寄せした人数（千人）。被保険者番号が変わった人は別人として数えられます
- 介護サービス（要介護1〜5）だけで、介護予防サービス（要支援）と総合事業は含みません。2006年度は予防給付の始まった年なので、比較は2008年度からにしています
- 2016年度から、小規模な通所介護は「地域密着型通所介護」に移りました。ここではこの2つを足して通所介護としていますが、両方を使った人は二重に数えられるため、2016年度以降の通所介護はやや多めです（2015→2016年度の段差もこのためと考えられます）
- 利用者の数で、利用回数や費用ではありません
