# F256 計画（結果を見る前に書く）

作成：2026-11-11。この計画は分析前にコミットし、結果とのずれは README の「計画とのずれ」に書く。

## 問い

自然災害（台風・豪雨・雪・ひょうなど）で損害保険会社が払った保険金は、この30年でどれだけ大きくなったのか。
物価（建設費）と建物の数で割り引いても、大きくなったと言えるのか。

## 使うデータ

- 日本損害保険協会「過去の主な風水害等による保険金の支払い」（上位10事故、1991年〜）：事故ごとの件数と支払保険金（火災・新種／自動車／海上）。
- 日本損害保険協会「近年の風水害等による支払保険金調査結果」：2012年度〜2025年度の事故ごとPDF（35事故）。件数と保険金を、火災・新種・自動車に分けて読む。
- 損害保険料率算出機構「火災保険・地震保険の概況」：補足（数字の確認用に限る）。
- 国土交通省「建設工事費デフレーター」年度・住宅総合：建物を直す費用の物価。
- 総務省 消費者物価指数（総合）：別の物価のものさし（頑健性用）。
- 総務省 住宅・土地統計調査：住宅数（5年ごと、間は補間）。

※データを選ぶ段階で、上位10事故表は一度目にしている。年度別の合計・件数あたり・住宅あたりの数字はまだ計算していない。

## 仮説

H1：名目の支払保険金は大きくなっている（上位10事故の6つが2014年以降）。
H2：建設費デフレーターと住宅数で割り引くと、増え方は小さくなるが、消えはしない。
H3：増えたのは主に「1件あたりの金額（重さ）」より「件数（頻度）」の側である……とは決めつけず、両方を分けて測る。

## 主な指標

1. 事故ごとの支払保険金：名目／実質（住宅総合デフレーター、2020年度=100）／実質・住宅1万戸あたり。
2. 1件あたり保険金（実質）。
3. 2012〜2025年度の、協会が調査した事故の年度合計（実質・住宅1万戸あたり）。

## 比べ方

- 上位10事故を「1991〜2004年の事故」と「2014年以降の事故」に分け、実質・住宅あたりで並べる。
- 2012〜2025年度の年度合計で、上位2事故（2018年台風21号、2019年台風19号）を抜いた場合も見る。

## 頑健性（3つ以上）

1. 物価のものさしを替える：住宅総合デフレーター ↔ CPI総合 ↔ 割り引かない。
2. 住宅数の補間を替える：直線補間 ↔ 直前の調査値のまま（階段）。
3. 大きな事故を抜く：上位1・2事故を除く。
4. 範囲を替える：火災・新種だけ（自動車・海上を除く）。
5. 事故の足切り：100億円以上の事故だけ。

## 反証の条件

- 実質・住宅あたりで、2014年以降の上位事故が1991〜2004年の上位事故と同じ程度なら、「割り引けば大きくなっていない」と書く。
- 1件あたり実質保険金が増えていなければ、「重さは変わらず、件数が増えた」と書く。

## 言えないと分かっていること

- 協会が調査した事故しか入らない。小さな災害の合計は入らない。
- 地震保険は対象外（風水害等のみ）。
- 保険に入っている建物の数（契約件数）ではなく、住宅数で割る。加入率の変化は分けられない。
