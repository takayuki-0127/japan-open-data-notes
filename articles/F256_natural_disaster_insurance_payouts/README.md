# F256 自然災害の保険金は、この30年でどれだけ大きくなったのか（物価と建物の数で割り引くと）

note 記事「自然災害の保険金は、この30年でどれだけ大きくなったのか？」のコード・データ・図です。

## 問い

台風・大雨・雪・ひょうなどで損害保険会社が払った保険金は、この30年でどれだけ大きくなったのか。建物を直す費用（建設工事費）と住宅の数で割り引いても、大きくなったと言えるのか。

計画（仮説・比べ方・頑健性・反証の条件）は分析の前に [PLAN.md](PLAN.md) としてコミットした（コミット a82a4ee）。

## 結論

1. **最大の事故は、割り引くと1.14倍**：記録上最大の2018年台風21号（名目1兆678億円）は、1991年台風19号（5,680億円）の名目1.88倍。1991→2018年度に建設費（住宅総合デフレーター）は1.17倍、住宅数は1.41倍になっており、両方で割り引くと住宅1戸あたり 17,446円 対 15,301円で **1.14倍**。物価のものさし・住宅数の補間・範囲を替えても 1.09〜1.33倍。
2. **問い直し：「大きくなった」より「大きいのが増えた」か**：住宅1戸あたり実質 4,456円以上の事故（この大きさなら協会の上位10表に必ず入るので、取りこぼしがない）は、1991〜2012年度の22年で3件、2013〜2025年度の13年で5件（年0.14件→0.38件）と後の期間が多いが、件数が少なく、片側 p=0.13 で偶然と区別できない。足切りを1.5倍（6,684円）にすると3件対3件。
3. **直近14年度に右肩上がりはない**：協会が個別に調べた自然災害（2012〜2025年度、34事故）の年度合計（住宅1戸あたり実質）にトレンドはない（ケンドールのτ=−0.06、p=0.83）。2018・2019年度の2年で14年度分の61%を占める。後半7年÷前半7年は0.68だが、最大の1事故を抜くと1.17に逆転し、前後比は1事故で決まる。
4. **1件あたりの重さは、時代より災害の種類**：1件あたり実質保険金は大雨（浸水）241万円、台風108万円、雪100万円、ひょう76万円。台風どうし（17事故）・大雨どうし（11事故）では、時期とともに重くなる傾向は見えない（τ=+0.03、−0.20）。年度合計を件数と1件あたりに分けても、後半÷前半は件数0.59・1件あたり1.16、τ は −0.12・+0.14 で傾向なし（PLAN の H3）。

## 手法

- **実質化**：名目保険金 × 100 ÷ 建設工事費デフレーター（住宅総合、発生年度）。2020年度価格。物の値段全体ではなく「建物を直す費用」で割り引くため、住宅総合を基準にした。
- **住宅1戸あたり**：実質保険金 ÷ 発生時点の住宅数。住宅数は5年ごとの調査（10月1日）を直線で補間し、2023年10月より後は2018→2023年の増え方で延ばした。自動車・海上の保険金も含めて全住宅数で割っており、「1戸が払われた額」ではなく「国の住宅のストックに対する大きさ」の目安。
- **年度**：発生月で決める（4月〜翌3月）。2014年2月の大雪は2013年度。2018年7月豪雨は上位10表に合わせて発生月を6月（6月28日〜）とした（年度は同じ）。
- **災害の種類**：事故名で分けた。台風に伴う大雨（2013年台風18号、2015年台風18号、2023年の梅雨前線と台風2号）は台風に入れた。
- **件数あたり（重さ）**：実質保険金 ÷ 支払件数（車両は台数、火災・新種は証券件数）。
- **取りこぼしのない足切り**：上位10表の10位は名目1,642億円。住宅1戸あたり実質がX円の事故の名目額は X×住宅数×デフレーター/100。1991年4月〜2026年3月のどの月に起きてもこれが1,642億円以上になる最小のXは 4,456円（1991年春で決まる。月ごとに、その月の住宅数とその年度のデフレーターで計算）。上位10表が1991年以降のすべての事故から名目順に選ばれている、という前提に立つ。X以上の事故はすべて上位10表に入っているので、表だけで数え漏れなく数えられる。
- **検定**：大きな事故の数は、件数が年数に比例するとした正確二項検定（片側）。年度合計の傾向はケンドールの順位相関。

## 言えないこと

- 協会が個別に調べた事故と、上位10事故しか入らない。小さな災害の合計、毎年の自然災害の保険金の総額は分からない（年度合計は「協会が個別に調べた事故の合計」）。どの事故を個別に調べるかの基準が年によって違う可能性もある（2012・2014・2016・2025年度は1事故だけ）。
- 地震保険（地震・噴火・津波）は対象外。
- 2005〜2011年度は、上位10に入る事故がなかったこと以外は分からない（個別の調査結果は2012年度から）。
- 保険に入っている建物の数（契約件数）や、水災の補償を付ける割合の変化は分けられない。住宅数で割っているので、加入率が上がっただけでも「1戸あたり」は増える。
- 上位10表は2026年3月末時点の見込みを含む値、事故ごとの表は各年度末時点の値（2018年2月の大雪は2018年3月時点）で、後から増える分がある。
- 1件あたりの比較は、車両（台数）と火災・新種（証券件数）を足した件数で割っている。種類の構成が違う事故どうしは、単純には比べられない。
- 2024・2025年度のデフレーターは暫定値。2025年度の住宅数・世帯数は2018→2023年の増え方で延ばした値。
- 住宅数には空き家も入り、その割合は上がってきた。世帯数で割ると1991→2018年の伸びは1.357倍（住宅数は1.409倍）、最大の事故どうしの比は1.18倍で、結論は同じ。
- 2012・2014・2016・2025年度は、協会が個別に調べた自然災害が1事故だけ。
- 台風と大雨の分け方は事故名による（上の「災害の種類」）。分け方を変えると種類別の1件あたりは変わる。
- 始まりの1991年は、上位10表のいちばん古い事故に合わせて、表を見てから決めた。始まりを動かすと、年あたりの件数も足切りの値も変わる。
- 2014年2月の大雪の件数は、上位10表で326,591件、事故ごとの表で326,595件（時点の違い。差は4件）。
- 大雨と台風の区別は事故名による。台風に伴う大雨（2019年台風19号の浸水など）は台風に入っている。

## 計画とのずれ

- 仮説 H1（名目は大きくなった）は当たり。H2（割り引くと小さくなるが消えない）は、最大の事故どうしで1.14倍と「ほぼ消える」に近かった。反証の条件（2014年以降の上位事故が1991〜2004年と同程度なら「割り引けば大きくなっていない」と書く）がほぼ当たったので、「最大級の事故は、割り引くと名目ほどは大きくなっていない（1〜3割増し）」と書いた。
- 計画では上位10事故を2つの時代に分けて平均を比べるつもりだったが、上位10表は名目の大きさで選ばれているため、物価と住宅数が増えた後の時代ほど小さめの事故まで入る。平均の比較（0.70倍）は選び方の偏りを含むので主な結果にせず、代わりに「取りこぼしのない足切り」で大きな事故を数えた（計画にない追加）。
- 時代の境目は「2014年以降」とした計画を「2013年度以降」とした（2014年2月の大雪は2013年度のため。事故の顔ぶれは同じ）。
- 物価のものさしは計画どおり住宅総合デフレーターを基準、CPIを頑健性に使った。建設総合デフレーターも加えた。
- 損害保険料率算出機構「火災保険・地震保険の概況」は、図の数字を表として取り出せなかったので使っていない。
- 災害の種類別の1件あたり（図5）は、問い直しの過程で加えた。
- PLAN の H3（頻度と重さを分ける）：2012〜2025年度の年度合計では、件数（住宅1,000戸あたり）の後半÷前半0.59（τ=−0.12）、1件あたり1.16（τ=+0.14）で、どちらも傾向なし。反証の条件2（1件あたり実質が増えていなければ「重さは変わらず、件数が増えた」と書く）は、件数も増えていないので当てはまらず、「どちらにも傾向はない」と書いた。上位10事故の1件あたり（1991〜2004年 113.5万円 → 2014年以降 152.6万円、1.34倍）は、名目で選ばれた表の偏りと、1件360万円の2018年7月豪雨が押し上げていること（推測）から主な結果にしていない。
- 計画を書く前に、データを選ぶ段階で上位10表は一度見ている（PLAN にもそう書いた）。PLAN の H1 にある「上位10事故の6つが2014年以降」は誤りで、実際は7つ（2014年2月の雪・2015・2018年×3・2019年×2）。
- コミットの順序：PLAN.md（a82a4ee）は分析のコミットより前。分析本体は 339b834 以降で、すべて main に入っている。

## レビューで直したこと

メインのスレッドが別に走らせた独立レビュー（記事・README・コードだけを渡したもの）の指摘と、直したこと。数字はすべて同じ値で再現でき、重大（高）の指摘はなかった。作成者自身の読み直しで先に直していたこと（足切りを月ごとに計算し直して4,456円に、「ほとんど変わらない」を「1〜3割増し」に、など）は前の版に記載。

1. **［中］住宅数の分母に空き家が入る**：空き家の割合は上がってきた。同じ表の世帯数で割る頑健性を加えた（1991→2018年の伸び1.357倍、最大の事故どうし1.18倍、足切り4,959円、3件対5件・p=0.13 は同じ）。言えないことにも追加。結論は変わらない（1.09〜1.33倍の幅の中）。適用の途中で、年度合計の分母が補間の選択を無視していたバグに気づき直した（階段の前後比 0.68→0.67）。
2. **［中］「台風は1件あたり50万〜130万円」は誤り**：実際は56万〜197万円で、130万円超が4事故。「多くは50万〜130万円」に直し、範囲と件数を書いた。
3. **［中］タイトルと図3の題が「増えた」と言い切っている**：「3件→5件と多いが、偶然と区別できない」に直し、タイトルも短くした。
4. **［中］「増えても減ってもいません」は言い過ぎ**：「増加・減少の傾向は見えません（p=0.83、14点）」に直した。
5. **［低〜中］PLAN の H3 と反証の条件2の結果が書かれていない**：年度合計の件数と1件あたりの前後比・τ を本文と「計画とのずれ」に書いた。上位10事故の1件あたりの比較（1.34倍）を主な結果にしない理由も書いた。
6. **［低］始まりを1991年にした理由**：上位10表のいちばん古い事故に合わせて表を見てから決めたこと、動かすと件数も足切りも変わることを書いた。
7. **［低］台風と大雨の分け方が事故名でばらばら**：2023年の「梅雨前線による大雨及び台風2号」を台風に入れ、台風に伴う大雨は台風にそろえた（大雨241万円・11事故、台風108万円・17事故、τ は +0.03・−0.20 に更新）。言えないことに1行追加。
8. **［低］しくみの説明に根拠がない**：「風で屋根などが広く壊れる」「浸水で1件が重い」を「〜と考えられます（推測）」に、図2の「災害の強さと関係なく押し上げている」を弱めた。
9. **［低］2025年度の住宅数は延ばした値、デフレーターは暫定値**：本文の2に書いた。
10. **［低］計画前に上位10表を見ていたこと、PLAN の「6つ」は実際は7つ**：「計画とのずれ」に開示した（PLAN.md 自体は書き換えていない）。
11. **［低］1事故だけの年度が4つ（2012・2014・2016・2025年度）**：言えないことに追加。
12. **［低］コミットの順序**：PLAN a82a4ee が分析より前で、本体はすべて main に入っていることを「計画とのずれ」に書いた。2014年2月の大雪の件数の差（4件）を言えないことに書き、2018年7月豪雨の発生月は上位10表の6月にそろえた。
