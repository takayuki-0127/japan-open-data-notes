# F256 自然災害の保険金は、この30年でどれだけ大きくなったのか（物価と建物の数で割り引くと）

note 記事「自然災害の保険金は、この30年でどれだけ大きくなったのか？」のコード・データ・図です。

## 問い

台風・大雨・雪・ひょうなどで損害保険会社が払った保険金は、この30年でどれだけ大きくなったのか。建物を直す費用（建設工事費）と住宅の数で割り引いても、大きくなったと言えるのか。

計画（仮説・比べ方・頑健性・反証の条件）は分析の前に [PLAN.md](PLAN.md) としてコミットした（コミット a82a4ee）。

## 結論

1. **最大の事故は、割り引くと1.14倍**：記録上最大の2018年台風21号（名目1兆678億円）は、1991年台風19号（5,680億円）の名目1.88倍。1991→2018年度に建設費（住宅総合デフレーター）は1.17倍、住宅数は1.41倍になっており、両方で割り引くと住宅1戸あたり 17,446円 対 15,301円で **1.14倍**。物価のものさし・住宅数の補間・範囲を替えても 1.09〜1.33倍。
2. **問い直し：「大きくなった」より「大きいのが増えた」か**：住宅1戸あたり実質 4,456円以上の事故（この大きさなら協会の上位10表に必ず入るので、取りこぼしがない）は、1991〜2012年度の22年で3件、2013〜2025年度の13年で5件（年0.14件→0.38件）。ただし件数が少なく、片側 p=0.13 で偶然と区別できない。足切りを1.5倍（6,684円）にすると3件対3件。
3. **直近14年度に右肩上がりはない**：協会が個別に調べた自然災害（2012〜2025年度、34事故）の年度合計（住宅1戸あたり実質）にトレンドはない（ケンドールのτ=−0.06、p=0.83）。2018・2019年度の2年で14年度分の61%を占める。後半7年÷前半7年は0.68だが、最大の1事故を抜くと1.17に逆転し、前後比は1事故で決まる。
4. **1件あたりの重さは、時代より災害の種類**：1件あたり実質保険金は大雨（浸水）225万円、台風108万円、雪100万円、ひょう76万円。台風どうし（16事故）・大雨どうし（12事故）では、時期とともに重くなる傾向は見えない（τ=+0.02、−0.24）。

## 手法

- **実質化**：名目保険金 × 100 ÷ 建設工事費デフレーター（住宅総合、発生年度）。2020年度価格。物の値段全体ではなく「建物を直す費用」で割り引くため、住宅総合を基準にした。
- **住宅1戸あたり**：実質保険金 ÷ 発生時点の住宅数。住宅数は5年ごとの調査（10月1日）を直線で補間し、2023年10月より後は2018→2023年の増え方で延ばした。自動車・海上の保険金も含めて全住宅数で割っており、「1戸が払われた額」ではなく「国の住宅のストックに対する大きさ」の目安。
- **年度**：発生月で決める（4月〜翌3月）。2014年2月の大雪は2013年度。
- **件数あたり（重さ）**：実質保険金 ÷ 支払件数（車両は台数、火災・新種は証券件数）。
- **取りこぼしのない足切り**：上位10表の10位は名目1,642億円。住宅1戸あたり実質がX円の事故の名目額は X×住宅数×デフレーター/100。1991年4月〜2026年3月のどの月に起きてもこれが1,642億円以上になる最小のXは 4,456円（1991年春で決まる。月ごとに、その月の住宅数とその年度のデフレーターで計算）。上位10表が1991年以降のすべての事故から名目順に選ばれている、という前提に立つ。X以上の事故はすべて上位10表に入っているので、表だけで数え漏れなく数えられる。
- **検定**：大きな事故の数は、件数が年数に比例するとした正確二項検定（片側）。年度合計の傾向はケンドールの順位相関。

## 言えないこと

- 協会が個別に調べた事故と、上位10事故しか入らない。小さな災害の合計、毎年の自然災害の保険金の総額は分からない（年度合計は「協会が個別に調べた事故の合計」）。どの事故を個別に調べるかの基準が年によって違う可能性もある（2012・2014・2016・2025年度は1事故だけ）。
- 地震保険（地震・噴火・津波）は対象外。
- 2005〜2011年度は、上位10に入る事故がなかったこと以外は分からない（個別の調査結果は2012年度から）。
- 保険に入っている建物の数（契約件数）や、水災の補償を付ける割合の変化は分けられない。住宅数で割っているので、加入率が上がっただけでも「1戸あたり」は増える。
- 上位10表は2026年3月末時点の見込みを含む値、事故ごとの表は各年度末時点の値（2018年2月の大雪は2018年3月時点）で、後から増える分がある。
- 1件あたりの比較は、車両（台数）と火災・新種（証券件数）を足した件数で割っている。種類の構成が違う事故どうしは、単純には比べられない。
- 2024・2025年度のデフレーターは暫定値。
- 大雨と台風の区別は事故名による。台風に伴う大雨（2019年台風19号の浸水など）は台風に入っている。

## 計画とのずれ

- 仮説 H1（名目は大きくなった）は当たり。H2（割り引くと小さくなるが消えない）は、最大の事故どうしで1.14倍と「ほぼ消える」に近かった。反証の条件（2014年以降の上位事故が1991〜2004年と同程度なら「割り引けば大きくなっていない」と書く）がほぼ当たったので、「最大級の事故は、割り引くと名目ほどは大きくなっていない（1〜3割増し）」と書いた。
- 計画では上位10事故を2つの時代に分けて平均を比べるつもりだったが、上位10表は名目の大きさで選ばれているため、物価と住宅数が増えた後の時代ほど小さめの事故まで入る。平均の比較（0.70倍）は選び方の偏りを含むので主な結果にせず、代わりに「取りこぼしのない足切り」で大きな事故を数えた（計画にない追加）。
- 時代の境目は「2014年以降」とした計画を「2013年度以降」とした（2014年2月の大雪は2013年度のため。事故の顔ぶれは同じ）。
- 物価のものさしは計画どおり住宅総合デフレーターを基準、CPIを頑健性に使った。建設総合デフレーターも加えた。
- 損害保険料率算出機構「火災保険・地震保険の概況」は、図の数字を表として取り出せなかったので使っていない。
- 災害の種類別の1件あたり（図5）は、問い直しの過程で加えた。

## レビューで直したこと

独立したレビュー用のエージェントを起動しようとしたが、この作業環境では入れ子の起動ができなかったため、作成者（Claude）が書き上げた後に、数字の照合・方法・言い過ぎ・分かりやすさ・コードの観点で読み直した。見つけたことと直したこと：

1. **足切りの計算が粗かった（直した）**：最初は各年10月時点だけで「必ず上位10に入る大きさ」を計算していた（4,420円）。1991年4〜9月は住宅数がもっと少ないので足切りはもっと高くなる。月ごとに、その月の住宅数とその年度のデフレーターで計算し直し、4,456円にした。件数（3件対5件）と p 値は変わらない。1.5倍・2倍の足切りも 6,684円・8,911円に直した。
2. **「割り引くとほとんど変わらない」は言い過ぎ（直した）**：比は1.09〜1.33倍で、1〜3割は増えている。「名目ほどは大きくなっていない（1〜3割増し）」に変えた。
3. **前提が書かれていなかった（直した）**：足切りの数え方は、上位10表が1991年以降のすべての事故から名目順に選ばれていることが前提。本文と README に書いた。
4. **年度合計の対象の変化（直した）**：協会がどの事故を個別に調べるかは年によって違う可能性があり、1事故だけの年度が4つある。言えないことに加えた。
5. **「件数」の意味が本文になかった（直した）**：車両は台数、火災・新種は証券件数であることを用語に加えた。
6. **上位10事故の時代別の平均（0.70倍）を主結果にしない（もとから対応）**：名目で選ばれた表なので、後の時代ほど小さめの事故が入る偏りがある。計画とのずれに理由を書いた。
7. **年度合計の前後比（直さず、扱いを明記）**：0.68だが最大の1事故を抜くと1.17に逆転する。結論には使わず、「1事故で決まる」ことの例として示した。
8. **コード**：02 の `__import__("csv")` を通常の import に直した。PDF から目で読んだ4表は、件数・金額の内訳の和が合計と合うことを assert で確かめている。
