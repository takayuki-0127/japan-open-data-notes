# F274 「人手不足倒産が過去最多」は、会社の数と数え方をそろえても増えたのか（精選モード C. ニュースの数字 Q27）

## 問い
「人手不足倒産が過去最多」と毎年のように報じられる。会社の数が増えれば倒産も増えるし、倒産全体が増えていればその一部も増える。さらに、どの要因を「人手不足」と数えるかは調査会社ごとに違い、同じ会社でも途中で数え方を変えている。これらをそろえても、本当に増えたと言えるのかを確かめた。与信管理や取引先のリスクを見る人、中小企業の経営や支援をする人が、見出しの数字をどう読めばよいかを知りたい点だと考えた。

計画（仮説と外れの基準）は分母を計算する前に書いてコミットした：[PLAN.md](PLAN.md)（コミット 74462e8）。計画を書く前に、帝国データバンクの件数の推移と、東京商工リサーチの2024・2025年の件数、2019年に後継者難を含めて数えていたことは見ていた（PLAN に記載）。

## データ
公表された集計値だけを使い、1件ずつ出典つきで `data/sources.csv` に書き写した（109行）。元の記事・PDFは著作権のためリポジトリに入れていない。

| 系列 | 出典 | 期間 |
|---|---|---|
| 人手不足倒産 | 帝国データバンク（TDB）「人手不足倒産の動向調査（2025年）」2026-01-08、件数推移の図 | 2016〜2025年 |
| 人手不足倒産の当時の公表値 | TDB 2019年の発表（2020-01-09、報道）：2019年185件 | 2018・2019年 |
| 「人手不足」関連倒産（求人難・従業員退職・人件費高騰） | 東京商工リサーチ（TSR）TSRデータインサイトの各年の記事 | 2016〜2019、2022〜2025年（2020・21年は年の値を見つけられず） |
| 後継者難倒産 | TSR の各年の記事 | 2016〜2025年 |
| 「人手不足」関連倒産（年度） | TSR の各年度の記事 | 2019〜2025年度 |
| 倒産全体 | TDB「全国企業倒産集計2025年報」、TSR「全国企業倒産状況」 | 2012〜2025年 |
| 法人数 | 国税庁「会社標本調査」令和6年度分 第1表（資本金階級別法人数の累年比較） | 2014〜2024年度 |
| 企業数 | 中小企業庁「中小企業・小規模事業者の数」（経済センサス、全規模合計） | 2014・2016・2021年 |
| 有効求人倍率 | JILPT「グラフでみる長期労働統計」g0301（厚生労働省「一般職業紹介状況」） | 2013〜2025年 |

- 倒産はどれも負債1,000万円以上。TDB は法的整理のみ。
- 東京商工リサーチの数え方：2019年までは「後継者難・求人難・従業員退職・人件費高騰」の4要因を「人手不足」関連倒産として発表していた（2019年は426件、うち後継者難270件）。2023年ごろの発表から後継者難を除いた3要因で発表し、2019年は156件として比べている。後継者難は別に発表を続けている。この記事では、3要因と4要因（3要因＋後継者難）の両方を作った。
- 逆算した値：TSR 2018年の3要因（2019年の記事の前年比から）、2022年の求人難・従業員退職（2023年の記事の前年比から）、2025年の求人難（合計−他の2要因）、2018年の後継者難。どれも `data/sources.csv` の note に計算を書いた。
- 2025年の法人数はまだ公表されていないので、2023→2024年度の伸び（+1.45%）で延ばした（推測）。企業数は2016・2021年の間を直線でつなぎ、2022年以降は2016→2021年の傾きで延ばした（推測）。

## 手法
- 法人10万社あたりの件数（暦年 t に年度 t の法人数を当てる）、倒産全体に占める割合、2025年÷2019年の比。
- 2019年を比べる年にしたのは、コロナの前で、どの調査会社も「それまでの最多」としていた年だから。
- 求人倍率との関係：2016〜2019年の「法人10万社あたりの人手不足倒産」を有効求人倍率で直線に当てはめ、2023〜2025年を予測した。

## 結果
| 仮説 | 基準 | 結果 | 判定 |
|---|---|---|---|
| H1 会社の数でそろえても増えた | TDB、法人10万社あたり 2025÷2019 ≥1.5 | 7.0 → 14.0件、2.02倍（件数は2.22倍、法人数は1.10倍） | 支持 |
| H2 倒産全体に占める割合も増えた | TDB、割合 2025÷2019 ≥1.5 | 2.30% → 4.16%、1.81倍（倒産全体は1.23倍） | 支持 |
| H3 後継者難を含めると「過去最多」の伸びは小さい | TSR 4要因の件数 2025÷2019 <1.5 | 426 → 851件、2.00倍（3要因だけなら156 → 397件、2.54倍） | 外れ |
| H4 求人倍率だけでは説明できない | 2016〜19年の当てはめで2023〜25年が3年とも予測より上 | 2025年は予測0.2件に対し実際14.0件（求人倍率は1.60 → 1.22に下がった） | 支持 |

- 後継者難は4要因の63%（2019年）から53%（2025年）に下がった。数え方を変えたことで伸びは大きく見えるが、どちらの数え方でも2019年の2倍以上。
- 倒産全体も法人10万社あたり303 → 337件（1.11倍）と増えたが、人手不足倒産の伸びはそれよりずっと大きい。
- H4 の当てはめは4年分しかない。2020〜2022年も予測より上に出ており、2016〜2019年の関係そのものが続いていない（下の「言えないこと」）。

## 頑健性
1. 分母を企業数（個人企業を含む、減っている）に替えると、2025÷2019 は TDB 2.40倍、TSR 3要因 2.75倍、4要因 2.16倍と、むしろ大きくなる。
2. TSR 3要因：法人10万社あたり2.31倍、倒産全体に占める割合 1.86% → 3.85%（2.07倍）。4要因の割合は 5.08% → 8.26%（1.63倍）。
3. 2016〜2019年の平均と比べると、TDB 法人10万社あたり2.94倍、割合2.63倍。
4. TSR 3要因の年度（4〜3月）：2019年度160件 → 2025年度442件、2.76倍（法人10万社あたり2.50倍）。
5. 2025年の法人数を延ばさず2024年度のまま使っても、TDB 2.05倍。
6. TDB は過去の年の値を後から直している（2019年は当時185件 → いま192件、2018年は153件 → 159件）。当時の185件で比べると2.09倍。
7. H4 の当てはめを2016〜2022年に広げると相関は0.39に下がるが、2023〜2025年の残差は +4.2・+7.0・+9.7件で、3年とも予測より上。

## 問い直し：増えたのは「採れない」倒産か、「払えない」倒産か
（結果を見てから足した問い）TSR の3要因の中身を見ると、2019年は求人難が50%、人件費高騰が22%だったが、2025年は求人難34%、人件費高騰38%と入れ替わった。法人10万社あたりで2025÷2019 は、求人難1.57倍、従業員退職2.27倍、人件費高騰4.05倍。2019→2025年の増加分241件のうち、人件費高騰が49%、従業員退職が27%、求人難が24%を占めた。求人倍率が下がるなかで増えたのは、主に「人件費が払えない」倒産と「辞められた」倒産だった。

## 言えないこと
- 倒産の要因は各調査会社の判断で、1件に1つの主な要因を付けている。判断の基準は公表されておらず、「人手不足」と書かれる倒産が増えたこと自体に、注目が集まって要因として記録されやすくなった分が入っている可能性がある（推測、確かめられない）。
- TSR の3要因の年の値は2020・2021年が見つからなかった（1-11月はそれぞれ91件・53件）。
- 法人数は年度、倒産は暦年で、ずれがある。2025年の法人数と2022年以降の企業数は延ばした値（推測）。
- 人手不足が倒産を増やしたという因果は扱っていない。政策の評価もしていない。
- 個社名は使っていない。

## 計画からのずれ
- PLAN では TDB を2013年からとしたが、公表値を確かめられたのは2016年からだった（2016〜2025年の図から読んだ）。H4 の当てはめも2013〜2019年ではなく2016〜2019年（4点）になった。
- TSR の4要因の合計は、2020・2021年の3要因の年の値がないため、その2年を空けた。
- 経済センサスの企業数は2012年ではなく、2014年（基礎調査）・2016年・2021年を使った。
- 問い直し（3要因の中身）と、TDB の過去の値の修正（頑健性6）、H4 の当てはめ期間の延長（頑健性7）は結果を見た後に足した。
