# 725 購入回数で顧客を5等分すると、同じ回数の人が別の段に分かれるのはどれだけか（実務の型）

RFM 分析などで、購入回数で顧客を5つの段に分けるとき、NTILE(5)（人数で5等分）がよく使われます。ところが購入回数は「1回」「2回」の人がとても多いので、人数でちょうど5等分すると、同じ1回の人が3段・4段・5段に分かれます。どの人がどの段に入るかは、並べるときの2つ目の順で決まります。**ここでは、架空の会員5,000人の購入回数で、NTILE(5)・2つ目の順を変えた NTILE(5)・同じ回数は同じ段にする方法の3通りで段を分け、同じ回数なのに別の段に入った人、段ごとの人数、2つ目の順で段が変わる人を数えました。** DuckDB の SQL と Python で同じ結果になることを確かめています。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A725 | 購入回数の5等分で、同じ回数の人はどれだけ別の段に分かれるか | 架空の会員5,000人の1年間の購入回数（幾何分布に近い、平均2.37回、1回の人42.2%）。NTILE(5)（同じ回数は顧客番号の順）・NTILE(5)（最終購入日の新しい順）・RANK で段を決める方法。seed 725 | `src/a725_rfm_ties.py`、`src/02_rfm_tiers_duckdb.sql`、`src/01_rfm_tiers_tsql.sql`（T-SQL：未検証） |

## 主な結果（5,000人）
| 項目 | 結果 |
|---|---|
| 2つ以上の段に分かれた購入回数 | 1回・2回・3回 |
| その回数の人（分かれる可能性のある人） | **4,058人（81.2%）** |
| 同じ回数の多数派と違う段に入った人 | 1,514人（30.3%） |
| 1回の人（2,109人）が入った段 | 3段・4段・5段 |
| 2つ目の順を顧客番号→最終購入日に変えて段が変わった人 | **1,744人（34.9%）** |

| 段 | NTILE(5) の人数 | 同じ回数は同じ段にした人数 |
|---|---|---|
| 1段 | 1,000 | 1,653（3回以上） |
| 2段 | 1,000 | 1,238（2回） |
| 3段 | 1,000 | 2,109（1回） |
| 4段 | 1,000 | 0 |
| 5段 | 1,000 | 0 |

- NTILE(5) は人数をそろえる代わりに、同じ回数の人を別の段に入れる。どの人がどの段に入るかは、並べる2つ目の順（顧客番号・最終購入日など）で決まる
- 同じ回数の人を同じ段にすると、人数は偏り、5段のうち3段しか使われなかった

## 注意（言えないこと）
- 架空のデータです。購入回数の分布は作成者が置いたもので、分かれる人の割合はこれで決まります
- どの分け方がよいかは、段を何に使うかで変わります。人数をそろえたいなら NTILE、同じ回数を同じ扱いにしたいなら値で区切る方法が向きます。2つ目の順を最終購入日にするのは、回数が同じなら最近の人を上にする、という決め方です
