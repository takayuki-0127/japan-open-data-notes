# 719 施策の開始時期が店ごとにずれ、効果が時間とともに大きくなるとき、ふつうの二方向固定効果の推定はどれだけずれるのか（手法の解説・正解の分かるデータで試す）

施策を店ごとに違う時期に始めたとき、「店の効果＋期の効果＋施策中かどうか」の回帰（二方向固定効果、TWFE）で効果を出すことがよくあります。効果が一定ならこれで正しく出ますが、始めてから効果が伸びていくと、先に始めた店が「比べる相手」に入ってしまい、推定がずれます。**ここでは、効果の本当の大きさが分かる架空の店の12期の売上で、二方向固定効果と、開始時期ごとに分けた差の差の2通りを比べました。** 場面は3つ、各300回くり返しています。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A719 | 開始時期がずれ、効果が伸びるとき、二方向固定効果はどれだけずれるか | 架空の店の12期。2期・5期・8期に始める3グループ（各20店）と施策なしの20店。店の差（標準偏差3）・共通の期の動き・ノイズ（標準偏差1）。効果は一定（+2）または毎期 0.5 ずつ伸びる。二方向固定効果と、グループ×期ごとに「まだ施策をしていない店」と比べる差の差。各300回、seed 719 | `src/a719_staggered_did.py` |

## 主な結果（300回の平均）
| 場面 | 正解（施策した店・期の効果の平均） | 二方向固定効果 | 開始時期ごとの差の差 |
|---|---|---|---|
| 一定の効果・施策なしの店あり | 2.00 | 2.00 | 2.00 |
| 伸びる効果・施策なしの店あり | 2.21 | **0.91** | 2.22 |
| 伸びる効果・施策なしの店なし | 2.21 | **−0.06** | 1.49（同じ店・期の正解 1.50） |

- 効果が一定なら、どちらの推定も正解の2.00と合った
- 効果が伸びると、二方向固定効果は正解の約4割（0.91）にしかならなかった。施策なしの店がない場面では −0.06 で、効果がないように見えた
- 施策なしの店がない場面では、最後のグループ（8期開始）の開始後は比べる相手がいない。差の差はそれより前の期だけで出すので、答えるのは「その店・期の効果」（正解1.50）で、全体の2.21ではない
- 開始時の効果を1にして伸び方を0〜1に変えると、正解は1.00→5.43と大きくなるのに、二方向固定効果は0.91〜1.00のまま動かなかった（各100回）

```
cd src && python a719_staggered_did.py
```

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- 効果が一定の場面で、両方の推定が置いた効果（2.00）と合うこと
- 差の差の推定が、同じ店・期の本当の効果の平均と合うこと（1.49 と 1.50）

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 719）

## 注意（言えないこと）
- 架空のデータです。開始時期・効果の伸び方・ノイズは作成者が置いたもので、ずれの大きさはこれで決まります
- 開始前の動きが施策をした店としていない店で同じ（平行トレンド）と置いています。これが崩れると、どちらの推定もずれます
- 開始時期ごとの差の差は、Callaway と Sant'Anna の方法の考え方を簡単にしたものです（共変量・標準誤差の計算は扱っていません）
- 施策の良し悪しや、実際の施策の進め方についての助言はしません
