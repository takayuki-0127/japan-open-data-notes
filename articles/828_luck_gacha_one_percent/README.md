# 828 ガチャの「1%」を100回引いても当たらない人は、何%いるのか？（運と実力）

当たりの確率が「1%」のくじ（ガチャ）を100回引けば、1回は当たる、と考えがちです。1% × 100回 = 100% という足し算です。しかし、毎回1%で前の結果と関係なく当たりが決まるなら、100回引いても1回も当たらない人が一定の割合で出ます。**ここでは、作成者が乱数で作った架空のゲームの架空のプレイヤー10万人（当たりの確率を作成者が置いたもの）で、100回引いて当たらない人の割合、最初に当たるまでの回数、外れが続いた人のその先を数えました。あわせて、同じ「1%」でも引き方の決まり（毎回1%か、100個に1個の箱から戻さずに引くか）で答えがどう変わるかを確かめました。**

確率の数え方だけを扱います。引くことをすすめたり、すすめなかったりする話はしません。連勝や連敗の長さは関連する記事 827、戻さずに引くくじを何人かで順番に引くときの有利不利は 834 で扱っています。この記事は、1人が何回引けば当たるかに絞ります。

## 主な結果

### 100回引いて、当たった回数（10万人）
| 当たった回数 | 割合（数えた値） | 割合（理屈の値） |
|---|---|---|
| 0回 | **36.6%** | 36.6% |
| 1回 | 36.9% | 37.0% |
| 2回 | 18.7% | 18.5% |
| 3回 | 6.0% | 6.1% |
| 4回以上 | 1.9% | 1.8% |

- 100回で当たった回数の平均は1.00回だった。平均は「1回」でも、0回の人が36.6%、2回以上の人が26.5%いた
- 1万人ずつ10組に分けると、0回の人の割合は35.8〜37.2%の間で振れた

### 何回引けば、何%の人が当たるか
| 当たった人の割合 | 必要な回数（理屈の値） | 数えた値 |
|---|---|---|
| 50% | 69回 | 70回 |
| 63.2% | 100回 | 100回 |
| 90% | 230回 | 230回 |
| 95% | 299回 | 299回 |
| 99% | 459回 | 462回 |

- 最初に当たった回の平均は100.3回、真ん中の人（中央値）は70回だった。平均は、とても長く外れた少数の人に引っぱられて大きくなる
- 300回引いても当たらない人が4.9%いた。10万人の中で最も遅い人は1,302回目だった

### 外れが続いた人が、次の100回で当たる割合
| それまでに外れた回数 | 人数 | 次の100回で当たる割合 |
|---|---|---|
| 0回（はじめから） | 100,000 | 63.4% |
| 50回 | 60,443 | 63.4% |
| 100回 | 36,587 | 63.1% |
| 200回 | 13,494 | 63.4% |
| 300回 | 4,941 | 62.6% |

- 毎回1%なら、外れが続いても次に当たりやすくはならなかった（どれも理屈の値63.4%の近く）

### 確かめ：同じ「1%」でも、引き方の決まりで変わる
| 引き方の決まり | 100回で当たらない人 |
|---|---|
| 毎回1%（前の結果と関係ない） | 36.6% |
| 100個に1個の当たりが入った箱から、戻さずに引く | **0%** |

- 箱から戻さずに引く決まりでは、50回で当たらない人は49.9%、100回では0%だった。最初に当たる回の平均は50.4回だった
- 毎回の確率と回数を変えると、当たらない人の割合は、確率×回数（np）で大まかに決まった（理屈の値 e^(−np) と近い）。たとえば、毎回2%を50回でも、毎回0.5%を200回でも、約36〜37%（`results/miss_by_p_and_draws.csv`）

| 毎回の確率 | 100回で当たらない人（理屈の値） |
|---|---|
| 0.5% | 60.6% |
| 1% | 36.6% |
| 2% | 13.3% |
| 3% | 4.8% |

## 動かし方
```
pip install -r requirements.txt
cd src && python a828_gacha.py
```
数秒で終わります。`data/players.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約1秒）
- 数えた値は、理屈の値（(1−p)^n、二項分布）とほぼ一致した（上の表）
- 1万人ずつ10組に分けると、100回で当たらない人の割合は35.8〜37.2%の間で振れた
- 引き方の決まりを「100個に1個の箱から戻さずに引く」に変えると、100回で当たらない人は0%になり、答えは決まりしだいで大きく変わった

## データ
- `data/players.csv`：架空のプレイヤー10万人（player_id・first_hit（最初に当たった回）・hits_in_100（100回のうち当たった回数））

## 注意（言えないこと）
- 架空のデータです。「毎回1%で、前の結果と関係なく当たりが決まる」と作成者が置いたもので、36.6%はこの置き方から出る値です。実際のゲームの当たりの決まりが、この置き方と同じかどうかは分かりません
- 一定の回数で必ず当たる決まりや、箱から戻さずに引く決まりがあれば、答えは変わります（箱の場合は100回で0%）
- 表示された確率が実際の確率と同じかどうかは、ここでは確かめていません
- くじを引くこと、引かないことをすすめるものではありません。お金の使い方についての助言もしません
- 連勝や連敗の長さは関連する記事 827、戻さずに引くくじを何人かで順番に引くときの有利不利は 834 で扱っています
