# 160 日本人の国内旅行は「日帰り化」していたのか：旅行・観光消費動向調査（2014〜2025年）

観光庁「旅行・観光消費動向調査」の年間値（確報）の集計表から、日本人の国内旅行の延べ旅行者数を宿泊旅行・日帰り旅行に分け、日帰りの割合の推移を目的別・年代別に比べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A160 | 日本人の国内旅行は「日帰り化」していたのか | 延べ旅行者数に占める日帰りの割合（構成比）の推移を、全体・旅行目的別・年代別に比較（2014〜19年と2023〜25年） | `src/a160_daytrip.py` |

## 主な結果
- 延べ旅行者数に占める日帰りの割合は、2014年50.0%、2017年50.1%から、2019年46.9%、2023年43.5%に下がり、2025年は45.8%。「日帰り化」ではなく、むしろ宿泊の割合が少し上がっていた
- 2014→2019年で、宿泊旅行は+4.8%、日帰り旅行は−7.5%。2025年は2019年と比べて宿泊96、日帰り92（2019年=100）
- 観光・レクリエーションの日帰り割合は53〜54%（2014〜19年）から48〜51%（2022〜25年）。出張・業務は2014年54.7%から2023年37.3%まで下がり、2025年43.0%
- 年代別では、日帰りの割合は年齢が上がるほど高い。2014〜19年と2023〜25年を比べると、20〜70代は4〜5ポイント下がったが、80代以上だけは53.7%→57.1%に上がった

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a160_daytrip.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/domestic_trips_by_age.csv | 年、年代（年齢計と9区分）、国内旅行の延べ旅行者数（千人回）：合計、宿泊旅行（計・観光・帰省等・出張等）、日帰り旅行（同） |

各年の「年間 集計表（確報）」Excel（観光庁 https://www.mlit.go.jp/kankocho/tokei_hakusyo/shohidoko.html ）の第3表（延べ旅行者数）をブラウザで読み、書き写しました。

## 注意
- 延べ旅行者数は、1人が何回旅行しても回数分数える値です
- 2017年から2018年にかけて合計が大きく減っており、年による推計の振れが大きい可能性があります。割合（構成比）で比べているのはそのためです
- 2015年の9歳以下・日帰り・出張は元表が空欄（該当なし等）です
- 海外旅行は含みません
