# F145 ごみの量は、有料化のあとに減ったのか？ 段階的な差の差（Callaway–Sant'Anna 型）

## 問い
家庭の可燃ごみの収集を有料にした市区町村では、1人1日あたりの生活系ごみは、有料化しなかった市区町村と比べてどれだけ減ったか。減った分は続くのか。

## データ
- 環境省「一般廃棄物処理実態調査結果」平成24年度（2012年度）〜令和5年度（2023年度）の12年度分
  - 市町村集計結果（ごみ処理状況）「ごみ処理概要」：総人口、1人1日あたりの排出量（合計・生活系・事業系）、リサイクル率
  - 都道府県別の集計結果（ごみ処理体制）「手数料（生活系）」：可燃ごみ・混合ごみの手数料（有料・一部有料・無料・収集なし）
- 取得のしかたは `src/01_取得.md`。抽出した JSON は `data/raw/f145_waste.json`、市区町村×年度のパネルは `data/panel.csv`（1,743市区町村×12年度）。

## 手法
- 処置：家庭の可燃ごみ（可燃ごみの収集がない自治体は混合ごみ）の手数料が「無料」から「有料」に変わった年度。
- 分析の対象（全年度のデータがそろう自治体）
  - 有料化した自治体：83（2014〜2023年度に有料化。有料化の前に2年以上の無料、その後に無料へ戻っていないもの）
  - 最後まで無料の自治体：566（対照）
  - 最初から有料の自治体：992（分析から除外）
  - 途中で無料に戻った、または一部有料をはさむ自治体：65（除外）
- 段階的な差の差（Callaway & Sant'Anna 2021 型、条件なし）を自前で実装。有料化の年度ごとに、前年度を基準として ATT(g,t) を求め、自治体数で重みづけして集計。
- 結果は 1人1日あたりの生活系ごみ（集団回収を含む）の対数。区間は自治体のブートストラップ（499回、シード0）。
- 比較のため、普通の二元固定効果（TWFE）の推定値も出した。

## 結果
- 家庭の可燃ごみを有料にしている市区町村の割合は、12年で 59% → 64% とゆっくり増えた（図1）。分析に使えた新たな有料化は83自治体。
- **有料化のあと、1人1日あたりの生活系ごみは、最後まで無料の自治体と比べて平均 3.5% 減った（95%区間 0.5〜6.6% 減）**。
- 年ごとに見ると、有料化した年度に −4.0%、翌年度 −4.9%、2年後 −4.4%。3年後以降は −2.6〜−4.0% で、区間は0をまたぐ（図3）。
- 有料化の前（−5〜−2年）の差は ±0.6% 以内で、前もって差があったようには見えない（事前の平均 +0.6%、区間 −1.6〜+2.8%）。
- 有料化した年度ごとの効果は −9.2%〜+6.0% とばらつき、1つの年度（2017年度、7自治体）だけ増えた（図4）。
- 生のデータで見ると、有料化した自治体の生活系ごみは有料化の前年を100として、翌年度 94.7 まで下がり、5年後には 98.3 で、最後まで無料の自治体（98.3）と同じ水準に戻った（図2）。
- 事業系を含む総排出量では −1.6%（区間 −4.5〜+1.6%）で、はっきりしない。リサイクル率は −1.1ポイント（区間 −4.0〜+1.4）で、上がったとは言えない。
- 普通の二元固定効果では −3.7%（区間 −7.7〜+0.6%）。
- 同じ期間に、全国の生活系ごみ（人口で重みづけ）は 633 → 550 g/人/日 と13%減っており、有料化しなかった自治体でも減っている。

## 頑健性
| 条件 | 推定値 | 95%区間 |
|---|---|---|
| 主な推定 | −3.5% | −6.6〜−0.5% |
| 対照を「まだ有料化していない自治体」に | −3.5% | −6.7〜+0.2% |
| 一部有料も「有料」とみなす | −4.4% | −7.7〜−1.0% |
| 人口1万人以上の自治体だけ | −4.7% | −6.4〜−2.8% |
| 基準年を導入2年前に | −3.1% | −6.2〜+0.5% |
| 導入年を2014〜2019年度に限る | −3.1% | −6.6〜+0.7% |
| コロナ前（2019年度まで）だけ | −3.9% | −7.0〜−1.0% |
| 結果を総排出量（事業系を含む）に | −1.6% | −4.5〜+1.6% |

向きはどれも「減った」。大きさは3〜5%で、区間が0をまたぐ条件もある。

## 言えないこと
- 有料化の料金の水準（袋1枚の値段）や、同時に行われた分別の変更・収集回数の変更は区別できていない。効果はそれらをまとめたもの。
- 有料化する自治体は自分で決めている。最後まで無料の自治体と、その後のごみの減り方がもともと同じだったという仮定（並行トレンド）に頼っている。事前の差は小さいが、確かめきれるものではない。
- 有料化のあと、ごみが別の経路（事業系への混入、不法投棄、自家処理）に移った分は測れていない。
- 分析に使えた有料化は83自治体と少なく、年度ごとの効果は数自治体で決まる。
- 実態調査の手数料の区分は自治体の回答で、年度の途中で有料化した場合の扱いは分からない。
- 市区町村の順位は出していない。
