# 01 取得

環境省「一般廃棄物処理実態調査結果」（https://www.env.go.jp/recycle/waste_tech/ippan/）から、平成24年度（2012年度）〜令和5年度（2023年度）の12年度分を取得しました。

| ファイル | 年度ごとの場所 | 使った表 |
|---|---|---|
| 市町村集計結果（ごみ処理状況） | `<年度>/data/shori/total/01.xls(x)` | 「ごみ処理概要」：総人口、1人1日あたりの排出量（合計・生活系）、リサイクル率 |
| 都道府県別 集計結果（ごみ処理体制） | `<年度>/data/shori/city/<01〜47>/02.xls(x)` | 「手数料（生活系）」：混合ごみ・可燃ごみの手数料（有料・無料・一部有料・収集無し） |

- 各年度の `index.html` からリンクを読み取り、ブラウザ上で fetch して SheetJS（xlsx 0.18.5）で読み、必要な列だけを JSON にまとめました（`data/raw/f145_waste.json`）。
- 環境省のサーバーに負担をかけないよう、1ファイルごとに4秒以上あけました。
- 列は見出しの文字（「総人口」「生活系ごみ(…)*10^6/総人口」「リサイクル率Ｒ(…)」など）で探しています。年度によって列の位置が変わるためです。
- 手数料の表は、見出し行の「可燃ごみ」「混合ごみ」の下にある「有料・無料・一部有料・収集無し」の4列のうち、○の付いた列を読みました。

再現するには、同じ URL から Excel を取り、`02_整形.py` が読む形（`fee[年度][団体コード]=[名称, 混合ごみの区分, 可燃ごみの区分]`、`amt[年度].out[団体コード]=[名称, 総人口, 合計, 生活系, 家庭系, 事業系, リサイクル率]`）にしてください。
