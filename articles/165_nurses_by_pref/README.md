# 165 看護師は、人口あたりでどの県に多いか：衛生行政報告例（就業医療関係者、2024年末）

厚生労働省「衛生行政報告例（就業医療関係者）」令和6年の統計表から、都道府県別の就業看護師・准看護師などを人口10万人当たりにして、ランキングとタイル地図で比べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A165 | 看護師は、人口あたりでどの県に多いか | 人口10万対の算出、都道府県ランキング、タイル地図（47都道府県を格子に配置）、看護師と准看護師の散布図・相関 | `src/a165_nurses.py` |

## 主な結果
- 就業看護師は全国 136.3万人、人口10万対 1,101人。准看護師は 23.3万人、188人（2024年末）
- 看護師が最も多いのは高知（1,758人）、次いで鹿児島 1,576、長崎 1,528、鳥取 1,509、佐賀 1,497。最も少ないのは埼玉 827、神奈川 837、千葉 837、茨城 895、東京 939。最大と最小で 2.1倍
- 中国・四国・九州・沖縄の17県の平均は 1,442人、それ以外の30都道府県は 1,123人
- 看護師が多い県ほど准看護師も多い（相関 r=0.75）。准看護師の割合は熊本 23.6%、東京 7.2%（全国 14.6%）
- 全国では看護師が 2014年 108.7万人 → 2024年 136.3万人に増え、准看護師は 34.0万人 → 23.3万人に減った

## データ
| ファイル | 中身 |
|---|---|
| data/nurses_by_pref_2024.csv | 都道府県別の就業保健師・助産師・看護師・准看護師（実人員と常勤換算数）、人口（統計表1と参考表） |
| data/nurses_national_trend.csv | 全国の就業保健師・助産師・看護師・准看護師数と人口10万対（2014〜2024年、表1） |

厚生労働省のページ（https://www.mhlw.go.jp/toukei/saikin/hw/eisei/24/）の Excel（統計表1〜5、表1〜6、参考）をブラウザで読み、書き写しました。人口は同じページの「人口10万対比率の算出に用いた人口」（総務省「人口推計」令和6年10月1日）です。

## 注意
- 就業地（勤め先の所在地）で数えた人数です。県境を越えて通勤する人が多い地域（埼玉・千葉・神奈川など）は、住んでいる人に比べて少なく出ることがあります
- 人口当たりの多さは、病床数・高齢化・病院の多さなどの影響を受けます。「看護師が足りているか」は、この比率だけでは判断できません
- タイル地図は各都道府県を同じ大きさのマスで描いた模式図で、実際の面積や位置とは異なります
- 中国・四国・九州・沖縄の区分は、比較のために置いたものです
