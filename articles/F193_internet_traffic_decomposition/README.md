# F193 インターネットの通信量は、どの時間に、どれだけ増えたのか？

総務省「我が国のインターネットにおけるトラヒックの集計・試算」の集計値を、トレンド・季節・2020年春の段差に分けて見ます。あわせて、2020年11月〜2026年5月の一週間の時間帯別の値から、どの時間帯がどれだけ伸びたかを比べます。

## 問い
- 固定ブロードバンドの通信量は、2004年からどれだけ増えたのか。伸び方は時期で変わったのか
- 2020年春の段差はどれだけで、その後も残っているのか
- 1日の中で、どの時間帯がいちばん伸びたのか

## データ
| ファイル | 中身 |
|---|---|
| data/raw/gt010108.xlsx | 総務省 情報通信統計データベース「我が国のインターネットにおけるトラヒックの集計・試算」（2026年5月分まで、令和8年8月31日公表） |
| data/semiannual.csv | 5月・11月（2004年は9〜11月）の全国推計。協力ISP5社（2004年9月〜2018年11月）と9社（2017年5月〜）、下り（out）・上り（in） |
| data/ix_monthly.csv | 国内主要IXの1日平均トラヒックの月平均と1日ピーク（平均は2003年3月〜2026年5月、ピークは1997年1月〜。分析は2011年1月以降が主） |
| data/diurnal.csv | 協力ISP9社のブロードバンド契約者（A1）の一週間の2時間ごとの平均（2020年11月〜2026年5月の12時点） |

## 手法
1. **長期の伸び**：協力ISP5社の推計と9社の推計は水準が違う（重なる4時点で9社÷5社＝下り0.82・上り0.78）。5社の時期を、この比で9社の水準にそろえてつないだ。期間ごとに、対数の通信量を時間と11月のダミーで回帰して年率を出した。
2. **2020年春の段差**：半年ごとの値を「トレンド＋11月ダミー＋2020年5月以降の段差」（と、段差＋傾きの変化）で回帰した。また、コロナ前の伸びをのばした線と実際の比を出した。月次の IX では、月のダミーとトレンド（折れ線）、2011年1月の集計団体の増加（3→5団体）の段差を入れて推定し、STL（周期12、ロバスト）でトレンド・季節・残りに分けた。
3. **時間帯**：2時間ごと・平日／週末ごとに、12時点の対数の値を回帰して年率を出した。2020年11月と2026年5月の比、1日の山と谷の比も出した。

## 結果
- **長期**：下りは2004年9月の約0.18Tbps（つないだ値）から2026年5月の約48.0Tbpsへ、約270倍。上りは約36倍で、上り÷下りは0.83から0.11に下がった。下りの年率は 2004〜09年 38%、2010〜14年 26%、2015〜19年 32%、2021〜26年 16%。
- **2020年春**：下りは2019年11月→2020年5月の半年で+50%（2015〜19年の半年の伸びはふつう+15%）。上りも+48%。
- **段差のその後**：2017〜19年の伸び（9社の推計だけ）をのばした線と比べると、下りは2020年5月に1.30倍まで上に出たが、その後の伸びが鈍く、2026年5月は1.05倍まで戻った。2015〜19年の伸びをのばすと、2026年5月は0.55倍で線の下にいる。上りは2026年5月も1.62倍で、段差が残っている。
- **IX（月次）**：STL の残りは2020年3月+12%、4月+21%、5月+24%、6月+6%。季節は小さく、いちばん高い8月といちばん低い12月の差は約4%。
- **時間帯**（下り、2020年11月→2026年5月で全体2.05倍）：伸びがいちばん大きいのは3〜7時台（平日 3時台2.50倍・5時台2.46倍、年率約15.5%）、いちばん小さいのは23時台（1.92倍、年率約10.9%、95%区間 9.4〜12.5%）。量としていちばん増えたのは19〜21時台（+20Tbps）。山はずっと19〜21時台で、山÷谷は3.41→2.75。昼（9〜17時台）の割合は約33%のままで、週末÷平日も1.13〜1.18でほぼ動かない。

## 頑健性
- **期間**：伸びの推定期間（2010年5月〜・2015年5月〜・2017年5月〜）、コロナ前の線の期間（2015〜19年・2017〜19年・2010〜19年）を変えた。
- **指標**：下り／上り、協力ISP5社をつながない版、IX（月次）で比べた。
- **段差の扱い**：段差だけ／段差＋傾きの変化、2020年の2点を除く、段差の月（IX は3月・4月）を変えた。下りの段差は12通り中9通りで p<0.05（−17%〜+44%）。2010年からの段差だけのモデルでは、2020年以降の伸びの鈍化を段差が吸収してマイナスになった。上りは12通りすべてで +28〜+44%。IX は12通り中10通りで +13〜+31%。
- **時間帯**：5月どうし（2021年5月→2026年5月）、11月どうし（2020年11月→2025年11月）で比べても、いちばん伸びたのは3〜5時台で同じ。いちばん小さいのは、11月どうしでは23時台、5月どうしでは平日13〜15時台と入れ替わった。

## 言えないこと
- 時間帯別の値は2020年11月からしかなく、コロナ前の時間帯の形とは比べられない。昼の割合がコロナで増えたかどうかは、このデータでは分からない
- 早朝が速く伸びた理由（自動更新・バックアップ・録画の配信など）は確かめていない（推測）
- 対象は固定ブロードバンドで、スマートフォンのモバイル通信は入っていない。通信が固定とモバイルの間で移った分は分けられない
- 全国推計は協力ISPの値を契約数のシェアで割り戻した試算で、協力ISPが5社から9社に変わったところで水準が約2割違う。つなぎ方で2015〜19年の伸びが変わる
- 2020年春の段差がコロナによるものかは、同じ時期の他の出来事（動画サービスの画質の変更など）と分けていない
