# 1022 予約の多い日は、当日も多いのか？（予約とキャンセル）

予約の多い日ほど、予約なしで来る客（飛び込み）も多い、と感じることがあります。予約の人数と飛び込みの人数の相関を、全部の日で取ると右上がりに出ることもあります。けれども、予約も飛び込みも曜日で大きく動くので、その右上がりは「予約が多いから」ではなく「金曜や土曜だから」かもしれません。さらに、席が埋まると飛び込みは断るので、記録に残る「座れた飛び込み」は、来たかった人数より少なくなります。**ここでは、作成者が乱数で作った架空の飲食店（48席・夜1回の営業）の2,100日（300週）で、予約の人数と、座れた飛び込み・来たかった飛び込み（断った人も入れる）の相関を、全部の日と同じ曜日どうしで数えました。予約と飛び込みを曜日のほかにつなぐのは季節の振れだけと作成者が置いたので、同じ曜日どうしの「来たかった人数」の相関は、その置き方の写しになります。席の数・季節の振れ・曜日の差を変えた27通りも確かめました。**

前日の夜の埋まり具合と当日の着席の差（当日の飛び込みの客がいる場合を含む）は関連する記事 1017、天気のよい日と比べた「集客の効果」の読み違えは 996、前日までの取り消しと当日の無断を分けて数える話は 1021、予約の数から当日の人数を見込むときの外れ（予約した人のうち来る人の見込み）は 1028 で扱っています。この記事は「予約の多い日と当日の飛び込みの多さのつながり」に絞ります。

## 主な結果

### 予約の人数との相関（48席・2,100日、`results/a1022_main.json`）
| | 全部の日 | 同じ曜日どうし |
|---|---|---|
| 座れた飛び込み（記録に残る人数） | **0.19**（0.193） | **−0.18**（−0.175） |
| 来たい人数（断った人も入れる） | 0.53（0.53） | 0.15（0.151） |

- **全部の日では、予約の人数と座れた飛び込みの相関は0.19と右上がりだった。同じ曜日どうしにすると−0.18と向きが逆になった**
- 来たい人数（断った人も入れる）では、全部の日で0.53、同じ曜日どうしで0.15だった。全部の日の0.53の多くは曜日の差から来ていた
- 同じ曜日どうしの来たい人数の相関0.15は、置いた季節の振れの写し。季節の振れを0にすると0.021になった（`season0_corr`）
- 同じ曜日どうしで座れた飛び込みの相関が負になったのは、予約の多い日ほど空いた席が少なく、来たい人がいても座れないため（作りからの向き）。季節の振れを0にしたときも−0.215だった
- 予約が1人多い日の座れた飛び込みの増え方（回帰の傾き）は、全部の日で+0.099人、同じ曜日どうしで−0.135人、来たい人数では同じ曜日どうしで+0.132人だった

### 予約の多い4分の1の日と少ない4分の1の日（`results/a1022_main.json`）
| | 座れた飛び込み | 来たい人数 | 断った人 |
|---|---|---|---|
| 全部の日：予約の多い4分の1 | 13.11人 | 17.84人 | 4.73人 |
| 全部の日：予約の少ない4分の1 | 9.19人 | 9.19人 | 0人 |
| 同じ曜日の中：予約の多い4分の1 | 10.24人 | 13.25人 | 3.02人 |
| 同じ曜日の中：予約の少ない4分の1 | 11.41人 | 11.43人 | 0.02人 |

- 全部の日で分けると、予約の多い日は座れた飛び込みも多かった（13.11人対9.19人）。同じ曜日の中で分けると、予約の多い日のほうが座れた飛び込みは少なかった（10.24人対11.41人）
- 断った人は、予約の多い日に集まった（全部の日で1日4.73人）

### 確かめ：席の数×季節の振れ×曜日の差（27通り、各2,100日、`results/sensitivity_grid.csv`）
- 同じ曜日どうしの座れた飛び込みの相関は、27通りで−0.435〜0.249と、置き方で向きまで変わった。負になったのは19通り。席の数ごとには、36席で−0.411〜−0.276、48席で−0.435〜0.192、72席で−0.049〜0.249
- 全部の日の座れた飛び込みの相関は−0.336〜0.649。曜日の差を置いた18通りのうち17通りで、同じ曜日どうしの相関より大きかった（例外は36席・季節±30%・曜日の差1倍の1通りで、どちらも負）。36席では全部の日でも−0.336〜−0.269と負だった
- 同じ曜日どうしの来たい人数の相関は、季節の振れの置き方でほぼ決まった（振れ0で−0.043〜0.013、±15%で0.072〜0.12、±30%で0.249〜0.368）。置いたつながりの写し
- 座れた飛び込みの相関は、27通りのうち24通りで来たい人数の相関より小さかった。残りの3通りは、72席で曜日の差なしの、断った人がほぼいない置き方で、2つは同じだった

## 動かし方
```
pip install -r requirements.txt
cd src && python a1022_busy_day.py
```
1秒ほどで終わります。`data/days.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約1秒）
- 季節の振れを0にすると、同じ曜日どうしの来たい人数の相関が0.021になり、置いたつながりがないときにほぼ0に戻ることを確かめた（作りの確かめ）
- 席の埋まらない月〜木で、座れた飛び込みと来たい人数の相関が一致することを確かめた
- 「同じ曜日どうしにすると、座れた飛び込みの相関は全部の日より小さくなる」は、曜日の差を置いた18通りのうち17通りで同じだった。相関の大きさと向きは、席の数と季節の振れで大きく動いた。「0.19」「−0.18」は基本の置き方での値

## データ
- `data/days.csv`：架空の2,100日。day・weekday（曜日）・booked（予約の人数）・booked_arrived（予約して来た人数）・walkin_demand（飛び込みの来たい人数）・walkin_seated（座れた飛び込み）・turned_away（断った人数）

## 注意（言えないこと）
- 架空のデータです。曜日ごとの平均、季節の振れ、日ごとの振れ、席の数は作成者が置いたもので、結果はこれで決まります。同じ曜日どうしの来たい人数の相関は、置いた季節の振れの写しです。実在の店の予約や来店を測ったものではありません
- 新しく数えたのは、記録に残る座れた飛び込みでは、同じ曜日どうしにすると相関の向きが逆になること、その大きさが席の数で−0.435〜0.249と動くことです
- 予約が入ること自体が飛び込みを増やす・減らす（たとえば、予約で混んで見えると入りにくい）という直接のつながりは置いていません。曜日と季節のほかの共通の要因（近くの催しなど）も置いていません
- 実際の記録では、断った飛び込みの人数は残らないことが多いと考えています（推測）。その場合は、来たい人数の相関は数えられません
- 予約の人数から当日の人数を見込む方法や、席の数・予約の受け方の決め方の助言はしません。キャンセル料や料金の決め方の助言もしません
