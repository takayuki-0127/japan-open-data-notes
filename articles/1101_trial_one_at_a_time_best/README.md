# 1101 条件を1つずつ変える試し方で、いちばん良い組み合わせは見つかるのか？（試作と実験）

仕上がりを良くしたいとき、「いつもの条件から、まず温度だけを変えて良かった段階に決め、次に薄め方だけを変えて…」と、条件を1つずつ変えて決めていく試し方がよく使われます。けれども、ある条件の良い段階が、ほかの条件の段階によって変わる（2つの条件の組み合わせの効き目がある）と、1つずつ決めた先がいちばん良い組み合わせとは限りません。**ここでは、作成者が乱数で作った架空の塗りの工房4,000軒（3つの条件×3段階の27通りの組み合わせに、本当の仕上がりの点数を作成者が置いたもの）で、①1つずつ1周、②1つずつ2周、③27通りを1回ずつ試していちばん良かった所、④27通りを1回ずつ試して式を当てはめて選ぶ、の4つの試し方が、本当にいちばん良い組み合わせに着く割合と、着いた所の点数の不足を数えました。組み合わせの効き目の大きさ・測りの誤差・始める条件を変えた24通りも確かめました。**

例の工房と点数は架空のもので、実在の工房・製品の数字ではありません。仕上がりの点数は、塗りのむらの少なさを機械で測った値と置いています（人に聞いて決める点数ではありません）。

関連する記事：組み合わせの効き目を見つけるのに、1つずつの効き目を見つけるときの何倍の件数が要るかは 657「交互作用を見つけるには、主効果を見つけるときの何倍の件数が要るのか」で扱っています。この記事は、組み合わせの効き目があるときに、1つずつ変えて決める試し方がどこに着くかに絞ります。同じ企画の 1102 は試す順番と時間とともに変わる分、1103 は同じ日にまとめて比べることを扱っています。1108「良い方へ少しずつ条件を動かしていくと、いちばん良い所に着くのか？」は良い方へ隣へ隣へと動く試し方が山の2つある地形でどこに着くかを、1110「2つの条件を別々に試した効き目を足して見込むと、組み合わせたときとどれだけずれるのか？」は1つずつ試した結果を足して組み合わせを見込むときのずれを、1107「組み合わせの半分だけを試すと、何と何の効き目が見分けられなくなるのか？」は組み合わせの半分だけを試したときに効き目が重なることを扱っています。

## 主な結果

### 試し方ごとの結果（基本、工房4,000軒、`results/methods_base.csv`）
| 試し方 | 測った回数（平均） | いちばん良い組み合わせに着いた割合 | 着いた所の点数の不足（平均） | 不足の90%点 | 不足1点以内の割合 |
|---|---|---|---|---|---|
| ①1つずつ1周（7条件×4回） | 28.0回 | **42.1%** | 1.277点 | 3.919点 | 60.62% |
| ②1つずつ2周（2回ずつ） | 21.25回 | 49.38% | 1.125点 | 3.692点 | 66.57% |
| ③27通りを1回ずつ、いちばん良かった所 | 27.0回 | 56.93% | 0.56点 | 1.984点 | 77.05% |
| ④27通りを1回ずつ、式を当てはめて選ぶ | 27.0回 | **72.97%** | 0.194点 | 0.752点 | 92.83% |

- ほぼ同じ回数を測っても、1つずつ変えて1周で決めると、いちばん良い組み合わせに着いたのは42.1%だった。27通りを1回ずつ試して式を当てはめると72.97%だった
- ①では、着いた所がいちばん良い所より3〜6点低かった工房が13.03%、6点より多く低かった工房が2.77%あった。④ではそれぞれ0.15%と0.0%だった（`results/a1101_main.json` の `short_bins`）

### 測りの誤差をなくしても（基本、`results/a1101_main.json` の `ofat_noisefree`）
- 測りの誤差を0にしても、1つずつ1周で着いたのは**56.2%**、点数の不足は平均0.866点だった。外れた分は、測りの誤差ではなく、組み合わせの効き目から来ていた
- 条件を変える順番を逆にすると、着いた所が63.65%の工房で変わった（いちばん良い所に着いたのは57.17%）
- 本当にいちばん良い所は、71.73%の工房で3つの条件すべてを、24.9%で2つを、いつもの条件から変えた所にあった。2つ変えた所が答えのとき、誤差のない1周で着いたのは57.73%、3つ変えた所のときは54.48%だった

### 置き方を変えると（24通り、各1,000軒、`results/grid.csv`）
| 組み合わせの効き目の大きさ | 誤差のない①（いつもの条件から） | 誤差のない①（3つとも−1から） |
|---|---|---|
| 0 | 100.0% | 100.0% |
| 1 | 68.5% | 63.1% |
| 2 | 55.0% | 50.8% |
| 4 | 48.5% | 46.0% |

- **組み合わせの効き目が0なら、誤差のない1つずつの試し方はいつもいちばん良い所に着いた（作りどおり）**。条件ごとの良い段階がほかの条件によらないため。組み合わせの効き目があると、誤差がなくても45.8〜68.5%だった
- ①の着いた割合は、24通りで28.1〜100%と、置き方で大きく動いた。③は22.4〜100%、④は34.0〜100%だった
- 測りの誤差がある16通りのうち、①が③より多く着いたのは7通りで、組み合わせの効き目が0か1の置き方だった（たとえば効き目0・誤差1.5点・いつもの条件から：①51.3%、③39.0%）。①は同じ条件を4回測って平均するので、効き目が小さいときは誤差に強かった
- ④は24通りすべてで①と同じかそれより多く着いた（多かったのは22通り）。組み合わせの効き目が0のときも、④と①の差は0〜5.0ポイントだった

### ④の式に入れていない効き目があると（基本の置き方に足した、各4,000軒、`results/a1101_main.json` の `three_way_check`）
| 3つがそろったときだけの効き目 | ①1つずつ1周 | ②1つずつ2周 | ③27通り・いちばん良かった所 | ④27通り・式を当てはめる |
|---|---|---|---|---|
| 標準偏差2 | 38.32% | 50.25% | 62.95% | 58.53% |
| 標準偏差4 | 37.2% | 49.95% | 70.47% | 49.15% |

- 基本の④が強かったのは、当てはめた式の形を、作成者が置いた本当の点数の形と同じにしたため（作りどおりの有利）。式に入れていない効き目を足すと、④は③より着かなくなった。それでも①は、どちらでも4つの中でいちばん少なかった


## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約2秒）
- 組み合わせの効き目0・測りの誤差0の置き方で、4つの試し方がすべて100.0%いちばん良い所に着く（作りどおり）ことを確かめた
- 図3枚を開き、日本語・重なり・軸（棒は0から）を確かめた

## データ
- `data/one_workshop_27.csv`：1軒目の工房の27通り。temp・dilution・brush_speed（各条件の段階 −1・0・+1）・true_score（本当の点数）・observed_1run（1回測った値）・observed_4run_mean（4回測った平均）
- `results/a1101_main.json`：主な結果すべて（`base` に基本、`ofat_noisefree` に誤差なしの①と順番を逆にした①、`best_n_changed` にいちばん良い所がいつもの条件から何個変えた所か、`three_way_check` に式に入れていない効き目を足した確かめ、`grid_` で始まる項目に24通りの範囲）
- `results/methods_base.csv`：試し方ごとの結果
- `results/grid.csv`：24通りの確かめ

## 注意（言えないこと）
- 架空のデータです。1つずつの効き目・曲がり・組み合わせの効き目の大きさ、測りの誤差は作成者が置いたもので、結果はこれで決まります。①の着いた割合は置き方で28.1〜100%と動きました
- 組み合わせの効き目が0なら、誤差のない1つずつの試し方は必ず着きます（作りどおり）。外れの大きさは、置いた組み合わせの効き目の大きさの写しです
- ④が強いのは、当てはめた式の形を置いた点数の形と同じにしたためです。式に入れていない効き目を足すと、④は③を下回りました
- 条件は3つ、段階は3つずつと置きました。条件や段階が多いと、27通りのように全部を試すことはできなくなり、くらべ方は変わると考えています（推測）
- 実在の工房・塗料・製品の条件を表すものではありません
