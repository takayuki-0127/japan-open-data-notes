# 259 統計表を定期的に取り直すとき、何で「変わった」を見つけるか（実務の型）

毎年（毎月）同じ統計表を取り直すとき、前のファイルと何が変わったかを見つける5つの点検を、統計センター「SSDSE-県別推移（SSDSE-B）」の2024・2025・2026年版（47都道府県×12年度×109項目）で比べたフォルダです。本物の版どうしの比較に加えて、保存した2026年版と「同じ版をあとで取り直したファイル」に黙った変化を1つずつ入れた8つの場面で、どの点検が反応するかを数えました。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A259 | 取り直したファイルの「変化」を、どの点検なら空振りなしで見つけられるか | C1 ハッシュ（md5）、C2 行数・列数、C3 項目コード・項目名の並び、C4 年度×地域コードの重複・欠け、C5 重なる年の値の1セルずつの照合（コードで突き合わせ） | `src/a259_version_check.py` |

## 主な結果
- 本物の版：2024年版→2025年版で、重なる11年度分の56,353セルのうち **290セル（0.51%）** の値が変わっていた。すべて労働の5項目（新規求職申込件数・月間有効求職者数・月間有効求人数・充足数・就職件数、いずれも一般）の2019〜2021年度。変化は最大0.06%（差は最大300）。2025年版→2026年版では、重なる年度の値の変化は0セル
- 1列目の見出しは版ごとに「SSDSE-B-2024」「SSDSE-B-2025」「SSDSE-B-2026」と変わる。列名をキーにすると突き合わせが失敗する
- 10の場面（本物2＋作った8）で、過去の年の中身が本当に変わったのは5場面：
  - C5 重なる年の値：5場面すべてで反応、変わっていない5場面での空振り0
  - C1 ハッシュ：5場面すべてで反応したが、空振り4（新しい版が出ただけ、文字コードだけ、列の並びだけ、項目名だけ）
  - C2 行数・列数、C4 キー：1行が抜けた場面だけで反応（5場面中1）
  - C3 列の並び：5場面中0、空振り2（並びや名前だけ変わった場面）

## 動かし方
```
pip install -r requirements.txt
cd src && python a259_version_check.py
```

## データ
- `data/SSDSE-B-2024.csv`・`SSDSE-B-2025.csv`・`SSDSE-B-2026.csv`：統計センターの配布ファイルをそのまま（cp932）
- `results/summary.json`：本物の版の比較、場面ごとの結果、点検ごとの見つけた数・空振りの数
- `results/scenario_matrix.csv`：場面×点検の表
- `results/real_changes_2024_2025.csv`：2024年版→2025年版で値が変わった290セルの一覧（前の値・新しい値）
- `results/real_changes_by_item.csv`：項目ごとのセル数と最大の変化

## 注意
- 本物の版の比較は SSDSE-B の3つの版だけ。ほかの統計表で過去の値がどれくらい変わるかは分からない
- 8つの場面は作成者が作った例（seed 259）で、実際に起きる変化の種類や頻度を表すものではない
- C5 は値の完全一致を見ている。丸めが変わるだけの表では、許す幅を決める必要がある
- 290セルが変わった理由は確かめていない（元の統計の見直しの取り込みかもしれない：推測）
