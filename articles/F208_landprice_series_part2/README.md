# F208 マンションの値段は地価とどう動き、地価の予測はどこで外れ続けるのか？（後編・シリーズD）

看板記事 F208。シリーズD「地価・住宅」の後編です。前編は F207（[articles/F207_landprice_series_part1](../F207_landprice_series_part1)、note 下書き key：n2bb6f9f9aa9c）。

前編の要点（3行）：
- 2006→2026年に同じ地点が続いた1.2万地点で、上がったのは44%。三大都市の中心から10km以内は93%が上がった
- 「駅から離れるとどれだけ下がるか」は、回帰に入れる変数しだいで −3%〜−32% と変わった
- 新しい駅のそばの地価は、開業の前から伸びていた。開業の前後だけでは駅の効果を測れない

後編では、①中古マンションの値段は地価とどう連動しているか、②地価の予測を毎年更新すると、どこで外れやすいか、③データが言えること・言えないこと（シリーズのまとめ）を扱います。新しいデータは取らず、F207・F182・F158・F03 のデータを使いました。

## 問い

1. 中古マンションの㎡単価は、同じ市区町村の地価とどれだけ一緒に動くか。築年数で違うか
2. 地価の予測を「前の年の公示で学習し直す」形で毎年更新したとき、どんな場所で、どちら向きに外れるか。その外れは毎年同じ地点で起きるか
3. 前編と合わせて、地価のデータで言えること・言えないことは何か

## データ

| データ | 内容 | どこから |
|---|---|---|
| 中古マンションの取引 | 国土交通省「不動産取引価格情報」の中古マンション等、2015〜2025年、全国。RC・SRC 造の525,764件 | F182 の `data/condo_clean.csv.gz` |
| 地価公示の履歴 | 各地点の1996〜2026年の価格と、前年と同じ地点が続いたかの印 | F207 の `data/price_hist_1996_2026.csv.gz`・`chg_2007_2026.csv.gz` |
| 地価公示のパネル | 2017〜2026年の地点×年の価格（244,684件） | F158 の `data/panel.csv` |
| 地点の特徴量 | 駅までの距離・乗降客数・容積率・市区町村の人口など30個（2026年時点） | F03 の `data/features.csv` |

## 手法

### A：マンションと地価

- **マンションの値段をそろえる**：log(㎡単価) を、築年数（1年ごとのダミー）、log(面積)、駅までの分、SRC 造、改装の有無で回帰し（市区町村×年の固定効果つき）、その分を差し引いた「品質をそろえた単価」を作った。市区町村×年の平均を指数にした（取引20件以上）
- **地価の変化**：同じ市区町村の住宅地の地点で、前年から同じ地点が続いたものだけの log 変化の平均
- **合わせ方**：地価公示は1月1日時点なので、y 年のマンション取引と y+1 年1月の公示（y 年中の動き）を合わせた（主）。0年・2年ずらしも比べた
- **連動の強さ**：市区町村×年の変化どうしの回帰。年の固定効果を入れて「同じ年の中で、地価が多く上がった市区町村ほどマンションも上がったか」を見た（取引数で重みづけ）。区間は市区町村単位のブートストラップ300回
- **全国の指数**：市区町村の年ごとの変化を、取引数で重みづけして平均し、つないだ

### B：毎年更新した予測の外れ

- F158 の「毎年更新」と同じ形：T 年の地価を、T−1 年の公示で学習した LightGBM（F158 と同じ設定）で予測。20km四方のブロックで5分割し、学習に使っていないブロックの地点を当てる（見ていない場所の予測）。2018〜2026年
- 外れ e＝log(予測)−log(実際)（＋は予測が高すぎ）。地点ごとに9年の平均をとり、地図・地価の水準・その地点の10年の変化・市区町村の人口の増減で分けた
- **外れの持ち越し**：同じ地点の e(T) と e(T−1) の相関。9年すべてそろう23,054地点で、外れのばらつきのうち地点に固有の分（地点平均の分散÷全体の分散）

## 主な結果

### A：マンションは地価より速く上がり、年ごとの連動は「地価1%で0.35%」

| 指標 | 値 |
|---|---|
| 全国の指数（2015→2025年、地価は2016→2026年1月） | マンション 176、地価 136 |
| 市区町村の8年の変化（332市区町村、中央値） | マンション +52%、地価 +12%。マンションが地価を上回ったのは94% |
| 8年の変化どうしの傾き | 0.22（相関0.27） |
| 同じ年の中での連動（年の固定効果つき） | **0.35**（95%区間 0.29〜0.42）、3,387市区町村×年 |
| 年の固定効果なし | 0.23 |
| 市区町村×年の変化どうしの相関 | 0.08 |

- 合わせ方：同じ年1月の公示 0.32、翌年1月 0.35（主）、翌々年 0.27。翌年1月がいちばん強かった
- 築年数別：築0〜9年 0.14（0.01〜0.29）、10〜19年 0.23、20〜29年 0.31、30年以上 0.33。**古いマンションほど地価と一緒に動く**。古い物件ほど値段のうち土地の割合が大きいため、と考えられる（推測）
- 全国の指数で見ると、築20〜29年が 191、築0〜9年が 165 で、新しい物件のほうが伸びは小さかった

### B：予測の外れは「同じ地点で、同じ向きに」続く

| 指標 | 値 |
|---|---|
| 外れの大きさ（中央値、2018〜2026年） | 18.2%（年ごとに 17.1% → 19.5%） |
| ±20%以内の割合 | 54% |
| 外れの向き（中央値） | −2.6%（予測が低め。2023年以降は −2.9〜−3.7%） |
| 同じ地点の前年の外れとの相関 | **0.95**（どの年も 0.947〜0.952） |
| 外れのばらつきのうち地点に固有の分 | **94%** |

外れの向き（地点の9年平均の中央値）：

| 分け方 | いちばん下の区分 | いちばん上の区分 |
|---|---|---|
| 2017年の地価の水準（10等分） | 安い10%：**+20%**（高すぎ） | 高い10%：**−12%**（低すぎ） |
| その地点の2017→2026年の変化（10等分） | 下がった10%：+12% | 上がった10%：−11% |
| 市区町村の人口の増減（2015→20年） | −5%未満：+0.3% | +2%以上：−5.1% |

- 安い地点は高めに、高い地点は低めに外れる（平均に引き寄せられる）。値段が動いた地点ほど、動いた向きと逆に外れる
- 外れは毎年同じ地点で起きるので、「来年は直る」ものではない。予測のずれの多くは、特徴量にない地点ごとの事情から来ていると読める（推測）
- 全国の前年の変化（学習側の地点の中央値）を足すと、外れの向きは −2.6% → −2.2% に縮んだが、外れの大きさは 18.35% → 18.33% でほぼ変わらなかった

## 頑健性

| 確かめたこと | 結果 |
|---|---|
| A：商業地の地価で | 0.26（0.21〜0.30） |
| A：住宅地＋商業地 | 0.30（0.25〜0.34） |
| A：取引50件以上の市区町村×年だけ | 0.34（0.27〜0.42） |
| A：東京圏だけ／東京圏以外 | 0.43（0.35〜0.51）／0.28（0.20〜0.37） |
| A：2020年以降だけ | 0.40（0.29〜0.48） |
| A：公示との合わせ方（0・1・2年） | 0.32・0.35・0.27 |
| B：地点でランダムに分割 | 外れ 13.9%、前年との相関 0.94 |
| B：リッジ回帰 | 外れ 28.0%、前年との相関 0.998 |
| B：住宅地だけ | 外れ 17.4% |
| B：前半（2018〜21）／後半（2022〜26） | 17.5%／18.7%、向き −1.9%／−3.1% |

どの条件でも、「マンションは地価の1%に対して0.25〜0.43%動く」「予測の外れは同じ地点で続く（相関0.94以上）」は変わらなかった。

## 言えないこと

- **マンションの値段の上がり方は、地価だけでは説明できない**：建築費、金利、需要の強さなどは入れていない。マンションが地価より速く上がった理由は、このデータでは分けられない
- **連動は因果ではない**：「地価が上がるとマンションが上がる」のか、その逆か、両方を動かす別の要因かは分けられない。地価公示は年1回の鑑定評価で、取引価格より遅れて動く可能性がある（推測）
- **取引価格は取引された物件だけ**：毎年同じ物件の値段ではない。品質は築年数・広さ・駅までの分・構造でそろえたが、階数・向き・管理の状態などはそろえていない
- **地価の外れは「見ていない場所」の話**：公示地点の値段そのものを去年の値段から当てる話ではない。前年の自分の値段をそのまま使うと、外れ（中央値）は1.3%しかない
- **地点に固有の外れの中身は分からない**：特徴量にない事情（再開発、土地の形、周りの環境など）と考えられるが（推測）、どれかは特定していない
- **特徴量は2026年の値**：前編と同じく、乗降客数や人口の増減は途中や後の値を含む
- **地域の評価ではない**：外れの大きい場所や地価が上がらない場所は、モデルが苦手な場所というだけで、地域の良し悪しではない。市区町村の順位は出していない
- **投資の判断には使えない**：過去の連動と外れ方を数えたもので、将来の値動きの予測ではない

## シリーズDのまとめ

1. 地価の上昇は大都市の中心と人口が増える市区町村に集中し、この10年の上昇の多くは戻りだった（前編）
2. 「何が効いているか」の答えは比べ方しだいで大きく変わり、駅の効果は開業前から出ていた（前編）
3. マンションの値段は地価より速く上がり、年ごとの連動は地価1%で0.35%。古い物件ほど地価と一緒に動いた（後編）
4. 地価の予測は毎年更新しても、同じ地点で同じ向きに外れ続けた。安い所は高めに、高い所は低めに外れる（後編）
