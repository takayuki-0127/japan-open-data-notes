# 1116 平均のダメージがいちばん大きい武器は、決まった回数のうちに倒せる割合もいちばん高いのか？（ゲームの数値設計）

ゲームの武器は、1回の平均のダメージ（期待値）で比べられることがよくあります。けれども、「5回の攻撃のうちに倒せるか」のように決まった回数で勝ち負けが決まる場面では、効くのは平均だけでなく、ダメージの振れ方です。体力が少なめの敵なら振れない武器が確実に倒し、体力が多めの敵なら大きく振れる武器のほうが、たまに倒せます。**ここでは、作成者が置いた架空のゲームの武器4つ（1回のダメージの出方を作成者が置いたもの。平均は C 216 ＞ B 212.5 ＞ D 210 ＞ A 200）で、敵の体力900を5回のうちに倒せる割合を、ダメージの出方の組み合わせをすべて足し合わせて式どおりに数え、乱数の戦い100,000回でも確かめました。敵の体力を500〜1500に変えたとき、攻撃できる回数（2〜12回）と1回あたりに要るダメージを変えた65通り、C の当たり方や敵の体力の散らばりを変えた確かめも行いました。**

例の武器・敵・数値は架空のもので、実在のゲームを表すものではありません。くじ・課金の話ではなく、どの武器を使うべきかも言いません。

関連する記事：同じ企画の 1113「攻撃力を10%上げるのと会心率を10ポイント上げるのでは、与えるダメージはどちらが伸びるのか？」は、1回あたりの平均の伸びと、試し打ちの合計で比べたときの見分けにくさを扱っています。1115「平均のダメージで敵の体力を割って「何回で倒せるか」を出すと、実際の回数とどれだけずれるのか？」は、1つの武器で倒すまでの回数の平均が「体力÷平均」からずれることを扱っています。28冊目 第7章（917「寸法の平均が規格の中でも、外れる品物は何%あるのか？」）は、平均が規格の中でも、ばらつきで外れる品物の割合が決まることを扱っています。1121「敵の体力を1割増やすと、倒すのに要る回数はなぜ1割より大きく跳ねることがあるのか？」は、同じプレイヤーにとって敵の体力を少し増やしたときに、回数と決まった回数で倒せる割合がどう跳ねるかを扱っています。この記事は、武器どうしを比べたときに、平均の順と「決まった回数で倒せる割合」の順が食い違うことに絞ります。

## 主な結果

### 敵の体力900・攻撃5回（`results/a1116_main.json`）
| 武器 | 1回の平均 | 1回の振れ（標準偏差） | 5回で倒せる割合（式どおり） | 乱数の戦い100,000回 | 倒すまでの回数の平均 |
|---|---|---|---|---|---|
| A 安定 | 200 | 6.06 | **100%** | 100% | 5回 |
| B 会心 | 212.5 | 73.61 | 76.27% | 76.07% | 4.959回 |
| C 大振り | **216** | 176.36 | **68.26%** | 68.35% | 4.998回 |
| D 一撃 | 210 | 180 | 40.95% | 40.88% | 4.792回 |

- **平均がいちばん大きい C は、5回で倒せる割合では4つの中で3番目（68.26%）だった。平均がいちばん小さい A が100%でいちばん高かった**。平均の順（C・B・D・A）と倒せる割合の順（A・B・C・D）は、ほぼ逆だった
- 割合は作りどおりに決まる。A は5回の合計が最低でも950で、いつも900に届く。C は5回のうち3回当たれば届くので、60%で当たる5回のうち3回以上の確率（68.26%）になる。D は5回のうち1回でも5倍が出れば届くので、1−0.9⁵（40.95%）になる
- 倒すまでの回数の平均がいちばん少ないのは D（4.792回）だったが、5回のうちに倒せる割合は D がいちばん低かった。D は5倍が出れば早く倒せる一方、出ないと6回かかる（倒すまでの回数の真ん中は6回）

### 敵の体力を変えたとき（攻撃5回、`results/by_hp.csv`）
| 敵の体力 | A 安定 | B 会心 | C 大振り | D 一撃 | いちばん高い武器 |
|---|---|---|---|---|---|
| 800 | 100% | 100% | 68.26% | 40.95% | A・B |
| 900 | 100% | 76.27% | 68.26% | 40.95% | A |
| 1000 | 51.43% | 76.27% | 68.26% | 40.95% | B |
| 1100 | 0% | 36.72% | 33.7% | 40.95% | D |
| 1200 | 0% | 10.35% | 33.7% | 40.95% | D |

- **いちばん高い武器は、敵の体力で A・B・C・D と入れかわった**。C が（同率を含めて）いちばんだったのは、500〜1500の41通りのうち6通り（1025〜1075 と 1375〜1425）だけだった
- 体力1000（A の5回の平均の合計）までは A か B が（同率を含めて）いちばんで、体力1025からは振れの大きい C か D がいちばんだった（C の5回の平均の合計は1080）
- B の76.27%は、5回のうち1回でも会心が出れば届く 1−0.75⁵ の式どおりの値

### 確かめ：1回あたりに要るダメージ×攻撃の回数（65通り、`results/grid.csv`）
| 置き方 | 平均がいちばん大きい C がいちばん | A（平均がいちばん小さい）がいちばん | 要るダメージ150〜190で A がいちばん | 要るダメージ220〜270で C か D がいちばん |
|---|---|---|---|---|
| ①基本（Cは60%で360） | **19通り** | 26通り | 25通り中25通り | 30通り中25通り |
| ②Cは50%で432 | 28通り | 25通り | 25通り中25通り | 30通り中25通り |
| ③Cは70%で309 | 25通り | 26通り | 25通り中25通り | 30通り中29通り |
| ④基本で敵の体力が±10%散らばる | 28通り | 24通り | 25通り中23通り | 30通り中27通り |

- **平均がいちばん大きい C が倒せる割合でもいちばんだったのは、65通りのうち19〜28通りだった**。1回あたりに要るダメージが C の平均（216）より小さい150〜210の35通りでは、C がいちばんだったのは4〜6通りだけだった
- 要るダメージが150〜190の25通りでは、①〜③のすべてで振れのいちばん小さい A がいちばんだった（④でも23通り）。要るダメージが220〜270の30通りでは、振れの大きい C か D がいちばんのことが多かった（25〜29通り）
- 攻撃の回数が12回でも、要るダメージが平均に近いところでは割合が分かれた。要るダメージ200（体力2400）では A 50.94%・B 60.93%・C 66.52%・D 71.76% で、平均では3番目の D がいちばんだった

## 注意（言えないこと）
- 架空のデータです。4つの武器のダメージの出方、敵の体力、攻撃の回数は作成者が置いたもので、結果はこれで決まります。主な割合は、置いた出方から式どおりに決まる値です
- どの武器がいちばんかは、1回あたりに要るダメージと平均・振れの関係で入れかわりました。平均で比べるのが悪いということではなく、回数の決まった場面では平均だけでは順が決まらないということです
- 敵の防御・回復、命中と会心のつながり、攻撃の順番の工夫は入れていません。防御の効かせ方は 1117 で扱っています
- 実在のゲームの武器や敵を表すものではなく、どの武器を使うべきか、どう作るべきかも言えません
