# 338 1918〜20年の流行で、死亡はふだんよりどれだけ多かったのか（人口動態統計）

1918〜20年のインフルエンザの流行（スペインかぜ）の時期の死亡を、前後の年から作った「ふだんの死亡」と比べたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A338 | 1918〜20年の死亡は、ふだんよりどれだけ多かったか。死因・1歳未満・月で見るとどうか | 年ごとの死亡率（人口10万対）に、1910〜27年（1918〜20年と1923年を除く）の直線を当て、差を人数に直す。別の「ふだん」として1916・17・21・22年の死亡率の平均でも計算。死因別（死因年次推移分類）と乳児死亡率にも同じやり方。月別は1920年を1915・1925年の平均と比べる | `src/a338_excess_deaths.py` |

## 主な結果
- ふだんより多かった死亡（直線）：1918年34.0万人（+29.5%）、1919年12.5万人（+10.8%）、1920年24.8万人（+21.1%）、計71.2万人。すぐ前後の4年の平均と比べると26.8万・5.0万・17.0万、計48.8万人。人口（1918年 約5,474万人）1,000人あたり8.9〜13.0人
- 直線の窓を変えると64.7万〜74.1万人。1913〜17年の平均と比べると67.4万人
- 死因別（直線、3年計）：肺炎23.4万人（33%）、結核4.8万人、老衰2.4万人、脳血管疾患1.2万人、心疾患0.7万人、がん0.3万人、そのほか38.4万人（インフルエンザと書かれた死亡を含む）。すぐ前後の4年との比べでは肺炎21.5万人（44%）
- 1歳未満：3年で10.2万人（すぐ前後の4年との比べでは2.8万人）。多かった分の14%（6%）で、ふだんの死亡に占める割合26%より小さい
- 男34.9万人、女36.4万人（直線）
- 1920年の月別：1月は1915・25年の平均の1.79倍、2月1.47倍、3月1.29倍、5月1.10倍。1〜3月だけで16.6万人多い

## ストックの案から変えた点
- 月別・年齢別の死亡数（1910〜1925年）は公開の表で取れなかった。月別は5年おき（1915・1920・1925年）だけ、年齢は1歳未満とそれ以外に分けるところまでにした

## 確かめたこと
- 「ふだん」の作り方を5通りにして幅を出した（`results/a338_main.json` の robust と near_years_baseline）
- 死因ごとの差と「そのほか」の合計は、総数の差と一致する
- 空のフォルダで流し直し、data・results・figures が一致した

## データ
- `data/raw/jinkou_h26_jokan_5-12_cause_by_year.csv`：e-Stat 人口動態統計 平成26年 上巻 第5.12表 死因年次推移分類別にみた性別死亡数及び率（statInfId=000031288450）を UTF-8 にしたもの
- `data/raw/chouki_02-26.xls`（乳児死亡）・`chouki_02-28.xls`（月別出生数及び死亡数）：総務省統計局「日本の長期統計系列」。Internet Archive の保存版から取得（2026-11-12）
- `data/deaths_by_cause_1899_1935.csv` ほか：使った年を抜き出したもの

## 注意（言えないこと）
- ふだんより多かった死亡は、流行で亡くなった人の数そのものではありません。「ふだん」の作り方で49万〜71万人の幅があります
- 年齢ごとの死亡数、1918・1919年の月別は取れていません。流行の山の数は数えられません
- 死因は当時の診断と分類によります。内地の数字で、地域ごとの違いは扱っていません
