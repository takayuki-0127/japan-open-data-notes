# F273 観光白書の「地方への分散」は、宿泊データで見えているか？（精選モード B. 白書・審議会）

観光白書は毎年、外国人の延べ宿泊者数のうち「三大都市圏を除いた地方部」の動きを取り上げています。2026年の国土交通省の審議会資料も、地方部が過去最多になり、割合も2024年30.9%→2025年（速報）33.0%と上がった一方、「このところ3割程度」と書いています。この「地方への分散」が、観光庁「宿泊旅行統計調査」の都道府県の値で見ても言えるのか、分散を測る物差し（地方部の割合・47都道府県のジニ係数・地方部の中の偏り）を変えると答えが変わるのかを確かめたフォルダです。

- 計画（事前登録）：[PLAN.md](PLAN.md)（コミット 947433c、分析の前に置いた）
- 誰が知りたいか：地方の観光の担当者、宿泊・交通の事業者、観光の政策を追う記者や研究者。「地方部が過去最多」という見出しが、偏りがほどけたことまで意味するのかを知りたい人

## 結論
- 外国人の延べ宿泊者数のうち地方部（三大都市圏8都府県以外の39道県）の割合は、2022年の26.0%から2025年は33.7%に戻った。ただしコロナ前の山（2017年41.0%）には届いていない（H1 支持）
- 審議会資料の2020〜2024年の割合（38.3・30.7・26.0・28.5・30.9%）と2024年の地方部5,086万人泊は、この推移表から小数1桁まで再現できた。2025年は資料が速報（33.0%、5,873万人泊）で、確定値では33.7%・6,056万人泊
- 47都道府県のジニ係数は2023年0.797→2025年0.774と、地方部の割合と同じ向きに下がった（H2 支持）。ただし2017年（0.719）・2019年（0.741）より偏りは強いまま。HHI・タイル指数・上位5都道府県の割合でも同じ形
- 地方部の中の偏り：39道県のうち上位5道県が地方部に占める割合は2019年58.9%→2025年59.8%とわずかに上がった（H3 支持、ただし差は0.9ポイント）。2019→2025年に地方部で増えた1,747万人泊のうち、増えた量の上位5道県で70%
- 2019→2025年に2019年を上回ったのは地方部39道県のうち32、三大都市圏8都府県のうち7。真ん中の増え方は地方部1.34倍、三大都市圏1.41倍
- 地方部の増加を分けると、2019→2025年の+1,747万人泊は「全体が増えた分」+2,394万から「割合が下がった分」−647万を引いたもの。2023→2025年は+2,698万のうち925万が割合の戻りの分
- 日本人の延べ宿泊者数の地方部の割合も2011年68.5%→2025年62.6%と5.9ポイント下がった（H4 支持）
- 白書の言い方の確かめ：2024→2025年の伸びは地方部+19.1%・三大都市圏+5.1%で地方部が上だが、2025年の割合（33.7%）は2015〜19年の平均（39.4%）を下回る（H5 支持）。伸び率で見ると「分散」、割合の水準で見ると「戻りの途中」

## 問い直し（結果を見た後で足した）
地方部の目標「2030年に1億3,000万人泊」（明日の日本を支える観光ビジョン）に、全体の伸びと地方部の割合のどちらが効くか。2025年の確定値から延ばす単純な計算（予測ではない）。
- 目標に要る地方部の伸びは年16.5%。コロナ前の2015→2019年の地方部の伸びは年14.4%
- 全体が2015→2019年の伸び（年15.2%）で増えるなら、割合が2025年のまま（33.7%）で1億2,300万人泊とわずかに届かず、要る割合は35.6%
- 全体が2024→2025年の伸び（年9.4%）なら要る割合は46.1%、年5%なら56.6%で、どれもコロナ前の山（41.0%）を超える

## 計画からのずれ
- PLAN を書く前に、外国人と日本人の地方部の割合の年ごとの値を一度見ていた（PLAN.md に書いたとおり）。ジニ係数などは見ていなかった
- R3 の人口は SSDSE-B-2026（統計センター、人口推計をもとにした年度の総人口、2012〜2023年度）を使い、2024・2025年は2023年度の人口で代用した（計画では「人口推計」）
- PLAN の問いの書き出しで「観光白書（令和7年版）が2024年30.9%→2025年33.0%と書く」としたのは誤り。2025年の値を書いているのは2026年の国土交通省の審議会資料で、令和7年版の白書は2025年の値を含まない。問い自体は変えていない
- 問い直し（2030年の目標の計算）は、結果を見た後に決めた
- 図3は都道府県の名前を出さず、増え方の分布だけを示した（結果ファイル B にも名前を入れず、都道府県コードだけ）

- 三大都市圏：埼玉・千葉・東京・神奈川・愛知・京都・大阪・兵庫（国土交通省の業績指標の定義）。地方部はそれ以外の39道県
- 延べ宿泊者数は「人泊」（1人が2泊すれば2）。従業者数が少ない施設も含む全体の値

## 手法
- 年ごとに、地方部の割合、47都道府県のジニ係数・HHI・タイル指数・上位5の割合、地方部39道県の上位5の割合とジニ係数を計算
- 地方部の増加 ＝ 全体の増加×前の割合 ＋ 割合の変化×後の全体（2つの時点の差の分け方）
- 都道府県ごとの2025÷2019年の比（外国人）

## 言えないこと
- 延べ宿泊者数は「泊まった数」で、日帰りの訪問・消費額・混み具合は入っていない。地方部の割合が上がっても、地方で使われたお金や、混雑のゆるみまで同じとは言えない
- 都道府県の単位なので、同じ県の中の観光地の偏り（例：一部の温泉地や都市に集まる）は見えない
- 地方部の割合が下がった・戻った理由（国・地域の構成、航空路線、為替、クルーズ、価格の差など）は、この表だけでは分けられない（推測を含む説明はしていない）
- 2025年の値は確定値で、白書・審議会資料の2025年（速報）とは少し違う
- 問い直しの計算は、全体の伸びと割合を一定に置いた機械的な延長で、見通しではない
- 政策の良し悪しは扱わない
