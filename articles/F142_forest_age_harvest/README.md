# F142 森林は、「切れる木」がどれだけ増えたのか？ — 齢級のコホート推移と伐採量の比較

## 問い
日本の人工林は戦後に植えた木が育ち、「伐って使える時期（主伐期）」に入ったと言われます。
主伐期の森林は実際にどれだけ増えたのか、そして伐採はその増え方に追いついているのかを、公表された集計値で確かめます。

## データ
| データ | 内容 | 時点 |
|---|---|---|
| 林野庁「森林資源の現況」 | 都道府県 × 樹種 × 齢級（5年ごと）の面積（ha）と蓄積（m3）。計画対象森林の立木地 | 2007・2012・2017・2022年の各3月31日現在 |
| 農林水産省「木材統計調査」（木材需給報告書） | 樹種別素材生産量（全国・年、千m3） | 2005〜2024年 |
| 同上 | 都道府県別・樹種別素材生産量（合計） | 2009・2014・2019・2024年 |

- 齢級は5年ごとの区切りで、1齢級＝1〜5年生、11齢級＝51〜55年生です。
- 2017・2022年は「21齢級以上」、2007・2012年は「19齢級以上」が最後の階級なので、19齢級以上にまとめてそろえました。
- 森林資源の現況の蓄積は、実測ではなく、齢級ごとの成長の表（収穫表など）から推計した値です。

## 手法
1. **主伐期の割合**：人工林の面積のうち11齢級以上（51年生以上）の割合を、時点ごと・樹種ごとに計算しました。
2. **コホート推移**：5年たつと齢級は1つ上がるので、「k齢級（t年）」と「k+1齢級（t+5年）」の面積を比べました。5年後に残った割合が100%を下回った分は、伐採や森林以外への転用、データの見直しなどで減った面積です。
3. **蓄積の増えと伐採の比較**：5年間の人工林の蓄積の増え（年あたり）と、同じ期間の針葉樹の素材生産量（年あたり）を比べました。
   - 素材の量は丸太として出てきた量なので、立木の量に直すため 0.7（利用率の仮定）で割りました。
   - 「伐った割合」＝伐採（立木換算）÷（蓄積の増え＋伐採）。1年に増えた木の量のうち、伐って森林の外に出した割合の目安です。
4. **見通し**：2017→2022年の齢級ごとの残り方と、2022年の1齢級の面積が続くとして、2037年までの割合を延ばしました。
5. **地域差**：都道府県ごとに、2017→2022年の人工林の蓄積の増えと2019年の針葉樹の素材生産量から「伐った割合」を出し、地方ごとに集計しました。都道府県の名前は出していません。

## 結果
### 1. 51年生以上の人工林は、15年で3倍になった
- 人工林の面積は 1,033万ha（2007年）から 1,008万ha（2022年）へ少し減りました。
- そのうち11齢級以上（51年生以上）は 215万ha → 360万ha → 510万ha → 644万ha で、割合は 21% → 35% → 50% → 64% になりました。
- 樹種別（2022年）：カラマツ 72%、スギ 70%、ヒノキ 54%。
- 20年生以下（1〜4齢級）は 84万ha から 39万ha へ半分以下になりました。

### 2. 主伐期の世代は、少しずつ減るようになった
- 10齢級以上の世代が5年後に残った割合は、98.7%（2007→12年）、97.5%（2012→17年）、97.1%（2017→22年）でした。年あたりに直すと 0.26%、0.51%、0.57% が減っています。
- 9齢級以下の若い世代はほぼ100%残っていました（98.8%、99.6%、100.2%）。
- 人工林全体の面積は、5年ごとに 5.6万ha、8.5万ha、10.8万ha 減っていました。
- 0.57%／年のペースが続くと、いまの主伐期の面積をすべて伐るには170年以上かかる計算です（単純な割り算による目安）。

### 3. 伐採は増えたが、蓄積の増え方には追いついていない
| 期間 | 蓄積の増え（百万m3/年） | 伐採（立木換算、百万m3/年） | 伐った割合 |
|---|---|---|---|
| 2007→2012年 | 78.9 | 21.4 | 21% |
| 2012→2017年 | 53.4 | 25.0 | 32% |
| 2017→2022年 | 47.7 | 27.6 | 37% |

- 針葉樹の素材生産量は、2007〜11年の平均 1,498万m3 から 2017〜21年の平均 1,934万m3 へ1.3倍になりました。
- 人工林の蓄積は 26.4億m3 から 35.4億m3 に増えました。増え方は年7,900万m3 から4,800万m3 へ小さくなっています。
- 樹種別（2017→22年）：スギ 40%、ヒノキ 22%、カラマツ 83%。カラマツはほぼ増えた分だけ伐っていました。

### 4. 伐った割合は地方で違い、主伐期の森林が多い県ほど伐っているわけではなかった
- 地方別：関東 53%、東北 47%、北海道 46%、九州・沖縄 44%、中国 35%、中部 27%、四国 25%、近畿 18%。
- 都道府県の中央値は 30%（四分位 23〜41%）でした。
- 51年生以上の割合と伐った割合の順位相関は −0.16（ブートストラップ95%区間 −0.46〜0.14、47都道府県）で、はっきりした関係はありませんでした。
- 1県だけ、2017→22年に人工林の蓄積が減っていました（伐った割合は計算できないので図から外しました）。

### 5. 見通し
- 2017→22年の減り方が続くと、51年生以上の割合は 2027年に74%、2032年に81%、2037年に85%になります。まったく伐らないときの87%（2037年）とほとんど変わりません。

### 6. 植え直しの目安（参考）
- 5年で新しく1齢級になった面積を、コホートで減った面積と比べると 57% → 44% → 42% でした。
- ただし1齢級は登録が遅れるため（1→2齢級の比が130〜143%）、その分を補正すると 74% → 62% → 60% です。どちらでも下がる向きでしたが、数え方の影響が大きいので参考値です。

## 頑健性
| チェック | 結果 |
|---|---|
| 主伐期の区切り（10齢級以上／11齢級以上／12齢級以上） | 2022年は 75%／64%／49%。どの区切りでも15年で2〜4倍 |
| 樹種（スギ・ヒノキ・カラマツ） | どの樹種でも割合は上がった。カラマツだけ伐った割合が8割台 |
| 所有（民有林・国有林） | 11齢級以上の割合は民有林 64%、国有林 62%。10齢級以上の5年後の残り方は民有林 97.4%、国有林 96.2%（2017→22年） |
| 期間（3つの5年） | 伐った割合は 21%→32%→37% と毎回上がった |
| 利用率（0.6／0.7／0.8／1.0） | 2017→22年の伐った割合は 40%／37%／34%／29% |
| 伐採の範囲（針葉樹計／スギ・ヒノキ・カラマツ／広葉樹を含む計） | 2017→22年は 37%／34%／39%（利用率0.7） |
| 都道府県の伐採の年（2019年／2019・2024年の平均） | 地方別の順は同じ。順位相関は −0.16／−0.16 |

どの条件でも「主伐期の森林は大きく増えたが、伐った割合は4割前後かそれ以下」という結論は変わりませんでした。

## 言えないこと
- 蓄積は推計値です。推計の方法や森林簿の見直しで変わることがあり、蓄積の増えには「木が育った分」以外の変化も入ります。
- 木材統計の素材生産量には天然林からの伐採も含まれ、暦年です。森林資源の現況は3月末の時点なので、期間が少しずれています。
- 利用率 0.7 は仮定です。0.6〜1.0 に変えた結果も載せました。
- コホートで減った面積には、主伐のほか、転用、災害、データの見直しが混ざっています。間伐は面積を減らさないので、この方法では見えません。
- 「伐った割合」は、伐ってよい量（持続的に伐れる量）を示すものではありません。森林の公益的な機能や採算は扱っていません。
- 都道府県の差の理由（林道、所有の規模、製材工場との距離など）は分析していません。
