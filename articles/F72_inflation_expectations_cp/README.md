# F72 家計は物価が何%上がると思っているのか？：Carlson–Parkin 法で「上がる・下がる」の回答を数値にする

看板記事 F72。note：「家計は、物価が何%上がると思っているのか？ 「上がる・下がる」の回答から予想インフレ率を推定すると、2022年からは5%前後。実際の物価より平均2ポイント高く、1年後より「いまの物価」とよく合っていた」

## 問い

- 消費動向調査の「1年後の物価の見通し」は、「5%以上上がる」「2%未満上がる」「0%程度」のような区分で答える。この回答の割合から、家計の予想インフレ率（何%上がると思っているか）を数字にできるか
- その予想は、実際に1年後になった物価上昇率と比べて当たっているか。「いまの物価」と「1年後の物価」のどちらに近いか
- 年齢や年収で、予想はどれくらい違うか

## データ

| データ | 内容 | 出どころ |
|---|---|---|
| 物価の見通し（全国、二人以上の世帯・単身世帯・総世帯） | 1年後の物価についての回答割合（7区分＋分からない）、2004年4月〜2026年9月の月次 | 内閣府「消費動向調査」長期時系列表3表（e-Stat statInfId 000040512912・000040512925・000040512937、2026年9月調査分） |
| 物価の見通し（属性別、二人以上の世帯） | 世帯主の年齢階級別（000040512915）、世帯の年間収入階級別（000040512917）。9区分（±10%で分かれる）と集計世帯数 | 同上 |
| 消費者物価指数（全国、月次） | 総合、生鮮食品を除く総合など。前年同月比を計算 | 総務省統計局。F12 で取得したもの（`data/raw/cpi_f12.csv`） |

e-Stat の Excel は、ブラウザのページの中で SheetJS で読み、`data/raw/f72_shouhi_price.json` にまとめました。

調査の注意（長期時系列表の注記より）：2013年4月から郵送調査に変わり、標本も6,720世帯から8,400世帯に増えたため、2013年3月と4月の間には段差があります。2018年10月からは郵送とオンラインの併用です。

## 手法

- **Carlson–Parkin 法**：家計の1年後の予想インフレ率が正規分布 N(μ, σ²) に従い、各家計は自分の予想がどの区分に入るかを答える、と考える。区分の境目は −5、−2、−δ、+δ、+2、+5（%）。「0%程度」は −δ〜+δ の幅とみなす
- 毎月、回答割合（「分からない」を除いて合計100%にそろえる）に合うように μ と σ を最尤法で推定。δ は全期間で共通とし、プロファイル尤度で選んだ（0.75%）
- **比較**：その月の消費者物価（総合、前年同月比）と、1年後に実際になった前年同月比。期間を2004/4〜2013/3、2013/4〜2021/12、2022/1〜 に分けた
- **後ろ向き・前向き**：μ を「いまの物価」と「1年後の物価」に回帰（HAC 標準誤差、ラグ12）
- **属性別**：年齢・年収の9区分を7区分にまとめ、同じ δ で推定。9区分のまま（±10% の境目を足す）も計算

## 主な結果

### 推定した予想インフレ率

| 期間 | 予想インフレ率（平均） | 予想のばらつき σ | その月の物価 | 1年後の物価 | 予想 − 1年後 |
|---|---|---|---|---|---|
| 2004/4〜2013/3 | 1.67% | 2.12 | −0.13% | −0.03% | +1.70 |
| 2013/4〜2021/12 | 2.78% | 2.40 | 0.64% | 0.83% | +1.95 |
| 2022/1〜 | 5.30% | 3.17 | 2.94% | 2.78% | +2.52 |
| 全期間 | 2.76% | 2.42 | 0.72% | 0.81% | +1.95 |

- いちばん低かったのは2009年12月（0.02%）、いちばん高かったのは2023年2月（6.89%）。2026年9月は4.92%で、「5%以上上がる」と答えた世帯が48.7%（「分からない」を除く）
- 1年後の実際と比べられる258か月のうち、92%の月で予想が実際を上回った
- 予想が2%を超えた月の割合は、2004/4〜2013/3 で30%、2013/4〜2021/12 で90%、2022/1〜 で100%
- 予想のばらつき σ は予想の水準と一緒に動く（相関0.86）。いちばん大きかったのは2022年12月（4.16）

### 「いまの物価」とよく合う

- 予想と物価上昇率の相関は、同じ月（0.85）や1か月後（0.855）がいちばん高く、1年後（0.54）や1年前（0.52）は低い
- 回帰（全期間）：予想 = 1.98 + 0.81 ×（いまの物価）+ 0.24 ×（1年後の物価）。いまの物価の係数は0.81（標準誤差0.09）で、1年後の物価の係数0.24（0.10）より大きい
- 期間ごとに分けると、1年後の物価の係数はどの期間も0と区別できない（−0.05、0.09、0.06）。いまの物価の係数は0.82、0.34、0.58
- 期間の中だけで見ると、予想と1年後の物価の相関は −0.25、0.12、−0.33 で、ほとんど関係がない

### 年齢・年収

| | 2013/4〜2021/12 | 2022/1〜 |
|---|---|---|
| 世帯主 29歳以下 | 2.45% | 4.50% |
| 30〜39歳 | 2.37% | 4.68% |
| 40〜49歳 | 2.60% | 4.93% |
| 50〜59歳 | 2.80% | 5.31% |
| 60〜69歳 | 2.87% | 5.54% |
| 70歳以上 | 2.89% | 5.36% |

- 年間収入別では、どの期間も収入が低いほど予想が高い。2022/1〜 は300万円未満 5.72%、1,200万円以上 4.59%
- 29歳以下は集計世帯数が月に50〜70世帯と少なく、値は揺れやすい

## 頑健性

| 設定 | 2004/4〜2013/3 | 2013/4〜2021/12 | 2022/1〜 | 基本との相関 |
|---|---|---|---|---|
| 基本（正規分布、δ=0.75） | 1.67 | 2.78 | 5.25 | 1.00 |
| δ=0.25／0.5／1.0 | 1.61〜1.71 | 2.72〜2.81 | 5.25 | 1.00 |
| t分布（自由度5） | 1.55 | 2.67 | 5.10 | 1.00 |
| ロジスティック分布 | 1.58 | 2.70 | 5.14 | 1.00 |
| 「分からない」を0%程度に入れる | 1.55 | 2.70 | 5.16 | 1.00 |
| 中点の平均（±5%以上を±6%とみなす） | 1.58 | 2.61 | 4.27 | 0.99 |
| 中点の平均（±8%とみなす） | 1.78 | 3.00 | 5.30 | 1.00 |

（期間平均は全月で計算。上の「主な結果」の表は1年後の実際と比べられる月だけの平均）

- 動き（時系列の形）はどの設定でもほぼ同じ（相関0.99以上）
- 水準は「5%以上」という上の開いた区分の扱いで変わる。2022年以降は回答の半分前後がこの区分に入るため、中点の平均（±6%）では4.27%、正規分布では5.25%と1ポイント近く違う
- 属性別を9区分のまま（±10% の境目を足して）推定すると、2022/1〜 の予想は0.6〜0.9ポイント高くなる（例：60〜69歳 5.54% → 6.43%）。年齢・年収の並びは同じ
- 期間別に δ を選ぶと、2013年3月以前は0.9、4月以降は0.6
- 消費税率の引き上げで実際の物価が動いた月（2013/4〜2015/3、2018/10〜2020/9 を起点とする月）を除いても、いまの物価の係数0.92、1年後の物価の係数0.20 で同じ形

## 言えないこと

1. 推定した数字は「回答が正規分布から出ている」などの仮定に立っています。とくに「5%以上上がる」の回答が半分前後ある2022年以降は、上の区分の扱いで水準が1ポイント近く変わります
2. 質問は「世帯で日ごろよく購入する品物の価格」についてで、消費者物価指数（総合）とは対象の品目が違います。予想が実際より高いことの一部は、この違いから来ている可能性があります（推測です）
3. 2013年4月は、日銀の大規模な金融緩和の開始と、調査方法の変更（郵送へ）が同じ月です。この月の予想の上がり方を、どちらのせいかに分けることはできません
4. 家計が「なぜ」そう予想したかは分かりません。いまの物価とよく合うことは、予想の作り方の一つの見方にすぎません
