# F236 A/B テストは、何人集めれば「差」が分かるのか

シリーズ「実務に近い分析」（F231〜F245）の6本目。A/B テストを始める前に決める「何人・何日集めるか」を、式とシミュレーションで確かめ、計画に使える表と計算ツール（HTML）を作った。ばらつきの形は公開データ（家計消費状況調査・国民生活基礎調査）から取り、テストのデータはすべてシミュレーション（架空のECサイトを想定）。

## 問い

- 見つけたい差の大きさと、いまの割合（基準）で、必要な人数はどれだけ変わるのか
- 1日の訪問者数が決まっているとき、何日かかり、4週間なら最小でどれだけの差が見つけられるのか
- 人数が足りないまま「有意」になった結果は、信じてよいのか
- 購入率ではなく「1人あたりの金額」を指標にすると、人数はどれだけ要るのか。上位を切る（ウィンザー化）とどれだけ減るのか

## データ

| データ | 中身 | 使い方 |
|---|---|---|
| 総務省「家計消費状況調査」ネットショッピング（二人以上の世帯、2024年平均） | 利用世帯の割合 55.27%、支出額 24,928円／月（全世帯平均）→ 利用世帯あたり 45,102円 | 割合の指標の基準値の1つ（55.3%）、金額の指標の平均 |
| 厚生労働省「国民生活基礎調査」所得金額階級別の世帯の割合（2024年、25階級） | 世帯の分布 | 金額の指標の「形」（右に長い分布）。階級内一様＋2,000万円以上はパレート（α=3.35、1,500万円と2,000万円の生存割合から） |
| シミュレーション | 2群の購入・金額 | 検出力・第1種の誤り・誇張の確認、SQL の検算用データ（data/sim_ab_events.csv.gz） |

公開データは F173（所得分布）と F185（ネット通販）で取得したものを使い回した（新しい取得なし）。基準 1〜30% の割合は、典型的な購入率・クリック率を想定して置いた値で、実在のサイトの数字ではない。

## 手法

- **必要な人数**：2つの割合の差の検定（両側 α=5%・検出力80%）の正規近似の式。金額は2群の平均の差（t 検定）の式
- **シミュレーション**：二項分布で各群の購入数を引き、z 検定で有意かを判定（各条件 6,000〜20,000回）。金額は公開データの形の分布から復元抽出（400回）
- **日数**：必要な人数×2 ÷ 1日の訪問者数を、曜日の偏りをならすため週単位に切り上げ
- **4週間で見つけられる最小の差（MDE）**：人数を固定して、式を差について解く（二分法）
- **誇張（タイプM）・向きの誤り（タイプS）**：検出力を10〜90%に変え、有意になった結果の推定差 ÷ 本当の差と、向きが逆の割合を数える
- **SQL**：SQL Server 互換の書き方で群ごとの購入率・差・z 値を集計（src/04_集計.sql）。SQLite で流して Python と比べた
- **計算ツール**：dashboard/index.html（基準・見つけたい差・1日の訪問者数・検出力・有意水準を入れると、人数・日数・4週間の MDE と日数表を出す）

## 結果

### 1. 必要な人数（1群あたり、両側 α5%・検出力80%）

| 基準＼見つけたい差 | +1% | +2% | +5% | +10% | +20% | +30% |
|---|---|---|---|---|---|---|
| 1% | 15,617,696 | 3,923,650 | 637,010 | 163,095 | 42,693 | 19,827 |
| 2% | 7,729,572 | 1,941,808 | 315,206 | 80,682 | 21,109 | 9,798 |
| 5% | 2,996,698 | 752,703 | 122,124 | 31,234 | 8,158 | 3,780 |
| 10% | 1,419,073 | 356,335 | 57,763 | 14,751 | 3,841 | 1,774 |
| 30% | 367,323 | 92,089 | 14,856 | 3,763 | 963 | 437 |
| 55.3% | 126,888 | 31,681 | 5,047 | 1,251 | 306 | 132 |

- 見つけたい差を半分にすると、人数は約4倍（基準5%で +10%→+5% は 3.91倍）
- 基準が低いほど人数が要る。同じ +10% でも、基準1%は基準10%の約11倍

### 2. 式はシミュレーションと合うか

- 式で出した人数で、シミュレーションの検出力は 79.1〜80.3%（8条件）、差がないときに有意になる割合は 4.8〜5.3%
- 人数を半分にすると、検出力は 50〜52% に落ちる（図2）
- 架空のECサイトの1回分のデータ（基準5%・本当の差+10%・式どおりの31,234人ずつ）では、推定された差は+5.9%、z=1.70（p=0.09）で有意にならなかった。式どおりに集めても、5回に1回はこうなる

### 3. 日数と、4週間で見つけられる最小の差（基準5%）

| 1日の訪問者（2群合計） | +5% を見つける日数 | +10% | +20% | 4週間の MDE |
|---|---|---|---|---|
| 1,000 | 245日 | 63日 | 21日 | +15.1% |
| 5,000 | 49日 | 14日 | 7日 | +6.6% |
| 20,000 | 14日 | 7日 | 7日 | +3.3% |
| 100,000 | 7日 | 7日 | 7日 | +1.5% |

基準2%・1日1,000人なら4週間の MDE は +24.8%、基準10%・1日10万人なら +1.0%。

### 4. 人数が足りないまま「有意」になると（基準5%・本当の差+10%、20,000回）

| 検出力 | 1群の人数 | 有意になった結果の差 ÷ 本当の差 | 向きが逆の割合 |
|---|---|---|---|
| 10% | 1,832 | 3.57倍 | 4.5% |
| 20% | 4,978 | 2.25倍 | 0.5% |
| 29% | 8,202 | 1.82倍 | 0.1% |
| 50% | 15,288 | 1.41倍 | 0.0% |
| 80% | 31,234 | 1.12倍 | 0.0% |
| 90% | 41,813 | 1.06倍 | 0.0% |

### 5. 金額の指標（+5% の差を見つける1群の人数）

| 指標 | CV（標準偏差÷平均） | 1群の人数 |
|---|---|---|
| 金額（全員・買わない人は0） | 1.49 | 13,877 |
| 金額（上位1%で切る） | 1.37 | 11,839（−15%） |
| 金額（上位5%で切る） | 1.29 | 10,475（−25%） |
| 買った人の金額（来訪者数に換算） | 0.88 | 8,815 |
| 買ったかどうか（割合 55.3%） | 0.90 | 5,047 |

- 指標ごとに「+5%」の意味が違う（購入する人が5%増える／1人あたりの金額が5%増える）ので、人数の比較は「同じ相対の差を見つけるなら」の比較
- 金額（全員）を式どおり13,877人ずつ集めても、シミュレーションの検出力は 75.5%（400回）。右に長い分布では式がやや楽観的
- 上位1%で切ると検出力は 78.3% に上がるが、推定される差は +5.0%→+4.75% と小さく出る（上位の伸びを切り捨てるため）

## 頑健性

| 確かめたこと | 結果 |
|---|---|
| 検出力・有意水準・片側（基準5%・+10%） | 主31,234人、検出力90%で41,813人、α1%で46,476人、片側α5%で24,603人 |
| 割り付けの比（対照:処置） | 1:1 の合計62,468人に対し、2:1で69,852人、4:1で96,535人、9:1で171,106人 |
| 金額の分布の形 | 同じ平均・同じ CV の対数正規に替えると、式どおりの人数での検出力は 76.3%（主は75.5%）。上位1%の値は 19.7万円（主は17.8万円） |
| 乱数の種 | 種を5通り変えて、基準5%・+10% の検出力は 79.5〜80.3% |
| 正規近似と厳密 | 基準1%（1群16万人）でも、シミュレーションの検出力は 80.0%、第1種の誤りは 5.3% |
| SQL と Python | 群ごとの購入率・z 値の差は 0（SQLite で SQL Server 互換の SQL を実行） |

## 言えないこと

- **実在のサイトの数字ではない**：基準1〜30% は想定の値。テストのデータはすべてシミュレーション。実際のサイトでは、訪問者の重複・ボット・曜日や季節の偏りがある
- **金額の分布は所得の形を借りた近似**：1人あたりの購入額の分布そのものは公開されていない。平均だけを家計消費状況調査に合わせた
- **途中で結果を見る（のぞき見）と、ここでの人数は当てはまらない**：F237 で扱う
- **前の期間のデータでばらつきを減らす方法（CUPED など）は扱っていない**：F238 で扱う
- **複数の指標・複数の群を同時に見る場合の補正**、効果が人によって違う場合、長く続けると効果が変わる場合（新しさの効果）は扱っていない
