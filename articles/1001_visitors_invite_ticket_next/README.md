# 1001 招待券で増えた人数は、次の回も来るのか？（来場者と集客）

催しで招待券を配ると、その回の来場者は増えます。では、招待券で来た人は次の回にも来て、来場者を押し上げ続けるのでしょうか。招待券で来た人の中には、招待がなくても有料で来た人が混ざっています。招待がなければ来なかった人は、もともと関心の弱い人が多く、次の回に戻る割合は低めです。しかも、次の回に戻った人の中には、前の回に来ていなくても次の回には来た人が入っています。**ここでは、作成者が乱数で作った架空の催し（年2回開く市。春の回と秋の回）の名簿6万人（一人ずつの関心の強さを作成者が置いたもの）で、春の回に招待券を5,000枚配り、同じ乱数で「配った世界」と「配らなかった世界」を作って、招待のおかげで春と秋に増えた本当の人数を数え、よくある3つの読み方と比べました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A1001 | 招待券で春の回に増えた人数のうち、秋の回（招待券なし）にも増えて残るのは何人か。「招待券で来てまた来た人数」「有料の人と同じ割合で戻るとした見込み」は、本当の増え方とどれだけずれるか | 架空の催し（年2回開く市）の名簿6万人。関心の強さ z は標準正規分布。春の回に有料で来る確率は logistic(−2.8＋1.2z)。名簿からでたらめに1万人を選び、でたらめに半分ずつ「招待券を配る5,000人」と「配らない5,000人（比べる相手）」に分けた。招待券を受け取った人の来る確率は logistic(−2.8＋C＋1.2z)、C＝2.0（招待がなくても来た人は、招待されても来る）。秋の回は招待券なしで、来る確率は logistic(−2.8＋1.2z＋H×春に来たか)、H＝0.5（一度来ると次も来やすくなる効き目）。同じ乱数で「配った世界」と「配らなかった世界」を作り、2つの世界の来場者の差を「招待のおかげで増えた本当の人数」とした。比べた読み方は、(1) 招待券で来た人数、(2) 招待券で来た人のうち秋にも来た人数、(3) 招待券で来た人数×有料で来た人が秋にも来た割合（見込み）、(4) 配った5,000人と配らなかった5,000人の秋の来場の差。名簿を作り直して200回くり返した。確かめとして、C を1・2・3、H を0・0.25・0.5・1、配る相手の選び方を「でたらめ」と「関心の強い人ほど選ばれやすい」に変えた24通り（各40回）。seed 1001 | `src/a1001_invite_next.py` |

## 主な結果

### 1回分（`results/a1001_main.json` の main）
| | 人数 |
|---|---|
| 春の回：招待券で来た人 | 1,809人 |
| 　うち招待がなくても有料で来た人 | 452人（24.99%） |
| 　うち招待で増えた人（本当の春の増加） | **1,357人** |
| 秋の回：招待券で来た人のうち、また来た人 | 409人 |
| 秋の回：見込み（招待券の来場1,809人×有料の人が秋にも来た割合28.29%） | 511.72人 |
| 秋の回：配った5,000人と配らなかった5,000人の来場の差 | 124人 |
| **秋の回：招待のおかげで増えた本当の人数** | **67人** |

- **春に招待で増えた1,357人のうち、秋の回の来場者を押し上げたのは67人（4.94%）だった**
- 「招待券で来てまた来た409人」を招待の効果と読むと6.1倍（H＞0 の18通りで2.57〜13.71倍）、「有料の人と同じ割合で戻る」見込み（511.72人）は7.64倍の見積もりになった
- 配った人と配らなかった人を同じ選び方で分けておき、秋の来場を比べると124人で、本当の67人の倍近くになった。この比べ方は向きのそろったずれはないが、1回では振れが大きい（下の200回の結果）

### 秋の回にも来た割合（200回の平均、`results/reps_base.csv`）
| 春の回に来た人 | 秋の回にも来た割合 |
|---|---|
| 有料で来た人 | 28.28% |
| 招待券で来た人（全体） | 21.47% |
| 　うち招待がなくても来た人 | 28.09% |
| 　うち招待で増えた人 | **19.05%** |
| （比べる値）招待で増えた人が、春に来なかった世界で秋に来た割合 | 13.15% |

- 招待で増えた人が秋にも来た割合は19.05%で、有料の人（28.28%）より低かった。関心の弱い人が多いため
- しかも、そのうち13.15%分は、春に来ていなくても秋に来た人だった。招待のおかげで秋に増えたのは、その差の分だけ
- 200回の平均で、春の本当の増加は1,278人、秋の本当の増加は75.4人。秋に残った割合は平均5.9%（10〜90%の範囲5.12〜6.79%）
- 配った人と配らなかった人の差で見た秋の増加は、平均72.6人で本当の値（75.4人）に近いが、1回ごとの振れは大きく、10〜90%の範囲は31.9〜110.1人だった

### 確かめ：招待の効き目・一度来た効き目・配る相手（24通り、各40回、`results/grid_c_h_target.csv`）
- 秋の回に増えた人数が春に増えた人数の何%かは、**0〜16.66%**だった。H＝0（一度来ても次の来やすさが変わらない）と置くと、どの置き方でも0%（式どおり、春に来たかどうかが秋に効かない置き方のため）。H＞0 では2.5〜16.66%
- この割合は、ほぼ H で決まり、招待の効き目 C や配る相手ではあまり動かなかった（H＝1で12.12〜16.66%）
- 招待券で来た人のうち、招待がなくても来た人の割合は17.12〜50.08%。関心の強い人に寄せて配り、C が小さいほど高かった
- H＞0 の18通りで、「有料の人と同じ割合で戻る」見込みは、本当の秋の増加の3.21〜14.01倍、「招待券で来てまた来た人数」は2.57〜13.71倍だった（`results/a1001_main.json` の grid_range）。H＝0 では本当の増加は0人なのに、見込みは196.8〜646.9人になった
- 配った人と配らなかった人の差（でたらめに半分ずつ分けたもの）の40回の平均は、24通りで本当の秋の増加から−10.6〜＋7.7人の範囲にあった。向きのそろったずれはなく、1回ごとの振れ（上の31.9〜110.1人）のほうが大きい

## 動かし方
```
pip install -r requirements.txt
cd src && python a1001_invite_next.py
```
6秒ほどで終わります。`data/invited_and_control.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約6秒）
- H＝0 と置いた12通りで、秋の本当の増加が0人になることを確かめた（同じ乱数で2つの世界を作っているので、春に来たかどうかが秋に効かなければ差は出ない、という作りの確かめ）
- 配った5,000人と配らなかった5,000人の差（でたらめに分けたもの）が、春は平均1,280.7人（本当は1,278人）、秋は平均72.6人（本当は75.4人）で、同じ乱数で作った本当の値に近かった

## データ
- `data/invited_and_control.csv`：1回分の、招待券を配った5,000人と配らなかった5,000人（person_id・interest（作成者が置いた関心の強さ）・invited・control・spring（春の回：有料・招待券・来ない）・spring_without_invite（配らなかった世界で春に来たか）・autumn（秋の回に来たか）・autumn_without_invite（配らなかった世界で秋に来たか））。〜without_invite の列は作成者だけが知る本当の値で、実際には見えません

## 注意（言えないこと）
- 架空のデータです。関心の強さの分布、招待の効き目 C、一度来た効き目 H は作成者が置いたもので、結果はこれで決まります。とくに秋に残る割合は H でほぼ決まり、H＝0 なら0%です。この記事で数えたのは、招待券で来た人の再来場の人数や「有料の人と同じ割合で戻る」見込みが、本当の増え方の何倍に見えるかです
- 招待がなくても来た人は、招待されても来ると置きました。招待券をもらって有料の券を買うのをやめた人の分（売上の減り）は数えていません
- 招待券で来た人が知り合いを連れてくる、口コミで広がる、といった効き目は入れていません
- 秋の回は1回だけ見ました。3回目以降に残るかは数えていません
- 実際の催しの招待券の効き目や、招待券を配るべきかを示すものではありません
- 関連する記事：870（謝礼を付けると、回答者の構成はどう変わるのか）は、謝礼で増える人の顔ぶれをアンケートで扱っています。同じ企画の1000は再来場率を数える日数とデータの締め日、993は延べの来場者と実際の人数、996はキャンペーンの日の効果のうちほかの日から移ってきた人の分を扱っています。この記事は、招待券で増えた人が次の回の来場者をどれだけ押し上げるかに絞りました
