# 238 大学院に進む人は、どの分野で増えて、どこで減ったのか

文部科学省「学校基本調査」の各年度の「専攻分野別 大学院入学状況」（2000〜2025年度）から、修士課程と博士課程の入学者を専攻分野ごとに並べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A238 | 大学院に進む人は、どの分野で増えて、どこで減ったのか | 修士・博士課程の分野別の入学者の推移（2000〜2025年度）／2000→2025年度の増減と構成比／博士課程の分野別の指数（2000年度＝100） | `src/a238_grad_fields.py` |

## 主な結果
- 修士課程の入学者は2000年度の70,336人から2025年度の80,452人へ14.4%増えた（最も多いのは2010年度の82,310人）
- 増えた約1万人の内訳は、「その他」（複数の分野にまたがる研究科など）が+9,219人、工学が+4,931人、保健が+2,117人、芸術が+1,142人。一方、社会科学は−3,441人（−34%）、教育は−3,356人（−64%）、人文科学は−982人（−19%）
- 修士の入学者に占める工学の割合は42.7%→43.5%とほぼ変わらず、「その他」が6.0%→16.7%に増え、社会科学は14.3%→8.2%、教育は7.4%→2.3%に下がった
- 博士課程の入学者は2003年度の18,232人が最多で、2022年度の14,382人まで減り、2025年度は16,212人（2000年度比−4.8%）
- 博士課程で減ったのは人文科学（1,710→879人、−49%）、社会科学（−43%）、農学（−37%）、理学（−26%）、工学（−9%）。増えたのは保健（+990人、+19%）と「その他」（+842人）で、保健は博士の入学者の39.0%を占める
- 女性の割合は修士26.3%→30.8%、博士26.8%→33.3%に上がった

## 頑健性
- 修士・博士課程の入学者の計は、別の表（大学院 年齢別入学者数）の入学者の計と、2000〜2025年度のすべての年で一致した
- 2025年度の「その他」は、計から他の分野を引いた値と、表に載っている「その他」の行の値が修士・博士とも一致した
- コードはきれいなフォルダで3回動かし直し、results と data の全ファイルが一致することを確かめた

## 動かし方
```
pip install -r requirements.txt
cd src && python a238_grad_fields.py   # data/raw の Excel から data/・results/・figures/ を作る
python fetch.py                        # data/raw を e-Stat から取り直す（任意）
```

## データ
- `data/raw/<年度>_N_<statInfId>`：専攻分野別 大学院入学状況（1枚目のシート＝修士課程、2枚目＝博士課程）
- `data/grad_entrants_by_field.csv`：年度×課程×分野の入学者（計・男・女）

## 注意
- 教育の修士課程の減少には、2008年度に始まった教職大学院（専門職学位課程で、この表の修士課程には入らない）に学生が移った分が含まれると考えられる（推測）。専門職学位課程はこの記事では扱っていない
- 「その他」は「自然科学」「社会・自然科学」「人文・社会科学」「その他」の合計で、複数の分野にまたがる研究科が多い。2025年度の修士では「その他」のうち7,959人が細目でも「その他」で、情報系などの新しい研究科が含まれるとみられる（推測）
- 専攻分野は学校基本調査の学科系統分類による。研究科の改組で分類が変わると、分野の増減に見える
- 入学者の数で、進学率ではない。修士課程には博士前期課程を含む

## 出典
文部科学省「学校基本調査」（e-Stat、https://www.e-stat.go.jp/stat-search/files?toukei=00400001）各年度の高等教育機関の表をもとに作成者が加工して作成
