# 617 時間で効き方の変わる要因に、Cox の比例ハザードモデルを当てると、ハザード比は何を表すのか（手法の解説・正解の分かるデータで試す）

Cox の比例ハザードモデルは、「要因の効き方（ハザード比）は時間がたっても同じ」と置いて、1つのハザード比を出します。入会時の割引のように、最初は辞めやすく、あとで辞めにくくなる要因では、この前提が崩れます。**ここでは、架空の会員4,000人（半分が割引で入会）で、割引の会員の本当のハザード比が「0〜3か月は3.0、3〜12か月は1.0、12か月以降は0.7」と変わる場合に、Cox モデルの1つのハザード比が何を表すか、期間を分けるとどうなるか、観察の長さで値がどう変わるかを数えました。** 退会の起きやすさの値は作成者が置いたもので、数字はその仮定で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A617 | 時間で変わる効き方を、1つのハザード比はどう表すか | lifelines の CoxPHFitter（割引のありなし）、期間を0〜3・3〜12・12か月〜に分けた Cox（左打ち切りつき、CoxTimeVaryingFitter）、Schoenfeld 残差による比例ハザードの検定（順位の時間）。観察の長さ6・12・24・36か月で各200回。seed 617 | `src/a617_cox_nph.py` |

## 主な結果
- **36か月まで観察した1つのハザード比**：**1.26**（95%区間1.17〜1.36）。本当の値は3.0・1.0・0.7のどれでもない
- **期間を分けると本当の値に戻る**：0〜3か月 3.00（2.58〜3.49）、3〜12か月 1.03（0.91〜1.17）、12か月〜 0.73（0.64〜0.84）
- **比例ハザードの検定**：p＝2×10⁻³⁸。観察の長さによらず、100回中100回で「比例が崩れている」と出た
- **観察の長さで1つのハザード比が変わる**：6か月 2.39、12か月 1.78、24か月 1.39、36か月 1.23（各200回の中央値）。同じ会員・同じ割引でも、いつまで観察したかで答えが変わる
- 1つのハザード比は、観察した期間の中で「退会が起きた時点の重み」で期間ごとの値をならしたもの。早い時期に退会が多いほど、最初の3か月の3.0に引っぱられる

## 確かめたこと
- 空のフォルダで流し直し、results・figures がバイト単位で一致した
- 期間を分けた推定が、置いた本当のハザード比（3.0・1.0・0.7）を区間の中に含むこと

## データ
- 36か月まで観察した会員の表を `results/members_follow36.csv` に置いた（T：退会か打ち切りまでの月数、E：退会したら1、promo：割引で入会したら1）
- 仮定：基本の退会の起きやすさは月4%で一定、割引の会員だけ期間ごとに倍率が変わる。観察の長さは会員ごとに「上限の半分〜上限」で一様（入会の時期のばらつきを表す）

## 注意（言えないこと）
- シミュレーションの結果。倍率と期間の区切りは作成者が置いたもので、結果はこれで決まる
- 期間の区切りは、本当の区切りを知っているので正しく置けた。実際のデータでは、区切りを生存曲線や残差を見て決める必要がある
- 割引そのものの良し悪しや、価格についての助言ではない。健康の例は使っていない
