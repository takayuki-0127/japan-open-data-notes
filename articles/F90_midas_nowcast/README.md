# F90 月次の統計で、四半期のGDPをどこまで当てられるか？（MIDAS 回帰・ブリッジ方程式・DFM との比較）

## 問い
GDP は四半期に1回、しかも1か月半ほど遅れて出る。それより早く毎月出る統計（鉱工業生産、出荷、雇用など）から、いまの四半期の GDP 成長率をどこまで当てられるか。
月次と四半期という頻度の違うデータをそのまま1本の回帰に入れる **MIDAS 回帰**で推定し、F18 の **ダイナミックファクターモデル（DFM）** と、昔ながらの **ブリッジ方程式** と比べる。

## データ
- F18（`articles/F18_nowcast_dfm`）の月次パネル（景気動向指数の採用系列など20系列、1994年1月〜2026年8月、変換済み）と実質 GDP 前期比（1994Q2〜2026Q2）をそのまま再利用
  - 元データ：内閣府 経済社会総合研究所「景気動向指数」の個別系列、「四半期別GDP速報」2026年4-6月期 2次速報（系列と公表の遅れは `src/common.py`）
- F18 の DFM のナウキャスト（`data/raw/f18_nowcast_base.csv`）も再利用し、同じ四半期・同じ時点で比べる

## 手法
| 手法 | 中身 |
|---|---|
| 疑似リアルタイム | F18 と同じ規則。各系列の公表の遅れを考え、各月末に「その時点で出ていたデータ」だけを使う。時点は四半期の1か月目末・2か月目末・3か月目末・翌月末（1次速報の直前）の4つ |
| MIDAS 回帰（基本） | 1系列ずつ、GDP 前期比を「手に入る最新の月から6か月分の月次値 × 重み」と GDP の手に入る最新期で回帰（直接予測）。重みは指数アーモン型（2パラメータ）、非線形最小二乗。時点（手に入る月の位置）ごとに推定し直す |
| 予測の組み合わせ | 20系列それぞれの MIDAS の予測を平均 |
| ブリッジ方程式（代替案） | 足りない月を月次の AR(2) で埋めて四半期平均にし、GDP に回帰 → 20系列の平均 |
| 比べる相手 | AR(1)（GDP だけ）、F18 の DFM |
| 評価 | 2008Q1〜2026Q2 の74四半期、各四半期は直前までのデータだけで推定。RMSE、AR(1) 比、Diebold–Mariano 検定、符号の一致率 |

## 主な結果
RMSE（前期比、%ポイント）と AR(1) 比：

| 時点 | AR(1) | ブリッジ | MIDAS（20系列の平均） | DFM（F18） |
|---|---|---|---|---|
| 1か月目末 | 1.49 | 1.52（1.02） | 1.46（0.98） | 1.36（0.91） |
| 2か月目末 | 1.59 | 1.41（0.89） | 1.37（0.86） | 1.00（0.63） |
| 3か月目末 | 1.59 | 1.36（0.86） | 1.26（0.79） | 0.90（0.56） |
| 翌月末 | 1.59 | 1.36（0.85） | 1.21（0.76） | 0.89（0.56） |

- MIDAS は月次のデータが出るほど良くなり、翌月末で AR(1) より誤差が24%小さい（DM 検定 p=0.03）。ブリッジ方程式（15%減）よりは良い
- ただし F18 の DFM（44%減）には届かない。翌月末の差は DM 検定で p=0.03
- 1か月目末はどの方法も AR(1) とほとんど変わらない（月次がまだほぼ出ていない）
- 1系列だけで見ると鉱工業生産が最も良く（翌月末 0.59）、在庫率・労働投入量・出荷が続く。金利・マネーストック・消費者態度指数などはほぼ AR(1) と同じで、20系列の単純平均はこれらに薄められる
- 鉱工業生産の重みは、1か月目末では「手に入る最新の月」に5割以上、翌月末では2〜3か月前（＝その四半期の真ん中あたり）に山が移る
- GDP がマイナスだった26四半期のうち、翌月末でマイナスを当てたのは MIDAS 8、DFM 14、ブリッジ 7
- 誤差が大きかったのは 2020Q2（実績 −7.5、MIDAS −1.8、DFM −3.7）、2020Q3、2009Q1 など大きなショックの期

## 頑健性
AR(1) 比（翌月末）。`results/robustness.csv` に4時点・4つの評価期間すべて。

| 設定 | 全期間 | コロナ期を除く | 2008〜2016年 | 2017〜2026年 |
|---|---|---|---|---|
| 指数アーモン・ラグ6（基本） | 0.76 | 0.82 | 0.79 | 0.75 |
| beta ラグ | 0.81 | 0.83 | 0.80 | 0.82 |
| 制約なし U-MIDAS | 0.74 | 0.81 | 0.78 | 0.72 |
| ラグ12か月 | 0.77 | 0.82 | 0.80 | 0.76 |
| GDP の自己ラグなし | 0.76 | 0.81 | 0.77 | 0.75 |
| 20系列の中央値 | 0.78 | 0.83 | 0.81 | 0.77 |
| 一致系列だけの平均 | 0.69 | 0.77 | 0.73 | 0.66 |
| 鉱工業生産だけ | 0.59 | 0.71 | 0.59 | 0.59 |
| ブリッジ方程式 | 0.85 | 0.88 | 0.86 | 0.85 |
| F18 の DFM | 0.56 | 0.67 | 0.57 | 0.55 |

- **ラグの形**（アーモン・beta・制約なし）とラグの長さで結果はほとんど変わらない（0.74〜0.81）
- **系列の数**を絞る（一致系列だけ・鉱工業生産だけ）と良くなる。差を生んでいるのは重みの形より「どの系列を使うか」
- **評価期間**：コロナ期を除いても、前半・後半に分けても順位（DFM ＞ MIDAS ＞ ブリッジ ＞ AR）は同じ
- 「鉱工業生産だけ」は結果を見てから選んだ系列なので、そのぶん有利に出ている

## 言えないこと
- 使ったのはいまの（改定後の）GDP と月次の値で、当時実際に出ていた数字（速報値）ではない。公表の遅れは再現しているが、改定は再現していない（F50 参照）
- 当てる相手も改定後の GDP で、1次速報の数字ではない
- MIDAS は1系列ずつの回帰を平均した。複数系列を1本の MIDAS に入れる、系列を事前に選ぶ、といった別の組み方は試していない
- 「鉱工業生産だけ」が良いのは、結果を見てから選んだ面がある
- 74四半期、うち大きなショックは数期だけで、RMSE はその数期に大きく左右される
- DFM との比較は F18 の設定（因子の数など）のまま。DFM 側の設定は変えていない
