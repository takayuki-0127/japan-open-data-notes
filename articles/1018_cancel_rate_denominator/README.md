# 1018 キャンセル率は、何を分母にするかでどう変わるのか？（予約とキャンセル）

「キャンセル率」は、取り消しの数を何かで割った値です。割る数（分母）を「受けた予約」にするか「泊まった予約」にするか、件数で数えるか人数で数えるか、日付の変更を取り消しに数えるかで、同じ予約から違う値が出ます。**ここでは、作成者が乱数で作った架空の宿3軒の予約台帳（組の人数ごとの取り消しの起きやすさと、日付の変更の割合を作成者が置いたもの）で、同じ1か月の予約を5つの数え方でキャンセル率にし、値と宿の順位がどう変わるかを数えました。置き方を変えた36通りと、1か月の予約の件数による振れも確かめました。**

分母を「全体」にするか「対象者」にするかの一般の話は関連する記事 902、反応率の分母で良い投稿が入れかわる話は 837 で扱っています。前日の夜の埋まり具合と当日の着席の差は同じ企画の 1017、予約を多めに取ったときの「断る人の%」は 1019、前日までの取り消しと当日の無断を1つの率にまとめると何が見えなくなるかは 1021、同じ人の重複した予約で埋まり具合が押し上げられる話は 1024 で扱っています。この記事は、予約の台帳からキャンセル率を出すときの分母と分子の決め方に絞ります。

## 主な結果

### 宿C（基本）の同じ予約を、5つの数え方で（2,000か月の平均、`results/inns_by_definition.csv`）
| 数え方 | キャンセル率（2,000か月の平均） | 1か月ごとの10〜90% | 置いた率からの式の値 |
|---|---|---|---|
| ①取り消し÷受けた予約（変更を除く） | **10.91%** | 8.54〜13.31% | 10.85% |
| ②台帳のまま（変更も取り消し・予約に数える） | 16.85% | 14.33〜19.26% | 16.78% |
| ③取り消し÷泊まった予約（変更を除く） | 12.3% | 9.34〜15.35% | 12.17% |
| ④台帳の取り消し÷泊まった予約 | **20.33%** | 16.73〜23.85% | 20.17% |
| ⑤取り消した人数÷予約の人数（変更を除く） | 12.81% | 9.71〜16.04% | 12.72% |

- **同じ予約でも、数え方で10.91%から20.33%まで動いた**
- ③は①÷(1−①)、②と④は日付の変更の割合、⑤は組の人数ごとの取り消しの起きやすさから決まる式の値どおりで、5つの値そのものは置いた率の写し。新しく数えたのは、宿どうしの順位の入れかわりと、1か月ごとの振れの大きさ
- ⑤が①より高いのは、団体ほど取り消しやすいと置いたため。人数による差を置かないと、⑤と①の差は−0.09〜+0.25ポイントだった（36通りのうち12通り）

### 3軒の宿の順位（`results/a1018_main.json`）
| 数え方 | 宿A（団体が多い） | 宿B（日付の変更が多い） | 宿C（基本） | 1か月ごとに1位だった割合（A／B／C） |
|---|---|---|---|---|
| ① | 10.93% | **9.82%** | 10.91% | 41.3%／17.95%／40.75% |
| ② | 13.25% | **23.57%** | 16.85% | 0%／**99.4%**／0.6% |
| ③ | 12.32% | 10.93% | 12.3% | 41.3%／17.95%／40.75% |
| ④ | 15.32% | 30.92% | 20.33% | 0%／99.4%／0.6% |
| ⑤ | **13.36%** | 11.54% | 12.81% | 46.1%／17.75%／36.15% |

（表の値は2,000か月の平均）

- **①では宿Bがいちばん低い（9.82%）のに、日付の変更を取り消しに数える②では宿Bが23.57%でいちばん高く、99.4%の月で1位だった**
- ①で1位の宿と②で1位の宿が違った月は81.55%、①と⑤で違った月は25.8%だった
- ①では宿Aと宿Cはほとんど同じ（10.93%と10.91%）で、1か月ごとの1位はほぼ半々だった。⑤では団体の多い宿Aが13.36%で上になった
- ③（泊まった予約で割る）は①と同じ順で、1か月ごとの1位も①と同じだった（③は①から式で決まるため）

### 確かめ：取り消しの倍率×日付の変更×人数による差（36通り、各300か月、`results/sensitivity_grid.csv`）
- ①は5.2〜24.27%の範囲になった
- 5つのうち最大÷最小は1.07〜3.879倍だった
- ③と①の差は+0.3〜+7.92ポイントで、①が大きいほど開いた（式どおり）
- ②と①の差は0〜11.74ポイント。日付の変更0%なら0（式どおり）
- ⑤と①の差は−0.09〜+7.76ポイント。人数による差を置かなければ−0.09〜+0.25ポイント

### 確かめ：1か月の件数と、①の1か月ごとの振れ（宿C、各2,000か月、`results/monthly_spread_by_volume.csv`）
| 1か月の予約 | ①の平均 | 1か月ごとの10〜90% |
|---|---|---|
| 30件 | 10.85% | 3.7〜18.75% |
| 100件 | 10.94% | 7.0〜15.09% |
| 300件 | 10.86% | 8.63〜13.21% |
| 1,000件 | 10.83% | 9.59〜12.1% |

- 1か月300件でも、①は月によって8.63〜13.21%と振れた。宿Aと宿Cの①の差（0.02ポイント）は、この振れよりずっと小さい

## 注意（言えないこと）
- 架空のデータです。組の人数ごとの取り消しの起きやすさ、団体の割合、日付の変更の割合は作成者が置いたもので、5つの値の差はこれで決まります。実在の宿の台帳ではありません
- どの数え方が正しい、とは言えません。何を知りたいか（予約の受け方を見るのか、空いた部屋を見るのか）で、使う分母が変わります（推測）
- 無断で来ない人、日付を変えたあとにさらに取り消す人、同じ人の重複した予約は入れていません
- 取り消しの数を、取り消した日の月で数えるか泊まる日の月で数えるかの違いは扱っていません。ここではすべて泊まる日の月で数えています
- キャンセル料・料金の決め方の助言はしません。数え方だけを比べています
