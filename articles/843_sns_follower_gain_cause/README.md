# 843 フォロワーが増えた日の、本当の原因の投稿はどれか？（SNSと動画）

SNS の運用では、フォロワーがたくさん増えた日を見て「この日の投稿が効いた」と読むことがよくあります。しかし、1本の投稿が連れてくるフォロワーは、投稿した日だけでなく、そのあと何日かにわたって少しずつ届きます。ある日の増加には、前の日までの投稿の分と、投稿と関係のない普段の増加も混ざっています。**ここでは、作成者が乱数で作った架空の SNS アカウント（投稿ごとに「本当に連れてきたフォロワーの数」を作成者が置いたもの）で、「その日の増加」「次の投稿までの増加」「届き方を置いて分ける」の3つの読み方で、本当に効いた投稿をどれだけ当てられるかを数えました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A843 | フォロワーの増加を投稿ごとに分けるとき、読み方で本当に効いた投稿をどれだけ当てられるか | 架空のアカウントの180日。毎日50%の確率で1本投稿する（1日に2本以上はなし）。1本が本当に連れてくる人数は中央値30人の対数正規分布（対数の標準偏差1.0）。その人数は投稿の日から14日（当日〜13日後）にかけて届き、届く割合は1日ごとに減る（半分になるまでの日数 1.5日。当日に37.1%、3日目までに75.1%）。普段の増加は1日20人。日ごとの増加は、普段の増加と届いた分を足した値を平均とするポアソン分布から引く。読み方は3つ。①その日の増加：投稿した日の増加をその投稿の成果とする。②次の投稿までの増加：投稿の日から次の投稿の前日までの増加の合計から、普段の増加（1日20人。作成者が教えた値）を日数分引く。③届き方を置いて分ける：届き方の形（半分になるまで1.5日）を置き、日ごとの増加を、投稿ごとの人数と普段の増加に分ける（非負の最小二乗。普段の増加も一緒に見積もる）。当たりは、最後の13日の投稿（届き切らない）を除いて、上位10本のうち本当の上位10本に入っていた割合、1位が本当の1位だった割合、順位の相関（スピアマン）で数えた。アカウントを作り直して300回の平均。確かめとして、半分が届くまでの日数を0.5・1.5・4日、投稿の確率を30%・50%・80%に変えた場合（各100回）と、③で届き方を1.5日と決め打ちしたまま本当の届き方を変えた場合も数えた。seed 843 | `src/a843_follower_cause.py` |

## 主な結果

### 読み方ごとの当たり（基本の置き方、300回の平均）
| 読み方 | 上位10本の当たり | 1位が本当の1位 | 順位の相関 |
|---|---|---|---|
| ①その日の増加 | **64%**（63.5%） | 70.7% | 0.65 |
| ②次の投稿までの増加 | 53%（53.3%） | 44.3% | 0.59 |
| ③届き方を置いて分ける | **84%**（83.5%） | 83.0% | 0.82 |

- その日の増加で選んだ上位10本のうち、本当の上位10本に入っていたのは64%だった。届き方を置いて分けると84%に上がった
- 次の投稿までの増加を合計する読み方は、その日の増加よりも当たらなかった。次の投稿が早いと自分の届く分を取りこぼし、前の投稿の届く分を拾うためと考えられる（推測）
- ③で一緒に見積もった普段の増加は、平均19.21人（置いた値は20人）だった

### いちばん増えた日（300回の平均）
| | 割合 |
|---|---|
| いちばん増えた日に投稿があった | 100% |
| その日の増加（見込み）のうち、その日の投稿から | 73.1% |
| 前の日までの投稿から | 13.8% |
| 普段の増加 | 13.1% |
| その日の投稿が、本当に1位の投稿だった | 70.7% |

- いちばん増えた日だけを見るなら、7割はその日の投稿が本当の1位だった。1本の人数が大きく散らばる（強い投稿が飛び抜ける）と置いたためで、いちばん増えた日にはその日の投稿の分が大きく出やすい
- それでも3割は、その日の投稿は本当の1位ではなかった

### 確かめ：届き方の速さと投稿の頻度を変えると（上位10本の当たり）
| 半分が届くまで | 投稿の確率 | ①その日の増加 | ②次の投稿まで | ③分ける（正しい届き方） | ③分ける（1.5日と決め打ち） |
|---|---|---|---|---|---|
| 0.5日 | 30% | 86.4% | 84.1% | 90.0% | 82.4% |
| 0.5日 | 50% | 85.4% | 83.3% | 89.6% | 80.7% |
| 0.5日 | 80% | 86.5% | 83.1% | 90.5% | 82.6% |
| 1.5日 | 30% | 68.9% | 63.2% | 84.8% | 84.8% |
| 1.5日 | 50% | 65.0% | 53.9% | 83.6% | 83.6% |
| 1.5日 | 80% | 59.2% | 50.2% | 82.4% | 82.4% |
| 4日 | 30% | 51.6% | 43.9% | 72.4% | 63.7% |
| 4日 | 50% | 43.6% | 34.3% | 70.8% | 61.9% |
| 4日 | 80% | 36.8% | 26.3% | 66.5% | 60.1% |

- その日の増加の当たりは、置き方で36.8〜86.5%と大きく動いた。届き方がゆっくりなほど、投稿が多いほど下がった
- 届き方がすぐ（0.5日）なら、その日の増加でも85%前後当たり、届き方を1.5日と決め打ちして分けるよりよかった（80.7〜82.6%）。分ける読み方は、置いた届き方が外れると当たりが下がる
- 届き方がゆっくり（4日）のときは、決め打ちが外れていても、分ける読み方（60.1〜63.7%）のほうがその日の増加（36.8〜51.6%）より当たった

### 1回分（data/）
- 投稿は82本。いちばん増えた日は47日目（273人）で、その日の投稿があり、その日の増加の見込みのうち82.8%がその日の投稿、9.9%が前の日までの投稿から来ていた

## 動かし方
```
pip install -r requirements.txt
cd src && python a843_follower_cause.py
```
20秒ほどで終わります。`data/daily.csv`・`data/posts.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約11秒）
- 届き方の速さ（0.5・1.5・4日）と投稿の頻度（30・50・80%）を変えると、その日の増加の当たりは36.8〜86.5%と動いた。届き方が1.5日以上なら、どの頻度でも分ける読み方のほうが当たった
- 分ける読み方で届き方を1.5日と決め打ちしたまま本当の届き方を変えると、0.5日では当たりがその日の増加より下がり（80.7〜82.6%対85.4〜86.5%）、4日では上だった（60.1〜63.7%対36.8〜51.6%）

## データ
- `data/daily.csv`：1回分の180日。day・gain（実際の増加）・posted（投稿した日なら1）・exp_base（普段の増加）・exp_same_day_post（その日の投稿から届く見込み）・exp_earlier_posts（前の日までの投稿から届く見込み）
- `data/posts.csv`：1回分の投稿82本。post_id・day・true_followers（本当に連れてきた人数）・est_same_day・est_until_next・est_split（3つの読み方での見積もり）

## 注意（言えないこと）
- 架空のデータです。1本が連れてくる人数の散らばり、届き方の形と速さ、普段の増加、投稿の頻度は作成者が置いたもので、当たりの大きさはこれで決まります（その日の増加で36.8〜86.5%）
- 分ける読み方は、届き方の形（1日ごとに一定の割合で減る）が投稿によらず同じと置いています。実際には投稿ごとに届き方が違ったり、ほかのアカウントに紹介されて急に届いたりします。その場合の当たりは数えていません
- 「次の投稿までの増加」では、普段の増加（1日20人）を作成者が教えたうえで引いています。実際にはこの値も見積もる必要があります
- フォローを外す人（減る分）は入れていません。増加は新しくフォローした人の数として扱いました
- 実際の SNS の集計の仕組みや、フォロワーの増え方を表すものではありません
