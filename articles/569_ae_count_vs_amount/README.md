# 569 死亡率の実績と予定の比を、件数で見るか保険金額で見るかで、どれだけ違うのか（保険数理・架空の保有契約）

保有契約の死亡率が予定と比べてどうだったかを見る「実績と予定の比（A/E）」は、**件数**（亡くなった人数 ÷ 予定の人数）でも、**保険金額**（亡くなった人の保険金額の合計 ÷ 予定の保険金額）でも計算できます。保険金額が大きい契約ほど死亡率が低いと、2つの A/E はずれます。また、金額で見ると大きな契約の1件で値が動くので、ぶれも大きくなります。ここでは、架空の保有契約5万件で、2つの A/E の差とぶれを数えました（各条件500回）。数字は置いた前提で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A569 | 件数の A/E と金額の A/E は、どれだけ違い、どれだけぶれるか | 架空の保有契約5万件（30〜70歳）。予定の死亡率は Gompertz–Makeham 型の架空の表。保険金額は対数正規（中央値1,000万円、σ=0.5・0.8・1.2）。本当の死亡率＝予定×(保険金額/1,000万円)^(−β)、β=0（関係なし）と0.2（金額が大きいほど低い）。1年分の死亡を500回引き、件数と金額の A/E、正規近似の95%区間（件数 Σq(1−q)、金額 Σ金額²q(1−q)）と、本当の比を含んだ割合を数えた。金額の5等分ごとの件数の A/E は同じ契約で200回分を合計。1回分の A/E は DuckDB（1スレッド）の SQL でも計算し Python と一致を確認。seed 569 | `src/a569_ae.py`、`src/a569_ae.sql`、`src/a569_ae_tsql.sql` |

## 主な結果
- 予定の死亡数は1年で約180人
- **金額と死亡率が関係ないとき**（β=0）：どちらの A/E も平均 1.00。ただし95%区間の半分の幅は、件数 ±0.145 に対し、金額は σ=0.5 で ±0.165、0.8 で ±0.199、1.2 で ±0.285 と広がる
- **金額が大きいほど死亡率が低いとき**（β=0.2、σ=0.8）：件数の A/E は平均 1.01、金額の A/E は平均 0.89。σ=1.2 では 1.03 と 0.77
- **1年分では逆に出ることもある**：件数の A/E の標準偏差は 0.077、金額は 0.094（β=0.2、σ=0.8）。差 0.12 に対してぶれが大きいので、1年だけ見ると金額の方が高く出る年もある（例の1回は件数 1.09、金額 1.12）
- **金額の5等分ごとの件数の A/E**（200回分を合計）：下位20% 1.27、20〜40% 1.10、40〜60% 1.00、60〜80% 0.89、上位20% 0.80。上位20%の契約が保険金額の合計の48%を占めるので、金額で見ると低い A/E が重く数えられる
- **区間の当たり方**：正規近似の95%区間が本当の比を含んだ割合は、件数 94.4〜96.8%、金額 94.4〜99.0%

## 確かめたこと
- 空のフォルダで流し直し、results がすべて一致した
- 例の1回の件数と金額の A/E、区間の幅が、Python と DuckDB の SQL で一致すること（T-SQL 版は SQL Server では動かしていない：**未検証**）

## データ
- データはコードの中で乱数から作る（seed 569）。例の1回分の契約（5万件）を `results/example_portfolio.csv` に置いた

## 注意（言えないこと）
- 架空の死亡率と架空の契約。死亡率と保険金額の関係（β）は作成者が置いたもので、実際の関係ではない
- 区間は正規近似。予定の死亡数が少ないときや、金額がとても偏っているときは当てはまりが悪くなる
- 件数と金額のどちらで見るべきかは目的で決まる。死亡率の設定や保険料・責任準備金への使い方の助言ではない
