# 347 災害の多い年と少ない年があるとき、件数をポアソンで見ると備えはどれだけ足りなくなるのか

災害の件数には、多い年と少ない年があります。年による当たり外れがあるのに、件数を「毎年同じ平均のポアソン分布」として備えを決めると、100年に1度の年の件数をどれだけ小さく見積もるのかを、本当の分布が分かる架空のデータで測ったフォルダです。F168（猛暑日の過分散）の考え方を、損害の件数に当てています。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A347 | 年による当たり外れがあるとき、ポアソン分布で置いた99%点（100年に1度の年の件数）は本当の値よりどれだけ小さいか。過去の記録から見積もるとどうなるか | 当たり外れの強さを6通りに変えた件数の分布（負の二項分布）とポアソン分布の99%点を比べる。過去10〜100年の記録に2つの分布を当てはめるシミュレーションを2,000回 | `src/a347_overdispersion.py` |

## データの作り方（架空）
- 年の災害の件数は平均10件。当たり外れなしはポアソン分布（分散＝平均）。当たり外れありは、その年の「起きやすさ」がガンマ分布で変わる形（負の二項分布）。分散÷平均が1.5・2・3・6・11倍の5通り
- 1件の損害額は対数正規分布（平均1、σ=1.2）。1年の損害額の合計の99%点は40万年分のシミュレーションで出した
- 乱数の種は347。実在の災害や会社の数字ではありません

## 主な結果
### 本当の分布が分かっているとき（ポアソンで置いた99%点は18件）
| 分散÷平均 | 本当の99%点（件数） | ポアソンで置いたときの不足 | ポアソンの「100年に1度」を実際に超える頻度 | 損害額の合計の99%点の不足 |
|---|---|---|---|---|
| 1倍（当たり外れなし） | 18件 | 0% | 139年に1度 | 0% |
| 1.5倍 | 20件 | −10% | 41年に1度 | −4% |
| 2倍 | 23件 | −22% | 23年に1度 | −7% |
| 3倍 | 26件 | −31% | 13年に1度 | −13% |
| 6倍 | 35件 | −49% | 8年に1度 | −26% |
| 11倍 | 48件 | −63% | 6年に1度 | −41% |

- **分散が平均の2倍あるだけで、ポアソンの「100年に1度」は23年に1度の頻度で超えられた**。6倍では8年に1度
- **損害額の合計で見ると不足は小さくなる**（6倍で−26%）。合計の揺れには、1件ごとの損害額の散らばりも入っているため

### 過去の記録から見積もるとき（分散÷平均が6倍、本当の99%点35件）
| 過去の年数 | ポアソンで置く（中央値） | 負の二項分布を当てはめ（中央値、10〜90%の範囲） | 当たり外れに気づけた割合（分散÷平均の検定、5%水準） |
|---|---|---|---|
| 10年 | 18件 | 33件（21〜49件） | 96% |
| 20年 | 18件 | 34件（26〜45件） | 100% |
| 50年 | 18件 | 35件（29〜42件） | 100% |
| 100年 | 18件 | 35件（31〜40件） | 100% |

- **負の二項分布を当てはめれば中央値は本当の値に近づくが、20年分では26〜45件と幅が広い**。誤差（RMSE）は20年で22%、100年で10%。ポアソンで置くと年数を増やしても49%のまま
- 分散÷平均が3倍のとき、10年分の記録で当たり外れに気づけたのは76%、20年分で93%
- **本当に当たり外れがないとき、負の二項分布を当てはめても損は小さい**。20年分で誤差は8%（ポアソンで置くと6%）。記録の約6割で分散が平均以下になり、当てはめはポアソンに戻った

## 動かし方
```
pip install -r requirements.txt
cd src && python a347_overdispersion.py
```
`data/example_counts_50y.csv`（50年分の件数の例）、`results/main.json`、`results/true_vs_poisson.csv`、`results/estimated_from_history.csv`、`figures/` の3枚ができます（約10秒）。

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures がバイト単位で一致した
- 負の二項分布の99%点は scipy の分布関数から、損害額の合計の99%点はシミュレーションから出した

## 注意（言えないこと）
- すべて架空のデータです。不足の幅は、置いた平均（年10件）と当たり外れの強さで決まります。実際の災害で分散が平均の何倍あるかは、このフォルダでは調べていません
- 当たり外れは年ごとに独立としています。多い年が続く・だんだん増えるといった流れは入れていません（増えていく場合は F244・F256）
- 件数は整数なので、99%点は1件きざみです。「139年に1度」のように、ちょうど100年に1度にならないのはそのためです
- 損害額は件数と無関係としています。件数の多い年に1件の損害も大きくなる場合は、合計の不足はもっと大きくなります
- 備えの額や再保険について助言するものではありません
