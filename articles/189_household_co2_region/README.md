# 189 1世帯あたりのCO2排出量は、寒い地域ほど多いのか：家庭部門のCO2排出実態統計調査

環境省「家庭部門のCO2排出実態統計調査」の2023年度の結果から、1世帯あたりの年間CO2排出量とエネルギー消費量（電気・都市ガス・LPガス・灯油）を10地方で比べ、寒い地方ほど多いのか、何が差を生んでいるのかを見たフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A189 | 1世帯あたりのCO2排出量は寒い地方ほど多いか | 地方別のエネルギー種別内訳（CO2・エネルギー消費量）、電気の排出係数の逆算（電気のCO2÷電気の消費量）、戸建・集合別の比較、2022年度との比較 | `src/a189_region.py` |

## 主な結果
- 電気・ガス・灯油による1世帯あたりのCO2は、北海道4.14 t、東北3.46 t、北陸3.45 tが多く、全国2.47 tの1.4〜1.7倍。少ないのは九州1.65 t、近畿2.00 t
- エネルギー消費量では北海道46.5 GJ（全国27.8 GJの1.67倍）、東北36.6 GJ、北陸35.3 GJ、最も少ないのは沖縄19.0 GJ。北海道ではエネルギーの54%、東北では39%が灯油
- ただし「寒いほど多い」はエネルギーではほぼ成り立つが、CO2では崩れる。沖縄はエネルギーが最も少ないのにCO2は2.62 tと全国より多く、九州はエネルギーが中ほどでもCO2は最少。電気のCO2を電気の消費量で割った値（t/MWh）は沖縄0.63、九州0.28と2倍以上違い、地域の電源の違いがそのまま出ている
- 戸建同士で比べても北海道5.47 t、関東甲信3.06 tで、建て方の違いだけでは説明できない。集合住宅は1.3〜2.6 t
- 九州は2022年度の2.26 tから2023年度1.65 tに下がり、年度による変動も大きい（電気の排出係数の変化とみられる）


## データ
| ファイル | 中身 |
|---|---|
| data/co2_per_household_region.csv | 年度（2022・2023）、地方、建て方（全体・戸建・集合）、エネルギー種別のCO2排出量（t-CO2/世帯・年：電気・都市ガス・LPガス・灯油・4種合計・ガソリン・軽油）、平均世帯人数 |
| data/energy_per_household_region.csv | 2023年度の同じ区分のエネルギー消費量（GJ/世帯・年）、太陽光の発電量・売電量 |

- 第6-4-1表「基本項目別-年間エネルギー種別二酸化炭素排出量」（2023年度 statInfId 000040277746、2022年度 000040161459）と第6-2-1表「同 エネルギー消費量」（2023年度 000040277732）の「地方別」「地方別・建て方別」の平均
- ダウンロード：`https://www.e-stat.go.jp/stat-search/file-download?statInfId=<ID>&fileKind=4`

## 注意
- 地方の値は標本調査の平均で、地方によっては集計世帯数が数百世帯。年度による振れがある
- 電気のCO2は、各地域の電気事業者の排出係数で計算されている。電気の使用量が同じでも地域によってCO2は違う
- ガソリン・軽油は自動車を持つ世帯の利用を含む別の集計で、主な比較（4種合計）には入れていない
- 気温そのものは使っていない。「寒い地方」は北海道・東北・北陸を目安にした地方区分の比較
