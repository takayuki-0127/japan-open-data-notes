# F505 事前の計画（PLAN）

作成：2026-11-18 22:25（JST）。平均の人数や割合を集計する前に書いた。

## 問い
1学級の人数は、35人学級でどれだけ減ったのか？
公立小学校の学級編制の標準（1学級の上限の目安）は、2021年度の小2から1学年ずつ40人から35人に下がり、2025年度の小6で全学年がそろいました（文部科学省の説明資料）。1年生はそれより前（2011年の法改正）から35人です。では、実際の学級の平均の人数はどれだけ下がったのか。36人以上の学級はどれだけ残っているのか。下がったのは、子どもが減ったからか、学級が増えた（減らなかった）からか。

## 知りたい人
小学校の子どもがいる家族、学校や教育委員会で働く人、教員の数や教室の数の話を読む人。「35人学級になった」と聞いても、もともと多くの学級は35人以下だったので、平均がどれだけ変わったのかは別に確かめる必要があります。

## データ
- 文部科学省「学校基本調査」（e-Stat、各年5月1日時点）、2008〜2025年度の18年分。小学校と中学校それぞれ：
  - 「編制方式別学級数」：単式学級（同じ学年だけの学級）の学年別の数、複式学級、特別支援学級。国立・公立・私立、公立は都道府県別。
  - 「学級編制方式別児童数（生徒数）」：同じ区分の児童生徒数。
  - 「収容人員別学級数」：学級の人数の幅（7人以下、8〜12人、…、31〜35人、36〜40人、41〜45人、…）ごとの学級の数。公立は単式・複式・特別支援の別。
- 平均の人数は「単式学級の児童数 ÷ 単式学級の数」（学年別）。主に公立を見る（35人の標準は公立に向けたもの）。
- 中学校は2025年度まで40人の標準のままなので、くらべる相手として使う。

### 取得前に見たもの（下見）
- 2025年度の小学校の表の形を確かめるために、表の先頭の数行を見た。そこで、収容人員別学級数の「計」（国公私と全種類の学級）の36〜40人の学級が 2024年度 3,916 → 2025年度 1,081、公立の単式学級の36〜40人が 2025年度 541 であることを目にした。
- 2025年度の公立の単式学級の数（1学年 33,310、…）と児童数（1学年 835,365、…）の行も目にしたが、平均は計算していない。
- 2008年度の表は、形を確かめるために先頭の行（2008年度の公立の単式学級 1学年 42,614 など）だけを見た。
- 2024年度の表にある「2023年度」の行の単式学級の数は、2023年度の表の値より各学年33ずつ多い（後から直された値と思われる。推測）。分析では各年度の表の値を使う。

## 仮説（外れの基準つき）
- H1：公立小の単式学級の平均人数（全学年）は、2020→2025年度に下がり、その下がり幅は2015→2020年度の下がり幅より大きい。外れ：2020→2025年度の下がり幅が2015→2020年度以下。
- H2：小2〜小6のそれぞれで、平均人数の前の年からの下がり幅は、その学年が35人になった年（小2 2021、小3 2022、小4 2023、小5 2024、小6 2025）が2009〜2025年度の中で最も大きい。外れ：5学年のうち2学年以上で、最も大きい下がりが別の年。
- H3：公立小の単式学級のうち36人以上の学級の割合は、2020年度に10%以上、2025年度に1%以下。外れ：どちらかを満たさない。
- H4：中学校（公立、40人の標準のまま）の平均人数の2020→2025年度の下がり幅は、小学校より小さい。外れ：中学校の下がり幅が小学校以上。
- H5：2020→2025年度の公立小では、単式学級の数の減り（%）は児童数の減り（%）より小さい（＝平均が下がったのは、学級が子どもほどには減らなかったから）。外れ：学級の数の減りの方が大きい。

## 手法
- 学年別・年度別の平均人数（公立、単式学級）と、その前年からの差。
- その学年が35人になった年の下がり幅から、まだ35人になっていない学年（同じ年の上の学年）の下がり幅の平均を引く「差の差」（同じ年に共通の子どもの減りの影響を除く目安）。
- 収容人員別学級数で、36人以上（36〜40人＋41人以上）の割合と、31〜35人の割合の推移。
- 平均の変化を、児童数の変化（%）と学級の数の変化（%）に分ける（平均＝児童数÷学級数なので、対数で差に分かれる）。
- 都道府県別（公立）の2020→2025年度の平均の変化を、北から南の順と地方別に並べる（順位は出さない）。

## 頑健性（3つ以上）
1. 全学級（複式・特別支援を含む）の平均（児童数÷学級数）で見る。
2. 国立・私立を含む全体（計）で見る。
3. 比べる年を変える（2019→2025年度、2020→2024年度）。
4. 差の差の比べる相手を、上の学年すべての平均でなく、1つ上の学年だけにする。
5. 2023年度の値を、2024年度の表にある直された値に替える。

## 言えないこと（予想）
- 学級の人数が減ったことで、学力や先生の忙しさがどう変わったかは、この統計では分からない。
- 都道府県や市町村が独自に行ってきた少人数学級の取り組みと、国の標準の引き下げの影響は、合計の数字からは分けられない。
- 平均は学校の大きさのちがいを含む（小さな学校の多い地域では、もともと平均が小さい）。
- 5月1日時点の数で、年度の途中の転入・転出は入らない。
- 先生の数（加配を含む）や教室の数は、この記事では扱わない。
