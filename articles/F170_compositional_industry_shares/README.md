# F170 産業の構成比を比べるとき、割合のまま回帰してよいか？（組成データ・ilr）

## 問い

「製造業の割合が高い地域ほど○○」のように、産業の構成比を回帰に入れることはよくある。ところが構成比は、足すと必ず100%になる。割合のまま回帰に入れると何が起き、対数比（ilr など）に直すと何が変わるのかを、市区町村と都道府県の産業構成で確かめる。

- A. 構成比を**説明変数**にする：製造業の割合と、1人あたり地方税
- B. 構成比どうしの**相関**：一部の産業を除いて割合を計算し直すと、相関は変わるか
- C. 構成比を**目的変数**にする：人口密度で産業構成を説明する
- D. 頑健性：産業の分け方・変換の種類・0 の扱い・年・目的変数・単位

## データ

- 統計センター「SSDSE（教育用標準データセット）」SSDSE-A-2026（1,741市区町村）と SSDSE-A-2021（年を変えた確認用）。F166 と同じファイルを data/raw/ に同梱している。
- 産業構成：経済センサス‐活動調査の従業者数（民営、2021年。SSDSE-A-2021 では2016年）、産業大分類18区分。
- 目的変数：地方税（市町村財政、2022年度）÷総人口（国勢調査2020年）の対数。確認用に、転入超過率（（転入−転出）÷人口、‰、2024年）。
- 説明変数（C）：総人口÷可住地面積の対数。
- 代替案の確認：国勢調査2020年の第1〜3次産業就業者数。
- 都道府県の値は、市区町村の値を地域コードで足し上げた。
- 国勢調査の人口が 0 の町（2026年版で1、2021年版で4。原発事故の避難指示区域）は、1人あたりの値が作れないので除いた。

産業の分け方（18産業から）

| 分け方 | 区分 |
|---|---|
| 3分類 | 一次（農林・漁業）／二次（鉱業・建設・製造）／三次（それ以外） |
| 6分類（基本） | 一次／建設・鉱業／製造／流通（電気ガス・運輸・卸小売）／知識系（情報通信・金融・不動産・学術専門）／生活・福祉（宿泊飲食・生活関連・教育・医療福祉・複合・その他サービス） |
| 10分類 | 一次／建設・鉱業／製造／電気・運輸／卸売・小売／情報・金融・不動産／学術・専門／宿泊・飲食・生活／医療・福祉／教育・その他 |

## 手法

- **割合のまま**：6つの割合のうち1つを落として（基準にして）最小二乗。製造業の係数は「ほかを固定して、基準の産業から製造業へ1ポイント移したとき」の差になる。基準を5通り変えて比べた。あわせて、製造業の割合だけを入れる単回帰も行った。
- **ilr（ピボット座標）**：製造業を先頭にした ilr 座標 z₁ = √(5/6)·ln(製造 ÷ ほか5分類の幾何平均) を使う。係数は「製造÷ほかの幾何平均」が10%高いときの差に直して示した。残りの並べ方を20通り変えて、係数が同じになることを確かめた。
- 標準誤差は頑健な標準誤差（HC1）。当てはまりは R² と、1つ抜き交差検証（LOO）の RMSE で比べた。
- **部分組成**：10分類の割合で都道府県間の相関を計算し、1産業を除いて割合を計算し直したときに相関の符号が変わるかを、10通りすべてで数えた。また、各産業の人数を都道府県の間で独立に並べ替えて（関係を壊して）から割合にする操作を500回くり返し、割合だけで生まれる相関を測った。
- **目的変数として**：市区町村の6分類の構成比を、人口密度の対数とその2乗で説明する。割合ごとの最小二乗と、ilr 座標で回帰して元に戻す方法を、5分割交差検証で比べた。
- **0 の扱い**：0 人の産業を δ 人とみなす乗法的置換（δ = 0.01・0.1・0.5・1、10分類では 0.1・1・5）。
- 乱数の種は 170。

## 結果

### A. 構成比を説明変数にする（製造業の割合と1人あたり地方税）

都道府県（47、6分類）。数値は「製造業の割合が1ポイント高いとき」の1人あたり地方税の差（%、対数差×100）。

| 基準（どこから移したとみなすか） | 係数（%） | 標準誤差 |
|---|---|---|
| 一次 | +7.92 | 2.93 |
| 建設・鉱業 | +3.14 | 1.29 |
| 流通 | −1.40 | 1.18 |
| 知識系 | +0.59 | 1.04 |
| 生活・福祉 | +1.74 | 0.45 |
| 製造の割合だけ（単回帰） | +0.92 | 0.31 |
| **ilr：製造÷ほかが10%高いとき** | **+1.47** | **0.47** |

- 割合のままでは、基準を変えるだけで −1.4% から +7.9% まで動き、符号も変わった。3通りではっきりプラス、2通りでは区別がつかなかった。
- 一次を基準にした +7.9% は、「平均1.3%しかない一次から10ポイント移す」ような、データにない動きを含む。
- ilr の係数は、残りの並べ方を変えても同じだった（20通りの最大差 4.5×10⁻¹⁷）。
- 当てはまりは同じ程度（R² 0.573 と 0.577）。LOO の RMSE は ilr の方が小さかった（0.173 と 0.135）。

市区町村（1,740、6分類）

| 基準 | 係数（%） | 標準誤差 |
|---|---|---|
| 一次 | +0.73 | 0.28 |
| 建設・鉱業 | −0.20 | 0.39 |
| 流通 | +0.41 | 0.26 |
| 知識系 | **−2.22** | 0.27 |
| 生活・福祉 | +0.65 | 0.13 |
| 製造の割合だけ | +0.26 | 0.08 |
| ilr（10%あたり） | +0.06 | 0.14 |

- 市区町村では、はっきりプラス（一次・生活福祉が基準）と、はっきりマイナス（知識系が基準）が両方出た。ilr では、はっきりした関係は見えなかった。
- 6つの産業すべてで同じことを調べると、基準しだいで係数の符号が変わる産業は都道府県で4、市区町村で4。はっきりプラスとはっきりマイナスが両方出る産業は、市区町村で2（製造、建設・鉱業）だった。
- 市区町村では、当てはまりは割合のままの方がやや良かった（R² 0.099 と 0.056、LOO RMSE 0.341 と 0.349）。どちらの形が正しいかは、データだけでは決まらない。
- alr・clr・ilr のどれを使っても、予測値は同じだった（最大差 10⁻¹³ 程度）。変わるのは係数の読み方だけ。

### B. 構成比どうしの相関

- 都道府県・10分類：1産業を除いて割合を計算し直すと、360組のうち22組（6%）で相関の符号が逆になった。6分類では60組中11組（18%）、市区町村・10分類では360組中20組（6%）。
- 対数比の分散（var ln(xᵢ/xⱼ)）は、どの産業を除いても同じだった（差 3×10⁻¹⁶）。
- 人数を都道府県の間でばらばらに並べ替えると、人数どうしの相関の平均は −0.000 だが、割合にすると −0.092（95%：−0.096〜−0.085）になった。理論値は −1/(10−1) = −0.111。実データの割合の相関の平均は −0.038。

### C. 構成比を目的変数にする（人口密度との関係）

- 割合ごとの最小二乗では、1,740市区町村のうち169（9.7%）で一次の予測が 0% 未満になった。ilr で回帰して戻す方法では、0 未満は出ない。
- 5分割交差検証の誤差（ポイント）は、割合のまま 7.18、ilr 7.28 とほぼ同じ。対数比で測った距離（Aitchison 距離の中央値）は 1.107 と 1.029 で、ilr の方が小さかった。
- 産業別の相対誤差の中央値は、小さい一次で 56% → 44% と ilr が良く、大きい産業ではほぼ同じだった。10分類・3分類でも同じ形。

### D. 頑健性

| 条件 | 割合のまま：基準による幅（%） | ilr（%、10%あたり） |
|---|---|---|
| 都道府県・6分類（基本） | −1.40〜+7.92 | +1.47（0.47） |
| 市区町村・6分類 | −2.22〜+0.73 | +0.06（0.14） |
| 都道府県・3分類 | +0.93〜+14.07 | +2.62（0.53） |
| 市区町村・3分類 | +0.22〜+1.12 | +0.60（0.16） |
| 都道府県・10分類 | −3.99〜+4.86 | +1.16（0.41） |
| 市区町村・10分類 | −2.92〜+1.73 | +0.29（0.11） |
| 都道府県・6分類・東京を除く | −3.91〜+3.57 | +1.29（0.36） |
| 都道府県・6分類・2016年センサス | −1.51〜+9.95 | +1.79（0.42） |
| 市区町村・6分類・2016年センサス | −2.33〜+0.79 | +0.15（0.16） |
| 市区町村・10分類・0を0.1／1／5人に | −2.94〜+1.73 ほか | +0.28〜+0.31 |

- 割合のままの係数の幅は、地方税を目的変数にした12条件中10条件で 0 をまたいだ。
- ilr の係数は12条件すべてでプラス、10条件で 95% 区間が 0 を含まなかった（市区町村・6分類の2021年と2016年は区別がつかない）。
- 目的変数を転入超過率に変えると、ilr でも割合のままでも、製造業についてはっきりしたことは言えなかった。
- 3分類（国勢調査）の代替案：都道府県では、一次を基準 +4.2%、三次を基準 +0.8%、ilr +2.4%（10%あたり）。
- 0 の扱い：18産業のまま市区町村で対数比を作ると、1,740 のうち 1,418 に 0 の産業がある（漁業1,006、鉱業1,023 など）。人口密度に対する製造業のピボット座標の係数は、δ=0.01 で 0.028、δ=1 で 0.112 と約4倍動いた。製造業自身の 0 は3件だけだが、「ほかの幾何平均」に 0 の多い産業が入るため。10分類にまとめると、δ を 0.1〜5 に変えても係数はほぼ同じ（+0.28〜+0.31%）。

## 言えないこと

- 産業構成が地方税を「増やす」という因果は言えない。人口規模・都市か地方か・企業の本社の場所など、ほかの違いを入れていない。
- ilr が「正しい」とも言えない。ilr の係数は「製造÷ほかの幾何平均」という別の問いに答えているだけで、割合のままの係数（どの産業から移したか）も、問いを明確にすれば意味がある。市区町村では、割合のままの方が当てはまりがやや良かった。
- 経済センサスは民営事業所だけで、公務と、個人経営の農林漁家は入っていない。一次の割合は実際より小さく、国勢調査の就業者とは違う。
- 0 の置き方に決まった正解はない。0 が多い細かい分類で対数比を使うと、結果が置き方に左右される。
- 都道府県は47しかなく、6分類で5つの係数を推定しているので、区間は広い。
- 市区町村や都道府県の順位づけや評価はしていない。
