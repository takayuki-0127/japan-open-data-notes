# 910 抜き取り検査で合格したロットに、不良はどれだけ残るのか？（品質と検査）

ロット（同じ条件でまとめて作った品物のまとまり）から一部を抜き取って調べ、不良が決めた数以下なら合格にする。これが抜き取り検査です。「合格」は「不良がない」ではありません。抜き取らなかった品物の中の不良は、そのまま出荷に回ります。**ここでは、作成者が乱数で作った架空の工場の部品のロット（ロットごとの本当の不良率を作成者が置いたもの）で、3つの抜き取り方について、合格したロットに不良がどれだけ残るか、出荷全体の不良率はどれだけ下がるかを数えました。あわせて、工程の平均の不良率とロットどうしの差の大きさを変えると、残る不良の割合がどう動くかを確かめました。**

## 主な結果

### 合格する確率（式、ロットの不良率が決まっているとき）
| ロットの不良率 | 32個・0個まで | 80個・1個まで | 125個・2個まで |
|---|---|---|---|
| 0.1% | 96.8% | 100.0% | 100.0% |
| 0.2% | 93.7% | 99.4% | 100.0% |
| 0.5% | 85.0% | 94.6% | 98.4% |
| 1% | 72.1% | 81.3% | 88.2% |
| 2% | 51.9% | 51.5% | 53.4% |
| 3% | 37.1% | 29.1% | 25.4% |
| 5% | 18.9% | 7.8% | 3.8% |

- 3つの抜き取り方とも、不良率2%のロットでも約半分（51.5〜53.4%）が合格した。不良率0.5%のロットは、85.0〜98.4%が合格した

### 工程の平均0.5%・ロットどうしの差1（20,000ロット）
| | 32個・0個まで | 80個・1個まで（基本） | 125個・2個まで |
|---|---|---|---|
| 合格したロットの割合 | 86.0% | 91.7% | 94.3% |
| 検査の前の不良率（全ロット） | 0.499% | 0.505% | 0.501% |
| 合格したロットに残る不良率 | 0.413% | **0.403%** | 0.388% |
| 検査の前に対する倍率 | 0.83倍 | **0.80倍** | 0.77倍 |
| 出荷全体の不良率（選別したロットを含む） | 0.355% | 0.370% | 0.366% |
| 不良のうち出荷に残った割合 | 71.2% | **73.3%** | 73.0% |
| 合格したロットのうち不良が1個以上残る割合 | 80.6% | 80.7% | 80.2% |
| 合格したロット1つに残る不良（平均・上から10%の値） | 4.13個・10個 | 4.03個・10個 | 3.88個・9個 |
| 不良率2%以上のロットのうち合格した割合 | 41.9% | 39.0% | 39.4% |

- **基本の抜き取り方では、合格したロットの不良率は0.403%で、検査の前（0.505%）の0.80倍にとどまった。不良の73.3%は出荷に残った**
- 合格したロットの80.7%には不良が1個以上残っていた。1ロットに平均4.03個
- 出荷に残った不良の60.4%は、不良率1%未満のロットからだった。抜き取り検査がほぼ合格にする範囲のロットが、数が多いぶん、残る不良の多くを占めた
- 抜き取る個数を増やしても（32個→125個）、残る割合は71.2〜73.3%でほぼ変わらなかった。合格の基準（0〜2個まで）もいっしょに変えたため、不良率2%のあたりで合格する確率がそろっている

- **不良のうち出荷に残った割合は、置き方で15.0〜90.8%と大きく動いた。工程の平均が低いほど、またロットどうしの差が小さいほど、多く残った**
- ロットどうしの差が0（どのロットも同じ不良率）のとき、合格したロットの不良率は、工程の平均によらず検査の前の0.92倍（＝（1,000−80）÷1,000）だった。このときの抜き取り検査は、悪いロットを選び出せず、抜き取った80個の中の不良を取り除くだけになる。出荷に残った割合は式の値と0.36ポイント以内でそろった（作りの確かめ）
- 抜き取り検査が効くのは、とくに悪いロットが混ざるとき（ロットどうしの差が大きいとき）だった。差2・平均2%では、合格したロットの不良率は検査の前の0.21倍まで下がった
- 基本の置き方（0.5%・差1）は、確かめでは乱数を変えて数え直したので、残った割合が73.9%と、上の表の73.3%から少し動く。全16通りは `results/robustness.csv`

## 注意（言えないこと）
- 架空のデータです。ロットの大きさ、工程の平均の不良率、ロットどうしの差の形（ガンマ分布）と大きさは作成者が置いたもので、結果はこれで決まります。不良のうち出荷に残った割合は、置き方で15.0〜90.8%と動きました
- 抜き取った品物の検査は、見逃しも誤検出もないと置きました。不合格のロットの全数選別も、不良をすべて取り除けると置きました。実際には選別にも見逃しがあり、残る不良はこれより多くなりえます（推測）
- 3つの抜き取り方は、作成者が例として選んだものです。規格の表に載っている抜き取り方式を表すものではありません
- ロットどうしの差は互いに関係しないと置きました。悪いロットが続けて出る場合（工程の変化）は入れていません
- どの抜き取り方を使うべきか、合格の基準をどう決めるべきか、取引先との約束や規格の決まりについては言えません
