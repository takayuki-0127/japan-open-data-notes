# F153 平均でなく「分布」で比べると、地域の差は何に見えるか？（分位関数・Wasserstein 距離・分布のクラスタリング）

看板記事 F153。note：「平均でなく『分布』で比べると、地域の差は何に見えるか？…」（下書き）

## 問い

都道府県の収入の差は、ふつう平均や中央値の1つの数字で比べられる。分布をまるごと比べると、次のことが分かるはずである。

- 差は「全体が上か下か」なのか、「広がり方」や「形」の違いなのか
- 平均だけで分けたときと、分布で分けたときで、似た県のまとまりは変わるのか
- 差は、世帯の人数や持ち家・借家の構成の違いで説明できるのか
- 5年でどの部分が動いたのか

## データ

| データ | 内容 | 出典 |
|---|---|---|
| 世帯の年間収入階級別の主世帯数（2023年） | 全国と47都道府県 × 収入11階級（100万円未満〜2,000万円以上、不詳）× 世帯人員7区分 × 持ち家・借家 | 総務省「令和5年住宅・土地統計調査」住宅及び世帯に関する基本集計 第40-1表（statInfId 000040209911） |
| 同（2018年） | 同じ。ただし収入は10階級（100〜200万円が1つの階級）、普通世帯のうち主世帯 | 総務省「平成30年住宅・土地統計調査」同 第41-1表（statInfId 000031865740） |

- 年間収入は世帯全員の1年間の収入（税込み）の合計。調査は10月1日時点
- 収入不詳の世帯（2023年は全国で約5%、都道府県で3〜9%）は除いて割り直した。頑健性で別の扱いも試した
- 住宅・土地統計調査は標本調査で、都道府県の数字には誤差がある

## 手法

1. **分位関数**：階級別の世帯数から累積分布を単調な3次スプライン（PCHIP）でつなぎ、2,000万円以上はパレート分布（α は 1,500・2,000万円の生存割合から）として、下から0.5%〜99.5%の分位点を199点求めた（F115 で当たり方が良かった方法）
2. **2-Wasserstein 距離と分解**：1次元の分布どうしの距離は、分位関数の差の2乗平均の平方根になる。その2乗は
   W² = (平均の差)² ＋ (標準偏差の差)² ＋ 2σ₁σ₂(1−相関)
   と「位置」「広がり」「形」に分けられる。47都道府県のフレシェ平均（分位関数の平均）からの W² の平均（フレシェ分散）を同じように分けた
3. **「全国の何倍か」で表せるか**：各県の分位関数を全国の分位関数の k 倍で近似し、残る W² の割合を見た
4. **分布のクラスタリング**：分位関数に Ward 法（＝W² の目で分ける）。クラスタ数はシルエットで選び、平均だけ・平均と標準偏差だけで分けた場合と調整ランド指数（ARI）で比べた
5. **構成をそろえた反実仮想（DFL 型）**：各県の「世帯人員 × 持ち家・借家」ごとの分布を、全国の構成の重みで混ぜ直した分布を作り、フレシェ分散がどれだけ減るかを見た
6. **分布の回帰（フレシェ回帰）**：分位関数を単身世帯の割合・持ち家の割合・平均世帯人員に分位点ごとに回帰し、W² の目の決定係数と1県抜きの予測誤差を見た
7. **2018→2023**：2023年を10階級にそろえ、分位点ごとの変化と、県の間のばらつきの変化を見た

## 結果

### 1. 地域差の3分の2は「位置」、3割は「広がり」、「形」は3%

フレシェ標準偏差は 57.8万円（47都道府県の分布が、平均的な分布から W で平均57.8万円離れている）。

| 見方 | 位置 | 広がり | 形 |
|---|---|---|---|
| 万円（基本） | 66% | 30% | 3% |
| 対数 | 93% | 5% | 2% |
| 等価（√世帯人員で割る） | 73% | 25% | 2% |
| 階級内一様 | 66% | 29% | 5% |
| 2018年 | 71% | 25% | 4% |

- 平均の高い県ほど標準偏差も大きい（順位相関 0.93）。万円の目で「広がり」に見える部分の大半は、対数の目では「位置」に入る
- 各県の分位関数を「全国の k 倍」で近似すると、残る W² は全体の 6.9%。k は 0.75〜1.24（中央値 0.93）。中央値の W（全国との距離）は 51.7万円から 16.1万円になる
- 都道府県の間の標準偏差は、下から10%の点で17万円、中央値で42万円、90%の点で84万円。比（標準偏差÷平均）では 13%・11%・10% で、下の方がやや大きい
- 下から10%の点で並べた順と90%の点で並べた順の順位相関は 0.90

### 2. 分布でクラスタに分けても、はっきりした型は出ない

- シルエットは k=2 で 0.47、k=3 で 0.47、k=4 以上で 0.39〜0.42。k=3 では「24県」「22県」「1都」に分かれ、3つめは東京都だけ（上の裾が厚い）
- クラスタ間の分散はフレシェ分散の 71%
- 平均だけで分けた3分類との ARI は 0.42、平均と標準偏差で分けた3分類とは 0.13
- 条件を変えると顔ぶれが入れ替わる：階級内一様 0.41、対数 0.25、等価 0.45、不詳を一番下の階級へ 0.18、不詳を700〜1,000万円へ 0.37、2018年のデータ 0.38、構成をそろえた分布 0.62
- 都道府県の分布は、型に分かれるというより「全国の分布を少しずつ伸び縮みさせた」連続の並びに近い

### 3. 世帯の人数や持ち家・借家の構成をそろえても、差は縮まらない

| 反実仮想 | フレシェ標準偏差（万円） | 減った割合（分散） |
|---|---|---|
| 実際 | 57.8 | — |
| 世帯人員を全国にそろえる | 58.1 | −1% |
| 持ち家・借家を全国にそろえる | 59.5 | −6% |
| 両方（14セル）を全国にそろえる | 58.1 | −1% |

- そろえると、単身世帯の多い県の分布は上に、少ない県は下に動く（平均の動きと単身世帯の割合の順位相関 0.95、動きは −47〜+45万円）。単身世帯の多い県は、もともと平均の高い県が多いので、差はむしろ少し開く
- 2018年でも、両方をそろえて減ったのは 8%
- フレシェ回帰の決定係数（W² の目）は、単身世帯の割合 0.02、持ち家の割合 0.01、平均世帯人員 0.04、3つ全部で 0.13。1県抜きの予測の W は 51.2万円で、何も使わない（フレシェ平均で予測）46.8万円より悪い
- 構成の違いは、分布の差の大きさを説明しない。差を生んでいるのは、同じ人数・同じ住まい方の世帯の中での収入の違い（推測：産業・職業・年齢の構成、物価や賃金の水準）

### 4. 2018→2023 は、上の方ほど伸びた（名目）

| 分位点 | 全国の変化 | 都道府県の中央値 |
|---|---|---|
| 下から10% | +3.2万円 | +2.3万円 |
| 中央値 | +15.0万円 | +8.8万円 |
| 下から90% | +35.1万円 | +22.2万円 |

- 47都道府県のうち43で、90%の点の伸びが10%の点の伸びより大きい
- 県の間のばらつき（フレシェ分散）は万円の目では 2,959 → 3,343 と広がったが、対数の目では 0.0139 → 0.0124 と縮んだ。中央値の変動係数は 11.4% → 11.2%。差は「金額では開き、比ではやや縮んだ」
- 2018年の平均の高さと5年間の平均の伸びの順位相関は −0.13 で、はっきりした傾向はない
- 物価の変化は調整していない

## 頑健性

| チェック | 位置・広がり・形 | クラスタの ARI |
|---|---|---|
| 基本 | 66・30・3% | 1 |
| 階級内一様 | 66・29・5% | 0.41 |
| 上の裾を2,000〜3,000万円の一様 | 67・30・4% | 1.00 |
| 対数 | 93・5・2% | 0.25 |
| 等価（√世帯人員） | 73・25・2% | 0.45 |
| 不詳を一番下の階級へ | 63・34・4% | 0.18 |
| 不詳を700〜1,000万円へ | 69・25・6% | 0.37 |
| 2018年 | 71・25・4% | 0.38 |

- 「形の違いは小さい（2〜6%）」「構成をそろえても差は縮まらない」は、どの条件でも同じ
- 等価にしても、相対のばらつき（フレシェ標準偏差÷平均）は 12.7% → 12.2% とほとんど変わらない
- クラスタの顔ぶれは条件で大きく変わる（ARI 0.18〜0.62）。クラスタ数を変えた場合の ARI は k=2 で 0.96、k=4 で 0.74、k=5 で 0.53

## 言えないこと

- 階級の中の分布は分からないので、分位関数は推定である。下から5%より下と上の裾（2,000万円以上）は特に不確か。上下0.5%は使っていない
- 収入は税込みの世帯収入で、手取りや資産、物価の違いは入っていない。地域の暮らし向きの差そのものではない
- 構成をそろえた反実仮想は、「同じ人数・同じ住まい方の世帯の収入の分布は、構成が変わっても変わらない」という仮定に立つ
- 都道府県の数字は標本調査の推定値で、誤差の幅は公表されていない
- 分析は都道府県の間の比較で、都道府県の中の差（市区町村・個人）は見ていない
- 特定の県の良し悪しを言うものではない
