# 1031 遅れの平均と、遅れた便の遅れの平均は、どれだけ違うのか？（移動と時間）

「平均の遅れは0.6分」と「遅れた便の平均の遅れは7分」は、同じ記録から出せる、どちらも正しい数字です。前者は遅れなかった便も0分として入れた平均、後者は遅れた便だけの平均で、全便の平均は「遅れた便の割合×遅れた便の平均（＋1分未満の小さな遅れ）」になります（式どおり）。どちらを出すかで数字は何倍も変わり、2つの路線を比べると順が入れかわることもあります。**ここでは、作成者が乱数で作った架空の路線A・B（1日100便・365日。便ごとの着く時刻のずれと乗る人の数を作成者が置いたもの）で、全便の遅れの平均・早着をマイナスで入れた平均・遅れた便の遅れの平均・乗った人1人あたりの遅れの平均の4つを並べ、何倍違うか、2つの路線の順が入れかわるかを数え、遅れた便の決め方・遅れの起き方・朝夕に乗る人の集まり方を変えて確かめました。**

客が体験する混み具合が、店の時間の平均より混んで見えることは関連する記事 875 で扱っていて、この記事の「乗った人1人あたりの遅れ」と同じ仕組みです。平均の待ち時間が5分でも10分以上待つ人がどれだけいるかは 873、平均の所要時間どおりに出て遅れる日の割合は同じ企画の 1030 で扱っています。同じ企画の 1033 は、遅れの何分未満を「定時」とするかで定時率と順位が入れかわることを扱っていて、この記事の「遅れた便」の決め方と近い題材です（1033 は割合、この記事は平均）。この記事は、遅れの「平均」の取り方で数字と比べ方がどう変わるかに絞ります。

## 主な結果

### 4つの平均（365日×1日100便、`results/measures.csv`）
| | A線 | B線 | 順 |
|---|---|---|---|
| ① 全便の遅れの平均（早着は0） | **0.64分** | **0.69分** | A線が短い |
| ② 全便のずれの平均（早着はマイナス） | 0.32分 | 0.45分 | A線が短い |
| ③ 遅れた便（1分以上）の遅れの平均 | **6.97分** | **2.85分** | **A線が長い** |
| ④ 乗った人1人あたりの遅れの平均 | **0.94分** | **0.81分** | **A線が長い** |
| 遅れた便の割合 | 8.47% | 20.87% | |
| ③÷① | **10.9倍** | **4.14倍** | |

- **遅れた便の遅れの平均は、全便の遅れの平均の10.9倍（A線）・4.14倍（B線）だった**。遅れた便が少ない路線ほど、倍率は大きい
- ①は「遅れた便の割合×③＋1分未満の小さな遅れの分」と一致した（A線：0.0847×6.97＋0.05＝0.64、B線：0.2087×2.85＋0.09＝0.69。式どおり）
- **全便の平均（①・②）ではA線が短いのに、遅れた便の平均（③）と乗った人1人あたり（④）ではA線が長かった**。①の差は0.05分と小さく、どちらの路線が「遅れる路線か」は、どの平均を選ぶかで決まった
- 早着の便は、A線で70.85%、B線で53.13%。早着をマイナスで入れると（②）、①より小さく出た
- 遅れた便のうち上から10%目の遅れは、A線13.97分、B線5.24分

### 乗った人1人あたりの遅れが大きく出るわけ（`results/by_hour.csv`）
- 朝夕の便は、便の数では22%だが、乗った人では58.49%（A線）・58.54%（B線）を占めた
- 遅れた便の割合は、朝夕の便でA線17.76%・B線30.05%、ほかの時間でA線5.84%・B線18.28%。朝夕はほかの時間の、A線で3.04倍、B線で1.64倍。人の多い便に遅れが集まるA線のほうが、1人あたりの遅れ（④）が①の1.48倍と大きく出た（B線は1.17倍）
- 遅れた便に乗っていた人の割合は、A線12.82%（便では8.47%）、B線25.2%（便では20.87%）

- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の10ファイルがバイト単位で一致した（cmp、約3秒）

## 注意（言えないこと）
- 架空のデータです。遅れの起きやすさ、遅れの大きさ、朝夕の置き方、乗る人の数は作成者が置いたもので、結果はこれで決まります。A線を「遅れはまれだが大きい」、B線を「遅れは多いが小さい」と作成者が置いたので、③でA線が長いのは置き方どおりの向きです。実在の路線や会社の数字を表すものではありません
- 「全便の平均＝遅れた便の割合×遅れた便の平均＋小さな遅れ」は式どおりで、③÷①の倍率は、ほぼ遅れた便の割合の逆数で決まります。数えて新しく分かったのは、この置き方での倍率の幅（決め方で2.13〜13.57倍）、①と③で順が入れかわる通りの多さ（9通り中5通り）、乗った人で重みをつけると順がもう一度入れかわることです
- 基本の置き方での①の差（A線0.64分・B線0.69分）は小さく、別の乱数では入れかわることがあります（確かめ2の「5分・1.0」の行では0.64分と0.66分）
- 遅れの原因は置いていません。乗り換えでの遅れの重なりは扱っていません
- どの平均を公表すべきか、どの路線を使うべきかは言えません。この記事は、平均の取り方で数字と比べ方がどう変わるかを数えただけです
