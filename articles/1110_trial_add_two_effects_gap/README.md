# 1110 2つの条件を別々に試した効き目を足して見込むと、組み合わせたときとどれだけずれるのか？（試作と実験）

工夫を1つずつ試して「Aでむらが5ポイント減った、Bで4ポイント減った」と分かると、両方を入れたら9ポイント減ると足し算で見込みたくなります。けれども、工夫の効き目が「むらの出る割合を何割か減らす」形で効くと、2つ目の工夫は1つ目で減ったあとの残りにしか効かないので、足し算の見込みは良すぎる側にずれます。2つを組み合わせたときにだけ出る上乗せ（よく効く・打ち消し合う）があると、さらにずれます。**ここでは、作成者が乱数で作った架空の陶芸工房4,000軒（いつもの作り方のむらの割合20%、8つの工夫それぞれの効き目、2つの工夫を組み合わせたときの上乗せを作成者が置いたもの）で、工夫を1つずつ試した結果から28組の組み合わせのむらの割合を①足し算、②割合の掛け算で見込み、見込みでいちばん良い組を選んだとき、本当のむらの割合が見込みとどれだけずれるかを数えました。ずれの中身は、しくみを1つずつ入れて分けました。いつものむらの割合・上乗せの大きさ・1つあたりの個数を変えた27通りも確かめました。**

例の工房と器は架空のもので、実在の工房・釉薬・会社を表すものではありません。むらの有無は決まった基準で見分けると置いています（人の好みを聞いて決める評価ではありません）。器の強さや安全にかかわる試験ではありません。

関連する記事：657「交互作用を見つけるには、主効果を見つけるときの何倍の件数が要るのか」は、組み合わせの効き目（交互作用）を見つけるのに要る件数を扱っています。この記事は、見つけるかどうかではなく、1つずつの結果を足して見込んだ値が組み合わせたときとどれだけずれるかに絞ります。同じ企画の 1101「条件を1つずつ変える試し方で、いちばん良い組み合わせは見つかるのか？」は1つずつ変えて決めていく試し方がどこに着くかを、1107「組み合わせの半分だけを試すと、何と何の効き目が見分けられなくなるのか？」は組み合わせの半分だけを試したときに効き目が重なることを、1104「条件の数を増やして繰り返しを減らすと、何を見落とすのか？」は、たまたま良く出た条件を選んで見かけが本当より良く出ることを扱っています。

## 主な結果

### 見込みでいちばん良い組を選んだとき（基本、4,000工房の平均、`results/a1110_main.json` の main）
| 見込み方 | 選んだ組の見込み | 選んだ組の本当のむらの割合 | 本当−見込み（10〜90%の範囲） | 選んだ組が本当にいちばん良い組だった割合 |
|---|---|---|---|---|
| ①足し算 | 0.64% | 6.3% | **+5.67ポイント**（+1.33〜+10.01） | 23.85% |
| ②割合の掛け算 | 5.45% | 6.3% | **+0.85ポイント**（−1.72〜+3.64） | 23.85% |
| （比べるため）28組を直接焼いて選ぶ | 3.88% | 4.91% | +1.03ポイント（−0.17〜+2.28） | 51.35% |

- **足し算で見込むと、選んだ組のむらの割合は見込み0.64%に対して本当は6.3%と、5.67ポイント悪かった**。割合の掛け算で見込むと、ずれは0.85ポイントだった
- どちらの見込みでも、選ぶ組は同じだった（100%）。1つずつの試しでむらのいちばん少なかった2つの工夫の組になるため。違うのは見込みの値だけで、選んだ組が本当にいちばん良い組だったのはどちらも23.85%
- 28組すべてで見ると、足し算の見込みは本当より平均1.62ポイント低く（良すぎる側）、外れの大きさの平均は3.91ポイント、2ポイントを超えて外れた組は68.21%だった。割合の掛け算では平均−0.1ポイント、外れの大きさの平均2.87ポイント
- 足し算の見込みが0%を下回った組が5.19%あった（むらの割合はマイナスにならない）
- 28組を直接焼いても、選んだ組は見込みより1.03ポイント悪かった。たまたま良く出た組を選ぶ分の上ずれで、直接試せば消えるわけではない。そのかわり、本当にいちばん良い組を選べた割合は51.35%と上がった（工夫1つずつの9通り3,600個に、28組11,200個を足した場合）

### ずれの中身（しくみを1つずつ入れる、各4,000工房、`results/components.csv`）
| 置き方 | ①足し算：本当−見込み | ②割合の掛け算：本当−見込み |
|---|---|---|
| 割合で効くだけ（上乗せなし・試しのぶれなし） | **+4.05ポイント** | −0.28ポイント |
| 上乗せあり・試しのぶれなし | +4.2ポイント | −0.11ポイント |
| 上乗せなし・試しのぶれあり | +5.42ポイント | +0.59ポイント |
| 上乗せあり・試しのぶれあり（基本） | +5.67ポイント | +0.85ポイント |

- **足し算のずれ5.67ポイントのうち4.05ポイントは、効き目を割合で効くと置いたことから決まる式どおりの分だった**（上乗せも試しのぶれもないとき）。2つ目の工夫は、1つ目で減ったあとの残りにしか効かないため。効き目の強い2つを選ぶほど大きくなる
- 効き目がみな平均（−0.4）の1組では、工夫1つで14.35%、2つで本当は10.1%のところ、足し算の見込みは8.71%、割合の掛け算は10.3%だった（式どおり、`formula_one_pair`）
- 試しのぶれを入れると（上乗せなし）、見込みより悪い側に、足し算で+1.37ポイント、割合の掛け算で+0.87ポイント動いた（`decomposition_diffs`）。1つずつの試しでたまたま良く出た工夫を選ぶ分の上ずれで、28組を直接焼いて選んだときの上ずれ（上乗せなしで+1.37ポイント）と同じくらいの大きさだった
- 上乗せ（標準偏差0.3）は、選んだ組の平均のずれをあまり動かさなかった（ぶれなしで足し算+0.15ポイント、割合の掛け算+0.17ポイント）が、28組ごとの外れは大きくした（足し算の外れの大きさの平均1.46→2.92ポイント）。選んだ組が本当にいちばん良い組だった割合は、ぶれなしでも100%→33.07%に下がった

### 確かめ：置き方を変えると（27通り、各1,000工房、`results/grid.csv`）
| | 27通りの範囲 |
|---|---|
| ①足し算：選んだ組の本当−見込み | **+2.25〜+11.09ポイント** |
| ②割合の掛け算：選んだ組の本当−見込み | −0.66〜+3.56ポイント |
| 28組を直接焼いたときの外れの大きさの平均 | 0.39〜3.15ポイント |
| 足し算の見込みが0%を下回った組 | 0.65〜24.31% |
| 選んだ組が本当にいちばん良い組だった割合 | 8.2〜75.2% |

- **27通りすべてで、選んだ組の見込みは足し算のほうが割合の掛け算より大きく外れた**。28組の外れの大きさの平均でも27通りすべてで足し算のほうが大きかった
- 割合の掛け算のずれは27通り中24通りで正（見込みより悪い）だった。負だったのは上乗せ0か0.3で1つあたり1,600個のときで、試しのぶれが小さく、割合と対数オッズの違いの分が出た
- 足し算のずれは、いつものむらの割合が高いほど、1つあたりの個数が少ないほど大きかった（上乗せ0でも+2.25〜+10.02ポイント）
- 割合の掛け算でも、上乗せを大きく（0.6）すると、ずれは+0.53〜+3.56ポイントになった
- どちらの見込みでも選ぶ組は、27通りすべてで95%以上の工房で同じだった。同じにならなかったのは、100個ずつで0個と出る工夫やいつもの作り方があるときで、いつものむらの割合8%・100個ずつの置き方に多かった

## 注意（言えないこと）
- 架空のデータです。いつものむらの割合、工夫の効き目、組み合わせたときの上乗せの大きさ、1つあたりの個数は作成者が置いたもので、結果はこれで決まります。足し算のずれは置き方27通りで+2.25〜+11.09ポイントと動きました
- 効き目を「むらの出やすさ（オッズの対数）に足す」形で置いたので、割合の掛け算が足し算より当たるのは、この置き方による結果です。効き目がむらの割合そのものに足し算で効く工夫なら、足し算の見込みのほうが当たります（この記事では数えていません）
- 2つの工夫の組み合わせだけを扱いました。3つ以上を重ねると、ずれはさらに大きくなると考えられます（推測）
- 実在の工房・材料での効き目を表すものではなく、どの工夫を入れるべきかも言えません。この記事は、1つずつの結果から組み合わせを見込むときのずれの大きさを数えただけです
