# 155 病床利用率は冬に高くなるのか（病院報告）

厚生労働省「病院報告」の月末病床利用率（月次、2000〜2025年）を STL 分解し、季節の動きと、月末の曜日による違いを調べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A155 | 病床利用率は冬に高くなるのか | STL分解（周期12か月、ロバスト）で傾向・季節・残りに分け、月ごとの季節成分を平均。月末が土日・祝日かどうかで、傾向を除いた値を同じ月どうしで比較 | `src/a155_season.py` |

## 主な結果
- 一般病床の季節成分：1月 +4.7、2月 +3.5、4月 −1.9、11月 +2.1、12月 −11.8 ポイント（季節性の強さ 0.89）
- 療養病床は季節の幅 1.4 ポイント（1〜2月がやや高い）、精神病床は 0.9 ポイント（夏がわずかに高い）
- 一般病床（12月を除く）：月末が土日・祝日の年は、同じ月で月末が平日の年より平均 2.9 ポイント低い（月ごとに 1.7〜3.9 ポイント）
- 月末が平日の月だけで見ても、傾向からのずれは 1〜2月 +4.6、4〜6月 +0.1、7〜8月 +1.5 ポイント
- 一般病床の年平均：79.4%（2004）→ 76.5%（2019）→ 69.0%（2022）→ 74.7%（2025）

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a155_season.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/month_end_occupancy.csv | 年・病床の種類（total 総数、general 一般病床、ltc 療養病床、psych 精神病床）ごとの年間と各月の月末病床利用率（%） |

元の CSV は e-Stat「病院報告」全国編 第16表（年により第17表）「月末病床利用率，月・病院－病床の種類別」の各年のファイル（2025年 000040500943、2024年 000040323434 ほか、2000〜2025年の26ファイル）。必要な行を取り出しています。一般病床・療養病床（再掲）は2004年から。

## 注意
- 月末1日の値です。月を通した平均の病床利用率とは違い、月末の曜日や年末の退院の影響を強く受けます
- 休日は土日と固定日の祝日・12月31日で判定し、移動する祝日（成人の日など）は入れていません
- 月末が休日の年は各月6〜7年と少なく、月ごとの差には振れがあります
- 2000〜2003年の総数・精神病床は病床区分の変更前の値です
