# 185 売上高の上位1%の企業が全体の何割を占めるか：経済センサス‐活動調査

総務省・経済産業省「令和3年経済センサス‐活動調査」の主要統計表 第9表（企業産業大分類×売上（収入）金額階級8区分別の企業等数・売上（収入）金額・付加価値額）から、売上の集中度を全産業と産業別に計算したフォルダです。売上は2020年1年間の値です。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A185 | 売上高の上位1%の企業が、全体の売上の何割を占めるか | 階級別の企業数と売上からローレンツ曲線を作り、上位1%の境目が入る階級の中は（切断）パレート分布で補間して上位1%のシェアを推計。分布を仮定しない上限・下限も計算。産業別にも同じ推計 | `src/a185_conc.py` |

## 主な結果
- 企業等は351万、売上（収入）金額の合計は1,693兆円（2020年）
- 売上100億円以上の企業は16,302社（0.46%）で、売上の69.6%、粗付加価値額の59.5%を占める。10億円以上（3.44%）まで広げると売上の86.5%
- 上位1%（約3.5万社）の売上シェアは、パレート補間で約77%（76.6%）。階級の中の分布を仮定しない範囲は72.6〜80.6%
- 売上1億円未満の企業は全体の79.7%だが、売上の3.35%、粗付加価値額の6.2%
- 産業別の上位1%のシェアは、電気・ガス・熱供給・水道業93%、金融業，保険業92%が高く、建設業53%、農林漁業35%が低い

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a185_conc.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/enterprises_by_sales_class_2021.csv | 産業（全産業・非農林漁業・大分類17）、売上（収入）金額階級（計と8区分）、企業等数、売上（収入）金額（百万円）、粗付加価値額（百万円） |

- 令和3年経済センサス‐活動調査 主要統計表 企業等に関する集計 第9表（statInfId 000040068630、Excel）
- ダウンロード：`https://www.e-stat.go.jp/stat-search/file-download?statInfId=000040068630&fileKind=4`
- 階級の合計が「計」と一致することを確認した（四捨五入の差を除く）

## 注意
- 階級別の集計しかないため、個々の企業の売上は分からない。上位1%のシェアは階級内の分布を仮定した推計で、HHI（ハーフィンダール指数）は計算できない。ジニ係数（0.945）は階級データの折れ線から計算した下限
- 上位0.1%など、いちばん上の開いた階級（100億円以上）の中の推計は、パレート分布の仮定に強く依存する
- 企業等は会社・会社以外の法人・個人経営を含む。金融業，保険業と会社以外の法人は経常収益を売上に含める
- グループ会社は別々の企業として数えている（連結ではない）。売上の集中は付加価値の集中より大きく出る（卸売・小売など仕入れの大きい業種）
- 2020年はコロナの影響を受けた年
