# 812 「4.5以上」で絞り込むと、良い店は何%外れるのか？（口コミと星の数）

口コミサイトで「星4.5以上」に絞り込むと、良い店だけが残るように見えます。しかし、件数の多い店の平均はほとんど振れないので、本当の満足度が4.4の店は件数が多いほど確実に外れます。逆に件数の少ない店は、たまたま4.5を超えて残ります。**ここでは、作成者が乱数で作った架空の店20万軒（本当の満足度を作成者が置いたもの）で、本当の満足度4.3以上を「良い店」とし、見かけの星の平均で「4.5以上」に絞ったとき、良い店がどれだけ外れ、残った一覧に良くない店がどれだけ入るかを数えました。**

件数の少ない店の星を全体の平均に寄せる並べ方（ベイズ平均）は関連する記事 801、カテゴリの1位の当たり外れは 811 で扱っています。この記事は「しきい値で絞り込む」ことに絞ります。

| A812 | 「4.5以上」で絞り込むと、良い店は何%外れるか。残った一覧のうち良い店は何%か。件数の帯でどう違うか | 架空の店2万軒を10回（計20万軒）。本当の満足度は平均3.9・標準偏差0.35の正規分布（2.5〜4.8の外は引き直す）。口コミの件数は1〜1,000件（対数で一様）。1件の星は、平均が本当の満足度になる1〜5の分布から引く（801 と同じ）。「良い店」は本当の満足度4.3以上（全体の12.2%）。絞り込みは見かけの星の平均が線以上の店を残す（小数の丸めはしない）。線は3.5〜4.9、件数の条件は「なし」と「20件以上」。本当の満足度と件数ごとの「4.5以上に入る確率」は、件数3・20・100・500件で各2万回引いて数えた。「良い店」の線を4.2・4.4に、店どうしの差（標準偏差）を0.2・0.5に、件数を1〜100件に変えた確かめも行った。seed 812 | `src/a812_filter_4_5.py` |

## 主な結果

### 「4.5以上」で絞り込んだとき（20万軒）
| | 値 |
|---|---|
| 良い店（本当4.3以上）のうち、外れた割合 | **57%** |
| 良い店のうち、残った割合 | 43% |
| 残った一覧のうち、良い店の割合 | 54% |
| 残った一覧のうち、本当の満足度が4.0未満の店の割合 | 20% |
| 残った一覧のうち、口コミ4件以下の店の割合 | 55% |

- 良い店の半分以上が「4.5以上」から外れた。残った一覧の半分近くは良い店ではなく、5軒に1軒は本当の満足度が4.0未満だった

### 件数の帯ごと
| 口コミの件数 | 良い店のうち残った割合 | 残った一覧の内訳 | その帯で残った店のうち良い店の割合 |
|---|---|---|---|
| 1〜4件 | 60% | 55% | 30% |
| 5〜19件 | 48% | 20% | 65% |
| 20〜99件 | 38% | 12% | 96% |
| 100件以上 | **32%** | 13% | 100% |

- 件数の多い良い店ほど外れた。100件以上の良い店で残ったのは32%
- 一覧の半分以上は口コミ1〜4件の店で、その7割は良い店ではなかった

### 本当の満足度と件数ごとに、「4.5以上」に入る確率
| 本当の満足度 | 3件 | 20件 | 100件 | 500件 |
|---|---|---|---|---|
| 4.0 | 13.5% | 0.2% | 0% | 0% |
| 4.4 | 43% | 32% | 8% | **0%** |
| 4.6 | 65% | 83% | 96% | 100% |

- 本当の満足度4.4の良い店は、口コミ500件ではまず残らない。口コミ3件なら43%で残る。本当の満足度4.0の店も、口コミ3件なら13.5%で残る

### 絞り込み方を変える
| 絞り込み | 残った店の数 | 良い店のうち外れた割合 | 残った一覧のうち良い店の割合 |
|---|---|---|---|
| 4.0以上 | 91,602 | 2% | 26% |
| 4.3以上 | 35,370 | 19% | 56% |
| 4.5以上 | 19,381 | 57% | 54% |
| 4.3以上かつ20件以上 | 14,920 | 49% | 83% |
| 4.5以上かつ20件以上 | 4,882 | 80% | 98% |

- 件数の条件がないと、線を上げても一覧の中の良い店の割合は6割ほど（線4.35で60%）で止まった。線を上げるほど、件数の少ない店の割合が増えるため
- 20件以上の条件を付けると、一覧の中の良い店は8〜9割台に上がった。ただし良い店の43%は口コミ20件未満なので、20件以上の条件では良い店の43%以上が必ず外れる

### 確かめ：置き方を変えても（各20万軒）
| 置き方 | 良い店の割合 | 「4.5以上」で良い店が外れた割合 | 「4.5以上」の一覧のうち良い店の割合 |
|---|---|---|---|
| 基本（良い店4.3以上・差0.35・件数1〜1,000件） | 12.2% | 57% | 54% |
| 良い店を4.2以上 | 19.2% | 67% | 64% |
| 良い店を4.4以上 | 7.2% | 40% | 44% |
| 店どうしの差0.2 | 2.3% | 75% | 10% |
| 店どうしの差0.5 | 18.3% | 47% | 72% |
| 件数1〜100件 | 12.2% | 51% | 47% |

- どの置き方でも、良い店の4割以上が「4.5以上」から外れた
- 店どうしの差が小さい（0.2）と、良い店はもともと少なく、「4.5以上」の一覧のうち良い店は10%だった
- 外れた割合は「良い店」の線（作成者の決め方）を4.2〜4.4に動かすだけで40〜67%と大きく動く。主な結果の57%は線4.3での数字

### 確かめ：本当の満足度の端を 801 と同じく「切る」（20万軒）
| | 値 |
|---|---|
| 良い店の割合 | 12.6% |
| 本当の満足度がちょうど4.8の店 | 0.53% |
| 「4.5以上」で良い店が外れた割合 | 54% |
| 「4.5以上」の一覧のうち良い店の割合 | 56% |

- 引き直す置き方（57%・54%）とほとんど変わらなかった


- `results/a812_main.json`：主な結果すべて
- `results/by_count_band.csv`：件数の帯ごとの結果
- `results/filter_rules.csv`：絞り込み方ごとの結果
- `results/threshold_sweep.csv`：線を3.6〜4.9で動かしたときの結果
- `results/pass_prob_curve.csv`：本当の満足度と件数ごとの「4.5以上」に入る確率

## 注意（言えないこと）
- 架空のデータです。店どうしの差、件数の分布、1件の星の散らばり、「良い店」の線（4.3）は作成者が置いたもので、結果はこれで決まります
- 本当の満足度は、801 と違い、2.5〜4.8の外を「切る」のではなく「引き直す」形にしました。1冊の本としては 801 と置き方がそろっていませんが、801 と同じく切っても、主な結果は57%→54%・54%→56%とほとんど動きませんでした（確かめの表）
- 見かけの星の平均は丸めずに比べました。画面で小数1桁に丸めて表示する場合の境目の扱いは、この分析に入っていません
- 口コミを書く人は、来た人からでたらめに選ばれると置きました。満足した人や不満な人ほど書きやすい偏り、サクラの投稿は入れていません
- 実際の口コミサイトの絞り込みの仕組みを表すものではありません
