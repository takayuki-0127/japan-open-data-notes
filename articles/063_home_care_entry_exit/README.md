## もとのリポジトリの説明

以下は、もとのリポジトリ `kaigo-service-offices-japan` の README です（同じリポジトリにあったほかの記事の分も含みます）。

### kaigo-service-offices-japan：介護サービス情報公表システムのオープンデータで、訪問介護の事業所の参入・撤退と「近くにない」問題を調べる

厚生労働省「介護サービス情報公表システム」オープンデータのうち、訪問介護と通所介護の事業所一覧を、2020年12月末〜2026年6月末の12時点（半年ごと）で突き合わせたリポジトリです（延べ約72万行）。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| K1 | 訪問介護の事業所は、2024年4月の報酬改定のあとで撤退しやすくなったか | 事業所番号で12時点をつないだ参入率・撤退率、通所介護と比べた離散時間ロジット（半年区間の固定効果、法人規模・法人種別・地域、事業所クラスター頑健標準誤差）、最後の区間を除いた頑健性 | `src/k1_flow.py` |
| K2 | 訪問介護の事業所がない市区町村は増えたか。近くにほかの事業所がない事業所は撤退しやすいか。日曜日も来てくれるか | 0か所・1か所の市区町村の推移、最寄りの事業所までの直線距離（BallTree、haversine）、距離別の撤退のロジット、利用可能曜日 | `src/k2_access.py` |

#### 主な結果
- **K1**：公表されている訪問介護の事業所は34,281（2020年12月末）→35,166（2026年6月末）でむしろ増え、通所介護は26,060→24,567（−5.7%）に減った。半年間の撤退率は訪問介護で2.6〜3.8%。通所介護と比べたロジットでは、報酬改定後の区間で訪問介護の撤退のオッズが1.40倍（95%信頼区間1.32〜1.49）に上がった（最後の1〜2区間を除いても1.40〜1.41倍）。一方で参入も多く、数は減っていない。2024年12月末の一時的な減少は、新しい事業所の掲載が少なかったため（参入率1.5%、次の半年は4.7%）。1か所だけの法人は20か所以上の法人と比べて撤退のオッズが2.6倍
- **K2**：訪問介護の事業所が0か所の市区町村は46（2020年12月末）→83（2026年6月末）に増え、1か所だけの市区町村も265→285に増えた（対象1,859市区町村）。最寄りの別の事業所まで10km以上離れている事業所は165〜176か所（約0.5%）で、こうした事業所が撤退しやすいという傾向は見られなかった（撤退率2.1%、全体は約2.9%）。日曜日も利用できる事業所は73.3%→72.1%と少しずつ減り、1か所だけの法人では67%、20か所以上の法人では83%

#### データ
| ファイル | 中身 |
|---|---|
| data/raw/YYYY-MM_110.csv・YYYY-MM_150.csv（各自ダウンロード） | 事業所ごとの市町村コード、事業所番号、所在地の緯度経度、法人の名称、利用可能曜日など |
| results/k2_zero_munis_2026-06.csv | 2026年6月末に訪問介護の事業所が0か所だった市区町村の一覧 |

#### 注意
- 公表システムに掲載されている事業所の一覧で、指定を受けているすべての事業所とは限りません。掲載の遅れや一時的な非掲載があります
- 「撤退」は、ある時点にあった事業所番号が、それ以降のどの時点にも出てこないことと定義しました。いったん消えて後で戻った事業所は撤退に数えていません。最後の区間は後の時点で確かめられないため、頑健性として除いた推定も載せています
- 事業所番号は、法人の変更などで指定を受け直すと変わることがあります。その場合は「撤退＋参入」と数えられます
- 法人規模は、同じ時点・同じサービスで同じ法人名を持つ事業所の数です。表記ゆれ（全角・半角のスペースなど）は一部だけそろえています
- 事業所が0か所の市区町村でも、となりの市区町村の事業所がサービスを提供していることがあります。「サービスを受けられない」という意味ではありません
- 最寄り距離は直線距離です。道のりや移動時間ではありません。同じ建物にある事業所は距離0になります
