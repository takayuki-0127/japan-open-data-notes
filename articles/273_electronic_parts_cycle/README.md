# 273 電子部品の生産の山と谷は、何と重なっていたのか

経済産業省「鉱工業指数」の生産指数（季節調整済、2020年=100）で、電子部品・デバイス工業の生産の山と谷を、鉱工業全体・情報通信機械工業と比べたフォルダです。1998〜2022年は接続指数、2023年以降は2020年基準の指数を使っています（2018〜2022年の重なる月は全系列で一致、差0.0）。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A273 | 電子部品・デバイスの生産の山と谷は、鉱工業全体や国内の情報通信機械とどう重なったのか | 3か月移動平均の前後15か月での最大・最小を山・谷とし、山から谷の下がり幅を鉱工業と比較。前年同月比（12か月の対数差）の相関を3つの期間（1999〜2007・2008〜2015・2016〜2026年9月）で比較。先行・遅行は±6か月のずらした相関 | `src/a273_electronic_parts_cycle.py` |

## 主な結果
- 電子部品・デバイスの生産指数は1998年平均45.1→2007年101.8→2025年106.2。同じ期間に情報通信機械工業（通信機器・パソコン・テレビなど）は279.1→277.0→81.5（2025年は1998年の約3割）、鉱工業全体は112.4→128.9→100.9
- 前年同月比の標準偏差は電子部品16.3%、鉱工業8.1%で約2.0倍。山から谷の下がり幅は2000年11月→2001年10月で−34%（鉱工業は同じ月の間に−12%）、2007年11月→2009年2月で−54%（−34%）、2010年5月→2012年8月で−22%（−4%）、2021年6月→2023年4月で−16%（−4%）。2018年6月→2020年6月だけはコロナで鉱工業（−22%）のほうが大きかった
- 前年同月比の相関（鉱工業と／情報通信機械と）は、1999〜2007年0.88／0.56、2008〜2015年0.86／0.69、2016年〜2026年9月0.33／−0.16。2016年以降は、鉱工業とも情報通信機械とも一緒に動かなくなった
- 先行・遅行：電子部品の前年同月比と、L か月後の鉱工業の前年同月比の相関は L=0 で0.76、L=1 で0.77で、はっきりした先行は見えない

## 頑健性
- 3か月移動平均の前年比で計算しても、期間別の相関（鉱工業と）は0.90・0.88・0.33、（情報通信機械と）0.58・0.73・−0.25
- 最後の期間の切れ目を2014年・2018年にずらしても、鉱工業と0.31、情報通信機械と−0.22・−0.20
- 2016年以降からコロナの時期（2020年3月〜2021年12月）を除くと、鉱工業と0.24、情報通信機械と−0.31
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致した

## データ
- `data/prod_sa_two_sources.csv`：鉱工業指数の Excel（`b2020_sgs1j.xlsx` 過去の接続指数 業種別 月次 季節調整済、`b2020_gsm1j.xlsx` 業種別 月次 季節調整済）から、鉱工業・電子部品・デバイス工業・電気・情報通信機械工業・情報通信機械工業の生産（付加価値額ウエイト）を抜き出したもの。2026年9月は速報

## 注意
- ストックの案は「スマホの山と重なったか」だったが、スマートフォンの月次の出荷台数は鉱工業指数に含まれず、公的な長い月次の系列もないため、国内の情報通信機械工業の生産と比べる形に変えた
- 電子部品の生産は、国内の機械向けだけでなく輸出向け（海外で組み立てるスマホ・自動車など）も多い。2016年以降に国内の情報通信機械と動きが合わなくなったのは、国内での組み立てが減り、行き先が海外に移ったから（推測）。行き先の内訳はこのフォルダでは見ていない（記事276で業種別の輸出向けの割合を扱った）
- 山と谷は機械的な決め方で、景気基準日付とは違う。窓の幅（±15か月）を変えると、小さな山・谷が増減する
- 2016年以降の期間はコロナの大きな落ち込みを含む。除いても相関は小さいままだった
