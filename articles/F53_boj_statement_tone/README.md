# F53 日銀の声明文は、いつ「強気」から「弱気」に変わったか？

看板記事 F53。日本銀行が金融政策決定会合のあとに出す公表文（「当面の金融政策運営について」など）を1998〜2026年の392文書集め、その中の「わが国の景気は…」「個人消費は…」といった景気の現状判断の文（2008年7月〜2026年9月の133会合・579文）を、辞書法と文の埋め込みの2通りで「強気・弱気」のスコアにした。スコアがいつ正から負（強気から弱気）に変わったかを景気の山・谷と並べ、景気動向指数・金利・株価とも比べた。

## 問い

- 公表文の景気判断は、いつ強気から弱気に（弱気から強気に）変わったか。景気の山や谷と比べて早いか遅いか
- スコアは景気の今を映しているか、先を映しているか
- 金利や株価と一緒に動いているか

## データ

| データ | 中身 | 出所 |
|---|---|---|
| 公表文 | 金融市場調節方針に関する公表文 年別一覧（1998年1月〜2026年9月、372会合・392文書。（参考）資料は除く）。PDF は pdf.js で文字を取り出した | 日本銀行 |
| 景気動向指数 | CI 一致指数（月次） | 内閣府（F13 と同じデータ） |
| 景気基準日付 | 山・谷（2008年2月の山〜2020年5月の谷） | 内閣府（F18 と同じ） |
| 金利 | 無担保コールレート O/N 月平均（日銀 API、F43 と同じ）、長期金利（F18 と同じ） | 日本銀行・財務省 |
| 株価 | TOPIX（月次、F18 と同じ） | 内閣府 |

- 公表文の全文（`f53_boj_statements.json`）には会合の出席者の氏名が含まれるので GitHub には置いていない。`src/01_取得.py`（または `01_取得_browser.js`）で取り直せる
- `data/sentences.csv` には、出席者・賛否の欄と、委員の氏名や「総裁」「大臣」を含む文を除いた文だけを置いた
- 景気の現状判断の文が公表文に入るのは2008年7月からで、それより前の公表文は金融市場調節方針だけ（景気判断は月報に載っていた）。2016年以降は、展望レポートを出す会合（年4回）の公表文には景気判断がない

## 手法

| 段階 | 中身 |
|---|---|
| 文の選び方 | 公表文を「。」で文に分け、主語が「わが国の景気」「海外経済」「輸出」「設備投資」「個人消費」「雇用・所得環境」などの文を「現状判断の文」とした（579文）。「先行き」で始まる文、物価の文は別に分けた |
| 辞書法 | 強気の語15（回復・改善・持ち直し・増加・底堅い…）と弱気の語22（悪化・減少・弱め・横ばい・減速…）を数え、文ごとに（強気−弱気）÷（強気＋弱気）を出して会合で平均した（−1〜+1） |
| 埋め込み | cl-nagoya/ruri-v3-30m（Apache-2.0）で文をベクトルにし、強気の基準文5つとの近さ − 弱気の基準文5つとの近さを会合で平均した（全会合で標準化） |
| 転換点 | 直近3会合の平均（その時点までの会合だけ）の符号が変わった会合 |
| 比べ方 | 会合の2か月前（会合の時点で公表済み）と6か月後の、CI 一致の12か月前比との相関（会合を復元抽出したブートストラップ1,000回で95%区間）。−6〜+6か月のずれの相関。TOPIX の月次の変化・金利と並べた |

## 主な結果

- 2つのスコアの相関は 0.78。年平均の辞書スコアは、2008年 −0.87、2009年 −0.33、2013年 +0.59、2017年 +0.57、2020年 −0.28、2024〜26年は 0.00〜0.09 だった
- いちばん多かった語は、強気が「改善」119・「増加」107・「持ち直し」106・「回復」103、弱気が「横ばい」65・「弱め」64・「減速」47
- 現状判断の文のうち「弱め」「横ばい」を含む文の割合は、2013〜19年の19%から2021〜26年は39%に増えた。強気の語を含む割合は61%→59%でほぼ同じ
- **転換点と景気の山・谷**
  - 2018年10月の山 → 弱気への転換は、辞書法で2019年6月（8か月後、いったん戻る）・2020年6月、埋め込みで2020年3月（17か月後）
  - 2012年3月の山 → 2011年12月にいったん弱気（山の3か月前）、2012年10〜12月に再び弱気（山の7〜9か月後。谷は2012年11月）
  - 谷のあとの強気への転換：2009年3月の谷 → 辞書法2009年11月（8か月後）・埋め込み2010年8月（17か月後）、2012年11月の谷 → 2013年5月（6か月後、両方）、2020年5月の谷 → 辞書法2021年3月（10か月後）。埋め込みは2024年12月まで平均を下回ったまま
- **景気との相関**（CI 一致12か月前比）
  - 会合の時点で公表済みの月：辞書法 0.33（95%区間 0.15〜0.47）、埋め込み 0.34（0.21〜0.46）
  - 6か月後の月：0.21、0.14
  - ずれを −6〜+6か月で変えると、埋め込みは3か月前（0.35）、辞書法は1か月前（0.35）で最大。先の月になるほど下がる。スコアは「これからの景気」より「ここ1年の景気」を映している
  - 3か月前比では 0.18、0.12 と弱い
- **金利・株価**
  - 会合ごとのスコアの変化と、その月の TOPIX の変化の相関は 0.04（辞書法）、0.19（埋め込み）
  - 2024〜26年の利上げは、辞書スコアが 0.0〜0.17 と強気でも弱気でもない時期に行われた（利上げ前後の会合のスコア：2025年1月 0.00、2025年12月 0.05、2026年6月 0.17）

## 頑健性（`results/robustness.csv`、`figures/f53_robust.png`）

| 作り方 | 会合 | 会合時点の景気との相関 | 6か月後との相関 | 2018年の山のあとの弱気転換 |
|---|---|---|---|---|
| 基本・辞書 | 133 | 0.33 | 0.21 | 2019-06 |
| 基本・埋め込み | 133 | 0.34 | 0.14 | 2020-06 |
| 文3つ以上の会合だけ・辞書 | 100 | 0.16 | −0.10 | 2020-09 |
| 文3つ以上の会合だけ・埋め込み | 100 | 0.19 | −0.33 | 2020-12 |
| 辞書から6語（横ばい・下げ止まり・大幅に・急速に・慎重・不透明）を外す | 133 | 0.30 | 0.25 | 2020-06 |
| 先行きの文も入れる・辞書／埋め込み | 136 | 0.39／0.33 | 0.20／0.00 | 2019-06／2020-06 |
| 会合の最初の文だけ・辞書／埋め込み | 133 | 0.39／0.40 | 0.30／0.28 | 2020-03 |
| 埋め込み・前置き「トピック: 」 | 133 | 0.26 | 0.14 | 2020-06 |
| 埋め込み・基準文を2つずつ | 133 | 0.34 | 0.14 | 2020-09 |
| 2020年を除く・辞書／埋め込み | 129 | 0.32／0.31 | 0.18／0.11 | 2019-06／なし |

- 景気との相関は、どの作り方でも会合時点のほうが6か月後より大きい
- 景気判断の文が1〜2つしかない短い公表文（2008〜09年の危機のときや臨時会合）を除くと、相関は 0.16〜0.19 に下がる。相関の多くは、リーマン・ショックとコロナの大きな落ち込みの時期から来ている
- 2018年の山のあとの弱気転換は、作り方によって2019年6月〜2020年12月（山から8〜26か月後）まで動く。2012年の谷のあとの強気転換は2013年1〜5月（2〜6か月後）

## 動かし方

```
pip install -r requirements.txt
python src/01_取得.py          # 公表文を集める（data/raw/f53_boj_statements.json）。届かない環境は 01_取得_browser.js
```

## 言えないこと

- スコアは「公表文の言葉づかい」の指標で、日本銀行の本当の見方そのものではない。「緩やかに回復」と「回復」のような程度の違いや、言い回しの慣行の変化（たとえば2021年以降「弱め」「横ばい」が増えた）は、景気の変化と区別しきれない
- 景気判断の文が入っている会合は2008年7月以降で、2016年以降は年4回（展望レポートの会合）が抜けている。転換点の時期は、会合のない月の分だけ遅く見えうる
- 相関はどれも0.3〜0.4ほどで、多くは2008〜09年と2020年の大きな落ち込みから来ている。スコアで景気を予測できるとは言えない
- 公表文の景気判断と金利・株価の関係は、因果を調べたものではない
- 辞書の語と基準文は自分で選んだもので、別の選び方をすれば数字は変わる（頑健性で一部を確かめた）
