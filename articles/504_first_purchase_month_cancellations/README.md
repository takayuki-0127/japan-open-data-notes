# 504 取消された注文を残したまま「初回購入月」を決めると、新規顧客の数は何%多く出るのか（実務の型）

架空の会員2万人とテスト用の会員60人の注文71,874件（確定・取消・返品を含む）を作り、初回購入月を3通りで決めて、月ごとの新規顧客の数と、3か月以内にもう一度買った割合を比べたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A504 | 初回購入月の決め方で、新規顧客の数と続いた割合はどれだけ変わるか | 架空の注文（初回の注文の12%が取消、そのうち4割は二度と買わず、残りは1〜60日後に買い直す）を作り、①全部の注文 ②取消だけ除く ③確定だけ（取消・返品・テスト用の会員を除く）で初回購入月を決める | `src/a504_first_month.py`、`src/02_first_month_duckdb.sql`、`src/01_first_month_tsql.sql`（T-SQL 版、未検証） |

## 主な結果
- **新規顧客の数（2024年2月〜2025年12月の合計）**：①全部の注文 19,128人、②取消だけ除く 18,141人、③確定だけ 17,994人。①は③より6.3%多い（月ごとでは平均6.36%、2.51〜10.81%）。②は③より0.82%多い
- **一度も確定しない会員**：①で新規に数えられたが、確定の注文が一度もない会員が1,163人（テスト用の会員を除く）
- **初回購入月が動く会員**：①と③の両方で数えられる会員の7.08%（1,333人）は、③で決めると初回購入月がうしろへ動く。1か月が818人、2か月が407人
- **3か月以内にもう一度買った割合**：①で決めると55.01%、③で決めると55.46%（差は平均0.45ポイント、最大1.69ポイント）。近く見えるのは、買い直しを「もう一度買った」と数えて上がる分と、一度も確定しない会員が分母に入って下がる分が打ち消し合うため。①から一度も確定しない会員を除くと58.4%になる

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した
- DuckDB で出した月ごとの新規顧客の数（①と③）が pandas と一致すること（コード内の assert）

## データ
- `data/fictional_orders.csv`：架空の注文（seed 504）。列は order_id, member, ordered_at, status（確定・取消・返品）, amount, is_test。期間は2024年1月〜2026年3月

## 注意（言えないこと）
- 架空のデータ。何%多く出るかは、置いた取消の割合と買い直しの割合で決まる
- どの決め方が正しいかは、その数字を何に使うか（広告の効果、会員数の報告など）で変わる。ここでは決め方による差を数えただけ
- 会計や税務の売上の扱いを言うものではない
- T-SQL 版は SQL Server 本体では動かしていない（未検証）
