# 1192 担当から担当へ回された問い合わせの解決を、どの担当の数字に入れるかで、担当ごとの解決率はどう変わるのか？（問い合わせ対応）

問い合わせ窓口では、初めに受けた担当が難しい問い合わせを詳しい担当へ回すことがあります。回された問い合わせが解決したとき、その解決を「初めに受けた担当」「最後に持っていた担当」のどちらに入れるかで、担当ごとの解決率は変わります。**ここでは、作成者が置いた架空の会社の問い合わせ窓口（初めに受ける担当8人 A〜H と、回された件だけを受ける担当2人 I・J。担当ごとの本当の解く力と、どれくらい難しいと手を付けずに回すかの「回しやすさ」を作成者が置いたもの）で、同じ1年分の記録を4つの数え方で担当ごとの解決率にし、本当の解く力の順・回しやすさの順とどれだけ結びつくかを数えました。回しやすさの散らばり・解く力の散らばり・解けなかったときに回す確率を変えた27通りも確かめました。**

担当は記号だけで、人の属性（年齢・性別など）は置いていません。例の窓口は架空のもので、実在の会社・問い合わせ管理の仕組みを表すものではありません。人の評価や処遇の決め方、回す決まりの良し悪しを言う記事ではありません。

関連する記事：933「甘い評価者と辛い評価者の点を、そのまま比べてよいのか？」は、評価する側のくせで点の順が変わることを、架空の会社の評価で数えています。この記事は、問い合わせの記録そのものは同じで、回された件の解決をどの担当に入れるかという数え方の決まりだけで、解決率の順がどう変わるかに絞ります。同じ企画の 1186「平均の対応時間が短い担当は、手早い担当なのか、易しい問い合わせを受けた担当なのか？」は、担当ごとの平均の時間に、受けた問い合わせの種類の混ざり方がどれだけ混ざるかを扱っています。

## 注意（言えないこと）
- 架空のデータです。解く力・回しやすさの散らばり、回された件を受ける担当の強さ、解ける確率の式は作成者が置いたもので、結果はこれで決まります。回しやすさとの結びつきの向きは、回した先を強く置いたことと数え方の定義から出る作りどおりのものです
- 「本当の解決率」は、置いた式から出した値で、実際の窓口では誰にも分かりません
- 初めに受ける担当はでたらめに決まると置きました。得意な種類の問い合わせを受ける担当がいる窓口では、結果は変わります
- 解決しないまま閉じた件が、もう一度問い合わせてくる動きは入れていません
- どの数え方がよいかは、この置き方の中でも置き方しだいで入れかわりました。人の評価や処遇の決め方、回す決まりの良し悪しには使えません
