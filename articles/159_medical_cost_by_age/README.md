# 159 年齢別の1人あたり医療費のカーブは、どう変わったか：国民医療費（2008・2013・2018・2023年度）

厚生労働省「国民医療費」の第5表（性、年齢階級別の国民医療費と人口一人当たり国民医療費）を、2008・2013・2018・2023年度の4時点で並べ、年齢別の一人当たり医療費のカーブの変化を比べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A159 | 年齢別の一人当たり医療費のカーブは、15年でどう変わったか | 5歳階級の一人当たり医療費の4時点比較、2008→2023年度の伸び率、65歳以上の割合、人口構成を2008年度に固定した場合との比較、男女の比 | `src/a159_curve.py` |

## 主な結果
- 国民医療費は2008年度34.8兆円→2023年度48.1兆円（+38%）。人口一人当たりは27.3万円→38.7万円（+42%）
- 年齢ごとの一人当たりの伸びは、10〜19歳が+86〜88%と最も大きく、70〜79歳は+5〜6%と小さい。カーブは若い年齢ほど持ち上がり、高齢側は85歳以上（+25%）を除いてあまり変わっていない
- 全体の一人当たり（+42%）がほとんどの年齢の伸びより大きいのは、医療費の高い高齢者の割合が増えたため。2008年度の人口構成のままなら、総額の伸びは+23%（2023年度の単価で42.7兆円）
- 65歳以上が医療費に占める割合は54.6%→60.1%（人口に占める割合は22.1%→29.1%）。65歳以上と65歳未満の一人当たりの差は4.24倍→3.66倍に縮んだ
- 2023年度、20〜49歳は女性の一人当たりが男性より高く（25〜34歳で1.5〜1.6倍）、55歳以上は男性が高い（65〜79歳で女性は男性の0.76〜0.77倍）

## 注意
- 2008・2013年度は「85歳以上」、2018・2023年度は「85〜89歳」「90歳以上」に分かれているため、人口（国民医療費÷一人当たり で逆算）で重みづけして「85歳以上」にまとめています
- 金額は名目で、物価や診療報酬の改定の影響を含みます
- 国民医療費には、正常な妊娠・分娩、健康診断、予防接種などは入りません
- 年齢階級別の金額は、各種調査の割合で按分した推計値です（元表の注による）
- 男女別の総数は2013年度以降の表に行がないため、CSVには2008年度のみ入っています（分析には使っていません）
