# 840 1本のバズで、再生数の平均はどれだけ動くのか？（SNSと動画）

動画の再生数は、ほとんどの投稿がそこそこで、まれに1本だけ桁違いに伸びる（バズる）形をしています。このとき「月の平均再生数」は、その1本でいくらでも動きます。**ここでは、作成者が乱数で作った架空の動画アカウント（実力＝ふだんの再生数の分布とバズの起きやすさを作成者が置き、月が変わっても同じにしたもの）で、1本のバズで月の平均がどれだけ動くか、実力が同じ月どうしで平均・中央値・上位1本を除いた平均がどれだけ動くかを数えました。**

伸びた投稿だけを見て「伸びる型」を決める話は関連する記事 838、少ない週の次に伸びて見える話は 844、同じ内容を2回投稿したときの差は 845 で扱っています。この記事は「1本の大きな値が平均をどれだけ動かすか」に絞ります。

| # | 問い | 手法 | ファイル |

| A840 | 1本のバズで、月の平均再生数は何倍になるか。実力が同じ月どうしでも、平均はどれだけ上下するか。平均・中央値・上位1本を除いた平均のどれが実力の変化を当てやすいか | 架空の動画アカウント。1か月に20本投稿。ふだんの投稿の再生数は対数正規分布（中央値3,000回・対数の標準偏差0.7、1本の期待値は約3,833回）。投稿1本ごとに2%の確率でバズが起き、再生数がふだんの値の約50倍（倍率は対数正規、中央値50倍・対数の標準偏差0.5）になる。①例の1か月：ふだんの20本のうち1本を30万回に置きかえた。②バズの大きさ（1万〜100万回）と1か月の本数（10・20・60本）で平均が何倍になるかを式（(本数−1)×3,833＋バズの再生数）÷（本数×3,833）で計算した。③実力が同じ月を2万か月作り、指標ごとに「ふつうの月（2万か月の中央の値）の1.5倍以上になった月の割合」と「前の月から±30%以上動いた割合」を数えた。④ふだんの再生数が2割上がった月（または2割下がった月）を2万か月作り、③の月と1か月ずつ比べて、指標が正しい向きに動いた割合を数えた。確かめとして、バズの確率（0.5%・5%・なし）、ふだんの散らばり（0.5・1.0）、1か月の本数（10・60本）を変えた。seed 840 | `src/a840_one_buzz_mean.py` |

## 主な結果

### 例の1か月：20本のうち1本が30万回
| | バズの前 | バズの後 |
|---|---|---|
| 平均 | 3,711回 | **18,631回（5.0倍）** |
| 中央値 | 2,895回 | 3,068回 |
| 上位1本を除いた平均 | | 3,822回 |

- 1本が月の合計の80.5%を占め、平均を上回った投稿はその1本だけだった（`results/a840_main.json` の example_month）

### バズの大きさと本数で、月の平均は何倍になるか（式）
| バズした1本の再生数 | 1か月10本 | 20本 | 60本 |
|---|---|---|---|
| 1万回 | 1.16倍 | 1.08倍 | 1.03倍 |
| 10万回 | 3.51倍 | 2.26倍 | 1.42倍 |
| 30万回 | 8.73倍 | 4.86倍 | 2.29倍 |
| 100万回 | 26.99倍 | 14.00倍 | 5.33倍 |

- 平均の動きは「バズの再生数 ÷（本数 × ふだんの1本）」でほぼ決まる。例の1か月の5.0倍と式の4.86倍の違いは、その月のふだんの20本がたまたま期待値より少し少なかったため

### 実力が同じ2万か月で、指標はどれだけ動くか
| 指標 | ふつうの月の値 | ふつうの月の1.5倍以上になった月 | 前の月から±30%以上動いた割合 | ふだんが2割上がった月に、指標も上がっていた割合 | ふだんが2割下がった月に、指標も下がっていた割合 |
|---|---|---|---|---|---|
| 平均 | 4,228回 | **29.6%** | **63.2%** | 63.8% | 65.7% |
| 中央値 | 3,061回 | 1.9% | 33.8% | 74.7% | 79.5% |
| 上位1本を除いた平均 | 3,514回 | 6.7% | 36.6% | 73.9% | 78.0% |

- バズを1本以上含む月は32.7%。実力は同じなのに、平均では3か月に1か月近くが「ふつうの1.5倍以上」に見えた。中央値では1.9%
- 全投稿をならした長い目の平均は8,068回で、74.5%の月は平均がこれを下回った。長い目の平均は、多くの月にとって「届かない数字」になる
- ふだんの再生数が本当に2割上がっても、平均で「上がった」と出たのは63.8%。中央値では74.7%

### 確かめ：置き方を変えても（各2万か月）
| 置き方 | バズを含む月 | 平均：1.5倍以上の月 | 中央値：1.5倍以上の月 | 平均：2割の上昇を当てた割合 | 中央値：2割の上昇を当てた割合 |
|---|---|---|---|---|---|
| 基本（バズ2%・散らばり0.7・20本） | 32.7% | 29.6% | 1.9% | 63.8% | 74.7% |
| バズ0.5% | 9.6% | 9.6% | 1.7% | 71.7% | 75.5% |
| バズ5% | 64.0% | 36.2% | 2.5% | 56.5% | 73.4% |
| 散らばり0.5 | 32.9% | 31.6% | 0.2% | 67.7% | 82.7% |
| 散らばり1.0 | 33.0% | 27.5% | 7.4% | 60.3% | 68.0% |
| 1か月10本 | 17.8% | 19.6% | 6.4% | 63.9% | 68.3% |
| 1か月60本 | 70.3% | 27.6% | 0.0% | 60.5% | 87.3% |
| バズなし | 0% | 1.1% | 1.6% | 76.7% | 75.2% |

- バズが起きる置き方では、どの置き方でも平均のほうが中央値より「1.5倍以上」に見える月が多く、2割の上昇を当てる割合は低かった
- 平均がどれだけ振れるかは、バズの確率で9.6〜36.2%と大きく動いた。主な結果の29.6%は、私が置いたバズ2%での数字
- バズが起きない置き方では、平均は中央値と同じくらい（またはわずかに上）当てた。平均が悪いのではなく、まれな大きな値が混ざるときに弱い
- 上位1本を除いた平均は、バズが1か月に1本ならよく効くが、バズ5%や60本（1か月に2本以上のバズが起きやすい）では効きが落ちた（1.5倍以上の月が24.0%・17.9%）

## 動かし方
```
pip install -r requirements.txt
cd src && python a840_one_buzz_mean.py
```
5秒ほどで終わります。`data/posts_12months.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約3秒）
- 図3枚を開き、日本語・重なり・軸を確かめた
- バズなしの置き方では、平均が「1.5倍以上」に見える月は1.1%で、中央値（1.6%）とほぼ同じだった。基本の置き方の平均の振れは、バズから来ている

## データ
- `data/posts_12months.csv`：架空のアカウントの1年分（12か月×20本）の投稿（month・post・views（再生数）・is_buzz（バズなら1））。この1年ではバズは7月と9月に1本ずつで、月の平均は7月8,791回・9月14,561回、中央値は4,324回・4,187回だった（`results/year_by_month.csv`）
- `results/a840_main.json`：主な結果すべて
- `results/buzz_size_mean_ratio.csv`：バズの大きさと本数ごとの、平均の倍率（式）
- `results/robustness.csv`：置き方を変えた確かめ
- `results/year_by_month.csv`：1年分の月ごとの平均・中央値・バズの本数

## 注意（言えないこと）
- 架空のデータです。ふだんの再生数の分布、バズの確率と大きさ、1か月の本数は作成者が置いたもので、結果はこれで決まります。とくに平均の振れの大きさは、バズの確率で大きく変わります（確かめの表）
- 実力は月が変わっても同じと置きました。実際には、バズのあとにフォロワーが増えて次の月も伸びるなど、月どうしがつながることがあります。それは入れていません
- 「中央値のほうが良い」とは言えません。バズを含めた合計の再生数が目的なら、平均（合計）を見るのが正しい場面もあります。この記事は「ふだんの投稿の実力の変化」を読むときの話です
- 実際の動画サイトやSNSの数字の出し方を表すものではありません
