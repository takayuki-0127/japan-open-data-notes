# 533 残業時間を15分単位で切り捨てて集計すると、1か月の時間は何%少なく出るのか？（実務の型）

架空の出退勤の記録（分単位、120人×2025年10月の平日22日）を作り、日ごとの残業（定時18:00より後の分）を、1分単位・15分切り捨て・30分切り捨て・15分の四捨五入の4通りで丸めてから月に合計し、1分単位の合計との差を測ったフォルダです。見ているのは算数の差だけで、どの扱いが認められるかといった労務・給与の判断には触れません。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A533 | 日ごとに丸めてから合計すると、月の合計は何%・何時間変わるか。人によってどれだけ違うか | 日ごとに4通りで丸め、人ごと・全員で月に合計する。同じ集計を SQL（DuckDB）でも行い、Python と一致するか確かめる | `src/a533_overtime_rounding.py`、`src/02_monthly_overtime_duckdb.sql`、`src/01_monthly_overtime_tsql.sql`（T-SQL 版、未検証） |

## 主な結果（120人・2,640日分、1分単位の月の合計 1,582時間）
- **月の合計（1分単位との差）**：15分切り捨て 1,357時間（−14.3%、−226時間）、30分切り捨て 1,204時間（−23.9%、−378時間）、15分の四捨五入 1,574時間（−0.6%、−9時間）
- **1人あたり（月）**：15分切り捨てで中央値 1.9時間少なく出る（少ない人 0.8時間〜多い人 2.8時間）。30分切り捨てで中央値 3.1時間（1.0〜5.1時間）。四捨五入は −0.7〜+0.7時間で、多く出る人も少なく出る人もいる
- **割合で見ると人による差がさらに大きい**：15分切り捨ての減り方は、中央値 −16.4%、減り方の大きい1割の人では −38%以上（月の残業が短い人ほど割合では大きく減る）
- 残業のあった日1日あたりの切り捨て分は、15分切り捨てで平均 6.5分、30分切り捨てで平均 10.9分。残業のあった日が多い人ほど、少なく出る時間も多い
- 残業のあった日（定時を1分でも過ぎた日）は全体の78.6%、その日の残業の中央値は18分。短い残業が多いほど、切り捨ての割合は大きくなる
- SQL（DuckDB）の人ごとの月の合計は、Python と全員一致

## 注意（言えないこと）
- 架空のデータ。残業する日の割合や残業の長さの分布は作成者が置いたもので、実際の職場の値ではない。残業が短い職場ほど切り捨ての割合は大きく、長い職場ほど小さくなる
- 定時より後を残業とし、出勤前・休憩・休日は入れていない
- 算数の差を測っただけで、どの丸め方が許されるか、給与の計算をどうすべきかといった判断はしていない。実際の扱いは、法令や社内の決まりを担当の部署や専門家に確かめてほしい
- 「15分の四捨五入」は7分以下を切り捨て、8分以上を切り上げとした。境目の決め方で数字は少し変わる
- T-SQL 版は SQL Server 本体では動かしていない（未検証）
