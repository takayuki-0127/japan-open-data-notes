# 1102 試す順番を決めて並べると、時間とともに変わる分はどうまざるのか？（試作と実験）

条件を変えて何枚も試作するとき、「まず4分の板を6枚、次に5分を6枚…」と、条件の順に並べて試すと段取りが楽です。けれども、窯がだんだん温まる、材料の湿り気が変わるなど、時間とともに仕上がりが動くと、その分が条件の差にまざります。**ここでは、作成者が乱数で作った架空の焼き付けの工房（焼く時間4・5・6・7分の板を1日に24枚、1枚ずつ焼く。焼き色は1分ごとに1.0濃くなると作成者が置き、7分と4分の本当の差は3.0）で、窯が1日に+3.0温まると置いたとき、5つの並べ方で7分と4分の差の見積もりにどれだけまざるかを、1日を10,000回作り直して数えました。温まり方の形・量・ゆっくりした揺れを変えた24通りも確かめました。**

例の工房と焼き色は架空のもので、実在の工房・製品の数字ではありません。焼き色の濃さは色を測る機械の値と置いています（人に聞いて決める値ではありません）。食べ物の焼き色ではありません。

関連する記事：同じ「決まった順番で測ると時間の分がまざる」しくみは、処理の速さの 1056「A のあとに B を測る順番を固定すると、何が差にまざるのか？」で、2つの処理と前の回の後片付けの持ちこしについて扱っています。この記事は、4段階の条件を並べたときの差と、時間とともに変わる分の形（まっすぐか、はじめに急か）に絞ります。1056 のだんだん遅くなる分は直線の形（ほかにゆっくりした揺れ）だけで、同じ量がはじめに急に動く形は数えていません。この記事では、曲がった温まりで往復にも残る分、あとから焼いた順番の直線を引いたときの散らばり、4枚ごとの組の中ででたらめに並べる並べ方を足しています。前の試作の残りの持ちこしは入れていません（同じ企画の 1112「前の試作の残りが次の結果にまざると、何がずれるのか？」で扱っています）。だんだん動く分を見つける側の話は 1062「短い時間の計測で、動かすほどだんだん遅くなる処理は見つかるのか？」、日によって効き方が違う分を短い期間で測るずれは 694「A/B テストを3日だけで止めると、曜日で効き方が違うとき、効果の推定はどれだけずれるのか」で扱っています。同じ企画の 1103 は、同じ日の分をまとめて比べることを扱っています。

## 主な結果

### 並べ方ごとの差の見積もり（窯がまっすぐ+3.0温まる、10,000回、`results/orders_base.csv`）
| 並べ方 | 差の平均（本当は3.0） | ずれ | 式の値 | 散らばり（標準偏差） | ±0.5以内に入った割合 |
|---|---|---|---|---|---|
| ①順に（4分を6枚→5分→6分→7分） | 5.351 | **+2.351** | +2.348 | 0.65 | **0.19%** |
| ②1周ずつくり返す（4567 4567…） | 3.391 | +0.391 | +0.391 | 0.324 | 63.29% |
| ③往復（4567 7654…） | 3.006 | +0.006 | 0.0 | 0.365 | 83.05% |
| ④全体をでたらめに | 2.995 | −0.005 | 0.0 | 0.657 | 56.32% |
| ⑤4枚ごとの組の中ででたらめに | 2.999 | −0.001 | 0.0 | 0.342 | **85.9%** |

- **順に並べると、窯の温まりの+2.351が7分と4分の差にまざった**。7分の板は平均で4分の板より18枚あとに焼くので、24枚で+3.0の温まりなら 3.0÷23×18＝2.348（式どおり）
- 1周ずつくり返すと、7分は同じ周の4分より3枚あとなので +0.391（式どおり）がまざった
- 往復は、4分と7分の板の焼いた順番の平均がそろうので、まっすぐの温まりは打ち消された（式どおり0）
- 全体をでたらめに並べると、平均のずれは消えたが、温まりが1日ごとの散らばりになり、0.657と、⑤の0.342より大きくなった。±0.5以内に入ったのは56.32%だった

### あとから焼いた順番の直線を引くと（同じ10,000回、`results/orders_base.csv` の「焼いた順番の直線も当てはめて引く」）
| 並べ方 | 差の平均 | 散らばり | ±0.5以内 |
|---|---|---|---|
| ①順に | 2.997 | **1.35** | 28.77% |
| ②1周ずつ | 2.999 | 0.325 | 87.69% |
| ③往復 | 3.006 | 0.365 | 83.05% |
| ④全体をでたらめに | 2.996 | 0.368 | 82.68% |
| ⑤4枚ごとの組の中ででたらめに | 3.0 | 0.329 | 87.5% |

- 順に並べた①でも、あとから直線を引けば平均のずれは消えた。ただし、焼く時間と焼いた順番がほぼ重なっているので、散らばりは1.35と、そのままの①の0.65より大きくなり、±0.5以内に入ったのは28.77%だった
- 往復の③は、焼く時間と焼いた順番が重ならないので、直線を引いても引かなくても同じ値になった

### 温まり方の形を変えると（同じ+3.0を「はじめに急」に、10,000回、`results/a1102_main.json` の `early_shape`）
| 並べ方 | ずれ（そのまま） | 式の値 | ずれ（直線を引く） |
|---|---|---|---|
| ①順に | +1.893 | +1.894 | −0.529 |
| ②1周ずつ | +0.405 | +0.41 | +0.097 |
| ③往復 | **+0.155** | +0.156 | +0.155 |
| ④全体をでたらめに | +0.005 | 0.0 | +0.006 |
| ⑤4枚ごとの組の中ででたらめに | +0.002 | 0.0 | +0.002 |

- **往復で消えるのは、まっすぐの分だけだった**。はじめに急に温まる形では、往復にも+0.155（式どおり）がまざった。直線を引いても消えなかった
- 順に並べた①に直線を引くと、今度は−0.529と逆向きにずれた
- でたらめに並べた④⑤は、形によらず平均のずれは±0.006以内だった

### 置き方を変えると（24通り、各4,000回、`results/grid.csv`）
- ずれは24通りすべてで、順番から求めた式の値と0.036以内で合った（式どおり）
- そのままのずれは、①順にで−2.36〜+4.695、②1周ずつで−0.412〜+0.825と、温まりの量と向きでほぼ決まった。温まりが−3.0（だんだん薄くなる）なら、①は差を−2.36小さく見せた
- ③往復は、まっすぐの温まりの12通りでずれ−0.01〜+0.007、はじめに急の温まりがある9通りで−0.155〜+0.311だった
- ⑤4枚ごとの組の中ででたらめは、24通りでずれ−0.014〜+0.009、散らばり0.294〜0.532、±0.5以内64.98〜90.95%だった。④全体をでたらめは、ずれ−0.019〜+0.021、散らばり0.286〜1.215、±0.5以内34.35〜91.72%だった
- ⑤の散らばりは、24通り中22通りで④以下だった

## 注意（言えないこと）
- 架空のデータです。焼く時間の効き目、窯の温まりの量と形、揺れ、1枚ごとの振れは作成者が置いたもので、結果はこれで決まります。①のずれは、置いた温まりの量で−2.36〜+4.695と動きました
- 主なずれ（①の+2.351、②の+0.391、往復の+0.155）は、置いた温まりと並べ方からの式どおりの値です。新しいのは、並べ方ごとにまざる分が、平均のずれになるか散らばりになるかで入れかわる点です
- 前の板の残りが次の板にまざる持ちこしは入れていません。持ちこしがあると、1周ずつくり返す・往復の並べ方にもずれがまざります（1056 で処理の速さについて、同じ企画の 1112 で4つの配合の試し染めについて数えています）
- 焼く時間の効き目はまっすぐ（1分ごとに1.0）と置きました。効き目が曲がっていると、どの時間がいちばん良いかの読み違いは、この記事の数え方とは別になると考えています（推測）
- 実在の窯・工房の動きを表すものではありません
