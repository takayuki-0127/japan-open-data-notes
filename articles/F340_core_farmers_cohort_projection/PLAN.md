# F340 PLAN（事前の計画）：農業で働く人の高齢化は、この先どう進むのか？

作成：2026-11-16 06:37（JST）。集計のスクリプトを書く前、推計の数字を出す前に書いた。

## 問い

基幹的農業従事者（自営農業を主な仕事としている世帯員）は、2000年の240万人から2025年の104万人へ、25年で半分以下になりました（農林水産省「食料・農業・農村白書」令和7年版）。2025年は65歳以上が約7割です。

「このまま減り続ける」「高齢化がさらに進む」とよく言われますが、どのくらいの速さで、どこまで進むのかを、年齢別の人数を5年ごとに追う方法（コーホート変化率法）で確かめます。あわせて、この方法が過去にどれだけ当たったかを、2020年・2025年の実績で答え合わせします。

知りたい人：農業・食品・農業資材の仕事で国内の担い手の数の見通しを使う人、地域の農業の計画を読む人、人口推計の方法を学ぶ人。

## データ

農林水産省「農林業センサス」（e-Stat、2026-11-16 取得）

- 累年統計 表5-11 年齢別基幹的農業従事者数：2005・2010・2015年は販売農家、2015・2020年は個人経営体。5歳階級（15〜19歳 … 85歳以上）、男女、全国・地域・都道府県
- 2025年農林業センサス 表2-54(1)ア：2025年と2020年、個人経営体、同じ5歳階級

2015年は販売農家と個人経営体の両方があるので、2015年までの変化率は販売農家、2015年からは個人経営体で計算する。

## 取得前に見たもの（開示）

- 2025年と2020年の全国の年齢別（男女計・男・女）の行と、地域別の数行を画面で見た
- 2015年（販売農家・個人経営体）、2000年の全国の年齢別の行を見た
- 白書の要約（2025年104万人、65歳以上69.6%、平均67.7歳、49歳以下13万人）を読んだ
- 変化率や推計の値は計算していない

## 方法

1. コーホート変化率：ある年の a〜a+4 歳の人数に対する、5年後の a+5〜a+9 歳の人数の比。85歳以上は「80〜84歳と85歳以上」から「85歳以上」への比。15〜19歳は、5年前の値で横ばいとおく
2. 4つの期間（2005→10、2010→15、2015→20、2020→25）の変化率をそれぞれ使い、2025年から2030・2035・2045年を推計する。4本の幅を「推計の幅」とする。主の推計は直近（2020→25年）の変化率
3. 答え合わせ：2015年の人数に2010→15年の変化率をかけて2020年を、2020年の人数に2015→20年の変化率をかけて2025年を推計し、実績と比べる（1期先）。2015年から2025年の2期先も
4. 指標：人数、65歳以上の割合、49歳以下の人数、平均年齢（各階級の中央の年齢で近似。85歳以上は87.5歳）

## 仮説（それぞれ「こうなったら外れ」の基準つき）

- **H1（答え合わせ）**：1期先の推計の誤差（総数）は2020年・2025年とも ±5% 以内。外れ：どちらかが5%を超える
- **H2（人数）**：2035年の推計は、4つの変化率のどれを使っても50万〜70万人の間。外れ：どれかが範囲の外
- **H3（高齢化）**：2035年の65歳以上の割合は、どの変化率でも65%以上。外れ：どれかが65%未満
- **H4（若い層）**：49歳以下の人数は総数より減り方が小さく、2035年の49歳以下の割合は2025年（12.6%）より高い。外れ：主の推計で割合が下がる

## 頑健性の確かめ（3つ以上）

1. 変化率の期間を変える（4本）と、4期間の平均
2. 男女別に推計して足す
3. 地域別（北海道・東北・北陸・関東・東山・東海・近畿・中国・四国・九州・沖縄）に推計して足す
4. 2015年の接続を個人経営体ではなく販売農家で通す（2010→15年の変化率で比べる）
5. 平均年齢の近似を、85歳以上＝90歳にして変わるか

## 言えないこと（予想）

- 新しく農業を始める人の動き（新規就農）や、法人に雇われて働く人は、基幹的農業従事者に入らない。推計は個人経営体の世帯員だけ
- 変化率が将来も同じとは限らない。政策・価格・天候の影響は入れていない
- 人が減っても、法人化や規模拡大で生産量がどうなるかは分からない
- 政策や経営についての助言はしない
