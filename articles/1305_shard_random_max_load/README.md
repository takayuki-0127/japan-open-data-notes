# 1305 1万件のデータを乱数で10台に振り分けると、いちばん多い1台の件数は平均の何倍になるのか？（データの振り分け）

データを何台かの機械に分けて置くとき、1件ずつ置く台を乱数で決めると、平均すればどの台も同じ件数になります。けれども1回の振り分けで見ると、台ごとの件数はでたらめにばらつき、いちばん多い1台は平均より多くなります。台の容量や負荷を考えるときに効くのは、平均ではなくこのいちばん多い1台です。**ここでは、作成者が置いた架空のアプリのデータ（1件ずつ、番号をでたらめな数に変えて10台のどれに置くかを決めるもの）で、1万件を10台に振り分けたときのいちばん多い1台の件数が平均（1,000件）の何倍になるかを2,000回数え、件数を1,000件〜100万件に変えた4通りでも確かめました。実機では測らず、すべてシミュレーションです。**

例のアプリ・データ・台は架空のもので、実在のデータベースや機械の振り分け方を表すものではありません。台数・費用の見込みの助言はしていません。

関連する記事：981「40人の中に同じ誕生日の人がいるのは、珍しいのか？」は、人数に比べて日の数が多くても、どこか2人が同じ日になるのはふつうに起きることを扱っています。1270「分けた仕事の大きさがばらつくと、全体の時間はいちばん遅い1つでどれだけ延びるのか？」は、処理を8つに分けたとき、組の大きさのばらつきで全体の時間がいちばん遅い1つの分だけ延びることを扱っています。1306「データの件数を変えずに、振り分ける台数を10台から100台に増やすと、いちばん多い1台と平均の比はどう広がるのか？」は、同じ振り分けで台数を増やしたときの広がりを扱っています。1313「置く台を乱数で2つ選んで、空いている方へ入れる決まりにすると、いちばん多い1台は1つだけ選ぶときよりどれだけ減るのか？」は、同じ「置く台を乱数で1つ選ぶ」置き方を1万件・100台で数え、置く台を2つ選んで少ない方に置くと、いちばん多い1台が平均より多い分が92.61%減ることを扱っています。この記事は、時間ではなく、乱数で置いたデータの1台ごとの件数を数え、いちばん多い1台が平均の何倍になるかに絞ります。

## 主な結果

### 1万件・10台（2,000回、`results/a1305_main.json` の base）
| 数えたもの | 値 |
|---|---|
| いちばん多い1台÷平均（平均） | **1.0488倍** |
| 同（10〜90%） | 1.031〜1.07倍 |
| 同（99%点） | 1.092倍 |
| 2番目に多い1台÷平均（平均） | 1.0322倍 |
| いちばん少ない1台÷平均（平均） | 0.9509倍 |
| いちばん多い1台が平均の1.05倍を超えた回 | 40.0% |
| いちばん多い1台が平均の1.1倍を超えた回 | 0.35% |
| 目安の式 | 1.0462倍 |

- **1万件を10台に乱数で振り分けると、いちばん多い1台は平均で1,000件の1.0488倍だった**。目安の式の1.0462倍に近かった
- 1回目の振り分けでは、10台の件数は959〜1,047件だった（`results/one_trial_counts.csv`、図1）
- 2,000回のうち40.0%の回で、いちばん多い1台が平均の1.05倍を超えた。1.1倍を超えたのは0.35%だった（図2）

### 確かめ：件数を変える（10台、各2,000回、`results/by_records.csv`）
| 件数 | 1台の平均 | いちばん多い1台÷平均（平均） | 10〜90% | 目安の式 | 1.05倍を超えた回 |
|---|---|---|---|---|---|
| 1,000件 | 100件 | 1.1572倍 | 1.1〜1.23倍 | 1.146倍 | 99.8% |
| 1万件 | 1,000件 | 1.0488倍 | 1.031〜1.07倍 | 1.0462倍 | 40.0% |
| 10万件 | 1万件 | 1.0155倍 | 1.0096〜1.022倍 | 1.0146倍 | 0.0% |
| 100万件 | 10万件 | 1.0048倍 | 1.003〜1.007倍 | 1.0046倍 | 0.0% |

- **件数が1,000件〜100万件の4通りで、いちばん多い1台は平均の1.0048〜1.1572倍だった**。件数が100倍になるごとに、平均を超える分はおよそ10分の1になった（1万件で4.88%、100万件で0.48%）。1台ごとの件数の振れが件数の平方根でしか増えないためで、目安の式どおりの向き
- 4通りすべてで、数えた平均は目安の式より少し大きかった（差は0.0002〜0.0112）。件数が少ないほど差が大きかった

## 注意（言えないこと）
- 架空のデータです。どの台も同じ確率で、1件ごとに独立に置くと置きました。結果はこの置き方で決まり、主な値は件数と台数からほぼ式で決まります
- 1件の大きさ・読み書きの多さはどれも同じと置きました。1件ごとの大きさや読み書きの多さが違う場合は、件数の偏りとは別に偏ります（この記事では数えていません）
- 番号の付け方に癖があり、でたらめな数に変える手順がその癖を消しきれない場合は、偏りがもっと大きくなることがあります（推測）
- 実在のデータベース・機械を表すものではなく、台の容量や台数をどう決めるべきかの助言でもありません
