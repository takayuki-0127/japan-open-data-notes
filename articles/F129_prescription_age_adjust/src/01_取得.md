# 01 取得

## NDBオープンデータ（厚生労働省）
- 第11回（診療年月 2024年4月〜2025年3月）：https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000177221_00017.html の「処方薬」→「公費レセプトを含まないデータ」（`001742577.zip`、2026/09/02 更新版）
- 第10回（診療年月 2023年4月〜2024年3月）：https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000177221_00016.html の「処方薬」（`001499737.zip`）
- zip の中の次の Excel を使いました（`raw/` に置く。どれも 3〜5MB なので GitHub には入れていません）
  - `【内服】外来（院外）_性年齢別薬効分類別数量.xlsx` → `gaiin_age.xlsx`（第10回は `gaiin_age10.xlsx`）
  - `【内服】外来（院外）_都道府県別薬効分類別数量.xlsx` → `gaiin_pref.xlsx`（第10回は `gaiin_pref10.xlsx`）
  - `【内服】外来（院内）_性年齢別薬効分類別数量.xlsx` → `innai_age.xlsx`（第11回のみ）
  - `【内服】外来（院内）_都道府県別薬効分類別数量.xlsx` → `innai_pref.xlsx`（第11回のみ）
- 取り方：厚生労働省のページの中で zip を fetch し、JSZip で必要な Excel だけを取り出して保存しました。手で取る場合は上のページから zip をダウンロードして展開すれば同じです。

## 人口推計（総務省）
- 2024年10月1日現在 第10表「都道府県，年齢（5歳階級），男女別人口－総人口，日本人人口」 statInfId=000040268918 → `raw/f129_pop2024_t10.csv`
- 2023年10月1日現在 第10表 statInfId=000040166082 → `raw/f129_pop2023_t10.csv`
- 取り方：`https://www.e-stat.go.jp/stat-search/file-download?statInfId=<id>&fileKind=4` を e-Stat のページの中で fetch し、SheetJS（xlsx 0.18.5）で `sheet_to_csv` にしました。
