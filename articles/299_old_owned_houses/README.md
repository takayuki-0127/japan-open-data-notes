# 299 築年数の古い家は、どれだけ増えたのか

総務省「令和5年住宅・土地統計調査」時系列統計表 第20-1表（建て方・構造・建築の時期・耐震改修工事の状況別の持ち家数、全国、2003〜2023年）を使ったフォルダです。全国の集計だけを使っています。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A299 | 古い持ち家はどれだけ増えたのか。昔に建った家は、どれだけ残っているのか | 調査年ごとの建築の時期別の持ち家数。同じ築年数の目安でそろえて比べた（建ってから43年以上：2003年調査は1960年以前、2013年は1970年以前、2023年は1980年以前）。同じ建築時期の持ち家が、2003年から2023年の調査でどれだけ残っているか（2003年＝100）。1980年以前に建った持ち家のうち、直近の数年に耐震改修工事をした割合 | `src/a299_old_owned_houses.py` |

## 主な結果
- 建ってから43年以上の持ち家は、2003年290万戸（建築時期が分かる持ち家の10.2%）、2013年449万戸（14.3%）、2023年821万戸（24.6%）。20年で数は2.8倍、割合は4分の1になりました。
- 1980年以前に建った持ち家は、2003年1,220万戸（43.0%）→ 2013年1,032万戸（33.0%）→ 2023年821万戸（24.6%）と減りました。「築年数の古い家」は増えた一方、「昔の基準のころに建った家」は減っています。
- 2003年の調査を100とすると、2023年の調査で残っていた持ち家は、1970年以前に建ったもの53.5、1971〜80年79.4、1981〜90年80.0でした。
- 2023年の持ち家のうち、1980年以前に建ったものの81.5%は木造です（持ち家全体では71.6%）。
- 1980年以前に建った持ち家のうち、調査前の約5年間に耐震改修工事をした割合は、2023年調査で2.6%（2019年以降の工事）。2003〜2018年の各調査でも2.5〜3.9%でした。

## 頑健性
- 建築時期が「不詳」の持ち家（1.0〜3.8%）を分母に含めても、43年以上の割合は10.1% → 13.9% → 24.2%で、同じ向き
- 建築時期の区切りは調査ごとに違う（例：2003年は1960年以前・1961〜70年、2023年は1970年以前）。区切りをまたいで数えていないことをコードで確かめた
- 1970年以前に建った持ち家は、2003年の調査の「1960年以前」と「1961〜70年」を足した
- コードはきれいなフォルダで3回動かし直し、data・results・figures の全ファイルが一致した

## 動かし方
```
pip install -r requirements.txt
python src/a299_old_owned_houses.py
```

## データ
- `data/raw/hlts_ts_subset.json`：e-Stat「令和5年住宅・土地統計調査 時系列統計表」第20-1表（statInfId=000040354052）の閲覧用 Excel を、ブラウザの中で SheetJS（xlsx 0.18.5）で CSV の文字列にしたもの（2026-11-12 取得）。手で取る場合は `https://www.e-stat.go.jp/stat-search/file-download?statInfId=000040354052&fileKind=4`
- `data/owned_by_construction_period.csv`：整形した表

## 注意
- 数えているのは「人が住んでいる持ち家」です。空き家や、貸家として使われるようになった家は入りません。「残っていた」は、取り壊されずに、持ち家として住まれていることを指します
- 1981年6月に建物の耐震の基準が変わりましたが、表の区切りは「1980年以前」なので、境目の家の分け方は正確ではありません
- 耐震改修工事の割合は、調査ごとに対象の期間が違います（2003年調査は1999年以降、2013年は2009年以降、2018年は2014年以降、2023年は2019年以降）。2008年調査は表に期間の記載がありません
- 標本調査の推定値です。建築の時期は住んでいる人の回答によります
- 空き家の記事（119・120・F278）とは対象が違い、この記事は人が住む持ち家だけを見ています
