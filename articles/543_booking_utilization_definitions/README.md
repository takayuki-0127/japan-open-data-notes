# 543 予約枠の稼働率は、無断キャンセルと直前キャンセルをどう数えるかで何ポイント違うのか（実務の型・指標の定義）

予約制の店や窓口の「稼働率」は、無断キャンセルや直前キャンセル、そのあと当日予約で埋め直した枠をどう数えるかで値が変わります。**ここでは、架空の予約制の店（2025年、火曜定休、1日16枠、5,008枠）の予約記録を作り、稼働率を4通りで数えて、全体・曜日・月の差と、月の順位の入れ替わりを数えました。** 予約やキャンセルの起きやすさは作成者が置いたもので、数字はその仮定で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A543 | 稼働率の4つの数え方で、全体・曜日・月の値と順位がどれだけ違うか | D1 予約件数 ÷ 枠（埋め直した枠は2件）、D2 予約が入った枠 ÷ 枠、D3 直前キャンセルを除く（来店＋無断キャンセルの枠）÷ 枠、D4 来店ベース（来店があった枠）÷ 枠。曜日・月の順位の比較（大小が逆になるペアの数）。Python と SQL（DuckDB、1スレッド）で曜日別の値が一致することを確認。seed 543 | `src/a543_utilization.py`、`src/02_utilization_duckdb.sql`、`src/01_utilization_tsql.sql`（未検証） |

## 主な結果
- **予約記録**：5,008枠に予約 3,878件（前もっての予約で来店 3,091件・無断キャンセル 194件・直前キャンセル 331件、当日予約で来店 262件）
- **全体の稼働率**：D1 77.4%、D2 75.2%、D3 70.8%、D4 67.0%。いちばん高い数え方と低い数え方の差は 10.5ポイント
- **曜日**：D1 − D4 の差は水・木 5.3ポイントから、土 14.8・日 19.4ポイントまで。直前キャンセルと無断キャンセルの多い曜日ほど差が大きい。曜日の高い順（土・日・金・月・木・水）はどの数え方でも同じ（D4 では月と木が同じ値）
- **月**：D1 − D4 の差は 7.3〜14.4ポイント。D1 と D4 では12か月のうち10か月の順位が変わり、66組のうち12組で大小が入れ替わった。D1 で1位の12月は D4 では4位、D4 で1位は5月
- 月の順位が変わる組の数は、定義の組み合わせで 3〜12組（D1 と D2 でも 3組）

## 動かし方
```
pip install -r requirements.txt
cd src && python a543_utilization.py
```
数秒で終わります。`data/` に予約記録（slots.csv・reservations.csv）を書き出します。

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures がバイト単位で一致した（DuckDB は `SET threads=1`）
- 曜日別の4つの稼働率が、Python と DuckDB の SQL で一致した
- T-SQL 版（`01_utilization_tsql.sql`）は書いたが、SQL Server では動かしていない（**未検証**）

## データ
- `data/slots.csv`：枠（slot_id・日付・枠番号）。`data/reservations.csv`：予約（res_id・slot_id・前もって／当日・来店／直前キャンセル／無断キャンセル）
- 仮定：前もって予約が入る確率 月62%・水58%・木63%・金72%・土90%・日86%、直前キャンセル 6〜15%（日曜が最も多い）、無断キャンセル 3〜9%、直前キャンセルの枠が当日予約で埋まる確率 25〜40%、空いていた枠が当日予約で埋まる確率 8〜15%。月ごとに予約の入りやすさ（0.92〜1.08倍）と直前キャンセルの起きやすさ（0.9〜1.4倍）を変えた
- 前もってのキャンセル（24時間より前）は、枠が空いたままになるものとして記録に入れていない

## 注意（言えないこと）
- 架空のデータ。実際の店や施設の数字ではない
- 差の大きさは、置いたキャンセルと埋め直しの起きやすさで決まる
- どの数え方が正しいかを決めるものではない。売上・人の手配・予約の受け方の見直しなど、使う目的で合う数え方は変わる
- 料金やキャンセル料の決め方についての助言ではない
