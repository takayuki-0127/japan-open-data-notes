# 975 項目ごとに欠けた行を除くと、件数はどれだけ減るのか？（欠けたデータ）

アンケートの集計では、「どこかの項目が空欄の人を除き、全部の項目に答えた人だけで数える」ことがよくあります。1つの項目の空欄は少しでも、項目が多いと、どこか1つが空欄の人は思ったより多くなります。除いた人が答えた人と違う人たちなら、残った人の平均もずれます。**ここでは、作成者が乱数で作った架空の店の来店アンケート（1,000人・1〜5の項目。全員が全部に答えたときの本当の答えを作成者が置いたもの）に、どの項目も平均5%の空欄を4通りの入り方で入れ、全部の項目がそろう人がどれだけ残るか、残った人だけの総合満足の平均が本当の平均からどれだけずれるかを数えました。**

店・アンケート・回答者はすべて架空のもので、実在の調査の数字は使っていません。

途中で答えるのをやめた人（後ろの問がまとめて空欄になる人）を入れるか除くかは関連する記事 866、そもそも答えるかどうかで回答者の顔ぶれが変わる話は 870 で扱っています。同じ企画では、1つの欄の空欄を除いて平均したときのずれは 969、空欄を平均や回帰で埋める話は 972、欠けたところだけ別の方法で埋める話は 978 で扱っています。この記事は、空欄があちこちの項目に散らばっているときに「全部そろった人だけ」に絞ると、件数と平均がどう動くかに絞ります。

## 主な結果

### 10項目が全部そろう人の割合（1項目の空欄は平均5%、各200回の平均）
| 空欄の入り方 | 全部そろう人 | 10〜90%の範囲 | 式の値 | 除いた人のうち、空欄が1項目だけだった人 |
|---|---|---|---|---|
| ①独立 | **59.97%** | 58.19〜61.9% | 59.87%（0.95の10乗） | 78.49% |
| ②人ごとに欠けやすさが違う | **71.08%** | 69.29〜73.01% | 70.99% | 61.48% |
| ③不満な人ほど空欄 | 63.66% | 61.8〜65.3% | 63.94% | 71.26% |
| ④②と③の両方 | 72.83% | 70.99〜74.81% | 72.88% | 59.45% |

- 1項目の空欄は5%でも、10項目が全部そろう人は約6割（59.97%）で、4割の人が除かれた。これは 0.95 の10乗（59.87%）という**式どおり**の値で、ここは置いた前提の写し
- 除かれた人の78.49%は、10項目のうち1項目だけが空欄の人だった（①）
- 空欄にしやすい人とそうでない人がいる（②）と、空欄が同じ人に重なるので、全部そろう人は71.08%と多めに残った。これも人の欠けやすさで平均した式の値（70.99%）どおり
- 例の1回分（④の置き方）では、10,000マスのうち空欄は467マス（4.67%）で、全部そろった人は1,000人のうち733人だった

### 使う項目の数と、全部そろう人の割合（各200回の平均）
| 使う項目の数 | ①独立 | ②人ごとに欠けやすさが違う | 式（独立） |
|---|---|---|---|
| 1 | 95.07% | 94.97% | 95.0% |
| 3 | 85.82% | 87.28% | 85.74% |
| 5 | 77.58% | 81.52% | 77.38% |
| 10 | 59.97% | 71.08% | 59.87% |
| 15 | 46.41% | 63.66% | 46.33% |
| 20 | 35.85% | 57.96% | 35.85% |

- 独立なら、項目を1つ足すたびに残る人は0.95倍になる。20項目では35.85%しか残らなかった

### 総合満足（q1）の平均の、本当の平均とのずれ（各200回の平均）
| 空欄の入り方 | 総合満足の空欄だけ除く | 10項目すべてそろった人だけ | 「4以上」の割合のずれ（そろった人だけ） |
|---|---|---|---|
| ①独立 | +0.0001点 | +0.0002点 | −0.03ポイント |
| ②人ごとに欠けやすさが違う | −0.0005点 | +0.0012点 | +0.06ポイント |
| ③不満な人ほど空欄 | +0.0238点 | **+0.1856点** | **+8.55ポイント** |
| ④②と③の両方 | +0.0194点 | +0.1014点 | +4.67ポイント |

（本当の総合満足の平均は3.4827〜3.4879点、「4以上」の本当の割合は49.91〜50.04%）

- 空欄が満足度と関係なく入る①②では、全部そろった人だけで数えても平均はずれなかった。件数が減って振れが大きくなるだけだった
- 不満な人ほど空欄にする③では、総合満足の空欄だけを除いた平均のずれは+0.0238点だったが、10項目すべてそろった人だけにすると+0.1856点と7.8倍になった。除く人を10項目分の空欄で選ぶので、不満な人がそれだけ多く抜けた
- 平均が高く出る向きは、不満な人ほど空欄にすると置いたことの写し。新しく数えたのは、同じ空欄の入り方でも「全部そろった人だけ」に絞るとずれが何倍にもなる、という大きさ
- ④のように空欄が同じ人に重なると、除かれる人が減り、ずれも+0.1014点（総合満足の空欄だけ除いたずれの5.23倍）に小さくなった

| 5%・10項目 | 人ごとの差なし60.08%、差2で75.65% |

## 動かし方
```
pip install -r requirements.txt
```

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の9ファイルがバイト単位で一致した（cmp、2回流して2回とも一致、1本10秒以内）
- 図3枚を開き、日本語・重なり・軸を確かめた
- 全部そろう人の割合が、置いた空欄の割合からの式の値と合うことを確かめた（4通りで0.28ポイント以内、36通りで0.59ポイント以内）。作りが置いたとおりに動いていることの確かめで、件数の減り方そのものは置いた前提の写しである
- 空欄が満足度と関係しない置き方（b=0）では、全部そろった人だけの平均が本当の平均とずれないこと（最大0.0046点）を確かめた

## データ

- `results/a975_main.json`：主な結果すべて
- `results/models.csv`：4つの空欄の入り方の結果
- `results/by_number_of_items.csv`：使う項目の数（1〜20）ごとの、全部そろう人の割合

- `results/robustness_bias.csv`：空欄の割合×人ごとの差×満足度の効き（24通り）

## 注意（言えないこと）
- 架空のデータです。空欄の割合、人ごとの欠けやすさの差、満足度の効きは作成者が置いたもので、結果はこれで決まります。全部そろう人の割合は式どおりで、置き方で1.1〜92.3%と動きました。平均のずれは、置き方で+0.028〜+0.3427点と動きました
- 「不満な人ほど空欄にする」は作成者が置いた向きです。満足した人ほど空欄にするなら、ずれは逆向きになります。実際のアンケートでどちら向きかは、この記事では言えません
- 空欄を何かで埋める方法（平均で埋める、ほかの答えから見込む など）は扱っていません（972・978）。全部そろった人だけに絞るか、項目ごとに空欄だけを除くかの2つを比べました
- 実在のアンケートの回答の仕方を表すものではありません
