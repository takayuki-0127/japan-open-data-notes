# tea-production-japan：農林水産省「作物統計調査」で、茶の栽培面積と荒茶生産の60年を調べる

農林水産省「作物統計調査」の茶の収穫量累年統計（全国 1959〜2024年、主産県の合計 1985〜2024年）と、全国の荒茶生産量の累年統計（茶種別、1926〜2024年産）を使ったリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A136 | 茶の栽培面積はどれだけ、いつ減ったのか。荒茶の生産は茶種でどう変わったか | 全国の栽培面積・荒茶生産量の推移と期間別の年率、栽培面積10a当たりの荒茶、茶種別（普通せん茶・番茶・おおい茶・玉緑茶）の生産量と構成比 | `src/a136_tea.py` |

## 主な結果
- 栽培面積は1980〜83年の6.1万haが最大で、2024年は3.51万ha（−42.5%）。減り方は2004→2014年の年0.9%から、2014→2024年は年2.4%に速まった
- 荒茶生産量は1975年の10.5万tが最大で、2024年は7.39万t（−29.9%）。面積ほど減っていない
- 栽培面積10a当たりの荒茶は、1959〜69年の平均168kgから、2015〜24年の平均198kg、2024年は211kg（最も多い）
- 茶種別（調査は2016年産まで）では、普通せん茶が1975年の8.33万tから2016年は4.73万tに減った。番茶は1.42万t→2.18万t、おおい茶（玉露・かぶせ茶・てん茶）は0.29万t→0.70万tに増えた。荒茶に占める普通せん茶の割合は79.0%→59.0%
- てん茶（抹茶の原料）は、分けて表章されていた2008年産までで、1975年の351tから2008年は1,780tになった

## 動かし方
`data/` に整えた CSV と元の Excel（`data/raw.zip`）が入っているので、そのまま動きます。CSV を消すと `raw.zip` を展開して作り直します。

```bash
pip install -r requirements.txt
cd src
python a136_tea.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/national.csv | 全国：年、栽培面積（ha）、摘採延べ面積、生葉収穫量、荒茶生産量（t） |
| data/main_prefs_total.csv | 主産県の合計：同じ項目（2005年以降、欠けた年あり） |
| data/aracha_by_type.csv | 全国の荒茶生産量（茶種別、t）：計、玉露、かぶせ茶、てん茶、普通せん茶、玉緑茶、番茶、その他、紅茶、おおい茶（玉露・かぶせ茶・てん茶の合計） |
| data/raw.zip | e-Stat から取得した Excel 3つ（収穫量累年統計 茶 全国・主産県、全国累年統計表 荒茶生産） |

## 注意
- 取得した表は全国と「主産県の合計」で、都道府県ごとの値は入っていません。産地（県）別の減り方は、このリポジトリでは調べていません
- 主産県は年によって入れ替わり、調査をしていない年もあります（全国の値も、摘採面積などは調査した年だけ）
- 荒茶生産量の茶種別の調査は2016年産で廃止されました。2009〜2016年産は玉露・かぶせ茶・てん茶が「おおい茶」として一括で表章されています
- 2011年産の全国の荒茶生産量は、原子力災害による出荷制限のため推計が行われず、主産県の合計値です
- 10a当たりの荒茶は「荒茶生産量÷栽培面積」で計算した値で、摘採した面積当たりの収量ではありません
- 1973年以前は沖縄県を含みません
