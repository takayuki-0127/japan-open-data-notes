# F241 顧客はどれくらいで離れていくのか？（実務に近い分析：生存分析・コホート表・LTV）

シリーズ「実務に近い分析」（F231〜F245）の11本目。解約（チャーン）の分析を、生存分析の道具で実務の形にする。

- note の記事：（公開後に記入）
- 前の記事：F236〜F238（A/B テスト）、F28（法人の生存分析）

## 問い
1. 「解約率 26.5%」のような数字は、何を意味していて、何を意味していないのか
2. 契約の種類や使っているサービスで、離れ方はどれだけ違うのか
3. コホート（始めた年）ごとの定着率表は、どう作り、どう読むのか
4. LTV（1人あたりの将来の売上）は、どこまで確かに言えるのか

## データ
- **A：IBM「Telco Customer Churn」**（架空の通信会社の顧客 7,043人の公開サンプル、Apache License 2.0）。在籍月数（tenure、0〜72か月）と、解約したかどうか、契約の種類・サービス・支払い方法・月額。実在の会社・顧客ではない
- **B：法人の存続**（この連載 F28 のデータ。国税庁 法人番号公表サイトの全件データから作成。2016〜2025年に設立された株式会社・合同会社 128.8万社、観察の終わりは 2026-09-30）。法人名・番号は使っていない
- ダッシュボードの「さくら回線」は架空の会社名

## 手法
- Kaplan–Meier（打ち切りを考えた残存率）、月ごとの生命表（ハザード）、制限平均生存時間（72か月まで）
- log-rank 検定、Cox 比例ハザードモデル、比例ハザードの検定（Schoenfeld 残差）、契約で層別した Cox、半分で学習・半分で検証
- コホートの定着率表（設立年×経過年、全員が観察できるマスだけ）。SQL でも作成
- LTV：月額×残存率を年5%で割り引いて足す（割引率は例示）。72か月より先は、最後の1年の解約率で一定・指数・Weibull・対数正規・sBG（毎月の解約確率が人ごとに違うモデル）で外挿して比べる
- SQL（SQL Server 互換：CTE・CASE・SUM のみ）で生命表とコホート表を書き、DuckDB で Python と照合

## 結果（A：架空の通信会社）
- 「解約した人の割合」は 26.5%。ただし在籍の長さがばらばらな人を一度に数えた数字で、期間がない。Kaplan–Meier では、残る割合は 12か月 84.3%、24か月 78.9%、72か月 59.3%
- 月ごとの解約の起こりやすさは 1か月目 5.4%、12か月目 0.76%、2〜3年目は平均 0.45%。最初の数か月に集中する。5〜6年目は平均 0.84% にやや上がる
- 解約した人の平均在籍は 18.0か月だが、全員の72か月までの平均在籍（制限平均）は 54.5か月。解約した人だけで「平均何か月で辞めるか」を出すと大きく短く見える
- 契約の種類：月ごと契約（3,875人）は12か月で 70.3%、72か月で 12.9%。1年契約は72か月で 56.8%、2年契約は 93.6%（log-rank p<0.001）
- Cox（ハザード比、95%区間）：2年契約 0.03（0.02〜0.05）、1年契約 0.18（0.15〜0.21）、光回線 3.70（3.01〜4.55）、電子小切手払い 1.65（1.50〜1.82）、パートナーあり 0.55、技術サポートあり 0.76。月額10ドル高いと 0.75（光回線などのサービスをそろえたうえでの値）。C 指数 0.846
- 比例ハザードの仮定は契約の種類などで崩れていた（p<0.01）。契約で層別しても、ほかのハザード比はほぼ同じ（光回線 3.53、電子小切手 1.63、パートナー 0.56）
- 半分で学習して残り半分に当てると、12か月の残存は予測 83.6% に対し実際 84.6%、24か月は 75.8% に対し 80.0%（C 指数 0.847）
- LTV（72か月まで、年5%割引）：1人あたり 3,124ドル（顧客を復元抽出した95%区間 3,067〜3,179）。月ごと契約 2,168、1年 3,807、2年 3,822
- 30年に外挿すると 5,180〜7,903ドルと1.5倍の幅：最後の1年の解約率で一定 5,180、指数 5,250、Weibull 6,586、対数正規 7,176、sBG 7,903。当てはまり（AIC）は sBG がいちばん良い（20,936、対数正規 21,041、Weibull 21,157、指数 21,697）。72か月時点の残存は KM 59.3% に対し各モデル 55〜66%
- よくある簡便式「月額 ÷ 月の解約率」（解約数 ÷ 延べ在籍月数＝0.82%）は 7,900ドル（割引なし・期間無限）。「月額 ÷ 26.5%」は単位が合わず意味がない（244ドル）

## 結果（B：法人のコホート表）
- 株式会社の「まだ続いている割合」は、1年で 99.3〜99.4%、5年で 94.6〜95.0%（2016〜2020年設立）。設立年が違ってもほとんど同じ
- 合同会社は 5年で 92.4〜93.0% で、株式会社より 2ポイントほど低い
- 全員が5年観察できるコホート（2016〜2020年設立の株式会社）では、コホート表と Kaplan–Meier の5年存続率が一致（94.75%）。観察が途中のコホートを混ぜるときは KM を使う

## 頑健性
- 比例ハザードの崩れ：契約で層別した Cox でもハザード比はほぼ同じ
- 学習・検証に分けた較正（上記）
- LTV の外挿モデル5通り、割引率 0%・3%・10%（72か月まで 3,567・3,289・2,771ドル）
- LTV のブートストラップ（300回）
- 0か月の顧客（11人）を除く：12か月 84.3%、72か月 59.3% で変わらない
- SQL との照合：生命表 72行の差の最大 9×10⁻¹⁰、コホート表 90マスの差の最大 3×10⁻⁸（CSV の丸め）

## 言えないこと
- **A は一時点の切り取り（スナップショット）のデータ**：72か月より前に入って、すでに辞めた人は入っていない（左側の切断）。在籍月数を「時間」とみなす分析はよく使われるが、厳密な追跡データではない
- 解約の理由は分からない。Cox のハザード比は関連であって、「光回線をやめさせれば解約が減る」という因果ではない（光回線の人ほど料金が高い・競合が多いなどが混ざる）
- 月額のハザード比 0.75 は、サービスの組み合わせをそろえたうえでの値で、「値上げすると解約が減る」という意味ではない
- LTV の割引率・30年の期間・粗利を考えない売上ベースは、すべて例として置いたもの
- B は法人の閉鎖で、顧客の解約ではない。コホート表の作り方の例として使った
