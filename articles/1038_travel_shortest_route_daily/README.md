# 1038 「最短の道」は、毎日同じなのか？（移動と時間）

通勤や配送で「この道がいちばん速い」と決めていても、その日いちばん速かった道が毎日同じとは限りません。混み方はその日ごとに振れるので、平均でいちばん速い道でも、ほかの道に負ける日があります。そこで「昨日はあの道が速かったから、今日はあの道にしよう」と乗りかえたくなります。**ここでは、作成者が乱数で作った架空の通勤の道4本（道ごとの本当の平均の時間と、日ごとの振れの大きさを作成者が置いたもの）の250日×400年で、平均で最短の道がその日いちばん速かった日の割合と、前の日に速かった道へ毎日乗りかえるやり方が、平均で最短の道に決めて通うやり方より速いかを数えました。道ごとの振れが次の日に残る度合い、町全体の混み方の残り方、振れの大きさ、道どうしの平均の差を変えた確かめも行いました。**

例の道は架空のもので、実在の道路・路線・地名は使っていません。

関連する記事：まっすぐの距離と道のりで近い店が入れかわる話は 947、配送の時間が距離に比例するかは 952 で扱っています。同じ企画の 1030「「平均の所要時間」で計画すると、何回に1回遅れるのか？」は1本の道の時間の振れを、1034「混む時間帯を避けると、どれだけ早く着くのか？」は出る時刻の選び方を扱います。1037「待ち合わせに余裕を何分みれば、9割の確率で間に合うのか？」は、過去10回ほどの少ない記録から余裕を決めると9割に届かないことを扱っていて、この記事の「最初の10日の記録で選ぶ」と同じく、少ない記録から決めるずれの話です。この記事は、道が何本かあるときに「いちばん速い道」が日によって入れかわるか、前の日の結果で道を選ぶと得かに絞ります。

## 主な結果

### 道ごとの、いちばん速かった日の割合（250日×400年、`results/routes.csv`）
| 道 | 本当の平均 | データの平均 | 日ごとの標準偏差 | いちばん速かった日 | 例の1年 |
|---|---|---|---|---|---|
| 道A | 31分 | 30.99分 | 3.347分 | 25.91% | 27.2% |
| **道B** | **30分** | 29.997分 | 4.113分 | **46.95%** | 48.4% |
| 道C | 32分 | 31.995分 | 3.202分 | 14.64% | 12.0% |
| 道D | 33分 | 33.003分 | 3.034分 | 12.51% | 12.4% |

- **平均でいちばん速い道Bが、その日いちばん速かったのは46.95%の日だった。残りの53.05%の日は、ほかの道のどれかが速かった**。道Bが、ほかの3本のうちいちばん速い道より5分を超えて遅かった日は15.36%あった
- いちばん速かった道が前の日と同じだったのは32.47%の日だった。日どうしが関係ないときの式の値（4本の「いちばん速かった日の割合」の2乗の和、32.46%）どおり
- 同じ道が続けていちばん速かった日のまとまりは平均1.478日で、まとまりの70.54%は1日だけで別の道に入れかわった（いちばん長く続いたのは15日）
- いちばん速かった日の割合は、置いた平均と振れの大きさで決まる値で、新しく数えた値ではない。新しく数えたのは、次の「どう選ぶと速いか」

### やり方ごとの1日あたりの時間（基本の置き方、11日目以降、`results/strategies_base.csv`）
| やり方 | 1日の平均 | 10%の日はこれより遅い | ④との差（平均） | ④より5分を超えて遅い日 |
|---|---|---|---|---|
| ①平均で最短の道に固定（本当の平均） | **29.996分** | 35.262分 | 1.987分 | 15.31% |
| ②最初の10日の平均で選んで固定 | 30.333分 | 35.342分 | 2.324分 | 18.26% |
| ③前の日にいちばん速かった道 | **30.932分** | 35.735分 | 2.923分 | 24.25% |
| ④その日いちばん速い道（後から分かる） | 28.009分 | 31.669分 | 0分 | 0% |

- **前の日にいちばん速かった道へ毎日乗りかえると、平均で最短の道に固定するより1日0.936分遅かった**。前の日にほかの道が速かったのは、その道のたまたまの振れで、次の日には残らないため
- 最初の10日の記録で選ぶと、道Bを選べたのは72.0%の年で、23.25%は道A、3.75%は道C、1.0%は道Dを選んだ。そのぶん①より0.337分遅かった
- 毎日その日いちばん速い道を通れたとしても（④）、①との差は1日1.987分だった

### 確かめ：置き方を1つずつ変えると（各200年、`results/sensitivity.csv`）
| 変えたもの | 値 | 道Bがいちばん速かった日 | 前の日と同じ道が速かった日 | ③前の日に速かった道 − ①固定 | ②10日で選んで固定 − ①固定 |
|---|---|---|---|---|---|
| 道ごとの振れが次の日に残る度合い | **0（基本）** | 46.73% | 32.24% | **+0.918分** | +0.245分 |
| | 0.5 | 46.4% | 47.64% | **−0.331分** | +0.481分 |
| | 0.8 | 46.03% | 61.5% | −1.179分 | +0.606分 |
| | 0.95 | 47.12% | 72.2% | **−1.499分** | +0.719分 |
| 町全体の混み方が次の日に残る度合い | 0.5 | 46.91% | 34.61% | +0.733分 | +0.356分 |
| | 0.9 | 46.81% | 36.51% | +0.586分 | +0.406分 |
| 道ごとの振れの大きさ | 0.5倍 | 56.49% | 42.29% | +0.618分 | +0.18分 |
| | 2倍 | 40.14% | 28.15% | +1.132分 | +0.694分 |
| 道Bの本当の平均（道Aは31分） | 28分 | **64.06%** | 45.95% | **+1.337分** | +0.041分 |
| | 30.8分 | **39.79%** | 28.94% | +0.561分 | +0.192分 |

- **道Bがいちばん速かった日の割合は、置き方で39.79〜64.06%と動いた**。どの置き方でも、平均でいちばん速い道がいちばん速い日は3分の2に届かなかった
- **前の日に速かった道へ乗りかえる得失は、道ごとの振れが次の日に残る度合いで逆転した**（−1.499〜+1.337分）。振れが日ごとにでたらめなら乗りかえは損（+0.918分）、0.5以上残るなら得（0.5で−0.331分、0.95で−1.499分）だった。工事のように何日も続く遅れがある道では、前の日の結果が次の日の手がかりになるため（仕組みからの説明）
- 町全体の混み方だけが何日も続くとき（0.5・0.9）は、乗りかえは損のままだった（+0.733分・+0.586分）。町全体の混み方は4本に同じ向きに効くので、道の順はあまり変えないため（仕組みからの説明）
- 最初の10日の記録で選ぶやり方は、振れが次の日に残るほど①との差が広がった（+0.245分→+0.719分）。似た日が続くと、10日の記録は10日分の手がかりにならないため
- 基本の行（0）は、主な結果（250日×400年）と乱数が違うため、+0.918分と+0.936分のように少し違う

## データ

- `results/strategies_base.csv`：やり方ごとの1日あたりの時間（mean_min・p90_min（10%の日はこれより遅い）・over_oracle_min（④との差）・share_over_5min（④より5分を超えて遅い日の%））
- `results/sensitivity.csv`：置き方を1つずつ変えた確かめ（mean_0〜mean_3 は①〜④の1日の平均、follow_minus_fixed_min は③−①、rec_minus_fixed_min は②−①）

## 注意（言えないこと）
- 架空のデータです。道の本数、本当の平均、振れの大きさ、町全体の混み方の効き方は作成者が置いたもので、結果はこれで決まります。平均で最短の道がいちばん速い日の割合は置き方で39.79〜64.06%、前の日に速かった道へ乗りかえる得失は−1.499〜+1.337分と動きました
- とくに、乗りかえが得か損かは、道ごとの振れが次の日に残るかどうかで逆転しました。実際の道でどれだけ残るかは、その道の記録で確かめる必要があります（推測）
- 出る時刻・天気・曜日による違い、道の途中で乗りかえること、その日の混み方を出る前に知る手段は入れていません
- どの道を通るべきかは言えません。この記事は、前の日の結果で道を選ぶと平均の時間がどう変わるかを数えただけです
