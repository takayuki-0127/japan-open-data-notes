# 1162 ファイルごとの圧縮率を平均すると、全体の縮み方とどれだけ違うのか？（データ量の見込み）

保存するデータを圧縮すると、どれだけ量が減るか。ファイルごとに「圧縮後÷圧縮前」（圧縮率）を出して平均すると、全体の圧縮後の合計÷圧縮前の合計とは違う値になります。全体の量を決めるのは大きいファイルの縮み方で、率の平均は件数の多い小さいファイルの縮み方に引っぱられるからです。圧縮では、中身によらない決まった上乗せ（見出しの情報など）があるので、小さいファイルほど縮みにくくなります。さらに、中身の種類によって大きいファイルほど縮みにくい（すでに縮めてある中身が多いなど）こともあれば、その逆もあります。**ここでは、作成者が置いた架空のアプリの保存ファイル5万件（大きさの分布と、決まった上乗せ＋中身の縮み方を置き、乱数で作ったもの）で、ファイルごとの率の平均と全体の率（合計÷合計）を比べ、率の平均で減る量を見込むと何倍ずれるかを数えました。大きさと縮み方の関係を「なし・大きいほど縮まない・大きいほど縮む」の3通りにし、一部（200件）を試しに圧縮して見込む場合も数え、上乗せの大きさと大きさの散らばりを変えた36通りで確かめました。**

率の平均と合計÷合計の差は、式でちょうど「−（ファイルごとの率と大きさの共分散）÷大きさの平均」になり、大きさで重みを付けた率の平均は合計÷合計と同じ値になります（式どおり）。この記事で数えて新しく分かったのは、置き方ごとの差の大きさと向き、それに一部から見込むときの当たり方です。

関連する記事：900「割合の平均と、合計で出した割合はどれだけ違うのか？」は、店ごとの購入率の平均と全店の合計の率の違いを扱い、差が同じ式になることを示しています。この記事は同じ形を圧縮率に当て、決まった上乗せのために大きさで縮み方が違う点と、中身の種類による大きさと縮み方の関係に絞ります。同じ企画の 1161「1件あたりの大きさの平均に件数を掛けた見込みは、とても大きい件が少しまざるとどれだけ外れるのか？」は、量の大半を少数の大きいファイルが占める場面を、平均×件数の見込みで扱っています。1171「中身の種類で圧縮のかかり方が違うとき、種類の割合が変わると全体の圧縮率はどう動くのか？」は、合計÷合計の全体の率を正しく出したうえで、それを種類の割合が違う来年に当てはめるずれを扱っています。この記事は、同じ時点のファイルの中で率の平均と全体の率が違う点に絞ります。1168「小さなファイルがたくさんあると、大きさの合計と実際に使う量はどれだけ違うのか？」は、小さなファイルが件数では多く量では少ない同じ形を、区画への切り上げで扱っています。

## 主な結果

### 基本の置き方（関係なし・上乗せ0.5KB、5万件、`results/a1162_main.json` の `base`）
| 数え方 | 圧縮率 |
|---|---|
| 全体（圧縮後の合計÷圧縮前の合計） | **36.85%** |
| ファイルごとの率の平均 | **39.62%** |
| ファイルごとの率の中央値 | 37.57% |
| 大きさで重みを付けた率の平均 | 36.85% |
| 差（率の平均−全体） | 2.77ポイント |
| 式（−共分散÷大きさの平均）で出した差 | 2.77ポイント |

- **率の平均39.62%は、全体の36.85%より2.77ポイント高かった**。差は式の値と一致し（式どおり）、大きさで重みを付けた平均は全体と同じ値になった（式どおり）
- 率の平均で減る量を見込むと、実際に減る量（4.826GB）の0.9561倍（4.614GB）だった

### 大きさの区分ごと（基本の置き方、`results/base_by_size.csv`）
| 元の大きさ | 件数の割合 | 量の割合 | 率の平均 |
|---|---|---|---|
| 1KB未満 | 0.48% | 0% | 97.01% |
| 1〜10KB | 13.68% | 0.5% | 48.65% |
| 10〜100KB | 53.56% | 14.56% | 38.46% |
| 100KB〜1MB | 30.02% | 54.31% | 36.87% |
| 1MB以上 | 2.26% | 30.62% | 36.9% |

- 10KB未満のファイルは件数で14.16%あるが、量では0.51%しかない。その率の平均は50.31%で、決まった上乗せのぶん縮みにくい。率の平均ではこの14.16%が件数どおりに効き、全体の率ではほとんど効かない

### 大きさと縮み方の関係の3通り（ほかは基本、`results/relation_three.csv`）
| 関係 | 全体の率 | 率の平均 | 差 | 減る量の見込み÷実際 |
|---|---|---|---|---|
| なし（基本） | 36.85% | 39.62% | +2.77ポイント | 0.9561倍 |
| 大きいほど縮まない | **72.6%** | **43.45%** | −29.15ポイント | **2.0638倍** |
| 大きいほど縮む | 19.86% | 42.54% | +22.69ポイント | 0.7169倍 |

- **大きいファイルほど縮まないと置くと、率の平均は43.45%なのに全体は72.6%で、率の平均で見込むと減る量（実際27.4%）を56.55%と見込み、2.0638倍に見込んだ**
- 大きいファイルほど縮むと置くと、向きが逆になり、率の平均は全体より22.69ポイント高く、減る量を0.7169倍に見込んだ
- 率の平均は3通りで39.62〜43.45%とあまり動かず、全体の率は19.86〜72.6%と大きく動いた。率の平均は、大きいファイルの縮み方をほとんど写さない（大きいファイルの件数が少ないため）

### 一部（200件）を試しに圧縮して見込む（2,000回、`results/sample_200.csv`）
| 関係 | 全体の率 | 率の平均（中央値） | ±3ポイントに入った回 | 200件の合計÷合計（中央値） | ±3ポイントに入った回 |
|---|---|---|---|---|---|
| なし（基本） | 36.85% | 39.61% | 60.45% | 36.84% | 88.55% |
| 大きいほど縮まない | 72.6% | 43.4% | 0% | 71.69% | 42.05% |
| 大きいほど縮む | 19.86% | 42.52% | 0% | 20.29% | 83.55% |

- 200件の合計÷合計は、3通りとも中央値が全体の率の近く（36.84%・71.69%・20.29%）だった。大きいほど縮まない置き方では、200件に大きいファイルが何件入るかで振れ、10〜90%の範囲は65.24〜78.62%、±3ポイントに入ったのは42.05%だった
- 200件の率の平均は、関係があると±3ポイントに入った回が0%だった。5万件すべての率の平均（43.45%・42.54%）でも全体の率とは上の表の差だけ違うので、選ぶ件数を増やしても縮まらない

### 確かめ：36通り（`results/grid.csv`）
- **36通りで、差（率の平均−全体）は−41.13〜+35.44ポイント**。大きいほど縮まない12通りはすべて全体より低く（−41.13〜−14.41ポイント、減る量の見込みは1.4054〜3.2488倍）、大きいほど縮む12通りはすべて高かった（+15.51〜+35.44ポイント、0.579〜0.7931倍）
- 関係なしの12通りの差は−0.02〜+16.34ポイント。上乗せ0KBの3通りでは−0.02〜+0.21ポイントでほぼ差がなく、上乗せが大きく大きさの散らばりが大きいほど差が開いた（上乗せ3KB・散らばり2.0で+16.34ポイント）
- 36通りで、率の平均は36.58〜59.34%、全体の率は15.41〜82.49%だった
- 36通りすべてで、差は式（−共分散÷大きさの平均）と一致し、大きさで重みを付けた率の平均は全体の率と一致した（どちらもずれ0、式どおり）

## 注意（言えないこと）
- 架空のデータです。大きさの分布、決まった上乗せ、中身の縮み方、大きさと縮み方の関係は作成者が置いたもので、差の大きさと向きはこれで決まります。とくに「大きいほど縮まない・縮む」の向きは置いたとおりに出ます（作りどおり）。実在の圧縮のやり方や、実在のアプリのデータを表すものではありません
- 圧縮率は「圧縮後÷圧縮前」で数えました。「何%減ったか」で数えると、数字の向きは逆になりますが、率の平均と全体の差の大きさは同じです
- 1つのファイルを1つずつ圧縮すると置きました。いくつものファイルをまとめて圧縮する場合や、同じ中身をまとめる場合は入れていません（同じ中身をまとめる見込みは 1163 で扱っています）
- 容量をどれだけ用意すべきかや、その費用は扱っていません
