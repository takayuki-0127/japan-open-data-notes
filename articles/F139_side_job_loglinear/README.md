# F139 副業をしている人は、どんな働き方の人か？ — 集計表のログリニアモデル

## 問い
副業がある人は「女性」「高齢者」に多いように見える。だが、それは雇用形態や所得の違いを映しているだけではないか。属性を組み合わせたときに、副業の多さを決めているのはどの属性か。2017年から2022年に副業が増えたのは、どこでか。

## データ
- 総務省統計局「就業構造基本調査」全国結果 第52表（2017年・2022年）
  男女 × 年齢 × 副業の有無 × 本業の所得 × 本業の年間就業日数・週間就業時間 × 本業の雇用形態（有業者）
- 公表された集計値（推計人口）だけを使う。個票は使っていない。
- 本業の所得が不詳の人は含まない（2022年：6,430万人／有業者6,706万人）。

そろえ方（`src/02_整形.py`）
- 年齢：10歳刻み（2022年の5歳刻みを2017年に合わせた）、7区分
- 本業の雇用形態：正規／非正規／役員（雇用者−正規−非正規）／自営業主など（有業者−雇用者。家族従業者を含む）
- 本業の所得：6区分（主）、16区分（頑健性）
- 本業の就業時間：200日未満／200日以上で週35時間未満／35〜59時間／60時間以上（両年で共通の区切り）

## 手法
- 男女(2)×年齢(7)×雇用形態(4)×所得(6) の各セルについて「副業あり／なし」を数え、ログリニアモデルを当てはめた。
  副業の有無を応答とみなすと、説明側の属性の組み合わせを飽和させたログリニアモデルは、グループ化したロジットモデルと同じになる（`statsmodels` の二項 GLM）。
- 比べたモデル：切片だけ／1属性だけ／4属性の主効果／主効果＋2属性の組み合わせ（交互作用）を1つずつ／すべて。
- 当てはまりは「逸脱度のうち説明できた割合」（1−D/D₀）と非類似度指数 Δ（セルの観測と予測のずれ）で比べた。どちらも推計人口の倍率によらない。
- 区間を出すために、推計人口を 100 で割って標本の人数の目安にした（推測：1標本あたりおよそ100人分。50・200でも試した）。
- 2017→2022年の変化は、セルの構成の変化と、セルの中の割合の変化に分けた（シフトシェア）。

## 結果
| | 2017年 | 2022年 |
|---|---|---|
| 副業がある人の割合 | 4.13% | 4.99% |
| 逸脱度の説明割合：男女だけ | 1% | 2% |
| 年齢だけ | 18% | 18% |
| 所得だけ | 32% | 44% |
| 雇用形態だけ | 68% | 71% |
| 4属性の主効果 | 78% | 79% |
| 主効果＋年齢×雇用形態（いちばん効く組み合わせ） | 87% | 85% |
| 主効果＋2属性の組み合わせすべて | 94% | 93% |

2022年の調整オッズ比（基準：男・35〜44歳・正規・300〜499万円、95%区間）
- 雇用形態：役員 3.27（3.13〜3.42）、自営業主など 2.75（2.63〜2.87）、非正規 2.18（2.11〜2.26）
- 所得：100万円未満 1.79、100〜199万円 1.51、200〜299万円 1.25、500〜699万円 0.94、700万円以上 1.20（U字）
- 女性：0.92（0.89〜0.94）。そのまま比べると 1.18 で、向きが逆になる
- 年齢：65〜74歳 1.08、75歳以上 0.98。そのまま比べると 1.93・2.01

年齢×雇用形態：正規は年齢とともに上がる（2022年 15〜24歳 1.2% → 75歳以上 6.7%）。非正規は 6.7〜8.9%、自営業主などは 7〜11% で、若いうちから高い。

本業の就業時間（2022年、雇用形態などをそろえたオッズ比。基準は200日以上・週35〜59時間）：200日未満 2.07、週35時間未満 1.52、週60時間以上 1.19。

2017→2022年：全体は +0.86ポイント。同じ属性の中で増えた分 +0.96、属性の構成が変わった分 −0.10。増えたのは 75歳以上（+3.0）、65〜74歳（+1.8）、所得100万円未満（+1.9）、自営業主など（+1.7）。所得700万円以上はほぼ横ばい（+0.1）。

## 頑健性
`results/robustness.csv`。2022年の非正規・役員・女性のオッズ比は次の範囲に収まった。
| 変えたこと | 非正規 | 役員 | 女性 |
|---|---|---|---|
| 主（所得6区分） | 2.18 | 3.27 | 0.92 |
| 所得16区分 | 2.13 | 3.07 | 0.91 |
| 倍率 50／200（区間だけが変わる） | 2.18 | 3.27 | 0.92 |
| 75歳以上を除く | 2.16 | 3.26 | 0.92 |
| 自営業主などを除く | 2.12 | 3.13 | 0.89 |
| 本業の就業時間を加える | 1.92 | 3.20 | 0.89 |
| 雇用形態以外の組み合わせをすべて加える | 1.99 | 2.93 | 0.84 |

2017年も同じ向き（非正規 2.23〜2.53、役員 3.54〜4.12、女性 0.80〜0.83）。設計の代替案「2属性ずつのクロス表」で比べると（粗いオッズ比）、女性と高齢層が多く見えるが、これは雇用形態と所得の構成の違いによるもので、組み合わせて見ると消える。

## 言えないこと
- 因果ではない。「非正規だから副業をする」のか、「副業をしたいから非正規を選ぶ」のかは分からない。
- 所得は本業の所得。副業の収入は入っていない。所得不詳の人（約4%）は除いた。
- 区間は「推計人口÷100＝標本の人数」という仮定（推測）にもとづく。調査の設計（層化・集落抽出）は反映していないので、実際の区間はもっと広い可能性がある。逸脱度の割合と Δ は、この仮定によらない。
- 公表値は100人単位で丸められ、小さいセル（例：15〜24歳の役員）はぶれが大きい。
- 産業・職業・配偶関係は今回の表に入っていない。2022年の産業別の表（第77表）は副業がある人だけで、分母がない。
- 2017年と2022年では、就業時間の区切りが違うため、4区分にまとめた。
