# 01 取得（ブラウザで実行）

e-Stat の Excel をページ内で取得し、SheetJS で CSV にしてまとめてダウンロードした（コンテナからは e-Stat に届かないため）。

| 年 | 表 | statInfId |
|---|---|---|
| 2022 | 第52表 男女、年齢、副業の有無、本業の年間就業日数・就業の規則性・週間就業時間、本業の所得、本業の従業上の地位・雇用形態別人口（有業者）－全国 | 000040077317 |
| 2017 | 第52表 男女，年齢，副業の有無，本業の所得，本業の年間就業日数・就業の規則性・週間就業時間，本業の従業上の地位・雇用形態別人口（有業者）－全国 | 000031729397 |
| 2022 | 第77表（参考：副業がある者だけの表で、分母がないため分析には使っていない） | 000040077343 |
| 2017 | 第51表（参考：産業別。今回は使っていない） | 000031729396 |

```js
// e-Stat のページ上で実行
const b = await fetch('https://www.e-stat.go.jp/stat-search/file-download?statInfId=000040077317&fileKind=0').then(r => r.arrayBuffer());
const wb = XLSX.read(b);                       // SheetJS 0.18.5
const csv = XLSX.utils.sheet_to_csv(wb.Sheets[wb.SheetNames[0]]);
```

CSV は `data/raw/<statInfId>.csv`。2022年の CSV は約10MB のため、GitHub には gzip にした `data/raw/*.csv.gz` を置いている（`gunzip` で戻せる）。
