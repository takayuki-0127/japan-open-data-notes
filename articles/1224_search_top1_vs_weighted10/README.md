# 1224 1件目に正しい文書があるかだけを数える点と、10件全体を順位で重み付けする点では、2つの検索の差がどう違って見えるのか？（検索の良さ）

検索のやり方の良さは、「1件目に正しい文書が出たか」だけで数えることも、「上位10件の正しい文書を、上の順位ほど重く数える」こともできます。前者は1語ごとに0か1、後者は0〜1の間の値になります。同じ2つの検索を比べても、どちらの点で数えるかで、差の大きさ・見分けやすさ、ときには向きまで変わります。**ここでは、作成者が置いた架空の社内の文書の集まりと架空の検索語（語ごとに候補の文書215件の「正しさ」を作成者が決め、検索の点を乱数で作ったもの）で、いちばん正しい文書を強く押し上げる検索Aと、やや正しい文書もよく拾う検索Bを、①1件目の点と②10件の点で比べました。検索語のうち「1つを探す語」の割合を0〜100%に変え、AとBの強さとの27通りでも確かめました。**

例の文書・検索語・検索は作成者が置いたもので、実在の検索サービスや社内の仕組みを表すものではありません。

A が「1つを探す語」で強いのは、正しさ2の文書を強く押し上げると置いたためです（作りどおり）。全体の差が「1つを探す語」の割合でまっすぐ動くのも、2種類の語の差を割合で重みづけした平均なので式どおりです。この記事で数えて新しく分かったのは、①では大半の語で A と B が同じになること、そのため同じ差でも①のほうが見分けにくいこと、どの割合で2つの点の向きが入れかわるか、です。

関連する記事：1221「上位10件の正しい割合で比べるか、正しい文書を拾えた割合で比べるかで、良い方の検索は入れかわるのか？」は、上位10件の数え方の違い（10で割るか、正しい文書の数で割るか）で良い方が入れかわるかを扱っています。この記事は、1件目だけを見るか、10件を順位で重み付けするかの違いに絞ります。618 は、起きる割合が1%の予測の良し悪しを2つの物差しで数え、物差しによって2つのモデルの順位が入れかわることを扱っています。1226「小さな改善の差は、検索語を何語そろえれば偶然と見分けられるのか？」は、同じ語で比べるときに要る検索語の数を見込んでいます。そこでも、1件目に正しい文書があるかの点で数えると、10件の点より多くの語が要りました（1,111語と186語）。

## 主な結果

### 本当の差（検索語2万語、1つを探す語40%）（`results/a1224_main.json` の population）
| | A | B | 差（A−B） | 語ごとの差の標準偏差 | 差÷標準偏差 |
|---|---|---|---|---|---|
| ①1件目の点 | 80.41% | 75.01% | **+5.4** | 39.72 | 0.1359 |
| ②10件の点 | 72.48% | 65.49% | **+6.99** | 23.12 | 0.3022 |

（差と標準偏差はポイント）

- 差の大きさはどちらも A が上で、5.4ポイントと6.99ポイントと似ていた。ただし、語ごとの差の散らばりは①が39.72ポイントと大きく、差÷標準偏差は①0.1359・②0.3022で、②のほうが見分けやすい値だった
- 語の種類で分けると、1つを探す語では①+17.27・②+14.24、広く集める語では①−2.44・②+2.2だった。広く集める語では、①は B が上、②は A が上と向きが逆だった

### 語ごとに A と B を比べる
| | A が上 | 同じ | B が上 |
|---|---|---|---|
| ①1件目の点 | 10.73% | **83.93%** | 5.33% |
| ②10件の点 | 50.4% | 20.84% | 28.76% |

- **①では、83.93%の語で A と B が同じだった**（どちらも1件目が正しい、またはどちらも正しくない）。①の差は、A が上の10.73%と B が上の5.33%の語だけで決まっていた
- ②で「同じ」が20.84%あるのは、1つを探す語で、ただ1件の正しい文書が A と B で同じ順位に出た場合が多いためだった

### 200語の一覧を1,000回引き直す（`results/query_sets.csv`）
| | A が上と見分けた | 偶然の幅の中 | B が上と見分けた | 差の平均の5〜95%の範囲 |
|---|---|---|---|---|
| ①1件目の点 | **48.5%** | 51.5% | 0% | +0.98〜+10.0 |
| ②10件の点 | **99.5%** | 0.5% | 0% | +4.4〜+9.64 |

- **同じ A・B を同じ200語で比べても、①で A が上と見分けられたのは48.5%の回だけだった**。②では99.5%の回で見分けられた
- 一覧の1回分（`data/queries_200.csv`）では、①の差は+2.5ポイント（A 74.0%・B 71.5%）、②の差は+6.66ポイント（A 69.7%・B 63.04%）だった

### 1つを探す語の割合を変える（`results/by_mix.csv`、各2万語）
| 1つを探す語の割合 | ①の差 | ②の差 | ①で同じだった語 |
|---|---|---|---|
| 0% | **−2.7** | **+2.03** | 90.96% |
| 10% | −0.54 | +3.51 | 88.74% |
| 20% | +1.2 | +4.57 | 87.34% |
| 40% | +4.91 | +6.73 | 83.94% |
| 60% | +10.17 | +10.02 | 79.83% |
| 100% | +17.76 | +14.57 | 72.95% |

- **1つを探す語が0%と10%のとき、①では B が上、②では A が上と向きが入れかわった**。10%のときの①の−0.54ポイントは、標準誤差0.24ポイントの2倍ほどで、偶然とはっきり分けられる大きさではない
- 差のポイントは、1つを探す語が50%以下では②が大きく、60%で並び、それより多いと①が大きかった。差÷標準偏差は、11の割合すべてで②のほうが大きかった
- ①で A と B が同じだった語は、どの割合でも72.95〜90.96%あった

### 確かめ：27通り（`results/grid.csv`）
- ①で A と B が同じだった語は75.33〜90.65%、②では5.03〜36.7%だった
- **2つの点で良い方が入れかわったのは27通りのうち5通り**（4通りは1つを探す語10%、1通りは40%）。ただし、①の差が標準誤差の2倍を超えていたのは2通りで、残り3通りの①の差（−0.27〜−0.44ポイント）は偶然の幅の中だった
- 向きがそろった22通りのうち、差÷標準偏差が②のほうが大きかったのは20通り（②÷①で0.3477〜7.1857倍）。①のほうが大きかった2通りは、A の上乗せが小さく（2.9）、1つを探す語10%で、B が上の置き方だった

## 注意（言えないこと）
- 架空のデータと、作成者が置いた架空の検索です。正しさの段階、正しい文書の数、上乗せの大きさ、乱数の散らばりは作成者が置いたもので、差の大きさも向きもこれで決まります。どちらの点がよいかを決めるものではありません
- 正しさは、作成者がすべての候補の文書について間違いなく決めたと置きました。判定していない文書、判定する人の間のずれは入れていません
- ①は「正しさ1以上」を正しいとしました。「正しさ2だけを正しい」とすると、①の差の向きは変わりえます
- ②の重み（1÷log2(r+1)）と、正しさの段階をそのまま点にする数え方は、置き方の1つです。重みや段階の点を変えれば、②の差も変わります
- 偶然の幅は、語ごとの差の散らばりから出した近似です。検索語は2万語の中からでたらめに選ばれると置きました
