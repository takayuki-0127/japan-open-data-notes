# 1134 1台の画面で合わせた色は、色の出方の違う別の画面でどれだけずれるのか？（画像と色）

商品の写真の色を、手元の画面で見ながら「正しく見える」まで直して保存することがあります。けれども、画面は1台ごとに色の出方（明るさの曲がり方・強さ・3色のまざり方）が少しずつ違います。手元の画面Aで合わせたファイルには、画面Aのくせを打ち消す直しが入るので、くせの違う別の画面Bで見ると、Bのくせに加えてAのくせの裏返しも乗ります。**ここでは、作成者が置いた架空の色の板24枚（灰色6・淡い色9・あざやかな色9）と、色の出方を乱数で置いた架空の画面の組4,000組で、①直さないファイルを画面Bで見たとき、②画面Aで合わせたファイルを画面Aで見たとき、③同じファイルを画面Bで見たとき、の色の差を数えました。画面Aが基準からどれだけ離れているかを変えたときと、画面のくせの大きさを変えた27通りでも確かめました。**

例の板・画面は、すべて作成者が式と乱数で置いたもので、実在の写真・商品・画面を表すものではありません。色の差は、作成者が置いた見え方の式（色を明るさ0〜100と2つの色みの軸に直した距離）で数えたもので、人に見てもらって確かめたものではありません。人の色の見え方を、人の属性で比べたものでもありません。

関連する記事：同じ企画の 1132「背景の色と照明が違うと、同じ商品の写真の色の数値はどれだけ動くのか？」は、写す側（背景・照明・カメラの合わせ方）で写真の色の値が動くことを扱っています。この記事は、写真の色の値は同じまま、見る側の画面の違いで見え方がどれだけずれるかに絞ります。1129「明るさの差を数値のまま測ると、人が見て感じる差とどこでずれるのか？」は、この記事と同じように、作成者が置いた見え方の式を物差しにしています。40冊目の 1061「同じ設定のつもりの2台で、速さはどれだけ違うのか？」は、同じつもりの2台の違いが比べたい差にまざることを、処理の速さで扱っています。20冊目の 821「色の順番と強さで、どの数字が目立つかは変わるのか？」は、グラフの色を見た明るさに直して数えています。

## 主な結果

### 画面の組4,000組（基本、`results/a1134_main.json`・`results/by_kind.csv`）
| 板 | ①直さないファイルを画面Bで | ②Aで合わせてAで | ③Aで合わせてBで | ③で差が5を超えた板の割合 |
|---|---|---|---|---|
| 灰色（6枚） | 4.46 | 0.01 | 5.79 | 54.09% |
| 淡い色（9枚） | 4.61 | 0 | 6.45 | 62.54% |
| あざやかな色（9枚） | 6.53 | 2.06 | 8.32 | 73.04% |
| 全部（24枚） | **5.29** | 0.78 | **6.99** | 64.37% |

- **画面Aで合わせたファイルを画面Bで見ると、色の差の平均は6.99で、直さないファイル（5.29）の1.321倍だった**。組ごとに見ると、80.08%の組で、合わせたファイルのほうが画面Bではかえってずれた
- 差が5を超えた板は、直さないときの44.08%から64.37%に増えた。「ほぼ同じ」（差2以下）の板は、8.52%から4.28%に減った
- 画面Aの上では、合わせたファイルの差は0.78で、88.02%の板が「ほぼ同じ」だった。残った差は、画面Aで出せないあざやかな色（Aの3色の強さが足りない・まざり方で届かない色）が端で止まった分で、灰色・淡い色はほぼ0だった
- 2台のくせが小さく、同じように散らばって独立なら、Aで合わせたファイルをBで見た差は「Bのくせ−Aのくせ」になり、直さないときの√2倍（1.414倍）が式の目安になる。数えた1.321倍はこれより少し小さかった（Aで出せない色を端で止めたことと、くせが色の値に対して曲がった形で効くことによる、と見ている。推測）
- 例の1組（`data/example_pair.csv`）では、直さないファイルをBで見た差4.13、Aで合わせてAで1.45、Aで合わせてBで6.56だった

### 画面Aが基準からどれだけ離れているか（`results/by_a_closeness.csv`、各4,000組）
| 画面Aの離れ方（Bを1とした倍率） | 0（基準どおりの画面） | 0.25 | 0.5 | 1 | 1.5 | 2 |
|---|---|---|---|---|---|---|
| ②Aで合わせてAで | 0 | 0.12 | 0.31 | 0.78 | 1.32 | 1.88 |
| ③Aで合わせてBで | 5.34 | 5.45 | 5.8 | 7.06 | 8.7 | 10.53 |
| ③÷①（①は5.34） | 1 | 1.019 | 1.086 | 1.321 | 1.629 | 1.972 |
| かえってずれた組 | 0% | 56.4% | 64.95% | 79.85% | 88.38% | 93.97% |

- **画面Aが基準どおりなら、合わせたファイルは直さないファイルと同じで、Bでの差も同じだった（作りどおり）**。Aが基準から離れるほど、Bでの差は大きくなった
- Aの離れ方がBの半分（0.5）でも、Bでの差は1.086倍になり、64.95%の組でかえってずれた
- 基本の4,000組を、Aで直さないときの差（Aのくせの大きさ）で4つに分けると、③は小さい側から6.03・6.4・6.96・8.57、かえってずれた組は75.4%・76.1%・81.7%・87.1%だった（`results/by_a_offset_quarter.csv`）

### 確かめ：置き方を変えると（27通り、各1,500組、`results/grid.csv`）
| | 27通りの結果 |
|---|---|
| ①直さないファイルを画面Bで | 2.87〜10.58 |
| ③Aで合わせてBで | 3.68〜14.03 |
| ③÷① | **1.282〜1.394倍** |
| かえってずれた組 | 75.07〜81.2% |
| ②Aで合わせてAで | 0.48〜1.5 |

- 差の大きさは画面のくせの大きさでほぼ決まり、27通りで2.87〜14.03と大きく動いた。けれども、③÷①は1.282〜1.394倍とほとんど動かず、かえってずれた組も75.07〜81.2%に収まった
- 27通りすべてで、③の差はあざやかな色のほうが灰色より大きかった

## 動かし方
```
pip install -r requirements.txt
cd src && python a1134_other_screen.py
```
10秒ほどで終わります。`data/patches.csv`・`data/example_pair.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の10ファイルがバイト単位で一致した（cmp、約7秒）
- 画面Aを基準どおり（離れ方0）にすると、合わせたファイルが直さないファイルと同じになり、①と③が同じ（5.34）になることを確かめた
- 図3枚を開き、日本語・重なり・軸（棒は0から）を確かめた

## データ
- `data/patches.csv`：色の板24枚（patch・kind（灰色・淡い色・あざやかな色）・r・g・b（色の値0〜1））
- `data/example_pair.csv`：例の1組での、画面Aで合わせた色の値（corrected_r・g・b）と、板ごとの色の差（diff_plain_on_b・diff_corr_on_a・diff_corr_on_b）
- `results/a1134_main.json`：主な結果すべて
- `results/by_kind.csv`：板の種類ごとの色の差
- `results/by_a_closeness.csv`：画面Aの離れ方を変えたとき
- `results/by_a_offset_quarter.csv`：Aのくせの大きさで4つに分けたとき
- `results/grid.csv`：27通りの確かめ（curve_x・gain_x・mix_x は、明るさの曲がり方・強さ・まざり方のずれの倍率）

## 注意（言えないこと）
- 架空のデータです。画面のくせの種類と大きさ、色の板、見え方の式、「ほぼ同じ」「並べると分かる」の目安は作成者が置いたもので、差の大きさはこれで決まります（27通りで2.87〜14.03）。③÷①が1.3倍前後になることは、2台が同じように散らばる置き方から来ています
- 画面Aは「基準どおりの画面」より離れているほど、Bでずれました。手元の画面が基準にどれだけ近いかは、この記事の置き方では作成者が決めています
- 画面の色の出方を基準に合わせる道具や、ファイルに画面の色の出方を書きこむ仕組みは数えていません。直すのはファイルの色の値だけと置きました
- 部屋の明るさ・画面を見る角度・人の目の慣れは入れていません
- 実在の画面の色の出方の違いを表すものではなく、どう合わせるべきかも言えません。この記事は、1台で合わせたファイルが別の画面でどれだけずれるかを数えただけです
