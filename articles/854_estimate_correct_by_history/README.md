# 854 過去の実績で見積もりを直すと、外れはどれだけ減るのか？（見積もりと締め切り）

見積もりには、いつも短めに見る・長めに見るといった人やチームごとの癖があります。過去の「実際にかかった日数÷見積もりの日数」をためておき、その倍率で新しい見積もりを直すと、癖の分の外れは減らせます。ただし、1件ごとの偶然のぶれは、過去の実績では直せません。**ここでは、作成者が置いた架空のチーム2,000組（チームごとに見積もりの癖を置いたもの）で、見積もりそのまま・全チーム共通の倍率・自分の過去の実績の倍率の3つで新しい1件を計画し、外れの大きさがどれだけ減るか、どこで下げ止まるかを数えました。**

## 主な結果

### 外れの大きさ（「実際÷計画−1」の絶対値の中央値、20回の平均）
| 過去の件数 | 見積もりそのまま | 全チーム共通の倍率 | 自分の過去の平均の倍率 |
|---|---|---|---|
| 1件 | 41.1% | 25.0% | 32.7% |
| 3件 | 41.2% | 25.1% | 26.7% |
| 5件 | 41.2% | 25.4% | 25.5% |
| 10件 | 41.9% | 25.4% | **24.5%** |
| 30件 | 41.6% | 25.2% | 23.5% |
| 1件ごとのぶれだけで残る外れ（下限） | | | **23.3%** |

- 自分の過去10件の倍率で直すと、外れの中央値は41.9%から24.5%に減った。それでも、癖が完全に分かっても残る1件ごとのぶれの分（23.3%）より下には下がらなかった
- 過去が1件だけだと、自分の倍率はその1件の偶然に引っぱられ、全チーム共通の倍率（25.0%）より外れが大きかった（32.7%）。自分の倍率のほうが共通の倍率より外れが小さくなったのは、10件以上ためたときだった
- 計画が実際の±20%に収まった割合は、見積もりそのままで27.2%、自分の過去10件で直すと41.6%（下限43.7%）

### 予定内に終わった割合（過去10件）
| 計画の立て方 | 予定内に終わった割合 |
|---|---|
| 見積もりそのまま | 18.9% |
| 自分の過去の平均の倍率 | 49.5% |
| 自分の過去の8割の点の倍率 | 74.8% |

- 平均の倍率で直すと、予定内に終わるのはほぼ半分になった。平均で直した計画は「半分は遅れる」計画になる。8割の点で直すと74.8%（過去5件で71.1%、30件で78.0%）で、8割に届かなかったのは、過去の件数が限られていて8割の点そのものがぶれるためと見ている（推測。件数が増えるほど8割に近づいた）

### 確かめ：置き方を変えると（過去10件）
| ぶれ | 仕事の種類のずれ | 見積もりそのまま | 自分の過去の平均の倍率 |
|---|---|---|---|
| 0.2 | 0 | 40.2% | 14.2% |
| 0.35 | 0 | 41.9% | 24.5% |
| 0.5 | 0 | 46.1% | 34.1% |
| 0.35 | 0.1 | 42.1% | 25.2% |
| 0.35 | 0.2 | 42.6% | 27.5% |
| 0.35 | 0.3 | 45.1% | 31.3% |

- どの置き方でも、過去の実績で直すと外れは減った。ただし減ったあとの外れは、1件ごとのぶれの大きさでほぼ決まった（ぶれ0.2で14.2%、0.5で34.1%）
- 新しい仕事の癖が過去とずれるほど、直したあとの外れは大きくなった（ずれ0.3で31.3%）。ずれ0.3では、自分の倍率（31.3%）と全チーム共通の倍率（32.1%）の差もほぼなくなった
- チームどうしの癖の違いをなくすと、全チーム共通の倍率（23.5%）のほうが自分の倍率（24.5%）より当たった。癖そのものをなくす（中央値1.0倍）と、見積もりそのままでも25.4%で、直しても24.5%とほとんど変わらなかった。**外れがどれだけ減るかは、作成者の置いた癖の大きさ（1.4倍）とぶれの大きさ（0.35）で決まる**

## 注意（言えないこと）
- 架空のデータです。癖の大きさ（中央値1.4倍）、チームどうしの違い（0.15）、1件ごとのぶれ（0.35）は作成者が置いたもので、外れがどれだけ減るかはこれで決まります。実際の見積もりの癖がどれくらいかは、ここからは言えません
- 癖は時間がたっても変わらないと置きました（仕事の種類のずれだけを確かめに入れた）。見積もる人が実績を見て癖を直していく効果は入れていません
- 過去の実績は、途中でやめた仕事や記録しなかった仕事も含めて、全部そろっていると置きました。記録が偏ると、倍率も偏ります（推測）
- 見積もりの幅（最短〜最長）を書いたときの外れ方と、幅の広さを実績で直すことは関連する記事 859、見積もりに使う1つの数（山の位置・半々・平均）の選び方は関連する記事 850 で扱っています。この記事は、見積もりの中心のずれ（癖）を実績の倍率で直すことだけを扱います
