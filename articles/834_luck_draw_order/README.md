# 834 くじは、先に引くのと後に引くのでどちらが有利か？（運と実力）

当たりの入ったくじを順番に引くとき、「先に引けば当たりが残っている」「後に引けば外れが減っている」と、どちらにも有利に見えます。**ここでは、作成者が乱数で作った架空のくじ（箱の中に10本、当たり1本など）を、引いたくじを戻さずに全員が順番に引く場面を10万回繰り返し、引く順番ごとの当たりの割合を数えました。あわせて、前の人の結果が見えるとき、当たりの札だけ取りやすい（取りにくい）とき、少ない回数の記録で順番を比べたときに、順番の有利不利がどう見えるかを数えました。**

|---|---|---|---|
| A834 | よく混ぜたくじを順番に引くとき、何番目に引くと有利か。混ぜ方や記録の回数で、見え方はどう変わるか | 架空のくじ。基本は箱の中に10本・当たり1本を10人が1本ずつ順に引き、引いたくじは戻さない。ほかに30本・当たり3本（30人）、100本・当たり5本（100人）も数えた。それぞれ10万回。前の人の結果が見えるときは、前の人が全員外れた回だけを取り出して数えた。確かめとして、当たりの札だけ取りやすさを0.5・1.5・2・3倍にした（取りやすさに比例した確率で、残りのくじから1本ずつ引く。1倍がよく混ぜたくじ）。少ない回数の記録は、よく混ぜた10本1当たりのくじを30・100・1,000回だけ引いた記録を、それぞれ2,000通り作って数えた。seed 834 | `src/a834_draw_order.py` |

## 主な結果

### よく混ぜたくじ：引く順番ごとの当たりの割合（10万回）
| くじ | 本当の当たりの割合 | 順番ごとの当たりの割合（いちばん低い〜いちばん高い） |
|---|---|---|
| 10本・当たり1本（10人） | 10% | 9.83%〜10.26% |
| 30本・当たり3本（30人） | 10% | 9.75%〜10.13% |
| 100本・当たり5本（100人） | 5% | 4.83%〜5.18% |

- **よく混ぜたくじなら、何番目に引いても当たりの割合は同じ（10本1当たりなら10%）だった**。順番ごとの違いは、10万回でも残る乱数の揺れの大きさだった

### 前の人の結果が見えるとき（10本・当たり1本）
| 引く順番 | 前の人が全員外れる割合 | 全員外れたと分かったときの当たり | 結果を知らないときの当たり |
|---|---|---|---|
| 1番目 | 100% | 9.9% | 9.9% |
| 5番目 | 60.2% | 17.0%（式では16.7%） | 10.3% |
| 9番目 | 19.9% | 49.9%（式では50%） | 9.95% |
| 10番目 | 10.0% | 100% | 10.0% |

- 「前の人が全員外れたのを見た」あとなら、後の人ほど当たりやすい。ただし、そこまで当たりが残っている回自体が少ない（10番目まで残るのは10.0%）。引く前に順番を選ぶ時点では、どの順番も10%だった

### 確かめ：当たりの札だけ取りやすい（取りにくい）とき（10本・当たり1本、10万回）
| 当たりの札の取りやすさ | 1番目の当たり | 10番目の当たり | 前半5人の誰かが当たる割合 |
|---|---|---|---|
| 0.5倍（取りにくい） | 5.2% | 28.3% | 30.2% |
| 1倍（よく混ぜたくじ） | 10.0% | 10.0% | 49.8% |
| 1.5倍 | 14.3% | 4.0% | 63.6% |
| 2倍 | 18.3% | 1.8% | 72.4% |
| 3倍 | 25.0% | 0.4% | 83.9% |

- **順番で差が出るのは、当たりの札だけ取りやすさが違うとき（大きさ・手触り・置き場所など）だった**。取りやすければ先が有利、取りにくければ後が有利に、向きごと入れ替わった

### 少ない回数の記録で見た「当たる順番」（よく混ぜた10本1当たり、各2,000通り）
| 記録の回数 | いちばん当たった順番の当たりの割合（平均） | どこかの順番が20%以上当たって見えた記録の割合 | 1回も当たらなかった順番がある記録の割合 |
|---|---|---|---|
| 30回 | 19.7% | **61.2%** | 37.3% |
| 100回 | 15.1% | 2.1% | 0% |
| 1,000回 | 11.6% | 0% | 0% |

- 30回だけの記録では、6割の記録で、どこかの順番が本当の2倍（20%）以上当たっているように見えた。1回分の30回の記録（`data/record_30.csv`）では、2番目が6回当たり、3番目と4番目は1回ずつだった

## 動かし方
```
pip install -r requirements.txt
cd src && python a834_draw_order.py
```
数秒で終わります。`data/record_30.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約3秒）
- 前の人が全員外れたときの当たりは、乱数で数えた値と式（1 ÷ 残りの本数）がほぼ一致した（上の表）
- くじの本数と当たりの本数を3通りに変えても、よく混ぜたくじなら順番による差は出なかった
- 当たりの札の取りやすさを0.5〜3倍に変えると、有利な順番の向きと大きさがそのまま変わった（上の表）

## データ
- `data/record_30.csv`：よく混ぜた10本1当たりのくじを30回引いた記録（round・pos1〜pos10（その順番の人が当たったら1））

## 注意（言えないこと）
- 架空のくじです。「よく混ぜたくじ」は、残ったくじのどれを引くかがまったくでたらめに決まる、と置いたものです。実際のくじがそうなっているかは、ここでは何も言えません
- 当たりの札の取りやすさ（0.5〜3倍）は作成者が置いた数です。順番の有利不利の大きさは、この置き方でそのまま決まります
- 引いたくじを戻すくじ（毎回まっさらな箱から引く）は、そもそも前の人の結果に左右されないので、ここでは数えていません
- 当たりが出たらそこで終わるくじ（全員が引かない）も、順番ごとの当たりの割合は同じになりますが、ここでは全員が引く形だけを数えました
- 少ない回数の記録で「当たる順番」があるように見えるのは、偶然の揺れです。ほかの記事（関連する記事 833 など）の「件数の少なさ」と同じ仕組みです
- 1人が何回引けば当たるか（毎回1%のくじと、箱から戻さずに引くくじの違い）は、関連する記事 828 で扱っています
