# 1225 結果が0件の検索を数から外すと、検索の良さはどう見えるのか？（検索の良さ）

検索の良さを「上位10件に正しい文書が1件以上あった語の割合」（見つかった割合）で数えるとき、結果が0件だった語をどう扱うかを決める必要があります。0件の語は「上位10件」がないので、数から外してしまうことがあります。ところが、0件を減らすように検索を直すと、新しく結果が出た語はもともと見つけにくい語なので、外す数え方では割合が下がって見えます。また、0件の語の中には、集まりの中にそもそも正しい文書がない語もあり、その語では0件は間違いではありません。**ここでは、作成者が置いた架空の社内の文書の集まりと、1か月に出た架空の検索語2,000語（語ごとのむずかしさ・正しい文書があるかを作成者が置き、0件になるか・見つかるかを乱数で決めたもの）で、語をすべて含む文書だけを出す検索Aと、語の一部が合えば出す検索Bを、①0件の語を外す、②0件の語を0点にする、③正しい文書がある語だけを数え0件は0点にする、の3つの数え方で比べました。0件の多さ・拾った語の見つかりやすさ・B の割りこみ・正しい文書がない語の割合の81通りでも確かめました。**

例の文書・検索語・検索は作成者が置いたもので、実在の検索サービスや社内の仕組みを表すものではありません。

A が0件だった語ほどむずかしく、B で新しく結果が出ても見つかりにくいのは、むずかしさを0件の確率にも見つかる確率にも効くよう置いたためです（作りどおり）。見つかりにくい語が分母に加われば①の割合が下がるのは、平均の式どおりです。この記事で数えて新しく分かったのは、3つの数え方で A と B の差がどれだけ違うか、0件の語のうち正しい文書がない語がどれだけあるか、置き方を変えると②・③の向きがどう動くか、です。

関連する記事：1221「上位10件の正しい割合で比べるか、正しい文書を拾えた割合で比べるかで、良い方の検索は入れかわるのか？」は、語ごとの割合の分母（10か、正しい文書の数か）の違いを扱っています。この記事は、0件の語を数に入れるかどうかという、語の側の分母に絞ります。1224「1件目に正しい文書があるかだけを数える点と、10件全体を順位で重み付けする点では、2つの検索の差がどう違って見えるのか？」は、語ごとの点の付け方の違いを扱っています。1231「言いかえて検索し直す人が減ったのは、見つかったからか、あきらめたからか？」は、検索し直しの減りを、見つかった人とあきらめた人に分けています。この記事では、0件のあとに言いかえる人・あきらめる人は入れていません。

## 主な結果

### 1か月分（2,000語）の3つの数え方（`results/a1225_main.json` の one_month）
| | A（語をすべて含む） | B（語の一部が合えば） | 差（B−A） |
|---|---|---|---|
| 0件だった語 | 23.05% | 1.25% | |
| ①0件の語を外す | **81.22%** | 65.47% | **−15.75** |
| ②0件の語を0点 | 62.5% | 64.65% | **+2.15** |
| ③正しい文書がある語だけ（0件は0点） | 67.97% | 70.31% | +2.34 |

（差はポイント）

- **①では A が15.75ポイント上、②・③では B が2.15・2.34ポイント上と、向きが逆になった**
- 2,000語を500回引き直すと、差の5〜95%の範囲は①−15.7〜−13.18、②+1.8〜+3.95、③+1.96〜+4.3で、①で A が上・②で B が上だった回はどちらも100%だった。A の0件の語の割合は21.1〜24.2%だった

### B の語の内訳（`results/a1225_main.json` の b_groups）
| | 語に占める割合 | B で見つかった割合 | むずかしさの平均 |
|---|---|---|---|
| A も結果を出した語 | 76.95% | 78.04% | −0.29 |
| A は0件、B は出した語 | 21.8% | **21.1%** | 0.82 |
| B でも0件の語 | 1.25% | 0% | 1.15 |

- **B が新しく結果を出した語で見つかったのは21.1%で、A が結果を出していた語（A で81.22%）よりずっと低かった**。①で B が下がって見えたのは、この見つかりにくい語が分母に加わったためと、A が結果を出した語の一部で割りこみが起きたため（78.04%）だった

### 0件の語の中身（`results/a1225_main.json` の zero_a_detail）
- A で0件だった461語のうち、**22.56%は集まりの中に正しい文書がない語だった**（全体では8.05%）。この語では0件は間違いではないが、②では0点に数えられる
- 正しい文書がない語で何かを出したのは、A で35.4%、B で96.27%だった。①・②・③のどれでも、この「正しくない文書を見せた」ことは減点にならない

### 確かめ：81通り（`results/grid.csv`、各2万語）
- **①で A が上だったのは81通りすべて**（差−27.28〜−2.67ポイント）。B が新しく結果を出した語の見つかった割合は5.44〜69.12%で、どの置き方でも A が結果を出した語の割合（73.38〜86.54%）より低かった
- ②で B が上だったのは62通り、③で B が上だったのは63通り（②の差−4.56〜+22.01ポイント）
- ②で B が上だった62通りは、どれも①では A が上だった
- 割りこみ0%では②で B が上は27通りすべて（B は A が見つけた語をすべて見つけるので作りどおり）、4%では20通り、8%では15通りだった。②で A が上だったのは18通り（1通りは差0）で、そのうち15通りは A の0件が少ない置き方（境目1.6、0件10.14〜20.77%）、3通りは境目1.1（0件18.96〜27.91%）だった。0件の多い置き方（境目0.55、0件32.92〜39.01%）では0通りだった
- A の0件の語のうち正しい文書がない語の割合は、正しい文書がない語が8%・20%の置き方で12.98〜60.12%だった

## 注意（言えないこと）
- 架空のデータと、作成者が置いた架空の検索です。むずかしさが0件の確率と見つかる確率の両方に効くこと、割りこみの割合、正しい文書がない語の割合は作成者が置いたもので、差の大きさと向きはこれで決まります。①で81通りすべて A が上だったのも、新しく結果が出た語ほど見つかりにくいと置いたためです
- 検索語は1語1回と置きました。よく出る語ほど重く数える場合、言いかえて検索し直す人、0件のあとにあきらめた人は入れていません
- 正しい文書がない語で「何かを出した」ことの良し悪しは、どの数え方にも入れていません
- どの数え方がよいか、どちらの検索がよいかを決めるものではありません
