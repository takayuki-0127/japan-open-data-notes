# 826 前半の打率トップは、後半もトップなのか？（運と実力）

シーズンの前半で打率トップの打者は、後半になると打率を落とすことがよくあります。「研究された」「打ち方が崩れた」と説明されがちですが、前半の打率には実力と偶然の両方が入っていて、トップに立つ打者は偶然が上に振れた分も持っています。後半はその偶然が引き継がれないので、打率は平均の側へ戻ります（平均への回帰）。**ここでは、作成者が乱数で作った架空のリーグ（打者60人、本当の打率を作成者が置いたもの）を1万回作り、前半の打率トップが後半もトップだった割合と、前半の上位の打率が後半どこまで戻るかを数えました。**

|---|---|---|---|
| A826 | 前半の打率トップは、後半もトップか。前半の上位の打率は、後半どこまで戻るか | 架空のリーグ。打者60人。本当の打率は平均0.265・標準偏差0.020の正規分布（0.18〜0.35の外は引き直す）。前半・後半とも、全員が250打数。1打数ごとに本当の打率の確率でヒットになり、打数どうしは互いに影響しないと置く（本当の打率は前半と後半で変わらない）。リーグを1万回作った。順位は打率の高い順で、同じ打率はでたらめに並べた。前半の打率から後半の打率への傾きは、リーグごとの平均を引いてから求めた（1なら前半の差がそのまま残り、0なら全部消える）。理屈の傾きは「本当の打率の差の分散 ÷（その分散＋偶然の振れの分散）」（偶然の振れの分散は 0.265×0.735÷250）。比べるために、本当の打率の差をなくした（全員0.265）リーグも1万回作った。確かめとして、本当の打率の標準偏差0.010・0.020・0.030 × 打数100・250・500（各1万回）、打者の人数12・30・60・120人（各1万回）を数えた。seed 826 | `src/a826_first_half_top.py` |

関連する記事：830「2年目のジンクスは、偶然だけで起きるのか？」は、1位の成績が次にどれだけ下がるかと、それを前もって見込む方法を扱います。831「営業成績の月間1位は、何か月続くのか？」は、12回の区切りで1位が何人に分かれるかを扱います。833「少ない打席の『最高打率』は、件数の少なさで決まるのか？」は、打数が人によって違う場合を扱います。この記事は、全員が同じ打数の2つの区切り（前半・後半）で、トップの順位がどれだけ残るかに絞ります。

## 主な結果

### 前半の打率トップは、後半どうなったか（打者60人・各250打数・1万リーグ）
| | 値 |
|---|---|
| 後半もトップだった割合 | **7.5%** |
| 後半も3位以内 | 18.2% |
| 後半も10位以内 | 42.3% |
| 後半の順位（中央値） | 14位 |
| 前半トップが、本当の打率でもトップだった割合 | 16.6% |
| 前半トップが、本当の打率で10位以内だった割合 | 67.4% |
| （比べる用）本当の打率に差がないときに、後半もトップだった割合 | 1.7% |

- 前半トップが後半もトップだったのは7.5%だった。打者に実力の差がまったくないとき（1.7%、60人から1人をでたらめに選ぶのと同じ）よりは高いが、多くの場合トップは入れ替わった

### 前半の打率と後半の打率（1万リーグの平均）
| | 前半の打率 | 本当の打率 | 後半の打率 |
|---|---|---|---|
| 前半トップの打者 | 0.347 | 0.292 | 0.292 |
| 前半の上位10人 | 0.316 | 0.282 | 0.282 |
| 前半の下位10人 | 0.215 | 0.248 | 0.248 |
| リーグ全体 | 0.265 | | |

- 前半トップの打率は、後半0.347→0.292に下がった。後半の打率は本当の打率とほぼ同じで、前半の上振れの分がそのまま消えた
- 前半の上位10人は、リーグ平均を上回っていた分のうち66.6%を後半に失った。前半の上位10人のうち、後半も10位以内だったのは31.2%
- 前半の下位10人は、0.215→0.248に上がった。何も変えていないのに「立ち直った」ように見える
- 前半から後半への傾きは0.339で、理屈の値（0.339）と合った。この置き方では、前半の打率の差のうち約3分の1だけが後半に残る

### 1回分のリーグ（`data/`、1万リーグの1回目）
- 前半の打率トップは0.344で2人が並び、表の順で先の打者（batter_id 26）を前半トップとした。この打者の後半の打率は0.272で27位、本当の打率は0.2667で60人中32位だった

- 置き方で、前半トップが後半もトップの割合は2.4〜20.0%、上位10人が失う上振れの割合は31.7〜95.1%まで動いた。打数が多く、打者どうしの差が大きいほど、前半の順位は後半に残った
- どの置き方でも、前半トップの多くは後半にトップから落ち、前半の上位の打率は後半に下がった

## 注意（言えないこと）
- 架空のリーグです。本当の打率の散らばり、打数、打者の人数は作成者が置いたもので、結果はこれで決まります。置き方で、前半トップが後半もトップの割合は2.4〜20.0%まで動きました
- 本当の打率は前半と後半で変わらないと置きました。相手の対策・打ち方の変更など、本当の打率そのものが変わることは入れていません。実際の後半の落ち込みに、偶然の戻りと本当の変化がどれだけ混ざっているかは、この分析では分けられません
- 1打数ごとのヒットは互いに影響しないと置きました。調子の波（当たりが続く・止まる）は入れていません
- 実在の選手・リーグの成績を表すものではありません
