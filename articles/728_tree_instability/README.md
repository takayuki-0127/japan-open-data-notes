# 728 決定木を学習データを少し入れ替えて作り直すと、最初の分かれ目の変数は何%で入れ替わるのか（手法の解説・正解の分かるデータで試す）

決定木は、「最初にどの変数で分けるか」が読みやすく、説明に使われます。ところが、よく似た（相関の強い）変数が2つあると、学習データが少し変わるだけで、最初の分かれ目がもう一方の変数に入れ替わります。**ここでは、効き方の分かる架空の来店客500人の購入額で、深さ4の決定木を作り、500人のうち50人（10%）を新しい人に入れ替えて作り直すことを300回くり返し、最初の分かれ目が入れ替わる割合と、予測の変わり方を数えました。** ランダムフォレスト（木100本）とも比べています。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A728 | 学習データの10%を入れ替えると、決定木の最初の分かれ目は何%で変わるか | 架空の500人。購入額（千円）＝2.0×x1＋1.6×x2＋0.8×x3＋ノイズ（標準偏差2）、x1 と x2 の相関0.8、x4〜x6 は効かない。深さ4の回帰の決定木、50人を入れ替えて300回。ランダムフォレスト（100本、葉に5人以上）は50回。テスト用に別の1,000人。seed 728 | `src/a728_tree.py` |

## 主な結果
| 項目 | 結果 |
|---|---|
| もとの木の最初の分かれ目 | x1（2段目までは x1 と x2） |
| 10%入れ替えて最初の分かれ目が x1 のまま | 81.0%（x2 に変わった：**19.0%**） |
| 2段目までの変数の組が同じ | 77.0% |
| テストの1,000人への予測の、もとのモデルとの平均の差 | 決定木 0.67千円、ランダムフォレスト **0.32千円** |
| テストの誤差（RMSE） | 決定木 2.36千円、ランダムフォレスト 2.12千円 |

- 500人のうち50人を入れ替えるだけで、5回に1回は最初の分かれ目が x1 から x2 に変わった。x3〜x6 が選ばれることはなかった
- 最初の分かれ目が同じでも予測は平均0.65千円、入れ替わると0.74千円、もとの木から動いた
- 木を100本平均するランダムフォレストは、入れ替えによる予測の変わり方が決定木の半分以下で、テストの誤差も小さかった


## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- 最初の分かれ目に選ばれたのが、効く変数の x1・x2 だけであること

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 728）

## 注意（言えないこと）
- 架空のデータです。変数の効き方と相関、ノイズは作成者が置いたもので、入れ替わる割合はこれで決まります。x1 と x2 の効きがもっと近ければ、入れ替わりはもっと多くなります
- 「最初の分かれ目の変数がいちばん大事」とは言えません。似た変数が2つあると、どちらが選ばれるかはデータ次第です
- 決定木の深さやランダムフォレストの設定は作成者が決めたもので、調整していません
