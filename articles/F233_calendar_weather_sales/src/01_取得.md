# 01 取得

新しい取得はしていません。F135（雨の日と小売の売上）で取得・整形したデータを使います。

- `data/raw/f135_retail_monthly.csv`：F135 の `data/retail_monthly.csv`（経済産業省「商業動態統計」時系列データを整形したもの）
  - https://github.com/takayuki-0127/japan-open-data-notes/tree/main/articles/F135_rain_retail
- `data/raw/f135_weather_monthly.csv`：F135 の `data/weather_monthly.csv`（気象庁「過去の気象データ検索」日別値から作った9地点の月の値）
- 祝日：Python の `jpholiday`（内閣府「国民の祝日」に基づく。振替休日・国民の休日を含む）で作成

元の取得手順は F135 の `src/01_取得.md` にあります。
