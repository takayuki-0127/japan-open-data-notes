# F233 祝日・連休・天気は、売上をどれだけ動かすのか？

経済産業省「商業動態統計」の業態別の月次販売額を使い、前年同月比の揺れを「カレンダー（曜日・祝日・連休・うるう年）」「天気（気温・雨の日数）」「消費税の駆け込みと反動」に分けました。販促や施策の効果を前年同月比で見る前に、どれだけを差し引いておくべきかを示すのが目的です。

シリーズ「② 実務に近い分析（F231〜F245）」の1本です。分析は Python、同じ計算を SQL（SQL Server 版と、動作確認用の DuckDB 版）でも書き、HTML 1枚のダッシュボードを作りました。数字はすべて公開データで、企業の実データは使っていません。

## この記事で分かること
- 平日1日が土曜・日曜に入れ替わると、前年同月比はスーパーで +0.8・+1.2 ポイント、ホームセンターで +1.3・+1.2、家電大型専門店で +2.2・+3.2 動いた。コンビニは +0.4 前後と小さかった。
- うるう年の2月は、1日多いだけで前年同月比が +3.0〜+4.5 ポイント（スーパー +3.6）。その翌年の2月は同じだけ下がる。
- 消費税の前後の月を除いた「ふだんの月」で、前年同月比の揺れのうちカレンダーと天気で説明できたのは、スーパー37%、ホームセンター46%、百貨店13%。
- スーパーでは36%の月で、カレンダーだけで前年同月比が1ポイント以上動いていた（ホームセンター62%、家電大型専門店67%、コンビニ6%）。
- 2013〜2019年だけで推定した係数で2023年6月〜2026年8月を補正すると、前年同月比の揺れ（標準偏差）はスーパーで23%、ホームセンターで21%減った。百貨店・家電大型専門店・ドラッグストアはほとんど減らなかった（ドラッグストアはかえって11%増えた）。

## 問い
- 祝日・連休・曜日の巡り・うるう年・気温・雨は、月の前年同月比をそれぞれ何ポイント動かすのか。
- 前年同月比の揺れのうち、どれだけがカレンダーと天気で説明できるのか。業態でどう違うのか。
- その補正は、推定に使っていない期間でも役に立つのか。

## データ
| データ | 内容 | 期間 |
|---|---|---|
| 経済産業省「商業動態統計」 | 百貨店・スーパーの既存店の前年同月比、コンビニ・ドラッグストア・ホームセンター・家電大型専門店の販売額（全国） | 2011年1月〜2026年8月（ドラッグストアなど3業態は2014年1月から） |
| 気象庁「過去の気象データ検索」 | 9地点（札幌・仙台・東京・名古屋・大阪・広島・高松・福岡・那覇）の日別の降水量・平均気温から作った月の値 | 2012年1月〜2026年9月 |
| 祝日 | Python の `jpholiday`（内閣府「国民の祝日」。振替休日・国民の休日を含む） | 2011〜2027年 |

- 売上と天気のデータは、F135（雨の日と小売の売上）で取得・整形したものをそのまま使っています（`data/raw/`）。新しい取得はしていません。
- 全国の天気は9地点の単純平均です。

## 手法
1. **カレンダーの変数**（`src/02_整形.py`、SQL 版は `sql/`）
   - 月ごとに、土曜（祝日を除く）、日曜（土曜の祝日を含む）、平日の祝日（振替休日を含む）、連休の日（休みが3日以上続く日。年末年始12/31〜1/3も休みとして数える）、月の日数を数えました。
2. **回帰**（`src/03_分析.py`）
   - 目的変数：前年同月比（対数差×100）。百貨店・スーパーは店舗数の増減を除くため既存店の値、ほかの業態は販売額から作りました。
   - 説明変数（どれも前年同月との差）：
     - 土曜の数、日曜の数、平日の祝日の数、連休の日数、月の日数
     - 平均気温（夏6〜9月・冬12〜2月・春秋で分ける）、雨の日（1日1mm以上）の数
     - 消費税の駆け込みと反動（2014年3・4月、2019年9・10月と、その1年後の比較月）
   - 月の日数が同じなら、「土曜が1日多い」は「平日1日が土曜に入れ替わった」と同じ意味です。
   - コロナ期（2020年2月〜2023年5月）は前年比が大きく乱れるため除きました。標準誤差は Newey–West（12ラグ）。
3. **説明できる割合**：カレンダー・天気・消費税の3つのまとまりで決定係数（R²）を分けました（シャープレイ値。順番による違いをならす分け方）。消費税の前後の月を除いた「ふだんの月」でも計算しました。
4. **期間外の検証**：2013〜2019年だけで推定し、その係数で2023年6月〜2026年8月を補正して、揺れがどれだけ減るかを見ました。
5. **この先の月の補正表**：カレンダーはこの先の分も決まっているので、2026年9月〜2027年12月の各月について、カレンダーだけで前年同月比が何ポイント動くかを計算しました（`results/G_calendar_effect_2026_2027.csv`）。

## 結果
### 1. 休みの日1日あたりの効果（%ポイント、95%区間）
| 業態 | 平日→土曜 | 平日→日曜 | 平日→平日の祝日 | 月の日数 +1日 | 雨の日 +1日 |
|---|---|---|---|---|---|
| 百貨店 | +0.80（+0.09〜+1.50） | +0.79（+0.17〜+1.40） | −1.15（−2.87〜+0.58） | +3.35 | −0.25 |
| スーパー | +0.77（+0.37〜+1.17） | +1.22（+0.71〜+1.73） | +0.93（+0.01〜+1.85） | +3.63 | −0.08 |
| コンビニ | +0.39（+0.10〜+0.69） | +0.39（+0.17〜+0.61） | +0.55（−0.06〜+1.17） | +3.03 | −0.01 |
| ドラッグストア | +0.67（+0.22〜+1.13） | +0.56（+0.25〜+0.87） | +0.60（−0.46〜+1.66） | +4.52 | −0.21 |
| ホームセンター | +1.28（+0.67〜+1.88） | +1.23（+0.57〜+1.89） | +1.36（+0.22〜+2.51） | +1.73 | −0.42 |
| 家電大型専門店 | +2.16（+0.86〜+3.47） | +3.25（+2.08〜+4.42） | +2.98（+0.69〜+5.27） | −1.90 | −0.04 |

- 月の日数が1日多いと、1/30≒3.3% 増えるのが目安です。スーパー・コンビニ・百貨店はほぼその大きさでした。家電大型専門店がマイナスなのは、うるう年の2月と、ほかの変数（曜日の巡り）が重なっているためと考えています（推測）。
- 連休の日の効果は、どの業態でも区間が0をまたぎました（百貨店 +0.58、−0.01〜+1.17 がいちばん大きい）。休みの日の数を入れたうえでは、「休みが続くこと」による上乗せは見分けられませんでした。
- 気温は、冬が暖かい月にスーパー（−0.62）・ホームセンター（−0.64）・家電大型専門店（−1.46）が下がりました（1℃あたり、区間は0をまたがない）。夏の気温は、どの業態でも区間が0をまたぎました。

### 2. 前年同月比の揺れのうち、説明できる割合
| 業態 | カレンダー | 天気 | 合計（ふだんの月） | 参考：消費税を含めた全体の R² |
|---|---|---|---|---|
| 百貨店 | 11% | 2% | 13% | 55% |
| スーパー | 29% | 8% | 37% | 60% |
| コンビニ | 17% | 6% | 23% | 26% |
| ドラッグストア | 21% | 8% | 29% | 67% |
| ホームセンター | 25% | 20% | 46% | 76% |
| 家電大型専門店 | 23% | 5% | 28% | 69% |

- 全体の R² が高いのは、主に消費税の前後の数か月が大きく動いたためです。
- カレンダーの寄与の大きさ（絶対値の中央値）は、スーパー 0.77、ホームセンター 1.23、家電大型専門店 2.16、コンビニ 0.39 ポイントでした。1ポイントを超えた月の割合は、スーパー36%、百貨店37%、ホームセンター62%、家電大型専門店67%、ドラッグストア15%、コンビニ6%です。

### 3. 例：スーパーの2026年6月
- 前年同月比はそのままだと −2.3% でした。
- そのうち、カレンダーの寄与が −1.2、天気の寄与が −1.5 ポイントです。
- 2つを引くと +0.4% になります。
- もし架空の小売チェーンがこの月に販促をして、前年同月比だけで評価していたら、「−2.3%で効果なし」と判断してしまいます。カレンダーと天気を引くと、前年並みよりやや上でした（例は説明のための仮定で、実在の企業ではありません）。

### 4. 期間外の検証（2013〜2019年の係数で 2023年6月〜2026年8月を補正）
| 業態 | そのままの揺れ | 補正後の揺れ | 変化 |
|---|---|---|---|
| 百貨店 | 5.30 | 5.26 | −1% |
| スーパー | 1.71 | 1.32 | −23% |
| コンビニ | 1.70 | 1.59 | −6% |
| ドラッグストア | 2.28 | 2.53 | +11% |
| ホームセンター | 3.01 | 2.37 | −21% |
| 家電大型専門店 | 5.83 | 6.01 | +3% |

- スーパーとホームセンターは、昔の係数でも補正が効きました。
- 百貨店・家電大型専門店・ドラッグストアは効きませんでした。コロナ後に客層や売れ方が変わった（訪日客、店舗数の急増など）可能性があります（推測）。この3業態では、係数を新しい期間で推定し直してから使う必要があります。

### 5. この先の月（2026年9月〜2027年12月）
- 2026年11月は、前年より土曜が1日少なく、連休の日も3日少ないため、百貨店 −2.5、家電大型専門店 −3.3、ホームセンター −1.7 ポイント、カレンダーだけで前年同月比が下がる計算です。
- 2027年1月は日曜が1日多く、スーパー +1.3、家電大型専門店 +2.9 ポイント上がる計算です。
- 一覧は `results/G_calendar_effect_2026_2027.csv`、図は `figures/fig4_calendar_effect_2026_2027.png` です。

## 頑健性
| 確かめたこと | 結果 |
|---|---|
| 天気を東京・名古屋・大阪の3都市の平均にする | 雨の係数は小さくなった（スーパー −0.08→−0.10、ホームセンター −0.42→−0.29）が、向きは同じ |
| 曜日を「月曜を基準にした7つの曜日の数」で表す | 土曜・日曜の係数はスーパー +0.78・+1.40 でほぼ同じ。ホームセンターは +0.76・+0.75 と小さくなり、家電大型専門店の土曜は +0.32 と大きく変わった |
| 1年ずつ抜いて推定し直す | スーパーの土曜 +0.68〜+0.93、日曜 +0.96〜+1.37、雨 −0.12〜−0.06。家電大型専門店の日曜 +2.75〜+3.67 |
| コロナ期を含める | スーパー・コンビニ・ドラッグストア・ホームセンターはほぼ同じ。百貨店は土曜が −4.5 になるなど大きく崩れた |
| 天気の並べ替え（500回） | 天気を入れて増える R² が、並べ替えの95%点を超えたのはスーパー（p=0.008）とホームセンター（p<0.002）。ドラッグストアは境目（p=0.064）、ほかは偶然の範囲 |
| SQL と Python の照合 | DuckDB 版の SQL で作った月の表（204か月×5変数）は Python と一致（ずれ0件）。カレンダーの寄与（672行）の差も最大 2×10⁻¹⁵ |

## SQL とダッシュボード
- `sql/01_calendar_and_adjust_sqlserver.sql`：SQL Server 用。日の表（再帰 CTE）→ 連休の印（ギャップと島）→ 月の表 → 前年同月との差 × 係数で、カレンダーの寄与と補正後の前年同月比を出します。この作業環境に SQL Server がないため、SQL Server では動かしていません。
- `sql/02_calendar_and_adjust_duckdb.sql`：同じ計算の DuckDB 版です。`src/05_SQLの照合.py` で Python の結果と一致することを確かめました。
- `dashboard/index.html`：HTML 1枚のダッシュボードで、外部のライブラリは使っていません。業態を選ぶと、次のものが出ます。
  - 前年同月比のそのままと補正後
  - カレンダー・天気の寄与
  - この先の月の補正表
  - 係数

## 言えないこと
- 全国の月次の値なので、店や地域ごとの効き方は分かりません。全国で平均すると、地域ごとの天気の違いは打ち消し合います。
- 係数は「同じ業態の全国の合計」についてのもので、個別の店や会社にそのまま当てはまるとは限りません。実務で使うなら、自社のデータで推定し直す必要があります。
- 祝日やお盆・年末年始の「日付」は入れていますが、学校の長期休み、給料日、ボーナス、セールの時期は入っていません。こうした要因がカレンダーの係数に混ざっている可能性があります。
- 気温は9地点の単純平均で、人口の重みはつけていません。
- コロナ期を除いても、2023年以降は売れ方そのものが変わった業態があります（百貨店・ドラッグストアなど）。
- 消費税の扱いは、前後の月をダミー変数で除くだけの簡単な形です。
- 2026年11月以降の補正表はカレンダーだけで、天気は入っていません（先の天気は分からないため）。
- 例に出した「架空の小売チェーン」は説明のための仮定で、実在の企業のデータではありません。
