# 1180 倍率の高い回は、申し込みたい人の多い回だと読んでよいのか？（抽選と倍率）

抽選の倍率は「申し込んだ人数÷枠」です。倍率の高い回は人気の回だと読みたくなりますが、倍率は分母の枠でも動きます。主催者が人気の出そうな回に大きな会場を用意すれば、人気の回の倍率はかえって下がり、小さな会場の回の倍率が上がります。**ここでは、作成者が置いた架空の文化教室の特別講座（1年に200回。回ごとの「本当に行きたい人の数」、枠を人気の見込みに合わせる強さ0.7、行きたい人のうち申し込む割合を作成者が置いたもの）で、倍率の高い順・申し込みの多い順・枠の小さい順に選んだ上位20回が、本当に行きたい人の多い上位20回にどれだけ入っていたかを1,000年分数えました。枠を合わせる強さ・枠の決め方のぶれ・申し込む割合のぶれを変えた27通りも確かめました。**

例の講座は架空のもので、実在の催し・会社・申し込みの仕組みを表すものではありません。申し込むかどうかを勧める・止める記事ではありません。

関連する記事：同じ企画の 1179「日にちごとに分けて抽選すると、混む日と空いた日の当たりやすさは何倍開くのか？」は、同じ催しを日に分けたときの当たりやすさの開きを扱っています。1023「予約のない枠は、本当に人気がないのか？」は、予約の数を人気として読むときのずれを扱っています。同じ企画の 1184「申し込む人数の見込みから枠の数を決めると、見込みの外れで倍率はどれだけ振れるのか？」は、この記事と同じく主催者が見込みから枠を決める場面で、見込みの外れによる倍率の振れを扱っています。1175「前回の倍率を見て申し込む人が増えたり減ったりすると、倍率はどこに落ち着くのか？」は、倍率を見て申し込む人が動く場面を扱っています。この記事は、回ごとの倍率を「申し込みたい人の多さ」として読めるかに絞ります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A1180 | 倍率の高い回は、本当に行きたい人の多い回か。倍率の順・申し込みの多い順で上位20回を選ぶと、本当の上位20回にどれだけ入るか | 架空の講座1年200回。本当に行きたい人の数＝300×exp(0.6×z)（z は回ごとの標準正規の乱数、整数に丸める）。枠＝100×exp(c×0.6×z＋枠の決め方のぶれ)（c は枠を人気の見込みに合わせる強さ、基本0.7。ぶれは標準偏差0.4の正規分布、10人未満は10人）。申し込む割合は0.6を中心に回ごとにぶれる（オッズの対数で標準偏差0.5）。申し込んだ人数は行きたい人の数と申し込む割合からの二項の乱数。倍率＝申し込んだ人数÷枠。①倍率の高い順、②申し込みの多い順、③枠の小さい順の上位20回のうち、本当に行きたい人の上位20回に入っていた割合を1,000年分平均した（でたらめに選べば10%）。倍率と行きたい人の数の相関（どちらも対数で見たもの）も数え、置いた式からの近似の値（(1−c)×0.6÷√((1−c)²×0.6²＋枠のぶれ²＋(0.4×申し込む割合のぶれ)²)）と照らした。確かめに、c（0・0.5・0.9）×枠のぶれ（0.2・0.4・0.8）×申し込む割合のぶれ（0.25・0.5・1.0）の27通りを各300年。seed 1180 | `src/a1180_ratio_vs_demand.py` |

## 主な結果

### 上位20回の当たり（基本、1,000年の平均、`results/a1180_main.json`）
| 選び方 | 本当に行きたい人の上位20回に入っていた割合 |
|---|---|
| ①倍率の高い順 | **25.35%** |
| ②申し込みの多い順 | **78.08%** |
| ③枠の小さい順 | 0.01% |
| でたらめに選ぶ | 10% |

- **倍率の高い順の上位20回のうち、本当に行きたい人の上位20回に入っていたのは25.35%で、申し込みの多い順（78.08%）の3分の1ほどだった**
- 倍率の上位20回の55.43%は、枠が下位3分の1の回だった。倍率の上位20回の行きたい人の数（中央値）は、全体の中央値の1.501倍にとどまった
- 倍率と行きたい人の数の相関（対数で見たもの）は0.365で、置いた式からの近似の値0.373とほぼ合った（式どおり）。申し込んだ人数と行きたい人の数の相関は0.941だった
- 1年分（`data/one_year.csv`）では、倍率の中央値1.736倍・最大4.175倍、倍率が1倍未満（定員割れ）の回は28回。この年の倍率の上位20回の当たりは15%、申し込みの多い順は60%だった

### 確かめ：置き方を変えると（27通り、各300年、`results/grid.csv`）
| 枠を人気に合わせる強さ | ①倍率の高い順の当たり | ②申し込みの多い順の当たり | 倍率と行きたい人の数の相関 |
|---|---|---|---|
| 0（合わせない） | 36.23〜73.2% | 65.37〜87.43% | 0.54〜0.931 |
| 0.5 | 23.17〜55.45% | 65.7〜87.68% | 0.312〜0.793 |
| 0.9 | **11.83〜18.83%** | 65.62〜88.47% | 0.068〜0.256 |

- **27通りすべてで、申し込みの多い順のほうが倍率の高い順より当たった**。倍率の順の当たりは11.83〜73.2%、申し込みの多い順は65.37〜88.47%
- 倍率の順の当たりは、枠を人気に合わせる強さと枠の決め方のぶれで決まった。合わせる強さ0.9では、でたらめ（10%）に近い11.83〜18.83%だった
- 枠を人気に合わせない（強さ0）でも、枠の決め方のぶれが0.8なら倍率の順の当たりは36.23〜37.83%に下がった
- 申し込みの多い順の当たりは、申し込む割合のぶれ（0.25・0.5・1.0）で87.02〜88.47%・77.67〜78.62%・65.37〜67.13%とほぼ決まり、枠の置き方ではほとんど動かなかった（作りどおり：申し込みの数は枠を使わない）
- 相関は27通りすべてで、置いた式からの近似の値と0.02以内で合った

## 注意（言えないこと）
- 架空のデータです。行きたい人の数の散らばり、枠を人気に合わせる強さ、枠の決め方のぶれ、申し込む割合のぶれは作成者が置いたもので、結果はこれで決まります。倍率の順の当たりは、とくに枠を人気に合わせる強さでほぼ決まります
- 申し込む人は、前の回の倍率を見て申し込みをやめたり増やしたりしない、と置きました。その動きがあれば、倍率の順はさらに人気とずれると考えられます（推測。倍率を見て人が動く場面は 1175 で扱っています）
- 1人1口と置きました。何口も申し込める決まり、重複した申し込みは入れていません
- 「本当に行きたい人の数」は作成者が置いた値で、実際には誰にも分かりません。この記事は、置いた値に対して倍率の順がどれだけ当たるかを数えただけで、実在の催しの人気を表すものでも、申し込むべきかどうかを言うものでもありません
