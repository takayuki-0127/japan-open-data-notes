# 297 持ち家の割合は、年齢でどう違うのか

総務省「令和5年住宅・土地統計調査」時系列統計表 第21-1表（住宅の所有の関係・家計を主に支える者の年齢別の主世帯数、全国、1968〜2023年）を使ったフォルダです。全国の集計だけを使っています。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A297 | 持ち家に住む世帯の割合（持ち家率）は、年齢でどう違い、40年でどう変わったか | 年齢別（5歳刻み、65歳以上はまとめる）の持ち家率の推移（1978〜2023年）。持ち家率が50%を超える年齢を線形補間で求めた。5年ごとの調査と5歳刻みの年齢をつなぎ、生まれ年ごとに持ち家率の上がり方を追った。全体の持ち家率の変化を「年齢構成の変化の分」と「同じ年齢の中の変化の分」に分けた（シフト・シェア分解、中点の重み） | `src/a297_owner_rate_by_age.py` |

## 主な結果
- 30〜34歳の持ち家率は1983年45.7% → 2003年29.1% → 2023年25.8%。35〜39歳は60.1% → 44.1%、40〜44歳は68.6% → 54.9%、50〜54歳は77.5% → 63.6%と、30〜50代のどの年齢でも13〜20ポイント下がりました。65歳以上は76.8% → 80.8%と上がっています。
- 持ち家率が50%を超える年齢（5歳刻みの帯の中央で補間）は、1983年33.5歳、2003年38.0歳、2023年39.7歳。2018年と2023年は同じでした。
- 生まれ年で見ると、40〜44歳の時点の持ち家率は、1939〜43年生まれ68.6%、1959〜63年生まれ61.4%、1969〜73年生まれ56.2%、1979〜83年生まれ54.9%。後に生まれた人ほど低い一方、最近の2つの世代の差は1.3ポイントと小さくなっています。
- 全体（年齢が分かる主世帯）の持ち家率は1983年62.8% → 2023年63.4%（+0.6ポイント）。このうち年齢構成の変化の分が+9.7ポイント、同じ年齢の中の変化の分が−9.1ポイントで、ほぼ打ち消し合っていました。65歳以上の世帯の割合は9.3%から39.9%に増えています。年齢別の率が1983年のままなら、2023年の持ち家率は69.4%になる計算です。

## 頑健性
- 所有の関係が「不詳」の世帯（2023年は総数の4.2%、1983年は0.3%）を分母から除いて計算し直しても、1983→2023年の分解は+9.7ポイントと−8.9ポイントで、結論は変わらない
- 計算した持ち家率と表に印刷された割合（小数1桁）の差は最大0.05ポイント
- 分解の起点を1978年・2003年に変えても、年齢構成の分がプラス、同じ年齢の中の分がマイナスで、同じ向き（1978→2023年：+12.0と−9.2、2003→2023年：+4.4と−4.1）
- コードはきれいなフォルダで3回動かし直し、data・results・figures の全ファイルが一致した

## データ
- `data/raw/hlts_ts_subset.json`：e-Stat「令和5年住宅・土地統計調査 時系列統計表」第21-1表（statInfId=000040354054）の閲覧用 Excel を、ブラウザの中で SheetJS（xlsx 0.18.5）で CSV の文字列にしたもの（2026-11-12 取得）。手で取る場合は `https://www.e-stat.go.jp/stat-search/file-download?statInfId=000040354054&fileKind=4`
- `data/owner_by_age_long.csv`・`data/owner_rate_by_band.csv`・`data/owner_rate_by_cohort.csv`：整形した表

## 注意
- 年齢は「家計を主に支える者」の年齢で、世帯の全員の年齢ではありません
- 表の「総数」の持ち家率（2023年60.9%）は、年齢不詳と所有の関係不詳を分母に含みます。分解では、年齢が分かる世帯の合計（2023年63.4%）を使いました
- 1968・1973年は年齢の区切りが粗いので、1978年以降を使いました。1968年は沖縄県を含みません
- 標本調査の推定値で、5年ごとの値です。生まれ年ごとの曲線は、同じ人を追ったものではなく、同じ年に生まれた人たちの別の調査年の値をつないだものです
- 持ち家率が下がった理由（結婚の時期、住宅の値段、働き方など）は、このデータでは分けていません
- 「持ち家の資産価値」はこの記事では扱っていません
