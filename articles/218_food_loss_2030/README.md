# 218 今のペースで、食品ロスの2030年度目標に届くか：推計値のトレンドを外挿する

環境省・農林水産省「我が国の食品ロスの発生量の推計値」（2012〜2024年度）の事業系・家庭系の食品ロス量に直線を当てはめて2030年度まで伸ばし、2030年度目標（2000年度比で事業系60%減＝219万t、家庭系半減＝216万t）と比べたフォルダです。206（食品ロスの内訳）の続きで、データは206と同じです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A218 | 今のペースが続けば、2030年度目標に届くか。何%ずつ減らせばよいか | 当てはめ期間を3通り（2012〜24、2015〜24、2019〜24年度）にした最小二乗の直線と95%予測区間、目標に必要な年あたり減少率と過去の減少率（幾何平均）の比較 | `src/a218_food_loss_2030.py` |

## 主な結果
- 2024年度は事業系237万t（目標まであと18万t）、家庭系224万t（あと8万t）
- 目標に届くには、2024→2030年度に事業系は年1.3%、家庭系は年0.6%ずつ減ればよい。過去の減少率は、事業系が2012→19年度で年1.0%、2019→24年度で年5.2%、家庭系が年2.5%、年3.0%
- 2012〜24年度の直線を伸ばすと、2030年度は事業系178万t（95%予測区間113〜244）、家庭系182万t（162〜202）。直線が目標を下回るのは事業系で2026年度、家庭系で2025年度ごろ
- 家庭系は3通りのどの期間でも、2030年度の予測（173〜184万t）と予測区間の上端（191〜202万t）が目標216万tを下回る
- 事業系は期間で予測が130〜178万tと大きく変わり、2012〜24年度と2019〜24年度の予測区間には目標が入る。事業系は2022〜24年度が236→231→237万tとほぼ横ばいで、外食産業が60→70万tに戻った

## 動かし方
```
pip install -r requirements.txt
cd src && python a218_food_loss_2030.py
```

## データ
- `data/food_loss_2012_2024.csv`：年度別の食品ロス量（万t）。事業系は業種別、家庭系は発生要因別（206と同じ）
- `data/targets.csv`：2030年度目標（基準の2000年度：事業系547万t、家庭系433万t）
- `results/projection_by_window.csv`：期間別の傾き・2030年度予測・95%予測区間・直線が目標に届く年度
- `results/required_vs_past_rate.csv`：目標に必要な年率と過去の年率

## 注意
- 直線の外挿は「これまでと同じ量ずつ減り続ける」という仮定です。2020年度以降はコロナ禍の影響（外食の落ち込みと回復）が入っていて、直線の当てはまりは良くありません
- 点が6〜13個と少なく、予測区間は広くなります。特に2019〜24年度（6点）は幅が大きいです
- 推計値は毎年の推計方法の見直しで過去分が変わることがあります。ここでは公表資料の図の値を使っています
