# F161 同じデータで記事を書き直すと、結論はどれだけ変わるか？ 初期の3本を今の手順で作り直す

看板記事 F161。note：「同じデータで記事を書き直すと、結論はどれだけ変わるか？…」（下書き）

## 問い
初期の記事（2026年10月ごろ）は、1つの手順で1つの答えを出していた。今の看板記事では、頑健性の確認・検証データの分け方・比べる相手を最初から決めている。
同じデータを今の手順で作り直すと、元の結論はどれだけ残るか。

対象にしたのは、種類の違う初期の3本：

| 元記事 | 種類 | 元の主な主張 |
|---|---|---|
| [008 人が集まっている街は、所得が高い街か？](../008_migration_income) | 横断の回帰 | 所得の係数は条件をそろえると0と区別できない（+2.09 → −0.58）。残ったのは大卒の割合と人口密度 |
| [019 1,740市区町村を「似た街」に分けてみた](../019_municipal_clusters) | クラスタリング | k-means で5つのグループ。乱数の種を変えても ARI 0.95。ただし境目はあいまい |
| [020 失業率は何か月先まで予測できるか？](../020_unemployment_sarima) | 時系列予測 | 1〜12か月先のどこでも SARIMA が単純な予測より誤差が小さい |

## データ
元記事のフォルダにあるファイルを、そのまま使った（`src/01_取得.py` がコミット 8090888 の版から取る）。新しいデータは取っていない。
- `data/raw/municipal_base.csv`・`municipal_extra.csv`：008・019 と同じ市区町村データ（1,740市区町村）
- `data/raw/lt01-a10.xlsx`：020 と同じ労働力調査 長期時系列（2000年1月〜2026年8月）
- `data/original/`：元記事の結果ファイル（比べるため）

## 手法
まず元の数字を再現し（008 は係数が小数3桁まで一致、019 は割り当てが ARI 1.00、020 は平均絶対誤差の差が最大0.00005）、そのうえで今の手順を足した。

| 元記事 | 足した手順 |
|---|---|
| 008 | ①都道府県でクラスタした標準誤差 ②条件の組み合わせ512通り（ほかの条件64通り×都道府県の有無×人口の重み×外れ値の丸め）の specification curve ③都道府県を1つずつ外す ④都道府県の中で所得を並べ替える置換検定（1,000回）⑤標本・所得の定義を変える |
| 019 | ①復元抽出200回でグループごとの再現（Jaccard、Hennig 2007）②k=2〜9 のシルエット・ギャップ統計・復元抽出の ARI ③Ward 法・混合正規分布 ④外れ値を丸めない・順位に変換・指標を1つ外す ⑤都道府県で半分に分けて、片方で作ったグループで残りを割り当てる（20回）|
| 020 | ①比べる相手に季節ナイーブと指数平滑法（ETS、減衰トレンド＋加法季節）を足す ②Diebold–Mariano 検定（h−1 次の Newey–West、小標本補正）③コロナ期を含める・予測先の期間を分ける ④80%・95%予測区間の当たり方 ⑤次数を毎年1月に AIC で選び直す |

## 結果

### 008 人の流入と所得
- 元の最後の形（すべての条件＋都道府県）は、都道府県でクラスタした標準誤差でも0と区別できない（−0.58、95%区間 −1.52〜+0.36、p=0.23）。都道府県の中で並べ替えた置換検定は p=0.059。
- ただし条件の組み合わせ512通りでは、中央値 −0.37、**はっきりマイナス38%**、はっきりプラス11%、はっきりしない52%（図1）。65歳以上の割合を入れた256通りに限ると、はっきりマイナス53%・はっきりプラス3%。
- 係数のばらつきの79%は、どの条件を入れるかで説明できた（大卒の割合を入れると −1.03、65歳以上 −0.61、人口密度 −0.52、人口で重みづけ −0.47）。
- 標本・定義を変えた4通りのうち3通りで、はっきりマイナス（人口5千人未満を除く −0.91、転入超過の上下1%を除く −0.56、所得を住民1人あたりにする −1.51）。東京23区を除くと −0.51 ではっきりしない（図2）。都道府県を1つずつ外すと −1.03〜−0.33。
- 大卒の割合は入れた指定の99%、人口密度は100%ではっきりプラスで、元の主張どおり。ただし元の結果表では単独世帯の割合もはっきりマイナス（−1.46、クラスタ標準誤差でも p=0.009）だったのに、要約に書いていなかった。
- 読み方：「条件をそろえると所得との関係は消える」は、元の1つの指定では残るが、指定を広げると「0というより弱いマイナスに寄る」と書くほうが近い。

### 019 似た街のグループ
- 元記事の「乱数の種を変えた ARI 0.95」は、同じデータでの計算のぶれしか見ていなかった。標本を入れ替える（復元抽出200回）と、全データの5グループとの一致は ARI の中央値 0.64（10%点 0.43）。
- k=2〜9 で比べると、k=5 は標本を入れ替えたときの一致が低い側（中央値 0.58。k=3 は0.94、k=6・7 は0.81・0.83）（図3）。ギャップ統計は k=9 まで増え続け、止まる k がなかった。
- グループごとの再現（Jaccard）の平均は 0.64〜0.76。0.75 を超えたのは「家族世帯が多い地方の市町」だけ（図4）。
- 別の手法との一致は ARI 0.34（混合正規分布）〜0.41（Ward 法）、順位に変換 0.37、外れ値を丸めない 0.53、指標を1つ外す 0.50〜0.69。都道府県で半分に分けて当てると中央値 0.52。
- いちばん近い中心と2番目の中心の距離の差が10%未満の市区町村が18%。「境目はあいまい」は元記事どおりで、作り直すとより強く言える。

### 020 失業率の予測
- 元の数字（コロナ期を除く128起点）を再現し、SARIMA の平均絶対誤差は12か月とも、足した2つ（季節ナイーブ・ETS）も含めてもっとも小さかった。コロナ期を含めても同じ。
- ただし差がはっきりしたのは、「最新の値のまま」に対して12か月中9か月分、「前年同月＋前年差」に対して5か月分、ETS に対しては0か月分。
- 予測先の期間を分けると、2015〜2019年は1か月先で「最新の値のまま」（0.096）が SARIMA（0.100）より小さい。2022年以降は ETS が12か月中11か月分で SARIMA より小さく（12か月先で 0.098 対 0.118）、12か月先では「最新の値のまま」とも並ぶ（図5）。
- 80%予測区間に実際が入った割合は平均97%、95%区間は99.8%（コロナ期を除く）。区間は広すぎた。コロナ期を含めると12か月先の95%区間で96%。
- 次数を毎年選び直すと、11年中8年で (2,1,2) から (2,1,1) や (2,1,0) に変わったが、平均絶対誤差の差は0.003ポイント以内。

## 言えないこと
- 3本は「種類の違う初期の記事」として選んだもので、初期の記事全体の傾向は言えない。結論が変わりやすい記事を選んだわけでも、変わりにくい記事を選んだわけでもない。
- 「今の手順」も選択の1つで、ほかの確かめ方をすれば別の判定になりうる。判定の言葉（同じ・一部変わった・変わった）は、この記事の中での目安。
- 008 の結果は横断の相関で、所得が流入を決めるかどうかは言えない（元記事と同じ）。
- 019 のグループが崩れやすいことは、「市区町村に違いがない」という意味ではない。違いが連続していて、5つの箱にきれいに分かれない、という意味。
- 020 の比較は2015〜2025年の失業率1系列だけ。ETS が2022年以降に小さかったのは、この期間の動き（ゆるやかな低下と横ばい）での結果。
- 元記事を書き直すものではない。元記事はそのまま残し、この記事で違いを並べる。
