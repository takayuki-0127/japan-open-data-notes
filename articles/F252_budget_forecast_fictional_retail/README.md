# F252 来期の予算のための需要予測（業務の再現：架空の会社で）

シリーズ③「業務の再現：架空の会社で」の7本目。架空の食品スーパー **サンプルマート（架空）** で、2026年3月末の時点に来期（FY2026）の売上を予測し、幅（下振れ・基本・上振れ）をつけて営業利益までの **予算案** にした。予測の作り方は F231（何か月先まで当たるか）・F232（店の予測を足し上げる）と同じ系統。最後に、予算を作ったあとの5か月（2026年4〜8月）で答え合わせをした。

> **会社も数字もすべて架空（乱数で合成したデータ）。** 実在の会社・店・顧客のデータは使っていない。公開データから借りたのは、売上の季節の形と食品の値段の上がり方（F246 の設定）と、幅を測るための商業動態統計（スーパー）の販売額だけ。

## 問い
自社の記録が4年しかない会社で、来期の予算の売上を「1つの数字」ではなく「幅」で出すとき、その幅はどう作れば正直か（実際がちゃんと入るか）。売上の幅は、利益ではどれだけ広がるか。

## 結論
- **FY2026 の予算（22店）：売上 274.9億円（同じ22店の FY2025 比 +3.1%）、80%の幅 269.5〜280.4億円（−2.0〜+2.0%）。営業利益 7.42億円（+4.2%）、幅 6.25〜8.61億円（−16〜+16%）**。売上の ±2% が、利益では ±16% になる（費用の多くは売上で動かないため）。
- **自社の記録だけでは幅を測れない**。4年の記録で「1年分の予算の外れ」の答えが出ているのは、FY2025 の予算を作る時点で1回分だけ。モデルの区間（ETS・SARIMA の乱数シミュレーション）は狭すぎ、過去の予算の起点13回 × 乱数の種20通りで実際が入ったのは **ETS 20%・SARIMA 57%**（目標80%）。
- そこで **業界（商業動態統計・スーパー）で同じ作り方の予測を2015年から毎月作り、1年合計の外れ（コロナ期を除く79回、80%の範囲 −1.0〜+2.9%）の広さを借り**、自社だけの偶然の揺れ（業界との差のばらつき）を足した。この幅には、同じ13回×20通りで **83%**（季節ナイーブ＋伸び）・**74%**（それに暦の補正）が入った。幅の大部分は市場の外れ（標準偏差 1.5%）で、自社だけの揺れ（0.25%）は小さい。
- 予測の精度そのもの（1年合計の外れ、全社・店の足し上げ）は、季節ナイーブ 2.5%、季節ナイーブ＋伸び 1.3%、それに暦の補正 1.4%、ETS 1.4%、SARIMA 1.1%。季節ナイーブ以外の差は小さい。予算には、**幅の当たり方を説明できて、月割りに暦を入れられる「季節ナイーブ＋伸び＋暦」を使った（決め）**。
- **答え合わせ（2026年4〜8月）：売上の累計は予算より −2.7%**。決めておいた見直しの線（5か月で −1.9〜+1.9%）を下に出た。業界の前年比が、予算を作った時点の直近12か月の +4.1% から 4〜8月は +1.4% に鈍ったため。同じ時点のほかのモデルでは、季節ナイーブ −0.1%、ETS −1.3%、SARIMA −1.5%（伸びを置かないほど外れが小さかった）。
- 5か月の営業利益は予算 2.86億円に対し実績 2.22億円（−22%）。**実績の売上を入れて同じ作り方で利益を計算すると 2.21億円**で実績とほぼ同じ。利益の外れは、ほぼすべて売上の外れから来ていた。

### F246 の設定からの差分
- **2026年4〜8月の5か月を足した**（答え合わせのため）。F246 の `gen(seed)` はコードを書き換えずにそのまま動かし、使った乱数の流れを受け取って、その続きの乱数で5か月分を作った。FY2022〜FY2025 の数字は `gen(seed)` と1円もずれない（`results/02_check.json`、種0・1で差0）。F247 の mart との差は売上で最大 7.8×10⁻⁸（円の丸め）、営業利益は人時の空を F247 が埋めた分だけ違う（売上比で最大 0.07%）。
- 5か月の「市場の量」は商業動態統計（スーパー）の実際の値から作った（F246 と同じ作り方）。**物価は F246 の仮定（2026年も年 +4%）のまま**なので、答え合わせのうち物価の部分は仮定どうしの比べになる。

## 手法
1. **予測するもの**：店×月の売上。全社・地域は店の予測を足し上げる（F232 で足し上げがいちばん外れが小さかったため）。直接に全社・地域を予測した場合も比べた。
2. **モデル**（F231 と同じ系統）：季節ナイーブ（前年の同じ月）、季節ナイーブ＋伸び（直近12か月 ÷ その前の12か月）、それに暦の補正（曜日・平日の祝日・年末の効果を FY2022〜FY2023 の店×日で推定し、予測する月と前年の同じ月の「日の重み」の比を掛ける）、ETS（対数、減衰つきトレンド＋季節）、SARIMA (0,1,1)(0,1,1)12（対数）。
3. **自社の過去で試す**：起点 2024-03〜2025-03 の13回（12か月先が 2026-03 までに収まる範囲）× 乱数の種20通り。2022-04 からずっと営業している20店で、1年分の合計の外れ（MAPE）を店・地域・全社で測った。
4. **業界の長い記録で試す**：商業動態統計（スーパー）で、起点 2015-12〜2025-08 の毎月、同じモデルで12か月先（と5か月先）までの合計を予測し、外れ（実際 ÷ 予測 の対数）を集めた。予測した期間にコロナ期（2020年3月〜2021年12月）の月が入る回は、幅の計算から外した。
5. **幅の作り方を比べる**：
   - ① モデルの区間：全社の ETS・SARIMA を500本シミュレーションし、1年合計の 10%・90% 点。
   - ② 自社の過去の外れ：その起点までに結果が出た自社の外れの 10%・90% 点（2回以上あるときだけ）。
   - ③ 業界の外れ＋自社の揺れ：その起点までに結果が出た業界の外れの 10%〜90% の広さ（標準偏差に直したもの）と、自社だけの揺れ（自社と業界の前年比の差の、月ごとの標準偏差 ÷ √12）を2乗和で足し、自社の予測を真ん中に左右同じ幅でつける。業界の過去の偏りは借りない（頑健性で借りた場合も見た）。
   - 覆えた割合：実際の1年合計が幅に入った割合。自社（13回×20通り）と、業界そのもの（時間を進めながら、その時点までの外れで幅を作る）で測った。
6. **予算（2026-03 時点、種0 ＝ F247 の mart と同じ数字）**：FY2026 に営業する22店。20店は「季節ナイーブ＋伸び＋暦」。08店（2024年10月開店）は前年の同じ月 × 地域の20店の伸び × 暦、16店（2025年4月開店、最初の半年は立ち上がり）は直近3か月の水準（地域の季節で割る）× 地域の季節の形 × 伸び × 暦（**決め**）。閉店した24店は入れない。
7. **利益まで**：粗利率は店ごとの FY2025 の実績。人時は「店×月の固定分＋レシート1枚あたり 0.0295 時間」（FY2024〜FY2025 の店×月で店の平均を引いて推定）。時給は +4.1%、その他の経費は +2.0%（直近12か月の伸び）。客数は、売上の伸びから一品単価（+4.0%）と1回の買上点数（−1.0%）の伸びを除いた分。下振れ・上振れは、全社の売上を幅の端まで同じ割合で動かして計算した。
8. **答え合わせ**：2026年4〜8月の累計を予算と比べた。見直しの線は、③の作り方を5か月先の合計で作ったもの（−1.9〜+1.9%）。売上の外れと費用の見込みの外れを分けるため、実績の売上を入れて同じ作り方で利益も計算した。
9. **SQL**：予算の積み上げ（`sql/10_budget_rollup.sql`）と、バックテストの集計（`sql/20_backtest_mape.sql`）を SQL Server 互換の書き方で書き、DuckDB で実行して pandas と照合（SQL Server では動かしていない）。

## 言えないこと
- **数字は架空の会社の合成データ**。実在のスーパーの伸び・利益の幅を示すものではない。合成の作り方上、自社の売上の動きは商業動態統計（スーパー）から作っているので、**業界の外れを借りるとうまくいくのは、作り方による当然の面がある**。実在の会社では、自社と業界の動きの重なりはもっと小さいはずで、自社だけの揺れの分を大きめに取る必要がある（推測）。
- 自社の答えは実質2年分しかない。モデルの順位も、覆えた割合も、大まかな目安。
- 答え合わせの5か月は、合成の物価の仮定（2026年も +4%）と、業界の名目の伸びの鈍化（+1.4%）が重なり、量の落ち込みが大きめに出ている可能性がある（推測）。
- 予算の前提（伸びが続く、廃棄の悪化が戻らない、新しい店の決め方）は筆者の決めたもの。実務では、販促・出店・値付けの計画や、本部の方針と合わせて決めるところ。
- 利益の幅は「全社の売上が同じ割合で動く」として計算した。店・部門ごとに動き方が違えば、幅は変わる。
