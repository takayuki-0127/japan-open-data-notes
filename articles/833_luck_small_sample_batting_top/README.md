# 833 少ない打席の「最高打率」は、件数の少なさで決まるのか？（運と実力）

打率は「安打÷打数」なので、打数が少ない打者ほど、たまたまの数本で上にも下にも大きく振れます。打者全員の中で打率の1位を決めると、1位は数打数の打者になりがちです。そこで「最低打数の線」（この打数以上の打者だけで1位を決める）を引きますが、線を高くすると、今度は打数の少ない本当に良い打者が外れます。**ここでは、作成者が乱数で作った架空のリーグの打者300人（本当の打率を作成者が置いたもの）で、線なしの打率1位がどんな打者か、最低打数の線を0〜500打数に動かすと1位がどれだけ当たるかを数えました。**

前半の打率1位が後半も1位か（平均への回帰）は関連する記事 826 で扱います。件数の少ない口コミの星が振れる話（801・811）と仕組みは同じです。801 は件数で寄せる並べ方（ベイズ平均）、811 は件数の条件を10件・30件まで付けたときの当たりを見ました。この記事は線を500打数まで上げ、線を高くしすぎると本当の1位が線の外に出て、「線の中の1位」は当たっても「全員の中の1位」は取りこぼす、というところ（線の高さのちょうどよい所）を見ます。

## 注意（言えないこと）
- 架空のデータです。本当の打率の散らばり、打数の分布、レギュラーの割合は作成者が置いたもので、どの線がよいか、1位がどれだけ当たるかはこれで決まります。300打数がよかったのは、この置き方（レギュラーを350〜600打数と置いたこと）での結果です
- 打数と本当の打率は関係なしと置きました。実際には、よく打つ打者ほど打席を多く与えられるはずで（推測）、そうなると線を引いたときに外れる良い打者は今回より少なくなります
- 1打数ごとの安打の確率は、相手や調子によらず一定と置きました
- 実在のリーグの規定打席の決め方を表すものでも、どの線にすべきかをすすめるものでもありません
