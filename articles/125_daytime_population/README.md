### daytime-population-japan：国勢調査で、昼夜間人口比率が高い・低い市区町村と30年の変化を調べる

総務省「国勢調査」時系列データ（従業地・通学地）第1表「常住地又は従業地・通学地別人口（夜間人口・昼間人口）－全国，都道府県，市区町村（平成2年～令和2年）」を使ったリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A125 | 昼夜間人口比率（昼間人口÷夜間人口×100）がいちばん高い・低い市区町村はどこか。1990〜2020年でどう変わったか | 2020年の順位（夜間人口5千人以上の区・市町村）、都心の区の推移、1990年と2020年の両方にある1,233区・市町村での比較 | `src/a125_daynight.py` |

#### 主な結果
- 2020年に最も高いのは千代田区1,355（夜間人口6.7万人に対し昼間人口90.4万人）。大阪市中央区433、中央区374、港区373、名古屋市中区316が続く。最も低いのは七ヶ浜町（宮城県）67、中山町（山形県）73、日高町（和歌山県）74、狛江市74
- 都心の区の比率は30年で大きく下がった。千代田区は2,637（1990年）→1,355、中央区1,107→374、大阪市中央区1,030→433。昼間人口も減ったが（千代田区103.7万→90.4万）、主に夜間人口（住む人）が増えたため（千代田区3.9万→6.7万、中央区6.8万→16.9万）
- 東京都23区全体は139.4→126.8。他県から通う人は296万人→251万人
- 1990年と2020年の両方にある1,233区・市町村で、比率が80未満の所は10.8%→4.0%、90未満は33.6%→25.9%に減り、中央値は95.7→96.5。都心は下がり、ベッドタウンは上がって、差が縮まった

#### 動かし方
`data/day_night_*.csv`（3ファイル）（年×地域に整えたもの）が入っているので、そのまま動きます。元の Excel から作り直すときは、e-Stat（https://www.e-stat.go.jp/stat-search/files?toukei=00200521 → 時系列データ → 従業地・通学地、statInfId=000001086184）のファイルを `data/raw/125_jikeiretsu_hiruma.xlsx` に置き、3つの CSV を消してから実行してください。

```bash
pip install -r requirements.txt
cd src
python a125_daynight.py
```

#### データ
| ファイル | 中身 |
|---|---|
| data/day_night_*.csv | 年（1990〜2020の7回）×全国・都道府県・市区町村：夜間人口、昼間人口、県内他市区町村・他県へ通う人、県内他市区町村・他県から来る人、区分（全国・都道府県・政令市・区・市町村）、昼夜間人口比率 |

#### 注意
- 2015・2020年は「原数値」のシート（1990〜2010年と同じ作り方）を使いました。不詳補完値ではありません
- 順位は、政令市の区と東京23区、一般の市町村を単位にしています。夜間人口5千人未満は除きました（2020年は福島県の避難指示区域の双葉町・大熊町などで比率が極端に高くなるため。愛知県飛島村は夜間人口4,575人で比率282）
- 市町村合併で地域の数が2,748（1990年）→1,606（2020年）に減っています。年の比較は、両方の年にある市区町村コードだけで行いました（合併した市町村は入りません）
- 昼間人口は、通勤・通学だけを数えた値で、買い物や観光で来る人は入りません
