# 1195 決まった文面で答えて1件の時間が縮んだとき、もう一度来る問い合わせはどれだけ増えるのか？（問い合わせ対応）

問い合わせ窓口で、はじめの返事を決まった文面で返すようにすると、記録の「1件の対応時間」はすぐに縮みます。けれども、決まった文面が合わない問い合わせにまで使うと、困りごとが片づかず、同じ人がもう一度問い合わせてきます。もう一度来た分は別の1件として数えられ、しかも込み入っているので時間がかかります。片づかないまま、もう来ない人もいます。**ここでは、作成者が乱数で作った架空の会社の問い合わせ窓口（困りごと40,000件。決まった文面で答えられる「定型」と、個別に調べて書く必要がある「込み入った」問い合わせの割合、それぞれの対応の時間と解決の確率、解決しなかった人がもう一度来る確率を作成者が置いたもの）で、はじめの返事を個別に書く「前」と、決まった文面を使う「後」を比べ、1回の対応あたりの時間・困りごと1つあたりの時間・7日以内にもう一度来た割合・来なくなった割合がどう動くかを数えました。確かめとして、込み入った割合・込み入った問い合わせにも文面を使ってしまう割合・文面での解決の確率・もう一度来る確率を変えた81通りも作りました。**

決まった文面での解決の確率を、込み入った問い合わせだけ低く置いたので、もう一度来る分が増える向きは作りどおりです。この記事で数えたのは、その増え方の大きさが記録の数字にどう出るか、出ない分がどれだけあるかです。

例は架空の会社の窓口で、実在の会社や問い合わせ管理のサービスを表すものではありません。決まった文面を使うかどうかを勧める・止める記事でも、担当を比べる記事でもありません。

関連する記事：同じ企画の 1185「1回で解決した割合は、何日以内に同じ人から再び来なければ解決と数えるかで、どれだけ変わるのか？」は、もう一度来たかどうかを数える日数の窓そのものを扱っています。この記事では窓を7日に決めて置き、前と後の差に絞ります。1186「平均の対応時間が短い担当は、手早い担当なのか、易しい問い合わせを受けた担当なのか？」は、1件の時間が問い合わせの種類の混ざり方で動く話で、この記事の「1回の対応あたりの時間」に、時間のかかる2回目以降の対応が混ざる点と同じしくみです。1016「スコアを狙って動くと、スコアと本当の良さはずれていくのか？」は、測っている数字だけが良くなる動きの話です。同じ企画の 1188「よくある質問のページを増やして問い合わせが減ったとき、減ったのは解決した人か、あきらめた人か？」は、記録に出ない「あきらめた人」を、問い合わせの件数の減り方から扱っています。この記事では、もう一度来た割合の増えに出ない「来なくなった人」を、決まった文面の前後で数えます。

## 主な結果

### 前と後（困りごと40,000件、`results/before_after_base.csv`）
| 物差し | 前（個別に書く） | 後（決まった文面） | 変化 |
|---|---|---|---|
| はじめの対応の時間 | 12.33分 | 6.11分 | −50.46% |
| 1回の対応あたりの時間（記録の1件の時間） | 12.95分 | 7.66分 | **−40.82%** |
| 困りごと1つあたりの対応の時間の合計 | 14.11分 | 8.65分 | **−38.67%** |
| 7日以内にもう一度来た割合（記録） | 7.3% | 10.38% | **+3.08ポイント（1.422倍）** |
| 8日以後にもう一度来た割合 | 0.79% | 1.09% | +0.31ポイント |
| 解決しないまま来なくなった割合（記録に出ない） | 4% | 5.8% | **+1.81ポイント** |
| 2回目以降の対応の回数 | 3,581件 | 5,165件 | +44.23% |
| 対応の回数の合計 | 43,581件 | 45,165件 | +3.63% |

- **決まった文面で記録の1件の時間は40.82%縮み、7日以内にもう一度来た割合は7.3%から10.38%へ1.422倍になった**。2回目以降の対応の回数は44.23%増えた
- 困りごと1つあたりの時間の合計の縮みは38.67%で、1件の時間の縮み（40.82%）より小さかった。1回あたり＝困りごとあたりの時間÷困りごとあたりの回数なので、回数が増えれば1回あたりのほうが大きく縮んで見える（式どおり）。この置き方では、文面で縮む時間（はじめの対応の約6分）が、増えた2回目以降の対応の時間より大きかったので、困りごとあたりでも縮んだ
- 解決しないまま来なくなった人は4%から5.8%に増えた。この分は記録の「もう一度来た割合」には出ない

| 定型（前） | 28,097 | 9.953分 | 4.98% | 2.69% |
| 定型（後） | 28,094 | 3.991分 | 4.86% | 2.7% |

- 全体では+3.08ポイントだったもう一度来た割合の増えは、込み入った問い合わせに文面を使った分に集まっていた（12.76%→34.81%）。定型の分は前と後でほぼ同じだった（4.98%と4.86%、作りどおり）

### 確かめ：81通りの置き方（各20,000件、`results/grid.csv`・`results/grid_by_share_use.csv`）
| 込み入った割合 | 込み入った問い合わせにも文面を使う割合 | 1件の時間の変化 | 困りごとあたりの時間の変化 | もう一度来た割合の増え |
|---|---|---|---|---|
| 0.1 | 0.2 | −48.05〜−43.58% | −47.9〜−42.94% | +0.19〜+0.94ポイント |
| 0.3 | 0.5 | −44.14〜−35.6% | −43.14〜−30.76% | +1.62〜+6.25ポイント |
| 0.5 | 0.8 | −52.63〜−37.54% | −50.89〜−26.23% | **+3.35〜+16.26ポイント** |

（各行は、文面での解決の確率3通り×もう一度来る確率3通りの9通りの範囲。ほかの6行は `results/grid_by_share_use.csv`）
- 81通りで、1件の時間は23.44〜53.91%縮み、もう一度来た割合は+0.19〜+16.26ポイント増えた（81通りすべてで増えた）
- **困りごとあたりの縮みは、81通りすべてで1件の時間の縮みより小さかった（差は0.14〜11.31ポイント、式どおり）**。81通りの中で、困りごとあたりの時間が増えた置き方はなかった（文面で縮む時間を大きく置いたため）
- もう一度来た割合の増えは、解決しなかった人がもう一度来る確率で変わった。込み入った割合0.3・文面を使う割合0.5・文面での解決の確率0.45のとき：

| もう一度来る確率 | もう一度来た割合の増え（記録） | 来なくなった割合の増え（記録に出ない） |
|---|---|---|
| 0.5 | +2.74ポイント | **+3.06ポイント** |
| 0.7 | +3.07ポイント | +1.8ポイント |
| 0.9 | +4ポイント | +0.54ポイント |

- **もう一度来る人が少ない置き方ほど、記録に出る増えは小さく、記録に出ない「来なくなった」増えが大きかった**。もう一度来た割合の増えだけを見ると、文面で片づかなかった分を小さく見積もる

## 注意（言えないこと）
- 架空のデータです。問い合わせの種類の割合、対応の時間、解決の確率、もう一度来る確率と日数は作成者が置いたもので、結果はこれで決まります。とくに、文面で縮む時間を大きく置いたので、困りごとあたりの時間は81通りすべてで縮みました。2回目以降の対応にもっと時間がかかる、文面で縮む時間が小さい、といった置き方では、困りごとあたりの時間が増えることもありえます（推測、この記事では数えていない）
- 来なくなった人は、記録に出ないので、実際の窓口では数えられません。この記事では作成者が知っている値として出しました
- 「もう一度来た」は同じ人の次の問い合わせが同じ困りごとのものだと見分けられると置きました。別の用件で来た分の混ざりは入れていません
- 前と後は同じ置き方の別々の乱数で作り、季節や問い合わせの増減は入れていません
- 決まった文面を使うかどうかの良し悪しは、この記事では決めていません。実在の会社の問い合わせの数字を表すものではありません
