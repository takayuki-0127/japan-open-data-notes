# 166 国内線の座席利用率は、季節でどう変わるか

国土交通省「航空輸送統計調査」の統計表2（国内定期航空月別運航及び輸送実績）から、2016〜2025年の月別の旅客数・座席数・座席利用率を取り出し、季節の型を調べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A166 | 国内線の座席利用率は何月に高く、何月に低いか。その波は旅客数と座席数のどちらから来るか | ふだんの年（2016〜19・2023〜25年）で、年平均からの差と、旅客数・座席数の季節指数（その年の月平均=100）を平均。幹線とローカル線の比較 | `src/a166_season.py` |

## 主な結果
- 座席利用率（総合計）の平均は8月が81.7%で最も高く、1月66.5%・4月68.3%が低い。年平均からの差は 8月 +7.5、1月 −7.7ポイントで、幅は15.2ポイント
- 3月（+3.1）と9〜11月（+3.4〜+4.6）も高く、12月（−2.9）と5〜6月（−2.4〜−2.7）は低め
- 季節指数の幅は、旅客数が28（1月89・8月117）、座席数が15で、利用率の波は主に旅客数の波から来ている
- 幹線は平均78.5%・幅12.3ポイント（最低は4月）、ローカル線は平均70.7%・幅18.1ポイント（最低は1月）
- 年平均（月の単純平均）は2019年73.7% → 2020年47.9%・2021年48.8% → 2025年80.5%で、コロナ前より高い

```bash
pip install -r requirements.txt

```

## データ
| ファイル | 中身 |
|---|---|
| data/domestic_monthly_wide.csv | 区分（総合計・幹線・ローカル線）×年×項目（座席利用率 lf、旅客数 passengers、座席数 seats）の月別の値。旅客数・座席数は総合計のみ |

e-Stat の統計表2（各年のファイル、statInfId）：2016 000031607433、2017 000031730080、2018 000031842368、2019 000031959670、2020 000032104086、2021 000032211478、2022 000040074177、2023 000040191397、2024 000040290548、2025 000040471583。各ファイルの1〜12月の行を使用（13〜15行目は翌年1〜3月で、年度集計用）。

## 注意
- 座席利用率は統計表の値（人キロ÷座席キロ）。月の日数が違うため、2月は旅客数・座席数とも少なく出る
- 季節の型は、コロナの影響が大きい2020〜2022年を除いた7年の平均
- 国内定期航空の合計で、会社別・路線別の違いは見ていない
- 元の Excel は Web ブラウザ上で読み取り、必要な値を CSV に書き写した
