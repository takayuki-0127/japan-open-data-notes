# 226 為替レートと訪日客1人あたりの支出は連動しているか：国籍×年のパネル回帰

観光庁「インバウンド消費動向調査」（旧・訪日外国人消費動向調査）の国籍・地域別「1人1回当たり旅行消費単価」（円）と、FRB H.10 の年平均為替レート（FRED）を組み合わせ、円安が進んだ通貨の国・地域ほど、円で見た支出が増えたかを見たフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A226 | 円安になると、訪日客1人あたりの支出（円）は増えるか。現地通貨で見た支出は変わらないのか | 15か国・地域×年（2019・2023〜2025年）のパネルで、log(支出・円) を log(現地通貨1単位あたりの円) に回帰。国籍の固定効果のみ／国籍＋年の固定効果（標準誤差は国籍でクラスタ）。2022年を加えた版と2023〜25年だけの版。2019→2025年の変化の横断回帰 | `src/a226_fx_spending.py` |

## 主な結果
- 2019→2025年に、現地通貨1単位あたりの円はインド通貨で+10.8%、韓国ウォンで+12.5%、ユーロで+38.6%、シンガポールドルで+43.2%と、通貨によって円安の大きさが違った
- 同じ期間の1人当たり旅行消費単価（円）は、韓国+44%、インド+46%、中国+23%に対し、ドイツ+100%、シンガポール+91%、カナダ+90%。円安の変化と支出の変化の相関は0.53、横断回帰の傾きは0.88（標準誤差0.16）
- 国籍と年の固定効果を入れたパネル回帰の弾力性は0.89（95%信頼区間0.49〜1.28）。「円安1%で円の支出が約1%増える」＝現地通貨では同じくらいの額を使う、という形と矛盾しない（1との差は p=0.58）
- 年の固定効果を入れないと1.73になる。全ての国・地域に共通する支出の増加（物価の上昇やコロナ後の旅行の変化）を除かないと、為替の効き方を大きく見積もってしまう
- 現地通貨で見た支出も、2019→2025年に中国（−6.5%）以外の14か国・地域で増えた（+12〜46%）

## 動かし方
```
pip install -r requirements.txt
cd src && python a226_fx_spending.py
```

## データ
- `data/spend_per_person.csv`：国籍・地域別の1人1回当たり旅行消費単価（円）。2019・2022・2023・2024・2025年の暦年集計表の表3-1「全体」行（観光庁）
- `data/fred_annual_fx_raw.csv`：FRED の年平均為替レート（AEXJPUS ほか12系列、1ドルあたり現地通貨、ポンドとユーロは1単位あたりドル）
- `results/panel_nationality_year.csv`：分析に使った国籍×年のデータ（現地通貨1単位あたりの円、現地通貨で見た支出）
- `results/regressions.csv`・`cross_section_2019_2025.csv`・`change_2019_2025.csv`：回帰の結果と2019→2025年の変化

## 注意
- FRB H.10 に年平均がない通貨（インドネシア・フィリピン・ベトナム・ロシア）と、系列がとれなかったオーストラリアは除き、15か国・地域で分析しています。ユーロ圏の4か国は同じ為替レートです
- 2020・2021年は調査がほぼ行われていません。2022年は入国制限が残り、回答者の構成がふだんと違うため、本体の推定からは除き、加えた版を参考に示しています
- 2024年から調査の名前と方法の一部が変わっています（インバウンド消費動向調査）
- 消費単価は調査の回答から推計した値で、国・地域によって回答者数が少ないものがあります。滞在日数の変化などは調整していません
- 年平均の為替レートと、旅行した時期の為替レートは一致しません
