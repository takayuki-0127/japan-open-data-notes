# 230 酒類の支出は、ビールから何に移ったのか

総務省統計局「家計調査」（二人以上の世帯）の「酒類」と8つの品目（ビール・発泡酒やビール風・チューハイやカクテル・焼酎・清酒・ワイン・ウイスキー・他の酒）について、2015〜2025年の1世帯当たり年間支出の割合と、年報の購入数量（L）で見た量の変化を調べたフォルダです。世帯主の年齢別の中身も出しました。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A230 | お酒の支出の中身は、どの品目からどの品目へ移ったのか。量でも同じことが言えるのか | 酒類に占める品目の割合（2015〜2025年）／年報 第4-6表（平均）の購入数量（2019〜2025年、L に換算）とビール系の合計／1Lあたりの平均価格／世帯主の年齢別の割合（2019・2025年）／2026年1〜9月の前年同期比 | `src/a230_alcohol.py` |

## 主な結果
- 酒類の支出は2015年の41,300円から2025年の45,407円へ。物価（CPI 酒類）で割った実質では、2015年の94.7%、2019年の98.5%
- 割合（2015→2025年）：ビール26.6%→29.6%、発泡酒・ビール風22.6%→16.6%、チューハイ・カクテル5.3%→12.4%、ウイスキー4.1%→6.4%。焼酎（16.2%→12.4%）、清酒（14.4%→12.1%）、ワイン（8.3%→7.4%）は下がった
- 量（2019→2025年）：ビール19.4L→25.1L（+29%）、発泡酒・ビール風27.2L→18.4L（−32%）。ビールと発泡酒・ビール風を合わせたビール系は46.6L→43.5L（−7%）で、ビールが増えた分より発泡酒・ビール風が減った分の方が大きかった。チューハイ・カクテルは+35%、ウイスキーは+39%、焼酎−15%、清酒−13%、ワイン−17%
- 1Lあたりの平均価格は、ビールが552円→535円と下がり、発泡酒・ビール風は325円→410円と上がった。2020・2023年の酒税の見直し（ビールは下げ、ビール風は上げ）の向きと合う（推測：税以外の値上げも含む）
- 年齢別（2025年）：チューハイ・カクテルの割合は30代で23%、70歳以上で6%。焼酎・清酒は70歳以上でそれぞれ17%。2019年から発泡酒・ビール風の割合が大きく下がったのは30代（−13.6ポイント）と40代（−9.1ポイント）
- 2026年1〜9月は前年同期比で、発泡酒・ビール風+8.2%、ビール−3.1%、焼酎−8.1%、酒類全体+0.1%。2026年10月の酒税の一本化（ビールは下げ、発泡酒・ビール風は上げ）の前の動きで、一本化の後の変化はこの分析に入っていない

## 頑健性
- 2025年改定で「発泡酒・ビール風アルコール飲料」は「発泡酒」に名前が変わった。名前が変わる前の2024年までで比べても、2019→2024年の量はビール+26%、発泡酒・ビール風−25%、ビール系の合計−4%で、向きは同じ。月の表でも2024年12月から2025年1月にかけて、季節の動き以上の段差は見えない
- 品目の割合の合計は、すべての年で酒類の100%と一致した（ずれ0.0ポイント）
- 年報の購入数量は二人以上の世帯の平均で、ビール・発泡酒系は L、ほかは mL の単位で公表されている。図と表では L にそろえた
- コードはきれいなフォルダで3回動かし直し、results の全ファイルが一致することを確かめた

## 動かし方
```
pip install -r requirements.txt
cd src && python a230_alcohol.py   # data/ から results/ と figures/ を作る
python fetch.py                     # data/ を e-Stat から作り直す（任意）
```

## データ
- `data/kakei_annual.csv`・`kakei_monthly.csv`：酒類と8品目、飲酒代の支出（年・月、2015年〜2026年9月）
- `data/kakei_detail.csv`：年報 第4-6表（世帯主の年齢階級別）の支出・購入数量・平均価格（2019〜2025年）
- `data/cpi_annual.csv`：消費者物価指数（2020年基準）の酒類と品目別（このリポジトリの F209 から抜き出した）

## 注意
- 家で飲むために買ったお酒（家計の支出）で、外食の飲酒代は含まない
- 二人以上の世帯の結果で、単身世帯は含まない。29歳以下の世帯は集計世帯数が約100と少なく、年齢別の割合は年ごとに大きく振れる（2019→2025年のチューハイ・カクテルの割合が29歳以下だけ−13ポイントなど）
- 税の変更の前後の駆け込みと反動は [F283](../F283_price_hike_front_loading) で扱った。この記事は10年の流れを見るもので、税の効果を取り出してはいない
