# 162 介護をしながら働く人は5年でどれだけ増えたか：就業構造基本調査（2017・2022年）

総務省「就業構造基本調査」の全国結果（平成29年 第227-3表、令和4年 第211-3表）から、介護をしている有業者の数と、有業者に占める割合を年齢・男女別に比べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A162 | 介護をしながら働く人は、5年でどれだけ、どの年齢で増えたか | 2017・2022年の人数と割合の差分比較（年齢を2017年の区分にそろえる）、雇用形態（正規・非正規）の比較 | `src/a162_carers.py` |

## 主な結果
- 介護をしている有業者は 2017年 346.3万人 → 2022年 364.6万人（+18.3万人、+5.3%）。男性 151.5万→156.6万、女性 194.8万→208.1万
- 増えたのは 50〜54歳（+8.3万）、55〜59歳（+8.3万）、60〜64歳（+7.0万）、70歳以上（+6.4万）。40歳未満は −2.9万
- 有業者に占める割合は 5.23% → 5.44% とほぼ横ばい。2017年の年齢別の割合のまま2022年の働く人の年齢構成にすると361.5万人になり、増加18.3万人のうち15.1万人（83%）は、介護をする年齢（50〜60代）の働く人が増えたことで説明できる
- 割合が最も高いのは55〜59歳の女性で16.0%（2017年も15.9%）。60〜64歳の女性は13.3%→15.2%に上がった
- 役員を除く雇用者のうち非正規の割合は、介護をしている女性61.1%（全体53.2%）、男性26.6%（全体22.1%）（2022年）

## 動かし方
```bash
pip install -r requirements.txt

```

## データ
| ファイル | 中身 |
|---|---|
| data/workers_by_care.csv | 年、男女、年齢、介護の有無（総数／介護をしている）、有業者数、うち雇用者、正規の職員・従業員、非正規の職員・従業員（人） |

e-Stat の Excel（2022年 statInfId=000040077493、2017年 statInfId=000031729600）をブラウザで読み、必要な行を書き写しました。

## 注意
- 年齢区分は2017年の表（30歳未満、30〜39歳、40〜44歳…65〜69歳、70歳以上）にそろえています
- 「介護をしている」は、調査票で「ふだん家族の介護をしている」と答えた人で、介護の頻度や時間は問いません
- 介護をしていて働いていない人（無業者）はこの表に入っていません。介護のために仕事を辞めた人の数は別の表で調べる必要があります
- 標本調査による推計値です
