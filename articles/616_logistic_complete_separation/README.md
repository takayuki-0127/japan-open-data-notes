# 616 ロジスティック回帰で、ある区分の全員が同じ結果だと、係数と区間はどうなるのか（手法の解説・正解の分かるデータで試す）

ロジスティック回帰で、件数の少ない区分の全員が成約（または全員が不成約）だと、その区分の係数は大きくなるほど当てはまりがよくなり、最尤法の答えが無限大に向かいます（完全分離）。ソフトは警告を出すか、大きな係数と巨大な標準誤差を返します。**ここでは、架空の申込みデータ（流入経路5区分、A300件・B150件・C100件・D40件、区分 E の件数を5〜40で変える）で、E の本当の成約率75%（係数の本当の値1.6）のとき、完全分離がどれだけ起き、最尤法・Firth の補正・区分をまとめる方法で係数がどうなるかを、各2,000回のシミュレーションで数えました。** 数字は置いた前提で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A616 | 件数の少ない区分で、完全分離がどれだけ起き、係数と区間がどうなるか | ML ふつうの最尤法（ニュートン法50回まで）、FI Firth の補正（罰則つき尤度、区間は Wald で簡略化）、MG E を D とまとめる。分離のないデータで自作の最尤法が statsmodels と一致することを確認。各2,000回、seed 616 | `src/a616_separation.py` |

## 主な結果
- **完全分離の起きた割合**：E が5件で24.5%、8件で9.0%、12件で2.6%、20件で0.3%、40件で0%
- **分離した回の最尤法**：係数は50を超え（打ち切りまで伸び続ける）、標準誤差は70万を超えた。区間は「本当の値を含む」が、幅が事実上無限で役に立たない
- **係数の誤差の平均（本当の1.6との差）**：最尤法は E が5件で12.7、8件で5.0、12件で1.8。Firth は0.71、0.63、0.52
- **Firth の補正**：分離した回でも係数は有限（中央値 5件で2.9、8件で3.3）、標準誤差は1.5〜1.6。分離していない回では係数をやや小さめに出す（5件で平均1.13）
- **95%区間が本当の値を含んだ割合**：どちらも96〜98%。最尤法は分離した回の巨大な区間で「当たって」いる
- **E を D とまとめる**：係数は D と E の中間の値（中央値0.6〜1.0）になり、E だけの効果は分からなくなる

```
pip install -r requirements.txt

```
1分ほどで終わります。

## 確かめたこと
- 空のフォルダで流し直し、results・figures がバイト単位で一致した（reps.csv.gz は圧縮の時刻を0に固定）
- 分離のないデータで、自作の最尤法の係数と標準誤差が statsmodels の Logit と一致した
- E が40件（分離なし）では、最尤法と Firth がほぼ同じ値になること

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 616）
- 仮定：成約するかどうかは区分ごとの成約率で決まる（A 37.8%・B 45.0%・C 33.2%・D 50.0%・E 75.0%）。ほかの説明変数は入れていない

## 注意（言えないこと）
- シミュレーションの結果。区分の件数と成約率は作成者が置いたもので、結果はこれで決まる
- Firth の区間は、ここでは簡略に Wald で出した。ふつうはプロファイル尤度で出す
- 区分の件数が少ないこと自体は直らない。どの方法でも、5件の区分の成約率の見積もりは大きく揺れる
