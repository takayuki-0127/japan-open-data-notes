# F514 事前の計画（PLAN）

作成：2026-11-16 13:10（JST）。結果を集計する前に書いた。

## 問い
家のインターネットは、光回線（固定）と携帯電話の回線（スマホの回線・ホームルーター）のどちらに移ったのか。固定の回線を使わない家は増えたのか。どんな世帯で違うのか。

## 知りたい人
家のネットの契約を考える人、通信の商品やサービスを企画する人、「若い人や一人暮らしは光回線を引かない」という話の大きさを確かめたい人。

## データ
- 総務省「通信利用動向調査」世帯全体編「問２ 自宅でインターネットを利用する世帯の接続回線」（2019〜2025年の7回）。対象は過去1年にインターネットを使った世帯。複数回答の割合（%）で、世帯主の年齢・世帯人員・世帯類型・世帯年収・都市区分・地方別がある。
- 2018年以前は問いの文が違う（「パソコン等から」）ので使わない。2024年から選択肢に「ホームルーター」が加わった。
- 総務省「情報通信統計データベース」ブロードバンドサービス等の契約数（2023年6月末〜2026年6月末の四半期）。FTTH（光回線）の契約数で、調査の割合の動きと照らす。

### 取得前に見たもの（下見）
- 2019年と2025年の表の「全体」「世帯主年齢」「世帯主性別」の行（表の形を確かめるため）。2019年：固定系ブロードバンド69.2%、光回線51.9%、携帯電話回線48.4%。2025年：固定系76.6%、光回線58.8%、携帯電話回線71.5%。
- 2025年の世帯人員・世帯類型・世帯年収・都市区分・地方の行も見た（2025年の単身の固定系は57.7%）。
- 2020〜2024年の値、2019年の世帯人員・年収などの行は見ていない。

## 仮説（外れの基準つき）
- H1：携帯電話回線の割合は、2020〜2025年の毎年、前年より高い。外れ：1年でも前年以下。
- H2：単身世帯の固定系ブロードバンドの割合は、2019年より2025年の方が低い。外れ：2025年の方が高いか同じ。
- H3：固定系ブロードバンドの割合の、世帯年収200万円未満と1000〜1500万円未満の差は、2019年より2025年の方が小さい。外れ：同じか大きい。
- H4：選択肢にホームルーターが加わった2024年に、携帯電話回線の割合は2023年より5ポイント以上上がった（選択肢の変更の影響を疑う）。外れ：5ポイント未満。

## 手法
- 回線の種類ごとの割合（複数回答）の推移。
- 固定系を使わない世帯の割合の目安＝100−固定系−無回答（携帯だけ・契約していない・その他を含む）。
- 世帯の属性別の比較（若い順・人数の少ない順・年収の低い順・北から南。順位は作らない）。
- FTTH の契約数の推移と照らす。

## 頑健性（3つ以上）
1. 選択肢が同じ2019〜2023年に限って変化を見る。
2. 無回答を除いた割合（無回答で割り戻す）でも見る。
3. 世帯主の年齢別、世帯類型別（単独・非高齢）でも同じ向きか。
4. FTTH の契約数（事業者の報告）と並べる。

## 言えないこと（予想）
- 複数回答なので、「携帯の回線だけ」の世帯の割合は直接は分からない（目安だけ）。
- 回答者が回線の種類を正しく区別しているかは分からない（ホームルーターと光回線の区別など）。
- 調査は抽出調査で、属性別の値は標本が少ない層で振れる。
- 料金や速度の比較はしない（助言はしない）。
