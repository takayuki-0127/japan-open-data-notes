# 1005 項目を足す前のそろえ方（標準化・順位・最大値）で、順位は変わるのか？（指数とスコア）

製品や店の「総合スコア」は、単位の違う項目（W・分・kg・dB など）を足して作ります。そのまま足すと単位の大きい項目ばかり効くので、足す前に項目ごとに「そろえる」処理をします。平均を引いて標準偏差で割る（標準化）、順位に直す、いちばん大きい値で割る、最小を0・最大を1にする、のどれも見かけます。重みを「均等」と書いても、そろえ方が違えば合計の順位は変わります。**ここでは、作成者が乱数で作った架空の掃除機30機種（4項目の「もとの良さ」と、単位の違う測った値への直し方を作成者が置いたもの）で、4通りのそろえ方で均等に足した合計の順位を比べ、1位・上位5機種がどれだけ入れ替わるか、各項目が実際にどれだけ効いているかを数えました。**

重みの選び方で順位が入れ替わることは関連する記事 939（人事評価）で、同じ企画の 1006 は基本の重みを少しだけ動かしたときを扱っています。この記事は、重みを均等のまま変えずに、足す前のそろえ方だけを変えたときに絞ります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A1005 | 単位の違う4項目を均等に足すとき、足す前のそろえ方（標準化・順位・最大値で割る・最小〜最大で0〜1）で、1位・上位5機種はどれだけ入れ替わるか。各項目は実際にどれだけ効いているか | 架空の掃除機30機種。機種ごとに4項目の「もとの良さ」を、平均0・標準偏差1・項目どうしの相関0.3の多変量正規分布から引いた。測った値は、吸う力＝150W×exp(0.35×良さ)（右に長い）、動く時間＝40分＋8分×良さ、重さ＝2.5kg−0.25kg×良さ（軽いほど良い）、音＝65dB−3dB×良さ（静かなほど良い）。そろえ方は (1) 標準化：平均を引いて標準偏差で割る、(2) 順位：良い順に30〜1、(3) 最大値で割る：大きいほど良い項目は値÷最大値、小さいほど良い項目は最小値÷値、(4) 最小〜最大で0〜1：（値−最小）÷（最大−最小）（小さいほど良い項目は1から引く）。4項目を均等（各1/4）に足した合計で順位を付けた（同点は同じ順位）。機種の組を1,000回作り直して数えた。「実際の効き」は、合計の散らばり（分散）のうち各項目が占める分（項目と合計の共分散÷4÷合計の分散）。「本当の良さ」は、4項目のもとの良さの均等な平均と作成者が置いたもの。確かめとして、項目どうしの相関（0・0.3・0.6）、吸う力の右への長さ（0（左右対称）・0.35・0.7）、音の散らばり（1.5・3・6dB）、機種の数（10・30・100）を1つずつ変え、各500組で数えた。項目どうしの相関0のとき、「最大値で割る」の実際の効きを式（そろえた値の分散の割合）でも出して比べた。seed 1005 | `src/a1005_normalize_rank.py` |

## 主な結果

### 例の30機種（`results/example_ranks.csv`）
| そろえ方 | 上位5機種（機種の番号、上から） |
|---|---|
| 標準化 | 24・3・28・20・29 |
| 順位 | 24・3・29・28・1 |
| 最大値で割る | 24・3・20・28・7 |
| 最小〜最大で0〜1 | 24・3・28・20・29 |
| （本当の良さ） | 24・3・29・30・28 |

- 例の1組では、1位（24番）と2位（3番）は4通りで同じだった。4通りのどれかで上位5機種に入った機種は7機種
- 4通りの中で順位が5つ以上動いた機種は30機種のうち5機種、いちばん大きく動いた機種（4番）は7つ動いた。上位10位に1度でも入った12機種のうち、5つ以上動いたのは3機種（図1）
- 順位に直して足すと同点が出やすく、例の組では9位に3機種が並んだ

### 1,000組で（基本の置き方、`results/a1005_main.json`）
| 数えたもの | 値 |
|---|---|
| 1位が4通りのそろえ方で同じ1機種だった組 | **51.2%** |
| 4通りのどれかで1位になった機種の数（平均） | 1.578機種 |
| 4通りのどれかで上位5機種に入った機種の数（平均） | 6.511機種 |
| 4通りの中で、いちばん大きく動いた機種の順位の動き（平均） | 8.97 |

- **1位が4通りのそろえ方で同じだったのは、半分ほど（51.2%）の組だけだった**。残りの組では、どのそろえ方を選ぶかで1位が変わった

### そろえ方ごと（1,000組の平均、`results/by_method.csv`）
| そろえ方 | 標準化との上位5機種の重なり | 吸う力の効き | 動く時間の効き | 重さの効き | 音の効き | 本当の上位5機種に入っていた割合 | 1位が本当の1位 |
|---|---|---|---|---|---|---|---|
| 標準化 | 5機種 | 24.8% | 25.0% | 25.1% | 25.1% | 93.6% | 87.1% |
| 順位 | 4.308機種 | 25.0% | 25.0% | 25.0% | 25.0% | 87.4% | 72.5% |
| 最大値で割る | **4.073機種** | **46.6%** | 31.8% | 15.1% | **6.5%** | 79.3% | 63.7% |
| 最小〜最大で0〜1 | 4.796機種 | 24.7% | 25.1% | 25.2% | 25.1% | 92.4% | 85.9% |

- **「最大値で割る」では、名目は均等でも、音の効きは6.5%、吸う力の効きは46.6%だった**。最大値で割った値の散らばりは「標準偏差÷最大値」で決まり、音（65dB前後で±3dB）のように水準に比べて散らばりの小さい項目は、狭い幅に詰まるため（例の組では、最大値で割った音は0.808〜1、吸う力は0.323〜1）
- 項目どうしの相関0のとき、「最大値で割る」の効きは式（そろえた値の分散の割合）の値とほぼ同じだった（式：吸う力53.7%・動く時間32.3%・重さ11.1%・音2.9%、数えた値：54.3%・32.0%・10.9%・2.8%、差は0.61ポイント以内）。この効きの偏りは、作成者が置いた単位と散らばりからの**式どおり**の値です
- 標準化・順位・最小〜最大の3つは、1,000組の平均ではどの項目もほぼ25%ずつ効いた。それでも上位5機種は、標準化と順位で平均4.308機種、標準化と最小〜最大で平均4.796機種しか重ならなかった。順位に直すと値の差の大きさが消え（1位と2位の差も、15位と16位の差も同じ1）、最小〜最大は各組の端の機種で目盛りが決まるため
- 「本当の上位5機種に入っていた割合」は標準化がいちばん高かったが、本当の良さを「もとの良さ（平均0・標準偏差1）の均等な平均」と作成者が置いたので、標準化が近くなるのは作りどおりです。言えるのは、そろえ方を変えると上位が入れ替わること、「最大値で割る」は名目の重みから大きくずれることまでです

### 確かめ：置き方を1つずつ変えると（各500組、`results/robustness.csv`）
| 変えたもの | 値 | 1位が4通りで同じ | 標準化と「最大値で割る」の上位5の重なり | 「最大値で割る」での音の効き | 本当の上位5に入った割合（標準化・順位・最大値・最小〜最大） |
|---|---|---|---|---|---|
| 項目どうしの相関 | 0 | 32.8% | 3.65機種 | 2.85% | 90.0%・82.48%・70.08%・88.68% |
| | **0.3（基本）** | 49.4% | 4.044機種 | 6.56% | 94.08%・88.0%・78.28%・93.08% |
| | 0.6 | **70.4%** | 4.376機種 | 8.23% | 96.52%・91.16%・85.52%・95.44% |
| 吸う力の右への長さ | 0（左右対称） | 56.6% | 4.058機種 | 6.23% | 95.8%・87.0%・81.56%・94.4% |
| | **0.35（基本）** | 53.0% | 4.062機種 | 6.58% | 93.64%・87.16%・79.68%・93.0% |
| | 0.7 | 41.4% | 3.972機種 | 5.86% | 90.52%・86.72%・74.48%・89.88% |
| 音の散らばり | 1.5dB | 42.6% | 3.944機種 | 3.12% | 94.32%・86.28%・76.24%・92.84% |
| | **3dB（基本）** | 50.0% | 4.11機種 | 6.62% | 93.72%・86.4%・79.88%・93.12% |
| | 6dB | 57.0% | 4.256機種 | 12.87% | 93.56%・86.52%・82.84%・92.52% |
| 機種の数 | 10 | 61.4% | 4.41機種 | 5.96% | 95.56%・92.12%・88.88%・94.92% |

| | 100 | 44.4% | 3.914機種 | 7.18% | 89.68%・79.12%・71.32%・88.24% |

- **1位が4通りで同じだった割合は、置き方で32.8〜70.4%と動いた**。項目どうしの結びつきが弱いほど、吸う力の右への長さが長いほど、機種が多いほど、1位はそろいにくかった
- 「最大値で割る」での音の効きは、12通りのどれでも名目の25%を大きく下回った（2.85〜12.87%）
- 本当の上位5機種に入った割合は、12通りすべてで「最大値で割る」がいちばん低かった
- 基本の置き方は、変えたものごとに乱数を変えて数え直したので、1,000組の値（51.2%）から少し動く（49.4〜53.0%）

## 注意（言えないこと）
- 架空のデータです。項目の数、単位と散らばり、項目どうしの相関、吸う力の右への長さ、機種の数は作成者が置いたもので、結果はこれで決まります。1位が4通りで同じだった割合は、置き方で32.8〜70.4%と動きました。実際の製品の比べ方や採点を表すものではありません
- 「どのそろえ方が正しいか」は言えません。本当の良さを「もとの良さの均等な平均」と作成者が置いたので、それに近いのは標準化になる作りです。本当の良さの決め方を変えれば（たとえば吸う力を重く見るなら）、近いそろえ方も変わります
- 「最大値で割る」の効きの偏りは、置いた単位と散らばり（音は65dB前後で±3dB）からの式どおりの値です。言いたいのは、名目の重みと実際の効きは、そろえ方によっては一致しないということです
- 測った値は、もとの良さをまちがいなく映すと置きました。測り方の誤差や、外れた値1つの効き方は入れていません（外れた値1つでそろえ方ごとに順位がどれだけ動くかは、同じ企画の 1011 で扱っています）
- 関連する記事：939（項目の重みで順位が入れ替わるか）は、重みの選び方を変える話です。906（割合の差と比で上位の店が変わるか）は、比べ方で並びが変わる話を割合で扱っています。同じ企画の 1006 は、基本の重みを少しだけ動かしたときに上位が何位入れ替わるかを扱っています。1011 は外れた値1つがそろえ方を通してほかの製品の順位まで動かす話、1012 は10点満点と100点満点の項目を「満点をそろえて」足す話で、満点で割るのはこの記事の「最大値で割る」に近く、効き方が点の散らばりで決まる点も同じです。1012 は意図した重みとのずれに絞り、この記事は4通りのそろえ方で1位・上位5機種がどれだけ入れ替わるかに絞りました。似た項目の数で実際の効きがずれる話は 1008、足し算か掛け算かは 1015 で扱っています
