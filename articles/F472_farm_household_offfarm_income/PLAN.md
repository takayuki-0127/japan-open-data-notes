# F472 PLAN（事前の計画）：農家の暮らしは、農業以外の所得にどれだけ頼っているのか？

作成：2026-11-18 20:35（02_build.py で表を組んだあと、03_analysis.py を書く前）

## 問い
農業をしている世帯（個人の経営）の総所得のうち、農業から来る分はどれだけで、農業以外の仕事の所得（農外所得）と年金等の収入はどれだけか。その割合は2004〜2018年にどう変わったか。主業・準主業・副業的（農業の所得が主かどうか、65歳未満で年60日以上農業をする人がいるか、で分けた区分）と、経営耕地の広さで、どれだけ違うか。

知りたい人：農業・農村の統計を読む人、地域の金融機関や農協で農家の家計を見る人、農業の担い手の話をする人。「日本の農家の多くは兼業で、農業の所得は暮らしの一部」とよく言われるが、どの層でどれだけかを数字で並べた資料は少ない。

## データ
- 農林水産省「農業経営統計調査 経営形態別経営統計（個別経営）」（e-Stat）
  - 長期累年：全国年次別統計表 (1) 経営の概要と分析指標（2004〜2018年）
  - 各年：農業の主副業別統計表、都府県の経営耕地規模別統計表の「経営の概要と分析指標」（2004〜2018年）
- 2019年からは調査が「個人経営体」に変わり、農外所得と年金等の収入を集めなくなった（2019〜2024年の表を開いて、農外所得・年金・総所得の項目がないことを確かめた）。このため、この記事は2018年までを扱う。

## 取得前・組み立てで見たもの（開示）
- 02_build.py の確かめで、全国の長期累年の表の値（2004〜2018年の農業所得・農外所得・年金等・総所得）を全部見た。
- 主副業別と都府県の規模別は、2004年と2018年の行を見た（主業の農業所得 4,375→6,616千円、副業的の年金 1,876→2,190千円 など）。2005〜2017年の値は見ていない。割合・分解・傾きは計算していない。

## 定義（事前に決める）
- 農業の割合 = （農業所得 + 農業生産関連事業所得）÷ 総所得。総所得 = 農業所得 + 農業生産関連事業所得 + 農外所得 + 年金等の収入（表の定義。02 で4つの和が総所得に一致することを確かめた）。
- 1経営体あたりの平均（千円、名目）。

## 手法
- M1：全国の割合の推移と、2004→2018年の変化を「農業所得の増え」「農外所得の減り」「年金等の増え」に分ける（割合 s = A/T の変化を、平均の点のまわりで1次の式に分け、残りは「交差の項」とする）。
- M2：主副業別の割合の推移（2004〜2018年）。
- M3：都府県の規模別に、農業の割合が5割を超える最も小さい規模区分を年ごとに出す。

## 仮説と「外れ」の基準
- H1：全国の農業の割合は、2004年から2018年に5ポイント以上上がる。5ポイント未満なら外れ。
- H2：その上がり方のうち、「農外所得の減り」の寄与が「農業所得の増え」の寄与より大きい。小さければ外れ。
- H3：主業では農業の割合が15年すべてで75%以上、副業的では15年すべてで15%以下。どれか1年でも外れれば外れ。
- H4：都府県で農業の割合が5割を超える最も小さい規模区分は、15年を通して同じ（3.0〜5.0ha）か、隣の区分までの動きにとどまる。2つ以上動く年があれば外れ。

## 頑健性（3つ以上）
1. 定義を替える：年金等を除いた「農業依存度」（農業所得÷（農業所得＋関連事業所得＋農外所得））で H1 と H3 を見る。
2. 2008年に調査の設計が変わり、集計の経営体数が約6,900から約4,700に減った。2008〜2018年だけで H1・H2 を見る。
3. 年の振れを抑える：2004〜2006年の平均と2016〜2018年の平均で H1・H2 を見る。
4. 2007年を、税制改正前の減価償却で計算した値（表に併記）に替える。

## 言えないこと（予想）
- 平均値なので、世帯ごとのばらつきは分からない。
- 2019年以降は分からない（調査の項目がない）。
- 主業・副業的などの区分の中身（経営体の入れ替わり）は追えない。毎年の標本は同じ経営体ではない。
- 物価で割っていない（名目）。
