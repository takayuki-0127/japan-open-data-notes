# 399 世帯の貯蓄は、年齢でどう積み上がっているのか（全国家計構造調査、2014・2019・2024年）

世帯主の年齢（5歳きざみ）ごとの貯蓄と負債を、平均と中央値で並べたフォルダです。対象は総世帯です。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A399 | 貯蓄の中央値は年齢でどう変わるか。平均とどれだけ違うか。負債が貯蓄を上回る年齢はどこか | 第6-108表（世帯主の年齢階級×貯蓄現在高階級の世帯数分布）から、階級の中を一様と置いて中央値・四分位を計算。平均は表の値。2024年の第4-4表で負債の内訳。2014年（遡及集計）・2019年と比べる | `src/a399_savings.py` |

## 主な結果
- 2024年の中央値（万円）：30歳未満146、30〜34歳284、35〜39歳439、40〜44歳516、45〜49歳559、50〜54歳604、55〜59歳786、60〜64歳1,193、65〜69歳1,138、70〜74歳991、75〜79歳991、80〜84歳813、85歳以上783
- 平均÷中央値は年齢ごとに1.9〜2.4倍。全体は平均1,527万円、中央値615万円（2.5倍）
- 60〜64歳：下から4分の1が358万円、上から4分の1が3,103万円。100万円未満14%、2,000万円以上37%
- 負債の平均は40〜44歳の1,183万円が山（うち住宅・土地のため1,104万円）。貯蓄−負債は30〜34歳−229万円、35〜39歳−268万円、40〜44歳−92万円、45〜49歳+161万円
- 全体の中央値：2014年698万円→2019年541万円→2024年615万円。平均は1,393→1,280→1,527万円

## 確かめたこと
- 階級の世帯数の合計が総数と一致（2019・2024年。2014年は全体で1.6%、年齢ごとに最大3.7%足りず、その分は階級が分からない世帯として除いた）
- 第4-4表と第6-108表で、全体の貯蓄・負債の平均が一致
- 空のフォルダで流し直し、data・results・figures が一致した

## データ
- `data/raw/kakei2024_t6_108_total.csv`・`kakei2024_t4_4_total.csv`：e-Stat「令和6年全国家計構造調査」第6-108表（statInfId=000040514305）・第4-4表（000040488257）から、総世帯・全世帯・男女計の行だけを抜いたもの（2026-11-12 取得）
- `data/raw/kakei2019_t6_108_total.csv`：「2019年全国家計構造調査」第6-108表（000032133730）の同じ行
- `data/raw/kakei2014retro_t6_108_total.csv`：平成26年全国消費実態調査の、2019年の方法による遡及集計 第6-108表（000032134109）の同じ行
- `data/savings_by_age.csv`・`data/assets_debt_2024.csv`：計算した表。金額は万円

## 注意（言えないこと）
- 同じ世帯を追った数字ではありません。年齢による違いと、世代による違いは分けられません
- 中央値は階級から計算した大まかな値です。いちばん上の階級（1億円以上）は2024年に1.7%です
- 世帯主の年齢で分けています。世帯の人数や働き方の違いは分けていません。貯蓄に住宅・土地などは入りません
- 貯蓄や投資についての助言ではありません
