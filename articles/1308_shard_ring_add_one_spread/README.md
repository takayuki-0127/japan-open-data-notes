# 1308 動くデータを少なくする振り分け（番号を輪の上に並べて、時計回りに次の台へ置く形）で1台足すと、動く量は少なくなっても、台ごとの受け持ちの量はどれだけばらつくのか？（データの振り分け）

「番号を台数で割った余り」で置く台を決めると、1台足しただけでほとんどのデータの置き場所が変わります。これを避ける決め方が「輪の上に並べる振り分け」です。データにも台にも輪の上の位置を決め、データは輪を時計回りに進んで最初に出会う台に置きます。1台足しても、動くのは新しい台の手前の区間のデータだけです。けれども、台の位置もでたらめに決まるので、台どうしの間隔はそろわず、受け持ちの量は台ごとに大きく違います。**ここでは、作成者が置いた架空のアプリのデータ10万件を10台に置き、1台を輪の上に1か所だけ置く形で、①1台足したときに動くデータの割合、②台ごとの受け持ちのばらつき（いちばん多い1台÷平均、いちばん少ない1台÷平均）、③1台足したとき、いちばん多い1台の受け持ちが減るかを、台の位置を作り直して2,000回数えました。台数（5〜100台）とデータの件数（1万〜100万件）を変えた15通りでも確かめました。実機では測っていません。**

例のアプリ・数は架空のもので、実在のデータベース・機械を表すものではありません。台数や費用の見込みの助言はしていません。

関連する記事：1305「1万件のデータを乱数で10台に振り分けると、いちばん多い1台の件数は平均の何倍になるのか？」は、1件ずつ置く台を乱数で決めたときの偏りを扱っています。1306「データの件数を変えずに、振り分ける台数を10台から100台に増やすと、いちばん多い1台と平均の比はどう広がるのか？」は、同じ置き方で台数を増やしたときの比の広がりを扱っています。1307「「番号を台数で割った余り」で置く台を決める振り分けで1台足すと、置き場所が変わるデータは全体の何割になるのか？」は、割った余りで決めると1台足しただけで大半のデータが動くことを扱っています。1309「輪の上に1台を何か所に分けて置くかで、いちばん多い1台の受け持ちはどれだけ平均に近づくのか？」は、この記事の1台1か所の置き方を、何か所にも分けて置くとばらつきがどれだけ縮むかを扱っています。1270「分けた仕事の大きさがばらつくと、全体の時間はいちばん遅い1つでどれだけ延びるのか？」は、分けた組の大きさのばらつきを、処理の時間で扱っています。1314「1台が止まって、輪の上で次の台がその分をまるごと受け持つと、受け持つ台の量は平均の何倍になるのか？」は、同じ輪の上に並べる振り分けで、1台足すのではなく1台が止まったとき、その分をまるごと受け持つ次の台がどれだけ重くなるかを扱っています。この記事は、輪の上に1台1か所で置いたときの、動く量と受け持ちのばらつきの両方に絞ります。

## 主な結果

### 基本の置き方（10万件・10台・1台1か所、2,000回、`results/a1308_main.json` の `base`）
| | 値 |
|---|---|
| 1台足したときに動いた割合（平均） | **9.04%**（受け持ちがそろうときの9.09%に近い） |
| 動いた割合（中央値・10〜90%） | 6.93%（1.03〜20.0%）、いちばん多い回は63.94% |
| 動いた割合が9.09%の半分未満だった回 | 36.6% |
| 動いた割合が9.09%の2倍を超えた回 | 12.5% |
| 動いたデータを渡した台が1台だけだった回 | 100.0%（作りどおり） |
| いちばん多い1台÷平均（10台のとき） | **2.944倍**（10〜90%で2.042〜4.055倍、目安の式2.929倍） |
| いちばん少ない1台÷平均 | 平均0.099倍（中央値0.073倍） |
| 台ごとの件数の散らばり（標準偏差÷平均） | 0.879 |
| いちばん多い1台÷平均（11台にしたあと） | 3.029倍（目安の式3.02倍） |
| 足した台が、いちばん多い1台からデータを受け取った回 | **29.5%** |
| いちばん多い1台の件数が、足しても変わらなかった回 | **70.5%** |
| いちばん多い1台の件数（平均） | 足す前29,437.1件 → 足したあと27,534.9件（1回ごとの減り方の平均5.67%） |

- 1台足したときに動いた割合は、平均では9.04%で、受け持ちがそろうときの1÷11（9.09%）に近かった。けれども1回ごとには1.03〜20.0%（10〜90%）と散らばり、36.6%の回では9.09%の半分にも届かなかった。足した台が受け持つ量そのものが、でたらめに決まるため
- 動いたデータは、毎回1台（足した台の時計回り側のとなりの台）からだけ来た。1台1か所で置くと、足した台はとなりの1つの区間を分けるだけなので、作りどおり
- 10台のとき、いちばん多い1台は平均の**2.944倍**、いちばん少ない1台は平均の0.099倍だった。1件ずつ乱数で置く形（1305）とちがい、データが10万件あっても、台の区間の長さのばらつきがそのまま件数のばらつきになった
- 足した台がいちばん多い1台の区間に入ったのは29.5%の回で、いちばん多い1台が受け持つ輪の長さの割合（平均29.44%）とほぼ同じだった。**残りの70.5%の回では、いちばん多い1台の件数は足しても1件も減らなかった**。11台にしたあとの、いちばん多い1台÷平均は3.029倍で、足す前より平均から離れた
- 1回目の例（図1、`data/example_one_trial.csv`）では、いちばん多い1台が46,821件、いちばん少ない1台が480件だった。足した台は2,351件を受け取ったが、いちばん多い1台は46,821件のままだった

### 確かめ：15通り（各1,000回、`results/grid.csv`）
- 動いた割合の平均は、15通りすべてで、受け持ちがそろうときの1÷（台数＋1）との差が−0.419〜+0.524ポイントだった
- いちばん多い1台÷平均は、2.251〜5.239倍だった。台数5で2.251〜2.317倍、10で2.913〜2.929倍、20で3.584〜3.638倍、50で4.408〜4.569倍、100で5.238〜5.239倍と、台数でほぼ決まり、データの件数ではほとんど変わらなかった。目安の式との差は−0.091〜+0.07だった
- 足した台が、いちばん多い1台からデータを受け取った回は4.5〜47.5%、いちばん多い1台の件数が変わらなかった回は52.5〜95.5%で、台数が多いほど、足した1台がいちばん多い1台に当たりにくかった
