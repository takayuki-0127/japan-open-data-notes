# 813 縦軸を0から始めないと、差は何倍に見えるのか？（グラフ）

棒の高さや線の位置は、ふつう「縦軸の0」から測った長さで読まれます。縦軸を0より上から始めると、描かれた高さの比は本当の数字の比より大きくなり、小さな差が大きな差に見えます。**ここでは、作成者が乱数で作った架空の会社1,000社の月ごとの売上（12か月）で、縦軸の始め方ごとに「描かれた高さの差」が「本当の差」の何倍になるか（見た目の差の倍率）を数えました。**

2本の縦軸のグラフは関連する記事 814、対数の軸は 820 で扱います。この記事は「縦軸をどこから始めるか」だけを見ます。

見た目の差の倍率 ＝（描かれた高さの比 − 1）÷（本当の比 − 1）。縦軸を0から始めれば、どの数字でも1倍です。

## 主な結果

### 縦軸を「小さいほうの値の何%」から始めるか
| 縦軸の始まり | 見た目の差の倍率 | 本当の差5%の2本の高さの比 |
|---|---|---|
| 0から | 1倍 | 1.05 |
| 50%から | 2倍 | 1.1 |
| 80%から | 5倍 | 1.25 |
| 90%から | **10倍** | 1.5 |
| 95%から | **20倍** | 2.0 |

- 見た目の差の倍率は 1 ÷（1 − 始まりの割合）で決まり、本当の差の大きさによらなかった（差2・5・10・30%のどれでも同じ）。小さいほうの値の90%から始めると、5%の差は1.5倍の高さ、つまり50%の差に見えた

### 線グラフの自動の目盛り（1,000社、最大の月と最小の月）
| | 中央値 | 10〜90%の範囲 |
|---|---|---|
| 本当の差（最大の月が最小の月より何%多いか） | 27.3% | 8.6〜63.4% |
| 自動（上下5%の余白）で描かれた高さの比 | **21倍** | 21〜21倍 |
| 自動（上下5%の余白）の見た目の差の倍率 | 73倍 | 32〜232倍 |
| 切りのいい数に丸める自動で描かれた高さの比 | 8.5倍 | 5.6〜16.6倍 |
| 切りのいい数に丸める自動の見た目の差の倍率 | 29倍 | 10〜108倍 |

- 上下5%の余白の自動の目盛り（matplotlib の既定）では、最大の月は最小の月の**必ず21倍の高さ**に描かれた（（1＋0.05）÷0.05＝21）。21倍はデータではなく既定の余白で決まる値で、余白を10%にすると11倍になる。本当の差が3%でも100%でも同じ高さの比になる
- そのため、本当の差が小さい会社ほど見た目の差の倍率は大きかった（本当の差0〜10%の会社で中央値275倍、40%以上の会社で37倍）
- 切りのいい数に丸める自動では、縦軸の下端は最小の月の97%（中央値）で、1,000社のうち縦軸が0から始まった会社は0社だった

### 本当の差の帯ごと（見た目の差の倍率の中央値）
| 本当の差 | 会社数 | 自動（上下5%） | 切りのいい数に丸める自動 |
|---|---|---|---|
| 0〜10% | 136 | 275倍 | 116倍 |
| 10〜20% | 218 | 135倍 | 51倍 |
| 20〜40% | 340 | 69倍 | 26倍 |
| 40%以上 | 306 | 37倍 | 14倍 |

### 確かめ：置き方を変えても（各300社、中央値）
| 置き方 | 本当の差 | 自動（上下の余白）の高さの比 | 自動の見た目の差の倍率 | 丸める自動の見た目の差の倍率 | 丸める自動で0から始まった割合 |
|---|---|---|---|---|---|
| 基本（12か月・振れ1〜15%・余白5%） | 27.3% | 21倍 | 73倍 | 30倍 | 0% |
| 余白10% | 29.9% | 11倍 | 34倍 | 18倍 | 0% |
| 6か月 | 21.5% | 21倍 | 93倍 | 41倍 | 0% |
| 24か月 | 40.6% | 21倍 | 49倍 | 22倍 | 0% |
| 振れ1〜5% | 10.9% | 21倍 | 183倍 | 68倍 | 0% |
| 振れ5〜30% | 73.6% | 21倍 | 27倍 | 11倍 | 0.7% |

- 余白の大きさで高さの比は決まり（5%なら21倍、10%なら11倍）、データの置き方では動かなかった
- 見た目の差の倍率（中央値）は、月ごとの振れの置き方で、丸める自動では11〜68倍、上下の余白の自動では27〜183倍と大きく動いた。ただし、どの置き方でも10倍を超えた。主な結果の73倍・29倍は基本の置き方での数字

## 注意（言えないこと）
- 架空のデータです。売上の水準・伸び・月ごとの振れは作成者が置いたもので、見た目の差の倍率（73倍・29倍など）はこの置き方で決まります。とくに月ごとの振れの置き方で、中央値が11〜183倍の間で動きます
- 「見た目の差の倍率」は、描かれた高さの比から計算した値です。人が実際に何倍の差と感じるかは測っていません
- 線グラフの縦軸を0から始めないこと自体は、変化を見るためにふつうに使われます。この分析は「高さの比で大小を読むと、どれだけずれるか」を数えたもので、線グラフの描き方の良し悪しを決めるものではありません
- 自動の目盛りは matplotlib の決まりで数えました。表計算ソフトなど、ほかの道具の自動の目盛りの決まりは違うことがあります
