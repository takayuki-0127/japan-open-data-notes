# 196 女性の校長の割合は、都道府県でどれだけ違うか：学校基本調査

文部科学省「学校基本調査」の職名別教員数（本務者・公立）から、公立小学校・中学校の校長に占める女性の割合を、都道府県別に2015年度と2025年度で比べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A196 | 女性の校長の割合は都道府県でどれだけ違い、10年でどう変わったか | 都道府県別の女性校長割合（2015・2025年度）、教員全体・副校長と教頭・校長の段階別の女性割合、10年前の副校長・教頭の女性割合との相関 | `src/a196_principals.py` |

## 主な結果
- 公立小学校の校長に占める女性は2015年度19.1%→2025年度29.6%、中学校は6.1%→13.9%
- 2025年度の小学校は石川57.7%・広島50.0%・神奈川45.6%が高く、島根12.2%・長崎12.3%・宮崎15.6%が低い（最大と最小で4.7倍）。30%以上の県は3→24
- 中学校は石川31.2%・高知29.8%が高く、福島4.7%・熊本5.8%が低い
- 小学校で割合が下がったのは青森（−4.4pt）・島根（−2.8pt）・長崎（−1.4pt）の3県。上がったのは茨城（+22.7pt）・千葉（+20.6pt）・和歌山（+20.2pt）など
- 教員全体に占める女性は小学校63%、中学校45%で10年ほぼ同じ。副校長・教頭は小学校23%→33%、中学校9%→21%
- 2015年度の副校長・教頭の女性割合が高い県ほど、2025年度の女性校長割合が高い（小学校 r=0.78、中学校 r=0.52）。教員全体の女性割合との相関は弱い（小学校 r=0.27）

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a196_principals.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/principals_by_pref.csv | 年度、学校（小・中）、都道府県、公立の本務教員の男女別人数（教員計・校長・副校長・教頭・主幹教諭） |

- 平成27年度 学校基本調査 報告書掲載集計 小学校52表（statInfId 000031357851）・中学校79表（000031357878）「職名別教員数（本務者）」の「3. 公立」
- 令和7年度 学校基本調査 旧報告書掲載集計 小学校54表（000040393707）・中学校82表（000040393735）の「3. 公立」
- ブラウザで Excel を読み、都道府県の行を書き写した。全国の合計は表の計と一致する

## 注意
- 公立だけ（国立・私立は含まない）。中等教育学校・義務教育学校は含まない
- 副校長を置く県（東京都・岩手県など）と、教頭を置く県があるので、副校長と教頭は合わせて見た
- 女性校長が多い理由（登用の方針、年齢構成、管理職試験の受験者数など）は、このデータでは分からない
- 小さな県は校長の数が少なく、割合が年ごとに動きやすい
