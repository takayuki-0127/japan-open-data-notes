# 757 LOESS の span を小さくするか大きくするかで、曲がり具合の見え方と誤差はどう入れ替わるのか（手法の解説・正解の分かるデータで試す）

LOESS は、各点の近くのデータだけで直線を当てはめ、それをつないで曲線を描く方法です。span は「近く」としてデータの何割を使うかで、小さいとぎざぎざ（誤差を拾いすぎる）、大きいと山や谷がつぶれます（形を見落とす）。**ここでは、x=3 付近に細い山とゆるい波のある曲線に誤差を足した200点で、span を0.05〜0.9 と変えて各300回当てはめ、本当の曲線との誤差・山の高さ・山の位置を測りました。5-fold の交差検証で span を選んだ場合も試しました。** 曲線の形と誤差の大きさは作成者が置いたもので、数字はその置き方で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A757 | span で、誤差と山の見え方はどう入れ替わるか | LOESS（statsmodels の lowess、局所的な直線、頑健化なし）。span 0.05〜0.9 の9通り×300回。本当の曲線との RMSE、x=2〜4 の最大値（山の高さ）とその位置。5-fold の交差検証で span を選ぶ（100回）。seed 757 | `src/a757_loess.py` |

## 主な結果
- **誤差がいちばん小さいのは span 0.15**（RMSE 0.141）。0.05 では1.55倍（ぎざぎざ）、0.75 では4.61倍（山がつぶれる）
- **山の高さ**：span 0.1 で本当の96%、0.3 で71%、0.6 で40%、0.75 で34%。statsmodels の lowess の既定値（2/3）は、この山をほとんど消してしまう
- **山の位置**：span 0.1〜0.2 ではずれが平均0.08〜0.09、0.75 以上では0.85
- **交差検証で選ぶ**：100回のうち69回が0.15、15回ずつ0.1と0.2を選んだ。誤差は平均0.145で、その回でいちばんよい span の0.138に近い

## 動かし方
```
pip install -r requirements.txt
cd src && python a757_loess.py
```
十秒ほどで終わります。`results/summary.csv` に span ごとの誤差と山の再現を、`results/cv_choice.csv` に交差検証で選んだ span を書き出します。

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 757）
- 仮定：f(x) = 2.0·exp(−(x−3)²/0.5) + 0.8·sin(0.9x)、x は0〜10の一様乱数、誤差は標準偏差0.5の正規分布、200点

## 注意（言えないこと）
- シミュレーションの結果。よい span は、曲線の形（細い山があるか）・点の数・誤差の大きさで変わる
- 頑健化（外れ値に強くする繰り返し）や2次の当てはめは試していない
- 交差検証の誤差には、データの誤差（標準偏差0.5）も入っている。本当の曲線との誤差は、それとは別に測った
