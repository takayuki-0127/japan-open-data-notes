# 181 定期と定期外、コロナ後に戻らなかったのはどちらか：鉄道輸送統計調査

国土交通省「鉄道輸送統計調査」の年報（2019〜2024年度版の「鉄道輸送概要」）から、2018〜2024年度の鉄道の旅客数量・旅客人キロを、定期・定期外別、JR・民鉄（JR以外）・新幹線別に並べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A181 | コロナ後に戻らなかったのは定期（通勤・通学）か、定期外か | 2019年度＝100の指数、区分別の2024年度の戻り、定期の割合と1人1回の平均乗車キロ（人キロ÷人数）の推移 | `src/a181_rail.py` |

## 主な結果
- 2020年度の落ち込みは定期外のほうが大きかった（2019年度＝100で定期76.0、定期外61.8）
- 2024年度は定期外が100.9とコロナ前を上回ったのに対し、定期は87.1にとどまる。2019→2024年度で定期の旅客数は約19億人（1,906百万人）減った
- 定期の戻りはJR 85.8、民鉄 88.0。新幹線は定期100.2・定期外104.7で、どちらもコロナ前を超えた
- 旅客数に占める定期の割合は、2019年度58.7%→2020年度63.7%→2024年度55.1%
- 定期外の1人1回の平均乗車キロは、2020年度に16.0kmまで短くなり（2019年度21.3km）、2024年度は21.4kmに戻った。定期は14km台でほとんど変わらない

## 動かし方

```bash
pip install -r requirements.txt
cd src
python a181_rail.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/rail_passengers_fy.csv | 年度（2018〜2024）、区分（全体・JR・民鉄・新幹線）、定期／定期外（全体は合計も）、旅客数量（百万人）、旅客人キロ（百万人キロ） |

- 各年度の年報「概要1 鉄道輸送概要」の表１（旅客輸送）・表２（新幹線）の値。前年度との比較表なので、2019年度版（statInfId 000032011977）から2018・2019年度、2020〜2024年度版（000032120266、000032233965、000040130705、000040222223、000040366426）から各年度の値を取った
- ダウンロード：`https://www.e-stat.go.jp/stat-search/file-download?statInfId=<ID>&fileKind=4`（2019年度版は fileKind=0）

## 注意
- 年度（4月〜翌3月）の値。2019年度には2020年2〜3月のコロナの影響が少し入っている
- 「定期」は通勤定期と通学定期の合計。この表では通勤・通学を分けていない
- 民鉄は JR 以外の鉄道・軌道（地下鉄・路面電車などを含む）
- 定期の旅客数は、定期券1枚の利用を一定の回数で数えた推計で、実際の乗車回数とは一致しない
- 定期が戻らない理由（テレワーク、定期券から回数・IC運賃への切り替え、人口構成など）は、このデータでは分けられない
