# 409 複数回答の設問は、分母の取り方で割合が何ポイント変わるのか（実務の型）

「当てはまるものをすべて選ぶ」設問の集計で、分母（回答者全体・無回答を除く・1つ以上選んだ人・回答の数）によって割合がどれだけ変わるかを、架空のアンケートで数えたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A409 | 4つの分母で、選択肢ごとの割合は何ポイント違うか。年齢の間・2回の調査の間の比べで、向きが逆になる組はいくつあるか | 架空の回答者3,000人・8つの選択肢（seed 409）。年上ほど選ぶ数が少なく、無回答が多いと置く。年齢の組（8選択肢×15組）の向きを比べる。乱数を変えて200回。2回目の調査（選ぶ確率を1.04〜1.5倍） | `src/a409_multiple_response.py`、`src/01_denominators_tsql.sql`（未検証） |

## 主な結果
- **分母**：①回答者全体3,000人、②無回答を除く2,799人、③1つ以上選んだ人2,704人、④回答の数7,704個（選んだ人1人あたり2.85個）
- **ネット通販の割合**：①59.6%、②63.9%、③66.1%、④23.2%。4つの分母の差は、8つの選択肢の平均で23.1ポイント、最大42.9ポイント。人が分母の①〜③の差は最大6.5ポイント
- **割合の合計**：①256.8%、②275.2%、③284.9%、④100.0%
- **回答の表だけで分母を数える書き方**（`COUNT(DISTINCT 回答者ID) FROM answers`）は③と同じになる
- **年齢の間の比べ**：1人あたりの回答の数は20代3.70個、70代2.18個。ポイントサービスは②では20代59.9%・70代43.9%、④では20代16.2%・70代21.8%。120組のうち、②と④で向きが逆は31組（200回の平均34.9組、23〜50組）。①と②で逆は5組。いちばん高い年齢が分母で変わる選択肢は8つのうち4つ
- **2回の調査**：1人あたりの回答の数は2.85→3.34個。②では8つすべてで上がる。④ではネット通販−3.0、ポイントサービス−2.0、テレビ通販−0.5、食材宅配−0.4ポイント

## データ
- `data/respondents.csv`（回答者3,000人：年齢・状態・選んだ数）、`data/answers.csv`（選んだ選択肢、7,704行）。作成者が乱数で作成（seed 409）。実在の調査の結果ではない

## 注意（言えないこと）
- 架空のアンケート。差の大きさは、無回答の割合と1人あたりの選ぶ数の置き方で決まる
- どの分母が正しいかは、知りたいことで決まる。この記事は分母を決めるものではない
- 2回目の調査は、同じ乱数（同じ人）で、選ぶ確率だけを変えた
- 重み付け（F290）、聞き方の違い（いくつでも・3つまで）は入れていない
- T-SQL 版は SQL Server 本体では動かしていない（未検証）
