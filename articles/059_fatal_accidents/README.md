## もとのリポジトリの説明

以下は、もとのリポジトリ `traffic-accidents-japan` の README です（同じリポジトリにあったほかの記事の分も含みます）。

### traffic-accidents-japan：警察庁の交通事故オープンデータ（約29万件）で、死亡事故になりやすい条件と事故の減り方を調べる

警察庁「交通事故統計情報のオープンデータ」の本票（人身事故1件ごとの記録）2019年・2025年を使ったリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| D1 | 人身事故のうち、死亡事故になりやすいのはどんな条件か | 条件別の死亡事故率、ロジスティック回帰（オッズ比）、勾配ブースティング（5分割交差検証のAUC・校正・並べ替え重要度） | `src/d1_fatal.py` |
| D2 | 2019年→2025年で、どんな事故が減ったか。事故と死亡事故はいつ・どこで起きているか | 第1当事者の年齢・種別ごとの件数変化、時間帯×曜日、緯度経度の六角形ビン | `src/d2_change.py` |

#### 主な結果
- **D1**：2025年の人身事故287,008件のうち死亡事故は2,495件（0.87%）。そのままの割合は、カーブ4.58%、相手なし（単独事故）4.19%、0〜5時4.13%、歩行者が相手2.33%、非市街地1.93%、夜1.56%。ほかの条件をそろえたオッズ比は、単独事故34.5倍、歩行者が相手8.5倍、相手が75歳以上6.5倍、0〜5時3.2倍、非市街地2.8倍、カーブ2.5倍、夜1.9倍、第1当事者が75歳以上1.5倍。勾配ブースティングのAUCは0.904（ロジスティック回帰0.899）で、予測の上位10%に死亡事故の73%が入る
- **D2**：人身事故は381,237件（2019年）→287,023件（2025年）で−25%、死亡事故は3,133件→2,495件で−20%。第1当事者の年齢別では75歳以上だけが+9%、種別では自転車等だけが+23%。事故は平日の8時台と17時台に集中し、死亡事故の割合は4時台が最も高い（4.95%）


#### データ
| ファイル | 中身 |
|---|---|
| data/raw/honhyo_2019.csv・honhyo_2025.csv（各自ダウンロード） | 本票：人身事故1件ごとの記録（発生日時、昼夜、天候、道路形状、事故類型、当事者A・Bの年齢・種別、速度規制、緯度経度など） |
| data/raw/codebook_2025.xlsx・fileteigisyo_2025.xlsx | 各種コード表・ファイル定義書 |

#### 注意
- 第1当事者（当事者A）は、事故に関係した人のうち過失が重い側、第2当事者（当事者B）はその相手です
- 死亡事故は、事故から24時間以内に亡くなった人がいる事故です（30日以内の死者は含みません）
- オッズ比は「ほかの条件をそろえたときの関係」で、原因を示すものではありません。「速度規制60km/h以下」が40km/h以下より低く出るのは、そうした道路の構造（歩道や中央分離帯）など、ほかの違いを含むためと考えられます
- 本票の年は「その年に集計された事故」で、前年末に起きた事故が少し含まれます
- 都道府県コードは警察の管轄のコードで、総務省の都道府県コードとは違います
