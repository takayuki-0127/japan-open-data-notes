# 797 2つの95%区間が重なっていたら「差なし」と読むと、本当は差がある場合を何%見逃すのか（手法の解説・正解の分かるデータで試す）

2つの群の平均に95%区間（誤差棒）を付けたグラフで、「区間が重なっているから差はない」と読むことがあります。しかし、2つの区間が重ならないのは、差が「片方の区間の半分の幅」のおよそ2倍を超えたときです。差そのものの検定に要る大きさ（およそ√2倍）より厳しく、区間が重なっていても差の検定では有意、ということがよく起きます。**ここでは、本当の差を置いた2群をくり返し作り、区間の重なりで読む方法と差の t 検定を比べました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A797 | 区間の重なりで読むと、本当の差をどれだけ見逃すか | 2群（各50件、標準偏差1）。本当の差 d＝0〜0.8、各5,000回。各群の平均の95%区間（t 分布）が重なるか、差の2標本 t 検定（5%）で有意か、を数える。scipy。seed 797 | `src/a797_overlap.py` |

## 主な結果（各5,000回）

| 本当の差 d | 区間が重ならない（差ありと読む） | 差の t 検定で有意 | 区間は重なるが有意 |
|---|---|---|---|
| 0 | 0.5% | 4.6% | 4.1% |
| 0.3 | 9.1% | 31.5% | 22.4% |
| 0.5 | **36.7%** | **68.3%** | **31.6%** |
| 0.8 | 87.6% | 97.8% | 10.2% |

- 本当の差が0.5のとき、区間の重なりで読むと63%の回で「差なし」とし、本当の差を見逃した。差の t 検定では見逃しは32%だった
- 本当の差0.5で区間が重なった回のうち、半分（50%）は差の t 検定で有意だった
- 区間の重なりで読む方法は、差がないときに「差あり」と言う割合が0.5%しかない。有意水準を5%ではなく約0.6%にしたのと同じで、そのぶん本当の差を見逃す

## 注意（言えないこと）
