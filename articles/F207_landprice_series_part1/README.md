# F207 地価はどこで上がり、駅ができると何が起きるのか？（前編）

看板記事 F207。深いシリーズ D「地価・住宅」の前編です（後編は F208）。これまでの地価の記事（F03 機械学習、F37 予測の幅、F91 解釈手法、F158 毎年の更新、042 この10年の変化）のデータを使い回し、1つの問い「地価の動きをどこまで説明でき、駅はどれだけ効くのか」を3つの角度から掘り下げました。

note：「地価はどこで上がり、駅ができると何が起きるのか？（前編）…」（下書き）

## 問い

1. この20年（2006→2026年）で、地価はどこで上がり、どこで下がったか。上がった地点にはどんな特徴があるか
2. 地価を「説明する」モデル（回帰）と「当てる」モデル（機械学習）は、同じ答えを出すか
3. 新しい駅ができると、そばの地価はどれだけ上がるか

## データ

| データ | 内容 |
|---|---|
| 地価公示（国土数値情報 L01-26、2026年） | 25,565地点。各地点の1996〜2026年の価格（L01_075〜L01_105）と、2007〜2026年の属性移動（L01_129〜L01_148） |
| 地点の特徴量・駅の位置 | F03 と同じもの（`articles/F03_land_price_ml/data/features.csv`・`stations.csv`）。三大都市の中心からの距離、最寄り駅までの距離、周り1kmの駅の乗降客数、市区町村の人口・人口密度・2015→20年の人口増減、容積率など |
| 新しい駅の開業日 | 2005〜2023年に開業した74駅（20路線）。各鉄道事業者の公表資料をもとに `data/stations_new.csv` に手で入力し、F03 の駅の位置と駅名・緯度で突き合わせた |

- `data/price_hist_1996_2026.csv.gz`：地点×年の価格（0 はその年に地点がない）
- `data/chg_2007_2026.csv.gz`：年ごとの属性移動のコード（先頭の数字が 1 なら前年と同じ地点が続いている）
- 2026年に選ばれている地点だけの履歴です。途中でなくなった地点は入っていません（言えないことを参照）

## 手法

| 問い | やったこと |
|---|---|
| 1. 20年の変化 | 2007〜2026年の毎年「前年と同じ地点が続いた」11,877地点で、log(2026年価格÷2006年価格)。三大都市の中心からの距離・市区町村の人口増減などで分けて集計し、標準化した回帰（市区町村でクラスター化した標準誤差）で特徴を比べた。前の10年（2006→16）と後の10年（2016→26）の変化も比べた |
| 2. 説明と予測 | 2026年の log(価格) を、①回帰（7変数）、②回帰＋市区町村の人口、③ LightGBM（14変数）で予測し、20km四方のブロックで5分割する「場所で分けた検証」とランダムな5分割で外れ（\|予測÷実際−1\| の中央値）を比べた。あわせて「最寄り駅までの距離」の効き方を、回帰の変数の入れ方4通りと LightGBM（距離を少し動かしたときの予測の差の平均）で比べた |
| 3. 新しい駅 | 新しい駅から1km以内で、ほかの駅から1km超の地点（＝その駅で初めて駅が近くなった地点）を「処置」、同じ駅から1.5〜4kmの地点を「比較」とし、開業後はじめての地価公示を0年として、−5〜+5年の価格の変化（開業1年前の公示からの差）を駅ごとに比べた（イベントスタディ）。区間は駅を単位にしたブートストラップ（2,000回） |

## 主な結果

### 1. 20年で上がったのは44%の地点。三大都市の中心から10km以内は93%（図1・図2）

- 2006→2026年に同じ地点が続いた11,877地点のうち、上がったのは43.9%、変化の中央値は −6.2%
- 圏域別（上がった割合／中央値）：東京圏 73%／+21%、名古屋圏 60%／+6%、大阪圏 53%／+2%、地方圏 24%／−24%
- 三大都市の中心からの距離別：10km以内 93%／+89%、10〜20km 82%／+29%、20〜40km 61%／+7%、40〜80km 29%／−14%、80km以上 25%／−24%
- 市区町村の人口の増減（2015→20年）別：−5%未満の市区町村では上がった地点は2%（中央値 −38%）、+2%以上では90%（+46%）
- 6つの特徴を同時に入れた回帰（標準化）では、市区町村の人口の増減（+0.27）と周り1kmの駅の乗降客数（+0.12）が大きく、三大都市の中心からの距離（+0.01、標準誤差0.016）は、ほかの変数を入れると効きが消えた（R² 0.58）

### 2. 後の10年の上昇の多くは「前の10年に下がった地点の戻り」（図3）

- 2006→16年に上がった地点は24%、2016→26年は63%
- 両方の10年で上がった 23%、前は下落→後は上昇 40%、前は上昇→後は下落 0.3%、どちらも下落 36%
- 前の10年と後の10年の変化の相関は 0.65（前に大きく下がった地点ほど、後も弱い）
- 開始年を変えると：2011→26年は上昇52%・中央値+1.8%、2016→26年は上昇63%・+7.1%

### 3. 当てる力は機械学習が上だが、「駅の効き方」の答えは回帰の変数しだいで大きく動いた（図4・図5）

外れの中央値（場所で分けた検証／ランダムな検証）：

| モデル | 場所で分けた | ランダム |
|---|---|---|
| 回帰（7変数） | 54.8% | 53.9% |
| 回帰＋市区町村の人口 | 36.3% | 36.0% |
| LightGBM（14変数） | 22.9% | 16.6% |

駅のすぐそば→約1.7km（log(1+km) が1増える）での地価の差：

| モデル | 差 | 95%区間 |
|---|---|---|
| 回帰（7変数） | −13% | −15〜−11% |
| 回帰＋市区町村の人口 | −3% | −5〜−2% |
| 回帰＋人口＋緯度経度 | −5% | −6〜−3% |
| 回帰＋市区町村ごとの比較（固定効果） | −32% | −34〜−31% |
| LightGBM（平均の差分） | −34% | — |

- 回帰では、「市区町村の人口」を入れると駅の効きが小さくなり（駅の近さと市区町村の大きさが重なっているため、推測）、「同じ市区町村の中で比べる」と大きくなった。LightGBM の答え（−34%）は、同じ市区町村の中で比べた回帰に近かった
- LightGBM の差は圏域で違った：東京圏 −47%、大阪圏 −38%、名古屋圏 −28%、地方圏 −25%（回帰7変数ではそれぞれ −25%、−28%、−23%、−13%）

### 4. 新しい駅のそばの地価は、開業の「前」から伸びていた（図6）

- 条件に合う「処置」の地点があったのは32駅・68地点（比較は3,962地点）
- 開業1年前の公示を0として、処置と比較の差：5年前 −5.8%、3年前 −4.0%、2年前 −1.4%、開業後はじめての公示 +1.7%、2年後 +2.9%、5年後 +2.0%
- 開業後1〜5年の平均の差は +2.4%（95%区間 +0.4〜+4.3%）。ただし開業前（−5〜−2年）の差も −3.9%（−5.8〜−1.9%）で、処置の地点は開業前から比較より年1〜2%速く伸びていた
- 開業を5年前にずらした「偽の開業」でも +5.7%（+3.4〜+8.0%）が出たため、開業の前後だけを比べる差の差は、駅の効果を正しく測れていない。駅の効果（とそれを見込んだ値上がり）は、開業の何年も前から少しずつ出ていたと考えられる（推測）
- -5年→+2年の合計では、処置の地点は比較より約8.7%多く上がった

## 頑健性

| 確かめたこと | 結果 |
|---|---|
| 20年の変化の開始年（2006・2011・2016年） | 上がった割合 44%・52%・63%。三大都市の中心に近いほど上がる形はどの開始年でも同じ（results/main.json） |
| 説明と予測：検証の分け方（場所／ランダム） | 回帰は分け方でほぼ変わらず、LightGBM は場所で分けると外れが 16.6%→22.9% に広がった。順位は同じ |
| 駅の効き方：住宅地だけ | 回帰（7変数）−18%、LightGBM −31%。回帰が小さく出る形は同じ |
| 新しい駅：処置の半径 0.5km | 開業後 +4.3%（+2.4〜+6.1%）、開業前 −2.7% |
| 新しい駅：「ほかの駅から1km超」の条件をなくす（58駅） | +2.2%（+0.5〜+3.9%）、開業前 −2.9% |
| 新しい駅：比較の範囲 1〜2km／2〜5km | +1.4%（−0.2〜+3.1%）／+2.9%（+0.9〜+4.8%） |
| 新しい駅：つくばエクスプレスを除く／新幹線を除く | +1.7%（−0.2〜+3.6%）／+2.7%（+0.8〜+4.6%） |
| 新しい駅：偽の開業（5年前にずらす） | +5.7%（+3.4〜+8.0%）。開業前からの伸びがあることを示す |

## 後編に渡すもの（F208 用）

- `data/price_hist_1996_2026.csv.gz`：地点×年の価格（1996〜2026年）。マンション価格と地価の時系列の比較（F56・F182）に、地点の年次の動きをそのまま使える
- `results/A_change_2006_2026.csv.gz`：20年の変化（地点・圏域・用途つき）。後編の「外れやすい場所」の地図と重ねられる
- `results/main.json` の `B_cv`・`B_eff`：説明と予測の比較の数字。後編の「毎年更新した予測はどこで外れるか」（F158 を取り込む）の出発点
- 今回の結論で後編に持ち越す点：①上昇は大都市の中心近くと人口が増える市区町村に集中し、後の10年は戻りが多い ②駅の効き方は比べ方しだいで大きく変わる ③新しい駅の効果は開業前から出ていて、開業の前後だけでは測れない
- 後編で扱うもの：マンションの価格は地価とどう連動しているか（不動産取引価格情報、F56・F182）、地価の予測を毎年更新するとどこで外れやすいか（F158・F108・F109）、データが言えること・言えないこと

## 言えないこと

- **生き残った地点だけ**：2026年に選ばれている地点の履歴なので、途中でなくなった地点（地価が大きく下がった場所に多い可能性がある、推測）は入っていない。下落の大きさを小さく見ている可能性がある
- **特徴量は今の値**：市区町村の人口増減は2015→20年、乗降客数は2024年など、20年の変化の「あと」の値も含む。人口が増えたから上がったのか、上がる場所に人が集まったのかは分けられない
- **駅の効き方は因果ではない**：回帰の係数も LightGBM の差も、「駅に近い地点は高い」という関係で、駅を動かしたときの効果ではない
- **新しい駅の効果は測れていない**：開業の前から伸びていたので、駅の効果、駅の計画を見込んだ値上がり、もともと伸びていた場所に駅が作られたこと、を分けられない。計画の発表日は使っていない
- **新しい駅の地点は少ない**：条件に合う地点は32駅・68地点で、路線ごとの比較はできない（1路線あたり1〜18地点）
- **開業日は手で入力**：各鉄道事業者の公表資料をもとに入力した。駅名と緯度で F03 の駅の位置と突き合わせたので、同じ名前の別の駅を拾っていないかは目で確かめた範囲
- **地域の評価はしていない**：地価の上がり下がりは土地の値段の動きで、地域の良し悪しではない。市区町村の順位は出していない
