### retail-sales-japan：経済産業省「商業動態統計」で、業態別の販売額とコロナ前後の変化を調べる

経済産業省「商業動態統計」の時系列データ（e-Stat「■時系列データ」、業種別は1980年〜、業態別のドラッグストア・ホームセンター・家電大型専門店は2014年〜、2026年8月分まで）を使ったリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| W1 | ドラッグストアは百貨店・スーパーをどれだけ追い上げたか。何を売って伸びたか | 業態別の販売額（2014・2019・2025年）、公表の前年比をつないだ指数（2014年＝100）、ドラッグストアの商品別構成比、業態別の食品の販売額の指数 | `src/w1_drugstore.py` |
| W2 | コロナ前後で売上が戻った業態・戻らない業態はどこか | 前年比をつないだ2019年比（年・月）、断層を除いた月次系列の STL 季節調整、2014〜2019年の傾向線（対数線形）との差、コロナ前（2014〜2019年）と2022年以降の傾き（HAC 標準誤差） | `src/w2_covid.py` |

#### 主な結果
- **W1**：2025年の販売額はスーパー16.8兆円、コンビニ12.7兆円、ドラッグストア9.4兆円、百貨店6.2兆円。ドラッグストアは2014年の4.9兆円から約1.9倍で、前年比をつないだ指数でも184（2014年＝100、年率5.7%）。2019年に百貨店（6.3兆円）を販売額で上回った。店舗数は13,069→20,373店。商品別では食品の割合が24.4%→34.1%に上がり、市販薬（OTC）は14.9%→11.0%、化粧品などは14.7%→13.2%に下がった。ドラッグストアの食品の販売額は2014年の2.6倍（指数255）で、スーパーの飲食料品（134）、コンビニの食品（130）より速く伸び、百貨店の飲食料品は83に減った
- **W2**：2019年＝100とすると、2025年はドラッグストア137.6、医薬品・化粧品小売業（業種）126.5、スーパー115.5、コンビニ111.0、小売業計111.1。戻っていないのは織物・衣服・身の回り品小売業86.4、各種商品小売業95.5、百貨店98.7。百貨店の中では身の回り品122.8に対し、食堂・喫茶86.1、飲食料品90.7。コロナ前（2014〜2019年）の傾向を延ばした線と比べると、2025年はスーパー＋9.5%、百貨店＋13.8%（減っていた傾向より上）、家電大型専門店＋7.9%、ホームセンター＋5.8%と上回り、コンビニは−8.1%、ドラッグストアは−3.3%と下回った。コンビニとドラッグストアは2022年以降の伸び（年率3.0%・6.5%）がコロナ前（3.0%・6.0%）と同じくらいで、2020年の落ち込み・足踏みの分を取り戻していない

#### 動かし方
`data/` の4つの CSV（Excel から取り出したもの）が入っているので、そのまま動きます。元の Excel から作り直すときは、e-Stat の「■時系列データ」から下の7ファイルを `data/raw/` に置き、`data/*.csv` を消してから実行してください（`src/common.py` が作り直します）。
- 一覧：https://www.e-stat.go.jp/stat-search/files?page=1&toukei=00550030&tstat=000001081875 （■時系列データ）
- `shogyo_ts_00.xlsx`：業種別商業販売額及び前年（度、同期、同月）比
- `shogyo_ts_02.xlsx`：百貨店・スーパー商品別販売額及び前年比
- `shogyo_ts_03.xlsx`：コンビニエンスストア商品別販売額等及び前年比
- `shogyo_ts_04.xlsx`：家電大型専門店商品別販売額等及び前年比
- `shogyo_ts_05.xlsx`：ドラッグストア商品別販売額等及び前年比

#### データ
| ファイル | 中身 |
|---|---|
| data/monthly_value.csv | 年月×系列の販売額（業種別は10億円、業態別は百万円）と店舗数。列名は「業態｜商品」または「業種別｜業種」 |
| data/monthly_yoy.csv | 年月×系列の前年同月比（公表値、前年同月＝100の比） |
| data/annual_value.csv | 年×系列の販売額 |
| data/annual_yoy.csv | 年×系列の前年比（公表値） |

#### 注意
- 販売額の水準には断層がある：業種別は2020年3月分と2025年1月分に「水準の調整」、ドラッグストアは2015・2017〜2019年の年間補正、家電大型専門店は2018年と2020年3月の対象企業の見直し、コンビニは2012年1月・2017年1月・2021年3月の調査対象の見直しなど。伸びは、断層をまたいでもつながるように公表されている前年比をつないで計算した。異なる年の販売額を直接割った値とは一致しない
- 毎年の年間補正で過去の値が変わることがある。数値は2026年10月公表分の時点のもの
- 業態別（百貨店・スーパー・コンビニ・ドラッグストアなど）は企業単位、業種別（○○小売業）は事業所単位の集計で、範囲が違う。業態どうしも調査対象企業の範囲が違うので、販売額の比較は目安
- すべて名目値で、物価の上昇を差し引いていない。2019年比や傾向との差には値上げの分が含まれる
- ドラッグストアの調剤医薬品は、2019年に調査対象の見直しで金額が大きく変わった（構成比の上昇の一部はこのため）
- 2019年9・10月は消費税率の引上げ前の駆け込みと反動で動きが大きく、2019年同月比の月次の値はこの2か月がゆがむ。年の比較は年の前年比をつないで計算した
- 季節調整は STL（周期12、ロバスト）で、公式の季節調整値（X-12-ARIMA 等）ではない。傾向線は2014〜2019年の季節調整値の対数に直線を当てはめたもので、「コロナがなければこうなった」という予測ではない
