# 610 説明変数に測りまちがいがあると、回帰の係数はどれだけ小さく出るのか（手法の解説・正解の分かるデータで試す）

回帰の説明変数が測りまちがい（測るたびに変わる誤差）を含むと、係数は本当の値より0に近く出ます（希薄化、減衰とも言う）。縮む割合は、測った値の「信頼性」λ（本当のばらつき÷測った値のばらつき）で決まります。**ここでは、架空の店500店で、本当の係数0.5の指標を信頼性1.0〜0.3で測った場合に、係数がどれだけ縮むか、2回測ることでどこまで直せるか、相関する別の変数にどう漏れるかを、各2,000回のシミュレーションで数えました。** 数字は置いた前提で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A610 | 測りまちがいで係数がどれだけ縮み、どの直し方で戻るか | 最小二乗。O 測った値でそのまま、A 2回測った平均、C 2回の測定から信頼性 λ̂=Cov(x1,x2)/Var(x1) を出して割り戻す、IV 2回目を操作変数に。x と相関0.6の変数 z（本当の係数0）を一緒に入れた回帰も。各2,000回、seed 610 | `src/a610_attenuation.py` |

## 主な結果
- **そのまま回帰すると、係数は 0.5×λ に縮む**：信頼性0.9で0.450、0.7で0.350、**0.5で0.250（半分）**、0.3で0.150
- **2回測った平均**：信頼性が上がる分だけ戻る（λ=0.5 で0.332）。それでも本当の0.5には届かない
- **信頼性で割り戻す・2回目を操作変数にする**：どの λ でも平均0.50〜0.51に戻る。そのかわり散らばりが広がる（λ=0.5 で標準偏差0.072、そのままは0.033）
- **相関する別の変数に漏れる**：本当は効かない z（x と相関0.6）を一緒に入れると、z の係数が λ=0.7 で0.121、λ=0.5 で **0.184** 出た。x の係数は0.195まで縮み、z とほぼ同じ大きさに見える

## 動かし方
```
pip install -r requirements.txt
cd src && python a610_attenuation.py
```
十数秒で終わります。

## 確かめたこと
- 空のフォルダで流し直し、results・figures がバイト単位で一致した
- 測りまちがいがない場合（λ=1）に、すべての方法で係数が0.498になること
- そのまま回帰した係数の平均が、理論の 0.5×λ と小数3桁で一致すること

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 610）
- 仮定：x・z・雑音は正規分布、測りまちがいは x と独立で、2回の測定どうしも独立

## 注意（言えないこと）
- シミュレーションの結果。信頼性と係数は作成者が置いたもので、結果はこれで決まる
- 2回の測りまちがいが互いに関係している（同じ人が測るなど）と、信頼性を高く見積もり、直し方が足りなくなる
- 目的変数 y の側の測りまちがいは係数を縮めない（散らばりが増えるだけ）。この記事は説明変数の側だけを扱った
