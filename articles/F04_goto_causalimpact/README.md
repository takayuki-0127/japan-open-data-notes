# F04 Go To トラベルは宿泊をどれだけ増やしたか？（ベイズ構造時系列・差の差・合成コントロール）

看板記事シリーズの4本目です。2020年7月22日〜12月28日の Go To トラベルの期間に、日本人の延べ宿泊者数が「キャンペーンがなかった場合」よりどれだけ多かったかを、3つの方法で推定しました。

1. **ベイズ構造時系列（CausalImpact型）**：全国の1本の時系列から「なかった場合」を作り、差を事後分布で示す
2. **差の差**：東京だけが10月1日から途中参加したことを使い、東京と他の46道府県を比べる
3. **合成コントロール**：他の道府県の重みつき平均で「合成東京」を作って比べる

## 問い

Go To の期間に、日本人の延べ宿泊者数は「なかった場合」より何人泊多かったか。その推定は、手法や前提によってどれだけ変わるか。

## データ

詳しくは `data/raw/SOURCES.md`。

| データ | 期間 |
|---|---|
| 観光庁「宿泊旅行統計調査」都道府県別 日本人延べ宿泊者数（月別、確定値） | 2011年1月〜2025年12月 |
| 厚生労働省 新規陽性者数（都道府県別・日別 → 月別に合計） | 2020年1月〜2023年5月 |
| 緊急事態宣言の日数の割合（東京都の発令期間で近似） | 2020〜2021年 |

整形後：`data/monthly_pref.csv`（48地域 × 180か月）。

## 手法

| 項目 | 内容 |
|---|---|
| 予測する値 | log(1日あたり日本人延べ宿泊者数)。月の日数で割ってから推定し、延べ宿泊者数に戻す |
| ベイズ構造時系列 | y = ローカルレベル（ランダムウォーク）＋ 月の季節効果 ＋ β₁·log(1＋1日あたり陽性者数) ＋ β₂·緊急事態宣言の日数割合 ＋ 誤差。PyMC（NUTS、nutpie）で4チェーン×1,000本。対象月の反実仮想は事後予測分布から |
| 学習期間（基本①） | 2015年1月〜2020年6月 |
| 学習期間（②） | ①に2021年1〜12月（全国の Go To なし）を加える。7〜12月は欠けた期間として内挿 |
| 比べる期間 | 2020年7〜12月（合計）、8〜11月（月のすべてが期間内）、7〜11月（12月の一時停止を除く） |
| 差の差 | 値：log(2020年の月 ÷ 2019年の同じ月)。7〜9月（東京だけ対象外）と10〜11月（全員対象）で、東京と他の46道府県の差がどれだけ変わったか。都道府県と月の固定効果。幅は他の46道府県を「東京役」にした置き換え（プラセボ） |
| 合成コントロール | 値：log(1日あたり宿泊者数) − 2019年平均。2015年1月〜2020年6月で重み（非負・合計1）を合わせ、7〜9月と10〜11月の差の変化を見る。幅はプラセボ |
| 都道府県別 | ①と同じ前提の簡易版。statsmodels の構造時系列（ローカルレベル＋季節＋全国の陽性者数・宣言）を県ごとに当てはめ、8〜11月（東京は10〜11月）の差 |
| 頑健性 | 学習期間（2011年〜／2017年〜）、共変量（陽性者数だけ）、2021年を学習に加える、12月の扱い、コロナ前だけで学習（参考） |

## 主な結果

### ベイズ構造時系列（全国、日本人延べ宿泊者数）

| 前提 | 2020年7〜12月の差（95%信用区間） | 割合 |
|---|---|---|
| ①基本（2015年〜2020年6月で学習） | +9,041万人泊（+6,394万〜+11,041万） | +100%（+55〜+158%） |
| ① 学習を2011年から | +8,756万人泊（+6,644万〜+10,426万） | +94% |
| ① 学習を2017年から | +9,272万人泊（+6,057万〜+11,687万） | +106% |
| ① 共変量を陽性者数だけに | +1億2,197万人泊（+1億709万〜+1億3,480万） | +209% |
| ②2021年も学習に加える | +4,411万人泊（+1,178万〜+7,072万） | +32%（+7〜+64%） |
| 参考：コロナ前だけで学習（共変量なし） | −7,700万人泊（−1億1,026万〜−4,899万） | −30% |

- 実績は2020年7〜12月で計1億8,048万人泊。①の「なかった場合」は9,007万人泊（6月の水準からあまり戻らない想定）
- ①の差の合計は、観光庁が公表した Go To の利用実績（12月28日までで約8,781万人泊）とほぼ同じ。利用した人がすべて「Go To がなければ泊まらなかった人」ということは考えにくく、①は大きめに出ていると考えられる
- ②は2021年10〜12月（陽性者が少なく宣言もない時期）に宿泊がほぼ元に戻ったことを学習に入れるため、「なかった場合」も回復する前提になり、差は半分以下になる
- 共変量の係数（①）：陽性者数 −0.095（−0.145〜−0.040）、緊急事態宣言 −0.78（−0.95〜−0.62）。②では −0.043、−0.42
- 12月の扱い：12月を除いた7〜11月で①+7,312万（+94%）、②+3,882万（+35%）

### 東京の途中参加（10月1日〜）

- 東京と他の46道府県の差（2019年同月比、log×100）：6月 +12 → 7〜9月 −20、−13、−28 → 10月 −11、11月 −4
- 差の差：東京が加わったことで、東京の宿泊は他県に比べ **+13.4%**。プラセボの95%の範囲は −18〜+29%（46道府県中、東京より大きいのは3県、置き換えの p = 0.19）
  - 陽性者数を調整 +12.8%、前を9月だけ +22.2%（東京が最大）、後を10月だけ +9.8%、12月も後に含める +13.0%
- 合成コントロール：合成東京の重みは 大阪 0.29、愛知 0.26、埼玉 0.25、福島 0.13、福岡 0.08。学習期間の当てはまり（RMSPE）0.05
  - 差は7〜9月平均 −8.3 → 10〜11月平均 +5.4。変化は **+14.7%**。46道府県のプラセボ中2位、95%の範囲は −18〜+14%

### 都道府県別（①と同じ前提の簡易版、8〜11月）

- 47都道府県すべてで実績が「なかった場合」を上回り、中央値 +93%
- 大きいのは千葉 +284%、京都 +172%、奈良 +161%、北海道 +154%、東京 +151%（10〜11月）。小さいのは茨城 +34%、福島・岡山 +50%
- 千葉は2020年4〜6月の落ち込みが特に大きく（大型テーマパークの休園などが考えられる）、「なかった場合」が低く出ている。県ごとの水準は①の前提に強く左右されるので、県どうしの大小の比較として見る

結果の表は `results/`、図は `figures/`（f01〜f05）。

## 注意

- 「なかった場合」は、陽性者数や緊急事態宣言の影響を学習した期間から作っています。2020年は春に1回しか波がなく、6月の水準から自然にどれだけ戻ったかは、データからはほとんど決まりません。結果の幅は手法の幅より前提の幅が大きいです
- ②で加えた2021年にも、都道府県の宿泊割引（県民割など）がありました。②の「なかった場合」は高めに、差は小さめに出ている可能性があります
- 差の差・合成コントロールが測っているのは「東京が加わった効果（他県と比べて）」です。東京の人が10月から他県に出かけやすくなった分は他県の宿泊を増やすので、東京の効果は小さめに出ます。また東京の数字は「東京に泊まった人」で、東京の人の旅行ではありません
- PyMC の推定は、学習を2011年からにした版と②で R-hat が最大1.09〜1.10と、少しばらつきが残りました（その他は1.05以下）。結果の大きさは変わりません
- 都道府県別は計算を軽くするため、ベイズではなく最尤推定の構造時系列にしています
- 宿泊の前倒しや、翌年の需要の先食いがあったかは、このデータでは分けられません
