# 989 平均で考えると、どのくじが得に見えるのか？（確率の直感）

くじの「1回あたりの平均」（期待値）は、当たりの大きさ×当たる確率で出せます。平均の大きいくじが得に見えますが、平均はとても大きく当たる少数の人に引っぱられます。何回か引いたとき、多くの人が実際にもらう量は、平均とはかなり違うことがあります。**ここでは、作成者が置いた架空の商店街の福引き3種類（買い物1回につき1回、無料で引けて、景品はポイント）で、1回の平均・真ん中の人・「必ずもらえる福引きより多くもらう人の割合」・少人数で見た平均のそれぞれで、どの福引きが得に見えるかを数えました。どの福引きを選ぶべきか、引くべきかの助言はしません。**

## 主な結果

### 1回の平均と振れ（式）
| 福引き | 1回の平均 | 1回の標準偏差 |
|---|---|---|
| A（必ず10） | 10 | 0 |
| B（10%で120） | 12 | 36.0 |
| C（0.1%で15,000） | **15** | **474.1** |

- 1回の平均で並べると C ＞ B ＞ A。どれも当たりの大きさ×確率の**式どおり**の値

### 10回引いたとき（式、`results/by_draws.csv`・`results/dist_10draws.csv`）
| 福引き | 平均 | 真ん中の人 | 0ポイントの人 | A（100ポイント）より多くもらう人 | 平均以上もらう人 |
|---|---|---|---|---|---|
| A | 100 | 100 | 0% | 0% | 100% |
| B | 120 | 120 | 34.87% | **65.13%** | 65.13% |
| C | **150** | **0** | **99.0%** | **1.0%** | 1.0% |

- **平均がいちばん大きい C では、10回引いた人の99.0%が0ポイントで、A より多くもらう人は1.0%だった**。B では65.13%の人が A より多くもらった
- 真ん中の人で並べると B（120）＞ A（100）＞ C（0）で、平均の順と入れかわった
- B の内訳は、0ポイント34.87%・120ポイント38.74%・240ポイント19.37%・360ポイント5.74%・480ポイント1.12%・600ポイント0.15%

### 引く回数ごとの、A より多くもらう人の割合（式）
| 引く回数 | B | C | C の真ん中の人 | C の0ポイントの人 |
|---|---|---|---|---|
| 1回 | 10.0% | 0.1% | 0 | 99.9% |
| 10回 | 65.13% | 1.0% | 0 | 99.0% |
| 100回 | 67.91% | **9.52%** | 0 | 90.48% |
| 1,000回 | 96.17% | 63.23% | 15,000 | 36.77% |

- **C が A を上回る人は、100回引いても9.52%、1,000回でも63.23%だった**。B は1,000回で96.17%
- B の100回の10〜90%の範囲は720〜1,680ポイント、1,000回では10,560〜13,440ポイントで、平均（1,200・12,000）のまわりに集まっていった。C は1,000回でも0〜30,000ポイントだった
- 平均以上もらう人の割合は、B では回数が増えるほど半分に近づいた（10回65.13%・100回54.87%・1,000回51.54%）
- 乱数20万人の値は式と合った（A より多くもらう人の割合の差は12通りで0.28ポイント以内。平均は C の1,000回で15,042.3と、式の15,000に対して乱数の揺れが残った）

### 少人数で見た平均で、どれがいちばん大きく見えるか（各10万組、`results/observed_mean_groups.csv`）
| 1回ずつ引いた人数 | A がいちばん大きく見えた | B | C | C の見た平均が A（10）を下回った | C の当たりが1人もいなかった（式） |
|---|---|---|---|---|---|
| 100人 | **29.12%** | 61.41% | **9.46%** | 90.53% | 90.48% |
| 1,000人 | 1.42% | 35.61% | 62.98% | 36.8% | 36.77% |
| 10,000人 | 0.0% | 27.74% | 72.26% | 13.07% | 0.0% |

- **100人が1回ずつ引いた結果の平均で比べると、C がいちばん大きく見えたのは9.46%で、A がいちばん大きく見えた組が29.12%あった**。C の当たりが1人もいない組が90.48%（式どおり、0.999の100乗）あるため
- 10,000人でも、C がいちばん大きく見えたのは72.26%で、残りは B が大きく見えた。C の見た平均の10〜90%の範囲は、10,000人で9〜21ポイントだった
- 式の順（C ＞ B ＞ A）どおりに見えた組は、100人で6.44%、1,000人で60.61%、10,000人で72.26%だった

### 確かめ：1回の平均15のまま、当たる確率と大きさを変える（式、`results/same_mean_variants.csv`）
| 当たる確率・当たりの大きさ | 10回で A より多い人 | 100回で A より多い人 | 1,000回で A より多い人 | 100回の真ん中の人 |
|---|---|---|---|---|
| 10%・150 | 65.13% | **88.28%** | 99.99% | 1,500 |
| 1%・1,500 | 9.56% | 63.4% | 87.11% | 1,500 |
| 0.1%・15,000 | 1.0% | 9.52% | 63.23% | 0 |
| 0.01%・150,000 | 0.1% | **1.0%** | 9.52% | 0 |

- **1回の平均は同じ15でも、100回引いて A より多くもらう人の割合は、当たりの大きさで1.0〜88.28%と動いた**。当たりがまれで大きいほど、平均では同じでも多くの人は A を下回った

## 注意（言えないこと）
- 架空の福引きです。当たる確率・当たりの大きさ・引く回数は作成者が置いたもので、結果はこれで決まります。1回の平均・標準偏差、10回で0ポイントの人の割合、A より多くもらう人の割合は、どれも二項分布の式どおりの値です。新しく数えたのは、物差し（平均・真ん中・A より多い人の割合・少人数で見た平均）によって、どれが得に見えるかの順が入れかわる様子です
- どの福引きを選ぶべきか、くじや賭けを引くべきか・やめるべきかの助言はしません。景品の設計や、くじの決まりについての助言もしません
- 福引きの結果は、人ごとに前の回と関係なく決まると置きました。当たりの本数が決まっている福引き（引くたびに残りが減る）では、数え方が少し変わります
- 実在の福引き・くじ・ゲームの確率を表すものではありません
- 関連する記事：840（1本のバズで、再生数の平均はどれだけ動くのか）は、まれな大きい値に平均が引っぱられる様子を投稿の数字で扱っています。828（ガチャの「1%」を100回引いても当たらない人は何%か）は、まれな当たりが何回で出るかを扱っています。834（くじは先に引くのと後に引くのでどちらが有利か）は、当たりの本数が決まったくじを扱っています。同じ企画の991「くじの当たりを『確率で山分け』すると、何がずれるのか？」は、取り分の見込み（平均）が同じでも、持ち寄ると0個になる割合（振れ）が大きく変わることを扱っています。この記事は、平均と多くの人がもらう量のずれに絞りました
