# 1009 項目の数を増やすと、合計点は安定するのか？（指数とスコア）

製品や店のスコアが月ごとに大きく上下すると、「項目を増やせば安定する」と考えたくなります。項目どうしのぶれが互いに打ち消し合えば、そのとおりになります。けれども、足した項目が既存の項目の言いかえで、同じ月に同じようにぶれるなら、数が増えてもぶれは打ち消し合いません。また、「月が変わっても同じ点が出る」ことは、「本当の良さに近い」こととは別です。**ここでは、作成者が乱数で作った架空の製品200点（本当の良さ・その項目だけの製品の癖・その月だけのぶれを作成者が置いたもの）を2か月続けて採点し、はじめの3項目に ①別々の良い項目 ②はじめの項目に似た項目 ③本当の良さとの結びつきが弱い項目 のどれかを足して3→18項目に増やしたとき、2か月の合計点のそろい方（安定）と本当の良さとの相関がどう動くかを数えました。**

製品・項目・採点はすべて架空のもので、実在の指数やランキングの数字は使っていません。

関連する記事 937 は、1人を評価する人の数を増やしたとき、どの評価者にも同じに見えるずれが残って外れが下がり止まることを数えています。この記事は、評価する人ではなく項目を増やす話で、足した項目の性質（別々か、似ているか、弱いか）で「安定」と「本当の良さへの近さ」が別々に動くことに絞ります。同じ企画の 1008（項目が互いに似ていると、合計点は何を測っているのか）は、似た項目が多い面に合計点が引っぱられることを数えています。1014（合計点の差が小さいとき、順位の差は意味があるのか）は月ごとの振れで隣の順位が入れかわる大きさ、1016（スコアを狙って動くと、スコアと本当の良さはずれていくのか）はスコアと本当の良さの結びつきが弱まる話です。

## 主な結果

### 項目の数と、安定・本当の良さとの相関（各300回の平均、`results/by_items.csv`）
| 足し方 | 項目の数 | 2か月の相関（安定） | 式 | 本当の良さとの相関 | 式 |
|---|---|---|---|---|---|
| はじめの3項目 | 3 | 0.7219 | 0.7209 | 0.7945 | 0.7924 |
| ①別々の良い項目 | 6 | 0.8274 | 0.8286 | 0.878 | 0.8783 |
| | 12 | **0.9026** | 0.9032 | **0.9328** | 0.9333 |
| | 18 | 0.9324 | 0.9326 | 0.9538 | 0.954 |
| ②はじめの項目に似た項目 | 6 | 0.7403 | 0.7416 | 0.8029 | 0.8037 |
| | 12 | **0.7651** | 0.7658 | 0.8145 | 0.8167 |
| | 18 | 0.7743 | 0.7763 | 0.8235 | 0.8223 |
| ③弱い項目 | 6 | 0.773 | 0.7727 | 0.7391 | 0.7385 |
| | 12 | **0.8162** | 0.8163 | **0.7418** | 0.7423 |
| | 18 | 0.8413 | 0.8415 | 0.7651 | 0.7651 |

（3項目の行は①の300回。②③の3項目は同じ置き方を別の乱数で数えたもので、`results/by_items.csv` にある）

- ①別々の良い項目を足すと、安定も本当の良さとの相関もそろって上がった。3→12項目で安定は0.7219→0.9026。これは項目どうしのぶれが打ち消し合う分を数えた**式どおり**の値で、置き方の写しです
- ②はじめの項目に似た項目を足すと、項目の数を4倍の12にしても安定は0.7651、18項目でも0.7743にとどまった。似た項目はその月のぶれをもとの項目と共有するので、数が増えても打ち消し合わない
- ③弱い項目を足すと、安定は0.8162（12項目）まで上がったが、本当の良さとの相関は0.7945から0.7418に下がった。弱い項目はその項目だけの製品の癖が大きく、癖は月が変わっても同じなので、2か月の点はそろう。そろうのは癖で、本当の良さではない
- ③で項目をさらに増やすと、本当の良さとの相関は9項目の0.733を底に18項目で0.7651と戻り始めた。癖が項目ごとに別なら、とても多く足せば癖も打ち消し合い、相関は上がっていく（式から言える向き）。18項目では、はじめの3項目にまだ届かなかった

### 上位20点（製品200点のうち上位1割）で見ると（各300回の平均）
| | 上位20点のうち、翌月も上位20点 | 上位20点のうち、本当の上位20点 |
|---|---|---|
| はじめの3項目 | 47.68% | 55.5% |
| ①別々の良い項目で12項目 | 69.32% | 73.63% |
| ②似た項目で12項目 | 52.28% | 57.13% |
| ③弱い項目で12項目 | **57.58%** | **50.82%** |

- ③では、翌月も上位に残る製品は47.68%→57.58%と増えたのに、本当の上位20点に入っていた割合は55.5%→50.82%と減った。「順位が毎月そろうようになった」ことは、当たるようになったことを示さない

### 確かめ：置き方を変えて（12項目、`results/robustness.csv`、値は式の値）
| 変えたもの | 値 | 安定 | 本当の良さとの相関 |
|---|---|---|---|
| ②似た項目が月のぶれを共有する度合い | 0（癖だけ共有） | 0.9118 | 0.8911 |
| | 0.5 | 0.8294 | 0.8499 |
| | **0.8（基本）** | 0.7658 | 0.8167 |
| | 0.95 | 0.7322 | 0.7986 |
| | 1（そっくり同じ） | 0.7209 | 0.7924 |
| ③弱い項目の a（本当の良さの係数）×b（癖）の12通り | | 0.5083〜0.9161 | 0.6343〜0.8687 |

- ②は、月のぶれを共有しないなら（0）、癖を共有していても安定は0.9118まで上がった。共有が1（そっくり同じ項目）なら、12項目にしても3項目のとき（0.7209・0.7924）と変わらない。似た項目が役に立つかどうかは、月のぶれをどれだけ共有しているかで決まる
- ③の12通りのうち、本当の良さとの相関が3項目のとき（0.7924）より下がったのは6通り（a が0.1と0.2のとき）、安定が3項目のとき（0.7209）より上がったのは8通りだった。安定が上がって相関が下がる、という両方がそろったのは2通り（b=0.8で a=0.1・0.2。基本の置き方はこの1つ）。b が小さい弱い項目では安定も下がった
- 本当の良さとの相関は、③では a だけで決まり、b を変えても同じだった（式どおり）
- はじめの項目の癖 b を0・0.4・0.6と変えると、3項目の安定は0.6279・0.7209・0.8372と動き、本当の良さとの相関はどれも0.7924だった。1つ1つの項目の安定が高いことと、本当の良さに近いことは別に動く

## 動かし方
```
pip install -r requirements.txt
cd src && python a1009_more_items_stability.py
```
10秒ほどで終わります。`data/products_example.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約8秒）
- 図3枚を開き、日本語・重なり・軸を確かめた
- 乱数で数えた安定と本当の良さとの相関が、置いた係数からの式の値と合うことを確かめた（項目の数と足し方の18通りで、安定は0.0037以内、相関は0.0022以内）。作りが置いたとおりに動いていることの確かめで、相関の値そのものは置いた前提の写しです。新しく数えたのは、上位20点が翌月も残る割合と本当の上位に入る割合が別々に動く大きさです

## データ
- `data/products_example.csv`：例の1回分の200点。product_id・true（本当の良さ）・k3_m1・k3_m2（はじめの3項目の合計点、1か月目・2か月目）・k12_A/B/C_m1・m2（①②③で12項目にした合計点）。この1回では、12項目の安定は①0.9077・②0.8019・③0.8403、本当の良さとの相関は①0.9324・②0.8531・③0.7582（`results/a1009_main.json` の one_draw_k12）
- `results/a1009_main.json`：主な結果すべて
- `results/by_items.csv`：3つの足し方×項目の数の、安定・順位相関・上位20点の値と式の値
- `results/robustness.csv`：置き方を変えた確かめ

## 注意（言えないこと）
- 架空のデータです。本当の良さ・癖・月のぶれの大きさ、似た項目の共有の度合い、弱い項目の係数は作成者が置いたもので、結果はこれで決まります。安定と相関の値は置いた係数からの式どおりです。弱い項目で本当の良さとの相関が下がるのは、12通りのうち a が0.2以下の6通りだけでした
- 本当の良さは作成者が置いたので分かっています。実際には分からないので、2か月の相関（安定）だけを見て「良い指数になった」とは言えない、というのがこの記事で言えることです。実際のデータで、どの項目が「似た項目」や「弱い項目」なのかを見分ける方法は数えていません
- 製品の本当の良さは2か月で変わらないと置きました。本当に良くなったり悪くなったりする製品があると、2か月の相関は下がります
- どの項目を残すべきか、項目をいくつにすべきかは、ここからは言えません
