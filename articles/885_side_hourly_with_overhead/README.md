# 885 案件の時給は、やり取りや修正の時間を入れるとどれだけ下がるのか？（副業の数字）

副業の案件の時給を「報酬÷作業時間」で出すと、打ち合わせ・連絡・見積もりのやり取りや、納めたあとの修正にかかった時間が入りません。やり取りの一部は案件の大きさによらず1件ごとにかかるので、作業時間の短い案件ほど、入れたときに時給が大きく下がるはずです。**ここでは、作成者が乱数で作った架空の案件3,000件（作業時間・報酬・やり取りの時間・修正の回数と時間を作成者が置いたもの）で、「作業時間だけで割った時給」と「やり取り・修正も入れて割った時給」を比べ、どれだけ下がるか、どの案件で下がるか、時給の上位の案件がどれだけ入れ替わるかを数えました。** 時給は円ではなく、作業時間だけで割った時給の全体の中央値を100とする指数で表しています。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A885 | やり取りと修正の時間を入れると、案件の時給はどれだけ下がるか。作業時間の短い案件と長い案件で違うか。時給の上位20%の案件はどれだけ入れ替わるか | 架空の案件3,000件。作業時間は1〜60時間（対数で一様）。作業時間だけで割った時給は案件ごとに対数正規（ばらつき0.3）で、作業時間とは関係なし。報酬＝時給×作業時間。やり取りの時間＝1件ごとの決まった分（平均 F＝1時間、ガンマ分布）＋作業時間の10%（c）。修正の回数は平均1.2回（λ、負の二項分布）、1回の修正は作業時間×15%（r）×0.5〜1.5の一様、さらに修正1回ごとにやり取り0.3時間。基本の置き方は案件を作り直して200回の平均。F（0・0.5・1・2時間）×λ（0.5・1.2・2.5回）×r（10・15・30%）の36通りで確かめた（各20回）。seed 885 | `src/a885_hourly_overhead.py` |

## 主な結果

### 基本の置き方（F＝1時間・λ＝1.2回・r＝15%、200回の平均）
| 作業時間 | 時給が下がった割合（中央値） |
|---|---|
| 3時間未満 | **48.6%** |
| 3〜10時間 | 31.5% |
| 10〜30時間 | 22.9% |
| 30時間以上 | 20.1% |
| 全体 | **30.5%** |

- やり取りと修正の時間を入れると、時給は中央値で30.5%下がった（200回の5〜95%の範囲で29.7〜31.2%）。報酬の合計÷時間の合計で見ると27.2%で、式（やり取り＋修正）÷（全部の時間）で出した27.3%とほぼ同じだった
- **作業時間3時間未満の案件では48.6%、30時間以上では20.1%下がった**。1件ごとの決まったやり取りが、短い案件ほど作業時間に比べて重くなるため
- 1回分のデータ（`data/projects.csv`）では、全部の時間のうちやり取りが12.5%、修正が14.8%だった

### 時給の上位20%の案件
| | 作業時間だけで割る | やり取り・修正も入れる |
|---|---|---|
| 上位20%のうち作業3時間未満の案件の割合 | 26.9% | 9.8% |

- 作業時間だけで割った時給の上位20%のうち、やり取り・修正も入れた時給でも上位20%に残ったのは65.1%だった（2つの時給の順位相関は0.73）
- 作業時間だけの時給では、上位20%の26.9%が作業3時間未満の案件だった。やり取り・修正を入れると9.8%に減った

### 修正の回数ごと（1回分のデータ）
| 修正の回数 | 0回 | 1回 | 2回 | 3回 | 4回以上 |
|---|---|---|---|---|---|
| 時給が下がった割合（中央値） | 16.5% | 29.2% | 35.9% | 45.1% | 54.1% |

### 確かめ：置き方を36通り変えると
| | 最小 | 最大 |
|---|---|---|
| 全体の下がり方（中央値） | 9.1% | 53.7% |
| 作業3時間未満の案件の下がり方 | 9.1% | 68.7% |
| 作業30時間以上の案件の下がり方 | 9.1% | 41.2% |
| 上位20%に残った割合 | 49.7% | 83.5% |

- **下がり方の大きさは、置いたやり取り・修正の量でほぼ決まった**（9.1〜53.7%）。最小の9.1%は、決まったやり取り0・修正の回数の平均0.5回で、中央の案件が修正0回になる置き方のときの値で、作業時間の10%のやり取りを足しただけの 0.1÷1.1 と同じ
- 作業3時間未満と30時間以上の差は、決まったやり取りを置いた27通りでは16.0〜42.2ポイントあった。**決まったやり取りを0にすると0〜14.8ポイントに縮んだ**（残った差は、修正1回ごとの0.3時間のやり取りによるもの）。短い案件ほど下がるのは、1件ごと・1回ごとに決まった時間がかかると置いたことの写しです

## 注意（言えないこと）
- 架空のデータです。やり取りの決まった時間・作業に比例するやり取りの割合（10%）・修正の回数と重さは作成者が置いたもので、下がり方の大きさはこれで決まります（36通りで9.1〜53.7%）。作業に比例するやり取りの割合10%は変えていないので、下がり方の下限（9.1%）もこの置き方の写しです。実際の案件でどれだけ下がるかは、ここからは言えません
- 作業時間だけで割った時給は、作業時間の長さと関係しないと置きました。短い案件ほど報酬が割高・割安といった関係は入れていません
- 修正の回数は案件の大きさや時給と関係しないと置きました
- 報酬・料金の決め方や、どの案件を受けるべきかについては何も言えません。この記事は時給の数え方だけを扱っています
- 関連する記事 886 は、時間帯を決めて対応する案件で、実働と拘束のどちらで割るかを数えています。この記事は、1件ずつ納める案件で、作業のほかにかかるやり取り・修正の時間を数えています。893 は、作業時間を15分単位で丸めて記録すると記録の合計がどれだけずれるかを数えています（短いやり取りが丸めで消えると、この記事のやり取りの時間がそもそも記録に残らない、という関係です）
