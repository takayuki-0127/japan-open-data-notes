# 264 1日の気温差（日較差＝日最高気温−日最低気温）は、小さくなっているのか

気象庁「過去の気象データ検索」の日ごとの値（14地点、1931〜2025年）を使ったフォルダです。262〜266の5本は同じデータ（`data/jma_daily_14st_1931_2025.tsv.gz`）を使っています。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A264 | 1日の気温差（日較差＝日最高気温−日最低気温）は、小さくなっているのか | 毎日の日較差を年平均し、1961〜1990年平均からの差を13地点で平均。1931年・1961年・1991年からの直線の傾き（HC1標準誤差）、地点別・季節別の傾き | `src/a264_diurnal_range.py` |

## 主な結果
- 13地点の平均で見ると、1930〜50年代は最低気温が低く、日較差は今より大きめでした。その後、最低気温が上がって日較差は縮み、1961〜1990年の平均は7.9℃、1996〜2025年は7.8℃です（1931〜1960年は8.1℃）。
- 1931〜2025年の直線では、日較差は100年あたり0.53℃（標準誤差0.09℃）小さくなりました。ところが1961年以降では−0.19℃（標準誤差0.14℃）と、はっきりしない大きさに縮み、1991年以降では+0.86℃（標準誤差0.32℃）と広がる向きでした。1991年以降は最高気温が100年あたり4.7℃、最低気温が3.8℃のペースで上がっています。
- 地点ごとに1931〜2025年の傾きを見ると、13地点のうち11地点で日較差が縮んでいました。大きく縮んだのは宮崎（100年あたり−1.6℃）、彦根（−1.2℃）、山形（−1.1℃）で、どれも最低気温の上がり方が最高気温より1℃以上大きい地点です。寿都と浜田では、逆に少し広がっていました。
- 東京は最低気温が100年あたり3.8℃上がり、最高気温の2.2℃を大きく上回って、日較差は1.6℃縮んでいました。大都市では夜の気温が下がりにくくなることが知られていて、それと合う結果です（推測）。
- 季節ごとに見ると、13地点の中央値で、日較差の縮み方は秋（9〜11月）が100年あたり0.85℃といちばん大きく、冬0.56℃、夏0.43℃、春0.27℃の順でした。どの季節も縮む向きです。

## 頑健性
- 13地点の地点ごとの傾きの中央値も100年あたり−0.52℃
- 季節別でも、4つの季節すべてで縮む向き（中央値）
- 期間平均で比べても、1931〜1960年8.1℃→1961〜1990年7.9℃→1996〜2025年7.8℃
- 東京を含めず13地点だけで計算している（東京は別に示した）
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致した

## 動かし方
```
pip install -r requirements.txt
cd src && python a264_diurnal_range.py
```
`src/fetch.py` は気象庁のページから同じ形のデータを取り直すスクリプトです（全地点・全月で約1.6万ページ。ふつうのネット環境向けで、このデータを取ったときはブラウザの中で同じページを読みました。このスクリプト自体は動かして確かめていません）。

## データ
- `data/jma_daily_14st_1931_2025.tsv.gz`：気象庁「過去の気象データ検索」日ごとの値（daily_s1、view=p1）を2026-11-12に取得し、地点・年・月・日・降水量合計・平均気温・最高気温・最低気温・降雪の深さ合計・最深積雪・天気概況（昼・夜）を取り出したもの（485,786行）。値の印（`)` 準正常値、`]` 資料不足値、`×` 欠測、`--` 現象なし）はそのまま残し、`src/common.py` で `)` は使う、`]`・`×` は欠測、`--` は0として読みます
- 地点：網走・根室・寿都・山形・石巻・伏木・飯田・銚子・境・浜田・彦根・多度津・宮崎（気象庁が長い気温の変化に使う、都市化の影響が比較的少ない15地点から、亜熱帯の名瀬・石垣島を除いた13地点）と、比べるための東京

## 注意
- 最高・最低気温の測り方（測器、1日の区切り方など）は、95年の間に変わっていて、その影響は補正していません
- 1991年以降の傾きは35年分で、年ごとの揺れの影響を受けやすい値です
- なぜ縮んだか、なぜ最近広がったか（雲の量、日照、都市化、大気のちりなど）は、このデータでは分けていません
- 地点の数は14で、日本全体の平均ではありません
