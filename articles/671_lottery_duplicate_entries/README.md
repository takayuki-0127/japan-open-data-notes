# 671 重複して登録した人を除かずに抽選すると、その人の当選確率は何倍になるのか（実務の型）

キャンペーンの抽選では、同じ人が何度も登録していることがあります。登録1件を1口として抽選すると、何度も登録した人ほど当たりやすくなります。重複を除くにも、メールアドレスの大文字・小文字や前後の空白といった表記ゆれがあると、完全一致では除ききれません。**ここでは、架空の応募1万人（重複登録を含む12,184件）から500本を抽選し、そのまま・完全一致で除く・表記をそろえて除くの3通りで、登録回数ごとの当選確率を2,000回のくり返しで数えました。** 数字は置いた重複の割合で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A671 | 重複登録を除かずに抽選すると、当選確率は何倍になるか | 応募1万人（88%が1回、7%が2回、3%が3回、2%が5回登録）。重複した登録の40%でメールに大文字・空白が混ざる。500本を N そのまま／E メールの完全一致で重複を除く／K 小文字・空白除去でそろえて除く、の3通りで抽選。2,000回、seed 671。重複を除いた件数は DuckDB の SQL でも出して一致を確認 | `src/a671_lottery.py`、`src/02_dedup_count_duckdb.sql`、`src/01_dedup_count_tsql.sql` |

## 主な結果
- **そのまま抽選すると、1回だけの人と比べて2回登録した人は1.97倍、3回で2.88倍、5回で4.60倍当たりやすい**（1回だけの人の当選確率4.10%、5回の人18.9%）
- 重複登録した人は応募者の12.6%だが、登録の28.3%、**当選の本数の28.3%**を取った
- **メールの完全一致で除いても、表記ゆれが残る**：12,184件が10,795件にしか減らず、5回登録した人はまだ2.24倍当たりやすい
- **表記をそろえて除くと**、1万件（1人1口）になり、登録回数によらず当選確率は5.0%でそろった
- 同じ人に2本目以降が当たった本数は、500本のうち平均でそのまま6.1本、完全一致で除いて2.0本、そろえて除くと0本

## 動かし方
```
pip install -r requirements.txt
cd src && python a671_lottery.py
```
1分ほどで終わります。`data/entries.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダで流し直し、results・figures・data がバイト単位で一致した
- 重複を除いたあとの件数（12,184・10,795・10,000）が、Python と DuckDB の SQL で一致すること
- 表記をそろえて除いた場合に、当選確率が 500÷10,000＝5% にそろうこと

## データ
- `data/entries.csv`：架空の応募の登録（entry_id・person_id・email・phone）。person_id は答え合わせ用の「本当の人」で、実際の抽選の現場では分からない列
- メールアドレスは example.com の架空のもの。電話番号も架空（ハイフンの有無が混ざる。この記事の重複の判定には使っていない）

## 注意（言えないこと）
- 架空のデータ。重複の割合と表記ゆれの起き方は作成者が置いたもので、結果はこれで決まる
- 本当の名寄せでは、同じ人が別のメールアドレスで登録することもあり、メールをそろえるだけでは除ききれない。電話番号や住所を組み合わせる方法（584 を参照）が要る
- SQL Server の既定の照合順序は大文字・小文字を区別しないことが多く、その場合は `COUNT(DISTINCT email)` でも大文字の違いは同じとみなされる。T-SQL 版は未検証
- 抽選の規約（1人1口か）や景品表示などの決まりの助言ではない
