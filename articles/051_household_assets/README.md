### household-flow-of-funds-japan：資金循環統計で、家計の金融資産の増え方と「買い方」を調べる

日本銀行「資金循環統計」の家計部門（ストック＝期末残高、フロー＝期中の取引）を、時系列統計データ検索サイトの API で取得して使ったリポジトリです。期間は1997年末〜2026年6月末（四半期）。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| F1 | 家計の金融資産の増加は「買った分」と「値上がりなど」のどちらによるか | 残高の前期差 ＝ フロー＋調整 の恒等式による分解（期間別・資産別）、構成比の推移 | `src/f1_decompose.py` |
| F2 | 家計は値上がりした後に買うのか、売るのか | 純購入率（フロー÷前期末残高）を値動き（調整÷前期末残高）とその過去の値に回帰。季節・NISA期間のダミー、HAC標準誤差 | `src/f2_chasing.py` |

#### 主な結果
- **F1**：家計の金融資産は1,285兆円（1997年末）→2,519兆円（2026年6月末）。1998年以降、株式等は差し引き47.5兆円の売り越しでしたが、調整（値上がりなど）が+447兆円で、残高は86兆円→486兆円。投資信託はフロー+96.5兆円・調整+71.4兆円。2024年以降（新NISA）は投資信託のフロー+30.0兆円・調整+56.8兆円、株式等はフロー−8.7兆円・調整+208.6兆円、現金・預金のフローは+3.7兆円にとどまる
- **F2**：投資信託の純購入率は、過去1年の値動きが1%高いと0.11ポイント高い（95%区間0.06〜0.16）。1〜2期前の値動きにも反応する。上場株式は過去の値動きとはほぼ無関係で、同じ期の値動きとはマイナスの関係（−0.065）。値動きを入れると、2024年以降の新NISA期間のダミーははっきりしたプラスにならない

| ファイル | 中身 |

日付の 202602 は2026年第2四半期（6月末）を表します。

#### 注意
- 「調整」は残高の変化からフローを引いた残りで、時価の変動のほか、分類の変更や推計の見直しも含みます
- 株式等には非上場株式・その他の持分が含まれ、その評価の変化も調整に入ります
- F2の同じ期の関係は、フローの測定誤差があると調整に逆向きの誤差が入るので、マイナスに偏りやすくなります。過去の値動きとの関係のほうが解釈しやすいです
- 投資信託の純購入には、NISA以外の口座や、分配金の再投資なども含まれます。個人単位の行動ではなく家計部門全体の集計です
- 2000年代前半の投資信託の大きな動きには、MMFなど公社債投信の増減が含まれます
