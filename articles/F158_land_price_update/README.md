# F158 地価の予測を、毎年の公示で更新していくとどうなるか？

看板記事 F158。F03（地価公示を LightGBM で予測）と F91（解釈手法の比較）の続編です。

地価公示の2017〜2026年の価格で、まず「2017年に作ったモデルを使い続ける」「毎年学習し直す」「2年・3年・5年ごとに学習し直す」などの更新のしかたを比べました。比べたのは、その年の公示価格を、見ていない場所でどれだけ当てられるかです。次に、年ごとのモデルで特徴量の重要度（SHAP）がどう移り変わったかを見ました。

note：「地価の予測を、毎年の公示で更新していくとどうなるか？…」（下書き）

## 問い

- 地価の予測モデルを作ったあと、更新しないと、何年でどれだけ外れるようになるか
- どのくらいの間隔で学習し直せば十分か。前年の公示までしか使えない「1年遅れ」で、どれだけ損をするか
- 外れが広がるのは、地価の水準が全体に動くからか、それとも効き方そのものが変わるからか
- 年ごとのモデルで、何が効いているか（重要度）は変わったか

## データ

| データ | 内容 |
|---|---|
| 地価公示（国土数値情報 L01、2026年） | 25,565地点。各地点の 1983〜2026 年の価格の列（L01_062〜L01_105）から 2017〜2026 年を使用（各年 23,282〜25,565 地点、計244,684）。年ごとの選定の有無（L01_061）と属性移動（L01_106〜L01_148）も |
| 地点の特徴量 | F03 と同じ30個（駅までの距離・地積・容積率・用途地域・周りの駅の乗降客数・三大都市の中心までの距離・市区町村の人口と増減率・緯度経度など） |

- 取り出し方は `src/01_取得.py`、加工済みは `data/raw/l01_price_history.csv`（地点×年の価格と属性移動）と `data/panel.csv`（年×地点の長い表）です。
- 特徴量は F03 の `articles/F03_land_price_ml/data/features.csv` を読みます（`src/02_整形.py`）。

**注意：特徴量はすべて2026年時点の値です。** 地点の属性（地積・用途地域など）は2026年の公示、乗降客数は2024年、市区町村の人口は2020年の国勢調査です。2017〜2026年に属性が変わった地点は全体の27%あります。そこで頑健性として、10年間属性が変わらなかった地点だけでもやり直しました。

## 手法

| 項目 | 内容 |
|---|---|
| 目的変数 | log(公示価格) |
| モデル | LightGBM（学習率0.1、葉63、300本、max_bin 63、行・列のサブサンプリング0.8） |
| 検証の分け方 | 20km四方のブロック単位の5分割（全年で同じ分け方）。学習側のブロックで作ったモデルで、検証側のブロックの地点を予測する。予測する年 T（2018〜2026年）には、T−1年までの公示しか使わない |
| 更新のしかた | ①毎年更新：T−1年の公示で学習<br>②2年・3年・5年ごと：最後に学習し直した年 s のモデルに、学習側の地点で測った s→T−1 年の全国の変化（中央値）を足す<br>③直近3年をまとめて学習：T−3〜T−1年を、全国の変化で T−1年の水準にそろえて学習<br>④2017年のまま<br>⑤2017年のまま＋全国の変化で補正<br>⑥2017年のまま＋都道府県ごと、または都道府県×用途ごとの変化で補正（03c）<br>参考：T年の公示で学習（1年遅れなし） |
| 評価 | 誤差＝\|予測÷実際−1\| の中央値、±20%以内の割合、log の RMSE、予測÷実際−1 の中央値（偏り） |
| 重要度 | 各年の全地点で学習したモデルを、10年すべてにある3,000地点で SHAP 分解（TreeExplainer）。地点のブートストラップ2回を足した3回で、ぶれの幅を見る。特徴量を5つのまとまり（駅と乗降客数、用途地域・容積率など、土地と建物の条件、都心からの距離・位置、市区町村の人口）に分けて割合を出す |

## 主な結果

### 1. 更新しないと、外れは年に0.8ポイントずつ広がった（図1）

見ていない場所の予測の誤差（中央値）は次のとおりです。

| 予測する年 | 2017年のまま | 毎年更新 | 参考：その年で学習 |
|---|---|---|---|
| 2018年 | 17.3% | 17.3% | 16.9% |
| 2022年 | 19.1% | 18.1% | 18.0% |
| 2026年 | **23.8%** | **19.4%** | 19.5% |

- 2017年のモデルのままだと、2026年には±20%以内に入る地点が56%から42%に減りました。
- 毎年更新すると、「その年の公示で学習した場合」とほぼ同じでした。前年までしか使えない1年遅れの損は、平均0.0ポイントです（どちらも2018〜2026年の平均18.2%）。
- 毎年更新でも誤差は17.3%から19.4%に、その年で学習した場合も16.9%から19.5%に広がりました。地価のばらつきそのものが広がったためと考えられます（推測、下の3）。

### 2. 2年に1回の更新で、毎年更新とほぼ同じだった（図2）

2018〜2026年の平均誤差は次のとおりです。

| 更新のしかた | 平均誤差 |
|---|---|
| 毎年更新 | 18.2% |
| 2年ごと | 18.3% |
| 3年ごと | 18.5% |
| 5年ごと | 18.8% |
| 直近3年をまとめて学習 | 18.4% |
| 2017年のまま＋全国の変化で補正 | 19.6% |
| 2017年のまま＋都道府県ごとの変化で補正 | 19.3% |
| 2017年のまま＋都道府県×用途ごとの変化で補正 | 19.3% |
| 2017年のまま | 19.8% |

- 直近3年をまとめて学習しても、毎年更新より良くはなりませんでした。
- 全体の水準を足すだけの補正は、都道府県×用途ごとにしても、2026年に23.8%を22.4%にする程度でした。2017年のままにするよりはましですが、学習し直した場合の19.4%には届きません。

### 3. 外れの原因は、全体の水準より「差の開き」（図3）

- 2017年のままの予測は、年を追うごとに低めにずれました。予測÷実際−1 の中央値は、2018年の −2.5% から2026年の −12.2% になりました。
- 同じ期間に、上から10%の地点と下から10%の地点の価格の比は、16.8倍から25.5倍に開きました。
- 全国・都道府県・用途ごとの平均的な変化を足しても、外れはあまり戻りません。高い場所はより高く、安い場所はより安くなる「差の開き」が、地域の中でも起きていたためです。

### 4. 重要度の顔ぶれはほぼ同じで、効き方が強くなった（図4・図5）

- 5つのまとまりの重要度の割合は、10年でほとんど動きませんでした（2017年→2026年）。

| まとまり | 2017年 | 2026年 |
|---|---|---|
| 駅と乗降客数 | 53% | 56% |
| 用途地域・容積率など | 16% | 15% |
| 土地と建物の条件 | 12% | 12% |
| 都心からの距離・位置 | 13% | 10% |
| 市区町村の人口 | 7% | 8% |

- 特徴量ごとの重要度の順位の相関（2017年と各年、Spearman）は 0.99〜0.93 でした。
- いちばん動いたのは市区町村の人口増減率（2015→20年）で、割合は1.6%から3.5%になりました（ブートストラップの幅は2017年1.6〜1.8%、2026年3.5〜3.8%）。減ったのは経度（4.4→2.8%）・緯度（5.6→4.7%）・用途地域（4.1→3.2%）です。
- 効き方（SHAP を%に換算した区間の平均）は、同じ特徴量で強くなっていました。

| 特徴量・区間 | 2017年 | 2026年 |
|---|---|---|
| 人口増減率：−8%未満の市区町村 | −3% | −13% |
| 人口増減率：+3%超の市区町村 | +4% | +10% |
| 10km内の乗降客数：いちばん少ない8分の1 | −18% | −24% |
| 10km内の乗降客数：いちばん多い8分の1 | +30% | +37% |

## 頑健性（図6、`results/robust_by_variant.csv`）

2018〜2026年の平均誤差（中央値）を比べました。

| 条件 | 毎年 | 2年ごと | 5年ごと | 2017年のまま＋全国補正 | 2017年のまま |
|---|---|---|---|---|---|
| 基本 | 18.2% | 18.3% | 18.8% | 19.6% | 19.8% |
| 属性が10年変わらなかった地点だけ（73%） | 18.5% | 18.5% | 18.9% | 19.7% | 19.8% |
| 地点単位のランダム5分割 | 13.9% | 14.0% | 14.7% | 15.7% | 15.9% |
| 住宅地だけ | 17.3% | 17.4% | 17.6% | 18.3% | 18.4% |
| 小さいモデル（葉15・200本） | 19.3% | 19.3% | 19.7% | 20.4% | 20.5% |
| リッジ回帰 | 27.9% | 27.9% | 28.0% | 28.5% | 28.5% |

- どの条件でも、並びは「毎年≒2年ごと＜5年ごと＜2017年のまま」で同じでした。
- リッジ回帰は、もともとの外れが大きいぶん、更新による差は0.6ポイントと小さくなりました。

## 言えないこと

- 見ていない場所の予測（公示のない土地の値付け）での比較です。公示のある地点なら、前年の価格をそのまま使うだけで誤差の中央値は1.3%です。モデルで当てるよりずっと小さいので、同じ地点の翌年の予測には、このモデルは向きません。
- 特徴量は2026年時点の値です。過去の年の地点の属性や乗降客数・人口が実際とずれている分、過去の年のモデルの精度は低めに出ている可能性があります。属性が変わらなかった地点だけでも並びは同じでしたが、乗降客数・人口の時点のずれは残ります。
- 2026年の公示に残っている地点だけを使っています。途中で廃止された地点は入っていません。
- 重要度（SHAP）は「モデルが何を手がかりにしたか」で、地価を動かした原因ではありません。人口増減率の効きが強まったことは、人口が増える市区町村ほど地価が上がりやすくなったことと整合しますが、因果は言えません。
- 10年・1つのモデルでの結果です。地価の動きが小さい時期や、別の種類のモデルでは、更新の間隔の答えは変わりえます。
- どの地域で外れやすいかの地図は、この記事では扱っていません。
