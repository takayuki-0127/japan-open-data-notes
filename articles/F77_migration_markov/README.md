# F77 今の人の流れが続くと、人口の分布は最後にどうなるか？（マルコフ連鎖・定常分布）

看板記事 F77。都道府県間の引っ越し（日本人）を「1年後にどの県にいるか」の推移確率にして、マルコフ連鎖の定常分布と収束の速さを計算しました。

## 問い
- 2025年の人の流れがこのまま続いたら、都道府県の人口の割合は最後にどこに落ち着くか
- そこにどれくらいの速さで近づくか
- 年ごとの流れで、行き着く先はどう変わってきたか（コロナで変わったか）
- 出生・死亡も入れると、社人研の将来推計とどれくらい似るか

## データ
| データ | 出典 | 使い方 |
|---|---|---|
| 都道府県間移動者数（日本人、2010〜2025年） | 総務省「住民基本台帳人口移動報告」（F33 の data/panel.csv を再利用） | 推移確率の分子 |
| 都道府県の日本人人口・出生数・死亡数（2012〜2023年） | 統計センター SSDSE-B-2026（F10 の data/raw を再利用） | 推移確率の分母、出生率・死亡率 |
| 都道府県の人口（2025年） | 総務省「令和7年国勢調査 人口等基本集計」（F45 の data を再利用） | いまの割合、投影の出発点 |
| 都道府県の将来人口（2050年） | 国立社会保障・人口問題研究所「日本の地域別将来推計人口（令和5年推計）」（F45 の data を再利用） | 比較 |

新しいダウンロードはしていません。`src/01_取得.py` は前の記事の GitHub から元のファイルを取り直します（data/raw は大きいので GitHub には置いていません）。

## 手法
- 推移確率：P[i,j] = （i→j の移動者数）÷（i の日本人人口）、P[i,i] = 1 − 転出率
- 定常分布 π：π P = π を満たす分布（P の固有値1の左固有ベクトル）
- 収束の速さ：P の2番目に大きい固有値 λ2 から半減期 log(0.5)/log(λ2)、と、2025年の割合から P を繰り返したときの定常分布までの差（全変動距離）が半分になる年数
- 出生・死亡を入れた投影：A = P + diag(出生率 − 死亡率)（2023年の率で固定）を2025年の人口に25回かけて2050年を出し、社人研の推計と比べる
- 移動者数のゆらぎ：移動者数をポアソン分布で500回引き直して定常分布の区間を出す

## 主な結果
- 2025年の流れが続くと、1都3県の割合は **30.1%（2025年）→ 35.9%（定常分布）**、東京都は 11.6% → 13.9%
- 割合が増えるのは10都府県（千葉1.21倍・東京1.20倍・埼玉1.18倍・神奈川1.18倍・大阪1.07倍・福岡1.05倍など）、37道県は減る（最も減るのは高知0.69倍、秋田0.71倍、山形0.72倍）
- 近づくのはとても遅い：λ2 = 0.991、半減期は約79年。2025年の割合から始めると、定常分布までの差が半分になるのに49年。移動だけなら1都3県の割合は2050年 31.8%、2075年 33.0%
- 年ごとの定常分布（1都3県）：2012年 30.9% → 2019年 36.6%（最大）→ 2021年 33.9%（コロナ）→ 2025年 35.9%
- 出生・死亡も入れた2050年：総人口 1億360万人（社人研 1億469万人）、1都3県の割合 33.1%（社人研 33.7%）。都道府県の割合の変化は社人研と相関0.94
- 出生・死亡を入れたまま長く続けると、1都3県の割合は 39.7% まで上がる

## 頑健性（1都3県の定常分布での割合）
| 設定 | 割合 |
|---|---|
| 基本：2025年の流れ | 35.9% |
| コロナ前 2017〜19年の平均 | 35.8% |
| コロナ期 2020〜22年の平均 | 34.4% |
| 直近 2023〜25年の平均 | 36.0% |
| 人口に外国人も含める | 36.2% |
| 人口を2025年国勢調査に | 36.6% |
| 北海道・沖縄を除く（45都府県の中での割合） | 38.1% |
| 移動者数のゆらぎ（95%区間） | 35.8〜36.0% |

## 言えないこと
1. 定常分布は「今の転出率がこの先も変わらない」と仮定したときの行き着く先で、予言ではありません。実際には、人口が減った県では転出する人の数も年齢構成も変わります
2. 移動は日本人の国内移動だけで、海外との出入りは入っていません
3. 年齢を分けていないので、若い人ほど動くこと、高齢化で動く人が減ることは入っていません
4. 出生・死亡を入れた投影は2023年の率を固定した単純な計算で、社人研の推計（年齢別）とは方法が違います
