# F57 インフルエンザの流行は、SIRモデルで再現できるか？

**看板記事 F57**：12シーズンのインフルエンザの週次データに SIR モデルを当てはめると、型の違う2つの流行を足せば山の形はほぼ再現できたが、山の4週前の時点では時期も高さも当てられなかった

## 問い

感染症発生動向調査のインフルエンザの「定点当たり報告数」（全国・週次）に、数理モデル（SIR／SEIR）を当てはめると、

1. 流行の形（立ち上がり・山の高さ・下がり方）をどこまで再現できるか
2. シーズン初めの実効再生産数（Reff0）はどれくらいで、増加率から出す R と合うか
3. 途中までのデータで、山の時期と高さを予測できるか

## データ

| データ | 内容 | 出典 |
|---|---|---|
| 感染症発生動向調査（IDWR 速報データ） | インフルエンザの定点当たり報告数、全国（「総数」の行）と47都道府県、2012年第37週〜2026年第42週 | 国立健康危機管理研究機構（旧 国立感染症研究所）。F52 で取得したデータを再利用 |
| 人口 | 都道府県の日本人人口（2023年） | F10 のデータを再利用 |

- 対象は 2012/13〜2019/20 の8シーズンと、2022/23〜2025/26 の4シーズンの計12シーズン（シーズン＝第36週〜翌年第35週）。2020/21・2021/22 はほとんど流行がなかったので除いた
- 2025年第14週から定点が急性呼吸器感染症（ARI）定点に変わったため、2025/26 の水準は前と少し違う

## 手法

| モデル | 中身 |
|---|---|
| M1 | 1つの SIR（β は一定） |
| M2 | 1つの SIR ＋ 年末年始（12/27〜1/7）の β の倍率 h |
| M3 | 2つの SIR（型の違う2つの流行、感受性者は別々）＋ h |

- 報告数 y＝c×その週の新しい感染（割合）＋b（下限の報告）とし、log(y+0.3) の残差の二乗和が最小になるように当てはめた（scipy の least_squares、初期値を変えて10回）
- 感染期間 D＝3日（γ＝1/3）。SEIR では潜伏期間 L＝1.5日を足した
- 割合で書いた SIR では、感受性者の割合 s0 と報告率 c は見分けられない。推定できるのは「シーズン初めの実効再生産数 Reff0＝β/γ×s0」と流行の形だけ
- 比べる指標として、立ち上がり（報告数が初めて1以上になった週〜山の週）の週ごとの増加率から R を出した（世代時間をガンマ分布：平均3.0日・標準偏差1.5日と仮定）
- 予測の確かめ方：山の6・4・2・0週前までのデータだけで当てはめ、山の週（±1週以内）と高さ（2/3〜1.5倍）を当てられたか
- 都道府県ごと（コロナ前8シーズン）にも M1 を当てはめ、Reff0 のばらつきを見た

## 主な結果

| | SIR 1つ（M1） | SIR 2つ＋年末年始（M3） |
|---|---|---|
| Reff0（12シーズンの中央値・範囲） | 1.20（1.10〜1.30） | 主な山 1.36（1.16〜1.71） |
| 山の高さ（モデル÷実際、中央値・範囲） | 0.84（0.55〜1.11） | 1.00（0.81〜1.25） |
| 山の週のずれ（±1週以内） | 12シーズン中6 | 12シーズン中10 |
| 当てはまり（log の RMSE、中央値） | 0.40 | 0.16 |

- **1つの SIR は山を低く見積もる**：高さはふつう8割ほど、低いシーズン（2012/13・2024/25）では6割に届かなかった。2つの流行を足した M3 は、AIC で12シーズンすべて M1 よりよかった。山が2つあるシーズン（2023/24・2025/26）は、1つの SIR ではまったく再現できない
- **増加率から出す R**：3週平均の最大は 1.33（1.12〜1.41）。SIR 1つの Reff0 との相関は 0.71
- **R は仮定しだい**：同じデータでも、感染期間を2日にすると Reff0 は 1.13、4日で 1.27、SEIR（潜伏1.5日）で 1.31。増加率から出す R も、世代時間の平均を2.6日にすると 1.28、3.5日で 1.39。データから決まるのは「増える速さ」で、R の値は世代時間の仮定で変わる
- **年末年始の効果は推定できなかった**：倍率 h は M2 で 0.73〜1.50、M3 で 0.59〜1.29 と、シーズンで向きまで変わった
- **最終規模**：M1 の Reff0 から計算すると、実効的な感受性者のうち感染する割合は 31%（18〜43%）。人口全体の割合ではない
- **予測**：

| 当てはめに使ったデータ | 山の週 ±1週（M1／M3） | 山の高さ 2/3〜1.5倍（M1／M3） |
|---|---|---|
| 山の6週前まで | 0%／8% | 0%／25% |
| 山の4週前まで | 8%／8% | 25%／25% |
| 山の2週前まで | 33%／50% | 42%／17% |
| 山の週まで | 58%／83% | 67%／92% |

  山の4週前の時点では、時期も高さもほとんど当てられなかった。山の手前では、増え方のわずかな違いで山の位置と高さが大きく変わる

- **都道府県**：Reff0 の中央値は 1.22（10〜90%点 1.16〜1.29）。同じ県のシーズンどうしの順位の相関は平均 0.20 で、毎年同じ県が高いわけではない。人口（対数）との順位相関は 0.11（p=0.48）

## 頑健性

| 設定 | M1 の Reff0 | M3 の Reff0 | M1 の山の高さの比 |
|---|---|---|---|
| 基本 D=3日 | 1.20 | 1.36 | 0.84 |
| D=2日 | 1.13 | 1.23 | 0.84 |
| D=4日 | 1.27 | 1.49 | 0.85 |
| SEIR 潜伏1.5日 | 1.31 | 1.59 | 0.84 |
| log の足し算 0.1 | 1.19 | 1.36 | 0.70 |
| log の足し算 1.0 | 1.21 | 1.36 | 0.84 |

（12シーズンの中央値）。どの設定でも、1つの SIR は山を低く見積もり（0.70〜0.85）、2つ足すとほぼ1になった。

## 言えないこと

- SIR は「全員が同じように混ざる」と仮定している。年齢・学校・地域の違いは入っていない。2つ足してよく合うのは、型の違いだけでなく、こうした違いを2つの山でまとめて表しているだけかもしれない
- s0（流行の前に免疫を持っていない人の割合）と報告率は分けられないので、何人が感染したかは分からない。最終規模の31%は「実効的な感受性者のうち」の割合
- 定点当たり報告数は医療機関を受診した人の数で、受診の行動（休みの日、混み具合、検査の方針）で変わる
- 2025/26 は定点の種類が変わったので、それ以前とそのままは比べられない
- 都道府県の結果は集計値の比較で、どの県から広がったかや、県の対策の良し悪しを示すものではない

## 動かし方

```
pip install -r requirements.txt
cd src
python 01_取得.py      # 入力ファイルの確認（取り直しは F52 の 01_取得.py）
python 02_整形.py      # 全国・都道府県の週次の表
python 03_分析.py nat  # シーズンごとの当てはめ
python 03_分析.py fc   # 山の予測
python 03_分析.py rb   # 頑健性
python 03_分析.py pref # 都道府県
python 04_図.py
```
