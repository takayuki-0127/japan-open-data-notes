# 1304 届ける順に取り出せるよう、あとで届ける荷物を奥に積む決まりを入れると、積載率はどれだけ下がるのか？（箱詰めと積載）

配送の車に荷物を積むとき、届ける順を気にしなければ、奥行きのそろった荷物どうしを同じ列に並べて、荷台の床をすきまなく使えます。けれども、配送先で荷物を取り出すたびにほかの荷物をどかすことになります。そこで「あとで届ける荷物ほど奥に積む」決まりを入れると、取り出しは楽になりますが、並べる順が届ける順で決まってしまうので、奥行きの違う荷物が同じ列にまざり、列ごとにすきまが残ります。**ここでは、作成者が置いた架空の配送（荷台の床は幅200cm・奥行き420cm、1日に40か所へ届け、1か所の荷物は平均2個、荷物の幅と奥行きは30〜90cmで乱数で作ったもの）で、①決まりなし、②あとで届ける荷物を奥に積む決まり、③さらに配送先ごとに列を分ける決まり、の3つで、要る車の台数と床の積載率を300日分数えました。荷物の大きさ3通り×1か所の荷物の数3通りの9通りと、②の列の切れ目をいちばん良く選ぶ積み方でも確かめました。**

すべて作成者が置いた決まりでのシミュレーションです。荷物は床に並べるだけで上に重ねず、向きも変えないと置きました。実在の配送・車・荷物の数字を表すものではありません。

関連する記事：1295「荷物を来た順に詰めるか、大きい順に並べ替えてから詰めるかで、使う車の台数と積載率はどれだけ違うのか？」は、来た順に詰めるか、大きい順に並べてから詰めるかで、台数と積載率がどれだけ違うかを数えています。1297「上に重ねられない荷物が1割まざると、体積で見た積載率はどれだけ下がり、車は何台増えるのか？」は、上に重ねられない荷物の上の空きが体積の見込みに入らず、置き方の決まりしだいで台数が増えることを数えています。1300「配送先の方面ごとに分けて詰め、方面をまぜないと、全部をまとめて詰めるより車は何台増えるのか？」は、方面ごとに車を分けると、方面ごとの最後の1台の切り上げが重なって台数が増えることを数えています。1303「詰め方の良さを、『体積の合計÷容量』の切り上げと比べるか、いちばん良い詰め方と比べるかで、どれだけ見え方が違うのか？」は、詰め方の良さを「体積の合計÷容量」の切り上げ（下限）と比べるか、いちばん良い詰め方と比べるかで、無駄の大きさの見え方がどれだけ違うかを数えています。この記事は逆に、並べる順が届ける順で縛られると、どれだけ積めなくなるかを数えます。①決まりなしも「奥行きの大きい順に並べてから詰める」1つの積み方で、いちばん良い積み方ではありません。

- **あとで届ける荷物を奥に積む決まりを入れると、床の積載率は72.4%から56.21%に16.19ポイント下がり、車は1日平均1.36台（28.79%）増えた**。300日のうち98.0%の日で台数が増えた
- 決まりなしでは奥行きのそろった荷物を同じ列に並べられるが、決まりがあると並べる順が届ける順で決まり、奥行きの違う荷物が同じ列にまざって、列ごとにすきまが残る
- ①で決めた車の受け持ちのまま②で積むと、要る奥行きの合計は①の1.2828倍になり、80.03%の車で荷台の奥行き（420cm）を超えた（`same_load`）
- 配送先ごとに列まで分けると（③）、積載率は41.96%まで下がり、車は1日平均3.427台増えた

- `results/a1304_main.json`：主な結果すべて（base・base_extra_trucks_dist・grid_summary）
- `results/base_extra_trucks_dist.csv`：基本の300日で①より増えた台数ごとの日数

## 注意（言えないこと）
- 架空のデータです。荷台の大きさ、荷物の大きさと数、配送先の数、積み方は作成者が置いたもので、結果はこれで決まります。下がり幅は、荷物の大きさと1か所の荷物の数の9通りで6.83〜36.77ポイントと大きく動きました
- 荷物は床に並べるだけで、上に重ねない・向きを変えないと置きました。重ねたり向きを変えたりできると、決まりがあっても下がり幅は小さくなる向きと考えます（推測。数えていません）
- 荷物を幅の向きの「列」に並べる単純な形です。列をまたいで荷物を置く積み方は入れていません
- ①は「奥行きの大きい順に並べてから入る最初の列へ」の1つの積み方で、いちばん良い積み方ではありません。①がもっと良く積めるなら、下がり幅はもっと大きく出る向きです（推測。数えていません）
- 車は届ける順に配送先を受け持つと置きました。どの配送先をどの車に受け持たせるかを選び直すことは入れていません
- 取り出しにかかる時間や手間は数えていません。決まりを入れるべきかどうか、どの車を何台用意するか、送料・料金の決め方の助言をする記事ではありません
