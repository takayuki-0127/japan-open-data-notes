# 352 専門用語には、最初に一言の説明が付いているか（④ 振り返り R107）

note に下書きした記事の原稿（手元の md）で、50の専門用語が本文に最初に出てくる所を探し、その場に説明が付いているかを数えた

## 問い

- 「専門用語は最初に一言で説明する」という決まりは、どれだけ守れていたか
- 説明なしで使われやすい用語はどれか
- 記事のグループで違うか

## 主な結果（`results/by_term.csv`、`results/by_group.csv`）

- 記事と用語の組1,201のうち、最初に出た所に説明があったのは195組（16%、機械の判定）
- 説明のしかたは、ふつうの言葉が先（用語はかっこの中）が117組、「用語を先に」の節が41組、直後のかっこが24組

## 確かめたこと（`results/manual_check_table.csv`）

- 機械が「説明つき」とした24組を読むと、21組は説明になっていた。3組は、値の注記（「（決定係数は0.78）」）や別の文の続きだった
- 機械が「説明なし」とした26組を読むと、1組は説明になっていた（「…引き直すブロック・ブートストラップ」のように、用語の前に説明が付く形）。2組はどちらとも言える
- この読みで直すと、説明つきの割合は17〜24%になる（推測。50組からの見積もり）
- 判定の決まりは、最初の版を50組読んで直した。直す前は「（対数）」「（標準誤差0.017）」のような注記を説明に数えていて、38%と出ていた
- `src/a352.py` を空のフォルダで流し直し、results と figures が一致することを確かめた

## 言えないこと

- 見たのは最初に出てくる所だけ。2回目以降に説明した場合や、図の説明に書いた場合は「説明なし」になる
- 用語の前に説明が付く形（「…する交差検証」）は、機械では拾えない。目で読んだ26組のうち1〜3組がこれに当たる
- 「中央値」のように、説明がなくても読める人が多い用語もある。説明が要るかどうかは読む人で変わる。ここで数えたのは、決まりどおりに書いたかどうかだけ
- 50語は自分で選んだ。選び方を変えると割合は変わる。「p値」は、地震の記事では別の意味（余震の減り方の指数）で使っていた
- 題名に出た用語は数えていない
- 原稿は note の下書きのもとになった md で、note の画面で直した分は入っていない
