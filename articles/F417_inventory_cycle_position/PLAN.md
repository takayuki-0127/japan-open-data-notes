# F417 事前の計画（PLAN）

作成：2026-11-18 12:05（JST）。指数の値を集計する前に書いた。

## 問い
鉱工業指数の「在庫循環図」は、横軸に出荷（または生産）の前年同期比、縦軸に在庫の前年同期比をとった図です。経済産業省の解説では、景気の局面に合わせて「意図せざる在庫減 → 在庫積み増し → 在庫積み上がり → 在庫調整」と反時計回りに回るとされます。

この図で、製造業の景気の位置は本当に分かるのか。2009〜2026年の四半期で、図の上の位置（局面）と、内閣府が決めた景気の山・谷（拡張期・後退期）を照らし合わせます。出荷の伸びだけを見る場合と比べて、在庫を足すと何が分かるのかも確かめます。

## 知りたい人
月次の鉱工業指数や月例経済報告の在庫の話を読む人。製造業の取引先の在庫や受注を見ていて、「今は在庫調整の局面か」を数字で確かめたい人。景気の予測や投資の判断は扱わない（図の読み方まで）。

## データ
- 経済産業省「鉱工業生産・出荷・在庫指数」の業種別・原指数（四半期、e-Stat の掲載ファイル）。2010年基準（2008〜2018年）、2015年基準（2013〜2023年）、2020年基準（2018年〜2026年7〜9月期）。出荷・在庫（期末）・生産。
- 同 月次の原指数（頑健性に使う）。
- 内閣府経済社会総合研究所「景気基準日付」（山：2008年2月・2012年3月・2018年10月、谷：2009年3月・2012年11月・2020年5月）。2020年5月の谷のあとの山は、まだ決められていない。

### 取得前に見たもの（下見）
- 各ファイルのシート名・見出し・業種の名前と、期間（列の最初と最後）だけを見た。指数の値はまだ見ていない。
- 2015年基準と2020年基準は業種の区分が同じ（鉄鋼・非鉄金属、生産用機械、汎用・業務用機械、電子部品・デバイス、電気・情報通信機械、輸送機械、化学など15業種）。2010年基準は区分が違う（鉄鋼と非鉄が別、電気機械と情報通信機械が別など）。
- 景気基準日付のページで、山・谷の月を見た。

## 手法
1. 前年同期比（%）：各基準の原指数から計算し、つなぐ。2009〜2013年は2010年基準、2014〜2018年は2015年基準、2019年以降は2020年基準（どれも、その基準の中で前年同期と比べる）。
2. 局面の分け方（先に決める。x＝出荷の前年同期比、y＝在庫の前年同期比）
   - 回復（意図せざる在庫減）：x > 0 かつ y ≤ 0
   - 積み増し：x > 0 かつ y > 0 かつ x ≥ y（45度線の下）
   - 積み上がり：y > 0 かつ y > x（45度線の上）
   - 調整：x ≤ 0 かつ y ≤ 0
3. 景気の局面：月を「拡張」「後退」に分け（山の月は拡張、谷の月は後退に入れる）、3か月のうち2か月以上が後退の四半期を「後退期」とする。2020年7〜9月期以降は山が決まっていないので「拡張（暫定）」とし、評価から外す確かめもする。
4. 照合：(a) 後退期の四半期のうち「積み上がり・調整」の割合、拡張期のうち「回復・積み増し」の割合。(b) 「出荷の伸び − 在庫の伸び」（x − y）と、出荷の伸び（x）のそれぞれで後退期を見分ける力（AUC：0.5なら当てずっぽう、1なら完全）。(c) x − y と生産の伸びの、先行・遅行の相関（−4〜+4四半期）。
5. 業種別（2014年以降、15業種）：各四半期で、鉱工業全体と同じ局面にいる業種の割合。
6. 直近（2026年7〜9月期）の位置を示す。

## 仮説（外れの基準つき）
- H1：後退期の四半期の75%以上が「積み上がり」か「調整」にある。外れ：75%未満。
- H2：拡張期（2020年4〜6月期まで）の四半期の60%以上が「回復」か「積み増し」にある。外れ：60%未満。
- H3：後退期を見分ける力（AUC）は、x − y の方が x（出荷の伸びだけ）より高い。外れ：x − y の AUC が x 以下。
- H4：業種別では、平均して半分以上の業種が全体と同じ局面にいる。外れ：平均50%未満。

## 頑健性（3つ以上）
1. 横軸を出荷ではなく生産にする（経済産業省の解説の図）。
2. 鉱工業ではなく製造工業にする。
3. 基準のつなぎ方を変える（2014〜2022年を2015年基準にする）。
4. 月次の原指数で、3か月の前年同月比の平均を使う。
5. 2020年7〜9月期以降（山が決まっていない期間）を除く。

## 言えないこと（予想）
- 景気の山・谷は製造業だけで決まるものではない。製造業の在庫で全体の景気が分かるとは言えない。
- 後退期は2009年以降で3回（四半期で十数個）しかなく、割合や AUC の幅は大きい。
- 前年同期比は、前の年の動き（反動・震災・コロナ）の影響を受ける。2014年の消費税率の引き上げのあとに、図が逆に回った時期がある（経済産業省の解説）。
- 在庫は量の指数で、在庫を持つ理由（戦略的な積み増しか、売れ残りか）は分からない。
- 景気の予測や投資の判断はしない。
