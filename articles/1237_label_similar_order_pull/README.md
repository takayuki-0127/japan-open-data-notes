# 1237 似た件が続く並べ方で付けると、前の件の判定にどれだけ引っぱられるのか？（ラベル付け）

ラベルを付けるとき、同じ話題の件をまとめて並べると、続けて読むので作業が楽です。けれども、すぐ前に似た件を「急ぎ」と付けたあとは、迷う件も「急ぎ」と付けやすくなる、という引っぱりがあると、判定は件そのものだけでなく前の件の判定でも決まります。**ここでは、作成者が置いた架空の問い合わせ文（話題ごとの急ぎの度合いと、件ごとの本当の分類、前の件の判定に引っぱられる強さを作成者が置き、乱数で判定を作ったもの）で、① 話題ごとにまとめて付ける、② ばらばらに付ける、の2つの並べ方を比べ、前の件に引っぱられて判定が変わった件の数、まちがいの多さ、話題ごとの急ぎの割合がどう動くかを数えました。置き方を変えた27通りで確かめました。**

例の問い合わせ文と付け手は架空のもので、実在の会社の問い合わせやラベル付けのサービスを表すものではありません。付け手の処遇を扱う記事ではありません。

## 主な結果

### 並べ方ごとの値（各200回の平均、`results/orders.csv`）
| | ① まとめる・引っぱり0.4 | ② ばらばら・引っぱり0.4 | ① まとめる・引っぱりなし |
|---|---|---|---|
| すぐ前が同じ話題だった件 | 95.05% | 0.94% | 95.05% |
| 引っぱりで判定が変わった件 | **7.48%** | 0.07% | 0% |
| 　うち本当の境目の近く（度合い0.7〜1.3）の件 | **25.96%** | 0.24% | 0% |
| まちがって付いた件 | **8.77%** | 9.28% | 9.28% |
| 「急ぎ」と付いた割合（本当は19.55%） | 19.47% | 21.48% | 21.56% |
| 話題ごとの急ぎの割合のずれ（平均） | 4.54ポイント | 5.01ポイント | 4.99ポイント |

- **① では、全体の7.48%、本当の境目の近くの件では25.96%の判定が、前の件の判定に引っぱられて変わった**。② では、すぐ前が同じ話題になることがほとんどなく（0.94%）、変わった件は0.07%だった
- **それでも、基本の置き方では、まちがって付いた件は引っぱりで0.51ポイント減った（9.28%→8.77%）**。同じ話題の件は本当の度合いも近いので、前の件の判定が、読みの揺れを打ち消す手がかりとして働いた分が、引っぱりで外れた分より大きかった
- 引っぱりは多い方の判定に寄せた。「急ぎでない」が約8割なので、前の件が「急ぎでない」で −0.4 ずれる件が多く、「急ぎ」と付いた割合は21.56%から19.47%に下がった。本当の19.55%に近づいたのは、引っぱりのないときに読みの揺れで「急ぎ」が多めに付いていた分とたまたま打ち消し合ったため
- 1回分の例（`data/labels_one_run_block.csv`、① の並べ方）：まちがって付いた件は10.05%、引っぱりで判定が変わった件は169件

### 同じ度合いの件で、前の判定ごとの付き方（① まとめる、`results/by_true_urgency.csv`）
| 本当の急ぎの度合い | 0.8〜1.0 | 1.0〜1.2 |
|---|---|---|
| 前の件（同じ話題）を「急ぎ」と付けたあと | 73.23% | 84.79% |
| 前の件（同じ話題）を「急ぎでない」と付けたあと | 15.1% | 27.39% |
| （参考）引っぱりなし：前が「急ぎ」／「急ぎでない」 | 42.04%／42.03% | 58.33%／57.85% |

- 本当の度合いをそろえて比べると、前の判定で付き方が大きく変わった。引っぱりがなければ、前の判定で付き方は変わらない（作りどおり）
- 本当の度合いをそろえずに、すぐ前が同じ話題だった件だけで「前が急ぎのあとに急ぎと付いた割合」と「前が急ぎでないあと」を比べると、差は ① で66.32ポイント、引っぱりのない ① でも38.98ポイントあった。同じ話題の件は本当に似ているので、前と同じ判定が続くこと自体は引っぱりがなくても起きる。前と同じ判定が続いた割合も、① 88.42%・引っぱりなし78.7%（本当の分類で前と同じだった割合83.1%）だった

### 確かめ：27通り（① まとめる、各20回、`results/grid.csv`）
- 引っぱりで判定が変わった件は、27通りで3.72〜13.29%（② ばらばらでは0.15%以下）。主に λ で決まった
- **引っぱりでまちがいが増えたのは27通り中11通りで、変わり方は−4.42〜+7.48ポイント**。読みの揺れが小さい（s=0.3）9通りでは7通り、s=0.5 で3通り、s=0.8 では1通りで増えた。話題の中の散らばりが大きい（w=1.0）9通りでは6通り、w=0.6 で4通り、w=0.3 では1通りで増えた。読みが確かで、同じ話題の件どうしがあまり似ていないほど、引っぱりは手がかりより外れとして働いた
- 「急ぎ」と付いた割合は、27通りすべてで引っぱりにより下がった（−4.15〜−0.71ポイント）
- 話題ごとの急ぎの割合のずれは、27通り中12通りで引っぱりにより大きくなり、変わり方は−3.93〜+4.91ポイントだった
- ① と ② を別々の乱数で比べたまちがいの差（① − ②）は−3.98〜+7.49ポイントで、27通り中12通りで ① が多かった

## 注意（言えないこと）
- 架空のデータです。引っぱりの形（すぐ前の1件が同じ話題のときだけ、前の判定の向きに一定の幅でずれる）と強さは作成者が置いたもので、変わった件の数はこれでほぼ決まります。実際の付け手がどれだけ引っぱられるかは測っていません
- 引っぱりでまちがいが増えるか減るかは、読みの揺れと、同じ話題の件どうしがどれだけ似ているかの置き方で逆になりました。「似た件をまとめるとまちがいが増える」とも「減る」とも言えません
- 2件以上前の判定の影響、前の件と逆の向きに離れる形、話題の中でも件ごとに似ている度合いが違う形は入れていません
- 同じ度合いの件の付き方を前の判定で分けて比べられたのは、本当の度合いを作成者が知っているからです。実際のデータでは本当の度合いは分からず、前と同じ判定が続く割合だけでは、引っぱりと本当の似かたを見分けられません
- 実在の問い合わせやラベル付けのやり方を表すものではありません。どの並べ方を使うとよいかを勧める記事ではありません
