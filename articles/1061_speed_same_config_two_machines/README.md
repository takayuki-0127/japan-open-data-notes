# 1061 同じ設定のつもりの2台で、速さはどれだけ違うのか？（処理の速さ）

同じ設定で用意したつもりのサーバーでも、台ごとに少しずつ速さが違うことがあります。その違いを知らないまま、古い版を1台目で、新しい版を2台目で測って比べると、台の違いが版の違いにまざります。しかも、台の違いは何回測っても平均されて消えることはありません。**ここでは、作成者が乱数で作った架空のサーバー200台（同じ設定のつもり。台ごとに見えない速さの違いを置き、1割ほどの台には理由の分からない遅さ（+15%）を置いた）で、2台の本当の差と見かけの差、何回ずつ測れば見かけの差が台の差に近づくか、効き目のない変更を別の台で比べると何%の回で「差がある」と出るか、同じ台で測る・2台で版を入れかえるとどうなるかを数えました。置き方を変えた27通りでも確かめました。処理時間はすべて作成者が置いた分布からの乱数で、実機の計測はしていません。**

同じ企画の1053は1回ずつ測った処理時間で速い方を選ぶと何回に1回まちがえるか、1056は A のあとに B を測る順番を固定すると何が差にまざるかという問いです。この記事は、測る台そのものの違いがまざる場合に絞ります。台ごとの99%点を平均するずれは同じ企画の 1059 で扱っています。

## 主な結果

### 2台の本当の差（基本、2万組）
| | 値 |
|---|---|
| 2台の本当の差の中央値 | **5.38%** |
| 本当の差が5%以上の組 | 52.87% |
| 本当の差が10%以上の組 | 25.21% |
| 200台で最も遅い台と最も速い台の差 | 39.24% |

- 同じ設定のつもりの2台でも、半分以上（52.87%）の組で5%以上の差があった
- これは作成者が置いた台の係数から決まる値（置いた物差しの写し）。変わった台がない通りで確かめると、2台の差（対数）の中央値は3.805%で、式の値（0.674×√2×0.04＝3.815%）と合った（式どおり）

### 何回ずつ測ると、見かけの差は台の差に近づくか（基本、2万組、`results/runs_each.csv`）
| 1台あたりの回数 | 見かけの差の中央値 | 見かけの差が5%以上の組 | 見かけの差と本当の台の差とのずれ（中央値） |
|---|---|---|---|
| 1回 | 6.62% | 60.73% | 3.32% |
| 3回 | 5.8% | 55.79% | 1.95% |
| 10回 | 5.53% | 53.83% | 1.05% |
| 30回 | 5.39% | 52.95% | 0.62% |

- **何回測っても、2台の見かけの差は0には近づかず、置いた台の差（中央値5.38%）に近づいた**。回数を増やして減るのは、回ごとの揺れの分（ずれ3.32%→0.62%）だけ
- 27通りでは、30回ずつ測ったときのずれ（中央値）は0.36〜1.12%だった

### 効き目のない変更を比べると（基本、10回ずつ、2万組）
| 比べ方 | 「差がある」と出た割合（本来5%） | 見かけの差が5%以上 |
|---|---|---|
| ①別の台で古い版と新しい版 | **68.16%** | 53.77% |
| ②同じ台で両方 | 5.15% | 0.17% |
| ③2台で版を入れかえる | 2.1% | ― |

- **効き目のない変更でも、別の台で比べると68.16%の回で「差がある」と出た**。同じ台で測れば5.15%で、本来の5%どおりだった
- ③入れかえると2.1%で、5%より少なかった。台の違いが同じ版の10回の中の散らばりに入るので、検定が「差がない」寄りになるため。入れかえは台の差を打ち消すが、そのぶん小さな効き目は見つけにくくなる（推測）
- 本当に3%速くなる変更でも、①別の台で比べると35.16%の回で遅くなったように見え、22.47%の回では「遅くなった」と検定で出た。②同じ台なら遅く見えたのは2.81%

### 置き方を変えた27通り（各5,000組、`results/grid.csv`）
- 本当の差が5%以上の組は7.14〜75.2%で、置いた台の差の大きさでほぼ決まった
- ①別の台での「差がある」は15.7〜89.16%で、27通りすべてで②同じ台（4.22〜5.42%）より多かった。③入れかえは0.58〜3.94%
- 本当に3%速くなる変更が①で遅く見えた割合は16.64〜43.22%

## 注意（言えないこと）
- 架空のデータです。台ごとの違いの大きさ、変わった台の割合と遅さ、回ごとの揺れは作成者が置いたもので、結果はこれで決まります。とくに「2台の本当の差」は置いた台の係数の写しで、実際の2台がどれだけ違うかは測ってみないと分かりません。実在のサーバーやクラウドの速さを表すものではありません
- 台の違いは時間がたっても変わらないと置きました。台の速さが日によって変わるなら、同じ台でも日をまたぐ比べには台の差に近いものがまざります（推測）
- 測る順番の効果（温まり・順番の固定）は入れていません。同じ企画の1054・1056の問いです
- どの比べ方を使うべきかの助言ではなく、台の違いがまざったときの見え方を数えただけです
