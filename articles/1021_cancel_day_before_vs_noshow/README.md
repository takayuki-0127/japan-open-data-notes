# 1021 前日のキャンセルと当日の無断の不来店は、分けて数えるべきか？（予約とキャンセル）

予約の取り消しと、連絡のないまま来ない人（無断の不来店）を合わせて「キャンセル率」として1つの数にまとめることがあります。けれども、前日までの取り消しで空いた枠は別の人で埋め直せることがあり、当日の無断で空いた枠は埋め直せません。合わせた率が同じでも、当日の空き席は同じとは限りません。**ここでは、作成者が乱数で作った架空の体験教室3つ（定員10人。前日までの取り消しと当日の無断の起きやすさ、取り消しで空いた枠を埋め直す割合を作成者が置いたもの）で、合わせたキャンセル率がほぼ同じでも当日の空き席がどれだけ違うか、取り消しと無断の内訳が変わったときに合わせた率で気づけるかを数えました。埋め直す割合と教室の差の置き方を変えた12通りも確かめました。**

前日の夜の埋まり具合と当日の着席の差（取り消し・無断・人数の減りの内訳）は関連する記事 1017、キャンセル率の分母の決め方は 1018、予約を多めに取ったときの「断る人の%」は 1019、予約の早さごとの取り消しやすさの比べ方は 1020 で扱っています。埋め直す割合がキャンセル待ちの人数でどう決まるかは 1026 で扱っています（この記事では埋め直す割合を1つの値として置きました）。この記事は「前日までの取り消しと当日の無断を1つの率にまとめると何が見えなくなるか」に絞ります。

## 主な結果

### 3つの教室（式の値、`results/classes.csv`）
| 教室 | 前日までの取り消し | 当日の無断（予約に対して） | 合わせたキャンセル率 | 1回あたりの当日の空き席 | 空き席が2席以上の回（乱数） |
|---|---|---|---|---|---|
| A | 12% | 1.76% | 13.76% | **0.67席** | 14.85% |
| B | 4% | 9.6% | 13.6% | **1.144席** | 31.15% |
| C | 8% | 5.52% | 13.52% | 0.901席 | 23.45% |

（当日の無断は、取り消さなかった人の n を予約に対する割合に直した値）

- **合わせたキャンセル率は13.52〜13.76%とほぼ同じ（BはAの0.988倍）なのに、当日の空き席はBがAの1.71倍（1.706倍）だった**。値は置いた確率からの式どおり。教室Aの取り消しの多くは前日までに出るので6割が埋め直され、教室Bは当日の無断が多く埋め直せない
- 各教室2,000回の乱数の値は、式の値と、合わせた率で0.4ポイント以内、空き席で0.025席以内で合った

### 1か月（8回）ごとに比べると（教室AとB、250か月、`results/a1021_main.json`）
- 合わせたキャンセル率が教室Aのほうが高い月は54.4%、当日の空き席が教室Bのほうが多い月は76.8%だった
- **合わせた率ではAのほうが悪く見えるのに、空き席はBのほうが多い月が31.6%あった**

### 内訳が変わった年（教室C、7か月目から無断の半分が前日までの取り消しに、`results/a1021_main.json`・`results/shift_C_example_year.csv`）
| | 前日までの取り消し | 当日の無断（予約に対して） | 合わせたキャンセル率 | 1回あたりの空き席 |
|---|---|---|---|---|
| 1〜6か月目 | 8% | 5.52% | 13.52% | 0.901席 |
| 7〜12か月目 | 10.76% | 2.76% | 13.52% | 0.726席 |

- 内訳が変わっても、合わせたキャンセル率は式の上で13.52%のまま変わらなかった（無断の人が取り消しの人に移っただけなので、作りどおり）。当日の空き席は19.4%減った
- 1,000年の乱数では、後半−前半の合わせた率の差は10〜90%の範囲で−2.92〜+2.92ポイントと上下に振れ、上がるか同じだった年が52.1%あった。当日の無断の割合が下がった年は98.2%、空き席が減った年は82.9%（減り方の平均は1回あたり0.178席）
- 図2の1年の例では合わせた率が後半に下がって見えるが、これはこの年のたまたまの振れ

### 確かめ：埋め直す割合×教室の差の置き方（12通り、`results/sensitivity_grid.csv`）
| 埋め直す割合 | 差が小さい | 基本 | 差が大きい |
|---|---|---|---|
| 0% | 0.994倍 | 0.988倍 | 0.961倍 |
| 30% | 1.107倍 | 1.224倍 | 1.328倍 |
| 60% | 1.302倍 | 1.706倍 | 2.198倍 |
| 90% | 1.724倍 | 3.262倍 | 6.913倍 |

（当日の空き席の比、教室B÷教室A。式の値。合わせたキャンセル率は、差が小さい 13.6%と13.52%、基本 13.76%と13.6%、差が大きい 14.43%と13.87%）

- **埋め直しがない（0%）とき、空き席の比は合わせたキャンセル率の比と同じになった（式どおり）。このときは分けても空き席の見込みは変わらない**
- 埋め直しがあると、空き席の比は1.107〜6.913倍に開いた。埋め直す割合が大きいほど、前日までの取り消しと当日の無断の違いが大きく出た
- 乱数（各2万回）の比は、式の比と3.6%以内で合った

## 動かし方
```
pip install -r requirements.txt
cd src && python a1021_split.py
```
1秒ほどで終わります。`data/sessions_first200.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約2秒）
- 3つの教室で、乱数の合わせた率と空き席が式の値と合った（上の差）
- 埋め直しが0%の3通りで、空き席の比が合わせたキャンセル率の比と同じになることを確かめた（作りの確かめ）
- 「埋め直しがあれば、合わせた率がほぼ同じでも無断の多い教室のほうが空き席が多い」は、埋め直しが30%以上の9通りのすべてで同じだった

## データ
- `data/sessions_first200.csv`：3つの教室の最初の200回ずつ。class・session・booked（予約）・cancel_before（前日までの取り消し）・noshow（予約した人の当日の無断）・refilled（埋め直した人）・refill_noshow（埋め直した人の無断）・attended（来た人）・empty（空き席）

## 注意（言えないこと）
- 架空のデータです。取り消しと無断の起きやすさ、埋め直す割合は作成者が置いたもので、結果はこれで決まります。表の値は置いた確率からの式どおりで、乱数は式の確かめと、月ごとの振れを見るために使いました。実在の教室の予約を測ったものではありません
- 新しく数えたのは、合わせた率がほぼ同じでも空き席が埋め直しの割合で1.107〜6.913倍違うこと、1か月単位では合わせた率と空き席が逆の順になる月が31.6%あること、内訳が変わっても合わせた率では見分けられないことです
- 前日までの取り消しは、どれも同じ確率で埋め直せると置きました。実際には、前の週の取り消しは埋め直しやすく、前日の夜の取り消しは埋め直しにくいはずです（推測）。取り消しの時期は 1020 で扱っています
- 当日の取り消しの連絡（来ないと連絡があったが、枠は埋め直せない）は、無断と同じ扱いになると考えています（推測）。ここでは区別していません
- 内訳が変わった理由（連絡の仕方が変わったなど）は置いただけで、何がそれを起こすかは扱っていません。キャンセル料・料金の決め方の助言はしません
