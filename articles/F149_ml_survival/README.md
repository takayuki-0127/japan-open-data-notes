# F149 生存分析を機械学習でやると、何が良くなるのか？ ランダムサバイバルフォレスト・勾配ブースティングと Cox の比較

看板記事 F149。note：「生存分析を機械学習でやると、何が良くなるのか？…」（下書き）

## 問い
F28・F79・F106・F148 では、法人の閉鎖を Cox や区分化指数モデルで分析してきた。機械学習の生存モデルに替えると、
- 「どの法人が早く閉鎖するか」の見分け（C 指数・時点別 AUC）は良くなるか
- 予測した閉鎖率は実際と合うか（較正・Brier スコア）
- 良くならないなら、それは手法のせいか、データ（特徴量）のせいか

## データ
- F28 と同じ。国税庁「法人番号公表サイト」全件データ（2026年9月30日更新）から、2015年11月1日以降に法人番号が指定された株式会社・合同会社・その他の設立登記法人 152.9万法人。
- 設計どおり **10万社を無作為に抽出**（種の値 42）。閉鎖 5,463件、リスク年 50.6万年、観察期間の中央値 4.8年。
- 閉鎖＝「清算の結了等」(01)＋「登記官による閉鎖」(21)。合併(11)は打ち切り（原因別ハザード、F79・F106 と同じ）。時間は月単位に切り上げ。
- 特徴量（登記上の属性と、所在市区町村の集計値だけ）：種別(3)・地域区分（東京23区／政令市／その他）・地方(6)・都道府県(47)・指定年（連続）・指定月・指定日の日にち・曜日・市区町村の新規法人数（対数）・市区町村の合同会社とその他法人の割合・**市区町村の閉鎖率**（標本に入らなかった142.9万法人だけで計算し、小さい市区町村は全体の率へ縮めたもの。目的変数の漏れを避けるため）。
- 法人名・法人番号・住所は使わず、公開もしていない。個別の法人・市区町村・都道府県の順位は出さない。

## 手法
| モデル | 中身 | 比例ハザード |
|---|---|---|
| Cox | 主効果だけ（scikit-survival、ごく弱いリッジ） | 仮定する |
| Cox＋交互作用 | 種別×（地域区分・地方・指定年）、地域区分×指定年、指定年² | 仮定する |
| Cox＋スプライン | 数値の特徴量を3次スプラインに（足し算の曲がりだけ） | 仮定する |
| RSF | ランダムサバイバルフォレスト（200本、葉の最小50〜60、学習データの半分ずつ） | 仮定しない |
| GBM-Cox | xgboost（survival:cox）＋ Breslow の基準ハザード | 仮定する |
| GBM-Cox(深さ1) | 木の深さ1＝交互作用なし、曲がりだけ | 仮定する |
| GBM-離散時間 | 四半期ごとの「その期に閉鎖するか」を xgboost で二値分類。経過時間も特徴量 | 仮定しない |

- RSF・GBM の設定は、1回目の分割の学習データをさらに分けて選んだ（評価用の30%は使っていない。`results/tuning.csv`）。GBM の木の本数は学習データの20%で早期打ち切り。
- 評価：Harrell の C、Uno の C（8年まで）、時点別 AUC（1・3・5年）、統合 Brier スコア（IBS、0.25〜8年）と「特徴量を使わない KM」に比べた改善率、較正（予測5年閉鎖率の十分位ごとの予測と KM による実績、その平均絶対差 ICI、全体の予測−実績）。
- 基本はランダム分割 70:30 を5回。リスクの点数は「5年以内に閉鎖する確率」（比例ハザードでないモデルもあるため）。

## 主な結果
**1. 5つのモデルの差は、分割のぶれと同じくらいしかない**（5回の平均、`results/main_metrics.csv`）

| モデル | Uno の C | AUC 1年 | AUC 3年 | AUC 5年 | IBS の改善（KM 比） | ICI 5年 |
|---|---|---|---|---|---|---|
| Cox | 0.593 | 0.570 | 0.622 | 0.629 | 1.41% | 0.59pt |
| Cox＋交互作用 | 0.592 | 0.571 | 0.625 | 0.632 | 1.48% | 0.60pt |
| Cox＋スプライン | 0.590 | — | 0.622 | 0.621 | 1.39% | 0.57pt |
| RSF | 0.586 | 0.569 | 0.623 | 0.605 | 1.08% | 0.60pt |
| GBM-Cox | 0.592 | 0.568 | 0.639 | 0.636 | 1.55% | 0.58pt |
| GBM-Cox(深さ1) | 0.590 | — | 0.628 | 0.628 | 1.31% | 0.61pt |
| GBM-離散時間 | 0.591 | 0.580 | 0.634 | 0.630 | 1.64% | 0.52pt |

- Uno の C の Cox との差（5回の平均、最小〜最大）：GBM-Cox −0.0004（−0.005〜+0.004）、GBM-離散時間 −0.0015（−0.006〜+0.002）、RSF −0.007（−0.012〜−0.002）。**RSF は5回とも Cox を下回った。**
- 一貫して勝ったのは **3年の AUC だけ**：GBM-Cox が5回とも +0.015〜+0.019。GBM-離散時間も +0.009〜+0.019。比例ハザードを外した GBM-離散時間は 1年の AUC が平均 +0.011（ただし分割で −0.037〜+0.037）。
- そもそも見分ける力が弱い：どのモデルでも C は 0.59 前後。予測の上位10%の5年閉鎖率は 11〜13%、下位10%は 3%。IBS は「全員に同じ曲線を当てる KM」より 1〜1.6% しか下がらない。
- 較正はどれも良い：5年の ICI は 0.5〜0.6ポイント、全体の予測と実績の差は ±0.4ポイント以内。

**2. 足りないのは手法でなく特徴量**
- 半合成データ（実際の特徴量と打ち切りはそのまま、閉鎖の時刻だけを決めたハザードから作り直す、`results/synth_metrics.csv`）：
  - 本当のハザードが線形のとき：本当のリスクでの C 0.587、Cox 0.581、GBM-Cox 0.579、RSF 0.571。機械学習は少し損をする。
  - 曲がり・交互作用（合同会社×東京23区、月初・月末の指定、設立年の曲がり、大きい市区町村）を入れたとき：本当 0.657、Cox 0.636、Cox＋交互作用 0.638、RSF 0.641、GBM-Cox 0.646、GBM-離散時間 0.649。**機械学習は Cox との差 0.021 のうち 3分の2 を取り戻した。**
  - 実データで差が出ないのは、手法が壊れているからではなく、使える特徴量に曲がりや交互作用がほとんどないから（推測ではなく、この比較から言えるのは「あれば拾える」まで）。
- 分解：Cox＋スプライン（0.590）・GBM-Cox(深さ1)（0.590）も Cox と同じ。足し算の曲がりも交互作用も、精度にはほとんど効いていない。
- 特徴量を「種別・地域区分・地方・指定年」の4つに減らしても、Cox の C は 0.593（全部のとき分割1回目で 0.604）。特徴量を11グループに増やしても 0.01 しか上がらない。

**3. 同じ精度でも、頼っている特徴量は違う**（並べ替えによる重要度、`results/importance.csv`）
- Cox：種別（C が 0.026 下がる）、市区町村の規模（0.021）、地域区分（0.014）、都道府県（0.012）。
- GBM-Cox：市区町村の閉鎖率（0.034）、種別（0.029）、市区町村の規模（0.013）、指定年（0.011）。地域区分・都道府県はほぼ 0。
- 地域の情報は「地域区分・都道府県・市区町村の規模・閉鎖率」の間で重なっていて、どれを使うかはモデル次第。重要度を「閉鎖の原因」と読んではいけない例。
- GBM-Cox の部分依存では、指定年の効果が 2023年以降の設立で上がる形（対数ハザード −0.15→+0.19）。比例ハザードの Cox では直線（年 +0.018）。後の年の法人は観察が短いので、「設立が新しいほど閉鎖しやすい」のか「設立直後ほど閉鎖しやすい」のかは、このデータでは分けにくい。

## 頑健性
Uno の C の Cox との差（機械学習 − Cox）。`results/delta_vs_cox.csv`、図4。

| 設定 | RSF | GBM-Cox | GBM-離散時間 | Cox の C |
|---|---|---|---|---|
| ランダム分割（基本、5回） | −0.007 | −0.000 | −0.002 | 0.593 |
| 都道府県で分ける（GroupKFold 5分割） | −0.007 | −0.003 | −0.002 | 0.562 |
| 時間で分ける（2020年までの設立で学習、2021年以降で評価、5年まで） | −0.005 | −0.001 | −0.001 | 0.597 |
| 閉鎖＝清算の結了等だけ | −0.006 | +0.001 | +0.001 | 0.607 |
| 市区町村の閉鎖率を除く | −0.003 | +0.002 | +0.001 | 0.603 |
| 特徴量4つだけ | −0.019 | −0.003 | −0.002 | 0.593 |
| 標本3万社（3回） | −0.002 | −0.002 | −0.002 | 0.592 |
| 標本1万社（3回） | +0.002 | +0.003 | +0.016 | 0.554 |

- どの設定でも平均の差は ±0.02 の中。RSF は8つのうち7つで Cox を下回る。
- 都道府県で分けると、どのモデルも C が 0.03 下がる（知らない県の法人には、県の特徴量が効かない）。較正も悪くなり、5年の ICI は 1ポイント前後。
- 1万社では GBM-離散時間が +0.016 と最も良いが、分割ごとのぶれ（−0.015〜+0.036）も大きく、標本が小さいときの偶然と区別できない。
- 時間で分けたとき、3年の AUC は Cox 0.614 に対し GBM-Cox 0.606・RSF 0.603。ランダム分割で見えた GBM の 3年 AUC の上積みは、未来の法人には持ち越されなかった。

## 言えないこと
- 法人の閉鎖を説明する本当の要因（業種・資本金・従業員・売上・代表者など）は法人番号データにない。この比較は「登記上の属性だけでの予測」の話で、機械学習一般の優劣ではない。
- 半合成データの「曲がり・交互作用」は、こちらで決めたもの。現実の閉鎖にそういう形があるかどうかは分からない。
- 重要度・部分依存は予測の仕組みの説明で、原因の推定ではない。
- 「閉鎖」は登記の閉鎖で、事業をやめた時期とはずれる。休眠や登記官による閉鎖の時期の偏りは F148 を参照。
