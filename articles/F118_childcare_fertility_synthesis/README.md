# F118 「保育所と出生率」に、これまでの記事はどう答えたか？（推定のまとめ直し）

看板記事 F118。「保育所に通う子どもが多い（増えた）地域ほど、出生率は高い（上がった）か」という同じ問いに、これまでの記事（022・F16・F20・F51・F81・F100）はそれぞれ違う手法・データで答えてきました。その推定値を **同じ単位** にそろえて並べ、答えが違ったのは何のせいかを整理しました。新しい分析は、022 の都道府県パネルを同じ単位で推定し直した部分だけです。

## 問い

- 5本の記事の答え（向き・大きさ）を同じ単位で並べると、どれくらいそろうか
- そろわないなら、答えを分けたのは「手法」か「データの単位」か「何と何を比べたか」か
- 実際に全国で増えた分の保育に当てはめると、出生率はどれくらい動く計算になるか

## 共通の単位

**在所児（保育所等に通う子ども）が0〜5歳100人あたり +10人のとき、合計特殊出生率がいくつ違うか**。F51・F100 はもともとこの単位です。022 は「15歳未満100人あたりの定員 +10人」だったので、同じデータ（SSDSE-B）で在所児と0〜5歳人口に置き換えて推定し直しました。

- 都道府県の0〜5歳人口 ＝ 15歳未満人口 ×（0〜5歳 ÷ 15歳未満）。この割合は国勢調査の年（2010・2015・2020年）の市区町村データ（F16 で取得）を県で合計し、年の間を直線で補いました（全国で0.37〜0.38）
- 期間は022 と同じ2012〜2022年（2023年は保育所等の値の定義が変わった可能性があるため除く）

## 主な結果

### 1. 推定値を同じ単位で並べると（23の推定）

| 何と何を比べたか | 推定の数 | 範囲 | 区間の半分の幅（中央値） | 向き |
|---|---|---|---|---|
| 県どうしの差（水準） | 2 | +0.029〜+0.068 | ±0.034 | すべてプラス |
| 県の中の年ごとの動き（固定効果） | 2 | −0.059〜−0.029 | ±0.015 | すべてマイナス |
| 県の変化どうし（長い差 2012→22） | 1 | −0.057 | ±0.028 | マイナス |
| 町どうしの差（水準、県ダミーあり） | 7（＋条件なし1） | −0.016〜−0.003（条件なしは +0.015） | ±0.004 | マイナス4・0をまたぐ3（条件なしはプラス） |
| 町の変化どうし | 10 | −0.004〜+0.001 | ±0.004 | マイナス4・0をまたぐ6 |

- **向きが変わったのは「比べる相手」が変わったとき**。県どうしで比べるとプラス（在所児が多い県ほど出生率が高い）。県の違いを除いて同じ県の中の動きを見るとマイナス。町の変化どうしでは0の近くに集まった
- 同じ比べ方の中では、手法を変えても答えはおおむねそろった（F100 の60通りのばらつきのうち、手法だけで説明できるのは13%、比べ方だけで31%、比べ方と県の扱いの組み合わせで46%）
- 022 のもとの単位（15歳未満100人あたりの定員 +10人）での推定は、プール +0.048、県の固定効果 −0.115、二方向 −0.030 で、022 の記事の値と一致した（再現できた）

### 2. 022 を同じ単位で推定し直すと

| モデル | 在所児＋10人（0〜5歳100人あたり） | 95%区間 |
|---|---|---|
| 県どうし（2022年の断面） | +0.068 | +0.026〜+0.109 |
| 県×年をプール | +0.029 | +0.003〜+0.055 |
| ＋県の固定効果 | −0.059 | −0.069〜−0.049 |
| ＋県と年の固定効果（二方向） | −0.029 | −0.050〜−0.008 |
| 長い差 2012→22 | −0.057 | −0.086〜−0.029 |
| 長い差 2012→19 ／ 2015→20 | −0.033 ／ −0.023 | どちらも0をまたぐ |

- 022 は「二方向固定効果では0と区別できない」と書いたが、処置を **在所児・0〜5歳あたり** にすると区間は0の下に出た。違いの多くは処置の単位による（定員・0〜5歳あたりにすると −0.012 で0をまたぐ）。在所児は「預けたい人の数」にも左右されるので、需要が増えた県（都市部など）を拾っている可能性がある（推測）
- 都道府県の推定は区間が市区町村の4〜8倍広い（±0.015〜0.034 と ±0.004）。47県では細かい差は見分けられない

### 3. 実際に増えた分に当てはめると

全国の在所児は2012年の0〜5歳100人あたり 34.9人から2022年 48.6人へ **+13.7人**。47県平均の出生率は 1.46 → 1.36（**−0.10**）。

| 比べ方 | +13.7人を当てはめた出生率の差 | 95%区間の端から端まで |
|---|---|---|
| 県どうし | +0.040〜+0.092 | +0.004〜+0.149 |
| 県の中の年ごとの動き | −0.081〜−0.039 | −0.094〜−0.011 |
| 町どうし（県ダミーあり） | −0.021〜−0.005 | −0.051〜+0.015 |
| 町の変化どうし | −0.006〜+0.001 | −0.013〜+0.013 |

- いちばん細かく比べられる「町の変化どうし」では、10年分の保育の拡大を当てはめても出生率の差は ±0.013 の中に収まる。実際の低下（−0.10）の大部分は、保育の増減とは別の全国の流れで起きた
- 「保育所の拡大で出生率がはっきり（例えば0.02以上）上がった」なら町の変化の比較で見えたはずだが、見えなかった。ただしこれは「5年後まで」「市区町村の集計値で」の話（言えないこと参照）

### 4. 女性の就業（問い2）への答え

F16・F51・F100 の21の推定は、点推定がすべてプラス。大きさは比べ方で約3倍違う（町どうしの水準 +0.14〜+0.20ポイント、町の変化どうし +0.04〜+0.07ポイント）。変化どうしの推定は多くが0をまたぐ。F51 の媒介分析では、この「就業を通る」経路が出生率に与える分は +0.0003（−0.0001〜+0.0007）で、出生率への答えを動かすほどの大きさはない。

## 頑健性（022 の二方向固定効果）

| 確かめたこと | 推定 | 95%区間 |
|---|---|---|
| 基本 | −0.029 | −0.050〜−0.008 |
| 0〜5歳の割合を全国一律（2015年）に | −0.027 | −0.048〜−0.006 |
| 0〜5歳を直近6年の出生数で近似（2017〜22年） | −0.030 | −0.051〜−0.008 |
| 同じ期間（2017〜22年）で基本の換算 | −0.021 | −0.043〜+0.001 |
| 処置を定員に（0〜5歳100人あたり） | −0.012 | −0.034〜+0.009 |
| 2012〜19年だけ（コロナの年を除く） | −0.020 | −0.050〜+0.010 |
| 有効求人倍率をそろえる | −0.025 | −0.046〜−0.004 |
| 1年前の在所児で | −0.023 | −0.043〜−0.003 |
| 出生数で重み付け | −0.024 | −0.042〜−0.006 |
| 県を1つずつ抜く（47回） | −0.034〜−0.025 | — |

- 0〜5歳の換算の仕方（3通り）では答えはほぼ変わらない
- 処置を定員にする、コロナ前だけにする、期間を2017〜22年に絞ると、区間は0をまたぐ。向きはどれもマイナスだが、「県の中で在所児が増えた年ほど出生率が下がった」の強さは設定に左右される
- どの1県を抜いても −0.034〜−0.025 で、特定の県に引っぱられた結果ではない

## なぜ答えが分かれたか（整理）

| 何が違ったか | 影響 | 例 |
|---|---|---|
| 何と何を比べたか（県どうし／県の中／町どうし／町の変化） | **向きが変わる** | 県どうし +0.068 → 県の固定効果 −0.059 |
| 県の違いを除くか | 町どうしの比較で向きが変わる | F100 水準：条件を足すと +0.015 → +0.001、県ダミーで −0.009 |
| 処置の単位（定員か在所児か、15歳未満か0〜5歳か） | 区間が0をまたぐかどうかが変わる | 022 の二方向：定員・15歳未満 −0.030（0をまたぐ）、在所児・0〜5歳 −0.029（0の下） |
| 集計の単位（県か市区町村か） | 区間の幅が4〜8倍違う | ±0.015〜0.034 と ±0.004 |
| 手法（回帰・DML・マッチング・空間回帰） | 同じ比べ方の中では小さい | F100 の変化の比較で −0.004〜+0.001 |

県どうしのプラスは、在所児の割合が高い北陸・山陰などと、割合が低い首都圏・京阪神などの地域の違い（働き方・住まい・世帯の形）を拾っていると考えられます（推測）。県の中のマイナスは、出生率が全国で下がった時期に保育の受け皿が広がったことを拾っており、2012→22年に在所児の増え方が大きかった県ほど出生率の下がり方も大きかった（47県の相関 −0.4）ことと合います。保育が増えたから下がったのか、下がる流れの中で預けたい世帯が増えたのかは、このデータでは区別できません。

## 言えないこと

- **どの比べ方が正しいかは決められない**。どれも観察データで、見えない交絡（若い共働き世帯の転入、待機児童対策の時期のずれなど）は残る。どの推定も「保育所を増やすと出生率がこれだけ変わる」という因果の値ではない
- 市区町村の推定は「2010→15年の保育の変化」と「その後の5年の出生率」の関係で、もっと長い時間をかけて効く効果は見ていない
- 都道府県の0〜5歳人口は、国勢調査の年の割合を補間した推計値。在所児には認定こども園の一部が入らない年があり、その分は「減った」ように見えることがある
- 推定を並べたのは同じデータを使い回した記事どうし（F16・F51・F100 は同じ市区町村データ）なので、23の推定は独立した23の証拠ではない。メタ分析のように平均することはしていない
- 個人の選択（誰が預けて、誰が子どもを持ったか）は分からない
