# 01 取得

新しく取得したデータはありません。これまでの記事のデータと結果を使い回しています。

| ファイル | もと | 内容 |
|---|---|---|
| `data/raw/SSDSE-B-2026.csv` | 022（`articles/022_nursery_birthrate_fe/data/raw/`） | 統計センター SSDSE-県別推移。都道府県×年（2012〜2023年）の出生率・保育所等定員・在所児・15歳未満人口・出生数など |
| `data/raw/pref_age0_5_census.csv` | F16（`data/panel_long.csv` を都道府県で合計） | 国勢調査の年（2005・2010・2015・2020年）の0〜5歳人口（A1405）と15歳未満人口（A1301）。0〜5歳の割合を補間するのに使う |
| `data/prior/F16_results.json` | F16 | 保育所と女性の労働力率（DML） |
| `data/prior/F20_coefficients.csv` | F20 | 出生率の空間回帰（保育所「数」の係数） |
| `data/prior/F51_results.json`・`F51_robustness.csv` | F51 | 保育所 → 女性の就業 → 出生率の媒介分析 |
| `data/prior/F81_results.json` | F81 | 通勤と出生率（保育所数は条件の1つ。参考） |
| `data/prior/F100_results.json`・`F100_specifications.csv`・`F100_variance_share.json` | F100 | 同じ問いを5つの手法で推定した60通り |

`pref_age0_5_census.csv` は次で作りました（F16 のフォルダがある場合）。

```python
d = pd.read_csv("F16_childcare_dml/data/panel_long.csv", dtype={"code": str})
d = d[d.year.isin([2005, 2010, 2015, 2020])]; d["pref"] = d.code.str[:2]
d.groupby(["pref", "year"])[["A1405", "A1301"]].sum().reset_index().to_csv("pref_age0_5_census.csv", index=False)
```
