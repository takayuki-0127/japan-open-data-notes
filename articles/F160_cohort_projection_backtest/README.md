# F160 人口の将来推計を、自分で作るとどこまで合うか？ 自作のコーホート要因法を、社人研の3回分の推計と同じ市区町村で答え合わせする

看板記事 F160。note：「人口の将来推計を、自分で作るとどこまで合うか？…」（下書き）

## 問い

F45 では、社人研（国立社会保障・人口問題研究所）の推計を再現し、2023年推計の5年先の外れを2025年国勢調査で確かめた。自作の素朴な推計は、市区町村では2020年基準の1回だけ、それより前は都道府県でしか比べられなかった。

F160 では、社人研2013年推計の市区町村編から2010年の市区町村の人口を取り直して、次の3点を確かめた。

- 基準年（2015・2020年）と先の年（5・10年）を変えて、自作と社人研の当たり方を同じ市区町村で比べる
- 移動率と子ども女性比の仮定をどう置くと、どこまで社人研に近づけるか
- 外れはどこから来るか

## データ

- 社人研「日本の地域別将来推計人口」
  - 2013年推計の市区町村編（2010年基準。結果と生残率）。今回新しく取得した。福島県は市区町村の推計がない。
  - 2018年推計（2015年基準）、2023年推計（2020年基準）。F45 で整形したものを使い回す。
- 総務省「令和7年国勢調査 人口等基本集計（不詳補完値）」：2025年の市区町村・男女・5歳階級別人口（F45 と同じ）
- **実績として使った人口：**
  - 2010・2015・2020年は、各推計の基準人口（国勢調査の年齢不詳を按分したもの）
  - 2025年は、国勢調査の不詳補完値
- **市区町村の単位：** 2025年の境界にそろえた1,681市区町村。合わせて2020年の人口の 1.24億人。
  - 政令市は市全体、東京23区は区ごと。
  - 市制施行などのコード変更は付け替えた。
  - 除いたのは、福島県と、2014年に岩舟町を編入した栃木市。
- **年齢区分：** 19区分（0～4歳…85～89歳、90歳以上）

## 手法

コーホート要因法（5年ごと、男女・5歳階級）を自分で組んだ。

- **5～9歳以上：** 「生残率＋純移動率」を掛けて進める。
- **0～4歳：** 子ども女性比（0～4歳 ÷ 女性15～49歳）から作る。

生残率は、基準年の時点で公表されていた社人研の推計のものを借りた（2015年基準には2018年推計、2020・2025年基準には2023年推計）。移動と出生の仮定は、自分で置いた。

| 仮定 | 中身 |
|---|---|
| 移動ゼロ | 純移動率＝0 |
| 直近5年の移動率 | 基準年の前の5年の実績から、純移動率を残差で出し、そのまま続ける |
| 直近10年の平均 | 前の2期の純移動率の平均（2020・2025年基準のみ） |
| 移動率を県へ縮める | 市区町村の率と同じ県の率を、n/(n+k) で混ぜる（n は期首の年齢・男女の人口）。k は2015年基準→2020年で選び（k=50）、2020年基準→2025年で確かめた |
| 移動率を半分 | 直近5年の率×0.5 |
| 子ども女性比 | 基準年の値のまま／県の値へ縮める／全国の直近5年の変化率で延ばす |
| 自作と社人研の平均 | 縮めた移動率の自作と社人研の推計を半々 |

**答え合わせの組み合わせ：**

| 基準年 | 推計する年 | 比べる社人研の推計 |
|---|---|---|
| 2015年 | 2020年（5年先） | 2018年推計 |
| 2015年 | 2025年（10年先） | 2018年推計 |
| 2020年 | 2025年（5年先） | 2023年推計 |

**外れの出どころ：** 2020年基準で、移動率・子ども女性比を2020～25年の実際の値に差し替えて、外れがどれだけ消えるかを見た。

**2050年の見通し：** 2025年の国勢調査を基準に2050年まで自作で延ばし、社人研2023年推計（2020年基準）と比べた。

## 結果

市区町村の人口の平均絶対誤差（%）。

| 方法 | 2015→2020 | 2015→2025 | 2020→2025 |
|---|---|---|---|
| そのまま（人口が変わらない） | 6.28 | 14.62 | 7.90 |
| 移動ゼロ | 2.83 | 6.28 | 3.25 |
| 直近5年の移動率 | 2.03 | 4.22 | 2.36 |
| 直近10年の平均 | — | — | 2.17 |
| 移動率を県へ縮める（k=50） | 1.84 | 3.82 | 2.38 |
| 縮める＋子ども女性比も県へ | 1.81 | 3.72 | 2.34 |
| 社人研 | 1.73 | 3.27 | 1.81 |
| 自作と社人研の平均 | 1.72 | 3.38 | 1.99 |

参考として、社人研2013年推計（2010年基準）の外れは、5年先1.81%、10年先3.32%、15年先5.40%。

**自作と社人研の差**
- 自作で最もよいものでも、社人研より外れが0.1～0.6ポイント大きかった。
- 単位を引き直したブートストラップで、縮めた移動率の自作と社人研の差（95%区間）を出した。

  | 基準年→推計する年 | 差（ポイント） | 95%区間 |
  |---|---|---|
  | 2015→2020 | +0.12 | +0.04～+0.19 |
  | 2015→2025 | +0.55 | +0.40～+0.71 |
  | 2020→2025 | +0.57 | +0.49～+0.65 |

- 自作と社人研の平均は、2015→2020では社人研と並んだ（−0.01、−0.05～+0.03）。ほかの2つでは社人研のほうがよかった。

**移動率を県へ縮める効果**
- 選んだ期間（2015→2020）では、外れが2.03%から1.84%に減った。2015→2025でも4.22%から3.82%に減った。
- 2020→2025では効かなかった（2.36%→2.38%。k=25 でも2.33%）。
- 県の値だけにすると、どの期間でも悪くなった（2020→2025は3.37%）。

**外れる場所**
- 自作と社人研の外れの相関は0.78～0.82で、外れの向きは80～86%の市区町村で同じだった。
- 自作のほうが当たった市区町村の割合は、2015→2020で51%、2015→2025で45%、2020→2025で35%。

**2020→2025の外れの向き**
- 自作は、どの規模でも人口を多めに見ていた（平均+1.4～+1.6%）。社人研は+0.75%。
- 1,681市区町村の合計は、自作+1.3%、社人研+0.2%。
- 0～14歳は、自作+6.1%、社人研+2.8%。

**外れの出どころ（2020→2025）**
- 自作の外れは2.38%。移動率を実際の値に差し替えると0.47%になり、外れの8割が消えた。
- 子ども女性比だけを差し替えると、外れは2.12%。ただし0～4歳の外れは23.6%から4.3%に減った。

**2050年の見通し（2025年基準）**
- 1,681市区町村の合計は、移動率を縮めた自作で1.028億人、社人研2023年推計で1.033億人と、ほぼ同じだった。
- 2050年に2025年の6割未満になる市区町村の割合は、自作38.6%、社人研28.6%。移動率を半分にした自作では29.4%。
- 合計がほぼ同じでも、移動の仮定しだいで市区町村の間の差の大きさが変わる。

## 頑健性

次の条件で、縮めた移動率の自作と社人研の差を確かめた。

- 生残率を1つ前の推計のものに替える
- 子ども女性比の分母を女性20～44歳にする
- 移動率を男女まとめて出す
- k を2倍・半分にする
- 人口1千人未満を除く

社人研との差はどの条件でも次の範囲に収まり、自作が社人研を上回る条件はなかった。

| 基準年→推計する年 | 社人研との差（ポイント） |
|---|---|
| 2015→2020 | +0.12～+0.14 |
| 2015→2025 | +0.46～+0.66 |
| 2020→2025 | +0.52～+0.65 |

生残率を替えても、外れは0.08ポイント以内しか動かなかった。

## 言えないこと

- 生残率は社人研のものを借りている。死亡まで含めた、すべてが自作の推計ではない（生残率を替えても結果はほとんど動かなかった）。
- 実績の2010・2015・2020年は社人研の基準人口（年齢不詳を按分したもの）、2025年は国勢調査の不詳補完値で、按分の仕方が完全には同じではない。
- 社人研の推計がなぜ当たったか（移動率の仮定の置き方）は、公表された仮定値から推し量れるだけで、この分析では確かめていない。
- 2020～25年の外れは、コロナ禍で外国人の転入が減ったことや、出生の減少が早まったことの影響を受けている可能性がある（推測）。別の5年でも同じ差になるとは限らない。
- 2050年の比較は、基準年が違う（自作は2025年、社人研は2020年）。どちらが当たるかを示すものではない。
- 市区町村の人口の増減は、評価ではない。この記事では特定の市区町村を取り上げていない。
