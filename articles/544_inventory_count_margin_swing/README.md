# 544 棚卸の差異を月末にまとめて計上すると、月の粗利はどれだけ振れるのか（実務の型・月次の数字の読み方）

在庫は、万引き・破損・数え違いなどで帳簿より少しずつ減ります（ここでは「目減り」と呼びます）。帳簿では見えないこの減りは、実地棚卸をしたときにまとめて表に出ます。**ここでは、架空の小売店（2023〜2025年の36か月、目減りは3年で原価の1.09%）で、棚卸を年1回・四半期・毎月にしたとき、および年1回の棚卸に前の年の率で毎月の見込みを入れたときに、月の粗利率がどれだけ振れ、棚卸の月にどれだけ落ち込むかを数えました。** 売上や目減りの起き方は作成者が置いたもので、数字はその仮定で決まります。会計処理の良し悪しを扱うものではなく、数え方で数字がどう動くかを測ったものです。

## 主な結果
- **その月に起きた目減りを入れた粗利率（参考）**：28.1〜29.5%、標準偏差 0.36ポイント。毎月棚卸（S3）はこれと同じになる
- **年1回（S1）**：1〜11月は 30.0%（目減りが入らない）で、12月は 24.0%・22.4%・23.6%。12月の落ち込みは平均 6.6ポイント、月の粗利率の標準偏差は 1.85ポイント（参考の約5.1倍）
- **四半期（S2）**：棚卸の月は平均 27.8%、それ以外は 30.0%。標準偏差は 1.05ポイント
- **年1回＋見込み（S4）**：標準偏差 0.31ポイントで参考とほぼ同じだが、前の年と目減りの率が違った年は12月に差が出る（2024年12月 27.7%、2025年12月 30.2%）。参考との差は最大 1.64ポイント
- **目減りの大きさを変えると（200店×3年の平均）**：年1回の12月の落ち込みは、目減りが原価の0.5%で 3.0ポイント、1%で 6.1ポイント、3%で 18.2ポイント。四半期は 0.5〜3.3ポイント、見込みを入れた場合は 0.0〜0.1ポイント

## 動かし方
```
pip install -r requirements.txt
cd src && python a544_count_swing.py
```
20秒ほどかかります。

## 確かめたこと
- 空のフォルダで流し直し、results・figures がバイト単位で一致した
- 毎月棚卸（S3）の粗利率が、その月に起きた目減りを入れた粗利率と一致すること
- 3年間の目減りの合計は、どの方法でも同じ額が原価に入ること（入る月だけが違う）

## データ
- データファイルは置いていない。売上と目減りはコードの中で乱数から作る（seed 544）。月ごとの結果は `results/monthly_store.csv`・`results/monthly_margin.csv`
- 仮定：月の売上は約1,000万円（12月は1.4倍などの季節の動き、日ごとのばらつきあり）、帳簿上の原価率 70%。目減りは毎日の小さな減りと、年に3回ほどのまれな大きな減りの合計で、平均は原価の約1%（置いた値は1.2%、この店の3年間では1.09%）
- S4 の見込みの率を作るため、2022年の1年分も作り、集計からは除いた

## 注意（言えないこと）
- 架空のデータ。実際の店の数字ではない
- 会計・税務の処理についての助言ではない。どの方法を使うべきか、認められるかは扱っていない
- 目減りを原価に入れるとした単純な形で数えた。棚卸資産の評価の方法（記事430）や、評価損などは入れていない
- 振れの大きさは、置いた目減りの大きさ・起き方・売上の季節の動きで決まる
