# F287 同じ数字を、経営向けと現場向けでどう書き分けるか？（精選・D. 求人票の業務 Q38）

架空の会社「みどり堂（架空）」（文具・書籍・雑貨・カフェの4部門、12店）の月次の数字から、
**共通版（C）・経営向け（E）・現場向け（S、店ごとに1枚）** の3つのレポートを自動で作り、
読み手の問いに答えるまでの手間・1枚に収めたときに残る答え・要らない数字・丸めの食い違いを数えました。
会社も数字も乱数で作った合成データです。実在の会社・顧客のデータは使っていません。

- 計画（事前登録）：[PLAN.md](PLAN.md)（コミット 30bf2b6。データの合成・レポート・測定のコミットはすべてこの後）
- F248（月次レポートの型）・F250（悪い月の1枚の報告）は1つの読み手向けの型。F287 は、同じ数字を2つの読み手向けに作り分けたときに何が得られ、何が壊れるかを数えた

## 結論
- **読む量（店の表の後ろに要約がある共通版の場合）**：経営の8問に答えるまでに読む文字数の中央値は、C 2,510字・E 460字（**5.5倍**）。店長の8問では C 2,711字・S 216字（**12.6倍**）。見出しから飛ぶ読み方でも 5.5倍・11.7倍（H1 支持）。**ただしこの差はほぼ作りから決まる**。経営の問いの答え（幅の外の店・部門、決めること、見通し、先月の結果）を共通版の冒頭に置いた「要約を先に置いた共通版（C2）」では、経営の読む量は429字で E の **0.93倍**（見出しから飛ぶ読み方で1.07倍）。店長の読む量は C2 でも 2,688字（12.4倍）で変わらない
- **1枚（1,500字）で切る**：C で答えが残るのは経営の問いの63%、店長の問いの70%。E・S は100%。店長の問いは C で5割を下回らなかったので **H2 は外れ**。表の後ろにある店ほど答えが消える（S01〜S06 は75%、S08 は64%、S09〜S12 は63%）。店が24店なら C は39%。C2 は経営100%、店長58%（要約の分だけ店の表が後ろへずれる）
- **要らない数字**：C を経営が読むとき、表示した数字の88%は8問の答えに使わない（店長なら94%）。E は0%（H4 支持。E は問いに合わせて作ったので、ほぼ作りから決まる）。「要らない数字」は、答えになる行に入っていない数字のこと（答えの行の中の数字はすべて要る数字として数えた）
- **丸めの食い違い**：部門（億円・小数1桁）・店（百万円・整数）・構成比（%・整数）を別々に丸めると、FY2025 の12か月中 **8か月** で「部門や店の合計」と「全社」が表示上合わない（構成比は100%にならない）。計画どおり店の合計と全社だけで数えると **4か月（33%）** で、基準の3割をわずかに超える。最大剰余法では、部分の合計がかならず丸めた合計と一致する作りなので0（H3 支持）。乱数の種20通りでは7〜12か月（中央値10）。最大剰余法の0は作りから決まり、種20通りは確かめとして流しただけ
- **問い直し（結果を見て追加）**：E の「偶然の幅の外」の欄に、入れておいた本当の動きは出たか（乱数の種20通り）。
  - ある店の客数 −8%：動きの後の月の89%（種ごとに67〜100%）で出た。最初に出たのは動きの月（遅れは最大1か月）
  - 雑貨の粗利率 −2pt：100%（全部の種で100%）
  - 1店のカフェ部門 +15%：**店として出たのは20%（0〜64%）で、動きのない店が幅の外に出る割合16%（10〜20%）と見分けにくい**。**部門として出たのは43%（18〜73%）で、動きのない部門が幅の外に出る割合14%（0〜29%）の約3倍**。ただし E からは、どの店のカフェかは分からない

## データ（合成）
- 12店（規模 L・M・S を4店ずつ）×4部門×36か月（2023年4月〜2026年3月）。客数・客単価・粗利率・人時を乱数で作り、季節の形・店の伸び方の違いを入れた（種287）
- 本当の動き（答え）：2025年4月から全社の単価 +3%、2025年7月から S07 の客数 −8%、2025年5月から S03 のカフェ部門の客数 +15%、2025年10月から雑貨の粗利率 −2pt（全店）
- 計画：FY2025 の各月 ＝ 前年同月 ×1.02（作成者が置いた値）
- `data/midorido_monthly.csv`（1,728行）

## 手法
- **偶然の幅**：本当の動きを入れない合成データを40通り作り、FY2025 の「店・部門の前年比 − 全社の前年比」と「部門の粗利率の前年差」の絶対値の90%点を幅とした（店の売上 ±5.5pt、店の客数 ±4.8pt、部門の売上 ±2.7pt、部門の粗利率 ±0.43pt）
- **レポート**：`src/zz_f287_common.py` の `report_C`・`report_E`・`report_S`。ブロック（見出し・本文・含む事実）の列として作る。2025年10月の見本は `reports/`。要約を先に置いた共通版（`report_C(..., summary_first=True)`、レビュー後に追加）の見本も置いた
- **問い**：経営8問・店長8問（PLAN.md のとおり）。各問いの答えを「事実」として各ブロックに付け、上から読んだときに全部見つかるまでの文字数を数える
- **1枚で切る**：先頭から N 字で切り、最後まで入っているブロックの事実だけを残す
- **要らない数字**：答えの事実を含まないブロック（行）に表示した数字の数 ÷ 全部の数字の数（店の番号は数字に数えない）。答えの行の中の数字は、問いに直接使わないものも要る数字として数えた
- **丸め**：部門の売上（億円・小数1桁）の合計と全社、店の売上（百万円・整数）の合計と全社、部門の構成比（%・整数）の合計と100% を、別々に丸めた場合と最大剰余法の場合で比べる

## 頑健性
1. **切る長さ**：1,000字で C は経営50%・店長42%、2,500字で 93%・88%。E・S はどれも100%
2. **見出しから飛ぶ読み方**：比は 5.5倍・11.7倍で、上から読む場合とほぼ同じ
3. **乱数の種20通り（丸め）**：合わない月は7〜12か月、最大剰余法では全部0（作りから決まる）
4. **店の数**：6店で経営 3.7倍・店長 7.7倍・1,500字の C 86%、24店で 9.4倍・21.8倍・39%（`results/E_robust_nstores.csv`）
5. **丸めの単位**：細かく（億円0.01・千円・%0.1）しても11か月、粗く（億円1・億円0.1・%5）しても9か月で合わない（この確かめでは最大剰余法は計算していない）
6. **要約を先に置いた共通版**（レビュー後に追加）：経営の読む量は E の0.93倍で、H1 の差は共通版の並べ方でほぼ消える

## 計画からのずれ
- **偶然の幅の基準**：最初は前年比そのもので判定したが、全社の値上げ（+3%）で全店が幅の外になったので、全社の前年比との差で判定するように直した。部門の粗利率も最初は全社の粗利率の前年差との差で判定したが、雑貨の低下が全社に混ざって他の部門まで幅の外に出たので、粗利率の前年差そのもので判定するように直した（見本の月のレポートを見てから直した）。最初の基準（前年比そのもの）のままでも、経営の読む量の比は 3.47倍（C 2,790字・E 803字）で、H1 の判定は変わらない
- **レポートの作り**：計画では E を「結論3行→全社の KPI と偶然の幅の判定→要因→決めること→店・部門の例外だけ」としたが、実際は「結論2行→例外→決めること→見通し→先月決めたことの結果」にした。C には計画になかった「店×部門」「見通し」「対応すること」「先月の結果」の節を足し、経営の問いの答えが店の表の後ろに来る並びにした。H1 の大きさは、主にこの並びで決まっている
- **営業利益の水準**：最初の設定では営業利益が売上の0.4%と小さすぎたので、時給と店の固定費を変えた（読む量・丸めの結果にはほぼ影響しない）
- **H3 の測り方**：計画では「経営向け（億円）と現場向け（百万円）を別々に丸める」としたが、単位が違うと分解能の差で必ず合わないので、同じ単位の中の「部分の合計と全体」で数えた。計画に近い「店の合計と全社」だけなら4/12か月（33%）
- **問い直し**：計画の候補を変えた問い。「省いた店の動きが後で全社に出たか」ではなく、「入れておいた動きが経営向けの例外の欄に出たか」を、結果を見てから決めた測り方で見た
- **PLAN.md の日付**：最初は「2026-11-12 作成」と書いたが、コミット 30bf2b6 の時刻は 2026-11-11 23:35（日本時間）なので、レビュー後に日付だけ直した
- **レポートの文の直し（レビュー後）**：前年比がプラスの店でも「いちばん落ちた部門」と書いていたので「いちばん伸びが小さい部門」に直した。決めることの店を3店までに絞っていて S09 が落ちていたので、絞らないようにした。直したあとに全部を流し直し、数字を更新した

## 言えないこと
- 人が読んだ時間ではなく、文字数と答えの位置で測った見積もり。表を読む速さ、文より表のほうが速い、といった違いは入っていない
- 3つのレポートの作り方は作成者が決めたもの。E・S は問いに合わせて作ったので、問いに答えやすいのは当たり前（循環）。共通版も、要約を先に置けば経営の読む量は E と同じくらいになる。結果は「店の表の後ろに要約を置いた共通版と比べると」の目安
- 「先月の結果」の答えは、場所を示すだけの定型の文。読む量は、最後に見つかるこの答えの位置で決まっている
- 店長が「S07」のように自店の名前で検索して読む読み方は試していない
- 合成データで、本当の会社の数字ではない。幅の外の判定も、この合成の揺れの大きさで決まる
- 「みどり堂（架空）」は、F275 の「みどりマート（架空）」とは別の架空の会社

## 外に出すなら
Qiita か Zenn に「レポートを読み手ごとに作り分けるときの丸め（最大剰余法）と、問いから逆算する構成」の手順として書ける。社内勉強会（BI・レポート業務）の題材にもなる。
