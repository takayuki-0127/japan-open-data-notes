# F287 同じ数字を、経営向けと現場向けでどう書き分けるか？（精選・D. 求人票の業務 Q38）

架空の会社「みどり堂（架空）」（文具・書籍・雑貨・カフェの4部門、12店）の月次の数字から、
**共通版（C）・経営向け（E）・現場向け（S、店ごとに1枚）** の3つのレポートを自動で作り、
読み手の問いに答えるまでの手間・1枚に収めたときに残る答え・要らない数字・丸めの食い違いを数えました。
会社も数字も乱数で作った合成データです。実在の会社・顧客のデータは使っていません。

- 計画（事前登録）：[PLAN.md](PLAN.md)（コミット 30bf2b6。データの合成・レポート・測定のコミットはすべてこの後）
- F248（月次レポートの型）・F250（悪い月の1枚の報告）は1つの読み手向けの型。F287 は、同じ数字を2つの読み手向けに作り分けたときに何が得られ、何が壊れるかを数えた

## 結論
- **読む量**：経営の8問に答えるまでに読む文字数の中央値は、C 2,456字・E 422字（**5.8倍**）。店長の8問では C 2,666字・S 215字（**12.4倍**）。見出しから飛ぶ読み方でも 5.9倍・11.5倍（H1 支持）
- **1枚（1,500字）で切る**：C で答えが残るのは経営の問いの63%、店長の問いの70%。E・S は100%。店長の問いは C で5割を下回らなかったので **H2 は外れ**。表の後ろにある店ほど答えが消える（S09〜S12 は63%、S01〜S07 は75%）。店が24店なら C は39%
- **要らない数字**：C を経営が読むとき、表示した数字の88%は8問の答えに使わない（店長なら94%）。E は0%（H4 支持。E は問いに合わせて作ったので、ほぼ作りから決まる）
- **丸めの食い違い**：部門（億円・小数1桁）・店（百万円・整数）・構成比（%・整数）を別々に丸めると、FY2025 の12か月中 **8か月** で「部門や店の合計」と「全社」が表示上合わない。最大剰余法で丸めると0（H3 支持）。乱数の種20通りでは7〜12か月（中央値10）
- **問い直し（結果を見て追加）**：E の「偶然の幅の外」の欄に、入れておいた本当の動きは出たか。ある店の客数 −8% は動きの後の月の89%、雑貨の粗利率 −2pt は100%で出た（どちらも動きの月から）。一方、1店のカフェ部門 +15% は、店としては20%、カフェ部門としては43%しか出ず、動きのない店が幅の外に出る割合（16%）と見分けにくい。E は「どの店のどの部門か」を出さないので、こうした小さな部分の動きは落ちる

## 計画と結果

| 仮説 | 基準 | 結果 | 判定 |
|---|---|---|---|
| H1 | 経営の読む量 C ÷ E ≥ 3 | 5.82（見出しから飛ぶ読み方で 5.90） | 支持 |
| H2 | 1,500字で C の店長の問い < 50%、S = 100% | C 70.0%、S 100% | 外れ |
| H3 | 別々に丸めて合わない月 ≥ 3割、最大剰余法で0 | 8/12、0 | 支持 |
| H4 | 経営にとって要らない数字 C ≥ 70%、E < 30% | C 88.3%、E 0.0% | 支持（E は作りから決まる） |

## データ（合成）
- 12店（規模 L・M・S を4店ずつ）×4部門×36か月（2023年4月〜2026年3月）。客数・客単価・粗利率・人時を乱数で作り、季節の形・店の伸び方の違いを入れた（種287）
- 本当の動き（答え）：2025年4月から全社の単価 +3%、2025年7月から S07 の客数 −8%、2025年5月から S03 のカフェ部門の客数 +15%、2025年10月から雑貨の粗利率 −2pt（全店）
- 計画：FY2025 の各月 ＝ 前年同月 ×1.02（作成者が置いた値）
- `data/midorido_monthly.csv`（1,728行）

## 手法
- **偶然の幅**：本当の動きを入れない合成データを40通り作り、FY2025 の「店・部門の前年比 − 全社の前年比」と「部門の粗利率の前年差」の絶対値の90%点を幅とした（店の売上 ±5.5pt、店の客数 ±4.8pt、部門の売上 ±2.7pt、部門の粗利率 ±0.43pt）
- **レポート**：`src/zz_f287_common.py` の `report_C`・`report_E`・`report_S`。ブロック（見出し・本文・含む事実）の列として作る。2025年10月の見本は `reports/`
- **問い**：経営8問・店長8問（PLAN.md のとおり）。各問いの答えを「事実」として各ブロックに付け、上から読んだときに全部見つかるまでの文字数を数える
- **1枚で切る**：先頭から N 字で切り、最後まで入っているブロックの事実だけを残す
- **要らない数字**：答えの事実を含まないブロックに表示した数字の数 ÷ 全部の数字の数（店の番号は数字に数えない）
- **丸め**：部門の売上（億円・小数1桁）の合計と全社、店の売上（百万円・整数）の合計と全社、部門の構成比（%・整数）の合計と100% を、別々に丸めた場合と最大剰余法の場合で比べる

## 頑健性
1. **切る長さ**：1,000字で C は経営50%・店長42%、2,500字で 95%・88%。E・S はどれも100%
2. **見出しから飛ぶ読み方**：比は 5.9倍・11.5倍で、上から読む場合とほぼ同じ
3. **乱数の種20通り（丸め）**：合わない月は7〜12か月、最大剰余法では全部0
4. **店の数**：6店で経営 3.7倍・店長 7.7倍・1,500字の C 86%、24店で 10.1倍・21.5倍・39%（`results/E_robust_nstores.csv`）
5. **丸めの単位**：細かく（億円0.01・千円・%0.1）しても11か月、粗く（億円1・億円0.1・%5）しても9か月で合わない

## 計画からのずれ
- **偶然の幅の基準**：最初は前年比そのもので判定したが、全社の値上げ（+3%）で全店が幅の外になったので、全社の前年比との差で判定するように直した。部門の粗利率も最初は全社の粗利率の前年差との差で判定したが、雑貨の低下が全社に混ざって他の部門まで幅の外に出たので、粗利率の前年差そのもので判定するように直した（見本の月のレポートを見てから直した）
- **営業利益の水準**：最初の設定では営業利益が売上の0.4%と小さすぎたので、時給と店の固定費を変えた（読む量・丸めの結果にはほぼ影響しない）
- **H3 の測り方**：計画では「経営向け（億円）と現場向け（百万円）を別々に丸める」としたが、単位が違うと分解能の差で必ず合わないので、同じ単位の中の「部分の合計と全体」で数えた
- **問い直し**：計画の候補どおり、経営向けで省いた動きが出たかを見た（結果を見てから測り方を決めた）

## 言えないこと
- 人が読んだ時間ではなく、文字数と答えの位置で測った見積もり。表を読む速さ、文より表のほうが速い、といった違いは入っていない
- 3つのレポートの作り方は作成者が決めたもの。E・S は問いに合わせて作ったので、問いに答えやすいのは当たり前（循環）。結果は「どのくらい違うか」の目安
- 共通版の順番（全社→部門→店）を変えれば、店長の問いの答えが残る割合は変わる
- 合成データで、本当の会社の数字ではない。幅の外の判定も、この合成の揺れの大きさで決まる
