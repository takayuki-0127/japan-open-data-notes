# 1202 件名を2つ試して勝った方は、次の配信でも同じだけ勝つのか？（メール配信）

お知らせのメールで、読者を半分に分けて件名Aと件名Bを送り、開封率の高かった方を「勝ち」とすることがあります。けれども、1回の開封率の差には、件名の本当の効き目のほかに、その回たまたま誰が開いたか、開きやすい読者がどちらの半分に多く入ったか、という偶然が入ります。勝った方は偶然が上に振れた分も持っているので、同じ2つを次の配信でもう一度比べると、勝ち幅は小さくなります。**ここでは、作成者が乱数で作った架空の店の読者（基本は4,000人、片側2,000人）と、件名の本当の効き目を置き、同じ2つの件名を2回続けて比べて、1回目の勝ち幅が2回目にどれだけ残るか、何%がまた勝つかを数えました。読者を配信ごとに分け直す場合と、同じ半分のまま比べる場合（会員番号の奇数・偶数のように固定）も比べ、置き方を変えた27通りで確かめました。**

例の店・読者・件名は作成者が置いた架空のもので、実在のメール配信サービス・メールソフト・会社の数字ではありません。件名の書き方の良し悪しや、値引き・価格の訴求の効き目は扱っていません。

関連する記事：845「同じ内容を2回投稿したときの差は、偶然でどこまで出るのか？」は、同じ強さの動画を2回投稿したときに再生数にどれだけの差が偶然で出るかを数えています。826「前半の打率トップは、後半もトップなのか？」は、偶然が上に振れた分が後半に引き継がれない形を、架空の打者で数えています。同じ企画の 1197「開封率で選ぶかクリック率で選ぶかで、良い件名は入れかわるのか？」は、開封率とクリック率のどちらで件名を選ぶかで、選ぶ件名が入れかわることを扱っています。同じ企画の 1207「一部の読者に試しに送った結果は、残りの読者に送ったときの数字にどれだけ当たるのか？」は、1通の配信を一部の読者と残りに分けたとき、試しの数字が残りにどれだけ当たるかを扱っています（件名は比べません）。この記事は、メールの読者を半分に分ける比べ方で、1回目に勝った件名の勝ち幅が次にどれだけ残るかと、読者の分け方による違いに絞ります。

## 主な結果

### 配信ごとに読者を分け直す場合（1万組、`results/a1202_main.json` の base.resh）
| | 値 |
|---|---|
| 1回目の勝ち幅（平均） | 1.1977ポイント |
| 同じ件名の2回目の勝ち幅（平均） | **0.208ポイント** |
| 勝った件名の本当の差（平均） | 0.2ポイント |
| 2回目の勝ち幅 ÷ 1回目の勝ち幅 | **17.36%**（式の見込み 16.84%） |
| 2回目もまた勝った割合 | 54.09% |
| 1回目に勝った件名が本当に良かった割合 | 62.35% |

- **1回目の勝ち幅1.1977ポイントのうち、2回目に残ったのは0.208ポイント（17.36%）で、置いた本当の差（0.2ポイント）とほぼ同じだった**。残る割合は、本当の差の散らばりと1回目の差の散らばりから決まる式の見込み（16.84%）どおりだった
- 2回目もまた勝ったのは54.09%で、半々に近かった。1回目に勝った件名が本当に良かったのは62.35%だった
- 1回目の差の標準偏差は1.5086ポイント、本当の差の標準偏差は0.6269ポイントで、1回目の差の大部分は偶然の振れだった

### 1回目の勝ち幅の帯ごと（分け直す、`results/by_margin_band.csv`）
| 1回目の勝ち幅 | 組の割合 | 1回目 | 2回目 | 本当の差 | また勝った |
|---|---|---|---|---|---|
| 0〜0.5 | 25.53% | 0.2319 | 0.0933 | 0.0386 | 49.16% |
| 0.5〜1 | 23.43% | 0.7185 | 0.1052 | 0.1261 | 51.05% |
| 1〜1.5 | 18.5% | 1.2177 | 0.1882 | 0.1926 | 54.0% |
| 1.5〜2 | 13.39% | 1.7271 | 0.2328 | 0.29 | 55.41% |
| 2〜3 | 14.26% | 2.3838 | 0.4192 | 0.3917 | 61.22% |
| 3以上 | 4.89% | 3.5512 | 0.6892 | 0.6197 | 70.35% |

- 1回目に2ポイント以上で勝った組（19.15%）でも、2回目の勝ち幅は平均0.4882ポイント（1回目は2.6819ポイント）で、また勝ったのは63.55%だった

### 同じ半分のまま比べる場合（1万組、base.fixed）と、効き目0の件名どうし（6,000組、null_effect0）
| | 分け直す | 同じ半分のまま |
|---|---|---|
| 2回目の勝ち幅 ÷ 1回目（効き目を置いた基本） | 17.36% | **44.77%** |
| また勝った割合（基本） | 54.09% | 63.39% |
| 1回目に勝った件名が本当に良かった割合（基本） | 62.35% | 63.02% |
| また勝った割合（効き目0） | 48.72% | **59.88%** |
| 2ポイント以上で勝った組がまた勝った割合（効き目0） | 49.89% | 74.51% |

- **同じ半分のまま比べると、2回目にも1回目の勝ち幅の44.77%が残り、63.39%がまた勝った**。けれども、1回目に勝った件名が本当に良かった割合は63.02%で、分け直す場合（62.35%）と変わらなかった。また勝つ分が増えたのは、件名の効き目ではなく、開きやすい読者が多く入った半分が、次もその半分のままだったため
- 件名の効き目を0と置いても、同じ半分のままなら59.88%がまた勝ち、2ポイント以上で勝った組では74.51%がまた勝った。1回目と2回目の差の相関は0.3405（分け直すと0.0055）だった

### 確かめ：置き方を変えた27通り（各400組、`results/grid.csv`）と効き目0の9通り（各1,000組、`results/null_grid.csv`）
- 分け直す場合の「2回目の勝ち幅 ÷ 1回目」は−4.5〜88.88%で、27通りすべてで1回目より小さかった。式の見込みとの差は最大0.1001（10.01ポイント、400組ずつの振れを含む）
- 残る割合は、件名の効き目の散らばりが大きく、片側の人数が多いほど大きかった（効き目の標準偏差0.12・片側8,000人で88.88%）。効き目の標準偏差0.02・片側2,000人以下の6通りでは−4.5〜10.75%で、2回目にはほとんど残らなかった
- また勝った割合は、分け直すと46〜83.25%、同じ半分のままだと50〜86.75%。同じ半分のままのほうが高かったのは27通り中22通り
- 効き目0でまた勝った割合は、分け直すと45.9〜53.4%、同じ半分のままだと51.1〜69.1%。同じ半分のままの1回目と2回目の差の相関は0.068〜0.5823で、読者ごとの開きやすさの差が大きいほど高かった

## 注意（言えないこと）
- 架空のデータです。読者ごとの開く確率の散らばり、件名の効き目の大きさと置き方、人数は作成者が置いたもので、結果はこれで決まります。2回目に残る勝ち幅は、27通りで−4.5〜88.88%に分かれました
- 件名の効き目は、2回の配信で変わらないと置きました。見慣れて効き目が薄れる、季節で効き方が変わる、といった動きは入れていません
- 2回の配信で読者は同じ人たちと置き、登録・停止による入れかわりは入れていません
- どの件名が良いか、何人に試せばよいかは言えません
