# 1281 5つの部品を重ねた棚の高さで、許容差をそのまま足した「最悪の幅」は、実際の高さのばらつきよりどれだけ広いのか？（寸法の積み上げ）

部品を重ねて組む品物の高さは、部品の寸法の合計です。部品ごとに「±0.8mm」のような許容差（図面の寸法から外れてよい幅）があるとき、許容差をそのまま足すと、組み立て品の高さがとりうるいちばん広い幅（最悪の幅）が出ます。けれども、5つの部品が全部そろって同じ側の端に寄ることはめったになく、実際に組んだ品物の高さは、それより狭い幅に収まります。もう1つの見込み方として、許容差を二乗して足し、平方根をとる言い方（二乗で足す）もあります。**ここでは、作成者が置いた架空の組み立て式の棚（台輪・箱A・箱B・箱C・天板の5つを重ねる。部品ごとの許容差と、1個ずつの寸法の散らばりを作成者が置き、乱数で20万台を組んだもの）で、最悪の幅・二乗で足した幅・実際に組んだ棚の高さの幅を比べました。部品の数・許容差の組み合わせ・1個ずつの寸法の散らばり方を変えた36通りでも確かめました。**

例の棚・部品・寸法は架空のもので、実在の家具や部品の規格を表すものではありません。品質の判断や購入の助言はしていません。

関連する記事：917「寸法の平均が規格の中でも、外れる品物は何%あるのか？」は、部品1つの寸法で、平均と標準偏差から規格を外れる割合を数えています。1048「途中の数字を1桁に丸めて計算すると、答えは何倍まで外れるのか？」は、掛け算の丸めで、最悪の外れ（式）とふつうの外れの差を数えています。849「作業ごとの見積もりを足すと、全体の見積もりは何%足りなくなるのか？」は、作業の日数を足したときに合計が足りなくなる向きのずれを扱っています。1282「部品の平均が許容差の中で少しずつ同じ向きにずれていると、二乗で足して見込んだ外れの割合は、実際の何分の1に出るのか？」は、部品の平均がそろって同じ向きにずれたときに、二乗で足した見込みが外れることを扱っています。1283「組み立て品の許容差を先に決めて部品に割り振るとき、二乗の足し算で割り振ると最悪の足し算より部品を何倍ゆるくでき、そのとき外れる組み立て品は何%出るのか？」は、先に決めた組み立て品の許容差を部品に割り振る向きを扱っています。1284「同じ日に作った部品どうしで寸法のずれがそろうとき、関係なしと見て二乗で足した幅は、実際の幅よりどれだけ狭く出るのか？」は、同じ日に作った部品どうしのずれがそろうと、二乗で足した幅が実際より狭く出ることを扱っています。この記事は、部品の許容差から組み立て品の幅を見込む2つの足し方が、実際の幅とどれだけ違うかに絞ります。

## 主な結果

### 基本の置き方での幅（棚20万台、`results/base_widths.csv`）
| 幅の出し方 | 幅 |
|---|---|
| ①許容差をそのまま足した最悪の幅 | **6.4mm**（±3.2mm） |
| ②許容差を二乗で足した幅 | 3.0067mm（±1.5033mm） |
| ③実際の高さの真ん中99.73%の幅 | **3.006mm** |
| ④1,000台の最高と最低の差（200組の平均） | 3.2352mm（200組でいちばん大きい組は4.31mm） |

- **最悪の幅は、実際の高さの真ん中99.73%の幅の2.129倍だった**。1,000台ずつ組んだときの最高と最低の差と比べても1.978倍だった
- 20万台のうち、最悪の幅の端（±3.2mm）を超えた棚は0台（0.0%）で、図面の寸法からいちばん離れた棚でも2.4312mmだった。最悪の幅の半分（±1.6mm）を超えた棚は0.132%だった
- 二乗で足した幅は、実際の99.73%の幅とほぼ同じだった（3.0067mm と 3.006mm、1.0倍）。これは、1個ずつの寸法を「平均のずれなし・標準偏差が許容差の3分の1の正規の乱数」で作ったからで、**作りどおり**の一致。二乗で足した幅の外に出た棚は0.269%だった
- 最悪の幅÷二乗で足した幅（2.129倍）は、置いた許容差だけで決まる**式どおり**の値（許容差がそろった5つなら√5＝2.236倍）
- 基本の置き方では、部品1個ずつのうち許容差を外れたものが0.258%あり、それも除かずに組んだ

### 確かめ：36通り（各20万台、`results/grid.csv`）
| 1個ずつの寸法の作り方 | 最悪の幅÷実際の99.73%の幅 | 二乗で足した幅÷実際の99.73%の幅 |
|---|---|---|
| 正規・標準偏差t/3 | 1.183〜4.461倍 | 0.994〜1.006倍 |
| 正規・標準偏差t/4 | 1.56〜5.922倍 | 1.324〜1.342倍 |
| 許容差の中で一様 | **1.04〜2.609倍** | **0.583〜0.884倍** |

- 36通りすべてで、最悪の幅は実際の99.73%の幅より広かった（1.04〜5.922倍）。1,000台の最高と最低の差と比べると1.03〜5.488倍だった
- 部品が多いほど差は開いた（部品2個で1.04〜1.881倍、5個で1.266〜2.998倍、10個で1.652〜4.244倍、20個で2.321〜5.922倍）。許容差が1つだけ大きい組み合わせでは、その部品の幅が大半を占め、差は小さめだった
- 1個ずつの寸法が許容差いっぱいに一様に散らばると、二乗で足した幅は実際の幅より狭く出た（0.583〜0.884倍）。二乗で足した幅が実際に合うのは、許容差＝標準偏差の3倍と置いたときだけで、合うかどうかは部品の作られ方で決まる
- 1個ずつが標準偏差t/4でよくそろうと、二乗で足した幅も実際より1.324〜1.342倍広かった

## 注意（言えないこと）
- 架空の棚と、作成者が置いた許容差・寸法の作りです。最悪の幅が実際の何倍になるかは、部品の数・許容差の組み合わせ・1個ずつの寸法の散らばり方でほぼ決まります。基本の2.129倍は、置いた許容差からの式どおりの値です
- 部品の平均は図面の寸法どおり（ずれなし）、部品どうしの寸法は関係なし（別々の乱数）と置きました。平均が同じ向きにずれる場合は 1282 で扱っています。同じ日に作った部品どうしでずれがそろう場合は、実際の幅が広がり（1284 で扱っています）、最悪の幅との差は小さくなります
- 「実際の幅」を真ん中99.73%で測ったのは、許容差＝標準偏差の3倍の置き方に合わせたためです。99%や99.9%で測ると倍率は変わります
- 最悪の幅は「どんな部品が来ても超えない幅」で、実際の幅は「たくさん組んだときの幅」です。どちらを使うべきかは、外れたときに困る度合いや組む台数で変わり、この記事では決めていません
