# 901 「前年比の前年比」は、何を表しているのか？（割合とパーセント）

「今月の売上は前年比105%、前年比の前年比は95%」のように、前年比をさらに前年と比べた数字が報告に出ることがあります。前年比の前年比は「今年の前年比÷去年の前年比」で、伸びが速まったか鈍ったかを表すつもりの数字です。売上が減ったことを表すわけではありません。また、式を書き直すと「今月×2年前の同じ月÷（前年同月）²」になり、前年同月の売上が2回効きます。**ここでは、作成者が乱数で作った架空の店5,000店の6年分の月の売上（年ごとの本当の伸びを作成者が置いたもの）で、前年比の前年比が本当の伸びの変化をどれだけ当てるか、前年同月のたまたまの振れにどれだけ引きずられるかを数え、月の振れと伸びの変わり方の置き方で確かめました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A901 | 前年比の前年比は、本当の伸びの変化をどれだけ当てるか。何に引きずられるか | 架空の店5,000店×6年（72か月）。店ごとに年ごとの本当の伸びを、平均5%・標準偏差3%で毎年引き直す（年の中では月ごとに同じ率でなめらかに伸びる）。季節の形（±15%ほどの山と谷、店ごとに時期がずれる）と、月ごとのたまたまの振れ（対数の標準偏差6%）を掛けた。前年比＝今月÷前年同月、前年比の前年比＝今月の前年比÷前年同月の前年比。本当の前年比の前年比は、振れを除いた本当の水準で同じように出したもの。3年目以降の48か月で数えた。比べとして、12か月の移動合計（年計）で出した前年比の前年比も数えた（年計は3年目の12月からの37か月）。例として、本当の伸び5%で一定・月の振れ1%の1店に、3年目の7月だけ改装で15%少ない月を置いた。確かめとして、月の振れ（2・6・12%）×伸びの年ごとの変わり方（1・3・6%）の9通りを各3,000店。seed 901 | `src/a901_yoy_of_yoy.py` |

## 主な結果

### 例の1店：1か月の落ち込みは、前年比の前年比に3回出る（data/example_shop.csv）
| 月 | 売上 | 前年比 | 前年比の前年比 | 2年前比 |
|---|---|---|---|---|
| 3年目7月（改装で15%少ない） | 964 | 87.96% | 83.14% | 93.05% |
| 4年目7月 | 1,177 | **122.1%** | **138.81%** | 107.39% |
| 5年目7月 | 1,261 | 107.14% | **87.75%** | 130.81% |
| 6年目7月 | 1,318 | 104.52% | 97.56% | 111.98% |

- 本当の伸びは毎年5%で一定なのに、前年比の前年比は「4年目に大きく加速、5年目に大きく鈍化」と読める動きをした。5年目7月の87.75%は、2年前の改装の月の影響である
- 前年比×前年同月の前年比＝2年前比、の関係はすべての月で成り立った（ずれは最大2.22e-16）

### 5,000店の3年目以降の48か月
| 数えたこと | 値 |
|---|---|
| 前年比の前年比が100%を下回った月 | 50.02% |
| そのうち、売上は前年同月より増えていた月 | **45.28%** |
| 前年比の前年比の向き（速まった／鈍った）が、本当の向きと合った割合 | **55.99%** |
| 同じことを年計で出した場合（3年目の12月から） | 59.85%（月ごとは同じ期間で56.04%） |
| 参考：前年比の向き（増えた／減った）が本当と合った割合 | 71.11% |
| 前年比の前年比と、前年同月のたまたまの振れとの相関 | **−0.8021** |

- 100%を下回った月の半分近くは、売上そのものは前年より増えていた。「前年比の前年比が100%を下回った」は、売上が減ったという意味ではない
- 伸びが速まったか鈍ったかを当てた割合は55.99%で、当てずっぽう（50%）に近かった。年計で出すと59.85%にやや上がった
- 前年比の前年比（対数）の散らばり0.1501のうち、本当の変化の散らばりは0.0288、たまたまの振れの部分は0.1474だった。振れの部分は、式どおり月の振れの√6倍（0.147）になる。前年同月の振れは−2倍で効くので、振れだけなら相関は−2÷√6＝−0.8165になる。数えた−0.8021はこれに近い
- 前年比の前年比が95%を下回った月は36.56%あった。そのうち、本当の前年比の前年比も95%を下回っていたのは5.6%で、87.22%は前年同月がたまたま多かった月だった

### 確かめ：月の振れ × 伸びの年ごとの変わり方（9通り、各3,000店）
| 月の振れ | 伸びの変わり方 | 向きが合った（月ごと） | 向きが合った（年計） | 100%を下回った月のうち売上は増えていた | 95%を下回った月のうち本当も95%を下回っていた |
|---|---|---|---|---|---|
| 2% | 1% | 55.97% | 59.53% | 90.42% | 0% |
| 2% | 3% | 66.39% | 67.79% | 81.43% | 12.81% |
| 2% | 6% | 76.45% | 70.36% | 67.19% | 50.05% |
| 6% | 1% | 52.03% | 53.48% | 45.76% | 0% |
| 6% | 3% | 55.97% | 59.5% | 45.19% | 5.38% |
| 6% | 6% | 61.65% | 64.94% | 43.54% | 27.47% |
| 12% | 1% | 50.88% | 51.77% | 29.88% | 0% |
| 12% | 3% | 53.05% | 54.9% | 30.34% | 4.32% |
| 12% | 6% | 56.11% | 59.91% | 30.25% | 22.05% |

- 向きが合った割合は、9通りで50.88〜76.45%（年計では51.77〜70.36%）だった。月の振れが伸びの変わり方より大きいほど、当てずっぽうに近づいた。向きの当たりと相関は、月の振れと伸びの変わり方の比でほぼ決まる（振れ2%・変わり方1%と、振れ6%・変わり方3%がほぼ同じ値）
- 前年同月のたまたまの振れとの相関は、9通りで−0.8153〜−0.5261だった
- 伸びの変わり方が大きく、月の振れが小さいときだけ、月ごとの前年比の前年比が年計より当たった（振れ2%・変わり方6%）。年計は振れを均す代わりに、変化に遅れて反応するためと考えている（仕組みからの説明。遅れを分けて数えてはいない）

## 動かし方
```
pip install -r requirements.txt
cd src && python a901_yoy_of_yoy.py
```
2秒ほどで終わります。`data/example_shop.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の6ファイルがバイト単位で一致した（cmp、約2秒）
- 前年比の前年比のたまたまの振れの部分は、式（月の振れの√6倍、前年同月が−2倍で効く）どおりの値になった。この記事の「前年同月に引きずられる」は式の写しで、数えて新しく分かったのは、本当の伸びの変化をどれだけ当てるかの割合と、その置き方による幅
- 前年比×前年同月の前年比＝2年前比が、例の店のすべての月で成り立つことを確かめた

## データ
- `data/example_shop.csv`：例の1店の72か月。year・month・sales（売上、万円）・yoy（前年比）・yoy_of_yoy（前年比の前年比）・two_year（2年前比）

## 注意（言えないこと）
- 架空のデータです。本当の伸びの平均と変わり方、月のたまたまの振れ、季節の形は作成者が置いたもので、結果はこれで決まります。向きが当たる割合は置き方で50.88〜76.45%まで動きました
- 月のたまたまの振れは、月ごとにばらばらに起きると置きました。振れが何か月か続く（改装が2か月続くなど）と、効き方は変わります
- 本当の伸びは年ごとに1つと置き、年の途中で変わることは入れていません
- 実在の店や会社の売上を表すものではありません。どの指標で報告すべきかの決まりを示すものでもありません
- 関連する記事 824 は、前年比の棒と実数の線を並べたグラフの読み違いを扱っています。この記事は、前年比をさらに前年と比べた数字が何を表すかだけを扱いました
- 同じ企画の 903 は、前年の個数が小さいと前年比そのものが大きく振れることを、品目の販売個数で数えています。この記事は、前年比をさらに前年と比べたときに前年同月の振れが2回効くことに絞りました
