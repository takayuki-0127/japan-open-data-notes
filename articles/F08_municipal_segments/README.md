# F08 1,740市区町村を62の指標で分けると何タイプか？（看板記事）

人口・世帯・産業・就業・財政・教育・医療・生活の62指標で全国の市区町村を分けると、何タイプに分かれ、それぞれどんな町か。分け方はどれくらい安定しているか。顧客セグメンテーションと同じ手順（標準化 → 次元削減 → クラスタリング → 解釈 → 安定性の検証）で確かめました。

## 問い

- 市区町村は、いくつのタイプに分けるのが妥当か（組の数の根拠）
- それぞれのタイプはどんな町か
- 手法・指標・標本を変えても同じ分け方になるか

## データ

| データ | 内容 |
|---|---|
| 統計センター「SSDSE-A（市区町村）」2026年版 | 1,741市区町村 × 125項目（2019〜2024年の各種統計。政令市は市全体で1行） |
| 国土数値情報「行政区域」2021年をもとにした簡略版 TopoJSON（smartnews-smri/japan-topography、CC BY 4.0） | 地図用の境界 |

- 2020年国勢調査で人口が0の福島県双葉町は除き、1,740市区町村で分析しました
- 125項目を、人口あたり・世帯あたり・割合などの62指標に直しました（`src/02_整形.py`）。偏りの大きい指標は対数をとり、上下1%で外れ値を丸めてから標準化しています
- 欠損は「小学校の教員1人あたり児童数」の2.4%だけで、中央値で埋めました

## 手法

| 段階 | 手法 |
|---|---|
| 次元削減 | 主成分分析（累積80%まで＝18主成分）、図用に UMAP |
| クラスタ数 | k-means のシルエット係数、ガウス混合の BIC、ブートストラップ安定性（ARI、50回） |
| 分類 | 18主成分の上で k-means（k=5、初期値50回） |
| 町ごとの安定性 | ブートストラップ100回で、同じタイプの町とまた同じ組になる割合 |
| 頑健性 | 手法（ガウス混合・ウォード法・UMAP上の k-means・HDBSCAN）と指標（財政／産業／医療・教育・生活を除く、主成分5つ、主成分にしない）を変えたときの一致度（ARI） |

## 主な結果

- 第1主成分（ばらつきの29.7%）は「人口が多く密度が高い ↔ 高齢化が進み1人あたり歳出・職員数が多い」という都市と過疎の軸。第2主成分（9.8%）は「製造業・女性の就業・大きい世帯 ↔ 単独世帯・サービス業・飲食店」、第3主成分（9.5%）は「転入・婚姻・就業率 ↔ 医療・福祉・高齢夫婦世帯」
- 組の数：シルエット係数は k=2 が最大（0.23）で、そのあとは k=5 に小さな山（0.133）。BIC は k=4 が最小で k=5 はほぼ同じ。ブートストラップ安定性は k=2（0.97）・k=3（0.92）が高く、k=4（0.70）より k=5（0.77）のほうが高い。中身の分かれ方も見て k=5 を採用
- 5つのタイプ

| タイプ | 町の数 | 人口の合計 | 特徴 |
|---|---|---|---|
| 1 都市 | 405 | 8,994万人 | 人口密度・地方税の割合・転入が高い。65歳以上は26.7%（中央値） |
| 2 ものづくりの町 | 374 | 1,664万人 | 製造業の従業者が34.7%、女性の就業率・外国人の割合・世帯人員が高い |
| 3 地方の中小の市と町 | 521 | 1,734万人 | 65歳以上38.0%、病院・医療福祉の従業者が多め。転入・婚姻は低め |
| 4 高齢化が進んだ小さな町村 | 308 | 170万人 | 65歳以上44.9%、人口の中央値4,276人、1人あたり歳出130万円 |
| 5 観光・一次産業の小さな町 | 132 | 53万人 | 宿泊・飲食の従業者13.5%、単独世帯・男性の割合・女性の就業率が高い（観光地・酪農・漁業の町） |

- 町ごとの安定性：中央値0.94、9割以上同じ組に入る町は64%、0.6未満の「境界の町」は9%。シルエット係数が負の町は10%
- 頑健性：指標を変えた場合の ARI は0.57〜0.90（主成分5つ 0.90、財政を除く 0.88、主成分にしない 0.81、医療・教育・生活を除く 0.68、産業を除く 0.57）。手法を変えた場合は0.30〜0.48と低く、HDBSCAN は1,082町（62%）を「どの塊にも属さない」と判定した
- 結論：市区町村には「はっきり離れた塊」はなく、都市から過疎までの連続的なグラデーションを、目的に合わせて区切っているに近い。5タイプは指標の選び方には比較的強いが、手法には弱い

## ファイル

- `data/indicators.csv`：62指標（市区町村×指標）。標準化した値 `data/z.csv` と主成分得点 `data/pcs.csv` は `03a` を実行すると作られます
- `results/clusters.csv`：各市区町村のタイプ・安定性・シルエット・UMAP座標
- `results/profile_z.csv`・`profile_median.csv`：タイプのプロフィール、`k_selection.csv`・`k_stability.csv`：組の数の検討、`robustness_ari.csv`：頑健性
- `figures/`：負荷量・組の数・UMAP・プロフィール・地図・頑健性

## 注意（このデータで言えないこと）

- タイプは分類の都合で、町の良し悪しではありません
- 指標の年次は2019〜2024年でそろっていません。所得の指標は SSDSE-A に入っていないため使っていません
- 政令市は市全体で1行です（区ごとの違いは見ていません）
- k=5 は根拠を示したうえでの選択ですが、唯一の正解ではありません。境界の町（安定性0.6未満）は、分け方しだいで別のタイプになります
