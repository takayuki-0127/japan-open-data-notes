# F173 2つの年の所得分布は、どれだけ「動いた」のか？（最適輸送・Wasserstein 距離と分位点の差の比較）

国民生活基礎調査の「所得金額階級別の世帯の割合（25階級）」から、1985〜2024年の39年分の所得の分布を作り直し、2つの年の分布の離れ具合を最適輸送の距離（Wasserstein 距離）で測った。平均・中央値・分位点の差、階級の割合だけを比べる距離（全変動距離・Hellinger・KS）とも比べた。

## 問い

- 1994年と2024年の世帯の所得分布は、物価をそろえたうえで、どれだけ動いたのか
- 「動いた量」を分布全体で測る Wasserstein 距離は、平均や中央値の差と比べて、何を新しく教えてくれるのか
- 「どの年に大きく動いたか」は、距離の種類で変わるのか
- 階級の扱い（分布のつなぎ方・いちばん上の開いた階級・階級の粗さ）で、距離はどこまで変わるのか

## データ

| データ | 内容 | 出典 |
|---|---|---|
| 世帯数の相対度数分布（所得金額階級別） | 1985〜2024年（所得の年、2019年は調査なし）の39年、25階級（50万円刻み〜1,000万円、1,000〜1,100、1,100〜1,200、1,200〜1,500、1,500〜2,000、2,000万円以上）、0.1%単位 | 厚生労働省「国民生活基礎調査」令和7年 所得・貯蓄 年次推移 第2表（e-Stat、statInfId 000040473361）。F115 で取得済み |
| 平均・五分位値・中央値 | 同じ39年（答え合わせ用） | 同 第1表・第6表・第7表（000040473360・000040473365・000040473366） |
| 消費者物価指数 | 2020年基準「持家の帰属家賃を除く総合」の暦年平均（頑健性で「総合」） | 総務省統計局（e-Stat、statInfId 000032103842）。F101 で取得済み |

- 所得は世帯の総所得（税・社会保険料を引く前）で、世帯人員による調整（等価所得）はしていない。
- 金額はすべて、所得の年の CPI で **2024年の価格** に直した（1994年→2024年の倍率は1.149）。名目の結果も results/ に置いた。
- 新しいデータは取得していない（data/ の3ファイルは F115・F101 の整形済みデータの写し）。

## 手法

**分布の作り直し**：F115 で公表の分位点にいちばん近かった「単調スプライン＋パレート」を主に使った。累積分布を階級の境目で単調な3次スプライン（PCHIP）でつなぎ、2,000万円以上はパレート分布（α は 1,500万円と2,000万円の生存割合から決める）とした（src/common.py は F115 のもの）。

**Wasserstein 距離**：所得のような1次元の分布では、最適輸送は「下から同じ順位の世帯どうしを結ぶ」形になり、距離は分位点関数 Q(u) の差で書ける。

| 指標 | 式 | 意味 |
|---|---|---|
| W1 | ∫₀¹ \|Q₂(u) − Q₁(u)\| du | 分布を動かすのに必要な「量×距離」。2本の累積分布の間の面積と同じ |
| 上向き・下向き | ∫ (Q₂−Q₁)⁺ du、∫ (Q₂−Q₁)⁻ du | W1 を、所得が増える向きと減る向きの動きに分ける（上向き−下向き＝平均の差） |
| W2 | √∫ (Q₂−Q₁)² du | 2乗で測る。W2² ＝ 平均の差² ＋「形の違い」の部分、に分けられる |
| 比での W1 | ∫ \|log Q₂ − log Q₁\| du | 順位ごとの「何%動いたか」の平均 |
| 形だけの W1 | ∫ \|Q₂/μ₂ − Q₁/μ₁\| du | それぞれ平均で割ってから比べる（水準を除いた形の違い。単位は平均の何倍か） |

u は 0〜1 を2万等分した点で数値積分した。

**比べた距離**：階級の割合だけを使う全変動距離（½Σ\|s₁−s₂\|）と Hellinger 距離、累積分布の差の最大（KS）。これらは「どれだけ遠くへ動いたか」を測らない。

**比べた組**：1994→2024 を主に、10年ごとの組、前の年との組（38組）、39年から2年を選ぶすべての組（741組）。

**動いていなくても出る大きさの目安**：2024年の分布から 2,000・5,000・20,000世帯を引き、25階級・0.1%単位に丸めてから作り直し、元の分布との W1 を測った（各80回、乱数の種 173）。

## 結果

### 0. 作り直した分布は、公表の分位点を1%前後で再現した

39年×5つの分位点（下から20・40・50・60・80%）で、公表値とのずれの中央値は0.2〜1.0%、最大2.7%。平均は中央値0.5%、最大1.2%。1994年→2024年の公表の分位点どうしの差と、作り直した分布の差のずれは、2.3万円以内だった（図2の黒い点）。

### 1. 1994年→2024年：W1 は178.8万円で、ほぼすべてが「下向き」

2024年の価格で比べると：

| 指標 | 値 |
|---|---|
| W1 | 178.8万円 |
| 上向きの動き ／ 下向きの動き | 0.2万円 ／ 178.6万円 |
| 平均の差（作り直した分布） | −178.4万円（公表値どうしでは −187.9万円） |
| 中央値の差 | −174.2万円（公表値どうしでは −175.1万円） |
| W2 | 213.0万円（「形の違い」の部分は W2² の30%） |
| 比での W1 | 0.29（順位ごとに平均でおよそ25%下がった） |
| 全変動距離（25階級） | 0.107（世帯の10.7%が別の階級にいる計算） |

- 下から2%を除くと、どの順位でも2024年の所得が1994年を下回っていた（分位点関数が交わらない）。このとき W1 は平均の差の大きさとちょうど同じになる。
- 順位ごとの差：下から10%で −42万円（−24%）、25%で −111万円（−31%）、50%で −174万円（−28%）、75%で −219万円（−22%）、90%で −304万円（−21%）。
- 万円で見ると上の順位ほど大きく下がり、上位10%の部分が W1 の23%を占めた（上位1%は4%）。率で見ると、下から20〜45%あたりの下がり方（約30%）がいちばん大きかった。

### 2. W1 が平均の差を上回るのは、平均がほとんど変わらない組だけ

39年から2年を選ぶ741組（実質）で、W1 と平均の差の大きさを比べた。

| 平均の差の大きさ | 組の数 | 逆向きの動きが W1 の10%を超える組 | W1 ÷ 平均の差（中央値） |
|---|---|---|---|
| 10万円未満 | 65 | 91% | 2.68 |
| 10〜25万円 | 108 | 49% | 1.24 |
| 25〜50万円 | 143 | 27% | 1.08 |
| 50万円以上 | 425 | 0% | 1.00 |

- 平均が50万円以上変わった組では、W1 は平均の差とほぼ同じで、新しい情報をほとんど足さなかった。
- 平均がほとんど変わらない組では、上の順位が上がり下の順位が下がる（またはその逆）ことがあり、平均の差では見えない動きを W1 が拾った。例：名目の2004→2024 は平均の差 −4.1万円だが、W1 は20.4万円（上向き8.1・下向き12.3）。
- 名目では741組の27%、実質では20%で、逆向きの動きが W1 の10%を超えた。

### 3. 「広がった」は、万円の W1 には出ず、率や形の距離に出る

1985年→2024年（実質）は、W1 が67.0万円で平均の差と同じだった（どの順位も下がった）。ただ率で見ると、下から10%は −25%、上から10%（90%点）は −2%で、下のほうが大きく下がって分布は広がっていた。平均で割ってから測る「形だけの W1」は 0.081 で、1994→2024 の 0.042 のほぼ2倍。万円の W1 は水準の動きにほぼ支配されるため、広がり方は率・形の距離で別に見る必要がある。

### 4. 「どの年に大きく動いたか」は、距離の種類で入れ替わる

前の年との38組（実質）で、いちばん大きく動いた3組：

| 距離 | 1位 | 2位 | 3位 |
|---|---|---|---|
| W1 | 1987→1988 | 2021→2022 | 1998→1999 |
| 平均の差 | 1987→1988 | 2021→2022 | 1998→1999 |
| 比での W1 | 2021→2022 | 1998→1999 | 2023→2024 |
| KS | 1998→1999 | 2021→2022 | 2004→2005 |
| 全変動距離 | 1998→1999 | 2004→2005 | 2023→2024 |
| W2 | 1987→1988 | 1989→1990 | 2013→2014 |

- 順位相関：W1 と全変動距離は0.52、全変動距離と Hellinger は0.91。W2 はほかの距離とほとんど相関しなかった（−0.27〜0.31）。W2 は上の裾の小さな揺れに引っぱられる。
- 前の年との W1 の中央値は15.4万円。2,000世帯の標本だと、分布が動いていなくても平均14.7万円（95%点26.1万円）、5,000世帯なら9.6万円（同16.5万円）の W1 が出る。1年ごとの動きの多くは、この揺れと区別しにくい大きさだった（調査の所得票の世帯数で目安が変わる。ここでは確かめていない）。

## 頑健性

1994→2024 の W1（実質、万円）：

| 確かめたこと | W1 | W2 |
|---|---|---|
| 主：単調スプライン＋パレート | 178.8 | 213.0 |
| 階級内一様＋パレート | 180.0 | 215.0 |
| GB2 を当てはめる | 179.7 | 219.4 |
| 階級の中央の値（開いた階級は2,000×1.5） | 182.0 | 237.6 |
| 2,000万円以上を全員2,000万円 | 172.3 | 195.1 |
| 2,000万円以上を全員3,000万円 | 180.5 | 226.8 |
| 14階級にまとめる | 179.5 | 213.3 |
| 8階級にまとめる | 181.1 | 215.1 |
| 5階級にまとめる | 234.8 | 518.6 |
| 1,000万円以上をひとまとめ | 240.2 | 597.7 |
| 物価を「総合」で調整 | 166.5 | 197.3 |
| 上位1%を除いて測る | 172.8 | — |
| 前後3年の平均（1993〜95 → 2022〜24） | 192.2 | — |

- 分布のつなぎ方と上の裾の仮定を変えても、W1 は172〜182万円、どれも「ほぼ全部が下向き」だった。
- 階級を粗くしすぎる（5階級、1,000万円以上をひとまとめ）と、上の裾のパレートの α が小さく出て、W1 は3割、W2 は2.5倍以上に膨らんだ（F115 と同じ崩れ方）。W2 は裾の扱いに弱く、階級データから測る指標としては W1 のほうが安定していた。
- 比べる年を変えても（1985・1990・1994・1997・2000・2005・2010・2015年 → 2024年）、どの組も逆向きの動きは W1 の3%以下で、W1 は平均の差とほぼ同じだった（34〜179万円）。
- 名目で測ると、1994→2024 の W1 は81.1万円（下向き80.8）。物価の調整の有無で大きさは2倍以上違うが、「ほぼ全部が下向き」は同じ。

## 言えないこと

- **同じ世帯が動いたわけではない。** 最適輸送の「動き」は、1994年の下から30%の世帯と2024年の下から30%の世帯を結んだもので、別の世帯どうしの比較。ある世帯の所得が下がったこと（所得の移動）は、このデータからは分からない。
- **下がった理由は分けていない。** 世帯の総所得は、高齢の世帯や1人の世帯が増えると、1人ひとりの所得が変わらなくても下がる。世帯の構成の変化と、世帯ごとの所得の変化を分けておらず、「暮らし向きが何割悪くなった」とは言えない。等価所得（世帯人員で調整した所得）での比較はしていない。
- **税・社会保険料を引く前の所得。** 可処分所得の分布は別に動いている可能性がある。
- **物価のそろえ方で大きさが変わる。** CPI の「総合」と「持家の帰属家賃を除く総合」で W1 は166〜179万円、名目では81万円。どの物価が世帯の暮らしに合うかは決めていない。
- **1年ごとの動きは、標本の揺れと区別しにくい。** 動いていなくても出る大きさの目安は、仮に置いた世帯数（2,000〜20,000）によるもので、調査の実際の標本の大きさでは確かめていない。前の年との比較から「この年に分布が変わった」とは言えない。
- **いちばん上はパレートの仮定。** 2,000万円以上（2024年は1.6%）の中の並びは分からない。W1 への影響は小さい（172〜182万円）が、W2 や上位の分位点の差は仮定に左右される。
- **距離の大小は「どちらが良いか」を示さない。** 分布の離れ具合を測るだけで、格差や暮らしの良し悪しの評価はしていない。
