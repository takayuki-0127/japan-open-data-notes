# 1033 「定時」の決め方（1分・5分）で、定時率はどう変わるのか？（移動と時間）

「定時率」は、時刻どおりに着いた便の割合です。ただ、何分までの遅れを「時刻どおり」とみなすか、遅れを秒で記録するか分で記録するか、早く着いた便をどう扱うかを決めないと、値は決まりません。遅れ方の形が違う路線どうしでは、決め方を変えると順位も入れかわります。**ここでは、作成者が乱数で作った架空の路線バス3系統（終点に着く遅れの形を系統ごとに作成者が置いたもの）の同じ1か月の便から、6つの決め方で定時率を出し、値と系統の順位、改善の見え方がどう変わるかを数えました。遅れの形を変えた27通りと、1か月の便の数による振れも確かめました。**

路線・系統・会社はすべて架空のもので、実在の路線や運行の記録は使っていません。

## 主な結果

### 6つの決め方での定時率（各系統2,000か月の平均、`results/routes_by_definition.csv`）
| 決め方 | 系統A（小さな遅れが多い） | 系統B（ほぼ時刻どおり・ときどき大きく遅れる） | 系統C（早く着くことが多い） | 1か月ごとに1位だった割合（A／B／C） |
|---|---|---|---|---|
| ①遅れ1分未満（秒で記録） | **29.58%** | **74.38%** | 69.79% | 0%／99.45%／0.55% |
| ②記録が1分以内（分で四捨五入） | 50.44% | 76.98% | 75.28% | 0%／83.95%／16.05% |
| ③記録が1分以内（分で切り捨て） | 67.32% | 78.84% | 79.75% | 0%／28.8%／71.2% |
| ④前後1分以内（1分以上の早着も外す） | 29.47% | 73.77% | **36.88%** | 0%／100%／0% |
| ⑤遅れ3分未満 | 85.82% | 82.11% | 86.45% | 33.75%／0.05%／66.2% |
| ⑥遅れ5分未満 | **93.96%** | **87.18%** | 93.9% | 52.05%／0%／47.95% |

- **遅れ1分未満では系統Bが74.38%で、99.45%の月で1位だった。系統Aは29.58%でいちばん低かった。遅れ5分未満では系統Aが93.96%になり、系統Bの87.18%を上回った**。系統Bは5分未満では、2,000か月のどの月も1位にならなかった
- 置いた分布で、系統Aと系統Bの定時率が入れかわる幅は153.5秒だった。この幅より短く区切るとB、長く区切るとAが上になる
- 「1分以内」でも、遅れを分で切り捨てて記録すると（実際は2分未満まで定時になる）、系統Aは29.58%から67.32%に上がり、1位は系統Cになる月が71.2%だった
- 1分以上早く着いた便も外すと、系統Cは69.79%から36.88%に下がった
- 遅れの平均は、系統A 114秒・系統B 105秒・系統C 29秒（置いた分布からの式の値）。平均の遅れでは系統AとBは近いのに、①の定時率では系統Bが44.8ポイント上だった
- ①と⑥で1位の系統が違った月は99.6%、①と③で違った月は70.65%だった
- 6つの定時率は、どれも置いた分布からの式の値と0.03ポイント以内で合った。定時率の値そのものは、置いた遅れの形の写しで、新しく見つけたことではない。数えたのは、決め方による値と順位の動きの大きさ、1か月ごとの振れ、改善の見え方

### 改善の見え方：系統Aで平均の遅れが同じくらい縮む2つの改善（20万便、`results/improvement_routeA.csv`）
| | 遅れの平均 | ①遅れ1分未満 | ③記録が1分以内（切り捨て） | ⑤遅れ3分未満 | ⑥遅れ5分未満 |
|---|---|---|---|---|---|
| 改善前 | 114.04秒 | 29.55% | 67.39% | 85.89% | 93.93% |
| 改善ア：ふだんの便の遅れを30秒縮める | 90.02秒（−24.02秒） | **50.43%（+20.88）** | 76.24%（+8.85） | 86.57%（+0.68） | 93.93%（**+0.0**） |
| 改善イ：大きく遅れる便の遅れを半分に | 87.04秒（−27.0秒） | 29.55%（**+0.0**） | 78.39%（+11.0） | 95.15%（+9.26） | **99.13%（+5.2）** |

- **平均の遅れは同じくらい縮む（−24.02秒と−27.0秒）のに、①の定時率では改善アだけが+20.88ポイント上がり、⑥では改善イだけが+5.2ポイント上がった**。どちらの改善が効いたように見えるかは、定時の決め方で入れかわった
- 改善アで平均が24.02秒縮むのは、ふだんの便（80%）を30秒縮めたため（式の値は−24.0秒）

### 確かめ：遅れの形を変えた27通り（式の値、`results/grid_shapes.csv`）
- 遅れ1分未満では、27通りすべてで系統Aが系統Bより低かった（差は−71.61〜−14.02ポイント）
- 遅れ5分未満では、27通りのうち24通りで系統Aが上になり、順位が入れかわった（差は−0.51〜+15.2ポイント）
- 入れかわらなかった3通りは、系統Bの大きく遅れる便が少なく（15%）遅れも短い（平均240秒）ときで、5分未満でも系統Bが0.51ポイント上だった。このうち系統Aのふだんの便が平均45秒の通りでは、1か月1,200便の記録で系統Aが上と出た月が31.0%あった

### 確かめ：1か月の便の数と、①の1か月ごとの振れ（系統B、各2,000か月、`results/monthly_spread_by_runs.csv`）
| 1か月の便 | ①の平均 | 1か月ごとの10〜90% |
|---|---|---|
| 120便 | 74.45% | 69.17〜79.17% |
| 300便 | 74.39% | 71.33〜77.67% |
| 1,200便 | 74.39% | 72.75〜76.0% |
| 4,800便 | 74.41% | 73.6〜75.19% |

- 1か月120便では、同じ系統でも①の定時率が月によって69.17〜79.17%と振れた。系統Bと系統C（①で74.38%と69.79%）の差は、120便ではこの振れの中に入る

## 注意（言えないこと）
- 架空のデータです。系統ごとの遅れの形（ふだんの便と大きく遅れる便の割合・平均・散らばり）は作成者が置いたもので、定時率の値はこの分布からの式どおりです。順位が入れかわるのも、作成者が遅れの形の違う系統を置いたためです。実在の路線の定時率を表すものではありません
- どの決め方が正しい、とは言えません。乗る人がどれだけの遅れで困るかで、使う幅が変わります（推測）
- 遅れは終点に着いた時刻だけで数えました。途中の停留所での遅れ（1040 で扱っています）、発車の遅れ、運休は扱っていません
- 改善アと改善イは、遅れの分布をそのまま縮めた架空の操作です。どの改善をすべきかの助言はしません
- まれに起きるとても大きな遅れは扱っていません
