## もとのリポジトリの説明

以下は、もとのリポジトリ `jma-sea-level-sst` の README です（同じリポジトリにあったほかの記事の分も含みます）。

### jma-sea-level-sst：気象庁「海洋の健康診断表」で、日本沿岸の海面水位と日本近海の海面水温の長期変化を調べる

気象庁「海洋の健康診断表」の公開データ（日本沿岸の平均海面水位 1906〜2025年、GPS併設13検潮所 2004〜2025年、日本近海13海域と全球平均の年平均海面水温）を使ったリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| W1 | 日本沿岸の海面水位は何cm上がったか。上昇率は期間でどう違うか。地点の差は | 期間別の線形トレンド（OLS）。90%信頼区間を OLS（気象庁と同じ）、Newey-West（HAC）、AR(1) の有効標本数で補正したものの3通りで計算。10年平均の差、5年移動平均の極大、13地点の地盤上下変動の補正前後の比較 | `src/w1_sea_level.py` |
| W2 | 日本近海の海面水温の上がり方は世界平均の何倍か。海域・季節でどう違うか | 気象庁の公表上昇率（℃/100年）の再現、同じ期間でそろえた日本近海と全球の上昇率の比、日本近海の偏差を全球の偏差で回帰した傾き（HAC）、海域×季節の上昇率 | `src/w2_sst.py` |

#### 主な結果
- **W1**：日本沿岸（4海域平均）の海面水位は、1980年代の平均が平年（1991〜2020年平均）より51mm低く、2016〜2025年の平均は53mm高い。約40年で**約10cm**上がった。上昇率は1980〜2025年で年2.8mm（90%信頼区間 2.4〜3.2、HAC）、2004〜2025年で年3.7mm（OLS の90%区間 2.7〜4.7）。13地点平均（地盤の上下変動を補正）は2004〜2025年で年3.5mm（同 2.8〜4.2）で、気象庁の公表値と一致した。一方、1906年からの4地点の記録では年0.4mm（1906〜2023年）で、年々の値の自己相関（0.70）を補正すると信頼区間は0.08〜0.75まで広がり、1906〜2018年に限ると0.29（−0.02〜0.59）で0と区別できない。5年移動平均は1950年頃に+18mmの山があり、2000年代前半と同じ高さだった（十年規模の変動）。13地点の2004〜2025年の上昇率は那覇1.2mm〜布良6.7mm
- **W2**：日本近海（13海域平均）の年平均海面水温の上昇率は100年あたり+1.36℃、全球平均は+0.63℃で、気象庁の公表値を小数第2位まで再現した（全海域・全季節で差は0.005以内）。ただし期間が違う（日本近海は1908年〜、全球は1891年〜）。同じ1908〜2025年でそろえると全球は+0.69℃で、日本近海は**約2.0倍**。1980〜2025年では3.21℃対1.42℃（2.3倍）。日本近海の偏差を全球の偏差で回帰した傾きは1.82（標準誤差0.17、1908〜2025年）。海域では日本海中部+2.05℃、釧路沖+1.81℃が大きく、日本海北東部+0.52℃、先島諸島周辺+0.83℃が小さい。季節は冬（1〜3月）+1.68℃、秋+1.55℃が大きく、夏（7〜9月）は+0.98℃。黄海は冬+2.29℃に対し夏+0.86℃

#### 動かし方
データは `data/raw/`（海面水位）と `data/sst_area_txt.zip`（海域別の海面水温、初回実行時に `data/raw/` へ自動で展開）に入っているので、そのまま動きます。

```bash

```

#### 注意
- 平年値は1991〜2020年の平均。海面水位の「4地点」と「4海域（16地点）」は気象庁の計算方法の違う系列で、4地点は2023年で終了している。長期（1906年〜）は4地点、1960年以降は4海域を使った
- 気象庁の表の信頼区間は「90%」。OLS で計算すると公表値（2004〜2025年 3.7[2.7〜4.7]、2006〜2018年 2.9[0.8〜5.0]、13地点 3.5[2.8〜4.2]）と一致した。年々の値に自己相関があるときは OLS の区間が狭すぎるので、Newey-West と AR(1) で補正した区間も `results/w1_trends.csv` に出した
- 13地点の補正前の記録には地震などによる地盤の動きが入る。大船渡は2011年の東北地方太平洋沖地震で記録上の水位が約70cm上がり、その後の地盤の隆起で下がり続けているので、補正前の直線の傾き（年23mm）には意味がない。函館は補正前だと下がって見える
- 海面水温の上昇率は各海域の統計開始年（1900〜1911年）から2025年までの OLS。気象庁の公表値と同じになった。有意性は気象庁が独自の目安（自己相関を考慮）で判定しているため、季節別の「有意でない」の印は一部が公表と一致しない（日本海北東部の夏）
- 日本近海の値は1942〜1949年など欠測がある。網走沖は1964〜2005年しかないので上昇率を出していない
- 「日本近海は世界の約2倍」は、陸に近い海と外洋全体の平均を比べたもの。日本の気温の上昇率（100年あたり+1.44℃、気象庁）と同程度である
