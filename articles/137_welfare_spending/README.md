# 137 市区町村の民生費：地方財政状況調査で、歳出に占める福祉の割合と内訳を12年分比べる

総務省「地方財政状況調査」市町村分の表7〜12（歳出内訳及び財源内訳）から、全国の市区町村（東京23区を含む）の決算を 2012・2016・2020・2024年度で比べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A137 | 市区町村の歳出のうち民生費はどれだけを占め、何が増えたか。市・町村や団体ごとにどう違うか | 款別の歳出合計を足して歳出合計とし、民生費の割合と内訳（児童・老人・社会福祉・生活保護）、財源、団体区分別の割合、団体ごとの分布を比較 | `src/a137_welfare.py` |

## 主な結果
- 民生費の合計は 2012年度 18.4兆円 → 2024年度 27.1兆円（+47%）。歳出合計の伸び（+29%）を上回り、歳出に占める割合は 34.3% → 39.2%
- 内訳では児童福祉費が最大（6.54 → 10.41兆円、+59%）。伸びが最も大きいのは社会福祉費（4.32 → 8.31兆円、+93%）。生活保護費は +3% でほぼ横ばい（民生費に占める割合は 20.0% → 13.9%）
- 2020年度は特別定額給付金（総務費）で歳出合計が 75.0兆円にふくらみ、民生費の割合は 29.9%
- 2024年度の割合（区分ごとの合計）：東京23区 50.9%、中核市 45.2%、政令指定都市 40.2%、その他の市 38.2%、町村 25.7%。町村の生活保護費は歳出の 0.1%（多くの町村では生活保護を都道府県が担う）
- 団体ごとの割合の中央値は 27.7% → 30.2%。40%以上の団体は 149 → 371、両年度がある 1,738団体のうち 71.2% で割合が上がった

## 動かし方
`data/municipal_expenditure.csv` が入っているので、そのまま動きます。

```bash
pip install -r requirements.txt
cd src
python a137_welfare.py
```

`data/municipal_expenditure.csv` を作り直すときは、下の表の CSV から「歳出合計」と民生費の財源の行を抜き出した `data/raw/d137b_bundle.csv`（大きいのでリポジトリには入れていません）を置いて `python build_data.py` を実行します。抜き出しファイルは、`#H,調査年,statInfId,元の見出し…` の行のあとに `調査年,statInfId,元の行…` が続く形式です。

## 注意
- 歳出合計は、款（議会費・総務費・民生費・衛生費・労働費・農林水産業費・商工費・土木費・消防費・教育費・災害復旧費・公債費・諸支出金・前年度繰上充用金）の「歳出合計」の行を足した値です。団体間の重複を除いた「純計」ではありません
- 団体区分 6（一部事務組合）・7（広域連合）などは除き、1・2・3・4・5・8・9（政令指定都市、特別区、中都市、小都市、町村、中核市、施行時特例市）を使いました。記事では 3・4・9 を「その他の市」としています
- 行番号は表ごとに違うため、行名（「歳出合計」など）で取り出しています
- 介護保険・国民健康保険・後期高齢者医療などの特別会計は含まず、普通会計からの繰出しだけが民生費に入ります
- 2024年度の社会福祉費には、物価高対策の給付金を計上した団体の分が含まれている可能性があります
- 人口で割っていないので、住民1人当たりの比較はしていません
