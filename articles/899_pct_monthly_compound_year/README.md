# 899 毎月3%の伸びは、1年で36%なのか？（割合とパーセント）

会員数が毎月3%ずつ伸びると、1年では3%×12＝36%ではなく、42.6%伸びます。2か月目の3%は、1か月目に伸びた分を含めた数にかかるからです（複利）。**ここでは、月の伸びを1年や3年に直す計算に加えて、作成者が乱数で作った架空の会社1,000社の会員数（毎月の伸びの平均と振れを作成者が置いたもの）で、「月の伸びの平均×12」「月の伸びの平均で複利」の2つの読み方が、実際の1年の伸びからどれだけずれるかを数えました。**

振れがなければ、1年の伸びは（1＋月の伸び）の12乗−1 で、式で決まります。この記事で数えたのは、月ごとの伸びに振れがあるとき、2つの読み方のどちらが実際に近いかです。

割合の変化を%ポイントと変わった率のどちらで書くかは関連する記事 897、上がって下がると元に戻らないことは 898、対数の軸で伸びの鈍りがどう見えるかは 820、累積のグラフの見え方は 816 で扱っています。この記事は、月の伸びを長い期間に直す数え方に絞ります。

## 主な結果

### 例：振れがないとき
| 毎月の伸び | ×12 | 12か月（複利） | ×24 | 24か月（複利） | ×36 | 36か月（複利） |
|---|---|---|---|---|---|---|
| 1% | 12% | 12.68% | 24% | 26.97% | 36% | 43.08% |
| 2% | 24% | 26.82% | 48% | 60.84% | 72% | 103.99% |
| **3%** | **36%** | **42.58%** | 72% | 103.28% | 108% | **189.83%** |
| 5% | 60% | 79.59% | 120% | 222.51% | 180% | 479.18% |
| 10% | 120% | 213.84% | 240% | 884.97% | 360% | 2991.27% |

- 毎月3%なら、1年で42.58%、3年で189.83%（約2.9倍）。×月数との差は、伸びた分にまた伸びがかかる分（式どおり）
- 会員数1万人からなら、12か月後は14,257.6人（×12なら13,600人）、36か月後は28,982.8人（×36なら20,800人）
- 逆に、1年で36%伸ばすには、毎月3%ではなく2.595%でよい。1年で42.58%を12で割ると3.548%になり、月の伸び（3%）より大きく出る

### 架空の会社1,000社・12か月（毎月の伸び 平均3%・振れ2%）
| | 1,000社の平均 | 読み方−実際（中央値） |
|---|---|---|
| 実際の12か月の伸び | 42.16%（中央値41.85%、10〜90%の範囲30.53〜54.69%） | |
| 月の伸びの平均×12 | 35.7% | **−6.16ポイント** |
| 月の伸びの平均で複利 | 42.45% | +0.27ポイント |

- ×12は、1,000社すべて（100%）で実際より小さく出た
- 振れ2%では、1,000社すべて（100%）で、複利の読みのほうが×12より実際に近かった

### 確かめ：振れと月数を変えると（毎月の伸びの平均3%、各2,000社）
| 振れ | 12か月：×12のずれ | 12か月：複利のずれ | 12か月：複利が近い会社 | 36か月：×36のずれ | 36か月：複利のずれ | 36か月：複利が近い会社 |
|---|---|---|---|---|---|---|
| 0% | −6.58 | 0.0 | 100% | −81.83 | 0.0 | 100% |
| 2% | −6.38 | +0.28 | 100% | −79.4 | +1.86 | 100% |
| 5% | −4.94 | +1.72 | 71.4% | −70.3 | +11.66 | 97.5% |
| 10% | **−0.48** | **+6.78** | **30.8%** | −40.46 | +44.33 | 47.4% |

（ずれは読み方−実際の中央値、ポイント）

- **振れが大きいと、月の伸びの平均で複利にした読みは実際より大きく出た**。振れ10%・12か月では、実際の中央値34.82%に対し、複利の読みの平均は49.39%だった。上がって下がると元に戻らない分（898）が、月の伸びの平均には入っていないため
- 振れ10%・12か月では、×12のずれ（中央値−0.48ポイント）がたまたま小さくなり、複利の読みが近い会社は30.8%に下がった。複利で増える分と、振れで減る分が打ち消し合ったためで、×12が正しい数え方になったわけではない
- 36通りで、複利の読みが近い会社は14.7〜100%、複利の読みのずれ（中央値）は0.0〜+81.74ポイント、×月数のずれ（中央値）は−299.18〜+7.45ポイントだった
- 毎月の伸びの平均1%・振れ10%・12か月では、実際の中央値は6.25%で、×12（平均11.84%）も複利の読み（平均18.73%）も大きく出た

## 動かし方
```
pip install -r requirements.txt
cd src && python a899_compound.py
```
2秒ほどで終わります。`data/companies_12months.csv` と `data/example_path_3pct.csv` もこのとき作ります。

- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約1.2秒）

## 注意（言えないこと）
- 架空のデータです。毎月の伸びの平均・振れ・月数は作成者が置いたもので、結果はこれで決まります。複利の読みが×月数より近い会社の割合は、置き方で14.7〜100%と動きました
- 振れがないときの1年の伸びは、式で決まる結果です
- 毎月の伸びは月ごとにでたらめに決まり、前の月とつながりがないと置きました。伸びがだんだん鈍る、季節で動くといった形は入れていません
- 実在の会社の会員数を表すものではありません。目標の決め方や、伸びの見通しは言えません
- 既存の記事 712 は、月の伸び率を年率に直すとき12倍するか複利で直すかを、途中で伸びが鈍る1社の会員数で、その後12か月の実際の伸びと比べています。644 は毎年の伸び率の算術平均と年率（幾何平均）の違いを扱っています。この記事は、月の伸びに振れがある1,000社で2つの読み方がどれだけ外れるかと、振れが大きいと月の伸びの平均で複利にした読みも外れることに絞りました
