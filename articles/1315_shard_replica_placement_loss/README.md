# 1315 写しを3台ずつに置いても、3台が同時に止まったときに読めなくなるデータの割合は、写しの置き方でどれだけ違うのか？（データの振り分け）

データを何台かに分けて置くとき、1台が止まっても読めるように、同じデータの写しを3台に置くことがあります。それでも、写しを置いた3台がそろって止まれば、そのデータは読めなくなります。どの3台に写しを置くかの決め方はいくつかあり、データごとにでたらめに3台を選ぶ形、台をはじめから3台ずつの組に分けておく形、輪の上で続く3台に置く形などがあります。**ここでは、作成者が置いた架空のアプリのデータ（10万件を30台に、写しを3台ずつ置いたもの）で、3台が同時に止まる組み合わせ4,060通りをすべて数え、読めなくなるデータの割合が4つの置き方でどう違うかを比べました。置き方を作り直して20回数え、4台が同時に止まる場合と、台の数（15〜120台）×データの件数（1万〜100万件）の12通りでも確かめました。実機では測らず、すべてシミュレーションです。**

例のアプリ・データ・台は架空のもので、実在のデータベースや機械の写しの置き方を表すものではありません。台数・費用の見込みの助言はしていません。

関連する記事：987「『少なくとも1回』の確率は、回数でどう増えるのか？」は、1回ごとの確率が小さくても、回数が増えると「少なくとも1回起きる」確率は大きくなることを扱っています。1314「1台が止まって、輪の上で次の台がその分をまるごと受け持つと、受け持つ台の量は平均の何倍になるのか？」は、1台が止まったときに、その分を受け持った台がどれだけ重くなるかを数えています。1309「その輪の上に1台を何か所に分けて置くかで、いちばん多い1台の受け持ちはどれだけ平均に近づくのか？」は、1台を輪の上の何か所に分けて置くかで、いちばん多い1台の受け持ちがどれだけ平均に近づくかを数えています。1316「容量の大きい台と小さい台がまざるとき、件数で均等に振り分けると、全体の何割が埋まった時点で最初の1台がいっぱいになるのか？」は、容量の違う台に件数で均等に振り分けたとき、全体のどこまで埋まった時点で最初の1台がいっぱいになるかを扱っています。この記事は、987 と同じ「どれかが起きる」確率の形を使いますが、問いは、読めなくなるデータの割合の平均は同じでも、写しの置き方で「起きやすさ」と「起きたときの大きさ」が入れかわる点です。

## 主な結果

### 基本（30台・10万件・3台が同時に止まる4,060通り、置き方20回の平均、`results/base_methods.csv`）
| 置き方 | 何か1件でも読めなくなる組み合わせの割合 | 読めなくなる割合の平均（全組み合わせ） | 読めなくなったときの割合（平均） | 同じく件数 | いちばん大きいとき |
|---|---|---|---|---|---|
| ①でたらめに3台 | **100.0%** | 0.02463% | **0.0246%** | 24.63件 | 0.0452% |
| ②決まった3台の組 | **0.2463%** | 0.02463% | **10.0%** | 10,000.0件 | 10.16565% |
| ③輪の上で続く3台 | 0.7389% | 0.02463% | 3.3333% | 3,333.33件 | 13.73305% |
| ④輪の上で続く3台（1台16か所） | 10.21675% | 0.02463% | 0.24116% | 241.168件 | 1.69275% |

- **読めなくなる割合の平均は、4つの置き方すべてで0.02463%（1÷4,060、式どおり）で同じだった**。どのデータも、写しを置いた3台がそろって止まる確率は4,060通りのうち1通りなので、置き方によらずこの値になる
- **違ったのは起き方だった**。①でたらめに3台では、どの3台が止まっても何かが読めなくなり（100.0%）、1回に読めなくなるのは平均24.63件（0.0246%）だった。②決まった3台の組では、何かが読めなくなるのは4,060通りのうち組と同じ10通りだけ（0.2463%）だが、そのときは組の1つ分（平均10.0%、10,000.0件）がまとめて読めなくなった
- ②の0.2463%（10÷4,060）と10.0%（10組の1つ）、③の0.7389%（30÷4,060）と3.3333%（30組の平均）は、組の数で決まる値（作りどおり）。③はとなりどうしの3台の組が30通りあり、受け持つ輪の長さがばらつくので、いちばん大きいときは13.73305%だった
- ④1台を16か所に分けて置くと、使われる3台の組は平均414.8通りに増え、何かが読めなくなる割合は10.21675%、読めなくなったときは平均0.24116%と、①と③の間になった（図1・図2）

### 参考：4台が同時に止まる場合（30台・10万件、27,405通り、1回目の置き方、`results/a1315_main.json` の four_down）
| 置き方 | 何か読めなくなる割合 | 読めなくなったときの割合（平均） |
|---|---|---|
| ①でたらめに3台 | 100.0% | 0.0985% |
| ②決まった3台の組 | 0.9852% | 10.0% |
| ③輪の上で続く3台 | 2.8462% | 3.4615% |
| ④輪の上で続く3台（1台16か所） | 34.6032% | 0.2847% |

- 読めなくなる割合の平均は、どれも0.09852%（式どおり）だった。止まる台が増えても、「①はいつも少し、②はまれにまとめて」という並びは変わらなかった

### 確かめ：12通り（`results/grid.csv`）
- 読めなくなる割合の平均は、12通り×4つの置き方すべてで式 1÷（台数から3台を選ぶ組み合わせの数）と同じだった（差は0.0）
- 何か読めなくなる組み合わせの割合は、①で3.49798〜100.0%、②で0.0142〜1.0989%、③で0.04232〜3.2967%、④で0.56166〜36.52748%だった。①は、データの件数が3台の組み合わせの数より十分多いと100%に近づき、120台・1万件（組み合わせ280,840通り）では3.49798%だった
- 読めなくなったときの割合は、①で0.0004〜0.2198%、②で2.5〜20.0%、③で0.8333〜6.6667%、④で0.0538〜0.64976%だった。②と③は台の数で決まり（②は3÷台数、③はほぼ1÷台数）、データの件数ではほぼ変わらなかった
- **12通りすべてで、何か読めなくなる割合は ①≧④＞③＞②、読めなくなったときの割合は ①＜④＜③＜② の同じ並びだった**（`a1315_main.json` の configs_same_order）
- 10万件の4通りでは、①で何か読めなくなる割合は15台・30台で100.0%、60台で94.64408%、120台で29.96834%だった（図3）

## 注意（言えないこと）
- 架空のデータです。台はどれも同じ確率で、ほかの台と関係なく止まると置きました。同じ棚・同じ電源の台がそろって止まるような、止まり方の偏りは入れていません。偏りがあると、どの置き方がよいかは変わります（推測、数えていません）
- 止まった台は戻らないものとして、その時点で読めなくなる件数だけを数えました。写しを作り直すまでの時間や、その間に別の台が止まることは数えていません
- 「まれにまとめて読めなくなる」と「いつも少しずつ読めなくなる」のどちらがよいかは、使い方で変わります。この記事はどちらかをすすめるものではありません。台数・費用の見込みの助言もしていません
