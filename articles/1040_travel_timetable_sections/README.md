# 1040 計画の時刻表どおりに動く割合は、区間の数でどう変わるのか？（移動と時間）

停留所の多いバスの路線では、区間が増えるほど時刻表どおりに走りにくくなりそうです。1区間で時刻表どおりの確率を、区間の数だけ掛け算して考えることもあります。けれども、「時刻表どおり」を終点で数えるか、全部の停留所で数えるか、停留所ごとの平均で数えるかで、答えは違います。早く着いたら時刻表の時刻まで待つ運び方や、時刻表に組んだ余裕でも変わります。**ここでは、作成者が乱数で作った架空のバスの路線（1区間の走る時間の分布と、時刻表の1区間の時間を作成者が置いたもの）の10万便で、区間の数を1〜30に変え、終点で定時・全部の停留所で定時・停留所ごとの定時の平均の3つの数え方と、1区間の定時率の掛け算を比べました。時刻表の1区間の時間、区間ごとの振れ、便に共通の振れ、早く着いても待たない運び方を変えた確かめも行いました。**

例の路線は架空のもので、実在の路線名・会社名は使っていません。

関連する記事：同じ企画の 1032「乗り換え1回で、全体の遅れはどう増えるのか？」は乗りかえでの遅れを、1033「「定時」の決め方（1分・5分）で、定時率はどう変わるのか？」は定時とみなす遅れの幅を、1039「移動時間の短縮は、全体の時間をどれだけ減らすのか？」は乗りつぐ通勤の1つの区間を短くしたときの全体の減り方を扱います。この記事は定時の幅を1分に固定し、区間の数での変わり方に絞ります。同時に進める作業が全部そろう確率が掛け算で下がる話は 851、順に行う作業の見積もりを足す話は 849 で扱っています。この記事の区間は順につながっていて、遅れが次の区間に持ちこされる点が 851 と違います。

- 1区間で定時の便は89.43%だった
- **10区間の同じ便を、終点で数えると55.58%、全部の停留所で数えると30.62%、停留所ごとの平均で数えると66.89%が「時刻表どおり」だった**。数え方だけで、いちばん高い停留所ごとの平均といちばん低い全部の停留所で36.27ポイント違った
- 終点で定時の割合は、区間が増えるほど下がり方がゆるやかになった（10区間55.58%、30区間46.45%）。途中で遅れても、時刻表の余裕（1区間あたり平均より約0.09分）で取りもどせる便があるため
- 全部の停留所で定時の割合は、掛け算（0.8943の k 乗）と、少ない区間では下に、多い区間では上に外れた。15区間から上回った（15区間で20.34%対18.71%、30区間で8.28%対3.5%）。1つの停留所で遅れた便はその次も遅れやすく、時刻表どおりの便は続けて時刻表どおりになりやすいため（仕組みからの説明）

- **早く着いたら待つ運び方の9通りで、30区間の終点で定時の割合は24.81〜77.77%、10区間の全部の停留所で定時の割合は10.25〜60.51%と動いた**
- 時刻表の1区間を平均（3.11分）より長く組むほど、終点の定時の下がり方はゆるやかになった（3.6分では10区間80.88%、30区間77.77%）。平均より短く組む（3.0分）と、区間が増えるほど下がり続けた（30区間27.54%）
- 掛け算との比べは、区間の数と置き方で向きが変わった。10区間では9通りのうち2通り（区間ごとの振れ0.4で10.25%対9.82%、便に共通の振れ0.2で36.4%対20.6%）でだけ全部の停留所で定時の割合が掛け算を上回った。30区間では9通りのうち7通りで上回り、区間ごとの振れ0.15（40.43%対42.07%）と便に共通の振れ0（1.43%対6.48%）で下回った。上回る分の多くは、その便の全区間に効く共通の振れ（道が混む日など）から来ていた
- 早く着いても待たない運び方では、時刻表に組んだ余裕の分だけ早く走り、早すぎる便が定時から外れた。30区間の終点の遅れの平均は−2.661分（早着）で、終点で定時は7.3%だった。「時刻表どおり」の割合は、早く着いたときの運び方で大きく変わる
- 基本の行は、主な結果（10万便）と乱数が違うため、10区間の終点で定時が55.32%と55.58%のように少し違う

## 注意（言えないこと）
- 架空のデータです。1区間の走る時間の分布、時刻表の1区間の時間、振れの大きさ、早く着いたときの運び方は作成者が置いたもので、結果はこれで決まります。30区間の終点で定時の割合は、置き方で24.81〜77.77%（早く着いても待たない運び方では7.3%）と動きました
- 定時とみなす遅れの幅は1分に固定しました。幅を変えると割合はどれも変わります（定時の決め方は 1033 で扱っています）
- 停留所での乗り降りの時間、前の便との間隔、途中で時刻表を組み直すことは入れていません。区間ごとの走る時間は、便に共通の振れを除いて互いに関係ないと置きました
- 実在の路線の定時率を表すものではありません。時刻表の組み方をどうすべきかも言えません。この記事は、区間の数と数え方で「時刻表どおり」の割合がどう変わるかを数えただけです
