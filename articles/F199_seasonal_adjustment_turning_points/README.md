# F199 季節調整のやり方で、「景気の山」の時期は変わるのか？

note：季節調整のやり方で、「景気の山」の時期は変わるのか？ 鉱工業・雇用の5系列で、同じ原数値を X-13・STL などで調整し直して山谷を決めると、公表値と同じ月になったのは約半分。4か月以上ずれた点の多くは、高さの差が1%未満の山がもう1つあるときで、前年比で決めると山は中央値2か月早かった（看板記事 F199）

## 問い

景気の「山」や「谷」の月は、季節調整した月次の統計から決めることが多い。では、季節調整のやり方（公表値・X-13・STL・移動平均・前年比）を変えると、決まる山谷の月はどれだけ動くのか。山谷の判定ルールを変えたときと比べて、どちらのほうが効くのか。

[F63](../F63_yoy_vs_mom/) は「前年比と前月比で、転換点に**早く気づける**のはどちらか」を調べた。この記事は、あとから振り返って山谷の**月を決める**とき、季節調整の方法でその月が動くかに絞る。[F174](../F174_business_cycle_hmm_multiseries/) は局面（拡張・後退）をモデルで分けた記事で、ここでは扱わない。

## データ

新しいデータは取っていません。F63 のフォルダ（コミット c3ad8a7 に固定）から取得しました（`src/01_取得.py`）。

| 系列 | 出典（F63・F42 で取得） | 期間 | 使った値 |
|---|---|---|---|
| 鉱工業生産・鉱工業出荷 | 経済産業省「鉱工業指数」 | 1978年1月〜2026年8月 | 原指数と季節調整済指数（接続指数） |
| 有効求人倍率 | 厚生労働省「一般職業紹介状況」 | 1990年1月〜2026年8月 | 実数と季節調整値 |
| 就業者・完全失業率 | 総務省「労働力調査」 | 1990年1月〜2026年8月 | 原数値と季節調整値 |
| 景気基準日付 | 内閣府 | 1975年3月の谷〜2020年5月の谷 | 山と谷の月 |

完全失業率は符号を逆にして「上＝良い」にそろえました。景気動向指数（CI）は季節調整前の値が公表されていないので、調整し直す比較には使っていません。

## 手法

**季節調整の方法（9通り）**：すべて同じ原数値から作る（公表値だけは公表された季節調整値）。

| 方法 | 内容 |
|---|---|
| 公表の季節調整値 | 各府省が公表した値 |
| X-13（X-11法） | X-13ARIMA-SEATS、対数、ARIMA の自動選択、外れ値の自動検出 |
| X-13（SEATS） | 同じ設定で SEATS 法 |
| X-13（X-11法・外れ値処理なし） | 外れ値の検出をしない |
| STL（季節の窓 7／13／35） | 対数の STL（頑健版）。窓が小さいほど季節の形が年ごとに変わってよい |
| 2×12移動平均 | 原数値の中心化12か月移動平均（季節を消した「傾向」） |
| 前年比 | 原数値の12か月前との比（率は差） |

自分で回した X-13 には、日本の祝日・曜日の調整を入れていません（確認で曜日の調整だけ入れた版も作りました）。

**山谷の判定**：簡略版の Bry–Boschan 法（`src/common.py`）。前後5か月でいちばん高い（低い）月を候補にし、山と谷を交互にそろえ、端の6か月は除き、6か月未満の局面と15か月未満の循環を消す。

**基準日付との対応**：景気基準日付の山（谷）から±12か月以内にある同じ種類の点のうち、いちばん近いものを「その山（谷）の判定月」とする。各系列の期間の最初と最後の12か月にある基準日付は除いた（5系列で計68点）。

**くらべ方**

- 方法ごとに、公表値で決めた月と同じになった割合（±0・±1・±3か月）
- 同じ基準日付について、季節調整4方法（公表値・X-11法・SEATS・STL13）で決めた月のずれの幅（最も遅い−最も早い）と、判定ルール5通り（基本／窓3／窓7／最短局面9か月／3か月移動平均してから判定）でのずれの幅

## 主な結果

**1. 公表値と同じ月になったのは約半分**（`f199_agreement.png`、`results/summary_by_method.csv`）

| 方法 | 同じ月 | ±1か月以内 | ±3か月以内 | 比べた点 |
|---|---|---|---|---|
| X-13（X-11法） | 53% | 71% | 80% | 49 |
| X-13（SEATS） | 48% | 67% | 77% | 48 |
| X-13（外れ値処理なし） | 53% | 71% | 80% | 49 |
| STL（窓7／13／35） | 49〜53% | 67〜69% | 80% | 51 |
| 2×12移動平均 | 2% | 23% | 66% | 47 |
| 前年比 | 33% | 48% | 69% | 42 |

自分で回した方法どうしでは一致が高く、X-11法とSEATSは85%、X-11法とSTL（窓13）は75%が同じ月でした（`results/pairwise_agreement.csv`）。公表値との差には、方法の違いに加えて、祝日・曜日の調整、基準年ごとに変わる調整の設定などが混ざっています。

**2. 4か月以上ずれた割合は、判定ルールを変えるより季節調整を変えたほうが大きい**（`f199_spread.png`）

| ずれの幅 | 季節調整4方法（48点） | 判定ルール5通り（公表値・43点） |
|---|---|---|
| 0か月 | 42% | 28% |
| 1か月以内 | 62% | 79% |
| 4か月以上 | 27% | 14% |
| 最大 | 14か月 | 18か月 |

判定ルールを変えると「1か月ずれる」ことが多く、季節調整を変えると「同じか、大きく飛ぶか」に分かれました。

**3. 大きくずれたのは、ほぼ同じ高さの山（谷）がもう1つあったとき**（`f199_near_tie.png`、`results/check_near_tie.csv`）

公表値で、判定した山（谷）と、4か月以上離れた次に高い（低い）月との高さの差を測りました。

- ずれの幅が4か月以上だった13点：差の中央値 0.51%（85%が1%未満）
- ずれの幅が1か月以内だった30点：差の中央値 2.71%（27%が1%未満）
- マン・ホイットニー検定（片側） p=0.0003、順位相関 −0.50
- 公表値と X-11法の季節調整値の、月ごとの差の中央値は 0.47〜0.85%（就業者は 0.03%）で、山の高さの差と同じくらいの大きさでした。

例：鉱工業生産の2018年10月の山は、公表値では2017年12月、X-11法では2018年5月、STL では2018年10月と判定されました（`f199_example_iip2018.png`）。3つの月の高さの差は1%前後です。X-11法の2018年5月は、ほかの方法にない上振れで、祝日（大型連休）の調整を入れていないことが関係していると考えています（推測）。

**4. 前年比で決めると、山は早く出た**（`f199_yoy.png`、`results/yoy_vs_pub.json`）

前年比で決めた月 − 公表値で決めた月（42点）：中央値 −1か月、平均 −2.5か月。早かった22点・遅かった6点・同じ14点（符号検定 p=0.004）。山では中央値 −2か月、谷では 0か月でした。前年比の山は「伸びがいちばん大きい月」なので、水準の山より前に来やすい（成長循環の山）。2×12移動平均は逆に、公表値より中央値2か月遅く出ました。

**5. 基準日付との差**

公表値で決めた月と基準日付との差は、中央値 −1か月（山 −1、谷 0）、平均の絶対値3.2か月でした。どの季節調整の方法でも、中央値は −1〜+1か月の範囲でした（前年比の山は −3.5か月）。

## 頑健性（`src/03b_確認.py`、`results/robustness.json`）

| 確認 | 結果 |
|---|---|
| 曜日の調整を入れた X-13（X-11法） | 公表値と同じ月 52%（入れない版 53%）。近づかなかった |
| データの終わりを切る（鉱工業2系列・有効求人倍率・完全失業率の43点、山谷の6・9・12・24か月後まで） | X-11法：山谷が見つかった割合 77%→86%→95%→95%、最終的な判定と同じ月 51%→51%→58%→74%。STL：60%→84%→88%→95%、35%→56%→49%→70%。2年後でも4つに1つは月が違った（`f199_endpoint.png`） |
| X-13 の推定期間（鉱工業2系列、1990年〜／2000年〜） | 1978年〜で推定したときと同じ月が 97%（38点） |
| 判定ルール5通り | 上の「主な結果2」 |
| STL の季節の窓（7／13／35） | 公表値と同じ月 49〜53% で、ほぼ変わらない |
| 外れ値処理の有無 | X-11法で同じ月の割合は変わらない（53%） |

## 言えないこと

- **公表値との差の中身は分けていない。** 公表の季節調整値は、祝日・曜日の調整、基準年ごとの設定、接続のしかたなどを含みます。自分で回した X-13 には祝日の調整を入れていないので、「公表値と半分しか一致しない」のうち、どこまでが方法の違いでどこまでが設定の違いかは分けられません。
- **判定ルールは簡略版。** 内閣府の景気基準日付は、ヒストリカル DI と専門家の検討で決まります。ここで使った簡略版の Bry–Boschan 法を、1系列ずつ当てたものとは違います。基準日付との差は「この系列・このルールでの差」です。
- **点の数が少ない。** 5系列×基準日付で68点、すべての方法で見つかったのは48点です。系列どうしは似た動きをするので、独立な48点ではありません。
- **データの終わりを切る確認は、公表値ではできない。** 過去の時点で公表されていた季節調整値（リアルタイムの値）は使っていません。自分の X-13・STL を、その時点までのデータで回し直しただけです。
- **景気動向指数（CI）は調整し直していない。** CI は季節調整済みの系列から作られるので、原数値からの比較に入れていません。
- **どの方法が「正しい」かは言えない。** ずれは、山の高さがほぼ同じときに起きる「どちらを選んでもおかしくない」状況で出ています。
