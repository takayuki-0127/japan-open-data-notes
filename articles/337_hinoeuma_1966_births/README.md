# 337 1966年の丙午に、出生はどれだけ減ったのか（人口動態統計）

1966年（丙午）の出生数を前後の年と比べ、減った数・前後の年に動いた数を出し、1906年の丙午と比べたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A337 | 1966年の出生はどれだけ減り、前後の年にどれだけ動いたか。1906年と何が違うか | 年ごとの出生数（男女別）に、丙午と前後の年を除いた前後4年ずつの対数の直線を当てて「見込んだ数」を作る。出生性比（女100に対する男）からふだんの性比との差を人数に直す。母の年齢別に1966年を前年・翌年の平均と比べる | `src/a337_hinoeuma.py` |

## 主な結果
- 1966年：出生1,360,974人、見込み1,779,048人、差−418,074人（−23.5%）。1965年は+84,180人（+4.8%）、1967年は+116,170人（+6.4%）。前後の年の合計は+20.0万人で、1966年の不足の48%。3年の差し引きは−21.8万人
- 見込みの窓を前後3年・5年に変えても、1966年は−23.4%・−23.8%
- 男は−23.1%、女は−23.9%。出生性比は1965年105.3、1966年107.6、1967年105.3。ふだんの性比（106.5）から数えた女の不足は1966年約0.7万人
- 1906年：出生性比は1905年102.7、1906年108.7、1907年102.7。ふだんの性比（104.6）から数えると、女は1906年に2.6万人少なく、1905年に1.3万人、1907年に1.4万人多い。出生は前年比−4.0%（男−1.3%、女−6.8%）
- 母の年齢別（1966年、前年と翌年の平均との比）：15〜19歳−3%、20〜24歳−22%、25〜29歳−32%、30〜34歳−30%、35〜39歳−19%、40〜44歳−7%。減った人数の55%は25〜29歳
- 1965年12月の出生（1日あたり）は年平均の0.94倍で、1960年の12月（0.94倍）と同じ

## ストックの案から変えた点
- もとの問いは「どの月にどれだけ減ったか」。公開の表（人口動態統計 上巻 第4.2表、長期統計系列 2-28）の月別出生数は、この時期は5年おき（1960・1965・1970年）しかなく、1966年の月別は取れなかった。年ごとの数字での確かめに変えた

## 確かめたこと
- 見込みの窓を変えた結果を `results/a337_main.json` の robust_window に残した
- 1906年は日露戦争の時期と重なるため、出生数の見込み（−12%）は本文で使わず、性比だけを使った
- 空のフォルダで流し直し、data・results・figures が一致した

## データ
- `data/raw/chouki_02-24.xls`（男女別出生数）・`02-26.xls`（乳児死亡）・`02-27.xls`（新生児死亡）・`02-29-a.xls`（母の年齢別出生数）：総務省統計局「日本の長期統計系列」。Internet Archive の保存版（`https://web.archive.org/web/2013id_/http://www.stat.go.jp/data/chouki/zuhyou/02-24.xls` など）から取得（2026-11-12）
- `data/raw/jinkou_r7_jokan_4-2_births_by_month.csv`：e-Stat 人口動態統計 令和7年 上巻 第4.2表（statInfId=000040503641）を UTF-8 にしたもの
- `data/births_1955_1975.csv` ほか：使った年を抜き出したもの

## 注意（言えないこと）
- 1966年の月ごとの出生数は取れていません。年末・年始への寄りは分かりません
- 見込んだ数は前後の年の流れをのばしたものです
- 出生を控えた理由や届け出の事情は、数字からは分かりません。地域ごとの違いは扱っていません
- 1947〜72年の数字は沖縄県を含みません。2026年の数字は使っていません
