# 01 取得（ブラウザ内で実行）

コンテナから政府サイトに直接つながらないため、Chrome のページ内で fetch と SheetJS（xlsx@0.18.5）を使って Excel を読み、必要な表だけを JSON にして保存した。

1. 再生可能エネルギー 事業計画認定情報（https://www.fit-portal.go.jp/PublicInfoSummary）
   - 「A表 都道府県別認定・導入量」2017年6月末〜2026年3月末（四半期、36ファイル）
   - 各ファイルの 表A①-1（導入件数・新規認定分）、表A①-2（導入件数・移行認定分）、表A②-1（導入容量・新規認定分, kW）、表A②-2（導入容量・移行認定分）、表A③・表A④（認定）
   - 見出し（3段）を前から埋めて「太陽光発電設備/10kW未満」のような列名にし、都道府県と合計の行だけを残した → data/raw/f134_fit_quarterly.json
2. 資源エネルギー庁「各種データの公開（過去公表分）」（https://www.enecho.meti.go.jp/category/saving_and_new/saiene/statistics/past.html）
   - A表（A_prefYYYYMM.xls）2014年4月末〜2017年3月末（月次）
   - 「再生可能エネルギー発電設備の導入状況」（YYYYMMsetsubi.xls）2012年8月末〜2014年3月末（月次）。県名の行が認定、その下の括弧内の行が運転開始分
   - 短い間隔で続けて取得すると応答が空になったため、12秒あけて取り直した → data/raw/f134_fit_monthly_old*.json
3. 共変量：SSDSE-E-2026（独立行政法人統計センター）の一戸建住宅数・総住宅数（2023年住宅・土地統計調査）、可住地面積、1人当たり県民所得。年間日照時間は気象庁の県庁所在地の観測値（198_sunshine_rank の data/sunshine_annual.csv、2012〜2024年の平均）。
