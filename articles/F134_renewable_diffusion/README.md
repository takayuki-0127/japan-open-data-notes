# F134 再生可能エネルギーの導入は、どこで速く進んだのか？

FIT・FIP（固定価格買取制度・市場連動の制度）の都道府県別の導入量に、普及曲線（Bass・ロジスティック・ゴンペルツ）を当てはめ、電源ごとに「どの時期に、どこで」広がったかを比べました。

## 問い
- 再エネの導入は、S字の普及曲線（ゆっくり始まり、加速し、頭打ちになる）で表せるか。電源（住宅用太陽光・事業用太陽光・風力）で形は違うか
- 都道府県で、普及の時期や水準はどれだけ違うか。日照時間・一戸建の多さ・所得とどう関係するか

## データ
- 資源エネルギー庁「再生可能エネルギー 事業計画認定情報」A表 都道府県別認定・導入量（2017年6月末〜2026年3月末、四半期、36時点）
- 資源エネルギー庁「各種データの公開（過去公表分）」A表（2014年4月末〜2017年3月末、月次）と「再生可能エネルギー発電設備の導入状況」の運転開始分（2012年12月末〜2014年3月末、月次）
- 合計88時点 × 47都道府県。新規認定分（2012年7月以降に認定された設備）の導入件数・導入容量を使う。2012年7月（制度開始）を0とした
- 住宅用太陽光＝太陽光10kW未満の件数、事業用太陽光＝10kW以上の容量（kW）、風力＝20kW未満と20kW以上の容量の合計
- 共変量：SSDSE-E-2026（統計センター）の一戸建住宅数・総住宅数（2023年住宅・土地統計調査）、可住地面積、1人当たり県民所得。年間日照時間は気象庁の県庁所在地の観測値（2012〜2024年の平均、198_sunshine_rank のデータ）

## 手法
- 3つの曲線を都道府県×電源ごとに非線形最小二乗で当てはめた：Bass（m・p・q）、ロジスティック（K・r・t0）、ゴンペルツ（K・b・c）。上限 K は観測の最大値の1〜20倍に制約
- 「速さ」の指標：当てはめた上限の50%に届く時点（t50）、10%→90%にかかる年数。モデルに頼らない指標として「その県の2026年3月末の水準の半分に届いた時点」（観測 t50、線形補間）も使う
- 予測の検証：2023年3月末までで当てはめ、2026年3月末を予測した誤差（47県の中央値）を、直近2年の伸びを延ばすだけの直線と比べた
- 地域差：一戸建1000戸あたりの住宅用の件数、可住地1km²あたりの事業用の容量、風力の地方別シェアを、日照時間・一戸建の割合・所得とスピアマンの順位相関（ブートストラップ2000回、seed=134）と標準化した重回帰（HC1）で比べた。県名の順位は出さず、地方ごとにまとめた

## 結果
1. **事業用太陽光はS字で、ほぼ頭打ち。** 全国では2017年後半に上限の半分に届き（Bass 2017.8年、ロジスティック 2017.8年、ゴンペルツ 2017.6年）、10%→90%に約10年（2013.8→2023.9年）かかった。上限は2026年3月末の1.00〜1.04倍。年間の導入量は2014年度の857万kWが最大で、2025年度は83万kW。47県の t50 は中央値2017.3年、四分位で2016.7〜2018.3年（Bass）と、どの県もほぼ同じ時期に進んだ。3年後の予測誤差は曲線で5〜6%、直線では10%
2. **住宅用太陽光はS字にならない。** 年間の件数は2013年度28.8万件→2017年度13.3万件と減ったあと、2025年度は22.4万件に増えている。曲線の t50 はモデルで2019.8〜2025.8年と6年もずれ、3年後の予測は曲線だと47県すべてで少なすぎ（誤差18〜24%）、直線なら2.6%だった。飽和の兆しは見えない
3. **住宅用の多さは日照時間と関係する。** 一戸建1000戸あたりの件数は県で28〜131件（4.7倍）。日照時間との順位相関は0.57（95%区間0.27〜0.77）で、一戸建の割合・所得を入れた重回帰でも日照の標準化係数は0.70（0.49〜0.91）、一戸建の割合（0.04）と所得（−0.07）はほぼ0。一方、「自分の県の半分に届いた時点」は日照と無関係（−0.03）で、日照の長い県は同じ形の曲線で量が多い
4. **事業用の時期は地方で少し違う。** 2017年6月末までに2026年3月末の水準の何割まで進んでいたかは、四国62%・九州・沖縄58%・中部58%に対し、東北30%。東北は後から伸びた（観測 t50 の中央値 2018.5年、九州・沖縄は2016.3年）
5. **風力はまだ途中で、北海道・東北に集中。** 2026年3月末の新規認定分は505万kW。北海道・東北で73%（2017年6月末は50%）、うち北海道は8.5%→24.9%。上位5県で70%。曲線の上限は Bass で現在の5.7倍、ロジスティックで1.6倍と決まらず、予測誤差も19〜40%で、普及曲線で先を読める段階ではない
6. 東京都の住宅用は2023年3月末の8.0万件から2026年3月末の15.9万件へ、3年でほぼ倍になった（他の県は同じ期間に1.2〜1.4倍程度）。新築住宅への設置を求める都の制度などの影響と考えられる（推測）

## 頑健性
- 曲線の形：事業用の t50 の県の順位は3モデルで相関0.97〜0.99。住宅用は Bass と他の2つで0.72にとどまり、形の選び方で時期が変わる（＝S字の位置が決まっていない）
- 期間：2017年6月以降だけで当てはめると、事業用の全国 t50 は2018.0年（ロジスティック）で同じ。住宅用は上限が現在の4.9倍に跳ね、やはり飽和は見えない
- モデルに頼らない観測 t50 と Bass の t50 の順位相関：事業用0.96、風力0.89、住宅用0.82
- 住宅用を件数ではなく容量で数えても、観測 t50 の県の順位は0.87で一致
- 日照との相関はブートストラップの95%区間が0を含まない（住宅用の水準0.27〜0.77、2017年以降の伸び0.32〜0.79）。事業用の時期（観測 t50）と日照は −0.41〜0.14 で関係が見えない
- 予測の検証（上記）：曲線が直線に勝つのは事業用だけ

## 言えないこと
- 数えているのは FIT・FIP の新規認定分だけ。制度の外の自家消費、制度開始前からの設備（移行認定分、住宅用で約120万件）、大型の水力などは入らない
- 2017年4月の法改正で認定が失効した案件があり、公表元も変わった。2014年3月末（旧表）と4月末（A表）、2017年3月末と6月末の間には数え方の段差がありうる。2012年11月末の値は翌月より多く、移行分を含むとみられるため除いた
- 普及曲線は「この先どこまで増えるか」を言い当てる道具ではない。住宅用と風力では上限がデータから決まらなかった
- 日照との関係は県単位の相関で、日照が導入を増やした（因果）とまでは言えない。補助金・電力会社の接続条件・屋根の向きなど、入れていない要因がある
- 日照時間は県庁所在地1地点の値で、県全体を代表するとは限らない
- 地方や県の差は良し悪しを示すものではない
