# F264 自動車の事故率は、高齢化でどこまで説明できるのか？

**問い**：運転者（原付以上、第1当事者）の免許保有者10万人当たりの人身事故・死亡事故は、2009〜2025年にどれだけ変わったか。そのうち、免許を持つ人の年齢構成の変化（高齢化）で説明できるのはどれだけか。保険の料率でいつも分ける「ミックス（契約者の構成）の変化」と「年齢ごとの頻度の変化」を、公表された全国の集計値で分けた。

計画（事前登録）：[PLAN.md](PLAN.md)（コミット abca560、結果を見る前に作成）

## 結果

| | 人身事故 | 死亡事故 |
|---|---|---|
| 10万人当たり 2009年 → 2025年 | 863.7 → 324.2（−62%） | 5.49 → 2.77（−50%） |
| 年齢ごとの率の変化の効果 | −534.0 | −3.07 |
| 年齢構成の変化の効果 | **−5.5**（下げ幅の1.0%分をさらに押し下げ） | **+0.34**（下げ幅の12.5%分を押し戻し） |
| うち65歳以上の層 ／ 65歳未満の層（平均の率からの差で分けた内訳） | +4.9 ／ −10.4 | +0.34 ／ −0.00 |
| 年齢層ごとの率（2009→2025） | 15区分すべてで −57〜−64% | 15区分すべてで −36〜−69% |
| 件数 2009 → 2025（15歳以下を除く） | 697,991 → 264,287 件（表の合計は 698,129 → 264,348） | 4,439 → 2,256 件 |
| 件数の変化の内訳（保有者の総数／年齢構成／年齢ごとの率） | +3,800 ／ −8,534 ／ −428,970 | +27 ／ +206 ／ −2,416 |

- **人身事故**：年齢構成の変化はほぼ効いていない。65歳以上の割合が増えた分（押し上げ）と、事故の多い16〜24歳の割合が減った分（押し下げ）が打ち消し合った。高齢の層の率は全体の率より少し高いだけ（2009年と2025年の平均で、75〜79歳は全体の1.1倍。免許保有者当たりで、走る距離の違いは入っていない）なので、高齢の層が増えても全体はあまり動かない。
- **死亡事故**：高齢の層の率は全体よりはっきり高い（75〜79歳 1.9倍、85歳以上 4.1倍）ので、年齢構成の変化が下げ幅の1割強を押し戻した（年齢構成を2009年のままに固定した率は −53%、実際は −50%）。
- **保険との比較**：自賠責の支払件数÷契約台数（年度）は 2009→2023年度に −28% で、警察の人身事故の率（暦年、−60%）ほどは下がっていない。年ごとの変化率の相関は 0.77（14年）だが、これは2020年の両方の大きな落ち込みにほぼ頼っていて、2020年を除くと 0.45（順位相関 0.38）。増減の向きが合ったのは14年中10年（2010・2011・2013・2015年は逆）。

### 仮説の判定

| 仮説 | 判定 | 中身 |
|---|---|---|
| H1 年齢構成の効果は押し上げ・変化の2割未満 | **外れ** | 押し下げ（−5.5、変化の −1.0%）。大きさは2割未満だが向きが逆 |
| H2 死亡事故では年齢構成の効果の割合が全事故の2倍以上 | **判定不能** | 全事故の割合が負（−1.0%）になり、「2倍以上」の比較は正の値なら何でも通ってしまう（基準が想定外の符号で働かない）。中身は、死亡事故は押し上げ（+12.5%）、全事故は押し下げ |
| H3 すべての年齢層で率が下がった | 支持 | 人身・死亡とも15区分すべてで下がった |
| H4 自賠責の頻度と警察の率の変化率の相関 0.7 以上 | **基準は超えたが頑健でない** | 0.77（2010〜2023年、14年）。2020年だけを除くと 0.45（1年ずつ抜くと、ほかの年では 0.74〜0.86）、順位相関は 0.51（2020年を除くと 0.38）、向きの一致は14年中10年。任意保険の 0.87 も6年分しかなく、2020年を除くと 0.62 |

### 問い直し：これから10年、年齢構成だけでどれだけ動くか

年齢ごとの率を2025年のままとし、免許保有者の各年齢層が前の10年（2015→2025）と同じ割合で次の年齢層に残る、16〜24歳は今と同じ人数、とおいて2035年の年齢構成を作った（推測を含む投影）。

| | 人身事故 | 死亡事故 |
|---|---|---|
| 2025→2035 の年齢構成だけの変化（16〜24歳を0.85〜1.15倍） | +1.1%（+0.2〜+1.9%） | +4.4%（+3.8〜+4.9%） |
| 同じ方法の答え合わせ：2015年から10年先を出した見込み ／ 実際 | +0.3% ／ −0.3%（どちらも0に近く、向きは逆） | +6.2% ／ +6.0%（合っていた） |
| 75歳以上の割合 2025 → 2035 | 10.2% → 11.3% | 同じ |

答え合わせは、死亡事故は合っていた。人身事故はどちらも0に近く、向きは逆だった。なお答え合わせで使った残り方（2009→2019年）は、確かめる相手の期間（2015→2025年）と重なっている。年齢ごとの率が下がり続ければ全体は下がる。年齢構成だけで見れば、死亡事故の率には10年で4%前後の押し上げが続く見込み（推測）。

## 頑健性（[results/robustness.csv](results/robustness.csv)）

1. **分解の重み**：人身事故の年齢構成の効果は、始点の重み −9.0、中点 −5.5、終点 −2.1（変化の −1.7〜−0.4%）。死亡事故は +0.18〜+0.50（変化の 6.8〜18.3%）。どの重みでも向きは同じ。
2. **期間**：人身事故の年齢構成の効果は 2009→2019 が −8.5（−2.0%）、2019→2025 は +1.8（+1.6%）で、最近は押し上げに変わった。2015→2025 は −0.1。死亡事故は 2009→2019 が +8.4%、2019→2025 が +18.1%、2015→2025 が +12.4%。
3. **毎年つないだ分解・コロナ期（2020〜2022年の変化）を除く**：人身事故 −12.8（−2.4%）、2020〜22年を除くと −13.7（−3.1%）。死亡事故 +0.28（+10.1%）、除くと +10.5%。
4. **年齢区分**：おおむね10歳刻み（16〜24歳、75歳以上はまとめた）でも人身 −1.1%・死亡 +11.1%。65歳以上を1つにまとめると、死亡事故は +4.8% まで小さくなる（65〜69歳と85歳以上の率の違いが消えるため）。区分を粗くすると年齢構成の効果を小さく見誤る。
5. **2つの版の照合**：2019年版と2025年版の重なる2015〜2019年の率は、全年齢層で一致（差0%）。「原付以上」→「一般原付以上」の呼び方の変化で過去の値は変わっていない。
6. **保有者数の戻し方**：件数÷10万人当たり件数で戻した保有者数は、表にある最新年の保有者数と人身事故で ±0.01%、死亡事故で ±0.3% 以内（死亡事故は率が小数2桁に丸められているため）。全体の率は、15歳以下を除いて組み立て直した値（2009年 863.7）と表の値（863.9）が少し違う。

## 計画からのずれ

- PLAN を書く前に、表の形を確かめるため2025年版の表3-1-1の先頭1行（16〜19歳）を見ていた（PLAN に記載）。
- H2 の基準（死亡事故の割合が全事故の2倍以上）は、全事故の年齢構成の効果が負になったため比として意味を持たない。符号が逆（全事故は押し下げ、死亡事故は押し上げ）という形で「支持」とした。
- H4 は、計画では任意保険の対人賠償の頻度を使う予定だった。各年度版の Excel で全国の契約台数と支払件数が年ごとにそろうのは、自賠責の「収支の推移」（1970〜2023年度）と、任意保険の都道府県別統計表の合計（全種目、2016〜2023年度）だった。主の比較を自賠責に変え、任意保険は2017〜2023年度だけ補助に使った（2016年度は契約台数が他の年より約500万台少なく、数え方が合わないため除いた）。
- コロナ期の除外は、計画では2020・2021年としていたが、コードでは2020〜2022年の各年の変化（2019→2020、2020→2021、2021→2022）を除いた。
- 計画にない分析を足した：年齢層ごとの内訳を「全体の平均の率からの差」で表したもの（どの層が押し上げ・押し下げたかを読むため）、件数の変化の分解（対数で分ける LMDI）、毎年つないだ分解。

## 手法

- 全体の率 R = Σ w_a r_a（w：年齢層 a の免許保有者の割合、r：10万人当たり件数）。年齢層は表の15区分（16〜19歳〜85歳以上）。
- 北川（Kitagawa）の分解：ΔR = Σ Δw (r_s+r_t)/2 ＋ Σ Δr (w_s+w_t)/2。
- 年齢をそろえた率：年齢構成を2009年（または2025年）に固定した Σ w_base r_t。
- 件数の分解：件数 = 保有者総数 × Σ w r を、対数で分ける LMDI。
- 投影：同じ生まれ年の人が10年で2つ上の区分に移るとし、前の10年の残り方（保有者数の比）をそのまま当てた。

## 言えないこと

- 免許保有者は「実際に運転している人」ではない。年齢ごとの運転の頻度・距離の違いは入っていない（高齢の層は走る距離が短いと言われるが、ここでは確かめていない）。
- 2023年7月から「一般原付以上」は特定小型原付（電動キックボードなど）を含まない。2つの版の重なる2015〜2019年の値は一致したが、2023年以降は数え方が変わった可能性がある。特定小型原付の運転者の事故は全体の中で少ないため、影響は小さいとみる（推測）。
- 件数は15歳以下を除いて足したもの（表の合計とは少し違う。人身事故 2009年 698,129件・2025年 264,348件に対し 697,991件・264,287件）。
- 第1当事者（過失の重い側）で数えている。事故の相手の年齢、被害の大きさは入っていない。
- 集計の分け方の話で、因果（高齢化が事故を増やした・減らした）を示すものではない。年齢ごとの率が下がった理由（車の安全装置、道路、取り締まりなど）も分けていない。
- 保険の頻度は全国の年度（4月〜3月）の合計で、警察の暦年と1〜3月がずれる。自賠責の契約台数はその年度に結んだ契約の台数で、2〜3年の契約も1台と数えるため「1年間に走った台数」ではない。2008年度は +7.7%、2009年度は −7.7% と動いており、基準の年（2009年度）の頻度は振れている可能性がある。年齢別の頻度は公表された Excel にない。警察の率と保険の頻度の水準の差の理由は調べていない。
- 投影は、前の10年の残り方と16〜24歳の人数の置き方に依存する（推測を含む）。
