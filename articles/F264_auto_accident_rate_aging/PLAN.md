# F264 計画（事前登録）：自動車の事故率は、高齢化でどこまで説明できるのか？

作成：2026-11-11（結果のデータを見る前に書いた。データの表の形を確かめるため、2025年版の表3-1-1の先頭1行〔16〜19歳〕だけは目に入っている）

## 問い

運転者（原付以上、第1当事者＝過失の重い側）の免許保有者10万人当たりの人身事故件数は、この十数年でどれだけ変わったか。そのうち、免許を持つ人の年齢構成が変わったこと（高齢化）で説明できるのはどれだけで、年齢ごとの事故の起こりやすさ自体の変化はどれだけか。

保険の言葉に直すと、「事故頻度の変化は、契約者の年齢構成の変化（ミックス）と、年齢ごとの頻度の変化のどちらから来ているか」という、料率の見直しでいつも分ける問いです。

## データ（予定）

- 警察庁「交通事故の発生状況」（e-Stat、道路の交通に関する統計）表3-1-1 年齢層別 免許保有者10万人当たり交通事故件数、表3-1-2 年齢層別 交通事故件数。2019年版（2009〜2019年）と2025年版（2015〜2025年）。
- 警察庁「交通死亡事故の発生状況」表3-1-1・3-1-2（死亡事故の同じ表）。2019年版・2025年版。
- 年齢層ごとの免許保有者数は「件数 ÷ 10万人当たり件数 × 10万」で戻し、表にある最新年の保有者数と照合する。
- 損害保険料率算出機構「自動車保険の概況」各年度版の Excel（任意自動車保険の契約台数・支払件数）から、対人賠償の支払件数÷契約台数を全国の年度の系列にして、警察の事故率と並べる（取れた年度だけ）。
- 地域の比較・順位づけはしない。全国の集計値だけを使う。

## 方法

1. 全体の事故率 R_t = Σ_a w_{a,t} r_{a,t}（w：年齢層 a の保有者の割合、r：年齢層 a の10万人当たり件数）。
2. 2つの年 s→t の差 R_t − R_s を、北川（Kitagawa）の分解で「年齢構成の効果」Σ (w_t − w_s)(r_s + r_t)/2 と「年齢ごとの率の効果」Σ (r_t − r_s)(w_s + w_t)/2 に分ける。
3. 年齢構成を基準年に固定した「年齢をそろえた事故率」を毎年計算し、そのままの率と並べる。
4. 同じことを死亡事故でも行う。
5. 期間：基本は 2009→2025（2つの版をつなぐ）。区切りとして 2009→2019、2019→2025 も出す。

## 仮説と「外れ」の基準

- H1：年齢構成の変化は全体の事故率を押し上げる向きに働くが、大きさは全体の変化（絶対値）の2割未満。→ 年齢構成の効果が下げる向き、または絶対値で2割以上なら外れ。
- H2：死亡事故では、年齢構成の効果の割合（全体の変化に対する比）が、全事故の2倍以上になる。→ 2倍未満なら外れ。
- H3：年齢ごとの率は、すべての年齢層で 2009→2025 に下がった。→ 1つでも上がった年齢層があれば外れ。
- H4：保険の対人賠償の支払件数÷契約台数の年ごとの変化率は、警察の全体の事故率の変化率と相関が0.7以上。→ 0.7未満なら外れ（取れた年度が6年未満なら判定しない）。

## 頑健性（少なくとも3つ）

1. 分解の重みの取り方：中点（北川）、始点の重み、終点の重みの3通り。
2. 期間：2009→2019、2019→2025、コロナ期（2020・2021年）を除く。
3. 年齢区分：表の区分のまま／65歳以上をまとめる／10歳刻みにまとめる。
4. 2つの版の重なる年（2015〜2019年）で値が合うか（「原付以上」→「一般原付以上」の定義の変化の影響）。
5. 保有者数の戻し方の照合（戻した値と表にある保有者数の差）。

## 問い直し

最初の結果を見てから、1つだけ追加の問いを立てて調べる（記事と README に書く）。

## 言えないこと（予定）

- 免許保有者は「運転している人」ではない。年齢ごとの走る距離の違いは入らない。
- 第1当事者で数えるので、事故の相手の年齢は入らない。
- 因果（高齢化が事故を増やした）ではなく、集計の分け方の話である。
