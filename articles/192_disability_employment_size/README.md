# 192 企業規模による実雇用率の差は縮まったのか：障害者雇用状況の集計結果

厚生労働省「障害者雇用状況の集計結果」（各年6月1日現在）の企業規模別の実雇用率と法定雇用率達成企業の割合を、2014〜2025年の12年分並べ、規模による差が縮まったのかを見たフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A192 | 企業規模による実雇用率の差は縮まったのか | 規模別パネル（5区分×12年）の記述。最大規模と最小規模の差（ポイント）と比（倍）、法定雇用率が上がった年の達成割合の変化 | `src/a192_size_gap.py` |

## 主な結果
- 実雇用率はすべての規模で上がった。2014→2025年に100人未満は1.46%→1.94%（+0.48ポイント）、1,000人以上は2.05%→2.69%（+0.64ポイント）
- 1,000人以上と100人未満の差は0.59ポイント→0.75ポイントで、縮まっていない。比で見ると1.40倍→1.39倍でほぼ同じ（最も小さいのは2023年の1.31倍）。2024〜2025年に差が開いた
- 12年間ずっと法定雇用率を上回っているのは1,000人以上だけ（2023年は500〜1,000人も上回った）
- 法定雇用率が上がった年（2018・2021・2024年）は、達成企業の割合がどの規模でも下がり、下がり幅は大きい企業ほど大きい（1,000人以上 −14.2・−4.1・−12.8ポイント、100人未満 −1.1・−0.2・−1.8ポイント）
- 達成企業の割合は100人未満が44〜47%でほぼ横ばい。1,000人以上は48〜68%と年による振れが大きい

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a192_size_gap.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/size_rates.csv | 年、法定雇用率、民間企業全体の実雇用率・達成割合、規模別（5区分）の実雇用率と達成企業の割合、最小規模の区分の範囲、出所の年報 |
| data/new_small_bands.csv | 報告対象が広がった年に新しく加わった小さな規模（45.5〜50人、43.5〜45.5人、40〜43.5人）の値 |

- 厚生労働省「障害者雇用状況の集計結果」平成27年〜令和7年（https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000079194_00005.html）の各PDFの本文「企業規模別の状況」から読み取った。2014年は平成27年版の前年値
- 民間企業全体の達成割合は本文に載っている2020年以降のみ

## 注意
- 最も小さい規模の区分は、報告対象の拡大に合わせて50〜100人未満（〜2018年）、45.5〜100人未満（2019〜2021年）、43.5〜100人未満（2022〜2024年）、40〜100人未満（2025年）と変わる。各年の報告書の区分のまま使っている
- 実雇用率は、短時間労働者や重度障害者のカウント方法など制度上の数え方による値で、雇用されている人の割合そのものではない
- 2025年は除外率（業種ごとに雇用義務を軽くする仕組み）が10ポイント下がった影響を含む
- 規模別の差の理由（採用の体制、特例子会社の有無など）はこのデータでは分けられない
