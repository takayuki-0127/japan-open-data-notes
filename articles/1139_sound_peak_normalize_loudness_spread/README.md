# 1139 いちばん大きい瞬間の値で音量をそろえると、曲ごとの聞いた大きさはどれだけばらつくのか？（音の大きさ）

何曲かの音量をそろえるとき、いちばん大きい瞬間の値（波の値の絶対値の最大）を同じ高さにそろえるやり方があります。けれども、曲全体の平均の強さは、いちばん大きい瞬間の値から「瞬間の値と平均の強さの差」を引いたものなので、瞬間の値でそろえると、その差が曲ごとにそのまま残ります（作りどおり）。**ここでは、作成者が式と乱数で作った架空の曲120曲（下地の音・打つ音・区間ごとの強弱を作成者が置いたもの）を、①いちばん大きい瞬間を−1dB にそろえる、②曲全体の平均の強さを−20dB にそろえる、の2つでそろえ、そろえたあとの平均の強さと、いちばん大きい瞬間の値がどれだけ散らばるかを数えました。はみ出した1点（どこかで1点だけ大きく出た値）が入ったとき、曲の長さが違うとき、曲の作り方を変えた9通りでも確かめました。**

この記事では、聞いた大きさの代わりに、曲全体の平均の強さ（波の値の二乗平均を dB にしたもの）を物差しにしました。作成者が置いた物差しで、人が聞いて感じる大きさや、配信先の音量の基準の測り方とは一致しません。人に聞き比べてもらうことはしていません。例の曲はすべて作成者が式と乱数で作ったもので、実在の曲・配信先・機材を表すものではありません。

関連する記事：1138「何曲かの音の大きさをデシベルのまま平均すると、音の強さで平均した値とどれだけずれるのか？」は、曲ごとの大きさをまとめるときの平均の取り方を数えています。1137「同じ大きさの音を2つ重ねると、デシベルの値は2倍になるのか？」は、強さで数える dB の足し方を扱っています。同じ企画の 1140「配信先が決まった大きさまで音量を下げるとき、大きく作った曲は得をするのか？」は、平均の強さでそろえる配信先の決まりのもとで大きく作った曲の得失を、1141「音をつぶして大きくする処理をかけると、平均の大きさと強弱の幅はどう入れかわるのか？」は、つぶす処理で瞬間の値と平均の強さの差を縮めたとき平均がどれだけ上がるかを数えています。1144「上限を超えて切れた部分の割合は、大きさの数字にどう表れるのか？」は、②で上限を超える瞬間を切ったとき、切れた割合が大きさの数字にどう表れるかを数えています。

## 主な結果

### そろえ方ごとの散らばり（基本、120曲、`results/summary.csv`）
| | 平均の強さの標準偏差 | 平均の強さの幅（最大−最小） | いちばん大きい瞬間の標準偏差 | いちばん大きい瞬間の幅 |
|---|---|---|---|---|
| そろえる前（作るときの音量はでたらめ） | 3.338dB | 11.956dB | 4.85dB | 21.237dB |
| ①いちばん大きい瞬間を−1dB に | **3.503dB** | **16.243dB** | 0 | 0 |
| ②平均の強さを−20dB に | 0（作りどおり） | 0 | 3.503dB | 16.243dB |

- **いちばん大きい瞬間を−1dB にそろえても、平均の強さは−31.081〜−14.838dB に散らばった**（10〜90%で−28.267〜−19.051dB、中央値−23.766dB）。そろえたあとの平均の強さは、−1dB から「いちばん大きい瞬間と平均の強さの差」を引いた値なので、散らばりはこの差の散らばりそのもの（作りどおり）
- この差は、打つ音がほとんどない曲（1秒あたり0.01回）で13.838dB、打つ音が多く高い曲（1.254回・下地より19.68dB 上）で30.081dB だった。①でそろえると、この2曲の平均の強さに16.243dB の差が残る
- 平均の強さを−20dB にそろえると、今度はいちばん大きい瞬間が−6.162〜10.081dB に散らばり、**120曲のうち88曲（73.33%）が0dB（波の値の上限）を超えた**。上限を超えないようにするには、上限を超えた分を削るか、その曲だけ−20dB より小さくするしかない。①と②の散らばりは同じ大きさ（3.503dB）で、どちらを0にするかの違いだった

### はみ出した1点（120曲、`results/one_click.csv`）
- 曲のどこか1点だけを、いちばん大きい瞬間より6dB 高くすると、①でそろえたあとの平均の強さは平均5.97dB（5.888〜5.997dB）下がった。式では6dB（いちばん大きい瞬間が6dB 上がる分、平均の強さは1点ではほとんど変わらない）
- 曲の中のたった1点のせいで、その曲だけ6dB 近く小さくそろえられる

### 曲の長さ（下地だけ、各40曲、`results/length_check.csv`）
| 長さ | ①でそろえたあとの平均の強さ（平均） | 最小〜最大 |
|---|---|---|
| 10秒 | −13.669dB | −15.224〜−12.445 |
| 60秒 | −14.316dB | −15.491〜−13.433 |
| 300秒 | −14.971dB | −15.653〜−14.103 |

- 同じ作り方の音でも、長いほどたまたま大きく出る瞬間に出会いやすく、①でそろえると300秒の曲は10秒の曲より1.302dB 小さくなった

### 確かめ：曲の作り方×はみ出した1点の9通り（各120曲、`results/grid.csv`）
| 曲の作り方 | はみ出し0% | 10% | 30% |
|---|---|---|---|
| 狭い | 2.235 | 2.345 | 3.766 |
| 基本 | 3.503 | 3.885 | 4.878 |
| 広い | 4.355 | 3.967 | 5.458 |

（数字は①でそろえたあとの平均の強さの標準偏差、dB）

- ①でそろえたあとの平均の強さの標準偏差は、9通りで2.235〜5.458dB、幅（最大−最小）は10.88〜26.228dB、10〜90%の幅は5.901〜14.306dB だった
- 打つ音が少なく低い「狭い」作り方でも、標準偏差2.235dB・幅10.88dB 残った
- ②で平均の強さを−20dB にそろえたとき、0dB を超えた曲は9通りで20〜92.5%だった
- 「広い」作り方では、はみ出し10%のほうが0%より標準偏差が小さかった（4.355→3.967dB）。曲を作り直した乱数の振れによるもので、120曲ではこの程度は動くと考えられる（推測）

## 注意（言えないこと）
- 架空のデータです。曲の作り方（下地・打つ音・強弱・長さ）は作成者が置いたもので、散らばりの大きさはこれで決まります。①のあとの散らばりが「瞬間の値と平均の強さの差」の散らばりと同じなのは、作りどおりです。新しく数えたのは、その大きさが置き方でどれだけ動くか、②で上限を超える曲の割合、1点のはみ出しと長さの効き方です
- 物差しは曲全体の平均の強さだけです。人が聞いて感じる大きさは、音の高さによる重み・静かな部分の扱い・短い区間の大きさなどで変わり、この記事の数字とは一致しません
- 1秒あたり4,000点で、点と点の間で波がもっと大きくなる分は数えていません
- どちらのそろえ方を使うべきか、どの大きさにそろえるべきかは言えません。この記事は、そろえ方の物差しで何が散らばるかを数えただけです
- 実在の曲・配信先の音量の基準・機材を表すものではありません
