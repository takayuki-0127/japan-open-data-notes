# 362 時系列をばらばらに分けて確かめると、予測の精度をどれだけ甘く見積もるのか

予測モデルの精度を確かめるとき、時系列のデータを「ばらばらに分ける交差検証」で確かめると、実際に先の期間を当てたときの誤差よりどれだけ小さく見えるかを、架空の日次需要50本と商業動態統計（月次）で測ったフォルダです。F123（場所で分けて確かめる）の時間版で、F22（電力需要の予測）とは違い、確かめ方の甘さだけを数えます。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A362 | ばらばらに分けた見積もりと、時間の順に分けた見積もりは、実際に先を当てた誤差とどれだけ違うか。モデルやデータの性質で変わるか | 3年分で学び、その先の半年を当てる。事前の見積もりを2通り（ばらばらの5分割／時間の順に5回）出して比べる。モデル×特徴量は3通り | `src/a362_cv_optimism.py` |

## データ
- 架空の日次需要50本（3年半）：伸び＋曜日＋年の季節＋何日も続くずれ（続きやすさ0.9）＋ゆっくり動く水準。乱数の種は362。実在の商品・店の数字ではありません
- 経済産業省「商業動態統計」業態別販売額（月次、6業態×152か月。232のフォルダの写し）：最後の24か月を「先の期間」にした

## 確かめ方
| 名前 | 中身 |
|---|---|
| ばらばらに分ける | 学習用の日を、順番に関係なく5つに分ける。4つで学び、残りの1つを当てる |
| 時間の順に分ける | 前の部分で学び、すぐ後ろの182日（月次は24か月）を当てる。区切りを後ろへずらして5回 |
| 実際 | 学習用の全部で学び、その先の182日（24か月）を当てる。これを正解とする |

誤差は MAPE（誤差÷実績の平均、%）。

## 主な結果
### 架空の日次需要（50本の中央値）
| モデル×特徴量 | ばらばら | 時間の順 | 実際 | ばらばら÷実際 | 時間の順÷実際 |
|---|---|---|---|---|---|
| 日付の特徴量＋勾配ブースティング | 7.6% | 17.6% | 16.0% | 0.48 | 1.06 |
| 日付の特徴量＋線形回帰 | 13.0% | 16.5% | 15.6% | 0.84 | 1.09 |
| 28日以上前の実績＋勾配ブースティング | 14.4% | 18.2% | 16.4% | 0.90 | 1.10 |

- **日付だけで当てる勾配ブースティングでは、ばらばらに分けた見積もりは実際の半分だった**。50本すべてで実際より小さく、27本（54%）では半分未満
- **時間の順に分けた見積もりは、実際の1.06〜1.10倍**で、少し厳しめだが近い
- 線形回帰や、過去の実績を特徴量にした形では、ばらばらの甘さは1〜2割にとどまった
- ばらばらの見積もりは、実際の誤差が9%の系列でも39%の系列でも7〜8%で、**どの系列が当てにくいかを教えない**

### 日ごとのずれの続き方を変える（日付の特徴量＋勾配ブースティング、各16本の中央値）
| データ | ばらばら÷実際 | 時間の順÷実際 |
|---|---|---|
| 続くずれなし | 0.93 | 1.02 |
| 弱く続く（0.5） | 0.84 | 1.08 |
| 強く続く（0.9） | 0.47 | 0.95 |
| 強く続く＋水準が動く | 0.48 | 1.16 |

- **ずれが翌日に続かないデータでは、ばらばらに分けてもほとんど甘くならない**。続くほど甘くなる

### 本物の月次（商業動態統計、6業態）
| 業態 | モデル | ばらばら | 時間の順 | 実際 |
|---|---|---|---|---|
| コンビニ | 勾配ブースティング | 4.5% | 5.4% | 5.4% |
| スーパー | 勾配ブースティング | 4.8% | 7.3% | 6.5% |
| ドラッグストア | 勾配ブースティング | 4.7% | 9.0% | 9.9% |
| ホームセンター | 勾配ブースティング | 8.7% | 8.6% | 8.8% |
| 家電大型専門店 | 勾配ブースティング | 12.2% | 11.2% | 9.8% |
| 百貨店 | 勾配ブースティング | 14.1% | 27.3% | 8.1% |

- 勾配ブースティングでは、6業態のうち4業態でばらばらの見積もりが実際より小さかった。比の中央値は0.91（時間の順は1.05）で、架空の日次ほどの差は出なかった
- 百貨店は、時間の順の見積もり（27.3%）が実際（8.1%）よりずっと大きい。確かめる区間にコロナの時期が入ったため
- 線形回帰では、6業態のうち4業態で、ばらばらの見積もりのほうが実際より大きかった（`results/real_monthly.csv`）。6系列だけなので、割合としては読めない

## 動かし方
```
pip install -r requirements.txt
cd src && python a362_cv_optimism.py
```
`data/example_series.csv`、`results/main.json`、`results/simulated_series.csv`、`results/summary_simulated.csv`、`results/sweep_persistence.csv`、`results/real_monthly.csv`、`figures/` の3枚ができます（約4〜6分。`--quick` を付けると本数を減らして短く試せます）。

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した

## 注意（言えないこと）
- 架空のデータの数字は、置いたずれの続き方（0.9）と水準の動き方で決まります。「半分に見える」はこの設定での結果です
- 勾配ブースティングの設定は1通り（木60本、学習率0.15）です。設定を変えれば甘さの大きさは変わります
- 先の期間は半年（日次）と24か月（月次）の1通りです
- 本物のデータは6系列だけです
- 時間の順に分ける方法にも種類があります（学ぶ期間を伸ばす・ずらす、間をあける）。試したのは1つだけです
