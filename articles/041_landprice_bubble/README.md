### land-price-japan：地価公示（国土数値情報）で、バブル後の40年とこの10年の二極化を見る

国土交通省「国土数値情報（地価公示データ）」2026年版（全国25,565の標準地。各地点に1983〜2026年の価格の履歴つき）を使ったリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| L1 | 今の地価は、バブルのピークの何%か | 継続する標準地の前年比（対数）の平均をつないだ連鎖指数（圏域×用途） | `src/l1_longrun.py` |
| L2 | この10年（2016→2026年）で、どんな地点が上がったか | 上昇地点の割合、駅からの距離別、県の中での価格順位別、重回帰（都道府県の固定効果） | `src/l2_decade.py` |

#### 主な結果
- **L1**：2026年の地価は、ピーク（1991〜92年）と比べて東京圏の住宅地46%・商業地31%、大阪圏の住宅地34%・商業地21%、名古屋圏の住宅地63%・商業地32%、地方圏の住宅地58%・商業地28%。地方圏の商業地は1983年の約半分
- **L2**：2016→2026年に上がった標準地は62%、下がったのは36%。東京圏の商業地は93%の地点が上がった（中央値+49%）一方、地方圏の住宅地は上がった地点46%・下がった地点52%。同じ県の中で2016年の価格が上位20%の住宅地は+27%、下位20%は−8%（二極化）。駅から0.5km以内の住宅地は+18%、5km以上は−8%。住宅地の中央値が下がったのは27道府県

#### 動かし方
```bash
pip install -r requirements.txt
cd src
python l1_longrun.py
python l2_decade.py
```

#### 注意
- 連鎖指数は2026年版に載っている標準地の価格履歴でつないだもので、途中で廃止された地点は入っていません（生き残った地点だけの指数）。1983年に価格がある地点は3,365
- 圏域は都道府県で近似しています（東京圏＝埼玉・千葉・東京・神奈川、大阪圏＝京都・大阪・兵庫・奈良、名古屋圏＝愛知・三重）。公式の三大都市圏は市町村単位です
- 地価公示は鑑定評価にもとづく「正常な価格」で、実際の取引価格ではありません
