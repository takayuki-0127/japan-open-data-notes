# 231 パンと米、どちらにお金を使う世帯が多いのか

総務省統計局「家計調査」（二人以上の世帯）の「米」と「パン」の支出を、全国の長期（2015〜2025年）、年報の購入数量（量と1kgあたりの値段）、52の市（都道府県庁所在市・政令指定都市）、世帯主の年齢別で比べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A231 | パンと米、どちらにお金を使う世帯が多いのか。2025年の逆転は、米をたくさん買ったからなのか、値段が上がったからなのか | 全国のパン÷米（2015〜2025年、2026年1〜9月）／年報 第4-6表（平均）の購入数量で量と1kgあたりの値段に分ける（2019〜2025年）／52市のパン÷米の分布とパンが多い市の数（2015・2019・2023・2024・2025年）、市の順位の順位相関／年齢別のパン÷米 | `src/a231_bread_rice.py` |

## 主な結果
- 全国では、2015〜2024年はずっとパンの支出が米を上回っていた（パン÷米は1.26〜1.66）。2025年は米42,739円・パン34,244円で、比は0.80と逆転した
- 2025年の米の支出は2023年の2.1倍（+109.5%）。年報の購入数量で分けると、1kgあたりの値段が360円→697円（+94%）、買った量は56.6kg→61.3kg（+8%）。2019年（62.2kg）と比べると量は−1.4%で、逆転はほぼ値段の上昇によるもの
- パンは、買った量が2019→2025年に46.0kg→41.8kg（−9%）、1kgあたりの値段は699円→819円（+17%）
- 52市でパンが米より多かった市は、2015年48市、2019年49市、2023年52市、2024年46市、2025年8市。2025年もパンが多かったのは、さいたま・鳥取・岡山・山口・徳島・高松・松山・神戸の8市
- 市のパン÷米の順位は年をまたいでかなり保たれる（順位相関 2015→2019年0.67、2023→2025年0.69）。どの市でもほぼ同じように米の値段が上がり、比が全体として下にずれた形
- 世帯主の年齢別では、若い世帯ほどパンの割合が高い（2019年：29歳以下2.04、70歳以上1.12）。2025年は30代（1.03）を除くすべての年齢で米が上回った
- 2026年1〜9月は前年同期比で米−10.4%、パン+3.4%。比は0.97まで戻っている

## 頑健性
- 市の値は1年分で、1市あたりの集計世帯は約100と少ない。統計局のランキングと同じく2023〜2025年の3年平均で比べると、パンが米より多い市は52市中41市で、2025年1年だけの結果（8市）とは大きく違う。「2025年に逆転した」は単年の話として読む必要がある
- 米の1kgあたりの値段の上がり方（2023→2025年、+94%）は、CPI「米類」の上がり方（+114%）より小さい。家計が値段の安い米を選んだ分が含まれるため（推測）
- 52市のうち30市で、2023→2025年に米を買った量が増えた（中央値+2.6%）
- コードはきれいなフォルダで3回動かし直し、results の全ファイルが一致することを確かめた

## データ
- `data/kakei_annual.csv`・`kakei_monthly.csv`：米・パン・食パン・他のパンの支出（全国、年・月）
- `data/kakei_detail.csv`：年報 第4-6表（世帯主の年齢階級別、2019〜2025年）と第4-1表（都市別、2015・2019・2023・2024・2025年）の支出・購入数量・平均価格
- `data/cpi_annual.csv`：消費者物価指数（2020年基準）の米類・パンなど（このリポジトリの F209 から抜き出した）
- `src/kakei_parse.py`：年報の Excel（2019年以前の xls と2020年以降の xlsx）を長い形に直す

## 注意
- 家で食べるために買った米とパンで、外食・弁当・おにぎりなどの調理食品は含まない
- 二人以上の世帯の結果で、単身世帯は含まない
- 市ごとの違いは好みの違いを示すもので、良い・悪いの順位ではない。この README では市の順位は示していない
- 2025年の米の量の増加には、値上がりの前の買い置きなどが入っている可能性がある（推測）。家計調査からは理由は分からない
- 米の値段と量の関係は [F286](../F286_household_saving_items)（物価高で節約）でも一部扱った。この記事はパンとの比較に絞った
