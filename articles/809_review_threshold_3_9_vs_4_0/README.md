# 809 星3.9と4.0の境目で、選ばれ方はどれだけ変わるのか？（口コミと星の数）

口コミの星は、小数第1位までで表示されることが多く、店を探す人の中には「星4.0以上」で絞り込む人もいます。そうすると、星3.9と4.0の店では、本当の満足度がほとんど同じでも選ばれ方が大きく変わります。**ここでは、作成者が乱数で作った架空の店3,000軒（本当の満足度を作成者が置いたもの）と、店を10軒見比べて1軒を選ぶ架空の客2万組で、表示が3.9と4.0の店の選ばれ方の差と、本当の満足度の差、そして本当は同じ4.0の店がどれだけ3.9と表示されるかを数えました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A809 | 表示の星3.9と4.0の境目で、選ばれ方はどれだけ変わるか。その差は本当の満足度の差に見合うか。本当は4.0の店が3.9と表示されるのはどれくらいか | 架空の店3,000軒。本当の満足度は平均3.9・標準偏差0.35の正規分布（2.5〜4.8で切る）。口コミの件数は5〜500件（対数で一様）。1件の星は、平均が本当の満足度になる1〜5の分布から引く（801 と同じ作り方）。表示の星は見かけの平均を小数第1位で四捨五入（3.95→4.0）。客は店10軒を見比べて1軒を選ぶ（2万組）。選びやすさは exp(2.0×表示の星)（表示が0.1上がると約1.22倍）。客の30%は「表示4.0以上」に絞ってから選ぶ（4.0以上が1軒もなければ絞らない）。「選ばれやすさ」は、見比べられた回数あたりに選ばれた割合（1＝平均どおり）。本当4.0の店が3.9以下と表示される割合は、件数ごとに2万回作り直して数えた。絞り込む客の割合（0・15・30・50%）と、星への敏感さ（1.0・2.0・3.0）を変えた確かめも行った。seed 809 | `src/a809_threshold.py` |

## 主な結果

### 表示の星ごとの選ばれやすさと本当の満足度
| 表示の星 | 店の数 | 本当の満足度の平均 | 選ばれやすさ（1＝平均） |
|---|---|---|---|
| 3.7 | 252 | 3.713 | 0.404 |
| 3.8 | 309 | 3.815 | 0.486 |
| **3.9** | 278 | **3.882** | **0.580** |
| **4.0** | 305 | **3.963** | **1.146** |
| 4.1 | 273 | 4.074 | 1.354 |
| 4.2 | 209 | 4.145 | 1.605 |
| 4.3 | 194 | 4.221 | 1.886 |

- 表示3.9→4.0で、選ばれやすさは**1.98倍**になった。本当の満足度の差は**0.08**だけ
- ほかの0.1の差（3.7→3.8で1.20倍、4.2→4.3で1.18倍）に比べ、境目だけが大きく跳んだ
- 表示3.9の店と表示4.0の店を1軒ずつ選ぶと、3.9の店のほうが本当は良い確率は**29.9%**だった

### 本当の満足度4.0ちょうどの店が「3.9以下」と表示される割合（2万回）
| 口コミの件数 | 3.9以下と表示される割合 |
|---|---|
| 10件 | **41.5%** |
| 30件 | 36.2% |
| 100件 | 24.3% |
| 300件 | 13.2% |
| 1,000件 | 2.4% |

- 店3,000軒のうち、本当の満足度が3.95〜4.05の店309軒では、**30.7%が3.9以下と表示**された。3.9以下と表示された店の選ばれやすさは0.50、4.0以上と表示された店は1.31で、本当はほぼ同じ店どうしで**2.63倍**の差になった

```
pip install -r requirements.txt

```

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約4秒）
- 絞り込む客の割合と、星への敏感さを変えると（`results/sensitivity.csv`）

| 絞り込む客の割合 | 3.9→4.0の倍率（敏感さ2.0） | 4.2→4.3の倍率（敏感さ2.0） |
|---|---|---|
| 0% | 1.20 | 1.19 |
| 15% | 1.52 | 1.18 |
| 30%（基本） | 1.98 | 1.18 |
| 50% | 2.99 | 1.17 |

- 絞り込む客がいなければ、境目の跳びは消えた（3.9→4.0も4.2→4.3もほぼ同じ1.2倍）。跳びの大きさは、絞り込む客の割合でほぼ決まる。星への敏感さを1.0〜3.0に変えても、絞り込む客30%なら1.92〜2.09倍だった

## 注意（言えないこと）
- 架空のデータです。客の選び方（星への敏感さ、4.0以上に絞り込む客の割合）は作成者が置いたもので、「約2倍」という跳びの大きさはこれで決まります。実際にどれだけの人が4.0で絞り込むかは調べていません
- 確かめで動かしても変わらないのは、「本当はほとんど同じ店が、表示の四捨五入と件数の少なさで3.9と4.0に分かれる」というところです
- 選ばれた店に口コミが増え、表示が動いていくこと（積み重なり）は入れていません。1回きりの選び方です
- 実際の口コミサイトの表示の仕方や並べ方を表すものではありません
- 件数が少ない店の星の振れそのものは、関連する記事 801 で扱っています
- 「4.5以上」で絞り込んだときに良い店がどれだけ外れるかは、関連する記事 812 で扱っています。812 は絞り込みの当たり外れ、この記事は表示の四捨五入と境目での選ばれ方の跳びを見ています
- 本当の満足度がほぼ4.0の店の30.7%が3.9以下と表示されるのは、件数を5〜500件と置いたからです。件数の多い店が多ければ、この割合は下がります（件数ごとの割合は上の表）
