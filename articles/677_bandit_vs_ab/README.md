# 677 多腕バンディットと固定の A/B テストでは、失う申込みの数と、正しい案を選ぶ割合はどう違うのか（手法の解説・正解の分かるデータで試す）

固定の A/B テストは、決めた人数まで案を均等に出し、終わってから良い案に切り替えます。多腕バンディットは、来訪者が来るたびに、それまでの結果を見て良さそうな案に多く出します。その分、テスト中に悪い案に出して失う申込みは減りますが、最後に正しい案を選べるかは別の話です。**ここでは、どの案がいちばん良いかが分かる架空の申込みページで、案の数と差を変え、A/B・トンプソン抽出・ε-greedy の3つを比べました（各設定400回）。** 数字は置いた申込み率で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A677 | 失う申込みと、正しく選ぶ割合はどう違うか | 来訪は合計2万人（100人ずつ200回）。基準の申込み率 5%。2案：[5%, 5%×(1+伸び)]、4案：[5%, 5%, 5%×(1+伸び/2), 5%×(1+伸び)]、伸びは 5%・10%・20%。A/B：最初の1万人を均等、残り1万人は申込み率が最高だった案。トンプソン抽出：Beta(1,1) の事後から来訪者ごとに引く（100人ごとに更新）。ε-greedy：10%は均等、90%はその時点の最高の案。失った申込み＝全員に最良の案を出した場合との差（期待値）。各400回、seed 677 | `src/a677_bandit.py` |

## 主な結果（失った申込みは2万人あたりの件数、400回の平均）

| 設定 | 失った申込み A/B・トンプソン・ε-greedy | 正しく選んだ割合 A/B・トンプソン・ε-greedy |
|---|---|---|
| 2案・+5% | 20・19・20 | 70%・74%・67% |
| 2案・+10% | 34・24・29 | 83%・93%・83% |
| 2案・+20% | 51・25・29 | 99%・99%・98% |
| 4案・+5% | 28・27・26 | 40%・46%・39% |
| 4案・+10% | 49・46・43 | 49%・62%・52% |
| 4案・+20% | 79・58・57 | 74%・90%・71% |

- **差が大きいほど、バンディットの方が失う申込みは少ない**。2案・+20%では A/B の半分（51件に対し25件）
- **正しく選ぶ割合は、トンプソン抽出がどの設定でも最も高かった**。ε-greedy は失う申込みは少なめでも、正しく選ぶ割合は A/B と同じくらい
- ε-greedy は、早いうちに悪い案に寄ると戻りにくく、失う申込みの上位10%の回は大きい（2案・+10%で91件。トンプソン抽出51件、A/B 75件）
- 差が +5%で2万人では、どの方法も正しい案を選べない回が多い（2案で67〜74%、4案で39〜46%）

## 注意（言えないこと）
- 架空のデータ。申込み率・伸び・人数は作成者が置いたもので、結果はこれで決まる
- 申込み率は期間中に変わらないと置いた。曜日や季節で変わる場合、バンディットは前半の結果に引きずられることがある（扱っていない）
- バンディットは案ごとの人数が偏るので、「伸びが何%か」をあとで推定すると、ばらつきが大きく、偏りも出やすい（扱っていない）
- A/B の人数（前半1万人）・ε=0.1・更新の間隔は作成者が決めた1通りだけ
- どの方法を使うべきかの助言ではない
