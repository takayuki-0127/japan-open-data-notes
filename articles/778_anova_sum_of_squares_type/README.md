# 778 件数のそろわない2元配置で、平方和の型（I・II・III）を変えると、有意の見え方はどれだけ変わるのか（手法の解説・正解の分かるデータで試す）

2つの要因（ここでは売り場の配置 A と時間帯 B）の効きを分散分析で見るとき、組ごとの件数がそろっていないと、「A の効き」をどう測るか（平方和の型）で答えが変わります。Type I は式に書いた順に効きを割り当てるので、先に書いた要因が、件数の偏りを通じてもう一方の効きを取ることがあります。Type II は相手の要因をそろえたうえで、Type III はさらに交互作用もそろえたうえで測ります。**ここでは、本当の効きが分かる架空のデータで、件数を偏らせた2×3の配置を作り、A が有意になる割合を型ごとに比べました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A778 | 平方和の型で、A の有意の見え方はどれだけ変わるか | A（2通り）×B（3通り）、件数 A1：10・30・80、A2：80・30・10（計240件）。B の効き 0・0.5・1.0。場面1：A は効かない、交互作用なし。場面2：A2 で+0.3、A2×B3 で+0.6。statsmodels の anova_lm（Type I は A を先・B を先、Type II、Type III は和が0の対比）。各300回。seed 778 | `src/a778_ss_type.py` |

## 主な結果

| A が有意（5%）になった割合 | Type I（A を先） | Type I（B を先） | Type II | Type III |
|---|---|---|---|---|
| 場面1（A は効かない） | **100%** | 5% | 5% | 5% |
| 場面2（A も効き、交互作用あり） | **41%** | 78% | 78% | 82% |

- 場面1では、A は効かないのに、Type I で A を先に書くと300回すべてで A が有意になった。A＝1 は効きの大きい B＝3 に件数が偏っているので、B の効きを A が取ったため
- B を先に書いた Type I と、Type II・Type III は5%前後で、決めた水準どおりだった
- 場面2では、Type I（A を先）は41%、ほかは78〜82%だった。A の効きと件数の偏りによる見かけの差が打ち消し合ったため
- Type II と Type III の違いは、交互作用のある場面2で4ポイントだった

## 注意（言えないこと）
- 架空のデータです。件数の偏りと効きの大きさは作成者が置いたもので、割合はこれで決まります
- 交互作用があるときに「A の効き」を1つの数で言うこと自体が難しく、どの型が正しいとは一つに決まりません。ここでは型によって答えが変わることだけを示しています
