# 267 相関を因果だと思いかけたとき、どう止めたか（④ 振り返り R006）

このシリーズで「一緒に動いている」を「動かした」と読みかけたとき、何をして止めたかを、記事ごとの README から数えたフォルダです。結論が動いたときの見落としを数えた [251](https://github.com/takayuki-0127/japan-open-data-notes/tree/main/articles/251_conclusion_reversals)、「言えないこと」の書き方を数えた [242](https://github.com/takayuki-0127/japan-open-data-notes/tree/main/articles/242_limits_section_writing) とは別に、「条件をそろえる前と後」と「因果の注意の中身」に絞りました。

## 問い

- 条件をそろえる前と後で、答えはどう変わったか
- 「言えないこと・注意」に因果の注意を書いた記事はどれだけあり、何を書いていたか
- 相関で止まらないために、どんな確かめ方を使ったか

## 手法

| 手順 | 中身 |
|---|---|
| README の重複を除く | 初期の記事（008〜019、021〜033 など）は複数の記事で同じ README を共有している。40字以上の行の8割以上が先に残した README と同じなら1本に数えた（528 → 463本） |
| そろえる前と後 | 題名に「そろえる」「除くと」とある記事などから、前と後の数字が README にある10本を手で写した（`data/cases.csv`） |
| 因果の注意 | 「言えないこと・注意・限界」の節で「因果」を含む行を拾い、中身を5種類の言葉で分けた。乱数（seed 7）で12行を選んで目で確かめ、12行とも因果の注意だった（`data/precision_check.csv`） |
| 確かめ方 | README の本文から、6種類の確かめ方の言葉を拾った |

## 主な結果

- そろえる前と後の10本（図1）：関係が消えた4（008・009・013・022）、向きが逆1（229）、縮んだが残った3（177・F62・F278）、残った1（F274）、大きくなった1（037）
- 「言えないこと・注意」に「因果」と書いた記事は463本中60本（13.0%）。グループ別では精選25%、F100〜F199 20%、F200〜F255 19%、000〜099 15%、F01〜F99 14%、1000本計画 3%、100〜226 2%（図2、`results/limits_causal_by_group.csv`）
- 因果の注意の中身（記事数、1本に複数つく）：ほかの理由で同時に動いた可能性13、集計・記述にとどまる9、手法の前提に頼る6、予測・重要度は因果ではない5、地域の関係を個人に当てはめない2。どれにも当たらない（「因果ではない」と書くだけ）31
- 確かめ方を書いた記事（図3）：1つの地域・年を外す162、固定効果54、比べる相手を置く32、年齢・物価で調整25、プラセボ21、条件を段階的にそろえる10。どれか1つ以上は215本

## 言えないこと

- 10本は、前と後の数字がはっきり書いてある記事から選んだもので、全体の割合ではない
- 言葉で拾ったので、取りこぼしと数え過ぎがある。特に「除くと」は因果の確かめ以外でも使うので、162本は多めに出ている
- そろえても残った関係が因果だとは言えない
