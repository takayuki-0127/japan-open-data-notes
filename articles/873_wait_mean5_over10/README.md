# 873 平均の待ち時間が5分でも、10分以上待つ人は何%いるのか？（待ち時間と混雑）

「平均の待ち時間は5分です」と言われると、多くの人が5分前後待つように聞こえます。けれども、待ち時間は「待たずに済む人」と「長く待つ人」に分かれやすく、平均はその間の数にすぎません。**ここでは、作成者が乱数で作った架空の店のレジ（客の来方・1人の処理時間・レジの数を作成者が置いたもの）で、全員の待ち時間の平均がちょうど5分になるように客の数を合わせ、10分以上待つ人の割合・待たずに済む人の割合・真ん中の人（中央値）の待ち時間を、8通りの置き方で数えました。**

利用率（レジが人を処理している時間の割合）と待ち時間の関係は関連する記事 874、店の混み具合と「混んでいる」と感じる人の割合は 875、平均・最長・10分以上の割合のどの指標が日ごとの満足に近いかは 884 で扱っています。この記事は「平均が同じ5分のとき、長く待つ人がどれだけいるか」に絞ります。

## 主な結果

### 基本の置き方（レジ1台・処理2分、400日・87,698人）
| | 値 |
|---|---|
| 全員の平均の待ち時間 | 5.0分 |
| 待たずに済んだ人 | **27.9%** |
| 真ん中の人（中央値）の待ち時間 | **2.56分** |
| 10分以上待った人 | **17.1%** |
| 20分以上待った人 | 4.0% |
| 上から10%目の人（90%点）の待ち時間 | 13.69分 |
| 待った人だけの平均 | 6.94分 |
| 利用率（レジが処理している時間の割合） | 73.1% |

- 平均が5分でも、真ん中の人は2.56分しか待たず、10分以上待った人が17.1%（約6人に1人）いた。平均は、少数の長い待ちに引っぱられて真ん中より上に出た
- 日ごとに見ると、10分以上待った人の割合は、少ない日（下から10%目）で4.3%、多い日（上から10%目）で32.2%と大きく振れた
- この値は、ずっと開いている店の待ち行列の式（レジ1台・処理時間が指数分布：10分以上待つ割合＝ρ×exp(−ρ×10÷5)、ρは利用率）の17.1%と一致した。基本の置き方では、結果は式どおりの値

### 置き方を変えると（どれも全員の平均の待ちは5.0分に合わせた）
| 置き方 | 利用率 | 待ちなし | 中央値 | 10分以上 | 20分以上 | 待った人だけの平均 |
|---|---|---|---|---|---|---|
| 基本（レジ1台・処理2分・多さ一定） | 73.1% | 27.9% | 2.56分 | **17.1%** | 4.0% | 6.94分 |
| 処理1分 | 83.6% | 17.2% | 2.92分 | 15.3% | 3.4% | 6.04分 |
| 処理4分 | 56.3% | 44.4% | 0.96分 | 18.3% | 5.9% | 9.00分 |
| 処理時間が毎回同じ | 84.2% | 16.9% | 3.23分 | 14.7% | 2.7% | 6.02分 |
| 処理時間のばらつき大 | 53.6% | 47.3% | 0.21分 | 14.8% | 7.1% | 9.49分 |
| レジ3台（1つの列） | 90.7% | 19.1% | 3.07分 | 16.5% | 2.9% | 6.18分 |
| 昼と夕方に山 | 66.4% | 31.9% | 2.12分 | 17.2% | 5.0% | 7.35分 |
| 昼と夕方に強い山 | 59.1% | 35.9% | 1.70分 | 17.6% | 5.7% | 7.80分 |

- **10分以上待つ人の割合は、8通りすべてで14.7〜18.3%に収まった**。一方、待たずに済む人は16.9〜47.3%、中央値は0.21〜3.23分と大きく動いた
- 「平均の2倍（10分）以上」の割合が動きにくいのは、待った人の待ち時間が指数分布に近い形になるためと考えられる（推測）。式（ρ×exp(−2ρ)）では、利用率が56〜83%と大きく違っても、10分以上は18.3〜15.7%とほぼ同じになる
- 「平均の4倍（20分）以上」は2.7〜7.1%と、置き方で2倍以上動いた。処理時間のばらつきが大きい店では、待たずに済む人が半分近くいる一方、長く待つ人も多かった

### 時間帯の山がある店（昼と夕方に山）
- 1日の平均は5分でも、いちばん混む時間帯（13時台）の平均は9.26分、10分以上待った人は35.6%だった。いちばん空いている時間帯（10時台）の平均は2.02分
- 10分以上待った人のうち60.1%は、平均の待ちが長い上位3つの時間帯（13時台・18時台・12時台）に来た人だった

- 処理時間の平均・形、レジの数、時間帯の山を変えた8通りで、10分以上の割合は14.7〜18.3%だった。「平均の2倍以上は約6人に1人」は、この範囲の置き方では保たれた

## 注意（言えないこと）
- 架空のデータです。客の来方（でたらめな間隔）、処理時間の分布、レジの数、時間帯の山は作成者が置いたもので、結果はこれで決まります。実際の店の待ち時間を表すものではありません
- 客は来たら必ず並び、途中で列を離れないと置きました。長い列を見て並ばずに帰る人、途中で離れる人がいると、長い待ちの割合は小さく出ます（推測）
- 客が予約の時刻どおりに来る、まとめて来る（団体）といった来方は入れていません。来方がでたらめでないと、10分以上の割合は変わる可能性があります（推測）
- 「平均の2倍以上は約6人に1人」は、平均5分・この置き方の範囲での結果です。平均の4倍以上の割合のように、もっと長い待ちの割合は置き方で大きく動きました
- 待ち時間は列に並んでからレジが始まるまでで、レジにかかる時間は含めていません
