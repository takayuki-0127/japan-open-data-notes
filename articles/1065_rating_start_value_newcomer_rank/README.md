# 1065 初めの点数をいくつにするかで、新しく入った人の順位はどれだけずれるのか？（対戦とレーティング）

対戦ゲームの点数の付け方では、新しく入った人にまず「初めの点数」を与え、試合のたびに勝ち負けで点を動かします。初めの点数は、本当の強さが分からないうちの仮の値です。これをリーグの平均にするか、低めにするか、高めにするかで、入ったばかりの人の順位は上にも下にもずれます。また、点の付け方は勝った人が足した分だけ負けた人が引かれるので、新しい人の初めの点数が高すぎると、その分の点がすでにいる人に流れます。**ここでは、作成者が乱数で作った架空の対戦ゲームのリーグ（すでに300試合した1,000人に、200人が新しく入る。本当の強さを作成者が置いたもの）で、新しい人の初めの点数を1000・1200・1300・1400・1500・1800の6通りにして、入ってから何試合で順位のずれが小さくなるか、すでにいる人の点数がどれだけ動くかを数えました。置き方を変えた27通りでも確かめました。**

同じ企画の関連する記事 1066 は、1試合で動かす点の幅を変えたときの近づく早さとぶれを扱います。1067 は、対戦の多い人とたまにしか対戦しない人の点数の読み方を扱います。件数の少ない店の星を全体の平均に寄せて読む考え方は 801、少ない打席の「最高打率」は 833 で扱っています。この記事は、新しく入った人の初めの点数の置き方に絞ります。

## 主な結果

### 新しい人の順位のずれ（基本、100回の平均、`results/by_start_and_games.csv`）
| 初めの点数 | 入ってすぐ（0試合） | 10試合後 | 30試合後 | 100試合後 |
|---|---|---|---|---|
| 1000 | 379.93位 | 331.78位 | 215.46位 | 69.74位 |
| 1200 | 339.42位 | 250.79位 | 142.86位 | 69.42位 |
| 1300 | 303.08位 | 205.65位 | 120.03位 | 69.69位 |
| 1400（新しい人の本当の平均） | 284.5位 | **183.71位** | 111.27位 | 70.08位 |
| 1500（すでにいる人の平均） | 315.49位 | **201.1位** | 117.31位 | 70.58位 |
| 1800 | 570.03位 | **439.6位** | 218.16位 | 72.78位 |
| （参考）すでにいる人のずれ（初め1500のとき） | 88.12位 | 79.63位 | 73.48位 | 70.14位 |

- 10試合後のずれは、初めの点数を新しい人の本当の平均（1400）にしたときがいちばん小さく183.71位、すでにいる人の平均（1500）では201.1位（1.095倍）だった。新しい人の本当の平均に合わせるのがいちばんよいのは、この置き方からの作りどおりの向き
- 初めの点数を1500から1400に変えても、10試合後のずれは小さくなるが大きくは変わらない。**ずれの多くは、初めの点数ではなく試合の少なさから来ていた**。初め1400でも、10試合後のずれは、そのときのすでにいる人のずれ（76.45位）の2.403倍だった
- 初めの点数が本当から大きく離れると（1000・1800）、ずれは大きく、残る試合も長かった
- 新しい人のずれが、すでにいる人のずれの1.1倍以下になったのは、初め1300・1400・1500で70試合後、1200で80試合後、1000・1800で90試合後だった（数えたのは0・1・2・3・5・7・10・15・20・25・30・40・50・60・70・80・90・100試合目。1.1倍は作成者の置いた物差し）
- 100試合後には、どの初めの点数でもずれは69.42〜72.78位とほぼそろった

### 10試合後、新しい人が本当より何位上に見えるか（基本）
| 初めの点数 | 本当より上に見える順位（平均） | 点数−本当の強さ（平均） |
|---|---|---|
| 1000 | −327.12位 | −323.57 |
| 1200 | −224位 | −154.85 |
| 1300 | −137.15位 | −75.65 |
| 1400 | −30.78位 | 0.98 |
| 1500 | **＋88.14位** | 76.16 |
| 1800 | **＋435.07位** | 305.82 |

- すでにいる人の平均（1500）から始めると、新しい人は10試合後も本当より平均88.14位上に見えた。新しい人のほうが弱いと置いたため
- 初め1800では、10試合後の点数の上位100人のうち15.3%が新しい人だった（本当の強さの上位100人では7.12%）

### すでにいる人の点数が動く（基本、100試合後）
| 初めの点数 | すでにいる人の点数の動き（平均） | 式：200×（初めの点数−新しい人の点数の平均）÷1,000 |
|---|---|---|
| 1000 | −62.92 | −62.92 |
| 1400 | −0.62 | −0.62 |
| 1500 | ＋15.3 | ＋15.301 |
| 1800 | **＋63.18** | ＋63.179 |

- 点の付け方は、勝った人が足した分だけ負けた人が引かれるので、リーグ全体の点数の合計は動かない。新しい人が初めの点数より下がった分は、すでにいる人に流れる。動きは式どおり（すべての通りで一致。`results/a1065_main.json` の `conservation_check`）
- 初め1800では、100試合後にすでにいる人の点数が平均63.18上がった。強さは変わっていないのに、点数だけが上がって見える

### 置き方を変えると（27通り、`results/grid.csv`）
- 10試合後のずれがいちばん小さい初めの点数は、27通り中26通りで新しい人の本当の平均と同じだった（作りどおり）。残る1通り（本当の平均1300・幅48・散らばり300）では1400だった
- 新しい人の本当の平均が1500でない18通りでは、初め1500のずれは、本当の平均に合わせたときの1.035〜2.301倍だった。本当の平均が1400の9通りでは1.035〜1.313倍、1300の9通りでは1.126〜2.301倍で、新しい人の散らばりが小さいほど差が開いた
- 10試合後のずれは、初め1500で152.97〜280.21位、本当の平均に合わせても115.2〜258.11位だった。本当の平均に合わせても、10試合後のずれは27通りすべてで、すでにいる人のずれの1.411〜3.744倍残った
- 100試合後のずれは、初めの点数6通り×27通りで51.3〜163.67位だった。大きいのは幅16で初めが1000か1800の通り（最大163.67位）で、幅32・48では最大113.46位だった

```
pip install -r requirements.txt

```
30秒〜1分ほどで終わります。`data/league_one_run.csv` もこのとき作ります。

- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約44秒。ほかの作業と同時に動かしたときの値）
- 図3枚を開き、日本語・重なり・軸を確かめた（棒グラフの軸は0から）
- すでにいる人の点数の動きが、点数の合計が動かないことからの式（200×（初めの点数−新しい人の点数の平均）÷1,000）と、6通りすべてで一致することを確かめた

- `data/league_one_run.csv`：1回目のリーグの1,200人（player・group（existing＝すでにいる人、new＝新しい人）・true_strength（本当の強さ）・rating_after100_start1000〜1800（新しい人が入って100試合後の点数、初めの点数ごと））

## 注意（言えないこと）
- 架空のデータです。本当の強さの分布、新しい人が少し弱いこと、勝つ見込みの式、幅K、全員がでたらめな相手と同じ数だけ対戦することは作成者が置いたもので、結果はこれで決まります。実在のゲームや大会の点数の付け方を表すものではありません
- 新しい人の本当の強さは、入ってから変わらないと置きました。実際には、入ったばかりの人は試合をするうちに強くなることが多く、そのときは初めの点数の影響の見え方が変わります（推測）
- 新しい人の最初の何試合かだけ点の幅を大きくする方法や、試合数の少ない人の順位を表に出さない方法は扱っていません
- 新しい人の本当の平均に合わせるのがいちばんよいのは作りどおりで、実際には新しい人の本当の平均は分かりません。どの初めの点数にするべきかの助言ではありません
