# 957 単語の数え方（区切り方）で、多い言葉の順位は変わるのか？（文章の数字）

日本語の文章は単語の間に空白がないので、「多い言葉」を数えるには、まずどこで区切るかを決める必要があります。「配送料」を1語とするか「配送」と「料」に分けるかで、「配送」の回数は変わります。**ここでは、作成者が乱数で語を組み合わせて作った架空の通販への問い合わせ文2,000件（話題ごとの本当の割合を作成者が置いたもの）を、作成者が決めた4つの簡単な区切り方で数え、多い言葉の上位10語がどれだけ入れかわるかを数えました。入れかわりの大きさは、同じ区切り方のまま文章を取り直したときの入れかわりと比べました。**

文章はすべて作成者が決まり文句と語を乱数で組み合わせて作ったもので、実在の問い合わせ・口コミ・SNS の文は使っていません。外部の辞書や単語を区切る道具も使わず、区切り方は下の表の決まりだけで行いました。

| A957 | 区切り方を変えると、多い言葉の上位10語はどれだけ入れかわるか。その入れかわりは、文章を取り直したときより大きいか | 架空の雑貨の通販「A商店」への問い合わせ文。1件ごとに話題を1つ（80%）か2つ（20%）選ぶ。話題の重み：届かない22%・返品16%・配送料12%・ポイント12%・支払い12%・在庫12%・ギフト8%・会員登録6%（2つ目は重みどおりに重ならずに選ぶ）。話題ごとに2〜3の文の型を持ち、1つの話題で1文（60%）か2文（40%）を書く。品物の名前（8つ）は乱数で入れる。「配送料／配送の料金」のような書き方は、複合語で書く確率 q=0.5 で選ぶ。始めのあいさつ（「お世話になります。」など3つ）を50%、結び（2つ）を40%の件に付ける。区切り方は4つ（下の「区切り方の決まり」）。数えるのは語の延べ回数で、同じ回数の語は文字コードの順に並べた。文章を作り直して200回（2,000件ずつ）、続けて作った2回の組（199組）で同じ区切り方どうしの重なりも数えた。確かめとして、q を0.2・0.5・0.8、件数を200・2,000件に変えて各100回。seed 957 | `src/a957_word_split_rank.py` |

### 区切り方の決まり（作成者が決めたもの）
| 名前 | 決まり |
|---|---|
| 長い単位 | 作成者の語のリスト（「配送料」「ポイントカード」「会員登録」など複合語12語を含む）を使い、文の左から、リストにある語のうち一番長いものを取る。リストの助詞・語尾（「が」「です」「ください」など）と、リストにない文字は数えない |
| 短い単位 | 同じ決まりで、リストから複合語12語を除く。「配送料」は「配送」と「料」、「ポイントカード」は「ポイント」と「カード」に分かれる |
| 文字種 | 漢字が続く部分、カタカナが続く部分をそれぞれ1語とし、ひらがな・記号は数えない。「願い」は「願」、「届きません」は「届」になる |
| 2文字ずつ | 文字種と同じ部分を、1文字ずつずらして2文字ずつ切る（1文字だけの部分はそのまま1語）。「ポイントカード」は「ポイ」「イン」「ント」「トカ」「カー」「ード」になる |

| 2 | 願い 570 | **配送 843** | 願 570 | 配送 843 |

| 4 | 待ち 412 | 知り 538 | 待 412 | 知 538 |

| 6 | 配送 412 | **日 430** | 配送 412 | トカ 487 |
| 7 | 在庫 393 | **ポイント 428** | 在庫 393 | ード 487 |

- 「配送料」「配送日」「配送状況」を分けると、「配送」は412回から843回に増えて6位から2位に上がった。長い単位では1回も出てこない「カード」が、短い単位では5位（487回）に入った。どちらも、複合語を作成者がそう置いたことからくる式どおりの足し算
- 1位はどの区切り方でも「注文」だった。「注文」は始めのあいさつ（「初めて注文しました。」など）と「届かない」の文の両方に出る語で、1つの話題を表す語ではない。いちばん多い話題「届かない」（483件）を表す「届き」は、長い単位で200回の中央値10位、短い単位で13位だった
- 2文字ずつでは、「トカ」「イン」のような語でない切れ端が上位に入った
- 文字種の上位10語は、長い単位と回数がほぼ同じで、「願い」が「願」になるような書き方の違いが大半だった。重なりは文字列が同じかで数えたので、文字種の重なりが少ないのはこの書き方の違いによるところが大きい

- 2,000件では、区切り方を変えたときの重なり（2.92〜7.22語）は、同じ区切り方で文章を取り直したときの重なり（8.49〜9.51語）より少なかった。複合語を1語とするか分けるかだけでも、重なりは7.22語だった
- 1位の語は、長い単位と文字種では200回すべて「注文」、短い単位と2文字ずつでは「注文」69.5%・「配送」30.5%だった
- 語の順位（200回の中央値）：「配送」は長い単位で4位、短い単位で2位。「ポイント」は16位と8位。「日」は13位と6位

- 複合語で書く人が多いほど（q が大きいほど）、長い単位と短い単位の差は大きくなり、2,000件で重なりは8.33語から5.32語に減った。区切り方の差がどれだけ効くかは、文章に複合語がどれだけ出るかの置き方で決まる
- 200件では、同じ区切り方で文章を取り直すだけでも重なりは7.64〜7.77語にとどまり、q=0.2・0.5では区切り方の差（8.26語・7.78語）と同じくらいかそれより大きかった。件数が少ないと、区切り方の差と取り直しの揺れを見分けにくい

## 注意（言えないこと）
- 架空のデータです。文の型、語のリスト、複合語で書く割合は作成者が置いたもので、結果はこれで決まります。「配送」「カード」の順位が上がるのは、作成者がそれらを含む複合語を置いたことからくる足し算です。長い単位と短い単位の重なりは、複合語で書く割合の置き方で5.32〜8.33語（2,000件）と動きました
- 4つの区切り方は、作成者が決めた簡単な決まりです。実際に使われている単語の区切りの道具や辞書の結果を表すものではありません。語のリストにない語は、長い単位と短い単位では数えていません
- 重なりは、上位10語の文字列が同じかで数えました。「願い」と「願」のように同じ語の書き方が違うだけのものも、違う語として数えています
- 数えたのは延べ回数です。1件の中に同じ語が何回出るかの扱い（長い文章ほど多く出る）は 959「文章が長い人ほど、同じ言葉が多く出るのはなぜか？」で扱っています
- どの区切り方が正しいかは言えません。何を数えたいか（話題か、語の書き方か）で選ぶもので、この記事が示せるのは、区切り方で順位が動くことと、その大きさの目安だけです

関連する記事：958「ワードクラウドの大きい文字は、本当に多い意見なのか？」は、同じ意見の言い方が分かれると語の回数が意見の多さを表さなくなることを扱っています。この記事で「届き」がいちばん多い話題なのに上位10語に入りにくかったのも、同じ仕組みです。871「自由記述の多い意見は、全体の多い意見なのか？」は、意見ごとの書きやすさの違いで件数の順が本当の順からずれることを扱っています。同じ企画の966「表記ゆれ（全角・半角・言い換え）をそろえると、数はどれだけ動くのか？」は、区切り方を決めたうえで、同じ用件の書き方（全角・半角・かな・言い換え）をどこまでそろえるかを扱っています。968「文字数の数え方（文字・バイト・単語）で、何が変わるのか？」は、語ではなく1つの文の長さの数え方を扱っています。
