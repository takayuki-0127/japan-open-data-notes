# 824 「前年比」の棒と「実数」の線を並べると、何を読み違えるのか？（グラフ）

月の報告の資料では、前年同月比（去年の同じ月と比べて何%増えたか）を棒で、売上そのものを線で、1枚の図に並べることがよくあります。棒と線は別のものを表しているのに、同じ図の中で上下すると、つい同じ意味で読んでしまいます。**ここでは、作成者が乱数で作った架空の会社2,000社の月の売上（本当の伸びを作成者が置き、季節の波と月ごとのばらつきを足したもの）で、前年同月比の棒と売上の線が、本当の伸びとどれだけ食い違って見えるかを数えました。**

2本の縦軸の目盛りの取り方（814）、期間の切り出し方（817）は別の記事で扱っています。この記事は「前年比の棒」と「実数の線」の読み違えに絞ります。

## 主な結果

### 本当の伸びが毎月+5%のとき（2,000社×36本）
| | 値 |
|---|---|
| 前年同月比の棒の平均 | 5.41% |
| 棒の10〜90%の範囲 | −3.98%〜15.15% |
| 棒がマイナス（前年割れ）だった月 | **24%** |
| 棒が前の月の棒より低かった月 | 50% |
| 1年（12本）の中に、3か月続けて棒が下がる並びがあった割合 | 29% |
| 前の年の同じ月の棒との相関 | **−0.50** |
| 前の年に棒が下位4分の1だった月のうち、翌年の棒が真ん中より上だった割合 | 76% |
| 線（売上）が前の月より下がった月の割合 | 48% |
| 線が前の月より下がった月のうち、棒はプラスだった割合 | 66% |

- 本当の伸びは毎月+5%で変わらないのに、4本に1本は前年割れの棒になった
- 棒どうしの上下は、本当の伸びの変化を表していない。棒が3か月続けて下がる並びは、1年のうち29%であった
- 前の年に低かった月は、翌年に高く出た（相関−0.50）。去年の同じ月がたまたま低いと、今年の棒は「回復」したように見える（前年の反動）
- 線が前の月より下がっていても、その3分の2では棒はプラスだった

### 本当の伸びが+10%から0%へ鈍るとき（2,000社）
| | 値 |
|---|---|
| 本当の前年同月比（13か月目→48か月目） | 9.0%→1.18% |
| 36本の棒が右下がりだった会社 | 98% |
| 最後の12か月の売上が、その前の12か月より多かった会社 | 87% |
| 棒は右下がりで、売上は増えていた会社 | **85%** |
| 最後の12か月の棒のうち、マイナスだった棒 | 37%（本当の前年同月比では0%） |

- 本当の売上は最後まで増え続けているのに、最後の1年の棒の37%は前年割れだった。棒が右下がりで、売上は増えていた会社が85%あった
- 図1の会社（1850社目、棒の下がり方が上から1割の位置の会社をはっきりした例として選んだ）では、棒は1年に約4.1ポイントずつ下がり、最後の12か月の売上はその前の12か月より1.2%多かった。2,000社の棒の下がり方の中央値は1年に2.7ポイント

### 確かめ：置き方を変えても（各2,000社）
| 置き方 | 棒がマイナスの月 | 3か月続けて下がる年 | 前年の同じ月との相関 | 線が下がった月のうち棒がプラス |
|---|---|---|---|---|
| 基本（伸び5%・ばらつき5%・自己相関0・季節15%） | 24% | 29% | −0.50 | 66% |
| ばらつき2% | 4% | 30% | −0.50 | 95% |
| ばらつき10% | 36% | 29% | −0.49 | 49% |
| 自己相関0.5 | 24% | 44% | −0.50 | 71% |
| 自己相関0.9 | 20% | 54% | −0.36 | 79% |
| 季節の波0% | 24% | 28% | −0.50 | 62% |
| 季節の波30% | 24% | 29% | −0.50 | 71% |
| 本当の伸び0% | 50% | 30% | −0.50 | 38% |
| 本当の伸び10% | 8% | 30% | −0.51 | 87% |

- 前年割れの棒の割合は、ばらつきと本当の伸びの置き方で4〜50%と大きく動いた。主な結果の24%は、ばらつき5%・伸び5%での数字
- 前の年の同じ月との相関は、月ごとのばらつきが前の月とつながっていなければ（自己相関0〜0.5）約−0.5でほとんど動かなかった。自己相関0.9では−0.36に弱まった
- 3か月続けて棒が下がる年は、自己相関0では約3割だったが、ばらつきが前の月とつながるほど増えた（0.9で54%）
- 季節の波の大きさは、どの数字もほとんど動かさなかった。前年同月比は同じ月どうしを比べるので、季節の波は打ち消される

- ばらつきのない本当の売上で前年同月比を計算すると、伸びの鈍化の例で最後の12か月の前年割れが0%になることを確かめた（数え方の点検）

## データ

- `results/a824_main.json`：主な結果すべて（伸びの鈍化の例と図1の会社の値を含む）
- `results/sensitivity.csv`：置き方を変えた確かめ

## 注意（言えないこと）
- 架空のデータです。本当の伸び、季節の波、月ごとのばらつきの大きさと自己相関は作成者が置いたもので、結果はこれで決まります。とくに前年割れの棒の割合は、置き方で4〜50%動きました
- 「前の年の同じ月との相関−0.50」は、月ごとのばらつきが互いにつながっていないと置いたことから出る値です。実際の売上でつながり方が違えば、反動の大きさも変わります
- 前年同月比の棒の平均（5.41%）が本当の伸び（5.13%）より少し大きいのは、比の平均をとると上に偏るためです
- 人が図をどう読むかは実験していません。数えたのは、棒と線の動きが本当の伸びとどれだけ食い違うかという図の形の性質です
- 実在の会社の売上を表すものではありません。売上の見通しや目標の立て方の助言ではありません
