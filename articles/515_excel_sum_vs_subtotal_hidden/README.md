# 515 Excel の SUM でフィルタで隠した行も含めて合計すると、表の合計は何%多くなるのか？（SUM・SUBTOTAL・AGGREGATE）（実務の型）

Excel の SUM・SUBTOTAL(9)・SUBTOTAL(109)・AGGREGATE(9, 1/3/7) が「フィルタで隠した行」「手で非表示にした行」「途中の小計の行」「エラーの値」をどう扱うかを、Microsoft のヘルプの説明どおり Python で再現し、架空の売上明細の表で「見えている明細の合計」と比べたフォルダです。**Excel 本体では動かしていません（未検証）。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A515 | フィルタや手で行を隠したとき、どの関数の合計が見えている明細の合計とずれるか。どれだけ多くなるか | 8地域×25行の架空の売上明細を作り、残す地域の数（1〜8）・手で隠す行の割合（0〜20%）・地域ごとの小計行・エラーの値（#N/A）を変えて、各関数の扱いを再現した合計を比べる。1,000枚のランダムな表でも数える。DuckDB の `FILTER` 句で同じ合計を出して一致を確認 | `src/a515_sum_subtotal.py`、`src/02_sum_duckdb.sql`、`src/01_sum_tsql.sql`（T-SQL 版、未検証） |

## 再現した扱い（Microsoft のヘルプの説明による）
| 関数 | フィルタで隠れた行 | 手で非表示にした行 | 範囲内の SUBTOTAL・AGGREGATE | エラーの値 |
|---|---|---|---|---|
| SUM | 足す | 足す | 足す | 結果がエラー |
| SUBTOTAL(9) | 除く | 足す | 除く | 結果がエラー |
| SUBTOTAL(109) | 除く | 除く | 除く | 結果がエラー |
| AGGREGATE(9,1) | 除く | 除く | 除く | 結果がエラー |
| AGGREGATE(9,3) | 除く | 除く | 除く | 飛ばす |
| AGGREGATE(9,7) | 除く | 除く | **足す** | 飛ばす |

AGGREGATE の「非表示の行」は、フィルタで隠れた行と手で非表示にした行を同じに扱うと置いた（ヘルプには区別の記述がない）。

## 主な結果
- **SUM の合計が見えている明細の合計より多い分（手で隠した行なし、各200枚の中央値）**：8地域のうち1地域だけ残すと+706%、2地域+307%、4地域+100%、6地域+32%、7地域+14%。残す割合が p なら、およそ 1/p − 1
- **SUBTOTAL(9)**：フィルタで隠れた行は正しく除くが、手で非表示にした行は足す。手で隠した行が2%で+1.8%、5%で+4.8%、10%で+10.4%、20%で+24.2%（フィルタなし、各300枚の中央値）
- **1,000枚のランダムな表（残す地域ランダム、手で隠す行0〜10%、小計行あり279枚、エラーの値あり82枚）で、見えている明細の合計と一致した割合**：SUM 2.5%、SUBTOTAL(9) 27.6%、SUBTOTAL(109)・AGGREGATE(9,1)・(9,3) 93.9%（残りはエラーの値がある表）
- **SUM の多い分の中央値**：小計行のない表で+83%、小計行を範囲に含む表で+191%（小計を二重に足すため）
- **AGGREGATE(9,7)**：小計行のある表の256枚で、小計を二重に足して約2倍（中央値+103%）。「エラーも非表示も無視」の7は、範囲内の小計を無視しない
- **エラーの値（#N/A）**：SUBTOTAL(109) と AGGREGATE(9,1) は、見えている行にエラーがあると結果もエラー（61枚）。AGGREGATE(9,3) はエラーを飛ばして合計を出す
- DuckDB の `SUM(...) FILTER (WHERE ...)` で出した3つの合計は、Python で再現した SUM・SUBTOTAL(9)・SUBTOTAL(109) と一致した

## 動かし方
```
pip install -r requirements.txt
cd src && python a515_sum_subtotal.py
```
`results/` に残す地域別の表（`by_keep.csv`）、1,000枚の表ごとの結果（`tables_1000.csv`）、まとめ（`a515_main.json`）が出ます。

## 注意（言えないこと）
- **Excel 本体では動かしていない**。関数の扱いは Microsoft のヘルプの説明を Python で書き直したもので、実際のブックで同じ結果になるかは確かめていない（未検証）
- 架空のデータ。何%多くなるかは、隠した行の割合と金額の偏りで決まる。実際の表の値ではない
- 横方向（列）の非表示、配列の式、ピボットテーブル、テーブルの集計行（自動で SUBTOTAL が入る）は扱っていない
- ストックの案にあった「表を写したときに失われる割合」（フィルタ中のコピーと貼り付け）は、Excel 本体で操作しないと確かめられないため、外した
- T-SQL 版は SQL Server 本体では動かしていない（未検証）
