# 517 保険金額の大きい契約と小さい契約が混ざると、損害率の振れは契約件数ではなく何で決まるのか（保険数理・リスク）

「契約が1万件あるから損害率は安定する」と考えがちですが、それは全件の保険金額が同じくらいのときの話です。**ここでは、保険金額のばらつき σ を変えた架空の1万件の契約で、損害率（損害÷保険料）の振れをシミュレーションで数え、「実質の件数」 n_eff =（保険金額の合計）²÷（保険金額の2乗の合計）から出した式と比べました。** 大きい契約を上から何件か除いたときの変化も出しています。数字は、置いた分布と事故の確率で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A517 | 保険金額が混ざると、損害率の振れは何で決まるか | 保険金額 S は対数正規（σ = 0・0.5・1・1.5・2、平均1にそろえる）。事故の確率5%、事故のときの損害は S × 一様乱数（0〜1）。保険料は目標の損害率65%になるように置く。同じ契約の顔ぶれで事故だけを20,000年分くり返し、損害率の標準偏差を数える。式は sd = 0.65 × （1件の損害の変動係数）÷ √n_eff | `src/a517_effective_n.py` |

## 主な結果
- **同じ1万件でも、振れは保険金額のばらつきで変わる**：損害率の標準偏差は σ=0 で 3.3ポイント、σ=1 で 5.8、σ=1.5 で 9.9、σ=2 で **14.8ポイント**（全件同じ額のときの約4.5倍）
- **振れを決めるのは実質の件数 n_eff**：1万件の n_eff は σ=0.5 で 7,803件、σ=1 で 3,266件、σ=1.5 で 1,129件、σ=2 で **506件**。n_eff から出した式は、どの σ でもシミュレーションと1%以内で合った（σ=2 で 14.6 対 14.8）
- 保険金額の上位1%の契約が合計に占める割合は σ=1 で 9%、σ=2 で 32%
- **件数を増やしたとき**：σ=1.5 の3万件（n_eff 3,392）の振れは 5.6ポイントで、全件同じ額の3,000件（6.0ポイント）とほぼ同じ
- **大きい契約を除くと**：σ=2 で上位10件（保険金額の合計の9.5%）を除くと、n_eff は 506 → 835件、振れは 14.6 → 11.4ポイント（シミュレーションでは 11.3）。σ=1 では上位10件を除いても 5.8 → 5.1ポイント
- 損害率が80%を超える年の割合は、σ=0 でほぼ0%、σ=1.5 で 7.0%、σ=2 で 14.7%（平均はどれも65%）

- 空のフォルダで流し直し、results・figures が一致した

- σ=2 で上位10件を除いた場合を、式とは別にシミュレーションでも数えた（11.3ポイント、式は11.4）

## 注意（言えないこと）
- 架空のシミュレーション。数字は、置いた保険金額の分布・事故の確率・損害の割合の分布で決まる。実際の保険で何ポイントになるかは言えない
- 契約どうしは独立と置いた。台風のように多くの契約が同時に被害を受ける場合は、n_eff の式だけでは振れを小さく見積もる
- 「大きい契約を除く」は振れがどう変わるかを数えたもので、引き受けや再保険の方法を勧めるものではない
- n_eff の式は、事故の確率と損害の割合の分布が保険金額によらないときに成り立つ
