# 526 1事故ごとの免責と1年の合計の免責では、同じ見込みの支払いでも、支払いの振れはどれだけ違うのか（保険数理・リスク）

保険の自己負担（免責）には、「1回の事故ごとに d 円までは自己負担」という形と、「1年の損害の合計が D 円になるまでは自己負担」という形があります。**ここでは、1年の事故件数が平均10件・1件の損害額が平均10万円の架空の損害を40万年分つくり、2つの形で見込みの支払い（平均）が同じになるように D を決めたうえで、支払いの標準偏差と99.5%点を比べました。** 件数の散らばり（ポアソンと分散3倍の負の二項）と、損害額の裾の重さ（対数正規 σ=0.8 と 1.6）を変えています。数字は、置いた件数と額の分布、免責の額で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A526 | 同じ平均の支払いで、免責の形によって振れはどれだけ違うか | 件数：ポアソン（平均10）と負の二項（分散 = 平均×3）。額：対数正規（平均10万円、σ 0.8・1.6）。1事故ごとの免責 d = 5・10・20万円、支払い = Σ max(額 − d, 0)。1年の合計の免責 D は max(合計 − D, 0) の平均が同じになるよう二分法で決める。各場面 40万年、seed 526 | `src/a526_deductible_forms.py` |

## 主な結果
- **1事故ごとの免責10万円・ポアソン・額σ0.8**：見込みの支払いは年31.1万円。同じ平均になる合計の免責は 75.3万円。支払いの標準偏差は 26.6万円 → **36.6万円（1.37倍）**、99.5%点は 138.8万円 → 170.1万円（1.23倍）
- **件数が散らばる（負の二項）と差は広がる**：同じ条件で標準偏差 **1.60倍**、99.5%点 **1.52倍**
- **額の裾が重い（σ1.6）と差はほとんどない**：標準偏差 1.03〜1.06倍、99.5%点 1.01〜1.03倍。大きな1件が支払いの振れを決めるので、免責の形の違いが効きにくい
- 免責の額（5・10・20万円）を変えた12の場面で、標準偏差の比は 1.03〜1.65倍、99.5%点の比は 1.01〜1.75倍。どの場面でも合計の免責のほうが大きかった
- **支払いが0の年**：ポアソン・σ0.8・10万円で、1事故ごとの免責は 3.2%、合計の免責は **31.2%**。合計の免責は「何もない年」と「大きく払う年」に分かれる
- **件数の多い年（上位1割）の平均の支払い**：47.5万円 → **78.2万円**。件数の少ない年（下位1割）では 16.0万円 → 2.7万円

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- 2つの形の見込みの支払い（平均）が、どの場面でも1円単位で一致すること（summary.csv の mean_per と mean_agg）
- 損害の合計の平均が 10件 × 10万円 = 100万円 前後になること

## データ
- データファイルは置いていない。件数と額はコードの中で乱数から作る（seed 526）

## 注意（言えないこと）
- 架空の件数と損害額。実際の保険商品・実際の会社の数字ではない
- 免責の形や額の選び方を勧めるものではない。「この分布とこの免責なら、振れはこれだけ違う」を計算したもの
- 件数と額は独立と置いた。実際には、件数の多い年に額も大きくなるなどのつながりがありうる
- 合計の免責は「1年の合計」だけを見た。上限（支払いの限度額）や、1事故ごとと合計の組み合わせは入れていない
