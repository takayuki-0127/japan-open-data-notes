# 元データ

| ファイル | 出典 | 取得方法 |
|---|---|---|
| L01-26_GML（地価公示 2026年、25,565地点） | 国土交通省「国土数値情報（地価公示データ）」 https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-L01-2026.html | zip（約20MB）は大きいため置いていません。上の URL から取得し、`data/raw/L01-26_GML/` に展開 |
| S12-25_GML（駅別乗降客数、2011〜2024年） | 国土交通省「国土数値情報（駅別乗降客数データ）」 https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-S12-2025.html | 同上。`data/raw/S12-25_GML/` に展開 |
| census2020_muni.csv（市区町村の人口・面積・人口密度） | 総務省「令和2年国勢調査 人口等基本集計」第1-1表（e-Stat） https://www.e-stat.go.jp/stat-search/files?toukei=00200521&tstat=000001136464 | Excel から必要な列だけを CSV にしたもの |

加工済みの特徴量は `data/features.csv`（1行＝1地点）、駅グループごとの乗降客数は `data/stations.csv` です。

- 地価公示の駅距離は、標準地から最寄駅までの道路距離（m）。0m は「駅に近接」「駅前広場に接する」地点
- 乗降客数は駅グループ（同じ駅の複数路線・会社）ごとに合計。0 はデータなし（路線・駅の新設・廃止や非公表）を含む
- 浜松市は2024年に区を再編したため、新しい区（22138〜22140）の地点には市全体の人口密度を使った
