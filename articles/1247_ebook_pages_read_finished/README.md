# 1247 読み放題で読まれたページ数から、最後まで読んだ人の数はどこまで分かるのか？（電子書籍）

読み放題で読まれる電子書籍では、書き手に見えるのが「読まれたページ数の合計」だけということがあります。そこで「読まれたページ数 ÷ 本のページ数」を、何冊分読まれたか、つまり最後まで読んだ人の数の目安にしたくなります。けれども、途中でやめた人の読んだページも合計に入るので、同じページ数でも、「何人かが最後まで読んだ」のか「多くの人が少しずつ読んでやめた」のかは見分けられません。**ここでは、作成者が乱数で作った架空の電子書籍1,000冊（本ごとに、読み始めた人の数と、どこでやめるかの決まりを作成者が置いたもの）で、「ページ数 ÷ 本のページ数」（冊分）が本当に最後まで読んだ人の何倍になるか、読まれ方の形でどれだけ変わるか、ページ数の近い2冊でどちらが多く最後まで読まれたかを当てられるかを数えました。本のページ数・読み返す人の割合を変えた9通りも確かめました。**

例の本・読まれ方は架空のもので、実在の本（作成者の本を含む）や読み放題のサービスの数字ではありません。ページの数え方（文字の大きさなどで1ページの量が変わること）は扱わず、1ページは本のどこでも同じ量と置きました。

関連する記事：841「長い動画と短い動画の維持率は、そのまま比べられるのか？」は、動画の平均の視聴秒数を長さで割った維持率が、長さの違う動画でどう読めるかを扱っています。1251「読み放題のページ数は、文字の大きさや図の多さでどれだけ変わるのか？」は、ページの数え方そのもの（文字の大きさ・図の数え方）でページ数がどう変わるかを扱っています。この記事は、1ページは本のどこでも同じ量と置き、読まれた量の合計しか見えないときに、最後まで読んだ人の数がどこまで分かるかに絞ります。

## 主な結果

### 架空の1,000冊（基本：200ページ、読み返しなし、`results/a1247_main.json` の `base_1000_books`）
| 冊分 ÷ 最後まで読んだ人 | 値 |
|---|---|
| 中央値 | **1.812倍** |
| 10〜90%の範囲 | 1.131〜2.973倍 |
| 0.8〜1.2倍に入った本 | 15.4% |
| 冊分が最後まで読んだ人以上だった本 | 100.0%（作りどおり） |

- 冊分は、本当に最後まで読んだ人の中央値1.812倍だった。冊分が最後まで読んだ人の0.8〜1.2倍に入った本は15.4%だった
- 最後まで読んだ人は1人あたり本のページ数をまるごと読むので、冊分は必ず最後まで読んだ人以上になる（作りどおり）。冊分から言えるのは「最後まで読んだ人はこれより多くない」という上限だけだった
- 冊分が250〜300冊分だった51冊では、最後まで読んだ人は80〜269人（10〜90%で87〜232人）だった
- 読まれたページ数の差が10%未満の2冊（40,948組）で、ページ数の多いほうが最後まで読んだ人も多かったのは**55.76%**だった。でたらめに当てる50%とあまり変わらなかった
- 読み始めた人のうち最後まで読んだ人の割合は、本によって11.49〜62.68%（10〜90%の範囲）だった

### 同じ10万ページ（200ページの本の500冊分）が読まれたとき（`results/shapes_100k_pages.csv`）
| 読まれ方の形 | 1人あたりの読んだページ（式） | 最後まで読んだ人の割合（式） | 読み始めた人 | 最後まで読んだ人 |
|---|---|---|---|---|
| はじめでやめる人が多い（e＝0.5、h＝0.01） | 48.57（48.55） | 6.73%（6.7%） | 2,058.8人 | **138.6人** |
| 少しずつ減る（e＝0、h＝0.008） | 99.89（99.92） | 20.05%（20.06%） | 1,001.1人 | 200.7人 |
| ほとんど読み切る（e＝0.05、h＝0.0005） | 181.46（181.38） | 85.98%（85.96%） | 551.1人 | **473.8人** |

- 同じ500冊分でも、最後まで読んだ人は読まれ方の形で138.6〜473.8人と大きく違った
- 1人あたりの読んだページと最後まで読んだ人の割合は、置いた決まりからの式どおり（括弧の中が式の値）。この表の人数は、10万ページをその1人あたりのページで割って出した見込み

## 注意（言えないこと）
- 架空のデータです。はじめでやめる人の割合、1ページごとにやめる確率、読み始めた人の数、読み返しの量は作成者が置いたもので、結果はこれで決まります。冊分 ÷ 最後まで読んだ人の中央値は、置き方で1.334〜3.572倍と動きました
- 冊分が最後まで読んだ人以上になるのは、最後まで読んだ人が本のページ数をまるごと読むと置いたためです（作りどおり）。読み飛ばして最後のページだけ開く人がいれば、この上限も崩れます（入れていません）
- 1ページは本のどこでも同じ量と置きました。文字の大きさや図の多さでページの数え方が変わる分は扱っていません
- 実在の読み放題のサービスのページの数え方を表すものではありません
