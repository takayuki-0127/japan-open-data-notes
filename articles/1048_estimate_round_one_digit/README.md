# 1048 途中の数字を1桁に丸めて計算すると、答えは何倍まで外れるのか？（概算）

概算では、「1万2千世帯」を「1万」、「2.2台」を「2台」のように、途中の数字を上から1桁（有効数字1桁）に丸めて掛けることがよくあります。1つの数字を1桁に丸めたときのずれはいちばん大きくて1.5倍（1.49…を1に丸めたとき）なので、4つ掛ければ最悪は1.5の4乗の5.0625倍です。これは式で決まります。けれども、ふつうはどのくらいで収まるのか、ずれが上と下のどちらに寄るのか、要素を見込むときの誤差と比べて大きいのかは、式の最悪の値だけでは分かりません。**ここでは、作成者が乱数で作った架空の概算の要素（値の頭の数字の分布を作成者が置いたもの）20万組で、要素の数を1〜8に変え、有効数字1桁・有効数字2桁・10の累乗だけ（桁だけ残す）の3つの丸め方で、丸めない答えから何倍外れるかを数えました。頭の数字の分布と、要素の見込みの誤差を変えた確かめも行いました。**

例の町・数字はすべて架空のもので、実在の地名・人口・会社の数字は使っていません。

関連する記事：四捨五入した構成比を足すと100%にならない話は 907、作業時間を15分単位で切り捨てると消える割合は 893 で扱っています。どちらも足し算での丸めです。この記事は、掛け算でつなぐときの丸めのずれを倍率で数えます。同じ企画の 1041 は、要素の見込みの誤差が要素の数でどう積み重なるかを扱います。この記事は、見込みの誤差とは別に、丸めだけで足されるずれに絞ります。

## 主な結果

### 例：A町のエアコンの掃除の件数
- 世帯数12,000×エアコンのある世帯の割合0.9×1世帯あたりの台数2.2×1年に掃除を頼む割合0.08＝1,900.8件を、1桁に丸めて10,000×0.9×2×0.08とすると1,440.0件になり、丸めない答えの0.7576倍（1.32分の1）だった

### 1つの数字の丸め（有効数字1桁）
- 上に外れる最大は1.3332倍（1.5を2に丸めたとき）、下に外れる最大は1.5分の1（1.5のすぐ手前を1に丸めたとき）だった（式どおり）

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約5.5秒）
- 20万組での外れの最大が、どの要素の数・丸め方でも式の最悪の値（1.5・1.05・10の0.5乗の要素の数乗）を超えないことを確かめた（1要素では1.5倍と式の値に届いた）
- 10の累乗だけに丸めると、丸めた答え÷丸めない答えの中央値が0.9938〜1.0031倍とほぼ1で、下への寄りは有効数字の丸めに特有だった
- 図3枚を開き、日本語・重なり・軸を確かめた（図2・図3は外れの倍率の点の図で、1倍（ずれなし）から始まる対数の目盛り）

## 注意（言えないこと）
- 架空のデータです。要素の値の頭の数字の分布は作成者が置いたもので、ふつうの外れや下への寄りはこれで変わります（4要素の90%の点で1.3606〜2.3661倍）。最悪の値は分布によらず式で決まります
- 四捨五入で丸めると置きました。切り上げ・切り捨てで丸めると、ずれの向きはそろって大きくなります（この記事では数えていません）
- 要素の値どうしは互いに関係なく選ばれると置きました。実際の概算で使う数字の頭の数字が、この分布に従うとは限りません
- 実在の町の需要を表すものではありません。丸めで答えがどれだけ動くかを数えただけです
