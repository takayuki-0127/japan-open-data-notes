# 985 「次こそ当たる」は、どこまで正しいのか？（確率の直感）

くじで外れが続くと、「そろそろ当たるはず」と感じます。毎回の当たりが前の結果と関係なく決まる（独立）なら、これは誤りで、外れが何回続いても次の当たりの確率は変わりません。一方、箱から札を戻さずに引くくじなら、外れの札が減るぶん、次の当たりは本当に上がります。ところが、箱ごとに当たりの数が違い、どの箱か分からないときは、外れが続くこと自体が「当たりの少ない箱かもしれない」という手がかりになり、次の当たりは下がる方向にも動きます。**ここでは、作成者が乱数で作った架空のくじの箱（箱の中の当たりの数を作成者が置いたもの）で、最初から続けて外れたあと、次の1枚が当たる割合が上がるか下がるかを、当たりの数の置き方ごとに数えました。**

くじの確率の数え方だけを扱います。くじを引くことをすすめたり止めたりする話はしません。

## 主な結果

### 続けて外れたあとの、次の1枚の当たり（1箱100枚、各100万箱、`results/next_hit_base.csv`）
| 当たりの数の置き方 | 0回外れたあと | 20回外れたあと | 40回外れたあと | 60回外れたあと |
|---|---|---|---|---|
| 毎回5%で決まる（独立） | 4.99% | 5.03% | 5.02% | 4.90% |
| どの箱も5枚 | 5.01% | **6.23%** | 8.28% | 12.58% |
| 二項分布（平均5枚） | 5.02% | 5.07% | 5.05% | 5.16% |
| 箱ごとに3〜7枚 | 5.01% | 5.73% | 6.74% | 8.91% |
| 箱ごとに0〜10枚 | 5.00% | **3.63%** | 2.33% | 1.67% |
| 2割の箱は0枚・8割は6枚 | 4.80% | 3.79% | 1.42% | 0.21% |
| 台ごとに0〜10%（戻す） | 4.99% | 3.12% | 1.86% | 1.12% |

- 式の値は、20回外れたあとで、独立5%、5枚の箱6.25%、二項分布5%、3〜7枚5.68%、0〜10枚3.62%、2割0枚3.77%、戻す台3.08%。乱数で数えた値との差は、どの置き方・どの k でも0.0016以内だった。**この表の値はどれも式どおりです**
- 毎回5%で決まるくじでは、60回外れたあとも次の当たりは4.90%（式では5%）で、外れが続いても上がらなかった
- どの箱も5枚なら、20回外れたあとの次の1枚は 5÷80＝6.25%（式どおり）に上がった。戻さずに引くと、「次こそ」は本当に正しくなる
- 箱ごとに0〜10枚と違うと、同じ平均5%でも、20回外れたあとは3.63%、60回外れたあとは1.67%に下がった。外れが続いた箱は、当たり0枚の箱である見込みが、引く前の9.09%から20回後に22.26%、60回後に60.40%に上がった（`results/wins_after_20_misses.csv`）
- 当たりの数が二項分布の箱では、戻さずに引いても次の当たりは5%のまま（式どおり）だった。100枚それぞれが5%で当たりになった箱は、毎回5%で決まるくじと区別がつかない

### 確かめ：箱の枚数・当たりの割合・当たりの数の分布（60通り、式、`results/grid_formula.csv`）
| 1箱100枚での置き方 | 当たり2% | 当たり5% | 当たり10% |
|---|---|---|---|
| 決まった枚数 | 1.25倍 | 1.25倍 | 1.25倍 |
| 二項分布 | 1.00倍 | 1.00倍 | 1.00倍 |
| 平均の6〜14割で一様 | 1.1563倍 | 1.1354倍 | 1.059倍 |
| 0〜平均の2倍で一様 | 0.9729倍 | 0.7238倍 | 0.4447倍 |
| 2割の箱が0枚 | 1.1228倍 | 0.7845倍 | 0.2916倍 |

（数字は、箱の2割を続けて外したあとの次の当たり ÷ 平均の当たり。当たりの枚数は整数に丸めたので、平均が置いた割合と少しずれる通りがある（100枚・2%の「2割の箱が0枚」は平均1.6%、50枚・5%の決まった枚数は2枚で4%）。倍率は、丸めたあとの平均に対する値）

- 60通りで、箱の2割を外したあとの次の当たりは平均の0〜1.25倍に動いた（0は小数4桁で0になった値で、2割の箱が0枚・1箱1,000枚の置き方）。決まった枚数では、どの通りも1.25倍（残りが8割になるので 1÷0.8、式どおり）
- **上がるか下がるかは、当たりの数の散らばり（分散）が二項分布の散らばりより小さいか大きいかで決まった**。二項分布の12通りを除く48通りのすべてで、この向きが合った。同じ「平均の6〜14割で一様」でも、枚数が多いと散らばりが二項分布を超えて下がる向きになった（1,000枚・5%で0.8452倍）
- 2枚目が当たる確率については、この向きは式で決まる（2枚の当たりの相関が、当たりの数の分散−二項分布の分散に比例する）。数えたのは、外れが続いたときにどれだけ上がるか下がるかの大きさです

## 注意（言えないこと）
- 架空のデータです。箱の枚数、当たりの平均、当たりの数の散らばりは作成者が置いたもので、上がるか下がるかとその大きさはこれで決まります。表の値はどれも式どおりで、乱数で新しく見つけた値ではありません
- 1人が新しい箱から続けて引く場面だけを数えました。何人かで同じ箱を順に引く場面、ほかの人の結果が見える場面は扱っていません
- 一定の回数で必ず当たる決まり、途中で札を足す決まりは入れていません
- 実際のくじの当たりの数の置き方を表すものではありません。くじを引くことをすすめたり止めたりするものでもありません
- 関連する記事：828「ガチャの『1%』を100回引いても当たらない人は、何%いるのか？」は、毎回1%で決まるくじで外れが続いた人の先を数え、確かめとして100個に1個の箱から戻さずに引く決まりも扱っています。834「くじは、先に引くのと後に引くのでどちらが有利か？」は、当たりの数が決まった箱を何人かで順に引く場面です。827「連勝の長さは、偶然でどこまで伸びるのか？」は、勝ち負けが独立なときの連続の長さを扱っています。同じ企画の987「『少なくとも1回』の確率は、回数でどう増えるのか？」は、台ごとに確率がばらつくと「少なくとも1回」が下がることを扱っていて、外れが続くと当たりの少ない箱の見込みが上がるこの記事と同じ仕組みです。990「偶然の集まり（かたまり）は、どれくらい出るのか？」は、1回ごとの当たり外れではなく、時刻の上で偶然のかたまりと空白がどれくらい出るかを扱います。この記事は、箱の中の当たりの数が分からないとき、外れが続くことが上がる方向と下がる方向のどちらに効くかに絞りました
