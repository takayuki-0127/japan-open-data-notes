# 237 短期大学の学生は、30年でどれだけ減ったのか

文部科学省「学校基本調査」の年次統計「短期大学の学校数、在籍者数、教職員数（昭和25年〜）」（1950〜2025年度）と、各年度の「関係学科別 学生数」（短期大学の本科、2000〜2025年度）を並べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A237 | 短期大学の学生は、30年でどれだけ減ったのか。どの学科から減り、何が残ったのか | 在籍者・学校数の長期推移（1950〜2025年度）／関係学科別の学生数と構成比（2000〜2025年度）／減った人数の学科別の内訳 | `src/a237_junior_college.py` |

## 主な結果
- 短期大学の在籍者は1993年度の530,294人が最多で、2025年度は71,196人。最多の年の13.4%、約7分の1になった。1995年度（498,516人）からの30年で85.7%減った
- 学校数は1996年度の598校から2025年度の292校へ約半分。1校あたりの在籍者は891人（1993年度）から244人に減った
- 女性の割合は1993年度の91.8%から2025年度の84.4%へ下がったが、在籍者の大半が女性であることは変わらない
- 学科別に本科の学生（2000→2025年度）を見ると、人文が63,394人→5,421人（2000年度の9%）、家政が77,218人→11,797人（15%）、社会が18%、保健が23%、教育が36%に減った
- 減った約25万人のうち、家政が26.1%、人文が23.1%、教育が15.4%、社会が14.1%を占める
- 残った学生の中心は教育の学科で、2000年度の18.9%から2025年度の32.1%に。なかでも幼稚園教育は18,221人で、本科の学生の27.0%を占める

## 頑健性
- 関係学科別の表（本科）の合計と、年次統計の在籍者（専攻科などを含む）は、2025年度で本科が在籍者の94.9%。差は本科以外の課程の分で、増減の向きは同じ
- 2025年度の「その他」の学科は、計から他の学科を引いた値と、表に載っている「その他」の行の値が一致した
- コードはきれいなフォルダで3回動かし直し、results と data の全ファイルが一致することを確かめた

## 動かし方
```
pip install -r requirements.txt
cd src && python a237_junior_college.py   # data/raw の Excel から data/・results/・figures/ を作る
python fetch.py                           # 関係学科別の表を e-Stat から取り直す（任意。年次統計は statInfId 000031852325）
```

## データ
- `data/raw/nenji_K012_000031852325.xlsx`：年次統計 短期大学の学校数、在籍者数、教職員数（1950〜2025年度）
- `data/raw/<年度>_GJ_<statInfId>`：関係学科別 学生数（短期大学の本科、国公私立の計）
- `data/jc_nenji.csv`・`data/jc_students_by_field.csv`・`data/jc_students_by_subfield.csv`

## 注意
- 1972年度以前は沖縄県を含まない（年次統計の注）
- 関係学科は学校基本調査の学科系統分類による。「その他」は2000年度の4,465人から2025年度の6,393人に増えたが、中身の学科の区分は年によって違うため、学科の名前で細かく追うのは2000年度と2025年度の比較だけにした
- 短期大学から4年制大学への改組や募集停止など、学生が減った理由はこのデータからは分からない
