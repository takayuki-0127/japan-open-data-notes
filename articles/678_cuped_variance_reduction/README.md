# 678 A/B テストで、前の期間の購入額を使って調整すると、必要な人数はどれだけ減るのか（手法の解説・正解の分かるデータで試す）

購入額の A/B テストは、人による購入額のばらつきが大きいので、小さな差を見つけるには多くの人数が要ります。テストの前の期間の購入額 X を使い、テスト期間の購入額 Y から θ(X − X の平均) を引いてから差をとると（CUPED）、ばらつきの分散はおよそ 1 − ρ²（ρ は X と Y の相関）倍になり、必要な人数も同じ割合で減ります。**ここでは、相関を変えた架空の通販の A/B テストで、推定のばらつきと必要な人数がどれだけ減るかを確かめました（各1,000回）。** 数字は置いた分布で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A678 | CUPED で、必要な人数はどれだけ減るか | 1案5,000人。購入額 Y は平均3,000円・標準偏差3,000円の右に長い分布（対数正規の形）。前の期間の購入額 X との相関 ρ を 0・0.3・0.5・0.7・0.9。B は本当に購入額が3%増える。ふつうの差と CUPED（θ＝A・B を合わせた Cov(X,Y)/Var(X)）を比べる。必要な人数は検出力80%・有意水準5%（両側）。各1,000回、seed 678 | `src/a678_cuped.py` |

## 主な結果

| 相関 ρ | 分散の比（シミュレーション） | 1 − ρ² | 1案に要る人数 ふつう → CUPED |
|---|---|---|---|
| 0 | 1.00 | 1.00 | 17,970 → 17,970 |
| 0.3 | 0.91 | 0.91 | 17,830 → 16,220 |
| 0.5 | 0.75 | 0.75 | 17,670 → 13,270 |
| 0.7 | 0.50 | 0.52 | 17,550 → 8,960 |
| 0.9 | 0.20 | 0.19 | 17,680 → 3,360 |

- **ρ=0.7で必要な人数はおよそ半分、ρ=0.9で5分の1**。ρ=0.3では9%しか減らない
- 1案5,000人のときに差（本当は約90円）を見つけられた割合は、ρ=0.7でふつう32%・CUPED 58%、ρ=0.9で33%・93%
- 推定の平均はどの ρ でもふつうの差と CUPED で同じくらいで、本当の差（約90円）と2円以内（偏りは見られない）

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 678）
- 仮定：前の期間とテスト期間の購入額は、置いた相関でつながる。購入額は0円未満にならないよう0で切った

## 注意（言えないこと）
- 架空のデータ。分布と相関は作成者が置いたもので、結果はこれで決まる
- 前の期間に購入がない人（新しい人）が多いと、相関は下がり、減り方は小さくなる（扱っていない）
- 調整に使う値は、テストの割り付けの影響を受けない値（テストの前の値）に限る。テスト中の値を使うと偏る（扱っていない）
- 外れ値の多いデータでは相関が不安定になる。購入額の大きい人をどう扱うかは扱っていない
- 必要な人数は、1回のテストの計画の助言ではない
