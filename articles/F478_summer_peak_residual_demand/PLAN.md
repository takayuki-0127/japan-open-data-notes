# F478 PLAN（事前の計画）：夏の電力の需要のピークは、太陽光で夕方にずれたのか？

作成：2026-11-18 20:38（結果の数字を集計する前に書いた）

## 問い
夏の1日で電気の使用（エリア需要）が最も多い時刻は、昼過ぎ（14〜15時台）と言われてきた。太陽光の発電が増えると、需要から太陽光（と風力）を引いた「残りの需要」（火力・水力・揚水などで賄う分。以下、残余需要）の山は、太陽光が落ちる夕方へずれるはずである。実際に、東京と九州のエリアで、夏の需要の山と残余需要の山の時刻はどう動いたのか。需要そのものの山も夕方へ動いたのか。

背景：資源エネルギー庁の「2024年度夏季の電力需給対策について」（2024年6月3日、電力・ガス基本政策小委員会）は、住宅の太陽光が最大需要の時間帯（2023年7月18日15時）の需要を約1.2%押し下げたと推計し、東京エリアの予備率を18:30〜19:00の時間帯でも示している（https://www.meti.go.jp/shingikai/enecho/denryoku_gas/denryoku_gas/pdf/075_11_00.pdf ）。夕方が需給を見る時間帯になっていることを、実績のデータで確かめる。

知りたい人：電力の需給や調達を見る人、エネルギーの統計を読む人、電気の使い方の計画にかかわる人。料金・投資・政策の良し悪しは扱わない。

## データ
- 東京電力パワーグリッド「エリア需給実績」：2016〜2023年度は年度ごとの1時間値（単位 万kWh）、2024年度以降は月ごとの30分値（MW平均）。夏（7〜9月）を使う。
- 九州電力送配電「エリア需給実績データ」：2016〜2023年度は四半期の1時間値（MWh、第2四半期＝7〜9月）、2024年度以降は月ごとの30分値（MW平均）。
- 期間：2016〜2026年の夏（7月1日〜9月30日）。2026年の夏は公表されている最新の月まで（確報か速報かを表の見出しで確かめて書く）。
- 内閣府「国民の祝日」CSV（平日の判定）。
- 時刻の扱い：1時間値はその1時間の始まりの時刻。30分値は、東京は30分の始まり、九州は30分の終わりの時刻なので、1時間ごとに平均して「その時の始まり」にそろえる（1時間の平均 MW ＝その1時間の MWh）。
- 地域は北から南（東京、九州）の順に並べる。

## 取得前に見たもの（開示）
- 東京の2016年7月1日の22時〜翌0時の行、2024年7月1日の先頭と7月31日の末尾の行（需要の数字）。九州の2016・2023年7月1日0時、2026年7月1日の先頭と末尾の行。どれも夜の時間帯で、昼の山の値や時刻は見ていない。
- 資源エネルギー庁の資料の要約（上の背景）。
- 山の時刻や残余需要の計算はしていない。

## 手法
1. 1時間値にそろえ、残余需要＝エリア需要−太陽光発電実績−風力発電実績 を作る。
2. 夏の平日（土日・祝日・8月13〜16日を除く）ごとに、需要の最大の時刻と、残余需要の最大の時刻を出す。夏ごとに中央値と、時刻の分布（何時台が何%）を出す。
3. 夏ごとに、需要の上位10日（その夏で需要の最大が大きい10日）の山の時刻と、その時刻の太陽光の大きさ、残余需要の最大と需要の最大の比を出す。
4. 2016〜2018年の夏と2024〜2026年の夏を比べる。

## 仮説と「外れ」の基準
- H1：東京の需要（エリア需要）の山の時刻は夕方へ大きくはずれていない：平日の山の時刻の中央値が、2024〜2026年は2016〜2018年より1時間以上遅くはない。1時間以上遅くなっていたら外れ。
- H2：東京の残余需要の山の時刻は、2024〜2026年の夏で需要の山より2時間以上遅い（中央値どうし）。2時間未満なら外れ。
- H3：東京の「残余需要の山の時刻−需要の山の時刻」は、2016〜2018年より2024〜2026年の方が1時間以上大きい。1時間未満なら外れ。
- H4：太陽光の割合が大きい九州では、2024〜2026年の差（残余需要の山−需要の山）が東京より大きい。東京以下なら外れ。

## 頑健性（3つ以上）
1. 日を変える：平日だけでなく全日、需要の上位10日だけ。
2. 中央値ではなく平均（時刻の平均）と、17時台以降が山になった日の割合。
3. 残余需要の定義：風力を引かない（太陽光だけ引く）。太陽光の出力制御量を足し戻した「制御がなかったら」の太陽光で引く。
4. 期間の端：2016〜2018年に代えて2016〜2017年、2024〜2026年に代えて2024〜2025年（2026年が速報の場合に備えて）。

## 言えないこと（予定）
- エリア需要は、屋根の太陽光の自家消費の分だけ小さく見える。需要の山の時刻の動きには、自家消費の増加が入りうる。
- 気温（暑さ）の違いは調整していない。上位10日の比較で一部を見るだけ。
- 太陽光の実績は推計を含む値で、エリアごとに作り方が違いうる。
- 需給の厳しさ（予備率）は供給力にもよるため、残余需要の山がそのまま需給の厳しい時刻とは言えない。

## 追記（2026-11-18 20:41、データ取得の段階・集計の前）
- 東京電力パワーグリッドのサイトは、取得スクリプトの User-Agent（open-data-notes-fetch）からの取得を HTTP 403 で拒否した。ブラウザを名乗って取りに行くことはしない。代わりに、同じ形式の1時間値・30分値を公開している**関西電力送配電**のエリアを使う。上の仮説 H1〜H4 の「東京」は「関西」に読み替える（基準は変えない）。地域の並びは北から南（関西、九州）。
- 関西の30分値の形を確かめるときに、2026年9月1〜8日の30分値（需要・太陽光を含む昼の値）を目にした。山の時刻の集計や比較はしていない。
- 関西の30分値は「その30分の始まり」の時刻（先頭が 0:00、末尾が 23:30）。
