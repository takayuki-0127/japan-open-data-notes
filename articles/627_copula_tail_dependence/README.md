# 627 相関の強さが同じでも、正規コピュラと t コピュラでは、同時に大きな損害が出る確率はどれだけ違うのか（手法の解説・正解の分かるデータで試す）

2つの損害のつながりを入れるとき、「相関の強さ」を1つの数字で決めても、つながりの形（コピュラ）を変えると、大きな損害が同時に起きる確率が変わります。**ここでは、架空の2つの事業の年間の損害（どちらも対数正規、平均100、変動係数0.5）を、順位の相関（ケンドールの τ）を0.35にそろえた3つのコピュラ（正規、t（自由度3）、ガンベル）でつなぎ、片方が大きな損害のときにもう片方も大きくなる割合と、合計の99.5%点・99.9%点を比べました。** 各300万回。数字は置いた分布で決まります。料率・備金・資本の助言ではありません。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A627 | 同じ τ のとき、コピュラの形で同時の大損害の確率と合計の分位点はどう変わるか | 正規コピュラ（ρ=sin(πτ/2)=0.52）、t コピュラ（自由度3、同じ ρ）、ガンベル・コピュラ（θ=1/(1−τ)=1.54、正の安定分布で生成）。300万回、seed 627 | `src/a627_copula.py` |

## 主な結果
- 3つとも順位の相関は τ=0.34〜0.35 にそろっている（確かめ）
- **事業1が自分の99%点を超えた年に、事業2も99%点を超える割合**：正規 13.8%、**t 34.5%**、ガンベル 43.6%（独立なら1%）
- **99.9%点（1000年に1度）では**：正規 5.9% に下がるが、t 33.3%、ガンベル 42.0% とほとんど下がらない。正規コピュラは、極端なところほど2つが別々に動く形
- **合計の99.5%点（平均の合計200）**：正規 534、t 555（+4.1%）、ガンベル 573（+7.3%）
- **合計の99.9%点**：正規 661、t 712（+7.8%）、ガンベル 735（+11.3%）
- それぞれの99.5%点（302）を足すと 604 で、どのコピュラの合計の99.5%点より大きい
