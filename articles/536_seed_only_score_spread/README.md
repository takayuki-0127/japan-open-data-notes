# 536 乱数の種を変えるだけで、同じモデルの検証の成績は何ポイント揺れるのか（機械学習・検証）

ランダムフォレストや勾配ブースティングは、学習の中で乱数を使います（木ごとに行や特徴量を抜き出すなど）。**ここでは、架空の2値分類データで、データ・学習と検証の分け方・ハイパーパラメータをすべて固定し、モデルの乱数の種だけを30通り変えて、検証の AUC と正解率がどれだけ揺れるかを測りました。** 件数（500・2,000・8,000件、検証はその30%）と特徴量の数（10・40、効くのは5個）を変えています。あわせて、2つの設定（A と B）を同じ種どうしで比べ、「設定Aのほうが良い」が種で入れ替わる割合を見ました。数字は、置いたデータとモデルの設定で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A536 | 種だけを変えたとき、検証の成績はどれだけ揺れ、設定の勝ち負けはどれだけ入れ替わるか | scikit-learn の RandomForestClassifier（100本、設定A max_features='sqrt'・B 0.5）と HistGradientBoostingClassifier（150回、max_features=0.5、設定A 学習率0.1・B 0.05）。種 0〜29。追加で分け方の種も変える場合（2,000件・特徴量10）。データの種 536 | `src/a536_seed_spread.py` |

## 主な結果
- **2,000件・特徴量10（検証600件）**：種だけで、ランダムフォレストの AUC は最大と最小で 1.65ポイント、勾配ブースティングは 2.09ポイント違った。正解率では 3.0・4.5ポイント
- **件数が少ないほど揺れは大きい**：AUC の最大−最小は、500件で 2.2〜6.6ポイント、2,000件で 1.3〜3.5ポイント、8,000件で 0.5〜1.2ポイント。正解率では 4.0〜8.0・2.7〜4.5・1.1〜2.0ポイント
- **「設定Aのほうが良い」が種で入れ替わる割合は、12の場面で 3〜43%**。平均の差が種による揺れより小さいと、ほぼ五分五分になる（ランダムフォレスト・500件・特徴量10 で 43%、平均の差 −0.41ポイント、差の標準偏差 0.96ポイント）
- **分け方の種も変えると、揺れはさらに大きい**：2,000件・特徴量10 で AUC の最大−最小は 5.6〜7.6ポイント（種だけのときの約3〜4倍）。標準偏差は 1.6〜1.8ポイント
- 分け方を変えても、同じ分け方の上での設定の比較は安定することがある（勾配ブースティングでは30通りすべてで B が上）

## 動かし方
```
pip install -r requirements.txt
cd src && OMP_NUM_THREADS=1 python a536_seed_spread.py
```
1スレッドで10分ほどかかります（ランダムフォレストは n_jobs=1、勾配ブースティングは OMP_NUM_THREADS=1 で動かすと、流し直しても同じ数字になります）。

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した（OMP_NUM_THREADS=1、n_jobs=1）
- 種を同じにすると、同じ AUC が再現されること
- 検証の件数が少ないと、正解率は「1件 = 1/検証の件数」の刻みでしか動かないこと（500件では検証150件、1件で0.67ポイント）

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 536）

## 注意（言えないこと）
- 架空のデータ。実際のモデルや業務の成績ではない
- 揺れの大きさは、モデルの設定（木の本数、抜き出す割合など）で変わる。木を増やせば種による揺れは小さくなる
- どの設定が良いかを勧めるものではない。「この条件なら、種だけでこれだけ揺れる」を測ったもの
- 交差検証や、くり返しの平均をとる方法は比べていない
