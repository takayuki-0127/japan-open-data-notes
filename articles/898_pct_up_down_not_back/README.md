# 898 20%上がって20%下がると、元に戻るのか？（割合とパーセント）

売上が20%上がったあと20%下がると、元には戻りません。100万円が120万円になり、120万円の20%（24万円）が減って96万円です。上がる率と下がる率では、もとにする値（分母）が違うためです。**ここでは、上がって下がる例の計算に加えて、作成者が乱数で作った架空の店1,000店の月の売上（前月比の平均を0%と置いたもの）を24か月作り、「前月比の平均が0%なら横ばい」と読んだとき、実際の売上がどこに行くかを数えました。**

同じ率で上がって下がると「率の2乗」だけ減ること、元に戻るのに要る上がりが「下がった率÷（1−下がった率）」になることは式で決まります。この記事で数えたのは、上がり下がりを何か月も繰り返したとき、店の平均と真ん中の店（中央値）がどう離れるかです。

割合の変化を%ポイントと変わった率のどちらで書くかは関連する記事 897、毎月の伸びを1年に直すときの数え方は 899、平均と中央値の離れ方は 891、期間の切り出し方で上昇にも下落にも見えることは 817 で扱っています。この記事は、上がり下がりの率を足し引きして読むことのずれに絞ります。

## 主な結果

### 例：同じ率で上がって下がる（100万円から）
| 率 | 上がって下がる | 下がって上がる | 減った分 | 下がったあと元に戻るのに要る上がり |
|---|---|---|---|---|
| ±5% | 99.75万円 | 99.75万円 | 0.25% | 5.26% |
| ±10% | 99.0万円 | 99.0万円 | 1.0% | 11.11% |
| ±20% | **96.0万円** | 96.0万円 | **4.0%** | **25.0%** |
| ±30% | 91.0万円 | 91.0万円 | 9.0% | 42.86% |
| ±50% | 75.0万円 | 75.0万円 | 25.0% | 100.0% |

- 上がって下がると（1＋率）×（1−率）＝1−率の2乗になり、率の2乗だけ減る。順番を逆にしても同じ（式どおり）
- 20%下がった店が元に戻るには、20%ではなく25.0%上がる必要がある

### 架空の店1,000店・24か月（前月比の平均0%・振れ10%）
| | 値 |
|---|---|
| 全部の店・全部の月の前月比の平均 | 0.035% |
| 24か月後の売上÷始め（店の平均） | **1.012** |
| 24か月後の売上÷始め（真ん中の店） | **0.92**（92.0万円） |
| 24か月後の売上÷始め（10〜90%の範囲） | 0.45〜1.734 |
| 始めを下回った店 | **57.7%** |
| 前月比の平均が0%以上だった店 | 52.0% |
| そのうち、24か月後に始めを下回った店 | **18.7%** |

- 店の平均は始めとほぼ同じ（1.012）だったが、真ん中の店は0.92まで下がった。上がった店が大きく上がり、平均を引き上げるため
- 前月比の平均が0%以上なのに、24か月後に始めを下回った店が、前月比の平均が0%以上の店の18.7%（全体の9.7%）あった
- 真ん中の店の0.92は、理屈の目安（24か月×振れの2乗÷2だけ減る、0.887）に近い。2,000店で数え直すと0.904だった

### 確かめ：置き方を変えると（各2,000店）
| 前月比の分布 | 振れ | 12か月 | 24か月 | 60か月 |
|---|---|---|---|---|
| 正規分布 | 5% | 0.986 | 0.985 | 0.936 |
| | 10% | 0.951 | 0.904 | 0.76 |
| | 20% | 0.8 | 0.597 | 0.27 |
| | 30% | 0.607 | 0.311 | 0.044 |
| ちょうど＋か−が半々 | 5% | 0.985 | 0.97 | 0.928 |
| | 10% | 0.941 | 0.886 | 0.74 |
| | 20% | 0.783 | 0.613 | 0.294 |
| | 30% | 0.568 | 0.322 | 0.059 |

（表の値は、前月比の平均0%のときの、終わりの売上÷始めの中央値）

- **前月比の平均0%の24通りで、真ん中の店は始めの0.044〜0.986倍だった。始めを下回った店は53.0〜89.3%で、どの置き方でも半分を超えた**。店の平均は0.76〜1.137倍で、ほぼ始めのまわりにとどまった（60か月・振れ30%の0.76は、ごく少数の大きく上がった店が2,000店に入るかどうかで動いた値と考えられる（推測））
- 「ちょうど＋か−が半々」の24か月の中央値（0.97・0.886・0.613・0.322）は、（1＋振れ）×（1−振れ）の12乗の式の値と一致した
- 前月比の平均を+1%にしても、振れが20%なら24か月後の真ん中の店は0.764倍で、始めを下回った店は59.5%だった（店の平均は1.248倍）。+1%の24通りでは、真ん中の店は0.095〜1.699倍、始めを下回った店は7.7〜83.1%だった

## 注意（言えないこと）
- 架空のデータです。前月比の平均・振れ・分布・月数は作成者が置いたもので、結果はこれで決まります。真ん中の店は、前月比の平均0%で始めの0.044〜0.986倍と、置き方で大きく動きました
- 同じ率で上がって下がると率の2乗だけ減ること、元に戻るのに要る上がりは、式で決まる結果です
- 前月比は月ごとにでたらめに決まり、前の月とつながりがないと置きました。季節の山や、下がったあとに戻りやすいといった動きは入れていません
- 実在の店の売上を表すものではありません。売上の見通しや、どうすればよいかは言えません
- 既存の記事 644 は、毎年の伸び率を足して割った平均（算術平均）と年率（幾何平均）の違いを、架空の100店の5年後の値のずれで数えています。この記事は、前月比の平均が0%でも真ん中の店が下がる大きさと、店の平均と中央値の離れ方に絞りました
