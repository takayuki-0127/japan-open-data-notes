# F140 外国人の住民は、どの地域に、どの速さで増えたのか？ — 空間的な集中度と増え方の分解

## 問い
2014年から2026年までの12年で、外国人の住民はどの地域に、どの速さで増えたのか。住む場所は大都市に集まる方向に動いたのか、広がる方向に動いたのか。増えた分は、国外からの転入・国内の移動・出生と死亡のどれによるものか。

この記事は、人数の分布と増え方だけを扱います。評価的な言葉は使わず、国籍・地域は公表されている区分にとどめます。個別の市区町村の順位は出しません。

## データ
| データ | 内容 | 使い方 |
|---|---|---|
| 総務省「住民基本台帳に基づく人口、人口動態及び世帯数」 | 市区町村別の人口（総計・外国人住民、各年1月1日）と、前年1年間の動態（国内・国外の転入出、出生、死亡、その他）。2014〜2026年の13回分 | 主な分析（集中度・増え方・分解） |
| 出入国在留管理庁「在留外国人統計」 | 市区町村別 国籍・地域別 在留外国人（2015年末・2022年末）、都道府県別 国籍・地域別（2015年末・2018年末）、市区町村別の総数（2023年末・2025年末） | 国籍・地域別の分析と、データ源の確認 |

- 単位は市区町村（政令指定都市は区、東京都は特別区）。2024年に区を再編した浜松市は、全期間を市にまとめました。2014年と2026年の両方にある 1,894 の単位を、2時点の比較に使います。
- 住民基本台帳の外国人住民は、中長期在留者・特別永住者などで、短期滞在者は含みません。
- 地域：東京圏＝埼玉・千葉・東京・神奈川、名古屋圏＝岐阜・愛知・三重、大阪圏＝京都・大阪・兵庫・奈良、地方圏＝それ以外。

## 手法
1. **集中度**：外国人と日本人の住む場所の違いを、次の4つの指標で毎年測りました。
   - 非類似度指数 D：0なら同じ分布、1なら完全に別の分布。
   - ローレンツ曲線とジニ係数。
   - Theil 指数：都道府県の間の差と、都道府県の中の差に分けました。
   - 外国人の多い上位5%の市区町村に住む割合。
2. **立地係数**：その市区町村の外国人の割合を全国の割合で割った値です。1を超える市区町村の数を数えました。
3. **増え方**：2014年から2026年の増加率を比べました。比べた切り口は4つです。
   - 2014年の外国人の割合（5分位）
   - 人口規模
   - 地域
   - 市区町村の種類（区・市・町村）
4. **増減の分解**：住民基本台帳の動態（2014〜2025年の各年中）を、次の4つに分けて足し上げました。
   - 国外との転入−転出
   - 国内の転入−転出
   - 出生−死亡
   - その他（職権による記載・消除、帰化など）
5. **国籍・地域**：在留外国人統計の市区町村別の表（2015年末・2022年末）で、国籍・地域ごとに D と地方圏に住む割合を求めました。国籍・地域の構成だけが変わった場合の D（シフトシェア型の反実仮想）とも比べました。
6. 乱数を使うのはブートストラップだけで、シードは140に固定しました。

## 結果
### 1. 人数は2倍になり、住む場所は日本人の分布に近づいた
- 外国人住民は 200万人（2014年、総人口の1.56%）から 403万人（2026年、3.26%）に増えました。コロナの時期の2021年・2022年だけ、前の年より減っています。
- **D は 0.312 から 0.273 に下がりました。**
  - 変化は −0.039 で、ブートストラップの95%区間は −0.048〜−0.030 です。
  - 2014〜2020年、2020〜2023年、2023〜2026年のどの期間でも下がりました。
- 他の指標も、同じ向きに動きました。
  - ジニ係数：0.433 → 0.380
  - 上位5%の市区町村に住む割合：45.2% → 42.4%
  - 立地係数が1を超える市区町村：341 → 466
- **都道府県の中の差の比重が増えました。**
  - 都道府県単位の D：0.215 → 0.184
  - Theil 指数のうち都道府県の中の差の割合：56% → 59%

### 2. 外国人の割合が低かった市区町村ほど速く増えた
- 2014年の外国人の割合で5つに分けると、増加率は次のとおりでした。
  - 最も低い20%：+221%
  - 最も高い20%：+90%
  - 割合と伸びの順位相関：−0.36
- 人口規模別の増加率：
  - 1万人未満：+193%
  - 20万人以上：+95%
- 種類別の増加率：
  - 町村：+147%
  - 市：+106%
  - 区：+91%
- 地方圏の町村は +162% でした。
- 外国人住民が10人以上いた市区町村のうち、62%で2倍以上に増えました。中央値は +119% です。
- 外国人住民のうち地方圏に住む割合は、29.4% から 31.3% に上がりました。総人口のうち地方圏の割合は、48.8% から 46.7% に下がっています。
- 東京圏の割合も 39.0% から 40.6% に上がりました。下がったのは名古屋圏（13.7% → 12.4%）と大阪圏（17.8% → 15.7%）です。
- 83%の市区町村で、日本人が減り、外国人は増えていました。これらの市区町村では、外国人の増加が日本人の減少の 14.8% にあたります。

### 3. 増えた分のほとんどは国外からの転入で、国内の移動は全国ではほぼ差し引きゼロ
2014〜2025年の各年中の動態を足し上げると、次のとおりでした。
- 国外との転入−転出：+333万人
- その他：−141万人
- 出生−死亡：+12万人
- 国内の転入−転出：−1万人

国外からの純流入を2014年の人数あたりで見ると、区 1.65倍、市 1.62倍、町村 2.15倍で、町村で最も大きくなりました。「その他」の減少も町村が最も大きく、区 −0.70倍、市 −0.68倍、町村 −0.99倍です。

国内の移動の向きは、地域で違いました。
- 東京圏の区と市は、国内の移動でも増えていました。
- 東京圏・大阪圏の町村と、地方圏・名古屋圏の区は、国内の移動で減っていました。

### 4. 国籍・地域によって、広がり方は違った（在留外国人統計、2015年末→2022年末）
- **ベトナム**：D は 0.366 → 0.287 で、最も大きく下がりました。2022年には最も日本人の分布に近い区分になり、地方圏に住む割合も 36% → 41% に上がりました。
- **ネパール**：D は 0.529 → 0.420 に下がりました。
- **中国**：D は 0.356 → 0.402 に上がり、地方圏に住む割合は 26.5% → 20.2% に下がりました。
- **ブラジル**：D は 0.681 → 0.686 で、最も集中したままでした（地方圏に住む割合は44%）。
- **総数**：D は 0.312 → 0.284 に下がりました。国籍・地域の構成だけを2022年に変えた場合の D は 0.300 で、下がった分の約4割は構成の変化で説明できます。

## 頑健性
| 確認 | D（2014年→2026年） | 結論 |
|---|---|---|
| 主な分析（市区町村、政令市は区） | 0.312 → 0.273 | — |
| 政令市を市に、23区を1つにまとめる | 0.298 → 0.257 | 同じ（下がる） |
| 東京都を除く | 0.305 → 0.266 | 同じ |
| 都道府県単位 | 0.215 → 0.184 | 同じ |
| ジニ・Theil・上位5%の割合 | すべて下がる | 同じ |
| 期間を3つに分ける（2014–20、20–23、23–26） | −0.017、−0.011、−0.011 | どの期間も下がる |
| 在留外国人統計（2025年末）と比べる | D 0.2736（住基 0.2730）、市区町村の相関 0.99995 | データ源で変わらない |
| ブートストラップ（市区町村を復元抽出、1,000回） | 変化 −0.048〜−0.030 | 0をまたがない |

## 言えないこと
- 住む場所が広がった理由（在留資格・仕事・住宅など）は、この分析では分けていません。
- 「その他」には、届け出のないまま転出した人の職権による消除などが入るとみられます。そのため「国内の転入−転出」と「その他」の境目ははっきりしません（推測）。
- 住民基本台帳（1月1日）と在留外国人統計（年末）は、対象と時点が少し違います。国籍・地域別の分析は2015年末と2022年末の2時点だけで、2015年末の表は上位8か国・地域の区分です。
- 立地係数や D は分布の違いを表す指標です。暮らしやすさや地域への影響を表すものではありません。
- 個々の市区町村の値は results/ や data/ にありますが、記事では順位を出していません。
