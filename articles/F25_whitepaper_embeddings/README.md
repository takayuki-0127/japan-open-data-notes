# F25 経済白書41年分を文埋め込みで読む（文書埋め込み・クラスタリング・検索）

看板記事 F25。内閣府の経済白書（1985〜2000年度）と経済財政白書（2001〜2025年度）の本文、41年度分・約757万字を約500字の塊（チャンク）に分け、日本語の文埋め込みモデル（ruri-v3-30m）で数字のベクトルにした。テーマに分けて年ごとの移り変わりを見て、質問文に近い節を探す検索も作った。

## 問い

経済白書の本文を埋め込みにすると、テーマはどう分かれ、41年でどう移り変わったか。話題が大きく入れ替わったのはいつか。

## データ

| 対象 | 範囲 | 件数 |
|---|---|---|
| 年次経済報告（経済白書）HTML 版 | 1985〜2000年度 | |
| 年次経済財政報告（経済財政白書）HTML 版 | 2001〜2025年度 | |
| 合計（目次・付注・参考文献・図表のページを除く） | 41年度 | 1,345ページ・16,964チャンク・約757万字 |

- 入口は内閣府「過去の経済財政白書／経済白書」（https://www5.cao.go.jp/keizai3/keizaiwp/index.html）。各年度の HTML 版の目次から、同じフォルダの中のリンクを3階層までたどった（`src/01_取得.py`、記事ではブラウザ版の `src/01_取得_browser.js` で取得）。
- 2026年度（令和8年度）は取得時点で PDF 版だけだったので入れていない。
- **白書の本文は GitHub に置いていない**（著作権に配慮）。置いているのは、チャンクの年度・URL・見出し・文字数（`data/chunks_meta.csv`）、埋め込み（`data/emb_*.npy`、float16）と集計結果だけ。本文は `src/01_取得.py` で取り直せる。

## 手法

| 段階 | 方法 |
|---|---|
| 整形 | サイトのメニュー（同じ年度のページの2割以上に出る行）、図表の題、15字未満の行を除き、文（「。」まで）をつないで約500字で区切る |
| 埋め込み | **cl-nagoya/ruri-v3-30m**（日本語の文埋め込み、256次元、Apache-2.0）。テーマ分け用は先頭に「トピック: 」、検索の文書側は「検索文書: 」、質問側は「検索クエリ: 」を付ける（モデルの説明どおり）。CPU で約45分 |
| テーマ分け | 正規化した埋め込みを KMeans（k=12、n_init=20）。名前は c-TF-IDF（テーマごとに特徴的な名詞、fugashi＋unidic-lite）と代表的な見出しを見て付けた |
| 地図 | UMAP（コサイン距離、2次元） |
| 年どうしの近さ | 年度ごとの平均ベクトルから全体の平均を引き、コサイン類似度（引かないと、どの年も「経済の文章」なので0.98以上にそろう） |
| 語の検索 | 質問文の埋め込みとのコサイン類似度。全チャンクの上位1%の近さを「近い」とし、その年度のチャンクの何%が近いかを数える |

## 主な結果

- **12のテーマ**：住宅・土地／景気の回復／生産性・技術／家計の消費・所得／貿易・為替／設備投資・在庫／金融・銀行／財政／社会保障・年金／雇用・賃金／規制改革・産業／物価・デフレ。
- **時代ごとの主役**（年度ごとの構成比の平均）：

| テーマ | 1985〜94 | 1995〜2004 | 2005〜14 | 2015〜25 |
|---|---|---|---|---|
| 貿易・為替 | **18.3%** | 8.6% | 7.0% | 5.4% |
| 設備投資・在庫 | **15.8%** | 7.6% | 5.4% | 5.0% |
| 金融・銀行 | 11.2% | **20.1%** | 11.7% | 3.1% |
| 財政 | 4.5% | **10.5%** | 8.5% | 5.7% |
| 生産性・技術 | 3.0% | 6.8% | **13.9%** | 13.1% |
| 雇用・賃金 | 6.9% | 7.9% | 15.1% | **28.9%** |
| 家計の消費・所得 | 5.4% | 3.3% | 5.8% | **10.1%** |
| 物価・デフレ | 5.7% | 3.9% | 7.5% | **8.8%** |

  - 1年度で最も大きかったのは、金融・銀行が1997年度の34%、財政が2001年度の33%、雇用・賃金が2019年度の38%。
- **話題の入れ替わり**：前の年度との近さ（平均ベクトルのコサイン類似度）の平均は、1986〜99年度 0.67、**2000〜14年度 0.33**、2015〜25年度 0.70。2000年代〜2010年代前半は、毎年テーマが大きく変わっていた。最も低いのは 2008年度（0.10）、2005年度（0.17）、2012年度（0.20）、2011年度（0.20）。2015年度以降は、雇用・賃金、生産性、物価が毎年続けて取り上げられ、年どうしが似ている。
- **語の検索**（その年度で質問文に近いチャンクの割合。平均は1%）：
  - 不良債権：2001年度 10.6% が最多。1996〜2005年度に集中し、2010年度以降はほぼ0。
  - 財政赤字：2000年度 5.0%、2012〜13年度にも山。
  - デフレ：2015年度 5.9%、2023年度 3.8%。
  - 少子化・人口減少：2003年度 8.6%、2020年度 6.5%、2023年度 9.1%。
  - デジタル・AI：2017・2018年度に 8〜9%。
  - 環境・脱炭素：2010年度 6.7%、2021・2022年度に 10〜14%。
  - 賃金：2014年度 4.1%、2025年度 6.0%（最多）。
- **検索デモ**（`results/search_demo.csv`、見出しのみ）：「不良債権」で 2003年度「不良債権処理の重要性」、1996年度「不良債権問題の経緯と現状」、「デジタル・AI」で 2018年度「第4次産業革命の社会実装」などが上位に出る。単語が一致しなくても意味が近い節が出る一方、「物価」のような広い質問では景気全般の節が上位に混ざった。

## 頑健性

| 設定 | 基本のテーマ分けとの一致（ARI） | 前半（〜2004）と後半（2005〜）のテーマ構成の違い |
|---|---|---|
| 基本（ruri・k=12・KMeans） | 1 | 31% |
| k=8 | 0.62 | 27% |
| k=16 | 0.58 | 32% |
| 乱数の種を変える（2通り） | 0.72・0.78 | 32%・33% |
| 前置きを「検索文書: 」に変えた埋め込み | 0.76 | 31% |
| 単語ベース（TF-IDF＋SVD、256次元） | 0.44 | 26% |
| UMAP（10次元）＋HDBSCAN | 0.33（57テーマ、30%は外れ） | — |

- テーマの境目は設定で動く（ARI 0.3〜0.8）。とくに単語ベースや HDBSCAN とは分け方がかなり違う。一方、「前半と後半でテーマの構成が約3割入れ替わった」という大きさは、どの設定でも26〜33%で変わらない。
- 語の検索の推移は、チャンクを1,000字にしても、「近い」の閾値を上位0.5%・2%に変えても、基本との相関が 0.88〜1.00。ピークの年度は多くの語で同じだった（物価は 2022→2018・2024、少子化は閾値を変えると 2023→2003 に入れ替わる。どちらも山が複数ある語）。

## 動かし方

```bash
pip install -r requirements.txt
python src/01_取得.py          # 本文の取得（約20分。data/raw/pages.json）
python src/02_整形.py 500 1000  # チャンク作成
python src/03_分析.py           # 埋め込み（CPU で約45分、2回目からは data/emb_*.npy を読む）・テーマ・検索
python src/03b_頑健性.py
python src/04_図.py
```

- モデルは Hugging Face の `cl-nagoya/ruri-v3-30m`。ネットにつながらない環境では、手元に置いたフォルダを環境変数 `RURI_PATH` で指定する。
- `results/theme_labels.json` は、`results/themes.csv` を見て手で付けたテーマの短い名前。
- 乱数の種は42で固定。KMeans・UMAP は種を固定しても、ライブラリの版によってわずかに結果が変わることがある。

## 言えないこと

- 白書の記述量は、政府（内閣府）の関心の目安で、政策の優先度そのものではない。経済財政白書は経済の分析の報告で、政策の文書ではない。
- テーマの名前は、特徴語と見出しを見て付けたもの。テーマの境目は設定で動く（頑健性を参照）。
- 年度によってページの分け方や本文の量が違う（1997年度は248チャンク、2025年度は579チャンク）。構成比は年度の中の割合なので量の違いはそろえているが、分け方の違いは残る。
- 埋め込みモデルは2020年代の文章で学習しているので、1980年代の言い回しの意味をうまくとらえられていない可能性がある。
- 語の検索の「近い」は類似度の上位1%という相対的な基準で、その語について書いているかを人が確かめたわけではない。
