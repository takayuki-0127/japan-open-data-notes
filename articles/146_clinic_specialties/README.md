# 146 診療所の「開業ブーム」はどの診療科で起きているか：医療施設調査で、診療科別の一般診療所の数と開設・廃止を見る

厚生労働省「医療施設調査」の公表表から、一般診療所（病床が19床以下の診療所。歯科を除く）の数を、掲げている診療科別（重複計上）・開設者別に並べ、毎年の開設・廃止とあわせて見たフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A146 | 一般診療所はどの診療科で増え、どの科で減ったか。開設・廃止と開設者はどう変わったか | 診療科別の施設数の増減率（2008→2023年、2008年に300施設以上の35科）、開設・廃止件数の推移（2011〜2025年）、開設者別の施設数の推移（2002〜2025年） | `src/a146_clinics.py` |

## 主な結果
- 一般診療所は 2008年 99,083 → 2023年 104,894（+5.9%）、2025年は 105,521
- 掲げる診療所が大きく増えた科（2008→2023年）：腎臓内科 +175%（873→2,399）、乳腺外科 +162%、糖尿病内科 +144%（1,908→4,647）、美容外科 +105%（983→2,016、2020→2023年の3年で +44%）、血液内科 +65%、心療内科 +41%、精神科 +38%
- 減った科：小児科 −21%（22,503→17,778）、外科 −23%、産婦人科 −22%、放射線科 −45%、気管食道外科 −61%
- 開設は毎年4,700〜11,300件、廃止は4,000〜10,600件で、差（純増）は −300〜+1,700。2011〜2025年の合計は開設10.9万件・廃止9.8万件
- 開設者は個人が 2002年 55% → 2025年 36%、医療法人が 29% → 46%。2017年に医療法人が個人を上回った

## 注意
- 診療科別の数は「その科を掲げている診療所の数」（重複計上）で、主に診ている科（主たる診療科目）ではありません。1つの診療所が複数の科を掲げると、それぞれに数えられます
- 2008年4月の医療法施行令の改正で、掲げられる診療科の名前の決め方が変わりました。2008年以降で比べ、1984〜2002年の表は参考にとどめています
- 2011年は福島県の全域を除いた数値です（総数は全国の数値）
- 開設・廃止には、移転に伴う旧施設の廃止と新施設の開設、開設者の変更に伴うものが含まれます。開設の件数そのものを「新しく開業した数」とは読めません
- 診療科別の開設・廃止の表は公表されていないので、どの科で開設が多いかは、施設数の増減から見ています
