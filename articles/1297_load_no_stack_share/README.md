# 1297 上に重ねられない荷物が1割まざると、体積で見た積載率はどれだけ下がり、車は何台増えるのか？（箱詰めと積載）

荷物には「上に重ねられない」ものがあります。台数を荷物の体積の合計から見込むと、こうした荷物が1割まざっても、見込みは変わりません。けれども、重ねられない荷物の上の空きにはほかの荷物を載せられないので、体積で見た積載率は下がり、台数は増えます。どれだけ増えるかは、重ねられない荷物を「ほかの荷物の上には置ける」とするか、「床に直に置く」とするかで変わります。**ここでは、作成者が置いた架空の通販の1日の発送（1日600個、荷物の底はどれも荷台の床の1区画分にそろえ、高さだけを乱数で散らばらせたもの、1台の床は16区画）で、重ねられない荷物の割合を0〜30%に変え、2つの決まりで台数と体積で見た積載率を数えました。荷物の高さの中央値と散らばりを変えた6通りで確かめました。**

すべて作成者が置いた決まりでのシミュレーションです。荷物の形は底をそろえた単純なもので、重さ・届ける順は考えていません。実在の運送会社・車・荷物の決まりを表すものではありません。

関連する記事：1168「小さなファイルがたくさんあると、大きさの合計と実際に使う量はどれだけ違うのか？」は、1件ごとに決まった大きさの区画へ切り上げると、使う量が大きさの合計を上回ることを扱っています。1294「車の台数を重さの上限だけ、または大きさの上限だけで見込むと、両方の上限を守って積んだときの台数よりどれだけ少なく出るのか？」は、重さと大きさの2つの上限があるとき、片方だけで台数を見込むとどれだけ少なく出るかを数えています。1296「車の荷台の半分を超える大きな荷物がいくつかまざると、要る台数と積載率はどう動くのか？」は、荷台の半分を超える大きな荷物は2つを同じ車に載せられないので、その数が大きさの合計とは別に台数の下限になることを数えています。1299「荷物の体積の合計は箱の容量に収まっていても、縦・横・高さで並べると入らない組み合わせはどれだけあるのか？」は、体積の合計では箱に収まる注文が、縦・横・高さで並べると入らない割合を数えています。1304「届ける順に取り出せるよう、あとで届ける荷物を奥に積む決まりを入れると、積載率はどれだけ下がるのか？」は、あとで届ける荷物を奥に積む決まりを入れると、並べる順が縛られて床の積載率が下がり、台数が増えることを数えています。この記事は、上に何も載せられない荷物の上の空きが、体積の合計の見込みに入らない点に絞り、2つの決まりで台数と積載率を比べます。

## 主な結果

### 重ねられない荷物の割合と台数・積載率（`results/base_by_share.csv`、300日の平均）
| 重ねられない荷物 | 決まりA 台数 | 決まりA 積載率 | 決まりB 台数 | 決まりB 積載率 |
|---|---|---|---|---|
| なし | 11.0267台 | 95.69% | 11.0267台 | 95.69% |
| 5% | 11.0267台 | 95.69% | 12.4667台 | 84.63% |
| 10% | 11.0767台 | 95.26% | **13.95台** | **75.64%** |
| 20% | 11.99台 | 88.0% | 16.5033台 | 63.93% |
| 30% | 13.9367台 | 75.71% | 19.04台 | 55.42% |

- **1割まざると、決まりB（床に直に置く）では台数が2.9233台増え、体積で見た積載率は20.0521ポイント下がった**。300日すべてで台数が増えた
- **決まりA（ほかの荷物の上には置ける）では、1割まざっても0.05台（300日のうち5%の日で1台）しか増えず、積載率は0.4319ポイントしか下がらなかった**
- 決まりAで台数が増えはじめたのは、重ねられない荷物の数が区画の数に近づいてから。なしのときの区画の数は170.63で、重ねられない荷物が20%（120個）で+0.9633台、30%（180個）で+2.91台だった。決まりAでは1区画に1つまでなので、区画の数は重ねられない荷物の数を下回らない（作りどおり）

### 決まりBで増えた区画と、重ねられない荷物の上の空き（`results/a1297_main.json` の `B_p10_extra_cells_vs_gap_above`）
- 1割のとき、増えた区画は平均42.95区画、重ねられない荷物の上の空き（1−高さの合計）は平均43.047区画分で、比は0.9977だった。日ごとの相関は0.9336
- 決まりBで増える区画は、重ねられない荷物の上の空きの分とほぼ同じになる（ほかの荷物は変わらず詰まるため、ほぼ式どおり）

### 確かめ：6通り（`results/grid.csv`）
- 1割まざったとき、決まりBでは1.91〜3.75台増え、積載率は8.6775〜40.3647ポイント下がった。増えた区画÷上の空きは0.9742〜0.9993だった
- 決まりAでは0.01〜0.58台増え、積載率は0.05〜9.7898ポイント下がった。いちばん増えたのは、荷物が低く（中央値0.12）散らばりの小さい置き方で、区画の数（なしのとき76.7）に対して重ねられない荷物（60個）が多かったとき
- 荷物が高いほど（中央値0.45）、決まりBで増える台数は小さかった（1.91・2.09台）。重ねられない荷物の上の空きが小さいため（作りどおり）

## 注意（言えないこと）
- 架空のデータです。荷物の数、高さの分布、床の区画の数、詰め方、重ねられない荷物の決まりは作成者が置いたもので、結果はこれで決まります
- 荷物の底を1区画分にそろえた単純な形です。底の大きさが違う荷物では、上の空きの使い方が変わります（数えていません）
- 重ねられない荷物は、ほかの荷物と同じ高さの分布から、でたらめに選びました。重ねられない荷物が特に高い・低いときは、決まりBで増える台数も変わります（上の空きの分で決まるので、低いほど増えると考えられます。推測）
- 詰め方は1つだけで、いちばん良い詰め方の台数は数えていません
- 送料・料金の決め方や、どの車を何台用意するかの助言をする記事ではありません
