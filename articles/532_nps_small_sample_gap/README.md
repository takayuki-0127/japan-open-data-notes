# 532 NPS は、回答が50件や200件のとき、本当は同じ店どうしでも何ポイント差が出てしまうのか？（実務の型）

本当の回答の分布（0〜10点）がまったく同じ店を考え、回答の件数を30〜1,000件に変えて NPS（推奨者の割合 − 批判者の割合）を繰り返し計算したフォルダです。同じ店どうしの NPS の差の分布と、差が10ポイント以上になる割合を、シミュレーション（各20,000組）と式の両方で出しました。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A532 | 本当は同じ2店の NPS は、回答件数ごとにどれだけ離れるか | 多項分布（推奨者・中立者・批判者）から件数を引くシミュレーションと、NPS の分散の式 (p₊ + p₋ − (p₊ − p₋)²) / n の比較。本当は同じ20店の架空の回答から、店別の NPS を SQL（DuckDB）でも出し、Python と一致するか確かめる | `src/a532_nps_gap.py`、`src/02_nps_by_store_duckdb.sql`、`src/01_nps_by_store_tsql.sql`（T-SQL 版、未検証） |

## 主な結果（本当の分布：推奨者40%・中立者35%・批判者25%、本当の NPS +15）
- **1店の NPS の標準偏差**：30件 14.5、50件 11.2、100件 7.9、200件 5.6、500件 3.5、1,000件 2.5ポイント（式とシミュレーションはほぼ一致）
- **同じ店どうしの差が10ポイント以上になる割合**：30件 64.9%、50件 55.4%、100件 40.0%、200件 21.8%、500件 4.6%、1,000件 0.5%
- **差の大きさ（絶対値）**：50件ずつなら中央値 10.0、上位1割は 26.0ポイント以上。200件ずつなら中央値 5.5、上位1割は 13.0ポイント以上
- 9割の確率で差を10ポイント未満に収めるには、正規近似で1店あたり約340件が要る
- **本当は同じ20店を並べると**：50件ずつで NPS は −2〜+38（幅40ポイント）、200件ずつで +6.5〜+24（幅17.5ポイント）
- SQL（DuckDB）で出した店別の NPS は、Python と40行すべて一致

## データ
- `data/fictional_responses_20stores.csv`：本当の分布が同じ20店の架空の回答（seed 532）。50件ずつと200件ずつの2通り。列は n_per_store・store・score（0〜10点）

## 注意（言えないこと）
- 架空のデータ。本当の分布（推奨者40%・批判者25%）は作成者が置いたもので、実在の店や業種の値ではない。推奨者と批判者の割合が違えば、標準偏差も変わる（両方が多いほど大きい）
- 回答は店の客から無作為に集まると置いている。回答する人の偏り（満足した人ほど答える、など）は入れていない
- ここで見たのは「偶然の振れ」だけ。差があるかの判断には、振れの幅（上の式）と並べて読むことを勧めるが、どの幅なら意味のある差かは用途で決まる
- 「10ポイント以上」の判定は、件数が少ないと NPS がとびとびの値になるため、正規近似より少し多めに出る
- T-SQL 版は SQL Server 本体では動かしていない（未検証）
