# 01 取得

## 令和7年国勢調査（e-Stat、ブラウザで取得）

政府統計のサイトは作業環境から直接取れないため、Chrome で e-Stat のページを開き、ページの中で Excel を読み込み（SheetJS 0.18.5）、必要な部分だけを CSV の文字列にして JSON に書き出した（`data/raw/` に同梱）。各ファイルは次の URL で取れる。

`https://www.e-stat.go.jp/stat-search/file-download?statInfId=<ID>&fileKind=0`

| 中身 | statInfId | 使った部分 | 書き出し先 |
|---|---|---|---|
| 人口等基本集計（原数値）第2-7表 男女、年齢（5歳階級及び3区分）、国籍総数か日本人別人口－全国、都道府県、市区町村（2000年（平成12年）市区町村含む） | 000040506431 | 国籍総数・男女総数の行（全地域） | `f120_census2025_raw.json` の `t2_7` |
| 同 第1-2表 男女別人口、2020年の人口（組替）、面積及び人口密度など－全国、都道府県、市区町村（人口集中地区） | 000040506424 | 全行 | 同 `t1_2` |
| 同 第1-1表（同、市区町村） | 000040506423 | 全行（確認用） | 同 `t1_1` |
| 同 第4-3表 男女、年齢（5歳階級）、配偶関係別人口（15歳以上）－全国、都道府県、市区町村 | 000040506438 | 全国・都道府県の行 | 同 `t4_3` |
| 不詳補完値（参考表）令和7年 第4-3表（同） | 000040506666 | 全国の行 | `f120_census_hokan_marital.json` の `t4_3_hokan2025` |
| 不詳補完値（参考表）令和2年国勢調査に関する不詳補完値（遡及集計）第4-3表（同） | 000040317857 | 全国の行 | 同 `t4_3_hokan2020` |

- 公開日はいずれも 2026-09-29。取得は 2026-10-29。
- 第2-7表の「（旧：○○）」の行は「令和2年10月1日現在の境域に基づいて、平成12年10月1日時点の市区町村に組み替えた令和7年の値」（表の注記）。2000年の 3,252 市町村すべてに値があり、合計は全国の 122,972,528 人と一致した。上九一色村だけは2つの今の市町村にまたがる（北部 162人＋南部 800人）ので足した。
