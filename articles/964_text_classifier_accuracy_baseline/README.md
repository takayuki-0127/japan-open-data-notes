# 964 文章を自動で分類したときの正解率は、何と比べればよいのか？（文章の数字）

問い合わせの文章を自動で「配送」「返品」などに分けたとき、「正解率89%」と聞くと高く見えます。けれども、問い合わせの7割が「配送」なら、何も読まずに全部「配送」と答えるだけで正解率は70%になります。**ここでは、作成者が乱数で語を並べて作った架空の店への問い合わせ（正しい分類と分類ごとの割合を作成者が置いたもの）を、作成者が書いた簡単な数え方の分類器で分け、その正解率を「全部いちばん多い分類と答える」「割合どおりにでたらめに答える」と比べ、分類ごとの当たりも数えました。**

文章は、作成者が書いた語の一覧（一般の語30個と、分類ごとの手がかりの語15個ずつ）から乱数で並べただけの短文です。実在の問い合わせの文、外部の辞書や文章を区切る道具、出来合いの分類の道具は使っていません。

## 主な結果

### 基本の置き方（最多「配送」70%、手がかり0.2、100回の平均、`results/methods_base.csv`）
| 答え方 | 正解率 | 分類ごとの当たりの平均 | κ | 会員登録（5%）の当たり |
|---|---|---|---|---|
| 分類器（分類の多さを足さない） | 82.54% | 81.65% | 0.6719 | 80.53% |
| 分類器（分類の多さを足す） | **89.1%** | 76.29% | 0.7584 | **57.5%** |
| 全部いちばん多い分類と答える | **70.2%** | 25% | 0 | 0% |
| 学習用の割合どおりにでたらめに答える | 52.58% | 24.89% | −0.0009 | 4.51% |

- **分類の多さを足す分類器の正解率89.1%は、全部「配送」と答えるだけの70.2%より18.9ポイント高いだけだった**。分類の多さを足さないほうは82.54%で、差は12.34ポイント
- 割合どおりにでたらめに答えたときの正解率は、割合の2乗の和（0.7²＋0.15²＋0.1²＋0.05²）の式で52.5%になり、数えた値52.58%と合った（**式どおり**）
- 分類の多さを足すと正解率は82.54%から89.1%に上がったが、いちばん少ない「会員登録」の当たりは80.53%から57.5%に下がった。多い分類に寄せて答えるので、多い「配送」の当たり（95.81%）が上がり、少ない分類を拾わなくなる
- 正解率と、分類ごとの当たりの平均では、2つの分類器の順が逆になった（正解率は足すほうが上、当たりの平均は足さないほうが上）

## 注意（言えないこと）
- 架空のデータです。分類の割合、手がかりの語の数と濃さ、ほかの分類の語が混ざる割合、件数は作成者が置いたもので、正解率はこれで決まります。全部最多と答えるのとの差は置き方で−0.01〜+57.32ポイントまで動くので、18.9ポイントという値そのものに重みはありません。言えるのは「正解率は、最多の割合と並べて読む」という向きです
- 全部最多と答えたときの正解率が最多の割合と同じになること、割合どおりにでたらめに答えたときの正解率が割合の2乗の和になることは、式どおりです。新しく数えたのは、この簡単な分類器で、分類の多さを足すかどうか・確かめ用の割合で、正解率と分類ごとの当たりがどう分かれるかです
- 「正しい分類」は作成者が置いたもので、間違いがないと置きました。実際には人が付けた正解にも揺れがあり、そのときは正解率の上限が下がると推測します
- 分類器は、作成者が書いた語の回数を数えるだけの簡単なものです。ほかの分類のやり方は比べていません。どの分類器がよいか、どの物差しを使うべきかの助言はしません。少ない分類を拾いたいか、全体の正解を増やしたいかで、見る物差しは変わります
- 関連する記事：915（検査員によって合否が違うとき、一致率と κ が何を表すか）は、同じ「偶然でもそろう分」を工場の検査で扱っています。911（検査で「不良」と出た品物は本当に不良か）と904（「〜の人の8割が」と「8割は」）は、少ないものを当てるときの読み違いを扱っています。同じ企画の963は「特徴的な言葉」の数え方を扱っています。この記事は、正解率を何と比べるかに絞りました同じ企画の967「問い合わせの件名だけで分けると、本文と比べて何がずれるのか？」は、同じ問い合わせのどこ（件名か本文か）を読んで分けるかで、分類ごとの割合と当たりがずれることを扱っています。
