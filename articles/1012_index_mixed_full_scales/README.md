# 1012 10点満点と100点満点の項目を混ぜると、何が起きるのか？（指数とスコア）

10点満点の項目と100点満点の項目をそのまま足して合計点を作ると、100点満点の項目が合計点をほとんど決めてしまいます。では、満点をそろえて（100点満点を10で割って）から足せば、項目は同じ重みになるのか。**ここでは、作成者が乱数で作った架空の店200軒の覆面調査（接客・清潔さ・品ぞろえは10点満点、待ち時間の短さは100点満点。店ごとの本当の良さを作成者が置いたもの）で、そのまま足す・満点をそろえて足す・平均と標準偏差でそろえて足すの3通りで、各項目が合計点にどれだけ効くか、意図した順位とどれだけ合うかを数えました。**

意図は「4項目を同じ重みで見る」と作成者が置きました。合計点の散らばりのうち各項目が受け持つ割合（以下「効き方」）が、それぞれ25%になるのが意図どおりです。

## 主な結果

### 1回分（`data/stores.csv`）
- 点の散らばり（標準偏差）は、接客1.342点・清潔さ1.17点・品ぞろえ1.366点・待ち時間の短さ5.875点。待ち時間の短さは49〜86点の中にあった
- そのまま足した合計点と待ち時間の短さの相関は0.9417だった
- 待ち時間の短さの効き方は、そのまま足すと75.13%、満点をそろえると10.94%、平均と標準偏差でそろえると26.06%だった

### やり方ごと（基本の置き方、1,000回の平均、`results/methods_base.csv`）
| やり方 | 待ち時間の短さの効き方 | 式の値 | 10点満点の項目1つの効き方 | 意図した順位との順位相関 | 意図した上位20軒のうち入った数 |
|---|---|---|---|---|---|
| そのまま足す | **78.61%** | 78.95% | 7.13% | 0.8019 | **11.534軒** |
| 満点をそろえて足す | **10.79%** | 11.05% | 29.74% | 0.9217 | 14.562軒 |
| 平均と標準偏差でそろえて足す | 25.17% | 25% | 24.94% | 0.9386 | **15.186軒** |
| （比べる相手）待ち時間の短さだけ | 100% | 100% | 0% | 0.5913 | 7.947軒 |

- **そのまま足すと、100点満点の待ち時間の短さが合計点の散らばりの78.61%を受け持った**（意図は25%）。10点満点の3項目は、1つ7.13%しか効かなかった
- **満点をそろえて足すと、今度は待ち時間の短さが10.79%に沈んだ**。待ち時間の短さは、満点に対する点の散らばりがほかの項目の半分と置いたため（平均の標準偏差は、10点満点の項目1.316〜1.32点、待ち時間の短さ6.434点）
- 効き方は、満点ではなく点の散らばり（標準偏差）と項目どうしの相関で決まる（式どおり。表の式の値との差は最大0.34ポイント）
- 平均と標準偏差でそろえると、効き方は各25%前後になり、意図した順位との合い方も3通りでいちばん良かった。**ただし、これは意図を「本当の良さを同じ重みで」と置いたことの写しです**。満点どおりの重み（100点満点の項目を10倍重く見る）を意図するなら、そのまま足すのが意図どおりになる
- 上位20軒の当たりは、そのまま足すと11.534軒、平均と標準偏差でそろえると15.186軒だった。調べる人の見方の揺れがあるので、どのやり方でも20軒にはならない

## 注意（言えないこと）
- 架空のデータです。点の散らばり（傾き）、項目どうしの相関、調べる人の見方の揺れは作成者が置いたもので、効き方はこれで決まります。表のとおり、満点をそろえたときの効き方は置き方で2.32〜68.58%まで動きます
- 効き方が満点でなく散らばりで決まることは、式から決まる性質です。新しく数えたのは、満点をそろえても効き方が意図から大きく外れうる幅と、そのとき意図した上位がどれだけ入れ替わるかです
- 平均と標準偏差でそろえるやり方が意図に合ったのは、意図を「本当の良さを同じ重みで」と置いたからです。どの重みが正しいかは、点を何に使うかで決まり、ここでは決めません。どのやり方がよいかの助言もしません
- 平均と標準偏差でそろえると、店の顔ぶれが変わるたびに物差しが変わります。年をまたいで比べるときの問題は扱っていません
- 関連する記事：808（5段階と10段階と「おすすめ度0〜10」）は、同じ満足度が段階の数でどう見えるかを扱っています。939（項目の重みで順位が入れ替わる）は、重みを決めたうえでの順位の動きを扱っています。同じ企画の1005（項目を足す前のそろえ方で順位は変わるか）はそろえ方どうしの順位の違い、1011（外れた値1つで合計点はどれだけ動くか）はそろえ方と外れた値を扱っています。1005 の「最大値で割る」は満点をそろえるのに近いやり方で、効き方が散らばりで決まる点も同じですが、あちらは4通りのそろえ方で1位・上位5機種が入れ替わるかを数えています。似た項目の数で効き方がずれる話は 1008、物差しの下の端で掛け算の効き方が変わる話は 1015 です。この記事は、満点の違う項目を混ぜたときの「効き方」に絞りました
