# 940 去年高かった人の点が下がるのは、本当に下がったのか？（人事評価）

前年の評価がいちばん高かった人たちの点が、今年は下がることがよくあります。「気がゆるんだ」「表彰されて満足した」と読まれがちですが、1年の評価点には本当の働きぶりのほかに、その年の評価者の見方やたまたまの出来事による振れが入っています。前年に上位だった人は、振れが上に出ていた人が多く、その分は今年は付いてきません（平均への回帰）。**ここでは、作成者が乱数で作った架空の会社の社員400人（本当の働きぶりを作成者が置き、基本は2年で変えないとしたもの）で、前年の上位1割の点が今年どれだけ下がって見えるか、指導や表彰が効いたように見えるか、本当に下がった人を2年の点から見つけられるかを数えました。**

1年目に活躍した新人が2年目に下がる「2年目のジンクス」の大きさと、その見込み方は関連する記事 830、シーズンの前半と後半でトップがどれだけ残るかは 826 で扱っています。この記事は、評価点で「本当に下がった人」を見分けられるか、前年との差で指導や表彰の効き目を読むと何が起きるかに絞ります。同じ企画の 944 は、その年の上司評価で人を分けると自己評価とのずれに同じ仕組みで形が出ることを、936 は前年実績×1.1の目標で前年の振れの大きかった人ほど達成率が下がることを、943 は「2年連続でA」の条件が年ごとの振れを除き、続く上司の甘さを残すことを数えています。

## 主な結果

### 例の1年（400人、本当の働きぶりは変えていない）
| | 前年の点（平均） | 今年の点（平均） |
|---|---|---|
| 前年の上位1割（40人） | 75.73 | **66.98** |
| 前年の下位1割（40人） | 43.93 | 51.57 |
| 全員 | 59.91 | 60.57 |

- 前年の上位1割の本当の働きぶりは平均67.74点だった。前年の75.73点と本当の働きぶりとの差は、振れの上乗せの分で、今年の66.98点は本当の働きぶりに近かった
- 前年の上位1割の85.0%が今年は下がり、62.5%が5点以上下がった。下位1割の82.5%は上がった
- 前年と今年の点の相関は0.517だった

### 1,000回で（本当の働きぶりは変えていない）
| | 値 |
|---|---|
| 前年の上位1割の、前年の点（平均） | 74.85 |
| 今年の点（平均） | 67.44 |
| 本当の働きぶり（平均） | 67.40 |
| 今年との差（平均） | **−7.41点**（10〜90%の範囲 −9.06〜−5.90） |
| 今年下がった人の割合 | 83.6% |
| 5点以上下がった人の割合 | **62.6%** |
| 平均へ寄せた見込みの差（平均） | −7.42点 |
| 前年の下位1割の今年との差（平均） | +7.42点 |
| 全員の今年との差（平均） | −0.01点 |

- 前年の上位1割は、本当の働きぶりが同じでも平均7.41点下がり、62.6%が5点以上下がった。今年の点は本当の働きぶり（67.40点）とほぼ同じだった
- 下がり幅は、式「−（1−確かさ）×（上位の前年の平均−全員の平均）」の値（−7.42点）と一致した。下がる大きさそのものは式どおりの結果です
- 前年の順位の帯ごとに見ると、上位0〜5%は−8.74点、上位40〜60%は−0.01点、下位5%（95〜100%）は+8.77点だった（`results/change_by_band.csv`、図2）

### 効き目0の指導と表彰が、効いたように見えるか（1,000回の平均）
| 比べ方 | 見かけの効き目 |
|---|---|
| 指導した前年の下位1割の差（+7.32点）−それ以外の人の差（+0.03点） | **+7.29点** |
| 表彰した前年の上位1割の差（−7.42点）−それ以外の人の差 | **−7.45点** |
| 前年の下位2割をでたらめに半分ずつ分け、指導あり−指導なし | −0.06点（10〜90%の範囲 −2.34〜+2.07） |

- 前年との差で比べると、効き目0の指導は7.29点効いたように、効き目0の表彰は7.45点悪くしたように見えた
- 前年の点が同じくらいの人をでたらめに分けて比べると、見かけの効き目は−0.06点で、ほぼ0に戻った

### 本当に下がった人（全員の1割、6点下げた）を見つけられるか（1,000回の平均）
| 「5点以上下がった」の数え方 | 前年の上位1割で拾った割合 | 上位1割の変わらない人のうち拾われた割合 | 上位1割の本当に下がった人のうち拾われた割合 | 上位1割で拾った人のうち本当に下がった人 | 全員の変わらない人のうち拾われた割合 | 全員で拾った人のうち本当に下がった人 |
|---|---|---|---|---|---|---|
| 前年の点と比べる | 64.6% | **62.2%** | 86.1% | 13.2% | 27.8% | 17.9% |
| 平均へ寄せた見込みと比べる | 28.0% | **25.0%** | 55.6% | 19.5% | 24.8% | 19.9% |

- 前年の点と比べると、前年の上位1割では、本当は変わらない人の62.2%が「5点以上下がった」に入った。上位1割で拾った人のうち、本当に下がった人は13.2%だった
- 平均へ寄せた見込みと比べると、上位1割の変わらない人が拾われる割合は25.0%に下がった。けれども全員で見ると、変わらない人が拾われる割合は27.8%から24.8%にしか下がらず、拾った人のうち本当に下がった人は19.9%だった
- 見込みと比べる方法は、上位の人ばかりを拾う偏りを直す。1年の振れ（標準偏差6点）が本当の下がり（6点）と同じくらいあるので、1年の差だけで本当に下がった人を見分けることはできなかった

## 注意（言えないこと）
- 架空のデータです。本当の働きぶりの散らばり、1年の振れの大きさ、本当に下がった人の割合と下がり幅は作成者が置いたもので、結果はこれで決まります。前年の上位1割の下がり幅は、振れの置き方で−2.34〜−18.61点と動きました。実際の会社の評価を表すものではありません
- 平均へ寄せた見込みには、置いた確かさ（0.5）をそのまま使いました。実際には確かさは分からず、過去の年どうしの相関などから見積もる必要があり、見積もりの外れの分だけ見込みも外れます
- 振れは毎年でたらめに出ると置きました。同じ評価者が続けて付けることによる年をまたいだ癖、評価者の交代、本当の働きぶりの少しずつの変化は入れていません
- 指導や表彰に効き目があるかどうかは言えません。この記事は、効き目0と置いても前年との差では効いたように見える、ということを数えただけです
- 給与・処遇の決め方、評価の制度の良し悪しについては何も言えません
