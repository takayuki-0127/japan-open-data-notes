# 880 平均の処理時間が同じでも、ばらつきが大きいと待ちは？（待ち時間と混雑）

窓口の混み具合を「1人あたり平均何分」と「1時間に何人来るか」だけで見積もると、1人ごとの時間のばらつきが抜け落ちます。平均が同じでも、ときどきとても長い用件が混ざると、その後ろに並んだ人がまとめて待たされます。**ここでは、作成者が乱数で作った架空の店の受付窓口（窓口1つ、用件の時間はどの置き方でも平均4分にそろえ、ばらつきだけを作成者が変えたもの）で、待ち時間の平均と、長く待つ人の割合がどれだけ変わるかを数えました。**

混み具合（利用率）が8割を超えると待ちが急に伸びる話は関連する記事 874、平均の待ちと10分以上待つ人の割合は 873、窓口を1人増やしたときの減り方は 882 で扱っています。874 でも処理時間のばらつきを確かめの1つとして式で見ましたが、この記事は、利用率を同じにしたまま「用件の時間のばらつき」だけを変えたときに絞り、1日で閉まる窓口・来方の違い・長く待つ人の割合・短い用件の人の待ちまで数えます。

## 主な結果

### 用件の時間のばらつきと待ち時間（利用率0.75・でたらめに来る・1日8時間×2,000日、各約18万人）
| 用件の時間 | 変動係数 | 待ちの平均 | 待ちの中央値 | 待ちの90%点 | 15分以上待った人 | 待たずに済んだ人 |
|---|---|---|---|---|---|---|
| 全員4分 | 0.00 | **5.79分** | 3.57分 | 14.99分 | 9.98% | 25.91% |
| ばらつき小 | 0.50 | 6.86分 | 4.05分 | 18.00分 | 14.19% | 26.54% |
| ばらつき中 | 1.00 | 10.72分 | 5.49分 | 29.02分 | 26.03% | 27.39% |
| 1割が17.5分 | 1.165 | 12.11分 | 4.63分 | 33.92分 | 30.77% | 27.84% |
| 20人に1人が42分 | 2.232 | **25.12分** | 4.31分 | 74.04分 | **42.90%** | 31.60% |

- 用件の時間の平均はどれも4分（乱数の結果で3.999〜4.012分）で、来る人数も同じなのに、待ちの平均は5.79分から25.12分まで変わった。20人に1人が42分かかる置き方では、全員4分のときの4.34倍、ばらつき中（指数分布）でも1.85倍だった
- 変わったのは主に平均と長い待ちの側で、待ちの中央値は3.57〜5.49分の間に収まった。待たずに済んだ人はむしろ少し増えた（25.91%→31.60%）。ばらつきが大きいと「すぐ済む人」と「長く待たされる人」に分かれる
- 長い用件の人だけが待つのではない。20人に1人が42分の置き方では、2分で済む用件の人も平均25.07分待った（長い用件の人は25.98分）。来た順に並ぶので、待ちは自分の用件の長さとほぼ関係なく、前にいる人の用件で決まる

### 確かめ：利用率×来方（9通り、各1,000日。全員4分のときの何倍か）
| 利用率 | 来方 | 全員4分の待ちの平均 | ばらつき中 | 20人に1人が42分 |
|---|---|---|---|---|
| 0.6 | でたらめ | 2.92分 | 1.89倍 | 4.91倍 |
| 0.6 | 予約に近い | 0.40分 | 6.88倍 | **30.28倍** |
| 0.6 | まとまって来る | 7.75分 | 1.32倍 | 2.50倍 |
| 0.75 | でたらめ | 5.90分 | 1.73倍 | 4.18倍 |
| 0.75 | 予約に近い | 1.05分 | 5.67倍 | 20.79倍 |
| 0.75 | まとまって来る | 12.78分 | 1.36倍 | 2.35倍 |
| 0.9 | でたらめ | 12.52分 | 1.62倍 | 3.08倍 |
| 0.9 | 予約に近い | 3.63分 | 3.68倍 | 9.35倍 |
| 0.9 | まとまって来る | 23.43分 | 1.21倍 | **1.94倍** |

- 9通りすべてで、待ちの平均は「全員4分＜ばらつき小＜ばらつき中＜1割が17.5分＜20人に1人が42分」の順だった
- 何倍になるかは、置き方で1.94〜30.28倍（20人に1人が42分）と大きく動いた。予約に近い来方では、全員4分ならほとんど待たないので、ばらつきの分がそのまま待ちになり倍率が大きい。まとまって来る来方では、来方のばらつきで待ちがすでに長いので、倍率は小さい（全9通り×5つは `results/sensitivity_days.csv`）

### 確かめ：ずっと開け続けたときの平均と、待ち行列の式（でたらめに来る）
| 利用率 | 全員4分（乱数／式） | ばらつき中（乱数／式） | 20人に1人が42分（乱数／式） |
|---|---|---|---|
| 0.6 | 3.00／3.00分 | 6.01／6.00分 | 17.95／17.94分 |
| 0.75 | 6.01／6.00分 | 12.02／12.00分 | 36.05／35.88分 |
| 0.9 | 18.12／18.00分 | 35.82／36.00分 | 109.98／107.64分 |

- ずっと開け続けたときの待ちの平均は、ポラチェック・ヒンチンの式「待ちの平均＝利用率÷(1−利用率)×(1＋変動係数の2乗)÷2×用件の平均」の値と、15通りすべてで0.991〜1.022倍の範囲で合った。**ばらつきで待ちが伸びるのは、この式どおりの結果**で、新しく見つけたことではない。式によれば、待ちの平均は「1＋変動係数の2乗」に比例して伸びる
- 1日8時間で朝は空から始めると、待ちの平均は式の値より短くなった（利用率0.75で、全員4分は5.79分対6.00分、20人に1人が42分は25.12分対35.88分）。ばらつきが大きいほど列ができ上がるまで時間がかかり、1日の中では式の値まで届かないためと考えられる（推測）

## 動かし方
```
pip install -r requirements.txt
cd src && python a880_variability.py
```
10秒ほどで終わります。`data/ten_days_same_arrivals.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約5秒）
- ずっと開け続けたときの待ちの平均は、15通りすべてで待ち行列の式の0.991〜1.022倍だった
- 利用率と来方の9通りすべてで、ばらつきの大きい順に待ちの平均が長かった。倍率は1.94〜30.28倍と、来方と混み具合で大きく動いた

## データ
- `data/ten_days_same_arrivals.csv`：同じ来方の10日分（利用率0.75、でたらめに来る）で、5通りの用件の時間とその待ち。day・customer・arrive_min（受付開始から何分後に来たか）・service_<置き方>（用件の時間）・wait_<置き方>（待ち時間）。置き方の名前は const（全員4分）・g05（ばらつき小）・exp（ばらつき中）・mix10（1割が17.5分）・mix5（20人に1人が42分）

## 注意（言えないこと）
- 架空のデータです。用件の時間の形、来る人数、来方は作成者が置いたもので、結果はこれで決まります。とくに「何倍になるか」は、来方と利用率で1.94〜30.28倍と大きく動きます
- 窓口は1つ、来た順に受けると置きました。長い用件を別の窓口や別の時間に分ける、窓口を増やす、といった手当ては入れていません（窓口を増やす話は関連する記事 882）
- 列の長さを見て帰る人、待ちが長くなると来なくなる人はいないと置きました
- 実在の店や窓口を表すものではありません
