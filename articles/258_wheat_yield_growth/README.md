# 258 小麦の10a当たり収量は、どれだけ上がったのか

農林水産省「作物統計調査」の収穫量累年統計（小麦：全国 1878〜2024年、北海道・都府県 1958〜2024年）を使ったフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A258 | 小麦の10a当たり収量は、どれだけ上がったのか。何が伸びを生んだのか | 全国の10a当たり収量の長期推移と10年平均。1958〜67年平均→2015〜24年平均の伸びを、北海道・都府県それぞれの収量の伸びと、北海道の面積の割合の変化に分ける（シフト・シェア分解、重みは2時点の平均。期間平均は面積で重みづけ）。対数収量から LOWESS（frac=0.3）のトレンドを引いた偏差で、年ごとの揺れを時期別に比べる | `src/a258_wheat_yield.py` |

## 主な結果
- 全国の10a当たり収量は71kg（1878年）→254kg（1960年）→444kg（2024年）。1958〜67年平均 237kg → 2015〜24年平均 442kg で1.87倍（面積で重みづけした平均）
- 同じ期間に、北海道は203→512kg（2.5倍）、都府県は238→348kg（1.46倍）
- 北海道の面積の割合は2.7%（1958〜67年）→57.3%（2015〜24年）。1970年代に急に増えた
- 全国の伸び +205kg の内訳：北海道の収量の伸び +93kg（45%）、都府県の収量の伸び +77kg（38%）、収量の高い北海道の面積の割合が増えた分 +35kg（17%）
- 年ごとの揺れ（トレンドからの偏差の標準偏差）は、全国で1958〜1989年 13.5%、1990〜2024年 10.2%。北海道は21.4%→14.8%、都府県は12.3%→10.8%。小さくはなったが、米（記事254の同じ方法で1990〜2024年 5.4%）の約2倍
- 1990年以降で全国の収量がトレンドより10%以上低かった年は7回（1995・1996・2009・2010・2011・2016・2018年）。いちばん大きいのは2010年の−31.5%（276kg）

## 頑健性
- 比べる期間を変えると内訳の割合は動く。1960〜69年→2010〜19年では +148kg のうち北海道 +72、都府県 +45、面積の割合 +32。1975〜84年→2015〜24年（北海道の割合が増え始めた後から）では +138kg のうち北海道 +103、都府県 +22、面積の割合 +13
- 北海道と都府県の収穫量・面積から全国の10a当たり収量を作り直すと、公表値との差は最大0.5kg
- LOWESS の frac を0.2にしても、全国の揺れは1958〜1989年 13.1%、1990〜2024年 10.1%
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致した

## 注意
- 10a当たり収量は「収穫量÷作付面積」。品種、栽培の技術、気象、病気（赤かび病など）、収穫期の雨などがまとめて入っていて、このデータでは分けられない
- 都府県の伸びが小さく見えるのは、梅雨と収穫期が重なる地域が多いことと関係する可能性がある（推測）
- 北海道の面積の割合が増えた理由（転作、畑作の広がりなど）は、このデータでは分からない
- 揺れの比べは「トレンドからの偏差」で、トレンドの引き方で値は変わる。米との比べは同じ方法・同じ期間（1990〜2024年）で計算した
