# 895 問い合わせから契約までの割合は、どこで落ちているのか？（副業の数字）

問い合わせから契約までの流れを「問い合わせ → 返信あり → 打ち合わせ → 見積もり提出 → 契約」のように段に分けると、どの段で落ちているかを見たくなります。ところが、件数がいちばん減る段と、次へ進む割合がいちばん低い段は同じとは限りません。また、段が進むには日数がかかるので、数える日にまだ途中の人をどう扱うかで、後ろの段の割合が低く出ます。**ここでは、作成者が乱数で作った架空のフリーランスの人の問い合わせ（段ごとの本当の割合と、次の段までの日数を作成者が置いたもの）で、3つの数え方と「件数の減り」で、割合のいちばん低い段を当てられるかを、問い合わせの件数（月5・15・50件）ごとに4,000人分数えました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A895 | 段ごとの割合を数えたとき、割合のいちばん低い段を当てられるか。数え方と件数でどう変わるか | 架空のフリーランスの人に来る問い合わせ。段ごとに次の段へ進む本当の割合は、問い合わせ→返信あり 60%、返信→打ち合わせ **50%（いちばん低い）**、打ち合わせ→見積もり提出 85%、見積もり→契約 55%（問い合わせ全体の14.0%が契約）。次の段までの日数は平均2・7・5・15日の指数分布。問い合わせは毎日でたらめに来る（ポアソン過程）。数えるのは6か月（180日）で、その前の3か月分の問い合わせも流れに入っている。「横ばい」は毎月同じ件数、「増えている」は前の3か月が月の件数の半分、数える6か月で半分から2倍まで一様に増える。数え方は3つ：①同じ月の件数で割る（6か月に起きた「次の段」の件数÷6か月に起きた「その段」の件数）、②問い合わせの月で追う・すぐ数える（6か月に来た問い合わせを追い、6か月目の末日までに進んだ段だけ数える）、③問い合わせの月で追う・60日待つ（問い合わせから60日以上たった人だけを追う）。ほかに、件数の減り（その段の件数−次の段の件数）がいちばん大きい段を選ぶ読み方。当たりは「いちばん低く出た段が、本当にいちばん低い段（返信→打ち合わせ）だった割合」。割合の出せない段（分母が0）がある回は外れとした。4,000人分。確かめとして、問い合わせの件数（月5・15・50件）×日数の長さ（0.5・1・2倍）×見積もり→契約の本当の割合（52・55・65%）×増え方（横ばい・増えている）の54通りを各1,500人分。seed 895 | `src/a895_funnel.py` |

## 主な結果

### 問い合わせ100件あたりの流れ（置いた本当の割合）
| 段 | 問い合わせ | 返信あり | 打ち合わせ | 見積もり提出 | 契約 |
|---|---|---|---|---|---|
| 件数 | 100.0 | 60.0 | 30.0 | 25.5 | 14.03 |
| 前の段から進む割合 | | 60% | **50%** | 85% | 55% |
| 前の段からの減り | | **−40.0件** | −30.0件 | −4.5件 | −11.47件 |

- 件数がいちばん減るのは問い合わせ→返信（−40.0件）で、割合がいちばん低い段（返信→打ち合わせ、50%）とは違った。前の段の件数が多いほど、同じ割合でも減る件数は大きくなる。これは置いた割合からの計算で決まる
- そのため「件数の減りがいちばん大きい段」を選ぶと、割合のいちばん低い段に当たったのは、月15件・6か月で12.0%だけだった（月5件で22.7%、月50件で2.2%。件数が多いほど、いつも問い合わせ→返信を選ぶ）

### 数え方ごとの段の割合（月15件、4,000人の平均）
| 数え方 | 問い合わせ→返信 | 返信→打ち合わせ | 打ち合わせ→見積もり | 見積もり→契約 |
|---|---|---|---|---|
| 本当の割合 | 60% | 50% | 85% | 55% |
| ①同じ月の件数で割る（横ばい） | 60.1% | 50.0% | 85.1% | 55.4% |
| ②問い合わせの月で追う・すぐ数える（横ばい） | 59.3% | 48.1% | 82.5% | **50.1%** |
| ③問い合わせの月で追う・60日待つ（横ばい） | 60.0% | 50.0% | 85.1% | 54.9% |
| ①同じ月の件数で割る（増えている） | 59.3% | 47.7% | 82.3% | **50.1%** |
| ②すぐ数える（増えている） | 59.1% | 46.9% | 81.2% | **47.8%** |
| ③60日待つ（増えている） | 60.2% | 49.9% | 85.2% | 54.7% |

- 問い合わせの月で追ってすぐ数えると、日数のかかる見積もり→契約（平均15日）が55%から50.1%に下がり、いちばん低い段（50%）と並んだ。まだ返事を待っている人を「進まなかった」と数えてしまうため
- 同じ月の件数で割る数え方は、問い合わせが横ばいなら本当の割合に近かった。問い合わせが増えているときは、後ろの段ほど低く出た（見積もり→契約が50.1%）。分子は前の、件数が少なかったころの問い合わせから来るため
- 60日待つ数え方は、増えていても本当の割合に近かったが、使える問い合わせが6か月のうち4か月分に減る

### いちばん低い段を当てた割合（6か月分、4,000人）
| 問い合わせの件数 | ①同じ月の件数で割る | ②すぐ数える | ③60日待つ | 件数の減りがいちばん大きい段 |
|---|---|---|---|---|
| 月5件（横ばい） | 46.3% | 44.5% | 44.2% | 22.7% |
| 月15件（横ばい） | **59.5%** | **52.8%** | **56.8%** | 12.0% |
| 月50件（横ばい） | 74.2% | 60.6% | 70.1% | 2.2% |
| 月15件（増えている） | 54.7% | 51.0% | 55.8% | 10.7% |

- 本当の割合が50%と55%で5ポイントしか違わないと、月15件・6か月分の記録では、どの数え方でも当たりは5〜6割だった
- すぐ数える数え方は、見積もり→契約をいちばん低い段と取り違えやすかった（月15件・横ばいで43.6%の人が見積もり→契約を選んだ。同じ月の件数で割る数え方では34.2%）
- 月50件でも、すぐ数える数え方の当たりは60.6%で、件数を増やしても取り違えは残った
- 1か月分だけで同じ月の件数で割ると、月15件では当たりは40.6%だった。1か月の見積もり→契約の割合は、10〜90%の範囲で0〜125%と振れた（同じ月の件数で割るので、100%を超える月もある）

### 確かめ：件数×日数の長さ×見積もり→契約の本当の割合×増え方（54通り、各1,500人）
| 見積もり→契約の本当の割合 | ①同じ月の件数で割る | ②すぐ数える | ③60日待つ | 件数の減り |
|---|---|---|---|---|
| 52%（いちばん低い段と2ポイント差） | 33.3〜59.6% | 17.9〜52.7% | 31.8〜58.4% | 1.2〜24.5% |
| 55%（基本、5ポイント差） | 41.5〜75.7% | 29.9〜70.5% | 37.4〜71.9% | 1.1〜23.8% |
| 65%（15ポイント差） | 54.1〜98.1% | 50.6〜97.2% | 47.2〜93.8% | 1.1〜23.9% |

（いちばん低い段を当てた割合の幅。件数・日数の長さ・増え方を動かした18通りずつ）

- すぐ数える数え方の当たりは、54通りのうち52通りで同じ月の件数で割る数え方より低かった。60日待つ数え方と比べると、低かったのは29通りで、どちらが当たるかは置き方で入れかわった（60日待つと使える件数が減るため）
- すぐ数える数え方での見積もり→契約の下がり方は、日数を半分にすると−3.3〜−1.6ポイント、基本の日数で−6.1〜−4.3ポイント、2倍にすると−12.7〜−10.1ポイント（横ばい）。増えているときは2倍で−17.1〜−13.4ポイントだった
- 同じ月の件数で割る数え方の見積もり→契約は、横ばいなら−1.6〜+1.6ポイントに収まり、増えているときは−11.5〜−1.8ポイントだった
- 60日待つ数え方も、日数を2倍（見積もり→契約が平均30日）にすると−7.7〜−4.8ポイント下がった。60日では待ちきれない人が残るため
- 件数の減りで選ぶ読み方は、54通りすべてで当たりが24.5%以下だった

## 動かし方
```
pip install -r requirements.txt
cd src && python a895_funnel.py
```
7秒ほどで終わります。`data/one_person_inquiries.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約7秒）
- 「件数の減りがいちばん大きい段は、割合のいちばん低い段と違う」は、置いた割合からの計算で決まる結果で、新しく数えたものではない。数えたのは、件数の減りで選ぶとどれだけ外れるか（54通りすべてで24.5%以下）と、数え方・件数で当たりがどれだけ変わるか
- すぐ数える数え方で後ろの段が低く出ることは、日数の長さを変えた3通りすべてで同じ向きだった（横ばいでも増えているときでも）。下がり方の大きさは、置いた日数の長さでほぼ決まる
- 当たりの数字（月15件で53〜60%）は、いちばん低い段と2番目の段の差を5ポイントと置いたための値で、54通り（件数・日数・増え方も動かした）では、差が15ポイントなら47〜98%、2ポイントなら18〜60%まで動いた

## データ
- `data/one_person_inquiries.csv`：架空の1人（月15件・横ばい）の、前の3か月と数える6か月に来た問い合わせ。inquiry_id・day_inquiry（問い合わせの日。0〜90日目が前の3か月、90〜270日目が数える6か月）・day_reply・day_meeting・day_quote・day_contract（その段に進んだ日。進まなかった段は空）。数える日（270日目）より後に進んだ段も、本当の結果として入れてある

## 注意（言えないこと）
- 架空のデータです。段の分け方、段ごとの本当の割合、次の段までの日数は作成者が置いたもので、結果はこれで決まります。実在の人の問い合わせを数えたものではありません
- 段ごとの割合は、問い合わせの中身によらず同じと置きました。実際には、問い合わせの来かた（紹介か、仲介サービス経由か）や案件の大きさで割合も日数も違うはずで、混ぜて数えると別のずれが出ます（推測）
- 「いちばん低い段」を見つけることと、そこを直すべきかは別のことです。どの段に手を入れるのがよいか、割合がいくらなら良いかは扱いません
- 断りの連絡があった人と、返事がないまま止まった人は分けていません。断りが記録に残る場合は、すぐ数えるずれは小さくなるはずです（推測）
- 関連する記事 889 は、応募の採用率（1つの割合）が何件で読めるかと、採用されたところで数えるずれを数えています。この記事は、いくつかの段の割合を並べたとき、いちばん低い段を当てられるかを数えています
