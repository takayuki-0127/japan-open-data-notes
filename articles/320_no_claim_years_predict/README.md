# 320 無事故の年数は、次の年の事故をどこまで当てるのか

「無事故が続いた人ほど保険料を下げる」という等級の考え方が、どのくらい根拠のあるものかを、人ごとの事故の起こしやすさが分かる架空の契約者10万人で数えたフォルダです。特定の保険商品や会社の等級制度ではなく、一般的な考え方だけを扱います。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A320 | 続けて無事故だった年数ごとに、次の年の事故率はどれだけ違うか。その差は、人ごとの事故の起こしやすさの差の大きさでどう変わるか。無事故の年数は、次の年に事故がある人をどこまで当てられるか | 人ごとの起こしやすさ（年あたりの平均件数）をガンマ分布で置き、年ごとの件数をポアソン分布で11年分つくる（件数全体は負の二項分布になる）。10年目の終わりの「続けて無事故だった年数」ごとに11年目の事故件数を数え、式の値と比べる。当てる力は AUC で測る | `src/a320_no_claim_years.py` |

## データの作り方（架空）
- 契約者10万人。平均の事故率は年8%（100人あたり年8件）
- 人ごとの起こしやすさの差は、変動係数1.0が基本（半分の人は年5.5%以下、上位1割は年18%以上）。比べるために、差なし・0.5・1.5 も作った
- 起こしやすさは11年間変わらないと置いた。乱数の種は320。実在の契約者の数字ではありません

## 主な結果（人ごとの差が変動係数1.0）
| 10年目の終わりの状態 | 人数の割合 | 11年目の事故（100人あたり） | 平均との比 |
|---|---|---|---|
| 前の年に事故があった（無事故0年） | 7.5% | 15.9件 | 2.01倍 |
| 無事故3年 | 4.9% | 12.6件 | 1.60倍 |
| 無事故5年 | 3.8% | 10.8件 | 1.37倍 |
| 無事故9年（1年目に事故） | 2.6% | 8.7件 | 1.11倍 |
| 10年ずっと無事故 | 55.7% | 4.4件 | 0.55倍 |

- **10年ずっと無事故の人は、次の年の事故が平均より45%少ない**（式の値は4.44件、数えた値は4.37件）。前の年に事故があった人は平均の2.0倍
- **9年無事故でも、1年目に事故があった人は平均より1割多い**。この作り（起こしやすさが変わらない）では、事故が最近か昔かは関係なく、10年間の回数で決まる。直近に事故がある人の率が高いのは、その中に何回も起こした人が多いため
- **差の大きさは、人ごとの起こしやすさの差で決まる**。10年無事故の人の「平均より低い割合」は、差なしで0%（数えた値は0.9%）、変動係数0.5で16%、1.0で45%、1.5で63%
- **当てる力（AUC）**は、無事故の年数0.64、10年間の事故の回数0.66、本当の起こしやすさを知っている場合でも0.76。差がなければどれも0.50。無事故の年数は回数とほぼ同じ力を持つが、上限そのものが高くない
- 10年無事故の人は全体の56%で、11年目の事故の31%を起こしていた。人数が多いので、事故の3件に1件は「10年無事故だった人」から出る

pip install -r requirements.txt

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures がバイト単位で一致した
- 10年無事故の人の事故率は、式 a/(b+10)（a＝1/変動係数²、b＝a/平均）と、3つの場合とも近い（0.0437 対 0.0444、0.0664 対 0.0667、0.0301 対 0.0286）

## 注意（言えないこと）
- すべて架空のデータです。45%や2.0倍という大きさは、人ごとの差の置き方（変動係数1.0）と平均の事故率（8%）で決まります。実際の差がどのくらいかは、ここからは分かりません
- 人の起こしやすさは変わらないと置きました。年齢や経験、事故のあとの運転の変化、車や走る距離の変化で起こしやすさが動くなら、最近の事故ほど重く見るべきことになります。その場合は試していません
- 事故の有無だけを見ていて、事故の大きさ（金額）は扱っていません。小さな事故で保険を使わない、という行動も入れていません
- 一般的な考え方の確かめで、特定の等級制度や割引率を評価するものではありません。保険料や契約について助言するものでもありません
