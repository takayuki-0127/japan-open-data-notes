# 959 文章が長い人ほど、同じ言葉が多く出るのはなぜか？（長さでそろえる）（文章の数字）

長い文章ほど、同じ言葉は多く出ます。そのため、短い文章の多い窓口と長い文章の多い窓口で「遅い」の回数を比べると、長い窓口のほうに不満が多く見えます。反対に、語数で割って長さをそろえると、今度は長い窓口が少なく見えることがあります。**ここでは、作成者が乱数で決まり文句を組み合わせて作った架空のパンの通販の感想文（短い「注文フォームの感想欄」と長い「メール」の2つの窓口で、「届くのが遅い」と感じた人の本当の割合を作成者が置いたもの）で、「遅い」の数え方を4つ比べ、長い文章で同じ言葉が多く出る理由を、くり返し・別の意味での使用に分けて数えました。**

文章はすべて作成者が決まり文句を乱数で組み合わせて作ったもので、実在の口コミ・SNS の文は使っていません。外部の辞書や単語を区切る道具も使っていません。

## 主な結果

### 窓口の比べ（200回の平均、本当の割合はどちらも20%）
| 数え方 | フォーム | メール | メール÷フォーム |
|---|---|---|---|
| 本当の割合（遅いと感じた人） | 19.98% | 20.0% | 1.001倍 |
| 100件あたりの延べ回数 | 26.24回 | 52.39回 | **1.996倍** |
| 1万語あたりの回数 | 836.6回 | 461.3回 | **0.551倍** |
| 「遅い」が出た件の割合 | 23.82% | 33.24% | 1.395倍 |
| 1〜3文の件だけで出た割合 | 23.82% | 26.52% | 1.113倍 |

（1件の平均：フォーム1.658文・3.137語、メール6.0文・11.36語）

- 本当の割合は同じなのに、延べ回数ではメールが1.996倍、1万語あたりでは0.551倍に見えた。同じ記録が、数え方で「メールのほうが不満が多い」とも「少ない」とも読める
- 「遅い」が出た件の割合でも、メールが1.395倍に見えた。長いメールほど、別の意味の「遅い」（「遅い時間に受け取りました」）が入る機会が多いため
- 1〜3文の件だけに絞っても1.113倍だった。同じ帯の中でも、メールは平均2.62文、フォームは1.658文で、長さがそろいきっていない

### なぜ長い文章で「遅い」が多く出るか（メール2万件、長さの帯ごと）
| 文の数 | 件数 | 本当の割合 | 100件あたりの延べ回数 | 1万語あたり | 出た件の割合 | 感じた人100人あたりの回数 | 感じていない人で出た割合 |
|---|---|---|---|---|---|---|---|
| 1〜3文 | 2,464 | 18.99% | 30.88回 | 623.4回 | 25.57% | 127.6回 | 8.12% |
| 4〜6文 | 9,867 | 19.44% | 45.82回 | 477.6回 | 31.08% | 171.6回 | 14.45% |
| 7〜9文 | 6,287 | 19.64% | 62.40回 | 428.2回 | 36.77% | 222.1回 | 21.32% |
| 10文以上 | 1,382 | 20.41% | 79.59回 | 390.8回 | 41.32% | 271.6回 | 26.27% |

- 本当の割合は長さの帯によらずほぼ20%（作成者がそう置いた）なのに、延べ回数は1〜3文の30.88回から10文以上の79.59回に増えた
- 理由は2つ。1つは、感じた人が残りの文で同じことをくり返すこと（感じた人100人あたり127.6回→271.6回）。もう1つは、感じていない人も長い文章ほど別の意味で「遅い」を使うこと（出た割合8.12%→26.27%）
- メール2万件の「遅い」の内訳は、最初の1回37.87%・くり返し28.16%・別の意味33.96%。フォーム2万件では75.62%・7.7%・16.68%だった
- 1万語あたりでは、長いほど少なく見えた（623.4回→390.8回）。不満は1人1回は必ず書くが、長い文章ではほかの語が増えるので、語数で割ると薄まる

### 確かめ：くり返し r・別の意味 e・メールの本当の割合（18通り、各50回）
| メールの本当の割合 | 数え方 | メール÷フォーム（9通りの範囲） | メールのほうが多いと読んだ通り |
|---|---|---|---|
| 20%（本当の比1.0倍） | 100件あたりの延べ回数 | 0.99〜2.6倍 | |
| | 1万語あたりの回数 | 0.28〜0.71倍 | |
| | 出た件の割合 | 0.99〜1.61倍 | |
| | 1〜3文の件だけで出た割合 | 0.99〜1.17倍 | |
| 14%（本当の比0.7倍） | 100件あたりの延べ回数 | 0.69〜2.11倍 | **9通り中8通り** |
| | 1万語あたりの回数 | 0.19〜0.58倍 | 9通り中0通り |
| | 出た件の割合 | 0.68〜1.45倍 | 9通り中6通り |
| | 1〜3文の件だけで出た割合 | 0.67〜0.99倍 | 9通り中0通り |

- メールの本当の割合のほうが低くても、延べ回数では9通り中8通りで「メールのほうが多い」と読んだ。逆向きの結論になる
- くり返しも別の意味もない（r＝0・e＝0）とき、延べ回数と出た件の割合は本当の比どおりになった（本当の比1.0倍のとき0.993倍、0.7倍のとき0.691倍）。一方、1万語あたりは0.278倍で、語数の比（フォームとメールの平均語数の比）をそのまま写した式どおりの値になった
- 1万語あたりは、向きはいつも当てたが、差を大きく見せた（本当0.7倍のとき0.19〜0.58倍）。1〜3文の件だけで出た割合は向きを外さなかったが、別の意味の「遅い」が多いと差が見えにくくなった（e＝0.06で0.966〜0.991倍）
- 全行は `results/sensitivity_r_e_true.csv`

## 注意（言えないこと）
- 架空のデータです。文の数の分布、くり返しの確率 r、別の意味の確率 e は作成者が置いたもので、結果はこれで決まります。延べ回数でメールが多く見えるのは、作成者がくり返しと別の意味の使用を置いたことの写しで、どちらもなければ本当の比どおりになりました。延べ回数の比は置き方で0.99〜2.6倍、1万語あたりは0.28〜0.71倍と動きました（本当の比1.0倍のとき）
- 不満を持った人は必ず1回は書くと置きました。短い欄では書ききれずに書かない人がいる、といった窓口ごとの書きやすさの違い（871「自由記述の多い意見は、全体の多い意見なのか？」の題材）は入れていません
- 「遅い」が別の意味か不満かは、作成者が文を作ったので分かっています。実際の文章では、語を数えるだけでは見分けられません
- どの数え方を使うべきかは、何を知りたいか（不満を持った人の割合か、不満の強さか）で変わります。この記事が示せるのは、長さの違う文章どうしを延べ回数や語数あたりで比べると、置き方によって向きまで変わることだけです
- 長さの帯をそろえて比べても、帯の中の長さの違いが残ります。帯を細かくすると件数が減り、揺れが大きくなります（推測）

関連する記事：837「反応率の分母（フォロワー・表示・再生）で、良い投稿は入れ替わるのか？」は、何で割るかで並びが変わることを SNS の投稿で扱っています。この記事は、語数で割ると1人1回の不満が薄まることを扱います。957「単語の数え方（区切り方）で、多い言葉の順位は変わるのか？」と958「ワードクラウドの大きい文字は、本当に多い意見なのか？」は、同じ延べ回数を使い、区切り方と言い方の分かれ方で数がずれることを扱っています。同じ企画の963「少ない件数の言葉の『特徴的な度合い』は、なぜ極端に出るのか？」は、2つのグループで語の出る割合を比べるとき、回数の少ない語がたまたまで大きく振れることを扱っています。この記事は、同じ語でも、グループごとに文章の長さが違うと比べ方で向きまで変わることを扱います。968「文字数の数え方（文字・バイト・単語）で、何が変わるのか？」は、長さそのものを文字・バイト・単語のどれで数えるかを扱っています。
