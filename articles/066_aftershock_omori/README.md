## もとのリポジトリの説明

以下は、もとのリポジトリ `jma-earthquake-catalog` の README です（同じリポジトリにあったほかの記事の分も含みます）。

### jma-earthquake-catalog：気象庁の震源データ（1919〜2024年、約536万件）で、地震の「大きさと回数の関係」と「余震の減り方」を調べる

気象庁「地震月報（カタログ編）」の震源データ（1919〜2024年、5,358,847件）を使ったリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| E1 | 地震の大きさ（M）と回数の関係（グーテンベルグ・リヒター則）の傾き b値はいくつか。小さな地震をどこまで数えられているか | 年ごとの検知の下限 Mc（最大曲率法＋0.2）、b値の最尤推定（宇津・Aki）とブートストラップの95%区間、b値の安定性で Mc を決める方法（Woessner & Wiemer 2005）、深さ別の b値、M5・M6以上の年間回数 | `src/e1_gr.py` |
| E2 | 大地震のあと、余震はどんな速さで減るか。最大余震は本震よりどれだけ小さいか | 改良大森公式 n(t)=K/(t+c)^p の最尤推定（本震から0.01〜365日）、p のブートストラップ95%区間、下限Mを変えた頑健性、最大余震とのM差（バートの法則） | `src/e2_omori.py` |

#### 主な結果
- **E1**：日本周辺（北緯24〜46度・東経122〜150度）で、最大曲率法の下限（2012〜2024年は M0.6）から b値を推定すると 0.50 と低く出る。下限を上げていくと b値は大きくなり、M4.5以上で安定して 0.96（95%区間 0.94〜0.99）。2001〜2010年も M4.4以上で 0.94（0.92〜0.97）とほぼ同じ。海の遠い所では小さな地震を数えきれていないため、下限を低くすると b値が小さく出る。深さ別（2012〜2024年）では、0〜30km が 0.81、30〜70km が 0.94、70〜300km が 1.10、300km以上が 0.85。検知の下限は 1980年の M2.7 から 2001年に M0.6 まで下がり、2017〜2020年は M0.5、2021年以降は M1.1〜1.3。M5以上は1年に平均118回、M6以上は13回（1960〜2024年、2011年を除く）で、比は 9.1 倍。2011年は M5以上 764回、M6以上 115回
- **E2**：p値は、東北地方太平洋沖地震（M4.5以上、半径350km）1.07（1.03〜1.11）、熊本地震（M2.5以上、半径50km）1.08（1.05〜1.10）、能登半島地震（M2.5以上、半径100km）1.03（1.01〜1.05）で、どれも1に近い（余震の数はほぼ経過時間に反比例して減る）。下限Mを0.5・1.0上げても p は 1.02〜1.06。最大余震と本震のM差は、東北 1.4（M7.6、本震の29分後）、熊本 1.4（M5.9、本震の約1時間半後）。能登は1年以内なら 1.0（2024年11月26日の能登半島西方沖 M6.6）、30日以内なら 1.5（M6.1）

#### 動かし方
元データ（年ごとの zip、展開すると約500MB）はリポジトリに入れていません。https://www.data.jma.go.jp/eqev/data/bulletin/hypo.html から各年の zip（例：https://www.data.jma.go.jp/eqev/data/bulletin/data/hypo/h2024.zip）をダウンロードし、展開したファイル（h2024 など）を `data/raw/` に置いてください。

```bash
pip install -r requirements.txt
cd src
python e1_gr.py
python e2_omori.py
```

#### データ
| ファイル | 中身 |
|---|---|
| data/raw/h1919〜h2024（各自ダウンロード） | 震源1つごとの固定長の記録：発震時刻、緯度・経度、深さ、マグニチュード、最大震度、地域名など（ファイル形式は上のページの「震源ファイルフォーマット」） |
| results/e1_*.csv・e2_*.csv | 年ごとの Mc、b値、年間回数、大森公式の推定値 |

#### 注意
- 震源データは、観測網の整備（1997年10月からの大学・防災科学技術研究所などのデータの一元化、2000年代の高感度地震観測網の整備など）や処理方法の変更で、小さな地震の数え方が年によって違います。年ごとの地震の「数」をそのまま比べることはできません
- b値は、使う地震の下限 Mc の選び方で大きく変わります。海の遠い所の小さな地震は数えきれていないため、日本周辺をまとめると、Mc を低くしたときの b値は小さく出ます。深さ別の b値も、下限 Mc がそれぞれ違います
- 余震は「本震からの距離」と「深さ」で選んでいるので、同じ範囲で起きた別の地震や誘発された地震も含みます。能登半島地震の最大余震としたM6.6（2024年11月26日）は、余震域の端に近い所で起きた地震です
- 改良大森公式は本震から0.01日（約15分）以降に当てはめています。本震直後は地震が重なって数えきれないため、c値にはその影響が含まれます
- マグニチュードは気象庁マグニチュードで、東北地方太平洋沖地震だけはモーメントマグニチュード（9.0）です
