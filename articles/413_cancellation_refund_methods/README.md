# 413 途中で解約した契約に返す保険料は、日割りと短期率でどれだけ違うのか（実務の型）

架空の1年契約3万件で、途中解約のときに返す額を、日割り・月割り・短期率の3通りで計算して比べたフォルダです。315（1年分の保険料を月に分ける）は途中解約を扱いませんでした。

**短期率の表（`data/short_rate_table_fictional.csv`）は、説明のために作成者が作った架空のものです。実在の約款の表ではありません。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A413 | 返す額は、決め方でどれだけ違うか。解約の時期で差はどう変わるか | 日割り・月割り（経過月数は切り上げ）・短期率（架空の表）を Python で計算し、同じ SQL を DuckDB で実行して一致を確かめる。解約の時期と、表の形を動かす | `src/a413_refund.py`、`src/01_refund_tsql.sql`（T-SQL 版、未検証） |

## 主な結果
- **返す額の合計（年間保険料の合計に対する割合）**
  - 解約が一様：日割り50.1%、月割り46.1%（日割りより−8.1%）、短期率32.5%（−35.2%）
  - 契約の初めに集まる：83.6%、79.3%（−5.2%）、63.8%（−23.7%）
  - 満期の近くに集まる：16.5%、12.7%（−22.7%）、7.9%（−52.0%）
- **経過月数ごとの日割りとの差（解約が一様）**：月割りは1か月目−4.3%、6か月目−7.3%、11か月目−33.0%、12か月目−100%。短期率は1か月目−15.3%、6か月目−44.3%、11か月目−58.8%
- **返す割合の差の最大**（年間保険料に対して）：月割り8.6ポイント、短期率31.3ポイント（123日目）
- **解約までの日数の平均を動かす**（20日→180日）：月割り−5.4%→−6.4%、短期率−16.3%→−30.5%
- **表の形を動かす**（使ったとみなす割合＝（経過日数÷365）の a 乗、解約が一様）：a=1.0 で0%、0.9 で−5.2%、0.8 で−11.1%、0.7 で−17.6%、0.6 で−24.9%、0.5 で−33.3%

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した
- DuckDB の SQL で出した3通りの返す額が、Python の計算と3万件すべてで一致する（コード内の assert）

## データ
- `data/cancellations_uniform.csv`：架空の1年契約3万件（解約が一様な場合。始期・年間保険料・経過日数・解約日と、3通りの返す額）。作成者が乱数で作成（seed 413）
- `data/short_rate_table_fictional.csv`：説明用に作った架空の短期率の表

## 注意（言えないこと）
- 短期率の表は架空。−35.2%は、この表を置いたときの数字で、実際の契約の差ではない
- どの決め方を使うべきかは約款で決まる。約款や税の扱いについての助言ではない
- 全部の契約が解約したとして計算した。解約する割合、保険料と解約の時期の関係は入れていない
- うるう年をまたぐ契約の分母、月払いの契約、保険金を支払ったあとの解約は扱っていない
- T-SQL 版は SQL Server 本体では動かしていない（未検証）
