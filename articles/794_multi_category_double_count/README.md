# 794 1つの商品が2つのカテゴリに入る表でカテゴリ別に売上を足すと、全体の何倍になるのか（実務の型）

商品とカテゴリの対応が「1品に1カテゴリ」とは限りません。「飲料」でもあり「季節もの」でもある、のように1品が複数のカテゴリに入る対応表（多対多）を売上に結合すると、その商品の売上は入っているカテゴリの数だけ数えられます。カテゴリ別の表を縦に足すと、全体の売上より大きくなります。**ここでは、作成者が乱数で作った架空の商品300品と売上明細20,000件で、3通りの足し方を比べました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A794 | 多対多の対応表で、カテゴリ別の合計は全体の何倍になるか | 架空の300品。主なカテゴリ（飲料・菓子・日用品・冷凍）に1つ入り、半分ほどは横断のカテゴリ（季節もの・ギフト・限定品・まとめ買い）にも1〜2つ入る。売上明細20,000件。そのまま結合して合計・主なカテゴリだけ・カテゴリの数で按分を DuckDB（1スレッド）で出し、pandas の値と一致を確認。seed 794 | `src/a794_multicat.py`、`src/02_category_duckdb.sql`、`src/01_category_tsql.sql` |

## 主な結果

| 足し方 | カテゴリ別の合計 | 全体の売上との比 |
|---|---|---|
| 全体の売上 | 40.9百万円 | 1 |
| そのまま結合してカテゴリ別に足す | **73.5百万円** | **1.80倍** |
| 主なカテゴリだけ | 40.9百万円 | 1 |
| カテゴリの数で按分 | 40.9百万円 | 1 |

- 300品のうち149品（50%）が2つ以上のカテゴリに入っていた。この商品は売れ筋が多く、売上の60%を占めた
- そのまま結合して足すと、カテゴリ別の合計は全体の1.80倍になった
- 主なカテゴリだけで数えると、横断のカテゴリ（季節もの など4つ）はどれも0になる
- 順位も変わった。「まとめ買い」は、そのまま結合では3位、按分では5位。「日用品」は6位から4位になった

## 動かし方
```
pip install -r requirements.txt
cd src && python a794_multicat.py
```
数秒で終わります。`data/product_category.csv`・`data/sales.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダで流し直し、results・figures・data がバイト単位で一致した
- DuckDB の3つの足し方が、pandas で出した値とカテゴリごとに一致すること（assert）
- 主なカテゴリだけ・按分の合計が、全体の売上と一致すること

## データ
- `data/product_category.csv`：架空の商品とカテゴリの対応表（product_id・category・is_primary）
- `data/sales.csv`：架空の売上明細（line_id・product_id・amount）

## 注意（言えないこと）
- 架空のデータです。倍率は、複数のカテゴリに入る商品の割合と売れ方で決まります
- 「そのまま結合」がまちがいとは限りません。「季節ものに入る商品の売上はいくらか」を知りたいなら、カテゴリごとの値は正しいです。まちがいなのは、それを縦に足して全体と見ることです。按分は合計を合わせるための決め方の1つで、「本当の」カテゴリ別の売上ではありません
- T-SQL 版は未検証です
