# F33 人の移動は距離でどれだけ減るのか？ 都道府県間の引っ越しを重力モデルで読む

看板記事 F33。貿易の分析で定番の「重力モデル」を、都道府県の間の引っ越しに当てはめる。ほとんどゼロのないデータでも、PPML（ポアソン疑似最尤）と対数の最小二乗法で距離の効き方が大きく違うこと、37年で距離の効き方がどう変わったか、新幹線でつながると移動が増えたかを確かめる。

## 問い

- 県庁所在地どうしの距離が2倍になると、移動は何割減るか
- その効き方は1989年から2025年でどう変わったか
- 隣の県・同じ地方であること、新幹線網でつながることは、移動を増やすか

## データ

| データ | 内容 | 使い方 |
|---|---|---|
| 総務省「住民基本台帳人口移動報告」長期時系列表 第11表（1989〜2011年：statInfId 000014898777〜000014898799、2012〜2025年：000040430819） | 都道府県×都道府県の移動者数（日本人移動者） | 47×46組×37年＝79,994件。ゼロは2件だけ |
| smartnews-smri/japan-topography（国土数値情報 行政区域 2021 の簡略版、CC BY 4.0） | 市区町村の境界 | 県庁所在地（東京都は新宿区）の代表点、都道府県の代表点、隣接の判定 |

- 距離は県庁所在地の代表点どうしの大圏距離（km）。頑健性で都道府県の代表点どうしの距離も使う
- 隣接は、簡略化した境界を 50m 広げて接していれば隣接とした（向きなしで87組。北海道・沖縄は隣接なし）
- 同じ地方は8地方区分
- 新幹線網：フル規格の新幹線の駅がある県を、本州からの網につながった年から「つながった」とした（3月までの開業はその年、4月以降は翌年から）。九州新幹線は全線開業の2011年、西九州新幹線（長崎）は網につながっていないので含めない。頑健性でミニ新幹線（山形・秋田）も含める

## 手法

| 段階 | 内容 |
|---|---|
| 年ごとの断面 | 出発県・到着県の固定効果（人口や魅力をまとめて吸収）＋距離の対数。PPML と対数の最小二乗法（ゼロを除く）を比べる |
| まとめた推定 | 出発県×年・到着県×年の固定効果（構造重力モデル）＋距離・隣接・同じ地方。PPML（pyfixest の fepois）。標準誤差は向きなしの県の組でクラスター |
| 期間ごとの変化 | 距離×期間（6期間）を入れて、1989〜95年と2020〜25年の差をワルド検定 |
| 新幹線 | 出発県×年・到着県×年・向きつきペアの固定効果を入れて、つながる前後の変化だけで推定。イベントスタディも作る |
| 残差 | 2025年の予測と実際の比。東京圏（1都3県）に出入りする移動の、実際÷予測の推移 |

## 主な結果

- **距離が2倍になると、移動は34%減る（PPML）**：まとめた推定の距離の弾力性は −0.60（95%区間 −0.69〜−0.52）。対数の最小二乗法では −1.04（−1.10〜−0.98）で、2倍で51%減る計算になる。ゼロは79,994件のうち2件だけなので、違いはゼロの扱いではなく、ばらつきの大きさが移動の多さで違う（不均一分散）ことから来ている
- **隣の県は1.61倍、同じ地方は1.25倍**：距離をそろえても、隣接していると移動は61%（39〜88%）、同じ地方だと25%（7〜46%）多い
- **距離の効き方は37年でわずかに弱まった**：PPML の弾力性は 1989〜95年 −0.614 → 2020〜25年 −0.580（差 +0.033、標準誤差 0.017）。年ごとの断面では、出発・到着の固定効果だけの PPML が −0.86（1989年）→ −0.83（2025年）、対数の最小二乗法が −1.30 → −1.16
- **弱まったのは東京圏が絡む移動**：東京圏を発着とする移動を除くと、弾力性は −0.86 で、1989〜95年 −0.861 と 2020〜25年 −0.856 とほぼ変わらない。東京圏への移動は遠くからも来るので、含めると全体の距離の効き方が小さく見える
- **東京圏への流れは、重力モデルの予測より2割多い**：東京圏以外から東京圏への移動は予測の1.28倍（1989年）→1.22倍（2025年）、東京圏から外への移動は1.37倍→1.31倍
- **予測より多い組・少ない組（2025年、移動者500人以上）**：多いのは島根→鳥取（6.3倍）、鳥取→島根（5.7倍）、高知→香川（3.9倍）、青森→宮城（3.1倍）、富山→石川（3.0倍）など。少ないのは福岡→宮城（0.38倍）、福島→大阪（0.38倍）、広島→北海道（0.42倍）、北海道→福岡（0.47倍）など、離れた地方の中心どうし
- **新幹線でつながっても、移動が増えた形跡は見えない**：ペアの固定効果を入れた推定は −0.11（−0.16〜−0.06、約10%減）。ただしイベントスタディでは、つながる前から相対的に減り続けており、つながった後の減少はその続きに見える。期間中につながった432組だけで、つながる時期の違いだけを使うと +0.05（−0.03〜+0.13）で0をまたぐ。比べる相手で符号が変わるので、「増えた」とも「減った」とも言えない

## 頑健性

| 設定 | 距離の弾力性（95%区間） |
|---|---|
| 基本（県庁所在地の距離、1989〜2025年） | −0.60（−0.69〜−0.52） |
| 距離を県の代表点で測る | −0.65（−0.75〜−0.55） |
| 東京圏を発着とする移動を除く | −0.86（−0.94〜−0.78） |
| コロナ期（2020〜2022年）を除く | −0.61（−0.69〜−0.52） |
| 隣接・同じ地方を入れない | −0.86（−0.92〜−0.80） |
| 北海道・沖縄を除く | −0.61（−0.70〜−0.52） |
| 対数の最小二乗法（log(移動者+1)） | −1.03（−1.09〜−0.97） |
| 対数の最小二乗法（ゼロを除く） | −1.04（−1.10〜−0.98） |

- 期間の比較（1989〜95年 → 2020〜25年）：基本 −0.614 → −0.580、県の代表点の距離 −0.656 → −0.627、北海道・沖縄を除く −0.624 → −0.589、東京圏を除く −0.861 → −0.856
- 新幹線（PPML、ペアの固定効果つき）：基本 −0.110、ミニ新幹線を含める −0.108、東京圏を除く −0.097、1995年以降だけ −0.066、コロナ期を除く −0.110、期間中につながったペアだけ +0.049（0をまたぐ）

## 言えないこと

- 引っ越しの理由（仕事・進学・結婚など）は分からない。距離の効果には、仕事や家族のつながり、情報の近さも混ざっている
- 住民票を移した移動だけを数えている。住民票を移さない進学・単身赴任は入っていない
- 1989〜2011年と2012〜2025年は別のファイルだが、どちらも日本人移動者。外国人の移動は入っていない
- 鉄道の所要時間は使っていない（直線距離だけ）
- 新幹線の推定は、つながった県が新幹線の来ない県と違う動き方をしていると崩れる。この記事でも、比べる相手を変えると符号が変わった
- 重力モデルの予測は、47都道府県の平均的な関係から外れているかを示すだけで、「多すぎる」「少なすぎる」という評価ではない
