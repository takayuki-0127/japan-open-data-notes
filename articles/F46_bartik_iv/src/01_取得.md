# 01 取得

`data/raw/f46_ssds_raw.json` は、e-Stat「社会・人口統計体系 市区町村データ」
（https://www.e-stat.go.jp/regional-statistics/ssdsview/municipality ）から、2026年10月27日にブラウザの中で取得しました（キーの登録は要りません）。
画面で一度「表示」したときに送られる `api_get_result`（POST）の `cols`（項目）と `tops`（年度）だけを書き換えて送り直し、返ってきた表を行ごとに保存しています。
画面で「地域：全て選択 → 項目を選択 → 年度を選択 → 表示 → ダウンロード」としても同じ値が取れます。

| JSON のキー | 項目 | 年度 |
|---|---|---|
| `M2009`〜`M2024` | A5101 転入者数、A5102 転出者数（住民基本台帳人口移動報告）、A4101 出生数、A4200 死亡数（人口動態統計） | 各年 |
| `E2014`、`E2016`、`E2021` | C2208 従業者数（民営）と産業大分類別の18項目（C220832〜C220852、経済センサス） | 2014（基礎調査）・2016・2021（活動調査） |
| `P2005`〜`P2020` | A1101 総人口、A1301〜A1303 年齢3区分人口（国勢調査） | 国勢調査の年 |

都道府県単位の参考分析には、F33 で取った住民基本台帳人口移動報告（長期時系列 第11表、都道府県間の日本人移動者）を `data/raw/f33_pref_migration_panel.csv` として再利用しています。
