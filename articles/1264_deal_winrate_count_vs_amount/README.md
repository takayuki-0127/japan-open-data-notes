# 1264 件数で数えた受注率と金額で数えた受注率では、良かった月はどう入れかわるのか？（受注の見込み）

法人向けの商談の受注率は、「受注した件数÷決まった件数」で数えることも、「受注した金額の合計÷決まった商談の金額の合計」で数えることもあります。商談の金額がまちまちだと、2つは一致しません。金額で数えると、その月にいちばん大きい商談が取れたかどうかで値が大きく動きます。どちらで数えるかで、「良かった月」の顔ぶれが入れかわることがあります。**ここでは、作成者が置いた架空の会社の24か月の商談（月ごとの本当の良さ・商談の金額・金額が大きいほど取りにくい効きを作成者が置き、乱数で取れる・取れないを決めたもの）で、件数の受注率と金額の受注率で24か月を並べたとき、276組のうち大小が逆になる組の数と上位3か月の重なりを数え、作成者だけが知っている「本当の月の良さ」の順とどれだけ合うかも数えました。金額の散らばり・金額の効き・月に決まる件数を変えた27通りでも確かめました。**

例の会社・商談・金額は架空のもので、実在の会社の数字を表すものではありません。担当や人を並べて良し悪しを決める形にはしていません（並べるのは月だけです）。売上の目標の立て方、値引き・価格の付け方、評価の決め方の助言はしていません。

関連する記事：1151「当たり率を件数で数えるかデータの量で数えるかで、良し悪しはどう入れかわるのか？」は、キャッシュの当たり率を件数と量で数える違いを、1189「1件が何往復もするとき、件数で数えるか往復の数で数えるかで、忙しい種類の順はどう変わるのか？」は、問い合わせの手間を件数と往復の数で数える違いを扱っています。1266「新しい取引先と前からの取引先をまぜた受注率は、まざる割合が変わるとどう動くのか？」は、件数で数えた受注率が、新しい取引先と前からの取引先のまざる割合で動くことを扱っています。この記事は、商談の受注率に固有の「1件の大きい商談が月の値を動かす」点に絞ります。

## 主な結果

### 基本の置き方（500回、`results/a1264_main.json` の `headline`）
| 比べた2つ | 大小が逆の組（276組中、平均） | 上位3か月の重なり（平均） |
|---|---|---|
| 件数の受注率 と 金額の受注率 | **63.21組**（10〜90%で44.9〜83.0組） | 1.572か月 |
| 件数の受注率 と 本当の月の良さ | 78.41組 | 1.308か月 |
| 金額の受注率 と 本当の月の良さ | 93.47組 | 1.02か月 |

- **件数と金額でいちばん良かった月が同じだったのは、500回のうち35.8%だった**
- 置いた月の良さの順とは、件数の受注率のほうが合った（逆の組78.41組と93.47組。でたらめに並べたときの見込みは138組）
- 受注率の平均は、件数で31.35%、金額で22.6%だった。金額が大きいほど取りにくいと置いたので、金額のほうが低く出るのは置き方どおり。24か月の散らばり（標準偏差）は、件数で0.0921、金額で0.1015だった
- 月の決まった金額のうち、いちばん大きい商談1件が占める割合は中央値13.15%だった。金額の受注率から件数の受注率を引いた差は、いちばん大きい商談が取れた月で平均+0.9ポイント、取れなかった月で平均−10.15ポイントだった
- 対照：金額をすべて同じにすると、2つの受注率は同じ値になり、逆の組は0組だった（作りどおり）

### 1回分の24か月（`data/months_one_set.csv`、`results/a1264_main.json` の `one_set`）
| | 上位3か月 |
|---|---|
| 件数の受注率 | 7・10・24か月目 |
| 金額の受注率 | 4・10・11か月目 |
| 本当の月の良さ | 8・10・11か月目 |

- 件数でいちばん良い月は24か月目、金額でいちばん良い月は11か月目で、11か月目は件数では7番目だった。この1回では276組のうち52組で大小が逆だった

### 確かめ：27通り（各40回、`results/grid.csv`）と月の良さの差（各100回、`results/month_sd.csv`）
- 件数と金額で逆の組は28.45〜87.15組だった。**ほぼ金額の散らばりで決まった**（散らばり0.5で28.45〜38.025組、1.0で55.7〜68.95組、1.5で79.775〜87.15組）。金額の効きと件数を変えても、同じ散らばりの中では大きくは動かなかった
- 本当の月の良さとの逆の組は、件数で57.525〜100.5組、金額で66.675〜111.45組だった。件数のほうが本当の月の良さと合ったのは27通りのうち26通りで、金額のほうが合ったのは1通り（散らばり0.5・効き−0.5・20件）だけだった
- 上位3か月の重なりは1.0〜2.35か月だった
- 月の良さの差を小さく（標準偏差0.1）すると、件数と金額の逆は76.72組、本当との逆は件数で113.82組・金額で122.31組となり、どちらもでたらめ（138組）に近づいた。差を大きく（0.6）すると、それぞれ46.04組・48.42組・65.08組だった

## 注意（言えないこと）
- 架空のデータと、作成者が置いた取れ方です。「本当の月の良さ」は、作成者が置いた月ごとの値で、件数にも金額にも同じように効くと置きました。件数の受注率のほうがこれと合ったのは、この置き方での結果です
- 金額の受注率は「お金の面でどれだけ取れたか」を数えるもので、件数の受注率とは別のものを数えています。どちらを使うべきかは、何を知りたいかで決まり、この記事では決めていません
- 月ごとの商談の顔ぶれ（大きい商談が多い月・少ない月）の偏り、季節の動き、同じ取引先の商談のつながりは入れていません
- 決まった日の数え方（その月に始まった商談か、その月に決まった商談か）は扱っていません
