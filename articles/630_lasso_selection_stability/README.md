# 630 Lasso で選ばれる変数は、データを少し変えるとどれだけ入れ替わるのか（手法の解説・正解の分かるデータで試す）

Lasso は、係数を0に縮めることで変数を選んでくれる回帰です。ただ、どの変数が残るかは、データを少し変えただけで入れ替わることがあります。**ここでは、候補の変数40個のうち本当に効くのは6個（係数0.5）で、効く変数それぞれに「よく似た効かない変数」（相関0.7）がある架空のデータ（150件）を10組作り、交差検証で強さを選んだ Lasso が選ぶ変数が、データの8割を取り出して当て直す50回でどれだけ入れ替わるか、安定選択（半分を100回取り出し、70%以上で選ばれた変数を残す）では何が残るかを数えました。** 数字は置いたデータで決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A630 | Lasso の選ぶ変数はどれだけ入れ替わり、安定選択で何が残るか | scikit-learn の LassoCV（5分割、強さの候補30個）、8割を取り出す50回、ジャカード係数、安定選択（半分×100回、元の CV の強さ、70%以上）。150件・候補40個・10組、seed 630 | `src/a630_lasso_stability.py` |

## 主な結果
- **元のデータで交差検証の Lasso が選んだ変数（10組の平均）**：15.2個。効く6個はどの組でも全部選ばれたが、よく似た効かない列 2.2個、その他の効かない列 7.0個も一緒に選ばれた
- **8割を取り出して当て直すと**：選ばれる数は 8〜39個と大きく動いた。2回の選択の重なり（ジャカード係数）は平均 0.61。効く変数が選ばれた割合は 99.97%、よく似た効かない列は平均 35%、その他の効かない列は平均 28%
- 効かない34個のうち、50回のどこかで一度でも選ばれた変数は 96%（10組の平均）
- **安定選択**：残った変数は平均 8.4個で、効く6個はすべて残り、効かない変数は平均 2.4個（0〜4個）に減った
- 1組目では、効く変数の似た列の1つが 94% の回で選ばれた

```
pip install -r requirements.txt

```

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- 効く6個がどの選び方でもほぼ毎回選ばれること

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 630）
- results の「boot_」で始まる列は、8割を取り出して当て直した50回の結果

## 注意（言えないこと）
- 架空のデータ。変数の数・効き方・相関は作成者が置いたもので、結果はこれで決まる
- 交差検証は予測の当たり方を基準に強さを選ぶので、効かない変数も入りやすい。変数を選ぶ目的なら、強さの選び方そのものを変える方法もある（ここでは扱っていない）
- 安定選択の「70%」は、よく使われる目安の1つを使った
