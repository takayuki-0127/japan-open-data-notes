# 656 同じ店の前と後を比べるとき、対応のない検定にすると、差を見つける力はどれだけ落ちるのか（手法の解説・正解の分かるデータで試す）

同じ店を施策の前と後で測ったデータは「対応のある」データで、店ごとの差（後−前）で検定します。前と後を別々の群とみなす「対応のない」検定にすると、店ごとの水準の差がそのまま雑音として残ります。**ここでは、架空の40店で、全体のばらつきのうち店ごとの水準の差が占める割合（＝前と後の相関 ρ）を0〜0.9で変え、本当の効果0.3（全体の標準偏差の0.3倍）を2つの検定がどれだけ見つけるかを、各3,000回のシミュレーションで数えました。** 数字は置いた前提で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A656 | 対応のある・ない t 検定で、検出力・偽陽性・区間の幅がどれだけ違うか | 対応のある t 検定（店ごとの差）、対応のない t 検定（等分散）。効果0.3と0、ρ=0〜0.9、各3,000回。必要な店の数も数えた。seed 656 | `src/a656_paired.py` |

## 主な結果
- **前と後の相関が高いほど、対応のある検定だけが差を見つける**：ρ=0.5 で対応あり46.6%・なし19.9%、**ρ=0.8 で83.3%・9.9%**、ρ=0.9 で98.5%・4.9%
- **相関が0なら同じ**：25.0%・26.0%
- **効果が0のとき**：対応ありはどの ρ でも4.3〜5.3%（ほぼ5%）。対応なしは ρ が高いと0%に近づく（相関を無視して、ばらつきを大きく見積もるため）
- **95%区間の幅**：対応のない区間は ρ=0.5 で1.39倍、0.8 で **2.2倍**、0.9 で3.1倍
- **検出力80%に要る店の数（効果0.3）**：ρ=0.8 で対応あり40店・なし130店、ρ=0.5 で95店・150店（1,500回のくり返しで5店刻みに探した）

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 656）
- 仮定：店ごとの水準と月ごとの揺れは正規分布、全体の分散は1。効果はどの店も同じ0.3

## 注意（言えないこと）
- シミュレーションの結果。相関と効果の大きさは作成者が置いたもので、結果はこれで決まる
- 前と後の差には、施策以外の時期の違い（季節など）も入る。比べる相手（施策をしなかった店）がいないと、差が施策の効果かどうかは分からない。ここは検定の選び方だけの話
- 店によって効果が違う場合や、外れ値が多い場合は扱っていない
