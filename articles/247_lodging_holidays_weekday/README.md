# 247 日本人の泊まりがけ旅行は、平日に移ったのか

宿泊旅行統計調査は月の値しかないので、曜日ごとの宿泊は分かりません。そこで「休日（土日・祝日・振替休日）の多い月ほど宿泊が多いか」を月の値で調べ、その関係がコロナの前（2015〜2019年）と後（2023〜2025年）で弱まったかを見ました。休日に集中していた旅行が平日に分散したなら、休日の日数の効きは小さくなるはず、という考え方です。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A247 | 日本人の泊まりがけ旅行は、平日に移ったのか | 月の1日あたり延べ宿泊者数（対数）を、月の休日の日数で回帰（月と年のダミーで季節と年の違いを除く。HC1 の標準誤差）。2015〜2019年と2023〜2025年で分け、交差項で差を検定 | `src/a247_holidays.py` |

## 主な結果
- 月の休日は8〜13日の幅で動く（同じ月でも年によって最大3日違う）
- 観光目的の宿泊者が50%以上の施設（観光の宿）に泊まった日本人は、2015〜2019年には休日が1日多い月に1日あたり1.21%多かった（95%区間 ±0.74、p=0.001）。2023〜2025年は+0.03%（±1.19、p=0.96）
- 日本人（全施設）は+0.74%（±0.57）→ −0.23%（±0.88）。出張などの宿（観光目的が50%未満）は+0.33% → −0.38%で、前の期間から有意ではない
- ただし、2つの期間の差を交差項で検定すると、観光の宿の日本人は −0.96%（±1.36、p=0.17）で、統計的にははっきりしない。後の期間は36か月しかなく、区間が広い
- 外国人は区間が広く（2023〜2025年は ±5.7%）、何も言えない

## 頑健性（`results/a247_robustness.csv`）
- 推移表の日本人延べ宿泊者数（2011〜2019年）でも同じ向き：+0.67%（±0.81）。東日本大震災の2011年を除くと+0.48%（±0.43、p=0.03）。2023〜2025年は −0.23%
- 祝日を数えず土日だけ数えると、観光の宿の日本人の2015〜2019年は+0.54%（±1.12）に弱まる。祝日（とくに連休）が効いていた可能性がある（推測）
- 年末年始・ゴールデンウィーク・お盆のある1・5・8・12月を除くと、2015〜2019年は+1.60%（±1.27）、2023〜2025年は −0.38%（±1.45）
- 推移表と年の確定値の全国の月の値（総数）は、2015〜2025年の132か月で差が最大50人泊（丸めの違い）
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致することを確かめた

## 動かし方
```
pip install -r requirements.txt
cd src && python a247_holidays.py   # data/ の CSV から results/・figures/ を作る
python fetch.py             # data/ の CSV を観光庁の Excel から作り直す（任意。ネットにつながる環境で）
```

## データ
- `data/table<n>_national.csv`：観光庁「宿泊旅行統計調査」各年（2015〜2025年）の「1月〜12月分（年の確定値）集計結果」Excel から、全国の行だけを取り出したもの（`src/extract.py`）。month=0 は年計、1〜12 は各月。列名は `src/extract.py` の COLS（total＝総数、tour＝観光目的の宿泊者が50%以上の施設、biz＝同50%未満の施設、s0_9 など＝従業者数の区分、foreign＝うち外国人）
- 施設数（第1表）は各月の値で、年の値は12か月の平均にした
- `data/suii_national_monthly_2011_2025.csv`：同じ調査の「推移表」の都道府県別・月別の延べ宿泊者数（総数・日本人・外国人）を全国に足したもの（記事 F273 の data と同じ表）
- 休日は Python の `jpholiday` で数えた（土日・国民の祝日・振替休日。年末年始の休みは入れていない）

## 注意
- 月の値なので、平日と休日の宿泊を直接は分けられない。「休日の日数の効き」が小さくなったことは、平日に移ったことの一つの手がかりにすぎない
- 延べ宿泊者数は宿のある場所で数えた数で、日帰りの旅行は入らない。出張と観光は施設の区分（観光目的の宿泊者が50%以上か）で分けただけで、一人ひとりの目的ではない
- 2023年はまだ戻りの途中の年で、年のダミーで水準の違いは除いたが、月ごとの戻り方の違いが残る可能性がある
