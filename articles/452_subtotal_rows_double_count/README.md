# 452 小計や合計の行が混ざった表をそのまま足すと、合計は何倍になるのか（実務の型）

消費者物価指数（2020年基準）のウエイトの表は、総合・10大費目・類・品目が1列に並んでいます。この表をそのまま足した合計が本当の合計の何倍になるかと、小計の行を機械で見つける決まりがどれだけ当たるかを数えたフォルダです。311（結合で行が増える）・373（pandas の型）とは別に、1枚の表の中の二重計上だけを扱います。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A452 | 小計の行が混ざった表をそのまま足すと何倍になるか。小計の行は値や名前から見つけられるか | 行の並びと値から本当の階層を決める。そのまま足した合計÷品目だけの合計を、全体と10大費目ごとに出す。小計を見つける決まり（名前・親＝子の和）を、丸めなしの表と丸めた表に当てる。合計は DuckDB の SQL でも出して一致を確かめる | `src/a452_subtotals.py`、`src/01_sum_without_subtotals_tsql.sql`（T-SQL 版、未検証） |

## 主な結果
- **表の行**：744行。品目582行、小計・合計の行146行（総合1、10大費目10、その下の類135）、別掲16行（「生鮮食品を除く総合」などの組み替えた合計と再掲）
- **そのまま足す**：別掲を除いた728行で本当の合計の **4.79倍**、別掲も入れた744行で **9.60倍**
- **品目が数えられる回数**：品目は、自分の行のほかに上の小計の行でも数えられる。4回が133品目（ウエイトの29%）、5回が362品目（64%）、6回が87品目（8%）
- **10大費目ごとの倍率**：光熱・水道、保健医療、教育は3.00倍（小計の段が2つ）。被服及び履物は4.44倍、教養娯楽は4.27倍、住居は4.00倍、食料は3.94倍

| 小計の行を見つける決まり | 表 | 見つけた小計（146行中） | 見逃し | 品目を小計と間違えた行 | 見つけた行を除いて足した合計 |
|---|---|---|---|---|---|
| 名前に「計」「総合」がある行 | — | 2（1%） | 144 | 3 | 3.79倍 |
| 親＝子の和（子は2つ以上） | 丸めなし | 124（85%） | 22 | 0 | 3.08倍 |
| 親＝子の和（子が1つでもよい） | 丸めなし | 108（74%） | 38 | 29 | 2.98倍 |
| 親＝子の和（子が1つでもよい、差0） | 整数に丸めた表 | 55（38%） | 91 | 54 | 4.10倍 |
| 親＝子の和（子が1つでもよい、差は子の数×0.5まで） | 整数に丸めた表 | 91（62%） | 55 | 80 | 3.08倍 |
| 親＝子の和（子が1つでもよい、差0） | 小数1桁に丸めた表 | 64（44%） | 82 | 30 | 3.74倍 |
| 親＝子の和（子が1つでもよい、差は子の数×0.05まで） | 小数1桁に丸めた表 | 103（71%） | 43 | 33 | 3.03倍 |

- **見逃しの中身（丸めなし、子は2つ以上）**：子が1つだけの小計が12行ある（牛乳、卵、電気代、持家の帰属家賃など）。この12行は値が子と同じで、決まりでは見つからない。その上にある小計（乳卵類、食料、住居、総合など10行）も、子の和が合わなくなって見逃す。見逃した22行には総合と10大費目の4つが入るので、見つけた124行を除いても合計は3.08倍のまま
- **丸めで崩れる行**：ウエイトを1万分比の整数に丸めると、小計146行のうち62行（42.5%）で「親＝子の和」が成り立たない。小数1桁でも60行（41.1%）
- **DuckDB**：そのまま SUM した値・品目だけ SUM した値が Python の計算と一致。品目だけの合計は総合の行と一致

## 動かし方

pip install -r requirements.txt
cd src && python a452_subtotals.py     # 数秒

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した
- 品目582行のウエイトの合計が、総合の行と一致する。本当の階層は、どの小計の行でも「親＝子の和」が成り立つ（コード内の assert）

## データ
- `data/cpi2020_weights.csv`：消費者物価指数 2020年基準 品目別価格指数（全国）の表の、列の番号・名前・コード・ウエイト（F209 で整形したものの写し。e-Stat statInfId 000032103844）
- `data/cpi2020_weights_with_levels.csv`：別掲を除いた728行に、深さ・親の行・10大費目の名前を足したもの

## 注意（言えないこと）
- 1つの表での結果。倍率は、表の階層の深さで決まる
- 「親＝子の和」の決まりは、ここで書いた1つの作り方（上から順に、後ろの行を足して自分の値に届けば小計とみなす）。ほかの作り方では当たり方が変わる
- 丸めた表は、ウエイトを総合＝10,000の割合に直して自分で丸めたもの。公表されている1万分比のウエイトの表そのものではない
- コードの列（先頭が0なら類、そうでなければ品目）を使えば、小計の行は決まりなしで分かる。ここでは、そういう列がない表を想定して値と名前だけで試した
- T-SQL 版は SQL Server 本体では動かしていない（未検証）
