### ltc-benefits-japan

厚生労働省「介護保険事業状況報告」年報の保険者別の表を使い、**高齢者（第1号被保険者）1人あたりの介護保険給付費がどの市町村（保険者）で高いか**を、都道府県の差・年齢構成・保険者の規模・5年の伸びに分けて見るリポジトリです。

#### 問い / 手法 / スクリプト

| 問い | 手法 | スクリプト |
|---|---|---|
| 1人あたり給付費の高い保険者・県はどこか。年齢構成でどこまで説明できるか。規模や5年の伸びは？ | 保険給付支払額（支払義務額累計）÷第1号被保険者数（年度末）。分位・県別集計、log(1人あたり給付費)を75〜84歳・85歳以上の割合に回帰（被保険者数で重み付け）、規模別のばらつき、2019→2024年度の伸び | `src/a132_per_capita.py` |

#### 主な結果（2024年度）

- 全国の1人あたり給付費は **31.2万円**（2019年度 28.0万円から11.4%増）。保険者（1,573）の中央値は31.0万円、下から10%が25.3万円、上から10%が37.4万円。
- 都道府県では大阪府37.6万円が最も高く、島根県・和歌山県35.0万円、京都府34.6万円が続く。低いのは栃木県26.4万円、茨城県26.7万円、埼玉県27.5万円（最高と最低で1.43倍）。保険者の差のうち県の違いで説明できるのは26%。
- 85歳以上の割合が1ポイント高いと1人あたり給付費は約4%高い。年齢構成（75〜84歳・85歳以上の割合）で保険者の差の35%を説明できる。年齢構成から見込まれる値と比べて最も高いのは大阪市（1.45倍）。
- 第1号被保険者が1,000人未満の保険者は標準偏差9.3万円、10万人以上は3.5万円と、小さい保険者ほどばらつきが大きい。
- 2019→2024年度の伸びは保険者の中央値で8.2%（85%の保険者で増加）。県では大阪府23.1%、埼玉県19.0%、千葉県17.9%が大きく、佐賀県0.9%が最も小さい。伸びと85歳以上の割合の変化の相関は0.63。

#### 動かし方

```
pip install -r requirements.txt
python src/a132_per_capita.py   # data/raw が無ければ data/raw.zip を展開
```

#### データ

- `data/raw.zip`：介護保険事業状況報告（年報）令和元年度・令和6年度の 第2表「保険者別 第1号被保険者数（年度末現在）」、第13表「保険者別 保険給付支払額」（Excel）。e-Stat 政府統計コード 00450351（https://www.e-stat.go.jp/stat-search/files?toukei=00450351）
- `data/insurer_panel.csv`：保険者×年度に整えたもの（被保険者数、年齢3区分、給付費（千円）、1人あたり給付費）
- `results/`：分布、県別、上位・下位、年齢構成で調整した上位、回帰、規模別、伸び

#### 注意

- 給付費は第2号被保険者（40〜64歳）の利用分も含みますが、分母は第1号被保険者数です（全国で給付費の数%程度）。
- 「支払義務額累計」を使いました。年度の区切りは支払いのタイミングで、サービスを使った月とは少しずれます。
- 年齢構成は65〜74・75〜84・85歳以上の3区分だけで調整しています。要介護認定率、施設の多さ、所得、世帯の形などは調整していません。
- 被保険者が数十〜数百人の島の村などは、1人の利用で値が大きく動きます（最低は東京都青ヶ島村の3.7万円）。
- 広域連合で運営している地域は、まとめて1つの保険者です。
