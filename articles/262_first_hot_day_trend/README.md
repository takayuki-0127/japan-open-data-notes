# 262 真夏日（日最高気温30℃以上）になる最初の日は、早くなったのか

気象庁「過去の気象データ検索」の日ごとの値（14地点、1931〜2025年）を使ったフォルダです。262〜266の5本は同じデータ（`data/jma_daily_14st_1931_2025.tsv.gz`）を使っています。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A262 | 真夏日（日最高気温30℃以上）になる最初の日は、早くなったのか | 毎年の最初・最後の真夏日（通し日）を地点ごとに求め、1961〜1990年平均からの差を10地点で平均。直線の傾き（HC1標準誤差）、Theil–Sen、期間平均（1931〜1960・1961〜1990・1996〜2025年）の比較 | `src/a262_first_hot_day.py` |

## 主な結果
- 10地点の平均で見ると、最初の真夏日は1980年代までほぼ横ばいで、1990年代から早くなりました。2020〜2025年は、1961〜1990年の平均より毎年15〜22日早い年が続いています。1931〜2025年の直線の傾きは10年に1.9日（標準誤差0.4日）で、1961年以降は10年に3.5日でした。
- 最後の真夏日は逆に遅くなり、傾きは10年に1.2日。1931〜1960年と1996〜2025年の平均で比べると、地点の中央値で7日遅くなっています。真夏日の季節は、前に11日、後ろに7日広がった形です。
- 地点ごとに、1931〜1960年の平均と1996〜2025年の平均を比べると、14地点すべてで最初の真夏日が早くなっていました。いちばん大きいのは飯田（長野県）の27日（6月17日→5月21日）、境（鳥取県）の22日（6月17日→5月26日）です。いちばん小さいのは彦根の5日（6月22日→6月16日）でした。
- 大都市の東京は10日（6月17日→6月6日）で、ほかの地点の中ほどでした。最初の真夏日については、東京だけが目立って早くなったわけではありません。北の網走・根室・寿都も早くなっていますが、真夏日のない年が多いので、目安として見てください。
- 季節が前後に広がったぶん、真夏日の日数も増えました。10地点の平均で、1931〜1960年は年37日、1996〜2025年は年48日です。2023〜2025年は3年続けて70日を超えました。

## 頑健性
- 最初の日の傾きを外れ値に強い Theil–Sen 法で測っても、10地点の中央値で10年に1.9日早くなった
- 線を25℃（夏日）に下げても、10地点の中央値で10年に1.0日早くなった
- 10地点のうち6地点で、地点ごとの傾きの95%区間が0を含まない
- 1961年以降に限ると、10地点平均の傾きは10年に3.5日（標準誤差0.6日）
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致した

## 動かし方
```
pip install -r requirements.txt
cd src && python a262_first_hot_day.py
```
`src/fetch.py` は気象庁のページから同じ形のデータを取り直すスクリプトです（全地点・全月で約1.6万ページ。ふつうのネット環境向けで、このデータを取ったときはブラウザの中で同じページを読みました。このスクリプト自体は動かして確かめていません）。

## データ
- `data/jma_daily_14st_1931_2025.tsv.gz`：気象庁「過去の気象データ検索」日ごとの値（daily_s1、view=p1）を2026-11-12に取得し、地点・年・月・日・降水量合計・平均気温・最高気温・最低気温・降雪の深さ合計・最深積雪・天気概況（昼・夜）を取り出したもの（485,786行）。値の印（`)` 準正常値、`]` 資料不足値、`×` 欠測、`--` 現象なし）はそのまま残し、`src/common.py` で `)` は使う、`]`・`×` は欠測、`--` は0として読みます
- 地点：網走・根室・寿都・山形・石巻・伏木・飯田・銚子・境・浜田・彦根・多度津・宮崎（気象庁が長い気温の変化に使う、都市化の影響が比較的少ない15地点から、亜熱帯の名瀬・石垣島を除いた13地点）と、比べるための東京

## 注意
- 地点の観測の場所や測り方の変化（移転、測器の入れ替え）は、補正していません
- 最初の真夏日は1日の値で決まるので、年ごとの揺れが大きく、1つの年の早い・遅いで傾向は言えません
- 日付は1月1日からの通し日で、うるう年の1日のずれはそのままです
- なぜ早くなったか（地球全体の温暖化、地点のまわりの都市化など）は、このデータでは分けていません
- 真夏日の数を数えた別の見方として、猛暑日の増え方は記事 F168 で扱っています
