# 845 同じ内容を2回投稿したときの差は、偶然でどこまで出るのか？（SNSと動画）

動画やSNSでは、同じ内容を時間を変えて投稿し直したり、サムネイルだけ変えた2本を比べたりします。2本の再生数に2倍の差があると、「2本目のほうが良かった」と読みたくなります。しかし、1本の再生数には、その回たまたま多くの人に表示されたかどうかという運が大きく入ります。**ここでは、作成者が乱数で作った架空の動画アカウント（内容の本当の強さを作成者が置いたもの）で、まったく同じ強さの内容を2回投稿したとき、再生数にどれだけの差が偶然で出るかを数えました。あわせて、本当に2割強い内容を見分けるには、何本ずつ比べればよいかを数えました。**

1本のバズで月の平均がどれだけ動くかは関連する記事 840、少ない週の次が伸びて見える形は関連する記事 844 で扱っています。この記事は、1本どうし・少ない本数どうしの差を、偶然とどう見分けるかに絞ります。

| A845 | 同じ強さの内容を2回投稿したとき、再生数の差は偶然でどこまで出るか。本当に強い内容を見分けるには何本ずつ必要か | 架空の動画アカウント。1本の再生数は、5,000回 × 内容の本当の強さ × その回の運（対数正規分布、対数の標準偏差0.6）× バズ（3%の確率で3〜20倍。倍率は対数で一様）を平均とするポアソン分布から引く。運とバズは1本ごとに独立で、1回目と2回目で強さは変わらない（2回目だから減る、といった変化は入れない）。①同じ強さ（1.0）の2本を20万組作り、多いほう÷少ないほうを数えた。②強さ1.0（A）と1.2（B、2割強い）を k 本ずつ（1・2・3・5・10・20・40本）投稿し、再生数の平均・中央値で B が上に出た割合と、A が B の1.3倍以上に見えた割合を数えた（各2万回）。強さ1.5（5割強い）でも数えた。確かめとして、運の大きさ（0.3・0.6・0.9）とバズの確率（0%・3%・10%）を変えた9通りも数えた（各10万組・1万回）。seed 845 | `src/a845_same_twice.py` |

## 主な結果

### 同じ内容を2回投稿したときの差（20万組）
| | バズあり（基本、3%） | バズなし |
|---|---|---|
| 多いほう÷少ないほう（中央値） | **1.84倍** | 1.78倍 |
| 1.5倍以上の差になった割合 | 65.3% | 63.3% |
| 2倍以上の差になった割合 | **44.4%** | 41.5% |
| 3倍以上の差になった割合 | 23.2% | 19.7% |
| 95%の組が収まる差 | **7.10倍まで** | 5.28倍まで |

- 内容がまったく同じでも、2本のうち多いほうは少ないほうの中央値で1.84倍あり、44.4%の組は2倍以上の差になった
- 「この差なら偶然では出にくい」と言える目安（95%の組が収まる差）は7.1倍だった。2倍や3倍の差では、偶然と見分けられない
- バズを入れなくても、2倍以上の差は41.5%あった。差の多くは、その回の運の揺れから来ていた

### 本当に2割強い内容（B）を、k 本ずつで見分けられるか（各2万回）
| 本数（それぞれ） | 1本 | 2本 | 3本 | 5本 | 10本 | 20本 | 40本 |
|---|---|---|---|---|---|---|---|
| 中央値で B が上に出た | **58.1%** | 60.5% | 62.8% | 65.1% | 70.9% | 77.9% | **85.9%** |
| 平均で B が上に出た | 58.1% | 60.5% | 62.4% | 63.9% | 66.8% | 69.0% | 72.7% |
| 中央値で A が1.3倍以上に見えた | 30.7% | 26.1% | 22.0% | 16.9% | 8.9% | 2.9% | 0.5% |

- 1本ずつ比べると、2割強い内容が上に出たのは58.1%で、当てずっぽう（50%）と大きく変わらなかった。30.7%は、弱いほうが1.3倍以上多く見えた
- 中央値で8割当てるには、20本と40本の間（20本で77.9%、40本で85.9%）が必要だった
- 平均で比べると、バズの1本に引っぱられるため、本数を増やしても当たりの伸びが遅かった（40本で72.7%）
- 5割強い内容なら、中央値で5本ずつ比べて80.4%当たった（1本では67.7%）

### 確かめ：運の大きさとバズの確率を変えると（9通り、`results/sensitivity.csv`）
| 運の大きさ | バズ 0% | バズ 3% | バズ 10% |
|---|---|---|---|
| 0.3 | 10.3% | 15.3% | 26.4% |
| 0.6（基本） | 41.3% | 44.4% | 50.6% |
| 0.9 | 58.5% | 60.2% | 63.5% |

（表は、同じ内容2回で2倍以上の差になった割合。確かめは別の乱数で作り直したため、基本の値と小数点以下で少し違うことがある）

- 同じ内容で2倍以上の差になる割合は、置き方で10.3〜63.5%、95%の組が収まる差は2.29〜23.41倍と大きく動いた
- 2割強い内容が1本ずつで上に出た割合は55.2〜66.3%で、どの置き方でも当てずっぽうに近かった。中央値で20本ずつ比べると69.0〜94.2%だった

## 動かし方
```
pip install -r requirements.txt
cd src && python a845_same_twice.py
```
数秒で終わります。`data/same_content_pairs.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約6秒）
- 運の大きさとバズの確率を変えた9通りで、同じ内容2回で2倍以上の差になる割合は10.3〜63.5%と動いた。運を小さく（0.3）置き、バズをなくした場合だけ、2倍以上の差はまれ（10.3%）になった
- 2割強い内容を1本ずつで見分けられる割合は、9通りすべてで55.2〜66.3%にとどまった

## データ
- `data/same_content_pairs.csv`：同じ強さの内容を2回投稿した1,000組。pair_id・views_1・views_2（1回目・2回目の再生数）

## 注意（言えないこと）
- 架空のデータです。運の大きさ、バズの確率と倍率は作成者が置いたもので、偶然で出る差の大きさはこれで決まります（2倍以上の差が10.3〜63.5%）
- 2回目の投稿でも、内容の強さは同じと置きました。実際には、同じ内容を2回見せると見た人が飽きる、前回見た人には表示されにくい、といった違いがあるかもしれません。その分は入れていません
- 運は1本ごとに独立と置きました。同じ週に投稿した2本の運がそろって動く（その週に見る人が多い）場合は、2本の差は小さくなります（推測）
- 実在の動画サイトや SNS の表示の仕組みを表すものではありません
