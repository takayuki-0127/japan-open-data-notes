# 598 年の途中で売る1年契約では、事故を事故年で数えるか契約年度で数えるかで、事故率の推移はどれだけ違って見えるのか（手法の解説・保険数理）

1年契約を年の途中にも売っていると、ある年に始まった契約の期間は翌年にまたがります。そのため、事故率を「事故が起きた年」で数えるか、「契約が始まった年（契約年度）」で数えるか、「事故が報告された年」で数えるかで、同じデータでも年ごとの数字と、変化が見える時期が変わります。**ここでは、架空の1年契約（年10万〜12万件、3〜4月に多く売れる）で、本当の事故率が5%から6%に上がる2つの場合（A：2023年7月から、すべての契約で事故が起きやすくなった／B：2023年4月以降に始まった契約だけ事故が起きやすい）をつくり、3通りの数え方で年の表と、その月末に分かる直近12か月の値を比べました。** 数字は置いた前提で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A598 | 事故年・契約年度・報告年で、事故率の推移と変化に気づく時期はどれだけ違うか | 契約の始まりの月×事故の月×報告の月で事故件数をつくる（ポアソン、報告の遅れは平均1.5か月の幾何分布）。経過件数は各契約の12か月に1/12ずつ割り振る。年の表は偶然の揺れを除いた期待値と1回の例。その月末までに報告された事故で直近12か月の値を出し、変化前の1.1倍を初めて超える月を各200回で数える。DuckDB（1スレッド）の SQL と Python で年の表を突き合わせ。seed 598 | `src/a598_basis.py`、`src/02_basis_duckdb.sql`、`src/01_basis_tsql.sql`（未検証） |

## 主な結果
- **A（2023年7月から、すべての契約で6%）の年の表**（期待値）：2023年は事故年5.50%、契約年度5.82%、報告年5.36%。契約年度では、何も変えていない2022年も5.08%に上がって見える（2022年後半に始まった契約の期間が2023年後半にかかるため）
- **B（2023年4月以降の契約だけ6%）の年の表**：2023年は事故年5.36%、契約年度5.73%、報告年5.26%。事故年では2024年も5.97%で、6%に届くのは2025年
- **その月末に分かる値で気づくまで**（変化前の1.1倍を初めて超えるまでの月数、中央値、各200回）：A は事故年6か月、報告年7か月、契約年度11か月。B は11か月、12か月、17か月
- **事故年の直近12か月は、その時点では低く出る**：直近の事故の報告が出そろっていないため、変化前で4.29%（報告年4.88%、契約年度4.81%）。本当は5%
- 契約年度の数字は、その年に始まった契約の期間がすべて終わり、報告が出そろうまで（およそ2年）固まらない

## 動かし方
```
pip install -r requirements.txt
cd src && python a598_basis.py
```
30秒ほどで終わります。`data/claims.csv`（start_month・accident_month・report_month・claims、シナリオ A の1回）と `data/policies.csv`（start_month・policies）を書き出します。

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures がバイト単位で一致した（DuckDB は `SET threads=1`）
- シナリオ A の1回の年の表（2019〜2025年、3通り）が、Python と DuckDB の SQL（`02_basis_duckdb.sql`）で一致した（差の最大 3×10^-17）
- T-SQL 版（`01_basis_tsql.sql`）は書いたが、SQL Server では動かしていない（**未検証**）。`GENERATE_SERIES` は SQL Server 2022 以降

## 前提
- 契約は2017年1月〜2026年12月に始まる1年契約。月の販売件数は3〜4月に多く、年3%ずつ増える（年10万〜12万件）
- 事故は契約期間の中で一様に起き、件数はポアソン分布。本当の事故率は5%（1契約・1年あたり）で、A・B とも6%に上がる
- 報告の遅れは平均1.5か月。報告されたものはすべて有効な事故とし、取り消しや金額は扱わない
- 経過件数は、各契約の12か月に1/12ずつ割り振った（月の中の日数は無視）

## 注意（言えないこと）
- 架空のデータ。実際の保険会社の契約や事故ではない
- 「暦年」は、ここでは「その年に報告された事故」で数える報告年として扱った。会社によっては、支払った年や計上した年で数えるなど、定義が違う
- 気づくまでの月数は、変化前の1.1倍という目安と、ポアソンの揺れの大きさで決まる
- 支払備金・料率・引受の判断の助言ではない
