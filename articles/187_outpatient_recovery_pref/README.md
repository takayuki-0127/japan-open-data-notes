# 187 外来患者数の戻り方は、都道府県で違ったか：病院報告

厚生労働省「病院報告」の都道府県別の外来患者延数（病院、年間）を2015〜2025年で並べ、2019年を100としたときに、コロナ禍の2020年にどれだけ減り、その後どこまで戻ったかを都道府県ごとに比べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A187 | 病院の外来患者数は、2019年の水準にどこまで戻ったか。戻り方は都道府県で違うか | 2019年=100の指数（県別パネル）、2020年の落ち込みのうち2022年までに戻った割合、2015→2019年の年率を延ばした傾向線との差、相関 | `src/a187_recovery.py` |

## 主な結果
- 全国の外来患者延数（2019年=100）は、2020年90.3、2022年94.9まで戻ったあと再び減り、2025年は90.1（2020年とほぼ同じ）
- 2021〜2025年のいちばん戻った年でも、47都道府県すべてが2019年に届いていない。37県は2022年がいちばん高い
- 2025年の水準は静岡96.0、徳島95.3、栃木95.0が高く、秋田84.2、新潟84.9、大阪85.2、東京86.8が低い（中央値90.2、90未満は20県）
- 2020年の落ち込みは東京（85.9）、沖縄（87.6）、神奈川（88.2）など大都市圏で大きく、鳥取（93.9）など地方で小さかった。大都市圏9都府県の平均は2020年89.2→2025年90.1、ほかの38道県は91.9→90.9で、2025年には差が1ポイント未満に縮んだ
- 外来はコロナ前から減っていた（全国 2015→2019年 年率−0.77%）。このペースが続いた場合の2025年は95.4で、実際の90.1はそれより5.3低い。コロナ前の減り方と2025年の水準の相関係数は0.43

## データ

- 各年の病院報告 都道府県編 第4表「外来患者延数，病院の種類・都道府県－指定都市・特別区・中核市（再掲）別」（年間、CSV）の「総数」列

- ダウンロード：`https://www.e-stat.go.jp/stat-search/file-download?statInfId=<ID>&fileKind=1`

## 注意
- 病院（病床20以上）の外来だけで、診療所（クリニック）の外来は含まない。外来の多くは診療所なので、外来受診全体の戻り方とは違う可能性がある
- 延数（のべ人数）なので、受診の回数が減ったのか、受診する人が減ったのかは分けられない。人口の増減もならしていない
- 病院の所在地で数えていて、住んでいる県とは限らない
- 傾向線は2015→2019年の年率をそのまま延ばした目安で、予測ではない
