# 1303 詰め方の良さを、「体積の合計÷容量」の切り上げと比べるか、いちばん良い詰め方と比べるかで、どれだけ見え方が違うのか？（箱詰めと積載）

荷物の詰め方がどれだけ良いかを測るとき、「その日の荷物の体積の合計÷箱1つの容量」を切り上げた数（下限）を物差しにすることがあります。どう詰めてもこれより少ない箱では収まらないので、下限との差は「詰め方の無駄」に見えます。けれども、荷物の大きさの組み合わせによっては、いちばん良い詰め方でも下限には届きません。たとえば容量の半分を超える荷物は、2つを同じ箱に入れられません。そのため、下限と比べた差には、詰め方の無駄と、どう詰めても埋まらないすきまの両方が入ります。**ここでは、作成者が置いた架空の通販の発送（箱の容量を100、商品12種類の大きさを置き、1日に40個の荷物を詰める）で、3つの詰め方（①来た順に今の箱へ詰め、入らなければ箱を閉じて次の箱 ②来た順に、入る最初の箱へ ③大きい順に並べてから、入る最初の箱へ）の箱の数を、下限と、その日の荷物でいちばん少ない箱の数（整数の計算で厳密に求めた）の2つと比べました。荷物の大きさの範囲4通り×1日の荷物の数2通り（各200日）で数えました。**

例の通販・箱・商品の大きさは作成者が置いた架空のもので、実在の箱や配送の数値を表すものではありません。

## 主な結果

### 基本（大きさ10〜60、1日40個、200日、`results/a1303_main.json` の by_range）
| | 箱の数（1日の平均） | 下限より多い箱 | いちばん良い詰め方より多い箱 | いちばん良い詰め方と同じ数だった日 | 積載率 |
|---|---|---|---|---|---|
| 下限（体積の合計÷容量の切り上げ） | 14.54 | − | − | − | − |
| いちばん良い詰め方 | 14.835 | +2.03%（1日平均0.295箱） | − | − | 94.66% |
| ①来た順・1箱ずつ閉じる | 18.21 | +25.24% | +22.75% | 0.0% | 77.11% |
| ②来た順・入る最初の箱 | 15.59 | +7.22% | +5.09% | 35.0% | 90.07% |
| ③大きい順に並べてから | 15.0 | **+3.16%** | **+1.11%** | **83.5%** | 93.62% |

- **③は、下限と比べると3.16%多く見えたが、いちばん良い詰め方と比べると1.11%多いだけだった**。200日のうち83.5%の日は、いちばん良い詰め方と同じ箱の数だった
- いちばん良い詰め方でも、29.5%の日は下限より箱が多かった（1日平均0.295箱）。③がいちばん良い詰め方と同じなのに下限より多く見えた日は29.5%あった
- ②は下限と比べて7.22%、いちばん良い詰め方と比べて5.09%多かった。①は25.24%と22.75%で、物差しを変えても大きいままだった

### 荷物の大きさの範囲で（③大きい順に並べてから、1日40個、各200日）
| 大きさの範囲 | ③が下限より多い箱 | ③がいちばん良い詰め方より多い箱 | いちばん良い詰め方が下限より多い箱 | いちばん良い詰め方でも下限より多い日 | いちばん良い詰め方の積載率 |
|---|---|---|---|---|---|
| 小さめ（5〜35） | 1.3% | 1.18% | 0.12% | 1.0% | 94.56% |
| 基本（10〜60） | 3.16% | 1.11% | 2.03% | 29.5% | 94.66% |
| 大きめ（20〜70） | 4.35% | 0.47% | 3.87% | 58.5% | 93.71% |
| 半分超えが多い（30〜80） | **18.27%** | **0.0%** | 18.27% | **100.0%** | 82.82% |

- **荷物が大きくなるほど、下限との差は大きく見え、いちばん良い詰め方との差は小さくなった**。半分超えが多い（30〜80）では、③は200日すべていちばん良い詰め方と同じだったが、下限と比べると18.27%多く見えた
- 荷物が小さいと、いちばん良い詰め方は下限より0.12%多いだけで、どう詰めても下限に届かない日はほとんどなく（1.0%）、2つの物差しの見え方はほぼ同じだった（1.3%と1.18%）
- 半分超えが多い範囲では、いちばん良い詰め方でも積載率は82.82%だった。容量の半分を超える荷物は2つを同じ箱に入れられないので、どう詰めてもすきまが残る

### 確かめ：1日の荷物の数（20個・40個）と詰め方（8通り、`results/grid.csv`）
- ③の「下限より多い箱」は8通りで1.3〜19.27%、「いちばん良い詰め方より多い箱」は0〜1.34%だった
- ②の「下限より多い箱」は3.01〜23.59%、「いちばん良い詰め方より多い箱」は2.89〜7.78%だった
- いちばん良い詰め方が下限より多い箱は8通りで0.12〜19.27%、下限より多い日は1.0〜100.0%だった。1日20個では、小さめ1.0%・基本16.0%・大きめ49.5%・半分超えが多い100.0%で、40個より少ないか同じだった
- 1日20個の半分超えが多い範囲では、②は55.0%の日でいちばん良い詰め方と同じ箱の数だったが、下限と比べると23.59%多く見えた

```
pip install -r requirements.txt

```

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の6ファイルがバイト単位で一致した（cmp、約35秒）
- 基本の200日すべてで、いちばん良い詰め方の箱の数が下限以上、3つの詰め方のいちばん少ない数以下に収まることを確かめた
- いちばん良い詰め方の箱の数を、別の数え方（荷物を1つずつ、すでに開けた箱か新しい箱に入れるすべての入れ方をたどる）でも求め、1日20個の4通りの800日すべてで同じ数になった（`results/a1303_main.json` の check_exhaustive_20）。1日40個ではこの数え方は時間がかかりすぎるので、照らしていない
- 図3枚を開き、日本語・重なり・軸（0から）を確かめた

## 注意（言えないこと）
- 架空の数値です。箱の容量・商品の大きさ・1日の荷物の数は作成者が置いたもので、結果はこれで決まります。とくに、2つの物差しの違いは、容量の半分を超える荷物がどれだけあるかで大きく動きました
- 体積の合計だけで入るかを決めました。縦・横・高さの形で入らない場合、重さの上限、荷物を壊さない置き方は入れていません。形を入れると、いちばん良い詰め方でも下限との差はもっと開きます（推測、数えていません）
- いちばん良い詰め方は、その日の荷物がすべてそろってから決めたものです。荷物が来るたびに詰める現場では、①②のように先が分からないまま詰めることになります
- 箱の大きさを選ぶこと、送料や料金の決め方、どの箱や車を使うべきかを言うものではありません
