# 439 3人目より後に生まれる子は、いつから少数になったのか（人口動態統計、1950〜2025年）

人口動態統計の「出生順位別にみた年次別出生数」から、第1子・第2子・第3子・第4子以上の割合を75年分並べたフォルダです。F204（支援策と出生順位）・290（第1子の母の年齢）とは別で、割合の長い推移だけを見ています。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A439 | 第3子以上の割合はどう動いたか。いつ大きく下がったか。第1子の割合がいちばん高かった年はいつか | 出生順位が分かる出生数に占める割合を計算（公表の百分率と照合）。出生数の増減を順位ごとに分ける | `src/a439_birth_order.py` |

## 主な結果
- 第3子以上の割合：1950年 44.8% → 1955年 40.5% → 1960年 22.9% → 1965年 14.9% → 1975年 14.3% → 1990年 18.9% → 2004年 14.0%（最小）→ 2021年 17.8% → 2025年 16.7%
- 第4子以上：1950年 28.4% → 1960年 9.1% → 1965年 3.7% → 1975年 2.5% → 2025年 4.2%
- 第1子の割合：1950年 27.2% → 1960年 44.5% → 2002年 49.5%（最高）→ 2025年 47.5%。第1子が第2子を上回ったのは1955年から。第2子は1980年の40.7%が最高
- 1950→1960年に出生は73.1万人減った。第3子以上が67.9万人減、第2子が13.2万人減、第1子は8.1万人増
- 第3子以上の出生数：1950年 104.7万人 → 1960年 36.8万人 → 2000年 17.2万人 → 2025年 11.2万人
- 2000→2025年の出生数は、第1子が45.3%減、第2子が44.8%減、第3子以上が35.1%減

## 確かめたこと
- 自分で計算した割合は、公表の百分率とすべての年・順位で一致（小数第1位）
- 空のフォルダで流し直し、results・figures が一致した

## データ
- `data/jinkou_r7_jokan_4-12_birth_order.csv`：上巻 4-12 出生順位別にみた年次別出生数及び百分率（statInfId=000040503649）。e-Stat「人口動態調査 人口動態統計 確定数 出生」（2025年）を2026-11-12に取得し、文字コードを UTF-8 に直したもの

## 注意（言えないこと）
- 1950〜2000年は5年おきの数字です。あいだの年に上下があっても、この表からは分かりません。「最小」「最高」は、表にある年の中での話です
- 出生順位は、同じ母親がそれまでに生んだ子の数で数えた順番です（表の注）。きょうだいの数や、1人の女性が生む子の数そのものではありません
- 割合は、その年に生まれた子の内訳です。第1子・第2子が減れば、第3子以上の人数が変わらなくても割合は上がります
- 割合が動いた理由（結婚の時期・家族の考え方・制度など）は分けていません。何人生むのがよいかを言うものではありません
- 1950〜1972年は沖縄県を含みません。全国の集計だけで、地域ごとの違いは見ていません
