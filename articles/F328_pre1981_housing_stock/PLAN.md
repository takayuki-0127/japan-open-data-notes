# F328 PLAN（事前の計画）：古い耐震基準の住宅は、どれだけのペースで減っているのか？

作成：2026-11-16 07:31 JST（都道府県別の値を集計する前に書いた）

## 問い
1981年6月に建築基準法の耐震の基準が改められた。それより前の基準で建てられた住宅（ここでは1980年以前に建てられた住宅）は、人が住む住宅の中にどれだけ残り、5年でどれだけ減っているのか。
減り方（5年でどれだけ残るか）は、大都市圏と地方圏で違うのか。耐震の改修工事はどれくらい行われているのか。

知りたい人：住宅・建設・損害保険の実務の人、自治体の住宅・防災の担当、住まいの記事を読む人。
（どの住宅を改修すべきか、制度や保険料をどうすべきかは扱わない。地域の悪い順の順位も作らない。）

## データ
- 総務省「住宅・土地統計調査」令和5年 第5-1表、平成30年 第6-1表（住宅の種類・所有の関係・建築の時期別住宅数、全国・都道府県。人が住んでいる住宅）
- 同 平成30年調査 時系列 第20-1表（持ち家の建て方・構造・建築の時期・耐震改修工事の状況、全国、2003〜2018年）
- 1980年以前＝「1950年以前」「1951〜1970年」「1971〜1980年」の合計。5年後に残る割合＝2023年の数÷2018年の数。

## 取得前・下見で見たもの（開示）
- 表の形を確かめるときに、2023年・2018年の全国の行（建築の時期別の住宅数と持ち家数）と、第20-1表の2018年の持ち家の行（建築の時期別、耐震工事の有無）を見た。全国の持ち家の1980年以前の数は目にしているため、全国の残る割合（H1）は参考扱いにする。都道府県別の値は見ていない。

## 仮説と「外れ」の基準
- H1（参考）：全国の1980年以前の持ち家は、2018→2023年の5年で1割未満しか減っていない（残る割合が90%以上）。90%未満なら外れ。
- H2：5年後に残る割合（人が住む住宅すべて、2018→2023年）は、三大都市圏の11都府県の平均が、地方圏36道県の平均より低い（建て替えが速い）。同じか高ければ外れ。
- H3：2023年に人が住む住宅に占める1980年以前の割合は、地方圏の平均が三大都市圏の平均より3ポイント以上高い。3ポイント未満なら外れ。
- H4：1980年以前の持ち家のうち、調査前の約5年間に耐震工事をした割合は、2003〜2018年のどの調査でも5%未満。5%以上の年があれば外れ。

## 手法
- 全国の持ち家の1980年以前の数を、2003・2008・2013・2018・2023年で並べ、5年ごとの残る割合を出す（同じ時期に建った住宅の数が5年でどれだけ残るか、生存分析の考え方）。
- 都道府県は北から南の順、または三大都市圏・地方圏の比較。順位は作らない。

## 頑健性（3つ以上）
1. 持ち家だけで（都道府県）
2. 建築の時期「不詳」を、時期のわかる住宅と同じ割合で配る
3. 1950年以前だけ、1971〜1980年だけに分ける
4. 三大都市圏の定義を東京圏だけにする

## 言えないこと（予想）
- 住宅・土地統計調査は人が住む住宅を数える（空き家は入らない）。「減った」には、取り壊しのほか空き家になった分が入る
- 1980年以前でも耐震性があるかどうかは、この表では分からない。改修や診断の結果も分からない
- 標本調査で、都道府県の値にはぶれがある
- 建築の時期は回答による（不詳が増えると数がゆがむ）
