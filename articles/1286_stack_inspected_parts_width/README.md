# 1286 検査で規格外を除いた部品だけを組むと、組み立て品のばらつきは、除く前の部品の標準偏差から見込んだ幅より狭くなるのか、それとも思ったほど狭くならないのか？（寸法の積み上げ）

部品を検査して規格の外のものを除くと、残った部品の寸法は規格の中に収まり、散らばりも小さくなります。その部品を重ねた組み立て品の幅を見込むとき、除く前の部品の標準偏差を使うと広く見込みすぎます。一方で、「規格に入っているのだから、規格の幅は標準偏差の3倍くらい」と見ると、今度は狭く見込みすぎます。規格で切った正規分布の標準偏差は式で決まり、測りのばらつきがなければ、組み立て品の幅もそこから式どおりに決まります。**ここでは、作成者が置いた架空の引き出し（5つの部品の寸法を足した長さ。部品の除く前の標準偏差・規格の幅・平均のずれ・検査の測りのばらつきを作成者が置き、乱数で100万台を組んだもの）で、検査に通った部品だけで組んだ組み立て品の標準偏差が、(a) 除く前の標準偏差から二乗で足した見込み、(b) 規格の幅÷3 を標準偏差と見て二乗で足した見込み、(c) 規格の中で平らに散らばると見た見込みの何倍になるかと、部品の規格を二乗で足した許容差の外に出る割合を数えました。規格の幅（4通り）×平均のずれ（3通り）×測りのばらつき（3通り）の36通りと、部品の数（2〜12個）でも確かめました。**

例の引き出し・部品はすべて架空のもので、実在の会社・製品・規格の数字ではありません。品質の判断や購入の助言はしていません。

関連する記事：917「寸法の平均が規格の中でも、外れる品物は何%あるのか？」は、部品1つの寸法で、平均と標準偏差から規格の外に出る割合を扱っています。911「検査で『不良』と出た品物は、本当に不良なのか？」は、測りの誤差で規格の端の近くの判定が入れかわり、「不良」と出た品物の中に良品がまざることを扱っています。この記事の測りのばらつきの確かめは、その反対側（通った部品の中に規格の外の部品がまざる）が組み立て品の幅をどう広げるかを数えます。1285「1つ1つの部品の寸法が正規分布でないとき、何個重ねると、組み立て品の外れの割合は正規と見た見込みに近づくのか？」は、部品の形のせいで外れの割合が正規と見た見込みと違うことを扱っています。規格で切った部品も、すそのない正規でない形です。1287「部品の寸法の記録に測りのばらつきがまざっていると、記録から見込んだ組み立て品の幅は、本当の幅よりどれだけ広く出るのか？」は、測りのばらつきが記録の標準偏差を広げ、記録から見込んだ組み立て品の幅が広く出ることを扱っています。この記事の測りのばらつきは、合否の判定にだけまざり、組むのは本当の寸法という点が違います。この記事は、除いた後の部品の散らばりをどの数で見込むかと、組み立て品の幅・外れの割合に絞ります。

## 注意（言えないこと）
- 架空のデータです。除く前の分布（正規）・標準偏差・規格の幅・平均のずれ・測りのばらつきは作成者が置いたもので、結果はこれで決まります。測りのばらつきがないときの組み立て品の幅は、規格で切った正規分布の式で決まる値です
- 部品どうしのずれは関係なく、5つの部品はどれも同じ置き方と置きました。部品ごとに規格の幅や除く前の散らばりが違う場合は数えていません
- 平均のずれは5つの部品が同じ向きにずれると置きました。部品ごとに向きが違えば、組み立て品の平均のずれは打ち消し合います
- 規格の外の部品を除いた分の数や費用は扱っていません。実在の部品の寸法・規格を表すものではなく、品質の判断・検査の決め方・部品の買い方の助言をする記事ではありません
