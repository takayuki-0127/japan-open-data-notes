# 480 ヒストグラムは、幅と始点の取り方で、山の数がどれだけ変わるのか？（手法の解説）

同じデータでも、ヒストグラムの棒の幅と、最初の棒をどこから始めるかで、山が1つに見えたり2つに見えたりします。**幅の決め方6通りと始点のずらし方で、見える山の数が本当の数とどれだけ合うかを、架空のデータと公的統計の分布で数えました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A480 | 幅の決め方で、山の数が合う割合はどう変わるか。始点をずらすだけで山の数は変わるか。きりのよい数字への丸めは山を作るか | 架空のデータ5種類（山が1つ・2つ）×件数50〜5,000×幅の決め方6通り＋核密度推定、500回ずつ。始点は幅の10分の1ずつ10通り。丸めのあるデータ（架空の利用時間2,000件）。市区町村の65歳以上の割合（1,740市区町村、値だけ） | `src/a480_histogram.py` |

## 置いたこと
- 「山」の数え方：まわりより高く、その高さの差がいちばん高い棒の1割以上あるものを1つと数える（`scipy.signal.find_peaks` の prominence）
- 架空のデータ：山が1つ（左右対称／右に長い）、山が2つ（離れている／近い／大きさが違う）
- 幅の決め方：スタージェス、スコット、フリードマン＝ディアコニス（以上は numpy の `bins=`）、10本・30本・60本に決め打ち

## 主な結果
### 山の数が合った割合（%、500回）
| 分布 | 決め方 | 50件 | 200件 | 1,000件 | 5,000件 |
|---|---|---|---|---|---|
| 山が1つ（左右対称） | スタージェス | 65 | 95 | 100 | 100 |
| | スコット | 95 | 93 | 94 | 96 |
| | フリードマン＝ディアコニス | 73 | 72 | 77 | 84 |
| | 10本 | 20 | 89 | 100 | 100 |
| | 30本 | 0 | 0.4 | 48 | 99 |
| | 60本 | 0 | 0 | 0.2 | 51 |
| 山が2つ（近い） | スタージェス | 58 | 59 | 57 | 65 |
| | スコット | 29 | 53 | 82 | 90 |
| | フリードマン＝ディアコニス | 39 | 65 | 79 | 91 |
| | 10本 | 32 | 67 | 45 | 24 |
| | 30本 | 0 | 0 | 19 | 93 |
| | 核密度推定 | 7 | 16 | 31 | 66 |

- 山が2つで離れている分布は、200件からは30本・60本を除くどの決め方でもほぼ100%
- どの決め方も、すべての場面でいちばん良いわけではなかった

### 始点をずらしただけで山の数が変わった割合（スコットの幅、始点10通り）
| 分布 | 50件 | 200件 | 1,000件 | 5,000件 |
|---|---|---|---|---|
| 山が1つ（左右対称） | 33% | 27% | 29% | 24% |
| 山が2つ（近い） | 71% | 79% | 59% | 33% |
| 山が2つ（離れている） | 73% | 1%未満 | 1%未満 | 1%未満 |

### きりのよい数字への丸め（架空の利用時間2,000件、本当の山は1つ）
| 10分単位に丸めて答える人 | 幅1分 | 幅5分 | 幅10分 |
|---|---|---|---|
| なし | 16.8個 | 1.1個 | 1.0個 |
| 20% | 10.4個 | 4.2個 | 1.0個 |
| 40% | 8.8個 | 7.0個 | 1.0個 |

（山の数の平均。丸めがないときの幅1分は、偶然のでこぼこ）

### 公的統計の分布：市区町村の65歳以上の割合（1,740市区町村）
| 決め方 | 棒の本数 | 山の数 | 始点を10通りずらしたとき |

| スタージェス | 12 | 1 | 1〜1 |
| スコット | 24 | 2 | 1〜2 |
| フリードマン＝ディアコニス | 30 | 1 | 1〜2 |
| 60本 | 60 | 6 | 2〜8 |
| 幅0.5ポイント | 111 | 13 | 10〜15 |
| 幅1ポイント | 56 | 2 | 2〜7 |
| 幅5ポイント | 12 | 1 | 1〜1 |
| 核密度推定 | — | 1 | — |

全部の数字は `results/` の5つの CSV と `main.json` にあります。

## 動かし方
```
pip install -r requirements.txt
cd src && python a480_histogram.py      # 約1分
```
`data/municipal_aged_share_values.csv` を読み、`data/` の例2つ、`results/` の6ファイル、`figures/` の3枚を作ります。

## 確かめたこと
- 空のフォルダで計算し直し、data・results・figures が一致した
- 置いた分布そのもの（密度）から数えた山の数は、置いた数と一致した（`results/true_modes.csv`）

## 注意（言えないこと）
- 「山」の数え方（いちばん高い棒の1割以上）は、ここで置いた決まりです。決まりを変えると数字は変わります
- 架空のデータは、正規分布などを混ぜて作りました。ほかの形の分布では、合う割合は変わります
- 市区町村の65歳以上の割合に、本当に山がいくつあるかは分かりません。ここで言えるのは「幅と始点で見え方が変わる」ことだけです。市区町村の名前や順位は扱っていません
- どの幅が正しいかを決めるものではありません
- 丸めたデータから出した平均とばらつきは447、グラフの縦軸の取り方は240で扱いました
