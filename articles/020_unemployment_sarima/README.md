### 公的統計の時系列を、季節調整と予測モデルで調べる

- **何を**：毎月の公的統計（まずは労働力調査の完全失業率）を、季節の動きと流れに分け、どこまで先を予測できるかを確かめる
- **どう**：原数値を STL で季節調整して公表値（X-12-ARIMA）と比べる → SARIMA の次数を2014年までのデータの AIC で決める → 2015年1月〜2025年8月の128か月を起点に、毎回学習し直して1〜12か月先を予測するローリング評価
- **結果**：自分で STL にかけた季節調整値は、公表の季節調整値と平均0.03ポイントの差でほぼ一致。SARIMA の誤差は、1か月先で0.087ポイント（「最新の値のまま」は0.100）、12か月先で0.127ポイント（同0.180）。ただし、2019年12月までのデータで作った予測は、コロナ禍の上昇をまったく捉えられなかった

#### 手順の要点
- 完全失業率の公表値は小数1桁なので、完全失業者 ÷ 労働力人口 で計算し直して使う
- SARIMA の次数は (p,1,q)(P,1,Q)12 を p,q∈{0,1,2}・P,Q∈{0,1} で探し、**2014年12月までのデータの AIC** で決めた（評価に使う期間を見ないため）。選ばれたのは (2,1,2)(0,1,1)12
- ローリング評価では、起点ごとにその月までのデータで学習し直す。比べた単純な予測は「最新の値のまま」と「前年同月＋直近の前年差」
- コロナ期（2020年3月〜2021年12月が予測先、または2020〜2021年が起点）は、平均誤差の表から除いた（図4で別に示す）

#### データ
出典：政府統計の総合窓口(e-Stat)（https://www.e-stat.go.jp/）「労働力調査 長期時系列データ 基本集計 表1 a-1 主要項目」（総務省統計局）をもとに作成者が加工して作成。政府標準利用規約（第2.0版）に基づいて利用。`data/raw/lt01-a10.xlsx` は e-Stat からダウンロードしたそのままのファイル。

#### 言えないこと
- 予測は過去のパターンの延長で、景気の転換点や大きな出来事は当てられない（図4）
- 2011年3〜8月は、岩手・宮城・福島を除いた値を総務省が補完推計している
- 季節調整の比較は、公表値（reg-ARIMA を使った X-12-ARIMA）と STL という別の方法の比較で、どちらが正しいかを決めるものではない
