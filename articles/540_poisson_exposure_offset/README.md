# 540 事故の件数をポアソン回帰で当てるとき、契約の期間（露出）を入れ忘れると、要因の効き目はどれだけずれるのか（保険数理・回帰）

事故の件数は、契約していた期間が長いほど多くなります。ポアソン回帰では、期間の対数を「オフセット」として入れ、1年あたりの事故率をモデルにするのがふつうです。**ここでは、架空の自動車の契約20,000件（1年の契約が6割、残りは途中加入・途中解約）で、「業務で使う」の本当の効き目を1.5倍に置き、期間と「業務で使う」の相関を −0.5〜+0.4 で変えて、(a) オフセットあり、(b) 期間を入れない、(c) 期間の対数を説明変数に、の3通りで当てました。** 各場面100回くり返しています。数字は、置いた期間の分布と相関で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A540 | 期間を入れ忘れたとき、要因の効き目（倍率）はどれだけずれるか | 事故率 λ = exp(b0 + b1·X)、exp(b1) = 1.5。件数 ~ ポアソン(λ·期間)。X=1 になる確率を期間とつなげて相関を変える。ポアソン回帰は IRLS。20,000件×100回、seed 540 | `src/a540_exposure_offset.py` |

## 主な結果
- **期間と要因に相関がなければ、入れ忘れてもずれない**：相関 0.00 で (a) 1.49倍、(b) 1.49倍
- **相関があると、その分だけずれる**：相関 +0.36 で (b) は **1.95倍（+30%）**、+0.22 で 1.78倍（+19%）、−0.28 で 1.20倍（−20%）、−0.51 で **0.97倍（−35%）**。−0.51 では「業務のほうが事故が少ない」向きに見える
- **ずれの倍率は、2群の期間の平均の比とほぼ同じ**：「業務で使う」の契約の期間の平均が、それ以外の1.30倍なら推定も約1.30倍になる
- **(a) オフセットに入れると、どの相関でも 1.49〜1.52倍**（5〜95%点は約1.36〜1.65倍）
- **(c) 期間の対数を説明変数に入れても 1.49〜1.52倍**。期間の対数の係数は 0.98〜1.03 で、オフセット（係数1）とほぼ同じになった

## 動かし方
```
pip install -r requirements.txt
cd src && python a540_exposure_offset.py
```

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- 相関 0 の場面で、3通りの当て方がすべて本当の値 1.5倍の近くになること
- IRLS が収束していること（係数の変化 1e-10 未満）

## データ
- データファイルは置いていない。契約と事故件数はコードの中で乱数から作る（seed 540）

## 注意（言えないこと）
- 架空の契約と事故件数。実際の保険会社や保険料の数字ではない
- 保険料の決め方や料率の区分を勧めるものではない。「期間と要因の相関がこれだけなら、効き目はこれだけずれる」を計算したもの
- 1年の中で事故率は一定と置いた。季節や、途中解約の理由が事故とつながる場合（事故のあとに解約する、など）は入れていない
- 件数のばらつきはポアソンと置いた。過分散がある場合の標準誤差の話は扱っていない
