# tornado-japan：気象庁「竜巻等の突風データベース」で、竜巻が多い月と時刻を調べる

気象庁「竜巻等の突風データベース」の突風事例一覧（1961〜2026年、2,914件）を使ったリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A135 | 竜巻は何月の何時ごろに多いのか。どこで、どれくらいの強さのものが多いか | 2007〜2025年の竜巻を月×時間帯で集計（ヒートマップ）、月別・時刻別、水上で発生し上陸しなかったものとの比較、年別の確認数と統計方法の変更、都道府県（地方）別、F/JEFスケールの分布 | `src/a135_season_time.py`, `src/a135_place_scale.py` |

## 主な結果
- 気象庁の集計と同じく、現象が「竜巻」と「竜巻またはダウンバースト」のものを竜巻とし、水上で発生して上陸しなかったものは分けた
- 2007〜2025年（19年）の陸上などの竜巻は368件（年平均19.4件）。月別では9月84件、8月67件、10月49件で、8〜10月が54.3%、7〜11月が72.3%
- 時刻別では15時台31件、13時台27件、14時台26件が多く、9〜17時台が57.8%。ただし夜（0〜2時台）や朝にも起きている。いちばん多いのは9月の12〜14時台（23件）
- 水上で発生し上陸しなかった竜巻は474件で、10月108件、9月104件が多い
- 多い都道府県・地方は高知県28件、静岡県26件、宮崎県23件、秋田県22件、千葉県・沖縄本島地方17件
- 最大のF/JEFスケールが分かる337件のうち、0が55%、1が33%、2が7%、3が1%
- 年別の確認数は2007年から増えたが、気象庁は1991年と2007年に調査体制を強化しており、年をまたいだ増減の比較はできない

## 動かし方
`data/events.csv`（必要な列だけに整えた一覧）が入っているので、そのまま動きます。元の CSV から作り直すときは、気象庁のページの「突風事例一覧」（CSV）を `data/raw/ichiran.csv` に置き、`data/events.csv` を消してから実行してください。

```bash
pip install -r requirements.txt
cd src
python a135_season_time.py
python a135_place_scale.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/events.csv | 事例番号、現象の種類、発生年月日・時刻、発生県（地方）、発生市町村、F/JEFスケール（最小・最大）、発生地点区別（陸上・水上）、死者・負傷者・住家全壊 |

## 注意
- 気象庁は1991年と2007年に竜巻等の突風の調査体制を強化しています。気象庁は「1961年から本年までの発生確認数を比較し、増えている・減っていると評価すること」などはできないとしています。このリポジトリでも、年の増減は比べていません
- 月別・時刻別は2007〜2025年の陸上など（水上で発生しその後上陸したもの、地点不明を含む）で集計しました。2026年は年の途中なので除いています
- 時刻は「発生時」の時台です。発生時刻には幅（確度）がある事例があります
- 北海道と沖縄県は地方（振興局・島）ごとに分かれています
- F/JEFスケールは2016年からJEFスケール（日本版改良藤田スケール）。F0とJEF0などは同じ物差しではありません
