# 1299 荷物の体積の合計は箱の容量に収まっていても、縦・横・高さで並べると入らない組み合わせはどれだけあるのか？（箱詰めと積載）

通販の発送で、注文の荷物（商品の箱）の体積を足して、発送の箱の容量以下なら「この箱に入る」と見込むことがあります。けれども、荷物は直方体なので、縦・横・高さで並べると、体積には余裕があっても入らないことがあります。**ここでは、作成者が置いた架空の通販の注文（1つの注文に荷物2〜4個。荷物の縦・横・高さは乱数）のうち、体積の合計が箱の容量以下のものを、詰まり具合（体積の合計÷箱の容量）の4つの区分から300件ずつ取り、縦・横・高さで並べて入るかを1件ずつ判定しました。入らない理由は「1つでも入らない荷物がある」「どれか2つの組が入らない」「探した並べ方では見つからない」に分けて数えました。荷物の大きさ・箱の形・向きの決まり（6通りの向きを使ってよい／上下はそのまま）を変えた18通りで確かめました。**

すべて作成者が置いた決まりでのシミュレーションです。実在の箱の規格・運送会社を表すものではありません。

関連する記事：1293「荷物の体積の合計を箱1つの容量で割って見込んだ箱の数は、1つずつ詰めていったときの本当の箱の数よりどれだけ少なく出るのか？」は、「体積の合計÷容量」の切り上げで見込んだ箱の数が、箱ごとに残るすきまの分だけ本当の箱の数より少なく出ることを数えています。1297「上に重ねられない荷物が1割まざると、体積で見た積載率はどれだけ下がり、車は何台増えるのか？」は、上に重ねられない荷物の上の空きが体積の見込みに入らず、置き方の決まりしだいで台数が増えることを数えています。1298「用意する箱の大きさを2種類から4種類に増やすと、箱の中のすきま（詰め物の量）はどれだけ減るのか？」は、箱の大きさの種類を増やすと箱の中のすきまがどれだけ減るかを、中身を体積だけで「入る・入らない」と決めて数えています。この記事は、1298 などが置いている「形を考えない」見込みが、縦・横・高さで並べるとどれだけ外れるかを、1つの注文ごとに数えます。

## 主な結果

### 詰まり具合ごと（基本の置き方、各300件、`results/base_by_fill.csv`）
| 体積の合計÷容量 | 並べると入らない（下〜上） | うち1つで入らない荷物がある | 1つずつなら入る注文のうち、組み合わせで入らない（下〜上） | 体積で入る注文に占める割合（自然な割合） |
|---|---|---|---|---|
| 50%以下 | 2.33〜2.33% | 2.33% | 0.0〜0.0% | 95.44% |
| 50〜70% | 21.67〜22.67% | 14.67% | 8.2〜9.38% | 3.71% |
| 70〜85% | 64.0〜77.67% | 32.33% | **46.8〜67.0%** | 0.64% |
| 85〜100% | 85.33〜99.67% | 51.0% | **70.07〜99.32%** | 0.2% |

- **体積の合計が容量の70〜85%の注文では、どの荷物も1つなら箱に入るのに、並べると入らないものが46.8〜67.0%あった**（46.8%は2つの組が入らないことで確か、残りは探した並べ方で見つからなかった分）
- 85〜100%では、1つずつなら入る注文のうち70.07〜99.32%が入らなかった。並べて入ったのは300件のうち1件（0.33%）だった
- 50%以下では、入らなかった2.33%はすべて「1つで入らない荷物がある」（縦・横・高さのどれかが箱の内のりより長い荷物）だった
- 例：荷物4個（5×13×21・9×11×9・31×28×15・16×12×11cm）の注文は、体積の合計が容量の57.96%なのに入らない。31×28×15cm の荷物は、31cm を横40cm、28cm を奥行き30cm に置くしかなく、その横に残る空きは幅9cm、奥に残る空きは2cm、上に残る空きは10cm だけで、いちばん短い辺が11cm の16×12×11cm の荷物はどの空きにも入らないため（`a1299_main.json` の example_pair_fill_le70）

### 体積で入る注文全体では（自然な割合で重みづけ、`a1299_main.json` の weighted_all）
- 基本の置き方では、**体積の合計が容量以下の注文のうち、並べると入らないのは3.61〜3.77%**だった。うち3.08%は1つで入らない荷物がある注文で、組み合わせで入らないのは1つずつなら入る注文の0.55〜0.71%だった
- 全体の割合が小さいのは、この置き方では体積で入る注文の95.44%が詰まり具合50%以下だったため。入らない注文は、詰まり具合の高い少数の注文に集まっていた

### 荷物の個数ごと（区分ごとに300件ずつ取った1,200件をそのまま数えたもの、`results/base_by_items_stratified.csv`）
- 1つずつなら入る注文のうち組み合わせで入らない割合は、2個で11.32%（下と上が同じ）、3個で27.19〜32.89%、4個で27.15〜41.6%だった。2個の注文は判定で入る・入らないが確かに決まるので、見つからない分は0だった

### 確かめ：18通り（`results/grid.csv`）
- **詰まり具合70〜85%で、1つずつなら入る注文のうち組み合わせで入らない割合は、件数の足りる10通りで33.17〜84.88%（下）〜65.43〜96.51%（上）だった**。85〜100%では60.94〜100.0%（下）〜96.88〜100.0%（上）
- 荷物の中央値9cmの6通りは、体積で入る注文の99.94〜99.96%が詰まり具合50%以下で、70〜85%の注文が足りなかった（4,000件×40回で2〜9件）。箱50×40×15cmで上下をそのままにする2通りは、荷物の高さが15cmを超えると入らないので、70〜85%の注文の99.0〜99.33%が1つで入らない荷物を含み、組み合わせの割合は出せなかった
- 体積で入る注文全体のうち入らない割合（上）は0.01〜80.74%と、置き方で大きく動いた。ほとんどは1つで入らない荷物の分（0.01〜80.47%）で、組み合わせで入らない分（1つずつなら入る注文のうち、上）は0.0〜15.06%だった
- 上下をそのままにすると、1つで入らない荷物のある注文の割合は2.03〜80.47%で、6通りの向きを使ってよいとき（0.01〜30.76%）より高かった
- 区分ごとの「探した並べ方では見つからない」の割合は、最大で25.33%だった。切り分けでは入らず④で初めて入った注文は、区分ごとに最大1.27%だった

- `results/base_by_fill.csv`：詰まり具合の区分ごと（no_fit_low/high は入らない割合の下・上、combo_low/high は1つずつなら入る注文のうち組み合わせで入らない割合の下・上、natural_share_pct は自然な割合）

## 注意（言えないこと）
- 架空のデータです。荷物の大きさの分布、1注文の個数、箱の寸法、向きの決まりは作成者が置いたもので、結果はこれで決まります。とくに体積で入る注文全体の割合（0.01〜80.74%）は置き方で大きく動きました
- 「探した並べ方では見つからない」注文は、作成者の作った探し方（切り分け＋置いた荷物の面の位置を組み合わせた所に置く）で見つからなかったもので、入らないと言い切れるものではありません。そのため割合を下（確か）と上（見つからないを含む）の幅で書きました
- 荷物は箱の面に平行に置き、つぶれない・曲がらない直方体としました。斜めに置く、やわらかい荷物を押し込む、といったことは考えていません。詰め物の厚みも考えていません
- 詰まり具合の区分ごとに同じ件数を取ったので、区分をまたいだ「1,200件の割合」は自然な割合とは違います。体積で入る注文全体の割合は、自然な割合で重みづけした値を使ってください
- どの箱を使うか、送料・料金をどう決めるかの助言をする記事ではありません
