# F07 新卒は何年目に辞めやすいのか？（離散時間ハザード・卒業年コホート）

看板記事シリーズの7本目です。厚生労働省「新規学卒就職者の離職状況」の集計値を、解約・退会の分析（チャーン分析）と同じ「生存分析」の形に直しました。1996〜2025年3月卒の30の卒業年について、1年目・2年目・3年目に辞める確率（ハザード）を学歴別に出し、「就職した年の景気」と「辞める年の景気」がそれぞれどれだけ効くかを、離散時間ハザードモデルで推定しています。

## 問い

- 新卒が辞める確率は、1年目・2年目・3年目でどう違うか。30年でその形は変わったか
- 就職した年の景気（入口）と、辞める年の景気（出口の選択肢）は、それぞれどれだけ離職を左右するか
- 産業や事業所の規模で、辞めやすい年目は違うか

## データ

詳しくは `data/raw/SOURCES.md`。

| データ | 中身 | 期間 |
|---|---|---|
| 厚生労働省「新規学卒就職者の離職状況」在職期間別離職状況（表） | 学歴（中学・高校・短大等・大学）×卒業年の就職者数と、1・2・3年目の離職者数 | 1996〜2023年3月卒は3年目まで、2024年卒は2年目まで、2025年卒は1年目まで |
| 同 産業別離職状況（大学・高校） | 産業×卒業年の就職者数と、1・2・3年目までの累積離職者数 | 2003〜2025年3月卒 |
| 同 事業所規模別離職状況（大学・高校） | 規模（6区分）×卒業年の1・2・3年目までの累積離職者数と離職率 | 2003〜2023年3月卒 |
| 厚生労働省「一般職業紹介状況」 | 有効求人倍率（パートを含む一般、全国、年平均） | 1963〜2025年 |
| 総務省「労働力調査」長期時系列 | 完全失業率（季節調整値の年平均） | 1953〜2026年 |

整形後：`data/turnover_by_education.csv`（120行）、`data/turnover_by_industry.csv`、`data/turnover_by_size.csv`、`data/macro_annual.csv`。

厚労省の表は PDF なので、ページ上で pdf.js（getTextContent）を使って文字を取り出し、行ごとに並べたものを `data/raw/mhlw_turnover_pdf_text.json` に置いています。`src/01_parse.py` がそこから表を作り、次の点を確かめています。

- 1〜3年目の離職者数の合計が「3年目までの離職者数」と一致する（1996〜2023年卒のすべて）
- 離職者数÷就職者数が、表の離職率と0.05ポイント以内で一致する
- 産業別の「調査産業計」の就職者数・3年目までの離職者数が、学歴別の表と一致する
- 規模別の3年目までの値が、同じリポジトリの記事 184 で書き写した値と一致する

## 手法

| 項目 | 内容 |
|---|---|
| ハザード | k年目のハザード ＝ k年目の離職者数 ÷（就職者数 − k−1年目までの離職者数）。その年の初めに残っていた人のうち、その年に辞めた割合 |
| 残存曲線 | 卒業年代（5年ずつ）ごとに離職者数と残っていた人を合計してハザードを出し、掛け合わせる（集計値の Kaplan–Meier 風） |
| 離散時間ハザードモデル | 二項ロジット（集計値）：logit h = 学歴×経過年数の固定効果 ＋ β₁·log(就職年の求人倍率) ＋ β₂·log(辞める年の求人倍率) ＋ 直線のトレンド。就職年＝卒業の前年（就職活動をした年）、辞める年＝k年目の始まる暦年（卒業年＋k−1）。標準誤差は卒業年でクラスター（30クラスター） |
| 傷跡（入口の景気が残るか） | 就職年の求人倍率 × 2年目以降 の交差項を加える |
| 産業別・規模別 | 2010〜2022年卒（産業）、2003〜2023年卒（規模）を合計してハザードを出す。産業別の1・2・3年目までの累積は、それぞれ卒業の翌年・翌々年・3年後の6月に把握した値 |
| 頑健性 | 学歴別に推定／景気を完全失業率に入れ替え／2009〜2012年卒（リーマン・ショック前後）を除く／2020・2021年の離職を除く／トレンドなし／高校と大学だけ |

## 主な結果

**何年目に辞めやすいか（1996〜2025年卒の合計）**

| 学歴 | 1年目 | 2年目 | 3年目 |
|---|---|---|---|
| 中学 | 44.8% | 25.1% | 21.0% |
| 高校 | 21.0% | 16.0% | 13.8% |
| 短大等 | 18.2% | 15.4% | 15.9% |
| 大学 | 12.7% | 12.3% | 12.0% |

- 高校卒は1年目のハザードがはっきり高く、年目とともに下がる。大学卒はほぼ平ら
- 大学卒は30年で形が変わった：1996〜2000年卒は 14.0% → 12.6% → 11.8% と1年目が最も高かったが、2016〜2020年卒は 11.4% → 12.2% → 12.5% と、2・3年目のほうが高い
- 3年目の終わりに残っている割合：大学卒は 66.3%（1996〜2000年卒）→ 68.1%（2016〜2020年卒）、高校卒は 52.0% → 62.3%

**景気の効き方（基本モデル、95%区間）**

| 項目 | 係数 |
|---|---|
| log(就職年の求人倍率) | −0.134（−0.223〜−0.044） |
| log(辞める年の求人倍率) | +0.201（+0.130〜+0.272） |

- 就職した年が不景気だと辞めやすく、辞める年が好景気だと辞めやすい（2つの景気は逆向きに効く）
- 求人倍率だけを0.5倍と1.5倍で比べると、3年以内の離職率（大学卒・2010年卒の水準）は、就職年で 35.2% と 31.4%、辞める年で 29.4% と 34.9%
- 傷跡モデル：就職年の景気の係数は、1年目 −0.307（−0.387〜−0.226）、2・3年目 −0.035（−0.124〜+0.055）。入口の景気が効くのは1年目で、2・3年目にはほとんど残っていない
- 予測と実際のハザードの相関は 0.967

**産業・規模（大学卒）**

- 3年以内の離職率（2010〜2022年卒）は、電気・ガス・熱供給・水道業 10.3%、製造業 19.3% から、宿泊業・飲食サービス業 51.8% まで
- 製造業・金融業・情報通信業などは1年目より2・3年目のハザードが高く、宿泊・飲食、生活関連サービス、教育などは1年目から高い
- 規模別では、1,000人以上の事業所は 7.9% → 9.4% → 9.7% と年目とともに上がり、5人未満は 30.2% → 24.4% → 21.2% と下がる。高校卒はどの規模でも年目とともに下がる

**頑健性**

就職年の係数はどの推定でも負（−0.097〜−0.241）、辞める年の係数はすべて正で、中学だけを除いて区間が0をまたがない（中学だけは +0.067、トレンドなしは +0.096 と小さめ）。失業率に入れ替えると、就職年の失業率 +0.076、辞める年の失業率 −0.084 と、同じ向きになる。

## このデータで言えないこと

- 1人ずつのデータではなく、卒業年ごとの集計値。辞めた理由（転職・進学・家庭の事情など）や、辞めたあとどうなったかは分からない
- 離職＝悪いこととは言えない（より合う仕事への転職も含まれる）
- 「卒業年」「経過年数」「暦年」は1つ決めると残りが決まるので、トレンドの入れ方で係数が変わる（トレンドなしでは就職年の係数が大きく、辞める年の係数が小さくなる）。就職年とその年の求人倍率は相関が高い（0.70）
- 雇用保険の加入記録から把握した数値で、加入しない働き方（短い時間のパートなど）は入っていない。2024・2025年3月卒は、それぞれ2年目・1年目までしか分からない
- 産業別の1・2・3年目までの累積は把握した時点が違い、学歴別の表（3年後にまとめて把握）とはわずかにずれる
