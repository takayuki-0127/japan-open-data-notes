# 655 平均の購入間隔を「2回以上買った人」だけで出すと、本当の間隔よりどれだけ短く出るのか（実務の型・顧客の指標）

購入間隔は、購入と購入のあいだの日数なので、2回以上買った人からしか出せません。ところが、2回以上買えるのは間隔の短い人に偏り、短い間隔の人ほどたくさんの間隔を残します。観察の期間が短い（登録して間もない）人では、長い間隔はそもそも観察できません。**ここでは、架空の会員1万人（2024〜2025年に少しずつ登録）に、1人ずつ本当の平均の購入間隔（中央値90日、人による差が大きい）を置いて購入を作り、よくある出し方と比べました。** 間隔の分布は作成者が置いたもので、数字はその仮定で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A655 | 2回以上買った人だけで出した購入間隔は、本当の値からどれだけずれるか | I1 2回以上の人の間隔の平均、I2 2回以上の人ごとの平均を人で平均、I4 登録から1年以上の人だけで I1、I3 見ていた日数の合計÷購入回数の合計。DuckDB（1スレッド）と pandas で一致を確認。seed 655 | `src/a655_interval.py`、`src/02_interval_duckdb.sql`、`src/01_interval_tsql.sql`（未検証） |

## 主な結果
- **本当の値**：1人ずつの平均の購入間隔の平均は113.6日（中央値89.2日）。全体で見て「何日に1回買われるか」は70.2日
- **2回以上買った人の間隔の平均（I1）は48.8日**：1人ずつの本当の平均より **57.0%** 短く、「全体で何日に1回」よりも短い
- **2回以上買えた人は71.0%**。計算から外れる0回・1回の人の本当の間隔は平均164.2日で、残る人（92.9日）より長い
- **観察の長さで変わる**：登録から3か月未満の人では、2回以上買えたのは14.8%で、その間隔の平均は16.2日。18〜24か月の人では93.6%・54.0日
- **1年以上見た人に絞っても（I4）52.0日**で戻らない。1人ずつの平均を人で平均（I2）しても69.1日
- **見ていた日数÷購入回数（I3）は70.9日**で、「全体で何日に1回」（70.2日）とほぼ一致した（+1.0%）。ただし、1人ずつの間隔の平均（113.6日）とは別のものを当てている

## 動かし方
```
pip install -r requirements.txt
cd src && python a655_interval.py
```
数秒で終わります。`data/` に customers（customer_id・registered_on）と purchases（customer_id・bought_on）を、`results/true_interval.csv` に作成者が置いた本当の間隔を書き出します。

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures がバイト単位で一致した（DuckDB は `SET threads=1`）
- I1 と I3 が DuckDB と pandas で一致した
- T-SQL 版（`01_interval_tsql.sql`）は書いたが、SQL Server では動かしていない（**未検証**）

## データ
- 仮定：登録日は2024-01-01〜2025-12-30 で一様、観察の終わりは2025-12-31。1人ずつの平均の購入間隔は対数正規（中央値90日、対数の標準偏差0.7）、購入はポアソン過程。途中でやめる人（離反）は置いていない

## 注意（言えないこと）
- 架空のデータ。実際の店の数字ではない
- 実際には途中で買わなくなる人がいるので、ずれ方はもっと複雑になる。ここでは「選ばれ方」と「観察の長さ」だけでどれだけずれるかを見た
- 「平均の購入間隔」は、1人ずつの間隔の平均か、全体の頻度の逆数かで意味が違う。どちらを出しているかを書いておくのが安全
