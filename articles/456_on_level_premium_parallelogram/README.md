# 456 料率を改定したあと、過去の保険料を「いまの料率」に直す近似は、どれだけずれるのか（手法の解説）

料率を改定したあとで過去の年の損害率を見るときは、過去の保険料を「いまの料率だったら」に直します。**契約ごとにいまの料率で計算し直した値（正解）と、暦年の保険料に係数を1つ掛けるだけの近似を、架空の1年契約で比べた**フォルダです。近似は、契約の始期が1年に均等に散らばると置く方法（平行四辺形の方法と呼ばれます）です。315（経過保険料の按分）・343（事故年と支払年）とは別で、料率の水準のそろえ方に絞っています。料率の決め方についての助言ではありません。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A456 | 始期が均等でないとき・契約が増減しているとき・改定が年に2回あるとき、係数を掛ける近似は正解からどれだけずれるか。月ごとの収入保険料を使うと、ずれはどこまで消えるか | 架空の契約（2021年に6万件。始期の散らばり方4通り×契約の増え方3通り）に改定を当て、暦年の経過保険料を、契約ごとの計算・均等と置いた係数・月ごとの実績を使った係数の3通りで直す | `src/a456_on_level.py` |

## 置いたこと（架空）
- 契約は1年契約。保険料は、始期の時点の料率で決まり、1年かけて日割りで経過する（途中解約・途中の変更なし）
- 改定は「その日以降に始まる契約から」当たる。基本の場面は、2023年7月1日の始期から+10%
- 始期の散らばり方：均等／毎月1日に集中／4割が4月1日／4割が10〜12月。契約の増え方：年20%減・増減なし・年20%増
- 近似の係数＝いまの料率の水準 ÷ その暦年の平均の水準（始期が均等と置いて出す）。2023年は1.0864、2024年は1.0115
- 直し方：始期の月ごとの収入保険料（実績）で重みをつけて、同じ係数を出す（月の中は均等と置く）
- 損害率への移り方は、本当の損害率（いまの料率で見た値）を65%と置いて計算

## 主な結果
### +10%の改定（2023年7月1日）のあと、近似のずれ（%、正解＝契約ごとの計算）
| 始期の散らばり方 | 2023年：年20%減 | 増減なし | 年20%増 | 2024年：年20%減 | 増減なし | 年20%増 |
|---|---|---|---|---|---|---|
| 均等 | −0.18 | +0.01 | +0.15 | −0.19 | +0.02 | +0.13 |
| 毎月1日に集中 | 0.00 | +0.19 | +0.38 | +0.03 | +0.19 | +0.31 |
| 4割が4月1日 | −0.59 | −0.49 | −0.41 | −0.71 | −0.46 | −0.26 |
| 4割が10〜12月 | −0.19 | 0.00 | +0.18 | +0.35 | +0.46 | +0.54 |

### 改定の日・幅・回数を変えたとき（始期の4割が4月1日、増減なし。2023年のずれ）
| 場面 | ずれ | 65%の損害率の見え方 |
|---|---|---|
| +10%（1月1日） | +0.94% | −0.61ポイント |
| +10%（4月1日） | **+1.82%** | **−1.16ポイント** |
| +10%（7月1日） | −0.49% | +0.32ポイント |
| +10%（10月1日） | −0.12% | +0.08ポイント |
| +3%／+5%／+20%／−10%（7月1日） | −0.15／−0.25／−0.97／+0.50% | |
| +5%を2回（4月1日・10月1日） | +0.85% | −0.55ポイント |
| +5%を3年続けて（毎年4月1日）、2022〜2024年 | +0.94〜+0.99% | −0.60〜−0.64ポイント |

- 試した110通り（場面×年）で、ずれの大きさは最大1.82%。始期が均等で増減がなければ、どの場面でも ±0.03%以内
- 月ごとの収入保険料を使った係数では、ずれは最大0.28%。残ったのは、月の中で始期が1日に寄っている分
- 始期が均等・増減なし（近似の前提どおり）でも、契約が少ないと偶然の振れが残る：年500件で ±0.10%、2,000件で ±0.05%、6万件で ±0.01%（200回の標準偏差）

全部の数字は `results/onlevel_errors.csv`、`results/small_book_noise.csv`、`results/main.json` にあります。

## 確かめたこと
- 空のフォルダで計算し直し、data・results・figures が一致した
- 始期が均等・増減なしのとき、近似の係数（2023年 1.0864、2024年 1.0115）と、契約ごとの計算から出した係数の差は0.02%以内
- 改定の前に全部が経過した年（2022年）と、全部が新しい料率になった年（2025年）は、ずれが0

## 注意（言えないこと）
- 架空の契約です。数字は、始期の散らばり方・契約の増え方・改定の日と幅の置き方で決まります
- 1年契約だけです。長期の契約、途中解約、途中での内容の変更、月払いの失効は入れていません
- 改定は全部の契約に同じ率で当たると置きました。契約の種類ごとに率が違う改定（構成が変わると平均の率も動く）は扱っていません
- 料率をどう決めるべきか、どの方法を使うべきかを言うものではありません。本物の保険データでは確かめていません
- 損害率への移り方は、保険料の側だけを見た計算です。損害の側の直し（物価など）は扱っていません
