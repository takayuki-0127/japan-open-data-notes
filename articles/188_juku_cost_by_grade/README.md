# 188 塾代は、何年生でピークになるか：子供の学習費調査

文部科学省「子供の学習費調査」の学年別の学習費から、学習塾費（1人あたり年額）を小1〜高3の12学年に並べ、どの学年で最も多くなるかを、2018・2021・2023年度の3回の調査と公立・私立で比べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A188 | 学習塾費は何年生でピークになるか。通う割合と、通う子の金額のどちらで決まるか | 学年別プロファイル（12学年×3調査×公立・私立）、支出率と支出者平均額の分解、学習費総額に占める割合 | `src/a188_profile.py` |

## 主な結果
- 公立の学習塾費（通っていない子も含めた1人あたり平均）は、3回の調査とも中3がピーク。2023年度は中3で34.1万円（2021年度39.0万円、2018年度31.4万円）
- 2023年度の公立は小1 3.2万円→小6 14.5万円（4.6倍）、中1 13.4万円→中3 34.1万円（2.6倍）。高1は9.0万円と中3の約4分の1に下がり、高3で20.6万円
- 塾代を払った割合（支出率）は中3が最も高く78.6%。払った子の平均額は高3が45.2万円で中3（43.4万円）より多い。高1で1人あたり平均が大きく下がるのは、払った割合（34.3%）と払った子の平均額（26.2万円）がともに下がるため
- 公立中3では、学習塾費が学習費総額（学校の費用や習い事を含む）の56.2%を占める
- 私立小学校は小6が最も多く44.3万円（2023年度）。私立中・高では中3 20.2万円、高3 21.5万円で、公立のような中3の山はない

- statInfId：2023年度 表2 000040233661〜63・表3 000040233665〜67、2021年度 表2 000032268973〜75・表3 000032268977〜79、2018年度 表2 000031894253〜55・表3 000031894257〜59
- ダウンロード：`https://www.e-stat.go.jp/stat-search/file-download?statInfId=<ID>&fileKind=0`

## 注意
- 学年ごとに別の子どもの平均（ある年度の横断面）で、同じ子を12年追いかけたものではない。12学年を足した金額は目安にとどまる
- 公立・私立は学校ごとに別の集団で、「公立小→公立中」のような進路別の合計ではない
- 標本調査で、学年別の値には誤差がある（調査票の注では学習費総額の標準誤差率は公立小の学年別で2〜4%程度）。2021年度はコロナ禍の影響を受けている可能性がある
- 金額は名目値で、物価の変化はならしていない
