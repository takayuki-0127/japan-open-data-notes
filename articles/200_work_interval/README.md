# 200 勤務間インターバル制度の導入率は、企業規模でどれだけ違うか：就労条件総合調査

厚生労働省「就労条件総合調査」から、勤務間インターバル制度（終業から次の始業までに一定の休息時間を置く制度）を導入している企業の割合を、企業規模別（2018〜2025年調査）と産業別（2025年調査）に並べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A200 | 勤務間インターバル制度の導入率は、企業規模でどれだけ違うか | 企業規模別の導入率の推移（8回分）、2025年調査の導入状況（導入・予定検討・予定なし）、産業別・製造業の規模別の導入率 | `src/a200_interval.py` |

## 主な結果
- 導入している企業は2018年調査1.8%→2025年調査6.9%
- 2025年調査で1,000人以上は20.1%、30〜99人は6.1%（3.3倍）。300〜999人9.6%、100〜299人7.5%
- 1,000人以上と30〜99人の差は2018年調査3.7ポイント→2025年調査14.0ポイントに広がった。倍率は2〜4倍の間で動いている
- 「導入の予定はなく、検討もしていない」は1,000人以上55.0%、30〜99人80.8%
- 産業別（2025年調査）は運輸業・郵便業15.9%、電気・ガス・熱供給・水道業12.1%、金融業・保険業10.4%が高く、複合サービス事業1.4%、サービス業（他に分類されないもの）4.0%、卸売業・小売業5.0%が低い
- 製造業では1,000人以上26.2%、30〜99人5.0%（5.2倍）
- 導入企業の1企業平均の間隔時間は10時間51分（2025年調査、全体）

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a200_interval.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/interval_by_size.csv | 調査年、企業規模、導入している・導入を予定または検討している・予定なく検討もしていない・不明の企業割合（%）、導入企業の平均間隔時間 |
| data/interval_2025_detail.csv | 2025年調査の企業規模別・産業別・製造業の規模別の導入割合と、間隔時間の区分（9時間未満〜11時間超）別の割合 |

- 就労条件総合調査の「産業・企業規模、勤務間インターバル制度の導入状況別企業割合」の表：2018年（statInfId 000031837670）、2019年（000031908988）、2020年（000032047315）、2021年（000032166114）、2022年（000040013224）、2023年（000040140781）、2024年（000040242221）、2025年（000040389695）
- ブラウザで Excel を読み、調査産業計の企業規模別の行と、2025年の産業別の行を書き写した。2022年調査からは間隔時間の区分（9時間未満〜11時間超）が加わったので、推移は「導入している」の合計で比べた

## 注意
- 調査は常用労働者30人以上の民営企業が対象。各年1月1日現在の状況
- 2018〜2020年の表は労働組合の有無別の表と一緒になっているため、調査産業計の部分を使った
- 割合は企業の数の割合で、働く人の数の割合ではない
- 産業別・規模別の細かい区分は標本が少なく、年ごとに動きやすい
- 企業規模で導入率が違う理由（人事の体制、業務の性質など）は、このデータでは分からない
