# 372 CSV を Excel で開いて保存すると、何セルが変わってしまうのか（実務の型）

CSV をダブルクリックして Excel で開き、何も触らずに CSV で保存し直す。それだけでセルの文字が変わることがあります。Excel（日本語の設定、表示形式は「標準」）の自動変換のうち、公開されている決まり8つを Python で再現し、架空の顧客 CSV（5,000行×9列）と商品 CSV（2,000行×7列）で、変わるセルと元に戻せないセルを数えたフォルダです。**Excel 本体では動かしていません（未検証）**。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A372 | 開いて保存するだけで何セルが変わるか。そのうち元に戻せないのはどれだけか | 1セルの文字が「開いて保存したあと」にどうなるかを返す関数（8つの決まり）を作り、全セルに当てる。保存後の文字と列の決まり（桁数など）だけから元の文字が1通りに決まるセルを「戻せる」、決まらないセルを「戻せない」と数える | `src/a372_excel_roundtrip.py` |

再現した決まり：先頭の0が落ちる／12桁以上は指数表記（1.23457E+11）になる／16桁以上は15桁までしか持てず、指数表記になって下の桁が消える／「1-2」「1/2」は日付（1月2日）になる／「2025-04-01」は「2025/4/1」になる／「12E3」は指数（1.20E+04）と読まれる／小数の末尾の0が落ちる／「true」は「TRUE」になる。

## 主な結果
- **変わったセル**：59,000セルのうち27,411セル（46%）。顧客 CSV は45,000セルのうち22,667セル（50%）、商品 CSV は14,000セルのうち4,744セル（34%）。16列のうち11列で、1セル以上が変わった
- **元に戻せないセル**：7,222セル（12%）。16桁の会員番号5,000セル、13桁の JAN コード2,000セル、「12E3」のような型番222セル
- 戻せない2つのコードは、保存後に別々の値が同じ文字になる。会員番号は5,000種類が4,983種類に、JAN コードは2,000種類が1,811種類になった
- **決まりで戻せるセル**：20,189セル。先頭の0（6,435セル。桁数が決まっていれば0を足して戻せる）、日付の書き方（5,000）、TRUE・FALSE（5,000）、日付になった部屋番号・サイズ・型番（2,216）、小数の末尾の0（1,538）
- 変わらなかった列：氏名、ハイフンつきの郵便番号、ポイント、在庫数、商品名

## 動かし方
```
pip install -r requirements.txt
cd src && python a372_excel_roundtrip.py
```
乱数の種を固定してあるので、実行のたびに同じ `data/`・`results/`・`figures/` を出します。

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した
- 決まりの関数が、よく知られた例（00123→123、4901234567894→4.90123E+12、1-2→1月2日、12E3→1.20E+04 など16例）と同じ答えを返すことを、コード内の assert で確かめた（`results/rule_examples.csv`）

## データ
- `data/customers.csv`・`data/products.csv`：架空の CSV（seed 372）。`data/*_after_excel.csv`：決まりを当てたあと
- `results/changed_by_column.csv`：列ごとの変わったセル・戻せないセル。`results/changed_by_rule.csv`：決まりごとの件数

## 注意（言えないこと）
- **Excel 本体では動かしていません**。公開されている決まりを Python で再現した結果です。Excel の版や地域の設定で、動きが違うことがあります（日付の表示は日本語の設定を前提にしました）
- このデータに出てくる書き方だけを扱いました。「1-2-3」「13-1」「MAR1」のような文字、数式に読まれる文字（= や + で始まる）、文字コードの違いによる文字化けは入れていません
- 変わる割合は、列の中身で決まります。電話番号や会員番号のような列が多い CSV ほど大きくなります。実際のデータでの割合ではありません
- 「戻せる」は、列の書き方が1つに決まっている場合の話です。「1-2」と「1/2」が同じ列に混ざっていれば、日付になったセルは戻せません
- 「データの取り込み」で列を文字列に指定して開く、拡張子を変える、といった避け方は試していません
