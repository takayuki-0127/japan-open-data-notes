# 250 連泊は増えているのか

宿泊旅行統計調査の延べ宿泊者数（人泊）を実宿泊者数（人）で割ると、1回の宿泊で平均何泊したか（平均泊数）になります。これを日本人・外国人、施設の区分・タイプで2015〜2025年に並べ、全体の伸びを分けました。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A250 | 連泊は増えているのか | 平均泊数＝延べ宿泊者数÷実宿泊者数。全体の変化を、日本人の平均泊数の変化・外国人の平均泊数の変化・外国人の割合（実宿泊者数で）の変化に分ける（2つの年の重みの平均を使う分け方） | `src/a250_nights_per_stay.py` |

## 主な結果
- 全体の平均泊数：1.331泊（2015年）、1.342泊（2019年）、1.429泊（2024年）、1.424泊（2025年）
- 日本人：1.303（2015年）、1.292（2019年）、1.338（2024年）、1.320（2025年）。外国人：1.554、1.598、1.794、1.806
- 実宿泊者に占める外国人の割合：11.2%（2015年）、16.3%（2019年）、21.5%（2025年）
- 2019→2025年の全体の伸び+0.082泊の分け方：日本人の平均泊数の伸び+0.022、外国人の平均泊数の伸び+0.039、外国人の割合が増えた分+0.020。外国人に関わる分が73%
- 2015→2019年の伸び+0.011泊は、日本人が −0.009、外国人の平均泊数が+0.006、外国人の割合が+0.014
- 日本人の平均泊数を2025年と2019年の同じ月で比べると、12か月すべてで2025年が長い（+0.009〜+0.041泊。最も小さいのは8月）
- 施設タイプ別の日本人（2019→2025年）：旅館1.19→1.18、リゾートホテル1.27→1.28、ビジネスホテル1.32→1.35、シティホテル1.31→1.37、簡易宿所1.40→1.45、会社・団体の宿泊所1.39→1.41

## 頑健性
- 施設の区分別でも、2019→2025年はすべての区分で平均泊数が伸びた（観光の宿1.315→1.420、出張などの宿1.373→1.417、従業者0〜9人1.429→1.500、100人以上1.375→1.463）（`results/a250_nights_per_stay.csv`）
- 分け方は2つの年の重みの平均を使い、3つの分の合計は全体の変化と一致する
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致することを確かめた

## 動かし方
```
pip install -r requirements.txt
cd src && python a250_nights_per_stay.py   # data/ の CSV から results/・figures/ を作る
python fetch.py             # data/ の CSV を観光庁の Excel から作り直す（任意。ネットにつながる環境で）
```

## データ
- `data/table<n>_national.csv`：観光庁「宿泊旅行統計調査」各年（2015〜2025年）の「1月〜12月分（年の確定値）集計結果」Excel から、全国の行だけを取り出したもの（`src/extract.py`）。month=0 は年計、1〜12 は各月。列名は `src/extract.py` の COLS（total＝総数、tour＝観光目的の宿泊者が50%以上の施設、biz＝同50%未満の施設、s0_9 など＝従業者数の区分、foreign＝うち外国人）
- 施設数（第1表）は各月の値で、年の値は12か月の平均にした

## 注意
- 平均泊数は施設ごとの数字の比で、旅行1回の泊数ではない。同じ旅行で2つの宿に1泊ずつ泊まると、平均泊数は1泊が2回と数えられる。宿を移らず同じ宿に続けて泊まる人が増えたのか、旅行そのものが長くなったのかは分けられない
- 施設タイプ別の数字は標本から推計した値で、タイプの合計は総数と一致しない年がある
- 2020〜2022年の外国人は人数がとても少なく、平均泊数（2021年2.19泊）は長く滞在する在留者などに引っぱられている可能性がある（推測）
