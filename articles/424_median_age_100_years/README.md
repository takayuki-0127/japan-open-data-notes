# 424 日本の人口の「真ん中の年齢」は、100年でどう上がったのか（国勢調査、1920〜2020年）

国勢調査の5歳階級別人口から、年齢の中央値（その年齢より若い人と年上の人が半分ずつになる年齢）を調査年ごとに計算したフォルダです。140（人口ピラミッド）と近い題材を、1つの数字で追っています。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A424 | 人口の年齢の中央値は、100年でどう上がったか | 5歳階級の人数を足し上げ、半分になる階級の中を比例で内挿。男女別、5年ごとの上がり、10歳上がるのにかかった年数 | `src/a424_median_age.py` |

## 主な結果
- 中央値：1920年 22.3歳 → 1930年 21.9歳 → 1950年 22.3歳 → 1960年 25.6歳 → 1980年 32.7歳 → 2000年 41.5歳 → 2020年 48.6歳
- 1920〜1950年の30年間は22歳前後のまま。1950年からの70年で26.3歳上がった
- 1950年の値から10歳上がったのは1979年ごろ（約29年）、20歳上がったのは2002年ごろ（そこから約23年）
- 5年間の上がりが大きかったのは1975〜95年（2.2〜2.5歳）。2000年以降は5年で1.7〜1.9歳
- 男女：1920年 男22.1歳・女22.6歳 → 2020年 男47.1歳・女50.2歳。差は0.5歳から3.0歳に
- 15歳未満の割合は36.5%から12.1%、65歳以上は5.3%から28.7%（年齢不詳を除く）

## 確かめたこと
- 2020年の中央値48.6歳は、国勢調査の結果として知られる年齢中位数（48.6歳）と同じ
- 階級の中を均等と置く方法と、前後の階級から傾きをつける方法の差は、全調査年で0.15歳以内
- 2015・2020年は、年齢不詳をあん分した値でも計算（46.8歳・48.5歳で、差は0.1歳以内）
- 空のフォルダで流し直し、results・figures が一致した

## データ

## 注意（言えないこと）
- 5歳階級から内挿した値で、各歳の人数から出した値とは小数第1位がずれることがあります
- 1945年は数え年での調査で、沖縄県を除きます（表の注）。軍人なども入っていないため、男の中央値（19.6歳）は前後の年と比べられません。本文の節目には使っていません
- 1940年は一部の外国人を除く人口です。2015・2020年は年齢不詳の人（2020年は2.3%）を除いて計算しています
- 中央値は「真ん中の1点」で、子どもや高齢の人がどれだけいるかは別に見る必要があります
- 上がった理由（出生の減り方・寿命の延び・世代の大きさ）は分けていません。将来の見通しも出していません
