# 423 「市」に住む人が半分を超えたのは、いつだったのか（国勢調査、1920〜2020年）

国勢調査の市部・郡部別人口（1920〜2020年）と、人口集中地区の人口（1960〜2020年）を並べ、市部の割合の上がり方のうち、合併で市が増えた時期の分がどれだけあるかを見たフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A423 | 市部に住む人の割合は、いつ5割・7割・9割を超えたか。合併の影響はどれくらいか | 市部の割合と人口集中地区の割合を並べ、5年ごとの変化を比べる。市の数・町村の数の変化と照らす | `src/a423_city_share.py` |

## 主な結果
- 市部の割合：1920年 18.0% → 1940年 37.7% → 1945年 27.8% → 1950年 37.3% → 1955年 56.1% → 1970年 72.1% → 2000年 78.7% → 2010年 90.7% → 2020年 91.8%
- はじめて超えた調査年：5割 1955年、6割 1960年、7割 1970年、8割 2005年、9割 2010年
- 5年間の上がりが大きかったのは、1950→55年 +18.8ポイント（市 +242、町村 −5,865）、2000→05年 +7.6（市 +79、町村 −1,092）、2005→10年 +4.4（市 +36、町村 −525）。この3回で30.8ポイント、100年の上がり73.7ポイントの42%
- 人口集中地区に住む人の割合：1960年 43.7% → 1970年 53.5% → 2000年 65.2% → 2020年 70.0%。5割を超えたのは1970年、7割は2020年
- 2000→2010年に市部の割合は+12.0ポイント、人口集中地区の割合は+2.1ポイント。市部の中で人口集中地区に住む人の割合は78.6%から71.9%に下がった
- 市の数は83から793に、町村の数は12,161から926になった（東京都の特別区部は1市と数える）

## 確かめたこと
- 自分で計算した市部の割合は、表の割合と全調査年で一致（小数第1位）
- 合併の少なかった1960〜2000年の5年あたりの上がりは、市部 +1.9ポイント、人口集中地区 +2.7ポイント
- 空のフォルダで流し直し、results・figures が一致した

## データ
- `data/ipss2026_T09-09_shibu_gunbu.csv`：国立社会保障・人口問題研究所「人口統計資料集 2026」表9-9 市部・郡部別人口および市町村数：1920〜2020年
- `data/ipss2026_T09-10_did.csv`：同 表9-10 市部・郡部別人口集中地区人口および面積：1960〜2020年
- どちらも、もとの数字は総務省統計局「国勢調査報告」。2026-11-12 に取得し、表の形のまま CSV にしたもの（ふりがなは除いた）

## 注意（言えないこと）
- 「市部」は、その調査の時点で市である区域です。合併や市制の施行で範囲が変わるので、割合の上がりは「町に住む人が増えた」ことと同じではありません
- 合併の分と、人の移動の分を正確に分けてはいません。5年ごとの変化と市町村の数を並べて、時期を示しただけです
- 人口集中地区は1960年からの区分で、それより前とは比べられません。基準（人口密度と人口の大きさ）で決まる区域で、調査のたびに引き直されます
- 1945年は11月1日の調査で、沖縄県を含みません。戦争による疎開などで市部の人口が減っていた時期です
- 全国の集計だけで、都道府県や市町村ごとの違いは見ていません
