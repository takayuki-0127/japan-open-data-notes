# F187 子どもの身長の伸びは、いつ止まったのか？（長期系列の変化点と、生まれ年での比較）

## 問い

子どもの平均身長は、戦後に大きく伸びて、どこかで止まった。では「止まった」のはいつか。
年齢や男女で違うのか、どの方法で測るかで答えが変わるのか、「その年に全年齢で止まった（時代）」のか「ある生まれ年から止まった（世代）」のか。

記事 094（`articles/094_height`）では、17歳の最高値の年度（1994年度）と、11〜14歳男子が今も伸びていることを示した。この記事では、5〜17歳の26系列すべてに変化点の方法を当て、「鈍った年」と「止まった年」を分けて測る。

## データ

- 文部科学省「学校保健統計調査」年次統計 表10「年齢別 平均身長の推移（明治33年度〜令和7年度）」（e-Stat）
  - 年度×男女×年齢（5〜17歳）の全国の平均身長（cm）。5歳は1948年度から
  - 094 で整形した `height_long.csv` をそのまま使った（`data/height_long.csv`、`src/01_取得.py`）
- 公表されている全国の平均値だけを使う。都道府県の値は使わない
- 注意
  - 2020〜2023年度は、コロナで測定の時期がずれた値で、過去と比べられない（文部科学省の注記）。主の分析から外した
  - 1940〜1947年度は調査なし。1939年度以前は調べ方が違うので、図で参考に示すだけにした
  - 年齢は4月1日時点の満年齢。「生まれ年の目安」は年度−年齢で、同じ子どもを追った値ではない

## 手法

主の期間は1948〜2019年度（72年）。年齢×男女の26系列ごとに、次の方法で変化点を求めた。

| 記号 | 方法 | 何を測るか |
|---|---|---|
| M1 | 折れ目1つの折れ線（連続な2本の直線）。残差平方和が最小の折れ目 | 伸びが**鈍った**年 |
| M1b | 折れ目のあとは傾き0とする折れ線 | 「ここで止まった」とみなせる年 |
| M2 | 毎年の伸び（前年差）の平均が1回だけ変わる点（ruptures, Binseg） | 伸びの速さが変わった年 |
| M3 | 5年移動平均が、その年齢の最高値−0.3cm に初めて届いた年 | 伸びが**止まった**年（ほぼ最高に届いた年） |
| M4 | 折れ目2つの折れ線の、あとの折れ目 | 伸びが**止まった**年 |

- M1 の95%区間：残差の移動ブロック・ブートストラップ（ブロック長5、999回、乱数の種187）
- 時代か世代か：M1 の折れ目の年を年齢で回帰した。その年に全年齢で鈍ったなら傾き0、ある生まれ年から鈍ったなら傾き+1
- 世代でみる：生まれ年の目安ごとに、11歳と17歳の身長、その差（11→17歳に伸びた分）を並べた
- 止まったあと：1994〜2019年度の傾き（HAC 標準誤差）と、2024・2025年度と2015〜2019年度の差
- 方法の当たり方の確認：1985年に止まる擬似データ（ノイズは実データの残差 0.30cm）で、各方法が正しい年を返すかを300回ずつ試した

## 結果

### 1. 鈍ったのは1970年代、止まったのは1980年代後半〜1990年代

| | 伸びが鈍った年（M1） | 止まった年（M4／M3） | 1994〜2019年度の傾き |
|---|---|---|---|
| 男子17歳 | 1979（1977〜1981） | 1991／1992 | −0.11cm／10年 |
| 男子13歳 | 1974（1972〜1976） | 1996／1998 | +0.02 |
| 男子11歳 | 1976（1974〜1978） | 1995／1996 | +0.02 |
| 女子17歳 | 1986（1985〜1987） | （1995）／1988 | −0.09 |
| 女子13歳 | 1973（1971〜1975） | 1984／1992 | −0.14 |
| 女子11歳 | 1974（1972〜1976） | 1996／1995 | −0.10 |

- 26系列の M1（鈍った年）は、男子1972〜1979年（中央値1975）、女子1973〜1986年（中央値1976）
- 鈍る前の伸びは10年あたり中央値 男子3.6cm・女子3.4cm、鈍ったあとは男子0.44cm・女子0.20cm。鈍ったあとも、男子9〜14歳は10年あたり0.4〜0.9cm伸び続けていた
- 止まった年（M4）は男子1986〜1998年、女子1984〜1996年。M4 の最後の傾きは −0.26〜+0.11cm／10年で、どの系列もほぼ0
- 女子17歳は、M1 の時点で傾きが0（1986年に止まる）。M4 のあとの折れ目（1995）は差の小さい揺れを拾ったもので、M1・M1b・M3 の1986〜1988年の方が当てはまる

### 2. 最後まで伸びたのは11〜13歳

止まった年を年齢で並べると、どちらの性も山の形になった。

- 5〜7歳：1989年ごろ
- 11〜13歳：1995〜1998年（いちばん遅い）
- 15〜17歳：男子1986〜1991年、女子1987年ごろ

最後の身長に近い17歳が先に止まり、そのあとも11〜13歳（伸びがいちばん大きい時期）の身長は伸び続けた。伸びる時期が早まった、と読める。

### 3. 時代か世代か

- M1（鈍った年）を年齢で回帰した傾き
  - 男子5〜17歳：+0.04（95%区間 −0.13〜+0.19）→ ほぼ0。どの年齢もほぼ同じ1970年代半ばに鈍った（時代の形）
  - 女子5〜17歳：+0.44（0.29〜0.57）。女子11〜17歳は +2.32（2.00〜2.64）で、世代の形（+1）よりも急。年上ほど遅く鈍った
- 生まれ年の目安で見ると、17歳の身長が最も高いのは男女とも1977年ごろ生まれ（男子170.9cm、女子158.1cm）、11歳が最も高いのは1987〜1988年ごろ生まれ
- 11歳から17歳までに伸びた分は、男子32.8cm（1938年ごろ生まれ）→25.6cm（2002年ごろ）、女子22.2cm→11.1cm。縮み方は1980年代後半生まれでほぼ止まった

### 4. 止まったあと

- 1994〜2019年度の傾きは、17歳で男子 −0.11cm／10年（−0.13〜−0.09）、女子 −0.09（−0.12〜−0.05）。はっきりした下がり方だが、25年で約0.3cm と小さい
- 5歳は男子 −0.25、女子 −0.31cm／10年で、いちばん下がっていた
- 2024・2025年度の平均は、2015〜2019年度より男子12〜13歳で+1.2cm、男女10〜11歳で+0.7〜+0.9cm 高い。17歳は+0.1cm 以下

### 戦前との比較（10年あたりの伸び）

| | 1900〜1939 | 1948〜1970 | 1970〜1994 | 1994〜2019 |
|---|---|---|---|---|
| 男子17歳 | 0.97 | 3.18 | 1.19 | −0.11 |
| 女子17歳 | 1.21 | 1.56 | 1.05 | −0.09 |
| 男子11歳 | 1.23 | 4.66 | 1.70 | 0.02 |
| 女子11歳 | 1.36 | 5.56 | 1.47 | −0.10 |

## 頑健性

- **期間**：始まりを1948・1955・1960年、終わりを2009・2019・2025年（コロナ期を除く／含む）に変えた（11・13・14・17歳）
  - M1 は始まりを遅らせると最大6年遅くなった（例：男子14歳 1973→1979）。伸びが少しずつ鈍った（曲がり方がなだらか）ためで、M1 の「鈍った年」は期間に左右される
  - M3（止まった年）は、コロナ期を除くかぎりどの期間でも同じ年（男子17歳は1991〜1992）
  - コロナ期（2020〜2023年度）の値を含めると、M3 は11〜14歳で2021年になった。2020年度以降の値は止まった年の判定には使えない
- **方法**：17歳では M1・M1b・M2・M3 が男子1977〜1992年、女子1986〜1989年に収まった。11〜14歳では「鈍った年」（M1・M2、1969〜1981年）と「止まった年」（M3、1991〜1998年）が15〜20年離れていて、どちらを聞くかで答えが変わる
- **方法の当たり方（擬似データ）**：1975・1985・1995年に止まる設定で、M1・M1b・M3 は中央値が正しい年だった。80%が入る幅は M1・M1b で±2年、M3 で−2〜+7年（遅めに出やすい）。M2（毎年の伸びの平均が変わる点）は ±10年近くばらついた
- **男女**：鈍った年の並び方（時代の形か世代の形か）は男女で違った

## 言えないこと

- **なぜ止まったか**：栄養・体格の遺伝的な上限・少子化・生活の変化など、原因はこのデータでは分けられない
- **個人の成長**：全国の年齢別の平均の推移で、同じ子どもを追った値ではない。「生まれ年」は年度−年齢で作った目安
- **2024・2025年度の上昇**：11〜13歳の+1cm 前後は、コロナ期のあとで調べ方の影響が残っていないかを分けられない（094 と同じ注意）。「再び伸びはじめた」とは言えない
- **地域・家庭による違い**：全国平均だけを使っていて、地域や世帯の違いは扱っていない（扱わない方針）
- **止まった年の幅**：伸びが少しずつ鈍ったので、「何年に止まった」は方法と期間で数年動く。この記事の年は「その前後」と読む必要がある
- **抽出調査**：標本の誤差がある。全国平均の誤差は小さいが、年ごとの0.1cm 単位の上下は誤差の範囲を含む
- **1939年度以前**：調べ方が違うので、戦前との比較は目安
