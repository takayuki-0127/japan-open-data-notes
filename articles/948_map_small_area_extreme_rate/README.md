# 948 小さい区域の率は、なぜ地図の端に極端な色が出やすいのか？（地図と場所）

区域ごとの率を色で塗った地図では、町の外側の区域ほど、いちばん濃い色やいちばん薄い色になりやすく見えることがあります。外側の区域は人が少なく、少ない人数で割った率は上にも下にも大きく振れるためです。**ここでは、作成者が乱数で作った架空の町（20×20の格子、400区域）と架空の店の会員で、区域ごとの「この1か月に買った会員の割合（購入率）」を塗り、本当の購入率を場所と関係なく置いたときに、上下1割の濃い色・薄い色の区域がどこに集まるかを数えました。** 会員数に応じて全体の率に寄せた率（ベイズの考え方で寄せる方法）で塗り直したときも比べました。

区域・町・店はすべて架空のもので、実在の地図や地名は使っていません。区域を良い順・悪い順に並べることはしていません。

## 主な結果

### 上下1割に塗られた区域は、どこにあったか（200回の平均）
| | 外側の2列の区域の割合 | 会員30人未満の区域の割合 |
|---|---|---|
| 全区域 | 36% | — |
| 見かけの率の上下1割（80区域） | **65.1%** | 91.9% |
| 寄せた率の上下1割（80区域） | 9.9% | 27.4% |

- 本当の購入率は場所と関係なく置いたのに、見かけの率で上下1割に塗られた区域の65.1%が外側の2列（全区域の36%）にあった。1回分の町（図1）では80区域のうち46区域だった
- 寄せた率で塗ると、上下1割に入る外側の区域は9.9%になり、こんどは全区域の割合（36%）より少なくなった。会員の少ない区域は全体の率の近くまで寄せられるため、ほとんど濃い色にも薄い色にもならない（逆向きの偏り）
- 寄せる強さ m は、200回の中央値で158.5（10〜90%の範囲 112.2〜281.8）だった。会員が数十人までの区域の率は、全体の率の近くまで寄せられる

### 会員数の層ごと（200回の町の合計）
| 区域の会員数 | 1つの町の区域数 | 全区域に占める割合 | 見かけの率の上下1割に占める割合 | 寄せた率の上下1割に占める割合 | 95%の帯の外に出た割合 | 見かけの率と本当の率の差（平均、ポイント） | 寄せた率と本当の率の差（平均、ポイント） |
|---|---|---|---|---|---|---|---|
| 10人未満 | 74.9 | 18.7% | **44.9%** | 1.6% | 4.5% | 13.36 | 2.55 |
| 10〜29人 | 170.6 | 42.7% | 47.0% | 25.9% | 5.4% | 7.99 | 2.47 |
| 30〜99人 | 117.3 | 29.3% | 7.8% | 49.3% | 8.4% | 4.58 | 2.22 |
| 100人以上 | 37.2 | 9.3% | 0.3% | 23.3% | 16.2% | 2.61 | 1.84 |

- 会員10人未満の区域は全区域の18.7%だが、見かけの率の上下1割の44.9%を占めた。会員100人以上の区域はほとんど入らなかった（0.3%）
- 95%の帯の外に出た区域は、会員の少ない層で4.5%、多い層で16.2%だった。帯は人数の少なさを考えに入れるので、会員の多い区域の本当の差のほうが見つかる
- 見かけの率と本当の率の差は、会員10人未満で平均13.36ポイント、100人以上で2.61ポイントだった。寄せた率ではどの層も2.55ポイント以下だった

### 本当に率の高い区域を当てられたか（200回の平均）
| 塗り方 | 上位40区域のうち、本当の上位40区域に入っていた割合 | 下位40区域のうち、本当の下位40区域に入っていた割合 |
|---|---|---|
| 見かけの率 | 22.1% | 17.8% |
| 寄せた率 | **27.9%** | 25.6% |

- 寄せた率のほうが当たりは多かったが、それでも3割に届かなかった。τ=0.2 では区域どうしの本当の差が小さく、1か月の買った人数では見分けにくい

### 本当の差がまったくないとき（τ=0、200回の町の合計）
| 区域の会員数 | 95%の帯の外に出た割合 | 見かけの率で上下1割に入った割合 | 上下1割に占める割合 |
|---|---|---|---|
| 10人未満 | 3.7% | 49.3% | 46.3% |
| 10〜29人 | 4.2% | 22.2% | 47.1% |
| 30〜99人 | 5.0% | 4.5% | 6.6% |
| 100人以上 | 4.5% | 0.1% | 0.05% |

- どの区域も本当の率が同じでも、上下1割の93.3%は会員30人未満の区域だった。上下1割は人数の少なさで決まる
- 95%の帯の外に出た割合は、どの層も3.7〜5.0%で、ほぼ5%どおりだった（帯の作り方からの式どおりの値）

### 確かめ：本当の差 τ × 会員数の倍率（12通り、各50回）
| | 12通りの幅 |
|---|---|
| 見かけの率の上下1割のうち、外側の2列の割合 | 53.4〜69.4% |
| 寄せた率の上下1割のうち、外側の2列の割合 | 7.4〜18.8% |
| 上位40区域の当たり：見かけの率（τ>0 の9通り） | 14.1〜48.0% |
| 上位40区域の当たり：寄せた率（τ>0 の9通り） | 16.7〜53.3% |

- 見かけの率で外側が上下1割に集まる向きは、12通りすべてで同じだった（全区域の36%に対し53.4〜69.4%）。本当の差が大きく、会員が多いほど集まり方は弱まった
- τ>0 の9通りすべてで、寄せた率の当たりは見かけの率と同じか上だった
- 外側に集まるのは、作成者が外側の会員を少なく置いたためである。会員の少ない区域が町の中にあれば、そこに極端な色が出る

## 動かし方
```
pip install -r requirements.txt
cd src && python a948_small_area_rate.py
```
3秒ほどで終わります。`data/town_example.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約4秒）
- 少ない人数で割った率が大きく振れるのは、二項分布の式どおりの結果で、新しく見つけたことではない。数えたのは、その振れが地図の上下1割の塗り分けにどれだけ出るか（外側の割合・会員数の層ごとの割合）
- 寄せた率が上下1割に会員の少ない区域をほとんど入れないのも、寄せ方の作りからの結果である。どちらの塗り方にも偏りがあり、寄せた率が「正しい地図」というわけではない
- 本当の差がないとき（τ=0）、95%の帯の外に出た割合はどの層もほぼ5%で、作りが正しく動いていることを確かめた

## データ
- `data/town_example.csv`：1回分の町の400区域。row・col（格子の位置）・outer（外側の2列なら1）・members（会員数）・buyers（買った会員）・rate（見かけの購入率）・true_rate（作成者が置いた本当の購入率）・shrunk_rate（寄せた率）・extreme_raw／extreme_shrunk（上下1割なら1）。この町の会員は15,621人、区域の会員数は2〜317人（中央値22人）、全体の購入率は20.1%。見かけの率は0〜57.1%（0%の区域が31）、本当の率は13.4〜30.2%、寄せた率は13.75〜25.92%

## 注意（言えないこと）
- 架空のデータです。会員数の分布（中心に多く外側に少ない）、本当の購入率の差の大きさ、1か月という期間は作成者が置いたもので、結果はこれで決まります。実在の町や店を表すものではありません
- 本当の購入率は場所と関係なく置きました。実際に外側の区域で率が違う場合、その違いと人数の少なさによる振れは、この地図だけでは分けられません
- 寄せた率の m は、すべての区域が同じ分布から来ると置いて決めました。外側だけ本当に率が違うような場合は、寄せすぎになります
- 上下1割で塗る方法だけを扱いました。区切り方そのものの違いは扱っていません
- 関連する記事：801（口コミの件数が少ない店ほど星が振れる）、833（少ない打席の最高打率）、865（回答が少ない層の割合）は、同じ「件数が少ないと率が振れる」仕組みを、口コミ・成績・アンケートで扱っています。949 は色分けの区切り方を扱っています。955 は、件数の少ない区域を「出さない」決まりで空白にしたとき、空白の読み方で平均がどれだけずれるかを扱っています（この記事は、出した率そのものが少ない人数で振れる話）。954 は、区域の数が少ないと区域の平均どうしの相関が大きく振れることを扱っています
