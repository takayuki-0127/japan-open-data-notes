# F280 医療費の伸びは、年齢・回数・日数・1日当たりのどれで決まっているのか？

1人当たり医療費（医療保険制度分）の伸びを、**年齢構成（高齢化）**と、年齢ごとの**受診率（1人当たり件数）×1件当たり日数×1日当たり医療費**（医療費の三要素）に分け、1日当たり医療費の伸びを**診療報酬改定の累積**と比べたフォルダです。計画（PLAN.md）を分析の前にコミットしています（コミット 4a2f76a）。

## 問いの出どころ
医療費の伸びは「高齢化」と「その他（医療の高度化等）」に分けて説明されることが多い。保険者の財政の担当、医療機関の経営企画、保険数理の担当は、その「その他」が受診の回数・日数・1日の値段のどれで動いたのかを知りたい（推測）。既存の 159（年齢別のカーブ）・215（国民医療費を人口・年齢構成・一人当たりに分ける）とは、一人当たりの中身を三要素に分ける点と、改定率と比べる点で分けた。

## 主な結果（2013→2023年度）
- 1人当たり医療費（人口の重みで計算）は 30.24万円 → 37.09万円（+22.6%、+68.5千円）。
- 増加の内訳（年ごとに LMDI で分けて足した値）：

| 要因 | 寄与（千円） | 増加に占める割合 |
|---|---|---|
| 年齢構成（高齢化） | +32.8 | 48.0% |
| 入院・受診率 | −16.8 | −24.5% |
| 入院・1件当たり日数 | −10.3 | −15.1% |
| 入院・1日当たり医療費 | +33.8 | +49.4% |
| 入院外・受診率 | +4.6 | +6.7% |
| 入院外・1件当たり日数 | −22.8 | −33.2% |
| 入院外・1日当たり医療費（調剤を含む） | +40.3 | +58.9% |
| その他の種類（歯科・訪問看護・療養費など） | +6.8 | +10.0% |

- まとめると、受診率 −12.2千円、1件当たり日数 −33.1千円、1日当たり医療費 +74.1千円。年齢ごとの変化（入院＋入院外、+28.8千円）の 257% が1日当たり医療費で、受診率と日数は合わせてマイナス。
- 1日当たり医療費（年齢の重みをそろえた値）は10年で対数 +24.7。同じ期間の診療報酬改定等の累積は −5.43%で、差は約30ポイント。1日当たり医療費は「値段×1日に行う医療の中身」なので、この差は値段の上昇ではなく、1日当たりの医療の中身（病気の構成、高い薬、短い入院で重い日が残ること、年齢階級の中の高齢化、長期処方で1日分の薬が増えることなど）の変化のうち、改定では説明できない分。
- 公表の要因分解（国民医療費、2014〜2023年度の和）では、伸び +18.8%、人口 −2.7%、高齢化 +10.2%、改定 −5.4%、その他 +16.6%。高齢化が1人当たりの伸びに占める割合は 高齢化10.2÷（伸び18.8＋人口2.7）＝47%で、この分析の 48%とほぼ同じ。国民医療費の率ベースで対象と方法が違うので目安。
- 2020年度の1日当たり医療費（年齢をそろえた値）は対数 +4.7と大きい。軽い受診が控えられて受診する人の構成が変わったことや、新型コロナに関する一時的な加算によると考える（推測）。
- 2020年度は受診率で −7.2ポイント（入院 −2.9、入院外 −4.4）と大きく下がり、2021〜2023年度に入院外の受診率が戻った。

## 計画と結果（PLAN.md）

| 仮説 | 基準 | 結果 | 判定 |
|---|---|---|---|
| H1 年齢構成の寄与は40%以上 | 40%未満なら外れ | 48.0% | 支持 |

## 問い直し（結果を見てから足した）
「1日当たり医療費の伸びは、日数が短くなった分の言い換えではないか」。同じ治療を短い日数で行えば、1日当たりは上がる。そこで1件当たり医療費（＝1件当たり日数×1日当たり）でも見た。
- 1件当たり医療費は対数 +13.6（入院 +18.1、入院外 +10.2）、1人当たり受診日数は −15.5、1人当たり件数は −4.4。
- 1件当たりで見ても改定の累積を約19ポイント上回る。1日当たりの差（30ポイント）と1件当たりの差（19ポイント）の開き約11ポイントは、年齢をそろえた1件当たり日数の減り全体にあたるので、日数の減りの言い換えは最大で約11ポイント、と読むこともできる（推測）。入院外では長期処方で通う日数が減り1日分の薬が増える仕組みも重なる。
- 2019年度で終えると、1日当たり +13.5・1件当たり +6.5、改定の累積 −2.49で、1件当たりの差は約9ポイント。

## 計画からのずれ
- 計画では歯科も三要素に分けるとしたが、年齢階級別の三要素は入院と入院外だけが公表されているため、歯科は「その他の種類」に入れた。
- 入院外の1日当たり医療費はもともと調剤を含む値なので、計画の R4（入院外と調剤をまとめる）はそのままでは行えない。代わりに始めを2011年度にする R4b を行った（結果を見る前に入れ替えた）。
- 計画の R5（重みを医療費の構成から逆算した人数にする）は、年齢別の加入者数が資料にないため行わなかった。
- R6（公表値の丸めの幅でずらす）は計画になく、データの形（1件当たり日数が小数1桁）を見てから足した。
- 計画を書く前に、PDF の目次と令和5年度の年齢階級別の図（1年分の水準）を、データの形を確かめるために見た。
- 人口の表の読み取りで、下の「割合（%）」の行を人口として読む誤りがあり、直した（直す前の結果は使っていない）。
- 独立レビューを受けて、R7（終わり2022年度）を結果のあとに足した。

## 手法
- C = Σ_a w_a × [ r_in·d_in·p_in ＋ r_out·d_out·p_out ＋ o_a ]（千円）。a：5歳階級（0〜4歳〜100歳以上の21区分）、w：人口の割合、r：受診率（件/人・年）、d：1件当たり日数、p：1日当たり医療費、in：入院（食事・生活療養を含む）、out：入院外（調剤を含む）、o：1人当たり医療費計 − 入院 − 入院外。
- 年ごとに加法型の LMDI で分け、2014〜2023年度を足した（残差 0）。
- 改定との比べ方：入院＋入院外の1日当たり医療費を、年ごとの LMDI の重みで年齢をそろえて伸びを出し（対数×100）、足した。改定率は「医療費の伸び率の要因分解」の診療報酬改定等（2014年度は消費税対応 +1.36%を含めて +0.10%）を足した。

## 言えないこと
- 「1件」はレセプト（1か月・1医療機関の請求）の単位で、入院1件当たり日数は在院日数ではない。月をまたぐ入院は複数の件になる。
- 公表値は小数1〜2桁に丸められている。とくに入院外の1件当たり日数（1.2〜2.4日、小数1桁）は丸めの影響が大きく、R6 で幅を出した。
- 重みは総人口で代用した。医療保険の加入者は生活保護の受給者などを含まないため、年齢構成は少しずれる。
- 1日当たり医療費の伸びが何から来たか（新しい薬・技術、長期処方で受診の回数が減り1回の処方が増えたこと、医療機関の機能分化など）は、このデータでは分けられない（推測）。
- 改定率は医療費全体に対する率で、入院・入院外ごとの率ではない。改定率の和と対数の伸びは、厳密には同じ物差しではない（10年で差は1ポイント程度と見込む、推測）。
- 2020年度以降は新型コロナの影響（受診控えとその戻り）を含む。
- 2023年度（令和5年度版）の年齢階級別の値は「各制度の事業年報等を基に、NDBデータ等を用いて保険局調査課により推計」で、それまで（医療給付実態調査など）と作り方が違う。2022→2023年度は入院の受診率の寄与が +2.77千円とそれまでと違う動きをした。R7（終わり2022年度）でも判定は変わらない。
- 個人の受診への助言や、政策の良し悪しの評価はしない。

## レビューで直したこと
作業を見ていない別のエージェントがレビューした。数字の照合、改定率 −5.43% と資料の注、PDF の値と抜き出した値の突き合わせ、クリーンな再実行はすべて一致。指摘を受けて次の8点を直した（新しい数字はすべて自分で計算し直した）。
- 2023年度の推計方法の変化を「言えないこと」に書き、R7（終わり2022年度）を足した：年齢構成 53.1%、1日当たり 347%、入院日数 −9.2千円、改定との差 +28.5ポイント、1件当たりの差 +18.1ポイント。判定は変わらない。
- 1日当たり医療費は値段×1日の医療の中身なので、改定との差を「中身の変化のうち改定で説明できない分」と書き、記事の「1日の値段」という言い方をやめた。
- 「約11ポイントは日数の減りの言い換え」は上限なので、「最大で約11ポイント（推測）」に弱め、長期処方の仕組みも書いた。
- 2020年度の1日当たりの伸び（+4.7）に、受診する人の構成の変化と一時的な加算の可能性を（推測）で書いた。
- 記事の「入院している日の医療は濃くなった」に（推測）を付けた。
- 公表の要因分解からの 47% の計算式と、目安であることを書いた。
- 人口の表の読み取りの直しを、記事の「計画からのずれ」にも書いた。
- 受診率は人数ではなく件数なので、題名を「年齢・人数・単価」から「年齢・回数・日数・1日当たり」に直し、副題を短くした。
