# 178 産業廃棄物の再生利用率は、種類でどう違い、どう伸びたか

環境省「産業廃棄物排出・処理状況調査」の種類別の排出・処理状況一覧表（e-Stat、2010〜2023年度のうち表がある10年分）と、「産業廃棄物の排出・処理状況等（令和5年度実績）」の再生利用量・減量化量・最終処分量の推移（1996〜2023年度）を使い、再生利用率の伸び方を種類別に比べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A178 | 産業廃棄物の再生利用率は、全体でどう伸びたか。種類によってどう違い、どの種類が伸びたか | 再生利用率＝再生利用量÷排出量。全体の推移（1996〜2023年度）、種類別の2010→2023年度の変化、主な種類の推移、汚泥を除いた率 | `src/a178_recycling.py` |

## 主な結果
- 全体の再生利用率は 1996年度 42.5% → 2005年度 51.9% と伸びたあと、2008年度以降は52〜55%の間でほぼ横ばい（2023年度 54.7%）
- 最終処分率は 14.1%（1996年度）→ 2.4%（2023年度）。最終処分量は 6,000万t → 900万t
- 2023年度の種類別の再生利用率は、がれき類95.9%、金属くず95.4%、動物のふん尿94.9%、鉱さい91.2%が高く、汚泥7.6%、廃アルカリ22.4%、廃酸33.0%、廃油46.1%が低い
- 2010→2023年度で伸びたのは、紙くず +18.3ポイント、動物系固形不要物 +15.5、ばいじん +12.1、ガラス・コンクリート・陶磁器くず +9.8、廃油 +9.2、廃プラスチック類 +8.9（54.1%→63.0%）
- 全体が伸びないのは、排出量の約4割を占める汚泥の再生利用率が6〜11%にとどまる（2023年度は91.5%が脱水・焼却などで減量化）ため。汚泥を除くと再生利用率は 87.5%（2010年度）→ 88.9%（2023年度）

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a178_recycling.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/by_type_2010_2023.csv | 年度、種類（19種類＋合計）、排出量・再生利用量計・最終処分量計（千t）。2010〜2013・2015・2019〜2023年度 |
| data/national_flow_1996_2023.csv | 年度、再生利用量・減量化量・最終処分量（百万t、図2-2の目盛の値） |

- 種類別：e-Stat「産業廃棄物排出・処理状況調査」（https://www.e-stat.go.jp/stat-search/files?toukei=00650102）の各年の「2-2 表」Excel にある「産業廃棄物排出・処理状況一覧表」（表Ⅲ・9 または 表Ⅲ・10）。調査年度は実績年度の2年後（令和7年度調査＝令和5年度実績）
- 全体の推移：環境省「産業廃棄物の排出・処理状況等（令和5年度実績）」別添資料（https://www.env.go.jp/press/110498_00003.html）の図2-2

## 注意
- 2014・2016〜2018年度は e-Stat に一覧表がなく、2008・2009年度は種類別の排出量の表の形が違うため使っていない。図3は表がある年を線でつないでいる
- 平成29年度調査の表の見出しは「平成26年度実施値」だが、合計（排出量391,185千t・再生利用量207,561千t）が別添資料の2015年度の値と合うため、2015年度として扱った
- 全体の推移は図の目盛の値（百万t、整数）から計算したので、2023年度は54.6%と公表値54.7%から少しずれる
- 都道府県の報告を環境省が集計し、補正した推計値。年度によって推計の方法が少し変わっている
