# F164 図をどう作ると、読まれ方が変わったか？ 自分の note 34本の公開されている数字で振り返る

看板記事 F164。note：「図をどう作ると、読まれ方が変わったか？…」（下書き）

## 問い
自分の note（https://note.com/takayukimatsuura）に公開した記事で、図の枚数や本文・タイトルの作りと、公開ページに出ている反応（スキ・コメント）には、どんな関係が見えるか。**記述だけ**で、因果は言わない。

## データ
- 2026年11月4日 8:54（日本時間）に取得した、公開済みの34本（2026年8月16日〜11月4日公開）。
- note の公開 API（`/api/v2/creators/takayukimatsuura/contents`、`/api/v3/notes/<key>`）で見える数字だけを使った。
  - 反応：スキの数、コメント数
  - 作り：本文の字数、画像の枚数、見出しの数、コードブロック・リンクの数、タイトルの字数、ハッシュタグの数、GitHub へのリンクの有無
- **閲覧数は使っていない。** 閲覧数は書き手の管理画面にしか出ず、公開ページには出ないため（設計書の「公開ページの数字だけ」に従った）。
- **図の「種類」は分けていない。** note の本文の画像にはキャプションがなく、ファイル名もランダムなので、公開データから図の種類（地図・散布図など）を決められなかった。
- スキを付けた人の一覧は保存していない。数だけを使った。

## 手法
1. 図の枚数（0枚／1〜2枚／3〜4枚／5〜6枚）、記事の型、タイトルの長さ、公開時期ごとに、スキの合計と「公開からの日数の合計」を数え、30日あたりのスキ（率）を出した。区間はポアソン分布の正確な95%区間（Garwood）。
2. 1本ごとの「スキ÷日数」と、作りの各指標の順位相関（置換検定 1万回）。
3. ポアソン回帰（日数の対数をオフセット）：スキ ～ 図の枚数＋字数＋タイトルの字数。
4. 日数の扱い（割る／平方根で割る／割らない）を変えたときの、図5枚以上と4枚以下の比。

記事の型は次の決め方：看板型＝3,000字以上かつ図5枚以上（17本）、短い分析・技術＝それ以外で GitHub つき（9本）、その他＝体験・業務の記事（8本）。

## 結果
- 34本でスキは計18、コメントは計2。**22本（65%）はスキ0**。
- 図の枚数ごとの 30日あたりのスキ：0枚 0.62（0.23〜1.36）、1〜2枚 0.79（0.10〜2.87）、3〜4枚 0.65（0.02〜3.60）、**5〜6枚 3.00（1.37〜5.70）**。
- ただし図5〜6枚の17本はすべて10月25日以降の新しい記事で、日数の合計が90日しかない。図0枚の5本は8〜9月の古い記事が中心で、日数の合計は289日。
- 同じ期間（10月17日以降の30本）で、図5枚以上と4枚以下を比べると、日数の扱いで結果が変わる：
  - 日数で割る：4.6倍（p=0.017）
  - 日数の平方根で割る：3.3倍（p=0.081）
  - 割らない（1本あたりのスキ）：2.3倍（p=0.25）
- ポアソン回帰で、図が1枚多いときのスキの倍率は 1.19（0.77〜1.85）。字数1,000字あたり 1.19（0.75〜1.91）、タイトル10字あたり 1.20（0.68〜2.14）。どれも1をまたぐ。
- 順位相関（スキ÷日数と）：図の枚数 0.15（p=0.40）、字数 0.20（p=0.25）、タイトルの字数 0.13（p=0.46）、見出しの数 0.26（p=0.14）。
- 図の枚数とタイトルの字数の順位相関は 0.85、図の枚数と字数は 0.30。図の多い記事は、タイトルも長く、看板型の記事でもある。どれが反応と関係したのかは、この34本からは分けられない。

## 頑健性
| 条件 | 図1枚あたりの倍率（95%区間） |
|---|---|
| 基本（日数で割る、字数・タイトル長も入れる） | 1.19（0.77〜1.85） |
| 10月17日以降の30本だけ | 1.48（1.01〜2.16） |
| スキ＋コメント | 1.19（0.79〜1.80） |
| 日数の平方根で割る | 1.11（0.72〜1.72） |
| 日数で割らない | 1.02（0.66〜1.59） |
| 「スキが1つ以上ついたか」（オッズ比、日数の対数を入れる） | 1.24（0.82〜1.87） |
| 1本ずつ外す | 1.03〜1.34 |

- ポアソン回帰のばらつきの比は 1.68 で、区間は実際より狭めに出ている可能性がある。
- 図5枚以上と4枚以下の差を、検出力80%で見分けられる最小の倍率は約5倍（今の本数とスキの数で、シミュレーション）。

## 言えないこと
- 因果は言えない。図の枚数は、記事の型・字数・タイトルの長さ・公開時期・ハッシュタグと一緒に動いていて、分けられない。
- スキは公開直後に集まりやすいと考えられ（推測）、「日数で割る」は新しい記事を有利に見せる。どの割り方が正しいかは、日ごとのスキの記録がないので決められない。
- 閲覧数（読まれた数）は見ていない。スキが少ないことは、読まれていないことと同じではない。
- 34本・スキ18は少なく、どの比較も偶然と区別しにくい。
- 図の種類（地図・散布図・棒グラフなど）は比べていない。
- 取得した時点（2026年11月4日 8:54）の数字で、この後も変わる。
