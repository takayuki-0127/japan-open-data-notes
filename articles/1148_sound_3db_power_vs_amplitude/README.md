# 1148 「3dB 上げる」は、音の強さで見るか波の振れ幅で見るかで、何倍の変化になるのか？（音の大きさ）

「3dB 上げると2倍」とよく言われます。けれども、dB（デシベル）で表す比には、音の強さ（波の値の二乗平均）の比と、波の振れ幅の比の2つがあり、同じ3dBでも強さでは約2倍、振れ幅では約1.41倍です。どちらで見るかを取り違えると、「2倍にした」つもりが+6dBにも+1.5dBにもなります。また、実際の音を上げるときは、上限で波が切れたり、一部の高さの音だけを上げたりするので、強さの比と振れ幅の比はさらに別々に動きます。**ここでは、作成者が式と乱数で作った架空の音（雑音・一定の高さの音・架空の曲の3種類の波形）を3dB上げ、①全体を同じだけ上げるとき、②上限（±1）を超えた分が切れるとき、③低い音の部分だけを上げるとき、の3つで、強さと振れ幅が何倍になったかを数えました。**

例の音は作成者が式と乱数で作ったもので、実在の曲・機材・ソフトの値を表すものではありません。人に聞き比べてもらった実験ではなく、人が聞いて何倍の大きさに感じるかは数えていません。

関連する記事：同じ企画の 1137「同じ大きさの音を2つ重ねると、デシベルの値は2倍になるのか？」は、2つの音を重ねたときの上がり幅（別々の音なら+3dB、同じ音なら+6dB）を数えています。この記事は重ねるのではなく、1つの音を「3dB 上げる」ときの比の読み方に絞ります。同じ企画の 1144「上限を超えて切れた部分の割合は、大きさの数字にどう表れるのか？」は、切れた部分の割合が大きさの数字にどう表れるかを数えています。この記事の②は、切れたときに強さの比と振れ幅の比が別々に動くことだけを扱います。1142「低い音と高い音では、同じデシベルでも、測り方の重み付けしだいで大きさの数字がどれだけ違うのか？」は、低い音を足したとき、重み付けのしかたで大きさの数字の上がりがどれだけ違うかを数えています。この記事の③は重みなしで、低い音の割合から決まる式どおりの上がりだけを扱います。

## 主な結果

### dB と、強さの比・振れ幅の比（式、`results/formula_table.csv`）
| 上げた大きさ | 強さの比 | 振れ幅の比 |
|---|---|---|
| 1dB | 1.2589倍 | 1.122倍 |
| 3dB | **1.9953倍** | **1.4125倍** |
| 6dB | 3.9811倍 | 1.9953倍 |
| 10dB | 10倍 | 3.1623倍 |
| 20dB | 100倍 | 10倍 |

- **3dB上げると、音の強さは1.9953倍、波の振れ幅は1.4125倍になる（式どおり）**。振れ幅で2倍にするのは6dB（式では6.021dB）で、そのとき強さは4倍になる
- 取り違えると、「振れ幅を2倍」にした音は+6.021dB、「強さを1.4125倍」にした音は+1.5dBで、どちらも+3dBにならない（式どおり、`results/a1148_main.json` の misread）
- 「3dB＝2倍」は近い値で、3dBを10回重ねた30dBでは、強さは1,000倍で、2の10乗（1,024）の0.9766倍だった（式どおり、`results/stack_3db.csv`）

### ① 全体を3dB上げる（3種類×各300、`results/whole_gain.csv`）
| 音の種類 | 強さの比 | 二乗平均の平方根の比 | いちばん大きい瞬間の比 | 絶対値の平均の比 |
|---|---|---|---|---|
| でたらめな雑音 | 1.9953倍 | 1.4125倍 | 1.4125倍 | 1.4125倍 |
| 一定の高さの音 | 1.9953倍 | 1.4125倍 | 1.4125倍 | 1.4125倍 |
| 架空の曲 | 1.9953倍 | 1.4125倍 | 1.4125倍 | 1.4125倍 |

- 波の値に同じ数を掛けるだけなら、音の種類によらず、強さはどれも1.9953倍、振れ幅はどの測り方でも1.4125倍だった（式どおり。式との差はすべて1兆分の1未満）

### ② 上限（±1）で切れるとき（架空の曲200曲、`results/a1148_main.json` の clip、`data/songs_clip.csv`）
| | 切れなかった曲（上げる前のいちばん大きい瞬間が−3dB以下） | 切れた曲（−3dBより大きい） |
|---|---|---|
| 曲の数の割合 | 48% | 52% |
| 強さの比（平均） | 1.9953倍（+3dB） | **1.9923倍**（+2.9936dB、最小+2.9673dB） |
| いちばん大きい瞬間の比（平均） | 1.4125倍 | **1.1981倍**（最小1.0125倍） |
| 切れた点の割合（平均） | 0% | 0.0229%（最大0.1219%） |

- **上限で切れた曲では、いちばん大きい瞬間の比は平均1.1981倍（最小1.0125倍）まで縮んだが、強さの比は平均1.9923倍とほぼ2倍のままだった**。切れた点は平均0.0229%とわずかで、強さはほとんど減らなかった
- いちばん大きい瞬間で見ると「3dB」は平均+1.532dB、強さで見ると+2.9936dBで、同じ操作が測り方で別の dB になった

### 音の種類で、切れたときの強さの比が変わる（いちばん大きい瞬間をそろえてから3dB上げる、各200、`results/clip_by_type.csv`）
| 音の種類 | 上げる前のいちばん大きい瞬間 | 強さの比 | いちばん大きい瞬間の比 | 切れた点の割合 |
|---|---|---|---|---|
| でたらめな雑音 | −1dB | 1.9923倍 | 1.122倍 | 0.083% |
| 架空の曲 | −1dB | 1.9913倍 | 1.122倍 | 0.0267% |
| 一定の高さの音 | −2dB | 1.8338倍 | 1.2589倍 | 29.9678% |
| 一定の高さの音 | −1dB | 1.5995倍 | 1.122倍 | 41.5585% |
| 一定の高さの音 | −0.1dB | **1.3856倍** | 1.0116倍 | 49.182% |

- 雑音や架空の曲は、いちばん大きい瞬間がまれにしか来ないので、切れても強さは2倍近くのままだった。一定の高さの音は、波の山がどれも同じ高さなので、上限近くから上げると多くの点が切れ、強さの比も1.3856倍まで下がった

### ③ 低い音の部分だけ上げるとき（各200、`results/low_band.csv`）
| 低い音の強さの割合 | 全体の強さの上がり（低い音だけ3dB） | 強さの比 | いちばん大きい瞬間の比 |
|---|---|---|---|
| 10% | +0.412dB | 1.0995倍 | 1.0512倍 |
| 30% | +1.135dB | 1.2986倍 | 1.1389倍 |
| 50% | +1.754dB | 1.4976倍 | 1.2265倍 |
| 70% | +2.296dB | 1.6967倍 | 1.2975倍 |
| 90% | **+2.778dB** | 1.8957倍 | 1.3616倍 |

- **低い音の部分だけを3dB上げると、全体の強さの上がりは、低い音の割合10〜90%で+0.412〜+2.778dBだった（式どおり、式との差は0.001dB未満）**。どの割合でも+3dBには届かなかった
- 低い音だけ1dB・6dB上げた場合も含めた27通りで、全体の上がりは+0.111〜+5.662dBで、いつも上げた大きさより小さかった
- いちばん大きい瞬間の比は、低い音の割合で1.0512〜1.3616倍（3dB上げたとき）と、強さの比とも1.4125倍とも違った

## 注意（言えないこと）
- 架空のデータです。①と③の主な値は式どおりで、波形で数えて式と合うことを確かめたものです。②の値は、置いた音の作り方（とくに、いちばん大きい瞬間がどれだけまれに来るか）で決まります
- 低い音と高い音の境目（1秒に500回）と、きっちり分ける分け方は作成者が置いたものです。実際の音の上げ下げの道具は、境目のまわりをなだらかに上げるので、値は少し変わります
- 上限で切るのは、超えた分をそのまま切る単純な形だけです。音をつぶして上限に収める処理は入れていません
- 人が聞いて何倍の大きさに感じるかは数えていません。音量を上げ下げするときの安全や聞こえ方についても言えません
