# 799 季節の波を月のダミー変数で表すか、フーリエ項で表すかで、予測の誤差はどれだけ違うのか（手法の解説・正解の分かるデータで試す）

月次の系列の季節の波を回帰で表すとき、よく使う方法が2つあります。月ごとのダミー変数（12か月のうち11個）を入れる方法と、sin と cos の組（フーリエ項）を何組か入れる方法です。ダミーはどんな形の波も表せますが、推定する数が多くなります。フーリエ項は少ない数で済みますが、なめらかな波しか表せません。**ここでは、なめらかな波と12月だけとがった波の2種類、系列の長さ2〜10年で、2つの方法の予測の誤差を比べました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A799 | 季節の波の表し方で、予測の誤差はどれだけ違うか | 架空の月次の系列＝水準＋ゆるい伸び＋季節の波＋ばらつき（sd 1）。季節の波は「なめらか（振幅3の正弦波）」と「とがった（12月だけ＋8）」。系列の長さ2・3・5・10年、各300回。伸び＋月のダミー11個、伸び＋フーリエ項 K＝1・2・3組を最小二乗で当てはめ、次の12か月を予測して本当の値との誤差（RMSE）を出す。seed 799 | `src/a799_fourier.py` |

## 主な結果（次の12か月の誤差、300回の平均）

| 季節の波 | 系列の長さ | 月のダミー（11個） | フーリエ K＝1（2個） | K＝2（4個） | K＝3（6個） |
|---|---|---|---|---|---|
| なめらか | 2年 | 0.91 | **0.61** | 0.69 | 0.77 |
| なめらか | 10年 | 0.35 | **0.21** | 0.25 | 0.28 |
| とがった | 2年 | **0.89** | 2.61 | 2.30 | 1.95 |
| とがった | 10年 | **0.35** | 2.20 | 1.95 | 1.66 |

- なめらかな波では、フーリエ項1組（2個）がいちばん当たった。2年の系列で、ダミー（0.91）より誤差が3分の1ほど小さかった（0.61）
- とがった波では、フーリエ項は何年分のデータがあっても外れたままだった（10年でも K＝3 で1.66）。ダミーは0.35まで下がった
- ダミーの誤差は波の形によらず同じ（2年で約0.9、10年で0.35）。形を問わない代わりに、推定する数の多さの分だけ誤差が大きい

## 動かし方
```
pip install -r requirements.txt
cd src && python a799_fourier.py
```
数秒で終わります。

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- 月のダミーの誤差が、なめらかな波ととがった波でほぼ同じになること

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 799）

## 注意（言えないこと）
- 架空のデータです。季節の波の形は作成者が置いた2種類だけです。実際の系列は、なめらかな部分ととがった月が混ざっていることが多いです
- 季節の波が年によって変わる場合や、週次・日次の長い周期（フーリエ項が特に役立つ場面）は扱っていません
- K の数は、交差検証や情報量規準で選ぶこともできます（ここでは固定して並べた）
