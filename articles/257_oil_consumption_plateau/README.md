# 257 油の消費は、いつから横ばいになったのか

農林水産省「食料需給表」（令和6年度、1960〜2024年度。2024年度は概算値）の油脂類を使ったフォルダです。データは記事101（`articles/101_food_balance`）と同じ e-Stat の CSV です。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A257 | 1人あたりの油の量は、いつから横ばいになったのか | 油脂類の国民1人・1年当たり供給純食料（kg）に、折れ目1つの連続した折れ線（ヒンジ）を最小二乗で当てはめ、折れ目の年を総当たりで選ぶ（1960〜2021年度、各区間5年以上）。熱量・3年移動平均・2024年度までの期間でも同じことをする。植物油脂（菜種油・大豆油・やし油・その他）と動物油脂の内訳、1日の供給熱量に占める油脂類の割合 | `src/a257_oil.py` |

## 主な結果
- 油脂類は1960年度の4.3kgから1985年度の14.0kgまで、年に約0.39kgずつ増えた
- 折れ線の折れ目は1985年度。そのあとの傾きは年−0.013kgで、ほぼ横ばい。1985〜2021年度は13.1〜15.1kg（平均14.3kg）の間に収まった。最大は1999年度の15.1kg
- 2022年度からは下がり、2021年度13.9kg → 2024年度12.8kg（−1.1kg、−7.9%）
- 中身は入れ替わった。1985→2021年度に、大豆油は4.5→3.0kg、動物油脂（ラード・牛脂・魚油など）は2.5→0.5kg に減り、菜種油は3.9→5.6kg、その他の植物油は2.9→4.8kg に増えた
- 1日の供給熱量に占める油脂類の割合は、4.6%（1960年度）→13.6%（1985年度）→14.9%（2021年度）→13.8%（2024年度）。1985年度より後も少しずつ上がったのは、油の量が横ばいの間に、全体の熱量が2,597kcalから2,266kcalに減ったから

## 頑健性
- 熱量（kcal）で折れ線を当てはめても折れ目は1985年度、3年移動平均でも1985年度、2024年度までを入れると1986年度
- 熱量に占める割合の折れ目は1982年度で、後の傾きは年+0.04ポイント
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致した

## 動かし方
```
pip install -r requirements.txt
cd src && python a257_oil.py
```

## データ
- `data/jukyu_r6_14.csv`：e-Stat「食料需給表」令和6年度 項目別累年表（国民1人・1年当たり供給純食料、kg）。記事101の `data/jukyu_raw.zip` の中身を UTF-8 にしたもの
- `data/jukyu_r6_16.csv`：同じく国民1人・1日当たり供給熱量（kcal）
- 元のファイル：e-Stat「食料需給表」（政府統計コード 00500300）https://www.e-stat.go.jp/stat-search/files?page=1&toukei=00500300&tstat=000001017950

## 注意
- 供給純食料は「国内に供給された量」で、実際に食べた量ではない。揚げ物の油の吸収・廃油など、食べずに捨てる分も入っている
- 油脂類の多くは、家庭で使う油ではなく、加工食品・外食・中食の中に入っている油（推測）。このデータでは家庭と業務を分けられない
- 2022年度からの減りの理由（値上がり、使い方の変化など）は、このデータでは分からない。2024年度は概算値
- 折れ線は「折れ目1つ」の形を仮定している。1985年度を境に急に変わったという意味ではなく、伸びが止まった時期の目安
