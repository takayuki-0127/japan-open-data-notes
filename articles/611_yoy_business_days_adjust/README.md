# 611 営業日の数が違う月を前年同月と比べると、前年比は何ポイント動くのか（実務の型・日数の違いの補正）

月の売上を前年同月と比べるとき、平日の数や土日祝の数が前年と違うと、その分だけ前年比が上下します。平日に売れる業態なら平日が1日少ない月は約5%下がり、土日祝に売れる業態ならその逆です。**ここでは、本当の伸びが毎日 +2% の架空の2業態（平日に売れる卸を想定した業態と、土日祝に多く売れる小売を想定した業態）の日次売上で、2025年の月次の前年比を3通りで出しました。** 祝日は2024・2025年の国民の祝日と振替休日を使い、売れ方は作成者が置いたもので、数字はその仮定で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A611 | 日数の違いの補正で、月次の前年比がどれだけ動くか | M1 月の合計をそのまま、M2 営業日1日あたり（卸は平日、小売は全日）、M3 日の種類の構成をそろえる（前年の「平日・土・日祝ごとの1日平均」×今年の日数を見込みにして比べる）。年末年始（12/29〜1/3）は卸を休みとした。seed 611 | `src/a611_business_days.py` |

## 主な結果
- **平日に売れる業態・そのまま（M1）**：前年比は −6.8%〜+7.8%。本当の +2% からのずれは平均3.4ポイント、最大8.8ポイント。**12か月中4か月がマイナス**に見えた
  - 11月：平日が20日→18日（文化の日・勤労感謝の日の振替が平日に）で −6.8%。6月：20日→21日で +7.8%
- **営業日1日あたり（M2）・構成をそろえる（M3）**：どちらもずれは平均1.1ポイント、最大2.9ポイント、マイナスの月は0
- **土日祝に多く売れる業態・そのまま（M1）**：前年比は −1.2%〜+4.5%、ずれは平均1.8ポイント、マイナスは3か月。2月はうるう年の分（29日→28日）で −1.2%
- 小売では、1日あたり（M2）は2月だけ直り（+2.3%）、土日祝の数の違い（6月・11月・12月など）は残る。構成をそろえる（M3）とずれは平均0.9ポイント、マイナスの月は0
- 補正したあとも残る ±3ポイントほどのずれは、日々の売上の振れ（標準偏差約3%）による

## 動かし方
```
pip install -r requirements.txt
cd src && python a611_business_days.py
```
数秒で終わります。

## 確かめたこと
- 空のフォルダで流し直し、results・figures がバイト単位で一致した
- 平日の数が同じ月（1・3・4・7・10・12月）では、卸の M1 と M2 が一致すること

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 611）。作った日次売上は `results/daily_sales.csv`
- 仮定：卸は平日の売上を1とし、土日祝と年末年始は0.02。小売は平日1、土1.6、日祝1.5。季節の波 ±5%、2025年は一律 +2%、日々の振れは対数正規（標準偏差0.03）

## 注意（言えないこと）
- 架空のデータ。実際の会社の数字ではない
- 給料日・月末・連休の前後など、曜日以外で動く要素は入れていない。実際の補正では、それも日の種類に加える必要がある
- 補正した数字は「日数の違いを除いた伸び」で、売上の金額そのものではない。両方を並べて出すのがよい
