# 946 面積で割るか人口で割るかで、密度の地図はどう変わるのか？（地図と場所）

区ごとの店の数を地図にするとき、「1km²あたり」にするか「1万人あたり」にするかで、色の濃い区は大きく変わります。面積で割った地図は「店が地面の上でどれだけ混んでいるか」、人口で割った地図は「住む人1人に対して店がどれだけあるか」に答えていて、どちらも計算としては正しい数です。**ここでは、作成者が乱数で作った架空の町（12の区、マスごとの人口と、人口に応じた店の数を作成者が置いたもの）で、店の数を面積・住める面積・人口の3つで割り、区の順位と地図の色の段がどれだけ入れ替わるかを数えました。** 2つの地図が似るか逆になるかが、店が人口にどれだけ寄って立つかで決まることを、置き方を変えて確かめました。

地図は架空の格子で、実在の地名や地図のデータは使っていません。区は A区〜L区 の名前の順に並べ、良し悪しの順には並べていません。

関連する記事：分母を「全体」にするか「対象者」にするかで割合が変わる話は 902（割合とパーセント）、反応率の分母で良い投稿が入れ替わる話は 837（SNSと動画）、区域の線の引き方で1位の地区が変わる話は 945、人数の少ない区域の率が極端な色になりやすい話は 948、色分けの区切り方で地図の印象が変わる話は 949 で扱っています。この記事は、地図の色を決める割る数に絞ります。

- **2つの地図の順位相関は、置き方で−0.67〜+0.75と動いた。** 店が人の多い所に多いが人口ほどには集まらない（β＝0.3〜0.7）と2つの地図は逆向き（−0.43〜−0.58）になり、人口以上に集まる（β＞1）と似た地図になった。店が人の住むマスに同じだけ（β＝0）だと、順位相関は−0.05でほぼ無関係だった（このとき面積で割った地図は人口密度とも0.23でほぼ無関係になる）。逆向きがいちばん強く出るのは、β が0と1の間のとき
- 「1km²あたり＝1万人あたり×人口密度」なので、面積で割った地図は、βが0.3以上のどの置き方でも人口密度の地図と0.76〜0.97の順位相関になった。これは割り算の式どおりの結果で、面積で割った地図は多くの場合「人の多い区の地図」に近くなる
- β＝1.0（店が人口に比例）では、人口で割った地図は人口密度と0.02でほぼ無関係になった。店が人口に比例すると置いたので、このとき人口で割った値の違いは、店の数の振れから来るもの
- 公園・池の有無は、2つの地図の関係をほとんど変えなかった（−0.45と−0.38）
- 基本の置き方は、変えたものごとに乱数を変えて数え直したので、順位相関は−0.43〜−0.45と、500回の−0.44から少し動く

## 注意（言えないこと）
- 架空のデータです。人口の分布、店の人口への寄り方、区割り、公園・池の場所は作成者が置いたもので、結果はこれで決まります。2つの地図の順位相関は、置き方で−0.67〜+0.75と動きました。実際の町の人口や店を表すものではありません
- 店は住む人の数だけに応じて置きました。駅や通りの人の流れ、昼の人口（働きに来る人）、区の外から来る客は入れていません。昼の人口で割れば、また別の地図になります（推測）
- 面積と人口のどちらで割るのが正しいかは言えません。問いによって決まります。この記事は、割る数で地図の色がどれだけ変わるかを数えただけです
- 人口の少ない区は、人口で割った値が店の数の小さな増減で大きく動きやすくなります（推測）。この記事ではその振れの大きさは数えていません。少ない人数で割った率が地図の端で極端な色になる話は 948 で数えています
- 区の良し悪しや、どこに店が足りないかは言えません
