# 978 欠けたところだけ別の方法で埋めると、何が混ざるのか？（欠けたデータ）

アンケートで答えなかった人の空欄を、式で予測した値や、電話で聞き直した値で埋めることがあります。埋めたあとの表は空欄がなく、ほかの行と同じように見えます。ただ、埋めた行には「埋めた方法の前提」が入っています。式に入れなかった違いは埋めた行には現れず、聞き方の違いは埋めた人の多いところに偏って入ります。**ここでは、作成者が乱数で作った架空の3店の会員アンケート（会員全員の本当の満足度を作成者が置いたもの）で、答えなかった人だけを5つの方法で扱い、新サービスを使った人と使わない人の差・店どうしの差・ばらつき・相関が、全員の本当の点で数えた値からどれだけずれるかを数えました。**

関連する記事：同じ企画の972（空欄を平均で埋めたときのばらつきと相関）は、平均や回帰の直線で埋めると標準偏差と相関がどう動くか、ばらつきを足すとどう戻るかを扱っています。この記事の標準偏差と相関の結果はそれと同じ向きです。この記事で新しく数えたのは、埋める式に入れなかった違い（新サービス・店）が薄まること、別の聞き方（電話）の違いが答えなかった人の多い店に偏って入ることです。970（答えなかった人は答えた人と同じか）は、答えなかった人を催促後の回答者と同じと置いて埋める読み方を、973 は抜けた月を前の値で埋める読み方を扱っています。既存の記事では、760（欠けた値を−999で埋めたまま回帰する）と F41（欠けの扱い方で回帰の結論が変わるか）が、埋めた値が結果に入る話です。870（謝礼で回答者の構成が変わる）は、答える人の顔ぶれの違いを扱っています。

## 主な結果

### 1回分（`data/members.csv`）
- 6,000人のうち答えなかったのは1,617人（26.95%）。店ごとに A 17.4%・B 25.4%・C 38.05%
- 答えなかった人だけで見ると、新サービスを使った人と使わない人の本当の差は1.043点だった。利用回数だけの式で埋めた値では0.374点しか差がなかった（残った差は、新サービスを使う人に利用の多い人が多いことから来る分）

### 扱い方ごと（基本の置き方、答えなかった人27.51%、200回の平均、`results/methods_base.csv`）

| 利用回数だけの式で埋める | 6.3415 | **0.874** | **−0.1715** | **1.3074** | **0.4579** | **10.6383%** |

（ずれそのものは `results/methods_base.csv` と図 `a978_methods.png`）

- **利用回数だけの式で埋めると、新サービスの差は1.0717点から0.874点に縮んだ（−0.1977点）**。埋めた行には「新サービスで満足度は変わらない」という式の前提が入り、その分が全体に混ざった。C店とA店の差も−0.2994点から−0.1715点に縮んだ。C店は答えなかった人が多いので、埋めた行（店の違いを持たない行）の割合が高い
- 式に店と新サービスを入れると、差のずれはほぼ0（新サービス+0.0008点、C店−A店+0.0018点）になった。それでも、式で埋めた点は散らばりを持たないので、標準偏差は0.1629点小さく、利用の多さとの相関は0.0493高く、8点以上の割合は2.6357ポイント低く出た
- 予測値に散らばりを足して埋めると、6つの値はどれも本当とほぼ同じになった（ずれは点で0.0028以内、8点以上の割合で0.0548ポイント）。**ただし、これは式の形（直線・誤差が正規分布）と、答えない理由が利用の多さと店だけで決まることを、作成者が置いた作りそのままに当てたからです**
- **電話で聞き直して埋めると、全体の平均は0.1637点高く出て、C店−A店の差は−0.2994点から−0.1532点と半分ほどに縮んだ**。電話で高めに答える分が、答えなかった人の多いC店に多く入った
- 除くと、全体の平均は0.0947点高く、8点以上の割合は1.2971ポイント高く出た（利用の少ない人ほど答えないと置いたため）

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約6秒）
- 電話で埋めたときのずれが、式（高めに出る分×答えなかった割合）と12通りで0.0054点以内で合うことを確かめた（作りの確かめ）
- 高めに出る分を0にすると、電話で埋めたときのずれが0になることを確かめた（作りの確かめ）
- `data/members.csv` で、答えた人の行は5つの列とも本当の点と同じで、除く列では答えなかった1,617人がすべて空欄であることを確かめた（埋めるのは答えなかった人の行だけ、という作りの確かめ）

## データ
- `data/members.csv`：架空の会員1回分6,000人（member_id・store（店）・visits（月の利用回数）・new_service（新サービスを使ったら1）・true（本当の満足度）・missing（答えなかったら True）・drop（除く：答えなかった人は空欄）・fill_visits（利用回数だけの式で埋めた値）・fill_full（利用回数・店・新サービスの式）・fill_full_noise（同じ式＋散らばり）・fill_phone（電話で聞き直した値））

## 注意（言えないこと）
- 架空のデータです。店の差、新サービスの差、答えない理由（店と利用の多さ）、電話で高めに答える分（0.6点）は作成者が置いたもので、ずれの大きさはこれで決まります。電話で高めに答えるかどうか、どれだけ高めかは、実際の調査で確かめたものではありません
- 電話で埋めたときのずれは、式（高めに出る分×答えなかった割合）どおりで、新しく数えた結果ではありません。この記事で数えたのは、その分が「答えなかった人の多い店」に偏って入り、店どうしの差が半分ほどに縮んで見えることです
- 式で埋めると、式に入れなかった違いが薄まり、ばらつきが小さくなる向きは、作りから決まる向きです。散らばりを足した (4) がほぼ本当どおりになったのは、作成者が置いた作りと同じ形の式を当てたからです。実際のデータでは本当の形は分からず、答えない理由が満足度そのものにもよるなら、どの埋め方でもこのとおりには戻らないと考えます（推測。数えていません）
- 1回だけ埋めた値を、本当に測った値と同じように扱って誤差の幅を出すと、幅は狭く出すぎると考えます（推測。この記事では幅は数えていません）
- どの埋め方がよいかの助言はしません。埋めた行に印を付けて、埋めた行を除いた結果とも並べる、のような読み方の話にとどめます
