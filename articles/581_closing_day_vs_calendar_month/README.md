# 581 締め日が20日の会社で、月の売上を暦の月で数えるか締めの期間で数えるかで、月ごとの数字はどれだけずれるのか（実務の型・期間の切り方）

請求の締め日が20日の会社では、「3月の売上」が、暦の3月1日〜31日の合計を指すこともあれば、締めの期間（2月21日〜3月20日）の合計を指すこともあります。**ここでは、架空の取引（2023〜2025年の3年分、187,460件）を、暦月と締め期間（前月21日〜当月20日）の2通りで月別に集計し、月ごとの売上と前年同月比がどれだけ違うかを比べました。** 平日中心の注文、月末3営業日の駆け込み、3月・12月の山と8月の谷、年4%の伸びは作成者が置いたもので、数字はその仮定で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A581 | 暦月と締め期間で、月の売上・前年同月比がどれだけ違うか | 同じ取引を暦月と締め期間（21日以降は翌月）で集計。月ごとの差（%）、前年同月比の差（ポイント）と増減の向きが逆になる月、期間に入る営業日数（土日を除いた日数）の前年差との相関、年の合計（暦年と締め年）。締め期間の集計を Python と SQL（DuckDB、1スレッド）で突き合わせ。seed 581 | `src/a581_closing_period.py`、`src/02_closing_duckdb.sql`、`src/01_closing_tsql.sql`（未検証） |

## 主な結果
- **月ごとの差**：締め期間で数えた月の売上は、暦月より −19.7%〜+22.3%違う。絶対値の中央値 5.8%、36か月のうち22か月で5%超、9か月で10%超
- **いちばん大きい月**：2023年3月は −19.7%（暦の3月末の駆け込みが、締めでは4月分に入る）、2023年4月は +22.3%
- **前年同月比**：2024〜2025年の24か月で、2つの数え方の前年同月比の差は絶対値の中央値 5.2ポイント、最大 11.3ポイント（2024年3月：暦月 +0.1%、締め期間 +11.4%）。13か月で5ポイント超
- **増減の向き**：24か月のうち11か月で、前年同月比の増減の向きが逆になった（例：2024年10月は暦月 +4.5%、締め期間 −5.4%）
- **営業日数**：前年同月比のぶれは、期間に入る営業日数の前年差とよく連動する（相関：締め期間 0.83、暦月 0.73）。置いた伸びは年4%だが、営業日数が1日違うと前年比は数ポイント動く
- **年の合計**：暦年と締め年（前年12月21日〜当年12月20日）の差は −0.27%〜+0.29%で、年で見ると小さい
- 21日〜月末の取引は売上の 38.9%。この部分が、どちらの月に入るかで入れ替わる

## 動かし方
```
pip install -r requirements.txt
cd src && python a581_closing_period.py
```
数秒で終わります。`data/transactions.csv`（tx_id・sold_on・amount）を書き出します。

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures がバイト単位で一致した（DuckDB は `SET threads=1`）
- 締め期間の月別売上が、Python と DuckDB の SQL（`02_closing_duckdb.sql`）で36か月すべて一致した
- T-SQL 版（`01_closing_tsql.sql`）は書いたが、SQL Server では動かしていない（**未検証**）

## データ
- 2022年12月21日〜2025年12月31日の取引。平日は1日あたり約200件、土曜はその25%、日曜は10%
- 暦月の月末3営業日は1.6倍。3月1.25倍・9月1.10倍・12月1.15倍・8月0.80倍。年末年始（12/29〜1/3）とお盆（8/13〜16）は0.15倍
- 金額は対数正規分布（中央値 約3.8万円）。年4%で伸びる
- 営業日数は土日を除いた日数。祝日は入れていない

## 注意（言えないこと）
- 架空のデータ。実際の会社の数字ではない
- ずれの大きさは、月末の駆け込みの強さと、21日〜月末に入る売上の割合で決まる。月末に注文が集まらない業種では小さくなる
- 祝日を営業日数から除いていないので、祝日の多い月（5月など）のぶれは、実際とは違う形になる
- 会計上の売上の計上時期（収益認識）については扱っていない。税務・会計の判断の助言ではない
