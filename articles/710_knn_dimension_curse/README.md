# 710 効かない変数を足していくと、k近傍法の当たり方はどれだけ落ちるのか（手法の解説・正解の分かるデータで試す）

k近傍法は、新しい点に「距離の近い学習データ」の多数決でクラスを付けます。効かない変数が多いと、距離はほとんどそれらで決まり、近い点が本当に似た点ではなくなります（次元の呪い）。**ここでは、効く変数2つ（中心からの距離でクラスが決まり、10%のラベルを入れ替え）に、クラスと無関係な変数を0〜50個足し、k近傍法（k=15）の正解率を学習1,000件・テスト2,000件・各10回で比べました。** 変数の単位（標準偏差）は0.5〜5でばらばらにしてあります。数字は置いた前提で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A710 | 効かない変数の数で、k近傍法の正解率はどう変わり、何が効くか | k近傍法（k=15）をそのまま・標準化してから・相互情報量で変数を2つ選んでから。最も近い点と最も遠い点の距離の比も計算。各10回。seed 710 | `src/a710_knn.py` |

## 主な結果
- **上限は90%**（ラベルの10%を入れ替えたため）。効かない変数0個で87.2〜87.8%
- **効かない変数を足すと**：標準化してからでも、2個で80.8%、10個で66.7%、**50個で54.1%**（当て推量は50%）
- **標準化だけでは足りない**：単位がばらばらでも、そのまま（50個で53.4%）と標準化（54.1%）の差は小さい。効かない変数が多いこと自体が問題
- **効く変数を選ぶと戻る**：学習データの相互情報量で2つ選ぶと、50個足しても87.4%
- **距離の差が縮む**：最も近い点の距離÷最も遠い点の距離は、0個で0.03、50個で0.60


## 確かめたこと
- 空のフォルダで流し直し、results・figures がバイト単位で一致した
- 変数の選び方を最初は F 検定（平均の差）にしたが、クラスが中心からの距離で決まる（曲がった関係）ため効く変数を選べず、正解率は50〜67%だった。相互情報量に変えた
- 変数の選択は学習データだけで行い、テストデータは使っていない

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 710）
- 仮定：効く変数は標準正規。クラスは x1²+x2² が中央値（1.386）より大きいか。効かない変数も標準正規で、全変数に0.5〜5の倍率をかけた

## 注意（言えないこと）
- シミュレーションの結果。効く変数の数・関係の形・件数は作成者が置いたもので、結果はこれで決まる
- 実データでは「どれが効く変数か」が分からないので、選び方そのものが外れることがある。ここでは選びやすい形にしてある
- k の値や距離の取り方を変える試しはしていない
