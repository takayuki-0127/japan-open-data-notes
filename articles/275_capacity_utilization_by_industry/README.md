# 275 稼働率が高い業種と低い業種は、何が違うのか

経済産業省「製造工業生産能力・稼働率指数」（鉱工業指数の一部、2020年=100）で、業種別に「生産能力」と「稼働率」の変化を分け、2025年の稼働率を各業種の過去と比べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A275 | 稼働率が高い業種と低い業種は、何が違うのか。生産の減りは、能力を減らしたからか、動かさなくなったからか | 2018年→2025年の年平均の変化を、生産能力指数と稼働率指数（原指数）の対数の差に分ける（稼働率指数は生産量指数÷生産能力指数）。稼働率は業種ごとに2020年=100の指数なので業種どうしで水準は比べず、2025年の平均（季節調整済）がその業種の過去の月の何%より高いかで比べた。過去の月は接続指数（1978〜2022年）と2020年基準（2023年〜）をつないだ | `src/a275_capacity_utilization.py` |

## 主な結果
- 製造工業の稼働率指数（季節調整済）の2025年平均は102.5。1978〜2024年の月のうち、これより低かったのは5.1%（2000年以降に限ると9.7%）。いちばん低い月は2009年2月の79.9、次が2009年3月81.1、2020年5月81.5
- 2018年→2025年に製造工業の生産能力は−4.9、稼働率は−15.1（対数の差×100、ほぼ%）。主な12業種のすべてで稼働率が下がり、能力が下がったのは9業種。能力より稼働率の下がり方が大きかったのは8業種
- 電子部品・デバイスは能力が−24.4で、稼働率（−11.4）より能力の減りが大きい。生産用機械は能力が+5.3、稼働率が−32.0。化学工業は能力−5.8、稼働率−20.5で、2025年の稼働率は1978年以降の月の下から1.4%
- 2025年の稼働率が自分の過去の月の25%未満の低さだった業種は、12業種中10。いちばん高い位置は石油・石炭製品の33.9%

## 頑健性
- 起点を2019年にすると、製造工業は能力−4.8、稼働率−11.3。電子部品は能力−21.1、稼働率+0.2（2018年が生産の山だったため、2019年起点では稼働率は下がっていない）。化学は能力−5.6、稼働率−20.8
- 季節調整済の稼働率で2018→2025年を出しても、製造工業−15.1、化学−20.4
- 2026年1〜8月の稼働率（季節調整済）は、汎用・業務用機械118.3、生産用機械111.8、輸送機械112.5と2025年より高い業種もある
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致した

## データ
- `data/capacity_utilization_2018_2026.csv`：`b2020_ngom1j.xlsx`（能力・稼働率 原指数）、`b2020_ngsm1j.xlsx`（稼働率 季節調整済）、業種別 月次、2018年1月〜2026年8月
- `data/utilization_sa_connected_1978_2022.csv`：`b2020_nsgs1j.xlsx`（過去の稼働率 接続指数 季節調整済）

## 注意
- 稼働率指数は「2020年を100としたときの動き」で、設備の何%が動いているか（稼働率の水準そのもの）ではない。業種どうしの水準は比べられないので、各業種の自分の過去と比べた
- 1978年からの長い系列は接続指数で、分類や基準の変更をつないだもの。業種によって系列の始まりが違う（1978・1998・2008・2013年）
- 能力の変化には、設備の廃棄だけでなく、調査の対象品目の能力の見直しも入る
- 稼働率が低い理由（需要の弱さ、人手不足、部品不足など）は、このデータでは分からない
