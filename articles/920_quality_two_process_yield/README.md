# 920 工程を2つつなぐと、全体の良品率はどうなるのか？（品質と検査）

2つの工程をつなぐとき、全体の良品率は「工程1の良品率×工程2の良品率」で出すのがふつうです。けれども、工程ごとの良品率を検査の合格率で数えると、検査の見逃し（不良を合格にする）と誤って捨てる（良品を不良にする）が入ります。さらに、材料のロットの良し悪しが両方の工程に効くと、2つの工程の不良は結びつきます。**ここでは、作成者が乱数で作った架空の2つの工程（本当の不良の確率・ロットの効き・検査の見つける確率と誤って捨てる確率を作成者が置いたもの）で、「検査の合格率の掛け算」「工程ごとの本当の良品率の掛け算」「本当に2つとも良品だった割合」がどれだけ違うか、出荷品に不良がどれだけ混ざるかを数えました。**

## 主な結果

### 基本の置き方（200回の平均）
| 全体の良品率の数え方 | 値 |
|---|---|
| 式：(1−0.05)×(1−0.08) | 87.40% |
| 検査の合格率の掛け算（工程1 94.55% × 工程2 91.97%） | **86.96%** |
| 工程ごとの本当の良品率の掛け算 | 87.42% |
| 本当に2つとも良品だった割合 | **87.51%** |
| 出荷できた良品（入れた数に対して） | 85.77% |

- 検査の合格率の掛け算は、入れた数のうち出荷できた割合そのもの（式どおり）。本当に2つとも良品だった割合より0.55ポイント低かった。見逃しで高く出る分より、良品を誤って捨てて低く出る分が大きかったため
- **出荷した品物のうち1.37%は不良だった**（見逃し）。良品なのに捨てた品物は、入れた数の1.74%だった
- 工程ごとの本当の良品率の掛け算は、本当に2つとも良品だった割合より0.095ポイント低かった（200回の10〜90%の範囲で−0.13〜−0.07ポイント）。ロットの良し悪しが両方の工程に効くと置いたため、悪いロットに不良が重なり、2つとも良品の割合は掛け算より少し高くなる

### 確かめ：ロットの効き・見つける確率・誤って捨てる確率を変えると（27通り、`results/grid_b_d_f.csv`）
| 見つける確率 | 誤って捨てる 0% | 1% | 3% |
|---|---|---|---|
| 100% | 0.00 | −1.75 | −5.16 |
| 90% | +1.20 | −0.55 | −4.01 |
| 70% | +3.65 | +1.87 | −1.63 |

（検査の合格率の掛け算 − 本当に2つとも良品だった割合、ポイント。ロットの効き b=0.5）

- **検査の合格率の掛け算は、27通りで本当に2つとも良品だった割合から−5.18〜+3.69ポイントずれた**。見逃しが多いと高く、誤って捨てるのが多いと低く出て、向きは2つの釣り合いで決まった
- 出荷品のうち不良の割合は0〜4.17%で、見つける確率だけでほぼ決まった（誤って捨てる確率ではほとんど動かない）
- 工程ごとの本当の良品率の掛け算と、本当に2つとも良品だった割合の差は、ロットの効き b=0 で0、b=0.5 で約−0.09、b=1.0 で約−0.4ポイント（27通りで−0.42〜0.00ポイント）。**ロットの結びつきによるずれは、検査によるずれよりずっと小さかった**
- 見つける確率100%・誤って捨てる0%・ロットの効き0なら、3つの数え方はすべて87.40%（87.395%）で式と一致した

### 工程の数を増やすと（どの工程も不良5%、見つける90%・誤って捨てる1%・b=0.5、`results/by_number_of_processes.csv`）
| 工程の数 | 0.95の工程の数乗 | 検査の合格率の掛け算 | 本当にすべての工程で良品 | 出荷品のうち不良 |
|---|---|---|---|---|
| 1 | 95.00% | 94.505% | 94.95% | 0.54% |
| 2 | 90.25% | 89.41% | 90.27% | 1.05% |
| 4 | 81.45% | 80.065% | 81.65% | 2.05% |
| 6 | 73.51% | 72.18% | 74.45% | 2.92% |

- 工程を増やすほど、合格率の掛け算と本当の良品率の差は−0.45ポイントから−2.27ポイントに広がり、出荷品の不良は工程の数にほぼ比例して増えた（見逃しが工程ごとに積み重なる）

- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約20秒）

- ロットの効きを変えても、工程ごとの本当の良品率が置いた95%・92%のまま（87.23〜87.48%の掛け算）になるよう、切片を合わせたことを確かめた

## データ
- `data/lots_one_period.csv`：架空の1回分の200ロット（lot・lot_factor（ロットの良し悪し z）・units・defect_p1・defect_p2（本当の不良の数）・defect_both・pass_p1・pass_p2（検査の合格の数）・shipped_defective（出荷した品物のうち不良の数））。この1回では、合格率の掛け算85.99%、本当に2つとも良品86.48%、出荷品のうち不良1.48%（`results/a920_main.json` の one_period）

## 注意（言えないこと）
- 架空のデータです。不良の確率、ロットの効き、検査の見つける確率と誤って捨てる確率は作成者が置いたもので、ずれの大きさと向きはこれで決まります。独立で検査が完璧なら掛け算で合う、検査の合格率の掛け算は出荷できた割合そのもの、は式どおりの結果で、新しく数えたのは、見逃しと誤って捨てるでどちらにどれだけずれるか、ロットの結びつきの効きがそれよりずっと小さいことです
- 各工程の検査は、その工程の不良だけを見ると置きました。工程2の検査が工程1の見逃しを拾うこと、手直しして戻すこと、工程1の不良が工程2の不良を起こしやすくすることは入れていません
- 部品の安全にかかわる不良は扱っていません。検査の見つける確率をどこまで上げるべきかは、ここからは言えません
- 関連する記事 851 は、並行する作業がすべてそろう確率が作業の数だけ掛け算で下がることを数えています。この記事の「0.95の工程の数乗」も同じ掛け算です。同じ企画の 911 は検査で不良と出た品物が本当に不良か（見逃しと誤検出）、914 は全数検査でも不良がゼロにならないことを、1つの検査について数えています。この記事は、工程をつないだときの良品率の数え方を扱っています
