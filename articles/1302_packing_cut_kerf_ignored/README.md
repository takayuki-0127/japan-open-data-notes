# 1302 切るときの刃の幅（切りしろ）を入れずに計算すると、1本の棒から取れる部品の数の見込みはどれだけ多く出るのか？（箱詰めと積載）

決まった長さの棒から部品を切り出すとき、「棒の長さ÷部品の長さ」で何個取れるかを見込むことがあります。けれども、のこぎりなどで1回切るたびに、刃の幅の分（切りしろ）が粉になって消えます。部品を n 個取るには、部品の長さの合計に加えて、n−1 回分の切りしろが要ります。棒の長さが部品の長さでちょうど割り切れるときは、切りしろの分だけ足りなくなり、最後の1個が取れません。**ここでは、作成者が置いた架空の通販の工房（長さ2,000mmの棒から棚の部品を切り出して発送する。切りしろ3mm）で、(1) 1種類の長さ（50〜1,000mm、1mm刻みの951通り）だけを切るときの見込みと本当の個数、(2) 8種類の長さがまざる1日の注文（平均95.52個）を500日分、切りしろなしで立てた計画のうち切りしろを入れると切れない棒の割合と、切りしろを入れて立て直したときに要る棒の数を数えました。切りしろ1・2・3・5mm×部品の長さのまざり方3通りの12通りの確かめも行いました。**

例の工房・棒・部品の長さは作成者が置いた架空のもので、実在の材料や道具の数値を表すものではありません。

関連する記事：1115「平均のダメージで敵の体力を割って『何回で倒せるか』を出すと、実際の回数とどれだけずれるのか？」は、平均で割った見込みが、最後の1回のあふれの分だけ実際の回数より少なく出ることを、ゲームの数値で数えています。1168「小さなファイルがたくさんあると、大きさの合計と実際に使う量はどれだけ違うのか？」は、1件ごとに決まった大きさの区画へ切り上げると、使う量が大きさの合計を上回ることを扱っています。1301「決まった長さの棒から長さの違う部品を切り出すと、余りの割合は、部品の長さの組み合わせしだいでどれだけ変わるのか？」は、決まった長さの棒から切り出すとき、部品の長さの組み合わせで余りの割合がどれだけ変わるかを、切りしろを0として数えています。1303「詰め方の良さを、『体積の合計÷容量』の切り上げと比べるか、いちばん良い詰め方と比べるかで、どれだけ見え方が違うのか？」は、詰め方の良さを「体積の合計÷容量」の切り上げ（下限）と比べるか、いちばん良い詰め方と比べるかで、無駄の大きさの見え方がどれだけ違うかを数えています。この記事は、割り算の見込みに入っていない「1回切るごとに消える分」で個数が減る点と、切りしろなしの計画がそのままでは切れなくなる割合に絞ります。

## 主な結果

### 1種類の長さだけを切るとき（951通り、`results/single_length.csv`、式どおり）
| 部品の長さ | 見込み（切りしろなし） | 本当（切りしろ3mm） | 見込みが多い分 |
|---|---|---|---|
| 50mm | 40個 | 37個 | **3個（8.11%）** |
| 80mm | 25個 | 24個 | 1個（4.17%） |
| 100mm | 20個 | 19個 | 1個（5.26%） |
| 125mm | 16個 | 15個 | 1個（6.67%） |
| 200mm | 10個 | 9個 | 1個（11.11%） |
| 250mm | 8個 | 7個 | 1個（14.29%） |
| 400mm | 5個 | 4個 | 1個（25.0%） |
| 500mm | 4個 | 3個 | 1個（33.33%） |
| 664mm | 3個 | 3個 | 0個 |
| 666mm | 3個 | 2個 | 1個（50.0%） |
| 1,000mm | 2個 | 1個 | **1個（100.0%）** |

| 部品の長さの帯 | 長さの数 | 見込みが多く出た長さの割合 | 多い分の最大 |
|---|---|---|---|
| 50〜99mm | 50 | **84.0%** | 3個（8.11%） |
| 100〜199mm | 100 | 27.0% | 1個（11.11%） |
| 200〜499mm | 300 | 5.67% | 1個（33.33%） |
| 500〜1,000mm | 501 | 1.0% | 1個（100.0%） |

- 951通りのうち、見込みが本当より多く出たのは**9.57%**だった。多く出るのは、棒の長さを部品の長さで割った値が、ちょうど整数か、整数より少しだけ大きいとき（式どおり）
- **2,000mmを割り切る9つの長さ（50・80・100・125・200・250・400・500・1,000mm）は、すべて見込みが1個以上多かった**（50mmは3個）。割り切れない942通りでは8.7%だった
- 部品が短いほど切る回数が増えるので、多く出る長さの割合は大きくなった（50〜99mmで84.0%）。部品が長いと多く出る長さはまれだが、多く出たときの割合は大きい（1,000mmで見込み2個に本当は1個）
- 664mm なら3個取れるが（664×3＋3×2＝1,998mm）、666mm では2個になった（666×3＋3×2＝2,004mm）

### 8種類がまざる1日の注文（基本、500日、`results/a1302_main.json` の base_days）
| | 値 |
|---|---|
| 1日の部品の数（平均） | 95.52個 |
| 切りしろなしで計画した棒（1日の平均） | 21.286本 |
| 切りしろを入れて計画し直した棒（1日の平均） | 21.312本（**+0.12%**） |
| 計画し直すと棒が1本以上増えた日 | 2.6% |
| 切りしろなしの計画のまま切ると、長さが足りない棒 | **計画の棒の1.32%**（1日平均0.282本） |
| そのとき取れずにあきらめる部品 | 部品の0.3% |

- 長さのまざった注文では、切りしろを入れて計画し直せば、要る棒はほとんど増えなかった（+0.12%）。部品の組み合わせを入れかえて、切りしろの分をほかの棒の余りで吸収できたため
- けれども、**切りしろなしで立てた計画をそのまま使うと、計画の棒の1.32%は長さが足りず**、計画どおりには切れなかった
- 棒の端を1回切りそろえる置き方では、計画し直すと+0.15%、計画のままでは足りない棒が2.09%、あきらめる部品が0.46%になった

### 確かめ：まざり方と切りしろ（12通り、各300日、`results/grid.csv`）
| まざり方 | 切りしろ | 計画し直すと増える棒 | 計画のままだと足りない棒 | あきらめる部品 |
|---|---|---|---|---|
| 短め（80〜300mm） | 1mm | 0.95% | 32.61% | 3.23% |
| 短め（80〜300mm） | 3mm | 1.6% | 72.54% | 7.13% |
| 短め（80〜300mm） | 5mm | 2.42% | **80.95%** | 8.06% |
| 基本（150〜760mm） | 1mm | 0.0% | **0.02%** | 0.0% |
| 基本（150〜760mm） | 3mm | 0.08% | 1.65% | 0.37% |
| 基本（150〜760mm） | 5mm | 0.18% | 2.99% | 0.67% |
| 長め（400〜1,000mm） | 1mm | 1.14% | 18.19% | 6.58% |
| 長め（400〜1,000mm） | 3mm | 1.33% | 18.53% | 6.67% |
| 長め（400〜1,000mm） | 5mm | 1.19% | 19.47% | 7.03% |

（2mm を含む12通りすべては `results/grid.csv`）

- **計画のままだと足りない棒の割合は、まざり方と切りしろで0.02〜80.95%と大きく動いた**。計画し直したときに増える棒は0〜2.42%にとどまった
- 長い部品の注文（1,000mm を2個、400mm を5個など、足すと2,000mm ちょうどになる組み合わせがある）では、切りしろの大きさにあまりよらず18%前後が足りなかった。切りしろなしの計画で部品の長さの合計がちょうど2,000mm になった棒が17.87〜18.54%あり、足りない棒の割合とほぼ同じだった（`results/grid.csv` の plan_rods_exact_share_pct）。ちょうど2,000mm の棒は、切りしろが1mm でもはみ出す
- 短い部品の注文でも、ちょうど2,000mm の棒が29.27〜30.6%あった。それに加えて1本から取る数が多く切る回数が増えるので、切りしろ1mm で32.61%、5mm で80.95%と、切りしろが大きいほど足りない棒が増えた
- 基本のまざり方では、ちょうど2,000mm の棒は0〜0.02%で、計画の余りに切りしろが収まりやすかった。このため、基本の置き方の値（1.32%）は12通りの中では小さい側である

## 注意（言えないこと）
- 架空の数値です。棒の長さ・切りしろ・部品の長さ・注文の数は作成者が置いたもので、結果はこれで決まります。とくに、まざった注文で計画が崩れる割合は、部品の長さを足して棒の長さちょうどになる組み合わせがどれだけあるかと、1本から取る数で、0.02〜80.95%と大きく動きました
- 1種類の長さの結果は式どおりで、乱数は使っていません
- 部品の長さの誤差、棒の長さのばらつき、切った面の仕上げの分、余りの端材を使い回すことは入れていません
- 詰め方は「長い順に並べてから入る最初の棒」の1つだけです。いちばん少ない本数の詰め方と比べてはいません
- 材料の買い方、道具の選び方、値段の決め方を言うものではありません
