# 850 「最もありそうな日数」で計画すると、間に合う確率は何%か？（見積もりと締め切り）

「この作業は何日かかりそうか」と聞かれると、いちばんよくありそうな日数（分布の山の位置）を答えがちです。作業の日数が右に長い分布なら、山の位置は半々で終わる日数より短く、それで計画すると間に合わない回が半分を超えます。**ここでは、作成者が乱数で作った架空のプロジェクト（作業10個を順に行う。作業ごとの本当の日数の分布を作成者が置いたもの）で、「最もありそうな日数」・半々の日数・平均の日数・三点見積もり・8割の日数のそれぞれで計画したとき、作業1個と作業10個の合計が計画以内に終わる確率を数えました。分布の形・ばらつき・作業どうしの関係・最短と最長の答え方を変えた確かめも行いました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A850 | 「最もありそうな日数」で計画すると、間に合う確率は何%か。三点見積もりで直せるか | 架空のプロジェクト。作業10個を順に行う。作業ごとの半々で終わる日数（中央値）は2〜10日の整数を乱数で置いた（合計59日、`data/tasks.csv`）。実際の日数は対数正規分布（右に長い分布）で、中央値は置いた日数・ばらつき sigma=0.5（日数の対数の標準偏差）。作業どうしは互いに影響しない（基本）。担当者が答える「最もありそうな日数」は分布の山の位置（最頻値＝中央値×exp(−sigma²)）、「最短」「最長」は分布の5%点・95%点と置いた。計画の決め方は6つ：最頻値・中央値・平均（中央値×exp(sigma²/2)）・三点見積もり（（最短＋4×最もありそう＋最長）÷6）・三点見積もり＋ばらつきで8割をねらう（三点見積もりの合計＋0.84×√（作業ごとの（最長−最短）÷6 の2乗の合計））・作業ごとの8割点。作業1個（1個目の作業）と作業10個の合計それぞれで、計画以内に終わる確率を20万回の乱数で数えた。確かめとして、ばらつき sigma=0.3・0.8、分布をガンマ分布（ばらつきは同じ、最頻値・平均もガンマのものに置き直す）、共通の振れ（全部の作業が一緒に延びる度合い rho=0.3・0.6）、最短・最長を1%点と99%点・10%点と90%点・20%点と80%点で答えるとした場合を数えた。seed 850 | `src/a850_most_likely.py` |

関連する記事：849「作業ごとの見積もりを足すと、全体の見積もりは何%足りなくなるのか？」は「半々の日数」を足す不足を、この記事は見積もりに使う1つの数（山の位置・半々・平均など）の選び方を扱います。854「過去の実績で見積もりを直すと、外れはどれだけ減るのか？」は見積もる人の癖を実績で直すことを、859「見積もりの幅（最短〜最長）を書くと、外れ方はどう変わるのか？」は幅の書き方そのものと幅に入る割合を扱います。この記事の確かめの「最短・最長の答え方」は、三点見積もりの計算に入れたときの影響だけを見ています。

## 主な結果

### 計画の決め方ごとの、計画以内に終わる確率（sigma=0.5・作業どうし独立、20万回）
| 計画の決め方 | 作業1個（1個目、半々5日）の計画 | 作業1個 | 作業10個の合計の計画 | 作業10個の合計 |
|---|---|---|---|---|
| 最もありそうな日数（最頻値） | 3.89日 | **30.94%** | 45.95日 | **1.60%** |
| 半々で終わる日数（中央値） | 5.00日 | 50.10% | 59.00日 | 26.06% |
| 三点見積もり | 4.86日 | 47.82% | 57.33日 | 20.91% |
| 平均の日数 | 5.67日 | 59.93% | 66.86日 | 53.76% |
| 三点見積もり＋ばらつきで8割をねらう | 6.15日 | 66.14% | 62.28日 | 37.40% |
| 作業ごとの8割点 | 7.62日 | 80.08% | 89.87日 | 96.35% |

- 「最もありそうな日数」で計画すると、作業1個でも間に合うのは30.94%だった。式で計算した値（30.85%）と合った。10個の作業それぞれでも30.69〜30.94%だった
- 作業10個の合計を「最もありそうな日数」の合計（45.95日）で計画すると、間に合ったのは1.60%だった。実際の合計の平均は66.86日で、計画より45.51%長かった
- 最もありそうな日数は、半々の日数の0.7788倍、平均の日数の1/1.455だった（sigma=0.5のときの式の値）
- 三点見積もりは、最短・最長を5%点・95%点で答えると、半々の日数より少し短くなった（作業1個で47.82%）。三点見積もりのばらつき（（最長−最短）÷6）で8割をねらっても、作業10個の合計では37.40%しか間に合わなかった。三点見積もりの式は、最短と最長を「ほぼ起きない端」として答える前提の式で、5%点・95%点ではばらつきを小さく見積もるため
- 作業ごとの8割点を足すと96.35%になり、8割をねらうには余りすぎた（余裕の置き方は関連する記事 852 で扱っています）

### 半々の日数を10日とした作業1個（式）
| 計画 | 日数 | 間に合う確率 |
|---|---|---|
| 最もありそうな日数 | 7.79日 | 30.85% |
| 半々の日数 | 10.00日 | 50.00% |
| 平均の日数 | 11.33日 | 59.87% |
| 8割の日数 | 15.23日 | 80.00% |

### 確かめ：置き方を変えると（20万回）
| 置き方 | 最もありそう・作業1個 | 最もありそう・10個の合計 | 三点見積もり・10個の合計 | 三点見積もり＋8割・10個の合計 |
|---|---|---|---|---|
| 基本（別の乱数） | 31.03% | 1.67% | 20.94% | 37.47% |
| ばらつき sigma=0.3 | 38.43% | 9.60% | 28.84% | 46.52% |
| ばらつき sigma=0.8 | 21.24% | 0.06% | 18.89% | 35.46% |
| 分布をガンマ分布に | 34.07% | 3.77% | 25.51% | 42.25% |
| 共通の振れ rho=0.3 | 30.95% | 14.40% | 36.44% | 46.96% |
| 共通の振れ rho=0.6 | 30.75% | 23.10% | 42.87% | 51.05% |
| 最短・最長を1%点と99%点で答える | 30.71% | 1.64% | 47.80% | 72.68% |
| 最短・最長を10%点と90%点で答える | 30.98% | 1.67% | 13.28% | 23.51% |
| 最短・最長を20%点と80%点で答える | 30.76% | 1.68% | 8.36% | 13.15% |

- 置き方で、「最もありそうな日数」で作業1個が間に合う確率は21.24〜38.43%、作業10個の合計では0.06〜23.10%だった。どの置き方でも、作業1個で半分を下回り、10個の合計では4回に1回を下回った
- 作業が一緒に延びやすいと置くと、10個の合計でも間に合う確率は上がった（rho=0.6で23.10%）
- 三点見積もりは、最短・最長の答え方で大きく動いた。10個の合計を8割の確率でねらった計画が間に合う確率は、13.15%（20%点と80%点で答える）から72.68%（1%点と99%点）まで動いた。最短・最長を狭く答えるほど、三点見積もりは短く、ばらつきも小さく出る

## 動かし方
```
pip install -r requirements.txt
cd src && python a850_most_likely.py
```
4秒ほどで終わります。`data/tasks.csv`・`data/runs.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（`src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp）。流し直しは約3.7秒
- 「最もありそうな日数」以内に終わる確率（乱数、作業ごとに30.69〜30.94%）が、式の値30.85%と合うことを確かめた
- 主な結果の表と確かめの表の「基本」は乱数が別なので、0.1ポイントほど違う（例：10個の合計 1.60% と 1.67%）

## 注意（言えないこと）
- 架空のプロジェクトです。作業の日数の分布の形、ばらつき、作業どうしの関係は作成者が置いたもので、結果はこれで決まります。置き方で、「最もありそうな日数」で作業1個が間に合う確率は21〜38%、10個の合計では0.06〜23%まで動きました
- 担当者が「最もありそうな日数」を聞かれて、分布の山の位置を正しく答えると置きました。実際の人が山の位置・半々・平均のどれに近い数を答えるかは、この分析では分かりません
- 三点見積もりの結果は、最短・最長を分布のどの点として答えるかの置き方で決まります。三点見積もりそのものの良し悪しを決めるものではありません
- 実在のプロジェクトや会社の実績を表すものではありません
