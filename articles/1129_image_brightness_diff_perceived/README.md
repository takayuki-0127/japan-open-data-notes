# 1129 明るさの差を数値のまま測ると、人が見て感じる差とどこでずれるのか？（画像と色）

2枚の画像の明るさの違いを数えるとき、画素の値（0〜255）の差や、光の強さの差をそのまま使うことがよくあります。けれども、人の見え方は暗い所の差に敏感で、明るい所の差には鈍いと言われます。数値の差が同じでも、感じる差は同じとは限りません。**ここでは、作成者が置いた「見え方の式」（画素の値→光の強さ→感じる明るさ）を正しい答えとして、架空の商品の写真に見立てた灰色の板の組20,000組と色の板の組20,000組で、①画素の値の差、②光の強さの差、で測ったときに、置いた式の差とどこでずれるかを数えました。見え方の式そのものを作成者が置いているので、ずれの場所と大きさは式どおり・作りどおりです。式の2つの指数と「気づける境目」を変えた27通りも確かめました。**

例の板は式と乱数で作った架空のもので、実在の写真・商品を表すものではありません。見え方の式は作成者が置いたもので、人に見てもらって確かめたものではありません。人の見え方を、人の属性で比べたものでもありません。

関連する記事：20冊目 第9章の 821「色の順番と強さで、どの数字が目立つかは変わるのか？」は、グラフの色の並びと背景で、背景との明るさの差が大きいマスが目立つと置いたときに、目立つマスが大きい数字と重なるかを扱っています。この記事は、その「明るさの差」を画素の値・光の強さ・置いた式のどれで数えるかでずれる場所に絞ります。同じ企画の 1126「色の値をそのまま平均して混ぜた色は、なぜ暗く濁って見えるのか？」は、色の値（画素の値）と光の量のどちらで平均するかで明るさが変わることを扱っています。この記事は同じ「画素の値→光の強さ」の式を使い、平均ではなく差の測り方に絞ります。1128「圧縮の画質の設定を下げると、ファイルの大きさと見た目の差は同じ割合で動くのか？」は、見た目の差を画素の差で数えています。1136「明るい所と暗い所を1枚に収める処理で、明るさの順番は入れかわるのか？」は、差の大きさではなく、明るい所と暗い所を1枚に収めたときに明るさの順が保たれるかを扱っています。

## 主な結果

### 画素の値で10上げたときの差（式どおり、`results/by_level.csv`）
| もとの画素の値 | 置いた式の差 | 光の強さの差（×100） | 境目（1）に届く画素の値の差 |
|---|---|---|---|
| 0 | 0.727 | 0.08 | 12 |
| 5 | 1.615 | 0.179 | 8 |
| 15 | 3.683 | 0.408 | 4 |
| 30 | **5.672** | 0.797 | 2 |
| 60 | 4.805 | 1.674 | 3 |
| 120 | 4.035 | 3.667 | 3 |
| 180 | 3.634 | 5.87 | 3 |
| 240 | 3.372 | **8.223** | 3 |

- **画素の値で同じ10上げても、置いた式の差は明るさで0.727〜5.672と7.8倍違った**。いちばん大きいのは画素の値30前後（少し暗い所）、いちばん小さいのは0（真っ黒の近く）。30〜240の間では1.68倍の違いにとどまった
- **光の強さの差は、画素の値240では10のときの28.45倍で、置いた式とは逆に明るい所ほど大きく出た**
- 境目に届く画素の値の差は、真っ黒の近くでは12、少し暗い所（25〜50）では2、それより明るい所では3だった

### 灰色の板の組20,000組（`data/gray_pairs.csv`）
| | 画素の値の差で分ける | 光の強さの差で分ける |
|---|---|---|
| 置いた式との順位の相関 | 0.935 | 0.583 |
| 「差あり」の境目 | 画素の値の差3以上 | 光の強さの差0.48（×100）以上 |
| 置いた式と分け方が違う組 | **3.56%** | **17%** |
| 外れた組のうち、暗い組（2枚の平均が64未満）の割合 | 100% | 気づけるのに「差なし」とした組の100%、気づけないのに「差あり」とした組のうち明るい組（192以上）が47.4% |

- 置いた式で差に気づける組は77.24%だった。同じ割合になるように画素の値の差の境目を選ぶと（3以上）、分け方が違う組は3.56%で、**すべて暗い組だった**（うち68%は2枚の平均が16未満）。明るい組での外れは0%だった
- 光の強さの差で分けると、17%の組で分け方が違った。暗い組の差を小さく見て「差なし」とし（8.48%）、明るい組の小さな差を「差あり」とした（8.52%）
- 組どうしで「どちらの組の差が大きいか」を比べると、画素の値の差と置いた式とで6.87%の対が入れかわった

### 色の板（明るさの感じ方だけ）
| 灰色（128,128,128）から1色だけ40上げる | 置いた式の差 |
|---|---|
| 赤 | 3.846 |
| 緑 | **11.624** |
| 青 | **1.353** |

- 画素の値の差は同じ40でも、置いた式の明るさの差は、緑を上げると青の8.59倍だった（置いた重みどおり）
- 色の板の組20,000組で、赤・緑・青の差の大きさ（二乗和の平方根）と置いた式の明るさの差の順位の相関は0.455だった。差の大きさが10〜12の組（3,945組）でも、置いた式の差は10〜90%の範囲で0.27〜2.74と開き、34.4%は境目（1）に届かなかった

### 確かめ：置き方27通り（`results/grid.csv`）
| | 27通りの結果 |
|---|---|
| 画素の値で分けたときに外れる組 | 1.17〜14.46% |
| 光の強さで分けたときに外れる組 | 7.76〜33.76% |
| 画素の値の外れのほうが小さかった置き方 | 25通り |
| 外れた組のうち暗い組の割合（画素の値で分けたとき） | 34.2〜100% |
| 画素の値の差と置いた式の差の順位の相関 | 0.84〜0.979 |
| 境目に届く差：画素の値20から | 1〜14 |
| 境目に届く差：画素の値235から | 1〜9 |
| 画素の値20→30の式の差÷235→245の式の差 | 0.27〜3.49（1を超えたのは15通り） |

- **暗い所と明るい所のどちらで画素の値の差が小さく見積もられるかは、置いた2つの指数で入れかわった**。g が小さく感じ方の指数が小さいと暗い所の差が大きく（3.49倍）、g が大きく感じ方の指数が大きいと明るい所の差が大きく（0.27倍）なった。基本の置き方（g＝2.2・指数1/3）では1.42倍だった
- 光の強さの差で分けると、25通りで画素の値の差より外れが多かった。光の強さの外れが少なかった2通りは、g＝2.6・感じ方の指数0.5の置き方（境目0.5・1）だった

## 注意（言えないこと）
- 見え方の式は作成者が置いたもので、この記事の「人が見て感じる差」はすべてこの式の値です。人に見てもらって確かめてはいません。ずれの場所と大きさは、置いた式で決まります（式どおり・作りどおり）
- 置いた式は、まわりの明るさ・画面の明るさ・板の大きさ・見る時間を入れていません。まわりが暗いか明るいかで、気づける差は変わると考えられます（推測）
- 色の板では明るさの感じ方だけを数え、色みの違い（赤っぽい・青っぽい）は数えていません。色みを入れると、青を上げた板の差はもっと大きく感じると考えられます（推測）
- 人の色の見え方の違いを、人の属性で比べたものではありません
