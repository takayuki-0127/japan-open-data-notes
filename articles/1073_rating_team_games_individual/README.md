# 1073 チーム戦の勝ち負けから、1人ひとりの強さはどこまで分かるのか？（対戦とレーティング）

チーム戦の勝ち負けは、味方と相手の何人もの強さが合わさって決まります。そこから1人ひとりの強さを読もうとすると、「味方に恵まれただけ」の勝ちが混ざります。けれども、1人の強さがチームの勝ち負けにどれだけ効くかは、チームの強さをどう置くかで変わります。**ここでは、作成者が乱数で作った架空の対戦ゲームのリーグ（100人。1人ひとりの本当の強さを作成者が置いたもの）で、1対1・3対3・5対5のチーム戦を1人あたり10〜800試合させ、1人ひとりの勝率と、チームの強さを置いた回帰で強さを見積もり、本当の強さの順位とどれだけ合うかを数えました。チームの強さを「メンバーの強さの合計」と置くときと「平均」と置くときを比べ、いつも同じ顔ぶれで組むときも数えました。**

点数の近い人どうしを当てる組み方で勝率が5割に近づく話は同じ企画の関連する記事 1074、総当たりでない記録から順位を決める話は 1076 で扱っています。少ない件数の上位が当たりにくい話は 833 で扱っています。この記事は、相手も味方もでたらめに組むチーム戦で、1人の強さがどこまで分かるかに絞ります。

## 主な結果

### チームの人数と1人あたりの試合数（回帰、各20回の平均、`results/by_size_games.csv`）
| 1人あたりの試合数 | 1対1 | 3対3（合計） | 5対5（合計） | 3対3（平均） | 5対5（平均） |
|---|---|---|---|---|---|
| 100試合 | 0.815 | 0.802 | **0.777** | 0.398 | 0.255 |
| 800試合 | 0.968 | 0.966 | 0.961 | 0.786 | **0.639** |

（本当の強さとの順位の相関）

- **チームの強さを合計と置くと、5対5でも1人100試合で順位の相関は0.777で、1対1（0.815）と大きくは変わらなかった**。順位の相関が0.8に届いたのは、1対1・3対3で100試合、5対5で200試合
- **チームの強さを平均と置くと、5対5は800試合でも0.639にとどまった**。3対3・5対5は、800試合までで0.8に届かなかった
- 違いは、1人の強さが1試合の勝つ確率にどれだけ効くかから来る。合計なら1人分の強さはそのまま効き、平均なら5対5では5分の1しか効かない（置き方どおり）。どちらの置き方が実際のゲームに近いかは、この記事では決められない
- でたらめに組む限り、①1人ひとりの勝率と②回帰の差は小さかった（5対5・合計・100試合で 0.755 と 0.777）。味方の当たり外れは、試合を重ねると打ち消し合うため

### 上位10人の当たり（5対5・合計）
| 1人あたりの試合数 | ① 勝率 | ② 回帰 |
|---|---|---|
| 10試合 | 21.0% | 21.5% |
| 50試合 | 44.5% | 49.0% |
| 100試合 | 55.5% | 55.5% |
| 200試合 | 57.5% | 63.0% |
| 800試合 | 83.5% | 84.5% |

- 1人100試合でも、本当の上位10人に入っていたのは半分ほどだった
- 例の1リーグ（5対5・1人50試合、500試合）では、本当にいちばん強い人の勝率は11位だった（`data/players_example_5v5.csv`）

### いつも同じ顔ぶれで組む割合（5対5・合計・1人100試合、各20回、`results/fixed_teams.csv`）
| 同じ5人で出た試合の割合 | 順位の相関（②回帰） | 同じチームの2人のうち強いほうを当てた割合（①勝率） | 同（②回帰） |
|---|---|---|---|
| 0%（毎回でたらめ） | 0.783 | 80.175% | 79.625% |
| 50% | 0.696 | 73.162% | 72.925% |
| 80% | 0.478 | 63.675% | 65.225% |
| 95% | 0.389 | 58.612% | 59.85% |
| 100% | 0.416 | **50.0%** | **50.0%** |

- **いつも同じ5人で出るなら、5人の勝ち負けはまったく同じになり、チームの中の誰が強いかは勝ち負けからは分からない**（当たりは50%、作りどおり）。全体の順位の相関が0.416残るのは、チームどうしの強さの差が分かるため
- 同じ顔ぶれで出る試合が半分あると、②回帰の順位の相関は0.696、勝率では0.603で、回帰のほうが高かった。80%を超えると、どちらも大きく下がった

### 確かめ：強さの差×人数（9通り、5対5・合計、各10回、`results/sensitivity_grid.csv`）
- 1人100試合の順位の相関（②回帰）は 0.545〜0.889。強さの差が小さい（標準偏差0.15）と 0.545〜0.567、大きい（0.5）と 0.873〜0.889
- 順位の相関が0.8に届く試合数は、強さの差0.15で400試合、0.3で100〜200試合、0.5で50〜100試合だった。人数（50・100・200人）ではあまり変わらなかった
- 1人100試合で②回帰と①勝率の差は −0.011〜+0.032

## 動かし方
```
pip install -r requirements.txt
cd src && python a1073_team.py
```
1分ほどで終わります（ほかの処理と重なると2〜3分）。`data/` の2つのファイルもこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の9ファイルがバイト単位で一致した（cmp、約53秒）
- 1対1では、合計と平均の置き方が同じ値になる（同じ乱数の結果を両方に使った）
- いつも同じ顔ぶれ（100%）のとき、チームの中の当たりがちょうど50.0%になった（作りどおり）
- 「試合数を増やすと②回帰の順位の相関が上がる」は、`results/by_size_games.csv` の人数と置き方の5通り（1対1、3対3・5対5の合計と平均）のすべてで同じだった

## データ
- `data/games_example_5v5.csv`：例の1リーグ（5対5・1人50試合）の500試合。game・team_a／team_b（両チームの人の番号）・team_a_won（Aチームが勝ったか）
- `data/players_example_5v5.csv`：同じリーグの100人。player・true_skill（本当の強さ）・games（出た試合数）・winrate_pct（勝率）・reg_estimate（②回帰の見積もり）

## 注意（言えないこと）
- 架空のデータです。強さの散らばり、チームの強さの置き方（合計か平均か）、組み方は作成者が置いたもので、結果はこれで決まります。とくに、チームの人数でどれだけ分かりにくくなるかは、合計と平均のどちらを置くかで答えが大きく変わります
- 1人の強さは試合ごとに変わらず、役割の違い、味方どうしの相性、うまい人が弱い人を助けるといったことは入れていません
- 相手も味方もでたらめに組むと置きました。点数の近い人どうしを当てる組み方は入れていません（1074 で扱っています）
- 実在のゲームの点数の付け方を表すものではありません。人を比べる道具としての良し悪しも言えません
