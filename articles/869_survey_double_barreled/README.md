# 869 2つのことを1つの質問で聞くと、何を読み違えるのか？（アンケート）

「料理と接客に満足していますか」のように、2つのことを1つの質問で聞くと、「はい」と答えた人が何に満足したのかが分からなくなります。両方に満足した人だけが「はい」と答えるのか、どちらかで「はい」と答えるのか、先に書かれたほうだけで決めるのかは、人によって違うからです。**ここでは、作成者が乱数で作った架空の飲食チェーン100店（店ごとに料理と接客に満足している客の割合を作成者が置いたもの）で、客の答えの決め方を作成者が置き、1つの質問の「はい」の割合が何を表すか、改善がどれだけ見えるか、接客の悪い店を当てられるかを、料理と接客を別々に聞いた場合と比べました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A869 | 2つのことを1つの質問で聞くと、「はい」の割合は何を表すか。一方だけを改善したとき、どれだけ見えるか。チェーンの中で接客（料理）の悪い店を当てられるか | 架空の飲食チェーン100店、1店200人。店ごとに料理に満足している客の割合を55〜90%、接客に満足している客の割合を40〜85%の一様分布から置く。客ごとの料理と接客の満足（はい／いいえ）は、相関0.3の2つの正規の値を、店の割合に合うように区切って作る。「料理と接客に満足していますか」への答えの決め方は4つ：両方（両方に満足なら「はい」）、どちらか（どちらかに満足なら「はい」）、先（先に書かれた料理だけで決める）、後（後に書かれた接客だけで決める）。客ごとの決め方は、両方40%・どちらか15%・先30%・後15%と作成者が置いた（基本）。1店の例は料理80%・接客50%の店を20万人で数えた。チェーンでは、1つの質問の「はい」が低い10店を選び、本当に接客（料理）の低い10店に入っていた割合を数えた（店を作り直して300回の平均）。確かめとして、決め方の混ざり方6通り×料理と接客の相関3通り（0・0.3・0.6）を100回ずつ数えた。seed 869 | `src/a869_double_barreled.py` |

## 主な結果

### 1店の例：料理80%・接客50%の店（20万人）
| 聞き方 | 「はい」の割合 |
|---|---|
| 料理だけ聞く | 79.9% |
| 接客だけ聞く | 50.1% |
| 1つの質問：全員が「両方」で決める | 43.4% |
| 1つの質問：全員が「どちらか」で決める | 86.6% |
| 1つの質問：全員が「先（料理）」で決める | 79.9% |
| 1つの質問：全員が「後（接客）」で決める | 50.1% |
| 1つの質問：決め方の混ざり（基本）、「料理と接客」の順 | **61.8%** |
| 1つの質問：決め方の混ざり（基本）、「接客と料理」の順 | **57.3%** |

- 1つの質問の「はい」は、客の決め方で43.4〜86.6%のどこにでもなりうる。基本の混ざり方では61.8%で、料理（79.9%）とも接客（50.1%）とも違う数字だった
- 「料理と接客」を「接客と料理」に入れかえるだけで、61.8%が57.3%になった（先に書かれたほうで決める人を置いたため）
- 料理50%・接客80%の、問題が逆の店は、「料理と接客」の順で57.2%だった。問題が逆の2つの店の差は4.6ポイントしかなく、どちらの店が何に困っているかは1つの質問からは分からない

### 接客だけを50%→70%に改善したとき
| 聞き方 | 改善前 | 改善後 | 増えた分 |
|---|---|---|---|
| 接客だけ聞く | 50.1% | 70.0% | +19.9ポイント |
| 1つの質問：混ざり（基本） | 61.8% | 71.9% | **+10.1ポイント** |
| 1つの質問：全員が「両方」 | 43.4% | 59.3% | +15.8ポイント |
| 1つの質問：全員が「どちらか」 | 86.6% | 90.8% | +4.2ポイント |
| 1つの質問：全員が「先（料理）」 | 79.9% | 80.1% | +0.2ポイント |

- 接客が20ポイント良くなっても、1つの質問では基本の混ざり方で10ポイントしか増えなかった。全員が先に書かれた料理で決めると、改善はまったく見えなかった

### チェーン100店：1つの質問で低い10店を選ぶと（300回の平均）
| 選び方 | 本当に接客の低い10店に入っていた割合 | 本当に料理の低い10店に入っていた割合 |
|---|---|---|
| 1つの質問で低い10店 | **38.0%** | 34.8% |
| 接客だけ／料理だけを聞いて低い10店 | 70.1% | 64.0% |
| でたらめに選ぶ | 10% | 10% |

- 接客の悪い店に研修を、と1つの質問で10店を選ぶと、本当に接客の低い10店だったのは38.0%で、接客だけを聞いた場合（70.1%）の約半分だった。選んだ店の残りは、料理が悪い店やたまたま低く出た店だった
- 接客だけを聞いても70%にとどまったのは、1店200人の答えにも偶然の振れがあるため
- 1つの質問の「はい」が2ポイント以内で並ぶ店どうしのうち、49.3%の組は、本当に弱いほう（料理か接客か。チェーンの真ん中からの下がり方が大きいほう）が違った

### 確かめ：決め方の混ざり方と相関を変えると（接客の低い10店に当たった割合、100回の平均）
| 決め方 | 相関0 | 相関0.3 | 相関0.6 |
|---|---|---|---|
| 基本（40:15:30:15） | 36.7% | 35.1% | 37.4% |
| 全員が両方 | 44.6% | 49.0% | 54.5% |
| 全員がどちらか | 34.8% | 32.2% | 29.9% |
| 全員が先（料理） | 10.2% | 10.1% | 10.1% |
| 全員が後（接客） | 69.4% | 70.2% | 70.5% |
| 4つを同じ割合 | 40.1% | 42.4% | 42.0% |
| （参考）接客だけを聞く | 66.6〜72.4%（18通り） | | |

- **当たりの大きさは、作成者が置いた決め方の混ざり方でほぼ決まった**（10.1〜70.5%）。全員が後に書かれた接客だけで決めるなら、接客だけを聞いたのと同じになる。それ以外の5通りでは10.1〜54.5%で、接客だけを聞いた場合（66.6〜72.4%）より低かった
- 料理と接客の満足の相関を変えても、向きは変わらなかった

## 動かし方
```
pip install -r requirements.txt
cd src && python a869_double_barreled.py
```
15秒ほどで終わります。`data/stores.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の6ファイルがバイト単位で一致した（cmp、約16秒）
- 1店の例で、全員が「先（料理）」で決めると料理だけを聞いた値（79.9%）に、全員が「後（接客）」で決めると接客だけを聞いた値（50.1%）に一致することを確かめた
- 決め方の混ざり方と相関を変えた確かめは上の表と `results/sensitivity.csv`

## データ
- `data/stores.csv`：1回分の架空のチェーン100店（store・true_food・true_service（作成者が置いた満足の割合）・obs_food・obs_service（200人に別々に聞いたときの割合）・obs_double（200人に1つの質問で聞いたときの「はい」の割合、基本の混ざり方））。この1回では、1つの質問で低い10店のうち、本当に接客の低い10店は4店、料理の低い10店は3店だった

## 注意（言えないこと）
- 架空のデータです。店ごとの満足の割合、料理と接客の相関、客の答えの決め方とその混ざり方（40:15:30:15）は作成者が置いたもので、結果はこれで決まります。とくに当たりの大きさは決め方の混ざり方の写しに近く、実際の客がどの決め方をどれくらい使うかは測っていません
- 「はい／いいえ」の2つの答えで置きました。5段階で聞いた場合や、「どちらとも言えない」を選ぶ人は入れていません
- 改善の例は、接客だけが良くなり料理は変わらないと置きました
- 選択肢の並び順で答えが変わる話は関連する記事 863、質問どうしの順番の話は関連する記事 862 で扱っています。この記事の「料理と接客」を「接客と料理」にする入れかえは、1つの質問の中の言葉の順で、862・863 の順番とは別のものです
