# 202 マンション購入価格の年収倍率は、何倍まで上がったか：住宅市場動向調査

国土交通省「住宅市場動向調査」の分譲住宅（三大都市圏）について、住宅の建て方別の「住宅購入資金総額」の平均を「平均世帯年収」で割り、年収倍率を2011〜2025年度調査で並べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A202 | マンション購入価格の年収倍率は、何倍まで上がったか | 平均購入資金総額 ÷ 平均世帯年収の時系列（分譲マンション・分譲戸建て、一次取得・二次取得）、2012年度＝100の指数 | `src/a202_ratio.py` |

## 主な結果
- 分譲マンションの年収倍率は2011年度調査5.53倍、2012〜2024年度は5.20〜5.59倍の範囲で、2025年度に6.57倍と最も高くなった
- 2025年度の分譲マンションの購入資金総額は平均6,443万円（2024年度4,679万円から+37.7%）、世帯年収は981万円（+10.1%）
- 2012→2025年度で、分譲マンションの購入資金総額は+89.5%、購入世帯の平均年収は+51.7%
- 分譲戸建ては2011年度6.10倍、2025年度5.80倍で、2012〜2024年度は5.30〜5.91倍
- 2025年度の分譲マンションは、一次取得6.21倍、二次取得7.99倍。二次取得は年ごとの振れが大きい（2015年度4.42倍〜2025年度7.99倍）

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a202_ratio.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/bunjo_income_price.csv | 調査年度、項目（income＝平均世帯年収、price＝住宅購入資金総額の平均、万円）、分譲住宅計・首都圏・分譲戸建て・分譲マンション（計・一次取得・二次取得） |

- 住宅市場動向調査「経年変化比較表（分譲住宅）」：2025年度（statInfId 000040477591、2021〜2025年度）、2020年度（000032091940、2016〜2020年度）、2015年度（000031429974、2011〜2015年度）
- ブラウザで Excel を読み、「平均世帯年収」と「購入資金総額（住宅購入資金総額）」の行を書き写した。表の「集合住宅」を分譲マンション、「一戸建て」を分譲戸建てとした

## 注意
- 分譲住宅の調査は三大都市圏（首都圏・中京圏・近畿圏）が対象で、全国の値ではない
- 年収倍率は「平均購入資金 ÷ 平均年収」で、1世帯ずつの倍率の平均とは違う。2024年度からは中央値も公表されている（2025年度の分譲マンションは購入資金5,500万円）
- 調査年度は調査を行った年度で、住宅の取得はその前の年度。調べた世帯の数は限られ、特に二次取得は少ないため値が振れやすい
- 購入資金総額は自己資金と借入金の合計で、物件価格そのものとは一致しない場合がある
- 2025年度の急な上昇がどこまで続くかは、このデータだけでは分からない
