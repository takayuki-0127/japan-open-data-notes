# 988 珍しい組み合わせを後から探すと、何が見つかるのか？（確率の直感）

「木曜の夜に来た客は、デザートも買う割合が2倍」。こうした組み合わせは、データを見てから探すと、本当は何の差もなくても見つかります。調べる組み合わせが多いほど、どこかに偶然の偏りが出るからです。見つかった組み合わせについて「偶然でこれが起きる確率は1%」と計算しても、その1%は「前もってその組み合わせだけを調べると決めていたとき」の値です。**ここでは、作成者が乱数で作った架空の店の客（デザートも買うかどうかは、どの客も10%と作成者が置いたもの）で、曜日・時間帯などの値と組み合わせを後から全部調べ、どれくらい「珍しい組み合わせ」が見つかるか、その組み合わせが次の月にどうなるかを数えました。**

## 主な結果

### 1回分の月（客2,000人、`data/customers.csv`、`results/one_draw_top15.csv`）
| いちばん珍しく見えた順 | 人数 | デザートも買った割合 | 偶然で起きる確率 | 次の月の割合 |
|---|---|---|---|---|
| 木曜×夜 | 56人 | **21.43%** | 0.0114 | **9.84%** |
| 南口×カード | 361人 | 14.13% | 0.0155 | 10.89% |
| 夜×晴れ | 192人 | 15.62% | 0.0158 | 11.92% |
| 土曜×電子マネー | 74人 | 18.92% | 0.0194 | 12.68% |
| 朝×カード | 149人 | 16.11% | 0.0204 | 15.97% |

- 全体の割合は10.4%（次の月は10.1%）。調べた196個のうち、9個が「偶然で起きる確率5%未満」に見えた
- **いちばん珍しく見えた「木曜×夜」は、56人中21.43%と全体の2倍を超えたが、次の月は9.84%だった**。本当の差は置いていないので、全体の割合に戻るのが当然の結果

### 基本：客2,000人・2つの組み合わせまで（196個）・本当の差なし（1,000回、`results/reps_base.csv`）
| | 値 |
|---|---|
| 1つでも「偶然では5%未満」が見つかった月 | **99.1%** |
| 「偶然では5%未満」に見えた個数の平均 | 5.85個（196個のうち） |
| いちばん珍しい組み合わせの「偶然で起きる確率」 | 中央値0.00992（約101回に1回）、10〜90%の範囲0.00159〜0.0288 |
| いちばん珍しい組み合わせの割合 | 平均**17.54%**（10〜90%の範囲14.21〜21.34%） |
| 同じ組み合わせの次の月の割合 | 平均**10.0%**（10〜90%の範囲6.67〜13.29%） |
| 次の月も「偶然では5%未満」だった | 2.1% |
| 前もって決めた1つ（土曜×雨）が「偶然では5%未満」だった | 2.9% |
| 基準を調べた数で割ると、1つでも残った月 | 1.0% |

- **本当の差がどこにもないのに、99.1%の月で「偶然では5%未満」の組み合わせが見つかった**。いちばん珍しいものは、中央値で「約101回に1回の偶然」に見えた
- 前もって1つだけ決めておけば、「偶然では5%未満」になったのは2.9%だった（人数が整数なので5%ちょうどにはならず、少し低く出る）
- いちばん珍しい組み合わせの98.4%は、2つの項目の組み合わせだった。組み合わせは数が多く、1つあたりの人数が少ないので、割合が大きく振れる

| 客の数 | 探す広さ（調べた個数の平均） | 1つでも「5%未満」 | いちばん珍しい組の割合 | 次の月 | 基準を調べた数で割ると |

| 500人 | 3つまで（182.7個） | 90.5% | 22.16% | 10.08% | 2.0% |
| 2,000人 | 1つの項目だけ（21個） | 37.0% | 12.55% | 10.02% | 1.0% |
| 2,000人 | 2つまで（196個） | 98.0% | 17.53% | 10.27% | 0.5% |
| 2,000人 | 3つまで（713.7個） | **100.0%** | 22.64% | 10.07% | 1.0% |
| 10,000人 | 1つの項目だけ（21個） | 42.5% | 11.16% | 9.97% | 0.0% |
| 10,000人 | 2つまで（196個） | 100.0% | 13.19% | 9.92% | 2.0% |
| 10,000人 | 3つまで（943個） | 100.0% | 16.81% | 10.1% | 2.0% |

- **1つでも「偶然では5%未満」が見つかる月は、探す広さと客の数で36.5〜100%だった**。広く探すほど増え、3つの組み合わせまで探すと客2,000人以上では100%だった
- 客の数が多いと、いちばん珍しい組み合わせの割合は全体の10%に近づいた（2つまでで、500人20.72%→10,000人13.19%）。それでも「偶然では5%未満」の組み合わせは見つかった
- 次の月の割合は9通りで9.46〜10.27%と、どれも全体の10%前後に戻った
- 基準（5%）を調べた個数で割ると、1つでも残った月は0〜2.0%になった
- 2,000人・2つまでの98.0%は、基本の99.1%と同じ置き方を別の乱数で200回数えた値

## データ
- `data/customers.csv`：架空の客2,000人×2か月（month（調べた月・次の月）・customer_id・曜日・時間帯・天気・入口・支払い・会員・dessert（デザートも買ったら1））。基本の置き方なので、どの組み合わせにも本当の差はありません

## 注意（言えないこと）
- 架空のデータです。項目の数と値の数、それぞれの割合、全体の割合10%、客の数、調べる最小の人数（30人）は作成者が置いたもので、見つかる個数や珍しさはこれで決まります。調べる個数が多いほど「偶然では5%未満」が1つは出やすいことは、確率の掛け算から決まる向きです（式どおりの向き）。新しく数えたのは、この置き方での大きさ（99.1%、探す広さと人数で36.5〜100%）と、見つかった組み合わせの次の月の割合、本当の差があるときに後から探して当たる割合です
- 「偶然で起きる確率」は片側の二項検定で、その月の全体の割合と比べました。ほかの検定や、組み合わせどうしの重なりを考えた補正は比べていません
- 基準を調べた数で割る補正は、偶然の見つかりを減らしますが、本当の差（2倍）も9.0%しか残しませんでした。どの補正を使うべきかの助言はしません
- 実際の店の客の買い方を表すものではありません。曜日や天気で本当に割合が変わる場合は、ここで数えた割合とは変わります
- 関連する記事：835（上位だけを見て「成功の秘訣」を決めると何を読み違えるか）と838（伸びた投稿だけ見て「伸びる型」を決めると何が起きるか）は、結果の良いものを先に選んでから共通点を探す読み違いを扱っています。963（少ない件数の言葉の「特徴的な度合い」はなぜ極端に出るか）は、人数の少ないところほど割合が振れる仕組みを言葉で扱っています。同じ企画の982「『100万分の1の偶然』は、どれくらい起きるのか？」は、試す店や回数が多いとまれな出来事がどこかで起きること、起きたあとで何を「同じ偶然」と数えるかで確率が桁で変わることを、抽選の番号で扱っています。990「偶然の集まり（かたまり）は、どれくらい出るのか？」は、売れた時刻を見てから10分の窓を合わせると、区切りを決めておくより多くの日にかたまりが見つかることを扱っていて、後から合わせる点が同じです。981「40人の中に同じ誕生日の人がいるのは、珍しいのか？」は、「同じ日」を「1日違い以内」にゆるめるだけで見つかる割合が上がることを扱っています。この記事は、客のデータの値と組み合わせを後から調べるときに、見つかった組み合わせが次の月にどうなるか、本当の差があるときに後から探して当たるかに絞りました
