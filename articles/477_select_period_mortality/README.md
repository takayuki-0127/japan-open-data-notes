# 477 加入のときの審査の効き目を考えずに死亡率を見積もると、どれだけずれるのか？（手法の解説）

保険に入るときに健康状態の審査があると、入ったばかりの人の死亡率は、同じ年齢の全体より低くなります。この差は、年数がたつと小さくなっていきます。**加入からの年数を分けずに死亡率を見積もり、新しい契約の割合が違う集団に当てはめると、見込みの死亡数がどれだけずれるかを、架空の契約で計算しました。** 数字は、置いた効き目の強さ・続く年数・契約の続く割合で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A477 | 加入からの年数を分けない見積もりは、新しい契約が増える・減る集団でどれだけずれるか。分けるには何人分のデータが要るか | 架空の契約（加入年齢30〜59歳、契約が続く割合は年94%）。もとの死亡率は公表の生命表。加入1〜5年目の死亡率を0.50・0.65・0.78・0.88・0.95倍に置く。分け方4通りで見積もり、6つの集団に当てはめる。揺れは死亡数をポアソン分布で2,000回 | `src/a477_select.py` |

## 置いたこと（架空）
- 審査の効き目：加入1年目の死亡率は審査なしの水準の0.50倍、2年目0.65、3年目0.78、4年目0.88、5年目0.95、6年目から1.00倍（説明用に置いた値）
- 集団のちがいは、新しい契約の数の増え方だけ（年+20%・+5%・一定・−10%・新しい契約を止めて5年・10年）
- 見積もり：実際の死亡数÷（審査の効き目なしの表での見込み）を、加入からの年数の組ごとに出す。分け方は、分けない／2つ／3つ／1年ごと

## 主な結果
### 集団ごとの姿
| 集団 | 加入5年未満の契約の割合 | 実際の死亡数÷効き目なしの表の見込み |
|---|---|---|
| 新しい契約が年20%ずつ増えている | 71% | 85.1% |
| 年5%ずつ増えている | 44% | 95.1% |
| 新しい契約の数が一定 | 32% | 97.6% |
| 年10%ずつ減っている | 9% | 99.7% |
| 新しい契約を止めて5年・10年 | 0% | 100.0% |

### 「一定」の集団で見積もって当てはめたときの、見込みの死亡数のずれ（%、揺れなし）
| 当てはめる集団 | 分けない | 2つに分ける | 3つに分ける | 1年ごと |
|---|---|---|---|---|
| 年20%ずつ増えている | **+14.7** | +2.6 | +0.5 | 0 |
| 年5%ずつ増えている | +2.6 | +0.2 | +0.1 | 0 |
| 年10%ずつ減っている | −2.1 | 0 | 0 | 0 |
| 新しい契約を止めて5年・10年 | **−2.4** | 0 | 0 | 0 |

- 見積もる集団を変えると：増えている集団（年+20%）で見積もって、新しい契約を止めた集団に当てはめると−14.9%。逆向きは+17.5%（`results/bias_cross_table.csv`）
- 新しい契約を止めたあとのずれ：1年後−0.9%、3年後−2.0%、5年後から−2.4%で止まる
- 効き目の置き方を変えると（年+20%の集団／止めて10年の集団）：弱い（1年目0.8倍）+4.6／−0.8%、強い（1年目0.3倍）+21.8／−3.3%、10年かけて戻る +27.5／−5.7%

### 揺れを入れたときのずれ（RMSE、%。2,000回）
| 見積もりに使う延べ人数（死亡数の見込み） | 当てはめ先：年20%増 分けない | 3つに分ける | 1年ごと | 当てはめ先：止めて5年 分けない | 1年ごと |
|---|---|---|---|---|---|
| 2千人年（15人） | 33.1 | 45.9 | 45.5 | 25.1 | 26.6 |
| 1万人年（75人） | 19.8 | 20.2 | 20.2 | 11.3 | 12.0 |
| 5万人年（374人） | 15.7 | 9.3 | 9.2 | 5.7 | 5.5 |
| 20万人年（1,494人） | 15.0 | 4.6 | 4.6 | 3.5 | 2.7 |
| 100万人年（7,472人） | 14.7 | 2.1 | 2.0 | 2.7 | 1.2 |

全部の数字は `results/` の6つの CSV と `main.json` にあります。

## 動かし方
```
pip install -r requirements.txt
cd src && python a477_select.py      # 約1分
```
`data/standard_qx_2024_male.csv`（もとの死亡率）を読み、`data/example_portfolio_50000.csv`、`results/` の7ファイル、`figures/` の3枚を作ります。

## 確かめたこと
- 空のフォルダで計算し直し、data・results・figures が一致した
- 見積もった集団と同じ集団に当てはめると、どの分け方でもずれは0
- 1年ごとに分けると、揺れなしではどの集団でもずれは0

## 注意（言えないこと）
- 架空の契約です。効き目の強さ（1年目0.5倍）と続く年数（5年）は説明用に置いた値で、実際の保険の数字ではありません
- 集団のちがいは新しい契約の割合だけにしました。実際は、商品・年齢・加入の経路なども違います
- 解約する人の健康状態の偏り、年ごとの死亡率の変化は入れていません
- 引受の基準や保険料をどうすべきかを言うものではありません。本物の保険データでは確かめていません
- 小さな集団の死亡率をなめらかにする方法は348、実際の死亡数と見込みの比の振れは349で扱いました
