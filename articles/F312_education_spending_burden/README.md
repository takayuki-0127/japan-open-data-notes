# F312 子育て世帯の教育費の負担は、重くなったのか？ 40代の世帯では消費支出に占める割合が9.4%→7.9%に下がったが、40〜50代でまとめると7.0%→7.9%に上がった

## 結論（先に）
- 世帯主が40代の世帯で、教育費が消費支出に占める割合は、2002〜04年平均の9.4%から2023〜25年平均の7.9%に下がりました（−1.5ポイント）。18歳未満の人1人当たりの実質の教育費も −6.5（対数差×100）でした。40代だけを見ると「重くなった」とは言えません。
- 一方で50代の世帯では、5.0%から7.8%に上がりました。50代の世帯の18歳未満の人数は0.32人から0.47人に増えていて、子育ての時期が遅くなった形です。
- 問い直し：40代と50代の世帯をまとめると、教育費の割合は7.0%から7.9%（+0.9ポイント）、18歳未満1人当たりの実質の教育費は +13.4 になりました。どの年齢を「子育て世帯」と見るかで答えが変わります。
- 中身では、40代の世帯の教育費に占める補習教育（塾など）の割合が27.6%から31.5%に上がりました。授業料等は2018〜19年から2021〜22年に −9.4 下がり、制度の変更の時期と重なります。

## 問い
子育ての費用、とくに教育費が重くなった、とよく言われます。家計の統計を読む人や教育サービスの担当の人にとっては、「どの世帯で」「何が」重くなったのかが知りたいところです。家計調査で、子育ての中心の年齢の世帯の教育費は、消費支出の中で重くなったのか。子どもの数が減った分をそろえるとどうか。物価の動きを除くとどうか。教育費の中身はどう変わったか。教育の制度の良し悪しは扱いません。

## データ（出典）

- 総務省「消費者物価指数」2025年基準 中分類「教育」「授業料等」の年平均。
- URL と取得日は data/raw/SOURCES.md にあります。

## 事前の計画
[PLAN.md](PLAN.md) に、年齢別の集計をする前に仮説と外れの基準を書きました。コードを確かめるときに2003年の「平均」の列の値を見たことは、PLAN.md に開示しています。

| 仮説（40代の世帯、2002〜04年→2023〜25年） | 基準 | 結果 | 判定 |
|---|---|---|---|
| H1 教育費の割合が上がった | +0.5ポイント以上 | 9.4%→7.9%（−1.5） | 外れ |
| H2 18歳未満1人当たりの実質の教育費が増えた | +10 以上 | −6.5 | 外れ |
| H3 教育費に占める補習教育の割合が上がった | +3ポイント以上 | 27.6%→31.5%（+3.9） | 支持 |
| H4 授業料等が2018〜19年→2021〜22年に下がった | −5 以下 | −9.4 | 支持 |

## やったこと
1. 年×世帯主の年齢（6つ）×項目の表を作りました。
2. 3年平均どうしで、教育費の割合（ポイント）と金額の変化（対数差×100）を比べました。
3. 18歳未満1人当たり ＝ 教育費 ÷ 18歳未満人員（世帯の平均）、実質 ＝ 名目 ÷ CPI 教育です。
4. 頑健性を5つ、問い直しを1つ足しました。

## 分かったこと
### 40代では下がり、50代では上がった（図1）
40代の世帯の教育費は、年38.9万円から31.6万円に減りました（名目）。18歳未満の人数は1.55人から1.49人で、ほとんど変わっていません。50代の世帯の教育費は21.1万円から33.7万円に増えました。30代の世帯は4.2%から2.9%に下がり、とくに2020年に大きく下がっています。

### 教育費の山が、40代から50代へ広がった（図2）
2002〜04年は40代に教育費の山がありましたが、2023〜25年は40代と50代がほぼ同じ高さ（7.9%と7.8%）になりました。50代の世帯の18歳未満の人数が増えたことと合わせると、子どもを持つ時期が遅くなったことと整合します（推測。出生の時期そのものはこの表では見ていません）。

### 授業料等と塾など（図3）
40代の世帯の授業料等は、2018〜19年から2021〜22年に −9.4 下がりました。CPI の授業料等も同じ期間に −15.0 下がっています。2020年4月の高等学校等就学支援金の拡充の時期と重なりますが、この表だけでは原因は分けられません。30代の世帯では −66.0 と大きく、2019年10月の幼児教育・保育の無償化の時期と重なります。補習教育の金額はほぼ横ばいで、授業料等が減った分、教育費の中での割合が上がりました。

## 問い直し（結果を見てから足した）
H1・H2 が外れ、50代では逆に上がっていたのを見て、「子育ての時期が遅くなったので、40代だけを見ると軽く見えるのではないか」と考え直しました。40代と50代の世帯を、世帯数分布で重みづけてまとめました（src/03b_requestion.py、図4）。

| | 2002〜04年 | 2023〜25年 | 変化 |
|---|---|---|---|
| 教育費の割合（40〜50代） | 7.0% | 7.9% | +0.9ポイント |
| 18歳未満1人当たりの実質の教育費（40〜50代） | | | +13.4 |
| 同（40代だけ） | | | −6.5 |

まとめると、負担は少し重くなった形になります。ただし50代の世帯の教育費には、18歳以上の大学生などの分が多く含まれるので、「18歳未満1人当たり」は大きめに出ます。

## 頑健性
| 確かめたこと | H1（ポイント） | H2 | H3（ポイント） | H4 |
|---|---|---|---|---|
| 本文（40代） | −1.5 | −6.5 | +3.9 | −9.4 |
| R1 30代の世帯 | −1.3 | −29.9 | +6.2 | −66.0 |
| R2 名目で H2 | | −16.9 | | |
| R3 始点を2005〜07年 | −1.8 | −7.2 | +3.6 | |
| R4 世帯人員1人当たり（実質） | | −2.5 | | |
| R5 50代の世帯 | +2.8 | +18.9 | +2.3 | +15.1 |

40代と30代では判定は変わりませんでした。50代では逆の向きで、年齢の区切り方が結論を左右します。

## 言えないこと
- 二人以上の世帯の平均で、子どものいない世帯も含みます。年齢で子育て世帯に近づけているだけです。
- 消費支出に対する割合で、収入に対する負担ではありません（この表には収入がありません）。
- 仕送りや奨学金の返済は教育費に入りません。下宿する大学生への仕送りが増えていても、この数字には出ません。
- 無償化で公費が払った分は、家計の教育費に入りません。CPI 教育も無償化で下がった（2002〜04年→2023〜25年で −10.4）ので、実質の値はその分大きめに出ます。
- 「子育ての時期が遅くなった」は、世帯主の年齢別の18歳未満人員からの推測です。

## 仕事で使うなら
- 「子育て世帯の教育費」を年齢で切って示すときは、40代だけか、40〜50代か、で向きが変わることを書き添えると誤解が減ります。
- 授業料等と補習教育は動き方が違います。教育費の合計だけでなく、中身の内訳も並べると読み違いが減ります。
