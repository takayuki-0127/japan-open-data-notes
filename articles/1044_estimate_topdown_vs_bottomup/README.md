# 1044 全体から割合で割っていく概算と、1件ずつ積み上げる概算は、どれだけ食い違うのか？（概算）

ある町で1年に何件の需要があるかを概算するとき、よく使うやり方は2つあります。1つは、町の世帯数から「持っている割合」「使う割合」「回数」と割合を掛けて絞っていくやり方（ここでは「割っていく概算」）。もう1つは、町にある店を1軒ずつ数え、1日の件数に営業日数を掛けて足していくやり方（「積み上げる概算」）です。2つを出して比べると、たいてい食い違います。その食い違いは、見込みの誤差から来るのか、2つが数えているものの違いから来るのか。**ここでは、作成者が乱数で作った架空のA町（12,000世帯）の自転車の修理の件数（正しい件数を作成者が置いたもの）で、①割っていく概算と②積み上げる概算を4,000回ずつ作り、それぞれ正しい件数の何倍だったか、①÷②が何倍離れたかを数えました。食い違いのしくみを1つずつ外した確かめと、置き方を変えた27通りの確かめも行いました。**

概算の外れは、差ではなく比（何倍か）で数えています。掛け算でつなぐ要素の数と外れやすさは同じ企画の関連する記事 1041、区分に分けて足すときの重なりと抜けは 1045、何人かの概算のまとめ方は 1046、要素のどれを実際に数えて確かめると外れが縮むかは 1051 で扱っています。この記事は、2つのやり方の食い違いの大きさと、その中身の切り分けに絞ります。

## 主な結果

### 2つの概算は、正しい件数の何倍だったか（基本、4,000回）
| | ①割っていく | ②積み上げる |
|---|---|---|
| 中央値 | 1.0倍 | 0.85倍 |
| 10〜90%の範囲 | 0.46〜2.2倍 | 0.57〜1.18倍 |
| 1.5倍以内（0.67〜1.5倍）に入った回 | 49.15% | 77.75% |
| 2倍以上外れた回 | 25.2% | 4.95% |

- ①は中央値では当たっていたが、幅が広く、4回に1回は2倍以上外れた。①の対数の標準偏差は0.6066で、3つの見込みの誤差を足し合わせた式の値（√(0.05²＋3×0.35²)＝0.6083）どおり。1標準偏差で1.84倍の外れになる
- ②は幅が狭いが、中央値は0.85倍と下に寄った。②が数えているのは「町の店がこなす件数」で、その正しい件数に対する比は式どおり 1−0.25＋0.12＝0.87倍（乱数の中央値0.8701）。店ごとに1日だけ数える振れが、さらに少し下に寄せた
- 正しい件数により近かったのは、②が68.85%の回。ただし、②の近さは町の外とのやり取りの置き方しだいで、27通りでは35.45〜89.75%と動いた

### ①÷②（2つの概算の食い違い）
| | 値 |
|---|---|
| **①÷②の中央値** | **1.21倍** |
| ①÷②の10〜90%の範囲 | 0.52〜2.86倍 |
| 1.5倍以上離れた回 | 56.27% |
| **2倍以上離れた回** | **31.65%** |
| 町の外とのやり取りだけで生まれる比（式） | 1.15倍 |

- 2つの概算は、3回に1回くらい2倍以上離れた。中央値の1.21倍は、町の外とのやり取りの式の値（1÷0.87＝1.15倍）に近い

### 食い違いのしくみを1つずつ外すと（`results/parts.csv`、4,000回）
| | ①÷②の中央値 | 1.5倍以上離れた回 | 2倍以上離れた回 |
|---|---|---|---|
| 基本 | 1.21倍 | 56.27% | 31.65% |
| 町の外とのやり取りなし | 1.04倍 | 53.2% | 29.48% |
| ②を300日すべて数える | 1.14倍 | 51.73% | 27.27% |
| ①の見込みが正しい（誤差0） | 1.18倍 | 22.15% | 5.38% |

- **2倍以上の食い違いの多くは、①の見込みの誤差から来た**。①の誤差を0にすると、2倍以上離れた回は31.65%から5.38%に減った。町の外とのやり取りをなくしても29.48%、②を300日すべて数えても27.27%で、あまり減らなかった
- 一方、①÷②の中央値（向きのずれ）を決めていたのは町の外とのやり取りで、なくすと1.04倍になった

### 町の外とのやり取りを割り戻すと
- ②を町の外とのやり取りの割合で割り戻すと、中央値は0.95倍になったが、割り戻す割合も見込みなので幅は0.54〜1.68倍に広がった。それでも①より正しい件数に近かったのは58.85%の回（27通りで48.8〜68.7%）
- ①と割り戻した②の幾何平均（掛けて平方根をとる）は、71.58%の回で1.5倍以内に入った

### 置き方を変えた27通り（`results/grid.csv`、各2,000回）
- 2倍以上離れた回は6.6〜49.7%。①の誤差が0.2の9通りでは25.25%以下、0.5の9通りでは42.05%以上で、①の見込みの誤差でほぼ決まった
- ①÷②の中央値は0.9〜1.5倍。町の外の店に出す割合が0%の9通りでは0.9〜0.94倍（式で1÷1.12＝0.89倍）、40%の9通りでは1.37〜1.5倍（式で1÷0.72＝1.39倍）と、向きは町の外とのやり取りの式でほぼ決まった
- ②で数える日数を1日から10日に増やすと、①の誤差0.2・町の外に出す割合25%の通りでは2倍以上離れた回が16.15%から6.6%に減ったが、①の誤差0.35では30.65%から27.55%とあまり減らなかった

## データ
- `data/towns.csv`：架空のA町を200通り（town_id・households（世帯数）・owners（自転車を持つ世帯）・repairers（1年に修理に出した世帯）・repairs（1年の修理の件数＝正しい件数））
- `data/trials_base.csv`：基本の置き方の4,000回（top（①÷正しい件数）・bottom（②÷正しい件数）・vin（町の店がこなす件数÷正しい件数）・bottom_adj（割り戻した②÷正しい件数））
- `results/a1044_main.json`：主な結果すべて（`headline` に本文で使った丸めた値、`formula` に式の値）
- `results/parts.csv`：しくみを1つずつ外した確かめ
- `results/grid.csv`：27通りの確かめ

## 注意（言えないこと）
- 架空のデータです。世帯数、持つ割合、修理の回数の分布、見込みの誤差の大きさ、店の数と件数の散らばり、町の外とのやり取りの割合は作成者が置いたもので、結果はこれで決まります。2倍以上離れた回は、置き方で6.6〜49.7%と動きました。実在の町や店の数字ではありません
- ①の見込みの誤差は、対数で上下に同じだけ（正しい値を中心に）振れると置きました。見込みがそろって上や下に偏る場合（たとえば身近な人の様子から割合を見込む）は、①の中央値も1倍からずれます（推測）
- ②は町の店をすべて見つけられると置きました。店の見落としがあると②はさらに下に寄ります。区分の抜けの話は 1045 で扱っています
- 「どちらのやり方を使うべきか」の助言ではありません。2つが食い違ったときに、その中身を切り分けて読むための数え方です
