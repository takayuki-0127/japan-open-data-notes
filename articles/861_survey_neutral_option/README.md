# 861 「どちらでもない」を入れると、賛成の割合は何ポイント動くのか？（アンケート）

アンケートで賛否を聞くとき、「賛成・反対」の2択にするか、「どちらでもない」を加えた3択にするかで、賛成の割合は変わります。同じ人たちに聞いても、3択では賛成が大きく減ったように見えます。**ここでは、作成者が乱数で作った架空の社員アンケート（社員1,000人の「本当の気持ち」を作成者が置いたもの）で、半分に2択・半分に3択で聞き、賛成の割合が何ポイント動くか、「どちらでもない」を選んだのはどんな人かを数えました。**

段階の数（3・5・7段階）で満足の割合が変わる話は、関連する記事 868 で扱っています。この記事は「真ん中の選択肢があるかないか」に絞ります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A861 | 「どちらでもない」を入れると、賛成の割合は何ポイント動くか。「どちらでもない」を選んだのはどんな人か。どちらでもないを除いて割ると元に戻るか | 架空の会社の社員1,000人に「会議を午前中にまとめる案」への賛否を聞く。社員ごとの本当の気持ち x は平均0.2・標準偏差1の正規分布（0より大きいと賛成寄り。作成者が置いた正解は「x>0 の人の割合」）。答えるときのぶれ e は平均0・標準偏差0.5の正規分布で、y=x+e で答えが決まる。2択（500人）は y+a>0 なら賛成（a は2択で迷った人が賛成に寄るくせ、基本は0）。3択（別の500人）は y の絶対値が t 未満なら「どちらでもない」、t 以上なら賛成、−t 以下なら反対（t は迷う幅、基本は0.5）。調査を作り直して2,000回。確かめとして、t を0.25〜1.0、全体の傾き（x の平均）を−0.2〜0.5、a を0と0.2に変えた32通りを各500回数えた。seed 861 | `src/a861_neutral_option.py` |

## 主な結果

### 4つの数え方の賛成の割合（2,000回の平均）
| 数え方 | 賛成の割合 | 10〜90%の範囲 |
|---|---|---|
| 本当に賛成寄りの人（作成者が置いた正解、x>0） | 57.9% | 55.9〜60.0% |
| 2択の「賛成」 | 57.1% | 54.2〜60.0% |
| 3択の「賛成」（3択の全員が分母） | **39.4%** | 36.6〜42.2% |
| 3択の「賛成」（どちらでもないを除いて割る） | 59.8% | 56.4〜63.1% |

- 3択では「どちらでもない」が34.1%、反対が26.5%だった
- 2択の賛成から3択の賛成を引くと、**17.6ポイント**（10〜90%の範囲で13.6〜21.6ポイント）下がった
- 3択の賛成は2,000回すべてで50%を下回った。2択の賛成は2,000回の99.9%で50%を上回った。同じ社員でも、聞き方だけで「過半数が賛成」にも「賛成は4割」にも見える
- どちらでもないを除いて割ると59.8%で、2択の57.1%より2.7ポイント高くなった（10〜90%の範囲で−1.7〜+7.2ポイント）。多いほうの側（この置き方では賛成）が大きく見える向きにずれた

### 「どちらでもない」を選んだのはどんな人か（同じ置き方で別に20万人を作り、3択で答えさせて数えた）
| | 値 |
|---|---|
| 「どちらでもない」を選んだ割合 | 33.8% |
| そのうち本当の気持ちが−0.5〜0.5の人 | 67.7%（ほかの答えの人では21.9%） |
| そのうち本当は賛成寄り（x>0）の人 | 53.7% |
| そのうち、2択で聞かれたら賛成と答える人 | 52.0% |

- 「どちらでもない」は、本当の気持ちが0の近くの人に集まった。ただし半分強は賛成寄りだった
- 下がったポイントは「どちらでもないの割合 33.8% × その人たちが2択で賛成に回る割合 52.0% = 17.6ポイント」で説明できた。この置き方では、下がる幅はほぼこの掛け算で決まる

### 確かめ：迷う幅・全体の傾き・2択のくせを変えると（32通り、各500回、`results/robustness.csv`）
| 迷う幅 t（全体の傾き0.2・くせなし） | どちらでもないの割合 | 2択の賛成 − 3択の賛成 |
|---|---|---|
| 0.25 | 17.5% | 8.8ポイント |
| 0.5（基本） | 34.0% | 17.7ポイント |
| 0.75 | 49.3% | 26.1ポイント |
| 1.0 | 62.0% | 33.2ポイント |

- 下がる幅は、迷う幅 t の置き方でほぼ決まった。くせなしの16通りで8.5〜34.5ポイント、2択で賛成に寄るくせ（a=0.2）を入れた16通りも合わせると8.5〜40.5ポイントだった
- 全体の傾きを−0.2〜0.5に変えても（t=0.5・くせなし）、下がる幅は16.4〜17.7ポイントとほとんど動かなかった
- どちらでもないを除いて割ったときのずれは、くせなしでは多いほうの側に寄る向きが全体の傾きの符号どおりに出た（傾き−0.2で−2.7、0で+0.1、0.2で+2.7、0.5で+5.4ポイント）
- ただし、2択で賛成に寄るくせ（a=0.2）を置くと、2択の賛成が64.0%にふくらみ、どちらでもないを除いた59.9%のほうが正解の58.0%に近くなった。どちらの数え方が正解に近いかは、置いたくせしだいで入れかわる

### 1回分の調査（data/respondents.csv）
- 正解59.2%、2択の賛成56.8%、3択の賛成37.2%、どちらでもない34.6%、どちらでもないを除くと56.9%だった

- 迷う幅 t を変えると下がる幅は8.8〜33.2ポイントと大きく動いた（上の表）。「18ポイント」はこの置き方での値

## データ
- `data/respondents.csv`：1回分の架空の社員1,000人。id・form（2択／3択）・true_lean（本当の気持ち x）・answer（答え）

## 注意（言えないこと）
- 架空のデータです。本当の気持ちの分布、答えるときのぶれ、迷う幅、2択のくせは作成者が置いたもので、結果はこれで決まります。とくに「何ポイント動くか」は、迷う幅（どちらでもないを選ぶ人の多さ）の置き方で9〜35ポイント（くせを入れると最大40ポイント）動きます
- 正解は「本当の気持ちが0より大きい人の割合」と作成者が決めたものです。2択の賛成が正解に近いのは、ぶれを左右対称に置き、2択のくせを0と置いたからです
- 「どちらでもない」を選ぶ理由は、ここでは「気持ちが0に近い」ことだけにしました。考えるのが面倒で真ん中を選ぶ人、質問の意味が分からない人、答えたくない人は入れていません
- 実際の人の答え方を測った実験ではありません。実際に何ポイント動くかは、質問の内容と答える人で変わります
- どちらの聞き方がよいかは、ここでは言えません。賛否のはっきりした人の割合を知りたいか、迷っている人の多さを知りたいかで変わります
