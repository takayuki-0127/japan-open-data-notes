# 1255 表紙を変えた前後の売れ方を比べると、発売からの日数で自然に減る分はどうまざるのか？（電子書籍）

電子書籍の表紙を変えたあと、「変える前の4週間」と「変えた後の4週間」の売れ方を比べて、表紙の効き目を読むことがあります。けれども、本の売れ方は発売の直後が高く、日数とともに自然に下がっていきます。前後をそのまま比べると、この自然に減る分が効き目にまざります。さらに、売れ方が落ちたのを見て表紙を変えると、変える日の選び方そのものが前後の差を作ります。**ここでは、作成者が置いた架空の電子書籍（発売からの日数で売れ方が下がる形・数週間続く売れ方の波・表紙の本当の効き目を作成者が決め、1日に売れた冊数を乱数で作ったもの）で、表紙を「決めた日に変える」ときと「売れ方が落ちた日に変える」ときに、4つの読み方で効き目がどう見えるかを、本当の効き目（+10%と0%）と比べました。減り方の速さと前後の日数を変えた18通りで確かめました。**

例の本と売れ方は架空のもので、実在の販売サイトの数字は使っていません。表紙の作り方や変えるかどうかの助言をする記事ではありません。

関連する記事：377「季節のあるデータで「施策の前後」を比べると、効果0でもどれだけ差が出るのか」は、季節の上下が前後の比べにまざることを扱っています。919「改善の前後で不良率を比べるとき、何か月見ればよいのか？」は、月ごとの振れの中で前後の差を見つけるのに要る期間を扱っています。830「2年目のジンクスは、偶然だけで起きるのか？」は、たまたま良かった次は下がって見える（平均への回帰）仕組みを扱っています。1249「新しい本を出したあと、シリーズの前の本の売れ方がどれだけ押し上げられたかは分かるのか？」は、新しい本を出した前後で前の本の売れ方を比べるときに、前の本がもともと減っていく分と季節の山がまざることを扱っています。この記事は、発売からの日数で下がっていく売れ方と、変える日の選び方に絞ります。

## 主な結果

### 基本の置き方（減り方の日数40日、前後28日ずつ、`results/base_methods.csv`）
| 読み方 | 決めた日・効き目+10% | 決めた日・効き目0% | 落ちた日・効き目+10% | 落ちた日・効き目0% |
|---|---|---|---|---|
| ① 前後をそのまま比べる | **−6.85%** | −16.24% | **−26.32%** | −33.0% |
| ② 変えていない本（同じ日数）と比べる | +11.66% | −1.51% | +0.34% | −10.39% |
| ③ 前の減り方を延ばして見込む | +18.24% | +4.97% | +72.28% | +56.91% |
| ④ 同じ決まりで日を選んだ変えていない本と比べる | **+10.24%** | −0.63% | **+10.66%** | +0.81% |
| （参考）変えていない本の同じ日数の前後 | −16.58% | −14.95% | −26.57% | −25.23% |

- **本当は+10%上がったのに、決めた日に変えた本を前後28日でそのまま比べると−6.85%と、下がって見えた**。変えていない本も同じ日数の前後で−16.58%下がっていて、その自然に減る分がまざった。1冊ずつ見ると、後ろの28日のほうが少なかった本が52.15%あった
- 決めた日に変えるときは、変えていない本の同じ日数の前後で割る ② で+11.66%、④ で+10.24%と、本当の+10%に近づいた
- **落ちた日に変えると、① は−26.32%、② も+0.34%と、本当の+10%から離れた**。④ だけが+10.66%だった。落ちた日に変えた本の変えた日は、発売から中央値49日目と早く、減り方の急なところだった
- ③ 前の28日の減り方を延ばす読み方は、+18.24%（決めた日）・+72.28%（落ちた日）と上ずれした。売れ方は底に近づくほど減り方がゆるむのに、直線はそのまま下がり続けるため（式どおりの向き）。落ちた日に変えた本では、前の28日に落ちる前の山が入り、急な下り坂が延ばされた

### 落ちた日に変えると、② がなぜずれるか（`results/no_wave_check.csv`）
| | 波あり（基本） | 波0 |
|---|---|---|
| ② 効き目+10% | +0.34% | +8.68% |
| ② 効き目0% | −10.39% | −1.55% |
| ④ 効き目+10% | +10.66% | +10.26% |
| ① 効き目+10% | −26.32% | −19.79% |

- 波を0にすると、② のずれはほぼ消えた。決まりは「直近14日がその前の14日の7割を初めて下回った日」なので、**その前の14日が波の山だった本が選ばれ、変える前の28日に山の分が入る**。同じ発売からの日数の、変えていない本と比べても、この山は消えない
- 図 `a1255_aligned_drop.png` の変えた本の線で、変える15日前の1日が高く、前の日が低いのは、決まりを「初めて」満たした日を選ぶためで、決まりの作りどおり
- 選ばれた本の減り方の日数の中央値は40.24日で、全体（40日）と同じだった。減り方の速い本が選ばれたわけではなかった

### 確かめ：36通り（`results/grid.csv`、`results/a1255_main.json` の `grid_summary`）
- **④ は36通りすべてで本当の効き目から3ポイント以内（+10%のとき7.69〜12.01%、0%のとき−1.36〜2.94%）**。② は36通りのうち19通りで3ポイント以内、③ は4通り、① は0通りだった
- ① は、効き目+10%のとき決めた日で−17.66〜+3.81%、落ちた日で−36.25〜+3.7%だった。18通りのうち13通りで0%を下回り、「表紙を変えたら下がった」と見えた
- ① のずれは前後の日数が長いほど大きく、効き目0%・決めた日で、14日ずつ −3.27〜−9.03%、42日ずつ −15.7〜−23.64%だった
- 落ちた日に変えて前後14日ずつで比べると、① は−0.92〜+3.7%（効き目+10%）。前の14日は決まりの「直近14日」そのもので、落ちた後の低いところだけが前に入るため、落ちる前の山は入らない
- ② は、落ちた日に変えたとき、効き目+10%で−2.92〜+17.84%と、前後の日数で上にも下にも外れた

## 注意（言えないこと）
- 架空のデータです。売れ方の下がり方、波、表紙の効き目、変える日の決まりは作成者が置いたもので、ずれの大きさはこれで決まります
- 「④ が36通りで当たる」のは、変えていない本の売れ方の下がり方と波を、変えた本と同じ分布に置いたためです（作りどおり）。実際には、表紙を変える本と変えない本で、もとの売れ方が違うことがあり、そのときは ④ もずれます
- 表紙のほかに、同じ時期に売れ方を動かすこと（新しい巻・値段・季節）は入れていません
- 表紙の効き目は、変えた日から同じ割合で続くと置きました。だんだん効く・だんだん消える形は入れていません
- 表紙を変えるとよいかどうか、いつ変えるとよいかは扱っていません
