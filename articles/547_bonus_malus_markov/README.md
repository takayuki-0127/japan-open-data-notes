# 547 自動車保険のような等級制度で、等級の分布が落ち着くまでに何年かかり、平均の割引率はどこに落ち着くのか（手法の解説・保険数理）

自動車保険のような等級制度では、事故がなければ等級が上がって割引が大きくなり、事故があると下がります。新しく入った人が多い集団と、長く続けている人が多い集団では、等級の分布も平均の割引率も違います。**ここでは、架空の20等級の制度（等級6で入り、事故なしで1つ上がり、事故1件で3つ下がる）をマルコフ連鎖として、入ってから等級の分布が落ち着くまでの年数、落ち着いたときの平均の割引率、事故率の違う人の差を数えました。** 等級表・割引率・事故率はすべて作成者が置いた架空のもので、実在の保険の等級表ではありません。数字は置いた制度と事故率で決まります。

## 主な結果
- **落ち着くまでの年数（分布の差が5%を切る年）**：事故率 0.03件/年で 22年、0.07件/年で 30年、0.15件/年で 50年、0.20件/年で 61年（1%を切るのは 26・38・71・92年）
- **定常での平均の割引率**（人ごとのばらつきなし）：0.03件/年で 69.0%、0.07件/年で 66.9%、0.15件/年で 58.2%、0.20件/年で 45.9%。0.07件/年では 77% の人が最上位の等級20にいる
- **入って1年目・10年目の平均の割引率**（0.07件/年）：3.6%・36.3%。定常の 66.9% とは大きく違う
- **事故率のばらつき**：平均の事故率が同じでも、ばらつきが大きいと定常の平均の割引率は変わる（0.15件/年で 変動係数0 58.2%、0.5 53.5%、1.0 50.6%）
- **事故率の低い人と高い人**（平均0.07件/年・変動係数1.0の集団の下位25%と上位25%）：事故率の平均は 0.0096件/年 と 0.167件/年で **17.4倍** 違うが、定常の平均の割引率は 69.7% と 51.5%、割引後の水準（1−割引率）の比は **1.60倍**。平均の等級は 19.9 と 16.3
- **乱数での確かめ**：10万人を動かした平均の割引率は 10年目 37.0%（計算 37.0%）、40年目 63.2%（計算 63.2%）

## 注意（言えないこと）
- 架空の等級制度。実在の保険会社の等級表・割引率・保険料ではない
- 保険料や料率の決め方を勧めるものではない。「この制度と事故率なら、分布はこう動く」を計算したもの
- 事故率は人ごとに一定で、年によって変わらないと置いた。事故があっても保険を使わない（等級を守るために自分で払う）動き、途中で入る人・やめる人、等級の引き継ぎは入れていない
- 割引後の水準の比は、事故の大きさ（1件あたりの損害）を同じと置いた場合の目安
