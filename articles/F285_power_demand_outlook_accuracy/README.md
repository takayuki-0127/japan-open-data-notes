# F285 エネルギー基本計画の電力需要の見通しは、過去にどれだけ当たったか？（精選モード B. 白書・審議会 Q20）

## 問い
国の長期エネルギー需給見通し・エネルギー基本計画は、電力需要（または発電電力量）の数字を何年も先まで置く。2025年の第7次は、データセンターや半導体工場で2040年度に需要が増える見通しを示した。では、過去の見通しはどれくらい当たったのか。外れは先の年ほど大きいのか。省エネを強く見込んだケースのほうが当たったのか。外れたなら、それは経済成長の見込みからか、GDPあたりの電力（原単位）の見込みからか。

## 手法
- 見通しごとに定義（電気事業用か、自家発込みか、需要か発電量か）が違うので、水準ではなく伸びで比べる。
  - 見通しの伸び＝目標年の値÷資料の基準年の値。実績の伸び＝同じ定義の実績系列の目標年÷基準年。
  - ずれ＝log（見通しの伸び）−log（実績の伸び）を％に直したもの（＋は見通しが多すぎ）。
- 目標年がまだの見通しは、基準年から目標年まで一定の率で進む道筋を引き、2024年（度）の実績と比べた（途中のずれ）。
- 実績（主）は見通しの定義に合わせた。
  - 電力需要の見通し → 年度の電力需要系列。
  - 電気事業用の発電電力量の見通し（2001・2004）→ 電事連の「電気事業者 計」の発電電力量（年度、2001〜2010）。この系列は2001年度からなので、基準年（2000年度）の代わりに2001年度を起点にし、見通しの伸びも同じ年数分（道筋の上で）に直した。
  - それ以外の発電電力量の見通し → OWID の暦年の発電電力量（自家発込み）。
  - 2008 の見通しは基準年（2005年度）の値が約9,845億kWhで、電気事業者計の実績（9,691）に近く、自家発込みの総発電（11,579）とは離れている。電気事業用の定義の可能性がある（推測）。電気事業者の系列が2010年度で切れるため、主は総発電のままとし、2010年度までを電気事業者の系列で比べた値も載せた。
- 先の長さ＝比べる年−基準年。

## 頑健性
1. 1年あたりのずれ：先の長さとの順位相関 0.50。2008 現状固定 2.6%/年、2015 対策前 2.2%/年が大きく、2001・2004 は1%/年以内。
2. 目標年の前後1年を含む3年の平均で比べる：H1 支持（4/4、1998 +18.4%、2001 +8.6%、2004 +7.7%、2008 +44.4%）、H2 0.71、H3 支持。
3. 実績系列を入れ替える（需要↔総発電、電気事業用→総発電）：H1 外れ（2/4、2001 +4.2%、2004 +3.3%）、H2 0.68、H3 外れ（2004 は高いケースが近い）、H4 支持（2015 +21.6%・+8.0%、2021 −0.2%）。
4. 2010年度の電気事業者計をつなぐ・2009年度で比べる・販売電力量と比べる：上の表。
5. 出所に食い違いのある 2010 基本計画を除く：H2 0.71。

## 問い直し（結果を見てから足した）
ずれを「GDPの前提のずれ」と「GDPあたりの電力（原単位）のずれ」に分けた（log差の和で分解。GDP は OWID の暦年で2022年まで。前提の分かる5本・14通り）。
- 前提の分かる5本すべてで、GDP の前提は実績より高かった（log差×100：1998→2010 +21.3、2004→2010 +11.9、2008→2020 +25.3、2015→2022 +11.9、2021→2022 +0.2）。
- 2021 は、公表時に実績として分かっていた2020年度の落ち込みを実績で置き、2020年度から先に前提の伸び（年1.7%）を当てた。ずれは +0.2 でほぼ0。GDP の定義の差（下）で符号は変わりうる。
- 原単位のずれは14通り中10通りでマイナス（見通しのほうが省エネが進む）で、GDP の見込み違いを打ち消していた。2004 のレファレンスの合計 +7.8 は、GDP +11.9 と原単位 −4.1 の和。
- 打ち消しが効かなかったのは、2008 の現状固定（原単位も +13.4）と 2015 の対策前（+7.8）。
- この分解は結果を見てから足したもので、仮説の確かめではない。

## 言えないこと
- 見通しの値は資料の要約や関連資料から転記した。ケース名の対応を表の並びや大小から決めた行がある（projections.csv の note）。2010 基本計画の2030年の値は、別の資料では約1.2兆kWhと書かれており、出所の数字に食い違いがある。
- 1998 の「電力需要」がどの範囲（自家発の自家消費を含むか、電気事業者の販売か）かは確かめていない。実績は自家用を含む使用電力量で比べている（推測で合わせた）。
- 2008 の見通しが電気事業用の定義だったかは確かめていない（基準年の値からの推測）。
- 電気事業者計の2010年度の値は、集計の範囲が変わった可能性がある（推測）。2001・2004 の判定はこれで変わる。
- 1990年・1994年の見通し、2009年の再計算、2012年の選択肢などは、電力の数字を集められず入れていない。
- 実績の電力需要は2つの統計を2010年度でつないでいる。つなぎ目の前後で定義が少し違う。
- 2008年以降の見通しの外れには、2008年のリーマン・ショック、2011年の震災、2020年の感染症の影響が入っている。見通しを作った時点では見込みようがない出来事で、「見通しの作り方が悪かった」とまでは言えない。
- GDP の実績は OWID の購買力平価のもの（暦年）で、見通しの前提（実質、年度）とは同じではない。内閣府の年度の実質GDPでは計算し直していない。問い直しの分解は目安で、2021 のように差が0に近いところは符号が変わりうる。
- 前提の期間の一部は、公表時にすでに実績だった（2008 の 2005〜07年度、2015 の 2013〜14年度）。その分は「見通し」ではなく実績の取り込み方の差になる。
- ずれの大きさの比べは、見通しどうしの数が少なく（8本）、統計的な検定は意味を持ちにくい。
- 政策の良し悪しや、今の見通しをどう置くべきかは扱わない。

## レビューで直したこと
独立レビュー（別の作業者が数字の照合・出所5行の確認・再実行を実施。数字は一致、再実行は同一）で、判定を変える定義の問題が1つ見つかり、次を直した。
1. 2001・2004 の見通しは電気事業用の発電電力量なのに、自家発込みの総発電と比べていた → 電気事業者計と比べる形に変え、H1・H3 の判定と結論を書き直した。2008 の定義の注、2010年度の集計の変化（推測）の注を足した。
2. 問い直しの「14通りすべてで GDP の前提が高い」→「前提の分かる5本すべてで」に直し、原単位のマイナスを 11/14 → 10/14 に直した。結果を見てから足したものと明記した。
3. 2021 の GDP の前提を、2020年度の落ち込みを実績として置き、2020年度からの伸びで計算し直した（+6.3 → +0.2）。
4. GDP の定義の違い（OWID の暦年・購買力平価と、年度の実質）で 2021 の符号が変わりうること、前提の期間の一部が公表時に実績だったことを書いた。
5. 2008 の見通しの道筋のずれを年ごとに出し、リーマン・ショック後の低い成長に触れた。
6. 先の長さとずれの関係は作りから大きくなることを書き、1年あたりの相関を併記した。
7. 「前後3年の平均」→「前後1年を含む3年の平均」。
8. 2015 の結論を「実績が道筋より12〜22%下（見通しが+13〜+28%多すぎ）」と書いた。
9. 1998 の「電力需要」の定義を確かめていないことを書いた。
