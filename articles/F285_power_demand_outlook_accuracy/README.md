# F285 エネルギー基本計画の電力需要の見通しは、過去にどれだけ当たったか？（精選モード B. 白書・審議会 Q20）

## 問い
国の長期エネルギー需給見通し・エネルギー基本計画は、電力需要（または発電電力量）の数字を何年も先まで置く。2025年の第7次は、データセンターや半導体工場で2040年度に需要が増える見通しを示した。では、過去の見通しはどれくらい当たったのか。外れは先の年ほど大きいのか。省エネを強く見込んだケースのほうが当たったのか。外れたなら、それは経済成長の見込みからか、GDPあたりの電力（原単位）の見込みからか。

## 手法
- 見通しごとに定義（電気事業用か、自家発込みか、需要か発電量か）が違うので、水準ではなく伸びで比べる。
  - 見通しの伸び＝目標年の値÷資料の基準年の値。実績の伸び＝同じ実績系列の目標年÷基準年。
  - ずれ＝log（見通しの伸び）−log（実績の伸び）を％に直したもの（＋は見通しが多すぎ）。
- 目標年がまだの見通しは、基準年から目標年まで一定の率で進む道筋を引き、2024年（度）の実績と比べた（途中のずれ）。
- 実績（主）：電力需要の見通しは年度の電力需要系列、発電電力量の見通しは OWID の暦年の発電電力量。
- 先の長さ＝比べる年−基準年。

## 頑健性
1. 実績系列を入れ替える（需要↔発電電力量）：H1 外れ（2/4）、H2 0.69、H3 外れ（2004 は高いケースがさらに近い）、H4 支持（2015 +21.6%・+8.0%、2021 −0.2%）。
2. 目標年の前後3年平均で比べる：H1 支持（4/4、2001 基準 +7.1%・2004 レファレンス +6.1%）、H3 支持。2010年度は2009年度（リーマン・ショック後）と2011年度（震災後）にはさまれた高めの年で、1年だけで比べると見通しが当たって見えやすい。
3. 1年あたりのずれ：先の長さとの順位相関 0.53。年あたりでは 2008 現状固定 2.6%/年、2015 対策前 2.2%/年が大きく、2001・2004 は ±0.5%/年以内。
4. 出所に食い違いのある 2010 基本計画を除く：H2 0.69。

## 問い直し（結果を見てから足した）
ずれを「GDPの前提のずれ」と「GDPあたりの電力（原単位）のずれ」に分けた（log差の和で分解。GDP は OWID の暦年で2022年まで。前提の分かる見通しだけ）。
- GDP の前提は14通りすべてで実績より高かった（1998→2010 +21.3、2004→2010 +13.6、2008→2020 +25.3、2015→2022 +11.9、2021→2022 +6.3、log差×100）。
- 原単位のずれは14通り中11通りでマイナス（見通しのほうが省エネが進む）で、GDP の見込み違いを打ち消していた。2004 のレファレンスが +3.2 と小さかったのは、GDP +13.6 と原単位 −10.4 の打ち消し合い。
- 打ち消しが効かなかったのは、2008 の現状固定（原単位も+13.4）と 2015 の対策前（+7.8）。

## 言えないこと
- 見通しの値は資料の要約や関連資料から転記した。ケース名の対応を表の並びや大小から決めた行がある（projections.csv の note）。2010 基本計画の2030年の値は、別の資料では約1.2兆kWhと書かれており、出所の数字に食い違いがある。
- 1990年・1994年の見通し、2009年の再計算、2012年の選択肢などは、電力の数字を集められず入れていない。
- 電力需要と発電電力量、年度と暦年が混ざる。伸びで比べることで定義の差の多くは消えるが、全部ではない（頑健性1で入れ替えて確かめた）。
- 実績の電力需要は2つの統計を2010年度でつないでいる。つなぎ目の前後で定義が少し違う。
- 2008年以降の見通しの外れには、2011年の震災と2020年の感染症の影響が入っている。見通しを作った時点では見込みようがない出来事で、「見通しの作り方が悪かった」とまでは言えない。
- GDP の実績は OWID の購買力平価のもの（暦年）で、見通しの前提（実質、年度）とは同じではない。問い直しの分解は目安。
- ずれの大きさの比べは、見通しどうしの数が少なく（8本）、統計的な検定は意味を持ちにくい。
- 政策の良し悪しや、今の見通しをどう置くべきかは扱わない。
