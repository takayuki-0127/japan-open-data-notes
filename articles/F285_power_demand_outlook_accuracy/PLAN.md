# PLAN（事前登録）F285 エネルギー基本計画の電力需要の見通しは、過去にどれだけ当たったか？

作成：2026-11-11（分析の計算を始める前）

## 先に断っておくこと（正直に）
- この計画を書く前に、データの形を確かめる途中で、次の値を目にしている：
  - 実績側：OWID の日本の発電電力量（暦年 1985〜2025）、総合エネルギー統計の 2010〜2024年度の発電電力量と最終電力消費、電気事業連合会「電気事業60年の統計」の使用電力量（1951〜2010年度）の一部。
  - 見通し側：各見通しの目標年の値（下の表）。
- つまり「どの見通しが上に外れたか」はおおよそ予想がついた状態で書いている。仮説の確かめとしては弱い部分があり、記事と README に明記する。

## 問い
政府の長期エネルギー需給見通し・エネルギー基本計画が示した電力需要（または発電電力量）の見通しは、実績とどれだけずれたか。ずれは先の年ほど大きいか。省エネを強く見込んだケースのほうが当たったか。

## 測り方
- 定義（電気事業用か自家発込みか、電力需要か発電量か）が見通しごとに違うので、水準ではなく **伸び**で比べる。
  - 見通しの伸び ＝ 目標年の値 ÷ 資料の基準年の値
  - 実績の伸び ＝ 実績の目標年 ÷ 実績の基準年（同じ実績系列の中で割る）
  - ずれ ＝ log(見通しの伸び) − log(実績の伸び)。％で示す（+は見通しが多すぎ）。
- 目標年がまだ来ていない見通しは、基準年から目標年まで一定の率で伸びるとした「途中の道筋」と、最新年（2024年度）の実績を比べる（途中のずれ）。
- 実績系列（主）：年度。電力需要は電気事業連合会の使用電力量（1951〜2009年度）を総合エネルギー統計の最終電力消費（2010〜2024年度）に2010年度でつないだもの。発電電力量は OWID（暦年）。
- 先の長さ（horizon）＝ 比べる年 − 基準年。

## 仮説と「外れ」の基準
- H1：目標年が来た見通し（1998・2001・2004 の2010年度、2008 の2020年度）の「基準・レファレンス・現状固定」ケースは、4本中3本以上で実績より5%以上多すぎる。→ 3本未満なら外れ。
- H2：ずれの大きさ（絶対値）は先の長さとともに大きくなる。全部の（見通し×ケース×比べる年）で、先の長さと |ずれ| の順位相関が 0.3 以上。→ 0.3 未満なら外れ。
- H3：同じ見通しの中では、いちばん低いケース（省エネ・対策を最も見込んだもの）が、いちばん高いケースより実績に近い。目標年が来た3本（2001・2004・2008）のうち、全部でそうなる。→ 1本でも逆なら外れ。
- H4：目標年がまだの 2015・2021 の見通しについて、2024年度時点の途中のずれは、2015 が −方向に（実績が道筋より下）5%以上、2021 は ±3%以内。→ どちらかを満たさなければ外れ。

## 頑健性（少なくとも3つ）
1. 実績系列を替える：電力需要の年度系列 ↔ OWID 発電電力量（暦年）。
2. 目標年の1年だけでなく、目標年の前後1年の平均（2009・2011 のような大きな変動の年の影響を見る）。
3. 1年あたりのずれ（ずれ ÷ 先の長さ）で比べる。
4. 出所の数字に食い違いのある 2010 の基本計画を除く。

## 問い直し（結果を見てから1つ足す予定）
ずれが経済成長の前提（GDP）と、GDP あたりの電力（原単位）のどちらから来たかを分ける、を第一候補とする。

## 言わないこと
政策の良し悪しや、今の見通しをどうすべきかは書かない。
