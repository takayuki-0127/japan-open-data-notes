# F270 「訪日客が過去最多」は、1人あたりの支出で見ても最多か？（精選モード）

2025年の訪日外客数は4,268万人で過去最多、旅行消費額も9.45兆円で過去最高でした。では、**1人あたり**で見ても最多なのか。円の名目、日本の物価で割った実質、訪日客の側から見た値（ドル・各国通貨、その国の物価で割る）で、答えが変わるかを確かめました。あわせて、1人あたりの増え方のうち、来る国・地域の構成が変わった分を分けました。

結果を見る前に計画を書いてコミットしました：[PLAN.md](PLAN.md)（コミット `50a94af`）。

## 問い
- 訪日客が過去最多の年に、1人あたりの支出も過去最多なのか。名目の円・実質の円・実質のドル・各国の実質の現地通貨で答えは変わるか。
- 1人あたりの増え方のうち、国籍・地域の構成の変化による分はどれくらいか。
- （問い直し）2025年の名目の「過去最多」は、何から来たのか（構成と泊数）。

## データ
| データ | 出典 | 使った範囲 |
|---|---|---|
| 1人当たり旅行支出（一般客、国籍・地域別、パッケージツアー参加費の国内分を含む） | 観光庁「訪日外国人消費動向調査」（2011〜2023年）・「インバウンド消費動向調査」（2024年〜）の暦年の集計表。2011〜2018年は国立国会図書館 WARP に保存された旧ページ | 2011〜2019年・2022〜2025年。2011〜2013年は付表4、2014〜2017年は参考表1、2018年以降は参考1の「全体」行（公表の「1人当たり旅行支出」と同じ）。平均泊数も同じ集計表から |
| 訪日外客数（国籍別・年） | 日本政府観光局（JNTO）「国籍/月別 訪日外客数（2003年～2026年）」（2026年10月21日公表版、F68 で Excel から作った縦長の CSV を写して使用） | 2011〜2025年 |
| 消費者物価指数（全国、2020年基準） | 総務省「消費者物価指数」長期時系列（e-Stat statInfId 000032103842） | 総合・生鮮食品を除く総合・外食・交通・教養娯楽サービスの年平均 |
| 為替レート（年平均）・米国の消費者物価 | FRED（FRB H.10、CPIAUCSL） | 2011〜2025年 |
| 各国の物価上昇率 | FRED 経由の世界銀行 FPCPITOTLZG（韓国・中国・香港・タイ・シンガポール・マレーシア・インド・英国・ドイツ・フランス・カナダ・オーストラリア） | 2010〜2025年。指数に積み上げ、2020年＝100 |

- 2020・2021年は調査がほぼ行われていないので外し、2022年は入国制限が残っていたので参考扱いにしました（計画どおり）。
- 消費動向調査の Excel は大きいので GitHub には入れていません。`src/zz_f270_01_取得.py` で取り直せます（md5 は `data/raw/MANIFEST_xls.csv`）。

## 手法
- **4つのものさし**：M1 名目の円、M2 実質の円（日本の消費者物価・総合で割る、2020年の物価）、M3 実質のドル（年平均の為替でドルに直し、米国の消費者物価で割る）、M4 国別の実質の現地通貨（その国の通貨に直し、その国の物価で割る）。
- **過去最多の判定**：2011年以降の、それより前のすべての年（2020〜2022年を除く）より大きければ「過去最多」。訪日外客数は JNTO の2003年以降の年で判定（2002年以前の年はどれも2010年より少ない）。
- **構成の分解**：全国籍の1人あたり＝Σ（国籍の割合×国籍の1人あたり）。割合は JNTO の訪日外客数（調査の21区分の国・地域＋その他）。比べる2年の変化を「国籍の中の変化」（2年の割合の平均×単価の差）と「構成の変化」（2年の単価の平均×割合の差）に分けた。この組み立てで作った全国籍の値は、公表値と2019年で1.5%、2025年で0.1%違う（クルーズ客を含む JNTO の人数を割合に使うため）。

## 結果
| 仮説 | 基準 | 結果 | 判定 |
|---|---|---|---|
| H1 実質の円でも2025年が最多 | それより前の年が2025年以上なら外れ | 2025年 20.4万円、2024年 20.9万円（−2.2%）で、比べられる12年で2番目（2022年を入れると3番目） | **外れ** |
| H2 実質のドルでは2011〜2019年の最大を15%以上下回る | 下回り方が15%未満なら外れ | 2025年 1,230ドル、最大は2011年 1,889ドル（−35%）。2025年は比べられる12年で最も低い。同じ方式の2018〜2019年の最大（1,472ドル）とは −16.5% | 支持（同じ方式の期間だけだと基準をわずかに超える程度） |
| H3 2019→2025年の増加のうち構成の変化は4分の1未満 | 4分の1以上なら外れ | 構成の変化 −0.30万円（組み立てた値の増加 6.81万円の4.4%、重みの取り方で0〜−0.60万円＝0〜8.8%）。公表値の差は 7.03万円 | 支持 |
| H4 訪日客が最多の年のうち、実質の円も最多だった年は半分未満 | 半分以上なら外れ | 訪日客が最多の9年のうち4年（2013・2014・2015・2024年、44%）。1人あたりの記録は2011年からしか数えていない。2022年を入れると2024年は最多でなくなり3年（33%） | 支持（あと1年で外れ） |

- **名目の円では2025年が最多**：22.88万円で2024年（22.69万円）より0.85%多い。公表の「22万9千円、2024年比0.9%増」と一致する。ただし入国制限中の2022年（23.45万円、平均泊数20泊）を入れると、2022年のほうが大きい。
- **日本の物価で割ると2024年を下回る**：物価は2024→2025年に3.2%上がり、名目の伸び（0.85%）を上回った。2025年の実質は2024年より2.2%少なく、2015年より14%、2019年より29%多い。
- **実質のドルでは2019年より少ない**：名目のドルは1,530ドルで2019年より5%多く、2017年（1,373ドル）などより多いが、2011年（1,641ドル）より少ない。米国の物価でも割ると1,230ドルで、2019年より16%少なく、比べられる12年で最も低い。
- **国・地域別**（13か国・地域）：実質の円では、2025年が2011〜2019年の最大を上回ったのは12か国・地域（中国だけ −24%）。それぞれの通貨と物価で見ると、上回ったのはドイツ（+15%）とカナダ（+12%）の2か国だけで、中央値は −12%（中国 −38%、香港 −34%、タイ −31%、インド −30%、韓国 −27%。シンガポール −4%、マレーシア −14%）。2019年と比べると、8か国・地域で増え、5か国・地域で減った。
- **構成の分解**（国籍別の値から組み立てた全国籍の値で行う。組み立てた値と公表値のずれは2019年 +1.54%、2024年 +0.42%、2025年 +0.11%）：2019→2025年の増加は、ほぼすべてが国・地域の中での増加（+7.11万円）で、構成の変化はほぼゼロ（−0.30万円、重みの取り方で0〜−0.60万円。2019年の組み立てのずれ0.24万円と同じくらい。クルーズ客を含む人数の割合がマイナスに寄せている可能性がある＝推測）。2015→2019年の減少（組み立てた値 −1.52万円、公表値 −1.76万円）では、国・地域の中の減少（−2.26万円）を構成の変化（+0.74万円）が一部打ち消していた。

## 問い直し（結果を見た後に追加）
2025年の名目の「過去最多」は、2024年よりわずか0.85%多いだけでした。この小さな更新は何から来たのかを、2つの分け方で見ました。
- **構成**：2024→2025年は、国・地域の中では −0.38万円（うち中国の分が −0.60万円。中国 −10.9%、香港 −9.2%、韓国 −3.7% など）で、来る国・地域の構成の変化が +0.50万円。この分け方では、構成の変化がなければ名目でも2024年を下回っていた計算になる（中国の値の調査誤差とクルーズ客の影響を考えると目安）。組み立てた値の差は +0.12万円、公表値の差は +0.19万円。
- **泊数**：平均泊数は8.99泊→9.52泊（+5.9%）に延び、1泊あたりの支出は名目で −4.8%（2.52万円→2.40万円）、実質で −7.7%。国・地域別に見ても、20か国・地域のうち12で1泊あたりが下がり、12で泊数が延びた。2019→2025年の +44% は、泊数 +7.65%、1泊あたり +34%。

## 確かめたこと（頑健性）
- **物価のものさし**：生鮮食品を除く総合でも −2.2%、旅行に近い物価（外食・交通・教養娯楽サービスの平均）でも −1.5%で、実質の2025年は2024年を下回る。
- **パッケージツアーの国内分を含まない単価（表3-1 など）**：名目は2024年比 +3.0%で最多だが、実質では −0.1%（2024年の 99.9%）でわずかに下回る。
- **調査の切れ目**：同じ方式の期間だけで見ると、実質の最大は2011〜2017年が2015年、2018〜2023年が2023年、2024〜2025年が2024年。
- **構成の分解の重み**：前の年・後の年・平均のどれでも、2019→2025年の構成の変化は増加の0〜8.8%。2024→2025年はどれでも構成の変化が +0.49〜+0.51万円、国・地域の中が −0.37〜−0.39万円。
- **比べる年**：2015→2025年でも構成の変化は増加の1〜12%。
- **実質のドルを同じ方式の期間で**：2018〜2019年の最大（1,472ドル）と比べると2025年は −16.5%、2011〜2017年の最大（1,889ドル）とは −35%。
- **2022年を入れる**：実質の円で2025年は3番目、H4 は3/9。
- **国別の実質の現地通貨**：結果は上のとおり（12か国・地域で円は最多、現地通貨では2か国）。

## 言えないこと
- 1人当たり旅行支出は調査の回答から推計した値で、誤差がある。標準誤差率は集計表の注に表として載っているが、数値の形では取れず、ここでは使っていない。2024→2025年の名目の差（0.85%）は、誤差の範囲に入りうる（推測）。
- 2018年と2024年に調査の方法が変わっている。2018年からクルーズ客は別の調査（クルーズ調査、表7-1〜7-4）に分けられ、集計表の1人あたりは一般客の値になった（2018年の集計表の注で確認）。調査する空港・海港の範囲も変わったと考えられる（推測）。2017年までの値がクルーズ客をどこまで含むかは確かめていない。2024年の暦年は、1〜3月期が旧調査、4〜12月期が新調査の結果。
- 構成の割合には、クルーズ客を含む JNTO の訪日外客数を使っている。調査の1人あたりは（2018年以降）一般客の値。国籍別の一般客の人数（旅行消費額÷1人あたり）で重みを付け直す分析は、国籍別の旅行消費額が集めた Excel になく、行っていない。
- 2025年の米国の消費者物価（CPIAUCSL）は、FRED の系列で2025年10月が欠けているので、11か月の平均。
- 各国の物価は年平均の上昇率を積み上げた指数で、旅行の時期や旅行に使うものの値段とは違う。台湾はこの物価のデータがないので M4 から外した。
- 国・地域の値は回答数が数百人のところもあり、ぶれが大きい。国・地域の良し悪しは扱わない。
- 観光政策の評価や提言はしない。

## 計画からのずれ
- 頑健性の「サービスの物価」は、使った長期時系列に「サービス」の系列がないので、外食・交通・教養娯楽サービス（宿泊料を含む）の平均に替えた。
- 過去最多の判定で、名目のドルは2011年がいちばん大きく、それ以降どの年も最多にならない（2011年は比べる前の年がない）。
- 2024→2025年の分解と泊数の分け方（問い直し）は、結果を見た後に加えた。計画では問いを1つ足すとしていたが、2つの分け方を足した。
- 図は計画に枚数の定めがなく、6枚にした。

## レビューで直したこと
別のエージェントによる独立レビューを受けた。数字はすべて一致し、手法も妥当、流し直しの結果（23ファイル）もバイト単位で一致した。指摘13件を次のように直した（新しい数字は `src/zz_f270_03_分析.py` で計算し直し、`results/main.json` の robust に入れた）。
| 指摘 | 直し方 |
|---|---|
| 構成の分解の差が組み立てた値で、公表値の差（+7.03・−1.76・+0.19万円）と違う | 本文・図5に両方を並べ、組み立てた値のずれ（2019年 +1.54%、2024年 +0.42%、2025年 +0.11%）を書いた |
| 「構成の変化はわずかにマイナス」 | 「ほぼゼロ（符号は重みの取り方で0〜−0.60万円）」に改め、クルーズ客の影響の可能性を（推測）で書いた |
| 「構成の変化がなければ前年を下回っていた」を事実として書いている | 「この分け方では〜計算になる（目安）」に弱め、中国の分（−0.60万円）を明記。一般客の人数での重み付けは、国籍別の旅行消費額が手元の Excel にないため行っていないと書いた |
| 「ドルで見ると最も低い」は実質だけ | 題名・結論・本文を「ドルに直して米国の物価でも割ると」「実質のドルでは」に直し、名目は2017年より多いことを書いた |

| 「15年の中で」 | 「比べられる12年の中で」に直し、2022年を入れると3番目と書いた |
| 図3の判定期間 | 訪日客数は2003年以降で判定と明記 |
| H4 の数え方 | 1人あたりは2011年から数えていること、2022年を入れると3/9 になることを書いた |
| 問い直しが2つ | 計画からのずれに書いた |
