# F270 計画（事前登録）：「訪日客が過去最多」は、1人あたりの支出で見ても最多か？

この計画は、1人あたり支出の長い系列（2011〜2018年）・物価や為替で直した値・国籍の構成で分けた値を、1つも計算する前に書いたものです。

## 見る前に知っていたこと（正直に書く）
- 訪日外客数（JNTO）の年ごとの総数は、以前の記事（F68・F150）で使っており、2024年・2025年が過去最多だったことは知っている。
- 1人あたり旅行支出（名目の円）は、以前の記事（145・226）で 2019年・2022〜2025年の値を見ている（2024年→2025年はわずかに増えた）。2011〜2018年の値は今回はじめて取る。
- 物価で割った値、ドルで見た値、国籍の構成で分けた値は、まだ計算していない。

## 問い
ニュースは「訪日客が過去最多」と伝え、同じ時期に「旅行消費額も過去最高」と伝える。では、1人あたりで見ても最多なのか。
円の名目、日本の物価で割った実質、訪日客の側から見た値（ドル・各国通貨、その国の物価で割る）で、答えは変わるのか。
1人あたりの増え方のうち、来る国・地域の構成が変わった分はどれくらいか。

## データ
- 訪日外客数：日本政府観光局（JNTO）の国籍別・年別（2011〜2025年）。
- 1人あたり旅行支出（一般客）：観光庁「訪日外国人消費動向調査」（2011〜2023年）・「インバウンド消費動向調査」（2024年〜）の暦年の集計表、国籍・地域別。2020・2021年は調査がほぼ行われていないので外す。2022年は入国制限が残るので参考扱い。
- 日本の物価：消費者物価指数（総合、2020年基準）。
- 為替と海外の物価：FRED の年平均為替レート、米国の消費者物価（CPIAUCSL の年平均）。主な国・地域は、その国の消費者物価（FRED で取れるもの）。

## 測り方
- M1：1人あたり支出（円、名目）
- M2：M1 ÷ 日本の消費者物価（総合）＝実質の円（2020年の物価）
- M3：M1 をその年の年平均為替でドルに直し、米国の消費者物価で割った実質ドル（全国籍の平均）
- M4（国別）：主な国・地域の1人あたり支出をその国の通貨に直し、その国の物価で割った実質（取れる国だけ）
- 構成の分解：全国籍の1人あたり＝Σ（国籍の割合×国籍の1人あたり）。比べる2年の変化を、国籍の中の変化と構成の変化に分ける（2つの年の重みの平均を使う対称な分け方）。

## 仮説と「外れ」の基準
- H1：実質の円（M2）でも、2025年は2011〜2025年（2020〜2022年を除く）で最多。外れ：それより前のどこかの年が2025年以上。
- H2：実質ドル（M3）では、2025年は2011〜2019年の最大を15%以上下回る。外れ：下回り方が15%未満、または上回る。
- H3：2019→2025年の名目の1人あたりの増加のうち、国籍の構成の変化による分は4分の1未満（絶対値）。外れ：4分の1以上。
- H4：訪日客数が過去最多を更新した年のうち、実質の円（M2）の1人あたりも過去最多だった年は半分未満。外れ：半分以上。

## 頑健性（少なくとも3つ）
1. 物価のものさしを変える：日本の消費者物価の総合／生鮮食品を除く総合／サービス。
2. 調査の切れ目：2018年（調査の方法の変更）と2024年（新しい調査）の前後で分けて、同じ方式の中だけで比べる。
3. 国籍の構成の分解の基準年を変える（前の年の重み・後の年の重み・平均）。
4. 比べる年を変える（2015年・2019年・2024年）。
5. 実質ドルを、主な国・地域の実質の現地通貨（M4）に替える。

## 問い直し
最初の結果を見てから、1つだけ問いを足す（候補：1日あたりで見るとどうか、総額の伸びのうち人数と1人あたりの分けはどうか）。足したことは記事と README に書く。

## 書き方の決まり
政策の評価や提言はしない。国・地域の比較は数字の説明にとどめ、良し悪しは言わない。推測には（推測）を付ける。
