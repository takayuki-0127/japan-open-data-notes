# 161 特定健診の受診率は、保険者の種類でどれだけ違うか：特定健康診査・特定保健指導の実施状況（2008〜2023年度）

厚生労働省「特定健康診査・特定保健指導の実施状況」の保険者種類別の実施率（2008〜2023年度）を並べ、市町村国保・国保組合・協会けんぽ・船員保険・健保組合・共済組合の差と、その差が縮んだかを調べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A161 | 特定健診・特定保健指導の実施率は、保険者の種類でどれだけ違い、差は縮んだか | 保険者種類別の実施率の推移（群間比較）、2023年度の細かい区分（市町村国保の規模・健保組合の総合／単一）での比較 | `src/a161_checkup.py` |

## 主な結果
- 2023年度の特定健診の実施率は、健保組合82.9%・共済組合82.6%に対して、協会けんぽ58.7%、船員保険52.8%、国保組合51.9%、市町村国保38.2%。全体は59.9%（国の目標70%）
- 2008→2023年度の上昇幅は、協会けんぽ+28.6ポイント、健保組合+23.4に対し、市町村国保は+7.3ポイント。健保組合・共済組合と市町村国保の差は29.0ポイント（2008年度）から44.7ポイント（2023年度）に広がった
- 2020年度はコロナ禍で市町村国保（38.0→33.7%）と国保組合（49.8→45.7%）が大きく下がり、協会けんぽ・健保組合・共済組合の下がり幅は1ポイント前後だった
- 特定保健指導の実施率（2023年度）は、健保組合35.4%・共済組合35.1%・市町村国保29.1%・協会けんぽ19.0%・船員保険15.0%・国保組合13.1%。市町村国保の中では、小さな市町村ほど高い（大13.9%・中28.7%・小44.9%）。健保組合も単一型45.5%・総合型19.3%と差が大きい

## 注意
- 2008〜2010年度は元の表で市町村国保の規模別・健保組合の総合／単一の区分がなく、列の見出しも一部欠けています。値の並び（市町村国保・国保組合・協会けんぽ・船員保険・健保組合・共済組合）から対応をとりました
- 実施率は「受診者数÷対象者数」で、保険者ごとに対象者の年齢構成や働き方が違います。この差をそろえた比較はしていません
- 市町村国保の「大・中・小」は、被保険者数の規模による区分です（区分の基準は元の資料を参照）
- 被扶養者（家族）と被保険者本人の差、事業主健診のデータの受け取りの違いなどは、この表では分けられません
