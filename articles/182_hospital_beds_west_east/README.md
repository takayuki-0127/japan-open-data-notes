# 182 人口あたりの病床数は、本当に「西高東低」なのか：医療施設調査

厚生労働省「医療施設調査」（令和7年＝2025年10月1日現在、都道府県編 第15表）の、人口10万人あたりの病院の病床数（種類別）を47都道府県で並べたフォルダです。高齢化との関係は、総務省「人口推計」（2023年10月1日現在）の65歳以上人口の割合と比べました。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A182 | 人口あたりの病床数は「西高東低」か。どの種類の病床が差を生み、高齢化でどこまで説明できるか | 都道府県の順位、8地方別の単純平均（一般・療養・精神・結核＋感染症）、中国・四国・九州沖縄の17県とほか30道府県の平均の比、65歳以上割合との相関と回帰の残差 | `src/a182_beds.py` |

## 主な結果
- 全国は人口10万人あたり1,178.6床（一般706.1・療養215.1・精神253.2）
- 最多は高知2,398、最少は神奈川786で3.05倍。上位15のうち14が中国・四国・九州沖縄（ほかは北海道）、下位は神奈川・愛知・埼玉・東京・千葉
- 中国・四国・九州沖縄17県の平均1,705に対し、ほか30道府県は1,183（1.44倍）。種類別の比は一般1.24倍、療養1.80倍、精神1.73倍で、差は療養と精神で大きい
- 地方別の平均は四国1,842、九州・沖縄1,746、北海道1,737、中国1,531、東北1,312、中部1,191、近畿1,189、関東978
- 65歳以上割合との相関は0.65（1ポイントあたり約68床）。高齢化の分を除いた残差は、西の17県で平均+258、ほかで−146。秋田・新潟・長野・岐阜などは高齢化の割に少ない

```bash
pip install -r requirements.txt

```

## データ
| ファイル | 中身 |
|---|---|
| data/beds_per100k_2025.csv | 全国と47都道府県の人口10万対病院病床数：総数・精神・感染症・結核・療養・一般（2025年10月1日） |
| data/aged65_share_2023.csv | 47都道府県の65歳以上人口の割合（%、2023年10月1日、人口推計の年齢階級別人口から計算） |

- 医療施設調査 令和7年 都道府県編 第15表（statInfId 000040501246、CSV）。山形の結核病床「-」は0とした
- ダウンロード：`https://www.e-stat.go.jp/stat-search/file-download?statInfId=000040501246&fileKind=1`

## 注意
- 病院の病床のみ（診療所の病床は含まない）。介護施設は含まない
- 地方別・西とほかの比較は都道府県の単純平均（人口で重みづけしていない）
- 高齢化の年（2023年）と病床の年（2025年）はずれている
- 病床の多さが良い・悪いはこのデータでは言えない。病床が多い理由（歴史的な病院の整備、医療の使われ方、介護との分担など）も分けられない
