# 01 取得（e-Stat、ブラウザから）

この環境から e-Stat に直接つながらないため、ブラウザでファイルを取り、必要な行だけを data/raw に保存した（2026-11-05）。

1. 家計調査 長期時系列表（二人以上の世帯、月）：
   https://www.e-stat.go.jp/stat-search/file-download?statInfId=000040270646&fileKind=1
   - CSV（Shift_JIS）。「消費支出」「電気代」の 2015年1月〜2026年8月 → data/raw/monthly_kakei.txt
2. 消費者物価指数 2020年基準 長期時系列（全国、月）：
   https://www.e-stat.go.jp/stat-search/file-download?statInfId=000032103842&fileKind=1
   - 「電気代」「総合」「ガス代」の 2015年1月〜2026年9月 → data/raw/cpi_monthly.txt
3. 家計調査 詳細結果表（年）＜品目分類＞1世帯当たり年間の支出金額，購入数量及び平均価格
   - 4-1 都市階級・地方別、4-3 年間収入五分位階級別、4-6 世帯主の年齢階級別（2020〜2025年。statInfId は README）
   - Excel の「二人」系のシートから「世帯人員」「消費支出」「電気代」（支出金額・購入数量）→ data/raw/annual_groups.csv
4. 家計調査 長期時系列表（年）：単身世帯 000040270666、総世帯 000040270663、二人以上の世帯 000040270652
   - 「消費支出」「電気代」の 2015〜2025年 → data/raw/annual_households.txt
5. 全国の電気代の購入数量（2005〜2024年）：F113 の data/items_panel.csv（品目コード 430）→ data/raw/national_kwh_2005_2024.csv
6. 国の値引き単価（低圧、使用月）→ data/raw/subsidy_rates.csv
   - 2023年1月〜2024年5月：電気・ガス価格激変緩和対策、2024年8〜10月：酷暑乗り切り緊急支援、2025年以降：電気・ガス料金支援（資源エネルギー庁・各電力会社の公表資料）
