# F186 電気料金の値上がりは、家計のどこに効いたのか？

家計調査の電気代を「1kWh あたりの単価」と「使用量（kWh）」に分け、2021年から2025年の増え方を、年間収入・世帯主の年齢・都市の大きさ・地方ごとに比べた。国の値引き（電気・ガス価格激変緩和対策など）を足し戻した場合も推計した。

## 問い

- 2021年からの電気代の増加は、単価と使用量のどちらによるものか
- 1kWh あたりの単価は、世帯の区分によって違うのか
- 消費支出に占める電気代の割合は、どの区分で大きく上がったのか
- 国の値引きは、1世帯あたりどれくらいだったか（推計）

## 手法

1. **年次の分解**：電気代 = 単価（円/kWh）× 使用量（kWh）。2021年からの増加を、対数平均（LMDI）で「単価の寄与」と「使用量の寄与」に分けた。
2. **国の値引きの推計**：使用月の値引き単価 × 月別の推計使用量。家計調査は支払いベースなので、支払月 t の値引きは前月 t−1 の単価を当てた。月別の使用量は、年間の kWh を「電気代 ÷ 電気代の物価指数」の月別の形で割り振った。区分ごとの値引きは、全国の「kWh あたり平均値引き」× 区分の年間 kWh とした。
3. **負担の比較**：消費支出に占める電気代の割合（%）の変化を、区分ごとに比べた。
4. **月次の確認**：電気代の支出を、2021年の同じ月との比で、物価指数（単価）とそれ以外（使用量の目安）に分けた。

## 結果（二人以上の世帯）

- 電気代は 2021年 123,804円 → 2025年 158,622円（+34,818円、+28.1%）。単価は 26.15 → 32.65円/kWh（+24.8%）、使用量は 4,734 → 4,859kWh（+2.6%）。増えた分のうち **単価の寄与は 31,169円（約9割）**、使用量は 3,649円。
- 総合の物価（+12.2%）で割った実質では +14.2%。
- 国の値引きの推計は、2023年が1世帯あたり 約27,700円、2024年 約12,600円、2025年 約5,900円。足し戻すと 2021→2025年の増加は +40,718円（+32.9%）。
- **単価は区分の間でほぼそろった**。2025年の年間収入五分位の単価は 32.45〜32.75円/kWh（2021年は 25.28〜26.97円）、世帯主の年齢では 32.27〜33.44円、都市階級では 32.14〜33.30円。地方の間では 29.32〜37.46円と差が残った。
- **割合の上がり幅は、収入の低い世帯ほど大きい**。第Ⅰ五分位は 4.80% → 5.53%（+0.72ポイント）、第Ⅴ五分位は 2.89% → 3.26%（+0.38ポイント）。円で見た増え方は第Ⅰ +33,915円、第Ⅴ +37,446円とほぼ同じ。
- 使用量の寄与が大きかった区分：小都市B・町村（+47,714円、使用量 +11.3%）、世帯主70歳以上（+39,742円、+8.5%）、第Ⅰ五分位（使用量 +8.2%）。大都市は使用量がほぼ横ばい（−0.2%）。
- 単身世帯は 65,790 → 88,040円（+33.8%）、消費支出に占める割合は 3.54% → 4.24%。

## 頑健性

| 確認 | 結果 |
|---|---|
| 期間（2021→2025・2020→2025・2021→2024・2021→2023）× 値引きの扱い（記録どおり・足し戻す）の8通り | 第Ⅰ五分位の割合の上がり幅は、8通りすべてで第Ⅴ五分位より大きい。ただし「いちばん上がった五分位」は、2021→2023年・2021→2024年の記録どおりでは第Ⅱ・第Ⅲ |
| 都市階級・地方 | 円で見た増え方の最大は、8通りすべてで「小都市B・町村」、地方では「東北」 |
| 世帯主の年齢 | 円で見た増え方の最大は8通り中4通りで「70歳以上」。割合の上がり幅の最大は期間で入れ替わる |
| 増加に占める単価の寄与（区分の中央値、2021→2025） | 年間収入 83%・年齢 100%・都市階級 94%・地方 96% |
| 値引きの月別の割り振り方（使用量の形 / 12か月均等） | 2023年 27,660円 / 27,290円、2024年 12,573円 / 11,639円、2025年 5,900円 / 5,142円 |
| 基準年を2019年にする | 2019→2025年は +28,717円、単価 +18.7%、使用量 +2.8% |
| 物価指数との照合 | 単価と物価指数（電気代）の前年比の相関は 0.94。ただし 2021→2025年の上昇は物価指数が約18%、家計調査の単価が約25%で、物価指数のほうが小さい |

## 言えないこと

- 家計調査は抽出調査で、区分ごとの値には標本の誤差がある（公表の標準誤差は使っていない）。区分の間の小さな差は偶然の範囲かもしれない。
- 使用量の変化（2025年の夏の暑さなど）の理由は分けていない。
- 単価には、基本料金・燃料費調整・再エネ賦課金・料金プランの違いがまとめて入っている。電力会社や契約の違いは見ていない。
- 国の値引きは推計で、実際の値引き額（世帯ごと・月ごと）ではない。高圧契約・オール電化の割引なども考えていない。
- 消費者物価指数と家計の支払単価のずれの理由（契約の構成、地域の重み、支払いの時期など）は確かめていない（推測）。
- 単身世帯は購入数量がないため、単価と使用量に分けていない。
- 特定の地域や世帯の評価をするものではない。
