# 209 都道府県ランキングの1位はどれくらい入れ替わるのか：社会・人口統計体系

総務省統計局「社会・人口統計体系」の都道府県別の指標（社会生活統計指標）で、同じ指標コードの値を、2015年版の最新年（主に2012〜2013年）と「統計でみる都道府県のすがた2026」の年（主に2023〜2024年）で比べたフォルダです。334指標について、順位全体の一致度（Kendallのτ）と、1位・最下位・上位5県の入れ替わりを数えました。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A209 | 都道府県ランキングの1位はどれくらい入れ替わるのか | 両方の版にある指標コードを突き合わせ（年の差10〜15年、45県以上に値があるもの）、Kendallのτ、1位・最下位が同じか、上位5県の重なり、順位の平均変化、分野別の集計 | `src/a209_rank.py` |

## 主な結果
- 334指標の年の差は中央値11年（2012年→2023年が中心）。τの中央値は0.75で、0.8以上が41.3%、0.6未満が28.1%
- 1位の県が同じだったのは186指標（55.7%）。最下位が同じだったのも186指標（55.7%）。上位5県の重なりは平均3.3県で、5県とも同じは18.3%
- 順位全体が安定していても1位は入れ替わる。τ0.9以上でも1位が同じは84%、τ0.6未満では24%
- 分野別のτの中央値は、自然環境0.87、人口・世帯0.86、居住0.84が高く、家計0.39、安全0.56、行政基盤0.61が低い。家計（消費支出に占める割合など）は1位が同じだったのが14指標中2つ（14%）
- 新しい年で1位の回数が多いのは東京都70、沖縄県23、高知県22、秋田県20。1位を保った186指標のうち56は東京都
- τが低かったのは住居費割合（0.02）、乳児死亡率（0.03）、0〜4歳の死亡率（0.06）など、県ごとの件数が少なく年ごとに振れやすい指標

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a209_rank.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/pref_indicators_2015_2026_editions.csv | 指標コード・版（2015/2026）・年ごとの47都道府県の指標値（p01〜p47は都道府県コード順）。2015年版は1指標に複数の年がある |
| data/indicator_names_2026.tsv | 2026年版の指標コード・指標名・単位・年 |

- e-Stat の「社会生活統計指標－都道府県の指標－2015」（A〜Mの13表、statInfId 000028462301〜000028462313）と「統計でみる都道府県のすがた2026」社会生活統計指標（A〜Lの12表、000040412522〜000040412533）の Excel を、ブラウザ内で読み、指標値の列だけを取り出した（順位の列は使わず、順位は自分で付け直した）
- 2015年版は各指標の最新年を使った

## 注意
- 指標コードが同じでも、定義や元の調査の方法が変わったものがあり得る。名前は2026年版のものを載せた
- 順位は値の大きい順（1位＝最大）。「低いほうがよい」指標でも同じ向きで数えている
- 件数が少ない指標（乳児死亡率など）は偶然の振れが大きく、τが低いことは、県の実力の入れ替わりとは限らない
- 年の差は指標によって10〜15年と違う
- 2015年版にだけ、または2026年版にだけある指標は比べていない
