# 1008 項目が互いに似ていると、合計点は何を測っているのか？（指数とスコア）

店や製品の「総合指数」は、いくつもの項目の点を平均して作ることがよくあります。作る人は「味・接客・居心地を同じだけ見る」つもりでも、項目を思いつくままに並べると、ある面の項目ばかりが増えることがあります。似た項目は互いに強く相関するので、そのまま平均した合計点は、項目の多い面に引っぱられます。**ここでは、作成者が乱数で作った架空の飲食店200店（味・接客・居心地の3つの面の本当の良さを作成者が置き、10項目のうち6項目を味に似た項目にしたもの）で、10項目をそのまま平均した合計点の散らばりのうち、各面から来る分がどれだけか、3つの面を同じだけ見た「本当の良さ」の上位20店をどれだけ当てるかを、面ごとにまとめてから足す作り方と比べました。**

店・指数・項目はすべて架空のもので、実在の指数やランキングの数字は使っていません。

関連する記事 939 は、項目ごとの点の散らばりが違うと「均等」の重みでも散らばりの大きい項目が強く効くことを数えています。この記事は、1つ1つの項目の散らばりは同じでも、似た項目の数が多い面が合計点を引っぱることに絞ります。同じ企画の 1009（項目の数を増やすと、合計点は安定するのか）は、項目を足したときの月ごとの安定を数えています。名目の重みと実際の効きのずれは、1005（足す前のそろえ方）と 1012（10点満点と100点満点の項目を混ぜる）でも扱っていますが、あちらは点の散らばりの違いから、この記事は似た項目の数から来るずれです。

## 主な結果

### 合計点の散らばりのうち、各面から来る分（500回の平均、`results/indices_base.csv`）
| 指数 | 味 | 接客 | 居心地 | 項目だけのぶれ（式） |
|---|---|---|---|---|
| ①10項目をそのまま平均 | **66.12%**（式 65.95%） | 11.64% | 11.53% | 10.78% |
| ②面ごとに平均してから3面を平均 | 28.34%（式 28.13%） | 28.12% | 27.88% | 15.62% |
| ③面ごとに1項目だけ | 22.77%（式 22.58%） | 22.52% | 22.38% | 32.26% |

- そのまま平均した合計点①は、散らばりの66.12%が味から来ていた。「3つの面を同じだけ見る」つもりの指数が、実際にはおもに味を測っていた。この割合は、項目の数と相関から決まる**式どおり**の値（65.95%）で、置き方の写しです
- 合計点①と各面の本当の良さとの相関は、味0.8653・接客0.4566・居心地0.4553だった
- 面ごとに平均してから足す②では、3つの面がほぼ28%ずつになった。そのかわり、接客と居心地は2項目ずつしかないので、項目だけのぶれの分は15.62%と①（10.78%）より大きい

### 「3面を同じだけ見た本当の良さ」をどれだけ当てるか（500回の平均）
| 指数 | 本当の良さとの相関 | 式 | 順位相関 | 上位20店の当たり | 10〜90%の範囲 |
|---|---|---|---|---|---|
| ①10項目をそのまま平均 | 0.8681 | 0.8685 | 0.8552 | **63.86%** | 55〜75% |
| ②面ごとに平均してから3面を平均 | 0.9177 | 0.9186 | 0.9087 | **71.61%** | 60〜80% |
| ③面ごとに1項目だけ | 0.821 | 0.8231 | 0.8057 | 58.69% | 49.5〜70% |

- 上位20店の当たり（指数の上位20店のうち、本当の良さの上位20店に入っていた割合）は、①63.86%に対して②71.61%だった。500回のうち、②のほうが当たったのは73.4%、同じだったのは15.6%
- 項目を減らして面ごとに1項目だけにした③は、面の偏りはなくなるが、項目だけのぶれが32.26%に増え、当たりは58.69%と①より下がった。「似た項目を捨てる」より「面ごとにまとめてから足す」ほうが当たった

### αは「何を測っているか」を教えない
- 10項目のαは平均0.8102で、よく使われる目安では「まとまった物差し」に見える高さだった。面ごとに1項目ずつの3項目のαは0.2815だった
- 確かめの27通りで、同じ面の項目どうしの相関0.6・面どうしの相関0.2のまま味の項目を4→6→8と増やすと、①の味の分は38.54%→65.61%→84.77%に増え、αも0.7645→0.8104→0.8747と上がった。上位20店の当たりは72.75%→62.0%→51.2%と下がった（`results/robustness.csv`。基本の置き方の値は、乱数を変えて数え直したので500回の値から少し動く）
- αが高いのは、似た項目どうしがよく相関しているからで、3つの面を広く測っているからではない。αが上がるほど、3面を同じだけ見る狙いから離れる置き方もあった

### 確かめ：置き方を変えて（27通り、各100回）
| 数えたもの | 値 |
|---|---|
| ①の散らばりのうち味から来る分 | **28.17〜95.46%**（味6項目の9通りでは50.04〜79.81%） |
| 式の値とのずれ（27通りで最大） | 0.42ポイント |
| ②の散らばりのうち味から来る分 | 12.57〜32.83% |
| 10項目のα | 0.4575〜0.9638 |
| 上位20店の当たりの差（②−①） | −5.35〜+32.55ポイント（味6項目では−0.45〜+23.4ポイント） |
| ②のほうが当たった置き方 | 27通り中21通り |

- ②が当たらなかった（差が0以下）6通りは、すべて同じ面の項目どうしの相関が0.3（1つの項目のぶれが大きい）置き方だった。項目だけのぶれが大きいと、2項目しかない面を3分の1の重みで足す②は、そのぶれも大きく拾う。相関0.6・0.9の18通りでは、②のほうが+0.2〜+32.55ポイント当たった
- 本当の良さを「味6割・接客2割・居心地2割」と置くと、向きは逆になった。上位20店の当たりは①76.3%・②61.12%・③51.82%（本当の良さとの相関 0.9442・0.8446・0.7556）。①が「おもに味を測る」こと自体は悪いことではなく、作る人が何を測りたかったかと合っているかどうかが問題です

## 注意（言えないこと）
- 架空のデータです。面の数、項目の数と割り振り、項目どうしの相関、面どうしの相関は作成者が置いたもので、結果はこれで決まります。そのまま平均した合計点の散らばりのうち味から来る分は、置き方で28.17〜95.46%と動きました。実在の指数やランキングを表すものではありません
- 「本当の良さ」は作成者が「3つの面を同じだけ」と置いたものです。味を重く見たいなら、そのまま平均した①のほうが当たります（味6割と置くと①76.3%・②61.12%）。どの面をどれだけ見るべきかは、ここからは言えません
- 項目がどの面に属するかは、作成者が置いたので分かっています。実際には、項目どうしの相関を見て似た項目のまとまりを探すことになりますが、その探し方の当たり外れは数えていません
- 1つの項目は1つの面だけを測ると置きました。1つの項目が2つの面にまたがる場合や、客の評価の甘さ辛さのような全項目に共通のずれは入れていません
