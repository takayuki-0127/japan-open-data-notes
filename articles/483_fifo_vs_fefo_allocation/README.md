# 483 在庫を「入った順」と「期限の近い順」で引き当てると、欠品と廃棄は何件変わるのか（実務の型）

期限のある商品の在庫を、出荷のときに「入った順」（先入れ先出し）で引き当てるか、「期限の近い順」で引き当てるかで、廃棄と欠品がどれだけ変わるかを数えたフォルダです。架空の30品目・2年分の入荷と出荷を、同じ需要・同じ発注の決まりで、引き当ての順番だけを変えて再現しています。参考に「新しい順」（新しいものから出す）も並べました。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A483 | 引き当ての順番で、廃棄と欠品はどれだけ変わるか。入荷するロットの残り期限のばらつき、売れる速さ、在庫の厚さでどう変わるか | 1日ごとに「入荷→期限切れの廃棄→出荷（引き当て）→発注」をくり返すシミュレーション。残り期限は中心7日で、ばらつき±0〜6日。3日ごとに12個単位で発注し、入荷まで2日。品目ごとに3回くり返し | `src/a483_fefo.py` |

## 主な結果
- **残り期限のばらつき±3日**（30品目×3回、需要197.3万個）：
  - 入った順：廃棄 29.0万個（需要1,000個あたり147）、欠品 2.19万個（11.1）、欠品の日 1,205
  - 期限の近い順：廃棄 23.8万個（121、入った順より18%少ない）、欠品 1.72万個（8.7、21%少ない）、欠品の日 982
  - 新しい順（参考）：廃棄 318、欠品 46
- **ばらつきがないか小さいとき**（±0〜1日）：入った順と期限の近い順は、廃棄も欠品もまったく同じ。後から入ったロットが先に期限を迎えることがないため
- **ばらつきが大きいほど差が開く**：需要1,000個あたりの廃棄の差は、±2日で5.9、±4日で52、±6日で89。欠品は±6日で入った順73、期限の近い順41
- **売れる速さ別**（±3日）：どの速さでも期限の近い順が少ない。廃棄は遅い品目で210→183、速い品目で132→106
- **在庫の厚さとの関係**：安全在庫を厚くすると欠品は減り廃棄は増える。同じ欠品（需要1,000個あたり約9.5）なら、廃棄は入った順180（安全在庫2.0）、期限の近い順119（同1.6）。安全在庫の厚さは±3日の場面で0.8〜3.0の6通りを試した

## 注意（言えないこと）
- 架空の品目と需要。残り期限・発注の間隔・単位・安全在庫は置いた値で、数字はこの置き方での結果
- 出荷先が残り期限の長いものを求める決まり（納品期限）や、値引きして売り切る動きは入れていない
- 入荷の時点で残り期限が分かっている、と置いた。分からなければ期限の近い順は使えない
- 在庫の評価の方法と粗利は 430 で扱った。ここは引き当ての順番だけを見ている
