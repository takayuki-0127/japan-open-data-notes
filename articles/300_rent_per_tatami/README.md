# 300 家賃は、広さあたりでどれだけ違うのか

総務省「令和5年住宅・土地統計調査」時系列統計表 第34-1表（住宅の種類・所有の関係別の1か月当たり家賃と1畳当たり家賃、全国、1973〜2023年）と第36表（1畳当たり家賃の階級別の借家（専用住宅）数、1993〜2023年）を使ったフォルダです。都道府県の値は使わず、全国と3大都市圏（とそれ以外）の集計だけを使っています。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A300 | 借家の家賃は、広さあたり（1畳当たり）でどれだけ違い、どう変わったか | 1畳当たり家賃の推移を借家の種類別に並べた。1か月の家賃の変化を「1畳当たり家賃」と「広さ（畳数＝家賃÷1畳当たり家賃、で求めた近似）」に分けた（対数の変化の比）。1畳当たり家賃の階級別の数から、中央値などを階級の中で線形に補間して求めた。3大都市圏以外＝全国−3大都市圏 | `src/a300_rent_per_tatami.py` |

## 主な結果
- 借家の1畳当たり家賃（月）は、1973年770円 → 1993年2,637円 → 2018年3,064円 → 2023年3,393円。1993〜2018年の25年で16%しか上がらなかったのが、2018〜2023年の5年で10.7%上がりました。
- 2023年の1畳当たり家賃は、民営借家（非木造）4,151円、UR・公社の借家3,633円、民営借家（木造）2,916円、給与住宅2,071円、公営の借家1,246円。民営（非木造）は公営の3.3倍で、この比は1993年から3.3〜3.5倍のままです。
- 2018〜2023年は、1畳当たり家賃が10.7%上がった一方、借家1戸あたりの広さ（近似）は18.1畳から17.5畳に小さくなり、1か月の家賃は7.1%の上がりでした（専用住宅）。1993〜2023年の30年で見ると、1か月の家賃の伸び（1.34倍）の87%は1畳当たり家賃、13%は広さの分です。
- 1畳当たり家賃の中央値（借家・専用住宅）は、全国で1993年2,560円 → 2023年3,525円。1,000円未満の借家は18.4%から8.5%に減り、5,000円以上は19.1%から31.8%に増えました。
- 3大都市圏の中央値は、それ以外の1.73倍（1993年）、1.55倍（2013・2018年）、1.64倍（2023年）。2023年は3大都市圏4,452円、それ以外2,714円でした。

## 頑健性
- 第36表の階級の数を足すと、どの調査年も表の総数（不詳を含む）と一致した（差は丸めの範囲）
- 中央値は階級の中で一様に分かれると見た補間です。階級の幅（250〜1,000円）より細かい違いは言えません。8,000円以上の階級は上限が分からないので、90%点などの高い分位は使わず、図の帯も25〜75%にした
- 1993年の最も低い階級は「50円未満」「50〜500円」、2023年は「0円」「1〜500円」なので、500円未満にまとめた
- コードはきれいなフォルダで3回動かし直し、data・results・figures の全ファイルが一致した

## 動かし方
```
pip install -r requirements.txt
python src/a300_rent_per_tatami.py
```

## データ
- `data/raw/hlts_ts_subset.json`：e-Stat「令和5年住宅・土地統計調査 時系列統計表」第34-1表（statInfId=000040354072）、第36表（000040354075）の閲覧用 Excel を、ブラウザの中で SheetJS（xlsx 0.18.5）で CSV の文字列にしたもの（2026-11-12 取得）。手で取る場合は `https://www.e-stat.go.jp/stat-search/file-download?statInfId=<id>&fileKind=4`
- `data/rent_by_tenure_long.csv`・`data/rent_per_tatami_quantiles.csv`：整形した表

## 注意
- 「1畳当たり家賃」は居住室の畳数あたりで、台所・浴室などは広さに入りません。共益費・管理費は家賃に含みません
- 借家1戸あたりの広さは、平均の家賃÷平均の1畳当たり家賃で求めた近似です
- 3大都市圏の範囲は調査年ごとの定義によります（古い調査では京浜葉大都市圏・京阪神大都市圏）。年ごとの比較には、この範囲の違いが混ざります
- 家賃は名目の金額で、物価の変化は除いていません
- 家賃の違いの理由（立地、建物の新しさ、設備など）は、このデータでは分けていません。特定の地域の順位づけはしていません
