# 660 回帰の「平均の区間」を新しい1件の予測の区間と取り違えると、何%の回が外れるのか（手法の解説・正解の分かるデータで試す）

回帰の結果には2種類の区間があります。平均の信頼区間は「その条件の店の平均がどこにあるか」、予測区間は「その条件の新しい1店がどこに来るか」を表します。図にすると前者の帯が細く目立つので、新しい1件の見込みとして読まれがちです。**ここでは、架空の店の「広告費と売上」（y = 2 + 0.5x + 雑音）で、回帰に使う店の数を10〜2,000に変え、新しい1店の売上が2つの95%区間に入る割合を、各5,000回数えました。** 数字は置いた関係と雑音の大きさで決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A660 | 平均の区間を予測の区間として使うと、新しい1件は何%外れるか | 最小二乗の平均の95%信頼区間と95%予測区間。1回分を statsmodels の get_prediction と一致させた。n=10〜2,000、各5,000回。seed 660 | `src/a660_ci_pi.py` |

## 主な結果
- **新しい1店の売上が「平均の信頼区間」に入った割合**：10店で62.3%、50店で30.8%、200店で **15.8%**、2,000店で **4.6%**
- **予測区間**には、どの件数でも94.6〜95.1%が入った。平均の信頼区間には、本当の平均が94.5〜95.3%入った（どちらも正しく働いている）
- **幅の比**：予測区間は平均の区間の、10店で2.4倍、200店で10.3倍、2,000店で32.4倍。平均の区間は件数とともに細くなるが、予測区間は雑音の分（約±2）より細くならない
- 200店の1回分の例では、回帰に使った店そのもののうち、平均の区間に入っていたのは13.5%だけ

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 660）
- 仮定：直線の関係、雑音は正規分布でどこでも同じ大きさ（標準偏差1）、x は0〜10の一様

## 注意（言えないこと）
- シミュレーションの結果。関係と雑音の大きさは作成者が置いたもので、結果はこれで決まる
- 雑音の大きさが x で変わる場合や、関係が直線でない場合は、予測区間も外れる（588 で扱った）
- 広告の効果の大きさについての話ではない。区間の読み方だけの話
