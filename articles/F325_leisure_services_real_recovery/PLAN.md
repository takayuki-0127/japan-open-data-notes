# F325 PLAN（事前の計画）：レジャー・娯楽への支出は、コロナ前に戻ったのか？

作成：2026-11-16 12:05ごろ（元データを取得しただけで、支出の数字はまだ見ていない段階で書いた）

## 問い
家計が旅行・宿泊・映画やスポーツ観戦・遊園地などの「出かけて使うお金」（レジャー・娯楽のサービス）に払う額は、物価の上がった分を除いても、2019年（コロナ前）に戻ったのか。品目・世帯主の年齢・年間収入によって、戻り方はどれだけ違うのか。

「旅行や外食などのサービス消費は戻った」「値上がりで量は戻っていない」といった見方が、報道や月例経済報告で語られる。観光・娯楽の事業者、消費の分析をする人が、家計の側から見た「量の戻り」を品目と世帯の違いで知りたい。

## 関連する記事との違い
- F336：国内旅行の消費額を「旅行の回数×1回の単価」に分けた（観光庁の調査、旅行者の側）。ここでは家計調査で、旅行以外の娯楽も含め、物価で割った量の戻りと、世帯の年齢・収入の違いを見る。
- F357：サービス業の売上（事業者の側）の実質の戻り。ここでは家計の支出の側。
- F310・F312・F342・F348：同じ家計調査だが、別の品目（新聞・書籍、教育、外食、贈答）。

## データ
- 総務省「家計調査」二人以上の世帯 詳細結果表（年）2015〜2025年：第4-6表（世帯主の年齢階級別）、第4-3表（年間収入五分位階級別）。品目の1世帯当たり年間支出金額。
- 総務省「消費者物価指数」2025年基準 品目別（年平均）。

## 取得前に見たもの（開示）
- 品目の行の場所を確かめるときに、2025年の第4-6表の品目名と分類コードを見た（金額は見ていない）。

## 対象の品目（レジャー・娯楽のサービス）と物価の割り引き方
| 家計調査の品目 | 使う物価指数（CPI 品目） |
|---|---|
| 宿泊料 | 宿泊料 |
| 国内パック旅行費 | 宿泊料（CPI に国内パック旅行がないため代用） |
| 外国パック旅行費 | 外国パック旅行費 |
| 映画・演劇等入場料 | 映画観覧料と演劇観覧料の平均 |
| スポーツ観覧料 | プロ野球観覧料 |
| スポーツクラブ使用料 | フィットネスクラブ使用料 |
| 他のスポーツ施設使用料 | 入場・観覧・ゲーム代（類） |
| 文化施設入場料 | 文化施設入場料 |
| 遊園地入場・乗物代 | テーマパーク入場料 |
| 他の入場・ゲーム代 | 入場・観覧・ゲーム代（類） |
月謝・放送受信料・教養娯楽賃借料などは対象から外す（出かけて使うレジャーでないため）。

実質の戻り率 = (2025年の支出 ÷ 2025年の物価) ÷ (2019年の支出 ÷ 2019年の物価)。合計は、品目ごとの実質の値を足す（2019年の価格で数えた量）。

注意：CPI の外国パック旅行費は、2021〜2023年の価格の調査が止まり、2020年の値で代わりに埋められている。外国パック旅行の実質は2019年と2024・2025年だけで比べる。

## 仮説と「外れ」の基準
- H1：レジャー・娯楽サービスの合計の実質の戻り率（2025年÷2019年）は 0.95 を下回る（戻っていない）。0.95 以上なら外れ。
- H2：品目で差が大きい。外国パック旅行費の実質の戻り率は 0.6 未満。宿泊料と遊園地入場・乗物代は 0.9 以上。どれかが当てはまらなければ、その部分は外れ。
- H3：世帯主が60歳以上の世帯（60〜69歳・70歳以上）の戻り率は、40歳未満の世帯（29歳以下・30〜39歳）より10ポイント以上低い。届かなければ外れ。
- H4：年間収入の第I五分位（収入の低い2割）の戻り率は、第V五分位（高い2割）より10ポイント以上低い。届かなければ外れ。

## 頑健性（3つ以上）
1. すべての品目を CPI の「教養娯楽サービス」（中分類）で割り引く。
2. 基準を2019年だけでなく2017〜2019年の平均にする。
3. 2025年でなく2024年で比べる。
4. 外国パック旅行費を除いた合計で比べる。
5. 世帯人員の違いを除くため、1人あたり（世帯人員で割る）で比べる。

## 言えないこと（予想）
- 単身世帯（二人以上の世帯だけを見る）。
- 1回あたりの値段と回数の分け方（家計調査の購入頻度はサービス品目では限られる）。
- 戻らない理由（好みの変化、時間の使い方、値上がりへの反応）は分けられない。
- 家計調査は標本調査で、品目の細かい値は年ごとに揺れる（標準誤差は公表の表からは分からない）。
