# F415 事前の計画（PLAN）

作成：2026-11-18 10:10（JST）。結果を集計する前に書いた。

## 問い
家電の販売には、制度の締め切りの前に大きな「山」ができた時期があります。家電エコポイント（2009年5月〜2011年3月）、地上アナログ放送の終了（2011年7月）、消費税率の引き上げ（2014年4月・2019年10月）です。山のあとの「谷」は、山と比べてどれだけ深く、どれだけ長かったのか。商品（テレビなどのAV家電・生活家電など）で違ったのか。

## 知りたい人
家電や小売の売上の月次の数字を読む人。前年同月比が大きく動いた月に、「山の反動なのか、需要が弱いのか」を見分けたい人。税や政策の良し悪し・価格の決め方は扱わない（販売の数字の読み方まで）。

## データ

## 手法
- 「平常の年」を、特別な制度や税率の変更の山・谷がないと考える 2007年・2016年・2017年・2018年（計48か月）とする。この48か月で `log(指数) = 定数 + 傾き×月 + 月のダミー` を推定し、2008〜2020年2月の「山も谷もなかった場合」を作る（反事実）。
- 実際÷反事実−1 を月ごとの「上乗せ（マイナスなら不足）」とし、窓の中で足した値を「平常の何か月分」で表す。
- 窓（先に決める）
  - E1 エコポイント・地デジ：山 2009年5月〜2011年7月（27か月）、谷 2011年8月〜2013年9月（26か月、2014年の山の前まで）。谷の最初の12か月も出す。
  - E2 2014年の税率引き上げ：山 2013年10月〜2014年3月（6か月）、谷 2014年4月〜2015年3月（12か月）。最初の5か月も出す。
  - E3 2019年の税率引き上げ：山 2019年4月〜9月（6か月）、谷 2019年10月〜2020年2月（5か月。3月以降はコロナと段差があるため使わない）。
- 戻り率＝谷の不足の合計÷山の上乗せの合計。1なら前倒しがちょうど戻った、1より大きければ山より谷が深い。
- 商品別：家電大型専門店の商品別で、2016〜2018年の36か月から同じ形の反事実を作り、E2（2014年）と E3（2019年）の山・谷を比べる。2014年は後ろに延ばした反事実なので参考とする。
- 地域は使わない。

## 仮説（外れの基準つき）
- H1：E1（エコポイント・地デジ）の山は、E2 と E3 の山を合わせたものより大きい（平常の月数で）。外れ：E2+E3 以下。
- H2：E1 の谷（26か月）の不足は、山の上乗せの半分以上（戻り率 0.5以上）。外れ：0.5未満。
- H3：E2（2014年）の戻り率（12か月）は1以上（谷が山より深い）。外れ：1未満。
- H4：E3（2019年）の山は E2 の山の半分未満。外れ：半分以上。

## 頑健性（3つ以上）
1. 平常の年を 2007年と2016年だけにする（トレンドの置き方が変わる）。
2. 平常の年に 2005・2006年を足す。
3. 季節調整済指数で、平常の年の平均の水準を基準にする（月のダミーを自分で置かない）。
4. 谷の長さを変える（E1：12・26か月、E2：5・12か月）。
5. 業種別商業販売額（金額）で同じ計算をして指数と照合する（段差のない期間だけ）。
6. 家電大型専門店（別の調査対象）で E3 を見て、機械器具小売業と同じ向きか。

## 言えないこと（予想）
- 反事実は「平常の年」の置き方に左右される。山や谷の大きさは幅をもって読む。
- 販売額は金額で、値下がり（テレビの単価の下落など）と台数の動きを分けられない。
- E1 の谷には、東日本大震災（2011年3月）のあとの消費の動きや、テレビの買い替えの周期など、制度以外の理由も混じる。
- 機械器具小売業には家電以外（パソコン・携帯電話・カメラなど）も入る。
- 政策や税率の変更の良し悪しは扱わない。
