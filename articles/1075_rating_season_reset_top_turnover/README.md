# 1075 シーズンの初めに点数を戻すと、上位はどれだけ入れかわるのか？（対戦とレーティング）

対戦ゲームのリーグでは、シーズンの初めに点数を平均に戻したり、半分だけ戻したりすることがあります。戻したあとの序盤の上位表を見て「顔ぶれが大きく変わった」と読むと、本当に強さが入れかわったのか、戻しただけなのかが分かりません。**ここでは、作成者が乱数で作った架空の対戦ゲームのリーグ（1,000人。本当の強さを作成者が置き、シーズンの間に少しだけ変わるもの）で、前のシーズンの終わりの点数を ①そのまま ②半分だけ平均に戻す ③全員1500に戻す の3つで次のシーズンを始め、5・10・25・50・100試合目の上位50人（上位5%）のうち、前のシーズンの上位50人から何人入れかわったか、本当の上位50人に何人入っていたかを、20リーグで数えました。置き方を変えた27通りでも確かめました。**

ここでいう「点数の付け方」は、勝つと点数が上がり、負けると下がり、その幅を「点数の差から見込んだ勝つ確率」で変える一般的なやり方です（実在のゲームや方式を表すものではありません）。

初めの点数をいくつにするかで新しく入った人の順位がずれることは同じ企画の関連する記事 1065、1試合で動かす点の幅の大きさは 1066、力の近い人どうしを当てると勝率が5割に集まることは 1074 で扱っています。前半の成績トップが後半もトップかは 826、2年目に成績が下がって見えることは 830、月間1位が何か月続くかは 831 で扱っています。この記事は、点数を戻すことで上位の入れかわりがどれだけ増えて見えるかに絞ります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A1075 | シーズンの初めに点数を戻すと、上位50人は前のシーズンから何人入れかわって見えるか。本当の強さの入れかわりと比べてどうか | 架空の1,000人。前のシーズンの本当の強さは平均1500・標準偏差200の正規分布、次のシーズンの本当の強さは、それに標準偏差30の正規分布の変化を足したもの。勝つ確率は、強さの差 d から 1÷(1＋10^(−d/400))（差400点で10対1）。点数は1試合ごとに「勝ち（1）か負け（0）−点数の差から見込んだ勝つ確率」に幅 K＝32 を掛けて動かす（相手は同じだけ逆に動く）。毎回全員が1試合ずつ戦い、相手は点数＋ゆらぎ（標準偏差100の正規分布）の順に並べた隣どうし。前のシーズンは全員1500から300試合。次のシーズンの初めの点数は 1500＋c×（前の終わりの点数−1500）で、①c＝1 ②c＝0.5 ③c＝0。次のシーズンは100試合。3つの決め方は同じ乱数で戦わせた。上位50人に同じ点数の人がいるときはくじで決めた。20リーグの平均。確かめとして、1シーズンの試合数（50・100・200）×本当の強さの変化（標準偏差0・30・60）×点の幅 K（16・32・64）の27通りを各5リーグで数えた。seed 1075 | `src/a1075_season_reset.py` |

## 主な結果

### 前のシーズンの上位50人から入れかわった人数（基本、20リーグの平均、`results/by_policy_games.csv`）
| 新しいシーズンの試合数 | ①そのまま | ②半分戻す | ③全員1500に戻す |
|---|---|---|---|
| 5試合目 | 5.7人 | 9.8人 | 34.45人 |
| 10試合目 | 7.7人 | 12.75人 | **28.0人** |
| 25試合目 | 11.6人 | 15.1人 | 22.15人 |
| 50試合目 | 13.65人 | 16.1人 | 17.8人 |
| 100試合目（終わり） | 14.9人 | 16.3人 | **16.55人** |

- 本当の強さの上位50人のうち、シーズンの間に入れかわったのは平均6.85人（20リーグで3〜11人）
- **③全員1500に戻すと、10試合目の上位50人は、前のシーズンの上位50人から平均28.0人が入れかわっていた**（20リーグで23〜32人）。本当の入れかわり（6.85人）の4.09倍で、ほとんどは戻したことと序盤の勝ち負けの偶然による
- 100試合目には、③でも16.55人まで減り、①そのまま（14.9人）に近づいた。戻した分の入れかわりは、試合を重ねると小さくなった
- ①そのままでも、100試合目には14.9人が入れかわっていた。本当の入れかわり（6.85人）の2.18倍で、残りは点数の勝ち負けによる上下（偶然）から来る

### 上位50人のうち本当の上位50人に入っていた人数（基本、20リーグの平均）
| | ①そのまま | ②半分戻す | ③全員1500に戻す |
|---|---|---|---|
| 10試合目 | 38.9人 | 36.6人 | **23.3人** |
| 100試合目（終わり） | **40.35人** | 38.65人 | 37.65人 |

- ③の10試合目の上位50人は、本当の上位50人を23.3人しか含んでいなかった
- シーズンの終わりでも、本当の上位に近いのは①そのまま（40.35人）で、③（37.65人）は2.7人少なかった

### 置き方を変えると（27通り、各5リーグ、`results/grid.csv`）
- ③の10試合目の入れかわりは26〜32.2人、①は3.8〜11.6人。27通りすべてで③が多かった
- シーズンの終わりの入れかわりは、①10.2〜19.6人、②11.2〜20.6人、③11.4〜22.0人。③が①より多かったのは27通り中23通り
- 1シーズン50試合の9通りでは、③のシーズンの終わりの入れかわりは15.4〜22.0人、200試合の9通りでは11.4〜20.0人。試合数が少ないほど、戻した分が終わりまで残った
- 本当の強さが変わらない9通り（本当の入れかわり0人）でも、①のシーズンの終わりの入れかわりは10.2〜16.0人あった
- シーズンの終わりに本当の上位50人をより多く含んだのは、27通り中26通りで①が③以上だった（③が上回ったのは1通り）

### 点数の幅
- シーズンの終わりの点数の標準偏差は、本当の強さの標準偏差の①1.305倍、②1.01倍、③0.913倍だった。点数の近い人どうしを当てると点数の差が広がりやすい（1074 と同じ向き）ので、①は前のシーズンから広がったまま続いた

## 動かし方
```
pip install -r requirements.txt
cd src && python a1075_season_reset.py
```
15〜40秒ほどで終わります。`data/league_example.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約40秒）
- 図3枚を開き、日本語・重なり・軸を確かめた（人数の軸は0〜50人）
- 3つの決め方を同じ乱数で戦わせ、違いが戻し方だけから来るようにした

## データ
- `data/league_example.csv`：基本の置き方の1リーグ目の1,000人（player_id・true_season1・true_season2（本当の強さ）・rating_end_season1（前のシーズンの終わりの点数）・rating_end_season2_そのまま／半分戻す／全員1500に戻す（次のシーズンの終わりの点数））
- `results/a1075_main.json`：主な結果すべて（`headline` に本文で使った丸めた値、`grid_summary` に27通りの幅）
- `results/by_policy_games.csv`：戻し方×試合数ごとの入れかわり（平均・20リーグの最小・最大）と本当の上位の数
- `results/reps_base.csv`：20リーグそれぞれの値
- `results/grid.csv`：27通りの確かめ

## 注意（言えないこと）
- 架空のデータです。強さの散らばり、シーズンの間の強さの変化、勝つ確率の式、点の幅、組むときのゆらぎ、試合数は作成者が置いたもので、結果はこれで決まります。10試合目の③の入れかわりは置き方で26〜32.2人、シーズンの終わりの入れかわりは10.2〜22.0人と動きました
- 全員が毎回1試合ずつ、同じ回数戦うと置きました。シーズンの初めにだけ多く戦う人、途中でやめる人がいると、序盤の上位はさらに偏ります（推測）
- 「上位50人」という区切りは作成者が置いたものです
- 実在の対戦ゲームの戻し方や点数の付け方を表すものではありません。どの戻し方がよいかの助言ではなく、戻し方で上位の入れかわりがどう見えるかを数えただけです
