# 248 観光目的の客が多い施設は、季節の山が大きいのか

宿泊旅行統計調査は、施設を「観光目的の宿泊者が50%以上」（観光の宿）と「50%未満」（出張などの宿）に分けて集計しています。この2つで、月ごとの宿泊者数の山と谷（季節の山）の大きさを比べ、2015〜2019年と2023〜2025年で変わったかを見ました。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A248 | 観光目的の客が多い施設は、季節の山が大きいのか | 月の1日あたり延べ宿泊者数を年平均で割った指数の、ばらつき（標準偏差）と最大÷最小を、施設の区分×日本人・外国人で年ごとに計算／観光の宿の山が小さくなった分を、日本人・外国人の月の形と外国人の割合に分ける | `src/a248_seasonality.py` |

## 主な結果
- 2015〜2019年の平均で、月の指数のばらつきは、観光の宿の日本人0.187、出張などの宿の日本人0.072（2.6倍）。施設全体（外国人を含む）では0.151と0.068（2.2倍）
- 観光の宿の日本人は8月が年平均の1.56倍（2015〜2019年）、出張などの宿の日本人は1.16倍。最も少ないのはどちらも1月（0.82・0.84）
- 2023〜2025年は、観光の宿の日本人の8月が1.41倍に下がった。ばらつきは0.187→0.149
- 8月を除いた11か月のばらつきは、観光の宿の日本人で0.078（2015〜2019年）→0.082（2023〜2025年）と変わっていない。小さくなったのは8月の山だった
- 観光の宿（施設全体）のばらつきは、2015年0.166、2019年0.121、2025年0.093。延べ宿泊者数に占める外国人の割合は15.2%（2015年）→25.6%（2019年）→33.2%（2025年）。外国人は8月に山がなく、10〜12月と4月が多い
- 2019→2025年の観光の宿のばらつきの低下（0.121→0.093）を分けると、日本人・外国人の月の形を2019年のままにして外国人の割合だけ2025年にすると0.110、割合を2019年のままにして月の形だけ2025年にすると0.107。どちらか一方だけでは説明しきれず、外国人の割合で低下分の約4割、月の形の変化で約5割を説明する（2つの順番で数字は変わる）
- 出張などの宿のばらつきは、2015年0.078→2025年0.064で、もともと小さく大きくは変わっていない

## 頑健性
- ばらつきの代わりに「最大の月÷最小の月」で見ても同じ：観光の宿の日本人1.91倍→1.74倍、出張などの宿の日本人1.37倍→1.33倍（期間の平均）
- 定員稼働率の月の幅（最大−最小）でも、観光の宿は20.5ポイント（2015年）→12.5ポイント（2025年）、出張などの宿は16.4→10.5ポイント（`results/a248_capacity_occupancy_range.csv`）
- 2020〜2022年はコロナで月の形が大きく崩れたので、期間の比較から除いた
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致することを確かめた

## 動かし方
```
pip install -r requirements.txt
cd src && python a248_seasonality.py   # data/ の CSV から results/・figures/ を作る
python fetch.py             # data/ の CSV を観光庁の Excel から作り直す（任意。ネットにつながる環境で）
```

## データ
- `data/table<n>_national.csv`：観光庁「宿泊旅行統計調査」各年（2015〜2025年）の「1月〜12月分（年の確定値）集計結果」Excel から、全国の行だけを取り出したもの（`src/extract.py`）。month=0 は年計、1〜12 は各月。列名は `src/extract.py` の COLS（total＝総数、tour＝観光目的の宿泊者が50%以上の施設、biz＝同50%未満の施設、s0_9 など＝従業者数の区分、foreign＝うち外国人）
- 施設数（第1表）は各月の値で、年の値は12か月の平均にした

## 注意
- 観光の宿・出張などの宿は、施設ごとに「観光目的の宿泊者が50%以上か」で分けた調査の区分で、宿泊者一人ひとりの目的ではない。年によって施設が別の区分に移ることがある
- 区分が分からない施設があるため、2つの区分の合計は総数と少し違う
- 2023年は外国人の戻りの途中で、外国人の月の形が大きく揺れた（ばらつき0.213）
- 季節の山が小さくなった理由（夏休みの分散、暑さ、値段など）は、この表からは分からない
