# 361 予測の良し悪しは、物差しを変えるとどれだけ順位が入れ替わるのか

予測の誤差を測る物差し（MAPE・MAE・RMSE・MASE）を変えると、「どのモデルがいちばん良いか」がどれだけ入れ替わるかを、架空の商品500本で数えたフォルダです。F231・F259（需要予測）とは違い、誤差の測り方だけを比べます。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A361 | 物差しを変えると、1位のモデルが変わる商品は何割あるか。需要が小さい商品で MAPE はどう壊れるか | 架空の日次需要500本（よく売れる250本・たまに売れる250本）に5つの単純な予測を当て、最後の56日の1日先予測を MAPE・MAE・RMSE・MASE で順位づけ | `src/a361_metric_ranking.py` |

## データの作り方（架空）
- 日次の需要を728日分。曜日の山とゆるい伸びがあり、ばらつきは負の二項分布
- よく売れる商品250本：1日の平均が20〜200個。たまに売れる商品250本：1日の平均が0.1〜2個（0の日が多い）
- 乱数の種は361。実在の商品・会社の数字ではありません

## 比べた5つの予測（どれも1日先を当てる）
前日の値／7日前の値／直近28日の平均／指数平滑（α=0.2）／同じ曜日の平均（直近8週）

## 物差し
- MAPE：誤差÷実績の平均（%）。実績が0の日は計算できないので除く
- MAE：誤差の大きさの平均。RMSE：誤差の2乗の平均の平方根
- MASE：MAE を、学習期間の「7日前の値」の誤差で割ったもの（1より小さければ、7日前の値より良い）

## 主な結果
### 商品ごとに1位のモデルを選ぶと
| 物差しの組 | よく売れる商品（250本） | たまに売れる商品（250本） |
|---|---|---|
| MAPE と MAE で1位が違う | 11.2% | 55.2% |
| MAPE と RMSE で1位が違う | 10.4% | 60.0% |
| MAE と RMSE で1位が違う | 13.6% | 61.2% |
| MAE と MASE で1位が違う | 0% | 0% |
| MAPE・MAE・RMSE がすべて同じ1位 | 82.8% | 24.0% |

- **よく売れる商品では、物差しを変えても1位はほとんど変わらない**（変わるのは10〜14%）
- **たまに売れる商品では、55〜61%で1位が変わった**。RMSE で選ぶと80%の商品で「直近28日の平均」が1位、MAE で選ぶと「同じ曜日の平均」30%・「直近28日の平均」29%・「指数平滑」17%・「前日の値」13%・「7日前の値」11%に割れた
- **MAE と MASE は、1つの商品の中では必ず同じ順位になる**（MASE は MAE を商品ごとの定数で割っただけ）。違いが出るのは、商品をまたいで平均するとき

### 需要が小さい商品で起きること
- たまに売れる商品は、確かめた56日のうち実績が0の日が中央値で68%。**80%の商品で、半分以上の日が MAPE を計算できなかった**
- **たまに売れる商品の82%で、「いつも0」と予測するほうが、MAE では5つのどのモデルよりも良かった**。MAE は真ん中の値（0）に寄せた予測を良いと判定する
- MAPE は「実績が0でない日」だけで計算するので、「いつも0」の MAPE は100%になる。たまに売れる商品のモデル×商品の6.5%は、それより悪い100%超だった

### 500本をまとめて1つのモデルを選ぶと
- MAPE・MAE・RMSE・MASE の平均・中央値の8通りすべてで、「同じ曜日の平均」が選ばれた（今回のデータでは結論は同じ）
- ただし中身は違う：MAPE の合計の57%はたまに売れる商品から、RMSE の合計の42%は誤差の大きい上位50本（すべてよく売れる商品）から来ていた

## 注意（言えないこと）
- すべて架空のデータです。割合は、置いた需要の大きさ・ばらつき・5つのモデルの選び方で変わります
- 5つのモデルはどれも単純なものです。機械学習のモデルどうしの比べではありません
- 1日先の予測だけを確かめました。先の期間が長い予測では、順位の入れ替わり方は違うかもしれません
- 「いつも0」が MAE で勝つのは、0の日が半分を超える商品の性質です。在庫の判断に使う物差しとしてどれがよいかは、欠品と持ちすぎの損で決まります（363で扱います）
