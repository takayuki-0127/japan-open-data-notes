# 658 ゼロを含むデータを log(y+c) で回帰すると、c の選び方で係数はどれだけ変わるのか（手法の解説・正解の分かるデータで試す）

売上個数のようにゼロを含むデータを対数で回帰するとき、log(0) が出せないので、log(y+1) のように小さな数 c を足すことがよくあります。この c は、ゼロの多いデータでは結果を大きく変えます。**ここでは、施策のあった日に売上の平均が本当に1.35倍（+35%）になる架空の商品×日の売上個数（負の二項分布）で、ゼロの日の割合を2%〜89%に変え、log(y+c) の回帰とポアソン回帰の推定を各500回比べました。** 数字は置いた前提で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A658 | c の選び方で、施策で増えた割合の推定がどれだけ変わるか | log(y+1)・log(y+0.5)・log(y+0.1)・log(y+0.01) の OLS、ポアソン回帰（statsmodels）。n=2,000、各設定500回。seed 658 | `src/a658_logc.py` |

## 主な結果
- **ゼロの日が4割（42%）のとき**：本当の +35% に対して、log(y+1) は **+14%**、log(y+0.5) は +20%、log(y+0.1) は +36%、log(y+0.01) は **+63%**。ポアソン回帰は +35%
- **ゼロが多いほどばらつく**：ゼロ89%では log(y+1) +2%・log(y+0.01) +15%。ゼロ2%では +32%〜+39% と、どれも本当の値に近い
- **c を小さくすれば正しくなるわけではない**：log(y+0.01) はゼロ25%で +66% と大きく出すぎる。c で推定が動くのは、ゼロと1の差を「log の目盛りでどれだけ離すか」を c が決めるため
- **同じ1つのデータでも**：ゼロ61%のデータで c を 0.0001〜10 に動かすと、推定は +1.8% から +136% まで動いた
- **ポアソン回帰**：どの設定でも +34.5%〜+35.6%（ばらつきの大きいデータでも、平均の比は当てられる）
