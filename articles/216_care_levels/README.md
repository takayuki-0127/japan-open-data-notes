# 216 要支援・要介護の内訳18年：介護保険事業状況報告（年報）

厚生労働省「介護保険事業状況報告（年報）」の全国計で、2007〜2024年度末の要介護（要支援）認定者数を要介護度別に並べ、内訳（構成比）がどう変わったかを見たフォルダです。要支援1・2に分かれた2006年度の制度改正の後、2007年度から揃えています。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A216 | 認定者の内訳は軽い方・重い方のどちらに寄ったか | 要介護度別の構成比の推移、2007年度末＝100の指数、年平均増加率。第1号の認定率（第1号認定者÷第1号被保険者）と、第1号認定者に占める85歳以上の割合（2014年度〜） | `src/a216_care_levels.py` |

## 主な結果
- 認定者は2007年度末の452.9万人から2024年度末は720.7万人（+59.1%）。第1号被保険者（65歳以上）の伸び（+30.3%）の約2倍
- 伸びが大きいのは要支援1（指数193）と要介護1（193）、小さいのは要介護5（116）。要介護5は2012年度の61.1万人が最多で、2024年度は57.8万人
- 軽度（要支援1・2＋要介護1）の割合は43.0%→49.7%、重度（要介護3〜5）は39.3%→33.4%
- 第1号の認定率は15.9%→19.7%。第1号認定者のうち85歳以上は2014年度48.4%→2024年度56.0%
- 65〜74歳の認定者は64.8万人でほぼ横ばい、75歳以上は373.0万人→642.8万人

## 動かし方
```
pip install -r requirements.txt
cd src && python a216_care_levels.py
```

## データ
- `data/care_levels_national_2007_2024.csv`：年度×区分（tot＝総数、d1＝第1号被保険者、d2＝第2号被保険者、a65_74、a75p、a85p＝85歳以上〔2014年度〜〕）×要介護度。各年度の年報「全国計」Excelの第4表（2014年度以降は第4-1表の男女計）から集計。経過的要介護（2007・2008年度のみ）は分析では要介護1に含めた
- `data/insured_65plus_2007_2024.csv`：第1号被保険者数（年度末、第2表）

## 注意
- 認定者数は年度末時点の人数で、サービスを使った人数ではありません
- 構成比の変化には、高齢化のほか、認定基準・認定調査の運用、早めに申請する人の増え方なども影響し、このデータでは分けられません
- 年齢区分は2013年度まで65〜74歳・75歳以上の2区分、2014年度から5歳刻みです。年齢別の被保険者数がないため、年齢別の認定率は計算していません
