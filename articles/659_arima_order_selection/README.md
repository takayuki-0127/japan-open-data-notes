# 659 ARIMA の次数を AIC で選ぶと、本当の次数を何%で当て、予測はどれだけ悪くなるのか（手法の解説・正解の分かるデータで試す）

時系列のモデル ARIMA の次数（p・q）は、AIC や BIC が小さいものを選ぶのがよくあるやり方です。**ここでは、本当の形が分かっている ARMA(1,1)（φ=0.6、θ=0.4）の系列を、長さ48・120・240期で100本ずつ作り、9通りの次数（p・q とも0〜2）から AIC・BIC で選んだとき、本当の次数を何%で当てるか、12期先までの予測がどれだけ悪くなるかを数えました。** 数字は置いた系列の形と長さで決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A659 | AIC・BIC は本当の次数を何%で選び、外したときの予測はどれだけ悪くなるか | statsmodels の ARIMA(p,0,q)（定数項あり）を9通り当てて AIC・BIC で選ぶ。選んだ次数・本当の次数・いつも AR(1) で12期先まで予測し RMSE を比べる。各長さ100回。seed 659 | `src/a659_arima_ic.py` |

## 主な結果
- **本当の次数(1,1)を選んだ割合**：48期で AIC 24%・BIC 19%、120期で **48%・58%**、240期で58%・74%
- **外れ方**：120期の AIC は、AR(2) を23回、パラメータの多いもの（合計3つ以上）を24回選んだ。48期の BIC は49%でパラメータの少ないものを選んだ
- **予測への影響は小さい**：120期で、AIC で選んだ次数の12期先までの誤差は本当の次数より +0.5%、1期先では −0.5%（100回では差が見分けられない程度）
- **いつも AR(1)** にすると、120期の1期先の誤差は本当の次数より **+9.2%**。ただし48期・240期では +0.6%・+0.2% で、差ははっきりしない

## 動かし方

```
pip install -r requirements.txt
cd src && python a659_arima_ic.py
```
2〜3分かかります（ARIMA を2,700回当てる）。
