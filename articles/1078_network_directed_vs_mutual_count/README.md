# 1078 双方向で数えるか片方向で数えるかで、つながりの数は何倍違うのか？（つながり）

社内の連絡の記録から「つながりの数」を数えるとき、Aさんが Bさんに送ったことを1本と数えるのか、AさんとBさんの両方が送り合ったときだけ1本と数えるのかで、数は大きく変わります。人ごとに「送った相手＋受けた相手」を足すと、送り合った相手を2回数えることにもなります。**ここでは、作成者が乱数で作った架空の会社（社員400人・10部署）の1か月の社内の連絡（誰から誰へ何通送ったか）で、つながりを5通りに数えて何倍違うかを数え、「つながりの多い人」の上位10人が数え方でどれだけ入れかわるかも数えました。連絡の量・人ごとの送りやすさの差・組ごとの仲の良さの差を変えた27通りでも確かめました。**

会社・社員・連絡はすべて架空のもので、実在の会社や連絡の道具の数字は使っていません。社員は番号だけで表し、人を属性で比べることはしていません。

## 主な結果

### 5通りの数え方（1人あたり、50回の平均、`results/ways.csv`）
| 数え方 | 1通以上で数える | 両方向の何倍 | 3通以上で数える | 両方向の何倍 |
|---|---|---|---|---|
| 両方向とも送った相手 | **5.96人** | 1 | 0.6人 | 1 |
| 送った相手 | 23.27人 | 3.915 | 2.09人 | 3.518 |
| 受けた相手 | 23.27人 | 3.915 | 2.09人 | 3.518 |
| どちらか一方でも送った相手 | **40.58人** | **6.829** | 3.59人 | 6.036 |
| 送った相手＋受けた相手（足し算） | 46.53人 | 7.829 | 4.19人 | 7.036 |

- 1人あたり1か月に33.99通送る置き方で、どちらか一方でも送った相手は両方向とも送った相手の6.829倍だった
- この倍率は、送った向きのうち相手からも送られていた割合（25.58%）からの式 (2−r)÷r どおりで、50回すべてで一致した（差0.0）。データから見つけたものではない。何倍違うかは、送り合う相手の割合だけで決まる
- 送った相手と受けた相手は、全体の平均では必ず同じ（送った1通は誰かが受けた1通）
- 「送った相手＋受けた相手」を足すと、送り合った相手を2回数えるので、どちらか一方の1.146倍になった（式 1＋1÷6.829 どおり）。社員ごとの「どちらか一方」を全員分足すと、組の数のちょうど2倍（2.0倍）になる。1つの組を両方の人が数えるため
- 社員ごとに見ると、どちらか一方÷両方向は中央値7.447倍。両方向とも送った相手が1人もいない社員が5.29%いた
- 3通以上送った向きだけを数えると、どちらか一方は3.59人、両方向は0.6人に減り、倍率は6.036倍、相手からも送られていた割合は28.62%だった

### 上位10人の入れかわり（50回の平均）
| 比べた2つの数え方 | 上位10人の重なり |
|---|---|
| 送った相手 と 受けた相手 | **1.88人** |
| 送った相手 と どちらか一方 | 5.56人 |
| 受けた相手 と どちらか一方 | 5.7人 |
| 両方向 と どちらか一方 | 6.42人 |

- 送った相手の数と受けた相手の数で、上位10人は平均1.88人しか重ならず、1位が同じだった回は2.0%だった（順位の相関0.432）
- ただし、これは送りやすさと受けやすさの相関を0.5と置いたことでほぼ決まる。相関を0にすると重なりは0.1人、0.8で4.0人、0.95で6.3人になった（各10回、`results/rho_check.csv`）

### 確かめ：27通り（各10回、`results/grid.csv`）
- どちらか一方÷両方向は3.668〜14.432倍。相手からも送られていた割合は13.0〜42.85%で、27通りすべてが式 (2−r)÷r の線の上にのった（図2）
- 倍率をいちばん大きく動かしたのは連絡の量で、量0.2では7.843〜14.432倍、0.5では5.352〜8.506倍、1.5では3.668〜5.711倍だった。連絡が少ないと、片方からしか送っていない組が多く残る
- 送った向きの数÷どちらか一方の組は1.069〜1.273倍（式どおり、上限は2倍）
- 送った相手と受けた相手の上位10人の重なりは0.6〜2.3人、両方向とどちらか一方の重なりは2.5〜7.7人だった

## 注意（言えないこと）
- 架空のデータです。社員と部署の数、仲の良さ・送りやすさ・受けやすさの分布と相関、連絡の量は作成者が置いたもので、結果はこれで決まります。どちらか一方÷両方向は置き方で3.668〜14.432倍と動きました。実在の会社の連絡を表すものではありません
- 返事は、仲の良さを通じて間接に入っているだけで、「受けたら返す」動きは入れていません。返事の多い職場では、相手からも送られる割合が上がり、倍率は小さくなると考えています（推測）
- 1対多の一斉の連絡（全員あての連絡）は入れていません。一斉の連絡を「送った相手」に数えると、送った相手の数は大きく増えます（推測）
- どの数え方が正しいかは、何を知りたいかで決まります。ここでは、数え方で数と顔ぶれがどれだけ違うかだけを数えました。人の評価には使えません
