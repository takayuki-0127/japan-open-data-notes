# F374 PLAN（事前の計画）：家具やインテリアへの支出は、引っ越しの多い年齢で多いのか？

作成：2026-11-16 15:20（データを取得し、表の形を確かめたあと、年齢別・月別の集計や移動率との比較をする前に書いた）

この記事は予備 R17 から作った（元の F374「ペットにかけるお金は、世帯のどの年齢で増えたのか？」は既存の F352 と同じ問いになるため。REPLACED.md に記録）。

## 問い
引っ越しをすると、家具やカーテン、照明、寝具をそろえることが多いはずです。そうなら、家具・インテリアへの支出は、引っ越しの多い年齢の世帯で多く、引っ越しの多い3〜4月に多くなるはずです。

知りたいこと：家具・インテリアへの1世帯当たりの支出は、世帯主の年齢でどう違うのか。それは年齢別の引っ越しの多さ（移動率）と重なるのか。月別に見ると、3〜4月に増えるのか。家具の支出全体のうち、どの年齢の世帯の分が大きいのか。

知りたい人：家具・インテリアの小売りや住まいの関連の販売・企画の担当、家計の統計を読む人。

既存の看板記事との違い：F452 は引っ越しの3〜4月への集中（住民基本台帳の移動の季節性）を扱い、家計の支出は扱っていない。jodn の F210・F286 は家具・家事用品を費目の1つとして物価や節約の文脈で扱うだけ。existing_F_titles.txt と jodn の README を「家具」「インテリア」「引っ越し」「移動」で検索して、同じ問いの記事はなかった。

## データ
- 総務省「家計調査」家計収支編 二人以上の世帯 年報（家具・家事用品）2013〜2024年の各年：世帯主の年齢階級別（29歳以下〜70歳以上）と月別の1世帯当たり支出金額。2025年は第4-6表（年齢別、5歳ずらしの再掲の年齢区分あり、世帯数分布あり）。
- 「家具・インテリア」＝一般家具（たんす、テーブル・ソファー、食器戸棚など）＋室内装備・装飾品（照明器具、カーテン、敷物など）＋寝具類（ベッド、布団など）とする。
- 総務省「住民基本台帳人口移動報告」2024年 年齢（5歳階級）別の都道府県内移動率・他都道府県への転出者の移動率、長期時系列表の月別移動者数（都道府県内＋都道府県間）。

## 取得前に見たもの（開示）
- 表の形を確かめるときに、2024年の家具・家事用品の表で、平均と年齢別（一般家具は29歳以下13,444円、70歳以上3,618円など）、月別（一般家具の1〜12月の値。3月736円、4月316円など）の値を目にした。2024年の一般家具では、3〜4月の山がはっきりしないことを知っている。ほかの年、合計した「家具・インテリア」、移動率との比較は計算していない。

## 仮説と「外れ」の基準
- H1：家具・インテリアの1世帯当たり年間支出（2013〜2025年の平均）は、世帯主29歳以下と30〜39歳が上位2つ。そうでなければ外れ。
- H2：世帯主の年齢別（6区分）の家具・インテリアの支出と、同じ年齢の移動率（都道府県内＋他県への転出、2024年）の相関は0.8以上。0.8未満なら外れ。
- H3：月別の家具・インテリアの支出（2013〜2024年の平均、月平均＝1）は、3月と4月の平均で1.2以上。1.2未満なら外れ。
- H4：月別の家具・インテリアの支出（同じく12か月の形）と、月別の移動者数（都道府県内＋都道府県間、2013〜2024年の平均の形）の相関は0.5以上。0.5未満なら外れ。

## 手法
- 年報の表から、品目番号（480〜489 一般家具、491〜499 室内装備・装飾品、500〜509 寝具類）の列を探し、年齢別・月別の金額を取り出す。
- 年齢別：各年の値を名目のまま平均する（2013〜2025年）。移動率は5歳階級を10歳にまとめる（2つの平均）。29歳以下は20〜24歳と25〜29歳、70歳以上は70〜74歳から85歳以上までの平均を使う。
- 月別：各年の月の値を、その年の月平均で割り（月平均＝1）、12年で平均する。移動者数も同じ。

## 頑健性（3つ以上）
1. 家具・インテリアの代わりに一般家具だけで H1〜H4 を見る。
2. 2025年の5歳ずらしの年齢区分（25〜34歳、35〜44歳など）で H2 を見る。
3. 2020〜2021年を除いて H3・H4 を見る（外出の制限があった年）。
4. 移動率を都道府県内だけ、他県への転出だけにして H2 を見る。

## 問い直し（予定）
結果を見てから1つ足す。候補：1世帯当たりでなく、世帯数を掛けた「家具・インテリアの支出の総額」では、どの年齢の世帯の分が大きいのか（2025年の世帯数分布を使う）。

## 言えないこと（予定）
- 二人以上の世帯だけで、単身の世帯（若い人の引っ越しに多い）は入っていない。
- 世帯主の年齢と、引っ越した人の年齢は同じではない（家族の引っ越しなど）。
- 住民基本台帳の移動は市区町村をまたぐもので、同じ市区町村の中の引っ越しは入っていない。
- 家計調査の月別の値は標本が少なく、品目によって振れが大きい。
- 引っ越した世帯だけの支出は分からない（引っ越したかどうかは家計調査にない）。
