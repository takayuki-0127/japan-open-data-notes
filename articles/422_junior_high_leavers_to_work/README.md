# 422 中学校を出てすぐ働く人は、いつ、ほとんどいなくなったのか（学校基本調査 年次統計、1950〜2025年）

学校基本調査の年次統計から、中学校卒業者のうち就職した人の割合（男女別）と卒業者数を1950年から2025年まで並べたフォルダです。340（高校への進学率）の裏側の数字にあたります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A422 | 中学校を出て就職する人の割合と人数は、いつ、どれだけ減ったか | 総括表5の割合（計・男・女）がはじめて下回った年。割合×卒業者数で人数を概算。1963→1975年の減りを「卒業者の数」と「割合」に分ける。高校卒の就職者と比べる | `src/a422_junior_high_work.py` |

## 主な結果
- 就職した人の割合：1950年 45.2% → 1952年 47.5%（最高）→ 1960年 38.6% → 1970年 16.3% → 1975年 5.9% → 1980年 3.9% → 2000年 1.0% → 2025年 0.2%。この表（1950年〜）では5割を超えた年はない
- はじめて下回った年：4割 1959年、3割 1964年、2割 1969年、1割 1973年、5% 1977年、1% 2002年
- 10年ごとの下がり：1950年代 −6.6ポイント、1960年代 −22.3、1970年代 −12.4、1980年代 −1.1
- 人数（割合×卒業者数の概算）：1950年 約72万人、1957年 約86.5万人（最多）、1963年 約76万人、1970年 約27万人、1975年 約9万人、2025年 約2千人。1950〜75年の合計は約1,420万人
- 1963→1975年に減った約67万人のうち、割合が下がった分が約51万人、卒業者が減った分が約17万人
- 男女の差は小さい（最大でも1953年の4.2ポイント）。1980年以降は男のほうが高く、1%を切ったのは女1995年、男2008年
- 高校を出て就職した人（概算）が中学校を出て就職した人を上回ったのは1961年

## 確かめたこと
- 「中学校卒業者」だけの割合と、義務教育学校などを含めた割合の差は最大0.1ポイント
- 割合は小数第1位までなので、人数の概算には±0.05ポイント分の幅がある（1957年で±約1,000人、2025年は1,600〜2,600人）
- 空のフォルダで流し直し、results・figures が一致した

## 注意（言えないこと）
- 人数は「割合×卒業者数」の概算で、調査の就職者数そのものではありません
- 学校基本調査の「就職者」には、働きながら定時制などに進んだ人（就職進学者）を含むのがふつうです。この表の注には書かれていないため、ここでは確かめられていません（推測）
- 1951〜66年は、盲学校・聾学校・養護学校の中学部の卒業者を含みません（表の注）
- 1950年より前の数字は、この表にはありません
- 就職が減った理由（家計・高校の数・求人など）は分けていません。就職した人のその後も、この数字からは分かりません
