# 1109 効き目が試す場所によって違うとき、1か所の結果はどこまで当てはまるのか？（試作と実験）

新しいやり方を試すとき、段取りのしやすい1か所（たとえば本社の工場）で試し、その結果をほかの場所にも当てはめることがあります。けれども、効き目が場所の事情（湿度など）で変わるなら、1か所で確かめた効き目はその場所の効き目で、ほかの場所や全体の平均とは別の数です。しかも1か所で枚数を増やすほど、結果の幅（95%の幅）は狭くなり、その場所の効き目にだけ近づいていきます。**ここでは、作成者が乱数で作った架空の印刷会社の工場12か所（新しい乾かし方が印刷のにじみの幅をどれだけ減らすか。効き目は工場の湿度で変わり、さらに工場ごとの説明できない違いがあると作成者が置いたもの）で、本社工場1か所・でたらめに選んだ1か所・同じ枚数を4か所に分けた場合の結果の95%の幅に、ほかの工場の効き目と12工場の平均の効き目が入る割合を2,000回ずつ数えました。工場ごとの違いと湿度での変わり方を変えた16通りの確かめも行いました。**

例の会社と工場は架空のもので、実在の会社・工場の数字ではありません。にじみの幅は機械で測った値と置いています（人の目で採点した値ではありません）。

関連する記事：694「A/B テストを3日だけで止めると、曜日で効き方が違うとき、効果の推定はどれだけずれるのか」は、効き方が曜日で違うときに、試した日の偏りで見積もりがずれることを扱います。1050「小さな町の数字を大きな町に当てはめると、規模の違いでどれだけずれるのか？」は、小さな町の1人あたりの数字を大きな町に当てはめたときのずれを扱います。同じ企画の 1103「同じ日の分をまとめて比べると、ばらつきはどれだけ減るのか？」は、日による振れを差から消すことを扱います。この記事は、効き目そのものが場所で違うときに、1か所の結果がほかの場所と全体の平均にどこまで当てはまるかに絞ります。

## 主な結果

### 置いた効き目（2,000回の平均、`results/a1109_main.json` の true_effects）
| | 効き目 |
|---|---|
| 本社工場（工場K、湿度72%） | 16.047µm |
| 12工場の平均 | 9.984µm |
| いちばん小さい工場 | 1.802µm |
| いちばん大きい工場 | 18.191µm |
| 本社工場の半分に届かない工場の割合 | 37.03% |

### 1つの乾かし方20枚ずつ（`results/coverage_by_sheets.csv`）
| 試し方 | 見積もり−12工場の平均（平均） | 95%の幅（±） | 試した工場の効き目が幅に入った | ほかの工場の効き目が幅に入った | 12工場の平均が幅に入った |
|---|---|---|---|---|---|
| 本社工場1か所 | **+6.126µm** | 3.719µm | 95.05% | 27.36% | **19.05%** |
| でたらめな1か所 | −0.082µm | 3.719µm | 95.1% | 34.68% | 47.7% |
| 4か所に分け、①1枚ごとのばらつきだけで幅 | — | 3.719µm | — | 45.64% | 82.05% |
| 4か所に分け、②4か所の散らばりから幅 | — | 9.552µm（平均） | — | 84.63% | **96.5%** |

- 試した工場の効き目が幅に入る割合は、どの試し方でも約95%だった（式どおり）。1か所の結果は、その工場の効き目には当てはまる
- 本社工場は湿度が高く、効き目の大きい工場だったので、見積もりは12工場の平均より平均+6.126µm大きく、12工場の平均が幅に入ったのは19.05%だった
- でたらめに選んだ1か所なら見積もりは平均ではずれない（−0.082µm）が、外れの大きさの平均は4.362µmで、12工場の平均が幅に入ったのは47.7%だった
- 4か所に分けた見積もりの外れの大きさの平均は2.216µmだった。ただし①1枚ごとのばらつきだけで幅を出すと、工場ごとの違いが幅に入らず、12工場の平均が入ったのは82.05%だった。②4か所の散らばりから幅を出すと96.5%で、そのかわり幅は±9.552µmと広かった

### 枚数を増やすと（1つの乾かし方の合計枚数、`results/coverage_by_sheets.csv`）
| 試し方 | 20枚 | 80枚 | 320枚 |
|---|---|---|---|
| 本社工場1か所：12工場の平均が幅に入った | 19.05% | 2.55% | **0.25%** |
| 本社工場1か所：ほかの工場が幅に入った | 27.36% | 13.68% | 6.82% |
| でたらめな1か所：12工場の平均が幅に入った | 47.7% | 26.3% | 12.7% |
| 4か所・①1枚ごとのばらつきだけ：12工場の平均が幅に入った | 82.05% | 57% | 32.05% |
| 4か所・②4か所の散らばりから：12工場の平均が幅に入った | 96.5% | 96.4% | 97.15% |
| 4か所・②の95%の幅（±、平均） | 9.552µm | 8.201µm | 7.917µm |

- 1か所で枚数を16倍（20→320枚）にすると、95%の幅は±3.719µmから±0.93µmに狭くなり、12工場の平均が入る割合は19.05%から0.25%に下がった。幅が狭くなっても、近づく先はその工場の効き目で、12工場の平均ではない
- ②の幅は枚数を増やしても±7.917µmより狭くならなかった。4か所の工場どうしの違いが幅の大部分を占めるため

### 確かめ：工場ごとの違いと湿度での変わり方（16通り、20枚ずつ、各2,000回、`results/grid.csv`）
| 試し方 | 12工場の平均が幅に入った割合（16通りの範囲） |
|---|---|
| 本社工場1か所 | **0〜94.4%** |
| でたらめな1か所 | 25.7〜94.55% |
| 4か所・①1枚ごとのばらつきだけ | 57.05〜95.3% |
| 4か所・②4か所の散らばりから | 94.1〜97.9% |

- 工場ごとの違いがなく、湿度でも変わらない（効き目がどの工場も同じ）ときだけ、本社工場1か所でも94.4%入った
- 湿度で変わらなくても、工場ごとの説明できない違いが4µmあると、本社工場1か所で61.45%、でたらめな1か所で62.35%だった
- 湿度1%あたり1µm変わると、本社工場1か所では0〜2.6%だった

- 試した工場の効き目が95%の幅に入る割合が、どの試し方・枚数でも約95%（94.6〜95.35%）になることを確かめた

## データ
- `data/factories.csv`：12工場（factory・humidity（湿度）・true_effect_world1（1回目の世界の本当の効き目）・true_effect_mean_2000（2,000回の平均））
- `data/hq_sheets_world1.csv`：1回目の世界で本社工場が20枚ずつ刷った記録（factory・method・sheet・bleed_um（にじみの幅））。今の乾かし方の平均を40µmと置いた
- `results/a1109_main.json`：主な結果すべて（置いた効き目、枚数ごと、16通りの範囲、1回目の世界の例）
- `results/coverage_by_sheets.csv`：枚数ごと・試し方ごとの幅に入った割合
- `results/grid.csv`：16通りの確かめ

## 注意（言えないこと）
- 架空のデータです。効き目の大きさ、湿度での変わり方、工場ごとの違い、1枚ごとのばらつき、本社工場の湿度は作成者が置いたもので、結果はこれで決まります。本社工場1か所の幅に12工場の平均が入る割合は、置き方で0〜94.4%と動きました
- 本社工場の見積もりが大きく出たのは、本社工場を湿度の高い（効き目の大きい）工場に置いたためです。湿度の低い工場に置けば、逆に小さく出ます
- 工場の湿度は1か所1つの値とし、日や季節で変わることは入れていません
- 4か所はでたらめに選びました。選び方が偏ると（たとえば湿度の高い工場ばかり）、②の幅でも平均は入りにくくなります
- 実際の印刷の条件や工場を表すものではなく、どの乾かし方を使うべきかは言えません
