# F148 会社は「休眠」をはさんでどう移り変わるのか？ 多状態の生存モデル

看板記事 F148。note：「会社は「休眠」をはさんでどう移り変わるのか？…」（下書き）

## 問い
法人の登記がなくなる道は、自分で清算を終えるもの（清算の結了など）、ほかの会社への合併、そして「登記官による閉鎖」の3つに分かれる。登記官による閉鎖は、解散したまま放っておかれた登記記録や、休眠会社のみなし解散のあとの記録を登記官が閉じるもので、「休眠」をはさんだ道にあたる。閉じられた登記記録が「復活」して戻ることもある。法人はこの状態の間をどう移り変わったのか。

## データ
- 国税庁「法人番号公表サイト」全件データ（CSV・Unicode・全国、2026年10月30日更新、585万法人）。
- 法人名・法人番号・住所は使わず、公開もしていない。`data/raw/` は、種別・都道府県・地域（東京23区／政令市／その他）・閉鎖の年月・閉鎖の事由ごとの件数の表だけ。
- 2つの集団に分けた。
  - **制度開始時にあった法人**：2015年11月より前に法人番号が指定された法人のうち、2015年10月時点で登記が残っていた 425.6万法人。全員を2026年10月まで追える。
  - **新しく設立された法人**：2015年11月以降に指定された株式会社・合同会社・一般社団・NPOなど 152.9万法人。設立の時期がばらばらなので、設立からの月数で見る。

| 状態 | 定義（閉鎖の事由・処理区分） |
|---|---|
| 0 活動 | 登記が残っている |
| 1 清算の結了など | 閉鎖の事由 01「清算の結了等」、31「その他の清算の結了等」 |
| 2 合併 | 11「合併による解散等」 |
| 3 登記官による閉鎖 | 21「登記官による閉鎖」 |
| 3→0 復活 | 最新の処理区分が 22「登記記録の復活等」 |

## 手法
| 段階 | 手法 |
|---|---|
| 遷移の確率 | Aalen–Johansen 推定（月単位）。制度開始時にあった法人は全員が同じ日に始まり同じ日まで追えるので、推定値は「その状態にいる割合」の数え上げと一致する。新しく設立された法人は、設立からの月数で打ち切りを扱う |
| 遷移の強さ | 月ごとの遷移強度（その月に移った数÷その月のはじめに活動していた数）。1月への集中を見る |
| 戻る遷移 | 復活（3→0）を入れた多状態の Aalen–Johansen。復活の前の閉鎖の日はデータにないので、復活はすべて登記官による閉鎖の状態から戻ったと仮定（頑健性で、閉鎖したすべての状態から戻る仮定も試す） |
| 年齢のパターン | 新しく設立された法人の、設立からの年ごとの登記官による閉鎖の発生率（1万法人・年あたり） |
| 比較 | 競合する道を無視した 1−Kaplan–Meier と Aalen–Johansen の差 |

## 主な結果
- 制度開始時にあった425.6万法人のうち、11年で登記がなくなったのは16.2%。内訳は清算の結了など10.1%、合併1.2%、登記官による閉鎖4.9%。**登記がなくなった法人の30%は、自分で清算を終えたのではなく登記官に閉じられていた**。株式会社では36%（192万社のうち6.8%）。
- 登記官による閉鎖の88%は1月に起きていた（株式会社では94%）。毎年1月にまとめて閉じられ、累積の曲線は階段状になる。件数は2017〜2024年は年0.8〜1.1万件だったが、2025年1月に6.0万件、2026年1月に4.7万件と大きく増えた。
- 種別で違う。閉鎖のうち登記官による閉鎖は、株式会社36%、合名・合資会社30%、一般社団・NPOなど28%、有限会社23%、合同会社9%。合同会社は清算の結了などが85%。
- 地域（株式会社）：閉鎖のうち登記官による閉鎖は、東京23区40%、政令市38%、その他の市町村34%。
- 新しく設立された法人では、登記官による閉鎖はほとんどない（10年で株式会社0.21%、一般社団・NPOなど0.25%、合同会社0.01%）。ただ、設立から60〜71か月の1月に山があり、1万法人・年あたり株式会社13.4件、一般社団・NPOなど14.7件（ほかの年は0.1〜4.9件）。登記官による閉鎖の56〜68%がこの1年に集まる。
- 復活：最新の処理が復活の法人は3,022（91%が制度開始時にあった法人）。年に26件（2016年）から637件（2026年、10月まで）に増えている。制度開始時にあった株式会社では、登記官による閉鎖100件に対して約1.2件（下限）。復活を入れた多状態モデルでも、11年後に活動している割合は81.21%→81.29%と0.08ポイントしか変わらない。
- 登記が残っている制度開始時からの株式会社の71%、有限会社の89%は、法人番号の指定のあと商号も所在地も変えていない（役員の変更などはこのデータに出ないので、休眠しているという意味ではない）。
- 新しく設立された法人で、競合する道を無視した 1−KM と Aalen–Johansen の差は、5年の清算で0.01〜0.02ポイント。合併も登記官による閉鎖も少ないので、無視しても数字はほとんど変わらない。

## 頑健性
| 設定 | 閉鎖のうち登記官による閉鎖 | 登記官による閉鎖（法人数に対して） |
|---|---|---|
| 基本 | 30.2% | 4.9% |
| 株式会社だけ | 36.4% | 6.8% |
| 有限会社だけ | 23.0% | 3.5% |
| 一般社団・NPOなどだけ | 28.2% | 3.3% |
| 2024年12月まで（2025・26年の大きな整理を除く） | 19.9% | 2.4% |
| 2016年3月〜2024年12月（最初の2016年1月の整理も除く） | 16.8% | 1.9% |
| 登記官による閉鎖を1月の分だけにする | 27.6% | 4.3% |
| 「その他の清算の結了等」を清算に入れない | 30.2% | 4.9% |

- 登記官による閉鎖の割合は、どの期間を見るかで17〜30%と動く。2025・26年の大きな整理を除くと2割になる。それでも、どの設定でも閉鎖の5〜6件に1件以上は登記官による閉鎖だった。
- 新しく設立された株式会社を2015〜2019年の設立と2020年以降の設立に分けても、登記官による閉鎖の67%・71%が設立6年目に集まる。
- 復活の割り当て方（登記官による閉鎖からだけ／すべての閉鎖から）を変えても、11年後の活動の割合は81.29%で同じ。

## 言えないこと
1. 「休眠」そのものはデータにない。休眠会社のみなし解散の登記は法人番号のデータに出ないので、登記官による閉鎖を「休眠や解散のまま放っておかれた道の終わり」として見ている。登記官による閉鎖のすべてが休眠会社の整理によるものかは分からない。
2. 2025年1月・2026年1月に登記官による閉鎖が大きく増えた理由は、このデータからは分からない。整理の進め方が変わった可能性がある（推測）。
3. 新しく設立された法人で、設立6年目の1月に登記官による閉鎖が集まる理由も分からない。一般社団法人などには、一定の期間登記がないと解散したものとみなす仕組みがあるので、それと関係している可能性がある（推測）。株式会社についても同じ山がある理由は分からない。
4. 復活は、最新の処理区分が復活の法人しか数えられない。復活のあとに所在地の変更などがあった法人は数えられないので、復活の数は下限。復活の前にどの道で閉じられたか、いつ閉じられたかも分からない。
5. 2015年10月より前に登記がなくなった法人や、法人番号が指定される前の歴史は見えない。制度開始時にあった法人は「2015年10月に活動していた」ことしか分からず、設立からの年数でそろえていない。
6. 閉鎖は事業をやめたことと同じではない（F28・F79 と同じ）。登記が残っていても事業をしていない法人は多い。
7. 法人の業種・規模はこのデータにない。
