# 249 1施設あたりの宿泊者は、増えたのか

宿泊旅行統計調査の施設数（第1表）と延べ宿泊者数（第2表）から、1施設あたりの延べ宿泊者数を出し、その変化を「大きさ（従業者数）ごとの1施設あたりの変化」と「小さい施設が増えた・減った（構成の変化）」に分けました。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A249 | 1施設あたりの宿泊者は、増えたのか | 1施設あたり延べ宿泊者数＝年の延べ宿泊者数÷施設数（12か月の平均）。全体の変化を、従業者数の4区分の中の変化と、区分の構成の変化に分ける（2つの年の重みの平均を使う分け方） | `src/a249_per_facility.py` |

## 主な結果
- 施設数（12か月の平均）は2015年50,055、2019年58,491、2025年72,570。2019→2025年に14,079（24.1%）増え、そのうち13,590は従業者0〜9人の施設。0〜9人の割合は76.0%（2015年）→77.0%（2019年）→80.8%（2025年）
- 全体の1施設あたり延べ宿泊者数は、2015年10,071、2019年10,188、2025年9,110人泊。2019→2025年に10.6%減
- 区分ごとの1施設あたり（2019→2025年）：0〜9人2,108→1,829（−13.2%）、10〜29人22,476→25,526（+13.6%）、30〜99人41,733→43,960（+5.3%）、100人以上127,067→130,141（+2.4%）
- 2019→2025年の全体の変化（−1,078人泊）を分けると、区分の中の変化が+366、構成の変化（小さい施設が増えた分）が −1,445。2015→2025年では −961＝+880と −1,840
- 実宿泊者数（人数）で同じことをしても、2019→2025年の −1,193人のうち −1,059が構成の変化

## 頑健性
- 施設数を12か月の平均でなく12月末の値にしても、全体の1施設あたりは2019→2025年に −11.8%、区分ごとの向きは同じ（`results/a249_summary.json`）
- 従業者数の4区分の施設数の合計は、総数とすべての年で一致した
- 施設タイプ（旅館・ビジネスホテルなど）の施設数は、2022年以降、タイプの合計が総数と大きく違う（2025年は合計53,415に対して総数72,570）ため、使わなかった
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致することを確かめた

## 動かし方
```
pip install -r requirements.txt
cd src && python a249_per_facility.py   # data/ の CSV から results/・figures/ を作る
python fetch.py             # data/ の CSV を観光庁の Excel から作り直す（任意。ネットにつながる環境で）
```

## データ
- `data/table<n>_national.csv`：観光庁「宿泊旅行統計調査」各年（2015〜2025年）の「1月〜12月分（年の確定値）集計結果」Excel から、全国の行だけを取り出したもの（`src/extract.py`）。month=0 は年計、1〜12 は各月。列名は `src/extract.py` の COLS（total＝総数、tour＝観光目的の宿泊者が50%以上の施設、biz＝同50%未満の施設、s0_9 など＝従業者数の区分、foreign＝うち外国人）
- 施設数（第1表）は各月の値で、年の値は12か月の平均にした

## 注意
- 1施設あたりは、施設の大きさ（客室数）をそろえた値ではない。0〜9人の区分には、ごく小さな簡易宿所なども多く入る
- 年によって施設が別の区分に移ることがあり、区分の中の変化には、その出入りも入る
- 0〜9人の施設の1施設あたりが減った理由（新しい小さな施設が多い、など）は、この表からは分からない（推測を含む説明はしていない）
