# F330 PLAN（事前の計画）：桜の開花は、どれだけ早くなったのか？ 全国の温暖化の分と、地点ごとの上乗せの分

作成：2026-11-16 07:43 JST（地点の気温を取る前、傾向や回帰を計算する前に書いた）

## 問い
さくらの開花は、どれだけ早くなったのか。そのうち、日本全体の温暖化（都市化の影響が少ない15地点の平均）で説明できる分と、その地点だけ余分に暖かくなった分（都市化などによる上乗せ）は、それぞれどれくらいか。
大きな都市の地点ほど、開花が早まったのか。

知りたい人：花見や観光の時期を考える自治体・観光の担当、季節の記事を書く人、気候の変化に関心がある人。

## 既存の分析との関係
- 同じ累年値を使った既存の分析（076 のもとのリポジトリ S1）で、さくらの開花が10年あたり約1日早まったこと、2〜3月の気温1℃で約4日早まることは示されている。
- この記事は、それを繰り返さず、地点の気温を「全国並みの分」と「地点の上乗せ分」に分け、開花の早まりのうちどれだけが上乗せ分に当たるかを見る点を新しくする。

## データ
- 気象庁 生物季節観測累年値「さくらの開花」（地点×年、1953年〜）
- 気象庁 日本の月平均気温偏差（15地点平均、1898年〜）
- 気象庁 過去の気象データ検索：さくらの観測地点の月平均気温（年ごと、観測開始〜）
- ソメイヨシノ以外（北海道の一部・奄美・沖縄など、rm が6・7の値）は除く。

## 取得前・下見で見たもの（開示）
- さくらのファイルの形を確かめるときに、稚内・留萌・旭川と、南西諸島の数地点の数年分の日付、rm の値の出現回数を見た。
- 日本の月平均気温偏差の最初と最後の数行を見た。
- 東京の月平均気温の表の1950〜1959年の行を、ページの形を確かめるために見た。
- 既存の分析の結果（10年あたり−1.1日、1℃あたり約4日）は読んでいる。H1・H2 はそれに近い値を置いているので参考扱い。

## 手法
- 対象：1961〜2025年に開花の値（ソメイヨシノ）が50年以上ある地点。
- 地点の2〜3月平均気温 T を、全国の2〜3月の偏差 N と、残り（上乗せ）U に分ける：地点ごとに T = a + N + U（U は地点の T と N の差から地点平均を引いたもの）。
- 開花日（1月1日からの通日）を、地点固定効果つきで N と U に回帰（年でクラスター頑健標準誤差）。
- 地点ごとの開花日の傾向（Theil–Sen、10年あたり日数）と、上乗せ U の傾向（10年あたり℃）の関係。
- 開花の早まり（1961〜1990年平均 → 1996〜2025年平均）を、N の変化×係数 と U の変化×係数 と 残り に分ける。

## 仮説と「外れ」の基準
- H1（参考）：1961〜1990年 → 1996〜2025年で、地点の中央値で開花は4日以上早まった。4日未満なら外れ。
- H2（参考）：N と U の係数はどちらも −3〜−5日/℃ の範囲。どちらかが範囲の外なら外れ。
- H3：開花の早まりのうち、上乗せ U で説明される分は全体の20%以上。20%未満なら外れ。
- H4：上乗せ U の傾向が大きい地点ほど、開花の早まりが大きい（地点間の順位相関が −0.3 より強い）。−0.3 より弱ければ外れ。
- H5：2〜3月がもともと暖かい地点（平年の2〜3月平均気温が上位4分の1）は、気温1℃あたりの早まりが小さい（冬の寒さが足りないと目覚めが遅れるため）。地点別の傾きの中央値が、ほかの地点より小さく（0に近く）なければ外れ。

## 頑健性（3つ以上）
1. 気温の期間を2〜3月ではなく3月だけ、1〜3月にする
2. 対象地点の条件を40年以上・60年以上にする
3. 期間を1961〜2020年（観測地点が減る前後の影響を見る）にする
4. 年トレンドを入れた回帰（N と U のほかに年を入れる）

## 言えないこと（予想）
- 上乗せ U は都市化だけでなく、観測場所の移転、測器の変更、周りの土地の変化も含む
- さくらの観測は標本木の植え替えでも変わる
- 因果（気温が開花を決める）は、生物学の知見に頼っており、この分析では確かめていない
- 観測地点は気象台・測候所の場所で、町全体の代表ではない
