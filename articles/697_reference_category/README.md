# 697 ダミー変数の基準のカテゴリを変えると、係数と有意の見え方はどれだけ変わるのか（手法の解説・架空の店で試す）

店や地域のようなカテゴリを回帰に入れるとき、1つを「基準」にしてダミー変数を作ります。係数は「基準との差」なので、基準を変えると係数も p 値も変わります。**ここでは、件数の少ない店を1つ含む架空の6店の売上で、基準を A〜F に変えて回帰し、有意になる店の数・全体の F 検定・予測値を比べました。** 同じ作り方で2,000回くり返した結果も数えました。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A697 | 基準を変えると、係数と有意はどう変わるか | 6店（A 300日・B 250・C 200・D 150・E 120・F 15日）、本当の平均 A 50・B 52・C 51・D 53・E 50・F 53万円、標準偏差8。店のダミーで最小二乗、基準を6通り。2,000回くり返し、seed 697 | `src/a697_reference_category.py` |

## 主な結果
| 基準にした店（日数） | 有意な店の数（このデータ） | 有意な店の数（2,000回の平均） | 有意な店が0の割合（2,000回） |
|---|---|---|---|
| A（300日） | 2 | 2.41 | 0.7% |
| B（250日） | 2 | 2.05 | 3.8% |
| C（200日） | 1 | 1.54 | 10.2% |
| D（150日） | **3** | 2.77 | 1.7% |
| E（120日） | 2 | 2.00 | 7.0% |
| F（15日） | **0** | 0.86 | 63.8% |

- 同じデータでも、有意な店の数は基準によって0〜3店と変わった。基準を15日しかない店Fにすると、どの差の区間も広くなり、有意な店は0だった
- 全体の F 検定（店で売上が違うか）は、どの基準でも F＝4.97・p＝0.0002 で同じ。店ごとの予測値も6通りで同じだった
- 2,000回のうち92.9%で、基準の選び方によって有意な店の数が2以上違った

## 注意（言えないこと）
