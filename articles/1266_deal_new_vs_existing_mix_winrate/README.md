# 1266 新しい取引先と前からの取引先をまぜた受注率は、まざる割合が変わるとどう動くのか？（受注の見込み）

法人向けの商談では、初めて取引する会社（新しい取引先）の商談は、前から取引のある会社の商談より取れにくいのがふつうです。この2つをまぜて「受注率（取れた件数÷決まった件数）」を1つにすると、その率は、区分ごとの取れやすさだけでなく、新しい取引先の商談がどれだけまざっているかでも動きます。新しい取引先を増やそうとした期に受注率が下がると「営業が弱くなった」と読みがちですが、まざる割合が変わった分まで取れやすさのせいにしてしまいます。**ここでは、作成者が置いた架空の会社B社の法人向けの商談（1期に決まる件数、新しい取引先の割合、区分ごとの本当の受注の確率を置き、取れる・取れないを乱数で決めたもの）で、第1期から第8期に新しい取引先の割合が変わったとき、まぜた受注率の動きと、割合を第1期にそろえた受注率の動きを比べました。区分ごとの率が上がっているのに、まぜた率が下がって見える場面がどれだけ起きるか、まぜた率で次の期の受注数を見込むとどれだけ外れるかも数え、置き方を変えた270通りで確かめました。**

例の会社・商談は架空のもので、実在の会社・取引先・商談の記録の仕組みを表すものではありません。担当どうしの良し悪し、新しい取引先をどれだけ増やすべきか、売上の目標の立て方は扱っていません。

関連する記事：1203「登録して間もない人ほどよく開くとき、全体の開封率の下がり方は、読者の入れかわりでどれだけ説明できるのか？」は、全体の率が読者の顔ぶれの入れかわりで動く形を、メールの開封率で扱っています。1171「中身の種類で圧縮のかかり方が違うとき、種類の割合が変わると全体の圧縮率はどう動くのか？」は、全体の率が種類の割合の重みで動く形を、保存データの圧縮率で扱っています。995「「前年比120%」の来場は、新しい人か、来る回数が増えたのか？」は、新しい人と前からの人に分けて読むときのずれを来場者で扱っています。1260「受注率を、その期に始まった商談で数えるか、その期に決まった商談で数えるかで、どれだけ違うのか？」は、受注率の分母にどの商談を入れるかの違いを扱っています。1264「件数で数えた受注率と金額で数えた受注率では、良かった月はどう入れかわるのか？」は、件数と金額のどちらで受注率を数えるかの違いを扱っています。この記事は、分母の商談の決め方は同じにしたまま、新しい取引先と前からの取引先のまざる割合だけが動いたときのずれに絞ります。

## 主な結果

### 第1期と第8期のまぜた受注率（各500回の平均、`results/scenarios_summary.csv`）

|---|---|---|---|---|
| S1 割合だけ3割→7割 | 35.8%（36.0%） | 23.8%（24.0%） | **−12.0ポイント** | +0.12ポイント（−6.65〜+6.8） |
| S2 割合3割→7割＋率が3ポイント上がる | 36.04%（36.0%） | 27.09%（27.0%） | **−8.95ポイント** | **+2.92ポイント**（−5.19〜+10.06） |
| S3 割合3割のまま＋率が3ポイント上がる | 35.71%（36.0%） | 38.97%（39.0%） | +3.26ポイント | +3.21ポイント（−2.5〜+8.86） |
| S4 割合だけ7割→3割 | 23.71%（24.0%） | 35.71%（36.0%） | **+12.0ポイント** | +0.2ポイント（−5.75〜+6.04） |

- **S1：区分ごとの率を変えていないのに、まぜた受注率は36%から24%へ12ポイント下がった（式どおり）**。新しい取引先15%・前からの取引先45%を、3割と7割でまぜるか、7割と3割でまぜるかの違いだけで決まる。S4 のように割合が逆に動けば、同じだけ上がった
- **S2：区分ごとの率がどちらも3ポイント上がったのに、まぜた率は36%から27%へ下がった（式どおり）**。500回のうち96.8%でまぜた率が下がって見えた。割合を第1期にそろえると平均+2.92ポイントで、置いた+3ポイントに近かった
- ただし1期200件では、割合をそろえた差の10〜90%の幅は−5.19〜+10.06ポイントと広く、そろえた率が上がって見えたのは S2 で71%だった。第8期の新しい取引先は約140件、前からの取引先は約60件で、区分ごとの率そのものが大きく振れるため
- S2 で、新しい・前からの両方の率が上がって見えたのは500回のうち47.4%だった。両方の率が上がって見えたのに、まぜた率は下がって見えた回は、S2 で44.2%、区分ごとの率を変えていない S1 でも24.8%あった（S1 は両方とも偶然上がって見えた回）

## 注意（言えないこと）
- 架空のデータです。区分ごとの受注の確率、新しい取引先の割合の動き方、1期の件数は作成者が置いたもので、まぜた率の動きはこれで決まります（S1・S2 の第1期・第8期の値は式どおり）
- 区分は「新しい取引先」と「前からの取引先」の2つだけにしました。実際には、商談の大きさ、紹介かどうかなど、ほかの内訳の割合も同時に動きます。2つにそろえただけでは、その分は残ります（推測）
- 新しい取引先の商談が取れると、その会社は次から「前からの取引先」になります。この記事では、どちらの区分の商談がどれだけ出るかを割合として外から置き、その入れかわりは入れていません
- 件数で数えた受注率だけを扱いました。金額で数えると、大きい商談の多い区分の重みが変わり、動き方は別になります（件数と金額の違いは 1264 で扱っています）
- 担当や部署ごとの比べ方、新しい取引先を増やすことの良し悪し、売上の目標の立て方は扱っていません
