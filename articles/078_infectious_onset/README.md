## もとのリポジトリの説明

以下は、もとのリポジトリ `idwr-weekly-japan` の README です（同じリポジトリにあったほかの記事の分も含みます）。

### idwr-weekly-japan：感染症発生動向調査（IDWR）の週ごとの速報データで、流行の季節のずれと、流行がどこから始まるかを調べる

国立健康危機管理研究機構「感染症発生動向調査週報（IDWR）」の速報データ（2023年第1週〜2026年第41週、197週分）を使ったリポジトリです。定点把握の19疾患×都道府県の週ごとの報告数・定点当たり報告数と、全数把握の疾患の都道府県別の報告数・累積を使いました。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| I1 | 2023〜2026年に、どの感染症がいつ・どれくらいの高さで流行したか。2025年の定点の見直しの前後で比べられるか | 全国の定点当たり報告数の週ごとの推移、シーズンごとの山の週と高さ、定点数（報告数÷定点当たり）の変化 | `src/i1_seasons.py` |
| I2 | 流行はどの都道府県から始まるか。毎年同じか。全数把握の疾患（百日咳・梅毒・劇症型溶連菌感染症・麻しん）はどう増減したか | 都道府県ごとに定点当たりが基準（インフルエンザ10、手足口病2）を初めて超えた週、緯度・東京からの距離とのスピアマン順位相関、シーズン間の順位相関、年間の累積報告数と人口10万人あたり | `src/i2_spread.py` |

#### 主な結果
- **I1**：インフルエンザの全国の山は、2023/24シーズン33.72（2023年第49週）、2024/25シーズン64.39（2024年第52週）、2025/26シーズン51.12（2025年第47週）で、3シーズンとも年内でした。2025/26は2026年第6週にも43.34の2つめの山がありました。2026年第41週は12.81で、同じ週の2024年（0.89）・2025年（2.36）より高く、2023年（11.07）と近い水準です。ほかに大きな山があったのは、手足口病2024年（13.34）・2026年（9.35）、マイコプラズマ肺炎2024年（2.84）、伝染性紅斑2025年（2.53。2023年の最大は0.03）、ヘルパンギーナ2023年（7.32）、咽頭結膜熱2023年（3.72）。A群溶連菌咽頭炎は2024年に52週すべてで定点当たり1以上でした
- **I1（定点の見直し）**：報告数÷定点当たりで見た定点数は、2025年第15週からインフルエンザ・COVID-19が約4,930→約3,810、小児科定点の疾患が約3,130→約2,300に変わりました（マイコプラズマ肺炎の基幹定点は約480のまま）。2025年4月の急性呼吸器感染症（ARI）サーベイランスの開始に伴う見直しで、その前後の定点当たりの値は厳密には比べられません
- **I2**：インフルエンザが定点当たり10を初めて超えた週は、3シーズンとも沖縄県が最も早く（2023/24と2024/25は第36週の時点ですでに超えていた）、沖縄以外では年によって順番が違いました。緯度との順位相関は2023/24が0.56、2024/25が0.48（南ほど早い）、2025/26は−0.36（北ほど早い）で、2025/26は東京からの距離との相関が0.50（東京に近いほど早い）でした。シーズン間の順位相関は0.41・−0.01・0.14と弱いです。手足口病は2024年・2026年とも南から北へ進み、緯度との順位相関は0.64・0.59でした
- **I2（全数把握）**：百日咳は1,009（2023年）→4,054（2024年）→89,387（2025年）、麻しんは28→45→265で、2026年は第41週までに579（2025年の同じ週は231）。劇症型溶血性レンサ球菌感染症は941→1,888→1,382、梅毒は14,906→14,663→13,530。2025年の人口10万人あたりは、百日咳が高知県202、新潟県190、群馬県161、梅毒が東京都24、大阪府19、福岡県15

#### データ
| ファイル | 中身 |
|---|---|
| data/idwr_raw.zip | 下の data/raw の CSV 一式（GitHub のファイル数の都合でzipにまとめています。src/common.py が初回に data/raw へ展開します） |
| data/raw/YYYY-WW-teiten.csv | 定点把握疾患の、疾病×都道府県の報告数と定点当たり報告数（その週） |
| data/raw/YYYY-WW-zensu.csv | 全数把握疾患の、疾病×都道府県の報告数と年初からの累積 |
| data/raw/SSDSE-E-2026.csv | 都道府県の人口（統計センター「教育用標準データセット SSDSE-E」、2024年） |

各週のCSVは https://id-info.jihs.go.jp/surveillance/idwr/provisional/YYYY/WW/YYYY-WW-teiten.csv（zensu も同じ形）から取得しました。

#### 注意
- すべて速報値です。あとで確定値に直されます。全数把握の年間の数は、その年の最終週の速報の累積です
- 定点把握は、決められた医療機関（定点）からの報告です。患者全体の数ではなく、定点当たり報告数は流行の大きさの目安です
- 2025年第15週から定点が見直され、定点の数も顔ぶれも変わりました。見直しの前後の定点当たりの値は厳密には比べられません
- 年末年始の週は受診が減るので、報告数が一時的に下がります
- 立ち上がりの週は、基準を初めて超えた週です。シーズンの始め（第36週）にすでに超えていた県は0週としています
- 全数把握の数は、検査や届出の状況の変化にも影響されます
- 人口10万人あたりは2024年の人口で割っています
