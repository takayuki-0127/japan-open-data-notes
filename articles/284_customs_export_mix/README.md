# 284 港ごとの輸出は、何に偏っているのか

財務省「貿易統計」の概況品別税関一覧表（輸出、2015年・2025年）で、税関の事務所ごとに、輸出する品物の偏りを測ったフォルダです。事務所の良し悪しの順位ではなく、何が出ていくかの違いを見ます。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A284 | 港（税関の事務所）ごとの輸出は、何に偏っているのか | 事務所（統計の3桁の税関コード、出張所などを含むまとまり）ごとに、概況品3桁（57分類）の割合の2乗の和（HHI）。いちばん多い品物は概況品5桁で見る。対象は輸出額1,000億円以上の56か所。2015年と比べる | `src/a284_customs_mix.py` |

## 主な結果
- 2025年の輸出110.4兆円のうち、1,000億円以上の56か所で98%。いちばん多い10か所で76%（2015年70%）
- 全国の輸出全体の偏り（HHI）は0.12。56か所の偏りの中央値は0.26で、多くの事務所は全国より品物が偏っている。全国より小さいのは2か所
- 17か所では、1つの品物（概況品5桁）が輸出の半分を超える。品物は自動車（5か所、そのうち3か所は97〜98%）、船舶類（5か所）、鉄鋼のフラットロール製品（3か所）、管及び管用継手（2か所）など。ただしこの17か所の輸出は全国の12%
- 成田（19.8兆円）・東京（8.1兆円）・横浜（8.9兆円）・神戸（7.5兆円）などの大きな窓口は品物が散らばっていて、偏りは0.13〜0.14。いちばん多い品物も輸出の5〜20%
- 2015年からの変化：両方の年に1,000億円以上の49か所のうち25か所で偏りが下がり、24か所で上がった。中央値の変化はほぼ0

## 頑健性
- 品物の分け方を概況品5桁にすると、事務所の偏りの中央値は0.22（2025年）。5桁は輸出の一部（中央値で84%）しかおおわないので、主な物差しは3桁にした
- 1,000億円未満の小さな事務所（2025年に78か所、輸出の2%）は対象から外した。小さな事務所ほど品物の数が少なく、偏りが大きく出やすい（推測）
- コードは新しいフォルダで2回動かし直し、results と figures のすべてのファイルが一致することを確かめた

## 動かし方
```
pip install -r requirements.txt
cd src && python a284_customs_mix.py   # data/ から results/ と figures/ を作る
python fetch.py                         # data/ を e-Stat から作り直す（任意）
```

## データ
- `data/exports_customs_gaikyo_2015_2025.csv`：概況品別税関一覧表（輸出、1-12月）の税関コード・概況品コード（5桁まで）・金額（千円）。e-Stat の statInfId は `src/fetch.py`
- `data/customs_names.csv`：税関符号表（税関のページ）。統計の3桁のコードは4桁の符号の上3桁で、名前は上3桁が同じ最初の符号のもの
- `data/gaikyo_export_names.csv`：概況品コード表（輸出、2025年）

## 注意
- 輸出の申告をした税関の事務所で数えた値で、品物を作った場所や、船が出た港とは一致しないことがある
- 事務所の名前は税関符号表のもの。3桁のまとまりには出張所などが含まれる
- 偏りが大きいことは良い・悪いを意味しない。近くに大きな工場があれば偏るのは自然（推測）。この README では偏りの大きさで事務所を並べていない
