# F127 空き家は、人口が減った分だけ増えたのか？（要因分解と都道府県パネル）

## 問い
空き家が増えたのは「人口が減ったから」とよく言われます。では、空き家は人口が減った分だけ増えたのでしょうか。住宅・土地統計調査の5回分（2003〜2023年）を都道府県別に並べ、空き家の増加を「住宅ストックの増加」「人口の増減」「世帯の小型化」「その他」に分けて確かめます。

## データ
- 総務省「住宅・土地統計調査」令和5年の時系列表（第1-2表・第2-2表・第3表・第4表）。都道府県×調査年（2003・2008・2013・2018・2023）＝235行。取り方は `src/01_取得.md`
- 人口は同じ調査の「世帯人員」、世帯数は同じ調査の「世帯数」を使います（国勢調査ではなく、空き家と同じ調査でそろえるため）
- 整えたデータ：`data/panel_pref.csv`

## 手法
1. **要因分解（恒等式）**：空き家 ＝ 住宅総数 − 居住世帯のある住宅 − その他の居住世帯なし（一時現在者のみ・建築中）。居住世帯のある住宅は世帯数でほぼ決まり、世帯数 ＝ 人口 ÷ 1世帯あたり人員 です。世帯数の変化を、対数平均ディビジア法（LMDI）で「人口の増減」と「世帯の小型化」に分けました。式の上で、分けた合計は実際の空き家の増減と一致します（誤差1戸未満を確認）
2. **都道府県パネル回帰**：5年ごとの差分（47県×4期＝188）。目的変数は「空き家の増加（期首の住宅数に対する%）」、説明変数は「人口の減少を世帯数に直した量（同じ単位）」。係数が1なら「人口が減った分だけ空き家が増えた」、0なら「人口の減少と空き家の増加は関係しない」という意味です。年の固定効果を入れ、県でクラスタリングした標準誤差を使いました

## 結果
- **全国では、人口要因は空き家の増加の一部**：2003→2023年に空き家は 241万戸増えました。分けると、住宅ストックの増加 +1,116万戸、人口の減少 +107万戸、世帯の小型化 -1,003万戸、その他 +21万戸です。人口は 324万人減りましたが、世帯数は 896万世帯増えました。2008→2023年では、空き家 +143万戸に対し、人口要因 +119万戸、ストック +746万戸、小型化 -743万戸です
- **人口が減った県では、空き家の増加は人口要因の半分ほど**：2008→2023年に人口が減った39県を合わせると、人口要因だけなら +218万戸の計算ですが、実際の増加は +109万戸でした。世帯の小型化（-449万戸）が人口の減少を打ち消し、それでも住宅ストックが +325万戸増えたためです
- **空き家率の変化は、「住宅の伸び − 世帯の伸び」でほぼ決まる**：2008→2023年の都道府県で、空き家率の変化との相関は、人口の伸びが -0.72、住宅の伸びと世帯の伸びの差が 0.99 でした。人口が減ったのは39県、世帯が減ったのは4県、住宅総数が減った県は0でした
- **パネル回帰**：人口の減少（世帯数換算）1世帯分あたり、空き家は 0.17（95%区間 0.06〜0.28） 戸増えました。1（減った分だけ）よりはっきり小さい値です。住宅ストックの増加と世帯の小型化をそろえると 0.99（95%区間 0.96〜1.02） になり、恒等式どおり1に近づきます
- **種類で違う**：人口の減少と結びついていたのは「その他の空き家」（係数 0.15（95%区間 0.10〜0.19）、人口の伸びとの相関 -0.84）で、「賃貸用の空き家」はほぼ無関係でした（0.01（95%区間 -0.06〜0.09）、相関 -0.15）。全国の割合は、その他が 3.9% → 5.9%、賃貸用は 6.8% → 6.8% です
- **住宅は世帯の伸びの7〜8割で増えた**：住宅の伸び率を世帯の伸び率で回帰すると係数 0.76。世帯の伸びが小さい県でも住宅はそれなりに増えるため、差が空き家として残ります（推測：新築が続き、古い住宅の取り壊しが追いつかないため）

## 頑健性チェック
| チェック | 人口の減少1世帯分あたりの空き家の増加 |
|---|---|
| 主（年の固定効果） | 0.17（95%区間 0.06〜0.28） |
| 県の固定効果も入れる | 0.03（95%区間 -0.83〜0.89）（区間が広く、県の中の時期の変化だけでは言い切れない） |
| 分母を世帯数にする | 0.18（95%区間 0.07〜0.28） |
| 2008年以降の差分だけ | 0.14（95%区間 0.01〜0.27） |
| 2023年を除く | 0.13（95%区間 0.00〜0.25） |
| 住宅数で重みづけ | 0.17（95%区間 0.07〜0.27） |
| 種類：その他の空き家 | 0.15（95%区間 0.10〜0.19） |
| 種類：賃貸用の空き家 | 0.01（95%区間 -0.06〜0.09） |

要因分解は、期間を 2003→2023・2008→2023・2003→2018・2018→2023 に変えても、「人口が減った県の空き家の増加は、人口要因だけの計算より小さい」が同じでした（人口要因 ÷ 実際の増加：1.5倍・2.0倍・1.3倍・2.3倍）。

## 言えないこと
- 要因分解は恒等式で、原因を示すものではありません。「世帯の小型化」や「ストックの増加」がなぜ起きたか（高齢の単身世帯の増加、新築の多さ、取り壊しの少なさ）はこのデータでは分けられません
- 県の固定効果を入れると係数の区間は広く、同じ県の中で「人口が減った時期ほど空き家が増えた」とは言い切れません
- 住宅・土地統計調査は標本調査で、空き家の数には誤差があります。2023年の表では「その他の住宅」が「賃貸・売却用及び二次的住宅を除く空き家」という名前になっており、この記事では同じ区分として扱いました
- 人口は調査の「世帯人員」で、国勢調査の人口とは一致しません。市区町村の違いは見ていません
- 特定の都道府県を良い・悪いと評価するものではありません
