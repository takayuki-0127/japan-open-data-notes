# 01 取得（住宅・土地統計調査 令和5年 時系列表）

`data/raw/f127_hlts_timeseries.json` は、e-Stat に置かれている総務省「令和5年住宅・土地統計調査」の時系列の表（閲覧用 Excel）を、2026年11月3日にブラウザの中で読み込み、シートごとに CSV の文字列にして1つの JSON にまとめたものです。

| キー | 表 | statInfId |
|---|---|---|
| `t12__平成15年` 〜 `t12__令和5年` | 第1-2表 居住世帯の有無(7区分)別住宅数―全国、3大都市圏、都道府県、大都市（昭和33年〜令和5年） | 000040354028 |
| `t22__平成15年` 〜 `t22__令和5年` | 第2-2表 世帯の種類別世帯数及び世帯人員―同上 | 000040354030 |
| `t3__003` | 第3表 住宅数及び世帯数―同上 | 000040354031 |
| `t4__総数` ほか | 第4表 空き家の種類(4区分)、建て方(4区分)別空き家数―同上 | 000040354032 |

取り方：`https://www.e-stat.go.jp/stat-search/file-download?statInfId=<id>&fileKind=4` を e-Stat のページの中で fetch し、SheetJS（xlsx 0.18.5）で読み、`XLSX.utils.sheet_to_csv` で各シートを文字列にしました。手で取る場合は、上の URL から Excel をダウンロードすれば同じ内容になります。

使う年は 2003・2008・2013・2018・2023 年の5回です。人口は、この調査の「世帯人員」（住宅以外に住む人や準世帯を含む）を使います。国勢調査の人口とは少しずれます。
