# 712 月の伸び率を年率に直すとき、12倍するか複利で直すかで、どれだけ違うのか（実務の型・伸び率の扱い）

月の伸び率を「年率にすると何%」と言うとき、12倍する直し方と、毎月の伸びが重なる（複利）として (1+月率)^12−1 で直す直し方があります。**ここでは、2つの直し方の差を式で出したうえで、架空の会員数の月次（2022〜2025年、途中で伸びが鈍る）で、1か月の伸びを年率に直した値が、その後12か月の実際の伸びとどれだけ合うかを比べました。** 会員数の伸び方は作成者が置いたもので、数字はその置き方で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A712 | 12倍と複利の年率はどれだけ違い、どちらが実際の1年の伸びに近いか | 式の比較（月率−6%〜+8%）、架空の会員数48か月で、12倍・複利・前年同月比と、その後12か月の実際の伸びの差。seed 712 | `src/a712_annualize.py` |

## 主な結果
- **式の差**：月+1%は12倍で12.0%・複利12.7%（差0.7ポイント）、月+2%は24.0%・26.8%、**月+3%は36.0%・42.6%**、月+5%は60.0%・79.6%。差が1ポイントを超えるのは月+1.3%から
- **マイナスでは逆向き**：月−3%は12倍で−36.0%、複利で−30.6%。月−5%は−60.0%・−46.0%
- **1か月の値は大きくゆれる**：架空の会員数では、月の伸びを年率にした値が12倍で−7.0〜70.9%、複利で−6.8〜99.1%の範囲で動いた
- **その後1年の伸びとの差**（2023年1月〜2024年12月の24か月の平均）：12倍15.2ポイント、複利19.0ポイント、前年同月比をそのまま使う10.5ポイント。この期間の途中で伸びが鈍ったため、どの値も先の伸びを大きく見た

## 動かし方
```
pip install -r requirements.txt
cd src && python a712_annualize.py
```
数秒で終わります。`data/members_monthly.csv` に会員数を書き出します。

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures がバイト単位で一致した
- 比べる月はそろえた（3つの値とその後12か月の伸びがすべて出せる24か月）

## データ
- `data/members_monthly.csv`：ym・members
- 仮定：月の伸びは2022〜2023年が平均2.5%、2024〜2025年が平均1.2%、月ごとのゆれは標準偏差1.2ポイント（作成者が置いた）

## 注意（言えないこと）
- 架空のデータ。「どちらが先の伸びに近いか」は、伸びが変わる時期を含むかどうかで変わる。ここでは複利のほうが離れた。伸びが鈍った期間に、大きく伸びた月を複利でさらに大きく直したためと考えられる（推測）
- 年率は「その伸びが1年続いたら」という仮の数字で、見込みではない。どちらで直したかを書いておくのが大切
- 金利や料率の計算は扱っていない
