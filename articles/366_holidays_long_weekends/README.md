# 366 祝日と3連休は、70年でどれだけ増えたのか（内閣府の祝日の一覧と暦の計算）

内閣府が公表している「国民の祝日」の一覧（1955年〜）と暦の計算だけで、祝日・振替休日の数、土曜・日曜との重なり、3連休以上の回数を1年ごとに数えたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A366 | 祝日・休日は1年に何日あるか。3連休以上は年に何回あるか。祝日を月曜に移した分（ハッピーマンデー）は何回分か | 祝日の一覧から、振替休日・国民の休日を決まりどおりに作り直して一覧と照合。土日・祝日・休日が3日以上続くかたまりを数える。4つの祝日を元の日付に戻した暦でも数える | `src/a366_holidays.py` |

## 主な結果
- 国民の祝日：1955年9日 → 1966年11日 → 1967年12日 → 1989年13日 → 1996年14日 → 2007年15日 → 2016年16日（2019年は天皇誕生日がなく15日）
- 振替休日（1973年〜）は2026年までに95日、国民の休日は20日、その年だけの休日は6日。祝日・休日の合計は1955年9日、2025年19日。最多は2019年の22日
- 月〜金に当たる祝日・休日：1955〜65年は年平均6.4日（3〜8日）、2016〜26年は14.8日（12〜17日）
- 3連休以上（土日を休みとして数える）：1955〜72年 年3.0回、1973〜99年 5.3回、1990年代 5.8回（3〜9回）、2003〜26年 8.5回（5〜12回）。最多は2024年の12回
- 月曜に移した4つの祝日（成人の日・海の日・敬老の日・体育の日）を元の日付に戻した暦では、2003〜26年（特例のあった2020・21年を除く22年）の3連休以上は年6.4回（2〜10回）。実際は8.6回（5〜12回）で、差は年2.2回。22年すべてで実際のほうが多い
- 元の日付に戻すと、祝日・休日の合計は年17.8日で実際（17.4日）より多い。日曜に重なって振替休日になる分があるため。月〜金に当たる日は、実際14.0日・戻した場合13.4日
- 祝日が土曜に重なった割合：1955〜99年14.0%、2003〜26年9.8%（7日に1日なら14.3%）。土曜の分は振り替えられない

## 確かめたこと
- 祝日（名前のある日）から、振替休日と国民の休日を法律の決まりどおりに作ると、一覧の「休日」115日とすべて一致した（1973年4月〜、2007年からの「後ろへ送る」決まり、1985年12月〜の国民の休日を含む）
- 土曜を休みに数えない場合（日曜と祝日だけで2日以上続く回数）：1955〜72年 年2.6回、1973〜99年 5.4回、2003〜26年 8.3回で、増え方は同じ向き
- 空のフォルダで流し直し、data・results・figures が一致した

## データ
- `data/raw/syukujitsu.csv`：内閣府「国民の祝日について」の「昭和30年（1955年）から令和9年（2027年）国民の祝日・休日（csv形式）」（2026-11-12 取得、Shift_JIS のまま）
- `data/holidays_by_year.csv`：1年ごとの祝日・振替休日・国民の休日・土日との重なり・3連休以上の回数
- `data/happy_monday_counterfactual.csv`：4つの祝日を元の日付に戻した場合との比べ（2000〜2026年、2020・21年を除く）

## 注意（言えないこと）
- 数えたのは暦の上の休みです。実際に休めた人の数や、会社の休み（年末年始・お盆）は入っていません
- 「土日を休み」は、いまの週休2日を昔の年にも当てはめた数え方です。昔は土曜に働く人が多く、当時の実感とは違います
- 3連休以上のかたまりは、最後の日がある年に数えました。年末年始をまたぐものは翌年に入ります
- 元の日付に戻した暦は、成人の日1月15日・海の日7月20日・敬老の日9月15日・体育の日10月10日としたものです。2020・2021年は特例で祝日が動いたため比べていません
- 2027年は一覧にありますが、数えていません
