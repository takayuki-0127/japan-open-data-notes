# 730 階層クラスタリングのつなぎ方（最短・最長・群平均・ウォード）で、本当のまとまりを何%で当てるのか（手法の解説・正解の分かるデータで試す）

階層クラスタリングは、近いものから順につないでまとまりを作る手法です。「まとまりとまとまりの近さ」をどう測るか（つなぎ方）に、いちばん近い2点で測る最短距離法、いちばん遠い2点で測る最長距離法、すべての組の平均で測る群平均法、まとまりの中のばらつきの増え方で測るウォード法などがあります。つなぎ方で、同じデータから違う分け方が出ます。**ここでは、形と大きさの違う3つの本当のまとまりを置いた架空の300店のデータで、4つのつなぎ方と k-means で3つに分け、本当のまとまりとの一致（ARI）と、数店だけの小さなまとまりができた回を300回数えました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A730 | つなぎ方で、本当のまとまりを何%で当てるか | 架空の300店の2つの指標。A：細長い（120店、横の標準偏差2.2・縦0.35）、B：小さく詰まった（60店、0.3）、C：大きく広がった（120店、1.1）。scipy の階層クラスタリング（single・complete・average・ward）と k-means で3つに分け、ARI を比べる。300回、seed 730 | `src/a730_linkage.py` |

## 主な結果（300回）
| 分け方 | ARI の平均 | ARI 0.9 以上（ほぼ当てた）の割合 | 5店以下のまとまりができた回 |
|---|---|---|---|
| 最短距離法 | 0.42 | 7.0% | **92.7%** |
| 最長距離法 | 0.58 | 0.0% | 1.7% |
| 群平均法 | 0.64 | 3.3% | 33.3% |
| ウォード法 | **0.73** | **19.3%** | 0.0% |
| k-means | 0.68 | 5.0% | 0.0% |

- どの方法も、形と大きさの違う3つのまとまりを安定しては当てられなかった。いちばんよいウォード法でも、ほぼ当てたのは19.3%の回
- 最短距離法は、うまくいく回（図1の例では ARI 0.99）もあるが、92.7%の回で、はずれた数店だけのまとまりを作り、ARI は中央値0.42だった
- 図1の例では、最長距離法・群平均法・ウォード法は細長い A を2つに割り、詰まった B を A の右の部分とまとめた。k-means も A を2つに割った

## 注意（言えないこと）
- 架空のデータです。まとまりの形・大きさ・距離は作成者が置いたもので、どのつなぎ方がよいかはこれで決まります。丸く同じくらいの大きさのまとまりなら、どの方法もよく当てます
- まとまりの数（3）は正解を知って与えています。実際には数も決める必要があります
- 「ほぼ当てた」の基準（ARI 0.9 以上）と「小さなまとまり」の基準（5店以下）は作成者が決めたものです
