# 539 必要な人数を、過去の小さな調査のばらつきから計算すると、本番で差を見つける力はどれだけ足りなくなるのか（統計・実験計画）

2つの群を比べる調査の人数は、「ばらつき（標準偏差）」と「見つけたい差」から決めます。ばらつきは、予備の小さな調査から見積もることが多く、その見積もりにも誤差があります。**ここでは、本当の標準偏差 1・見つけたい差 0.4 の架空の比較で、予備の調査（m 人）から見積もった標準偏差 s をもとに「検出力80%」の人数を決め、本当の標準偏差のもとでの本番の検出力を計算しました。** m を 5〜100人で変え、予備の調査を各100,000回くり返しています。数字は、置いた差と標準偏差で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A539 | 見積もった s で決めた人数で、本番の検出力はどれだけ80%を下回るか | n = ceil(2(z0.975+z0.8)² s²/δ²)、両側5%の t 検定。本番の検出力は非心 t 分布で計算。s をそのまま使う場合と、s の片側80%の上側信頼限界を使う場合を比べる。各 m で100,000回、seed 539 | `src/a539_pilot_sd_power.py` |

## 主な結果
- 本当の標準偏差を知っていれば、各群 **99人** で検出力 80.0%
- **s をそのまま使うと、80%を下回る割合は予備の人数によらず半分強**（m=5 で60%、m=100 で54%）。s の中央値が本当の値より少し小さく出るため
- **大きく下回る割合は、予備が小さいほど多い**：検出力 70%未満になる割合は m=5 で47%、10人で38%、20人で28%、30人で23%、50人で15%、100人で7%
- 検出力の下位10%点：m=10 で 47.5%、30人で 63.9%、100人で 71.6%。平均の人数はどの m でもほぼ99人で、人数の平均は合っていても検出力は下振れする
- **s の上側80%信頼限界で決めると**、80%を下回る割合は約20%、70%未満は m=10 で11%、30人で5%。代わりに人数の平均は m=10 で165人、30人で127人、100人で112人に増える

- 空のフォルダで流し直し、results・figures が一致した
- 確かめとして、m=20 の予備の調査を400回つくり、それぞれ本番の t 検定を500回くり返した。計算の検出力の平均 0.766 に対し、くり返しで出した値は 0.766（results/check_m20.csv）
- 本当の標準偏差で決めた99人の検出力が 0.800 になること

## 注意（言えないこと）
- 架空の比較。実際の調査や試験の数字ではない
- 予備の調査と本番で、ばらつきの本当の値は同じと置いた。対象や時期が違えば、ばらつきそのものも変わりうる
- 見つけたい差（0.4）は決まっていると置いた。差の見積もりの誤差は入れていない
- 上側の信頼限界を使う決め方を勧めるものではない。人数を増やす負担と、検出力が足りない危険のどちらを重く見るかで変わる
