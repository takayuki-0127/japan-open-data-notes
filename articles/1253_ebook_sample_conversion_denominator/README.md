# 1253 試し読みから買った割合は、試し読みの数で割るか、本の紹介ページを見た数で割るかで、本の順がどう変わるのか？（電子書籍）

電子書籍の「試し読みから買った割合」は、買った数を何かで割った値です。割る数（分母）を試し読みの数にするか、本の紹介ページを見た数にするかで、本の順が変わります。しかも電子書籍のシリーズでは、2巻目以降の紹介ページに来る人の中に、前の巻を読んで続きを待っていた人がいて、その人たちは試し読みをせずにそのまま買います。買った数の記録からは、買った人が試し読みをしたかどうかは分かりません。**ここでは、作成者が置いた架空の電子書籍の2つのシリーズ（各6巻、計12冊。紹介ページを見た人のうち、続きを待っていた人の割合・試し読みする割合・試し読みした人のうち買う割合（本当の値）を作成者が置き、乱数で数を作ったもの）で、①買った数÷試し読みの数、②買った数÷紹介ページを見た数の2つで12冊を並べたとき、順がどれだけ入れかわるか、本当の「試し読みした人のうち買った割合」の順とどれだけ合うかを数えました。続きを待っていた人の割合・その人がそのまま買う割合・試し読みする割合の本ごとの差を変えた27通りでも確かめました。**

例の本・数は架空のもので、実在の販売サイトの試し読みの仕組みや集計のしかたを表すものではありません。試し読みの範囲の決め方、値段・広告の決め方、売上の見込みの助言はしていません。

関連する記事：837「反応率の分母（フォロワー・表示・再生）で、良い投稿は入れ替わるのか？」は、SNS の投稿の反応率で分母の選び方によって上位の顔ぶれが変わることを、1198「届かなかったアドレスを分母に残すか除くかで、開封率はどう変わるのか？」は、メールの開封率で届かなかった宛先を分母に入れるかどうかを、1018「キャンセル率は、何を分母にするかでどう変わるのか？」は、予約のキャンセル率の分母を扱っています。この記事は、電子書籍に固有の分母（試し読みの数と紹介ページを見た数）と、シリーズの続きの巻で試し読みをせずに買う人が分子に入る点に絞ります。

## 主な結果

### 基本の置き方（500回、`results/a1253_main.json` の `headline`）
| 比べた2つ | 大小が逆の組（66組中、平均） |
|---|---|
| ①買った数÷試し読みの数 と ②買った数÷紹介ページを見た数 | **24.24組**（10〜90%で18〜31組） |
| ① と 本当の値 | 28.82組 |
| ② と 本当の値 | 21.74組 |
| 比べる相手：試し読みした人の買った数÷試し読みの数（作成者だけが分かる）と 本当の値 | 6.11組 |

- **①と②では66組のうち平均24.24組で大小が逆になり、上位3冊の重なりは平均0.57冊だった**
- ①と本当の値の逆は28.82組で、でたらめに並べたときの見込み（33組）に近かった。上位3冊のうち本当の上位3冊に入っていたのは平均0.946冊（②は1.566冊）
- 2巻目以降の10冊（45組）だけで比べても、①と本当の値の逆は18.77組（でたらめなら22.5組）、②は11.63組だった

### 巻ごと（500回、`results/by_volume.csv`）
| | 1巻 | 2巻目以降 |
|---|---|---|
| ①買った数÷試し読みの数（中央値） | 21.89% | **108.18%** |
| ②買った数÷紹介ページを見た数（中央値） | 3.97% | 14.85% |
| 本当の値（中央値） | 17.5% | 17.59% |
| 買った数のうち、試し読みした人の分（平均） | 77.74% | 15.71% |
| 12冊の中の順位（①・②・本当の平均） | 11.5位・11.5位・6.523位 | 5.398〜5.577位・5.401〜5.664位・6.405〜6.61位 |

- **2巻目以降の本の59.92%で、①は100%を超えた**。1巻は500回を通して一度も超えなかった。2巻目以降の買った数のうち、試し読みした人の分は平均15.71%で、残りは試し読みをしなかった人（1回分のデータでは、ほとんどが続きを待っていた人）の分だった
- ①でも②でも、1巻は平均11.5位と最下位近くに来た。本当の値の順位は巻によらず6.405〜6.61位だった。上位3冊は、①と②では500回の平均で3冊とも2巻目以降、本当の上位3冊では2.516冊だった

### 確かめ：27通り（各40回、`results/grid.csv`）
- ①と②の逆は12.52〜32.72組。**試し読みする割合の本ごとの差が大きいほど増えた**（範囲0.15〜0.25で12.52〜20.9組、0.1〜0.3で20.48〜25.82組、0.05〜0.4で27.92〜32.72組）
- ①と本当の値の逆は14.5〜34.02組で、続きを待っていた人が多いほど増えた（10%で14.5〜27.8組、30%で22.9〜30.6組、60%で28.08〜34.02組）。②と本当の値の逆は12.5〜27.35組
- ①が100%を超えた本は、置き方で平均0〜10冊だった。①の上位3冊のうち2巻目以降の本は、27通りすべてで平均2.975〜3冊だった

- `results/by_volume.csv`：巻ごとの①・②・本当の値の中央値と平均の順位、買った数のうち試し読みした人の分
- `results/reps_base.csv`：基本の置き方の500回（`agree_` は大小が同じ向きの組の数、`top3_` は上位3冊の重なり、`m1_over_100_books` は①が100%を超えた本の数）
- `results/grid.csv`：確かめの27通り（`f` は続きを待っていた人の割合、`d` はその人がそのまま買う割合、`t_lo`・`t_hi` は試し読みする割合の範囲、`disagree_` は逆の組の数）

## 注意（言えないこと）
- 架空のデータと、作成者が置いた買い方です。とくに「続きを待っていた人は試し読みをしない」と置いたことで、2巻目以降の①が大きくなることはほぼ決まります。実在の販売サイトの数を表すものではありません
- ②は「紹介ページを見た人のうち買った割合」としてはずれのない数え方ですが、「試し読みから買った割合」とは別のものを数えています。どちらを使うべきかは、何を知りたいかで決まり、この記事では決めていません
- 試し読みした人がいつ買ったか（数日後に買う人）、1人が何度も紹介ページを見ること、別の端末で試し読みすることは入れていません
- 試し読みの範囲の長さや紹介ページの作り方で、試し読みする割合や買う割合がどう変わるかは扱っていません
