# 163 調剤医療費の伸びは、技術料と薬剤料のどちらか：調剤医療費（電算処理分）の動向（2012〜2024年度）

厚生労働省「調剤医療費（電算処理分）の動向 令和6年度版」の統計表から、薬局の調剤医療費を技術料・薬剤料（内服薬・注射薬・外用薬など）に分け、伸びに対する寄与度を計算したフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A163 | 調剤医療費の伸びは、技術料と薬剤料のどちらによるものか | 項目別の増加額と寄与度分解（期間・年度ごと）、処方箋枚数×1枚当たりへの分解、内服薬1枚当たり薬剤料の3要素（種類数・日数・1日単価）の指数化 | `src/a163_dispensing.py` |

## 主な結果
- 調剤医療費は 2012年度 6兆5,902億円 → 2024年度 8兆4,008億円（+1兆8,106億円、+27.5%）
- 増加のうち技術料 +6,231億円（34%）、内服薬 +6,237億円（34%）、注射薬 +4,925億円（27%）
- 2019→2024年度に限ると、増加 6,983億円のうち技術料が 3,480億円（50%）、注射薬が 3,093億円（44%）で、内服薬は 945億円（14%）にとどまる
- 技術料の割合は 25.8% → 27.7%。注射薬の薬剤料は 1,719億円 → 6,644億円（3.9倍）
- 内服薬の処方箋1枚当たり薬剤料は 2012年度比 101（ほぼ横ばい）。1種類当たり投薬日数は 129 に伸びた一方、1種類1日当たり薬剤料は 80 に下がった
- 処方箋枚数は 7.85億枚 → 8.96億枚（+14.3%）、1枚当たり 8,400円 → 9,372円（+11.6%）

## 注意
- 電算処理分（電子レセプト）の集計で、全数の約99.6%にあたります。保険薬局の調剤分で、病院・診療所の院内処方は入りません
- 令和4年度改定で調剤技術料の一部が薬学管理料に再編されたため、技術料の内訳（調剤基本料・薬剤調製料・薬学管理料など）は2021年度以前と2022年度以降で単純に比べられません。この分析では技術料を合計で扱っています
- 薬剤料は薬価改定（ほぼ毎年）の影響を受けます。2016・2018年度などの減少は薬価改定の年と重なります
- 寄与度＝項目の増加額÷基準年度の総額×100（%ポイント）。増加に占める割合は各項目の増加額÷総額の増加額です
