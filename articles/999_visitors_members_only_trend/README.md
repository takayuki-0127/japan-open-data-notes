# 999 会員の来場だけで、全体の傾向は読めるのか？（来場者と集客）

会員証で入る人の来場は、日付も回数もきちんと記録が残ります。そこで「会員の来場が前年より伸びた」を全体の傾向として読みたくなります。でも、会員はよく来る人に偏っていて、時々しか来ない人の動きはほとんど入りません。会員を増やす募集をすれば、来場の回数が同じでも会員の来場は増えます。**ここでは、作成者が乱数で作った架空の美術館の24か月（常連3,000人と時々の人6万人。人ごとの来やすさと、会員になる人を作成者が置いたもの）で、全体の来場の前年比（本当の値）を、会員の来場・会員1人あたり・1年目からの会員・常連と時々の人に分けて重みを付けた値の4つの読み方と比べ、特別展の強さ・会員募集の大きさ・時々の人の減り方を変えて確かめました。**

| # | 問い | 手法 | ファイル |

| A999 | 会員の来場から読んだ前年比と特別展の伸びは、全体の来場（本当の値）とどれだけずれるか。どう読めば合うか | 架空の美術館の24か月（1〜12か月目が1年目、13〜24か月目が2年目）。来る可能性のある人は常連3,000人と時々の人6万人。人ごとの1か月の来やすさ（平均の回数）はガンマ分布（形2）で、平均は常連1.5回・時々の人0.05回。1か月の回数は来やすさを平均にしたポアソン分布。季節は、時々の人は4か月目と10か月目に山（±35%）、常連はほぼ平ら（±5%）。1年目の会員は、常連の40%（来やすさに比例した確率で選ぶ）と時々の人の3%（でたらめ）。2年目の初めに会員募集をして、残りの常連から同じ選び方で足し、常連の会員を65%にした。2年目は時々の人の来やすさを0.85倍にし、16〜18か月目に特別展（時々の人2.5倍、常連1.2倍）を置いた。会員の来場はすべて記録され、会員でない人の来場は全体の数にしか入らないとした。読み方は (1) 会員の来場の合計、(2) 会員1人あたりの来場（会員の来場÷会員の数）、(3) 1年目からの会員の来場、(4) 1年目からの会員を常連と時々の人に分けて群ごとの前年比を出し、1年目の全体の来場に占める群の割合（常連59.87%）で重み付けしたもの。1回分の結果と、人を作り直した100回。確かめとして、特別展の強さ（時々の人1・2.5・4倍。常連の1.2倍はどれも同じ）×2年目の常連の会員の割合（40%＝募集なし・65%・90%）×2年目の時々の人の来やすさ（1・0.85・0.7倍）の27通り（各20回）。seed 999 | `src/a999_members_only.py` |

## 主な結果

### 前年比（2年目÷1年目−1、100回の平均と10〜90%の範囲、`results/a999_main.json` の reps100）
| 読み方 | 前年比 | 10〜90%の範囲 | 本当の値との差 |
|---|---|---|---|
| 全体の来場（本当の値） | **+11.23%** | +10.55〜+11.9% | |
| 会員の来場 | **+53.88%** | +51.58〜+56.48% | +42.66ポイント |
| 会員1人あたり | +23.11% | +21.26〜+25.19% | +11.88ポイント |
| 1年目からの会員 | **+5.48%** | +4.41〜+6.61% | −5.75ポイント |
| 常連と時々の人に分けて重み付け | +11.59% | +8.49〜+14.12% | +0.37ポイント |

- **全体の来場は+11.23%なのに、会員の来場は+53.88%だった**。ほとんどは会員募集で会員が増えた分で、来る回数が増えたわけではない
- 会員1人あたりにしても+23.11%。募集で足した常連は時々の人の会員より来る回数が多いので、会員の中の顔ぶれが変わっただけで1人あたりが上がった
- 1年目からの会員にそろえると+5.48%で、今度は全体より小さく出た。1年目からの会員の来場は常連がほとんどで、2年目に大きく動いた時々の人（特別展で増え、ふだんは0.85倍に減った）がほとんど入らないため。常連の来やすさは特別展の3か月だけ1.2倍と置いたので、常連の前年比は式で+4.89%（`results/a999_main.json` の main の regular_yoy_formula_pct）になり、1年目からの会員の+5.48%はこの置いた値の写しに近い（作りどおり）
- 常連と時々の人に分けて、群ごとの前年比を全体の来場の割合で重み付けすると+11.59%で、本当の値に近かった。ただし1回ごとの振れは大きく（10〜90%で+8.49〜+14.12%）、時々の人の会員（1,800人、1か月平均0.05回）の少ない来場で決まるため

### 1回分（`data/monthly_visits.csv`）
- 1年目、会員は来る可能性のある人の4.76%だが、来場の33.45%を占めた。2年目は45.93%
- 1年目の常連の会員の1か月の来やすさは平均2.01回、会員でない常連は1.15回、2年目に会員になった常連は1.51回
- 前年比は、全体+10.81%、会員の来場+52.13%、会員1人あたり+21.7%、1年目からの会員+5.29%、重み付け+16.36%（この回は重み付けが5.55ポイント上にずれた）

### 特別展の月（16〜18か月目と前年の同じ月の比べ、100回の平均）
| 読み方 | 前年の同じ月からの伸び |
|---|---|
| 全体の来場（本当の値） | +59.96% |
| 会員の来場 | +78.6% |
| 1年目からの会員 | +23.52% |

- 会員の来場では特別展の伸びが大きく、1年目からの会員では半分以下に見えた。どちらも全体の伸びとは合わない

### 確かめ：27通り（各20回、`results/grid_event_member_occ.csv`）
- 全体の前年比は、置き方で−9.28〜+36.39%と動いた。**1年目からの会員の前年比は、どの置き方でも+3.15〜+7.71%にとどまった**。27通りは時々の人の動きと会員の割合だけを変え、常連の変化（特別展の3か月だけ1.2倍）は変えていないので、常連に置いた+4.89%の近くにとどまるのは作りどおり。新しく数えたのは、全体がこれだけ動いても会員の記録からは見えないこと
- 会員の来場の前年比は+3.15〜+90.59%。全体が減った6通り（特別展なし・時々の人0.85倍か0.7倍）では、会員の来場も1年目からの会員も、6通りすべてで増えたと読めた（向きが逆）
- 会員募集のない9通り（常連の会員40%のまま）では、会員の来場・会員1人あたり・1年目からの会員は同じ値になり、全体との差は−28.81〜+12.34ポイントだった
- 重み付けの値は、27通りのどれでも本当の値との差が−0.5〜+1.05ポイントで、向きも全部合った。これは、同じ群の中では会員も会員でない人も同じ割合で来やすさが変わる、と作成者が置いたからで、作りからそうなる面が大きい

## 動かし方
```
pip install -r requirements.txt
cd src && python a999_members_only.py
```
5秒ほどで終わります。`data/monthly_visits.csv` と `data/regulars_and_occasional_members.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約5秒）
- 会員募集のない9通りで、会員の来場・会員1人あたり・1年目からの会員の前年比が同じ値になることを確かめた（会員が変わらなければ3つは同じ、という作りの確かめ）
- 1年目の12か月は、会員の来場と1年目からの会員の来場が一致した（図1で青と緑の線が重なる）

## データ
- `data/monthly_visits.csv`：1回分の24か月（month・overall（全体の来場）・regular・occasional・members（会員の来場）・member_count・panel（1年目からの会員の来場）・panel_reg・panel_occ・per_member）
- `data/regulars_and_occasional_members.csv`：常連3,000人と、時々の人のうち会員1,800人（person_id・group・rate（作成者が置いた1か月の来やすさ）・member_y1・member_y2・visits_y1・visits_y2）。会員でない時々の人は合計だけを作ったので入っていません

## 注意（言えないこと）
- 架空のデータです。常連と時々の人の人数と来やすさ、季節、会員になる人の選び方、特別展と2年目の変化は作成者が置いたもので、ずれの大きさはこれで決まります。表のとおり、会員の来場と全体の差は置き方で大きく動きます
- 重み付けがよく合ったのは、同じ群の中では会員も会員でない人も同じ動きをすると置いたからです。実際には、会員になった人ほど特別展に反応しやすい、といった違いがありえます。また、全体の来場に占める常連と時々の人の割合を知っているとしました。実際にはこの割合を別に調べる必要があります
- 会員をやめる人、会員になったことで来る回数が増える効き目は入れていません。常連の来やすさの変化（特別展の3か月だけ1.2倍）も変えていないので、1年目からの会員の前年比が+3.15〜+7.71%にとどまったのは置き方の写しです
- 実際の美術館の会員や来場の数字、会員の制度の良し悪しを示すものではありません
- 関連する記事：995（「前年比120%」の来場は、新しい人か、来る回数が増えたのか）は、会員証などで来た人を見分けられるときの伸びの分け方を扱っています。803（口コミを書かなかった人の満足度は、口コミの平均とどれだけ違うのか）は、記録が残る人が全体と違う偏りを口コミで扱っています。同じ企画の1000は再来場率を数える日数とデータの締め日を扱っています。この記事は、会員の記録だけから全体の傾向を読むことに絞りました
