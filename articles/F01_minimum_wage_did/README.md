# F01 最低賃金の引き上げは、雇用を減らしたのか？（差の差・イベントスタディ）

看板記事シリーズの1本目です。2016年度から最低賃金は、ほぼ据え置きだった2020年度を除いて毎年3%台、2023年度以降は4.6〜6.9%上がりました（47都道府県の単純平均）。都道府県のデータで、引き上げが「効きやすい県」と「効きにくい県」を比べ、就業率や失業率が変わったかを確かめます。

## 問い

最低賃金が平均の時給に近い県（＝引き上げの影響を受ける人が多いと考えられる県）で、2016年以降に就業率が下がったり、失業率が上がったりしたか。

## データ

| データ | 表 | URL | 期間 |
|---|---|---|---|
| 総務省「労働力調査 都道府県別結果（モデル推計値）」 | 第1表 15歳以上人口、第3表 就業者、第6表 完全失業率（年平均） | https://www.e-stat.go.jp/stat-search/file-download?statInfId=000031952605&fileKind=0 | 2008〜2025年（元データは2002年から） |
| 厚生労働省「地域別最低賃金の全国一覧」 | 都道府県別の時間額（年度） | https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/roudoukijun/minimumichiran/index.html | 2002〜2026年度 |
| 厚生労働省「平成27年賃金構造基本統計調査」 | 短時間労働者 都道府県別第1表（1時間当たり所定内給与額、産業計・男女計） | https://www.e-stat.go.jp/stat-search/files?toukei=00450091 （statInfId=000029008222〜226） | 2015年6月 |
| 厚生労働省「職業安定業務統計」 | 都道府県別 有効求人数・有効求人倍率（受理地別、年平均） | https://www.e-stat.go.jp/stat-search/files?toukei=00450222 | 2008〜2025年 |

元データのファイルは `data/raw/`（一覧は `data/raw/SOURCES.md`）、県×年パネルは `data/panel.csv`（47県×18年＝846行）です。

## 手法

| 項目 | 内容 |
|---|---|
| 単位 | 都道府県 × 年（2008〜2025年） |
| 処置の強さ（bite） | 2015年6月時点の最低賃金（2014年度の額）÷ 2015年の短時間労働者の平均時給。66.6%（徳島）〜80.0%（青森）、中央値73.3% |
| 比べ方 | bite が中央値（73.3%）より高い23県（処置群、平均75.2%）と、中央値以下の24県（比較群、平均70.9%）。2016年度以降、どちらのグループも最低賃金は同じくらいの率で上がったので（2015→2019年度で約12%）、bite が高い県ほど同じ引き上げが「平均の時給の近くまで」届く、という考え方（Card 1992 型の bite デザイン） |
| 差の差（DID） | 結果 = 県効果 + 年効果 + δ×（処置群 × 2016年以降）。2008〜2019年（コロナ前） |
| イベントスタディ | 処置群ダミー × 各年（基準 2015年）。2008〜2025年 |
| 二方向固定効果（TWFE） | 結果 = 県効果 + 年効果 + β×log(最低賃金)。最低賃金は暦年に合わせて「前年度×9/12 ＋ 当年度×3/12」 |
| 結果の指標 | 就業率（就業者÷15歳以上人口）、完全失業率、有効求人倍率、有効求人数÷15歳以上人口、就業者数（log） |
| 標準誤差 | 県でクラスター。主要な推定は wild cluster bootstrap（Rademacher、999回）の p 値も |

## 主な結果

- **差の差（2008〜2019年）**：処置群の就業率は比較群より **+0.41%pt**（95%信頼区間 −0.03〜+0.86、p=0.07、wild bootstrap p=0.07）。完全失業率は **−0.19%pt**（−0.39〜+0.01、p=0.07）。どちらも「雇用が減った」向きではありません。
- **イベントスタディ**：2008〜2014年の係数は0と区別できません（事前トレンドの検定 p=0.30（就業率）、p=0.29（失業率））。ただ就業率は2008〜11年に −0.2〜−0.4、2012〜14年に +0.06〜+0.22 と、処置前から少しずつ上向いていました。
- **県別トレンドを入れると**：就業率 **+0.00%pt（−0.51〜+0.52）**、失業率 −0.12%pt（−0.31〜+0.07）。処置群で就業率が「上がった」ように見えた分は、もともとの傾きで説明できます。
- **言えること**：2016〜19年の引き上げで、bite の高い県の就業率が低い県より0.5%pt以上下がった、という結果は出ていません。逆に、それより小さな影響があったかどうかは、このデータでは見分けられません（最小検出効果は基本形で約0.64%pt、県別トレンドありで約0.74%pt）。
- **TWFE（log 最低賃金）**：最低賃金10%あたりの就業率の差は、指定により −1.20%pt（県別トレンド・2008〜2025年）から −0.01%pt（基本・2008〜2019年）まで揺れ、失業率は −0.27〜+0.70%pt と符号も変わります。県ごとの上昇率の差（2015→2025年度で東京 +35%〜徳島 +50%）は「低い県を引き上げる」政策で決まっており、地域の景気や高齢化の流れと重なるため、この方法は決め手になりません。

## 頑健性チェック（results/robustness.csv）

| チェック | 就業率 | 完全失業率 |
|---|---|---|
| 基本（2008〜2019年） | +0.41（−0.03〜+0.86） | −0.19（−0.39〜+0.01） |
| プラセボ：2012年に始まったとみなす（2008〜2015年） | **+0.39**（−0.08〜+0.86） | −0.03（−0.24〜+0.18） |
| 県別線形トレンド | +0.00（−0.51〜+0.52） | −0.12（−0.31〜+0.07） |
| 2025年まで延長 | +0.55（+0.09〜+1.02） | −0.20（−0.42〜+0.02） |
| 2025年まで・2020〜22年を除く | +0.53（+0.08〜+0.98） | −0.19（−0.41〜+0.02） |
| 被災3県（岩手・宮城・福島）を除く | +0.40（−0.06〜+0.85） | −0.22（−0.42〜−0.02） |
| 連続版（bite 1標準偏差＝2.7%ptあたり） | +0.26（+0.06〜+0.46） | −0.11（−0.25〜+0.03） |
| 別の指標：有効求人倍率（基本） | −0.05（−0.11〜+0.02） | |
| 並べ替え検定（処置群をランダムに選び直す2,000回） | p=0.06 | p=0.06 |

プラセボ（処置がまだない2012年を開始年とみなす）でも就業率は +0.39 と、本番とほぼ同じ大きさが出ます。就業率の「プラス」は最低賃金の効果ではなく、処置群でもともと就業率が上向いていた流れを拾っている、と読むのが自然です。失業率はプラセボでほぼ0（−0.03）なので、2016年以降の −0.19 には少し意味があるかもしれませんが、県別トレンドを入れると有意ではなくなります。

異質性（results/heterogeneity.csv）：bite を3等分すると、上位3分の1の県の就業率は下位3分の1より 2016〜19年 +0.69%pt、2020〜22年 +0.63%pt、2023〜25年 +0.73%pt（2008〜15年比）で、引き上げ幅が大きくなった2023年以降に下がる様子はありません。

## 言えないこと

1. 県単位の集計だけで、個人や事業所の動き（誰が職を失い、誰が新たに働き始めたか）は分かりません。
2. 労働時間や、価格・賞与・採用基準での調整は見ていません。就業者の数が変わらなくても、時間が減っている可能性は残ります。
3. 最低賃金の引き上げは景気の良い時期に重なっていて、景気の影響と完全には切り分けられません（全国共通の動きは年効果で除いていますが、県ごとに違う景気の動きは残ります）。
4. 処置群と比較群は「最低賃金の上がり方」ではなく「同じ引き上げがどれだけ効くか」で分けています。bite は2015年の値1時点で、短時間労働者の平均時給（企業規模10人以上）を分母にしています。
5. 県別の若者・パートの就業率は今回のデータにないため、影響を受けやすい層だけを見る分析はできていません。モデル推計値は標本調査からの推計で、県によっては誤差が大きいです。

## 設計書からの変更点

- 若年・パート別の異質性は、県別モデル推計値に年齢・雇用形態の内訳がないため、bite の3分位 × 期間の異質性に置き換えました。
- Callaway–Sant'Anna 型の推定は、全県が同時に毎年の引き上げを受ける（処置の開始時期がずれない）ため当てはまらず、連続版の bite、県別トレンド、並べ替え検定で代えました。
- 「代わりの結果指標」は有効求人倍率と有効求人数（職業安定業務統計）を使いました。
