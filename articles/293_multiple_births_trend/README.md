# 293 双子・三つ子の出生は、どれだけ増えたのか

厚生労働省「人口動態統計」確定数（2025年）上巻 4-36（単産－複産別の年次別分娩件数、1995〜2025年）、4-28（母の年齢・単産－複産別の出生数、2025年）、4-6（母の年齢別出生数）を使ったフォルダです。全国の集計だけを使っています。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A293 | 双子・三つ子の出生はどれだけ増えたのか。母の年齢が上がった分で説明できるか | 分娩1,000件あたりの複産（双子以上）の件数の推移。複産の分娩の内訳（「2出生1死産」など）から複産で生まれた子の数を数え、出生に占める割合を計算。2025年の母の年齢別の複産の割合を固定して各年の母の年齢構成に当て（直接標準化）、実際と比べた | `src/a293_multiple_births.py` |

## 主な結果
- 分娩1,000件あたりの複産は、1995年9.0件、2005年11.8件と上がり、2011年に9.6件まで下がりました。2016年から再び上がり、2025年は12.9件で、1995年以降で最も高い値です。件数は1995年1万900件、2004年1万3,215件、2025年8,750件で、割合が上がったのは分娩全体が減ったためでもあります。
- 三つ子以上の分娩は、1995年371件（分娩1万件あたり3.1件）から2015年128件（1.3件）に減り、2025年は147件（2.2件）でした。複産に占める三つ子以上の割合は3.4%から1.7%です。
- 2025年に複産で生まれた子は1万6,840人で、出生の2.5%。母の年齢別の複産の割合は、20〜24歳1.1%、30〜34歳2.6%、40〜44歳3.7%と、年齢が高いほど高くなっていました。
- 2025年の年齢別の割合で固定し、母の年齢構成だけを動かした場合の割合は、1995年2.10%、2015年2.45%、2025年2.51%。実際は1.72%、1.94%、2.51%でした。2015〜2025年の実際の上がり（0.57ポイント）のうち、年齢構成で説明できるのは0.06ポイント（約1割）です。
- 実際の割合と年齢構成だけの見込みの差は、2005年はほぼ0、2010〜2020年は−0.4〜−0.5ポイントで、2021年から縮みました。同じ年齢の中での複産の割合が、2010年代に低く、2020年代に上がったことになります（推測：生殖補助医療での胚の移植のしかたや、不妊治療の受け方の変化が関わっている可能性があります。このデータでは確かめていません）。

## 頑健性
- 複産で生まれた子の数を分娩の内訳から数え直すと、2025年は4-28の複産の出生数（1万6,840人）とぴったり一致した
- 双子だけで見ても、分娩1,000件あたり8.7件（1995年）→11.5件（2005年）→9.5件（2011年）→12.7件（2025年）と、同じ形
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致した

## 動かし方
```
pip install -r requirements.txt
cd src && python a293_multiple_births.py
```

## データ
- `data/jinkou_r7_jokan_4-36_deliveries_single_multiple.csv`：上巻 4-36（statInfId=000040503673）
- `data/jinkou_r7_jokan_4-28_lbw_by_mother_age.csv`：上巻 4-28（statInfId=000040503665）
- `data/jinkou_r7_jokan_4-6_births_mother_age.csv`：上巻 4-6（statInfId=000040503643）
- いずれも e-Stat「人口動態調査 人口動態統計 確定数 出生」（2025年、2026-09-30公表）を2026-11-12に取得したもの（cp932）

## 注意
- 分娩件数は出生と死産を合わせた「出産をした母の数」です
- 母の年齢別の複産の割合は2025年の分しか使っていません。年ごとの年齢別の割合はこの表からは分からないので、比べたのは「年齢構成だけが変わった場合」との差です
- 出生に占める割合は、4-6 に値がある年（1995・2000・2005・2010・2012〜2025年）だけ計算しています
- なぜ複産の割合が変わったのか（治療の方法、制度の変化など）は、このデータでは分けていません
- この記事は統計の数字の変化だけを扱っており、医療や出産についての判断の材料にするものではありません
