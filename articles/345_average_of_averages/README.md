# 345 店ごとの平均を平均すると、全体の平均からどれだけずれるのか（実務の型）

「平均の平均」と全体の平均の差を、宿泊旅行統計（従業者数の4区分の客室稼働率）、商業動態統計（6業態の前年同月比）、架空の200店（客単価）と30店（成約率）で数えたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A345 | 平均の平均は、全体の平均からどれだけずれるか。どんなときに広がるか | 客室稼働率：公表の全体の値／4区分の単純平均／施設数で重みをつけた平均。前年同月比：合計の伸び率／6業態の伸び率の単純平均。架空の店：大きさの偏り（0〜1.5）と、大きさと客単価の結びつき（−0.6〜+0.6）を変えて300回ずつ。成約率：2,000回 | `src/a345_avg.py` |

## 主な結果
- 客室稼働率（2025年）：公表の全体の値 61.6%、4区分の単純平均 62.1%、**施設数で重みをつけた平均 42.4%**（−19.2ポイント。2015〜2025年で −7.5〜−19.9）。施設の81%が従業者0〜9人（稼働率35.6%）
- 2019→2025年の変化：全体 −1.1、単純平均 −1.6、施設数で重み −2.5 ポイント
- 小売6業態の前年同月比（140か月）：単純平均と合計の差は平均0.9ポイント、1ポイントを超えた月が31、向きが違った月が8。最大は2021年4月（合計 +9.1%、単純平均 +29.0%）。前年の売上で重みをつけると合計と一致
- 架空の200店：全店同じ大きさなら0%。偏りがあっても結びつきがなければ +0.4%。**大きい店ほど客単価が高い（+0.6）と、偏り中で −8.4%、偏り強で −15.7%**。逆（−0.6）は +19.3%
- 成約率：どの店も約1ポイント上がったとき、店ごとの率の平均は +0.98、全店の率は +0.62 ポイント。2,000回中293回（15%）で向きが逆

## 動かし方
```
pip install -r requirements.txt
cd src && python a345_avg.py
```
乱数の種を固定してあるので、実行のたびに同じ `results/`・`figures/` を出します。

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- 6業態の前年同月比を前年の売上で重みづけすると、合計の前年同月比と一致した（コード内の assert）

## 注意（言えないこと）
- 「施設数で重みをつけた平均」は4区分の値から出したもので、施設1つずつの稼働率の平均ではありません
- 6業態は小売の全体ではありません
- 架空の店の数字は、置いた偏りと結びつきの強さで決まります
- データは 246（宿泊旅行統計）と 232（商業動態統計）のフォルダの写しです
