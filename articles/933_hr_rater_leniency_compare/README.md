# 933 甘い評価者と辛い評価者の点を、そのまま比べてよいのか？（人事評価）

評価者（上司）によって、同じ働きにも高めの点を付ける人と低めの点を付ける人がいます。会社全体で点の高い順に並べると、甘い評価者の部下が上に集まります。よくある直し方は「評価者ごとの平均点を引く」ことですが、これはチームどうしの本当の実力の差まで消してしまいます。**ここでは、作成者が乱数で作った架空の会社の評価（社員ごとの本当の実力の点と、評価者ごとの甘さを作成者が置いたもの）で、点のまま・評価者ごとの平均を引く・ほかのチームの評価者にも見てもらった人から甘さを見積もって引く、の3つの数え方が、本当の上位20人をどれだけ当てるか、甘い評価者の部下にどれだけ偏るかを数えました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A933 | 評価者の甘さの差があるとき、点のままの上位はどれだけ甘い評価者の部下に偏るか。評価者ごとの平均を引く・甘さを見積もって引くと、本当の上位20人をどれだけ当てるか | 架空の会社の社員200人。評価者20人が自分のチームの10人ずつに100点満点で点を付ける。本当の実力の点は平均60点・標準偏差10点の正規分布で、そのうちチームの平均の差（標準偏差）を基本3点と置く。評価者の甘さ（部下全員に同じだけ足す点）は平均0・標準偏差の基本5点。1回の評価のぶれは標準偏差6点。基本では社員の30%が、ほかのチームの評価者1人にも評価される（2人目の評価）。「甘さを見積もって引く」は、全員の点（本人の評価者と2人目）から社員の実力と評価者の甘さを同時に見積もり（実力の標準偏差10点・ぶれ6点は分かっているとして置いたリッジ付き最小二乗）、本人の評価者の甘さを引く。「甘い4人」は置いた甘さの大きい4人の評価者（部下は全体の20%）。会社を作り直して300回。確かめとして、甘さの差（0・2.5・5・10点）×チームの実力差（0・3・6点）の12通りと、2人目の評価を受ける人の割合（0・10・30・60%）を変えた。seed 933 | `src/a933_rater_leniency.py` |

## 主な結果

### 1社分（`data/ratings_one_company.csv`）
- 置いた評価者の甘さは −9.31〜+8.90点に散らばった（いちばん甘い人と辛い人で18.21点の差）。2人目の評価を受けたのは56人で、見積もった甘さと置いた甘さの相関は0.758だった（`results/evaluators_one_company.csv`）

### 基本の置き方（甘さの差5点・チームの実力差3点、300社の平均）
| 数え方 | 上位20人のうち本当の上位20人 | 上位20人のうち甘い4人の部下 | 本当の点との順位相関 |
|---|---|---|---|
| 点のまま | 55.5% | **43.2%** | 0.774 |
| 評価者ごとの平均を引く | 53.2% | 20.6% | 0.752 |
| 2人目の評価から甘さを見積もって引く | **59.3%** | 20.9% | 0.812 |

- 点のままだと、部下が全体の20%しかいない甘い4人の評価者から、上位20人の43.2%が出た
- 評価者ごとの平均を引くと偏りは20.6%に戻ったが、本当の上位20人を当てた割合は点のままの55.5%から53.2%に下がった。チームの本当の実力の差まで消したため
- 2人目の評価から甘さを見積もって引くと、偏りも戻り（20.9%）、当たりも59.3%に上がった。ただし点のままとの差は3.8ポイントで、1回の評価のぶれ（6点）があるため、どの数え方でも当たりは6割前後にとどまった

### 確かめ：甘さの差とチームの実力差を変えると（`results/robustness_leniency_team.csv`、本当の上位20人を当てた割合）
| 甘さの差 | チームの差 | 点のまま | 平均を引く | 甘さを見積もって引く |
|---|---|---|---|---|
| 0点 | 0点 | **62.9%** | 58.1% | 60.9% |
| 0点 | 6点 | **61.4%** | 40.2% | 53.4% |
| 2.5点 | 3点 | **59.6%** | 52.6% | 58.7% |
| 5点 | 0点 | 55.1% | 58.1% | **60.4%** |
| 5点 | 3点（基本） | 55.5% | 53.2% | **59.3%** |
| 5点 | 6点 | **54.8%** | 40.3% | 54.2% |
| 10点 | 0点 | 42.8% | 57.8% | **59.8%** |
| 10点 | 6点 | 42.4% | 38.9% | **53.3%** |

（12通りの全部は csv。上の表はその一部）

- **どの数え方がいちばん当たるかは、置き方で入れかわった**。甘さの差が0〜2.5点の6通りのうち5通りで点のままがいちばん当たり（残る1通り、2.5点・チームの差0点では見積もって引くが60.5%で点のままの59.9%をわずかに上回った）、甘さの差が10点では3通りすべてで甘さを見積もって引くがいちばん当たった。5点ではチームの差6点のときだけ点のまま（54.8%）が見積もって引く（54.2%）をわずかに上回った
- 評価者ごとの平均を引くは、12通りのどれでもいちばんにならなかった。甘さの差が0点のときは、点のままより4.8ポイント（チームの差0点）、8.0ポイント（3点）、21.2ポイント（6点）低かった
- 当たりの幅は、点のまま42.4〜62.9%、平均を引く38.9〜58.1%、甘さを見積もって引く53.3〜60.9%で、見積もって引くがいちばん動きが小さかった
- 点のままの上位20人に甘い4人の部下が占めた割合は、甘さの差0点で18.7〜20.5%、5点で41.8〜43.2%、10点で62.1〜63.4%だった

### 確かめ：2人目の評価を受ける人の割合（`results/robustness_link_share.csv`、基本の置き方）
| 2人目の評価を受ける人 | 点のまま | 平均を引く | 甘さを見積もって引く |
|---|---|---|---|
| 0% | 55.5% | 52.0% | 52.1% |
| 10% | 54.4% | 52.3% | 55.2% |
| 30%（基本） | 55.5% | 53.2% | 59.3% |
| 60% | 54.2% | 53.3% | 60.9% |

- 2人目の評価がないと、甘さを見積もって引くは評価者ごとの平均を引くとほぼ同じ（52.1%と52.0%）になった。ほかのチームの評価者が同じ人を見ないかぎり、評価者の甘さとチームの実力の差は、点だけからは分けられないため

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の9ファイルがバイト単位で一致した（cmp、約30秒）
- 甘さの差0点・チームの差0点では、点のままの上位20人に甘い4人の部下が占める割合が20.5%で、部下の数の割合（20%）とほぼ同じになることを確かめた
- 作る途中で、甘さの見積もりを、正規方程式を直接解く形と、行列を縦に積んだ最小二乗（numpy の lstsq）の2つで計算し、results の json が一致することを確かめた（いまのコードは速い前者）
- 2人目の評価がないとき、甘さを見積もって引くが評価者ごとの平均を引くとほぼ同じ当たり（52.1%と52.0%）になることを確かめた（理屈どおり）

## データ
- `data/ratings_one_company.csv`：架空の会社1社の社員200人（person_id・evaluator（評価者1〜20）・true_score（置いた本当の実力の点）・own_rating（本人の評価者の点）・second_evaluator（2人目の評価者、0はなし）・second_rating）
- `results/evaluators_one_company.csv`：同じ会社の評価者ごとのまとめ（leniency（置いた甘さ）・team_true_mean_offset（置いたチームの実力の平均の差）・mean_rating・est_leniency（見積もった甘さ））

## 注意（言えないこと）
- 架空のデータです。甘さの差、チームの実力差、評価のぶれは作成者が置いたもので、どの数え方が当たるかはこれで決まります。評価者ごとの平均を引くとチームの差まで消える、2人目の評価がないと甘さとチームの差を分けられない、は置き方から決まる理屈どおりの結果です。新しく数えたのは、その大きさと、どの置き方で入れかわるかです
- 甘さは「部下全員に同じだけ足す」と置きました。点の幅を広く使う人と狭く使う人の違い、好き嫌いで人ごとに変わる甘さは入れていません
- 甘さを見積もる方法には、実力の散らばり（10点）と評価のぶれ（6点）が分かっているとして置きました。実際にはこれも見積もる必要があります
- 2人目の評価者は、ほかのチームから偶然に選ばれると置きました。2人目に誰を選ぶかに偏りがあれば、結果は変わります
- 評価の点をどう使うか（処遇や給与の決め方）については、ここからは何も言えません
- 関連する記事 915 は、検査員どうしの合否の一致を数え、甘めの線の2人がいちばんそろうことを示しています。この記事の評価者の甘さも、そろっていることと正しいことが違うという点で同じです。801 は、件数の少ない店の星を全体の平均に寄せて読む話で、この記事の「甘さを見積もる」も、手がかりの少ない評価者の甘さを0に寄せて見積もっています。同じ企画の 941 は、部署ごとの平均点の散らばりのうち評価者の分を数え、評価者全員が同じ共通の事例を採点して直しています。この記事は部署の平均ではなく1人ずつの点で上位20人を選ぶ話で、直し方も別のチームの評価者に同じ人を見てもらう形です。943 は、上司ごとに点をそろえると強いチームの人を下げることを「2年連続でA」の基準で、924 は年ごとに難しさが違う試験の点を共通の問題でつなぐ方法を数えています
