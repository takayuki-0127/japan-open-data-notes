# 657 交互作用を見つけるには、主効果を見つけるときの何倍の件数が要るのか（手法の解説・正解の分かるデータで試す）

「施策は駅前の店でよく効くのか」のような交互作用（効き方の違い）は、施策の効果そのもの（主効果）より見つけにくいことが知られています。**ここでは、施策の有無と店の種類（駅前・郊外）を同じ数ずつ組み合わせた2×2の架空の実験で、主効果0.2と、同じ大きさ・半分の大きさの交互作用を、件数を変えて2,000回ずつ検定し、検出力80%に要る件数を比べました。** 指標のばらつき（標準偏差1）と効果の大きさは作成者が置いたもので、数字はその仮定で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A657 | 同じ大きさの主効果と交互作用で、要る件数はどれだけ違うか | 回帰 y = a + b·A + c·B + d·A×B（A・B は ±1/2 で符号化）の b と d の t 検定。マスの平均から計算し、1回分を statsmodels の OLS と一致させた。全体100〜16,000件、各2,000回。seed 657 | `src/a657_interaction.py` |

## 主な結果
- **検出力80%に要る全体の件数**：主効果0.2は **800件**、同じ大きさの交互作用0.2（施策の効果が駅前0.3・郊外0.1）は **3,200件（4倍）**、半分の交互作用0.1は **12,800件（16倍）**
- 正規近似の計算（主効果 4(z₀.₉₇₅+z₀.₈)²/δ²）でも785件・3,140件・12,558件で、シミュレーションと合った
- **全体800件のとき**：主効果は81.2%で見つかるが、交互作用0.2は29.8%、0.1は11.3%
- **なぜ4倍か**：±1/2 の符号化で、交互作用の推定（効果の差）は主効果の推定（効果の平均）の **2倍の標準誤差** になる（800件で 0.143 と 0.071）。件数は標準誤差の2乗で効くので4倍


## 確かめたこと
- 空のフォルダで流し直し、results・figures がバイト単位で一致した
- マスの平均から出した b・d が、statsmodels の OLS（`y ~ A * B`）の係数と一致し、交互作用の標準誤差がちょうど主効果の2倍になること

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 657）
- 仮定：4つのマスに同じ件数、どのマスもばらつきは同じ（標準偏差1）、正規分布

## 注意（言えないこと）
- シミュレーションの結果。効果の大きさは作成者が置いたもので、結果はこれで決まる
- 「交互作用を同じ大きさ」と言うとき、何と比べるかで倍率は変わる。ここは「効果の平均」と「効果の差」が同じ大きさの場合
- マスの件数がそろっていない場合や、店の種類が2つより多い場合は扱っていない
