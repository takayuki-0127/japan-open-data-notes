# 438 1年に働く時間は、いつ2,000時間を切ったのか（毎月勤労統計調査、1950〜2025年）

毎月勤労統計調査の月間の総実労働時間（事業所規模30人以上）を12倍して、年間の時間を76年分並べたフォルダです。087（実質賃金と働く時間）と近いですが、時間だけを長く追っています。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A438 | 年間の時間が最も長かった年、2,000時間・1,800時間を切った年はいつか。一般労働者だけで見るとどうか | 月間の総実労働時間×12。1993年からは一般労働者・パートタイム労働者別。1993→2025年の減りを「それぞれの時間が減った分」と「パートの割合が増えた分」に分ける | `src/a438_hours.py` |

## 主な結果
- 30人以上の事業所の年間の時間：1950年 2,335時間 → 1960年 2,432時間（最長、月202.7時間）→ 1975年 2,064時間 → 1988年 2,111時間 → 1993年 1,913時間 → 2025年 1,693時間
- 1960→1975年に368時間減り、1975→1988年は47時間増え、1988→1993年に198時間減った
- 2,000時間を切ったのは1992年（1,972時間）。1,900時間は1997年、1,800時間は2009年（その後2010・2012年に戻り、2013年からは下）、1,700時間は2020年（1,685時間）が最初
- 一般労働者だけ（30人以上、1993年〜）：1993年 2,010時間、2007年 2,034時間（最長）、2018年 1,993時間、2020年 1,910時間（最短）、2025年 1,916時間。2,000時間を最後に上回ったのは2017年
- パートタイム労働者の割合（30人以上）：1993年 11.6% → 2025年 25.3%。パートの年間の時間は 1,168 → 1,031時間
- 1993→2025年の減り220時間のうち、一般・パートそれぞれの時間が減った分が102時間、パートの割合が増えた分が118時間（54%）
- 5人以上の事業所（1990年〜）：1990年 2,064時間 → 2025年 1,621時間。1,800時間を切ったのは2008年
- 所定内は1970年の2,039時間から2025年は1,555時間。所定外は127〜200時間のあいだ（1970年 200、1975年 127、2025年 138）。出勤日数は月22.9日 → 17.8日

## 確かめたこと
- 2つの資料が重なる1970〜2005年の月間の時間は、1年を除いて一致（差は最大0.1時間）
- 空のフォルダで流し直し、data・results・figures が一致した

```
pip install -r requirements.txt

```

## データ
- `data/raw/chouki_19-15.xls`：総務省統計局「日本の長期統計系列」19-15 産業別常用労働者月間実労働時間（事業所規模30人以上、1950〜2005年）。Internet Archive の保存版から取得（2026-11-12）
- `data/maikin_jissu_TL_CY.csv`：e-Stat「毎月勤労統計調査 全国調査 長期時系列表 実数・指数累積データ 実数」（statInfId=000032189776、2026-11-12取得）から、調査産業計（TL）の年平均（CY）の行だけを抜き出したもの。規模の記号は 0＝30人以上、T＝5人以上、就業形態は 0＝計、1＝一般、2＝パート

## 注意（言えないこと）
- 年間の時間は「月間の時間×12」です。公表の年間の値と小数の丸めの分だけ違うことがあります
- 1950〜69年は「調査産業計（サービス業を除く）」、1970年からは「調査産業計」です。重なる1970〜2000年では、サービス業を除く値のほうが月0.4〜3.3時間長く、線はここで少し段があります
- 事業所が答えた時間です。記録されていない残業は入りません。働く人が答える調査（労働力調査など）の時間とは水準が違います
- 調査の対象や推計の方法は何度か変わっています（産業分類の改定、標本の入れ替え、再集計）。細かい年ごとの上下は、その影響を含みます
- パートの割合が増えた分と、それぞれの時間が減った分への分け方は、2時点の平均で重みをつけた1つの方法です
- 時間が減った理由（週休2日・法律・景気・働き方など）は分けていません。全国・調査産業計だけで、産業ごとの違いは見ていません
