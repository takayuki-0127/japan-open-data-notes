# 1231 言いかえて検索し直す人が減ったのは、見つかったからか、あきらめたからか？（検索の良さ）

検索のやり方を新しくしたあと、言葉を言いかえて検索し直す人が減ると、「1回目で見つかるようになった」と読みたくなります。けれども、検索し直さずに終わる道は2つあります。1回目で正しい文書が見つかった人と、1回目で見つからず、言いかえるのもやめた人（あきらめた人）です。検索の記録には、検索語・クリック・読んだ長さは残りますが、探しものが見つかったかどうかは残りません。**ここでは、作成者が置いた架空の社内の文書検索（探しものの種類、検索するたびに正しい文書が上位10件に入る確率、見つからないときに言いかえる確率を作成者が置いたもの）で、古い検索 A と新しい検索 B の「検索し直した割合」の減りを、1回目で見つかった分と1回目であきらめた分に分け、記録から見える数（検索し直した割合・クリックのない検索の割合・長く読んだクリックの割合）が本当に見つかった割合とどれだけ合うかを数えました。置き方を変えた54通りで確かめました。**

例の検索と文書は架空のもので、実在の会社の検索の仕組みを表すものではありません。どちらの検索を使うとよいかを勧める記事ではありません。

関連する記事：1188「よくある質問のページを増やして問い合わせが減ったとき、減ったのは解決した人か、あきらめた人か？」は、問い合わせ窓口の件数の減りを、ページで解決した人とあきらめた人に分けています（置いた例では、10→320ページの減りの43.73%があきらめた人）。窓口には問い合わせてこなかった人の記録が残りませんが、検索では1回ごとの検索語とクリックが残ります。1227「クリックされた文書を正しいと見なすと、上に出ていた文書はどれだけ有利になるのか？」は、クリックを正しさの答えに使うと、今の検索の上に出ていた文書が有利になることを扱っています。この記事は、検索の記録に固有の見える数（検索し直し・クリックのない検索・長く読んだクリック）が、見つかったかどうかをどれだけ表すかに絞ります。クリックのない検索には、結果の一覧の要約だけで答えが分かった人もまざります。

## 主な結果

### 基本の置き方（2万件×50回の平均、`results/base_compare.csv`・`results/a1231_main.json`）
| | A 古い検索 | B 新しい検索 | B−A |
|---|---|---|---|
| 検索し直した割合（記録から見える） | 39.33% | 27.89% | **−11.44ポイント** |
| 1つの場の検索の回数（平均、記録から見える） | 1.5674回 | 1.387回 | −0.1804回 |
| クリックのない場の割合（記録から見える） | 24.15% | 27.47% | +3.32ポイント |
| 長く読んだクリックのある場の割合（記録から見える） | 61.24% | 57.26% | −3.97ポイント |
| 1回目で見つかって終わった | 47.57% | 53.53% | **+5.96ポイント** |
| 1回目であきらめて終わった | 13.1% | 18.58% | **+5.47ポイント** |
| 本当に見つかった | **72.42%** | **67.36%** | −5.06ポイント |
| 本当にあきらめた | 27.58% | 32.64% | +5.06ポイント |
| 見つかった（よくある探しもの） | 79.81% | 84.67% | +4.85ポイント |
| 見つかった（まれな探しもの） | 55.21% | 27.03% | −28.18ポイント |
| クリックがなく、見つかっていた場の割合 | 12.11% | 12.18% | +0.07ポイント |

- **検索し直した割合は39.33%から27.89%へ11.44ポイント減った。そのうち5.96ポイントは1回目で見つかって終わった場の増え、5.47ポイントは1回目であきらめて終わった場の増えで、減りの47.85%はあきらめた分だった**
- 検索し直さなかった場は「1回目で見つかった」か「1回目であきらめた」のどちらかなので、検索し直した割合の減りは、この2つの増えの足し算にちょうど分かれる（作りどおり。表の値は丸めのため0.01ずれる）
- **本当に見つかった割合は、検索し直しが減ったのに72.42%から67.36%へ下がった**。B はよくある探しものでは見つかりやすくなった（+4.85ポイント）が、まれな探しものでは55.21%から27.03%に下がった。B がまれな探しものに弱く、見つからないときに言いかえにくいと置いたので、向きは置き方どおり
- クリックのない場は24.15%から27.47%に増えた。クリックのない場の約半分（A 12.11%・B 12.18%）は、要約だけで答えが分かって見つかっていた場で、クリックのない場をそのまま「あきらめた」とは数えられなかった
- 1回分の例（`data/sessions_B_example.csv`、B の2万件）：検索し直した割合28.44%

### 確かめ：54通り（各2万件×10回、`results/grid.csv`）
- **検索し直した割合が減ったのは54通り中52通り。そのうち37通りでは、本当に見つかった割合も下がっていた**（15通りでは上がった）。本当に見つかった割合の変化は−16.01〜+6.45ポイント、検索し直した割合の変化は−20.62〜+0.14ポイント
- 減りのうちあきらめた分の割合は、−37.42%〜102.53%と置き方で大きく動いた（負は、1回目であきらめた場がかえって減った置き方。100%を超えるのは、1回目で見つかった場が減った置き方）
- B で見つからないときの検索し直しやすさを A と同じ（1倍）にした18通りでも、検索し直しは16通りで減った。このときあきらめた分の割合は−37.42%〜61.06%で、まれな探しものの見つかりやすさを0.15に置いた6通りでは見つかった割合が下がった。0.6倍の18通りでは48.17%〜101.28%だった
- 長く読んだクリックのある場の割合の増減の向きは、54通り中51通りで本当に見つかった割合の向きと合った。合わなかった3通りは、見つかった割合の変化が小さい（±1.16ポイント以内）置き方だった
- クリックのない場は、本当に見つかった割合が上がった置き方のうち8通りでも増えた

## 注意（言えないこと）
- 架空のデータです。B がまれな探しものに弱いこと、見つからないときに言いかえにくいこと、要約で答えが分かる確率は作成者が置いたもので、あきらめた分の割合はこれで大きく動きます（−37.42%〜102.53%）。実在の検索でどれくらいかは分かりません
- 1つの場は1つの探しものと置き、途中で探しものを変える人、別の日に探し直す人、ほかの人に聞く人は入れていません
- 長く読んだクリックは、正しい文書なら必ず長く読み、違う文書でも一部は長く読むと置きました。読む長さの線の引き方は扱っていません
- 本当に見つかったかどうかは、ここでは作成者が置いたので分かりますが、実際の記録には残りません
- どちらの検索を使うとよいかは扱っていません
