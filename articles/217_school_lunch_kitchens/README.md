# 217 給食は自校方式かセンター方式か：学校給食実施状況等調査の都道府県差

文部科学省「学校給食実施状況等調査」で、公立小・中学校の給食の調理方式（単独調理場＝自校方式、共同調理場＝センター方式、その他）の割合を都道府県ごとに比べ、平成22年度（2010）から令和7年度（2025）への変化を見たフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A217 | 自校方式とセンター方式の割合は都道府県でどれだけ違うか。15年でどう変わったか | 調理方式別の学校数から単独調理場方式の割合を計算。タイル地図、小・中学校の比較、2010年度と2025年度の散布図 | `src/a217_kitchens.py` |

## 主な結果
- 令和7年度、全国の公立小学校17,996校のうち自校方式は45.5%、センター方式は53.9%。中学校（8,695校）は自校24.3%、センター65.1%、その他10.5%
- 小学校の自校方式の割合は、神奈川87.1%、福岡83.8%、東京81.1%、大阪75.9%、京都74.8%が高く、島根1.1%、鳥取2.7%、青森8.5%、沖縄10.2%が低い。中央値は34.3%
- 47都道府県中44で、中学校の自校方式の割合が小学校より低い（神奈川は小学校87.1%に対し中学校2.8%）
- 2010→2025年度で、小学校の自校方式の割合は39都道府県で下がり、平均−6.4ポイント。山口−24.8、山梨−24.4、宮崎−20.0。上がったのは群馬+4.0、千葉・埼玉+3.7など
- 自校方式の小学校は10,260校→8,187校、センター方式は10,738校→9,699校

## 動かし方
```
pip install -r requirements.txt
cd src && python a217_kitchens.py
```

## データ
- `data/lunch_kitchen_type_pref_2010_2025.csv`：平成22年度 第8表「都道府県調理方式別完全給食実施状況（公立小・中学校数）」と、令和7年度 第7表「都道府県調理方式別学校給食実施状況（公立小・中学校、義務教育学校、中等教育学校（前期課程）数）」から、小学校・中学校の学校数と調理方式別の内訳を抜き出したもの（義務教育学校・中等教育学校は含めていない）

## 注意
- 平成22年度の表は完全給食の実施校、令和7年度の表は学校給食の実施校が対象で、範囲が少し違います。中学校の学校数が増えているのは、中学校給食を始めた自治体があるためと考えられ、中学校の15年比較はしていません
- 「その他調理方式」は民間の調理場からの配送（デリバリー方式）などです
- 学校数の割合で、児童生徒数の割合ではありません。小さな学校が多い県では、学校数と人数の割合がずれます
