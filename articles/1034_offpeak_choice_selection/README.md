# 1034 混む時間帯を避けると、どれだけ早く着くのか？（移動と時間）

通勤の記録で「混む時間帯を避けた便は、混む時間帯の便より平均で十数分早く着いている。だから避ければそれだけ早くなる」と読むことがあります。しかし、混む時間帯を避けるかどうかは、通勤する人が選んでいます。会社の近くに住む人ほど時間をずらしやすければ、避けた便はもともと道のりが短く、避けたこととは関係なく早く着きます。**ここでは、作成者が乱数で作った架空の通勤者3,000人の20日分（人ごとの道のりと、混む時間帯に乗ったときのよけいな時間＝避けたときの本当の得を作成者が置いたもの）で、避けた便と混む便の所要時間をそのまま比べた差と、本当の得を比べました。道のりをそろえる比べ方、同じ人の日どうしで比べる比べ方も並べ、避ける人の選ばれ方を変えた9通りも確かめました。**

通勤者・路線・会社はすべて架空のもので、実在の路線や通勤の記録は使っていません。

## 主な結果

### 基本：近い人ほど・よけいな時間の大きい人ほど避けやすい（100回の平均、`results/estimates_base.csv`）
| 比べ方・本当の得 | 避けると何分早いか（100回の平均） | 100回の10〜90% |
|---|---|---|
| ①そのまま比べる（混む便の平均−避けた便の平均） | **14.78分** | 14.215〜15.288分 |
| ②1kmあたりで比べる（×全員の平均の道のり） | 2.557分 | 2.281〜2.79分 |
| ③道のりをそろえる（道のりを入れた回帰） | 5.481分 | 5.345〜5.61分 |
| ④同じ人の、混む日と避けた日の差 | 7.053分 | 6.865〜7.242分 |
| 本当の得：いま混む時間帯に乗っている便 | **6.865分** | 6.694〜7.064分 |
| 本当の得：全員の平均 | 7.062分 | 6.892〜7.234分 |
| 本当の得：いま避けている便 | 7.437分 | 7.212〜7.648分 |
| 本当の得：両方の日がある人 | 7.06分 | 6.883〜7.252分 |

- **そのまま比べると避けた便は14.78分早かったが、いま混む時間帯に乗っている便が避けたときの本当の得は6.865分だった（2.153倍）**
- 避けた便の平均の道のりは11.5483km、混む便は15.5057kmだった。避けた日は全体の34.47%
- そのままの差と本当の得（混む便）のずれは7.915分で、空いている時間帯の「2分×道のり」に道のりの差を入れた式の値（7.915分）と同じだった。このモデルでは、そのままの差は「混む便の本当の得」＋「道のりの違いの分」になる（式どおり）
- ②1kmあたりで比べると、2.557分と小さく出すぎた。所要時間に入っている決まった8分は、道のりの短い人ほど1kmあたりで大きく効く。避けた便は道のりが短いので、1kmあたりの時間が長く見える
- ③道のりを入れた回帰は5.481分で、本当の得（混む便）の0.798倍だった。本当の得は道のりに比例して大きくなるが、回帰は「どの人も同じ分だけ縮む」形で表すため、とずれたと考えている（推測）
- ④同じ人で比べると7.053分で、両方の日がある人の本当の得（7.06分）とほぼ同じだった。両方の日がある人は85.17%で、一度も避けなかった人（12.72%）と毎日避けた人（2.11%）はこの比べ方に入らない

- **①そのままの差は、選ばれ方で−2.856〜16.504分と動いた。遠い人ほど避けると置いた3通りでは負になり、「避けると遅く着く」ように見えた**。どの通りでも本当の得（混む便）は5.409〜8.461分の正の値
- ①と本当の得（混む便）のずれは−8.882〜+8.495分で、9通りすべてで道のりの差からの式の値と0.011分以内で合った
- 道のりで選ばれていない（b_d＝0）3通りでは、①は本当の得（混む便）とほぼ同じだった（ずれ−0.038〜−0.011分）
- ③道のりを入れた回帰でも、本当の得（混む便）からのずれは−1.621〜+1.444分残った
- ④同じ人で比べた値は、9通りすべてで両方の日がある人の本当の得と0.01分以内で合った。ただし、いま混む時間帯に乗っている便の本当の得とは−2.344〜+1.885分ずれた。よけいな時間の大きい人ほど避ける（b_g＝＋0.8）と、いま避けている便の得（7.44〜10.131分）は混む便の得より大きくなり、避けている人の経験は、混む時間帯に乗っている人がまねしたときの得より大きく出る

```
pip install -r requirements.txt
cd src && python a1034_offpeak.py
```

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約2秒）
- そのままの差と本当の得（混む便）のずれが、「2分×（混む便の平均の道のり−避けた便の平均の道のり）」の式の値と、基本で一致し（7.915分対7.915分）、9通りで0.011分以内だった
- 避ける人が道のりでもよけいな時間でも選ばれない通り（b_d＝0・b_g＝0）で、4つの比べ方と4つの本当の得がすべて7.021〜7.117分にそろうことを確かめた（作りの確かめ）

## データ
- `data/commuters.csv`：基本の置き方の1回分の3,000人。person_id・distance_km（道のり）・extra_min_per_km_peak（混む時間帯の1kmあたりのよけいな分数、作成者が置いた値）・true_gain_min（避けたときの本当の得、分）・p_avoid（避ける日の確率）・days_peak／days_avoid（20日のうち混む時間帯に乗った日・避けた日）・mean_min_peak／mean_min_avoid（それぞれの日の平均の所要時間。その日がない人は空欄）

## 注意（言えないこと）
- 架空のデータです。道のりの分布、所要時間の式（8分＋2分×道のり）、混む時間帯のよけいな時間の分布、避ける人の選ばれ方は作成者が置いたもので、結果はこれで決まります。そのままの差のずれは、置いた所要時間の式から決まる値（式どおり）です。実在の通勤の記録を表すものではありません
- 避ける人がいても、混む時間帯の混み方は変わらないと置きました。避ける人が増えると混み方が変わる場合（878 で扱っています）は、得の大きさも変わります
- 混む時間帯を避けると、家を出る時刻や会社に着く時刻が変わります。その不便さや、時刻をずらせるかどうかは扱っていません。混む時間帯を避けるべきかの助言はしません
- ④同じ人で比べる方法が当たったのは、ある人の得が日によって変わらないと置いたためです。避ける日を、その日の事情（遅れの見込みなど）で選ぶ場合は、同じ人でもずれます（推測）
- まれに起きるとても大きな遅れは扱っていません
