# F180 2つの統計の数字は、本当に同じものを測っているか？

国勢調査と、同じ名前の数字を出している別の統計（住民基本台帳・労働力調査）を、都道府県と市区町村で突き合わせました。使った手法は Bland–Altman 法と一致相関（CCC）です。ふつうの相関が1に近くても「一致している」とは限らないことを、5つの組で確かめます。

## 問い

- 国勢調査と住民基本台帳の「人口」「世帯数」「外国人人口」、国勢調査と労働力調査の「完全失業率」「就業率」は、どれだけ一致するか。
- ずれは偶然の揺れか、決まった向きの系統的なずれか。
- 相関・一致相関・Bland–Altman の一致の限界は、それぞれ何を教えてくれるか。

## データ

| 統計 | 内容 | 単位・時点 |
|---|---|---|
| 国勢調査（総務省） | 総人口・日本人人口・外国人人口・世帯数・15歳以上人口・就業者数・完全失業者数・非労働力人口 | 市区町村（SSDSE-A）、2015年・2020年の10月1日 |
| 住民基本台帳に基づく人口、人口動態及び世帯数調査（総務省） | 人口（総計・日本人・外国人）・世帯数 | 都道府県・市区町村、2016年・2021年の1月1日（都道府県の総数は2015年・2020年の1月1日も） |
| 労働力調査 都道府県別結果（モデル推計値）（総務省） | 15歳以上人口・就業者数・就業率・完全失業率 | 都道府県、2015年・2020年の年平均 |

- 国勢調査の都道府県の値は、市区町村を足し上げて作りました。
- 国勢調査の率は、労働力状態「不詳」を除いて計算しています。
  - 完全失業率＝完全失業者÷（就業者＋完全失業者）
  - 就業率＝就業者÷（就業者＋完全失業者＋非労働力人口）
  - 確認用に、分母を「年齢が分かる15歳以上人口」（不詳を含む）にした就業率も作りました。
- 住民基本台帳は、国勢調査の3か月後（翌年1月1日）の値です。確認用に、前後の1月1日から10月1日の値を直線でならした値も作りました。
- 市区町村は、団体コードの上5桁で突き合わせました（2015年1,739、2020年1,741）。

## 手法

- **Bland–Altman 法**：2つの統計の差（人数は「対数の差×100」＝おおよその%、率はポイント）を、平均の大きさに対して描きます。
  - 平均のずれ（bias）：系統的なずれの大きさ
  - 一致の限界（bias±1.96×標準偏差）：個々の地域で、ずれがどこまで広がるか
  - 比例的なずれ：差を大きさに回帰した傾き
  - 平均のずれと一致の限界には、ブートストラップ（2,000回、種180）で95%区間を付けました。
- **一致相関（Lin の CCC）**：相関に「平均のずれ」と「ばらつきの大きさの違い」の罰を加えた指標です。完全に一致すれば1になります。
- **年をまたいだ安定性**：県ごとのずれの、2015年と2020年の相関です。高ければ、ずれは偶然ではなく系統的だと考えられます。

  - 相関も CCC も1.000 でしたが、住基の方が平均0.9〜1.2%多く、47県中42〜44県で住基が多くなりました。
  - 県の人口が大きいほど、ずれは小さくなりました（傾き−0.58、p&lt;0.001）。

- **外国人人口**：住基が全47県で多く、平均+16〜21% でした。全国では、国勢調査240万人に対し住基281万人です（2020年）。
- **完全失業率**
  - 全47県で、労働力調査の方が低くなりました（−1.15〜−1.42ポイント）。
  - 国勢調査の値に対する労働力調査の傾きは0.72 / 0.69 で、県の差を小さめに出しています。
  - 相関0.75〜0.84 に対し、CCC は0.13〜0.30 でした。
- **就業率**
  - 国勢調査の分母から「不詳」を除くと、ずれは0.2〜0.9ポイントでした。
  - 分母に「不詳」を含めると2.5〜5.4ポイントになり、そのずれは「不詳」の割合と相関0.91〜0.95 でした。
  - 「不詳」の割合は、県の平均で4.0%（2015年）から7.5%（2020年）に増えています。

## 結果（市区町村、人口と世帯数）

- 2011年の原発事故で避難指示区域が設定された福島県の12市町村では、国勢調査（実際に住む場所）と住基（住民票の場所）が極端にずれました。2020年の人口は、中央値で住基が1.8倍です。2015年は5町村で国勢調査の人口が0でした。
- この12市町村を除くと、人口の平均のずれは+2.2% / +2.0%、一致の限界は−3.2〜+7.6% / −3.3〜+7.3% でした。
- 人口規模別（2020年）の平均のずれは、次のとおりです。人口の小さい市区町村ほど住基が多く、幅も広くなります。

| 人口規模 | 平均のずれ | 標準偏差 |
|---|---|---|
| 5千人未満 | +2.9% | 4.6 |
| 5千〜2万 | +2.9% | 2.2 |
| 2万〜10万 | +1.7% | 1.7 |
| 10万〜100万 | +0.3% | 1.6 |
| 100万以上 | −1.3% | 1.5 |

- ずれの年をまたいだ順位相関は、人口0.86、世帯数0.92 でした。

## 頑健性

1. **組を変える**：人口・日本人人口・外国人人口・世帯数・15歳以上人口・就業者数・失業率・就業率の8組で比べました。
2. **年を変える**：2015年と2020年で比べました。ずれの向きは、人口で96%、世帯数・外国人・失業率で100%の県が同じでした。
3. **単位を変える**：
   - 都道府県と市区町村で比べました。
   - 人数のまま・対数・人口あたりの3つの尺度で比べました。
   - 率は、分母の取り方を2通りにしました。
4. **時点をそろえる**：住基を10月1日にならしました。
5. **丸めの影響**：労働力調査の失業率は小数1桁なので、±0.05 の揺れを1,000回足しました。CCC は0.128〜0.138 で、結論は変わりません。
6. **外れた地域を除く**：避難指示区域が設定された12市町村を除いた場合と、含めた場合を両方示しました。

## 言えないこと

- どちらの統計が「正しい」かは決められません。国勢調査は実際に住んでいる場所で、住基は住民票の場所で人を数えます。世帯の決め方も違います。ずれの多くは、定義の違いから来ていると考えられます（推測）。
- 住基が多い理由として、住民票を移さずに進学・就職・入所で移った人や、国外転出の届け出の遅れが考えられます。ただし、このデータでは人数を分けられません（推測）。
- 労働力調査の都道府県別の値はモデル推計で、標本調査の結果を全国の動きで補った値です。県の差が小さめに出るのはそのためと考えられます（推測）。月ごとの調査の平均と、10月の1週間の調査という時期の違いも分けていません。
- 国勢調査の「不詳」が、どの労働力状態の人に多いかは分かりません。就業率の分母をどちらにするのが適切かも、このデータでは決められません。
- 2時点・47都道府県の比較で、年ごとの動きは見ていません。
- 個々の都道府県・市区町村の値の良し悪しを評価するものではありません。
