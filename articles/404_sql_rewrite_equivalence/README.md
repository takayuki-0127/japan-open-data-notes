# 404 SQL を書き直したとき、結果が同じだとどう確かめるか（実務の型）

集計の SQL を読みやすく書き直したり、速くするために書き直したりしたあと、「結果は前と同じ」をどう確かめるかを比べたフォルダです。架空の注文20万行で、もとの SQL と、違いを1つずつ入れた書き直し10本を用意し、5つの確かめ方がいくつ見つけるかを数えました。あわせて、答えは同じなのに「違う」と出てしまう書き直し6本（見かけの差）でも試しました。233（合計が合わないときの調べ方）に対し、ここでは書き直しの前後の比べに絞ります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A404 | 確かめ方ごとに、10個の違いのうちいくつ見つけるか。答えが同じ6本で、何本が「違う」と出るか | 確かめ方は、並べずに行の位置で比べる／件数と合計（ぴったり・0.1%まで許す）／EXCEPT を両方向／EXCEPT ALL を両方向／行のハッシュの合計と件数。列の順・数の型・小数の桁をそろえてから比べる場合も試す | `src/a404_rewrite_check.py`、`src/pairs_sql.py` |

## 主な結果
| 確かめ方 | 違い10個のうち見つけた | 同じ答え6本で「違う」 | そろえた後（見つけた／「違う」） |
|---|---|---|---|
| 並べずに行の位置で比べる | 10 | 4 | 10／3 |
| 件数と合計（ぴったり） | 9 | 2 | 9／0 |
| 件数と合計（合計は0.1%まで許す） | 8 | 0 | 8／0 |
| EXCEPT（両方向） | 8 | 3 | 8／0 |
| EXCEPT ALL（両方向） | 10 | 3 | 10／0 |
| 行のハッシュの合計と件数 | 10 | 4 | 10／0 |

- **件数と合計が見逃したもの**：区分の名前を2つ取り違えた書き直し（行数も合計も同じ）。0.1%まで許すと、「丸めてから足す→足してから丸める」（合計の差は−2,479円、0.0003%）も見逃した
- **EXCEPT が見逃したもの**：明細に DISTINCT を足した書き直し（正しい重複の1,221行が消える）と、6月が2回入った書き直し（同じ行が2つあるだけ）。EXCEPT は同じ行をまとめて比べるので、行の数の違いは見えない。EXCEPT ALL は両方見つけた
- **見かけの差**：足す順が変わった浮動小数の合計、AVG と SUM÷COUNT、整数と浮動小数の型の違い、列の順、並び順。そろえる前は、EXCEPT ALL が3本、ハッシュが4本で「違う」と出た
- **そろえてから比べる**（数は小数2桁に丸めて DECIMAL に、列は名前の順に）と、行の位置で比べる方法のほかは、見かけの差が0本になり、見つける数は変わらなかった

## 動かし方
```
pip install -r requirements.txt
cd src && python a404_rewrite_check.py     # 10秒ほど
```

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した
- 違いを入れた10本は、どれも EXCEPT ALL の両方向で1行以上の差が出る（本当に違うことの確認、コード内の assert）

## 未検証
- SQL は T-SQL でも通る書き方に寄せましたが、SQL Server では動かしていません。DuckDB 1.5（1スレッド）で実行しました
- SQL Server には EXCEPT ALL がありません。同じことをするには、行ごとに件数を数えてから EXCEPT で比べる、などの書き方が要ります（未検証）
- ハッシュは md5 の先頭13桁を足しました。SQL Server の `CHECKSUM_AGG` や `HASHBYTES` での結果は確かめていません

## データ
- すべて架空（作成者が乱数で作成、seed 404）。`data/customers.csv`（顧客3,000。「法人」のうち20件は後ろに空白つき）、`data/orders_sample5000.csv`（注文200,800行のうち5,000行の抜き出し。全体はコードが作る）

## 注意（言えないこと）
- 10個の違いと6本の見かけの差は、作成者が選びました。「10本中いくつ」は、選び方で変わります
- 小数2桁に丸めて比べると、2桁より小さい本当の違いは見えなくなります。丸める桁は、数字の使い道で決めます
- 結果が同じでも、それは手元のデータでの話です。データにない場面（NULL が入る、重複がある）での違いは見えません
- 速さは比べていません
