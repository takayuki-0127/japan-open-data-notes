# 934 5段階評価の「3」に集まると、何が見えなくなるのか？（人事評価）

5段階の評価では、評価者が真ん中の「3」を付けやすく、社員の多くが「3」になることがあります（中心化）。**ここでは、作成者が乱数で作った架空の会社の評価（社員ごとの本当の実力と、評価者が受ける印象のぶれを作成者が置いたもの）で、1〜5を広く使う付け方と「3」に7割が集まる付け方を比べ、本当の上位10%がどれだけ「3」に埋もれるか、評価で上位30人を選べるか、実力が伸びた人の評価が上がるかを数えました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A934 | 「3」に集まると、本当の上位の人・実力の伸びがどれだけ見えなくなるか。上位を選ぶ当たりはどれだけ下がるか | 架空の会社の社員300人。本当の実力は平均0・標準偏差1の正規分布。評価者の印象は、本当の実力に標準偏差0.5のぶれを足したもの。印象を5段階に区切る位置は、狙った割合になるように置く：「段階を広く使う」は1〜5が10・20・40・20・10%、「3に集まる」は5・10・70・10・5%。2年目は、社員の20%の本当の実力が0.5（標準偏差の半分）伸び、ほかは変わらないと置き、印象のぶれは引き直し、区切りは1年目と同じ位置にした。上位30人を評価で選ぶときは、上の段から取り、同じ段の中はくじで決める。会社を作り直して300回。確かめとして、「3」の割合（40・55・70・85%、残りは1:2:2:1で両側に分ける）×印象のぶれ（0.3・0.5・0.8）の12通りを数えた。seed 934 | `src/a934_center_three.py` |

## 主な結果

### 1社分（`data/grades_one_company.csv`）
- 「3」は、段階を広く使うと115人、3に集まると215人だった。本当の上位30人のうち「3」になったのは、広く使うと0人、3に集まると5人だった

### 段階を広く使う と 3に集まる（300社の平均、`results/wide_vs_center.csv`）
| | 段階を広く使う | 3に集まる |
|---|---|---|
| 「3」の人の割合 | 39.8% | 70.2% |
| 本当の上位10%のうち「3」の人 | 2.8% | **18.6%** |
| 「3」の人の本当の順位（下から数えた%、10〜90%の範囲） | 24.8〜74.8% | 18.8〜81.2% |
| 評価と本当の実力の相関 | 0.854 | 0.774 |
| 評価で選んだ上位30人のうち、本当の上位30人 | 64.4% | 62.3% |
| 実力が伸びた人のうち、評価が上がった人 | 46.9% | **30.6%** |
| 実力が伸びた人のうち、評価が変わらなかった人 | 44.3% | 63.7% |
| 伸びていない人のうち、評価が上がった人 | 23.9% | 15.2% |
| 評価が上がった人のうち、本当に伸びた人 | 33.1% | 33.3% |

- 3に集まると、本当の上位10%の18.6%が「3」の中に入り、ほかの「3」の人と見分けがつかなくなった。「3」の人の本当の順位は、下から18.8%の人から81.2%の人までにわたった
- **評価で上位30人（10%）を選ぶ当たりは、64.4%と62.3%でほとんど変わらなかった**。3に集まっても4と5で15%いるので、上位10%は4と5の中から選べるため。見えなくなるのは、4・5に入らなかった上位の人と、「3」の中の違い
- 実力が伸びた人の評価が上がる割合は46.9%から30.6%に下がり、63.7%の人は伸びても評価が変わらなかった。評価が上がった人のうち本当に伸びた人は、どちらでも33%ほどで、上がったことの確かさは変わらなかった
- 印象を区切らずに点のまま持っていたときの相関（理屈の値）は0.894で、5段階に区切るだけで0.854、3に集まると0.774に下がった。区切ると情報が減るのは式どおりで、新しく数えたのは、上位の人・伸びた人がどれだけ見えなくなるかの大きさ

### 確かめ：「3」の割合と印象のぶれを変えると（`results/robustness_share3_noise.csv`）
| 「3」の割合 | 本当の上位10%が「3」（ぶれ0.3〜0.8） | 伸びた人の評価が上がる | 上位30人の当たり |
|---|---|---|---|
| 40% | 0.2〜10.8% | 45.1〜48.6% | 52.0〜74.9% |
| 55% | 1.0〜18.8% | 40.1〜41.1% | 51.7〜71.7% |
| 70%（3に集まる） | 7.8〜31.7% | 30.6〜31.6% | 51.5〜71.7% |
| 85% | 33.8〜55.0% | 18.2% | 47.0〜67.2% |

- 本当の上位10%が「3」に埋もれる割合は、12通りで0.2〜55.0%まで動き、「3」の割合とぶれの両方で大きくなった
- **伸びた人の評価が上がる割合は、ぶれにはほとんどよらず、「3」の割合でほぼ決まった**（40%で45.1〜48.6%、85%で18.2%）
- 上位30人の当たりは、主にぶれで決まり（ぶれ0.3で67.2〜74.9%、0.8で47.0〜52.0%）、「3」の割合が85%になって4と5を合わせても10%に届かなくなったところで下がった

## 動かし方
```
pip install -r requirements.txt
cd src && python a934_center_three.py
```
10秒ほどで終わります。`data/grades_one_company.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約7秒）
- 区切りの位置で狙った「3」の割合が出ていることを確かめた（狙い40%で39.8%、70%で70.2%、85%で84.9〜85.1%）
- 「3」が70%・ぶれ0.5の升は「3に集まる」と同じ置き方なので、同じ乱数で数えて値が一致するようにした

## データ
- `data/grades_one_company.csv`：架空の会社1社の社員300人（person_id・true（置いた本当の実力）・impression（評価者の印象）・grade_wide（段階を広く使ったときの評価）・grade_center（3に集まったときの評価））

## 注意（言えないこと）
- 架空のデータです。本当の実力の分布、印象のぶれ、区切りの位置、伸びの大きさは作成者が置いたもので、結果はこれで決まります。段階に区切ると情報が減ること、「3」が増えるほど上位や伸びが埋もれることの向きは、置き方から決まる理屈どおりの結果です
- 評価者は1人で、全員に同じ区切りを使うと置きました。評価者ごとに区切りが違うときの話は入れていません（関連する記事 933 は、評価者ごとの甘さの違いを数えています）
- 「3」に集まる理由（評価者の迷い・説明の手間など）は扱っていません。どちらの付け方がよいか、評価をどう処遇に使うかは、ここからは言えません
- 関連する記事 868 は、満足の段階の数（3・5・7段階）で満足の割合がどう変わるかを、861 は「どちらでもない」を入れると賛成の割合がどう動くかを数えています。この記事は、段階に区切ったあとで、上位の人と伸びがどれだけ見えなくなるかを数えています。同じ企画の 938 は、直近の出来事に引っぱられた少しのずれで、段の境目の近くの人の段が入れかわることを、939 は5段階の点を足すと同点が多く出ることを数えています
