# 670 退会と転居の2つの理由で会員が抜けるとき、片方を打ち切りにした生存曲線は、退会の割合をどれだけ大きく見るのか（手法の解説・正解の分かるデータで試す）

会員が抜ける理由が2つ以上あるとき（退会と転居など）、片方の理由で抜けた人を「打ち切り」として Kaplan–Meier の生存曲線を描き、1から引いて「退会の割合」とすることがあります。この値は「転居が起きない世界での退会の割合」で、実際に退会で抜ける割合より大きく出ます（競合リスク）。実際の割合は累積発生関数（Aalen–Johansen 推定）で出せます。**ここでは、架空の会員2万人で、転居の起きやすさを変えたとき、3年以内に退会で抜ける割合を2通りで出し、本当の値と比べました（各100回）。** 数字は置いた起きやすさで決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A670 | 転居を打ち切りにした 1−KM は、退会の割合をどれだけ大きく見るか | 退会の起きやすさ 0.15/年、転居 0〜0.30/年（指数分布）。入会は0〜4年に散らばり、5年で観察を締める。1−Kaplan–Meier（転居を打ち切り）と累積発生関数を3年の時点で比べる。本当の値は式から。各100回、seed 670 | `src/a670_competing.py` |

## 主な結果
- **転居がなければ2つは同じ**：36.2%（本当36.2%）
- **転居があると、1−KM は転居の多さに関係なく約36%のまま**。本当の退会の割合は転居 0.10/年で31.7%、0.20/年で27.9%、0.30/年で24.7%に下がるので、**1−KM は15%・30%・47%大きく見る**
- **累積発生関数**はどの場合も本当の値と0.1ポイント以内で合った
- **理由別の 1−KM を足すと、抜けた人より多くなる**：転居 0.30/年で、退会の1−KM＋転居の1−KM は95.7%、実際に3年以内に抜けた人は74.1%
