# 198 日照時間の「晴れの県ランキング」は、何年で入れ替わるか：気象庁 過去の気象データ

気象庁「過去の気象データ」の年ごとの値から、47都道府県の県庁所在地など47地点の年間日照時間を1987〜2025年で並べ、順位がどれだけ入れ替わるかを見たフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A198 | 日照時間の県別順位は、何年で入れ替わるか | 年ごと・13年平均ごとの順位、間隔（1〜30年）別のスピアマン順位相関の平均、1位・上位5・下位5に入った回数 | `src/a198_sunshine.py` |

## 主な結果
- 1年違いの順位相関は平均0.87、10年違いで0.86、30年違いでも0.84。年ごとの入れ替わりはあるが、離れるほど入れ替わる形にはなっていない
- 13年平均の順位は、1987〜1999年と2013〜2025年で順位相関0.94
- 山梨（甲府）は39年中21年で1位、36年で上位5。秋田は34年で下位5、山形28年、青森26年
- 13年平均で順位が上がったのは茨城（水戸）25→13位、埼玉（熊谷）12→3位、大阪18→10位。下がったのは沖縄（那覇）33→43位、大分16→24位、宮崎6→14位
- 47地点の平均は1987〜1999年1,871時間→2013〜2025年2,026時間。最も長い年は2023年（2,158時間）、短い年は1993年（1,660時間）

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a198_sunshine.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/sunshine_annual.csv | 都道府県、地点、地点番号、年、年間日照時間（時間）、品質の印（] は資料不足値） |

- 気象庁「過去の気象データ検索」の地点ごとの年ごとの値（annually_s）から日照時間の列を書き写した（1981〜2025年）
- 地点は各都道府県の気象台など。埼玉は熊谷、滋賀は彦根、北海道は札幌、沖縄は那覇
- ブラウザでページを読み、47地点の合計値が元のページと一致することを確かめた

## 注意
- 1986年に日照計の種類が変わり、それより前とは比べにくいため、分析は1987年から
- 資料不足値（]）の9個は使わず、その年はその地点を順位から外した（残りの46地点で順位をつけた）
- 県の値ではなく、1地点の値。同じ県でも地点によって日照時間は違う
- 地点の移転や観測機器の変更による影響は取り除いていない
- 2026年は年の途中のため使っていない
