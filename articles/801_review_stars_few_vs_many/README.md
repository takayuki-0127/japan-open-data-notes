# 801 星4.8（5件）と星4.3（500件）は、どちらが良い店か？（口コミと星の数）

口コミサイトでは、件数の少ない店ほど星の平均が上にも下にも大きく振れます。平均の星の順に並べると、上位には件数の少ない店が集まります。**ここでは、作成者が乱数で作った架空の店2,000軒（本当の満足度を作成者が置いたもの）で、星の平均そのまま・件数で寄せた平均（ベイズ平均）・件数の多い順の3つの並べ方を比べ、「5件で星4.8前後」と「500件で星4.3」の店のどちらが本当に良いかを数えました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A801 | 件数の少ない高評価の店と、件数の多いそこそこの店は、どちらが本当に良いか。並べ方で上位はどれだけ当たるか | 架空の店2,000軒。本当の満足度は平均3.9・標準偏差0.35の正規分布（2.5〜4.8で切る）。口コミの件数は1〜1,000件（対数で一様）。1件の星は、平均が本当の満足度になる1〜5の分布から引く。上位20軒の当たりは店を作り直して200回の平均。「4.8（5件）対 4.3（500件）」は、店2万軒×40回の中から、件数4〜6件で平均4.7以上の店と、件数400〜600件で平均4.25〜4.35の店を取り出して比べた。店どうしの差（標準偏差）を0.2・0.35・0.5に変えた確かめも行った。seed 801 | `src/a801_few_vs_many.py` |

## 主な結果

### 並べ方ごとの上位20軒（200回の平均）
| 並べ方 | 本当の上位20軒に入っていた割合 | 上位20軒の件数（中央値） | 上位20軒の本当の満足度（平均） |
|---|---|---|---|
| 平均の星そのまま | **6%** | 約1件 | 4.16 |
| 件数で寄せる（m=10） | **48%** | 約252件 | 4.71 |
| 件数で寄せる（m=30） | 39% | 約373件 | 4.68 |
| 件数で寄せる（m=100） | 29% | 約519件 | 4.64 |
| 件数の多い順 | 1% | 約964件 | 3.90 |

- 平均の星そのままで並べると、上位20軒はほぼ口コミ1件の店になり、本当の上位20軒に入っていたのは6%だった（1回分のデータでは、上位20軒すべてが5件以下の店）
- 「件数で寄せる」は、全体の平均（3.91）を m 件分足して割る並べ方（ベイズ平均）。m=10 で当たりは48%に上がった。m を大きくしすぎると件数の多い店に寄り、当たりは下がった

### 「5件前後で星4.7以上」と「500件前後で星4.3」
| | 5件前後・星4.7以上 | 500件前後・星4.3 |
|---|---|---|
| 本当の満足度の平均 | 4.38 | 4.29 |
| 本当の満足度の10〜90%の範囲 | 4.02〜4.76 | 4.24〜4.35 |

- 5件の店の本当の満足度は、平均で4.38まで割り引かれた。それでも、500件の店より本当に良い確率は**64%**だった。ただし幅が広く、1割の店は4.02以下だった
- **どちらが良いかは、店どうしの本当の差の大きさで逆転した**。5件の店が良い確率は、店どうしの差（標準偏差）を0.2にすると18%、0.5にすると84%（基本の0.35では64%）

### 本当の満足度4.0の店で、見かけの平均が振れる大きさ
| 件数 | 見かけの平均の標準偏差 | 見かけが4.5以上になる割合 |
|---|---|---|
| 1件 | 0.79 | 27.8% |
| 5件 | 0.36 | 7.4% |
| 10件 | 0.25 | 3.3% |
| 30件 | 0.15 | 0.0% |
| 500件 | 0.04 | 0.0% |

## 注意（言えないこと）
- 架空のデータです。店どうしの差の大きさ、件数の分布、1件の星の散らばりは作成者が置いたもので、結果はこれで決まります。とくに「4.8（5件）と4.3（500件）のどちらが良いか」は、店どうしの差の置き方で逆転します
- 口コミを書く人は、来た人全員からでたらめに選ばれると置きました。とても満足した人や不満な人ほど書きやすい偏り、サクラの投稿は入れていません（別の記事で扱う予定）
- 実際の口コミサイトの並べ方や点数の出し方を表すものではありません
- m=10 がいちばん当たったのは、この置き方での結果です。どの m がよいかは、店どうしの差と1件の星の散らばりで変わります
