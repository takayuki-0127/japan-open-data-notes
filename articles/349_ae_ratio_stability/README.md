# 349 実際の死亡数と見込みの比は、何人分のデータで安定するのか

集団の死亡率が見込みどおりかを確かめるとき、「実際の死亡数÷見込みの死亡数」（A/E 比）を見ます。この比が偶然でどれだけ振れるか、何人×何年のデータがあれば±10%に収まるのかを、見込みが正しいと分かっている架空の集団で測ったフォルダです。346（損害率は何件で安定するか）と組です。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A349 | A/E 比が10回のうち9回、±10%に収まるのに必要な人数×年数はどれだけか。年齢の構成が違うとどうなるか | 標準の表どおりに死亡が起きる集団を作り、見込みの死亡数を5〜2,000人に変えて A/E 比を4,000回ずつ出す。若い・中年・高齢の3つの集団で必要な人数×年数を探す。年齢でずれ方が違う場合の全体の比も出す | `src/a349_ae_ratio.py` |

## データ
- 見込みに使う標準の表：厚生労働省「令和6年簡易生命表」（男）の20〜94歳の死亡率（`data/standard_qx_2024_male.csv`、F268 のフォルダから写したもの）
- 集団は架空。若い集団（25〜54歳）、中年の集団（45〜69歳）、高齢の集団（65〜89歳）で、それぞれの年齢に同じ人数。死亡は年齢ごとの二項分布
- 乱数の種は349

## 主な結果
### 見込みの死亡数と、比の振れ方（本当の比は1.00）
| 見込みの死亡数 | 比の5〜95%の範囲 | ±10%に収まった割合 | ±20%に収まった割合 |
|---|---|---|---|
| 5人 | 0.40〜1.80 | 18% | 37% |
| 20人 | 0.65〜1.35 | 34% | 63% |
| 50人 | 0.78〜1.24 | 52% | 85% |
| 100人 | 0.84〜1.17 | 67% | 95% |
| 300人 | 0.90〜1.10 | 91% | 100% |
| 1,000人 | 0.95〜1.05 | 100% | 100% |

- **比が10回のうち9回、±10%に収まるには、見込みの死亡数で約270人が必要だった**（式では (1.645÷0.10)²＝271人。シミュレーションでは263〜293人）
- **人数×年数に直すと、年齢で40倍違う**。若い集団（25〜54歳）で22.7万人年、中年（45〜69歳）で4.3万人年、高齢（65〜89歳）で5,500人年
- 見込みの死亡数が20人のとき、比が0.65〜1.35の間なら「見込みどおり」と区別がつかない
- 比の95%の区間（ポアソン分布の正確な区間）が本当の値1.00を含んだ割合は、見込み20人以上で95%前後。5人では99%（区間が広すぎる側にずれる）

### 保険金額で数えた比
- 1人ごとの保険金額がばらつく（対数正規、変動係数1.3）と、金額で数えた比を±10%に収めるには、件数のときの2.7倍（1＋変動係数²）のデータが要る。若い集団で57万人年、中年で12万人年、高齢で1.5万人年
- 件数なら足りる量のデータ（見込みの死亡数で約270人）で金額の比を見ると、±10%に収まったのは67〜72%

### 年齢でずれ方が違うとき
本当の死亡率÷標準の表を、50歳未満0.80・50〜69歳1.00・70歳以上1.15と置いた場合の、全体の比（データが十分あるとき）：

| 集団（どれも40〜79歳） | 全体の比 | 見込みの死亡のうち70歳以上 |
|---|---|---|
| 若い人が多い | 1.05 | 47% |
| どの年齢も同じ人数 | 1.09 | 65% |
| 高齢の人が多い | 1.11 | 73% |

- **全体の比は、死亡の多い高い年齢のずれでほぼ決まる**。若い人が多い集団でも、見込みの死亡の47%は70歳以上
- **全体の比を50歳未満にそのまま当てはめると、32〜38%高く見積もる**（本当は0.80のところを1.05〜1.11と見る）
- 年齢の幅が違う集団では差がもっと大きい：25〜54歳の集団は0.88、45〜69歳は0.99、65〜89歳は1.14

```
pip install -r requirements.txt

```
`data/example_ae_10000x5.csv`（中年の集団1万人の5年分の例）、`results/main.json`、`results/ae_by_expected_deaths.csv`、`results/need_person_years.csv`、`results/age_mix_overall_ae.csv`、`results/age_mix_cross_error.csv`、`results/age_range_overall_ae.csv`、`figures/` の3枚ができます（約5秒）。

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures がバイト単位で一致した
- 必要な見込みの死亡数は、式（271人）とシミュレーション（263〜293人）で比べた

## 注意（言えないこと）
- 見込みの表が正しい（本当の比が1.00）と分かっている架空の集団です。実際には、比が1から離れているのが偶然か本当の差かを、この幅と見比べて判断することになります
- 死亡は人ごとに独立としています。同じ人が複数の契約を持つ場合や、流行・災害で死亡がまとまって起きる年は、比の振れはもっと大きくなります
- 必要な人数×年数は、置いた年齢の構成と標準の表（全国の男）で決まります。女性の表や、選択された集団（加入時に健康な人）では数字が変わります
- 年齢でずれ方が違う場合の数字（0.80・1.00・1.15）は、説明のために置いたものです
- 死亡率の見込みの立て方や、保険料について助言するものではありません
