# 760 欠けた値を「-999」で埋めたまま回帰すると、係数はどれだけずれるのか（手法の解説・正解の分かるデータで試す）

システムによっては、値が欠けているときに「-999」や「9999」のような目印の値を入れます。表では数字に見えるので、そのまま回帰に入れてしまうことがあります。**ここでは、架空の会員1,000人（年間の利用額 = 2 + 0.5×会員歴 + 1.0×来店回数 + 誤差）で、会員歴の1〜30%が欠けて -999 が入っている場合に、3つの扱い方で係数と予測の誤差を各300回測りました。** 欠ける割合と係数は作成者が置いたもので、数字はその置き方で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A760 | -999 のまま回帰すると、係数と予測はどれだけずれるか | A -999 のまま線形回帰、B 平均で埋めて「欠けの印」（0/1）の列を足す、C 欠けた行を除く。欠け1・5・10・30%（無作為）、各300回。テストデータも同じ割合で欠ける。参考に決定木（深さ5）。seed 760 | `src/a760_sentinel.py` |

## 主な結果
- **係数はほぼ0になる**：会員歴の係数（本当は0.5）は、-999 のままだと欠け1%でも0.0019（本当の0.4%）、5%で0.0004。-999 の点が離れすぎていて、傾きを横に引っぱる
- **ほかの係数はずれない**：来店回数の係数は0.99〜1.01。欠けが無作為なので、会員歴の効き目が誤差に回るだけ
- **予測の誤差**：-999 のままの線形回帰は RMSE 3.50〜3.52 万円で、欠けなし（2.00）の1.75倍。B（平均＋欠けの印）と C（欠けた行を除く）は欠け1%で2.03、30%で2.55
- **決定木は -999 を扱える**：決定木は -999 を「別の区分」として切り分けるので、-999 のままでも RMSE 2.28〜2.78 で、欠けの印を足した場合（2.25〜2.73）とほぼ同じ

## 動かし方
```
pip install -r requirements.txt
cd src && python a760_sentinel.py
```
数秒で終わります。`results/summary.csv` に欠けの割合ごとの係数と予測の誤差を書き出します。

## 確かめたこと
- 空のフォルダで流し直し、results・figures がバイト単位で一致した
- 欠けなしの線形回帰の RMSE が、置いた誤差の標準偏差（2.0）とほぼ同じになることを確かめた

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 760）
- 仮定：会員歴は0〜20年の一様分布、来店回数は平均4のポアソン分布、誤差は標準偏差2の正規分布。欠けは会員歴の値と無関係（無作為）

## 注意（言えないこと）
- シミュレーションの結果。欠けが無作為なので、B と C は同じくらいよかった。欠け方が値や結果と関係するときは、B も C もずれることがある
- 決定木の結果は深さ5の1本だけ。ほかの木のモデルでも同じとは限らない（推測）
- 実在の会員の数字ではない
