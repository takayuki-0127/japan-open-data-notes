# 542 問い合わせの分類を2人が別々に付けると、何%が食い違い、カッパ係数はいくつになるのか（実務の型・分類の品質）

問い合わせにカテゴリを付ける作業は、人によって付け方が少しずつ違います。**ここでは、架空の問い合わせ（本当のカテゴリ6つ）に2人の担当者 A・B が別々にカテゴリを付けると置き、一致率・コーエンのカッパ係数（偶然の一致を除いた一致の度合い）・混同行列を出しました。あわせて、件数が少ないときにカッパがどれだけ揺れるか、カテゴリが偏るとカッパがどれだけ下がるかを見ました。** 人ごとの取り違えやすさや、どちらとも取れる問い合わせの割合は作成者が置いたもので、数字はその仮定で決まります。

|---|---|---|---|
| A542 | 2人の付け方の一致率とカッパ、件数とカテゴリの偏りでカッパがどう動くか | 一致率、コーエンのカッパ（自作の式と scikit-learn の cohen_kappa_score で一致を確認）、混同行列、同じ仕組みから1,000回作り直した95%の範囲（50〜2,000件）、いちばん多いカテゴリの割合を17〜90%に変えた比較（各200回）。seed 542 | `src/a542_kappa.py` |

## 主な結果
- **2,000件**：一致 78.1%、食い違い 438件（21.9%）。偶然に一致する見込みは 18.3% で、カッパは 0.73
- 本当のカテゴリと比べた正しさは A 88.1%・B 84.0%（カッパ 0.85・0.80）。2人とも同じ間違いをした（一致したが本当とは違う）のは 54件
- **どちらとも取れる問い合わせ（15%と置いた）**では一致は 50.3%、それ以外は 83.0%
- **食い違いの多い組み合わせ**：配送と返品・交換（95件）、請求・支払いとアカウント（62件）、使い方とアカウント（42件）
- **件数とカッパの幅（1,000回の95%の範囲）**：50件 0.56〜0.85、100件 0.61〜0.82、200件 0.64〜0.78、500件 0.67〜0.76、2,000件 0.69〜0.74。50件ではカッパが 0.6 を下回る回が 8.7%
- **カテゴリの偏り**：付け方の仕組みは同じまま、いちばん多いカテゴリの割合を 17%→90% にすると、一致率は 76.5〜76.8% でほぼ変わらず、カッパは 0.71→0.41 に下がった（偶然に一致する見込みが 18%→60% に上がるため）

## 確かめたこと
- 空のフォルダで流し直し、results・figures がバイト単位で一致した
- 自作のカッパの式と scikit-learn の cohen_kappa_score が一致した（差 1e-12 未満）
- カテゴリの偏りの比較では、カテゴリごとの正しく付ける確率と取り違えの傾向を変えていないこと

## データ
- データファイルは置いていない。問い合わせとカテゴリはコードの中で乱数から作る（seed 542）
- 仮定：本当のカテゴリの割合 請求・支払い 22%・配送 26%・返品・交換 16%・使い方 18%・アカウント 12%・その他 6%。ふつうの問い合わせで正しく付ける確率 A 92%・B 88%。どちらとも取れる問い合わせ 15%（正しく付ける確率 55%、間違えるときは2人とも同じ相手のカテゴリに寄る）。間違えるときの付け先は人ごとに置いた（B は配送と返品・交換を取り違えやすい、など）

## 注意（言えないこと）
- 架空のデータ。実際の問い合わせや担当者の数字ではない
- カッパの大きさは、置いた正しさ・取り違えの傾向・カテゴリの割合で決まる。「0.6以上なら十分」のような目安の良し悪しは扱っていない
- 2人の一致は「正しさ」とは別のもの。2人が同じ間違いをすれば一致に数えられる
- 3人以上の一致（フライスのカッパなど）や、重み付きカッパ、偏りに強い別の指標（Gwet の AC1 など）は比べていない
