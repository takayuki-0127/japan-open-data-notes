# 263 初雪の日は、どれだけ遅くなったのか（日ごとの表で毎年そろえて作れる「初めて雪が1cm以上積もった日」で見る）

気象庁「過去の気象データ検索」の日ごとの値（14地点、1931〜2025年）を使ったフォルダです。262〜266の5本は同じデータ（`data/jma_daily_14st_1931_2025.tsv.gz`）を使っています。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A263 | 初雪の日は、どれだけ遅くなったのか（日ごとの表で毎年そろえて作れる「初めて雪が1cm以上積もった日」で見る） | 寒候年（8月〜翌7月）ごとに最深積雪1cm以上の最初・最後の日と日数を求め、1961〜1990年平均からの差を9地点で平均。直線の傾き（HC1標準誤差）、Theil–Sen、期間平均の比較 | `src/a263_first_snow_cover.py` |

## 主な結果
- 9地点の平均で、初めて雪が積もる日は1931〜2024年の直線で10年に0.8日（標準誤差0.3日）遅くなっていました。1961年以降に限ると10年に1.3日です。年ごとの揺れは大きく、1つの冬の遅い・早いは珍しくありません。
- 春に最後に雪が積もっていた日は、10年に1.3日のペースで早くなっていました。秋〜冬の始まりが遅くなるより、春の終わりが早くなるほうが大きかったことになります。
- 1931〜1960年の平均と1995〜2024年の平均を比べると、9地点のうち8地点で遅くなっていました。いちばん大きいのは伏木（富山県）と根室の8日で、伏木は12月9日から12月17日、根室は11月29日から12月7日です。山形は11月30日から12月5日、網走は11月12日から11月17日でした。寿都（北海道）はほぼ同じです。
- 地点ごとの傾きの95%区間が0を含まないのは、9地点のうち3地点でした。1つひとつの地点で「はっきり遅くなった」と言えるほどではなく、9地点をまとめると見えてくる、という大きさです。
- 始まりが遅く、終わりが早くなったぶん、雪が1cm以上積もっていた日数は減りました。1931〜1960年と1995〜2024年で比べると、伏木で14日、境で14日、根室・彦根で10日、山形で9日、網走で6日少なくなっています。
- 雪が積もらない冬が多い地点では、東京で積もらない冬が1931〜1960年の30冬中2冬から、1995〜2024年は11冬に増えました。銚子と宮崎は、もともと多くの冬で積もりません。

## 頑健性
- 初めて5cm以上積もった日で見ても、9地点の中央値で10年に0.6日遅くなった
- 傾きを Theil–Sen 法で測っても、9地点の中央値で10年に0.8日遅くなった
- 1953年ごろから記録のある「降雪の深さ1cm以上」の最初の日と比べると、同じ地点・同じ冬で差の中央値は0日（656冬）で、積雪で見ても降雪で見ても同じ日になることが多い
- 1961年以降に限ると、9地点平均の傾きは10年に1.3日（標準誤差0.5日）
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致した

## 動かし方
```
pip install -r requirements.txt
cd src && python a263_first_snow_cover.py
```
`src/fetch.py` は気象庁のページから同じ形のデータを取り直すスクリプトです（全地点・全月で約1.6万ページ。ふつうのネット環境向けで、このデータを取ったときはブラウザの中で同じページを読みました。このスクリプト自体は動かして確かめていません）。

## データ
- `data/jma_daily_14st_1931_2025.tsv.gz`：気象庁「過去の気象データ検索」日ごとの値（daily_s1、view=p1）を2026-11-12に取得し、地点・年・月・日・降水量合計・平均気温・最高気温・最低気温・降雪の深さ合計・最深積雪・天気概況（昼・夜）を取り出したもの（485,786行）。値の印（`)` 準正常値、`]` 資料不足値、`×` 欠測、`--` 現象なし）はそのまま残し、`src/common.py` で `)` は使う、`]`・`×` は欠測、`--` は0として読みます
- 地点：網走・根室・寿都・山形・石巻・伏木・飯田・銚子・境・浜田・彦根・多度津・宮崎（気象庁が長い気温の変化に使う、都市化の影響が比較的少ない15地点から、亜熱帯の名瀬・石垣島を除いた13地点）と、比べるための東京

## 注意
- 気象庁が発表する「初雪」（雪やみぞれが降ったのを見て記録する日）とは違う指標です。積もらない雪は数えていないので、この記事の日付は発表の初雪より遅くなります
- 積雪の測り方は、人が雪尺で測る方法から積雪計へ変わっていて、その影響は補正していません
- 1つの冬の値は揺れが大きく、9地点のうち地点ごとにはっきり言えるのは3地点です
- 雪が積もる日は気温だけでなく、その冬の雪雲の通り道でも決まります。原因は分けていません
