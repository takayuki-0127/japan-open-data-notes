# 608 件数の少ないクラスがあるとき、層化しない交差検証では何%の fold にそのクラスが入らないのか（手法の解説・正解の分かるデータで試す）

解約や不正のように、起きる割合が1%前後のクラスを予測するとき、ふつうの K-fold（並べ替えて K 等分）で交差検証すると、そのクラスが1件も入らない fold ができます。その fold では AUC が出せず、残りの fold の成績も大きく揺れます。**ここでは、架空の解約予測のデータ（2,000件、特徴量5つ、解約1%＝20件）で、ふつうの K-fold と層化 K-fold（各 fold の解約の割合をそろえる）を比べ、解約が0件の fold の割合、fold ごとの AUC の散らばり、交差検証の AUC の振れを数えました。** データ200組。解約の割合を0.5〜5%で変えた比較もしています。数字は置いた前提で決まります。

|---|---|---|---|
| A608 | 分け方で、少ないクラスが入らない fold の割合と AUC の振れがどう変わるか | ロジスティック回帰、KFold（shuffle）と StratifiedKFold、K=5・10。解約が0件の fold は AUC を出せないので除いて平均。解約の割合を変えた比較は、学習を省いて本当の係数で点数を付け、分け方だけを比べた。各200〜300組、seed 608 | `src/a608_stratified_cv.py` |

## 主な結果
- **解約1%（20件）・ふつうの10-fold**：fold の **13.0%** で解約が0件。データの **83.5%** で、どこかの fold が0件になった。5-fold では fold の1.5%、データの7.0%
- **層化すると0件の fold はなくなる**：解約1%なら、5-fold では各 fold 4件、10-fold では各2件ずつ入る
- **解約の割合を変えると（ふつうの K-fold）**：解約0.5%（10件）・10-fold では fold の34.1%が0件、すべてのデータで0件の fold ができた。2%では10-fold で1.4%、5%では0%
- **fold ごとの AUC は大きく揺れる**：解約1%で、fold ごとの AUC の標準偏差は 5-fold で0.11、10-fold で0.16（層化しても0.16）。1つの fold の AUC だけで判断するのは危うい
- **交差検証の AUC（fold の平均）の振れ**：データ200組での標準偏差は、ふつうの5-fold 0.066、層化5-fold 0.059、ふつうの10-fold 0.067、層化10-fold 0.057。層化すると1割ほど小さくなる。平均の値（0.772〜0.776）はほとんど変わらない（本当の AUC は0.797）

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 608）
- 仮定：特徴量5つは標準正規、効くのは3つ（係数0.9・0.6・0.4）、解約はロジスティックのモデルで、切片を合わせて割合をちょうど1%（などの値）にした

## 注意（言えないこと）
- シミュレーションの結果。件数・解約の割合・モデルは作成者が置いたもので、結果はこれで決まる
- 0件の fold を除いて平均したので、ふつうの K-fold の AUC の平均は少し楽観的になりうる。fold をまたいで予測をまとめてから AUC を出す方法もある
- 時系列のデータや、同じ顧客の行が複数あるデータでは、層化だけでは足りない（時間やグループで分ける必要がある）
