# 1039 移動時間の短縮は、全体の時間をどれだけ減らすのか？（移動と時間）

「電車が3分速くなる」と聞くと、家から職場までの時間も3分減ると思いがちです。けれども、途中で乗りかえる通勤では、乗りかえ先の電車の時刻は変わりません。早く乗りかえ駅に着いても、同じ電車を待つなら、全体の時間は1分も減りません。**ここでは、作成者が乱数で作った架空の通勤（10分おきの路線1と路線2を乗りつぐ。歩く時間・乗っている時間・発車の間隔を作成者が置いたもの）で、路線1の乗っている時間だけを3分短くしたとき、家を出てから職場に着くまでの時間（全体の時間）が1回ごと・時刻表ごとにどれだけ減るかを、時刻表を1,000通り作り直して数えました。最後の区間（路線2）を短くした場合、短くする分・乗っている時間の振れ・発車の間隔を変えた場合も確かめました。**

例の路線と時刻表は架空のもので、実在の路線名・会社名は使っていません。

関連する記事：同じ企画の 1032「乗り換え1回で、全体の遅れはどう増えるのか？」は遅れが乗りかえで便の間隔の分の段になることを扱っていて、この記事の「0分か1本分」と同じ仕組みを遅れの向きから見たものです。1040「計画の時刻表どおりに動く割合は、区間の数でどう変わるのか？」は区間が多い路線の定時を、1037「待ち合わせに余裕を何分みれば、9割の確率で間に合うのか？」は電車の間隔で要る余裕が変わることを扱います。時間が距離に比例しない話は 952（配送の時間。決まった時間が入るため）でも扱っていますが、この記事は乗りかえ先の便の時刻で減りが段になる話で、仕組みは違います。この記事は、1つの区間を短くしたときに全体の時間がどれだけ減るかに絞ります。

## 主な結果

### 路線1を3分短くしたとき（基本、時刻表1,000通り×2,000回、`results/a1039_main.json`）
| | 路線1（途中の区間）を3分短く | 路線2（最後の区間）を3分短く |
|---|---|---|
| 短くする前の全体の時間（平均） | 57.983分 | 58.053分 |
| 全体の時間の減り（全部の回の平均） | **2.96分** | 3.0分 |
| 減りが1分未満の回 | **70.4%** | 0% |
| 減りが9.5分以上の回 | 29.6% | 0% |
| 平均の減りが1分未満の時刻表 | **43.8%** | 0% |
| 時刻表ごとの平均の減り（10〜90%） | 0.015〜8.206分 | 3.0〜3.0分 |

- 全部の回を合わせた減りの平均は2.96分で、短くした3分とほぼ同じだった。路線2の発車の位置がでたらめなら平均は短くした分になる、という式どおりの値
- **ところが1回ごとに見ると、70.4%の回は1分も減らず、29.6%の回は9.5分以上（路線2の1本分の10分）減った**。早く着いても同じ路線2の電車を待つ回は0分、1本前の電車に間に合う回は10分減る。0分の回の割合は、式（1−短くした分÷発車の間隔＝1−3÷10＝70%）どおり
- **同じ時刻表で毎日通う人の平均で見ると、43.8%の時刻表では平均の減りが1分未満だった**。時刻表ごとの平均の減りは0〜8.77分と広く散らばった。どの時刻表で通うかで、「3分の短縮」がほぼ0分にも8分超にもなる
- 最後の区間（路線2）を3分短くすると、どの回も3.0分減った。あとに待つ電車がないため
- 路線1に乗っている20分は全体の57.983分の34.49%で、20分の15%を短くしても、全体は平均で5.17%（3÷57.983）しか減らない。これは式どおり

### 振れのない例：路線2の発車の位置ごとの減り（`results/offset_example_nonoise.csv`）
- 乗っている時間の振れを0にすると、路線2の発車の位置0.5分きざみの20通りで、全体の減りは0分か10分のどちらかだった。0分になったのは20通りの70%だった（式どおり）。路線1と路線2が同じ10分おきなので、すべての電車で乗りかえのずれが同じになるため

### 確かめ：置き方を1つずつ変えると（各300通り×1,500回、`results/sensitivity.csv`）
| 変えたもの | 値 | 減りの平均 | 減りが1分未満の回 | 平均の減りが1分未満の時刻表 | 時刻表ごとの平均の減り（10〜90%） |
|---|---|---|---|---|---|
| 基本（路線1を3分短く、時刻表1,000通り） | | 2.96分 | 70.4% | 43.8% | 0.015〜8.206分 |
| 短くする分 | 1分 | 1.182分 | 88.18% | 60.33% | 0.0〜3.581分 |
| | 5分 | 4.889分 | 51.11% | 24.0% | 0.319〜9.76分 |
| | 8分 | 7.997分 | 20.03% | 0.0% | 3.845〜10.0分 |
| 乗っている時間の振れ | 0分 | 2.733分 | 72.67% | **72.67%** | 0.0〜10.0分 |
| | 2分 | 3.016分 | 69.84% | 15.67% | 0.851〜5.315分 |
| | 4分 | 3.013分 | 69.87% | **0.0%** | 2.767〜3.267分 |
| 路線2の発車の間隔 | 5分 | 2.956分 | 40.88% | 0.0% | 1.623〜4.257分 |
| | 15分 | 2.959分 | 80.28% | 0.0% | 1.68〜4.181分 |
| | 20分 | 2.91分 | 85.45% | 47.67% | 0.013〜8.107分 |
| 路線1の発車の間隔（路線2は10分） | 7分 | 2.984分 | 70.16% | 0.0% | 2.84〜3.12分 |

- 減りの平均は、どの置き方でも短くした分に近かった（3分短くした行で2.733〜3.016分）
- 減りが1分未満の回の割合は、置き方で0〜88.18%と動いたが、どれも「1−短くした分÷路線2の発車の間隔」の式に近かった（20分おきで85%の式に対し85.45%など）
- **新しく数えたのは、時刻表ごとの平均の散らばり**。平均の減りが1分未満の時刻表は、置き方で0〜72.67%と動いた。乗っている時間の振れが大きいほど（4分で0%）、また路線1と路線2の発車の間隔がそろっていないほど（7分と10分、15分と10分で0%）、同じ時刻表でも日によって乗りかえのずれが変わり、時刻表ごとの差はならされた
- 路線2が20分おき（路線1の10分の倍）のときは、乗りかえのずれが2通りしかなく、47.67%の時刻表で平均の減りが1分未満だった

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約1.9秒）
- 減りが1分未満の回の割合が、式（1−短くした分÷路線2の発車の間隔）と合うことを、間隔5・10・15・20分と短くする分1・3・5・8分で確かめた（40.88%対40%、80.28%対80%、85.45%対85%、20.03%対20%など。短くする分1分は88.18%対90%で、振れの分だけずれた）
- 最後の区間を短くすると、どの回も短くした分だけ減る（3.0分、1分未満0%）ことを確かめた
- 図3枚を開き、日本語・重なり・軸を確かめた

## 注意（言えないこと）
- 架空のデータです。歩く時間、乗っている時間、発車の間隔、振れの大きさは作成者が置いたもので、結果はこれで決まります。平均の減りが1分未満の時刻表の割合は、置き方で0〜72.67%と動きました
- 減りの平均（2.96分）と、減りが1分未満の回の割合（70.4%）は、式どおりの値です。新しく数えたのは、時刻表ごとに減り方がどれだけ散らばるかです
- 家を出る時刻はでたらめと置きました。着く時刻が決まっている人が、時刻表に合わせて家を出る時刻を選ぶ場合（待ち時間を家で過ごす場合）は入れていません
- 乗りかえ先の電車が乗りかえを待つこと、混雑で乗れないこと、遅れが次の電車に移ることは入れていません
- 路線の速さをどう変えるべきかは言えません。この記事は、1つの区間を短くしたときの全体の時間の減り方を数えただけです
