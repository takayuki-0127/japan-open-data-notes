# 939 項目ごとの点を足すときの重みで、順位は入れ替わるのか？（人事評価）

評価では、「成果」「業務の質」「協働」「改善」のような項目ごとに点を付け、重みを掛けて足した合計で順位を決めることがあります。重みは「成果を4割」のように決めますが、その決め方に正解はありません。**ここでは、作成者が乱数で作った架空の会社のチーム（4項目を1〜5の5段階で付けた30人。項目どうしの結びつきと点の散らばりを作成者が置いたもの）で、5つの重みと、0.05刻みの重みの組455通りで合計を出し直し、順位、とくに上の端がどれだけ入れ替わるかを数えました。「どの重みが正しいか」は扱いません。**

割合の差と割合の比のどちらで比べるかで上位の店が入れ替わることは関連する記事 906 で扱っています。この記事は、評価の項目を足すときの重みだけで、チームの中の順位がどれだけ動くかに絞ります。

## 主な結果

### 例のチーム（30人）
| 重み | 上位3人（人の番号、同点を含む） | 1位 |
|---|---|---|
| 均等 | 9・18・30 | 30 |
| 成果重視 | 9・18・30 | 30 |
| 成果を強く | 9・18・30 | 30 |
| 協働重視 | 1・9・18・19・20・30（同点で6人） | 30 |
| 改善重視 | 7・9・18・19・28・30（同点で6人） | 18・30（同点） |

- 5つの重みのどれかで上位3人に入った人は8人だった。455通りの重みまで広げると、1位になれる人は4人、上位3人に入れる人は11人だった
- 1人の順位が重みで動いた幅は、いちばん大きい人で14だった（図1）
- 均等と協働重視で、順位が5つ以上動いた人は30人のうち13.3%だった

### 1,000チームで（基本の置き方）
| 数えたもの | 値 |
|---|---|
| 均等と協働重視の順位相関（チーム全体） | **0.987** |
| 1位が5つの重みでずっと同じ1人だったチーム | **44.7%** |
| 5つの重みのどれかで上位3人に入る人（平均） | 5.19人 |
| 均等と協働重視で、上位3人の重なり（平均） | 2.59人 |
| 455通りのどれかで1位になれる人（平均） | **2.39人**（10〜90%の範囲 1〜4人） |
| 455通りのどれかで上位3人に入れる人（平均） | 6.30人 |
| 均等の合計で、3位と4位が同点だったチーム | 60.9% |
| 1人の順位が5つの重みで動く幅（平均） | 3.39 |

- チーム全体の順位は、重みを変えてもほとんど変わらなかった（順位相関0.987）。それでも1位が5つの重みで同じだったのは44.7%で、残りのチームでは重みの選び方で1位が変わるか、同点が生じた
- 5段階の点を足すと同点が多く、均等の合計で3位と4位が同点のチームが60.9%あった。上位3人を選ぶ線は、同点をどう分けるかでも変わる

### 「均等」に足したときの実際の効き（1,000チームの平均）
| 項目 | 名目の重み | 5段階の点をそのまま均等に足す | 散らばりをそろえてから均等に足す |
|---|---|---|---|
| 成果 | 25% | **35.1%** | 25.5% |
| 業務の質 | 25% | 27.8% | 25.2% |
| 協働 | 25% | **16.7%** | 24.5% |
| 改善 | 25% | 20.3% | 24.8% |

- 「均等」に足しても、点の散らばりが大きい成果の項目が合計の散らばりの35.1%を占め、散らばりの小さい協働は16.7%だった。項目ごとに散らばりをそろえて（平均を引き標準偏差で割って）から足すと、ほぼ25%ずつになった
- 散らばりの差は作成者が置いたもの（成果1.0・協働0.5）なので、この差は置き方の写しです。言いたいのは、名目の重みと実際の効きは、点の散らばりが違えば一致しないということです

### 確かめ：置き方を1つずつ変えると（各300チームの平均）
| 変えたもの | 値 | 1位が5つの重みで同じ | 455通りで1位になれる人 | 5つの重みで上位3人に入る人 | 順位相関（均等と協働重視） | 式の相関（丸めないとき） | 成果の実際の効き（均等） |
|---|---|---|---|---|---|---|---|
| 項目どうしの相関 | 0 | 19.7% | 4.86人 | 7.38人 | 0.951 | 0.962 | 41.3% |
| | 0.3 | 33.7% | 3.03人 | 5.79人 | 0.977 | 0.986 | 36.4% |
| | **0.5（基本）** | 45.0% | 2.37人 | 5.36人 | 0.987 | 0.992 | 35.1% |
| | 0.8 | 60.3% | 1.71人 | 4.41人 | 0.996 | 0.998 | 34.1% |
| チームの人数 | 10人 | 52.0% | 2.01人 | 4.32人 | 0.983 | 0.992 | 35.1% |
| | 30人 | 50.0% | 2.32人 | 5.31人 | 0.986 | 0.992 | 34.9% |
| | 100人 | 36.7% | 2.85人 | 6.13人 | 0.988 | 0.992 | 35.0% |
| 点の付け方 | 5段階 | 45.7% | 2.38人 | 5.11人 | 0.987 | 0.992 | 35.1% |
| | 丸めない | 55.7% | 2.76人 | 4.07人 | 0.984 | 0.992 | 36.9% |

- **1位が5つの重みで同じだった割合は、項目どうしの相関の置き方で19.7〜60.3%と動いた。** 項目どうしの結びつきが弱いほど、重みで1位が入れ替わりやすかった。相関0.8でも60.3%にとどまった
- 点を丸めない（同点が出ない）置き方でも、1位が5つの重みで同じだったのは55.7%だった。入れ替わりは同点だけのせいではない
- チーム全体の順位相関は、どの置き方でも0.95以上で、丸めないときの式の相関（0.962〜0.998）に近かった。全体の順位の動きは、項目どうしの相関と重みから式でほぼ決まる値です
- 基本の置き方は、変えたものごとに乱数を変えて数え直したので、1,000チームの値（44.7%など）から少し動く

## 動かし方
```
pip install -r requirements.txt
cd src && python a939_item_weights_rank.py
```
15秒ほどで終わります。`data/team_example.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約11.5秒）
- 図3枚を開き、日本語・重なり・軸を確かめた
- 丸めない置き方（相関0.5）で、均等と協働重視の順位相関0.984が、式で出した合計どうしの相関0.992に近かった。作りが置いたとおりに動いていることの確かめ
- 重みを掛けた合計の小数の誤差で同点が崩れないよう、合計を小数9桁で丸めてから順位を付けた

- `results/a939_main.json`：主な結果すべて
- `results/example_team_ranks.csv`：例のチームの、5つの重みでの順位と合計
- `results/teams_1000.csv`：1,000チームそれぞれの数えた値

## 注意（言えないこと）
- 架空のデータです。項目の数、項目どうしの相関、項目ごとの点の散らばり、チームの人数は作成者が置いたもので、結果はこれで決まります。1位が5つの重みで同じだった割合は、置き方で19.7〜60.3%と動きました。実際の会社の評価を表すものではありません
- 「どの重みが正しいか」は言えません。本当の働きぶりを置いていないので、どの重みの順位が当たっているかは数えていません。この記事は、重みの選び方だけで順位がどれだけ動くかを数えただけです
- 項目の点は評価者がまちがいなく付けたものと置きました。評価者による甘さ辛さや、項目どうしで点が引っぱられる見方の癖は入れていません
- 「実際の効き」の偏りは、作成者が置いた項目ごとの散らばりの差の写しです
- 給与・処遇の決め方、評価の制度の良し悪しについては何も言えません
