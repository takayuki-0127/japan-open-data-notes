# 01 取得（ブラウザで実行した手順）

コンテナからは官公庁のサイトに直接つながらないため、Chrome のページ内で取得して JSON に保存した。

## 商業動態統計（経済産業省）
- 時系列データのページ https://www.meti.go.jp/statistics/tyo/syoudou/result-2/index.html の Excel を、ページ内で fetch し SheetJS（xlsx 0.18.5）で読んだ。
  - h2slt31j.xlsx（百貨店・スーパー 商品別 販売額・伸び率・既存店伸び率）
  - h2slt41j.xlsx（コンビニエンスストア）、h2slt42j.xlsx（家電大型専門店）、h2slt43j.xlsx（ドラッグストア）、h2slt44j.xlsx（ホームセンター）。いずれも全国の商品別と経済産業局別の月次
  - h2slt11j.xlsx（業種別商業販売額。今回は未使用）
- 月次のシートだけを残して `data/raw/f135_meti_monthly.json` に保存（2026年8月分まで）。

## 気象庁「過去の気象データ検索」日別値
- https://www.data.jma.go.jp/stats/etrn/view/daily_s1.php?prec_no=..&block_no=..&year=..&month=.. を、9地点×2012年1月〜2026年9月について 0.7秒以上の間隔で取得し、表から「日・降水量合計・日平均気温・日照時間」を抜き出した。
- 地点（経済産業局の区域の代表）：札幌(14,47412)・仙台(34,47590)・東京(44,47662)・名古屋(51,47636)・大阪(62,47772)・広島(67,47765)・高松(72,47891)・福岡(82,47807)・那覇(91,47936)
- `data/raw/f135_jma_daily.json` に保存。値の「)」「]」（準正常値・資料不足値）は値として使い、「--」（降水なし）は 0、「×」「///」は欠測とした。

```js
// 取得に使ったループ（要点）
const h = await fetch(`/stats/etrn/view/daily_s1.php?prec_no=${p}&block_no=${b}&year=${y}&month=${m}&day=&view=`).then(r => r.text());
const t = new DOMParser().parseFromString(h, 'text/html').querySelector('table.data2_s');
const rows = [...t.rows].filter(r => /^\d+$/.test(r.cells[0].textContent.trim()))
  .map(r => [r.cells[0], r.cells[3], r.cells[6], r.cells[16]].map(c => c ? c.textContent.trim() : ''));
```
