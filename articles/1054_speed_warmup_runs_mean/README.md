# 1054 温まる前の最初の数回を入れて平均すると、どれだけ遅く出るのか？（処理の速さ）

処理の速さを測ると、起動してすぐの最初の何回かは遅く、だんだん速くなって落ち着くことがあります（ここでは「温まる」と呼びます）。この最初の数回も入れて平均すると、温まったあとの速さより長く出ます。最初の何回かを捨てて平均することもありますが、何回捨てれば足りるかは、温まりの早さで変わります。**ここでは、作成者が置いた分布から乱数で作った架空のアプリの処理時間（実機では測っていない）で、10回などの平均が温まったあとの平均より何%長く出るか、最初の1・3・5回を捨てると残りはどれだけか、温まったあとは5%速いが温まりのあるやり方 A と、温まりのないやり方 B を比べるとどちらを選ぶかを数えました。温まりの大きさ・早さ・ばらつきを変えた27通りでも確かめました。**

1回ずつ測った時間で速い方を選ぶとどれだけまちがえるかは、同じ企画の関連する記事 1053、平均・中央値・最小値のどれで比べるかは 1055、A のあとに B を測る順番を固定すると何が差にまざるかは 1056、始めだけでなく動かすほど遅くなり続ける処理が短い計測で見つかるかは 1062 で扱っています。この記事は、最初の温まる前の回を平均に入れるか捨てるかで出るずれに絞ります。

## 主な結果

### 何回測って最初の何回を捨てるか（A、基本、2万回の起動、`results/bias_by_n_drop.csv`）
| 測った回数 | 捨てた回数 | 温まったあとの平均より長く出た割合 | 式どおりの値 |
|---|---|---|---|
| 5回 | 0回 | +139.89% | +139.97% |
| 10回 | **0回** | **+75.68%** | +75.73% |
| 10回 | 1回 | +50.8% | +50.81% |
| 10回 | **3回** | **+23.56%** | +23.57% |
| 10回 | 5回 | +11.48% | +11.49% |
| 30回 | 0回 | +25.38% | +25.41% |
| 30回 | 3回 | +6.28% | +6.3% |
| 30回 | 5回 | +2.48% | +2.5% |
| 100回 | 0回 | +7.62% | +7.62% |

- A の1回目は温まったあとの約4倍（2万回の起動の平均で381.53ミリ秒、温まったあとの本当の平均は95.48ミリ秒）かかる置き方。10回すべての平均は、温まったあとの平均より75.68%長く出た
- この値は、置いた温まりの形から出る式 （1÷n）×Σ（1＋W×exp(−(k−1)÷τ)）−1 どおり（75.68%対75.73%）。ずれの大きさは、何回測ったかと置いた温まりの形でほぼ決まる
- 最初の3回を捨てても、10回測るなら23.56%長く出た。30回測って5回捨てると2.48%まで縮んだ
- 100回すべての平均でも7.62%長く、測る回数を増やすだけではずれは消えにくい

### 温まりのある速いやり方 A と、温まりのない B（基本、10回ずつ測る）
| 捨てた回数 | 温まったあと速い A を選んだ割合 |
|---|---|
| 0回（10回すべて） | **0%** |
| 1回 | 0% |
| 3回 | 0.12% |
| 5回 | 18.25% |

- A は温まったあと B より5%速いのに、10回すべての平均で比べると A を選んだ組はなかった。最初の5回を捨てても18.25%だった
- 起動から何回動かすかで、どちらが本当に速いかが変わる。起動から N 回の合計（期待値）で A が B より短くなるのは、N＝145回から（式どおり）。それより少ない回数しか動かさない使い方なら、温まりも入れた B のほうが本当に速い

### 27通りの確かめ（`results/grid.csv`）
| | 値 |
|---|---|
| 10回すべての平均のずれ | +15.81〜+286.23% |
| 最初の3回を捨てたあとのずれ | +1.11〜+195.58% |
| 3回捨てても5%より大きくずれた通り | 27通り中21通り |
| 最初の5回を捨てたあとのずれの最大 | +153.99% |
| 10回すべてで A を選んだ割合 | 0〜14.85%（27通りすべて50%未満） |
| 3回捨てたあとで A を選んだ割合 | 0〜93.21%（21通りで50%未満） |

- ゆっくり温まる（τ＝5回）通りでは、最初の5回を捨てても、1回目が2倍のときで25.56〜25.68%、7倍のときで153.94〜153.99%長く出た
- 速く温まる（τ＝1回）通りでは、3回捨てるとずれは1.11〜6.75%に縮み、A を選ぶ割合も29.87〜93.21%に上がった

## 注意（言えないこと）
- 架空のデータです。温まりの形（1回目がどれだけ遅いか・どれだけ速く落ち着くか）、ばらつき、A と B の差は作成者が置いたもので、結果はこれで決まります。ずれの大きさは式どおりの値で、置き方で+15.81〜+286.23%と動きました。実在のソフトやサーバーで測った値ではありません
- 温まりは、起動からの回数だけで決まり、だんだん落ち着くと置きました。途中でまた遅くなる、日によって温まり方が違う、といったことは入れていません
- 「温まったあとの速さ」が正しい物差しとは限りません。起動してから少ない回数しか動かさない使い方なら、最初の遅い回も入れた平均のほうが使う人の待ち時間に近くなります（基本では145回より少なければ、温まりのない B のほうが合計で速い）
- 何回捨てるべきかの決まりを示すものではありません。温まりの早さによって、足りる回数が変わることを数えただけです
