# F251 販促の効果を測る（業務の再現：架空の会社で）

シリーズ③「業務の再現：架空の会社で」の6本目。架空の食品スーパー **サンプルマート（架空）** で、地方の6店に打った「会員アプリの来店クーポン」（8週）の効果を、6つの測り方で測り、効果測定の報告（1枚）を書く。効果はこちらで決めて入れたので、どの測り方がどれだけ外れるかを答えと比べられる。

> **会社も数字も販促もすべて架空（乱数で合成したデータ）。** 実在の会社・店・顧客・販促のデータは使っていない。公開データから借りたのは、売上の季節の形と食品の値段の上がり方（F246 の設定）だけ。

## 問い
「弱い店にてこ入れ」で選んだ店に販促を打ったとき、その効果を、どの測り方ならどれだけ正しく測れるか。黒字か赤字かの判断まで変わるか。

## 結論
- **入れた効果は売上 +5.0%**（期間の8週、6店）。増えた売上 52.3百万円、増えた粗利 14.1百万円（期間の後の4週の残り +1.5% を含む）、クーポン 5.3百万円・固定費 0.6百万円を引いて **差し引き +8.2百万円**。
- 同じデータでも、測り方で **+1.3%〜+6.9%** と割れた。
  - **前年比 +6.9%**：値上がり（一品単価 年+4%）がそのまま入る。乱数を変えた20通りの平均で **+3.6pt 高く**出る。
  - **前年比の差（対象外の店と比べる）+1.3%**：選んだ6店がすべて地方（客数の流れ 年−2.5%）で、比べる相手は都市・郊外。20通りの平均で **−1.5pt**、この回（6店すべて地方）は −3.7pt。**差し引きは −6.6百万円と、黒字の販促が赤字に見えた**（20通り中7通りで赤字に見える）。
  - **前後比較（直前8週）+5.8%**：季節と値上がりが入る（20通りの平均 +1.5pt）。期間の後の4週（12月）は +22.5% と、年末の動きをそのまま効果にしてしまう。
  - **差の差 +3.8%**（20通りの平均 −0.6pt）：週ごとに見ると、期間の前から対象の6店は相手より1年で約 −3.8pt ずつ下がっており、「平行」の前提が崩れている（図2）。
  - **差の差＋店ごとの傾き +6.1%**（平均 +1.0pt）：傾きを足すと、7〜9月が弱かった店を選んだ分まで「流れ」として引いてしまい、高めに出る。店を無作為に選ぶとこの偏りは −0.2pt に消える。
  - **合成対照 +4.6%**（平均 −0.3pt、90%の幅 ±2.0pt）がいちばん答えに近かった。相手は郊外の店 71%・都市の店 29% の組み合わせ。
- **偽の販促（プラセボ）で何が分かるか**：対象外の14店から6店を選ぶ「場所の入れ替え」（200通り）では、差の差・合成対照とも今回の値は偽の効果の外（p＜0.005）。ただし相手が都市・郊外だけなので、地方の流れの違いは見えない。**同じ6店で1年前に偽の販促を置く「時の入れ替え」では、差の差 −1.4%・合成対照 −0.8%（本当は0%）と低めに出て、偏りの向きが分かった。**
- **偶然の幅（90%）は、差の差・合成対照でも ±1.6〜2.0pt**。効果がプラスであることは言えても、+4% か +6% かは1回の販促では分けられない。差し引きの幅は合成対照で ±6百万円。
- 店を **無作為に選ぶと**、差の差・合成対照・前年比の差の偏りは ±0.5pt 以内に縮んだ（前後比較は +0.8pt、前年比は値上がりの分 +4.6pt のまま）。**「どの店に打つか」を測り方より先に決めておくのが、いちばん効く。**
- 1枚の報告（`reports/promo_effect_report.md`）は「結論 → 数字（測り方ごとの値と弱いところ）→ 確かめたこと → 理由にしないもの → 次にやること」の順に書いた。報告は答えを知らない担当者の立場で、合成対照を主に、差の差を確かめに使っている。

| 対象の店 | 7〜9月の既存店売上の前年比が低い6店（候補は FY2023〜FY2025 にずっと営業している20店。08・16・21・24 の開店・閉店の店は除く）。乱数の種 0 では 17・18・19・20・22・23 店（すべて地方） |

| 費用 | クーポンの利用はレシートの6%、1回200円（売上からは引かず販促費として数える）。アプリの配信・制作の固定費 60万円 |

## 手法
効果は「期間の8週の、対象の6店の売上が、販促がなかった場合より何%多いか」。6つの測り方は「販促がなかった場合」の作り方が違う。週は月曜始まり、売上は対数で扱う。
| 測り方 | 販促がなかった場合の作り方 |
|---|---|
| M1 前後比較 | 対象の6店の直前の8週 |
| M2 前年比 | 対象の6店の52週前の同じ8週 |
| M3 前年比の差 | 対象の6店の52週前 ×（対象外の14店の前年比） |
| M4 差の差（DiD） | 店×週の対数売上を、店と週の固定効果で回帰（期間の前の52週＋期間＋期間の後） |
| M5 差の差＋店ごとの傾き | M4 に、店ごとの直線の流れを足す |
| M6 合成対照 | 対象外の14店に重み（0以上、合計1）を付け、期間の前の52週の動き（各店の平均を引いた対数）が対象の6店の合計にいちばん近い組み合わせを作る |

- **お金の勘定**：増えた売上 ＝ 期間の売上 ×（1 − 1/(1+効果)）、増えた粗利 ＝ 増えた売上 × 対象の店の期間の粗利率。差し引き ＝ 増えた粗利（期間＋後の4週）− クーポン − 固定費。
- **プラセボ**：①場所の入れ替え：対象外の14店から6店を選んだ200通り（3,003通りから乱数 251 で抽出）を偽の対象にして、同じ測り方を当てる。②時の入れ替え：同じ6店・同じ8週の1年前（2024-10-07〜12-01）に偽の販促を置く（答えは0）。
- **偶然の幅**：F246 の `gen(seed)` で乱数の種 0〜19 の20通りを作り、同じ選び方で店を選び、同じ効果を入れて測る。「測った値 − 答え」の平均を偏り、標準偏差 ×1.645 を90%の幅（半分の幅）とした。選ばれる店は種ごとに変わる（地方の店は平均3.6店、6店すべて地方は種 0 だけ）。
- **SQL**：M1〜M3 を SQL（`sql/10_promo_simple_estimates.sql`）でも計算し、pandas と照合した。DuckDB で実行（SQL Server では動かしていない）。

## 1枚の報告の書き方（この回で決めたこと）
1. 結論は「効果（幅つき）」「お金の差し引き（幅つき）」「使わない数字」の3行。
2. 測り方は1つに決めて主に使い、ほかは「弱いところ」と並べて表にする。
3. 確かめは、期間の前の動き・時の入れ替え・場所の入れ替えの3つ。場所の入れ替えだけでは、相手の店にない流れの違いは見えないことも書く。
4. 次にやることには、次の販促の店の選び方（同じ地域・同じ大きさの対から無作為に）を入れる。

## 言えないこと
- **数字は架空の会社の合成データと、こちらで決めた架空の効果**。実在の販促の効果や、実在のスーパーで差の差・合成対照がどれだけ外れるかを示すものではない。どの測り方が勝つかは、合成の設定（地域の流れ・店×月のずれ σ=2% など）と選び方で決まっている。
- 効果は全店に同じ割合で入れ、店ごとの違いも、ほかの店への波及（近くの店から客が移るなど）もない。実際の販促では、対象外の店の売上も動くことがあり、そのときは差の差も合成対照も外れる。
- クーポンの利用率・固定費・粗利の扱い（人件費を変えない）は仮の置き方。差し引きの値はこの置き方で変わる。
- 合成対照の幅は乱数を変えた20通りから測った。実務では答えも種も分からないので、時・場所の入れ替えで幅と偏りを見積もることになる。
- 「傾きを足すと、弱い時期を選んだ分まで引いてしまう」は、無作為に選ぶと偏りが消えることからの説明で、ほかの理由が混ざっている可能性は残る（推測）。
