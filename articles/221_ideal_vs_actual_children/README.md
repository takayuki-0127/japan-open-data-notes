# 221 理想の子ども数と実際の子ども数の差は、いつから広がったのか

国立社会保障・人口問題研究所「出生動向基本調査」（夫婦調査、第7回1977年〜第16回2021年）の公表値で、夫婦の平均理想子ども数・平均予定子ども数・完結出生子ども数を並べ、理想と予定・実際の差がいつ広がったのかを確かめたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A221 | 理想の子ども数と実際の子ども数の差は、いつから広がったのか | 調査回ごとの理想・予定・完結出生子ども数の長期比較。理想−予定を結婚持続期間別に、理想−完結出生子ども数を結婚15〜19年の夫婦で比べる。出生子ども数の分布 | `src/a221_ideal_gap.py` |

## 主な結果
- 差は広がっていなかった。結婚15〜19年の夫婦の「理想−完結出生子ども数」は、1977年0.48人、1987年0.51人、2002年0.46人、2021年0.36人と、むしろ小さくなっている
- 夫婦全体（妻50歳未満）の「理想−予定」も、1992年の0.46人から2021年は0.24人に縮んだ。結婚0〜4年（0.34→0.16人）から15〜19年（0.54→0.35人）まで、どの結婚持続期間でも1977年より小さい
- 差が縮んだのは、理想そのものが下がったため。平均理想子ども数は1987年の2.67人を最高に、2021年は2.25人。平均予定子ども数は2.23人（1987年）→2.01人
- 実際の子ども数（完結出生子ども数）は2002年まで2.2人前後で、2005年2.09人、2010年1.96人、2021年1.90人と下がった（2021年を前回までと同じ妻50歳未満で集計すると1.99人）
- 結婚15〜19年の夫婦で、子どもが3人以上の割合は2002年の34.4%から2021年は21.8%に、0〜1人は12.3%から27.4%になった

## 動かし方
```
pip install -r requirements.txt
cd src && python a221_ideal_gap.py
```

## データ
- `data/ideal_planned_completed_1977_2021.csv`：調査回別の平均理想子ども数・平均予定子ども数（妻50歳未満の初婚どうしの夫婦、結果の概要 図表7-1）と完結出生子ども数（結婚持続期間15〜19年、図表6-1。2021年の妻50歳未満の値は注の値）
- `data/ideal_planned_by_duration_1977_2021.csv`：結婚持続期間別の平均理想・予定子ども数（図表7-2）
- `data/completed_children_distribution_1977_2021.csv`：結婚15〜19年の夫婦の出生子ども数の分布（図表6-2）
- いずれも「第16回出生動向基本調査 結果の概要」（2022年9月公表）の図表の数値を書き写したもの

## 注意
- 第16回（2021年）は晩婚化に合わせて、完結出生子ども数と結婚持続期間別の値を「妻が50歳未満で結婚し、調査時に55歳未満の夫婦」で集計しています。第15回以前は「妻が調査時に50歳未満」です
- 夫婦全体の理想・予定子ども数は、結婚してすぐの夫婦から長い夫婦までを含む平均で、結婚持続期間の構成が変わると値も動きます
- 結婚していない人や、離婚した人は入っていません。独身者の希望子ども数は別の集計です
- 標本調査なので、値には誤差があります（第16回の結婚15〜19年の夫婦は948組）
