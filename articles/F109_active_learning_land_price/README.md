# F109 どのデータを集めれば、予測は早く良くなるか？ 地価公示で能動学習をシミュレーションする

看板記事シリーズの109本目です。F03 で作った地価公示（2026年、25,565地点）の特徴量を使い、「値段を知っている地点」を少しずつ増やすとき、どの地点の値段を次に聞けば予測が早く良くなるかを、能動学習（active learning）のシミュレーションで比べます。新しいデータは取っていません。

## 問い

予測モデルを作るためにデータを集めるとき、ランダムに集めるのと、「モデルが自信のない地点」を選んで集めるのとでは、同じ数でどれだけ精度が違うか。選び方を変えると、どんな地点の誤差が下がり、どんな地点の誤差が上がるか。

## データ

| データ | 内容 |
|---|---|
| F03 の特徴量（`data/features.csv`） | 地価公示 2026年の25,565地点の価格（円/㎡）と、30個の特徴量（駅までの距離、半径1・3・10km内の乗降客数、用途地域、容積率、市区町村の人口密度など）。作り方は F03 の `src/01_features.py` |

元データは国土交通省「国土数値情報」の地価公示（L01、2026年）・駅別乗降客数（S12、2024年）と、総務省「令和2年国勢調査」です（F03 の README と `data/raw/SOURCES.md`）。

## 手法

| 項目 | 内容 |
|---|---|
| 目的変数 | log(地価公示価格) |
| 分け方 | 25,565地点のうち2割（5,113地点）を評価用、残り8割（20,452地点）を「値段をまだ知らない候補（プール）」にする |
| 進め方 | プールからランダムに200地点の値段を「聞いた」状態から始め、選び方に従って200地点ずつ聞いて足し、3,000地点まで。毎回モデルを作り直して評価用の誤差を測る |
| モデル | LightGBM（200本、学習率0.08、葉31）をブートストラップで4つ作る「委員会」。予測は4つの平均（どの選び方でも同じ） |
| 選び方 | ① ランダム ② 不確実性：委員会の4つの予測の分散が大きい順 ③ 多様性：まだ聞いていない地点を標準化した数値の特徴量で k-means（200群）にかけ、各群の中心にいちばん近い地点 ④ 不確実性＋多様性：分散の大きい上位1,000地点を k-means で200群に分け、各群の中心に近い地点 |
| くり返し | 評価用とプールの分け方・最初の200地点を変えて8回。初期の200地点は選び方によらず同じ |
| 評価 | log の RMSE、予測÷実際のずれの中央値、±20%以内の割合、価格の上位10%・下位10%の地点の RMSE。ランダムとの差は同じ回どうしの差の平均と、8回の t 分布による95%区間 |
| 参考 | プールの約2万地点を全部使ったときの誤差（4回） |

## 主な結果

8回の平均。評価用の誤差は log の RMSE（0.33 なら、おおよそ±33%の外れ方）。

| 値段を知っている地点 | ランダム | 不確実性 | 多様性 | 不確実性＋多様性 |
|---|---|---|---|---|
| 200 | 0.479 | 0.484 | 0.485 | 0.483 |
| 1,000 | 0.393 | 0.389 | 0.393 | 0.380 |
| 2,000 | 0.357 | 0.351 | 0.359 | 0.347 |
| 3,000 | 0.335 | 0.332 | 0.344 | 0.331 |
| 参考：約2万地点を全部 | 0.286 | | | |

- 不確実性＋多様性は、ランダムより RMSE が 600地点で −0.016（95%区間 −0.026〜−0.005）、1,000地点で −0.014（−0.019〜−0.008）、2,000地点で −0.011（−0.016〜−0.005）、3,000地点で −0.004（−0.011〜+0.003）。差は地点が増えるほど縮んだ
- ランダムと同じ RMSE に届くのに必要な地点の数（8回の平均の曲線から補間）：

| ランダムで | 不確実性 | 多様性 | 不確実性＋多様性 |
|---|---|---|---|
| 1,000地点 | 958 | 1,010 | 781 |
| 2,000地点 | 1,793 | 2,115 | 1,553 |
| 3,000地点 | 2,748 | 届かず | 2,579 |

- 不確実性だけで選ぶと、2,000地点で −0.006（−0.012〜−0.000）と差は小さく、区間は0近くまで広がった。多様性（k-means）だけでは、3,000地点で +0.008（+0.002〜+0.015）とランダムより悪かった
- 何が下がったか（3,000地点）：価格の上位10%の地点の RMSE はランダム0.407 → 不確実性0.373・不確実性＋多様性0.382、下位10%は0.507 → 0.445・0.443。外れやすい地点の誤差が大きく下がった
- 何が上がったか：ずれの中央値はランダム18.7% → 不確実性20.2%・不確実性＋多様性20.1%（差 +1.6・+1.4ポイント、600地点以降はどの地点数でも区間が0をまたがない）。±20%以内に収まる地点の割合も53.1% → 49.5%・49.8%。ふつうの地点の当たり方は悪くなった
- 選ばれた地点の中身：不確実性で選ぶと、3,000地点のうち商業地が41%（全地点では25%）、log 価格の標準偏差は1.97（全地点1.34）。高い地点と安い地点に偏って集めていた

## 頑健性

設定を変えて4回ずつ（最後の地点数で、ランダムとの RMSE の差。マイナスがよい）。

| 設定 | 地点数 | 不確実性 | 多様性 | 不確実性＋多様性 |
|---|---|---|---|---|
| 基本（4回分） | 3,000 | −1.0% | +2.0% | −2.4% |
| 初期を50地点に | 2,050 | −1.7% | +1.5% | −3.0% |
| 初期を1,000地点に | 3,000 | −4.0% | −0.6% | −4.0% |
| 1回に50地点ずつ | 1,000 | −0.9% | +2.4% | −3.4% |
| 1回に1,000地点ずつ | 3,200 | +0.5% | +1.0% | −2.3% |
| 評価用を20km四方のブロック単位で分ける | 3,000 | +0.6% | +3.3% | −1.6% |
| モデルをリッジ回帰（線形）に | 3,000 | +0.7% | +0.8% | +0.9% |

- 不確実性＋多様性は、リッジ回帰以外のすべての設定でランダムより平均で1.6〜4.0%よかった。ただし、評価用をブロックで分けたときは4回の範囲が0をまたいだ
- 多様性（k-means）だけは、ほぼすべての設定でランダムと同じか悪かった
- リッジ回帰では、どの選び方もランダムより少し悪かった。線形モデルは外れやすい地点を集めても当てはまりがよくならないため（推測）
- ずれの中央値は、すべての設定で不確実性・不確実性＋多様性のほうがランダムより大きかった（例：初期1,000地点で18.8% → 19.8%・19.6%）

結果の表は `results/`（`al_main.csv`・`al_robust.csv`・`al_full_pool.csv`・`diff_vs_random.csv`・`points_to_reach.csv`・`robust_summary.csv` など）、図は `figures/`。

## 動かし方

```
pip install -r requirements.txt

```

- `01_取得.py`：F03 の `data/features.csv` を data/ にコピー（同じファイルを置いてあるので、そのままでも動く）
- `02_整形.py`：k-means 用の標準化した数値の行列（`data/z_numeric.npy`、作り直せるので GitHub には置いていない）
- `03_能動学習.py main|full|robust`：シミュレーション。CPU 1コアで main 約35分、robust 約40分

乱数は固定しています（`SEED = 2026`）。

## 言えないこと

- これは「値段がすでに分かっている地点を、知らないふりをして順に聞く」シミュレーションです。実際の調査では、地点によって調べる手間（費用）が違い、選んだ地点の値段がすぐ手に入るとも限りません
- 評価用はプールと同じ分布からランダムに取った地点です。将来知りたい地点の分布が違えば（たとえば新しく開発される地域）、よい選び方も変わります
- 不確実性で選んだデータは、高い地点・安い地点に偏ります。このデータで平均や割合を出すと、全国の姿とずれます。予測モデルを作る目的に限った集め方です
- 委員会は4つ、LightGBM の設定は固定です。委員会の数・不確実性の測り方（分位点の幅など）・多様性の距離の定義を変えれば、結果は変わりえます。多様性は数値の特徴量だけで測り、用途地域などのカテゴリは入れていません
- 地価公示は鑑定評価で、実際の取引価格とは違います
