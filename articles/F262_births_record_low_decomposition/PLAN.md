# PLAN：F262 「出生数が過去最少」は、女性の人口の減少でどこまで説明できるか？

この計画は、分析の結果（年齢別の分解）を出す前に書いて GitHub に置いたものです（コミットメッセージ "plan"）。結果が計画とずれたときは、README と記事にそう書きます。

## 問い

毎年6月（概数）と9月（確定数）に「出生数が過去最少」と報じられる。2025年は67万1,270人（確定数）で、10年続けて最少を更新した。出生数は「子どもを産む年齢の女性の数 × 年齢ごとの出生率」なので、減った分の一部は、女性の数そのものが減ったことで起きる。

- 出生数の減少のうち、15〜49歳の女性の数の減少（人数と、年齢の並び方）で説明できるのは何割か。残りが、年齢ごとの出生率の低下か。
- 割合は時期で違うか。2005〜2015年と2015〜2025年、そして「過去最少」が毎年続いた2016〜2025年の各年で比べる。

## データ（計画の時点で取得済み。分解の計算はまだしていない）

- 出生数（日本における日本人、母の年齢5歳階級）：国立社会保障・人口問題研究所「人口統計資料集（2026年版）」表4-7（厚生労働省「人口動態統計」による、1925〜2024年。2005年以降は毎年、それより前は5年ごと）、2025年は厚生労働省「令和7年人口動態統計（確定数）の概況」第6表。14歳以下は15〜19歳に、50歳以上は45〜49歳に含める（合計特殊出生率と同じ扱い）。
- 女性の人口（日本人、5歳階級、10月1日）：総務省統計局「人口推計」長期時系列 第3表（2000〜2020年、千人）、各年10月1日現在 第10表（2021〜2024年、千人）。2025年は「令和7年人口動態統計（確定数）の概況」の「諸率の算出に用いた人口」（令和7年国勢調査の不詳補完値、人）。
- 2004年以前の女性の人口は、表4-7の出生数 ÷ 出生率（千対、小数1桁）から逆算する（長い期間の参考）。

## 手法

- 出生数 B = N × Σ_a c_a × f_a（N：15〜49歳の女性の数、c_a：年齢5歳階級の構成比、f_a：年齢別出生率）。
- 主な方法：Das Gupta の3要因の対称な分解で、出生数の変化を「女性の数（N）」「年齢の並び方（c）」「年齢別出生率（f）」の3つに分ける。人口の効果 = N + c。
- 比べる期間：2005→2015、2015→2025、2016〜2025年の各年（前年からの変化）。

## 仮説と「外れ」の基準

- H1（2015→2025）：出生数の減少（約3割）のうち、人口の効果（N + c）は半分に届かず、出生率の低下が半分以上を占める。
  - 外れ：人口の効果が減少の50%以上。
- H2（2005→2015）：この10年の出生数の減少は、主に人口の効果によるもので、出生率の効果は減少を打ち消す向き（プラス）。
  - 外れ：出生率の効果がマイナス。
- H3（2016〜2025年の各年）：毎年の「過去最少」のうち、半分以上の年では出生率の効果が人口の効果より大きい。
  - 外れ：出生率の効果の大きさが人口の効果を上回る年が10年中5年未満。
- H4（年齢の並び方）：2015→2025の人口の効果のうち、年齢の並び方（c）が4分の1以上を占める（第2次ベビーブーム世代が出生の多い年齢を過ぎたため）。
  - 外れ：c が人口の効果の25%未満。

## 頑健性（少なくとも3つ）

1. 分解の方法：Kitagawa の2要因の分解（女性の数 × 出生率）、順番を決めた分解（人口を先に・率を先に）、各年の分解を足し合わせた場合と両端だけで分解した場合。
2. 年齢の範囲：15〜49歳を20〜44歳にする。14歳以下・50歳以上を除く。
3. 女性の人口の出どころ：人口推計（千人単位）の代わりに、出生数 ÷ 出生率で逆算した人口を使う。2025年は国勢調査にもとづく人口で、2024年までの推計人口とつながりが切れるため、終わりを2024年にした場合（2015→2024）も示す。
4. 期間の取り方：2015→2025 の代わりに 2016→2025、2014→2024。
