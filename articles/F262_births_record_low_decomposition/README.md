# F262 「出生数が過去最少」は、女性の人口の減少でどこまで説明できるか？

2015→2025年に出生数は3割減った（100.6万人→67.1万人）。そのうち、15〜49歳の女性の数が減った分（年齢の並び方を含む）は4割強（43%）で、残りの6割弱（57%）は年齢別の出生率が下がった分だった。年齢別の出生率が2015年のままでも、女性の数の減少だけで出生数は毎年それまでの最少を下回った。女性の数と年齢の並びを2025年にそろえて見ると、「それまでで最少」は2023〜2025年の3年だけだった。

## 問い

毎年6月（概数）と9月（確定数）に「出生数が過去最少」と公表・報道される。2025年は67万1,270人（確定数）で、10年続けて最少を更新した。

- 出生数の減少のうち、子どもを産む年齢の女性の数の減少で説明できるのは何割で、残りは年齢別の出生率の低下か。
- その割合は時期で違うか（2005〜2015年、2015〜2025年、2016〜2025年の各年）。

出生率が下がった理由（結婚や夫婦の出生など）は F203・F204 で扱った。この回は「女性の数」と「率」の分け方だけを扱う。

## データ

| 何 | 出どころ | 期間 |
|---|---|---|
| 出生数（日本における日本人、母の年齢5歳階級） | 国立社会保障・人口問題研究所「人口統計資料集（2026年版）」表4-7（厚生労働省「人口動態統計」による） | 1925〜2024年（2005年以降は毎年） |
| 同（2025年） | 厚生労働省「令和7年(2025)人口動態統計（確定数）の概況」第6表（2026年9月30日公表） | 2015・2024・2025年など |
| 女性の人口（日本人、5歳階級、10月1日） | 総務省統計局「人口推計」長期時系列 第3表（2000〜2020年）・各年10月1日現在 第10表（2021〜2024年）、いずれも千人単位 | 2000〜2024年 |
| 同（2025年） | 「令和7年人口動態統計（確定数）の概況」の「諸率の算出に用いた人口」（令和7年国勢調査の不詳補完値、人） | 2025年 |
| 年齢別出生率（女性人口千対、小数1桁） | 人口統計資料集 表4-7 | 1925〜2024年（1999年以前の女性人口の逆算と、頑健性に使用） |

- 14歳以下の出生は15〜19歳に、50歳以上は45〜49歳に含めた（年齢別出生率・合計特殊出生率と同じ扱い）。年齢不詳の出生（2025年で19人）は分解に入らない。
- 計算した合計特殊出生率は2015年1.448・2024年1.145・2025年1.136で、公表値（1.45・1.15・1.14）とそろう。2005年は1.270（公表1.26。分母の人口の違いによる）。
- 2015年と2025年の女性の人口は、どちらも国勢調査にもとづく値。2016〜2024年は人口推計（2020年国勢調査を基準）。

## 手法

出生数 B = N × Σ_a c_a f_a（N：15〜49歳の女性の数、c_a：年齢5歳階級の構成比、f_a：年齢別出生率）。

- **Das Gupta（1993）の3要因の対称な分解**：出生数の変化を「女性の数（N）」「年齢の並び方（c）」「年齢別出生率（f）」に分ける。3つの和は変化と一致する（コードで確認）。人口の効果 = N + c。
- 比べた期間：2005→2015、2015→2025、2016〜2025年の各年（前年からの変化）。長い期間（1975〜2025年の5年ごと）は、1999年以前の女性の人口を出生数÷出生率で逆算した。45〜49歳は率が0.0（小数1桁）になる年があって逆算できないので、長い期間だけ15〜44歳で計算した。
- **問い直し（結果を見た後に加えた）**：「過去最少」は、女性の数が減らなくても起きていたか、出生率が下がらなくても起きていたか。
  - (a) 年齢別出生率を2015年に固定し、女性の数だけを動かした出生数。
  - (b) 女性の数と年齢の並びを2025年に固定し、率だけを動かした出生数（2015年に固定しても同じ結果）。

## 結果

### 2つの10年（図2）

| 期間 | 出生数の増減 | 女性の数（N） | 年齢の並び方（c） | 年齢別出生率（f） | 人口の効果の割合 |
|---|---|---|---|---|---|
| 2005→2015 | −5.7万人（−5.3%） | −7.6万人 | −13.8万人 | **+15.7万人** | 376% |
| 2015→2025 | −33.4万人（−33.3%） | −12.8万人 | −1.7万人 | **−19.0万人** | **43%** |

- 2005〜2015年：15〜49歳の女性は7.1%減り、年齢の並び方（第2次ベビーブーム世代が出生の多い年齢を過ぎた）でも大きく減る向きだった。出生率が上がった分（合計特殊出生率 1.27→1.45）が、そのかなりの部分を打ち消した。
- 2015〜2025年：女性は14.3%減り（2,545万人→2,182万人）、それで出生数が12.8万人減る計算。年齢の並び方の効果は小さい（−1.7万人）。残りの19.0万人は出生率の低下（1.45→1.14）。

### 各年（図3）

- 2016〜2025年の毎年、人口の効果だけで出生数は前年比1.4〜2.2%（0.9万〜2.2万人）減る計算。
- 出生率の効果は年によって大きく違い、前年比−0.6%（2016年）〜−4.3%（2024年）。率の効果の大きさが人口の効果を上回ったのは2019・2021・2022・2023・2024年の5年（10年中5年）。
- 2025年は前年比−2.2%と減り方が小さく、その主な理由は率の低下が小さかったこと（−0.8%）。ただし2025年は分母が国勢調査にもとづく人口に切り替わるので、この年の分け方は分母の違いの影響を受けている可能性がある（推測）。

### 年齢別（図4、2015→2025年）

- 30〜34歳・35〜39歳では、女性の数の減少の効果（−6.2万・−5.0万人）が率の効果（−4.7万・−2.3万人）より大きい。この年齢の女性は353万→288万人、405万→311万人と減った。
- 20代は率の低下が中心（25〜29歳で出生率85.1→60.4‰、20〜24歳で29.4→14.4‰）。
- 40〜44歳と45〜49歳は率が少し上がった。

### 仮説の判定

| 仮説 | 基準 | 結果 | 判定 |
|---|---|---|---|
| H1：2015→2025 の減少のうち、人口の効果は半分に届かない | 50%以上なら外れ | 43%（頑健性 40〜47%） | 支持 |
| H2：2005→2015 は、出生率の効果がプラス | マイナスなら外れ | +15.7万人 | 支持 |
| H3：2016〜2025年の半分以上の年で、率の効果が人口の効果より大きい | 10年中5年未満なら外れ | 5年（ちょうど基準。逆算した人口では9年中6年） | 支持（ぎりぎり） |
| H4：2015→2025 の人口の効果のうち、年齢の並び方が4分の1以上 | 25%未満なら外れ | 12%（頑健性 −7〜19%） | **外れ** |

H4 の外れ：年齢の並び方が大きく効いたのは2005〜2015年（人口の効果の65%）で、2015〜2025年は女性の数そのものの減少が中心だった。2021年以降は年齢の並び方の効果がむしろプラス（出生の多い20代後半〜30代前半の割合が少し上がった）。

### 問い直し：「過去最少」は女性の数だけで起きていたか（図6）

- **率が2015年のままでも、毎年「過去最少」**：年齢別出生率を2015年に固定すると、出生数は毎年1.3〜2.2%減り、2016年の98.4万人から2025年の85.0万人まで、10年すべてでそれまでの最少（2014年の100.4万人）を下回る。
- **女性の数をそろえると、最少は3年だけ**：女性の数と年齢の並びを2025年にそろえた出生数は、2015年の85.0万人が最も多く、2022年（73.8万人）までは2005年の水準（73.7万人）を上回っていた。それまでの最少を下回ったのは2023・2024・2025年の3年（合計特殊出生率が2005年の水準を下回った年と同じ）。2015年の女性にそろえても同じ3年。
- つまり、「10年続けて最少」のうち、女性の数の減少がなければ最少でなかった年が7年あった。2023年以降は、女性の数をそろえても最少。

## 頑健性（図5、results/robustness.csv・robustness_h3.csv）

| 条件 | 人口の効果の割合（2015→2025） |
|---|---|
| 基準（Das Gupta） | 43% |
| Kitagawa の2要因の分解 | 43% |
| 順番：人口を先に／率を先に | 47%／40% |
| 各年の分解の和 | 45% |
| 年齢20〜44歳 | 44% |
| 女性の人口を出生数÷出生率で逆算（2015→2024） | 42% |
| 終わりを2024年（推計人口のみ） | 42% |
| 2016→2025 | 41% |
| 2014→2024 | 47% |
| 14歳以下・50歳以上を除く | 43% |

- どの条件でも40〜47%で、半分を下回る（H1 の判定は変わらない）。
- H3（率の効果が大きい年の数）は、Kitagawa・20〜44歳・推計人口のみ（2016〜2024）で5年、逆算した人口（2016〜2024）で9年中6年。基準ぎりぎりなので、「ほぼ半々」と読むのが妥当。
- H4（年齢の並び方の割合）は −7〜19% で、どの条件でも25%未満（外れは変わらない）。
- 長い期間（1975〜2025年、5年ごと、15〜44歳、results/long_decomposition.csv）：人口の効果の大きさが率の効果を上回ったのは1980〜85年・1995〜2000年・2010〜15年・2015〜20年の4期間（1975〜80年はほぼ同じ）。2020〜25年は率の効果が人口の効果の約2倍。1990〜2000年は年齢の並び方の効果がプラス（第2次ベビーブーム世代が出生の多い年齢に入った）だった。

## 計画からのずれ

- H4 は外れた（年齢の並び方の効果は12%）。
- 長い期間の分解は、計画では15〜49歳としていたが、1999年以前は45〜49歳の出生率が0.0（小数1桁）で人口を逆算できない年があるため、15〜44歳で行った。
- 「女性の人口を逆算」の頑健性は、2025年の年齢別出生率（小数1桁）を人口統計資料集でまだ得られないため、2015→2024で行った。
- 問い直し（過去最少の年を数え直す）は、結果を見た後に加えた。

## 言えないこと

- **出生率が下がった理由は言えない**：結婚・夫婦の出生・所得・住宅などの要因は扱っていない（F203・F204）。
- **因果ではなく会計の分け方**：「女性の数の効果」は、率を固定したときの機械的な計算。女性の数が減ると率が変わる、といった関係は入っていない。
- **分け方は方法に少し依存する**：順番を決めた分解では40〜47%と動く。対称な分解（Das Gupta・Kitagawa）の43%を基準にした。
- **分母の切り替わり**：2016〜2024年は人口推計（千人単位）、2015・2025年は国勢調査にもとづく人口。各年の分解、とくに2025年の分け方は、分母の違いの影響を受けうる。
- **日本人だけ**：日本における日本人の出生と日本人女性。外国人の出生、外国にいる日本人は入らない。
- **報道の評価ではない**：「過去最少」という公表・報道の言い方が正しいかどうかではなく、その中身の分け方を示した。

## 外に出す先（案）

Zenn か Qiita に「出生数の増減を Das Gupta の分解で『人数』と『率』に分ける（pandas で20行）」として手法だけを書く。人口の分解は売上（客数×単価）や保険の事故件数（契約数×事故率）にも同じ形で使えるので、その例も添える。まだどこにも投稿していない。
