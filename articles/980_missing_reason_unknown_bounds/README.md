# 980 欠けている理由が分からないとき、何まで言えるのか？（欠けたデータ）

アンケートに答えなかった人が、なぜ答えなかったのかは、ふつう分かりません。答えなかった人が答えた人と同じなら、答えた人だけの割合でよいのですが、違うなら、答えた人のデータをいくら細かく見ても、その違いは分かりません。**ここでは、作成者が乱数で作った架空の店の会員アンケート（答えた人のデータはまったく同じで、答えなかった人の「また来たい」の割合だけが違う4つの世界を作成者が置いたもの）で、答えた人だけの95%の幅・何も仮定しない幅・「答えなかった人は答えた人と最大 δ ポイント違う」と置いた幅・答えなかった人の一部への聞き直しが、本当の割合をどれだけ含むかを数えました。2店を比べたときに、答えた人の差（8ポイント）の向きが、答えなかった人の置き方で入れかわるかも数えました。**

関連する記事：同じ企画の970（答えなかった人は答えた人と同じか）は催促後の回答者を手がかりに答えなかった人を読む話を、979（欠けやすい人に重みを付ける）は名簿の区分で説明できる分を戻す話を、974（欠けの割合が何%を超えると読めないか）は答えにくさの比を置いたときのずれと、答えた人の割合からの本当の値の逆算を扱っています。この記事は、違いの理由が分からないときに、何を置けば何が言えるかに絞りました。866（途中でやめた人の回答）と870（謝礼で回答者の構成が変わる）も、答えない人の違いを扱っています。

## 主な結果

### 1回分（`data/members.csv`）
- 2,000人のうち答えたのは1,197人、そのうち「また来たい」は835人（69.76%）
- 何も仮定しない幅は41.75〜81.9%。4つの世界の本当の割合は、同じ69.05%・15ポイント低い63.45%・30ポイント低い57.65%・10ポイント高い73%で、どれもこの幅の中だった
- `data/members.csv` の answer 列（答えた人の答え）は4つの世界で共通で、true_ の4列は答えなかった人の行だけが違う。**答えたデータからは、どの世界かは見分けられない（作りどおり）**
- 「半分以上がまた来たい」と言えなくなるのは、答えなかった人の「また来たい」が20.55%を下回るとき、つまり答えた人より49.21ポイント低いときだった（式：(0.5−答えた人のうち来たい人÷2,000)÷答えなかった割合）

- **答えた人だけの95%の幅に本当の割合が入ったのは、4つの世界で0〜99.7%だった**。答えなかった人が同じ世界でしか当たらず、違う3つの世界では0〜3.6%だった
- 答えた人と同じ世界で99.7%と95%より高いのは、本当の割合をこの2,000人自身の割合としたからです。答えた人は2,000人の6割を占めるので、幅は広めに出ます
- **何も仮定しない幅は、どの世界でも100%当たった。幅は平均39.968〜39.987ポイントで、答えなかった人の割合（40%）と同じ（式どおり）**。本当の割合は、答えた人の「来たい」と答えなかった人の数の足し算で決まるので、必ずこの幅に入る（作りどおり）
- 「最大 δ 違う」と置いた幅は、置いた δ の中に本当の違いが入る世界では当たり、外れる世界では0%前後だった。ちょうど端（δ が本当の違いと同じ）のときは、49.55〜50.85%と半々だった。幅は δ×答えなかった割合×2（ほぼ式どおり。0〜100%で切った分だけ小さい）
- 答えなかった人のうち100人に聞き直すと、4つの世界のどれでも94.35〜95.05%当たった。幅は5.81〜7.256ポイントで、答えた人だけの幅（5.18ポイント）より少し広い程度だった。**ただし、選んだ人が全員答えると置いた結果です**

### 2店の比べ方（16通り、各2,000回、`results/two_stores.csv`）
- 答えた人の割合の差（A店−B店）は、16通りのどれでも平均7.967〜8.082ポイントだった
- **本当の差は、答えなかった人の置き方で−5.965〜+25.995ポイントと動いた。16通りのうち13通りではA店が上、3通りではB店が上だった**（A店15ポイント低い×B店10ポイント高いで−1.548、A店30ポイント低い×B店同じで−0.938、A店30ポイント低い×B店10ポイント高いで−5.965）
- 何も仮定しないときの差の幅は−31.6〜+48.4ポイント（式）。A店の答えなかった人が δ 低く、B店の答えなかった人が δ 高いと置くと、差が0になるのは δ＝10ポイント（式：8÷（0.3＋0.5））。B店のほうが答えなかった人が多いので、B店の置き方の効き目が大きい

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約1秒）
- 何も仮定しない幅が、すべての回・すべての世界で本当の割合を含むこと（100%）、幅が答えなかった割合と同じになることを確かめた（式どおりの作りの確かめ）
- `data/members.csv` で、答えた1,197人の行は4つの true_ 列が answer と同じで、違うのは答えなかった人の行だけであることを確かめた

## データ
- `data/members.csv`：架空の会員1回分2,000人（member_id・responded（答えたら1）・answer（答えた人の「また来たい」：1・0、答えなかった人は空欄）・true_same／true_minus15／true_minus30／true_plus10（4つの世界での本当の「また来たい」）・followup_100（聞き直しに選んだ100人なら1））

## 注意（言えないこと）
- 架空のデータです。答える割合、答えた人の「また来たい」、答えなかった人の4つの置き方は作成者が置いたもので、当たりの数はこれで決まります。実際の答えなかった人が、どの世界に近いかは分かりません
- 何も仮定しない幅とその当たり（100%）、幅の大きさ（答えなかった割合）、δ を置いた幅の大きさ、2店の差が0になる δ は、どれも式どおりで、数えて新しく見つけたものではありません。この記事で数えたのは、答えた人だけの幅が世界ごとにどれだけ外れるか、δ の端で当たりが半々になること、聞き直しの人数ごとの幅と当たり、2店の差が16通りのどこで入れかわるかです
- 聞き直しは、選んだ人が全員答えると置きました。実際には聞き直しにも答えない人がいて、そのときはこの当たりにはなりません
- 答えなかった人の違いを「最大 δ」とする δ の大きさは、データからは決まりません。どの δ を置くべきかの助言はしません
