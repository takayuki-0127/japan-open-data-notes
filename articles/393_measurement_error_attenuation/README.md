# 393 説明する側の数字に測り間違いがあると、回帰の係数はどれだけ小さく出るのか

回帰で、説明する側の変数に測り間違い（本当の値に、関係のない揺れが乗っている）があると、係数は0のほうへ薄まります。真の係数が分かっている架空のデータで、**どれだけ薄まるか、薄まった分がどこへ行くか、どう直せるか**を数えたフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A393 | 測り間違いの大きさ（信頼性）と、もう1つの変数との相関で、係数はどれだけ小さく出るか。もう1つの変数の係数に移る分はどれだけか。2回測ってあれば直せるか | 真の係数1.0のデータを2,000回ずつ作って回帰する。理屈の式と比べる | `src/a393_measurement_error.py` |

## 設定
- 本当の関係：y = 1.0×x + 0.5×z + 揺れ（標準偏差1）。x と z は標準偏差1で、相関は0〜0.8
- 測った値：w = x + 測り間違い。**信頼性**＝x の散らばり ÷ w の散らばり（1.0なら測り間違いなし、0.5なら散らばりの半分が測り間違い）
- 回帰は y を w と z で説明する。z は正しく測れている

## 主な結果
### 係数（1,000件、2,000回の平均。本当は w が1.0、z が0.5）
| z との相関 | 信頼性 | w の係数 | z の係数 |
|---|---|---|---|
| 0 | 0.9 / 0.7 / 0.5 | 0.90 / 0.70 / 0.50 | 0.50 / 0.50 / 0.50 |
| 0.3 | 0.9 / 0.7 / 0.5 | 0.89 / 0.68 / 0.48 | 0.53 / 0.60 / 0.66 |
| 0.6 | 0.9 / 0.7 / 0.5 | 0.85 / 0.60 / 0.39 | 0.59 / 0.74 / 0.87 |
| 0.8 | 0.9 / 0.7 / 0.5 | 0.77 / 0.46 / 0.27 | 0.69 / 0.93 / 1.09 |

- **相関がなければ、係数は信頼性の分だけ小さく出る**（信頼性0.7なら0.70）
- **もう1つの変数と相関があると、もっと小さく出る**。相関0.8・信頼性0.7で0.46。薄まった分は z の係数に移り、0.5のはずが0.93になる
- どれも理屈の式と小数第2位まで一致した（`results/attenuation.csv`）

### 本当は効いていない変数が「効いている」（p<0.05）と出た割合（%、z の本当の係数0、相関0.6）
| 信頼性 | 100件 | 300件 | 1,000件 | 3,000件 |
|---|---|---|---|---|
| 1.0（測り間違いなし） | 5.1 | 4.9 | 5.6 | 4.7 |
| 0.9 | 10.5 | 22.2 | 58.7 | 97.2 |
| 0.7 | 44.7 | 88.5 | 100 | 100 |
| 0.5 | 75.6 | 99.8 | 100 | 100 |

- **データを増やすほど、効いていない変数が「効いている」と出る**。偏りは件数を増やしても消えず、幅だけが狭くなるため

### 直し方の比べ（z なし、本当の係数1.0）
| 信頼性 | 件数 | そのまま | 2回の測定の平均 | 信頼性で割る | 2回目の測定を道具に使う |
|---|---|---|---|---|---|
| 0.7 | 200 | 0.70（±0.07） | 0.82（±0.07） | 1.00（±0.10） | 1.01（±0.10） |
| 0.7 | 1,000 | 0.70（±0.03） | 0.83（±0.03） | 1.00（±0.04） | 1.00（±0.05） |
| 0.5 | 200 | 0.50（±0.06） | 0.67（±0.07） | 1.01（±0.14） | 1.01（±0.15） |
| 0.5 | 1,000 | 0.50（±0.03） | 0.67（±0.03） | 1.00（±0.06） | 1.00（±0.06） |

（かっこ内は2,000回のばらつき＝標準偏差）

- そのままの回帰の95%区間が本当の1.0を含んだのは、信頼性0.7・200件で0.65%、1,000件で0%
- **同じものを2回測ってあれば戻せる**。2回の相関を信頼性の見積もりにして割る方法と、2回目を道具に使う方法（操作変数）は、どちらも平均1.00〜1.01。ばらつきは、そのままの1.5〜2.4倍に広がる
- 2回の平均を使うだけでは、薄まりは半分ほどしか戻らない（0.70→0.82）

### 測り間違いが y の側にあるとき
| y の測り間違い（標準偏差） | 係数の平均 | 標準誤差の平均 |
|---|---|---|
| 0 | 0.999 | 0.032 |
| 1 | 1.000 | 0.045 |
| 2 | 1.002 | 0.071 |

- 係数は薄まらず、幅だけが広がる

## 確かめたこと
- 空のフォルダで計算し直し、data・results・figures が一致した
- 試した係数の平均と、理屈の式の値の差は、24通りすべてで0.003以内
- 測り間違いがないとき、効いていない変数が「効いている」と出たのは4.7〜5.6%（本来の5%）

## 注意（言えないこと）
- すべて架空のデータです。測り間違いは「本当の値とも、ほかの変数とも、y の揺れとも関係のない揺れ」と置いています。大きい値ほど大きく間違える、同じ向きに偏る、といった測り間違いでは、薄まるとは限りません
- 直し方は、同じものを独立に2回測ってある場合だけです。2回の測り間違いどうしが似ている（同じ人が同じ思い違いで答える、など）と、直しすぎや直し足りなさが出ます。試していません
- 信頼性が分からないデータでは、「どれだけ薄まっているか」はデータからは分かりません
- 区分に分けた変数（年収の階級など）の付け間違いは扱っていません
