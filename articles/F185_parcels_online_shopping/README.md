# F185 宅配便の個数は、どこまで通販で説明できるのか

2004〜2024年度の宅配便の取扱個数（国土交通省）を、家計のネット通販への支出・ネットで注文した世帯の割合（家計消費状況調査）・人口・単独世帯で説明できるかを、年度ごとの時系列の回帰で調べたフォルダです。

## 問い
宅配便は「通販が増えたから増えた」とよく言われます。では、宅配便の増え方のうち、どこまでをネット通販の伸びで説明できるのでしょうか。長い流れ（水準）と、年ごとの増減（前年度比）を分けて確かめます。

## データ
| データ | 期間 | 単位 | 使い方 |
|---|---|---|---|
| 国土交通省「宅配便等取扱個数の調査」（各年度の公表資料） | FY2003〜2024 | 百万個 | 目的変数。FY2003〜2006 はゆうパックを足して FY2007 以降とそろえる |
| 日本郵便・日本郵政公社「引受物数」（ゆうパック） | FY2003〜2007 | 百万個 | 上の補正 |
| 総務省「家計消費状況調査」ネットショッピング（二人以上の世帯） | 2004年1月〜2025年12月（月） | 円／月、1万分比 | 説明変数。月の値を年度（4月〜翌3月）に組み替え |
| 同上、22品目別 | 2015〜2025年 | 円／月 | 「モノだけ」の支出（旅行・チケット・保険・出前・デジタル配信を除く） |
| 総務省「国勢調査」単独世帯・一般世帯 | 2005・2010・2015・2020年 | 千世帯 | 年ごとに対数で補間、2021年以降と2004年以前は前後5年の伸びでのばす |
| 総務省「人口推計」総人口 | 2003〜2024年 | 千人 | 説明変数 |

取得の手順は `src/01_取得.md` にあります。

## 方法
1. **水準の回帰**：log(宅配便) を log(ネット支出)・log(人口)・log(単独世帯)・トレンドなどで回帰し、R² と残差の単位根検定（ADF）を見る
2. **前年度比の回帰（主分析）**：Δlog(宅配便) を Δlog(ネット支出) で回帰（FY2005〜2024 の20年度、HAC 標準誤差）。2015年の品目の定義の変更は、「その年度に新しい定義の月が占める割合」の変化をダミーとして入れる
3. **変数の組み合わせ**：ネット支出・注文世帯の割合・人口・単独世帯の全16通り
4. **伸びの分解**：弾力性 ×（定義の切れ目をつないだネット支出の伸び）が、宅配便の伸びの何割にあたるか
5. **予測での確認**：FY2005〜2013 で推定し、FY2016〜2024 の伸びを当てる
6. **置換検定**：前年度比の並びを2万回入れ替え

## 結果
- **全体**：宅配便は FY2004 の30.9億個から FY2024 の50.3億個へ +63%（1人あたり24個→41個）。同じ期間に、二人以上の世帯のネット通販への支出は月1,897円から25,266円へ13.3倍（定義の切れ目をつなぐと12.7倍）、ネットで注文した世帯の割合は9%から55%になった。総人口は −3%、単独世帯は +68%（補間）
- **水準では区別がつかない**：log(宅配便) の R² は、ネット支出だけで0.956、トレンドだけで0.942、単独世帯＋人口で0.943、注文世帯の割合だけで0.940。どれも同じくらい「説明」する
- **前年度比では説明できない**：ネット支出の伸びの弾力性は0.13（標準誤差0.12、p=0.29）、R² は0.04。置換検定でも p=0.37。16通りの組み合わせで R² が最も高いのは4変数すべての0.22、注文世帯の割合だけで0.12（p=0.09）
- **FY2020 だけが効いている**：FY2020 は宅配便 +11.9%・ネット支出 +20.0%。FY2020 を除くと弾力性は0.02、コロナ前（〜FY2019）だけでは −0.01
- **伸びの分解**：弾力性0.13 に12.7倍の伸びを掛けると、宅配便の伸びの66% にあたる。ただし弾力性の95%区間（−0.11〜0.36）では −56%〜187% となり、割合は決められない
- **予測**：FY2005〜2013 で推定した関係から FY2016〜2024 を予測すると +17.6%。実際は +34.4%。「前半の平均と同じだけ毎年伸びる」とした場合（+17.7%）とほぼ同じで、ネット支出の情報は予測をほとんど改善しない
- **モノだけ**：旅行・チケットなどを除いた「モノ」の支出（FY2016〜2024、9年度）では、弾力性0.26（p=0.01、R² 0.34）とはっきりした関係が出た。ただし9年度だけで、FY2020 を含む
- **1万円あたりの個数**：宅配便の個数を「二人以上の世帯のネット支出 × 世帯数」で割った目安は、ネット支出1万円あたり28個（FY2004）→2.9個（FY2024）。新しい定義の中だけでも6.9個→2.9個に下がった（世帯の種類の違いを無視した粗い目安）

- 期間（コロナ前、FY2020 を除く、FY2008〜、旧定義だけ、新定義だけ）：弾力性 −0.01〜0.29、どれも p>0.2
- 宅配便の補正なし：0.05（p=0.75）
- 暦年の年平均（年度に組み替えない）：−0.05（p=0.52）
- つないだネット支出で切れ目の2年を除く：0.12（p=0.34）
- 単独世帯・人口も入れる：0.14（p=0.25）
- 前年のネット支出の伸びも入れる：同じ年度0.27（p=0.04）・前年度 −0.24 で、合わせるとほぼ0。FY2020 を除くと同じ年度0.10（p=0.44）
- 1年度ずつ抜く：0.02（FY2020 を抜く）〜0.18（FY2016 を抜く）
- 水準の回帰の残差は、ネット支出だけのモデルで ADF の p=0.03、DW 0.70。残差に強い自己相関があり、水準の R² は見かけの当てはまりを含む

## 言えないこと
- 家計消費状況調査は二人以上の世帯の家計の支出です。単身世帯の通販、企業間の通販（BtoB）、フリマアプリなど個人どうしの発送、企業の返品・修理品などは入っていません。宅配便のうち、どれだけが家計のネット通販によるものかは分かりません
- ネット支出には旅行・チケット・保険など、荷物を伴わない支出が含まれます。2015年に品目の区分が変わり、2017年には調査票の変更で注文世帯の割合が大きく上がっています。切れ目の扱い方で結果が変わる可能性があります
- 国交省の宅配便の調査は、届け出のある事業者の「宅配便」の個数です。通販事業者が自社や委託先で配る荷物、軽貨物の個人事業者による配送は、多くが入っていない可能性があります（推測）。ネット通販が伸びても宅配便の個数が伸びない年があるのは、この「数えられない配送」への移り変わりや、運賃の値上げ（2017年前後）と関係している可能性があります（推測）
- メール便（ネコポスなど小さな荷物の一部が含まれる）は扱っていません
- 年度は21年分しかなく、前年度比は20個です。小さな関係（弾力性0.1〜0.2）は見分けられません。「関係がない」とは言えず、「年ごとの増減を説明できるほどの関係は見えない」にとどまります
- 金額は名目で、物価の変化は除いていません。単独世帯は国勢調査の5年おきの値を補間・延長した値です
