# F156 最低賃金の効果は、地域の「賃金の低さ」で違うのか？

看板記事 F156。F01（差の差）・F17（因果フォレスト）・F121（まとめ直し）では、最低賃金の引き上げで「雇用が減った」とは言えない、という答えでした。この記事では、効き方そのものが地域の賃金の低さで違うかに絞って調べます。

前の記事にはなかった、短時間労働者の時給の県×年のデータ（2009〜2025年）を集め直しました。そのうえで、次の2つを比べます。
- 賃金への届き方
- 雇用への効き方

## 問い

- 最低賃金の引き上げは、賃金の低い県ほど、短時間労働者の時給に大きく届いたか。
- 雇用（就業率・失業率）への効き方は、賃金の低い県ほど大きかったか。
- 「県による違い」を推定するとき、どの変動を使うかで答えは変わるか。比べるのは次の2つ。
  - 全国の引き上げ×県の賃金の低さ
  - 同じ年の中で、県によって上げ幅が違った分

## データ

| データ | 中身 | 期間 |
|---|---|---|
| 賃金構造基本統計調査（短時間労働者 都道府県別第1表） | 47都道府県×年の1時間当たり所定内給与額（企業規模10人以上・産業計・男女計）と労働者数 | 2009〜2025年（各年6月） |
| 地域別最低賃金 | 47都道府県×年度の時間額 | 2002〜2026年度 |
| 労働力調査（都道府県別モデル推計値）ほか（F01 のパネル） | 就業率・完全失業率・有効求人倍率 | 2008〜2025年 |

出典の詳細と statInfId は `data/raw/SOURCES.md` にあります。

**賃金の低さは3通りで測りました。** どれも基準期間の値で固定し、標準化（平均0・標準偏差1）しています。
1. 平均時給の低さ：2009〜11年の短時間労働者の平均時給。低いほど＋。標準偏差は73円。
2. 最低賃金÷平均時給（bite）：2009〜11年の平均。標準偏差は0.023。
3. 最低賃金の低さ：2011年度の額。調査の誤差を含まない測り方です。低いほど＋。標準偏差は約6.7%。

推定に使うのは2012年以降の変化だけです。基準期間と重ならないようにして、時給の調査の誤差が「平均への回帰」として効果に混ざるのを避けています。

## 手法

| 項目 | 内容 |
|---|---|
| 単位 | 都道府県×年 |
| 時給の分析 | 2012〜19年の時給の変化（376行）。2020年は調査の作り方が変わり、全国平均が約18%跳ねているので、主分析から外しています |
| 雇用の分析 | 2012〜19年と2023〜25年の変化（517行）。コロナの2020〜22年は除きます |
| 処置 | 最低賃金の前年比（%）。時給は6月の調査なので、前年度（前年10月に改定）の額を使います。雇用は暦年に換算した額です |
| 結果 | 時給の前年比（%）、短時間労働者の数の前年比（%）、就業率の前年差（%pt）、完全失業率の前年差（%pt） |
| (A) 全国の引き上げ×賃金の低さ | 結果 ＝ 最低賃金の前年比 ＋ 前年比×賃金の低さ ＋ 賃金の低さ ＋ 年の効果（雇用は前年の就業率の変化も入れる）。県でクラスターした標準誤差。年の効果を入れても、「全国の引き上げが大きい年に、賃金の低い県がどれだけ違う動きをしたか」は残ります。「賃金の低さ」の主効果は、県ごとの一定の傾きを吸収します |
| 3つに分けた比較（分位点） | 平均時給で県を3つに分けました（低：815〜913円、中：920〜976円、高：979〜1,177円）。傾きの差を「高」と比べます |
| (B) 同じ年の中の上げ幅の違いだけ | 年ダミーで処置と結果を残差にします（DML）。そのうえで、効果が賃金の低さでどう違うかを LinearDML（線形）と CausalForestDML（木2,000本、honest、葉の最小10、県でまとめた5分割）で推定しました。検証として、地方ごとに外した森で効果を予測し直し、BLP（予測した効果の差が、実際の残差に表れるか）で確かめました |
| 検出力 | (A) の就業率の交互作用の標準誤差から、80%で見つけられる最小の差（MDE）を出しました |
| プラセボ | 全国の引き上げの「年」を300回並べ替えます。県ごとの年平均からのずれはそのまま残します。年の並びと、地域の傾きの偶然の重なりだけで、どれくらいの t 値が出るかを見ます |

## 主な結果

### 長い差（2011→2019年、図1）

- 時給が低かった県ほど、時給はやや大きく伸びました（相関 −0.26）。
- 最低賃金の上昇率も、時給の低い県ほど大きめでした（相関 −0.20）。
- 就業率の変化は、時給の低さとほぼ無関係でした（相関 −0.10）。

### 使える変動の大きさ（図2）

- 全国平均の引き上げは、年に0.5〜5.5%でした。
- 同じ年の中で県によって上げ幅が違った分は、標準偏差で0.1〜0.7%しかありません。
- (B) の手法は、この小さい変動だけで効果の違いを推定します。

### (A) 全国の引き上げ×賃金の低さ（図3、`results/interaction_main.csv`）

数字は「全国で1%引き上げたとき、賃金の低さが1標準偏差大きい県で、どれだけ違うか」です。かっこ内は95%区間です。

| 結果 | 平均時給の低さ | 最低賃金÷平均時給 | 最低賃金の低さ |
|---|---|---|---|
| 時給（%） | +0.20（−0.09〜+0.50） | −0.06（−0.41〜+0.29） | **+0.35（+0.09〜+0.62）** |
| 短時間労働者の数（%） | +0.33（−0.80〜+1.46） | −0.66（−1.65〜+0.33） | +1.02（+0.07〜+1.98） |
| 就業率（%pt） | −0.021（−0.065〜+0.022） | **−0.030（−0.053〜−0.007）** | −0.006（−0.073〜+0.061） |
| 失業率（%pt） | **+0.020（+0.005〜+0.036）** | +0.013（+0.003〜+0.023） | +0.026（+0.005〜+0.047） |

- **時給：** 最低賃金の額が低い県ほど、全国の引き上げが時給に大きく届きました。全国で3%上がった年なら、1標準偏差低い県の時給は約1.1ポイント多く伸びた計算です。平均時給で測った低さでは同じ向きですが、区間は0をまたぎます。bite で測ると差は見えません。
- **雇用：** 基本の推定では、bite の高い県ほど就業率が少し下がり、失業率が少し上がる向きでした。就業率の差（−0.030%pt）を雇用の弾力性に直すと、1標準偏差あたり約0.05です。
- **3つに分けた比較（`results/tercile_diff.csv`）：**
  - 時給の傾きの差（低−高）：+0.01%（−1.44〜+1.46）
  - 就業率の傾きの差（低−高）：−0.28%pt（−0.50〜−0.07）
  - 就業率の差は、年に2〜3%の引き上げなら毎年0.6〜0.8ポイントの差になり、最低賃金の効果としては大きすぎます。次の頑健性で、地域の景気の動きとの重なりを疑います。

### 頑健性（図4・図5、`results/robustness.csv`・`results/placebo_year_permutation.csv`）

| 確かめたこと | 時給×最低賃金の低さ | 就業率×bite | 失業率×平均時給の低さ |
|---|---|---|---|
| 基本 | +0.35（+0.09〜+0.62） | −0.030（−0.053〜−0.007） | +0.020（+0.005〜+0.036） |
| 県ごとの傾き（県の固定効果） | +0.37（+0.09〜+0.66） | −0.031（−0.053〜−0.009） | +0.023（+0.007〜+0.039） |
| **地方×年の効果（同じ地方の中だけで比べる）** | +0.48（+0.04〜+0.91） | **−0.013（−0.044〜+0.019）** | **+0.012（−0.011〜+0.034）** |
| 東北3県を除く | +0.33（+0.05〜+0.61） | −0.025（−0.045〜−0.006） | +0.017（+0.002〜+0.033） |
| 期間：時給は2021〜25年も含める／雇用は2012〜19年だけ | **+0.03（−0.32〜+0.37）** | −0.063（−0.124〜−0.002） | +0.042（+0.007〜+0.077） |
| プラセボ：年を並べ替えて同じ以上の t が出る割合 | 1% | 6% | 4% |

- **雇用の差は、同じ地方の中で比べると消えます。** 就業率・失業率のどの組み合わせも、地方×年の効果を入れると区間が0をまたぎました（6通りすべて）。賃金の低い県が多い地方の景気の動きと、全国の引き上げが大きかった年の重なりが、基本の推定に入っていた可能性があります。
- **プラセボでも、雇用の差ははっきりしません。** 年を並べ替えた t 値の標準偏差は、雇用の6通りのうち4通りで1.35〜1.65と、本来の1より広く散らばりました。クラスター標準誤差だけで見ると、差を過大に「有意」と判断しやすい設定です。雇用の6通りのうち、並べ替えで5%未満だったのは、失業率×平均時給の低さ（4%）だけでした。
- **時給の差は、2012〜19年の中では頑健です。** 地方×年の効果を入れても、並べ替えのプラセボ（1%）でも残りました。ただし2021〜25年を含めると消えます。2020年以降は調査の作り方が変わり、県の時給の年ごとのぶれが大きくなったためと考えられます（推測）。

### (B) 同じ年の中の上げ幅の違いだけ（図6、`results/forest_blp.csv`）

| 結果 | 森の平均効果 | LinearDML の交互作用（平均時給の低さ1SD） | 地方を外した検証（BLP） |
|---|---|---|---|
| 時給 | +1.03（−2.86〜+4.92） | +0.66（−0.19〜+1.51） | 係数 −0.36、p=0.53 |
| 就業率 | −0.09（−0.50〜+0.33） | −0.09（−0.20〜+0.01） | 係数 +0.32、p=0.40 |

- 県による上げ幅の違いは、同じ年の中では標準偏差0.23〜0.32%しかありません。平均効果も効果の違いも、区間が広すぎて判断できませんでした。
- 森が描く「賃金の低さ別の効果」（図6）はでこぼこしています。ただ、地方を外して予測し直すと、実際の残差には表れませんでした。F17 と同じ結論です。

### 検出力

- (A) の就業率の交互作用で、80%の確率で見つけられる最小の差は、1標準偏差あたり0.062%pt（雇用の弾力性で約0.11）です。3つに分けた比較（低−高）では0.31%pt（弾力性で約0.53）でした。
- 地方×年の効果を入れると、標準誤差は1.2〜1.5倍に広がります。
- 海外でよく報告される大きさ（弾力性0〜−0.3）の中で起きうる「県による違い」は、多くがこの検出の限界より小さいと考えられます（推測）。

## 言えないこと

1. 時給の差は、最低賃金の額で測った「低さ」でだけ出ました。平均時給や bite で測ると、はっきりしません。3通りの測り方を並べた中の1つなので、偶然の可能性を消しきれません。
2. 雇用の差（bite の高い県で就業率が下がる向き）は、同じ地方の中で比べると消えました。「賃金の低い地域ほど、最低賃金で雇用が減った」とは言えません。「差はない」とも言えません。
3. 結果は県全体の就業率・失業率と、10人以上の事業所の短時間労働者の平均時給です。最低賃金近くで働く人だけを見たものではありません（影響率の分析は F201・F203 に回します）。
4. 時給は標本調査なので、県によっては年ごとのぶれが大きい値です。2020年以降は調査の作り方が変わったため、主分析から外しました。
5. 県による上げ幅の違いは、地方の最低賃金審議会と全国の目安で決まります。地域の景気と無関係とは言い切れません。
6. 県の名前を挙げての評価はしていません。

## 設計書からの変更点

- 設計書の「F01 系のデータで再推定」に加えて、短時間労働者の時給の県×年（2009〜2025年）を新しく集めました。賃金への届き方（第一段階）と雇用を並べるためです。
- 「賃金の低さ」を3通りで測り、基準期間（2009〜11年）と推定期間（2012年〜）を分けました（平均への回帰を避けるため）。
- 異質性を「全国の引き上げ×賃金の低さ」と「同じ年の中の上げ幅」の2つに分けて比べました。前者には地方×年の効果と、年の並べ替えのプラセボを足しました。
- 「分位点」は、平均時給で県を3つに分けた比較にしました（県の時給の分布の分位点は、年ごとのデータがないため使っていません）。
- 設計書の注意（F203 に取り込み）に合わせ、影響率や産業別の分析は入れず、県単位の「賃金の低さ」に絞りました。
