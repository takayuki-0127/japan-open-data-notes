# 962 「よく一緒に出る言葉」は、本当に関係があるのか？（文章の数字）

問い合わせや感想の文章で「よく一緒に出る言葉の組」を数えると、言葉どうしの関係が見えるように思えます。けれども、一緒に出た件数は、もともとよく出る言葉ほど多くなります。長い文章にはどの言葉も出やすいので、関係のない言葉どうしも一緒に出やすくなります。**ここでは、作成者が乱数で語を組み合わせて作った架空の問い合わせ文3,000件（本当に関係のある語の組を8組だけ作成者が置いたもの）で、4つの数え方の上位20組に本当の組がいくつ入るか、関係を置いていない組がどれだけ「関係あり」に見えるかを数えました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A962 | よく一緒に出る語の組は、本当に関係のある組か。数え方で上位の組はどう変わるか。文章の長さのばらつきは、関係のない組をどれだけ「関係あり」に見せるか | 架空の問い合わせ文3,000件。数える語は60語（予約・変更・時間 など）で、作成者が決めた順に出やすさを置いた（k 番目の語の出やすさは 1÷k^1.3 に比例）。文章の語数は中央値12語・対数の標準偏差0.6の対数正規分布（3〜80語で切る）で、そのうち60%は数えない「つなぎの語」（です・ます・お願い など10語）。数える語 w は、語数 L の文章に 1−（1−w の出やすさ）^（0.4L） の確率で、ほかの語と関係なく出る（同じ文章に2回出ても1回と数える）。本当に関係のある組は8組（予約→変更、返品→交換、クーポン→割引、ギフト→包装、修理→保証、電池→充電、ログイン→パスワード、個室→席）で、前の語が出た文章に後の語がなければ、40%で後の語を書き足す。数え方は4つ：①一緒に出た文章の数、②リフト（一緒に出た数×文章の数÷（それぞれが出た数の積）。1なら関係なし並み）、③リフト（一緒に出た数5件以上の組だけ）、④長さでそろえた比（文章を長さで10の層に分け、層ごとの語の出る割合から「関係がないときに一緒に出る見込みの数」を足し上げ、一緒に出た数をそれで割る。5件以上の組だけ）。60語から作れる1,770組を並べ、上位20組を取った（同点はくじで並べる）。確かめとして、文章の数（500・3,000・10,000件）と長さのばらつき（対数の標準偏差0・0.3・0.6・0.9。0は全部12語）を変えた12通りを各30回作り直した。seed 962 | `src/a962_cooccurrence.py` |

語の区切りは、作成者が語のあいだに置いた空白で決めました（外部の辞書や区切りの道具は使っていません）。数える語の一覧とつなぎの語の一覧は、作成者が決めた架空のものです。

関連する記事：948「小さい区域の率は、なぜ地図の端に極端な色が出やすいのか？」は、人数の少ない区域の率がたまたまで大きく振れることを地図で数えています。この記事のリフトも、出る数の少ない語の組ほど大きく振れます。906「割合の差と割合の比、どちらで比べると順位が変わるのか？」は、比で並べると元の割合の低いものが上に来ることを扱っていて、リフトの上位にまれな語が集まるのと同じ形です。同じ企画の963「少ない件数の言葉の『特徴的な度合い』は、なぜ極端に出るのか？」は、まれな語1つの点の振れを扱い、この記事は語の組の関係の読み方を扱います。同じ企画の960「『似ている度合い』の数え方で、似ている文章の組は入れ替わるのか？」は、長い文章ほど共通する語が多くなり、文章どうしの「似ている」上位を長い文章の組が占めることを扱っています。長い文章が数を押し上げる仕組みは同じで、この記事は語どうしの組を扱います。

## 主な結果

### 1回分（3,000件）の上位20組に入った本当の組（8組中）
| 数え方 | 本当の組 | 上位20組の一緒に出た数（中央値） | いちばん少ない組 |
|---|---|---|---|
| ①一緒に出た件数 | **1組** | 356.5件 | 234件 |
| ②リフト | 6組 | 3.5件 | 1件 |
| ③リフト（5件以上） | 7組 | 6.5件 | 5件 |
| ④長さでそろえた比（5件以上） | 7組 | 6件 | 5件 |

- **①の上位20組で本当の組は「予約・変更」の1組だけだった**。残りの19組は、予約・時間（960件）のように、もともとよく出る語どうしの組。もっともよく出る「予約」は2,472件（82.4%）の文章に出た
- ②リフトの上位20組のうち6組は、一緒に出たのが1〜2件の組だった（持ち帰り・宅配は2件でリフト9.57）。まれな語どうしは、1〜2件一緒に出るだけでリフトが大きくなる
- 逆に、本当の組の「予約・変更」はリフトが1.103で、1,770組中1,062位だった。「変更」はもともと3,000件のうち1,997件の文章に出るので、関係があっても割合が上がる余地が小さい（リフトの作りからくる式どおりの向き）。どの数え方の上位20組にも入らない本当の組があった

## 注意（言えないこと）
- 架空のデータです。語の出やすさ、長さの分布、本当の組の数と強さ（40%で書き足す）は作成者が置いたもので、結果はこれで決まります。本当の組を強く置いたので、②〜④の上位にはよく入りました。関係が弱いと、どの数え方でも見つけにくくなります
- 本当の組以外は、長さを決めれば互いに関係しないと置きました。実際の文章では、話題（予約の問い合わせ・配送の問い合わせなど）によって多くの語が一緒に動くので、「関係あり」に見える組はもっと多くなると考えられます（推測）
- ①が、もともとよく出る語の組を上に出すこと、②がまれな語の組で大きく振れること、長さのばらつきでリフトが1を超えやすくなることは、どれも数え方の作りからくる式どおりの向きです。この記事で新しく数えたのは、その向きが上位20組と関係を置いていない組にどれだけ出るか（1組、87.4%など）
- 「一緒に出る」は関係があることを示しても、どちらが原因かは示しません。この記事の本当の組も、作成者が向き（A→B）を置いていますが、どの数え方でも向きは分かりません
- どの数え方を使うべきか、件数の下限を何件にすべきかは言えません
