# F243 どの指標を見れば、売上の変化の理由が分かるのか？ ― KPI ツリーで分けるときの落とし穴

看板記事 F243（② 実務に近い分析）。売上の変化を「訪問数 × 購入率 × 点数 × 単価」のような KPI ツリーで分けて説明するとき、**ツリーの切り方・分ける順番・構成（ミックス）**で答えがどれだけ変わるかを、架空の会社のシミュレーションと公的統計（家計調査・商業動態統計）で確かめた。

- note：（公開後に記入）
- シリーズの関連：F231（売上の予測）、F234（価格弾力性）、F239（広告）、F240（比べる相手がないとき）。月の不調を説明する業務の再現は F250、KPI の決め方は F267 で扱う予定。

## 問い
売上が動いたとき、どの指標を見れば理由が分かるのか。KPI ツリーで分けた「寄与」は、分け方しだいでどれだけ変わるのか。

## データ
- 総務省「家計調査」（二人以上の世帯）品目別の年平均価格・購入数量・支出金額、2002〜2024年。F113 で整形したもの（F234 と同じ）。食料・飲料の127品目（光熱を除く）を使用。
- 経済産業省「商業動態統計」スーパー・百貨店の全国の販売額と既存店の前年同月比、1988年1月〜2026年8月（F135 で取得したもの）。
- 架空の書店チェーン「ひかり書店（架空）」：アプリと Web の2チャネルの訪問数・購入率・点数・単価を置いたシミュレーション。**実在の会社・データではない。**

新しい取得はしていない（src/01_取得.py に出どころを記載）。

## 手法
- **KPI ツリー**：売上 ＝ 訪問数 × Σ（チャネルの割合 × 購入率 × 点数 × 単価）。チャネルを分けない「素朴なツリー」（総訪問 × 全体の購入率 × 平均点数 × 平均単価）と比べた。
- **寄与の分け方**：シャープレイ値（要因を動かす順番120通りの平均）、順番ごとの寄与の幅、LMDI（対数平均で分ける方法）。家計調査では「値段を先に動かす」「量を先に動かす」「中点（2要因のシャープレイ値）」「LMDI」の4つを比べた。
- **構成（ミックス）と率の分解**：100g あたりの平均価格の変化を、品目の値段の変化（率）と、品目の量の割合の変化（構成）に中点で分けた。
- **全店と既存店**：全店の前年比（販売額の水準から計算）と既存店の前年比の差を、店の数の増減などによる部分とみなした。
- **SQL**：値段・量の分解と構成・率の分解を T-SQL（SQL Server 互換）で書き、DuckDB で流して pandas と照合（sql/decomp_tsql.sql）。
- **ダッシュボード**：架空の会社の月次報告を想定した静的 HTML（dashboard/kpi_tree_dashboard.html）。

## 結果
### A 架空の会社（シミュレーション）
- 総訪問は20万で同じ、アプリの割合が10%→30%。購入率はアプリ 20%→18%、Web 2.0%→1.8% と**どちらも1割下がった**のに、全体の購入率は 3.8%→6.7% に上がった（シンプソンのパラドックス）。売上は1,505万円→2,853万円（+89.6%）。
- チャネルを分けないツリーでは、伸び1,349万円のうち1,179万円が「全体の購入率」の寄与に見える。チャネルを分けると、**構成 +1,582万円、チャネル別の購入率 −234万円**（シャープレイ値）。
- 分ける順番（120通り）で、構成の寄与は +1,499〜+1,666万円、購入率は −317〜−150万円と動いた。LMDI は +1,564万円・−216万円。
- ランダムに置いた2チャネルの変化（2万回）では、**14.7%** で「全体の購入率の向き」が「両方のチャネルの向き」と逆になった。

### B 家計調査（食料・飲料127品目）
- 2019→2024年、1世帯あたり年間の支出は 438,558円→480,176円（**+41,618円、+9.5%**）。中点で分けると、**値段 +77,497円、量 −35,879円**。値段が上がった分の半分近くを、買う量を減らして吸収した形。
- 値段の寄与が大きかったのは米・他のパン・牛肉・豚肉・卵、量の減りが大きかったのは牛肉・発泡酒など・他のパン・トマト・牛乳。
- 群別では、魚介類は値段 +10,121円・量 −10,731円で、支出はほぼ変わらない（−610円）。
- **構成の効果**：100g あたりの平均価格は、肉類で +8.8%。品目の値段だけなら +12.6% で、安い肉へ移った分（構成）が −3.8%。飲料・穀類・果物・野菜も構成はマイナス、魚介類と油脂・調味料はプラス。
- **分け方の違い**：2019→2024年の値段の効果は、値段を先に 81,826円、量を先に 73,168円、中点 77,497円、LMDI 77,139円（差は最大で約1割）。2004→2024年では 96,629〜139,238円と、**期間が長いほど差が広がる**。

### C 商業動態統計（全店と既存店）
- スーパーは1990〜2026年の440か月のうち **38%** で、全店と既存店の前年比の向きが逆。全店の平均 +1.9% に対して既存店は −1.2% で、差の平均は +3.0 ポイント（店の数の増減などによる部分）。
- 百貨店は向きが逆の月が9%、相関0.99で、全店と既存店はほぼ同じ動き。
- 「売上が伸びた」の理由は、業態によって「1店ごとの売上」か「店の数」かが違う。

## 頑健性
- **分け方**：シャープレイ値・順番の幅・LMDI（A）、4つの方法（B）。
- **期間**：2019→2024、2014→2019、2022→2024、2004→2024（B）。2014→2019 は支出 −6,005円＝値段 +19,769円・量 −25,774円。
- **品目の範囲**：生鮮を除く49品目でも、値段 +41,501円・量 −9,695円（支出 +31,806円）で、値段が支出を押し上げた形は同じ。区分の変更らしき年（ドレッシング2010年）は主の期間に入らず、含めても結果は同じ。
- **構成と率の期間**：肉類の構成の効果は 2014→2019 で −2.2円、2022→2024 で −3.1円と、どの期間もマイナス。
- **全店の段差**：全店の前年比は販売額の水準から計算しているため、調査の見直しなどで段差が出た月がある。差が10ポイントを超える17か月（スーパー、1995〜2021年）を除いても、向きが逆の月は39%、差の平均 +2.7 ポイント。
- **シミュレーション**：2チャネルの購入率と構成をランダムに2万回置いた。
- **SQL 照合**：群別の値段・量の差は最大 1.8×10⁻¹²、構成・率の差は最大 3.5×10⁻¹⁴（results/E_sql_check.csv）。

## 言えないこと
- 架空の会社の数字はシミュレーションで、実在の会社でこの大きさの構成の効果が出るとは限らない。
- 家計調査の「量」は家計が買った量で、店の販売数量ではない。品目の中の銘柄・サイズの違い（同じ「牛肉」の中の構成）は分けられない。
- 寄与の分け方に「正解」はない。シャープレイ値は順番の平均を取るという約束で、因果の大きさを示すものではない。
- 全店と既存店の差には、店の数の増減のほか、調査対象の入れ替えや定義の変更も混ざる。
- 商業動態統計の既存店の定義・対象は、時期によって見直されている。
