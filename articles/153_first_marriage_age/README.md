# 153 平均初婚年齢の上昇はいつ頭打ちになったのか（人口動態統計）

厚生労働省「人口動態統計」の婚姻の表で、夫・妻の平均初婚年齢の推移に折れ線を当てはめ、上がり方が変わった年（変化点）を探したフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A153 | 平均初婚年齢の上昇はいつ頭打ちになったのか | 1970〜2025年の値に、つながった折れ線（区分線形回帰）を当てはめ、折れ目の年を総当たりで探索（折れ目の数1〜3をBICで選択、区間は5年以上）。10年ごとの上昇幅、都道府県別の前後10年の比較 | `src/a153_first_marriage.py` |

## 主な結果
- 折れ目は 夫 1986・1998・2014年、妻 1978・1995・2013年。10年あたりの傾きは 夫 1.62歳（1998〜2014）→ −0.11歳（2014〜）、妻 1.73歳（1995〜2013）→ 0.33歳（2013〜）
- 夫は2014年に31.1歳になってから横ばい（2025年 31.0歳）。妻は29.4歳（2014年）→ 29.7歳（2025年）
- 10年ごとの上昇幅は 1995→2005年が最大（夫+1.3、妻+1.7）、2015→2025年は 夫−0.1、妻+0.3
- 夫妻の年齢差（初婚）は 2.7歳（1970年）→ 1.8歳（2000年）→ 1.3歳（2025年）
- 都道府県（妻、3年平均）：2005→2013〜15年は全県で+1.1〜1.7歳、2013〜15→2023〜25年は中央値+0.40歳（島根−0.03、富山+0.03 〜 福島+0.93）。夫は30都道府県で+0.1歳以下

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a153_first_marriage.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/national_marriage_age.csv | 1947〜2025年の全婚姻・初婚の夫妻の平均婚姻年齢と年齢差（上巻 第9.11表、statInfId 000040503704） |
| data/pref_first_marriage_age.csv | 都道府県別の夫妻の平均初婚年齢 1950〜2025年（上巻 第9.12表、夫 000040503705・妻 000040503706） |

元の CSV から必要な行を書き写しています。

## 注意
- 1991年までは「出生年月と同居年月による年齢の平均に0.46歳を加えた値」、1992年以降は月齢の平均で、計算の仕方が変わっています
- 1968年以降は結婚式または同居を始めたときの早いほうの年齢です
- 都道府県表は2005年の次が2009年のため、前の10年は「2005年単年 → 2013〜15年平均」で比べています
- 折れ目の年は、折れ目の数や区間の最短の長さの決め方で1〜2年ずれることがあります（results/a153_breaks.csv に折れ目1〜3個の結果を載せています）
- 結婚した人の平均年齢だけを見ており、結婚する人の数や割合は扱っていません
