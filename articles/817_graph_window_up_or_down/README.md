# 817 期間の切り出し方で、「上昇」も「下落」も描けるのか？（グラフ）

同じ月ごとの数字でも、グラフにどの期間を切り出すかで、上がっているようにも下がっているようにも見えます。とくに、始めの月と終わりの月を比べる読み方は、季節の山谷とたまたまの揺れに強く引っぱられます。**ここでは、作成者が乱数で作った架空の店200店の月ごとの来店数（10年分、本当の伸びは0と置いたもの）から、長さ12〜36か月の期間を始まりの月をずらしてすべて切り出し、「上昇」「下落」「横ばい」のどれに見えるかを3つの読み方で数えました。**

累積のグラフの見え方は関連する記事 816、移動平均の幅は 819、前年比の棒の読み方は 824 で扱います。この記事は「どの期間を切り出すか」だけを見ます。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A817 | 本当の伸びが0の店の来店数から期間を切り出すと、どれだけの期間が「上昇」「下落」に見えるか。読み方でどう変わるか | 架空の店200店、各120か月。来店数＝3,000×季節の山谷×揺れ。季節の山谷は12月が山・6月が谷の波（対数で振れ幅0.15、およそ±15%）。揺れは前の月の揺れが0.8の割合で残る形（AR(1)、対数で全体の標準偏差0.08）。本当の伸びは0（作成者が置いた正解）。期間は長さ12〜36か月の25通り×始まりの月をすべてずらし、200店で計48万5,000個。読み方は ①始めの月と終わりの月の比 ②期間に引いた直線（対数）の始めから終わりまでの変化 ③最初の12か月と最後の12か月の平均の比（長さ24か月以上だけ、23万6,600個）。+10%以上を「上昇」、−10%以下を「下落」、その間を「横ばい」とした（作成者の決め方）。揺れの残りやすさを0.5・0.95に、季節の振れ幅を0・30%に、本当の伸びを年+3%・年−3%に、上昇・下落の線を±5%・±20%に変えた確かめ（各200店）も行った。seed 817 | `src/a817_window.py` |

## 主な結果

### 読み方ごとの見え方（200店・長さ12〜36か月のすべての期間）
| 読み方 | 上昇に見えた | 横ばい | 下落に見えた | 上昇か下落に見えた |
|---|---|---|---|---|
| ①始めの月と終わりの月 | 31.1% | 40.4% | 28.5% | **59.6%** |
| ②期間に引いた直線 | 25.6% | 51.6% | 22.8% | 48.4% |
| ③最初と最後の12か月の平均 | 11.1% | 80.4% | 8.5% | **19.6%** |

- 本当の伸びは0なのに、始めの月と終わりの月で比べると、6割の期間が上昇か下落に見えた
- 最初と最後の12か月の平均で比べると、2割に下がった。12か月の平均は季節の山谷を打ち消すため
- 200店のすべてで、①の読み方なら「上昇」に見える期間も「下落」に見える期間も選べた（100%）

### 期間の長さごと（①始めの月と終わりの月、上昇か下落に見えた割合）
| 期間の長さ | 始めと終わりの月の関係 | 上昇か下落に見えた |
|---|---|---|
| 13か月・25か月 | 同じ暦の月（例：1月と翌年の1月） | 36.2%・38.1% |
| 12か月・24か月・36か月 | 隣り合う暦の月 | 41.5%・43.4%・43.3% |
| 18か月・19か月 | 半年ずれた月（例：6月と12月） | 74.6%・75.4% |

- 始めと終わりが季節の山と谷になる切り出し方では、4分の3の期間が上昇か下落に見えた
- 同じ暦の月どうしで比べても、36〜38%は上昇か下落に見えた。揺れが数か月残るため
- ②期間に引いた直線は、長さ12か月で72.0%が上昇か下落に見えた。1年に満たない山谷に直線を引くと、季節の形がそのまま傾きになる

### 1店（`data/store_visitors.csv`）の中で、長さ24か月の期間を選ぶと
| | 値 |
|---|---|
| いちばんの「上昇」 | +31.3%（78〜101か月目） |
| いちばんの「下落」 | −22.2%（31〜54か月目） |
| 上昇に見える期間の割合 | 28.9% |
| 下落に見える期間の割合 | 16.5% |
| ③最初と最後の12か月の平均で見たときの幅 | −9.4%〜+13.3% |
| 10年の最初の12か月と最後の12か月の平均の比 | +1.7% |

### 確かめ：置き方を変える（各200店）
| 置き方 | ①始めと終わりの月：上昇か下落 | ②直線：上昇か下落 | ③12か月の平均：上昇か下落 |
|---|---|---|---|
| 基本（残りやすさ0.8・季節15%・伸び0・線±10%） | 59.8% | 47.3% | 18.1% |
| 揺れの残りやすさ 0.5 | 59.8% | 39.3% | 6.0% |
| 揺れの残りやすさ 0.95 | 56.4% | 43.9% | 15.2% |
| 季節なし | 37.2% | 39.3% | 18.6% |
| 季節30% | 74.4% | 60.6% | 17.5% |
| 本当の伸び 年+3% | 61.4%（うち下落19.8%） | 52.6%（うち下落13.3%） | 26.8%（うち下落2.5%） |
| 本当の伸び 年−3% | 60.9%（うち上昇21.4%） | 51.1%（うち上昇14.2%） | 23.8%（うち上昇2.8%） |
| 上昇・下落の線 ±5% | 79.2% | 72.9% | 51.2% |
| 上昇・下落の線 ±20% | 28.8% | 15.9% | 0.8% |

- どの置き方でも、①始めと終わりの月の比べ方がいちばん上昇か下落に見えやすく（28.8〜79.2%）、③12か月の平均がいちばん見えにくかった（0.8〜51.2%）
- 本当に年+3%で伸びている店でも、①なら19.8%の期間が「下落」に見えた。③では2.5%だった
- 数字の大きさは、季節の振れ幅と「上昇・下落」の線の決め方で大きく動く。とくに③は揺れの残りやすさで6.0〜18.1%動いた
- 基本の行は、主な結果とは別に作り直した200店での値（主な結果は59.6%・48.4%・19.6%）

## 動かし方
```
pip install -r requirements.txt
cd src && python a817_window.py
```
10秒ほどで終わります。`data/store_visitors.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（`src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp）。流し直しは約6秒
- 図3枚を開き、日本語・重なり・軸を確かめた。図1の切り出した2つの期間は、縦軸を0から始め、10年全体と同じ高さにそろえた（縦軸を0から始めない見え方は関連する記事 813 で扱う）

## データ
- `data/store_visitors.csv`：1店分の架空の来店数（month・calendar_month（暦の月）・visitors）
- `results/a817_main.json`：置いた前提・主な結果・確かめのすべて
- `results/share_by_method.csv`：読み方ごとの割合
- `results/share_by_length.csv`：読み方と期間の長さ（12〜36か月）ごとの割合
- `results/sensitivity.csv`：置き方を変えた確かめ

## 注意（言えないこと）
- 架空のデータです。季節の山谷の形と大きさ、揺れの大きさと残りやすさ、本当の伸びは作成者が置いたもので、割合の数字はこれで決まります
- 「±10%で上昇・下落」は作成者の決め方です。線を±5%にすると①は79.2%、±20%にすると28.8%と大きく動きます
- 12か月の平均で比べても、揺れが残る限り、上昇・下落に見える期間はなくなりません。本当の伸びがあるかどうかは、この分析だけでは決められません
- 実在の店の来店数を表すものではありません
