# 1082 似た人どうしがつながっているのは、影響しあったからか、もとから似ていたからか？（つながり）

つながっている人どうしは、好みが似ていることがよくあります。似ている理由は、つながってから互いに影響しあったのか、もとから似た人を選んでつながったのかの2つが考えられます。1回の調査で「つながった2人の好みが似ている」と分かっても、どちらかは決められません。**ここでは、作成者が乱数で作った架空の趣味の会を3つ（もとから似ていた会・影響しあった会・両方が半分ずつの会。会員1,500人。「道具の好み」の本当の値と、つながりのでき方・好みの動き方を作成者が置いたもの）作り、①1回の調査、②2回の調査で好みの変化を友だちの好みで説明する回帰、③新しくつながった2人の「つながる前」の好みの似かた、の3つの物差しで、3つの会を見分けられるかを数えました。** 「道具の好み」は、手作りの道具が好きか、買った道具が好きかを点数にした架空の好みです。

## 主な結果

### 3つの物差しで3つの会を比べる（各100回の平均、`results/three_worlds.csv`）
| | もとから似ていた会 | 影響しあった会 | 両方が半分ずつの会 |
|---|---|---|---|
| ① 1回の調査：つながった2人の点数の相関 | **0.211**（0.185〜0.24） | **0.206**（0.173〜0.24） | 0.215（0.184〜0.247） |
| ② 2回の調査：変化を友だちの点数で説明した係数 | **0.164**（0.124〜0.207） | 0.278（0.238〜0.324） | 0.221（0.177〜0.265） |
| ③ 新しくつながった2人の、つながる前の点数の相関 | **0.497**（0.424〜0.564） | **0.127**（0.035〜0.218） | 0.259（0.176〜0.338） |

（括弧は100回の10〜90%の範囲）

- **① 1回の調査では、つながった2人の点数の相関は0.211・0.206・0.215で、3つの会を見分けられなかった**。3つの会の相関がそろうように、作成者が選び方の強さと寄る強さを選んだ（作成者の置いた物差しの写し）。言えるのは、同じ相関がどちらの仕組みからも出せる、ということ
- **② 2回の調査で「友だちの点数が高い人ほど、1年で点数が上がったか」を回帰すると、もとから似ていた会でも係数は0.164と正になった**。この会では友だちに寄る動きはまったく置いていない（β＝0）。1回目の点数には聞き取りの誤差が入っているので、友だちの点数が「本人の本当の好み」の手がかりになり、1回目にたまたま低く出た人ほど2回目に戻る（平均への回帰）ためで、誤差をなくすと −0.001 になった（下の確かめ）
- ③ 1回目と2回目の調査の間に新しくつながった2人の、つながる前の点数の相関は、もとから似ていた会で0.497、影響しあった会で0.127だった。もとから似ていた会では、つながる前から似ていた
- 影響しあった会でも③は0にならなかった（0.127）。新しいつながりの80%は同じ班の中ででき、同じ班の人はそれまでのつながりで影響しあって、すでに似ているため
- 本当の好みで数えた①の相関（誤差なし）は、もとから似ていた会0.278・影響しあった会0.258・両方0.276だった。本当の好みのばらつきは、影響しあった会では0.436と、もとから似ていた会（0.998）より小さかった（友だちに寄るほど、全体が似てくる）

### 確かめ1：聞き取りの誤差を変えると（12通り、各30回、`results/grid_measurement_error.csv`）
| 聞き取りの誤差（好みのばらつきの何倍） | 0 | 0.25 | 0.5 | 0.8 |
|---|---|---|---|---|
| ② もとから似ていた会 | −0.001 | 0.065 | 0.165 | 0.219 |
| ② 影響しあった会 | 0.211 | 0.232 | 0.278 | 0.291 |

- 誤差がないとき、もとから似ていた会の②は −0.001 でほぼ0、影響しあった会は0.211で、置いた寄る強さ0.2に近かった（ほぼ作りどおり）
- 誤差が大きいほど、もとから似ていた会の②は大きくなり、誤差0.8倍では0.219と、誤差がないときの影響しあった会（0.211）を上回った。②の係数が正でも、影響しあった証拠にはならない
- どの誤差でも、②はもとから似ていた会のほうが影響しあった会より小さかった（4通り中4通り）。ただし、本当の寄る強さが分からなければ、この差は使えない（推測）

### 確かめ2：選び方の強さ・寄る強さを変えると（6通り、各30回、`results/grid_strength.csv`）
| | ① 1回の調査の相関 | ② の係数 | ③ つながる前の相関 |
|---|---|---|---|
| もとから似ていた会（選び方の強さ3通り） | 0.176〜0.226 | 0.137〜0.175 | **0.407〜0.548** |
| 影響しあった会（寄る強さ3通り） | 0.159〜0.213 | 0.18〜0.346 | **0.078〜0.13** |

- ①は両方の会で重なり、②もどちらも正だった。③だけは、6通りのどれでも、もとから似ていた会のほうがはっきり大きかった

## 注意（言えないこと）
- 架空のデータです。選び方の強さ、寄る強さ、班の作り、つながりの入れかわり、聞き取りの誤差は作成者が置いたもので、結果はこれで決まります。①の相関がそろっているのは、そうなるように作成者が強さを選んだためです
- 置き方によらず言えるのは、1回の調査の似かたからは、影響しあったのか、もとから似ていたのかは決められないこと、②の回帰の係数は、聞き取りの誤差があると影響がなくても正になることです。②がどれだけ大きく出るかは誤差の大きさで決まり、この記事の数字からは分かりません
- ③は、つながった日が分かり、つながる前に好みを聞いていることが前提です。知り合ってから記録に載るまでの間に影響しあった分は、③では「もとから似ていた」に入ります。また、同じ班の中での影響で③が0にならないことは、上のとおりです
- 好みの似かたを生む3つ目の理由（同じ集まりに出て同じものに触れる、など、2人に共通の外からのきっかけ）は入れていません
- 「道具の好み」は架空の好みで、人の性別・年齢などの属性は扱っていません。実在の会・サービスの数字ではありません
- 関連する記事：同じ企画の 1080（知り合いをたどって集めた人は全体を表しているか）は、似た人どうしがつながっていると、たどって集めた人が最初の人の組に偏ることを扱っています。1088（新しい道具の使い始めは、まわりの何人が使えば広がるか）は、まわりの影響だけで使い始めると置いたときの広がり方を扱っています
