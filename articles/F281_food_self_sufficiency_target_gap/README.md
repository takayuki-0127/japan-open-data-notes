# F281　食料自給率の目標と、実際の動きの差はどこから来ているか？

精選モード（B. 白書・審議会 Q19）。食料・農業・農村基本計画は2000年から5年ごとにカロリーベースの食料自給率の目標を掲げてきた。2015年計画の目標年度である2025年度の実績（概算）が2026年8月に公表されたので、目標と実績の差を「分子（国産の熱量）・分母（全体の熱量）」と「品目」に分け、過去の計画とも比べた。

- 計画（事前登録）：[PLAN.md](PLAN.md)（コミット 6954844、分析より前）
- 政策の良し悪しや目標の立て方への提言はしない。品目の生産者を評価するものではない。

## 問い

1. 2015年計画の目標 45%（国産 1,040kcal ÷ 全体 2,313kcal）と、2025年度の実績 37.1%（概算、830 ÷ 2,237kcal から計算）の差は、どこから来ているか
2. 2000・2005・2010年計画でも同じ形で外れてきたか。目標の高さと、届いた割合に関係はあるか
3. （問い直し）今の計画（2020年・2025年）の 45% は、これまでの国産熱量の動き方で届く高さか

## 結果

### 1. 2015年計画：目標 45.0% → 実績 37.1%（−7.9ポイント）

| 分け方 | ポイント |
|---|---|
| 分子：国産の熱量が目標（1,040kcal）に届かなかった分（実績 830kcal） | −9.2 |
| 分母：全体の熱量が見通し（2,313kcal）より減った分（実績 2,237kcal） | +1.4 |
| 合計 | −7.9 |

- 全体の熱量が見通しより少なかったことは、自給率を押し上げる向きに働いた。差はすべて分子から来ている（H1 支持。ただし PLAN 前に分子・分母の値は見ていたので、確かめとしては弱い）。
- 2つの順番の分け方では、分子 −9.4〜−9.1、分母 +1.2〜+1.5。2024・2025年度の平均では分子 −8.6、分母 +1.3。

### 2. 品目に分ける（2015年計画の表から目標の国産熱量を組み立てる）

計画の「1人1年当たり消費量」と「生産努力目標 ÷ 国内消費仕向量」を、2025年度の品目の熱量に当てはめて、目標の国産熱量・供給熱量を品目ごとに組み立てた（畜産物は飼料自給率の目標 40% も反映）。

| 品目 | 国産熱量の不足（kcal） | 分子の分（ポイント） |
|---|---|---|
| 畜産物（生乳・牛肉・豚肉・鶏肉・鶏卵） | 49.1 | −2.2 |
| 　うち飼料自給率が40%に届かなかった分（実績24%） | 46.0 | |
| 　うち畜産物の生産量の不足 | 3.0 | |
| 米 | 38.5 | −1.7 |
| 魚介類 | 34.0 | −1.5 |
| 野菜 | 19.9 | −0.9 |
| 果実・大豆・いも・麦 | 16.0 | −0.7 |
| 表にない品目・換算の差 | 52.4 | −2.3 |
| （分母：全体の熱量が見通しより減った分） | | ＋1.4 |

- 品目の不足（プラスの分の合計 160kcal）のうち、畜産物 31%、魚介類 21%（合わせて 52%）、米 24%。**H2 は判定保留／弱い支持**：判定は事後の2つの選択に左右される。1つは不足の分母で、国産熱量の不足全体（210kcal）を分母にすると畜産物＋魚介類 40%・米 18% で外れになる（どちらにするかは計画で決めていなかった）。もう1つは大豆の定義の直し（「計画からのずれ」）。
- 畜産物の不足のほとんど（49kcal のうち 46kcal）は飼料自給率から来ていた。肉・卵・牛乳の生産量はほぼ目標どおり（生乳 99%、牛肉 96%、豚肉 98%、鶏肉 118%、鶏卵 101%）。ただし 46kcal は、品目ごとの「飼料を考えた自給率」を目標と実績の飼料自給率の比（40÷24）で一律に伸ばした近似で、計画が実際に置いた飼料の内訳ではない。R3（重量の自給率 × 飼料自給率で一律）では、畜産物の不足 47kcal のうち飼料の分は 45kcal。
- 米の割合は、2025年度に国産米の一部が在庫の積み増しに回った（国産米在庫取崩し ▲44.2万トン）分が大きい。米の自給率 95% は、国内生産量からこの積み増し分を引いて国内消費仕向量で割った値とみられ（(804−44)÷800、推測）、下がったのは主に在庫の積み増しによる（輸入ではない）。米の割合は基本 24%、2024年度の係数で 13%（R2）、国内生産量÷国内消費仕向量で 8%（R4）と、8〜24% の幅がある。
- 計画の数字（1,040kcal）は、表の品目からは 988kcal までしか組み立てられなかった。残りの 52kcal（2.0〜2.3ポイント）は、表にない品目（砂糖・油脂・でん粉など）と、計画が使った2013年度の換算との差で、ここでは分けられない。
- 品目の生産が目標どおりで、消費は実績どおりだったとすると、組み立てた範囲では 41.6%。

### 3. 過去の計画（H3・H5）

| 計画 | 目標年度 | 目標 | 実績 | 差 | 分子の分 | 分母の分 | 飼料自給率 目標→実績 |
|---|---|---|---|---|---|---|---|
| 2000年 | 2010 | 45% | 39% | −6 | −7.6 | +1.6 | 35% → 25% |
| 2005年 | 2015 | 45% | 39% | −6 | −7.1 | +1.1 | 35% → 28% |
| 2010年 | 2020 | 50% | 37% | −13 | （分母の目標なし） | | 38% → 25% |
| 2015年 | 2025 | 45% | 37.1% | −7.9 | −9.2 | +1.4 | 40% → 24% |

- 4つの計画すべてで実績は目標より5ポイント以上低く、分母の分はどれもプラス（全体の熱量は見通しより減った）。差はすべて分子から来ていた（H3 支持）。
- 飼料自給率の目標にも4つとも届かなかったが、2005年計画の差は 7ポイントで、基準の8ポイントに届かなかった（H5 外れ）。
- 2000・2005年計画の分子は「目標の自給率 × 分母」、実績の分子は「自給率（整数）× 全体の熱量」で近似（2025年度は公表値 830kcal）。

### 4. 目標の高さと実際の伸び（H4）

4つの計画 × 14品目（56組）の生産努力目標のうち、目標年度に届いたのは12組（21%）。

- **目標の高さ（目標 ÷ 基準年度）と実際の伸び（実績 ÷ 基準年度）の順位相関は +0.01**（並べ替え検定、両側 p = 0.91）。目標を高くしても、その品目の生産が伸びたわけではない。その分、高い目標ほど届かない。
- 目標の高さと届いた割合（実績 ÷ 目標）の順位相関は −0.57 だが、これは両方に目標が入る割合の作り方から出るもので、伸びが目標の高さと無関係でも −0.57（95% の幅 −0.71〜−0.41）になる。最初に出した「並べ替え検定 p < 0.001」はこの点を除けていないので取り下げた（正しい帰無仮説の下では p = 0.49）。
- **H4 の注記**：計画の基準（順位相関 < −0.3）では「支持」だが、上の理由で、この判定は「目標が高いほど届かない」という見かけの関係を示すだけで、「高い目標が生産を伸ばさない／下げる」ことは示さない。
- 「維持か減らす」目標（高さ 1.0 以下、17組）は 53% が届き、届いた割合の中央値 1.01（実際の伸びの中央値 0.98）。「1割以上増やす」目標（21組）は 10% しか届かず、中央値 0.77（実際の伸びの中央値 0.92）。
- 参考（計画からのずれ）：計画の14品目にあった飼料作物（良質粗飼料、TDN）を、飼料作物の収穫量（TDN、年）で足すと、4回とも届かず（届いた割合 0.69〜0.73）、60組で実際の伸びとの順位相関 +0.05、届いた割合との順位相関 −0.61。収穫量と計画の「良質粗飼料」は定義が同じとは限らない（基準年度の計画値と近い年の収穫量の水準が合わない）。
- 4回とも届いたのは鶏肉と鶏卵だけ。米・野菜・果実・いも・大豆・生乳・牛肉・魚介類は一度も届いていない。

### 5. 問い直し（結果を見てから足した）：今の 45% は届く高さか

- 2025年度の国産熱量 830kcal から、2020年計画の目標（2030年度 1,031kcal）までは +24.2%、2025年計画の目標（975kcal）までは +17.5% が要る（年 +3.3%）。
- 1965〜2025年度の国産熱量（1人1日）の「5年前と比べた変化」56個のうち、増えたのは4個（7%）だけで、最大は 1998年度の +7.2%（1993年の大冷害からの戻り）。+17.5% に届いた5年はない。
- 1965〜2023年度の国産熱量は、どの年度も「自給率（整数）× 全体の熱量」の近似（公表値は2024・2025年度だけ）。自給率を ±0.5 ポイントの一様で1万回ずらすと、5年ごとの変化の 95% の幅は窓ごとに ±1.7 ポイント前後（最大 ±2.3）、いちばん大きい窓も 9.4% まで（97.5% 点）で、+17.5% に届く場合はなかった。結論は変わらない。
- 国産熱量が今のままなら、45% には全体の熱量を 1,844kcal（−17.6%）まで下げる必要がある。5年で最も大きく下がったのは −9.3%（2018→2023年度、2019年度の推計方法の変更をまたぐ）。
- 2025年計画は飼料自給率の目標を 28% にし（2015年計画は 40%）、全体の熱量の見通しも 2,190kcal と低めに置いている。それでも国産熱量は過去にない伸び方が要る計算になる（推測を含む比較：過去の伸びは、これからの伸びの上限を示すものではない）。

## 頑健性

| 確かめ | 結果 |
|---|---|
| R1 3年度平均（H3：目標年度までの3年、H4：生産量） | 差は −5.0〜−12.7ポイント、分子の分は差の 117〜132%。H4：実際の伸びとの順位相関 +0.03（届いた割合とは −0.58） |
| R1 2024・2025年度の平均（H1） | 分子 −8.6、分母 +1.3 |
| R2 2024年度の値で品目を換算（H2） | 畜産物＋魚介類 58%、米 13% |
| R3 畜産物を「重量の自給率 × 飼料自給率」で一律に換算（H2） | 51%、24% |
| R4 米を国内生産量 ÷ 国内消費仕向量で数える（H2） | 63%、8% |
| R5 H4 から魚介類を除く／牛肉・豚肉を除く／2010年計画を除く | 実際の伸びとの順位相関 +0.07／+0.06／+0.06（両側 p 0.62〜0.69）。届いた割合とは −0.53／−0.56／−0.48 |
| R6（事後に追加）品目値を農林水産省の品目別の値に合わせない（H2） | 52%、22% |
| 分母を国産熱量の不足全体（210kcal）に（H2、レビューで追加） | 40%、18%（外れ） |

H2 は、分母を品目のプラスの分（160kcal）にすると R2〜R6 のどれでも支持だが、基本の条件では2つの基準（50% と 25%）の境目に近く、分母を 210kcal にすると外れる。

## 計画からのずれ

- **H2 の判定が変わる直しを、結果を見てからした。** 最初の計算では、大豆の目標の自給率を「油用を含む全体」で、実績を「食用」で比べてしまい、大豆が目標を上回る形（−11.9kcal）になった。そのときの米の割合は 25.2% で、H2 は外れだった。定義をそろえて（食用の自給率を全体の自給率の比で伸ばす）直すと米は 24.0% になり、支持に変わった。直した理由は定義の食い違いだが、判定の変わる直しなので H2 は弱い支持として扱う。
- H2 の「不足のうち」は、品目ごとの不足のうちプラスの分の合計（160kcal）を分母にした（計画では決めていなかった）。分子の不足全体（210kcal）を分母にすると、畜産物＋魚介類は 40%、米は 18%。
- 頑健性 R5 は、計画では「2020年計画を除く」としたが、2020年計画は目標年度が来ておらず H4 に入っていないので、代わりに2010年計画（小麦・大豆の目標が2倍以上で外れ値に近い）を除いた。
- 実績の分子（2010・2015・2020年度）は公表の値ではなく、自給率（整数）× 全体の熱量の近似（±0.5ポイント分、約12kcal の幅）。問い直し（5.）の1965〜2023年度の国産熱量も、すべて同じ近似。
- 問い直し（5.）は結果を見てから足した。
- H4 の品目は、計画では14品目に飼料作物を入れていたが、分析では飼料作物の代わりに魚介類を入れた（累年表に飼料作物の生産量がないため）。飼料作物を足した結果は 4. の参考に載せた（レビュー後に追加）。
- 頑健性 R6（品目値に合わせない）は計画になく、結果を見てから足した。
- H4 は、レビューの指摘を受けて、目標の高さと実際の伸びの順位相関を主にした（届いた割合との相関は割合の作り方から出るため）。

## 言えないこと

- 目標の国産熱量の品目分けは、計画の消費量・生産量を2025年度の熱量の係数に当てはめて組み立てたもので、計画が実際に使った品目の内訳ではない。計画の合計（1,040kcal）とは 52kcal 合わない。
- 「なぜ届かなかったか」（価格、担い手、天候、政策の中身など）は分けていない。ここで分かるのは、どの品目の数字が目標と違ったかまで。
- 2025年度は概算値で、確定値で変わりうる。
- 米は、2025年度の在庫の積み増しの影響を強く受けている（米の割合は 8〜24%）。1年だけの値で「米が足りなかった」とは言えない。
- 実績の全体の熱量は2019年度から推計方法が変わった（訪日客などの分を除く）。2018年度以前と2019年度以降の比較には段差が入る。
- 飼料自給率の目標の差が畜産物の国産熱量にどう効くかは、品目ごとの「飼料を考えた自給率 ÷ 重量の自給率」を目標の比（40÷24）で一律に伸ばす近似による。計画が実際に置いた品目ごとの飼料の内訳ではない（R3 の一律の扱いでは飼料の分 45kcal）。
- 目標の高さと届いた割合の関係は、割合の作り方から出る見かけの関係を含む。目標の高さそのものが生産の伸びに影響したかどうかは、この分析では分からない。

## レビューで直したこと

独立レビュー（メインで実施）では、分解の式、すべての数値、元の公表値、クリーンな再実行（バイト単位で一致）が確かめられた。そのうえで次の指摘を受けて直した（新しい数値は `src/zz_f281_06_レビュー対応.py` で計算し直した）。

- **H4（高）**：届いた割合（実績÷目標）と目標の高さ（目標÷基準）の両方に目標が入るため、順位相関 −0.57 はほぼ割合の作り方から出る（伸びが無関係でも −0.57、95% の幅 −0.71〜−0.41）。目標の高さと実際の伸び（実績÷基準）の順位相関 +0.01（p = 0.91）を主にし、「目標を高くしても生産が伸びたわけではない。その分、高い目標ほど届かない」に書き直した。「p < 0.001」は取り下げ、H4 の判定に注記を付けた。図4 も実際の伸びに替え、軸の目盛りを読みやすくした。
- **H2（高）**：判定は分母（160kcal か 210kcal か）と大豆の直しという事後の2つの選択に左右されるので、「判定保留／弱い支持」とした。210kcal なら畜産物＋魚介類 40% で外れ。
- **米（中）**：米の割合は 8〜24% と幅があり、2025年度の在庫の積み増しによる分が大きいことをタイトル・結論に入れた。自給率 95% は主に在庫の積み増しによるもの（推測）と書き直した。
- **飼料の分（中）**：46kcal は一律の近似であることを「言えないこと」に足し、R3 での飼料の分（45kcal）を載せた。
- **計画からのずれ（中）**：H4 の品目で飼料作物を魚介類に替えたことと、R6 が事後であることを足した。飼料作物を足した結果を参考に載せた。
- **問い直しの近似（低〜中）**：1965〜2023年度の国産熱量がすべて近似であることを書き、丸めの幅（95% で最大 ±2.3 ポイント）を計算した。結論は変わらない。
- **細かい点（低）**：実績の範囲を「37〜41%」に（2008年度 41%）、37.1% の初出に「概算、830÷2,237kcal から計算」と添えた、生産量の例に牛肉 96% を足した。

## 外に出す先（案）

「公表された計画の数字から、品目ごとの目標を組み立て直して実績と比べる」手順は、Zenn か Qiita に「計画と実績の差を分子・分母と品目に分ける」として方法の記事にできる。政策の評価ではなく、手法（比の差の分け方、定義の違う数字のそろえ方）として書く。投稿はしていない。
