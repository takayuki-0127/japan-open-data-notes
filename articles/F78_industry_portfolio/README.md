# F78 産業がばらけている町は、不景気に強いのか？ 産業ポートフォリオと雇用の落ち方

note：「産業がばらけている町は、不景気に強いのか？ 1,735市区町村の産業ポートフォリオで調べると、多様な町ほどぶれが小さく見えたのは町の大きさのせいで、効いていたのは『どの産業に偏っているか』だった」

## 問い

いろいろな産業に雇用が分かれている町（多様な町）は、1つの産業に偏った町より、不景気のときに雇用が落ちにくいのか。投資の「分散投資」の考え方（ポートフォリオ）を、町の産業構成に当てはめて確かめる。

## データ

| 中身 | 出どころ | 年 |
|---|---|---|
| 産業大分類（18）別の従業者数（民営） | 経済センサス（基礎調査2014、活動調査2016・2021）。e-Stat「社会・人口統計体系 市区町村データ」。F46 で取得したものを再利用 | 2014・2016・2021 |
| 総人口・年齢3区分 | 国勢調査（同上、F46 から再利用） | 2015 |
| 都道府県別の就業者 | 労働力調査 都道府県別結果（モデル推計値）年平均 第3表（statInfId 000031952605、F01 から再利用） | 2002〜2025 |

- 単位は1,735市区町村（政令市は市全体、東京23区は区ごと。データの欠けた町村を除く）
- 新しいデータの取得はしていない

## 手法

1. **多様性の指標（2016年の産業シェア）**：実質的な産業の数（1/HHI）、エントロピー、全国との近さ（クルーグマン指数）
2. **雇用の伸び**：2016→21年の民営の従業者の伸び（対数×100、上下1%を丸め）。この期間はコロナの影響を含む
3. **産業構成で決まる伸び（バーティク）**：2016年の産業シェア ×（自分を除いた）全国の産業別の伸び
4. **その町だけのぶれ** u ＝ 実際の伸び − バーティク。|u| を「産業の流れでは説明できない、その町独自の動き」とみなす
5. **産業ポートフォリオのぶれ**：産業 j の町レベルの伸び（全国との差）のばらつきと、産業どうしの相関を、2016年に30人以上いる町から計算（共分散行列）。町の予測されるぶれ ＝ √(s′Σs)（s は町の産業シェア）
6. **回帰**：|u|、平均の伸び、10%超の落ち込み（線形確率）を、多様性・ポートフォリオのぶれ・人口（対数）・年齢構成・都道府県の固定効果で説明。標準誤差は都道府県でクラスター
7. **都道府県**：リーマン・ショック（2008→10年）とコロナ（2019→21年）の就業者の変化、平常時（2003〜2019年）の年ごとの伸びの標準偏差を、多様性と製造業・宿泊飲食の割合で説明（47、HC3）

## 主な結果

- 実質的な産業の数は中央値 **6.8**（下位10% 4.6、上位10% 8.3）。人口が多い町ほど多様（相関 0.30）
- 2016→21年、全国の民営の従業者は +1.9%、市区町村の中央値は −1.0%。**9.7%** の町で10%超減った
- **そのまま比べると、多様な町ほどぶれは小さい**：多様性の5分位で、その町だけのぶれ |u| は 6.4 → 4.9%、10%超減った町の割合は 11.5% → 7.5%
- **人口・年齢構成・都道府県をそろえると差は消える**：多様性1標準偏差あたり |u| は **+0.09%ポイント（95%区間 −0.40〜+0.57）**。平均の伸び（−0.02）、10%超の落ち込み（+0.6%ポイント）も区間が0をまたぐ
- **効いていたのは「どの産業に偏っているか」**：ポートフォリオで予測したぶれの5分位（6.7 → 8.8%）に対し、実際のぶれは 5.4 → 9.7%（5分位の相関 **0.98**）。条件をそろえても、予測したぶれ1標準偏差あたり |u| は **+0.41（0.06〜0.75）**、多様性と同時に入れると +0.56（0.16〜0.97）
- 産業構成で決まる伸び（バーティク）は平均の伸びを説明する（1ポイントあたり +0.78、0.44〜1.11）が、町ごとの伸びのばらつきのうち説明できるのは約1%
- 同じ町の中の産業どうしの伸びの相関は平均 **0.03** とほぼ0。分散の効果は理屈の上では大きいはずだが、実際のぶれは町の大きさ（従業者の多さ）でほぼ決まっていた（推測です：小さい町ほど、1つの事業所の開業・閉鎖で数字が大きく動くため）
- **都道府県**：リーマン・ショックで多様な県ほど落ち込みが小さかった（相関 +0.31）が、製造業の割合と強く関係していて（相関 −0.35）、産業の割合をそろえると差は消える。コロナ（相関 +0.15）、平常時の伸びのぶれ（−0.04）とも、はっきりした関係はない

## 頑健性

| 設定 | 多様性1SDあたり |u|（%ポイント） | 95%区間 |
|---|---|---|
| 基本（実質的な産業の数） | +0.09 | −0.40〜+0.57 |
| エントロピー | −0.03 | −0.54〜+0.49 |
| 全国との近さ（クルーグマン指数の逆） | −0.29 | −0.72〜+0.14 |
| 人口5千人以上 | +0.07 | −0.30〜+0.44 |
| 都道府県の固定効果なし | +0.23 | −0.13〜+0.60 |
| 人口で重みづけ | +0.06 | −0.21〜+0.33 |
| 宿泊・飲食の割合が上位10%の町を除く | +0.14 | −0.28〜+0.57 |
| 製造業・宿泊飲食の割合を統制 | −0.52 | −1.08〜+0.05 |
| 平常時 2014→16 | −0.16 | −0.39〜+0.06 |

人口の帯（5千未満、5千〜2万、2万〜10万、10万以上）に分けても、どの帯でも区間が0をまたいだ。

## 言えないこと

- 経済センサスは3時点（2014・2016・2021）しかなく、「不景気」はコロナを含む2016→21年の1回だけ。2014（基礎調査）と2016（活動調査）は調査の種類が違い、平常時の比較には調査の違いが混ざる
- 従業者は事業所のある場所で数えている。町に住む人が仕事を失ったかどうかではない
- 公務・個人経営の農家などは含まない（民営の事業所のみ）
- 都道府県の分析は47しかなく、2016年の産業構成を2008年のリーマン・ショックに当てはめている（時期がずれている）
- 多様性が雇用を守らない、とまでは言えない。人口と多様性は一緒に動いていて、このデータでは分けきれない部分がある
