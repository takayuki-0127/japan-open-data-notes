# 401 集計用の表は、1枚の大きな表と、事実とマスタに分けた表のどちらが直しやすいか（実務の型）

レポート用のデータを、マスタの列（商品名・部門・店名・地域）を写して持つ「1枚の大きな表」にするか、売上の事実とマスタに分けて持つかを比べたフォルダです。架空の売上30万行（商品200・店20、2024〜2025年）で、同じ8本のレポートを2つの持ち方で書き、マスタが変わる場面とマスタに不備がある場面で、書き換える行の数と、何もしないと答えが合わなくなるレポートの本数を数えました。F275（集計の SQL の直しやすさ）・F249 に対し、ここでは表の持ち方だけを比べます。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A401 | SQL の長さはどれだけ違うか。マスタが変わったとき、どちらが何行を書き換えるか。何もしないと何本のレポートが合わなくなるか | 8本のレポートを2つの持ち方で書き、はじめは答えが一致することを確かめる。8つの場面（部門替え・過去分だけ直した・売れた時点の部門で見たい・地域の区分替え・商品名の訂正・属性の追加・マスタにないコード・マスタの重複）で数える | `src/a401_wide_vs_star.py`、`src/sql_reports.py` |

## 主な結果
- **SQL の行数（8本の合計）**：1枚の表は26行、事実とマスタは34行。つなぐ表が1つ増えるごとに1行増えるだけで、差は8行
- **商品12個の部門替え（全期間を今の部門で見たい）**：事実とマスタはマスタの12行を書き換える。1枚の表は13,310行。直さないと、1枚の表は8本のうち4本が合わない
- **過去分だけ直して、毎日の取り込みを直し忘れた**：1枚の表に古い部門の行が3,344行入り続け、4本が合わないまま
- **店3つの地域の区分替え**：3行 対 45,027行（直さないと2本が合わない）。**商品名の訂正1件**：1行 対 3,732行（1本）。**属性の追加**：200行 対 30万行
- **「売れた時点の部門で見たい」**：1枚の表は何も直さなくてよい（写した値がそのまま売れた時点の値）。事実とマスタは、今のマスタだけでは8本のうち4本が合わず、期間つきのマスタに変えて、商品をつなぐ5本のレポートのつなぎ方を直す。「今の部門」と「売れた時点の部門」の両方を出すには、1枚の表は列が2つ要る
- **マスタにない商品コードの売上（500行）**：事実とマスタの内部結合は、500行（売上の0.19%）を黙って落とす（商品をつなぐ5本）。1枚の表は部門が空欄の行として残る
- **商品マスタに同じ商品が2行（5商品）**：事実とマスタは、つないだ行が増えて売上が+2.81%（4本が合わない）。1枚の表は、取り込みのときに同じことが起きる

## 動かし方
```
pip install -r requirements.txt
cd src && python a401_wide_vs_star.py     # 10秒ほど
```
乱数の種を固定してあるので、`data/`・`results/`・`figures/` は毎回同じです（`results/timing_varies_each_run.json` の秒数だけ変わります）。

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures が一致した（秒数のファイルを除く）
- はじめの状態では、8本のレポートが2つの持ち方で同じ答えになる（コード内の assert）
- 期間つきのマスタに直した SQL は、1枚の表の「売れた時点の部門」の答えと8本とも一致する（assert）

## 未検証
- SQL は T-SQL でも通る書き方にしましたが、SQL Server では動かしていません。DuckDB 1.5 で実行しました
- 速さは比べていません。参考の秒数は30万行・1スレッドの DuckDB のもので、表の大きさや製品で変わります

## データ
- すべて架空（作成者が乱数で作成、seed 401）。`data/product.csv`（商品200）、`data/store.csv`（店20）、`data/fact_sales_sample5000.csv`（売上30万行のうち5,000行の抜き出し。全体はコードが作る）

## 注意（言えないこと）
- 架空の8本のレポートと8つの場面です。場面は作成者が選びました。「何本が合わない」は、レポートがどの列を使うかで決まります
- 「書き換える行の数」は手間の1つの目安です。1枚の表を毎晩ぜんぶ作り直す運用なら、書き換えの手間は取り込みの時間に変わります
- 速さ・容量・権限の分け方は比べていません
- どちらの持ち方がよいかは、何を見たいか（今の区分か、売れた時点の区分か）で変わります。この記事は、どちらかを勧めるものではありません
