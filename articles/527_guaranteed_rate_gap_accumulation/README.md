# 527 予定利率と実際の利回りが0.5ポイントずれると、30年の積立金はどれだけ足りなくなるのか（保険数理・リスク）

毎年同じ額を積み立てて、「予定利率で増えればこの額になる」という目標を置いたとき、実際の利回りが予定より少し低いと、30年後にどれだけ足りなくなるのでしょうか。**ここでは、毎年の期初に1ずつ30年積み立てる架空の積立で、予定利率 0.5・1.5・3.0%、実際の平均利回りのずれ 0〜1.0ポイント、年ごとの利回りの振れ 0・2・5% を組み合わせ、不足率と目標に届かない確率を10万通りのくじで出しました。** 数字は、置いた利率・ずれ・振れで決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A527 | 利回りが予定より低いと、30年後にどれだけ足りないか | 期初に1ずつ30年。目標 = 予定利率で増えたときの30年後の額。実際の利回り = 予定 − ずれ + 振れ × 標準正規（年ごとに独立）。ずれ 0・0.25・0.5・1.0ポイント、振れ 0・2・5%。不足率 = 1 − 実際 ÷ 目標。各場面10万通り（同じ乱数を全場面で使う）、seed 527 | `src/a527_rate_gap.py` |

## 主な結果
- **振れがないとき、0.5ポイントのずれで30年後の不足率は**：予定0.5%で 7.5%、予定1.5%で **7.8%**、予定3.0%で 8.2%。1.0ポイントのずれでは 14.4%・14.9%・15.6%
- ずれが同じなら、予定利率が高いほど不足率は少しだけ大きい（複利で差が積み上がるため）
- **予定1.5%・ずれ0.5ポイントで振れを入れると**：不足率の中央値は 振れ2%で 8.0%、5%で 9.2%。不足率の95%点は 17.5%・**30.7%**
- **目標に届かない確率（予定1.5%）**：ずれ0では振れ2%で 51%、5%で 54%。ずれ0.5ポイントでは 振れ0%で100%、2%で **89%**、5%で 72%
- 振れが大きいほど「届かない確率」は下がるが、届かないときの不足は大きくなる（95%点が大きくなる）
- 不足率の平均は、振れの大きさによらず、振れがないときの値とほぼ同じ（予定1.5%・ずれ0.5ポイントで 7.8%）
- 不足を積立額の上乗せで埋めるとすると、予定1.5%・ずれ0.5ポイント・振れなしで毎年の積立を **8.5%** 増やす計算になる

## 動かし方
```
pip install -r requirements.txt
cd src && python a527_rate_gap.py
```

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- 振れ0の不足率が、式（Σ(1+r)^k の比）で計算した値と一致すること（予定1.5%・ずれ0.5ポイントで 7.79%）
- 振れを入れたときの不足率の平均が、振れ0の値とほぼ一致すること（年ごとに独立なので、掛け算の期待値は期待値の掛け算になる）

## データ
- データファイルは置いていない。利回りはコードの中で乱数から作る（seed 527）

## 注意（言えないこと）
- 架空の積立。実際の保険商品・年金・実際の会社の数字ではない
- 利回りの見込みや、積立の仕方・商品の選び方を勧めるものではない。「このずれとこの振れなら、30年後にこれだけ足りない」を計算したもの
- 利回りは年ごとに独立な正規分布と置いた。実際には、低い年が続く・高い年が続くといったつながりがありうる
- 費用・税・途中の引き出し・積立額の変更は入れていない
