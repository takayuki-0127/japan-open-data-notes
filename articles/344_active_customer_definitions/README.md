# 344 「アクティブな顧客」は、定義でどれだけ人数が変わるのか（実務の型）

架空の顧客3万人・2年分の購買（約17万件）とログイン（約101万件）の記録から、「アクティブな顧客」を5つの定義で月末ごとに数え、人数の比と、前月比の向きの食い違いを数えたフォルダです。SQL は DuckDB で動かしました。T-SQL 版は `src/01_active_definitions_tsql.sql` に置きましたが、**SQL Server 本体では動かしていません（未検証）**。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A344 | 1つの指標の定義の違いだけで、人数と増減の向きはどれだけ変わるか | 5つの定義（過去30日に購入／過去90日に購入／その月に購入／過去30日にログイン／過去90日に2回以上購入）を22か月の月末で数える。出来事を2つ入れる（2024年10月：ログインだけ増える、2025年5月：セール） | `src/a344_active.py`、`src/01_active_definitions_tsql.sql` |

## 主な結果
- 2025年12月末：過去30日に購入 4,701人、その月に購入 4,778人、過去90日に2回以上購入 4,792人、過去90日に購入 7,296人、過去30日にログイン 9,016人
- いちばん多い定義÷いちばん少ない定義は、平均2.1倍（1.8〜2.4倍）
- **前月比の向きが定義で割れた月は、21か月のうち13か月**。過去30日に購入と向きが違った月：その月に購入 2、過去90日に購入 7、過去90日に2回以上購入 8、過去30日にログイン 9
- 前月比の揺れ（標準偏差）：過去30日に購入 10.6%、その月に購入 12.4%、過去90日に購入 2.6%、過去30日にログイン 2.7%、過去90日に2回以上購入 4.4%
- 2025年2月：過去30日に購入 −6.2%、その月に購入 −11.8%（月の日数の違い）
- 前年同月比では、10か月すべてで5つの向きがそろった
- 出来事の出方：ログインだけ増えた月は、ログインの定義で+10.3%、過去90日に購入で+0.6%。セールの月は、過去30日に購入 +26.3%・過去90日に購入 +7.6%、翌月は −21.4%・−0.8%

## 動かし方
```
pip install -r requirements.txt
cd src && python a344_active.py
```
乱数の種を固定してあるので、実行のたびに同じ `results/`・`figures/` を出します。

## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- SQL の人数は、pandas で別に数えた値と一致した（2025年2月末の2つの定義、コード内の assert）

## 注意（言えないこと）
- すべて架空のデータです。「2.1倍」「13か月」は、置いた買う頻度・やめる速さ・出来事で決まります
- 5つの定義は作成者が選んだものです
- 「向きが割れた」は、増減の大きさを問わずに数えました
- 前年同月比は10か月分だけです
- KPI をどう決めるかは F246 で扱いました。この記事は、1つの指標の定義の違いだけを数えています
- T-SQL 版は SQL Server 本体では動かしていません
