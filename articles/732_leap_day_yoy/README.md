# 732 うるう年の2月29日を含む月の前年同月比は、日数をそろえないとどれだけ高く見えるのか（実務の型）

うるう年の2月は29日あり、前年より1日多くなります。月の合計どうしで前年同月比を出すと、売上が伸びていなくても約3.6%（1÷28）高く見え、翌年の2月は逆に低く見えます。**ここでは、本当の伸びが毎日+2%と分かっている架空の店の3年分（2023〜2025年）の日次売上で、月ごとの前年同月比を「そのまま」「日あたり」「2月29日を除く」「曜日をそろえる」の4通りで出し、2024年2月・2025年2月と年の合計のずれを比べました。** DuckDB の SQL と Python で同じ値になることを確かめています。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A732 | 2月29日のある月の前年同月比は、どれだけずれるか | 架空の店の1,096日（2023-01-01〜2025-12-31）。本当の伸び +2.0%／年、曜日の波（月−10%〜土+18%）、ノイズ3%。前年同月比を4通りで。seed 732 | `src/a732_leap_yoy.py`、`src/02_leap_yoy_duckdb.sql`、`src/01_leap_yoy_tsql.sql`（T-SQL：未検証） |

## 主な結果（本当の伸びは +2.0%）
| 前年同月比の出し方 | 2024年2月（29日） | 2025年2月（28日） |
|---|---|---|
| そのまま（月の合計どうし） | **+5.16%** | **−0.48%** |
| 日あたり（合計÷日数） | +1.54% | +3.08% |
| 2月29日を除く | +1.67% | +2.94% |
| 曜日をそろえる（曜日ごとの1日平均の平均） | +1.81% | +2.80% |

- 日数をそろえないと、2024年2月は+5.2%と本当の倍以上に、2025年2月は −0.5% と減ったように見えた
- 日数をそろえる3通りは、どれも+1.5〜+3.1%で、本当の+2%に近づいた。残るずれは曜日の並び（2024年2月は木曜が1日多い）とノイズ
- 年の合計でも、2024年（366日）はそのまま+1.91%・日あたり+1.64%、2025年はそのまま+1.97%・日あたり+2.25%で、1日分の約0.3ポイントずれた
- 2月以外の月も、そのままの前年同月比は −0.05〜+3.62% と動いた。月の中の曜日の並び（土曜が5回ある月など）とノイズのため
