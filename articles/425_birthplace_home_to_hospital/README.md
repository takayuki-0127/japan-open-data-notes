# 425 赤ちゃんが生まれる場所は、自宅から病院へ、いつ入れ替わったのか（人口動態統計、1947〜2025年）

人口動態統計の「出生の場所別にみた出生数」（全国・市部・郡部）から、病院・診療所・助産所での出生と、自宅などでの出生の割合を並べたフォルダです。048（亡くなる場所）の出生版にあたります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A425 | 施設での出生が5割・9割を超えたのはいつか。市部と郡部でどれだけ違ったか | 場所別の割合を計算（公表の百分率と照合）。5年おきの数字を直線でつないで、5割・9割を超えた時期を出す。全国の上がりを市部・郡部の中の変化と、市部の出生が増えた分に分ける | `src/a425_birthplace.py` |

## 主な結果
- 自宅・その他での出生：1947年 97.6% → 1950年 95.4% → 1955年 82.4% → 1960年 49.9% → 1965年 16.0% → 1970年 3.9% → 1980年 0.5% → 2025年 0.1%（1,003人）
- 施設内（病院・診療所・助産所）が5割になったのは1960年（50.1%）。9割を超えたのは1965年と1970年のあいだ（直線でつなぐと1967〜68年ごろ）。5割から9割までは約7〜8年
- 市部は1960年に63.6%、郡部は27.0%で、差は36.6ポイント。郡部が5割を超えたのは1960年と1965年のあいだ（1962〜63年ごろ）、9割は1969〜70年ごろ。市部より5年ほど遅い
- 1950→1970年の上がり91.5ポイントのうち、市部・郡部それぞれの中の変化が88.0ポイント、市部での出生が増えた分が3.5ポイント
- 1950→1960年に、出生数は73万人減り、自宅での出生は143万人減り、施設での出生は70万人増えた
- 助産所での出生は1965年の12.9%（23.6万人）が山で、1990年からは1%以下。病院が5割を超えたのは1980年。2025年は病院54.6%、診療所44.8%、助産所0.4%

## 確かめたこと
- 自分で計算した割合は、公表の百分率（上巻 4-8）とすべての年・区分で一致（小数第1位）
- 空のフォルダで流し直し、results・figures が一致した

## 注意（言えないこと）
- 1947〜2010年は5年おきの数字しかありません。5割・9割を超えた年は、あいだを直線でつないだ目安です
- 1947年は「事件発生地」、1950年は「母の住所地」、1955年以降は「子の住所地」で数えています（表の注）。1947年は施設の内訳がありません
- 市部・郡部は、その年の時点の区分です。合併で市が増えると市部の範囲が広がるので、同じ地域を追った数字ではありません（423 を参照）
- 「自宅・その他」には、自宅のほか、病院などに向かう途中での出生なども入ります
- 場所が変わった理由（施設の数・制度・費用など）は分けていません。どこで産むのがよいかを言うものではありません
- 全国・市部・郡部の集計だけで、都道府県ごとの違いは見ていません
