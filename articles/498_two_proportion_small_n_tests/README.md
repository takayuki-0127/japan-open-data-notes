# 498 件数が少ないとき、2つの割合の差の検定は、効果が0でも何%で「差あり」と出るのか（手法の解説）

2つの群の割合の差を、4つの検定で調べたとき、本当は差がないのに「差あり」（両側5%）と出る確率と、本当の差を見つける確率を、起こりうる結果をすべて数え上げて正確に出したフォルダです。乱数は使っていません。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A498 | 件数が少ないとき、4つの検定の空振りと見つける力はどれだけ違うか | カイ二乗（補正なし＝2つの割合の z 検定）・イェーツの補正・フィッシャーの正確検定（両側、確率が小さい順）・mid-p。各群10〜200件、割合1〜99%、2群の全結果を二項分布の確率で重みづけして足す | `src/a498_two_proportion_tests.py` |

## 置いたこと（架空）
- 2つの群は独立で、件数は決まっている。空振りは2群とも同じ割合、見つける力は片方を+20ポイント
- 2群とも全部0か全部1のときは「差なし」

## 主な結果
- **各群20件**（割合1〜99%）：補正なし 最大5.34%（割合31%）・平均4.24%、イェーツ 最大2.15%・平均1.44%、フィッシャー 最大2.53%・平均1.87%、mid-p 最大4.64%・平均3.34%
- **各群50件**：補正なし 最大5.69%（50%）・68%の割合で5%超え、イェーツ＝フィッシャー 最大3.52%・平均2.55%、mid-p 最大5.69%・平均4.18%
- **割合5%**：各群20件で補正なし1.2%、フィッシャー0.2%
- **10%と30%を見つける割合**：20件で補正なし36%・イェーツ22%・フィッシャー24%・mid-p 34%。50件で73%・64%・64%・70%。100件で96%・93%・94%・95%
- **10件と100件**（割合5%）：補正なし5.5%、イェーツ1.8%、フィッシャー1.9%、mid-p 3.2%
