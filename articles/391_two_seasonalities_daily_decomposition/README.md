# 391 週の波と年の波が重なる日次データは、どう分ければ元の波に戻るのか

日ごとのデータには、曜日でくり返す「週の波」と、季節でくり返す「年の波」が重なっています。真の波が分かっている架空の日次データを作り、**4つの分け方で取り出した波が、真の波からどれだけずれるか**を測ったフォルダです。祝日が入ったときの崩れ方も確かめました。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A391 | 週の波と年の波は、STL（1つの周期）・MSTL（2つの周期）・回帰で、どこまで元に戻るか。データの年数と祝日でどう変わるか | 傾き＋週の波＋年の波＋日々の揺れ の日次データを作り、取り出した波と真の波の誤差を測る（4年分は60回、3・6・10年分は20回ずつ） | `src/a391_two_seasonalities.py` |

## データの作り方（架空）
- 水準は1,000。ゆるい上りの傾きに、ゆっくりした波を足す
- 週の波：月〜日で −60・−75・−70・−45・+20・+110・+120（週末が高い）
- 年の波：夏に高く冬に低いなだらかな波に、**年末の鋭い山（+160、幅は1〜2週間）とお盆の鋭い谷（−110、幅は1週間ほど）**を足す
- 日々の揺れ：標準偏差30
- 祝日（年16日前後。日付が決まった休み12日と、月曜に置いた休み4日）は、曜日の波の代わりに +150 になる

## 比べた方法
| 方法 | 中身 |
|---|---|
| STL（週だけ） | 周期7日で分ける。年の波は「傾き」の側に入る |
| STL（年だけ） | 周期365日で分ける。週の波は分けられない |
| MSTL（週と年） | 周期7日と365日を順に取り出す（statsmodels の初期設定） |
| MSTL（週の波の窓を101に） | 週の波をなめらかにする窓を、初期設定の11から101に広げる（週の波がゆっくりとしか変わらないと置く） |
| 回帰（三角関数3組／10組） | 曜日のダミー＋年の波（sin・cos を3組または10組）＋3次式の傾き |
| 回帰（10組＋祝日） | 上に、祝日のダミーを足す（祝日の日は曜日の波から外す） |

誤差は「取り出した波 − 真の波」の RMSE を、真の波の散らばり（標準偏差）で割った値（%）です。

## 主な結果
### 4年分・祝日なし（60回の平均）
| 方法 | 週の波の誤差 | 年の波の誤差 | 傾きの誤差（水準比） |
|---|---|---|---|
| STL（週だけ） | 17.4% | 分けられない | 6.5%（年の波が傾きに残る） |
| STL（年だけ） | 分けられない | 110.2% | 0.7% |
| MSTL（週と年） | 12.7% | 30.1% | 0.5% |
| MSTL（週の波の窓を101に） | 4.6% | 32.4% | 0.5% |
| 回帰（三角関数3組） | 2.3% | 40.6% | — |
| 回帰（三角関数10組） | 2.3% | 22.4% | — |

- **週の波は、曜日のダミーを入れた回帰で2%、MSTL の初期設定で13%**。MSTL は週の波が少しずつ変わることを許すので、日々の揺れを拾う。曜日ごとに平均すれば真の波とほぼ同じで、窓を101に広げると5%になる
- **年の波は、どの方法でも22〜41%の誤差が残る**。MSTL は鋭い山と谷を追えるが、4年分では日々の揺れも拾う。回帰は、三角関数3組では鋭い山と谷を表せず（41%）、10組で22%
- STL を1つの周期だけで使うと、もう片方の波が傾きか残りに入る。年だけの STL は、週の波と揺れを年の波として拾い、誤差は110%

### データの年数と、年の波の誤差
| 方法 | 3年 | 4年 | 6年 | 10年 |
|---|---|---|---|---|
| MSTL（週と年） | 35.3% | 30.1% | 25.1% | 19.8% |
| 回帰（三角関数10組） | 22.8% | 22.4% | 22.8% | 21.9% |

- MSTL は年数が増えるほどよくなり、10年分で回帰（10組）を下回る。回帰の誤差は、式で表せない鋭い山と谷の分なので、年数を増やしても減らない

### 祝日が入ったとき（4年分。祝日でない日で比べる）
| 方法 | 週の波の誤差（祝日なし→あり） | 年の波の誤差（祝日なし→あり） |
|---|---|---|
| MSTL（週と年） | 12.7% → 18.1% | 30.1% → 36.2% |
| MSTL（週の波の窓を101に） | 4.6% → 9.4% | 32.4% → 37.5% |
| 回帰（三角関数10組） | 2.3% → 8.0% | 22.4% → 24.3% |
| 回帰（10組＋祝日） | 2.5% | 20.9% |

- **祝日が入ると、週の波の誤差は MSTL で13%→18%、回帰で2%→8%**。祝日を式に入れると2.5%に戻る
- MSTL では、祝日の上乗せの約8割（4年分で78%、3〜10年分で78〜94%）が年の波に入った。日付が決まった休みは「毎年その日に高い」として年の波になり、月曜に置いた休みは日付が動くので残りに散る

全部の数字は `results/error_table.csv`・`results/errors_by_run.csv` にあります。

## 確かめたこと
- 空のフォルダで計算し直し、data・results・figures が一致した
- MSTL の週の波は、曜日ごとに平均すると、真の波との差が3以内（例の1本。真の波は−75〜+120）
- 回帰の週の波の誤差は、年数が増えるほど小さい（3年2.8%→10年1.3%）

## 注意（言えないこと）
- すべて架空のデータです。誤差は、波の形・揺れの大きさ・年数の置き方で決まります。とくに年の波の誤差は、鋭い山と谷を入れたことで大きく出ています
- 波は足し算で重なり、年によって形が変わらないと置いています。水準に比例して波が大きくなるデータ（掛け算の波）や、年々形が変わる波では、結果が変わります
- MSTL は statsmodels の実装で、初期設定と、週の波の窓を101にした設定だけを試しました。ほかの設定や、ほかの方法（TBATS、Prophet など）は試していません
- 祝日は、日付が決まった休みと月曜に置いた休みだけで、連休の前後の動きは入れていません
- 季節調整そのものは、記事 F42・F150 で扱っています
