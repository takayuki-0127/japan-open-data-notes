# 711 月の売上を「30」で割るか、その月の日数や営業日数で割るかで、日あたりの前月比はどれだけ違うのか（実務の型・月次の集計）

月の売上を日あたりにして前月と比べるとき、割る日数を「30」に決めてしまうと、31日の月は高く、2月は低く出ます。暦の日数で割っても、休業日の数が月で違えば同じことが起きます。**ここでは、架空の店の日次売上2年分（毎週水曜と年末年始は休業、1営業日あたりの水準は一定）で、30・暦の日数・営業日数で割った日あたりの前月比を比べました。** 本当の変化は0なので、出てきた前月比はすべて割り方による見かけの動きです。曜日の波と休業日は作成者が置いたもので、数字はその置き方で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A711 | 割る日数の決め方で、日あたりの前月比はどれだけ振れるか | 30で割る、暦の日数（last_day）で割る、営業日数（売上のある日の数）で割る。DuckDB（1スレッド）と pandas で一致を確認。seed 711 | `src/a711_daily_avg.py`、`src/02_daily_duckdb.sql`、`src/01_daily_tsql.sql`（未検証） |

## 主な結果
- **前月比の振れ（標準偏差）**：30で割る5.9ポイント、暦の日数で割る6.1ポイント、**営業日数で割る2.9ポイント**
- **3月の前月比**：2024年は30で割ると+10.1%（暦の日数+3.0%、営業日数+2.0%）。2025年は+10.4%（−0.3%、−1.9%）
- **暦の日数でも残る**：水曜の数が月で4回か5回か違うので、営業日数は月に24〜27日。暦の日数で割ると、2025年5月は+7.2%と出た
- **営業日数で割っても残る分**：土日の数の違い（曜日の並び）で、最大±7.1%の見かけの前月比が出た
- **年末年始**：2025年1月の前月比は、30・暦の日数で割ると−5.8%、営業日数で割ると+2.1%

## 動かし方
```
pip install -r requirements.txt
cd src && python a711_daily_avg.py
```
数秒で終わります。`data/daily.csv` に日次売上（営業日だけ）を書き出します。

- DuckDB の3つの日あたりの値が、pandas の結果と一致した

## データ
- `data/daily.csv`：sale_date・sales（営業日だけ）
- 仮定：曜日の倍率は月火0.9・木0.95・金1.1・土1.35・日1.25（水曜は休業）。日々のゆれ8%。12/31〜1/3 は休業

## 注意（言えないこと）
- 架空のデータ。見かけの前月比の大きさは、曜日の波と休業日の置き方で決まる
- 営業日数で割っても曜日の並びの分は残る。消すには、前年の同じ曜日と比べる、曜日の構成で調整する、などが要る
- 実在の店の数字ではない
