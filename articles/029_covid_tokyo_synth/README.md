### SSDSE（教育用標準データセット）で、1テーマずつ分析する

- **何を**：統計センターの SSDSE（都道府県・市区町村ごとの主な公的統計を1つの表にまとめたデータ）で、毎回ちがう手法を使って1つの問いを調べる
- **どう**：特化係数と階層クラスタリング（家計消費）、二方向固定効果モデル（都道府県×年のパネル）、年齢構成との相関と残差（社会生活）、コロナ前後の比較と集中度（宿泊）、合成コントロール法（コロナと東京の転入）、時間配分の重回帰（通勤と睡眠）、コレスポンデンス分析（お酒）、スケーリング則（市区町村の人口と施設）、σ収束・β収束（進学率）
- **結果**：食料の買い方は地域ごとにまとまる（関西・首都圏と東海・東日本・中四国・北陸・九州・那覇）。保育所の定員と出生率は、県どうしで比べるとプラスだが、県の違いと年の流れを取り除くと0と区別できない。スマホ・ゲーム機のゲームや音楽鑑賞をする人の割合は、県の高齢化と相関 −0.8 前後

#### 注意
- S2：SSDSE-B の保育所等定員は2023年に前年から水準が大きく下がっている（全国平均で15歳未満100人あたり22.8→16.6）。定義の変更の可能性があるので、2012〜2022年だけを使った
- S3：社会生活基本調査は2021年（コロナ禍）の調査。65歳以上の割合は2024年で、年がずれている
- どれも都道府県（または県庁所在市）単位の関係で、個人には当てはめられない。因果も言えない
- S6：比較の候補から埼玉・千葉・神奈川を除いた（東京から移った人の受け皿で、コロナの影響を受けている）。前の期間は8年と短く、当てはまりがほぼ完全になる県が多いので、プラセボの順位は後の期間のずれの大きさで比べた
- S8：家計調査は二人以上の世帯で、県庁所在市・政令市の支出。都市の中の割合で比べている
- S9：0の市区町村は対数がとれないので除いた（情報通信業は334、図書館は390市区町村が0）。そのぶん傾きは偏る可能性がある
