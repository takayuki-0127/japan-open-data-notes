# 261 データ辞書（列の説明書）は、何を書くと役に立つのか（実務の型）

統計センター「SSDSE-県別推移（SSDSE-B）」2026年版（47都道府県×12年度×109項目）の CSV だけでは答えられない「この列は何か」の問いを、項目一覧と解説 PDF から1つのデータ辞書にまとめ、問いの種類ごとに何項目が辞書で初めて分かるかを数えたフォルダです。値から確かめられることは値で確かめました。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A261 | CSV だけでは分からないことが、辞書でいくつ分かるか | 項目一覧（単位）＋解説の別表（出典・地域の範囲・注意）＋値から作る列（値の型・最小最大・負の値・千の倍数にそろう年度） | `src/a261_dictionary.py` |

## 主な結果
- 単位：CSV には単位の行がなく、109項目すべてが辞書で初めて分かる。単位は20種類（人58項目、1か月あたりの円11項目、校7項目 など）。出典は17の統計
- 単位のほかに、37項目に1つ以上（合わせて48）の問いがあった
  - 県全体か県庁所在市か：16項目（気象5・家計11。CSV の見出しは「都道府県」）
  - 年によって出典が変わるか：15項目（人口。国勢調査の年とそれ以外）
  - 1か月分か1年分か：11項目（家計。二人以上の世帯の1か月あたりの支出の年平均）
  - 率・割合で足し合わせられないか：3項目
  - 項目名が項目一覧と違う：3項目（E3702・E4602・G7102）
- 値で確かめると、人口の15項目は2015・2020年度だけ千の倍数にそろわず、ほかの10年度は47都道府県すべてが千の倍数だった。辞書に写した「国勢調査の年とそれ以外で出典が違う」と一致した

## 動かし方
```
pip install -r requirements.txt
cd src && python a261_dictionary.py
```

## データ
- `data/SSDSE-B-2026.csv`：統計センターの配布ファイルをそのまま（cp932）
- `data/SSDSE_ITEM_2025.xlsx`：SSDSE 項目一覧（単位つきの項目名）
- `results/data_dictionary_ssdse_b_2026.csv`：作ったデータ辞書（109行、UTF-8 BOM つき）
- `results/summary.json`：問いの種類ごとの項目数、単位の内訳など

## 注意
- 出典の対応（`src/a261_dictionary.py` の `SOURCE_BY_PREFIX`）は、解説 PDF（kaisetsu-B-2026.pdf）4〜6ページの別表を手で写したもの。詳しい定義は「社会・人口統計体系」の項目定義で確かめる必要がある
- 問いの種類は作成者が決めた。時点（年度か暦年か、何月何日現在か）は、資料から項目ごとには読み取れなかったので数えていない
- 単位は2025年版の項目一覧から取った（2026年版で収録項目の変更はないと解説に書かれている）
