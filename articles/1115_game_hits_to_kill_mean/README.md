# 1115 平均のダメージで敵の体力を割って「何回で倒せるか」を出すと、実際の回数とどれだけずれるのか？（ゲームの数値設計）

ゲームの数値を決めるとき、「敵の体力10,000、1回の平均のダメージ1,100だから、約9回で倒せる」と見込むことがあります。けれども、実際には敵の体力を超えたところで倒れるので、最後の1回のダメージは体力からあふれて無駄になります。そのため、倒すまでの回数の平均は「体力÷平均」より多くなります。ダメージの振れが大きいほど、また敵の体力が1回のダメージに比べて小さいほど、見込みとのずれの割合は変わります。**ここでは、作成者が置いた架空のゲームの数値（攻撃力1,000・会心率20%・会心の倍率1.5倍で1回の平均1,100、敵の体力10,000）で、「体力÷平均」の見込みと、20万回倒したときの実際の回数（平均・真ん中・分布）、最後の1回であふれたダメージ、同じ敵を10体続けて倒したときの合計の回数を比べました。1回の平均を1,100にそろえたまま振れ方を変えた4通り×敵の体力5通りの20通りの確かめも行いました。**

例のゲームと数値は作成者が置いた架空のもので、実在のゲームの数値や計算の決まりを表すものではありません。

関連する記事：1030「「平均の所要時間」で計画すると、何回に1回遅れるのか？」は、平均どおりに予定を立てると平均より遅い日はすべて遅れることを扱っています。この記事は、平均で割った回数の見込みが、最後の1回のあふれのぶん必ず少なめになることを、ゲームの数値で数えます。989「平均で考えると、どのくじが得に見えるのか？」は、平均だけを見ると、多くの人が実際に受け取る量とずれることを扱っています。同じ企画の 1113「攻撃力を10%上げるのと会心率を10ポイント上げるのでは、与えるダメージはどちらが伸びるのか？」は、この記事と同じ置き方（攻撃力1,000・会心率20%・1.5倍）で、1回あたりの平均の伸びを比べています。1114「強化の倍率を足し合わせる決まりと掛け合わせる決まりでは、重ねたときの強さはどれだけ違うのか？」は、強化を重ねたときの強さを扱っています。1116「平均のダメージがいちばん大きい武器は、決まった回数のうちに倒せる割合もいちばん高いのか？」は、武器どうしを比べたときに、平均の順と決まった回数で倒せる割合の順が食い違うことを扱っています。1121「敵の体力を1割増やすと、倒すのに要る回数はなぜ1割より大きく跳ねることがあるのか？」は、体力の小さな変化で回数が切り上げの段をまたいで跳ねることを扱っています。この記事は、1つの攻撃の置き方で、回数の平均が「体力÷平均」より多くなるずれに絞ります。

## 主な結果

### 基本の置き方（体力10,000・1回の平均1,100、20万回、`results/a1115_main.json` の base）
| | 値 |
|---|---|
| 見込み（体力÷平均） | 9.0909回 |
| 実際の回数の平均 | **9.607回** |
| 実際−見込み | **+0.5161回（+5.68%）** |
| 実際の回数の真ん中 | 10回 |
| 10%の位置〜90%の位置 | 9〜10回 |
| いちばん少ない・多い | 7回・11回 |
| 9回以内（見込みの切り捨て）に倒せた割合 | **41.27%** |
| 10回以内（見込みの切り上げ）に倒せた割合 | 94.57% |
| 11回かかった割合 | 5.43% |
| 最後の1回であふれたダメージの平均 | 570.06（1回の平均の0.5182回分） |

| 倒すまでの回数 | 7回 | 8回 | 9回 | 10回 | 11回 |
|---|---|---|---|---|---|
| 割合（`results/base_hits_dist.csv`） | 0.02% | 3.41% | 37.84% | 53.3% | 5.43% |

- **「体力÷平均」の見込みは9.0909回だったが、実際の平均は9.607回で、0.5161回多かった**。「約9回で倒せる」と読むと、9回以内に倒せたのは41.27%だけだった
- ずれは、最後の1回のあふれでほぼ説明できた。あふれの平均は570.06で、1回の平均の0.5182回分。回数の平均×1回の平均（10,567.7）は、体力＋あふれの平均（10,570.1）とよく合った
- 見込みを切り上げた10回でも、5.43%は11回かかった

### 10体続けて倒す（2万組、`results/a1115_main.json` の series10）
| | 値 |
|---|---|
| 見込み（合計の体力100,000÷平均） | 90.9091回 |
| 実際の合計の回数の平均 | **96.0784回** |
| 実際−見込み | +5.1693回 |
| 10%の位置〜90%の位置 | 93〜99回 |
| 91回以内に倒せた割合 | **1.16%** |
| 100回以内に倒せた割合 | 98.76% |

- 1体ごとにあふれが捨てられるので、ずれは体の数だけ積み重なった。10体では5.1693回多く、合計の体力で割った見込み（90.9091回）を切り上げた91回以内に10体を倒せたのは1.16%だった
- 1体ごとの見込みを切り上げて足した100回（10回×10体）以内には、98.76%が倒せた

### 確かめ：振れ方と敵の体力を変えると（20通り、各5万回、`results/grid.csv`）
| 振れ方 | 体力2,000（見込み1.8182回） | 5,000（4.5455回） | 10,000（9.0909回） | 20,000（18.1818回） | 50,000（45.4545回） |
|---|---|---|---|---|---|
| 振れ±10%だけ（会心なし） | +0.1861回 | +0.4545回 | +0.6038回 | +0.5895回 | +0.5055回 |
| 基本（会心20%・1.5倍） | +0.503回 | +0.5164回 | +0.5174回 | +0.5149回 | +0.5265回 |
| 会心10%・3倍 | **+0.8862回** | +0.664回 | +0.5727回 | +0.5899回 | +0.6381回 |
| 会心50%・2倍 | +0.4323回 | +0.4687回 | +0.5292回 | +0.5687回 | +0.5567回 |

（表の値は実際の回数の平均−見込み）

- **20通りすべてで、実際の回数の平均は見込みより多かった**。ずれは0.1861〜0.8862回で、割合にすると1.11〜48.74%だった
- ずれの回数は、体力が大きくなっても小さくならなかった。体力5,000以上の16通りでは+0.4545〜+0.664回だった。割合で見ると、体力が小さい（見込みが少ない）ほど大きかった（会心10%・3倍の体力2,000で+48.74%）
- 振れ±10%だけでは、ずれは体力が1回のダメージのちょうど何倍の近くにあるかで大きく動いた（体力2,000で+0.1861回、10,000で+0.6038回）。基本の振れ方では、どの体力でも+0.503〜+0.5265回にそろった
- 見込みを切り上げた回数以内に倒せた割合は、振れ方と体力で19.42〜100%と動いた（図3、`results/grid.csv` の within_ceil_estimate_pct）。会心10%・3倍は、5つの体力すべてで4通りの中でいちばん低かった

## 注意（言えないこと）
- 架空の数値です。攻撃力・会心率・会心の倍率・振れの幅・敵の体力は作成者が置いたもので、ずれの大きさはこれで決まります。ずれの向き（実際が多くなる）は、最後の1回であふれる作りから来るもので、20通りすべてで同じでした
- 敵の防御・回復、命中しない回、あふれたダメージを次の敵に持ちこす作りは入れていません。あふれを持ちこす作りなら、10体続けたときのずれは小さくなります（推測、数えていません）
- 体力が1回のダメージのちょうど何倍の近くにあるかで回数が跳ねること自体は、この記事では扱っていません（1121 で扱っています）
- 実在のゲームの敵の強さを言うものではありません
