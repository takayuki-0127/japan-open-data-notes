# 998 アンケートで聞いた「初めて来た人の割合」は合うのか？（来場者と集客）

施設の中で来場した人に「今日、初めて来ましたか」と聞き、「初めて」と答えた割合を「初めて来た人の割合」と呼ぶことがあります。ところが、館の中で聞くと、よく来る人ほど何度も聞かれる側に立っています。聞いた答えが表すのは「来場（延べ）のうち初めての来場の割合」で、「1年に来た人（実人数）のうち初めて来た人の割合」とは別のものです。**ここでは、作成者が乱数で作った架空の体験型の展示館「C館」の1年（来た人ごとの来場回数と、初めて来た人かどうかを作成者が置いたもの）で、館の中で12日行うアンケートの答えを、この2つの本当の割合と比べました。答えやすさの違い、「初めて」の答え違い、聞く日を土日に寄せること、1年の来場回数で重みを付ける読み方も数えました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A998 | 館の中のアンケートで聞いた「初めて」の割合は、延べの来場のうち初めての来場の割合と、実人数のうち初めて来た人の割合の、どちらにどれだけ合うか | 架空の展示館の1年364日。1年に来た人は20,000人で、3つの組に分けた：1回だけ（65%、1年に1回）・ときどき（25%、2〜5回）・常連（10%、6〜40回。回数は組の中で一様）。この館に初めて来た人の割合は、1回だけ70%・ときどき40%・常連10%。来る日は、1回だけ・ときどきの人は土日に平日の3倍来やすく、常連は曜日によらない（同じ人が同じ日に2回来ることも許した）。初めて来た人の、1年でいちばん早い来場を「初めての来場」とする。アンケートは、364日からでたらめに選んだ12日（または土日だけから選んだ12日）に、来場した人の2人に1人に聞く。答えてくれる確率は、初めての来場で50%、それ以外で35%。問1「今日、初めて来ましたか」：前の年までに来たことがある人も、今年の最初の来場では20%の確率で「初めて」と答える（答え違い）。問2「去年までに、この館に来たことがありますか」：来たことがある人も20%の確率で「ない」と答える。問2には「1年に何回くらい来ますか」の答え（本当の回数に対数の標準偏差0.3のずれを掛けて丸めたもの）の逆数で重みを付けた。1年を作り直して200回。確かめとして、常連の割合（5・10・20%）×答えやすさ（初めてが答えやすい50%対35%・同じ40%・初めてが答えにくい35%対50%）×答え違い（0・20・40%）の27通りを各50回。seed 998 | `src/a998_first_time_share.py` |

## 主な結果

### アンケートの答えと、本当の2つの割合（200回の平均、`results/a998_main.json`）
| | 「初めて」の割合 | 1年分の10〜90% |
|---|---|---|
| 本当：1年に来た人（実人数）のうち初めて来た人 | **56.51%** | |
| 本当：来場（延べ）のうち初めての来場 | 14.76% | |
| 問1：聞いた全員が答え、答え違いもないとき | 14.85% | |
| 問1：＋答えやすさの違い | 20.05% | |
| 問1：＋答え違い（基本） | **22.28%** | 18.37〜26.15% |
| 問1：土日だけの12日で聞く（基本の置き方） | 29.67% | 26.31〜32.49% |
| 問2に回数の逆数で重み：全員が答え、答え違いもなく、本当の回数のとき | 56.42% | 53.04〜59.7% |
| 問2に、答えた回数の逆数で重み（基本） | 70.37% | 66.38〜74.22% |

- **館の中で「今日、初めて来ましたか」と聞くと、「初めて」と答えたのは22.28%だった。1年に来た人のうち初めて来た人は56.51%で、アンケートはその半分にも届かなかった**
- 聞いた全員が答え、答え違いもないときのアンケート（14.85%）は、延べの来場のうち初めての来場の割合（14.76%）に合った。館の中で来場をでたらめに選んで聞くので、延べの来場の割合になるのは式どおり
- 延べと実人数が離れるのは、常連が何度も来るため。例の1年では、常連は実人数の9.91%だったが、延べの来場の60.04%を占めた（`results/example_people_vs_visits.csv`）。アンケートに答えた人のうち常連は、平均56.95%だった
- 答えやすさの違い（初めての来場で50%、それ以外で35%）で20.05%に、答え違い（前に来たことのある人の20%が今年の最初の来場で「初めて」と答える）を足すと22.28%に上がった。どちらも延べの来場の割合から離れる向きで、実人数の割合には届かなかった
- 土日だけの12日で聞くと29.67%だった。土日には1回だけ・ときどきの人が多く来るため、答えた人のうち常連は40.44%に下がった
- 実人数の割合を見たいなら、聞き方を変える必要があった。「去年までに来たことがありますか」（問2）に、1年の来場回数の逆数で重みを付けると、全員が答えて答え違いもなく本当の回数を使うときは56.42%で、実人数の割合（56.51%）に合った（重みの付け方の確かめ）。ただし、基本の答えやすさと答え違いを入れると70.37%と、今度は大きく出た。重みは、来場回数による選ばれやすさは直すが、答えやすさと答え違いは直さない
- 聞いたのは1年の平均1,263.71件で、答えたのは472.17件だった

### 例の1年（`data/survey_example.csv`）
- 本当の割合は、実人数のうち初めて来た人57.45%、延べの来場のうち初めての来場14.92%。アンケートの問1は22.03%、問2の重み付きは71.11%だった

### 確かめ：置き方を変えると（27通り、各50回、`results/grid_regular_response_misreport.csv`）
| 常連の割合 | 本当：実人数 | 本当：延べの来場 | 問1のアンケート（答えやすさ×答え違いの9通り） |
|---|---|---|---|
| 5% | 58.88〜59.01% | 20.84〜21.02% | 15.91〜32.34% |
| 10%（基本） | 56.38〜56.52% | 14.69〜14.78% | 10.9〜24.43% |
| 20% | 52.17〜52.32% | 9.34〜9.41% | 6.6〜15.48% |

- **27通りのすべてで、問1のアンケートは実人数のうち初めて来た人の割合より低く、差は26.63〜45.66ポイントだった**。常連が多いほど、差は広がった
- 問1のアンケートと延べの来場の割合の差は、−5.04〜+11.34ポイントだった。初めての人が答えやすいと上に、答えにくいと下にずれ、答え違いが多いと上にずれた。答えやすさが同じで答え違いがないときは−0.43〜+0.28ポイントで、延べの来場の割合に合った
- 土日だけの12日で聞くと、でたらめな12日より3.97〜8.14ポイント高かった（27通りのすべてで高い）
- 問2の重み付きと実人数の割合の差は、−8.44〜+22.79ポイントと、答えやすさと答え違いで上にも下にも動いた。答えやすさが同じで答え違いがないときは−1.67〜−1.02ポイントで、少し低く出た。「1年に何回くらい」の答えのずれで、回数の逆数が平均では大きめになるため（推測）。本当の回数を使い、全員が答えて答え違いもないときの差は−0.65〜+0.39ポイントだった

## 注意（言えないこと）
- 架空のデータです。組の割合、来場回数、初めて来た人の割合、答えやすさ、答え違いの起きやすさは作成者が置いたもので、アンケートと本当の割合の差はこれで決まります。表のとおり、差は置き方で26.63〜45.66ポイント動きます
- 置き方によらず言えるのは、館の中で来場をでたらめに選んで聞く限り、アンケートが表すのは延べの来場の割合だということです（式どおり）。実人数の割合とどれだけ離れるかは、よく来る人がどれだけ多いかで決まります
- 答えやすさや答え違いの大きさは、作成者が置いた例です。実際の値は、この記事では分かりません。問2の重み付きが大きく出たのは、置いた答えやすさと答え違いのためです
- 1年の中で、初めて来た人が2回目以降に来る時期の偏り（初めての来場が年の前のほうに多い、など）は入れていません。同じ人が同じ日に2回来ることも許しました
- 「初めて」を、今年初めて・この催しで初めて、と受け取る答え方は、答え違いの確率でまとめて置きました
- 実在の施設の来場者・アンケートの数字ではありません
- 関連する記事：865（回答が少ない層の割合は何件あれば読めるか）と870（謝礼を付けると回答者の構成はどう変わるか）は、答える人の偏りをアンケートで扱っています。979（欠けやすい人に重みを付けると、どこまで戻せるか）は、重みで戻せるものと戻せないものを扱っています。同じ企画の 993 は、延べと実人数がどれだけ違うかを扱っています。この記事は、来場を選んで聞くことで、よく来る人が多く聞かれることに絞りました
