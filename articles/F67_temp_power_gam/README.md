# F67 気温が1℃上がると、電気の使用量は何%増えるか？（一般化加法モデル・スプライン回帰）

note の看板記事 F67 のコード・データ・図です。

## 問い

東京エリアの1日の電力需要は、気温が1℃変わると何%変わるのか。その効き方は気温によってどう違い、暑い側と寒い側で非対称なのか。10年でどう変わったか。

## データ

| データ | 期間 | 出どころ |
|---|---|---|
| 東京エリアの1時間ごとの需要 | 2016年4月〜2026年9月 | 東京電力パワーグリッド「エリア需給実績」 |
| 関西エリアの1時間ごとの需要 | 2024年4月〜2026年9月 | 関西電力送配電「エリア需給実績」 |
| 東京・大阪の日ごとの気温・湿度 | 同上 | 気象庁「過去の気象データ」 |

- 新しくは取得していません。F22（[articles/F22_power_demand_forecast](../F22_power_demand_forecast)）で整えた表（`data/raw/hourly_tokyo.csv`・`hourly_kansai.csv`）をそのまま使っています。
- 1時間ごとの需要を日ごとの合計（GWh）にしました（東京 3,834日、関西 912日）。

## 手法

- **本体**：log(1日の需要) を、日平均気温の3次スプライン（自由度8、patsy の `cr`）と、曜日・祝日・お盆（8/10〜20）・年末年始（12/28〜1/4）・GW・コロナ期（2020年4月〜2021年9月）・年度のダミーで回帰しました。標準誤差は HAC（7日）です。
- **1℃あたりの変化率**：当てはめた曲線を気温で微分し、100倍しました（デルタ法で95%区間）。「暑い日（日平均26℃以上）」「寒い日（8℃以下）」は、それぞれの日の実際の気温での値を平均しています。
- **GAM**：pyGAM の `LinearGAM`（平滑化の強さは交差検証で自動選択）でも同じ曲線を推定し、比べました。
- **気温の入れ方の比較**：年度ごとに1年度を抜いて当てる交差検証で、直線・2次式・冷暖房度日（18℃で折れる直線）・スプライン・GAM を比べました。
- **時刻別**：1時間ごとの需要で、時刻ごとに同じモデルを当てはめました。
- **需要がいちばん少ない気温**：係数の推定分布から1,000回引いて区間を出しました。

## 主な結果

- **需要がいちばん少ないのは日平均18.0℃**（95%区間 17.6〜18.4℃）でした。
- **暑い日は1℃上がるごとに +4.5%、寒い日は1℃下がるごとに +2.8%**（どちらも、その日の実際の気温での平均）。暑さは寒さの約1.6倍効いていました。
  - 気温ごとに見ると、5℃で −2.7%、10℃で −3.2%、25℃で +4.2%、28℃で +4.7%、30℃で +4.3% です（30℃前後は日数が少なく区間が広い）。
- **曲げ方が大事**：交差検証の誤差（log の RMSE）は、直線 0.128、2次式 0.046、冷暖房度日 0.045、スプライン 0.040、GAM 0.040 でした。
- **10年の変化**：18℃前後の需要の水準は、2016〜19年度の 714GWh から 2023〜26年度は 657GWh に 7.9% 下がりました。一方、28℃の日の水準は 920GWh → 897GWh（−2.5%）で、あまり下がっていません。28℃の日の需要は、18℃の日の 1.29倍から 1.37倍になりました。
- **時刻別**：30℃の日に1℃上がったときの増え方は、昼（12〜16時）が約 5.0%、明け方（4時）が 2.6% でした。5℃の日に1℃下がったときの増え方は、1.9〜3.1% で、昼夜の差は小さめです。
- **関西**（2024年4月〜）：いちばん少ない気温は 18.3℃、暑い日 +4.1%、寒い日 +3.2% で、暑さと寒さの差は東京（同じ期間で 4.6% と 3.0%）より小さめでした。

## 頑健性

東京の暑い日・寒い日の変化率（%／℃）と、その比です。

| 設定 | 暑い日 | 寒い日 | 比 |
|---|---|---|---|
| 本体 | +4.52 | −2.77 | 1.63 |
| 2016〜2019年度だけ | +4.37 | −2.69 | 1.63 |
| 2020〜2022年度だけ | +4.42 | −2.82 | 1.57 |
| 2023〜2026年度だけ | +4.50 | −2.96 | 1.52 |
| 最高気温で見る | +3.33 | −2.07 | 1.61 |
| スプラインの自由度 5／12 | +4.69／+4.52 | −2.80／−2.81 | 1.68／1.61 |
| 湿度を加える | +4.64 | −2.82 | 1.64 |
| 前日の気温も加える | +3.43 | −2.27 | 1.51 |
| 月の違いも除く | +4.34 | −2.52 | 1.72 |
| 平日だけ | +4.40 | −2.65 | 1.66 |
| コロナ期を除く | +4.50 | −2.79 | 1.61 |

- 「前日の気温も加える」では当日の気温の効果が小さくなります。前日の暑さ・寒さも需要に効いている（その分が前日の項に移る）ためです。
- 東京では、どの設定でも暑さは寒さの 1.5〜1.7倍効いていました。

## 言えないこと

- 気温と需要の関係は、因果の大きさそのものではありません。暑い日は日射が強い、休みの人が多いなど、気温と一緒に動く要因も含みます。
- 日ごとの気温を使っているので、1日の中の気温の動き（夕方の暑さなど）は区別できません。
- 30℃を超える日は少なく、その範囲の傾きの区間は広くなります。
- 需要には、自家発電や太陽光の自家消費は含まれません。屋根の太陽光が増えた分は、晴れた暑い日ほど需要を小さく見せている可能性があります（推測です）。
- 関西は2年半分しかなく、東京との比較は同じ期間だけです。
