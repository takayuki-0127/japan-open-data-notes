# 750 交互作用を入れた回帰で、変数を中心化しないと、主効果の係数はどう読めてしまうのか（手法の解説・正解の分かるデータで試す）

`y ~ z + x + z×x` のように交互作用を入れると、z の係数（主効果）は「x＝0 のときの z の効果」になります。x が店の広さのように0から遠い値しかとらない変数だと、z の係数はデータのない所での効果になり、施策の効果とは別の数になります。x から平均を引いて（中心化して）から入れると、z の係数は「x が平均の店での効果」になります。**ここでは、広さが平均の店での施策の効果を5に固定した架空の400店で、中心化する・しないで z の係数と有意を比べました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A750 | 中心化しないと、主効果の係数はどう変わるか | 400店。施策 z は無作為に半分、広さ x は平均 μ・標準偏差20。y＝5z＋0.1(x−μ)＋γz(x−μ)＋誤差（sd 15）。最小二乗で y ~ z＋x＋z×x（x そのまま／中心化）。γ＝0.2 で μ＝0〜200、μ＝100 で γ＝0〜0.3。各1,000回。seed 750 | `src/a750_centering.py` |

## 主な結果

| 広さの平均 μ（γ＝0.2） | 中心化しない z の係数 | 中心化した z の係数 |
|---|---|---|
| 0 | 5.0 | 5.0 |
| 50 | −5.0 | 4.9 |
| 100 | **−14.9** | **5.0** |
| 200 | −35.3 | 4.9 |

| 交互作用 γ（μ＝100） | 中心化しない：有意にマイナス | 中心化しない：有意にプラス | 中心化する：有意にプラス |
|---|---|---|---|
| 0 | 0.3% | 9.0% | 93.0% |
| 0.1 | 9.2% | 0.6% | 91.7% |
| 0.2 | **47.4%** | 0.0% | 91.7% |
| 0.3 | 89.9% | 0.0% | 90.8% |

- 広さの平均が100の店で、施策の効果は+5なのに、中心化しない z の係数は平均−14.9（＝5−0.2×100）になった。47%の回で「有意にマイナス」だった
- 中心化すると、z の係数はどの条件でも5前後で、91〜93%の回で有意にプラスだった
- 交互作用の係数（0.199）と予測値は、中心化してもしなくても同じ。変わるのは主効果の意味だけ

## 注意（言えないこと）
- 架空のデータです。効果・交互作用・ばらつきは作成者が置いたもので、係数や有意の割合はこれで決まります
- 中心化に使う値は平均でなくてもよく、「基準にしたい広さ」を引けば、z の係数はその広さでの効果になります
- 交互作用があるとき、「施策の効果」は広さごとに違います。1つの数で言うときは、どの広さでの効果かを添える必要があります
