# 235 大学・大学院に入る社会人は、どれだけいるのか

文部科学省「学校基本調査」の各年度の「大学院 年齢別入学者数」（2000〜2025年度）と「大学 年齢別入学者数」（2015〜2025年度）を並べたフォルダです。大学院の表には入学者のうち「社会人」の数が載っています。学部の表には社会人の数がないので、25歳以上・30歳以上の入学者の数で近づけました。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A235 | 大学・大学院に入る社会人は、どれだけいるのか。増えているのはどの課程か | 課程別（修士・博士・専門職学位）の社会人入学者の数と、入学者に占める割合の推移（2000〜2025年度）／学部の25歳以上・30歳以上の入学者の推移（2015〜2025年度） | `src/a235_adult_learners.py` |

## 主な結果
- 2025年度の大学院の社会人入学者は18,097人で、入学者105,991人の17.1%。割合が最も高かったのは2018年度の18.7%で、2004年度（15.8%）からはほぼ横ばい
- 課程で大きく違う。2025年度の社会人の割合は、修士課程8.8%（7,075人）、博士課程39.8%（6,450人）、専門職学位課程49.0%（4,572人）
- 修士課程の社会人は2007年度の8,470人が最多で、割合は2001年度の11.5%から2025年度の8.8%に下がった。修士では入学者が増えた（70,336→80,452人）のに社会人は増えていない
- 博士課程の社会人の割合は2003年度の21.7%から2020年度に43.2%まで上がった。社会人は3,952人から6,450人に増え、社会人以外の入学者は14,280人から9,762人に減った。割合の上がり分18.1ポイントを2つに分けると、社会人が増えた分が約10.2ポイント、社会人以外が減った分が約7.9ポイント（2つの順番で計算した平均）
- 学部の25歳以上の入学者は、2015年度の3,999人（入学者の0.65%）から2022年度の2,162人（0.34%）まで減り、2025年度は2,814人（0.44%）。30歳以上は1,335人から772人に減った
- 2025年度は、大学院の社会人入学者が学部の25歳以上の入学者の約6.4倍。大人の学び直しの入り口は、学部より大学院になっている

## 頑健性
- 社会人の割合の代わりに「30歳以上の入学者の割合」を見ても、修士は10.9%（2000年度）→7.1%（2025年度）と下がり、博士は38.0%、専門職学位は42.7%で、課程の順番は同じ（`results/a235_grad_social_by_course.csv`）
- 大学院の入学者の計は、別の表（専攻分野別 大学院入学状況）の入学者の計と、2000〜2025年度のすべての年で一致した
- コードはきれいなフォルダで3回動かし直し、results と data の全ファイルが一致することを確かめた

## 動かし方
```
pip install -r requirements.txt
```

## データ
- `data/raw/<年度>_AG_<statInfId>`：大学院 年齢別入学者数（2000〜2002年度は修士課程だけ）
- `data/raw/<年度>_AU_<statInfId>`：大学 年齢別入学者数（2015年度から）
- `data/grad_entrants_social.csv`・`data/undergrad_entrants_age.csv`：上の表から拾った数（`src/gakko_parse.py` が年度ごとに違う表の書式をそろえる）

## 注意
- 「社会人」は学校基本調査の定義による。給料などの経常的な収入を得る仕事に就いている人のほか、そうした仕事をすでに退いた人や主婦なども含む（調査の手引の定義。年度によって細かな言い回しが違う可能性がある：推測）
- 学部の25歳以上には、外国の学校を出た人や留学生も含まれ、社会人とは同じではない。2015年度より前は同じ年齢別の表がないため、学部は2015年度からにした
- 2003年度は専門職学位課程ができた年で、入学者が少ない（572人）。専門職学位課程の割合はこの年が85.7%と高く出る
- 入学者の数で、在籍している社会人の数ではない。通信制の大学・大学院は含まない
