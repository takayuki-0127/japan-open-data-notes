# 312 SQL の NULL は、集計をどれだけ黙ってずらすのか（実務の型）

架空の顧客・注文に NULL を一定の割合で入れ、「NULL を気にせず書いた SQL」と「NULL の扱いを書いた SQL」の答えを14本で比べたフォルダです。SQL は T-SQL の書き方で `sql/` に置き、DuckDB で実行して確かめました。**SQL Server 本体では試していません（未検証）**。文字の連結 `+` は DuckDB では `||` に書き換えて実行しています（どちらも、片方が NULL なら結果は NULL）。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A312 | NULL を気にしない書き方は、何本がずれ、どれだけずれるか | 架空の顧客2万人・注文6万件・40店（seed 312）。14本（ずれる場面10本＋ずれない場面4本）を2通りに書いて比べる。NULL の割合を0〜150%に変える | `src/a312_run.py`・`a312_figs.py`、`sql/naive.sql`・`fixed.sql` |

## 主な結果
- NULL の置き方（基本）：割引が NULL の注文 34.9%（「割引なし」を NULL で持つ行）、顧客番号が NULL の注文 6.0%（会員でない人）、生年が NULL の顧客 11.8%、地域が NULL 4.9%、名が NULL 4.0%。返品のない店が40店中10店
- **14本のうち10本がずれ、エラーは1本も出なかった**

| 書き方 | 差 | 起きたこと |
|---|---|---|
| Q01 AVG(割引) | +53.6% | NULL の行を分母から外す |
| Q02 SUM(金額 − 割引) | −35.9% | NULL を引くと NULL になり、行ごと合計から外れる |
| Q03 COUNT(顧客番号) | −6.0% | NULL の行を数えない |
| Q04 NOT IN（副問い合わせ） | **−100%**（6,272人 → 0人） | 副問い合わせに NULL があると結果は0行 |
| Q05 地域 <> '関東' | −8.0% | NULL との比較は真にならない |
| Q06 NOT (割引 > 100) | −45.2% | NOT をつけても NULL は真にならない |
| Q07 SUM(年齢) / COUNT(*) | −11.8% | 分子は NULL を外し、分母は外さない |
| Q08 姓 + ' ' + 名 | −4.0% | 片方が NULL だと全体が NULL |
| Q09 地域で集計してから目標の表と結合 | −10.7% | NULL どうしは等しくないので結合で落ちる（会員でない人の注文も落ちる） |
| Q10 売上 − 返品（外部結合のあと） | −25.3% | 返品のない店は NULL になり、引き算が NULL になる |

- ずれなかった4本：GROUP BY（NULL は1つの組になる）、`割引 > 0`、`IN (…)`、MAX
- NULL の割合を変えると、ずれ方は3通りだった
  - **NOT IN**：顧客番号が NULL の注文が1件あるだけで 0 人（NOT EXISTS は 6,211人）
  - 割合に応じて大きくなる：Q01〜Q03・Q05〜Q09
  - **データに NULL がなくても起きる**：Q10（外部結合が NULL を作る）。NULL の割合0でも −25.3%
- seed を10通りに変えても、ずれた本数は10本で同じ

## 動かし方
```
pip install -r requirements.txt
cd src && python a312_run.py && python a312_figs.py
```

## 確かめたこと
- 空のフォルダで流し直し、results と figures の6ファイルがバイト単位で一致した
- 「扱いを書いた SQL」の14本の答えは、pandas で別に計算した値と一致する（コード内の assert）

## 注意（言えないこと）
- 14本は作成者が選んだものです。「14本中10本」は、NULL でつまずきやすい書き方を集めた結果で、ふつうの SQL の何割がずれるかを表す数字ではありません
- 差の大きさは NULL の割合（架空の置き方）で決まります。割引の35%が NULL という置き方は大きめです
- 「NULL をどう扱うのが正しいか」は列の意味で変わります。ここでは「割引の NULL は0」「地域の NULL は関東以外に入れる」「年齢の平均は分かる人だけ」と決めて比べました。決め方が違えば、正解も変わります
- F244（間違えにくい SQL）と近い題材です。ここでは NULL だけを扱いました
