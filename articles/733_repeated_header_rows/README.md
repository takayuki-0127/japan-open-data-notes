# 733 見出し行つきの CSV を何本も縦につなぐと、見出し行が何行まざり、数の列はどうなるのか（実務の型）

月ごとに出力した CSV を1つにまとめるとき、テキストのまま縦につなぐ（`cat` やコピー＆貼り付け）と、2本目以降の見出し行がデータの行として入ります。数の列に「amount」という文字が入るので、列全体が文字として読まれます。さらに、途中で列の順が変わったファイルがあると、見出しを飛ばしても値が別の列に入ります。**ここでは、架空の店の月別の売上 CSV 12本（7月だけ列の順が違う）を、そのままつなぐ・2本目以降の見出しを飛ばしてつなぐ・1本ずつ見出しを読んで列の名前でそろえる、の3通りで読み、まざった行、数の列の型、月ごとの件数と合計を比べました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A733 | 見出しつきの CSV を縦につなぐと、何がまざり、合計はどうずれるか | 架空の2025年1〜12月の売上 CSV 12本（1本450〜550行、計6,045行）。列は sales_date・store_id・amount、7月だけ sales_date・amount・store_id の順。3通りの読み方と、DuckDB の read_csv(union_by_name)。seed 733 | `src/a733_headers.py`、`src/02_read_duckdb.sql`、`src/01_read_tsql.sql`（T-SQL：未検証） |

## 主な結果
| 読み方 | 読んだ行数 | 数に直せなかった amount | 年の合計（数に直せた分） | 本当の合計とのずれ |
|---|---|---|---|---|
| 本当 | 6,045 | — | 28,552,580円 | — |
| そのままつなぐ | **6,056**（見出し11行がまざる） | 529行 | 26,067,700円 | **−8.7%** |
| 2本目以降の見出しを飛ばす | 6,045 | 518行（7月すべて） | 26,067,700円 | −8.7% |
| 1本ずつ読み、列の名前でそろえる | 6,045 | 0行 | 28,552,580円 | 0 |

- そのままつなぐと、見出しが11行データとして入り、amount の列は文字になった。日付で月にまとめると「sales_d」という13番目の月ができた
- 文字を0として平均すると4,304円で、本当の4,723円より低かった
- 見出しを飛ばしても、列の順が違う7月は amount の列に店コードが入り、7月の売上（518行、2,484,880円）が丸ごと消えた。エラーは出ない
- 1本ずつ見出しを読んで列の名前でそろえる方法（pandas、DuckDB の `union_by_name`）は、件数も合計も本当と一致した
