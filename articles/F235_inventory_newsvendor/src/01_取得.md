# 01 取得

新しいデータは取っていない。F231（売上の予測は、何か月先まで役に立つのか？）の予測結果をそのまま使う。

- 元：japan-open-data-notes/articles/F231_sales_forecast_horizon（コミット 613a8c77d8d3969140bc2eb2203dba25cf6b4a69）の `results/forecasts_main.csv.gz`
- 中身：経済産業省「商業動態統計調査」の6業態の月次販売額について、2016年12月〜2024年8月の47回の起点から1〜24か月先を予測した結果（実績・予測・SARIMA の80%区間）
- これを `data/raw_f231_forecasts_main.csv.gz` として置いた（F231 のファイルと同じもの）

取り直す場合：
```
curl -L -o data/raw_f231_forecasts_main.csv.gz https://raw.githubusercontent.com/takayuki-0127/japan-open-data-notes/613a8c77d8d3969140bc2eb2203dba25cf6b4a69/articles/F231_sales_forecast_horizon/results/forecasts_main.csv.gz
```
