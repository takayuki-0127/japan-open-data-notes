# F235 在庫はどれだけ持てばよいのか？

F231 で作った売上予測（商業動態統計の6業態、1か月先）の「外れ方」をそのまま使い、毎月の仕入れ量を決める練習をした。足りないと売り逃し、余ると値引きや廃棄で損をする――という「ニュースベンダー問題」として、発注量の決め方を5つ比べた。

- **架空の設定**：業態全体の販売額を、架空の小売チェーンの需要とみなした。実在の会社のデータは使っていない
- **損の比は例**：「足りない1単位の損 ÷ 余る1単位の損」を 1・2・4・9・19 と置いた（実在の費用ではない）

## 問い
- 予測をそのまま発注量にすると、どれだけ損をするか
- 予測の外れの分布から発注の倍率を決めると、損はどれだけ減るか。目標どおりに欠品を防げるか
- 予測が良いと、在庫はどれだけ減らせるか

## データ
- F231（articles/F231_sales_forecast_horizon、コミット 613a8c7）の予測結果 `results/forecasts_main.csv.gz` を `data/raw_f231_forecasts_main.csv.gz` に置いた
- 元のデータ：経済産業省「商業動態統計調査」業態別の月次販売額（百貨店・スーパー・コンビニ・ドラッグストア・ホームセンター・家電大型専門店）
- 使ったのは 1〜3か月先、季節ナイーブ・ETS・SARIMA の予測（`data/forecasts_h1to3.csv`）

## 手法
- 外れ＝実績÷予測。起点ごとに、その時点で答えが出ている過去の外れだけを使って倍率を決め（業態ごと・8個以上）、発注量＝予測×倍率とした
- 発注量の決め方（5つ）
  1. 点予測そのまま（倍率1）
  2. 一律＋5%
  3. 正規近似の安全在庫：1＋z×（過去の外れの標準偏差）
  4. 過去の外れの分位点（ニュースベンダー）：外れの「目標のサービス率」の点
  5. SARIMA の80%区間の上端（＝90%の片側の点）
- 目標のサービス率（臨界比）＝ 足りない損 ÷（足りない損＋余る損）。比9なら90%
- 損＝比×不足＋余り（需要100あたり、余る1単位の損＝1）。サービス率＝欠品しなかった月の割合
- コロナ期（2020年3月〜2021年12月）の月は、倍率の計算にも採点にも使わない
- SQL（SQL Server 互換の書き方、`src/04_在庫の判断.sql`）で、固定の分け方（2017〜2019年の外れで90%点を決め、2022年以降に当てはめる）を計算し、DuckDB で流して Python と一致することを確かめた
- ダッシュボード：`dashboard/index.html`（業態と損の比を選ぶと、倍率と発注量の目安が出る）

## 結果（1か月先、2018〜2024年の月、6業態）
- 外れの偏り：季節ナイーブは平均＋2.9%（足りない側に偏る）、SARIMA は＋0.3%。90%点は＋7.9%と＋3.1%
- 点予測そのままだと、欠品しない月は SARIMA 57%、季節ナイーブ 30%。損は比9で 13.6（SARIMA）・32.1（季節ナイーブ）
- 比9（目標90%）の損（SARIMA）：分位点 9.9、一律＋5% 10.0、正規近似 10.5、80%区間の上端 12.6、点予測 13.6
  - 分位点 − 点予測 −3.7（95%区間 −6.3〜−1.6）、比19では −11.1（−16.8〜−5.9）
- 一律＋5% は比9ではほぼ最良だが、比1では損 6.1（分位点 2.9 の2倍）、比19では 14.8 と分位点（15.9）より良い。決まった比でしか合わない
- 目標と実際のサービス率：業態ごとの分位点は目標90%で 85%、95%で 90% と届かない（過去の外れが20個前後と少ないため）。6業態の外れをまとめると 89%・93% に近づき、比9の損は 8.9 に下がる
- 予測の良さ：同じ分位点の決め方で、比9の損は SARIMA 9.9・ETS 10.1・季節ナイーブ 11.9（SARIMA − 季節ナイーブ −2.0、95%区間 −6.1〜＋0.9）
- 業態別（比9・SARIMA・分位点）：倍率はコンビニ 1.01〜家電大型専門店 1.08。損はコンビニ 3.3、家電大型専門店 18.2、百貨店 15.7
- SQL の検算：18行（3モデル×6業態）すべてで、倍率・損・サービス率の差は 1e-12 以下

## 頑健性
- 3か月前に発注（h=3）：比9の損 SARIMA 分位点 12.5（1か月先 9.9）、点予測 17.1
- 直近12個の外れだけで倍率を決める：SARIMA 分位点 10.2、季節ナイーブ 11.9
- 6業態の外れをまとめる：SARIMA 分位点 8.9（サービス率 89%）
- コロナ期も入れる：SARIMA 分位点 13.0、点予測 17.3
- 固定の分け方（2017〜2019年→2022年以降、比9）：SARIMA のサービス率は 82〜100%。季節ナイーブの百貨店は 6% まで落ち、損 67（訪日客の戻りで需要が急に伸びた時期）
- 起点を単位にしたブートストラップ（1,000回）で差の区間を出した

## 言えないこと
- 業態全体の合計を需要とみなした練習。1店・1商品の需要はずっと大きくばらつき、倍率もずっと大きくなる
- 損の比は例。実際の比は、粗利・廃棄・値引き・保管・欠品による客離れで決まる
- 1か月ごとに売り切る（翌月に持ち越さない）前提。持ち越せる商品では、在庫の補充の考え方（発注点など）が別に要る
- 過去の外れが少ないと、分位点は目標より低く出やすい。どれだけ集めればよいかは、業態の動き方で変わる
- コロナ期のような大きな変化の前後では、過去の外れは役に立たないことがある（固定の分け方の百貨店）
