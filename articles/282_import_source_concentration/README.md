# 282 輸入元が少数の国に偏っている品目はどれか

財務省「貿易統計」の概況品別国別表（輸入、2015年・2025年）で、品目ごとに輸入元の国の集中度（HHI）を測ったフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A282 | 輸入元が少数の国に偏っている品目はどれか。10年で偏りは強まったか | 品目（概況品5桁の172品目、3桁の57品目）ごとに国の割合の2乗の和（HHI、0〜1）、1位の国の割合、8割に届く国の数。HHI 0.25超を「偏りが強い」とし、その品目の輸入額の割合を2015・2025年で比べる。重み（品目の構成）を2015年に固定した場合も計算 | `src/a282_source_hhi.py` |

## 主な結果
- 2025年、概況品5桁の172品目（輸入額の78%）のうち83品目で HHI が0.25を超えた。1,000億円以上で偏りが強いのは、とうもろこし（米国97%、HHI 0.94）、がん具及び遊戯用具（中国87%）、時計（スイス82%）、家庭用電気機器（中国76%）、通信機（中国71%、HHI 0.52）、石炭（オーストラリア67%、0.48）など。とうもろこし・がん具・時計は1か国、通信機・石炭は2か国で8割を超える
- 原油（9.6兆円）は HHI 0.35。アラブ首長国連邦43%・サウジアラビア40%で、2015年（33%・26%、ロシア9%）より2か国に寄った
- 偏りが強い品目の輸入額の割合は、5桁で2015年40% → 2025年54%。品目の構成を2015年に固定しても53%で、上がった分のほとんどは品目の中の偏りの変化による
- 上がった分の多くは、大きな品目が0.25の線を越えたこと：原油（HHI 0.20→0.35）、半導体等電子部品（0.21→0.31、台湾53%）、原動機（0.25→0.29）の3品目で2025年の輸入額の19%。逆に自動車・衣類・半導体等製造装置などは線より下に下がった（7%）
- 輸入額で重みをつけた平均の HHI は0.28 → 0.29で、ほとんど変わっていない

## 頑健性
- 品目を3桁（57分類、輸入額のほぼ100%）にまとめると、偏りが強い品目の割合は2015年33% → 2025年27%と、5桁とは逆に下がった。3桁では、中の品目ごとに違う国から買っている分が混ざって偏りが小さく見える。「偏りが強まった」かどうかは品目の分け方しだいで、はっきりは言えない
- 線（0.25）の近くの大きな品目が少し動くだけで割合が大きく動く（原油だけで約11ポイント）。平均の HHI では変化は小さい
- コードは新しいフォルダで2回動かし直し、results と figures のすべてのファイルが一致することを確かめた

## 動かし方
```
pip install -r requirements.txt
cd src && python a282_source_hhi.py   # data/ から results/ と figures/ を作る
python fetch.py                        # data/ を e-Stat から作り直す（任意）
```

## データ
- `data/imports_gaikyo_country_2015_2025.csv`：概況品別国別表（輸入、1-12月）の概況品コード・国コード・金額（千円）。e-Stat の statInfId は `src/fetch.py`
- `data/gaikyo_import_names.csv`・`country_names.csv`：概況品コード表（2025年）と統計国名符号表（税関のページ）

## 注意
- HHI 0.25（2,500）は米国の企業結合審査で使われる目安を借りたもので、輸入の安全性の基準ではない
- 国で数えた偏りで、地域（中東・アジアなど）や、その国の中の取引先の数は分からない。原油は国では0.35でも、中東の割合はもっと高い（推測）
- 概況品は品目のまとまりで、同じ概況品の中に違う品物が入る。5桁の概況品は輸入額の8割弱しかおおわない
- 偏りの良し悪し（調達の不安）を判断するものではない。相手国の順位づけでもない
