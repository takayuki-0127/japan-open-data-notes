### job-openings-japan：厚生労働省「一般職業紹介状況」で、職業別・都道府県別の有効求人倍率を調べる

厚生労働省「一般職業紹介状況（職業安定業務統計）」の長期時系列表（e-Stat）を使ったリポジトリです。ハローワークの求人・求職の数から、職業別（2012年3月〜2026年8月）と都道府県別（1963年〜2025年）の有効求人倍率を調べます。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| W1 | 人手不足（有効求人倍率の高さ）はどの職業で深いか。2013年からどう変わったか | 職業別の月の有効求人数・有効求職者数を年平均にして倍率を計算（パートを含む常用）、2025年の中分類のランキング（有効求職者が月平均1,000人以上の50職業）、2013→2019年の倍率の変化を「求人の変化」と「求職者の変化」に分ける（対数差）、職業分類の切り替え（2023年4月）の影響を2022年度の重なりで確認 | `src/w1_occupation.py` |
| W2 | 都道府県の有効求人倍率は近づいているか。求人を出した場所で数えるか、働く場所で数えるかで違うか | σ収束（47都道府県の倍率の対数の標準偏差、1973〜2025年）、β収束（期間の初めの倍率の対数で年率の変化を回帰、HC1標準誤差）、受理地別と就業地別の比較（2025年）、オンライン登録者を含めた影響（第26表のハローワーク利用登録者のみの値と比較） | `src/w2_prefecture.py` |

#### 主な結果
- **W1**：職業計の有効求人倍率（年平均）は0.83倍（2013年）→1.45倍（2019年）→1.12倍（2025年）、2026年1〜8月は1.06倍（2025年1〜8月は1.11倍）。2025年に最も高いのは建設躯体工事（7.91倍、有効求人1.9万人に対し有効求職者2.4千人）、次いで土木作業（6.24倍）、建築・土木・測量技術者（5.60倍）。保安（警備員など）は6.55倍、介護サービスは3.88倍、自動車運転は2.61倍。低いのは一般事務（0.34倍、有効求人13.9万人に対し有効求職者40.3万人）、美術家・デザイナーなど（0.17倍）。50の中分類のうち36が1倍以上。2013→2019年に職業計の倍率が上がったのは、有効求人が31%増え、有効求職者が25%減ったことの両方による。介護サービスは求人が57%増、土木作業は求職者が49%減。看護師などは求職者が20%増えて倍率が2.72→2.26倍に下がった
- **W1（分類の切り替え）**：2023年4月分から職業分類が「厚生労働省編職業分類（平成23年改定）」から「日本標準職業分類（平成21年改定）」に変わった。2022年度は両方の分類の値があり、69行のうち57行（建設躯体工事、介護サービス、自動車運転、情報処理・通信技術者、一般事務などを含む）は倍率が同じだった。違ったのは12行で、販売類似（2.12→2.57倍）、管理的職業（1.17→0.88倍）、接客・給仕（2.99→3.25倍）、介護関係職種（3.75→3.88倍）など
- **W2**：47都道府県の倍率の差（対数の標準偏差）は0.54（1975年）→0.40（1990年）→0.29（2000年）→0.16（2019年）と縮み、2019〜2025年は0.15前後で止まっている。最も高い県と低い県の比は12.1倍（1975年）→1.8倍（2019年）→2.0倍（2025年）。2013年に倍率が低かった県ほどその後上がった（β＝−4.04、標準誤差0.66、2013→2025年）が、2019→2025年は弱い（β＝−3.51、標準誤差1.38、R²＝0.14）。2025年は受理地別では東京都1.73倍が最も高く神奈川県0.86倍が最も低いが、就業地別では東京都は1.10倍（47都道府県中42位）で、福井県1.84倍が最も高く、47都道府県すべてが1倍以上だった。オンライン登録者は有効求職者の1.5%（2025年、全国）で、除いても都道府県の差（0.146）は変わらない

元の Excel から作り直すときは、e-Stat の一覧（https://www.e-stat.go.jp/stat-search/files?page=1&toukei=00450222&tstat=000001020327 ）から次の5つを `data/raw/` に置き、`data/` の CSV を消して `python common.py` を実行してください。
- `kyujin_21.xlsx`：第21表 職業別労働市場関係指標（実数）（令和4年4月〜）（「〜令和8年8月」の月次）
- `kyujin_old400_01.xlsx`：第21表 職業別労働市場関係指標（実数）（平成23年改定）（平成24年3月〜）（「〜令和5年3月【旧様式】」）
- `kyujin_11.xlsx`：第11表 都道府県（受理地）別 労働市場関係指標（実数、季節調整値）
- `kyujin_18.xlsx`：第18表 都道府県（就業地）別 労働市場関係指標（実数、季節調整値）
- `kyujin_26.xlsx`：第26表 都道府県（受理地）別 労働市場関係指標（実数、ハローワーク利用登録者）

#### データ
| ファイル | 中身 |
|---|---|
| data/occ_monthly.csv | 分類（旧・新）×行×年月：新規求人、有効求人、新規求職、有効求職、就職件数（パートを含む常用、人・件） |
| data/occ_names.csv | 分類×行：職業名（行の並びは旧・新で同じ） |
| data/pref_annual.csv | 基準（受理地・就業地）×都道府県×年：有効求人、有効求職、有効求人倍率（パートを含む一般、年平均） |
| data/pref_monthly.csv | 都道府県×年月（2019年1月〜2026年8月、受理地）：有効求人、有効求職、有効求人倍率、ハローワーク利用登録者のみの有効求職（2021年9月〜） |

#### 注意
- 職業別は「パートを含む常用」、都道府県別は「パートを含む一般」（常用＋臨時・季節）で、範囲が違います
- 倍率は月の有効求人数の年平均÷月の有効求職者数の年平均で計算しました。公表の年平均の倍率とほぼ同じですが、小数第2位が違うことがあります
- 職業分類は2023年4月分から変わりました（旧＝第4回改訂 厚生労働省編職業分類、新＝平成21年改定 日本標準職業分類）。2013〜2022年は旧分類、2023年以降は新分類の値を使っています。2022年度に両方の値がある行のうち12行は値が違うので、それらの行では2022年と2023年の間に段差があります（`results/w1_break_fy2022.csv`）
- 2021年9月分から、有効求職者数などにハローワークに来所しないオンライン登録者が入りました。2025年は全国で有効求職者の1.5%です
- 2020年1月に求人票の様式が変わり、新規求人が減ったと厚生労働省が説明しています。2020年の低下には、コロナの影響とこの変更の両方が入っています
- ハローワークを通さない求人・求職（民間の求人サイトなど）は入っていません。倍率は「ハローワークでの人手の足りなさ」です
- 受理地別は求人を受け付けたハローワークの都道府県で数えるので、本社でまとめて求人を出す企業の多い東京都などが高く出ます。就業地別の倍率は、就業地別の有効求人数÷受理地別の有効求職者数です
- 沖縄県の本土復帰（1972年5月）前の値も表にありますが、σ収束は1973年からにしました
