# 1194 夜と休みの日に来た分を翌朝まとめて受けると、朝の返事までの時間はどう見えるのか？（問い合わせ対応）

問い合わせの窓口が平日の昼だけ開いていると、夜と土日に来た分は、次の朝に積み残しとして並びます。すると「朝の返事までの時間」は、どう区切って数えるかで違う意味になります。朝に返した分の平均は、前の晩からの待ちを含みます。朝に来た分の平均は、積み残しの後ろに並んだ待ちを含みます。どちらも、朝の担当が遅いことを表しているとは限りません。**ここでは、作成者が乱数で作った架空の会社の問い合わせ窓口（担当4人、1件の時間はどの時刻も同じ分布、来る件数の3割が夜と土日、と作成者が置いたもの）の26週で、返事までの時間を「返した時刻の帯」と「来た時刻の帯」、「暦の時間」と「営業時間」で数え、受け方を3通り（来た順・営業時間中に来た分を先に・朝だけ1人増やす）に変えて比べました。確かめとして、時間外に来る割合・込み具合・担当の人数を変えた36通りも作りました。**

担当の速さはどの時刻も同じに置いたので、朝の数字が大きく出る分は、すべて積み残しと数え方によるものです（作りどおり）。この記事で数えたのは、その大きさと、受け方・置き方でどう動くかです。

例は架空の会社の窓口で、実在の会社や問い合わせ管理のサービスを表すものではありません。担当どうしを比べる記事でも、人の配置を勧める記事でもありません。

関連する記事：同じ企画の 1187「返事までの時間を営業時間で数えるか暦の時間で数えるかで、遅く見える曜日はどう入れかわるのか？」は、暦と営業時間の数え方で遅く見える曜日が入れかわる話です。この記事は曜日ではなく1日の中の時刻の帯と、積み残しをどう受けるかを扱います。883「開店直後の行列は、何分で解消するのか？」は、開店前からの行列がいつなくなるかを扱っていて、この記事の朝の積み残しと同じしくみです。521「問い合わせの対応時間を「営業時間」で数えるか「暦の時間」で数えるかで、期限内に返せた割合は何ポイント変わるのか？」は、期限内の割合が数え方で変わる話です。524「深夜まで営業する店で、売上を暦日で切るか「朝5時締めの営業日」で切るかで、曜日別の売上はどれだけ変わるのか？」は、区切る時刻で見え方が変わる話です。この記事は、朝の数字が積み残しで何を表すようになるかに絞ります。

## 主な結果

### 返した時刻の帯で区切ると（A 来た順、26週、`results/by_reply_band_A.csv`）
| 返した時刻の帯 | 件数 | 返事までの時間の平均（暦） | そのうち時間外に来た分の割合 |
|---|---|---|---|
| 9時台 | 2,035 | **20.4時間** | **80%** |
| 10時台 | 1,985 | 14.333時間 | 51.59% |
| 12時台 | 1,543 | 8.293時間 | 33.25% |
| 15時台 | 1,381 | 2.07時間 | 3.69% |
| 17時台 | 1,451 | 1.187時間 | 0% |

- **9時台に返した分の返事までの時間は平均20.4時間で、その80%は夜と土日に来た分だった**。15〜17時台に返した分は1.581時間だった（`results/policies.csv`）
- 9時台に返した分のうち、月曜の分は平均57.661時間、火〜金曜の分は11.113時間だった（土日の分が月曜の朝に並ぶため）

### 来た時刻の帯で区切ると（26週、`results/by_arrival_band.csv`）
| 来た時刻の帯 | A 暦の時間の平均 | A 営業時間の平均 | B 営業時間の平均 | C 営業時間の平均 |
|---|---|---|---|---|
| 時間外（夜と土日） | 21.803時間 | 121.24分 | **252.77分** | 99.63分 |
| 9時台 | 2.319時間 | **139.16分** | 21.19分 | 110.11分 |
| 10時台 | 1.962時間 | 117.7分 | 21.65分 | 86.7分 |
| 13時台 | 1.64時間 | 72.62分 | 18.74分 | 57.23分 |
| 17時台 | 3.971時間 | 31.25分 | 15.32分 | 24.37分 |

（ほかの帯の値もすべて `results/by_arrival_band.csv`）

- **営業時間で数えると、9時台に来た分がいちばん長く待った**（139.16分。15〜17時台に来た分の42.67分の3.261倍）。担当の速さはどの時刻も同じに置いたので、この差は、9時台に来た分が前の晩の積み残しの後ろに並んだことによる（作りどおり）
- 同じ分を暦の時間で数えると、9時台に来た分（2.319時間）より17時台に来た分（3.971時間）のほうが長く見えた。17時台に来た分の一部は翌朝に回り、夜の時間が暦の時間に入るため。どの帯が「遅い」かは、暦か営業時間かで入れかわった

### 受け方の3通り（26週、`results/policies.csv`）
| 受け方 | 9時台に来た分（営業時間） | 15〜17時台に来た分 | 比 | 時間外に来た分（営業時間） | 全体の平均（営業時間） | 全体の平均（暦） |
|---|---|---|---|---|---|---|
| A 来た順 | 139.16分 | 42.67分 | **3.261倍** | 121.24分 | 90.44分 | 8.145時間 |
| B 営業時間中に来た分を先に | **21.19分** | 18.0分 | **1.177倍** | **252.77分** | 89.28分 | 8.129時間 |
| C 9〜11時だけ1人増やす | 110.11分 | 33.92分 | 3.246倍 | 99.63分 | 71.88分 | 7.641時間 |

- **営業時間中に来た分を先に受けると（B）、9時台に来た分の待ちは139.16分から21.19分に縮み、朝の遅さはほぼ消えた。そのかわり、時間外に来た分の待ちは121.24分から252.77分に延びた**。全体の平均は90.44分と89.28分でほぼ同じだった。朝の数字は、担当の速さではなく、誰を先に受けるかの決め方を写していた
- B では、営業時間中に来た分の98.73%が営業時間60分以内に返事を受けた（A は62.24%）。時間外に来た分では21.82%（A は36.32%）だった
- 朝だけ1人増やすと（C）、どの帯も短くなったが、9時台に来た分と15〜17時台に来た分の比は3.246倍とほとんど変わらなかった。9時台に返した分の暦の時間の平均も19.294時間と、A（20.4時間）から少し縮んだだけだった

### 確かめ：36通りの置き方（各8週、`results/grid.csv`）
| 時間外に来る割合 | A 9時台÷15〜17時台に来た分（営業時間） |
|---|---|
| 0% | 0.802〜1.041倍 |
| 15% | 1.893〜3.31倍 |
| 30% | 2.197〜5.629倍 |
| 45% | 2.112〜5.162倍 |

（各割合で、込み具合3通り×担当の人数3通りの9通りの範囲）
- **時間外に来る分がない9通りでは、9時台に来た分と15〜17時台に来た分の待ちはほぼ同じだった（0.802〜1.041倍、作りの確かめ）**。時間外に来る分を置いた27通りでは、すべてで9時台に来た分が長く待った（1.893〜5.629倍）
- B では、時間外に来る分を置いた27通りで1.092〜1.594倍だった。B の全体の平均（営業時間）は A の0.905〜0.997倍だった
- 比が大きかったのは、込み具合が低い置き方だった（担当4人・時間外30%で、込み具合0.6なら5.209倍、0.9なら2.617倍）。空いているときは午後の待ちがとても短く、朝の積み残しの分が目立つためと考えられる（推測）
- 時間外に来る分を置いた27通りで、A の9時台に返した分の返事までの時間は平均13.892〜25.732時間、そのうち時間外に来た分は53.73〜96.06%だった。時間外に来る分のない9通りでも、込んだ置き方では前の日の夕方に来た分が翌朝に回り、0.702〜13.63時間だった

```
pip install -r requirements.txt

```
10秒ほどで終わります。`data/inquiries_A_weeks1_4.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の9ファイルがバイト単位で一致した（cmp、約7.6秒）
- 時間外に来る分を0に置くと、9時台に来た分と15〜17時台に来た分の営業時間の待ちがほぼ同じになることを確かめた（0.802〜1.041倍、作りの確かめ）
- 時間外に来る分を0に置くと、A と B が同じ結果になることを確かめた（`results/grid.csv` の0%の行）
- 図3枚を開き、日本語・重なり・軸（棒は0から）を確かめた

## 注意（言えないこと）
- 架空のデータです。来る件数、時間外に来る割合、1件の時間、担当の人数、営業時間は作成者が置いたもので、結果はこれで決まります。とくに、担当の速さはどの時刻も同じに置いたので、朝の数字が大きく出るのは作りどおりです
- 実際の窓口では、朝の担当の人数や慣れ、問い合わせの種類が時刻で変わることがありえます。この記事では入れていません
- 来る勢いは、営業時間中も時間外も、時間の中で同じに置きました。昼休みや夕方の山は入れていません
- どの受け方がよいかは、時間外に来た人をどれだけ待たせてよいかの決め方によります。この記事では決めていません
- 実在の会社の問い合わせの数字を表すものではありません
