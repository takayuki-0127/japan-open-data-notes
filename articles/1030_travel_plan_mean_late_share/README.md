# 1030 「平均の所要時間」で計画すると、何回に1回遅れるのか？（移動と時間）

「いつも平均35分くらいだから、35分前に出れば間に合う」と考えることがあります。けれども、平均どおりに出ると、平均より時間がかかった日はすべて予定より遅れて着きます。何回に1回遅れるかは、所要時間の分布の形（まれに大きく遅れる日があるか、雨の日のように平均のちがう日が混ざっているか）で決まります。**ここでは、作成者が乱数で作った架空の通勤（家からバス停まで歩き、バスを待って乗り、バス停から会社まで歩く。それぞれの時間を作成者が置いたもの）で、平均の所要時間どおりに家を出たときに遅れる日の割合を数え、計画の決め方（去年の平均・中央値・直近20日の平均・雨かどうかで分けた平均）と、まれに道が大きく混む日の置き方で、どう変わるかを確かめました。**

平均の待ち時間が5分でも10分以上待つ人がどれだけいるかは関連する記事 873、作業ごとの見積もりを足すと全体が足りなくなるかは 849、余裕を作業ごとに持つか最後にまとめて持つかは 852 で扱っています。同じ企画では、9割間に合うには平均に何分足せばよいかを 1037、遅れの平均の取り方を 1031、乗り換えで遅れが段になって増えることを 1032 で扱っています。この記事は、移動の「平均の所要時間」を予定にしたときに遅れる日の割合に絞ります。

## 主な結果

### 基本の置き方（40万日、`results/a1030_main.json` の `base_400k_days`）
| | 値 |
|---|---|
| 所要の平均 | 35.69分 |
| 所要の中央値 | 35.12分 |
| 上から10%目（90%点） | 41.23分 |
| 上から1%目（99%点） | 56.6分 |
| **平均どおりに出て、遅れて着く日** | **44.91%（約2.23回に1回）** |
| 平均より5分以上遅れる日 | 11.62% |
| 平均より10分以上遅れる日 | 4.01% |
| 中央値どおりに出て、遅れて着く日 | 50%（式どおり） |

- **平均どおりに出ると、44.91%の日（約2.23回に1回）に遅れた**。「平均」は半分より少し少ない日にしか遅れない値だが、それでも半分近い
- 遅れる日が半分より少ないのは、まれに大きく遅れる日（道が大きく混む日、雨の日）が平均を中央値より0.57分ほど上に引っぱっているため（平均35.69分、中央値35.12分）
- 日の種類で分けると、雨の日（20.01%）は77.52%、雨でない日は36.75%の日に遅れた。道が大きく混む日（4.02%）は100%遅れた。遅れた日のうち、65.45%は雨でない日だった
- 雨の日の平均は39.31分、雨でない日の平均は34.78分だった

### 計画の決め方（去年で決めて今年1年、200回の平均、`results/plan_methods.csv`）
| 計画の決め方 | 計画の所要（平均） | 遅れる日 | （200回の10〜90%） | 雨の日 | 雨でない日 | 5分以上遅れる日 |
|---|---|---|---|---|---|---|
| 去年の平均 | 35.68分 | **45.01%** | 39.59〜51.06% | **77.77%** | 36.8% | 11.54% |
| 去年の中央値 | 35.16分 | 49.71% | 44.49〜55.51% | 81.71% | 41.69% | 13.55% |
| 直近20日の平均 | 35.7分 | 44.96% | 42.04〜47.76% | 76.96% | 36.91% | 12.21% |
| 雨かどうかで分けた去年の平均 | 35.68分 | 45.36% | 40.41〜50.65% | **45.24%** | **45.4%** | **8.92%** |

- 去年1年の平均で計画しても、今年の遅れる日は45.01%で、40万日で数えた44.91%とほぼ同じだった。ただし年ごとに39.59〜51.06%（10〜90%）と振れた
- **雨かどうかで計画を分けても、遅れる日の割合は45.36%と減らなかった**。変わったのは中身で、雨の日（77.77%→45.24%）と雨でない日（36.8%→45.4%）が同じくらいになり、5分以上遅れる日は11.54%から8.92%に減った
- 直近20日の平均で計画しても、遅れる日（44.96%）は去年の平均とほぼ同じだった。この置き方では季節の変化を入れていないので、直近の値を使う利点が出ない

### 確かめ：道が大きく混む日（各20万日、平均どおりに出たとき、`results/robustness_jam.csv`）
| 混む日の割合 | 5〜10分増える | 10〜25分増える | 20〜40分増える |
|---|---|---|---|
| 0% | 49.21% | 49.26% | 49.22% |
| 2% | 48.74% | 47.11% | 44.9% |
| **4%** | 48.42% | **44.89%** | 40.44% |
| 8% | 47.7% | 41.42% | 32.98% |
| 15% | 46.86% | 36.76% | **26%** |

- **平均どおりに出て遅れる日は、15通りで26〜49.26%と動いた**。混む日が多く、混んだときに大きく増えるほど、平均が上に引っぱられ、ふだんの日は間に合いやすくなる。そのかわり、遅れる日の遅れは大きくなる
- 混む日がなければ49.21〜49.26%と、ほぼ半分（中央値と平均がほぼ同じになるため）

### 確かめ：ほかの置き方を1つずつ（各20万日、`results/robustness_other.csv`）
| 置き方 | 平均 | 中央値 | 平均どおりで遅れる日 | 5分以上遅れる日 |
|---|---|---|---|---|
| 基本 | 35.7分 | 35.13分 | 44.85% | 11.53% |
| 雨の日なし | 34.79分 | 34.29分 | 45.22% | 8.6% |
| 雨の日40% | 36.6分 | 36.05分 | 45.19% | 13.11% |
| バスの待ちなし（時刻表に合わせて家を出る） | 30.69分 | 29.71分 | **36.47%** | 7.58% |
| バスに乗る時間の振れ大（0.25） | 36.19分 | 35.29分 | 44.22% | **19.62%** |
| 雨・混む日なし・振れ小（左右対称に近い） | 34分 | 34分 | **49.94%** | 3.02% |

- 分布が左右対称に近いと、平均どおりで遅れる日は49.94%と、ほぼ半分になった（式どおり：平均と中央値が同じになる）
- バスの待ち（0〜10分の一様分布）をなくすと、ふだんの日の振れが小さくなり、まれな大きな遅れが平均を引っぱる分が目立って、遅れる日は36.47%に下がった
- 雨の日の割合を0%・40%に変えても、平均どおりで遅れる日は45.19〜45.22%とほとんど動かなかった。5分以上遅れる日は8.6〜13.11%と動いた
- **置き方を変えた21通り（15通り＋基本を含む6通り）で、平均どおりに出て遅れる日は26〜49.94%だった**。どの置き方でも50%を超えなかった（右に長い分布では平均が中央値より上に来るため、この置き方の作りどおりの向き）

## データ
- `data/commute_2years.csv`：架空の通勤の2年分（1年245日）の1回（year・day・walk1（家→バス停の徒歩、分）・wait（バスの待ち）・ride（バスに乗る時間）・walk2（バス停→会社の徒歩）・rain（雨の日）・jam（道が大きく混む日）・total（1日の所要））。この1回では、1年目の平均35.79分で計画すると、2年目の41.63%（102日）が遅れた
- `results/a1030_main.json`：主な結果すべて
- `results/plan_methods.csv`：計画の決め方ごとの遅れる日の割合
- `results/robustness_jam.csv`：道が大きく混む日の置き方を変えた確かめ
- `results/robustness_other.csv`：ほかの置き方を1つずつ変えた確かめ

## 注意（言えないこと）
- 架空のデータです。歩く時間、バスの待ち、乗る時間、雨の日と道が大きく混む日の割合と大きさは作成者が置いたもので、結果はこれで決まります。平均どおりに出て遅れる日は、置き方で26〜49.94%と動きました。実在の路線や会社の通勤の数字を表すものではありません
- 「中央値どおりなら50%」「左右対称なら平均どおりでも約50%」「右に長い分布では50%より少ない」は式どおりの向きです。数えて新しく分かったのは、この置き方での大きさ（44.91%）、雨の日と雨でない日で遅れ方が大きく違うこと、計画を分けても遅れる日の割合は減らず中身が変わることです
- 道が大きく混む日の原因は置いていません。ここで置いたよりさらにまれで大きな遅れは入れていません
- 遅れたときに何分遅れるか、何分の余裕を見ればよいかは、この記事では「5分以上・10分以上遅れる日」の割合までしか数えていません（9割間に合う余裕の大きさは 1037 で数えています）
- 季節や曜日による変化は入れていません。直近20日の平均が去年の平均と変わらなかったのは、このためです
