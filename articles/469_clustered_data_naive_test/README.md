# 469 同じ店や同じ人の中で似ているデータを、ばらばらの件数として検定すると、効果が0でも何%で「差あり」が出るのか（手法の解説）

店ごとに施策を割り当てて、お客さん1人ずつの値で検定するような場面では、同じ店の中の値が似ている分だけ、独立な情報は件数より少なくなります。**効果0のシミュレーションで、1件ずつの t 検定・店の平均での t 検定・固まりを考えた標準誤差（補正なし／あり）の空振りの割合を数えました。**

|---|---|---|---|
| A469 | 固まり（店）の中で似ているデータを1件ずつ独立として検定すると、効果が0でも何%で「差あり」と出るか。店の平均で検定する・固まりを考えた標準誤差を使うと、どこまで直るか。件数と店の数のどちらが検出力に効くか | 店の数 K（6〜200）、1店の件数 m（10〜1,000）、級内相関 ρ（0〜0.3）。値＝店ごとの違い＋1件ごとの違い（正規分布）。施策は店ごとに半分へ割り当て、効果は0。4,000回ずつ、5%水準で「差あり」の割合を数える（店ごとの合計と平方和から計算） | `src/a469_cluster.py` |

## 置いたこと
- 級内相関 ρ＝値の散らばりのうち、店ごとの違いが占める割合。全体の散らばりは1
- どの店も件数は同じ。固まりは店の1段だけ
- 検定：①1件ずつの t 検定、②店の平均どうしの t 検定、③固まりを考えた標準誤差（補正なし・正規分布）、④同じく補正つき（K/(K−1) を掛け、自由度 K−1 の t 分布）
- 検出力は、本当の差を0.1標準偏差と置いて測った

## 確かめたこと
- 空のフォルダで計算し直し、data・results・figures が一致した
- ρ=0 では、どの方法も空振りが5%前後
- 1件ずつの検定の空振りは、式 2Φ(−1.96/√(1+(m−1)ρ)) とほぼ一致した

## 注意（言えないこと）
- シミュレーションです。数字は、店の数、1店の件数、級内相関の置き方で決まります。値は正規分布で、店ごとの件数は同じです
- 級内相関は、実際のデータでは分かっていない数です。その見積もりの誤差は扱っていません
- 固まりは1段だけです。入れ子の固まり、時間の順に似ている場合は扱っていません。指標をいくつも同時に見るときの空振りは446で扱いました
- 混合モデルは試していません。区間が正解を含む割合は出していません
