# F359 PLAN（事前の計画）：「初任給が過去最高の伸び」は、賃金全体の伸びと比べてどれだけ特別なのか？

作成：2026-11-16 12:45（データを取得し、表の形を確かめたあと、伸び率や差を集計する前に書いた）

## 問い
厚生労働省「令和7年賃金構造基本統計調査の概況」（2026年3月24日）では、新規学卒者の賃金（所定内給与額、6月分）が大学で262.3千円、対前年5.6%増、高校で207.3千円、5.0%増でした。同じ概況で一般労働者全体の賃金は340.6千円、3.1%増です。報道では初任給の「過去最高」が繰り返し見出しになっています。

知りたいこと：新卒の伸びは、賃金全体の伸びと比べて、2006年以降の中でどれだけ大きいのか。新卒だけが上がっているのか、若い層全体が上がっているのか。中高年との差は縮まっているのか。

知りたい人：採用や人事の担当、就職を控えた学生と家族、賃金の統計を読む記者や研究者。「初任給が上がった」が賃金全体の動きとどうつながっているかを知りたい人。

既存の看板記事との違い：既存の記事は最低賃金、賃金の分解（シフトシェア）、名目と実質などで、新規学卒者の賃金を全体と比べたものはない（existing_F_titles.txt と jodn/articles の README を「初任給」で検索して確認）。

## データ
- 厚生労働省「賃金構造基本統計調査」新規学卒者 第1表（新規学卒者の学歴別所定内給与額、民営事業所、企業規模計と規模別、男女別）。2020〜2025年は各年の表、2006〜2019年は【参考掲載】「令和2年調査と同じ推計方法を用いた過去分の集計」（高校・大学のみ）。
- 同 一般労働者 産業大分類 第1表（産業計、学歴・年齢階級別の所定内給与額と労働者数、企業規模計と規模別）。2006〜2019年は同じ【参考掲載】の集計。
- 同 時系列（〜令和元年まで）第1表 新規学卒者の初任給の推移（1976〜2019年、旧推計方法、男女別・学歴別。初任給は確定額で通勤手当を除く）。長い期間の比べ方にだけ使う。
- 単位は千円（6月分の所定内給与額）。名目。

## 取得前に見たもの（開示）
- 概況の第10表（2025年：大学262.3千円・5.6%、高校207.3千円・5.0%、大学院299.0千円・4.0%）と、一般労働者340.6千円・3.1%。
- 表の形を確かめるときに、2019年の新規学卒者（高校176.4千円）、2019年の一般労働者の年齢別（男女計の所定内給与306.0千円、20〜24歳211.3千円など）、2025年の新規学卒者（大学院299.0千円）、旧系列の1977年の大卒男の前年比（7.1%）と2009〜2019年の大卒男の値を目にした。伸びの比較はしていない。

## 仮説と「外れ」の基準
- H1：2025年の大学新卒の前年比（男女計・企業規模計）は、2007〜2025年（同じ推計方法の範囲）でいちばん大きい。ほかの年に2025年以上の伸びがあれば外れ。
- H2：2025年の「大学新卒の前年比 − 一般労働者（学歴計・年齢計）の前年比」は、2007〜2025年でいちばん大きい。ほかの年のほうが大きければ外れ。
- H3：2019→2025年の累積の伸びは、大学新卒・高校新卒とも、一般労働者全体より大きく、50〜54歳より大きい。新卒の伸びが全体以下なら外れ。
- H4：旧推計方法の長い系列（1976〜2019年）では、大卒男の初任給の前年比が5.6%以上の年がある（=「過去最高の伸び」と言えるのは、比べる期間を限ったときだけ）。1976〜2019年に5.6%以上の年がなければ外れ。

## 手法
- 各年の値を表から読み、前年比（%）を計算する（表にある値ではなく水準から計算し、表の値と照合する）。
- 一般労働者は、年齢計の平均（高齢化で構成が変わる）と、年齢の構成を2019年に固定した平均（年齢階級別の所定内給与を2019年の労働者数で重みづけ）の両方で伸びを出す。
- 年齢階級別（20〜24歳から60〜64歳）の2019→2025年の累積の伸びを並べる。
- 50〜54歳の所定内給与 ÷ 20〜24歳の所定内給与（倍率）の推移。

## 頑健性（3つ以上）
1. 男女別に分ける（男・女それぞれで H1・H2）。
2. 企業規模別（1,000人以上・100〜999人・10〜99人）で、2025年の新卒の伸びと全体の伸びの差。
3. 比べる相手を「年齢構成を固定した平均」と「20〜24歳」に替える。
4. 2020年（推計方法が変わった年。過去分は同じ方法で集計し直されている）をまたぐ伸びを除いた期間（2021〜2025年）だけで見る。
5. 高校新卒で同じことをする。

## 問い直し（予定）
結果を見てから1つ足す。候補：新卒の給与と、入社2〜7年目にあたる25〜29歳の給与の差（倍率）は縮まったのか。

## 言えないこと（予定）
- 6月分の所定内給与で、残業代や賞与、手当の一部（通勤手当など）の扱いは時期で違う。年収の比較ではない。
- 2019年以前と2020年以降は調査の推計方法が違い、2006〜2019年は厚労省が同じ方法で集計し直した参考値に頼る。旧系列とは水準が直接つながらない。
- 新卒の伸びの理由（人手不足、採用の競争、物価）は、このデータでは分からない。
- 名目の値で、物価を除いた実質の比較はしていない。
- 標本調査なので、前年比の小さな差は誤差の範囲かもしれない（標準誤差率の表は使っていない）。
