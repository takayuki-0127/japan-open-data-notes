# 1010 平均で合わせるか、いちばん低い項目で合わせるかで、何が変わるのか？（指数とスコア）

いくつかの項目からなるスコアは、項目の平均で1つにまとめることが多い一方で、「どれか1つでも悪ければ全体が台なし」という考えから、いちばん低い項目の点をそのままスコアにすることもあります。平均なら得意な項目で苦手な項目を埋め合わせられ、いちばん低い項目なら埋め合わせはききません。どちらを選ぶかで上位の店は入れ替わります。けれども、毎月の調査の点には測り方の振れがあり、いちばん低い項目の点は、その月にたまたま低く出た項目を拾いがちです。**ここでは、作成者が乱数で作った架空のチェーン店300店の運営スコア（5項目それぞれの本当の点と、毎月の測り方の振れを作成者が置いたもの）で、5項目の平均といちばん低い項目のどちらで並べるかによって、上位30店の顔ぶれ、翌月の順位とのそろい方、本当の上位30店の当たりがどう変わるかを数えました。「どちらが正しいか」は扱いません。**

店・スコア・項目はすべて架空のもので、実在の指数やランキングの数字は使っていません。

関連する記事 931 は、試験の分野ごとの足切りで、問題の少ない分野の振れが落ちる人を決めてしまうことを数えています。884 は、待ち時間の平均と最長のどちらが満足に近いかを数えています。この記事は、合否の線ではなく、店を並べるスコアを平均といちばん低い項目のどちらで作るかに絞ります。同じ企画の 1015 の問い（足し算か掛け算かで、苦手な項目の効き方はどう変わるのか）は、足し算と掛け算の比べで、この記事は平均といちばん低い項目の両端を比べます。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A1010 | 5項目の平均で並べるのと、いちばん低い項目の点で並べるのとで、上位30店（300店の1割）はどれだけ入れ替わるか。翌月の順位とどれだけそろうか。本当の平均・本当のいちばん低い項目の上位30店を、それぞれどれだけ当てるか | 架空のチェーン店300店。項目は清潔さ・待ち時間の短さ・品ぞろえ・接客・会計の正確さの5つ（各100点満点）。店ごとの項目の本当の点＝70＋10×(√r×店の共通の良さ＋√(1−r)×項目だけの良さ)（どちらも標準正規）で、r＝0.6（項目どうしの本当の点の相関0.6、標準偏差10点）。毎月の点＝本当の点＋測り方の振れ（平均0・標準偏差6点の正規分布、月ごと・項目ごとに別）を整数に丸めて0〜100に収めた。2か月分を作り、1か月目の点で並べた。本当の上位30店は、本当の点の平均と、本当の点のいちばん低い項目のそれぞれで決めた。店を作り直して300回。確かめとして、測り方の振れ（0・3・6・10・15点）×項目どうしの相関（0.3・0.6・0.8）×項目の数（3・5・8）の45通りを各60回数えた。seed 1010 | `src/a1010_mean_vs_min_item.py` |

## 主な結果

### 例の300店（1回分、`data/stores_example.csv`）
| 店 | 清潔さ | 待ち時間の短さ | 品ぞろえ | 接客 | 会計の正確さ | 平均（順位） | いちばん低い項目（順位） |
|---|---|---|---|---|---|---|---|
| 店103 | 75 | 97 | 100 | 71 | 87 | 86.0（4位） | 71（37位） |
| 店66 | 82 | 83 | 78 | 83 | 79 | 81.0（31位） | 78（6位） |

- 例の300店では、上位30店のうち22店はどちらで並べても上位30店で、8店ずつが入れ替わった（図1）
- 店103は、得意な項目が高く平均では4位だが、接客が71点でいちばん低い項目では37位だった。店66は、どの項目も80点前後で平均では31位だが、いちばん低い項目では6位だった

### 300回の平均（振れ6点・相関0.6・5項目、`results/a1010_main.json` の base_300reps）
| 数えたもの | 平均で並べる | いちばん低い項目で並べる |
|---|---|---|
| 上位30店の重なり（平均といちばん低い項目） | **70.76%** | |
| 順位相関（平均といちばん低い項目） | 0.8856 | |
| 翌月の順位との順位相関 | **0.8939** | **0.7524** |
| 上位30店のうち、翌月も上位30店 | 69.38% | 55.12% |
| 本当の平均の上位30店を当てた割合 | 78.34% | 64.68% |
| 本当のいちばん低い項目の上位30店を当てた割合 | **69.06%**（10〜90%の範囲 60〜76.67%） | **65.96%**（56.67〜73.33%） |
| 本当のいちばん低い項目と順位相関 | 0.879 | 0.8551 |
| 見かけの点 − 本当の点（店の平均） | −0.0206点 | **−2.7954点** |

- 平均といちばん低い項目で、上位30店の約3割が入れ替わった（重なり70.76%）
- いちばん低い項目は、翌月の順位とのそろい方が0.7524と、平均（0.8939）より低かった。5つの振れのうちいちばん下に出たものを拾うので、月ごとに入れ替わる
- いちばん低い項目の点は、本当のいちばん低い項目より平均2.7954点低く出た。振れのうち下に出たものを選ぶための偏りで、平均の点にはこの偏りがない（−0.0206点）
- 1か月目にいちばん低かった項目が、本当にいちばん低い項目だった店は55.03%、翌月もいちばん低い項目が同じだった店は42.72%だった。「この店の弱点はこの項目」という読みは、1か月の点では半分ほどしか当たらない
- **本当のいちばん低い項目の上位30店を当てたいときでも、平均で並べたほうが少し当たった（69.06%対65.96%）**。300回のうち平均のほうが当たったのは57.67%、いちばん低い項目のほうが当たったのは22.67%。いちばん低い項目で並べると振れを拾い、平均で並べると5項目の振れが打ち消し合う。項目どうしの本当の点が相関しているので、平均の高い店は本当のいちばん低い項目も高いことが多い

### 確かめ：置き方を変えて（45通り、各60回、`results/robustness.csv`）
| 数えたもの | 値 |
|---|---|
| 上位30店の重なり（平均といちばん低い項目） | 55.17〜84.5% |
| 順位相関（平均といちばん低い項目） | 0.6925〜0.9717 |
| 振れのある36通りで、翌月の順位とのそろい方がいちばん低い項目のほうが低かった数 | **36通りすべて** |
| 振れのある36通りで、本当のいちばん低い項目の上位30店を平均のほうが当てた数 | **26通り**（いちばん低い項目のほうが当てたのは10通り） |
| 当たりの差（平均−いちばん低い項目、振れのある36通り） | −12.84〜+12.39ポイント |
| 見かけのいちばん低い項目 − 本当のいちばん低い項目（振れのある36通り） | −15.8167〜−0.4451点 |
| 1か月目にいちばん低い項目が本当にいちばん低い項目だった店（振れのある36通り） | 22.51〜83.39% |

- いちばん低い項目のほうが当てた10通りは、振れが3点の9通りのうち7通りと、振れが6点で項目どうしの相関が0.3の3通りだった。振れが小さいか、項目どうしの本当の点がばらばらなときは、いちばん低い項目で並べたほうが本当のいちばん低い項目に近い。平均のほうが当てた26通りは、振れが10点以上の18通りすべて、振れが6点で相関0.6以上の6通り、振れが3点で相関0.8の2通りだった
- 相関0.6・5項目で振れを変えると、本当のいちばん低い項目の上位30店の当たりは、平均で並べると0点で75.83%・3点で75.11%・6点で69.72%・10点で58.78%・15点で50.06%、いちばん低い項目で並べると96.72%・78.89%・66.33%・51.39%・42.61%だった（図3）
- 振れ0点でも、いちばん低い項目で並べた当たりが100%にならない（95〜96.72%）のは、点を整数に丸めて同点ができるため。振れ0点では2か月の点が同じなので、翌月とのそろい方は平均もいちばん低い項目も1になる
- 本当の平均の上位を当てたいなら平均、本当のいちばん低い項目の上位を当てたいならいちばん低い項目、というのは振れがないときの話で、振れがあると後者は崩れることがある

- 平均の見かけと本当の差が小さいことを確かめた（基本の置き方で−0.0206点、45通りで−0.4369〜+0.0117点。振れが大きいと100点で頭打ちにする分だけ下に出る）

## 注意（言えないこと）
- 架空のデータです。項目の数、本当の点の散らばり、項目どうしの相関、測り方の振れの大きさは作成者が置いたもので、結果はこれで決まります。本当のいちばん低い項目の上位を当てるのに平均といちばん低い項目のどちらが向くかは、振れの大きさと項目どうしの相関で逆転しました（36通り中26通りで平均、10通りでいちばん低い項目）
- 「平均といちばん低い項目のどちらで並べるべきか」は言えません。それは、店にとって何が大事か（埋め合わせがきくかどうか）で決まることで、この記事は、選んだあとに測り方の振れでどれだけずれるかを数えただけです
- 測り方の振れは、項目ごと・月ごとにばらばらで、店の本当の点とは関係なく出ると置きました。調査する人の甘さ辛さのような、店ごとに続くずれは入れていません
- 実在の店舗の評価の仕組みやランキングを表すものではありません
