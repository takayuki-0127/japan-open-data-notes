# 272 季節調整を、業務の月次データにどう当てるか（実務の型）

毎月の数字を「先月より良かったか」で読むときの3つの見方——前月比（原数値）、前年同月比、季節調整後の前月比（STL）——を、本物の月次（商業動態統計の6業態）と、正解の分かる架空の月次で比べた。

| 番号 | 問い | 手法 | ファイル |
|---|---|---|---|
| A272 | 業務の月次データで、前月比・前年同月比・季節調整後の前月比をどう使い分けるか。最新月の季節調整値は、どれだけ当てになるか | STL（周期12、外れ値に強い設定、季節の窓7年）、各月の時点で推定し直した値と全期間で推定した値の比較、正解の分かるシミュレーション（61か月目から5%上がる系列1,000本） | `src/a272_seasonal.py` |

X-13ARIMA-SEATS で公表値を再現する（F42）、季節調整のやり方で景気の山の時期が変わるか（F199）、SARIMA の予測（020）とは別の、**業務の月次の読み方**に絞った。

## 主な結果

### ① 本物の月次（2014年1月〜2026年8月、6業態）

| 業態 | 前月比の向きが原数値と季節調整後で逆の月 | 最新月の季節調整後の前月比の向きが、あとで逆になった月（2019〜2025年） | 最新月の改訂の大きさ（平均、ポイント） |
|---|---|---|---|
| コンビニ | 52% | 35% | 0.96 |
| スーパー | 42% | 29% | 1.56 |
| ドラッグストア | 38% | 36% | 1.45 |
| ホームセンター | 44% | 28% | 2.54 |
| 家電大型専門店 | 42% | 18% | 3.17 |
| 百貨店 | 48% | 41% | 7.87 |

- 原数値の前月比の動きのうち、季節の分が季節を除いた動きより大きかった月は、6業態で74〜95%
- 「最新月」は、その月までのデータだけで STL をかけたときの値。「あとで」は2026年8月までの全期間でかけ直した値。改訂の大きさは、季節調整後の前月比のふだんの振れ（標準偏差）の0.3〜0.6倍

### ② 正解の分かる架空の月次（7年分、61か月目＝1月から5%上がる、1,000本）

「いつもと違う」は、その系列の直前36か月の同じ数字から2標準偏差以上ずれたとき、とした。

- **原数値の前月比**：変化のない系列でも、1月は98%で「下がった」と出る（12月→1月の季節の落ち込み）。この読み方では、変化があってもなくても同じに見える
- **前年同月比**：上がった月に「上」と読めたのは63%（変化のない系列では4%）。ただし前年同月比の前の月からの変化で見ると、上がった月に51%で跳ね、ちょうど1年後に48%で「下がった」と出た。1年前の上がった月が比べる相手になるので、何も起きていないのに下がって見える
- **季節調整後の前月比（最新月）**：上がった月に「上」と読めたのは9%。1年後には17%で「下がった」と出た。最新月の STL は、新しく起きた変化の一部を「季節」として受け取ってしまう
  - 上がった3か月後の時点で、季節調整値に出た上昇は5%のうち17%（季節の窓を13年にすると39%）。全84か月でかけ直すと89%（同87%）が出た
  - 外れ値に強い設定を外すと、上がった月のずれは中央値 1.2標準偏差まで出るが、「上」と読める割合は8%で同じくらい

## 動かし方

```
pip install -r requirements.txt
cd src && python a272_seasonal.py
```

`results/summary.json` に数字、`results/revisions.csv` に月ごとの改訂、`results/sim.csv`・`shown.csv` にシミュレーションを書き出す。シミュレーションは数分かかる。

## 言えないこと・注意

- STL は1つの方法。曜日や祝日の並び（営業日の数）は調整していない。公表値に使われる X-13ARIMA-SEATS（F42）では、端の扱いや改訂の大きさが違う
- 架空の月次は、季節の形が毎年同じで、上がり方が一度きりの5%という単純な設定。実際の変化は少しずつ起きることが多い
- 「いつもと違う」の決め方（直前36か月から2標準偏差）は1つの例。しきい値を変えると割合は変わる
- 本物の月次の結果は、2014年以降の6業態のもの。ほかの業態・期間で同じとは限らない
- 「最新月の季節調整値は仮の値として伝える」「前年同月比は1年後の比べる相手に注意する」は、この結果から考えた伝え方の案（推測）
