# 419 契約を代表の契約にまとめて計算すると、結果はどれだけずれるのか（手法の解説）

たくさんの契約を、年齢と期間のマスごとに1件の「代表の契約」にまとめて計算したとき、**全件を1件ずつ計算した結果からどれだけずれるか**を、架空の定期保険10万件で測ったフォルダです。死亡率は公表の生命表、契約は架空です。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A419 | 代表の契約にまとめると、将来の支払いの現在価値はどれだけずれるか。まとめ方・細かさ・前提の動かし方でどう変わるか | 定期保険10万件（年齢25〜70歳、残り1〜30年）の死亡保険金の現在価値を、全件と、3通りのマス×4通りの代表の決め方で計算する。契約の作り方を変えて20回 | `src/a419_model_points.py` |

## 置いたこと
- 契約（架空）：年齢は平均45歳・標準偏差10歳を25〜70歳に収めたもの。残りの期間は1〜30年で、若い人ほど長い。保険金額は対数正規（中央値およそ1,000万円）で、若い人ほどやや大きい
- 死亡率：厚生労働省「令和6年簡易生命表」（男）。`data/life_table_2024_qx.csv`（F268 のフォルダから写したもの）
- 現在価値：保険金額 × Σ v^(k+1)・(k年生きる割合)・(その年の死亡率)。金利1%。保険料・解約・経費は入れていない
- マス：粗い（年齢10歳×期間4区分、代表 約17件）／中くらい（5歳×3年、約69件）／細かい（2歳×2年、約220件）
- 代表の決め方：マスの真ん中／件数で平均／金額で重みをつけた平均／金額で重みをつけた平均を整数に丸める。保険金額はマスの合計
- 整数でない年齢・期間は、まわりの4点から線で補う

## 主な結果
### 現在価値の合計のずれ（金利1%、20回の平均。かっこは20回の最小〜最大）
| マス | マスの真ん中 | 件数で平均 | 金額で重みをつけた平均 | 同（整数に丸める） |
|---|---|---|---|---|
| 粗い（約17件） | +11.3%（+10.5〜+12.0） | −2.8%（−3.0〜−2.7） | −3.4%（−3.5〜−3.4） | −1.4%（−1.7〜−1.1） |
| 中くらい（約69件） | +1.3%（+1.1〜+1.4） | −0.7%（−0.8〜−0.6） | −0.9%（−0.9〜−0.9） | +0.1%（−1.2〜+0.7） |
| 細かい（約220件） | +0.4%（+0.4〜+0.5） | +0.03%（−0.01〜+0.10） | +0.002% | −2.2%（−3.0〜−1.6） |

- 平均で代表させると小さく出る（現在価値が年齢に対して下に凸の曲線のため）
- 整数に丸めると、細かいマスでもずれが残る

|---|---|---|---|---|
| 金利1%→3%（全件では−16.9%） | 粗い | +17.3% | −4.9% | −5.5% |
| | 中くらい | +1.9% | −1.0% | −1.2% |
| | 細かい | +0.8% | +0.03% | 0.00% |
| 死亡率×1.1 | 粗い | +9.8% | −2.4% | −3.0% |

| | 細かい | +0.3% | +0.03% | 0.00% |

### 年齢の幅だけを広げたとき（期間は1年ごと。1つのポートフォリオ）

| 2歳 | +0.03% | 0.00% |

## 動かし方
```
pip install -r requirements.txt
cd src && python a419_model_points.py      # 約10秒
```
`data/example_policies_2000.csv`、`results/` の5ファイル、`figures/` の3枚ができます。

## 確かめたこと
- 空のフォルダで計算し直し、data・results・figures が一致した
- 年齢1歳×期間1年のマス（まとめない場合と同じ）では、ずれが0になる（`error_by_age_band_width.csv` の幅1）
- 全件の現在価値の合計は、20回で705〜715億円（保険金額の単位を万円としたとき）で、ポートフォリオによる違いは1%ほど

## 注意（言えないこと）
- 架空の契約です。年齢・期間・保険金額の分布の置き方で、ずれの大きさも向きも変わります
- 計算したのは定期保険の死亡保険金の現在価値だけです。保険料・解約・経費・満期の支払いがある商品では、ずれが違います
- 代表の決め方は4通りだけです。全件の結果に合うように代表を選ぶ方法は試していません
- 丸めた場合のずれは、丸め方（偶数への丸め）にも左右されます
- 実務でどの細かさが許されるかは、計算の目的と求められる精度で決まります
