# F74 観測点のない場所の気温を、どこまで当てられるか？（クリギング・IDW・回帰クリギング・LightGBM）

看板記事 F74。note の記事：「観測点のない場所の気温は、どこまで当てられるか？ アメダス915地点で手法を比べると、距離だけのクリギングは平均1.2℃外れ、標高を足した回帰クリギングは0.54℃。機械学習は富士山頂で15℃外れた」

## 問い

アメダスの観測点がない場所の気温を、まわりの観測点から推定（空間補間）すると、どれくらい当たるか。距離だけを使う方法（IDW・通常クリギング）、標高などで説明する方法（線形回帰）、その両方（回帰クリギング）、機械学習（LightGBM）でどう違うか。

## データ

- 気象庁「平年値（統計期間1991〜2020年）」のアメダス月別平年値（normal_amedas_monthly.zip）と地点一覧（amedas_station_index.zip）
  - 要素 0500（月平均気温）、0600（日最高気温の月平均）、0700（日最低気温の月平均）。値は0.1℃単位、品質フラグ8（平年値）だけを使った
  - 年平均と1・8月の平年値がそろう917地点のうち、同じ緯度・経度の地点が2組あったので統計年数の長いほうを残し、**915地点**
  - `data/raw/f74_jma_normals.txt`：地点一覧と気温3要素の行だけを抜き出したもの（`src/01_取得.py` で作り直せる。記事を作ったときはブラウザのページ内で同じ処理をした）
- 標高の中央値53m、500m以上は71地点。最も近い観測点までの距離の中央値は15.7km（90%点22.5km）

## 手法

| 手法 | 使う情報 | 中身 |
|---|---|---|
| IDW | 距離 | 近い12地点の距離の2乗の逆数で重みづけ平均 |
| 通常クリギング（OK） | 距離 | 球形のバリオグラム、近い40地点で推定（pykrige） |
| 線形回帰 | 緯度・経度・標高 | 最小二乗法 |
| 回帰クリギング（RK） | 緯度・経度・標高＋距離 | 線形回帰の残差を通常クリギング |
| LightGBM | 緯度・経度・標高・平面座標 | 600本、葉15 |

- 平面座標は北緯36度・東経137度を原点にした正距円筒図法（km）
- 交差検証（10分割）は3通り：地点をランダムに分ける／予報区（地点番号の上2桁、約60）ごとに外す／100km四方のブロックごとに外す
- 対象：年平均、1月・4月・8月・10月の平均気温。頑健性で日最高・日最低（年）

## 主な結果

- 緯度・経度・標高の線形回帰で年平均気温の97%が説明できる。標高100mで −0.60℃（1月 −0.77℃、8月 −0.47℃）
- 年平均気温の外れ（RMSE、℃）

| 手法 | 地点ランダム | 予報区ごと | 100km四方ごと |
|---|---|---|---|
| IDW | 1.23 | 1.48 | 1.50 |
| 通常クリギング | 1.20 | 1.63 | 1.38 |
| 線形回帰 | 0.73 | 0.75 | 0.75 |
| 回帰クリギング | **0.54** | **0.59** | **0.58** |
| LightGBM | 0.74 | 0.89 | 0.78 |

- 標高帯別（地点ランダム）：500〜1000m の60地点で、IDW 1.99・通常クリギング 1.95 に対し、回帰クリギング 0.46。通常クリギングは500m以上の地点を平均+1.4℃高く当てる
- 富士山頂（3,775m）は、IDW +18.5℃、通常クリギング +18.1℃、LightGBM +15.4℃ 外れた（回帰クリギング −1.2℃、線形回帰 −2.0℃）。富士山頂を評価から外すと LightGBM は0.54で回帰クリギング（0.54）と並ぶ。木のモデルは学習した範囲の外の標高を外挿できない
- 回帰の残差のバリオグラム：ナゲット0.39、シル0.69（球形）。残差のばらつきの約56%は、距離では説明できない地点ごとの違い
- 月別：1月がいちばん外れる（回帰クリギング 0.93、100km四方 1.00）。8月は線形回帰だけが悪い（1.18）：夏は緯度で気温が下がりにくく、直線の関係が崩れる
- 予測区間：地点ランダムの95%区間に入った割合は通常クリギング 93.8%、回帰クリギング 98.7%

## 頑健性（`results/robustness.csv`）

- バリオグラム：指数型で OK 1.21／RK 0.52、ガウス型は OK が数値的に不安定で発散（RK は0.57）
- IDW のべき1〜3・近傍6〜30：1.23〜1.27（地点ランダム）
- 最も近い観測点が50km以上の地点（離島など）を除く：OK 1.15、RK 0.53、LightGBM 0.74
- LightGBM から標高を外すと1.30（100km四方 1.50）で、通常クリギングと同じ水準
- 日最高（年）：OK 1.29、RK 0.55／日最低（年）：OK 1.37、RK 1.00、LightGBM 1.05。夜の最低気温は地形（盆地・冷気湖）の影響が強く、標高だけでは足りない
- 分割の乱数の種を変えても RK 0.545〜0.547、LightGBM 0.738〜0.744

## 言えないこと

- 評価は観測点の上だけ。観測点のない山の上や谷の中（いちばん補間したい場所）での当たり方は、観測点で測った外れより大きい可能性がある
- 回帰クリギングで地図を描くには、予測したい場所の標高（数値標高モデル）が要る。この記事の地図は標高を使わない通常クリギング
- 平年値（30年平均）での比較で、日々の気温の補間とは当たり方が違う
- 海からの距離・斜面の向き・都市化などは入れていない
