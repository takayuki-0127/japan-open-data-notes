# 1032 乗り換え1回で、全体の遅れはどう増えるのか？（移動と時間）

乗り換えのある通勤では、1本目の遅れがそのまま足されるだけではありません。1本目が乗り換えの余裕より多く遅れると、計画の便に乗れず次の便になり、着く時刻は便の間隔の分だけ一度に遅れます。1本目が1〜2分遅れた日はほとんど影響がないのに、2〜3分遅れた日は10分近く遅れる、という段のついた形になります。**ここでは、作成者が乱数で作った架空の通勤（路線1で乗り換え駅へ行き、決まった間隔で出る路線2に乗りかえる。どちらの路線の遅れやすさも作成者が置いたもの）で、乗り換え1回のときの会社の駅に着く遅れを、乗り換えのない場合（2区間の遅れを足すだけ）と比べました。便の間隔・乗り換えの余裕・1本目の遅れやすさを変えた57通りと、路線2にも同じ遅れが乗る場合も確かめました。**

路線・駅・会社はすべて架空のもので、実在の路線や時刻表は使っていません。遅れの原因（天気・混雑など）は置かず、遅れの分数だけを乱数で作っています。

### 基本：10分おき・余裕2分（20万日、`results/base_cases.csv`）

| 乗り換えなし・2区間の遅れを足す | 1.549分 | 0.064分 | 9.87% | 1.88% | 0.35% | 4.963分 |
| **乗り換え1回** | **2.23分** | 0分 | 18.24% | **16.42%** | 0.93% | 10.0分 |
| 乗り換えなし・3区間の遅れを足す | 2.038分 | 0.787分 | 13.48% | 2.62% | 0.51% | 5.946分 |
| 乗り換え2回 | 3.089分 | 0分 | 25.41% | 23.76% | 2.34% | 10.0分 |

- **乗り換え1回では、10分以上遅れる日が16.42%だった。同じ2区間の遅れを足すだけなら1.88%**。遅れの平均は2.23分で、足し算（1.549分）の1.44倍だった
- 計画の便に乗りそこねた日は16.4%（2便以上乗りそこねた日は0.63%）。10分以上遅れる日の割合がこれとほぼ同じなのは、乗りそこねると次の便（10分後）になるため（作りどおり）
- 中央値はどちらも0分前後で、ふだんの日の遅れは変わらない。違いは、遅れる日の遅れ方がまとまって大きくなること
- 前の便が遅れていて、計画より早い便に乗れた日は0.253%だった

### 式との照らし合わせ：路線2がいつも時刻どおりのとき（20万日、`results/a1032_main.json`）
| | 乱数で数えた値 | 式の値 |
|---|---|---|
| 計画の便に乗りそこねる割合（＝0.35×exp(−余裕2分÷平均3分)） | 17.949% | 17.97% |
| 着く遅れの平均（＝間隔×乗りそこねる割合÷(1−exp(−間隔÷平均3分))） | 1.86分 | 1.863分 |

- 置いた指数分布からの式の値と合った。乗りそこねる割合と遅れの平均は、置いた分布と間隔・余裕から決まる値で、新しく見つけたことではない。数えたのは、その大きさを「遅れの足し算」と並べたときの差と、置き方を変えたときの幅

### 確かめ：1本目の遅れやすさ × 間隔 × 余裕（57通り、各4万日、`results/grid_headway_buffer.csv`）
| | 57通りの幅 |
|---|---|
| 10分以上遅れる日：乗り換え1回 | **0.95〜45.38%** |
| 10分以上遅れる日：乗り換えなし（足し算） | 1.03〜2.74% |
| 5分以上遅れる日：乗り換え1回 | 4.32〜47.19% |
| 5分以上遅れる日：乗り換えなし（足し算） | 6.3〜13.58% |
| 計画の便に乗りそこねた日 | 2.45〜46.41% |
| 遅れの平均：乗り換え1回÷足し算 | 0.36〜4.792倍 |

- 間隔が10分以上の45通りでは、45通りすべてで10分以上遅れる日が足し算より多かった（乗り換え1回で2.46〜45.38%）。5分おきでは乗りそこねても5分しか遅れないので、10分以上の日は少なかった
- 遅れの平均が足し算より大きかったのは57通りのうち39通り。余裕0分では1.485〜4.792倍、余裕6分では0.519〜0.892倍だった。余裕を大きくすると、1本目の遅れは余裕に吸収され、着く遅れは路線2の便の遅れだけになる。ただし、余裕の分だけ計画の所要時間そのものが長くなる（式どおり）。ここでは計画からの遅れだけを数えている
- 1本目が35%の日に遅れる置き方で、余裕2分のとき、乗り換え1回の遅れの平均は5分おきで1.462分、10分おきで2.225分、15分おきで2.985分、20分おきで3.845分と、間隔に比例するように増えた（乗りそこねる割合は16.15〜17.84%でほとんど同じ）

|---|---|---|---|---|---|
| 0（別々に遅れる。基本） | 16.42% | 16.44% | 1.93% | 2.235分 | 1.563分 |
| 0.5 | 8.1% | 8.23% | 1.85% | 1.842分 | 1.556分 |
| 1（同じだけ遅れる） | 0.16% | 1.86% | 1.83% | 1.541分 | 1.552分 |

- 路線2の便も1本目と同じだけ遅れるなら、乗りそこねはほとんど起きず、乗り換え1回は足し算とほぼ同じになった。2つの路線が別々に遅れるときほど、乗り換えで遅れが増える
- k=0 の行は、基本と同じ置き方を別の乱数で20万日数えた値

## 注意（言えないこと）
- 架空のデータです。遅れる日の割合、遅れの分数の分布（指数分布）、便の間隔、歩く時間、乗り換えの余裕は作成者が置いたもので、結果はこれで決まります。乗りそこねる割合と遅れの平均は、置いた分布からの式どおりの値です。実在の路線の遅れを測ったものではありません
- 比べる相手の「乗り換えなし」は、同じ2区間を乗り換えずに走り、遅れが足されるだけと置いた架空の比べ方です。乗り換えのない経路が本当にあるとき、その遅れ方は別です
- 路線2が乗り換えの客を待つこと（接続待ち）、ホームの混雑で歩く時間が延びること、遅れを見て別の経路に変えることは入れていません。1本目の遅れと路線2の遅れの関係は、k の3通りだけを確かめました
- ここで数えたのは計画の時刻からの遅れです。余裕を大きくすると遅れは減りますが、計画の所要時間はその分長くなります。どれだけ余裕をみるべきか、どの経路を使うべきかの助言はしません
- まれに起きるとても大きな遅れや運休は扱っていません
