# F405 事前の計画

作成：2026-11-18 04:15（JST）。国勢調査のファイルは表の形（列の並び）を見ただけで、離島の市町村の人口の増減はまだ集計していない。

## 問い

離島の人口は減っている、とよく言われます。ただ、離島の多くは人口の小さな町村で、本土でも小さな町村は人口が速く減っています。「離島だから速く減っている」のか、「小さくて高齢化した町だから速く減っている」のかは、同じ規模の本土の町と比べないと分かりません。そこで、町全体が離島である市町村と、人口の規模（と高齢化の度合い）をそろえた本土の市町村で、2015→2025年の人口の増減を比べます。

知りたい人：島の仕事・観光・物流・行政に関わる人、地方の人口の記事を書く人。どの島に何をすべきかは扱いません。島を減り方の悪い順に並べることもしません（図や表は北から南の順、または人口の規模別）。

## データ

- 国土交通省「離島振興対策実施地域一覧」（令和8年4月1日現在、PDF）：有人離島と市町村、島ごとの2020年の人口
- 総務省「国勢調査」の「都道府県・市区町村別の主な結果」2015・2020・2025年（Excel）：市町村の人口、年齢3区分、5年前の人口（いまの市町村の境界に組み替えたもの）
- 離島の市町村：一覧の島だけで町全体ができている市町村（島の人口の合計が、その市町村の2020年の人口と一致するもの）。37市町村を見込む
- 本土の市町村：一覧に島が一つでも載っている市町村（一部が島）と、沖縄県・奄美群島・小笠原村（別の法律の離島）を除いた市町村。政令市の区は使わず市で数える

取得前に見たもの：一覧の合計は 77地域・255島・人口33.9万人（2020年）。佐渡市 51,492人、青ヶ島村 169人など、規模の差が大きい。

## 仮説（外れの基準つき）

- H1：離島の市町村の2015→2025年の人口の増減率は、2015年の人口の規模が近い本土の市町村（5つ）の平均より、中央値で3ポイント以上低い。外れ：差が3ポイント未満
- H2：2015年の65歳以上の割合もそろえると、H1 の差は半分以下に縮む（違いの多くは高齢化の度合い）。外れ：縮みが半分未満
- H3：人口5,000人未満の離島の方が、5,000人以上の離島より、本土との差が大きい。外れ：小さい方の差が大きくない
- H4：15〜64歳の人口の減り方は、離島の方が本土より3ポイント以上大きい。外れ：3ポイント未満

## 手法

1. 2025年の境界で、2015→2020年（2020年ファイルの組み替え人口）と2020→2025年（2025年ファイルの組み替え人口）の増減率をつなぎ、2015→2025年の増減率を作る
2. 離島の市町村ごとに、本土の市町村から2015年の人口（対数）が近い5つを選び（重複は可）、その平均と比べる。差の中央値と、ブートストラップ（2,000回、種は 20261116）の95%区間を出す
3. H2 は、2015年の人口（対数）と65歳以上の割合を標準化した距離で近い5つを選ぶ
4. 回帰（増減率 ～ 離島 ＋ 人口の対数 ＋ 65歳以上の割合 ＋ 地方）でも確かめる

## 頑健性（3つ以上）

1. 選ぶ数を5つから10に変える
2. 同じ地方（北海道・東北・関東・中部・近畿・中国・四国・九州）の中だけから選ぶ
3. 期間を2020→2025年だけにする／2010→2025年にのばす
4. 本土の側から、増減率が極端な市町村（上下1%）を除く
5. 回帰で確かめる

## 言えないこと（予想）

- 市町村の一部が島の場合（多くの小さな島）は扱えない。島ごとの人口の推移は一覧に2020年しかない
- 沖縄・奄美・小笠原は別の法律の離島で、この一覧に入っていない
- 減り方の理由（仕事、進学、交通、出生と死亡）は分けられない
- 37市町村と数が少なく、個々の町の事情で差が動く
- 将来の予測ではない
