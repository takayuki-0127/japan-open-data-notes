# 902 分母を「全体」にするか「対象者」にするかで、割合はどう変わるのか？（割合とパーセント）

クーポンの利用率は、「使った人÷会員全体」でも「使った人÷クーポンを送った対象者」でも出せます。対象者を絞った施策ほど、対象者で割った率は高く、全体で割った率は低く出ます。分母が違えば、同じ施策の評価も、施策どうしの比べも変わります。**ここでは、作成者が乱数で作った架空の通販の会社の40回のクーポン施策（対象者の割合と、対象者のうち使う人の本当の割合を作成者が置いたもの）で、2つの分母で施策の順位と2つずつの上下がどれだけ入れかわるか、分母がまざった比べがどれだけ当てにならないかを数え、置き方を変えて確かめました。** 対象を広げていくと2つの率が逆に動く例も、計算で示しました。

どちらの分母が正しいかは、問いで決まります。会員全体で割った率は「会員のうち何%が使ったか」、対象者で割った率は「送った人のうち何%が使ったか」に答えています。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A902 | 会員全体で割るか、対象者で割るかで、施策の順位と上下はどれだけ入れかわるか | 架空の通販の会社の40回のクーポン施策。会員の数は中央値20,000人・対数で標準偏差0.5。対象者の割合はロジットで中央30%・標準偏差0.6、対象者のうち使う人の本当の割合はロジットで中央12%・標準偏差0.6。2つの相関を−0.3と置いた（対象を絞った施策ほど、対象者の利用率が高い）。対象者の数と使った人の数は二項分布で引く。対象者でない会員は使えない。数えたのは、2つの分母での順位の相関（順位どうしの相関）、40回から2つずつ選んだ780組のうち上下が入れかわった組の割合、1位が同じか、上位5回の重なり。ほかに、片方を対象者で割り、もう片方を全体で割って比べた「分母がまざった比べ」。施策を作り直して500回。確かめとして、相関（−0.6・−0.3・0・0.3）×対象者の割合の施策どうしの差（ロジットの標準偏差0.3・0.6・1.0）の12通りを各200回。対象を広げる例は、会員10万人を使いそうな順に並べ、順位 u（0〜1）の人が使う確率を0.40×exp(−4u) と置いて、上から5・10・20・40・80・100%に送ったときの期待値を計算した。seed 902 | `src/a902_denominator.py` |

## 主な結果

### 40回の施策、2つの分母（500回）
| 数えたこと | 平均 | 10〜90%の範囲 |
|---|---|---|
| 順位どうしの相関 | 0.6793 | 0.5557〜0.786 |
| 2つの施策の上下が入れかわった組 | **24.86%** | 20.24〜30.26% |
| 1位が同じだった割合 | 27% | — |
| 上位5回の重なり | 2.364回 | 1〜4回 |

- 2つの施策を比べたとき、4組に1組ほどで「どちらが良いか」の答えが分母で入れかわった
- 1位の施策が2つの分母で同じだったのは500回のうち27%だった

### 1回分（data/campaigns.csv）
- 順位どうしの相関は0.7839、上下が入れかわった組は20.26%。10位以上動いた施策が12.5%あり、いちばん大きく動いた施策は24位動いた
- この回はたまたま1位が同じだった（施策23。対象者の割合31.41%、対象者で割ると30.31%、全体で割ると9.52%）。上位5回で重なったのは1回だった

### 分母がまざった比べ（500回）
| 数えたこと | 平均 | 10〜90%の範囲 |
|---|---|---|
| 対象者で割って報告した側が「上」になった割合 | **94.68%** | 92.05〜97.18% |
| その答えが、対象者どうしで比べた答えと合った割合 | 55.04% | 48.33〜61.94% |
| その答えが、全体どうしで比べた答えと合った割合 | 55.21% | 48.32〜61.81% |

- 片方を対象者で、もう片方を全体で割って比べると、ほとんどの組で対象者で割った側が上に見えた。対象者で割った率は、全体で割った率を対象者の割合（1より小さい）で割った値なので、もともと高く出る。これは式から決まる向きである
- まざった比べの答えは、どちらの分母にそろえた比べとも55%ほどしか合わず、当てずっぽうに近かった

### 対象を広げると（計算の例、results/expand_example.csv）
| 対象者の割合 | 使った人（期待値） | 対象者で割った率 | 全体で割った率 |
|---|---|---|---|
| 5% | 1,812.7人 | 36.25% | 1.81% |
| 10% | 3,296.8人 | 32.97% | 3.3% |
| 20% | 5,506.7人 | 27.53% | 5.51% |
| 40% | 7,981.0人 | 19.95% | 7.98% |
| 80% | 9,592.4人 | 11.99% | 9.59% |
| 100% | 9,816.8人 | 9.82% | 9.82% |

- 対象を広げると、使った人と全体で割った率は増え、対象者で割った率は下がった。使いそうな人から先に送ると置いたため、後から入る人ほど使う確率が低い。この向きは置いた並べ方の写しである
- 同じ施策の「改善」か「悪化」かが、分母の選び方で逆になる

### 確かめ：相関 × 対象者の割合の施策どうしの差（12通り、各200回）
| 相関 | 差 0.3 | 差 0.6 | 差 1.0 |
|---|---|---|---|
| −0.6 | 12.99% | 27.44% | 41.89% |
| −0.3 | 13.09% | 24.54% | 35.06% |
| 0 | 11.85% | 21.11% | 28.86% |
| +0.3 | 10.59% | 17.18% | 22.85% |

（2つの施策の上下が入れかわった組の割合）

- 上下が入れかわった組は、12通りで10.59〜41.89%だった。対象者の割合が施策ごとに大きく違うほど、また対象を絞った施策ほど対象者の利用率が高いと置くほど、入れかわりが増えた
- 順位どうしの相関は0.2273〜0.9292、1位が同じだった割合は9〜66.5%、分母がまざった比べで対象者で割った側が上になった割合は88.61〜96.41%だった

## 動かし方
```
pip install -r requirements.txt
cd src && python a902_denominator.py
```
5秒ほどで終わります。`data/campaigns.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約5秒）
- 分母がまざった比べで対象者で割った側が上に見えるのは、対象者で割った率＝全体で割った率÷対象者の割合という式から決まる向きである。数えたのは、その比べの答えがそろえた比べとどれだけ合わないか
- 上下が入れかわる割合は、置いた「対象者の割合の差」と「相関」で10.59〜41.89%まで動いた。基本の置き方の24.86%を一般の値として読むことはできない

## データ
- `data/campaigns.csv`：架空の40回のクーポン施策（1回分）。campaign・members（会員の数）・targets（対象者の数）・used（使った人の数）・true_target_share・true_use_rate_in_target（作成者が置いた本当の値）・rate_all（全体で割った率）・rate_target（対象者で割った率）・rank_all・rank_target（それぞれの順位）

## 注意（言えないこと）
- 架空のデータです。会員の数、対象者の割合、対象者の利用率とその相関は作成者が置いたもので、結果はこれで決まります。実在の会社の施策を表すものではありません
- どちらの分母が正しいかは問いで決まります。この記事はどちらかをすすめるものではなく、施策の良し悪しやクーポンの出し方の助言もしません
- 対象者でない会員は使えないと置きました。クーポンが転送されるなど対象外の人も使える場合は、2つの率の関係が変わります
- 対象を広げる例は、使いそうな順に送ると置いた計算の値です。でたらめに選んで送るなら、対象者で割った率は広げても変わりません
- 関連する記事 837 は、SNSの投稿の反応率をフォロワー・表示・再生のどれで割るかで、上位の投稿が入れかわることを扱っています。この記事は、送った対象者で割るか全体で割るかと、分母がまざった比べを扱いました
- 同じ企画では、同じ表を逆の向きから割る取り違え（「上位の客の8割が」と「使った客の8割は」）を 904、店ごとの率の平均と合計の率の違いを 900 で扱っています
