# 1023 予約のない枠は、本当に人気がないのか？（予約とキャンセル）

予約の画面で「この枠は予約0件」と出ていると、その枠は人気がないと読みがちです。けれども、予約の数は人気だけで決まりません。受付を始めたのが遅い枠は、人気があっても申し込める日が短く、たまたま0件になることもあります。**ここでは、作成者が乱数で作った架空の陶芸教室2,000教室（1週間に28枠・定員6人。枠ごとの本当の人気と、4分の1の枠は10日前からしか受付しないことを作成者が置いたもの）で、毎週月曜の朝に予約0件だった枠のうち、本当に人気が下位3分の1の枠がどれだけかを数えました。何週か続けて見る場合、件数の合計で選ぶ場合と受付していた1日あたりで選ぶ場合、置き方を変えた27通りも確かめました。**

件数の少ないものほど値が大きく振れる話は関連する記事 801・948、途中から測り始めた項目の比べ方は 977、前日の夜の埋まり具合と当日の着席の差は同じ企画の 1017、同じ人の重複した予約は 1024、予約を締め切る時刻の違いは 1025 で扱っています。この記事は「予約0件の枠を人気がないと読んでよいか」に絞ります。

## 主な結果

### 1週目に予約0件だった枠（基本の置き方、`results/a1023_main.json`）
| | 値 |
|---|---|
| 予約0件の枠の割合 | 14.89%（式の値 14.75%） |
| ふだんの枠のうち0件 | 6.38% |
| 追加の枠のうち0件 | 40.47% |
| 0件の枠のうち追加の枠 | 67.83%（全枠では24.96%） |
| **0件の枠のうち、本当に人気が下位3分の1** | **61.09%** |
| 0件の枠のうち、本当に人気が上位3分の1 | 12.56% |
| ふだんの枠の0件のうち、下位3分の1 | 85.53% |
| 追加の枠の0件のうち、下位3分の1 | 49.5% |

- **1週目に予約0件だった枠のうち、本当に人気が下位3分の1だったのは61.09%だった**。12.56%は人気が上位3分の1の枠だった
- 0件の枠の67.83%は追加の枠で、全枠に占める割合（24.96%）よりずっと多く混ざっていた。追加の枠は受付していた日数が3〜9日と短く、人気があっても0件になりやすい
- 予約0件の割合（14.89%）は、人気と受付していた日数から出る式の値（ポアソン分布で0件になる確率の平均、14.75%）とほぼ合った。0件になる確率そのものは置き方どおりで、新しく数えたのは、0件の枠に何が混ざるか
- 1週目に定員まで埋まった枠は23.76%だった

### 1週目の0件の枠の内訳（0件の枠に占める%）
| | 人気が下位3分の1 | 真ん中 | 上位3分の1 |
|---|---|---|---|
| ふだんの枠 | 27.52% | 4.23% | 0.42% |
| 追加の枠 | 33.57% | 22.12% | 12.14% |

### 何週か続けて見たとき（`results/by_weeks.csv`）
| 見た週の数 | ずっと0件の枠 | そのうち追加の枠 | そのうち人気が下位3分の1 | 件数の合計で選んだときの当たり | 1日あたりで選んだときの当たり |
|---|---|---|---|---|---|
| 1週 | 8,337枠（14.89%） | 67.83% | 61.09% | 56.8% | 64.16% |
| 2週 | 3,440枠（6.14%） | 83.66% | 67.06% | 59.23% | 71.83% |
| 4週 | 1,059枠（1.89%） | 94.52% | 75.45% | **60.26%** | **78.07%** |
| 8週 | 220枠（0.39%） | 97.27% | 87.27% | 60.15% | 83.82% |

- 「当たり」は、全枠の3分の1を「人気のない枠」として選んだとき、そのうち本当に人気が下位3分の1だった割合。でたらめに選ぶと33.33%
- **件数の合計で選ぶと、4週見ても当たりは60.26%、8週でも60.15%で、週を増やしてもほとんど上がらなかった**。選んだ枠の62.02%（4週）が追加の枠で、受付の短さは週を重ねても消えないため
- 受付していた1日あたりで選ぶと、当たりは1週で64.16%、4週で78.07%、8週で83.82%と上がった
- 何週も続けて0件の枠は、ほとんど追加の枠になった（4週で94.52%）。それでも、そのうち人気が下位3分の1だったのは4週で75.45%だった

### 確かめ：人気の平均×追加の枠の割合×人気の散らばり（27通り、各500教室、`results/sensitivity_grid.csv`）
- **1週目の0件の枠のうち人気が下位3分の1だった割合は、置き方で43.24〜96.33%と動いた**。追加の枠がない9通りでは61.69〜96.33%、追加の枠がある18通りでは43.24〜76.75%だった
- 追加の枠がある18通りでは、0件の枠の43.69〜98.91%が追加の枠だった
- 4週で人気のない枠を選んだときの当たりは、件数の合計で43.42〜87.83%、1日あたりで60.42〜88.45%だった。27通りすべてで1日あたりのほうが高かった。追加の枠がないときは差が小さかった（曜日で受付していた日数が21〜27日と少し違う分だけ）
- 予約0件の割合と式の値の差は、27通りで最大0.83ポイントだった
- 人気の平均0.4人で追加の枠がない2通りでは、4週ずっと0件の枠がなかった（`sensitivity_grid.csv` の空欄）

## 動かし方
```
pip install -r requirements.txt
cd src && python a1023_empty_slot.py
```
数秒で終わります。`data/slots.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の7ファイルがバイト単位で一致した（cmp、約2秒）
- 予約0件の割合（14.89%）が、置いた人気と受付していた日数からの式の値（14.75%）と合った。27通りでも差は最大0.83ポイント
- 0件の枠の内訳の6つを足すと100%になる
- 「1日あたりで選ぶほうが件数の合計で選ぶより当たる」は27通りすべてで同じだった。差の大きさは追加の枠の割合で大きく動く

## データ
- `data/slots.csv`：基本の置き方の最初の200教室（5,600枠）。class_id・weekday（1=月〜7=日）・time_slot（1=朝〜4=夜）・late_open（1=追加の枠）・true_rate（本当の人気、受付中の1日あたりの申し込みの平均）・true_tertile（1=下位3分の1〜3=上位3分の1）・open_days（月曜の朝の時点で受付していた日数）・booked_w1〜booked_w8（各週の月曜の朝の予約の数、定員6まで）

## 注意（言えないこと）
- 架空のデータです。人気の分布、追加の枠の割合、受付を始める日、定員は作成者が置いたもので、「61.09%」は置き方で43.24〜96.33%と動きます。実在の教室の予約を測ったものではありません
- 申し込みは、受付している間どの日も同じ起きやすさで来ると置きました。実際には直前に申し込みが集まるなど、日によって起きやすさが違うことがあります。その場合、受付を始めた時期の効き方は変わります（推測）
- 「1日あたり」で選ぶ読み方も、定員で埋まった枠の人気は分かりません。ここでは人気の低い枠を選ぶことだけを比べています
- 追加の枠は、人気と関係なくでたらめに選んだと置きました。人気の時間帯に足すといった選び方があると、結果は変わります
- 枠をなくすべきか、料金をどうするかは扱っていません。予約の数の読み方だけを比べています
