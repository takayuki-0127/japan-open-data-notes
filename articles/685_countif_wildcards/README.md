# 685 Excel の COUNTIF で「*」や「?」を含む品名を数えると、何件を多く数えるのか（実務の型）

Excel の COUNTIF・SUMIF は、条件の文字列の「*」を任意の文字列、「?」を任意の1文字として扱います（ワイルドカード）。品名そのものに「*」や「?」が入っていると、その品名で数えたつもりでも、よく似た別の品名の行まで数えてしまいます。**ここでは、架空の品名マスタ（246品目、うち記号を含む品名18品目）と販売明細3万行で、品名ごとの件数を「完全一致（正解）」「COUNTIF そのまま」「~ で打ち消した COUNTIF」の3通りで数え、多く数えた件数と金額を比べました。** Excel の規則は Python で再現しています（Excel では未検証）。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A685 | COUNTIF のワイルドカードで、何件を多く数えるか | COUNTIF の条件を正規表現に直して再現（* → 任意の文字列、? → 任意の1文字、~* ~? ~~ は文字そのもの、大文字小文字は区別しない、完全一致）。品名ごとに正解・そのまま・「~」で打ち消しの3通りで行数と金額を数える。seed 685 | `src/a685_countif_wildcards.py` |

## 主な結果
| 項目 | 値 |
|---|---|
| 記号を含む品名 | 18品目（「*」12、「?」6） |
| 多く数えた品目 | 12品目 |
| 記号を含む品名の行数（正解 → COUNTIF） | 2,606行 → **6,960行（2.67倍）** |
| 同じく金額（正解 → SUMIF） | 1,681万円 → 4,041万円 |
| いちばん多く数えた品目 | 「ネジM4*12」：正しくは16行、COUNTIF は936行（58.5倍） |
| 倍率の中央値 | 「*」を含む品名 1.64倍、「?」を含む品名 3.78倍 |
| 「~」で打ち消した COUNTIF | 246品目すべて正解と一致 |

- 「ネジM3*10」のように「×」の代わりに「*」を入れた品名は、「ネジM3x10」「ネジM3×10」「ネジM3-10」「ネジM310」の行もまとめて数えた
- 「袋?」のように「?」で終わる品名は、「袋A」「袋B」「袋S」「袋L」もまとめて数えた
- 「お試し*0」のように、似た品名がない場合は多く数えなかった（そのため、気づきにくい）
- 記号のない品名は、どれも正しく数えた

## 確かめたこと
- 空のフォルダで流し直し、results・figures・data が一致した
- 「~」で打ち消した COUNTIF・SUMIF が、すべての品目で完全一致の件数・金額と同じになること（assert）
- 記号のない品名では、3通りがすべて同じになること（assert）

## 注意（言えないこと）

- COUNTIFS・AVERAGEIF・MATCH・VLOOKUP（完全一致）などもワイルドカードを使いますが、ここでは COUNTIF と SUMIF だけを扱いました
