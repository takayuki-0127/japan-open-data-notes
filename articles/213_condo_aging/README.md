# 213 古いマンションの住人の高齢化：マンション総合調査（築年別の比較）

国土交通省「マンション総合調査」（平成30年度・令和5年度）で、マンションの完成年次（築年）ごとに、管理組合の役員の年代、管理組合が挙げる将来の不安、区分所有者の永住意識を比べたフォルダです。同じ完成年次の区分を5年おいた2回の調査で比べ、「同じ建物群が5年たつとどうなるか」を見ています。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A213 | 古いマンションほど住人は高齢か。同じ築年のマンションは5年でどれだけ高齢化したか | 管理組合向け調査「役員の年代別平均人数」から70歳以上の割合を計算し、完成年次の区分ごとに平成30年度と令和5年度を比べる（疑似コホート）。将来の不安・永住意識は令和5年度の完成年次別クロス集計 | `src/a213_condo_aging.py` |

## 主な結果
- 令和5年度、役員のうち70歳以上の割合は、昭和54年以前完成で47.1%、昭和59年以前で40.7%、平成26年以前（〜2014年）で7.9%
- 同じ完成年次の8区分を平成30年度→令和5年度で比べると、7区分で70歳以上の割合が上がり、平均+4.6ポイント（〜昭和59年は32.1%→40.7%）。全体では19.7%→22.5%
- 管理組合運営の将来の不安に「区分所有者の高齢化」を挙げた割合は、昭和54年以前で81.3%、令和2年以降で11.8%。「理事の選任が困難」は昭和49年以前で67.0%
- 永住するつもりの区分所有者は、昭和54年以前・昭和59年以前完成で71%、令和元年以前で43%
- 令和5年度の区分所有者全体では、世帯主が60歳以上の割合は53.7%

```
pip install -r requirements.txt

```

## データ
- `data/mansion_survey_extract_2018_2023.txt`：e-Stat掲載の「マンション総合調査」調査結果（データ編）Excelから、必要な表をCSV形式で抜き出したもの
  - 令和5年度 管理組合向け 10-④(1) 役員の年代別平均人数、46-1 管理組合運営における将来の不安
  - 平成30年度 管理組合向け 11-②(1) 役員の年代別人数
  - 令和5年度 区分所有者向け 5②-(1) 永住・住み替えの意向、1 世帯主の年齢

## 注意
- 完成年次別の「世帯主の年齢」の表は公表されていないため、住人の年齢は管理組合の役員の年代で代わりに見ています。役員は住人全体と同じ年齢構成とは限りません
- 70歳以上の割合は、年代別の「平均人数」（小数1桁）の比で計算しているため、丸めの誤差があります
- 2回の調査は別々の標本で、同じマンションを追いかけたものではありません。区分によっては回答数が100前後と少なく、振れがあります
- 平成30年度と令和5年度では完成年次の一番古い区分・新しい区分の切り方が違うため、共通する8区分だけを比べています
