# 1079 「中心の人」は、中心の測り方で入れかわるのか？（つながり）

社内のやり取りから「中心の人」を探すとき、測り方はいくつもあります。やり取りの相手が多い人、ほかの人どうしの間に入る人、誰にでも少ない手数で届く人、中心の人とつながっている人。どれも「中心」と呼ばれますが、上位に来る人は同じとは限りません。**ここでは、作成者が乱数で作った架空の会社（社員240人・8部署）の1か月のやり取りで、4つの測り方の上位10人がどれだけ重なるかを数え、同じ測り方で翌月にもう一度数えたときの重なりと比べました。部署の外とのつながりやすさ・人ごとのやり取りの多さの差・部署をまたぐ橋渡し役の人数を変えた27通りでも確かめました。**

会社・社員・やり取りはすべて架空のもので、実在の会社や連絡の道具の数字は使っていません。社員は番号だけで表し、人を属性で比べることはしていません。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A1079 | 4つの中心の測り方で、上位10人と1位はどれだけ入れかわるか。その入れかわりは、同じ測り方で翌月に測り直したときより大きいか | 架空の会社。社員240人を8部署（各30人）に置いた。人ごとのやり取りの多さ w を対数正規分布で置いた（対数の標準偏差0.6、平均1）。部署ごとに1人を「部署の人気者」とし w を3倍、人気者以外から6人を「橋渡し役」とし w を0.5にして、ほかの3部署の2人ずつ（計6人）を相手に置いた。部署ごとのやり取りの密さを0.7〜1.3倍で置いた。2人がその月にやり取りする確率は、同じ部署なら 0.2×密さ×w_i×w_j、ちがう部署なら 0.003×w_i×w_j（1を上限）、橋渡し役と相手は0.8とし、向きのないつながりにした。翌月は、同じ置き方からつながりだけを引き直した。測り方は、**相手の数**、**間に入る度合い**（ほかの2人のいちばん短い道のりのうち、その人を通る割合の合計）、**近さ**（ほかの人までの道のりの逆数の平均、届かない人は0）、**中心の人とのつながり**（つながりの表のいちばん大きい固有値の固有ベクトル）の4つ。上位10人（同じ値は番号の若い順）の重なりを2つずつ6組で数え、同じ測り方の1か月目と翌月の重なりと比べた。置いた人気者・橋渡し役が上位10人に何人入るか、上位10人が何部署から来ているかも数えた。会社を作り直して100回の平均。確かめとして、部署の外とのつながりやすさ（0.001・0.003・0.01）×やり取りの多さの差（0.3・0.6・1.0）×橋渡し役の人数（0・6・12人）の27通りを各6回。seed 1079 | `src/a1079_center_measures.py` |

## 主な結果

### 測り方どうしの上位10人の重なり（100回の平均、`results/pairs.csv`）
| 比べた2つの測り方 | 上位10人の重なり | 順位の相関 |
|---|---|---|
| 相手の数 と 近さ | 7.08人 | 0.893 |
| 間に入る度合い と 近さ | 6.84人 | 0.83 |
| 相手の数 と 間に入る度合い | 5.74人 | 0.798 |
| 相手の数 と 中心の人とのつながり | 3.55人 | 0.721 |
| 近さ と 中心の人とのつながり | 3.14人 | 0.779 |
| 間に入る度合い と 中心の人とのつながり | **1.63人** | 0.493 |

- 6組の平均は**4.66人**。4つの測り方すべての上位10人に入った人は平均1.46人で、どれか1つの上位10人に入った人は21.44人だった
- **1位が4つの測り方で同じだった回は13.0%**。1位になった人は平均2.27人いた
- 順位の相関は0.493〜0.893と高めでも、上位10人は入れかわった。相関は全員の並びを見るが、上位10人は上の端だけを見るため

### 同じ測り方で翌月に測り直すと（100回の平均、`results/by_measure.csv`）
| 測り方 | 翌月との上位10人の重なり | 1位が翌月も同じ | 置いた橋渡し役（6人）が上位10人に | 置いた人気者（8人）が上位10人に | 上位10人の部署の数 |
|---|---|---|---|---|---|
| 相手の数 | 6.66人 | 56.0% | 0.0人 | 3.18人 | 5.59 |
| 間に入る度合い | 4.26人 | 37.0% | 0.63人 | 3.12人 | 6.75 |
| 近さ | 4.49人 | 37.0% | 0.28人 | 2.74人 | 5.37 |
| 中心の人とのつながり | 6.17人 | 56.0% | 0.0人 | 1.12人 | **1.37** |

- 同じ測り方で翌月に測り直しても、上位10人の重なりは平均**5.39人**（4つの平均）だった。1か月のやり取りは、同じ置き方からでもたまたまで大きく動く
- 測り方どうしの平均（4.66人）は翌月との平均（5.39人）より少なかったが、その差は小さかった。組によって違い、間に入る度合いと中心の人とのつながり（1.63人）、近さと中心の人とのつながり（3.14人）は、どの測り方の翌月との重なり（4.26〜6.66人）よりも少なかった。相手の数と近さ（7.08人）は、どの測り方の翌月との重なりよりも多かった
- 中心の人とのつながりの上位10人は、平均1.37部署から来ていて、ほぼ1つの部署に集まった。つながりの密な部署の中の人どうしが互いを押し上げるため。いちばん密に置いた部署の人は、そのうち平均3.84人だった
- 間に入る度合いの上位10人は6.75部署に散らばった。ただし、置いた橋渡し役（6人）が入ったのは平均0.63人で、部署の外にもつながりを持つ人気者（3.12人）のほうが多く入った
- 全員どうしが道でつながっていた回は1.0%で、ほとんどの回に、やり取りのない社員がいた

### 確かめ：27通り（各6回、`results/grid.csv`）
- 測り方どうしの重なり（6組の平均）は3.33〜7.25人、同じ測り方の翌月との重なり（4つの平均）は3.67〜7.79人だった
- 測り方どうしの重なりのほうが少なかったのは27通り中19通りで、残る8通り（同じだった通りを含む）では測り方どうしの重なりのほうが多いか同じだった。測り方の違いによる入れかわりが、いつも翌月の入れかわりより大きいとは言えない
- 1位が4つの測り方で同じだった回は、置き方で0〜50.0%
- 相手の数と間に入る度合いの重なりは3.0〜8.67人、相手の数と中心の人とのつながりの重なりは2.33〜6.67人、中心の人とのつながりの上位10人の部署の数は1.0〜4.5だった
- 橋渡し役を0人にしても、相手の数と間に入る度合いの重なりは3.0〜8.67人で、12人のとき（3.83〜8.17人）と幅はほぼ同じだった

## 動かし方
```
pip install -r requirements.txt
cd src && python a1079_center_measures.py
```
1分ほどで終わります。`data/staff_one_run.csv` と `data/ties_one_run.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の10ファイルがバイト単位で一致した（cmp、約40秒）
- 図3枚を開き、日本語・重なり・軸を確かめた（図1・図2の棒は0始まり）
- 間に入る度合いと近さを自分で書いた計算で出しているので、1回分で、つながりの分析によく使われる公開のライブラリの値と照らし、一致することを確かめた（この照らし合わせのコードは src に入れていない）

## データ
- `data/staff_one_run.csv`：基本の置き方の1回分（1か月目）の社員240人。staff_id・dept（架空の部署A部〜H部）・role_set（作成者が置いた役：部署の人気者・橋渡し役・その他）・degree／between／close／eigen（4つの測り方の値）
- `data/ties_one_run.csv`：同じ1回分のつながり（staff_a・staff_b）
- `results/a1079_main.json`：主な結果（`headline` に本文で使った値）
- `results/base_reps.csv`：基本の置き方の100回分
- `results/pairs.csv`：測り方どうしの重なりと順位の相関
- `results/by_measure.csv`：測り方ごとの翌月との重なり・置いた役の入り方・部署の数
- `results/grid.csv`：27通りの確かめ

## 注意（言えないこと）
- 架空のデータです。社員と部署の数、やり取りの多さ、部署の密さ、人気者・橋渡し役の置き方、部署の外とのつながりやすさは作成者が置いたもので、結果はこれで決まります。測り方どうしの重なりは置き方で3.33〜7.25人と動きました。実在の会社のやり取りを表すものではありません
- 「本当の中心の人」は置いていません。どの測り方が正しいかは、何に使うか（連絡を早く広めたい、部署の間をつなぐ人を知りたい、など）で決まります。ここで数えたのは、測り方で顔ぶれがどれだけ違うかだけです
- つながりは1か月にやり取りがあったかどうかだけで、回数や向きは入れていません（向きの数え方は1078で扱っています）
- 中心の値は人の評価には使えません。とくに、記録に残るやり取りの多さは、仕事の内容や役割で決まる面が大きいと考えています（推測）
