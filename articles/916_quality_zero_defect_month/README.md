# 916 「不良0件」の月は、不良率0%と言えるのか？（品質と検査）

月の報告で「今月は不良0件」と出ると、その月の不良率は0%だったと書きたくなります。けれども、不良率が0.1%のラインでも、月に検査する個数が少なければ、不良が1つも出ない月はよくあります。0件から言えるのは「不良率はこの値より低いだろう」という上限までで、その上限は検査した個数で決まります。**ここでは、作成者が乱数で作った架空の工場のライン（本当の不良率と月の検査個数を作成者が置いたもの）で、0件の月がどれだけ出るか、0件の月のラインは本当に不良率が低いか、「0件の月の数」でラインを並べると当たるかを数えました。**

不良率0.1%を確かめるには何個検査すればよいかは関連する記事 909、不良率の月ごとの上下が工程の変化か偶然かは 913、全数検査でも見逃しが残ることは 914 で扱っています。この記事は「0件の月をどう読むか」に絞ります。

## 主な結果

### 本当の不良率0.1%のラインで、検査個数ごとの0件の月
| 月の検査個数 | 0件の月になる確率 | 1年のうち0件の月（平均） | 0件だったときの不良率の95%上限 |
|---|---|---|---|
| 300個 | **74.07%** | 8.89か月 | 0.994% |
| 1,000個 | 36.77% | 4.41か月 | 0.299% |
| 3,000個 | 4.97% | 0.6か月 | 0.100% |
| 10,000個 | ほぼ0%（0.0045%） | 0.0か月 | 0.030% |

- 月300個しか検査しないラインでは、不良率が0.1%でも、1年のうち平均8.89か月が0件になった。0件の確率は式(1−0.001)^300どおりで、20万回の乱数でも74.09%だった
- 月300個で0件だったときに言えるのは「不良率は0.994%以下だろう」までで、0.1%どころか1%近くまでありうる。上限は約3÷検査個数（3の決まり）で、これは式どおりの値
- 0件から「0.1%以下」と言えるのは、月3,000個以上を検査して0件だったときだけ
- この表の上限は、909 の「不良が0個なら何個で言えるか」と同じ式の値です。この記事で新しく数えたのは、次の2つの節（0件の月の数でラインを比べたときのずれ）です

### 検査個数の少ないラインXと、多いラインY（2万年分）
| | X（月500個・本当の不良率0.3%） | Y（月5,000個・0.05%） |
|---|---|---|
| 1年のうち0件の月（平均） | **2.67か月** | 0.97か月 |
| 1年の不良の件数（平均） | 17.98件 | 30.05件 |

- 本当の不良率が6倍のXのほうが、0件の月が多い年が75.91%あった（同じ数の年が14.81%）
- 不良の件数で比べても、Xのほうが少なかった（17.98件と30.05件）。件数は検査個数に比例するので、検査個数の少ないラインが良く見える
- 1年の合計の不良率（件数÷検査個数）で比べると、Xのほうが低く出た年は0%だった

### ライン100本（400回）
| 数えたもの | 値 |
|---|---|
| ライン×月のうち0件の月の割合 | 27.81% |
| 0件の月のうち、本当の不良率0.1%以上のラインのもの | **30.49%** |
| 0件の月で、本当の不良率が95%上限を超えていた割合 | 0.97% |

- 0件の月の3割は、不良率が中央値（0.1%）以上のラインの月だった

- 95%上限は、0件の月のうち上限を超えていたのが0.97%で、5%より少なかった。上限の式は控えめに出るためで、0件の月に「上限◯%以下」と書く読み方は外れにくい

- 0件の月の数がよく当たるのは、検査個数の幅が狭く（1,000〜5,000個）、ラインどうしの不良率の差が大きいとき（散らばり1.2で0.86）だった。検査個数がそろっていれば、0件の月の数は合計の不良率に近づく

## 動かし方
```
pip install -r requirements.txt
cd src && python a916_zero_month.py
```
3秒ほどで終わります。`data/lines_monthly.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約3秒）
- 0件の月になる確率と95%上限は式どおりの値で、新しく数えたものではない（乱数でも式と0.1ポイント以内で一致した）。数えたのは、ラインを並べたときに0件の月の数がどれだけ外れるか
- XとYの比べは、作成者が選んだ2本の写しで、検査個数と不良率の組み合わせで答えは変わる。ライン100本の結果（12通り）のほうが一般的な目安になる

## データ
- `data/lines_monthly.csv`：1回分のライン100本×12か月。line_id・month・inspected（月の検査個数）・defects（不良の件数）・true_rate（作成者が置いた本当の不良率）

## 注意（言えないこと）
- 架空のデータです。ラインの不良率の分布、検査個数の分布は作成者が置いたもので、結果はこれで決まります。実在の工場のラインを数えたものではありません
- 不良は1個ずつ別々に、同じ確率で出ると置きました。不良がまとまって出る（ある日の材料が悪いなど）と、0件の月はさらに増え、1か月の件数は大きく振れるはずです（推測）
- 「0件」が検査をした結果か、検査をしなかった結果かは区別していません。検査個数が記録にないときは、0件の月から不良率について何も言えません
- どの不良率なら良いか、目標をどう決めるかは扱いません
- 関連する記事 909 は、不良率0.1%を確かめるための検査個数を扱っています。この記事は、すでに出た0件の月をどう読むかと、0件の月の数でラインを比べるずれに絞りました
