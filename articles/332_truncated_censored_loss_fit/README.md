# 332 免責や支払いの上限で切られたデータから、元の損害の分布は戻せるのか

保険の支払いの記録には、免責（自己負担）より小さい事故は残らず、支払いの上限を超えた損害は上限の額で残ります。この「切られた記録」に分布をそのまま当てはめるとどれだけずれるか、切られ方を計算に入れると戻せるかを、元の分布が分かる架空のデータで測ったフォルダです。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A332 | 切られた記録をそのまま当てはめると、平均と散らばりは何%ずれるか。切断と打ち切りを入れた最尤法で戻るか。免責を上げるとどうなるか | 対数正規の損害2,000件から、免責以下を消し、上限超えを上限の額にする。①記録をそのまま最尤法、②切断（免責）と打ち切り（上限）を尤度に入れた最尤法、を500回ずつ | `src/a332_truncated.py` |

## データの作り方（架空）
- 元の損害額（万円）：対数正規、中央値30万円、σ=1.2（平均61.6万円、99%点489万円）
- 起きた事故は2,000件。免責（0・5・10・20・50・100万円）以下の事故は記録に残らない。上限500万円を超えた損害（全体の1.0%）は500万円と記録される
- 記録に残る額は損害額そのもの（免責を引く前の額）と置いた
- 乱数の種は332。実在の会社の数字ではありません

## 主な結果（中央値の、正解からのずれ）
| 免責 | 記録から消える割合 | そのまま：平均 | そのまま：σ | そのまま：99%点 | 切られ方を入れる：平均／σ／99%点 | 切られ方を入れる：平均の10〜90%の範囲 |
|---|---|---|---|---|---|---|
| 0万円 | 0% | −1.4% | −0.8% | −2.7% | +0.3%／0.0%／+0.1% | −4〜+5% |
| 5万円 | 7% | −1.1% | −13.1% | −18.2% | +0.2%／−0.1%／+0.3% | −5〜+6% |
| 10万円 | 18% | +8.4% | −23.5% | −24.1% | −0.2%／−0.1%／−0.2% | −5〜+5% |
| 20万円 | 37% | +33.9% | −35.1% | −23.7% | 0.0%／−0.4%／−0.6% | −8〜+8% |
| 50万円 | 66% | +111.7% | −50.0% | −9.9% | −0.9%／−0.2%／−2.5% | −29〜+24% |
| 100万円 | 84% | +230.2% | −61.1% | +10.5% | +1.7%／−1.5%／−2.4% | −82〜+75% |

- **記録をそのまま当てはめると、免責が高いほど平均は高く、散らばり（σ）は小さく出る**。免責20万円で平均+34%・σ−35%
- **切られ方を尤度に入れると、偏りはほぼ消える**（どの免責でも中央値のずれは±2.5%以内）
- **ただし免責が高いと、偏らない代わりに幅が広がる**。免責100万円（事故の84%が消える）では、平均の見積もりの10〜90%の範囲は−82〜+75%。起きた事故が1万件あっても、平均の誤差（RMSE）は30%
- 切り方を分けると、ずれのほとんどは免責の側：免責20万円だけで平均+36.5%、上限500万円だけなら−1.7%
- 上限を200万円に下げる（5.7%が上限に当たる）と、そのままの99%点は−39.5%。切られ方を入れれば−0.2%
- 起きた事故が300件で免責100万円のとき、切られ方を入れた当てはめの1割以上で、σが正解の何倍にもなり平均がほぼ0になった（当てはめが決まらない）

## 動かし方
```
pip install -r requirements.txt
cd src && python a332_truncated.py
```
`data/example_recorded_d20.csv`（免責20万円の記録の例）、`results/main.json`、`results/bias_by_deductible.csv`、`figures/` の3枚ができます（約4分）。

## 確かめたこと
- 空のフォルダで流し直し、data・results・figures がバイト単位で一致した

## 注意（言えないこと）
- すべて架空のデータです。ずれの大きさは、置いた分布（対数正規、中央値30万円、σ=1.2）と免責・上限の位置で決まります
- **切られ方を入れた方法は、当てはめる分布の形が正しいことを前提にしています**。ここでは元の分布と同じ対数正規を当てはめたので戻せました。免責より下の形はデータからは見えないので、形を取り違えると、消えた部分の戻し方も違ってきます（この確かめはしていません）
- 免責や上限が契約ごとに違う場合、免責を引いた後の額だけが残る場合、免責以下でも届け出がある場合は扱っていません
- 平均は「免責を引く前の、すべての事故の平均」で比べました。支払額の平均（免責を引いた後）を知りたいだけなら、記録の平均をそのまま使えます
- 保険の料率や商品の設計について助言するものではありません
