# 1123 失敗するたびに成功率が上がる強化の決まりでは、成功までの回数の平均とばらつきはどれだけ縮むのか？（ゲームの数値設計）

ゲームの装備の強化には、失敗するたびに次の成功率が少しずつ上がり、成功すると元に戻る決まりがあります。成功率が毎回同じ決まりでは、運の悪い人がとても長く失敗し続けることがありますが、成功率が上がる決まりでは、その長い失敗が切られます。**ここでは、作成者が置いた架空のゲームの強化（ゲームの中の素材を1個使って1回試す。はじめの成功率と、失敗ごとに上がる幅を作成者が置いたもの）で、成功までに使う素材の数の平均・ばらつき・遅い人の回数を式で出し、架空のプレイヤー2万人の乱数で確かめました。はじめの率を同じにした場合に加えて、平均の回数をそろえた場合、はじめの率と上がる幅を変えた9通りも数えました。**

例のゲームと強化は作成者が置いた架空のもので、実在のゲームの数値や決まりを表すものではありません。強化はゲームの中の素材で試す決まりとして置き、課金・くじ・賭けの話は扱いません。試すことを勧めたり止めたりする話もしません。

関連する記事：987「『少なくとも1回』の確率は、回数でどう増えるのか？」と 828「ガチャの『1%』を100回引いても当たらない人は、何%いるのか？」は、毎回同じ確率のとき、何回で少なくとも1回起きるかを扱っています。828 は、当たりの入った箱から戻さずに引く決まり（引くほど当たりやすくなる）も確かめています。この記事は、失敗ごとに率が上がる決まりで、成功までの回数の平均とばらつきがどれだけ縮むか、表に出る率と記録から数えた成功の割合がどれだけ違うかに絞ります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A1123 | 失敗するたびに成功率が上がる決まりでは、成功までに使う素材の数の平均・ばらつき（標準偏差）・遅い人の回数は、毎回同じ率の決まりよりどれだけ縮むか。平均をそろえても縮むか | 架空のゲームの強化。1回の試しで素材を1個使う。①決まった率：毎回10%で成功。②上がる率：はじめ10%、失敗するたびに2ポイント上がる（100%で止まる）、成功したら10%に戻る。③平均をそろえた上がる率：②のはじめの率と上がる幅を同じ倍率で下げ、成功までの回数の平均を①と同じ10回にそろえた（はじめ4.38%、失敗ごとに+0.88ポイント）。成功までの回数の分布は式で出した（n 回目で初めて成功する確率＝1回目〜n−1回目の失敗の確率の積×n 回目の成功の率）。架空のプレイヤー2万人がそれぞれ1回成功するまで試す乱数で確かめた。記録から数えた「1回あたりの成功の割合」は、成功の数÷試した回数の合計。確かめに、はじめの率（5・10・20%）×失敗ごとに上がる幅（1・2・5ポイント）の9通りを式で出した（③のそろえ方も同じ）。seed 1123 | `src/a1123_rising_rate.py` |

## 主な結果

### 成功までに使う素材の数（式の値、`results/a1123_main.json`）
| | ①決まった率10% | ②10%から失敗ごとに+2ポイント | ③平均をそろえた（4.38%から+0.88ポイント） |
|---|---|---|---|
| 平均 | 10.0 | **5.823** | 10.0 |
| 標準偏差 | 9.487 | **3.698** | **6.18** |
| 真ん中の人（中央値） | 7 | 5 | 9 |
| 90%の人が成功する数 | 22 | 11 | 19 |
| 99%の人が成功する数 | **44** | **16** | **27** |
| 30回を超えて失敗する人 | 4.24% | 0.0% | 0.32% |
| 必ず成功する回 | なし | 46回目 | 111回目 |
| 1回あたりの成功の割合（記録から数えた値の式） | 10.0% | **17.17%** | 10.0% |

- **はじめの率を同じ10%にして失敗ごとに2ポイント上げると、平均は0.582倍（10.0→5.823回）、標準偏差は0.39倍（9.487→3.698回）に縮んだ**。式どおりの値
- **平均を10回にそろえても、標準偏差は0.651倍（6.18回）に縮んだ**。99%の人が成功する数は44個から27個に下がった。そのかわり、真ん中の人は7個から9個に増え、早く成功する人が減った
- ②では、表に出るはじめの率は10%でも、記録から数えた1回あたりの成功の割合は17.17%だった（式では1÷平均の回数）。失敗が続いた人ほど高い率で試すため
- プレイヤー2万人の乱数では、平均と標準偏差は①10.055回・9.625回、②5.846回・3.686回、③9.96回・6.238回で、式の値と近かった

### 失敗が続いた人の、次の1回の成功の割合（プレイヤー2万人の記録、`results/after_fails.csv`）
| それまでの失敗 | ①決まった率（人数） | ①次に成功した割合 | ②上がる率（人数） | ②次に成功した割合（置いた率） |
|---|---|---|---|---|
| 0回 | 20,000 | 9.7% | 20,000 | 9.62%（10%） |
| 5回 | 11,834 | 10.01% | 9,461 | 20.4%（20%） |
| 10回 | 6,928 | 9.73% | 2,340 | 29.91%（30%） |
| 15回 | 4,160 | 10.53% | 288 | 38.89%（40%） |

- ①では、何回失敗しても次の成功の割合は10%前後のままだった。②では置いた率どおりに上がり、15回失敗した人は288人まで減った
- 20回以上の失敗は②で22人以下しかおらず、割合は振れが大きいので本文では使わない

### 確かめ：置き方を変えると（9通り、式の値、`results/grid.csv`）
| | 9通りの範囲 |
|---|---|
| 平均の比（②÷①） | 0.265〜0.871倍 |
| 標準偏差の比（②÷①） | 0.133〜0.744倍 |
| 標準偏差の比（③平均をそろえた÷①） | **0.528〜0.859倍** |
| 99%の人が成功する数 ①／②／③ | 21〜90個／9〜25個／14〜52個 |
| ②の1回あたりの成功の割合 | 10.87〜29.2%（はじめの率の1.15〜3.78倍） |

- 9通りすべてで、平均をそろえても標準偏差は①より小さかった。上がる幅を大きく、はじめの率を小さく置くほど縮みは大きかった（はじめ5%・+5ポイントで0.528倍、はじめ20%・+1ポイントで0.859倍）
- ②の記録上の成功の割合は、はじめの率5%・+1ポイントでも10.87%と、表に出るはじめの率の2倍を超えた

## 注意（言えないこと）
- 架空のゲームです。はじめの率、上がる幅、成功したら元に戻る決まりは作成者が置いたもので、結果はこれで決まります。平均・標準偏差・99%の人の数は、置いた決まりからの式どおりの値です
- ③の平均のそろえ方は、はじめの率と上がる幅を同じ倍率で下げる1つの形だけです。上がる幅だけを変えるなど、別のそろえ方では縮みは変わります
- 失敗すると素材が減る、強化の段が下がるなどの決まりは入れていません
- 実在のゲームの決まりを表すものではなく、どの決まりがよいかも言えません。この記事は、決まりで回数の平均とばらつきがどう変わるかを数えただけです
