# 917 寸法の平均が規格の中でも、外れる品物は何%あるのか？（品質と検査）

部品の寸法の報告で「平均は50.02mmで、規格（50.00±0.10mm）の中です」と書くと、ほとんどの品物が規格の中にあるように聞こえます。けれども、平均が規格の中にあることと、1個1個が規格の中にあることは別のことで、外れる品物の割合は、ばらつき（標準偏差）と分布の形で決まります。**ここでは、作成者が乱数で作った架空の工場の樹脂部品の長さ（平均・標準偏差・分布の形を作成者が置いたもの）で、平均が規格の中のときに外れる品物が何%あるか、30個・100個の抜き取りでそれを読めるかを数えました。**

平均の待ち時間が5分でも10分以上待つ人がいることは関連する記事 873、平均と中央値の違いは 891、不良率0.1%を確かめるための検査個数は 909 で扱っています。この記事は「寸法の平均と、規格から外れる割合の違い」に絞ります。

## 主な結果

### 正規分布で、平均と標準偏差ごとの外れる割合（式）
| 平均 | 標準偏差0.02mm | 0.03mm | 0.04mm | 0.05mm |
|---|---|---|---|---|
| 50.00mm | ほぼ0%（Cpk 1.67） | 0.086%（1.11） | 1.242%（0.83） | 4.55%（0.67） |
| 50.02mm | 0.003%（1.33） | 0.386%（0.89） | **2.41%（0.67）** | 6.3%（0.53） |
| 50.04mm | 0.135%（1.0） | 2.275%（0.67） | 6.704%（0.5） | 11.762%（0.4） |
| 50.06mm | 2.275%（0.67） | 9.121%（0.44） | 15.869%（0.33） | 21.254%（0.27） |

（かっこの中は Cpk）

- 16通りとも平均は規格の中だが、外れる割合はほぼ0%から21.254%まで動いた。これは正規分布の式の値で、新しく数えたものではない
- 基本の平均50.02mm・標準偏差0.04mmでは2.41%が外れ、そのうち2.275%が上の端（50.10mm）を超え、0.135%が下の端を下回った。平均が上にずれているので、外れはほとんど上の側に出る
- 同じ外れる割合でも、平均と標準偏差の組み合わせは何通りもある（50.04mm・0.03mm と 50.06mm・0.02mm は、どちらも2.275%）。平均だけを見ても、標準偏差だけを見ても、外れる割合は決まらない

### 平均50.02mm・標準偏差0.04mmをそろえた4つの形（各200万個）
| 形 | 外れる割合 | 下の端を下回る | 上の端を超える | 正規分布の式（2.41%）との比 |
|---|---|---|---|---|
| 山が1つ（正規分布） | 2.414% | 0.137% | 2.277% | 1.0 |
| 機械2台の混ざり | **1.502%** | 0.018% | 1.484% | 0.63 |
| すそが重い | 3.049% | 0.671% | 2.378% | 1.25 |
| 片側に長い | **4.234%** | 0.0% | 4.234% | 1.75 |

（比は確かめの表の平均50.02mm・標準偏差0.04mmの行から。各100万個で数え直した値）

- 平均と標準偏差が同じでも、外れる割合は形で1.502〜4.234%まで動いた
- 機械2台の混ざりは、山が2つでてっぺんが平らになり、すそが短いので外れが少なかった。片側に長い形は、長いすそを上の端の側に置いたので、外れが多かった（長いすそを逆の側に置けば少なくなるはず。推測）

### 30個・100個の抜き取りで読むと（4,000回）
| 形 | 本当の外れる割合 | 30個に外れ0個 | 30個から式で推定（中央値、10〜90%） | 100個に外れ0個 | 100個から式で推定（中央値、10〜90%） |
|---|---|---|---|---|---|
| 山が1つ | 2.414% | **48.33%** | 2.36%（0.709〜5.316%） | 8.33% | 2.411%（1.336〜3.822%） |
| 機械2台の混ざり | 1.502% | 63.25% | 2.461%（0.854〜4.906%） | 21.95% | 2.402%（1.435〜3.637%） |
| すそが重い | 3.049% | 39.45% | 1.704%（0.239〜7.081%） | 4.8% | 2.031%（0.73〜4.946%） |
| 片側に長い | 4.234% | 26.35% | 2.114%（0.343〜6.945%） | 1.45% | 2.363%（0.96〜4.684%） |

- 抜き取りの平均は、4つの形・30個でも100個でも、4,000回すべて（100.0%）で規格の中だった
- 30個を抜き取って外れを数えると、正規分布でも48.33%の回で外れが0個だった。「30個すべて規格の中」でも、2.4%が外れる工程はありうる
- 外れの個数を数える読み方は、平均すれば本当の割合に近い（30個で正規分布2.418%、片側に長い4.318%）が、1回ごとには0個か1個かで大きく振れる
- 抜き取りの平均と標準偏差から正規分布の式で出す読み方は、形が正規分布なら中央値で本当の値に近い（30個で2.36%）が、幅が広い（0.709〜5.316%）。形が違うと、100個でも中央値がずれたまま残った（片側に長いで2.363%対本当の4.234%、機械2台の混ざりで2.402%対1.502%）

### 確かめ：平均×標準偏差の9通り×4つの形（各100万個）
| 形 | 本当の外れる割合÷正規分布の式 | 本当の外れる割合 |
|---|---|---|
| 山が1つ（正規分布） | 0.94〜1.01 | 0.081〜11.726% |
| 機械2台の混ざり | 0.05〜1.07 | 0.004〜12.574% |
| すそが重い | 0.77〜10.69 | 0.919〜9.083% |
| 片側に長い | 0.93〜7.33 | 0.63〜11.859% |

（正規分布の式の値は9通りで0.086〜11.762%）

- 正規分布の式とのずれは、外れる割合が小さい置き方ほど大きかった。平均50.00mm・標準偏差0.03mmでは、式は0.086%なのに、すそが重い形では0.919%（10.69倍）、片側に長い形では0.63%（7.33倍）だった。外れが少ない工程ほど、すその形がそのまま外れる割合になる
- 外れる割合が大きい置き方（平均50.04mm・標準偏差0.05mm、式で11.762%）では、形による違いは0.77〜1.07倍に縮んだ

## 動かし方
```
pip install -r requirements.txt
cd src && python a917_out_of_spec.py
```
3秒ほどで終わります。`data/pieces_by_shape.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の9ファイルがバイト単位で一致した（cmp、約3秒）
- 正規分布で外れる割合（表の16通り）は式の値で、新しく数えたものではない。乱数で数えた正規分布の外れる割合（2.414%）は、式（2.41%）と合っていた
- 4つの形の外れる割合の違いは、作成者が選んだ形の写しで、形を変えれば値も変わる。数えたのは、平均と標準偏差をそろえても外れる割合がどれだけ動くかと、抜き取りでそれを読めるか

## データ
- `data/pieces_by_shape.csv`：4つの形ごとに1,000個の部品の長さ。piece_id・shape（形）・length_mm

## 注意（言えないこと）
- 架空のデータです。規格、平均、標準偏差、分布の形は作成者が置いたもので、結果はこれで決まります。実在の工場の部品を数えたものではありません
- 測る道具の誤差は入れていません。測る誤差があると、規格の端の近くの品物は、合否が入れかわります（関連する記事 911 の測りの誤差と同じ仕組み、推測）
- 工程は時間で変わらないと置きました。平均が日によって動く工程では、1日分の標準偏差より全体の標準偏差が大きくなり、外れる割合も増えるはずです（推測）
- どの Cpk なら良いか、規格をどう決めるかは扱いません
- 関連する記事 873 は、待ち時間の平均と長く待つ人の割合の違いを扱っています。この記事は、寸法の平均と規格から外れる割合の違いに絞りました
