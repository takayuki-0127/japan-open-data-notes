# F13 失業率を来月まで予測できるか？ 複数モデルの予測精度を比べる

note：失業率を来月まで予測できるか？ 4つのモデルを21年分のローリング予測で比べると、1か月先は「前月の値」に勝てず、3か月先は求人の情報で誤差が15%減った（看板記事 F13）

## 問い

完全失業率（季節調整値）の1か月先・3か月先を、有効求人倍率や景気動向指数を使ってどこまで当てられるか。いちばん単純な予測「前月の値のまま」に本当に勝てるか。

## データ

| データ | 出典 | 使った系列 |
|---|---|---|
| 労働力調査 長期時系列 表1 a-1 | 総務省統計局（e-Stat） | 完全失業率（季節調整値・原数値）、1975年1月〜2026年8月 |
| 一般職業紹介状況 第3表 | 厚生労働省（e-Stat） | 有効求人倍率（パートを含む一般、季節調整値） |
| 景気動向指数 | 内閣府 経済社会総合研究所 | CI 先行指数・一致指数、一致系列の鉱工業生産指数・労働投入量指数、先行系列の新規求人数（除学卒）・消費者態度指数（いずれも季節調整済み） |

`data/raw/` に 2026-10-26 に取得したファイルを置いています（lfs.xlsx・jobs.xlsx・f13_ci.json）。`data/monthly.csv` は 02 で作る月次の表です。

## 手法

**予測する時点と、使える情報。** 予測を出すのは「T月の失業率が公表された日」（T+1月の月末）とし、そのとき公表済みの値だけを使います。

- 失業率・有効求人倍率・新規求人数・消費者態度指数：T月まで（失業率と有効求人倍率は同じ日に公表）
- CI・鉱工業生産・労働投入量：T−1月まで

目的変数は変化幅 u(T+h) − u(T)（h = 1, 3か月）。

| モデル | 中身 | 学習し直す頻度 |
|---|---|---|
| 前月の値（ナイーブ） | u(T+h) = u(T) | ― |
| AR（失業率だけ） | ARIMA(2,1,0) | 毎月 |
| SARIMAX | ARIMA(2,1,0)＋前月の求人倍率・新規求人数の変化（3か月先は外生変数を「変化なし」と置く） | 毎月 |
| ElasticNet | 22個の特徴量（失業率の過去6か月の変化・求人倍率と新規求人の変化・CI・鉱工業生産など）、正則化の強さは時系列の交差検証 | 毎年1月 |
| LightGBM | 同じ特徴量、木300本・葉15 | 毎年1月 |
| 平均（3モデル） | SARIMAX・ElasticNet・LightGBM の平均 | ― |

- **ローリング評価**：予測の対象月が 2005年1月〜2026年8月（1か月先260回・3か月先258回）。学習は1985年7月から各時点までの拡張窓。
- **評価指標**：平均絶対誤差（MAE、%ポイント）、RMSE、向き（±0.05pt 未満を横ばいとした3区分）の一致率。
- **検定**：Diebold–Mariano 検定（絶対誤差、HAC、Harvey らの小標本補正）で「前月の値」と比べる。

## 主な結果

| | 1か月先 MAE | 前月の値比 | 3か月先 MAE | 前月の値比 | 3か月先の向きの一致率 |
|---|---|---|---|---|---|
| 前月の値（ナイーブ） | 0.083 | 1.00 | 0.128 | 1.00 | 26% |
| AR（失業率だけ） | 0.085 | 1.03（悪い、p=0.03） | 0.130 | 1.02 | 27% |
| SARIMAX | 0.086 | 1.04（悪い、p=0.01） | 0.131 | 1.02 | 27% |
| ElasticNet | 0.083 | 1.00 | **0.109** | **0.85（p=0.01）** | 47% |
| LightGBM | 0.088 | 1.05 | 0.114 | 0.89（p=0.09） | 53% |
| 平均（3モデル） | 0.083 | 1.00 | 0.111 | 0.87（p=0.002） | 48% |

1. **1か月先は、どのモデルも「前月の値」に勝てなかった。** 失業率は0.1ポイント刻みで公表され、2005年以降の月の変化の38%はゼロ、平均の変化幅は0.083ポイント。1か月の動きの多くは、モデルでは読めない細かい揺れでした。
2. **3か月先は、求人の情報を使うと誤差が15%減った**（ElasticNet、DM 検定 p=0.01）。向きが当たった割合も26%から47〜53%に上がった。
3. **効いていたのは求人の情報。** 失業率の過去の動きだけで学習すると、3か月先でも「前月の値」より悪くなる（前月の値比 1.05〜1.07）。重要度は有効求人倍率の水準と6か月の変化、CI 先行の3か月の変化が上位。
4. **ARIMA 系（AR・SARIMAX）は、どちらの期間でも前月の値に届かなかった。** 前月の求人の変化を入れても、ほとんど変わらなかった。
5. **期間別（3か月先 MAE）**：2005〜09年 ナイーブ 0.183 → ElasticNet 0.147、2010〜20年2月 0.116 → LightGBM 0.100、コロナ期 0.164 → 平均 0.108、2022年〜 0.082 → ElasticNet 0.070。
6. **コロナ期**：2020年3〜7月の上がり始めは、どのモデルも3か月前には0.1〜0.4ポイント低く予測した。求人が急に減ったあとの8〜9月は、ElasticNet が0.2ポイント以上高く予測した（上がり過ぎを予測）。

## 頑健性チェック（3か月先、前月の値比）

| チェック | ElasticNet | LightGBM |
|---|---|---|
| 基本 | 0.85 | 0.89 |
| 学習を直近15年だけに | 0.82 | 0.95 |
| 失業率の過去だけ（求人・景気の情報を除く） | 1.05 | 1.07 |
| まだ公表されていない T+1 月の求人・景気の値を使う（リーク） | 0.85 | 0.91 |
| コロナ期（2020年3月〜21年）を除く | 0.87（p=0.04） | 0.91 |

- **原数値（季節調整前）で予測すると**：前月の値の MAE は 0.213 と大きく、SARIMA(1,1,0)(0,1,1)12 は 0.76、ElasticNet は 0.62 と「楽に勝てて見える」。前月の値が季節の動きを無視しているためで、比べる相手を「季節ナイーブ＋直近の差」（0.94）にすると差は小さくなる。比べる相手の選び方で結論が変わる例として載せた。
- **リーク**：公表前の T+1 月の求人倍率を入れても、ほとんど良くならなかった（ElasticNet 0.85 → 0.85）。求人の情報は「その月の値」より「ここ数か月の流れ」として効いている。

## 言えないこと

- 予測が当たることと、失業の仕組みを理解したことは別。重要度は「予測に使われた」ことを示すだけで、因果ではない。
- 失業率は標本調査の推計値で、月々の値には標本による誤差がある。1か月先が当たらないのは、モデルの力不足だけでなく、この誤差の影響もある。
- 季節調整値は、新しい月が加わると過去の値も少し改定される。ここでは 2026年10月時点の値を使っており、当時の公表値（リアルタイムのデータ）で予測した場合とは少し違う。
- 景気動向指数の構成系列も、あとから改定される。
