# 1141 音をつぶして大きくする処理をかけると、平均の大きさと強弱の幅はどう入れかわるのか？（音の大きさ）

曲を大きくするとき、大きいところだけ音量を下げてから（この記事では「つぶす処理」と呼びます）、いちばん大きい瞬間を上限にそろえ直すと、平均の大きさは上がり、そのぶん強弱の幅は縮みます。けれども「強弱の幅」には、打ちの一瞬が周りよりどれだけ大きいか（瞬間の幅）と、静かな部分と盛り上がる部分がどれだけ違うか（部分の差）の、時間の長さの違う2つがあります。どちらを削ると平均が上がるのかは、平均の大きさの数字だけからは分かりません。**ここでは、作成者が式と乱数で作った架空の曲300曲（拍ごとの打ちと、6秒ずつの静かな部分・盛り上がる部分を作成者が置いたもの）に、大きさをならす幅（10ミリ秒・100ミリ秒・1秒・3秒）とつぶす強さ（r＝1〜20）を変えたつぶす処理をかけ、平均の大きさの上がりと、瞬間の幅・部分の差の減りを数えました。曲の強弱の差の置き方3つ×しきい値3つの9通りでも確かめました。**

例の曲はすべて作成者が式と乱数で作った波形で、実在の曲・機材やソフトを表すものではありません。つぶす処理も作成者が置いた簡単なもので、実在の製品のしくみではありません。大きさはすべて数値の計算で、人に聞き比べてもらうことはしていません。

関連する記事：同じ企画の 1140「配信先が決まった大きさまで音量を下げるとき、大きく作った曲は得をするのか？」は、つぶして大きく作った曲を配信先が下げて再生したとき、盛り上がる部分がどうなるかを扱っています。この記事は、配信先を置かず、つぶし方ごとに何が減るかに絞ります。1139「いちばん大きい瞬間の値で音量をそろえると、曲ごとの聞いた大きさはどれだけばらつくのか？」は、いちばん大きい瞬間でそろえると「瞬間の値と平均の強さの差」が曲ごとにそのまま残ることを扱っています。この記事の「平均の上がり＝瞬間の幅の減り＋区間の幅の減り」は、同じ関係を1曲の中で処理の前後に当てはめたものです。1144「上限を超えて切れた部分の割合は、大きさの数字にどう表れるのか？」は、つぶさずに上限で切ったとき、切れた割合が大きさの数字にほとんど表れないことを数えています。

## 主な結果

### つぶす強さ r＝4 で、ならす幅ごと（300曲の平均、`results/by_speed_ratio.csv`）
| ならす幅 | 平均の大きさの上がり | 瞬間の幅の減り | 区間の幅の減り | 部分の差の減り | 3秒ごとの散らばりの減り |
|---|---|---|---|---|---|
| 10ミリ秒 | **+4.86 dB** | 4.38 dB | 0.48 dB | 2.01 dB | 2.1 dB |
| 100ミリ秒 | +2.6 dB | 2.09 dB | 0.51 dB | 2.09 dB | 2.19 dB |
| 1秒 | +0.14 dB | −0.14 dB | 0.29 dB | 1.42 dB | 1.49 dB |
| 3秒 | **+0.08 dB** | −0.16 dB | 0.23 dB | **1.34 dB** | 1.43 dB |

つぶす前は、平均の大きさ −20.34 dB、瞬間の幅 17.96 dB、区間の幅 2.39 dB、部分の差 7.46 dB、3秒ごとの散らばり 7.66 dB（300曲の平均）。

- **平均の大きさの上がりの大半は、瞬間の幅の減りだった**。10ミリ秒では +4.86 dB のうち 4.38 dB、100ミリ秒では +2.6 dB のうち 2.09 dB が瞬間の幅の減りで、残りは区間の幅の減り（この分け方は、いちばん大きい瞬間を上限にそろえ直すことから決まる式どおりのもので、300曲×28通りで誤差 3.55×10⁻¹⁵ dB 以内）。つぶす強さ r を変えた直線の傾きで見ても、平均1 dB の上がりにつき瞬間の幅は 0.88〜0.942 dB 減った（`slopes_per_dB`）
- **ゆっくりつぶす（1秒・3秒）と、部分の差は1.34〜1.42 dB 縮んだのに、平均の大きさは0.08〜0.14 dB しか上がらなかった**。いちばん大きい瞬間は盛り上がる部分の打ちで決まり、その瞬間と周りの差（瞬間の幅）はかえって少し広がった（−0.14〜−0.16 dB）ので、上限にそろえ直しても全体はほとんど持ち上がらない。曲ごとの平均の上がりは、3秒で10〜90%の範囲が −0.62〜+0.61 dB と、下がる曲もあった
- **速くつぶす（10ミリ秒）と、平均は大きく上がるが、部分の差も2.01 dB 縮んだ**。打ちを下げる処理は、打ちの多い盛り上がる部分をより多く下げるため。平均の上がり1 dB あたりの部分の差の減り（傾き）は、10ミリ秒 0.227 dB、100ミリ秒 0.481 dB だった。平均が +3〜+5 dB 上がった組どうしで比べても、部分の差の減りは10ミリ秒 1.88 dB、100ミリ秒 2.44 dB（`gain3to5`）
- つぶす強さを r＝20 まで上げると、10ミリ秒で平均 +5.84 dB・部分の差の減り 2.35 dB、3秒で平均 +0.04 dB・部分の差の減り 1.69 dB だった

### 例の1曲（`figures/a1141_example.png`、`data/example_song_100ms.csv`）
- つぶす前：平均の大きさ −20.62 dB、瞬間の幅 17.69 dB、部分の差 10.04 dB
- 10ミリ秒でつぶす（r＝4）：平均 −15.79 dB、瞬間の幅 13.4 dB、部分の差 7.45 dB
- 3秒でつぶす（r＝4）：平均 −20.71 dB（つぶす前より下がった）、瞬間の幅 18.12 dB、部分の差 8.4 dB

### 確かめ：強弱の差×しきい値（9通り、r＝4、各200曲、`results/grid.csv`）
| ならす幅 | 平均の大きさの上がり（9通りの範囲） | 瞬間の幅の減り | 部分の差の減り |
|---|---|---|---|
| 10ミリ秒 | +1.65〜+5.86 dB | 1.5〜4.85 dB | 0.38〜6.17 dB |
| 100ミリ秒 | +0.04〜+3.52 dB | 0.01〜2.35 dB | 0.06〜6.42 dB |
| 1秒 | 0〜+0.98 dB | −0.19〜0 dB | 0〜6.1 dB |
| 3秒 | −0.07〜+0.75 dB | −0.19〜0 dB | 0〜5.48 dB |

- **9通りすべてで、10ミリ秒でつぶしたほうが3秒より平均が大きく上がり、瞬間の幅も大きく減った**。部分の差が3秒のほうで大きく縮んだ組は0通りだった
- 1秒・3秒で部分の差が0.5 dB 以上縮んだ12組（しきい値 −6・0 dB の6通り×2つの幅）では、部分の差は0.94〜6.1 dB 縮み、平均の大きさの上がりは −0.07〜+0.98 dB と、どれも1 dB に届かなかった
- しきい値 +6 dB では、1秒・3秒でならした大きさがしきい値を超えず、何も変わらなかった（作りどおり）
- 部分の差の減りの大きさは、曲の強弱の差としきい値でほぼ決まった（しきい値 −6 dB・強弱の差が広い曲で大きい）

## 注意（言えないこと）
- 架空のデータです。曲の作り（雑音と拍の打ち、6秒ずつの強弱）、つぶす処理のしくみ（ならし方・しきい値・下げ方）は作成者が置いたもので、結果はこれで決まります。とくに「ゆっくりつぶすと平均が上がらない」のは、いちばん大きい瞬間が盛り上がる部分の打ちで決まる曲を置いたためで、ゆっくりした大きな音が続く曲では違う結果になると考えられます（推測、この記事では数えていません）
- 平均の上がりの分け方（瞬間の幅＋区間の幅）は、いちばん大きい瞬間を上限にそろえ直すことから決まる式どおりのものです。新しく数えたのは、どちらの幅がどれだけ減るかが、ならす幅でどう変わるかです
- 実在の機材やソフトの処理は、下げ始めと戻りの速さが違う、先を読んで下げるなど、もっと複雑です。その分は入っていません
- どのつぶし方がよいかは言えません。人の耳での感じ方も扱っていません。この記事は、つぶし方ごとに数字の上で何が減るかを数えただけです
