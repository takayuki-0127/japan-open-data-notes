# 1226 小さな改善の差は、検索語を何語そろえれば偶然と見分けられるのか？（検索の良さ）

検索を少し直したとき、検索語の一覧で良さを数えて「上がった」と言えるかは、一覧に何語あるかで決まります。検索語ごとの良さは、やさしい語では高く、むずかしい語では低く、大きく散らばります。同じ語で直す前と直したあとを両方出して語ごとの差をとれば、この散らばりは打ち消されます。また、直しが効くのは一部の語だけで、ほかの語では10件がまったく同じになることが多いので、語ごとの差の大半は0です。**ここでは、作成者が置いた架空の社内の文書の集まりと架空の検索語2万語（語ごとに候補の文書215件の「正しさ」を作成者が決め、検索の点を乱数で作ったもの）で、全体の良さを+2ポイント上げる直し（効く語30%）を、n 語の一覧で偶然と見分けられた割合を、同じ語で比べる場合と、直す前と直したあとを別々の語で比べる場合で数えました。改善の大きさ（+0.5・+1・+2ポイント）・効く語の割合・効く語で良くも悪くもなる度合いの27通りで、見分けるのに要る語数も見込みました。**

例の文書・検索語・検索は作成者が置いたもので、実在の検索サービスや社内の仕組みを表すものではありません。

見分けるのに要る語数は、語ごとの差の散らばりと改善の大きさで決まる式（（1.96＋0.84）×散らばり÷改善）の2乗）どおりで、乱数で数えた割合もこの式とおおむね合いました。この記事で数えて新しく分かったのは、検索の良さに固有の、語ごとの差の大半が0になること・語ごとの良さの散らばりが大きいことで、同じ語で比べるか別々の語で比べるかの差がどれだけ大きくなるか、効く語の割合や良くも悪くもなる度合いで要る語数がどれだけ動くか、です。

関連する記事：F236「A/B テストは、何人集めれば「差」が分かるのか？」は、購入の割合の差を人を2つに分けて見つけるのに要る人数を扱っています。この記事は、同じ検索語で2つの検索を両方出せる、検索の比べ方に固有の形に絞ります。1224「1件目に正しい文書があるかだけを数える点と、10件全体を順位で重み付けする点では、2つの検索の差がどう違って見えるのか？」は、同じ2つの検索を1件目の点と10件の点で比べると、200語で差を見分けられた回が48.5%と99.5%と大きく違うことを扱っています。1229「決まった検索語の一覧で調整を重ねると、新しい検索語での良さはどれだけ下がるのか？」は、調整に使った一覧での良さが、一覧の語数や語の型の偏りでどれだけ上ずるかを扱っています。

## 主な結果

### 基本の置き方（効く語30%、全体で+2ポイント）（`results/a1226_main.json` の base）
- A の10件の点の平均は67.24%、B は69.24%（改善+2.0ポイント、効く語の中では+6.66ポイント）
- **語ごとの差は、77.6%の語で0だった**。上がった語は16.98%、下がった語は5.42%
- 語ごとの差の標準偏差は9.73ポイント。語ごとの良さそのものの標準偏差は、A で28.8ポイント、B で28.39ポイントだった

### 語数と見分けられた割合（`results/curve_base.csv`、1,000回）
| 語数（片方あたり） | 同じ語で比べる | 別々の語で比べる |
|---|---|---|
| 25語 | 13.4% | 4.5% |
| 50語 | 35.3% | 5.4% |
| 100語 | 62.2% | 5.9% |
| 200語 | **86.5%** | 9.6% |
| 400語 | 98.8% | 15.9% |
| 800語 | 100% | 30.1% |
| 1,600語 | 100% | 51.0% |
| 3,200語 | 100% | **78.9%** |
| 6,400語 | 100% | 97.6% |

- **式で見込んだ要る語数は、同じ語で比べると186語、別々の語で比べると片方3,210語で、17.26倍だった**。乱数で数えた割合も、同じ語では200語で86.5%、別々の語では3,200語で78.9%と、式とおおむね合った
- 同じ +2ポイントの改善でも、1件目に正しい文書があるかの点（1か0）で数えると、改善は+1.59ポイント、同じ語で比べて要る語数は1,111語と見込まれた
- 改善0のときに偶然の幅を上下どちらかに超えた割合は、50語で3.3%、200語で4.2%、800語で5.2%だった

### 確かめ：27通り（`results/grid.csv`）
| 全体の改善 | 同じ語で比べる（要る語数） | 別々の語で比べる（片方の要る語数） |
|---|---|---|
| +0.5ポイント | 456〜10,099語 | 51,815〜52,257語 |
| +1ポイント | 227〜2,512語 | 12,905〜12,997語 |
| +2ポイント | 102〜623語 | 3,201〜3,232語 |

（式で見込んだ値。2万語より多いものは、この置き方の2万語では足りないことを表す）

- 別々の語で比べると、同じ語で比べるより5.14〜114.05倍の語数が要った
- **同じ語で比べるときに要る語数は、改善の大きさが同じでも、効く語の割合と引き直す乱数の重みで大きく動いた**。+2ポイントでは、効く語10%・重み0.25で151語、効く語60%・重み0.75で623語だった
- 改善の大きさと乱数の重みが同じ9組のうち8組で、効く語が少ないほど要る語数が少なかった。少ない語に大きく効く直しのほうが、多くの語で良くなる語と悪くなる語が入りまじる直しより、差の散らばりが小さかった（置いた形による。+2ポイントのとき、下がった語の割合は、効く語10%・重み0.25で0.01%、効く語60%・重み0.75で18.82%）
- 1件目に正しい文書があるかの点では、10件の点の2.71〜26.46倍の語数が要ると見込まれた
- 式で見込んだ語数で乱数を引いて数えると、見分けられた割合は77.4〜98.4%だった（27通りのうち4通りは80%をわずかに下回った）。効く語10%の置き方では80.4〜98.4%で、見込みより多く見分けられる置き方が多かった。差の大半が0で、少ない語数では標準誤差が小さめに出る回があるため（推測）

## 注意（言えないこと）
- 架空のデータと、作成者が置いた架空の検索です。語ごとの良さの散らばり、直しが効く語の割合、効く語で良くも悪くもなる度合いは作成者が置いたもので、要る語数はこれで決まります。「何語あれば足りる」とは言えません
- 検索語は2万語からでたらめに選ばれると置きました。同じ一覧で何度も調整した場合、よく検索される語に重みを付ける場合、検索語の顔ぶれが時期で変わる場合は入れていません
- 偶然の幅は、差の平均が正規分布に近いとみなす近似です。差の大半が0のときや語数が少ないときは、ずれます
- 正しさは、作成者がすべての候補の文書について間違いなく決めたと置きました。判定していない文書は入れていません
