# 274 季節の山がいちばん大きい業種はどこか

経済産業省「鉱工業指数」の業種別の季節指数（生産、2018〜2025年）で、1年の中の山と谷の差を業種ごとに比べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A274 | 季節の山がいちばん大きい業種はどこか。山と谷は何月か | 業種別の月次の季節指数（`b2020_si1j.xlsx`）を、2018〜2025年の月ごとに平均し、最大と最小の差（ポイント）を振れ幅とした。原指数の前月比の分散のうち、季節調整で取り除かれる分の割合も計算 | `src/a274_seasonal_amplitude.py` |

## 主な結果
- 振れ幅がいちばん大きいのは電気・情報通信機械工業の42.5ポイント（3月127.0、8月84.4）。次が生産用機械工業35.1、汎用・業務用機械工業32.0。小さいのは化学工業10.2、鉄鋼・非鉄金属工業11.9。鉱工業全体は18.3（3月110.2、8月91.9）
- 14業種のうち8業種で山が3月、7業種で谷が8月（4業種は5月）。石油・石炭製品は12月が山（113.0）で6月が谷、食料品・たばこは12月が山（107.4）で1月が谷（85.8）
- 原指数の前月比の揺れ（分散）のうち、季節調整で取り除かれる分は鉱工業で93%。業種別では電気・情報通信機械と食料品・たばこが96%、輸送機械74%、鉄鋼・非鉄金属77%

## 頑健性
- 2018〜2019年だけと2023〜2025年だけで振れ幅を出し、14業種の順位を比べると順位相関0.99。上位3業種は 41.2→40.9、32.2→34.6、31.0→30.0
- 季節指数そのものではなく「原指数÷季節調整済指数」で計算しても、振れ幅の差は最大0.03ポイント
- コードはきれいなフォルダで3回動かし直し、results と figures の全ファイルが一致した

## 動かし方
```
pip install -r requirements.txt
cd src && python a274_seasonal_amplitude.py
```

## データ
- `data/prod_seasonal_2018_2026.csv`：鉱工業指数の Excel（`b2020_si1j.xlsx` 季節指数、`b2020_gsm1j.xlsx` 季節調整済、`b2020_gom1j.xlsx` 原指数、いずれも業種別 月次）から、生産の業種（中分類）を抜き出したもの。2026年の季節指数は見込みの値なので集計に使っていない

## 注意
- 季節指数には、月ごとの稼働日数・曜日の並び・祝日の違いの影響も含まれている（推測：原指数÷季節調整済指数とほぼ一致するため）。「3月に山」が年度末の納入なのか、稼働日の多さなのかは分けていない
- 振れ幅は業種の「平均の月の形」で、年ごとの形は少しずつ違う（図3）
- 業種の中の品目の動きは見ていない。電気・情報通信機械の3月の山がどの品目から来ているかは分からない
- 記事F42（季節調整を自分でやって公表値と比べた）とは別の切り口で、ここでは公表の季節指数を業種どうしで比べただけ
