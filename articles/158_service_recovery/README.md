# 158 サービス産業の売上は、コロナ後どこまで戻ったか：サービス産業動向調査（2018〜2024年の月次）

総務省「サービス産業動向調査」の「時系列 事業活動の産業（中分類）別消費税込み売上高」から、業種ごとの月々の売上を2019年の同じ月と比べ、コロナ禍の落ち込みと戻りを調べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A158 | サービス産業の売上は、コロナ前（2019年）の水準にどこまで戻ったか。業種でどう違うか | 2019年の同じ月を100とした比（季節の違いを取り除く簡単な方法）、年計の2019年比、2020〜22年の最低月との比較 | `src/a158_recovery.py` |

## 主な結果
- サービス産業計の売上（消費税込み）は、2019年の414.7兆円から2020年375.3兆円（−9.5%）に減り、2023年416.1兆円で戻り、2024年は428.5兆円（2019年比103.3）
- 2019年の同じ月を初めて上回ったのは2023年3月。最も落ち込んだのは2020年5月（77.6）
- 2024年の年計（2019年=100）は、航空運輸業・郵便業128、宿泊業118、情報通信業110が高く、飲食店85、旅行業などを含むその他の生活関連サービス業87、バス・タクシー89、教育・学習支援業91は戻っていない
- 宿泊業は2020年5月に19まで落ちたが、2022年12月に2019年同月を上回った。飲食店は2024年12月でも84.5

## 動かし方
```bash
pip install -r requirements.txt
cd src
python a158_recovery.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/service_sales_monthly.csv | 2018年1月〜2024年12月の月次売上（億円、消費税込み）。サービス産業計、大分類9業種、中分類10業種 |

統計局の Excel（https://www.stat.go.jp/data/mssi/zuhyou/tax.xls）をブラウザで読み、上の列を百万円から億円（四捨五入）にして書き写しました。

## 注意
- 名目の売上（値段の上昇を含む）です。宿泊業や航空の2024年の伸びには、料金の上昇も含まれます
- 季節の違いは「2019年の同じ月との比」で取り除いています。X-12-ARIMA などの季節調整値ではありません
- 消費税込みの値で、2019年10月の税率引上げ（8%→10%）の影響が2019年10月以降に含まれます（医療業や社会福祉・介護事業は非課税として計算されています）
- 「4*」の列は航空運輸業と郵便業を合わせたものです
- 使ったファイルは2024年12月分までです
