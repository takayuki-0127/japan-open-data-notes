# 872 前年と質問文を変えた年の比較は、どこまでできるのか？（アンケート）

毎年のアンケートで質問文を変えると、答えは「本当の変化」と「言い回しが変わった分」が混ざって動きます。前年からの増減をそのまま読むと、言い回しの分まで変化と受け取ってしまいます。**ここでは、作成者が乱数で作った架空の会社の社員アンケート（8部署×300人、社員ごとの本当の気持ちと、新しい質問文で答えがどれだけ低く出るかを作成者が置いたもの）で、質問文を変えた年の「満足の割合」の前年比・部署の順位・部署の伸びの順位が、本当の値とどれだけ合うかを数えました。**

「満足」の段階の数（3・5・7段階）を変えたときの割合は関連する記事 868、質問の順番による答えの変化は 862 で扱っています。この記事は「質問文の言い回しを変えた年の、前年との比べ方」に絞ります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A872 | 質問文を変えた年に、満足の割合の前年比・部署の順位・部署の伸びの順位はどこまで正しく読めるか。2年目に半分ずつ前年と新しい質問文で聞き分けると前年比は戻せるか | 架空の会社の8部署×300人。社員ごとの本当の気持ち（見えない値）＝部署の平均（標準偏差0.3）＋人ごとの違い（標準偏差1）。5段階の答えは、気持ちが区切り（−1.5・−0.6・0.2・1.0）をいくつ超えたかで決まる。4以上を「満足」とする。2年目の気持ち＝1年目＋全社の変化0.10＋部署ごとの変化（標準偏差0.15）＋人ごとの揺れ（標準偏差0.3）。新しい質問文では、気持ちが0.30低く出る（言い回しのずれ、基本は全部署共通）。回答率は毎年70%（でたらめに答える）。本当の変化は「2年目も前年と同じ質問文で全員に聞いたら」の満足の割合との差。会社を作り直して1,000回。確かめとして、言い回しのずれ（0・−0.1・−0.3・−0.5）×部署ごとのずれの違い（標準偏差0・0.15・0.3）を各300回、本当の変化（0・0.1・0.2）を各300回。seed 872 | `src/a872_wording.py` |

## 主な結果

### 満足の割合の前年比（ポイント、1,000回）
| 比べ方 | 平均 | 5〜95%の範囲 | 下がって見えた割合 |
|---|---|---|---|
| 本当の変化（同じ質問文なら） | **+3.96** | +0.79〜+7.17 | 2.3% |
| そのまま前年と比べる（質問文を変えた） | **−6.66** | −10.23〜−3.22 | **99.9%** |
| 2年目に半分ずつ聞き分け、前年の質問文の半分で比べる | **+3.91** | −0.18〜+8.25 | 6.3% |

- 本当は満足の割合が+3.96ポイント上がったのに、質問文を変えたまま前年と比べると−6.66ポイントに見え、1,000回のうち99.9%で「下がった」と読めた
- 言い回しのずれの分は−10.60ポイント（全員に両方で聞いた差）。2年目に半分ずつ聞き分けると、新しい質問文の半分と前年の質問文の半分の差から、−10.57ポイント（5〜95%：−14.82〜−6.55）と見積もれた
- 半分ずつの聞き分けで、前年比の平均は本当の値に戻った（+3.91）。ただし人数が半分になるので幅は広がり、6.3%の回で「下がった」と見えた

### 部署の比べ方（8部署、1,000回の平均、本当の順位との順位相関）
| 比べるもの | 質問文を変えたまま | 同じ質問文なら |
|---|---|---|
| 2年目の部署の満足の割合の順位 | 0.944 | 0.963 |
| 部署の伸び（前年からの変化）の順位 | 0.781 | 0.855 |

- 順位相関（スピアマンの順位相関）は、2つの順位がどれだけ同じ並びかを−1〜1で表す。1なら完全に同じ順
- 言い回しのずれが全部署で同じなら、同じ年の中の部署の順位はほぼ保たれた（0.944）。部署の伸びの順位は0.855から0.781に下がった（満足の割合は区切りの近くにいる人の多さで動き方が変わり、同じずれでも部署ごとに下がり幅が違うため）
- 部署ごとの「前年より下がった」は、質問文を変えたまま読むと平均86.2%の部署、本当は23.4%の部署だった

### 確かめ：言い回しのずれ×部署ごとの違い（各300回）
| 言い回しのずれ | 部署ごとの違い | 本当の変化 | そのまま前年と比べた変化 | 下がって見えた割合 | 2年目の部署の順位 | 部署の伸びの順位 |
|---|---|---|---|---|---|---|
| 0（同じ） | 0 | +3.96 | +3.92 | 3.7% | 0.962 | 0.844 |
| −0.1 | 0 | +4.22 | +0.71 | 33.7% | 0.956 | 0.829 |
| −0.3（基本） | 0 | +3.94 | −6.68 | 100% | 0.939 | 0.787 |
| −0.5 | 0 | +3.99 | −13.06 | 100% | 0.937 | 0.705 |
| −0.3 | 0.15 | +4.08 | −6.19 | 99.3% | 0.831 | 0.597 |
| −0.3 | 0.3 | +3.95 | −5.85 | 91.3% | 0.659 | 0.380 |
| 0（平均は同じ） | 0.3 | +4.01 | +4.18 | 16.3% | 0.672 | 0.376 |

- 言い回しのずれが−0.1（気持ちの標準偏差の1割）でも、+4ポイントほどの本当の上がり幅は+0.71にまで縮んで見えた
- **言い回しのずれが部署ごとに違うと、部署の順位も崩れた**。部署ごとの違いが0.3だと、2年目の部署の順位は0.66〜0.68、部署の伸びの順位は0.35〜0.41だった。全社の平均のずれが0でも同じだった（全12通りは `results/sensitivity_wording.csv`）
- 同じ質問文なら、部署の伸びの順位は12通りすべてで0.84〜0.86だった。0.86ほどで止まるのは、各部署210人ほどの回答の偶然の揺れの分

### 確かめ：本当の変化の大きさ（言い回しのずれ−0.3、各300回）
| 置いた全社の変化 | 本当の変化 | そのまま前年と比べた変化 | 半分ずつ聞き分け（5〜95%） | 聞き分けで下がって見えた割合 |
|---|---|---|---|---|
| 0 | +0.48 | −9.92 | +0.56（−3.32〜+4.57） | 43.7% |
| 0.1（基本） | +4.11 | −6.41 | +4.16（−0.19〜+8.41） | 6.0% |
| 0.2 | +7.65 | −3.14 | +7.71（+3.78〜+12.40） | 0% |

- 全社の変化を0と置いても本当の変化が+0.48になるのは、人ごとの揺れを足したので、区切り（0.2）を超える人が少し増えるため

### 1回分のデータ（data/employees.csv）
- 全員の満足の割合は1年目48.3%、2年目（前年と同じ質問文なら）54.8%で、本当は+6.5ポイント上がった。回答者で見ると、1年目47.1%（前年の質問文）、2年目42.3%（新しい質問文）で、−4.8ポイントに見えた

## 動かし方

```
pip install -r requirements.txt
cd src && python a872_wording.py
```

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約10秒）
- 言い回しのずれを0〜−0.5に変えると、そのまま前年と比べた変化は+3.92〜−13.06ポイントと大きく動いた。「−6.66」は置いたずれ（−0.3）での値で、前年比の読み違いの大きさは置いたずれの写しに近い
- 半分ずつの聞き分けの前年比は、本当の変化を0・0.1・0.2のどれに置いても、平均で本当の値から0.1ポイント以内だった
- 基本の置き方のそのままの前年比は、本表（1,000回）で−6.66、確かめ（別の乱数で300回）で−6.68と−6.41だった

## データ
- `data/employees.csv`：架空の社員2,400人（1回分）。emp_id・dept（部署A〜H）・y1_answer_old（1年目の答え、前年の質問文）・y2_answer_old（2年目に前年の質問文で聞いたら）・y2_answer_new（2年目の新しい質問文での答え）・y1_responded／y2_responded（回答したか）・y2_split_old_half（半分ずつ聞き分けるとき前年の質問文の側か）

## 注意（言えないこと）
- 架空のデータです。言い回しのずれの大きさ、部署ごとの違い、本当の変化、5段階の区切りは作成者が置いたもので、結果はこれで決まります。実際に質問文を変えると答えがどれだけ動くかは、質問文しだいで、ここでは測っていません
- 言い回しのずれは、気持ちが一定の量だけ低く（または高く）出る形だけを置きました。答えのばらつきが変わる、「どちらでもない」が増える、といった変わり方は入れていません（段階の数の違いは関連する記事 868）
- 回答する人はでたらめに選ばれると置きました。満足している人ほど答える偏りは入れていません（謝礼と回答者の構成は関連する記事 870）
- 半分ずつの聞き分けは、2つの質問文の差を見積もる1つのやり方です。人数が少ないと幅が広がり、部署ごとの差まで見積もるにはさらに人数が要ります（推測）
- 実在の会社やアンケートを表すものではありません
