# 842 表示が増えると、クリック率は下がって見えるのか？（SNSと動画）

SNSの投稿は、まずフォロワーに表示され、反応が良いとおすすめに乗って、興味の遠い人にまで表示が広がります。フォロワーはクリックしやすく、遠い人はクリックしにくいので、表示が広がった投稿ほど、全体のクリック率（クリック数 ÷ 表示回数）は下がって見えます。**ここでは、作成者が乱数で作った架空のSNSアカウントの投稿300本（投稿ごとの「本当の引きの強さ」と、相手ごとのクリックのしやすさを作成者が置いたもの）で、全体のクリック率・フォロワーだけのクリック率・相手の内訳でそろえたクリック率の3つが、本当に引きの強い投稿をどれだけ当てるかを数えました。**

反応率の分母（フォロワー・表示・再生）の選び方は関連する記事 837 で扱っています。流入元の違う再生数を合わせる関連する記事 847 も「分けるとどれも上なのに、合わせると下」という同じ形を扱いますが、847 は流入元の内訳が月や動画で外から変わる場合です。この記事は、投稿の引きの強さそのものが表示を遠い人に広げるため、良い投稿ほど全体のクリック率が下がって見える、という結びつきに絞ります。

## 主な結果

### 表示回数の帯ごと（1回分、投稿300本を表示回数で5つに分けた）
| 表示回数 | 表示回数（中央値） | 本当の引きの強さ（平均） | 全体のクリック率 | フォロワーだけのクリック率 | 表示のうちフォロワーの割合 |
|---|---|---|---|---|---|
| 少ない5分の1 | 3,883回 | 0.60 | 3.01% | 3.57% | 76.5% |
| 2 | 5,578回 | 0.80 | 3.26% | 4.78% | 53.2% |
| 3 | 9,257回 | 0.98 | 3.13% | 5.87% | 32.2% |
| 4 | 16,025回 | 1.20 | 2.95% | 7.18% | 16.7% |
| 多い5分の1 | 45,564回 | 1.61 | **2.83%** | **9.69%** | 3.2% |

- 表示の多い5分の1は、少ない5分の1より本当の引きが2.7倍強いのに、全体のクリック率は3.01%→2.83%と少し下がった。フォロワーだけで見ると3.57%→9.69%と大きく上がった
- 表示の多い投稿ほど、表示のほとんどがクリックしにくい遠い興味の人になる

### 例の2本
| | 表示が上位1割の投稿（中ほどの1本） | 表示が中くらいの投稿 |
|---|---|---|
| 本当の引きの強さ | 1.63 | 0.99 |
| 表示回数 | 81,288回 | 9,250回 |
| フォロワーのクリック率 | **10.1%** | 5.7% |
| 近い興味のクリック率 | **4.1%** | 2.5% |
| 遠い興味のクリック率 | **1.6%** | 1.3% |
| 全体のクリック率 | 2.3% | **3.4%** |

- どの相手でもクリック率が上なのに、全体では下になった。表示の内訳が、上位1割の投稿は81%が遠い興味、中くらいの投稿は37%がフォロワーだったため

### 指標ごとに、本当の上位30本をどれだけ当てたか（投稿300本、50回の平均）
| 指標 | 上位30本の当たり（10〜90%の範囲） |
|---|---|
| 全体のクリック率 | **8.9%**（3.3〜16.7%） |
| フォロワーだけのクリック率 | 88.5%（83.3〜93.3%） |
| 相手の内訳でそろえたクリック率 | 81.7%（73.3〜87.0%） |

- 表示回数と全体のクリック率の順位の相関は、50回の平均で −0.34（−0.46〜−0.24）。1回分では −0.19 で、表示回数と本当の引きの強さの順位の相関は 0.95 だった
- 全体のクリック率の当たり（8.9%）は、でたらめに選んだとき（10%）と同じくらいだった

### 確かめ：置き方を変えても（各50回の平均）
| 置き方 | 表示回数と全体のクリック率の相関 | 全体のクリック率の当たり | フォロワーだけの当たり | 内訳でそろえた当たり |
|---|---|---|---|---|
| 基本（6%・2.5%・1%、広がり3乗・5乗） | −0.35 | 8.4% | 87.7% | 82.1% |
| 相手の差を小さく（6%・4.5%・3.5%） | **+0.82** | 84.0% | 88.2% | 86.5% |
| 相手の差なし（どこでも6%） | +0.94 | 96.0% | 88.1% | 88.0% |
| 広がりを弱く（1乗・2乗） | +0.17 | 47.6% | 87.8% | 89.8% |
| 引きの強さの差を小さく（0.2） | −0.56 | 5.5% | 78.1% | 81.8% |

- **「表示が増えるとクリック率が下がって見える」は、相手どうしのクリック率の差が大きく、表示が引きの強さで大きく広がるときに起きた**。相手の差が小さい置き方では、表示の多い投稿ほど全体のクリック率も高く、全体のクリック率でも84.0%当たった
- フォロワーだけのクリック率と、相手の内訳でそろえたクリック率は、どの置き方でも78〜90%当たった

- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の8ファイルがバイト単位で一致した（cmp、約6秒）

## 注意（言えないこと）
- 架空のデータです。相手ごとのクリック率（6%・2.5%・1%）、表示の広がり方（3乗・5乗）、引きの強さの散らばりは作成者が置いたもので、結果はこれで決まります。とくに「下がって見える」かどうかは、相手どうしのクリック率の差で逆転します（確かめの表）
- 引きの強さは、どの相手にも同じ倍率で効くと置きました。フォロワーには受けるが遠い人には受けない投稿のような、相手によって効き方が違う投稿は入れていません
- 相手の内訳でそろえたクリック率は、アカウント全体の相手ごとのクリック率を使います。表示の内訳が手元で分からないときは使えません
- 1本の投稿の中で、時間とともに表示が広がっていく流れ（はじめはフォロワー、あとから遠い人）は数えていません。推測ですが、同じ形で、1本の投稿のクリック率も日がたつほど下がって見えると考えられます
- 実際のSNSのおすすめの仕組みやクリック率の出し方を表すものではありません
