# 145 国籍・地域別に、訪日客は何にお金を使っているか：インバウンド消費動向調査の費目別支出と対応分析

観光庁「インバウンド消費動向調査」（2023年以前は「訪日外国人消費動向調査」）の年間（暦年）集計表から、国籍・地域（21区分）別の費目別1人1回当たり旅行支出を取り出し、2019・2023・2024・2025年で比べたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A145 | 国籍・地域で、宿泊・飲食・交通・娯楽・買物への支出の配分はどう違い、2019年からどう変わったか。買物の中身は国でどう分かれるか | 費目別の構成比、2019年と2025年の比較、買物16品目×20の国籍・地域の対応分析（SVD） | `src/a145_inbound.py` |

## 主な結果
- 2025年の1人当たり旅行支出は全体で22.9万円。宿泊費36.7%、買物代26.7%、飲食費22.0%、交通費10.0%、娯楽等サービス費4.5%
- 欧米豪8か国（単純平均）は36.4万円で、宿泊費が43.8%、買物代は16.5%。東・東南アジア10か国・地域は22.1万円で、宿泊費35.7%、買物代29.4%
- 2019年→2025年で、全体の買物代の割合は33.6%→26.7%、宿泊費は29.9%→36.7%。中国は買物代が10.9万円→9.1万円（51.1%→37.1%）と、額でも減った。英国・米国・オーストラリアは買物代が2倍以上になった
- 買物の中身の対応分析（第1軸38%）：医薬品・健康グッズ・化粧品が台湾・中国・ベトナムなど、民芸品・ソフトウェア・本・酒類がドイツ・イタリア・スペイン・フランスなどの側に並んだ。第2軸（24%）は時計・宝石とシンガポール


## データ
| ファイル | 中身 |
|---|---|
| data/spending_by_item.csv | 年（2019・2023・2024・2025）×費目（全体・宿泊費・飲食費・交通費・娯楽等サービス費・買物代・その他）×国籍・地域の1人1回当たり旅行支出（円） |
| data/shopping_items_2025.csv | 2025年の買物代の内訳（16品目）×国籍・地域（円） |

いずれも各年の集計表（暦年・確報）のシート「参考2 国籍・地域（21区分）別 費目別１人１回当たり旅行消費単価（パッケージツアー参加費内訳含む）」の「消費単価」を、円単位に丸めて写したものです。元のファイル：2019年 002020401.xls、2023年 002020300.xls、2024年 002022649.xls、2025年 002025515.xls（https://www.mlit.go.jp/kankocho/content/<ファイル名>）。

## 注意
- 一般客（クルーズ客を除く）・全目的の値です。観光目的だけに絞ると数字は変わります
- 2024年4-6月期から調査が「インバウンド消費動向調査」に変わり、調査方法の一部が変わっています。2019年との比較は目安です
- パッケージツアー参加費は、観光庁の推計で各費目に割り振った値を含みます
- 1人当たりの平均で、訪日客の人数（国籍別の総額）は考えていません。滞在日数の違い（欧米豪は長い）も、宿泊費の割合に効いています
- 対応分析は「買物の中身の比率」の違いを見るもので、買物の額の大小は反映しません
