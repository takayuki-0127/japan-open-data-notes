# 214 季節パターンで都道府県を分ける：宿泊旅行統計の月別延べ宿泊者数

観光庁「宿泊旅行統計調査」（2019年・2025年の年確定値）の都道府県別・月別の延べ宿泊者数から、1日当たりの宿泊者数を年平均＝100とした季節指数をつくり、季節の形が似た都道府県をグループに分けたフォルダです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A214 | 宿泊の季節の形で都道府県はどう分かれるか | 月別延べ宿泊者数÷日数を年平均＝100に指数化（12次元）。Ward法の階層クラスタリングで5グループ。振れ幅（最大月−最小月）、2019年との相関、2019年のクラスタとの一致度（ARI） | `src/a214_season.py` |

## 主な結果
- 全国では8月が120で最も多く、1月が87で最も少ない（2025年）
- 5つのグループ：7〜8月に強く集中（山梨、8月185）、8月と10月に集中（富山・秋田・青森）、夏と秋に山があり冬が少ない（京都・石川・島根など14府県）、冬にも山がある・4月が底（北海道・長野・新潟・沖縄・群馬・山形・岩手）、1年を通して差が小さい（東京・大阪・福岡など22都府県）
- 季節の振れ幅が大きいのは山梨116、富山90、福井80、長野76。小さいのは東京15、福岡19、大阪20
- ピークが8月でないのは京都（4月）、石川・広島・愛媛・福岡・熊本・鹿児島（11月）、東京（12月）、奈良（5月）、大分（3月）
- 2019年と2025年の季節指数の相関は中央値0.87と形はおおむね同じ。クラスタの一致度（ARI）は0.61

## 動かし方
```
pip install -r requirements.txt
cd src && python a214_season.py
```

## データ
- `data/lodging_monthly_pref_2019_2025.csv`：宿泊旅行統計調査 年確定値の第2表（月別・施設所在地別の延べ宿泊者数）から、都道府県×月の延べ宿泊者数（total）、観光目的の宿泊者が50%以上／未満の施設の内訳（tour50／nontour50）、外国人延べ宿泊者数（foreign）を抜き出したもの（人泊）

## 注意
- 当初は「共通基準による観光入込客統計」の期別データを使う予定でしたが、2022年は23／46都道府県、2023年は4〜8都道府県しか集計されていないため、47都道府県がそろう宿泊旅行統計に替えました。日帰り客は含みません
- 季節指数は宿泊者の数の形で、観光客だけでなく出張などの宿泊も含みます
- クラスタの数（5）は解釈しやすさで決めたもので、別の数にすると分かれ方は変わります。2019年と2025年でグループの顔ぶれが一部入れ替わります
