# 875 「混んでいる」と感じる人の割合は、実際の混み具合と合うのか？（待ち時間と混雑）

店が「混み具合」を数えるときは、ふつう営業時間の中の平均（どの時刻も同じ重み）を見ます。一方、客に「混んでいましたか」と聞くと、答えるのは来た客です。混む時間ほど客は多いので、客は混んだ時間を多めに体験しています。**ここでは、作成者が乱数で作った架空の店（客の来方・店にいる時間・「混んでいる」と感じる線を作成者が置いたもの）で、時間で数えた混み具合と、客に聞いた「混んでいる」の割合を比べました。同じ人ごとの線を使い、重みだけを「時間」と「客」で変えて、ずれの大きさを数えました。**

待ち時間の平均と長い待ちの割合は関連する記事 873、利用率と待ち時間は 874、誰の待ちを数えるか（来た客全員の平均と、今並ぶ人の待ち）は 881 で扱っています。この記事は「混雑の感じ方を聞いた割合と、店が数える混み具合のずれ」に絞ります。

## 主な結果

### 時間で数える値と、客に聞く値（基本の置き方、350日）
| | 時間で数える（どの時刻も同じ重み） | 客に聞く（来た客1人ずつ同じ重み） |
|---|---|---|
| 混み具合の平均 | 84.4% | **96.6%** |
| 混み具合が線（90%）を超えていた割合 | 38.4% | 53.1% |
| 「混んでいる」の割合（人ごとの線） | 40.4% | **53.2%** |

- **同じ店・同じ日々・同じ人ごとの線でも、客に聞いた「混んでいる」は53.2%で、時間で数えた40.4%より12.8ポイント高かった**。客が混んだ時間に多くいるので、客の平均の混み具合（96.6%）は、時間の平均（84.4%）より高く出た
- 平日だけで見ても、時間で数える「混んでいる」は29.9%、客に聞くと39.4%だった。週末だけでは66.8%と77.2%
- 週末は日数では28.6%だが、客の数では36.5%を占めた。混む日に客が多いことも、客に聞いた割合を押し上げた

### 確かめ：山の強さ×線の平均（各350日）
| 客の来方 | 線の平均 | 時間で数える「混んでいる」 | 客に聞く「混んでいる」 | 差（ポイント） |
|---|---|---|---|---|
| 山なし | 0.7 | 69.4% | 76.6% | +7.2 |
| 山なし | 0.9 | 38.3% | 44.7% | +6.4 |
| 山なし | 1.1 | 18.1% | 23.5% | +5.4 |
| 昼と夕方に山（基本） | 0.7 | 62.8% | 74.7% | +11.9 |
| 昼と夕方に山（基本） | 0.9 | 40.4% | 53.2% | +12.8 |
| 昼と夕方に山（基本） | 1.1 | 21.4% | 31.2% | +9.8 |
| 強い山 | 0.7 | 53.2% | 73.3% | +20.1 |
| 強い山 | 0.9 | 38.1% | 59.6% | +21.5 |
| 強い山 | 1.1 | 27.3% | 46.8% | +19.5 |

- **9通りすべてで、客に聞いた割合のほうが高かった（+5.4〜+21.5ポイント）**。差の大きさは、ほぼ山の強さで決まった
- 山なしでも差が残ったのは、週末・日ごとの揺れで混む日に客が多いこと、開店直後と閉店前の空いている時間に客が少ないことによると考えられる（推測）
- この差は、「時間で平均するか、客で平均するか」の定義の違いから必ず出る向きで、大きさは作成者が置いた山の強さの写しに近い

### 日ごとに見ると（基本の置き方）
| その日の混み具合の平均（時間で数える） | 日数 | 「混んでいる」と答えた割合の平均 | いちばん低い日〜高い日 |
|---|---|---|---|
| 50〜60% | 11 | 11.1% | 5.6〜18.2% |
| 60〜70% | 61 | 23.7% | 12.4〜31.9% |
| 70〜80% | 110 | 38.0% | 26.8〜48.1% |
| 80〜90% | 64 | 51.9% | 43.7〜60.0% |
| 90〜100% | 30 | 65.0% | 57.2〜72.2% |
| 100%以上 | 74 | 81.0% | 68.1〜97.9% |

- 同じ店の中では、日ごとの順番はよく合った（順位相関0.993。山なしで0.997、強い山で0.980）。順位相関は、2つの順位がどれだけ同じ並びかを−1〜1で表す値
- ただし「混んでいる」の割合は、混み具合の%と同じ数にはならず、70〜80%の日でも26.8〜48.1%と幅があった

### 山の形が違う店どうしでは（日の混み具合の平均がほぼ同じ日どうし）
| その日の混み具合の平均 | 山なし | 昼と夕方に山 | 強い山 |
|---|---|---|---|
| 65〜75% | 16.7% | 31.1% | 49.4% |
| 75〜85% | 33.4% | 45.2% | 57.3% |
| 105〜115% | 89.0% | 79.0% | 72.6% |

- 時間で数えた混み具合が同じ日でも、空いている日（75〜85%）には山の強い店ほど「混んでいる」が多かった（33.4%→57.3%）
- **混む日（105〜115%）には向きが逆になり**、山なしの店のほうが多かった（89.0%と72.6%）。山なしの店は1日中線を超え、山の強い店は空いた時間帯の客が「混んでいない」と答えるため（推測）
- 店どうしを「混んでいる」の割合で比べると、混み具合の順と逆になることがある

## データ
- `data/days_base.csv`：基本の置き方の350日。day・weekend（週末か）・customers（客の数）・time_mean_ratio（時間で数えた混み具合の平均）・time_share_over_line（線0.9を超えた時間の割合）・time_weighted_felt（時間で数えた「混んでいる」の割合）・cust_mean_ratio（客の平均の混み具合）・cust_share_over_line・felt_share（客が「混んでいる」と答えた割合）・peak_ratio（その日のいちばん高い混み具合）
- `data/one_day_people.csv`：ある週末の1日の、0.5分ごとの店にいる人数（time_min・people）
- `data/one_day_customers.csv`：同じ日の客1,907人。arrival（開店からの来た時刻、分）・stay（店にいた時間、分）・experienced_ratio（いた間の混み具合の平均）・threshold（その人の線）・felt_crowded（「混んでいる」と答えたか）

## 注意（言えないこと）
- 架空のデータです。客の数、来方の山、店にいる時間、「混んでいる」と感じる線は作成者が置いたもので、結果はこれで決まります。人に聞いた調査ではありません
- 客は、自分がいた間の混み具合の平均で答えると置きました。いちばん混んだ瞬間やレジの待ちで答える人がいれば、客に聞いた割合はもっと高く出ます（推測）
- 全員が答えると置きました。混んで不満だった人ほど答えやすいといった、答える人の偏りは入れていません（謝礼で答える人の顔ぶれが変わる話は関連する記事 870）
- 混んでいると店にいる時間が変わる、混んでいるのを見て帰る、といった客の動きは入れていません
- 実在の店の混み具合や客の声を表すものではありません
