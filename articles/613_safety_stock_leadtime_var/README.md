# 613 安全在庫を需要のばらつきだけで決めると、届くまでの日数がばらつくとき欠品は何%になるのか（実務の型・安全在庫の式）

発注点（在庫がこれを下回ったら発注する量）は、「届くまでの平均の需要＋安全在庫」で決めます。教科書によく出る安全在庫の式 z×σ_d×√L は、需要のばらつきだけを入れた式で、届くまでの日数（リードタイム）が毎回同じ前提です。**ここでは、架空の1品目（1日の需要は平均100個・標準偏差30個、平均7日で届く）で、リードタイムの標準偏差を0〜3日に変え、需要だけの式と、リードタイムのばらつきも入れた式で、欠品の起き方と在庫の量を比べました。** 欠品しない回を95%にするつもり（z=1.645）で発注点を決めています。数字は置いた前提で決まります。

## 主な結果
- **リードタイムが毎回7日なら**：どちらの式も安全在庫131個、欠品した回は **5.00%**（目標どおり）
- **需要だけの式（S1）**：リードタイムの標準偏差が1日で欠品 **15.7%**、2日で26.9%、3日で33.4%。安全在庫は131個のまま変わらない
- **ばらつきも入れた式（S2）**：欠品は5.4〜6.0%でほぼ目標どおり。そのかわり安全在庫は、標準偏差1日で210個、2日で354個、3日で510個（需要の5.1日分）
- **平均在庫（日数分）**：S2 は標準偏差1日で5.6日分（S1 は4.9日分）、3日で8.7日分（S1 は5.5日分）。リードタイムが1日ぶれるだけで、欠品を目標に保つための在庫は大きく増える
- **1回の発注あたりの欠品の個数（発注量700個に対する割合）**：S1 は標準偏差3日で10.1%、S2 は1.0%
- リードタイムを整数に丸めた分、シミュレーションの「届くまでの需要」の標準偏差は式より少し大きい（標準偏差0.5日で97.7個と93.8個）。そのため S2 の欠品は5%を少し上回った

- 「届くまでの需要」の標準偏差が、式 √(L σ_d² + μ_d² σ_L²) とほぼ一致すること

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 613）
- 仮定：毎日の需要は独立な正規分布（負は0）、リードタイムは需要と独立。発注した分が届く前に次の発注は重ならない（発注量700個＝7日分）

## 注意（言えないこと）
- シミュレーションの結果。需要・リードタイム・発注量は作成者が置いたもので、結果はこれで決まる
- 実際のリードタイムは「遅れる側」に偏ることが多い。その場合は、正規分布の式でも欠品が目標を上回る
- 欠品のコストと在庫のコストの比べ方、目標の決め方についての助言ではない
