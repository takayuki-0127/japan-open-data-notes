# 1193 1つの不具合で問い合わせが一度に来ると、件数の上位の種類は何を表すのか？（問い合わせ対応）

問い合わせを種類ごとに数えて多い順に並べると、上位の種類が「お客さまがよく困っていること」に見えます。けれども、ある機能に不具合が出ると、1つの原因から同じ種類の問い合わせが数日のうちに固まって来ます。その月の件数の上位には、ふだんの困りごとの多さと、1つの不具合のかたまりの大きさがまざります。**ここでは、作成者が置いた架空の会社の問い合わせ窓口（種類12。種類ごとのふだんの1日の件数と、不具合の起き方・大きさを作成者が置いたもの）で、月ごとの件数の1位・上位3がふだんの順とどれだけ合うか、1位の種類の件数のうち1つの不具合から来た分はどれだけかを100年分（1,200か月）数えました。1日の件数がその種類のふだんの3倍を超えた日をならしてから並べる数え方とも比べ、不具合の起きやすさ・大きさ・ふだんの件数の散らばりを変えた27通りも確かめました。**

種類の名前は作成者が置いた架空の分類で、実在の会社・製品・問い合わせ管理の仕組みを表すものではありません。不具合の中身や原因は扱いません。

関連する記事：918「不良の原因の上位を、件数で並べるか損失で並べるかで変わるのか？」は、件数の上位と損失の上位のずれを、架空の工場の不良で数えています。この記事は、件数そのものに「ばらばらの原因から1件ずつ来た分」と「1つの原因から固まって来た分」がまざることに絞ります。967「問い合わせの件名だけで分けると、本文と比べて何がずれるのか？」は、問い合わせを種類に分けるときのずれを扱っています（この記事では種類の分け方は正しいと置きました）。同じ企画の 1189「1件が何往復もするとき、件数で数えるか往復の数で数えるかで、忙しい種類の順はどう変わるのか？」は、同じ種類の上位を、件数・往復の数・時間のどれで数えるかで比べています。

## 主な結果

### 基本の置き方（1,200か月、`results/a1193_main.json`）
| | ①件数の順 | ②固まった日をならした順 |
|---|---|---|
| 1位がふだんの1位（ログイン）だった月 | **72.08%** | 91.17% |
| うち不具合のあった月 | 50.98% | 91.65% |
| うち不具合のなかった月 | 90.74% | 90.74% |
| 1位の種類にその月の不具合がまざった月 | 27.42% | 7.25% |
| 1位の種類の件数のうち不具合の分（月の平均） | **14.56%** | 2.34% |
| 1位の種類の件数の半分以上が1つの不具合からだった月 | 15.33% | 1.17% |
| 上位3がふだんの上位3と重なった割合 | 90.14% | 98.36% |
| ふだんの順との順位相関 | 0.938 | 0.991 |

- 不具合は1,200か月で707回起き、1つの大きさの中央値は116件・90%点は292件だった。不具合のあった月は46.92%、全部の問い合わせのうち不具合から来た分は5.84%だった
- **全体では5.84%しかない不具合の分が、件数で1位の種類の中では平均14.56%を占めた**。不具合のあった月では、1位の種類の58.44%にその月の不具合がまざり、まざったときは1位の件数の53.1%が1つの不具合から来ていた
- 不具合のなかった月でも、1位がふだんの1位だったのは90.74%だった（ふだんの1位と2位の差が小さいため、乱数の振れで入れかわる）
- 1位になった種類は、ログイン72.08%・支払い10.58%のほか、ふだん12位の「その他」（0.83%）まで、12種類すべてに散らばった
- ②では、1位がふだんの1位だった月は91.17%で、不具合のなかった月の90.74%とほぼ同じになった。1日に固まって来る形で置いた不具合を、3倍の線でほぼ取り除けたため（作りどおりに近い）

| ふだんの順位 | 不具合の回数 | ①件数で1位 | ①件数で3位以内 | ②ならして3位以内 |
|---|---|---|---|---|
| 1〜3位 | 187回 | 86.1% | 100% | 100% |
| 4〜6位 | 173回 | 45.09% | 80.35% | 1.16% |
| 7〜12位 | 346回 | 23.7% | **48.55%** | 0% |

- ふだん7〜12位の種類でも、不具合が起きた月には48.55%が件数の3位以内に入り、23.7%が1位になった。不具合の起きた種類の順位は、中央値で3つ上がった（3つ以上上がったのは56.95%）

### 確かめ：置き方を変えると（27通り、各480か月、`results/grid.csv`）
- **1位の種類のうち不具合の分（月の平均）が、全体のうち不具合の分を上回ったのは27通り中24通り（比は0.608〜3.829倍）**。下回った3通りは、不具合が小さく（中央値40件）、ふだんの件数が上の種類に寄った置き方で、ふだんの1位が不具合を受けても受けなくても1位に残る
- ①で1位がふだんの1位だった月は17.29〜98.54%、上位3の重なりは55.14〜99.38%と、置き方で大きく動いた
- ②は27通りすべてで、1位がふだんの1位だった月・上位3の重なりとも①以上だった（66.25〜99.79%、88.4〜100%）。1位のうち不具合の分は27通りすべてで全体の分を下回った（0.38〜10.08%）
- 全体のうち不具合から来た分は0.82〜36.53%、不具合のあった月は18.54〜89.79%だった

## 注意（言えないこと）
- 架空のデータです。ふだんの件数、不具合の起きやすさ・大きさ・来方は作成者が置いたもので、結果はこれで決まります。とくに②がよく効いたのは、不具合の問い合わせを3日に固まって来ると置いたからで、何週間もかけて少しずつ増える不具合なら、3倍の線では取り除けないと考えられます（推測）
- 「ふだんの困りごと」と「不具合から来た分」は、作成者が分けて置いたので数えられました。実際の記録では、どの問い合わせが不具合から来たかは分からないことが多いです
- ②は不具合の分を取り除くだけで、不具合が起きたこと自体は件数の順から見えなくなります。件数の上位が何を表すかを数えただけで、どちらの並べ方を使うべきかを言うものではありません
- 種類の分け方は正しいと置きました。分け方の誤り（967 で扱う形）は入れていません
