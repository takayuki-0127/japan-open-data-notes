# F234 価格を1%上げると、買われる量は何%減るのか？ ― 値付けの判断に使う価格弾力性

看板記事 F234（② 実務に近い分析）。家計調査の130品目（2002〜2024年）を使い、「値上げの判断に価格弾力性をどう使うか」を、推定の仕方・操作変数・交差弾力性・判断表・ダッシュボード・SQL まで一通り試した。F209（物価と家計・前編）でも家計調査の弾力性を出したが、ここでは「推定値が値付けの判断にそのまま使えるか」に絞った。

## 問い
1. 同じデータでも、推定の仕方で弾力性はどれだけ変わるか
2. 値段の変化が「需要の変化に押された分」を、輸入物価を使った操作変数で切り分けられるか
3. 代わりになる品目の値段（交差弾力性）は、どこまで見えるか
4. 推定した弾力性で「5%値上げすると利益は増えるか」を判断できるか

## データ
- 総務省「家計調査」（二人以上の世帯）品目別の年平均価格・購入数量・支出金額、2002〜2024年、130品目（F113 で整形したものを使用、`data/raw/kakei_items_panel_f113.csv`）
- 日本銀行「輸入物価指数（円ベース）」飲食料品・食料用農水産物、石油・石炭・天然ガス、総平均、ドル円（F210 で取得したものを使用、`data/raw/boj_import_prices_fx.csv`）。このデータは日本銀行時系列統計データ検索サイトの API 機能を使用して取得したものです。サービスの内容は日本銀行によって保証されたものではありません。
- 新しい取得はしていない。

## 手法
- **A 推定の仕方の比較**：品目ごとの単純回帰（値段と量の水準）、年のトレンドを入れた回帰、前年からの変化どうしの回帰。全品目をまとめた「前年差＋年の効果」（品目でクラスターの標準誤差）と、その支出の重みつき版。
- **B 操作変数**：「輸入物価の前年差 × その品目が輸入の影響を受けやすいか」を値段の変化の操作変数にした2段階最小二乗（年の効果あり、品目単位のブートストラップ500回）。輸入の受けやすさの区分は推測で決めたので、狭い版13品目・広い版30品目・エネルギー3品目で比べた。
- **C 交差弾力性**：肉（牛・豚・鶏）、油脂（バター・マーガリン）、主食（米・食パン・パスタ・即席麺）、お酒（ビール・発泡酒・清酒）、飲み物（緑茶・紅茶・コーヒー）の組で、自分の値段・相手の値段・食料の支出の変化を同時に入れた回帰（HC1）。
- **D 判断表**：粗利率 m・値上げ幅 x・弾力性 ε から、利益の変化 = ((1+x)−(1−m))/m × (1+x)^ε − 1。利益が減り始める弾力性（分かれ目）= ln(m/(m+x)) / ln(1+x)。群ごとの弾力性のブートストラップ分布から「利益が減る確率」を出した。
- **データの点検**：量が1年で半分以下・値段が1.6倍以上動いた4つの品目×年（あさり2022、えのきたけ2015、ドレッシング2010、即席麺2005）は、品目の区分の変更らしい（推測）ので前年差から外した。
- **SQL**：前年差・区分変更の判定・群ごとの弾力性・分かれ目の表を T-SQL で書き（`sql/`）、同じ計算を DuckDB で動かして Python と照合した（行数2,804で一致、差の最大 1e-16）。
- **ダッシュボード**：粗利率・値上げ幅・弾力性を動かすと利益と売上の変化が出る静的 HTML（`dashboard/price_decision_board.html`）。店は架空（「さくらマート」）。

## 結果
**1. 推定の仕方で、弾力性は −0.3〜−0.9 と変わる（図1）**

| 推定の仕方 | 弾力性 | 備考 |
|---|---|---|
| 品目ごと：水準どうし | 中央値 −0.86 | 18%の品目でプラス（値上げで量が増える） |
| 品目ごと：トレンドあり | 中央値 −0.53 | プラスは10% |
| 品目ごと：前年差どうし | 中央値 −0.68 | プラスは5% |
| 全品目：前年差＋年の効果 | −0.71（−0.86〜−0.56） | 2,800観測・130品目 |
| 同・支出の重みつき | −0.34（−0.55〜−0.13） | 支出の大きい品目（電気・米など）に引っぱられる |

**2. 操作変数は弱く、このデータでは使えなかった（図1）**
- 主の推定：+0.01（95%区間 −1.71〜+0.24）、1段目の F は 7.3（目安の10未満）。同じ標本の前年差の回帰は −0.75。
- 広い区分 +0.06（F 7.7）、食料だけ −1.15（−3.37〜+2.29、F 4.8）、エネルギーだけ +0.07（−0.36〜+0.34、F 10.2）。
- 「操作変数を入れたら答えが変わった」とは言えない。区間が広すぎて、前年差の回帰の値（−0.75）も区間に入る。

| 魚介類 | −1.30 | −1.54〜−1.07 | 27 |
| 果物 | −0.95 | −1.21〜−0.74 | 14 |
| 飲料 | −0.82 | −1.09〜−0.37 | 4 |
| 酒類 | −0.78 | −1.27〜−0.55 | 7 |
| 油脂・調味料 | −0.54 | −0.74〜−0.28 | 13 |
| 野菜・海藻 | −0.54 | −0.68〜−0.43 | 37 |
| 肉類 | −0.39 | −0.57〜−0.16 | 8 |
| 乳卵類 | −0.34 | −0.58〜−0.24 | 4 |

**4. 判断表：家計全体の弾力性なら、どの群も値上げで利益が増える計算になる（図3・図4）**
- 5%値上げで利益が減り始める弾力性は、粗利率10%で −8.31、20%で −4.57、30%で −3.16、50%で −1.95。
- 群ごとの弾力性は最も大きい魚介類でも −1.30 なので、粗利率30%なら「利益が減る確率」はどの群もブートストラップで0%。
- ただし、これは家計全体（市場）の弾力性。1つの店・ブランドが値上げすると、客はほかの店・ブランドへ移るので、自分の弾力性はずっと大きい。利益を最大にしている店なら弾力性 ≒ −1÷粗利率（粗利率30%で −3.3）になるはずで、市場の値（−0.3〜−1.3）の数倍。**市場の弾力性を、自社の値付けにそのまま使ってはいけない**。
- 弾力性が −1 より大きい（−1.5 など）と、5%値上げで売上は減る（−2.4%）が、粗利率30%なら利益は増える（+8.4%）。売上だけ見て判断すると誤る。

**5. 交差弾力性：22年分では多くがはっきりしない（図5）**
- 32の組のうち、95%区間が0をまたがないプラス（代わりに買われる）は3つ：豚肉が上がると鶏肉 +0.88、バターが上がるとマーガリン +0.56、紅茶が上がると緑茶 +0.28。マイナスは1つ（牛肉が上がると鶏肉 −0.68）。
- 自分の値段の弾力性がはっきりマイナスなのは15品目中6品目。

**6. データの点検の効果**
- 区分の変更らしき4つの年を入れたままだと、即席麺の自分の弾力性は +2.79（値上げで量が増える）、パスタとの交差は −1.99 と、はっきりした「おかしな結果」が出た。外すと +0.18、−0.35 で、どちらも区間が0をまたぐ。全品目の値は −0.67 → −0.71 でほとんど変わらない。

## 言えないこと
- **市場の弾力性であって、店・ブランドの弾力性ではない。** 家計調査は「家計全体がその品目をどれだけ買ったか」で、どの店で買ったかは分からない。自社の値付けには、自社の販売データ（値段を変えた店・時期と変えなかった店・時期の比較など）が要る。
- **因果とは言い切れない。** 前年差＋年の効果でも、値上げの年に需要が別の理由で変わった分（流行・健康志向・品質の変化）は残る。操作変数で切り分けようとしたが、1段目が弱く（F 4.8〜10.2）、使えなかった。
- 年平均のデータなので、セールや季節の動き、買いだめは見えない。月次・店舗単位なら弾力性はもっと大きく出るはず（推測）。
- 値段は「購入金額÷購入数量」の平均単価なので、安い品へ切り替えた分も「値下がり」に見える。品質の違いは調整していない。
- 輸入の受けやすさの区分は推測で決めた。
- 判断表の利益の式は、仕入れ値が変わらず、値上げ後も費用の形が同じという単純な前提による。
- 交差弾力性は22年分の時系列で推定しているので、区間が広い。
