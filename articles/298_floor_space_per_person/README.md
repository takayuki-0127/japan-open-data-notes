# 298 1人あたりの住まいの広さは、広くなったのか

総務省「令和5年住宅・土地統計調査」時系列統計表の第14-1表（所有の関係別の1住宅当たり居住室の畳数・延べ面積・1人当たり居住室の畳数、全国、1968〜2023年）、第13表（建て方別、1993〜2023年）、第27表（1人当たり居住室の畳数の階級別の主世帯数、1988〜2023年）を使ったフォルダです。全国の集計だけを使っています。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A298 | 1人あたりの住まいは広くなったのか。それは家が広くなったからか、1つの家に住む人が減ったからか | 1人当たり居住室の畳数を、1住宅当たりの畳数と1住宅当たりの人数（＝1住宅当たり畳数÷1人当たり畳数、で求めた近似）に分けた（対数の変化の比）。1人当たり6畳未満・15畳以上の主世帯の割合。持ち家・借家、一戸建・共同住宅の別 | `src/a298_floor_space_per_person.py` |

## 主な結果
- 1人当たり居住室の畳数は、1968年5.56畳 → 2003年12.17畳 → 2023年14.69畳。55年で2.64倍です。
- 1968〜2003年は、1住宅当たりの畳数（22.0 → 32.7畳）と1住宅当たりの人数（3.96 → 2.69人）がほぼ半分ずつ効いていました。2003〜2023年は1住宅当たりの畳数が32.7畳のまま変わらず、1人当たりの伸び（1.21倍）はすべて人数の減り（2.69 → 2.22人）の分でした。
- 1住宅当たりの延べ面積は2003年の94.85㎡が最も広く、2023年は91.66㎡。1人当たりの延べ面積（近似）は1968年18.6㎡、2003年35.3㎡、2023年41.2㎡です。
- 1人当たり6畳未満の主世帯の割合は1988年19.2% → 2008年6.2% → 2023年4.6%。15畳以上は19.6% → 37.4% → 44.5%でした。
- 1人当たり畳数は持ち家16.19畳、借家10.68畳（2023年）。差は1993年の4.3畳から5.5畳に広がりました。1住宅当たりの延べ面積は、持ち家が2003年123.9㎡ → 2023年118.3㎡、借家は45〜46㎡で、ほとんど変わっていません。

## 頑健性
- 1人当たり畳数の分布で、階級が分からない（不詳の）世帯を分母から除いても、6畳未満は1988年19.5% → 2023年4.8%、15畳以上は19.8% → 46.4%で、同じ向き
- 分解の区切りを1993年にすると、1993〜2023年の伸びのうち89%が人数の減り、11%が家の広さの分
- 建て方別（第13表）でも、一戸建の1住宅当たり延べ面積は2003年128.5㎡ → 2023年126.9㎡で広くなっていない。1人当たり畳数は一戸建11.6 → 16.5畳、共同住宅7.7 → 11.6畳（1993 → 2023年）と、どちらも伸びた
- コードはきれいなフォルダで3回動かし直し、data・results・figures の全ファイルが一致した

## データ
- `data/raw/hlts_ts_subset.json`：e-Stat「令和5年住宅・土地統計調査 時系列統計表」第13表（statInfId=000040354044）、第14-1表（000040354045）、第27表（000040354062）の閲覧用 Excel を、ブラウザの中で SheetJS（xlsx 0.18.5）で CSV の文字列にしたもの（2026-11-12 取得）。手で取る場合は `https://www.e-stat.go.jp/stat-search/file-download?statInfId=<id>&fileKind=4`
- `data/national_series.csv` ほか：整形した表

## 注意
- 1住宅当たりの人数と1人当たりの延べ面積は、表の平均どうしの割り算で求めた近似です（表に直接は載っていません）
- 「居住室の畳数」は居間や寝室などの広さで、台所・浴室・廊下などは含みません。延べ面積はそれらを含みます
- 1968年は沖縄県を含みません。1973年は沖縄を含む値を使いました
- 2023年の分布は15畳以上が2つの階級に分かれているので、合わせて15畳以上としました
- 標本調査の推定値です。世帯の人数が減った理由（単身の世帯や高齢の世帯が増えたことなど）は、このデータでは分けていません
