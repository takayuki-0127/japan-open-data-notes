# 708 誤差に自己相関のある時系列で回帰すると、ふつうの標準誤差は何倍小さく出るのか（手法の解説・正解の分かるデータで試す）

月次の系列どうしを回帰するとき、誤差に自己相関（前の月と似た値になる性質）があり、x にも自己相関があると、ふつうの標準誤差は小さく出ます。データが n か月あっても、似た月が続くので、実質の情報はもっと少ないからです。**ここでは、無関係な x と y（どちらも自己相関 ρ の AR(1)）を作り、ρ と長さを変えて各3,000回、傾きを検定しました。** 標準誤差は、ふつうのものと、自己相関を認める Newey–West の2種類（ずらし幅を自動で決めたものと12か月）です。数字は置いた前提で決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A708 | 自己相関のある系列の回帰で、ふつうの標準誤差はどれだけ小さく、Newey–West でどこまで直るか | 単回帰。ρ=0・0.3・0.6・0.9、n=60・120・480か月、各3,000回。Newey–West のずらし幅 L＝floor(4(n/100)^(2/9))（60か月で3、120か月で4、480か月で5）と L=12。式で出した値が statsmodels の HAC と一致することを確認。seed 708 | `src/a708_autocorr.py` |

## 主な結果
- **ふつうの標準誤差**：120か月で、ρ=0 なら偽の有意4.7%、ρ=0.6 で17.9%、**ρ=0.9 で50.4%**。標準誤差は本当のばらつきの0.70倍・**0.34倍**
- **長くしても直らない**：ρ=0.9 で60か月48.5%、480か月51.7%
- **Newey–West（自動のずらし幅）**：ρ=0.6・480か月で7.6%まで戻るが、ρ=0.9 では120か月29.1%、480か月22.8%と直りきらない
- **ずらし幅12**：ρ=0.9・480か月で15.6%と近づくが、短い系列では ρ=0 でも13.7%（60か月）と出しすぎる

## 動かし方

```
pip install -r requirements.txt

```

## 確かめたこと
- 空のフォルダで流し直し、results・figures がバイト単位で一致した
- 式で出した傾きと Newey–West の標準誤差が、1回分で statsmodels の OLS（cov_type="HAC"、maxlags=4、use_correction=False）と一致した
- ρ=0 ではふつうの標準誤差の偽の有意が約5%で、作りが正しいことを確かめた

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 708）
- 仮定：x と誤差は独立で、どちらも同じ ρ の AR(1)。傾きの本当の値は0。最初の100か月は捨てて、落ち着いた形から使う
