# 1035 道のりの長い日ほど、1kmあたりの時間は短いのか？（移動と時間）

配送の車の記録を1日ずつ並べると、道のりの長い日ほど「1日の時間÷1日の道のり」（1kmあたりの時間）が短く見えることがあります。ここから「道のりを長く組めば効率が上がる」と読みたくなります。けれども、この見え方には3つのしくみが混ざります。1日に1回の決まった時間（積み込み・車を出す準備など）が長い道のりで割られて薄まる分、遅くなると前もって分かる日に道のりを短く組む選び方の分、道のりの記録の誤差の分です。道のりを伸ばしたときに本当に1kmあたりが短くなるのは、1つ目だけです。**ここでは、作成者が乱数で作った架空の配送の車（300日を200回）で、道のりの長い4分の1の日と短い4分の1の日の1kmあたりの時間の差を数え、そのうち道のりで本当に変わる分（決まった時間の割り算）がどれだけかを、しくみを1つずつ入れて切り分けました。置き方を変えた36通りでも確かめました。**

1件ごとに決まった時間（停めて渡す時間）があると近い配送ほど1kmあたりが長くなる形は関連する記事 952 で、1件ごとのやり取りで短い案件ほど時給が下がる形は 885 で扱っています。この記事の決まった時間の割り算はそれらと同じ式です。この記事で新しく数えたのは、日ごとの記録を並べたときに、その割り算に選び方と記録の誤差がどれだけ上乗せされるかです。混む時間帯を避けて出る人が早く着くのは避けた効果か選んだ人の違いか、は同じ企画の 1034 で、道のりの記録の抜けで距離がずれる話は 1036、記録した速さの平均の取り方（距離ごと・時間ごと）で平均の速さがずれる話は 1029 で扱っています。

| A1035 | 道のりの長い日ほど、1kmあたりの時間は短いのか。その差のうち、道のりを伸ばしたら本当に短くなる分はどれだけか | 架空の配送の車1台。1日の時間＝決まった時間（基本25分、道のりによらない）＋本当の道のり×その日の走りの遅さ。走りの遅さは1kmあたり2.4分に、前もって分かる遅さ（対数で標準偏差0.12の正規分布）と当日にならないと分からない遅さ（同0.10）を掛けた値。本当の道のりは、60kmに対数で標準偏差0.25の振れを掛け、さらに前もって分かる遅さ k に対して exp(−β×k) を掛けた（遅くなると分かる日は短く組む。基本 β＝1.5）。記録の道のりは、本当の道のりに対数で標準偏差0.06の誤差を掛けた値（基本）。1kmあたりの時間は「1日の時間÷記録の道のり」。記録の道のりで長い4分の1の日と短い4分の1の日を分け、1kmあたりの時間の平均の差を「見かけの差」とした。道のりで本当に変わる分は「決まった時間÷本当の道のり」の、同じ2つの組の平均の差（同じ日に道のりだけを変えると、走りの遅さは変わらず、この分だけが動く）。300日を作り直して200回数えた。しくみを1つずつ入れた5通り（各200回）と、決まった時間（0・10・25・40分）×β（0・1.5・3）×記録の誤差（0・0.06・0.12）の36通り（各50回）も数えた。seed 1035 | `src/a1035_long_day_per_km.py` |

## 主な結果

### 基本の置き方（300日を200回の平均、`results/mechanisms.csv`）
| | 短い4分の1の日 | 長い4分の1の日 | 差 |
|---|---|---|---|
| 記録の道のりの平均 | 40.85km | 90.76km | |
| 1kmあたりの時間（1日の時間÷記録の道のり） | 3.309分 | 2.47分 | **−0.839分**（10〜90%の範囲 −0.935〜−0.757分） |
| うち、道のりで本当に変わる分（決まった時間÷本当の道のり） | | | **−0.331分（見かけの差の39.5%）** |
| うち、走りの遅さの違い（遅い日を短く組んだ選び方） | | | −0.423分 |
| うち、記録の誤差（本当の道のりで割った差 −0.754分との違い） | | | −0.085分（−0.839−（−0.754）） |

- **道のりの長い4分の1の日は、短い4分の1の日より1kmあたり0.839分短く見えた。そのうち、道のりを伸ばしたら本当に短くなる分は0.331分（39.5%）だった**
- 残りのうち0.423分は、長い日にはもともと走りの速い日が集まっていた分だった。遅くなると前もって分かる日に道のりを短く組んだからで、その日に道のりを足しても走りは速くならない
- 本当の道のりで割ると差は−0.754分で、記録の道のりで割った−0.839分より小さかった。記録の道のりが多めに出た日は「長い日」に入りやすく、1kmあたりが短く出る（記録の誤差の分）
- すべての日に道のりを10km足すと、1kmあたりの時間は平均0.069分短くなった（決まった時間25分の割り算の式どおり）

### しくみを1つずつ入れると（各200回の平均）
| 入れたしくみ | 見かけの差 | 道のりで本当に変わる分 | 割合 | 回帰の切片（1日の時間＝切片＋傾き×記録の道のり） |
|---|---|---|---|---|
| 基本（3つとも） | −0.839分 | −0.331分 | 39.5% | 64.9分 |
| 決まった時間だけ（25分） | −0.274分 | −0.269分 | 98.3% | 25.83分 |
| 選び方だけ（β＝1.5） | −0.432分 | 0分 | 0% | 35.03分 |
| 記録の誤差だけ（0.06） | −0.086分 | 0分 | 0% | 8.87分 |
| どれもなし | +0.005分 | 0分 | | −0.78分 |

- 決まった時間だけなら、見かけの差はほぼすべて道のりで本当に変わる分だった（98.3%。残りは走りの遅さの偶然の差）。これは置いた式どおり
- 選び方だけ、記録の誤差だけでも、決まった時間がないのに長い日ほど1kmあたりが短く見えた（−0.432分・−0.086分）
- しくみの差は足し算にはならない（3つを別々に入れた差の合計は−0.792分、3つとも入れると−0.839分）。選び方があると短い日がより短くなり、決まった時間の割り算の差も大きくなるため
- **1日の時間を記録の道のりで直線に当てはめると、切片（道のり0kmのときの時間）は64.9分で、置いた決まった時間25分の2.6倍に出た**。決まった時間がなくても、選び方だけで切片は35.03分になった。切片をそのまま「1日の決まった時間」と読むことはできない

### 確かめ：決まった時間 × 選び方の強さ × 記録の誤差（36通り、各50回、`results/grid.csv`）
- 見かけの差は、36通りで−1.599〜−0.001分と動いた。3つとも0の通りでは−0.001分で、ほぼ0だった（作りの確かめ）
- **決まった時間があり、選び方か記録の誤差もある24通りでは、見かけの差のうち道のりで本当に変わる分は15.3〜78.3%だった**。決まった時間だけの3通りでは100.2〜102%（式どおり、残りは偶然の差）
- 決まった時間を25分に置いた9通りで、回帰の切片は25.6〜75.43分。決まった時間を0分に置いても、切片は−0.56〜50.43分だった

## 注意（言えないこと）
- 架空のデータです。決まった時間、走りの遅さの振れ、遅い日に道のりを短く組む強さ、記録の誤差は作成者が置いたもので、結果はこれで決まります。見かけの差のうち道のりで本当に変わる分は、置き方で15.3〜78.3%と動きました。実在の配送の会社や車の記録ではありません
- 道のりを伸ばしても走りの遅さは変わらないと置きました。実際には、道のりを伸ばすと速い道を走る割合が増えたり、混む時間帯にかかって遅くなったりすることがあり、そのときは道のりで本当に変わる分も変わります（推測）
- 「道のりで本当に変わる分」は、置いた決まりを知っている作成者だから数えられる値です。実際の記録だけからは、この切り分けはできません
- 1日の道のりをどう組むべきか、人や車の数をどう決めるべきかの助言はしません。1kmあたりの時間の読み方を比べただけです
