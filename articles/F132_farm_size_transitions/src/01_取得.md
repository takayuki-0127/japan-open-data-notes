# 01 取得（農林業センサス 構造動態の相関表・2025年総括編）

`data/raw/f132_census_transitions.json` は、e-Stat に置かれている農林水産省「農林業センサス」の Excel を、2026年11月3日にブラウザの中で読み込み、シートごとに CSV の文字列にして1つの JSON にまとめたものです。キーは `<年_表>__<シート名>` です。

| キー | 表 | statInfId |
|---|---|---|
| 2020_kei | 2020年 第6巻 構造動態編 1-1 経営耕地面積規模別経営体数の相関表【計】（2015→2020） | 000032168967 |
| 2020_dantai | 同【団体経営体】 | 000032168968 |
| 2020_hojin | 同【法人経営体】 | 000032168969 |
| 2015_kei | 2015年 第6巻 構造動態編 1-1 経営耕地面積規模別経営体数の相関表【計】（2010→2015） | 000031550391 |
| 2015_hojin | 同【法人経営】 | 000031550392 |
| 2015_soshiki | 同【組織経営体】 | 000031550393 |
| 2010_kei | 2010年 第6巻 農業構造動態統計報告書 Ⅰ-1 経営耕地面積規模別経営体数の相関表（2005→2010、全国農業地域別） | 000012668087 |
| 2025_size | 2025年 第2 総括編 Ⅱ-3 経営耕地面積規模別経営体数（2020・2025） | 000040483739 |
| 2025_area | 2025年 第2 総括編 Ⅱ-11 経営耕地面積規模別経営耕地面積（2020・2025） | 000040483747 |

取り方：`https://www.e-stat.go.jp/stat-search/file-download?statInfId=<id>&fileKind=0` を e-Stat のページの中で fetch し、SheetJS（xlsx 0.18.5）で読み、`XLSX.utils.sheet_to_csv` で各シートを文字列にしました。手で取る場合は、上の URL から Excel をダウンロードすれば同じ内容になります。

- 2015年・2020年の表は、全国・全国農業地域・都道府県（計66）の相関表が1枚のシートに続けて並んでいます。
- 2010年の表には全国の相関表がないため、北海道と都府県を足して全国としました。2010年の表は、前回側の「今回は農業経営体以外」と「接続不可」が1つの列（継続農業経営体以外）です。
- 法人・団体経営体の表は、今回（2020年）その形態である経営体の前回の規模を数えた表で、退出の列がありません。本分析では使っていません（データは残しています）。
