# F132 農家は「やめる」のか「大きくなる」のか？

農業経営体の数は5年ごとに2割以上減っています。減った分は「やめた」のか、それとも「大きくなって、ほかの経営体の土地を引き受けた」のか。農林業センサスの構造動態編には、前回と今回のセンサスで同じ経営体をつなぎ、経営耕地面積の規模がどう移ったかを数えた表（相関表）があります。これを遷移行列（マルコフ連鎖）として読み、規模ごとの「やめる」「大きくなる」を数えました。

## 問い
- 5年のあいだに、規模ごとに何割がやめ、何割が大きくなったか
- 大きい層（10ha以上など）の数は、どこから来て、どこへ出ていったか
- この遷移で次の5年を予測すると、2025年センサスの実際の数にどれだけ合うか
- 都道府県による残り方の差は、規模の構成の違いで説明できるか（シフトシェア）

## データ
- 農林水産省「農林業センサス」（e-Stat）
  - 2020年 第6巻 構造動態編「経営耕地面積規模別経営体数の相関表（経営形態別）」【計】【団体経営体】【法人経営体】（2015→2020、全国・地域・都道府県）
  - 2015年 第6巻 構造動態編 同表【計】【法人経営】【組織経営体】（2010→2015、全国・地域・都道府県）
  - 2010年 第6巻 農業構造動態統計報告書「経営耕地面積規模別経営体数の相関表」（2005→2010、北海道・都府県・地域）
  - 2025年 第2 総括編「経営耕地面積規模別経営体数」「経営耕地面積規模別経営耕地面積」（2020・2025）
- 取得方法と statInfId は `src/01_取得.md`。元の表を CSV 文字列にした JSON が `data/raw/`、整形した長い表が `data/transitions_long.csv`。

## 手法
1. **遷移行列**：前回の規模（行）× 今回の規模（列）＋「やめた」の件数を、行ごとに割って5年の遷移確率にしました。規模は、2010→15・2015→20年は9区分（1ha未満、1〜3、3〜5、5〜10、10〜20、20〜30、30〜50、50〜100、100ha以上）、3期間の比較は5区分（1ha未満〜10ha以上）にまとめました（2005→10年の都府県の表は15ha以上が1つの区分のため）。
2. **やめた**の定義：本推定は「今回は農業経営体でない」＋「接続不可（前回側）」。接続不可は、法人化・経営の引き継ぎ・世帯の分かれなどで前後をつなげなかったものを含むため、やめたとは限りません。頑健性として「接続不可を除く」定義（接続不可を、つながった経営体と同じ割合で振り分けるのと同じ）でも出しました。
3. **大きい層の増減の内訳**：10ha以上・30ha以上・100ha以上などの層について、2020年の数を「同じ層にとどまった」「下の層から上がってきた」「新しく始めた」「接続不可（今回側）」に、出ていった数を「小さくなった」「やめた」「接続不可（前回側）」に分けました。
4. **マルコフ連鎖の予測と検証**：2020年の規模別の数に 2015→2020年の遷移行列を掛け、新しく始める数（新規＋接続不可（今回側））を足して2025年を予測し、2025年センサスの実際の数と比べました。2010→15年の遷移で2015→20年・2020→25年を予測する検証もしました。
5. **シフトシェア**：都道府県ごとの5年残存率（2015年の経営体のうち2020年も経営体である割合）を、「全国の規模別の残存率 × その県の規模の構成」で見込んだ値と比べ、差を規模の構成の効果と地域の効果に分けました。
6. **集計だけで遷移を推定したら**：設計の代替案（規模別の数の推移だけで行う）の確かめとして、都道府県別の規模別の数（前回）と継続経営体の規模別の数（今回）だけから、遷移確率を制約つき最小二乗で推定し、実際の相関表と比べました。

乱数は使っていません。

## 結果
- 農業経営体は 2015年 137.7万 → 2020年 107.6万 → 2025年 83.6万。2015年の経営体の **27.5%** が2020年までにやめていました（接続不可を含む）。
- **1ha未満**：35.4%がやめ、上の規模に移ったのは4.7%。やめた数（26.2万）は大きくなった数（3.5万）の **7.5倍**。**1〜3ha**：やめた20.2%、小さくなった15.7%、大きくなった4.0%（5.1倍）。
- **3ha以上**：やめた割合はどの規模でも14〜15%でほぼ同じで、大きくなった割合は12〜19%。やめた数と大きくなった数の比は0.8〜1.2倍で、ほぼ同じ数でした（50〜100haは上が100ha以上しかないため2.2倍）。
- **やめる割合は期を追って上がった**：1ha未満は 28.0%（2005→10）→ 29.1%（2010→15）→ 35.4%（2015→20）、1〜3haは 15.0% → 14.5% → 20.2%。大きくなる割合は増えていません（1ha未満 6.3% → 5.9% → 4.7%）。
- **大きい層**：10ha以上は 52,784 → 55,162（+4.5%）。2020年の10ha以上のうち、74%は同じ層にとどまった経営体、16%は下の層から上がってきた経営体、9%は接続不可（今回側）、新しく始めた経営体は0.7%でした。100ha以上は 1,590 → 1,933（+22%）で、2020年の29%が下の層から上がってきた経営体でした。
- 経営耕地面積のうち10ha以上の経営体が耕す割合は、55.3%（2020）→ 61.2%（2025）、50ha以上は24.5% → 28.1%。
- **予測の検証**：2015→20年の遷移で予測した2025年の経営体数は 84.4万で、実際の83.6万との差は **+0.9%**、10ha以上は +0.2%、規模別の外れの平均は1.5%でした。一方、1期前（2010→15年）の遷移を使うと +6.4% で、やめる割合が上がった分だけ多めに外れました。
- 同じ遷移が続くと置くと、2035年の経営体は約52万（推測の目安）。10ha以上の数は2020年の5.5万がピークで、2025年は5.48万とすでに少し減っており、2035年は約4.9万になる計算です。100ha以上は増え続けます（2035年 約2,250、ただし2025年の実際は2,165で、予測より速く増えています）。
- **シフトシェア**：全国の5年残存率は72.5%、都道府県の5%点〜95%点は65.4%〜78.6%。規模の構成だけで見込んだ残存率で説明できた差は **R²=0.03**（2010→15年は0.007）でした。規模の構成の効果と地域の効果は逆向きに打ち消し合っていて（相関 −0.58）、同じ規模でも地域によって残り方がかなり違います（例：北海道の1ha未満は45%がやめ、都府県は35%）。
- **集計だけの推定**：都道府県別の周辺の数だけから推定した遷移確率は、実際の表と大きくずれました（100ha以上にとどまる確率 0.24 対 実際 0.70、1〜3haのやめた割合 0.33 対 0.20 など）。規模の遷移を語るには、同じ経営体をつないだ相関表が欠かせません。

## 頑健性
| 確かめたこと | 1ha未満のやめた割合 | 3ha以上のやめた割合 | 3〜50haの大きくなった割合 |
|---|---|---|---|
| 本推定（2015→20、9区分、接続不可を含む） | 35.4% | 13.5〜15.4% | 11.7〜19.3% |
| 接続不可を除く（2015→20） | 29.3% | 5.5〜8.2% | 12.6〜21.3% |
| 2010→15年 | 29.1% | 9.5〜13.9% | 11.7〜18.4% |
| 2010→15年、接続不可を除く | 25.1% | 3.8〜5.3% | 12.3〜19.6% |
| 5区分（2015→20） | 35.4% | 13.5〜14.5% | 11.7〜11.9% |
| 北海道だけ（2015→20） | 45.1% | 12.9〜31.1% | 7.9〜15.3% |
| 都府県だけ（2015→20） | 35.3% | 12.3〜22.3% | 12.1〜23.7% |

- 接続不可を除くと、3ha以上のやめた割合は半分ほどになり、「大きい経営体ほどやめにくい」形に変わります。大きい経営体の接続不可には、法人化などの組み替えが多く含まれていると考えられます（推測）。一方、「1ha未満はやめる数が大きくなる数のずっと多い」「3ha以上では大きくなる割合がやめる割合と同じかそれ以上」はどの定義でも変わりません。
- 予測の検証で、新しく始める数を「前回と同じ数」と置くと2025年の外れは +3.0%、「前回の数に比例」では +0.9% でした。
- シフトシェアの R² は 2010→15年でも 0.007 で、規模の構成で説明できないことは期間を変えても同じでした。

## 言えないこと
- 接続不可がやめたのか、法人化などで形を変えて続いているのかは、この表では区別できません。本推定の「やめた」には、続いている経営体が一部含まれます。
- 経営耕地面積の規模だけで見ているので、販売金額や作目（施設園芸・畜産など、面積が小さくても大きい経営）の違いは見ていません。
- 5年に1度の比較なので、5年のあいだに大きくなって、またやめた経営体などは見えません。
- 2030年・2035年の数は「同じ遷移が続いたら」という計算で、予測ではありません。
- 特定の都道府県や地域を、残り方が良い・悪いと評価するものではありません。
