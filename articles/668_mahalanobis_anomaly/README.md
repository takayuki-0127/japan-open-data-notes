# 668 1列ずつ3σで見る方法とマハラノビス距離では、相関を崩す異常をどれだけ見つけられるのか（手法の解説・正解の分かるデータで試す）

異常な値を見つけるとき、列ごとに「平均から3標準偏差（3σ）より離れたら異常」と見ることがよくあります。この方法は、列どうしの関係（相関）を見ません。たとえば来店客数と売上のように強く相関する2列で、「客数は多いのに売上は少ない」日は、どちらの列も3σの内側に収まるので見逃されます。マハラノビス距離は、2列の平均・ばらつき・相関から「ふつうの日の広がり」に対する離れ具合を測るので、こうした異常も拾えます。**ここでは、相関のある2列に異常を混ぜた架空のデータで、3つの見つけ方が異常の何%を見つけるかを数えました。** 数字は置いた相関・異常の大きさ・割合で決まります。

| A668 | 3σとマハラノビス距離で、相関を崩す異常をどれだけ見つけるか | 標準化した2列（相関 ρ=0〜0.95）を2,000日分作り、異常40日（2%）を混ぜる。A 相関を崩す異常（片方 +1.0、もう片方 −1.0）、B 片方の列だけ3.3。1列ずつ3σ、マハラノビス距離（閾値は正常を誤って拾う割合が3σと同じ0.54%になる値）、頑健版のマハラノビス距離（MinCovDet）で比べる。平均や共分散は異常を含んだデータから出す。各200回（頑健版は40回）、seed 668 | `src/a668_mahalanobis.py` |

## 主な結果
- **相関を崩す異常（A）は、1列ずつ3σではどの相関でも0%**。どちらの列も ±1.0 で、3σの内側にあるため
- **マハラノビス距離は、相関が強いほどよく見つける**：相関0.8で22%、0.9で85%、0.95で99%。頑健版は相関0.8で45%、0.9で98%
- 相関が0.5以下では、どの方法でも A はほとんど見つからない（相関が弱いと、±1.0 の組み合わせは珍しくないため）
- **片方の列だけ3.3の異常（B）は、相関が弱いと3σの方がよく見つける**：相関0のとき、3σは99.8%、マハラノビス距離は47%、頑健版は94%。相関0.8以上では、どの方法も97%以上
- 正常な日を誤って拾う割合は、どの方法も0.1〜0.6%

## 確かめたこと
- 空のフォルダで流し直し、results・figures がバイト単位で一致した
- 相関0で相関を崩す異常（A）を混ぜたとき、正常な日を誤って拾う割合が、3σで0.54%、マハラノビス距離で0.55%と、閾値を決めたときの0.54%に合うこと（summary.csv の false_pos_pct）

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 668）
- 仮定：正常な日の2列は2次元の正規分布。異常は全体の2%

## 注意（言えないこと）
- シミュレーションの結果。相関・異常の大きさ・割合は作成者が置いたもので、結果はこれで決まる
- マハラノビス距離が強いのは、正常な日が楕円の形に集まるとき。形が曲がっていたり、まとまりがいくつもあったりすると当てはまらない
- 平均と共分散を異常を含んだデータから出すと、異常に引っぱられて見逃しが増える（頑健版との差）。列が多いと頑健版の計算は重くなる
- 異常を見つけたあと、それが本当に問題かどうかの判断は扱っていない
