# 790 学習データを2倍にすると、テストの誤差はどれだけ減り、どこで頭打ちになるのか（手法の解説・正解の分かるデータで試す）

「データを増やせば精度は上がる」とよく言われますが、どれだけ上がるかはモデルによって違います。モデルが単純すぎると、データを増やしても誤差はある所で止まります。**ここでは、曲がった関係を持つ架空のデータで、学習件数を50〜12,800と2倍ずつ増やし、線形回帰と決定木のテストの誤差がどう減るかを比べました（学習曲線）。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A790 | 学習件数を2倍にすると、誤差はどれだけ減るか | x は3つの一様乱数（−2〜2）、y＝2·sin(2x1)＋x2²＋x1·x3＋ばらつき（sd 1）。学習件数50〜12,800、各20回。線形回帰と決定木（葉の最小件数5）。2万件のテストデータの RMSE（二乗平均誤差の平方根）。scikit-learn。seed 790 | `src/a790_learning_curve.py` |

## 主な結果（20回の平均、誤差の下限は1.0）

| 学習件数 | 線形回帰 | 決定木 |
|---|---|---|
| 50 | 2.48 | 2.24 |
| 200 | 2.42 | 1.70 |
| 400 | 2.41 | 1.57 |
| 1,600 | 2.40 | 1.34 |
| 12,800 | **2.40** | **1.24** |

- 線形回帰は200件ほどでほぼ頭打ちになり、その先は12,800件まで増やしても2.42が2.40になっただけだった。どれだけ増やしても2.40（線形回帰で出せる限界）より下がらない
- 決定木は件数を増やすほど下がり続けた。ただし2倍にしたときの減りは、50→100件で11%、6,400→12,800件で1.5%と小さくなった
- 決定木の学習データでの誤差（0.74）は、ばらつきの分（1.0）より小さい。学習データにはばらつきまで当てはまっている


## 確かめたこと
- 空のフォルダで流し直し、results・figures が一致した
- 線形回帰の誤差が、20万件で学習した線形回帰の誤差（2.40）に近づくこと

## データ
- データファイルは置いていない。データはコードの中で乱数から作る（seed 790）

## 注意（言えないこと）
- 架空のデータです。頭打ちの位置や減り方は、作成者が置いた関係とモデルの設定で決まります
- 決定木の設定（葉の最小件数5）は固定しました。件数に合わせて設定を変えれば、曲線は変わります
- 実際のデータでは、件数を増やすと新しい種類のデータもまざることが多く、ここでの「同じ作り方のデータが増える」とは違います
