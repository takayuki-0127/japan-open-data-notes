# 285 輸入の半分は、何品目で占められているのか

財務省「貿易統計」の統計品別表（輸入、9桁の統計品目番号）を金額の大きい順に並べ、累積の割合を調べたフォルダです（パレート分析）。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A285 | 輸入の半分は、何品目で占められているのか | 品目を金額の大きい順に並べた累積の割合、半分・8割・9割に届く品目の数、ジニ係数。品目番号を6桁・4桁にまとめた場合、2015・2020年、2025年の輸出と比べる | `src/a285_pareto.py` |

## 主な結果
- 2025年の輸入（特殊なコードを除く111.3兆円）は8,015品目。上位80品目（1.0%）で半分、542品目（6.8%）で8割、1,150品目で9割。ジニ係数0.91
- 1位の原油だけで8.6%（9.6兆円）。上位10品目で27%、上位100品目で53%
- 金額の小さいほうから半分の品目（約4,000）を合わせても輸入額の0.6%
- 燃料の4品目（原油・液化天然ガス・一般炭・揮発油）で17%。燃料以外の上位は、スマートフォン（2.8%）、銅鉱、医薬品、ノートパソコンなど
- 半分に必要な品目の数は、2015年79品目、2020年95品目、2025年80品目。原油が安かった2020年は上位の割合が下がり、数が増えた
- 輸出（2025年、5,904品目）は71品目で半分、404品目で8割。輸出は1位（ハイブリッドの乗用車の1品目番号）が4.1%で、上位が輸入ほど大きくない一方、数で見るとやや少ない品目に集まる

## 頑健性
- 品目番号を6桁にまとめると5,252品目のうち59で半分、4桁にまとめると1,250分類のうち25で半分。品目の数に対する割合は1〜2%で、まとめ方で大きくは変わらない
- 少額貨物などの特殊なコード（000000xxx、輸入額の1.8%、輸出の9.3%）は品目でないので除いた
- コードは新しいフォルダで2回動かし直し、results と figures のすべてのファイルが一致することを確かめた

## 動かし方
```
pip install -r requirements.txt
cd src && python a285_pareto.py   # data/ から results/ と figures/ を作る
python fetch.py                    # data/ を e-Stat から作り直す（任意）
```

## データ
- `data/hs9_values.csv`：統計品別表（1-12月）の輸入2015・2020・2025年と輸出2025年の品目番号・金額（千円）。e-Stat の statInfId は `src/fetch.py`
- `data/hs9_to_gaikyo_top_import2025.csv`：2025年の輸入の上位60品目を概況品に割り当てた表（作成者が作成）

## 注意
- 品目の名前は、作成者が品目番号の内容（HS の号）から短くつけたもの
- 統計品目番号の細かさは品物によって違う（同じ額でも細かく分かれた品物は数が多くなる）。品目の数の比べ方には限りがある
- 集中しているから問題という意味ではない。輸入元の国の偏りは [282](../282_import_source_concentration)、金額の増え方は [281](../281_import_price_quantity_yen) で扱った
