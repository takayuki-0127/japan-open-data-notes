# F282 「円安で輸出が増えた」は、数量と価格に分けるとどうか（ニュースの数字、精選モード）

note 記事：「円安で輸出が増えた」は、数量と価格に分けるとどうか？ 輸出額は2020→2025年に1.6倍になったが、数量は1.03倍で伸びの6%だけ。残りは価格で、為替の換算の分が44%、相手の通貨での値上げが25%。前の円安（2012〜15年）では相手の通貨で値下げしたが、そのときも数量は増えなかった

## 問い
円安の局面で「輸出が過去最高」と報じられる。円で数えた輸出額の伸びのうち、数量（運んだ量）の分と価格（1単位あたりの円）の分はどれだけか。価格の分のうち、円に直すときの為替の分と、相手の通貨（契約通貨）での値上げはどちらが大きいか。
計画（事前登録）は [PLAN.md](PLAN.md)（コミット 21c751a、分析より先）。

## 手法
自然対数の差で、足し算になるように分けた。
- ln(金額) = ln(数量指数) + ln(価格指数) + 指数の丸めによる残り
- ln(価格指数) = ln(輸出物価・円ベース) + 品目の構成などの分
- ln(輸出物価・円ベース) = ln(輸出物価・契約通貨ベース) + 為替の分（円ベース÷契約通貨ベース）
輸出物価は月次の暦年平均（年度は4〜3月の平均）。月次の関係は、数量指数（世界）の前年同月比と実質実効為替レートの前年同月比（0〜12か月前）の相関（2010年1月〜2026年9月、201か月）。

## 結果（2020→2025年、暦年、世界）
- 金額 1.614倍、数量 1.027倍、価格指数 1.572倍。輸出物価：円ベース 1.389倍、契約通貨ベース 1.126倍。ドル円 106.8→149.6円。
- 金額の伸び（対数の差 0.479）の内訳：数量 5.6%、品目構成など 25.8%、相手の通貨での値上げ 24.7%、為替の分 44.0%（残り −0.1%）。
- 輸出物価（円ベース）の上昇のうち為替の分 64.1%。
- 「品目構成など」（価格指数と輸出物価の差）は2009〜2025年の17年中16年でプラス、年平均+2.2%（5年で約0.11）。2020→2025年の0.123のほとんどはこの毎年の積み上がりで、円安の効果ではなく統計の差（構成・品質・作り方）と見る（推測）。
- 輸出物価の円ベースと契約通貨ベースは2016〜2020年はほぼ重なる（2020年は基準年でどちらも100）。2010〜2012年は円ベースが12〜18ポイント下（2012年 95.1 対 112.8）、2015年は8ポイント上。

## 問い直し（結果を見てから追加）：前の円安では、相手の通貨で値下げしていたのか
results/F_reask_episodes.csv・G_reask_yearly.csv・reask.json（src/zz_f282_05_問い直し.py）。
- 数量（H1b）は事前登録の確かめで支持。以下の契約通貨・類別の比較は事後。
- 2012→2015年：契約通貨ベース −9.0%（為替の分 0.248 のうち 38% を値下げに回した計算）、数量 0.980倍。値下げは化学 −15%、金属 −21% に偏り、輸送用機器 −3%、はん用・生産用・業務用機器 +0%、電気・電子機器 −8%。
- 2020→2025年：契約通貨ベース +12.6%（全類別で上昇）、数量 1.027倍。2021→2024年：+6.4%、数量 0.930倍。
- 年ごと（為替の分が +3% を超えた年）：値下げの割合 2013年 14%、2014年 37%、2015年 82%、2022年 −44%（値上げ）、2023年 5%、2024年 −39%、2026年1〜9月 −145%。

## 計画からのずれ
- 起点2019年の確かめ、2026年1〜9月の分解、問い直しは結果を見てから足した。月次の相関の EU 向けと2010〜2019年限定も計画になく後から足した。
- 計画の前に、世界の2021〜2025年の年の金額・数量・価格指数と、米国の2021〜2024年の数量指数を見ていた（PLAN に記載）。
- 年ごとの分解（results/A_yearly_decomp.csv）は図にしていない。

## 言えないこと
- 因果は言えない（世界の物価、半導体・自動車の供給制約、中国の景気などが同時に動いている。2012〜2015年も生産の海外移転や中国・新興国の減速があった（推測））。
- 「品目の構成などの分」は、貿易統計の価格指数（単価）と日本銀行の輸出物価指数（同じ品質の値段）の違いで、構成・品質・統計の作り方が混ざる。
- 月次の相関は単純相関で、世界の需要などをそろえていない。前年同月比が重なるため実質の標本は少なく、12か月より長い遅れは見ていない。
- 相手先別には相手の通貨での値段がない。
- 2026年の値は改定される。
