### school-health-japan：文部科学省「学校保健統計調査」で、子どもの視力と身長の長期推移を調べる

文部科学省「学校保健統計調査」（e-Stat）の年次統計（年齢別の平均身長 1900〜2025年度、学校種別の疾病・異常被患率 1948〜2025年度）と、都道府県別・年齢別の被患率（2024・2025年度）を使ったリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| W1 | 裸眼視力1.0未満の子どもは、1979年度から何ポイント増えたか。何歳で増えるか。都道府県で違うか | 学校種別の推移、1979〜2019年度の線形トレンド（HAC標準誤差、2020〜2023年度は除外）、むし歯との対比、2025年度の年齢別（0.3未満の内訳）、11歳の都道府県別（2024・2025年度の相関） | `src/w1_vision.py` |
| W2 | 子どもの身長の伸びは止まったか。いつ頭打ちになったか | 年齢別の平均身長の推移、年齢ごとの最高値の年度、年度−年齢で作ったおおよその生まれ年ごとの成長曲線、1948→1994年度と1994→2025年度の伸びの比較 | `src/w2_height.py` |

#### 主な結果
- **W1**：裸眼視力1.0未満の割合は、1979年度→2025年度で小学校17.9%→36.1%、中学校35.2%→59.4%、高校53.0%→71.5%に増えた。1979〜2019年度の増え方は10年あたり小学校＋4.0ポイント、中学校＋5.3ポイント、高校＋2.9ポイント。0.3未満の割合は小学校2.7%→10.1%、高校26.3%→42.4%。同じ期間にむし歯のある子は小学校94.8%→30.8%と大きく減った。2025年度は年齢とともに上がり、5歳24%、11歳48%、14歳65%、15歳以上は約71〜72%で、どの年齢でも女子のほうが高く、差は10歳ごろから広がる（17歳 女子77.0%・男子67.2%）。11歳の都道府県別は北海道36.4%〜青森県58.8%で、2024年度との相関は0.78
- **W2**：17歳の平均身長は男子170.9cm・女子158.1cm（いずれも1994年度）が最高で、2025年度は170.6cm・157.9cm。1948→1994年度に男子＋10.3cm・女子＋6.0cm伸びたのに対し、1994→2025年度は−0.3cm・−0.2cm。10年ごとの伸びは男子17歳で1950年代＋3.2cm→1980年代＋0.7cm→1990年代＋0.4cm→2000年代−0.1cm。一方、男子11〜14歳は2024〜2025年度が最も高く（13歳161.1cm、1994年度より＋1.8cm）、最終に近い身長は変わらないまま、伸びる時期が早くなっている。ただし男子13歳は1994年度159.3cm→2019年度160.0cm→2024年度161.1cmで、伸びの多くは2019→2024年度に出ており、調べ方の影響が残っていないかは分けられない。17歳の身長が最も高いのは1977年度ごろ生まれ（年度−年齢）の世代

#### 動かし方
`data/gakko_raw.zip`（年次統計の Excel 2つ）、`data/height_long.csv`、`data/pref_vision.csv` が入っているので、そのまま動きます。zip は最初の実行で `data/raw/` に展開されます。都道府県表の元の Excel を使うときは、e-Stat の「都道府県別 年齢別 疾病・異常被患率等（各年齢ごと）」（表番号8）を `data/raw/gakko_pref2025_3.xlsx`・`gakko_pref2024_3.xlsx` の名前で置いてください。

```bash
pip install -r requirements.txt
cd src
python w1_vision.py
python w2_height.py
```

#### データ
| ファイル | 中身 |
|---|---|
| data/gakko_raw.zip | 年次統計 表10「年齢別 平均身長の推移（明治33年度〜令和7年度）」、表15「学校種別 疾病・異常被患率等の推移（昭和23年度〜令和7年度）」 |
| data/height_long.csv | 年度×性×年齢（5〜17歳）の平均身長（cm） |
| data/pref_vision.csv | 2024・2025年度の都道府県×年齢×性：裸眼視力1.0未満・0.3未満・むし歯の割合（%） |

#### 注意
- 令和2〜5年度（2020〜2023年度）は、コロナで測定の時期がずれた値が入っていて、過去の数値と比べられない、と文部科学省が注記しています。トレンドの計算と最高値の判定からは外し、図では灰色の帯にしました
- 1940〜1947年度は調査がなく、1939年度以前は「生徒児童身体検査統計」で、調べ方が今と同じではありません
- 裸眼視力は1979年度から。眼鏡やコンタクトの人も外した視力で数えます。視力検査はスクリーニングで、近視かどうかの診断ではありません
- 抽出調査です。都道府県の値は標本誤差が大きく、標本が少ない県・年齢では「X」で伏せられています（11歳で2025年度は43都道府県、14歳は33都道府県のみ）
- 年齢は4月1日時点の満年齢です。「生まれ年」は年度−年齢で作った目安で、同じ子どもを追った値ではありません
