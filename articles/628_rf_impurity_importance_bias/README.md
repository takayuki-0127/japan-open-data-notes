# 628 ランダムフォレストの不純度による重要度は、値の種類の多い列をどれだけ重く見るのか（手法の解説・正解の分かるデータで試す）

ランダムフォレストの「変数の重要度」としてよく見る feature_importances_ は、木を分けたときに不純度（混ざり具合）がどれだけ下がったかを足し上げたものです。値の種類が多い列は分け目の候補が多いので、効かなくても「たまたまよく分けられる」分け目が見つかります。**ここでは、効く列が2つ（連続の x1、0/1 の x2）だけの架空の申込みデータに、効かない列を4つ（0/1、10種類の区分、100種類の区分、連続）足し、不純度による重要度と、確かめデータで並べ替えたときの重要度（AUC の下がり方）を50回比べました。** 数字は置いたデータで決まります。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A628 | 効かない列の値の種類で、2つの重要度はどう変わるか | scikit-learn の RandomForestClassifier（200本）、feature_importances_、permutation_importance（確かめデータ、AUC、5回並べ替え）。学習1,000件・確かめ1,000件、50回、seed 628 | `src/a628_rf_importance.py` |

## 主な結果
- **不純度による重要度（50回の平均、合計100%）**：x1（効く、連続）32.5%、**ncont（効かない、連続）21.6%**、n100（効かない、100種類）19.5%、x2（効く、0/1）13.2%、n10（効かない、10種類）10.7%、n2（効かない、0/1）2.5%。効かない4列の合計は 54%
- **効かない列が、効く x2 より上に出た回**：ncont 100%、n100 100%、n10 14%、n2 0%
- **並べ替えの重要度（AUC の下がり方）**：x2 0.139、x1 0.117 に対し、効かない4列は −0.000〜0.001。効かない列が x2 より上に出た回は 0%
- 2つの重要度で、効く列どうしの順位も入れ替わった（不純度では x1 が上、並べ替えでは x2 が上）
