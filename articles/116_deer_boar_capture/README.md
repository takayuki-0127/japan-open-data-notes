## もとのリポジトリの説明

以下は、もとのリポジトリ `wildlife-capture-japan` の README です（同じリポジトリにあったほかの記事の分も含みます）。

### wildlife-capture-japan：環境省「鳥獣関係統計」で、クマ・シカ・イノシシの捕獲と狩猟免状の24年を調べる

環境省「鳥獣関係統計」の1998〜2021年度（平成10〜令和3年度）の表を使ったリポジトリです。狩猟で獲られた獣の数（種類別・都道府県別）、都道府県知事の許可による獣の捕獲数（被害防止や数の調整など）、狩猟免状の交付件数を年度でつなぎました。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| W1 | 狩猟で獲られたクマ（ツキノワグマ・ヒグマ）は年度・都道府県でどう変わったか。狩猟で獲られる獣の中でクマはどのくらいか | 表11（狩猟者登録を受けた者による捕獲鳥獣数）の全国・都道府県の値、期間（1998〜2005／2006〜2013／2014〜2021年度）の平均と合計、獣類の内訳 | `src/w1_bear.py` |
| W2 | 獣の捕獲は「狩猟」から「許可による捕獲」に移ったか。狩猟免状の種類はどう変わったか | 表11の獣類計と表12（1）総括表の獣類の捕獲数の比較、2021年度の都道府県別の割合、表1（狩猟免状交付状況）の免許の種類別件数 | `src/w2_permit.py` |

#### 主な結果
- **W1**：狩猟で獲られたツキノワグマは年259頭（2006年度）〜676頭（2000年度）で、平均は1998〜2005年度514頭、2014〜2021年度369頭。ヒグマ（北海道）は121頭→56頭。前年度より半分前後に減った年度（2004年度−45%、2006年度−54%）と倍増した年度（2005・2007年度）が交互に出る。2014〜2021年度の合計は岩手510頭、群馬426頭、福島325頭、秋田267頭、岐阜260頭で、上位5県で60.5%。1998〜2005年度と比べると福井（328→106頭）、栃木（192→53頭）、富山（208→70頭）で大きく減り、石川（140→203頭）は増えた。狩猟で獲られる獣類のうちクマは0.1〜0.3%で、ニホンジカとイノシシの割合は62%（1998年度）→94%（2021年度）
- **W2**：許可による獣類の捕獲は12.7万（1998年度）→117.1万（2021年度）と9.2倍になり、狩猟による捕獲（30.8万→28.3万）を2008年度に上回った。2021年度は獣類の捕獲の80.5%が許可による捕獲で、47都道府県のうち44で半分を超えた（2008年度は25）。割合が高いのは長崎99.5%、香川97.2%、東京96.3%、低いのは奈良14.7%、沖縄26.2%、秋田41.7%。狩猟免状は総計が21〜23万件でほぼ横ばいだが、第一種銃猟（2000年度までは乙種）は18.9万件→8.4万件と55%減り、わな猟は5.2万件（2007年度）→11.9万件（2021年度）と2.3倍で、2015年度から第一種銃猟を上回る

#### 動かし方
`data/` の3つの CSV が入っているので、そのまま動きます。

```bash
pip install -r requirements.txt
cd src
python w1_bear.py
python w2_permit.py
```

元の Excel から作り直すときは、各年度の表を `data/raw/` に「年度_ファイル名」（例：`h10_H10-11.xls`、`r03_R3-12-01.xlsx`）の名前で置き、3つの CSV を消してから実行してください。元の Excel は合わせて約15MBあるので、リポジトリには入れていません。
- 入手先：環境省「鳥獣関係統計」 https://www.env.go.jp/nature/choju/docs/docs2/index.html （年度ごとのページの「狩猟免状交付状況」「狩猟者登録を受けた者による捕獲鳥獣数」「都道府県知事の捕獲許可による捕獲鳥獣数(1)総括表」）
- 使った年度：平成10（1998）〜令和3（2021）年度。表12は平成11・12年度のファイルがなく、1999・2000年度の値は平成13年度の表に載っている値を使った

#### データ
| ファイル | 中身 |
|---|---|
| data/hunt_species.csv | 狩猟による捕獲数（表11の「計」の列）。全国は獣類の種類別と獣類計、都道府県はツキノワグマ・ヒグマ・ニホンジカ・イノシシ・獣類計 |
| data/permit_mammals.csv | 都道府県知事の許可による獣類の捕獲数の合計（表12（1）総括表）、全国と都道府県 |
| data/license.csv | 狩猟免状の交付件数（全国）：総計、甲種・乙種・丙種（2000年度まで）、網・わな（2001〜2004年度）、網（2005・2006年度は網・わな）、わな（2007年度から）、第一種・第二種銃猟（2001年度から） |

#### 注意
- 鳥獣関係統計はこのサイトでは2021年度（令和3年度）までで、2022年度以降はこのデータに入っていない
- 表12の許可による捕獲は獣類の合計で、種類別（クマ・シカ・イノシシなど）には分けていない。種類別は別の表（12（2）など）にあり、今回は取得していない。クマの捕獲の多くは許可による捕獲（有害鳥獣捕獲など）で行われるため、W1 の狩猟の数はクマの捕獲全体ではない
- 環境大臣の許可による捕獲（表14）は含めていない
- 年度ごとの値は、その年度の表に載った値を使った。次の年度の表で前年度の値が修正されていることがある（例：2002年度のツキノワグマは平成14年度の表で649頭、平成15年度の表で1,028頭）
- 2002年度までの表のツキノワグマは「クマ」、ニホンジカは「オスジカ」「メスジカ」、2021年度のイノシシ・ニホンジカは性別の内訳と合計がある。合計にそろえた
- 1998年度の表にある1996・1997年度の値は、ニホンジカの数え方が違うように見えるため使っていない
- 狩猟免状の件数は有効な免状の件数で、人数ではない。2007年度に網とわなが別の免許になり、両方を持つ人が2件に数えられる
- 許可による捕獲が増えた理由（被害防止の取り組み、2008年施行の鳥獣被害防止特措法、捕獲への報奨金など）は、このデータでは分けられない
