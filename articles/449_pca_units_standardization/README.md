# 449 指標の単位をそろえないまま主成分分析をすると、第1主成分はどれだけ変わるのか（手法の解説）

単位や桁の違う指標を**そのまま主成分分析にかけたとき、第1主成分がどれだけ単位に引っぱられるか**を、架空の店300店・指標8本と、公的データ（SSDSE-B の都道府県8項目）で確かめたフォルダです。F116（重みで変わる総合指標）と近いですが、単位と標準化に絞っています。地域の順位は載せていません。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A449 | そのまま／標準化／対数にしてから標準化で、第1主成分の重みと、得点の順位はどれだけ変わるか。単位を書き換えるとどうなるか | 特異値分解による主成分分析。1回分の例＋1,000回のくり返し＋売上高の単位の書き換え＋公的データの例 | `src/a449_pca_units.py` |

## 置いたこと（架空）
- 店300店。隠れた性質「規模」「質」（どちらも標準正規）と、指標ごとの固有の振れから作る
- 指標8本：売上高（円）、従業員数（人）、売場面積（㎡）、客単価（円）、粗利率（%）、リピート率（0〜1）、営業年数（年）、在庫回転（回）
- 対数に直すのは、売上高・従業員数・売場面積・客単価の4本
- 公的データ：SSDSE-B-2026 の2023年度・47都道府県・8項目（`data/ssdse_b_2023_8items.csv`）。対数に直すのは、総人口・住宅地の標準価格・延べ宿泊者数

### 公的データの例（47都道府県・8項目）

## 確かめたこと
- 空のフォルダで計算し直し、data（example_stores.csv）・results・figures が一致した
- 標準化した主成分分析は、単位を書き換えても重みが変わらない（最大の差0）
- 重みの2乗の合計は、どの方法でも1

## 注意（言えないこと）
- 架空の店の数字です。指標の選び方と、規模・質の効き方の置き方で、重みは変わります
- 標準化が「正しい」と言うものではありません。標準化すると、ほとんど差のない指標も、差の大きい指標と同じ重さになります。同じ単位の指標どうしなら、そのまま使うほうが合う場合もあります
- 対数に直す指標は作成者が選びました
- 第2主成分より後ろは比べていません
- 都道府県の例は、単位の影響を見るためのものです。この8項目で都道府県を並べることに意味があるとは言っていません。順位は載せていません
