# 1252 本ごとの売れ方を出した月で比べると、月の途中で出した本はどう見えるのか？（電子書籍）

電子書籍の売れ方を本ごとに比べるとき、「発売した月に何冊売れたか」を並べることがあります。ところが月の25日に出した本は、その月に6日ほどしか売っていません。冊数で比べれば低く見え、売っていた日数で割って1日あたりにすると、発売直後に売れる山だけを数えることになり、今度は高く見えます。翌月の冊数で比べても、月末に出した本は山の続きが翌月に入ります。**ここでは、作成者が置いた架空の電子書籍48冊（本ごとの「ふだんの1日の冊数」（本当の売れる力）と、発売直後の山の形を作成者が置き、1日の冊数を乱数で作ったもの）で、①発売した月の冊数、②発売した月の1日あたり、③発売から30日の冊数、④発売の翌月の冊数の4つで比べたとき、月の途中で出した本がどう見えるか、本当の売れる力の順にどれだけ合うかを数えました。山の高さ・山の減り方・本どうしの差を変えた36通りでも確かめました。**

例の本・売れ方は架空のもので、実在の販売サイトの集計のしかたを表すものではありません。いつ本を出すとよいか、値段・広告の決め方、売上の見込みの助言はしていません。

関連する記事：1000「再来場率は、何日以内で数えるかでどう変わるのか？」は、締めた日の直前に初めて来た人ほど戻るための日数が足りずに低く見えることを、1208「送ってから何日目で開封率を締めるかで、遅く開く人の多い配信はどれだけ低く出るのか？」は、締めた後の開封が数に入らないことを扱っています。1248「発売した週の山を含めて平均すると、ふだんの1日の売れ方はどう見えるのか？」は、同じ発売の山が、発売からの日数で割った平均をどれだけ押し上げるかを扱っています。この記事は、電子書籍の発売直後に売れる山があるため、月で区切ると月の後半に出した本が、数え方によって低くも高くも見える点に絞ります。

## 主な結果

### 式どおり：ふだん1日1冊の本を30日の月に出したときの見込み（`results/expected_by_release_day.csv`）
| 比べ方 | 1日に出した | 25日に出した | 25日÷1日 |
|---|---|---|---|
| ①発売した月の冊数 | 59.634冊 | 23.296冊 | **0.3906倍** |
| ②発売した月の1日あたり | 1.988冊 | 3.883冊 | **1.9532倍** |
| ③発売から30日の冊数 | 59.634冊 | 59.634冊 | 1倍 |
| ④発売の翌月の冊数（翌月30日） | 30.408冊 | 42.576冊 | 1.4002倍 |

- 同じ売れる力の本でも、25日に出すと①は1日に出した本の0.3906倍、②は1.9532倍に見えた。③は出した日によらない（式どおり）

### 出した日の区切りごと（基本の置き方、300回、`results/by_release_day_bin.csv`）
本当の売れる力1あたりの値を、1〜10日に出した本を1とした比で示します。

| 比べ方 | 1〜10日 | 11〜20日 | 21日〜末日 |
|---|---|---|---|
| ①発売した月の冊数 | 1 | 0.7695 | **0.3849** |
| ②発売した月の1日あたり | 1 | 1.2697 | **1.8679** |
| ③発売から30日の冊数 | 1 | 0.9989 | 1.003 |
| ④発売の翌月の冊数 | 1 | 1.0895 | 1.4456 |

### 本当の売れる力の順との合い方（基本の置き方、300回、`results/a1252_main.json` の `headline`）
| 比べ方 | 大小が同じ向きの組（1,128組中） | 本当の上位10冊の当たり |
|---|---|---|
| ①発売した月の冊数 | 75.66% | **66.03%** |
| ②発売した月の1日あたり | 82.68% | 67.27% |
| ③発売から30日の冊数 | 93.83% | **90.97%** |
| ④発売の翌月の冊数 | 86.59% | 77.13% |

- ③は出した日による偏りがない作りなので（作りどおり）、外れは1日の冊数の揺れの分だけ
- ①は月の後半に出した本を本当の力より下に、②と④は上に見せるので、③より合わなかった

### 確かめ：36通り（各40回、`results/grid.csv`）
- 本当の上位10冊の当たりは、①で41〜78%、②で41.5〜89.5%、③で77.25〜95.75%、④で47〜93.25%だった
- 36通り中33通りで③がいちばん合った。残りの3通りはすべて山の高さ0の置き方で、④が③を最大0.0031（大小が同じ向きの組の割合）上回っただけだった（④も③も、ほぼ1か月の日数を数えるため）
- 36通り中32通りで①がいちばん合わなかった。残りの4通りは山の高さ8・τ3日か7日の置き方で、②がいちばん合わなかった（山が高く短いほど、②は発売直後の山だけを数える）
- 山の高さ0（発売直後の山がない）でも、①の上位10冊の当たりは平均53.75%、③は86.42%だった。①のずれは山がなくても、売っていた日数の違いで起きる

## データ
- `data/books_one_set.csv`：1回分の48冊（book_id・true_daily（ふだんの1日の冊数）・release_dayofyear（発売の日、1年の何日目か）・release_month・release_day・days_on_sale_in_month（発売した月に売っていた日数）・m1_month〜m4_next_month（①〜④の値））
- `results/a1252_main.json`：主な結果すべて（`headline` に基本の置き方、`expected_30day_month_day1_vs_day25` に式どおりの値、`robust` に確かめのまとめ）
- `results/expected_by_release_day.csv`：ふだん1日1冊の本を30日の月の1〜30日に出したときの①〜④の見込み
- `results/by_release_day_bin.csv`：出した日の区切りごとの、本当の売れる力1あたりの値（`vs_1to10` は1〜10日を1とした比）
- `results/reps_base.csv`：基本の置き方の300回（`concord_` は大小が同じ向きの組の割合、`top10_` は上位10冊の当たり）
- `results/grid.csv`：確かめの36通り（`peak` は山の高さ、`tau` はτ（日）、`sigma` は本どうしの差）

## 注意（言えないこと）
- 架空のデータと、作成者が置いた売れ方の形です。発売直後の山の高さと減り方で、②と④のずれの大きさはほぼ決まります。実際の本の売れ方の形を表すものではありません
- 本の売れる力は1年のあいだ変わらず、曜日・季節・ほかの本の発売の影響もないと置きました
- 山の形は、どの本も同じ高さ・同じ減り方と置きました。本ごとに山の形が違うと、③でも合わなくなります
- 11月・12月に出した本は入れていません（翌月の冊数をそろえて数えるため）
- いつ本を出すとよいかは扱っていません
