# 849 作業ごとの見積もりを足すと、全体の見積もりは何%足りなくなるのか？（見積もりと締め切り）

プロジェクトの日数は、作業ごとの見積もりを足して出すことがよくあります。作業ごとの見積もりが「半々で終わる日数」として正しくても、作業の日数は早く終わる幅より遅れる幅のほうが大きいので、足した合計は全体の日数として足りなくなります。**ここでは、作成者が乱数で作った架空のプロジェクト（作業10個を順に行う。作業ごとの本当の日数の分布を作成者が置いたもの）で、作業ごとの見積もりを足した合計と、実際の合計日数を比べ、何%足りないか・合計以内に終わる確率はどれくらいかを数えました。作業の数・ばらつき・作業どうしが一緒に延びる度合いを変えた確かめも行いました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A849 | 作業ごとに正しく見積もっても、足した合計は全体の日数として何%足りないか。合計以内に終わる確率はどれくらいか | 架空のプロジェクト。作業10個を順に行う（並行なし）。作業ごとの見積もり（日）は2〜10日の整数を乱数で置いた（合計61日、`data/tasks.csv`）。作業の実際の日数は対数正規分布（右に長い分布。早く終わる幅より遅れる幅が大きい）で、中央値＝見積もり・ばらつき sigma=0.5（日数の対数の標準偏差）。つまり、どの作業も見積もり以内に終わる確率は50%で、見積もりは作業ごとには正しい。作業どうしは互いに影響しない（基本）。実際の合計を20万回作り、見積もりの合計と比べた。作業の数（1・2・3・5・10・20・40個。40個の見積もりの先頭から取る）とばらつき（sigma=0.3・0.5・0.8）を変えた表も作った。確かめとして、共通の振れ（全部の作業が一緒に延びたり縮んだりする度合い rho=0・0.2・0.5・0.8・1。1は全部が同じ割合で延びる）、ばらつき sigma=0.3・0.8、分布をガンマ分布（ばらつきの大きさ＝変動係数は同じ、中央値を見積もりに合わせる）、作業の大きさをそろえる（各6.1日）を数えた。seed 849 | `src/a849_sum_of_tasks.py` |

関連する記事：850「『最もありそうな日数』で計画すると、間に合う確率は何%か？」は見積もりの1つの数の選び方を、851「並行する作業が増えると、全体の遅れはどれだけ増えるのか？」は並行する作業の合流を、852「余裕を作業ごとに持つのと、最後にまとめて持つのでは、どちらが間に合いやすいか？」は余裕の置き方を扱います。850 の表の「半々の日数」の行は、この記事と同じ「中央値を足す」計画ですが、作業の日数の置き方が違うので値も違います（850は合計59日で26.06%）。この記事は、順に行う作業の見積もりを足すことだけを扱います。

## 主な結果

### 作業10個・ばらつき sigma=0.5・作業どうし独立（20万回）
| | 値 |
|---|---|
| 見積もりの合計 | 61日 |
| 実際の合計の平均 | 69.12日（**+13.31%**） |
| 実際の合計の中央値（半々で終わる日） | 67.75日（+11.07%） |
| 実際の合計の8割点（8割の確率でこれ以内） | 79.18日（+29.80%） |
| 実際の合計の9割点 | 86.06日（+41.08%） |
| 見積もりの合計以内に終わる確率 | **27.98%** |
| 作業ごとに見積もり以内に終わる確率 | 49.85〜50.09% |
| 10個すべてが見積もり以内に終わる確率 | 0.105% |

- 作業ごとには半々で見積もり以内に終わるのに、足した合計61日以内に終わったのは28%だった。実際の合計は平均で13.31%（約8日）多かった
- 見積もりを超える作業は平均5.006個で、超えた作業の遅れの合計は平均17.28日、見積もりより早く終わった作業の早まりの合計は平均9.16日だった。遅れの幅が早まりの幅より大きいので、足すと遅れが残る
- 平均の不足13.31%は、対数正規分布の式（平均＝中央値×exp(sigma²/2)）から出る13.31%と一致した

### 作業の数・ばらつきと、見積もりの合計以内に終わる確率（20万回）
| 作業の数 | sigma=0.3 | sigma=0.5 | sigma=0.8 |
|---|---|---|---|
| 1 | 50.21% | 49.95% | 50.15% |
| 2 | 46.26% | 43.94% | 41.18% |
| 3 | 43.55% | 39.70% | 35.25% |
| 5 | 41.07% | 36.01% | 29.73% |
| 10 | 35.99% | 28.05% | 19.30% |
| 20 | 29.19% | 18.82% | 9.25% |
| 40 | 20.20% | 9.08% | 2.30% |

| | sigma=0.3 | sigma=0.5 | sigma=0.8 |
|---|---|---|---|
| 平均の不足（作業の数によらない） | 4.54〜4.63% | 13.29〜13.44% | 37.59〜37.82% |
| 8割点の超過（作業10個） | 13.74% | 29.81% | 69.30% |

- 平均で何%足りないかは、ばらつきだけで決まり、作業の数では変わらなかった（sigma=0.3で約4.6%、0.5で約13.3%、0.8で約37.7%）
- 見積もりの合計以内に終わる確率は、作業が増えるほど下がった。作業40個・sigma=0.5では9.08%
- 作業10個・sigma=0.5の行（28.05%）は、上の表（27.98%）と乱数が別なので0.07ポイント違う

### 確かめ：置き方を変えると（作業10個・見積もりの合計61日）
| 置き方 | 合計以内に終わる確率 | 平均の不足 | 9割点の超過 |
|---|---|---|---|
| 共通の振れ rho=0（基本と同じ置き方・別の乱数） | 27.92% | 13.33% | 41.09% |
| 共通の振れ rho=0.2 | 37.85% | 13.32% | 55.53% |
| 共通の振れ rho=0.5 | 44.23% | 13.29% | 71.01% |
| 共通の振れ rho=0.8 | 48.17% | 13.31% | 82.66% |
| 共通の振れ rho=1（全部が同じ割合で延びる） | 50.00% | 13.39% | 89.96% |
| ばらつき sigma=0.3 | 36.10% | 4.54% | 19.24% |
| ばらつき sigma=0.8 | 19.09% | 37.76% | 95.61% |
| 分布をガンマ分布に（ばらつきは同じ） | 32.74% | 10.23% | 37.24% |
| 作業の大きさをそろえる（各6.1日） | 25.35% | 13.29% | 38.34% |

- 置き方で、合計以内に終わる確率は19.09〜50.00%、平均の不足は4.54〜37.76%まで動いた
- 作業どうしが一緒に延びやすいほど、合計以内に終わる確率は50%に近づいた。ただし平均の不足は13.3%のまま変わらず、1割の確率で起きる大きな超過は41%から90%まで広がった。「合計以内に終わる確率」が上がっても、外れたときの外れ方は大きくなる
- ガンマ分布は対数正規分布より右の裾が短いので、平均の不足は10.23%と少し小さかった

## 注意（言えないこと）
- 架空のプロジェクトです。作業の日数の分布の形、ばらつき、作業どうしの関係は作成者が置いたもので、結果はこれで決まります。置き方で、合計以内に終わる確率は19〜50%、平均の不足は約5〜38%まで動きました
- 作業ごとの見積もりは「半々で終わる日数」として正しいと置きました。実際の見積もりがもっと楽観的（または慎重）なら、不足はこれより大きく（小さく）なります。実際の見積もりがどちらに偏っているかは、この分析では分かりません
- 作業は順に行い、前の作業が早く終わればすぐ次に進めると置きました。早く終わっても次の作業を予定日まで始めない場合は、早まりが使われないので、不足はこれより大きくなる（推測）
- 実在のプロジェクトや会社の実績を表すものではありません
