# F137 郵便物は、いつ半分になるのか？（減衰モデルと予測区間）

## 問い
手紙やはがきの数（郵便物の引受物数）は減り続けている。このまま減ると、いつ今の半分になるのか。減り方の「形」（一定の割合で減る／減り方が加速する／下限に近づく）の決め方で、答えはどれだけ変わるのか。

## データ
| データ | 期間 | 単位 | 使い方 |
|---|---|---|---|
| 日本郵便「郵便物・荷物の引受物数」年度版（2013〜2026年公表のPDF 13本） | FY2011〜FY2025 | 千通（個） | 主分析。種類別（第一種・第二種・年賀・第三種・特殊・国際・荷物） |
| 総務省 郵政民営化関係資料（080919_2_si4.pdf）「種類別引受物数等の推移」 | FY2003〜FY2007 | 百万通 | 長期の確認（頑健性） |
| 情報通信白書 平成15年版「総引受郵便物数の推移」 | FY1992〜FY2002 | 億通 | 図1の参考のみ |

- 「郵便物」は手紙・はがき・定期刊行物・書留など（国際の差立を含む）。ゆうパック・ゆうメール・ゆうパケットは「荷物」で、郵便物に含まない（2007年10月の民営化以降の区分。総務省資料のFY2003〜2007も同じ区分で並べてある）。
- FY2008〜FY2010 は年度版が見つからず、欠けている。FY2010 だけは FY2011 の前年比（小数1桁）から逆算でき、頑健性の確認に使った。
- 2025年公表版から、ゆうパックとゆうパケットの区分が変わり前年度欄が書き換えられたため、荷物は合計だけを使う。
- データ: `data/postal_annual_long.csv`（年度×種類、出所つき）、`data/postal_annual_wide.csv`、`data/raw/f137_postal_annual.json`（PDFから取り出した文字列と読み取り結果）。

## 手法
- 主分析は郵便物 FY2011〜2025（15年度、億通）。t = 年度 − 2025。
- 4つの減衰モデルを対数で当てはめた。
  1. 指数（一定の割合で減る）: log y = a + b t
  2. 対数2次（減り方が加速）: log y = a + b t + c t²
  3. ロジスティック（下限あり）: y = F + (U − F) / (1 + exp(k (t − t0)))
  4. 指数＋下限: y = F + A exp(−k t)
- 「半分」の基準は FY2025 の実績（117.5億通）の半分 = 58.8億通。モデルの線がこれを下回る年度を求めた。
- 予測区間: 対数の残差のブートストラップ（1,000回、乱数の種 137）で、当てはめ直したモデルが半分を下回る年度の5%点〜95%点。2100年度までに下回らない回の割合も出した。
- 予測の当たり方: FY2017〜2022 を起点に、それまでのデータだけで当てはめ、1〜3年先を予測したときの平均絶対誤差率（ローリング予測）。
- 種類別: FY2016〜2025（とFY2011〜2025）の指数モデルの年率と半減期。

## 結果
1. **FY2003 の半分はすでに割った。** 郵便物は FY2003 の 248.9億通から FY2025 の 117.5億通（47%）へ減り、FY2025 に初めて FY2003 の半分を下回った。
2. **減り方は速くなっている。** 年率は FY2011→16 が −1.5%、FY2016→21 が −3.5%、FY2021→25 が −5.7%。FY2023 から3年続けて −6〜−7.5%（FY2024 は2024年10月の料金改定の年で −7.5%）。
3. **「次の半分」の年はモデルの形で15年ずれた。**

| モデル | AIC | 半分になる年度 | 90%予測区間 | FY2030 の予測（億通） |
|---|---|---|---|---|
| 指数（一定の割合、年 −3.3%） | −93.5 | 2048 | 2045〜2052 | 108（98〜115） |
| 対数2次（加速） | −130.9 | 2033 | 2033〜2034 | 81（78〜85） |
| ロジスティック（下限あり） | −134.6 | 2032 | 2031〜（11%は2100年度まで届かず） | 74（70〜90） |
| 指数＋下限 | −91.5 | 2048 | 2046〜（30%は届かず） | 108（100〜123） |

   - 下限 F は、ロジスティックでも指数＋下限でも 0 と推定された。15年分の減り方からは「ここで止まる」という水準は読み取れない。
   - それぞれのモデルの中の予測区間は数年の幅だが、モデルの選び方による違い（2032〜2048年度）のほうがずっと大きい。
4. **過去の予測では、加速型がよく当たった。** ローリング予測の平均絶対誤差率は、対数2次 2.4%、ロジスティック 3.7%、指数 7.1%（3年先では 3.3%、5.1%、10.5%）。
5. **値上げ前のデータだけでも、加速型は大きく外さなかった。** FY2023 までで当てはめると、FY2025 の予測は指数で実績より14%多く、対数2次で4%、ロジスティックで6%多かった。
6. **種類で減り方は大きく違う（FY2016〜2025、年率と半減期）。** 年賀 −14.5%（4年）、第三種 −4.7%（14年）、第二種（はがき）−4.3%（16年）、第一種（封書）−3.0%（23年）。特殊（書留など）+0.5%、荷物 −0.7% でほぼ横ばい。年賀は FY2011 の 26.8億通から FY2025 の 5.1億通へ、郵便物に占める割合は FY2003 の 13.5% から 4.3% に下がった。

## 頑健性
| 確認 | 指数 | 対数2次 | ロジスティック |
|---|---|---|---|
| 主分析 FY2011〜2025 | 2048 | 2033 | 2032 |
| R1 期間を FY2016〜2025 に | 2041 | 2033 | 2032 |
| R2 FY2003〜2025（FY2008〜10は欠け） | 2052 | 2039 | 2039 |
| R3 FY2020（コロナ）を除く | 2048 | 2033 | 2032 |
| R4 値上げ前の FY2023 まで | 2055 | 2035 | 届かず |
| R5 FY2010（逆算）を加える | 2049 | 2034 | 2032 |
| R6 荷物を含む総計 | 2057 | 2034 | 届かず |

- どの確認でも「一定の割合で減る」なら2040〜50年代、「加速が続く」なら2030年代で、モデルの形による差は残った。
- 荷物を含む総計では、荷物がほぼ横ばいのため下限ありのモデルは半分に届かない。

## 言えないこと
- どのモデルが正しいかは、このデータからは決められない。加速型は過去の予測がよく当たったが、減り方の加速がこの先も続く保証はない。2次の項は、遠い将来ほど減り方を大きく見積もる。
- 値上げ（2024年10月）、デジタル化、年賀状じまいなど、減った理由は分けていない。値上げの影響を取り出すには月次のデータが要る。
- 半分になる年は「FY2025 の実績の半分」を基準にしている。基準を変えれば年も変わる。
- 予測区間は、モデルの形が正しいと仮定したうえでのぶれで、モデル選びの不確かさは含まない。
- FY2008〜2010 は欠けており、2003〜2007年度は別の資料（総務省）の値をつないでいる。
- 2007年の民営化の前後で、ゆうメール（旧冊子小包）の扱いが変わっている。
