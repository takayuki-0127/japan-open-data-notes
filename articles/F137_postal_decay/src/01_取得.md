# 01 取得

データはすべてブラウザ（Chrome）で取得した。官公庁・日本郵便のサイトは作業用コンテナから直接取れないため。

## 1. 日本郵便「郵便物・荷物の引受物数」年度版（FY2011〜FY2025）
- 2013〜2025年に公表された年度版のPDF 13本（URLは `data/raw/f137_postal_annual.json` の `urls`）。
- 各PDFは「当年度」と「前年度」の2年分の表を載せているので、FY2011〜FY2025 の15年度がそろう（2018年公表のFY2017版は見つからなかったが、2019年公表版の前年度欄で補える）。
- 取得方法: 日本郵便のページ上で `fetch` → pdf.js（cdnjs 4.0.379）で文字を取り出し（`01_取得.js`）、表の行（総計・郵便物・第一種…ゆうメール）を正規表現で読んだ。生の文字列も JSON に残してある。
- 2013〜2024年公表分は `https://www.post.japanpost.jp/notification/pressrelease/<年>/00_honsha/<月日>_0x_01.pdf`。公表一覧が残っていないため、4/15〜6/15 の日付を総当たりで確かめて見つけた。

## 2. 総務省資料（FY2003〜FY2007）
- 総務省「郵政民営化に伴うユニバーサルサービス」関係資料 080919_2_si4.pdf「種類別引受物数等の推移」（百万通）。数値は `02_整形.py` に直接書いた。

## 3. 情報通信白書 平成15年版（FY1992〜FY2002、参考）
- 図表「総引受郵便物数の推移」（億通、整数）。長期の流れを見る図だけに使い、モデルには入れていない。

FY2008〜FY2010 は年度版の公表資料が見つからず、欠けたまま扱う（FY2010 は FY2011 の前年比から逆算した値を頑健性の確認だけに使う）。
