# 1000 再来場率は、何日以内で数えるかでどう変わるのか？（来場者と集客）

「初めて来た人のうち、また来た人の割合」（再来場率）は、何日以内に戻った人を数えるかを決めないと値が決まりません。30日以内と365日以内では、同じ人たちでも値が倍ほど違います。しかも、すぐ戻る人が多い施設と、しばらくしてから戻る人が多い施設では、日数を変えると上下が入れかわります。データを締めた日の直前に初めて来た人は、戻るための日数がまだたっていないので、そのまま数えると再来場率が低く見えます。**ここでは、作成者が乱数で作った架空の施設の初来場者（次に来るまでの日数の分布を作成者が置いたもの）で、数える日数で再来場率がどれだけ動くか、1年分のデータで締めたときに初来場の月ごとの再来場率がどうずれるか、架空の施設40か所を30日以内と365日以内で並べたときにどれだけ入れかわるかを数えました。**

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A1000 | 再来場率は、数える日数（7〜365日）でどれだけ動くか。データの締め日で、後の月の初来場者の再来場率はどれだけ低く見えるか。施設を並べると、30日以内と365日以内で順位はどれだけ入れかわるか | 架空の施設の初来場者。次に来るまでの日数を、二度と来ない人（割合 q）、すぐ戻る人（平均 near 日の指数分布、戻る人のうち割合 s）、しばらくして戻る人（平均 far 日の指数分布）の3種類で置いた。本当の「W日以内の再来場率」は (1−q)×(s×(1−e^(−W/near))＋(1−s)×(1−e^(−W/far))) の式で決まる。施設A：q＝0.55、s＝0.4、near＝14日、far＝150日。(1) 施設Aの初来場者2万人を全員365日以上追えるとして、7・14・30・60・90・180・365日以内の再来場率を数え、式の値と比べた。(2) 施設Aの初来場者2万人の初来場日を365日の中で一様に置き、365日目でデータを締めた。初来場の月（1〜12月目）ごとに、締め日までに再来場した割合、90日以内に再来場した割合（90日たっていない人も入れる）、90日以内に再来場した割合（月の全員が90日を追える月だけ）を出した。(3) 架空の施設40か所（q は0.4〜0.8、s は0.1〜0.9、near は7〜30日、far は90〜300日の一様分布から施設ごとに引く）で、各2,000人の初来場者の30日以内と365日以内の再来場率を出し、順位相関（スピアマン）・上位10か所の重なり・1位が同じ割合を数えた（施設を作り直して200回）。比べる相手として、同じ40か所で初来場者を引き直した30日以内どうし（取り直しの振れ）と、式の値どうし（人数の振れなし）も出した。確かめとして、near を3〜10・7〜30・20〜60日、far を60〜150・90〜300・200〜600日に変えた9通り（各100回）。seed 1000 | `src/a1000_return_window.py` |

## 主な結果

### 数える日数で、同じ人たちの再来場率が動く（施設A、2万人、`results/curve_facility_a.csv`）
| 数える日数 | 数えた再来場率 | 置いた分布からの式の値 |
|---|---|---|
| 7日以内 | 8.14% | 8.31% |
| 14日以内 | 13.26% | 13.78% |
| 30日以内 | **20.17%** | 20.78% |
| 60日以内 | 26.32% | 26.65% |
| 90日以内 | 29.62% | 30.15% |
| 180日以内 | 36% | 36.87% |
| 365日以内 | **41.69%** | 42.63% |

- **同じ施設の同じ初来場者でも、30日以内なら20.17%、365日以内なら41.69%だった**。この曲線は置いた分布の式どおりで（差0.94ポイント以内）、数えたのは日数を決めずに再来場率を言うとどれだけ違う数字になり得るか、という幅です
- 365日以内に戻った人のうち、30日以内に戻っていた人は48.38%。残りは31日目以降に戻っていた
- 二度と来ない人を55%と置いたので、日数をどれだけ延ばしても、いつかは戻る人の45%を超えない

### 1年分のデータで締めると、後の月ほど低く見える（`results/cohort_by_month.csv`）
| 初めて来た月 | 締め日までに再来場した割合 | 90日以内（90日たっていない人も入れる） | 90日以内（90日たった人だけ） |
|---|---|---|---|
| 1月目 | 39.96% | 29.62% | 29.62% |
| 6月目 | 38.71% | 31.39% | 31.39% |
| 9月目 | 32.07% | 30.41% | 30.41% |
| 10月目 | 29.61% | 29.61% | （出せない） |
| 11月目 | 25.19% | 25.19% | （出せない） |
| 12月目 | **13.98%** | **13.98%** | （出せない） |

- 本当の再来場率は、どの月も同じ（90日以内30.15%、365日以内42.63%）と置いた
- **「締め日までに再来場した割合」は、1月目の初来場者で39.96%、12月目で13.98%と、後の月ほど下がって見えた**。後の月の人ほど、戻るまでの日数がデータの中に残っていないため。1年分をまとめると34.2%（初来場日が一様なときの式の値は34.19%）で、日数の決まっていない数字になる
- 90日以内に決めても、90日たっていない人を入れると、11月目は25.19%、12月目は13.98%に下がり、全員をまとめると28.46%（本当は30.15%）
- 月の全員が90日を追える1〜9月目だけで数えると、29.17〜31.7%で、まとめて30.37%（14,984人）。本当の30.15%に合った。10月目以降は、90日以内の再来場率はまだ出せない

### 施設40か所の順位は、30日以内と365日以内で入れかわる（各200回の平均、`results/rank_pairs.csv`）
| 比べた日数 | 順位相関 | 上位10か所の重なり | 1位が同じ割合 |
|---|---|---|---|
| 7日と30日 | 0.939 | 8.13か所 | 61.5% |
| 30日と90日 | 0.931 | 8.22か所 | 54% |
| 30日と180日 | 0.835 | 7.18か所 | 39.5% |
| **30日と365日** | **0.718** | **6.13か所** | **26%** |
| 90日と365日 | 0.874 | 7.34か所 | 46% |
| （比べる相手）30日どうし、初来場者を引き直す | 0.983 | 9.35か所 | 82.5% |
| （比べる相手）30日と365日、式の値どうし | 0.72 | 6.23か所 | 28% |

- **30日以内と365日以内では、上位10か所のうち平均6.13か所しか重ならなかった**。同じ30日以内で初来場者を引き直したとき（9.35か所）よりずっと少ない
- 式の値どうし（人数の振れなし）でも6.23か所で、入れかわりはほぼすべて、施設ごとに置いた「すぐ戻る人」と「しばらくして戻る人」の割合の違いから来ていた
- 図3の回（200回目、順位相関0.717）では、1位は30日以内でも365日以内でも施設30で同じだったが、順位がいちばん動いた施設は22位動いた

### 確かめ：戻るまでの日数の置き方（9通り、各100回、`results/grid_near_far.csv`）
- 30日と365日の順位相関は0.7〜0.795、上位10か所の重なりは5.99〜7.31か所、1位が同じ割合は20〜59%だった
- 同じ30日以内で初来場者を引き直したときは、順位相関0.974〜0.989、重なり8.92〜9.42か所で、9通りのどれでも日数を変えたときの入れかわりのほうが大きかった

## 動かし方
```
pip install -r requirements.txt
cd src && python a1000_return_window.py
```
15秒ほどで終わります。`data/facility_a_first_visits.csv` と `data/facilities_one_rep.csv` もこのとき作ります。

## 確かめたこと
- 空のフォルダ（/tmp）に src と requirements.txt を写して流し直し、results・figures・data の10ファイルがバイト単位で一致した（cmp、約15秒）
- 施設Aの7〜365日以内の再来場率が、置いた分布の式の値と0.94ポイント以内で合った
- 1年分を締めたときの「締め日までに再来場した割合」の全体34.2%が、初来場日が一様なときの式の値34.19%と合った
- 90日を追える月だけで数えた90日以内の再来場率（30.37%）が、本当の値（30.15%）と合った

## 注意（言えないこと）
- 架空のデータです。二度と来ない人の割合、すぐ戻る人としばらくして戻る人の割合と日数は、作成者が置いたものです。再来場率の曲線（7日以内8.14%〜365日以内41.69%）と締め日での下がり方は、置いた分布の式どおりの値です。新しく数えたのは、施設を並べたときに日数を変えると上位10か所が平均6.13か所しか重ならない（置き方で5.99〜7.31か所）という入れかわりの大きさです
- 入れかわりは、施設ごとに「すぐ戻る人」と「しばらくして戻る人」の割合が違うと置いたから出ます。どの施設も同じ形で戻るなら、日数を変えても順位はほとんど変わりません
- 次に来るまでの日数は、人ごとに1回目だけを見ました。2回目以降の来場、季節や催しによる戻りやすさの変化は入れていません
- 初来場者は、初めて来たことが分かる人（会員番号などで同じ人だと分かる人）だけを数える前提です。同じ人だと分からない来場の数え方は扱っていません
- 実際の施設の再来場率や、どの日数で数えるべきかを示すものではありません
- 関連する記事：887（継続率は、月で数えるか案件で数えるかで変わるのか）は、副業の取引先の継続率を数え方の単位で比べています。977（途中から測り始めた項目は、前の期間とどう比べるのか）は、記録の始まりで欠ける期間を扱っています。同じ企画の993は延べの来場者と実際の人数、999は会員の来場だけで全体を読むこと、1001は招待券で来た人が次の回も来るかを扱っています。この記事は、再来場を数える日数とデータの締め日に絞りました
