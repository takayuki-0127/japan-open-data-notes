# F48 ガソリンが10%上がると、買う量は何%減るか？（需要の価格弾力性）

看板記事 F48。ガソリンの店頭価格と国内販売量（月次）から、需要の価格弾力性を推定した。価格と量の関係を測るときの「同時性」（量が価格を動かす向きもある）を、原油の円建て価格を操作変数にして扱い、短期と長期の弾力性、2022年からの補助金と2025年末の暫定税率の廃止の期間の動きまで見た。

## 問い

- ガソリンの価格が上がると、販売量はどれだけ減るか（短期・長期）
- 最小二乗法と操作変数法で、答えは変わるか
- 補助金（2022年1月〜）や暫定税率の廃止（2025年12月31日）の期間に、何が起きたか

## データ

| データ | 中身 | 期間 |
|---|---|---|
| 経済産業省「資源・エネルギー統計」（石油連盟「統計資料リスト 02. 石油製品バランス」の「3.販売」の表） | ガソリンの国内向け販売量（kℓ、月次） | 2017年1月〜2026年8月 |
| 資源エネルギー庁「石油製品価格調査」週次ファイル | レギュラーガソリンの店頭現金価格（全国、円/ℓ、週次→月平均） | 1990年8月〜2026年10月（使うのは2014年〜） |
| IMF Primary Commodity Prices（FRED: POILDUBUSDM） | 原油価格（ドバイ、ドル/バレル、月平均） | 1992年〜 |
| 日本銀行 時系列統計データ（FXERM07） | ドル円（東京市場 17時、月中平均） | 035・F39 で取得済み |
| 総務省「消費者物価指数」（総合） | 実質化に使う | F12・F39 で取得済み |
| 総務省「家計調査」（二人以上の世帯、長期時系列 000040270649〜51） | ガソリンの支出金額（円/世帯・月）。頑健性の確認用 | 2015年1月〜2026年8月 |

- 販売量の月次が取れたのは2017年1月からで、主分析は2018年1月〜2026年8月の前年同月差（コロナで移動が大きく落ちた2020年3月〜2021年12月を除く82か月）
- 原油の円建て価格（円/ℓ）＝ドバイ原油（ドル/バレル）×ドル円÷158.987
- 販売量は1日当たりにそろえた（うるう年の2月の分）

## 手法

| ステップ | 中身 |
|---|---|
| 季節をそろえる | 対数の前年同月差（同じ月どうしを比べる） |
| 最小二乗法 | Δ12 log(販売量) を Δ12 log(実質価格) に回帰。標準誤差は HAC（12か月） |
| 操作変数法（2段階最小二乗法） | 操作変数＝原油の円建て価格の前年同月差（当月・1か月前・2か月前）。原油と為替は世界の需給で決まり、日本のガソリン需要が動かしにくい、という仮定 |
| 部分調整モデル | log(販売量)ₜ＝a＋b log(実質価格)ₜ＋c log(販売量)ₜ₋₁＋月ダミー＋トレンド＋コロナ期ダミー。短期の弾力性＝b、長期＝b/(1−c)。区間は係数の同時分布からのシミュレーション（4,000回） |
| 補助金の期間 | ①原油→店頭価格の連動（24か月の移動窓で、価格の前年同月比を原油の前年同月比に回帰）②暫定税率の廃止の前後（2025年12月〜2026年2月）の価格と販売量（直前3年の減少トレンドとの差） |
| 頑健性 | 期間（補助金の前・後、コロナ期を含める）、名目価格、操作変数の組み方（ドル建て・当月のみ）、季節調整の方法（STL で季節を除いて前月差）、家計調査の購入量（支出÷価格） |

## 主な結果

- 販売量は 2017年の5,190万kℓ から 2025年の4,358万kℓ に16%減った。同じ期間に店頭価格（年平均）は133.5円から176.8円に上がった
- **短期の弾力性**（前年同月差、82か月）

| 手法 | 弾力性 | 95%区間 |
|---|---|---|
| 最小二乗法 | −0.068 | −0.118〜−0.018 |
| 操作変数法 | −0.051 | −0.246〜+0.144 |

  価格が10%上がると、量は0.5〜0.7%減る程度。操作変数法の第1段階は F=12.8（HAC で 5.5）と強くはなく、区間は広い
- **短期と長期**（部分調整モデル）：前月の量の係数は0.36。最小二乗法で短期 −0.071、長期 −0.111（−0.23〜+0.05）。操作変数法で短期 −0.053、長期 −0.084（−0.28〜+0.20）
- **補助金で原油と店頭価格の連動が弱まった**：原油の前年同月差で店頭価格の前年同月差を説明する当てはまり（R²）は、補助金の前（2018年1月〜2020年2月）の0.97から、補助金の後（2022年〜）は0.27に下がった。そのため、補助金の後だけの操作変数法は第1段階の F が6.3と弱く、区間は −0.36〜+0.17 と広い
- **暫定税率の廃止の前後**（補助金の拡充と2025年12月31日の廃止）：2025年12月〜2026年2月の店頭価格は前年同月より平均14%低く、販売量は直前3年の減少トレンドより平均2.0%多かった。比を取ると −0.14 だが、3か月だけの比較で、月ごとのばらつきも大きい（+3.4%、+3.9%、−1.4%）

## 頑健性（results/robustness.csv）

| 設定 | 最小二乗法 | 操作変数法 |
|---|---|---|
| 基本 | −0.068 | −0.051 |
| 補助金の前だけ（26か月） | +0.012 | +0.004 |
| 補助金の後だけ（56か月） | −0.076 | −0.096 |
| コロナ期も含める | +0.071 | +0.210 |
| 名目価格 | −0.052 | −0.054 |
| 操作変数＝原油のドル建て | — | −0.084 |
| 操作変数＝当月の原油だけ | — | −0.046 |
| STL で季節を除いて前月差 | −0.076 | −0.066 |
| 家計調査の購入量（支出÷名目価格） | +0.180 | +0.231 |

- 多くの設定で0〜−0.1の範囲。コロナ期を入れると、移動の落ち込みと価格の下落が重なり、符号が逆になる
- 家計調査の支出÷価格で作った購入量の目安では、弾力性がプラスに出た。家計調査は約9千世帯の標本で、ガソリンの支出は月ごとの振れが大きい。支出を価格で割って量を作るため、価格の動きと量の動きを分けにくい。この結果は当てにしない

## 言えないこと

1. 長期の減少（2017→2025年で−16%）には、燃費の改善、ハイブリッド車・電気自動車の増加、人口の減少も混ざっている。トレンドで取り除いているが、価格の効果と完全には分けられない
2. 操作変数（原油の円建て価格）は第1段階が強くなく、補助金の期間には店頭価格との連動が弱まった。操作変数法の推定は幅が広い
3. 販売量は国内向けの出荷で、家計の消費だけでなく、事業用の車両も含む
4. 暫定税率の廃止の前後の比較は3か月だけで、年末年始の動きや天候も混ざる
5. 気温や祝日の影響は、前年同月差でそろえた以上には入れていない
