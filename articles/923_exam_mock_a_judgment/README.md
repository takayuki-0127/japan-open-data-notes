# 923 模試の「A判定」は、何%の確率で受かるという意味なのか？（試験と点数）

資格試験の模擬試験（模試）では、点数に応じて「A判定（合格の見込み80%以上）」のような判定が付くことがあります。けれども、判定は前の年までのデータから作った物差しで、今年の本番の難しさや、本番までの伸び方までは分かりません。また「A判定」は、模試の点が判定の下限ぎりぎりの人から、ずっと上の人までをまとめた呼び名です。**ここでは、作成者が乱数で作った架空の資格試験と模試で、作成者が置いた物差し（前の年の模試の点の帯ごとに、本番に受かった人の割合が80%以上ならA判定）でA〜E判定を作り、次の年の受験者に当てたとき、A判定の人が実際に何%受かるかを、年ごとの振れ、A判定の中の位置、置き方を変えた54通りで数えました。**

この記事は、点の数え方と読み方だけを扱います。勉強の仕方や、模試・講座の良し悪しは扱いません。判定の物差し（80%・60%・40%・20%）は作成者が置いたもので、実在の模試の判定の出し方ではありません。

| # | 問い | 手法 | ファイル |
|---|---|---|---|
| A923 | 前の年のデータで「80%以上が受かった点の帯」をA判定にしたとき、次の年のA判定の人は何%受かるか。A判定の中の位置、年ごとの振れでどう変わるか | 架空の資格試験。1年の模試の受験者5,000人（全員が本番も受ける）。模試の時点の実力は平均55点・標準偏差12点の正規分布。模試の点＝実力＋振れ（標準偏差5点、整数に丸め0〜100点）。本番までの伸びは人ごとに平均+3点・標準偏差4点。本番の点＝実力＋伸び＋振れ（標準偏差5点）−その年の難しさ（全員共通、年ごとに標準偏差3点）。合格点は65点で固定（合格率は年平均30.89%）。判定の作り方（作成者が置いた物差し）：前の年の受験者2,000人の模試の点を5点きざみの帯に分け（10人未満の帯は使わない）、その帯から上のどの帯でも本番に受かった割合が80%以上になる、いちばん低い帯の下限をA判定の下限とした。B・C・D は同じく60%・40%・20%、残りはE。これを次の年の受験者5,000人に当て、判定ごとに本番に受かった割合を数えた。前の年と次の年の組を2,000回作り直した。確かめとして、年ごとの難しさの振れ（0・3・6点）×伸びのばらつき（0・4・8点）×模試の振れ（3・5・8点）×前の年の人数（200・2,000人）の54通りを各300回。seed 923 | `src/a923_mock_judgment.py` |

関連する記事：904「『〜の人の8割が〜』と『〜の人の8割は〜』は同じなのか？」は、条件を逆にした割合が別の値になることを扱っています。この記事の「A判定の人のうち受かった割合」と「受かった人のうちA判定だった割合」も、その違いです。921「合格率30%の試験で、実力は合格ラインちょうどの人は何%受かるのか？」は、実力が分かっているときに受かる確率を数えています。この記事は、模試の点と、前の年のデータで作った判定から読む場合を扱います。

## 主な結果

### 判定ごとに、次の年の本番で受かった割合（2,000回）
| 判定 | 物差し（前の年に受かった割合） | 受験者に占める割合 | 次の年に受かった割合（平均） | 年ごとの10〜90% | 受かった人に占める割合 |
|---|---|---|---|---|---|
| A | 80%以上 | 11.43% | **89.21%** | 77.49〜98.22% | **33.36%** |
| B | 60〜80% | 10.01% | 68.09% | 43.86〜89.87% | 21.29% |
| C | 40〜60% | 11.56% | 49.81% | 24.33〜76.81% | 17.69% |
| D | 20〜40% | 15.81% | 31.85% | 11.19〜57.76% | 15.42% |
| E | 20%未満 | 51.2% | 7.25% | 1.55〜15.32% | 12.24% |

- A判定の人が受かった割合は、平均で89.21%と、物差しの80%より高かった。A判定には、下限ぎりぎりの人から、ずっと上の人まで入るため
- それでも、年ごとに見ると、A判定の人の合格が80%を下回った年が**14.06%**あった（いちばん低い年は50.04%）。本番の難しさが年ごとに上下するためで、全体の合格率も年ごとの10〜90%で21.16〜41.44%動いた
- 受かった人のうちA判定だったのは33.36%で、受かった人の66.64%はB〜E判定だった。「A判定の人の多くが受かる」と「受かる人の多くがA判定」は別のこと（904と同じ）

### A判定の中の位置で
| 模試の点（A判定の下限から） | 次の年に受かった割合（平均） | 年ごとの10〜90% |
|---|---|---|
| 下限の1つ下の帯（−5点、B判定） | 69.53% | 45.48〜91.45% |
| A判定のいちばん下の帯（0〜4点上） | **83.32%** | 65.21〜97.27% |
| +5〜9点 | 92.31% | 81.95〜100% |
| +10〜14点 | 97.09% | 92.08〜100% |
| +15点以上 | 99.3% | |

- A判定のいちばん下の帯の人では、受かった割合は平均83.32%で、**32.98%の年（3年に1年ほど）は80%を下回った**
- A判定の下限そのものも、前の年のデータで動いた。下限は 70点の年が44.25%、75点が35.15%、65点が12.2%、80点が7.5%などで、同じ模試の点でも年によってA判定にもB判定にもなる。前の年のデータでA判定の帯ができなかった年が0.1%あった

### 確かめ：置き方を変えた54通り（各300回）
| | 前の年の人数 2,000人（27通り） | 前の年の人数 200人（27通り） |
|---|---|---|
| A判定の人が受かった割合（平均） | 80.2〜95.18% | 70.28〜92.24% |
| A判定の合格が80%を下回った年 | 0〜41.35% | 0〜65.56% |
| A判定のいちばん下の帯が受かった割合 | 74.17〜91.45% | 60.45〜85.89% |
| A判定の帯ができなかった年 | 0〜11.67% | 14.33〜78.67% |

- 80%を下回る年の多さは、本番の難しさの年ごとの振れでほぼ決まった。前の年の人数2,000人・模試の振れ5点で、振れ0点ならどの伸びのばらつきでも0%、3点で13.51〜21.33%、6点で26.1〜30.31%だった（図3）
- 前の年の人数が200人だと、A判定の帯そのものを作れない年が14.33〜78.67%あった。点の高い帯には10人以上がそろわず、使える帯のいちばん上でも80%に届かないことが多いため（仕組みからの説明）。作れた年も、A判定の人が受かった割合は低めになった
- 受かった人のうちA判定でなかった人は、54通りで48.0〜94.27%だった
- 全54通りの値は `results/robustness.csv`

## 確かめたこと
- 空のフォルダ（/tmp に `src` と `requirements.txt` だけを写したもの）で流し直し、results・figures・data の9ファイルがバイト単位で一致した（cmp、約30秒）
- 図3枚を開き、日本語・重なり・軸を確かめた
- A判定の人の平均の合格が80%を上回るのは、作成者が置いた物差し（A判定の下限の帯で80%以上）から出る向きで、データから見つけたものではない。数えたのは、下限の帯や年ごとに80%を下回る割合と、置き方による幅
- 本番の難しさの年ごとの振れを0にすると、前の年の人数2,000人の9通りのうち8通りで80%を下回る年は0%、残る1通りも1.05%だった（`results/robustness.csv`）

## 注意（言えないこと）
- 架空のデータです。実力の分布、模試と本番の振れ、本番までの伸び、年ごとの難しさ、判定の物差し（80%・60%・40%・20%、5点きざみ、10人以上の帯）は作成者が置いたもので、結果はこれで決まります。A判定のいちばん下の帯が受かった割合は、置き方で60.45〜91.45%と動きました
- 模試を受けた人が全員本番を受け、模試を受けない人はいない、と置きました。実際には、模試の受け方や本番を受けるかどうかで、受験者の集まりが変わるはずです
- 判定が出たあと、判定を見て勉強の量を変える人の動きは入れていません
- 実在の模試の判定の出し方や、合格の見込みを表すものではありません。1人の受験者が受かる確率を言うものでもありません。勉強の仕方、模試や講座の良し悪しは言えません
