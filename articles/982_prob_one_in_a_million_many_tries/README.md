# 982 「100万分の1の偶然」は、どれくらい起きるのか？（確率の直感）

「100万分の1の偶然が起きた」と聞くと、めったにないことに思えます。けれども、その「100万分の1」は、ふつう1か所・1回について数えた確率です。同じことを試す場所と回数がたくさんあれば、どこかで起きるのはふつうのことになります。また、起きたあとで「何が起きたら驚いたか」を決めると、確率は桁で変わります。**ここでは、作成者が乱数で作った架空の店の毎日の抽選（3けたの番号、出やすさを作成者が置いたもの）で、1軒・1日あたり100万分の1の「同じ番号が3日続く」が、店の数と年数でどれくらい起きるかを数え、何を「同じ偶然」と数えるか、番号の出やすさの偏り、店どうしが同じ抽選を使い回すときにどう変わるかを確かめました。**

## 主な結果

### 1軒の店から見ると（式）
| 見ている期間 | 「同じ番号が3日続く」が1回以上起きる確率 |
|---|---|
| 1年 | 0.0363% |
| 10年 | 0.3641% |
| 30年 | 1.0888% |

- 1軒の店だけを見ていれば、30年でも1.0888%しか起きない。どこかで初めて起きるまでの年数の中央値は、1軒なら1899.03年（式）

### 店1,000軒で見ると
| | 乱数 | 式 |
|---|---|---|
| 1年で、どこかで1回以上起きる | **30.6%**（1,000年分） | **30.44%** |
| 1年に起きる回数の平均 | 0.369回 | 0.363回 |
| 10年で、どこかで1回以上起きる | 98.33%（60回分） | **97.4%** |
| 4つの型のどれかが、1年でどこかで起きる | 77.0% | 76.59% |
| 決めた番号（777）が3日続くのが、1年でどこかで起きる | 1,000年分で1回 | 0.0363% |

- **1軒・1日あたり100万分の1でも、店が1,000軒あれば、30.44%の年にどこかで起きた（式どおり）。10年見ていれば97.4%**
- 1年に起きた回数は、0回が69.4%、1回が25.5%、2回が4.3%、3回が0.5%、4回が0.2%、5回が0.1%だった（図2）
- 4日続けば「3日の区切り」は2つ数える。区切りが連なった塊を1回と数えても、平均は0.368回で、ほとんど変わらなかった
- 店100軒×10年（区切り36万4,800個）は、店1,000軒×1年（36万3,000個）とほぼ同じ区切りの数で、式では30.57%、乱数（300回分）では34.0%だった。起きやすさは、店の数と年数を掛けた「試した回数」でほぼ決まる

### 何を「同じ偶然」と数えるか（店1,000軒・1年、式）
| 数え方 | 1つの区切りでの確率 | どこかで1回以上起きる確率 |
|---|---|---|
| 決めた番号（777）が3日続く | 10億分の1 | 0.0363% |
| どれかの番号が3日続く | 100万分の1 | 30.44% |
| 4つの型のどれか | 100万分の1×4 | **76.59%** |

- 同じ「3日続けて777」が起きても、「777が続く」と決めてから数えるか、「何かの番号が続く」と数えるかで、起きやすさは約1,000倍違う（10億分の1と100万分の1）
- 「増える」「減る」「ぞろ目」も驚く型に入れると、1年でどこかで起きる確率は76.59%になった。乱数でも、4つの型はそれぞれ1年に平均0.356〜0.369回起きた
- どこかで初めて起きるまでの年数の中央値は、店1,000軒なら「同じ番号」だけで1.9年、4つの型のどれかなら0.47年だった（式）

### 店の数×年数（`results/by_shops_years.csv`、式）
| 店の数 | 1年 | 10年 | 30年 |
|---|---|---|---|
| 1軒 | 0.036% | 0.364% | 1.089% |
| 10軒 | 0.362% | 3.582% | 10.37% |
| 100軒 | 3.565% | 30.566% | 66.539% |
| 1,000軒 | 30.441% | 97.396% | 99.998% |
| 1万軒 | 97.348% | 100.0% | 100.0% |

（同じ番号が3日続くのが、どこかで1回以上起きる確率）

### 確かめ1：番号の出やすさに偏りがあると（`results/robust_bias.csv`、店1,000軒・1年、式）
| 偏り（σ） | いちばん出やすい÷いちばん出にくい | 1つの区切りでの確率（100万分の） | どこかで1回以上起きる確率 |
|---|---|---|---|
| 0（偏りなし） | 1倍 | 1.0 | 30.44% |
| 0.3 | 8.1倍 | 1.354 | 38.83% |
| 0.6 | 64.8倍 | 3.705 | 73.95% |
| 1.0 | 651.3倍 | 10.41 | **97.71%** |

- 抽選の番号に偏りがあると、出やすい番号が続きやすくなるので、「100万分の1」は実際より小さく見積もった値になる。σ＝1.0では、1つの区切りで100万分の10.41、どこかで起きる確率は97.71%だった

### 確かめ2：店どうしが同じ抽選を使い回すと（`results/robust_shared_draws.csv`、店1,000軒、式）
| 互いに独立な抽選の数 | 1年 | 10年 |
|---|---|---|
| 1個（全店が同じ番号） | **0.036%** | 0.364% |
| 10個 | 0.362% | 3.582% |
| 100個 | 3.565% | 30.566% |
| 1,000個（基本） | 30.441% | 97.396% |

- 店が1,000軒あっても、全店が同じ抽選の番号を使えば、試した回数は1軒分と同じで、1年で0.036%だった。「試す回数の多さ」は、店の数ではなく、互いに独立な試しの数で決まる
- **1年でどこかで起きる確率は、番号の偏りと抽選の使い回しの置き方で0.036〜97.71%と動いた**

## 注意（言えないこと）
- 架空のデータです。番号の出やすさ（基本は同じ）、日どうし・店どうしが互いに影響しないこと、店の数と年数は作成者が置いたもので、結果はこれで決まります。1年でどこかで起きる確率は、置き方で0.036〜97.71%と動きました
- 主な結果（30.44%・97.4%など）は、「少なくとも1回」の式どおりの値です。乱数はその確かめです。この記事で新しく数えたのは、何を「同じ偶然」と数えるかで起きやすさが桁で変わること、番号の偏りと抽選の使い回しで試す回数の意味が変わることです
- 「4つの型」は作成者が選んだもので、人が驚く偶然の型をすべて数えたものではありません。驚く型をもっと多く数えれば、起きやすさはさらに上がります（推測）
- くじや抽選を勧めたり止めたりするものではありません。確率の数え方だけを扱っています
- 実際の抽選やくじの番号の出方は扱っていません
