# F286 計画（事前登録）：「物価高で節約」は、家計調査のどの品目に表れているか？

作成：2026-11-11。家計調査の詳細結果表 第4-3表（年間収入五分位階級別 1世帯当たり品目別 支出金額・購入数量・平均価格、二人以上の世帯、2020年計・2025年計）を取得し、表の形を確かめるために見出しと先頭の数行だけを見た段階で書いた。そのとき目に入った値は、2025年の世帯人員（2.87人）・消費支出（平均 3,768,007円）・食料と穀類の支出金額（平均）だけで、品目の購入数量・平均価格はまだ見ていない。F113（家計調査 品目別 2002〜2024年）と F209（消費者物価 品目指数）の写しは、それぞれの記事で値を扱ったことがある。

## 問い
物価が上がった2020→2025年に、家計は「買う量を減らした（量の節約）」のか、「同じ品目の中で安い物に替えた（安い物への切り替え）」のか、それとも「量は減らさず、値上がりの分だけ多く払った」のか。どの品目にどの形で表れたか。収入の低い世帯ほど量を減らしたか。

誰が知りたいか：「物価高で節約」という毎月の見出しの中身を知りたい人、食品メーカー・小売の需要予測の担当（値上げのあと量が戻るか）、家計の支援の数字を読む人。

## F209・F234・F266・F283 との違い
- F209：値上がりがどの品目から来て、誰に重いか（支出の重み）。量は弾力性として1つの数字にまとめた。
- F234：品目ごとの価格弾力性の推定（年のパネル）。
- F266：米の値段の段階（生産・卸・小売）。
- F283：たばこ・酒の税の改正の前後（月）。
- ここでは、品目ごとに「支出の変化＝量の変化＋平均価格の変化」「平均価格の変化＝物価指数の変化＋切り替え（品目の中の安い物・高い物への移り）」に分け、どの品目で量の節約・切り替え・値上がりの払いが起きたかを数える。収入五分位別にも見る。

## データ
1. 家計調査 詳細結果表 第4-3表、二人以上の世帯、2020年計（e-Stat statInfId 000032048837）・2025年計（000040409548）。平均と収入五分位Ⅰ〜Ⅴの 支出金額・購入数量・平均価格。購入数量が公表されている品目だけを使う。
2. 消費者物価指数（2020年基準）品目別の年平均（F209 の写し）。家計調査の品目と名前で対応づける（対応がないものは切り替えの分析から外す）。
3. 家計調査 品目別 時系列 2002〜2024年（F113 の写し）。2015→2020年の量の変化（前からの流れ）と、2019年を起点にした確かめに使う。

## 変数と手法
- 品目 i の対数差（2020→2025年）：Δln 支出 = Δln 量 + Δln 平均価格。
- Δln 平均価格 = Δln 物価指数 + 切り替え。切り替えが負なら「同じ品目の中で安い物に移った（または量目・品質の違い）」。
- 重み：2020年の支出（対象の品目の中の割合）。
- 「量の節約が表れた品目」：Δln 量 ≤ −0.105（約10%減）かつ、2015→2020年の流れより5ポイント以上減ったもの。

## 仮説と「外れ」の基準
- H1：対象の品目全体で、支出の重みつき平均の Δln 量 ≤ −0.03（量は減った）。さらに、物価指数が10%以上上がった品目の Δln 量の重みつき平均は、10%未満の品目より3ポイント以上小さい。どちらかが満たされなければ外れ。
- H2：切り替え（Δln 平均価格 − Δln 物価指数）の重みつき平均 ≤ −0.02。満たさなければ外れ。
- H3：量の減りによる支出の減り（w_i × Δln 量_i が負のもの）のうち、上位10品目が半分以上を占める。満たさなければ外れ。
- H4：Δln 量 ≤ −0.105 の品目のうち半分以上は、2015→2020年にも量が減っていた（前からの流れ）。満たさなければ外れ。
- H5：収入五分位Ⅰの重みつき Δln 量は、Ⅴより3ポイント以上小さい（低い収入の世帯ほど量を減らした）。満たさなければ外れ。

## 頑健性（少なくとも3つ）
1. 1人あたり：世帯人員の変化で割る（世帯の人数が減った分を除く）。
2. 米を除く（2025年の米は供給の事情が大きい）。
3. 起点を2019年にする（2020年はコロナで家で食べる量が多かった）。全国だけ、2019→2024年（F113）で。
4. 重みなし（品目の中央値）。
5. 物価指数との対応を厳しくする（名前が完全に一致する品目だけ）。

## 言えないこと（先に書いておく）
- 品目の中の「切り替え」には、量目の変化（内容量の減った値上げ）や品質の違いも入る。分けられない。
- 家計調査は標本調査で、品目ごとの誤差がある。五分位ごとはさらに大きい。
- 因果（値上がりが量を減らした）は言わない。需要の流れ・健康志向・世帯の変化も入る。
- 政策の評価・提言はしない。
