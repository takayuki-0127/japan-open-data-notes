# F286 「物価高で節約」は家計調査のどこに表れているか？

精選モード（C. ニュースの数字 Q30）。家計調査の品目ごとに、2020→2025年の支出の変化を「買う量の変化」「物価指数の変化」「平均価格と物価指数の差（同じ品目の中の安い物への移りなどを含む残差。以下「価格の差」）」に分け、「物価高で節約」がどの品目に、どの形で表れたかを数えた。計画（PLAN.md）を先にコミットしてから分析した（コミット 計画）。

## 問い
- 物価が上がった2020→2025年に、家計は買う量を減らしたのか、同じ品目の中で安い物に替えたのか、値上がりの分だけ多く払ったのか。
- どの品目に表れたか。収入の低い世帯ほど量を減らしたか。
- 誰が知りたいか：毎月の「物価高で節約」という見出しの中身を知りたい人、値上げのあと量が戻るかを見積もる需要予測の担当。

- 対象は、両年とも購入数量が公表されている個別の品目186（食料124、光熱・水道3、交通・通信2、住居4、被服及び履物29、家具・家事用品14、教養娯楽3、その他7）。集計の行（鮮魚・貝類など）は除いた。
- 「発泡酒・ビール風アルコール飲料」は2025年に「発泡酒」に名前と中身が変わったので除いた（計画になかった除外）。
- 物価指数との対応は名前の一致（123品目）と手で決めた対応（13品目：米・生うどん・そば・即席麺・パスタ・かつお節・削り節・牛肉・豚肉・チーズ・ぶどう・マヨネーズ・コーヒー・チューハイ・カクテル・ワイン。米→うるち米Ａ・Ｂ、牛肉・豚肉→国産品・輸入品など、複数のときは対数の平均）。対応がない50品目は価格の差の計算から外した。名前の一致だけにすると全体の価格の差は −0.6% → ＋0.6% と向きが変わる（R5）。

## 手法
- 品目 i の対数差（2020→2025年）：Δln 支出 ＝ Δln 量 ＋ Δln 平均価格。
- 価格の差 ＝ Δln 平均価格 − Δln 物価指数。負なら同じ品目の中で安い物に移った可能性がある（推測）。品質の違い、調べ方の違い、物価指数との対応の決め方も入る残差。
- 重み：2020年の支出（対象の品目の中の割合）。品目・群の値の％は exp(対数差)−1、群と群の差は対数ポイント（対数差×100）で表した。
- 前からの流れ：F113 の2015→2020年の量の変化（食料の多くの品目）。
- 問い直し（結果を見た後に追加）：コロナの2020年をはさまないように、2019→2024年の量の変化から2014→2019年の変化（前からの流れ）を引いた（F113、食料121品目、2019年の支出で重みづけ）。流れが続くというのは仮定（2014年は消費税率が上がった年）。「値上がり」は平均価格で決め、物価指数で決めた版も並べた。
- 区間：品目を入れ替えて計算し直す（ブートストラップ5,000回、`src/zz_f286_05_レビュー.py`）。家計調査の標本の誤差は入っていないので、本当の幅はもっと広い。

- 全体の重みの半分以上は、電気代（13%）・自動車購入（9%）・民営家賃（8%）・ガソリン（5%）など、量がほとんど減らなかった品目が占めた。電気代の量は ＋0.8%、ガソリンは ＋8.0% で、値上がりの分だけ支出が増えた。2020年はガソリンが安く電気を多く使った年で、起点の年の影響がありうる（推測）。
- H1 では、物価指数が10%以上上がった側に電気代・ガソリン（量は増えた）、それ以外の側に民営家賃（−0.6%）が入る。自動車購入は物価指数と対応がなく H1・H2 に入らない。
- 食料だけ（124品目、計画になかった集計）では、量 −13.4%、物価指数が10%以上上がった94品目は −14.0%、それ以外の8品目は −5.3%（差 −9.7対数ポイント）、価格の差 −3.7%。
- 食料で価格の差が大きかった品目：豚肉 −9.9%（量 −3.7%）、食パン −9.5%（量 −7.7%）、米 −8.3%（量 −5.0%、物価指数 ＋105%、支出 ＋79%）、牛肉 −6.9%（量 −24.8%）、キャベツ −6.9%（量 −16.8%）。鶏肉は量 −0.6%、価格の差 −0.7%。
- 量の減りの寄与の上位は、公営家賃（量 −55%）・牛肉・プロパンガス（−19%）・灯油（−20%）・他の塩干魚介・他のパン・テレビ・さけ・トマト・りんご。公営家賃・テレビなどの「量」は世帯の構成や買い替えの時期で揺れやすい（推測）。
- 計画で決めた「量の節約が表れた品目」（量が約10%以上減り、2015→2020年の流れより5ポイント以上減った）は71で、すべて食料。
- 収入五分位Ⅰは値が欠けたか0だった1品目を除く185品目。Ⅰの価格の差は −2.2%。

### 問い直し：コロナの2020年をはさまないと、量の減りはどれだけ残るか
- 食料の量（重みつき）は、2019年を0とすると2014年 ＋5.3%、2020年 ＋5.8%、2024年 −8.0%（品目の再抽出の95%の幅 −11.2〜−5.0%）。同じ系列で2020→2024年は −13.0%、2020年の山はその約4割、2020年起点は2019年起点の約1.7倍（対数で1.67）。
- 2019→2024年の量の変化 −8.0% のうち、2014→2019年と同じ流れなら −5.0%。流れを引いた減りは −3.1%（95%の幅 −6.4〜＋0.7%）。流れより減った品目は54%。
- 平均価格が10%以上上がった107品目は流れより −4.3%、それ以外の14品目は ＋6.4%（差 −10.6対数ポイント、95%の幅 −23.3〜＋1.2）。それ以外の増えはほぼビール1品目（流れより ＋39%、群の重みの23%、平均価格 −4%、酒税の改正が関係か（推測））。ビールを除くと −1.8%、差は約2.5ポイント。
- 平均価格の上がり方と流れを引いた量の変化の重みつき相関は −0.28（n=121、95%の幅 −0.52〜−0.02）。平均価格は支出÷量なので、量の誤差だけで負の相関が出やすい。
- 物価指数（2019→2024年）で値上がりを決めた版：対応のとれた100品目、上がった84品目 −4.3%、それ以外16品目 ＋5.3%、相関 −0.32（−0.56〜−0.05）、差 −9.5対数ポイント（−21.1〜＋1.3）。
- 「値上がりした品目に寄る傾向が見えたが、幅は大きい」と書いた。
- 同じ計算を1期前（2014→2019年の変化 − 2009→2014年の変化）にすると ＋0.6ポイントで、流れからの外れはほぼなかった。

## 言えないこと
- 価格の差には、同じ品目の中の安い物への移りだけでなく、品質の違い、家計調査の平均価格と物価指数の調べ方の違い、対応の決め方も入る。分けられない。内容量を減らした値上げは1単位あたりの値段として両方に入るので、この差にはあまり出ないと考える（推測）。
- 家計調査は標本調査で、品目ごとの誤差がある。収入五分位ごとはさらに大きい。区間にはこの誤差は入っていない。
- 因果（値上がりが量を減らした）は言えない。需要の流れ、健康志向、世帯の構成の変化（高齢化・世帯人員の減少）も入る。
- 収入五分位は年ごとに区切りの金額が変わる。2020年と2025年で同じ世帯を比べたものではない。
- 公営家賃などの「量」は家計の選択より世帯の構成の変化を映している可能性がある（推測）。
- 政策の評価・提言はしない。

## レビューで直したこと
独立レビュー（数値の照合・元の xlsx の抜き取り・再現）で、数値・再現は一致。次を直した。
- 題名：2020年起点の13%ではなく流れを除いた約3ポイントを先に置き、「値上がりした品目ほど減り」（結果を見た後の集計）と「安い物への切り替えにも表れた」（残差）の言い切りをやめた。
- 問い直し：品目数と品目の再抽出の95%の幅を足し、ビールを除いた値、物価指数で値上がりを決めた版を並べた。「寄る傾向が見えたが、幅は大きい」に弱めた。標本の誤差が入っていないことを書いた。
- 「切り替え」を「平均価格と物価指数の差（残差）」に改め、量目についての書き方を直し、手で対応した13品目と、名前の一致だけで向きが変わることを本文に書いた。
- コロナの反動を、同じ系列の比較（2020→2024年 −13.0%）で「4割ほど」「1.6倍ほど」に直した。R3 と問い直しの −7.3% / −8.0% の違いを書いた。
- 電気代・ガソリンに起点の年の注意、H1 の例を電気代・ガソリン・民営家賃に、％と対数ポイントの表し方、食料の群の品目数、五分位Ⅰの −2.2% と185品目、量の寄与の上位の注意、流れの仮定、計画からのずれ、図の番号と表にない大分類（約15%）。
