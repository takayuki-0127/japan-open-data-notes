# F286 「物価高で節約」は、家計調査のどの品目に表れているか？

精選モード（C. ニュースの数字 Q30）。家計調査の品目ごとに、2020→2025年の支出の変化を「買う量の変化」「物価指数の変化」「同じ品目の中の切り替え（平均価格と物価指数の差）」に分け、「物価高で節約」がどの品目に、どの形で表れたかを数えた。計画（PLAN.md）を先にコミットしてから分析した（コミット 計画）。

## 問い
- 物価が上がった2020→2025年に、家計は買う量を減らしたのか、同じ品目の中で安い物に替えたのか、値上がりの分だけ多く払ったのか。
- どの品目に表れたか。収入の低い世帯ほど量を減らしたか。
- 誰が知りたいか：毎月の「物価高で節約」という見出しの中身を知りたい人、値上げのあと量が戻るかを見積もる需要予測の担当。

- 対象は、両年とも購入数量が公表されている個別の品目186（食料124、光熱・水道3、交通・通信2、住居4、被服及び履物29、家具・家事用品14、教養娯楽3、その他7）。集計の行（鮮魚・貝類など）は除いた。
- 「発泡酒・ビール風アルコール飲料」は2025年に「発泡酒」に名前と中身が変わったので除いた（計画になかった除外）。
- 物価指数との対応は名前の一致（123品目）と手で決めた対応（13品目：米→うるち米Ａ・Ｂ、牛肉→国産品・輸入品など。複数のときは対数の平均）。対応がない50品目は切り替えの計算から外した。

## 手法
- 品目 i の対数差（2020→2025年）：Δln 支出 ＝ Δln 量 ＋ Δln 平均価格。
- 切り替え ＝ Δln 平均価格 − Δln 物価指数。負なら「同じ品目の中で安い物（または量目の少ない物）に移った」。量目の変化や品質の違いも入る。
- 重み：2020年の支出（対象の品目の中の割合）。％は exp(対数差)−1 で表した。
- 前からの流れ：F113 の2015→2020年の量の変化（食料の多くの品目）。
- 問い直し（結果を見た後に追加）：コロナの2020年をはさまないように、2019→2024年の量の変化から2014→2019年の変化（前からの流れ）を引いた（F113、食料121品目、2019年の支出で重みづけ）。

- 全体の重みの半分以上は、電気代（13%）・自動車購入（9%）・民営家賃（8%）・ガソリン（5%）など、量がほとんど減らなかった品目が占めた。電気代の量は ＋0.8%、ガソリンは ＋8.0% で、値上がりの分だけ支出が増えた。
- 食料だけ（124品目、計画になかった集計）では、量 −13.4%、物価指数が10%以上上がった94品目は −14.0%、それ以外の8品目は −5.3%、切り替え −3.7%。
- 食料で切り替えが大きかった品目：豚肉 −9.9%（量 −3.7%）、食パン −9.5%（量 −7.7%）、米 −8.3%（量 −5.0%、物価指数 ＋105%、支出 ＋79%）、牛肉 −6.9%（量 −24.8%）、キャベツ −6.9%（量 −16.8%）。鶏肉は量 −0.6%、切り替え −0.7%。
- 量の減りの寄与の上位は、公営家賃（量 −55%）・牛肉・プロパンガス（−19%）・灯油（−20%）・他の塩干魚介・他のパン・テレビ・さけ・トマト・りんご。公営家賃の「量」は世帯の構成の変化を映している可能性が高い（推測）。
- 「量が約10%以上減り、前からの流れより5ポイント以上減った」品目は71で、すべて食料。

### 問い直し：コロナの2020年をはさまないと、量の減りはどれだけ残るか
- 食料の量（重みつき）は、2019年を0とすると2014年 ＋5.3%、2020年 ＋5.8%、2024年 −8.0%。2020年はコロナで家で食べる量が多かったため、2020年を起点にすると減りが大きく見える。
- 2019→2024年の量の変化 −8.0% のうち、2014→2019年と同じ流れなら −5.0%。流れを引いた減りは −3.1ポイント。流れより減った品目は54%。
- 平均価格が10%以上上がった107品目は流れより −4.3ポイント、それ以外の14品目は ＋6.4ポイント。平均価格の上がり方と流れを引いた量の変化の重みつき相関は −0.28。
- 同じ計算を1期前（2014→2019年の変化 − 2009→2014年の変化）にすると ＋0.6ポイントで、流れからの外れはほぼなかった。

## 言えないこと
- 切り替えには、同じ品目の中の安い物への移りだけでなく、量目の変化（内容量の減った値上げ）や品質の違いも入る。家計調査の平均価格と物価指数の調べ方の違いも入る。分けられない。
- 家計調査は標本調査で、品目ごとの誤差がある。収入五分位ごとはさらに大きい。
- 因果（値上がりが量を減らした）は言えない。需要の流れ、健康志向、世帯の構成の変化（高齢化・世帯人員の減少）も入る。
- 収入五分位は年ごとに区切りの金額が変わる。2020年と2025年で同じ世帯を比べたものではない。
- 公営家賃などの「量」は家計の選択より世帯の構成の変化を映している可能性がある（推測）。
- 政策の評価・提言はしない。
