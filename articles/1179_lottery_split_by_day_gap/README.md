# 1179 日にちごとに分けて抽選すると、混む日と空いた日の当たりやすさは何倍開くのか？（抽選と倍率）

催しを何日かに分けて開き、申し込む人が日を1つ選んで、日ごとに抽選することがあります。発表される倍率が「全体で2倍」でも、人が集まる日と集まらない日があるので、当たりやすさは日によって違います。空いた日は申し込みが定員に届かず、全員が当たることもあります。**ここでは、作成者が置いた架空の体験会（5日間、各日の定員100人、申し込みの見込みの総数1,000人、日ごとの申し込みの割合32%・26%・20%・13%・9%）で、日ごとの申し込み数を乱数で2,000回作り、いちばん当たりやすい日といちばん当たりにくい日の見込みが何倍開くか、全体の倍率から読む見込みと混む日の本当の見込みがどれだけ違うかを数えました。申し込みの総数・日ごとの偏り・回ごとの人気の振れを変えた27通りも確かめました。**

例の体験会は架空のもので、実在の催し・会社・申し込みの仕組みを表すものではありません。申し込むかどうか、どの日に申し込むかを勧める・止める記事ではありません。

関連する記事：同じ企画の 1180「倍率の高い回は、申し込みたい人の多い回だと読んでよいのか？」は、回ごとの倍率を人気の多さとして読めるかを扱っています。1023「予約のない枠は、本当に人気がないのか？」は、予約の数を人気として読むときのずれを扱っています。878「混雑の予測を出すと、空いている時間に人が集まって外れるのか？」は、空いている時間に人が移る動きを扱っています。同じ企画の 1174「第1希望と第2希望を書ける抽選では、第2希望が当たる見込みは何で決まるのか？」は、第2希望を書けるときに、空いた回の枠が第2希望の人に回る場面を扱っています。1182「先着の枠と抽選の枠に分けると、抽選の枠の倍率はどう見えるのか？」は、同じ回の席を先着と抽選に分けたときの抽選の倍率の見え方を扱っています。この記事では、人が当たりやすい日に移る動きは入れず、日ごとに分けた抽選そのものの開きに絞ります。

## 主な結果

### 日ごとの当たる見込み（基本、2,000回、`results/by_day_base.csv`）
| 日 | 申し込みの見込み | 当たる見込みの平均 | 10〜90%の範囲 | 式の値 | 定員割れした回 |
|---|---|---|---|---|---|
| A日 | 320人 | **32.11%** | 25.97〜38.76% | 31.25% | 0% |
| B日 | 260人 | 39.62% | 31.75〜48.31% | 38.46% | 0% |
| C日 | 200人 | 51.17% | 40.32〜62.5% | 50% | 0.05% |
| D日 | 130人 | 78.52% | 62.89〜98.04% | 76.92% | 6.85% |
| E日 | 90人 | **97.58%** | 90.09〜100% | 100% | 72.6% |

- **全体の倍率から読む見込みは平均50.35%（申し込み約1,000人に席500）だが、日ごとに抽選すると、A日に申し込んだ人の見込みは32.11%、E日は97.58%だった**
- **回ごとの開き（いちばん当たりやすい日÷いちばん当たりにくい日）は中央値3.151倍（10〜90%の範囲2.616〜3.8倍）**。見込みの人数どおりなら A日の倍率3.2倍・E日は全員当選なので、開きは3.2倍（式どおり）。開きは、空いた日が定員割れしているかぎり、混む日の倍率そのものになる
- 回ごとにいちばん当たりにくかった日の見込みは、全体の倍率から読む見込みの中央値0.622倍だった
- 2,000回のうち74.35%の回で、どこかの日が定員割れし、空いた席は平均13.46席だった。このため、申し込んだ人全体で当たった割合は平均48.97%で、全体の倍率から読む見込み（50.35%）より少し低かった（式の値49%）
- いちばん申し込みの多い日は、81.15%の回で A日だった（残りの回は、回ごとの人気の振れで B日が上回った）

### 確かめ：置き方を変えると（27通り、各2,000回、`results/grid.csv`）
| 日ごとの偏り | 開き（中央値）の範囲 | いちばん当たりにくい日の見込み÷全体の倍率から読む見込み（中央値）の範囲 |
|---|---|---|
| そろう（各20%） | 1.11〜2.006倍 | 0.735〜0.947倍 |
| 基本（32〜9%） | 1.6〜4.048倍 | 0.594〜0.642倍 |
| 強い（45〜5%） | 2.18〜8.79倍 | 0.444〜0.479倍 |

- **開きは、27通りで1.11〜8.79倍と、日ごとの偏りと総数で大きく動いた**
- 回ごとの人気の振れが0のとき、開きは式の値と0.21以内で合った。総数2,000人ではどの日も定員を超え、開きは日の割合の比（基本で0.32÷0.09＝3.556倍、強いで9倍）に近づいた。総数500人では空いた日が定員割れし、開きは混む日の倍率（基本1.6倍、強い2.25倍）に近かった
- **見込みの割合が各日そろっていても、回ごとの人気の振れがあると開きが出た**。総数1,000人・2,000人で振れ0.3なら開きは約2倍（2.006倍・2.004倍）、振れ0でも、申し込み数のでたらめな振れだけで1.11〜1.173倍あった
- 偏りが強いほど、いちばん当たりにくい日の見込みは全体の倍率から読む見込みより下がった（強いで0.444〜0.479倍）

## 注意（言えないこと）
- 架空のデータです。日ごとの申し込みの割合、総数、回ごとの人気の振れ、定員は作成者が置いたもので、結果はこれで決まります。開きの大きさは、見込みの人数からの式でほぼ決まります（式どおり）
- 申し込む人は1日だけを選び、ほかの日の当たりやすさを見て日を変えない、と置きました。前の回の当たりやすさを見て空いた日に人が移る動きは入れていません（人が移ると開きは縮むと考えられます。推測）
- 第2希望を書ける決まり（1174 で扱っています）、全日をまとめて抽選する決まりは数えていません
- 実在の催しの申し込みを表すものではなく、どの日に申し込むべきか、申し込むべきかどうかも言えません。この記事は、日ごとに分けた抽選で当たりやすさがどれだけ開くかを数えただけです
