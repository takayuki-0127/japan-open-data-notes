# F05 医療費の地域差は「県」と「市町村」のどちらで決まるか？（階層ベイズモデル）

看板記事シリーズの5本目です。市町村国保の、年齢をそろえた1人当たり医療費（地域差指数）を、全国1,895の市区町村・3年度分のデータで「県の差」と「同じ県の中の市区町村の差」と「年ごとのぶれ」に分けます。PyMC の階層ベイズモデルで、小さい町の値のぶれを県の平均へ引き寄せる（部分プーリング）のがポイントです。

## 問い

1人当たり医療費（市町村国保、年齢調整後）のばらつきのうち、県の違いと、同じ県の中の市区町村の違いはそれぞれ何割か。その差は、病床数や人口密度などと一緒に動いているか。

## データ

| データ | 内容 | 出典 |
|---|---|---|
| `data/raw/iryohi_muni_r03_r05.csv` | 市区町村別の地域差指数（年齢調整後の1人当たり医療費 ÷ 全国）と1人当たり実績医療費。計・入院・入院外・歯科、市町村国保と後期高齢者医療、令和3〜5年度 | 厚生労働省「医療費の地域差分析」基礎データ（各年度の Excel の「市区町村別データ」シート） https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/iryouhoken/database/iryomap/index.html |
| `data/raw/census2020_muni.csv` | 市区町村の人口・人口増減率（2015→2020）・人口密度 | 総務省「令和2年国勢調査」（e-Stat、F03 と同じファイル） |
| `data/raw/beds_per100k_2025.csv` | 都道府県の人口10万対病床数（2025年） | 厚生労働省「医療施設調査」（182 と同じファイル） |
| `data/raw/aged65_share_2023.csv` | 都道府県の65歳以上人口割合（2023年） | 総務省「人口推計」（182 と同じファイル） |

- 単位は市区町村。政令指定都市は区を単位にし、市の合計の行は落とした（20市）。浜松市の新しい区（2024年再編）は市全体の人口で代用
- 結合後：`data/panel.csv`（市区町村×年度×制度、市町村国保は 5,672 行・1,895 市区町村）
- 国保の加入者数は市区町村別に公表されていないため、年ごとのぶれの大きさは人口で代用した

## 手法

| 項目 | 内容 |
|---|---|
| 目的変数 | y = 100 ×（地域差指数 − 1）。全国平均を0とした「年齢をそろえた医療費の高さ（%）」 |
| モデル | y[i,t] = mu + g[年度] + a[県] + b[市区町村] + e[i,t] |
| 県の差 a | 合計0の正規分布（ZeroSumNormal）、標準偏差 sigma_pref |
| 市区町村の差 b | 合計0の正規分布、標準偏差 sigma_muni（毎年続く差） |
| 年ごとのぶれ e | 正規分布、標準偏差 sigma_noise × √(人口の中央値 ÷ 人口)。人口が小さい町ほどぶれが大きい |
| 事前分布 | 標準偏差は HalfNormal(10)、mu は Normal(0,10)（頑健性：HalfCauchy(2)、Exponential(0.2)） |
| 共変量つき | 県の病床数・65歳以上割合を a の平均に、市区町村の人口・人口密度（log）・人口増減率を b の平均に入れる（すべて標準化） |
| 推定 | PyMC 5（NUTS、2チェーン × 1,500 回、チューニング 1,000 回、target_accept 0.9）。R-hat はすべて 1.03 未満 |
| 県の割合 | sigma_pref² ÷ (sigma_pref² + sigma_muni²)。毎年続く差のうち、県で説明される割合 |
| 部分プーリング | 3年平均のそのままの値と推定値を比べ、「県の平均との差」が何割縮んだかを人口の大きさ別に集計 |
| 事後予測チェック | モデルから作ったデータと実際のデータで、分布の形と、人口の大きさ別の年ごとのぶれを比べる |

## 主な結果（市町村国保、令和3〜5年度）

| 指標 | 値（95%区間） |
|---|---|
| 県の差の標準偏差 | 7.8% |
| 同じ県の中の市区町村の差の標準偏差 | 6.3% |
| 年ごとのぶれ（人口が中央値の町） | 2.8% |
| 毎年続く差のうち「県の差」の割合 | **60%（50〜70%）** |
| 共変量を入れたあとの県の差の標準偏差 | 4.9%（県の差の分散の約6割を病床数などが説明） |

- 県の差は西日本で高く東日本で低い。県の効果の推定値は −14%〜+19% の範囲（`results/pref_effects_kokuho.csv`）
- 県の病床数が1標準偏差多いと +7.3%（+6.0〜+9.0）。人口密度（log）が1標準偏差高いと +2.2%（+1.5〜+2.9）、人口増減率が1標準偏差高いと −1.9%（−2.3〜−1.4）。県の65歳以上割合は −2.2%（−3.6〜−0.7）、市区町村の人口の大きさははっきりしない
- 診療の種類別の「県の割合」：入院 70%（61〜78%）、入院外 29%（20〜39%）、歯科 48%（38〜58%）。入院は県で、入院外は同じ県の中の市区町村で差がつく
- 部分プーリング：県の平均との差が縮んだ割合（中央値）は、人口3千人未満 53%、3千〜1万人 24%、1万〜3万人 10%、3万〜10万人 4%、10万人以上 1%
- 後期高齢者医療でも県の割合は 62%（52〜71%）で、国保とほぼ同じ

## 頑健性

`results/robustness.csv`

| モデル | 県の割合（95%区間） |
|---|---|
| 基本 | 59.9%（50.2〜69.8） |
| 事前分布 HalfCauchy | 59.4%（49.1〜70.4） |
| 事前分布 Exponential | 59.5%（49.7〜69.4） |
| 2023年度だけ | 75.1%（67.1〜82.7） |
| 2021年度だけ | 75.1%（66.4〜83.0） |
| ぶれを人口で調整しない | 50.4%（40.2〜61.1） |
| 後期高齢者医療 | 61.9%（52.0〜71.4） |
| 頻度論の混合モデル（REML、等分散） | 49.6% |

- 事前分布を変えても結果はほとんど変わらない
- 1年度だけで推定すると、市区町村の差と年ごとのぶれを分けにくく（人口によるぶれの違いだけが手がかりになる）、市区町村の差が小さく、県の割合が大きく出る。3年分を使う基本モデルの方が分け方の根拠がはっきりしている
- ぶれを人口で調整しないと、小さい町の年ごとのぶれが「市区町村の差」に入り、県の割合は 50% に下がる。頻度論の混合モデル（同じく等分散）でも 50% で、ベイズと頻度論の推定は一致した
- 事後予測チェックでは、人口3千人未満の町で、モデルの年ごとのぶれが実際より大きい（実際 8.7%、モデル 10.7〜12.1%）。人口の平方根でぶれを調整する仮定がやや強く、小さい町の縮み方は少し大きめに出ている可能性がある

## 言えないこと

- 医療費が高い＝医療が過剰、とは言えない。病気の多さ、医療機関の近さ、入院できる場所の多さなど、理由はこのデータでは分けられない
- 個人の受診行動は分からない（市区町村の平均だけ）
- 病床数との関係は県単位の相関で、病床を減らせば医療費が下がるという因果は言えない
- 国保の加入者数の代わりに人口を使っているので、加入者の割合が違う町ではぶれの大きさの見積もりがずれる
- 特定の市区町村や県を評価する意図はない（推定値の一覧は `results/` にあるが、記事では順位として扱わない）
