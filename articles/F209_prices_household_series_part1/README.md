# F209 この5年の値上がりは、どの品目から来て、誰に重く、家計は何を減らしたのか？（シリーズE「物価と家計」前編）

看板記事シリーズE（物価と家計）の前編。消費者物価指数（CPI）の582品目と、家計調査の世帯の区分別の支出・品目別の購入数量を使い、2020→2025年の物価上昇を「どの品目から来たか」「どんな世帯に重かったか」「値上げのあと何を減らしたか」の3つに分けて調べた。

後編（F210）では、円安が品目の値段に届くまでの時間、家計と専門家の物価見通しの違い、データで言えること・言えないことを扱う。

## 問い

1. 2020→2025年の物価上昇（CPI 総合 +11.9%）は、どの品目・費目から来たのか。財とサービスで違うのか。
2. 買う物の割合（ウエイト）が違うと、物価の上がり方は世帯によってどれだけ違うのか（年間収入五分位・世帯主の年齢）。
3. 値段が上がった品目ほど、家計は買う量を減らしたのか（価格弾力性）。

## データ

| データ | 期間 | 出典 |
|---|---|---|
| 消費者物価指数 2020年基準 品目別価格指数（全国・月次、ウエイトつき、582品目） | 2015年1月〜2026年9月 | 総務省統計局「消費者物価指数」長期時系列（e-Stat statInfId 000032103844） |
| 消費者物価指数 2020年基準 財・サービス分類指数（全国・月次） | 同上 | 同（000032103845） |
| 家計調査 年間収入五分位階級別・世帯主の年齢階級別 1世帯当たり品目別支出金額（二人以上の世帯） | 2020年・2025年 | 総務省統計局「家計調査」詳細結果表 第4-3表（2020年 000032048837、2025年 000040409548）・第4-6表（000032048838、000040409549） |
| 家計調査 品目別の年間支出金額・平均価格・購入数量（二人以上の世帯、130品目） | 2002〜2024年 | F113 で整形したもの（`F113_price_index_formulas/data/items_panel.csv` の写し） |

- 取得はブラウザ経由（`src/01_取得.md`）。`data/raw/` は取得したファイル（必要な部分）、`data/` は整形後。
- 家計調査の支出は、CPI の中分類（諸雑費は小分類）に対応づけた（`src/02_整形.py` の MAP）。こづかい・交際費・仕送り金は CPI に対応する品目がないので除いた（消費支出の92〜94%を対応づけ）。家計調査には持家の帰属家賃がないので、区分別の物価は「持家の帰属家賃を除く総合」に相当する。

## 手法

1. **品目別の寄与**：CPI は2020年のウエイトで固定したラスパイレス指数なので、品目 i の寄与（ポイント）＝ w_i ×（I_i,2025 − I_i,2020）÷（Σw × I_総合,2020）× 100。582品目の寄与の合計は総合の変化と一致する（11.93% と 11.93pt）。財・サービスは公表の分類指数の内訳（生鮮商品・食料工業製品・石油製品・電気都市ガス水道など8つと、公共サービス・外食・民営家賃・持家の帰属家賃・他のサービスの5つ）で同じ計算をした。
2. **世帯の区分別の物価**：区分ごとの2020年の支出の割合（CPI の類に対応づけたもの）で、類別指数の上がり方を加重平均した（区分別のラスパイレス指数）。区分の間の差は、費目ごとに「支出の割合の差 × その費目の上がり方」に分けた。
3. **価格弾力性**：品目別の購入数量の対数差を、平均価格の対数差に回帰した（年の固定効果で物価全体の動きを除き、前年の支出で重みづけ、品目でクラスター化した標準誤差）。あわせて、2020→2024年の4年の長い差を品目の横断で回帰し、並べ替え検定（2,000回）をした。

## 結果

### 1. 値上がりは食料と「財」に集中した

- CPI 総合は2020→2025年に +11.9%。582品目のうち上がったのは539品目、変わらなかったのは7品目、下がったのは36品目（下がった品目の寄与は合計 −1.76pt）。
- 寄与の大きい品目は、電気代 +0.62pt、ガソリン +0.55pt、宿泊料 +0.53pt、うるち米（B・A）+0.42・+0.24pt、火災・地震保険料 +0.30pt、チョコレート +0.23pt、灯油 +0.20pt。上位10品目で上昇の29%、上位39品目で半分、123品目で8割。
- いちばん押し下げたのは携帯電話の通信料（−42%、−1.14pt）。これがなければ総合はおよそ13%上がっていた計算。
- 10大費目では食料が +6.76pt で上昇の57%。
- 財は +20.6%、サービスは +3.1%。財（ウエイト50%）の寄与は +10.4pt、サービスは +0.7pt。財の中では食料工業製品 +3.7pt、他の工業製品（家電・日用品など）+2.0pt、生鮮商品 +1.8pt。
- 前年比のピークは2023年1月の +4.4%（財 +3.8pt、サービス +0.3pt）。2026年9月は +2.2%（財 +1.5pt、サービス +0.3pt）。

### 2. 収入が低い世帯・高齢の世帯ほど上がり方が大きかった

| 区分 | 2020→2025年 |
|---|---|
| 年間収入 第Ⅰ五分位（低い20%） | +15.5% |
| 第Ⅱ | +14.8% |
| 第Ⅲ | +14.0% |
| 第Ⅳ | +13.3% |
| 第Ⅴ五分位（高い20%） | +12.9% |
| 世帯主 29歳以下 | +11.0% |
| 30〜39歳 | +12.7% |
| 40〜49歳 | +12.4% |
| 50〜59歳 | +12.3% |
| 60〜69歳 | +14.8% |
| 70歳以上 | +16.0% |
| 平均（確認用） | +13.9%（CPI 持家の帰属家賃を除く総合は +14.0%） |

- 第Ⅰと第Ⅴの差は2.6ポイント。差を押し上げたのは穀類 +0.57、魚介類 +0.51、野菜・海藻 +0.50、授業料等 +0.40（授業料等は5年で約9%下がったが、その下がった分は授業料の支出の割合が大きい収入の高い世帯に多く効いた）、他の光熱（灯油など）+0.33。押し下げたのは外食 −0.43、教養娯楽サービス −0.29、自動車等関係費 −0.29。
- 70歳以上と29歳以下の差は5.0ポイント。設備修繕・維持（火災・地震保険料を含む）+0.92、魚介類 +0.86、野菜・海藻 +0.76 が押し上げ、自動車等関係費 −0.50、外食 −0.47 が押し下げた。
- 区分の物価の上がり方は、食料の割合とほぼ一直線に並んだ（相関 0.97）。
- 円で見ると逆になる：2020年の値段のままなら払わずに済んだ額は、第Ⅰ五分位で年約32万円、第Ⅴ五分位で年約57万円（支出の対応づけた部分）。率は低い世帯ほど高いが、額は支出の多い世帯ほど大きい。

### 3. 値段が大きく上がった品目ほど、買う量を減らしていた

- 130品目（食料127品目と電気代・プロパンガス・灯油）の年ごとの変化では、値段が1%上がると購入数量は0.28%減った（95%区間 −0.51〜−0.05）。2003〜19年 −0.28、2021〜24年 −0.28 で、期間による違いは見えない。エネルギーを除くと −0.46。
- 4年の長い差（2020→2024年）では −0.87（−1.17〜−0.57、並べ替え p=0.0005）。1年では買う量をあまり変えなくても、値上がりが続くと少しずつ減らす形に見える（推測：買い方の調整には時間がかかる）。
- 値上がりが大きい上位4分の1の品目は購入数量が平均 −21%、下位4分の1は −5%。130品目全体では、値段 +17%・数量 −11%・支出 +3.5%（支出の重み）。
- 群別では、魚介類 −1.24、酒類 −1.17、果物 −0.81、肉類 −0.50 と反応が大きく、穀類（+0.41、区間は0をまたぐ）、野菜・海藻（−0.17）は小さかった。

## 頑健性

1. **期間を変える**（品目の寄与）：2021→2025年（+12.2%）、2020→2024年、2022→2025年、2021年1〜9月→2026年1〜9月（+13.8%）。食料の割合は55〜58%、上位10品目の割合は21〜29%で、「食料中心・多くの品目に広がった値上がり」は同じ。2022→2025年だけはエネルギーの寄与がほぼ0（補助金と価格の下落のため）。
2. **区分別の物価の作り方を変える**（`results/B_household_inflation.csv`）：第Ⅰ−第Ⅴの差は、2025年の買い方で計算 2.9pt、2021→2025年 2.6pt、2021→2026年（1〜9月）3.2pt、通信を除く 2.9pt、電気・ガス・灯油を除く 2.4pt。70歳以上−29歳以下の差は4.1〜5.1pt。どの作り方でも向きと大きさの順は変わらない。
3. **弾力性の推定を変える**：重みなし −0.67、エネルギーを除く −0.46、2年の差 −0.20、群ごと（上の表）。重みのある推定は支出の大きい電気代・米などの反応の小ささに引っぱられる。
4. **確認**：区分別の物価の平均（+13.9%）と CPI「持家の帰属家賃を除く総合」（+14.0%）の差は0.1ポイント。

## 言えないこと

- 区分別の物価は、全国共通の値段の上がり方に、区分ごとの買い方の違いを当てたもの。同じ品目でも区分によって買う店や銘柄が違う分は入らない。家計調査は標本調査なので、区分の支出の割合には誤差がある（公表の標準誤差は使っていない）。
- 持家の帰属家賃を除いている。単身世帯は含まない。
- 購入数量の減少は、値段だけでなく、世帯人数の減少・高齢化・外食や中食への移り変わりでも起きる。年の固定効果で全体の動きは除いたが、品目ごとの好みの変化は分けられない。値段と量は同時に決まるので、弾力性は「関係の強さ」であり、値上げが原因で減ったとは言い切れない。
- 平均価格は単価なので、安い銘柄への切り替えも「値段の変化」に入る。
- 品目別の数量は2024年まで。2025年の米の大きな値上がりへの反応は入っていない。
- ビールは2023年の酒税の見直しで発泡酒などから移った分があり、値段と量の関係が他の品目と違う。

## 後編に渡すもの

- `data/cpi_items_monthly.csv.gz`：品目別 CPI（2015年1月〜2026年9月、582品目と類）。円安の転嫁の遅れ（F102 の続編）で品目別に使える。`data/cpi_items_meta.csv` にウエイト。
- `data/cpi_gs_monthly.csv`：財・サービス分類（同期間）。輸入品の多い財（食料工業製品・他の工業製品・石油製品）を転嫁の分析の対象にできる。
- `results/A_item_contrib_2020_2025.csv`：品目別の寄与（上位の品目を転嫁の分析の候補に）。
- `results/B_household_inflation.csv`・`B_food_energy_share.csv`：区分別の物価（家計の見通しとの比較で「実際に感じる物価」の目安に使える：収入の低い世帯・高齢の世帯ほど +2〜5pt 高い）。
- `results/C_elasticity.csv`・`C_long_diff_2020_2024.csv`：弾力性（短期 −0.28、4年 −0.87）。
- 後編で扱う3つ：円安は品目の値段にどれだけ時間をかけて届くのか（輸入物価、F102）／物価の見通しは家計と専門家でどれだけ違うのか（消費動向調査・公表の予測、F72）／データで言えること・言えないこと（シリーズEのまとめ）。
