# 01 取得（e-Stat、ブラウザから）

この環境から e-Stat に直接つながらないため、ブラウザ（e-Stat のページ上の fetch と SheetJS）でファイルを取り、必要な部分を data/raw に保存した（2026-11-06）。

1. 消費者物価指数 2020年基準 長期時系列 品目別価格指数（全国・月次）：
   https://www.e-stat.go.jp/stat-search/file-download?statInfId=000032103844&fileKind=1 → data/raw/cpi_items_long.csv（Shift_JIS を UTF-8 に変換）
2. 同 財・サービス分類指数：statInfId=000032103845 → data/raw/cpi_goods_services_long.csv
3. 家計調査 詳細結果表 第4-3表（年間収入五分位階級別）・第4-6表（世帯主の年齢階級別）の Excel（fileKind=0）：
   2020年 000032048837・000032048838、2025年 000040409548・000040409549
   - 4-3 は「二人（支出金額）」シート、4-6 は「二人」シートの「◯◯・支出金額」の列（平均・29歳以下〜70歳以上）
   - 階層コード・分類コード・品目名・単位と、各区分の支出金額 → data/raw/kakei_q5_age_2020_2025.csv
4. 品目別の価格と数量（2002〜2024年）は F113 の data/items_panel.csv を使う（取得手順は F113 の README）。
