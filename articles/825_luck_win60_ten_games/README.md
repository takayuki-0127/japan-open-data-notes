# 825 勝率6割のチームが、10試合で負け越す確率は？（運と実力）

本当に強いチームでも、短い区切りでは負け越すことがあります。10試合の成績だけを見て「調子が落ちた」「実力がない」と決めると、偶然の負け越しを実力と読み違えます。**ここでは、作成者が置いた架空のチーム（1試合ごとに本当の勝率で勝つ）で、10試合で負け越す確率を二項分布の式と乱数の両方で数え、試合数と本当の勝率を変えるとどう動くか、引き分け・相手の違い・勢いを入れるとどう動くかを確かめました。**

| A825 | 本当の勝率6割のチームが、10試合で負け越す確率はどれくらいか。試合数と本当の勝率で、どう変わるか | 架空のチーム。基本は、毎試合 本当の勝率0.6で勝ち、引き分けなし、試合どうしは互いに影響しないと置く。負け越しは「勝ち数 < 負け数」、五分は「勝ち数 = 負け数」。10試合の勝ち数の分布は二項分布（勝つ確率が毎回同じで、互いに影響しない試合を何回か行ったときの勝ち数の分布）の式で計算し、乱数20万回でも数えた。試合数10・20・40・80・140、本当の勝率0.55・0.6・0.65・0.7で負け越す確率を式で計算。負け越す確率が5%・1%を下回る試合数は、偶数の試合数で、その次の偶数でも下回る最少の数。140試合のシーズン（勝率0.6）を乱数で2万回作り、10試合ごとの14区間・連続する10試合の131区間で負け越す区間を数えた。確かめとして、引き分け1割・2割（決着した試合の勝率は0.6）、相手ごとに勝率が違う日程（10試合の勝率を平均0.6で0.44〜0.76・0.29〜0.91に等間隔に並べる、式で計算）、勢いあり（勝った次の試合は勝率0.7・0.8、負けた次は全体の勝率が0.6になるように0.45・0.30）、本当の勝率0.55・0.65を数えた（乱数は各20万回）。seed 825 | `src/a825_win60_ten_games.py` |

## 主な結果

### 本当の勝率0.6・10試合の勝ち数（二項分布の式）
| | 確率 |
|---|---|
| 負け越し（4勝以下） | **16.6%** |
| 五分（5勝5敗） | 20.1% |
| 勝ち越し（6勝以上） | 63.3% |
| 五分以下（負け越しか五分） | 36.7% |
| ちょうど6勝4敗 | 25.1% |
| 3勝以下 | 5.5% |
| 8勝以上 | 16.7% |

- 本当の勝率6割のチームでも、10試合で負け越すことは約6回に1回、五分以下は36.7%あった
- 乱数20万回では負け越し16.5%・五分20.1%で、式と合った。1回分の1,000シーズン（`data/`）では負け越し186回・五分192回
- 「8勝以上」も16.7%で、負け越しとほぼ同じだけ起きた。10試合で8勝したチームを見て「勝率8割の実力」と読むのも同じ読み違いになる

### 試合数と本当の勝率ごとの、負け越す確率（式）
| 試合数 | 勝率0.55 | 勝率0.6 | 勝率0.65 | 勝率0.7 |
|---|---|---|---|---|
| 10 | 26.2% | **16.6%** | 9.5% | 4.7% |
| 20 | 24.9% | 12.8% | 5.3% | 1.7% |
| 40 | 21.3% | 7.4% | 1.7% | 0.2% |
| 80 | 15.6% | 2.7% | 0.2% | 0.0% |
| 140 | 10.2% | 0.7% | 0.0% | 0.0% |

- 負け越す確率が5%を下回るのは、勝率0.6で56試合、0.65で22試合、0.7で10試合、0.55で250試合から。1%を下回るのは、勝率0.6で122試合から
- 偶数の試合数では五分がありうる。五分になる確率は10試合・勝率0.6で20.1%、40試合で5.5%

### 140試合のシーズン（勝率0.6、乱数2万回）
- 10試合ごとに14区間に分けると、負け越す区間は1シーズンに平均2.3区間あり、少なくとも1区間は負け越すシーズンが92%だった
- 連続する10試合（どこから数えてもよい131区間）で見ると、負け越す区間のあるシーズンは99.5%、3勝以下の区間のあるシーズンも87%だった
- 140試合を通して負け越したのは0.7%だった

### 確かめ：置き方を変えると（10試合）
| 置き方 | 負け越す確率 |
|---|---|
| 基本（毎試合 勝率0.6、式） | 16.6% |
| 引き分け1割（決着した試合の勝率0.6） | 21.3% |
| 引き分け2割（決着した試合の勝率0.6） | 22.6% |
| 相手ごとに勝率が違う（平均0.6・0.44〜0.76） | 16.1% |
| 相手ごとに勝率が違う（平均0.6・0.29〜0.91） | 14.3% |
| 勢いあり（勝った次は0.7、負けた次は0.45） | 22.5% |
| 勢いあり（勝った次は0.8、負けた次は0.30） | 28.0% |
| 本当の勝率を0.55にする | 26.2% |
| 本当の勝率を0.65にする | 9.5% |

- 置き方で、負け越す確率は9.5〜28.0%まで動いた。勝率0.6のまま置き方だけを変えた行では14.3〜28.0%
- 引き分けがあると決着する試合が減り、負け越しは増えた。勢い（勝つと次も勝ちやすい）を入れると、勝ち負けが固まって出るので、負け越しは増えた
- 相手ごとに勝率が違う日程では、少し減った（試合ごとの勝ち負けの読みやすさが上がるため）

## 注意（言えないこと）
- 架空のチームです。本当の勝率、引き分けの割合、相手の違い、勢いの大きさは作成者が置いたもので、結果はこれで決まります。置き方で、10試合で負け越す確率は9.5〜28.0%まで動きました
- 「本当の勝率」は、作成者が置いたので分かっています。実際のチームでは本当の勝率は分からず、10試合の成績から本当の勝率を当てることはこの記事では扱っていません
- 選手の入れ替え・日程の詰まりなど、本当の勝率そのものが途中で変わることは入れていません。実際の負け越しに、偶然と本当の変化のどちらがどれだけ混ざっているかは、この分析では分けられません
- 実在のチーム・リーグの成績を表すものではありません
