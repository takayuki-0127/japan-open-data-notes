# 1053 1回ずつ測った処理時間で速い方を選ぶと、何回に1回まちがえるのか？（処理の速さ）

2つのやり方 A・B の処理時間を1回ずつ測り、短かった方を「速い」と決めることがあります。けれども、同じ処理でも1回ごとの時間は振れ、まれに大きく遅れる回もあります。本当の差が小さいと、1回ずつの比べでは遅い方を選んでしまうことがよくあります。**ここでは、作成者が置いた分布から乱数で作った架空のアプリの処理時間（実機では測っていない）で、本当は B が約5%速いとき、1回ずつの比べで A が速いと出る割合と、A・B を何回ずつ測って平均すればまちがいが5%以下になるかを数えました。本当の差・ふだんのばらつき・まれな遅れの確率を変えた36通りでも確かめました。**

平均・中央値・最小値のどれで比べるかで速い方が入れかわるかは、同じ企画の関連する記事 1055、A のあとに B を測る順番を固定すると何が差にまざるかは 1056 で扱っています。測る台そのものが違うと、何回測っても縮まらない差が残ることは 1061、少ない日の記録で「いちばん速い道」を選ぶと外れることは 1038、件数の少ない平均が上にも下にも振れることは 801 で扱っています。この記事は、1回（または n 回）ずつの比べで遅い方を選んでしまう割合と、それを減らすのに要る回数に絞ります。

## 主な結果

### 基本の置き方（本当の差5%・ばらつき10%・まれな遅れ5%）
| | 値 |
|---|---|
| 本当の平均の処理時間 | A 123.6ミリ秒・B 117.57ミリ秒（B が4.88%短い） |
| 本当の中央値 | A 120.66ミリ秒・B 114.65ミリ秒 |
| **1回ずつの比べで A が速いと出る割合** | **36.83%** |
| まれな遅れがないときの1回ずつのまちがい | 35.82%（式どおりの値は35.84%） |
| 10回ずつの平均で比べたときのまちがい | 22.47% |
| **まちがいが5%以下になるのに要る回数（A・B 各）** | **75回** |

- 本当は B が約5%速いのに、1回ずつ比べると36.83%、ほぼ3回に1回は A を速いと選んだ
- まれな遅れがないときの値は、対数正規分布の式 Φ(ln(1−d)÷(σ×√2)) どおり（35.82%対35.84%）。1回ずつのまちがいは、本当の差 d と1回ごとのばらつき σ の比でほぼ決まる
- 同じ速さ（d＝0）の2つでも、1回ずつの比べで「5%以上違う」と出たのは73.64%、10回ずつの平均でも42.94%だった

### 何回ずつ測って平均すればよいか（基本、1万組、`results/wrong_by_n.csv`）
| A・B 各何回の平均 | まれな遅れなし | まれな遅れ5%（基本） | まれな遅れ20% |
|---|---|---|---|
| 1回 | 35.4% | 35.94% | 39.12% |
| 3回 | 26.15% | 29.57% | 36.04% |
| 10回 | 12.1% | 22.47% | 33.9% |
| 30回 | 2.35% | 13.41% | 26.38% |
| 100回 | 0.02% | 3.04% | 12.93% |
| **5%以下になる回数** | **21回** | **75回** | **214回** |

- まれな遅れが5%入るだけで、まちがいを5%以下にするのに要る回数は21回から75回に増えた。20%では214回だった
- 平均はまれな大きな遅れに引っぱられるので、回数を増やしても、まちがいはなかなか減らない
- この表の1回の値（35.94%）は、上の表の200万組の値（36.83%）と0.89ポイント違う。1万組で数えた振れの分

### 36通りの確かめ（各4,000組、`results/grid.csv`）
| | 値 |
|---|---|
| 1回ずつのまちがい | 0.05〜49.1% |
| 10回ずつの平均のまちがい | 0〜46.15% |
| まちがいが5%以下になる回数 | 1〜832回（3通りは1,000回でも届かない） |
| まれな遅れなしの12通りで、式どおりの値との差 | 最大1.14ポイント |

- 本当の差が2%でまれな遅れ20%の3通りでは、1,000回ずつ測ってもまちがいは5%以下にならなかった
- 本当の差20%・ばらつき5%（まれな遅れなし・5%）の2通りだけが、1回ずつでまちがい5%以下だった
- 本当の差10%・ばらつき5%・まれな遅れ20%では、10回ずつの平均のまちがい（21.25%）が1回ずつ（19.55%）より大きかった（36通り中1通り）。ふだんの差がはっきりしているときは、平均にまれな遅れが混ざることのほうが比べを乱すと考えられる（推測）
- 基本と同じ置き方の通りでは5%以下まで74回で、上の表（75回）と1回違う。組の数（4,000組と1万組）による振れの分

## 注意（言えないこと）
- 架空のデータです。処理時間の分布（対数正規分布＋まれな遅れ）、本当の差、ばらつき、まれな遅れの確率と大きさは作成者が置いたもので、結果はこれで決まります。1回ずつのまちがいは置き方で0.05〜49.1%、5%以下に要る回数は1回から1,000回超まで動きました。実在のソフトやサーバーで測った値ではありません
- 1回ごとの時間は互いに関係なく（でたらめに）振れると置きました。実際の計測では、測る順番や機械の状態の変化で振れがそろって動くことがあり、そのときは回数を増やしても減らないずれが残ります（推測。順番の話は 1056、台の違いの話は 1061）
- 比べ方は n 回ずつの「平均」だけです。中央値や最小値で比べるとどうなるかは 1055 で扱っています
- 何回測るべきかの決まりを示すものではありません。本当の差とばらつきの大きさによって、要る回数が何百倍も変わることを数えただけです
