### labour-force-japan：総務省「労働力調査」長期時系列で、就業者の増え方と非正規の割合を調べる

総務省統計局「労働力調査」の長期時系列表（基本集計 表3-1・3-3：男女×5歳階級の15歳以上人口と就業者、1968〜2025年／詳細集計 表10-2：男女×5歳階級の雇用形態別雇用者、2002〜2025年）を使ったリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| W1 | 就業者の増減は、女性・高齢者・それ以外のどこから来たか。人口が増えたからか、働く人の割合が上がったからか | 男女×年齢（15〜64歳／65歳以上）別の増減の寄与、男女×5歳階級ごとに「人口の変化×平均就業率」と「就業率の変化×平均人口」に分ける分解（期間：1990→2000、2000→2012、2012→2019、2019→2025） | `src/w1_growth.py` |
| W2 | 非正規の職員・従業員の割合は、男女・年齢別にどう変わったか。全体の割合の変化は年齢構成の変化でどこまで説明できるか | 役員を除く雇用者に占める非正規の割合（男女×年齢）、非正規・正規の人数の増減（年齢別）、全体の割合の変化を「年齢別の割合の変化」と「男女×年齢の構成の変化」に分けるシフト・シェア分解 | `src/w2_nonregular.py` |

#### 主な結果
- **W1**：就業者は2012年の6,279万人から2025年の6,830万人へ550万人増えた（男女×年齢の合計、公表値は6,828万人）。内訳は女性15〜64歳＋299万人、女性65歳以上＋170万人、男性65歳以上＋177万人、男性15〜64歳−96万人で、女性と高齢者の増加が全体の増加を上回った。男女×5歳階級で分けると、人口の変化による分は−362万人、就業率の上昇による分は＋912万人。女性の30〜34歳の就業率は65.5%→84.0%、60〜64歳は44.5%→65.8%。65歳以上の就業者は596万人→943万人。2019→2025年の増加は79万人にとどまった
- **W2**：役員を除く雇用者に占める非正規の割合は29.4%（2002年）→36.6%（2013年）→38.2%（2019年）→36.5%（2025年）。女性は49.3%→55.8%→52.0%、男性は15.0%→21.2%→22.3%。2013→2025年に非正規は1,910万人→2,128万人と218万人増えたが、そのうち65歳以上が＋242万人で、25〜44歳は−181万人。女性25〜34歳の割合は41.5%→28.7%、男性55〜64歳は32.7%→23.3%と下がった。2013→2025年の全体の割合はほぼ横ばい（−0.1ポイント）だが、年齢別の割合の低下（−3.9ポイント）と、非正規の多い高齢層が増えた構成の変化（＋3.8ポイント、うち65歳以上の分＋3.4ポイント）が打ち消し合っていた

#### データ
| ファイル | 中身 |
|---|---|
| data/emp_pop_5yr.csv | 年（1968〜2025）×男女×5歳階級（65歳以上と、65〜69・70〜74・75歳以上）：15歳以上人口、就業者（万人） |
| data/emptype_5yr.csv | 年（2002〜2025）×男女×5歳階級：就業者、雇用者、役員を除く雇用者、正規の職員・従業員、非正規の職員・従業員（万人、詳細集計） |
| data/rodo_raw.zip | 上の元になった Excel 3本 |

#### 注意
- 各表の「既公表値」ではなく、人口の基準を切り替えたときに過去分を補正した値（時系列接続用の値）のシートを使っています
- 1972年以前は沖縄県を含みません。1973年は沖縄を含む行を使いました。2011年は岩手・宮城・福島の3県を補完的に推計した値です
- 65〜69歳・70〜74歳・75歳以上の内訳がない年があるため、W1 の分解は「65歳以上」をひとまとめにしています
- 万人単位で四捨五入された値を足しているので、男女や年齢の合計は公表の総数と数万人ずれることがあります
- 詳細集計（W2）は基本集計とは別の集計で、同じ年齢の就業者数でも基本集計と違います（例：2025年の15〜19歳は基本集計117万人、詳細集計133万人）。W1 と W2 の数字は混ぜていません
- 非正規の割合は「正規＋非正規」に対する非正規の割合で、役員を除く雇用者に対する割合です
- 労働力調査は世帯への標本調査で、外国人も日本に住んでいれば対象に含まれますが、国籍別の集計はないため、外国人の寄与は分けていません
- 就業率の変化には、働きたい人が増えたことと、働き口が増えたことの両方が含まれていて、この分析では区別できません
