# tourism-daytrip-japan

観光庁「共通基準による観光入込客統計」の都道府県別・年間値で、観光客のうち日帰りの割合を都道府県ごとに比べた分析です（note 記事 130 のコードと集計結果）。

## 問い・手法

| 問い | 手法 | スクリプト |
|---|---|---|
| 観光客はどの県で「日帰り」が多いのか | 日本人・観光目的の観光入込客数（実人回）を、県内・県外 × 宿泊・日帰りに分けて割合を計算。各都道府県で2016〜2019年のうち集計がある最新の年を使い、44都道府県を比較。人数の割合と観光消費額の割合も比べた | `src/a130_daytrip.py` |

## 主な結果

- 日本人・観光目的の観光客のうち日帰りの割合は、44都道府県の中央値で84.9%、合計では89.7%。
- 高いのは埼玉県98.5%、東京都97.4%（2017年）、愛知県95.3%。低いのは和歌山県50.7%（2018年）、長野県70.1%、高知県74.0%（2016年）、岩手県74.0%。
- 県内から来た客の日帰り割合（中央値92.3%）より、県外から来た客の日帰り割合（中央値78.7%）のほうが低い。県外客で最も低いのは北海道の5.5%（2017年）。
- 観光消費額で見ると日帰りの割合は合計65.3%、中央値55.6%。日帰りの消費額単価（中央値：県内4,095円、県外7,502円）は宿泊（19,466円、27,386円）の4分の1前後。
- 2016年（44都道府県）の日帰り割合は、日本人・観光目的89.8%、日本人・ビジネス目的35.3%、訪日外国人23.1%。

## 動かし方

```
pip install -r requirements.txt
python src/a130_daytrip.py
```

`data/irikomi_pref_year.csv`（整理済みの表）があればそれを使います。消してから実行すると、`data/raw.zip`（元の集計表 Excel 13年分）を `data/raw/` に展開して作り直します。

## データ

- `data/irikomi_pref_year.csv`：年（2010〜2022）× 都道府県 × 区分（日本人・観光目的／日本人・ビジネス目的／訪日外国人）× 県内・県外 × 宿泊・日帰り の観光入込客数（千人回）、観光消費額単価（円/人回）、観光消費額（百万円）。集計表1〜3から作成。「集計中」は欠測。
- `data/raw.zip`：元の集計表（Excel）。2022年は `130_annual_2022_new.xls` を使用。
- 2010年は「平成22年度」（年度）、2011年以降は暦年の表。
- 元データ：観光庁「共通基準による観光入込客統計」https://www.mlit.go.jp/kankocho/tokei_hakusyo/irikomikyaku.html （2021年以前の表は国立国会図書館インターネット資料収集保存事業 WARP の保存版から取得）

## 注意

- 都道府県が共通基準で調査・集計した値で、年によって集計がそろっていない県がある（2019年は32都道府県、2022年は20都道府県）。そのため年ごとの全国合計は比べられない。
- 石川県・大阪府・沖縄県は2016〜2019年の集計がなく、比較に入っていない。
- 観光入込客数は「実人回」で、1人が同じ県の複数の観光地点を訪れても1回と数える。訪問者の推計方法は県ごとの調査に依存する。
- 年の違う県を並べているので、厳密に同じ時点の比較ではない。
