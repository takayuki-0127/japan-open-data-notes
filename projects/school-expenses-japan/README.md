# school-expenses-japan：文部科学省「子供の学習費調査」で、公立と私立の学習費の差が何に使われているかを調べる

文部科学省「子供の学習費調査」（令和5年度）の年次統計（学校種別・支出項目別、1994〜2023年度）を使ったリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| 133 | 公立と私立の学習費の差は、何に使われているか。差は広がったか | 2023年度の私立−公立の差を7つの費目に分解、私立÷公立の比と学習塾費の年次推移 | `src/a133_gap.py` |

## 主な結果
- 2023年度の学習費総額（子ども1人・年間）は、公立と私立で幼稚園18.5万円・34.7万円（1.9倍）、小学校36.7万円・174.2万円（4.8倍）、中学校54.2万円・156.0万円（2.9倍）、高校（全日制）59.7万円・117.9万円（2.0倍）
- 差のうち、授業料が37〜45%（小学校・中学校・高校）、学校納付金等（入学金・施設整備費など）が13〜25%。授業料・納付金・そのほかの学校教育費を合わせた「学校に払うお金」は、差の66%（小学校）、96%（中学校）、83%（高校）、52%（幼稚園）
- 小学校では学習塾費の差（18.4万円、差の13%）と習い事などの差（19.9万円、15%）も大きい。中学校は逆に公立のほうが学習塾費が多く（公立23.0万円、私立16.8万円）、塾の分だけ差が6.2万円縮まる
- 私立÷公立の比は、中学校が2.5〜2.9倍、小学校が4.1〜5.0倍で、30年でほぼ同じ幅。幼稚園は2018年度の2.4倍から2021年度に1.9倍に下がった（公立22.4万円→16.5万円、私立52.8万円→30.9万円）。高校は2010年度に公立の授業料が0円になって比が2.3倍に上がり、2023年度は2.0倍

## 動かし方
`data/learning_cost.csv`（学校種別×公私×年度×費目に整えたもの）が入っているので、そのまま動きます。元の Excel から作り直すときは、この CSV を消して実行してください（`data/raw.zip` を自動で展開します）。

```bash
pip install -r requirements.txt
cd src
python a133_gap.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/raw.zip | e-Stat「子供の学習費調査」令和5年度 年次統計「学校種別支出項目別経費の推移」（幼稚園・小学校・中学校・高等学校（全日制））、項目別経費の金額段階別構成比 |
| data/learning_cost.csv | school, setting（公立／私立）, year（調査年度）, item（費目。同じ名前の費目は「親の費目/費目」）, yen（子ども1人当たりの年間の金額、円） |

## 注意
- 調査は2年ごと（2018年度の次は2021年度）。私立小学校は2006年度から
- 金額は、その学校に通う子ども全体の平均（支出しなかった人も0円として含む）。物価の上昇は差し引いていない名目の金額
- 費目の分け方は2021年度調査で変わり（入学金・施設整備費等などを細かく分けた）、それ以前と細かい費目は比べられない。この分析で使った大きな費目（授業料、学校納付金等、学校給食費、学習塾費、補助学習費、その他の学校外活動費）は通して使える
- 公立小中学校の授業料は0円（表では「…」）。高校の公立授業料は2010年度に不徴収、2014年度から就学支援金（所得制限あり）
- 学校給食費は高校では調査していない。私立中学校は給食のない学校が多い
- 差がどんな家庭の違い（所得、住んでいる地域など）によるかは、このデータでは分からない
