# side-jobs-japan：就業構造基本調査で、副業をしている人の働き方・年収・職業を調べる

総務省「令和4年就業構造基本調査」全国結果の集計表（第76表・第84表・第206表）を使ったリポジトリです。個票ではなく、公表されている集計表（推計人数）を使っています。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A126 | 副業をしている人は、どんな働き方・本業の年収・職業に多いか | 本業の所得×従業上の地位・雇用形態×男女別の副業者比率、集計表からのグループ化ロジスティック回帰（オッズ比）、本業の職業×副業の職業のクロス表 | `src/a126_sidejob.py` |

## 主な結果
- 有業者6,706万人のうち副業がある人は332万人（5.0%）。正規の職員・従業員は2.6%、非正規の職員・従業員は7.3%、自営業主8.8%、会社などの役員9.2%、フリーランス（別掲）9.9%
- 本業の年間所得で見るとU字型：50万円未満9.7%、50〜99万円8.2%、300〜399万円3.2%、700〜799万円2.5%で最も低く、1,000〜1,249万円5.0%、1,500万円以上9.6%
- 男女と働き方をそろえても所得のU字は残る（300〜399万円を1としたオッズ比：50万円未満1.86、700〜799万円0.83、1,500万円以上1.89）。働き方では正規に比べて役員3.2倍、自営業主2.8倍、非正規2.2倍（オッズ比）。男女差は小さい（女性0.92）
- 副業がある人の本業の職業は、専門的・技術的職業が76万人（23%）で最も多く、事務54万人、サービス51万人。専門的・技術的職業の人の58%は副業も専門的・技術的職業。副業の職業全体では専門的・技術的23%、サービス16%、販売11%、事務11%

## 動かし方
`data/` に集計表を縦長に直した CSV が入っているので、そのまま動きます。元の Excel から作り直すときは、e-Stat（https://www.e-stat.go.jp/stat-search/files?toukei=00200532 → 令和4年就業構造基本調査 → 全国編）の第76表・第84表・第206表を `data/raw/126_r4_076.xlsx` などの名前で置き、CSV を消してから実行してください。

```bash
pip install -r requirements.txt
cd src
python a126_sidejob.py
```

## データ
| ファイル | 中身 |
|---|---|

| data/126_r4_084.csv | 第84表：男女×本業の従業上の地位・雇用形態×本業の職業×副業の職業（副業がある者。副業の地位は総数だけ残した） |
| data/126_r4_076.csv | 第76表：男女×本業の従業上の地位・雇用形態×本業の職業（副業がある者。就業日数は総数・200日未満・200日以上だけ） |

## 注意
- 集計表の推計人数を使っていて、個人のデータではありません。ロジスティック回帰は、集計表の人数を重みにした「グループ化データ」の当てはめで、標準誤差や検定は意味を持たないため、オッズ比だけを示しています
- 本業の職業別の「有業者の総数」はこのリポジトリに入れた表にないため、職業別の副業者比率は計算していません。職業は副業がある人の内訳だけです
- 非正規の職員・従業員で所得が高い区分（800万円以上）は人数が少なく（数千〜数万人）、割合の振れが大きくなります
- 本業の所得は、ふだん得ている年間の収入（税込み）を区分で答えたものです。副業の所得は入りません
- 副業がある理由（収入、スキル、つきあいなど）はこの表からは分かりません
