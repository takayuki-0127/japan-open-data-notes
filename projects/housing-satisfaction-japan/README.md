# housing-satisfaction-japan

国土交通省「住生活総合調査」の表4（住宅及び居住環境の総合満足度 × 各要素の満足度）で、住まいのどの点に不満が多いか、10年でどう変わったか、どの不満が「総合的な不満」と結びつきやすいかを見た分析です（note 記事 129 のコードと集計結果）。

## 問い・手法

| 問い | 手法 | スクリプト |
|---|---|---|
| 住まいへの不満は何に多く、10年でどう変わり、どれが総合的な不満と結びつくか。持ち家と借家で総合的な不満はどう違うか | 要素ごとの不満の割合（「多少不満」＋「非常に不満」、不明を除く）を2013・2018・2023年で計算。2013年と2023年で内容が近い28項目を対応させて変化を比較。2023年は、要素に不満な世帯と満足な世帯で「総合での不満の割合」の差と比を計算。持ち家・借家×世帯の型の総合の不満の割合（2023年のみ） | `src/a129_satisfaction.py` |

## 主な結果

- 住宅と居住環境の総合で不満な世帯は、22.2%（2013年）→21.6%（2018年）→21.4%（2023年）。
- 2023年に不満の割合が高いのは、近隣のシェアオフィスなど仕事のできる環境50.2%、敷地やまわりのバリアフリー45.9%、高齢者への配慮45.8%、断熱性43.3%、エネルギー消費性能41.9%、地震に対する安全性40.5%。低いのは治安17.7%、広さや間取り22.4%、公園や緑・水辺22.4%。
- 2013年と2023年で対応させた28項目は、すべて不満の割合が下がった。大きく下がったのは治安（37.4%→17.7%）、換気（36.7%→25.5%）、高齢者への配慮（54.8%→45.8%）、地震への安全性（49.4%→40.5%）。ほとんど変わらないのはプライバシー（25.2%→24.7%）と断熱性（45.0%→43.3%）。
- 2023年、要素に不満な世帯の総合での不満の割合は31〜46%、満足な世帯は12〜17%。差が大きいのは治安（46.2%対16.0%）、プライバシー確保（43.8%対14.0%）、維持管理のしやすさ（41.6%対12.8%）。
- 2023年の総合の不満は、持ち家19.9%、借家25.2%。借家の65歳以上の単独世帯は28.6%、持ち家の子育て世帯（長子17歳以下）は15.6%。

## 動かし方

```
pip install -r requirements.txt
python src/a129_satisfaction.py
```

`data/satisfaction_t4.csv`（整理済みの表）があればそれを使います。消してから実行すると、`data/raw.zip`（元の表4、3年分）を `data/raw/` に展開して作り直します。

## データ

- `data/satisfaction_t4.csv`：年（2013・2018・2023）× 区分（住宅／居住環境／属性）× 項目 × 回答（満足・まあ満足・多少不満・非常に不満・不明）ごとの世帯数（千世帯）と、その総合満足度の内訳。
- `data/raw.zip`：e-Stat の住生活総合調査 表4（2013年・2018年・2023年）。
- 元データ：国土交通省「住生活総合調査」（e-Stat、statInfId 000031318812・000031971253・000040313606）

## 注意

- 調査票の項目は年によって言い回しや数が違う（2013年は住宅17・居住環境17項目、2023年は住宅18・居住環境18項目）。変化の比較は内容の近い項目を対応させたもので、言い回しの変化の影響を含む（例：「治安、犯罪発生の防止」→「治安」）。
- 表4には、要素別の満足度を持ち家・借家に分けた値はない。持ち家・借家の比較は総合満足度だけ、2023年だけ。
- 標本調査の推計値（千世帯）。総合と要素の関係は同じ世帯の回答の結びつきで、どちらが原因かは分からない。
