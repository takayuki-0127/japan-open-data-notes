# product-concentration-japan：製造品の出荷金額が「一つの県に集中」している品目を調べる

総務省・経済産業省「経済構造実態調査（製造業事業所調査）」の品目別統計表 第3表「品目別、都道府県別の出荷及び産出事業所数」（2025年調査＝2024年実績、2022年調査＝2021年実績）を使ったリポジトリです。

| # | 問い | 手法 | スクリプト |
|---|---|---|---|
| A128 | 製造品の出荷金額で、一つの県に集中している品目はどれか。どの県が1位の品目を多く持つか | 品目ごとの上位1県のシェアとHHI（ハーフィンダール・ハーシュマン指数）。秘匿値（X）は全国計との差から下限と上限を計算 | `src/a128_concentration.py` |

## 主な結果（2024年実績、全国の出荷金額100億円以上の1,373品目）
- 上位1県のシェアの中央値は24%。公表された値だけで1県が全国の50%以上を占めるのは137品目（10%）。秘匿分がすべて1県にまとまっていたと仮定した上限では598品目（44%）
- 秘匿（X）の県の合計が全国の20%以下の606品目で上位1県のシェアが高いのは、ピアノ（静岡県100%）、その他の複写機（大分県97%）、国内産の甘味資源作物からの精製糖（北海道96%）、まぐろ缶詰（静岡県96%）、その他の炭素質電極（京都府94%）、紙幣識別ユニット・貨幣区分ユニット（埼玉県94%）、眼鏡枠（福井県92%）など
- 出荷金額が全国1位の品目が多いのは愛知県184、大阪府140、兵庫県100、埼玉県75、静岡県70。その県だけで全国の50%以上を占める品目は、愛知県25、静岡県14、大阪府12
- 2021年と2024年の両方で100億円以上の1,316品目では、1位の県が同じだったのは64%、上位1県のシェアの相関は0.86。中央値は23.8%→24.1%でほとんど変わらない

## 動かし方
`data/` に整えた CSV（品目×都道府県の出荷金額、品目名、県名）が入っているので、そのまま動きます。元の Excel から作り直すときは、品目別統計表（e-Stat：https://www.e-stat.go.jp/stat-search/files?toukei=00200555 の「製造業事業所調査」→「品目別統計表」）を `data/raw/128_2025_hinmoku.xls`・`data/raw/128_2022_hinmoku.xls` として置き、`data/ship_*.csv` を消してから実行してください。

```bash
pip install -r requirements.txt
cd src
python a128_concentration.py
```

## データ
| ファイル | 中身 |
|---|---|
| data/ship_<年>_a.csv, _b.csv | year, item_code（6桁の品目コード）, pref_code（00＝全国計）, value_mil_yen（出荷金額、百万円。秘匿は空）, secret（1＝X）, establishments（産出事業所数）。品目コードの上2桁が26未満を a、それ以外を b に分けた |
| data/items.csv | year, item_code, item（品目名） |
| data/prefs.csv | pref_code, pref |

## 注意
- 「X」は集計対象の事業所が1か2で、そのままだと個々の事業所の値が分かってしまうため秘匿された値です。秘匿の県の合計は「全国計−公表された県の合計」で分かりますが、県ごとの内訳は分かりません。HHIと上位1県のシェアは、残りを秘匿の県で等分した場合（下限に近い）と、残りが1県にまとまっていた場合（上限）の両方を計算しました（`results/a128_concentration_all.csv`）
- 品目の順位は、秘匿分が全国の20%以下で、公表値だけで1位の県が決まる品目に限りました。それ以外の品目では、秘匿された県のほうが大きい可能性があります
- 出荷金額は事業所のある県で数えています。本社の所在地ではありません。個人経営の事業所は含みません
- 2021年と2024年は品目の数が少し違う（1,777品目と1,780品目）ため、比較は両方の年にある品目コードだけで行いました
